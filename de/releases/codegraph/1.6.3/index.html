Codegraph v1.6.3

[1.6.3] – 17.11.2026

Highlights

  • Neun weitere Agenten und Redakteure. codegraph install richtet jetzt IBM Bob, Factory Droid, Windsurf, Qwen Code, DeepSeek Harness, Grok Build, Kimi Code, den Qoder CLI und Pi ein.
  • Sicherheitskorrekturen. Ein sensibler Ordner wie ~/.ssh kann nicht mehr als Projekt über einen Link, eine Verknüpfung oder eine andere Schreibweise seines Pfads geöffnet werden, und der gebündelte Node.js wird nach 24.22.1 verschoben, wodurch CVE-2026-111497 behoben wird.
  • Genauere Links in jeder Sprache. Hunderte von Fixes helfen Aufrufen, Importen und Typen dabei, den Code zu erreichen, den sie bedeuten, vor allem in JavaScript und TypeScript, Go, C und C++, Rust, Python, C#, Java und Dart. Tauri, CodeIgniter 3, Drupal-Dienste und -Plugins, Next.js-Middleware und MediatR-Handler werden jetzt ebenfalls abgedeckt.
  • Bessere Antworten für Ihren Agenten. codegraph_explore bleibt bei einem großen Projekt nicht länger stehen, antwortet in Sekundenschnelle auf ein eingefügtes Protokoll oder eine eingefügte Datei, findet Code mit Namen auf Chinesisch, Japanisch oder Koreanisch und sein Flow erreicht jedes Symbol Ihrer Abfragenamen.
  • Neue Befehle. codegraph cycles findet Dateien, die sich gegenseitig in einem Kreis importieren, codegraph implementations listet auf, was einen Typ implementiert, codegraph files --format package teilt ein Monorepo nach Paket auf und codegraph init --local-only hält .codegraph/ aus Git fern.
  • Ein stabilerer Hintergrundserver. Eine neue Sitzung wartet nicht länger mehrere Minuten, wenn der Hintergrundserver hängen bleibt. Durch ein Upgrade während einer Sitzung wird auf die neue Version umgeschaltet, und codegraph sync und der Dateiwächter behalten die Links beim Hinzufügen, Löschen und Wiederherstellen von Dateien bei.
  • Schneller und leichter. Befehle, die nur den Index lesen, starten schneller und die Indizierung benötigt weniger CPU und Speicher, vor allem bei kleinen Projekten sowie in C und C++.
  • Aktualisierung: Indizieren Sie Ihre Projekte nach dieser Version mit codegraph index neu. Die meisten dieser Korrekturen werden während der Indizierung geschrieben, und codegraph status und Ihr Agent teilen Ihnen beide mit, wann ein Index von einer älteren Version erstellt wurde.

Zuvor wurde eine Sitzung in einer Sitzung gestartet, die einen Index enthielt, der aus den darin enthaltenen Dateien beantwortet wurde. (#3012) – Die gebündelte Node.js-Laufzeit wird auf 24.22.1 verschoben, die Oktober-Sicherheitsversion von Node, die CVE-2026-111497 behebt, einen hochgradigen Out-of-Bounds-Schreibvorgang in seinem Brotli-Decoder, und jede Version prüft nun den gebündelten Node anhand der von nodejs.org veröffentlichten Prüfsummen.   • In Ruby, a call on a method's parameter now links to the right class when every call of that method in the project passes a value of one class.
