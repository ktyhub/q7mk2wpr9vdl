11/20
v1.6.4 Patch MT

Kleine Fragen kosten weniger. Fragen Sie Ihren Agenten, was eine Funktion oder Konstante ist oder wer sie aufruft, und codegraph_explore antwortet jetzt mit der Definition und jeder Zeile, die sie verwendet, statt einer langen Antwort zu zugehörigen Dateien.

 11/17
v1.6.3 Patch MT

Neun weitere Agenten und Redakteure. Codegraph Install richtet jetzt IBM Bob, Factory Droid, Windsurf, Qwen Code, DeepSeek Harness, Grok Build, Kimi Code, den Qoder CLI und Pi ein.

 10/03
v1.6.2 Patch MT

Weitaus weniger falsche Links, in jeder Sprache. Ein Aufruf, Import oder Typ löst jetzt die Art und Weise auf, wie seine Sprachbereiche Namen umfassen – durch Importe, Pakete, Namespaces und die Klasse, in die er geschrieben ist – sodass er nicht mehr auf einem… landet.

 09/29
v1.6.1 Patch MT

Schärfere Antworten von codegraph_explore. Es gibt die von Ihnen benannten Funktionen und Methoden zurück – selbst aus einer sehr großen Datei oder einer Datei voller gleichnamiger Überschreibungen –, berücksichtigt Zeilennummern in einer Abfrage und sagt, wann eine Datei gekürzt wurde.

 08/26
v1.6.0 Minor MT

GitHub Copilot wird jetzt unterstützt – Codegraph Install richtet es in VS Code, den Copilot CLI- und JetBrains-IDEs neben den Agenten ein, die es bereits kannte.

 07/21
v1.5.0 Minor MT

Diese Version baut die Parsing-Engine von CodeGraph als nativen Rust-Kernel neu auf, überarbeitet die Auflösungspipeline um sie herum und macht das Live-Diagramm praktisch sofort verfügbar: Ein Speichervorgang erreicht das Diagramm jetzt in deutlich weniger als einer Sekunde …

 07/10
v1.4.1 Patch MT

Der MCP-Server erkennt jetzt, wenn eine neuere CodeGraph-Version vorhanden ist, und teilt Ihnen dies mit – ein Server mit langer Laufzeit, der früher stillschweigend hinter Versionen herdriftete, bis etwas kaputt ging.

Methodenaufrufe, die über eine lokale Variable erfolgen, werden jetzt in vielen weiteren Sprachen in die Methode aufgelöst. Wenn der Code const logger = new Logger(); logger.log();
