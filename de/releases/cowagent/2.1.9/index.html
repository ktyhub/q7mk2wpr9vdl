CowAgent 2.1.9

🌐 Englisch | 中文

Dies ist eine Weiterentwicklung der [2.1.8 Multi-Agent-Version] (https://docs.cowagent.ai/releases/v2.1.8), die darauf aufbaut und eine Reihe von Verbesserungen und Korrekturen in den Bereichen Multi-Agent-Zusammenarbeit, Modellfunktionen und Kanalintegration enthält.

🤝 Multi-Agent-Erfahrung

Weitere Verbesserungen beim Einsatz von Multi-Agent-Teams:

  • Multi-Agent-Sitzungsauswahl: Die Multi-Agent-Auswahl während der Sitzung fügt eine Lead-Agent-Markierung hinzu, die den Lead-Agent klar von den Mitgliedern trennt und gleichzeitig die Ansicht in Einzel-Agent-Setups vereinfacht.
  • Korrektur bei der Zusammenarbeit: Fehler beim Delegieren von Aufgaben von nicht leitenden Agenten in Gruppenchats mit mehreren Agenten behoben, wodurch Mitgliedsagenten jetzt korrekt identifiziert werden.
  • Bildwiedergabe von Mitgliedsagenten: Es wurde ein Problem behoben, bei dem Bilder, die von nicht standardmäßigen Agenten generiert wurden, auf der Webkonsole und dem Desktop client nicht gerendert werden konnten.
  • Gruppenchat-Eintrag: Die Desktop-Seite Team fügt einen Gruppenchat-Eintrag hinzu, sodass Sie eine Gruppensitzung direkt von einem Agententeam aus starten können.
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/agent-group-chat-picker.png" alt="Gruppenchat mit mehreren Agenten" width="800" />

📡 Kanalintegrationskorrekturen

Wichtige Probleme entlang des Kanal-Start-/Stopp-Pfads der Konsole wurden behoben, um eine stabilere Kanalintegration zu gewährleisten:

  • Fix für die Integration von Desktop-Kanälen: Es wurde ein Problem behoben, bei dem Kanäle im Desktop client nicht gestartet werden konnten.
  • Channel Stop Fix: Es wurde ein verlorener app_module-Lookup während des Channel Stop Flows behoben, der Verbindungsfehler verursachte (eine durch #3141 eingeführte Regression).
  • Wiederverbindung des QQ-Kanals: Es wurde behoben, dass der QQ-Kanal nach einer stillen WebSocket-Trennung nicht wieder eine Verbindung herstellte. Die Verbindung wird jetzt automatisch wiederhergestellt.

🤖 Modellfähigkeiten

  • Konfiguration der Modellliste: Modellanbieter können jetzt eine Modellliste konfigurieren und dabei den Modellnamen, den Modelltyp, das Kontextfenster, die maximale Ausgabe und mehr festlegen. Danke @alanyz106 (#3146)
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-catalog-config.png" alt="Modelllistenkonfiguration" width="800" />
  • Mehrere Fallback-Modelle: Wenn das primäre Modell ausfällt, versucht CowAgent nun nacheinander eine geordnete Fallback-Kette und ersetzt so das vorherige einzelne Fallback-Modell. Danke @alanyz106 (#3125)
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-fallback-chain.png" alt="Mehrere Fallback-Modelle" width="800" />
  • Fix für Fallback-Anmeldeinformationen: Die Auflösung der Anmeldeinformationen während des Fallbacks wurde korrigiert, wodurch Anmeldeinformationen jetzt nach dem tatsächlich weitergeleiteten Anbieter und nicht nach der globalen Konfiguration aufgelöst werden. Danke @alanyz106 (#3142)
  • Neue Bildmodelle: gpt-image-2.5-flare und gpt-image-2.5-sunburst hinzugefügt. Danke @cowagent (#3140)

🛠 Verbesserungen und Korrekturen

– Konfigurationsdateitoleranz: Toleriert ein UTF-8-BOM in config.json und stoppt die 401-Abfrage vor der Anmeldung, um ungültige Anfragen vor der Anmeldung zu vermeiden.

  • Korrekturen bei der Bildgenerierung: – Es wurde behoben, dass Baidu Ernie IMAGE_CREATE abstürzte, wenn es nicht unterstützt wurde, und jetzt stattdessen eine Fehlermeldung zurückgegeben wurde (Danke @c020627 #3144). – Behoben: Antwortwiederholungsversuche während der Fahrt wurden nicht korrekt in die Sendelogik rekursiert (Danke @c020627 #3151).
  • Voice-Korrektur: Die Transkodierung von Silk-Sprachen wurde behoben, indem Silk zuerst in eine eigenständige WAV-Datei dekodiert und dann in MP3 neu kodiert wurde, wodurch ein Überschreiben der Quelldatei vermieden wurde (Danke @c020627 #3149).
  • Medien-URL-Klassifizierung: Bestimmen Sie den Medientyp anhand des aufgelösten URL-Pfads und beheben Sie falsch klassifizierte Medienlinks (Danke @c020627 #3150).
  • Baidu Translate: Behoben, dass Baidu Translate den API-Fehler nicht meldete, nachdem alle Wiederholungsversuche fehlgeschlagen waren (Danke @c020627 #3147).
  • Erkennung von Hintergrundbefehlen: Beschränken Sie run_in_background auf Prozesse mit langer Laufzeit, um zu verhindern, dass Aufgaben zu früh als abgeschlossen markiert werden.
  • Kürzung der Tool-Ausgabe: Melden Sie den bytebasierten Kürzungsgrund korrekt, wenn beibehaltene Zeilen teilweise abgeschnitten werden (Danke @c020627 #3137).
  • Web-Mobile-Layout: Das Konsolenlayout auf Mobilgeräten wurde verbessert.
  • Desktop client: Problem behoben, bei dem das Multi-Agent-Teammenü nicht angezeigt wurde.

📦 So führen Sie ein Upgrade durch

  • Quellbereitstellung: Führen Sie cow update für ein click-Upgrade aus oder rufen Sie den neuesten Code ab und starten Sie neu. Siehe die Upgrade-Anleitung.
  • Desktop client: Suchen Sie nach Updates und aktualisieren Sie mit einem click im client, ​​oder holen Sie sich die neueste Version von der Download-Seite.

Englisches Original / English original

CowAgent 2.1.9

Highlights

  • Ordered model fallbacks — #3125 replaces the single fallback model with an ordered chain, allowing recovery across multiple model failures. Review existing fallback configuration and place the previous fallback first to preserve current behavior.
  • Fallback credentials follow the routed provider — #3142 fixes credential resolution to use the provider actually selected by fallback rather than global configuration. Multi-provider deployments should verify failover with their intended credentials.
  • Configurable model catalog — #3146 lets providers define model names, types, context windows, and maximum output sizes, giving teams more control over model selection and context budgeting.
  • More reliable multi-Agent workflows — Fixes non-lead Agent delegation and image rendering from non-default Agents across web and desktop. The lead-Agent marker and desktop Team group-chat entry also clarify roles and simplify starting team sessions.
  • Stable channel lifecycle and recovery — Desktop channels now start correctly, the app_module stop-flow regression introduced by #3141 is fixed, and QQ automatically reconnects after silent WebSocket disconnections—reducing manual recovery during long-running deployments.
  • Breaking changes — None announced.

🌐 English | 中文

This is a refinement release for the 2.1.8 multi-Agent version, building on it with a series of improvements and fixes across multi-Agent collaboration, model capabilities, and channel integration.

🤝 Multi-Agent Experience

Further polish around using multi-Agent teams:

  • Multi-Agent session selection: the in-session multi-Agent selector adds a lead-Agent marker that clearly separates the lead Agent from members, while simplifying the view in single-Agent setups.
  • Collaboration fix: fixed failures when delegating tasks from non-lead Agents in multi-Agent group chats, now correctly identifying member Agents.
  • Member Agent image rendering: fixed images generated by non-default Agents failing to render on the Web console and desktop client.
  • Group-chat entry: the desktop Team page adds a group-chat entry, so you can start a group session directly from an Agent team.
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/agent-group-chat-picker.png" alt="Multi-Agent group chat" width="800" />

📡 Channel Integration Fixes

Fixed key issues along the console's channel start/stop path for more stable channel integration:

  • Desktop channel integration fix: fixed channels failing to start in the desktop client.
  • Channel stop fix: fixed a lost app_module lookup during the channel stop flow that caused disconnect errors (a regression introduced by #3141).
  • QQ channel reconnection: fixed the QQ channel not reconnecting after a silent WebSocket disconnect; it now reconnects automatically.

🤖 Model Capabilities

  • Model list configuration: model providers can now configure a model list, setting the model name, model type, context window, max output, and more. Thanks @alanyz106 (#3146)
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-catalog-config.png" alt="Model list configuration" width="800" />
  • Multiple fallback models: when the primary model fails, CowAgent now tries an ordered fallback chain in turn, replacing the previous single fallback model. Thanks @alanyz106 (#3125)
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-fallback-chain.png" alt="Multiple fallback models" width="800" />
  • Fallback credential fix: fixed credential resolution during fallback, which now resolves credentials by the provider actually routed to rather than the global configuration. Thanks @alanyz106 (#3142)
  • New image models: added gpt-image-2.5-flare and gpt-image-2.5-sunburst. Thanks @cowagent (#3140)

🛠 Improvements & Fixes

  • Config file tolerance: tolerate a UTF-8 BOM in config.json, and stop the pre-login 401 polling to avoid invalid requests before sign-in.
  • Image generation fixes:
    • fixed Baidu Ernie IMAGE_CREATE crashing when unsupported, now returning an error message instead (Thanks @c020627 #3144).
    • fixed Midjourney reply retries not recursing into the send logic correctly (Thanks @c020627 #3151).
  • Voice fix: fixed silk voice transcoding by first decoding silk into a standalone wav and then re-encoding to mp3, avoiding overwriting the source file (Thanks @c020627 #3149).
  • Media URL classification: determine media type from the resolved URL path, fixing misclassified media links (Thanks @c020627 #3150).
  • Baidu Translate: fixed Baidu Translate not reporting the API error after all retries failed (Thanks @c020627 #3147).
  • Background command detection: restrict run_in_background to long-running processes, preventing tasks from being marked complete too early.
  • Tool output truncation: report the byte-based truncation reason correctly when kept lines are partially truncated (Thanks @c020627 #3137).
  • Web mobile layout: improved the console layout on mobile.
  • Desktop client: fixed the multi-Agent team menu not showing.

📦 How to Upgrade

  • Source deployment: run cow update for a one-click upgrade, or pull the latest code and restart. See the upgrade guide.
  • Desktop client: check for updates and update with one click inside the client, or get the latest version from the download page.
