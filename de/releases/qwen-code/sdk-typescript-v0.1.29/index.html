Highlights

Das Paket CLI 0.23.0 enthält zwei in #11022 angeforderte Korrekturen: – Die verwaltete Speicherverfügbarkeit berücksichtigt jetzt die memory.enableManagedAutoMemory-Einstellung (#6941). Hosts, die den verwalteten automatischen Speicher deaktivieren, sehen in der Systemeingabeaufforderung keine zugelassenen Erinnerungs-/Dream-Anfragen oder Anweisungen zum verwalteten Speicher mehr. Lokale Patches können entfernt werden. – Die durch die Größe ausgelöste Mikrokomprimierung löscht nun alte Werkzeugergebnisse in Richtung eines niedrigen Wasserzeichens (#8464), sodass nicht mehr bei jeder weiteren Runde ein weiterer Teil des Konversationspräfixes neu geschrieben wird. Die Wiederverwendung des Prompt-Cache des Anbieters bleibt über lange, Tool-intensive Sitzungen hinweg erhalten, wodurch die Kosten für zwischengespeicherte Eingaben gesenkt werden.

Highlights

The bundled CLI 0.23.0 includes two fixes requested in #11022:

  • Managed memory availability now respects the memory.enableManagedAutoMemory setting (#6941). Hosts that disable managed auto memory no longer see remember/dream requests admitted or managed-memory instructions in the system prompt; local patches can be removed.
  • Size-triggered microcompaction now clears old tool results toward a low watermark (#8464), so it no longer rewrites another part of the conversation prefix on every subsequent turn. Provider prompt-cache reuse is preserved across long tool-heavy sessions, reducing cached-input cost.
