Qwen-Code v0.27.0

<!-- qwen-release-notes:v1 -->

Highlights

  • Managed-Agent-Sitzungen können mehrere untergeordnete Fragen gleichzeitig enthalten, diese in beliebiger Reihenfolge beantworten und Entwürfe und Fehler pro Kind getrennt halten. (#16484)
  • Web Shell fügt eine Aufgaben-Q&A-Heatmap und eine Nebenaufgabe „Nach Details fragen“ hinzu, die ausstehende Optionen „Benutzerfrage stellen“ erklärt, ohne zu antworten. (#16037, #16458)
  • Der Kanaleditor GitHub fügt Repository-Filter-Zulassungs- und Sperrlisten hinzu, während die gebundene PR-Zustellung und die einfache Kommentarzustellung zuverlässiger werden. (#16493, #16502, #16416) – Shell-Tool-Änderungen verarbeiten CRLF und Unicode jetzt sicher bei sed-Ersetzungen, und abgebrochene Befehle werden als unterbrochen gemeldet, während die teilweise Ausgabe beibehalten wird. (#15701, #15836) – Die Laufzeit des verwalteten Agenten ist schneller und weniger anfällig für Deadlocks, mit sichererer Sitzungsumbenennung, Snapshot-Veröffentlichung, Speicherzugriff und Sperrenbehandlung. (#16480, #16478, #16376, #16489, #16447) – Durch Upgrade-Ablehnungen und Advisor-Startfehler werden eingebettete Anmeldeinformationen nicht mehr offengelegt, und leere Harness-Benutzerinformationen werden beim Start und bei der Überprüfung abgelehnt. (#16352, #16083)

Breaking Changes

Keine bekannten bahnbrechenden Änderungen.

qwen-code v0.27.0

<!-- qwen-release-notes:v1 -->

Highlights

  • Managed-agent sessions can hold multiple child questions at once, answer them in any order, and keep drafts and errors separated per child. (#16484)
  • Web Shell adds a task Q&A heatmap and an Ask for details side task that explains pending Ask User Question options without answering. (#16037, #16458)
  • GitHub channel editor adds Repository Filter allowlists and blocklists, while bound PR delivery and plain comment delivery become more reliable. (#16493, #16502, #16416)
  • Shell tool edits now handle CRLF and Unicode safely in sed substitutions, and cancelled commands report as interrupted while keeping partial output. (#15701, #15836)
  • Managed-agent runtime is faster and less prone to deadlocks, with safer session rename, snapshot publication, storage admission, and lock handling. (#16480, #16478, #16376, #16489, #16447)
  • Upgrade refusals and Advisor startup errors no longer expose embedded credentials, and empty Harness user info is rejected during start and verify. (#16352, #16083)

Breaking Changes

No known breaking changes.
