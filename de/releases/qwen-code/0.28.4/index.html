Qwen-Code v0.28.4

<!-- qwen-release-notes:v2 -->

Highlights

– Der lokale Daemon-Modus von Web Shell fügt eine Arbeitsbereichs-Artefaktbibliotheksseite mit progressivem Scannen und Streaming-Updates hinzu. (#18071)

  • Der Web-Shell-Chat fügt eine gemeinsame Chatoberfläche, Fortsetzungs-Badges, Vorschlags-Chips und Korrekturen für das mobile Layout für Sitzungen hinzu. (#17952, #18044, #17918, #17883, #18011) – Core fügt integrierte Gemini 4-Argumentationsstandards hinzu. (#18039) – Local Runtime erstellt jetzt sein Statusverzeichnis beim Prozess-Spawn mit besitzerprivaten Berechtigungen. (#17964) – Bei der Befehlsmigration werden ausschließlich Markdown-Ziele erstellt und die ursprüngliche TOML bei Zielkonflikten beibehalten. (#17873) – Erweiterungen laden jetzt Manifeste, die mit einer UTF-8-Stückliste gespeichert sind. (#15786)

Breaking Changes

Keine bekannten bahnbrechenden Änderungen.

Web-Shell

Verbessert das Web Shell-Chat-Erlebnis durch Sitzungsfortsetzung, Artefakt-Browsing, mobiles Layout, Vorschlagschips und klarere Statushinweise.

  • Web-Shell: Mobil bleiben Über Software-Tastatur senden (#17883) – Fügt einen antippbaren Vorschlagschip in Web Shell Composers hinzu, sodass Touch-Benutzer vor dem Senden Folgevorschläge einfügen und bearbeiten können. (#17918)
  • Web Shell rendert jetzt Mod-Umschreibungen erweiterter Denkzeilen und behält dabei den ursprünglich gespeicherten Gedanken und die reduzierte Fertig-Denkzeile bei. (#17920)
  • Web-Shell: Seitenleistenlogo für dunkles Design aktualisieren (#17935) – Web Shell fügt eine gemeinsame ChatSurface-Chatspalte hinzu, die Transkript, Genehmigungen, Fragen und Verfasser aus dem Sitzungsstatus rendert. (#17952)
  • Web-Shell: Automatische Trigger-Nachrichten kompaktieren (#17970) – Bietet Sitzungstiteln mehr Platz auf Mobilgeräten und Desktops, indem optionale Zeilenaktionen in das Menü „Mehr“ verschoben werden. (#18011) – In der Web Shell-Seitenleiste wird jetzt ein Weiter-Symbol für Sitzungen angezeigt, deren letzte Runde unterbrochen wurde und fortgesetzt werden muss. (#18044)
  • Web-Shell: Gültigkeit der ChatSurface-Zugangssperren für die besitzende Sitzung und Bindung von LoadOlder (#18066)
  • Web-Shell: Sitzungs-Hover-Status an den Statushinweisen der Zeile ausrichten (#18070) – Fügt die Seite „Workspace-Artefaktbibliothek“ im lokalen Web Shell-Daemon-Modus mit progressivem Scannen und Streaming-Updates hinzu. (#18071)
  • Web-Shell: Lauffarbe für aktive Arbeit verwenden (#18072)

Managed Agent und Hosted Harness

Behebt gehostete Sitzungsrennen, Preflight-Konfiguration, Berechtigungen, Telemetriekanäle und Speicherkennungen für Managed Agent-Umgebungen.

  • Managed-Agent: Schließen Sie über die Ressourcen einen config_install-Datensatznamen (#17468) – Behebt ein gehostetes Trabrennen, indem ein Schloss beim Bauen, Schließen und Übernehmen des langsam gebauten client verwendet wird. (#17961) – Managed-Agent-Preflight behandelt jetzt ein leeres Workspace-CWD als unkonfiguriert, anstatt das aktuelle Arbeitsverzeichnis zu verwenden, und Dokumente entsprechen jetzt den mitgelieferten Statusverzeichnisregeln. (#17965)
  • Dauerhafte Preflight-Vorrichtungen überspringen jetzt sauber, wenn niemand aufgelöst werden kann, verwenden explizite 0755-Berechtigungen und Dokumente klären die Eigentumserwartungen der Dienstbenutzer. (#18020) – Fügt einen verwalteten Telemetriewert client-channel hinzu, damit verwaltete Agent-Sitzungen vom normalen Daemon-Verkehr unterschieden werden können. (#18022) – Managed-Agent-OSS-Objekte verwenden jetzt lesbare Mandanten-, Arbeitsbereichs- und Sitzungskennungen in Schlüsseln, wodurch Bucket-Inhalte einfacher zu überprüfen sind. (#18048)

Kernlaufzeit und Modelle

Aktualisiert die Befehlsmigration, die Berechtigungen für den lokalen Laufzeitstatus, die Wiederherstellung der Tool-Ausgabe, die Transkriptleistung und die Standardeinstellungen für die Gemini 4-Begründung. – Die Befehlsmigration erstellt jetzt ausschließlich Markdown-Ziele und behält die ursprüngliche TOML bei, wenn ein Zielkonflikt besteht. (#17873)

  • Kern: Schützt die dauerhafte Wiederherstellung der Tool-Ausgabe (#17875) – Übergroße Transkriptindizes werden in einer separaten begrenzten Klasse zwischengespeichert, sodass große Indizes die Hook-Aufbewahrung in kleinen Sitzungen nicht mehr blockieren. (#17910) – Erstellt das lokale Runtime-Statusverzeichnis beim Prozess-Spawn mit besitzerprivaten Berechtigungen statt während der Anbietererstellung. (#17964)
  • Kern: Integrierte Gemini 4-Argumentationsstandards hinzufügen (#18039)

Erweiterungen und Kanäle

Verbessert das Laden von Erweiterungsmanifesten und die Handhabung der ACP-Kanal-Liveness für vielbeschäftigte Agenten. – Erweiterungen: Erweiterungsmanifeste laden, die mit einer UTF-8-Stückliste gespeichert wurden (#15786) – Ermöglicht die ACP-Kanal-Liveness, beschäftigte Agenten länger als gesund zu behandeln und Beweise aufzuzeichnen, wenn Kanäle geschlossen sind. (#18028)

Sitzungen und Genehmigungen

– In den Dokumenten heißt es nun, dass bei der Ausführung interaktiver Sitzungen automatisch mcpServer-Änderungen übernommen werden, wobei der Neustart nur als Ausweichlösung für die Fehlerbehebung dient. (#17743) – Serve: Genehmigungen für den Arbeitsbereich „create_sub_session“ verfeinern (#17863)

Beweise automatisch reparieren

Entfernt Terminalsteuerzeichen und Unicode-Bidi-Überschreibungen vor der Anzeige aus Autofix-Fehlerprüfungsnachweisen.

  • Autofix-Nachweise für fehlgeschlagene Prüfungen entfernen jetzt Terminalsteuerzeichen und Unicode-Bidi-Überschreibungen aus Protokollauszügen vor der Anzeige. (#16748)

  • Web-Shell: Automatische Trigger-Nachrichten kompaktieren (#17970)
  • Schaffen Sie mehr Platz für Sitzungstitel auf Mobilgeräten und Desktops und verschieben Sie optionale Aktionen in das Menü „Mehr“. Managed Agent 与 Hosted Harness

Korrigieren Sie verwaltete Sitzungsrennen, Preflight-Konfigurationen, Berechtigungen, Telemetriekanäle und Speicheridentitäten, um die Zuverlässigkeit verwalteter Agent-Umgebungen zu verbessern.

  • Managed-Agent: Schließen Sie über die Ressourcen einen config_install-Datensatznamen (#17468)
  • Behebung der Hosted-Harness-Race-Bedingung, Verwendung der gleichen Sperre beim Erstellen, Schließen und Übernehmen verzögert erstellter Clients. (#17961) – Der verwaltete Agent behandelt ein leeres Workspace-CWD als unkonfiguriert, anstatt das aktuelle Arbeitsverzeichnis zu verwenden, und synchronisiert Preflight-Dokumente. (#17965) – Persistentes Preflight-Fixture überspringt, wenn niemand aufgelöst werden kann, verwendet explizite 0755-Berechtigungen und gibt die Eigentümererwartung des Dienstbenutzers an. (#18020) – Verwalteter Telemetriewert client-channel hinzugefügt, um verwaltete Agent-Sitzungen vom normalen Daemon-Verkehr zu unterscheiden. (#18022) – Die OSS-Objektschlüssel des verwalteten Agenten werden in lesbare Mandanten-, Arbeitsbereichs- und Sitzungskennungen geändert, um die Betriebs- und Wartungsanzeige zu erleichtern. (#18048)

Kernlaufzeit und -modell

Aktualisierte Befehlsmigration, Berechtigungen für lokale Laufzeit-Statusverzeichnisse, Wiederherstellung der Tool-Ausgabe, Transkriptionsleistung und Gemini 4-Inferenzstandards. – Die Befehlsmigration erstellt jetzt ausschließlich Markdown-Zieldateien und behält bei Zielkonflikten die ursprüngliche TOML bei. (#17873)

  • Kern: Schützt die dauerhafte Wiederherstellung der Tool-Ausgabe (#17875) – Platzieren Sie den sehr großen Transkriptindex in einer separaten eingeschränkten Cache-Klasse, um zu vermeiden, dass große Indizes die Hook-Aufbewahrung kleiner Sitzungen blockieren. (#17910) – Erstellen Sie das Statusverzeichnis nur mit Besitzerzugriff, wenn der lokale Laufzeitprozess startet, und nicht, wenn der Anbieter erstellt wird. (#17964)
  • Kern: Integrierte Gemini 4-Argumentationsstandards hinzufügen (#18039)

Erweiterungen und Kanäle

Verbessern Sie das Laden von Erweiterungsmanifesten und optimieren Sie die Erkennung der ACP-Kanalaktivität für vielbeschäftigte Agenten. – Erweiterungen: Erweiterungsmanifeste laden, die mit einer UTF-8-Stückliste gespeichert wurden (#15786) – Stellen Sie sicher, dass die ACP-Kanal-Liveness-Erkennung beschäftigte Agenten als vorübergehend fehlerfrei behandelt und Beweise protokolliert, wenn der Kanal geschlossen wird. (#18028)

qwen-code v0.28.4

<!-- qwen-release-notes:v2 -->

Highlights

  • Web Shell local daemon mode adds a workspace artifact library page with progressive scanning and streaming updates. (#18071)
  • Web Shell chat adds a shared ChatSurface, Continue badges, suggestion chips, and mobile layout fixes for sessions. (#17952, #18044, #17918, #17883, #18011)
  • Core adds built-in Gemini 4 reasoning defaults. (#18039)
  • Local Runtime now creates its state directory at process spawn with owner-private permissions. (#17964)
  • Command migration creates Markdown destinations exclusively and preserves the original TOML on destination conflicts. (#17873)
  • Extensions now load manifests saved with a UTF-8 BOM. (#15786)

Breaking Changes

No known breaking changes.

Web Shell

Improves the Web Shell chat experience with session continuation, artifact browsing, mobile layout, suggestion chips, and clearer status cues.

  • web-shell: keep mobile Send above software keyboard (#17883)
  • Adds a tappable suggestion chip in Web Shell composers so touch users can insert and edit follow-up suggestions before sending. (#17918)
  • Web Shell now renders Mod rewrites of expanded thinking rows while preserving the original stored thought and collapsed Done thinking line. (#17920)
  • web-shell: update sidebar logo for dark theme (#17935)
  • Web Shell adds a shared ChatSurface chat column that renders transcript, approvals, questions, and composer from session state. (#17952)
  • web-shell: compact automatic trigger messages (#17970)
  • Gives session titles more space on mobile and desktop by moving optional row actions into the More menu. (#18011)
  • Web Shell sidebar now shows a Continue badge for sessions whose last turn was interrupted and needs continuation. (#18044)
  • web-shell: scope ChatSurface admission locks to the owning session and bind loadOlder (#18066)
  • web-shell: align session hover status with the row's status cues (#18070)
  • Adds the workspace artifact library page in Web Shell local daemon mode, with progressive scanning and streaming updates. (#18071)
  • web-shell: use running color for active work (#18072)

Managed Agent and Hosted Harness

Fixes hosted session races, preflight configuration, permissions, telemetry channels, and storage identifiers for Managed Agent environments.

  • managed-agent: close over the resources a config_install record names (#17468)
  • Fixes a Hosted Harness race by using one lock when building, closing, and adopting the lazily built client. (#17961)
  • Managed-agent preflight now treats a blank workspace-cwd as unconfigured instead of using the current working directory, and docs now match shipped state-directory rules. (#17965)
  • Durable preflight fixtures now skip cleanly when nobody cannot be resolved, use explicit 0755 permissions, and docs clarify service-user ownership expectations. (#18020)
  • Adds a managed telemetry client-channel value so Managed Agent sessions can be distinguished from ordinary daemon traffic. (#18022)
  • Managed-agent OSS objects now use readable tenant, workspace, and session identifiers in keys, making bucket contents easier to inspect. (#18048)

Core runtime and models

Updates command migration, local Runtime state permissions, tool-output recovery, transcript performance, and Gemini 4 reasoning defaults.

  • Command migration now creates Markdown destinations exclusively and preserves the original TOML when a destination conflict exists. (#17873)
  • core: protect persisted tool-output recovery (#17875)
  • Caches oversized transcript indexes in a separate bounded class so large indexes no longer block small-session hook retention. (#17910)
  • Creates the local Runtime state directory at process spawn with owner-private permissions instead of during provider creation. (#17964)
  • core: add built-in Gemini 4 reasoning defaults (#18039)

Extensions and channels

Improves extension manifest loading and ACP channel liveness handling for busy agents.

  • extensions: load extension manifests saved with a UTF-8 BOM (#15786)
  • Lets ACP channel liveness treat busy agents as healthy longer and records evidence when channels are closed. (#18028)

Sessions and approvals

  • Docs now state that running interactive sessions automatically pick up mcpServers changes, with restart kept only as a troubleshooting fallback. (#17743)
  • serve: refine create_sub_session workspace approvals (#17863)

Autofix evidence

Strips terminal control characters and Unicode Bidi overrides from Autofix failed-check evidence before display.

  • Autofix failed-check evidence now strips terminal control characters and Unicode Bidi overrides from log excerpts before display. (#16748)

Other Changes

  • ci: use live review bot for manual re-review (#17848)
  • Stabilizes the required Managed Agent check name as Managed Agent gate and prevents skipped or no-suite review runs from overwriting real results. (#17865)
  • Replaces the receipt-catalog SpotBugs exclusion with an explicit assertion while keeping the HTTP 400 contract for missing receipt bytes unchanged. (#17919)
  • Updates identity de-hash design docs to correct workspace and storage budgets and record duplicate-key constraints before VARCHAR conversion. (#17960)
  • Makes RocketMQ stop checks wait for listeners to clear instead of immediately rebinding ports, reducing flaky CI failures. (#17967)
  • Release retries can resume after a partial publish by reusing a matching release branch and publishing remaining packages; divergent same-version trees are still rejected. (#17951)
  • Managed-agent identity storage removes redundant same-row hash key columns and rebuilds affected unique keys and indexes on raw identity columns without changing column order. (#18019)
  • ci: isolate verify scratch in runner temp (#17879)
  • web-shell: deliver per-turn assistant feedback to telemetry (#18021)
  • refactor(managed-agent): drop dead and redundant schema objects (#18041)
  • test(channels): make four managed DingTalk witnesses exclude what they claim (#17968)
  • CI verification now fails clearly when the scratch directory is not prepared instead of silently using shared OS temp space. (#18040)
  • The DingTalk recent-window cap test timeout is raised to 120 seconds and pinned to reduce flaky CI failures. (#17837)
  • The CLI restart-recovery crash test now waits for transcript and partial-response state before killing the daemon. (#18049)
  • Documentation now proposes a read-only workspace artifact library page for Web Shell local daemon mode. (#18036)
  • Adds bilingual design documentation for managed-agent Action parking in stateless Hosted Harness Phase 4. (#18047)
  • Marks the workspace artifact library design as accepted but not yet implemented in bilingual documentation. (#18063)
  • Restores green CI builds by updating the document export renderer size budget for ChatSurface copy. (#18067)
  • Fixes nightly desktop release checks by re-pinning the RHEL 10 rpm build root to a current CentOS Stream 10 digest. (#18069)
  • Fixes macOS e2e tests for qwen serve assistant feedback telemetry by using real workspace transcript paths. (#18074)
  • test(managed-agent): gate the four durable existing-dir preflight tests to Linux (#18076)
  • refactor(managed-agent): move publication OSS scope naming to the contract (#18085)
  • test(integration): deflake the SIGKILL restart-recovery case (#18055) (#18057)
  • test(cli): deflake the admitted-mutation idle-timer case (#18053) (#18056)
  • Updates design docs to mark the automatic-trigger message as landed and align renderer-budget history with implemented behavior. (#18080)
  • Makes self-hosted Java CI jobs rebuild a writable job-local Maven repository and safely fall back when cache reuse fails. (#18065)
