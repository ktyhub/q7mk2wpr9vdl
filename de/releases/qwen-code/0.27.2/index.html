Qwen-Code v0.27.2

<!-- qwen-release-notes:v1 -->

Highlights

  • Web Shell kann WeChat-, QQ- und E-Mail-Kanäle konfigurieren, einschließlich QR-Anmeldung, Scan-Fortschritt, Identitätsanzeige und Abmeldung, sofern unterstützt. (#16736, #16724, #16746) – Mods können einmalige $.model.complete-Aufrufe ausführen, angezeigten AssistantMessage-Text über ui.render umschreiben und Plugin-Werte mit $.store beibehalten. (#16737, #16794, #16791)
  • Übrigens werden Nebenfragen für den Kontext wiedergegeben, und der verwaltete Agent fügt private Nachverfolgungen mit manuellen oder optionalen automatischen Sitzungsrückblicken hinzu. (#16408, #16758)
  • Ausstehende Genehmigungen werden jetzt im Live-Panel angezeigt und können eine Terminalglocke oder eine Desktop-Benachrichtigung auslösen, wenn das Terminal nicht fokussiert ist. (#16800, #16809)
  • Web Shell zeigt Runden, Ausgabegeschwindigkeit, Gesamttokens und Cache-Trefferrate unter dem Composer an, mit Hover-Details und Zugriff auf die Token-Nutzung. (#16815) – Benutzer können einen Skill aus dem ursprünglichen Runtime-Arbeitsbereich einer ausgewählten Sitzung importieren und ihn explizit installieren, ohne ihn erneut hochzuladen. (#16638)

Breaking Changes

  • fix(deps)!: Upgrade-Abhängigkeiten, die von SDK und Web Shell (#16452) von @yiliang114 bereitgestellt werden

Vollständige Änderungsliste

Funktionen

– Ermöglicht Benutzern, einen Skill aus dem ursprünglichen Runtime-Arbeitsbereich einer ausgewählten Sitzung zu importieren und ihn explizit zu installieren, ohne ihn erneut hochzuladen. (#16638) von @doudouOUC

  • Macht /btw-Nebenfragen zu einem Teil der Sitzung und spielt die letzten 20 beantworteten Nebenfragen noch einmal ab, sodass Folgefragen auf frühere Fragen verweisen können. (#16408) von @sorrycc
  • Fügt Tool v4-Ausführungsmessungen zur verwalteten Aktivitätsdiagnose hinzu und zeigt Dauer, gültige Probenanzahl und vorgeschlagene gegenüber angewendeten Zeilenänderungen an. (#16498) von @doudouOUC – Daemon PR-State Watch fügt die Erkennung zugelassener Hosts aus der GH-Konfiguration und das geordnete Herunterfahren hinzu, während es ausgeschaltet bleibt. (#16732) von @wenshao – Wenn „experimental.unifiedAgentLoop“ aktiviert ist, durchlaufen OpenTUI-Modellrunden jetzt die Shared-Agent-Schleife, wodurch die Parität mit Ink verbessert und gleichzeitig ein eigener Tool-Schritt beibehalten wird. (#16743) von @qqqys – Mods können jetzt einmalige Textvervollständigungen mit $.model.complete(request, {signal}) ausführen, indem sie die Sitzung client ohne Tools, Verlauf oder eine zusätzliche Systemeingabeaufforderung verwenden. (#16737) von @qqqys – Managed Agent fügt private BTW-Follow-ups und manuelle oder optionale automatische Sitzungszusammenfassungen hinzu, wobei WebShell-Panels persistente Ergebnisse verwenden; Die automatische Zusammenfassung ist standardmäßig deaktiviert. (#16758) von @doudouOUC – Die Urteile der Zielüberprüfung zeigen jetzt den Grund der letzten Prüfung in der Ausgabesprache der Sitzung an, während die Entscheidungswerte weiterhin „Akzeptieren“ oder „Ablehnen“ bleiben. (#15806) von @4ekuct25 – Mods können jetzt die AssistantMessage-Renderseite und den ui.render-Hook verwenden, um den angezeigten Modellantworttext im Ink-Terminal neu zu schreiben, ohne gespeicherten oder kopierten Text zu ändern. (#16794) von @qqqys – Selbstgehostete Autofix-Läufe haben jetzt ein Agentenbudget von 240 Minuten, wodurch vorzeitige Timeouts bei langen Autofix-Runden reduziert werden. (#16777) von @wenshao
  • feat(web-shell): Konfigurieren Sie den E-Mail-Kanal über den Channel-Manager (#16746) von @wenshao
  • feat(cli): Führen Sie die Tool-Batches von OpenTUI auf der Shared-Agent-Schleife aus (#16789) von @qqqys
  • feat(mods): Behalten Sie die Werte jedes Plugins zwischen Sitzungen bei mit $.store (#16791) von @qqqys – Web-Shell-verwaltete Sitzungen können Host-Shell-Chrome mit showManagedSessionHeader und alignManagedChatWithHost wiederverwenden, wodurch doppelte Header und Hinweise reduziert werden. (#16324) von @yiliang114
  • Das Lieferbuch des Managed Agent-Kanals erfasst jetzt jedes Liefersegment separat und bewahrt Segmentbelege für Lieferungen mit mehreren Segmenten auf. (#16797) von @wenshao – Fügt requireBoundWatch zum GitHub-Kanal hinzu, sodass Überprüfungs- oder Verifizierungsbindungen PR-Ereignisse nur dann empfangen, wenn eine aktive /autofix-pr- oder /verify-pr-Überwachung stattfindet. (#16772) von @wenshao
  • Fügt WeChat als konfigurierbaren Web-Shell-Kanal mit QR-Anmeldung im Browser, Scan-Fortschritt, Identitätsanzeige, Abmeldung und Aktualisierung abgelaufenen Codes hinzu. (#16736) von @wenshao – Fügt eine QQ-Kanalkonfiguration und einen optionalen QR-Login-Verwaltungsablauf hinzu, der es der Web Shell ermöglicht, Konten durch Scannen eines QR-Codes zu binden. (#16724) von @wenshao – Fügt ein Segment-Array zur Bereitstellungsressource des öffentlichen Kanals hinzu und sorgt gleichzeitig für die Kompatibilität vorhandener einzelner Segmentfelder. (#16807) von @wenshao – Zeigt Runden, Ausgabegeschwindigkeit, Gesamttokens und Cache-Trefferrate im Web Shell Composer an, mit Hover-Details und Zugriff auf das Token-Verwendungsfeld. (#16815) von @qqqys

Fehlerbehebungen

– Korrigiert die CI-Flusenfrischeprüfung, um den vollständigen Hübscher-Ignorierungssatz an der Basisspitze zu vergleichen, damit die Urteile nicht falsch eingegrenzt werden. (#16729) von @wenshao – Ermöglicht einem Agent-Host, eine verlorene Registrierung oder einen Ersetzungsbefehl sicher erneut zu versuchen, sodass er mit dem vorhandenen Host abgeschlossen wird, anstatt fehlzuschlagen oder ein Duplikat zu erstellen. (#16722) von @wenshao – Lehnt fehlerhafte „authorExclude“-Werte in eingehenden Aufgabendatensätzen ab, bevor sie die Kommentarübermittlung erreichen, wodurch Abstürze und ungültiges Übermittlungsverhalten verhindert werden. (#16740) von @wenshao

  • Macht das CI-Flusen-Verengungsprotokoll zu einer Warnung, wenn ein abgeschnittener Baum eine Verengung verhindert, und verarbeitet Schrägstrich-basierte Basisreferenzen korrekt. (#16747) von @wenshao – Stoppt PR-CI-Fehler des Forks, indem Strg+C von der fokussierten Shell ferngehalten wird, dem Managed Agent-Testfork 40 % des Maschinenspeichers zur Verfügung gestellt wird und die Überprüfungen der Lease-Erneuerung stabilisiert werden. (#16150) von @TianYuan1024 – Korrigiert das Parsen von Shell-Befehlen, sodass der Self-Kill-Guard und die Dateiberechtigungsprüfungen ANSI-C-Escapezeichen und -c-Optionsterminatoren korrekt verarbeiten. (#16540) von @yiliang114 – Verhindert, dass automatische Korrekturen veralteter Basisaktualisierungen automatische PR-Überprüfungen nach einer Zeitüberschreitung neu starten, wodurch wiederholte Überprüfungs- und Basisaktualisierungszyklen vermieden werden. (#16749) von @wenshao – Fällt auf die Datentabellenansicht zurück, wenn ein Diagrammrenderer fehlschlägt, Inline-Daten jedoch lesbar sind, anstatt das Diagramm als nicht verfügbar anzuzeigen. (#16021) von @zhangxy-zju – Die Renderer-Größenbudgets für den Dokumentexport werden auf die Größe des zusammengeführten Bundles angehoben, wodurch NPM-Run-Build-Fehler behoben werden, die durch die Web-Shell-Erhöhung nach der Zusammenführung verursacht werden. (#16774) von @yiliang114 – Nur im Leerlauf verfügbare Slash-Befehle wie /branch, /cd, /fork, /recap und /advisor werden jetzt ausgeführt, wenn sie von einer inaktiven Ink-TUI-Sitzung gesendet werden, anstatt durch den App-weiten Status blockiert zu werden. (#16731) von @qqqys
  • Das Slash-Menü der Web-Shell gibt Befehlen und Fertigkeitsnamen jetzt Vorrang, wobei die Beschreibungen zuerst abgeschnitten werden, während die vollständigen Details beim Schweben angezeigt bleiben. (#16790) von @callmeYe
  • Hintergrund- und Workflow-Genehmigungsanfragen lösen jetzt eine Terminal-Klingel- oder Desktop-Benachrichtigung aus, wenn sie nicht fokussiert sind, wobei general.terminalBell und general.notificationMode berücksichtigt werden. (#16800) von @qqqys – Der CLI öffnet den Composer nun stillschweigend, wenn ein gespeichertes Abonnementmodell nicht verfügbar ist, und verschiebt das Senden des Fehlers und zeigt die Gateway-Antwort an. (#16798) von @liuxuely0626
  • fix(core): Automatische Sitzungstitel in der Sprache der Konversation schreiben (#16806) von @qqqys
  • fix(cli): Zeigt die ausstehende Genehmigung eines Vordergrundagenten im Live-Panel an (#16809) von @qqqys
  • fix(cli): Sandbox-Debugging nur für explizite DEBUG-Werte aktivieren (#16805) von @yiliang114 – Mit gh pr create erstellte Pull-Anfragen werden jetzt an das Verzeichnis gebunden, in dem der Befehl ausgeführt wird, wodurch die Genauigkeit der Arbeitsbaumbindung verbessert wird. (#16725) von @wenshao – Die Wiedergewinnung von HTTP Managed Session Writern wartet jetzt auf während der Übertragung befindliche Siegel und vermeidet den Erwerb einer Lease, solange sich ein Siegel noch begnügen kann. (#16726) von @wenshao – Verhindert, dass veraltete Sitzungen als aktiv gemeldet werden, wenn ihre PID recycelt wird, indem ein Prozessstart-Token unter Linux validiert wird. (#16128) von @yiliang114 – Ermöglicht Kanalkonfigurationsfeldern die Angabe einer inklusiven Untergrenze, sodass Nullwerte in Validierungs- und Bereichsnachrichten korrekt akzeptiert werden. (#16783) von @wenshao

Leistung

– perf(memory): Löschen Sie die gebündelte Auto-Memory-Referenz und behalten Sie die residente Richtlinie (#16739) von @qqqys bei – Die PR-Statusüberwachungs- und Benachrichtigungsliste des GitHub-Kanals verwendet jetzt bedingte Anfragen und speichert unveränderte Antworten im Cache, um zu vermeiden, dass Quoten für unveränderte Daten ausgegeben werden. (#16741) von @wenshao – Verbessert die Leistung verwalteter Agenten durch Reduzierung des CSI-Proof-Kopierens, Optimierung der CSI-Suche und Verwendung eines begrenzten Start-Polling-Backoffs. (#16828) von @doudouOUC – Verbessert die Reaktionsfähigkeit verwalteter Agenten durch Entfernen redundanter Lesepfadabfragen, ohne das Verhalten zu ändern. (#16827) von @doudouOUC

  • Fügt zweisprachige Designvorschläge für die Einbindung von /loop in verwaltete Sitzungen hinzu und deckt Zeitpläne und Weckzeiten ab, ohne das Produktionsverhalten zu ändern. (#16792) von @wenshao – docs(managed-agent): Verwaltete Planungsentwürfe – Schleifenüberprüfungskorrekturen und externe Planer (#16796) von @wenshao – Korrigiert die Designdokumentation dahingehend, dass „wakeDormant false“ die Übermittlung bis zum nächsten Aktualisierungstick verzögert, anstatt ausstehende Übergänge zu stranden. (#16763) von @doudouOUC – Reduziert alle Shard-CI-Spuren auf zwei Shards und erhöht die Obergrenze für Smoke-Jobs auf 75 Minuten, während der Run-Headroom erhalten bleibt. (#16764) von @wenshao – Schließt die Erneuerung der Hintergrundaktivierung von einem Protokolltest für verwaltete Sitzungen aus, um zu verhindern, dass unabhängige Protokollschreibvorgänge die Byte-Offset-Prüfung beeinträchtigen. (#16756) von @wenshao – Verwaltete HTTP-Routen für Runtime-Worker werden jetzt von einem einzigen Routenplan abgeleitet, wodurch die Konsistenz zwischen Routen-Gating und -Montage verbessert wird. (#16788) von @doudouOUC – Entfernt nicht verwendete Konstruktoren und Hilfsprogramme für verwaltete Agent-Server, ohne das Laufzeitverhalten zu ändern. (#16822) von @doudouOUC – Refaktoriert die Sitzungswiederherstellung in einen gemeinsam genutzten Kern, sodass In-Process-Aufrufer Arbeitsbereichssitzungen ohne HTTP wiederherstellen können. qwen-code v0.27.2

<!-- qwen-release-notes:v1 -->

Highlights

  • Web Shell can configure WeChat, QQ, and Email channels, including QR login, scan progress, identity display, and logout where supported. (#16736, #16724, #16746)
  • Mods can run one-off $.model.complete calls, rewrite displayed AssistantMessage text via ui.render, and persist plugin values with $.store. (#16737, #16794, #16791)
  • /btw side questions are replayed for context, and Managed Agent adds private follow-ups with manual or optional automatic session recaps. (#16408, #16758)
  • Pending approvals now appear in the live panel and can trigger a terminal bell or desktop notification when the terminal is unfocused. (#16800, #16809)
  • Web Shell shows turns, output speed, total tokens, and cache hit rate under the composer, with hover details and Token Usage access. (#16815)
  • Users can import a Skill from the original Runtime workspace of a selected Session and install it explicitly without re-uploading it. (#16638)

Breaking Changes

  • fix(deps)!: upgrade dependencies shipped by SDK and Web Shell (#16452) by @yiliang114

Complete Change List

Features

  • Lets users import a Skill from the original Runtime workspace of a selected Session and install it explicitly without re-uploading it. (#16638) by @doudouOUC
  • Makes /btw side questions part of the session and replays the last 20 answered side questions so follow-ups can reference earlier ones. (#16408) by @sorrycc
  • Adds Tool v4 execution measurements to Managed activity diagnostics, showing duration, valid sample counts, and proposed versus applied line changes. (#16498) by @doudouOUC
  • Daemon PR-state watch adds allowed-host discovery from gh configuration and ordered shutdown while remaining turned off. (#16732) by @wenshao
  • With experimental.unifiedAgentLoop enabled, OpenTUI model rounds now run through the shared agent loop, improving parity with Ink while keeping its own tool step. (#16743) by @qqqys
  • Mods can now run one-off text completions with $.model.complete(request, {signal}), using the session client without tools, history, or an added system prompt. (#16737) by @qqqys
  • Managed Agent adds private BTW follow-ups and manual or optional automatic session recap, with WebShell panels using persisted results; automatic recap is off by default. (#16758) by @doudouOUC
  • Goal verifier verdicts now show the Last check reason in the session output language while decision values remain accept or reject. (#15806) by @4ekuct25
  • Mods can now use the AssistantMessage render site and ui.render hook to rewrite displayed model reply text in the Ink terminal without changing stored or copied text. (#16794) by @qqqys
  • Self-hosted autofix runs now have a 240-minute agent budget, reducing premature timeouts for long autofix rounds. (#16777) by @wenshao
  • feat(web-shell): configure the Email channel from the channel manager (#16746) by @wenshao
  • feat(cli): run OpenTUI's tool batches on the shared agent loop (#16789) by @qqqys
  • feat(mods): keep each plugin's values between sessions with $.store (#16791) by @qqqys
  • Web shell managed sessions can reuse host shell chrome with showManagedSessionHeader and alignManagedChatWithHost, reducing duplicate headers and hints. (#16324) by @yiliang114
  • Managed Agent channel delivery ledger now records each delivery segment separately, preserving segment receipts for multi-segment deliveries. (#16797) by @wenshao
  • Adds requireBoundWatch to the GitHub channel so review or verify bindings receive PR events only while an active /autofix-pr or /verify-pr watch is held. (#16772) by @wenshao
  • Adds WeChat as a configurable Web Shell channel with in-browser QR login, scan progress, identity display, logout, and expired-code refresh. (#16736) by @wenshao
  • Adds QQ channel configuration and an optional QR-login management flow that lets the Web Shell bind accounts by scanning a QR code. (#16724) by @wenshao
  • Adds a segments array to the public channel delivery resource while keeping existing singular segment fields compatible. (#16807) by @wenshao
  • Shows turns, output speed, total tokens, and cache hit rate under the Web Shell composer, with hover details and Token Usage panel access. (#16815) by @qqqys

Bug Fixes

  • Fixes the CI lint freshness check to compare the full prettier ignore set at the base tip so verdicts are not narrowed incorrectly. (#16729) by @wenshao
  • Lets an Agent Host safely retry a lost enrollment or Replace command so it finishes with the existing Host instead of failing or creating a duplicate. (#16722) by @wenshao
  • Rejects malformed authorExclude values on inbound task records before they reach comment delivery, preventing crashes and invalid delivery behavior. (#16740) by @wenshao
  • Makes CI lint narrowing log a warning when a truncated tree prevents narrowing and handles slash-bearing base refs correctly. (#16747) by @wenshao
  • Stops fork PR CI failures by keeping Ctrl+C out of the focused shell, giving the Managed Agent test fork 40% of machine memory, and stabilizing lease renewal checks. (#16150) by @TianYuan1024
  • Fixes shell command parsing so the self-kill guard and file-permission checks correctly handle ANSI-C escapes and -c option terminators. (#16540) by @yiliang114
  • Prevents autofix stale-base updates from restarting automated PR reviews that timed out, avoiding repeated review and base-update cycles. (#16749) by @wenshao
  • Falls back to the Data table view when a chart renderer fails but inline data is readable, instead of showing the chart as unavailable. (#16021) by @zhangxy-zju
  • Document export renderer size budgets are raised to the merged bundle size, fixing npm run build failures caused by the post-merge Web Shell increase. (#16774) by @yiliang114
  • Idle-only slash commands such as /branch, /cd, /fork, /recap, and /advisor now run when dispatched from an idle Ink TUI session instead of being blocked by app-wide state. (#16731) by @qqqys
  • The Web Shell slash menu now gives command and Skill names priority, truncating descriptions first while full details remain on hover. (#16790) by @callmeYe
  • Background and workflow approval requests now trigger a terminal bell or desktop notification when unfocused, honoring general.terminalBell and general.notificationMode. (#16800) by @qqqys
  • The CLI now opens the composer silently when a saved subscription model is unavailable and defers the error to send, showing the gateway response. (#16798) by @liuxuely0626
  • fix(core): write auto session titles in the conversation's language (#16806) by @qqqys
  • fix(cli): show a foreground agent's pending approval in the live panel (#16809) by @qqqys
  • fix(cli): only enable sandbox debugging for explicit DEBUG values (#16805) by @yiliang114
  • Pull requests created with gh pr create are now bound using the directory where the command runs, improving worktree binding accuracy. (#16725) by @wenshao
  • HTTP Managed Session writer reacquisition now waits for in-flight seals and avoids acquiring a lease while a seal may still settle. (#16726) by @wenshao
  • Prevents stale sessions from being reported active when their PID is recycled by validating a process-start token on Linux. (#16128) by @yiliang114
  • Allows channel config fields to declare an inclusive lower bound so zero values are accepted correctly in validation and range messages. (#16783) by @wenshao

Performance

  • perf(memory): drop the bundled auto-memory reference and keep the resident policy (#16739) by @qqqys
  • GitHub channel's PR state watch and notifications list now use conditional requests and cache unchanged responses to avoid spending quota on unchanged data. (#16741) by @wenshao
  • Improves managed-agent performance by reducing CSI proof copying, optimizing CSI lookup, and using capped startup polling backoff. (#16828) by @doudouOUC
  • Improves managed-agent responsiveness by removing redundant read-path queries without changing behavior. (#16827) by @doudouOUC

Documentation

  • docs: clarify tool bridge requirements when migrating from tools.core (#16750) by @521Peter
  • Adds bilingual design proposals for bringing /loop to Managed Sessions, covering schedules and wakeups without changing production behavior. (#16792) by @wenshao
  • docs(managed-agent): Managed scheduling designs — loop review fixes and external schedulers (#16796) by @wenshao
  • Corrects design documentation to state wakeDormant false may delay delivery until the next refresh tick rather than stranding pending transitions. (#16834) by @wenshao

Internal Changes

  • Renames Managed Agent JDBC persistence implementations to distinguish them from repository interfaces and simplify imports. (#16759) by @doudouOUC
  • Shares Hosted Harness capability tokens across connectors so feature checks remain consistent without changing connector behavior. (#16763) by @doudouOUC
  • Reduces all sharded CI lanes to two shards and raises the smoke job cap to 75 minutes while preserving run headroom. (#16764) by @wenshao
  • Excludes background activation renewal from a Managed Session log test to prevent unrelated log writes from affecting its byte-offset check. (#16756) by @wenshao
  • Managed Runtime worker HTTP routes now derive from a single route plan, improving consistency between route gating and mounting. (#16788) by @doudouOUC
  • Removes unused managed-agent-server constructors and helpers without changing runtime behavior. (#16822) by @doudouOUC
  • Refactors session restore into a shared core so in-process callers can restore workspace sessions without HTTP. (#16810) by @wenshao

New Contributors

  • @521Peter made their first contribution in #16750
