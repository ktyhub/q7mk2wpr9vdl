QwenPaw v1.1.5

✨ Hinzugefügt

  • CJK-fähige Speichersuche: Die Speichersuche tokenisiert jetzt CJK-Abfragen auf Zeichenebene und behält dabei lateinische/Ziffernläufe bei (#3811)
  • Fallback zur Kontextkomprimierung: Wenn die LLM-basierte Kontextkomprimierung fehlschlägt oder deaktiviert ist, versucht der Kontextmanager jetzt die Kontextaufteilung mit einer erhöhten Reserve erneut, um neuere Gesprächsrunden beizubehalten (#3882)
  • Adaptive Modellwiederholung: Die Laufzeit lernt jetzt modellspezifische Macken aus API-Fehlern und passt nachfolgende Anforderungen proaktiv an (#3874)
  • Umbenennen und Löschen von ACP-Agenten: ACP-Agenten können jetzt über die WebUI umbenannt und gelöscht werden (#3859)
  • QQ-Sprach- und ASR-Unterstützung: Der QQ-Kanal erkennt Sprachnachrichten jetzt anhand der Dateierweiterung und verwendet die Plattform-ASR-Transkription, sofern verfügbar (#3845)

🔄 Geändert

  • Navigation zur Agentenstatistik: Die Seite „Agentenstatistik“ wurde in die Gruppe „Arbeitsbereich“ in der Seitenleiste verschoben (#3754)
  • Dockerfile Cleanup: Das Build-Verzeichnis wird jetzt nach pip install in der Docker-Datei entfernt, um ein schlankeres Image zu erhalten (#3638)
  • Chat-Komponenten-Upgrade: @agentscope-ai/chat mit stopChat-Fix aktualisiert (#3917)

⚡ Leistung

  • Config Loading Cache: Root- und Pro-Agent-Konfigurationsdateien werden jetzt mit mtime-basierter Invalidierung zwischengespeichert (#3865)
  • Skill-Manifest-Cache: Skill-Manifest-Lesevorgänge werden nach Dateipfad und Mtime zwischengespeichert, wodurch wiederholte Festplatten-Lesevorgänge auf Hot-Pfaden reduziert werden (#3910)
  • Modell API-Deduplizierung: Gleichzeitige listProviders- und getActiveModels-Aufrufe auf der Chat-Seite deduplizieren jetzt ihre eigenen In-Flight-Anfragen (#3897)
  • Konsolen-Chat-Leistung: Die Chat-Sitzungsliste wird mit react-window virtualisiert, die Suche lädt Sitzungen schrittweise mit einer Fortschrittsanzeige (#3908, #3912)

🐛 Behoben

Kanäle

  • Genehmigung in Kanälen: Die Befehle /approve und /deny funktionierten nicht in Kanälen (#3832, #3896)
  • WeCom @Mention-Befehle: Fehler behoben, bei dem Slash-Befehle in WeCom-Gruppenchats fehlschlugen, wenn der Bot @-erwähnt wurde (#3903)
  • Feishu-Reaktionsereignisse: Registrierte No-Op-Handler für Feishu-Nachrichtenreaktionsereignisse (#3890)
  • QQ WebSocket Reconnect: Der QQ-Kanal stellt jetzt bei behebbaren WebSocket-Fehlern die Verbindung wieder her (#3872) Konsole und Benutzeroberfläche
  • Pro-Tab-Agentenauswahl: Fehler bei der Agentenauswahl zwischen Browser-Registerkarten behoben (#3857, #3867)
  • Symbol für den Import von Backups: Die Schaltfläche zum Importieren von Backups wurde aktualisiert, um anstelle des Hochladens ein Importsymbol zu verwenden (#3909) Agentensystem
  • Zeitzonennormalisierung: Nicht standardmäßige Zeitzonennamen werden jetzt kanonischen IANA-Kennungen zugeordnet (#3858)
  • ACP-Fallback-Vererbung: Das Fallback-Agent-Profil erbt jetzt die ACP-Konfiguration von der Hauptkonfiguration (#3834)
  • MCP-Ausführungs-Timeout: MCP client-Timeout wird jetzt an die Tool-Ausführung weitergegeben (#3904)

QwenPaw v1.1.5

Highlights

  • CJK-aware memory retrieval (#3811) — Memory search now tokenizes Chinese/Japanese/Korean queries at character level while preserving Latin words and digit runs. If you serve CJK users, expect a meaningful recall boost from memory; the catch is that ranking shifts for existing stores — the same query can surface different memories after upgrading, so re-run any retrieval quality checks you depend on.

  • More resilient long conversations (#3882) — When LLM-based compaction fails or is disabled, the context manager retries the split with a raised reserve, keeping more recent turns. This cuts abrupt context loss in long sessions, but compaction is no longer strictly deterministic — size/token planning should account for the larger retained window.

  • Adaptive model retry (#3874) — The runtime learns per-model quirks from API failures and proactively reshapes subsequent requests. Great for reliability across flaky providers, but watch out: outgoing requests can be silently adapted based on observed failures, so enable it deliberately where request shape matters and check logs when a provider behaves oddly.

  • Config and skill caching (#3865, #3910) — Root/per-agent configs and skill manifests are now cached with mtime-based invalidation, joined by in-flight dedup for listProviders/getActiveModels (#3897) and a virtualized, progressively-searchable console session list (#3908, #3912). Big startup and hot-path latency win; the risk is that edits made by tooling that doesn't bump mtime may not take effect until a touch or restart.

  • MCP timeouts and config normalization (#3904, #3858) — The MCP client timeout now propagates into tool execution, so a single slow tool can't run past your configured deadline, and non-standard timezone names are mapped to canonical IANA IDs. Both are behavioral changes: audit long-running MCP tools and update configs that use custom timezone aliases.

  • Channel and console reliability fixes (#3832, #3896, #3903, #3890, #3872, #3857, #3867, #3917) — /approve and /deny work in channels again, WeCom @-mention slash commands and Feishu reaction events are handled, QQ reconnects on recoverable WebSocket errors, agent selection no longer leaks across browser tabs, and stopChat is fixed. Remove any workarounds you added for these.

No breaking changes were introduced in this release.

✨ Added

  • CJK-Aware Memory Search: Memory search now tokenizes CJK queries at character level while preserving Latin/digit runs (#3811)
  • Context Compaction Fallback: When LLM-based context compaction fails or is disabled, the context manager now retries the context split with a raised reserve to keep more recent conversation turns (#3882)
  • Adaptive Model Retry: The runtime now learns per-model quirks from API failures and proactively adapts subsequent requests (#3874)
  • ACP Agent Rename & Delete: ACP agents can now be renamed and deleted from the WebUI (#3859)
  • QQ Voice & ASR Support: QQ channel now detects voice messages by file extension and uses platform ASR transcription when available (#3845)

🔄 Changed

  • Agent Statistics Navigation: Moved Agent Statistics page into the Workspace group on the sidebar (#3754)
  • Dockerfile Cleanup: Build directory is now removed after pip install in Dockerfile for a leaner image (#3638)
  • Chat Component Upgrade: Upgraded @agentscope-ai/chat with stopChat fix (#3917)

⚡ Performance

  • Config Loading Cache: Root and per-agent config files are now cached with mtime-based invalidation (#3865)
  • Skill Manifest Cache: Skill manifest reads are cached by file path and mtime, reducing repeated disk reads on hot paths (#3910)
  • Model API Deduplication: Concurrent listProviders and getActiveModels calls on the chat page now deduplicate their own in-flight requests (#3897)
  • Console Chat Performance: Chat session list is virtualized with react-window, search loads sessions progressively with a progress indicator (#3908, #3912)

🐛 Fixed

Channels

  • Approval in Channels: Fixed /approve and /deny commands not working in channels (#3832, #3896)
  • WeCom @Mention Commands: Fixed slash commands failing in WeCom group chats when the bot is @-mentioned (#3903)
  • Feishu Reaction Events: Registered no-op handlers for Feishu message reaction events (#3890)
  • QQ WebSocket Reconnect: QQ channel now reconnects on recoverable WebSocket errors (#3872)

Console & UI

  • Per-Tab Agent Selection: Fixed agent selection leaking between browser tabs (#3857, #3867)
  • Backups Import Icon: Updated the backup import button to use an import icon instead of upload (#3909)

Agent System

  • Timezone Normalization: Non-standard timezone names are now mapped to canonical IANA identifiers (#3858)
  • ACP Fallback Inheritance: Fallback agent profile now inherits ACP configuration from the main config (#3834)
  • MCP Execution Timeout: MCP client timeout is now passed through to tool execution (#3904)
