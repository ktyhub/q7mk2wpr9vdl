QwenPaw v2.2.1

Was hat sich geändert?

✨ Hinzugefügt

Modelle, Agenten & Erinnerung

– Konfigurieren Sie das Modellrouting separat für jeden Agenten, einschließlich Anbietereinstellungen und Fallback-Verhalten (#7501) – Fügen Sie die proaktive Speicherüberprüfung von Auto Fin hinzu und aktualisieren Sie ReMe für eine zuverlässigere Langzeitspeicherverarbeitung (#7441) – Fügen Sie PowerContext als optionales Langzeitspeicher-Backend mit Konfiguration in der Konsole hinzu (#7080) – Verstärktes Verhalten des integrierten Agenten rund um den Anforderungsbereich, den nicht bearbeiteten Inhalt, die Bestätigungen, die Tool-Nutzung und den Abschluss (#7526)

QwenPaw-Ersteller

– Fügen Sie eine Blueprint-Workbench, Multi-Timeline-Vergleich, wiederverwendbare Videovorlagen, MiniMax H3-Unterstützung, Projekt-Snapshot-Rollback, klareren Agentenfortschritt und Docker-Bereitstellung in Creator 1.2.0 hinzu (#7486)

Konsole und Arbeitsbereiche

– Verwalten Sie Umgebungsvariablen auf einer einheitlichen Einstellungsseite, die von Agenten, MCP-Diensten, Tools und lokalen Modellen gemeinsam genutzt wird (#7538)

  • Verfügbare Plugin- und PawApp-Updates erkennen und mit einem click installieren (#7605) – Neugestaltung der Seitenleiste und der Einstellungen mit anpassbarer Navigation und verbessertem Sitzungs-Browsing (#7502)
  • Direkte Pfadeingabe wiederherstellen, wenn ein Sitzungsprojektverzeichnis ausgewählt wird (#7593) – Chinesische und englische Lokalisierung zu Agent Kanban hinzufügen (#7482)

Fähigkeiten & MCP

– Lassen Sie ausgewählte Fertigkeiten ihre vollständigen Anweisungen vorab laden, sodass sie ohne einen zusätzlichen Aktivierungsschritt bereit sind (#7183)

  • Erweitern Sie Make Skill mit geführten Entwurfs-, Validierungs-, Verhaltenstests- und Veröffentlichungstools (#7509) – Skill-Versionen anzeigen und deklarierte Abhängigkeiten vor der Verwendung validieren (#7609) – Verbindungs-Timeouts für HTTP und SSE MCP clients konfigurieren (#7649)

🔄 Geändert

– Geben Sie automatischen Speicher-Backends eine konsistente Lebenszyklus- und Aktionsschnittstelle und stellen Sie ADBPG und PowerContext als Plugins bereit (#7561, #7616)

  • Konsolenfarben und Komponentenzustände für helle und dunkle Themen standardisieren (#7487)
  • Verbesserung der Agentenauswahl auf kleineren Bildschirmen (#7623)

🐛 Behoben

Konsole, Chat und Dateien

– Verhindern Sie veraltete Sitzungsstatus und Senderennen in der Warteschlange beim Streamen, Wechseln von Gesprächen oder beim schnellen Senden von Nachrichten (#7523, #7610, #7237) – Halten Sie kostenlose Modelle von der Registerkarte „Pro-Modell“ getrennt (#7524) – Behalten Sie den ausgewählten Schleifenmodus bei, wenn Sie einen Chat über einen Link öffnen (#7560) – Verwenden Sie in der gesamten Konsole dieselben Sprachoptionen (#7595) – Behalten Sie die Gruppierung der Chrome-Erweiterungsregisterkarten mit der richtigen QwenPaw-Sitzung bei (#7457)

  • Machen Sie Navigations- und Theme-Umschaltsymbole optisch einheitlich (#7499)
  • PawApp-Updates anzeigen, wenn sich die installierte und die verfügbare Version unterscheiden (#7651) – Datei-Upload-Steuerelemente nur innerhalb eines Arbeitsbereichs anzeigen (#7667) – Stellen Sie den konsistenten QwenPaw-Stil für Formulare und das Git-Bedienfeld wieder her (#7646)

Laufzeit, Sicherheit und Kompatibilität

– Für kritische Sicherheitsbefunde ist eine Genehmigung erforderlich, es sei denn, die Richtlinie verweigert die Aktion ausdrücklich (#7525) – Erzwingen Sie die Tool-Zulassungsliste jedes MCP-Servers im Agent-Laufzeitpfad (#7504) – Verwaltete Chromium-Installation aus dem Startpfad verschieben, damit das Browser-Setup den Start von QwenPaw nicht blockieren kann (#7539) – Verhindern Sie, dass ACP-Agents beim Start des Arbeitsbereichs unter Windows blockieren (#7401) – Akzeptieren Sie numerisch aussehende Toolargumente, die von einigen Modellen als JSON-Zahlen ausgegeben werden (#6936) – PDF-Inhalte sicher konvertieren, wenn ein ausgewähltes Modell Text, aber keine Dokumentblöcke akzeptiert (#7621)

  • Halten Sie lange Gespräche innerhalb der Kontextgrenzen, indem Sie bereits konsumierte Denkinhalte falten (#7521) – Stellen Sie die Kompatibilität mit MCP-Servern wieder her, deren Legacy-Authentifizierungsfluss auf die Erkennung mit HTTP 401 reagiert (#7627) – Verhindern Sie, dass untergeordnete Shell-Prozesse mit QwenPaw um interaktive Eingaben konkurrieren (#7598) – Geben Sie die korrekte „Nicht gefunden“-Antwort zurück, wenn die Konfiguration für ein unbekanntes Tool angefordert wird (#7498) – Behalten Sie die vollständigen Ausnahmedetails in Protokollen bei, wenn ein Downstream-Tool-Aufruf-Handler fehlschlägt, und geben Sie gleichzeitig einen sicheren Fehler an das Modell zurück (#7578)

Speicher, Hub und Betrieb

– Gibt einen umsetzbaren Speicherstatus zurück, wenn ein konfiguriertes Backend nicht verfügbar ist, und greift sicher zurück, wenn das Plugin nicht geladen werden kann (#7544, #7663) – Starten Sie Hub-Laufzeiten, ohne Lebenszyklusvorgänge zu blockieren, und authentifizieren Sie CLI-Anfragen bei der aktiven lokalen Laufzeit (#7566, #7631) – Wiederherstellung der Skill-Erkennung über den aktuellen ClawHub-Endpunkt (#7640) – Unix-Berechtigungsbits für wiederhergestellte Geheimnisse und Hauptschlüssel beibehalten (#7658) – Base64-kodierte Bilder und andere Medien korrekt über unterstützte Chat-Kanäle bereitstellen (#7647)

QwenPaw v2.2.1

Highlights

  • Per-agent model routing with fallbacks — #7501 gives each Agent its own provider preferences and fallback chain instead of inheriting a global default. This is the headline capability for multi-agent deployments: you can pin a cheap, fast model for routine agents and reserve a stronger one for critical paths, and ride out a provider outage without touching shared config. Audit agents that previously relied on the global default, since their routing behavior will change after upgrade.

  • Memory backends become plugins with a unified lifecycle — The main migration surface: automatic memory backends now share a consistent lifecycle/action interface, with ADBPG and PowerContext delivered as plugins (#7561, #7616). PowerContext is newly available as an optional Console-configured backend (#7080), and Auto Fin adds proactive memory review atop an upgraded ReMe (#7441). If you relied on a built-in backend, confirm its plugin is installed and re-check its settings; unavailable backends or plugins that fail to load now return actionable status and fall back safely (#7544, #7663) instead of failing quietly.

  • Skills and MCP get stricter contracts — Selected Skills can preload their full instructions to remove an activation round-trip (#7183), version display plus declared-dependency validation (#7609) catch missing dependencies before use, and Make Skill gains guided drafting, validation, behavior tests, and publishing tools (#7509). For MCP, HTTP/SSE connection timeouts are now configurable (#7649), which helps with flaky remote servers — but the tighter validation means configurations that were previously tolerated may now surface as hard errors.

  • Security and runtime behavior tightened — Critical security findings now require approval unless a policy explicitly denies the action (#7525), and every MCP server's tool allowlist is enforced on the Agent runtime path (#7504). Workflows that silently auto-approved risky actions or called tools outside a server's allowlist will now prompt or fail, so review policies and allowlists before rollout. Model interop also improves: numeric-looking tool args emitted as JSON numbers are accepted (#6936), legacy MCP servers that answer discovery with HTTP 401 work again (#7627), and text-only models get safe PDF conversion (#7621).

  • Reliability and context management — Streaming/conversation races that left stale session state or queued sends (#7523, #7610, #7237) are fixed, and already-consumed thinking content is folded to keep long conversations inside context limits (#7521) — a practical win for long-running agents. Startup and ops hardening: managed Chromium no longer blocks launch (#7539), Hub runtimes start without blocking lifecycle operations and CLI requests authenticate to the active local runtime (#7566, #7631), Windows ACP workspace-startup stalls are fixed (#7401), and shell child processes no longer compete for interactive input (#7598).

  • Console configuration consolidated — Environment variables move to a single settings page shared by Agents, MCP services, tools, and local models (#7538), so secrets are managed in one place, and one-click detection now covers both plugin and PawApp updates (#7605, #7651). The sidebar/Settings redesign with customizable navigation (#7502), consistent language options (#7595, #7482), and restored direct-path entry for session directories (#7593) are workflow improvements rather than API changes — expect UI locations to move.

No breaking changes were declared for v2.2.1.

What's Changed

✨ Added

Models, Agents & Memory

  • Configure model routing separately for each Agent, including provider preferences and fallback behavior (#7501)
  • Add Auto Fin proactive memory review and upgrade ReMe for more reliable long-term-memory processing (#7441)
  • Add PowerContext as an optional long-term-memory backend with configuration in the Console (#7080)
  • Strengthen built-in Agent behavior around request scope, untrusted content, confirmations, tool use, and completion (#7526)

QwenPaw Creator

  • Add a blueprint workbench, multi-timeline comparison, reusable video templates, MiniMax H3 support, project snapshot rollback, clearer Agent progress, and Docker deployment in Creator 1.2.0 (#7486)

Console & Workspaces

  • Manage environment variables in a unified settings page shared by Agents, MCP services, tools, and local models (#7538)
  • Detect available plugin and PawApp updates and install them with one click (#7605)
  • Redesign the sidebar and Settings experience with customizable navigation and improved session browsing (#7502)
  • Restore direct path entry when choosing a session project directory (#7593)
  • Add Chinese and English localization to Agent Kanban (#7482)

Skills & MCP

  • Let selected Skills preload their full instructions so they are ready without an extra activation step (#7183)
  • Upgrade Make Skill with guided drafting, validation, behavior tests, and publishing tools (#7509)
  • Show Skill versions and validate declared dependencies before use (#7609)
  • Configure connection timeouts for HTTP and SSE MCP clients (#7649)

🔄 Changed

  • Give automatic memory backends a consistent lifecycle and action interface, and deliver ADBPG and PowerContext as plugins (#7561, #7616)
  • Standardize Console colors and component states across light and dark themes (#7487)
  • Improve the Agent selector on smaller screens (#7623)

🐛 Fixed

Console, Chat & Files

  • Prevent stale session state and queued-send races when streaming, switching conversations, or submitting messages quickly (#7523, #7610, #7237)
  • Keep free models separate from the Pro model tab (#7524)
  • Preserve the selected loop mode when opening a chat from a link (#7560)
  • Use the same language options throughout the Console (#7595)
  • Keep Chrome extension tabs grouped with the correct QwenPaw session (#7457)
  • Make navigation and theme-toggle icons visually consistent (#7499)
  • Show PawApp updates whenever the installed and available versions differ (#7651)
  • Show file upload controls only inside a workspace (#7667)
  • Restore consistent QwenPaw styling for forms and the Git panel (#7646)

Runtime, Security & Compatibility

  • Require approval for critical security findings unless policy explicitly denies the action (#7525)
  • Enforce each MCP server's tool allowlist on the Agent runtime path (#7504)
  • Move managed Chromium installation out of the startup path so browser setup cannot block QwenPaw launch (#7539)
  • Prevent ACP Agents from stalling during workspace startup on Windows (#7401)
  • Accept numeric-looking tool arguments emitted as JSON numbers by some models (#6936)
  • Convert PDF content safely when a selected model accepts text but not document blocks (#7621)
  • Keep long conversations within context limits by folding thinking content that has already been consumed (#7521)
  • Restore compatibility with MCP servers whose legacy authentication flow responds to discovery with HTTP 401 (#7627)
  • Prevent shell child processes from competing with QwenPaw for interactive input (#7598)
  • Return the correct not-found response when configuration is requested for an unknown tool (#7498)
  • Preserve full exception details in logs when a downstream tool-call handler fails, while returning a safe error to the model (#7578)

Memory, Hub & Operations

  • Return actionable memory status when a configured backend is unavailable, and fall back safely when its plugin cannot load (#7544, #7663)
  • Start Hub runtimes without blocking lifecycle operations and authenticate CLI requests to the active local runtime (#7566, #7631)
  • Restore Skill discovery through the current ClawHub endpoint (#7640)
  • Preserve Unix permission bits for restored secrets and master keys (#7658)
  • Deliver Base64-encoded images and other media correctly across supported chat channels (#7647)
