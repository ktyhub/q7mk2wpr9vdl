spring-framework v7.0.10

Patch Veröffentlicht22. Okt. 2026 Quellespring-projects/spring-framework Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Federrahmen v7.0.10

:star: Neue Funktionen

– DelegatingMessageSource-Fallback-Implementierung mit AbstractMessageSource ausrichten #37383 – HttpEntity(T, MultiValueMap) speichert ein HttpHeaders ungeprüft, wodurch IncompatibleClassChangeError in RestTemplate entsteht #37358 – Verlagerte Mockito MockAccess-Schnittstelle in ProxyProcessorSupport erkennen #37342 – Laufzeitkompatibilität mit JPA 4.0 M7 und entsprechenden Hibernate 8.0-Snapshots #37315 – Kotlin-Reflexion in MethodParameter für nicht anhaltende Funktionen vermeiden #37300 – Überarbeitung des Fallbacks für die Benennung von Unterstrichen in SimplePropertyRowMapper #37297 – Vermeiden Sie unnötige Warteschlangenoperationen in ConcurrentLruCache.clear() #37292 – PathMatchingResourcePatternResolver übersieht Jars auf java.class.path, deren Pfad % enthält #37280 – Entfernen Sie redundante Leerzeichen in Ausnahmemeldungen #37277 – OpenInView funktioniert nicht mehr mit HibernateTransactionManager #37273 – Behandeln Sie setClientInfo/setNetworkTimeout in LazyConnectionDataSourceProxy träge #37261

  • Vermeiden Sie redundante Filterung in FilteredMap.size() #37256 – Unterstützt NaN- und unendliche Float-Werte in toString() für synthetisierte Anmerkungen #37244
  • Verwenden Sie ArrayList anstelle von LinkedList in CompositeRetryListener #37231
  • redirectedUrl()-Argument in MockMvcResultMatchers sollte @Nullable sein #37230 – In der veröffentlichten Gradle-Moduldatei fehlen javadocElements und sourcesElements #37209 – Einführung eines Builders für SpelParserConfiguration #37187 – Alle Protobuf-Unterstützungsklassen implementieren getMessageBuilder() #37147 – Null contextPath in ServerHttpRequest.Builder zulassen #37099 – Broker-Verfügbarkeitsereignisse als String-Nachrichten protokollieren #36856

:lady_beetle: Fehlerbehebungen

– Vermeiden Sie unnötige abhängige Bean-Registrierung für Autowire-by-Type #37424 – Behandeln Sie null readTimeout in JdkClientHttpConnector #37412 – Racebedingung in PartGenerator.CreateFileState kann das Abschlusssignal verlieren #37409 – Angehaltener Executor mit spätem Herunterfahren verliert seinen Arbeitsthread (und den geschlossenen Kontext) nach dem Schließen #37406 – Hängende Wiederholungsversuche für Flux-Return-Methoden mit Caching behoben #37403 – Vermeiden Sie die Bereitstellung veralteter Werte nach einem fehlgeschlagenen Nachfüllen in AbstractIdentityColumnMaxValueIncrementer #37402

  • Cookies in RenderingResponse.from() kopieren #37378
  • Vermeiden Sie Phantomtasten in LinkedCaseInsensitiveMap.computeIfAbsent #37351 – Korrektur der Einzelwertanpassung für primitive Array-Typen in TypeMappedAnnotation #37349 – CssLinkResourceTransformer schlägt bei ungültigen CSS-Links fehl #37336 – Behebung der Wiederverwendung zwischengespeicherter IDs nach einem Commit-Fehler in MySQLMaxValueIncrementer #37322 – Verbindungsleck im MySQLMaxValueIncrementer behoben #37321 – @CacheEvict schneidet Flux-Ergebnisse auf das erste Element ab #37309 – ConcurrentLruCache.clear() kann während der Ausführung hinzugefügte Einträge übersehen #37287 – Erzwingen Sie die Beschränkung der Festplattennutzung, wenn Teile auf die Festplatte übertragen werden #37285 – Doppelte Größenverringerung in ConcurrentLruCache verhindern #37268 – LogAccessor.debug(CharSequence) rendert LogMessage eifrig, seit Spring-Core 7 von Spring-JCL auf Commons-Logging umgestellt wurde #37266 – WebFlux verliert eine leere mehrteilige Datei, wenn der Dateiteil nicht der letzte ist. #37264 – Vervollständigen Sie leere Uni-Instanzen vom reaktiven Mutiny-Adapter #37259 – DefaultAsyncServerResponse.writeAsync() verwirft zuvor konfigurierte AsyncWebRequest-Zeitüberschreitung #37257 – Bereitstellung fehlender nativer Bildhinweise für Proxy-Abfragetypen im Ruhezustand 8 #37251 – Geben Sie einen fehlenden nativen Image-Hinweis für den von SharedEntityManagerCreator erstellten StatelessSession-Proxy an. #37249 – Geben Sie einen Hinweis auf fehlende native Bildreflexion für den Ruhezustand PersistenceUnitInfoDescriptor an. #37247
  • Sortieren Sie doppelte Schlüsselcodes in SQLErrorCodes #37235 – Behandeln Sie null readTimeout in JdkClientHttpRequestFactory #37234 – Falsche Anzahl der Wiederverbindungsversuche in ReactorNettyTcpClient #37223 – OUT-Parameterwerte gespeicherter Prozeduren gehen ab 7.0.9 #37221 außerhalb einer Transaktion verloren. – Int-Überlauf bei Ablaufzeitberechnungen in MockMvc und FlashMap vermeiden #37208 – ScheduledAnnotationBeanPostProcessor unterstützt die Bean-Zerstörung nicht korrekt #37207 – Normalisierung der Funktionsrückgabeparametersuche in CallMetaDataContext #37206 – Korrigieren Sie das Lesen außerhalb der Grenzen für abgeschnittenes Prozent-Escape im undurchsichtigen Host #37203 – ClassFileTransformerAdapter-Deadlocks zwischen zwei Persistenzeinheiten beim Load-Time-Weaving #37199 – Kotlin-Wertklassenbehandlung zum Anhalten von AOP-Methoden korrigiert #37191 – Update auf NullAway 0.14.0 und Behebung neuer Warnungen #37188 – ProtobufJsonEncoder gibt ein JSON-Array aus, wenn der Medientyp ndjson ist #37158 – StreamingMediaTypes in ProtobufJsonEncoder ist keine Teilmenge von encodableMimeTypes #37154 – Richten Sie die DataBufferUtils$WriteCompletionHandler-Ausnahmebehandlung an der read()-Seite aus #37145 – DataBufferUtils.read() mit NettyDataBuffer auf JDK 25 bleibt auf unbestimmte Zeit hängen #37143 – Geben Sie in der Warteschlange befindliche Body-Token-Puffer bei mehrteiligem Abbruch frei #37115 – Reihenfolge des asynchronen API-Versionsresolvers beibehalten #37096 – Der Builder ClientResponse.mutate() kann originalResponse-Header ändern. #37086 – Benutzerdefinierter Grund wird durch die i18n-Nachricht in ResponseStatusException.updateAndGetBody() #36984 überschrieben. – Generieren Sie kompilierbaren Code für nicht endliche Gleitkommawerte #36965 – Parametertypnamen in ClassFileMethodMetadata rendern #36919
  • sourceStart-Offset in AbstractXMLStreamReader#getTextCharacters berücksichtigen #36914 – Reparieren Sie „reserveMethodNames“, um jeden bereitgestellten Namen zu reservieren #36912 – Thread-unsicheres SimpleDateFormat durch DateTimeFormatter in AbstractMockHttpServletRequestBuilder ersetzen #36772 – MockHttpServletRequest.isRequestedSessionIdValid() folgt nicht dem Servlet 6.1 Javadoc #36631 – Kartenversion von @HttpExchange zu RequestMappingInfo #36602 – Stellen Sie sicher, dass ConversionService.canConvert(Enum) keine Ausnahme mehr auslöst #34532

:notebook_with_decorative_cover: Dokumentation

– Korrigieren Sie falsche Klassennamen in WebFlux- und MVC-Dokumenten #37467 – Dokumentieren Sie das XXE-Bedrohungsmodell von SourceHttpMessageConverter #37407 – Aktualisierung der Anweisungen zum Importieren von Projekten in die Eclipse-IDE #37397

  • Syntaxfehler im Referenzhandbuch beheben #37392 – Korrigieren Sie das Kotlin-Beispiel in den Spring MVC-Testdokumenten #37388 – Dokumentverwendung des Attributs type im JSP-Tag <form:input> #37376
  • Machen Sie CONTRIBUTING.md eigenständig und fügen Sie AGENTS.md #37372 hinzu. – ConcurrentReferenceHashMap-Referenzsemantik klären #37357 – Fehlende umschließende einfache Anführungszeichen in Javadoc hinzugefügt #37338 – Beispiel für asynchrone MockMvc-Anfragen in der Dokumentation behoben #37318 – Schließende geschweifte Klammern zu Beispielen hinzufügen #37305
  • Tippfehler im Javadoc beheben #37229 – Weitere Aktualisierungen des Datenbindungsinhalts in Webabschnitten der Dokumentation #37228 – Fehlende schließende Klammer im WebFlux-Konfigurationsreferenzbeispiel hinzugefügt #37163 – Verwenden Sie <<id,text>> anstelle von xref: für lokale Links in Referenzdokumenten #37161 – Defekte interne XRef-Links in Referenzdokumenten beheben #37152 – Korrigieren Sie Kotlin-Beispiele im Referenzhandbuch #37101 – Dokument, das @Retryable mit Proxy-basierten Funktionen kombiniert #37005 – Update-Empfehlungen für die Web-Datenbindung #36789

:hammer: Abhängigkeits-Upgrades

  • Upgrade auf Mikrometer 1.16.8 #37440
  • Upgrade auf Reaktor 2025.0.8 #37374

Englisches Original / English original

spring-framework v7.0.10

:star: New Features

  • Align DelegatingMessageSource fallback implementation with AbstractMessageSource #37383
  • HttpEntity(T, MultiValueMap) stores an HttpHeaders unchecked, causing IncompatibleClassChangeError inside RestTemplate #37358
  • Recognize relocated Mockito MockAccess interface in ProxyProcessorSupport #37342
  • Runtime compatibility with JPA 4.0 M7 and corresponding Hibernate 8.0 snapshots #37315
  • Avoid Kotlin reflection in MethodParameter for non-suspending functions #37300
  • Revise underscore naming fallback in SimplePropertyRowMapper #37297
  • Avoid useless queue ops in ConcurrentLruCache.clear() #37292
  • PathMatchingResourcePatternResolver misses jars on java.class.path whose path contains % #37280
  • Remove redundant whitespace in exception messages #37277
  • OpenInView does no longer work with HibernateTransactionManager #37273
  • Lazily handle setClientInfo/setNetworkTimeout in LazyConnectionDataSourceProxy #37261
  • Avoid redundant filtering in FilteredMap.size() #37256
  • Support NaN and inifinite float values in toString() for synthesized annotations #37244
  • Use ArrayList instead of LinkedList in CompositeRetryListener #37231
  • redirectedUrl() argument in MockMvcResultMatchers should be @Nullable #37230
  • Published Gradle module file is missing javadocElements and sourcesElements #37209
  • Introduce a builder for SpelParserConfiguration #37187
  • Protobuf support classes all implement getMessageBuilder() #37147
  • Allow null contextPath in ServerHttpRequest.Builder #37099
  • Log broker availability events as String messages #36856

:lady_beetle: Bug Fixes

  • Avoid unnecessary dependent-bean registration for autowire-by-type #37424
  • Handle zero readTimeout in JdkClientHttpConnector #37412
  • Race condition in PartGenerator.CreateFileState can lose the completion signal #37409
  • Paused executor with late shutdown leaks its worker thread (and the closed context) after close #37406
  • Fix hanging retries for Flux-returning methods with caching #37403
  • Avoid serving stale values after failed refill in AbstractIdentityColumnMaxValueIncrementer #37402
  • Copy cookies in RenderingResponse.from() #37378
  • Avoid phantom keys in LinkedCaseInsensitiveMap.computeIfAbsent #37351
  • Fix single-value adaptation for primitive array types in TypeMappedAnnotation #37349
  • CssLinkResourceTransformer fails for invalid CSS links #37336
  • Fix cached ID reuse after commit failure in MySQLMaxValueIncrementer #37322
  • Fix connection leak in MySQLMaxValueIncrementer #37321
  • @CacheEvict truncates Flux results to the first element #37309
  • ConcurrentLruCache.clear() can miss entries added while it's running #37287
  • Enforce disk usage limit when spilling part to disk #37285
  • Prevent double size decrement in ConcurrentLruCache #37268
  • LogAccessor.debug(CharSequence) eagerly renders LogMessage since spring-core 7 switched from spring-jcl to commons-logging #37266
  • WebFlux loses empty multipart file when the file part is not last. #37264
  • Complete empty Uni instances from the Mutiny reactive adapter #37259
  • DefaultAsyncServerResponse.writeAsync() discards previously configured AsyncWebRequest timeout #37257
  • Provide missing native image hints for proxied hibernate 8 query types #37251
  • Provide missing native image hint for StatelessSession proxy created by SharedEntityManagerCreator. #37249
  • Provide missing native image reflection hint for hibernate PersistenceUnitInfoDescriptor. #37247
  • Sort duplicate key codes in SQLErrorCodes #37235
  • Handle zero readTimeout in JdkClientHttpRequestFactory #37234
  • Wrong reconnection attempt count in ReactorNettyTcpClient #37223
  • Stored procedure OUT parameter values are lost outside a transaction as of 7.0.9 #37221
  • Avoid int overflow in expiration time calculations in MockMvc and FlashMap #37208
  • ScheduledAnnotationBeanPostProcessor doesn't correctly support bean destruction #37207
  • Normalize function return parameter lookup in CallMetaDataContext #37206
  • Fix out-of-bounds read for truncated percent-escape in opaque host #37203
  • ClassFileTransformerAdapter deadlocks between two persistence units under load-time weaving #37199
  • Fix Kotlin value class handling for suspending AOP methods #37191
  • Update to NullAway 0.14.0 and fix new warnings #37188
  • ProtobufJsonEncoder emits JSON array when media type is ndjson #37158
  • streamingMediaTypes in ProtobufJsonEncoder not a subset of encodableMimeTypes #37154
  • Align DataBufferUtils$WriteCompletionHandler exception handling with the read() side #37145
  • DataBufferUtils.read() with NettyDataBuffer on JDK 25 hangs indefinitely #37143
  • Release queued body token buffers on multipart cancel #37115
  • Preserve async API version resolver order #37096
  • ClientResponse.mutate() builder can modify originalResponse headers. #37086
  • Custom reason is overwritten by i18n message in ResponseStatusException.updateAndGetBody() #36984
  • Generate compilable code for non-finite floating-point values #36965
  • Render parameter type names in ClassFileMethodMetadata #36919
  • Honor sourceStart offset in AbstractXMLStreamReader#getTextCharacters #36914
  • Fix reserveMethodNames to reserve each supplied name #36912
  • Replace thread-unsafe SimpleDateFormat with DateTimeFormatter in AbstractMockHttpServletRequestBuilder #36772
  • MockHttpServletRequest.isRequestedSessionIdValid() does not follow Servlet 6.1 Javadoc #36631
  • Map version from @HttpExchange to RequestMappingInfo #36602
  • Ensure that ConversionService.canConvert(Enum) no longer throws an exception #34532

:notebook_with_decorative_cover: Documentation

  • Fix incorrect class names in WebFlux and MVC docs #37467
  • Document the XXE threat model of SourceHttpMessageConverter #37407
  • Update instructions for importing projects into Eclipse IDE #37397
  • Fix syntax errors in the reference manual #37392
  • Fix Kotlin example in Spring MVC test docs #37388
  • Document usage of type attribute in JSP <form:input> tag #37376
  • Make CONTRIBUTING.md self-contained and add AGENTS.md #37372
  • Clarify ConcurrentReferenceHashMap reference semantics #37357
  • Add missing enclosing single quotes in Javadoc #37338
  • Fix MockMvc async requests example in documentation #37318
  • Add closing braces to examples #37305
  • Fix typos in Javadoc #37229
  • Further updates to Data Binding Content in Web Sections of Documentation #37228
  • Add missing closing parenthesis in WebFlux config reference example #37163
  • Use <<id,text>> instead of xref: for local links in reference docs #37161
  • Fix broken internal xref links in reference docs #37152
  • Fix Kotlin examples in the reference manual #37101
  • Document combining @Retryable with proxy-based features #37005
  • Update recommendations for web data binding #36789

:hammer: Dependency Upgrades

  • Upgrade to Micrometer 1.16.8 #37440
  • Upgrade to Reactor 2025.0.8 #37374
