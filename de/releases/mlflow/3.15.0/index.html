mlflow v3.15.0

MLflow 3.15.0 enthält mehrere wichtige Funktionen und Verbesserungen

Wichtige neue Funktionen

  • 🧩 MCP Registry: Ein zentraler Katalog zum Registrieren, Versionieren und Teilen von Model Context Protocol-Servern – mit semantisch versionierten Konfigurationen, heraufstufungsfähigen Aliasen, Tags, automatisch erkannten Tools und vorgefertigten Verbindungsanweisungen für Claude Code und .mcp.json. Verwalten Sie es über die Benutzeroberfläche, REST API oder Python!
  • 🤖 Verbesserungen des MLflow-Assistenten: Der In-App-KI-Assistent unterstützt jetzt mehrere LLM-Anbieter (Claude Code, Codex und OpenAI-kompatible/Gateway-Endpunkte), die auf einer einzigen Einstellungsseite ausgewählt werden können, zeigt die Token-Nutzung pro Sitzung und die geschätzten Kosten im Composer live an und ist einfacher einzurichten – mlflow agent setup kann ihn in einer Eingabeaufforderung aktivieren, wobei API-Schlüssel sicher in den LLM-Verbindungen des Gateways gespeichert werden.
  • 🗂️ Gemeinsam nutzbare Tabellenansichten: Speichern Sie benannte Ansichten der Runs-Tabelle – erfassen Sie Spalten, Reihenfolge, Breiten, Filter und Sortierung – und geben Sie sie per URL frei.
  • ⚡ Proxy-loser Artefakt-Upload/Download über vorsignierte URLs: Große Artefaktübertragungen können jetzt den Tracking-Server umgehen und über vorsignierte URLs direkt mit dem Cloud-Speicher (z. B. S3) kommunizieren, wodurch die Serverlast und Zeitüberschreitungen bei großen Dateien reduziert werden. Aus Gründen der Abwärtskompatibilität greifen wir automatisch auf die Proxy-Übertragung zurück.
  • 🖼️ Multimodale Anhänge in LLM-Richter: {{ trace }}-Richter, die mit make_judge() erstellt wurden, können jetzt über ein neues get_span_image-Tool, das Anhänge als Base64-Daten-URLs abruft und sie an multimodale Modelle (Anthropic, Gemini und OpenAI-kompatibel über litellm) übergibt, in Trace-Spans erfasste Bilder sehen – was die Auswertung von Sehaufgaben, Screenshots und anderen visuellen Inhalten ermöglicht.

mlflow v3.15.0

MLflow 3.15.0 includes several major features and improvements

Major New Features

  • 🧩 MCP Registry: A centralized catalog for registering, versioning, and sharing Model Context Protocol servers — with semantic-versioned configs, promotable aliases, tags, auto-discovered tools, and ready-made connection instructions for Claude Code and .mcp.json. Manage it from the UI, REST API, or Python!
  • 🤖 MLflow Assistant enhancements: The in-app AI assistant now supports multiple LLM providers (Claude Code, Codex, and OpenAI-compatible/Gateway endpoints) chosen from a single settings page, displays live per-session token usage and estimated cost in the composer, and is easier to set up — mlflow agent setup can enable it in one prompt, with API keys stored securely in the Gateway's LLM Connections.
  • 🗂️ Sharable table views: Save named views of the Runs table — capturing columns, order, widths, filters, and sort — and share them by URL.
  • ⚡ Proxy-less artifact upload/download via presigned URLs: Large artifact transfers can now bypass the tracking server and talk directly to cloud storage (e.g. S3) through presigned URLs, cutting server load and timeouts on big files. We fall back to proxied transfer automatically for backward compatibility.
  • 🖼️ Multi-modal attachments in LLM judges: {{ trace }} judges created with make_judge() can now see images captured in trace spans via a new get_span_image tool, which fetches attachments as base64 data URLs and passes them to multimodal models (Anthropic, Gemini, and OpenAI-compatible via litellm) — enabling evaluation of vision tasks, screenshots, and other visual content.
