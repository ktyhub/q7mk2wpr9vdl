rocketmq rocketmq-all-5.5.0

Diese Version führt den Lite-Modus ein, einen einfachen Abonnementmechanismus, der für KI-Szenarien entwickelt wurde, sowie Verbesserungen für Broker-, Proxy- und client-Komponenten.

Neue Funktion (Lite-Modus)

Einführung eines einfachen Abonnementmodus (Lite-Modus), der effizientere Nachrichtenübermittlung bei geringerem Ressourcenverbrauch ermöglicht. Dieser Modus bietet vollständige Lebenszyklusverwaltung, Ereignisverteilung, Abonnementregistrierung, Nachrichtenverarbeitung und Metriküberwachung. Mit dem neu hinzugefügten Lite-Nachrichtenprozessor, dem Long-Polling-Dienst, dem Steuerungshandler und der entsprechenden Protokollunterstützung wird ein effizienter, leichter Nachrichtenabonnementmechanismus eingerichtet, der auf KI-Szenarien zugeschnitten ist.

  • [RIP-83] Lite-Thema: Ein neues Nachrichtenmodell von @f1amingo in https://github.com/apache/rocketmq/pull/9800

rocketmq rocketmq-all-5.5.0

This version introduces Lite Mode, a lightweight subscription mechanism designed for AI scenarios, alongside enhancements across Broker, Proxy, and client components.

New Feature (Lite Mode)

Introduced a lightweight subscription mode (Lite Mode) that delivers more efficient messaging with reduced resource consumption. This mode provides complete lifecycle management, event dispatching, subscription registration, message processing, and metrics monitoring. With the newly added Lite message processor, long-polling service, control handler, and corresponding protocol support, it establishes an efficient lightweight message subscription mechanism tailored for AI scenarios.
