17-Versionen indiziert · neueste v2.2.3 auf 1. Okt. 2026

10/01
v2.2.3 Patch MT

ECC 2.2.3 ist ein Update zur Benennung und Release-Zuverlässigkeit. Das Projekt heißt überall dort, wo es ausgeliefert wird, ECC, beginnend mit dem pi/core-Profil, und der Release-Workflow wartet nun lange genug darauf, dass npm ein frisch veröffentlichtes … bereitstellt.

 09/30
v2.2.2 Patch MT

ECC 2.2.2 fügt pi/core hinzu, ein kuratiertes Pi-natives Profil nur für Fähigkeiten und Eingabeaufforderungen, das für nachgeschaltete Paketierer entwickelt wurde, die GitHub-Versionen widerspiegeln, sowie eine Reihe von Paketierungs-, Speicher-, Hooks- und Windows-Kompatibilitätskorrekturen.

 09/08
v2.2.1 Patch MT

ECC 2.2.1 ist ein Bug- und Sicherheitspatch für ECC 2.2. Dadurch bleibt der veröffentlichte v2.2.0-Verlauf unveränderlich. Diese Hinweise beschreiben den vorbereiteten Patch;

 08/28
v2.2.0 Minor MT

ECC 2.2 ist da, geleitet von einem geführten Installer für Claude Code, Codex und Kimi. Es bietet außerdem native Antigravity 2.0-Unterstützung und eine experimentelle, optionale Nasiko CLI-Lebenszyklusbrücke.

 07/27
v2.1.0 Minor MT

ECC 2.1 verwandelt die Planüberprüfung in eine visuelle Schleife und öffnet den Zugriff auf selbstgehostete Modelle. Mit Plan Canvas können Sie Agentenpläne im Browser überprüfen. Zeigen Sie auf den Teil, den Sie meinen, anstatt ihn im Chat noch einmal einzugeben.

 06/10
v2.0.0 Major MT

ECC 2.0.0 is the stable graduation of the 2.0 line: ECC as a cross-harness operating system for agentic work. Claude Code stays first-class;
