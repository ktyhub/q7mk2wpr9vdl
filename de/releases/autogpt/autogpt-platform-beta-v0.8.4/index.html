AutoGPT autogpt-platform-beta-v0.8.4

Highlights

  • Resumable Copilot turn runtime — #15089 moves Copilot chat onto a turn runtime that resumes at its cursor over a single connection. Queued turns now start streaming as soon as the backend runs them (#15346), and a lost connection no longer leaves false errors, spinners, endless retries, or "Failed to fetch" in place of a finished answer (#15398, #15402). Net effect: fewer reload-to-see-the-answer workflows; watch that slot reservation and approval envelopes were reworked alongside it (#15347, #15353).
  • Billing corrected to per-turn accounting — a cluster of hotfixes stops overcharging: each SDK turn is charged its own cost instead of the session's running total (#15305, #15342), retried turns bill only the attempt that succeeded and never repeat tool calls (#15399, #15420), and Anthropic 5xx/overload errors reported by Claude CLI are retried (#15381). If you reconcile spend against provider invoices, expect totals to shift downward and per-turn charges to become the source of truth.
  • MCP-first expert integrations — experts now connect through MCP by default (#15199), with Slack and HubSpot authenticating via configured apps/OAuth rather than static credentials (#15066, #15366). Migration watch: the HubSpot block now asks for a service key or private-app token because the legacy API key is retired (#15367), and placeholder clients are refused where a secret is required; MCP OAuth errors echo state to aid debugging (#15311). Discovery improves too — marketplace search matches job titles and find_capability sees roster experts (#15147, #15149).
  • Self-hosted parity and safer startup — hosted-only UI is kept out of self-hosted installs, and self-hosted signup grants, the memory page, and no-model chat are fixed (#15408, #15409). Feature flags now load at startup in every service that reads them and retired flag names are dropped (#15370, #15354), so stale runtime flag behavior should disappear. Image builds are repaired by isolating poetry and prisma in their own venvs for debian:13-slim (#15309) and refreshing Debian packages daily so security fixes ship (#15464).
  • Security and tenancy hardening — credentials are masked in request URLs before logging and Sentry (#15417), Office files such as .pptx render safely on the Files page (#15359, SECRT-2437), and retransmitted chat sends no longer queue a duplicate run (#14939, SECRT-2695). Community Replicate models run without a version hash (#15128, SECRT-2806), and deleted shared runs stop serving their page and files (#15489).
  • Model coverage and observability — new providers land (Meta Muse Wonder #15480, Google Gemini 4 Argon #15496) and the AI/ML API blocks/llm URL is corrected (#14154). Copilot turns and graph node runs get their own Sentry traces tagged with the deployed commit (#15462, #15460), while noisy/duplicate reports are cut down (#15391, #15433) — useful if you lean on traces to debug turn-level latency.

No breaking changes in this release.
