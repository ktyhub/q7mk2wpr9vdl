🔥 Was ist neu?

⚠️ Breaking Changes

  • #16416 – Selbstgehostete Installationen: .env.default liefert kein Web Push-Schlüsselpaar (VAPID) mehr und das Backend sendet keine Push-Benachrichtigungen mehr mit dem alten gelieferten Paar. Führen Sie make init-env aus, um ein Paar für Ihre Installation zu generieren. Das Einzelcontainer-Image generiert beim ersten Start ein eigenes Image. Durch das Ersetzen des Paares werden bestehende Push-Abonnements ungültig. NEXT_PUBLIC_VAPID_PUBLIC_KEY kann leer bleiben und das Frontend verwendet dann den Schlüssel des Backends (von @ntindle)

Highlights

  • Self-hosted Web Push keys require migration — .env.default no longer ships a VAPID pair, and the backend no longer sends notifications with the old shared pair. Run make init-env to generate install-specific keys; the single-container image generates them on first boot. Rotation invalidates existing push subscriptions, so users may need to resubscribe. NEXT_PUBLIC_VAPID_PUBLIC_KEY can remain blank to use the backend’s key (#16416).

  • Workflow inputs and data integrations expand — Graphs can now use input nodes alongside triggers (#11220). New Firecrawl Alexandria and Treg blocks cover people, company, and web data (#16561, #16393), while Exa now targets its current API (#16395). Existing Exa workflows should be rechecked against the updated integration behavior.

  • Copilot gains command-driven skills and background work — Skills can run as /commands with arguments (#14991), and background subtasks now perform real work and return results to the chat (#16582). Run cards follow execution through completion or failure (#16617, #16587), making delegated work visible instead of fire-and-forget.

  • Linked data and file outputs are safer — Linked values now reach MCP tool arguments (#16276), workflow validation accepts links into list items (#16356), and unusable linked values fail the block explicitly (#16521). NumPy scalars are converted to plain Python values (#16357). Same-name run outputs no longer delete earlier files (#16343), and read_workspace_file returns text files as text (#16333).

  • Runtime failures happen earlier and recovery is more predictable — Startup retries failed database connections instead of reporting a false healthy state (#16331), oversized numbers receive a 4xx before reaching the database (#16392), and regex/Sentry scrubbing costs are bounded (#16475). Interval jobs retain their next-run time across scheduler restarts (#16367), while Windows runtime configuration writes are now atomic (#16450).

  • Onboarding, trials, and outcome metrics change — New and unfinished sign-ups are routed to onboarding, with checks repeated on account switch (#16629). Canceled-trial users receive warnings three days and one day before access ends (#16506), and paying early during a trial now grants the plan (#16649). Error-ending turns count as failed and outcomes are exportable (#16624), so success-rate reporting must account for errored turns.

  • #16416 - Self-hosted installs: .env.default no longer ships a Web Push (VAPID) key pair, and the backend no longer sends push notifications with the old shipped pair. Run make init-env to generate a pair for your install; the single-container image generates its own on first boot. Replacing the pair invalidates existing push subscriptions. NEXT_PUBLIC_VAPID_PUBLIC_KEY can stay blank, and the frontend then uses the backend's key (by @ntindle)
