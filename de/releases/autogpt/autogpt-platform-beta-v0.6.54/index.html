AutoGPT autogpt-platform-beta-v0.6.54

Highlights

  • Breaking dropdown schema change — AgentDropdownInputBlock replaces placeholder_values with options (#12595), and the old field is now scoped exclusively to that block (#12551). Update serialized graphs, templates, tests, and custom code that reads or writes the old property before upgrading.
  • CoPilot gains safer, more capable execution — Fast/Thinking mode retains full tool parity (#12623), OrchestratorBlock supports extended thinking (#12512), and tool-call circuit breakers with intermediate persistence improve failure recovery (#12604). Compaction now preserves thinking blocks and recovers truncated tool calls (#12574, #12625); AIConditionBlock also raises errors instead of silently swallowing them (#12593).
  • Dry-run becomes an end-to-end generation workflow — Session-level dry_run (#12582) combines with create → dry-run → fix (#12578), LLM simulation propagation (#12575), and OpenRouter-backed simulation (#12656). Teams can validate generated graphs—including non-OpenAI models and special blocks—before real execution; misleading INCOMPLETE/error dry-run statuses are also fixed (#12580, #12709).
  • Managed credentials and cost visibility — Generic managed credentials now support AgentMail auto-provisioning (#12537), while system-credential usage gains cost tracking (#12696). Fixes for cross-event-loop credential loading and host-scoped authenticated requests (#12628, #12579) reduce intermittent integration failures.
  • CoPilot analytics and history tooling — A multi-database SQL block (#12569), generic ask_question tool (#12647), artifact previews (#12629), newest-first cursor pagination (#12328), and all-output display (#12504) improve data inspection and long-session debugging. Client integrations should consume pagination cursors rather than assume page-number navigation.
  • Usage controls and runtime hardening — CoPilot adds rate-limit tiers and credit-funded resets (#12581, #12526), alongside LD-configurable global limits and admin reset tooling (#12566, #12577), changing how teams manage quota exhaustion. Docker builds move from EOL Node 21 to Node 22 LTS (#12561), so check native dependencies; gitleaks also adds pre-commit secret scanning (#12649).
