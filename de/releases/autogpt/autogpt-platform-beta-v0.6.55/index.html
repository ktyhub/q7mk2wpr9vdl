AutoGPT autogpt-platform-beta-v0.6.55

Highlights

  • CoPilot memory & context reliability — #12720 adds Graphiti temporal knowledge graph memory to CoPilot, paired with #12782's context fallback (upload gate, gap-fill, token-budget compression) and #12750's unified MCP Read/Write/Edit tools that fix truncation-related data loss. Together these materially improve long-session recall and file handling, so anyone relying on CoPilot for multi-step or file-heavy work benefits — this is the headline reason to upgrade.

  • Cost visibility and billing correctness (behavior change) — #12726, #12757, #12762, and #12775/#12735 rework cost accounting: per-model cost breakdowns, cache token tracking, a cost dashboard with averages, and notably charging per LLM iteration and per tool call in OrchestratorBlock (plus a cost fix there). If you self-host or meter usage, expect billing/cost numbers to shift after upgrading — verify your cost dashboards and any quotas against the new methodology before rolling out broadly.

  • Prompt caching push and a potential prompt-behavior change — #12725, #12758, and #12790 make the system prompt fully static via SystemPromptPreset to enable cross-user prompt caching. This is a cost/latency win, but making the system prompt static may change how dynamic context is injected — test your prompt-sensitive flows after upgrading rather than assuming identical output.

  • Upgrade if you run CoPilot, sub-agents, or streaming chat; skip if you don't — Stability fixes are the real value here: #12763 strips <internal_reasoning> tags from Sonnet responses, #12759/#12788 deduplicate SSE-replayed and duplicate messages, #12774 fixes a sub-agent hang/orphan on E2B API stalls, and #12766 aborts stale SSE listeners on session switch. No explicit breaking changes or migration steps are listed in this changelog, but dependency bumps worth noting are claude-agent-sdk to 0.1.58 (#12747, with OpenRouter compatibility and cost controls) and untracked auto-generated API client files (#12778) — regenerate your API client if you build against it. Pure backend/maintenance users with no CoPilot or cost-dashboard exposure can likely skip this one.
