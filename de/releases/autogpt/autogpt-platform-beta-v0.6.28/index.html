AutoGPT autogpt-platform-beta-v0.6.28

Highlights

  • Prometheus observability lands — #10923 adds comprehensive Prometheus instrumentation, so self-hosters can finally scrape real metrics instead of flying blind. Plan to expose/scrape the new metrics endpoint and wire up dashboards and alerts before rolling this into production.
  • API key storage tightened — #10796 hardens the security and reliability of stored API keys while #10936 fixes credential registration outright. If you have agents depending on persisted credentials, re-verify keys after the upgrade since the storage internals and registration path both changed.
  • Cost isolation for internal AI calls — #10930 introduces a separate OpenAI key for execution summaries and other internal AI work, letting you meter platform overhead apart from agent workloads. Provision that second key up front or summary/internal features will fail or silently fall back.
  • Scheduler becomes timezone-aware — #10921 changes how scheduled runs resolve their trigger times. Any automation that assumes a fixed wall-clock fire time should have its schedule re-checked post-upgrade, since the same cron config can now resolve differently depending on timezone.
  • Atomic execution state and shareable runs — #10863 makes graph execution status transitions atomic, eliminating inconsistent run states after partial failures; #10938 adds public share links for run results. Share links push run data outside your account boundary, so review them before enabling on agents handling sensitive output.
  • Trigger Setup removed from Builder — #10418 disables configuring triggers through the Builder UI. Workflows that relied on setting up triggers in the visual editor need to be reworked or managed elsewhere — this is the change most likely to break an existing authoring flow.

No formally breaking changes are declared in this release.
