AutoGPT autogpt-platform-beta-v0.4.2

Highlights

  • Scheduler DB connections are now bounded — #9149 makes the scheduler pool size configurable and prevents implicit overflow connections, reducing the risk of exhausting PostgreSQL connections under load. Self-hosted operators should tune the pool against their database connection budget and monitor pool wait times.
  • Breaking: prompts use Jinja syntax only — #9229 removes Python-style {Variable} compatibility from Agent Output, Fill Text Template, AI Text Generator, and AI Structured Response Generator in favor of {{Variable}}. This prevents JSON braces from being mistaken for placeholders. A database migration updates stored templates, but audit imported workflows and test prompts containing literal JSON.
  • Stopped executions get a distinct terminal status — #9185 adds TERMINATED to the database and frontend execution enums; forcefully stopped node and graph executions no longer report as FAILED or COMPLETED. Update API consumers, dashboards, retry rules, and alerts so intentional cancellations do not inflate failure counts.
  • HTTP blocks close SSRF and URL edge cases — #9157 blocks Agent Blocks from reaching internal IPv6 addresses, while #9171 fixes validation of hostname-less URLs. Workflows targeting IPv6-only internal services will now be rejected. Retest dynamic URLs, webhook endpoints affected by #9209/#9210, and plain-text request bodies handled by #9219.
  • Credential and API-key workflows are more capable — #8932 lets blocks accept multiple credential inputs, and #9212 adds frontend API-key generation. Default credentials for Fal, Exa, and E2B (#9233), plus NVIDIA support (#9235), reduce setup friction; verify the account, quota, and data policy behind defaults, and update custom block schemas where per-operation credentials are needed.
  • New blocks expand social, repository, and AI automation — Twitter integration (#8754), GitHub Create File (#9144), Create Repo (#9169), List Stargazers (#9172), and NVIDIA Deepfake Detection (#9213) add native capabilities. GitHub write blocks require appropriately scoped tokens and create persistent side effects, so test permissions against a non-production repository first.

New Features

  • #9149 - Make scheduler DB connection pool configurable & prevent connection overflow (by @majdyz)

Enhancements

  • #9180 - Move some GitHub blocks to the correct file (by @Bentlybro)
  • #9164 - Delete old marketplace code (by @Swiftyos)
