claude-code v2.1.239

Claude-Code v2.1.239

Was hat sich geändert?

– Kostenschätzungen (/cost, Statuszeile, --max-budget-usd) beinhalten jetzt die 1.1×-Inferenzprämie nur für die USA für Arbeitsbereiche mit Datenresidenz

  • Das einmalige Vollbild-Renderer-Angebot wurde für Bedrock, Vertex, Foundry und andere zuvor ausgeschlossene Setups hinzugefügt. Neue Installationen dort starten jetzt im Vollbildmodus – /claude-api upgrade hinzugefügt, um Python-Projekte von anthropic 0.x auf 1.x zu migrieren, und die Python-Referenz des Skills für 1.x aktualisiert (Timeouts verwenden anthropic.Timeout, nicht httpx.Timeout)
  • Cloud-Sitzungen: Von claude.ai synchronisierte Plugins werden jetzt als name@synced angezeigt, funktionieren mit claude plugin enable/disable <name>@synced und überschreiben niemals ein gleichnamiges Plugin, das Sie installiert haben
  • Alpine/Musl-Builds: native Bildeinfügung, clipboard und Audio-Capture-Add-Ons werden jetzt geladen (Musl-erstellte Binärdateien anstelle von Glibc-Binärdateien, die von der Laufzeit abgelehnt werden)
  • Die Meldung zum Nutzungslimit, die angezeigt wird, wenn Ihr monatliches Ausgabenlimit bereits aufgebraucht ist, zeigt jetzt auch an, wann Ihr Sitzungs- oder Wochenlimit zurückgesetzt wird – Das Bedrock-Streaming hinter Proxys wurde behoben, das den Content-Type-Header der Antwort entfernte, wodurch die in Rechnung gestellten API-Aufrufe stillschweigend verdoppelt wurden, indem jede Runde ohne Streaming erneut ausgeführt wurde – Problem behoben, bei dem Claude Code beim Start hinter einem HTTPS-Proxy hängen blieb, wenn Bedrock mit einem SSO-Profil und awsAuthRefresh verwendet wurde – die Vorprüfung der Anmeldeinformationen berücksichtigt jetzt HTTPS_PROXY – Ein roher Absturzspeicherauszug beim Starten von Claude Code aus einem Verzeichnis behoben, das nicht mehr existiert; es gibt jetzt eine klare Nachricht aus – Problem behoben, bei dem Bearbeitungs- und Schreibaufrufe in JetBrains-IDE-Terminals für etwa 5 Sekunden pausierten, wenn das Claude Code-Plugin verbunden war
  • Es wurde ein Rennen behoben, bei dem das Drücken von Esc bei in der Warteschlange befindlicher Eingabeaufforderung dazu führen konnte, dass die nächste Runde vorzeitig beendet wurde, die Sitzung im Leerlauf blieb, während Claude noch arbeitete, und ein späterer Spieler Wiederholungsaktionen durchführen konnte – Problem behoben, bei dem WebFetch abgelaufene Seiteninhalte für die gesamte Sitzung im Speicher behielt, statt für die vorgesehenen 15 Minuten – Problem behoben, bei dem Cloud-Sitzungen (Claude Code im Web, auf dem Desktop und in mobilen Apps) nach einem Neustart eines inaktiven Mitarbeiters außerhalb des Planmodus wieder aufgenommen wurden
  • Problem behoben, bei dem MCP-Ermittlungsformulare höher waren als das Terminal, das im Vollbildmodus clipped wurde: Das Formular passt jetzt ins Fenster, wobei versteckte Felder durch Scrollen erreichbar sind und Accept/Decline immer sichtbar sind – Problem behoben, bei dem Remote-MCP-Server nach einem vorübergehenden 5xx bei einer Wiederverbindung mitten in der Sitzung in Cloud-Sitzungen oder über SDK setMcpServers() ausfielen – Behoben, dass benutzerdefinierte Sitzungstitel aus /resume verschwanden, nachdem nach der Umbenennung mehr als ~64 KB Konversation geschrieben wurden – Problem behoben, bei dem claude -c/resume Sitzungen aus einem anderen Verzeichnis abholte, dessen Pfad sich nur durch Zeichen wie _, - oder . unterschied – Behoben: /resume und die Agentenansicht zeigten eine Sitzung als kürzlich geändert an (und ordneten sie neu), wenn nur ihre Datei berührt oder sie lediglich erneut geöffnet wurde
  • /resume im Modus „Alle Projekte“ behoben, der Sie dazu aufforderte, cd in ein gelöschtes Verzeichnis (z. B. einen entfernten Arbeitsbaum) zu verschieben; Solche Sitzungen werden nun im aktuellen Verzeichnis fortgesetzt – Das dark-ansi-Theme-Rendering-Ergebnis des erweiterten Tools im Vollbildmodus mit Text in der gleichen Farbe wie der Hintergrund wurde behoben – Das Problem wurde behoben, bei dem die Vollbild-Renderer-Eingabeaufforderung bei jedem Start erneut angezeigt wurde, wenn sie nie beantwortet werden konnte. Es stoppt nun, nachdem es bei drei Starts angezeigt wurde – Behoben, dass .worktreeinclude-Muster, die mit **/ begannen, stillschweigend mit nichts übereinstimmten, wenn sich das Ziel in einem gitignored-Verzeichnis befand – Problem behoben, bei dem Agenten, Fertigkeiten und Befehle, deren .md-Datei mit einer UTF-8-Stückliste beginnt, stillschweigend ignoriert wurden – Problem behoben, bei dem /insights bei einigen Modellen literale <message>-Tags in seiner Antwort wiedergab – Problem behoben, bei dem der Marktplatz metadata.pluginRoot keine Auswirkung hatte: Quellnamen bloßer Plugins werden jetzt darunter aufgelöst, wie in den Dokumenten beschrieben – Problem mit der Mausbewegung in browserbasierten Terminals, bei der Text wie „"35;150;7M"“ in die Eingabeaufforderung eingefügt wurde, wenn ein Mausbericht über mehrere Schreibvorgänge verteilt eintraf, wurde behoben – Behoben, dass benutzerdefinierte Designüberschreibungen für die Farben des Aufwands-/Ultracode-Statusabzeichens ignoriert wurden
  • OpenTelemetry-Trace-Fragmentierung behoben: Werkzeugausführungen, die durch einen PreToolUse-Hook verzögert wurden, werden jetzt im Trace des ursprünglichen Turns fortgesetzt, anstatt einen neuen Trace zu starten
  • Vim-Modus in der Agentenansicht behoben: Escape wechselt jetzt in den NORMAL-Modus und behält Ihren Text bei, anstatt die Eingabeaufforderung zu löschen – Die selection:copy-Tastenkombination hat dazu geführt, dass eine Textauswahl, die mit Umschalt+Pfeiltasten erweitert wurde, stillschweigend gelöscht wurde – Der Starthinweis für /voice wurde behoben, der immer noch angezeigt wurde, nachdem das Sprachdiktieren über die voice.enabled-Einstellung aktiviert wurde – Problem behoben, bei dem die Tab-Vervollständigung im Shell-Modus (!) den ./ aus einem ./script-Pfad entfernte, wodurch ein Befehl zurückblieb, den die Shell nicht ausführen konnte – Problem behoben, bei dem der Vollbildmodus auf eine Berechtigungsaufforderung reagierte oder eine Taste drückte, wenn man das Terminalfenster cliklickte, nur um es wieder in den Fokus zu bringen
  • Slash-Befehlsfelder (z. B. /config, /model) im Vollbildmodus korrigiert, die die neuesten Nachrichten abdecken; Die Konversation bleibt jetzt über dem Panel angeheftet – Der Detaildialog von /workflows wurde behoben, der das Terminal überfüllte und seinen Header außerhalb des Bildschirms verlor, wenn er geöffnet wurde, während Claude noch antwortet – Behoben, dass die Linux-Sandbox einen nicht vorhandenen .git/config.worktree unlesbar machte, wodurch jeder Sandbox-Git-Befehl in Repos mit festgelegtem extensions.worktreeConfig kaputt ging – Fehler behoben, bei dem Hooks mit „posix_spawn ENOENT“ fehlschlugen, nachdem das Arbeitsverzeichnis der Sitzung gelöscht wurde; Sie werden jetzt stattdessen vom Stammverzeichnis oder Home-Verzeichnis des Projekts ausgeführt – Problem behoben, bei dem claudeMdExcludes eine symbolisch verknüpfte .claude/rules-Datei nicht ausschloss, wenn das Muster das Regelverzeichnis oder den symbolischen Link anstelle seines Ziels benennt – Die außer Kontrolle geratene Sitzungstitelsynchronisierung mit der Fernsteuerung wurde behoben, wenn zwei Claude Code-Prozesse den Status eines Hintergrundjobs teilten (2.1.232-Regression); Titelaktualisierungen sind jetzt dedupliziert und ratenbegrenzt – Behoben: Sitzungen, deren Titel mit / beginnt, konnten von SendMessage nicht adressiert werden und wurden in ListAgents als „(ohne Titel)“ angezeigt – Behoben: Strg+W, Strg+U, Strg+K, Option+Rücktaste, Option+D und vim df/dt hinterließen einen defekten [Pasted text #N]-Platzhalter, wenn sich der Cursor darin befand
  • Maskierte (passwortartige) Eingaben wie das Login-Code-Feld wurden behoben, sodass deren Text mit Strg+Y an anderer Stelle wieder eingefügt oder im Eingabeaufforderungsverlauf gespeichert werden konnte, wenn er mit doppelter Esc gelöscht wurde – Problem behoben, bei dem Strg+Rücktaste ein Zeichen statt eines Wortes in Suchfeldern löschte – Es wurde ein Problem behoben, bei dem eine durch eine Organisationsrichtlinienprüfung abgelehnte Anfrage erneut gesendet wurde, bevor die Ablehnung angezeigt wurde – Die nach der Komprimierung angezeigte Erinnerung wurde verbessert, sodass die ursprünglichen Argumente eines Skills nicht als neue Anfrage erneut ausgeführt werden
  • Lange Dateipfade in Werkzeugzeilen werden jetzt in der Mitte abgeschnitten, um in einer Zeile zu bleiben – Remote-Sitzungen senden weiterhin Keep-Alives, während ein langer SessionStart- oder Setup-Hook ausgeführt wird, sodass der Container während des Hooks nicht im Leerlauf geerntet wird
  • /goal: Wiederholte Check-ins bei Hintergrundarbeiten mit langer Laufzeit werden jetzt unterbrochen (30 Minuten, dann 1 Stunde, dann alle 2 Stunden), anstatt sie alle 30 Minuten zu wiederholen
  • /goal: Das Fortsetzen einer Sitzung über die claude --resume-Auswahl stellt jetzt ihr aktives Ziel wieder her – ListAgents teilt einer Sitzung jetzt ihren eigenen Namen mit (den, den Peers verwenden, um ihr Nachrichten zu senden), und SendMessage sagt dies zu Ihrem eigenen Namen anstelle von „Kein Agent namens …“.
  • ListAgents und /list-agents listen jetzt Ihre Live-Teamkollegen auf (zuvor wurden nur Subagenten und andere Sitzungen angezeigt, sodass ein erreichbarer Teamkollege abwesend schien). – keybindingFlavor: "readline" stimmt jetzt auch mit Bash für Wortschlüssel überein: Alt+F und Strg/Wahl+→ stoppen am Ende des Wortes, Alt+D löscht es (Strg+Y fügt es wieder ein) und Satzzeichen trennt Wörter – Der permanente Wiederholungsmodus (CLAUDE_CODE_RETRY_WATCHDOG) schlägt jetzt sofort fehl, wenn Fehler bezüglich des Ausgabenlimits der Organisation oder bei fehlendem Guthaben auftreten, anstatt auf unbestimmte Zeit auf eine Zurücksetzung zu warten
  • Claude in Chrome: /clear schließt jetzt die Chrome-Tab-Gruppe der Sitzung und leere Gruppen werden bei /resume und beim Beenden von Claude Code geschlossen
  • Remote-Sitzungen: Vom Mobilgerät hochgeladene Bilder enthalten jetzt ihren gespeicherten Dateipfad, sodass Claude sie in die von ihm erstellten Dateien kopieren kann
  • Claude Code im Web: Anfragen von Bash und anderen Tools an Nicht-API-Hosts von anthropic.com (z. B. www, docs) laufen jetzt über den Netzwerk-Proxy der Sitzung, sodass die zulässigen Domänen Ihrer Umgebung gelten
  • Fernbedienung: Klarere Meldung und claude doctor-Wortlaut, wenn die Fernbedienung für Ihr Konto nicht aktiviert ist
  • Windows: Sitzungsübergreifendes Messaging ist jetzt verfügbar, sodass Claude Code-Sitzungen auf Ihren Computern sich gegenseitig mit SendMessage Nachrichten senden und sich mit ListAgents finden können, wie unter macOS und Linux – [VSCode] „Nutzung anzeigen“ im Nutzungslimit-Banner befindet sich jetzt inline mit dem Warntext statt schwebend in der Mitte des Banners

Englisches Original / English original

claude-code v2.1.239

What's changed

  • Cost estimates (/cost, status line, --max-budget-usd) now include the 1.1× US-only-inference premium for data-residency workspaces
  • Added the one-time fullscreen renderer offer on Bedrock, Vertex, Foundry and other previously excluded setups; new installs there now start in fullscreen
  • Added /claude-api upgrade to migrate Python projects from anthropic 0.x to 1.x, and updated the skill's Python reference for 1.x (timeouts use anthropic.Timeout, not httpx.Timeout)
  • Cloud sessions: plugins synced from claude.ai now show as name@synced, work with claude plugin enable/disable <name>@synced, and never override a same-named plugin you installed
  • Alpine/musl builds: native image paste, clipboard, and audio-capture add-ons now load (musl-built binaries instead of glibc ones refused by the runtime)
  • The usage-limit message shown when your monthly spend limit is already used up now also says when your session or weekly limit resets
  • Fixed Bedrock streaming behind proxies that strip the response Content-Type header, which silently doubled billed API calls by re-running every turn non-streaming
  • Fixed Claude Code hanging at startup behind an HTTPS proxy when using Bedrock with an SSO profile and awsAuthRefresh — the credential pre-check now honors HTTPS_PROXY
  • Fixed a raw crash dump when starting Claude Code from a directory that no longer exists; it now prints a clear message
  • Fixed Edit and Write calls pausing for about 5 seconds in JetBrains IDE terminals when the Claude Code plugin is connected
  • Fixed a race where pressing Esc with a prompt queued could let the next turn finish early, leaving the session idle while Claude was still working and letting a later resubmit repeat actions
  • Fixed WebFetch retaining expired page content in memory for the whole session instead of the intended 15 minutes
  • Fixed cloud sessions (Claude Code on the web, desktop and mobile apps) resuming out of plan mode after an idle worker restart
  • Fixed MCP elicitation forms taller than the terminal being clipped in fullscreen mode: the form now fits the window, with hidden fields reachable by scrolling and Accept/Decline always visible
  • Fixed remote MCP servers staying failed after a transient 5xx on a mid-session reconnect in cloud sessions or via SDK setMcpServers()
  • Fixed custom session titles disappearing from /resume after more than ~64 KB of conversation was written following the rename
  • Fixed claude -c/resume picking up sessions from a different directory whose path differed only by characters like _, -, or .
  • Fixed /resume and the agents view showing a session as recently changed (and reordering it) when only its file was touched or it was merely reopened
  • Fixed /resume in all-projects mode telling you to cd into a deleted directory (e.g. a removed worktree); such sessions now resume in the current directory
  • Fixed the dark-ansi theme rendering expanded tool results in fullscreen mode with text the same color as the background
  • Fixed the fullscreen renderer prompt reappearing on every launch when it could never be answered; it now stops after being shown on three launches
  • Fixed .worktreeinclude patterns starting with **/ silently matching nothing when the target lived in a gitignored directory
  • Fixed agents, skills, and commands whose .md file starts with a UTF-8 BOM being silently ignored
  • Fixed /insights echoing literal <message> tags in its response on some models
  • Fixed marketplace metadata.pluginRoot having no effect: bare plugin source names now resolve under it as the docs describe
  • Fixed mouse movement in browser-based terminals inserting text like "35;150;7M" into the prompt when a mouse report arrived split across writes
  • Fixed custom theme overrides for the effort/ultracode status badge colors being ignored
  • Fixed OpenTelemetry trace fragmentation: tool executions deferred by a PreToolUse hook now resume in the original turn's trace instead of starting a new trace
  • Fixed vim mode in the agent view: Escape now switches to NORMAL mode and keeps your text instead of clearing the prompt
  • Fixed the selection:copy keybinding silently dropping a text selection that had been extended with Shift+Arrow keys
  • Fixed the /voice startup tip still appearing after voice dictation was enabled via the voice.enabled setting
  • Fixed shell-mode (!) Tab completion dropping the ./ from a ./script path, which left a command the shell couldn't run
  • Fixed fullscreen mode answering a permission prompt or pressing a button when you clicked the terminal window only to bring it back into focus
  • Fixed slash-command panels (e.g. /config, /model) in fullscreen mode covering the latest messages; the conversation now stays pinned above the panel
  • Fixed the /workflows detail dialog overflowing the terminal and losing its header off-screen when opened while Claude is still responding
  • Fixed the Linux sandbox making a nonexistent .git/config.worktree unreadable, which broke every sandboxed git command in repos with extensions.worktreeConfig set
  • Fixed hooks failing with "posix_spawn ENOENT" after the session's working directory was deleted; they now run from the project root or home directory instead
  • Fixed claudeMdExcludes not excluding a symlinked .claude/rules file when the pattern names the rules directory or the symlink rather than its target
  • Fixed runaway session-title syncing to Remote Control when two Claude Code processes shared one background job's state (2.1.232 regression); title updates are now deduplicated and rate-limited
  • Fixed sessions whose title starts with / being unaddressable by SendMessage and shown as "(untitled)" in ListAgents
  • Fixed Ctrl+W, Ctrl+U, Ctrl+K, Option+Backspace, Option+D and vim df/dt leaving a broken [Pasted text #N] placeholder when the cursor was inside it
  • Fixed masked (password-style) inputs such as the login code field letting their text be pasted back with Ctrl+Y elsewhere or saved to prompt history when cleared with double Esc
  • Fixed Ctrl+Backspace deleting one character instead of a word in search boxes
  • Fixed a request rejected by an organization policy check being re-sent before the rejection was shown
  • Improved the reminder shown after compaction so a skill's original arguments are not re-run as a new request
  • Long file paths on tool-use rows now truncate in the middle to stay on one line
  • Remote sessions keep sending keep-alives while a long SessionStart or Setup hook runs, so the container is not idle-reaped mid-hook
  • /goal: repeat check-ins on long-running background work now back off (30 min, then 1 h, then every 2 h) instead of repeating every 30 minutes
  • /goal: resuming a session from the claude --resume picker now restores its active goal
  • ListAgents now tells a session its own name (the one peers use to message it), and SendMessage to your own name says so instead of "no agent named …"
  • ListAgents and /list-agents now list your live teammates (previously only subagents and other sessions appeared, so a reachable teammate looked absent)
  • keybindingFlavor: "readline" now also matches Bash for word keys: Alt+F and Ctrl/Option+→ stop at the end of the word, Alt+D deletes to it (Ctrl+Y pastes it back), and punctuation separates words
  • Persistent retry mode (CLAUDE_CODE_RETRY_WATCHDOG) now fails immediately on organization spend-limit and out-of-credits errors instead of waiting indefinitely for a reset
  • Claude in Chrome: /clear now closes the session's Chrome tab group, and empty groups are closed on /resume and when Claude Code exits
  • Remote sessions: images uploaded from mobile now include their saved file path, so Claude can copy them into files it creates
  • Claude Code on the web: requests from Bash and other tools to non-API anthropic.com hosts (e.g. www, docs) now go through the session's network proxy, so your environment's allowed domains apply
  • Remote Control: clearer message and claude doctor wording when Remote Control isn't enabled for your account
  • Windows: cross-session messaging is now available, so Claude Code sessions across your machines can message each other with SendMessage and find each other with ListAgents, as on macOS and Linux
  • [VSCode] "View usage" in the usage-limit banner now sits inline with the warning text instead of floating mid-banner
