claude-code v2.1.236

Patch Veröffentlicht19. Aug. 2026 Quelleanthropics/claude-code Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Claude-Code v2.1.236

Was hat sich geändert?

– Umgebungsvariable ANTHROPIC_DEFAULT_MODEL hinzugefügt: Legt das Modell fest, mit dem neue Sitzungen beginnen, während eine /model-Auswahl es immer noch überschreibt und über Neustarts hinweg bestehen bleibt (im Gegensatz zu ANTHROPIC_MODEL) – notify_when_idle zum sitzungsübergreifenden SendMessage hinzugefügt: Bitten Sie eine andere Claude Code-Sitzung auf diesem Computer, eine Benachrichtigung zu senden, wenn er das nächste Mal inaktiv geht – Opt-in, One-Shot, keine Abfrage (macOS und Linux)

  • Sandbox: Unter macOS haben Wildcard-Leseverweigerungsregeln (z. B. **/.env) jetzt innerhalb zulässiger Lesebereiche Vorrang, decken übereinstimmende Verzeichnisinhalte ab und können nicht durch Umbenennen der verweigerten Datei umgangen werden – Behoben: clipboard-Kopie, Hintergrundverwaltung, Hintergrundsitzungen und lokale MCP-Protokolle, die nach dem Entfernen des Verzeichnisses, in das eine Sitzung gewechselt hatte, unterbrochen wurden (seit 2.1.229) – Es wurde behoben, dass der Vollbild-Renderer nach einem einzigen fehlgeschlagenen Start dauerhaft fehlschlug: Er greift jetzt auf den klassischen Renderer zurück, anstatt ihn bei jedem weiteren Start zu beenden
  • Problem behoben, bei dem der /model-Picker höher dargestellt wurde als das Terminal: Es werden jetzt nur so viele Modelle angezeigt, wie in das Fenster passen, während der Rest durch Scrollen erreichbar ist – Problem behoben, bei dem SendMessage-Aufrufe abgelehnt wurden, wenn ein fehlerhaftes schließendes Tag den Nachrichtentext im Zusammenfassungsfeld hinterließ – Unbehandelte Versprechenablehnungen behoben, wenn ein Unterprozess nicht gestartet werden konnte, zum Beispiel powershell.exe auf WSL mit deaktiviertem Windows-Interop (Regression in 2.1.234) – Problem behoben, bei dem im Vollbildmodus manchmal eine neu gesendete Nachricht erst beim nächsten Update angezeigt wurde, nachdem die Größe des Terminals geändert wurde – Es wurde ein leeres Band behoben, das über der Eingabeaufforderung verbleiben konnte, nachdem eine mehrzeilige Eingabeaufforderung gelöscht wurde, und es wurde behoben, dass Bereiche nach der Größenänderung des Terminals im Vollbildmodus nicht neu gezeichnet wurden – Es wurde behoben, dass die Aufforderung zur Genehmigung verwalteter Einstellungen beim Start manchmal nicht angezeigt wurde, obwohl der erste Tastendruck dennoch als Genehmigung erfasst wurde
  • Das Springen von Terminal-Tab-Titeln in tmux wurde behoben (iTerm tmux-Integration): Der Titel wird jetzt nur geschrieben, wenn sich sein Text ändert, anstatt alle 960 ms animiert zu werden – Es wurde ein unklarer Fehler behoben, der dazu führte, dass die Liste der Cloud-Umgebungen leer oder fehlerhaft war – Problem behoben, bei dem bei der ersten Nutzung von Fable 5 bei Verwendung der Fernbedienung automatisch das Ersatzmodell ausgewählt wurde, nachdem 60 Sekunden lang keine Antwort erfolgte – Problem behoben, bei dem Spinner-Tipps nie angezeigt wurden und ein wiederholter Hintergrundfehler auftrat, wenn die zwischengespeicherte Gastpass-Belohnung in ~/.claude.json fehlerhaft war
  • Problem behoben, bei dem das Hot-Reload von Fertigkeiten in SDK/VS-Code-Sitzungen bei jeder Fertigkeitsänderung einen Fehler auslöste, nachdem das Arbeitsverzeichnis der Sitzung gelöscht wurde (2.1.229+) – Problem behoben, bei dem selbst gehostete Runner-Sitzungen, die bei Zeitüberschreitung im Leerlauf, im Ruhestand oder beim Start freigegeben wurden, gelegentlich auf einem anderen Runner fortgesetzt wurden, bevor der Post-Session-Hook beendet war – Die Augen und Füße des Clawd-Maskottchens wurden in iTerm2 bei manchen Schriftgrößen ungleichmäßig dargestellt
  • Gelegentliche außer Kontrolle geratene Sitzungsrückblicke wurden behoben: Der Zusammenfassungstext (automatisch und /recap) ist jetzt auf 400 Zeichen begrenzt und an einer Wortgrenze abgeschnitten
  • Verbesserte Startleistung: Der Sitzungszähler wird jetzt im Hintergrund geschrieben
  • Verbesserter Auto-Modus: Monitor-Zulassungsregeln werden jetzt beiseite gelegt, während der Auto-Modus aktiv ist, sodass Monitor-Befehle genauso überprüft werden wie Bash-Befehle
  • Verbesserter automatischer Modus bei Bedrock, Vertex AI und Foundry und bei deaktivierter Telemetrie: Der Klassifikator verwendet jetzt dieselben Standardeinstellungen wie beim Claude API, einschließlich der nach Schweregrad bewerteten Klassifizierung
  • Verbesserter automatischer Modus: Die Git-Statusprüfung kann nicht mehr durch die status.showUntrackedFiles=no-Einstellung eines Repos dazu verleitet werden, einen sauberen Baum zu melden – Die /model-Auswahl wurde geändert, um nur den Namen des neuesten Modells hervorzuheben, sodass die Hervorhebung die neue Version markiert und nicht eine beliebige Teilmenge der Liste
  • /goal: Eine inaktive Sitzung, deren Ziel hinter lang laufender Hintergrundarbeit geparkt ist, wird jetzt automatisch nach 30 Minuten (dann 1 Stunde, 2 Stunden) eingecheckt, anstatt auf Ihre Rückkehr zu warten – /usage zeigt jetzt die Zeile „Nutzungsguthaben-Ausgaben“ für Team- und Enterprise-Mitglieder an und zeigt eine begrenzte Zeile bei 0 %, bevor etwas ausgegeben wird
  • SIGTERM zeichnet im Druck-/SDK-Modus vor dem Verlassen keine unterbrochene Kurve oder synthetische Werkzeugverweigerungen mehr auf; laufende Befehle werden weiterhin beendet und der Prozess wird weiterhin mit Code 143 beendet
  • Das Drücken der Eingabetaste bei einem Schrägstrich-Befehls-Tippfehler oder einem Befehl, der in dieser Sitzung nicht verfügbar ist, meldet dies jetzt, anstatt den nächsten Fuzzy-Match auszuführen; Präfixe und Aliase werden weiterhin ausgeführt
  • Remote Control markiert jetzt eine Sitzung innerhalb von Sekunden als offline, wenn der CLI beendet oder sein Terminal geschlossen wird – SendMessage lehnt jetzt weitere Nachrichten an eine Sitzung im Voraus ab, wenn ein rapid-Burst die vom Posteingang dieser Sitzung akzeptierten Werte überschreiten würde, anstatt sie als gesendet zu melden, während sie gelöscht wurden – Der Sitzungstitelchip am Eingabeaufforderungsrand wurde am rechten Rand der Fußzeile ausgerichtet
  • Rechtsbündige Fußzeilenelemente (Zielanzeige, Sitzungsstatus, Status des Hintergrundagenten) und abgeschnittene Hinweise haben jetzt einen einheitlichen rechten Rand mit dem Rest des Eingabeaufforderungsbereichs
  • [VSCode] Screenreader-Unterstützung für das Transkript hinzugefügt: Live-Ankündigungen für Antworten, Berechtigungsanfragen, Fehler und Statusänderungen sowie Überschriftennavigation pro Runde

Englisches Original / English original

claude-code v2.1.236

What's changed

  • Added ANTHROPIC_DEFAULT_MODEL environment variable: sets the model new sessions start on, while a /model pick still overrides it and persists across restarts (unlike ANTHROPIC_MODEL)
  • Added notify_when_idle to cross-session SendMessage: ask another Claude Code session on this machine to send one notice when it next goes idle — opt-in, one-shot, no polling (macOS and Linux)
  • Sandbox: on macOS, wildcard read-deny rules (e.g. **/.env) now take precedence inside allowed read regions, cover matched directories' contents, and can't be bypassed by renaming the denied file
  • Fixed clipboard copy, background housekeeping, background sessions, and local MCP logs breaking after the directory a session had switched into was removed (since 2.1.229)
  • Fixed the fullscreen renderer failing permanently after a single failed start: it now falls back to the classic renderer instead of exiting on every subsequent launch
  • Fixed the /model picker rendering taller than the terminal: it now shows only as many models as fit the window, with the rest reachable by scrolling
  • Fixed SendMessage calls being rejected when a malformed closing tag left the message text inside the summary field
  • Fixed unhandled promise rejections when a subprocess fails to start, for example powershell.exe on WSL with Windows interop disabled (regression in 2.1.234)
  • Fixed fullscreen mode sometimes not showing a newly sent message until the next update after the terminal was resized
  • Fixed a blank band that could remain above the prompt after clearing a multi-line prompt, and panes not repainting after resizing the terminal away and back, in fullscreen mode
  • Fixed the managed-settings approval prompt sometimes not appearing at startup while still capturing the first keypress as approval
  • Fixed terminal tab titles jumping in tmux (iTerm tmux integration): the title is now written only when its text changes instead of animating every 960ms
  • Fixed an unclear error when the cloud environments list came back empty or malformed
  • Fixed the Fable 5 first-time usage-credits prompt auto-selecting the fallback model after 60 seconds with no answer when using Remote Control
  • Fixed spinner tips never appearing, with a repeated background error, when the cached guest-pass reward in ~/.claude.json was malformed
  • Fixed skills hot-reload in SDK/VS Code sessions raising an error on every skills change after the session's working directory was deleted (2.1.229+)
  • Fixed self-hosted runner sessions released on idle, retire, or startup timeout occasionally resuming on another runner before the post-session hook had finished
  • Fixed the Clawd mascot's eyes and feet rendering unevenly in iTerm2 at some font sizes
  • Fixed occasional runaway session recaps: recap text (automatic and /recap) is now capped at 400 characters, cut at a word boundary
  • Improved startup performance: the session counter is now written in the background
  • Improved auto mode: Monitor allow rules are now set aside while auto mode is active, so Monitor commands are reviewed the same way Bash commands are
  • Improved auto mode on Bedrock, Vertex AI, and Foundry, and when telemetry is disabled: the classifier now uses the same defaults as on the Claude API, including severity-scored classification
  • Improved auto mode: the git status check can no longer be fooled by a repo's status.showUntrackedFiles=no setting into reporting a clean tree
  • Changed the /model picker to highlight only the newest model's name, so the highlight marks the new release rather than an arbitrary subset of the list
  • /goal: an idle session whose goal is parked behind long-running background work now checks in automatically after 30 minutes (then 1h, 2h) instead of waiting for you to return
  • /usage now shows the usage-credits spend row for Team and Enterprise members, and shows a capped row at 0% before anything is spent
  • SIGTERM in print/SDK mode no longer records an interrupted turn or synthetic tool denials before exiting; running commands are still terminated and the process still exits with code 143
  • Pressing Enter on a slash-command typo or a command unavailable in this session now reports it instead of running the closest fuzzy match; prefixes and aliases still run
  • Remote Control now marks a session offline within seconds when the CLI exits or its terminal closes
  • SendMessage now refuses further messages to a session up front once a rapid burst would exceed what that session's inbox accepts, instead of reporting them sent while they were dropped
  • Aligned the session title chip on the prompt border with the footer's right edge
  • Right-aligned footer items (goal indicator, session state, background agent status) and truncated notices now share a consistent right margin with the rest of the prompt area
  • [VSCode] Added screen reader support for the transcript: live announcements for replies, permission requests, errors, and status changes, plus per-turn heading navigation
