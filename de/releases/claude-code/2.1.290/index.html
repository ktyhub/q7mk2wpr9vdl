Claude-Code v2.1.290

Was hat sich geändert?

  • serverToolUses zum Ergebnis des turn.step-Hooks eines Mods hinzugefügt: Das Tool ruft den API-Lauf selbst auf (den Advisor), jeweils mit seiner ID, seinem Namen, seiner Eingabe, seinem Start und seinem Ende – agentId zum tool.check-Ereignis von Plugin-Hooks hinzugefügt, sodass ein Hook die Berechtigungsprüfung eines Subagenten von der der Hauptsitzung unterscheiden kann
  • ceiling zur Frage und zum Urteil hinzugefügt. Der tool.check-Hook eines Mods lautet und benennt die Genehmigung, die eine Organisation für ein Tool benötigt
  • Die Typen ThemeKey und Color wurden zu den Plugin-Hooks-Typisierungen hinzugefügt, sodass ein Editor die Themenfarben auflistet, die die Zeichnung eines Mods benennen kann
  • Zu claude plugin validate hinzugefügt: Jeder Hook, den ein Mod an einer Gating-Site registriert, wird aufgelistet, ob er einen .catch hat (gatingHooks unter --json) – Der Anmeldegenehmigungsseite des Claude-Apps-Gateways wurde eine Schaltfläche „Verweigern“ hinzugefügt: Sie beendet die ausstehende Anmeldung, sodass das wartende Terminal innerhalb von Sekunden stoppt
  • claude attach <name> und claude logs <name> hinzugefügt: Ein Teil eines Sitzungsnamens funktioniert anstelle der ID – /claude-api managed-agents-onboard <url> hinzugefügt, um das Managed Agents-Muster einzurichten, das eine Seite als ant apply-Dateien beschreibt – /claude-api managed-agents-onboard <quickstart-name> hinzugefügt, um eine Konsolen-Schnellstartvorlage wie deep-researcher mit dem ant CLI zu erstellen – Es wurde eine Warnung hinzugefügt, wenn eine Datei mit verwalteten Einstellungen ein Link zu einer Datei außerhalb des Ordners mit verwalteten Einstellungen ist – Eine /status- und eine Doctor-Warnung hinzugefügt, wenn verwaltete Einstellungen vom Benutzer konfigurierte Sandbox-AllowRead-Pfade oder zugelassene Domänen ignorieren – Es wurde ein Problem behoben, bei dem Anfragen hinter Proxys und Gateways fehlschlugen, die einen der Beta-Header von Claude Code mit einem anderen Status als 400 oder zusammen mit einer zweiten Beta ablehnten – Es wurde ein Problem behoben, bei dem lange Sitzungen mit Hunderten von Bildern aufgrund der Fehlermeldung „Anfrage vom Modell als nicht verarbeitbar abgelehnt“ hängen blieben
