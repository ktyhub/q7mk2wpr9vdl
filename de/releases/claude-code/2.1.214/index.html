Claude-Code v2.1.214

Was hat sich geändert?

– Fehler behoben, bei dem Einzelsegment-dir/**-Regeln wie Edit(src/**) die automatische Genehmigung von Schreibvorgängen in verschachtelte dir/-Verzeichnisse an einer beliebigen Stelle im Baum ermöglichen, anstatt nur in <cwd>/dir – Es wurde eine Umgehung der Berechtigungsprüfung behoben, die sich auf Befehle auswirkte, die in Windows PowerShell 5.1-Sitzungen ausgeführt wurden – Es wurde behoben, dass Bash-Berechtigungsprüfungen bei Dateideskriptor-Umleitungsformularen, die Bash anders analysiert als der Berechtigungsanalysator, fehlschlugen – Behoben, dass Bash-Berechtigungsprüfungen sehr lange Befehle falsch einschätzten – Befehle mit mehr als 10.000 Zeichen werden jetzt immer angezeigt, anstatt automatisch ausgeführt zu werden – Fehler bei Bash-Berechtigungsprüfungen behoben, bei denen ZSH-Variablenindizes und Modifikatoren in [[ ]]-Vergleichen als inaktiver Text behandelt wurden – diese Befehle erfordern jetzt eine Genehmigung – Die Bash-Berechtigungsprüfungen haben dazu geführt, dass bestimmte help- und man-Befehle, die unsichere Optionen, Befehlsersetzungen oder Backslash-Pfade ausführen könnten, nicht mehr automatisch genehmigt wurden – Berechtigungsaufforderungen bei Remote-Sitzungen behoben, die vor dem lokalen Bestätigungsdialog fortgesetzt werden konnten – EndConversation-Tool hinzugefügt: Claude kann Sitzungen mit äußerst missbräuchlichen Benutzern oder Jailbreak-Versuchen beenden, wie auf claude.ai seit 2025 – siehe https://www.anthropic.com/research/end-subset-conversations – Es wurde ein periodischer Fortschritts-Heartbeat für lang andauernde Tool-Aufrufe hinzugefügt, die zuvor stumm blieben – Dem Speicherdatei-Frontmatter wurde ein ISO-modified-Zeitstempel hinzugefügt – Attribute message.uuid, client_request_id und tool_source zu OpenTelemetry-Protokollereignissen für Korrelation auf Nachrichtenebene und Tool-Herkunft hinzugefügt – CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH hinzugefügt, um das 60-KB-Kürzungslimit für OpenTelemetry-Inhaltsattribute zu konfigurieren – Begründungsaufwand zur subagentStatusLine-Nutzlast hinzugefügt, sodass benutzerdefinierte Agentenzeilen Modell und Aufwand rendern können – Berechtigungsaufforderungen für docker-Befehle (einschließlich des Podman docker-Shims) hinzugefügt, die Daemon-Redirect-Flags (--url, --connection, --identity und Podmans Remote-Modus) tragen, die zuvor ohne eines ausgeführt wurden – Es wurde ein Absturz behoben, der auftrat, wenn eine GrowthBook-Funktion als null ausgewertet wurde, sowie ein Fehler, bei dem eine fehlerhafte Flag-Payload die zwischengespeicherten Feature-Flags löschen konnte – Problem behoben, bei dem das Bash-Tool die Claude-Sitzung beendete, wenn ein pkill -f-Muster versehentlich mit dem eigenen Prozess des CLI übereinstimmte (Linux) – Unbegrenztes Speicherwachstum behoben, wenn --settings auf eine Gerätedatei oder eine Multi-GB-Datei zeigt; Übergroße (>2 MiB) Einstellungsdateien schlagen jetzt beim Start mit einem eindeutigen Fehler fehl – Problem behoben, bei dem Streaming-Runden hinter Unternehmens-Proxys unter Windows mit der Meldung „Socket ist geschlossen“ fehlschlugen – Das Abschneiden der Stream-json-Ausgabe beim Beenden für langsam lesende SDK/Pipeline-Konsumenten wurde behoben; Der Exit-Drain skaliert jetzt mit in der Warteschlange befindlichen Bytes statt mit einer flachen 2-Sekunden-Obergrenze – Behoben: Geplante Aufgaben verweigerten ihre eigene konfigurierte Eingabeaufforderung als untrusted-Eingabe – die ausgelöste Eingabeaufforderung wird jetzt als der Sitzung zugewiesene Aufgabe übermittelt – Behoben, dass Befehle des PowerShell-Tools bis zum Timeout hängen blieben, wenn ein untergeordneter Prozess auf die Standardeingabe wartete (Windows) – Behoben: Python-Skripte unter dem PowerShell-Tool stürzten mit UnicodeDecodeError ab, wenn Nicht-UTF-8-Daten aus der Standardeingabe gelesen wurden (Windows) – Problem behoben, bei dem Python-Skripte, die über das PowerShell-Tool ausgeführt wurden, mit UnicodeEncodeError bei Nicht-ASCII-Ausgaben abstürzten und PowerShell 7-Fehlermeldungen mit rohen ANSI-Escape-Sequenzen (Windows) auftraten. – Problem behoben, bei dem das PowerShell-Tool where.exe, fc.exe und diff.exe als Fehler meldete, wenn sie eine gültige negative Antwort zurückgaben (Windows) – Behoben: > und >> unter dem PowerShell-Tool unter Windows PowerShell 5.1, das UTF-16LE-Dateien schreibt, die andere Tools nicht als UTF-8 lesen konnten – Ein verschobener Hintergrunddämon wurde behoben, der beim Herunterfahren den Steuersockel seines Nachfolgers löschte, was dazu führte, dass der nächste client den fehlerfreien Ersatzdämon beendete – Behoben: Hintergrundsitzungen, die mit ← oder /background geparkt und im Leerlauf gelassen wurden, wodurch der Hintergrunddämon und ein Arbeitsprozess auf unbestimmte Zeit am Leben blieben – Behoben: Abgeschlossene Hintergrundsitzungen konnten nicht über claude rm oder die Agentenansicht entfernt werden, sobald der Hintergrunddienst inaktiv war – Problem behoben, bei dem Hintergrundsitzungen, die aus einem Nicht-Git-Ordner gesendet wurden, nicht aus der Agentenansicht gelöscht werden konnten – Problem behoben, bei dem das erneute Öffnen einer gestoppten Hintergrundsitzung dazu führte, dass die gespeicherte Konversation nicht wiederhergestellt werden konnte, wenn im Sitzungsspeicher ein nicht lesbarer Ordner vorhanden war – Das Auslösen der Remote Control-Push-Benachrichtigung „Sitzung bereit“ für Sitzungen, in denen Remote Control nicht explizit aktiviert war, wurde behoben – Das Blockieren von /install-github-app und dem Einstellungsmenü /mcp in Sitzungen mit Agentenansicht wurde behoben – sie werden jetzt nur in Hintergrundsitzungen ohne angeschlossenes Terminal abgelehnt

  • Problem behoben, bei dem Plugins, die über das Flag --settings CLI aktiviert wurden, nicht geladen wurden (Rückgang seit v2.1.181) – Problem behoben, bei dem Feature-Flags in Sitzungen mit langer Laufzeit veraltet blieben, nachdem das OAuth-Token rotiert wurde – Behoben, dass /ultrareview die Ausführung in Repos ohne Merge-Basis verweigerte – es bietet jetzt die Möglichkeit, alle verfolgten Dateien zu überprüfen – Behoben, dass claude update und claude doctor unbemerkt hängen blieben und der /status-Systemdiagnoseabschnitt leer blieb, wenn ein Shell-Konfigurationspfad ein Verzeichnis ist – Problem behoben, bei dem Speicher-Frontmatter-Werte beim Speichern von Speicherdateien stillschweigend bei einem Inline-# abgeschnitten wurden – Die Doppelzählung von Sitzungskosten und Token-Telemetrie bei Streams, die mehrere kumulative message_delta-Frames ausgeben, wurde behoben – Es wurde eine falsche Warnung „Überprüfen Sie Ihr Netzwerk“ behoben, die angezeigt wurde, während der Berater nachdachte – Behoben, dass Hooks mit Exit-Code 2 nicht blockierten, wie dokumentiert, wenn der stdout JSON des Hooks die Schemavalidierung nicht bestanden hat – Behoben: OTel-Protokollereignisse, die außerhalb des asynchronen Kontexts der Runde ausgegeben wurden, fehlten im Trace-Kontext der Interaktionsspanne – Vorübergehende MCP-Fehler während der Aktualisierung von Eingabeaufforderungen/Ressourcen behoben, wodurch die Slash-Befehle und Ressourcen des Servers gelöscht wurden – Der Fehler „claude rc workspace-trust“ im Home-Verzeichnis wurde dahingehend verbessert, dass trust dort nie gespeichert wird und die Ausführung aus einem Projektverzeichnis vorgeschlagen wird – Die Bedingungen für den dir/**-Hook if: mit einem Segment wurden so geändert, dass sie nur mit <cwd>/dir übereinstimmen. Schreiben Sie **/dir/** für den Abgleich mit beliebiger Tiefe. Die Berechtigungsregeln deny/ask behalten ihre Übereinstimmung mit beliebiger Tiefe bei. – file-Befehle, die -m/--magic-file oder -f/--files-from verwenden, wurden so geändert, dass sie eine Berechtigung erfordern, anstatt automatisch als schreibgeschützt zugelassen zu werden – Das Keep-Alive-Verbindungspooling wurde so geändert, dass es nach einem Fehler aufgrund einer veralteten Verbindung deaktiviert wird, sodass erneut versucht wird, einen neuen Socket zu öffnen – SessionStart-Hooks wurden geändert, um die Quelle "fork" zu melden, wenn eine Sitzung als Fork statt als "resume" beginnt

Englisches Original / English original

claude-code v2.1.214

What's changed

  • Fixed single-segment dir/** allow rules like Edit(src/**) auto-approving writes to nested dir/ directories anywhere in the tree instead of only <cwd>/dir
  • Fixed a permission-check bypass affecting commands run in Windows PowerShell 5.1 sessions
  • Fixed Bash permission checks to fail closed on file-descriptor redirect forms that bash parses differently than the permission analyzer
  • Fixed Bash permission checks misjudging very long commands — commands over 10,000 characters now always prompt instead of running automatically
  • Fixed Bash permission checks treating zsh variable subscripts and modifiers in [[ ]] comparisons as inert text — these commands now prompt for approval
  • Fixed Bash permission checks to no longer auto-approve certain help and man commands that could run unsafe options, command substitutions, or backslash paths
  • Fixed permission prompts on remote sessions that could proceed before the local confirmation dialog
  • Added the EndConversation tool: Claude can end sessions with highly abusive users or jailbreak attempts, as on claude.ai since 2025 — see https://www.anthropic.com/research/end-subset-conversations
  • Added a periodic progress heartbeat for long-running tool calls that previously went silent
  • Added an ISO modified timestamp to memory file frontmatter
  • Added message.uuid, client_request_id, and tool_source attributes to OpenTelemetry log events for message-level correlation and tool provenance
  • Added CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH to configure the 60 KB truncation limit on OpenTelemetry content attributes
  • Added reasoning effort to the subagentStatusLine payload, so custom agent rows can render model and effort
  • Added permission prompts for docker commands (including the Podman docker shim) carrying daemon-redirect flags (--url, --connection, --identity, and Podman's remote mode) that previously ran without one
  • Fixed a crash when a GrowthBook feature evaluates to null, and a bug where a malformed flag payload could wipe the cached feature flags
  • Fixed Bash tool killing the Claude session when a pkill -f pattern accidentally matched the CLI's own process (Linux)
  • Fixed unbounded memory growth when --settings points at a device file or multi-GB file; oversized (>2 MiB) settings files now fail at startup with a clear error
  • Fixed streaming turns failing with "Socket is closed" behind corporate proxies on Windows
  • Fixed stream-json output truncation at exit for slow-reading SDK/pipeline consumers; the exit drain now scales with queued bytes instead of a flat 2s cap
  • Fixed scheduled tasks refusing their own configured prompt as untrusted input — the fired prompt is now delivered as the session's assigned task
  • Fixed PowerShell tool commands hanging until timeout when a child process waited on standard input (Windows)
  • Fixed Python scripts under the PowerShell tool crashing with UnicodeDecodeError when reading non-UTF-8 data from standard input (Windows)
  • Fixed Python scripts run via the PowerShell tool crashing with UnicodeEncodeError on non-ASCII output, and PowerShell 7 error messages containing raw ANSI escape sequences (Windows)
  • Fixed the PowerShell tool reporting where.exe, fc.exe, and diff.exe as errors when they return a valid negative answer (Windows)
  • Fixed > and >> under the PowerShell tool on Windows PowerShell 5.1 writing UTF-16LE files that other tools couldn't read as UTF-8
  • Fixed a displaced background daemon deleting its successor's control socket on shutdown, which made the next client kill the healthy replacement daemon
  • Fixed background sessions parked with ← or /background and left idle keeping the background daemon and a worker process alive indefinitely
  • Fixed completed background sessions being impossible to remove via claude rm or the agent view once the background service had gone idle
  • Fixed background sessions dispatched from a non-git folder being impossible to delete from the agents view
  • Fixed reopening a stopped background session failing to restore its saved conversation when an unreadable folder exists in the session store
  • Fixed the Remote Control "session ready" push notification firing for sessions where Remote Control was not explicitly enabled
  • Fixed /install-github-app and the /mcp settings menu being blocked in agent-view sessions — they're now refused only in background sessions with no terminal attached
  • Fixed plugins enabled via the --settings CLI flag not loading (regression since v2.1.181)
  • Fixed feature flags going stale in long-running sessions after the OAuth token rotates
  • Fixed /ultrareview refusing to run in repos with no merge base — it now offers to review all tracked files
  • Fixed claude update and claude doctor hanging silently, and the /status System diagnostics section going blank, when a shell-config path is a directory
  • Fixed memory frontmatter values being silently truncated at an inline # when memory files are saved
  • Fixed session cost and token telemetry double-counting on streams that emit multiple cumulative message_delta frames
  • Fixed a spurious "check your network" warning that appeared while the advisor was thinking
  • Fixed hooks with exit code 2 not blocking as documented when the hook's stdout JSON fails schema validation
  • Fixed OTel log events emitted outside the turn's async context missing the interaction span's trace context
  • Fixed MCP transient errors during prompts/resources refresh clearing the server's slash commands and resources
  • Improved the claude rc workspace-trust error in the home directory to say trust there is never saved and to suggest running from a project directory
  • Changed single-segment dir/** hook if: conditions to match only <cwd>/dir; write **/dir/** for any-depth matching. deny/ask permission rules keep their any-depth match.
  • Changed file commands using -m/--magic-file or -f/--files-from to require permission instead of being auto-allowed as read-only
  • Changed keep-alive connection pooling to disable after a stale-connection error, so retries open a fresh socket
  • Changed SessionStart hooks to report source "fork" when a session begins as a fork instead of "resume"
