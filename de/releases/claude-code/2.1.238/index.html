Claude-Code v2.1.238

Was hat sich geändert?

– Eine keybindingFlavor-Einstellung hinzugefügt: Setzen Sie sie auf "readline", um Strg+W in der Eingabeaufforderung zum Löschen zurück zum vorherigen Leerzeichen zu bringen, wie in Bash; Der Standardwert ("classic") bleibt unverändert

  • Plugin-Marktplätze: headersHelper führt auf einem URL-Marktplatz oder einem Katalogeintrag einen Befehl aus, der HTTP-Header (z. B. ein kurzlebiges Token) für Katalog- und Archivabrufe gleichen Ursprungs prägt
  • headersHelper eines Katalogeintrags wird nur ausgeführt, wenn Sie dieses Plugin installieren oder aktualisieren, nachdem sein Befehl angezeigt wird; claude plugin install/update fragen Sie [y/N] (oder geben Sie -y)
  • claude self-hosted-runner --defer-shutdown-max-min <minutes> hinzugefügt: Auf SIGTERM weiterhin angehängte Sitzungen bereitstellen, nach so vielen Minuten parken, was noch übrig ist, und dann beenden – claude self-hosted-runner --proxy-authorization-command / --proxy-authorization-file für Ausgangs-Proxys hinzugefügt, die bei jeder Verbindung einen frisch ausgestellten Proxy-Authorization-Header erfordern – Unbegrenztes Speicherwachstum in langen interaktiven Sitzungen behoben: Ergebnisse des Subagenten-Tools werden jetzt freigegeben, sobald sie das aktuelle Anzeigefenster verlassen – Behoben: Benutzerdefinierte, Projekt- und Plugin-Ausgabestile, die während der Sitzung auf die Standardstimme zurückfielen – Problem behoben, bei dem CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=true keine sofortigen Vorschläge bereithielt, wenn Ihr Konto das Nutzungslimit erreicht, aber nicht überschritten hat – Worktree-Isolation Bash weigerte sich, Sie aufzufordern, eine Umleitung zu entfernen, wenn der Befehl keine hatte, behoben – Problem behoben, bei dem selbst gehostete Läufer gelegentlich nach einer einzigen langsamen oder verlorenen Umfrageanfrage vom Server entfernt wurden und ihre fehlerfreie Sitzung an einen anderen Läufer übergeben wurde – Problem behoben, bei dem MCP-Ermittlungsdialoge für URLs mit mehr als 4.096 Zeichen nichts anzeigten, und Berechtigungsaufforderungen, bei denen die Option „Nicht erneut fragen“ entfernt wurde, wenn der Projektpfad nicht in die Terminalbreite passte – Übrig gebliebene /tmp/claude-*-cwd-Dateien behoben, wenn ein Bash-Befehl abgebrochen wird, eine Zeitüberschreitung auftritt oder unterbrochen wird – Problem behoben, bei dem die gedrückte Rücktaste auf Terminals ignoriert wurde, die Strg+H für die Rücktaste senden, wenn Tastenanschläge in großen Mengen eintreffen (langsame SSH-/Mosh-Links).
  • Textumbruch in Berechtigungsaufforderungsunterschieden behoben: Zeilen, die breite Multi-Codepunkt-Zeichen (z. B. Emoji) oder Tabulatoren enthalten, werden nicht mehr mit cli versehen – Problem behoben, bei dem das Abbrechen einer angehaltenen Sitzung (Strg+Z) manchmal dazu führte, dass das Terminal im Einfügemodus in Klammern blieb und der Cursor ausgeblendet war – Problem behoben, bei dem Standard-MCP-Server eine server/discover-Anfrage vor initialize erhielten, was dazu führte, dass Lazy-Server ihr Backend bei jeder geöffneten Sitzung starten mussten – Die Weigerung eines Proxys, eine Verbindung herzustellen, wurde als allgemeiner Netzwerkfehler gemeldet, anstatt den Proxy zu benennen – Die Cache-Fehlerwarnung /model und /effort wurde behoben, die angezeigt wurde, wenn der Prompt-Cache bereits abgelaufen war – Problem behoben, bei dem der Stopp pro Aufgabe im Remote Control-Aufgabenfenster bei von CLI gehosteten Sitzungen nichts bewirkte – Problem behoben, bei dem Remote-Sitzungen beendet wurden, wenn ein client eine Benutzernachricht ohne gültige Rolle zustellte – Problem behoben, bei dem Fernsteuerungssitzungen, die von claude remote-control gestartet wurden, sitzungsbezogene Umgebungsvariablen von der Start-Shell erbten – Es wurde eine Fernsteuerungssitzung behoben, deren Prozess abstürzte und nicht verfügbar blieb, bis claude remote-control neu gestartet wurde. Es kann jetzt wiederverwendet werden, wenn Sie ihm das nächste Mal eine Nachricht senden
  • Problem behoben, bei dem Fernsteuerungsnachrichten, die über das Web oder den Desktop gesendet wurden, während Claude mitten in der Runde war, nach Ende der Runde aus dem Transkript verschwanden
  • Problem behoben, bei der Modellauswahl per Fernsteuerung, die über ein Telefon oder das Internet vorgenommen wurde, das im Terminal angezeigte Modell nicht aktualisierte
  • Problem behoben, bei dem die Fernsteuerung mit der Meldung „Anmeldung abgelaufen“ getrennt wurde, wenn ein kurzer Netzwerkproblem die Erneuerung Ihrer Anmeldung verzögerte; Es versucht nun erneut und bleibt verbunden – Problem behoben, bei dem Remote Control beim Abmelden eine fehlgeschlagene erneute Verbindung meldete; Wenn Sie sich jetzt abmelden, wird die Sitzung mit einer klaren Nachricht beendet – Problem mit der Meldung „Remote Control is not connected“ durch ListAgents/SendMessage in Sitzungen behoben, die von claude remote-control (Servermodus) oder Desktop-/IDE-Hosts ausgeführt werden; Sie listen jetzt Remote Control-Kollegen auf und erreichen sie – Problem behoben, bei dem ListAgents und SendMessage den inaktiven Worker offenlegten, den die Agentenansicht für Ihre nächste Hintergrundsitzung vorwärmt; Es erscheint jetzt nur noch, wenn eine Aufgabe es beansprucht
  • Sitzungsübergreifendes Messaging: Beim Senden an eine Sitzung auf diesem Computer, die eingehende Nachrichten ablehnt (z. B. crossSessionInbound: "refuse"), wird dem Absender jetzt „abgelehnt“ statt als stiller Erfolg gemeldet
  • Sitzungsübergreifendes Versenden von Nachrichten: Eine Sitzung, deren Posteingang Ihre Nachrichten verwirft (Ratenbegrenzung oder volle Warteschlange), informiert jetzt Ihre Sitzung, anstatt dass die Nachrichten stillschweigend verschwinden
  • Verbesserter Start: Bare claude startet unter macOS früher – Verbesserte Berechtigungsprüfung des Bash-Tools für zsh-spezifische Syntax in Shell-Bedingungen
  • Verbesserte Widerstandsfähigkeit der Fernsteuerungsverbindung: Kurze HTTP 403-Ablehnungen von einem Netzwerk-Edge, einem VPN oder einem Proxy werden jetzt bis zu 3 Minuten lang toleriert, wobei die ablehnende Partei benannt wird, wenn eine Blockierung bestehen bleibt
  • Verbesserte Reaktionsfähigkeit beim Start: Die automatische Update-Prüfung wird jetzt etwa 10 Sekunden nach dem Start ausgeführt, anstatt mit dem Start um CPU zu konkurrieren – Der gebündelte claude-api-Skill für die Managed Agents-Version vom 19. August wurde aktualisiert: Websuche/Abruf von Domäneneinstellungen und Speicherspeichern auf selbstgehosteten Sandboxes – Strg+L und Cmd+K im Vollbildmodus so geändert, dass sie immer nur neu gezeichnet werden – die Tastenkombination „/clear“ durch zweimaliges Drücken wurde entfernt und einzeilige nvim-Terminals lösen keine automatischen /clear-Schleifen mehr aus – claude mcp list und claude mcp get wurden geändert, um deaktivierte Server als ⊘ Disabled anzuzeigen, anstatt für eine Gesundheitsprüfung eine Verbindung zu ihnen herzustellen
  • MCP headersHelper in einem Projekt .mcp.json und Inline-MCP-Server in Projekt- oder --add-dir-Agentendateien erfordern jetzt, dass der trust-Dialog dieses Ordners akzeptiert wurde (auch unter claude -p). – MCP headersHelper aus einem Projekt .mcp.json, Plugin oder Agent-Datei wird ohne geerbte Anmeldeinformations-Umgebungsvariablen ausgeführt; Benutzer-, verwaltete und claude.ai-scope-Helfer werden jetzt im Claude-Konfigurationsverzeichnis ausgeführt

Englisches Original / English original

claude-code v2.1.238

What's changed

  • Added a keybindingFlavor setting: set it to "readline" to make Ctrl+W in the prompt delete back to the previous whitespace, as in Bash; the default ("classic") is unchanged
  • Plugin marketplaces: headersHelper on a url marketplace or a catalog entry runs a command that mints HTTP headers (e.g. a short-lived token) for catalog and same-origin archive fetches
  • A catalog entry's headersHelper runs only when you install or update that plugin, after its command is shown; claude plugin install/update ask [y/N] (or pass -y)
  • Added claude self-hosted-runner --defer-shutdown-max-min <minutes>: on SIGTERM, keep serving attached sessions, park what is left after that many minutes, then exit
  • Added claude self-hosted-runner --proxy-authorization-command / --proxy-authorization-file for egress proxies that require a freshly issued Proxy-Authorization header on every connection
  • Fixed unbounded memory growth in long interactive sessions: subagent tool results are now released once they leave the recent display window
  • Fixed custom, project, and plugin output styles drifting back to the default voice mid-session
  • Fixed CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=true not keeping prompt suggestions on when your account is near, but not over, its usage limit
  • Fixed worktree-isolation Bash refusals telling you to remove a redirect when the command had none
  • Fixed self-hosted runners occasionally being removed by the server after a single slow or lost poll request, handing their healthy session to another runner
  • Fixed MCP elicitation dialogs showing nothing for URLs longer than 4,096 characters, and permission prompts dropping the "don't ask again" option when the project path didn't fit the terminal width
  • Fixed leftover /tmp/claude-*-cwd files when a Bash command is killed, times out, or is interrupted
  • Fixed held Backspace being ignored on terminals that send Ctrl+H for Backspace when keystrokes arrive in large bursts (slow SSH/mosh links)
  • Fixed text-wrapping in permission prompt diffs: lines containing wide multi-code-point characters (such as emoji) or tabs are no longer clipped
  • Fixed killing a suspended (Ctrl+Z) session sometimes leaving the terminal in bracketed-paste mode with the cursor hidden
  • Fixed stdio MCP servers receiving a server/discover request before initialize, forcing lazy servers to start their backend on every session open
  • Fixed a proxy's refusal of a connection being reported as a generic network error instead of naming the proxy
  • Fixed the /model and /effort cache-miss warning appearing when the prompt cache had already expired
  • Fixed per-task Stop from the Remote Control tasks panel doing nothing on CLI-hosted sessions
  • Fixed remote sessions exiting when a client delivered a user message without a valid role
  • Fixed Remote Control sessions started by claude remote-control inheriting session-scoped environment variables from the launching shell
  • Fixed a Remote Control session whose process crashed staying unavailable until claude remote-control was restarted; it can now be reused when you next message it
  • Fixed Remote Control messages sent from the web or Desktop while Claude is mid-turn disappearing from the transcript after the turn finishes
  • Fixed Remote Control model picks made on a phone or web not updating the model shown in the terminal
  • Fixed Remote Control disconnecting with "login expired" when a brief network hiccup delays renewing your sign-in; it now retries and stays connected
  • Fixed Remote Control reporting a failed reconnect on sign-out; signing out now ends the session with a clear message
  • Fixed ListAgents/SendMessage reporting "Remote Control is not connected" in sessions run by claude remote-control (server mode) or Desktop/IDE hosts; they now list and reach Remote Control peers
  • Fixed ListAgents and SendMessage exposing the idle worker that the agent view pre-warms for your next background session; it now appears only once a task claims it
  • Cross-session messaging: sending to a session on this machine that refuses inbound messages (e.g. crossSessionInbound: "refuse") now reports "refused" to the sender instead of a silent success
  • Cross-session messaging: a session whose inbox drops your messages (rate limit or full queue) now tells your session, instead of the messages vanishing silently
  • Improved startup: bare claude starts sooner on macOS
  • Improved Bash tool permission checking for zsh-specific syntax in shell conditionals
  • Improved Remote Control connection resilience: brief HTTP 403 refusals from a network edge, VPN, or proxy are now tolerated for up to 3 minutes, with the refusing party named when a block persists
  • Improved startup responsiveness: the automatic update check now runs about 10 seconds after launch instead of competing with startup for CPU
  • Updated the bundled claude-api skill for the Managed Agents Aug 19 release: web search/fetch domain settings and memory stores on self-hosted sandboxes
  • Changed Ctrl+L and Cmd+K in fullscreen to always just repaint — the double-press /clear shortcut was removed, and 1-row nvim terminals no longer trigger automatic /clear loops
  • Changed claude mcp list and claude mcp get to show disabled servers as ⊘ Disabled instead of connecting to them for a health check
  • MCP headersHelper in a project .mcp.json, and inline MCP servers in project or --add-dir agent files, now require that folder's trust dialog to have been accepted (also under claude -p)
  • MCP headersHelper from a project .mcp.json, plugin, or agent file runs without inherited credential env vars; user, managed and claude.ai-scope helpers now run from the Claude config dir
