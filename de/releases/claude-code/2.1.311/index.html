Claude-Code v2.1.311

Was hat sich geändert?

– --hold-idle-file und --max-hold-min zu self-hosted-runner hinzugefügt, um eine Sitzung im Leerlauf beizubehalten, während Ihr Host Prozesse meldet, die ausgeführt wurden

  • Es wurde ein Tipp für den Ausgabestil „Erläuternd“ hinzugefügt, der angezeigt wird, wenn Sie Claude um Erklärungen bitten – Langes Einfrieren beim Start und nach dem Lesen oder Bearbeiten von Dateien behoben, wenn eine CLAUDE.md-Datei ein sehr langes Listenelement enthält – Problem behoben, bei dem die Unterbrechung durch Claude erst nach einer Zeitüberschreitung wirksam wurde, während ein MCP-Server nicht auf eine gelesene Ressource geantwortet hatte oder ein Skill noch heruntergeladen wurde – Problem behoben, bei dem Standardkontextsitzungen mit der Fehlermeldung „Nutzungsguthaben für 1 Mio. Kontext erforderlich“ angehalten wurden, wenn eine Anfrage mehr als 200.000 Tokens ausführte; Claude Code verdichtet nun das Gespräch und fährt fort – Problem behoben, bei dem Schreiben und Bearbeiten bis zu 5 Sekunden nach der Ausführung anhielten und beim Ändern von Tausenden von Zeilen in einer Datei 0 geänderte Zeilen gemeldet wurden – Problem behoben, bei dem Subagenten keine MCP-Tools von Servern verwenden konnten, deren Verbindung nach dem Start des Subagenten abgeschlossen war – Problem behoben, bei dem Claude direkt nach der automatischen Komprimierung veraltete MEMORY.md- und CLAUDE.md-Inhalte sah, wenn diese Dateien früher in der Sitzung bearbeitet wurden – Problem behoben, bei dem in claude -p- und SDK-Sitzungen Transkriptnachrichten in der falschen Reihenfolge gespeichert oder zurückgenommene Nachrichten aufbewahrt wurden – Problem behoben, bei dem SubagentStop-Hooks für jeden ausgeführten Subagenten etwa zweimal pro Minute ausgeführt wurden, statt einmal, wenn er beendet ist – Behoben, dass die @-Dateiauswahl .ignore/.rgignore-Negationsregeln ignorierte, die von Git ignorierte Dateien wieder einschließen – Problem behoben, bei dem der isolierte Arbeitsbaum eines Subagenten entfernt wurde, während ein von ihm gestarteter Hintergrund-Subagent noch darin arbeitete
  • Hintergrundagenten im automatischen Modus wurden behoben, die darauf warteten, dass ihre eigenen Shells bei jedem Aufwachen eine neue Hauptkonversation starten – Die Beschreibung des Bash-Tools wurde korrigiert, die besagte, dass das Arbeitsverzeichnis zwischen Aufrufen immer bestehen bleibt – Der Umgebungsblock, der Shell-Befehle benennt, die nicht ausgeführt werden, wie z. B. „fish“, wenn das Bash-Tool „zsh“ verwendet, wurde behoben – Problem behoben, bei dem claude mcp add, claude mcp remove und /mcp den aktuellen Ordner anstelle des Projekteintrags in ~/.claude.json benannten, der einen Server mit lokalem Bereich enthält, wenn sie unterhalb eines Repository-Stamms ausgeführt werden – Problem behoben, bei dem claude mcp list und claude mcp get den Fehlercode zweimal auf fehlgeschlagenen Verbindungsleitungen anzeigten (z. B. ENOENT: ENOENT: …) – Problem behoben, bei dem Fernsteuerungssitzungen etwa zwei Minuten lang auf „Verbinden“ blieben, wenn ein Netzwerk-Proxy eine Startanforderung blockierte – Problem behoben, bei dem Nachrichten, die Claude an eine Cloud- oder Fernsteuerungssitzung sendet, in den mobilen Claude-Apps als Ihre eigene Nachricht angezeigt werden – Problem behoben, bei dem Claude nicht über die Ursache informiert wurde, wenn eine an eine über Remote Control oder an eine Cloud-Sitzung gesendete Nachricht angehängte Datei nicht gespeichert werden konnte, weil die Festplatte voll war oder weil die Anhänge einer Nachricht über die ersten 20 hinaus weggelassen wurden – Problem behoben, bei dem WebFetch und WebSearch bei einer blockierten Antwort in Cowork-Cloud-Sitzungen hängen blieben; Eine nicht abgeschlossene Anfrage schlägt jetzt nach 300 Sekunden fehl – Es wurde eine Hintergrundsitzung behoben, die zwischen Runden abstürzte und nicht neu gestartet wurde, während sie angehängt oder angeheftet war oder eine geplante Aufgabe oder einen Weckruf hatte – Der Fehler „Hintergrunddienst hat nicht geantwortet“ wurde behoben, der darauf hindeutet, dass claude daemon restart deaktiviert ist. Es schlägt jetzt claude daemon stop --any vor und sagt, dass Hintergrundsitzungen beendet werden – Problem behoben, bei dem claude respawn <id> den Hintergrunddienst startete, bevor gemeldet wurde, dass keine Hintergrundsitzung mit der ID übereinstimmt – Behoben: /effort warnte nicht vor einem Prompt-Cache-Fehler im Planmodus, wenn das Planmodell vom Sitzungsmodell abweicht – /ide wurde behoben, das besagte, dass die VS-Code-Erweiterung installiert wurde, bevor die Installation abgeschlossen war oder als sie fehlschlug – Problem behoben, bei dem in der Dateivorschau des Schreibtools Zeilen übersprungen und verdeckte Zeilen falsch gezählt wurden, wenn eine Zeile breiter als das Terminal ist
  • Problem behoben, bei dem ↑ im Chat-Tab eines Agenten eine Nachricht zurückrief, die noch auf die Zustellung wartete, sodass beim erneuten Senden eine zweite Kopie gesendet wurde – Problem behoben, bei dem Cowork-Cloud-Sitzungen nach einem Neustart ihre Konnektoren und die meisten Tools verloren, wenn ein Plugin oder Ihre Einstellungen den Namen agent erhielten; Cowork-Cloud-Sitzungen ignorieren diese Einstellung jetzt – Problem behoben, bei dem Agententeamsitzungen eine leere Aufgabenliste anzeigten, wenn sie mit --resume, --continue, /resume oder --session-id zurückkehrten, auch nach /clear oder einem Absturz, und /branch in die Liste der ursprünglichen Sitzung schrieb – Das Einfügen von Text, der eine Bilddatei wie ! open /tmp/shot.png oder /review look at /tmp/shot.png erwähnt, wurde behoben, wobei das Bild angehängt und sein Pfad aus der Eingabeaufforderung entfernt wurde
  • Problem behoben, bei dem auf der Feedback-Entwurfskarte die Tastenkombinationen 1/2/0 und Esc angezeigt wurden, während die Eingabeaufforderung Text enthält, wenn diese Tasten auf die Eingabeaufforderung und nicht auf die Karte wirken – Ein einzelner Backslash in Anführungszeichen oder Klammern, wie "\" oder (\), wurde behoben und verschwand aus Claudes Antworten – Problem behoben, bei dem Agenten-Teamkollegen ihren Verlauf komprimierten, wenn DISABLE_COMPACT eingestellt war
  • Das Rückspulmenü mit den Optionen „Von hier aus zusammenfassen“ und „Bis hierher zusammenfassen“ wurde korrigiert, wenn DISABLE_COMPACT eingestellt ist – Behoben, dass ein abgeschlossener /code-review oder ein anderer Skill, der in einem Subagenten ausgeführt wird, ein zweites Mal ausgeführt wird, wenn eine Cloud- oder Hintergrundsitzung neu gestartet wird – Problem behoben, bei dem langes verborgenes Denken bei Google Vertex AI, Microsoft Foundry und Claude Platform auf AWS als inaktiv abgeschnitten wurde, wo der Endpunkt Aktualisierungen des Denkfortschritts sendet – Problem behoben, bei dem /ide mitteilte, dass das JetBrains-Plugin installiert wurde, obwohl nichts installiert war
  • Problem behoben, bei dem Claude Pro- und Max-Abonnenten aufgefordert wurden, ihren Administrator zu fragen, wenn ihr Abonnement nicht genutzt werden kann; Die Nachricht verweist nun auf die Abrechnungseinstellungen – Das Problem, dass sich das Diff-Fenster nach einer Bearbeitung in Wide-Fullscreen-Terminals von selbst öffnete, wenn nichts angezeigt wurde, wurde behoben – Problem behoben, bei dem /mcp einen Remote-Server nach „Authentifizierung löschen“ als fehlgeschlagen anzeigte, wenn der Server ohne Anmeldung funktionierte – Behoben: /mcp zeigt „authentifiziert“ für einen Remote-Server an, an den Claude Code keine Anmeldeinformationen sendet – Ein --plugin-dir-Ordner mit Plugins wurde behoben, der als ein Plugin geladen wurde, wenn sich oben ein leerer .mcp.json befand – Problem behoben, bei dem /usage unter „Was trägt zur Nutzung Ihrer Limits bei?“ nie große Prompt-Cache-Fehler anzeigte. – Problem behoben, bei dem Statuszeilen-Links in Hintergrundsitzungen als Klartext angezeigt wurden, nachdem Sie sie von einem Terminal aus geöffnet haben, das Links unterstützt – Die /rewind-Bestätigung mit dem Hinweis, dass die Konversation „gegabelt“ wird, wenn die späteren Nachrichten aus der Konversation entfernt werden, wurde korrigiert – Die /rewind-Warnung, die fälschlicherweise besagte, dass manuelle und Bash-Änderungen niemals von einer Code-Wiederherstellung betroffen sind, wurde behoben
  • Die Plangenehmigung im Screenreader-Modus, bei der Feedback gesendet wurde, das Sie mit Escape abgelehnt hatten, wurde behoben – Behoben: Claude-Code-Wiederholungsversuche forderten den API auf, der als „Nicht erneut versuchen“ markiert war, was eine Runde minutenlang oder im unbeaufsichtigten Wiederholungsmodus (CLAUDE_CODE_RETRY_WATCHDOG) auf unbestimmte Zeit verzögern konnte – Linux: Sandbox-Bash-Befehle wurden behoben, die mit bwrap: Can't create file fehlschlugen, wenn ein --plugin-dir-Ordner auch ein hinzugefügtes Verzeichnis war und permissions.blockReadsOutsideWorkingDirectories aktiviert war
  • Selbstgehosteter Läufer: Es wurde ein Problem behoben, bei dem eine Sitzung nicht gestartet werden konnte, wenn eine Ratenbegrenzung (HTTP 429 oder ein Git-Wrapper, der 75 beendet) ein hinzugefügtes schreibgeschütztes Repository blockiert. es startet jetzt ohne dieses Repository – Verbesserte Startzeit für Pro- und Max-Konten durch Überspringen zweier Netzwerkanfragen bei Starts innerhalb einer Stunde nach der letzten Überprüfung – /teleport und claude --teleport wurden verbessert, um zu warnen, wenn eine komprimierte Cloud-Sitzung nach ihrer letzten Komprimierung geladen wird, sodass die zusammengefassten Nachrichten nicht in der lokalen Kopie enthalten sind – Die Meldungen, die angezeigt werden, wenn der Prozess einer Hintergrundsitzung beendet wird, wurden verbessert: Sie versprechen nicht mehr einen Neustart, der nicht erfolgt, und sagen, wie die Sitzung fortgesetzt werden kann
  • Verbesserte Artefakte bei mehreren Ansichten: Claude leitet jetzt jede Ansicht auf den #name des Links weiter und sagt nicht mehr, dass die Adressleiste gleich bleibt, wenn Sie die Ansicht wechseln
  • Verbesserte Shell-Befehle, die ihr Timeout erreichen: Das Ergebnis zeigt jetzt die bisherige Ausgabe und besagt, dass der Befehl immer noch im Hintergrund ausgeführt wird
  • Verbesserte Komprimierung: Wenn die Antwort des Modells keine Zusammenfassung enthält, fragt Claude Code jetzt normalerweise noch einmal nach der Zusammenfassung, bevor sie die Konversation ersetzt – Die Auswahl des Artefakt-Tools zwischen einer Seite und einem Dokument wurde verbessert: Erklärungen und visuelle oder interaktive Arbeiten werden zu Artefaktseiten; Dokumente sind zum Schreiben da, die Leute bearbeiten sie weiter oder geben sie weiter – Verbesserte Startzeit für Starts, deren einzige Argumente Optionen und deren Werte sind, wie z. B. claude --model opus
  • Der API-Fehler „Verbindung unterbrochen“ wurde verbessert: Es wird nun angezeigt, wo zuerst gesucht werden muss (der verwendete Proxy oder das verwendete Gateway, andernfalls VPN oder Firewall; nur Anthropic API, Bedrock, Vertex und Foundry bleiben unverändert)
  • Verbesserter Screenreader-Modus: Beim Löschen einer Regel in /permissions wird sofort „Gelöschte Zulassungsregel …“ angezeigt – Die Meldung, die angezeigt wird, wenn ein eingefügter Anmeldecode abgelehnt wird, wurde verbessert: Jetzt heißt es, dass der Code möglicherweise abgelaufen ist oder bereits verwendet wurde und Sie sich erneut anmelden müssen
  • Verbesserte Slack-Connector-Sendungen: Claude überprüft jetzt das Thema eines Kanals auf Veröffentlichungsregeln, bevor er eine Nachricht an einen Kanal sendet, den Sie nicht benannt haben
  • Verbesserter Screenreader-Modus: Claudes Fragen werden als „Fragen: Farbe (beantwortet), Seiten“ ohne Pfeile oder Symbole aufgelistet

  • Der ultrathink-Regenbogen wurde so geändert, dass er nur dort angezeigt wird, wo das Schlüsselwort den Aufwand erhöhen kann, und nicht, wenn das Wort in Anführungszeichen steht oder Teil eines Dateipfads ist
  • Strg+D in der Agentenansicht geändert, um der Eingabeaufforderung zu entsprechen: Bei einer leeren Eingabe wird durch zweimaliges Drücken die Taste beendet – Die Ausgabe von --output-format json und stream-json wurde geändert, um DEL-, C1-Steuer- und Unicode-Formatzeichen in Zeichenfolgen zu schreiben, während \uXXXX maskiert wird. Die analysierten Werte bleiben unverändert
  • Modellnamen und -IDs geändert, um das Suffix [1m] und seine Bezeichnung bei Modellen zu entfernen, bei denen das Suffix keine Auswirkung hat; Das Suffix wird weiterhin akzeptiert – Startwarnungen zu Berechtigungsregeln in Einstellungsdateien wurden so geändert, dass sie einmal pro Benutzer angezeigt werden, bis sich die Regel ändert
  • /code-review wurde geändert, um Claude anzuweisen, die Anstrengungsstufe an die erste Stelle zu setzen und das Maximum nur zu verwenden, wenn er dazu aufgefordert wird
  • DISABLE_COMPACT in den Einstellungsdateien und im $.env.set eines Mods geändert, sodass sie die Komprimierung nur ausschalten und nicht wieder einschalten können

  • clicks auf Bildlaufleistenpfeilen und -leisten in Vollbildlisten wurden so geändert, dass sie beim Loslassen der Maustaste funktionieren. Wenn Sie also die Bildlaufleiste vor dem Loslassen verlassen, wird das click abgebrochen – claude purge wurde dahingehend geändert, dass es nur Daten auf diesem Computer löscht, nicht alles, was von Anthropic gespeichert wurde
  • [VSCode] Syntaxfärbung zu Codeblöcken in Claudes Antworten hinzugefügt, in hellen, dunklen und dunklen Designs mit hohem Kontrast
  • [VSCode] Es wurden ein Spinnerstatus und eine Screenreader-Ankündigung „UserPromptSubmit-Hooks werden ausgeführt“ für langsame UserPromptSubmit-Hooks hinzugefügt

  • [VSCode] Problem mit cli behoben, bei dem ein Bild in einem Tool-Ergebnis angezeigt oder dessen Vorschau geschlossen wurde, wodurch auch der Text des Ergebnisses in einer Editor-Registerkarte geöffnet wurde
  • [VSCode] Problem behoben, bei dem das Sprachdiktat weiterhin aufgezeichnet wurde, nachdem eine Nachricht mit der Schaltfläche „Senden“ gesendet wurde; Das Senden stoppt jetzt zunächst das Diktat, wie es bereits beim Drücken der Eingabetaste der Fall war – [VSCode] Die Erweiterung wurde geändert, um Claude Code-Sitzungen mit eingestelltem DISABLE_TELEMETRY zu starten, während die Telemetrieeinstellung von VS Code deaktiviert ist, sodass sie keine Nutzungsmetriken oder Fehlerberichte senden und keine Funktionsflags abrufen – [VSCode] Die Seitenleiste der Sitzungsliste wurde so geändert, dass Websitzungen geladen werden, wenn die Registerkarte „Web“ zum ersten Mal geöffnet wird, nicht beim Start

  • [Cloud-Sitzungen] Eine fehlgeschlagene Routine zum Löschen oder Neugenerieren von Tokens API wurde behoben und zeigte nichts an, wenn der Bearbeitungsdialog bereits geschlossen war. Es wird jetzt ein Fehlertoast angezeigt
  • [Cloud-Sitzungen] Die Dialoge in der Cloud-Umgebung, einschließlich des Admin-Dialogs, wurden korrigiert und akzeptierten nun doppelte Namen. Sie lehnen nun einen Namen ab, den eine andere gelistete Umgebung bereits hat

  • [Claude Tag] Die Admin-Einstellungen von Claude Tag wurden geändert, um für private Slack-Kanäle, die Ihr eigenes Slack-Konto sehen kann, eine Sperre anstelle von # anzuzeigen

claude-code v2.1.311

What's changed

  • Added --hold-idle-file and --max-hold-min to self-hosted-runner, to keep an idle session while your host reports processes it left running
  • Added a tip for the Explanatory output style, shown when you ask Claude for explanations
  • Fixed long freezes at startup and after reading or editing files when a CLAUDE.md file holds a very long list item
  • Fixed interrupting Claude not taking effect until a timeout while an MCP server had not answered a resource read or a skill was still downloading
  • Fixed standard-context sessions stopping with "Usage credits required for 1M context" when a request ran over 200K tokens; Claude Code now compacts the conversation and continues
  • Fixed Write and Edit stalling for up to 5 seconds after they ran, and reporting 0 lines changed, when changing thousands of lines in a file
  • Fixed subagents being unable to use MCP tools from servers that finish connecting after the subagent starts
  • Fixed Claude seeing stale MEMORY.md and CLAUDE.md content right after automatic compaction when those files were edited earlier in the session
  • Fixed claude -p and SDK sessions saving transcript messages out of order or keeping messages that were taken back
  • Fixed SubagentStop hooks running about twice a minute for each running subagent instead of once when it finishes
  • Fixed the @ file picker ignoring .ignore/.rgignore negation rules that re-include git-ignored files
  • Fixed a subagent's isolated worktree being removed while a background subagent it started was still working in it
  • Fixed background agents in auto mode that wait on their own shells starting a new main conversation turn on every wake
  • Fixed the Bash tool description claiming the working directory always persists between calls
  • Fixed the environment block naming a shell commands don't run in, such as fish when the Bash tool uses zsh
  • Fixed claude mcp add, claude mcp remove and /mcp naming the current folder instead of the project entry in ~/.claude.json that holds a local-scope server when run below a repository root
  • Fixed claude mcp list and claude mcp get showing the error code twice on failed-connection lines (for example ENOENT: ENOENT: …)
  • Fixed Remote Control sessions staying on "Connecting" for about two minutes when a network proxy blocks a startup request
  • Fixed messages that Claude sends to a cloud or Remote Control session appearing as your own message in the Claude mobile apps
  • Fixed Claude not being told the cause when a file attached to a message sent over Remote Control or to a cloud session could not be saved because the disk was full, or that a message's attachments past the first 20 were left out
  • Fixed WebFetch and WebSearch hanging on a stalled response in Cowork cloud sessions; an unfinished request now fails after 300 seconds
  • Fixed a background session that crashed between turns not being restarted while it was attached, pinned, or had a scheduled task or wake-up set
  • Fixed the "background service did not respond" error suggesting the disabled claude daemon restart; it now suggests claude daemon stop --any and says it ends background sessions
  • Fixed claude respawn <id> starting the background service before reporting that no background session matches the id
  • Fixed /effort not warning about a prompt cache miss in plan mode when the plan model differs from the session model
  • Fixed /ide saying the VS Code extension was installed before the install finished or when it failed
  • Fixed the Write tool's file preview skipping rows and miscounting hidden lines when a line is wider than the terminal
  • Fixed ↑ in an agent's chat tab recalling a message that was still waiting to be delivered, so resending it sent a second copy
  • Fixed Cowork cloud sessions losing their connectors and most tools after a restart when a plugin or your settings named an agent; Cowork cloud sessions now ignore that setting
  • Fixed agent teams sessions showing an empty task list when coming back with --resume, --continue, /resume or --session-id, including after /clear or a crash, and /branch writing to the original session's list
  • Fixed pasting text that mentions an image file, such as ! open /tmp/shot.png or /review look at /tmp/shot.png, attaching the image and dropping its path from the prompt
  • Fixed the feedback draft card showing its 1/2/0 and Esc shortcuts while the prompt has text, when those keys act on the prompt instead of the card
  • Fixed a lone backslash in quotes or brackets, like "\" or (\), disappearing from Claude's responses
  • Fixed agent teammates compacting their history when DISABLE_COMPACT is set
  • Fixed the rewind menu offering "Summarize from here" and "Summarize up to here" when DISABLE_COMPACT is set
  • Fixed a finished /code-review, or another skill that runs in a sub-agent, running a second time when a cloud or background session restarts
  • Fixed long hidden thinking being cut off as idle on Google Vertex AI, Microsoft Foundry and Claude Platform on AWS, where the endpoint sends thinking progress updates
  • Fixed /ide saying it had installed the JetBrains plugin when nothing was installed
  • Fixed Claude Pro and Max subscribers being told to ask their admin when their subscription can't be used; the message now points to billing settings
  • Fixed the diff pane opening by itself after an edit in wide fullscreen terminals when it had nothing to show
  • Fixed /mcp showing a remote server as failed after "Clear authentication" when the server works without sign-in
  • Fixed /mcp showing "authenticated" for a remote server that Claude Code sends no credentials to
  • Fixed a --plugin-dir folder of plugins loading as one plugin when an empty .mcp.json was at its top
  • Fixed /usage never showing large prompt-cache misses under "What's contributing to your limits usage?"
  • Fixed status line links staying plain text in background sessions after you open them from a terminal that supports links
  • Fixed the /rewind confirmation saying the conversation "will be forked" when the later messages are removed from the conversation
  • Fixed the /rewind warning that wrongly said manual and Bash edits are never affected by a code restore
  • Fixed plan approval in screen reader mode sending feedback you had dismissed with Escape
  • Fixed Claude Code retrying requests the API marked not to retry, which could hold a turn for minutes or, in unattended retry mode (CLAUDE_CODE_RETRY_WATCHDOG), indefinitely
  • Linux: Fixed sandboxed Bash commands failing with bwrap: Can't create file when a --plugin-dir folder was also an added directory and permissions.blockReadsOutsideWorkingDirectories was on
  • Self-hosted runner: Fixed a session failing to start when a rate limit (HTTP 429, or a git wrapper that exits 75) blocks an added read-only repository; it now starts without that repository
  • Improved startup time for Pro and Max accounts by skipping two network requests on launches within an hour of the last check
  • Improved /teleport and claude --teleport to warn when a compacted cloud session loads from its last compaction, so the messages it summarized aren't in the local copy
  • Improved the messages shown when a background session's process exits: they no longer promise a restart that isn't coming, and they say how to resume the session
  • Improved artifacts with several views: Claude now routes each view on the link's #name and no longer says the address bar stays the same as you switch views
  • Improved shell commands that reach their timeout: the result now shows the output so far and says the command is still running in the background
  • Improved compaction: when the model's reply has no summary in it, Claude Code now usually asks for the summary once more before it replaces the conversation
  • Improved the Artifact tool's choice between a page and a document: explainers and visual or interactive work become artifact pages; documents are for writing people keep editing or pass around
  • Improved startup time for launches whose only arguments are options and their values, such as claude --model opus
  • Improved the "Connection dropped" API error: it now says where to look first (the proxy or gateway in use, else VPN or firewall; Anthropic API only, Bedrock, Vertex and Foundry are unchanged)
  • Improved screen reader mode: deleting a rule in /permissions says "Deleted allow rule …" right away
  • Improved the message shown when a pasted sign-in code is refused: it now says the code may have expired or been used, and to sign in again
  • Improved Slack connector sends: Claude now checks a channel's topic for posting rules before messaging a channel you didn't name
  • Improved screen reader mode: Claude's questions are listed as "Questions: Color (answered), Pages", without arrows or symbols
  • Changed ultrathink in the interactive terminal to run its turn at xhigh effort on Opus 5.5, Sonnet 5.5, Haiku 5.5 and Fable 5.1 through Anthropic's API; typed while Claude is working, it raises the rest of that turn
  • Changed the ultrathink rainbow to appear only where the keyword can raise effort, and not when the word is quoted or part of a file path
  • Changed Ctrl+D in agent view to match the prompt: on an empty input, pressing it twice exits
