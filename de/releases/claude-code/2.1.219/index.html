Claude-Code v2.1.219

Was hat sich geändert?

– Claude Opus 5 (claude-opus-5) hinzugefügt, jetzt das Standard-Opus-Modell – 1 Mio. Kontext, Schnellmodus für 10 $/50 $ pro Mtok – sandbox.network.strictAllowlist-Einstellung hinzugefügt, um nicht auf der Zulassungsliste stehende Hosts für Sandbox-Befehle ohne Aufforderung zu verweigern – DirectoryAdded-Hook hinzugefügt, der ausgelöst wird, nachdem /add-dir oder die SDK register_repo_root-Steuerungsanforderung mitten in der Sitzung ein neues Arbeitsverzeichnis registriert – mcp_server_errors zum Headless-Stream-json-Init-Ereignis hinzugefügt, das --mcp-config-Einträge auflistet, die bei der Konfigurationsvalidierung übersprungen wurden; Terminalausführungen geben eine Startwarnung aus – Der Einstellungsschlüssel workflowSizeGuideline wurde hinzugefügt, sodass die beratende dynamische Workflow-Größenrichtlinie aus jeder Einstellungsdatei festgelegt werden kann. Die Zeile /config wird dabei ausgeblendet – Weiterleitung verschachtelter Subagenten in Stream-json hinzugefügt: Subagenten, die bei Tiefe 2+ gespawnt werden, werden jetzt angezeigt, wenn --forward-subagent-text festgelegt ist, gekennzeichnet durch ihre Spawning-Agent-ID tool_use – Problem behoben, bei dem die Textausgabe claude -p die bereits erzeugte Antwort vernachlässigte, wenn eine Runde aufgrund eines API-Fehlers in der Mitte des Streams abgebrochen wurde – HTTP-Status- und Fehlertext zu claude mcp list und /mcp hinzugefügt, wenn ein Server keine Verbindung herstellen kann, sowie eine Warnung für MCP-Konfigurationswerte mit versteckten führenden oder nachgestellten Leerzeichen – Es wurde behoben, dass eine Berechtigung, die Sie während des Neustarts eines selbst gehosteten Läufers genehmigt hatten, bei der Wiederaufnahme der Sitzung gelöscht wurde, sodass die genehmigte Aktion jetzt ausgeführt wird

  • Die Zeile „Fable-Modell“ mit der Meldung „Nutzungsguthaben erforderlich“ für Pläne, die es enthalten, wurde behoben, wenn ein veralteter Cache das Etikett eingebrannt hatte – Ein SIGTERM wurde behoben, das eintraf, während ein selbst gehosteter Läufer startete und eine veraltete aktive Zeile hinterließ, bis die Lease abgelaufen war. Die Registrierung wird jetzt sauber abgemeldet – Strukturierte Fehlerkategorien zu selbstgehosteten Runner-Spawn- und Sitzungsfehlern hinzugefügt, sodass Hook-Fehler, Runner-Abstürze und Konfigurationsfehler unterschieden werden können – Der /model-Picker hat die zusammengeführte Opus-Zeile als einfaches „Opus“ anstelle von „Opus (1M-Kontext)“ angezeigt. – Problem behoben, bei dem das Kopieren bei Auswahl innerhalb des GNU-Bildschirms base64 in das Terminal gedruckt wurde, anstatt die Auswahl zu kopieren – Problem behoben, bei dem Fernbedienungs-clients nach einem Modellwechsel, einer erneuten Verbindung oder einer fehlgeschlagenen Organisationsprüfung einen veralteten Schnellmodusstatus beibehielten – Problem behoben, bei dem CLAUDE_CODE_GIT_BASH_PATH unter Windows beendet wurde oder als Bash verwendet wurde, wenn der Pfad keine Bash/Sh-Binärdatei ist; Es wird jetzt mit einer Warnung ignoriert
  • Vim-Modus behoben: Durch Drücken von ← an einer leeren Eingabeaufforderung wird nun vom NORMAL-Modus zur Agentenansicht zurückgekehrt, nicht nur vom EINFÜGEN – Problem behoben, bei dem der Bildschirmlesemodus bei jedem Tastendruck die gesamte Eingabezeile neu schrieb, anstatt nur das eingegebene Zeichen wiederzugeben – Der Fehler „Fernbedienung ist nur über api.anthropic.com verfügbar“ wurde verbessert, um die spezifische Einstellung zu benennen, die ihn verursacht hat – claude --teleport wurde verbessert, um anzuzeigen, an welchem Repo sich Ihre aktuellen Checkout-Punkte befinden, wenn es nicht mit dem Repo der Sitzung übereinstimmt
  • Dynamische Arbeitsabläufe wurden so geändert, dass sie standardmäßig auf eine mittlere Größe basieren (weniger als 15 Agenten anstreben); Wählen Sie eine andere Größe oder uneingeschränkt mit der dynamischen Workflow-Größe in /config – Die Einträge der verwalteten MCP-Zulassungs-/Verweigerungsliste ${VAR} wurden so geändert, dass sie aus der Startumgebung und der verwalteten Einstellungsumgebung statt aus der Einstellungsdateiumgebung aufgelöst werden – Die /model-Auswahl wurde geändert, um nur den Namen des neuesten Modells hervorzuheben, sodass die Hervorhebung die neue Version markiert und nicht eine beliebige Teilmenge der Liste – Die aktuelle Standard-Workflow-Größe wurde zur Statuszeile des laufenden Workflows hinzugefügt, mit einem Zeiger auf /config zum Ändern
  • Opus 4.7 aus dem Schnellmodus entfernt; /fast gilt jetzt für Opus 5 und Opus 4.8 – Der Skill claude-api wurde aktualisiert und standardmäßig auf Claude Opus 5 mit einem Migrationspfad von Opus 4.8 umgestellt
  • Subagenten können jetzt standardmäßig verschachtelte Subagenten bis zur Tiefe 3 erzeugen (vorher 1); Setzen Sie CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1, um die Verschachtelung zu deaktivieren

Englisches Original / English original

claude-code v2.1.219

What's changed

  • Added Claude Opus 5 (claude-opus-5), now the default Opus model — 1M context, fast mode at $10/$50 per Mtok
  • Added sandbox.network.strictAllowlist setting to deny non-allowlisted hosts for sandboxed commands without prompting
  • Added DirectoryAdded hook that fires after /add-dir or the SDK register_repo_root control request registers a new working directory mid-session
  • Added mcp_server_errors to the headless stream-json init event, listing --mcp-config entries skipped by config validation; terminal runs print a startup warning
  • Added the workflowSizeGuideline settings key so the advisory Dynamic workflow size guideline can be set from any settings file; the /config row is hidden while one does
  • Added nested subagent forwarding in stream-json: subagents spawned at depth-2+ now appear when --forward-subagent-text is set, keyed by their spawning Agent tool_use id
  • Fixed claude -p text output dropping the answer already produced when a turn dies on a mid-stream API error
  • Added HTTP status and error text to claude mcp list and /mcp when a server fails to connect, and a warning for MCP config values with hidden leading or trailing whitespace
  • Fixed a permission you approved while a self-hosted runner was restarting being dropped when the session resumed, so the approved action now runs
  • Fixed the Fable model row showing "Requires usage credits" for plans that include it, when a stale cache had baked the label in
  • Fixed a SIGTERM arriving while a self-hosted runner was starting up leaving a stale active row until the lease expired; it now deregisters cleanly
  • Added structured failure categories to self-hosted runner spawn and session failures, so hook errors, runner crashes and config errors can be told apart
  • Fixed the /model picker showing the merged Opus row as plain "Opus" instead of "Opus (1M context)"
  • Fixed copy-on-select inside GNU screen printing base64 into the terminal instead of copying the selection
  • Fixed Remote Control clients keeping a stale fast-mode status after a model switch, reconnect, or failed org check
  • Fixed CLAUDE_CODE_GIT_BASH_PATH on Windows exiting or being used as bash when the path isn't a bash/sh binary; it's now ignored with a warning
  • Fixed Vim mode: pressing ← on an empty prompt now returns to the agent view from NORMAL mode, not just INSERT
  • Fixed screen-reader mode rewriting the entire input line on every keystroke instead of echoing only the typed character
  • Improved the "Remote Control is only available via api.anthropic.com" error to name the specific setting that caused it
  • Improved claude --teleport to show which repo your current checkout points at when it doesn't match the session's repo
  • Changed dynamic workflows to default to a medium size guideline (aim for fewer than 15 agents); pick another size or unrestricted with Dynamic workflow size in /config
  • Changed managed MCP allowlist/denylist ${VAR} entries to resolve from the startup environment and managed-settings env instead of settings-file env
  • Changed the /model picker to highlight only the newest model's name, so the highlight marks the new release rather than an arbitrary subset of the list
  • Added the current default workflow size to the running-workflow status line, with a pointer to /config for changing it
  • Removed Opus 4.7 from fast mode; /fast now applies to Opus 5 and Opus 4.8
  • Updated the claude-api skill to default to Claude Opus 5, with a migration path from Opus 4.8
  • Subagents can now spawn nested subagents up to depth 3 by default (was 1); set CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 to disable nesting
