Claude-Code v2.1.281

Was hat sich geändert?

– Claude Apps Gateway-Unterstützung für neuere Claude Desktop-Schlüssel in desktop-Richtlinienblöcken hinzugefügt, einschließlich blockReadsOutsideWorkingDirectories und disableBypassPermissionsMode – assume_role für Claude-Apps-Gateway-Bedrock-Upstreams hinzugefügt: Das Gateway ruft Bedrock als IAM-Rolle auf, die es über STS übernimmt, bei Bedarf in einem anderen AWS-Konto, optional eine Sitzung pro Entwickler – guardrail: {id, version} für Claude-Apps-Gateway-Bedrock-Upstreams hinzugefügt, um eine Amazon-Bedrock-Leitplanke auf jede über sie gesendete Anfrage anzuwenden (legen Sie sie auf allen Bedrock-Upstreams oder keinem fest) – telemetry.resource_attributes zur Gateway-Konfiguration der Claude-Apps hinzugefügt, um der Telemetrie von Claude Desktop- und /login-Sitzungen feste Bezeichnungen zuzuweisen

  • "attribution": false in settings.json hinzugefügt, um alle Commit- und PR-Attribute auszublenden; Ältere CLI-Versionen überspringen eine Einstellungsdatei, die es enthält. Behalten Sie daher die Objektform in Dateien bei, die von allen Versionen gemeinsam genutzt werden – MCP-URL-Modus-Ermittlung für Protokollverbindungen vom 28.07.2026 hinzugefügt, sodass Server Claude Code auffordern können, einen browserbasierten Fluss zu öffnen; Es bleibt kein Wartedialog auf dem Bildschirm, wenn der Server keine Möglichkeit hat, den Abschluss zu bestätigen – MCP-Serverprüfungen zu claude plugin validate hinzugefügt: Es werden .mcp.json-Einträge gemeldet, die beim Laden stillschweigend gelöscht würden, nicht deklarierte ${user_config.*}-Referenzen und unsichere URLs – /insights wurde eine Empfehlung für den automatischen Modus hinzugefügt, die schätzt, wie viele Berechtigungsaufforderungen der automatische Modus in Ihren letzten Sitzungen hätte verarbeiten können
