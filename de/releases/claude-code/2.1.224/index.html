Claude-Code v2.1.224

Was hat sich geändert?

  • Selbst gehostete Umgebungen hinzugefügt: claude self-hosted-runner verwandelt Ihre eigenen Maschinen oder Container in einen Ort, an dem Claude Code Web-, Mobil- und Desktop-Sitzungen im Rahmen von Team- und Enterprise-Plänen ausgeführt werden können
  • archive-Plugin-Quelle hinzugefügt: Plugins aus einer ZIP-Datei über HTTPS ohne Git oder NPM installieren, mit optionalem SHA-256-Pinning – Es wurde ein Schritt zum Abbrechen und Bestätigen hinzugefügt, wenn das Entfernen eines nicht verfügbaren Einfügens den Text eines Befehls ändert – ANTHROPIC_BEDROCK_REGION_PREFIX-Umgebungsvariable für Bedrock hinzugefügt, um ein bestimmtes regionsübergreifendes Inferenzprofil gegenüber dem von AWS_REGION abgeleiteten Profil zu bevorzugen – Einstellungen crossSessionInbound und dialogExpiry hinzugefügt: Sitzungsübergreifende Nachrichten, die an eine Sitzung gesendet werden, die mit umgangenen Berechtigungen ausgeführt wird, werden für Ihre Genehmigung zurückgehalten, und Nachrichten an andere Sitzungen werden automatisch zugestellt – Sandbox-Optionen zur Maskierung von Anmeldeinformationen hinzugefügt: extract und onExtractNoMatch für strukturierte Umgebungswerte, decode: "jwt" mit maskClaims für JWT-fähige Maskierung und awsPairs/sigv4 für AWS SigV4-Neusignierung; Diese benötigen network.tlsTerminate und werden nur von Benutzer-, verwalteten oder --settings-Einstellungen berücksichtigt
  • Sitzungsübergreifendes SendMessage hinzugefügt: Claude Code-Sitzungen können sich jetzt auf jedem Ihrer Computer gegenseitig Nachrichten mit ListAgents senden, um sie zu erkennen (macOS und Linux). – Lange Projektpfade (>200 Zeichen) wurden behoben, die unter einem gemeinsam genutzten, bereinigten Präfix in das Sitzungsverzeichnis eines anderen Projekts aufgelöst wurden. Sitzungsliste, Umbenennen, Forken, Löschen und /resume sind nicht mehr projektübergreifend – Problem behoben, bei dem SendMessage die Meldung „Nachricht gesendet“ meldete, wenn das Schreiben in den Posteingang eines Teamkollegen tatsächlich fehlgeschlagen war; Fehllieferungen werden nun als Fehler gemeldet – Behoben, dass Sandbox-Dateisystem-Verweigerungseinträge, die mit einem abschließenden Schrägstrich geschrieben wurden (z. B. denyRead: "~/.aws/"), unter Linux und macOS stillschweigend umgangen werden konnten – Es wurde behoben, dass Details zu Sandbox-Verstößen nie in den Ergebnissen des Bash-Tools angezeigt wurden. Claude sieht nun, welche Datei oder welcher Netzwerkzugriff verweigert wurde und warum
  • Problem behoben, bei dem MCP-Werkzeuge, die sich mitten in der Runde verbinden, für die Werkzeugsuche zurückgestellt wurden, ohne dass ihre Namen dem Modell bekannt gegeben wurden – Problem behoben, bei dem Plugin-Installationsdatensätze stillschweigend beschädigt wurden, wenn dasselbe Plugin in mehreren Projekten installiert wurde – Es wurde ein Problem behoben, bei dem abgerufene oder wiederhergestellte Einfügeinhalte gelegentlich falsche Daten anfügten oder stillschweigend Text verloren, wenn die Einfügung veraltet war oder Platzhalternummern kollidierten
  • Behoben: Copy-on-Select auf Wayland erreichte manchmal nicht das clipboard; Die beiden Auswahlschreiber fahren nicht mehr Rennen – Problem behoben, bei dem die Transkriptfreigabe der Feedback-Umfrage bei langen Sitzungen stillschweigend fehlschlug; Bei einer fehlgeschlagenen Freigabe wird jetzt ein Fehler anstelle einer Erfolgsmeldung angezeigt – Problem behoben, bei dem der automatische Start von Remote Control bei einem Kaltstart mit einem veralteten Anmeldetoken zeitweise mit der Meldung „Abruf der Remote-Anmeldeinformationen fehlgeschlagen“ fehlschlug
  • Problem behoben, bei dem Remote Control und SDK clients nach /clear und anderen Befehlen ohne Ausgabe eine leere Meldung „(kein Inhalt)“ anzeigten – Es wurde ein Problem behoben, bei dem eine Fernsteuerungssitzung neu erstellt wurde, nachdem ihre Serversitzung abgelaufen war, wodurch der vorherige lokale Konversationsverlauf in die neue Sitzung hochgeladen wurde – Verbesserter Vollbildmodus, um den gesamten Verlauf vor der Komprimierung beim Scrollback über wiederholte Komprimierungen hinweg beizubehalten, anstatt nur das letzte Intervall
  • Verbesserte Fernbedienung: Angeschlossene Web- und mobile clients sehen jetzt den Verdichtungsfortschritt und die Grenze nach der Verdichtung anstelle einer stillen Pause; /clear-Resets werden jetzt auf angeschlossene clients übertragen
  • Verbesserte Fernsteuerung: Bei Verbindungsfehlern wird jetzt eine dauerhafte Fehleranzeige mit Details und einer Verknüpfung zum erneuten Verbinden angezeigt, statt nur eines 8-Sekunden-Toasts – Die Spawn-Grenze für 200 Subagenten pro Sitzung wurde entfernt; Lange laufende Sitzungen lehnen neue Agenten nicht mehr ab (Gleichzeitigkeits- und Tiefenbeschränkungen gelten weiterhin).
  • Geänderte verwaltete Einstellungen: Die Genehmigungsaufforderung wird nach einer erneuten Anmeldung oder einem Organisationswechsel nicht mehr erneut angezeigt, wenn die Einstellungen der Organisation unverändert bleiben – Die Freigabe des Feedback-Umfrage-Transkripts wurde geändert: Mit Ihrer Zustimmung werden jetzt auch die Modelleinstellungen der letzten Anfrage hochgeladen – die Systemeingabeaufforderung (einschließlich Ihrer CLAUDE.md-Anweisungen), Werkzeugdefinitionen und Modellparameter. Geheimnisse werden wie zuvor geschwärzt und diese Felder werden zuerst gelöscht, wenn der Anteil zu groß ist – Die Beschreibung des Bash-Tools wurde dahingehend geändert, dass immer darauf hingewiesen wird, dass die Befehlsausgabe dem Modell und nicht zuverlässig dem Benutzer angezeigt wird
  • Abgerufene Einfüge-Platzhalternummern wurden geändert, sodass sie neu nummeriert werden, wenn sie in die Eingabe übernommen werden – Remote Control wurde geändert, um die veraltete Serversitzung zu archivieren, anstatt eine tote Serversitzung aufzulisten, wenn nach der Komprimierung oder /resume eine neue Sitzung erstellt wird – [VSCode] Die Erweiterung, die die Fernbedienung als verbunden anzeigte, nachdem die Verbindung fehlgeschlagen war, wurde behoben – Es wurde ein Problem behoben, durch das die Sitzungswiederaufnahme stillschweigend wieder mit der Fernbedienung verbunden wurde, nachdem der Benutzer sie ausgeschaltet hatte (--resume-, SDK-Hosts und die VS-Code-Erweiterung). – [VSCode] Behoben: Sitzungen berücksichtigen remoteControlAtStartup nicht, wenn sie explizit aktiviert sind

Englisches Original / English original

claude-code v2.1.224

What's changed

  • Added self-hosted environments: claude self-hosted-runner turns your own machines or containers into a place Claude Code web, mobile, and desktop sessions can run, on Team and Enterprise plans
  • Added archive plugin source: install plugins from a zip over HTTPS without git or npm, with optional SHA-256 pinning
  • Added a cancel-and-confirm step when removing an unavailable paste changes a command's text
  • Added ANTHROPIC_BEDROCK_REGION_PREFIX env var for Bedrock to prefer a specific cross-region inference profile over the AWS_REGION-derived one
  • Added crossSessionInbound and dialogExpiry settings: cross-session messages sent to a session running with bypassed permissions are held for your approval, and messages to other sessions auto-deliver
  • Added sandbox credential-masking options: extract and onExtractNoMatch for structured env values, decode: "jwt" with maskClaims for JWT-aware masking, and awsPairs/sigv4 for AWS SigV4 re-signing; these need network.tlsTerminate and are honored only from user, managed, or --settings settings
  • Added cross-session SendMessage: Claude Code sessions can now message each other, on any of your machines, with ListAgents to discover them (macOS and Linux)
  • Fixed long (>200 char) project paths resolving to another project's session directory under a shared sanitized prefix; session list, rename, fork, delete and /resume no longer cross projects
  • Fixed SendMessage reporting "Message sent" when the write to a teammate's inbox had actually failed; failed deliveries are now reported as errors
  • Fixed sandbox filesystem deny entries written with a trailing slash (e.g. denyRead: "~/.aws/") being silently bypassable on Linux and macOS
  • Fixed sandbox violation details never appearing in Bash tool results; Claude now sees which file or network access was denied and why
  • Fixed MCP tools that connect mid-turn being deferred for tool search without their names announced to the model
  • Fixed plugin install records being silently corrupted when the same plugin is installed in multiple projects
  • Fixed recalled or restored paste content occasionally attaching wrong data or silently losing text when the paste had aged out or placeholder numbers collided
  • Fixed copy-on-select on Wayland sometimes not reaching the clipboard; the two selection writes no longer race
  • Fixed the feedback survey's transcript share silently failing on long sessions; a failed share now shows an error instead of a success message
  • Fixed Remote Control auto-start intermittently failing with "Remote credentials fetch failed" on a cold start with a stale login token
  • Fixed Remote Control and SDK clients showing a blank "(no content)" message after /clear and other output-less commands
  • Fixed a Remote Control session recreated after its server session expired uploading prior local conversation history into the new session
  • Improved fullscreen mode to keep the full pre-compaction history in scrollback across repeated compactions, instead of only the most recent interval
  • Improved Remote Control: attached web and mobile clients now see compaction progress and the post-compaction boundary instead of a silent pause; /clear resets now propagate to attached clients
  • Improved Remote Control: connection failures now show a persistent failure indicator with details and a reconnect shortcut, instead of only an 8-second toast
  • Removed the 200-subagent-per-session spawn cap; long-running sessions no longer refuse new agents (concurrency and depth limits still apply)
  • Changed managed settings: the approval prompt no longer re-appears after re-login or org switching when the organization's settings are unchanged
  • Changed the feedback-survey transcript share: with your consent it now also uploads the last request's model settings — the system prompt (which includes your CLAUDE.md instructions), tool definitions, and model parameters. Secrets are redacted as before, and these fields are dropped first if the share is too large
  • Changed the Bash tool description to always note that command output is displayed to the model, not reliably to the user
  • Changed recalled paste placeholder numbers to renumber when accepted into the input
  • Changed Remote Control to archive the stale server session instead of leaving a dead one listed when a fresh session is minted after compaction or /resume
  • [VSCode] Fixed the extension showing Remote Control as connected after the connection failed
  • Fixed a session resume silently reconnecting Remote Control after the user turned it off (--resume, SDK hosts, and the VS Code extension)
  • [VSCode] Fixed sessions not honoring remoteControlAtStartup when explicitly enabled
