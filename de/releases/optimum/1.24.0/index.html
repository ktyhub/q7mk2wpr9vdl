optimal v1.24.0

Release Notes: Optimales v1.24.0

Wir freuen uns, die Veröffentlichung von Optimum v1.24.0 bekannt zu geben. Dieses Update erweitert die ONNX-basierten Modellfunktionen und enthält mehrere Verbesserungen, Fehlerbehebungen und neue Beiträge der Community.

:rocket: Neue Funktionen und Verbesserungen

  • ORTQuantizer unterstützt jetzt Modelle mit ONNX-Unterordnern.
  • ONNX Runtime IO Binding-Unterstützung für alle unterstützten Transformers-Modelle (keine Modelle bleiben zurück).
  • Unterstützung für SD3- und Flux-Modelle zu ORTDiffusionPipeline hinzugefügt, um die neuesten diffusionsbasierten Modelle zu ermöglichen.
  • Kompatibilität der Transformatoren v4.47 und v4.48, um eine nahtlose Integration mit den neuesten Fortschritten im Hugging Face-Ökosystem zu gewährleisten.
  • ONNX-Exportunterstützung auf verschiedene Modelle erweitert, darunter Decision Transformer, ModernBERT, Megatron-BERT, Dinov2, OLMo und viele mehr (siehe Details).

:wrench: Wichtige Korrekturen und Optimierungen

  • Unterstützung für Python 3.8 eingestellt
  • Fehlerbehebungen in ModelPatcher, SDXL-Refiner-Export und Geräteprüfungen für verbesserte Zuverlässigkeit.

:busts_in_silhouette: Neue Mitwirkende

Ein großes Dankeschön an unsere erstmaligen Mitwirkenden:

optimum v1.24.0

Release Notes: Optimum v1.24.0

We’re excited to announce the release of Optimum v1.24.0. This update expands ONNX-based model capabilities and includes several improvements, bug fixes, and new contributions from the community.

:rocket: New Features & Enhancements

  • ORTQuantizer now supports models with ONNX subfolders.
  • ONNX Runtime IO Binding support for all supported Transformers models (no models left behind).
  • SD3 and Flux model support added to ORTDiffusionPipeline enabling latest diffusion-based models.
  • Transformers v4.47 and v4.48 compatibility, ensuring seamless integration with the latest advancements in Hugging Face's ecosystem.
  • ONNX export support extended to various models, including Decision Transformer, ModernBERT, Megatron-BERT, Dinov2, OLMo, and many more (see details).

:wrench: Key Fixes & Optimizations

  • Dropped support for Python 3.8
  • Bug fixes in ModelPatcher, SDXL refiner export, and device checks for improved reliability.

:busts_in_silhouette: New Contributors

A huge thank you to our first-time contributors:

  • @gabe-l-hart
  • @ra9hur
  • @bndos
  • @mlynatom
  • @LoSealL
  • @sjrl
  • @guangy10

Your contributions make Optimum better! :tada:

For a detailed list of all changes, please check out the full changelog.

:rocket: Happy optimizing!
