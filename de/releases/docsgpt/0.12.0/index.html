DocsGPT 0.12.0

Highlights

  • Expanded document ingestion — New parsers for .xlsx (#1184, #1349), .pptx (#1405), and JSON (#1377) make office and structured-data repositories easier to index. The GitHub loader also handles binary files more safely (#1337); validate upload allowlists and extraction quality with representative files before bulk ingestion.
  • More vector-store options and retrieval fixes — LanceDB support (#1122), Milvus fixes (#1407), and improved FAISS error handling, typing, and documentation (#1183) strengthen backend flexibility. Test the updated migration script (#1198) against a copy of your index, and regression-check streaming retriever selection (#1314) and empty-document behavior (#1384).
  • New model and integration paths — Groq LLM support (#1246) adds another provider option, while text-to-speech (#1397, #1381) and Slack integration (#1346) enable new delivery channels. Discord fixes (#1401–#1403) improve formatting and message chunking; verify provider credentials, bot permissions, and rate limits before rollout.
  • Better rendering for technical content — Markdown equation support (#1190), empty-table handling (#1178), and the table redesign (#1300) improve readability for documentation-heavy answers. Existing documentation should be checked for table-layout and equation-rendering regressions.
  • React widget advances to v0.4.7 — Rapid releases (#1415, #1418, #1424, #1426) add custom sizing and default-open behavior (#1389), smoother transitions (#1423, #1425), and a fix for stray undefined output (#1355). Pin the widget version and visually regression-test embeddings before upgrading.
  • Breaking changes — None announced.
