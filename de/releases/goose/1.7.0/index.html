Gans v1.7.0

Gans v1.7.0 Release Notes

🚀 Funktionen

  • Linux-Computersteuerung für Android (Termux) (#3890) – Unterstützung für Computersteuerungsfunktionen auf Android-Geräten über Termux hinzugefügt – Sitzungsfreigabe wieder eingeführt (#4370) – Die Möglichkeit, Sitzungen zwischen Benutzern zu teilen, wurde wiederhergestellt
  • Erweiterungs-Malware-Prüfung (#4272) – Erste Implementierung der Sicherheitsüberprüfung für Erweiterungen zum Schutz vor bösartigem Code
  • Navigation in der Chat-Sitzungsliste (#4360) – Scroll-Status-Unterstützung für verbesserte Navigation in der Chat-Sitzungsliste hinzugefügt
  • Autovisualizer für strukturierte Daten (#4153) – Neue MCP-UI-Funktion zur automatischen Visualisierung strukturierter Daten – Anbietermodellabfrage (#4270) – Die Benutzeroberfläche fragt Anbieter jetzt dynamisch nach ihren unterstützten Modellen

🐛 Fehlerbehebungen

  • ElevenLabs Audio Transcription (#4358) – Probleme bei der Audiotranskription behoben und zusätzliche Protokollierung für besseres Debugging hinzugefügt
  • Benutzerdefinierte Anbieter-URL-Pfade (#4345) – Die Behandlung von abschließenden Schrägstrichen für benutzerdefinierte Anbieter-URLs wurde korrigiert
  • Modaler Bildlauf in der Erweiterungsliste (#4305) - Probleme beim Scrollen im Chatmodus-Erweiterungslistenmodus behoben
  • OpenAI-kompatible Fehlerbehandlung (#4175) – Verbesserte Fehlerbehandlung für OpenAI-kompatible Anbieter mit erweiterter Testabdeckung
  • Fokusring beim Senden von Formularen (#4332) – Probleme mit dem visuellen Fokusring beim Senden von Formularen behoben
  • Timing der Seitenaktualisierung (#4355) – Die Aktualisierungsfunktion wurde korrigiert, indem auf die Fertigstellung des Dokuments gewartet wurde, anstatt Zeitüberschreitungen zu verwenden

🏗️ Aufgaben und Verbesserungen

  • Schneller Modell-Fallback (#4375) – Schnelle Modelle greifen jetzt ordnungsgemäß auf normale Modelle zurück, wenn sie nicht verfügbar sind
  • TODO-Statusverwaltung (#4361) – Der TODO-Status wurde zur besseren Organisation vom Agentenbereich in den Sitzungsbereich verschoben
  • Rezeptfehlerbehandlung (#4363) – Eine elegante Fehlerbehandlung für Rezepte mit verbesserter Dateinamenanzeige wurde implementiert
  • Modaler Refaktor für die Installation von Erweiterungen (#4328) – Die modale Schnittstelle für die Installation von Erweiterungen wurde verbessert
  • Kompaktes UX-Design (#4202) – Vereinfachte und optimierte Benutzeroberfläche für bessere Benutzerfreundlichkeit
  • Verbesserungen beim automatischen Senden (#4282) – Künstliche Verzögerungen entfernt und die Funktion zum automatischen Senden überarbeitet
  • Erweiterung wird geladen (#4271) – Nachrichtenversand blockieren, bis Erweiterungen vollständig bereit sind
  • Verschachtelte Hinweisdateien (#4002) – Das Laden verschachtelter Hinweisdateien für eine bessere Projektorganisation wurde aktiviert
  • Unterstützung für benutzerdefinierte Provider-Ports (#4312) – Unterstützung für Portnummern in benutzerdefinierten OpenAI-Provider-Konfigurationen hinzugefügt – Copilot wieder aktiviert (#3931) – GitHub Copilot-Funktionalität wiederhergestellt
  • Nächtlicher Release-Workflow (#4326) – Richten Sie einen automatisierten Workflow für nächtliche Releases ein

📚 Dokumentation

  • Update der Windows-Anweisungen (#4333) – Aktualisierte und verbesserte Windows-Installations- und Setup-Anweisungen
  • Airgapped Operation Guide (#4063) – Dokumentation für die Ausführung von Goose in Airgap-Umgebungen hinzugefügt
  • Anbieterdokumentation (#4356, #4339) – Liste der verfügbaren Anbieter aktualisiert und Dokumentation zum Tetrate Agent Router Service hinzugefügt
  • AGENTS.md-Standardlesung (#4346) – AGENTS.md-Dateien werden jetzt standardmäßig gelesen, um den Projektkontext zu verbessern
  • Plan-Tutorial (#4309) – Umfassendes Tutorial für Planungsfunktionen hinzugefügt – Korrekturen im CI/CD-Tutorial (#4223) – Fehlerhafte Pipeline-Dokumentation im CI/CD-Tutorial behoben
  • Docker-Tutorial-Links (#4285) – Defekte Links in der Docker-Tutorial-Dokumentation behoben
  • Release-Dokumentation (#4317) – Verbesserte Dokumentation des Release-Prozesses

🔧 Anbieter- und Integrationsaktualisierungen

  • Tetrate Agent Router Service (#4354) – Neuer Anbieter zur Registrierung hinzugefügt – Entfernung der Ollama-Karte (#4348) – Die Ollama-Anbieterkarte wurde vom Begrüßungsbildschirm entfernt – Neuordnung der Anbieterkarte (#4335) – Anbieterkarten neu organisiert und Streaming für Ollama deaktiviert
  • OTLP-Konfiguration (#4292) – Unterstützung für das Lesen der OTLP-Konfiguration aus Konfigurationsdateien und Umgebungsvariablen hinzugefügt

goose v1.7.0

goose v1.7.0 Release Notes

🚀 Features

  • Linux Computer Control for Android (Termux) (#3890) - Added support for computer control functionality on Android devices through Termux
  • Session Sharing Re-introduced (#4370) - Restored the ability to share sessions between users
  • Extension Malware Check (#4272) - Initial implementation of security scanning for extensions to protect against malicious code
  • Chat Session List Navigation (#4360) - Added scroll state support for improved navigation in the chat session list
  • Autovisualiser for Structured Data (#4153) - New MCP-UI feature for automatically visualizing structured data
  • Provider Model Querying (#4270) - UI now queries providers for their supported models dynamically

🐛 Bug Fixes

  • ElevenLabs Audio Transcription (#4358) - Fixed audio transcription issues and added additional logging for better debugging
  • Custom Provider URL Paths (#4345) - Fixed trailing slash handling for custom provider URLs
  • Extension List Modal Scroll (#4305) - Fixed scrolling issues in the chat mode extension list modal
  • OpenAI-Compatible Error Handling (#4175) - Improved error handling for OpenAI-compatible providers with enhanced test coverage
  • Focus Ring on Form Submits (#4332) - Fixed visual focus ring issues when submitting forms
  • Page Refresh Timing (#4355) - Fixed refresh functionality by waiting for document ready instead of using timeouts

🏗️ Chores & Improvements

  • Fast Model Fallback (#4375) - Fast models now gracefully fall back to regular models when unavailable
  • TODO State Management (#4361) - Moved TODO state to session scope from agent scope for better organization
  • Recipe Error Handling (#4363) - Implemented graceful error handling for recipes with improved filename display
  • Extensions Install Modal Refactor (#4328) - Improved the extensions installation modal interface
  • Compact UX Design (#4202) - Simplified and streamlined the user interface for better usability
  • Auto-submit Improvements (#4282) - Removed artificial delays and reworked auto-submit functionality
  • Extension Loading (#4271) - Block message sending until extensions are fully ready
  • Nested Hint Files (#4002) - Enabled loading of nested hint files for better project organization
  • Custom Provider Port Support (#4312) - Added support for port numbers in custom OpenAI provider configurations
  • Copilot Re-enabled (#3931) - Restored GitHub Copilot functionality
  • Nightly Release Workflow (#4326) - Set up automated workflow for nightly releases

📚 Documentation

  • Windows Instructions Update (#4333) - Updated and improved Windows installation and setup instructions
  • Airgapped Operation Guide (#4063) - Added documentation for running Goose in airgapped environments
  • Provider Documentation (#4356, #4339) - Updated available providers list and added Tetrate Agent Router Service documentation
  • AGENTS.md Default Reading (#4346) - AGENTS.md files are now read by default for better project context
  • Plan Tutorial (#4309) - Added comprehensive tutorial for planning features
  • CI/CD Tutorial Fixes (#4223) - Fixed broken pipeline documentation in CI/CD tutorial
  • Docker Tutorial Links (#4285) - Fixed broken links in Docker tutorial documentation
  • Release Documentation (#4317) - Improved release process documentation

🔧 Provider & Integration Updates

  • Tetrate Agent Router Service (#4354) - Added new provider to the registry
  • Ollama Card Removal (#4348) - Removed Ollama provider card from welcome screen
  • Provider Card Rearrangement (#4335) - Reorganized provider cards and disabled streaming for Ollama
  • OTLP Configuration (#4292) - Added support for reading OTLP config from configuration files and environment variables
