Gans v1.19.0

:sparkles: Funktionen

– Generierung der Shell-Vervollständigung über den neuen Unterbefehl completion für Bash, ZSH, Fish und mehr #6313 – OpenAI Codex CLI-Anbieterunterstützung #6263 – Caching-Unterstützung für Anthropic-Modelle über Databricks #6320

  • MCP-Server von clients wie Zed jetzt geehrt (stdio + http) #6230 – MCP-App-Renderer für umfassendere UI-Erlebnisse #6095 – Servernamen werden jetzt für MCP-Erweiterungen im Codemodus verwendet #6284
  • Verbesserte UX für Tool-Aufrufe über execute_code #6205 – JSONL-Streaming-Option für die JSON-Ausgabe #6228 – Standard-ToDo-Nachricht für eine bessere Aufgabenverfolgung #6217 – Auf rmcp 0.12.0 und sacp 10.0.0 aktualisiert (SSE-Transport entfernt) #6304

:bug: Fehlerbehebungen

– Azure OpenAI API-Schlüssel jetzt optional, passend zur Dokumentation #6215 – Klammernotation und mehrere Importstile werden jetzt bei der Codeausführung unterstützt #6290 – Verschachtelte Streaming-Blöcke in OpenAI-Tool-Aufrufen werden korrekt behandelt #6312

  • Werkzeugnamen ohne Unterstriche werden jetzt ordnungsgemäß behandelt #6318 – Die Reihenfolge des Sitzungsverlaufs wird beim Anzeigen einer Sitzung auf dem Desktop nicht mehr geändert #6156 – Die MCP-Benutzeroberfläche sendet jetzt eine Eingabeaufforderungsnachricht, wenn ein Element clicked ist #6207 – Granularität auf Minutenebene für MOIM-Zeitstempel #6294 – Das Installationsskript funktioniert jetzt, wenn es in Bash weitergeleitet wird #6296 – Bash-Syntax in Terminal-Integrationsfunktionen korrigiert #6181
  • Weitere offene Modelle zur Anbieterliste hinzugefügt #6300

:Schraubenschlüssel: Verbesserungen

  • Rezept-Download und Kopieren der YAML-Funktionalität #6201
  • Rezept-Slash-Befehlsanalyse #6173
  • RPI-Rezepte hinzugefügt #6258 – MCP Apps-Ausrüstung für zukünftige Verbesserungen #6286
  • Goose Issue Solver löst jetzt Probleme wie ein Goose Contributor #6321
  • Goose Issue Solver wurde auf das Opus-Modell verschoben #6233 – Protokollierungs- und Analyseverbesserungen für Updater-Prozesse #6208 – Die Toolchain Rust wurde auf 1.92 geändert (derzeit stabil) #6356
  • Vorschau der Werkzeugauswahlstrategie entfernt #6250

:books: Dokumentation

  • Gans für VS-Code-Erweiterung #6262
  • RPI-Tutorial #6261 – Erweiterung für Codemodus und Codeausführung #6255 – Skills-Erweiterung aktualisiert, um .agents/skills-Verzeichnisse zu unterstützen #6199
  • Kompatibilitätshinweis zu Agentenfähigkeiten #6299 – Es wurde klargestellt, dass GOOSE_TERMINAL ~/.zshenv für zsh-Benutzer erfordert #6297 – Vorbehalte bezüglich Datenschutzinformationen in Protokollen #6218
  • Rezept-Deeplink/Open-Parameter-Option #6206 – In-Place- oder Fork-Sitzung bearbeiten #6203

goose v1.19.0

:sparkles: Features

  • Shell completion generation via new completion subcommand for bash, zsh, fish, and more #6313
  • OpenAI Codex CLI provider support #6263
  • Caching support for Anthropic models via Databricks #6320
  • MCP servers from clients like Zed now honored (stdio + http) #6230
  • MCP app renderer for richer UI experiences #6095
  • Server names now used for MCP extensions in code mode #6284
  • Improved UX for tool calls via execute_code #6205
  • JSONL streaming option for JSON output #6228
  • Default todo message for better task tracking #6217
  • Upgraded to rmcp 0.12.0 and sacp 10.0.0 (SSE transport removed) #6304

:bug: Bug Fixes

  • Azure OpenAI API key now optional to match documentation #6215
  • Bracket notation and multiple import styles now supported in code execution #6290
  • Interleaved streaming chunks in OpenAI tool calls handled correctly #6312
  • Tool names without underscores now handled properly #6318
  • Session history order no longer modified when viewing a session in desktop #6156
  • MCP UI now sends prompt message when an element is clicked #6207
  • Minute-level granularity for MOIM timestamps #6294
  • Install script now works when piped into bash #6296
  • Bash syntax corrected in terminal integration functions #6181
  • More open models added to provider list #6300

:wrench: Improvements

  • Recipe download and copy YAML functionality #6201
  • Recipe slash command parsing #6173
  • RPI recipes added #6258
  • MCP Apps plumbing for future enhancements #6286
  • goose issue solver now solves issues like a goose contributor #6321
  • goose issue solver moved to Opus model #6233
  • Logging and analytics improvements for updater processes #6208
  • Rust toolchain bumped to 1.92 (current stable) #6356
  • Tool Selection Strategy preview removed #6250

:books: Documentation

  • goose for VS Code extension #6262
  • RPI tutorial #6261
  • Code mode and code execution extension #6255
  • Skills extension updated to support .agents/skills directories #6199
  • Agent skills compatibility note #6299
  • Clarified GOOSE_TERMINAL requires ~/.zshenv for zsh users #6297
  • Privacy information caveats in logs #6218
  • Recipe deeplink/open param option #6206
  • Edit in place or fork session #6203
