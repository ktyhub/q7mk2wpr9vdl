goose v1.16.0

Minor Veröffentlicht10. Dez. 2025 Quelleaaif-goose/goose Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Gans v1.16.0

🚀 Funktionen

  • Modalauswahl nach der Konfiguration eines Anbieters anzeigen (#6005) – Onboarding erkennt Anbieter anhand des Schlüssels api (#5955)
  • Mehrere Datei-Popups (#5905)
  • Kontextinformationen zur Seitenleiste für Firefox hinzugefügt (#5433) – Aktivieren Sie Rezept-Deeplink-Parameter für die Vorbefüllung (#5757) – ActionRequired (#5897) – Unterstützung beim Laden von Sitzungen in ACP (#5942) – Benutzerdefinierte Header und Optionen zum Umschalten des Schlüsselbunds CLI hinzugefügt (#5017)
  • Automatische Update-Installation (#5345)
  • @goose im Terminal (native Terminalunterstützung) (#5887)
  • Erweiterungsselektor hinter der ALPHA-Flagge (#5892)
  • Goose-Fernzugriff (#5251) – Unterstützung für Mathematik-/Naturwissenschaftssymbologie über Katex hinzufügen (#5773) – Möglichkeit hinzugefügt, Fehlermeldungen im Toast anzuzeigen (#5851)
  • SKILLS.md implementieren – Claude-Kompatibilität (#5760)
  • Scheduler zur Diagnose hinzufügen (#5849)
  • Cors und Token (#5850)
  • Markdown-Export von URL (#5830) – Komprimierungstest außerhalb des Kontexts über Fehler-Proxy hinzugefügt (#5805) – Endpunkt /agent/stop hinzufügen, maximale Anzahl aktiver Agenten konfigurierbar machen (#5826) – Anbietername und Modellkonfiguration in der Sitzung beibehalten (#5419)
  • Slash-Befehle (#5718) – MCP-UI-Proxy und bessere Nachrichtenverarbeitung (#5487) – WAL mit Commit-Transaktionsverwaltung wieder aktiviert (#5793)
  • Provider-Fehler-Proxy zur Simulation verschiedener Fehlerarten (#5091) – Metriken zu Posthog (#6024)

🐛 Fehlerbehebungen

  • Parameter werden in Aktivitäten nicht ersetzt (#5992) – final assistant content cannot end with trailing whitespace-Fehler von Anthropic (#5967) – Groq-Konfigurationsfix (#5833)
  • Eingabeaufforderungsänderung entfernen, Modell aus Konfiguration lesen (#5976) – Verwenden Sie eine Sperre, um sicherzustellen, dass der Tunnel nur für den Fall mehrerer Durchgänge ausgeführt werden muss … (#5885)
  • „Zusammengeführte aufeinanderfolgende Assistentenmeldungen“ wurde zu den akzeptablen Problemen für die Moim-Injection-Prüfung hinzugefügt (#5933) – Abrufen des Anthropic-Provider-Modells (#5932) – MCP-UI fügt CSP für Bilder zum Proxy-HTML hinzu (#5931)
  • Tippfehler im Blogbeitrag (AIMDOEL -> AIMODEL) korrigiert (#5902) – Passen Sie seltsame Abstände in agent.rs an (#5877)
  • „Aktive Erweiterungen nicht laden, wenn keine Erweiterungen im Rezept vorhanden sind“ zurücksetzen (#5871)
  • Multi-Tool-Aufruf behoben (#5855)
  • Bessere Handhabung mehrerer Inhaltsblöcke und Bilder (#5839)
  • GitHub kaputte Läufer für Macos (#5853)
  • Generische Prüfung auf Gemini-Kompatibilität (#5842) – Sitzungen kommen mit leeren Nachrichten zurück (#5841) – Abwärtskompatibilität für den Nachrichtentyp „conversationCompacted“ hinzugefügt (#5819)
  • Behandeln Sie 404s (#5791) – Setx-Aufrufe entfernen, um den Windows-Shell-PATH nicht dauerhaft zu bearbeiten (#5821) – Maas-Modelle für GCP-Vertex-Anbieter analysieren (#5816)
  • Unterstützen Sie die Gedankensignaturen von Gemini 3 (#5806)
  • Cron-Fehler abfangen (#5707) – Pfade aus einer interaktiven & Login-Shell lesen (#5774) – Schnellkorrektur für das Community-All-Stars-Skript (#5798)

✨ Verbesserungen

  • Rezeptsymbol im leeren Chat ausblenden (#6022) – Anthropic- und Google Gemini-Modelle auf die neuesten API-Versionen aktualisieren (#5980) – Aktualisierung der Bereinigungsmarkierungslogik für Fedora-Benutzer (#5868) – Verbessern Sie das Laden von AWS-Anmeldeinformationen und die Konfigurationsverarbeitung in BedrockProvider (#5699)
  • Rezeptaktionen in das Symbol der unteren Leiste verschieben und Goosehints in den Einstellungen bearbeiten (#5864)
  • Aktualisieren Sie rmcp auf 0.9.1 (#5860) – Schlagen Sie vor, beim Abrufen von Inhalten Text/Markdown zu verwenden (#5854)
  • Es hängen einige alte Codes herum und erwähnen die Konfiguration von cli (#5822)
  • Nächster Camp-Refactor live (#5706) – Kommentieren Sie die unzuverlässigen mcp-Aufrufer aus (#5827)
  • Adrian Cole zu den Betreuern hinzufügen (#5815) – Experimentelle Autopilot-Funktion entfernen (#5781) – Links zu Betreuerprofilen hinzufügen (#5788)
  • LF-Feedback integrieren (#5787) – Npm-Pakete aktualisieren (#5951)

📚 Dokumentation

  • Tutorial zum Chat-Rückruf (#5975)
  • Rat von mir MCP (#5979)
  • Nano-Bananen-Erweiterung (#5977) – Videos zur Seite mit mehreren Modellen hinzufügen (#5938)
  • Planungsleitfaden bewerben (#5934) – Hinzufügen KI-freundlicher Funktionen (#5918) – Einführung der KI-Ankündigung (#5917)
  • Blog-Tippfehler behoben (#5896)
  • Blog korrigiert Bild-URL (#5895) – MCPs für Entwickler (#5884) – Extension Manager MCP (#5883)
  • Blogbeitrag „Aufbau eines Social-Media-Agenten“ hinzufügen (#5844) – Dokumentation zur DataHub MCP-Servererweiterung hinzufügen (#5769)
  • Kleinbuchstaben in den verbleibenden Themen (#5861) – Kleinbuchstaben in den Themen „Erste Schritte“ und „Leitfäden“ (#5857)
  • Menü „Neues Fenster dokumentieren“ im macOS-Dock (#5811)
  • ACP clients (#5800)
  • Document Mistral AI-Anbieter (#5799)
  • Community Stars-Rezeptskript und TXT-Datei hinzufügen (#5776)
  • Schnellstarter (#5779) Vollständig Changelog: v1.15.0...v1.16.0

goose v1.16.0

🚀 Features

  • Show modal selector after configuring a provider (#6005)
  • Onboarding detect provider from api key (#5955)
  • Multiple file popups (#5905)
  • Added sidebar contextual information for firefox (#5433)
  • Enable recipe deeplink parameters for pre-population (#5757)
  • ActionRequired (#5897)
  • Support loading sessions in acp (#5942)
  • Added custom headers and toggle keyring CLI options (#5017)
  • Automatic update installation (#5345)
  • @goose in terminal (native terminal support) (#5887)
  • Extension selector behind ALPHA flag (#5892)
  • Goose remote access (#5251)
  • Add support for math / science symbology via katex (#5773)
  • Add ability to see error message in toast (#5851)
  • Implement SKILLS.md - claude compatibility (#5760)
  • Add scheduler to diagnostics (#5849)
  • Cors and token (#5850)
  • Markdown export from URL (#5830)
  • Add out of context compaction test via error proxy (#5805)
  • Add /agent/stop endpoint, make max active agents configurable (#5826)
  • Persist provider name and model config in the session (#5419)
  • Slash commands (#5718)
  • MCP-UI Proxy and Better Message Handling (#5487)
  • Re-enabled WAL with commit transaction management (#5793)
  • Provider error proxy for simulating various types of errors (#5091)
  • Metrics on posthog (#6024)

🐛 Bug Fixes

  • Params not being substituted in activities (#5992)
  • final assistant content cannot end with trailing whitespace error from Anthropic (#5967)
  • Groq configure fix (#5833)
  • Remove prompt change, read model from config (#5976)
  • Use a lock to ensure only need to run tunnel just in case multiple go… (#5885)
  • Added "Merged consecutive assistant messages" to the acceptable issues for moim injection check (#5933)
  • Anthropic provider model fetching (#5932)
  • MCP-UI add CSP for images to proxy HTML (#5931)
  • Correct typo in blog post (AIMDOEL -> AIMODEL) (#5902)
  • Adjust strange spacing in agent.rs (#5877)
  • Revert "do not load active extensions when no extensions in the recipe" (#5871)
  • Fix multi tool calling (#5855)
  • Handle multiple content chunks & images better (#5839)
  • GitHub broke runners for macos (#5853)
  • Generic check for gemini compat (#5842)
  • Sessions coming back with empty messages (#5841)
  • Add backward compatibility for conversationCompacted message type (#5819)
  • Handle 404s (#5791)
  • Remove setx calls to not permanently edit the windows shell PATH (#5821)
  • Parse maas models for gcp vertex provider (#5816)
  • Support Gemini 3's thought signatures (#5806)
  • Catch cron errors (#5707)
  • Read paths from an interactive & login shell (#5774)
  • Quick fix for community all stars script (#5798)

✨ Improvements

  • Hide recipe icon in empty chat (#6022)
  • Update Anthropic and Google Gemini models to latest API versions (#5980)
  • Update cleanup marker logic for Fedora users (#5868)
  • Improve AWS credential loading and configuration handling in BedrockProvider (#5699)
  • Move recipe actions to bottom bar icon and edit goosehints to settings (#5864)
  • Upgrade rmcp to 0.9.1 (#5860)
  • Suggest using text/markdown when fetching content (#5854)
  • Some old code hanging around, and mention configure cli (#5822)
  • Next camp refactor live (#5706)
  • Comment out the flaky mcp callers (#5827)
  • Add Adrian Cole to Maintainers (#5815)
  • Remove autopilot experimental feature (#5781)
  • Add links to maintainer profiles (#5788)
  • Incorporate LF feedback (#5787)
  • Upgrade npm packages (#5951)
