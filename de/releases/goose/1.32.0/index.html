🐛 Fehlerbehebungen

– TLS-Zertifikat auf der Festplatte zwischenspeichern, um einen langsamen Start beim ersten Start zu vermeiden #8174 – Preprompt wurde nach dem Laden der Sitzung angezeigt #8744 – Fehlendes Delta-Feld in Streaming-Chunks behandeln #8700 – Akzeptieren Sie Streaming-Blöcke mit beiden Begründungsfeldern im OpenAI-Anbieter #8715 – strict:false für Antworten API-Tools und gpt-5.4 auf bekannte Modelle #8636 – Korrigierte Grammatik in der App-Ansichtsbeschreibung #8679

  • Links im Chat konnten nicht geöffnet werden #8544 – Shell-Tool unter bash/sh ausführen, unabhängig von der Login-Shell #8659 – /chat/completions für vorangestellte v1-Basis-URLs anhängen #8521 – Richten Sie die Metadaten des Kimicode-Modells mit dem Live-Kimi-Code API #8588 aus. – Stoppen Sie die 300-ms-Re-Rendering-Schleife im Leerlauf, die die TUI überfluten könnte #8616 – Platzhalter für Chat-Ladezustandsmodell #8431 – Werkzeugaufrufe standardmäßig erweitern, wenn der Antwortstil auf „Detailliert“ eingestellt ist #8478 – Erstellen Sie ein Protokollverzeichnis, bevor Sie das LLM-Anforderungsprotokoll schreiben #8522 – Token-Nutzungsverfolgung und konfigurierbares Stream-Timeout für Ollama-Anbieter aktivieren #8493 – Verwenden Sie die SQLX-Chrono-Dekodierung für Thread-Zeitstempel anstelle der manuellen Analyse #8575 – Doppelte Umrandung von Inhalten im Chat entfernen #8545 – Selbstsignierte Zertifikate vom konfigurierten externen Goos-Host akzeptieren #8400 – Seitenleistensitzungen nach dem Löschen des Chatverlaufs synchronisieren #7707 – Sitzungsblockierung verhindern, wenn im Headless-Modus eine Tool-Genehmigung erforderlich ist #7915 – Eliminierung der Verzögerung von ca. 5 Sekunden beim Öffnen des Bedienfelds „Modelle wechseln“ bei einem lokalen Anbieter #8626 – Hartcodierte Abhängigkeit von goose-acp-macro entfernt #8753 – Laden des OpenAI-Schnellmodells für openapi-kompatiblen benutzerdefinierten Endpunkt stoppen #8644

🔧 Verbesserungen

  • Fitnessstudio-Szenario Cargo-Projekte vom übergeordneten Arbeitsbereich isolieren #8640

  • Unix domain socket transport for StreamableHttp MCP #7860
  • Cash App extension in Extensions Library #8622
  • /edit command for on-demand prompt editing #8566

  • Cache TLS cert to disk to avoid slow startup on first launch #8174
  • Preprompt would show after loading session #8744
  • Handle missing delta field in streaming chunks #8700
  • Accept streaming chunks with both reasoning fields in OpenAI provider #8715
  • strict:false for Responses API tools and gpt-5.4 to known models #8636
  • Correct grammar in apps view description #8679
  • Links in chat could not be opened #8544
  • Run shell tool under bash/sh regardless of login shell #8659
  • Append /chat/completions for prefixed v1 base URLs #8521
  • Align Kimicode model metadata with live Kimi Code API #8588
  • Stop idle 300ms re-render loop that could OOM the TUI #8616
  • Chat loading-state model placeholder #8431
  • Expand tool calls by default when Response Style is Detailed #8478
  • Create logs dir before writing LLM request log #8522
  • Enable token usage tracking and configurable stream timeout for Ollama provider #8493
  • Use sqlx chrono decode for thread timestamps instead of manual parsing #8575
  • Remove double border on content in chat #8545
  • Accept self-signed certs from configured external goosed host #8400
  • Sync sidebar sessions after chat history deletion #7707
  • Prevent session hang when tool approval required in headless mode #7915
  • Eliminate ~5s delay when opening Switch Models panel with local provider #8626
  • Removed hardcoded dependency of goose-acp-macro #8753
  • Stop load openai fast model for openapi compatible custom endpoint #8644

🔧 Improvements

  • Split agent setup into staged phases to reduce startup blocking #8746
  • Extensions management migrated to ACP+ #8733
  • Harden code review skill for async state and default-resolution bugs #8740
  • Persist and reliably apply chat model selection #8734

  • Sidebar activity indicators, placeholder token, and search field refinements #8606
  • Warm shell PATH lookup during session init #8631
  • Gate perf logs and dedup build_config_update on first message #8627
