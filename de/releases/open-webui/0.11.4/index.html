Behoben

  • 🛡️ Sicherheitshinweis: Diese Version enthält Sicherheits- und Zugriffskontrollkorrekturen. Wir empfehlen, Produktionsbereitstellungen so bald wie möglich zu aktualisieren. Möglicherweise sind nicht alle Sicherheitsfixes in dieser Version im Abschnitt „Fixed“ aufgeführt. Einige werden möglicherweise für kurze Zeit zurückgehalten, um Administratoren Zeit für ein Upgrade zu geben. Hinweise
  • 🔑 Token bleiben aus den Protokollen entfernt. Ein Fehler bei der Anmeldung bei einem Identitätsanbieter schreibt die übergebenen Anmeldeinformationen nicht mehr in das Anwendungsprotokoll, sondern zeichnet stattdessen den Anbieter und den von ihm gemeldeten Fehler auf. #29709
  • 🔐 Anmelderollenzuordnung. Von einem Identitätsanbieter gesendete Rollen wurden in einigen Setups nicht angewendet, sodass ein Konto auf der Standardrolle belassen wurde und eine Anmeldung, deren Rollen nicht gelesen werden können, jetzt abgelehnt und nicht durchgelassen wird. Festschreiben
  • 🚫 Blockierte Anmeldegruppen gespeichert. Durch Kommas getrennte Gruppennamen, die in das Feld „Blockierte Gruppen“ eingegeben werden, werden jetzt nach dem Speichern wirksam, wobei beim Speichern der Text als geschrieben gespeichert und bei der Anmeldeprüfung dann als nichts gelesen wurde; Ein Gruppenname, der ein eigenes Komma trägt, überlebt auch einen Speichervorgang. Festschreiben
  • 🚪 Durch das Abmelden wird die Sitzung beendet. Durch das Abmelden oder den Widerruf jedes Tokens wurde jede Live-Verbindung, die das Konto bereits hatte, aufgehoben, und diese werden jetzt im selben Moment getrennt; Ein bereits widerrufener Token kann nicht mehr wiederholt werden, um die neuere Sitzung einer anderen Person zu unterbrechen. Festschreiben
  • 🛡 Diagramme und SVG bleiben an diesem Ursprung. Meerjungfrau-Diagramme und SVG-Vorschauen, angehängt oder hochgeladen, folgen nicht mehr Referenzen, die auf einen anderen Ursprung zeigen, ein Bild, einen Stil oder eine Konfigurationslinie dazwischen, und ein Diagramm, das nach außen reicht, wird mit einem Fehler abgelehnt; Eine Datei, deren Zeichnung auf einem externen Sprite basiert, zeigt diesen Teil jetzt leer an. #30271
  • 📲 Terminalsitzungen folgen Zugriffsänderungen. Eine Terminalverbindung überprüft jetzt alle zehn Sekunden Ihren Zugriff erneut, solange sie geöffnet bleibt. Wenn Sie also die Erlaubnis einer Person entfernen oder ihr Konto deaktivieren, wird ihr Live-Terminal bei der nächsten Überprüfung beendet, und zwar bei jedem Mitarbeiter und nicht nur bei dem, über den er sich angemeldet hat. Festschreiben, Festschreiben
  • 🔒 Zugriff auf die Auflistung von Verbindungsmodellen. Die Endpunkte, die die Modelle auf einer einzelnen Ollama- oder OpenAI-Verbindung auflisten, können von einem angemeldeten Konto mit einer beliebigen Rolle erreicht werden und prüfen nun die Rolle des Anrufers. #29619
  • 🔏 Zugriff auf Wissensdateien. Der Zugriff auf eine Datei über eine Wissensdatenbank folgt jetzt nur noch ihrem eigentlichen Anhang und nicht auch einem Sammlungsnamen, der im Dateidatensatz zurückbleibt. #29937
  • 🌳 Wissensverzeichnisse bleiben in ihrer Datenbank. Eine den Wissensdateirouten bereitgestellte Verzeichnis-ID wird jetzt abgelehnt, wenn sie zu einer anderen Wissensdatenbank gehört, in der eine vom Aufrufer bereitgestellte ID in einen Verzeichnisbaum außerhalb der angesprochenen gelangen könnte. Commit, #29887
  • 🍪 Cookie-Weiterleitungsbereich.   • 📷 Anhänge werden ohne Text gesendet. Beim Senden eines Bildes oder einer Datei ohne Text an ein Modell mit angehängten Fertigkeiten wurde die leere Nachricht durch die Liste der Fertigkeitsnamen ersetzt, sodass das Modell mit seinem eigenen Katalog geantwortet hat, anstatt sich anzusehen, was Sie gesendet haben. #30045, #30040
  • 🖍️ SVG-Anhänge werden als Text gelesen. Eine an einen Chat angehängte SVG-Datei ging als Bild hoch und wurde von jedem Modell, das versuchte, sie zu dekodieren, abgelehnt. Sie wird nun stattdessen als Quelltext gelesen, was ein Modell erfordert, das Datei-Uploads akzeptiert. #30102, #30100
  • 🩹 Notizen überleben eine kleine Bearbeitung.   • 📋 Platzierung von Notizeneinfügungen. Eine einfache Einfügung ersetzte mehr von der Notiz als ausgewählt wurde, und eine Einfügung in einen Codeblock brach aus dem Block heraus, anstatt in ihn hineinzugehen; beide landen nun genau dort, wo sie abgeworfen wurden. Commit

  • 🤝 Das Teilen von Notizen bleibt auch nach dem Speichern bestehen. Durch das Speichern einer Notiz, auf die Sie Zugriff hatten, wurde das Teilen verloren, sodass die Notiz privat wurde und alle anderen sie verloren haben. #30175

  • ⏳ Genauigkeit des Sitzungsablaufs. Eine Sitzung mit einem Identitätsanbieter läuft jetzt mit dem Token ab, mit dem sie tatsächlich aufruft, und nicht mit dem Token, das zuerst abgelaufen ist, wodurch sie vorzeitig erneuert und bei jedem Fehlschlagen abgebrochen wurde. Commit
  • 🧩 Tool-Schritte in fertigen Antworten. Web search through searchapi.io now reports a bad key instead of coming back empty, reads the news results it returns alongside its ordinary ones, and hands the web loader the resolved destination link, so citations stop pointing at a redirect page. #30308, #30305
  • 🔼 Honest version checks. An instance that cannot reach the release listing now says the check failed, instead of reporting whatever it is running as the newest version and recording nothing about it. #29626, #29580
  • 🏟️ Arena models report their errors. A message to an arena model whose provider answers with an error now shows that error in the chat, where it used to fail on something unrelated and leave the real reason unsaid, and titles and tags no longer break the same way. #29662, #29658
  • 🏳️ Nameless tool calls fail once. A model endpoint that sends a tool call with no name at all now has that call fail on the spot, rather than the missing name being kept, stored with the message and sent back on the next turn for the endpoint to reject. #29690, #29686
  • 🧹 Direct connections stop leaking listeners. A server talking to a direct connection no longer leaves a listener behind for every request that ends any way but a clean finish, which grew without limit while a connection kept failing. #29509
  • 🚀 Cheaper model refreshes. The model registry shared through Redis is now written only when the models themselves change, rather than on every refresh because of the countdown Ollama attaches to a model it holds in memory. Commit

Asking for the rest of a cut-off reply in a temporary chat replaced what was on screen with only the new text, because the message being continued was read back from the saved chat it did not have. It is now taken from the request before the model is called, the continuation joins the same message instead of arriving as a second one, on a connection whose provider is set to llama.cpp the model is told to carry on from the text it is handed rather than repeat it back, opening the result in the message editor no longer shows a line break where the two halves meet, and, where haptic feedback is switched on, a continuation buzzes as it streams like any other reply.   • 🔗 Cancelled edits keep attachments. Cancelling the edit of a message no longer strips the files attached to it, where dropping the edit took the attachments down with it. #30281, #30192
  • 🏎️ Faster media page reads. The browser-driven loader pulled every image, video and font a page referenced down through the server before any text was extracted, so a page carrying a few dozen audio players took ten seconds or timed out.   • 📝 Starting a note from search.   • 📱 Apple device replies. An assistant reply no longer comes up blank in a home screen app, an in-app browser or a desktop-class window on Apple devices, where the check that avoided the drawing fault only recognised Safari itself. #29734, #29688, #26712
  • 📊 Single source relevance. A reply drawing on a single source now shows how relevant that source is, where the figure appeared only once a second source joined it and so looked as though it came and went. #29647, #29646
  • 🔧 Arduino sketches upload to knowledge. A sketch file now reaches the plain text reader like the C++ and header files beside it, rather than being handed to a document extraction server that could make nothing of it and failing the upload. #29673, #29670

  • 🔦 Readable slash command labels. The entries in the slash command menu no longer show as white text on a white background in the light theme. #29512, #29510

  • 🖱️ A plain note date. The date under a note title no longer shows a pointing hand or announces itself as something to press, having never done anything when clicked. #29708
  • 🌇 Folder backgrounds on creation. The background image picked in the Create Folder dialog now arrives on the folder when it is created from the sidebar, where the image was discarded unless the dialog was opened from an existing folder. #30218, #30217
  • 🖇 Delete Chat shortcut everywhere. The keyboard shortcut that deletes the open chat now works wherever the chat was opened from, where it did nothing unless the chat's row happened to be on screen in the sidebar at that moment. #30165, #30164
  • 🚮 Retired chat variables. A model whose system prompt no longer declares a variable a previous prompt did stops asking for it, where every new chat kept opening the dialog and refusing to send until a value was entered. #30173, #30172
  • 👁️ Compact hover previews in Safari. Holding over a chat in the sidebar shows the small preview every other browser shows, rather than one laid out at the width and spacing of a full conversation. #29734
  • 🔖 Visible title generation faults. When a new chat's automatic title cannot be generated, the reason now reaches the log at the default level, rather than only under debug logging where a broken feature looked the same as a switched-off one. #30106, #29533

Changed

  • 🪶 Slim starts with nothing configured. The slim image leaves out the local models and the libraries around them, and still starts and holds a conversation on its defaults; the features that leaned on those models each need an external service of their own. Commit
  • 🗄️ Slim database support. The slim image runs on SQLite, its default, or on PostgreSQL; pointed at MySQL, MariaDB or another engine, or started with AWS RDS IAM logins switched on, it stops with an error instead of starting, and those deployments need the standard image. Commit
  • 📁 Slim file storage. The slim image keeps files on local storage, its default; configured for an S3, Google Cloud or Azure bucket, it stops with an error instead of starting, and those deployments need the standard image. Commit
  • 🧮 Slim searches only through pgvector. Knowledge search on the slim image needs PostgreSQL with pgvector, and configured for another vector store the instance still starts, and the failure arrives the first time something is searched rather than at startup. Commit, Commit
  • 🧠 Slim embedding requirements. The slim image carries no embedding or reranking model, so knowledge needs OpenAI, Ollama or Azure OpenAI embeddings and an external reranker, falling back to plain cosine scoring where none is set. Commit
  • ✂️ Slim document splitting. Splitting a document along a downloaded tokenizer is unavailable on the slim image, which leaves splitting by character or by token count. Commit
  • 📃 Slim document readers. The slim image reads text, Markdown, CSV, HTML and XML files as they are; uploading a PDF, a Word file or a presentation fails unless one of the external document extractors is configured. Commit
  • 🎙️ Slim speech requirements. The slim image carries neither local Whisper nor local voices, so speech to text and text to speech need an external engine before they will work. Commit
  • 🕸️ Slim web page fetching. The slim image carries no headless browser, so a web page is fetched over plain HTTP or through an external loader, and a page that draws itself with JavaScript comes back with less of its content than on the standard image. Commit, Commit
  • 🔎 Slim leaves out DDGS. DDGS, the metasearch provider that needs no key of its own, is not carried in the slim image, so web search there needs a provider with a key. Commit
  • 📥 Slim code interpreter packages. The slim image leaves out the code interpreter's packages, so the browser fetches numpy, pandas, matplotlib, scikit-learn and the rest from "cdn.jsdelivr.net" and the interpreter stops working where that is blocked. Commit
  • 🧰 Slim git requirements. The slim image no longer carries git, so a tool or function whose requirements point at a "git+https://" address fails to install and needs the standard image or a published package. Commit
  • 🧺 LangChain community removal. The readers for text, HTML, Word, CSV, PDF and Azure Document Intelligence are now written here rather than taken from "langchain-community", which is no longer installed; a tool or function importing it has to name it in its own requirements from now on. Commit
  • 🧾 Undeclared package imports. Packages that sat in the image only by accident, among them nltk, pymongo, the Google Drive client and the Gemini SDK, are no longer installed, so a tool or function importing one must name it in its own requirements. #29725, #29726, Commit
  • 🆔 Model ID whitespace. A workspace model whose ID contains a space or a tab is now refused in the editor, through the API and on import; one already stored goes on answering but cannot be saved again until it is recreated. Commit
  • 🖇️ Link scheme rendering. A link in a reply, a citation or a web search result is now rendered only where it points at a web address, a mail address, a telephone number or somewhere inside this instance; anything else, an "ftp://" address or an application link such as "obsidian://" or "vscode://" among them, is shown as the text it is. Two old oddities go with it: a source written as "HTTP://" now becomes a link, and a filename merely containing the letters http no longer becomes one that leads nowhere. #29890
  • 🧲 Integrations tab is opt-in. The Integrations tab in personal settings, where tool and terminal connections of your own are managed, is now hidden until an administrator turns on Direct Integrations under Integrations or sets "ENABLE_DIRECT_INTEGRATIONS", and hiding it leaves existing connections working. Commit, Commit
  • 📡 Image connection check endpoint. The endpoint that checks an image generation connection has moved and now takes the connection to test in the request itself, so anything calling the old address needs updating. Commit
