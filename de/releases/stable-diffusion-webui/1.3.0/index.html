stable-diffusion-webui v1.3.0

Minor Veröffentlicht27. Mai 2023 QuelleAUTOMATIC1111/stable-diffusion-webui Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Stable-Diffusion-Webui v1.3.0

Funktionen:

  • Benutzeroberfläche hinzufügen, um Standardeinstellungen zu bearbeiten
  • Token-Zusammenführung (über dbolya/tomesd)
  • Überarbeitung der Registerkarte „Einstellungen“: viele zusätzliche Erklärungen und Links hinzugefügt
  • Laden Sie die Git-Metadaten der Erweiterungen parallel zum Laden des Hauptprogramms, um beim Start viel Zeit zu sparen
  • Erweiterungstabelle aktualisieren: Zweig anzeigen, Datum in separater Spalte anzeigen und Version von Tags anzeigen, falls verfügbar
  • TAESD – eine weitere Option für günstige Live-Vorschauen
  • Auswahl des Probenehmers und Eingabeaufforderungen für den zweiten Durchgang der Einstellungsreparatur möglich – standardmäßig ausgeblendet, in den Einstellungen aktiviert
  • Hashes für Lora berechnen
  • Lora-Hashes zum Infotext hinzufügen
  • Verwenden Sie beim Einfügen von Infotext die Lora-Hashes von Infotext, um lokale Loras für <lora:xxx:1>-Einträge zu finden, deren Hashes mit den Loras des Benutzers übereinstimmen
  • Wählen Sie in der Benutzeroberfläche die Option „Queraufmerksamkeitsoptimierung“ aus

Moll:

  • Erhöhen Sie Gradio auf 3.31.0
  • Erhöhen Sie PyTorch auf 2.0.1 für macOS und Linux AMD
  • Ermöglicht das Festlegen von Standardwerten für Elemente in den Registerkarten der Erweiterungen
  • ermöglicht die Auswahl des Dateityps für Live-Vorschauen
  • Bei der ersten Anzeige wird „Laden...“ für zusätzliche Netzwerke angezeigt
  • ENSD-Infotext für Sampler unterdrücken, die ihn nicht verwenden
  • clientside-Optimierungen
  • Optionen hinzufügen, um versteckte Dateien und Verzeichnisse in zusätzlichen Netzwerken anzuzeigen/auszublenden und Modelle/Dateien in versteckten Verzeichnissen nicht aufzulisten
  • Leerzeichen in der Datei „styles.csv“ zulassen
  • Option zum Neuanordnen von Tabs hinzufügen
  • Verschieben Sie einige Funktionen (Auflösung tauschen und Seed auf -1 setzen) nach client
  • Option zum Festlegen der Editorhöhe für img2img
  • Schaltfläche zum Kopieren der Bildauflösung in die Breiten-/Höhenregler von img2img
  • Wechsel von Pyngrok zu Ngrok-py
  • Lazy-Load-Bilder in der Benutzeroberfläche für zusätzliche Netzwerke
  • Setzen Sie die Option „Bildbetrachter mit Gamepad navigieren“ auf Anfrage standardmäßig auf „false“.
  • Upscaler so ändern, dass sie Modelle in ein vom Benutzer angegebenes Verzeichnis herunterladen (von Befehlszeilenargumenten) und nicht in die Standardversion models/<...>
  • Ausblenden von Schaltflächen in ui-config.json zulassen

Erweiterungen:

  • /sdapi/v1/script-info api hinzufügen
  • Verwenden Sie Ruff, um den Python-Code zu fusseln
  • Verwenden Sie ESlint, um den Javascript-Code zu linten
  • CFG-Rückrufe für die Erweiterung „Self-Attention Guidance“ hinzufügen/ändern
  • Befehl und Endpunkt hinzufügen, um den Server ordnungsgemäß zu stoppen
  • Fügen Sie einige lokale Elemente (Eingabeaufforderungen/Seeds/usw.) aus der Verarbeitungsfunktion als Felder in die Verarbeitungsklasse ein
  • Überarbeitung der Zitate für Infotextelemente, die Kommas enthalten, um JSON zu verwenden (sollte abwärtskompatibel sein, außer in Fällen, in denen es zuvor nicht funktionierte)
  • /sdapi/v1/refresh-loras api Checkpoint-Post-Anfrage hinzufügen
  • testet Überholung

Fehlerbehebungen:

  • Behebung eines Problems, das den Start des Programms verhindert, wenn der Benutzer ein schlechtes Gradio-Thema angibt
  • Fehlerhafte Eingabeaufforderungen aus dem Dateiskript beheben
  • Symlink-Scanning für zusätzliche Netzwerke behoben
  • Fix --data-dir wurde beim Start über webui-user.bat COMMANDLINE_ARGS ignoriert
  • Erlauben Sie, dass die Web-Benutzeroberfläche vollständig offline ausgeführt wird
  • Behebung der Unfähigkeit, mit --freeze-settings zu laufen
  • Behebung der Unfähigkeit, Prüfpunkte zusammenzuführen, ohne Metadaten hinzuzufügen
  • Problem behoben, bei dem beim Speichern des Vorschaubilds zusätzlicher Netzwerke kein Infotext für JPEG/WebM hinzugefügt wurde
  • Entfernen Sie den Blinkeffekt aus dem Text in der Hires-Fix- und Skalierungsauflösungsvorschau
  • Sorgen Sie dafür, dass Links zu http://<...>.git-Erweiterungen im Erweiterungs-Tab funktionieren
  • Fehler behoben, bei dem WebUI beim Start hängen blieb, weil der Git-Prozess hängen blieb

Englisches Original / English original

stable-diffusion-webui v1.3.0

Features:

  • add UI to edit defaults
  • token merging (via dbolya/tomesd)
  • settings tab rework: add a lot of additional explanations and links
  • load extensions' Git metadata in parallel to loading the main program to save a ton of time during startup
  • update extensions table: show branch, show date in separate column, and show version from tags if available
  • TAESD - another option for cheap live previews
  • allow choosing sampler and prompts for second pass of hires fix - hidden by default, enabled in settings
  • calculate hashes for Lora
  • add lora hashes to infotext
  • when pasting infotext, use infotext's lora hashes to find local loras for <lora:xxx:1> entries whose hashes match loras the user has
  • select cross attention optimization from UI

Minor:

  • bump Gradio to 3.31.0
  • bump PyTorch to 2.0.1 for macOS and Linux AMD
  • allow setting defaults for elements in extensions' tabs
  • allow selecting file type for live previews
  • show "Loading..." for extra networks when displaying for the first time
  • suppress ENSD infotext for samplers that don't use it
  • clientside optimizations
  • add options to show/hide hidden files and dirs in extra networks, and to not list models/files in hidden directories
  • allow whitespace in styles.csv
  • add option to reorder tabs
  • move some functionality (swap resolution and set seed to -1) to client
  • option to specify editor height for img2img
  • button to copy image resolution into img2img width/height sliders
  • switch from pyngrok to ngrok-py
  • lazy-load images in extra networks UI
  • set "Navigate image viewer with gamepad" option to false by default, by request
  • change upscalers to download models into user-specified directory (from commandline args) rather than the default models/<...>
  • allow hiding buttons in ui-config.json

Extensions:

  • add /sdapi/v1/script-info api
  • use Ruff to lint Python code
  • use ESlint to lint Javascript code
  • add/modify CFG callbacks for Self-Attention Guidance extension
  • add command and endpoint for graceful server stopping
  • add some locals (prompts/seeds/etc) from processing function into the Processing class as fields
  • rework quoting for infotext items that have commas in them to use JSON (should be backwards compatible except for cases where it didn't work previously)
  • add /sdapi/v1/refresh-loras api checkpoint post request
  • tests overhaul

Bug Fixes:

  • fix an issue preventing the program from starting if the user specifies a bad Gradio theme
  • fix broken prompts from file script
  • fix symlink scanning for extra networks
  • fix --data-dir ignored when launching via webui-user.bat COMMANDLINE_ARGS
  • allow web UI to be ran fully offline
  • fix inability to run with --freeze-settings
  • fix inability to merge checkpoint without adding metadata
  • fix extra networks' save preview image not adding infotext for jpeg/webm
  • remove blinking effect from text in hires fix and scale resolution preview
  • make links to http://<...>.git extensions work in the extension tab
  • fix bug with webui hanging at startup due to hanging git process
