stabile-diffusion-webui v1.7.0

Funktionen:

  • Überarbeitung der Registerkarte „Einstellungen“: Suchfeld hinzufügen, Kategorien hinzufügen, Seite mit UI-Einstellungen in mehrere aufteilen
  • altdiffusion-m18-Unterstützung hinzufügen (#13364)
  • unterstützt Inferenz mit LyCORIS GLora-Netzwerken (#13610)
  • Lora-Embedding-Bundle-System hinzufügen (#13568)
  • Option zum Verschieben der Eingabeaufforderung aus der oberen Zeile in die Generierungsparameter
  • Unterstützung für SSD-1B hinzufügen (#13865)
  • unterstützt Inferenz mit OFT-Netzwerken (#13692)
  • Skriptmetadaten und DAG-Sortiermechanismus (#13944)
  • unterstützt HyperTile-Optimierung (#13948)
  • Unterstützung für SD 2.1 Turbo hinzufügen (#14170)
  • Entfernen Sie die Registerkarte „Train->Preprocessing“ und legen Sie alle Funktionen auf der Registerkarte „Extras“ ab
  • anfängliche IPEX-Unterstützung für Intel Arc GPU (#14171)

Moll:

  • Ermöglicht das Lesen von Modell-Hash aus Bildern im img2img-Batch-Modus (#12767)
  • Option zur Anpassung an die Sampling-Implementierung von SGM Repo hinzufügen (#12818)
  • zusätzliches Feld für Lora-Metadaten-Viewer: ss_output_name (#12838)
  • Aktion auf der Einstellungsseite hinzufügen, um alle SD-Checkpoint-Hashes zu berechnen (#12909)
  • Schaltfläche zum Kopieren der Eingabeaufforderung in den Stileditor hinzufügen (#12975)
  • Option --skip-load-model-at-start hinzufügen (#13253)
  • Infotext zu GIF-Bildern schreiben
  • Infotext aus GIF-Bildern lesen (#13068)
  • erlaubt die Konfiguration des Anfangszustands von InputAccordion in ui-config.json (#13189)
  • Bearbeitung von Leerzeichentrennzeichen für die Eingabeaufforderungsbearbeitung mit Strg+Auf/Strg+Ab ermöglichen (#13444)
  • versehentliches Schließen von Popup-Dialogen verhindern (#13480)
  • Option hinzugefügt, um den Benachrichtigungston abzuspielen oder nicht (#13631)
  • Vorschaubild im Vollbild-Bildbetrachter anzeigen, falls verfügbar (#13459)
  • Unterstützung für webui.settings.bat (#13638)
  • Option hinzufügen, um Stack-Traces bei Strg+C nicht zu drucken
  • Generierung mit Strg (Alt) + Eingabetaste starten/neu starten (#13644)
  • Skript „prompts_from_file“ aktualisieren, um die Verkettung von Einträgen mit der allgemeinen Eingabeaufforderung zu ermöglichen (#13733)
  • Ein sichtbares Kontrollkästchen zur Eingabe von Akkordeon hinzugefügt
  • Option hinzugefügt, um alle txt2img/img2img-Parameter in einem Akkordeon auszublenden (#13826)
  • Sortieroption „Pfad“ für zusätzliche Netzwerkkarten hinzugefügt (#13968)
  • Eingabeaufforderungs-Hotkeys im Style-Editor aktivieren (#13931)
  • Option zum Anzeigen von Batch-img2img-Ergebnissen in der Benutzeroberfläche (#14009)
  • Infotext-Updates: Option hinzufügen, um bestimmte Infotextfelder zu ignorieren, Option hinzufügen, um VAE nicht in den Infotext einzubeziehen, Erklärung zur Infotext-Einstellungsseite hinzufügen, einige Optionen auf die Infotext-Einstellungsseite verschieben
  • FP32-Fallback-Unterstützung für sd_vae_ approx hinzufügen (#14046)
  • unterstützt XYZ-Skripte / Split-Hires-Pfad von unet (#14126)
  • Verwendung von CSV-Dateien mit mehreren Stilen zulassen (#14125)

  • Funktion onEdit für js hinzufügen und token-counter.js überarbeiten, um sie zu verwenden
  • Behebung der Schlüsselfehlerausnahme bei der Verarbeitung von override_settings-Schlüsseln (#13567)

stable-diffusion-webui v1.7.0

Features:

  • settings tab rework: add search field, add categories, split UI settings page into many
  • add altdiffusion-m18 support (#13364)
  • support inference with LyCORIS GLora networks (#13610)
  • add lora-embedding bundle system (#13568)
  • option to move prompt from top row into generation parameters
  • add support for SSD-1B (#13865)
  • support inference with OFT networks (#13692)
  • script metadata and DAG sorting mechanism (#13944)
  • support HyperTile optimization (#13948)
  • add support for SD 2.1 Turbo (#14170)
  • remove Train->Preprocessing tab and put all its functionality into Extras tab
  • initial IPEX support for Intel Arc GPU (#14171)

Minor:

  • add option to align with sgm repo's sampling implementation (#12818)
  • extra field for lora metadata viewer: ss_output_name (#12838)
  • add action in settings page to calculate all SD checkpoint hashes (#12909)
  • add button to copy prompt to style editor (#12975)
  • add --skip-load-model-at-start option (#13253)
  • write infotext to gif images
  • read infotext from gif images (#13068)

  • added option to play notification sound or not (#13631)
  • show the preview image in the full screen image viewer if available (#13459)
  • support for webui.settings.bat (#13638)
  • add an option to not print stack traces on ctrl+c

  • added a visible checkbox to input accordion
  • added an option to hide all txt2img/img2img parameters in an accordion (#13826)
  • added 'Path' sorting option for Extra network cards (#13968)
  • enable prompt hotkeys in style editor (#13931)
  • option to show batch img2img results in UI (#14009)

  • update is_installed() from launch_utils.py to fix reinstalling already installed packages (#14192)
