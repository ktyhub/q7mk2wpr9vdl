Hermes-Agent v2026.3.12

Hermes Agent v0.2.0 (v2026.3.12)

Veröffentlichungsdatum: 12. März 2026

Erste getaggte Veröffentlichung seit v0.1.0 (der ersten voröffentlichen Gründung). In etwas mehr als zwei Wochen entwickelte sich Hermes Agent von einem kleinen internen Projekt zu einer voll ausgestatteten KI-Agentenplattform – dank einer Explosion von Community-Beiträgen. Diese Version deckt 216 zusammengeführte Pull-Anfragen von 63 Mitwirkenden ab und löst 119 Probleme.

✨ Highlights

  • Multi-Plattform-Messaging-Gateway – Telegram-, Discord-, Slack-, WhatsApp-, Signal-, E-Mail- (IMAP/SMTP) und Home Assistant-Plattformen mit einheitlicher Sitzungsverwaltung, Medienanhängen und Toolkonfiguration pro Plattform.
  • MCP (Model Context Protocol) Client – Native MCP-Unterstützung mit stdio- und HTTP-Transporten, Wiederverbindung, Ressourcen-/Prompt-Erkennung und Sampling (serverinitiierte LLM-Anfragen). (#291 — @0xbyt4, #301, #753)
  • Skills-Ökosystem – Über 70 gebündelte und optionale Skills in mehr als 15 Kategorien mit einem Skills Hub für Community-Entdeckung, Aktivierung/Deaktivierung pro Plattform, bedingte Aktivierung basierend auf der Tool-Verfügbarkeit und Voraussetzungsvalidierung. (#743 — @teyrebaz33, #785 — @teyrebaz33)
  • Zentralisierter Anbieter-Router – Unified call_llm()/async_call_llm() API ersetzt verstreute Anbieterlogik in den Bereichen Vision, Zusammenfassung, Komprimierung und Trajektorienspeicherung. Alle Hilfsverbraucher durchlaufen einen einzigen Codepfad mit automatischer Auflösung der Anmeldeinformationen. (#1003)
  • ACP-Server – VS Code-, Zed- und JetBrains-Editor-Integration über den Agent Communication Protocol-Standard. (#949)
  • CLI Skin/Theme Engine – Datengesteuerte visuelle Anpassung: Banner, Spinner, Farben, Branding. 7 integrierte Skins + benutzerdefinierte YAML-Skins.
  • Git Worktree Isolation – hermes -w startet isolierte Agentensitzungen in Git Worktrees für sicheres paralleles Arbeiten am selben Repo. (#654)
  • Dateisystem-Prüfpunkte und Rollback – Automatische Snapshots vor destruktiven Vorgängen mit /rollback zur Wiederherstellung. (#824)
  • 3.289 Tests – Von einer nahezu Null-Testabdeckung bis hin zu einer umfassenden Testsuite, die Agent, Gateway, Tools, Cron und CLI abdeckt.

Hermes Agent v0.2.0 (v2026.3.12)

Release Date: March 12, 2026

First tagged release since v0.1.0 (the initial pre-public foundation). In just over two weeks, Hermes Agent went from a small internal project to a full-featured AI agent platform — thanks to an explosion of community contributions. This release covers 216 merged pull requests from 63 contributors, resolving 119 issues.

✨ Highlights

  • Multi-Platform Messaging Gateway — Telegram, Discord, Slack, WhatsApp, Signal, Email (IMAP/SMTP), and Home Assistant platforms with unified session management, media attachments, and per-platform tool configuration.

  • MCP (Model Context Protocol) Client — Native MCP support with stdio and HTTP transports, reconnection, resource/prompt discovery, and sampling (server-initiated LLM requests). (#291 — @0xbyt4, #301, #753)

  • Skills Ecosystem — 70+ bundled and optional skills across 15+ categories with a Skills Hub for community discovery, per-platform enable/disable, conditional activation based on tool availability, and prerequisite validation. (#743 — @teyrebaz33, #785 — @teyrebaz33)

  • Centralized Provider Router — Unified call_llm()/async_call_llm() API replaces scattered provider logic across vision, summarization, compression, and trajectory saving. All auxiliary consumers route through a single code path with automatic credential resolution. (#1003)

  • ACP Server — VS Code, Zed, and JetBrains editor integration via the Agent Communication Protocol standard. (#949)

  • CLI Skin/Theme Engine — Data-driven visual customization: banners, spinners, colors, branding. 7 built-in skins + custom YAML skins.

  • Git Worktree Isolation — hermes -w launches isolated agent sessions in git worktrees for safe parallel work on the same repo. (#654)

  • Filesystem Checkpoints & Rollback — Automatic snapshots before destructive operations with /rollback to restore. (#824)

  • 3,289 Tests — From near-zero test coverage to a comprehensive test suite covering agent, gateway, tools, cron, and CLI.
