Hermes-Agent v2026.6.5

Hermes-Agent v0.16.0 (v2026.6.5)

Veröffentlichungsdatum: 5. Juni 2026 Seit v0.15.2: 874 Commits · 542 zusammengeführte PRs · 1.962 geänderte Dateien · 205.216 Einfügungen · 46.217 Löschungen · 399 geschlossene Probleme (2 P0, 62 P1, 16 mit Sicherheitsmarkierungen) · 170 Community-Mitwirkende (einschließlich Co-Autoren)

The Surface Release. Hermes trifft Sie, wo auch immer Sie arbeiten. Eine brandneue native Desktop-App – erstellt über 100 PRs und 159 Commits in einer einzigen Woche – bietet Ihnen Hermes als echte macOS/Linux/Windows-Anwendung: eine click-Installation, In-App-Selbstaktualisierung, Drag-and-Drop-Dateien in den Chat, eine Inline-Modellauswahl in der Statusleiste, gleichzeitige Multi-Profil-Sitzungen, eine vollständige vereinfachte chinesische Übersetzung und die Möglichkeit, über OAuth oder eine Verbindung zu einem Remote-Hermes-Gateway herzustellen Benutzername/Passwort. Daneben wurde das Web-Dashboard um ein vollständiges browserbasiertes Verwaltungspanel erweitert (MCP-Katalog, Messaging-Kanäle, Anmeldeinformationen, Webhooks, Speicher, steckbares OIDC/Benutzername-Passwort-Login) und die Ersteinrichtung verfügt über einen „Quick Setup via Nous Portal“-Pfad, der Sie in Sekundenschnelle von der Installation bis zur ersten Nachricht führt. Der Standard-Skill-Satz wurde auf das getrimmt, was Sie tatsächlich benötigen, NVIDIA/skills wurde den trusted Skills Hub-Taps hinzugefügt, die Modellauswahl ist jetzt überall durchsuchbar (Desktop, Web, TUI, CLI) und mit /undo können Sie endlich die letzten N Runden zurücknehmen. 2 P0- und 62 P1-Verschlüsse fahren mit, plus eine Sicherheitsrunde (CVE-2026-48710 Starlette-Stift, SSRF-Off-Loop-Härtung, Subprozess-Credential-Stripping).

✨ Highlights

  • Hermes Desktop – eine echte native App, kein Terminal-Wrapper – Das ist die Überschrift. Es gibt jetzt eine apps/desktop/ Electron-Anwendung, die wie jede andere Desktop-App auf macOS, Linux und Windows installiert wird, sich selbst aus der App heraus aktualisiert und Ihnen eine ausgefeilte GUI für alles bietet, was Hermes tut. Sie erhalten ein richtiges Chat-Fenster mit Streaming, eine Sitzungsliste, die Sie archivieren und durchsuchen können, Dateien per Drag-and-Drop an eine beliebige Stelle im Chat-Bereich, clipboard-Bildeinfügung, eine Cmd+K-Befehlspalette und eine Modellauswahl direkt in der Statusleiste. Wenn Sie Freunden erzählt haben, dass es sich um einen CLI-Agenten handelt, und beobachtet haben, wie ihre Augen glasig werden, können Sie ihnen jetzt einfach einen Installer schicken. Vor einer Woche gab es davon noch nichts. (#20059, #35607, #37099, #37379, #38631 – @OutThisLife, @jquesnelle, @ethernet8023, @austinpickett, @benbarclay)
  • Führen Sie die Desktop-App gegen ein Remote-Hermes aus – melden Sie sich mit OAuth oder Benutzername/Passwort an – Die Desktop-App muss Hermes nicht lokal ausführen. Richten Sie es auf ein entferntes Hermes-Gateway (Ihr Homelab, eine gehostete Box, den Server eines Teamkollegen) und es verbindet sich über einen sicheren WebSocket und authentifiziert sich mit OAuth oder einem Benutzernamen/Passwort-Login – kein Hantieren mit --insecure-Flags oder handkopierten Sitzungstoken. Jedes Profil kann auf seinen eigenen Remote-Host abzielen, und Sie können gleichzeitige Sitzungen über mehrere Profile hinweg in einem Fenster mit profilübergreifenden @session-Links ausführen. Die praktische Version: Auf Ihrem Laptop läuft eine dünne GUI, der Heavy Agent läuft überall dort, wo Ihre API-Tasten und -Rechner live sind. (#37888, #38851, #39330, #39778 — @benbarclay, @OutThisLife, @teknium1)
  • Das Web-Dashboard ist jetzt ein vollständiges Admin-Panel – konfigurieren Sie alles über den Browser – Das Dashboard hat sich von „Sitzungen anzeigen“ zu einer vollständigen Administrationsoberfläche entwickelt. Es gibt eine Kanalseite, die jede Gateway-Messaging-Plattform (Telegram, Discord, Slack usw.) über den Browser einrichtet, ein Admin-Panel für den MCP-Katalog mit Aktivierungs-/Deaktivierungsschaltern, Anmeldeinformationsverwaltung, Webhook- und Hook-Erstellung, Speicherkonfiguration, Gateway-Steuerelemente und eine Systemseite mit Prüfung vor dem Update und One-click-Debug-Freigabe. Sie müssen sich nicht mehr über SSH anmelden und config.yaml bearbeiten, um einen neuen Messaging-Kanal oder MCP-Server einzurichten – jetzt ist alles Point-and-click. (#36704, #36736, #37211, #38205, #38600 — @teknium1)
  • Hermes Desktop spricht vereinfachtes Chinesisch – vollständiges 简体中文 in der Chat-GUI – Die Desktop-App liefert jetzt eine vollständige Übersetzung in vereinfachtes Chinesisch (简体中文) auf jeder Benutzeroberfläche – dem Chat-Fenster selbst, der Seitenleiste, den Einstellungen, der Befehlszentrale, Cron, Messaging, Profilen, Fähigkeiten, Agenten usw. Englisch bleibt die Standardeinstellung; Wechseln Sie die Sprache in den Darstellungseinstellungen und die Auswahl bleibt in Ihrer Konfiguration (display.language) bestehen. Es basiert auf einer ordnungsgemäß typisierten i18n-Ebene, sodass das Hinzufügen weiterer Sprachen von hier aus problemlos möglich ist. (#38241 — @JimLiu)
  • Reduzierter Standard-Fähigkeitssatz – Hermes versendet nur das, was Sie tatsächlich benötigen – Der gebündelte Fähigkeitssatz wurde bewusst gekürzt. Überflüssige oder tote Fähigkeiten sind verschwunden (spotify – ersetzt durch die 7 Tools des nativen Spotify-Plugins; linear – ersetzt durch hermes mcp install linear; kanban-codex-lane, debugging-hermes-tui-commands, ein veraltetes domain-Waise und mehrere leere Kategoriemarkierungen). Schwerere oder Nischenfähigkeiten wurden von gebündelt auf optional verschoben (das Baoyu-Kreativset, dspy, subagent-driven-development, minecraft-modpack-server, pokemon-player, hermes-s6-container-supervision) – immer noch einen hermes skills install entfernt, nur nicht standardmäßig geladen. Und ein neues environments:-Relevanzgate hält kontextspezifische Fertigkeiten (Kanban, docker/s6) aus dem Fertigkeitsindex für Benutzer fern, die sie nie verwenden werden, lädt sie aber dennoch auf ausdrückliche Anfrage. Das Ergebnis: eine kleinere, schärfere Standardfähigkeitsliste, weniger Rauschen in der Auswahl und eine einfachere Eingabeaufforderung. Der Kurator kann jetzt auch ungenutzte integrierte Fertigkeiten (nicht nur vom Agenten erstellte) bereinigen, wobei die Nutzung für jede Fertigkeit nachverfolgt wird. (#39028, #36701, #36228 — @teknium1)
  • NVIDIA/skills ist jetzt ein integrierter trusted-Skills-Tap – NVIDIA/skills schließt sich OpenAI, Anthropic und HuggingFace als standardmäßiger trusted-Tap im Skills Hub an – erkennbar, durchsuchbar, durchsuchbar und automatisch aktualisierbar über dieselbe Pipeline. NVIDIAs verifizierte Fähigkeiten für CUDA-X, AIQ, cuOpt und den Rest ihres Produktstacks sind nur eine Installation entfernt, mit echten Kategoriebezeichnungen aus dem skills.sh.json-Beiwagen des Repos. (#34333 — @teknium1)
  • Schnelle Einrichtung über das Nous-Portal – von der Installation bis zur ersten Nachricht in Sekunden – Die erstmalige Einrichtung wurde auf zwei klare Pfade reduziert: Schnelle Einrichtung (mit Nous-Portal anmelden, Modellauswahl erhalten, sofort mit dem Chatten beginnen) oder vollständige Einrichtung (der detaillierte Assistent für Power-User). hermes portal ist jetzt der für Menschen lesbare Alias, der den vollständigen Nous-Schnelleinrichtungsablauf ausführt. Das erste Menü erklärt den Unterschied direkt, sodass Neulinge nicht raten müssen. Das Ziel: Ein brandneuer Benutzer sollte keine Dokumente lesen müssen, um seine erste Nachricht zu senden. (#35723, #36227, #38449, #38465 — @teknium1, @kshitijk4poor)
  • Fuzzy-Modellauswahl, überall – geben Sie ein paar Buchstaben ein, finden Sie Ihr Modell – Die Modellauswahl führt jetzt eine Fuzzy-Suche in der Desktop-App, dem Web-Dashboard, TUI und CLI durch. Typ „v4fl“ und deepseek-v4-flash-Oberflächen; Multi-Endpunkt-Anbieter werden in einer Zeile gruppiert, anstatt die Liste mit Duplikaten zu überladen, und jede Zeile enthält eine Beschreibung, damit Sie wissen, was Sie auswählen. Der Katalog wird stündlich statt täglich aktualisiert, sodass neue Modelle noch am Tag ihrer Markteinführung angezeigt werden. Neu in diesem Fenster: deepseek-v4-flash, MiniMax-M3 mit 1M-Kontext, qwen3.7-plus. (#36928, #35227, #35756, #35659, #36214 — @kshitijk4poor, @teknium1)
  • /undo [N] – die letzten N Kurven zurücknehmen – Das Falsche gesagt oder den Agenten auf die falsche Fährte geschickt? /undo sichert N Benutzerrunden, füllt Ihre letzte Nachricht vorab aus, damit Sie sie bearbeiten und erneut senden können, und löscht die dazwischen liegenden Runden vorläufig. Es funktioniert im CLI, der TUI und auf allen Messaging-Plattformen (Telegram, Discord usw.) mit voller Parität. Schließt eine seit langem bestehende Anfrage (#21910). (#36229, #36699 — @teknium1)
  • Wählen Sie Ihre Standardschnittstelle – cli oder tui – Sie können jetzt festlegen, ob hermes chat Sie standardmäßig zur klassischen CLI oder zur Ink-TUI weiterleitet, mit einem --cli-Flag zum Überschreiben pro Aufruf. Die TUI verfügt außerdem über einen einzigen einheitlichen /model-Befehl und ein Sitzungs-Overlay zum Wechseln zwischen Live-Sitzungen. Nutzen Sie die Schnittstelle, die Ihnen tatsächlich gefällt. (#37782, #37112 — @OutThisLife)

Hermes Agent v0.16.0 (v2026.6.5)

Release Date: June 5, 2026 Since v0.15.2: 874 commits · 542 merged PRs · 1,962 files changed · 205,216 insertions · 46,217 deletions · 399 issues closed (2 P0, 62 P1, 16 security-tagged) · 170 community contributors (including co-authors)

The Surface Release. Hermes meets you wherever you work. A brand-new native desktop app — built across 100 PRs and 159 commits in a single week — gives you Hermes as a real macOS/Linux/Windows application: one-click install, in-app self-update, drag-and-drop files into chat, an inline model picker in the status bar, concurrent multi-profile sessions, a full Simplified Chinese translation, and the ability to connect to a remote Hermes gateway over OAuth or username/password. Alongside it, the web dashboard grew a full browser-based administration panel (MCP catalog, messaging channels, credentials, webhooks, memory, pluggable OIDC / username-password login), and first-time setup got a "Quick Setup via Nous Portal" path that gets you from install to first message in seconds. The default skill set was trimmed to what you actually need, NVIDIA/skills joined the trusted Skills Hub taps, the model picker is now fuzzy-searchable everywhere (desktop, web, TUI, CLI), and /undo finally lets you take back the last N turns. 2 P0 and 62 P1 closures ride along, plus a security round (CVE-2026-48710 Starlette pin, SSRF off-loop hardening, subprocess credential stripping).

✨ Highlights

  • Hermes Desktop — a real native app, not a terminal wrapper — This is the headline. There's now a apps/desktop/ Electron application that installs like any other desktop app on macOS, Linux, and Windows, updates itself in place from inside the app, and gives you a polished GUI for everything Hermes does. You get a proper chat window with streaming, a session list you can archive and search, drag-and-drop files anywhere in the chat area, clipboard image paste, a Cmd+K command palette, and a model picker right in the status bar. If you've been telling friends "it's a CLI agent" and watching their eyes glaze over — now you can just send them an installer. None of this existed a week ago. (#20059, #35607, #37099, #37379, #38631 — @OutThisLife, @jquesnelle, @ethernet8023, @austinpickett, @benbarclay)

  • Run the desktop app against a remote Hermes — sign in with OAuth or username/password — The desktop app doesn't have to run Hermes locally. Point it at a remote Hermes gateway (your homelab, a hosted box, a teammate's server) and it connects over a secure WebSocket, authenticating with OAuth or a username/password login — no fiddling with --insecure flags or hand-copied session tokens. Each profile can target its own remote host, and you can run concurrent sessions across multiple profiles in one window with cross-profile @session links. The practical version: your laptop runs a thin GUI, the heavy agent runs wherever your API keys and compute live. (#37888, #38851, #39330, #39778 — @benbarclay, @OutThisLife, @teknium1)

  • The web dashboard is now a full admin panel — configure everything from the browser — The dashboard grew from "view your sessions" into a complete administration surface. There's a Channels page that sets up every gateway messaging platform (Telegram, Discord, Slack, etc.) from the browser, an admin panel for the MCP catalog with enable/disable toggles, credential management, webhook and hook creation, memory configuration, gateway controls, and a System page with check-before-update and one-click Debug Share. You no longer have to SSH in and edit config.yaml to wire up a new messaging channel or MCP server — it's all point-and-click now. (#36704, #36736, #37211, #38205, #38600 — @teknium1)

  • Hermes Desktop speaks Simplified Chinese — full 简体中文 in the chat GUI — The desktop app now ships a complete Simplified Chinese (简体中文) translation across every UI surface — the chat window itself, sidebar, settings, command center, cron, messaging, profiles, skills, agents, the lot. English stays the default; switch language in Appearance settings and the choice persists to your config (display.language). It's built on a proper typed i18n layer, so adding more languages from here is straightforward. (#38241 — @JimLiu)

  • Leaner default skill set — Hermes ships only what you actually need — The bundled skill set got a deliberate trim. Skills that were redundant or dead are gone (spotify — superseded by the native Spotify plugin's 7 tools; linear — superseded by hermes mcp install linear; kanban-codex-lane, debugging-hermes-tui-commands, a stale domain orphan, and several empty category markers). And a new environments: relevance gate keeps context-specific skills (kanban, docker/s6) out of the skills index for users who'll never use them, while still loading them on explicit request. The result: a smaller, sharper default skill list, less noise in the picker, and a lighter prompt. The curator can now prune unused built-in skills too (not just agent-created ones), with usage tracked for every skill. (#39028, #36701, #36228 — @teknium1)

NVIDIA's verified skills for CUDA-X, AIQ, cuOpt and the rest of their product stack are one install away, with real category labels from the repo's skills.sh.json sidecar. (#34333 — @teknium1)
