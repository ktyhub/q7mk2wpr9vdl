Hermes-Agent v0.23.0

Hermes-Agent v0.23.0

Veröffentlichungsdatum: 5. November 2026 Seit v0.22.0: ~10.080 Commits · ~1.950 zusammengeführte PRs · ~8.720 Dateien geändert · ~725.200 Einfügungen · ~201.400 Löschungen · ~850 Probleme geschlossen · 666 Mitwirkende

The Hearth Release. In den alten Hymnen behielt Hermes die Schwelle und Hestia den Herd, und die beiden wurden Seite an Seite geehrt. v0.22.0 brachte Neulinge durch die Tür; v0.23.0 entfacht das Feuer, um das sie sich versammeln. Die Überschrift: Ihr gesamter Desktop-Arbeitsbereich wird jetzt in einem Browser-Tab geöffnet, der von Ihrem eigenen Gateway bedient wird. Darunter lebt jede Konversation an einem Ort: Ein einzelnes Gateway ist für jede Sitzung verantwortlich, und CLI, TUI, Desktop, Editoren, Bots und Cron sitzen alle an einem Tisch, anstatt dass jeder seinen eigenen Agenten ausführt. Von diesem einen Herd aus hält der Desktop jeden Computer, auf dem Sie Hermes ausführen, gleichzeitig verbunden, Gruppenchats leiten ihre eigenen Konversationen weiter, und das Terminal zeichnet schließlich Ihre Bilder inline und ermöglicht Ihnen, eine Konversation zurückzuspulen. Drumherum: Plugins, die sich selbst auf dem neuesten Stand halten, Preisschilder und Ausgabenlimits für kostenpflichtige MCP-Tools, steckbare Delegation, ein Plugin-Katalog, der von etwa 600 auf über 1.050 Einträge angewachsen ist, ein schlankeres integriertes Skillset und eine lange Speicher- und Latenzarbeit für langlebige Gateways. In dieser Version werden die Patch-Versionen v0.22.1–v0.22.7 zusammengefasst und vollständig dokumentiert.

✨ Highlights

  • Ihr Desktop-Arbeitsbereich in einem Browser-Tab – Die neue Webapp bedient den gesamten Desktop-Arbeitsbereich von Ihrem eigenen Gateway aus: dieselben Chats, Gruppenchats, Plugins und Einstellungen, in jedem Browser in Ihrem Netzwerk oder hinter einer öffentlichen URL mit Anmeldung. Das Docker-Image und das Nix-Paket liefern es. Es ist standardmäßig deaktiviert. Aktivieren Sie es mit webapp.enabled oder Web Access in den Einstellungen. (#141864, #145598, #145536, #145072, #145153 – @jquesnelle, @BearHuddleston, @IAvecilla, @Adolanium)

  • Ein Gateway besitzt jede Konversation – Früher konnten CLI, TUI, Desktop, Editoren (ACP), Messaging-Bots und Cron jeweils ihre eigene Kopie des Agenten für denselben Chat ausführen, was dazu führte, dass Nachrichten zweimal geschrieben wurden oder zwischen Oberflächen verloren gingen. Jetzt betreibt jede Maschine ein Gateway, das jede Sitzung besitzt, und jede Oberfläche verbindet sich mit ihr als client: Ein Chat, den Sie überall öffnen, ist derselbe Chat, mit einer Warteschlange und einem Verlauf. Sie können eine Eingabeaufforderung in der Warteschlange sogar vom Desktop aus steuern oder bearbeiten, ohne dass sie zweimal ausgeführt wird. (#106742, #140334 – @unsupportedpastels, @kshitijk4poor)

  • Bilder im Terminal – Wenn Sie ein Bild einfügen oder ein Tool einen Screenshot macht, zeichnen CLI und TUI es jetzt direkt im Chat, anstatt einen Dateipfad auszugeben: echte Pixel in Kitty und Ghostty (CLI und TUI) und in iTerm2, WezTerm und Konsole (CLI), farbige Blöcke überall sonst und volle Auflösung im Terminal von VS Code, wenn die Bildunterstützung aktiviert ist. (#147293, #148874 — @Adolanium)

  • Eine Konversation zurückspulen – Drücken Sie zweimal Esc oder geben Sie /rewind in der TUI oder im klassischen CLI ein, wählen Sie eine frühere Nachricht aus, bearbeiten Sie sie und senden Sie sie erneut oder verzweigen Sie von diesem Punkt an eine neue Sitzung. Die ursprüngliche Sitzung bleibt genau so, wie sie war. Die TUI kann /new auch während einer laufenden Kurve starten; das alte läuft im Hintergrund weiter. (#144937, #148880 — @SaguaroDev)

  • Jeder Computer in einem Desktop-Fenster – Desktop hält jetzt alle Ihre Gateways gleichzeitig verbunden, sodass der Wechsel zwischen diesem Computer und einem SSH- oder Remote-Gateway sofort erfolgt. Terminal-Tabs werden auf dem Host ausgeführt, auf dem sie geöffnet wurden, und ein Gruppenchat kann Bots von verschiedenen Computern mischen. (#147681, #147708, #148418 — @dskwe, @janviernine)

  • Gruppenchats, die sich selbst ausführen – In Bot-Modus-Räumen kann ein Lead-Bot oder ein automatischer Router auswählen, wer auf eine Nachricht antwortet, in der niemand genannt wird. Geplante Jobs können in einem Raum gepostet werden, Räume behalten einen Zweck und gemeinsame Notizen und Bots pingen sich nicht mehr in Endlosschleifen gegenseitig an. Räume sehen jetzt auch wie ein normaler Hermes-Chat aus und jeder Bot zeigt live, was er tut („scout · terminal · 7s“). (#144833, #148417, #148888, #148903, #148422 — @KoNit-K)

  • Plugins, die sich selbst auf dem neuesten Stand halten – hermes plugins update aktualisiert alles auf einmal, und ein optionaler Schalter für die automatische Aktualisierung (CLI, Chat, Desktop und Dashboard) hält Katalog- und Git-Plugins auf dem neuesten Stand. Updates, die Ihr Setup beschädigen würden, werden zurückgehalten statt angewendet. Der Katalog selbst wuchs von etwa 600 auf über 1.050 Einträge, und eine neue Verifiziert-Stufe kennzeichnet Plugins, die vom Anbieter selbst erstellt wurden. (#141513, #85794, #143468, #144257 – @charan-rathore, @YS-OH-CORE)

  • Preisschilder und Ausgabenlimits für kostenpflichtige Tools – Kostenpflichtige MCP-Tools wie 3D oder Mediengenerierung können angeben, was ein Anruf kostet. Die Genehmigungsaufforderung zeigt den Preis jedes Anrufs und die laufende Summe des Chats an, und Hermes fragt nach, bevor ein Chat sein Limit überschreitet, selbst im YOLO-Modus. (#142470, #143780, #143795, #143787 — @liuhao1024, @fangliquanflq)

  • Neue offizielle Plugins und ein kleinerer Kern – Meshy (Text und Bild in 3D), ElevenLabs Music and Sound Effects, X Chat, REA (Reverse Engineering) und eine Bubblewrap-Sandbox sind jetzt Installationen mit nur einem Befehl. Camofox, mcp-serve, die Agenten-Importeure und Singularity sind vom Kern in Plugins übergegangen, die sich für jeden, der sie verwendet, selbst installieren. (#142619, #146294, #139725, #143484, #139983)

  • Wählen Sie, wie Subagenten ausgeführt werden – Die Delegierung ist jetzt anpassbar: Behalten Sie die Standardeinstellung bei oder installieren Sie das offizielle advanced-delegation-Plugin, um jede Subagentenaufgabe an ein benanntes Modell oder an ein separates Profil zu senden. Wechseln Sie mit /delegation. (#142563, #142564, #143423)

  • Leichter und schneller, insbesondere wenn Hermes den ganzen Tag läuft – Wiederkehrende Cron-Jobs teilen sich einen Prompt-Cache, One-Shot-Läufe senden etwa 1.570 Prompt-Tokens pro Aufruf weniger und patch/write_file kehren bei aktiviertem LSP in Millisekunden zurück. Langlebige Gateways geben jetzt den Speicher geschlossener Sitzungen frei und die Desktop-Seitenleiste wird nicht mehr langsamer, wenn sich Sitzungen häufen (ein Store mit ca. 35.000 Cron-Läufen wurde von einer 121-sekündigen Aktualisierung auf eine sofortige Aktualisierung umgestellt). (#139876, #144177, #140387, #147863, #137087, #147819, #144940 — @kshitijk4poor)

  • Ein schlankeres Fertigkeitsset, das Sie sperren können – Die integrierten Fertigkeiten stiegen von 58 auf 44, wobei Word, PowerPoint und Excel in einer microsoft-office-Fähigkeit zusammengeführt wurden. hermes curator lock verhindert, dass der Agent einen von Ihnen manuell kuratierten Skill mit einem beliebigen Tool umschreibt, sogar im YOLO-Modus. (#147557 — @daviseford)

  • Passwort-Manager und ein Schlüsselbund-Tresorschlüssel – Verifizierte Passwort-Manager-Plugins können Ihre Anmeldungen an den Browser weitergeben, ohne die anderer zu sehen, und der Schlüssel des Browser-Tresors kann jetzt in Ihrem Betriebssystem-Schlüsselbund gespeichert werden. (#143964, #144246 — @Jesssullivan)

  • Stoppen Sie einen laufenden Cron-Job – Brechen Sie einen laufenden Job über den CLI, den Desktop, den API oder den Agenten selbst ab und legen Sie für jeden Job fest, was mit Ausführungen geschieht, die verpasst wurden, während Hermes ausgeschaltet war. (#144801 — @kokhlo, @fangliquanflq, @LeonSGP43)

⚠️ Upgrade-Hinweise

  • Die alten integrierten Browser-Tools sind weg. Die Browser-Automatisierung läuft nur auf browser_exec; agent-browser und die zehn browser_*-Tools (browser_navigate, browser_click, ...) wurden entfernt. Bei Häusern, die Camofox verwendet haben, wird das camofox-Plugin automatisch installiert. Wenn Ihre eigenen Eingabeaufforderungen, Fertigkeiten oder Toolset-Listen die alten Tools benennen, ändern Sie sie in browser_exec. (#143146)
  • Desktop benötigt macOS 13+ und 64-Bit-Windows. Die App wurde auf Electron 44 verschoben, das nicht mehr auf macOS 11, macOS 12 oder 32-Bit-Windows läuft. (#142727 – @OutThisLife, @Adihaliem)
  • hermes mcp serve ist jetzt hermes mcp-serve (es wurde in ein Plugin verschoben). MCP clients, die Hermes als Server starten, müssen ihre Befehle aktualisieren; nichts schreibt es für dich um.
  • Word-, PowerPoint- und Excel-Kenntnisse sind jetzt eine microsoft-office-Fähigkeit. Alte Kopien bleiben auf der Festplatte, bis Sie sie entfernen.
  • Die Webanwendung ist standardmäßig deaktiviert. Einem Browser wird nichts bereitgestellt, bis Sie webapp.enabled oder Web Access aktivieren.

Claude Mythos wird als stets denkender Mensch behandelt, sodass Argumentationsanfragen nicht schon beim ersten Versuch scheitern. Nemotron 3.5 Super VL erhält Standardparameter. (#145204, #140496, #139466, #148127, #138462 – @benbarclay, @unsupportedpastels, @rroverin)

Die Kommissionierer listen zuerst die empfohlenen Modelle des Plans auf, kennzeichnen sie mit „Groß“ oder „Kostenlos“ und sagen, wann das Kontingent aufgebraucht ist. (#142308, #145682 — @rob-maron)

Es erscheint nur bei Modellen, die im Codex-Katalog Ihres Kontos als genehmigt aufgeführt sind, und wird bei jeder Anfrage erneut überprüft. (#148056 — @unsupportedpastels, @Froraut)

Wiederaufgenommene Chats bleiben auf dem Endpunkt, der sie bedient hat, und der Schlüssel eines integrierten Anbieters gelangt nicht mehr an einen benutzerdefinierten Eintrag mit demselben Namen. (#138513, #139947, #140335, #147761 – @jquesnelle, @unsupportedpastels)

Gemini-Sicherheitsblöcke werden nun als Inhaltsrichtlinienfehler angezeigt und gehen zum Fallback-Modell über. Nur-Text-vLLM-Server, die Bilder ablehnen, werden wiederhergestellt, und Byte-Cap-400er lösen die Komprimierung aus. Auf Bedrock schlägt ein hängender Anruf nach einer statt fünf Lesezeitüberschreitungen fehl. (#140485, #85031, #85005, #85126, #146314 — @Chukwuebuka-2003)
  • Lokale Laufzeit auf llama.cpp b11671 – Fügt DFlash-Entwürfe mit einem Steckplatz und Opt-in-Nemotron 3.5 Bolt hinzu. (#139703 — @jquesnelle)

Agentenschleife und Sitzungen

  • Geringere Prompt-Token- und Cache-Kosten – Jede Auslösung desselben Cron-Jobs teilt sich jetzt einen Prompt-Cache-Schlüssel. Einmalige Hintergrundaufrufe (Zusammenfassungen, Titel, /moa) zahlen nicht mehr für Cache-Schreibvorgänge. One-Shot-Läufe senden pro Aufruf 1.570 Prompt-Tokens weniger, und vier Tool-Schemata sind 319 Token kürzer. Gateway-Ziel- und Heartbeat-Turns, Post-Compaction-Turns und MCP-Aktualisierungen zwischen Turns schreiben das zwischengespeicherte Präfix nicht mehr neu. (#139876, #140478, #144177, #144173, #139865, #139851 — @100yenadmin, @jonpol01, @chelsealong, @AdrianBinDC)
  • Opt-in-vorbereitete Komprimierung – Mit compression.prepare_ahead: true wird die nächste Zusammenfassung im Hintergrund geschrieben, wenn sich eine Sitzung dem Auslöser nähert, sodass die Komprimierung die Runde nicht mehr anhält, während die Zusammenfassung geschrieben wird. In der Zwischenzeit eintreffende Nachrichten bleiben Wort für Wort im Tail. Standardmäßig deaktiviert. (#144684, #144886 — @kshitijk4poor)
  • Verdichtung ist ehrlicher und schwerer aufzuhalten – Zusammenfassungen führen unsichere Behauptungen auf UNVERIFIED:-Linien auf, sodass eine Vermutung nicht als Tatsache gilt. Der Hauptmodell-Fallback verwendet die Hauptroute, /stop schließt einen Zusammenfassungsstrom und in der Warteschlange befindliche Nachrichten sowie /steer überleben einen Kontexterschöpfungs-Reset. (#86019, #139872, #144825, #139783, #139923 – @helix4u, @thehugegatsby)
  • hermes sessions refresh-prompts – Fortlaufende Sitzungen erhalten in ihrer nächsten Runde ein bearbeitetes SOUL.md, Fertigkeiten oder Kontextdateien ohne /new. Der Verlauf wird gespeichert und jede Sitzung erleidet einen Cache-Fehler. (#143581 — @victor-kyriazakos)
  • Opt-in-Stream-Lebensdauerobergrenze – agent.stream_max_lifetime (standardmäßig deaktiviert) unterbricht einen Stream, der nie beendet wird. Timeout-Fehler benennen jetzt die fehlgeschlagene Phase und die zu erhöhende Einstellung. (#80701, #80873 — @krzsda)
  • Bei weiteren Fragen zu einem Foto wird das Foto immer noch angezeigt – Dies gilt nach der Fortsetzung der Serversitzung --resume, API und dem Neustart des Gateways. (#139873 — @Alexbob0)
  • Sitzungsspeicher – Auto-Prune ist wieder aktiviert und Hermes fragt einmal, wenn die Festplatte zur Neige geht. hermes sessions optimize-storage zeigt den Fortschritt an und hat einen echten Laden etwa 18x schneller fertiggestellt. Der Start wartet nicht mehr auf die Scratch-Bereinigung und hermes sessions-Fehler beenden 1. (#139762, #144630, #144625, #144767)

Messaging-Plattformen (Gateway)

  • Ein Gateway besitzt jetzt jede lokale Sitzung – Seit v0.22.0 führen die klassischen CLI-, TUI-, Desktop-, API-, ACP-Editoren, Bots und Cron ihre Sitzungen alle über ein Gateway aus. Dieser Zyklus hat das Problem behoben: Slash-Befehle, /retry, /refine, /review, Karten klären, Begründungsanzeige, Nutzung und ACP-Sitzungen funktionieren wieder und Konfigurationsänderungen erreichen wieder aufgenommene Sitzungen. (#139149, #139577, #139884, #140249, #140595, #141916, #144005, #138719 – @unsupportedpastels, @yoniebans, @drzxk, @fangliquanflq)
  • Gateway-Speicher und Reaktionsfähigkeit – Das etwa einmal pro Minute auftretende Einfrieren während der Speicherbeschneidung ist verschwunden, geschlossene Sitzungen verlassen den Speicher, Glibc-Malloc-Arenen sind auf 4 begrenzt und gemessene Event-Loop-Blocker wurden aus der Schleife entfernt. (#147840, #147831, #147810, #144911, #137156 – @kouyichi, @ygd58, @zwmaupin, @kshitijk4poor)
  • Sichererer Gateway-Lebenszyklus – hermes gateway stop/restart lehnen ab, während Sitzungen aktiv sind, und greifen niemals auf den Dienst eines anderen Zuhauses zurück. Ein vom Terminal eines Agenten gestartetes Gateway verwechselt sich nicht mehr mit dem launchd-Dienst, und wenn jede Plattform beim Start ausfällt, bleibt das Gateway im beeinträchtigten Zustand. (#142041, #145930, #144592, #140922 — @salch-cred)
  • Bot-Modus-Gruppenchats – Cron-Jobs können in einem Raum gepostet werden (deliver: room:<id>@<profile>), wodurch nur die Bots aktiviert werden, die sie @erwähnen. Räume erhalten einen Zweck und gemeinsame Notizen, und zwei Opt-in-Modi legen fest, wer auf eine Nachricht antwortet, die niemanden nennt (ein Lead-Bot oder auto-Routing). message_agent weckt den Fragesteller einmal bei jeder Antwort. (#144833, #148417, #148888, #144789 – @rorsch, @OutThisLife)
  • Bot-zu-Bot-Schleifen enden – Bots erhalten nie Laufzeitbenachrichtigungen und ein Austausch ist nach der letzten menschlichen Nachricht auf max_hops (Standard 4) begrenzt. hermes peer dm <peer>/hermes erreicht den Standard-Bot des Peers. (#148903, #144900 — @KoNit-K)
  • Telegram – Neues Opt-in dm_topic_auto_transfer öffnet ein neues Thema für Root-DM-Nachrichten. Die erste Nachricht eines neuen Themas landet darin, Videonotizen erreichen den Agenten und Gruppennachrichten, die nicht an den Bot adressiert sind, können stumm bleiben. (#141347, #141751, #147572, #147144 – @KoNit-K, @PRELVAS94, @sharpnotebot, @Horizont367, @diegoasanch)
  • Slack, Feishu, Discord – Der Slack-Thread-Kontext umfasst Emoji-Reaktionen und ein neues Opt-in thread_followup_silence deckt unadressierte Thread-Antworten ab. Feishu erhält Aufklärungskarten und eine Auswahlauswahl, die du antippen kannst. Discord respektiert längere Genehmigungsfristen und sendet reines Audio als Anhang. Räume können sich für absichtliche Stille entscheiden. (#80882, #139586, #82170, #145948, #143800, #147143 — @hackartists, @helix4u, @liuhao1024, @nicodoggie)
  • Jeder Messaging-Adapter ist jetzt ein Plugin – Signal, Weixin, BlueBubbles, QQ Bot, Yuanbao und WhatsApp Cloud werden jetzt als gebündelte Plattform-Plugins ausgeliefert. Für die Nutzer ändert sich nichts. (#139843, #140168 — @karljohannisson, @sprmn24)
  • Gestreamte Antworten liefern Bilder – Markdown-Bilder in einer gestreamten Antwort kommen als Bilder an und Tool-Fortschrittsargumente werden in Codeblöcken gerendert. (#144041, #139759 — @686f6c61, @sambouli)

Tools, Browser und Terminal

  • patch und write_file kehren in Millisekunden zurück, wenn LSP aktiviert ist – Eine saubere TypeScript-Bearbeitung ging von 10.1 s auf etwa 0.06 s. Tippfehler gelangen weiterhin ins Modell. (#140387)
  • Intelligentere Hintergrundprozesse – Ein Befehl, der mit einem einzelnen & endet, wird als verfolgter Hintergrundprozess ausgeführt, anstatt abgelehnt zu werden. Anstatt einen stillen Prozess abzufragen, wird der Agent benachrichtigt, wenn er beendet wird. Aufträge, die während einer geschäftigen Runde beendet werden, kommen als eine Runde zurück. (#140317, #140330, #147678 – @lucasfdale, @suhanrain)
  • Passwortmanager in browser_vault – Gebündelte oder verifizierte/offizielle Katalog-Plugins können ihre eigenen Logins über ctx.register_login_backend hinzufügen, und jedes kann nur seine eigenen Einträge bearbeiten. Der Tresorschlüssel kann in den Betriebssystem-Schlüsselbund verschoben werden (Opt-in vault.key_storage: keychain). Gespeicherte Passwörter werden auf Camofox-Seiten ausgefüllt. (#143964, #144246, #146240, #139203 – @Jesssullivan, @WillPlatnick)
  • Mediengenerierung – Krea 3-Bildgenerierung und -bearbeitung über das Nous-Gateway oder den Krea API sowie das Standardbildmodell für zahlende Abonnenten, die sich nicht für eines entschieden haben. Wan 2.7 Video auf FAL. Der Agent kann ElevenLabs-Stimmen in text_to_speech suchen und auswählen. (#142155, #87464, #144633 — @entropidelic)
  • Terminal-Backends – Sandboxing-Backends können uses_host_filesystem = False festlegen, damit die Dateitools in der Sandbox ausgeführt werden, und Plugin-Backends können ihr Startverzeichnis festlegen. Singularity wurde in sein Plugin verschoben. Die Befehlsausgabe verschwindet nicht mehr, sobald ein Prozess mehr als 1024 offene Dateideskriptoren hat. (#143756, #142225, #142561, #142299 – @unsupportedpastels, @aholten, @MohamadKanso)
  • Browser-Zuverlässigkeit – Die Einstellung für das echte Profil funktioniert weiterhin, wenn Chrome das Profil sperrt. Verschachtelte Seitendaten führen nicht mehr zum Absturz der Tools und Screenshots mit ausgeblendeten Registerkarten hängen nicht mehr. (#139245, #140562, #146082 — @cmaldonado80)

Cron, Delegation und Multi-Agent

  • Pluggable Delegation Backends – delegation.backend wählt aus, wie jede delegate_task-Aufgabe zu einer untergeordneten Ausführung wird, und die Standardstrategie ist jetzt ein gebündeltes Plugin. Das offizielle advanced-delegation-Plugin fügt Modellzuordnung und Routing pro Profil hinzu. /delegation <mode> speichert für die nächste Sitzung und --now wendet es sofort an. Mit der Option delegation.prefix_stagger_seconds können Batch-Subagenten den Eingabeaufforderungscache wiederverwenden. (#142563, #142564, #143423, #86553)
  • Stoppen Sie einen laufenden Cron-Job – hermes cron cancel, eine Desktop-Stopp-Schaltfläche, API und cronjob_manage stoppen einen Live-Lauf und das Löschen eines Jobs bricht ihn ab. Jeder Job wählt seine eigene Richtlinie für verpasste Ausführungen (--catch-up on|off). Ein manueller Lauf verbraucht nicht länger einen einmaligen Schuss und Eingabeaufforderungen übertragen die Feuerzeit. (#144801, #146113, #82826 – @kokhlo, @fangliquanflq, @LeonSGP43)
  • Hintergrund-Subagenten überleben und melden sich zurück – Durch das Stoppen einer Runde werden Hintergrund-Subagenten wie /review nicht mehr getötet. /bg und weitergeleitete Chats warten auf ihre Delegationen, und verlorene Abschlüsse werden aus dem Hauptbuch erneut angeboten. (#144759, #147745, #147753, #147748 – @professorpalmer, @nateEc, @rungmc357)
  • Kanban-Arbeiter sind wieder verwendbar – delegate_task und session_search arbeiten in Karten, fehlgeschlagene Versuche geben ihren Platz frei, ein Arbeiter, dessen Sockel fällt, nimmt denselben Versuch wieder auf und Arbeiterzüge werden nicht mehr als Ihre Erinnerungen gespeichert. (#141944, #141906, #145954, #144861 – @tmaarcxs, @nonkun12, @calvinnwq)

Sicherheit und Zuverlässigkeit

Hermes Agent v0.23.0

Release Date: November 5, 2026 Since v0.22.0: ~10,080 commits · ~1,950 merged PRs · ~8,720 files changed · ~725,200 insertions · ~201,400 deletions · ~850 issues closed · 666 contributors

The Hearth Release. In the old hymns Hermes kept the threshold and Hestia kept the hearth, and the two were honored side by side. v0.22.0 got newcomers through the door; v0.23.0 builds the fire they gather around. The headline: your whole Desktop workspace now opens in a browser tab, served by your own gateway. Underneath it, every conversation lives in one place: a single gateway owns each session, and the CLI, TUI, Desktop, editors, bots and cron all sit down at the same table instead of each running its own agent. From that one hearth, Desktop keeps every machine you run Hermes on connected at once, Group Chats route their own conversations, and the terminal finally draws your images inline and lets you rewind a conversation. Around it: plugins that keep themselves updated, price tags and spend limits on paid MCP tools, pluggable delegation, a plugin catalog that grew from about 600 to over 1,050 entries, a leaner built-in skill set, and a long run of memory and latency work for long-lived gateways. This release rolls up and fully documents the v0.22.1–v0.22.7 patch releases.

✨ Highlights

  • Your Desktop workspace in a browser tab — The new Webapp serves the full Desktop workspace from your own gateway: the same chats, Group Chats, plugins and settings, in any browser on your network or behind a public URL with sign-in. The Docker image and Nix package ship it. It is off by default; turn it on with webapp.enabled or Web Access in Settings. (#141864, #145598, #145536, #145072, #145153 — @jquesnelle, @BearHuddleston, @IAvecilla, @Adolanium)

  • One gateway owns every conversation — Before, the CLI, TUI, Desktop, editors (ACP), messaging bots and cron could each run their own copy of the agent against the same chat, which is how messages got written twice or went missing between surfaces. Now each machine runs one gateway that owns every session, and every surface attaches to it as a client: a chat you open anywhere is the same chat, with one queue and one history. You can even steer or edit a queued prompt from Desktop without it running twice. (#106742, #140334 — @unsupportedpastels, @kshitijk4poor)

  • Pictures in the terminal — When you paste an image, or a tool takes a screenshot, the CLI and TUI now draw it right in the chat instead of printing a file path: real pixels in kitty and Ghostty (CLI and TUI) and in iTerm2, WezTerm and Konsole (CLI), coloured blocks everywhere else, and full resolution in VS Code's terminal when its image support is on. (#147293, #148874 — @Adolanium)

  • Rewind a conversation — Press Esc twice or type /rewind in the TUI or classic CLI, pick an earlier message, then edit and resend it or fork a new session from that point. The original session stays exactly as it was. The TUI can also start /new while a turn is still running; the old one keeps working in the background. (#144937, #148880 — @SaguaroDev)

  • Every machine in one Desktop window — Desktop now keeps all your gateways connected at once, so switching between this computer and an SSH or remote gateway is instant. Terminal tabs run on the host they were opened on, and a Group Chat can mix bots from different machines. (#147681, #147708, #148418 — @dskwe, @janviernine)

  • Group Chats that run themselves — Bot Mode rooms can let a lead bot, or an automatic router, pick who answers a message that names nobody. Scheduled jobs can post into a room, rooms keep a purpose and shared notes, and bots no longer ping each other in endless loops. Rooms also look like a normal Hermes chat now, and each bot shows what it is doing live ("scout · terminal · 7s"). (#144833, #148417, #148888, #148903, #148422 — @KoNit-K)

  • Plugins that keep themselves current — hermes plugins update updates everything at once, and an opt-in Auto-update switch (CLI, chat, Desktop and dashboard) keeps catalog and git plugins up to date. Updates that would break your setup are held back instead of applied. The catalog itself grew from about 600 to over 1,050 entries, and a new Verified tier marks plugins built by the vendor itself. (#141513, #85794, #143468, #144257 — @charan-rathore, @YS-OH-CORE)

  • Price tags and spend limits for paid tools — Paid MCP tools, such as 3D or media generation, can declare what a call costs. Skills

  • Lock a skill — after hermes curator lock <skill>, the agent can't change that skill with skill_manage, file edits or terminal writes, even under --yolo, and the curator won't archive it. (#147557 — @daviseford)
  • Leaner built-in skills — a fresh install ships 44 built-in skills instead of 58. Word, PowerPoint and Excel merge into one microsoft-office skill, 12 niche skills become optional installs, and optional skills that vendor repos, catalog MCPs or the built-in web search now cover are removed. The vendor repos for W&B, Qdrant, Pinecone, Notion, Airtable and Shopify are now trusted taps in hermes skills browse. The skills index in the prompt is shorter too.   • Skills survive compaction and load by plugin name — every skill that compaction removes, small or slash-loaded, now leaves a reload marker. Plugin skills are named after their plugin (blender:blender) and load even when the model adds plugin: in front. (#138428, #143822, #143784 — @100yenadmin)
  • unbroker handles spam calls — the optional unbroker skill can now start from a phone number and register it on the US Do Not Call list. (#145118 — @SHL0MS)

MCP

  • Tool costs and per-chat spend limits — MCP servers, from plugin packages or config.yaml, can declare what each tool costs and a spend limit per chat. The approval prompt shows the cost and the chat's running total, and a call that would go over the limit asks first, even on a trusted server or in YOLO mode. (#142470, #143787)
  • Clearer approvals for untrusted servers — choosing Allow for this session or Always now actually stops the next prompt for that tool, prompts show the call's arguments with secrets masked, and YOLO or approvals.mode: off skips them. (#143780, #143795, #143787 — @liuhao1024, @fangliquanflq)
  • Live progress for long MCP calls — when a server reports progress, the Desktop tool row and the CLI spinner show the percentage and message, and plugins get a tool.progress event. Servers that declare a longer deadline are no longer cut off by the generic tool timeout. (#141985, #138491)
  • MCP events over webhooks (experimental, opt-in) — a server with mcp_servers.<name>.events: true can notify Hermes when something happens upstream, and each event starts an agent run through the gateway's webhook listener. (#140121 — @Potrock)
  • Connections — servers now see hermes-agent/<version> as the client name, results and tool lists over 1 MiB work on Streamable HTTP, and Otter.ai OAuth logins complete.
