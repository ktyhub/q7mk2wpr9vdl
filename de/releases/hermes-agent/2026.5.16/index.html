Hermes-Agent v2026.5.16

Hermes Agent v0.14.0 (v2026.5.16)

Veröffentlichungsdatum: 16. Mai 2026 Seit v0.13.0: 808 Commits · 633 zusammengeführte PRs · 1393 geänderte Dateien · 165.061 Einfügungen · 545 geschlossene Ausgaben (12 P0, 50 P1) · 215 Community-Mitwirkende (einschließlich Co-Autoren)

Die Foundation Release – Hermes lässt sich überall installieren und ausführen, liefert die Dinge mit, die Sie tatsächlich verwenden möchten, und stoppt den Versand der Dinge, die Sie nicht verwenden möchten. xAI Grok landet als SuperGrok OAuth-Anbieter, wobei grok-4.3 auf ein 1-Millionen-Kontextfenster gestoßen ist. Ein neuer OpenAI-kompatibler lokaler Proxy verwandelt jeden OAuth-authentifizierten Hermes-Anbieter – Claude Pro, ChatGPT Pro, SuperGrok – in einen Endpunkt, den Codex / Aider / Cline / Continue erreichen kann. x_search landet als erstklassiges X-Suchtool (Twitter) mit OAuth-oder-API-Schlüsselauthentifizierung. Der Microsoft Teams-Stack ist durchgängig verkabelt (Graph-Authentifizierung + Webhook-Listener + Pipeline-Laufzeit + ausgehende Zustellung). Eine Debloating-Welle macht Installationen erheblich einfacher – schwere Backends werden jetzt bei der ersten Verwendung verzögert installiert, die [all]-Extras lassen alles fallen, was von Lazy-Deps abgedeckt wird, und eine mehrstufige Installation fällt zurück, wenn ein Rad auf Ihrer Plattform ablehnt. pip install hermes-agent funktioniert mit PyPI. Die Kaltstartwelle verkürzt den Start von hermes um etwa 19 Sekunden. Browser-CDP-Aufrufe sind 180-mal schneller. Zwei neue Messaging-Plattformen (LINE + SimpleX Chat) erhöhen die Gesamtzahl auf 22. Sitzungsübergreifendes 1-stündiges Claude-Prompt-Caching, /handoff, das Sitzungen tatsächlich live überträgt, native Schaltflächen-Benutzeroberfläche für clarify auf Telegram und Discord, Backfill des Discord-Kanalverlaufs, semantische LSP-Diagnose bei jedem Schreibvorgang, ein einheitliches steckbares video_generate, ein computer_use-Cua-Treiber-Backend, das endlich mit Nicht-Anthropic-Anbietern funktioniert, cliaktivierbare URLs in jedem Terminal, Zed ACP Registry-Integration über uvx, native Windows-Beta, 9 neue optionale Skills, OpenRouter Pareto Code-Router, Huggingface/Skills als trusted-Standardtipp. 12 P0 + 50 P1-Verschlüsse.

✨ Highlights

  • xAI Grok über SuperGrok OAuth – und grok-4.3 springt zu einem 1M-Kontextfenster – Wenn Sie für SuperGrok bezahlen, können Sie Grok jetzt in Hermes verwenden, indem Sie sich mit Ihrem xAI-Konto anmelden – kein API-Schlüssel, keine separate Abrechnung. Durch die Durchleitung wird grok-4.3 auch auf ein 1-M-Token-Kontextfenster übertragen, sodass Sie ganze Codebasen oder Recherchekorpora in einer einzigen Eingabeaufforderung ablegen können. Beinhaltet die ordnungsgemäße Behandlung von Berechtigungsfehlern und eine Seite mit SSH-zu-Tunnel-Dokumenten für den Fall, dass Sie über SSH mit einer Remote-Box verbunden sind und den OAuth-Ablauf abschließen müssen. (#26534, #26664, #26644, #26592)
  • OpenAI-kompatibler lokaler Proxy für OAuth-Anbieter – Führen Sie hermes proxy aus und Sie erhalten einen http://localhost:port-Endpunkt, der OpenAI API spricht, aber von dem OAuth-Anbieter unterstützt wird, bei dem Sie angemeldet sind – Claude Pro, ChatGPT Pro, SuperGrok. Jetzt funktioniert jedes Tool, das einen OpenAI-kompatiblen Endpunkt erwartet (Codex CLI, Aider, Cline, Continue, Ihre benutzerdefinierten Skripte), einfach mit Ihrem bestehenden Abonnement, kein API-Schlüssel erforderlich. Ein Abonnement, jedes Tool. (#25969)
  • x_search – erstklassiges X-Suchtool (Twitter) – Der Agent kann X jetzt direkt durchsuchen, ohne einen Skill zu installieren oder eine benutzerdefinierte Integration einzurichten. Durchsuchen Sie die Timeline, finden Sie Threads und zeigen Sie bestimmte Beiträge an – direkt aus dem Chat. Authentifizieren Sie sich entweder mit Ihrem X-OAuth-Login oder einem API-Schlüssel, je nachdem, was Sie haben. (#26763)
  • Microsoft Teams – End-to-End – Hermes kann jetzt Nachrichten von Teams lesen und zurücksenden. Der vollständige Microsoft Graph-Stack landet zusammen: auth + client Foundation, ein Webhook-Listener, der Teams-Ereignisse empfängt, eine Pipeline-Plugin-Laufzeit und ausgehende Zustellung. Vernetzen Sie den Bot einmal und chatten Sie dann über einen beliebigen Teams-Kanal, eine DM oder eine Gruppe mit Ihrem Agenten. (Bergungen von #21408–#21411) (#21922, #21969, #22007, #22024)
  • Debloating-Welle – einfachere Installationen, weniger, die Sie nicht verwenden – Ein sauberer pip install hermes-agent, der verwendet wurde, um alles herunterzufahren: jeden Messaging-Adapter SDK, jeden Image-Gen-SDK, jeden Sprach-/TTS-Anbieter, unabhängig davon, ob Sie ihn verwendet haben oder nicht. Jetzt werden diese umfangreichen Backends (Slack-/Matrix-/Feishu-/DingTalk-Adapter, Rückblick client, ​​Codex-App-Server, Pixverse/Camofox/image-gen SDKs, Sprach-/TTS-Anbieter) automatisch installiert, wenn Sie sie zum ersten Mal tatsächlich verwenden. Die [all]-Extras lassen alles fallen, was von Lazy-Deps abgedeckt wird, der Installer greift durch die Stufen zurück, wenn ein Rad nicht zu Ihrer Plattform passt, und ein Supply-Chain-Advisory-Checker scannt jede Installation auf unsichere Versionen. Schnellere Installationen, geringerer Speicherplatzbedarf, weniger transitive Schwachstellen. (#24220, #24515, #25014, #25038, #25766, #21818)
  • pip install hermes-agent && hermes – Hermes Agent ist jetzt ein echtes PyPI-Paket. Kein Klonen des Repositorys oder Ausführen von Shell-Installationsprogrammen mehr – ein Pip-Befehl und schon kann es losgehen. Das Rad wird mit dem Ink TUI-Bundle und dem Shell Launcher geliefert, sodass das volle Erlebnis sofort einsatzbereit ist. (Bergung von #26350) (#26593, #26148)
  • Sitzungsübergreifender 1-Stunden-Cache für Claude-Eingabeaufforderungen – Wenn Sie Claude über Anthropic, OpenRouter oder Nous Portal verwenden, wird das Eingabeaufforderungspräfix (Systemeingabeaufforderung, Fähigkeiten, Speicher) jetzt sitzungsübergreifend eine Stunde lang zwischengespeichert. Starten Sie eine /new-Sitzung und die erste Antwort kommt schneller und günstiger zurück, da der Cache noch warm von Ihrer letzten Sitzung ist. Die Überprüfung des Hintergrundspeichers betrifft auch den Cache, sodass nicht immer der volle Preis bezahlt wird. (#23828, #25434, #24778)
  • 180-mal schnellere browser_console-Auswertungen – Wenn der Agent das Browser-Tool verwendet, um eine Seite zu überprüfen oder JavaScript auszuführen, teilen sich diese Aufrufe jetzt eine dauerhafte Verbindung zu Chrome, anstatt jedes Mal eine neue DevTools-Sitzung zu starten. Der Unterschied ist enorm: Dinge, die früher ein paar Sekunden pro Anruf dauerten, werden jetzt in Millisekunden erledigt. Echte Seiteninteraktionen fühlen sich sofort an. (#23226)
  • Kaltstart-Leistungswelle – ~19 Sekunden nach dem Start von hermes – Beim Ausführen von hermes mussten Sie früher einen Teil des Importaufwands und Netzwerkaufrufe abwarten, bevor Sie eine Eingabeaufforderung sahen. Jetzt ist der Startpfad größtenteils verzögert: Schwere Adapter werden nur geladen, wenn Sie sie verwenden, Modellkataloge kommen zuerst aus dem Festplatten-Cache, Arztprüfungen werden parallel ausgeführt und chat -q überspringt das Willkommensbanner vollständig. Allein der Bildschirm des hermes tools All-Platforms sank von 14 Sekunden auf unter 1.5 Sekunden. (#22138, #22120, #22681, #22790, #22808, #22831, #22859, #22904, #22766, #25341)
  • Zwei neue Messaging-Plattformen – LINE + SimpleX Chat – LINE ist in Japan, Korea und Taiwan sehr beliebt, und jetzt läuft Hermes nativ auf dem LINE Messaging API. SimpleX Chat ist der datenschutzorientierte dezentrale Messenger ohne Benutzer-IDs – auch als erstklassige Plattform konzipiert. Damit verfügt Hermes nun über insgesamt 22 Messaging-Plattformen, sodass der Agent überall da sein kann, wo Sie und Ihr Team chatten. (#23197, #26232)
  • /handoff überträgt die Sitzung tatsächlich live – Das Wechseln von Modellen oder Persönlichkeiten mitten im Gespräch bedeutete früher, den Kontext zu verlieren oder von vorne zu beginnen. Jetzt verschiebt /handoff Ihre aktive Sitzung – jede Nachricht, jeden Tool-Aufruf, jeden Kontext – live zum Zielmodell, zur Zielperson oder zum Zielprofil, ohne dass etwas verloren geht. Übergeben Sie sich während des Debuggens von einem schnellen Modell an ein tiefgründiges Modell oder übergeben Sie eine Sitzung zwischen Profilen für verschiedene Teile einer Aufgabe. (#23395)
  • Native Schaltflächen-Benutzeroberfläche für clarify auf Telegram und Discord – Wenn der Agent das clarify-Tool verwendet, um Ihnen eine Multiple-Choice-Frage zu stellen, werden jetzt echte plattformnative Schaltflächen auf Telegram und Discord angezeigt, anstatt Sie aufzufordern, die Optionsnummer erneut einzugeben. Tippen Sie auf die Schaltfläche, der Agent erhält Ihre Antwort. Besonders schön auf dem Handy. (#24199, #25485)
  • Backfill des Discord-Kanalverlaufs (standardmäßig aktiviert) – Wenn Hermes zum ersten Mal einem Discord-Kanal oder -Thread beitritt, liest es jetzt den aktuellen Nachrichtenverlauf, damit es weiß, was gesagt wurde, bevor es antwortet. Kein „Wovon reden wir?“ mehr. – Der Agent verfügt über den Kontext, der bereits für alle anderen auf dem Bildschirm angezeigt wird. (#25984)
  • vision_analyze gibt Pixel an visionsfähige Modelle zurück – Wenn Sie den Agenten mit vision_analyze auf ein Bild richten und das aktive Modell tatsächlich sehen kann (GPT-5, Claude, Gemini, Grok-vision), übergibt Hermes die Rohpixel jetzt direkt an das Modell, anstatt sie zuerst in eine Textbeschreibung umzuwandeln. Sie erhalten die tatsächliche visuelle Argumentation des Modells anstelle eines verschlechterten Textzusammenfassungs-Roundtrips. (#22955)
  • Fußzeile der Dateimutationsüberprüfung pro Runde – Nach jeder Runde, in der Dateien geschrieben oder bearbeitet wurden, erhält der Agent jetzt eine kurze Fußzeile, die genau zusammenfasst, was sich auf der Festplatte geändert hat – die Dateipfade, die Zeilenanzahl, das tatsächliche Delta. Das bedeutet, dass der Agent seine eigenen Fehler erkennt, wenn ein Schreibvorgang nicht erfolgreich war oder stillschweigend überschrieben wurde, anstatt Ihnen selbstbewusst zu sagen: „Ich habe die Funktion hinzugefügt“, obwohl die Datei nicht tatsächlich gespeichert wurde. (#24498)
  • LSP-Semantikdiagnose bei jedem Schreibvorgang – Wenn der Agent write_file oder patch verwendet, führt Hermes jetzt einen echten Sprachserver für die bearbeitete Datei aus und meldet dem Agenten alle neuen Fehler vor der nächsten Runde. Tippfehler, undefinierte Symbole, fehlende Importe – sofort erkannt. Geht weit über das grundlegende Python/JSON/YAML/TOML-Linting von v0.13.0 hinaus, da es sich um eine tatsächliche semantische Analyse handelt. (#24168, #25978)
  • Einheitliches video_generate mit steckbaren Anbieter-Backends – Ein Tool, jedes Videomodell. Hermes wird bereits mit den offensichtlichen Backends ausgeliefert, aber Sie können einen neuen Videoanbieter als Plugin hinzufügen, ohne den Kern zu berühren. Wenn also nächsten Monat ein neues Videomodell auf den Markt kommt, kann es sich um ein Ein-Datei-Plugin statt um einen Fork handeln. (#25126)
  • computer_use cua-driver Backend – funktioniert jetzt mit Nicht-Anthropic-Modellen – Die Computernutzung (der Agent, der Ihre Maus und Tastatur steuert, um GUI-Apps zu steuern) war früher an den SDK von Anthropic gebunden. Das neue Cua-Treiber-Backend funktioniert auch mit Nicht-Anthropic-Anbietern, verfügt über ordnungsgemäße fokussichere Vorgänge und aktualisiert sich selbst auf hermes update. Jetzt kann jedes visionsfähige Modell Ihren Desktop steuern. (Wiederrettung von #16936) (#21967, #24063)
  • Cliackable URLs in jedem Terminal – Links in der Agentenausgabe sind jetzt echte OSC8-Hyperlinks mit Hover-Highlight in jedem Terminal, das sie unterstützt. Click zum Öffnen in Ihrem Browser – kein Kopieren, Einfügen und Ausschneiden langer URLs aus dem Transkript mehr. Funktioniert einfach in iTerm2, Kitty, Ghostty, modernen Windows-Terminals usw. (@OutThisLife) (#25071, #24013)
  • Zed ACP Registry – uvx wird in einem click installiert – Hermes ist jetzt in Zeds Agent Client Protocol Registry aufgeführt, sodass Zed-Benutzer es mit einem click installieren können. Der Installationspfad verwendet uvx, sodass keine NPM-Abhängigkeit besteht. hermes acp --setup-browser bootet die Browser-Tools für registrierungsgesteuerte Installationen. (Bergung von #25908) (#26079, #26120, #26234)
  • OpenRouter Pareto-Code-Router mit min_coding_score-Knopf – Der „Pareto“-Router von OpenRouter wählt automatisch das günstigste Modell aus, das eine Mindestqualitätsgrenze erfüllt. Mit der neuen min_coding_score-Konfiguration können Sie die Messlatte speziell für Codierungsaufgaben festlegen – Hermes leitet zum günstigsten Modell weiter, das mindestens so gut im Codieren ist. Hören Sie auf, für Modelle der Spitzenklasse zu zahlen, wenn ein Modell der Mittelklasse ausreichen würde. (#22838)
  • NovitaAI als neuer Modellanbieter – NovitaAI schließt sich der Anbieterpalette an und bietet Ihnen mit ihren Preis- und Tarifbeschränkungen eine weitere Option für Open-Source-Modellhosting (Llama, Qwen, DeepSeek usw.). (Bergung #7219) (@kshitijk4poor) (#25507)
  • Codex-App-Server-Laufzeit für OpenAI-/Codex-Modelle – Eine optionale Laufzeit, die den Codex CLI von OpenAI unter der Haube steuert, wenn Sie OpenAI- oder Codex-Pfade verwenden. Sie profitieren von der Wiederverwendung von Sitzungen, der automatischen Beendigung eingeklemmter Sitzungen und einer korrekten OAuth-Aktualisierungsklassifizierung – die Art von Installation, die dafür sorgt, dass lange Agentenläufe nicht scheitern. (#24182, #25769)
  • huggingface/skills als trusted-Standardtipp – Der unter Huggingface.co/skills gehostete Community-Skills-Index ist jetzt standardmäßig mit dem Skills Hub verbunden. Wenn also jemand dort einen nützlichen Skill veröffentlicht, können Sie ihn ohne zusätzliche Konfiguration über Ihren eigenen hermes skills-Browser installieren. (schließt #2549) (#26219)
  • 9 neue optionale Fertigkeiten – Hyperliquid (Perp + Spot-Handel über SDK und REST API), Yahoo Finance (Live-Marktdaten, Fundamentaldaten, historische Daten), api-Testing (REST + GraphQL-Debug-Rezepte), einheitliche EVM-Multi-Chain (eine Fertigkeit deckt Ethereum + L2s + Base ab), Darwinian-Evolver (evolutionäre Eingabeaufforderung/Skill-Tuning), Osint-Untersuchung (OSINT-Rezepte). für Personen/Domänen/Organisationen), Pinggy-Tunnel (lokale Dienste dem öffentlichen Internet zugänglich machen), Watchers (Umfragen RSS/HTTP JSON/GitHub über Cron-no_agent-Modus zur Änderungserkennung) und eine vollständige Überarbeitung von Notion für die Entwicklerplattform vom Mai 2026. (#23582, #23583, #23590, #25299, #26760, #26729, #26765, #21881, #26612)
  • Der Server API macht Ausführungsgenehmigungsereignisse verfügbar – Wenn Sie Hermes programmgesteuert über HTTP API steuern, bleiben lang laufende Ausführungen nicht mehr stillschweigend hängen, wenn der Agent einen Befehl ausführt, für den eine Genehmigung erforderlich ist. Die Genehmigungsanfrage wird jetzt im API-Stream angezeigt, sodass Ihr client den Benutzer auffordern und antworten kann – kein stilles Abwürgen mehr. (Bergung von #20311) (#21899)
  • Plugins können jeden LLM-Anruf über ctx.llm ausführen + integrierte Tools über tool_override ersetzen – Wenn Sie ein Hermes-Plugin schreiben, erhalten Sie jetzt erstklassigen Zugriff zum Tätigen von LLM-Anrufen über den aktiven Anbieter und die Anmeldeinformationen – keine manuelle client-Verkabelung. Mit dem neuen Flag tool_override kann ein Plugin ein integriertes Tool sauber durch eine eigene Implementierung ersetzen. Plugin-Autoren erhalten das gleiche Modell-Routing und die gleiche Authentifizierung, die der Kernagent verwendet. (schließt #11049) (#23194, #26759)
  • Brave Search (kostenloses Kontingent) + DuckDuckGo (DDGS) als Web-Suchanbieter – Zwei neue kostenlose Web-Such-Backends ergänzen Tavily, SearXNG und Exa. Brave Search verfügt über ein großzügiges kostenloses Kontingent; DDGS ist der DuckDuckGo-Schaber, der überhaupt keinen Schlüssel benötigt. Wählen Sie, was zu Ihrem Budget und Ihren Preislimitanforderungen passt. (#21337)
  • Sudo-Brute-Force-Blockierung + 3 Umgehungen gefährlicher Befehle geschlossen + Bereinigung von Tool-Fehlern – Das Genehmigungstor blockiert jetzt sudo -S-Brute-Force-Versuche und klassifiziert stdin-fed- oder askpass-entfernte Sudo-Aufrufe als GEFÄHRLICH. Drei bekannte Umgehungsmöglichkeiten für die Erkennung gefährlicher Befehle sind geschlossen (inspiriert von Claude Codes Arbeit zur Befehlserkennung). Und Tool-Fehlerzeichenfolgen werden jetzt bereinigt, bevor sie erneut in den Modellkontext eingefügt werden, sodass eine schädliche Datei oder ein Remotedienst keine Anweisungen über die Fehlerausgabe an Ihren Agenten weitergeben kann. (#23736, #26829, #26823)
  • /subgoal – vom Benutzer hinzugefügte Kriterien, die an einen aktiven /goal angehängt werden – Wenn ein /goal ausgeführt wird (das dauerhafte Ralph-Loop-Ziel, bei dem der Agent so lange weiterläuft, bis die Kriterien erfüllt sind), können Sie jetzt /subgoal <text> verwenden, um ihm während der Ausführung zusätzliche Erfolgskriterien hinzuzufügen. Der Juror berücksichtigt Ihre neuen Kriterien in der Entscheidung „Fertig oder weitermachen“, ohne die Schleife neu zu starten. (#25449)
  • Umbenennung des Anbieters – Alibaba Cloud → Qwen Cloud – Der Alibaba Cloud-Anbieter wird in der Auswahl und Konfiguration in Qwen Cloud umbenannt, damit er mit der Bezeichnung im Rest der Welt übereinstimmt. Vorhandene Konfigurationsschlüssel funktionieren weiterhin – keine wichtigen Änderungen – aber die Benutzeroberfläche entspricht jetzt der tatsächlichen Marke. (#24835)
  • Native Windows-Unterstützung (frühe Beta) – Hermes läuft jetzt nativ auf cmd.exe und PowerShell ohne WSL. Ein vollständiges PowerShell-Installationsprogramm übernimmt die automatische MinGit-Installation, die Microsoft Store python-Stub-Erkennung und den Vordergrund-Strg+C-Tanz. Es gibt immer noch Ecken und Kanten (das ist der „frühe Beta“-Stempel) – etwa 40 Nachfolge-Fixes nur für Windows sind bereits im Fenster gelandet –, aber die grundlegende Schleife funktioniert durchgängig auf einem sauberen Windows-Rechner. (#21561)
