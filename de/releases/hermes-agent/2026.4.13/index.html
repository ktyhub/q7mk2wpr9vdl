Hermes-Agent v2026.4.13

Hermes Agent v0.9.0 (v2026.4.13)

Veröffentlichungsdatum: 13. April 2026 Seit v0.8.0: 487 Commits · 269 zusammengeführte PRs · 167 gelöste Probleme · 493 Dateien geändert · 63.281 Einfügungen · 24 Mitwirkende

Die überall verfügbare Version – Hermes wird mobil mit Termux/Android, fügt iMessage und WeChat hinzu, liefert den Fast Mode für OpenAI und Anthropic, führt Hintergrundprozessüberwachung ein, startet ein lokales Web-Dashboard zur Verwaltung Ihres Agenten und bietet den bislang umfassendsten Sicherheitshärtungsdurchgang auf 16 unterstützten Plattformen.

✨ Highlights

  • Lokales Web-Dashboard – Ein neues browserbasiertes Dashboard zur lokalen Verwaltung Ihres Hermes-Agenten. Konfigurieren Sie Einstellungen, überwachen Sie Sitzungen, durchsuchen Sie Fähigkeiten und verwalten Sie Ihr Gateway – alles über eine übersichtliche Weboberfläche, ohne Konfigurationsdateien oder das Terminal zu berühren. Der einfachste Weg, mit Hermes einzusteigen.
  • Schnellmodus (/fast) – Prioritätsverarbeitung für OpenAI- und Anthropic-Modelle. Schalten Sie /fast um, um bei unterstützten Modellen (GPT-5.4, Codex, Claude) durch Prioritätswarteschlangen zu leiten und so die Latenz deutlich zu verringern. Erweitert sich über alle OpenAI Priority Processing-Modelle und die schnelle Stufe von Anthropic. (#6875, #6960, #7037)
  • iMessage über BlueBubbles – Vollständige iMessage-Integration über BlueBubbles, wodurch Hermes in das Messaging-Ökosystem von Apple integriert wird. Automatische Webhook-Registrierung, Integration des Einrichtungsassistenten und Absturzsicherheit. (#6437, #6460, #6494)
  • WeChat (Weixin) und WeCom-Rückrufmodus – Native WeChat-Unterstützung über iLink Bot API und einen neuen WeCom-Rückrufmodus-Adapter für selbst erstellte Unternehmensanwendungen. Streaming-Cursor, Medien-Uploads, Handhabung von Markdown-Links und Persistenz des atomaren Zustands. Hermes deckt nun das chinesische Messaging-Ökosystem durchgängig ab. (#7166, #7943)
  • Termux-/Android-Unterstützung – Führen Sie Hermes nativ auf Android über Termux aus. Angepasste Installationspfade, TUI-Optimierungen für mobile Bildschirme, Sprach-Backend-Unterstützung und der /image-Befehl funktionieren auf dem Gerät. (#6834)
  • Hintergrundprozessüberwachung (watch_patterns) – Legen Sie Muster fest, auf die in der Hintergrundprozessausgabe geachtet werden soll, und erhalten Sie in Echtzeit eine Benachrichtigung, wenn sie übereinstimmen. Überwachen Sie auf Fehler, warten Sie auf bestimmte Ereignisse („Überwachen des Ports“) oder überwachen Sie Build-Protokolle – alles ohne Abfrage. (#7635)
  • Native xAI- und Xiaomi MiMo-Anbieter – Erstklassige Anbieterunterstützung für xAI (Grok) und Xiaomi MiMo mit direktem API-Zugriff, Modellkatalogen und Integration des Einrichtungsassistenten. Plus Qwen OAuth mit Unterstützung für Portalanfragen. (#7372, #7855)
  • Pluggable Context Engine – Die Kontextverwaltung ist jetzt ein steckbarer Steckplatz über hermes plugins. Tauschen Sie benutzerdefinierte Kontext-Engines ein, die steuern, was der Agent in jeder Runde sieht – Filterung, Zusammenfassung oder domänenspezifische Kontextinjektion. (#7464)
  • Einheitlicher Proxy-Support – SOCKS-Proxy, DISCORD_PROXY und automatische System-Proxy-Erkennung auf allen Gateway-Plattformen. Hermes hinter Unternehmens-Firewalls funktioniert einfach. (#6814)
  • Umfassende Sicherheitshärtung – Path-Traversal-Schutz im Checkpoint-Manager, Shell-Injection-Neutralisierung bei Sandbox-Schreibvorgängen, SSRF-Redirect-Guards bei Slack-Bild-Uploads, Twilio-Webhook-Signaturvalidierung (SMS-RCE-Fix), API-Serverauthentifizierungsdurchsetzung, Git-Argument-Injection-Verhinderung und Autorisierung der Genehmigungsschaltfläche. (#7933, #7944, #7940, #7151, #7156)
  • hermes backup & hermes import – Vollständige Sicherung und Wiederherstellung Ihrer Hermes-Konfiguration, Sitzungen, Fähigkeiten und Speicher. Migrieren Sie zwischen Maschinen oder erstellen Sie Snapshots vor größeren Änderungen. (#7997)
  • 16 unterstützte Plattformen – Mit BlueBubbles (iMessage) und WeChat neben Telegram, Discord, Slack, WhatsApp, Signal, Matrix, E-Mail, SMS, DingTalk, Feishu, WeCom, Mattermost, Home Assistant und Webhooks läuft Hermes jetzt sofort auf 16 Messaging-Plattformen.
  • /debug & hermes debug share – Neues Debugging-Toolkit: /debug-Slash-Befehl auf allen Plattformen für eine schnelle Diagnose, plus hermes debug share zum Hochladen eines vollständigen Debug-Berichts in einen Pastebin zur einfachen Weitergabe bei der Fehlerbehebung. (#8681)

hermes-agent v2026.4.13

Hermes Agent v0.9.0 (v2026.4.13)

Release Date: April 13, 2026 Since v0.8.0: 487 commits · 269 merged PRs · 167 resolved issues · 493 files changed · 63,281 insertions · 24 contributors

The everywhere release — Hermes goes mobile with Termux/Android, adds iMessage and WeChat, ships Fast Mode for OpenAI and Anthropic, introduces background process monitoring, launches a local web dashboard for managing your agent, and delivers the deepest security hardening pass yet across 16 supported platforms.

✨ Highlights

  • Local Web Dashboard — A new browser-based dashboard for managing your Hermes Agent locally. Configure settings, monitor sessions, browse skills, and manage your gateway — all from a clean web interface without touching config files or the terminal. The easiest way to get started with Hermes.

  • Fast Mode (/fast) — Priority processing for OpenAI and Anthropic models. Toggle /fast to route through priority queues for significantly lower latency on supported models (GPT-5.4, Codex, Claude). Expands across all OpenAI Priority Processing models and Anthropic's fast tier. (#6875, #6960, #7037)

  • iMessage via BlueBubbles — Full iMessage integration through BlueBubbles, bringing Hermes to Apple's messaging ecosystem. Auto-webhook registration, setup wizard integration, and crash resilience. (#6437, #6460, #6494)

  • WeChat (Weixin) & WeCom Callback Mode — Native WeChat support via iLink Bot API and a new WeCom callback-mode adapter for self-built enterprise apps. Streaming cursor, media uploads, markdown link handling, and atomic state persistence. Hermes now covers the Chinese messaging ecosystem end-to-end. (#7166, #7943)

  • Termux / Android Support — Run Hermes natively on Android via Termux. Adapted install paths, TUI optimizations for mobile screens, voice backend support, and the /image command work on-device. (#6834)

  • Background Process Monitoring (watch_patterns) — Set patterns to watch for in background process output and get notified in real-time when they match. Monitor for errors, wait for specific events ("listening on port"), or watch build logs — all without polling. (#7635)

  • Native xAI & Xiaomi MiMo Providers — First-class provider support for xAI (Grok) and Xiaomi MiMo, with direct API access, model catalogs, and setup wizard integration. Plus Qwen OAuth with portal request support. (#7372, #7855)

  • Pluggable Context Engine — Context management is now a pluggable slot via hermes plugins. Swap in custom context engines that control what the agent sees each turn — filtering, summarization, or domain-specific context injection. (#7464)

  • Unified Proxy Support — SOCKS proxy, DISCORD_PROXY, and system proxy auto-detection across all gateway platforms. Hermes behind corporate firewalls just works. (#6814)

  • Comprehensive Security Hardening — Path traversal protection in checkpoint manager, shell injection neutralization in sandbox writes, SSRF redirect guards in Slack image uploads, Twilio webhook signature validation (SMS RCE fix), API server auth enforcement, git argument injection prevention, and approval button authorization. (#7933, #7944, #7940, #7151, #7156)

  • hermes backup & hermes import — Full backup and restore of your Hermes configuration, sessions, skills, and memory. Migrate between machines or create snapshots before major changes. (#7997)

  • 16 Supported Platforms — With BlueBubbles (iMessage) and WeChat joining Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Email, SMS, DingTalk, Feishu, WeCom, Mattermost, Home Assistant, and Webhooks, Hermes now runs on 16 messaging platforms out of the box.

  • /debug & hermes debug share — New debugging toolkit: /debug slash command across all platforms for quick diagnostics, plus hermes debug share to upload a full debug report to a pastebin for easy sharing when troubleshooting. (#8681)
