Hermes-Agent v0.20.0 (v2026.8.3)

Veröffentlichungsdatum: 3. August 2026 Seit v0.19.0: ~3.650 Commits · ~1.400 zusammengeführte PRs · ~5.200 geänderte Dateien · ~559.000 Einfügungen · ~405.000 Löschungen · ~1.200 geschlossene Probleme · 650+ Mitwirkende

The Herald Release. Hermes ist der Herold der Götter, und diese Veröffentlichung macht ihn ernsthaft zu einem: Er spricht (Echtzeit-Gesprächsstimme mit Streaming-TTS, Einschalten, Weckwörtern auf dem Gerät und freihändiger Steuerung über den CLI, den Desktop und jede audiofähige Gateway-Plattform), er übermittelt Nachrichten an andere Agenten (A2A v1.0), er kündigt Ereignisse an Ihre Systeme an (signierte ausgehende Webhooks) und er zitiert seine Quellen (fundierte Recherche mit überprüfbaren Zitaten und Faktenprüfung). Um dieses Rückgrat herum: Die Desktop-App wurde zu einer Plattform (Artefakte mit Live-Vorschau, ein Plugin SDK, Schnellzugriff von überall, mehrere Fenster), der CLI erhielt eine Welle von Power-Befehlen (!-Shell-Modus, /init, /diff, /context, /focus), die Komprimierung wurde intelligenter und sanfter, und die Tools selbst erholen sich jetzt von ihren eigenen Fehlern, anstatt das Modell raten zu lassen. In dieser Version wird alles ab dem Infrastruktur-Patch-Tag v0.19.1 zusammengefasst – dieses Fenster ist hier vollständig dokumentiert.

✨ Highlights

  • Mit Hermes sprechen – Streaming, Konversationssprache mit Einschaltung – Der Sprachmodus bedeutete früher: Sprechen, warten, bis die gesamte Antwort generiert wurde, und dann eine lange Audiodatei anhören. Jetzt spricht Hermes Satz für Satz, während die Antwort strömt. Sie können ihn mitten im Satz unterbrechen, indem Sie einfach sprechen (er stoppt, hört zu und das Modell wird darüber informiert, dass Sie sich unterbrechen). Dies funktioniert im CLI-Sprachmodus, auf dem Desktop und über Gateway-Adapter. Das Gespräch mit Hermes fühlt sich endlich wie ein Gespräch an, nicht wie ein Voicemail-Austausch. (#69511, #73862, #74223, #74000, #69602 – @teknium1, @OutThisLife)
  • Weckwörter und Freisprechsteuerung – Sagen Sie Ihre eigene Weckphrase mit offenem Vokabular („Hey Hermes“ oder was auch immer Sie auswählen) und Hermes beginnt zuzuhören – die Erkennung erfolgt auf dem Gerät, sodass kein Ton Ihr Gerät verlässt, während es wartet. Durch die Sprachweiterleitung mit mehreren Profilen können unterschiedliche Aktivierungswörter unterschiedliche Profile erreichen. Wenn Sie „Stopp“ sagen, wird der Voice-Chat auf jeder Oberfläche beendet, ohne dass die Tastatur berührt werden muss. Ihr Terminal ist jetzt etwas, mit dem Sie von der anderen Seite des Raums aus sprechen können. (#70509, #73106, #73933 — @teknium1)
  • Stimme auf jeder Plattform – Senden Sie eine Sprachnotiz an Hermes über WhatsApp, Feishu, DingTalk, LINE, QQ, Photon oder Weixin und sie wird transkribiert und beantwortet; Auto-TTS-Antworten werden plattformabhängig übermittelt (Opus, wo Plattformen Opus wünschen, Untertitel korrekt angehängt). STT ist jetzt vollständig konfigurierbar – eine eigene hermes tools-Kategorie, GUI-Umschaltungen, Dashboard-Dropdowns, einheitliche Sprachauflösung, damit Transkripte nicht mehr in der falschen Sprache zurückkommen, und OpenAIs gpt-trancribe-Unterstützung. Ein einheitlicher Präprozessor für gesprochenen Text entfernt Markdown, Code und URLs bei allen TTS-Anbietern aus der Sprache. (#73515, #73508, #73910, #73513, #73067 — @teknium1)
  • Forschung, die Sie können trust – fundierte Zitate mit Faktenprüfung – Mit der neuen grounded-citations-Fähigkeit erstellt Hermes Recherchen, bei denen jede Behauptung durch eine überprüfbare Quelle gestützt wird: Zitate werden mit dem tatsächlichen Seitentext abgeglichen (nicht halluziniert), Zitate sind mit den genauen Beweisen verknüpft, und ein Faktenprüfungsmodus aktiviert bei jedem Dokument oder jeder Behauptung, die Sie ihm übergeben, die gleiche Maschinerie – er sagt Ihnen, was überprüft wird, was nicht und was nicht überprüft werden. Wenn Sie Hermes für die Recherche nutzen, ist dies der Unterschied zwischen „klingt richtig“ und „nachweisbare Quelle“. (#71698, #77104 — @teknium1)
  • Ausgehende Webhooks – Hermes leitet Ereignisse an Ihre Systeme weiter – Bisher bedeutete die Integration mit Hermes das Abfragen oder Abhören auf einer Plattform. Jetzt überträgt Hermes signierte Lebenszyklusereignisse (Sitzungsaktivität, Turn-Abschlüsse, Tool-Ereignisse) an jeden von Ihnen registrierten HTTP-Endpunkt – mit HMAC-Signaturen, damit Ihr Empfänger die Authentizität überprüfen kann. Verknüpfen Sie Hermes mit Ihrem CI, Ihrer Hausautomation, Ihren Dashboards oder jedem anderen Dienst, der HTTP spricht, ohne Abrufschleife. (#69406 — @teknium1)
  • Die Desktop-App wird zu einer Plattform – Artefakte, Plugin SDK, Schnelleingabe – Der Hermes-Desktop rendert jetzt Artefakte: versionierte Karten mit Sandbox-Live-Vorschau in einem rechten Viewer, sodass generierte HTML/Apps sicher neben dem Chat laufen. Ein echtes Plugin SDK landete mit Kanban als Gründungs-Plugin, ctx.download für die Weitergabe von Benutzerdateien, die Platzierung schwebender Fenster und mehrere GUI-Fenster. Ein Schnelleingabefenster mit globalem Hotkey erfasst einen Gedanken in jeder Sitzung von überall in Ihrem Betriebssystem. Der Desktop hörte auf, ein Chat client zu sein, und begann, eine Workbench zu sein. (#72345, #61173, #74413, #72315, #68259, #73143 — @OutThisLife, @teknium1)
  • Hermes spricht Agent-zu-Agent – A2A v1.0 – Ein neues gebündeltes Plugin implementiert das Agent-zu-Agent-Protokoll, sodass Hermes andere A2A-kompatible Agenten entdecken, mit ihnen kommunizieren und von ihnen gesteuert werden kann. Damit ist Problem Nr. 514 abgeschlossen – eine der ältesten offenen Funktionsanfragen im Repo. Wenn Sie Multiagentensysteme mit heterogenen Stapeln aufbauen, verfügt Hermes jetzt über ein Standard-Kabelprotokoll für deren Verbindung. (#77109 — @teknium1)
  • CLI Power-User-Welle – !command führt einen Shell-Befehl sofort aus, ohne eine Modellrunde aufzuwenden. /init scannt Ihr Projekt und generiert (oder aktualisiert) ein AGENTS.md. /diff zeigt gestaffelte/alle/Sitzungsänderungen von jeder Oberfläche aus, /context schlüsselt genau auf, was Ihr Kontextfenster füllt, /focus bietet Ihnen eine reduzierte Ausgabeansicht mit Wiederherstellung verdeckter Zeilen und Strg+S speichert eine halbgeschriebene Eingabeaufforderung in einem durchsuchbaren Bereich. Außerdem migriert hermes import-agent Ihr Claude Code- oder Codex CLI-Setup mit einem Befehl in Hermes. (#72257, #72178, #72240, #72242, #72302, #72262, #72190 – @teknium1, mehrere Bergungen langjährige Community-PRs)
  • Korrigieren Sie den Agenten mitten im Zug – Weiterleitungen – Wenn Hermes in die falsche Richtung fährt, müssen Sie nicht mehr /stop und es erneut erklären. Geben Sie eine Korrektur ein, während es funktioniert, und der aktive Zug wird umgeleitet: Die Arbeit im Flug bleibt erhalten, die ursprüngliche Eingabeaufforderung wird beibehalten und der Agent korrigiert den Kurs anhand Ihrer neuen Anleitung. In Kombination mit dem Doppel-ESC-Entwurfsverwerfen und einem Composer-Rückgängig-Stapel fühlt sich die Steuerung wie Bearbeiten und nicht wie ein Neustart an. (#63104, #72339, #74736 — @OutThisLife)
  • Tools, die sich selbst reparieren – Eine Reihe von Selbstwiederherstellungs-Upgrades bedeuten, dass der Agent deutlich weniger Umdrehungen aufgrund von Tool-Reibungen verschwendet: Abgeschnittene Terminalausgaben werden in eine Datei übertragen, die der Agent zurücklesen kann, patch erkennt bereits vorgenommene Bearbeitungen und diagnostiziert Nichtübereinstimmungen von Leerzeichen, write_file überprüft den Inhalt auf der Festplatte, sucht, bei denen nichts übereinstimmt, nach Beinaheunfällen und stellt sie wieder her, und häufige Fehlerklassen werden mit umsetzbaren Hinweisen zurückgegeben. Das standardmäßige Iterationslimit für Werkzeugaufrufe stieg ebenfalls auf 90 → 500 – lange autonome Läufe stießen nicht mehr gegen eine künstliche Wand. (#77041, #76998, #77024, #77055, #77011, #76992, #72176 — @teknium1)
  • Komprimierung, die Ihre Konversation respektiert – Die Kontextkomprimierung wurde grundlegend überarbeitet: proaktive Tool-Ergebnisbereinigung für Modelle mit großen Fenstern, Mikrokomprimierung pro Runde, die die Kosten anstelle einer riesigen Pause amortisiert, ein garantierter N-Benutzer-Nachrichtende, damit die letzte Konversation immer überlebt, fortschrittsbezogene Zeitüberschreitungen, die langsame Zusammenfassungsmodelle nicht mehr bestrafen, und Ghost-Skill-Abwehr, damit eine beschnittene Fertigkeit niemals stillschweigend eine Sitzung verfolgen kann. Schwellenwerte sind jetzt pro Modell und in absoluten Token konfigurierbar. Lange Sitzungen bleiben kohärent und geraten nicht ins Stocken. (#70254, #75345, #70250, #71508, #70275 – @teknium1, @kshitijk4poor, Rettung mehrerer Community-PRs)
  • Intelligente Genehmigungen werden erwachsen – hermes approvals suggest analysiert Ihren Genehmigungsverlauf in Vorschläge für die Zulassungsliste, Bediener können die Richtlinie für intelligente Genehmigungen anpassen, ein Schutzschalter für fortlaufende Ablehnung stoppt eine fehlerhafte Schleife und Desktop-Pairing-Genehmigungen erfolgen profilrichtig mit einer geeigneten Oberfläche, von der aus sie beantwortet werden können. Plus ein neues Genehmigungstor für docker/podman daemon-redirect-Befehle. Weniger clicking „genehmigen“, ohne auch nur einen Zentimeter Kontrolle zu geben. (#72259, #72186, #72203, #74446, #71092 – @teknium1, @OutThisLife)
  • Überall wieder schneller – Prompt-Caching deckt jetzt Tool-Schemata auf nativem Anthropic ohne Verlaufsverlust ab. Der Kaltstart von hermes -w sank um ca. 14 Sek. → ca. 1,8 Sek., hermes update-No-Ops wurden 2–6 Sek. schneller, schwere SDKs laden Lazy-Load aus dem Importpfad, Konfigurationslesevorgänge stoppten Deep-Copy (54-mal schneller am Telemetrie-Gate) und der Desktop sendete eine zweite 60-fps-Welle – Streaming-Kosten unabhängig von der Transkriptlänge, Drag bei 60 fps mit fünf Streaming-Registerkarten, CPU im Leerlauf nahe Null in der Hintergrund. (#76032, #71637, #74218, #74204, #71835, #72346, #75218 — @kshitijk4poor, @teknium1, @OutThisLife)
  • Neue Orte zum Ausführen und Erreichen – Buzz landet als gebündelte Gateway-Plattform (Blocks Nostr-basierter Messenger mit nativem WebSocket-Transport und NIP-42-Authentifizierung), der Vercel AI Gateway-Anbieter und das Vercel Sandbox-Terminal-Backend werden modernisiert, der Desktop erhält einen SSH-Remote-Backend-Verbindungsmodus und das Relay liefert vier Phasen der Parität – Medien, interaktive Eingabeaufforderungen, Thread-Lebenszyklus, Eingabeindikatoren – plus HSP-Personal- und Organisations-Skill-Synchronisierung. Hermes Agent v0.20.0 (v2026.8.3)

Release Date: August 3, 2026 Since v0.19.0: ~3,650 commits · ~1,400 merged PRs · ~5,200 files changed · ~559,000 insertions · ~405,000 deletions · ~1,200 issues closed · 650+ contributors

The Herald Release. Hermes is the herald of the gods, and this release makes him one in earnest: he speaks (real-time conversational voice with streaming TTS, barge-in, on-device wake words, and hands-free control across the CLI, desktop, and every audio-capable gateway platform), he carries word to other agents (A2A v1.0), he announces events to your systems (signed outbound webhooks), and he cites his sources (grounded research with verifiable citations and fact-checking). Around that spine: the desktop app became a platform (artifacts with live preview, a plugin SDK, quick-entry from anywhere, multiple windows), the CLI got a wave of power commands (! shell mode, /init, /diff, /context, /focus), compression got smarter and gentler, and the tools themselves now recover from their own failures instead of making the model guess. This release rolls up everything from the v0.19.1 infrastructure patch tag — that window is fully documented here.

✨ Highlights

  • Talk to Hermes — streaming, conversational voice with barge-in — Voice mode used to mean: speak, wait for the whole reply to generate, then listen to one long audio file. Now Hermes speaks clause-by-clause as the response streams, you can interrupt it mid-sentence by just talking (it stops, listens, and the model is told you cut in), and busy-aware silence detection means it doesn't talk over you. This works in CLI voice mode, on the desktop, and through gateway adapters. Talking to Hermes finally feels like a conversation, not a voicemail exchange. (#69511, #73862, #74223, #74000, #69602 — @teknium1, @OutThisLife)

  • Wake words and hands-free control — Say your own open-vocabulary wake phrase ("hey Hermes", or anything you pick) and Hermes starts listening — detection runs on-device, so no audio leaves your machine while it waits. Multi-profile voice routing means different wake words can reach different profiles, and saying "stop" ends the voice chat on every surface without touching the keyboard. Your terminal is now something you can talk to from across the room. (#70509, #73106, #73933 — @teknium1)

  • Voice on every platform — Send a voice note to Hermes on WhatsApp, Feishu, DingTalk, LINE, QQ, Photon, or Weixin and it's transcribed and answered; auto-TTS replies are delivered platform-aware (opus where platforms want opus, captions attached correctly). STT is now fully configurable — its own hermes tools category, GUI toggles, dashboard dropdowns, unified language resolution so transcripts stop coming back in the wrong language, and OpenAI's gpt-transcribe support. One unified spoken-text preprocessor cleans markdown, code, and URLs out of speech across all TTS providers. (#73515, #73508, #73910, #73513, #73067 — @teknium1)

  • Research you can trust — grounded citations with fact-checking — The new grounded-citations skill makes Hermes produce research where every claim is backed by a verifiable source: quotes are matched against the actual page text (not hallucinated), citations link to the exact evidence, and a fact-checking mode turns the same machinery on any document or claim you hand it — it tells you what checks out, what doesn't, and what couldn't be verified. If you use Hermes for research, this is the difference between "sounds right" and "provably sourced." (#71698, #77104 — @teknium1)

  • Outbound webhooks — Hermes pushes events to your systems — Until now, integrating with Hermes meant polling or listening on a platform. Now Hermes pushes signed lifecycle events (session activity, turn completions, tool events) to any HTTP endpoint you register — with HMAC signatures so your receiver can verify authenticity. Wire Hermes into your CI, your home automation, your dashboards, or any service that speaks HTTP, with no polling loop. (#69406 — @teknium1)

  • The desktop app becomes a platform — artifacts, plugin SDK, quick entry — Hermes desktop now renders artifacts: versioned cards with sandboxed live preview in a right-rail viewer, so generated HTML/apps run safely next to the chat. A real plugin SDK landed with Kanban as its founding plugin, ctx.download for handing users files, floating pane placement, and multiple GUI windows. A global-hotkey quick-entry window captures a thought into any session from anywhere in your OS. The desktop stopped being a chat client and started being a workbench. (#72345, #61173, #74413, #72315, #68259, #73143 — @OutThisLife, @teknium1)

  • Hermes speaks Agent-to-Agent — A2A v1.0 — A new bundled plugin implements the Agent-to-Agent protocol, so Hermes can discover, talk to, and be driven by other A2A-compatible agents. This closes issue #514 — one of the oldest open feature requests in the repo. If you're building multi-agent systems with heterogeneous stacks, Hermes now has a standard wire protocol for joining them. (#77109 — @teknium1)

  • CLI power-user wave — !command runs a shell command instantly without spending a model turn. /init scans your project and generates (or updates) an AGENTS.md. /diff shows staged/all/session changes from any surface, /context breaks down exactly what's filling your context window, /focus gives you a reduced-output view with hidden-line recovery, and Ctrl+S stashes a half-written prompt into a browsable panel. Plus hermes import-agent migrates your Claude Code or Codex CLI setup into Hermes in one command. (#72257, #72178, #72240, #72242, #72302, #72262, #72190 — @teknium1, several salvaging long-standing community PRs)

  • Correct the agent mid-turn — redirects — If Hermes is heading the wrong way, you no longer have to /stop and re-explain. Type a correction while it works and the active turn is redirected: work in flight is preserved, the original prompt is kept, and the agent course-corrects with your new guidance. Paired with double-ESC draft discard and a composer undo stack, steering feels like editing, not restarting. (#63104, #72339, #74736 — @OutThisLife)

  • Tools that fix themselves — A sweep of self-recovery upgrades means the agent wastes far fewer turns on tool friction: truncated terminal output spills to a file the agent can read back, patch detects already-applied edits and diagnoses whitespace mismatches, write_file verifies content on disk, searches that match nothing probe for near-misses and recover, and common failure classes come back with actionable hints. Thresholds are now configurable per-model and in absolute tokens. Long sessions stay coherent and stop stalling.
