OpenCLI v1.8.7

Highlights

  • Daemon write locking — Write commands now fail fast instead of racing when another write already holds the site session (#2100); service-worker wake events no longer wipe the lease registry, now backed by an owned-group ledger (#2098), and daemon pings omit credentials (#2282, fixing #2278). Scripts that fire concurrent writes will get explicit errors rather than silent corruption — wrap them in retry/backoff.
  • New surfaces — LinkedIn gains company and connections commands (#2088, #2083); new adapters land for Google Images (#2111), Trip.com international (#2158), Ctrip's travel verticals (#2156), Midjourney end-to-end (#2201), and Pinterest (#2177). Twitter adds muted-word (#2333), bounded collection (#2173), and full-archive likes/bookmarks sync that streams JSONL (#2143) — the last is the one to reach for when you need to export large datasets without loading everything into memory. GPT-5.6 Pro is also available as a ChatGPT target (#2129).
  • Site-drift catch-up — A large share of this release is reactive maintenance as upstream sites changed their markup and endpoints: X relocated profile counts out of legacy (#2193), TikTok switched explore endpoints (#2199), Douyin retired metrics_trend (#2307), ke/douban redesigned for 2026-08 (#2305), and Zhihu began accepting HTTP pagination URLs (#2151), among many Facebook/Instagram/Twitter fixes. The takeaway: adapter reliability is tightly coupled to upstream DOM, so expect steady patch releases after any redesign.
  • Data correctness — Several silent-wrong-output bugs are fixed: Eastmoney's mislabeled convertible YTM/remainingYears columns (#2131), four wrong Dianping city IDs (#2280), Amazon honoring the input marketplace instead of rewriting to .com (#2185), and Twitter no longer reporting an unrelated tweet as the posted permalink (#2251). If you built reports on those fields, re-pull your data.
  • Dependency security — js-yaml was bumped twice, to 4.3.0 for GHSA-52cp-r559-cp3m (#2186) and then 4.3.1 for GHSA-5p4m-2wfm-xmqj (#2267). No action for normal consumers, but if you vendor adapters or bundle OpenCLI, refresh your lockfile to pick up both advisories.
  • Stricter args and internal cleanup — Invalid integer values are now rejected (#2300), caret ranges below 1.0.0 are honored for plugins (#2299), completion falls back on invalid manifests (#2298), and discovery warns instead of silently dropping skipped YAML adapters (#2229) — previously tolerated bad input may now error. Ejected adapters copy shared deps (#2321), fixing post-eject breakage. A coordinated sweep removed dead/internal symbols, retired tab/explore/DOM helpers, an unused TUI prompt, dead error exports, and orphan test hooks (#2323–#2330); public adapter commands are unaffected, but plugin authors reaching into internal paths should re-check imports. On the plus side, the CI now gates a daemon transport contract and headless AX smoke tests on all platforms (#2081, #2082).

No breaking changes.

What's Changed
