OpenCLI v1.8.5

Highlights

  • Typed errors replace sentinel rows — Adapters now surface empty results as EmptyResultError instead of fabricated sentinel rows (#1981), DeepSeek throws TimeoutError on no-reply rather than a silent placeholder (#1983), Bilibili raises structured PAID_CONTENT before fetching paid media (#1947), and Xiaohongshu login walls emit AUTH_REQUIRED alongside a hydration-race fix (#1945). Consumers that parsed sentinel rows must migrate to catching typed errors — this is the change most likely to silently break downstream parsing, so audit error paths first. Browser goto retry also now treats a bare Page not found: as an invalid-identity signal (#1869).
  • Wide adapter expansion — New read-only sources land in one release: Internet Archive (#1969), Semantic Scholar academic graph (#1994), GitHub Trending (#1953), Juejin (#2007), and no-login Chinese car platforms 懂车帝/瓜子二手车/汽车之家 (#2009), plus Kimi usage (#1985), a full Zhihu user/answers/articles/following/followers/pins suite (#1986), and Xiaohongshu saved/liked collections (#1920). Notably, several require no auth setup, widening coverage without new credential plumbing.
  • Fixed daemon bridge port & reconnect recovery — The browser daemon bridge is pinned to a fixed port (#2031) with unified active-ensure and reconnect recovery, "Layer 1b" (#2032); E2E tests were reworked to match (#2036, #2037). Watch out if you ran multiple daemon instances or custom bridge wiring — the port is no longer dynamic. The CLI also now tolerates a trailing --window option (#1963).
  • Schema-affecting fields — video commands expose paid/member markers (#1946), Xiaohongshu ask sources add like_count/note_type/user_id/published_at (#1965), and SMZDM search results gain interaction metrics and update time (#1968). Update downstream schemas accordingly. Bilibili also gains --page for multi-part (分P) selection across video/subtitle/download (#2003), and Xianyu search moves price-range and region filters server-side via the mtop API (#2013).
  • Scraper reliability and speed — Reddit drops a redundant pre-navigation step, halving per-command navigation (#1987); Twitter enables paginated backfills (#2033) with a 2-second default page delay to ease rate limiting (#2034); Qwen anchors waitForAnswer to stop returning stale prior answers (#1982); download host matching moves from substring to host-boundary to avoid false platform hits (#1937); Gemini matches Traditional Chinese "send" labels (#1967) and expands collapsed Recents before history extraction (#1962).
  • CLI UX and misc resilience — opencli list now splits into App vs Site sections (#2000) and the README recommends the OpenCLIApp install path (#1996); ChatGPT gains project commands (#1992) and current intelligence-level support (#1966), while 12306 handles endpoint rotation via 302 redirects (#1999).

No breaking changes in this patch release.
