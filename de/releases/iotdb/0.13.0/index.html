iotdb v0.13.0

Neue Funktionen

  • [IOTDB-924] Unterstützt das Einfügen mehrerer Zeilen in SQL
  • [IOTDB-959] Grammatik zum Erstellen von Speichergruppen hinzufügen
  • [IOTDB-1037] hat rpc_compression als Parameter in der JDBC-URL festgelegt
  • [IOTDB-1059] Unterstützt das Einfügen von SQL-Anweisungen ohne Zeitstempel
  • [IOTDB-1143] Unterstützt kontinuierliche Abfrage
  • [IOTDB-1199] Unterstützt ausgerichtete Zeitreihen und Schemavorlagen
  • [IOTDB-1319] Support-Trigger
  • [IOTDB-1391] Fügen Sie ein neues Aggregationsfunktions-Extrem hinzu (maximaler Absolutwert)
  • [IOTDB-1399] Fügen Sie eine Sitzungsschnittstelle hinzu, um mehrere Knoten zu verbinden
  • [IOTDB-1400] Unterstützt arithmetische Operationen in SELECT-Klauseln
  • [IOTDB-1403] Wörterbuchkodierung für TEXT
  • [IOTDB-1490] Integrierte UDTFs hinzufügen: sinh, conh, tanh
  • [IOTDB-1514] Unterstützt Null in insertTablet
  • [IOTDB-1524] Unterstützt die SELECT ... INTO ...-Klausel
  • [IOTDB-1647] Verschachtelte Ausdrücke in SELECT-Klauseln
  • [IOTDB-1673] CLI-Upgrade auf JLine3
  • [IOTDB-1739] Funktionen zur Erzeugung konstanter Zeitreihen (const, pi und e)
  • [IOTDB-1760] Unterstützt die Aggregationen „Durchschnitt“, „Anzahl“, „Extrem“, „erster_Wert“, „letzter_Wert“, „max_time“, „max_value“, „min_time“, „min_value“ und „Summe“ in der Gruppe nach Füllung
  • [IOTDB-1761] Metrik-Framework für IoTDB hinzufügen
  • [IOTDB-1775] CAST-Funktion zum Konvertieren des Datentyps hinzugefügt
  • [IOTDB-1823] Support-Gruppe nach mehreren Ebenen
  • [IOTDB-1844] Abfrage unterstützt Zeitreihen-Präfix- und Suffix-Übereinstimmung: root.*sg*
  • [IOTDB-1859] Unterstützt REST API
  • [IOTDB-1860] Neues Grafana-Plugin
  • [IOTDB-1886] Unterstützt konstante Ausdrücke in ausgewählten Klauseln
  • [IOTDB-1973] Unterstützt Aggregatabfragen, Konstanten und arithmetisch verschachtelte Ausdrücke in SELECT-Klauseln
  • [IOTDB-1986] Unterstützt „select UDF as alisa“-Klauseln
  • [IOTDB-1989] Spark-IoTDB-Connector unterstützt das Einfügen von Daten
  • [IOTDB-2131] Unterstützt die vorherige, lineare Füllfunktion mit konstanten Werten. Neue Füllung
  • [IOTDB-2593] Unterstützung bei der Verwendung von IoTDB mit JDK17
  • [ISSUE-3811] Stellen Sie eine Datentypspalte für den letzten Abfragedatensatz bereit
  • Rabbitmq-Beispiel hinzufügen

Verbesserungen

  • [IOTDB-1280] Schreiben Sie die Antlr-Grammatikdatei neu
  • [IOTDB-1372] Verbesserte Verwaltung von TsFileResource
  • [IOTDB-1428] Bitten Sie Abfrage-Threads, sich zu beenden, wenn bei der Abfrage eine Zeitüberschreitung vorliegt
  • [IOTDB-1450] Beim Löschen sollten nur zugehörige Zeitpartitionen gelöscht werden
  • [IOTDB-1463] Builder-Muster für Session und SessionPool implementieren
  • [IOTDB-1477] Optimieren Sie die Codelogik von genericAlignByDevicePlan()
  • [IOTDB-1559] Refaktorieren Sie das IT-Framework

  • [IOTDB-1607] Ablaufverfolgung optimieren
  • [IOTDB-1613] Mods-Datei wiederherstellen, wenn die Schreibänderung fehlgeschlagen ist
  • [IOTDB-1639] Refactoring der Cluster-Klassenstruktur, um sie mit dem Servermodul konsistent zu machen
  • [IOTDB-1730] client-cpp, verbessert die Leistung von session::insertTablet() usw
  • [IOTDB-1852] Beschleunigen Sie Abfragen durch die Verwendung von Statistiken
  • [IOTDB-1857] Entfernen Sie nutzlose Handle-Logik für CountPlan inexecuteNonQuery im Cluster-Modul
  • [IOTDB-1884] Unterscheiden Sie zwischen Null- und Nullwerten bei der Summenaggregation
  • [IOTDB-1924] Entfernen Sie den Vorgang zum Löschen des Caches nach Abschluss der Komprimierung
  • [IOTDB-1950] Bloom-Filter-Cache für Abfrage hinzufügen
  • [IOTDB-2001] Redundante StorageGroupNotReadyException entfernen
  • [IOTDB-2011] Letzten Cache aktualisieren, während die Abfrage der neuesten Zeitreihen angezeigt wird
  • [IOTDB-2022] SessionDataSet implementiert AutoCloseable
  • [IOTDB-2075] Beschleunigen Sie den Prozess von insertTablets durch Verwendung des Thread-Pools
  • [IOTDB-2119] IoTDB CSV-Exporttools fügen eine Funktion zur Einstellung der Zeitstempelgenauigkeit hinzu
  • [IOTDB-2162] Vereinfachen Sie den Wiederherstellungszusammenführungsprozess
  • [IOTDB-2176] Begrenzen Sie die Zielblockgröße, wenn Sie eine Innenraumkomprimierung durchführen
  • [IOTDB-2193] Reduzieren Sie unnötige Sperrvorgänge von RaftLogManager, um die Schreibleistung zu verbessern
  • [IOTDB-2195] Steuern Sie den Thread zur gleichzeitigen Abfrageausführung
  • [IOTDB-2632] Legen Sie „compaction_write_throughput_mb_per_sec“ standardmäßig auf 16 fest
  • [ISSUE-3445] Neue Verdichtungsstrategie und Verdichtungsplanungsstrategie
  • [ISSUE-3856] Verfeinerung der Ausnahmebehandlungslogik in commitTo in RaftLogManager
  • [Cluster] Es ist nicht nötig, sich selbst die Hand zu schütteln, wenn ein Knoten neu startet

Inkompatible Änderungen

  • [IOTDB-1026] Unterstützt Platzhalter ** im Pfad und ersetzt die Verwendung von PrefixPath durch PathPattern in IOTDB-SQL
  • [IOTDB-1620] Unterstützt Backtick-Zeichen (`) und doppelte Anführungszeichen ("), um Bezeichner in Anführungszeichen zu setzen
  • [IOTDB-1650] Benennen Sie den SQL-Befehl move in unload um

  • [IOTDB-1342] Fehlermeldung zu LIMIT und OFFSET geändert, die in Verbindung mit der FILL-Klausel verwendet werden
  • [IOTDB-1372] Gerätefeld in FileTimeIndex löschen
  • [IOTDB-1531] Überprüfen Sie bei der Wiederherstellung die Erstellungszeit der TS-Datei

  • [IOTDB-1923] Trennen Sie die Logik zum Entpacken der Anforderung und zur Verarbeitung der Ausführung von TSServiceImpl

  • [IOTDB-2014] MicrometerPrometheusReporter#getReporterType gibt null zurück

  • [IOTDB-2206] Benennen Sie StorageGroupProcessor in VirtualStorageGroupProcessor um

  • [ISSUE-4047] Der generische Typ in Statistics erweitert die Serialisierbarkeit

  • Fügen Sie einen Konstruktor von IoTDBDescriptorHolder hinzu, um die Instanziierung zu verhindern

iotdb v0.13.0

New Features

  • [IOTDB-924] Support insert multi rows in SQL
  • [IOTDB-959] Add Create Storage Group Grammar
  • [IOTDB-1037] set rpc_compression as a parameter in JDBC URL

  • [IOTDB-1143] Support Continuous query
  • [IOTDB-1199] Support aligned timeseries and schema template
  • [IOTDB-1319] Support Trigger
  • [IOTDB-1391] Add a new Aggregation function extreme (max absolute value)
  • [IOTDB-1399] Add a session interface to connect multiple nodes
  • [IOTDB-1400] Support arithmetic operations in SELECT clauses
  • [IOTDB-1403] Dictionary encoding for TEXT
  • [IOTDB-1490] Add built-in UDTFs: sinh, conh, tanh
  • [IOTDB-1514] Support null in insertTablet
  • [IOTDB-1524] Support SELECT ... INTO ... clause
  • [IOTDB-1647] Nested Expressions in SELECT clauses
  • [IOTDB-1673] CLI upgrade to JLine3
  • [IOTDB-1739] Constant timeseries generating functions (const, pi and e)
  • [IOTDB-1760] Support avg, count, extreme, first_value, last_value, max_time, max_value, min_time, min_value, sum aggregations in group by fill
  • [IOTDB-1761] Add metric framework for IoTDB
  • [IOTDB-1775] Add CAST function to convert data type
  • [IOTDB-1823] Support group by multi level
  • [IOTDB-1844] Query support timeseries prefix and suffix matching: root.*sg*
  • [IOTDB-1859] Support REST API
