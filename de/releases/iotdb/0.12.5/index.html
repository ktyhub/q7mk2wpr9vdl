iotdb v0.12.5

Neue Funktionen

  • [IOTDB-2078] Großes TsFile-Tool teilen
  • [IOTDB-2192] Unterstützt extreme Funktionen

Verbesserungen

  • [IOTDB-1297] Refaktorieren Sie die Speichersteuerung beim Aktivieren von Zeitpartitionen
  • [IOTDB-2195] Steuern Sie den Thread zur gleichzeitigen Abfrageausführung
  • [IOTDB-2475] SG-Not-Ready-Log im Batch-Prozess entfernen
  • [IOTDB-2502] Fügen Sie die SQL-Abfrage zum Fehlerprotokoll hinzu, wenn eine Ausnahme auftritt
  • [IOTDB-2506] Verfeinern Sie die Sperrgranularität der Aggregationsabfrage
  • [IOTDB-2534] Zeichenunterstützung bei Verwendung von doppelten Anführungszeichen hinzufügen
  • [IOTDB-2562] Standardwert des Parameters „Synchronisierungs-Mlog-Zeitraum“ ändern
  • Vermeiden Sie, dass zu viele Warnprotokolle gedruckt werden, wenn zu viele Dateihandler geöffnet werden

Fehlerbehebungen

  • [IOTDB-1960] Fehler bei der Zählung von Zeitreihen im Clustermodus behoben
  • [IOTDB-2174] Fehler bei der Serialisierung und Deserialisierung des Regexp-Filters behoben
  • [IoTDB-2185] Behebung eines Ausnahmefehlers beim Parsen des CSV-Headers
  • [IOTDB-2194] Fix SHOW TIMESERIES zeigt im Cluster-Modus nur 2000 Zeitreihen an
  • [IOTDB-2197] Ausnahme bei der Datentypkonvertierung im Spark Connector behoben
  • [IOTDB-2209] Problem mit der Protokollierung CVE-2021-42550 behoben
  • [IOTDB-2219] Behebung, dass Abfrage-In-Memory-Daten im Cluster-Modus falsch sind
  • [IOTDB-2222] Fehler im Spark Connector behoben, bei denen OOM und Daten falsch geschrieben wurden
  • [IOTDB-2251] [IOTDB-2252] Abfrage-Deadlock behoben
  • [IOTDB-2282] Fehler bei der Tag-Wiederherstellung nach Tag-Aktualisierung behoben
  • [IOTDB-2320] MemoryLeak verursacht durch wal Geplanten Trim-Task-Thread
  • [IOTDB-2381] Deadlock behoben, der durch einen falschen Pufferpoolgrößenzähler verursacht wurde
  • [IOTDB-2400] Fehler beim Serienleser behoben
  • [IOTDB-2426] WAL-Deadlock verursacht durch zu viele geöffnete Dateien
  • [IOTDB-2445] Behebung des Fehlers „Überlappende Daten sollten zuerst verbraucht werden“.
  • [IOTDB-2499] Fehler bei der Division durch Null beim Wiederherstellen der Zusammenführung behoben
  • [IOTDB-2507] NPE bei der Zusammenführungswiederherstellung behoben
  • [IOTDB-2528] Behebung des MLog-Beschädigungs- und Wiederherstellungsfehlers nach dem Beenden des Systems
  • [IOTDB-2532] Behebung einer Abfrage mit Ausrichtung nach Gerät, nach dem Löschen des Caches konnte kein Wert abgerufen werden
  • [IOTDB-2533] Fix-Änderung max_deduplicated_path_num wird nicht wirksam
  • [IOTDB-2544] Fehler bei der Tag-Info-Synchronisierung während der Metadaten-Synchronisierung behoben
  • [IOTDB-2550] Fehler beim Anzeigen der Zeitreihen nach dem Ändern des Tags beim Synchronisierungssender vermeiden
  • [IOTDB-2567] Thread- und ByteBuffer-Leck behoben, nachdem der Dienst beendet wurde
  • [IOTDB-2568] „Abfrageprozessliste anzeigen“ ist blockiert
  • [IOTDB-2580] DirectByteBuffer und Thread-Leck beim Löschen der Speichergruppe behoben
  • [IOTDB-2584] Korrigieren Sie den Cross-Space-Komprimierungsselektor
  • [IOTDB-2603] Komprimierungswiederherstellung behoben
  • [IOTDB-2604] Fix-Batchgröße ist im Import-CSV-Tool ungültig
  • [IOTDB-2620] Nicht erkennbarer Operatortyp (SHOW) für AuthorityChecker
  • [IOTDB-2624] Fix „Überlappende Daten sollten zuerst verbraucht werden“ tritt beim Ausführen einer Abfrage auf
  • [IOTDB-2640] Fehler bei der Wiederherstellung durch Kreuzkomprimierung behoben
  • [IOTDB-2641] Zeitbereich von TsFile-Ressourcenüberlappungen nach unseq-Komprimierung behoben
  • [IOTDB-2642] Behebung, dass die neue Datei bei der unseq-Komprimierung eine höhere Komprimierungspriorität hat als die alte Datei
  • Behebung eines logischen Fehlers in ProcessPlanLocally im Cluster-Modus
  • Löst eine Ausnahme aus, wenn die letzte Abfrage mit der Ausrichtung nach Gerät verwendet wird
  • Fügen Sie eine Beurteilung hinzu, um zu bestimmen, ob die Raft-Protokollgröße in den Puffer passt, bevor das Protokoll im Cluster-Modus angehängt wird
  • Behebung des Fehlers „grafana kann nicht verwendet werden“.

Englisches Original / English original

iotdb v0.12.5

New Features

  • [IOTDB-2078] Split large TsFile tool
  • [IOTDB-2192] Support extreme function

Improvements

  • [IOTDB-1297] Refactor the memory control when enabling time partitions
  • [IOTDB-2195] Control the concurrent query execution thread
  • [IOTDB-2475] Remove sg not ready log in batch process
  • [IOTDB-2502] Add query sql in error log if encountering exception
  • [IOTDB-2506] Refine the lock granularity of the aggregation query
  • [IOTDB-2534] add character support while using double quote
  • [IOTDB-2562] Change default value of sync mlog period parameter
  • Avoid too many warning logs being printed, when opening too many file handlers

Bug Fixes

  • [IOTDB-1960] Fix count timeseries bug in cluster mode
  • [IOTDB-2174] Fix Regexp filter serializing and deserializing error
  • [IoTDB-2185] fix get an exception bug when parsing the header of CSV
  • [IOTDB-2194] Fix SHOW TIMESERIES will only display 2000 timeseries in cluster mode
  • [IOTDB-2197] Fix datatype conversion exception in Spark Connector
  • [IOTDB-2209] Fix logback CVE-2021-42550 issue
  • [IOTDB-2219] Fix query in-memory data is incorrect in cluster mode
  • [IOTDB-2222] Fix OOM and data was written in incorrectly bugs of Spark Connector
  • [IOTDB-2251] [IOTDB-2252] Fix Query deadlock
  • [IOTDB-2282] fix tag recover bug after tag update
  • [IOTDB-2320] MemoryLeak cause by wal Scheduled trim task thread
  • [IOTDB-2381] Fix deadlock caused by incorrect buffer pool size counter
  • [IOTDB-2400] Fix series reader bug
  • [IOTDB-2426] WAL deadlock caused by too many open files
  • [IOTDB-2445] Fix overlapped data should be consumed first bug
  • [IOTDB-2499] Fix division by zero error when recovering merge
  • [IOTDB-2507] Fix NPE when merge recover
  • [IOTDB-2528] Fix MLog corruption and recovery bug after killing system
  • [IOTDB-2532] Fix query with align by device can't get value after clear cache
  • [IOTDB-2533] Fix change max_deduplicated_path_num does not take effect
  • [IOTDB-2544] Fix tag info sync error during metadata sync
  • [IOTDB-2550] Avoid show timeseries error after alter tag on sync sender
  • [IOTDB-2567] Fix thread and ByteBuffer leak after service stopped
  • [IOTDB-2568] "show query processlist" is blocked
  • [IOTDB-2580] Fix DirectByteBuffer and thread leak when deleting storage group
  • [IOTDB-2584] Fix cross space compaction selector
  • [IOTDB-2603] Fix compaction recover
  • [IOTDB-2604] Fix batch size is invalid in import-csv tool
  • [IOTDB-2620] Unrecognizable operator type (SHOW) for AuthorityChecker
  • [IOTDB-2624] Fix "overlapped data should be consumed first" occurs when executing query
  • [IOTDB-2640] Fix cross compaction recover bug
  • [IOTDB-2641] Fix time range of TsFile resource overlaps after unseq compaction
  • [IOTDB-2642] Fix the new file has a higher compact priority than the old file in unseq compaction
  • Fix a logical bug in processPlanLocally in cluster mode
  • Throw Exception while using last query with align by device
  • Add a judgement to determine raft log size can fit into buffer before log appending in cluster mode
  • Fix grafana can't be used bug
