opentelemetry-Kollektor v0.162.0

Endbenutzer changelog

🛑 Breaking Changes 🛑

  • cmd/mdatagen: Generierte Prozessorlebenszyklustests bestätigen jetzt, dass der Prozessor den eingehenden Kontext standardmäßig unverändert an den nächsten Verbraucher weitergibt. (#15994) Mit skip_context_propagation: true deaktivieren
  • processor/queue_batch: queuebatch-Prozessor in queue_batch-Prozessor umbenennen. (#14396)

💡 Verbesserungen 💡

  • extension/memory_limiter: Fügen Sie die Metrik otelcol_memorylimiter_refused_requests hinzu, um Ablehnungen von Netzwerkanfragen im Erweiterungsmodus aufzuzeichnen. (#15561)
  • pkg/confighttp: Keepalive-Konfiguration standardmäßig aktivieren. (#16026) Stellt das Feature-Gate pkg.confighttp.PrioritizeNewKeepalive vor. Wenn diese Flagge deaktiviert ist Stellt das alte Verhalten des Entfernens der Keepalive-Konfiguration wieder her der veralteten Felder IdleConnTimeout, MaxIdleConns, MaxIdleConnsPerHost, DisableKeepAlives, wenn das Flag deaktiviert ist.
  • pkg/exporterhelper: Machen Sie das Leerlauf-Timeout der Partition über batch::partition::idle_timeout konfigurierbar und erhöhen Sie den Standardwert auf 90 Sekunden. (#15894)
  • pkg/exporterhelper: Machen Sie die LRU-Cache-Größe der Multi-Batcher-Partition konfigurierbar und exportieren Sie Cache-Größenmetriken. (#14526) Fügt sending_queue::batch::partition::cache_size (Standard 10000) hinzu, um die zu begrenzen Anzahl der aktiven Partitions-Batcher. Der Wert muss positiv sein. Aktuelle Größe und konfigurierte Kapazität werden exportiert als otelcol_exporter_queue_batch_partition_cache_size und otelcol_exporter_queue_batch_partition_cache_capacity.
  • pkg/pprofile: Beschleunigen Sie das Zusammenführen von Profilwörterbüchern während der Batchverarbeitung in der Exporter-Warteschlange, indem Sie die Deduplizierung des linearen Scans in switchDictionary durch eine indizierte Suche ersetzen, wodurch die Kosten pro Zusammenführung von O(N*L^2) auf O(N+L) gesenkt werden. (#15544) Keine Verhaltensänderung: Zusammengeführte Wörterbuchinhalte und neu zugeordnete Indizes sind identisch mit zuvor. – pkg/receiverhelper: Stoppen Sie die Zuweisung eines Span-Links, der immer verworfen wird, wenn ein langlebiger Kontextempfänger einen Vorgang ohne einen übergeordneten Span-Kontext startet. (#15998) Mit LongLivedCtx: true erstellte Empfänger erstellen keinen trace.Link mehr, wenn die Der langlebige Kontext enthält keinen gültigen Span-Kontext. Der SDK hat einen solchen Link bereits verworfen, Das Verhalten bleibt also unverändert. Dadurch werden 3 von 7 Zuweisungen pro Empfangsvorgang entfernt.
  • pkg/xpdata: Reduzieren Sie die Zeit, die xhash.MapHash für Karten mit vielen Einträgen benötigt. (#15990)

🧰 Fehlerbehebungen 🧰

– exporter/debug: Unterstützung für die Behandlung bekannter Synchronisierungsfehler unter AIX (#15924) Aktivieren Sie den Debug-Exporter, um bekannte synchrone Fehler unter AIX zu behandeln.

  • pkg/exporterhelper: Beim Aufteilen eines Stapels wird nur der übergroße Artikel gelöscht, anstatt jeden Artikel in der Warteschlange dahinter zu verwerfen (#15936) Gilt vorerst nur für Protokolle – pkg/exporterhelper: Exporter- und data_type-Attribute zu Exporter-/Enqueue-Bereichen hinzufügen. (#16022) – receiver/otlp: Der Fehlerhandler behält den HTTP-Statuscode bei, wenn der Inhaltstyp der Anforderung keiner ist, in dem ein Status codiert werden kann (#15995) Erweitert den Fix in #13414, der einen fehlenden Content-Type behandelte. Ein Inhaltstyp, der war vorhanden, aber nicht unterstützt oder missgebildet, fiel dennoch durch 500 {"code": 13, "message": "failed to marshal error message"}, meldet client-Fehler wie 401 von einer Server-Authentifizierungserweiterung oder 400 von einer nicht unterstützten Content-Encoding als Serverfehler.

  • pkg/pdata: Zuweisungen in WriteInt64 und WriteUint64 vermeiden (#15629)

  • cmd/schemagen: Akzeptieren Sie Komponenten, die ohne Konfigurationstext im generierten Collector-Konfigurationsschema geschrieben wurden (#15728) – pkg/confmap: Fehler behoben, bei dem ein maskierter URI, der vor einem gültigen URI erschien, verhinderte, dass der nachfolgende URI erweitert wurde. (#15867) Das URI-Scannen wird jetzt nach einem maskierten URI fortgesetzt, wobei der maskierte Ausdruck als wörtlicher Text erhalten bleibt.
  • pkg/featuregate: Feature-Gate-IDs mit einem leeren, durch Punkte getrennten Segment (führende, nachfolgende oder aufeinanderfolgende Punkte) ablehnen, z. B. .foo, foo., foo..bar. (#15676) – pkg/pprofile: Stoppen Sie das Löschen von Inline-Attributschlüsseln, wenn key_strindex nicht gesetzt ist, und löschen Sie key_strindex, sobald es aufgelöst ist. (#15793) – pkg/pprofile: Verweisen Sie auf Ressourcen- und Bereichsattributzeichenfolgen über die ProfilesDictionary-Zeichenfolgentabelle beim Marshallen und Unmarshaling von Exportanforderungen für OTLP-Profile. (#15792) – pkg/scraperhelper: Behebung, dass das Herunterfahren durch zusätzliche Scrapes verzögert wird, wenn ein Scrape länger als das Sammelintervall läuft (#15736) Wenn beim Auslösen des nächsten Ticks noch ein Scrape ausgeführt wurde, werden der ausstehende Tick und das Herunterfahren angezeigt Das Signal könnte beide bereit sein, wenn es fertig ist, und der Controller wählt nach dem Zufallsprinzip zwischen ihnen aus.

– cmd/mdatagen: Autoren von Konfigurationsmetadaten erlauben, configoptional.Some oder configoptional.Default für generierte optionale Felder auszuwählen (#15977) Legen Sie go_struct.optional_mode: default fest, um eine optionale Objektkonfiguration zu generieren Abschnitt mit einem Fallback-Standard, während er bis zur Konfiguration nicht vorhanden bleibt. Weglassen optional_mode behält das vorhandene configoptional.Some-Verhalten bei.

  • pkg/config/configgrpc: Migrieren Sie Kerntypen allgemeiner Einstellungen für einen gRPC client zur schemabasierten Konfiguration, die von mdatagen generiert wird. (#15967)
  • pkg/exporterhelper: Fügen Sie NewDefaultBatchConfig hinzu, um ein BatchConfig mit Standardwerten zu erstellen, einschließlich der Partitionsstandardwerte cache_size und idle_timeout. (#14526, #15894)
  • pkg/exporterhelper: Machen Sie das Leerlauf-Timeout der Partition über batch::partition::idle_timeout konfigurierbar und erhöhen Sie den Standardwert auf 90 Sekunden. (#15894) – pkg/exporterhelper: Machen Sie die LRU-Cache-Größe der Multi-Batcher-Partition konfigurierbar und exportieren Sie Cache-Größenmetriken. (#14526) Fügt sending_queue::batch::partition::cache_size (Standard 10000) hinzu, um die zu begrenzen Anzahl der aktiven Partitions-Batcher. Der Wert muss positiv sein. Aktuelle Größe und konfigurierte Kapazität werden exportiert als otelcol_exporter_queue_batch_partition_cache_size und otelcol_exporter_queue_batch_partition_cache_capacity. – pkg/xpdata: Pdata-Hash APIs aus dem Contrib-Repo verschieben (#15914)

🧰 Fehlerbehebungen 🧰

(#15984) – pkg/pdata: Korrigieren Sie pcommon.Value.CopyTo, um ValueTypeBytes-Werte tief zu kopieren, anstatt das Hintergrundarray zu teilen (#15621) Das Feld bytes oneof in CopyAnyValue wurde direkt zugewiesen, sodass Kopie und Quelle dasselbe []Byte gemeinsam nutzten. Dies betraf auch Map.CopyTo und Slice.CopyTo, die an CopyAnyValue delegieren.

opentelemetry-collector v0.162.0

End-user changelog

🛑 Breaking changes 🛑

  • cmd/mdatagen: Generated processor lifecycle tests now assert that the processor propagates the incoming context unchanged to the next consumer by default. (#15994) Disable with skip_context_propagation: true

  • processor/queue_batch: Rename queuebatch processor to queue_batch processor. (#14396)

💡 Enhancements 💡

  • extension/memory_limiter: Add otelcol_memorylimiter_refused_requests metric to record network request refusals in extension mode. (#15561)

  • pkg/confighttp: Enable keepalive configuration by default. (#16026) Introduces the feature gate pkg.confighttp.PrioritizeNewKeepalive. When disabled, this flag restores the old behaviour of removing the keepalive configuration in favour of the deprecated fields IdleConnTimeout, MaxIdleConns, MaxIdleConnsPerHost, DisableKeepAlives when the flag is disabled.

  • pkg/exporterhelper: Make the partition idle timeout configurable via batch::partition::idle_timeout and raise the default to 90s. (#15894)

  • pkg/exporterhelper: Make the multi-batcher partition LRU cache size configurable and export cache size metrics. (#14526) Adds sending_queue::batch::partition::cache_size (default 10000) to cap the number of active partition batchers. The value must be positive. Current size and configured capacity are exported as otelcol_exporter_queue_batch_partition_cache_size and otelcol_exporter_queue_batch_partition_cache_capacity.

  • pkg/pprofile: Speed up profiles dictionary merging during exporter-queue batching by replacing the linear-scan dedup in switchDictionary with an indexed lookup, reducing per-merge cost from O(N*L^2) to O(N+L). (#15544) No behavior change: merged dictionary contents and remapped indices are identical to before.

  • pkg/receiverhelper: Stop allocating a span link that is always discarded when a long-lived-context receiver starts an operation without a parent span context. (#15998) Receivers created with LongLivedCtx: true no longer build a trace.Link when the long-lived context carries no valid span context. The SDK already discarded such a link, so behaviour is unchanged. This removes 3 of 7 allocations per receive operation.

  • pkg/xpdata: Reduce the time xhash.MapHash takes for maps with many entries. (#15990)

🧰 Bug fixes 🧰

  • exporter/debug: Support known sync error handling on AIX (#15924) Enable the debug exporter to handle known synchronous errors on AIX.

  • pkg/exporterhelper: Drop only the oversized item when splitting a batch, instead of discarding every item queued behind it (#15936) Applied to logs only for now

  • pkg/exporterhelper: Add exporter and data_type attributes to exporter/enqueue spans. (#16022)

  • receiver/otlp: Error handler preserves the HTTP status code when the request Content-Type is not one a Status can be encoded in (#15995) Extends the fix in #13414, which handled a missing Content-Type. A Content-Type that was present but unsupported, or malformed, still fell through to 500 {"code": 13, "message": "failed to marshal error message"}, reporting client errors such as 401 from a server auth extension or 400 from an unsupported Content-Encoding as server faults.

v1.67.0/v0.161.0

🛑 Breaking changes 🛑

  • pkg/pprofile: Remove deprecated AggregationTemporality, Duration, SetDuration (#15855)
  • pkg/scraperhelper/controller: Remove deprecated AddScraper func (#15934)
  • pkg/service: Remove deprecated ZapOptions (#15935)
  • pkg/xconfmap: Remove deprecated WithForceUnmarshaler func (#15932)

💡 Enhancements 💡

  • pkg/pdata: avoid allocations in WriteInt64 and WriteUint64 (#15629)

🧰 Bug fixes 🧰

  • cmd/schemagen: Accept components written without a configuration body in the generated Collector configuration schema (#15728)

  • pkg/confmap: Fix bug where an escaped URI appearing before a valid URI prevented the subsequent URI from being expanded. (#15867) URI scanning now continues after an escaped URI while preserving the escaped expression as literal text.

  • pkg/featuregate: Reject feature gate IDs with an empty dot-separated segment (leading, trailing, or consecutive dots), e.g. .foo, foo., foo..bar. (#15676)

  • pkg/pprofile: Stop erasing inline attribute keys when key_strindex is unset, and clear key_strindex once it is resolved. (#15793)

  • pkg/pprofile: Reference resource and scope attribute strings via the ProfilesDictionary string table when marshaling and unmarshaling OTLP profiles export requests. (#15792)

  • pkg/scraperhelper: Fix shutdown being delayed by extra scrapes when a scrape runs longer than the collection interval (#15736) If a scrape was still running when the next tick fired, the pending tick and the shutdown signal could both be ready when it finished and the controller chose between them at random.

API changelog

💡 Enhancements 💡

  • cmd/mdatagen: Allow config metadata authors to choose configoptional.Some or configoptional.Default for generated optional fields (#15977) Set go_struct.optional_mode: default to generate an optional object configuration section with a fallback default while keeping it absent until configured. Omitting optional_mode preserves the existing configoptional.Some behavior.

  • pkg/config/configgrpc: Migrate core types of common settings for a gRPC client to schema-based configuration generated by mdatagen. (#15967)

  • pkg/exporterhelper: Add NewDefaultBatchConfig to build a BatchConfig with default values, including the partition cache_size and idle_timeout defaults. (#14526, #15894)

  • pkg/exporterhelper: Make the partition idle timeout configurable via batch::partition::idle_timeout and raise the default to 90s. (#15894)

  • pkg/exporterhelper: Make the multi-batcher partition LRU cache size configurable and export cache size metrics. (#14526) Adds sending_queue::batch::partition::cache_size (default 10000) to cap the number of active partition batchers. The value must be positive. Current size and configured capacity are exported as otelcol_exporter_queue_batch_partition_cache_size and otelcol_exporter_queue_batch_partition_cache_capacity.

  • pkg/xpdata: Move pdata hash APIs from the contrib repo (#15914)

🧰 Bug fixes 🧰

  • cmd/schemagen: Fix RefResolver mutating shared, cached type definitions with per-occurrence annotations, which caused generated schemas to have incorrect (and run-to-run nondeterministic) description/x-optional/x-pointer values whenever multiple fields referenced the same type. (#15984)
  • pkg/pdata: Fix pcommon.Value.CopyTo to deep-copy ValueTypeBytes values instead of sharing the backing array (#15621) The bytes oneof field in CopyAnyValue was assigned directly, so the copy and source shared the same []byte. This also affected Map.CopyTo and Slice.CopyTo, which delegate to CopyAnyValue.
