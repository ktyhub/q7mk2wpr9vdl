whisper.cpp v1.7.5

Übersicht

Dabei handelt es sich um ein relativ großes Update mit diversen Build- und CI-Verbesserungen insbesondere für iOS und WASM. Es gibt auch einige Leistungssteigerungen, insbesondere für das Metal-Backend und wahrscheinlich für Arm-basierte Geräte.

Großes Dankeschön an @danbev für die Intensivierung und Vervollständigung der Wartungs-Roadmap für diese Version!

Mobile Beispiele

Alle mobilen Beispiele wurden aktualisiert. Insbesondere die iOS-Beispiele sind dank des neuen XCFramework-Workflows jetzt viel einfacher zu erstellen. Dies sollte die Integration von whisper.cpp in iOS- und macOS-Apps von Drittanbietern erheblich vereinfachen. Die Anweisungen zum Erstellen und Konvertieren von CoreML wurden ebenfalls aktualisiert.

WASM-Beispiele

Die WASM-Beispiele werden jetzt bei jedem neuen Commit automatisch aktualisiert und auf den Seiten Github unter gehostet https://ggml.ai/whisper.cpp/

Probleme mit CORS-Regeln sollten behoben werden.

whisper.cpp v1.7.5

Overview

This is a relatively big update with various build and CI improvements especially for iOS and WASM. There are also some performance gains, especially for the Metal backend and probably for Arm-based devices.

Big shoutout to @danbev for stepping up and completing the maintenance roadmap for this release!

Mobile examples

All mobile examples have been refreshed. The iOS examples specifically are now much easier to build thanks to the new XCFramework workflow. This should simplify significantly integration of whisper.cpp in 3rd party iOS and macOS apps. CoreML build and convert instructions have also been updated.

WASM examples

The WASM examples are now automatically updated on each new commit and hosted in Github Pages at https://ggml.ai/whisper.cpp/

Problems with CORS rules should be resolved.
