Qdrant Edge :hocho:

Qdrant Edge ist eine In-Process-Version von Qdrant, die dieselben Interna, dasselbe Speicherformat und dieselben Punkte wie die Serverversion aufweist, jedoch für den lokalen Betrieb konzipiert ist. Qdrant Edge ist mit der Serverversion kompatibel und kann Shard-Snapshots lesen, die mit der Serverversion von Qdrant erstellt wurden. Weitere Dokumentation finden Sie hier.

Abwertungen :warnung:

  • Ab v1.17.0 ändert Qdrant das Antwortformat für Vektorfelder in der gRPC-Schnittstelle. Alle offiziellen Qdrant clients sollten bereits an diese Änderung angepasst sein. Stellen Sie daher bitte sicher, dass Sie Ihre client-Bibliotheken aktualisieren und sicherstellen, dass Sie keine veralteten Felder verwenden. Weitere Informationen: https://github.com/qdrant/qdrant/pull/7183

  • Bevorstehende Einstellung:

    • In Qdrant v1.18.x werden alle veralteten Suchmethoden vollständig entfernt und sind nicht einmal in alten client-Bibliotheken verfügbar.
    • In Qdrant v1.17.x werden wir die RocksDB-Unterstützung vollständig zugunsten von gridstore entfernen, was bedeutet, dass ein direktes Upgrade von v1.15.x auf v1.17.x nicht möglich ist. Bitte befolgen Sie die Upgrade-Anweisungen und aktualisieren Sie jeweils eine Nebenversion, um nicht unterstützte Speicherfehler zu vermeiden. Beachten Sie, dass die Qdrant Cloud-Infrastruktur automatisch die richtigen Upgrade-Schritte generiert, sodass Sie sich darüber keine Sorgen machen müssen.

Qdrant Edge :hocho:

Qdrant Edge is an in-process version of Qdrant, which shares the same internals, storage format, and points API as the server version, but designed to work locally. Qdrant Edge is compatible with server version and it can read shard snapshots created by server version of Qdrant. More documentation available here.

Deprecations :warning:

  • Starting from v1.17.0 Qdrant changes response format for vector fields in gRPC interface. All official Qdrant clients should be already adopted to this change, so please make sure you upgrade your client libraries and check that you are not using deprecated fields. More info: https://github.com/qdrant/qdrant/pull/7183

  • Upcoming deprecations:

    • In Qdrant v1.18.x all deprecated search methods will be completely removed and won't be available even from old client libraries.
    • In Qdrant v1.17.x we will completely remove RocksDB support in favor of gridstore, that means that direct upgrade from v1.15.x into v1.17.x won't be possible. Please follow upgrade instructions and upgrade one minor version at a time to avoid unsupported storage errors. Note that Qdrant Cloud infrastructure automatically generates a proper upgrade steps, so you don't have to worry about that.
