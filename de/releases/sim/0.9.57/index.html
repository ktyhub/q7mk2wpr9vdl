sim v0.9.57

Funktionen

  • feat(monaco): Monaco CRM-Integration hinzufügen (#10009)
  • Kunststück (Computernutzung): Batch 2-8 Aktionen pro Aufruf und Lesen des App-Status in einem Roundtrip pro Element (#9995)

Verbesserungen

  • Verbesserung (Suche): Überspringen Sie die Slack-Kanalsuche bei kanalbezogenen Suchen und lesen Sie Kanalnamen in jedem Skript (#10023)
  • Verbesserung (Anmeldeinformationen): Nicht gespeicherte schlüssellose Themen werden zurückgehalten, damit die später angewendeten trust-Richtlinien immer noch übereinstimmen (#10011)
  • Verbesserung (Blöcke): Teilen Sie den Tool-Call-Fallback-Helper und bereinigen Sie den Hex/Stripe-Validierungscode (#10014)
  • Verbesserung (Suche): Benennen Sie passende Slack-Kanäle und sagen Sie, ob ein gefilterter Kanal vorhanden ist (#10007) – Verbesserung (search-mcp): Protokollieren, warum ein Batch-Lesevorgang einen Fehler für ein Dokument zurückgegeben hat (#10010)
  • Verbesserung (search-mcp): Protokollieren Sie die Feldnamen, die die Argumente eines abgelehnten Tool-Aufrufs enthalten (#10003)
  • Verbesserung (Computernutzung): Leere Layoutgruppen falten und den im Modell angezeigten Barrierefreiheitsbaum komprimieren (#9997)
  • Verbesserung (Computernutzung): Aktivitätsleiste über dem Chat-Composer entfernen (#9994)

Fehlerbehebungen

  • Fix (Computernutzung): Geben Sie nach einem Fokus click nur ein, wenn das Caret am Ende bestätigt wird (#10019)
  • fix(hex): Geben Sie die Ausgabe des Blocks projectVersion als „any“ ein und markieren Sie Kategoriebeschreibungen als optional (#10022) – Fix(Anmeldeinformationen): Begrenzen Sie die Databricks-Identitätsprüfung mit einer Frist und melden Sie keine Sperre für einen nicht zurückgehaltenen Reconnect-Betreff (#10021)
  • Fix(Monaco): Einen Phasenschlüssel und eine Phasen-ID zusammen bei Opportunity-Schreibvorgängen ablehnen (#10020)
  • Fix(Slack): Block Kit-Nachrichten dürfen Benachrichtigungstext enthalten (#10018)
  • Fix (Desktop-Browser): Verweigerung der Eingabe hinter einem nicht markierten Vollbild-Modal oder wenn kein abgetasteter Punkt landet (#10013)
  • Fix (Computernutzung): Batch- und click-to-Focus-Randfälle aus dem Staging-Audit verschärfen (#10012) – Fix(Google-Drive): Behalten Sie das Seitentoken bei, das ein Agent weitergibt (#10008) – Fix(blockiert): Behalten Sie die vom Agenten bereitgestellten Tool-Argumente bei, die die Neuzuordnung von Mappern aus dedizierten Feldern blockieren (#10006)
  • fix(hex,stripe): Hex und Stripe anhand ihrer API-Dokumente validieren (#10005)
  • Fix (Computernutzung): click einen Editor in den Fokus, wenn Accessibility ihn nicht fokussieren kann (#10004) – Fix(aws-marketplace): Überprüfen Sie die nicht gezählte Nutzungsberechtigung der Containerlizenz, damit jedes Replikat Enterprise aktiviert (#9996)

Weitere Änderungen

  • chore(credentials): Verschieben Sie das IAM-Ablehnungs-TSDoc zurück nach iamFailureMessage (#10024)
  • Dokumente (Bibliothek): Best-AI-Agent-Platforms-2026 aktualisieren (#10002)
  • Dokumente (Bibliothek): Best-ai-agents-invoice-processing-finance-reconciliation-2026 aktualisieren (#10000)
  • Dokumente (Bibliothek): Open-Source-AI-Agent-Plattformen aktualisieren (#10001)
  • Dokumente (Bibliothek): Best-AI-Agents-for-Customer-Support-Automation aktualisieren (#9999)
  • docs(library): best-ai-agent-marketplaces-template-libraries aktualisieren (#9998)

Englisches Original / English original

sim v0.9.57

Features

  • feat(monaco): add Monaco CRM integration (#10009)
  • feat(computer-use): batch 2-8 actions per call and read app state in one round trip per element (#9995)

Improvements

  • improvement(search): skip the Slack channel lookup on channel-scoped searches and read channel names in any script (#10023)
  • improvement(credentials): hold unsaved keyless subjects so trust policies applied later still match (#10011)
  • improvement(blocks): share the tool-call fallback helper and tidy the Hex/Stripe validation code (#10014)
  • improvement(search): name matching Slack channels and say whether a filtered channel exists (#10007)
  • improvement(search-mcp): log why a batched read returned an error for a document (#10010)
  • improvement(search-mcp): log the field names a rejected tool call's arguments carry (#10003)
  • improvement(computer-use): fold empty layout groups and compact the accessibility tree shown to the model (#9997)
  • improvement(computer-use): remove the activity strip above the chat composer (#9994)

Bug Fixes

  • fix(computer-use): type after a focus click only once the caret is confirmed at the end (#10019)
  • fix(hex): type the block projectVersion output as any and mark category descriptions optional (#10022)
  • fix(credentials): cap the Databricks identity check with a deadline and report no hold for an unheld reconnect subject (#10021)
  • fix(monaco): reject a stage key and a stage ID together on opportunity writes (#10020)
  • fix(slack): let Block Kit messages carry notification text (#10018)
  • fix(desktop-browser): refuse typing behind an unmarked full-screen modal or when no sampled point lands (#10013)
  • fix(computer-use): tighten batch and click-to-focus edge cases from the staging audit (#10012)
  • fix(google-drive): keep the page token an agent passes (#10008)
  • fix(blocks): keep agent-supplied tool args that block mappers remap from dedicated fields (#10006)
  • fix(hex,stripe): validate Hex and Stripe against their API docs (#10005)
  • fix(computer-use): click an editor into focus when Accessibility cannot focus it (#10004)
  • fix(aws-marketplace): check the container license's uncounted usage entitlement so every replica turns Enterprise on (#9996)

Other Changes

  • chore(credentials): move the IAM refusal TSDoc back onto iamFailureMessage (#10024)
  • docs(library): update best-ai-agent-platforms-2026 (#10002)
  • docs(library): update best-ai-agents-invoice-processing-finance-reconciliation-2026 (#10000)
  • docs(library): update open-source-ai-agent-platforms (#10001)
  • docs(library): update best-ai-agents-for-customer-support-automation (#9999)
  • docs(library): update best-ai-agent-marketplaces-template-libraries (#9998)
