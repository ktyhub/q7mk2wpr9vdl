sim v0.9.39

Funktionen

  • feat(library): AI Agent Output Controls im Vergleich: Leitplanken, strukturierte Ausgaben und Streaming (#9539)
  • feat(library): Beste KI-Agenten für Jira Triage und Datadog Incident Response (#9536)
  • feat(mothership): Beantworten Sie einen langen Workflow-Tool-Lauf, der noch läuft, und stoppen Sie getrennte Läufe bei Stop (#9507)
  • feat(people): Personenseite der Organisation mit Profilen, Berichtslinien und Personendatenimport (#9517)
  • feat(desktop): Setzen Sie die Anmeldung mit einem Passkey in Ihrem Browser fort und bringen Sie die Sitzung zurück (#9515)
  • feat(mothership): Privaten Speicher löschen, wenn ein Mitglied austritt oder eine Organisation gelöscht wird (#9503)

Verbesserungen

  • Verbesserung (Dokumente): Sammeln Sie Leser-Feedback inline (#9538)
  • Verbesserung (Release): Favoriten, Sim-Links und die Erweiterung aus einem Vorab-Release-Audit härten (#9530)
  • Verbesserung (Suche): Live-Suchphasen überlappen und jede nicht durchsuchte Quelle melden (#9514)
  • Verbesserung (Desktop): Anmeldeaufforderungen für den Agentenbrowser – Site-Passwörter, Passkey-Konten, client-Zertifikate und App-Links (#9521)
  • Verbesserung (cli): SIM-Anmeldeinformationsanbieter listet Anbieter auf (#9522)
  • Verbesserung (Desktop): Updates auf einem click installieren und nur nach echten Arbeiten während des Flugs fragen (#9505)
  • Verbesserung (cli): Beim Stapellöschen von Dateien werden Datei-IDs als Argumente verwendet (#9518)
  • Verbesserung (Desktop): Browsermenüs, Tasten und Vollbild des Agenten an Chrome anpassen (#9512)
  • Verbesserung (Erweiterung): Datenverarbeitung im Dokumentbrowser und eingeschränkte Nutzung
  • Verbesserung (Erweiterung): Datenverarbeitung im Dokumentbrowser und eingeschränkte Nutzung (#9513)
  • Verbesserung (oauth): Noch gültige Token bereitstellen und vor Ablauf aktualisieren (#9509)
  • Verbesserung (Sim-Links): Abfragen weiterleiten, eingefügte Satzzeichen entfernen und Links aus der Adressleiste vorschlagen (#9508)

Fehlerbehebungen

– Fix(Dateien): Teilen Sie ein Served-Bytes-Prädikat zwischen der Serve-Route und großen Downloads (#9548)

  • Fix(Release): Excel-Startdaten lesen, unmögliche Zeiten und wiederholte Spalten ablehnen, eingegebene Escapezeichen beibehalten, keine Vorschläge für Interpunktion (#9545)
  • fix(oauth): Standardmäßig wird das Warten eines Leader-Lock-Followers auf die Lease eingestellt, damit seine Übernahme landen kann (#9546)
  • Fix(Desktop): Überprüfung der Veröffentlichung beheben – App-Downloads und ungeprüfte Terminals vor einem Update-Neustart zählen, den Seitenverweis bei „Bild speichern“ senden und Anmelde- und Personenrandfälle verschärfen (#9547)
  • fix(ci): Löschen Sie das Duplikat --accept-routes, das die Tailscale-Aktion bereits durchläuft (#9543)
  • fix(files): Streamte bereitgestellte Dateien mit Bytebereichen, anstatt sie unter 100 MB zu puffern (#9542)
  • fix(files): v2-Dateipfade werden nur auf der v2-Oberfläche durch den kanonischen Resolver aufgelöst (#9531) – fix(oauth): eine abgelaufene Aktualisierungsmiete übernehmen, überlappende Lesevorgänge für Dienstkontoschlüssel teilen und nicht durchsuchte Konten kennzeichnen (#9537)
  • fix(auth): Überprüfen Sie den persönlichen Schlüsselwechsel eines Arbeitsbereichs nach der Mitgliedschaft (#9540) – Fix(oauth): Behalten Sie eine Untergrenze von fünf Minuten für bereitgestellte Token bei und aktualisieren Sie sie früher (#9528)
  • Fix(Mutterschiff): Stopp bricht nur getrennte, noch laufende Ausführungen ab, und eine angehaltene Workflow-Ausführung blockiert niemals die Workbench der nächsten Runde (#9532)
  • Fix (Desktop): Vor einem Update-Neustart über das Menü nachfragen, Uploads und Downloads als laufende Arbeit zählen und Anmeldeaufforderungen verschärfen (#9533)
  • fix(files): Autorisieren Sie den Arbeitsbereich, bevor Sie eine Datei/den Pfad auflösen (#9527)
  • fix(auth): Nur kuratierte Einwegdomänen blockieren und niemals SSO- oder SCIM-Bereitstellung blockieren (#9529)
  • fix(people): Behalten Sie einen gesperrten Manager-Link bei der Bearbeitung bei und verhindern Sie, dass das Organisationslayout bei der Personensuche fehlschlägt (#9526)
  • fix(execution): Benennen Sie den Signal-Exit-Code eines fehlgeschlagenen Sandbox-Prozesses (#9523) – Fix(Erweiterung): Site-Zugriff kompatibel mit strengem CSP halten (#9524)
  • fix(mothership): Sagen Sie, warum ein Workflow-Copilot-Chat andere Chats nicht lesen kann (#9520)
  • fix(auth): Kontoerstellung aus Wegwerf-E-Mail-Domänen für jeden Anbieter verweigern (#9516)
  • Fix(Desktop): Anmelde-Popups funktionieren weiterhin im Agent-Browser (#9506)
  • fix(files): Dateien/VFS-Pfade in v2-Dateien akzeptieren, beschreiben, umbenennen und löschen (#9504)

Englisches Original / English original

sim v0.9.39

Features

  • feat(library): AI Agent Output Controls Compared: Guardrails, Structured Outputs, and Streaming (#9539)
  • feat(library): Best AI Agents for Jira Triage and Datadog Incident Response (#9536)
  • feat(mothership): answer a long workflow tool run still running, and stop detached runs on Stop (#9507)
  • feat(people): organization People page with profiles, reporting lines, and people-data import (#9517)
  • feat(desktop): continue a passkey sign-in in your browser and bring the session back (#9515)
  • feat(mothership): erase private memory when a member leaves or an organization is deleted (#9503)

Improvements

  • improvement(docs): collect reader feedback inline (#9538)
  • improvement(release): harden favicons, sim links, and the extension from a pre-release audit (#9530)
  • improvement(search): overlap live search stages and report every unsearched source (#9514)
  • improvement(desktop): sign-in prompts for the agent browser — site passwords, passkey accounts, client certificates, and app links (#9521)
  • improvement(cli): sim credentials providers lists providers (#9522)
  • improvement(desktop): install updates on one click, asking only about real in-flight work (#9505)
  • improvement(cli): files batch-delete takes file ids as arguments (#9518)
  • improvement(desktop): bring agent browser menus, keys and fullscreen in line with Chrome (#9512)
  • improvement(extension): document browser data handling and limited use
  • improvement(extension): document browser data handling and limited use (#9513)
  • improvement(oauth): serve still-valid tokens while refreshing ahead of expiry (#9509)
  • improvement(sim-links): pass queries through, trim pasted punctuation, and suggest links from the address bar (#9508)

Bug Fixes

  • fix(files): share one served-bytes predicate between the serve route and large downloads (#9548)
  • fix(release): read Excel start dates, refuse impossible times and repeated columns, keep typed escapes, no suggestions for punctuation (#9545)
  • fix(oauth): default a leader-lock follower's wait to the lease so its takeover can land (#9546)
  • fix(desktop): address release review — count app downloads and unchecked terminals before an update restart, send the page referrer on Save Image, and tighten sign-in and people edge cases (#9547)
  • fix(ci): drop the duplicate --accept-routes the Tailscale action already passes (#9543)
  • fix(files): stream served files with byte ranges instead of buffering them under 100 MB (#9542)
  • fix(files): resolve v2 file paths only on the v2 surface, through the canonical resolver (#9531)
  • fix(oauth): take over a lapsed refresh lease, share overlapping service-account key reads, and label unsearched accounts (#9537)
  • fix(auth): check a workspace's personal-key switch after membership (#9540)
  • fix(oauth): keep a five-minute floor on served tokens and refresh ahead earlier (#9528)
  • fix(mothership): Stop only cancels detached runs still running, and a held workflow run never blocks the next turn's workbench (#9532)
  • fix(desktop): ask before an update restart from the menu, count uploads and downloads as running work, and harden sign-in prompts (#9533)
  • fix(files): authorize the workspace before resolving a files/ path (#9527)
  • fix(auth): block only curated disposable domains, and never gate SSO or SCIM provisioning (#9529)
  • fix(people): keep a suspended manager link on edit and never fail the org layout on the People lookup (#9526)
  • fix(execution): name the signal exit code of a failed sandbox process (#9523)
  • fix(extension): keep site access compatible with strict CSP (#9524)
  • fix(mothership): say why a workflow copilot chat cannot read other chats (#9520)
  • fix(auth): refuse account creation from disposable email domains for every provider (#9516)
  • fix(desktop): keep sign-in popups working in the agent browser (#9506)
  • fix(files): accept files/ VFS paths in v2 file describe, rename and delete (#9504)

Other Changes

  • chore(ci): reach the database over the tailnet when CI_DB_TAILNET is set (#9541)
  • chore(search): retire legacy search knowledge base projection rows in place (#9511)
  • chore(auth): correct where the short disposable list runs (#9535)
  • docs(library): update best-multi-agent-frameworks-2026 (#9534)
  • Merge pull request #9519 from simstudioai/codex/extension-privacy-production

  • @waleedlatif1
