codebase-memory-mcp v0.5.0

Abgeschlossen Gehen Sie zu C Rewrite

v0.5.0 ist die erste Version, die vollständig aus C erstellt wurde. Die gesamte Codebasis – Pipeline, Store, MCP-Server, CLI, Watcher – wurde von Go auf C umgeschrieben, wobei die über CGo kompilierten Tree-Sitter-Grammatiken durch bereitgestellte C-Quellen für alle 64 Sprachen ersetzt wurden.

Was dies ermöglicht

  • RAM-First-Pipeline: Die gesamte Indizierung wird im Speicher ausgeführt (LZ4 HC-komprimierter Lesevorgang, In-Memory-SQLite, einzelner Dump am Ende). Keine Festplatten-E/A zwischen Massenladevorgang und endgültigem Schreibvorgang.
  • Fused Aho-Corasick Multi-Pattern Matching: Die Aufrufauflösung verwendet einen einzigen Durchgang über den AST, wobei alle Muster gleichzeitig geladen werden, wodurch sequentielles Grep pro Funktion ersetzt wird.
  • C/C++-Hybrid-LSP-Resolver: Vorlagenersetzung, intelligente Zeigerketten, Überlastbewertung, Lambda/Decltype-Inferenz, virtueller Versand – über 700 dedizierte Tests.
  • Globaler Mimalloc-Allokator: Verfolgt alle Zuweisungen (C + C++ über globale Überschreibung) und ermöglicht so eine präzise Speicherbudgetierung pro Worker.
  • Kein CGo-Grenzen-Overhead: Das gesamte Tree-Sitter-Parsing erfolgt in reinem C – kein CGo-Hop pro Datei.

Leistung

Indizierung des Linux-Kernels (28 Mio. LOC, 75.000 Dateien):

  • Vollmodus: 2,1 Millionen Knoten, 5 Minuten und 33 Sekunden (Apple M3 Pro)
  • Schnellmodus: 1,88 Millionen Knoten, 1 Minute und 12 Sekunden (Apple M3 Pro)

Neu: Benutzeroberfläche zur Diagrammvisualisierung

v0.5.0 wird in zwei Varianten geliefert:

  • Standard – nur MCP-Server (kleinere Binärdatei)
  • ui – MCP-Server + eingebettete 3D-Grafikvisualisierung Aktivieren Sie die Benutzeroberfläche: ```bash codebase-memory-mcp --ui=true --port=9749 ``` Öffnen Sie dann http://localhost:9749, um Ihren Wissensgraphen visuell zu erkunden. Die Benutzeroberfläche wird als Hintergrundthread auf localhost ausgeführt, stellt eingebettete Frontend-Assets bereit und leitet Abfragen per Proxy an eine schreibgeschützte SQLite-Verbindung weiter.

Automatische Sitzungserkennung + automatischer Index

Der MCP-Server erkennt jetzt beim Sitzungsstart Ihr Projektstammverzeichnis aus dem Arbeitsverzeichnis. Kombiniert mit dem Konfigurationsspeicher: ```bash codebase-memory-mcp config set auto_index true ``` Wenn diese Option aktiviert ist, werden neue Projekte automatisch bei der ersten MCP-Verbindung indiziert und der Beobachter registriert sie für die fortlaufende Git-basierte Änderungserkennung. Zuvor indizierte Projekte werden unabhängig von dieser Einstellung immer beim Watcher registriert. Die Konfiguration CLI unterstützt: `list`, `get <key>`, `set <key> <value>`, `reset <key>`.

`codebase-memory-mcp install` erkennt jetzt automatisch alle installierten Codierungsagenten und konfiguriert jeden einzelnen mit MCP-Servereinträgen, Anweisungsdateien und Pre-Tool-Hooks, sofern unterstützt. | Agent | MCP-Konfiguration | Anleitung | Haken | |-------|-----------|-------------|-------| | Claude Code | .claude/.mcp.json | 4 Fähigkeiten (Anweisungsmuster) | PreToolUse auf Grep/Glob/Read | | Codex CLI | .codex/config.toml | .codex/AGENTS.md | -- | | Zwillinge CLI | .gemini/settings.json | .gemini/GEMINI.md | BeforeTool auf grep/read | | Zed | Einstellungen.json (JSONC) | -- | -- | | OpenCode | opencode.json | .config/opencode/AGENTS.md | -- | | Antigravitation | mcp_config.json | .gemini/antigravity/AGENTS.md | -- | | Helfer | -- | KONVENTIONEN.md | -- | | KiloCode | mcp_settings.json | ~/.kilocode/rules/ | -- |

Verbesserungen des Agentenverhaltens

Agenten bevorzugen jetzt MCP-Tools aktiv gegenüber grep/glob/read** für die Codeerkennung:

  • Direktive Fertigkeitsbeschreibungen erreichen eine automatische Aktivierung von ca. 100 % (gegenüber ca. 37 % beim alten Beschreibungsmuster)
  • PreToolUse/BeforeTool-Hooks drucken Hinweiserinnerungen, wenn Agenten nach integrierten Suchtools greifen
  • Schlüsselwortreiche MCP-Tool-Beschreibungen verbessern die Entdeckung von Claudes Tool-Suche
  • Anleitungsdateien mit konkreten Beispielen und expliziten Fallback-Anleitungen für alle Agenten
  • Startup-Update-Prüfung benachrichtigt beim ersten Tool-Aufruf, ob eine neuere Version verfügbar ist Diese Verbesserungen wurden durch Community-Berichte und Beiträge vorangetrieben: – @David34920 – berichtet, dass Claude MCP-Tools ohne CLAUDE.md-Änderungen ignoriert (#69)
  • @sonicviz – detaillierte Analyse der Heuristiken zur Auswahl von Agententools (#34) – @chitralverma – berichtete, dass Gemini CLI standardmäßig auf integrierte Tools zurückgreift (#19) – @noelkurian – Fehler im Zed-Konfigurationsformat und JSONC-Parsing-Problem identifiziert (#24) – @zeval – OpenCode-Installations-PR mit Konfigurationspfad-Recherche (#36) – @harshil480 – KiloCode installiert PR mit Konfigurationsformat und Testplan (#53)

  • Zed: Config verwendet jetzt args:[""] anstelle von defekter Quelle:"custom" (#24)
  • Zed: Parser verarbeitet JSONC (Kommentare + nachgestellte Kommas) in vorhandenen Einstellungen.json
  • Install ist idempotent: Zweimaliges Ausführen der Installation erzeugt keine Duplikate – markerbasiertes Upsert für Anweisungen, schlüsselbasiertes Upsert für JSON/TOML-Konfigurationen

Englisches Original / English original

codebase-memory-mcp v0.5.0

Complete Go to C Rewrite

v0.5.0 is the first release built entirely from C. The entire codebase -- pipeline, store, MCP server, CLI, watcher -- has been rewritten from Go to C, with tree-sitter grammars compiled via CGo replaced by vendored C source for all 64 languages.

What this enables

  • RAM-first pipeline: All indexing runs in memory (LZ4 HC compressed read, in-memory SQLite, single dump at end). Zero disk I/O between bulk load and final write.
  • Fused Aho-Corasick multi-pattern matching: Call resolution uses a single pass over the AST with all patterns loaded simultaneously, replacing sequential per-function grep.
  • C/C++ hybrid LSP resolver: Template substitution, smart pointer chains, overload scoring, lambda/decltype inference, virtual dispatch -- 700+ dedicated tests.
  • mimalloc global allocator: Tracks all allocations (C + C++ via global override), enabling precise memory budgeting per worker.
  • No CGo boundary overhead: All tree-sitter parsing happens in pure C -- no per-file CGo hop.

Performance

Indexing the Linux kernel (28M LOC, 75K files):

  • Full mode: 2.1M nodes, 5m33s (Apple M3 Pro)
  • Fast mode: 1.88M nodes, 1m12s (Apple M3 Pro)

New: Graph Visualization UI

v0.5.0 ships in two variants:

  • standard -- MCP server only (smaller binary)
  • ui -- MCP server + embedded 3D graph visualization

Enable the UI: ```bash codebase-memory-mcp --ui=true --port=9749 ``` Then open http://localhost:9749 to explore your knowledge graph visually. The UI runs as a background thread on localhost, serving embedded frontend assets and proxying queries to a read-only SQLite connection.

Session Auto-Detect + Auto-Index

The MCP server now detects your project root from the working directory on session start. Combined with the config store:

```bash codebase-memory-mcp config set auto_index true ```

When enabled, new projects are automatically indexed on first MCP connection, and the watcher registers them for ongoing git-based change detection. Previously-indexed projects are always registered with the watcher regardless of this setting.

The config CLI supports: `list`, `get <key>`, `set <key> <value>`, `reset <key>`.

Multi-Agent Install (8 Coding Agents)

`codebase-memory-mcp install` now auto-detects all installed coding agents and configures each one with MCP server entries, instruction files, and pre-tool hooks where supported.

| Agent | MCP Config | Instructions | Hooks | |-------|-----------|-------------|-------| | Claude Code | .claude/.mcp.json | 4 Skills (directive pattern) | PreToolUse on Grep/Glob/Read | | Codex CLI | .codex/config.toml | .codex/AGENTS.md | -- | | Gemini CLI | .gemini/settings.json | .gemini/GEMINI.md | BeforeTool on grep/read | | Zed | settings.json (JSONC) | -- | -- | | OpenCode | opencode.json | .config/opencode/AGENTS.md | -- | | Antigravity | mcp_config.json | .gemini/antigravity/AGENTS.md | -- | | Aider | -- | CONVENTIONS.md | -- | | KiloCode | mcp_settings.json | ~/.kilocode/rules/ | -- |

Agentic Behavior Improvements

Agents now actively prefer MCP tools over grep/glob/read for code discovery:

  • Directive skill descriptions achieve ~100% auto-activation (up from ~37% with the old descriptive pattern)
  • PreToolUse / BeforeTool hooks print advisory reminders when agents reach for built-in search tools
  • Keyword-rich MCP tool descriptions improve Claude's Tool Search discovery
  • Instruction files with concrete examples and explicit fallback guidance for all agents
  • Startup update check notifies on first tool call if a newer release is available

These improvements were driven by community reports and contributions:

  • @David34920 -- reported Claude ignoring MCP tools without CLAUDE.md edits (#69)
  • @sonicviz -- detailed analysis of agent tool-selection heuristics (#34)
  • @chitralverma -- reported Gemini CLI defaulting to built-in tools (#19)
  • @noelkurian -- identified Zed config format bug and JSONC parsing issue (#24)
  • @zeval -- OpenCode install PR with config path research (#36)
  • @harshil480 -- KiloCode install PR with config format and test plan (#53)

Fixes

  • Zed: Config now uses args:[""] instead of broken source:"custom" (#24)
  • Zed: Parser handles JSONC (comments + trailing commas) in existing settings.json
  • Install is idempotent: Running install twice produces no duplicates -- marker-based upsert for instructions, key-based upsert for JSON/TOML configs

Cross-Platform Support

Fully tested on all platforms with ASan + LeakSanitizer + UBSan:

| Platform | Tests | Build | |----------|-------|-------| | macOS arm64 | 2030 passed | OK | | macOS amd64 | OK | OK | | Linux arm64 | 2012 passed | OK | | Linux amd64 | OK | OK | | Windows amd64 | OK | OK (CLANG64) |

Vendored dependencies (zero system library requirements): sqlite3, mimalloc, tree-sitter runtime, yyjson, zlib, TRE regex (Windows only).

Upgrading

```bash codebase-memory-mcp update ```

Or fresh install: ```bash curl -fsSL https://raw.githubusercontent.com/DeusData/codebase-memory-mcp/main/install.sh | bash codebase-memory-mcp install -y ```

Existing indexes will be rebuilt automatically -- the C pipeline produces a different (improved) graph format.
