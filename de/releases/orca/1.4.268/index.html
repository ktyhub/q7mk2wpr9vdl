Orca v1.4.268

Wir haben heute mehr als eine Veröffentlichung versendet. Schauen Sie sich auch 1.4.267 und 1.4.266 an.

Bots auf mehr Agenten, reichhaltigerem Slack und einem schnelleren Orca ✨

Bots können jetzt auf Cursor, GitHub Copilot und Hermes ausgeführt werden, Slack übernimmt Planung und Canvases und Orca erledigt weniger Arbeit im Hintergrund, sodass es sich schneller anfühlt.

  • 🤖 Bots auf mehr Agenten ausführen: Bots können auf Cursor, GitHub Copilot und Hermes ausgeführt werden, und OpenCode 2.x-Bots erhalten ihre ständigen Anweisungen. Neue Bots bekommen einen Ausweis und Soul & Memory haben die Editoren neu gestaltet.
  • 🖼️ Bilder und Dateien senden: Hängen Sie Bilder und Dateien in Bot-Chats, Gruppenchats und Artikelkommentaren an, auch an einen Bot auf einem gekoppelten Computer. Bilder auf einer Slack-Anfrage erreichen den Agenten als Bilder.
  • 💬 Mehr von Slack: orca slack post --at plant einen Beitrag für später, und die neuen Befehle pin, canvas, list und scheduled decken Pins, Leinwände und Listen ab. Beim Verbinden mit Slack wird das kopierte Token ohne zusätzliche clicks übernommen und als Namen gelesen.
  • ⚡ Ein leichterer, flüssigerer Orca: Animationen laufen wieder reibungslos statt etwa einmal pro Sekunde, Spinner und Pulse zeichnen weniger Frames, Lesevorgänge für Anmeldeinformationen werden aus dem Hauptthread verschoben und automatische Heap-Profile gibt es nicht mehr. Orca empfiehlt außerdem, Arbeitsbereiche zu bereinigen, wenn die Festplatte fast voll ist.
  • 🧭 Zuverlässigere Mitarbeiter und Chats: Durch einen Absturz oder Neustart unterbrochene Chats können fortgesetzt werden, der Abschlussbericht eines Mitarbeiters weckt den Agenten, der ihn gestartet hat, und Mitarbeiternamen im Chat öffnen den Mitarbeiter. Chat erhält außerdem Antigravity-, Claude-, Codex- und Droid-Korrekturen.
  • 🌐 Seiten auf Remote-Hosts kommentieren: Browser-Anmerkungen funktionieren jetzt auch auf Remote-Hosts.

Über Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="36" height="36" valign="middle" />

Orca-Bots arbeiten wie erstklassige Teamkollegen: Jede verwaltete Agentensitzung erhält ihre Tools und Identität, Bots können im Namen des Eigentümers Inhalte teilen, sie folgen Slack-Threads und Gmail-Triggern zuverlässiger und die Verbindung zwischen ihnen ist klarer und sicherer.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> Jede Bot-Sitzung erhält ihre Tools und Identität: Verwaltete Agentensitzungen sind nicht mehr auf Claude und Codex beschränkt; Jeder beginnt mit den Werkzeugen und der Identität, die er benötigt.
  • 🔗 Bots können teilen, genau wie der Besitzer: Agent CLI-Anrufer können Sharing auf die gleiche Weise nutzen wie der Besitzer.
  • 💬 Slack-Threads zeigen, was ein Bot tut: Ein Thread spiegelt jetzt wider, woran er gerade arbeitet, und lange Antworten kommen im Ganzen statt zerschnitten an.
  • 📬 Gmail-Trigger stimmen mit dem tatsächlichen Absender überein: Trigger stimmen mit der tatsächlichen Adresse des Absenders überein, nicht mit einem Anzeigenamen, der abweichen kann.
  • 🛡️ Deutlichere Zugriffswarnungen: Im Dialogfeld zur Zugriffsbestätigung wird jetzt angezeigt, was Sie zulassen, bevor Sie einen Bot verbinden.

orca v1.4.268

We shipped more than one release today. Check out 1.4.267 and 1.4.266 too.

Bots on more agents, richer Slack & a faster Orca ✨

Bots can now run on Cursor, GitHub Copilot and Hermes, Slack gets scheduling and canvases, and Orca does less work in the background so it feels quicker.

  • 🤖 Run bots on more agents: Bots can run on Cursor, GitHub Copilot and Hermes, and OpenCode 2.x bots get their standing instructions. New bots get an identity card, and Soul & Memory have redesigned editors.
  • 🖼️ Send images and files: Attach images and files in bot chats, group chats and item comments, including to a bot on a paired computer. Images on a Slack request reach the agent as images.
  • 💬 More from Slack: orca slack post --at schedules a post for later, and new pin, canvas, list and scheduled commands cover pins, canvases and lists. Connecting Slack takes the copied token without extra clicks, and mentions read as names.
  • ⚡ A lighter, smoother Orca: Animations run smoothly again instead of about once a second, spinners and pulses draw fewer frames, credential reads move off the main thread, and automatic heap profiles are gone. Orca also suggests cleaning up workspaces when the disk is almost full.
  • 🧭 More reliable workers and chats: Chats cut by a crash or restart can continue, a worker's final report wakes the agent that started it, and worker names in chat open the worker. Chat also gets Antigravity, Claude, Codex and Droid fixes.
  • 🌐 Annotate pages on remote hosts: Browser annotations now work on remote hosts too.
