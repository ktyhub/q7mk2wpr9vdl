Orca v1.4.243

Chrome-Erweiterungen im Orca-Browser, iPhone Duo-Unterstützung und Konvertieren einer Terminal-Agent-Sitzung live in eine Chat-Benutzeroberfläche 🧩

Mit dieser Version werden Chrome-Erweiterungen für den Browser von Orca experimentell bereitgestellt, eine Konversation kann im Chat fortgesetzt werden, sobald Sie den Agenten im Terminal beenden, und Ihre lokalen Arbeitsbäume werden nach einem Neustart früher angezeigt. Außerdem werden Unterstützung für das faltbare iPhone Duo, kompakte Menüs im nativen Stil, helle und dunkle Designs auf dem Telefon sowie Korrekturen für Windows-Terminals, SSH-Hosts und Updates hinzugefügt.

Die Kurzversion

  • Chrome-Erweiterungen (experimentell): Fügen Sie Erweiterungen aus dem Chrome Web Store mit Zu Orca hinzufügen hinzu, damit Passwort-Manager wie Bitwarden und 1Password Anmeldungen im Browser von Orca ausfüllen können. Standardmäßig deaktiviert.
  • Konvertieren Sie eine Terminal-Agentensitzung live in eine Chat-Benutzeroberfläche: Sobald Sie Claude oder Codex in einem Terminal beenden, kann dieselbe Konversation im Chat fortgesetzt werden, während die Registerkarte des Terminals geöffnet bleibt. Claude-Chats behalten auch bei Modelländerungen ihre gespeicherte Genehmigungsauswahl und werden beim Schließen eines Chats, der noch funktioniert, zuerst gefragt.
  • Arbeitsbäume früher nach einem Neustart: Lokale Arbeitsbäume werden geladen, bevor die Terminals wiederhergestellt werden, und in der Seitenleiste wird angezeigt, dass die Erkennung noch läuft, anstatt eine leere Liste anzuzeigen.
  • Stabilere Terminals: Windows-Terminals behalten ihren Verlauf auch bei Breitenänderungen, ruhende Terminals werden in dem Ordner aktiviert, den Sie verlassen haben, die in macOS integrierte Bash sorgt für die Befehlsverfolgung nach einer DEBUG-Trap-Änderung und das Kopieren von Pi auf einem Remote-Host erreicht Ihr clipboard.
  • Orchestrierung: Wählen Sie das Worker-Heartbeat-Intervall oder schalten Sie Heartbeats aus und reduzieren Sie die CPU-Auslastung, indem Sie festgesetzte Worker davon abhalten, Befehle abzufragen.
  • Polnisch, wo es darauf ankommt: Kompakte Menüs im nativen Stil, Markdown-Hervorhebung im VS-Code-Stil mit eingeklebten Überschriften und Aktualisierungsprüfungen über Ihren Einstellungs-Proxy.
  • Korrekturen aus der Community: Alle Sitzungen beenden und stoppen, Mathematik in Chats, Remote-URL mit Zeilenbereichen kopieren, IME-Hervorhebung in Terminals, FNM unter Windows sowie japanische und chinesische Übersetzungen funktionieren alle besser. Telefon- und Web-Updates: Telefone erhalten helle und dunkle Designs, Unterstützung für das faltbare iPhone Duo, PDFs in Quick Look und Schaltflächen zum Kopieren in Chats. Viele Telefonbildschirme folgen jetzt den Desktop-Regeln für Chats, Quellcodeverwaltung und Terminals, und das Tippen und Scrollen in langen Chats bleibt schnell.

Kompatibilitäts- und Upgrade-Hinweise

  • Neuer Terminal-Host: Neue Terminals starten auf einem neuen Terminal-Host, daher gelten die Terminal-Korrekturen dieser Version, einschließlich der Fortsetzung eines Chats nach dem Beenden des Terminal-Agenten. Terminals, die bereits vor dem Update geöffnet waren, laufen auf dem vorherigen Host weiter und bleiben mit diesem verbunden, bis Sie sie schließen.
  • Browsererweiterungen (experimentell): Aktivieren Sie Einstellungen → Experimentell → Browsererweiterungen, starten Sie neu und öffnen Sie dann den Chrome Web Store in einem Orca-Browser-Tab. Erweiterungen werden nur in lokalen Browserprofilen ausgeführt. Werbeblocker werden installiert, aber noch nicht blockiert, und einige Erweiterungen, wie z. B. Tampermonkey, funktionieren nicht.
  • Worker-Heartbeats: Heartbeats bleiben standardmäßig alle 5 Minuten aktiviert. Änderungen in Einstellungen → Agenten-Orchestrierung gelten für neu entsandte Mitarbeiter; Arbeiter, die bereits aktiv sind, behalten ihre Kurzfrist, und ältere Hosts behalten 5 Minuten.
  • Claude-Subagentennavigation: Das Auge, das den angezeigten Subagenten markierte, ist verschwunden. Die angezeigte Subagentenzeile verwendet die normale Hervorhebung der aktuellen Zeile.

orca v1.4.243

Chrome extensions in Orca’s browser, iPhone Duo support, and Convert a terminal agent session live into a chat ui 🧩

This release brings Chrome extensions to Orca’s browser under experimental, lets a conversation continue in Chat once you quit its agent in the terminal, and shows your local worktrees sooner after a restart. It also adds support for the folding iPhone Duo, compact native-style menus, light and dark themes on the phone, and fixes for Windows terminals, SSH hosts and updates.

The short version

  • Chrome extensions (experimental): Add extensions from the Chrome Web Store with Add to Orca, so password managers like Bitwarden and 1Password can fill logins in Orca’s browser. Off by default.
  • Convert a terminal agent session live into a chat ui: Once you quit Claude or Codex in a terminal, the same conversation can continue in Chat while the terminal tab stays open. Claude chats also keep their saved approval choice across model changes, and closing a chat that’s still working asks first.
  • Worktrees sooner after a restart: Local worktrees load before terminals restore, and the sidebar says discovery is still running instead of showing an empty list.
  • Steadier terminals: Windows terminals keep their history through width changes, slept terminals wake in the folder you left, macOS’s built-in bash keeps command tracking in order after a DEBUG trap change, and copying from pi on a remote host reaches your clipboard.
  • Orchestration: Choose the worker heartbeat interval or turn heartbeats off, and reduce CPU use by stopping settled workers from polling for commands.
  • Polish where it counts: Compact native-style menus, VS Code–style Markdown highlighting with sticky headings, and update checks through your Settings proxy.
  • Fixes from the community: Quit and Stop All Sessions, math in chats, Copy Remote URL with line ranges, IME highlighting in terminals, fnm on Windows, and Japanese and Chinese translations all work better.

Phone & web updates: Phones get light and dark themes, support for the folding iPhone Duo, PDFs in Quick Look and copy buttons in chats. Many phone screens now follow desktop’s rules for chats, Source Control and terminals, and typing and scrolling in long chats stay fast.

Compatibility & upgrade notes

  • Fresh terminal host: New terminals start on a fresh terminal host so this release’s terminal fixes apply, including continuing a chat after its terminal agent exits. Terminals already open before you update keep running, and stay attached, on the previous host until you close them.
  • Browser extensions (experimental): Turn on Settings → Experimental → Browser extensions, restart, then open the Chrome Web Store in an Orca browser tab. Extensions run in local browser profiles only. Ad blockers install but don’t block yet, and some extensions, such as Tampermonkey, don’t work.
  • Worker heartbeats: Heartbeats stay on every 5 minutes by default. Changes in Settings → Agent Orchestration apply to newly dispatched workers; workers already running keep their brief, and older hosts keep 5 minutes.
  • Claude subagent navigation: The eye that marked the subagent you’re viewing is gone. The viewed subagent row uses the normal current-row highlight.
