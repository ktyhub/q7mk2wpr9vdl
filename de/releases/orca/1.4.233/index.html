Orca v1.4.233

Vielen Dank, dass Sie Orca nutzen und für Ihre anhaltende Unterstützung! ❤️ Wir haben heute zwei Veröffentlichungen verschickt! Wenn Sie es verpasst haben, schauen Sie sich auch die v1.4.232 release notes an. Zu den Highlights gehören manuelle/automatische/Yolo-Agentenberechtigungen, OpenCode 2 im nativen Chat, ein besserer Phone Composer mit Dateianhängen und Inline-Fähigkeiten, eine reibungslosere SSH-Wiederherstellung und eine kleinere App mit schnelleren Mac-Updates. Telefonaktualisierungen: Wenn Sie Orca auf Ihrem Desktop aktualisieren, wird auch die App auf Ihrem verbundenen Telefon aktualisiert – das Telefon lädt sie direkt von Ihrem Desktop.

Die Kurzversion

  • SSH und Remote-Arbeitsbereiche: Die Verbindung zu einem SSH-Host funktioniert, wenn keiner der Computer Node.js herunterladen kann, mit einem Ein-click-Spiegel, den sich Orca merkt und es erneut versucht. Ältere Windows-Hosts (Windows 10 1809 und Server 2019) können den Orca-Server ausführen und Tunnel werden wiederhergestellt, wenn ein Port von einer alten SSH-Verbindung belegt ist.
  • Remote-Server in den Einstellungen: „Remote-Orca-Server“ ist eine Liste statt sechs Abschnitten, und SSH-Hosts können in großen Mengen entfernt werden und bleiben entfernt. Orca teilt Ihnen mit, wenn derselbe Server zweimal gespeichert wurde. Wenn Sie einen Server hinzufügen, den Sie bereits gespeichert haben, wird er stattdessen aktualisiert.
  • Telefon: Das Erstellen eines Arbeitsbereichs über das Telefon geht viel schneller, die Arbeitsbereichsliste bleibt mit dem Desktop im Einklang und die Symbole der Sitzungsregisterkarten behalten neben langen Titeln ihre Größe.
  • Editor: Orca weigert sich, Änderungen an einer Datei auf der Festplatte zu speichern, die Sie nicht gesehen haben, und Neuladen und Rückgängig verhalten sich danach vorhersehbar.
  • Alltäglicher Schliff: Projekte mit demselben Namen auf verschiedenen Maschinen behalten kurze Namen und zeigen an, auf welcher Maschine sie sich befinden. Lange gespeicherte Konversationen verbrauchen viel weniger Speicher, wenn Orca sie nach dem Sitzungsverlauf durchsucht.

  • Linux-Bibliotheken zuverlässig über SSH und WSL erkennen von @nwparker in https://github.com/stablyai/orca/pull/31077

orca v1.4.233

Thank you so much for using Orca and for your continued support! ❤️

We shipped two releases today! If you missed it, check out the v1.4.232 release notes too. Highlights include Manual / Auto / Yolo agent permissions, OpenCode 2 in native chat, a better phone composer with file attachments and inline skills, smoother SSH recovery, and a smaller app with faster Mac updates.

Phone updates: Updating Orca on your desktop also updates the app on your connected phone—the phone loads it directly from your desktop.

The short version

  • SSH & remote workspaces: Connecting to an SSH host works when neither machine can download Node.js, with a one-click mirror Orca remembers and retries. Older Windows hosts (Windows 10 1809 and Server 2019) can run Orca's server, and tunnels recover when a port is held by an old SSH connection.
  • Remote servers in Settings: Remote Orca Servers is one list instead of six sections, and SSH hosts can be removed in bulk and stay removed. Orca tells you when the same server was saved twice, and adding a server you already saved updates it instead.
  • Phone: Creating a workspace from the phone is much faster, the workspace list stays in step with the desktop, and session tab icons keep their size beside long titles.
  • Editor: Orca refuses to save over changes made to a file on disk that you haven't seen, and Reload and Undo behave predictably afterwards.
  • Everyday polish: Projects with the same name on different machines keep short names and show which machine they're on. Long saved conversations use far less memory when Orca scans them for Session History.
