Orca v1.4.238

Mehr vernetzte Arbeit, sicherere Bearbeitungen 🐳

Diese Version erleichtert den Wechsel zwischen Agenten, Dateien, Browsern und Remote-Rechnern. Tabs derselben Datei teilen jetzt nicht gespeicherte Änderungen, native Chats greifen an anderer Stelle vorgenommene Runden auf und das Telefon verfügt über zuverlässigere Terminal-Gesten und umfangreichere Tab-Steuerelemente.

Die Kurzversion

  • Ihre Änderungen bleiben zusammen: Tabs derselben Datei teilen nicht gespeicherten Text in allen Arbeitsbereichen. Bei der Konfliktüberprüfung wird festgestellt, dass Live-Text, das Löschen von Arbeitsbereichen nicht gespeicherte Dateien auflistet und veraltete Markdown- oder Notizbuchbearbeitungen neuere Arbeiten nicht mehr überschreiben.
  • Chats, die mithalten: Codex und Pi zeigen Runden an, die außerhalb des Chats vorgenommen wurden. Lange Einfügungen können zu Textanhängen werden, Codex-Fragen erhalten Antwortkarten und OMP erhält Bildversand- und umsetzbare Planüberprüfungskarten.
  • Mehr Kontrolle über Agenten: Wählen Sie beim Erstellen eines Arbeitsbereichs Chat oder Terminal aus, legen Sie diese Wahl für Ihren Standardagenten fest, fügen Sie Claude- und Codex-Konten auf unterstützten Remote-Servern hinzu und installieren Sie gemeinsame Fähigkeiten für 11 weitere Agenten.
  • Ein leistungsfähigerer Browser: Ein neuer Tab, der den Arbeitsbereich berücksichtigt, Vorschläge für die Adressleiste, gespeicherte Site-Berechtigungen, Darstellung und Zoom pro Site sowie Fortschritt beim Laden von Seiten auf Desktop und Telefon.
  • Ein reibungsloseres Telefonerlebnis: Sehen Sie sich die Agentenaktivität in Registerkarten an, benennen Sie sie mit einem Doppeltipp um, blättern Sie durch frühere Chatnachrichten zurück, wählen Sie Terminaltext natürlicher aus und kehren Sie nach der Fortsetzung zu Ihrer Terminal-Leseposition zurück.
  • Bessere Sichtbarkeit und Wiederherstellung: Überprüfen Sie lokale Terminals im Resource Manager, verwenden Sie einfaches SSH, wenn die Verschiebung eines Hosts auf einen Orca-Server blockiert ist, und behalten Sie die Paarungen durch Aktualisierungen und Wiederherstellungen verwalteter Server bei.
  • Alltäglicher Feinschliff: Brasilianisches Portugiesisch, Sprachauswahl beim Onboarding, durchsuchbare Release-Builds, klarerer Verlaufsscan-Fortschritt und Lösung mit KI für angehaltene Zusammenführungen, Rebases und Cherry-Picks – selbst nachdem Dateikonflikte behoben wurden. Telefonaktualisierungen: Durch die Aktualisierung von Orca auf dem Computer, der Ihr Telefon bedient, wird die bereitgestellte Schnittstelle aktualisiert. Der neue Eintrag Home → Neuer Arbeitsbereich und native iOS-Diktierkorrekturen erfordern eine aktualisierte native Telefon-App; Der Eintrag auf dem Startbildschirm wird mit dem nächsten App-Build geliefert.

Kompatibilitäts- und Upgrade-Hinweise

  • Remote-Konten: Aktualisieren Sie den gekoppelten Server für den neuen Claude- und Codex-Konto hinzufügen-Flow. Windows-Server und ältere Hosts behalten die orca account add-Anleitung bei. Anmeldeinformationen bleiben auf dem Server; Die Remote-Neuauthentifizierung eines vorhandenen Kontos fällt nicht unter diese Änderung.
  • Nativer Chat (experimentell): Aktualisieren Sie gekoppelte und SSH-Hosts neben Orca, um die neuesten Chat-Korrekturen zu erhalten. Die Überprüfung der Agent-Version akzeptiert jetzt neuere Versionen und Vorabversionen, die das erforderliche Minimum erfüllen. Eine bekannte ältere Version zeigt Update-Anleitungen.
  • Ressourcenmanager: Die neue PTYs-Ansicht deckt lokale Terminals ab. Das Beenden eines Terminals erfordert Hostunterstützung zur Überprüfung der ausgewählten Sitzung. Ältere Hoster lehnen eine ungeprüfte Kündigung ab.
  • HTML-Dateien: Das standardmäßige Öffnen von HTML in der Vorschau wurde für diese Version zurückgesetzt.
  • Experimentelle Grundlagen: Die unten aufgeführten Layout-Eigentümer- und Seitenleistenänderungen bleiben deaktiviert. Für die neuen optionalen Agenten-Schreibsteuerungen sind keine vorhandenen Anrufer aktiviert.

orca v1.4.238

More connected work, safer edits 🐳

This release makes it easier to move between agents, files, browsers and remote machines. Tabs of the same file now share unsaved edits, native chats pick up turns made elsewhere, and the phone gets more dependable terminal gestures and richer tab controls.

The short version

  • Your edits stay together: Tabs of the same file share unsaved text across workspaces. Conflict review sees that live text, workspace deletion lists unsaved files, and stale Markdown or notebook edits no longer overwrite newer work.
  • Chats that keep up: Codex and Pi show turns made outside the chat. Long pastes can become text attachments, Codex questions get answer cards, and OMP gains image sending and actionable plan-review cards.
  • More control over agents: Pick chat or terminal when creating a workspace, set that choice for your default agent, add Claude and Codex accounts on supported remote servers, and install shared skills for 11 more agents.
  • A more capable browser: A workspace-aware new tab, address-bar suggestions, remembered site permissions, per-site appearance and zoom, and page-loading progress on desktop and phone.
  • A smoother phone experience: See agent activity in tabs, rename with a double-tap, scroll back through earlier chat messages, select terminal text more naturally, and return to your terminal reading position after resuming.
  • Better visibility and recovery: Inspect local terminals in Resource Manager, use plain SSH when a host’s move to an Orca server is blocked, and keep pairings through managed-server updates and recovery.
  • Everyday polish: Brazilian Portuguese, language selection during onboarding, searchable release builds, clearer history-scan progress, and Resolve with AI for paused merges, rebases and cherry-picks—even after file conflicts are fixed.

Phone updates: Updating Orca on the computer serving your phone updates the served interface. The new Home → New Workspace entry and native iOS dictation fixes require an updated native phone app; the home-screen entry ships with the next app build.

Compatibility & upgrade notes

  • Remote accounts: Update the paired server for the new Claude and Codex Add Account flow. Windows servers and older hosts retain the orca account add guidance. Credentials stay on the server; remote re-authentication of an existing account is outside this change.
  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat fixes. Agent version checks now accept newer releases and prereleases that meet the required minimum; a known older version shows update guidance.
  • Resource Manager: The new PTYs view covers local terminals. Ending a terminal requires host support for verifying the selected session; older hosts refuse unchecked termination.
  • HTML files: Opening HTML in preview by default was reverted for this release.
  • Experimental groundwork: Layout-owner and sidebar changes listed below remain disabled. The new optional agent-write controls have no existing callers enabled.
