Orca v1.4.262

Vorherige Version: 1.4.261: Wesentliche Leistungsverbesserungen, Cursor-Chat und ein anpassbares +-Menü.

Schnelleres Chat-Wechseln, geringerer Speicherverbrauch und Git-Schuld ✨

Halten Sie unter macOS und Linux mehr Konversationen mit weniger Speicher offen und wechseln Sie zwischen Chats, ohne dass in ausgeblendeten Ansichten Arbeit anfällt. Dieses Update hilft auch dabei, Terminalsitzungen dort fortzusetzen, wo Sie aufgehört haben, und fügt den Zeilenverlauf direkt in den Editor ein.

  • ⚡ Funktioniert in vielen Chats: Die Chat-Benutzeroberfläche verwendet einfachere Helfer unter macOS und Linux. Versteckte Chat-Ansichten pausieren ihre Aktualisierungen, während Ihr Entwurf, Ihre Leseposition und Ihr Bearbeitungsstatus für Ihre Rückkehr beibehalten werden; Agenten arbeiten weiter.
  • 🧹 Festplattenspeicher zurückgewinnen: Einstellungen → Arbeitsbereichsbereinigung kann Orca-, Claude Code- und Codex-Chats aus gelöschten Arbeitsbereichen löschen. Es ist standardmäßig deaktiviert; Wenn Sie es aktivieren, werden Sie um eine Bestätigung gebeten und zuvor gelöschte Arbeitsbereiche einbezogen. Gelöschte Chats können nicht wiederhergestellt werden.
  • ⌨️ Zurück zum gleichen Terminalordner: Fenster merken sich bei Neustarts, auch in Ordnerarbeitsbereichen, wo Sie zuletzt das Verzeichnis geändert haben. Windows behebt außerdem verirrte Zeichen nach der Rückkehr zu einem belebten Bereich.
  • 🔍 Sehen Sie, wer eine Zeile geändert hat: Das Git-Blamme-Statuselement zeigt den Autor und das Datum der Cursorzeile an. In Repo-Arbeitsbereichen click es aktivieren, um den Commit zu öffnen; Aktivieren Sie Inline Git Blame in Einstellungen → Editor für Anmerkungen neben Ihrem Code.
  • 👤 Machen Sie den Kontowechsel klarer: Benennen Sie gespeicherte Claude- und Codex-Konten und sehen Sie sich deren zuletzt beobachtete Pläne an. Wenn Sie „Neustart“ akzeptieren oder „Immer neu starten“ verwenden, werden ausgelastete Claude-Terminalsitzungen auf dem ausgewählten Konto fortgesetzt, ohne auf den Abschluss ihrer aktuellen Arbeit zu warten.

Highlights

  • Einen Agenten auf einer Karte einrichten: Wählen Sie den Agenten, das Modell und den unterstützten Aufwand oder die Schnelloptionen zusammen aus und verwenden Sie dann Als Chat öffnen oder Als Terminal öffnen. Sofern angeboten, ermöglicht der Standardaufwand dem Agenten die Auswahl seiner eigenen Stufe.
  • Unterbrechungen steuern: Klicken Sie mit der rechten Maustaste auf einen Arbeitsbereich, um seine Benachrichtigungen stummzuschalten, während der ungelesene Punkt erhalten bleibt. Ruhende Arbeitsbereiche bleiben nach dem Neustart im Ruhezustand und mit der Vorschau der Arbeitsbereichskarte können Sie verschiedene Stile ausprobieren.
  • Verwenden Sie Ihre Sprache und Plugins: Entdecken Sie Community-Übersetzungen in den Einstellungen oder beim Onboarding. Plugin-Update-Überprüfungen benennen den hinzugefügten Zugriff und können Genehmigungen gruppieren; Berechtigte Aktualisierungen können anhand ihrer Benachrichtigung genehmigt werden.
  • Remote-Dateien für später speichern: Wählen Sie Herunterladen… auf einem Remote-Datei-Link, um sie zu speichern, ohne eine andere App zu öffnen. Windows erkennt auch Projektordner auf Laufwerksbuchstaben, die WSL-Distributionen zugeordnet sind.
  • Blockierte Codex-Aktion auflösen: Chat erklärt eine Verweigerung der automatischen Überprüfung und bietet Einmalige Genehmigung für diese Aktion an.

Kompatibilitäts- und Upgrade-Hinweise

  • Freigabe des Codex-Verlaufs: Wenn die Freigabe aktiviert ist, werden Konten vor ihrem nächsten Start in einen Konversationsspeicher verschoben. Dies kann den ersten Start verzögern und ausgelastete Konten werden später migriert. Wenn Sie die Freigabe deaktivieren, bleibt der gemeinsame Verlauf bestehen. Lange Gespräche wurden gestartet, während die Freigabe aktiviert war. Sie mussten aktiviert werden, um sie fortzusetzen. Nach einem Windows-Downgrade greifen zusätzliche Konten auf Ihre Standard-Codex-Anmeldung zurück, bis Sie erneut aktualisieren.
  • Windows-Terminals: Schließen Sie vorhandene Terminals und öffnen Sie sie erneut, um die Korrektur für verirrte Zeichen zu übernehmen.
  • Repo-Setup-Schritte: Frühere orca.yaml-Genehmigungen gelten jetzt als trust für zukünftige Versionen der Setup-Befehle dieses Repos. Die VM-Erstellung und die gemeinsame Nutzung einer ID auf mehreren Hosts behalten die Genehmigung pro Version bei.

orca v1.4.262

Previous release: 1.4.261: Major performance improvements, Cursor Chat and a customizable + menu.

Faster chat switching, lower memory use & git blame ✨

Keep more conversations open with less memory on macOS and Linux, and move between chats with less work happening in hidden views. This update also helps terminal sessions pick up where you left off and puts line history directly in the editor.

  • ⚡ Work across many chats: Chat UI uses lighter helpers on macOS and Linux. Hidden chat views pause their updates while retaining your draft, reading position and editor state for your return; agents keep working.
  • 🧹 Reclaim disk space: Settings → Workspace Cleanup can delete Orca, Claude Code and Codex chats from deleted workspaces. It is off by default; enabling it asks for confirmation and includes previously deleted workspaces. Deleted chats cannot be recovered.
  • ⌨️ Return to the same terminal folder: Panes remember where you last changed directory across restarts, including in folder workspaces. Windows also fixes stray characters after returning to a busy pane.
  • 🔍 See who changed a line: The Git blame status item shows the cursor line’s author and date. In repo workspaces, click it to open the commit; enable Inline git blame in Settings → Editor for annotations beside your code.
  • 👤 Make account switching clearer: Name saved Claude and Codex accounts and see their last observed plans. When you accept Restart or use Always restart, busy Claude terminal sessions resume on the selected account without waiting for their current work to finish.

Highlights

  • Set up an agent in one card: Choose the agent, model and supported effort or Fast options together, then use Open as chat or Open as terminal. Where offered, Default effort lets the agent choose its own level.
  • Control interruptions: Right-click a workspace to mute its notifications while keeping its unread dot. Sleeping workspaces stay asleep after relaunch, and the workspace-card preview lets you try different styles.
  • Use your language and plugins: Discover community translations in Settings or onboarding. Plugin update reviews name the added access and can group approvals; eligible updates can be approved from their notification.
  • Save remote files for later: Choose Download… on a remote file link to save it without opening another app. Windows also recognizes project folders on drive letters mapped to WSL distros.
  • Resolve a blocked Codex action: Chat explains an automatic-review denial and offers Approve once for that action.

Compatibility & upgrade notes

  • Codex history sharing: With sharing enabled, accounts move to one conversation store before their next launch; this may delay the first launch, and busy accounts migrate later. Turning sharing off leaves shared history in place; long conversations started while sharing was on need it enabled to resume. After a Windows downgrade, additional accounts fall back to your default Codex sign-in until you update again.
  • Windows terminals: Close and reopen existing terminals to pick up the stray-character fix.
  • Repo setup steps: Earlier orca.yaml approvals now count as trust for future versions of that repo’s setup commands. VM creation and repos sharing an ID across hosts keep per-version approval.
