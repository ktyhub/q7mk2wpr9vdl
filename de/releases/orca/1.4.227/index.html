Orca v1.4.227

Vielen Dank, dass Sie Orca nutzen und für Ihre anhaltende Unterstützung! ❤️

Die Kurzversion

  • Native Chats haben ihren eigenen Berechtigungsmodus. Wählen Sie Berechtigungen für jeden neuen Claude- oder Codex-Chat unter Einstellungen → Chat → Verhalten; Bestehende Chats behalten den Modus, den sie bereits verwendet haben, und ein Wechsel des Modells führt nicht mehr zu einem Zurücksetzen.
  • Native Chat-Sitzungen lassen sich einfacher fortsetzen. Sie können große Terminalgespräche in einem neuen nativen Chat fortsetzen, Chats wiederherstellen, deren einzige Arbeit im Hintergrund nach einem Neustart ausgeführt wurde, und alle unterstützten Chat-Anbieter im Sitzungsverlauf genau sehen.
  • Claude-Konten und Codex-Chat-Einrichtung sind reibungsloser. Claude-Konten verwenden wieder separate Ordner, der Anmeldelink kann kopiert werden, Codex-Chats erfordern die Version 0.136.0 oder höher und Codex Ultrafast ist als Geschwindigkeitsauswahl verfügbar.
  • Die Browserautomatisierung gibt Ihre Tastatur zuverlässig zurück. Agent-Browserbefehle zielen auf die gewünschte Seite ab und Browser-Popups verhalten sich eher wie Chrome.
  • Außerdem: Die Bereinigung des Arbeitsbaums ist sicherer, gelesene macOS-Benachrichtigungen verschwinden aus dem Benachrichtigungscenter, lange Chats werden auf Telefonen besser geladen und kalte Lesevorgänge im Sitzungsverlauf vermeiden unnötige Neuindizierung.

orca v1.4.227

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chats have their own permission mode. Choose permissions for each new Claude or Codex chat from Settings → Chat → Behavior; existing chats keep the mode they were already using, and changing models no longer resets it.
  • Native chat sessions are easier to continue. You can resume large terminal conversations in a new native chat, recover chats whose only work ran in the background after a restart, and see every supported chat provider accurately in Session History.
  • Claude accounts and Codex chat setup are smoother. Claude accounts again use separate folders, the sign-in link can be copied, Codex chats require version 0.136.0 or later, and Codex Ultrafast is available as a speed choice.
  • Browser automation gives your keyboard back reliably. Agent browser commands target the intended page, and browser popups behave more like Chrome.
  • Also: worktree cleanup is safer, read macOS notifications disappear from Notification Center, long chats load better on phones, and cold session-history reads avoid unnecessary reindexing.
