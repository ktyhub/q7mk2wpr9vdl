Orca v1.4.240

Ein zuverlässigerer Arbeitsplatz 🐳

Diese Version bietet dem integrierten Browser einen durchsuchbaren Verlauf, erleichtert die Verfolgung der Agentenaktivitäten und verbessert die Wiederherstellung über Chats und Remote-Terminals hinweg. Sie finden außerdem Hervorhebung der Lean- und Zig-Syntax, Unterstützung für größere Schnellbefehlssammlungen und einen neuen orca ports-Befehl zum Auffinden Ihrer Entwicklungsserver.

Die Kurzversion

  • Gespräche, die im Gedächtnis bleiben: In Claude-Chats werden jetzt Wendungen angezeigt, die außerhalb von Orca vorgenommen wurden. Zurückbehaltene Nachrichten kehren nach erneuter Verbindung zurück, ohne dass der Chat erneut geöffnet werden muss, und die Wiederherstellung nach einem Absturz geht nicht mehr davon aus, dass eine gesendete Nachricht nicht zugestellt wurde.
  • Ein Browser mit besserem Speicher: Durchsuchen Sie Ihren Browserverlauf, öffnen Sie Seiten erneut, entfernen Sie unerwünschte Vorschläge und löschen Sie den Verlauf mit „Rückgängig“. Seiten können auch Dateien verwenden, die Sie über den Dateisystemzugriff auswählen, speichern oder ablegen.
  • Remote-Arbeit mit weniger Unterbrechungen: Langsame Verbindungen überstehen verpasste Wake-Probes, Wiederverbindungsbenachrichtigungen erklären, was passiert, SSH-Terminals warten auf die Anmeldung und neue Splits bleiben auf dem gekoppelten Server.
  • Agentenstatus können Sie einsehen trust: Abgeschlossene Codex-Subagenten werden nicht mehr als „Arbeitend“ angezeigt, laufende Hauptaufgaben bleiben in /side-Konversationen sichtbar und Codex MCP-Tools, die eine Genehmigung erfordern, erhalten eine Genehmigungskarte.
  • Mehr Platz für Ihren Workflow: Speichern Sie mehr als 40 Schnellbefehle, finden Sie die erkannten Dev-Server-Ports eines Arbeitsbaums mit orca ports und fordern Sie alte Abhängigkeitsinstallationen und Build-Ausgaben von Entwicklungs-Arbeitsbäumen zurück.
  • Polnisch, wo es darauf ankommt: Lean- und Zig-Hervorhebung, klarere Sitzungssuchauszüge, flüssigeres Scrollen mit dem Mac-Trackpad in Terminal-Apps und besserer Schutz für nicht zusammengeführte Zweige und Arbeitsbäume, die zwischen Windows und WSL geteilt werden. Telefon- und Web-Updates: Wenn Sie Orca auf dem Computer aktualisieren, der Ihr Telefon oder Ihren Browser bedient, wird die bereitgestellte Benutzeroberfläche aktualisiert. Diese Version führt außerdem weiterhin Codex-Aufgaben aus, die während /side-Konversationen in gekoppelten und mobilen Ansichten sichtbar sind, und behebt das Hochladen von vom Browser ausgewählten oder gelöschten Chat-Anhängen auf den gekoppelten Server.

Kompatibilitäts- und Upgrade-Hinweise

  • Nativer Chat (experimentell): Aktualisieren Sie gekoppelte und SSH-Hosts neben Orca, um die neuesten Chat-, Agentenstatus- und Startkorrekturen zu erhalten. Die neuen Genehmigungskarten von Codex decken MCP-Werkzeuggenehmigungen ab, für die keine Formularfelder erforderlich sind. Allgemeine MCP-Formulare und URL-basierte Überprüfung werden von dieser Änderung nicht unterstützt.
  • Browserverlauf: Öffnen Sie Verlauf über das Seitenmenü oder verwenden Sie Befehl+Y unter macOS und Strg+H unter Linux und Windows. Suchen Sie, entfernen Sie einzelne Einträge oder löschen Sie die letzte Stunde, heute oder alle Zeiten, mit „Rückgängig“ zum Löschen.
  • Erkannte Ports: orca ports unterstützt die Arbeitsbereichsauswahl und die JSON-Ausgabe auf Laufzeiten mit hostbasiertem Port-Scanning. Direkte SSH-Hosts unterstützen die Erkennung noch nicht; Arbeitsbereiche mit nativen Ordnern erfordern --all, um die Listener des Hosts aufzulisten.
  • Entwicklungsbereinigung: Durch manuelles pnpm reclaim-space und automatische Bereinigung bei Entwicklungsstarts können ignorierte, nicht verfolgte Abhängigkeitsinstallationen und generierte Ausgaben in alten Geschwister-Arbeitsbäumen unter Verwendung einer standardmäßigen 30-Tage-Grenze wiederhergestellt werden. Ausgewählte, aufrufende und ausgeschlossene Arbeitsbäume bleiben geschützt. Stoppen Sie Geschwister-Apps, Agenten, Installationen, Builds und Tests, bevor Sie eine manuelle Bereinigung durchführen. Zurückgeforderte Installationen und Ausgaben müssen bei erneuter Verwendung neu installiert oder neu erstellt werden.
  • Terminaldatei-Links: Die frühere Änderung, einen Dateilink im Arbeitsbereich zu öffnen, in dem er clicked war, wurde in dieser Version rückgängig gemacht.

orca v1.4.240

A more dependable workspace 🐳

This release gives the built-in browser searchable history, makes agent activity easier to follow, and improves recovery across chats and remote terminals. You’ll also find Lean and Zig syntax highlighting, support for larger quick-command collections, and a new orca ports command for finding your dev servers.

The short version

  • Conversations that stay with you: Claude chats now show turns made outside Orca. Retained messages return after reconnect without reopening the chat, and crash recovery no longer guesses that a sent message was undelivered.
  • A browser with a better memory: Search your browsing history, reopen pages, remove unwanted suggestions, and clear history with Undo. Pages can also use files you pick, save or drop through File System Access.
  • Remote work with fewer interruptions: Slow connections survive missed wake probes, reconnect notices explain what is happening, SSH terminals wait for sign-in, and new splits stay on the paired server.
  • Agent status you can trust: Completed Codex subagents stop showing as Working, running main tasks stay visible through /side conversations, and Codex MCP tools that require approval get an approval card.
  • More room for your workflow: Save more than 40 quick commands, find a worktree’s detected dev-server ports with orca ports, and reclaim old dependency installs and build output from development worktrees.
  • Polish where it counts: Lean and Zig highlighting, clearer session-search excerpts, smoother Mac trackpad scrolling in terminal apps, and better protection for unmerged branches and worktrees shared between Windows and WSL.

Phone & web updates: Updating Orca on the computer serving your phone or browser updates the served interface. This release also keeps running Codex tasks visible on paired and mobile views during /side conversations and fixes browser-picked or dropped chat attachments uploading to the paired server.

Compatibility & upgrade notes

  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat, agent-status and launch fixes. Codex’s new approval cards cover MCP tool approvals that do not require form fields; general MCP forms and URL-based verification are not supported by this change.
  • Browser history: Open History from the page menu, or use Cmd+Y on macOS and Ctrl+H on Linux and Windows. Search, remove individual entries, or clear the last hour, today or all time, with Undo for clearing.
  • Detected ports: orca ports supports workspace selection and JSON output on runtimes with host-scoped port scanning. Direct SSH hosts do not support detection yet; native folder workspaces require --all to list the host’s listeners.
  • Development cleanup: Manual pnpm reclaim-space and automatic cleanup on development launches can reclaim ignored, untracked dependency installs and generated output in old sibling worktrees, using a default 30-day cutoff. Selected, invoking and excluded worktrees remain protected. Stop sibling apps, agents, installs, builds and tests before applying manual cleanup; reclaimed installs and output need reinstalling or rebuilding when used again.
  • Terminal file links: The earlier change to open a file link in the workspace where it was clicked was reverted in this release.
