Orca v1.4.239

Zwei Veröffentlichungen heute! Schauen Sie sich auch die v1.4.238 release notes an. Diese Version brachte gemeinsame, nicht gespeicherte Änderungen in allen Arbeitsbereichen, umfassendere Agenten-Chats und die Einrichtung von Remote-Konten, einen leistungsfähigeren Browser und eine reibungslosere Telefonsteuerung.

Dein Arbeitsbereich, gemeinsames Arbeiten 🐳

Richten Sie Agentenfähigkeiten in einem click ein, halten Sie Browsersitzungen zwischen Projekten getrennt und wechseln Sie einfacher zwischen Chat und Terminal. Diese Version stärkt auch das Wesentliche: Geteilte Dateien bleiben synchron, SSH-Sitzungen werden zuverlässiger wiederhergestellt und Telefoninteraktionen fühlen sich vorhersehbarer an.

Die Kurzversion

  • Skills, immer verfügbar, wo immer Sie arbeiten: Installieren Sie die Skills von Orca über die Setup-Bildschirme in einem click und installieren oder aktualisieren Sie sie auf gekoppelten Servern und SSH-Hosts mit dem eigenen Installationsprogramm von Orca.
  • Ein Browser, der zu Ihren Projekten passt: Wählen Sie freigegebene, Repository- oder Arbeitsbereichsprofile für neue Registerkarten. Halten Sie lokale App-Anmeldungen getrennt, verwenden Sie ein vertrautes Seitenkontextmenü und erhalten Sie klarere Erklärungen, wenn eine Seite nicht geladen werden kann.
  • Flüssigere Agentengespräche: Teilen Sie sich in einen neuen Chat neben Ihrem aktuellen auf, fahren Sie mit einem Terminalagenten aus der Kopfzeile des Bereichs fort und behalten Sie Nachrichten in der Warteschlange und mehrere Bildanhänge bei.
  • Sicherere Bearbeitungen, leisere Hintergrundarbeit: Freigegebene Dateiansichten bleiben nach dem Rückgängigmachen und Verwerfen aktuell. Nicht-UTF-8-Dateien fragen vor der Konvertierung nach, die Dateiüberwachung wird nach Verlangsamungen wiederhergestellt und Orca überwacht weniger nicht verwandte Dateien.
  • Remote-Arbeit mit einem Weg zurück: Stellen Sie unterstützte verwaltete SSH-Server aus einer veralteten Sperre in den Einstellungen wieder her, stellen Sie Terminals nach der Passwortanmeldung wieder her und behalten Sie die SSH-Zugriffsverbindung eines gekoppelten Servers bei Neustarts bei.
  • Besser von Ihrem Telefon aus: Wenn Sie auf eine Benachrichtigung tippen, wird der Agent geöffnet, der sie gesendet hat, Agenten-Chat-Registerkarten können mit dem Diktieren beginnen, Terminal-Kopierbefehle erreichen das Telefon clipboard und Android-Scrollen hält die Tastatur aus dem Weg.
  • Alltägliche Politur, sprachübergreifend: Bessere koreanische Eingabe, bengalische und andere indische Terminalwiedergabe, vollständigere Übersetzungen, Jira-Benutzerauswahl und PR-Kommentarlinks, die direkt zum Editor führen. Telefonaktualisierungen: Durch die Aktualisierung von Orca auf dem Computer, der Ihr Telefon bedient, wird die bereitgestellte Schnittstelle aktualisiert. Native Download-, Fortschritts- und Navigationsverbesserungen erfordern eine aktualisierte native Telefon-App.

Kompatibilitäts- und Upgrade-Hinweise

  • Browserprofile: Wählen Sie Einstellungen → Browser → Profil für neue Tabs. Geteilt bleibt die Standardeinstellung; Pro-Repo- und Pro-Workspace-Profile gelten für neue Registerkarten. Paired-Server-Seiten verwenden die eigenen Profile des Servers.
  • Nativer Chat (experimentell): Aktualisieren Sie gekoppelte und SSH-Hosts neben Orca, um die neuesten Chat- und Startkorrekturen zu erhalten. Die Chat-Verfügbarkeit prüft jetzt die Chat-Laufzeit getrennt vom Terminal CLI, einschließlich unterstützter Antigravity-Setups.
  • SSH-Wiederherstellung: Server wiederherstellen… ist für unterstützte verwaltete Linux-SSH-Hosts verfügbar, die eine Ablehnung der veralteten Sperre melden. Es überprüft die Sperre und fordert Sie auf, zu bestätigen, dass Orca nicht auf einem anderen Computer ausgeführt wird, der sich das Haus teilt, bevor die Sperre aufgehoben wird. Telefone verweisen Sie auf die Desktop-Einstellungen.
  • Experimentelle Grundlagen: Die Grundlagen für den Layoutbesitzer bleiben deaktiviert. Die Startaktionen für leere Gruppen und das Umschalten des Status des untergeordneten Arbeitsbereichs wurden vor der Veröffentlichung zurückgesetzt.

orca v1.4.239

Two releases today! Check out the v1.4.238 release notes too. That release brought shared unsaved edits across workspaces, richer agent chats and remote account setup, a more capable browser, and smoother phone controls.

Your workspace, working together 🐳

Set up agent skills in one click, keep browser sessions separate between projects, and move more easily between chat and terminal. This release also strengthens the essentials: shared files stay in sync, SSH sessions recover more reliably, and phone interactions feel more predictable.

The short version

  • Skills, ready wherever you work: Install Orca’s skills in one click from setup screens, and install or update them on paired servers and SSH hosts with Orca’s own installer.
  • A browser that fits your projects: Choose shared, per-repo or per-workspace profiles for new tabs. Keep local app logins separate, use a familiar page context menu, and get clearer explanations when a page cannot load.
  • More fluid agent conversations: Split into a fresh chat beside your current one, continue with a terminal agent from the pane header, and keep queued messages and multiple image attachments intact.
  • Safer edits, quieter background work: Shared file views stay current after undo and discard. Non-UTF-8 files ask before conversion, file watching recovers after slowdowns, and Orca watches fewer unrelated files.
  • Remote work with a way back: Recover supported managed SSH servers from a stale lock in Settings, restore terminals after password sign-in, and keep a paired server’s SSH access link through restarts.
  • Better from your phone: Tapping a notification opens the agent that sent it, agent chat tabs can start dictation, terminal copy commands reach the phone clipboard, and Android scrolling keeps the keyboard out of the way.
  • Everyday polish, across languages: Better Korean input, Bengali and other Indic terminal rendering, more complete translations, Jira user pickers, and PR comment links that jump straight to the editor.

Phone updates: Updating Orca on the computer serving your phone updates the served interface. Native download, progress and navigation improvements require an updated native phone app.

Compatibility & upgrade notes

  • Browser profiles: Choose Settings → Browser → Profile for new tabs. Shared remains the default; per-repo and per-workspace profiles apply to new tabs. Paired-server pages use the server’s own profiles.
  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat and launch fixes. Chat availability now checks the chat runtime separately from the terminal CLI, including supported Antigravity setups.
  • SSH recovery: Recover server… is available for supported managed Linux SSH hosts reporting a stale-lock refusal. It checks the lock and asks you to confirm that no other machine sharing that home is running Orca before clearing it. Phones point you to desktop Settings.
  • Experimental groundwork: The layout-owner groundwork remains disabled. The empty-group launch actions and child-workspace status toggle were reverted before release.
