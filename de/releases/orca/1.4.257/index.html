Orca v1.4.257

Vorherige Version: 1.4.256 – Einfachere Diktiereinrichtung auf dem Gerät und frühere Leistungsverbesserungen bei langen Chats.

Reibungslosere lange Chats, gespeichertes Feedback und besseres Diktat ✨

Orca 1.4.257 reduziert das Einfrieren, wenn mehrere lange Chat-UI-Konversationen gleichzeitig gestreamt werden. Wenn Sie mehrere Agenten an Gesprächen mit langer Historie arbeiten lassen, reduziert dieses Update die Arbeit von Orca, wenn ihre Antworten eingehen.

  • 🌐 Behalten Sie Ihr Browser-Feedback über Neustarts hinweg bei: Nicht gesendete Textnotizen auf Seiten im Orca-Browser werden jetzt nach einem Neuladen oder Neustart angezeigt. Wenn Sie einen Tab mit nicht gesendeten Notizen schließen, werden Sie vor dem Verwerfen gefragt, sodass Sie Feedback hinterlassen und später darauf zurückkommen können. Agenten, die auf Ihrem Desktop ausgeführt werden, können diese Notizen mit orca tab annotations lesen, bevor Sie auf Senden klicken.
  • 🎙️ Lassen Sie sich beim Diktieren Zeit zum Nachdenken: Wählen Sie unter Einstellungen → Sprache → Eingabe → Stopp nach Stille 30 Sekunden, eine Minute, zwei Minuten oder Aus. Das Diktat kann eine längere Pause einlegen, während Sie eine Nachricht oder einen Terminalbefehl verfassen. Auf derselben Einstellungsseite wird eine Schaltfläche Test hinzugefügt, um Ihr Mikrofon aufzuzeichnen und wiederzugeben, mit einem Transkript, wenn Ihr Sprachmodell bereit ist.
  • ⌨️ Einfügen, während ein Terminal eine Verbindung herstellt: Ein Befehl, der in ein startendes oder erneut verbindendes Terminal eingefügt wird, wartet jetzt auf seine Shell, anstatt gelöscht zu werden. Dies umfasst lokale, SSH- und Remote-Terminals für Pasten bis zu 64 KB; Größere Pasten benötigen weiterhin ein angeschlossenes Terminal.
  • 🗂️ Automatisieren Sie Ordner-Arbeitsbereichsroutinen: Konfigurierte Setup-Skripts werden jetzt ausgeführt, wenn Sie einen Ordner-Arbeitsbereich erstellen, auch über CLI. Archivskripte werden vor dem Entfernen ausgeführt. Verwenden Sie sie, um das Projekt vorzubereiten und seine Bereinigungsroutine auszuführen. Diese Skripte werden im freigegebenen Projektordner ausgeführt.

Highlights

  • Finden Sie, was in einen geteilten Bereich gehört: Drücken Sie / in einem leeren geteilten Bereich, um nach einem Agenten oder einer Datei zu suchen. Verwenden Sie die Pfeiltasten und die Eingabetaste, um Ihre Auswahl zu öffnen, ohne die Tastatur zu verlassen.
  • Behalten Sie Ihr ausgewähltes Claude-Modell bei: Die Chat-UI-Auswahl behält Ihre letzte Auswahl, wenn Antworten von einem früheren Zug eingehen, anstatt zu ihrem Modell zurückzukehren.
  • Sehen Sie sich die Bilder an, die Sie von Codex erstellen lassen: Erstellte Bilder bleiben nach Abschluss einer Runde sichtbar, ohne dass die Werkzeugdetails erweitert werden. Aktualisieren Sie bei Remote-Chats sowohl den Host als auch client, ​​um dieses Verhalten zu erhalten.

orca v1.4.257

Previous release: 1.4.256 — Easier on-device dictation setup and earlier long-chat performance improvements.

Smoother long chats, saved feedback and better dictation ✨

Orca 1.4.257 reduces freezes when several long Chat UI conversations stream at once. If you keep multiple agents working in conversations with a lot of history, this update cuts the work Orca does as their replies arrive.

  • 🌐 Keep your browser feedback across restarts: Unsent text notes on pages in Orca’s browser now return after a reload or restart. Closing a tab with unsent notes asks before discarding them, so you can leave feedback and come back to it later. Agents running on your desktop can read those notes with orca tab annotations before you press Send.
  • 🎙️ Give yourself time to think while dictating: In Settings → Voice → Input → Stop After Silence, choose 30 seconds, one minute, two minutes or Off. Dictation can wait through a longer pause while you compose a message or terminal command. The same settings page adds a Test button to record and play back your microphone, with a transcript when your speech model is ready.
  • ⌨️ Paste while a terminal connects: A command pasted into a starting or reconnecting terminal now waits for its shell instead of being dropped. This covers local, SSH and remote terminals for pastes up to 64 KB; larger pastes still need a connected terminal.
  • 🗂️ Automate folder workspace routines: Configured setup scripts now run when you create a folder workspace, including through the CLI. Archive scripts run before removal. Use them to prepare the project and run its cleanup routine; these scripts operate in the shared project folder.

Highlights

  • Find what belongs in a split pane: Press / in an empty split pane to search for an agent or file. Use the arrow keys and Enter to open your selection without leaving the keyboard.
  • Keep your chosen Claude model: The Chat UI picker keeps your latest selection when replies from an earlier turn arrive, rather than snapping back to their model.
  • See the images you asked Codex to make: Generated images remain visible after a turn finishes, without expanding its tool details. For remote chats, update both the host and client to get this behavior.
