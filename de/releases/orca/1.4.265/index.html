Orca v1.4.265

Vorherige Version: 1.4.264 – Chat-Befehle finden ihren Arbeitsbereich und sorgen dafür, dass der Browser mit dem richtigen Chat funktioniert.

Wir stellen vor: Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" />

Orca-Bots arbeiten wie erstklassige Teamkollegen: Jede verwaltete Agentensitzung erhält ihre Tools und Identität, Bots können im Namen des Eigentümers Inhalte teilen, sie folgen Slack-Threads und Gmail-Triggern zuverlässiger und die Verbindung zwischen ihnen ist klarer und sicherer.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" /> Jede Bot-Sitzung erhält ihre Tools und Identität: Verwaltete Agentensitzungen sind nicht mehr auf Claude und Codex beschränkt; Jeder beginnt mit den Werkzeugen und der Identität, die er benötigt.
  • 🔗 Bots können teilen, genau wie der Besitzer: Agent CLI-Anrufer können Sharing auf die gleiche Weise nutzen wie der Besitzer.
  • 💬 Slack-Threads zeigen, was ein Bot tut: Ein Thread spiegelt jetzt wider, woran er gerade arbeitet, und lange Antworten kommen im Ganzen statt zerschnitten an.
  • 📬 Gmail-Trigger stimmen mit dem tatsächlichen Absender überein: Trigger stimmen mit der tatsächlichen Adresse des Absenders überein, nicht mit einem Anzeigenamen, der abweichen kann.
  • 🛡️ Deutlichere Zugriffswarnungen: Im Dialogfeld zur Zugriffsbestätigung wird jetzt angezeigt, was Sie zulassen, bevor Sie einen Bot verbinden.

Highlights

Bots, Konnektoren und Zugriff. Verbinden Sie einen Bot über eine schnellere Konnektorauswahl mit Kategoriesymbolen, einem gekürzten Slack-Verbindungsdialog, der zeigt, wie der Bot erwähnt wird, sobald er installiert ist, und einer klareren Warnung zur Zugriffskontrolle. Andere Konversationen werden nur zu Referenzzwecken im Kontext eines Agenten aufgelistet, sodass sich ein Bot auf die Konversation konzentrieren kann, nach der er gefragt wurde. Abschlusswarnungen und Worker-Stop-Berichte enthalten die Antwort, die ein gelesenes Transkript hinzufügt, und Agenten wird mitgeteilt, welcher E-Mail-Typ eingestellt werden soll, einschließlich über --on. Ein leichterer Desktop für vielbeschäftigte Chats und Terminals. Lange Tab-Strips rendern nur den sichtbaren Bereich, Sitzungsspeicher schreiben geänderte Einträge, neue Nachrichten werden durchgelassen, während andere Chats gestreamt werden, und eine Terminal-Scroll-Schleife, die das Fenster einfrieren könnte, wurde behoben. Senden, während andere Chats streamen. Die Sendearbeit eines neuen Chats hat Vorrang vor Streaming-Schreibvorgängen im Hintergrund. Versteckte Komponisten hören außerdem nicht mehr auf jeden Tastendruck und geschlossene Chats geben Statuszeilen frei, die sie nicht mehr benötigen. Diese Änderungen reduzieren konkurrierende Arbeit, wenn mehrere Konversationen aktiv sind. Lesen Sie den Status, ohne den Thread zu verlieren. Erweitern Sie die Aktivitätszeilen für Details oder öffnen Sie die eigene Ansicht eines Subagenten. Text vor einer Frage bleibt auch nach dem Abbruch der Runde sichtbar, beibehaltene Diagramme überdauern Arbeitsbereichswechsel und fehlgeschlagene viele frühere Nachrichten bieten „Wiederholen“ an. Verwenden Sie den Agenten auf dem richtigen Host. Die Installation von Claude und Codex erfolgt auf dem Host, auf dem der Chat ausgeführt wird. Eine bestehende persönliche Installation hat Vorrang; Die verwalteten Kopien von Orca stehen auch seinen Terminals zur Verfügung. Auch Remote-Kontokontrollen und Nutzungsanzeigen erhalten Korrekturen. Wählen Sie automatische Desktop-Updates. Aktivieren Sie Automatische Updates unter Einstellungen → Allgemein → Info, damit Orca mit Ihrer Update-Rhythmusfrequenz, Ihrem Update-Kanal und Ihrer Verzögerung herunterladen, installieren und neu starten kann. Die Standardeinstellung ist „Aus“. Die automatische Installation wartet, wenn sie ein aktives oder startendes In-Process-Terminal beenden würde, eine WSL-Verschiebung aktiv ist oder der Fensterstatus nicht gespeichert werden kann. Telefonkompatibilität. Die unten aufgeführten Telefonänderungen sind Quelländerungen, die in dieser Versionsgrenze enthalten sind. Durch die Installation dieses Desktop-Updates wird kein Update für eine mobile App installiert. Für diese Funktionen ist der entsprechende mobile Build erforderlich.

orca v1.4.265

Previous release: 1.4.264 — Chat commands find their workspace, keeping browser work with the right chat.

Introducing Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" />

Orca Bots work like first-class teammates: every managed agent session gets its tools and identity, bots can share on the owner's behalf, they follow Slack threads and Gmail triggers more reliably, and connecting them is clearer and safer.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" /> Every bot session gets its tools and identity: Managed agent sessions are no longer limited to Claude and Codex; each one starts with the tools and identity it needs.
  • 🔗 Bots can share, just like the owner: Agent CLI callers can use Sharing the same way the owner does.
  • 💬 Slack threads show what a bot is doing: A thread now reflects what its turn is working on, and long answers arrive whole instead of cut up.
  • 📬 Gmail triggers match the real sender: Triggers match the sender's actual address, not a display name that can differ.
  • 🛡️ Clearer access warnings: The access confirm dialog now spells out what you are allowing before you connect a bot.

Highlights

Bots, connectors and access. Connect a bot through a faster connector picker with category icons, a trimmed Slack connect dialog that shows how to mention the bot once it is installed, and a clearer access-control warning. Other conversations are listed for reference only in an agent's context, so a bot stays focused on the one it was asked about. Finish alerts and worker stop reports carry the reply a transcript read adds, and agents are told which mail type to set, including over --on.

A lighter desktop for busy chats and terminals. Long tab strips render only the visible region, session saves write changed entries, new messages get through while other chats stream, and a terminal scroll loop that could freeze the window is fixed.

Send while other chats stream. A new chat’s sending work gets priority over background streaming writes. Hidden composers also stop listening to every keystroke, and closed chats release status rows they no longer need. These changes reduce competing work when several conversations are active.

Read status without losing the thread. Expand activity rows for details or open a subagent’s own view. Text before a question remains visible after the turn folds, retained diagrams survive workspace switches, and failed loads of earlier messages offer Retry.

Use the agent on the right host. Claude and Codex installation follows the host where the chat runs. An existing personal installation takes precedence; Orca’s managed copies are available to its terminals too. Remote account controls and usage displays also receive fixes.

Choose automatic desktop updates. Enable Automatic updates in Settings → General → About to let Orca download, install and relaunch using your update cadence, channel and delay. It defaults to off. Automatic installation waits if it would terminate a live or launching in-process terminal, a WSL move is active, or window state cannot be saved.

Phone compatibility. The phone changes listed below are source changes included in this release boundary. Installing this desktop update does not install a mobile app update; those features require the corresponding mobile build.
