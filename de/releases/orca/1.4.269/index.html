Orca v1.4.269

Nach 1.4.268 folgt hier die nächste Runde von Orca. Bots lernen acht weitere Agenten und die Telefon-App holt mit dem Desktop gleich.

Bots auf acht weitere Agenten, ein volleres Telefon und einen leiseren Mac ✨

Bots können jetzt auf Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid und Goose ausgeführt werden, Chat öffnet direkt mehr Agenten und die Telefon-App kann fast alles beantworten, genehmigen und einrichten, was der Desktop kann.

  • 🤖 Bots auf mehr Agenten ausführen: Bots können auf Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid und Goose ausgeführt werden. Der Chat kann auch Kiro, Auggie und Goose öffnen, und Kiro-Chats führen Ihre eigenen Hooks aus.
  • 📱 Machen Sie mehr mit Ihrem Telefon: Beantworten Sie die Fragen eines Agenten und Google- oder Composio-Einrichtungskarten in seinem Chat, überprüfen Sie Tool-Genehmigungen und Zugriffsanfragen in „Benötigt Sie“, verwalten Sie die Tools und Webhooks eines Agenten, starten Sie einen neuen Chat über + und durchsuchen Sie die Threads und Elemente einer Gruppe. Diese benötigen den passenden mobilen Aufbau.
  • 🔐 Antigravity, ganz nach Ihrem Geschmack: Benutzer eines Google-Kontos können die integrierte Google-Anmeldung von Orca oder den AGY-Agenten auswählen, und AGY verfügt über eigene Anmeldeeinstellungen.
  • 💤 Ein leiserer Mac im Leerlauf: Mac-Terminals im Leerlauf verbrauchen weniger CPU und die Git-Arbeit beginnt auf dem Hintergrundprozess-Worker unter macOS und Linux.
  • 🧭 Übersichtlichere Chats: Ältere Nachrichten zeigen Kalenderdaten an, Lebenslauf sticht in einer pausierten Warteschlange hervor und Claude-Chats, deren Einstellungen den Vollzugriff blockieren, sagen es und wählen den nächstgelegenen zulässigen Modus aus.

Über Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="36" height="36" valign="middle" />

Orca-Bots arbeiten wie erstklassige Teamkollegen: Sie arbeiten jetzt mit viel mehr Agenten, arbeiten in Gruppenräumen gegenseitig zusammen und senden Ergebnisse, die Sie tatsächlich öffnen können.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> Acht weitere Agenten hinter deinen Bots: Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid und Goose gesellen sich zu den Agenten, auf denen ein Bot laufen kann.
  • Links zeigen den Fortschritt an, während Bots sie veröffentlichen, und Sie können eine Zugriffsanfrage direkt über das Dialogfeld „Zugriff gewähren“ ablehnen.
  • 🤝 Übergaben in Gruppenräumen: Wenn ein Bot in seiner Antwort ein anderes Mitglied als @Name benennt, ist dieses Mitglied an der Reihe.
  • 📎 Ergebnisse, die Sie öffnen können: Bots teilen einen Link, hängen die Datei an oder geben den Inhalt anstelle eines Pfads auf ihrem eigenen Computer an, und lokale Pfade in Slack-Nachrichten werden zu lesbaren Etiketten.
  • 🧩 Ein Skills-Ordner pro Bot: Die eigenen Skills eines Bots befinden sich in einem agentenneutralen Ordner, den jeder Agent, auf dem er ausgeführt wird, verwenden kann.

Demnächst verfügbar

  • Antigravitations-Fehlerbehebungen
  • Mehr Anschlüsse
  • Einfacheres Verschieben von Bots zwischen verschiedenen Maschinen
  • Weitere Leistungsverbesserungen
  • Beheben Sie Probleme mit dem Blockieren von Bots bei hoher Aufgabenlast
  • Verbesserter PR-Review-Workflow
  • Weiteres Plugin API
  • UX-Verbesserungen in der Seitenleiste

orca v1.4.269

Following 1.4.268, here is the next round of Orca. Bots learn eight more agents, and the phone app catches up with the desktop.

Bots on eight more agents, a fuller phone & a quieter Mac ✨

Bots can now run on Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid and Goose, Chat opens more agents directly, and the phone app can answer, approve and set up almost everything the desktop can.

  • 🤖 Run bots on more agents: Bots can run on Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid and Goose. Chat can open Kiro, Auggie and Goose too, and Kiro chats run your own hooks.
  • 📱 Do more from your phone: Answer an agent's questions and Google or Composio setup cards from its chat, review tool approvals and access requests in Needs you, manage an agent's tools and webhooks, start a new chat from +, and browse a group's threads and items. These need the matching mobile build.
  • 🔐 Antigravity, your way: Google account users can pick Orca's built-in Google sign-in or the agy agent, and agy has its own Sign in in Settings.
  • 💤 A quieter Mac when idle: Idle Mac terminals use less CPU, and Git work starts on the background process worker on macOS and Linux.
  • 🧭 Clearer chats: Older messages show calendar dates, Resume stands out in a paused queue, and Claude chats that settings block from Full access say so and pick the closest allowed mode.

About Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="36" height="36" valign="middle" />

Orca Bots work like first-class teammates: they now run on many more agents, hand work to each other in group rooms, and send results you can actually open.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> Eight more agents behind your bots: Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid and Goose join the agents a bot can run on.
  • Links show progress while Bots publish them, and you can reject an access request right from its Give access dialog.
  • 🤝 Hand-offs in group rooms: When a bot names another member as @Name in its reply, that member picks up the turn.
  • 📎 Results you can open: Bots share a link, attach the file or give the content instead of a path on their own computer, and local paths in Slack messages become readable labels.
  • 🧩 One skills folder per bot: A bot's own skills live in one agent-neutral folder that every agent it runs on can use.
