Orca v1.4.247

Verbesserte Chat-Benutzeroberfläche, umfangreichere Telefonbewertungen und mehr Möglichkeiten, Orca zu Ihrem zu machen ✨

  • 🔄 Weiter nach Zurücksetzen der Nutzungsbeschränkung: Eine optionale Einstellung setzt Ihren Chat automatisch fort, wenn die Nutzungsbeschränkung zurückgesetzt wird.
  • 📱 Reichhaltigere Bewertungen auf Ihrem Telefon: Durchsuchen Sie Branch-Commits, springen Sie zwischen Dateien in Diffs und lesen Sie Pull-Request-Überprüfungskommentare oder fügen Sie sie neben dem Code hinzu.
  • 🎨 Machen Sie Orca zu Ihrem: Entdecken Sie weitere Themen, zeigen Sie Schriftarten in ihren eigenen Schriftarten in der Vorschau an und importieren Sie Ghostty- oder Kitty-Konfigurationsdateien.
  • 🧩 Leistungsstärkere Plugins: Erstellen Sie benutzerdefinierte Editoren, Live-Statuselemente und -Panels und verbinden Sie Plugins mit Agentenaufforderungen, Starts und Arbeitsbereichsaktionen.
  • 🤝 Eindeutigere Agentenaktivität: Laufende Mitarbeiter bleiben sichtbar, nachdem ihr Koordinator fertig ist, mit einfacherem Kontowechsel und klareren Übergabekarten.
  • ⚡ Flüssigere tägliche Arbeit: Weniger unnötige Neuzeichnungen und Offscreen-Animationen, zuverlässigere gespeicherte Antworten und Korrekturen für Arbeitsbereiche, Terminals und Emulatorvorschauen.
  • 💬 Verbesserte Chat-Benutzeroberfläche: Wählen Sie in den Einstellungen der Chat-Benutzeroberfläche für jeden Agenten „Chat“ oder „CLI“, behalten Sie Entwürfe bei, wenn Sie von einem Terminal aus fortfahren, und sehen Sie Ihren ausgewählten Berechtigungsmodus deutlich.

Highlights

  • Chat-Benutzeroberfläche: Wählen Sie für jeden Agenten direkt in den Chat-Benutzeroberflächeneinstellungen „Chat“ oder „CLI“. Berechtigungsoptionen bleiben sichtbar, Modell- und Aufwandskontrollen bleiben nutzbar, während die Optionen aktualisiert werden und die Fokussierung auf den Composer sorgt dafür, dass offene Überlagerungen an Ort und Stelle bleiben.
  • Konversationskontinuität: Behalten Sie nicht gesendeten Text bei, wenn Sie von einem Terminal in den Chat wechseln, und behalten Sie empfangene Antworten und Tool-Ergebnisse bei, während der Speichervorgang aktiv ist. Aktivieren Sie die automatische Fortsetzung, um einen Chat fortzusetzen, nachdem sein Nutzungslimit zurückgesetzt wurde.
  • Telefon-Quellcodeverwaltung: Überprüfen Sie jedes Branch-Commit auf einer eigenen Seite, springen Sie zwischen Dateien, falten Sie den Diff-Kontext und lesen Sie Überprüfungskommentare oder fügen Sie sie neben dem Code hinzu. Die Registerkarte „Pull-Request“ konzentriert sich auf das, was die Zusammenführung blockiert, mit klareren nächsten Aktionen und automatischen Aktualisierungen.
  • Themen und Schriftarten: Finden Sie GitHub-, VS-Code- und Katalogthemen in den Darstellungssteuerelementen. Sehen Sie sich jede Schriftart in ihrer eigenen Schriftart an, importieren Sie Ghostty-Designs mit Hell/Dunkel-Paaren und fügen Sie auch Kitty-Konfigurationsdateien hinzu.
  • Plugins: Erstellen Sie benutzerdefinierte Editoren, die ausstehende Bearbeitungen durch Speichern und Neuladen, Live-Statusleistenelemente und Komponentenfelder mit einem Box-Layout-Container beibehalten. Hooks verbinden Plugins mit Agentenstarts, Eingabeaufforderungen, Toolaufrufen, Terminalsendungen und der Erstellung von Arbeitsbereichen. Screenshot- und Testtools helfen, das Ergebnis zu überprüfen.
  • Agenten und Orchestrierung: Laufende Worker bleiben in der Agentenliste, nachdem ihr Koordinator fertig ist. Übergabekarten erleichtern die Nachverfolgung delegierter Arbeiten und die Kontowechselfunktionen von Codex und Claude sind einfacher zu verwenden.
  • Remote-Arbeit und Arbeitsbereiche: Zeigen Sie eine Vorschau von Remote-HTML außerhalb registrierter Arbeitsbereiche an, finden Sie Projekte in gestoppten WSL-Distributionen nach einem Neustart und sehen Sie einen klareren Git-Fortschritt. Untergeordnete Arbeitsbäume bleiben im Projekt des Aufrufers, Ordnerstämme bleiben sichtbar und Zweiglinks öffnen die aktuelle Pull-Anfrage.
  • Reaktionsfähigkeit und Zuverlässigkeit: Offscreen-Animationen werden angehalten, unabhängige Einstellungsänderungen führen zu weniger Diff-Neuzeichnungen und nicht verwendete Editormodelle werden freigegeben. Terminal-Korrekturen verhindern verirrten Escape-Text, während Emulator-Vorschauen klareres Verbindungs- und Start-Feedback bieten.

Kompatibilitäts- und Upgrade-Hinweise

  • Chat oder CLI pro Agent: Die Chat-Benutzeroberfläche ist nicht mehr experimentell. Gemeinsame Startsteuerungen sind auch unter Einstellungen → Chat-Benutzeroberfläche verfügbar, sodass Sie auswählen können, welche Oberfläche jeder Agent öffnet.
  • Automatische Fortsetzung ist optional: Aktivieren Sie diese Option, wenn Sie möchten, dass ein Chat mit eingeschränkter Nutzung nach dem Zurücksetzen des Limits automatisch fortgesetzt wird.
  • Sendeverhalten des Telefons: Das Telefon folgt der Sendeeinstellung des gekoppelten Desktops. Aktualisieren Sie Orca Mobile sowie Ihren Desktop oder Server, um die mobilen Änderungen zu erhalten.
  • Orchestrierungsfenster: Das experimentelle Orchestrierungsfenster ist deaktiviert, während seine App-weite Verzögerung behoben wird. Orchestrierungsbefehle funktionieren weiterhin.

Bekannte Probleme

Gesparter Chat-Speicher: Der Chat-Verlauf kann weiterhin mehr Speicherplatz beanspruchen, wenn die Konversationen zunehmen. Die automatische Speicherkomprimierung ist in dieser Version nicht enthalten.

Plugin-Befehlsersetzungen: Ein Plugin, das einen integrierten Befehl ersetzt, kann immer noch beendet werden, nachdem Orca stattdessen den normalen Befehl verwendet hat, was dazu führt, dass die Aktion zweimal ausgeführt wird.

Highlights

  • Chat UI: Choose Chat or CLI for each agent directly in Chat UI settings. Permission choices stay visible, model and effort controls remain usable while options refresh, and focusing the composer keeps open overlays in place.
  • Conversation continuity: Keep unsent text when moving from a terminal into chat, and preserve received replies and tool results while saving is busy. Turn on automatic continuation to resume a chat after its usage limit resets.
  • Phone source control: Review each branch commit on its own page, jump between files, fold diff context, and read or add review comments alongside the code. The pull-request tab focuses on what blocks the merge, with clearer next actions and automatic refreshes.
  • Themes & fonts: Find GitHub, VS Code and catalog themes in the appearance controls. Preview each font in its own typeface, import Ghostty themes with light/dark pairs, and bring in Kitty configuration files too.
  • Plugins: Create custom editors that keep pending edits through saves and reloads, live status bar items, and component panels with a Box layout container. Hooks connect plugins to agent launches, prompts, tool calls, terminal sends and workspace creation; screenshot and testing tools help check the result.
  • Agents & orchestration: Running workers remain in the Agents list after their coordinator finishes. Hand-off cards make delegated work easier to follow, and Codex and Claude account switchers are simpler to use.
  • Remote work & workspaces: Preview remote HTML outside registered workspaces, find projects in stopped WSL distros after a restart, and see clearer Git progress. Child worktrees stay in the caller’s project, folder roots remain visible, and branch links open the current pull request.
  • Responsiveness & reliability: Offscreen animations pause, unrelated settings changes cause fewer diff redraws, and unused editor models are released. Terminal fixes prevent stray escape text, while emulator previews offer clearer connection and startup feedback.

Compatibility & upgrade notes

  • Chat or CLI per agent: Chat UI is out of Experimental. Shared launch controls are also available in Settings → Chat UI, so you can choose which surface each agent opens.
  • Automatic continuation is optional: Enable it if you want a usage-limited chat to continue automatically after the limit resets.
  • Phone Send behavior: The phone follows the paired desktop’s send setting. Update Orca Mobile as well as your desktop or server to get the mobile changes.
  • Orchestration panel: The experimental Orchestration panel is disabled while its app-wide lag is addressed. Orchestration commands continue to work.

Known issues

Saved chat storage: Chat history can continue to use more disk space as conversations grow; automatic storage compaction is not included in this release.

Plugin command replacements: A plugin replacing a built-in command can still finish after Orca has used the normal command instead, causing the action to happen twice.
