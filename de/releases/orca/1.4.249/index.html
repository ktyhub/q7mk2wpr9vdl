Orca v1.4.249

Einfachere Einrichtung, mehr Kontrolle über Chats und aufgeräumtere Arbeitsbereiche ✨

  • 🎛️ Wählen Sie von Anfang an Chat oder Terminal: Beim Onboarding können Sie jetzt Chat-UI oder Terminal auswählen, dann einen Agenten auswählen und die Fähigkeiten für dieses Setup installieren.
  • 💬 Behalten Sie die Kontrolle über Konversationen: Behalten Sie Chat-Eingaben durch unsichere Zustellung und Stopp bei, legen Sie fest, ob das Senden die Bildlaufposition verschiebt, und entscheiden Sie, wann inaktive Chat-Agenten anhalten – oder weitermachen.
  • 🗂️ Sorgen Sie für Ordnung bei Projekten: Durch das Hinzufügen eines Projekts werden erkannte Arbeitsbäume ausgeblendet, während beim Erstellen und Klonen verknüpfte übergeordnete Ordner konsistent verarbeitet werden.
  • 📝 Machen Sie das Lesen und Bearbeiten zu Ihren eigenen Wünschen: Legen Sie die Standard-Markdown-Ansicht fest, fügen Sie beim Speichern optional eine letzte neue Zeile ein und passen Sie die Chat-Breite in den Bereichskopfzeilen an.
  • 📱 Eine übersichtlichere Telefon-Startseite: Die aktualisierte Telefon-App trennt Feed, Nutzung, Automatisierungen und Einstellungen, zeigt mehr Agentennutzung an und benennt aktuelle Gespräche.
  • 🧩 Kleine Korrekturen bei der täglichen Arbeit: Behalten Sie die Scrollposition des Terminals bei der Eingabe bei, öffnen Sie Dateilinks in ihrem Arbeitsbereich, rendern Sie Mermaid in PR-Kommentaren und schließen Sie schwebende Browser-Splits über ihre eigene Symbolleiste.

Highlights

  • Einrichtung und Fähigkeiten: Wählen Sie beim Onboarding Chat oder Terminal aus, verwenden Sie die aktualisierte Agentenauswahl und den aktualisierten Designschritt und installieren Sie Chat-Kenntnisse für den ausgewählten Anbieter auf diesem Computer. Leere, neu hinzugefügte Projekte können den ausgewählten Chat-Agenten öffnen, wenn diese Route unterstützt wird.
  • Chat-Verhalten: Eingaben und in der Warteschlange befindliche Folgeanfragen bleiben durch unsichere Zustellung und Stopp erhalten. Neue Einstellungen steuern die Bildlaufposition beim Senden und wenn inaktive Chat-Agenten anhalten. Geladene Chat-Bilder bleiben beim Scrollen und beim Wechseln des Arbeitsbereichs sichtbar, und die Pi-Komprimierung hält Sendungen an, bis sie abgeschlossen ist.
  • Agent-Auswahl: Verwaltete Claude-Konten behalten spätere /model- und Aufwandsoptionen bei, wenn sich die Standardeinstellungen nicht geändert haben. Claude-Fallback wird angezeigt, ohne dass die gespeicherten Modellauswahlen geändert werden; Der OpenCode-Aufwand folgt dem ausgewählten Modell und Claude Chat fügt den Ultracode-Aufwand hinzu.
  • Projekte und Navigation: Durch das Hinzufügen eines Projekts werden erkannte Arbeitsbäume ausgeblendet. Beim Erstellen und Klonen von Projekten werden verknüpfte übergeordnete Elemente konsistent aufgelöst. Die manuelle Arbeitsbereichsreihenfolge und die zu suchende Eingabe in der Agentenauswahl für neue Arbeitsbereiche werden behoben.
  • Editor und Browser: Wählen Sie die Standard-Markdown-Ansicht, aktivieren Sie „Endgültige neue Zeile beim Speichern einfügen“, behalten Sie das HTML-Erscheinungsbild des Chats in der Dateivorschau bei und schließen Sie einen schwebenden Browser-Split, ohne das Terminal daneben zu schließen.
  • Telefon: Die aktualisierte App fügt Home-Registerkarten, die Verwendung für mehr Agenten und Konversationsnamen in „Zurückspringen“ hinzu. Außerdem werden die Terminaleingabe, die Aufwandskontrolle, die HTML-Vorschau und das Android-Design-/Navigationsverhalten verbessert.
  • Automatisierung und Benachrichtigungen: Automatisierungen verwenden die gemeinsame Agentenauswahl, akzeptieren Pi-Modell-/Denkargumente und werden aktualisiert, wenn sich Projekte ändern. Unterbrochene Terminalautomatisierungsläufe werden als fehlgeschlagen aufgezeichnet, bestätigte Desktop-Warnungen gelöscht und OpenCode-Abschlussbenachrichtigungen behandeln OSC 7501.

Kompatibilitäts- und Upgrade-Hinweise

  • Bestehende Setup-Optionen: Die neuen Onboarding-Optionen verwenden vorhandene Oberflächen- und Agenteneinstellungen. Diese Version setzt nicht den Standardagenten aller zurück und stellt nicht jeden vorhandenen Arbeitsbereich auf Chat um. Ein Arbeitsbereich mit vorhandenen Registerkarten behält diese bei; Der Chat-Pfad für ein neues Projekt hängt von einer unterstützten Laufzeit und einem unterstützten Agenten ab.
  • Chat-Einstellungen: Scrollen beim Senden und Stoppen des Agenten im Leerlauf sind konfigurierbar. Wählen Sie Nie, wenn inaktive Chat-Agenten weiterhin ausgeführt werden sollen. Das Stoppen eines inaktiven Agenten ist unabhängig vom Löschen der Konversation.
  • Verwaltete Claude-Konten: Unveränderte Standardeinstellungen überschreiben spätere Kontoauswahlen nach der Synchronisierung der Einstellungen nicht mehr. Dadurch werden von einem älteren Build überschriebene Auswahlmöglichkeiten nicht wiederhergestellt, und geänderte Standardschlüssel gelten weiterhin.
  • Gepaarte Server: Verbesserungen an Dateiverknüpfungen mit gepaarten Servern nutzen die neue Funktion, sofern verfügbar; Ältere Server behalten ihren bestehenden Pfad. Für die Setup-Änderungen gibt es keine neue Mindestserverversion. Die GitHub-Problembeschränkungen bei älteren Servern bleiben unten.
  • Änderungen am Telefon: Korrekturen an der nativen Benutzeroberfläche des Telefons und an Android erfordern eine aktualisierte Orca Mobile-App sowie einen kompatiblen Desktop oder Server. Die mobilen Änderungen sind in Orca Mobile 0.0.64 enthalten; Durch die alleinige Aktualisierung des Desktops wird keine native Telefonversion installiert.
  • Orchestrierungspanel: Das experimentelle Panel und seine Einstellungen sind vorübergehend wieder deaktiviert. Änderungen der Orchestrierungsnachrichten sind unabhängig von der Verfügbarkeit dieses Panels.

Bekannte Probleme

Chat-Einrichtung ohne Standardagenten: Wenn die Chat-Benutzeroberfläche aktiviert und der Standardagent in den Einstellungen deaktiviert ist, kann die Schaltfläche Skills installieren im Setup-Handbuch ohne Erklärung deaktiviert bleiben. Wählen Sie vor der Installation einen Standardagenten, z. B. Claude.

Shell-Verlauf nach einem Kaltstart: Einige Mac-Shell-Fenster können nach einem vollständigen App- und Terminal-Neustart erneut geöffnet werden, ohne dass ihre vorherige Ausgabe angezeigt wird. Diese Fehlerklasse wurde auch bei v1.4.248 beobachtet; Die Ursache bleibt ungeklärt. Diese Version erhebt nicht den Anspruch, das Problem zu beheben.

GitHub-Probleme auf älteren gekoppelten Servern: Das Öffnen eines Problems über ein Repository oder eine URL kann dazu führen, dass die Bearbeitung von Titel, Label und Beauftragter nicht möglich ist. Telefonproblem Schließen/Erneutöffnen kann auch einen älteren Server oder Vermittler ablehnen. Geöffnet am GitHub bleibt verfügbar.

Gesparter Chat-Speicher und Leistung: Die Komprimierung des Live-Verlaufs bleibt angehalten, sodass der Speicherplatz mit fortschreitenden Gesprächen wachsen kann. Diese Version erhebt nicht den Anspruch, jede Quelle von Chat-Störungen zu entfernen. Hook-Änderungen reduzieren die Arbeit von Unterprozessen, es wurden jedoch keine Latenz-, CPU- und Heap-Verbesserungen für die gesamte App gemessen.

Lange Update-Verzögerungen: Bei einer Verzögerung von 14 oder 30 Tagen kann eine Veröffentlichung den Update-Feed verlassen, bevor sie berechtigt ist. „Keine“ und „Verzögerung einmal überspringen“ bleiben verfügbar.

Plugin-Befehlsersetzungen: Ein Plugin, das einen integrierten Befehl ersetzt, kann immer noch beendet werden, nachdem Orca stattdessen den normalen Befehl verwendet hat, was dazu führt, dass die Aktion zweimal ausgeführt wird.

orca v1.4.249

Easier setup, more control over chats & tidier workspaces ✨

  • 🎛️ Choose Chat or Terminal from the start: Onboarding now lets you pick Chat UI or Terminal, then choose an agent and install the skills for that setup.
  • 💬 Keep control of conversations: Preserve chat inputs through uncertain delivery and Stop, choose whether sending moves the scroll position, and decide when idle chat agents stop—or keep them running.
  • 🗂️ Keep projects tidy: Adding a project keeps discovered worktrees hidden, while create and clone handle symlinked parent folders consistently.
  • 📝 Make reading and editing your own: Set the default Markdown view, optionally insert a final newline on save, and adjust chat width from pane headers.
  • 📱 A clearer phone Home: The updated phone app separates Feed, Usage, Automations and Settings, shows more agent usage, and names recent conversations.
  • 🧩 Small fixes across daily work: Keep terminal scroll position on input, open file links in their workspace, render Mermaid in PR comments, and close floating browser splits from their own toolbar.

Highlights

  • Setup & skills: Pick Chat or Terminal during onboarding, use the updated agent picker and theme step, and install Chat skills for the selected provider on this computer. Empty newly added projects can open the chosen Chat agent when that route is supported.
  • Chat behavior: Inputs and queued follow-ups are retained through uncertain delivery and Stop. New settings control scroll position when sending and when idle chat agents stop. Loaded chat images stay visible across scrolling and workspace switches, and Pi compaction holds sends until it finishes.
  • Agent choices: Managed Claude accounts keep later /model and effort choices when the defaults have not changed. Claude fallback is shown without changing saved model choices; OpenCode effort follows the selected model, and Claude chat adds Ultracode effort.
  • Projects & navigation: Adding a project keeps discovered worktrees hidden. Project creation and cloning resolve symlinked parents consistently; manual workspace order and type-to-search in the new-workspace agent picker receive fixes.
  • Editor & browser: Choose the default Markdown view, enable Insert Final Newline on save, preserve chat HTML appearance in file previews, and close a floating browser split without closing the terminal beside it.
  • Phone: The updated app adds Home tabs, usage for more agents and conversation names in Jump back in. It also improves terminal input, effort controls, HTML previews and Android theme/navigation behavior.
  • Automation & notifications: Automations use the shared agent picker, accept Pi model/thinking arguments and refresh when projects change. Interrupted terminal automation runs are recorded as failed, acknowledged desktop alerts clear, and OpenCode completion notifications handle OSC 7501.

Compatibility & upgrade notes

  • Existing setup choices: The new onboarding choices use existing surface and agent preferences. This release does not reset everyone's default agent or switch every existing workspace to Chat. A workspace with existing tabs keeps them; the new-project Chat path depends on a supported runtime and agent.
  • Chat settings: Scroll-on-send and idle-agent stopping are configurable. Choose Never if you want idle chat agents to remain running; stopping an idle agent is separate from deleting the conversation.
  • Managed Claude accounts: Unchanged defaults stop overwriting later account choices after settings synchronization. This does not recover choices overwritten by an older build, and changed default keys still apply.
  • Paired servers: Improvements to paired-server file links use the new capability when available; older servers retain their existing path. There is no new minimum server version for the setup changes. GitHub issue limitations with older servers remain below.
  • Phone changes: Native phone UI and Android fixes require an updated Orca Mobile app as well as a compatible desktop or server. The mobile changes are included in Orca Mobile 0.0.64; updating desktop alone does not install a native phone release.
  • Orchestration panel: The experimental panel and its setting are temporarily disabled again. Orchestration messaging changes are separate from availability of that panel.

Known issues

Chat setup with no default agent: With Chat UI enabled and the default agent cleared in Settings, Setup Guide's Install skills button can remain disabled without an explanation. Choose a default agent, such as Claude, before installing.

Shell history after a cold restart: Some Mac shell panes can reopen without showing their previous output after a full app and terminal restart. This class of failure was also observed on v1.4.248; the cause remains unresolved. This release does not claim to fix it.

GitHub issues on older paired servers: Opening an issue through a repository or URL can leave title, label and assignee editing unavailable. Phone issue Close/Reopen can also refuse an older server or intermediary. Open on GitHub remains available.

Saved chat storage & performance: Live-history compaction remains paused, so storage can grow as conversations continue. This release does not claim to remove every source of chat stalls. Hook changes reduce subprocess work, but whole-app latency, CPU and heap improvements were not measured.

Long update delays: With a 14- or 30-day delay, a release can leave the update feed before it becomes eligible. None and Skip Delay Once remain available.

Plugin command replacements: A plugin replacing a built-in command can still finish after Orca has used the normal command instead, causing the action to happen twice.
