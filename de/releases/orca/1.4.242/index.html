Orca v1.4.242

Weniger Speicher, Claude-Subagenten sind nur click entfernt und Remote-Server, die sich erinnern 🪄

Diese Version ist speichersparender, mit geringerer Speichernutzung im Terminal-Host und WSL-Verbindungen sowie weniger Leerlauf-CPU-Nutzung in Terminals. Außerdem können Sie damit Claude-Subagenten direkt aus der Seitenleiste öffnen, Codex-Chats im Fragemodus vor der Bearbeitung fragen und gekoppelte Server sowie SSH- und WSL-Hosts dabei unterstützen, den Überblick zu behalten und Fehler zu erklären. Diese Version behebt auch Probleme unter Windows, Linux und macOS.

Die Kurzversion

  • Öffnen Sie Claude-Subagenten aus der Seitenleiste: Climarkieren Sie eine Claude-Subagentenzeile in der Seitenleiste oder im Dashboard, um deren Transkript im selben Terminal zu öffnen, und climarkieren Sie dann den übergeordneten Agenten, um zurückzugehen. Ein Auge markiert das, was Sie gerade betrachten.
  • Chats, die zuerst fragen: Codex-Chats im Fragemodus fragen jetzt, bevor Sie Ihren Arbeitsbereich bearbeiten. Remote-Claude-Terminals auf gekoppelten Servern können im Chat fortfahren, und Chats, die nicht gestartet werden können, sagen Ihnen, warum.
  • Agenten werden so fortgesetzt, wie Sie sie verlassen haben: Wiederaufgenommene Claude-Sitzungen behalten ihr Aufwandsniveau und ihre Startflags, Codex behält die Berechtigung, die Sie ihm zuletzt erteilt haben, und der Sitzungsverlauf findet Chats in mehr Ordnern und auf Servern.
  • Remote-Server, die sich erinnern: Gepaarte Server behalten Ihre Tabs über Neustarts hinweg, geschlossene Tabs bleiben geschlossen, WSL-Hosts hören nach jedem Neustart auf, sich erneut zu koppeln, und SSH-Fehler zeigen, was tatsächlich schief gelaufen ist.
  • Weniger Arbeitsspeicher: Terminals verbrauchen deutlich weniger CPU im Leerlauf, der Terminal-Host verbraucht beim nächsten Neustart weniger Speicher, WSL-Verbindungen benötigen viel weniger Speicher und das Ressourcenfenster entspricht jetzt dem Aktivitätsmonitor unter macOS.
  • Korrekturen aus der Community: Verteilte Windows-Startpfade, koreanische Eingabe, Sommerzeit in Automatisierungen, Fokus-Folgt-Maus, Tab-Dragging und Linux-Pakete funktionieren alle besser. Telefon- und Web-Updates: Telefone erklären jetzt, dass ein Computer nicht erreichbar ist, anstatt sich ewig zu drehen, und Streaming-Antworten und lange Web-Chats werden weniger neu gezeichnet. Terminalprogramme, die dem Terminal eine Frage stellen, funktionieren auch weiterhin, während ein Telefon in Desktopgröße zuschaut.

Kompatibilitäts- und Upgrade-Hinweise

  • Codex-Chats im Ask-Modus: Ask läuft jetzt schreibgeschützt und fragt, bevor der Arbeitsbereich bearbeitet wird; „Für mich genehmigen“ und „Voller Zugriff“ bleiben unverändert, und bereits laufende Arbeiten behalten ihre Gewährung. Chats auf einem gekoppelten Server behalten das alte Verhalten bei, bis dieser Server aktualisiert wird.
  • Claude-Subagenten-Navigation: Standardmäßig aktiviert mit Claude-Status-Hooks. Orca lädt sein Plugin nur in Orca-Fenster und fügt in jedem verwendeten Claude-Ordner eine Verknüpfung zu keybindings.json hinzu, die erste ohne Strg+Alt+G, H oder V. Deaktivieren Sie es unter Einstellungen → Agenten → Claude-Subagentennavigation, um diese Verknüpfung zu entfernen. Bereits laufende Claude-Sitzungen müssen neu gestartet werden.
  • Gepaarte Server: Um einen Bereich in einen neuen Tab zu verschieben und ein Remote-Claude-Terminal im Chat fortzusetzen, ist der Server erforderlich, um diese Version auszuführen. Auf älteren Servern bleibt die Verschiebung wie zuvor nur in diesem Fenster und „Weiter“ in der Chat-Benutzeroberfläche wird mit einem Aktualisierungshinweis als deaktiviert angezeigt.
  • Claude-Kontowechsel: Das Wechseln von Konten bietet jetzt auch die Möglichkeit, Sitzungen neu zu starten, die in Ihrem standardmäßigen Claude-Ordner Ihres Systems ausgeführt werden, wenn dieser Ordner beim alten Konto angemeldet ist. Das Dialogfeld gruppiert Sitzungen in Sitzungen für das alte Konto, andere und Sitzungen, die nicht verschoben werden können.
  • WSL-Hosts: Verbindungen zum Server eines WSL-Hosts laufen jetzt über Bash und fallen auf Node zurück, wenn Bash fehlt oder zu alt ist. Dies erfordert kein Server-Update und funktioniert mit jeder Serverversion.

orca v1.4.242

Lighter on memory, Claude subagents a click away, and remote servers that remember 🪄

This release is lighter on memory, with lower memory use in the terminal host and WSL connections, plus less idle CPU use in terminals. It also lets you open Claude subagents straight from the sidebar, makes Codex chats in Ask mode ask before editing, and helps paired servers, SSH and WSL hosts keep your tabs and explain failures. This release also fixes problems across Windows, Linux and macOS.

The short version

  • Open Claude subagents from the sidebar: Click a Claude subagent row in the sidebar or dashboard to open its transcript in the same terminal, then click the parent to go back. An eye marks the one you’re viewing.
  • Chats that ask first: Codex chats in Ask mode now ask before editing your workspace, remote Claude terminals on paired servers can continue in Chat, and chats that can’t start tell you why.
  • Agents resume as you left them: Resumed Claude sessions keep their effort level and launch flags, Codex keeps the permission you last gave it, and Session History finds chats in more folders and on servers.
  • Remote servers that remember: Paired servers keep your tabs across restarts, closed tabs stay closed, WSL hosts stop re-pairing after each restart, and SSH failures say what actually went wrong.
  • Lighter on memory: Terminals use far less idle CPU, the terminal host uses less memory once it next restarts, WSL connections need much less memory, and the resource panel now matches Activity Monitor on macOS.
  • Fixes from the community: Spaced Windows launcher paths, Korean input, DST in automations, focus-follows-mouse, tab dragging and Linux packages all work better.

Phone & web updates: Phones now explain an unreachable computer instead of spinning forever, and streaming replies and long web chats redraw less. Terminal programs that ask the terminal a question also keep working while a phone watches at desktop size.

Compatibility & upgrade notes

  • Codex chats in Ask mode: Ask now runs read-only and asks before workspace edits; Approve for me and Full access are unchanged, and work already running keeps its grant. Chats on a paired server keep the old behavior until that server is updated.
  • Claude subagent navigation: On by default with Claude status hooks. Orca loads its plugin only into Orca panes and adds one shortcut, the first free of Ctrl+Alt+G, H or V, to keybindings.json in each Claude folder it uses. Turn it off in Settings → Agents → Claude subagent navigation to remove that shortcut. Claude sessions already running need a fresh launch.
  • Paired servers: Moving a pane into a new tab and continuing a remote Claude terminal in Chat need the server to run this release. On older servers the move stays in this window only, as before, and Continue in Chat UI shows disabled with an update hint.
  • Claude account switching: Switching accounts now also offers to restart sessions running in your System default Claude folder when that folder is signed in to the old account. The dialog groups sessions into those on the old account, others, and ones it can’t move.
  • WSL hosts: Connections to a WSL host’s server now go through bash and fall back to Node when bash is missing or too old. This needs no server update and works with any server version.
