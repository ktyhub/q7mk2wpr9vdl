Orca v1.4.237

100.000 Sterne. Danke schön! ⭐🐳

Orca hat gerade 100.000 Sterne auf GitHub überschritten! Jeder Fehlerbericht, jede Pull-Anfrage, jeder gemeinsame Workflow und jede Empfehlung hat uns dabei geholfen, hierher zu kommen. Vielen Dank, dass Sie mit Orca zusammenarbeiten und mitgestalten, was als nächstes kommt. ❤️ Um dies zu feiern, bietet diese Version ein leistungsfähigeres Telefonerlebnis, zuverlässigere Agentengespräche und Korrekturen, die Ihre Arbeit auf Desktops und Remote-Rechnern am Laufen halten.

Die Kurzversion

  • Mehr von Ihrem Telefon aus erledigen: Notizen erstellen und bearbeiten, Markdown auf Headless-Hosts speichern, relativen Dateilinks folgen und eingebettete Bilder sehen. Gepufferte Terminalentwürfe können jetzt auch die Navigation im Arbeitsbereich überstehen.
  • Chats, zu denen Sie zurückkehren können: Codex-Chats werden nach dem Rückgängigmachen wieder korrekt geöffnet, Claude behält seinen zurückgespulten Kontext über Orca-Rollbacks hinweg bei und Screenshots bleiben bei der Konversation. Die Fertigkeitsauswahl des Codex spiegelt nun die tatsächlich geladenen Fertigkeiten des Codex wider.
  • Ihre Arbeit bleibt geschützt: „Verwerfen“ unterbricht die automatische Speicherung derselben Datei in allen Arbeitsbereichen. Schreibgeschützte Markdown- und CSV-Ansichten schützen Ihre nicht gespeicherten Änderungen, und neue, nicht bereitgestellte Markdown-Dokumente werden direkt im Rich-Editor geöffnet.
  • Sprache über den Desktop hinaus: Das Telefondiktieren funktioniert wieder über kopflose orca serve-Hosts, mit einem CLI-Befehl zum Konfigurieren des OpenAI-Schlüssels des Hosts.
  • Reinigere Remote-Arbeit: Versteckte Terminal-Registerkarten nach einem Neustart wieder verbinden, Browser-Anmeldungen beibehalten, wenn Hosts erneut gekoppelt werden, und SSH-Konfigurationen mit Tausenden von Hosts durchsuchen, ohne dass die Schnittstelle einfriert.
  • Kleine Details, besserer Ablauf: Telefonregisterkarten folgen der Desktop-Reihenfolge, Querformat-Layouts zeigen den Sitzungstitel an, Tastatursteuerelemente behalten ihre Höhe und Worktree-Sicherheitsdurchläufe überspringen unveränderte Arbeitsbereiche. Telefonaktualisierungen: Durch die Aktualisierung von Orca auf dem Computer, der Ihr Telefon bedient, wird auch die bediente Schnittstelle des Telefons aktualisiert. Für dauerhafte Terminalentwürfe ist zusätzlich eine aktualisierte mobile Shell erforderlich.

Kompatibilitäts- und Upgrade-Hinweise

  • Nativer Chat (experimentell): Aktualisieren Sie gekoppelte und SSH-Hosts neben Orca, um die neuesten Chat-Korrekturen zu erhalten. Die genaue Auswahl der Codex-Skill-Dateien ist auf dem Desktop mit einem unterstützenden Host verfügbar; Telefonauswahlen und ältere Hosts behalten die Klartext-Skill-Namen bei. Senden Sie eine Fertigkeit als neue Nachricht an Codex, um sie zu Beginn einer Runde anzuwenden.
  • Kopfloses Diktat: Speichern Sie den OpenAI-Schlüssel auf dem Host, der die Transkription durchführt, mit orca speech openai-key set (liest den Schlüssel von stdin). orca serve-Hosts mit installierter App unter Linux und macOS können auch die gebündelte On-Device-Erkennung verwenden; Windows-, verwaltete SSH- und WSL-Server verwenden Cloud-Modelle.
  • CLI-Startauswahl: Explizite --surface-Auswahlmöglichkeiten erfordern einen aktualisierten Ausführungshost. Wenn Sie die Option weglassen, bleiben Ihre bestehenden Standardeinstellungen erhalten.

orca v1.4.237

100,000 stars. Thank you! ⭐🐳

Orca just crossed 100,000 stars on GitHub! Every bug report, pull request, shared workflow and recommendation has helped us get here. Thank you for building with Orca and helping shape what comes next. ❤️

To celebrate, this release brings a more capable phone experience, more dependable agent conversations, and fixes that keep your work moving across desktops and remote machines.

The short version

  • More done from your phone: Create and edit notes, save Markdown on headless hosts, follow relative file links, and see embedded images. Buffered terminal drafts can now survive workspace navigation, too.
  • Chats you can come back to: Codex chats reopen correctly after undo, Claude keeps its rewound context across Orca rollbacks, and screenshots stay with the conversation. Codex’s skill picker now reflects the skills Codex actually loaded.
  • Your work stays protected: Discard pauses autosave of the same file across workspaces. Read-only Markdown and CSV views protect your unsaved edits, and new, unstaged Markdown documents open straight into the rich editor.
  • Voice beyond the desktop: Phone dictation works again through headless orca serve hosts, with a CLI command to configure the host’s OpenAI key.
  • Smoother remote work: Reconnect hidden terminal tabs after a restart, keep browser logins when hosts pair again, and search SSH configurations with thousands of hosts without freezing the interface.
  • Small details, better flow: Phone tabs follow desktop order, landscape layouts show the session title, keyboard controls keep their height, and worktree safety sweeps skip unchanged workspaces.

Phone updates: Updating Orca on the computer serving your phone also updates the phone’s served interface. Persistent terminal drafts additionally require an updated mobile shell.

Compatibility & upgrade notes

  • Native chat (experimental): Update paired and SSH hosts alongside Orca to get the latest chat fixes. Exact Codex skill-file selection is available on desktop with a supporting host; phone selections and older hosts retain plain-text skill names. Send a skill as a new message for Codex to apply it at the start of a turn.
  • Headless dictation: Save the OpenAI key on the host doing the transcription with orca speech openai-key set (reads the key from stdin). Installed-app orca serve hosts on Linux and macOS can also use the bundled on-device recognizer; Windows, managed SSH and WSL servers use cloud models.
  • CLI launch choice: Explicit --surface choices require an updated execution host. Omitting the option keeps your existing defaults.
