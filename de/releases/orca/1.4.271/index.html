Orca v1.4.271

Nach 1.4.269 folgt hier die nächste Runde von Orca. Bots erreichen Qwen Code und erstrecken sich über Ihre gekoppelten Computer, die Telefon-App verwaltet Agenten durchgängig und Chats werden einfacher und schneller.

Bots auf allen Computern, ein Telefon, das Ihre Agenten steuert, und schnellere Chats ✨

Eine Bot-Gruppe kann jetzt Bots von Ihren gekoppelten Computern speichern, Bots können auf Qwen Code ausgeführt werden, Chats können gelöscht werden und nach einer Nutzungsbeschränkung selbstständig fortgesetzt werden, und die Telefon-App kann Agenten ohne den Desktop teilen, importieren und verbinden.

  • 🤖 Bots über Computer und Agenten hinweg: Eine Bot-Gruppe kann Bots von gekoppelten Computern enthalten, Bots können auf Qwen Code ausgeführt werden und Gruppenräume geben Follow-up-Runden an jedes Mitglied, das ein Agent @erwähnt.
  • 📱 Agenten von Ihrem Telefon aus ausführen: Bearbeiten Sie die Automatisierungen eines Agenten, verbinden Sie Slack, Linear, GitHub, Google und Composio, teilen Sie einen Agenten per Link, importieren Sie einen von OpenClaw oder Hermes, lesen Sie seine Seele und verwalten Sie sein Gedächtnis und seine Fähigkeiten und übergeben Sie eine Verlaufssitzung an einen anderen Agenten. Diese benötigen den passenden mobilen Aufbau.
  • 💬 Ruhigere Chats: Löschen Sie einen Chat, fahren Sie standardmäßig nach einer Nutzungsbeschränkung fort, listen Sie Ordner im @-Menü auf und sehen Sie ruhigere Zeilen und einen Composer, der seinen Begrüßungstext klar hält.
  • 🐧 Stabileres Windows und WSL: WSL-Hosts zählen funktionierende Agents für das Wachhalten, Codex-Konten und -Einstellungen verhalten sich auf WSL und das Verschieben eines Ordners auf einen WSL-Host fragt zuerst nach.
  • ⚡ Rundum leichter: Terminaltiteländerungen, Aktualisierungen des Agentenstatus, Bot-Listen und Telefonaktualisierungen hören auf, alles erneut zu scannen oder neu zu erstellen, und ausgeblendete Animationen werden angehalten.
  • 🐙 Mehr als ein GitHub-Konto: Verknüpfen Sie mehrere GitHub-Konten mit schlankeren Linkvorschauen und Kommentarabfragen.

Über Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="36" height="36" valign="middle" />

Orca-Bots funktionieren wie erstklassige Teamkollegen: Sie verteilen sich jetzt auf Ihren Computern, merken sich, was sie erledigt haben, und machen dort weiter, wo eine Nutzungsbeschränkung oder ein Neustart sie unterbrochen hat.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> Qwen Code hinter Ihren Bots: Qwen Code verbindet die Agenten, auf denen ein Bot ausgeführt werden kann.
  • 🖥️ Eine Gruppe, viele Computer: Eine Bot-Gruppe kann Bots von gekoppelten Computern enthalten und die Antwort eines Agenten auf die Anfrage eines Peers wird im Raum angezeigt.
  • 📓 Speicher, der auf dem Laufenden bleibt: Bots protokollieren jedes geschlossene Element und seine PRs, wissen, dass der Arbeitsstatus in Elementen und im Journal gespeichert ist, und ein Pilot-Tidy-up verschiebt und führt Speicherzeilen zusammen, anstatt sie neu zu schreiben.
  • 🔁 Macht dort weiter, wo es aufgehört hat: Nach einem Neustart oder einer Nutzungsbegrenzungspause behalten Bots ihre offenen Anfragen und setzen sie einmal fort.
  • 💬 Einfachere Antworten: In den Kommentarfeldern für Elemente werden die Erwähnung des Komponisten und die Slash-Auswahl angezeigt, und „Antworten auf“ springt zu der Frage, die es beantwortet.

Bekanntes Problem

  • ⚠️ Bots können ihre Arbeit unterbrechen: Nach dem Neustart der App oder nach einem Fehler, z. B. dem Erreichen eines Nutzungslimits, kann ein Bot während der Arbeit anhalten. Dies wird in der nächsten Version behoben.

Bots across computers, a phone that runs your agents & snappier chats ✨

One bot group can now hold bots from your paired computers, bots can run on Qwen Code, chats can be deleted and continue on their own after a usage limit, and the phone app can share, import and connect agents without the desktop.

  • 📱 Run agents from your phone: Edit an agent's automations, connect Slack, Linear, GitHub, Google and Composio, share an agent by link, import one from OpenClaw or Hermes, read its soul and manage its memory and skills, and hand a history session to another agent.   • ⚡ Lighter all around: Terminal title changes, agent status updates, bot lists and phone refreshes stop rescanning or rebuilding everything, and hidden animations pause.
  • 🐙 More than one GitHub account: Link several GitHub accounts, with leaner link previews and comment polling.
