Orca v1.4.229

Vielen Dank, dass Sie Orca nutzen und für Ihre anhaltende Unterstützung! ❤️

Die Kurzversion

  • Nativer Chat (experimentell): Überprüfen Sie Turn-by-Turn-Änderungen inline, erweitern Sie Diagramme zum Schwenken und Zoomen, teilen Sie Chat-Visuals mit einem click und sehen Sie sich die Ziele von Claude und die Verwendung des Codex-Kontexts an. Tastaturantworten, eine ungelesene Trennlinie und „Kopieren bei Auswahl“ erleichtern die Navigation in langen Gesprächen.
  • Gemeinsame Fertigkeiten: Die Installation mit geteilten Fertigkeiten unterstützt jetzt 20 zusätzliche Agenten, mit umfassenderer WSL-Erkennung und den richtigen Installationsspeicherorten für Tools wie Kiro, Qoder und CodeBuddy.
  • Telefon: Arbeitsbereichsfilter, Gruppierung und Sortierung folgen jetzt den gemeinsamen Auswahlmöglichkeiten des Desktops. Drücken Sie lange, um verknüpfte Probleme und Notizen aufzurufen, arbeiten Sie mit Serverarbeitsbereichen und Browserseiten oder setzen Sie einen unterstützten Chat in einer neuen Terminalkonversation fort.
  • SSH und Remote-Terminals: Reconnect-Korrekturen behalten geteilte Fensterbereiche bei, fügen Reihenfolge ein und verwaltete Server-Projektgruppen. Schlafende Agenten nehmen ihre Gespräche wieder auf, und wenn das Projekt einer Maschine entfernt wird, bleibt das Gegenstück auf dem gleichen Pfad in Ruhe.
  • Arbeitsbereiche und Alltagspolitur: Öffnen Sie eine Website über Cmd/Strg+J, beobachten Sie den Checkout-Fortschritt, während ein Arbeitsbaum erstellt wird, und bereinigen Sie Arbeitsbereiche mit einer expliziten Bestätigung, bevor Sie die Ausführung von Agenten stoppen.
  • Jira-Planung: Wechseln Sie zwischen Problemlisten und Boards, konzentrieren Sie sich auf den aktuellen Sprint, verwenden Sie gespeicherte JQL- und Jira-Favoriten wieder und starten Sie Arbeitsbereiche vom Desktop oder Telefon aus. Auch Ihre Agenten können Jira-Tickets über den Orca CLI lesen und aktualisieren.

Bekannte Probleme

Nativer Chat (experimentell): Funktionen, die von einem Remote-Host abhängen, sind verfügbar, wenn dieser Host sie unterstützt. Aktualisieren Sie den Host zusammen mit Orca, um die neuesten Funktionen zu erhalten. Der Befehl orca auf SSH-Hosts: Vorhandene Hosts behalten ihre gespeicherte Orca CLI-Steuerungseinstellung. Damit Agenten dort Arbeitsbereiche verwalten oder den Desktop-Browser steuern können, aktivieren Sie Dem Orca CLI dieses Hosts erlauben, Orca zu steuern unter Einstellungen → SSH-Hosts → Host bearbeiten → Erweiterte Verbindung.

orca v1.4.229

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chat (experimental): Review turn-by-turn edits inline, expand diagrams to pan and zoom, share chat visuals with a click, and see Claude goals and Codex context usage. Keyboard answers, an unread divider and Copy on Select make long conversations easier to navigate.
  • Shared skills: Shared-skill installation now supports 20 additional agents, with broader WSL discovery and the right install locations for tools such as Kiro, Qoder and CodeBuddy.
  • Phone: Workspace filters, grouping and sorting now follow the desktop’s shared choices. Long-press for linked issues and notes, work with server workspaces and browser pages, or continue a supported chat in a new terminal conversation.
  • SSH and remote terminals: Reconnect fixes preserve split panes, paste order and managed-server project groups. Sleeping agents resume their conversations, and removing one machine’s project leaves its same-path counterpart alone.
  • Workspaces and everyday polish: Open a website from Cmd/Ctrl+J, watch checkout progress as a worktree is created, and clean up workspaces with an explicit confirmation before stopping running agents.
  • Jira planning: Switch between issue lists and boards, focus on the current sprint, reuse saved JQL and Jira favourites, and start workspaces from desktop or phone. Your agents can read and update Jira tickets through the Orca CLI, too.

Known issues

Native chat (experimental): Features that depend on a remote host are available when that host supports them. Update the host alongside Orca to get the latest capabilities.

The orca command on SSH hosts: Existing hosts keep their saved Orca CLI control preference. To let agents there manage workspaces or control the desktop browser, turn on Allow this host’s orca CLI to control Orca under Settings → SSH Hosts → edit the host → Advanced Connection.
