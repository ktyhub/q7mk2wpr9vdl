Orca v1.4.248

Zuverlässigere Terminals, zuverlässige Chats und einfachere KI-Auswahl ✨

  • 🖥️ Zuverlässigere Terminals: Halten Sie aktive Remote-Streams verbunden, bewahren Sie die Agentenidentität über Daemon-Neustarts hinweg, verbessern Sie geordnete mobile Eingaben und lange Nachrichten an Windows Codex und rendern Sie Nerd-Schriftartsymbole nach dem Laden der Schriftarten korrekt.
  • 💬 Zuverlässigere Konversationen: Streamen Sie Antworten weiterhin nach ihren Aufforderungen, halten Sie Folgeanfragen in der Warteschlange, wenn eine Runde fehlschlägt, und halten Sie eingefügten Text und Terminalentwürfe von Chat-Versendungen getrennt.
  • 🎛️ Wählen Sie aus, wie KI für Sie schreibt: Wählen Sie Modell und Aufwand für Commit-Nachrichten, Pull-Request-Beschreibungen, Branch-Namen und Chat-Namen aus den Quellcodeverwaltungseinstellungen.
  • ⚡ Weniger unnötige Chat-Arbeit: Vorschau-Updates vermeiden das Kopieren der gesamten geladenen Konversation, und diese Version entfernt die Bereinigung des Live-Verlaufs, die große Chats blockieren könnte.
  • 📱 Bessere Telefonkontinuität: Öffnen Sie Chats aus zwischengespeicherten Nachrichten erneut, halten Sie die Optionen aktuell und senden Sie lange Nachrichten zuverlässiger an Windows Codex.
  • ⏳ Wählen Sie, wann Updates eintreffen: Fügen Sie in den Einstellungen eine optionale Update-Verzögerung hinzu, mit einer einmaligen Option, um das Warten zu überspringen.
  • 📝 Editor- und Arbeitsbereichsverbesserungen: Aktivieren Sie das Format beim Speichern, durchsuchen Sie die Themenauswahl und verwenden Sie bekannte Rechts-click-Aktionen auf Chat-Registerkarten.

Highlights

  • Terminals: Remote-Streams bleiben verbunden, während die Ausgabe fließt, die Agentenidentität übersteht Daemon-Neustarts, mobile Eingaben werden der Reihe nach weitergeleitet und lange Telefonnachrichten erreichen Windows Codex. Nerd-Schriftsymbole werden neu gezeichnet, sobald Schriftarten geladen werden, und geschlossene Terminalarbeiter können über ihre Orchestrierungskarten wieder öffnen.
  • Chat-Kontinuität: Streaming-Antworten bleiben nach der Aufforderung, auf die sie antworten, bestehen. Follow-ups bleiben nach einem fehlgeschlagenen Zug in der Warteschlange, abgelaufene Anhänge werden identifiziert, wenn ein Versand abgelehnt wird, und eingefügter Text kann aus strukturierten Chats geöffnet werden.
  • Agent-Start und Optionen: Eine endgültige Startverweigerung wird nach dem ersten Versuch anstelle wiederholter Wiederholungsversuche angezeigt; Vorübergehende Ausfälle erholen sich immer noch. Chats behalten den konfigurierten Aufwand bei, wenn Sie keine Außerkraftsetzung ausgewählt haben, und Textaktionen der Quellcodeverwaltung verwenden die Menüs „Modell“ und „Aufwand“.
  • Telefon: Zwischengespeicherte Chats werden erneut geöffnet, bevor Änderungen abgerufen werden. Chat-Optionen, Terminaleinstellungen, Branch- und Pull-Request-Details werden zuverlässiger aktualisiert; Lange Telefonnachrichten erreichen Windows Codex und von einem Desktop-Server gehostete Browser-Registerkarten können auf das Telefon gestreamt werden.
  • Updates und Windows: Wählen Sie eine Update-Verzögerung, behalten Sie den Speicherort einer verschobenen Windows-Installation während Updates bei und erhalten Sie eine klarere Erklärung, wenn die Installation unvollständig ist.
  • Editor und Navigation: Aktivieren Sie das Format beim Speichern, suchen Sie nach Themenoptionen, markieren Sie ausgewählte Markdown-Tabellenzellen und verwenden Sie Bildzoom-Verknüpfungen außerhalb der Editor-Registerkarten.
  • Orchestrierung und Plugins: Das Orchestrierungspanel ist wieder als experimentelle Option verfügbar. Geschlossene Terminalmitarbeiter können von ihren Karten aus wieder öffnen, native Chats erhalten vollständige Orchestrierungsnachrichten und aktivierte Statusleisten-Plugins sorgen dafür, dass ihre Mitarbeiter weiterarbeiten.
  • Leistung und Zuverlässigkeit: Chat-Vorschauaktualisierungen vermeiden eine redundante Kopie des gesamten Verlaufs, zwischengespeicherter Text-Scrolling vermeidet Layoutaktualisierungen ganzer Dateien und die Diagnoseprotokollierung verbraucht weniger Daten. Durch die Änderung der Vorschau entfällt unnötige Arbeit. Es wird keine Latenzverbesserung für die gesamte App behauptet.

Kompatibilitäts- und Upgrade-Hinweise

  • Update-Verzögerung ist optional: Einstellungen → Allgemein → Updates bietet Keine, 1, 3, 7, 14 oder 30 Tage. „Keine“ bleibt die Standardeinstellung und Skip Delay Once umgeht ein angehaltenes Update.
  • Format beim Speichern ist optional: Das bestehende Bearbeitungsverhalten bleibt gleich, bis Sie es aktivieren.
  • Orchestrierungspanel: Diese Version stellt die experimentelle Opt-in-Funktion nach der früheren Deaktivierung des Panels wieder her.
  • Telefonänderungen: Für Änderungen an der Telefon-App ist eine aktualisierte Orca Mobile-App sowie ein kompatibler Desktop oder Server erforderlich.
  • Gespeicherter Chat-Verlauf: Die zuvor hinzugefügte Bereinigung des Live-Verlaufs wurde zurückgesetzt. Vorhandene gespeicherte Konversationen, einschließlich bereits komprimierter Verläufe, bleiben weiterhin lesbar.

Bekannte Probleme

Gespeicherter Chat-Speicher: Die Komprimierung des Live-Verlaufs wird angehalten, sodass der Chat-Speicher mit fortschreitenden Gesprächen wachsen kann. Diese Version erhebt nicht den Anspruch, jede Quelle von Chat-Störungen zu entfernen.

Lange Update-Verzögerungen: Bei einer Verzögerung von 14 oder 30 Tagen kann eine Veröffentlichung den Update-Feed verlassen, bevor sie berechtigt ist. „Keine“ und „Verzögerung einmal überspringen“ bleiben verfügbar.

GitHub-Probleme auf älteren gekoppelten Servern: Das Öffnen eines Problems über ein Repository oder eine URL kann dazu führen, dass die Bearbeitung von Titel, Label und Beauftragter nicht möglich ist. Lokale und vom Projekt ausgehende Routen sind davon nicht betroffen. Geöffnet am GitHub bleibt verfügbar.

Plugin-Befehlsersetzungen: Ein Plugin, das einen integrierten Befehl ersetzt, kann immer noch beendet werden, nachdem Orca stattdessen den normalen Befehl verwendet hat, was dazu führt, dass die Aktion zweimal ausgeführt wird.

orca v1.4.248

More reliable terminals, dependable chats & easier AI choices ✨

  • 🖥️ More reliable terminals: Keep active remote streams connected, preserve agent identity across daemon restarts, improve ordered mobile input and long messages to Windows Codex, and render Nerd Font symbols correctly after fonts load.
  • 💬 More dependable conversations: Keep streaming replies after their prompts, hold queued follow-ups when a turn fails, and keep pasted text and terminal drafts separate from chat sends.
  • 🎛️ Choose how AI writes for you: Pick Model and Effort for commit messages, pull-request descriptions, branch names and chat names from the Source Control settings.
  • ⚡ Less unnecessary chat work: Preview updates avoid copying the full loaded conversation, and this release removes the live-history cleanup that could stall large chats.
  • 📱 Better phone continuity: Reopen chats from cached messages, keep options current, and send long messages to Windows Codex more reliably.
  • ⏳ Choose when updates arrive: Add an optional update delay in Settings, with a one-time option to skip the wait.
  • 📝 Editor & workspace improvements: Opt into format on save, search theme pickers, and use familiar right-click actions on chat tabs.

Highlights

  • Terminals: Remote streams stay connected while output is flowing, agent identity survives daemon restarts, mobile input is pipelined in order, and long phone messages reach Windows Codex. Nerd Font symbols repaint once fonts load, and closed terminal workers can reopen from their orchestration cards.
  • Chat continuity: Streaming replies stay after the prompt they answer. Follow-ups remain queued after a failed turn, expired attachments are identified when a send is refused, and pasted text can be opened from structured chats.
  • Agent startup & choices: A final startup refusal is shown after the first attempt instead of repeated retries; temporary failures still recover. Chats preserve configured effort when you have not chosen an override, and Source Control text actions use Model and Effort menus.
  • Phone: Cached chats reopen before fetching changes. Chat options, terminal settings, branch and pull-request details refresh more reliably; long phone messages reach Windows Codex, and browser tabs hosted by a desktop server can stream to the phone.
  • Updates & Windows: Choose an update delay, retain a moved Windows installation's location during updates, and get a clearer explanation when installation is incomplete.
  • Editor & navigation: Enable format on save, search theme choices, highlight selected Markdown table cells, and use image zoom shortcuts outside editor tabs.
  • Orchestration & plugins: The Orchestration panel is available again as an experimental opt-in. Closed terminal workers can reopen from their cards, native chats receive complete orchestration messages, and enabled status bar plugins keep their workers running.
  • Performance & reliability: Chat preview updates avoid a redundant full-history copy, cached text scrolling avoids whole-file layout updates, and diagnostic logging uses less data. The preview change removes unnecessary work; no whole-app latency improvement is claimed.

Compatibility & upgrade notes

  • Update delay is optional: Settings → General → Updates offers None, 1, 3, 7, 14 or 30 days. None remains the default, and Skip Delay Once bypasses a held update.
  • Format on save is optional: Existing editing behavior stays the same until you enable it.
  • Orchestration panel: This release restores the experimental opt-in after the earlier panel disablement.
  • Phone changes: Phone app changes require an updated Orca Mobile app as well as a compatible desktop or server.
  • Saved chat history: The live-history cleanup added earlier has been rolled back. Existing saved conversations, including already-compacted histories, remain readable.

Known issues

Saved chat storage: Live-history compaction is paused, so chat storage can grow as conversations continue. This release does not claim to remove every source of chat stalls.

Long update delays: With a 14- or 30-day delay, a release can leave the update feed before it becomes eligible. None and Skip Delay Once remain available.

GitHub issues on older paired servers: Opening an issue through a repository or URL can leave title, label and assignee editing unavailable. Local and project-origin routes are unaffected; Open on GitHub remains available.

Plugin command replacements: A plugin replacing a built-in command can still finish after Orca has used the normal command instead, causing the action to happen twice.
