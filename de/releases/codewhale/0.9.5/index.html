Codewal v0.9.5

Codewhale ist das öffentliche Produkt von Shannon Labs. Der codewhale Befehls-, NPM-Paket- und Release-Asset-Namen bleiben technisch in Kleinbuchstaben geschrieben Identifikatoren. Das alte NPM-Paket deepseek-tui ist veraltet und erhält keine weiteren Veröffentlichungen. Benutzer aus v0.8.x Legacy deepseek / deepseek-tui-Namen sollten mit docs/REBRAND.md migriert werden.

Installieren

Empfohlen – npm (ein Befehl, beide Einstiegspunkte)

npm install -g codewhale

Der Wrapper lädt die übereinstimmenden Befehlsressourcen codewhale und codew herunter aus dieser Version. Beide enthalten die gleiche kompilierte Laufzeit.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.5

Das Bild stellt die gleiche Laufzeit bereit wie codewhale und codew. Die Das latest-Tag wird bei der Veröffentlichung ebenfalls aktualisiert.

Fracht (Linux / macOS)

cargo install codewhale-cli --locked

Das Cargo-Paket installiert codewhale. Cargo kann keinen zweiten Befehl erstellen Alias von einem binären Ziel; Benutzer, die die kürzere Schreibweise wünschen, können a hinzufügen codew-Symlink zu der installierten ausführbaren Datei. Das npm, Homebrew, Archiv, Shell-Installer und Containerkanäle installieren beide Befehlsnamen direkt.

Was ist in v0.9.5

Codewhale v0.9.5 konsolidiert die Terminalanwendung in einer kompilierten Laufzeit unter Beibehaltung der bekannten Befehle codewhale und codew. Es Erweitert außerdem die verwaltete Runtime API und erleichtert die Sitzungs- und Flottenarbeit Inspizieren und fortsetzen und entfernt die versteckte lokale Fortsetzungs-Backstop-Funktion könnte die produktive Arbeit ohne eine abschließende Antwort des Assistenten beenden.

Hinzugefügt

  • model = "auto" für aufforderungsbasierte Stufenauswahl: Wenn festgelegt, wird die Der Dispatcher analysiert die Eingabeaufforderung des Benutzers, bevor er sie an die TUI delegiert wählt deepseek-v4-pro für komplexe Aufgaben oder deepseek-v4-flash für einfache Aufgaben (PR #5257). – Laufzeit-API-Kontrollen für persistente Ziele, begrenzte Speicherinspektion, MCP Server- und Skill-Lifecycle-Management sowie dauerhafte Belege für den Flottenempfang.
  • Sitzungsbaumverlauf nur anhängen mit /tree, /branch, /fork und /resume, plus /rc-Fernbedienung und verwaltete Anmeldung.
  • Eine einheitliche Flottenliste für integrierte Versandpositionen und einen angehefteten Indikator Dadurch bleiben aktive Hintergrundarbeiten über dem Komponisten sichtbar. – Inkrementelle MCP-Registrierungsaktualisierungen, die den lokalen Snapshot sofort zurückgeben und aktualisieren Sie es im Hintergrund.
  • Scout- und Reviewer-Agenten können eine begrenzte Direktbefehls-Beweis-Shell für verwenden schreibgeschützter Arbeitsbereich, Git und GitHub-Inspektion und können privat arbeiten Notizen in ihrem eigenen To-Do, während das dauerhafte Transkript ihre Beweise behält.

Geändert

  • codewhale-cli enthält jetzt direkt die Terminal-Laufzeit. Installationsprogramme veröffentlichen Stellen Sie byteidentische codewhale- und codew-Befehle ohne separate TUI bereit ausführbar. Der v0.9.5-Asset-Satz allein bleibt veraltet codewhale-tui-* Dateinamen als byteidentische Kompatibilitätskopien also Installierte v0.9.4 clients können dieses Upgrade entdecken und abschließen.
  • Die Startup-Version überprüft den Cache erfolgreicher Suchvorgänge eine Stunde lang. Der Updater lädt die primäre Laufzeit herunter, überprüft sie einmal und aktualisiert dann alle vorhandenen codew- oder ältere codewhale-tui-Befehlspfade aus denselben Bytes.
  • Headless codewhale exec läuft nicht mehr und Verifier-Benchmark-Rollouts sind nicht mehr möglich einen Standardwert von 100 Schritten festlegen. --max-turns bleibt als explizite Version verfügbar Opt-in-Obergrenze; Fuhrparkmitarbeiter behalten ihr separat konfiguriertes Budget.
  • Zieltoken und Zeitbudgets sind Telemetriedaten und kein Standardstopp Bedingungen und die automatische Zielfortsetzung ist unbegrenzt, es sei denn, der Benutzer Konfiguriert explizit eine Fortsetzungsobergrenze.
  • Befehlspalette und Slash-Completion-Shadowing teilen sich jetzt ein Alias-fähiges Entdeckungsvertrag.
  • Die Website-Installationsanleitung, lokalisierte Produktkopie, Navigationssteuerung, Soziale Metadaten und die Cloudflare-Build-Pipeline beschreiben und stellen nun die bereit denselben Veröffentlichungsvertrag für eine Laufzeit.

Behoben

  • Die versteckte 20-stufige Rücklaufsperre ohne Benutzereingabe beendet produktive Runden nicht mehr. Tool-Ergebnisse, Steuerung in der Warteschlange, untergeordnete Vervollständigungen, REPL-Feedback und Ziel Fortsetzungen können alle den nächsten Anbieterschritt und einen letzten Assistenten erreichen Reaktion; Es bleiben explizite, vom Benutzer konfigurierte Grenzwerte und echte Stuck-Loop-Schutzvorrichtungen bestehen.
  • Vollständige Fehlerdetails sind direkt nach einem Fehler einsehbar Verlassen des Terminals mit einem clipped, nicht behebbaren Fehlerfragment.
  • Ein neu geprägtes OAuth-Credential wird in die gleiche Provider-Auswahl übernommen Durchfluss, anstatt einen zweiten Picker-Ausflug zu erfordern. – Neue Sitzungstitel können einen veralteten zwischengespeicherten New Session-Platzhalter ersetzen. Unbekannte Modellkontextgrenzen schlagen lautstark fehl und Release-/Quellinstallations-Fallbacks Fordern Sie keine Binärdateien mehr an, die durch die Single-Runtime-Konvertierung entfernt wurden.

Englisches Original / English original

Codewhale v0.9.5

Highlights

  • Single-runtime packaging and migration — codewhale-cli now embeds the terminal runtime, while installers provide byte-identical codewhale and codew commands. Scripts that invoke a separate codewhale-tui executable need updating; those assets exist only as v0.9.5 compatibility copies. The deprecated deepseek-tui npm package receives no further releases, so legacy users should follow docs/REBRAND.md. Cargo installs only codewhale, requiring a manual cod symlink.

  • Prompt-based automatic model selection — model = "auto" analyzes each prompt and selects deepseek-v4-pro for complex work or deepseek-v4-flash for simple tasks (PR #5257). This can reduce unnecessary model spend, but adds routing overhead and makes model choice prompt-dependent; pin an explicit model when reproducibility matters.

  • Long-running turns lose hidden stop conditions — Headless codewhale exec and verifier rollouts no longer impose a 100-step default, and the hidden 20-step no-input backstop is removed. Goal token/time budgets are now telemetry, with automatic continuation unlimited by default. Set --max-turns or an explicit continuation ceiling for unattended automation; Fleet workers retain their separately configured budgets.

  • Durable session and Fleet control — Append-only session history adds /tree, /branch, /fork, and /resume, making exploratory work easier to inspect and recover. /rc, managed login, a unified Fleet roster, and pinned active-work indicators improve remote supervision, while durable Fleet receipts provide evidence for completed background work.

  • Managed Runtime API and responsive MCP discovery — New API controls cover persistent goals, bounded memory inspection, and MCP server/skill lifecycle management. Incremental MCP registry refreshes return the local snapshot immediately and update it in the background, avoiding startup blocking; consumers should tolerate a briefly stale registry view.

  • More transparent agent execution and failures — Scout and Reviewer agents gain a bounded, read-only command shell for workspace, Git, and GitHub evidence, with private notes kept in their own To-do while durable evidence remains in the transcript. Full error details are now inspectable, unknown context limits fail loudly, and newly minted OAuth credentials apply without another provider-selection trip.

Codewhale is the public product from Shannon Labs. The codewhale command, npm package, and release-asset names remain lowercase technical identifiers. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Install

Recommended — npm (one command, both entrypoints)

npm install -g codewhale

The wrapper downloads the matched codewhale and codew command assets from this Release. Both contain the same compiled runtime.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.5

The image exposes the same runtime as both codewhale and codew. The latest tag is also updated on release.

Cargo (Linux / macOS)

cargo install codewhale-cli --locked

The Cargo package installs codewhale. Cargo cannot create a second command alias from one binary target; users who want the shorter spelling can add a codew symlink to that installed executable. The npm, Homebrew, archive, shell-installer, and container channels install both command names directly.

What's in v0.9.5

Codewhale v0.9.5 consolidates the terminal application into one compiled runtime while preserving the familiar codewhale and codew commands. It also expands the managed Runtime API, makes session and Fleet work easier to inspect and resume, and removes the hidden local continuation backstop that could end productive work without a final assistant response.

Added

  • model = "auto" for prompt-based tier selection: When set, the dispatcher analyses the user's prompt before delegating to the TUI and selects deepseek-v4-pro for complex tasks or deepseek-v4-flash for simple tasks (PR #5257).
  • Runtime API controls for persistent goals, bounded memory inspection, MCP server and skill lifecycle management, and durable Fleet receipt evidence.
  • Append-only session-tree history with /tree, /branch, /fork, and /resume, plus /rc remote control and managed login.
  • A unified Fleet roster for built-in dispatch postures and a pinned indicator that keeps active background work visible above the composer.
  • Incremental MCP registry refreshes that return the local snapshot immediately and update it in the background.
  • Scout and Reviewer agents can use a bounded direct-command evidence shell for read-only workspace, Git, and GitHub inspection, and can keep private working notes in their own To-do while the durable transcript retains their evidence.

Changed

  • codewhale-cli now contains the terminal runtime directly. Release installers expose byte-identical codewhale and codew commands without a separate TUI executable. The v0.9.5 asset set alone retains deprecated codewhale-tui-* filenames as byte-identical compatibility copies so installed v0.9.4 clients can discover and complete this upgrade.
  • Startup release checks cache successful lookups for one hour. The updater downloads and verifies the primary runtime once, then refreshes any existing codew or legacy codewhale-tui command paths from the same bytes.
  • Headless codewhale exec runs and verifier benchmark rollouts no longer impose a 100-step default. --max-turns remains available as an explicit opt-in ceiling; Fleet workers retain their separately configured budget.
  • Goal token and time budgets are telemetry rather than default stop conditions, and automatic goal continuation is unlimited unless the user explicitly configures a continuation ceiling.
  • Command-palette and slash-completion shadowing now share one alias-aware discovery contract.
  • The website install guidance, localized product copy, navigation controls, social metadata, and Cloudflare build pipeline now describe and deploy the same one-runtime release contract.

Fixed

  • The hidden 20-step no-user-input backstop no longer ends productive turns. Tool results, queued steering, child completions, REPL feedback, and goal continuations can all reach the next provider step and a final assistant response; explicit user-configured limits and genuine stuck-loop guards remain.
  • Complete error details are directly inspectable after a failure instead of leaving the terminal with a clipped, unrecoverable error fragment.
  • A newly minted OAuth credential is adopted in the same provider-selection flow instead of requiring a second picker trip.
  • Fresh session titles can replace a stale cached New Session placeholder, unknown model context limits fail loudly, and release/source-install fallbacks no longer request binaries removed by the single-runtime conversion.

Contributors

  • Sh1Zuku (@SparkofSpike) fixed stale cached session titles that could pin the New Session placeholder.
  • Paulo Aboim Pinto (@aboimpinto) built the shared alias-aware command discovery contract and acceptance coverage.
  • Sun Zhenyuan (@bistack) contributed the background incremental MCP Registry refresh.
  • SKY ZHAO (@skyzhao1223) contributed prompt-based model = "auto" routing in PR #5257.

See CHANGELOG.md for full notes and docs/CHANGELOG_ARCHIVE.md for older releases.
