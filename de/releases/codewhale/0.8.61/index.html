Codewal v0.8.61

CodeWhale ist das kanonische Projekt, der Befehl, das NPM-Paket und Name des Release-Assets. Das alte NPM-Paket deepseek-tui ist veraltet und erhält keine weiteren Veröffentlichungen. Benutzer kommen aus Die alten v0.8.x-Namen deepseek/deepseek-tui sollten migriert werden mit docs/REBRAND.md.

Installieren

Empfohlen – npm (ein Befehl, beide Binärdateien)

npm install -g codewhale

Der Wrapper lädt beide Binärdateien aus dieser Version herunter und legt sie im selben Verzeichnis ab.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.61

Das Image enthält den codewhale-Dispatcher und die codewhale-tui-Laufzeit. Das latest-Tag wird bei der Veröffentlichung ebenfalls aktualisiert.

Fracht (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Beide Kisten sind erforderlich – codewhale-cli erzeugt den codewhale-Dispatcher und codewhale-tui erzeugt die interaktive Laufzeit, an die der Dispatcher delegiert. Die Installation nur einer Binärdatei schlägt zur Laufzeit mit dem Fehler MISSING_COMPANION_BINARY fehl.

Manueller Download – Plattformarchive (empfohlen)

Jedes der folgenden Archive enthält sowohl den codewhale-Dispatcher als auch die codewhale-tui-Laufzeitumgebung sowie ein Installationsskript: | Plattform | Archiv | Skript installieren | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (Installer) | CodeWhaleSetup.exe | NSIS-Setup | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (tragbar) | codewhale-windows-x64-portable.zip | — | Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Führen Sie für den Installationspfad CodeWhaleSetup.exe aus. Es installiert beide Binärdateien unter %LOCALAPPDATA%\Programs\CodeWhale\bin und fügt dieses Verzeichnis dem PATH des aktuellen Benutzers hinzu.
  • Extrahieren Sie codewhale-windows-x64.zip
  • Führen Sie install.bat aus (kopiert nach %USERPROFILE%\bin)
  • Fügen Sie %USERPROFILE%\bin zu Ihrem PATH hinzu Das tragbare Windows-Archiv überspringt das Installationsskript – extrahieren Sie es und führen Sie es aus einem beliebigen Verzeichnis aus. An jede Plattform sind unten außerdem nackte, nicht archivierte Binärdateien angehängt (codewhale-<platform> und codewhale-tui-<platform>) – diese werden vom npm-Wrapper und dem In-App-Download codewhale update heruntergeladen, wohingegen die oben genannten .tar.gz-/.zip-Archive der empfohlene manuelle Download sind und zusätzlich ein Installationsskript enthalten. Das alte NPM-Paket deepseek-tui ist veraltet und wird nicht erneut veröffentlicht. Informationen zur Migration von v0.8.x-Legacy-Binärnamen finden Sie unter docs/REBRAND.md.

Was ist in v0.8.61

Mit dieser Version wird die Laufzeitsteuerungsebene für die Arbeit mit mehreren Agenten bereitgestellt: Die TUI bleibt erhalten Während die Unteragenten reagieren, konvergieren sie zu langlebigen Arbeitskräften im Flottenstil mit Pro-Rollen-Modell-Routing und Anbieter-/Modell-Routen werden pro Sitzung isoliert. Es auch Faltet mehrere Community-Beiträge ein.

Hinzugefügt

  • WhaleFlow-Laufzeitgrundlagen – Worker-Laufzeitprofile (Rolle/Berechtigungen/Shell/ tools/model-route, mit nicht eskalierender untergeordneter Ableitung), eine anbieterübergreifende Modellregistrierung mit Offline-Kataloghydrierung und Anbieterbereitschaft/Kontextbudget/Anbieteradapter/ Ressourcentelemetriedienste. (#3217, #3071, #3072, #3073)
  • Pro-Rolle, heterogenes Modell-Subagenten-Routing – Subagenten können ein Modell und zugewiesen werden Anbieter pro Rolle (z. B. Scout vs. Synthese; Verifizierer leiten zu einem schnellen Modell weiter). (#2027, #1768)
  • Dauerhafter Zielmodus – zugübergreifender Zielfortschritt mit Token-/Zeitabrechnung und a Bevor ein Tor vollendet werden kann, muss es ein Prüfer-als-Schiedsrichter-Gate geben. (#3215, #891, #1976, #2058, #2029)
  • Vertrag über die Interaktion zwischen Eltern und Arbeitnehmer – eine empfohlene Maßnahme pro Arbeitnehmer. (#3226)
  • Workflow-Kenntnisse des Betreuers GitHub; Einreichung des ACP-Registers vorbereitet. (#3192) – OpenAI-kompatibler /v1/chat/completions-Endpunkt auf dem alten App-Server-HTTP-Transport, Anbieterneutral, mit Modellregistrierungsauflösung und Weiterleitung konfigurierter Anmeldeinformationen.

Geändert

  • Subagenten konvergieren zu langlebigen Arbeitern im Flottenstil – echte Lebenszykluszustände der Arbeiter sind es wird anstelle eines fest codierten „Laufens“ in die Seitenleiste projiziert, und ein Subagent gibt ein strukturiertes Ergebnis zurück Bedarfseingabe-Kontrollpunkt statt Parken. (#3226, #3096, #3154) – Das Runtime-Tag pro Runde legt die Fähigkeitslage offen, statt menschlich zugewandte Modusbezeichnungen. (#3213) – Unabhängige Shell- und Verifizierer-Arbeit erfolgt standardmäßig auf Hintergrundjobs mit nicht blockierenden Wartezeiten und a Fertigstellungsbenachrichtigung; Das Blockieren erfordert jetzt ein explizites Warten. (#3212) – Beim Starten von Subagenten werden dem Modell jetzt explizite model_strength- und thinking-Steuerelemente zur Verfügung gestellt anstelle von verstecktem untergeordnetem Modell-Auto-Routing; Die Arbeit von explore ist nachweislich gut geeignet für schnellere Modelle und thinking: "off".
  • Der Planmodus ist streng schreibgeschützt (keine Shell-Tools), was seinem Laufzeitstatus entspricht.
  • /swarm ist hinter dem langlebigen Arbeitssubstrat angebracht. (#3218) – Der Installations-/Aktualisierungspfad „Legacy deepseek“ wird in „codewhale“ aufgelöst. (#2960, #2924, #2917)

Behoben

  • TUI friert ein, wenn mehrere Subagenten spawnen (Startblocker) – die Eingabepumpe des Terminals läuft Außerhalb des Renderthreads werden AgentProgress-Ereignisse zusammengeführt und Subagenten werden nicht mehr darauf geparkt Eingabe ohne zu beantwortenden Orchestrator; Ein Stresstest mit sechs Mitarbeitern schützt die Eingabe/das Rendern/Abbrechen Lebendigkeit. (#3216, #3096)
  • Benachrichtigungen über den Abschluss inaktiver Unteragenten setzen jetzt den übergeordneten Zug fort, anstatt auf einen zu warten spätere Benutzernachricht; Danke @giovanni-paolilla für den Deadlock-Bericht (#3266).
  • Anbieter-/Modellroutenisolation – Anbieter- und Modellstatus ist sitzungslokal und a Nicht übereinstimmendes Anbieter+Modell-Tupel wird an der Routengrenze abgelehnt. (#3227)
  • Routenwirksame Kontextfenster-Metadaten, Preflight bei Überschreitung des Limits und begrenzte Wiederherstellung von context_length_exceeded statt erneuter Schleife. (#3204)
  • Synchronwerkzeuge (file_search, grep_files, list_dir) sind stornierbar und nicht mehr haltbar eine Wende offen gegen Stornierung. (#1791) – MCP-Stdio-Proxy-Startaufforderungen blockieren YOLO/nicht-interaktive Ausführungen nicht mehr. (#2475)
  • Blockierte/fehlgeschlagene Hintergrund-Shell-Wiederherstellung; konfigurierbarer Subagent API Timeout. (#1737, #1786, #1806)
  • Composer: zuverlässige Warteschlangensteuerung + Strg+S senden (#3203, #3224); Besetzt-/Leerlaufanzeige in der Fußzeile (#2982); CJK-Zeilenumbruch (#963); cliackable Seitenleisten-Stoppziele (#3028); Live-Token-Durchsatz (#3190); automatisch ablaufende Terminal-Subagentenkarten (#3078). – Linux-Glibc-Preflight im Installations-/Update-Pfad mit einem eindeutigen Fehler. (#3207, #1067) – Die Selbstaktualisierung wiederholt vorübergehende GitHub-Metadaten-/Asset-Fehler und greift auf GitHub zurück REST API zur öffentlichen releases/latest-Umleitung, bevor Release-Asset-URLs erstellt werden. (#3232)
  • Die Anbieterauswahl listet Anbieter in neutraler alphabetischer Reihenfolge auf, anstatt DeepSeek zuerst fest zu codieren. Der aktive Anbieter bleibt vorausgewählt. (#3076)
  • In der Arbeitsseitenleiste werden veraltete phase now:/phase next:-Strategiezeilen nach der Checkliste nicht mehr angezeigt ist zu 100 % abgeschlossen.
  • Der Planmodus führt nicht mehr zu einer Verknüpfung der Untersuchung für Anfragen, die ein Repository, eine URL, eine Version usw. benennen. Release, Build-Status, Benchmark, Fehler, PR, Problem, API-Oberfläche oder lokaler Codepfad.
  • Übergroßer eingefügter Text bleibt im Composer bearbeitbar, wobei beim Absenden eine Dateisicherung angehängt wird Zeit für den Modellzugriff; Danke @idling11 (#3267, schließt #3263).
  • Die bloßen Zifferntasten 1-8 fügen jetzt Text ein, anstatt Hotbar-Slots auszulösen; Verwenden Sie Alt+digit für Hotbar-Aktionen. Danke @wjq2026 für den Bericht und @DieMoe233 für den Einfügepfad-Hinweis (#3243).
  • Kimi/Moonshot-Tool-Schemas normalisieren leere Funktionsparameter zu einem Stammobjektschema; Danke @jghwwnq für die Provider-Repro (#3265). – Novita verwendet standardmäßig seinen OpenAI-kompatiblen /openai/v1-Endpunkt, sodass keine Chat-Abschlüsse mehr möglich sind 404 sofort einsatzbereit; Danke @buko für den Bericht und die Endpunktüberprüfung (#3255). – Abhängigkeitssicherheit: ws wird über NPM-Pakete hinweg an 8.21.0 angeheftet, um die Erschöpfung des Remote-Speichers zu verhindern DoS (Depenabot).

Englisches Original / English original

Codewhale v0.8.61

Highlights

  • Durable multi-agent runtime — Worker profiles now encode roles, permissions, tools, and model routes with non-escalating child derivation. Durable goals track token/time budgets across turns and require verifier approval before completion; the sidebar reports real worker states and structured needs-input checkpoints instead of a generic “running” status. /swarm now requires this worker substrate. (#3217, #3215, #3226, #3218)
  • Responsive background execution — The multi-agent TUI freeze is fixed by moving input handling off the render thread and coalescing progress events, guarded by a six-worker liveness test. Shell and verifier work now default to background jobs, and idle sub-agent completion resumes the parent automatically; integrations that assumed implicit blocking must explicitly wait. Cancellation also reaches synchronous file tools. (#3216, #3212, #3266, #1791)
  • Explicit model routing and session isolation — Sub-agents can use different providers/models by role, with model_strength and thinking exposed instead of hidden child-model auto-routing—fast models with thinking disabled are a documented fit for exploration. Provider/model state is now session-local, mismatched routes are rejected, and context-window preflight plus bounded recovery prevents context_length_exceeded retry loops. (#2027, #1768, #3227, #3204)
  • CodeWhale migration and paired binaries — codewhale is now the canonical package, command, and release name; deprecated deepseek-tui receives no further releases, so follow docs/REBRAND.md. npm archives install both binaries, but Cargo users must install both codewhale-cli and codewhale-tui; a missing companion fails with MISSING_COMPANION_BINARY. CODEWHALE_HOME is now the primary configuration home. (#2960, #2924, #2917)
  • Changed TUI and plan-mode contracts — Plan mode is strictly read-only, with no shell tools and no investigation shortcuts for repository, URL, version, or code-path requests. Bare keys 1–8 now insert text; hotbar actions require Alt+digit, so existing keyboard workflows need updating. Runtime tags now describe capability posture rather than user-facing mode labels. (#3213, #3243)
  • Broader provider and integration surface — The legacy app-server gains a provider-neutral OpenAI-compatible /v1/chat/completions endpoint with registry resolution and credential forwarding. Provider fixes include normalized Kimi/Moonshot tool schemas, a working Novita default endpoint, and DeepInfra support; ws is pinned to 8.21.0 to address a remote memory-exhaustion DoS. (#3265, #3255, #3235)

CodeWhale is the canonical project, command, npm package, and release-asset name. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Install

Recommended — npm (one command, both binaries)

npm install -g codewhale

The wrapper downloads both binaries from this Release and places them in the same directory.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.61

The image ships the codewhale dispatcher and codewhale-tui runtime. The latest tag is also updated on release.

Cargo (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Both crates are required — codewhale-cli produces the codewhale dispatcher and codewhale-tui produces the interactive runtime that the dispatcher delegates to. Installing only one binary will fail at runtime with a MISSING_COMPANION_BINARY error.

What's in v0.8.61

This release lands the runtime control plane for multi-agent work: the TUI stays responsive while sub-agents run, sub-agents converge toward fleet-style durable workers with per-role model routing, and provider/model routes are isolated per session. It also folds in several community contributions.

Added

  • WhaleFlow runtime foundations — worker runtime profiles (role / permissions / shell / tools / model-route, with non-escalating child derivation), a cross-provider model registry with offline catalog hydration, and provider-readiness / context-budget / provider-adapter / resource-telemetry services. (#3217, #3071, #3072, #3073)
  • Per-role, heterogeneous-model sub-agent routing — sub-agents can be assigned a model and provider per role (e.g. scout vs. synthesis; verifiers route to a fast model). (#2027, #1768)
  • Durable goal mode — cross-turn goal progress with token/time accounting and a verifier-as-judge gate before a goal may complete. (#3215, #891, #1976, #2058, #2029)
  • Parent-visible worker interaction contract — a recommended action per worker. (#3226)
  • Maintainer GitHub workflow skills; ACP registry submission prepared. (#3192)
  • OpenAI-compatible /v1/chat/completions endpoint on the legacy app-server HTTP transport, provider-neutral, with model registry resolution and configured-credential forwarding.

Changed

  • Sub-agents converge toward fleet-style durable workers — real worker lifecycle states are projected to the sidebar instead of a hardcoded "running", and a sub-agent returns a structured needs-input checkpoint instead of parking. (#3226, #3096, #3154)
  • The per-turn runtime tag exposes capability posture instead of human-facing mode labels. (#3213)
  • Independent shell and verifier work defaults to background jobs with nonblocking waits and a completion notification; blocking now requires an explicit wait. (#3212)
  • Sub-agent launches now expose explicit model_strength and thinking controls to the model instead of hidden child-model auto-routing; explore work is documented as a good fit for faster models and thinking: "off".
  • Plan mode is strictly read-only (no shell tools), consistent with its runtime posture.
  • /swarm is gated behind the durable worker substrate. (#3218)
  • Legacy deepseek install/update path resolves to codewhale. (#2960, #2924, #2917)

Fixed

  • TUI freeze when multiple sub-agents spawn (launch blocker) — the terminal input pump runs off the render thread, AgentProgress events are coalesced, and sub-agents no longer park on input with no orchestrator to answer; a six-worker stress test guards input/render/cancel liveness. (#3216, #3096)
  • Idle sub-agent completion notifications now resume the parent turn instead of waiting for a later user message; thanks @giovanni-paolilla for the deadlock report (#3266).
  • Provider/model route isolation — provider and model state is session-local, and a mismatched provider+model tuple is rejected at the route boundary. (#3227)
  • Route-effective context-window metadata, over-limit preflight, and bounded recovery from context_length_exceeded instead of re-looping. (#3204)
  • Synchronous tools (file_search, grep_files, list_dir) are cancellable and no longer hold a turn open against cancellation. (#1791)
  • MCP stdio proxy startup prompts no longer strand YOLO / non-interactive runs. (#2475)
  • Stalled / failed background-shell recovery; configurable sub-agent API timeout. (#1737, #1786, #1806)
  • Composer: reliable queued steering + Ctrl+S send (#3203, #3224); footer busy/idle indicator (#2982); CJK word-wrap (#963); clickable sidebar stop targets (#3028); live token throughput (#3190); auto-expiring terminal sub-agent cards (#3078).
  • Linux glibc preflight in the installer/update path with a clear error. (#3207, #1067)
  • Self-update retries transient GitHub metadata/asset failures and falls back from the GitHub REST API to the public releases/latest redirect before constructing release asset URLs. (#3232)
  • Provider picker lists providers in neutral alphabetical order instead of hard-coding DeepSeek first; the active provider stays pre-selected. (#3076)
  • Work sidebar no longer shows stale phase now: / phase next: strategy rows once the checklist is 100% complete.
  • Plan mode no longer shortcuts investigation for requests that name a repository, URL, version, release, build state, benchmark, bug, PR, issue, API surface, or local code path.
  • Oversized pasted text stays editable in the composer, with a file backup appended at submit time for model access; thanks @idling11 (#3267, closes #3263).
  • Bare digit keys 1-8 now insert text instead of firing hotbar slots; use Alt+digit for hotbar actions. Thanks @wjq2026 for the report and @DieMoe233 for the paste-path note (#3243).
  • Kimi/Moonshot tool schemas normalize empty function parameters to a root object schema; thanks @jghwwnq for the provider repro (#3265).
  • Novita defaults to its OpenAI-compatible /openai/v1 endpoint so chat completions no longer 404 out of the box; thanks @buko for the report and endpoint verification (#3255).
  • Dependency security: ws pinned to 8.21.0 across npm packages to close remote memory-exhaustion DoS (dependabot).
