Codewal v0.9.10

Codewhale ist das öffentliche Produkt von Shannon Labs. Der codewhale Befehls-, NPM-Paket- und Release-Asset-Namen bleiben technisch in Kleinbuchstaben geschrieben Identifikatoren. Das alte NPM-Paket deepseek-tui ist veraltet und erhält keine weiteren Veröffentlichungen. Benutzer aus v0.8.x Legacy deepseek / deepseek-tui-Namen sollten mit docs/REBRAND.md migriert werden.

Installieren

Empfohlen – npm (ein Befehl, beide Einstiegspunkte)

npm install -g codewhale

Der Wrapper lädt die übereinstimmenden Befehlsressourcen codewhale und codew herunter aus dieser Version. Beide enthalten die gleiche kompilierte Laufzeit.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.10

Das Bild stellt die gleiche Laufzeit bereit wie codewhale und codew. Die Das latest-Tag wird bei der Veröffentlichung ebenfalls aktualisiert.

Fracht (Linux / macOS)

cargo install codewhale-cli --locked

Das Cargo-Paket installiert codewhale. Cargo kann keinen zweiten Befehl erstellen Alias von einem binären Ziel; Benutzer, die die kürzere Schreibweise wünschen, können a hinzufügen codew-Symlink zu der installierten ausführbaren Datei. Das npm, Homebrew, Archiv, Shell-Installer und Containerkanäle installieren beide Befehlsnamen direkt.

Manueller Download – Plattformarchive (empfohlen)

Jedes unten aufgeführte Archiv enthält dieselbe Laufzeit unter codewhale und codew-Befehlsnamen sowie ein Installationsskript:

Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Führen Sie für den Installationspfad CodeWhaleSetup.exe aus. es wird installiert codewhale.exe, codew.exe und codewhale.bat unten %LOCALAPPDATA%\Programs\CodeWhale\bin, fügt dieses Verzeichnis dem hinzu PFAD des aktuellen Benutzers und erstellt eine Startmenü-Verknüpfung, die bevorzugt wird Windows Terminal (wt.exe) bei der Installation.
  • Extrahieren Sie das Archiv für Ihren Computer: codewhale-windows-x64.zip oder codewhale-windows-arm64.zip
  • Double-click codewhale.bat (nicht das rohe .exe) zum Starten
  • Führen Sie install.bat aus, um die Binärdateien und den Launcher nach %USERPROFILE%\bin zu kopieren
  • Fügen Sie %USERPROFILE%\bin zu Ihrem PATH hinzu

Das tragbare Windows-Archiv überspringt das Installationsskript – extrahieren Sie codewhale.bat und führen Sie es aus einem beliebigen Verzeichnis aus. Das NSIS-Installationsprogramm ist derzeit nicht signiert und löst möglicherweise Windows SmartScreen aus, bis ein Signaturzertifikat in die Release-Pipeline eingebunden wird.

Jede Plattform verfügt außerdem über nackte, nicht archivierte codewhale-<platform> und codew-<platform>-Vermögenswerte. Die sieben codewhale-tui-<platform>-Dateinamen An v0.9.5 angehängt sind byteidentische Kompatibilitätskopien, die nur zum Verlassen verwendet werden Bereits installierte v0.9.4 clients entdecken und überqueren diese einzelne Binärdatei Übergang; Aktuelle Installationsprogramme stellen keine dritte Laufzeit zur Verfügung. Das alte npm Paket deepseek-tui ist veraltet und wird nicht erneut veröffentlicht. Für Migration aus v0.8.x-Legacy-Binärnamen, siehe docs/REBRAND.md.

Was ist in v0.9.10

– Zeigt den vollständigen Schrägstrich-Befehl oder die /model-Vervollständigungszeile in einem begrenzten, umschließenden Hover-Popover an, wann immer schmale Terminals ihn abschneiden, wodurch die verbleibende bereichsbezogene Lücke von #998 geschlossen wird. Vielen Dank an @AiurArtanis und @formp3 für die Identifizierung der betroffenen Oberflächen. – registry_sync liefert nicht mehr den vollständigen MCP-Registrierungskatalog in die Gespräch. Es nimmt eine erforderliche Abfrage entgegen und bewertet den lokalen Snapshot Gastgeberseite und bringt höchstens acht Spiele zurück; Der Gesamtkatalog bleibt bestehen Festplatte und die Komprimierungs- und Spillover-Ausnahmen, die es einem Multi-Hundert ermöglichen, Kilobyte-Dumps, die das Modell unverändert erreichen, sind verschwunden. – Anbieter, die den ausgehenden (reasoning omitted)-Replay-Platzhalter widerspiegeln Zurück als Argumentationsdelta wird dieses Echo nicht mehr als real aufgenommen Denken Sie: Der genaue Transportplatzhalter wird bei der Ankunft gelöscht, also leben Sie Sitzungen zeigen keinen Strom von Platzhalter-Argumentationsblöcken mehr an und werden gespeichert Transkripte bleiben davon frei.

  • Verbindungsabbrüche in der Mitte des Streams während einer interaktiven Runde bleiben nicht mehr bestehen synthetische [runtime]-Benutzernachricht. Der Wiederholungsstatus ist ein typisierter Engine-interner Wert Deskriptor; Ein Drop nur zum Denken stellt die Anfrage erneut aus, ohne a zu beanspruchen Teilantwort wurde beibehalten, das Wiederholungsbudget wird im Mechanismus erzwungen und Die Wiederherstellung liefert genau eine verbindliche endgültige Antwort.

Codewhale v0.9.10 ist eine Version zur Aufbewahrung, Identität und Produktklarheit: die Shell und Das Transkript kann keine unbegrenzte Werkzeugausgabe mehr im Speicher oder auf der Festplatte behalten. Mid-Turn-History-Einsätze strangieren nicht länger In-Flight-Tool-Reihen, jeder Agent der diese Sitzung ausgeführt hat, ist aus /agents list, der PTY-Akzeptanz, ersichtlich Lane verfügt über einen Stall-Watchdog und begrenzte CI-Schritte, Genehmigungsergebnisse sind vorhanden dauerhaft und fehlgeschlagen geschlossen (cyq1017, #5360) und drei $HOME-Festplattenlecks sind vorhanden zurückgewonnen. Erweiterungsflächen benennen jetzt ihren tatsächlichen Zustand und wirken nur noch durch die überprüften Installations- und trust-Flows sowie Subagent, Shell, Task, und der Workflow-Status gehört der Sitzung, die ihn erstellt hat (#5518). Testen Threads erhalten einen 8-MiB-Stack, sodass die Lib-Suite dies nicht mehr kann Abbruch unter Last.

Behoben

  • Der erste Durchlauf startet erneut auf dem Begrüßungsbildschirm. Ein fehlender Schlüssel gehört nicht mehr dazu überspringt die Begrüßung und öffnet automatisch die Liste der lokalen Anbieter: Geben Sie Spaziergänge zum ein Ruhige Anbietererklärung, dann öffnet Enter den Picker, also eine erste API-Taste eingestellt werden kann. Durch die Rückgabe der Wiederherstellung fehlender Schlüssel wird weiterhin die Auswahl geöffnet starten.
  • Ein im Vordergrund stehender bash-Befehl mit der Bezeichnung „Kein Timeout“ ist erneut begrenzt. Die Das modellseitige bash-Werkzeug hinterließ im Inneren einen ausgelassenen timeout_ms Obergrenze (~24.8 Tage) anstelle der 120 s standardmäßig ein eigenes Schema wirbt, also ein CLI, der bei einer interaktiven Eingabeaufforderung blockiert oder eingehängt wurde Der Netzwerkanruf hielt die Runde auf unbestimmte Zeit offen – ein Bericht blieb auf einem einzigen unauthentifizierter CLI-Anruf für über zwei Stunden mit der Werkzeugreihe einfach Sekunden zählen. Es gilt nun die angekündigte Standardeinstellung, die das aktiviert Vorhandene Wiederherstellung: Der Prozess wird abgebrochen und das Modell wird angewiesen, erneut auszuführen mit background=true und Umfrage mit action="wait". Ein explizites timeout_ms wird immer noch für seine wirklich lange Arbeit im Vordergrund geehrt Hintergrund- und interaktive Läufe behalten ihre eigene Lebensdauer. – Der Erweiterungs-Marktplatz (/plugin) ist keine schreibgeschützte Liste mehr. Jede Empfehlung und jeder gespeicherte Kandidat benennt seinen wahrheitsgemäßen Zustand und primäre Aktion – Hinzufügen, Aktivieren, Konfiguriert oder Nicht verfügbar – und Enter oder a Die Maus click führt diese Aktion über das vorhandene überprüfte „/mcp add“ aus Empfohlen, /mcp enable, and /plugininstall/trust Controller, also Es existiert kein zweiter trust-Pfad. Browsernutzung und Sandbox-Laufzeit bleiben bestehen Ehrlich gesagt nicht verfügbar mit ihrem echten Setup-Routing, anstatt eine zu implizieren Codewhale kann nicht installiert werden. – Die MCP-Registerkarte „Erweiterungen“ zeigt jetzt ein ehrliches Inventar an: die Header-Anzahl und die sichtbaren Zeilen stammen aus demselben konfigurierten Serversatz, alsoMCP (6)` kann nicht mehr über zwei gerenderten Zeilen liegen. Deaktivierte Server Bleiben Sie sichtbar und als deaktiviert gekennzeichnet, anstatt stillschweigend zu verschwinden, und Konfigurierte Server fehlen in der Live-Snapshot-Liste und werden als noch nicht überprüft angezeigt mit ihrer eigenen expliziten Neulademöglichkeit über den MCP-Befehl Controller.
  • Installierte Plugin-Zeilen wirken sich jetzt auf ihren tatsächlichen Zustand aus: Enter öffnet ein aktives Bundle (/plugin show), bietet Aktivieren für ein trusted-aber-deaktiviertes Bundle, oder leitet ein untrusted-Bundle an die vorhandene trust-Überprüfung weiter – über die Dieselben Bestätigungs- und Persistenz-Controller wie die Slash-Befehle.
  • Übergaben und Dienstpläne von Subagenten, Shell-Jobs im Hintergrund, dauerhafte Aufgaben, verzögerte Fortsetzungen und Workflow-Kontrollen sind jetzt auf die beschränkt Sitzung, der sie gehören. Datensätze tragen unveränderlichen Besitz der Root-Sitzung, Veraltete Completion-Channel-Payloads werden vor der Deduplizierung abgelehnt. Hintergrundarbeit wird nur an die Eigentümersitzung weitergeleitet und gemeldet, und Ältere, eigentümerlose Jobs schlagen fehl, geschlossen zu werden (Fehlerklasse Nr. 5518, gemeldet von @hxfhd; Die genaue Herkunft des Berichts JavaScript wurde nicht angegeben reproduziert). – Der aufgelöste Routenumschlag erreicht jetzt jeden ausgehenden Modellaufruf: alle Drahtdialekte und Hilfsrufe klemmen an der gemeinsamen Transportnaht Im Rahmen eines Überweisungs-/Reservierungsbudgets werden die Eingabegrenzen der Anbieter berücksichtigt Beim Wechseln von Modellen auf demselben Protokoll wird das vorherige nicht mehr geerbt Grenzen des Modells (#5516, #5518).
  • Erstmalige Kontinuität: Der ausgewählte Onboarding-Anbieter bleibt bestehen startet neu, eine fehlende Erstkonfiguration unterbricht den Fluss nicht mehr und Der automatische Prüfpunkt für die Arbeitsvereinbarung wird als eigenständiges Setup gerendert Übergabe, anstatt die Onboarding-Schiene auf die des vollständigen Assistenten zurückzusetzen 4/10 Fortschritt. – Explizit formulierte /goal-Deklarationen in natürlicher Sprache erstellen jetzt eine dauerhaftes Ziel in der anbieterneutralen Engine vor dem Modellversand, während Gewöhnliche Aufgaben und zitierte Transkripte bleiben fern von Zielvorgaben und Prosa Anerkennung allein kann nicht mehr als Ersatz für die Schaffung von Zielen dienen.
  • /model hält jetzt den aktuellen Z.ai-Standard (GLM-5.3) sichtbar, wenn ein Bei älteren Installationen ist eine explizite GLM-5.2-Route gespeichert. Der gespeicherte 5.2 Route bleibt exakt; Wenn Sie 5.3 wählen, wird die eindeutige 5.3-ID gesendet und gespeichert.
  • Der Verfassungskontrollpunkt führt nun mit der gebündelten ausgewogenen Einigung; Der Standardpfad schreibt keine benutzerdefinierte Verfassung. Die Startoberfläche des Startups unterscheidet schreibgeschützten Chat von ordnergebundener, genehmigungsgeschützter Arbeit. – Tabby und andere IME-Brücken beobachten kein veraltetes sichtbares Caretzeichen mehr, während a Rahmendifferenzial wird lackiert; Codewhale verbirgt den Cursor während des Diffs, stellt die kanonische Composer-Zelle wieder her und gibt sie erst dann wieder frei (BrathonBai, #5023). – HTTP/2/SSE-Transportfehler vor dem Header führen zu einem begrenzten HTTP/1.1-Wiederholungsversuch. Authentifizierung, Anbietersemantik, Antworttext und bereits angeheftetes HTTP/1 Fehler bleiben bei Fehlern geschlossen (demian-welt, #4683).
  • MCP tools/call-Bilder werden jetzt als begrenzter typisierter Inhalt übertragen statt Base64 leckt durch modellsichtbares JSON. Direkte und parallele Anrufe teilen sich das gleiche MIME, die gleiche Größe, die gleiche Validierung und die Ein-Bild-Grenze (PR #5515 von @cacdcaecawae).
  • Linux npm-Installationen und -Updates konkurrieren mit den GitHub-Releases mit dem CNB-Spiegel auf der Prüfsummen-Manifest-Ebene, dann von der ersten verifizierten Quelle herunterladen ohne dass Benutzer eine zum Scheitern verurteilte Zeitüberschreitung bei langsamer Quelle abwarten müssen. – CODEWHALE_PREFER_BWRAP wendet jetzt die dokumentierte Linux-Sandbox-Überschreibung an, und Codewhale-Ära benennt eigene Build-Metadaten, Hook-Sitzungs-/Tool-Aufruf-IDs und Untergeordnete Sandbox-Marker. Die entsprechenden DEEPSEEK_*-Namen bleiben als 0.9.x erhalten Kompatibilitätsaliase (#5443).
  • Windows-Standardstart bevorzugt Windows-Terminal: ZIP-Archive werden ausgeliefert codewhale.bat (CRLF, wt.exe, dann die Exe), install.bat kopiert das Launcher, und die NSIS-Startmenü-Verknüpfung öffnet es anstelle des Rohformats binär (#1854).

Codewhale v0.9.10

Highlights

  • Rebrand and migration path — deepseek-tui is deprecated and gets no further releases; v0.8.x deepseek/deepseek-tui users must follow docs/REBRAND.md, while DEEPSEEK_* env names survive only as 0.9.x compatibility aliases beside the new Codewhale-owned identifiers for build metadata, hook session/tool-call IDs, and sandbox markers (#5443). npm install -g codewhale now wires both codewhale and codew; Cargo installs only codewhale, so add a codew symlink yourself. Watch out: the Windows NSIS installer is unsigned and trips SmartScreen until signing lands.

  • registry_sync is now query-scoped (breaking) — the tool requires a query, scores the on-disk snapshot host-side, and returns at most eight matches instead of shipping the full MCP Registry catalog into the conversation; the compaction/spillover exemptions that let a multi-hundred-kilobyte dump reach the model unchanged are gone. Anything automating against the full catalog will break — rework it around queries, in exchange for a much smaller context footprint.

  • Foreground bash timeout finally matches its schema — an omitted timeout_ms was left at the internal ceiling (~24.8 days) rather than the advertised 120 s, so a CLI hanging on an interactive prompt or unauthenticated call could hold a turn open for hours. The 120 s default now applies and arms the existing recovery (kill the process, rerun with background=true, poll via action="wait"); an explicit timeout_ms is still honored. Long foreground work that relied on the old bug must now set an explicit timeout.

  • Bounded tool-output retention (#5472) — raw streams cap at 16 MiB in flight and release delivered output, and retained tool output is capped at 64 KiB per record / 8 MiB per transcript, fixing cases where a 1.1 MB Bash call stayed resident for over an hour; the three $HOME disk leaks (orphaned session dirs, unbounded audit.log, stranded writer temp files) are also reclaimed. Expect real ceilings now — oversized outputs are truncated in transcripts by design.

  • Session-scoped state and fail-closed approvals (#5518, #5360) — sub-agent handoffs, background shell jobs, durable tasks, delayed continuations, and workflow controls now carry immutable root-session ownership, stale completion-channel payloads are rejected before dedup, and legacy ownerless jobs fail closed; approval receipts are committed to a session-owned log before execution, so unpersistable evidence blocks the tool and resume reconstructs closed/interrupted approvals. This kills multi-session cross-talk but means any persisted state without an owner will stop working.

  • Transport and model-call hardening (#5516, #5518, #4683, #5515) — the resolved route envelope now reaches every outbound call under one wire/reservation budget with provider input limits honored, and switching models on the same protocol no longer inherits the previous model's limits; pre-header HTTP/2/SSE failures get one bounded HTTP/1.1 retry while auth/provider-semantic failures stay fail-closed; mirrored (reasoning omitted) placeholders are dropped instead of being ingested as real thinking, mid-stream drops yield exactly one authoritative final answer without a synthetic [runtime] message, and MCP tools/call images travel as bounded typed content rather than base64 in model-visible JSON.

Codewhale is the public product from Shannon Labs. The codewhale command, npm package, and release-asset names remain lowercase technical identifiers. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

What's in v0.9.10

  • Show the full slash-command or /model completion row in a bounded, wrapping hover popover whenever narrow terminals truncate it, closing the remaining scoped gap from #998. Thanks @AiurArtanis and @formp3 for identifying the affected surfaces.
  • registry_sync no longer ships the full MCP Registry catalog into the conversation. It takes a required query, scores the local snapshot host-side, and returns at most eight matches; the complete catalog stays on disk, and the compaction and spillover exemptions that let a multi-hundred- kilobyte dump reach the model unchanged are gone.
  • Providers that mirror the outgoing (reasoning omitted) replay placeholder back as a reasoning delta no longer have that echo ingested as real thinking: the exact transport placeholder is dropped on arrival, so live sessions stop showing a stream of placeholder reasoning blocks and saved transcripts stay free of them.
  • Mid-stream connection drops during an interactive turn no longer persist a synthetic [runtime] user message. Retry state is a typed engine-internal descriptor; a thinking-only drop re-issues the request without claiming a partial reply was preserved, the retry budget is enforced in mechanism, and recovery produces exactly one authoritative final answer.

Codewhale v0.9.10 is a retention, identity, and product-clarity release: the shell and transcript can no longer retain unbounded tool output in memory or on disk, mid-turn history inserts no longer strand in-flight tool rows, every agent that ran this session is visible from /agents list, the PTY acceptance lane has a stall watchdog and bounded CI steps, approval outcomes are durable and fail closed (cyq1017, #5360), and three $HOME disk leaks are reclaimed. Extension surfaces now name their real state and act only through the reviewed install and trust flows, and sub-agent, shell, task, and workflow state is owned by the session that created it (#5518). Test threads get an 8 MiB stack so the lib suite can no longer abort under load.
