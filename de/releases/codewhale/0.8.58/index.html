Codewal v0.8.58

CodeWhale ist das kanonische Projekt, der Befehl, das NPM-Paket und Name des Release-Assets. Das alte NPM-Paket deepseek-tui ist veraltet und erhält keine weiteren Veröffentlichungen. Benutzer kommen aus Die alten v0.8.x-Namen deepseek/deepseek-tui sollten migriert werden mit docs/REBRAND.md.

Installieren

Empfohlen – npm (ein Befehl, beide Binärdateien)

npm install -g codewhale

Der Wrapper lädt beide Binärdateien aus dieser Version herunter und legt sie im selben Verzeichnis ab.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.58

Das Image enthält den codewhale-Dispatcher und die codewhale-tui-Laufzeit. Das latest-Tag wird bei der Veröffentlichung ebenfalls aktualisiert.

Fracht (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Beide Kisten sind erforderlich – codewhale-cli erzeugt den codewhale-Dispatcher und codewhale-tui erzeugt die interaktive Laufzeit, an die der Dispatcher delegiert. Die Installation nur einer Binärdatei schlägt zur Laufzeit mit dem Fehler MISSING_COMPANION_BINARY fehl.

Manueller Download – Plattformarchive (empfohlen)

Jedes der folgenden Archive enthält sowohl den codewhale-Dispatcher als auch die codewhale-tui-Laufzeitumgebung sowie ein Installationsskript: | Plattform | Archiv | Skript installieren | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (Installer) | CodeWhaleSetup.exe | NSIS-Setup | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (tragbar) | codewhale-windows-x64-portable.zip | — | Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Führen Sie für den Installationspfad CodeWhaleSetup.exe aus. Es installiert beide Binärdateien unter %LOCALAPPDATA%\Programs\CodeWhale\bin und fügt dieses Verzeichnis dem PATH des aktuellen Benutzers hinzu.
  • Extrahieren Sie codewhale-windows-x64.zip
  • Führen Sie install.bat aus (kopiert nach %USERPROFILE%\bin)
  • Fügen Sie %USERPROFILE%\bin zu Ihrem PATH hinzu Das tragbare Windows-Archiv überspringt das Installationsskript – extrahieren Sie es und führen Sie es aus einem beliebigen Verzeichnis aus. Das NSIS-Installationsprogramm ist derzeit nicht signiert und löst möglicherweise Windows SmartScreen aus, bis ein Signaturzertifikat in die Release-Pipeline eingebunden wird. Nachfolgend sind auch einzelne Binärdateien für die Skripterstellung und den NPM-Wrapper angehängt. Das alte NPM-Paket deepseek-tui ist veraltet und wird nicht erneut veröffentlicht. Informationen zur Migration von v0.8.x-Legacy-Binärnamen finden Sie unter docs/REBRAND.md.

sha256sum -c codewhale-bundles-sha256.txt

Was ist in v0.8.58

Hinzugefügt

  • Native Anthropic-Anbieter. Ein dedizierter Messages API-Adapter (/v1/messages mit x-api-key-Authentifizierung) ersetzt OpenAI-Dialekt-Shims für Claude-Modelle: Adaptives Denken mit output_config.effort shaping, Prompt-Cache-Haltepunkte (begrenzt auf 4, frühestens gelöscht), signiertes Denken Wiedergabe über signature_delta, normalisierte Cache-Hit/Miss-Nutzungstelemetrie, und SSE-Fehlerumschläge. claude-opus-4-8, claude-sonnet-4-6 und claude-haiku-4-5 der Modellregistrierung beitreten; konfigurieren mit ANTHROPIC_API_KEY (#3014).
  • Hooks v2. tool_call_before-Hooks können jetzt eine JSON-Entscheidung zurückgeben — {"Entscheidung": "Erlauben"|"Verweigern"|"Fragen", "Grund", "updatedInput", „additionalContext“} – mit deny > ask > Vorrang über mehrere hinweg zulassen Hooks, Last-Writer-Wins-Eingabeumschreibung und verketteter Kontext. Ausstieg Code 2 bleibt ein Vermächtnis, das schwer zu leugnen ist. Haken unterstützen Glob-Matcher und Projektlokal .codewhale/hooks.toml (#3026).
  • Clickable-Seitenleiste. Hintergrundjobzeilen werden auf click angezeigt/abgebrochen Strg+K-Hinweiszeile führt /jobs cancel-all aus und Agentenzeilen öffnen /subagents; Zeilenaktionen werden im selben Durchgang wie die gerenderten Zeilen erstellt, also ein click kann niemals den falschen Job anvisieren (#3028).
  • OSC 8 Out-of-Band-Hyperlink-Infrastruktur mit regionalem Öffnen/Schließen Sequenzen, die teilweise Neuzeichnungen überleben (#3029).
  • codewhale exec gewinnt --allowed-tools, --disallowed-tools (Siege verweigern), --max-turns und --append-system-prompt (#3027).
  • Verfassungs-Eingabeaufforderungsquelle: YAML-Quelle der Wahrheit plus Python-Renderer für Die Systemeingabeaufforderung, wobei die aktive Eingabeaufforderung jetzt von bedient wird constitution.md (#3015, Renderer-Abgleich wird weiterhin verfolgt).
  • Vorlage, Etiketten und Läuferprotokoll für Agentenaufgaben (#3021); entfernt Rauchtest-Tröpfchenschleifenhärtung – gh CLI, Auslagerungsdatei, Agentensitzungen (#3022).

Geändert

  • Subagenten-Routing ist anbieterabhängig. DeepSeek-IDs sind nicht mehr vorhanden fest in die Modellvalidierung einprogrammiert; Routing funktioniert pro Anbieter Große/billige Kandidaten, der Netzwerk-Router wird bei einem Anbieter übersprungen Keine billige Stufe, und Anfragen nach Spawn-Zeitmodellen werden anhand der validiert aktiver Anbieter (#3018).
  • Modellspezifische Fakten im System-Prompt (Kontextfenster, Subagent). Preisgestaltung, Denknotizen, Architekturmerkmale) sind jetzt als Vorlagen verfügbar pro Modell statt fest codierter DeepSeek V4-Ansprüche, sowohl in base.md als auch constitution.md (#3025).
  • Anbieterfähigkeitssuchen für Moonshot/OpenAI/Atlascloud werden aufgelöst von Registrierungszeilen pro Modell (nackte IDs und IDs mit Herstellerpräfix) anstelle von hartcodierte Böden aus der 64K-Ära (#3023).
  • Reasoning-Effort erreicht jetzt Atlascloud (DeepSeek-Dialekt), Moonshot (thinking aktivieren/deaktivieren) und Ollama (think-Parameter) (#3024); Mondschuss/ Kimi-Modelle traten dem Reasoning-Content-Anbieter und Model Gates bei (#3016).
  • Transkriptpolitur: kompakte Tool-Call-Zellen ohne Boilerplate (#3031), Interne Turn-/Agenten-IDs werden hinter stabilen Beschriftungen versteckt (#3030) und Strg+B Stellt jetzt die laufende Vordergrund-Shell direkt in den Hintergrund, anstatt sie zu öffnen ein Menü (#3032).
  • Die Aufgaben-Seitenleiste trennt „Modellbegründung“ von „Hintergrundbefehlen“, und auth list meldet die gleiche aktive Anmeldeinformationsquelle wie auth status für openai-codex.

Behoben

  • TUI friert unter Subagentenlast ein. Rapid AgentProgress-Ereignisse die Renderschleife ist gesättigt und die Terminaleingabe ist ausgehungert; Fortschrittsorientiert Neulackierungen werden jetzt auf einen pro 100 ms gedrosselt (#3033).
  • Hooks unter Windows. Hook-Befehle wurden an cmd /C weitergeleitet Argumentanführung im CRT-Stil, die literale \"-Sequenzen einfügt cmd.exe entkommt nie – JSON-Entscheidungen konnten nicht analysiert werden. Befehle jetzt Erreichen Sie cmd.exe wörtlich über raw_arg.
  • Codex-Antworten: Ergebnisse des Assistententools werden konvertiert function_call_output-Artikel (Multi-Turn-Werkzeugaufruf, zuvor kaputt), Tool-Schemata werden für die Antworten API und maximum bereinigt Karten zu xhigh (#3019, #3017 – beide teilweise; erneut versuchen/backoff und Der strikte Modus pro Werkzeug bleibt geöffnet). – Bessere Tool-Ablehnungs- und Anbieter-Fehlermeldungen aus PR #2933 (#3020). Die Mitwirkenden für diese Veröffentlichung finden Sie im obigen changelog-Eintrag – Vielen Dank an alle, deren Berichte, PRs, Rezensionen und Reproduktionen es geprägt haben. Vollständige Hinweise finden Sie unter CHANGELOG.md und unter docs/CHANGELOG_ARCHIVE.md für ältere Versionen.

Englisches Original / English original

Codewhale v0.8.58

Highlights

  • Breaking rename and install migration — CodeWhale is now the canonical command, npm package, and release-asset name. deepseek-tui is deprecated, receives no further releases, and is not republished; users of legacy v0.8.x names should follow docs/REBRAND.md. Cargo and manual installations must include both codewhale and codewhale-tui, or runtime fails with MISSING_COMPANION_BINARY.
  • Native Anthropic provider (#3014) — Claude models now use a dedicated /v1/messages adapter with x-api-key authentication instead of an OpenAI-dialect shim. It adds adaptive thinking via output_config.effort, signature_delta replay, up to four prompt-cache breakpoints, normalized usage telemetry, and SSE error handling. Configure ANTHROPIC_API_KEY; claude-opus-4-8, claude-sonnet-4-6, and claude-haiku-4-5 are registered.
  • Hooks v2 and tool controls (#3026, #3027) — tool_call_before hooks can return allow, deny, or ask decisions with input rewrites and additional context. Deny beats ask, ask beats allow, input uses last-writer-wins, and contexts concatenate. Glob matching and project-local .codewhale/hooks.toml are supported; exit code 2 remains a legacy hard deny. codewhale exec also gains --allowed-tools, --disallowed-tools (deny wins), --max-turns, and --append-system-prompt.
  • Provider-aware routing and reasoning (#3016, #3018, #3023–#3025) — Hardcoded DeepSeek model assumptions and 64K-era capability floors are replaced by per-provider candidates and per-model registry data. Spawn-time requests are validated against the active provider, prompt facts are model-templated, and reasoning effort now reaches Atlascloud, Moonshot, and Ollama. This materially improves reliability for non-DeepSeek model users.
  • Upgrade recommendation — Worth upgrading for Claude users, hook-based automation, Codex Responses multi-turn tool calling, or heavy sub-agent workloads: this release fixes Codex function_call_output conversion and throttles TUI progress repaints to 100ms to prevent input starvation. It also fixes Windows hook quoting via raw_arg, adds clickable sidebar actions, and makes Ctrl+B background the foreground shell directly. Stable DeepSeek-only workflows can skip. Note that Codex retry/backoff and per-tool strict mode remain unfinished, and CodeWhaleSetup.exe is still unsigned.

CodeWhale is the canonical project, command, npm package, and release-asset name. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Install

Recommended — npm (one command, both binaries)

npm install -g codewhale

The wrapper downloads both binaries from this Release and places them in the same directory.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.58

The image ships the codewhale dispatcher and codewhale-tui runtime. The latest tag is also updated on release.

Cargo (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Both crates are required — codewhale-cli produces the codewhale dispatcher and codewhale-tui produces the interactive runtime that the dispatcher delegates to. Installing only one binary will fail at runtime with a MISSING_COMPANION_BINARY error.

Manual download — platform archives (recommended)

Each archive below contains both the codewhale dispatcher and codewhale-tui runtime, plus an install script:

| Platform | Archive | Install script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (installer) | CodeWhaleSetup.exe | NSIS setup | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portable) | codewhale-windows-x64-portable.zip | — |

Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • For the installer path, run CodeWhaleSetup.exe; it installs both binaries under %LOCALAPPDATA%\Programs\CodeWhale\bin and adds that directory to the current-user PATH.
  • Extract codewhale-windows-x64.zip
  • Run install.bat (copies to %USERPROFILE%\bin)
  • Add %USERPROFILE%\bin to your PATH

The portable Windows archive skips the install script — extract and run from any directory. The NSIS installer is currently unsigned and may trigger Windows SmartScreen until a signing certificate is wired into the release pipeline.

Individual binaries are also attached below for scripting and the npm wrapper. The legacy npm package deepseek-tui is deprecated and is not republished. For migration from v0.8.x legacy binary names, see docs/REBRAND.md.

What's in v0.8.58

Added

  • Native Anthropic provider. A dedicated Messages API adapter (/v1/messages with x-api-key auth) replaces OpenAI-dialect shims for Claude models: adaptive thinking with output_config.effort shaping, prompt-cache breakpoints (capped at 4, earliest dropped), signed-thinking replay via signature_delta, normalized cache-hit/miss usage telemetry, and SSE error envelopes. claude-opus-4-8, claude-sonnet-4-6, and claude-haiku-4-5 join the model registry; configure with ANTHROPIC_API_KEY (#3014).
  • Hooks v2. tool_call_before hooks can now return a JSON decision — {"decision": "allow"|"deny"|"ask", "reason", "updatedInput", "additionalContext"} — with deny > ask > allow precedence across multiple hooks, last-writer-wins input rewriting, and concatenated context. Exit code 2 remains a legacy hard deny. Hooks support glob matchers and project-local .codewhale/hooks.toml (#3026).
  • Clickable sidebar. Background-job rows show/cancel on click, the Ctrl+K hint row runs /jobs cancel-all, and agent rows open /subagents; row actions are built in the same pass as the rendered lines so a click can never target the wrong job (#3028).
  • OSC 8 out-of-band hyperlink infrastructure with per-region open/close sequences that survive partial redraws (#3029).
  • codewhale exec gains --allowed-tools, --disallowed-tools (deny wins), --max-turns, and --append-system-prompt (#3027).
  • Constitution prompt source: YAML source-of-truth plus Python renderer for the system prompt, with the active prompt now served from constitution.md (#3015, renderer reconciliation still tracked).
  • Agent-task issue template, labels, and runner protocol (#3021); remote smoke-test droplet loop hardening — gh CLI, swapfile, agent sessions (#3022).

Changed

  • Sub-agent routing is provider-aware. DeepSeek ids are no longer hardcoded into model validation; routing works from per-provider big/cheap candidates, the network router is skipped when a provider has no cheap tier, and spawn-time model requests are validated against the active provider (#3018).
  • Model-specific facts in the system prompt (context window, sub-agent pricing, thinking notes, architecture characteristics) are now templated per-model instead of hardcoded DeepSeek V4 claims, in both base.md and constitution.md (#3025).
  • Provider capability lookups for Moonshot/OpenAI/Atlascloud resolve from per-model registry rows (bare and vendor-prefixed ids) instead of hardcoded 64K-era floors (#3023).
  • Reasoning-effort now reaches Atlascloud (DeepSeek dialect), Moonshot (thinking enable/disable), and Ollama (think param) (#3024); Moonshot/ Kimi models joined the reasoning-content provider and model gates (#3016).
  • Transcript polish: compact tool-call cells without boilerplate (#3031), internal turn/agent ids hidden behind stable labels (#3030), and Ctrl+B now backgrounds the running foreground shell directly instead of opening a menu (#3032).
  • The Tasks sidebar separates "Model reasoning" from "Background commands", and auth list reports the same active-credential source as auth status for openai-codex.

Fixed

  • TUI freeze under sub-agent load. Rapid AgentProgress events saturated the render loop and starved terminal input; progress-driven repaints are now throttled to one per 100ms (#3033).
  • Hooks on Windows. Hook commands were passed to cmd /C through CRT-style argument quoting, which injected literal \" sequences that cmd.exe never unescapes — JSON decisions could not parse. Commands now reach cmd.exe verbatim via raw_arg.
  • Codex Responses: assistant tool results are converted to function_call_output items (multi-turn tool calling previously broke), tool schemas are sanitized for the Responses API, and maximum effort maps to xhigh (#3019, #3017 — both partially; retry/backoff and per-tool strict mode remain open).
  • Better tool-denial and provider error messages harvested from PR #2933 (#3020).

Contributor credits for this release live in the changelog entry above — thank you to everyone whose reports, PRs, reviews, and reproductions shaped it.

See CHANGELOG.md for full notes and docs/CHANGELOG_ARCHIVE.md for older releases.
