Codewal v0.9.8

Codewhale ist das öffentliche Produkt von Shannon Labs. Der codewhale Befehls-, NPM-Paket- und Release-Asset-Namen bleiben technisch in Kleinbuchstaben geschrieben Identifikatoren. Das alte NPM-Paket deepseek-tui ist veraltet und erhält keine weiteren Veröffentlichungen. Benutzer aus v0.8.x Legacy deepseek / deepseek-tui-Namen sollten mit docs/REBRAND.md migriert werden.

Installieren

Empfohlen – npm (ein Befehl, beide Einstiegspunkte)

npm install -g codewhale

Der Wrapper lädt die übereinstimmenden Befehlsressourcen codewhale und codew herunter aus dieser Version. Beide enthalten die gleiche kompilierte Laufzeit.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.8

Das Image stellt die gleiche Laufzeit bereit wie codewhale und codew. Die Das latest-Tag wird bei der Veröffentlichung ebenfalls aktualisiert.

Fracht (Linux / macOS)

cargo install codewhale-cli --locked

Das Cargo-Paket installiert codewhale. Cargo kann keinen zweiten Befehl erstellen Alias von einem binären Ziel; Benutzer, die die kürzere Schreibweise wünschen, können a hinzufügen codew-Symlink zu der installierten ausführbaren Datei. Das npm, Homebrew, Archiv, Shell-Installer und Containerkanäle installieren beide Befehlsnamen direkt.

Was ist in v0.9.8

Codewhale v0.9.8 liefert das verbleibende zugewiesene Ziel. Verbleibendes Web Die Poliereinstellungen werden auf v0.9.9 verschoben. Vorgefertigte Vorlagen von Drittanbietern, die über Folgendes verfügen ein veröffentlichtes OpenAI-kompatibles Hostschiff hier (#5350).

Behoben

  • sudo (und su/setuid-Helfer) funktionieren wieder für Radgruppenadministratoren Wer möchte, dass Codewhale eskalieren kann: die Härtung des Linux-Startups irreversibles PR_SET_NO_NEW_PRIVS-Flag – wird von jedem untergeordneten Prozess geerbt – ist jetzt mit CODEWHALE_NO_NEW_PRIVS=0 (#5413) überspringbar. Die Flagge bleibt an standardmäßig; Die No-Ptrace- und No-Core-Dump-Maßnahmen werden niemals übersprungen.
  • Prozesstodesfälle der Abort-Klasse vergiften das Terminal nicht mehr (#5424). A Stapelüberlauf, Zuordnungsfehler oder doppelte Panik überspringen den Panik-Hook und jeder Aufräumschutz, so wie der Ausgang eines v0.9.7-Benutzers in der Mitte der Kurve nach links ging Maus fängt SGR-Sequenzen ein und dringt in ihre Hülle ein. Ein Der async-signal-safe-Handler stellt jetzt die Terminalmodi wieder her und hängt a an einzeiliger Ursachenmarker für ~/.codewhale/crashes/last-fatal-signal.log vor dem erneuten Erhöhen den ehrlichen 128+Signal-Wartestatus beibehalten. EIN SIGKILL (OOM-Killer) bleibt konstruktionsbedingt unabfangbar.

Geändert

– Das Prompt-Cache-Präfix ist für die Sitzung angeheftet. Die Werkzeugschleife nicht mehr stellt bei jedem Modellschritt die Systemeingabeaufforderung von der Festplatte neu zusammen, also ein Agent Durch das Schreiben einer Datei wird der KV-Präfix-Cache des Anbieters nicht mehr mitten in der Runde zerstört. Die Systemeingabeaufforderung und Werkzeugkatalog werden nur für einen deklarierten Header neu zusammengestellt Änderung (/model, Modus, Ziel, Sitzungswiederaufnahme), die unter einem protokollierten erneut angeheftet wird Grund; Eine nicht deklarierte Änderung wird als Drift gemeldet, der ursprüngliche Pin jedoch beibehalten, anstatt stillschweigend zur neuen Grundlinie zu werden. Arbeitsbereich, AGENTS.md, Fähigkeiten, Gedächtnis und Zieldrift erreichen das Modell nun als eine einzige Grenze <context_update> Benutzernachricht beim nächsten Benutzerzug – ein Anhängen des Verlaufs, kein Header-Rewrite. /cache stats zeigt den Pin-Grund, den letzten Fehlschlag Grund, die Anzahl der nicht deklarierten Abweichungen und die Anzahl der Kontextaktualisierungen. Siehe docs/CACHE.md.

  • Die Plugin-Kompatibilität erfolgt jetzt pro Komponente. A überprüft, trusted, aktiviert Bundle, das Skills oder MCP mit nicht unterstützten Befehlen, Agenten, Hooks usw. mischt. LSP-, native, Dateisystem-Roots- oder Lifecycle-Mutation-Deklarationen behalten die unterstützte Adapter aktiv und meldet den Rest als inaktiv (full / partial / unsupported). Komplett nicht unterstützte Pakete können immer noch nicht aktiviert werden. Der Capability-Hash ist jetzt v2 und bindet die Aktivierungsrichtlinie dieses Builds Ältere v1-Belege und alle späteren Adapteraktivierungsänderungen schlagen fehl, geschlossen als Bedarfsanalyse. Fertigkeiten und jeder MCP-Transport fordern ihre eigene Fähigkeit erneut an an der Verbrauchsgrenze.

Codewhale v0.9.8

Highlights

  • Session-scoped prompt caching — The system prompt and tool catalog are pinned for the session, preventing edits from invalidating the provider’s KV prefix cache mid-turn. /model, mode, goal, and resume changes deliberately re-pin; undeclared drift preserves the original pin. Workspace, AGENTS.md, skills, memory, and goal changes now arrive as bounded <context_update> messages on the next user turn. Use /cache stats and docs/CACHE.md to diagnose misses.
  • Partially supported plugins can now run — Bundles retain supported Skills and MCP adapters when commands, hooks, LSP, or other declarations are unsupported, with full / partial / unsupported diagnostics. Capability receipts are now v2: existing v1 receipts fail closed as needs-review, so plan for re-review after upgrading. All-unsupported bundles remain disabled.
  • Local federated plugin marketplace — /plugin marketplace add|list|show|remove|install reads local Kimi, Claude, Codex, or native catalog files without network access. Installation still uses the reviewed, fail-closed path; bundles enter disabled and untrusted, and foreign INSTALLED_BY_DEFAULT policies never trigger auto-install or vendor trust.
  • Sub-agents inherit permission posture — Workers now honor the session’s Auto-Review floor and model guardian, surface held calls through the parent approval UI under Ask, and retain the safety floor under Full Access. Prompt-less decisions are audited. Read-only roles still cannot write; custom inherits parent write/network/shell posture except for explicit restrictions.
  • Provider defaults and hosted options changed — Z.ai now defaults to GLM-5.3, while explicit GLM-5.2 selections retain their model IDs; 5.3 inherits 5.2 limits and may return entitlement error 1311 on unprovisioned accounts. Ollama Cloud is available through /provider ollama-cloud with credential isolation from neighboring custom remotes, and Eden AI adds a named provider with EDENAI_API_KEY, global/EU endpoint overrides, and a live catalog.
  • Crash recovery and migration housekeeping — Abort-class failures now restore terminal modes through an async-signal-safe handler, log a cause marker, and preserve signal-based exit status; SIGKILL remains uninterceptable. Separately, the deprecated deepseek-tui npm package will receive no further releases: v0.8.x users should migrate to codewhale using docs/REBRAND.md.

Codewhale is the public product from Shannon Labs. The codewhale command, npm package, and release-asset names remain lowercase technical identifiers. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

What's in v0.9.8

Codewhale v0.9.8 ships the remaining assigned finish. Remaining web settings polish moves to v0.9.9. Prefab third-party templates that have a published OpenAI-compatible host ship here (#5350).

Fixed

  • sudo (and su/setuid helpers) work again for wheel-group administrators who want Codewhale to be able to escalate: the Linux startup hardening's irreversible PR_SET_NO_NEW_PRIVS flag — inherited by every child process — is now skippable with CODEWHALE_NO_NEW_PRIVS=0 (#5413). The flag stays on by default; the no-ptrace and no-core-dump measures are never skipped.

  • Abort-class process deaths no longer poison the terminal (#5424). A stack overflow, allocation failure, or double panic skips the panic hook and every cleanup guard, which is how a v0.9.7 user's mid-turn exit left mouse capture leaking SGR sequences into their shell. An async-signal-safe handler now restores the terminal modes and appends a one-line cause marker to ~/.codewhale/crashes/last-fatal-signal.log before re-raising, keeping the honest 128+signal wait status. A SIGKILL (OOM killer) remains uninterceptable by design.

Changed

  • Prompt-cache prefix is pinned for the session. The tool loop no longer recomposes the system prompt from disk on every model step, so an agent writing a file no longer busts the provider KV prefix cache mid-turn. The system prompt and tool catalog are re-composed only on a declared header change (/model, mode, goal, session resume), which re-pins under a logged reason; an undeclared change is reported as drift and the original pin is kept instead of silently becoming the new baseline. Workspace, AGENTS.md, skills, memory, and goal drift now reaches the model as one bounded <context_update> user message at the next user turn — a history append, not a header rewrite. /cache stats shows the pin reason, the last-miss reason, the undeclared-drift count, and the context-update count. See docs/CACHE.md.

  • Plugin compatibility is now per-component. A reviewed, trusted, enabled bundle that mixes Skills or MCP with unsupported commands, agents, hooks, LSP, native, filesystem-roots, or lifecycle-mutation declarations keeps the supported adapters active and reports the rest as inactive (full / partial / unsupported). All-unsupported bundles still cannot be enabled. The capability hash is now v2 and binds this build's activation policy, so older v1 receipts and any later adapter-enablement change fail closed as needs-review. Skills and each MCP transport re-request their own capability at the consumption boundary.
