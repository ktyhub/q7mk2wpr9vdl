pi v1.0.0

Major Veröffentlicht1. Okt. 2026 Quelleearendil-works/pi Englisches Original

pi v1.0.0

Neue Funktionen

  • Standardmäßig Vollbild – Die TUI läuft jetzt im Vollbildmodus. Setzen Sie tuiMode auf "regular", um den normalen Scrollback des Terminals beizubehalten. Siehe Terminal und Display.
  • Leanerer Codemodus – Etwa 40 % weniger Eingabeaufforderungstoken und Fehler, die dem Modell mitteilen, wie es wiederhergestellt werden soll. Siehe Codemodus.
  • Bildgenerierung im Codemodus – Skripte rufen models.generateImages() mit den Anmeldeinformationen der Sitzung auf. Siehe Bilder generieren und Bildmodelle verwenden.
  • Radius in /login – Melden Sie sich bei Radius an und richten Sie den MCP-Server in einem Schritt ein. Siehe Radius.
  • Anthropic Copy Code Login – Melden Sie sich an, wenn der Browser auf einem anderen Computer ausgeführt wird. Siehe Interaktiv authentifizieren. – MCP OAuth-Härtung – oauth.authServerMetadataUrl, RFC 9207 iss-Prüfungen, Anmeldeinformationen pro Server und Step-up-Anmeldung, die gewährte Bereiche beibehält. Siehe Mit OAuth authentifizieren.
  • Leiser Start nur im Header – quietStartup: "header" behält die Version und wichtige Hinweise und verbirgt den Rest. Siehe Terminal und Display.

Hinzugefügt

– Es wurde eine oauth.authServerMetadataUrl-Einstellung für MCP-Server hinzugefügt, die einen falschen oder keinen OAuth-Autorisierungsserver ankündigen. Pi verwendet das konfigurierte Metadatendokument anstelle der Erkennung (#10172). – quietStartup: "header" hinzugefügt, das den Startup-Header mit Versions- und Schlüsselhinweisen beibehält, aber die Modellbereichszeile und die Liste der geladenen Ressourcen verbirgt.

  • models.generateImages() zu Codemodus-Skripten hinzugefügt. Es führt Image-Modelle wie OpenRouter mit den Anmeldeinformationen der Sitzung aus und gibt Base64-Image-Blöcke zurück, die image() an das Ergebnis anfügt. Die Nutzung wird wie models.classify() auf die Sitzungskosten angerechnet. Erweiterungen können ctx.modelRegistry.generateImages() aufrufen. Siehe Bildmodelle verwenden. – Anthropic /login wurde eine Anmeldemethode zum Kopieren von Codes für Headless-Setups hinzugefügt, bei denen der Browser auf einem anderen Computer ausgeführt wird (#10194 von @lucasmeijer).

Geändert

  • Der Standard-TUI-Modus wurde auf Vollbild geändert. Setzen Sie tuiMode auf "regular" oder übergeben Sie --tui-mode regular, um den normalen Scrollback des Terminals beizubehalten.
  • /login bietet jetzt auf der obersten Ebene als letzte Option mit seinem Status „Mit Radius anmelden“ an. Nach einer Radius-Anmeldung bietet /login an, den Radius MCP-Server im globalen mcp.json mit "auth": { "provider": "radius" } zu konfigurieren und lädt ihn neu. Wenn Sie eine Anmeldung abbrechen, kehren Sie zu dem Menü zurück, von dem aus sie gestartet wurde. – Die Seite mit den Anbieterdokumenten wurde in Anbieter umbenannt, der Abschnitt „Cloud-Anbieter“ lautet jetzt „Anbieterspezifische Konfiguration“ und es wird zuerst Radius dokumentiert. – MCP-OAuth-Anmeldeinformationen werden jetzt pro Servername und URL gespeichert, sodass sich MCP-Server mit derselben URL mit unterschiedlichen Konten anmelden können. Nur über die URL gespeicherte Anmeldeinformationen werden an den ersten Server verschoben, der sie verwendet (#10252).
  • Der Codemodus kostet weitaus weniger Eingabeaufforderungstoken: Wenn die Standardtools und der Codemodus aktiv sind, schrumpft eine GPT-5.6-Anfrage von etwa 5.300 auf 3.300 Token. Die codemode-Beschreibung listet die Skript-Globals jeweils in einer Zeile auf und verweist auf die neue Codemode-Referenz für models API, die das Modell liest, wenn es sie benötigt. Deklarierte Tools sagen in einer Zeile, wie Skripte sie aufrufen und in was der Aufruf aufgelöst wird, anstatt ihre vollständige Deklaration zu wiederholen, und die Codemodus-Anleitung und der MCP-Serverabschnitt der Systemeingabeaufforderung sind kürzer.
  • Codemode-Fehler sagen jetzt, wie die Wiederherstellung erfolgen kann: Das Lesen eines nicht vorhandenen Tools oder models-Mitglieds benennt die nahen Übereinstimmungen (tools.Bash schlägt tools.bash vor), models.classify() und models.generateImages() lehnen fehlerhafte Argumente mit der erwarteten Form ab, ein unbekanntes Modell zeigt auf models.getAvailableOfType(), ein übergroßer store()-Wert erklärt, wozu der Speicher dient, und ein Skript, das Bilder generiert, ohne sie anzuzeigen, erhält eine Notiz. Skripte, die nach einem Werkzeug mit typeof tools.name suchen, müssen "name" in tools verwenden. – /login und /logout kennzeichnen Anbieter ohne Anmeldeinformationen jetzt als „nicht konfiguriert“ statt „unkonfiguriert“.
  • OAuth-Browserseiten zeigen jetzt das farbige Pi-Logo.

Behoben

– Problem behoben, bei dem die MCP-OAuth-Anmeldung eine Autorisierungsantwort akzeptierte, deren Parameter iss einen anderen Autorisierungsserver benennt; Der Code wird nun vor dem Austausch abgelehnt (RFC 9207). – Fehler bei der MCP-OAuth-Anmeldung mit Invalid scope behoben, wenn die Token-Antwort "scope": "" enthält, und ähnliche Fehler für andere leere oder optionale OAuth-Felder null (#10266). – Problem behoben, bei dem die von /mcp login gedruckte Anmelde-URL beim Umbruch nicht cli prüfbar war (#10186).

  • --provider behoben, ohne dass --model stillschweigend ignoriert wurde und das Standardmodell eines anderen Anbieters ausführte; es schlägt jetzt mit einem Fehler fehl (#10236). – Behoben: MCP-Server, die mehr Umfang anfordern (insufficient_scope) und immer wieder eine Anmeldung anfordern. Bei der neuen Anmeldung wurden nur die fehlenden Bereiche angefordert, sodass das neue Token den Zugriff verlor, den das vorherige hatte. Es behält jetzt die gewährten Bereiche bei.
  • Problem behoben, bei dem Benutzermeldungen im Transkript zwei Kopien in voller Breite jeder gerenderten Zeile enthielten; Sie behalten eins mit identischer Leistung. – Problem behoben, bei dem /login und /logout jede OAuth-Anmeldung, einschließlich Radius, als Abonnement kennzeichnen; Nur abonnementbasierte Anbieter sagen „Abonnement“, andere OAuth-Anmeldungen sagen „Konto“.
  • Das lückenhafte Rendern des Start-Header-Logos im Apple Terminal wurde behoben; Stattdessen wird jetzt ein farbiges „Pi“ mit der Version angezeigt. – Es wurde behoben, dass verzögerte MCP-Tools, die von tool_search geladen wurden, beim Fortsetzen gelöscht wurden, und /reload auch dann, wenn der Server vor der nächsten Eingabeaufforderung erneut eine Verbindung herstellte, da die Sitzung ihre Tools wiederhergestellt hatte, bevor die MCP-Server erneut eine Verbindung hergestellt hatten.
  • Das Systemdesign wurde korrigiert, wodurch Pastellpaletten wie Catppuccin Frappe viel lebendiger wurden. Palettenfarben behalten jetzt ihre Chroma (#10255, #10293 von @dgtlntv). – Behoben, dass die automatische Vervollständigung von Slash-Befehlen nicht ausgelöst wurde, wenn die Eingabe mit Leerzeichen beginnt (#10218 von @haoqixu). – Farbausbluten über Mausauswahlen und Suchhervorhebungen im Vollbildmodus hinweg behoben, wenn ein gestaltetes Token an der Hervorhebungsgrenze endet (#10169).
  • Der pro gerenderte Nachricht im Transkript beibehaltene Speicher wurde korrigiert; Eine lange Assistentennachricht behält etwa ein Fünftel des Heaps, den sie zuvor hatte.

Englisches Original / English original

pi v1.0.0

New Features

  • Fullscreen by default — The TUI now runs fullscreen. Set tuiMode to "regular" to keep the terminal's normal scrollback. See Terminal and display.
  • Leaner codemode — About 40% fewer prompt tokens, and errors that tell the model how to recover. See Codemode.
  • Image generation in codemode — Scripts call models.generateImages() with the session's credentials. See Generate images and Use image models.
  • Radius in /login — Sign in with Radius and set up its MCP server in one step. See Radius.
  • Anthropic copy code login — Sign in when the browser runs on another machine. See Authenticate interactively.
  • MCP OAuth hardening — oauth.authServerMetadataUrl, RFC 9207 iss checks, credentials per server, and step-up sign-in that keeps granted scopes. See Authenticate with OAuth.
  • Header-only quiet startup — quietStartup: "header" keeps the version and key hints and hides the rest. See Terminal and display.

Added

  • Added an oauth.authServerMetadataUrl setting for MCP servers that advertise a wrong OAuth authorization server or none. Pi uses the configured metadata document instead of discovery (#10172).
  • Added quietStartup: "header", which keeps the startup header with version and key hints but hides the model scope line and loaded-resource listing.
  • Added models.generateImages() to codemode scripts. It runs image models such as OpenRouter's with the session's credentials and returns base64 image blocks that image() attaches to the result; usage counts toward the session cost like models.classify(). Extensions can call ctx.modelRegistry.generateImages(). See Use image models.
  • Added a copy code login method to Anthropic /login for headless setups where the browser runs on another machine (#10194 by @lucasmeijer).

Changed

  • Changed the default TUI mode to fullscreen. Set tuiMode to "regular" or pass --tui-mode regular to keep the terminal's normal scrollback.
  • /login now offers "Sign in with Radius" at the top level, as the last option, with its status. After a Radius sign-in, /login offers to configure the Radius MCP server in the global mcp.json with "auth": { "provider": "radius" } and reloads. Cancelling a login returns to the menu it was started from.
  • The provider docs page is renamed to Providers, its "Cloud Providers" section is now "Provider Specific Config", and it documents Radius first.
  • MCP OAuth credentials are now stored per server name and URL, so MCP servers with the same URL can sign in with different accounts. Credentials stored by URL alone move to the first server that uses them (#10252).
  • Codemode costs far fewer prompt tokens: with the default tools and codemode active, a GPT-5.6 request shrinks from about 5,300 to 3,300 tokens. The codemode description lists the script globals in one line each and points to the new Codemode reference for the models API, which the model reads when it needs it. Declared tools say in one line how scripts call them and what the call resolves to, instead of repeating their full declaration, and the system prompt's codemode guidance and MCP server section are shorter.
  • Codemode errors now say how to recover: reading a tool or models member that does not exist names the close matches (tools.Bash suggests tools.bash), models.classify() and models.generateImages() reject malformed arguments with the expected shape, an unknown model points to models.getAvailableOfType(), an oversized store() value explains what the store is for, and a script that generates images without showing them gets a note. Scripts that probed for a tool with typeof tools.name must use "name" in tools.
  • /login and /logout now label providers without credentials as "not configured" instead of "unconfigured".
  • OAuth browser pages now show the color Pi logo.

Fixed

  • Fixed MCP OAuth sign-in accepting an authorization response whose iss parameter names another authorization server; the code is now rejected before it is exchanged (RFC 9207).
  • Fixed MCP OAuth sign-in failing with Invalid scope when the token response contains "scope": "", and similar failures for other empty or null optional OAuth fields (#10266).
  • Fixed the sign-in URL printed by /mcp login not being clickable when it wraps (#10186).
  • Fixed --provider without --model being silently ignored and running the default model from another provider; it now fails with an error (#10236).
  • Fixed MCP servers that ask for more scope (insufficient_scope) requesting sign-in over and over. The new sign-in requested only the missing scopes, so the new token lost access the previous one had; it now keeps the granted scopes.
  • Fixed user messages in the transcript keeping two full-width copies of every rendered line; they keep one, with identical output.
  • Fixed /login and /logout labeling every OAuth sign-in, including Radius, as a subscription; only subscription-backed providers say "subscription", other OAuth sign-ins say "account".
  • Fixed the startup header logo rendering with gaps in Apple Terminal; it now shows a colored "Pi" with the version instead.
  • Fixed deferred MCP tools that tool_search loaded being dropped on resume and /reload even when their server reconnected before the next prompt, because the session restored its tools before the MCP servers reconnected.
  • Fixed the system theme making pastel palettes such as Catppuccin Frappe much more vivid; palette colors now keep their chroma (#10255, #10293 by @dgtlntv).
  • Fixed slash command autocompletion not triggering when the input starts with whitespace (#10218 by @haoqixu).
  • Fixed color bleeding past mouse selections and search highlights in fullscreen mode when a styled token ends at the highlight boundary (#10169).
  • Fixed memory retained per rendered message in the transcript; a long assistant message keeps about a fifth of the heap it kept before.
