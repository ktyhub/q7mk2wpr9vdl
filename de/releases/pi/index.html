pi

20-Versionen indiziert · neueste v1.6.0 auf 20. Nov. 2026

earendil-works/pi ↗

202620

11/20
v1.6.0 Minor MT

GPT-6.2 Astra und GPT-6.2 Sol: Beide Modelle sind bei den Anbietern openai, azure und openai-codex verfügbar, und GPT-6.2 Sol ist jetzt das Standardmodell für alle drei. Siehe Anbieter.

 11/10
v1.5.2 Patch MT

Fork-Sitzungen, deren Ordner nicht mehr vorhanden ist: Wenn der ursprüngliche Ordner einer Sitzung verschoben oder gelöscht wurde, können Sie ihn jetzt in den aktuellen Ordner verzweigen, anstatt nur fortzufahren, sodass bei späteren Fortsetzungen nicht mehr gefragt wird.

 11/09
v1.5.1 Patch MT

Shell-Anmeldung und -Abmeldung: Verwenden Sie die Pi-Authentifizierungs-Anmeldung und die Pi-Authentifizierungs-Abmeldung, ohne eine Sitzung zu starten, mit den Optionen API-Taste und Anmeldung ohne Browser. Siehe Anmeldeinformationsbefehle.

 11/02
v1.5.0 Minor MT

Erweiterungsupdate changelogs: Sehen Sie, was sich beim nächsten Neustart nach einem Update an den installierten Erweiterungspaketen geändert hat. Paketautoren können den changelog-Pfad wählen und collapChangelog fasst die Hinweise zusammen.

 10/21
v1.4.0 Minor MT

Bildeingabe für Klassifikatoren: codemode models.classify() akzeptiert Bilder für die Jev-Modelle von TypeSafe und die Clef-Modelle von Cloudflare auf Typesafe, cloudflare-workers-ai und OpenRouter. Siehe Verwenden von Klassifikatormodellen und Codemodus.

 10/15
v1.3.0 Minor MT

Choose where /share uploads: sessionShareDestination selects auto, gist, or radius. See Sessions and context and Export or share a session.

 10/12
v1.2.0 Minor MT

OpenRouter-Modelllisten pro Schlüssel: Mit einem OpenRouter-Schlüssel listet Pi nur die Modelle auf, die dieser Schlüssel verwenden darf, mit der Kontextgröße des Schlüssels, der maximalen Ausgabe und den Preisen, einschließlich der in models.json festgelegten regionalen Endpunkte. Siehe OpenRouter.

 10/07
v1.1.0 Minor MT

Programmstatusberichte: Terminals und Agent-Dashboards, die OSC 7501 unterstützen, sehen, ob Pi funktioniert, bei einem Dialog oder bei der Anmeldung blockiert, erledigt oder fehlgeschlagen ist. Siehe Programmstatus.

 10/05
v1.0.4 Patch MT

Tool-Muster und --no-mcp: --tools und --exclude-tools akzeptieren Muster, zum Beispiel --tools read,codemode,'mcp__radius' behält nur die Tools eines MCP-Servers.

 10/05
v1.0.3 Patch MT

Azure Foundry Chat Completions – Der Azure-Anbieter (umbenannt in azure-openai-responses) bedient nun auch Foundry Chat Completions-Bereitstellungen, beginnend mit azure/deepseek-v4-pro. Siehe Azure OpenAI.

 10/04
v1.0.2 Patch MT

Sampling nach Denkebene – samplingParamsByThinkingLevel in models.json legt Sampling-Parameter wie Temperatur und top_p für jede Denkebene auf OpenAI-kompatiblen APIs fest.

 10/03
v1.0.1 Patch MT

Nix Flake – Nix Run github:earendil-works/pi/stable führt die neueste Version aus und Nix Profile Add github:earendil-works/pi/stable installiert sie. Siehe „Pi installieren“.

 10/01
v1.0.0 Major MT

Standardmäßig Vollbild – Die TUI wird jetzt im Vollbildmodus ausgeführt. Setzen Sie tuiMode auf „regular“, um den normalen Scrollback des Terminals beizubehalten. Siehe Terminal und Display.

 09/30
v0.99.2 Patch MT

MCP-Server bleiben aus dem Weg: Server mit der standardmäßigen Codemodus-Bereitstellung werden nicht mehr in der Codemodus-Beschreibung aufgeführt und blockieren nicht mehr die erste Eingabeaufforderung.

 09/29
v0.99.1 Patch MT

GPT-6.1 Sol – Verfügbar auf OpenAI, Azure OpenAI und OpenAI Codex und jetzt das Standardmodell von OpenAI Codex. Siehe Modell auswählen.

 09/29
v0.99.0 Minor MT

Codemode und MCP – Verbinden Sie MCP-Server und lassen Sie Modelle JavaScript ausführen, das Tools parallel aufruft. Siehe MCP-Server und Codemodus aktivieren.

 09/22
v0.87.1 Patch MT

Neueste Frontier-Modelle – Verwenden Sie Claude Opus 5.5, GPT-6 Sol und GPT-6 Luna über unterstützte Anbieter, einschließlich GitHub Copilot. Siehe Modell auswählen.

 09/21
v0.87.0 Minor MT

Kanonischer Sitzungskontext und Erweiterungsgrenzen – Bearbeiten Sie den Modellkontext, ohne den Verlauf neu zu schreiben, und fügen Sie umsetzbare Lebenszyklus-Hooks hinzu. Siehe ContextEditEntry und Erweiterungsereignisse.

 09/20
v0.86.1 Patch MT

Meta Muse provider — Sign in with Meta using /login meta or use META_API_KEY to access Muse Spark models. Siehe Meta (Muse-Abonnement).

 09/19
v0.86.0 Minor MT

Prompt cache warming — Keep valuable prompt caches alive during long tool runs and optionally while idle using cost-aware refreshes. See Cache Warming.
