pi v0.99.2

Neue Funktionen

– MCP-Server bleiben aus dem Weg: Server mit der standardmäßigen codemode-Belichtung werden nicht mehr in der codemode-Beschreibung aufgeführt und blockieren nicht mehr die erste Eingabeaufforderung. They appear in a short system prompt section, and scripts find their tools with searchTools() and describeNamespace(). Siehe Belichtung mit dem Werkzeug steuern. – Weitere MCP-Authentifizierungsoptionen: oauth.clientName für Server, die nur bekannte OAuth-clients akzeptieren, und "auth": { "provider": "<provider>" } zur Authentifizierung von HTTP-Servern mit dem /login-Token eines Anbieters. Siehe Mit OAuth authentifizieren.

  • Anthropic workload identity federation from the Anthropic SDK environment variables. See Use an API key from the environment.
  • /reload enables tools newly added to the defaultTools setting. Siehe Tools.

Hinzugefügt

– Ein description-Feld für MCP-Server (pi mcp add --description) hinzugefügt, das zusammen mit dem Server in der Systemeingabeaufforderung angezeigt wird und zur Einstufung seiner Werkzeuge in der Werkzeugsuche verwendet wird, sowie ein describeNamespace(name)-Codemodus-Helfer, der die Anweisungen und Werkzeugnamen eines Namespace zurückgibt. describeNamespace() und searchTools() akzeptieren einen Namespace als mcp__dev-radius, mcp__dev_radius, dev-radius oder dev_radius. – Eine oauth.clientName-Einstellung für MCP-Server (pi mcp add --oauth-client-name) hinzugefügt, um den client-Namen zu ändern, der während der OAuth-client-Registrierung gesendet wird, für Server, die nur bekannte clients akzeptieren (#10226).

  • Added "auth": { "provider": "<provider>" } for HTTP MCP servers to send a provider's current /login token as the bearer token instead of using MCP OAuth. The token is read on every request, so provider refreshes apply. Only allowed in the global mcp.json and from extensions, and requires https except on loopback hosts. – Anthropic Workload Identity Federation aus den Umgebungsvariablen ANTHROPIC_FEDERATION_RULE_ID, ANTHROPIC_ORGANIZATION_ID und ANTHROPIC_IDENTITY_TOKEN_FILE hinzugefügt (siehe Providers) (#10177, #10242 von @philfreo).
  • /reload now enables tools newly added to the defaultTools setting. Entfernte Tools bleiben aktiviert, während der Sitzung deaktivierte Tools bleiben deaktiviert, sofern sie nicht neu hinzugefügt werden, und --tools, --no-tools und --no-builtin-tools überschreiben weiterhin die Einstellung (#10245).

Geändert

– MCP-Server mit der standardmäßigen codemode-Belichtung erscheinen nicht mehr in der codemode-Beschreibung; Skripte finden sie mit searchTools(). codemode-deferred ist jetzt ein Alias ​​für codemode. Use direct exposure for tools the model should see without searching (#10212). – Die codemode-Beschreibung enthält keine verzögerten Werkzeuge, Werkzeugzählungen oder MCP-Serveranweisungen mehr, sodass sie sich nicht mehr ändert, wenn MCP-Server eine Verbindung herstellen oder ihre Werkzeuge ändern. The tool_search description no longer lists the servers whose tools it can load, for the same reason. Servers are listed instead in an mcp_servers system prompt section with a one-line summary, updated at the start of each prompt; a changed section is appended to the conversation. Scripts read server instructions with describeNamespace() (#10212).

  • The first prompt no longer waits for MCP servers without direct tools. Sie verbinden sich im Hintergrund und werden darauf gewartet, wenn ein Codemodus-Skript sie benennt, ein Skript nach Tools sucht oder tool_search ausführt (#10212).

Behoben

– Behoben: Neue Sitzungen ignorierten zeitweise das gespeicherte Standardmodell oder gaben eine Warnung aus, dass keine Modelle verfügbar sind, wenn es zu einem erweiterungsregistrierten nativen Anbieter mit gespeicherten Anmeldeinformationen gehört (#9962, #10190 von @davidbrai). – Es wurde behoben, dass die /mcp-Anmelde-URL nicht clickbar war, wenn sie über Zeilen hinweg umbrochen wurde, indem sie als Terminal-Hyperlink mit einer Cmd/Ctrl+click to open-Zeile wie /login ausgegeben wurde (#10186). – Der Codemodus image() akzeptierte fehlerhafte Base64-Daten oder nicht unterstützte Bildtypen, wodurch ein ungültiger Bildblock bestehen blieb, der dazu führte, dass jede spätere Anbieteranforderung mit HTTP 400 fehlschlug (#10215). – Behoben: Codemodus konnte seinen Skript-Worker nicht aus der eigenständigen ausführbaren Windows-Datei starten (#10204). – Problem mit der Verlangsamung der Eingabeaufforderungsübermittlung mit der Sitzungslänge behoben, da beim Auflösen der Modellauswahl der Sitzung der Modellkatalog einmal pro Assistentennachricht nachgeschlagen wurde (#10198). – Problem behoben, bei dem die Modellsuche bei Anbietern mit einem aktualisierten pi.dev-Katalog langsamer wurde, da das Zusammenführen von Remote-Katalogmodellen quadratische Zeit in Anspruch nahm. – Die Erweiterungsbeispiele built-in-tool-renderer.ts und minimal-mode.ts wurden korrigiert, indem die Zusammenfassungen und Richtlinien der integrierten Tools aus der Systemeingabeaufforderung entfernt wurden (#10072, #10193 von @christianklotz). – Kontextüberlauferkennung für Z.AI CN-Endpunkt-Prompt exceeds max length-Fehler behoben (#10208). – Es wurde behoben, dass Anthropic-Anfragen fehlschlugen, wenn ein Tool-Schema Schlüsselwörter verwendet, die Anthropic bei strikter Tool-Nutzung ablehnt, wie z. B. minimum/maximum; Solche Tools werden jetzt nicht streng gesendet (#9953). – Problem behoben, bei dem der Anbieter die Auslösung sofort wiederholt, wenn ein Retry-After-Header ein nicht analysierbares Datum enthält; Sie verwenden jetzt einen exponentiellen Backoff (#9571). – Problem behoben, bei dem Erweiterungsbefehle, die ohne einen String-Namen oder einen Handler registriert wurden, bei der Eingabe von / zum Absturz von pi führten; Die Erweiterung kann jetzt nicht geladen werden, stattdessen tritt ein Fehler auf (#10054). – Problem behoben, bei dem reduzierte Ergebnisse von codemode und MCP-Tools den Bildschirm ausfüllten, wenn die Ausgabe eine lange Zeile war, wie z. B. minimiertes JSON. Wie bei der Bash-Ausgabe ist die Vorschau jetzt auf umgebrochene Zeilen statt auf logische Zeilen beschränkt. – Behoben, dass codemode.mode: "only" read, bash, edit und write in der Toolliste der Systemeingabeaufforderung auflistet, obwohl Anfragen nur codemode deklarieren (#10192). – Codemodus-Skripte, die das falsche MCP-Tool aufrufen, wenn sich zwei Tool-Namen nur in - und _ unterscheiden, wie z. B. read-file und read_file, wurden behoben. Wie im Codex ersetzen MCP-Tool- und Namespace-Namen jetzt - durch _ (mcp__my-server__x ist jetzt mcp__my_server__x), kollidierende Tools eines Servers erhalten alle ein Hash-Suffix und Servernamen, die sich nur in - und _ unterscheiden, werden abgelehnt (#10239).

Englisches Original / English original

pi v0.99.2

New Features

  • MCP servers stay out of the way: servers with the default codemode exposure are no longer listed in the codemode description and no longer block the first prompt. They appear in a short system prompt section, and scripts find their tools with searchTools() and describeNamespace(). See Control tool exposure.
  • More MCP authentication options: oauth.clientName for servers that only accept known OAuth clients, and "auth": { "provider": "<provider>" } to authenticate HTTP servers with a provider's /login token. See Authenticate with OAuth.
  • Anthropic workload identity federation from the Anthropic SDK environment variables. See Use an API key from the environment.
  • /reload enables tools newly added to the defaultTools setting. See Tools.

Added

  • Added a description field for MCP servers (pi mcp add --description), shown with the server in the system prompt and used to rank its tools in tool search, and a describeNamespace(name) codemode helper that returns a namespace's instructions and tool names. describeNamespace() and searchTools() accept a namespace as mcp__dev-radius, mcp__dev_radius, dev-radius, or dev_radius.
  • Added an oauth.clientName setting for MCP servers (pi mcp add --oauth-client-name) to change the client name sent during OAuth client registration, for servers that only accept known clients (#10226).
  • Added "auth": { "provider": "<provider>" } for HTTP MCP servers to send a provider's current /login token as the bearer token instead of using MCP OAuth. The token is read on every request, so provider refreshes apply. Only allowed in the global mcp.json and from extensions, and requires https except on loopback hosts.
  • Added Anthropic workload identity federation from the ANTHROPIC_FEDERATION_RULE_ID, ANTHROPIC_ORGANIZATION_ID, and ANTHROPIC_IDENTITY_TOKEN_FILE environment variables (see Providers) (#10177, #10242 by @philfreo).
  • /reload now enables tools newly added to the defaultTools setting. Tools removed from it stay enabled, tools turned off during the session stay off unless newly added, and --tools, --no-tools, and --no-builtin-tools still override the setting (#10245).

Changed

  • MCP servers with the default codemode exposure no longer appear in the codemode description; scripts find them with searchTools(). codemode-deferred is now an alias for codemode. Use direct exposure for tools the model should see without searching (#10212).
  • The codemode description no longer includes deferred tools, tool counts, or MCP server instructions, so it no longer changes when MCP servers connect or change their tools. The tool_search description no longer lists the servers whose tools it can load, for the same reason. Servers are listed instead in an mcp_servers system prompt section with a one-line summary, updated at the start of each prompt; a changed section is appended to the conversation. Scripts read server instructions with describeNamespace() (#10212).
  • The first prompt no longer waits for MCP servers without direct tools. They connect in the background and are waited for when a codemode script names them, a script searches tools, or tool_search runs (#10212).

Fixed

  • Fixed new sessions intermittently ignoring the saved default model, or warning that no models are available, when it belongs to an extension-registered native provider with a stored credential (#9962, #10190 by @davidbrai).
  • Fixed the /mcp sign-in URL not being clickable when it wraps across lines, by emitting it as a terminal hyperlink with a Cmd/Ctrl+click to open line like /login (#10186).
  • Fixed codemode image() accepting malformed base64 data or unsupported image types, which persisted an invalid image block that made every later provider request fail with HTTP 400 (#10215).
  • Fixed codemode failing to start its script worker from the standalone Windows executable (#10204).
  • Fixed prompt submission slowing down with session length, because resolving the session's model selection looked up the model catalog once per assistant message (#10198).
  • Fixed model lookups slowing down for providers with a refreshed pi.dev catalog, because merging remote catalog models took quadratic time.
  • Fixed the built-in-tool-renderer.ts and minimal-mode.ts extension examples removing the built-in tools' summaries and guidelines from the system prompt (#10072, #10193 by @christianklotz).
  • Fixed context overflow detection for Z.AI CN endpoint Prompt exceeds max length errors (#10208).
  • Fixed Anthropic requests failing when a tool schema uses keywords Anthropic strict tool use rejects, such as minimum/maximum; such tools are now sent non-strict (#9953).
  • Fixed provider retries firing immediately when a Retry-After header contains an unparseable date; they now use exponential backoff (#9571).
  • Fixed extension commands registered without a string name or handler crashing pi when typing /; the extension now fails to load with an error instead (#10054).
  • Fixed collapsed codemode and MCP tool results filling the screen when the output is one long line, such as minified JSON. Like bash output, the preview is now limited to wrapped lines instead of logical lines.
  • Fixed codemode.mode: "only" listing read, bash, edit, and write in the system prompt's tool list although requests only declare codemode (#10192).
  • Fixed codemode scripts calling the wrong MCP tool when two tool names differ only in - and _, such as read-file and read_file. Like in Codex, MCP tool and namespace names now replace - with _ (mcp__my-server__x is now mcp__my_server__x), colliding tools of a server all get a hash suffix, and server names that differ only in - and _ are rejected (#10239).
