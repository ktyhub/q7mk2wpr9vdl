airflow 3.1.6

Highlights

  • HITL approval authorization — Auth managers gain is_authorized_hitl_task() (#59399), letting custom backends decide who may approve a Human-in-the-Loop task instead of relying on coarse admin checks. Review your approval setup alongside the ApprovalOperator fix for SimpleAuthManager with all_admins=True (#60116): the new authorization path is now genuinely consulted.
  • Proxy configuration treated as secret — proxy and proxies join DEFAULT_SENSITIVE_FIELDS (#59688/#59792), so proxy URLs — including embedded credentials — are masked in logs and the UI by default; secrets in rendered templates are also redacted correctly when templates are truncated (#59566/#59704). If you intentionally surface proxy settings in reports or custom masker patterns, expect masks where values used to appear.
  • Stable DAG serialization — Template fields supplied via callables no longer produce unstable serialized DAGs (#60065/#60221), and XCom keys with slashes/special characters are handled correctly (#59311). This cuts spurious DAG-version churn in the scheduler and lets you use structured XCom keys without breaking xcom_pull lookups.
  • Execution API and Task SDK plumbing — DagRun deletion now validates run state (#60195/#60207), the Execution API refresh-token flow is fixed (#58782/#59713), and Task SDK calls add Content-Type when missing (#59676/#59687). Clients that delete runs in arbitrary states may see new rejections. The Task-SDK client also drops its FastAPI dependency (#59250/#59257): a lighter worker dependency surface, but avoid relying on FastAPI types leaking transitively from the SDK.
  • Backfills and monitoring correctness — run_on_latest_version now defaults to True as intended (#59304/#59328), so backfills use current DAG code rather than historical versions — a visible behavior change if you relied on the old default. Missing ti_failure metrics are recorded (#59731/#59964) and TaskInstanceHistory rows are restored on scheduler TI resets (#59639/#59752), making dashboards and audit trails more complete.
  • Scheduler and DAG processor robustness — aiosqlite 0.22+ hanging-thread protection (#60217/#60245), the DAG processor no longer crashes on Excel files in the DAG folder (#59069/#59170) or on logging errors (#59317/#59581), .airflowignore negation works in subfolders (#58740/#59305), and DagRun.queued_at updates correctly on clear (#59066/#59177). Most relevant to SQLite/local deployments and repos with mixed file types.

No breaking changes.

Significant Changes

is_authorized_hitl_task() method now available in auth managers(#59399).

This method is now available in auth managers to check whether a user is authorized to approve a HITL task

proxy and proxies have been added to DEFAULT_SENSITIVE_FIELDS in secrets_masker to treat proxy configurations as sensitive by default
