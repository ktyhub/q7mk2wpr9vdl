bootstrap v5.3.4

Highlights

  • Color-mode visual fixes — If you ship light/dark themes, this patch clears several regressions: modal and offcanvas headers no longer collapse (#41336), close buttons render correctly on contextual light/dark backgrounds (#41126), and the "light" carousel variant displays properly on a dark page (#40695). Watch out if you added local CSS to compensate for these bugs — those overrides may now be redundant.
  • Floating labels tuned up — A cluster of fixes makes floating labels more predictable: they now align with form-select sizes (#41013), respect correct max-width and background-color (#39720), and use an updated placeholder color (#39494). If you hand-patched label sizing or colors, diff against the new defaults before upgrading.
  • Popover toggle behavior changed — #40803 fixes the popover so a second toggle click actually closes it. This is a genuine behavioral change: revisit any UI logic or tests that relied on (or worked around) the old double-toggle behavior. #38725 also corrects this binding for functions in the JS internals — worth a smoke test if you invoke plugin methods indirectly.
  • Sass and build-tool compatibility — Compiling from source gets cleaner: #40623 relocates declarations that appeared after nested rules (deprecated in Dart Sass 1.77.7) to silence warnings, #41004 works around postcss-values-parser failing on negative calc() values, and #39804 optimizes the Sass SVG assets. The obsolete flexbug workaround was also removed (#40876), so custom builds should be quieter and slightly leaner.
  • Component polish and a migration reminder — btn-group-vertical now reuses the btn-group rules for consistent styling (#40488), and accordion border-radius selectors were consolidated (#39697). For anyone upgrading from v4, the migration guide now explicitly documents the removal of util.js (#41187) — a useful prompt that v5 has no standalone utility JS layer to carry over.
  • Breaking changes — None; this is a patch release with no API-breaking changes.
