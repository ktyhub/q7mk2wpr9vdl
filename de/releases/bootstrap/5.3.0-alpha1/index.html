bootstrap v5.3.0-alpha1

Highlights

  • Dark mode lands as a first-class color mode system — #35857 introduces built-in light/dark theming driven by data-bs-theme, backed by new CSS variables and Sass/JS hooks. This is the main reason to try the alpha, but it's still settling: the "Enable dark mode" docs were corrected late (#37553), the color-mode script was moved (#37658), and Sass builds using $color-mode-type: media-query only compiled after #37687. Expect to revisit your theme bootstrap as the alpha hardens.

  • JavaScript internals were restructured — audit direct imports — #36854 switches source files to explicit imports, #36027 relocates getElementFromSelector/getSelectorFromElement, and #37438 makes getSelector non-exported. If you imported Bootstrap's ESM internals to extend components, those entry points moved or vanished. execute() now accepts arguments (#36652), and a replaceAll regression introduced in #35566 was repaired in #37473 — both matter if you vendored an early alpha.

  • New utilities cut custom CSS — #37317 adds .z-* z-index utilities, #36540 new border-radius utilities, #36781 fw-medium (500), #36848 overflow/object-fit helpers, and #36095 CSS variables for breakpoints. The docs now stamp "added in" badges (e.g. #37491 for z-index), so check the badge before assuming a utility is available in 5.2.

  • Progress bar markup was reworked — #36831 changes both the markup and the styles, alongside an accessibility pass over examples (#37432, #37498). If you override progress bar internals or copy example HTML, diff your templates against the new structure instead of assuming a class-only tweak.

  • Floating labels get functional fixes — #37125 adds an artificial background to the label, while #37299 and #37408 fix disabled-state rendering with new docs examples. Combined with the --bs-body-font-family quoting fix (#37526) and the WebKit date/time whitespace fix (#37350), these subtly change computed output — visual regressions after upgrading are most likely here.

  • Sass prefixing now applies across all assets — #37617 pushes $prefix through the whole asset set, which can rename generated CSS custom properties if you ship under a custom prefix. Pair that with the new color variables for .alert-link, .btn-close, Offcanvas and list groups (#36456, #36457, #36815, #37644) and verify your overrides still target the right variable names.

No formally flagged breaking changes in this alpha, but the JS internals and progress bar markup above need migration checks.
