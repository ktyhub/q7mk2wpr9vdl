unsloth v0.1.915-beta

Diese Version führt Qwen3.8-Flash-Next Dynamic V3.1 ein, verfeinert die Glass-Designs (jetzt in der Beta), fügt einen Composer-Positionsschieberegler hinzu und ermöglicht die Interaktion von Modellen mit Dateien im integrierten Browser. Es sorgt außerdem für eine geringere Leerlaufspeichernutzung, einen erhaltenen Chat-Kontext beim Wechsel des GGUF-Modells, ein schnelleres Laden von MLX und ein FP8-LoRA-Training.

Highlights

  • Qwen3.8-Flash-Next Dynamic V3.1 – 10–15 % zusätzliche Genauigkeit Anleitung
  • Verbesserungen des Glass-Designs für Seiten, Menüs, die Seitenleiste und den Browser
  • Browser-Dateiinteraktion ermöglicht es Models, HTML, Dateien und Seiten zu lesen, zu lesen und zu bearbeiten
  • Geringerer Leerlaufspeicher durch schnelleres Laden und Neuladen von MLX
  • Chat-Kontext bleibt erhalten beim Wechsel zwischen GGUF-Modellen
  • FP8 LoRA-Training mit geringerer GPU-Speichernutzung
  • Schieberegler Komponistenposition, um das Chat-Feld an einer beliebigen Stelle in neuen Chats zu platzieren

Glas und Aussehen

  • Legen Sie die Position des Chat-Felds von oben nach unten unter Einstellungen > Darstellung > Komponist fest. – Glasthemen verfügen jetzt über weichere Glanzlichter, hellere Schatten und verbesserte Mattierungseffekte in Menüs, Bedienfeldern und im Browser.
  • Seiten wie „Bibliothek“, „Bilder“ und „Zug“ verwischen Hintergrundbilder nicht mehr stark.
  • Bei offenen Gesprächen wird der Hintergrund jetzt leicht abgedunkelt und für den Komponisten wird dichteres Glas verwendet.
  • Die Titelleisten von Windows und Linux passen besser zu Glass-Themen und Hintergrundbildern.
  • In einem Browser-Tab vorgenommene Einstellungsänderungen werden jetzt mit anderen geöffneten Tabs synchronisiert.

Eingebauter Browser

  • Wenn Browser-Nutzung aktiviert ist, können Models im Chat erstellte HTML- und React-Seiten clickgeben und eingeben.
  • Modelle können HTML-, React-, Markdown-, Code- und Textdateien direkt im Browser lesen und bearbeiten. Zurück stellt die vorherige Version wieder her.
  • Modelle können auch PDFs und andere im Browser geöffnete Dokumente lesen.
  • Download-Eingabeaufforderungen können sich Berechtigungen pro Site oder über alle Sites hinweg merken, auch für Programmdateien.

Chatten

– Chats zeigen jetzt Aktivitäten zwischen Tool-Aufrufen an, einschließlich Kontextkomprimierung auf GGUF-Modellen.

  • Hängen Sie gespeicherte Bibliotheksdateien über + > Mehr > Aus Bibliothek anhängen an.
  • Wenn Sie von einem GGUF-Modell weg und zurück wechseln, bleibt der Chat-Kontext erhalten, sodass lange Historien nicht mehr erneut gelesen werden müssen.
  • GGUF-Modelle können bis zu vier Webseiten gleichzeitig lesen, wenn die Tools ohne Nachfrage ausgeführt werden.

Verbindungen und API

– OpenRouter-Modelle werden jetzt live geladen, mit funktionierender Unterstützung für Modelle neu laden.

  • Verbesserte Kompatibilität mit neueren MCP-Servern. – Der Decision API fügt die d1-Modelle von LiquidAI und Decider 2B (nur MLX) hinzu.
  • Einstellungen > API > Schnellstart enthält jetzt Beispiele für Curl, Python und JavaScript.

Leistung und Medien

– Unsloth lädt PyTorch und andere ML-Bibliotheken nicht mehr beim Start, wodurch die Leerlaufspeichernutzung erheblich reduziert wird. Konfigurieren Sie Startfunktionen unter Einstellungen > Allgemein > Startleistung.

  • MLX-Modelle werden viel schneller geladen und neu geladen, und das Reduzieren des Kontexts eines geladenen Modells dauert jetzt Sekunden. – Lange Eingabeaufforderungen bei unterstützten MLX-Modellen verbrauchen weniger Speicher.
  • SDXL rendert schneller mit sehr begrenztem VRAM, einschließlich 4-GB-Setups.
  • Bild-LoRAs in Ihren Modellordnern werden jetzt auf der Seite „Bilder“ angezeigt.

Ausbildung

– Schnelleres LoRA-Training mit geringerem Speicherbedarf auf 16-Bit-Basis mit aktuellen NVIDIA-GPUs unter Verwendung von float8_training = "fp8_lora".

  • DPO-, ORPO-, KTO-, GRPO- und CPO-Schulungen laufen jetzt auf MLX.
  • Abstürze bei der vollständigen Feinabstimmung von Gemma 4 in float16 behoben.

unsloth v0.1.915-beta

This release introduces Qwen3.8-Flash-Next Dynamic V3.1, polishes the Glass themes (now in Beta), adds a Composer position slider and lets models interact with files in the built-in browser. It also brings lower idle memory usage, preserved chat context when switching GGUF models, faster MLX loading and FP8 LoRA training.

Highlights

  • Qwen3.8-Flash-Next Dynamic V3.1 - 10-15% extra accuracy Guide
  • Glass theme improvements across pages, menus, the sidebar and browser
  • Browser file interaction lets models click, read and edit HTML, files and pages
  • Lower idle memory with faster MLX loading and reloading
  • Preserved chat context when switching between GGUF models
  • FP8 LoRA training with lower GPU memory usage
  • Composer position slider to place the chat box anywhere on new chats

Glass and appearance

  • Set the chat box position, from top to bottom, in Settings > Appearance > Composer.
  • Glass themes now have softer highlights, lighter shadows and improved frosted effects across menus, panels and the browser.
  • Pages like Library, Images and Train no longer heavily blur background images.
  • Open conversations now slightly dim the background and use denser glass for the composer.
  • Windows and Linux title bars better match Glass themes and background images.
  • Settings changes made in one browser tab now sync across other open tabs.

Built-in browser

  • With Browser use enabled, models can click and type in HTML and React pages created in chat.
  • Models can read and edit HTML, React, Markdown, code and text files directly in the browser. Back restores the previous version.
  • Models can also read PDFs and other documents open in the browser.
  • Download prompts can remember permissions per site or across all sites, including for program files.

Chat

  • Chats now show activity between tool calls, including context compaction on GGUF models.
  • Attach saved Library files using + > More > Attach from Library.
  • Switching away from a GGUF model and back now preserves chat context, avoiding the need to re-read long histories.
  • GGUF models can read up to four web pages at once when tools run without asking.

Connections and API

  • OpenRouter models now load live, with working Reload models support.
  • Improved compatibility with newer MCP servers.
  • The Decision API adds LiquidAI's d1 models and Decider 2B (MLX only).
  • Settings > API > Quickstart now includes curl, Python and JavaScript examples.

Performance and media

  • Unsloth no longer loads PyTorch and other ML libraries at startup, significantly reducing idle memory usage. Configure startup features in Settings > General > Startup performance.
  • MLX models load and reload much faster, and reducing a loaded model's context now takes seconds.
  • Long prompts on supported MLX models use less memory.
  • SDXL renders faster with very limited VRAM, including 4 GB setups.
  • Image LoRAs in your model folders now appear on the Images page.

Training

  • Faster, lower-memory LoRA training on 16-bit bases with recent NVIDIA GPUs using float8_training = "fp8_lora".
  • DPO, ORPO, KTO, GRPO and CPO training now run on MLX.
  • Fixed crashes when full fine-tuning Gemma 4 in float16.
