MaxKB v2.3.0

Neue Funktionen

  • Wissensdatenbank: Funktion „Tag-Management“ hinzugefügt;
  • Wissensdatenbank: Funktion „Tag-Einstellung“ für Dokumente in der Wissensdatenbank hinzugefügt;
  • Wissensdatenbank: Funktion „Originaldokument ersetzen“ für die allgemeine Wissensdatenbank hinzugefügt;
  • Anwendungen: Knoten „Dokument-Tag-Abruf“ zu Advanced Orchestration Applications hinzugefügt;
  • Anwendungen: Knoten „Video Understanding“ zu Advanced Orchestration Applications hinzugefügt;
  • Anwendungen: Knoten „Variablenaufteilung“ zu Advanced Orchestration Applications hinzugefügt;
  • Anwendungen: Knoten „Variable Aggregation“ zu Advanced Orchestration Applications hinzugefügt;
  • Anwendungen: Knoten „Parameterextraktion“ zu Advanced Orchestration Applications hinzugefügt;
  • Anwendungen: Option „Video“-Dateityp zu den Datei-Upload-Einstellungen hinzugefügt;
  • Anwendungen: Die Beurteilungsbedingungen „startwith“ und „endwith“ wurden zum Judge-Knoten hinzugefügt;
  • Anwendungen: Parameter „Historische Chat-Datensätze {history}“ zu den Ausgabeparametern des AI-Konversationsknotens hinzugefügt;
  • Anwendungen: Zwei Abrufbereichsoptionen (manuelle Auswahl der Wissensdatenbank und Variablenreferenz) zum Knoten „Knowledge Base Retrieval“ hinzugefügt;
  • Ressourcenautorisierung: Unterstützte Autorisierung von Ordnerressourcen durch Benutzer;
  • Ressourcenautorisierung: Unterstützte ordnerbasierte Ressourcenautorisierung für Anwendungen, Wissensdatenbanken und Tools im Arbeitsbereich;
  • Systemverwaltung (X-Pack): Bereinigungsrichtlinien zu Betriebsprotokollen hinzugefügt, um Administratoren bei der effizienten Verwaltung von Protokolldaten zu helfen.

Funktionsoptimierungen

  • Anwendungen (X-Pack): Unterstützte passwortfreie Anmeldung für Benutzer, nachdem die Anwendung mit WeChat Work, Lark oder DingTalk verbunden ist;
  • Anwendungen: Unterstützte Videodateitypen für Datei-Uploads;
  • Anwendungen: Unterstützung für die Einstellung von URL-Adressen für den Parameter „Datei auswählen“ der Knoten „Image Understanding“, „Image-to-Video“ und „Video Understanding“ hinzugefügt;
  • Anwendungen: Zulässige Verwendung von Variablenzuweisungsknoten als Endknoten;
  • Anwendungen: Unterstützte Stapelauswahl von Knoten auf der Workflow-Orchestrierungsseite;
  • Anwendungen: Ein Beschreibungsfeld zu den Schnittstellenparametern hinzugefügt;
  • Anwendungen: Der Maximalwert der Option „Fragenlimit pro Client“ in „Zugriffsbeschränkungen“ wurde auf 10 Millionen Mal pro Tag angepasst;
  • Anwendungen: Benutzerdefinierte Eingabeunterstützung für Mehrfachauswahlfeldkomponenten im Formularsammlungsknoten hinzugefügt;
  • Anwendungen: Zeigt alle Anwendungen im aktuellen Arbeitsbereich im Stammverzeichnis an und unterstützt die globale Suche;
  • Tools: Zeigt alle Tools im aktuellen Arbeitsbereich im Stammverzeichnis an und unterstützt die globale Suche;
  • Tools: Unterstützung für das Parsen von Variablen für benutzerdefinierte Parametertypen hinzugefügt;
  • Wissensdatenbank: Zeigt alle Wissensdatenbanken im aktuellen Arbeitsbereich im Stammverzeichnis an und unterstützt die globale Suche;
  • Rollen: Die „Info“-Berechtigung wurde an die normale Benutzerrolle angepasst;
  • Modelle: Unterstützung für die Einstellung von Modellparametern für Vektormodelle hinzugefügt.

Fehlerbehebungen

  • Anwendungen: Das Problem wurde behoben, bei dem Werkzeugknoten im Schleifenkörper beim Exportieren der Anwendung nicht exportiert wurden.
  • Anwendungen: Das Problem wurde behoben, bei dem Knoten nach dem Formularsammlungsknoten im Schleifenkörper keine Schleifenvariablen ausgeben konnten.
  • Anwendungen: Das Problem wurde behoben, bei dem der Inhalt des ersten Parameters gelöscht wurde, wenn der Inhalt des zweiten Parameters im MCP-Aufrufknoten geändert wurde.
  • Anwendungen: Das Problem wurde behoben, bei dem Token während Konversationen 0 anzeigten, wenn das große Zhipu-Sprachmodell verwendet und die Tool-Funktion im AI-Konversationsknoten aktiviert wurde;
  • Anwendungen (X-Pack): Das Problem wurde behoben, bei dem die Einstellungsoption für die Verlaufsaufzeichnung in den Anzeigeeinstellungen nicht wirksam wurde (#4201);
  • Q&A-Seite: Das Problem, bei dem hochgeladene Dateien verloren gingen, wenn cli nach dem Hochladen von Dateien und dem Stellen von Fragen auf der Q&A-Seite auf die Schaltfläche „Weitere Antwort erhalten“ klickte, wurde behoben (#4180);
  • Q&A-Seite: Das Problem wurde behoben, bei dem Konversationsaufzeichnungen verloren gingen, wenn die Größe des Konversationsfensters angepasst wurde, während Fragen auf der Q&A-Seite gestellt wurden (#4202).

Englisches Original / English original

MaxKB v2.3.0

Highlights

  • Advanced orchestration gets a major expansion — v2.3.0 adds five new nodes—Document Tag Retrieval, Video Understanding, Variable Splitting, Variable Aggregation, and Parameter Extraction—plus startwith/endwith conditions in the Judge node, a Historical Chat Records {history} output on the AI Conversation node, and manual-selection vs variable-reference retrieval scopes on the Knowledge Base Retrieval node. Variable Assignment nodes can now act as end nodes and workflow nodes support batch selection. For anyone building orchestrated apps, this is the headline reason to upgrade: video input, variable reshaping, and tag-filtered retrieval no longer need workarounds.

  • Knowledge base: tagging and in-place document replacement — New "Tag Management" and per-document "Tag Setting" functions, plus a "Replace Original Document" action for general knowledge bases. This enables tag-driven organization (which the new Document Tag Retrieval node consumes) and updating documents without delete-and-reupload—worth it if you maintain large or frequently refreshed corpora.

  • Permissions and X-Pack access changes (behavioral, not migration) — Folder-based resource authorization now covers applications, knowledge bases, and tools and can be granted by user; note the "About" permission was moved to the ordinary user role, so non-admin users gain access that previously needed elevated rights—review this if your permission model is strict. X-Pack adds password-free login after connecting WeChat Work, Lark, or DingTalk and operation-log cleaning policies. No explicit breaking changes or migration steps are documented for this release.

  • Concrete correctness fixes that justify upgrading — Tool nodes inside loop bodies were missing from app exports and downstream nodes couldn't emit loop variables after a Form Collection node; the MCP Call node cleared the first parameter when editing a second; Tokens showed 0 with the Zhipu LLM when tool functions were enabled in the AI Conversation node; and three tracked issues are resolved—#4180 (uploaded files lost via "Get Another Answer"), #4201 (display-settings history option ignored), and #4202 (conversation records lost when resizing the chat window). If you hit any of these, upgrade.

  • Upgrade verdict — Not a no-op, re-tag, or metadata-only release: this is a substantive feature-and-fix version with no migration burden. Upgrade if you use Advanced Orchestration, knowledge-base tagging, folder-level authorization, WeChat Work/Lark/DingTalk SSO (X-Pack), or any of the fixed bugs; you can safely skip if you only run basic single-tenant Q&A and need none of the tags, video, or workflow/loop fixes.

New Features

  • Knowledge Base: Added "Tag Management" function;
  • Knowledge Base: Added "Tag Setting" function for documents in the knowledge base;
  • Knowledge Base: Added "Replace Original Document" function for the general knowledge base;
  • Applications: Added "Document Tag Retrieval" node to Advanced Orchestration Applications;
  • Applications: Added "Video Understanding" node to Advanced Orchestration Applications;
  • Applications: Added "Variable Splitting" node to Advanced Orchestration Applications;
  • Applications: Added "Variable Aggregation" node to Advanced Orchestration Applications;
  • Applications: Added "Parameter Extraction" node to Advanced Orchestration Applications;
  • Applications: Added "Video" file type option to file upload settings;
  • Applications: Added "startwith" and "endwith" judgment conditions to the Judge node;
  • Applications: Added "Historical Chat Records {history}" parameter to the output parameters of the AI Conversation node;
  • Applications: Added two retrieval scope options (manual selection of knowledge base and variable reference) to the Knowledge Base Retrieval node;
  • Resource Authorization: Supported authorizing folder resources by user;
  • Resource Authorization: Supported folder-based resource authorization for applications, knowledge bases, and tools in the workspace;
  • System Management (X-Pack): Added cleaning policies to operation logs to help administrators manage log data efficiently.

Feature Optimizations

  • Applications (X-Pack): Supported password-free login for users after the application is connected to WeChat Work, Lark, or DingTalk;
  • Applications: Supported video file types for file uploads;
  • Applications: Added URL address setting support for the "select file" parameter of Image Understanding, Image-to-Video, and Video Understanding nodes;
  • Applications: Allowed Variable Assignment nodes to be used as end nodes;
  • Applications: Supported batch selection of nodes on the workflow orchestration page;
  • Applications: Added a description field to interface parameters;
  • Applications: Adjusted the maximum value of the "Question Limit per Client" option in "Access Restrictions" to 10 million times per day;
  • Applications: Added custom input support for multi-select box components in the Form Collection node;
  • Applications: Displayed all applications in the current workspace in the root directory and supported global search;
  • Tools: Displayed all tools in the current workspace in the root directory and supported global search;
  • Tools: Added variable parsing support for custom-type parameters;
  • Knowledge Base: Displayed all knowledge bases in the current workspace in the root directory and supported global search;
  • Roles: Adjusted the "About" permission to the ordinary user role;
  • Models: Added model parameter setting support for vector models.

Bug Fixes

  • Applications: Fixed the issue where tool nodes in the loop body were not exported when exporting the application;
  • Applications: Fixed the issue where nodes after the Form Collection node in the loop body could not output loop variables;
  • Applications: Fixed the issue where the content of the first parameter was cleared when modifying the content of the second parameter in the MCP Call node;
  • Applications: Fixed the issue where Tokens showed 0 during conversations when using the Zhipu large language model and enabling the tool function in the AI Conversation node;
  • Applications (X-Pack): Fixed the issue where the history record setting option in display settings did not take effect (#4201);
  • Q&A Page: Fixed the issue where uploaded files were lost when clicking the "Get Another Answer" button after uploading files and asking questions on the Q&A page (#4180);
  • Q&A Page: Fixed the issue where conversation records were lost when adjusting the size of the conversation window while asking questions on the Q&A page (#4202).
