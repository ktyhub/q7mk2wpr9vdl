MaxKB v2.9.0

MaxKB v2.9.0

Neue Funktionen

  • Agent: Langzeitspeicherfunktion hinzugefügt. Es unterstützt die Generierung von Erinnerungen nach Gesprächsrunden und Zeiträumen. Erinnerungen können über variable Referenzen in Eingabeaufforderungen eingefügt werden, um die Konversationspersonalisierung und -kontinuität zu verbessern.
  • Agent: Knoten in erweiterten Agent-Workflows unterstützen das Aktivieren/Deaktivieren und ermöglichen so Debugging und temporäre Logikabschirmung ohne Löschen von Knoten.
  • Agent: Funktion zur Anzeige zugeordneter Ressourcen hinzugefügt, um abhängige und abhängige Ressourcen zu überprüfen (#4859, #4872).
  • Wissensdatenbank: Funktion zur Anzeige zugehöriger Ressourcen mit bidirektionaler Abhängigkeitsverfolgung hinzugefügt.
  • Tools: Funktion zur Anzeige zugehöriger Ressourcen mit bidirektionaler Abhängigkeitsverfolgung hinzugefügt.
  • Tools: Knoten in Workflow-Tools unterstützen das Aktivieren/Deaktivieren und ermöglichen so Debugging und temporäre Logikabschirmung ohne Löschen von Knoten.
  • Modell: Zugriffsunterstützung für große MiniMax-Sprachmodelle und Text-to-Speech-Modelle hinzugefügt (#4876).
  • Modell: Alibaba Cloud Bailian hat Unterstützung für den Zugriff auf das MiniMax Speech-Sprachmodell hinzugefügt (#4950).

Funktionsoptimierungen

  • Agent: Benutzereingabe- und Formularsammlungsknoten unterstützen jetzt die Baumauswahlkomponente (#4903).
  • Agent: Der Variablenzuweisungsknoten unterstützt die explizite Zuweisung einer Variablen zu Null (#4964, #5107).
  • Agent: Modi für den Vergleich regulärer Ausdrücke und Platzhalter für Richterknoten in erweiterten Agenten hinzugefügt (#4975).
  • Agent: Stapelkopieren und -einfügen wird für Knoten auf dem Orchestrierungs-Canvas von erweiterten Agenten und Workflows unterstützt.
  • Agent: Knoten innerhalb von Schleifen unterstützen das Stapelkopieren und Einfügen über verschiedene Schleifenkörper hinweg (#5128).
  • Agent: Die Berechtigung Veröffentlichen erweiterter Agenten ist unabhängig von der Bearbeitungsberechtigung getrennt und kann separat autorisiert werden.
  • Agent: Formatrichtlinien für variable Parameter integrierter Knoten hinzugefügt.
  • Modell: Im Modellauswahlfeld werden für eine übersichtlichere Benutzeroberfläche nur Anbietersymbole und Modellnamen angezeigt.
  • Modell: Alle Modellanbieter unterstützen die benutzerdefinierte API-Basis-URL zur Anpassung an private Bereitstellungsszenarien.
  • Modell: Modellparameteränderungen werden automatisch mit allen zugehörigen referenzierten Ressourcen synchronisiert (#5134).
  • Tools: ZIP-Installationspakete, die für das Herunterladen von Skills-Tools hochgeladen wurden.
  • System: Browser-Ruckeln, das durch übermäßige Dateiverzeichnisse verursacht wird, wurde optimiert.
  • System: Front-End-Ruckler beim Hinzufügen einer großen Anzahl von Mitgliedern zu einer Rolle optimiert.

Fehlerbehebungen

– Agent: Das Problem wurde behoben, bei dem nachfolgende Knoten keine Ausgabe hatten, nachdem ein Subagentenknoten in einem Schleifenkörper verschachtelt war (#5197). – Agent: Das Problem, dass Konversationsaufzeichnungen verloren gingen, nachdem die Seite beim Streamen von Antworten in einfachen Agenten aktualisiert wurde, wurde behoben (#5156).

  • Agent: Ungültige Suche nach Ersteller in der Agentenliste behoben (#5177).
  • Agent: Das Problem, dass Trigger für unveröffentlichte Agenten erstellt werden konnten, wurde behoben (#5146).
  • Agent: Die abnormale Symbolanzeige von Workflow-Tools innerhalb der Skill-Tools wurde behoben. – Agent: Das Problem wurde behoben, bei dem das Aufheben der Bindung der zugehörigen Wissensdatenbank in Wissensdatenbank-Abrufknoten nicht wirksam wurde (#5173).
  • Modell: Unnormale Parameterkonfiguration der Bildgenerierungsmodelle der Volcano Engine behoben (#5089).
  • Modell: Fehler bei multimodalen Vektormodellen von Volcano Engine und unterstützten benutzerdefinierten Modellparametern behoben.
  • Modell: Die falsche Anzeigeposition der Modell-Basis-URL wurde behoben.
  • Modell: Gelegentliche NaN-Fehler beim Neuranking von Modellen behoben.

Behebung von Sicherheitslücken

  • Sicherheitslücke: Die Sicherheitslücke aufgrund fehlender Authentifizierung für Webhook-Trigger-Endpunkte wurde behoben, die es nicht authentifizierten Anfragen ermöglichte, die Autorisierung zu umgehen und beliebige Aufgaben auszulösen.

Englisches Original / English original

MaxKB v2.9.0

Highlights

  • Webhook authentication gap closed — This is the one to prioritize: Webhook trigger endpoints previously accepted unauthenticated requests, letting anyone bypass authorization and fire arbitrary tasks. If you expose webhook triggers, upgrade before anything else and rotate any tokens you relied on as the only gate. Expect callers that previously worked without credentials to start failing.

  • Agent long-term memory — A genuinely new primitive: memory is generated by conversation round and by time period, then injected into prompts through variable references. That means you can build continuity without stuffing the entire chat history into context. Watch for prompt-size and cost implications if you inject aggressively, and note there's no mention of a memory-management API here, so plan for cleanup policy on your side.

  • Workflow debugging gets practical — Nodes in advanced agents and workflow tools can now be enabled/disabled in place, so you can shield logic while debugging instead of deleting and rebuilding it. Combined with batch copy/paste — including across different loop bodies (#5128) — large orchestration canvases become far less painful to iterate on. This is a workflow-level change that speeds up development but doesn't alter runtime semantics.

  • Model layer: broader private deployment and MiniMax — Every provider now accepts a custom API Base URL, which is the real story for self-hosted or proxy setups (the "Base URL display position" fix in the changelog suggests this was fiddly before). MiniMax LLM and TTS are added directly (#4876) and via Alibaba Cloud Bailian's speech voice model (#4950). Critically, model parameter changes now propagate to all referencing resources (#5134) — good for consistency, but be aware that a single param edit can ripple across every agent and tool that uses that model.

  • Publish permission split from edit — Authorization behavior changes: publishing an advanced agent is now a distinct permission that must be granted separately. If you have editors who were implicitly able to publish, audit your role assignments after upgrading or deployments may silently stop shipping. No migration is forced, but the new capability is opt-in by configuration.

  • Advanced agent logic and dependency tracing — Judge nodes gain regex and wildcard matching (#4975), variable assignment can now explicitly set a variable to null (#4964, #5107) — important for clearing state rather than leaving stale values — and form/user-input nodes support a tree selector (#4903). Separately, associated-resource views for agents (#4859, #4872), knowledge bases, and tools give bidirectional dependency tracing, which is what you'll want before deleting or republishing shared resources. Notable stability fixes: streaming simple agents no longer lose conversation history on refresh (#5156), and nested sub-agents inside loops produce downstream output again (#5197).

No breaking changes reported in this release.

New Features

  • Agent: Added long-term memory capability. It supports generating memory by conversation rounds and time periods. Memories can be injected into prompts via variable references to improve conversation personalization and continuity.
  • Agent: Nodes in advanced agent workflows support enable/disable, allowing debugging and temporary logic shielding without deleting nodes.
  • Agent: Added associated resource viewing capability to check dependent and depended-on resources (#4859, #4872).
  • Knowledge Base: Added associated resource viewing capability with bidirectional dependency tracing.
  • Tools: Added associated resource viewing capability with bidirectional dependency tracing.
  • Tools: Nodes in workflow tools support enable/disable, allowing debugging and temporary logic shielding without deleting nodes.
  • Model: Added access support for MiniMax large language models and text-to-speech models (#4876).
  • Model: Alibaba Cloud Bailian added support for MiniMax Speech voice model access (#4950).

Feature Optimizations

  • Agent: User input and form collection nodes newly support the tree selector component (#4903).
  • Agent: The variable assignment node supports explicitly assigning a variable to null (#4964, #5107).
  • Agent: Added regular expression and wildcard matching modes for judge nodes in advanced agents (#4975).
  • Agent: Batch copy and paste is supported for nodes on the orchestration canvas of advanced agents and workflows.
  • Agent: Nodes inside loops support batch copy and paste across different loop bodies (#5128).
  • Agent: The Publish permission of advanced agents is separated independently from edit permission and can be authorized separately.
  • Agent: Added format guidelines for variable parameters of built-in nodes.
  • Model: The model selection box only displays provider icons and model names for a cleaner interface.
  • Model: All model providers support custom API Base URL to adapt to private deployment scenarios.
  • Model: Model parameter changes are automatically synchronized to all associated referenced resources (#5134).
  • Tools: ZIP installation packages uploaded for Skills tools support downloading.
  • System: Optimized browser stuttering caused by excessive file directories.
  • System: Optimized front-end stuttering when adding a large number of members to a role.

Bug Fixes

  • Agent: Fixed the issue where subsequent nodes had no output after nesting a sub-agent node in a loop body (#5197).
  • Agent: Fixed the issue that conversation records were lost after refreshing the page during streaming replies in simple agents (#5156).
  • Agent: Fixed invalid search by creator in the agent list (#5177).
  • Agent: Fixed the problem that triggers could be created for unpublished agents (#5146).
  • Agent: Fixed abnormal icon display of workflow tools inside skill tools.
  • Agent: Fixed the issue where unbinding the associated knowledge base in knowledge base retrieval nodes did not take effect (#5173).
  • Model: Fixed abnormal parameter configuration of Volcano Engine image generation models (#5089).
  • Model: Fixed errors of Volcano Engine multimodal vector models and supported custom model parameters.
  • Model: Fixed the incorrect display position of the model Base URL.
  • Model: Fixed occasional NaN errors in reranking models.

Security Vulnerability Fixes

  • Security Vulnerability: Fixed the security vulnerability of missing authentication for Webhook trigger endpoints, which allowed unauthenticated requests to bypass authorization and trigger arbitrary tasks.
