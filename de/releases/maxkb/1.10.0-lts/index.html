MaxKB v1.10.0-lts

Highlights

  • New model providers — Model settings gain four providers: SILICONFLOW (#2127) covers LLMs, vector, rearrangement (rerank), speech-recognition and image-generation models; Anthropic (#1974) adds LLMs and visual models; vLLM (#2038) adds vector and image-understanding models; Doubao (#2006) adds vector models. This materially widens model choice without changing application config — the main reason to upgrade if you were waiting on any of these backends.
  • Reasoning/thinking display — #2158 adds the ability to output the thinking process and to set custom thinking-process labels. If you run reasoning models (e.g. DeepSeek-style) and want that chain-of-thought surfaced and branded in the UI, this is the headline feature; otherwise it's inert.
  • Voice and internationalization — Hands-free support arrives via automatic sending of voice input and automatic voice playback (#1971), plus per-Q&A-page language settings (#2011). System-wide language switching (#2011) ships with simplified Chinese, traditional Chinese and English — relevant for deployments serving non-Chinese or mixed-language users.
  • Robustness and UX fixes — Right-click to quote/copy AI replies (#2005) and better uploaded-file styling (#2061); fixes for offline-file uploads with filenames >128 characters (#1962), opening remarks >4096 characters (#2075), application subnode parameters not updating in real time (#1962), uploaded documents becoming unreadable after starting a new conversation, and truncated X-Pack replies in WeChat for Business. Mostly quality-of-life, but the >128-char and >4096-char crashes are real blockers if you hit them.
  • Breaking changes / upgrade guidance — No breaking changes or migration steps are documented in this release; this is a genuine feature-bearing v1.10.0-lts tag, not a no-op, re-tag or metadata-only update. Upgrade if you need the new providers, thinking display, i18n or voice, or if you're hitting the fixed length/encoding bugs; since it's an LTS release,稳定性的 argument favors moving, but teams on a stable earlier version with none of these needs can safely skip.
