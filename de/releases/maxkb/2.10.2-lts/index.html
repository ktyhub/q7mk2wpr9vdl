MaxKB v2.10.2-lts

Funktionsoptimierungen

  • Q&A-Seite: Spracheingabelogik optimiert, um transkribierten Text anzuhängen, anstatt vorhandenen Eingabeinhalt zu überschreiben (#6212);
  • Q&A-Seite: Funktion zum Löschen von Eingabeinhalten hinzugefügt, nachdem Benutzer Inhalte in das Eingabefeld eingegeben haben (#6212);
  • Q&A-Seite: Benutzer können normalerweise neue Fragen senden, nachdem sie zu Sitzung 2 gewechselt haben, während Sitzung 1 Antworten generiert;
  • Agent: Über Formulare übermittelte Dateien können aus Konversationsprotokollen heruntergeladen werden (#5271);
  • Agent: Die sendMessage-Methode im html_render-Tag der erweiterten Agenten-Eröffnungsbemerkungen unterstützt die Übergabe von API-Parametern und Benutzereingabeparametern;
  • Agent: Anzeige von Tool-Quelleninformationen im Betriebsmenü von Tool-Knoten für erweiterte Agenten hinzugefügt;
  • Agent (X-Pack): Berechtigungssteuerungskonfiguration für die Konversationsfreigabe in den Anzeigeeinstellungen hinzugefügt;
  • Agent (X-Pack): Geben Sie „/new“ ein, um automatisch eine brandneue Konversation für Anwendungsintegrationen von Drittanbietern zu erstellen;
  • Wissensdatenbank: Spalten in der Dokumentliste unterstützen die manuelle Breitenanpassung;
  • Wissensdatenbank: Der Dokumentenliste wurde ein Erstellerfeld hinzugefügt, und der Ersteller neu hochgeladener Dokumente wird aufgezeichnet (#5240);
  • Wissensdatenbank: Es wurden zwei Exportmodi bereitgestellt, mit denen Benutzer auswählen können, ob beim Exportieren einer Wissensdatenbank Originalquelldateien exportiert werden sollen (#6137);
  • Wissensdatenbank: Optimierte Paginierungslogik für die Tag-Verwaltung, um Frontend-Verzögerungen zu verhindern, die durch übermäßige Daten unter einem einzelnen Tag verursacht werden;
  • Modelle: Unterstützung für das Bildgenerierungsmodell Imagen unter dem Gemini-Anbieter hinzugefügt (#5234);
  • Modelle: Unterstützung für das VEO-Videogenerierungsmodell unter dem Gemini-Anbieter hinzugefügt (#5234);
  • Modelle: Die Modell-Dropdown-Liste aller Modellanbieter wurde aktualisiert, um die neuesten Modelle anzuzeigen;
  • Berechtigungsverwaltung: Benutzern, die nur über die Berechtigung zur Werkzeugansicht verfügen, ist der Zugriff auf die Werkzeugbearbeitungsseite untersagt.
  • Workspace (X-Pack): Optimierte Lazy-Loading-Leistung der Workspace-Liste.

Fehlerbehebungen

  • Q&A-Seite: Das Problem wurde behoben, dass die Anzeige des Knotenausführungsfortschritts nicht durch den Umschalter für die Ausführungsdetails gesteuert wurde;
  • Q&A-Seite: Fortschritt der Knotenausführung ausblenden, wenn die KI-Antwort angehalten wird, und Anzeige des Fortschritts nach clicking „Fortfahren“ wieder aufnehmen;
  • Agent (X-Pack): Fehler bei der Vorschau von PDF-Dateien aus Wissensquellen in integrierten Konversationen von Drittanbietern behoben (#6202);
  • Tools: Die fehlende Pflichtfeldmarkierung für das Namenseingabefeld beim Erstellen eines neuen MCP-Tools wurde behoben;
  • Knowledge Base: Beschädigte heruntergeladene DOCX-Quelldateien nach dem Upgrade von v2.3.1 auf v2.10.1 behoben (#6238);
  • Knowledge Base: Ausführungsfehler behoben, die vom Write-to-Knowledge-Base-Knoten beim Workflow-Debuggen ausgelöst wurden;
  • Modelle: Fehler beim Hinzufügen des qwen3-tts-flash-Modells vom Alibaba Cloud Bailian-Anbieter behoben (#6236);
  • Anmeldeeinstellungen: Die Sicherheitslücke wurde behoben, die es Benutzern der Community Edition ermöglichte, sich ohne Captcha-Überprüfung anzumelden (#6214).

Englisches Original / English original

MaxKB v2.10.2-lts

Highlights

  • Conversational UX and multi-session reliability — Voice input now appends to the existing draft instead of overwriting it and a clear-input control was added (#6212), while users can switch sessions and send new questions even while a previous session is still streaming. Node-execution progress is finally gated by the detail toggle and hidden while a reply is paused. For developers this removes the race conditions that made chat-state handling brittle — expect fewer "lost input" reports and more predictable streaming behavior in embedded Q&A flows.

  • Agent extensibility and third-party integrations — The html_render tag's sendMessage now accepts both API parameters and user-input parameters, form-submitted files are retrievable from conversation logs (#5271), tool nodes expose source information, and X-Pack adds a /new shortcut to force a fresh conversation plus a fix for knowledge-source PDF previews in integrated chats (#6202). These are the hooks integrators actually depend on: parameterized sendMessage and reliable file/PDF handling close long-standing gaps for embedded agents.

  • Knowledge Base data integrity and export control — A bug that corrupted downloaded DOCX source files after upgrading from v2.3.1 to v2.10.1 (#6238) is fixed — critical if you upgraded through that range and redistributed exported sources. Exports now let you choose whether to include original source files (#6137), document lists record an uploaded-by creator (#5240), and tag pagination was reworked to prevent frontend freezes on heavily populated tags.

  • Model provider coverage — Gemini gains Imagen (image) and VEO (video) generation (#5234), all provider dropdowns are refreshed with current models, and a broken qwen3-tts-flash add from Alibaba Cloud Bailian (#6236) is repaired. If you depend on multimodal generation or Bailian TTS this unblocks previously failing configurations — but note the Gemini additions are generation models, so validate credentials and quota before rolling out.

  • Security and permission hardening — A vulnerability that let Community Edition users log in without captcha verification (#6214) is patched, view-only tool permissions no longer grant access to the editing page, and X-Pack adds conversation-sharing permission controls. This is the highest-priority item for public-facing deployments: verify captcha enforcement after upgrading and audit accounts that may have relied on the permissive behavior.

No breaking changes are noted in this release.

Feature Optimizations

  • Q&A Page: Optimized voice input logic to append transcribed text instead of overwriting existing input content (#6212);
  • Q&A Page: Added a clear input content function after users type content in the input box (#6212);
  • Q&A Page: Users can normally send new questions after switching to Session 2 while Session 1 is generating replies;
  • Agent: Files submitted via forms can be downloaded from conversation logs (#5271);
  • Agent: The sendMessage method in the html_render tag of advanced agent opening remarks supports passing API parameters and user input parameters;
  • Agent: Added tool source information display in the operation menu of tool nodes for advanced agents;
  • Agent (X-Pack): Added permission control configuration for conversation sharing in display settings;
  • Agent (X-Pack): Input "/new" to automatically create a brand-new conversation for third-party application integrations;
  • Knowledge Base: Columns in the document list support manual width adjustment;
  • Knowledge Base: Added a creator field to the document list, and the creator of newly uploaded documents will be recorded (#5240);
  • Knowledge Base: Provided two export modes allowing users to choose whether to export original source files when exporting a knowledge base (#6137);
  • Knowledge Base: Optimized pagination logic for tag management to prevent frontend lag caused by excessive data under a single tag;
  • Models: Added support for the Imagen image generation model under the Gemini provider (#5234);
  • Models: Added support for the VEO video generation model under the Gemini provider (#5234);
  • Models: Updated the model dropdown list of all model providers to show the latest models;
  • Permission Management: Users who only have tool view permission are prohibited from accessing the tool editing page;
  • Workspace (X-Pack): Optimized lazy loading performance of the workspace list.

Bug Fixes

  • Q&A Page: Fixed the issue that the display of node execution progress was not controlled by the execution detail toggle switch;
  • Q&A Page: Hide node execution progress when AI reply is paused, and resume displaying progress after clicking Continue;
  • Agent (X-Pack): Fixed the failure to preview PDF files from knowledge sources in third-party integrated conversations (#6202);
  • Tools: Fixed the missing required field marker for the name input box when creating a new MCP tool;
  • Knowledge Base: Fixed corrupted downloaded DOCX source files after upgrading from v2.3.1 to v2.10.1 (#6238);
  • Knowledge Base: Fixed execution errors thrown by the Write-to-Knowledge-Base node during workflow debugging;
  • Models: Fixed errors when adding the qwen3-tts-flash model from Alibaba Cloud Bailian provider (#6236);
  • Login Settings: Fixed the vulnerability allowing Community Edition users to log in without captcha verification (#6214).
