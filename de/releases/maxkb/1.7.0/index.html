  • Modelleinstellungen: Unterstützt das Abfragen von Modellen nach Modelltyp, Ersteller und Berechtigungen; von @liuruibin in https://github.com/1Panel-dev/MaxKB/pull/1358

  • Wissensdatenbank: Das Problem wurde behoben, bei dem Textinhalte nicht angezeigt wurden, wenn MarkDown-Flussdiagramme in Wissensdatenbanksegmente eingefügt wurden.
  • Anwendung: Das Problem, dass beim Zugriff auf Unternehmens-WeChat zum Stellen von Fragen keine Antwort erfolgte, wenn das von der Anwendung verwendete Modell das Beanbao-Agentenmodell ist, wurde behoben. von @wxg0103 in https://github.com/1Panel-dev/MaxKB/pull/1425
  • Anwendung: Das Problem wurde behoben, bei dem die Anzeige der Benutzeroberfläche gestört war, wenn der Dateiname des Referenzsegments der Wissensquelle zu lang war.
  • Anwendung: Das Problem wurde behoben, dass beim Stellen von Fragen im verbundenen offiziellen Konto das Bild nicht zurückgegeben werden konnte, wenn der Antwortinhalt Textinhalte hinter dem Bild enthielt. (X-Pack)
  • Modellverwaltung: Das Problem wurde behoben, dass beim Hinzufügen eines Xinference-Modells das Modell nicht hinzugefügt werden konnte, wenn der Modellname und die ID inkonsistent waren. von @wxg0103 in https://github.com/1Panel-dev/MaxKB/pull/1390 – Modellverwaltung: Das Problem wurde behoben, bei dem beim Hinzufügen eines Xinference-Modells keine Authentifizierungsparameter übergeben wurden, was zu einer Meldung führte, dass der API-Domänenname ungültig sei. von @dolphinlife in https://github.com/1Panel-dev/MaxKB/pull/1334

MaxKB v1.7.0

Highlights

  • 应用编排能力显著增强 — 工作流节点现支持多进多出；高级编排应用可启用自动保存，默认每 5 分钟保存一次，但该设置默认关闭。历史版本查看与恢复、组件按名称搜索及导出时保留知识库检索引用数据，也让复杂应用的维护和迁移更可靠。值得依赖复杂工作流或多人维护应用的用户升级。

  • 模型与语音配置覆盖扩大 — 新增阿里云百炼、Amazon Bedrock、腾讯混元、讯飞星火、百度千帆的向量模型支持，并为阿里云百炼和 Xinference 增加语音识别、语音合成模型支持。用户还可以自定义大语言模型和语音合成参数，并设置语音播放的声音与语速。使用这些供应商或语音交互功能的用户应优先升级。

  • 企业集成与问答控制更完善 — X-Pack 新增问答页面个性化显示、身份验证，以及企业微信、钉钉、飞书扫码登录，适合需要控制访问和统一身份认证的团队。对话日志清除策略也有助于管理存储与隐私；未使用 X-Pack 或这些企业能力的用户可跳过这部分收益。

  • 多处影响实际使用的缺陷得到修复 — 修复了 PDF 高级分段长度不生效、DOCX 图片导入失败、文档图片缺失导致回复异常、空知识库导出文件打不开，以及豆包智能体在企业微信不回复等问题。正在使用 PDF 高级分段、DOCX、企业微信或 Xinference 的用户升级收益尤其明确。

  • 未列出破坏性变更或强制迁移步骤 — 更新日志没有明确标注不兼容变更；主要行为变化是自动保存默认关闭，以及基础节点全局变量改为“用户输入”和“接口传参”两个参数表单。现有基础节点用户应检查配置是否符合新表单结构。若当前功能稳定且不涉及上述新增供应商、编排或企业能力，可以暂缓升级。
