faiss v1.9.0

Hinzugefügt

  • AVX-512-Implementierung für die Distanz- und Skalarquantisierungsfunktionen hinzufügen. (#3853)
  • K- und M-Suffixe in IVF-Indizes zulassen (#3812)
  • Rekonstruktionsunterstützung für additive Quantisierer hinzugefügt (#3752)
  • Einführung von Optionen zur Reduzierung des Overheads für ein Clustering-Verfahren (#3731) – HNSW-Suchparameter für die Option „Begrenzte Warteschlange“ hinzugefügt (#3748)
  • ROCm-Unterstützung (#3462)
  • SVE-Ziele hinzufügen (#2886)
  • get_version() für c_api hinzufügen (#3688)
  • QINCo-Implementierung in CPU Faiss (#3608)
  • Suchfunktion zu FlatCodes hinzufügen (#3611)
  • Dispatcher für VectorDistance und ResultHandlers hinzufügen (#3627)
  • SQ8bit-Signed-Quantisierung hinzufügen (#3501) – ABS_INNER_PRODUCT-Metrik hinzufügen (#3524)
  • Interop zwischen CAGRA und HNSW (#3252)
  • Flag „skip_storage“ zu HNSW hinzufügen (#3487)
  • QT_bf16 für Skalarquantisierer für bfloat16 (#3444)
  • Implementieren Sie METRIC.NaNEuclidean (#3414)
  • TimeoutCallback C++ und Python (#3417)
  • Unterstützung von Big-Endian-Maschinen (#3361) – Unterstützung für das Entfernen von IDs aus dem IVFPQFastScan-Index (#3354) – Implementieren Sie reconstruct_n für GPU-IVFFlat-Indizes (#3338)
  • Unterstützung von skip_ids in der merge_from_multiple-Funktion von OnDiskInvertedLists (#3327) – Fügen Sie die Möglichkeit hinzu, binäre Indizes zum C API zu klonen und zu lesen. (#3318)
  • AVX512 für PQFastScan (#3276)

Geändert

  • Schnelleres HNSW-CPU-Index-Training (#3822)
  • Einige kleine Verbesserungen. (#3692) – Erster Versuch eines LSH-Matchings mit nbits (#3679)
  • Verbosoe vor Zug setzen (#3619) – Entfernen Sie doppelte NegativeDistanceComputer-Instanzen (#3450)
  • Interrupt für NNDescent (#3432) – Überflüssige Anweisungen in ScalarQuantizer entfernen (#3430)
  • PowerPC, Codegenerierung für Funktion fvec_L2sqr verbessern (#3416)
  • Schleife in „lookup_2_lanes“ abrollen (#3364)
  • Filterung und Weitergabe von Suchparametern verbessert (#3304) – Ändern Sie index_cpu_to_gpu, um für Indizes zu werfen, die nicht auf der GPU implementiert sind (#3336)
  • Fehler beim Versuch, IndexPQ auf die GPU zu verschieben (#3328) – HNSWPQ sdc init mit neuem IO-Flag überspringen (#3250)

Behoben

  • Behebung eines Fehlers für einen Nicht-Simdlib-Code von ResidualQuantizer (#3868) – „assign_index“ sollte standardmäßig null sein (#3855) – Behebung einer falsch gezählten Anzahl berechneter Distanzen für HNSW (#3840)
  • Fehler für überlaufende Nbits während der PQ-Erstellung hinzugefügt (#3833)
  • Umkreissuche mit HSNW und IP behoben (#3698)
  • Algorithmus zur Verteilung von Vektoren über Shards korrigiert (#3374) – Korrektur der IndexBinary.assign Python-Methode (#3384) – Einige Korrekturen in bench_fw, um IndexFromCodec zu aktivieren (#3383) – Behebung des Endianness-Problems in AIX beim Ausführen des Benchmarks. (#3345)
  • Faiss-Swig-Build mit Version > 4.2.x behoben (#3315)
  • Beheben Sie Probleme bei der Verwendung von 64-Bit-Ganzzahlen. (#3322) – Korrektur der IVFPQFastScan-Dekodierungsfunktion (#3312)
  • Behandlung von FaissException in einigen Destruktoren von ResultHandler.h (#3311)
  • HNSW-Statistiken korrigiert (#3309) – AIX-Kompilierungskorrektur für io-Klassen (#3275)

Englisches Original / English original

faiss v1.9.0

Added

  • Add AVX-512 implementation for the distance and scalar quantizer functions. (#3853)
  • Allow k and M suffixes in IVF indexes (#3812)
  • add reconstruct support to additive quantizers (#3752)
  • introduce options for reducing the overhead for a clustering procedure (#3731)
  • Add hnsw search params for bounded queue option (#3748)
  • ROCm support (#3462)
  • Add sve targets (#2886)
  • add get_version() for c_api (#3688)
  • QINCo implementation in CPU Faiss (#3608)
  • Add search functionality to FlatCodes (#3611)
  • add dispatcher for VectorDistance and ResultHandlers (#3627)
  • Add SQ8bit signed quantization (#3501)
  • Add ABS_INNER_PRODUCT metric (#3524)
  • Interop between CAGRA and HNSW (#3252)
  • add skip_storage flag to HNSW (#3487)
  • QT_bf16 for scalar quantizer for bfloat16 (#3444)
  • Implement METRIC.NaNEuclidean (#3414)
  • TimeoutCallback C++ and Python (#3417)
  • support big-endian machines (#3361)
  • Support for Remove ids from IVFPQFastScan index (#3354)
  • Implement reconstruct_n for GPU IVFFlat indexes (#3338)
  • Support of skip_ids in merge_from_multiple function of OnDiskInvertedLists (#3327)
  • Add the ability to clone and read binary indexes to the C API. (#3318)
  • AVX512 for PQFastScan (#3276)

Changed

  • faster hnsw CPU index training (#3822)
  • Some small improvements. (#3692)
  • First attempt at LSH matching with nbits (#3679)
  • Set verbosoe before train (#3619)
  • Remove duplicate NegativeDistanceComputer instances (#3450)
  • interrupt for NNDescent (#3432)
  • Get rid of redundant instructions in ScalarQuantizer (#3430)
  • PowerPC, improve code generation for function fvec_L2sqr (#3416)
  • Unroll loop in lookup_2_lanes (#3364)
  • Improve filtering & search parameters propagation (#3304)
  • Change index_cpu_to_gpu to throw for indices not implemented on GPU (#3336)
  • Throw when attempting to move IndexPQ to GPU (#3328)
  • Skip HNSWPQ sdc init with new io flag (#3250)

Fixed

  • FIx a bug for a non-simdlib code of ResidualQuantizer (#3868)
  • assign_index should default to null (#3855)
  • Fix an incorrectly counted the number of computed distances for HNSW (#3840)
  • Add error for overflowing nbits during PQ construction (#3833)
  • Fix radius search with HSNW and IP (#3698)
  • fix algorithm of spreading vectors over shards (#3374)
  • Fix IndexBinary.assign Python method (#3384)
  • Few fixes in bench_fw to enable IndexFromCodec (#3383)
  • Fix the endianness issue in AIX while running the benchmark. (#3345)
  • Fix faiss swig build with version > 4.2.x (#3315)
  • Fix problems when using 64-bit integers. (#3322)
  • Fix IVFPQFastScan decode function (#3312)
  • Handling FaissException in few destructors of ResultHandler.h (#3311)
  • Fix HNSW stats (#3309)
  • AIX compilation fix for io classes (#3275)
