Funktionsaktualisierungen

– Artefakt-Panels zeigen jetzt alle Artefakte an, auf die Sie im aktuellen Bereich zugreifen können, mit Ersteller- und Projektfiltern, einer Suchleiste, die beim Scrollen sichtbar bleibt, Projektbeschriftungen und kompakten Zeilen mit Miniaturansichten. Filterauswahlen werden in allen Projektfenstern im selben Browser gespeichert.

  • Laden Sie freigegebene Artefakte direkt aus dem Browser-Viewer oder mit „teable artifact get“ herunter. Empfänger können nur die aktuell freigegebene Version herunterladen und passwortgeschützte Freigaben müssen im Browser geöffnet werden.

Fehlerbehebungen und Verbesserungen

– Kopierte, importierte oder vorlagenbasierte Workflows fordern Benutzer jetzt auf, ein Konto zu verbinden, wenn ein Connector-Trigger dies erfordert.

  • Routinemäßige Duplizierung und Konfigurationsveröffentlichung sind zuverlässiger. Duplizierte Routinen werden erst angezeigt, nachdem die Einrichtung abgeschlossen ist. – Verbesserte Berechtigungsdurchsetzung für Massenaktualisierungen von Datensätzen.
  • Verbesserte Stabilität der Zusammenarbeit in Echtzeit und weniger wiederholte erneute Verbindungen nach Verbindungsunterbrechungen. – Falsche Fehlerbanner in Artefaktvorschauen, die Browserspeicher verwenden, wurden behoben. Speicherdaten bleiben verfügbar, solange die Vorschau geöffnet ist. – Aktualisierte CLI- und App Builder-Anleitung, um „Teable Record Get“ zum Durchsuchen und „Teable Query“ zum Filtern und gruppierte Zusammenfassungen zu empfehlen. In der Anleitung wird erläutert, wie mit Abfragefehlern umgegangen wird und wann schreibgeschütztes SQL verwendet werden sollte. – Beim Löschen einer App, auch über ihren Ordner, werden jetzt alle aktiv generierten Apps aufgelistet und vor dem Unterbrechen um Bestätigung gebeten. Beim Abbrechen bleibt die Arbeit bestehen. Durch das Löschen eines Projekts, Spaces oder Kontos werden auch die damit verbundenen Generierungen und in der Warteschlange befindlichen Versendungen gestoppt. – Verbesserte Sitzungszuverlässigkeit, damit aktive Benutzer angemeldet bleiben. – Workflow-Schaltflächen zeigen jetzt eine lokalisierte Meldung an und überspringen die Aktion, wenn ein Datensatz den Auslöserfilter nicht erfüllt, auch in freigegebenen Ansichten. – Numerische SWITCH-Fälle wurden korrigiert, sodass sie in Formelfeldern und strukturierten Abfragen nach Wert übereinstimmen, anstatt fälschlicherweise das Standardergebnis zurückzugeben.

teable release.2026-11-19T10-43-10Z.3988

Feature Updates

  • Artifact panels now show all artifacts you can access in the current space, with creator and project filters, a search bar that stays visible as you scroll, project labels, and compact rows with thumbnails. Filter selections are remembered across project panels in the same browser.
  • Download shared artifacts directly from the browser viewer or with teable artifact get. Recipients can download only the currently shared version, and password-protected shares must be opened in the browser.

Bug Fixes & Improvements

  • Copied, imported, or template-based workflows now prompt users to connect an account when a connector trigger requires one.
  • Routine duplication and configuration publishing are more reliable. Duplicated routines appear only after setup is complete.
  • Improved permission enforcement for bulk record updates.
  • Improved real-time collaboration stability and reduced repeated reconnects after connection interruptions.
  • Fixed false error banners in artifact previews that use browser storage. Storage data remains available while the preview is open.
  • Updated CLI and App Builder guidance to recommend teable record get for browsing and teable query for filtering and grouped summaries. The guidance explains how to handle query errors and when to use read-only SQL.
  • Deleting an app, including through its folder, now lists any apps that are actively generating and asks for confirmation before interrupting them. Canceling leaves the work running. Deleting a project, space, or account also stops related generation and queued sends.
  • Improved session reliability to help active users stay signed in.
  • Workflow buttons now show a localized message and skip the action when a record does not meet the trigger filter, including in shared views.
  • Fixed numeric SWITCH cases so they match by value in formula fields and structured queries instead of incorrectly returning the default result.
