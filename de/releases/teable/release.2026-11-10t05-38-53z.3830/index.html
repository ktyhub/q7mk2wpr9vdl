Funktionsaktualisierungen

– Filterbasierte Aktualisierungen wenden dieselben Werte auf alle übereinstimmenden Datensätze an und werten Filterbedingungen aus, wenn die Aktualisierung ausgeführt wird. Aktualisierungen, die auch Änderungen an Beziehungen erfordern, müssen weiterhin datensatzbasierte Aktualisierungen verwenden.

  • JWT-Anmeldeinformationen können jetzt nach App- oder Projektnamen oder -ID gesucht werden. Massenvorgänge sind auf Apps beschränkt, die der aktuellen Suche und den aktuellen Filtern entsprechen. – Veröffentlichte Apps können jetzt mit neuen Anmeldeinformationen aktualisiert werden, während ihr zuletzt veröffentlichter Code und ihre Anmeldekonfiguration beibehalten werden. Apps mit abgelaufenen Produktionsanmeldeinformationen werden jetzt von Apps unterschieden, deren Aktualisierung fehlgeschlagen ist. – Standard-Pi-Sitzungen unterstützen jetzt strukturierte Abfragen für Datensatzlisten, Aggregationen und zeitbasierte Gruppierung. Folgeanfragen können Abfrageparameter anpassen und nicht unterstützte Anfragen geben eindeutigere Fehlermeldungen zurück.

Fehlerbehebungen und Verbesserungen

  • Passwortänderungen lehnen jetzt ein neues Passwort ab, das mit dem aktuellen Passwort übereinstimmt, wodurch irreführende Erfolgsmeldungen und unnötige Abmeldungen verhindert werden.
  • Durch das Aktualisieren der Chat-Seite werden Registerkarten für Tabellen, die durch Rollenberechtigungsaktualisierungen ausgeblendet wurden, nicht mehr wiederhergestellt, wodurch falsche Ressourcenzugriffsbeschränkungen und Meldungen „Tabelle gelöscht“ verhindert werden.
  • Gesperrte Rasteransichten verhindern jetzt das Ziehen von Spalten, das Ändern der Spaltengröße und das Einfrieren von Spalten. Persönliche Ansichten können weiterhin bearbeitet werden. – Automatisierungen, die durch neu installierte Vorlagen aktiviert werden, aktivieren nun korrekt geplante Auslöser und E-Mail-Empfangsauslöser. – Es wurde ein Problem behoben, bei dem eingefügter Text, der mit dem Kleinbuchstaben „rec“ begann (z. B. „recipe“ oder „record“), in einzeiligen Textfeldern falsch gespeichert wurde. Bei großen Batch- und Streaming-Einfügevorgängen bleibt nun auch Text konsistent erhalten; Zuvor beschädigte Werte werden nicht automatisch wiederhergestellt. – Verbesserte Sicherheit und Zuverlässigkeit der Anmeldeinformationseinstellungen, Verwaltung, Freigabe und dauerhaften Löschung.
  • Verbesserte Ressourcentitelleisten, Symbolleistenbeschriftungen und Ansichtslisten, um Aktionen und aktuelle, markierte, gesperrte und ziehbare Zustände leichter zu unterscheiden. – Freigabe- und CSV-Exportvorgänge gelten jetzt für die ausgewählte Ansicht und nicht für die aktuell geöffnete Ansicht, einschließlich Vorgängen, die über klassische Ansichtsregisterkarten initiiert werden.
  • Konsolidierte App-Einstellungsaktionen und verbessertes Menüverhalten für Anmeldekonfiguration, GitHub-Integration und Versionsverlauf. – Fehlende Ansichtsinformationen beim Erstellen, Konvertieren, Ändern des verknüpften Ziels oder Entfernen bidirektional verknüpfter Datensatzfelder behoben. Gegenseitig verknüpfte Felder sorgen jetzt für eine konsistente Sichtbarkeit und Reihenfolge, mit verbesserter Zuverlässigkeit für Selbstverknüpfungen, verknüpfte Tabellen und Rückgängig/Wiederholen. – Die ausgeblendeten und sichtbaren Feldfelder unterstützen jetzt eine zuverlässige Neuanordnung per Drag-and-Drop, wobei die Reihenfolge nach der Aktualisierung erhalten bleibt. Es wurde ein Absturz behoben, der durch die Neuordnung von Feldern in Tabellen- und Kanban-Ansichten verursacht wurde, bevor die Ansichtsinformationen vollständig geladen waren.

teable release.2026-11-10T05-38-53Z.3830

Feature Updates

  • Filter-based updates apply the same values to all matching records and evaluate filter conditions when the update runs. Updates that also require changes to relationships must still use record-based updates.
  • JWT credentials can now be searched by app or project name or ID. Bulk operations are limited to apps that match the current search and filters.
  • Published apps can now be refreshed with new credentials while retaining their last published code and login configuration. Apps with expired production credentials are now distinguished from apps whose refresh failed.
  • Default Pi sessions now support structured queries for record lists, aggregations, and time-based grouping. Follow-up requests can adjust query parameters, and unsupported requests return clearer error messages.

Bug Fixes & Improvements

  • Password changes now reject a new password that matches the current password, preventing misleading success messages and unnecessary sign-outs.
  • Refreshing the chat page no longer restores tabs for tables hidden by role permission updates, preventing incorrect resource access restriction and “Table deleted” messages.
  • Locked Grid views now prevent column dragging, column resizing, and column freezing. Personal views remain editable.
  • Automations enabled by newly installed templates now correctly activate scheduled triggers and email receipt triggers.
  • Fixed an issue where pasted text beginning with lowercase “rec” (such as “recipe” or “record”) was saved incorrectly in Single line text fields. Large-batch and streaming paste operations now also preserve text consistently; previously corrupted values will not be restored automatically.
  • Improved the security and reliability of credential settings, management, sharing, and permanent deletion.
  • Improved resource title bars, toolbar labels, and view lists to make actions and current, starred, locked, and draggable states easier to distinguish.
  • Sharing and CSV export operations now apply to the selected view rather than the currently open view, including operations initiated from classic view tabs.
  • Consolidated app settings actions and improved menu behavior for login configuration, GitHub integration, and version history.
  • Fixed missing view information when creating, converting, changing the linked target of, or removing two-way linked record fields. Reciprocal linked fields now maintain consistent visibility and ordering, with improved reliability for self-links, linked tables, and undo/redo.
  • The hidden and visible field panels now support reliable drag-and-drop reordering, with the order preserved after refreshing. Fixed a crash caused by reordering fields in Grid and Kanban views before view information had finished loading.
