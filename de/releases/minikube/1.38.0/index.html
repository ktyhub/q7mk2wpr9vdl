minikube v1.38.0

📣😀 Bitte füllen Sie unsere schnelle 5-Fragen-Umfrage aus, damit wir erfahren, wie und warum Sie Minikube verwenden und welche Verbesserungen wir vornehmen sollten. Danke schön! 💃🎉

Release Notes

Version 1.38.0 – 28.01.2026

Höhepunkte

  • Kein Sudo erforderlich für vfkit/krunkit unter macOS 26+ (erfordert den neuesten vmnet-helper)
  • Kein Sudo erforderlich, um [AI Playground auf MacOS-GPUs mit Minikube] auszuführen (https://minikube.sigs.k8s.io/docs/tutorials/ai-playground/)
  • vfkit: Rosetta-Unterstützung für die Bereitstellung von amd64-Images auf Apple-Chips hinzugefügt (#22140)

Funktionen

  • Unterstützung für Kubernetes v1.35.0 (#21650)(#22015)(#22119)(#22328) hinzufügen
  • VM-Treiber: Unterstützung für NVMe-oF/TCP-Blockgeräte hinzufügen (#22464)
  • VM-Treiber: BTF-Debugsymbole aktivieren, um eBPF-Tools in ISO zu unterstützen (#21800)
  • Option zum Herunterladen von Preloads von github anstelle von GCS über --preload-source hinzugefügt (#22221)
  • Vfkit/Krunkit-Treiber: Möglichkeit hinzugefügt, vmnet-helper als unprivilegierter Benutzer unter macOS 26+ auszuführen (#22501)
  • Option zum Hinzufügen von Helm-basierten Add-ons hinzugefügt (#21847)
  • Vorab laden: Download von github, wenn GCS nicht verfügbar ist (#21605)

Warnungen und Abwertungen

  • Benutzeroberfläche: Warnung beim Ändern der Standardlaufzeit in „containerd“ in der nächsten Version hinzugefügt (v1.39.0) (#22508)
  • Hyperkit: Treiber-Builds entfernen und Benutzer zum Wechseln warnen (#21946)
  • Minikube-Unterstützung für 32-Bit-Architekturen entfernen (#22401)

Verbesserungen

  • Benutzeroberfläche: bunt basierend auf dem Status (Profilliste, Add-On-Liste) (#22418)
  • Caching-Binärdateien überspringen, wenn --no-kubernetes gesetzt ist (#21139)
  • Wiederholungsprotokolle verbessern, um weniger doppelte Zeilen zu drucken (#22232)
  • SSH-Runner beim Kopieren von Zertifikatsdateien verbessern (#21923)
  • vmnet: Validierung im Nur-Download-Modus überspringen (#21635)
  • Windows-Zertifikat in kubeconfig verbessern: generierte Zertifikatspfade normalisieren, um Schrägstriche weiterzuleiten (#21845)
  • cgroup v2 Freezer-Check für API-Serverstatus hinzugefügt (#22249)
  • Legen Sie die Kubelet-Option FailCgroupV1 für Kubenetes 1.35+ fest, wenn cgroup v1 (#22319)
  • containerd: Wiederholen Sie den Versuch bei vorübergehenden EOF-Fehlern beim Laden des Bildes (#22310)
  • cri: Standard-Timeout für Crictl-Befehle auf 2 Sekunden erhöhen (#22214)
  • crio: Überprüfen Sie, ob Bilder nach „image rm“ gelöscht werden (#22243)
  • docker-Laufzeit: CRI für ListImages-Funktion verwenden (#22263)
  • Bildspeicherung: Wiederholungslogik für lokales Bild im Falle von EOF hinzugefügt (#22072)
  • HA (Multi-Control-Ebene): kube-vip von v1.0.0 auf v1.0.3 aktualisieren (#21699)(#21960)(#22258)

Treiber

  • Hyperkit-Treiber: Dateideskriptorlecks im Status behoben (#22524)
  • kvm: Minikube auf Fedora/RHEL mit SELinux reparieren (#21550)
  • kvm: Abhängigkeit von externem Treiber entfernen (#21625)

Higlights

  • No Sudo required for vfkit/krunkit on macOS 26+ (requires latest vmnet-helper)

  • VM Drivers: add support for NVMe-oF/TCP block devices (#22464)
