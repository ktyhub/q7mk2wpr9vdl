Roo-Code v3.48.0

Highlights

  • Broader model coverage — Claude Sonnet 4.6 is available through Anthropic, Bedrock, Vertex, OpenRouter, and Vercel AI Gateway (#11509), while GLM-5 arrives on Z.ai (#11440). The CLI default also moves from Opus 4.5 to Opus 4.6 (#11273), so review pinned configurations before upgrading.
  • Breaking feature removals — Browser use, built-in skills and their loading mechanism, and file-based system-prompt overrides are removed (#11392, #11414, #11387). Audit workflows that depend on browser automation or external prompt/skill injection; these capabilities cannot simply be re-enabled after upgrading.
  • Provider and tool migrations — Nine low-usage providers are removed, with retired-provider UX added (#11297); affected profiles must move to supported providers. search_and_replace becomes edit (#11296), requiring updates to custom prompts and tool references. The new disabledTools setting provides a global native-tool kill switch (#11277).
  • CLI defaults favor automation — Stdin streaming (#11476), Linux ARM64 support (#11314), and IPC queries for commands, modes, and models (#11279) strengthen pipeline integration. Auto-approval is now enabled by default (#11424), so CI users who require confirmation must explicitly opt into require-approval.
  • Delegated and resumed tasks retain more context — Fixes address parent-state loss, delegation races, and concurrent taskHistory writes (#11281, #11331, #11335). Condensation summaries now survive resume (#11487, #11488), and delegation-aware cleanup prevents orphaned parent tasks (#11302)—important for long-running, multi-step workflows.
  • Execution and configuration safeguards — Disabling auto-approve now cancels its backend countdown (#11439), while command inspection reduces inline-JS and zsh false positives (#11382, #11365). Custom getModelParams callers must now supply defaultTemperature (#11218): a required code change that prevents silent temperature overrides.
