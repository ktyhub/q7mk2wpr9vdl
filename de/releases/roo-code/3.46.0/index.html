  • Fügen Sie AI SDK-Abhängigkeiten und Nachrichtenkonvertierungsdienstprogramme hinzu (PR #11047 von @daniel-lxs) – React-Compiler-Integration zur Webview-UI für automatische Memoisierung und Leistungsverbesserungen hinzugefügt (#9916 von @In-line, PR #9565 von @In-line)
  • Fix: Einbeziehen reservierter Ausgabetokens in die Berechnung des Task-Header-Prozentsatzes (PR #11034 von @app/roomote)
  • Fix: Berechnen Sie den Header-Prozentsatz basierend auf dem verfügbaren Eingaberaum (PR #11054 von @app/roomote)
  • Fix: Zeitreisefehler beim parallelen Tool-Aufruf verhindern (PR #11046 von @daniel-lxs) – Dokumente: Klarstellen, dass der Suchparameter read_command_output weggelassen werden sollte, wenn nicht gefiltert wird (PR #11056 von @hannesrudolph) – Befehl „pnpm servo“ für die Code-Server-Entwicklung hinzufügen (PR #10964 von @mrubens) – Aktualisieren Sie Next.js auf die neueste Version (PR #11108 von @cte)

Englisches Original / English original

Roo-Code v3.46.0

Highlights

  • Parallel tool calls are now enabled by default — Independent tools can execute concurrently for faster agent workflows, with the parallel time-travel bug fixed. Upgrade for performance gains, but validate workflows that depend on strictly serialized execution.
  • More complete code and terminal context — read_file gains indentation mode to extract complete semantic blocks, while read_command_output retrieves full truncated command output using pagination and regex filtering. Especially valuable for large repositories and log-heavy debugging.
  • Migration required for fetch_instructions workflows — The new skill system replaces fetch_instructions with a dedicated skill tool, built-in create-mcp-server and create-mode skills, configurable locations, and mandatory skill checks. Custom instructions or automation using fetch_instructions should be migrated to skills; workspace and global skills can now be managed in settings.
  • Five providers moved to the AI SDK — Moonshot, DeepSeek, Cerebras, Groq, and Fireworks now use AI SDK-backed infrastructure for improved streaming and tool support. Users of these providers should upgrade and regression-test provider-specific behavior.
  • Upgrade recommendation — This is a substantive release: agent-heavy users and anyone working with large code or command outputs should upgrade. Users who do not use the affected providers or skill workflows can defer if parallel execution is acceptable, though they will miss the retrieval improvements.

[3.46.0] - 2026-01-27

3.46.0 Release - Parallel Processing Power

  • Parallel tool calls enabled by default for improved performance (PR #11031 by @daniel-lxs)
  • Codex-inspired read_file refactor introduces indentation mode for extracting complete semantic code blocks without mid-function truncation, ideal when targeting specific lines from search results or errors (#10239 by @pwilkin, PR #10981 by @hannesrudolph)
  • Lossless terminal output with new read_command_output tool allows retrieving full command output from truncated executions with pagination and regex filtering (#10941 by @hannesrudolph, PR #10944 by @hannesrudolph)
  • New skill system replaces fetch_instructions with a dedicated skill tool and built-in skills for create-mcp-server and create-mode, with configurable skill locations and mandatory skill checks (#11062 by @hannesrudolph, PR #11084 by @hannesrudolph)
  • Skills management UI added to settings panel for managing workspace and global skills (#10513 by @SannidhyaSah, PR #10844 by @SannidhyaSah)
  • AI SDK provider migrations: Moonshot (PR #11063 by @daniel-lxs), DeepSeek (PR #11079 by @daniel-lxs), Cerebras (PR #11086 by @daniel-lxs), Groq (PR #11088 by @daniel-lxs), and Fireworks (PR #11118 by @daniel-lxs) now use the AI SDK for better streaming and tool support
  • Add OpenAI-compatible base provider infrastructure for AI SDK migrations (PR #11063 by @daniel-lxs)
  • Add AI SDK dependencies and message conversion utilities (PR #11047 by @daniel-lxs)
  • React Compiler integration added to webview-ui for automatic memoization and performance improvements (#9916 by @In-line, PR #9565 by @In-line)
  • Fix: Include reserved output tokens in task header percentage calculation (PR #11034 by @app/roomote)
  • Fix: Calculate header percentage based on available input space (PR #11054 by @app/roomote)
  • Fix: Prevent time-travel bug in parallel tool calling (PR #11046 by @daniel-lxs)
  • Docs: Clarify read_command_output search param should be omitted when not filtering (PR #11056 by @hannesrudolph)
  • Add pnpm serve command for code-server development (PR #10964 by @mrubens)
  • Update Next.js to latest version (PR #11108 by @cte)
  • Replace bespoke navigation menu with shadcn navigation menu on website (PR #11117 by @app/roomote)
  • Add Linear integration marketing page to website (PR #11028 by @app/roomote)
