AionUi v2.1.53

Highlights

Slack als Chat-Kanal

  • Slack wechselt von „bald verfügbar“: Konfigurieren Sie ein Bot-Token und ein Token auf App-Ebene unter Einstellungen → Kanäle, testen Sie die Verbindung, wählen Sie ein Modell aus und verwalten Sie, welche Slack-Benutzer berechtigt sind, mit Ihrem Agenten zu sprechen.

Claude und Codex führen jetzt Ihre eigene Installation aus

  • AionUi lieferte früher seine eigenen angehefteten Kopien von Claude und Codex, sodass sich dieselbe Eingabeaufforderung in AionUi anders verhalten konnte als in Ihrem Terminal – unsichtbar. Beide führen nun die Installation aus, die Sie bereits haben, so wie es Antigravity immer getan hat, und AionUi teilt Ihnen mit, wenn Ihre Version von der Version abweicht, anhand derer diese Version verifiziert wurde.

Quellcodeverwaltung, Runde zwei

– Das Panel ist in zusammenklappbare Abschnitte mit Trennwänden zum Ändern der Größe durch Ziehen und Doppel-click zum Zurücksetzen umstrukturiert, die eng an die VS Code-Seitenleiste angelehnt sind.

  • Der Abschnitt „Änderungen“ erhält einen Umschalter zwischen Baum- und Listenansicht. – Repositorys werden jetzt eine Ebene tiefer als Ihre Workspace-Stammverzeichnisse erkannt, sodass Multi-Repo-Projekte ohne manuelle Einrichtung übernommen werden können.

Pfad aus dem Explorer kopieren

  • Klicken Sie mit der rechten Maustaste auf eine Datei oder einen Ordner im Projekt-Explorer, um den relativen Pfad oder (auf dem Desktop) den absoluten Pfad zu kopieren.

Fehlerbehebungen

– Ein vollständig weißer Bildschirm bei gepackten Desktop-Builds, der WebUI-Umschaltung und dem Web-Build wurde behoben – verursacht durch eine fehlerhafte Anbieter-Chunk-Aufteilung.

  • In schmalen Fenstern öffnet das cliKlicken einer Datei im Baum einer Projektkonversation jetzt tatsächlich die Vorschau.
  • Wenn Sie mit der rechten Maustaste auf einen Ordner klicken und „Zum Chat hinzufügen“ wählen, wird jetzt ein Chip erzeugt und der Ordner tatsächlich an den Agenten gesendet, anstatt nur einen Erfolgs-Toast anzuzeigen.
  • Die Schaltfläche „Kopieren“ bei einer KI-Antwort kopiert jetzt die gesamte Runde. Antworten verschachtelt mit Tool-Aufrufen oder Gedanken, die vor dem letzten Textsegment alles verloren haben.
  • Bilder mit relativen Pfaden in Projekt-Markdown-Vorschauen werden nicht mehr fehlerhaft dargestellt.
  • Das Durchsuchen von Skilldateien funktioniert jetzt in der WebUI, nicht nur auf dem Desktop.
  • Antigravity wird wieder im Dropdown-Menü „Agent“ des Editor-Assistenten angezeigt und im Feld „Agent“ wird der Name anstelle einer Roh-ID angezeigt. – Ein Dateiüberwachungsabonnement, das fehlgeschlagen ist (offline oder ein Socket, der unmittelbar nach der erneuten Verbindung geschlossen wird), wird jetzt erneut versucht, anstatt diesen Ordner stillschweigend für immer veraltet zu lassen.

Engine-Updates (AionCore v0.1.62 → v0.1.63)

– Agenten, die Hintergrundarbeit ausführen – einen Workflow, eine Hintergrund-Shell, einen Hintergrund-Subagenten – werden nicht mehr vom Leerlauf-Scanner getötet, während sie sich noch mitten im Flug befinden. – Agenten erhalten jetzt den echten, absoluten Pfad Ihres Projekts statt eines in Einzelfällen zusammengefassten Pfads.

Hinweis

– Die einmalige Migration der Theme-Einstellungen aus der Fork-Ära wurde entfernt. Themes, die vor dem aktuellen Theme-System erstellt wurden, werden nicht mehr automatisch übernommen.

AionUi v2.1.53

Highlights

Slack as a Chat Channel

  • Slack moves out of "coming soon": configure a Bot Token and App-Level Token in Settings → Channels, test the connection, pick a model, and manage which Slack users are authorized to talk to your agent.

Claude and Codex Now Run Your Own Install

  • AionUi used to ship its own pinned copies of claude and codex, so the same prompt could behave differently in AionUi than in your terminal — invisibly. Both now run the install you already have, the same way Antigravity always has, and AionUi tells you when your version differs from the one this release was verified against.

Source Control Panel, Round Two

  • The panel is restructured into collapsible sections with drag-to-resize dividers and double-click-to-reset, closely following the VS Code sidebar.
  • The Changes section gains a tree / list view toggle.
  • Repositories are now discovered one level down from your workspace roots, so multi-repo projects are picked up without manual setup.

Copy Path from the Explorer

  • Right-click any file or folder in the project Explorer to copy its relative path, or (on desktop) its absolute path.

Bug Fixes

  • Fixed a full white screen on packaged desktop builds, the WebUI toggle, and the web build — caused by a bad vendor-chunk split.
  • On narrow windows, clicking a file in a project conversation's tree now actually opens the preview.
  • Right-clicking a folder and choosing "Add to chat" now produces a chip and actually sends the folder to the agent, instead of just showing a success toast.
  • The copy button on an AI reply now copies the whole turn. Replies interleaved with tool calls or thinking previously lost everything before the last text segment.
  • Relative-path images in project markdown previews no longer render broken.
  • Browsing skill files now works in WebUI, not just on desktop.
  • Antigravity shows up in the assistant editor's Agent dropdown again, and its Agent field shows the name instead of a raw id.
  • A file-watch subscription that failed (offline, or a socket closing right after reconnect) is now retried, instead of silently leaving that folder stale forever.

Engine updates (AionCore v0.1.62 → v0.1.63)

  • Agents running background work — a workflow, a background shell, a background subagent — are no longer killed by the idle scanner while still mid-flight.
  • Agents now receive the real-case absolute path of your project instead of a case-folded one.

Note

  • The one-time migration of fork-era theme settings has been removed. Themes created before the current theme system are no longer carried over automatically.
