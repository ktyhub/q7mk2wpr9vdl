Vibe-Trading v0.1.12

🌀 v0.1.12 – Zeitleiste des Korrelationsregimes, drei neue Anbieter, MetaTrader 5 + eine Zuverlässigkeitswelle

v0.1.12 fasst fast zwei Wochen Arbeit seit 0.1.11 (10.07.2026) zusammen – die Schlagzeilen: eine Zeitleiste des Korrelationsregimes, die antwortet: „Wann ist der Markt zu einem Block verschmolzen, und befinden wir uns jetzt in diesem Zustand? Strategy Development Manager-Fähigkeit, Binance USD-M Perpetuals mit historischer Finanzierung und eine breite Zuverlässigkeitswelle – strikte JSON/finite Härtung, Sitzungs-/Journal-Robustheit, eine 80-fache Vektorisierung und der native zai-Streaming-Fix. Diese Version ist auf den Versionen PyPI, ClawHub und GitHub verfügbar.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Highlights

🌀 Zeitleiste des Korrelationsregimes

Ein neuer additiver GET /correlation/regime-Endpunkt und ein Opt-in-Streifen „Regime-Zeitleiste“ auf der Registerkarte „Korrelation“ (#756, schließt #719, danke @ebujinovch). Es verwendet dieselben Preisdaten, die /correlation bereits abruft: Rollende paarweise Korrelationen reduzieren sich auf einen Kantendichte-Skalar pro Balken (der Bruchteil der Vermögenswertpaare, deren |ρ| einen Schwellenwert überschreitet), die Reihe wird kausal geglättet (nachgestelltes Fenster – liest nie die Zukunft) und eine Hysterese-Zustandsmaschine mit zwei Schwellenwerten markiert aufeinanderfolgende FUSED-Episoden mit einem Totband, das Chatter unterdrückt. Es teilt sich das Authentifizierungs- und Ratenlimit-Budget von /correlation, legt das Zeitfenster fest, sodass kurze Zeitpläne nicht leer zurückkehren können, und ist ausdrücklich beschreibender Risikokontext, kein Handelssignal. Unterstützt durch die Fertigkeit correlation-regime (#557).

🔌 Drei neue LLM-Anbieter + robuste Endpunktauflösung

Native Adapter für SiliconFlow (CN + Global, #565, danke @UNHNQ), iFlytek Spark (#537, danke @FenjuFu) und die nativen Anthropic Messages API (#695, danke @jelech; pip install "vibe-trading-ai[anthropic]") sowie Regionale MiniMax-Endpunkte (#731, danke @octo-patch). Darunter werden Anbieteranmeldeinformationen über einen zentralen Pfad aufgelöst (#563, danke @shadowinlife) und zwei seit langem bestehende Ecken und Kanten behoben (#758): Wenn kein *_BASE_URL festgelegt ist, greift das Backend jetzt auf den kanonischen Katalogendpunkt jedes Anbieters zurück (die gleichen Standard-Webeinstellungen, die bereits verwendet wurden), anstatt stillschweigend auf api.openai.com zurückzusetzen – sodass ein Anbieter nur mit einem Schlüssel arbeitet – und ein Endpunkt, der null Chunks streamt, zurückfällt zu einem Nicht-Streaming-Aufruf statt zu einem Fehler, mit einem HTML-Fehlerseitenhinweis, wenn eine Basis-URL falsch konfiguriert ist.

📈 MetaTrader 5 (Exness)-Anschluss + mt5-Datenquelle – 12 Broker

Ein erstklassiger MetaTrader 5-Broker-Connector (#481, danke @StaniellG) – volle Leseoberfläche plus Ordererteilung über ein lokal betriebenes Terminal, mit einem bidirektionalen Identitätsschutz (Papierprofil ⇔ Demo trade_mode, Login angepinnt, Wettbewerb abgelehnt) und max_order_volume / max_order_notional_usd-Caps auf Connector-Ebene auf Demo UND Live. Das Live-Mandat-Gate erhält das Instrumentenvokabular forex/cfd und einen Lot-abhängigen Größen-Hook, sodass USD-Obergrenzen für Orders in Lot-Größe gelten (0.1 Lot EURUSD ≈ 10.800 $, niemals 0.1 × Kurs). Der mt5-Loader leitet die Forex-Fallback-Kette (brokergenaue Symbole mit Exness-Suffix-Erkennung, 1m–1D-Balken). Broker-Anschlüsse: 11 → 12; Marktdatenquellen → 23.

🧬 Strategieentwicklungsmanager

sdm_register / sdm_status / sdm_decay_scan verwandeln wissenschaftliche Arbeiten und Maklerforschung in registrierte Faktoren und Strategien (#457, schließt #455, danke @shadowinlife), unterstützt durch einen persistenten SQLite-Artefaktspeicher (UNIQUE(name, universe)) und automatisierte IC/Sharpe-Zerfallsüberwachung, die einen active → monitoring → decayed → disabled-Lebenszyklus steuert. Wird mit steckbarer OCR für read_document geliefert (standardmäßig lokales RapidOCR; Cloud-Qwen-VL ist nur explizites Opt-in, niemals automatisch ausgewählt).

₿ Binance USD-M-Perpetuals

Explizites BTC-USDT-PERP-Routing mit Trennung von Ausführungs-/Markierungspreisen (nicht geschlossen, wenn die beiden nicht zeitstempelsynchronisiert sind) und historischen Finanzierungsabrechnungen (#470/#716, danke @honginp). Wartungsklammern werden vom authentifizierten Live-Abruf entkoppelt und stattdessen als validiertes, inhaltsgehashtes Artefakt bereitgestellt (#757), sodass ein einfacher -PERP-Backtest null-Anmeldeinformationen bleibt – die Regression, bei der jeder Täterabruf einen Binance-API-Schlüssel erforderte, ist weg.

👁️ Steckbare OCR + LLM-Vision-Extraktion

read_document erhält eine steckbare OCR-Engine-Architektur mit optionaler LLM-Vision-Extraktion und einem konfigurierbaren Textdichteschwellenwert (#548, danke @shadowinlife) – standardmäßig lokal, Cloud-Engines nur Opt-In, nie automatisch ausgewählt.

🧰 Plattform & Sicherheit

  • Korrektur des Look-Ahead-Bias bei allen fünf Portfolio-Optimierern (#487, danke @YZY0108) – Gewichtungen, die bei der Eröffnung eines Balkens ausgeführt werden, berücksichtigen nicht mehr die Rendite dieses Balkens nahe am Schluss. Plus realisierte Portfolioumschlagskennzahlen für jeden Optimierer (#478, danke @Robin1987China).
  • Sicherheitshärtung – alle 10 Ergebnisse des externen Audits vom 10.07.2026 abgeschlossen (#476): AST-gehärtete Backtest-Sandbox, kurzlebige SSE-Authentifizierungstickets, gehärtetes Compose, /correlation-Authentifizierungs- und Ratenbegrenzung, Sicherheitsheader, Hash-gesperrte Abhängigkeiten und SHA-fixierte Aktionen.
  • 80-fache Signalausrichtungsvektorisierung (#698, danke @shadowinlife) und Swarm-MCP-Tool-Discovery-Caching (#704) haben bei breiten Panels und Multi-Worker-Läufen den Takt eingehalten.
  • Opt-in-TAP-Modus für Alpaca (#377, danke @0xZKnw), IBKR-Thread-lokaler Verbindungspool + Snapshot-Anführungszeichen (#636, danke @MikeCer), Robinhood account_number-Verkabelung (#726, danke @nareshkps), der Requesty-Gateway-Anbieter (#474, danke @Thibaultjaigu) und Erkennung von Benutzerschwarmvoreinstellungen (#570, danke @darkknight4563).
  • Zwei neue akademische Faktoren – Frazzini-Pedersen-Wetten gegen Beta (#480, danke @YogeshModi24) und academic_corr_rewire (#705, danke @ebujinovch): Alpha Zoo 460 → 462 über 5 Familien.

🛠️ Zuverlässigkeits- und Korrektheitswelle

  • Strict-JSON / Finite-Number-Hardening im gesamten Backtest + Tools-Stack (danke @santhreal) – Risikoverhältnisse bleiben endlich, wenn das Eigenkapital Null überschreitet (#765) oder einen explosiven Pfad auf Jahresbasis erreicht (#739/#740); Skalare Metriken (#766), Faktor IC std (#767) und Mustertrendsteigung (#764) geben striktes RFC-8259 JSON (null, niemals NaN/Infinity) aus; Black-Scholes-Helfer behandeln nicht-positive Spots/Strikes als intrinsisch (#744).
  • Sitzungs-/Journal-Robustheit – eine beschädigte session.json-Zeile (#762) oder eine schemafehlerhafte messages.jsonl-Zeile (#763) bricht das Auflisten/Lesen nicht mehr ab; Excel-A-Share-Codes mit Gleitkomma-Zeichenfolgen (#770), Unicode-Dash-PDF-Seitenbereiche (#769), export KEY=-Dotenv-Zeilen (#768) und Yahoo-1m-Balken (#761) werden alle korrekt analysiert.
  • Hohe Zuverlässigkeit – Abbruch wird vor der ersten AgentLoop-Iteration berücksichtigt (#641, schließt #638), ein Frontend-insertBefore-Streaming-DOM-Rennen ist behoben (#717, danke @Marnie0415), die zusammengesetzte Engine greift auf unbekannte Symbole zurück (#734), Codex-Stream-HTTP-Fehler werden für einen korrekten Wiederholungsversuch klassifiziert (#663) und #584 (danke @xkam7ar) schließt eine Reihe von Probleme mit Verpackung/Web/Scheduler/Swarm/CLI.

🙌 Mitwirkender-Zyklus

~90 Korrektheits-/Zuverlässigkeitskorrekturen und Funktionen aus einer breiten Kohorte von Mitwirkenden – @santhreal (ein 30-PR-Korrektheits-Sweep), @xkam7ar (Zuverlässigkeit + QVeris-Härtung), @shadowinlife (SDM, OCR, Vektorisierung), @ebujinovch (Zeitleiste des Regimes), @honginp (Binance-Täter), @StaniellG (MetaTrader 5) und viele mehr. Die vollständigen Credits pro Person finden Sie im Abschnitt „README-Mitwirkende“ und im CHANGELOG. Vielen Dank auch an @GabbaTauchi für den zai-Fehlerbericht (#758).

Vibe-Trading v0.1.12

🌀 v0.1.12 — Correlation regime timeline, three new providers, MetaTrader 5 + a reliability wave

v0.1.12 rolls up nearly two weeks of work since 0.1.11 (2026-07-10) — the headlines: a correlation regime timeline that answers "when did the market fuse into one bloc, and are we in that state now?", three new LLM providers plus catalog-based endpoint resolution that makes every provider work with just a key, the MetaTrader 5 (Exness) broker connector (12 brokers), the Strategy Development Manager skill, Binance USD-M perpetuals with historical funding, and a broad reliability wave — strict-JSON/finite hardening, session/journal robustness, an 80× vectorization, and the native zai streaming fix.

This release is available on PyPI, ClawHub, and GitHub Releases.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Highlights

🌀 Correlation regime timeline

A new additive GET /correlation/regime endpoint and an opt-in "Regime timeline" strip on the Correlation tab (#756, closes #719, thanks @ebujinovch). It reuses the same price data /correlation already fetches: rolling pairwise correlations reduce to an edge-density scalar per bar (the fraction of asset pairs whose |ρ| clears a threshold), the series is causally smoothed (trailing window — never reads the future), and a two-threshold hysteresis state machine marks contiguous FUSED episodes, with a dead band that suppresses chatter. It shares /correlation's auth + rate-limit budget, floors the window so short timelines can't return empty, and is explicitly descriptive risk context, not a trading signal. Backed by the correlation-regime skill (#557).

🔌 Three new LLM providers + robust endpoint resolution

Native adapters for SiliconFlow (CN + Global, #565, thanks @UNHNQ), iFlytek Spark (#537, thanks @FenjuFu), and the native Anthropic Messages API (#695, thanks @jelech; pip install "vibe-trading-ai[anthropic]"), plus MiniMax regional endpoints (#731, thanks @octo-patch). Underneath, provider credentials are resolved through one centralized path (#563, thanks @shadowinlife), and two long-standing rough edges are fixed (#758): when no *_BASE_URL is set, the backend now falls back to each provider's canonical catalog endpoint (the same default Web Settings already used) instead of silently defaulting to api.openai.com — so a provider works with just a key — and an endpoint that streams zero chunks falls back to a non-streaming invoke rather than erroring, with an HTML-error-page hint when a base URL is misconfigured.

📈 MetaTrader 5 (Exness) connector + mt5 data source — 12 brokers

A first-class MetaTrader 5 broker connector (#481, thanks @StaniellG) — full read surface plus order placement against a locally running terminal, with a bidirectional identity guard (paper profile ⇔ demo trade_mode, login pinned, contest rejected) and connector-level max_order_volume / max_order_notional_usd caps on demo AND live. The live mandate gate gains forex/cfd instrument vocabulary and a lot-aware sizing hook so USD caps bind on lot-sized orders (0.1 lot EURUSD ≈ $10,800, never 0.1 × quote). The mt5 loader heads the forex fallback chain (broker-exact symbols with Exness suffix discovery, 1m–1D bars). Broker connectors: 11 → 12; market-data sources → 23.

🧬 Strategy Development Manager

sdm_register / sdm_status / sdm_decay_scan turn academic papers and broker research into registered factors and strategies (#457, closes #455, thanks @shadowinlife), backed by a persistent SQLite artifact store (UNIQUE(name, universe)) and automated IC/Sharpe decay monitoring driving an active → monitoring → decayed → disabled lifecycle. Ships with pluggable OCR for read_document (local RapidOCR by default; cloud Qwen-VL is explicit opt-in only, never auto-selected).

₿ Binance USD-M perpetuals

Explicit BTC-USDT-PERP routing with execution/mark price separation (fail-closed when the two aren't timestamp-synchronized) and historical funding settlements (#470/#716, thanks @honginp). Maintenance brackets are decoupled from the live authenticated fetch and supplied as a validated, content-hashed artifact instead (#757), so a plain -PERP backtest stays zero-credential — the regression where every perp fetch required a Binance API key is gone.

👁️ Pluggable OCR + LLM-vision extraction

read_document gains a pluggable OCR engine architecture with optional LLM-vision extraction and a configurable text-density threshold (#548, thanks @shadowinlife) — local by default, cloud engines opt-in only, never auto-selected.

🧰 Platform & safety

  • Look-ahead-bias fix across all five portfolio optimizers (#487, thanks @YZY0108) — weights executed at a bar's open no longer include that bar's close-to-close return. Plus realized portfolio turnover metrics for every optimizer (#478, thanks @Robin1987China).
  • Security hardening — all 10 findings from the 2026-07-10 external audit closed (#476): AST-hardened backtest sandbox, short-lived SSE auth tickets, hardened Compose, /correlation auth + rate limiting, security headers, hash-locked dependencies, and SHA-pinned Actions.
  • 80× signal-alignment vectorization (#698, thanks @shadowinlife) and swarm MCP tool-discovery caching (#704) cut wall-clock on wide panels and multi-worker runs.
  • Opt-in TAP mode for Alpaca (#377, thanks @0xZKnw), IBKR thread-local connection pool + snapshot quotes (#636, thanks @MikeCer), Robinhood account_number wiring (#726, thanks @nareshkps), the Requesty gateway provider (#474, thanks @Thibaultjaigu), and user swarm-presets discovery (#570, thanks @darkknight4563).
  • Two new academic factors — Frazzini-Pedersen betting-against-beta (#480, thanks @YogeshModi24) and academic_corr_rewire (#705, thanks @ebujinovch): Alpha Zoo 460 → 462 across 5 families.

🛠️ Reliability & correctness wave

  • Strict-JSON / finite-number hardening across the backtest + tools stack (thanks @santhreal) — risk ratios stay finite when equity crosses zero (#765) or annualizes an explosive path (#739/#740); scalar metrics (#766), factor IC std (#767), and pattern trend-slope (#764) emit strict RFC-8259 JSON (null, never NaN/Infinity); Black-Scholes helpers treat non-positive spot/strike as intrinsic (#744).
  • Session / journal robustness — one corrupt session.json (#762) or schema-bad messages.jsonl line (#763) no longer aborts listing/reading; Excel float-stringified A-share codes (#770), unicode-dash PDF page ranges (#769), export KEY= dotenv lines (#768), and yahoo 1m bars (#761) all parse correctly.
  • Broad reliability — cancellation is honored before the first AgentLoop iteration (#641, closes #638), a frontend insertBefore streaming DOM-race is fixed (#717, thanks @Marnie0415), the composite engine falls back for unknown symbols (#734), codex stream HTTP failures are classified for correct retry (#663), and #584 (thanks @xkam7ar) closes a batch of packaging/web/scheduler/swarm/CLI issues.

🙌 Contributor cycle

~90 correctness/reliability fixes and features from a wide contributor cohort — @santhreal (a 30-PR correctness sweep), @xkam7ar (reliability + QVeris hardening), @shadowinlife (SDM, OCR, vectorization), @ebujinovch (regime timeline), @honginp (Binance perps), @StaniellG (MetaTrader 5), and many more. Full per-person credits live in the README Contributors section and the CHANGELOG. Thanks also to @GabbaTauchi for the zai bug report (#758).

Install / upgrade

| Channel | Command | |---|---| | PyPI | pip install -U vibe-trading-ai | | uv tool | uv tool install --reinstall vibe-trading-ai | | ClawHub (Claude Desktop / OpenClaw / MCP clients) | clawhub install vibe-trading or update the installed skill | | Docker | docker compose pull && docker compose up -d |

Remote API/Web deployments should set API_AUTH_KEY and explicit trusted CORS origins; local CLI and localhost Web UI workflows stay low-friction.

By the numbers

Numbers at 0.1.12: 8 backtest engines + options_portfolio · 462 alphas / 5 families · 88 skills · 30 swarm presets · 23 market-data sources · 12 broker connectors · 75 free-mode tools (78 with QVeris) · 54 MCP tools · 5 optimizers · 16 IM adapters.

Validation

Full backend suite 6,019 passed (only pre-existing env/network fails, confirmed against clean main); frontend build + 310 vitest green; wheel verified (vibe_trading_ai-0.1.12, contents spot-checked). Protected agent core (src/agent, src/session, src/providers) reviewed for every change.

Full changelog: CHANGELOG.md · Compare: v0.1.11...v0.1.12 </content>
