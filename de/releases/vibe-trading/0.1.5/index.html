Vibe-Trading v0.1.5

Highlights

Zwei neue Hero-Loops zusätzlich zum Research-Agenten – Extrahieren Sie Ihre eigene Strategie aus Ihrem Broker-Tagebuch und testen Sie dann den Schatten dessen, wie Sie hätten handeln sollen.

👥 Schattenkonto (neu)

Laden Sie ein Broker-Journal hoch → LLM extrahiert Ihre Regeln → führt das Regelwerk marktübergreifend aus → 8-teiliger HTML-/PDF-Bericht, der genau zeigt, wie viel Gewinn und Verlust Sie auf dem Tisch lassen, um Ausfälle (Regelverstöße, vorzeitige Ausstiege, verpasste Einstiege, kontrafaktische Geschäfte) zu disziplinieren. 4 neue Werkzeuge (extract_shadow_strategy, run_shadow_backtest, render_shadow_report, scan_shadow_signals) + 1 Fertigkeit.

📊 Trade Journal Analyzer (neu)

analyze_trade_journal nimmt 同花顺 / 东方财富 / 富途 / generische CSV-Exporte auf → vollständiges Handelsprofil (Haltetage, Gewinnrate, PnL-Verhältnis, Drawdown) + 4 Verhaltensdiagnosen (Dispositionseffekt, Überhandeln, Jagd nach Dynamik, Verankerung).

📄 Universeller Dateireader (neu)

read_document versendet PDF, Word, Excel, PowerPoint, Bilder (OCR) und über 40 Textformate in einem einheitlichen Umschlag. read_url über Jina für das Web.

🧠 Agent Harness v2

  • Persistenter sitzungsübergreifender Speicher (~/.vibe-trading/memory/)
  • SQLite FTS5-Sitzungssuche
  • Sich selbst weiterentwickelnde Fähigkeiten – vollständiges CRUD (Speichern / Patchen / Löschen / Skill-Datei)
  • 5-Ebenen-Kontextkomprimierung
  • Batchverarbeitung mit Lese-/Schreibtools
  • 107 neue Tests

0.1.5 Wartung

  • Sicherheit: python-multipart >= 0.0.18 (CVSS 7.5 CVE-Boden)
  • MCP: 5 neue Tools verfügbar (Handelsjournal + Schattenkontofamilie), Nichtübereinstimmung der Registrierungsnamen pattern_recognition → pattern behoben (gab 404 zurück)
  • Docker-Parität: 9 Laufzeit-Deps zu requirements.txt hinzugefügt (openpyxl, python-docx, python-pptx, pypdfium2, Pillow, ddgs, jinja2, matplotlib, weasyprint) – diese fehlten stillschweigend im Docker-Image
  • CLI: Bannerversion auf 0.1.5 erhöht (blieb bei 0.1.0 hängen)
  • Frontend: Seitenleiste + package.json-Version auf 0.1.5 erhöht
  • Tests: test_skills.py dringt nicht mehr in ~/.vibe-trading/skills/user/ ein
  • SKILL-Manifest: synchronisiert mit 22 MCP-Tools / 71 Fertigkeiten / 29 Schwarmvoreinstellungen

Installieren/Upgrade

pip install -U vibe-trading-ai==0.1.5

Docker:

docker compose pull && docker compose up -d

Anhand der Zahlen

  • 32 Tools (27 Registry + 5 neue)
  • 22 MCP-Werkzeuge freigelegt
  • 71 gebündelte Fähigkeiten (+ vom Benutzer erstellt)
  • 7 Backtest-Engines + Optionsportfolio
  • 13 LLM-Anbieter, 5 Datenquellen mit automatischem Fallback
  • 29 Schwarmvoreinstellungen

Vibe-Trading v0.1.5

Highlights

Two new hero loops on top of the research agent — extract your own strategy from your broker journal, then backtest the shadow of how you should have traded.

👥 Shadow Account (new)

Upload a broker journal → LLM extracts your rules → run the rulebook across markets → 8-section HTML/PDF report showing exactly how much P&L you leave on the table to discipline breakdowns (rule violations, early exits, missed entries, counterfactual trades). 4 new tools (extract_shadow_strategy, run_shadow_backtest, render_shadow_report, scan_shadow_signals) + 1 skill.

📊 Trade Journal Analyzer (new)

analyze_trade_journal ingests 同花顺 / 东方财富 / 富途 / generic CSV exports → full trading profile (holding days, win rate, PnL ratio, drawdown) + 4 behavior diagnostics (disposition effect, overtrading, chasing momentum, anchoring).

📄 Universal File Reader (new)

read_document dispatches PDF, Word, Excel, PowerPoint, images (OCR), and 40+ text formats behind one unified envelope. read_url via Jina for web.

🧠 Agent Harness v2

  • Persistent cross-session memory (~/.vibe-trading/memory/)
  • SQLite FTS5 session search
  • Self-evolving skills — full CRUD (save / patch / delete / skill_file)
  • 5-layer context compression
  • Read/write tool batching
  • 107 new tests

0.1.5 maintenance

  • Security: python-multipart >= 0.0.18 (CVSS 7.5 CVE floor)
  • MCP: 5 new tools exposed (trade journal + shadow account family), fixed pattern_recognition → pattern registry name mismatch (was returning 404)
  • Docker parity: 9 runtime deps added to requirements.txt (openpyxl, python-docx, python-pptx, pypdfium2, Pillow, ddgs, jinja2, matplotlib, weasyprint) — Docker image was silently missing these
  • CLI: banner version bumped to 0.1.5 (was stuck at 0.1.0)
  • Frontend: sidebar + package.json version bumped to 0.1.5
  • Tests: test_skills.py no longer leaks into ~/.vibe-trading/skills/user/
  • SKILL manifest: synced to 22 MCP tools / 71 skills / 29 swarm presets

Install / upgrade

pip install -U vibe-trading-ai==0.1.5

Docker:

docker compose pull && docker compose up -d

By the numbers

  • 32 tools (27 registry + 5 new)
  • 22 MCP tools exposed
  • 71 bundled skills (+ user-created)
  • 7 backtest engines + options portfolio
  • 13 LLM providers, 5 data sources with auto-fallback
  • 29 swarm presets
