Vibe-Trading v0.1.6

🚀 v0.1.6 – Kritische Paketkorrektur + Community-gesteuerte Funktionen

Wenn Sie vibe-trading-ai==0.1.5 über pip install oder uv tool install installiert haben, gab vibe-trading --swarm-presets No presets available zurück und run_swarm war unbrauchbar. Diese Version behebt das – bitte aktualisieren Sie.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Highlights

🐛 Swarm-Presets-Verpackungskorrektur (#55)

Voreingestellte YAMLs wurden über [tool.setuptools.data-files] in pyproject.toml deklariert, wodurch sie unter <install-prefix>/.data/data/config/swarm/ landen und nicht unter <site-packages>/config/swarm/, wo der Lader gesucht hat. Bearbeitbare Installationen (pip install -e .) funktionierten zufällig, weil der Quellbaumpfad korrekt aufgelöst wurde, sodass der Fehler nur in veröffentlichten Rädern auftauchte – jeder pip install vibe-trading-ai==0.1.5 war in diesem Codepfad defekt. Lösung: 29 voreingestellte YAMLs wurden in agent/src/swarm/presets/ verschoben, sodass sie als normale package-data ausgeliefert werden. Loader wird jetzt über Path(__file__).parent / "presets" aufgelöst – identisch unter bearbeitbaren Installationen und gebauten Rädern. Wird von einer 6-Test-Paketierungsregressionssuite fixiert, sodass sich dies nicht stillschweigend erneut zurückbilden kann. Von @qxj gemeldeter Fehler – Screenshots machten es zu einer 5-minütigen Ursachensuche.

📊 Benchmark-Vergleichspanel

Die Backtest-Ausgabe liefert jetzt ein Benchmark-Vergleichspanel (Ticker / Benchmark-Rendite / Überschussrendite / Informationsverhältnis) mit yfinance-gestützter Auflösung für SPY, CSI 300 und andere wichtige Indizes. Beigetragen von @MB-Ndhlovu (#48).

🛡️ /upload Streaming + Größenbeschränkungen

Der /upload-Endpunkt streamt den Anforderungstext in 1-MB-Blöcken und bricht nach MAX_UPLOAD_SIZE mit teilweiser Dateibereinigung ab. Die 50-MB-Obergrenze wird jetzt tatsächlich unter böswilligen/übergroßen clients durchgesetzt. Gepinnt durch 4 Regressionstests. Beigetragen von @genoshide (#53).

📈 Futu-Datenlader (HK + A-Aktie)

  1. Datenquelle – Futu OpenAPI-Integration für Hongkong- und A-Aktien-Aktien mit Echtzeitkursen auf Broker-Niveau. Beigetragen von @hamza-mobeen (#47).

🔧 vnpy CtaTemplate-Exportfähigkeit

  1. Fähigkeit – vnpy-export generiert einsatzbereiten CtaTemplate-Strategiecode für das Vnpy-Backtest-Framework. Beigetragen von @hamza-mobeen (#46).

0.1.6 Wartung

  • Loader: Der AKShare-Loader leitet ETFs (510300.SH) und Forex (USDCNH) korrekt an die richtigen Endpunkte mit gehärtetem Registry-Fallback
  • Arbeitsbereich: Relativer run_dir auf aktives Laufverzeichnis normalisiert – behebt leere/relative Pfade in Werkzeugaufrufen (#43, @Mothilal-M)
  • Sicherheit: Pfadeindämmung in safe_path + Sandboxing für Journal-/Schattenkonto-Tools erzwungen
  • Build: MANIFEST.in liefert .env.example / Tests / Docker-Dateien in sdist
  • Frontend: Lazy Loading auf Routenebene verkleinert das anfängliche Paket um 688 KB → 262 KB
  • Dokumente: README-Verwendungsbeispiele (#45, @hamza-mobeen)
  • SKILL-Manifest: synchronisiert mit 22 MCP-Tools / 72 Fertigkeiten / 6 Datenquellen / 29 Schwarmvoreinstellungen

Vibe-Trading v0.1.6

🚀 v0.1.6 — Critical packaging fix + community-driven features

If you installed vibe-trading-ai==0.1.5 via pip install or uv tool install, vibe-trading --swarm-presets returned No presets available and run_swarm was unusable. This release fixes that — please upgrade.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Highlights

🐛 Swarm presets packaging fix (#55)

Preset YAMLs were declared via [tool.setuptools.data-files] in pyproject.toml, which lands them under <install-prefix>/.data/data/config/swarm/ rather than at <site-packages>/config/swarm/ where the loader looked. Editable installs (pip install -e .) happened to work because the source-tree path resolved correctly, so the bug only surfaced in published wheels — every pip install vibe-trading-ai==0.1.5 was broken on this code path.

Resolution: 29 preset YAMLs moved into agent/src/swarm/presets/ so they ship as ordinary package-data. Loader now resolves via Path(__file__).parent / "presets" — identical under editable installs and built wheels. Pinned by a 6-test packaging regression suite so this can't silently regress again.

Bug reported by @qxj — screenshots made it a 5-minute root cause hunt.

📊 Benchmark comparison panel

Backtest output now ships a benchmark comparison panel (ticker / benchmark return / excess return / information ratio) with yfinance-backed resolution for SPY, CSI 300, and other major indices. Contributed by @MB-Ndhlovu (#48).

🛡️ /upload streaming + size limits

The /upload endpoint streams the request body in 1 MB chunks and aborts past MAX_UPLOAD_SIZE with partial-file cleanup. The 50 MB cap is now actually enforced under malicious / oversized clients. Pinned by 4 regression tests. Contributed by @genoshide (#53).

📈 Futu data loader (HK + A-share)

6th data source — Futu OpenAPI integration for Hong Kong and A-share equities, with broker-grade real-time quotes. Contributed by @hamza-mobeen (#47).

🔧 vnpy CtaTemplate export skill

72nd skill — vnpy-export generates ready-to-run CtaTemplate strategy code for the vnpy backtest framework. Contributed by @hamza-mobeen (#46).

0.1.6 maintenance

  • Loader: AKShare loader correctly routes ETFs (510300.SH) and forex (USDCNH) to the right endpoints with hardened registry fallback
  • Workspace: Relative run_dir normalized to active run dir — fixes empty/relative paths in tool calls (#43, @Mothilal-M)
  • Security: Path containment enforced in safe_path + sandboxing for journal / shadow account tools
  • Build: MANIFEST.in ships .env.example / tests / Docker files in sdist
  • Frontend: Route-level lazy loading shrinks initial bundle 688 KB → 262 KB
  • Docs: README usage examples (#45, @hamza-mobeen)
  • SKILL manifest: synced to 22 MCP tools / 72 skills / 6 data sources / 29 swarm presets

Install / upgrade

| Channel | Command | |---|---| | PyPI | pip install -U vibe-trading-ai | | uv tool | uv tool install --reinstall vibe-trading-ai | | ClawHub (Claude Desktop / OpenClaw) | clawhub install vibe-trading | | Docker | docker compose pull && docker compose up -d |

By the numbers

  • 27 agent tools (22 exposed via MCP)
  • 72 bundled skills (+ user-created via full CRUD)
  • 6 data sources with auto-fallback: tushare, yfinance, okx, akshare, ccxt, futu (new)
  • 29 swarm presets, 7 backtest engines + options portfolio
  • 13 LLM providers

🙌 New contributors

Huge thanks to everyone who opened a PR in this cycle — all 4 are first-time contributions to Vibe-Trading:

  • @hamza-mobeen — Futu data loader (#47), vnpy CtaTemplate export skill (#46), README usage examples (#45) — three first-time PRs in one cycle 👏
  • @MB-Ndhlovu — backtest benchmark comparison panel (#48)
  • @genoshide — /upload streaming + size limits (#53)
  • @Mothilal-M — _normalize_tool_run_dir workspace fix (#43)

Issue reporters who kept the surface area honest: thanks to @qxj for the high-quality #55 reproduction and to @myrassel for the OAuth feature suggestion (#49) we are tracking for a future release.
