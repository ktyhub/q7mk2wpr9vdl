herdr v0.9.2

Patch Veröffentlicht29. Sept. 2026 Quelleherdrdev/herdr Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

herdr v0.9.2

Breaking Changes

  • Die Herdr-spezifische Fenstergrafik API ist weg. pane.graphics.info, set, clear und stream geben jetzt unknown_method zurück. Apps zeigen Bilder an, indem sie Standard-Kitty-Grafiken auf ihr Terminal schreiben, die Herdr nativ rendert. (#4561)

Hinzugefügt

  • Agenten können ihren eigenen Wiederaufnahmebefehl melden. Herdr öffnet dann nach einem Serverneustart die exakte Sitzung erneut, ohne dass eine integrierte Integration erforderlich ist. Selbst gemeldete Agenten werden ebenfalls gelöscht, sobald sich ihr Bereich wieder in einer inaktiven Shell befindet. Der neue Leitfaden [Hinzufügen von Herdr-Unterstützung zu Ihrem Agenten] (https://herdr.dev/docs/add-herdr-support/) behandelt Status, Lebenslauf und Freigabe für Agentenautoren. (#4687)
  • Verwenden Sie mehr als einen Präfixschlüssel: prefix = ["ctrl+space", "ctrl+s"]. Jeder Eintrag wechselt in den gleichen Präfixmodus und prefix+? listet sie alle auf. (#4653, danke @JJLiebig)
  • „Gehe zu“ zeigt jeden Agenten und jedes Terminal als eigene Zeile an, gruppiert nach Arbeitsbereich, mit Status und Pfad. Links und rechts springen zwischen Arbeitsbereichen. (#4384) – Binden Sie keys.clear_pane, um den Bildschirm des fokussierten Bereichs zu löschen und zurückzuscrollen, während die aktuelle Eingabeaufforderungszeile beibehalten wird. Es ist standardmäßig ungebunden und lässt Vollbild-Apps wie Vim in Ruhe. (#4383)
  • herdr machine status prüft gespeicherte Maschinen ohne Nachfrage. herdr machine reconnect schließt die SSH-Authentifizierung, einschließlich MFA, in Ihrem Terminal ab. Öffnen Sie clients und überprüfen Sie alle 30 Sekunden erneut fehlerhafte Computer, sodass nach dem Wiederherstellen einer Verbindung kein Neustart erforderlich ist. (#3763)
  • Interactive machine add findet die Herdr-Sitzungen, die bereits auf dem Host ausgeführt werden, und lässt Sie eine auswählen. --label ist optional; Die Maschine ist nach ihrem SSH-Host benannt. (#4204, #4678, danke @JJLiebig und @dhh)
  • terminal session control akzeptiert terminal.mouse-Ereignisse, sodass Bridge-clients Schaltflächen in Apps clicken können, die Mausberichte ermöglichen. (#4685) – Wiederhergestellte Agenten starten einzeln, standardmäßig im Abstand von 100 ms, statt alle auf einmal. Ändern Sie den Abstand mit [session] startup_per_agent_delay_ms. (#4102, danke @JJLiebig)

Geändert

  • Bilder werden schneller und zuverlässiger gerendert. Local Ghostty empfängt Bilddaten über temporäre Dateien statt über die Terminalausgabe. Popups und Benachrichtigungen beschneiden Bilder um sich herum, anstatt sie auszublenden. Bilder, die außerhalb der Ansicht gescrollt werden, bleiben geladen, sodass sie beim Zurückscrollen nicht mehr erneut gesendet werden. (#4561, #4652, #4686)
  • SSH-Verbindungen erfordern Komprimierung. Bei langsamen Links holen Remote-Fenster nach dem Scrollen in einem Bruchteil der Zeit auf. (#4340) – Beim Scrollen der Ausgabe auf gespeicherten Maschinen werden nur die geänderten Zeilen gesendet, wodurch die Bandbreite für Build-Protokolle und Streaming-Agents verringert wird. Ältere clients und Server arbeiten weiterhin mit dem bisherigen Format. (#4711)
  • Neues Scheibenset TERM_PROGRAM=herdr und TERM_PROGRAM_VERSION. Sie erben keine Terminal-Sitzungs-IDs mehr, wie z. B. iTerm2 oder Claude-Code-Sitzungsmarkierungen, von dem Terminal, das den Server gestartet hat. (#4104) – Windows-Fenster werden bei der Installation standardmäßig auf PowerShell 7 (pwsh) umgestellt und greifen auf Windows PowerShell zurück. Ein expliziter default_shell gewinnt immer noch. (#4297, danke @JJLiebig)
  • Das Schließen der letzten Registerkarte eines Arbeitsbereichs erfordert jetzt eine Bestätigung. (#4379, #4409, danke @minatoaquaMK2)
  • Event-Abonnements liefern volle Bursts. Ein Leser, der zu weit zurückfällt, erhält jetzt einen events_lost-Fehler, anstatt Ereignisse stillschweigend zu überspringen. (#4178, #4225, danke @minatoaquaMK2) – Unter Unix liest das Senden von SIGWINCH an einen Herdr client die Farben des Host-Terminals neu, sodass Theme-Umschalter, die die Farben ohne Hell-/Dunkel-Benachrichtigung ändern, Fenster aktualisieren können. (#4349, danke @dhh)

Behoben

  • Gespeicherte Layouts überstehen das Herunterfahren des Hosts und fehlgeschlagene Wiederherstellungen. Unter Linux mit logind speichert Herdr, bevor das System heruntergefahren wird. Jede Plattform speichert bis zu 48 Layout-Snapshots in session-snapshots/ zur manuellen Wiederherstellung. (#4320) – CliWenn Sie einen Bereich öffnen, wird kein verirrter Escape mehr gesendet, der einen Arbeitsagenten unterbricht. (#3480) – Die erste Aufgabe eines Agenten gilt jetzt als erledigt, auch wenn sie mit einer Eingabeaufforderung gestartet wurde. Startup, wiederhergestellte Sitzungen und Pis /new lösen keine falschen Benachrichtigungen mehr aus. Der vom Hook gemeldete Status überlebt die Live-Übergabe. (#3338, #3990, #3916)
  • Der Server verbraucht viel weniger CPU mit vielen gefüllten Bereichen. Der Navigator, die Bereichsaufteilung und die benannten Ziele bleiben in großen Sitzungen schnell und die Ausbrüche externer Ereignisse verzögern das Rendern nicht mehr. (#4506, #4546, #4426, #4669, #4670, #4671, #4672, danke @JJLiebig und @minatoaquaMK2)
  • Apps, die eine synchronisierte Ausgabe verwenden, zeigen während der Eingabe keine zerrissenen Frames mehr an. Der Cursor flackert beim Neuzeichnen des Status nicht mehr und springt nicht mehr um einen inaktiven Codex unter Windows. (#2968, #4303, danke @JJLiebig) – Der API-Socket akzeptiert nach einem vorübergehenden Fehler weiterhin Verbindungen, sodass CLI-Befehle und Live-Handoff nicht mehr fehlschlagen, während der Server weiterläuft. (#4601)
  • Langsame Git-Vorgänge während Worktree-Lookups frieren die Eingabe nicht mehr ein. (#4492, danke @JJLiebig) – worktree open übernimmt nicht mehr den eigenen Arbeitsbereich des Repositorys, sodass das Entfernen des Arbeitsbaums ihn nicht mehr schließt. (#4293) – Weitergeleitete SSH-Agenten funktionieren nach einer erneuten Verbindung weiterhin in Remote-Bereichen. Wiederholte --machine-Befehle öffnen weitaus weniger SSH-Verbindungen. (#1931, #4252) – OpenCode V1-Bereiche funktionieren weiterhin oder sind blockiert, während ihre Subagenten ausgeführt werden. Eine vorhandene Registrierung in tui.json wird berücksichtigt, anstatt tui.jsonc neu zu generieren. (#1362, #4240)
  • Codex wird während der aktiven Ausgabe nicht mehr als inaktiv gemeldet, seine Erwähnungs-Popups werden erkannt und neu zugeordnete Interrupt-Tasten unterbrechen nicht mehr die Erkennung. (#4507, #4196, danke @JJLiebig und @unmanbearpig)
  • Kiro-Genehmigungsaufforderungen werden als blockiert gemeldet. Grok-Leerlauffenster funktionieren mit benutzerdefinierten oder deaktivierten OSC-Titeln. (#4203, #4372, #4333, danke @vinayshah1998)
  • Die Scrollback-Löschen des Droiden werden berücksichtigt, sodass sich der Willkommensheader und das alte Transkript nicht mehr wiederholen. (#4432, danke @factory-ain3sh)
  • Der Kopiermodus bleibt aktiv, während die Ausgabe fortgesetzt wird und eine Bewegungstaste gedrückt gehalten wird. (#3812, #4281, danke @marcomayer)
  • Strg+Umschalt+Buchstabe behält die Umschalttaste in Bereichen bei, in denen keine erweiterte Tastatureingabe aktiviert ist, sodass Strg+Umschalt+C nicht mehr als Strg+C angezeigt wird. (#4581, #4597, danke @factory-ain3sh) – Über mehrere Lesevorgänge verteilte Mausberichte dringen nach einem Fokuswechsel über SSH nicht mehr in die Shell ein. (#4630)
  • Windows: Mehrzeilige Einfügungen in Claude Code werden nicht mehr an der ersten neuen Zeile übermittelt, und Umschalt+Eingabe bleibt erhalten. Die Mauserfassung überlebt Fokusänderungen und Größenänderungen, Strg+Win öffnet den Präfixmodus nicht mehr mit einem ctrl+space-Präfix und das Remote-Einfügen von clipboard-Bildern funktioniert wieder. (#4251, #4284, #4470, #4314, danke @JJLiebig) – Windows: Von npm installiertes OMP und über gehärtete Laufzeiten gestartete Agents werden erkannt. machine add gegen einen Windows-Host schlägt nicht mehr als „nicht bereit für gespeicherte Maschinen“ fehl. (#4313, #4579, #4309, danke @JJLiebig) – Die Arbeitsbereichshervorhebung im Navigationsmodus ist mit theme = "terminal" sichtbar. Die Suche im Sitzungsnavigator gleicht Wörter unabhängig voneinander ab. In der Seitenleiste werden die von cycling ausgewählten Agenten oder Verknüpfungen angezeigt. (#4300, #4408, #4273, #4535, #4355, danke @minatoaquaMK2)
  • session attach ohne Terminal erklärt das Problem, anstatt eine neue Sitzung laufen zu lassen. (#4393) – Socket-Fehlerantworten behalten die ursprüngliche Anforderungs-ID bei, einschließlich Fehlern bei der Abonnementeinrichtung. (#4344)
  • plugin install akzeptiert Optionen vor dem Repository. (#4446) – Windows-Fenster übernehmen von Anfang an die hellen oder dunklen Farben des Host-Terminals, sodass Apps in einem hellen Terminal nicht mehr standardmäßig in den dunklen Modus wechseln. (#1530, #4369) – Nach herdr update listet Herdr auf, welche laufenden Server noch auf der alten Version laufen, mit den genauen Befehlen zum Neustart jedes einzelnen und erinnert Sie daran, Ihre gespeicherten SSH-Maschinen zu aktualisieren.

Englisches Original / English original

herdr v0.9.2

Breaking Changes

  • The Herdr-specific pane graphics API is gone. pane.graphics.info, set, clear, and stream now return unknown_method. Apps show images by writing standard Kitty graphics to their terminal, which Herdr renders natively. (#4561)

Added

  • Agents can report their own resume command. Herdr then reopens their exact session after a server restart, with no built-in integration needed. Self-reported agents are also cleared once their pane is back at an idle shell. The new Add Herdr support to your agent guide covers state, resume, and release for agent authors. (#4687)
  • Use more than one prefix key: prefix = ["ctrl+space", "ctrl+s"]. Every entry enters the same prefix mode, and prefix+? lists them all. (#4653, thanks @JJLiebig)
  • Go To shows every agent and terminal as its own row, grouped by workspace, with its status and path. Left and Right jump between workspaces. (#4384)
  • Bind keys.clear_pane to clear the focused pane's screen and scrollback while keeping the current prompt line. It is unbound by default and leaves full-screen apps such as Vim alone. (#4383)
  • herdr machine status checks saved machines without prompting. herdr machine reconnect finishes SSH authentication, including MFA, in your terminal. Open clients recheck failed machines every 30 seconds, so no restart is needed after fixing a connection. (#3763)
  • Interactive machine add finds the Herdr sessions already running on the host and lets you pick one. --label is optional; the machine is named after its SSH host. (#4204, #4678, thanks @JJLiebig and @dhh)
  • terminal session control accepts terminal.mouse events, so bridge clients can click buttons in apps that enable mouse reporting. (#4685)
  • Restored agents start one at a time, 100 ms apart by default, instead of all at once. Change the spacing with [session] startup_per_agent_delay_ms. (#4102, thanks @JJLiebig)

Changed

  • Images render faster and more reliably. Local Ghostty receives image data through temporary files instead of terminal output. Popups and notifications crop images around themselves instead of hiding them. Images that scroll out of view stay loaded, so scrolling back no longer resends them. (#4561, #4652, #4686)
  • SSH connections request compression. On slow links, remote panes catch up after scrolling in a fraction of the time. (#4340)
  • Scrolling output on saved machines sends only the rows that changed, cutting bandwidth for build logs and streaming agents. Older clients and servers keep working with the previous format. (#4711)
  • New panes set TERM_PROGRAM=herdr and TERM_PROGRAM_VERSION. They no longer inherit terminal session IDs, such as iTerm2's, or Claude Code session markers from the terminal that started the server. (#4104)
  • Windows panes default to PowerShell 7 (pwsh) when it is installed, falling back to Windows PowerShell. An explicit default_shell still wins. (#4297, thanks @JJLiebig)
  • Closing the last tab of a workspace now asks for confirmation. (#4379, #4409, thanks @minatoaquaMK2)
  • Event subscriptions deliver bursts in full. A reader that falls too far behind now gets an events_lost error instead of silently skipping events. (#4178, #4225, thanks @minatoaquaMK2)
  • On Unix, sending SIGWINCH to a Herdr client re-reads the host terminal's colors, so theme switchers that change colors without a light/dark notification can refresh panes. (#4349, thanks @dhh)

Fixed

  • Saved layouts survive host shutdown and failed restores. On Linux with logind, Herdr saves before the system shuts down. Every platform keeps up to 48 layout snapshots in session-snapshots/ for manual recovery. (#4320)
  • Clicking a pane no longer sends a stray Escape that interrupts a working agent. (#3480)
  • An agent's first task now counts as done, even when it started with a prompt. Startup, restored sessions, and Pi's /new no longer fire false done notifications. Hook-reported status survives live handoff. (#3338, #3990, #3916)
  • The server uses far less CPU with many populated panes. The navigator, pane splits, and named targets stay fast in large sessions, and bursts of external events no longer stall rendering. (#4506, #4546, #4426, #4669, #4670, #4671, #4672, thanks @JJLiebig and @minatoaquaMK2)
  • Apps that use synchronized output no longer show torn frames while you type. The cursor no longer flickers during status redraws or jumps around an idle Codex on Windows. (#2968, #4303, thanks @JJLiebig)
  • The API socket keeps accepting connections after a transient error, so CLI commands and live handoff no longer fail while the server keeps running. (#4601)
  • Slow Git operations during worktree lookups no longer freeze typing. (#4492, thanks @JJLiebig)
  • worktree open no longer takes over the repository's own workspace, so removing the worktree no longer closes it. (#4293)
  • Forwarded SSH agents keep working in remote panes after a reconnect. Repeated --machine commands open far fewer SSH connections. (#1931, #4252)
  • OpenCode V1 panes stay working or blocked while their subagents run. An existing registration in tui.json is respected instead of regenerating tui.jsonc. (#1362, #4240)
  • Codex is no longer reported idle during active output, its mention popups are recognized, and remapped interrupt keys no longer break detection. (#4507, #4196, thanks @JJLiebig and @unmanbearpig)
  • Kiro approval prompts are reported as blocked. Grok idle panes settle with custom or disabled OSC titles. (#4203, #4372, #4333, thanks @vinayshah1998)
  • Droid's scrollback clears are honored, so its welcome header and old transcript no longer repeat. (#4432, thanks @factory-ain3sh)
  • Copy mode stays active while output continues and a movement key is held. (#3812, #4281, thanks @marcomayer)
  • Ctrl+Shift+letter keeps Shift in panes that have not enabled enhanced keyboard input, so Ctrl+Shift+C no longer arrives as Ctrl+C. (#4581, #4597, thanks @factory-ain3sh)
  • Mouse reports split across reads no longer leak into the shell after a focus switch over SSH. (#4630)
  • Windows: multi-line pastes into Claude Code no longer submit at the first newline, and Shift+Enter is preserved. Mouse capture survives focus changes and resizes, Ctrl+Win no longer opens prefix mode with a ctrl+space prefix, and remote clipboard image paste works again. (#4251, #4284, #4470, #4314, thanks @JJLiebig)
  • Windows: npm-installed OMP and agents launched through hardened runtimes are detected. machine add against a Windows host no longer fails as "not ready for saved machines." (#4313, #4579, #4309, thanks @JJLiebig)
  • The navigate-mode workspace highlight is visible with theme = "terminal". Session navigator search matches words independently. The sidebar reveals agents selected by cycling or shortcuts. (#4300, #4408, #4273, #4535, #4355, thanks @minatoaquaMK2)
  • session attach without a terminal explains the problem instead of leaving a new session running. (#4393)
  • Socket error responses keep the original request ID, including subscription setup errors. (#4344)
  • plugin install accepts options before the repository. (#4446)
  • Windows panes pick up the host terminal's light or dark colors from the start, so apps no longer default to dark mode inside a light terminal. (#1530, #4369)
  • After herdr update, Herdr lists which running servers are still on the old version, with the exact commands to restart each one, and reminds you to update your saved SSH machines.
