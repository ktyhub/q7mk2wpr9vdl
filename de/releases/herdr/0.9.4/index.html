herdr v0.9.4

Patch Veröffentlicht13. Okt. 2026 Quelleherdrdev/herdr Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

herdr v0.9.4

Hinzugefügt

  • herdr plugin update aktualisiert Plugins, die von GitHub installiert wurden, alle auf einmal oder nach Namen. Laufende Plugin-Bereiche arbeiten weiterhin an ihren alten Dateien, und neue Ausführungen übernehmen das Update, ohne dass die Konfiguration neu geladen werden muss. Lokal verlinkte Plugins bleiben unberücksichtigt. (#4245, danke @JJLiebig)
  • Windows-Benachrichtigungen bleiben im Benachrichtigungscenter. Clicking springt zu seinem Bereich und bringt das Terminalfenster nach vorne. (#4773, #4803, danke @JJLiebig)

Geändert

– Ein erhöhter Windows-Server akzeptiert jetzt standardmäßig nur Administrator-clients. Um normale clients vom gleichen Konto hereinzulassen, legen Sie [server] allow_unelevated_clients = true fest oder starten Sie den Server mit --allow-unelevated-clients. Bei Berechtigungsfehlern wird jetzt angezeigt, wie diese behoben werden können, und Sitzungen, die Sie nicht erreichen können, werden als nicht verfügbar statt als gestoppt angezeigt. (#4717, #4769, #4777, #4779, danke @JJLiebig) – Unter Linux und macOS stoppt das Schließen der Shell, die Herdr gestartet hat, den Server nicht mehr. Skripte, die Herdr mit SIGHUP gestoppt haben, sollten herdr server stop oder SIGTERM verwenden. Das Serverprotokoll gibt nun an, warum der Server gestoppt wurde. (#4920, #4965)

  • Wenn die Mauserfassung aktiviert ist, erhalten Plugins, die einen Link verarbeiten, die erste Auswahl, wenn Sie ihn anklicken. Schalten Sie die Erfassung aus, um die eigenen Link-Shortcuts Ihres Terminals zu verwenden, wie z. B. Command-click unter macOS. (#4874, #5064, danke @JJLiebig)
  • Antigravity und Grok gelten als inaktiv, sobald sie wieder bei ihrer Eingabeaufforderung sind, auch wenn ihre eigenen Hintergrundaufgaben oder Subagenten noch laufen. (#3530, #4735, #4959)
  • Strg+Umschalt+Buchstabe erreicht einfache Shells wie die Strg-Taste, wie in Alacritty und WezTerm. Super-, Hyper- und Meta-Verknüpfungen geben keinen Escape-Code-Schrott mehr in Apps ein, die sie nicht lesen können. (#4356, #5017)

Behoben

  • Wenn Sie einen Mac neu starten oder Windows herunterfahren, bleiben die Sitzungen Ihrer Agenten erhalten. Herdr speichert, bevor das System mit dem Schließen von Apps beginnt, sodass die Agenten dorthin zurückkehren, wo sie waren. (#4414, #5013, #5057, #5092, danke @JJLiebig)
  • Sitzungsspeicherungen werden auf die Festplatte geschrieben, bevor sie die alte Datei ersetzen, sodass ein Absturz oder ein Stromausfall nicht dazu führen kann, dass die Speicherung unlesbar wird. (#5150, #5152, danke @JJLiebig) – Der Server läuft weiter, wenn der Maschine keine Prozesse oder Threads mehr zur Verfügung stehen, anstatt alle Fenster mit herunterzufahren. (#3324, #4958) – Eine Arbeitsbereichsnummer außerhalb des zulässigen Bereichs gibt workspace_not_found zurück, anstatt den Server zum Absturz zu bringen. (#5096, #5171) – Wenn Sie einen Agenten mit Strg+Z suspendieren und ihn mit fg wieder zurückholen, bleiben sein Name und die gespeicherte Konversation erhalten. (#1647, #4964) – Die Wiederherstellung einer Sitzung bleibt reaktionsfähig, wenn die Git-Daten einer Kasse langsam sind oder fehlen. Worktree-Gruppen überdauern Auscheckvorgänge, die vorübergehend nicht verfügbar sind, und beim zweimaligen Öffnen desselben Repositorys wird ein Arbeitsbereich nicht mehr in dem anderen verschachtelt. (#4926, #4736, #4945, #4770, #4772, danke @minatoaquaMK2 und @JJLiebig)
  • Wenn Sie den einzigen Bereich eines Arbeitsbereichs schließen, werden Sie zuerst gefragt, wie es bereits beim Schließen der letzten Registerkarte der Fall ist. Schalten Sie dies mit ui.confirm_close = false aus. (#5143, #5173)
  • Strg-Tastenkombinationen wie Strg+W funktionieren auf nicht-lateinischen Tastaturlayouts wie Russisch, Griechisch oder Hebräisch. Lateinische Layouts und AltGr-Zeichen behalten ihre normale Bedeutung. (#1079, #4961)
  • Akzenttasten und AltGr-Tastenkombinationen funktionieren unter Windows. (#4688, #5021, danke @JJLiebig) – Umschalt+Eingabe und andere erweiterte Tasten funktionieren weiterhin, nachdem das äußere Terminal zurückgesetzt wurde, beispielsweise nach dem Neuladefenster von VS Code. (#4985, #5088)
  • Quick-Escape-Tips funktionieren unter macOS mit dem Kitty-Tastaturmodus von WezTerm. (#1266, #5089)
  • Kitty-Tastatur-Apps erhalten Tastenfreigaben und F1, F2 und F4 korrekt und die Rücktaste funktioniert, wenn das Terminal dafür Strg+H sendet. (#4184, #4403, #3244, #5017)
  • Farbantworten der Tastatur und des Terminals lassen keine verirrten Zeichen mehr in den Eingabebereich gelangen, und eine halb fertige Farbantwort friert die Eingabe nicht mehr ein. (#4856, #4025, #5052, #5017, #5087)
  • Fish wiederholt Eingabeaufforderungsfragmente nicht mehr, während Sie die Größe eines Fensters ändern. Das gleiche Problem mit zsh und Powerlevel10k ist immer noch offen und wartet auf eine Ghostty-Behebung. (#3672, #4977)
  • Apps, die nach Pixel-Mauskoordinaten fragen, erhalten diese und clicks landen an der richtigen Stelle auf Terminals, die nur Zellen melden. (#4750, #3675, #5017, #4971)
  • Wenn Sie die Kitty-Grafik deaktivieren, wird in den Fenstern die Unterstützung für Werbebilder eingestellt, sodass Apps wieder auf Text zurückgreifen. (#4978, #4979)
  • Die Eingabe erfolgt schneller, insbesondere in PowerShell. (#4884, #5149, danke @JJLiebig) – Große Sitzungen verbrauchen weniger CPU bei ausgelasteten Agenten und inaktiven Shells, ausgeblendete Bereiche verbrauchen weniger Speicher und Windows-Bereiche benötigen weniger Threads. (#4506, #5083, #4845, #4847, #4849, #4850, #4873, #5085, #5091, danke @JJLiebig) – Neue Arbeitsbereiche, Registerkarten und Splits beginnen mit der richtigen Größe ihrer Hülle, anstatt sich die Größe eines anderen Bereichs zu leihen. (#4419, #4873) – Weitergeleitete SSH-Agenten werden nicht mehr jede Sekunde kontaktiert, was möglicherweise die SSH- und Git-Authentifizierung unterbrechen könnte. (#4931, #4962) – Die Breite der Seitenleiste, reduzierte Gruppen und Agentensortierung auf Remote-Rechnern überdauern erneute Verbindungen. Ein schneller Arbeitsplatzwechsel bei gleichzeitigem Maschinenwechsel wird nicht mehr abgebrochen. (#4364, #5019, #4536, #5061, danke @minatoaquaMK2 und @JJLiebig) – Die Schaltfläche zum Reduzieren der Seitenleiste bleibt cliaktivierbar, wenn die Agentenliste über eine Bildlaufleiste verfügt. (#4692, #4734, danke @minatoaquaMK2)
  • Der Begrüßungsbildschirm zeigt Ihr konfiguriertes Präfix. (#4745, #4747, danke @JJLiebig)
  • Strg+[ verlässt die Arbeitsbereichsnavigation. (#1431, #2340, danke @qaz74107410)
  • Tastenkombinationen, die + verwenden, überleben das Neuladen der Konfiguration, und / öffnet die Gehe-zu-Suche in Layouts, in denen die Umschalttaste erforderlich ist. (#4960, #4963, #4983, #5090, danke @minatoaquaMK2) – Beim Einfügen von WezTerm unter Windows in Remote-Fenster werden keine verschlüsselten Schlüsseldaten mehr eingegeben. Durch das Kopieren werden keine doppelten clipboard-Verlaufseinträge mehr hinzugefügt, und das Schließen eines Fensters hängt nicht mehr an einer ausstehenden Eingabetaste. (#4725, #4730, #4709, #4872, danke @JJLiebig) – Windows-Shells, die über Scoop oder 32-Bit-Wrapper gestartet wurden, behalten ihr Arbeitsverzeichnis in neuen Tabs und nach Neustarts. (#4472, #4749, #5062, danke @JJLiebig)
  • Windows ARM64-Maschinen können über den x64-Build nach bestem Wissen und Gewissen als Remote-Hosts verwendet werden. (#4752)
  • Codex meldet abgeschlossene Runden durch seine Integration, wenn er mit --no-daemon gestartet wird, sein Startup-Update-Bildschirm wird als blockiert angezeigt und der Codex- und Pi-Status wird in mehr Fällen erkannt. (#4507, #4811, #4756, #5174, danke @JJLiebig)
  • Antigravity-Berechtigungs-, Frage- und Arbeitsbereich-trust-Dialoge werden als blockiert angezeigt und der Denk-Spinner wird als funktionierend angezeigt. (#3871, #3419, #3530, #4959)
  • Hermes, das über das Python-Installationsprogramm gestartet wurde, wird erkannt und durch die Installation oder Entfernung der Integration bleibt Ihre YAML-Plugin-Liste intakt. (#4910, #4909, #4911, #4984, danke @minatoaquaMK2)
  • Unter macOS lehnen pane run und agent start zu lange Befehle für eine noch startende Shell ab, anstatt sie stillschweigend abzubrechen. (#4950, #4988, danke @minatoaquaMK2)

Entfernt

  • Die experimentelle HERDR_WINDOWS_INPUT_BACKEND=crossterm-Einstellung ist weg. Windows verwendet immer seine native Konsoleneingabe. (#5017)

Englisches Original / English original

herdr v0.9.4

Added

  • herdr plugin update updates plugins installed from GitHub, all at once or by name. Running plugin panes keep working on their old files, and new runs pick up the update without a config reload. Locally linked plugins are left alone. (#4245, thanks @JJLiebig)
  • Windows notifications stay in Notification Center. Clicking one jumps to its pane and brings the terminal window forward. (#4773, #4803, thanks @JJLiebig)

Changed

  • An elevated Windows server now only accepts administrator clients by default. To let normal clients from the same account in, set [server] allow_unelevated_clients = true or start the server with --allow-unelevated-clients. Permission errors now say how to fix them, and sessions you can't reach show as unavailable instead of stopped. (#4717, #4769, #4777, #4779, thanks @JJLiebig)
  • On Linux and macOS, closing the shell that started Herdr no longer stops the server. Scripts that stopped Herdr with SIGHUP should use herdr server stop or SIGTERM. The server log now says why the server stopped. (#4920, #4965)
  • With mouse capture on, plugins that handle a link get first pick when you click it. Turn capture off to use your terminal's own link shortcuts, like Command-click on macOS. (#4874, #5064, thanks @JJLiebig)
  • Antigravity and Grok count as idle once they are back at their prompt, even if their own background tasks or subagents are still running. (#3530, #4735, #4959)
  • Ctrl+Shift+letter reaches plain shells as the Ctrl key, like in Alacritty and WezTerm. Super, Hyper and Meta shortcuts no longer type escape-code junk into apps that can't read them. (#4356, #5017)

Fixed

  • Restarting a Mac or shutting down Windows keeps your agents' sessions. Herdr saves before the system starts closing apps, so agents come back where they were. (#4414, #5013, #5057, #5092, thanks @JJLiebig)
  • Session saves are written to disk before they replace the old file, so a crash or power cut can't leave an unreadable save. (#5150, #5152, thanks @JJLiebig)
  • The server keeps running when the machine runs out of processes or threads, instead of taking every pane down with it. (#3324, #4958)
  • An out-of-range workspace number returns workspace_not_found instead of crashing the server. (#5096, #5171)
  • Suspending an agent with Ctrl+Z and bringing it back with fg keeps its name and saved conversation. (#1647, #4964)
  • Restoring a session stays responsive when a checkout's Git data is slow or missing. Worktree groups survive checkouts that are temporarily unavailable, and opening the same repository twice no longer nests one workspace inside the other. (#4926, #4736, #4945, #4770, #4772, thanks @minatoaquaMK2 and @JJLiebig)
  • Closing a workspace's only pane asks first, like closing its last tab already does. Turn this off with ui.confirm_close = false. (#5143, #5173)
  • Ctrl shortcuts like Ctrl+W work on non-Latin keyboard layouts such as Russian, Greek or Hebrew. Latin layouts and AltGr characters keep their normal meaning. (#1079, #4961)
  • Accent keys and AltGr shortcuts work on Windows. (#4688, #5021, thanks @JJLiebig)
  • Shift+Enter and other enhanced keys keep working after the outer terminal resets, for example after VS Code's Reload Window. (#4985, #5088)
  • Quick Escape taps work on macOS with WezTerm's Kitty keyboard mode. (#1266, #5089)
  • Kitty keyboard apps get key releases and F1, F2 and F4 correctly, and Backspace works when the terminal sends Ctrl+H for it. (#4184, #4403, #3244, #5017)
  • Keyboard and terminal color replies no longer leak stray characters into pane input, and a half-finished color reply no longer freezes typing. (#4856, #4025, #5052, #5017, #5087)
  • Fish no longer repeats prompt fragments while you resize a pane. The same problem with zsh and Powerlevel10k is still open, waiting on a Ghostty fix. (#3672, #4977)
  • Apps that ask for pixel mouse coordinates get them, and clicks land in the right place on terminals that only report cells. (#4750, #3675, #5017, #4971)
  • Turning off Kitty graphics makes panes stop advertising image support, so apps fall back to text. (#4978, #4979)
  • Typing shows up faster, especially in PowerShell. (#4884, #5149, thanks @JJLiebig)
  • Big sessions use less CPU on busy agents and idle shells, hidden panes use less memory, and Windows panes need fewer threads. (#4506, #5083, #4845, #4847, #4849, #4850, #4873, #5085, #5091, thanks @JJLiebig)
  • New workspaces, tabs and splits start their shell at the right size instead of borrowing another pane's size. (#4419, #4873)
  • Forwarded SSH agents are no longer contacted every second, which could eventually break SSH and Git authentication. (#4931, #4962)
  • Sidebar width, collapsed groups and agent sorting on remote machines survive reconnects. Switching workspaces quickly while changing machines no longer gets canceled. (#4364, #5019, #4536, #5061, thanks @minatoaquaMK2 and @JJLiebig)
  • The sidebar collapse button stays clickable when the agent list has a scrollbar. (#4692, #4734, thanks @minatoaquaMK2)
  • The welcome screen shows your configured prefix. (#4745, #4747, thanks @JJLiebig)
  • Ctrl+[ leaves workspace navigation. (#1431, #2340, thanks @qaz74107410)
  • Keybindings that use + survive config reloads, and / opens Go To search on layouts where it needs Shift. (#4960, #4963, #4983, #5090, thanks @minatoaquaMK2)
  • Pasting from WezTerm on Windows into remote panes no longer types encoded key data. Copying no longer adds duplicate clipboard history entries, and closing a pane no longer hangs on a pending Enter. (#4725, #4730, #4709, #4872, thanks @JJLiebig)
  • Windows shells started through Scoop or 32-bit wrappers keep their working directory in new tabs and after restarts. (#4472, #4749, #5062, thanks @JJLiebig)
  • Windows ARM64 machines can be used as remote hosts through the x64 build, on a best-effort basis. (#4752)
  • Codex reports finished turns through its integration when started with --no-daemon, its startup update screen shows as blocked, and Codex and Pi status is recognized in more cases. (#4507, #4811, #4756, #5174, thanks @JJLiebig)
  • Antigravity permission, question and workspace-trust dialogs show as blocked, and its thinking spinner shows as working. (#3871, #3419, #3530, #4959)
  • Hermes started through its Python installer is recognized, and installing or removing its integration keeps your YAML plugin list intact. (#4910, #4909, #4911, #4984, thanks @minatoaquaMK2)
  • On macOS, pane run and agent start refuse commands too long for a shell that is still starting, instead of silently cutting them off. (#4950, #4988, thanks @minatoaquaMK2)

Removed

  • The experimental HERDR_WINDOWS_INPUT_BACKEND=crossterm setting is gone. Windows always uses its native console input. (#5017)
