Scrapling v0.4

Die bisher größte Veröffentlichung von Scrapling – Einführung des Spider-Frameworks, der Proxy-Rotation und wichtiger Parser-Verbesserungen

Diese Version bringt ein vollständig asynchrones Spider-/Crawling-Framework, intelligentes Proxy-Management und bedeutende API-Änderungen mit sich, die Scrapling leistungsfähiger und konsistenter machen. Bitte lesen Sie den Abschnitt „Breaking Changes“ sorgfältig durch, bevor Sie ein Upgrade durchführen.

🕷️ Spinnen-Framework

Ein neues asynchrones Crawling-Framework, das auf anyio aufbaut, für strukturiertes, umfangreiches scraping:

from scrapling.spiders import Spider, Response

class MySpider(Spider):
  name = "demo"
  start_urls = ["https://example.com/"]

  async def parse(self, response: Response):
      for item in response.css('.product'):
          yield {"title": item.css('h2::text').get()}

MySpider().start()
  • Scrapy-like Spider API: Definieren Sie Spiders mit start_urls, asynchronen parse-Callbacks, Request/Response-Objekten und einer Prioritätswarteschlange.
  • Gleichzeitiges Crawling: Konfigurierbare Parallelitätsgrenzen, Drosselung pro Domäne und Download-Verzögerungen.
  • Unterstützung mehrerer Sitzungen: Einheitliche Schnittstelle für HTTP-Anfragen und versteckte Headless-Browser in einem einzigen Spider – Leiten Sie Anfragen anhand der ID an verschiedene Sitzungen weiter. Unterstützt die verzögerte Sitzungsinitialisierung.
  • Pause & Resume: Checkpoint-basierte Crawl-Persistenz. Drücken Sie Strg+C, um ordnungsgemäß herunterzufahren. Starten Sie dann neu, um dort fortzufahren, wo Sie aufgehört haben.
  • Streaming-Modus: Streamen Sie gelöschte Elemente, sobald sie über async for item in spider.stream() eintreffen, mit Echtzeitstatistiken – ideal für Benutzeroberflächen, Pipelines und lang laufende Crawls.
  • Erkennung blockierter Anfragen: Automatische Erkennung und Wiederholung blockierter Anfragen mit anpassbarer Logik.
  • Integrierter Export: Exportieren Sie Ergebnisse über Hooks und Ihre eigene Pipeline oder den integrierten JSON/JSONL mit result.items.to_json() bzw. result.items.to_jsonl().
  • Lebenszyklus-Hooks: on_start(), on_close(), on_error(), on_scraped_item() und weitere Hooks für die vollständige Kontrolle über den Crawl-Lebenszyklus.
  • Detaillierte Crawl-Statistiken: Verfolgen Sie Anfragen, Antworten, Bytes, Statuscodes, Proxys, Aufschlüsselungen pro Domäne/Sitzung, Anzahl der Protokollebenen und mehr.
  • UVloop-Unterstützung: Übergeben Sie use_uvloop=True an spider.start() für eine schnellere asynchrone Ausführung, sofern verfügbar.

🔄 Proxy-Rotation

  • Neue ProxyRotator-Klasse mit threadsicherer Rotation. Funktioniert mit allen Fetchern und Sitzungen: 
    from scrapling import ProxyRotatorrotator = ProxyRotator(["http://proxy1:8080", "http://proxy2:8080"])Fetcher.get(url, proxy_rotator=rotator)
  • Benutzerdefinierte Rotationsstrategien: Erstellen Sie Ihre eigene Proxy-Rotationslogik
  • Proxy-Überschreibung pro Anfrage: Übergeben Sie proxy= an jeden einzelnen get()/post()/fetch()-Aufruf, um den Sitzungsproxy für diese Anfrage zu überschreiben.

🌐 Verbesserungen beim Browser-Fetcher

  • Domain-Blockierung: Neuer blocked_domains-Parameter auf DynamicFetcher/StealthyFetcher, um Anfragen an bestimmte Domains zu blockieren (Subdomains werden automatisch abgeglichen).
  • Automatische Wiederholungsversuche: Browser-Abrufe versuchen es jetzt bei einem Fehler erneut mit den Parametern retries (Standard: 3) und retry_delay (Standard: 1s). Beinhaltet eine Proxy-fähige Fehlererkennung.
  • Antwortmetadaten: Response.meta dict speichert automatisch den verwendeten Proxy und führt Anforderungsmetadaten zusammen.
  • Response.follow(): Erstellen Sie Folge-Request-Objekte mit automatischem Referrer-Fluss, entwickelt für das Spider-System.
  • Keine automatische Wiedergabe: Browsersitzungen blockieren jetzt die automatische Wiedergabe von Inhalten, was zuvor zu Problemen geführt hat.
  • Geschwindigkeit: Verbesserte Tarnung und Geschwindigkeit durch Anpassen der Browser-Flags.

🔧 Fehlerbehebungen und Verbesserungen

  • Parser-Optimierung: Der Parser wurde für wiederholte Vorgänge optimiert und so die Leistung verbessert.
  • Fehlerhafte Seiten: Es wurde ein Fehler behoben, der dazu führte, dass der Browser nicht geschlossen wurde, wenn Seiten fehlerhafte Seiten lieferten.
  • Leerer Text: Behandeln Sie Antworten mit leerem Text.
  • Playwright-Schleife: Behebung eines Problems beim Offenlassen der Playwright-Schleife, wenn die CDP-Verbindung fehlschlägt
  • Typsicherheit: Alle Mypy-Fehler wurden behoben und Typhinweise für nicht typisierte Funktionskörper hinzugefügt. Mypy und Pyright zum CI-Workflow hinzugefügt.

⚠️ Breaking Changes

  • css_first/xpath_first entfernt: Verwenden Sie stattdessen css('.selector').first, css('.selector')[0] oder css('.selector').get().
  • Alle Auswahlen geben jetzt Selectors zurück: css('::text'), xpath('//text()'), css('::attr(href)') und xpath('//@href') geben jetzt Selectors zurück (Textknoten in Selector-Objekten werden mit tag="#text" umbrochen) anstelle von TextHandlers. Dadurch wird API über alle Auswahlmethoden und Typhinweise hinweg konsistent.
  • Response.body ist immer bytes: Konnte bisher str oder bytes sein, gibt jetzt immer bytes zurück.
  • get()/getall()-Verhalten: Bei Selector: get() gibt TextHandler (serialisierter HTML- oder Textwert) zurück, getall() gibt TextHandlers zurück. Aliase: extract_first = get, extract = getall. Der alte get_all() auf Selectors wird entfernt.
  • Selectors.first/.last: Sichere Accessoren, die Selector | None zurückgeben, anstatt IndexError auszulösen.
  • Interne Konstanten umbenannt: DEFAULT_FLAGS → DEFAULT_ARGS, DEFAULT_STEALTH_FLAGS → STEALTH_ARGS, HARMFUL_DEFAULT_ARGS → HARMFUL_ARGS, DEFAULT_DISABLED_RESOURCES → EXTRA_RESOURCES.

🔨 Weitere Änderungen

  • Abhängigkeitsänderungen: tldextract durch tld ersetzt, internes _html_utils.py zugunsten von w3lib.html.replace_entities entfernt, typing_extensions als zwingende Anforderung hinzugefügt.
  • Überarbeitung der Dokumente: Vollständiger Wechsel von MkDocs zu Zensical, neuer Abschnitt zur Spider-Dokumentation, Aktualisierung aller vorhandenen Seiten und Hinzufügung neuer API-Referenzen.

Scrapling v0.4

Highlights

  • New Spider framework — the headline feature — A fully async crawling framework built on anyio with a Scrapy-like API (start_urls, async parse, Request/Response, priority queue). It adds concurrent crawling with per-domain throttling, multi-session support that unifies plain HTTP and stealthy headless browsers by session ID, Ctrl+C pause/resume via checkpoints, async for item in spider.stream() for streaming results, lifecycle hooks (on_start(), on_close(), on_error(), on_scraped_item()), built-in result.items.to_json() / to_jsonl() export, and optional use_uvloop=True. If you were bolting your own crawl loop onto a fetcher, this is a strong reason to upgrade.

  • Proxy rotation and browser fetcher upgrades — New thread-safe ProxyRotator works across all fetchers/sessions, supports custom strategies, and can be overridden per request with proxy= on any get()/post()/fetch(). Browser fetchers gain blocked_domains (subdomains matched automatically), automatic retries via retries (default 3) / retry_delay (default 1s) with proxy-aware error detection, Response.meta carrying the proxy used, Response.follow() for referer-aware requests, autoplay blocking, and faster stealth flags. Notably useful for anyone fighting blocks or running large proxy pools.

  • BREAKING — expect to migrate existing code — This release is not a drop-in upgrade. css_first/xpath_first are removed (use .first, [0], or .get()); text/attribute selections like css('::text') and xpath('//@href') now return Selectors wrapping Selector objects with tag="#text" instead of TextHandlers; Response.body is now always bytes; Selector.get() returns TextHandler and getall() returns TextHandlers, while get_all() on Selectors is removed; Selectors.first/.last are now safe (Selector | None, no IndexError); and internal constants were renamed (DEFAULT_FLAGS→DEFAULT_ARGS, DEFAULT_STEALTH_FLAGS→STEALTH_ARGS, HARMFUL_DEFAULT_ARGS→HARMFUL_ARGS, DEFAULT_DISABLED_RESOURCES→EXTRA_RESOURCES). Dependency changes also land: tldextract replaced by tld, internal _html_utils.py dropped in favor of w3lib.html.replace_entities, and typing_extensions is now a hard requirement. Budget real refactoring time before upgrading.

  • Type safety, reliability fixes, and docs migration — All mypy errors fixed with type hints added to previously untyped function bodies, and mypy + pyright added to CI. Bug fixes cover parser optimization for repeated operations, browsers not closing on errored pages, empty-body responses, and a leaked Playwright loop on failed CDP connections. Docs moved from MkDocs to Zensical with a new spiders section and API references. Good hygiene wins, but secondary to the framework and breaking changes.

  • Verdict: upgrade for new crawlers and block-heavy workloads; pause if you're deeply coupled to the old selection API — Worth it if you need structured large-scale crawling, proxy rotation, or the new browser retry/blocking behavior, and you're willing to work through the selection/body/constant migrations. You can reasonably skip or delay if you're on a stable, simple single-page scraping setup that relies heavily on css_first/xpath_first, text-vs-Selectors return types, get_all(), or the old constant names and can't absorb the breaking changes right now.

The biggest release of Scrapling yet — introducing the Spider framework, proxy rotation, and major parser improvements

This release brings a fully async spider/crawling framework, intelligent proxy management, and significant API changes that make Scrapling more powerful and consistent. Please review the breaking changes section carefully before upgrading.

🕷️ Spider Framework

A new async crawling framework built on top of anyio for structured, large-scale scraping:

from scrapling.spiders import Spider, Response

class MySpider(Spider):
  name = "demo"
  start_urls = ["https://example.com/"]

  async def parse(self, response: Response):
      for item in response.css('.product'):
          yield {"title": item.css('h2::text').get()}

MySpider().start()
  • Scrapy-like Spider API: Define spiders with start_urls, async parse callbacks, Request/Response objects, and priority queue.
  • Concurrent Crawling: Configurable concurrency limits, per-domain throttling, and download delays.
  • Multi-Session Support: Unified interface for HTTP requests, and stealthy headless browsers in a single spider - route requests to different sessions by ID. Supports lazy session initialization.
  • Pause & Resume: Checkpoint-based crawl persistence. Press Ctrl+C to gracefully shut down; then restart to resume from where you left off.
  • Streaming Mode: Stream scraped items as they arrive via async for item in spider.stream() with real-time stats - ideal for UI, pipelines, and long-running crawls.
  • Blocked Request Detection: Automatic detection and retry of blocked requests with customizable logic.
  • Built-in Export: Export results through hooks and your own pipeline or the built-in JSON/JSONL with result.items.to_json() / result.items.to_jsonl() respectively.
  • Lifecycle hooks: on_start(), on_close(), on_error(), on_scraped_item(), and more hooks for full control over the crawl lifecycle.
  • Detailed crawl stats: track requests, responses, bytes, status codes, proxies, per-domain/session breakdowns, log level counts, and more.
  • uvloop support: Pass use_uvloop=True to spider.start() for faster async execution when available.

🔄 Proxy Rotation

  • New ProxyRotator class with thread-safe rotation. Works with all fetchers and sessions: 
    from scrapling import ProxyRotatorrotator = ProxyRotator(["http://proxy1:8080", "http://proxy2:8080"])Fetcher.get(url, proxy_rotator=rotator)
  • Custom rotation strategies: Make your own proxy rotation logic
  • Per-request proxy override: Pass proxy= to any individual get()/post()/fetch() call to override the session proxy for that request.

🌐 Browser Fetcher Improvements

  • Domain blocking: New blocked_domains parameter on DynamicFetcher/StealthyFetcher to block requests to specific domains (subdomains matched automatically).
  • Automatic retries: Browser fetchers now retry on failure with retries (default: 3) and retry_delay (default: 1s) parameters. Includes proxy-aware error detection.
  • Response metadata: Response.meta dict automatically stores the proxy used, and merges request metadata.
  • Response.follow(): Create follow-up Request objects with automatic referer flow, designed for the spider system.
  • No autoplay: Browser sessions are now blocking autoplay content, which caused issues before.
  • Speed: Improved stealth and speed by adjusting browser flags.

🔧 Bug Fixes & Improvements

  • Parser optimization: Optimized the parser for repeated operations, improving performance.
  • Errored pages: Fixed a bug that caused the browser to not close when pages gave errors.
  • Empty body: Handle responses with empty body.
  • Playwright loop: Solving an issue with leaving the Playwright loop open when CDP connection fails
  • Type safety: Fixed all mypy errors and added type hints across untyped function bodies. Added mypy and pyright to the CI workflow.

⚠️ Breaking Changes

  • css_first/xpath_first removed: Use css('.selector').first, css('.selector')[0], or css('.selector').get() instead.
  • All selection now returns Selectors: css('::text'), xpath('//text()'), css('::attr(href)'), and xpath('//@href') now return Selectors (wrapping text nodes in Selector objects with tag="#text") instead of TextHandlers. This makes the API consistent across all selection methods and the type hints.
  • Response.body is always bytes: Previously could be str or bytes, now always returns bytes.
  • get()/getall() behavior: On Selector: get() returns TextHandler (serialized HTML or text value), getall() returns TextHandlers. Aliases: extract_first = get, extract = getall. Old get_all() on Selectors is removed.
  • Selectors.first/.last: Safe accessors that return Selector | None instead of raising IndexError.
  • Internal constants renamed: DEFAULT_FLAGS → DEFAULT_ARGS, DEFAULT_STEALTH_FLAGS → STEALTH_ARGS, HARMFUL_DEFAULT_ARGS → HARMFUL_ARGS, DEFAULT_DISABLED_RESOURCES → EXTRA_RESOURCES.

🔨 Other Changes

  • Dependency changes: Replaced tldextract with tld, removed internal _html_utils.py in favor of w3lib.html.replace_entities, added typing_extensions as a hard requirement.
  • Docs overhaul: Full switch from MkDocs to Zensical, new spider documentation section, updated all existing pages, and added new API references.
