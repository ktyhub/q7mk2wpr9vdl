🚀 Neue Funktionen: Zusammenfassender Index

Wir führen Summary Index ein, eine leistungsstarke Erweiterung unseres Wissensdatenbank-Abrufsystems, das die Suchgenauigkeit erheblich verbessert, indem es KI-gestützte Zusammenfassungen für Dokumentblöcke generiert.

Hintergrund

Die herkömmliche Vektorsuche basiert auf rohen Chunk-Einbettungen, die beim Abgleichen von Benutzeranfragen semantische Nuancen und Kontext übersehen können. Dies stellt eine besondere Herausforderung bei langen Dokumenten oder komplexen Inhalten dar, bei denen wichtige Informationen möglicherweise über mehrere Abschnitte verteilt sind. Summary Index behebt dieses Problem, indem für jeden Dokumentabschnitt prägnante, semantisch umfassende Zusammenfassungen erstellt werden, die dann vektorisiert und als zusätzliche Abrufebene verwendet werden.

Schlüsselfunktionen

  • KI-gestützte Zusammenfassung: Erstellt mithilfe konfigurierbarer LLM-Modelle automatisch prägnante Zusammenfassungen für Dokumentblöcke und erfasst wichtige semantische Informationen in einem kompakten Format.
  • Multimodale Unterstützung: Bei Verwendung visionfähiger LLMs (z. B. GPT-4V, Claude-3) kann das System Zusammenfassungen generieren, die sowohl Text als auch Bilder aus Dokumentblöcken enthalten und so ein umfassenderes Kontextverständnis ermöglichen.
  • Verbesserte Abrufgenauigkeit: Zusammenfassungsvektoren dienen als zusätzliche Abrufebene und verbessern die Präzision von Wissensdatenbanksuchen, indem sie Abfragen sowohl mit Originalinhalten als auch mit KI-generierten Zusammenfassungen abgleichen.
  • Flexible Konfiguration: Unterstützt standardmäßige Zusammenfassungsaufforderungen, sodass Sie den Zusammenfassungsstil an Ihre domänenspezifischen Anforderungen anpassen können.
  • Asynchrone Verarbeitung: Die Zusammenfassungsgenerierung läuft asynchron und stellt so sicher, dass die Dokumentindizierung schnell und nicht blockierend bleibt.
  • Manuelle Zusammenfassungsbearbeitung: Ermöglicht Ihnen die manuelle Bearbeitung und Verfeinerung von KI-generierten Zusammenfassungen, um sie besser an den ursprünglichen Blockinhalt anzupassen und sicherzustellen, dass Zusammenfassungen die domänenspezifische Terminologie und den Kontext genau widerspiegeln.
  • Kompatibilität der Indexstruktur: Funktioniert sowohl im allgemeinen Chunking- als auch im Parent-Child-Chunking-Modus mit intelligenter Handhabung hierarchischer Dokumentbeziehungen.
  • High-Quality-Index-Integration: Exklusiv verfügbar für Datensätze, die die Indexierungstechnik „high_quality“ verwenden, um eine optimale Leistung für Produktionswissensdatenbanken sicherzustellen.

Weitere Verbesserungen

  • Multimodale Unterstützung der Agent-App: Die Agent-App unterstützt jetzt nativ multimodale Eingaben (Bilder/Dateien).
  • Qdrant-Volltextsuche: Volltextsuche mit Unterstützung mehrerer Schlüsselwörter für die Qdrant-Vektordatenbank implementiert.
  • Workflow-Verbesserungen:
    • Unterstützung für das Registrieren und Lesen von Kontext in Workflows hinzugefügt.
    • OpenTelemetry-Unterstützung für Einzelläufe hinzugefügt.
  • Plugin-System: Option zum Löschen oder Beibehalten von API-Schlüsseln bei der Deinstallation eines Plugins hinzugefügt.
  • Vorlagenvorschau vor dem Erstellen: Eine detaillierte App-Vorlagenvorschau mit Workflow-Diagrammen oder App-Konfigurationen nach App-Typ hinzugefügt.

  • ENABLE_EXPLORE_BANNER: Aktiviert das Erkundungsbanner (Standard: false).

Upgrade-Anleitung

Docker Bereitstellungen erstellen

  1. Sichern Sie Ihre angepasste docker-compose YAML-Datei (optional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Holen Sie sich den neuesten Code aus der Hauptniederlassung

    git checkout main
git pull origin main

  3. Stoppen Sie den Dienst. Bitte im Verzeichnis docker ausführen

    docker compose down

  4. Daten sichern

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Upgrade-Dienste

    docker compose up -d

dify 1.12.0

🚀 New Features: Summary Index

We are introducing Summary Index, a powerful enhancement to our knowledge base retrieval system that significantly improves search accuracy by generating AI-powered summaries for document chunks.

Background

Traditional vector search relies on raw chunk embeddings, which can miss semantic nuances and context when matching user queries. This is especially challenging for long documents or complex content where key information might be scattered across multiple chunks. Summary Index addresses this by creating concise, semantically-rich summaries for each document chunk, which are then vectorized and used as an additional retrieval layer.

Key Capabilities

  • AI-Powered Summarization: Automatically generates concise summaries for document chunks using configurable LLM models, capturing essential semantic information in a compact format.
  • Multimodal Support: When using vision-capable LLMs (e.g., GPT-4V, Claude-3), the system can generate summaries that incorporate both text and images from document chunks, providing richer context understanding.
  • Enhanced Retrieval Accuracy: Summary vectors serve as an additional retrieval layer, improving the precision of knowledge base searches by matching queries against both original content and AI-generated summaries.
  • Flexible Configuration: Supports default summary prompts, allowing you to tailor the summarization style to match your domain-specific requirements.
  • Asynchronous Processing: Summary generation runs asynchronously, ensuring that document indexing remains fast and non-blocking.
  • Manual Summary Editing: Allows you to manually edit and refine AI-generated summaries to better align with the original chunk content, ensuring summaries accurately reflect domain-specific terminology and context.
  • Index Structure Compatibility: Works with both general chunking and parent-child chunking modes, with intelligent handling of hierarchical document relationships.
  • High-Quality Index Integration: Available exclusively for datasets using the "high_quality" indexing technique, ensuring optimal performance for production knowledge bases.

Other Improvements

  • Agent App Multimodal Support: Agent App now natively supports multimodal inputs (images/files).
  • Qdrant Full-Text Search: Implemented full-text search with multi-keyword support for Qdrant vector database.
  • Workflow Enhancements:
    • Added support for registering and reading context in workflows.
    • Added OpenTelemetry support for single runs.
  • Plugin System: Added an option to delete or keep API keys when uninstalling a plugin.
  • Template Preview Before Creating: Added a detailed app template preview with workflow graphs or app configs by app type.

    • Fixed CORS resource pattern for /console/api routes.
