🚀 Was ist neu in v1.14.2?

v1.14.2 ist eine Patch-Version, die sich nach v1.14.1 auf Sicherheitshärtung, Workflow- und Wissenszuverlässigkeit, Beobachtbarkeitskorrekturen, Agentenvorbereitung und Bereitstellungs-/Laufzeitoptimierung konzentriert.

🔐 Sicherheit und Verwaltung

  • Sensible Endpunkte im Mandantenbereich – verbesserte Mandantenisolation für App-Trace-Konfigurationsendpunkte und FilePreview-Textextraktion. Danke @xr843 in #35793 und #35797.
  • Sicherheit der Tool-Anmeldeinformationen – Aktualisierungen der standardmäßig integrierten Tool-Anmeldeinformationen wurden auf Arbeitsbereichsadministratoren und -besitzer beschränkt und während reset-encrypt-key-pair wurden veraltete Mandanten-Tool-Anmeldeinformationen bereinigt. Danke @NeatGuyCoding und @xr843 in #36264 und #35843.

🧩 Workflow, HITL und App-Laufzeit

  • Zuverlässigkeit der Workflow-Ausführung – Wiederherstellung der Ablaufverfolgung nach Wiederaufnahme des HITL-Workflows, verbesserte Callback-Verfolgung der Workflow-Ausführung, reduzierte Nachrichtenaktualisierungs-Datenbank-Roundtrips, korrigierte Speicherabrufe außerhalb des Flask-Kontexts und korrekt geschlossene Base64-Dateisuchsitzungen. Danke @Blackoutta, @CodingOnStar, @wylswz, @hjlarry und @escape0707 in #36064, #36149, #36213, #36253 und #36308.
  • Verfeinerung von Workflow und Modellauswahl – korrigiertes Ladeverhalten, wenn kein Modell ausgewählt ist, gefilterte Modellvoreinstellungen nach unterstützten Parametern und verbesserte Steuerelemente für den Erweiterungsdialog API. Danke @iamjoel und @lyzno1 in #36342, #36339 und #36323.

📚 Daten, RAG und Wissen

  • Stabilität der Wissensbasis – Rendering von Wissenstreffertests, leere Wissenserstellung, empfohlene App-Kategoriereihenfolge und Nullbehandlung beim Abrufen empfohlener App-Details korrigiert. Danke @FFXN, @laipz8200, @hjlarry und @EvanYao826 in #36106, #36336, #36161 und #36153.
  • RAG- und Dokumentverarbeitung – erlaubte LLM-Knoten den Zugriff auf abgerufene Wissensdateien, regenerierte Dokumentzusammenfassungen nach API-Updates, korrigierte das Rendern von Pipeline-Vorlagen und behandelte Fehler beim Abrufen von Anmeldeinformationen in RAG-Pipelines eleganter. Vielen Dank an @laipz8200, @EvanYao826, @FFXN und @linw1995 in #36175, #36035, #36168 und #36165.

🎨 Web-UI und Produkterfahrung

  • App-Erstellung und Onboarding – verfolgte App-Erstellungsquelle und Vorlagen-ID, initialisierte Benutzerzeitzone und -sprache über den Browser sowie korrigierte Anzeige von WebApp-Symbolen und -Beschreibungen. Vielen Dank an @CodingOnStar, @lyzno1 und @JzoNgKVO in #36369, #36170, #36206 und #36209.
  • Benutzeroberfläche für Annotationen und Datensätze – erlaubte Annotations-Antwort-Score-Schwellenwerte unter 0.8, leitete nicht autorisierte Wissenseditoren zurück zu Datensätzen um und korrigierte die Umbenennung von Tags ohne Typnutzlast. Danke @JzoNgKVO, @iamjoel und @lyzno1 in #36337, #36073 und #36182.
  • Migration und Verfeinerung der UI-Plattform – Checkbox- und CheckboxGroup-Grundelemente hinzugefügt, mehr Steuerelemente auf @langgenius/dify-ui migriert, Dialogüberlauf-Layouts verbessert und Konto-Avatar- und Installationsablauf-Interaktionen verfeinert. Vielen Dank an @lyzno1 und @CodingOnStar in #36271, #36295, #36255, #36302, #36111, #36199 und #36210.

🔎 Beobachtbarkeit und Rückverfolgung

  • Tracing-Zuverlässigkeit – isolierte Langfuse v3 SDK-Tracer-Anbieter, um aufgabenübergreifende Interferenzen zu verhindern, und hinzugefügtes Phoenix-Fallback-Verhalten für übergeordnete Traces. Danke @GareArc und @Blackoutta in #36136 und #36290.

⚙️ Bereitstellung, Abhängigkeiten und Entwicklererfahrung

  • Bereitstellungsoptimierung – Plugin-Daemon auf 0.6.1 aktualisiert, die standardmäßige Mindest-Worker-Anzahl von GraphEngine erhöht und Docker-README-Referenzen aktualisiert. Vielen Dank an @laipz8200, @kenwoodjw und @RiskeyL in #36312, #35650 und #36303.
  • Backend- und CI-Wartung – statische Analyse in Richtung Pyrefly verschoben, Graphon auf 0.4.0 aktualisiert, Hotfix-Cherry-Pick-Herkunftsprüfungen hinzugefügt und generierte Vertragsworkflows verbessert. Danke @cqjjjzr, @laipz8200 und @hyoban in #36154, #36124, #36340 und #36286.
  • Abhängigkeitsaktualisierungen – aktualisierte Backend- und Agent-Abhängigkeiten, einschließlich authlib, ujson, langsmith und urllib3. Danke @dependabot[bot] in #36112, #36121, #36142 und #36160.

Upgrade-Anleitung

[!IMPORTANT]

– Diese Version beinhaltet eine neue Datenbankmigration für konfigurierbare Explore-App-Kategorien. Führen Sie im Rahmen des Upgrades Datenbankmigrationen durch.

  • Docker Compose-Umgebungsvariablen werden jetzt in kategorisierte Dateien unter docker/envs/** aufgeteilt. Wenn Sie ein angepasstes docker-compose.yaml oder .env verwalten, überprüfen Sie das neue Layout und wenden Sie die lokalen Anpassungen erneut sorgfältig an. – Bei selbstgehosteten Bereitstellungen werden explizit konfigurierte SECRET_KEY-Werte weiterhin berücksichtigt. Wenn SECRET_KEY leer ist, generiert und speichert Dify jetzt automatisch einen Laufzeitschlüssel.

Docker Bereitstellungen erstellen

  1. Sichern Sie Ihre benutzerdefinierten docker-compose YAML- und env-Dateien.

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak
cp .env .env.$(date +%s).bak 2>/dev/null || true

  2. Holen Sie sich den neuesten Code aus dem Release-Zweig oder Tag.

    git fetch --tags
git checkout 1.14.2

  3. Stoppen Sie den Dienst. Bitte im Verzeichnis docker ausführen.

    docker compose down

  4. Daten sichern.

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Überprüfen Sie das neue docker/envs/**-Env-Dateilayout und wenden Sie alle lokalen Anpassungen erneut an.

  6. Upgrade-Dienste.

    docker compose up -d

Quellcode-Bereitstellungen

  1. Stoppen Sie den API-Server, den Worker und den Web-Frontend-Server.

  2. Holen Sie sich den neuesten Code aus dem Release-Tag.

    git fetch --tags
git checkout 1.14.2

  3. Aktualisieren Sie die Python-Abhängigkeiten.

    cd api
uv sync

  4. Führen Sie das Migrationsskript aus.

    uv run flask db upgrade

  5. Starten Sie den API-Server, den Worker und den Web-Frontend-Server neu.

dify 1.14.2

🚀 What's New in v1.14.2?

v1.14.2 is a patch release focused on security hardening, workflow and knowledge reliability, observability fixes, agent groundwork, and deployment/runtime tuning after v1.14.1.

🔐 Security and administration

  • Tenant-scoped sensitive endpoints — strengthened tenant isolation for app trace-config endpoints and FilePreview text extraction. Thanks @xr843 in #35793 and #35797.
  • Tool credential safety — restricted default builtin tool credential updates to workspace admins and owners, and cleaned stale tenant tool credentials during reset-encrypt-key-pair. Thanks @NeatGuyCoding and @xr843 in #36264 and #35843.

🧩 Workflow, HITL, and app runtime

  • Workflow execution reliability — restored tracing after HITL workflow resume, improved workflow run callback tracking, reduced message-update database roundtrips, fixed memory fetches outside Flask context, and closed base64 file lookup sessions correctly. Thanks @Blackoutta, @CodingOnStar, @wylswz, @hjlarry, and @escape0707 in #36064, #36149, #36213, #36253, and #36308.
  • Workflow and model selection polish — fixed loading behavior when no model is selected, filtered model presets by supported parameters, and improved API extension dialog controls. Thanks @iamjoel and @lyzno1 in #36342, #36339, and #36323.

📚 Data, RAG, and knowledge

  • Knowledge-base stability — fixed knowledge hit-testing rendering, empty knowledge creation, recommended app category ordering, and null handling in recommended app detail retrieval. Thanks @FFXN, @laipz8200, @hjlarry, and @EvanYao826 in #36106, #36336, #36161, and #36153.
  • RAG and document processing — allowed LLM nodes to access retrieved knowledge files, regenerated document summaries after API updates, fixed pipeline template rendering, and handled credential fetch failures in RAG pipelines more gracefully. Thanks @laipz8200, @EvanYao826, @FFXN, and @linw1995 in #36175, #36035, #36168, and #36165.

🎨 Web UI and product experience

  • App creation and onboarding — tracked app creation source and template ID, initialized user timezone and language from the browser, and fixed WebApp icon and description display. Thanks @CodingOnStar, @lyzno1, and @JzoNgKVO in #36369, #36170, #36206, and #36209.
  • Annotation and datasets UI — allowed annotation reply score thresholds below 0.8, redirected unauthorized knowledge editors back to datasets, and fixed tag rename without type payload. Thanks @JzoNgKVO, @iamjoel, and @lyzno1 in #36337, #36073, and #36182.

Upgrade Guide

[!IMPORTANT]

  • This release includes a new database migration for configurable Explore app categories. Run database migrations as part of the upgrade.
  • Docker Compose environment variables are now split into categorized files under docker/envs/**. If you maintain a customized docker-compose.yaml or .env, review the new layout and re-apply local customizations carefully.
  • For self-hosted deployments, explicitly configured SECRET_KEY values continue to be respected. If SECRET_KEY is empty, Dify now generates and persists a runtime key automatically.

Docker Compose Deployments

  1. Back up your customized docker-compose YAML and env files.

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak
cp .env .env.$(date +%s).bak 2>/dev/null || true

  2. Get the latest code from the release branch or tag.

    git fetch --tags
git checkout 1.14.2

  3. Stop the service. Please execute in the docker directory.

    docker compose down

  4. Back up data.

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Review the new docker/envs/** env file layout and re-apply any local customizations.

  6. Upgrade services.

    docker compose up -d

Source Code Deployments

  1. Stop the API server, Worker, and Web frontend Server.

  2. Get the latest code from the release tag.

    git fetch --tags
git checkout 1.14.2

  3. Update Python dependencies.

    cd api
uv sync

  4. Run the migration script.

    uv run flask db upgrade

  5. Restart the API server, Worker, and Web frontend Server.
