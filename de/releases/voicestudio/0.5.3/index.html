VoiceStudio v0.5.3

Ein neuer Look. Eine neue Desktop-App. Immer noch Ihre Stimmen, auf Ihrem Gerät.

VoiceStudio wechselt mit v0.5.3 zu Electron: einem neu gestalteten Arbeitsbereich für Stimmklonung, Stimmdesign, Geschichten, Synchronisation und Transkription. Electron ist jetzt die primäre Desktop-App für Windows, macOS und Linux. Die lokale Spracherstellung läuft weiterhin auf Ihrer eigenen Hardware, ohne dass ein Konto oder ein API-Schlüssel erforderlich ist.

Highlights

  • Ein neu gestalteter Desktop mit dedizierten Arbeitsbereichen, einklappbarer Navigation und anpassbaren Seitenleisten (#1823, #2129)
  • Einrichtung in vier Schritten mit Modellpaketen und optionaler Diktierkonfiguration (#2129)
  • Bessere Synchronisation: zoombare Zeitleisten, gespeicherte Übersetzungsrichtung und Hintergrundton rund um den Dialog erhalten (#2129)
  • Ein einfacherer Modellkatalog und One-click-Installationen für VoxCPM2, MOSS-TTS-Nano und CosyVoice 3 (#2013, #2021, #2022, #2025)
  • Zuverlässigere Generierung auf älteren NVIDIA-GPUs und Live-CPU-, GPU- und Speicherablesungen durch Remote-Mitarbeiter (#2135, #2155)

Umzug von Tauri? Electron separat installieren.

v0.5.3 ist auch das letzte Tauri-Update. Der Tauri-Updater wird Sie nicht auf Electron umstellen; Wählen Sie oben ein VoiceStudio-Electron-Installationsprogramm aus. Ältere Tauri-Assets bleiben für bestehende Installationen verfügbar.

  1. Schließen Sie Tauri und sichern Sie das gesamte Datenverzeichnis sowie alle an anderer Stelle gespeicherten Referenzaudios.
  2. Installieren Sie Electron und überprüfen Sie vor der Generierung die Speicher-/Backend-Konfigurationspunkte für Ihre vorhandenen Daten. Führen Sie niemals beide Apps gleichzeitig für dieses Verzeichnis aus.
  3. Überprüfen Sie Ihre Stimmen, Projekte, Geschichte und Modellstandorte; Erzeugen Sie einen kurzen clip, bevor Sie Tauri entfernen.
  4. Überprüfen Sie Geräte, Verknüpfungen, Design, Backend-Adresse, Berechtigungen und Anmeldeinformationen erneut. Die Übertragung von Desktop-Einstellungen und Anmeldeinformationen kann nicht garantiert werden.

VoiceStudio v0.5.3

Highlights

  • Desktop migration — action required for Tauri users — Electron is now the primary desktop app, and v0.5.3 is the final Tauri update; the Tauri updater will not migrate you. Close Tauri, back up its entire data directory and external reference audio, install VoiceStudio-Electron, and point its storage/backend configuration at the existing data. Never run both apps against that directory simultaneously. Verify voices, projects, history, models, and a test clip before removing Tauri; preferences and credentials may not transfer.

  • Workspace and model-management overhaul — Dedicated workspaces, remembered sidebar widths, four-step setup, and searchable integrations reduce navigation and configuration friction. VoxCPM2, MOSS-TTS-Nano, and CosyVoice 3 now support one-click installation in isolated environments, avoiding disruption to other engines. Note that model/voice previews moved to Settings → Storage, and the Hugging Face mirror moved to Network.

  • More robust dubbing — Timeline zoom, live logs, cancellation/retries, remembered translation direction and custom tone instructions make dubbing easier to control. Fixes preserve background audio outside dialogue, keep short segments proportional, repair missing speech caches, and reject incomplete output—particularly valuable for users producing multilingual videos.

  • GPU, transcription, and security fixes — Older NVIDIA GPUs, including Tesla T4, no longer kill the backend on first generation; torch.compile disabling and crash diagnostics are also more reliable. PyTorch Whisper gains M4A support and better VRAM budgeting for 6 GB cards, while MCP transcription waits now follow the backend timeout instead of failing after 120 seconds. CosyVoice 3 dependency updates address five security advisories; remote workers now report CPU, GPU, and memory without confusing unavailable readings with zero.

  • Upgrade recommendation and installer trust — Upgrade if you want the redesigned desktop workflow, improved dubbing/model installation, or fixes affecting your GPU or transcription setup. Stable Tauri users who need none of these can defer until ready for the manual migration. Electron installers are unsigned or ad-hoc signed and not Apple-notarized, so expect possible Windows/macOS trust warnings; macOS automatic updates are unverified, making manual installer updates the safer path.

A new look. A new desktop app. Still your voices, on your machine.

VoiceStudio moves to Electron with v0.5.3: a redesigned workspace for voice cloning, voice design, stories, dubbing, and transcription. Electron is now the primary desktop app on Windows, macOS, and Linux. Local voice creation still runs on your own hardware, without a required account or API key.

Highlights

  • A redesigned desktop with dedicated workspaces, collapsible navigation, and resizable sidebars (#1823, #2129)
  • Four-step setup with model packs and optional dictation configuration (#2129)
  • Better dubbing: zoomable timelines, saved translation direction, and background sound preserved around dialogue (#2129)
  • A simpler Model Catalogue and one-click installs for VoxCPM2, MOSS-TTS-Nano, and CosyVoice 3 (#2013, #2021, #2022, #2025)
  • More reliable generation on older NVIDIA GPUs and live remote-worker CPU, GPU, and memory readings (#2135, #2155)

Moving from Tauri? Install Electron separately.

v0.5.3 is also the final Tauri update. The Tauri updater will not switch you to Electron; choose a VoiceStudio-Electron installer above. Legacy Tauri assets remain available for existing installations.

  1. Close Tauri and back up its entire data directory, plus any reference audio stored elsewhere.
  2. Install Electron and check its storage/backend configuration points to your existing data before generating. Never run both apps against that directory at once.
  3. Verify your voices, projects, history, and model locations; generate a short clip before removing Tauri.
  4. Recheck devices, shortcuts, theme, backend address, permissions, and credentials. Desktop preferences and credentials are not guaranteed to transfer.
