reagieren v19.3.0

Nachfolgend finden Sie eine Liste aller neuen Funktionen, APIs und Fehlerbehebungen. Weitere Informationen finden Sie im React 19.3-Release-Beitrag.

Neue Reaktionsfunktionen

  • <ViewTransition />: Fügt <ViewTransition /> und addTransitionType APIs hinzu, um Ansichtsübergangsanimationen in React zu ermöglichen (@sebmarkbage, @jackpope, @gaearon: #31975, #31987, #31996, #31999, #32001, #32002, #32028, #32029, #32031, #32034, #32038, #32041, #32050, #32090, #32105, #32254, #32379, #32422, #32462, #32540, #32545, #32585, #32599, #32611, #32612, #32617, #32651, #32653, #32656, #32664, #32699, #32723, #32734, #32751, #32752, #32760, #32761, #32764, #32772, #32790, #32819, #32820, #32822, #32833, #32849, #33094, #33191, #33200, #33206, #33293, #33330, #33331, #33332, #33357, #33362, #33433, #33576, #34374, #34450, #34481, #34500, #34502, #34510, #34511, #34539, #35567, #35564, #35485, #35380, #35063, #35060, #34676, #36917, #35337, #35520)
  • Fragment-Referenzen: Referenzen zu <Fragment /> hinzufügen, um das Verhalten zusammensetzbarer Plattformen zu unterstützen (@jackpope, @sebmarkbage, @eps1lon, @Dhakshin2007, @chirokas, @teamleaderleo, @fallintoplace: #32465, #32613, #32619, #32654, #32660, #32682, #32722, #32813, #32814, #33056, #33058, #33093, #34069, #34103, #34544, #34545, #37062, #37061, #37060, #36047, #36010, #35642, #35641, #35637, #35630, #34935, #37457, #37408, #37326, #37251, #37171, #37169, #37168, #37167, #37166, #37165, #37164, #37163, #37162, #37161, #37160, #37125, #37063)

Neue React DOM-Funktionen

  • browser(): ein neues react-dom API, das einen verwendbaren Fehler beim Rendern des Servers zurückgibt und im Browser auflöst. use(browser()) innerhalb einer <Suspense>-Grenze markiert einen Teilbaum als nur für den Browser, ohne einen behebbaren Fehler zu melden (@gnoff: #37143, #37241) – Den react-dom/server APIs wurde eine onBrowserBailout-Option hinzugefügt, um zu beobachten, wann ein Unterbaum an den Browser verlagert wird (@gnoff #37193)

Bemerkenswerte Änderungen

– Aktivieren Sie die Integration von Trusted Types API (@rickhanlonii #35816)

  • Übergänge werden jetzt unabhängig gerendert, anstatt in einem einzigen Rendering verwickelt zu sein, sodass ein langsamer Übergang keine nicht zusammenhängenden Übergänge mehr aufhält (@acdlite #37290) – Es wurde eine Nur-DEV-Warnung hinzugefügt, wenn eine Komponente scheinbar durch den bedingten Aufruf von use() entsperrt wurde (@hoxyq, @eps1lon: #37104, #37203, #37491)
