oh-my-pi v19.0.1

@oh-my-pi/pi-ai

Behoben

  • Problem behoben, bei dem GIF-Bilder bei der Beurteilung durch Liquid AI mit HTTP 422 fehlschlugen; Sie werden jetzt als PNG gesendet (#19757 von @alphastorm) – Anthropic Strict-Tool-Fallback behandelt jetzt eine Vertex-Organisationsrichtlinien-Ablehnung von structured_outputs (allowedPartnerModelFeatures / „disallowed feature structure_outputs“) als Strict-Tools-Ablehnung, versucht es einmal ohne strict und pinnt strictToolsDisabled (#19576) (#19655 durch @koeria) – Kiro-Anfragen, die mit Input is too long. oder CONTENT_LENGTH_EXCEEDS_THRESHOLD abgelehnt wurden, können jetzt durch Konversationskomprimierung wiederhergestellt werden (#19723 von @emotionbug)
  • Kiro „Denken ausschalten“ schaltet jetzt das Denken aus, anstatt den Standardaufwand des Modells auszuführen; Modelle, die das Denken nicht deaktivieren können, verwenden den geringsten Aufwand (#19722 von @emotionbug) – Kiro /usage zeigt gekaufte Add-on-Credits an und ein Konto, dessen Plan-Credits ausgegeben wurden, bedient weiterhin, solange Add-on-Credits verbleiben (#19724 von @emotionbug) – Kiro Identity Center-Anmeldungen in AWS GovCloud (USA) listen jetzt Profile in us-gov-west-1 und us-gov-east-1 statt in den kommerziellen Regionen auf, die GovCloud-Tokens ablehnen (#19726 von @TechDufus) – Statuslose Gateway-Fehler beim Lesen von stream interrupted werden jetzt wie stream was interrupted wiederholt, anstatt den Zug zu beenden (#19709).

@oh-my-pi/browser-relay

Behoben

– Die Browser-Relay-Erweiterung überlebt einen Browser, dessen geladener Berechtigungssatz älter als die downloads-Berechtigung ist: Der Service-Worker arbeitet ohne Download-Pairing weiter, anstatt abzustürzen, bevor er jemals eine Verbindung herstellt (#19659 von @pavel-kalmykov)

@oh-my-pi/pi-catalog

Hinzugefügt

  • Die Richtermodelle d1.2 und d1.2-ultra von Liquid AI hinzugefügt; liquid ist jetzt standardmäßig d1.2 (#19753 von @alphastorm) – gemini-4-neon zum gebündelten Antigravity CLI-Dienstplan hinzugefügt, mit den low/medium/high/xhigh-Gedankenstufen, die agy dafür anbietet (#19787 von @ataberkus).
  • Model.snapcompactShape ({ variant, frameSize? }) verleiht einem Modell seine eigene Snapcompact-Rahmenform (#19591 von @ryanskidmore)

Behoben

  • Entdeckte Kiro-Modelle, die das Denken nicht ausschalten können, verwenden jetzt ihren niedrigsten unterstützten Aufwand, wenn das Denken ausgeschaltet ist (#19722 von @emotionbug) – Kiro akzeptiert AWS GovCloud (US)-Profil-ARNs (arn:aws-us-gov:codewhisperer:…), die zuvor bei der Profilauflistung übersprungen wurden (#19726 von @TechDufus) – Google Antigravity listet den Sonar-Monitor-Steckplatz des Gemini 4 Hydrogen oder seine abgestuften High/XHigh-SKUs nicht mehr als separate Modelle auf; Die abgestuften SKUs ergeben zusammen das eine Gemini 4 Hydrogen-Modell (#19795 von @eggpeat) – Gemini 4 Neon auf Google Antigravity wird jetzt als ein Modell angezeigt, dessen Denkebene (niedrig, mittel, hoch, xhoch) die passende SKU anstelle von vier separaten Modellen auswählt, und der Preis beträgt 3 $/15 $ pro Million Token ($0.15 zwischengespeichert) statt 0 $ (#19789 von @eggpeat)
  • Gemini 4 Neon lässt sich jetzt auch auf dem Gemini CLI zu einem Modell zusammenfassen, und auf dem Gemini API und Vertex AI bietet das xhigh-Denkniveau und lange Ausgaben bis zu 262.144 Token zum Preis von 3 $/15 $ Gemini API

@oh-my-pi/pi-coding-agent

Hinzugefügt

– /session zeigt den Pfad des local://-Verzeichnisses der Sitzung an, und /copy local kopiert ihn und erstellt das Verzeichnis zuerst, damit es eingegeben werden kann, bevor dort etwas geschrieben wird (#19778 von @farnoy) – snapcompactShape bei den Modellen models.yml, modelOverrides und der Erweiterung registerProvider legt die Snapcompact-Rahmenform dieses Modells fest (#19591 von @ryanskidmore)

Behoben

– Problem behoben, bei dem PTY-Befehlstranskripte manchmal eine Leerzeile enthielten, wenn das Zeilenende \r\n auf zwei Terminal-Lesevorgänge aufgeteilt wurde. – Der unter Windows integrierte dirname der Shell ignorierte \-Trennzeichen und Laufwerkspräfixe (dirname 'C:\a\b' gab . aus), wodurch Skripte wie der code-Launcher von VS Code (./Code.exe: No such file or directory) beschädigt wurden. – Problem behoben, bei dem die Bash-Ausgabe unter Windows minimiert wurde, wenn ein Befehl durch einen \-Pfad oder mit .exe ("C:\Program Files\Git\cmd\git.exe" status, git.exe log) benannt wurde. – Die gebündelten omp://tools-Dokumente, die immer noch das entfernte ida-Tool beschreiben, wurden korrigiert. tools/dsm.md dokumentiert jetzt den dsm-Namespace und die disassembler.*-Einstellungen von eval, und tools/read.md dokumentiert nur Metadaten-Lesevorgänge für ausführbare Dateien (#19608)

  • Problem behoben, bei dem native Terminal-Hosts wie Tern Erweiterungen über Editor-Widgets und eine leere Zeile zwischen der Statuszeile und der Taskleiste platzierten; Die Widgets befinden sich jetzt über der Statuszeile (#19767) – Problem behoben, bei dem ^model-Erwähnungen in Nachrichten in der Warteschlange (->/=> während der Agent beschäftigt ist, spätere Elemente einer nummerierten Liste, RPC steer/follow_up, ACP-Steuerung) das Modell als wörtlichen ^provider/model-Text erreichten, anstatt ihren m<N>-Agenten zu registrieren (#19683 von @a-glapinski) – ^model-Erwähnungen in Erweiterungsnachrichten, die mit sendUserMessage({ deliverAs: "steer" | "followUp" | "aside" }) gesendet wurden, während der Agent damit beschäftigt ist, das Modell zu erreichen, wurden als wörtlicher Text behoben (#19799 von @H4vC) – Problem behoben, bei dem jede Nachricht, die hinter einer nicht zugestellten ^model-Erwähnung in der Warteschlange stand, den Hinweis „m<N> jetzt verfügbar“ für das Modell wiederholte (#19799 von @H4vC) – Ein Plugin-Manifest mit einem Nicht-String-extensions-Eintrag (z. B. einem Objekt) stürzt beim Laden der Erweiterung mit ERR_INVALID_ARG_TYPE nicht mehr ab; Der Eintrag wird als nicht gefunden gemeldet und gültige Einträge werden weiterhin geladen (#19674 von @koeria) – Der eingebettete bash script.sh löste BASH_SOURCE[0] in bash anstelle des Skriptpfads auf, was dazu führte, dass Skripte Dateien neben sich selbst nicht laden konnten (#19792) – Problem behoben, bei dem die Proxy-Modellerkennung die angekündigten Eingabemodalitäten und die Ausgabe-Token-Obergrenze eines Gateways ignorierte (#19754 von @zhyc9de). – Problem behoben, bei dem ein Anbieter, der über ein Authentifizierungs-Gateway weitergeleitet wurde (transport: pi-native in models.yml), weiterhin Modelle vom eigenen Endpunkt des Anbieters auflistete und den Gateway-Schlüssel dorthin sendete; Solche Anbieter überspringen jetzt die Modellerkennung des Anbieters und behalten ihre gebündelten und zwischengespeicherten Modelle (#19646 von @ray8828) – Eine falsche „Cache-Miss“-Markierung in der ersten Runde nach einer Komprimierung wurde behoben: Die Komprimierung schreibt das Eingabeaufforderungspräfix neu, sodass ein Fehlschlag erwartet und nicht mehr gekennzeichnet wird (#19679 von @Petyok) – Problem behoben, bei dem omp --resume <id> unter --mode rpc, --mode rpc-ui und --mode acp beim Start fehlschlug, wenn das Sitzungsverzeichnis nicht mehr existierte; Die Sitzung wird nun dort geöffnet, wo sie gespeichert ist, mit dem Startverzeichnis als Arbeitsverzeichnis, ohne zu fragen, ob sie verschoben werden soll (#19651 von @sjawhar) – Es wurde behoben, dass die Browser-Relay-Erweiterung in einem Browser, dessen geladener Berechtigungssatz älter als die downloads-Berechtigung war, stillschweigend abstürzte: Sie funktioniert jetzt weiterhin ohne Download-Pairing und das Relay meldet eine Download-Tracking-Lücke anstelle einer generischen Nicht-Gefunden-Anzeige (#19659 von @pavel-kalmykov) – Das Teilen einer Sitzung, deren Subagenten einen schnelleren Fortschritt melden als der Uplink-Drain, endet nicht mehr mit „Collab-Senderückstand hat sein Limit überschritten“, während ein Gast beitritt – Problem behoben, bei dem /loop-Iterationen und /goal-Fortsetzungen ca. 800 ms nach einer Runde ausgelöst wurden, um auf Hintergrund-Subagenten oder -Jobs zu warten; Sie warten nun, bis der Lauf beendet ist (#19781) – Problem behoben, bei dem die Codex- und OpenAI-Websuche API die Denkebene der Rolle web (openai-codex/gpt-6-luna:xhigh) ignorierte; Der Level erreicht die Anfrage nun als reasoning.effort (#19793)
  • Bei der Planüberprüfung wurde „Kontext genehmigen und beibehalten“ anhand des Vorplanmodells und nicht anhand der im Schieberegler „Weiter mit“ ausgewählten Ebene gemessen. Der Wechsel zu einer Ebene mit größerem Kontext ermöglicht dies nun (#19660)

@oh-my-pi/pi-natives

Behoben

– Das Einfrieren von OMP für Sekunden bis Minuten auf WSL2 beim Speichern von Sitzungen wurde behoben: Linux FileLock sperrt jetzt eine Sidecar-Datei, anstatt einen Socket zu binden, was dort etwa 10 ms pro Aufruf dauert. Ältere OMP-Versionen, die noch laufen, sehen diese Sperren nicht, also starten Sie sie nach dem Update neu (#19704 von @turgaybulut)

Behoben

– Problem behoben, bei dem Bilder aus einer vorherigen Sitzung nach /new in der Herdr-App wieder oben links auf dem Bildschirm angezeigt wurden (#19749 von @jaredlyon) – Die Schleifenstillstandsdiagnose (ui.loop-blocked) tastet den JS-Thread nicht mehr ab, während keine TUI ausgeführt wird, z. B. in einem externen Editor oder nach Beendigung der Sitzung (#19703 von @will-bogusz) – Das Nutzungs-Dashboard korrigierte die Anzeige erschöpfter oder unter Druck stehender Nutzungszeilen ohne Quotenleiste (Prepaid-Guthaben, verbrauchte Quoten) als schwachen Informationstext; Sie nehmen jetzt die Fehler- oder Warnfarbe an, die ihr gemeldeter Status erfordert, und ein verbrauchtes Kontingent ohne messbaren Betrag lautet „erschöpft“ statt „keine Daten“ (#19764)

oh-my-pi v19.0.1

@oh-my-pi/pi-ai

Fixed

  • Fixed GIF images failing Liquid AI judgments with HTTP 422; they are now sent as PNG (#19757 by @alphastorm)
  • Anthropic strict-tool fallback now treats a Vertex org-policy rejection of structured_outputs (allowedPartnerModelFeatures / "disallowed feature structured_outputs") as a strict-tools rejection, retries once without strict, and pins strictToolsDisabled (#19576) (#19655 by @koeria)
  • Kiro requests rejected with Input is too long. or CONTENT_LENGTH_EXCEEDS_THRESHOLD can now recover through conversation compaction (#19723 by @emotionbug)
  • Kiro thinking off now turns reasoning off instead of running the model's default effort; models that cannot disable reasoning use their lowest effort (#19722 by @emotionbug)
  • Kiro /usage shows purchased add-on credits, and an account whose plan credits are spent keeps serving while add-on credits remain (#19724 by @emotionbug)
  • Kiro Identity Center logins in AWS GovCloud (US) now list profiles in us-gov-west-1 and us-gov-east-1 instead of the commercial regions, which reject GovCloud tokens (#19726 by @TechDufus)
  • Statusless gateway errors reading stream interrupted now retry like stream was interrupted instead of ending the turn (#19709).

@oh-my-pi/browser-relay

Fixed

  • The browser relay extension survives a browser whose loaded permission set predates the downloads permission: the service worker keeps working without download pairing instead of crashing before it ever connects (#19659 by @pavel-kalmykov)

@oh-my-pi/pi-catalog

Added

  • Added Liquid AI's d1.2 and d1.2-ultra judge models; liquid now defaults to d1.2 (#19753 by @alphastorm)
  • Added gemini-4-neon to the bundled Antigravity CLI roster, with the low/medium/high/xhigh thought levels agy offers for it (#19787 by @ataberkus).
  • Model.snapcompactShape ({ variant, frameSize? }) gives a model its own snapcompact frame shape (#19591 by @ryanskidmore)

Fixed

  • Discovered Kiro models that cannot turn reasoning off now use their lowest supported effort when thinking is set to off (#19722 by @emotionbug)
  • Kiro accepts AWS GovCloud (US) profile ARNs (arn:aws-us-gov:codewhisperer:…), which were previously skipped during profile listing (#19726 by @TechDufus)
  • Google Antigravity no longer lists Gemini 4 Hydrogen's sonar monitor slot or its tiered High/XHigh SKUs as separate models; the tiered SKUs fold into the one Gemini 4 Hydrogen model (#19795 by @eggpeat)
  • Gemini 4 Neon on Google Antigravity now shows as one model whose thinking level (low, medium, high, xhigh) selects the matching SKU, instead of four separate models, and is priced at $3/$15 per million tokens ($0.15 cached) instead of $0 (#19789 by @eggpeat)
  • Gemini 4 Neon now collapses into one model on Gemini CLI too, and on the Gemini API and Vertex AI offers the xhigh thinking level and long outputs up to 262,144 tokens, with its $3/$15 Gemini API price

@oh-my-pi/pi-coding-agent

Added

  • /session shows the path of the session's local:// directory, and /copy local copies it, creating the directory first so it can be entered before anything was written there (#19778 by @farnoy)
  • snapcompactShape on models.yml models, modelOverrides and extension registerProvider models sets that model's snapcompact frame shape (#19591 by @ryanskidmore)

Fixed

  • Fixed PTY command transcripts sometimes gaining a blank line where a \r\n line ending was split across two terminal reads.
  • Fixed the shell's dirname builtin on Windows ignoring \ separators and drive prefixes (dirname 'C:\a\b' printed .), which broke scripts like VS Code's code launcher (./Code.exe: No such file or directory)
  • Fixed bash output minimizing being skipped on Windows when a command is named by a \ path or with .exe ("C:\Program Files\Git\cmd\git.exe" status, git.exe log)
  • Fixed the bundled omp://tools docs still describing the removed ida tool; tools/dsm.md now documents eval's dsm namespace and disassembler.* settings, and tools/read.md documents metadata-only executable reads (#19608)
  • Fixed native terminal hosts such as Tern placing extension aboveEditor widgets and a blank row between the status row and the tray; the widgets now sit above the status row (#19767)
  • Fixed ^model mentions in queued messages (->/=> while the agent is busy, later items of a numbered list, RPC steer/follow_up, ACP steering) reaching the model as literal ^provider/model text instead of registering their m<N> agent (#19683 by @a-glapinski)
  • Fixed ^model mentions in extension messages sent with sendUserMessage({ deliverAs: "steer" | "followUp" | "aside" }) while the agent is busy reaching the model as literal text (#19799 by @H4vC)
  • Fixed every message queued behind an undelivered ^model mention repeating the "m<N> now available" notice to the model (#19799 by @H4vC)
  • A plugin manifest with a non-string extensions entry (e.g. an object) no longer crashes extension loading with ERR_INVALID_ARG_TYPE; the entry is reported as not found and valid entries still load (#19674 by @koeria)
  • Fixed embedded bash script.sh resolving BASH_SOURCE[0] to bash instead of the script path, which broke scripts loading files beside themselves (#19792)
  • Fixed proxy model discovery ignoring a gateway's advertised input modalities and output-token cap (#19754 by @zhyc9de).
  • Fixed a provider routed through an auth gateway (transport: pi-native in models.yml) still listing models from the provider's own endpoint, sending the gateway key there; such providers now skip the provider's model discovery and keep their bundled and cached models (#19646 by @ray8828)
  • Fixed a spurious "cache miss" marker on the first turn after a compaction: compaction rewrites the prompt prefix, so that miss is expected and no longer flagged (#19679 by @Petyok)
  • Fixed omp --resume <id> under --mode rpc, --mode rpc-ui and --mode acp failing at start when the session's directory no longer exists; the session now opens where it is stored, with the launch directory as its working directory, without asking whether to move it (#19651 by @sjawhar)
  • Fixed the browser relay extension dying silently in a browser whose loaded permission set predates the downloads permission: it now keeps working without download pairing, and the relay reports a download tracking gap instead of a generic not-found (#19659 by @pavel-kalmykov)
  • Sharing a session whose subagents report progress faster than the uplink drains no longer ends with "collab send backlog exceeded its limit" while a guest joins
  • Fixed /loop iterations and /goal continuations firing ~800ms after a turn yields to wait on background subagents or jobs; they now wait until the run finishes (#19781)
  • Fixed Codex and OpenAI API web search ignoring the web role's thinking level (openai-codex/gpt-6-luna:xhigh); the level now reaches the request as reasoning.effort (#19793)
  • Fixed plan review measuring "Approve and keep context" against the pre-plan model instead of the tier chosen in the "continue with" slider, so switching to a larger-context tier now enables it (#19660)

@oh-my-pi/pi-natives

Fixed

  • Fixed omp freezing for seconds to minutes on WSL2 while saving sessions: Linux FileLock now locks a sidecar file instead of binding a socket, which takes about 10 ms per call there. Older omp versions still running do not see these locks, so restart them after updating (#19704 by @turgaybulut)

@oh-my-pi/snapcompact

Added

  • resolveShape() uses a model's configured snapcompactShape in place of its model-line default; an explicit variant still wins and billing still follows the model (#19591 by @ryanskidmore)

@oh-my-pi/omp-stats

Added

  • Added 2d and 3d range presets with hourly buckets to the stats dashboard time selector (#19766, #19774 by @thekitaev).

@oh-my-pi/pi-tui

Added

  • The native session sheet shows a Local report line (the session's local:// directory) as a copyable field beside the ID and file (#19778 by @farnoy)

Fixed

  • Fixed images from a previous session reappearing at the top-left of the screen after /new in herdr-app (#19749 by @jaredlyon)
  • Loop-stall diagnostics (ui.loop-blocked) no longer sample the JS thread while no TUI runs, such as in an external editor or after the session ends (#19703 by @will-bogusz)
  • Fixed the usage dashboard rendering exhausted or pressured usage rows without a quota bar (prepaid balances, spent quotas) as dim informational text; they now take the error or warning color their reported status calls for, and a spent quota with no measurable amount reads "exhausted" instead of "no data" (#19764)
