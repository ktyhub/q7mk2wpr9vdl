oh-my-pi v18.22.2

@oh-my-pi/pi-ai

Hinzugefügt

– Nativer Kiro-Anbieter hinzugefügt: Melden Sie sich mit AWS IAM Identity Center, AWS Builder ID, Google, GitHub oder einem Kiro API-Schlüssel (KIRO_API_KEY) an, streamen Sie Antworten mit Begründung, Toolaufrufen und Bildern und melden Sie Kiro-Credits in /usage (#18955 von @Xytronix, basierend auf #14215 von @ajdiyassin)

  • Eine definitive-Option zu OAuthError hinzugefügt; isDefinitiveOAuthFailure nimmt nun das Fehlerobjekt und deaktiviert einen als definitiv gekennzeichneten Berechtigungsnachweis, ohne mit seiner Nachricht übereinzustimmen (#18955 von @Xytronix) – buildAnthropicSearchHeaders übernimmt extraBetas, anforderungsspezifische Betas, die neben der Websuche-Beta gesendet werden (#18125 von @will-bogusz) – omitDemotedReasoning zu StreamOptions hinzugefügt: Eine Anthropic-Anfrage lässt die Argumentation anderer Modelle außer Acht, dass sie andernfalls als Text abgespielt würde, und eine abgelehnte Anfrage meldet, wie viele solcher Blöcke sie in demotedReasoningBlocks trug (#10407) (#17610 von @will-bogusz)

Behoben

– Problem behoben, durch das das Herunterfahren oder Abbrechen einer OMP-Sitzung dazu führte, dass bei jeder anderen Sitzung, die das Agentenverzeichnis nutzte, die OAuth-Konten für 5 Minuten als erschöpft angezeigt wurden; Noch gültige Token werden auch während des Herunterfahrens bereitgestellt (#19607) – Über einen Authentifizierungsbroker aktualisierte OAuth-Konten behalten ihre gespeicherten Routing-Metadaten (z. B. einen API-Endpunkt) im für die Anforderung erstellten Schlüssel, anstatt sie nach der ersten Aktualisierung zu verlieren (#18955 von @Xytronix, basierend auf #14215 von @ajdiyassin)

  • Abgegrenztes („denkendes“) Denken mit sehr langen, ununterbrochenen Zeilen wird beim Streamen nicht mehr langsamer (#19493 von @H4vC) – Behoben: Anthropic-Anfragen, die einen signierten Server-Komprimierungsblock wiedergeben und immer noch nach einem Nachrichtenthread fragen, der von API abgelehnt wird (thread_unsupported_request), sodass jede solche Anfrage zunächst einen abgelehnten Roundtrip bezahlt, bevor sie ohne den Thread erneut gesendet wird (#19473 von @alphastorm) – Anthropische Anfragen, deren Verbindung vor einer Antwort unterbrochen wird, geben jetzt an, wie lange nach dem Start der Anfrage die Verbindung unterbrochen wurde und ob der Anfragetext noch hochgeladen wurde oder bereits vollständig in den Socket geschrieben wurde, einschließlich der Größe, statt eines bloßen „Verbindungsfehlers“. (#18624 von @will-bogusz) – Behoben: Anthropic-Anfragen ließen die Argumentation früherer Nicht-Claude-Turniere weg, die unter einem anderen Berechtigungsnachweis angemeldet waren oder durch eine Verdichtung beibehalten wurden; es wird jetzt wie die Argumentation anderer Modelle wiedergegeben (#7241) (#17610 von @will-bogusz)

@oh-my-pi/pi-catalog

Hinzugefügt

  • Kiro zum Modellkatalog mit automatischer Erkennung aller Modelle hinzugefügt, die für das angemeldete Kiro-Konto verfügbar sind (#18955 von @Xytronix, basierend auf #14215 von @ajdiyassin) – Claude Fable 5.2, Gemini 4 Carbon von Factory Droid (mit Startguthaben-Aktion, halbe Eingaberate bis 01.12.2026) und Kimi K3.1 Pro hinzugefügt, jeweils aufgeführt, sobald das Feature-Flag des Kontos dies aktiviert, sowie GPT-Image 2.6 und GPT-Image 2.6 Flare vor GPT-Image 2.5 in der Factory der image-Rolle Standardeinstellungen (#19191 von @will-bogusz) – writeModelCacheAsync() und forEachInSlices() hinzugefügt: Modellaktualisierungen erstellen und speichern jetzt erkannte Modelle in Slices, die der Ereignisschleife unterliegen; writeModelCache() gibt sein Ergebnis zurück und schreibt einen Anbieter, dessen Zeilen unverändert bleiben, nicht mehr neu

Geändert

– readModelCache() analysiert eine Nutzlast einmal pro Prozess: Cache-Dateien mit identischen Zeilen geben dieselben gemeinsam genutzten Zeilenobjekte zurück

@oh-my-pi/pi-coding-agent

Hinzugefügt

  • Der Computer el.setValue(75) schreibt die Nummer jetzt als "75", anstatt einen Nicht-String abzulehnen; NaN, Infinity, boolesche Werte und Objekte werden weiterhin abgelehnt, ebenso wie eine ganze Zahl nach 2^53 und eine Zahl, die mit einem Exponenten gedruckt wird, die stattdessen als Text in Ziffern übergeben werden (#19405 von @will-bogusz) – Ein Bericht über native Fenster zu den Browserergebnissen auf macOS für sichtbare verwaltete Browser, erzeugte Chromium-Browser und ein Loopback-Relay hinzugefügt: ein <select>-Menü, eine Farb- oder Datumsauswahl oder ein Druck-, Speicher-, Anmelde-, Passkey- oder Berechtigungsblatt oder eine Blase. Ein über seine Registerkarte ausgelöster Anruf wird mit seiner computer.window()-ID benannt, während die Registerkartenliste des Browsers diese Registerkarte vor seinem Fenster anzeigt, beim nächsten Aufruf, wenn sie unmittelbar nach der Rückkehr des Anrufs angezeigt wird, und auch bei fehlgeschlagenen Anrufen; Angeschlossene CDP-Endpunkte, Remote-Relays und seitengestützte Popup-Fenster sind ausgeschlossen (#18925 von @will-bogusz) – Kiro als integrierten Anbieter hinzugefügt: Führen Sie /login kiro aus, wählen Sie Identity Center, Builder-ID oder einen API-Schlüssel und wählen Sie ein erkanntes kiro/<model-id>-Modell. Jeder /login kiro fügt ein Konto hinzu (#18955 von @Xytronix, basierend auf #14215 von @ajdiyassin)
  • Google und GitHub zu /login kiro hinzugefügt: Genehmigen Sie einen Einmalcode bei app.kiro.dev und melden Sie sich dann mit diesem Konto an (#18955 von @Xytronix, basierend auf #14215 von @ajdiyassin) – /usage und omp usage zeigen jetzt Kiro-Guthaben an: das monatliche Planguthaben mit ihrem Rücksetzdatum, aktive Bonusguthaben mit ihrem Ablauf sowie Überschreitungsgutschriften und -gebühren, wenn die Überschreitung aktiviert ist (#18955 von @Xytronix, basierend auf #14215 von @ajdiyassin)

Geändert

– Modellregistrierungen in einem Prozess (SDK-Embedder, Tests) teilen jetzt Builds erkannter Modelle, so dass beim Aktualisieren einer anderen Registrierung die Neuerstellung von Modellen eines früheren, bereits erstellten Modells übersprungen wird

Behoben

– Das Problem, dass die Benutzeroberfläche kurzzeitig einfriert, wenn eine Eingabeaufforderung gesendet wird, wurde behoben: Der Eingabeaufforderungsverlauf wird jetzt im Hintergrund (innerhalb von 100 ms und beim Beenden) auf die Festplatte geschrieben, anstatt beim Drücken der Eingabetaste – Das Einfrieren der Benutzeroberfläche beim Zusammenführen erkannter Modelle aus großen Anbieterkatalogen wurde behoben: Die Zusammenführung wird jetzt in Slices ausgeführt, die der Ereignisschleife weichen – Problem behoben, bei dem das Schließen des Headless-Browsers von OMP etwa 7 Sekunden dauerte, wenn Chromium nie ordnungsgemäß heruntergefahren wurde (beobachtet bei Chrome zum Testen 150 unter macOS 27): Ein Browser in einem von OMP erstellten Profil wird jetzt sofort beendet – Bei fehlgeschlagenen Computerläufen bleiben Text und Screenshots erhalten, die bereits in JavaScript und Python Eval erstellt wurden, sodass Agenten Teilaktionen überprüfen können, ohne den Fehler zu verlieren; Direkte Computeraufrufe zeigen neben der Teilausgabe auch den Namen und die Meldung des Fehlers an (#19100 von @will-bogusz) – Problem behoben, bei dem Exa- und Firecrawl-Websuchen stillschweigend auf ihre schlüssellosen öffentlichen Endpunkte zurückfielen, wenn eine konfigurierte Anmeldeinformation nicht aufgelöst werden konnte (z. B. ein fehlerhafter !command); Sie melden jetzt den Anmeldeinformationsfehler – Problem behoben, bei dem Auswertungszellen yield (direkt oder über xd://yield) aufrufen konnten, ohne die delegierte Aufgabe abzuschließen; eval lehnt nun yield ab und verweist auf das direkte Tool (#19470 von @alphastorm) – Behoben, dass Dienst ready.log und Wartemuster an Zeilengrenzen nach früherer Ausgabe nicht mit ^ und $ übereinstimmten (#19471 von @alphastorm)

  • Die Shell-Integrationen stat, diff und find haben das Ignorieren von TZ beim Drucken von Dateizeiten behoben. find -ls gibt jetzt Zeiten in der Zeitzone der Shell statt in UTC aus, und find -newermt liest Datumsangaben wie Nov 15, 2023 in der Zeitzone der Shell (#19482 von @alphastorm) – Bei aktiven TTSR-Regeln werden große write- und edit-Aufrufe beim Streamen ihrer Argumente nicht mehr langsamer (#19494 von @H4vC) – Problem behoben, bei dem /commit und eval commit während einer Zusammenführung einen Single-Parent-Commit erstellten; Das Festschreiben wird jetzt abgelehnt, während eine Zusammenführung, ein Cherry-Pick, ein Zurücksetzen, ein Rebase oder ein git am ausgeführt wird oder der Index ungelöste Konflikte aufweist (#19474 von @alphastorm) – Die Beschreibung des apply_patch-Tools wurde korrigiert, indem es einen Shell-Befehl nannte und absolute Pfade verbot (#19325, #19468 von @alphastorm) – Das in der Shell eingebaute rg hat das Ignorieren von --glob-Mustern, die einen Schrägstrich enthalten, behoben (#19476 von @alphastorm) – Es wurde behoben, dass die Auswertung commit only(...) fehlschlug, wenn einer ihrer Pfade oder Globs mit keiner geänderten Datei übereinstimmte. nicht übereinstimmende werden jetzt gemeldet (#19472 von @alphastorm) – Es wurde ein Tern-Browserblock behoben, der jeden späteren Browseraufruf mit „Tab ist beschäftigt: Ein anderer Aufruf auf diesem Tab läuft noch“ nach einem Aufruf beantwortet, dessen Seitenauswertung nie zurückgegeben wurde, z. B. wenn er durch eine Umleitung unterbrochen wurde; Ein solcher Anruf endet nun nach Ablauf seiner Frist oder bei Abbruch und der Tab nimmt den nächsten Anruf an – Problem behoben, bei dem das Browser-Tool ein JavaScript confirm oder prompt als noch geöffnet meldete und Seitenaufrufe darauf fehlschlug, nachdem der Benutzer cli es weggesperrt oder ein anderer CDP client darauf geantwortet hatte (#19481 von @will-bogusz) – Problem behoben, bei dem computer setValue auf einem <select> in Chrome oder einer Electron-App auf macOS mit einer leeren Optionsliste fehlschlug; es wählt nun die Option die Wertnamen (#19224 von @will-bogusz) – Ein Relay-Tab wird nicht mehr geschlossen, wenn der Frame einer anderen Erweiterung, z. B. das Autofill-Menü eines Passwort-Managers, das das Löschen des Relays rückgängig macht, dazu führt, dass Chrome omp ablehnt: Der Aufruf sagt nicht, was den Tab enthält, der Tab bleibt geöffnet, als der Benutzer ihn verlassen hat, und der nächste Aufruf wird wieder daran angehängt (#19178 von @will-bogusz) – Problem behoben, bei dem das Computertool dem Modell mitteilte, dass nur eine X11-Übernahme enden kann, ohne dass nichts gesendet wird, weil der Benutzer weiter tippt; Eine macOS-Übernahme wartet nun auch auf die Pause des Benutzers und meldet UserIntervened auf die gleiche Weise (#19296 von @will-bogusz) – Wenn das Browser-Relay den Frame einer anderen Erweiterung in einem Tab-OMP-Laufwerk (dem Inline-Menü oder einer Speicherkarte eines Passwort-Managers) verbirgt, benennt der Aufruf, der darauf lief, oder ein späterer auf diesem Tab, jetzt die Seite des Frames, die ID der Erweiterung und den eigenen Titel der Seite und sagt, dass der Frame auch für den Benutzer ausgeblendet ist (#19001 von @will-bogusz) – Die Anthropic-Websuche übergibt jetzt Abfragen im site:-Bereich an Claude, wobei die Domäne und der Pfad noch im Text enthalten sind, und weist Claude an, immer zu suchen, sodass Suchvorgänge und Abfragen, von denen angenommen wurde, dass sie aus dem Speicher beantwortet werden könnten, nicht mehr mit „keine Quellen zurückgegeben“ fehlschlagen (#18125 von @will-bogusz)

(#18125 von @will-bogusz)
  • Subagenten ohne Ausgabeschema (einschließlich eval agent()-Aufrufe ohne schema) erhalten kein yield-Tool mehr; Ihre letzte Botschaft ist das Ergebnis.
  • Ein yield ohne data verwendet nicht mehr die letzte Nachricht des Subagenten als Ergebnis; Es schließt nur inkrementelle Abschnitte ab, die bereits übermittelt wurden. – Ein computer-Tastendruck, der das Menü einer macOS-Popup-Schaltfläche oder einer Menüschaltfläche im Hintergrund öffnet, schlägt jetzt fehl, die Elemente aufzulisten und den Tastendruck zu benennen, oder click, der eines auswählt, anstatt das Menü mit der Tastatur geöffnet zu lassen (#19179 von @will-bogusz) – Problem behoben, bei dem Claude nach einem Modellwechsel die Begründung früherer Codex-, Kimi-, Grok- und anderer Nicht-Claude-Runden nicht sah, einschließlich Runden, die durch eine Verdichtung beibehalten wurden; Jetzt erhält es diese Begründung als Text. Wenn Claude eine Runde mit Refusal (reasoning_extraction) aufgrund dieser Argumentation ablehnt, wird die Runde einmal ohne sie wiederholt und die Sitzung stoppt das Senden an Claude (#7241) (#17610 von @will-bogusz) – Nach einer Anthropic-Ablehnung senden spätere Runden den Ablehnungstext nicht mehr erneut, während die Tool-Aufrufe gestoppt wurden: Diese Aufrufe werden jetzt nur noch als „nicht ausgeführt“ wiedergegeben, sodass eine reasoning_extraction-Ablehnung aufhört, wodurch wahrscheinlich auch jede folgende Runde der Sitzung abgelehnt wird (#19419 von @flosrn)

Vorhandene initialisierte Gitlinks können jetzt überprüft und explizit ausgewählt werden, ohne dass Änderungen innerhalb des Submoduls vorgenommen werden müssen (#19556 von @kim-dali) – Problem mit Git-Lesevorgängen behoben, z. B. dass der Statusscan von /commit hängen blieb, wenn ein Hintergrund-Git-Prozess die Ausgabepipe offen hielt (#19478 von @alphastorm) – Das Problem, dass der Browser beim ersten Start eines neuen WebKit-Engine-Builds auf macOS auf Chromium zurückfiel, wurde behoben: Der WebKit-Host hat jetzt 60 statt 10 Sekunden Zeit, um auf seine Begrüßung zu antworten, während macOS die Binärdateien und Bibliotheken der Engine scannt (#19423 von @shgew) – Problem behoben, bei dem --continue eine neue leere Sitzung öffnete, wenn die letzte Sitzung des Terminals in einem anderen Verzeichnis gestartet und vor der ersten Nachricht geschlossen wurde; es setzt nun die neueste Sitzung des aktuellen Verzeichnisses fort (#19495). – Es wurde behoben, dass die Standardausgabe eines ablehnenden pre-commit-Hooks (z. oh-my-pi v18.22.2

@oh-my-pi/pi-ai

Added

  • Added the native Kiro provider: sign in with AWS IAM Identity Center, AWS Builder ID, Google, GitHub, or a Kiro API key (KIRO_API_KEY), stream responses with reasoning, tool calls, and images, and report Kiro credits in /usage (#18955 by @Xytronix, based on #14215 by @ajdiyassin)
  • Added a definitive option to OAuthError; isDefinitiveOAuthFailure now takes the error object and disables a credential marked definitive without matching its message (#18955 by @Xytronix)
  • buildAnthropicSearchHeaders takes extraBetas, request-specific betas sent beside the web search beta (#18125 by @will-bogusz)
  • Added omitDemotedReasoning to StreamOptions: an Anthropic request leaves out other models' reasoning that it would otherwise replay as text, and a refused request reports how many such blocks it carried in demotedReasoningBlocks (#10407) (#17610 by @will-bogusz)

Fixed

  • Fixed shutting down or cancelling an omp session making every other session sharing the agent directory see its OAuth accounts as depleted for 5 minutes; still-valid tokens are also served during shutdown (#19607)
  • OAuth accounts refreshed through an auth broker keep their stored routing metadata (such as an API endpoint) in the key built for the request, instead of losing it after the first refresh (#18955 by @Xytronix, based on #14215 by @ajdiyassin)
  • Fenced (```thinking) reasoning with very long unbroken lines no longer slows down as it streams (#19493 by @H4vC)
  • Fixed Anthropic requests that replay a signed server-compaction block still asking for a message thread, which the API refuses (thread_unsupported_request), so every such request first paid a rejected round trip before resending without the thread (#19473 by @alphastorm)
  • Anthropic requests whose connection drops before any response now say how long after the request started it dropped and whether the request body was still uploading or had all been written to the socket, with its size, instead of a bare "Connection error." (#18624 by @will-bogusz)
  • Fixed Anthropic requests dropping the reasoning of earlier non-Claude turns signed in under another credential, or kept through a compaction; it is now replayed like other models' reasoning (#7241) (#17610 by @will-bogusz)

@oh-my-pi/pi-catalog

Added

  • Added Kiro to the model catalog with automatic discovery of every model available to the signed-in Kiro account (#18955 by @Xytronix, based on #14215 by @ajdiyassin)
  • Added Factory Droid's Claude Fable 5.2, Gemini 4 Carbon (with its launch credit promotion, half the input rate until 2026-12-01) and Kimi K3.1 Pro, each listed once the account's feature flag enables it, and GPT Image 2.6 and GPT Image 2.6 Flare ahead of GPT Image 2.5 in the image role's Factory defaults (#19191 by @will-bogusz)
  • Added writeModelCacheAsync() and forEachInSlices(): model refreshes now build and cache discovered models in slices that yield to the event loop; writeModelCache() returns its outcome and no longer rewrites a provider whose rows are unchanged

Changed

  • readModelCache() parses a payload once per process: cache files holding identical rows return the same shared row objects

@oh-my-pi/pi-coding-agent

Added

  • Computer el.setValue(75) now writes the number as "75" instead of refusing a non-string; NaN, Infinity, booleans and objects are still refused, as are a whole number past 2^53 and a number that prints with an exponent, which are passed as text in digits instead (#19405 by @will-bogusz)
  • Added a report of native windows to browser results on macOS for visible managed browsers, spawned Chromium browsers and a loopback relay: a <select> menu, colour or date picker, or a print, save, sign-in, passkey or permission sheet or bubble a call raised over its tab is named with its computer.window() id while the browser's tab list shows that tab in front of its window, by the next call when it shows just after the call returned, and on failed calls too; connected CDP endpoints, remote relays and page-backed popup windows are excluded (#18925 by @will-bogusz)
  • Added Kiro as a built-in provider: run /login kiro, pick Identity Center, Builder ID, or an API key, and choose a discovered kiro/<model-id> model. Each /login kiro adds an account (#18955 by @Xytronix, based on #14215 by @ajdiyassin)
  • Added Google and GitHub to /login kiro: approve a one-time code at app.kiro.dev, then sign in with that account (#18955 by @Xytronix, based on #14215 by @ajdiyassin)
  • /usage and omp usage now show Kiro credits: the monthly plan credits with their reset date, active bonus credits with their expiry, and overage credits and charges when overage is enabled (#18955 by @Xytronix, based on #14215 by @ajdiyassin)

Changed

  • Model registries in one process (SDK embedders, tests) now share discovered-model builds, so refreshing another registry skips rebuilding models an earlier one already built

Fixed

  • Fixed the UI freezing briefly when a prompt is submitted: prompt history is now written to disk in the background (within 100 ms, and on exit) instead of on the Enter keystroke
  • Fixed the UI freezing while discovered models from large provider catalogs are merged: the merge now runs in slices that yield to the event loop
  • Fixed closing omp's headless browser taking about 7 s when Chromium never finishes a graceful shutdown (seen with Chrome for Testing 150 on macOS 27): a browser on an omp-created profile is now killed at once
  • Failed computer runs retain text and screenshots already produced in JavaScript and Python Eval, so agents can inspect partial actions without losing the error; direct computer calls also show the failure's name and message alongside partial output (#19100 by @will-bogusz)
  • Fixed Exa and Firecrawl web searches silently falling back to their keyless public endpoints when a configured credential failed to resolve (for example a failing !command); they now report the credential error
  • Fixed eval cells being able to call yield (directly or through xd://yield) without finishing the delegated task; eval now rejects yield and points to the direct tool (#19470 by @alphastorm)
  • Fixed service ready.log and wait patterns not matching ^ and $ at line boundaries after earlier output (#19471 by @alphastorm)
  • Fixed the shell's stat, diff and find builtins ignoring TZ when printing file times; find -ls now prints times in the shell's time zone instead of UTC, and find -newermt reads dates like Nov 15, 2023 in the shell's time zone (#19482 by @alphastorm)
  • With TTSR rules active, large write and edit calls no longer slow down as their arguments stream (#19494 by @H4vC)
  • Fixed /commit and eval commit creating a single-parent commit during a merge; committing now refuses while a merge, cherry-pick, revert, rebase or git am is in progress or the index has unresolved conflicts (#19474 by @alphastorm)
  • Fixed the apply_patch tool description calling it a shell command and forbidding absolute paths (#19325, #19468 by @alphastorm)
  • Fixed the shell's rg builtin ignoring --glob patterns that contain a slash (#19476 by @alphastorm)
  • Fixed eval commit only(...) failing when one of its paths or globs matched no changed file; unmatched ones are now reported (#19472 by @alphastorm)
  • Fixed a Tern browser block answering every later browser call with "Tab is busy: another call on this tab is still running" after a call whose page evaluation never returned, such as one cut off by a redirect; such a call now ends at its time limit or when cancelled, and the tab takes the next call
  • Fixed the browser tool reporting a JavaScript confirm or prompt as still open, and failing page calls on it, after the user clicked it away or another CDP client answered it (#19481 by @will-bogusz)
  • Fixed computer setValue on a <select> in Chrome or an Electron app on macOS failing with an empty list of options; it now chooses the option the value names (#19224 by @will-bogusz)
  • A relay tab is no longer closed when another extension's frame, such as a password manager's autofill menu that undoes the relay clearing it, keeps Chrome refusing omp: the call fails saying what holds the tab, the tab stays open as the user left it, and the next call reattaches to it (#19178 by @will-bogusz)
  • Fixed the computer tool telling the model that only an X11 takeover can end with nothing sent because the user kept typing; a macOS takeover now waits for the user's pause too and reports UserIntervened the same way (#19296 by @will-bogusz)
  • When the browser relay hides another extension's frame in a tab omp drives (a password manager's inline menu or save card), the call that ran into it, or a later one on that tab, now names the frame's page, the extension's id and the page's own title, and says the frame is hidden for the user too (#19001 by @will-bogusz)
  • Anthropic web search now passes site:-scoped queries to Claude with the domain and path still in the text, and tells Claude to always search, so those lookups and queries it thought it could answer from memory no longer fail with "returned no sources" (#18125 by @will-bogusz)
  • Anthropic web search on models with a refusal fallback (Opus 5 and 5.5, Sonnet 5.5, Fable 5) has Anthropic retry a query the safety classifier declines on another Claude model, and reports a refusal or a failed search (too_many_requests, …) by name instead of "returned no sources" (#18125 by @will-bogusz)
  • Subagents without an output schema (including eval agent() calls without schema) no longer get a yield tool; their final message is the result.
  • A yield without data no longer uses the subagent's last message as the result; it only finalizes incremental sections that were already submitted.
  • A computer key press that opens a macOS popup button's or menu button's menu in the background now fails listing the items and naming the press or click that chooses one, instead of leaving the menu open with your keyboard (#19179 by @will-bogusz)
  • Fixed Claude not seeing the reasoning of earlier Codex, Kimi, Grok and other non-Claude turns after a model switch, including turns kept through a compaction; it now gets that reasoning as text. When Claude refuses a turn with Refusal (reasoning_extraction) because of that carried reasoning, the turn is retried once without it, and the session stops sending it to Claude (#7241) (#17610 by @will-bogusz)
  • After an Anthropic refusal, later turns no longer resend the refusal text with the tool calls it stopped: those calls now replay as "not executed" only, so one reasoning_extraction refusal stops making every following turn of the session likely to be refused too (#19419 by @flosrn)
  • Fixed selective commits skipping updated submodule pointers; existing initialized gitlinks can now be reviewed and explicitly selected without committing changes inside the submodule (#19556 by @kim-dali)
  • Fixed git reads such as /commit's status scan hanging when a background git process kept the output pipe open (#19478 by @alphastorm)
  • Fixed the browser falling back to Chromium on the first launch of a new WebKit engine build on macOS: the WebKit host now gets 60 seconds instead of 10 to answer its greeting while macOS scans the engine's binaries and libraries (#19423 by @shgew)
  • Fixed --continue opening a new empty session when the terminal's last session was started in another directory and closed before its first message; it now resumes the current directory's newest session (#19495).
  • Fixed a rejecting pre-commit hook's stdout (e.g. the pre-commit framework's per-hook report) missing from the error raised by the eval commit namespace and omp commit (#19449)
  • /commit now shows the subject a commit-msg hook wrote onto the commit, instead of the subject from before the hook ran (#19448 by @eggpeat)
  • ^model references followed by sentence punctuation now register their model agent instead of remaining literal (#19445 by @yuzu-octopus)
  • Selective commits in sparse checkouts no longer report paths outside the cone as unstaged deletions to commit hooks (#19453 by @yuzu-octopus)
  • Custom providers pointing at the Zhipu Coding Plan endpoint now retry at the Beijing-time quota reset instead of waiting eight hours too long (#19446 by @yuzu-octopus)
  • /copy now copies what a mid-turn out:// reply showed, instead of the reply tool's own "Shown to the user." result, and lists the reply's code blocks in the turn's blocks (#19551 by @bannert1337)
  • Fixed tools enabled during goal mode becoming unavailable after leaving it (#19514 by @yuzu-octopus)
  • Fixed the status-line usage segment showing another account's quota for multi-credential API-key providers such as opencode-go; it now follows the credential row the session router actually serves from (#19456) (#19492 by @thekitaev).
  • Fixed Objective-C message results and arm64 retain-register data flow in Ghidra analysis of Mach-O binaries, including previously analyzed cache-extracted frameworks (#19558 by @shgew).
  • With a modal dialog open, browser fill, type and press aimed at a field behind it now fail naming what covers it, as click does, instead of typing into the dialog's button and reporting success (on Chromium tabs and Tern tabs without native DOM reads); press also refuses a disabled element (on Chromium tabs and Tern tabs without native DOM reads), and Chromium drag refuses a covered start or end (#19524 by @will-bogusz)
  • Fixed RPC login refusing providers with an at-your-own-risk warning (antigravity-cli, google-antigravity): the warning now reaches the host as an extension_ui_request input, and login continues on "yes" and cancels on anything else (#19523)
  • On Linux, file watching for language servers no longer puts an inotify watch on every directory under node_modules and .git/objects, which could use up the system's inotify watch limit and keep other programs such as systemd from adding watches (#19459)
  • /restart now re-execs through the launcher omp was started by, so an open session moves onto an upgraded binary instead of re-running a retained old install (#19529 by @yuzu-octopus)
  • RPC hosts now always receive a terminal agent_end after an over-quota 429: usage-limit bookkeeping is bounded so a stalled usage report can no longer hold the event (#19411, #19417 by @yuzu-octopus)
  • Rex and other OSC 7501 terminals no longer play a success sound mid-run when a stale agent end arrives after another run has opened (#17307, #19418 by @yuzu-octopus)

@oh-my-pi/pi-natives

Added

  • TtyWriter now works on Windows consoles: it writes off the JS thread in 16 KiB WriteFile chunks, restores the UTF-8 console code pages that child processes change, and stop() cancels a blocked write
  • Added isolateThreadStartsFromConsole(), which keeps a Windows console whose terminal stopped reading from blocking new threads in the process

@oh-my-pi/pi-tui

Added

  • ui.loop-blocked log records now name what held the event loop (cause, causeShare, top), sampled by an always-on profiler; PI_LOOP_SAMPLER=0 turns it off

Changed

  • On Windows, terminal output is written off the JS thread, so input and rendering stay responsive while the console drains a large repaint

Fixed

  • On Windows, omp no longer freezes when the terminal stops reading its output (a hung Windows Terminal, a paused ssh client); it keeps running and catches up once the terminal reads again

@oh-my-pi/pi-utils

Added

  • Added readBoundedBody and readBoundedJson for reading HTTP response bodies with a size limit, with an optional signal so a stalled peer cannot outlive the caller's deadline (#18955 by @Xytronix)
