oh-my-pi v18.22.1

@oh-my-pi/pi-agent-core

Hinzugefügt

– Ein Modell auf dem benutzerdefinierten api einer Erweiterung kann die Anthropic On-Demand-Komprimierungsspur übernehmen, indem es remoteCompaction: { api: "anthropic-messages", enabled: true } deklariert; Die Anfrage durchläuft wie jede Runde ihren eigenen Stream (#19580 von @ryanskidmore)

Behoben

  • Die Behandlung von Anbieterfehlern wurde korrigiert, sodass fehlgeschlagene Toolaufrufe nicht mehr als Ablehnungserklärungen an das Modell zurückgemeldet werden. – Einmalige Wiederholungsversuche und Titelgenerierung für benutzerdefinierte Zhipu-Coding-Plan-Anbieter wurden korrigiert, sodass Kontingentzurücksetzungen nach Peking-Zeit berücksichtigt werden. – Die OpenAI-Remotekomprimierung (V1 und V2) hat dazu geführt, dass konfigurierte Header von models.yml und erweiterungsregistrierten Modellen gelöscht wurden, sodass Header-authentifizierte Gateways 401 zurückgegeben haben (#19579 von @ryanskidmore)

@oh-my-pi/pi-ai

Hinzugefügt

– Unterstützung für anforderungsspezifische Anthropic-Beta-Header durch die Option extraBetas in buildAnthropicSearchHeaders hinzugefügt. – omitDemotedReasoning zu StreamOptions hinzugefügt, wodurch Anthropic-Anfragen die Argumentation anderer Modelle weglassen können, die andernfalls als Text wiedergegeben würden; Bei abgelehnten Anfragen wird die Anzahl der ausgelassenen Blöcke in demotedReasoningBlocks gemeldet. – Nutzungsberichte können jetzt die Anmeldeinformations-ID enthalten, die von API-Schlüssel- oder OAuth-Anmeldeinformationen verwendet wird, und AuthStorage.sessions.sticky bietet eine schreibgeschützte Suche nach den Anmeldeinformationen, die eine Sitzung bedienen. – riskAcknowledgement zu OAuthPrompt hinzugefügt, wodurch Hosts den Anmeldewarnungs-Akzeptanztext auch dann anzeigen können, wenn sie eine Eingabe ablehnen, bevor die Autorisierungs-URL angezeigt wird. – remoteCompaction: { api: "anthropic-messages", enabled: true } wählt ein Anthropic-Modell an einem Gateway baseUrl außerhalb der bekannten Bereitstellungen für die On-Demand-Verdichtung; Allein durch enabled bleibt ein solches Gateway ausgeschlossen, und eine Umleitung vom konfigurierten Endpunkt muss immer noch eine bekannte Bereitstellung erreichen. isBuiltinApi() informiert einen integrierten Anforderungsadapter über den benutzerdefinierten api einer Erweiterung (#19580 von @ryanskidmore)

Geändert

– OpenAI-Codex-Anfragen verfolgen jetzt automatisch die neueste kompatible @openai/codex client-Version mit einer optionalen PI_AI_CODEX_CLIENT_VERSION-Überschreibung, sodass neu verfügbare Codex-Modelle ohne Aktualisierung von omp verwendet werden können. – Aktualisierte OpenAI-Codex-Anfrageformatierung und ChatGPT-Token-Aktualisierungsberichte, um mit Codex CLI 0.169 übereinzustimmen. – Die Versionskennungen von Claude Code und Gemini CLI client wurden auf 2.1.326 bzw. 0.68.0 aktualisiert.

Behoben

– Die OpenAI Decisions-Nutzungsabrechnung für Gateways, die prompt_tokens und completion_tokens anstelle von input_tokens und output_tokens melden, wurde korrigiert. – Verbesserte Streaming-Leistung für eingezäunte Denkinhalte mit sehr langen, ununterbrochenen Zeilen. – Problem behoben, bei dem Anthropic-Anfragen signierte Serverkomprimierungsblöcke mit nicht unterstützten Thread-Metadaten wiedergaben, wodurch eine abgelehnte Anfrage vor einem erneuten Versuch vermieden wurde. – Verbesserte Diagnose für Anthropic-Verbindungen, die vor einer Antwort unterbrochen werden, indem die verstrichene Zeit, der Upload-Status und die Anfragegröße gemeldet werden.

  • Problem behoben, bei dem Anthropic-Gespräche die Argumentation früherer Nicht-Claude-Runden verloren oder durch Komprimierung erhalten blieben. – Korrektur der Anmeldeinformationsrotation und des Wiederholungszeitraums für benutzerdefinierte Anbieter, die den Zhipu Coding Plan-Endpunkt verwenden, sodass Kontingentzurücksetzungen nach Peking-Zeit berücksichtigt werden.
  • Fehler bei der Nutzungsbeschränkung von Claude Fable und Mythos behoben, sodass bei der Rotation nach Möglichkeit ein Geschwisterkonto mit verfügbarem Kontingent ausgewählt wird. – Ungültige Antigravity CLI-Werkzeugargumente geben jetzt Validierungsfehler und das erwartete Schema an das Modell zurück, anstatt den Zug zu beenden.
  • Verlassene Antigravity CLI-Anmeldeverzeichnisse ohne Anmeldeinformationen werden nach 24 Stunden automatisch bereinigt. – Verbesserte Zuverlässigkeit verwalteter Antigravity CLI-Downloads bei langsamen Verbindungen und Bereitstellung nützlicherer Fortschritts- und Zeitüberschreitungsfehler. – Problem behoben, bei dem Host-Tools von Antigravity CLI mit gemischten Vereinigungsschemata falsch veröffentlicht wurden, sodass Subagenten Ergebnisse übermitteln konnten.
  • Problem behoben, bei dem Codex-Assistentennachrichten in der partial_answer-Phase ihre Phase verloren, wenn sie gespeichert und wiedergegeben wurden.

@oh-my-pi/pi-catalog

Behoben

  • Die Unterstützung für den Muse Spark 1.3 von Factory Droid wurde korrigiert, sodass Bildeingaben funktionieren und das Modell ohne das Feature-Flag für den Ruhestand verfügbar ist.
  • Die GitLab Duo Claude-Modelle wurden korrigiert, sodass der frühere Argumentationskontext bei nachfolgenden Drehungen und Verdichtungen korrekt gehandhabt wird. – Veraltete Metadaten des Befehlscodemodells wurden korrigiert, einschließlich Unterstützung für Bildeingaben, Argumentationskontrollen, Token-Preise und Einschränkungen für den Bereitstellungskontext. – Die Zeitzonenbehandlung bei erneuten Versuchen und Zurücksetzen für benutzerdefinierte Anbieter, die den Zhipu Coding Plan-Endpunkt verwenden, wurde korrigiert, einschließlich Basis-URLs mit abschließenden Schrägstrichen.

@oh-my-pi/pi-coding-agent

Breaking Changes

– Der JavaScript eval commit-Helfer validiert seine Argumente jetzt streng: Unbekannte Optionsnamen und Nicht-Objekt-Optionen lösen ein TypeError aus, das die unterstützten Optionen auflistet. Aktualisieren Sie Skripte, die zusätzliche Optionen übergeben. Beim Festschreiben eines unveränderten Entwurfs-Repositorys wird nun gemeldet, dass es unverändert ist, anstatt take() vorzuschlagen.

Hinzugefügt

– Die standardmäßig aktivierte Einstellung providers.webKeyless wurde hinzugefügt, um zu steuern, ob die Websuche und das Lesen von URLs schlüssellose Dienste nutzen dürfen. Deaktivieren Sie es, um diese Vorgänge auf konfigurierte Anbieter zu beschränken. Einzelne omp q --model web/<engine>-Anfragen können weiterhin explizit einen schlüssellosen Motor ausführen. – Konfigurierbare Live-Voice-Endpunkte und API-Tasten bis live.endpoint und live.apiKey hinzugefügt. Live Voice kann jetzt ohne Codex- oder ChatGPT-Anmeldung eine Verbindung zu jedem OpenAI Realtime WebRTC-kompatiblen Server herstellen, einschließlich Offline-Nutzung, und live.voice akzeptiert beliebige Sprachnamen. – Der Computer el.setValue() akzeptiert jetzt endliche sichere Ganzzahlen und Dezimalzahlen und schreibt sie als Text, während er weiterhin nicht unterstützte Werte wie Boolesche Werte, Objekte, NaN und Infinity ablehnt. – Unter macOS melden Browser-Ergebnisse jetzt relevante native Fenster – wie Auswahlmöglichkeiten, Druck- oder Speicherblätter, Anmeldeaufforderungen, Passkey-Dialoge und Berechtigungsblasen – mit ihren computer.window()-Kennungen. – Der Browser select() akzeptiert jetzt label-, wert- und nullbasierte indexbasierte Auswahlmöglichkeiten, einschließlich gemischter Auswahlmöglichkeiten für Mehrfachauswahl-Steuerelemente, über Chromium-, Tern- und cmux-Registerkarten hinweg.

Geändert

  • Keyless Parallel Searches senden keine Sitzungs- oder Modell-IDs mehr; Es wird nur die Suchanfrage gesendet. – Die macOS-Übernahmemeldungen des computer-Tools beschreiben jetzt den tatsächlichen Status der Tastaturübergabe und erläutern das Verhalten von Hintergrundfensterbewegungen und Nur-Hover-Steuerelementen. – Chromium tab.observe() und tab.ariaSnapshot() warten jetzt kurz auf Seitenaktualisierungen, die durch vorhergehende Aktionen ausgelöst wurden, wodurch zuverlässigere Ergebnisse nach der Aktion erzielt werden. – Wenn ein anderer Agent den Desktop steuert, identifiziert InputBusy jetzt diesen Agenten und seinen OMP-Prozess. – Subagenten verwenden jetzt standardmäßig ihren eigenen Browserkontext, anstatt Tabs in der Chrome-, Tern- oder cmux-Sitzung des Benutzers zu öffnen; Relay- oder Tern-Zugriff kann weiterhin explizit angefordert werden. – Die Browser-Aufgabenführung wird jetzt automatisch nach dem ersten Browseraufruf bereitgestellt, wobei die Sicherheitsanleitung vor dem ersten Aufruf verfügbar ist und nach der Komprimierung oder dem Zurückspulen wiederhergestellt wird.
  • Lesevorgänge für benannte Menüs umfassen jetzt verschachtelte Befehle mit ihren vollständigen Befehlspfaden. – Der eval commit-Helfer führt jetzt zusätzlich zu den Hooks in .git/hooks/ auch konfigurierte Git-Hooks aus, was dem Verhalten von git commit entspricht. Konfigurierte Hooks können dazu führen, dass Commits länger dauern oder abgelehnt werden. – Dienstbereitschaftsmuster stimmen jetzt korrekt mit Zeilengrenzen überein und Shell-Dateizeitbefehle berücksichtigen die konfigurierte TZ-Zeitzone. – Große write- und edit-Aufrufe reagieren weiterhin, während ihre Argumente gestreamt werden. – Selektive Commits verarbeiten initialisierte Submodulzeiger und Sparse-Checkouts jetzt genauer und melden nicht übereinstimmende Pfade explizit. – Git-Commit-Vorgänge bieten jetzt klareres Status- und Hook-Feedback, einschließlich unveränderter Repositorys, Hook-Ausgabe, Hook-modifizierter Commit-Subjekte und Repositorys mit einem laufenden Vorgang oder ungelösten Konflikten. – /continue setzt jetzt die neueste Sitzung für das aktuelle Verzeichnis fort, wenn die letzte Sitzung vor dem Empfang der ersten Nachricht an anderer Stelle erstellt wurde. – /copy kopiert jetzt den Inhalt, der von out://-Antworten in der Mitte der Runde angezeigt wird, und behält deren Codeblöcke bei.
  • Im Zielmodus aktivierte Tools bleiben auch nach Verlassen dieses Modus verfügbar. – Die Verwendung der Statuszeile spiegelt jetzt die tatsächlich ausgewählten Anmeldeinformationen für Anbieter mit mehreren Anmeldeinformationen wider. – Benutzerdefinierte Anbieter, die den Zhipu Coding Plan-Endpunkt verwenden, versuchen es jetzt erneut mit der korrekten Kontingentrücksetzung nach Peking-Zeit. – ^model-Referenzen, gefolgt von Satzzeichen, werden jetzt als Model-Agent-Referenzen aufgelöst. – /restart startet jetzt über den ursprünglichen Launcher neu, sodass aktualisierte Installationen von der fortgesetzten Sitzung verwendet werden. – RPC-Hosts empfangen zuverlässig Abschlussereignisse nach Kontingentfehlern und OSC 7501-Terminals geben bei einem neueren Lauf keine veralteten Erfolgsbenachrichtigungen mehr wieder.

Behoben

– Problem behoben, bei dem konfigurierte Exa- und Firecrawl-Anmeldeinformationen stillschweigend auf schlüssellose Endpunkte zurückfielen, wenn die Auflösung der Anmeldeinformationen fehlschlug; Anmeldefehler werden jetzt gemeldet. – Problem behoben, bei dem Auswertungszellen den Abschluss delegierter Aufgaben mit yield umgingen; Verwenden Sie stattdessen das Direktwerkzeug. – Problem mit /commit und Eval-Commits behoben, die während der Zusammenführung und anderen Git-Vorgängen falsche Single-Parent-Commits erzeugten; Commits werden jetzt abgelehnt, während ein Vorgang ausgeführt wird oder Konflikte bestehen bleiben. – Die Dokumentation des apply_patch-Tools wurde behoben, in der es fälschlicherweise als Shell-Befehl beschrieben wurde und absolute Pfade nicht zulässig waren. – Die in der Shell rg eingebaute Ignorierung von Schrägstrich-enthaltenden --glob-Mustern wurde behoben. – Fehler behoben, bei dem eval commit only(...) fehlschlug, wenn ein ausgewählter Pfad oder Glob mit keinen geänderten Dateien übereinstimmte. – Problem behoben, bei dem Browseraufrufe nach einer unterbrochenen Seitenauswertung dauerhaft beschäftigt waren, und veraltete JavaScript-, confirm- oder prompt-Dialoge behoben, die dazu führten, dass nachfolgende Aufrufe fehlschlugen. – Behoben, dass macOS Chrome und Electron computer.setValue() keine Option aus einer leeren Optionsliste auswählen konnten. – Problem behoben, bei dem Browser-Relay-Tabs geschlossen wurden, wenn eine andere Erweiterung – etwa ein Passwort-Manager – den Tab hält; Die Lasche bleibt jetzt zum erneuten Anbringen verfügbar. – Behoben: macOS-Computerübernahmen meldeten keinen Benutzereingriff, wenn der Benutzer mit der Eingabe fortfuhr. – Verbesserte Browser-Relay-Fehler für versteckte Erweiterungsframes durch Identifizierung des beteiligten Frames, der Erweiterung und der Seite. – Die Anthropic-Websuche für site:-Anfragen und sicherheitsverweigerte Suchen wurde korrigiert, einschließlich klarerer Ablehnungs- und Anbieterfehlerberichte und angemessenem Wiederholungsverhalten.

  • Subagenten ohne Ausgabeschema erhalten kein unnötiges yield-Tool mehr und yield ohne Daten verwendet nicht mehr fälschlicherweise die letzte Nachricht als Ergebnis.
  • macOS-Popup- und Menüinteraktionen behoben, die dazu führen konnten, dass Menüs geöffnet blieben oder das falsche Steuerelement gedrückt wurde.
  • Behoben, dass Claude nach Modellwechseln oder Komprimierung die Argumentation früherer Nicht-Claude-Modellrunden verlor, und verhinderte, dass der Ablehnungstext spätere Anfragen kontaminierte. – Problem behoben, bei dem selektive Commits aktualisierte Submodulzeiger übersprangen und Sparse-Checkout-Pfade fälschlicherweise als Löschungen meldeten. – Problem behoben, bei dem Git-Statusscans hängen blieben, wenn Git-Hintergrundprozesse die Ausgabepipes offen hielten. – Problem behoben, bei dem der WebKit-Start beim ersten Start unter macOS auf Chromium zurückfiel, während die Engine noch initialisiert wurde. – Problem behoben, bei dem die Ausgabe von Pre-Commit-Hooks bei der Ablehnung bei Commit-Fehlern weggelassen wurde. – Die Ghidra-Analyse von Objective-C-Nachrichtenergebnissen und Arm64-Retain-Register-Daten in Mach-O-Binärdateien, einschließlich zwischengespeicherter Frameworks, wurde korrigiert.
  • Browserinteraktionen hinter modalen Dialogen behoben, die fälschlicherweise den Erfolg meldeten; Abgedeckte Felder und deaktivierte Elemente werden nun abgelehnt und abgedeckte Drag-Endpunkte werden erkannt.
  • RPC-Anmeldung für Anbieter korrigiert, die eine Bestätigung auf eigenes Risiko erfordern; Die Bestätigung wird nun dem Gastgeber vorgelegt und die Anmeldung erfolgt erst nach Genehmigung. – Unter Linux verbraucht die Sprachserver-Dateiüberwachung nicht mehr übermäßig viele Inotify-Überwachungen in node_modules und .git/objects.

Behoben

  • macOS-Übernahme und Hintergrundeingabe durch Senden von Tasten behoben, während der Benutzer aktiv tippt oder Eingabesteuerungen gedrückt hält; Solche Vorgänge warten nun auf einen sicheren Ruhepunkt oder schlagen fehl, ohne Eingaben zu senden. – Es wurde behoben, dass bei Interaktionen mit macOS-Menüs und Popup-Schaltflächen Menüs geöffnet blieben oder Tasten an die Anwendung des Benutzers gesendet wurden, nachdem die Hintergrundeingabe abgeschlossen war. – Behoben, dass macOS-Hintergrundaktionen fälschlicherweise gestoppt wurden, wenn die App des Benutzers kurzzeitig die Tastatur betätigte, und verbesserte Zielauswahl nach Drag-and-Drop oder Fernsteuerungsinteraktion. – Wayland-Screenshots und Screenshot-abhängiges clicks, Drags und Scrolls in veröffentlichten Linux-Builds wurden behoben. capabilities() meldet jetzt, wenn die Erfassung nicht verfügbar ist, mit einem erklärenden Fehler, wenn PipeWire fehlt. – Ein Windows-nativer IPC-Absturz wurde behoben, der dazu führen konnte, dass vom Daemon bereitgestellte Tools hängen blieben, nachdem eine andere Sitzung ihre Verbindung geschlossen hatte. – commitCreate()-Fehler behoben, die dadurch verursacht wurden, dass die Hook-Ausgabe pre-commit oder commit-msg nicht abgelehnt wurde; Die Hook-Ausgabe ist jetzt konsistent mit git commit enthalten. – Die am ersten Attribut oder Dokumentationskommentar verankerten Rust-Blockbearbeitungen wurden korrigiert, sodass sie das gesamte Element abdecken und nicht als einzeilige Bearbeitungen behandelt werden.

oh-my-pi v18.22.1

@oh-my-pi/pi-agent-core

Added

  • A model on an extension's custom api can take the Anthropic on-demand compaction lane by declaring remoteCompaction: { api: "anthropic-messages", enabled: true }; the request goes through its own stream like any turn (#19580 by @ryanskidmore)

Fixed

  • Fixed provider-error handling so failed tool calls are no longer fed back to the model as refusal explanations.
  • Fixed one-shot retries and title generation for custom Zhipu Coding Plan providers so Beijing-time quota resets are honored.
  • Fixed OpenAI remote compaction (V1 and V2) dropping configured headers of models.yml and extension-registered models, so header-authenticated gateways returned 401 (#19579 by @ryanskidmore)

@oh-my-pi/pi-ai

Added

  • Added support for request-specific Anthropic beta headers through the extraBetas option in buildAnthropicSearchHeaders.
  • Added omitDemotedReasoning to StreamOptions, allowing Anthropic requests to omit other models' reasoning that would otherwise be replayed as text; refused requests report the omitted block count in demotedReasoningBlocks.
  • Usage reports can now include the credential ID used by API-key or OAuth credentials, and AuthStorage.sessions.sticky provides a read-only lookup for the credential serving a session.
  • Added riskAcknowledgement to OAuthPrompt, allowing hosts to display login-warning acceptance text even when they decline input before the authorization URL is shown.
  • remoteCompaction: { api: "anthropic-messages", enabled: true } opts an Anthropic model at a gateway baseUrl outside the known deployments into on-demand compaction; enabled alone keeps such a gateway excluded, and a reroute away from the configured endpoint still has to reach a known deployment. isBuiltinApi() tells a built-in request adapter from an extension's custom api (#19580 by @ryanskidmore)

Changed

  • OpenAI Codex requests now track the latest compatible @openai/codex client version automatically, with an optional PI_AI_CODEX_CLIENT_VERSION override, so newly available Codex models can be used without updating omp.
  • Updated OpenAI Codex request formatting and ChatGPT token-refresh reporting to match Codex CLI 0.169.
  • Updated Claude Code and Gemini CLI client version identifiers to 2.1.326 and 0.68.0, respectively.

Fixed

  • Fixed OpenAI Decisions usage accounting for gateways that report prompt_tokens and completion_tokens instead of input_tokens and output_tokens.
  • Improved streaming performance for fenced thinking content containing very long unbroken lines.
  • Fixed Anthropic requests replaying signed server-compaction blocks with unsupported thread metadata, avoiding a rejected request before retrying.
  • Improved diagnostics for Anthropic connections that drop before a response by reporting elapsed time, upload state, and request size.
  • Fixed Anthropic conversations losing reasoning from earlier non-Claude turns or turns retained through compaction.
  • Fixed credential rotation and retry timing for custom providers using the Zhipu Coding Plan endpoint so Beijing-time quota resets are honored.
  • Fixed Claude Fable and Mythos usage-limit errors so rotation selects a sibling account with available quota when possible.
  • Invalid Antigravity CLI tool arguments now return validation errors and the expected schema to the model instead of ending the turn.
  • Abandoned Antigravity CLI login directories without credentials are automatically cleaned up after 24 hours.
  • Improved reliability of managed Antigravity CLI downloads on slow connections and provided more useful progress and timeout errors.
  • Fixed Antigravity CLI host tools with mixed-type union schemas being published incorrectly, allowing subagents to submit results.
  • Fixed Codex assistant messages in the partial_answer phase losing their phase when stored and replayed.

@oh-my-pi/pi-coding-agent

Breaking Changes

  • The JavaScript eval commit helper now validates its arguments strictly: unknown option names and non-object options throw a TypeError that lists the supported options. Update scripts that pass extra options. Committing an unchanged draft repository now reports that it is unchanged instead of suggesting take().

Added

  • Added the providers.webKeyless setting, enabled by default, to control whether web search and URL reading may use keyless services. Disable it to restrict these operations to configured providers; individual omp q --model web/<engine> requests can still explicitly run a keyless engine.
  • Added configurable live voice endpoints and API keys through live.endpoint and live.apiKey. Live voice can now connect to any OpenAI Realtime WebRTC-compatible server without Codex or ChatGPT sign-in, including offline use, and live.voice accepts arbitrary voice names.
  • Computer el.setValue() now accepts finite safe integer and decimal numbers and writes them as text, while continuing to reject unsupported values such as booleans, objects, NaN, and Infinity.
  • On macOS, browser results now report relevant native windows—such as pickers, print or save sheets, sign-in prompts, passkey dialogs, and permission bubbles—with their computer.window() identifiers.
  • Browser select() now accepts label-, value-, and zero-based index-based choices, including mixed choices for multi-select controls, across Chromium, Tern, and cmux tabs.

Changed

  • The computer tool's macOS takeover messages now describe the actual keyboard handoff state and explain the behavior of background window moves and hover-only controls.
  • Chromium tab.observe() and tab.ariaSnapshot() now wait briefly for page updates triggered by preceding actions, producing more reliable post-action results.
  • When another agent controls the desktop, InputBusy now identifies that agent and its omp process.
  • Subagents now use their own browser context by default instead of opening tabs in the user's Chrome, Tern, or cmux session; relay or Tern access can still be requested explicitly.
  • Browser task guidance is now delivered automatically after the first browser call, with safety guidance available before the first call and restored after compaction or rewind.
  • Named-menu reads now include nested commands with their complete command paths.
  • The eval commit helper now runs configured Git hooks in addition to hooks in .git/hooks/, matching git commit behavior. Configured hooks may cause commits to take longer or be rejected.
  • Service readiness patterns now match line boundaries correctly, and shell file-time commands honor the configured TZ timezone.
  • Large write and edit calls remain responsive while their arguments stream.
  • Selective commits now handle initialized submodule pointers and sparse checkouts more accurately, and report unmatched paths explicitly.
  • Git commit operations now provide clearer status and hook feedback, including unchanged repositories, hook output, hook-modified commit subjects, and repositories with an in-progress operation or unresolved conflicts.
  • /continue now resumes the newest session for the current directory when the most recent session was created elsewhere before receiving its first message.
  • /copy now copies the content displayed by mid-turn out:// replies and preserves their code blocks.
  • Tools enabled in goal mode remain available after leaving that mode.
  • Status-line usage now reflects the credential actually selected for multi-credential providers.
  • Custom providers using the Zhipu Coding Plan endpoint now retry at the correct Beijing-time quota reset.
  • ^model references followed by sentence punctuation now resolve as model-agent references.
  • /restart now restarts through the original launcher so upgraded installations are used by the resumed session.
  • RPC hosts reliably receive completion events after quota errors, and OSC 7501 terminals no longer play stale success notifications during a newer run.

  • Fixed eval cells bypassing delegated-task completion with yield; use the direct tool instead.
  • Fixed /commit and eval commits creating incorrect single-parent commits during merge and other Git operations; commits are now refused while an operation is in progress or conflicts remain.
  • Fixed the apply_patch tool documentation incorrectly describing it as a shell command and disallowing absolute paths.
  • Fixed the shell rg builtin ignoring slash-containing --glob patterns.
  • Fixed eval commit only(...) failing when a selected path or glob matched no changed files.
  • Fixed browser calls becoming permanently busy after interrupted page evaluation, and fixed stale JavaScript confirm or prompt dialogs causing subsequent calls to fail.
  • Fixed macOS Chrome and Electron computer.setValue() failing to select an option from an empty option list.
  • Fixed browser relay tabs being closed when another extension—such as a password manager—holds the tab; the tab now remains available for reattachment.
  • Fixed macOS computer takeovers failing to report user intervention when the user continued typing.
  • Improved browser relay errors for hidden extension frames by identifying the frame, extension, and page involved.
  • Fixed Anthropic web search for site: queries and safety-refused searches, including clearer refusal and provider-error reporting and appropriate retry behavior.
  • Subagents without an output schema no longer receive an unnecessary yield tool, and yield without data no longer incorrectly uses the last message as its result.
  • Fixed macOS popup and menu interactions that could leave menus open or press the wrong control.
  • Fixed Claude losing reasoning from earlier non-Claude model turns after model switches or compaction, and prevented refusal text from contaminating later requests.
  • Fixed selective commits skipping updated submodule pointers and incorrectly reporting sparse-checkout paths as deletions.
  • Fixed Git status scans hanging when background Git processes kept output pipes open.
  • Fixed first-launch WebKit startup on macOS falling back to Chromium while the engine was still initializing.
  • Fixed rejecting pre-commit hook output being omitted from commit errors.
  • Fixed Ghidra analysis of Objective-C message results and arm64 retain-register data in Mach-O binaries, including cached frameworks.
  • Fixed browser interactions behind modal dialogs incorrectly reporting success; covered fields and disabled elements are now rejected, and covered drag endpoints are detected.
  • Fixed RPC login for providers that require an at-your-own-risk confirmation; the confirmation is now presented to the host and login proceeds only after approval.
  • On Linux, language-server file watching no longer consumes excessive inotify watches in node_modules and .git/objects.

  • Tree listings now expose gitlink modes so selective commits can distinguish submodule pointers from ordinary files.

Fixed

  • Fixed macOS and Windows focus restoration after computer takeovers and background input, including cases where the target application brought itself forward; the originating app now becomes active again and focus results are reported accurately.
  • Fixed keyboard input on Windows and X11 when the target uses a different keyboard layout or when Caps Lock, StickyKeys, or another layout is active.
  • Fixed X11 input being delivered to another application's menu, screen lock, or other keyboard grab; input now waits for transient grabs to end or fails without sending keys.
  • Fixed Linux text entry from affecting the user's active field during agent input. Supported GTK and Qt text fields now use safe accessibility-based entry where possible, while unsupported fields continue to use the existing keyboard path.
  • Fixed Linux interactions with combo boxes so unsupported popup-opening actions are refused safely, while supported GTK 3 and Chromium selections can be made without taking over the keyboard.
  • Fixed macOS accessibility labels for SwiftUI toggles, including matching their adjacent labels with find({ title }).
  • Fixed macOS element references in refreshed tables, including Activity Monitor, so row actions follow an unchanged row, reject a changed row safely, and provide useful before-and-after details when the row cannot be matched.
  • Fixed macOS clicks and presses being reported as successful when the target was hidden, unavailable, covered by a sheet, or otherwise not clickable.
  • Fixed macOS Chromium <select> interactions, including option matching, menu cleanup, and safe handling when the available options are incomplete.
  • Fixed macOS setValue for numeric controls such as sliders and steppers, including reporting values that the control clamps or rounds; unsupported but step-able controls now explain how to use their increment and decrement actions.
  • Fixed macOS takeover and background input from sending keys while the user is actively typing or holding input controls; such operations now wait for a safe idle point or fail without sending input.
  • Fixed macOS menu and popup-button interactions from leaving menus open or sending keys into the user's application after background input completes.
  • Fixed macOS background actions from incorrectly stopping when the user's app briefly took the keyboard, and improved target selection after drag-and-drop or remote-control interaction.
  • Fixed Wayland screenshots and screenshot-dependent clicks, drags, and scrolls in released Linux builds. capabilities() now reports when capture is unavailable, with an explanatory error when PipeWire is missing.
  • Fixed a Windows native IPC crash that could leave daemon-served tools hanging after another session closed its connection.
  • Fixed commitCreate() errors from omitting rejecting pre-commit or commit-msg hook output; hook output is now included consistently with git commit.
  • Fixed Rust block edits anchored on the first attribute or documentation comment so they cover the complete item instead of being treated as single-line edits.

Removed

  • Removed the obsolete wayland-pipewire Cargo feature and OMP_NATIVE_FEATURES configuration variable.

@oh-my-pi/omp-stats

Fixed

  • Fixed the Gain tab undercounting savings for sessions that use snapcompact context compaction, including backfilling recent compaction history after upgrading.

@oh-my-pi/pi-tui

Added

  • Task tool and agent hub rows now use distinct, theme-aware colours for the main agent and subagents; themes can optionally customize the six subagent colours.
  • Added word wrapping for table columns and rows, preserving hard line breaks so long table content remains readable.

Changed

  • Improved terminal UI responsiveness and reduced CPU usage while streaming long responses, monitoring the event loop, and typing with macOS spell checking enabled.
  • Status account identities can now include an optional credential ID, allowing usage to be attributed to API-key accounts and cached usage to refresh when the credential changes.

Fixed

  • Images in Ask forms now render correctly in Kitty-protocol terminals, including Kitty, Ghostty, and herdr.
  • Fixed model mentions followed by punctuation so they become editable chips without consuming the punctuation.
  • Fixed /copy to copy the visible prose from mid-turn out:// replies, including replies sent by commands, instead of the tool's internal result text.
