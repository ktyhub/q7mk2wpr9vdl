oh-my-pi v18.18.3

Patch Veröffentlicht9. Nov. 2026 Quellecan1357/oh-my-pi Englisches Original

oh-my-pi v18.18.3

@oh-my-pi/pi-catalog

Geändert

– Eine balanced-Delegierungsvoreingenommenheit zwischen eager und restrained hinzugefügt; Modelle ohne eine delegation-bias-Regel werden jetzt nach dieser statt nach eager aufgelöst

@oh-my-pi/pi-coding-agent

Breaking Changes

– Das ask-Tool verwendet ein HTML-Formular ({ html }) anstelle von questions[]: Das Modell schreibt ein <form> aus Radios, Kontrollkästchen, Auswahlen, Texteingaben und Textbereichen mit vorausgewählter Empfehlung und empfängt die übermittelten Formulardaten als JSON. AskToolDetails ist jetzt { answers: { name, question, answer }[]; timedOut? }; QuestionResult, die Pfade „Andere“, „Chat darüber“, Antwort-Notiz und Antwortbild des Tools werden entfernt, und die erneute Antwort /tree öffnet das ursprüngliche Formular erneut (NavigateTreeResult.reopenAsk trägt html).

Hinzugefügt

– In Tern bietet das Rechts-cliKlicken einer ask-Antwort eine Notiz, die diese Antwort mit Anmerkungen versehen, ohne sie auszuwählen (#18551 von @H4vC)

  • task.eager (preferred/always) formt jetzt nur die Systemaufforderung des Hauptagenten; Subagenten greifen auf die eigene Delegationsrichtlinie ihres Modells zurück, anstatt dazu gedrängt zu werden, weitere Subagenten zu erzeugen
  • ask-Formulare können Bilder anzeigen: <img src> von einer http(s)-URL, einem data:-URI oder einer lokalen Datei (relativ zum Arbeitsverzeichnis der Sitzung) und Inline-<svg>-Diagramme, die im Terminalformular und nativ in Tern gezeichnet werden
  • ask-Formulare geben jeder Radio- und Checkbox-Gruppe eine Freitext-Antwort „Andere“: Der Text ist der Wert des Radios oder wird an das Array der Checkbox-Gruppe angehängt (Feld-für-Feld-Fallback, Collab-Gäste und ACP-Ermittlung inbegriffen). – Die Benutzeroberfläche der Erweiterung erhält das optionale ui.formDialog(html, options), das ein HTML-<form> rendert und in { data, timedOut? } auflöst (undefiniert, wenn abgebrochen). Die interaktive TUI stellt es als Formulardialog dar, ACP clients mit Formularerhebung erhalten eine Erhebung mit einer Eigenschaft pro Feld und Hosts ohne diese (RPC) beantworten das ask-Tool Feld für Feld über select/input/editor. – Eval-Zellen können Shell-Befehle mit sh ausführen: sh("git status") in Python, await sh`ls ${dir}` or await sh("make", { cwd }) in JavaScript. Commands run on the embedded bash engine to completion (never auto-backgrounded), return their output, and raise ShellError mit dem Exit-Code bei Fehler. – omp zsh unter Windows führt die integrierten Dienstprogramme von omp (ls, cat, head, jq, …) für Befehle aus, die PATH nicht hat, es sei denn, ein command_not_found_handler verarbeitet sie (#18532 von @H4vC).

Geändert

– Präzisierte Tool- und interne URL-Beschreibungen für prägnante history://-Transkripte, proc://-Jobaufbewahrung und Suche nach geparkten Agenten sowie read JSON-Abfragetextausgabe (#18553 von @xiangnan0811)

  • Modelle ohne Delegationsregel (Claude, Gemini, …) werden nicht mehr zum Delegieren gedrängt: Die Regel „Unbekannten Code über Aufgabe zuordnen“ und die „Aufgabe + Scout“-Nudges in Suchwerkzeugbeschreibungen werden durch einen leichten Vorschlag ersetzt, unbekannte Subsysteme mit einem Scout zu erkunden
  • In Tern markiert cli eine ask-Antwort und dann „Notiz“ kommentiert jetzt die auf der angezeigten Frage hervorgehobene Antwort anstelle der gerade cli markierten Antwort (#18551 von @H4vC)

Behoben

  • Problem behoben, bei dem ask-Notizen mit n hinzugefügt wurden, direkt nachdem eine Antwort ausgewählt wurde, die auf der vorherigen Frage statt auf der angezeigten landete; ein Tern click, dann notiert Note immer noch die Antwort, nur clicked, und die Notizschaltfläche benennt sie (#18317 von @DonMikone) – Fehler behoben, bei dem /export unter Windows beim Speichern im aktuellen Verzeichnis fehlschlug, einschließlich relativer Pfade wie sub/../session.html; Die Exportmeldung zeigt nun den vollständigen Pfad der geschriebenen Datei an (#18369, #18525 von @minhngoc25a). – Die Todo-Initialisierung nennt leere Phasen jetzt Tasks, sodass nachfolgende Updates sie beheben können (#18552 von @xiangnan0811) – omp zsh und das Bash-Tool unter Windows: Hintergrundbefehle ohne Jobsteuerung ignorieren Strg-C (INT und QUIT in zsh) wie zsh und Bash, sodass sie durch Strg-C der Konsole ausgeführt werden (#18532 von @H4vC). – omp zsh findet die Funktionsbibliothek des Systems zsh (compinit lädt) unter Debian, Ubuntu und Arch und unter Windows von einem MSYS2, Cygwin oder Git für Windows zsh (#18532 von @H4vC).
  • omp zsh unter Windows: Eingegebene Befehle enden nicht mehr auf ^M, Programme werden über Path gefunden, über Pipelines geleitete Skripte werden in jeder Zeile ausgeführt, cd übernimmt C:\…/C:/…, .. und ~ (wobei $PWD als C:/… beibehalten wird), >/dev/null funktioniert, die Eingabeaufforderung ist % und nicht die von Root #, $OSTYPE ist msys und es wird keine USERNAME-Warnung gedruckt (#18532 von @H4vC).
  • omp zsh unter Windows bearbeitet Zeilen mit ZLE (Verlauf, Tab-Vervollständigung, Tastenkombinationen, $COLUMNS); Strg-C verlässt die Zeile, führt einen INT-Trap aus oder unterbricht einen read, der dann fortgesetzt wird, anstatt die Shell zu beenden (#18532 von @H4vC).
  • omp zsh unter Windows: Strg-C unterbricht das Vordergrundprogramm, jobs, fg und bg arbeiten (ein mit fg zurückgebrachter Job erhält auch Strg-C), und die Prozessersetzung erreicht Windows-Programme (diff <(…) <(…), prog >(…)) (#18532 von @H4vC). – Unter Windows funktioniert /dev/null im Bash-Tool (>/dev/null, cat /dev/null, [ -c /dev/null ]) (#18532 von @H4vC). – Unter Windows öffnet /dev/tty die Konsole in omp zsh und dem Bash-Tool (prog >/dev/tty) und ein durch Strg-C beendetes MSYS- oder Cygwin-Programm meldet Status 130 statt 512 (#18532 von @H4vC). – omp zsh druckt die [n] pid-Zeile für eine Hintergrundpipeline unter Jobsteuerung, wie es für einen einzelnen Befehl der Fall ist (#18532 von @H4vC). – omp zsh startet compinit um ein Vielfaches schneller: Einzelne Array- und Assoziationselemente werden zugewiesen und gelesen, ohne den gesamten Parameter zu kopieren, und autoload -r liest die .zwc-Digests in $fpath nicht mehr für jede aufgelöste Funktion erneut (#18533 von @H4vC). – read -k und read -q von omp zsh lesen einen Schlüssel vom Terminal, ohne auf die Eingabetaste zu warten, wie es zsh tut, anstatt die Standardeingabe zu lesen (#18533 von @H4vC). – omp zsh-Vervollständigungslisten markieren Dateitypen erneut (dir/, exe*), print -c ordnet Wörter in Spalten ohne Terminal an und ${x?msg} beendet eine nicht interaktive Shell mit Status 1, wie es zsh tut (#18533 von @H4vC).
  • omp zsh-Floats behalten die volle Genauigkeit in der Arithmetik (s=$EPOCHREALTIME; print $(( EPOCHREALTIME - s )) driftet nicht mehr um bis zu einer Sekunde) und drucken weiterhin im -F/-E-Stil (#18533 von @H4vC). – omp zshs typeset -U path / typeset -U fpath (und local -U path) löschen wiederholte Einträge, wie es zsh tut (#18533 von @H4vC). – omp zsh und das Bash-Tool: $! einer Hintergrundpipeline ist die PID des letzten Programms, wie in Bash und ZSH, also signalisiert kill $! dieses Programm; Die [n]-Zeile von omp zsh für eine Hintergrundpipeline listet die PID jedes ihrer Prozesse auf, wie es zsh tut (#18547 von @H4vC).
  • omp zsh ist schneller: Funktionsaufrufe, Schleifen und Arithmetik laufen 2–3× schneller, compinit fast 4× schneller, und der Aufbau eines großen Arrays oder einer Assoziation Element für Element (a+=(x), h[k]=v) oder das Lesen von $a[i] aus einem großen Array verlangsamt sich nicht mehr mit seiner Größe (#18565 um @H4vC).

@oh-my-pi/collab-web

Geändert

  • ask-Toolkarten zeigen die Feldsatzlegenden und die Feldanzahl des HTML-Formulars an, während sie ausstehen, und jede Frage mit ihrer übermittelten Antwort (oder „(keine Antwort)“), sobald sie beantwortet wurde, wobei die bis zum Timeout erfolgten Übermittlungen gekennzeichnet werden

@oh-my-pi/pi-tui

Breaking Changes

– Der ask-Tool-Renderer zeichnet jetzt { html }-Formularaufrufe und AskToolDetails { answers, timedOut }-Ergebnisse; QuestionResult und die Detailfelder der Fragenliste wurden entfernt.

Hinzugefügt

– Dem rechten click-Menü jeder Antwortzeile im Fragedialog in Tern wurde ein Notizeintrag hinzugefügt, der diese Antwort kommentiert, ohne sie auszuwählen (#18551 von @H4vC) – HtmlFormDialog hinzugefügt, das ein HTML-Formular als interaktives Terminalformular darstellt, lange Formulare in Seiten aufteilt und die Antworten als JSON zurückgibt. Einzelne <select>s sind einzeilige Dropdown-Listen, Radio- und Kontrollkästchengruppen erhalten eine Freitext-Antwort „Andere“, <img> (URL, data:-URI oder lokale Datei) und Inline-<svg>-Bilder werden im Hintergrund geladen, ein optionales Inaktivitäts-Timeout übermittelt die aktuellen Werte und Tern-Terminals erhalten das Formular nativ. – Option cursor: "start" zu Editor.setText hinzugefügt, sodass vorab ausgefüllter mehrzeiliger Text in der ersten Zeile geöffnet wird.

Geändert

– Die Notiz des Fragedialogs direkt nach einem Zeiger click kommentiert jetzt die hervorgehobene Antwort der angezeigten Frage anstelle der nur clicked Antwort, und die Notizschaltfläche benennt kein Weiterleitungsziel mehr (#18551 von @H4vC)

Behoben

– Der Fehler n des Fragedialogs direkt nach einem Tastaturbefehl wurde behoben, der die Antwort der vorherigen Frage anstelle der angezeigten hervorgehobenen Zeile mit Anmerkungen versehen hat; Nur ein Zeiger click leitet Note immer noch auf die gerade ausgewählte Antwort um, und die Schaltfläche „Notiz“ benennt sie dann (#18317 von @DonMikone)

Englisches Original / English original

oh-my-pi v18.18.3

@oh-my-pi/pi-catalog

Changed

  • Added a balanced delegation bias between eager and restrained; models without a delegation-bias rule now resolve to it instead of eager

@oh-my-pi/pi-coding-agent

Breaking Changes

  • The ask tool takes one HTML form ({ html }) instead of questions[]: the model writes a <form> of radios, checkboxes, selects, text inputs and textareas with its recommendation preselected, and receives the submitted form data as JSON. AskToolDetails is now { answers: { name, question, answer }[]; timedOut? }; QuestionResult, the "Other", "Chat about this", answer-note and answer-image paths of the tool are removed, and /tree re-answer reopens the original form (NavigateTreeResult.reopenAsk carries html).

Added

  • In Tern, right-clicking an ask answer offers Note, which annotates that answer without picking it (#18551 by @H4vC)
  • task.eager (preferred/always) now shapes only the main agent's system prompt; subagents fall back to their model's own delegation policy instead of being pushed to spawn further subagents
  • ask forms can show pictures: <img src> from an http(s) URL, a data: URI or a local file (relative to the session's working directory), and inline <svg> diagrams, drawn in the terminal form and natively in Tern
  • ask forms give every radio and checkbox group a free-text "Other" answer: its text is the radio's value or is appended to the checkbox group's array (field-by-field fallback, collab guests and ACP elicitation included)
  • Extension UI gains optional ui.formDialog(html, options), which renders an HTML <form> and resolves to { data, timedOut? } (undefined when cancelled). The interactive TUI renders it as a form dialog, ACP clients with form elicitation get one elicitation with a property per field, and hosts without it (RPC) answer the ask tool field by field through select/input/editor.
  • Eval cells can run shell commands with sh: sh("git status") in Python, await sh`ls ${dir}` or await sh("make", { cwd }) in JavaScript. Commands run on the embedded bash engine to completion (never auto-backgrounded), return their output, and raise ShellError with the exit code on failure.
  • omp zsh on Windows runs omp's builtin utilities (ls, cat, head, jq, …) for commands PATH does not have, unless a command_not_found_handler handles them (#18532 by @H4vC).

Changed

  • Clarified tool and internal-URL descriptions for history:// concise transcripts, proc:// job retention and parked-agent lookups, and read JSON query text output (#18553 by @xiangnan0811)
  • Models without a delegation rule (Claude, Gemini, …) no longer get pushed to delegate: the "map unknown code via task" rule and the "Task + scout" nudges in search tool descriptions are replaced by a light suggestion to explore unfamiliar subsystems with a scout
  • In Tern, clicking an ask answer and then Note now annotates the answer highlighted on the question shown instead of the one just clicked (#18551 by @H4vC)

Fixed

  • Fixed ask notes added with n right after picking an answer landing on the previous question instead of the one shown; a Tern click then Note still notes the answer just clicked, and the Note button names it (#18317 by @DonMikone)
  • Fixed /export failing on Windows when saving in the current directory, including relative paths such as sub/../session.html; the export message now shows the full path of the written file (#18369, #18525 by @minhngoc25a).
  • Todo initialization now names empty phases Tasks, so subsequent updates can address them (#18552 by @xiangnan0811)
  • omp zsh and the bash tool on Windows: background commands without job control ignore Ctrl-C (INT, and QUIT in zsh) as zsh and bash do, so the console's Ctrl-C leaves them running (#18532 by @H4vC).
  • omp zsh finds the system zsh's function library (compinit loads) on Debian, Ubuntu and Arch, and on Windows from an MSYS2, Cygwin or Git for Windows zsh (#18532 by @H4vC).
  • omp zsh on Windows: typed commands no longer end in ^M, programs are found through Path, piped scripts run every line, cd takes C:\…/C:/…, .. and ~ (keeping $PWD as C:/…), >/dev/null works, the prompt is % rather than root's #, $OSTYPE is msys, and no USERNAME warning is printed (#18532 by @H4vC).
  • omp zsh on Windows edits lines with ZLE (history, Tab completion, key bindings, $COLUMNS); Ctrl-C abandons the line, runs an INT trap, or interrupts a read that then goes on, instead of ending the shell (#18532 by @H4vC).
  • omp zsh on Windows: Ctrl-C interrupts the foreground program, jobs, fg and bg work (a job brought back with fg gets Ctrl-C too), and process substitution reaches Windows programs (diff <(…) <(…), prog >(…)) (#18532 by @H4vC).
  • On Windows, /dev/null works in the bash tool (>/dev/null, cat /dev/null, [ -c /dev/null ]) (#18532 by @H4vC).
  • On Windows, /dev/tty opens the console in omp zsh and the bash tool (prog >/dev/tty), and an MSYS or Cygwin program killed by Ctrl-C reports status 130 instead of 512 (#18532 by @H4vC).
  • omp zsh prints the [n] pid line for a background pipeline under job control, as it does for a single command (#18532 by @H4vC).
  • omp zsh starts compinit many times faster: single array and association elements are assigned and read without copying the whole parameter, and autoload -r no longer re-reads the .zwc digests in $fpath for every function it resolves (#18533 by @H4vC).
  • omp zsh's read -k and read -q read a key from the terminal without waiting for Enter, as zsh does, instead of reading standard input (#18533 by @H4vC).
  • omp zsh completion listings mark file types again (dir/, exe*), print -c lays words out in columns without a terminal, and ${x?msg} ends a non-interactive shell with status 1 as zsh does (#18533 by @H4vC).
  • omp zsh floats keep full precision in arithmetic (s=$EPOCHREALTIME; print $(( EPOCHREALTIME - s )) no longer drifts by up to a second) and still print in their -F/-E style (#18533 by @H4vC).
  • omp zsh's typeset -U path / typeset -U fpath (and local -U path) drop repeated entries as zsh does (#18533 by @H4vC).
  • omp zsh and the bash tool: $! of a background pipeline is its last program's pid, as in bash and zsh, so kill $! signals that program; omp zsh's [n] line for a background pipeline lists the pid of each of its processes, as zsh does (#18547 by @H4vC).
  • omp zsh is faster: function calls, loops and arithmetic run 2–3× faster, compinit almost 4× faster, and building a large array or association one element at a time (a+=(x), h[k]=v) or reading $a[i] from a large array no longer slows down with its size (#18565 by @H4vC).

@oh-my-pi/collab-web

Changed

  • ask tool cards show the HTML form's fieldset legends and field count while pending, and each question with its submitted answer (or "(no answer)") once answered, flagging submissions made by the timeout

@oh-my-pi/pi-tui

Breaking Changes

  • The ask tool renderer now draws { html } form calls and AskToolDetails { answers, timedOut } results; QuestionResult and the question-list detail fields were removed.

Added

  • Added a Note entry to the right-click menu of each ask dialog answer row in Tern, annotating that answer without picking it (#18551 by @H4vC)
  • Added HtmlFormDialog, which renders an HTML form as an interactive terminal form, splits long forms into pages, and returns the answers as JSON. Single <select>s are one-row dropdowns, radio and checkbox groups get a free-text "Other" answer, <img> (URL, data: URI or local file) and inline <svg> pictures load in the background, an optional inactivity timeout submits the current values, and Tern terminals get the form natively.
  • Added a cursor: "start" option to Editor.setText so prefilled multi-line text opens at its first line.

Changed

  • The ask dialog's Note right after a pointer click now annotates the highlighted answer of the question shown instead of the answer just clicked, and the Note button no longer names a redirect target (#18551 by @H4vC)

Fixed

  • Fixed the ask dialog's n right after a keyboard pick annotating the previous question's answer instead of the highlighted row shown; only a pointer click still redirects Note to the answer just picked, and the Note button then names it (#18317 by @DonMikone)

What's Changed

  • fix(shell): name a background pipeline by its last program's pid by @H4vC in https://github.com/can1357/oh-my-pi/pull/18547
  • fix(todo): default empty init phase names to Tasks by @xiangnan0811 in https://github.com/can1357/oh-my-pi/pull/18552
