oh-my-pi v18.18.7

@oh-my-pi/pi-ai

Hinzugefügt

– LiteLLM-Nutzungsadapter (@oh-my-pi/pi-ai/usage/litellm), der die Schlüssel- und Benutzer-USD-Budgets eines Gateways meldet (#17873 von @maykonmichel) – UsageApi.replaceConfiguredProviders registriert konfigurationsbasierte Nutzungsanbieter zwischen Laufzeitüberschreibungen und dem integrierten Resolver, und UsageProvider.usesRequestKey sorgt dafür, dass die Gesamtnutzungsprüfung nur die Schlüsselinferenz durchführt, die gesendet werden würde (#17873 von @maykonmichel)

Geändert

  • Anbieter mit einer login-warning-Authentifizierungsregel zeigen ihr Kontorisiko vor einer neuen Anmeldung an und starten diese erst, nachdem der Benutzer yes antwortet; Jede andere Antwort oder ein Abbruch speichert nichts und ihr Eintrag in der Anmeldeliste ist mit „(auf eigene Gefahr)“ gekennzeichnet (#18499)

Behoben

  • Claude Fable-Start-Resets melden jetzt das wöchentliche Fable-Limit, das sie löschen, anstelle eines unbekannten Fensters (#18661 von @TheAifam5)

@oh-my-pi/pi-catalog

Hinzugefügt

– Muse Ember (muse-ember-1.0) zum Metamodell API und Muse-Code mit der Argumentationsaufwandsleiter minimal–max und seinem Preis für lange Kontexte von >200.000 hinzugefügt – Authentifizierungsregel login-warning "<text>" hinzugefügt, die dafür sorgt, dass bei einer neuen Anmeldung zuerst das angegebene Kontorisiko akzeptiert wird (#18499)

Geändert

  • Google Antigravity wurde hinter einer Anmeldewarnung wieder aufgenommen, anstatt es anzuhalten (#18499)

Behoben

– Morph (api.morphllm.com)-Anfragen senden jetzt x-session-id und führen eine Konversation über den Worker, der seinen Prompt-Cache hält (#18704 von @wolfiesch)

@oh-my-pi/pi-coding-agent

Hinzugefügt

– /usage und omp usage zeigen LiteLLM-Schlüssel- und Benutzerbudgets für den integrierten litellm-Anbieter und jeden models.yml-Anbieter mit discovery.type: litellm, sofern nicht in disabledProviders aufgeführt (#17873 von @maykonmichel)

  • Erweiterungen können den Bediener vor einem interaktiven Beenden fragen oder diesen abbrechen, mit session_before_shutdown; ein weiteres /exit oder Strg+D überspringt die ausstehenden Eingabeaufforderungen und schließt (#18424 von @aw1cks)

Geändert

  • Die automatische Einlösung bei gespeichertem und zurückgesetztem Wert wird pro Fenster festgelegt: codexResets.autoRedeem5h/autoRedeemWeekly und claudeResets.autoRedeem5h/autoRedeemWeekly/autoRedeemFable ersetzen den autoRedeem jedes Anbieters, dessen Wert in die 5-Stunden- und Wochenschlüssel migriert; Ein Zurücksetzen des Claude Fable-Starts wird allein von autoRedeemFable gesteuert und nur für einen Block ausgegeben, der die wöchentliche Fable-Obergrenze enthält, oder vor Ablauf, wenn die Fable-Nutzung über Null liegt (#18661 von @TheAifam5) – Für Sitzungen ohne Eingabeaufforderungs-Benutzeroberfläche (z. B. omp -p) werden keine gespeicherten Zurücksetzungen mehr ausgegeben, während die automatische Einlösung unset ist, selbst solche, die bald ablaufen (#18661)
  • Google Antigravity ist zurück in /login und omp login, gekennzeichnet mit „(auf eigene Gefahr)“: Eine neue Anmeldung erklärt zunächst, dass Google möglicherweise Konten sperrt, die sich über Tools von Drittanbietern anmelden, und fährt erst fort, nachdem Sie yes eingegeben haben; gespeicherte Antigravity-Logins funktionieren wieder (#18499) – Unter Windows teilt die Beschreibung des Bash-Tools dem Modell mit, dass es in einer emulierten Bash-Umgebung und nicht in cmd oder PowerShell ausgeführt wird, sodass es bash anstelle von dir, %VAR% und anderer cmd-Syntax schreibt

Behoben

– Erweiterungsaufforderungen, die von session_before_*-Handlern angezeigt werden, laufen nicht mehr nach 30 Sekunden ab, während der Operator noch antwortet (#18424 von @aw1cks) – Eine zweite Exit-Anfrage überspringt jetzt ausstehende worktree.onExit-Eingabeaufforderungen und behält diese Arbeitsbäume bei, anstatt auf eine Antwort zu warten (#18424 von @aw1cks) – Hinweise, die dazu führen, dass der Agent weiterarbeitet, nachdem er fertig ist, kommen nicht mehr ein zweites Mal zurück, oft als Blocker, während der Agent das Problem behebt: Beraterüberprüfungen der früheren Antwort werden abgebrochen und der Berater überprüft stattdessen die Korrektur (#18735 von @H4vC) – Unter Windows löst die Shell des Bash-Tools überall MSYS-Laufwerkspfade (/c/Users/..., /mnt/c/...) auf, sodass die Ausführung von /c/.../tool.exe, cd /c/..., [ -f /c/... ] und < /c/... Laufwerk C: erreicht, wie sie es bereits für ls und andere integrierte Dienstprogramme getan haben

  • Unter Windows führen Befehlszeilen im Cmd-Stil wie dir | find /c /v "", sort /r, timeout /t 5 und whoami /all im Bash-Tool die Windows-Programme aus, für die sie geschrieben wurden, anstelle von Pis GNU-Stil find/sort/timeout/whoami (die /c als Laufwerk C: lesen und das gesamte Laufwerk durchlaufen können) – Beim Ändern oder Deaktivieren von PATH in der Shell des Bash-Tools werden jetzt wie bei Bash gespeicherte Befehlsspeicherorte vergessen, sodass ein Befehl nicht mehr aus einem Verzeichnis ausgeführt wird, das PATH verlassen hat – Ein langsamer oder überfluteter Collab-Gast beendet die Freigabe für den Raum nicht mehr: Der Gastgeber löscht den Rückstand dieses Gastes und bittet ihn, erneut beizutreten, Sitzungen, die größer als das Sendebudget sind, können beigetreten werden und Gastfragen, die niemand erhalten hat, werden als nicht verfügbar gewertet (#18629 von @iliaal)

@oh-my-pi/pi-tui

Geändert

– grep- und ast_grep-Ergebnisse ohne Übereinstimmungen werden als eine Zeile mit 0 matches in der Warnfarbe dargestellt, wodurch die separate No matches found-Zeile gelöscht wird (#18700 von @JustasMasiulis)

Behoben

– Gespeicherte und zurückgesetzte Nachrichten benennen das wöchentliche Limit von Claude Fable als „Claude Fable wöchentlich“ anstelle seiner Roh-ID (#18661 von @TheAifam5)

  • feat(coding-agent): Aufteilung der gespeicherten und zurückgesetzten automatischen Einlösung in 5-Stunden-, wöchentliche und Claude-Fable-Einstellungen von @TheAifam5 in https://github.com/can1357/oh-my-pi/pull/18661

oh-my-pi v18.18.7

@oh-my-pi/pi-ai

Added

  • LiteLLM usage adapter (@oh-my-pi/pi-ai/usage/litellm) reporting a gateway's key and user USD budgets (#17873 by @maykonmichel)
  • UsageApi.replaceConfiguredProviders registers configuration-sourced usage providers between runtime overrides and the built-in resolver, and UsageProvider.usesRequestKey makes aggregate usage probe only the key inference would send (#17873 by @maykonmichel)

Changed

  • Providers with a login-warning auth rule show their account risk before a new login and start it only after the user answers yes; any other answer or a cancel stores nothing, and their login-list entry is marked "(at your own risk)" (#18499)

Fixed

  • Claude Fable launch resets now report the Fable weekly limit they clear instead of an unknown window (#18661 by @TheAifam5)

@oh-my-pi/pi-catalog

Added

  • Added Muse Ember (muse-ember-1.0) on Meta Model API and Muse Code with the minimal–max reasoning effort ladder and its >200K long-context pricing
  • Added the login-warning "<text>" auth rule, which makes a new login accept the stated account risk first (#18499)

Changed

  • Resumed Google Antigravity behind a login warning instead of pausing it (#18499)

Fixed

  • Morph (api.morphllm.com) requests now send x-session-id, keeping a conversation on the worker that holds its prompt cache (#18704 by @wolfiesch)

@oh-my-pi/pi-coding-agent

Added

  • /usage and omp usage show LiteLLM key and user budgets for the built-in litellm provider and every models.yml provider with discovery.type: litellm, unless listed in disabledProviders (#17873 by @maykonmichel)
  • Extensions can ask the operator before an interactive quit, or cancel it, with session_before_shutdown; a further /exit or Ctrl+D skips the pending prompts and closes (#18424 by @aw1cks)

Changed

  • Saved-reset auto-redeem is set per window: codexResets.autoRedeem5h/autoRedeemWeekly and claudeResets.autoRedeem5h/autoRedeemWeekly/autoRedeemFable replace each provider's autoRedeem, whose value migrates into the 5h and weekly keys; a Claude Fable launch reset is governed by autoRedeemFable alone and spent only for a block that includes the Fable weekly cap, or before expiry when Fable usage is above zero (#18661 by @TheAifam5)
  • Sessions without a prompt UI (such as omp -p) no longer spend saved resets while auto-redeem is unset, even ones about to expire (#18661)
  • Google Antigravity is back in /login and omp login, marked "(at your own risk)": a new login first explains that Google may suspend accounts that sign in from third-party tools and continues only after you type yes; saved Antigravity logins work again (#18499)
  • On Windows, the bash tool's description tells the model it runs in an emulated bash environment, not cmd or PowerShell, so it writes bash instead of dir, %VAR% and other cmd syntax

Fixed

  • Extension prompts shown from session_before_* handlers no longer time out after 30 seconds while the operator is still answering (#18424 by @aw1cks)
  • A second exit request now skips pending worktree.onExit prompts and keeps those worktrees instead of waiting for an answer (#18424 by @aw1cks)
  • Advice that makes the agent keep working after it finished no longer comes back a second time, often as a blocker, while the agent is fixing it: advisor reviews of the earlier answer are cancelled and the advisor reviews the fix instead (#18735 by @H4vC)
  • On Windows, the bash tool's shell resolves MSYS drive paths (/c/Users/..., /mnt/c/...) everywhere, so running /c/.../tool.exe, cd /c/..., [ -f /c/... ] and < /c/... reach drive C: like they already did for ls and other built-in utilities
  • On Windows, cmd-style command lines such as dir | find /c /v "", sort /r, timeout /t 5 and whoami /all in the bash tool run the Windows programs they were written for, instead of pi's GNU-style find/sort/timeout/whoami (which read /c as drive C: and could walk the whole drive)
  • Changing or unsetting PATH in the bash tool's shell now forgets remembered command locations, as bash does, so a command no longer runs from a directory that has left PATH
  • One slow or flooding collab guest no longer ends sharing for the room: the host drops that guest's backlog and asks it to rejoin, sessions larger than the send budget can be joined, and guest questions nobody received settle as unavailable (#18629 by @iliaal)

@oh-my-pi/pi-tui

Changed

  • grep and ast_grep results with no matches render as one line with 0 matches in the warning color, dropping the separate No matches found row (#18700 by @JustasMasiulis)

Fixed

  • Saved-reset messages name the Claude Fable weekly limit as "Claude Fable weekly" instead of its raw id (#18661 by @TheAifam5)

What's Changed

  • feat(extensions): add an interactive pre-shutdown hook by @aw1cks in https://github.com/can1357/oh-my-pi/pull/18424
  • fix(tui): show grep's 0 matches in yellow on one line by @JustasMasiulis in https://github.com/can1357/oh-my-pi/pull/18700
  • fix(shell): resolve MSYS drive paths (/c/...) in the engine on Windows by @H4vC in https://github.com/can1357/oh-my-pi/pull/18703
  • fix(catalog): pin Morph conversations to one worker with x-session-id by @wolfiesch in https://github.com/can1357/oh-my-pi/pull/18704
  • fix(shell): run cmd-syntax command lines through the Windows programs pi's utilities shadow by @H4vC in https://github.com/can1357/oh-my-pi/pull/18711
  • feat(coding-agent): split saved-reset auto-redeem into 5h, weekly and Claude Fable settings by @TheAifam5 in https://github.com/can1357/oh-my-pi/pull/18661
  • fix(advisor): stop superseded reviews from re-raising advice the primary is already fixing by @H4vC in https://github.com/can1357/oh-my-pi/pull/18735
  • fix(collab): keep one guest from ending sharing for the room by @iliaal in https://github.com/can1357/oh-my-pi/pull/18629
  • feat(ai): report LiteLLM key/user budgets in /usage and omp usage by @maykonmichel in https://github.com/can1357/oh-my-pi/pull/17873
