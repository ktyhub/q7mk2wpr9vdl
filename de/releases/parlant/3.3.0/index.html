Parlant v3.3.0

[3.3.0] – 15.03.2026

Hinzugefügt

  • Fügen Sie Planer pro Agent über Server.create_agent(planner=...) hinzu, sodass jeder Agent eine benutzerdefinierte Planner-Implementierung verwenden kann
  • Akzeptieren Sie Tag als Ziel in depend_on(), exclude() und prioritize_over() sowohl auf Guideline als auch auf Tag, um Beziehungen zu ermöglichen, die auf alle Richtlinien abzielen, die ein benutzerdefiniertes Tag teilen – Fügen Sie die Methoden Tag.depend_on(), Tag.exclude() und Tag.prioritize_over() zum SDK hinzu und ermöglichen Sie tagbasierte Abhängigkeiten und Prioritätsbeziehungen mit Richtlinien und Reisen
  • Unterstützt benutzerdefiniertes TAG als Quelle für DEPENDENCY-Beziehungen im relationalen Resolver – Fügen Sie den Parameter tags zu create_guideline, create_observation und create_journey sowohl auf Agent als auch auf Journey hinzu, sodass benutzerdefinierte Tags zum Zeitpunkt der Erstellung an Entitäten angehängt werden können – Fügen Sie die Methode Tag.reevaluate_after() zu SDK hinzu, um tagbasierte Neubewertungsbeziehungen mit Tools zu ermöglichen
  • Tag-basierte Neubewertungsunterstützung in der Engine hinzufügen: Wenn ein Tool ausgelöst wird, werden jetzt alle Richtlinien mit einem Tag, das eine Neubewertungsbeziehung mit diesem Tool hat, neu bewertet – Fügen Sie staged_events zu GuidelineMatchingContext in SDK hinzu – Fügen Sie die Eigenschaft priority zu Richtlinien und Reisen hinzu, um eine prioritätsbasierte Filterung im relationalen Resolver zu ermöglichen
  • Fügen Sie vorübergehende Richtlinien hinzu (umbenannt in „vom Tool bereitgestellte Richtlinien“), sodass Tools dynamisch Verhaltensrichtlinien in den Kontext des Agenten einfügen können – Fügen Sie Agent.utter() zu SDK hinzu, um die Generierung programmgesteuerter Agent-Nachrichten mit transienten Richtlinien zu ermöglichen
  • Fügen Sie Customer.update() und CustomerMetadata zum SDK hinzu, damit Tools Kundennamen und Metadaten aktualisieren können – Fügen Sie Session.update(), SessionMetadata und SessionLabels zum SDK hinzu, damit Tools Sitzungseigenschaften, Metadaten und Beschriftungen aktualisieren können – Fügen Sie die Eigenschaften customer, agent, mode und title zur Klasse SDK Session hinzu
  • Fügen Sie Server.get_tag() zu SDK hinzu und unterstützen Sie die Suche durch id oder name – Fügen Sie über einen optionalen name-Abfrageparameter eine namensbasierte Filterung zu TagStore.list_tags() und dem Endpunkt GET /tags API hinzu – Erzwingen Sie die Eindeutigkeit von Tag-Namen in TagStore, was zu einem Fehler führt, wenn ein Tag mit einem doppelten Namen erstellt wird

Geändert

– Der erweiterte Denkindikator wurde in der Richtlinie zur wahrgenommenen Leistung optional gemacht

  • Ändern Sie reevaluate_after() in Tag und Guideline, um mehrere Werkzeuge zu akzeptieren (*tools) und geben Sie Sequence[Relationship] zurück
  • Ändern Sie den Feldtyp tags von Sequence[TagId] in Sequence[Tag] für Guideline, Journey, Capability, Term, Variable, Customer und Agent im SDK – Ändern Sie Tag.preamble(), um ein vollständiges Tag-Objekt anstelle eines TagId zurückzugeben
  • Aktualisieren Sie den MCP-Dienst und erhöhen Sie die Abhängigkeitsversionen, um Sicherheitslücken zu schließen

Veraltet

  • OpenAPI-Tooldienste sind jetzt veraltet; Bitte migrieren Sie zu den SDK-Tool-Services

Behoben

  • Deadlock beim Senden einer neuen Nachricht direkt nach einer Präambel behoben – Korrigieren Sie die transitive Filterung im relationalen Resolver für benutzerdefinierte Tag-Abhängigkeitsziele (Richtlinien, die von einem benutzerdefinierten Tag abhängig sind, werden jetzt korrekt deaktiviert, wenn ein getaggtes Mitglied herabgestuft wird) – Behebung des SSE read_event-Endpunkts, der nach dem ersten Streaming-Block bis zur vollständigen Fertigstellung blockiert – Behebung, dass Antwortanalyseprotokolle nicht immer die integrierte Benutzeroberfläche erreichen
  • Korrigieren Sie die Richtlinienformatierung in den vorgefertigten Antwort- und Streaming-Modi, wenn die Bedingung fehlt – Korrigieren Sie die Größe der kleinen AzureService-Texteinbettungsdimension – Behebung der Onnxruntime-Kompatibilität mit Python 3.10 und Transformers 5.x-Typänderungen
  • Sofortige Klärung der Absicht des Agenten – Die eingebettete LRU-Cache-Räumung wurde behoben, wodurch der Längenindex beschädigt wurde, wenn Einträge dieselbe Textlänge haben – Behebung, dass LiteLLMEmbedder nicht über den Lagom-Container aufgelöst werden konnte, wenn LITELLM_EMBEDDING_MODEL_NAME festgelegt ist – Behebung eines Problems, bei dem nicht-konsequente Werkzeugaufrufe abgelehnt werden, wenn optionale Parameter fehlen

Entfernt

– Entfernen Sie veraltete parlant-test-Einstiegspunkt- und Test-Framework-Dokumentation aus der README-Datei

parlant v3.3.0

[3.3.0] - 2026-03-15

Added

  • Add per-agent planners via Server.create_agent(planner=...), allowing each agent to use a custom Planner implementation
  • Accept Tag as a target in depend_on(), exclude(), and prioritize_over() on both Guideline and Tag, enabling relationships that target all guidelines sharing a custom tag
  • Add Tag.depend_on(), Tag.exclude(), and Tag.prioritize_over() methods to the SDK, enabling tag-based dependency and priority relationships with guidelines and journeys
  • Support custom TAG as source for DEPENDENCY relationships in the relational resolver
  • Add tags parameter to create_guideline, create_observation, and create_journey on both Agent and Journey, allowing custom tags to be attached to entities at creation time
  • Add Tag.reevaluate_after() method to the SDK, enabling tag-based reevaluation relationships with tools
  • Add tag-based reevaluation support in the engine: when a tool fires, all guidelines carrying a tag that has a reevaluation relationship with that tool are now re-evaluated
  • Add staged_events to GuidelineMatchingContext in SDK
  • Add priority property to guidelines and journeys for priority-based filtering in the relational resolver
  • Add transient guidelines (renamed from tool-provided guidelines), allowing tools to dynamically inject behavioral guidelines into the agent's context
  • Add Agent.utter() to the SDK, enabling programmatic agent message generation with transient guidelines
  • Add Customer.update() and CustomerMetadata to the SDK, allowing tools to update customer name and metadata
  • Add Session.update(), SessionMetadata, and SessionLabels to the SDK, allowing tools to update session properties, metadata, and labels
  • Add customer, agent, mode, and title properties to SDK Session class
  • Add Server.get_tag() to the SDK, supporting lookup by either id or name
  • Add name-based filtering to TagStore.list_tags() and the GET /tags API endpoint via an optional name query parameter
  • Enforce tag name uniqueness in TagStore, raising an error when creating a tag with a duplicate name

Changed

  • Made extended thinking indicator optional in perceived performance policy
  • Change reevaluate_after() on Tag and Guideline to accept multiple tools (*tools) and return Sequence[Relationship]
  • Change tags field type from Sequence[TagId] to Sequence[Tag] on Guideline, Journey, Capability, Term, Variable, Customer, and Agent in the SDK
  • Change Tag.preamble() to return a full Tag object instead of a TagId
  • Upgrade MCP service and bump dependency versions to resolve security vulnerabilities

Deprecated

  • OpenAPI tool services are now deprecated; please migrate to SDK tool services

Fixed

  • Fix deadlock when sending a new message right after a preamble
  • Fix transitive filtering in relational resolver for custom tag dependency targets (guidelines depending on a custom tag are now correctly deactivated when a tagged member is deprioritized)
  • Fix SSE read_event endpoint stalling after first streaming chunk until full completion
  • Fix response analysis logs not always reaching the integrated UI
  • Fix guideline formatting in canned response and streaming modes when condition is absent
  • Fix AzureService small text embedding dimension size
  • Fix onnxruntime compatibility with Python 3.10 and transformers 5.x type changes
  • Fix agent intention proposer prompt clarification
  • Fix embedding LRU cache eviction corrupting the length index when entries share the same text length
  • Fix LiteLLMEmbedder failing to resolve via lagom container when LITELLM_EMBEDDING_MODEL_NAME is set
  • Fix non-consequential tool calls being rejected when optional parameters are missing

Removed

  • Remove stale parlant-test entry point and testing framework documentation from README
