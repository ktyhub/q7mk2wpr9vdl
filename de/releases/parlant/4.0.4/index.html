Parlant v4.0.4

[4.0.4] – 08.11.2026

Hinzugefügt

  • Agent.queue_response() kombiniert Hintergrund-Follow-ups mit anderen fertigen Ergebnissen oder einem Kundenkontakt. Übergeben Sie after=coroutine, um die Arbeit zu registrieren, bevor sie beginnt. nur die verzögerte Antwort wartet auf den registrierten Stapel. Die Koordination erfolgt in einem Prozess und erfordert Sitzungsrouting-Affinität. Ausstehende Arbeiten werden nach einem Neustart nicht wiederhergestellt. Antworten in der Warteschlange tolerieren Verlaufsänderungen und beenden unterbrochene Streams, ohne veralteten Text anzuhängen.

Geändert

  • Wenn Tool-Präambeln empfohlen werden, schreibt der Agent sie und die darauf folgenden Fortschrittsaktualisierungen in der Sprache des Kunden.
  • Agenten erkennen wiederkehrende Informationslücken, wenn verschiedene Fragen nicht beantwortet werden können, ohne eine neue Frage als eine bereits beantwortete zu behandeln.
  • Agenten fragen, welchen Datensatz oder welche Anfrage der Kunde meint, wenn er nicht eindeutig ist, und welche der mehreren noch nicht abgeschlossenen Anfragen zuerst bearbeitet werden sollen, bevor sie Aufgabendetails erfassen.

Behoben

  • Gemini-Gespräche können nach dem Löschen des Verlaufs mit Hintergrundergebnissen fortgesetzt werden, ohne dass ein Fehler bei der Reihenfolge der ungültigen Tool-Antworten auftritt. – Das Parlant-Dashboard zeigt jetzt die Argumentation Ihres Agenten unter Agentenaktivität an, wenn der Agent seine Nachrichten streamt, die Standardeinstellung für create_agent. Die Begründung jedes Schritts wird jetzt als Loop.reasoning-Trace-Ereignis aufgezeichnet. Zuvor erreichte es das Dashboard nur als Protokollzeile, die das Dashboard nur von Agenten im Blockausgabemodus las. parlant[anthropic] arbeitet mit dem aktuellen Anthropic SDK. Bei einer Neuinstallation wurde anthropic 1.0 oder höher ausgewählt, dessen client Parlants Timeout-Anfrage ablehnte, sodass kein Claude-Modell gestartet werden konnte. Das Extra erfordert jetzt anthropic>=1.0.0; Wenn Ihr Projekt eine anthropische Obergrenze unter 1.0 hat, um dies zu umgehen, lassen Sie die Obergrenze fallen.
  • Das Chat-Widget zeigt eine von rechts nach links geschriebene Antwort, z. B. Hebräisch, von rechts nach links an, selbst wenn es mit einem englischen Wort, einer URL oder einem Code geöffnet wird. Früher wurde die Richtung vom ersten Buchstaben übernommen, sodass eine solche Antwort von links nach rechts mit der Interpunktion auf der falschen Seite gelesen wurde. Jeder Absatz, das Meldungsfeld und die Vorschlagsschaltflächen folgen nun dem Skript, in dem sich die meisten Wörter befinden.

[4.0.3] – 05.11.2026

Geändert

  • Parlant-Dashboard-Befehle teilen dem Parlant-Dashboard jetzt mit, welcher Befehl die jeweilige Anfrage gesendet hat. Jede Anfrage trägt User-Agent: parlant-cli/<version>, den Namen des Befehls im X-Parlant-CLI-Command (z. B. Parlant-Dashboard-Sitzungsliste, niemals seine Argumente oder Optionswerte) und eine X-Parlant-CLI-Invocation-ID, die von jeder Anfrage aus einem Lauf geteilt wird. Das Dashboard verwendet sie, um Ihre CLI-Aktivität als die von Ihnen ausgeführten Befehle anzuzeigen.

parlant v4.0.4

[4.0.4] - 2026-11-08

Added

  • Agent.queue_response() combines background follow-ups with other ready results or a customer turn. Pass after=coroutine to register work before it starts; only the deferred reply waits for the registered batch. Coordination lives in one process and requires session routing affinity; pending work is not recovered after a restart. Queued replies tolerate history edits and terminate interrupted streams without appending stale text.

Changed

  • When tool preambles are encouraged, the agent writes them, and the progress updates that follow, in the customer's language.
  • Agents acknowledge recurring information gaps when different questions cannot be answered, without treating a new question as one already answered.
  • Agents ask which record or request the customer means when it's ambiguous, and which of several unfinished requests to handle first, before collecting task details.

Fixed

  • Gemini conversations can resume from background results after history is cleared, without an invalid tool-response ordering error.
  • The Parlant dashboard now shows your agent's reasoning under Agent activity when the agent streams its messages, the default for create_agent. Each step's reasoning is now recorded as a loop.reasoning trace event. Before, it reached the dashboard only as a log line, which the dashboard read only from agents in block output mode. parlant[anthropic] works with the current Anthropic SDK. A fresh install picked anthropic 1.0 or later, whose client refused Parlant's request timeout, so no Claude model could start. The extra now requires anthropic>=1.0.0; if your project capped anthropic below 1.0 to work around this, drop the cap.
  • The chat widget lays out a right-to-left reply, such as Hebrew, right to left even when it opens with an English word, a URL or code. It used to take the direction from the first letter, so such a reply read left to right with its punctuation on the wrong side. Each paragraph, the message box and the suggestion buttons now follow the script most of their words are in.

[4.0.3] - 2026-11-05

Changed

  • parlant dashboard commands now tell the Parlant dashboard which command sent each request. Every request carries User-Agent: parlant-cli/<version>, the command's name in X-Parlant-CLI-Command (for example parlant dashboard session list, never its arguments or option values), and an X-Parlant-CLI-Invocation id shared by every request from one run. The dashboard uses them to show your CLI activity as the commands you ran.
