vault v2.0.3

Patch Veröffentlicht17. Juni 2026 Quellehashicorp/vault Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Tresor v2.0.3

SICHERHEIT:

  • auth/radius: Der Schalter „case_insensitive_names“ wurde hinzugefügt, um Benutzernamenkollisionen zu verhindern und die Benutzerbehandlung ohne Berücksichtigung der Groß-/Kleinschreibung zu ermöglichen.
  • core/acl: Korrektur der LIST-ACL-Umgehung, bei der eine Anfrage mit abschließendem Schrägstrich eine spezifischere Ablehnungsregel überspringen konnte.
  • Kern: Verwenden Sie einen Wiederherstellungs-Token-Vergleich mit konstanter Zeit
  • Secrets/Spiffe (Enterprise): Stellen Sie sicher, dass Vorlagenwerte ordnungsgemäß maskiert sind.
  • transform (enterprise): Fügen Sie entsprechende datenbankspezifische Anführungszeichen und escaping hinzu. ÄNDERUNGEN:
  • auth/cf: Plugin auf v0.23.1 aktualisieren
  • core/acl: LIST-Anfragen mit einem abschließenden Schrägstrich berücksichtigen nun korrekt spezifischere Ablehnungsrichtlinien. Zuvor konnte eine Ablehnung für path "kv/*" { deny } für LIST kv/private/ umgangen werden, wenn auch eine umfassendere Zulassung path "kv/*" vorhanden war. Richtlinien, die sich auf das vorherige (falsche) Verhalten stützen, können nun abgelehnt werden.
  • core: Vault leitet jetzt nicht kanonisierte Pfade (die /./, /../ oder // enthalten) auf einen bereinigten Pfad um, anstatt diese Anfragen abzulehnen
  • Secrets/Azure: Plugin auf v0.26.5+ent aktualisieren EIGENSCHAFTEN:
  • KI-Agent-Unterstützung (Beta/Enterprise): Fügt Beta-Unterstützung für erstklassige KI-Agenten hinzu. Fügt hinzu eine Agentenregistrierung zum Registrieren von Agenten und fügt Unterstützung für die Verwendung von Vault als OAuth-Ressourcenserver hinzu für registrierte Agentenunternehmen. Wenn es konfiguriert ist, können OAuth 2.0-JWTs zur direkten Autorisierung verwendet werden Anfragen an Vault, ohne dass ein Vault-Token erforderlich ist. VERBESSERUNGEN:
  • Verbrauchsabrechnung: Fügen Sie einen neuen sys/billing/config-Endpunkt hinzu, um die Konfiguration der Aufbewahrung von Abrechnungsdaten zu ermöglichen (mindestens 13 Monate, höchstens 6 Jahre).
  • core (Enterprise): Machen Sie die Deadlock-Erkennung in Sealwrap konfigurierbar, indem Sie „sealwrap“ zur vorhandenen Konfiguration „detekt_deadlocks“ hinzufügen.
  • Identity/scim (Enterprise): Aktualisieren Sie PATCH-Vorgänge auf scim/v2/Users, um mehrere Änderungen im selben Patch-Aufruf zu ermöglichen, unterstützen Sie Patch-Vorgänge für Benutzermetadaten und -namen zusätzlich zum aktiven Status und ermöglichen Sie die Angabe des path-Werts in Patch-Vorgängen
  • sdk/helper/keysutil: Die GetPolicy-Funktion des Sperrmanagers gibt jetzt immer eine gesperrte Richtlinie zurück, auch wenn die Zwischenspeicherung aktiviert ist aktiviert. Die PolicyRequest-Struktur verfügt über ein neues Feld, das angibt, ob der Aufrufer eine Schreibsperre für die Richtlinie benötigt.
  • ui (Unternehmen): Migrieren Sie Diagramme von Lineal zu Carbon Charts in der Client-Nutzungsübersicht und im Vault-Nutzungs-Dashboard. FEHLERBEHEBUNGEN:
  • core/rotationMgr: Speicherrouting für lokale Mounts in Namespaces korrigieren, um Metadatenreplikation zu verhindern und DSGVO-Konformität sicherzustellen.
  • kmip (Enterprise): Behebung eines Fehlers, der verhindert, dass die alte Zertifizierungsstelle auf einem benannten Listener funktioniert.
  • Secret-Sync (Unternehmen): Behebung der Persistenz der GCP Secret Manager-Replikationsrichtlinie bei Vault-Neustarts.
  • Secrets/Datenbank/mssql: Deregistrieren Sie veraltete TLS-Konfigurationen, wenn sich die TLS-Einstellungen der MySQL-Verbindung ändern oder die Verbindung geschlossen wird, wodurch verhindert wird, dass sich Pools beibehaltener Zertifikate ansammeln.
  • Secrets/PKI: Korrigiert die Ausstellung von PKI-Zertifikaten nicht nach Ablauf der Zeit, um die maximale TTL einzuhalten.
  • Secrets/Transit: Unterstützung für verwaltete Schlüssel zum Transit-Rewrap-Endpunkt hinzufügen.
  • Lagerung/Floß: performance_multiplier-Werte kleiner oder gleich Null ablehnen

Englisches Original / English original

vault v2.0.3

SECURITY:

  • auth/radius: Added case_insensitive_names toggle to prevent username collisions and enable case-insensitive user handling.
  • core/acl: Fix LIST ACL bypass where a trailing-slash request could skip a more-specific deny rule.
  • core: Use constant-time recovery token comparison
  • secrets/spiffe (enterprise): Ensure template values are properly escaped.
  • transform (enterprise): Add appropriate db specific quoting and escaping.

CHANGES:

  • auth/cf: Update plugin to v0.23.1
  • core/acl: LIST requests with a trailing slash now correctly respect more-specific deny policies. Previously, a deny on path "kv/*" { deny } could be bypassed for LIST kv/private/ if a broader allow path "kv/*" also existed. Policies relying on the previous (incorrect) behavior may now be denied.
  • core: Vault will now redirect non-canonicalized paths (containing /./, /../, or //) to a cleaned path, instead of rejecting these requests
  • secrets/azure: Update plugin to v0.26.5+ent

FEATURES:

  • AI Agent Support (Beta/Enterprise): Adds beta support for first-class AI agents. Adds an Agent Registry to register agents, and adds support for using Vault as an OAuth resource server for registered agent entities. When configured, allows OAuth 2.0 JWTs to be used to directly authorize requests to Vault, without needing a Vault token.

IMPROVEMENTS:

  • consumption-billing: Add a new sys/billing/config endpoint to allow configuration of billing data retention (min 13 months, max 6 years).
  • core (Enterprise): Make deadlock detection in sealwrap configurable by adding "sealwrap" to existing configuration detect_deadlocks.
  • identity/scim (enterprise): Update PATCH operations on scim/v2/Users to allow multiple modifications in the same patch call, support for patch operations on user metadata and name in addition to active status, and allow specifying path value in patch operations
  • sdk/helper/keysutil: The lock manager's GetPolicy function now always returns a locked Policy, even when caching is enabled. The PolicyRequest struct has a new field to indicate whether the caller requires a write lock on the policy.
  • ui (enterprise): Migrate charts from Lineal to Carbon Charts in the Client usage overview and Vault usage dashboard.

BUG FIXES:

  • core/rotationMgr: Fix storage routing for local mounts in namespaces to prevent metadata replication and ensure GDPR compliance.
  • kmip (enterprise): Fix a bug that prevents the legacy CA from working on a named listener.
  • secret-sync (enterprise): Fix GCP Secret Manager replication policy persistence across Vault restarts.
  • secrets/database/mssql: Deregister stale TLS configurations when MySQL connection TLS settings change or the connection is closed, preventing retained certificate pools from accumulating.
  • secrets/pki: Fix PKI certificate issuance not_after time to respect max TTL.
  • secrets/transit: Add managed key support to Transit rewrap endpoint.
  • storage/raft: reject performance_multiplier values less than or equal to zero
