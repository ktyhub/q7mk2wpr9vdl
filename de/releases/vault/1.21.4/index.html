Tresor v1.21.4

SICHERHEIT:

  • Aktualisieren Sie cloudflare/circl auf v1.6.3, um CVE-2026-1229 zu beheben
  • Aktualisieren Sie filippo.io/edwards25519 auf v1.1.1, um GO-2026-4503 zu beheben
  • vault/sdk: Aktualisieren Sie cloudflare/circl auf v1.6.3, um CVE-2026-1229 zu beheben
  • vault/sdk: Aktualisieren Sie go.opentelemetry.io/otel/sdk auf v1.40.0, um GO-2026-4394 zu beheben ÄNDERUNGEN:
  • Kern: Bump Go-Version auf 1.25.7
  • mfa/duo: Aktualisieren Sie duo_api_golang client auf 0.2.0, um die neuen Duo-Zertifizierungsstellen einzuschließen
  • ui: Möglichkeit zum Massenlöschen von Secrets-Engines aus der Listenansicht entfernt. VERBESSERUNGEN:
  • core/seal: Erweitern Sie sys/seal-backend-status, um mehr Informationen über Seal-Backends bereitzustellen.
  • Secrets/kmip (Enterprise): Befolgen Sie die konfigurierte best_effort_wal_wait_duration, wenn Sie kmip-Anfragen weiterleiten.
  • Secrets/PKI (Enterprise): Gibt die POSTPKIOperation-Funktion innerhalb des SCEP-GetCACaps-Endpunkts zurück, um eine bessere Legacy-client-Unterstützung zu gewährleisten. FEHLERBEHEBUNGEN:
  • core (enterprise): Puffern Sie den POST-Body auf Binärpfaden, um ein erneutes Lesen bei nicht-logischen Weiterleitungsversuchen zu ermöglichen. Behebt ein Problem bei der Ausstellung von SCEP-, EST- und CMPv2-Zertifikaten mit langsamer Replikation von Entitäten
  • core/identity (enterprise): Übermäßige Protokollierung beim Aktualisieren vorhandener Aliase behoben
  • core/managed-keys (enterprise): client-Anmeldeinformationen sollten nicht erforderlich sein, wenn Azure Managed Identities in verwalteten Schlüsseln verwendet wird.
  • Plugins (Unternehmen): Fehler behoben, bei dem Anfragen an externe Plugins, die den Speicher ändern, den X-Vault-Index-Antwortheader nicht ausfüllten.
  • Geheimnisse (pki): Ermöglicht die Ausstellung von Zertifikaten ohne Verwendung des server_flag-Schlüssels aus den Protokollen SCEP, EST und CMPV2.
  • Secrets/pki (Enterprise): Beheben Sie Cache-Ungültigmachungsprobleme mit CMPv2 auf Performance-Standby-Knoten.
  • Secrets/PKI (Enterprise): Beheben Sie Probleme bei der Verwendung von SCEP auf Leistungs-Standby-Knoten, die aufgrund von Konfigurationsungültigkeitsproblemen zusammen mit Fehlern beim Schreiben in den Speicher ausfallen
  • Secrets/PKI (Enterprise): Ändern Sie den SCEP-GetCACaps-Endpunkt, um die konfigurierten Verschlüsselungs- und Digest-Algorithmen dynamisch widerzuspiegeln.
  • Secrets/pki: Der Root/Sign-Intermediate-Endpunkt sollte nicht fehlschlagen, wenn ein CSR mit einer Basiseinschränkungserweiterung bereitgestellt wird, die isCa enthält und auf „true“ gesetzt ist
  • Secrets/pki: Erlaubt DNS-Namen im Glob-Stil in alt_names.

Englisches Original / English original

vault v1.21.4

SECURITY:

  • Upgrade cloudflare/circl to v1.6.3 to resolve CVE-2026-1229
  • Upgrade filippo.io/edwards25519 to v1.1.1 to resolve GO-2026-4503
  • vault/sdk: Upgrade cloudflare/circl to v1.6.3 to resolve CVE-2026-1229
  • vault/sdk: Upgrade go.opentelemetry.io/otel/sdk to v1.40.0 to resolve GO-2026-4394

CHANGES:

  • core: Bump Go version to 1.25.7
  • mfa/duo: Upgrade duo_api_golang client to 0.2.0 to include the new Duo certificate authorities
  • ui: Remove ability to bulk delete secrets engines from the list view.

IMPROVEMENTS:

  • core/seal: Enhance sys/seal-backend-status to provide more information about seal backends.
  • secrets/kmip (Enterprise): Obey configured best_effort_wal_wait_duration when forwarding kmip requests.
  • secrets/pki (enterprise): Return the POSTPKIOperation capability within SCEP GetCACaps endpoint for better legacy client support.

BUG FIXES:

  • core (enterprise): Buffer the POST body on binary paths to allow re-reading on non-logical forwarding attempts. Addresses an issue for SCEP, EST and CMPv2 certificate issuances with slow replication of entities
  • core/identity (enterprise): Fix excessive logging when updating existing aliases
  • core/managed-keys (enterprise): client credentials should not be required when using Azure Managed Identities in managed keys.
  • plugins (enterprise): Fix bug where requests to external plugins that modify storage weren't populating the X-Vault-Index response header.
  • secrets (pki): Allow issuance of certificates without the server_flag key usage from SCEP, EST and CMPV2 protocols.
  • secrets/pki (enterprise): Address cache invalidation issues with CMPv2 on performance standby nodes.
  • secrets/pki (enterprise): Address issues using SCEP on performance standby nodes failing due to configuration invalidation issues along with errors writing to storage
  • secrets/pki (enterprise): Modify the SCEP GetCACaps endpoint to dynamically reflect the configured encryption and digest algorithms.
  • secrets/pki: The root/sign-intermediate endpoint should not fail when provided a CSR with a basic constraint extension containing isCa set to true
  • secrets/pki: allow glob-style DNS names in alt_names.
