Helfer v0.84.0

Modellunterstützung und Anbieteraktualisierungen

  • Unterstützung für neue Claude-Modelle hinzugefügt, einschließlich der Sonnet 4- und Opus 4-Serien (z. B. claude-sonnet-4-20250514, claude-opus-4-20250514) bei verschiedenen Anbietern. Die Standardaliase sonnet und opus wurden auf diese neueren Versionen aktualisiert Versionen.
  • Unterstützung für das vertex_ai/gemini-2.5-flash-preview-05-20-Modell hinzugefügt. – Aktualisierte Standard-OpenRouter-Modelle während des Onboardings auf deepseek/deepseek-r1:free für das kostenlose Kontingent und anthropic/claude-sonnet-4 für kostenpflichtige Stufen.
  • GitHub-Copilot-Token automatisch aktualisieren, wenn sie als OpenAI-API-Schlüssel verwendet werden, von Lih Chen.

Verbesserungen der Kernfunktionalität

– Es wurde ein Problem behoben, bei dem Dateien, die explizit über die Befehlszeile hinzugefügt wurden, nicht korrekt ignoriert wurden, wenn sie in .gitignore aufgeführt waren. – Verbesserte automatische Commit-Nachrichten durch Bereitstellung von mehr Kontext während ihrer Generierung, von Wangboxue.

  • Die Berechnung der OpenRouter-Token-Kosten wurde korrigiert, um die Genauigkeit zu verbessern.

Verbesserungen der Lebensqualität

– Verbesserte Verarbeitung von Metadaten des OpenRouter-Modells durch Einführung eines lokalen Caches, wodurch Zuverlässigkeit und Leistung erhöht werden.

  • Shell-Tab-Vervollständigung für Dateipfadargumente (von Saviour) und für die Optionen --edit-format/--editor-edit-format hinzugefügt. – Der Befehl /settings zeigt jetzt detaillierte Metadaten für aktive Haupt-, Editor- und schwache Modelle an.
  • Verbesserte Erkennung der Benutzersprache durch korrekte Normalisierung von Sprachcodes mit Bindestrichen (z. B. en-US zu en) und Verbesserung der Validierung der Gebietsschemaergebnisse. – Der Helfer konnte den LLM nicht anweisen, in „C“ oder „POSIX“ zu antworten, wenn diese als Systemgebietsschema erkannt wurden. – Beim Generieren von Commit-Nachrichten wurde ein Spinner mit dem Modellnamen angezeigt. – configargparse wurde auf 1.7.1 verschoben, als 1.7 gezogen wurde.

Englisches Original / English original

aider v0.84.0

Highlights

  • Claude 4 becomes the default sonnet/opus — The sonnet and opus aliases now resolve to the 20250514 Sonnet 4 / Opus 4 builds across providers. Anything invoking these aliases implicitly gets newer (and potentially different-behavior) models, so teams that need reproducible output should pin explicit model IDs rather than rely on the aliases.
  • OpenRouter onboarding defaults reshuffled — New users on the free tier now land on deepseek/deepseek-r1:free, while paid tiers default to anthropic/claude-sonnet-4. This changes the first-run experience and cost profile; anyone scripting onboarding or assuming the old defaults should revisit their setup.
  • Copilot tokens self-refresh — When GitHub Copilot credentials are supplied as an OpenAI API key, aider now refreshes the token automatically (Lih Chen). That removes a recurring manual rotation failure mode for Copilot-based setups.
  • .gitignore now overrides explicit CLI paths — Files passed on the command line that are also listed in .gitignore are correctly ignored. This keeps ignored secrets and build artifacts out of model context, but it is a behavioral change: workflows that intentionally used explicit paths to force-include ignored files will need another approach.
  • OpenRouter reliability and cost accuracy — A local metadata cache reduces dependence on live model-metadata fetches, and token cost calculation was corrected. Together these make model selection snappier and budget/cost reporting more trustworthy — watch for changes in reported spend if you tracked costs before.
  • Workflow polish — Shell tab completion for file paths and --edit-format/--editor-edit-format, richer /settings metadata for main/editor/weak models, normalized hyphenated locale codes (en-US → en), and a guard against telling the LLM to answer in C/POSIX. Also note configargparse bumped to 1.7.1 because 1.7 was pulled from distribution.
  • Breaking changes — None in this release.

Model support & provider updates

  • Added support for new Claude models including the Sonnet 4 and Opus 4 series (e.g., claude-sonnet-4-20250514, claude-opus-4-20250514) across various providers. The default sonnet and opus aliases were updated to these newer versions.
  • Added support for the vertex_ai/gemini-2.5-flash-preview-05-20 model.
  • Updated default OpenRouter models during onboarding to deepseek/deepseek-r1:free for the free tier and anthropic/claude-sonnet-4 for paid tiers.
  • Automatically refresh GitHub Copilot tokens when used as OpenAI API keys, by Lih Chen.

Core functionality improvements

  • Fixed an issue where files explicitly added via the command line were not correctly ignored if listed in .gitignore.
  • Improved automatic commit messages by providing more context during their generation, by wangboxue.
  • Fixed OpenRouter token cost calculation for improved accuracy.

Quality of life improvements

  • Improved OpenRouter model metadata handling by introducing a local cache, increasing reliability and performance.
  • Added shell tab completion for file path arguments (by saviour) and for --edit-format/--editor-edit-format options.
  • The /settings command now displays detailed metadata for active main, editor, and weak models.
  • Improved user language detection by correctly normalizing hyphenated language codes (e.g., en-US to en) and enhancing the validation of locale results.
  • Prevented aider from instructing the LLM to reply in 'C' or 'POSIX' when these are detected as the system locale.
  • Displayed a spinner with the model name when generating commit messages.
  • Bumped configargparse to 1.7.1 as 1.7 was pulled.
