Pulsar v2.7.4

Sicherheit

– Aktualisieren Sie log4j auf 2.17.0 – CVE-2021-45105 #13392 – Upgrade von commons-compress auf 1.21 – CVE-2021-35515, CVE-2021-35516, CVE-2021-35517 und CVE-2021-36090 #11345

Makler

– Fix DispatchRateLimiter wird nicht wirksam #8611 – Fix „set-publish-rate“ bei Verwendung von precisionTopicPublishRateLimiterEnable=true #10384 – Behebung, dass die Aufbewahrungsrichtlinie in der Themenrichtlinie nicht funktioniert #11021 – Behebung, dass GetTopicsOfNamespace mit dem binären Suchdienst die Authentifizierung nicht überprüft #11172 – Beibehaltung von Schlüsseln bei der Komprimierung behoben #11287 – Behebung eines Problems mit dem Namen eines partitionierten Themas zum Abrufen der Richtlinie #11294 – NPE beim Entladen eines persistenten, partitionierten Themas behoben #11310 – RateLimiter-Konstruktoren entfernen und durch Builder-Verwendung ersetzen #11599 – Backoff für Einstellung zum Abrufen von Themenrichtlinien hinzugefügt #11574 – Korrektur der Decodierungskomprimierung von ManagedLedgerInfo-Daten #11569 – Einige Themenrichtlinienoperationen ohne Backoff behoben #11560 – Datenverlust behoben, wenn die früheste Position zum Abonnieren eines Themas verwendet wurde #11547 – Korrigieren Sie das Löschen des Schemas, wenn Sie ein Thema mit dem Löschschema löschen #11501 – Erstellen Sie kein Systemthema für den Heartbeat-Namespace #11499

  • Verwaltete Ledger-Informationen komprimieren #11490 – Backoff für Einstellung zum Abrufen von Themenrichtlinien hinzugefügt #11487
  • Das Lösen einer präzisen Ratenbegrenzung wird nicht wirksam #11446 – Behebung des direkten Speicherverlusts bei replizierten Abonnements #11396 – Schließen Sie den Replikator und die Replikation client, wenn Sie den Cluster löschen #11390 – Machen Sie das Lesehandle ungültig, nachdem alle Cursor verbraucht sind #11389 – NPE beim Entladen eines persistenten, partitionierten Themas behoben #11386 – Beibehaltung von Schlüsseln bei der Komprimierung behoben #11384 – Deaktivieren Sie die Replikation des Systemthemas über Cluster hinweg #11376
  • Parallel Precise Publish Rate Limiting Fix #11372 – Pulsar Admin List Subscription listet nur Abonnements auf, die für Partition 0 erstellt wurden, wenn partitionsspezifische Abonnements erstellt werden #11355 – Inkonsistentes Verhalten für den Namespace-Bundle-Cache behoben #11346 – Fehler bei der Aktualisierung der Ledger-Liste aufgrund einer Nichtübereinstimmung der Znode-Versionen behoben, Ledger wurde nicht gelöscht #12015
  • Positionsinformationen drucken, wenn die nächste gültige Position nicht gefunden werden kann #11969 – Das Lesen der Daten anderer Themen in der ManagedLedger-Ebene verbieten #11913 – Behebung eines Problems mit der Verwendung eines partitionierten Themennamens zum Abrufen von Themenrichtlinien #11897 – Verfeinern Sie das Warnungsprotokoll für Backlog-Kontingentrichtlinien auf Themenebene #11863 – Wenn der Produzent den Produzenten beschäftigt, wird der vorhandene Produzent aus der Liste entfernt #11804 – Behandeln Sie NPE und Speicherverlust, wenn nicht der gesamte Schlüsselbereich durch aktive Verbraucher abgedeckt wird #11749 – Rufen Sie .release() auf, wenn Sie einen Eintrag verwerfen, um einen direkten Speicherverlust zu verhindern #11748 – Das Thema wurde im abgeschirmten Zustand behoben und kann nicht wiederhergestellt werden #11737 – Unterstützung für die Deaktivierung von Nicht-TLS-Dienstports #11724 – Behebung des Fehlers, Thema kann nicht aktualisiert werden, wenn der Aktualisierungsthemaname in einem vorhandenen Thema als Teil enthalten ist #11686 – Behebung, dass Pulsar beim Auslösen einer InterceptException nicht auf Fehlermeldungen reagierte #11650 – Vermeiden Sie redundante Aufrufe zum Abrufen der Offload-Richtlinien vom Offloader #11629
  • ManagedLedger-Ledger-Besitzprüfung optimieren #13222 – Verwenden Sie das Failed OpAddEntry-Objekt nicht wieder, was zu einer Zeitüberschreitung beim Entladen des Bundles geführt hat #12993 – Behebung eines Problems, bei dem der Produzent fälschlicherweise aus der Produzentenkarte des Themas entfernt wurde #12846 – Konfiguration der Schemakompatibilitätsrichtlinie für Systemthemen zulassen #12598 – Bereinigen bereits gelöschter Namespace-Themen #12583 – OpAddEntry nach der Statusprüfung zu pendingAddEntries hinzufügen #12570 – Geplante Aufgaben beim Löschen von ManagedLedgerImpl abbrechen #12565 – NPE bei OpAddEntry, während ManagedLedger geschlossen wird #12364 – Vermeiden Sie das potenzielle Blockieren von Aufrufen von Metadaten in kritischen Threads #12340 – Behebung, die nach dem Recyclingproblem in OpAddEntry verwendet wurde #12103 – Optimieren Sie die Speichernutzung von Cache Eviction #12045 – Behebung eines falschen Schlüssel-Hash-Selektors, der für neue Verbraucher verwendet wurde, nachdem die Verbindung aller vorherigen Verbraucher getrennt wurde #12035 – Nur auth_errors sollten auf Fehlerebene protokolliert werden #9325

Abhängigkeits-Upgrade

– Boost::System-Laufzeitabhängigkeit entfernen #9498

  • Upgrade von Jetty auf 9.4.43.v20210629 #11660 – maven.restlet.org-Repository hinzufügen #13248
  • Upgrade der ZooKeeper-Version auf 3.5.9 #12981 – Pulsar-Dashboard aus dem Veröffentlichungsprozess von Bildern entfernen #12534 – Zurück zur Verwendung von Java 8 für docker-Bilder #12357
  • Upgrade von TestContainern auf 1.15.1 #9120

Client

– [Java] Refactor versucht, gemeinsame Logik wiederzuverwenden #9670

  • [Java] Partitionierte Themennachrichten in verschiedenen Listener-Threads verarbeiten #10017
  • [Java] Fix Der Consumer-Listener berücksichtigt die Größe der Empfängerwarteschlange nicht #11455
  • [Java] Fügen Sie einen optionalen Parameterbereich für pulsar oauth2 client hinzu #11931
  • [Java] Korrektur der Suche auf BatchIndex-Ebene, Empfang doppelter Nachrichten #11826 – [Java] Race-Bedingung bei Multi-Topic-Consumer behoben #11764
  • [Java] Verbraucherreferenz aus PulsarClient bei Abonnementfehler entfernen #11758
  • [Java] Fehler beim Blockieren für immer in Consumer.batchReceive behoben #11691
  • [Java] CloseProducer bei Zeitüberschreitung senden #13161
  • [Java] Ungültigen Aufruf von Thread.currentThread().interrupt() entfernen #12652 – [Python] Korrigieren Sie Felder, die das erforderliche Schlüsselargument ignorieren #11508
  • [C++] Verwendungen von boost::regex entfernen #9533 – [C++] Verwenden Sie sendRequestWithId, um eine Zeitüberschreitung zu hasMessageAvailable hinzuzufügen #11600
  • [Pulsar perf] Log-Level-Konfiguration für pulsar-admin, pulsar-client und pulsar-perf korrigiert #12915

Funktionen und Pulsar IO

– Korrigieren Sie Quellstatistiken, die eine leere Ausnahmeliste offenlegen #11478 – Fix-Funktion API kann Authdata nicht verwenden, um Superuser zu überprüfen #11418 – Unterstützung der Einstellung KEY_BASED Batch Builder für Pulsar Sinks #11710 – Erkennen Sie .nar-Dateien und verhindern Sie Spam-Protokolle beim Funktionsstart #12665 – Entfernen Sie die veraltete api-Nutzung in HDFS #12080

Abgestufter Speicher

– Behebung der potenziellen Race-Bedingung im BlobStore-Readhandler #12123

Bauen

– CMake zwingen, Python2 zu finden #9690 – Verwenden Sie Ubuntu 20.04 als docker-Image-Basis #12017 – Behebung des docker-Image-Installationsproblems python3.7-dev #11942

pulsar v2.7.4

Security

  • Upgrade log4j to 2.17.0 - CVE-2021-45105 #13392
  • Upgrade commons-compress to 1.21 - CVE-2021-35515, CVE-2021-35516, CVE-2021-35517 and CVE-2021-36090 #11345

Broker

  • Fix DispatchRateLimiter does not take effect #8611
  • Fix set-publish-rate when using preciseTopicPublishRateLimiterEnable=true #10384
  • Fix retention policy in topic policy not work #11021
  • Fix GetTopicsOfNamespace with binary lookup service not check auth #11172
  • Fix retention of keys in compaction #11287
  • Fix using partitioned topic name to get Policy #11294
  • Fix NPE when unloading persistent partitioned topic #11310
  • Remove RateLimiter constructors and replace with builder usage #11599
  • Add backoff for setting for getting topic policies #11574
  • Fix decode compression managedLedgerInfo data #11569
  • Fix some topic policy operation without backoff #11560
  • Fix data lost when using earliest position to subscribe to a topic #11547
  • Fix the schema deletion when delete topic with delete schema #11501
  • Do not create system topic for heartbeat namespace #11499
  • Compress managed ledger info #11490
  • Add backoff for setting for getting topic policies #11487
  • Solving precise rate limiting does not take effect #11446
  • Fix replicated subscriptions direct memory leak #11396
  • Close the replicator and replication client when deleting cluster #11390
  • Invalidate the read handle after all cursors are consumed #11389
  • Fix NPE when unloading persistent partitioned topic #11386
  • Fix retention of keys in compaction #11384
  • Disable replicate system topic across clusters #11376
  • Parallel Precise Publish Rate Limiting Fix #11372
  • Pulsar Admin List Subscription lists only subscriptions created for Partition-0 when partition specific subscriptions are created #11355
  • Fix inconsistent behavior for Namespace bundles cache #11346
  • Fix update ledger list to znode version mismatch failed, ledger not delete #12015
  • Print position info when can't find next valid position #11969
  • Forbid to read other topic's data in managedLedger layer #11913
  • Fix using partitioned topic name to get topic policies #11897
  • Refine topic level backlog quota policies warning log #11863
  • Producer getting producer busy is removing existing producer from list #11804
  • Handle NPE and memory leak when full key range isn't covered with active consumers #11749
  • Call .release() when discarding entry to prevent direct memory leak #11748
  • Fix the topic in fenced state and can not recover #11737
  • Support disabling non-TLS service ports #11724
  • Fix the bug, can not update topic when the update topicName is contained by an existed topic as a part #11686
  • Fix Pulsar didn't respond error messages when throw InterceptException #11650
  • Avoid redundant calls for getting the offload policies from the offloader #11629
  • Optimize ManagedLedger Ledger Ownership Check #13222
  • Do not reuse the Failed OpAddEntry object which lead bundle unloading timeout #12993
  • Fix producer getting incorrectly removed from topic's producers map #12846
  • Allow to configure schema compatibility policy for system topics #12598
  • Cleanup already deleted namespace topics #12583
  • Add OpAddEntry to pendingAddEntries after the state check #12570
  • Cancel scheduled tasks when deleting ManagedLedgerImpl #12565
  • NPE on OpAddEntry while ManagedLedger is closing #12364
  • Avoid potentially blocking calls to metadata on critical threads #12340
  • Fix used after recycle issue in OpAddEntry #12103
  • Optimize the memory usage of Cache Eviction #12045
  • Fix wrong key-hash selector used for new consumers after all the previous consumers disconnected #12035
  • Only auth_errors should log at error level #9325

Dependency upgrade

  • Remove Boost::System runtime dependency #9498
  • Upgrade Jetty to 9.4.43.v20210629 #11660
  • Add maven.restlet.org repository #13248
  • Upgrade ZooKeeper version to 3.5.9 #12981
  • Remove pulsar-dashboard from the publish process of images #12534
  • Roll back to using Java 8 for docker images #12357
  • Upgrade TestContainers to 1.15.1 #9120

Client

  • [Java] Refactor seek to reuse common logic #9670
  • [Java] Process partitioned-topic messages on different listener-threads #10017
  • [Java] Fix Consumer listener does not respect receiver queue size #11455
  • [Java] Add a optional params scope for pulsar oauth2 client #11931
  • [Java] Fix seek at batchIndex level receive duplicated messages #11826
  • [Java] Fix race condition on multi-topic consumer #11764
  • [Java] Remove consumer reference from PulsarClient on subscription failure #11758
  • [Java] Fix block forever bug in Consumer.batchReceive #11691
  • [Java] Send CloseProducer on timeout #13161
  • [Java] Remove invalid call to Thread.currentThread().interrupt() #12652
  • [Python] Fix fields that are ignoring the required key argument #11508
  • [C++] Remove usages of boost::regex #9533
  • [C++] Use sendRequestWithId to add timeout to hasMessageAvailable #11600
  • [Pulsar perf] Fix log level config for pulsar-admin, pulsar-client and pulsar-perf #12915

Functions and Pulsar IO

  • Fix source stats exposing empty exceptions list #11478
  • Fix function API can not use authdata to check superuser #11418
  • Support setting KEY_BASED batch builder for Pulsar Sinks #11710
  • Detect .nar files and prevent spammy logs on functions boot #12665
  • Remove the deprecated api usage in hdfs #12080

Tiered Storage

  • Fix the potential race condition in the BlobStore readhandler #12123

Build

  • Force CMake to find Python2 #9690
  • Use ubuntu 20.04 as docker image base #12017
  • Fix docker image install python3.7-dev problem #11942
