Pulsar v4.1.1

27.09.2025

Bibliotheksaktualisierungen

– [fix][sec] Upgrade von Netty auf 4.1.127.Final, um CVEs zu adressieren (#24717)

  • [verbessern][bauen] Lombok auf 1.18.42 aktualisieren, um JDK25 vollständig zu unterstützen (#24763)
  • [verbessern][build] Apache Parent POM auf Version 35 aktualisieren (#24742)
  • [verbessern][build] Aktualisieren Sie Mockito, AssertJ und ByteBuddy, um JDK25 vollständig zu unterstützen (#24764)
  • [verbessern][build] Aktualisieren Sie SpotBugs auf eine Version, die JDK25 unterstützt (#24768)
  • [feat][misc] Oxia-Version auf 0.6.2 aktualisieren (#24689)
  • [verbessern][io] Upgrade auf Debezium 3.2.2 (#24712)

Makler

– [fix][broker] Key_Shared-Abonnement stellt Nachrichten nicht immer aus der Wiedergabewarteschlange zu, nachdem ein Verbraucher die Verbindung trennt und einen Rückstand hinterlässt (#24736) – [Fix][Broker] Stellen Sie sicher, dass der KeyShared-Sticky-Mode-Consumer die zugewiesenen Bereiche respektiert (#24730)

  • [Fix][Broker] Der erste Eintrag wird übersprungen, wenn NonDurableCursor geöffnet wird, während das gekürzte Hauptbuch den ersten Eintrag hinzufügt. (#24738) – [Fix][Broker] Fix konnte den Broker nicht ordnungsgemäß durch den Administrator api herunterfahren (#24731) – [fix][broker] Speicherverlust behoben, wenn Metriken in einem anderen Thread als FastThreadLocalThread aktualisiert werden (#24719) – [fix][broker] Verhindert unerwartete Recyclingfehler im Leserückruf des Dispatchers (#24741) – [fix][broker]Fix: Das Problem mit der fehlerhaften Version des Metadatenspeichers wurde nie wiederhergestellt, wenn eine umfangreiche Antwort von ZK einging (#24580)
  • [fix][ml]Fix EOFException nach aktiviertem Topic-Offloading (#24753) – [fix][broker] NPE behoben und nullfähige Rückgabewerte für ManagedCursorContainer mit Anmerkungen versehen (#24706) – [fix][broker]Dispatcher hat eine unnötige Sortierung für „recentlyJoinedConsumers“ durchgeführt und verrauschte Fehlerprotokolle gedruckt (#24634)
  • [fix][broker]Dirty Reading von Offload-Schwellenwerten auf Namespace-Ebene behoben (#24696)
  • [fix][ml] Negativer Rückstand und bestätigte Positionen sind nicht vorhanden und die Nachricht geht verloren, wenn gleichzeitig der Themeneigentümer besetzt ist (#24722)
  • [verbessern][Broker] Wenn es einen Deadlock im Dienst gibt, sollte der Test einen Fehler zurückgeben, da der Dienst möglicherweise nicht verfügbar ist (#23634) – [verbessern][Broker] Ermöglicht das Löschen leerer persistenter Themen unabhängig von der Aufbewahrungsrichtlinie (#24733)
  • [verbessern][Broker] PIP-402: Optional Rollen-/OriginalPrincipal-Protokollierung verhindern (#23386)
  • [verbessern][Broker] Reduzieren Sie unnötiges MessageMetadata-Parsing, indem Sie die analysierte Instanz im Broker-Cache zwischenspeichern (#24682) – [verbessern][ml] Verbessern Sie die Cache-Einfügungsleistung, indem Sie die Prüfung auf „Existenz“ entfernen, da diese bereits von putIfAbsent abgedeckt wird (#24699)

Client

– [fix][client] Vermeiden Sie, dass dasselbe ConcurrentBitSetRecyclable zwischen verschiedenen Threads recycling wird (#24725)

  • [fix][client] Automatische Skalierung der Empfängerwarteschlange ohne Speicherbegrenzung behoben (#24743) – [fix][client]TopicListWatcher wurde beim Aufruf der PatternMultiTopicsConsumerImpl.closeAsync()-Methode nicht geschlossen (#24698)
  • [fix][client] Rollback-TopicListWatcher-Wiederholungsverhalten (#24752)
  • [fix][client] io.prometheus:simpleclient_caffeine von client-seitigen Abhängigkeiten ausschließen (#24761)
  • [verbessern][client] PIP-407 newMessage mit Schema und Transaktionen hinzufügen (#23942)

Pulsar IO und Pulsar-Funktionen

  • [fix][io] Verbesserung der Kafka Connect-Source-Offset-Flushing-Logik (#24654)
  • [feat][fn] Fallback zur Verwendung von STATE_STORAGE_SERVICE_URL in PulsarMetadataStateStoreProviderImpl.init (#24721)

Andere

  • [fix][misc] CompareTo-Vertragsverletzung für NamespaceBundleStats, TimeAverageMessageData und ResourceUnitRanking behoben (#24772)
  • [Fix] Commons-lang-Abhängigkeit vom Buchhalter ausschließen (#24749)

Tests & CI

  • [fix][test] Flaky-Test: BrokerServiceTest.testShutDownWithMaxConcurrentUnload (#24769)
  • [fix][broker] TestServiceConfigurationRetentionPolicy-Einheitentest behoben (#24756)
  • [fix][broker]Fix die falsche Logik des Tests PartitionCreationTest.testCreateMissedPartitions (#24683)
  • [verbessern][build] Javadoc-Build-Fehler deaktivieren (#24594)
  • [fix][ci] CI für Java 25 korrigiert, einschließlich Upgrade der Gradle Develocity Maven-Erweiterung (#24767) Die vollständige Liste finden Sie im vollständigen changelog.

Englisches Original / English original

pulsar v4.1.1

2025-09-27

Library updates

  • [fix][sec] Upgrade Netty to 4.1.127.Final to address CVEs (#24717)
  • [improve][build] Upgrade Lombok to 1.18.42 to fully support JDK25 (#24763)
  • [improve][build] Upgrade Apache Parent POM to version 35 (#24742)
  • [improve][build] Upgrade Mockito, AssertJ and ByteBuddy to fully support JDK25 (#24764)
  • [improve][build] Upgrade SpotBugs to a version that supports JDK25 (#24768)
  • [feat][misc] upgrade oxia version to 0.6.2 (#24689)
  • [improve][io] Upgrade to Debezium 3.2.2 (#24712)

Broker

  • [fix][broker] Key_Shared subscription doesn't always deliver messages from the replay queue after a consumer disconnects and leaves a backlog (#24736)
  • [fix][broker] Ensure KeyShared sticky mode consumer respects assigned ranges (#24730)
  • [fix][broker] First entry will be skipped if opening NonDurableCursor while trimmed ledger is adding first entry. (#24738)
  • [fix][broker] Fix cannot shutdown broker gracefully by admin api (#24731)
  • [fix][broker] Fix memory leak when metrics are updated in a thread other than FastThreadLocalThread (#24719)
  • [fix][broker] Prevent unexpected recycle failure in dispatcher's read callback (#24741)
  • [fix][broker]Fix never recovered metadata store bad version issue if received a large response from ZK (#24580)
  • [fix][ml]Fix EOFException after enabled topics offloading (#24753)
  • [fix][broker] Fix NPE and annotate nullable return values for ManagedCursorContainer (#24706)
  • [fix][broker]Dispatcher did unnecessary sort for recentlyJoinedConsumers and printed noisy error logs (#24634)
  • [fix][broker]Fix dirty reading of namespace level offload thresholds (#24696)
  • [fix][ml] Negative backlog & acked positions does not exist & message lost when concurrently occupying topic owner (#24722)
  • [improve][broker] If there is a deadlock in the service, the probe should return a failure because the service may be unavailable (#23634)
  • [improve][broker] Allow deletion of empty persistent topics regardless of retention policy (#24733)
  • [improve][broker] PIP-402: Optionally prevent role/originalPrincipal logging (#23386)
  • [improve][broker] Reduce unnecessary MessageMetadata parsing by caching the parsed instance in the broker cache (#24682)
  • [improve][ml] Improve cache insert performance by removing exists check since it's already covered by putIfAbsent (#24699)

Client

  • [fix][client] Avoid recycling the same ConcurrentBitSetRecyclable among different threads (#24725)
  • [fix][client] Fix receiver queue auto-scale without memory limit (#24743)
  • [fix][client]TopicListWatcher not closed when calling PatternMultiTopicsConsumerImpl.closeAsync() method (#24698)
  • [fix][client] rollback TopicListWatcher retry behavior (#24752)
  • [fix][client] Exclude io.prometheus:simpleclient_caffeine from client-side dependencies (#24761)
  • [improve][client] PIP-407 Add newMessage with schema and transactions (#23942)

Pulsar IO and Pulsar Functions

  • [fix][io] Improve Kafka Connect source offset flushing logic (#24654)
  • [feat][fn] Fallback to using STATE_STORAGE_SERVICE_URL in PulsarMetadataStateStoreProviderImpl.init (#24721)

Others

  • [fix][misc] Fix compareTo contract violation for NamespaceBundleStats, TimeAverageMessageData and ResourceUnitRanking (#24772)
  • [fix] Exclude commons-lang dep from bookkeeper (#24749)

Tests & CI

  • [fix][test] Flaky-test: BrokerServiceTest.testShutDownWithMaxConcurrentUnload (#24769)
  • [fix][broker] Fix testServiceConfigurationRetentionPolicy unit test (#24756)
  • [fix][broker]Fix the wrong logic of the test PartitionCreationTest.testCreateMissedPartitions (#24683)
  • [improve][build] Disable javadoc build failure (#24594)
  • [fix][ci] Fix CI for Java 25 including upgrade of Gradle Develocity Maven extension (#24767)

For the complete list, check the full changelog.
