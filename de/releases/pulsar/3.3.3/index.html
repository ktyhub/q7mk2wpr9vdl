Pulsar v3.3.3

03.12.2024

Bibliotheksaktualisierungen

– [fix][sec] HDFS2-Unterstützung einstellen, Hadoop3 auf 3.4.0 und DNSjava auf 3.6.2 aktualisieren, um CVE-2024-25638 zu beheben (#23411) – [fix][sec] Ersetzen Sie die bcprov-jdk15on-Abhängigkeit durch bcprov-jdk18-on (#23532) – [fix][sec] Upgrade von Zookeeper auf 3.9.3 zur Behebung von CVE-2024-51504 (#23581) – [fix][sec] Upgrade auf Netty 4.1.115.Final zur Behebung von CVE-2024-47535 (#23596)

  • [verbessern] Upgrade der OpenTelemetry-Bibliothek auf die 1.44.1-Version (#23656)
  • [verbessern] Oxia-Java auf 0.4.10 aktualisieren und das Schließen von OxiaMetadataStore beheben (#23653)

Makler

  • [fix][broker] Vermeiden Sie verwaiste Ledger in BucketDelayedDeliveryTracker (#22802) – [Fix][Broker] Broker kann kein nicht dauerhaftes Sub erstellen, wenn das Thema eingezäunt ist (#23579)
  • [fix][broker] AvgShedder-Strategieprüfung behoben (#23156) – [fix][broker] Behebung der Broker-Migrations-NPE, während die Broker-TLS-URL nicht konfiguriert ist (#23534) – [Fix][Broker] Fix: Derzeit versucht client erneut, bis der Vorgang eine Zeitüberschreitung erfährt, wenn das Thema nicht vorhanden ist (#23530)
  • [fix][broker] Fix fehlgeschlagener TokenAuthenticatedProducerConsumerTest (#23602) – [Fix][Broker] Fix: Das Entladen des Namespace wurde möglicherweise zu lange mit dem erweiterbaren Lademanager blockiert (#23433) (#23517)
  • [fix][broker] Eigentumsverlust behoben (#23515)
  • [fix][broker] Antwort auf den Druckcluster-Migrationsstatus behoben (#23535)
  • [fix][broker] Racebedingung behoben, die zu wiederholtem Löschen des Themas führte (#23522)
  • [fix][broker] Behebung, dass die Broker-Registrierung möglicherweise für längere Zeit blockiert war (#23371) (#23507)
  • [fix][broker] Fix unloadNamespaceBundlesGracefully kann mit dem erweiterbaren Lademanager hängen bleiben (#23349) (#23496) – [fix][broker] Erhöhen Sie die readBuffer-Größe für bookkeeper.DLOutputStream (#23548) – [Fix][Broker] Themen konnten nach dem Entfernen des Clusters aus replizierten Clustern nicht gelöscht werden und verursachten OOM (#23360)
  • [fix][broker] korrigiert die Protokollierung mit korrekter Fehlermeldung beim Laden des Themas (#23544) – [fix][broker] korrigiert Null-Suchergebnis beim Starten von Brokern (#23642)
  • [Fix][Broker] normalisiert den Pfad (#23438) – [Fix][Broker]-Timeout, wenn die Broker-Registrierung hängt und die Broker-Registrierung überwacht (nur ExtensibleLoadManagerImpl) (#23382) (#23510)
  • [verbessern][Broker] Protokoll hinzufügen, um Problem zu verfolgen, wenn handleGetTopicsOfNamespace (#23434)
  • [verbessern][Broker] Löschen Sie die lokale BrokerEntryMetadata-Instanz des Threads vor der Wiederverwendung (#22752)
  • [verbessern][Broker] Entkopplung der pulsar_storage_backlog_age_seconds-Metrik mit der BacklogQuota-Prüfung (#23619)
  • [verbessern][Broker] Systemthemen von der Veröffentlichungs- und Versandratenbegrenzung auf Namespace-Ebene ausschließen (#23589) – [verbessern][Broker] Cluster-Metadaten-Init-Befehl zur Unterstützung des Metadaten-Konfigurationspfads festlegen (#23269) – [verbessern][Broker] Den Cluster-Metadaten-Teardown-Befehl zur Unterstützung des Metadaten-Konfigurationspfads anpassen (#23520)
  • [improve][broker] PIP-383: Unterstützung beim Gewähren/Entziehen von Berechtigungen für mehrere Themen (#23372) – [verbessern][Broker] PIP-392: Konfiguration hinzugefügt, um konsistentes Hashing zu ermöglichen, um den aktiven Verbraucher für ein partitioniertes Thema auszuwählen (#23584) – [improve][broker] Entladen überspringen, wenn der Bundle-Durchsatz Null ist (nur ExtensibleLoadManagerImpl) (#23626) – [verbessern][Broker] Unterstützt die Bereinigung von replication cluster und allowed cluster beim Abbau von Cluster-Metadaten (#23561)
  • [verbessern][Broker] wählt den Kanalbesitzer erneut, wenn kein Kanalbesitzer gefunden wird (#23516) (#23580)
  • [verbessern][Broker] ersetzen Sie HashMap durch die innere Implementierung ConcurrentLongLongPairHashMap im Negative Ack Tracker. (#23582)

Client

  • [fix][admin] Korrigiert, dass die Suche ein Null-Ergebnis liefert, wenn ein Proxy verwendet wird (#23556)
  • [fix][client] DLQ-Produzentennamenskonflikte behoben, wenn es gleichnamige Konsumenten gibt (#23577) – [fix][client] Fix: Reader.hasMessageAvailable gibt nach der Suche nach Zeitstempel mit startMessageIdInclusive einen falschen Wert zurück (#23502)
  • [fix][client] Fix ReaderBuilder gibt kein illegalArgument bei erneutem Verbindungsversuch aus (#22639)
  • [fix][client] Deadlock von NegativeAcksTracker beheben (#23651) – [fix][client] Behebung des Producer/Consumer-Stopps zum erneuten Verbinden oder Pub/Sub aufgrund einer E/A-Thread-Race-Condition (#23499)
  • [fix][client] Racebedingung behoben, die dazu führte, dass doReconsumeLater hängen blieb, wenn die Erstellung von retryLetterProducer fehlgeschlagen ist (#23560)
  • [fix][client] Korrigieren Sie das Javadoc für ConsumerBuilder.isAckReceiptEnabled (#23452)
  • [fix][client] Es wurde ein Problem behoben, bei dem eine Zertifikatskette bei der TLS-Authentifizierung nicht verwendet werden konnte (#23644)
  • [Fix][client] Initialisierung der client-Authentifizierung mit konfigurierten Authentifizierungsparametern (#23610)
  • [fix][client] Protobuf-Java-Abhängigkeit in Java-client-Bibliotheken optional machen (#23632)
  • [Fix][client] Einbetten von Protobuf-Java-Klassendateien in pulsar-client-admin und pulsar-client-all verhindern (#23468)
  • [fix][client] Der partitionedProducer maxPendingMessages ist immer 0 (#23593) – [fix][client] Dedizierten Executor für Anfragen in BinaryProtoLookupService verwenden (#23378)
  • [fix][client] korrigiert incomingMessageSize und client-Speichernutzung ist negativ (#23624) – [fix][client] korrigiert die Methode beforeConsume(), die zuvor mit dem Nachrichten-Listener getroffen wurde (#23578)
  • [verbessern][admin] Fehlerprotokoll drucken, wenn die Handle-HTTP-Antwort fehlschlägt (#23563)
  • [verbessern][client] Fehlerbehandlung für nicht vorhandene Abonnements bei der Verbrauchererstellung verbessern (#23254)
  • [verbessern][client] Standard-Java-client-VerbindungMaxIdleSeconds auf 60 Sekunden erhöhen (#23430)
  • [verbessern][client] Reduzieren Sie nicht schattierte Abhängigkeiten und Schattierungswarnungen in schattierten Java client-Modulen (#23647)
  • [verbessern][client] Ersetzen Sie NameUtil#generateRandomName durch RandomStringUtils#randomAlphanumeric (#23645)

Pulsar IO und Pulsar-Funktionen

– [fix][fn] Bestätigungsmeldungen für die Fensterfunktion, wenn ihr Ergebnis null ist (#23618) – [verbessern][io] Support-Update-Abonnementposition für Sink-Connector (#23538)

  • [verbessern][io] Upgrade der Spring-Version auf 6.1.13 in IO-Anschlüssen (#23459)

Andere

  • [fix][misc] Klassenkonflikt während des Jetcd-Core-Shaded-Shading-Prozesses (#23641) – [Fix][Sonstiges] Aufgrund eines Jetc-Core-Sharding-Problems kann kein etcd-Metastore mit neueren Versionen verbunden werden (#23604) – [fix][ml] Das verwaltete Hauptbuch sollte wiederhergestellt werden, nachdem das offene Hauptbuch fehlgeschlagen ist (#23368)
  • [fix][proxy] Fix Pattern Consumer funktioniert nicht, wenn Proxy verwendet wird (#23489) – [fix][ws] Fehlende http-Header-Datenfunktionen in AuthenticationDataSubscription implementieren (#23638)
  • [verbessern] Logik zur Aktivierung der Netty-Leckerkennung verbessern (#23613)
  • [verbessern] Einzelnen Puffer für Metriken verwenden, wenn keine unsichere Verwendung erfolgt (#23612)
  • [verbessern][Sonstiges] OTel standardmäßig deaktivieren, wenn das Pulsar-Perf-Tool ausgeführt wird (#23585)
  • [verbessern][Sonstiges] Jetty auf 9.4.56.v20240826 upgraden (#23405) – [verbessern][ml] Wiederholte verschachtelte Sperren für isMessageDeleted in ManagedCursorImpl vermeiden (#23609)
  • [verbessern][auslagern] FilesystemURI als Speicherpfad verwenden (#23591) – Aktivieren von DNS retryOnTimeout mit TCP in DnsNameResolver (#23590)

Tests & CI

– [cleanup][build] überspringt die Generierung von pom.xml.versionsBackup (#23639)

  • [fix][build] Grundlegende Unterstützung für vscode-java und Eclipse IDE hinzufügen (#23448)
  • [fix][build] Fehler „Elementkodierung ist hier nicht zulässig“ in pom.xml behoben (#23655)
  • [fix][build] Entfernen Sie doppelte Abhängigkeiten in pom.xml (#23440)
  • [fix][ci] Pin aquasecurity/trivy-action@0.26.0, da Master defekt ist (#23431)
  • [fix][test] Adresse unzuverlässig GetPartitionMetadataMultiBrokerTest (#23456)
  • [fix][test] DeadLetterTopicTest.testDeadLetterTopicWithInitialSubscriptionAndMultiConsumers beheben (#23552)
  • [fix][test] Fix SimpleProducerConsumerTest.testMultiTopicsConsumerImplPauseForManualSubscription (#23546)
  • [fix][test] Flaky GetPartitionMetadataMultiBrokerTest.testCompatibilityDifferentBrokersForNonPersistentTopic beheben (#23259)
  • [fix][test] Flaky Test ManagedLedgerTest.testDeleteCurrentLedgerWhenItIsClosed behoben (#23437)
  • [fix][test] Speicherverlust über OTel-Shutdown-Hooks in Tests behoben (#23483)
  • [fix][test] Fehler beim Ausführen von ClusterMetadataSetupTest in der IDE behoben (#23492)
  • [fix][test][branch-3.3] Fix OneWayReplicatorUsingGlobalZKTest#testRemoveCluster
  • [verbessern][build] Erfordert Java 17 oder Java 21 zum Erstellen von Pulsar (#22875)

  • [verbessern][test] Nachrichteneigenschaftentests für Batch- und Nicht-Batch-Nachrichten hinzugefügt (#23473)

pulsar v3.3.3

2024-12-03

Library updates

  • [fix][sec] Drop hdfs2 support, Upgrade hadoop3 to 3.4.0 and dnsjava to 3.6.2 to address CVE-2024-25638 (#23411)
  • [fix][sec] Replace bcprov-jdk15on dependency with bcprov-jdk18-on (#23532)
  • [fix][sec] Upgrade Zookeeper to 3.9.3 to address CVE-2024-51504 (#23581)
  • [fix][sec] Upgrade to Netty 4.1.115.Final to address CVE-2024-47535 (#23596)
  • [improve] Upgrade OpenTelemetry library to 1.44.1 version (#23656)
  • [improve] Upgrade oxia-java to 0.4.10 and fix closing of OxiaMetadataStore (#23653)

Broker

  • [fix][broker] Avoid orphan ledgers in BucketDelayedDeliveryTracker (#22802)
  • [fix][broker] Broker is failing to create non-durable sub if topic is fenced (#23579)
  • [fix][broker] Fix AvgShedder strategy check (#23156)
  • [fix][broker] Fix Broker migration NPE while broker tls url not configured (#23534)
  • [fix][broker] Fix currently client retries until operation timeout if the topic does not exist (#23530)
  • [fix][broker] Fix failed TokenAuthenticatedProducerConsumerTest (#23602)
  • [fix][broker] Fix namespace unload might be blocked too long with extensible load manager (#23433) (#23517)
  • [fix][broker] Fix ownership loss (#23515)
  • [fix][broker] Fix print cluster migration state response (#23535)
  • [fix][broker] Fix race-condition causing repeated delete topic (#23522)
  • [fix][broker] Fix the broker registering might be blocked for long time (#23371) (#23507)
  • [fix][broker] Fix unloadNamespaceBundlesGracefully can be stuck with extensible load manager (#23349) (#23496)
  • [fix][broker] Increase readBuffer size for bookkeeper.DLOutputStream (#23548)
  • [fix][broker] Topics failed to delete after remove cluster from replicated clusters set and caused OOM (#23360)
  • [fix][broker] fix logging with correct error message while loading the topic (#23544)
  • [fix][broker] fix null lookup result when brokers are starting (#23642)
  • [fix][broker] normalize path (#23438)
  • [fix][broker] timeout when broker registry hangs and monitor broker registry (ExtensibleLoadManagerImpl only) (#23382) (#23510)
  • [improve][broker] Add log to track issue when handleGetTopicsOfNamespace (#23434)
  • [improve][broker] Clear thread local BrokerEntryMetadata instance before reuse (#22752)
  • [improve][broker] Decouple pulsar_storage_backlog_age_seconds metric with backlogQuota check (#23619)
  • [improve][broker] Exclude system topics from namespace level publish and dispatch rate limiting (#23589)
  • [improve][broker] Make cluster metadata init command support metadata config path (#23269)
  • [improve][broker] Make cluster metadata teardown command support metadata config path (#23520)
  • [improve][broker] PIP-383: Support granting/revoking permissions for multiple topics (#23372)
  • [improve][broker] PIP-392: Add configuration to enable consistent hashing to select active consumer for partitioned topic (#23584)
  • [improve][broker] Skip unloading when bundle throughput is zero (ExtensibleLoadManagerImpl only) (#23626)
  • [improve][broker] Support cleanup replication cluster and allowed cluster when cluster metadata teardown (#23561)
  • [improve][broker] re-elect the channel owner if no channel owner is found (#23516) (#23580)
  • [improve][broker] replace HashMap with inner implementation ConcurrentLongLongPairHashMap in Negative Ack Tracker. (#23582)

Client

  • [fix][admin] Fix lookup get a null result if uses proxy (#23556)
  • [fix][client] Fix DLQ producer name conflicts when there are same name consumers (#23577)
  • [fix][client] Fix Reader.hasMessageAvailable return wrong value after seeking by timestamp with startMessageIdInclusive (#23502)
  • [fix][client] Fix ReaderBuilder doest not give illegalArgument on connection failure retry (#22639)
  • [fix][client] Fix deadlock of NegativeAcksTracker (#23651)
  • [fix][client] Fix producer/consumer stop to reconnect or Pub/Sub due to IO thread race-condition (#23499)
  • [fix][client] Fix race-condition causing doReconsumeLater to hang when creating retryLetterProducer has failed (#23560)
  • [fix][client] Fix the javadoc for ConsumerBuilder.isAckReceiptEnabled (#23452)
  • [fix][client] Fixed an issue where a cert chain could not be used in TLS authentication (#23644)
  • [fix][client] Initializing client-authentication using configured auth params (#23610)
  • [fix][client] Make protobuf-java dependency optional in java client libraries (#23632)
  • [fix][client] Prevent embedding protobuf-java class files in pulsar-client-admin and pulsar-client-all (#23468)
  • [fix][client] The partitionedProducer maxPendingMessages always is 0 (#23593)
  • [fix][client] Use dedicated executor for requests in BinaryProtoLookupService (#23378)
  • [fix][client] fix incomingMessageSize and client memory usage is negative (#23624)
  • [fix][client] fix the beforeConsume() method earlier hit with message listener (#23578)
  • [improve][admin] Print error log if handle http response fails (#23563)
  • [improve][client] Enhance error handling for non-exist subscription in consumer creation (#23254)
  • [improve][client] Increase default Java client connectionMaxIdleSeconds to 60 seconds (#23430)
  • [improve][client] Reduce unshaded dependencies and shading warnings in shaded Java client modules (#23647)
  • [improve][client] Replace NameUtil#generateRandomName with RandomStringUtils#randomAlphanumeric (#23645)

Pulsar IO and Pulsar Functions

  • [fix][fn] ack messages for window function when its result is null (#23618)
  • [improve][io] Support update subscription position for sink connector (#23538)
  • [improve][io] Upgrade Spring version to 6.1.13 in IO Connectors (#23459)

Others

  • [fix][misc] Class conflict during jetcd-core-shaded shading process (#23641)
  • [fix][misc] Unable to connect an etcd metastore with recent releases due to jetc-core sharding problem (#23604)
  • [fix][ml] Managed ledger should recover after open ledger failed (#23368)
  • [fix][proxy] Fix pattern consumer does not work when using Proxy (#23489)
  • [fix][ws] Implement missing http header data functions in AuthenticationDataSubscription (#23638)
  • [improve] Improve logic for enabling Netty leak detection (#23613)
  • [improve] Use single buffer for metrics when noUnsafe use (#23612)
  • [improve][misc] Disable OTel by default when running the pulsar-perf tool (#23585)
  • [improve][misc] Upgrade Jetty to 9.4.56.v20240826 (#23405)
  • [improve][ml] Avoid repetitive nested lock for isMessageDeleted in ManagedCursorImpl (#23609)
  • [improve][offload] Use filesystemURI as the storage path (#23591)
  • Enabling DNS retryOnTimeout with TCP in DnsNameResolver (#23590)

Tests & CI

  • [cleanup][build] skip generating pom.xml.versionsBackup (#23639)
  • [fix][build] Add basic support for vscode-java and Eclipse IDE (#23448)
  • [fix][build] Fix error "Element encoding is not allowed here" in pom.xml (#23655)
  • [fix][build] Remove duplicate dependencies in pom.xml (#23440)
  • [fix][ci] Pin aquasecurity/trivy-action@0.26.0 since master is broken (#23431)
  • [fix][test] Address flaky GetPartitionMetadataMultiBrokerTest (#23456)
  • [fix][test] Fix DeadLetterTopicTest.testDeadLetterTopicWithInitialSubscriptionAndMultiConsumers (#23552)
  • [fix][test] Fix SimpleProducerConsumerTest.testMultiTopicsConsumerImplPauseForManualSubscription (#23546)
  • [fix][test] Fix flaky GetPartitionMetadataMultiBrokerTest.testCompatibilityDifferentBrokersForNonPersistentTopic (#23259)
  • [fix][test] Fix flaky test ManagedLedgerTest.testDeleteCurrentLedgerWhenItIsClosed (#23437)
  • [fix][test] Fix memory leak via OTel shutdown hooks in tests (#23483)
  • [fix][test] Fix running ClusterMetadataSetupTest in IDE (#23492)
  • [fix][test][branch-3.3] Fix OneWayReplicatorUsingGlobalZKTest#testRemoveCluster
  • [improve][build] Require Java 17 or Java 21 for building Pulsar (#22875)
  • [improve][build] Update maven-wrapper (mvnw) to recent stable version 3.3.2 (#23410)
  • [improve][ci] Continue Pulsar CI build even when Trivy scanner fails (#23397)
  • [improve][test] Added message properties tests for batch and non-batch messages (#23473)
  • [improve][test] Disable OTel autoconfigured exporters in tests (#23540)
