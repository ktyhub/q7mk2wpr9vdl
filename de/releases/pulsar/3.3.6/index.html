Pulsar v3.3.6

09.04.2025

Bibliotheksaktualisierungen

  • [Fix] Bump google.golang.org/protobuf von 1.32.0 auf 1.33.0 in /pulsar-function-go (#22261) – [fix][sec] Aktualisieren Sie jwt/v5 auf 5.2.2, um CVE-2025-30204 zu beheben (#24140) – [fix][sec] Aktualisieren Sie die Pulsar-Function-Go-Abhängigkeiten, um CVE-2025-22870 zu beheben (#24135)
  • [verbessern] Upgrade von Netty auf 4.1.119.Final (#24049)

Makler

  • [Fix] Negative geschätzte Eintragsanzahl vermeiden (#24055)
  • [fix][broker] Ablaufprüfung für Replikator hinzufügen (#23975) – [Fix][Broker] IllegalStateException vermeiden, wenn das Feld marker_type beim Veröffentlichen nicht festgelegt ist (#24087) – [Fix][Broker] Korrigiert den erneuten Erstellungsversuch des Metadata Event Synchronizer-Produzenten, sodass der Produzent schließlich erstellt wird (#24081)
  • [fix][broker] Fix Der Metadaten-Ereignissynchronisierer sollte bei fehlerhafter Version nicht fehlschlagen (#24080)
  • [fix][broker] Fehlende Validierung beim Festlegen der Aufbewahrungsrichtlinie auf Themenebene behoben (#24032)
  • [fix][broker] Behebung von NPE beim Veröffentlichen von Metadatenereignissen ohne Init-Produzenten (#24079) – [fix][broker] Das Musterabonnement funktioniert nicht, wenn das Muster die Themendomäne ausschließt. (#24072) – [Fix][Broker]-Themen konnten nach dem Entfernen des Clusters aus replizierten Clustern bei Verwendung eines partitionierten Systemthemas unendlich nicht gelöscht werden (#24097)
  • [fix][broker]Fehler beim Verbrauch nach dem Laden eines beendeten Themas behoben (#24063) – [fix][ml] Die Pulsar_storage_size-Metrik wurde korrigiert, um den ausgelagerten Speicher nicht mit dem Schreibquorum zu multiplizieren (#24054)
  • [fix][ml] Anzahl der Einträge nicht schätzen, wenn Hauptbücher leer sind, stattdessen 1 zurückgeben (#24125)
  • [fix][ml] Behebung von Problemen in „estimateEntryCountBySize“ (#24089) – [fix][ml] Gibt 1 zurück, wenn die Bytegröße für die Schätzung der Eintragsanzahl 0 oder negativ ist (#24131)
  • [verbessern][Broker] Thema ändern, Protokoll vorhanden, um zu warnen (#24116)
  • [verbessern][Broker] Optimierung der Nachrichtenablaufrate bei wiederholten Aktualisierungsproblemen (#24073)
  • [verbessern][Broker] Optimieren Sie ThresholdShedder mit verbesserten Grenzprüfungen und Parameterwiederverwendung (#24064) – [verbessern][Broker] Separaten Offload-Lese- und Schreib-Thread-Pool (#24025)
  • [verbessern][meta] Protokollebene von Fehler auf Warnung für unbekannte Benachrichtigungstypen in OxiaMetadataStore ändern (#24126)

Client

  • [fix][client] EventTime kopieren, um Briefthema und DLQ-Nachrichten erneut zu versuchen (#24059)
  • [fix][client] Fehler beim Erstellen fehlerhafter Batch-Nachrichten beim Veröffentlichen behoben (#24061)
  • [fix][client] Verbraucherleck behoben, wenn der Thread unterbrochen wird, bevor das Abonnement abgeschlossen ist (#24100) – [fix][client] Regression des Musterabonnements, wenn die Broker-seitige Auswertung deaktiviert ist (#24104)
  • [verbessern][client] NullPointException beim Schließen von ClientCredentialsFlow verhindern (#24123)
  • [clean][client] Bereinigter Code für die Erstellung des Themennamens für Wiederholungsversuche/unzustellbare Nachrichten (#24082)

Pulsar IO und Pulsar-Funktionen

  • [fix][io] KinesisSink json-Reduzierung für SchemaType.BYTES von AVRO behoben (#24132)
  • [verbessern][io] Verbessern Sie die Kafka-Connector-Protokollierung mit fokussierten Bootstrap-Serverinformationen (#24128)
  • [verbessern][io] Sleep entfernen, wenn sourceTask.poll von Kafka null zurückgibt (#24124)

Andere

– [fix][doc] Dokument im Zusammenhang mit der Chunk-Message-Funktion korrigiert. (#24023)

  • [verbessern][monitor] Version=0.0.4 zum Inhaltstyp /metrics hinzufügen, um Prometheus 3.x-Kompatibilität zu gewährleisten (#24060)

Tests & CI

  • [fix][ci] Bump-Abhängigkeitsprüfung auf 12.1.0, um den OWASP-Abhängigkeitsprüfungsjob zu reparieren (#24083)
  • [fix][test] Flaky NonPersistentTopicTest.testMsgDropStat beheben (#24134)
  • [fix][test] Flaky PrometheusMetricsTest.testBrokerMetrics beheben (#24042) Die vollständige Liste finden Sie im vollständigen changelog.

pulsar v3.3.6

2025-04-09

Library updates

  • [fix] Bump google.golang.org/protobuf from 1.32.0 to 1.33.0 in /pulsar-function-go (#22261)
  • [fix][sec] Upgrade jwt/v5 to 5.2.2 to address CVE-2025-30204 (#24140)
  • [fix][sec] Upgrade pulsar-function-go dependencies to address CVE-2025-22870 (#24135)
  • [improve] Upgrade Netty to 4.1.119.Final (#24049)

Broker

  • [fix] Avoid negative estimated entry count (#24055)
  • [fix][broker] Add expire check for replicator (#23975)
  • [fix][broker] Avoid IllegalStateException when marker_type field is not set in publishing (#24087)
  • [fix][broker] Fix Metadata Event Synchronizer producer creation retry so that the producer gets created eventually (#24081)
  • [fix][broker] Fix Metadata event synchronizer should not fail with bad version (#24080)
  • [fix][broker] Fix missing validation when setting retention policy on topic level (#24032)
  • [fix][broker] Fix NPE while publishing Metadata-Event with not init producer (#24079)
  • [fix][broker] Pattern subscription doesn't work when the pattern excludes the topic domain. (#24072)
  • [fix][broker] topics infinitely failed to delete after remove cluster from replicated clusters modifying when using partitioned system topic (#24097)
  • [fix][broker]Fix failed consumption after loaded up a terminated topic (#24063)
  • [fix][ml] Corrected pulsar_storage_size metric to not multiply offloaded storage by the write quorum (#24054)
  • [fix][ml] Don't estimate number of entries when ledgers are empty, return 1 instead (#24125)
  • [fix][ml] Fix issues in estimateEntryCountBySize (#24089)
  • [fix][ml] Return 1 when bytes size is 0 or negative for entry count estimation (#24131)
  • [improve][broker] Change topic exists log to warn (#24116)
  • [improve][broker] Optimize message expiration rate repeated update issues (#24073)
  • [improve][broker] Optimize ThresholdShedder with improved boundary checks and parameter reuse (#24064)
  • [improve][broker] Separate offload read and write thread pool (#24025)
  • [improve][meta] Change log level from error to warn for unknown notification types in OxiaMetadataStore (#24126)

Client

  • [fix][client] Copy eventTime to retry letter topic and DLQ messages (#24059)
  • [fix][client] Fix building broken batched message when publishing (#24061)
  • [fix][client] Fix consumer leak when thread is interrupted before subscribe completes (#24100)
  • [fix][client] Pattern subscription regression when broker-side evaluation is disabled (#24104)
  • [improve][client] Prevent NullPointException when closing ClientCredentialsFlow (#24123)
  • [clean][client] Clean code for the construction of retry/dead letter topic name (#24082)

Pulsar IO and Pulsar Functions

  • [fix][io] Fix KinesisSink json flattening for AVRO's SchemaType.BYTES (#24132)
  • [improve][io] Enhance Kafka connector logging with focused bootstrap server information (#24128)
  • [improve][io] Remove sleep when sourceTask.poll of kafka return null (#24124)

Others

  • [fix][doc] fix doc related to chunk message feature. (#24023)
  • [improve][monitor] Add version=0.0.4 to /metrics content type for Prometheus 3.x compatibility (#24060)

Tests & CI

  • [fix][ci] Bump dependency-check to 12.1.0 to fix OWASP Dependency Check job (#24083)
  • [fix][test] Fix flaky NonPersistentTopicTest.testMsgDropStat (#24134)
  • [fix][test] Fix flaky PrometheusMetricsTest.testBrokerMetrics (#24042)

For the complete list, check the full changelog.
