Pulsar v3.2.1

Makler

– Fügen Sie REST konsequent eine detaillierte Autorisierung hinzu. API #22202 – Detaillierte Autorisierung zum Aufbewahrungsadministrator API hinzufügen #22163 – Kein Protokoll drucken, wenn das Löschen des partitionierten Themas fehlgeschlagen ist #22153 – Behebung, dass der Broker nicht startet, wenn beide Transaktionen und der Extensible Load Manager aktiviert sind #22139 – Geben Sie getOwnerAsync zurück, ohne beim Zuweisen und Freigeben auf den Quellbroker zu warten, und verarbeiten Sie Rollenänderungen während der Rolleninitialisierung #22112 – Zwischenspeichern des internen Writers, wenn er an das Systemthema gesendet wird. #22099 – Das Aktivieren des Batches führt aufgrund der Parallelität von Bestätigung und Zustellung zu negativen unackedMessages #22090 – Unterstützt die Ausführung des docker-Containers mit gid != 0 #22081 – Fügen Sie ein Fehlerprotokoll hinzu, um den Fehler beim Starten der Broker-Registrierung zu beheben #22065 – Legen Sie den ServiceUnitStateChannel-Themenkomprimierungsschwellenwert explizit fest, verbessern Sie getOwnerAsync und beheben Sie andere Fehler #22064 – Hash-Kollision behoben, wenn ein Verbrauchername verwendet wird, der mit einer Zahl endet #22053 – Bereinigen Sie die Werte, bevor Sie sich im Skript „apply-config-from-env.py“ anmelden #22044 – Fix kann kein partitioniertes Thema mit einem Suffix-passenden regulären Ausdruck abonnieren #22025 – Behalten Sie die Daten im Systemthema nicht bei #22022 – Abonnement bleibt hängen, weil Admin API analysiereSubscriptionBacklog #22019 – Versuchen Sie nicht, ML zu öffnen, wenn das Themen-Meta nicht vorhanden ist, und erwarten Sie nicht, ein neues zu erstellen #22004 – Drucken Sie kein Fehlerprotokoll aus, wenn Sie auf HTTP-404 antworten, wenn Sie Admin API aufrufen und das Thema nicht existiert #21995 – Schließen Sie den Socket nicht, wenn die Suche aufgrund von LockBusyException #21993 fehlschlägt. – Unterstützt die dynamische Einstellung von autoSkipNonRecoverableData in PersistentMessageExpiryMonitor #21991 – Zeitüberschreitung für Integritätsprüfung hinzufügen, lesen #21990 – Schema-Löschfehler beim Löschen eines partitionierten Themas mit vielen Partitionen und Schemata behoben #21977 – Verschieben Sie die Eigentumsprüfungen, wenn der Eigentümer inaktiv ist (ExtensibleLoadManager) #21811 – Komprimierungs-/Replikationsdatenverlust bei Ablaufmeldungen behoben #21865 – Überspringen Sie das Laden der NAR-Pakete, wenn diese nicht konfiguriert sind #21867 – Verbesserung der NamespaceUnloadStrategy-Fehlermeldung #21880 – Leere Konten nicht aufgrund von Inaktivität übertragen #21893 – Nachrichten entsprechend der Ledger-Schließzeit ablaufen lassen, um client-Uhrzeitversatz zu vermeiden #21940 – Behebung eines Problems, bei dem der Reader beim Lesen aus einem komprimierten Thema mit deaktiviertem Lesekompaktmodus hängen bleibt #21969

Client

– Behebung eines Problems, bei dem Multi-Themen-Konsumenten nach der Suche alte Nachrichten erhalten konnten #21945 – Behebung eines stillen Hängenbleibens von ConsumerBuilderImpl#subscribe bei Verwendung von pulsar-client:3.0.x mit jackson-annotations vor 2.12.0 #21985

Pulsar IO und Pulsar-Funktionen

  • [FN] Konfiguration für Connector- und Funktionspaket-URL-Quellen hinzugefügt #22184 – [FN] Fehlendes „Ausnahme“-Argument zu einigen Protokollfehlern hinzugefügt #22140 – [FN] Verhindert, dass Putstate leere Werte verwendet #22127 – [FN] Optimieren Sie den Start von Function Worker durch Lazy Loading und direkten ZIP-/Bytecode-Zugriff #22122 – [FN] Verhindert das Erstellen einer Statustabelle aus API-Aufrufen für nicht vorhandene Instanzen #22107 – [FN] Verwenden Sie den einheitlichen Paketverwaltungsdienst, um Pakete herunterzuladen #21955

CLI

– [Admin] Legen Sie den Offload-Schwellenwert in Sekunden für den Administrator offen #22101 – [CLI] Beheben Sie den Fehler, wenn die Set-Retention-Größe mit -T angegeben wurde #22150 – [CLI] Fehler, wenn „--destinationBroker“ gesetzt ist, wenn „--bundle“ leer ist #21879

Andere

  • [MISC] Fügen Sie eine Prüfung für den Eingabezeitwert hinzu #22023 – [Proxy] Fügen Sie eine Prüfung für „brokerServiceURL“ hinzu, die noch keine Multi-URI unterstützt #21972
  • [TX] Vorherige Position durch verwaltetes Hauptbuch abrufen #22024
  • [ML] Wiederholungsmechanismus zum Löschen von Ledgern korrigiert, um #21869 ungültig zu machen
  • [ML] Gelöschte Einträge herausfiltern, bevor Einträge aus dem Hauptbuch gelesen werden #21739

Bibliotheksaktualisierungen

– Aktualisieren Sie Jetty auf 9.4.54.v20240208, um CVE-2024-22201 #22144 zu beheben.

  • Upgrade von commons-compress auf 1.26.0 #22086 – Upgrade der BookKeeper-Abhängigkeit auf 4.16.4 #21983

Ein besonderer Dank geht an die folgenden Mitwirkenden, die zu Pulsar 3.2.1 beigetragen haben: mattisonchao, lhotari, armbarcode, Technoboy-, jiangpengcheng, dragosvictor, freeznet, liangyepianzhou, heesung-sn, zymap, massakam, thetumbled, BewareMyPower, chenhongSZ, Shawyeok, hangc0276, 315157973, coderzc, dao-jun.

Englisches Original / English original

pulsar v3.2.1

Broker

  • Consistently add fine-grain authorization to REST API #22202
  • Add fine-grain authorization to retention admin API #22163
  • Print non log when delete partitioned topic failed #22153
  • Fix broker not starting when both transactions and the Extensible Load Manager are enabled #22139
  • Return getOwnerAsync without waiting on source broker upon Assigning and Releasing and handle role change during role init #22112
  • Cache the internal writer when sent to system topic. #22099
  • Enabling batch causes negative unackedMessages due to ack and delivery concurrency #22090
  • Support running docker container with gid != 0 #22081
  • Add an error log to troubleshoot the failure of starting broker registry #22065
  • Set ServiceUnitStateChannel topic compaction threshold explicitly, improve getOwnerAsync, and fix other bugs #22064
  • Fix hash collision when using a consumer name that ends with a number #22053
  • Sanitize values before logging in apply-config-from-env.py script #22044
  • Fix can not subscribe partitioned topic with a suffix-matched regexp #22025
  • Do not retain the data in the system topic #22022
  • Subscription stuck due to called Admin API analyzeSubscriptionBacklog #22019
  • Do not try to open ML when the topic meta does not exist and do not expect to create a new one #22004
  • Do not print an Error log when responding to HTTP-404 when calling Admin API and the topic does not exist #21995
  • Do not close the socket if lookup failed due to LockBusyException #21993
  • Support setting autoSkipNonRecoverableData dynamically in PersistentMessageExpiryMonitor #21991
  • Add timeout for health check read #21990
  • Fix schema deletion error when deleting a partitioned topic with many partitions and schema #21977
  • Defer the ownership checks if the owner is inactive (ExtensibleLoadManager) #21811
  • Fix compaction/replication data loss when expire messages #21865
  • Skip loading the NAR packages if not configured #21867
  • Improve NamespaceUnloadStrategy error message #21880
  • Don't rollover empty ledgers based on inactivity #21893
  • Expire messages according to ledger close time to avoid client clock skew #21940
  • Fix reader stuck when read from compacted topic with read compact mode disable #21969

Client

  • Fix multi-topics consumer could receive old messages after seek #21945
  • Fix ConsumerBuilderImpl#subscribe silent stuck when using pulsar-client:3.0.x with jackson-annotations prior to 2.12.0 #21985

Pulsar IO and Pulsar Functions

  • [FN] Add configuration for connector & functions package url sources #22184
  • [FN] Add missing "exception" argument to some log.error #22140
  • [FN] Prevent putstate uses empty values #22127
  • [FN] Optimize Function Worker startup by lazy loading and direct zip/bytecode access #22122
  • [FN] Prevent create state table from API calls for non-exists instances #22107
  • [FN] Use unified PackageManagement service to download packages #21955

CLI

  • [Admin] Expose the offload threshold in seconds to the admin #22101
  • [CLI] Fix the bug when set-retention specified size with -T #22150
  • [CLI] Error out when --destinationBroker is set when --bundle is empty #21879

Others

  • [MISC] Add a check for the input time value #22023
  • [Proxy] Add a check for brokerServiceURL that does not support multi uri yet #21972
  • [TX] Get previous position by managed ledger #22024
  • [ML] Fix retry mechanism of deleting ledgers to invalidate #21869
  • [ML] Filter out deleted entries before read entries from ledger #21739

Library updates

  • Upgrade Jetty to 9.4.54.v20240208 to address CVE-2024-22201 #22144
  • pgrade commons-compress to 1.26.0 #22086
  • Upgrade BookKeeper dependency to 4.16.4 #21983

A special thanks to the following contributors who contributed to Pulsar 3.2.1: mattisonchao, lhotari, poorbarcode, Technoboy-, jiangpengcheng, dragosvictor, freeznet, liangyepianzhou, heesung-sn, zymap, massakam, thetumbled, BewareMyPower, chenhongSZ, Shawyeok, hangc0276, 315157973, coderzc, dao-jun.
