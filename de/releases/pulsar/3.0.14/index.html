Pulsar v3.0.14

27.09.2025

Bibliotheksaktualisierungen

– [fix][sec] Aktualisieren Sie die bcpkix-fips-Version von bouncycastle auf 1.79, um CVE-2025-8916 zu beheben (#24650) – [fix][sec] Upgrade von Netty auf 4.1.127.Final, um CVEs zu adressieren (#24717) – [fix][sec] Upgrade auf Netty 4.1.124.Final zur Behebung von CVE-2025-55163 (#24637)

  • [verbessern][build] Bump org.apache.commons:commons-lang3 von 3.17.0 auf 3.18.0 (#24514)
  • [improve][io] Upgrade der Versionen AWS SDK v1 & v2, Kinesis KPL und KPC (#24661)
  • [fix][misc] Abhängigkeiten aktualisieren, um kritische Sicherheitslücken zu schließen (#24532)
  • [verbessern][bauen] Lombok auf 1.18.42 aktualisieren, um JDK25 vollständig zu unterstützen (#24763)

Makler

– [Fix][Broker] Doppelprüfung für die Erstellung nicht dauerhafter Cursor hinzugefügt (#24643) – [fix][broker] Stellen Sie sicher, dass der KeyShared-Sticky-Mode-Consumer die zugewiesenen Bereiche respektiert (#24730)

  • [Fix][Broker] Der erste Eintrag wird übersprungen, wenn NonDurableCursor geöffnet wird, während das gekürzte Hauptbuch den ersten Eintrag hinzufügt. (#24738) – [Fix][Broker] Fix konnte den Broker nicht ordnungsgemäß durch den Administrator api herunterfahren (#24731)
  • [fix][broker] Behebung einer doppelten Watcher-Registrierung nach SessionReestablished (#24621) – [fix][broker] Speicherverlust behoben, wenn Metriken in einem anderen Thread als FastThreadLocalThread aktualisiert werden (#24719) – [fix][broker] Race-Bedingung im MetadataStoreCacheLoader behoben, die inkonsistentes Cachen der AvailableBroker-Liste verursacht (#24639) – [fix][broker] Fix REST API, um Nachrichten an einfach partitionierte Themen zu erzeugen (#24450) – [fix][broker] Ungültiger regulärer Ausdruck in PulsarLedgerManager führt dazu, dass die ZK-Datenbenachrichtigung ignoriert wird (#23977) – [fix][broker] Verhindert unerwartete Recyclingfehler im Leserückruf des Dispatchers (#24741)
  • [fix][broker][branch-3.0] Korrigieren Sie falsche Backlog-Alter-Metriken, wenn die Markierungslöschposition auf ein gelöschtes Hauptbuch zeigt (#24518) (#24671) – [fix][broker][branch-3.0] NPE in ownBundlesCountPerNamespace beim ersten Bundle-Laden verhindern (#24758) – [fix][broker]Fix: Das Problem mit der fehlerhaften Version des Metadatenspeichers wurde nie wiederhergestellt, wenn eine umfangreiche Antwort von ZK einging (#24580) – [fix][ml]Fix EOFException nach aktiviertem Topic-Offloading (#24753) – [verbessern][Broker] Wählen Sie einen zufälligen Thread für ConsumerFlow in PersistentDispatcherSingleActiveConsumer (#20522)
  • [verbessern][Broker] Wenn es einen Deadlock im Dienst gibt, sollte der Test einen Fehler zurückgeben, da der Dienst möglicherweise nicht verfügbar ist (#23634)
  • [verbessern][Broker] Aggregation von Themenstatistiken optimieren und bereinigen (#21361)

Client

– [fix][client] Vermeiden Sie, dass das gleiche ConcurrentBitSetRecyclable zwischen verschiedenen Threads recycling wird (#24725) – [fix][client] korrigiert ArrayIndexOutOfBoundsException in SameAuthParamsLookupAutoClusterFailover (#24662)

  • [fix][client] Behebung der ArrayIndexOutOfBoundsException bei Verwendung von SameAuthParamsLookupAutoClusterFailover (#23336)
  • [fix][client] Automatische Skalierung der Empfängerwarteschlange ohne Speicherbegrenzung behoben (#24743)
  • [fix][client] Bei unbekannten Ausnahmen beim Erstellen eines Produzenten oder Konsumenten erneut versuchen (#24599) – [fix][client] Überspringen Sie die Schemavalidierung beim Senden von Nachrichten an DLQ, um eine Endlosschleife zu vermeiden, wenn die Schemavalidierung bei einer eingehenden Nachricht fehlschlägt (#24663) – [fix][client]Verhindern, dass ZeroQueueConsumer Batch-Nachrichten empfängt, wenn MessagePayloadProcessor verwendet wird (#24610)
  • [fix][client]TopicListWatcher wurde beim Aufruf der PatternMultiTopicsConsumerImpl.closeAsync()-Methode nicht geschlossen (#24698) – [fix][client] Rollback-TopicListWatcher-Wiederholungsverhalten (#24752)
  • [verbessern][client] Unterstützt das Laden des privaten RSA PKCS#8-Schlüssels (#24582)

Pulsar IO und Pulsar-Funktionen

  • [fix][io] Verbesserung der Kafka Connect-Source-Offset-Flushing-Logik (#24654)
  • [verbessern][io] Informationen zum Namen der Abhängigkeitsdatei zur Fehlermeldung hinzufügen, wenn die Validierung der .nar-Datei mit ZipException fehlschlägt (#24604)
  • [verbessern][io] Unterstützung für die Angabe des nativen Binärpfads von Kinesis KPL mit dem versionspezifischen Pfad 1.0 (#24669)

Andere

  • [fix][proxy] TooLongFrameException mit Pulsar Proxy beheben (#24626) – [Fix][Sonstiges] CompareTo-Vertragsverletzung für NamespaceBundleStats, TimeAverageMessageData und ResourceUnitRanking behoben (#24772)
  • [verbessern][doc] Verbessern Sie die JavaDocs von sendAsync, um eine missbräuchliche Verwendung zu vermeiden (#24601)
  • [fix][offload] Unnötige Abhängigkeiten von Tiered-Storage-Anbietern/Offloader-NAR-Dateien ausschließen (#24649)

Tests & CI

  • [verbessern][build] Verwenden Sie org.apache.nifi:nifi-nar-maven-plugin:2.1.0 mit skipDocGeneration=true (#24668)
  • [fix][ci] Codeabdeckungsmetriken in Pulsar CI korrigiert (#24595)
  • [fix][test] ConcurrentModificationException in Ipv4Proxy beheben (#24632)
  • [fix][test] Flaky-Test: BrokerServiceTest.testShutDownWithMaxConcurrentUnload (#24769)
  • [fix][test]fixiert den flockigen ZeroQueueSizeTest.testZeroQueueGetExceptionWhenReceiveBatchMessage (#24633)
  • [fix][test]fixiert den flockigen ZeroQueueSizeTest.testZeroQueueGetExceptionWhenReceiveBatchMessage (#24630)
  • [fix][broker] Behebung des fehlerhaften testReplicatorsInflightTaskListIsEmptyAfterReplicationFinished (#24590)
  • [verbessern][build] Javadoc-Build-Fehler deaktivieren (#24594)
  • [verbessern][build] Erhöhen Sie das Zeitlimit für den Synchronisierungskontext des Maven-Resolvers (#24666)
  • [verbessern][test] Test für unzustellbare Nachrichten mit Blockierung der maximalen Anzahl nicht gepackter Nachrichten hinzufügen (#24535)
  • [verbessern][testen] Refaktorieren Sie die Art und Weise, wie die Pulsar-io-debezium-oracle-NAR-Datei gepatcht wird, wenn das Testbild erstellt wird (#24586)
  • [fix][build] Import isNotBlank
  • [fix][ci] CI für Java 25 korrigiert, einschließlich Upgrade der Gradle Develocity Maven-Erweiterung (#24767) Die vollständige Liste finden Sie im vollständigen changelog.

pulsar v3.0.14

2025-09-27

Library updates

  • [fix][sec] Upgrade bouncycastle bcpkix-fips version to 1.79 to address CVE-2025-8916 (#24650)
  • [fix][sec] Upgrade Netty to 4.1.127.Final to address CVEs (#24717)
  • [fix][sec] Upgrade to Netty 4.1.124.Final to address CVE-2025-55163 (#24637)
  • [improve][build] Bump org.apache.commons:commons-lang3 from 3.17.0 to 3.18.0 (#24514)
  • [improve][io] Upgrade AWS SDK v1 & v2, Kinesis KPL and KPC versions (#24661)
  • [fix][misc] Upgrade dependencies to fix critical security vulnerabilities (#24532)
  • [improve][build] Upgrade Lombok to 1.18.42 to fully support JDK25 (#24763)

Broker

  • [fix][broker] Add double-check for non-durable cursor creation (#24643)
  • [fix][broker] Ensure KeyShared sticky mode consumer respects assigned ranges (#24730)
  • [fix][broker] First entry will be skipped if opening NonDurableCursor while trimmed ledger is adding first entry. (#24738)
  • [fix][broker] Fix cannot shutdown broker gracefully by admin api (#24731)
  • [fix][broker] Fix duplicate watcher registration after SessionReestablished (#24621)
  • [fix][broker] Fix memory leak when metrics are updated in a thread other than FastThreadLocalThread (#24719)
  • [fix][broker] Fix race condition in MetadataStoreCacheLoader causing inconsistent availableBroker list caching (#24639)
  • [fix][broker] Fix REST API to produce messages to single-partitioned topics (#24450)
  • [fix][broker] Invalid regex in PulsarLedgerManager causes zk data notification to be ignored (#23977)
  • [fix][broker] Prevent unexpected recycle failure in dispatcher's read callback (#24741)
  • [fix][broker][branch-3.0] Fix wrong backlog age metrics when the mark delete position point to a deleted ledger (#24518) (#24671)
  • [fix][broker][branch-3.0] Prevent NPE in ownedBundlesCountPerNamespace on first bundle load (#24758)
  • [fix][broker]Fix never recovered metadata store bad version issue if received a large response from ZK (#24580)
  • [fix][ml]Fix EOFException after enabled topics offloading (#24753)
  • [improve][broker] Choose random thread for consumerFlow in PersistentDispatcherSingleActiveConsumer (#20522)
  • [improve][broker] If there is a deadlock in the service, the probe should return a failure because the service may be unavailable (#23634)
  • [improve][broker] Optimize and clean up aggregation of topic stats (#21361)

Client

  • [fix][client] Avoid recycling the same ConcurrentBitSetRecyclable among different threads (#24725)
  • [fix][client] fix ArrayIndexOutOfBoundsException in SameAuthParamsLookupAutoClusterFailover (#24662)
  • [fix][client] Fix ArrayIndexOutOfBoundsException when using SameAuthParamsLookupAutoClusterFailover (#23336)
  • [fix][client] Fix receiver queue auto-scale without memory limit (#24743)
  • [fix][client] Retry for unknown exceptions when creating a producer or consumer (#24599)
  • [fix][client] Skip schema validation when sending messages to DLQ to avoid infinite loop when schema validation fails on an incoming message (#24663)
  • [fix][client]Prevent ZeroQueueConsumer from receiving batch messages when using MessagePayloadProcessor (#24610)
  • [fix][client]TopicListWatcher not closed when calling PatternMultiTopicsConsumerImpl.closeAsync() method (#24698)
  • [fix][client] rollback TopicListWatcher retry behavior (#24752)
  • [improve][client] Support load RSA PKCS#8 private key (#24582)

Pulsar IO and Pulsar Functions

  • [fix][io] Improve Kafka Connect source offset flushing logic (#24654)
  • [improve][io] Add dependency file name information to error message when .nar file validation fails with ZipException (#24604)
  • [improve][io] Support specifying Kinesis KPL native binary path with 1.0 version specific path (#24669)

Others

  • [fix][proxy] Fix TooLongFrameException with Pulsar Proxy (#24626)
  • [fix][misc] Fix compareTo contract violation for NamespaceBundleStats, TimeAverageMessageData and ResourceUnitRanking (#24772)
  • [improve][doc] Improve the JavaDocs of sendAsync to avoid improper use (#24601)
  • [fix][offload] Exclude unnecessary dependencies from tiered storage provider / offloader nar files (#24649)

Tests & CI

  • [improve][build] Use org.apache.nifi:nifi-nar-maven-plugin:2.1.0 with skipDocGeneration=true (#24668)
  • [fix][ci] Fix code coverage metrics in Pulsar CI (#24595)
  • [fix][test] Fix ConcurrentModificationException in Ipv4Proxy (#24632)
  • [fix][test] Flaky-test: BrokerServiceTest.testShutDownWithMaxConcurrentUnload (#24769)
  • [fix][test]fix flaky ZeroQueueSizeTest.testZeroQueueGetExceptionWhenReceiveBatchMessage (#24633)
  • [fix][test]fix flaky ZeroQueueSizeTest.testZeroQueueGetExceptionWhenReceiveBatchMessage (#24630)
  • [fix][broker] Fix flaky testReplicatorsInflightTaskListIsEmptyAfterReplicationFinished (#24590)
  • [improve][build] Disable javadoc build failure (#24594)
  • [improve][build] Increase maven resolver's sync context timeout (#24666)
  • [improve][test] Add test for dead letter topic with max unacked messages blocking (#24535)
  • [improve][test] Refactor the way way pulsar-io-debezium-oracle nar file is patched when building the test image (#24586)
  • [fix][build] Import isNotBlank
  • [fix][ci] Fix CI for Java 25 including upgrade of Gradle Develocity Maven extension (#24767)

For the complete list, check the full changelog.
