Pulsar v3.3.2

04.10.2024

Bibliotheksaktualisierungen

– [fix][sec] Avro auf 1.11.4 aktualisieren, um CVE-2024-47561 zu beheben (#23394) – [fix][sec] Vertx auf 4.5.10 aktualisieren, um CVE-2024-8391 zu beheben (#23338)

  • [fix][sec][branch-3.3] Upgrade von protobuf-java auf 3.25.5 (#23356) (#23358)
  • [verbessern][Verschiedenes] Upgrade von Netty auf 4.1.113 und netty-tcnative auf 2.0.66 (#23255)
  • [Fix] Bump commons-io:commons-io von 2.8.0 auf 2.14.0 (#23393)
  • [Fix] Erhöhung von io.grpc von 1.56.0 auf 1.56.1 (#23276)
  • [fix][metadata] Oxia auf 0.3.2 aktualisieren (#23140)
  • [feat][meta] Bump Oxia Java-Version von 0.3.2 auf 0.4.5 (#23277)
  • [verbessern] Aktualisieren Sie Pulsar Python client im docker-Bild auf 3.5.0 (#23377)
  • [verbessern] OpenSSL im docker-Image installieren, um die Kompatibilität mit dem Apache Pulsar Helm-Chart zu beheben (#23362)

Makler

– [fix][broker] Mögliches ausstehendes Replay-Lesen in cancelPendingRead abbrechen (#23384) – [Fix][Broker] Führen Sie die ausstehenden Rückrufe der Reihe nach aus, bevor Sie für eingehende Anfragen bereit sind (#23266) – [Fix][Broker] Schneller Fehler, wenn der erweiterbare Lademanager nicht gestartet werden konnte (#23297)

  • [fix][broker] Behebung der Logik und Protokollierung des Controllers für replizierte Abonnements (#23142)
  • [fix][broker] Authentifizierungsreihenfolge in AuthenticationProviderList korrigiert (#23111) – [fix][broker] Fix-Broker versuchen immer noch, die Replikation zu starten, nachdem das Thema geschlossen wurde (#23237)
  • [fix][broker] Kompatibilitätsprobleme für PIP-344 behoben (#23136)
  • [fix][broker] Behebung einer unvollständigen NAR-Dateiextraktion, die den Start des Brokers verhindert (#23274) – [fix][broker] Behebung von Out-of-Order-Problemen mit ConsistentHashingStickyKeyConsumerSelector (#23327) – [fix][broker] Fixschattenthemen können nicht genutzt werden, wenn der Eintrag nicht zwischengespeichert ist (#23147) – [fix][broker] Fix-Systemthema kann nicht geladen werden, wenn es ausgelagerte Daten enthält (#23279) – [fix][broker] Behebung, dass die Broker-Registrierung nach dem Löschen des Metadatenknotens nicht wiederhergestellt werden kann (#23359)
  • [fix][broker] Behebung des Fehlers, dass der gewählte Anführer glaubt, er sei ein Gefolgsmann (#23138) – [fix][broker] Behandelt den Fall, wenn getOwnedServiceUnits ordnungsgemäß fehlschlägt (#23119) – [fix][broker] Interner Reader von __change_events kann nach der Neuerstellung der Metadatenspeichersitzung nicht gestartet werden (#23018) – [Fix][Broker] Der Handler für ausstehende Bestätigungen kann die Initialisierung erneut versuchen, wenn ein Metadatenspeicherfehler auftritt (#23153)
  • [fix][broker] Vorlesen von Einträgen aus geschlossenem Cursor überspringen. (#22751) – [Fix][Broker] Das Thema kann nie geladen werden, da der Broker eine fehlgeschlagene Themenerstellung in der Zukunft verwaltet (#23184) – Die [fix][Broker]-Fix-Ausnahme wird möglicherweise ausgeblendet und bleibt beim Laden des Themas hängen (#23102) – [Fix][Broker] Fix Pulsar-Admin-Themen Stats-internal verursachte einen Deadlock eines BK client-Threads (#23258) – [Fix][Broker] korrigiert den Filter für replizierte Namespaces in filterAndUnloadMatchedNamespaceAsync (#23100)
  • [Fix][Broker]-Typumwandlung bei Ausnahmen kann in Ausnahmefällen zu verlorenen Anrufen führen (#23117)
  • [fix][broker]Eine ausgefallene Consumer/Producer-Zukunft in ServerCnx kann niemals entfernt werden (#23123)
  • [verbessern][Broker] msgInReplay-Abonnementstatistik und -Metrik hinzufügen, um die Beobachtbarkeit von Key_Shared zu verbessern (#23224) – [verbessern][Broker] Wiederholung für Start-Service-Unit-Statuskanal hinzufügen (nur ExtensibleLoadManagerImpl) (#23230) – [verbessern][Broker] Vermeiden Sie nach Möglichkeit Abonnement-Fenced-Fehler mit Consumer.seek (#23163)
  • [verbessern][Broker] LB-interne Themen explizit schließen, wenn ein Follower abgespielt wird (nur ExtensibleLoadManagerImpl) (#23144)
  • [verbessern][Broker] Verbessern Sie die Metrik pulsar_topic_load_failed, um die korrekte Fehlerzeit aufzuzeichnen (#23199)
  • [verbessern][Broker] Optimieren Sie die hohe CPU-Auslastung bei der Nutzung von Themen mit laufender Übertragung (#23189)
  • [verbessern][Broker] Optimieren Sie den Nachrichtennutzlastverkehr für ShadowReplicator (#23236)
  • [verbessern][Broker] Optimieren Sie die Leistung für die Überprüfung der maximalen Themen, wenn das Thema ein Systemthema ist (#23185)
  • [verbessern][Broker] Optimieren Sie die Leistung einzelner Bestätigungen (#23072) – [verbessern][Broker] Registrieren Sie den Broker im Metadatenspeicher ohne Versions-ID-Vergleich (#23298) – [verbessern][Broker] Sollte das OnLoad-Ereignis des Bundle-Besitz-Listeners benachrichtigen, wenn ServiceUnitState gestartet wird (nur ExtensibleLoadManagerImpl) (#23152)
  • [verbessern][Broker] Unterstützt benutzerdefinierte Shadow-Managed-Ledger-Implementierung (#23179) – [verbessern][Broker] Unterstützung für die Angabe von Authentifizierungs-Plugin, Authentifizierungsparametern und TLS-Aktivierungsargumenten beim Init-Cluster-Metadaten (#23087)
  • [verbessern][Broker] Methode getAvailableBrokersAsync wiederverwenden (#23099)
  • [verbessern][admin] PIP-369 unload-Flag in ns-isolation-policy set-Aufruf einführen (#23120)
  • [Fix] StatsOutputStream: String-Schreibfunktion hinzufügen (#23227)

Client

  • [Fix] DLQ zur korrekten Handhabung des Byteschlüssels (#23172)
  • [fix][client] Bestellschlüssel kopieren, um Briefthema und DLQ-Nachrichten erneut zu versuchen und Fehler beim Kopieren beheben (#23182)
  • [fix][client] Erstellen Sie den Wiederholungsproduzenten asynchron (#23157)
  • [fix][client] Fix für Early Hit beforeConsume für MultiTopicConsumer (#23141)
  • [fix][client] Timeout-Behandlung in Pulsar Admin client behoben (#23128)
  • [Fix][client] TransactionCoordinatorClient unterstützt Wiederholungsversuch (#23081) – [fix][client] der Nullwert in msgMetadata sollte standardmäßig wahr sein (#22372)
  • [verbessern][client] MaxConnectionsPerHost und ConnectionMaxIdleSeconds zu PulsarAdminBuilder hinzufügen (#22541)
  • [verbessern][client] Infoprotokolle nicht für jedes von client geladene Schema drucken (#23206)
  • [verbessern][client] Neue ServiceUrlProvider-Implementierung hinzufügen: SameAuthParamsAutoClusterFailover (#23129)

Pulsar IO und Pulsar-Funktionen

  • [fix][io] Upgrade des MSSQL-Server-Tags docker in DebeziumMsSqlContainer (#23318) – [verbessern][fn] Unterstützung für das Überschreiben von „additionalJavaRuntimeArguments“ mit der Umgebung „PF_additionalJavaRuntimeArguments“ hinzugefügt (#23130)

Andere

– [fix][log] Fehlerprotokoll nicht drucken, wenn Mandant/Namespace beim Aufruf von get topic metadata nicht vorhanden ist (#23291)

  • [fix][log] Warnprotokoll nicht drucken, wenn gleichzeitig Ledger veröffentlicht und gewechselt werden (#23209)
  • [feat] Skripte zum Aktualisieren von BK RocksDB-INI-Dateien hinzufügen (#23178) – [fix][meta] Oxia-Metadatenspeicher: Konvertierungsfehler in MetadataStoreException, wenn der Vorgang fehlgeschlagen ist (#23154)
  • [fix][misc] Initialisierungswarnungen des Conscrypt-Sicherheitsanbieters auf Debug-Ebene protokollieren (#23364)
  • [verbessern][Verschiedenes] AES-GCM-Verschlüsselungsleistung verbessern (#23122) – [verbessern][Verschiedenes] TLS-Leistung optimieren, indem zusätzliche Pufferkopien weggelassen werden (#23115)
  • [verbessern][pip] PIP-366: Unterstützung für die Angabe unterschiedlicher Konfigurationen für die Konfiguration und den lokalen Metadatenspeicher (#23041)
  • [verbessern][Proxy] Authentifizierungsinstanz im Pulsar-Proxy wiederverwenden (#23113)

Tests & CI

  • [fix][test] Unzuverlässiges SubscriptionSeekTest.testSeekIsByReceive beheben (#23170)
  • [fix][test] Flaky UnloadSubscriptionTest.testMultiConsumer beheben (#23243)
  • [fix][test] Fehlerhafte Tests LeaderElectionTest.revalidateLeaderWithinSameSession behoben (#22383)
  • [fix][test] Behoben, dass viele Tests von Pulsar-Proxy nicht ausgeführt wurden (#23118)
  • [fix][build] Problem behoben, bei dem git.commit.id.abbrev beim Bild-Tagging fehlt (#23337)
  • [fix][build] Entfernen Sie unnötiges Oracle-Maven-Repository aus pom.xml (#23132)
  • [verbessern][build] Amazoncorretto:21-alpine-Image anstelle der APK-Installation verwenden (#22973)
  • [verbessern][ci] Wechsel zu Java 21 als Standard-JVM-Version für CI (#23373) Die vollständige Liste finden Sie im vollständigen changelog.

pulsar v3.3.2

2024-10-04

Library updates

  • [fix][sec] Upgrade Avro to 1.11.4 to address CVE-2024-47561 (#23394)
  • [fix][sec] Upgrade vertx to 4.5.10 to address CVE-2024-8391 (#23338)
  • [fix][sec][branch-3.3] Upgrade protobuf-java to 3.25.5 (#23356) (#23358)
  • [improve][misc] Upgrade Netty to 4.1.113 and netty-tcnative to 2.0.66 (#23255)
  • [fix] Bump commons-io:commons-io from 2.8.0 to 2.14.0 (#23393)
  • [fix] Bump io.grpc from 1.56.0 to 1.56.1 (#23276)
  • [fix][metadata] Upgrade Oxia to 0.3.2 (#23140)
  • [feat][meta] Bump oxia java version from 0.3.2 to 0.4.5 (#23277)
  • [improve] Upgrade Pulsar Python client in docker image to 3.5.0 (#23377)
  • [improve] Install openssl in the docker image to fix compatibility with Apache Pulsar Helm chart (#23362)

Broker

  • [fix][broker] Cancel possible pending replay read in cancelPendingRead (#23384)
  • [fix][broker] Execute the pending callbacks in order before ready for incoming requests (#23266)
  • [fix][broker] Fail fast if the extensible load manager failed to start (#23297)
  • [fix][broker] Fix 'Disabled replicated subscriptions controller' logic and logging (#23142)
  • [fix][broker] Fix authenticate order in AuthenticationProviderList (#23111)
  • [fix][broker] Fix brokers still retry start replication after closed the topic (#23237)
  • [fix][broker] Fix compatibility issues for PIP-344 (#23136)
  • [fix][broker] Fix incomplete NAR file extraction which prevents broker from starting (#23274)
  • [fix][broker] Fix out-of-order issues with ConsistentHashingStickyKeyConsumerSelector (#23327)
  • [fix][broker] Fix shadow topics cannot be consumed when the entry is not cached (#23147)
  • [fix][broker] Fix system topic can not be loaded up if it contains data offloaded (#23279)
  • [fix][broker] Fix the broker registery cannot recover from the metadata node deletion (#23359)
  • [fix][broker] Fix the bug that elected leader thinks it's a follower (#23138)
  • [fix][broker] Handle the case when getOwnedServiceUnits fails gracefully (#23119)
  • [fix][broker] Internal reader of __change_events can not started after metadata store session rebuilt (#23018)
  • [fix][broker] Let Pending ack handler can retry to init when encounters a metadata store error (#23153)
  • [fix][broker] Skip reading entries from closed cursor. (#22751)
  • [fix][broker] Topic can never be loaded up due to broker maintains a failed topic creation future (#23184)
  • [fix][broker] fix exception may hidden and result in stuck when topic loading (#23102)
  • [fix][broker] fix pulsar-admin topics stats-internal caused a BK client thread a deadlock (#23258)
  • [fix][broker] fix replicated namespaces filter in filterAndUnloadMatchedNamespaceAsync (#23100)
  • [fix][broker] type cast on exceptions in exceptionally can lead to lost calls (#23117)
  • [fix][broker]A failed consumer/producer future in ServerCnx can never be removed (#23123)
  • [improve][broker] Add msgInReplay subscription stat and metric to improve Key_Shared observability (#23224)
  • [improve][broker] Add retry for start service unit state channel (ExtensibleLoadManagerImpl only) (#23230)
  • [improve][broker] Avoid subscription fenced error with consumer.seek whenever possible (#23163)
  • [improve][broker] Explicitly close LB internal topics when playing a follower (ExtensibleLoadManagerImpl only) (#23144)
  • [improve][broker] Improve pulsar_topic_load_failed metric to record correct failed time (#23199)
  • [improve][broker] Optimize high CPU usage when consuming from topics with ongoing txn (#23189)
  • [improve][broker] Optimize message payload traffic for ShadowReplicator (#23236)
  • [improve][broker] Optimize performance for checking max topics when the topic is a system topic (#23185)
  • [improve][broker] Optimize the performance of individual acknowledgments (#23072)
  • [improve][broker] Register the broker to metadata store without version id compare (#23298)
  • [improve][broker] Should notify bundle ownership listener onLoad event when ServiceUnitState start (ExtensibleLoadManagerImpl only) (#23152)
  • [improve][broker] Support customized shadow managed ledger implementation (#23179)
  • [improve][broker] Support to specify auth-plugin, auth-parameters and tls-enable arguments when init cluster metadata (#23087)
  • [improve][broker] Reuse method getAvailableBrokersAsync (#23099)
  • [improve][admin] PIP-369 Introduce unload flag in ns-isolation-policy set call (#23120)
  • [fix] StatsOutputStream: add string write function (#23227)

Client

  • [fix] DLQ to handle bytes key properly (#23172)
  • [fix][client] Copy orderingKey to retry letter topic and DLQ messages and fix bug in copying (#23182)
  • [fix][client] Create the retry producer async (#23157)
  • [fix][client] Fix for early hit beforeConsume for MultiTopicConsumer (#23141)
  • [fix][client] Fix timeout handling in Pulsar Admin client (#23128)
  • [fix][client] TransactionCoordinatorClient support retry (#23081)
  • [fix][client] the nullValue in msgMetadata should be true by default (#22372)
  • [improve][client] Add maxConnectionsPerHost and connectionMaxIdleSeconds to PulsarAdminBuilder (#22541)
  • [improve][client] Don't print info logs for each schema loaded by client (#23206)
  • [improve][client] Add new ServiceUrlProvider implementation: SameAuthParamsAutoClusterFailover (#23129)

Pulsar IO and Pulsar Functions

  • [fix][io] Upgrade mssql server docker tag in DebeziumMsSqlContainer (#23318)
  • [improve][fn] Add support for overriding additionalJavaRuntimeArguments with PF_additionalJavaRuntimeArguments env (#23130)

Others

  • [fix][log] Do not print error log if tenant/namespace does not exist when calling get topic metadata (#23291)
  • [fix][log] Do not print warn log when concurrently publishing and switching ledgers (#23209)
  • [feat] Add scripts for updating BK RocksDB ini files (#23178)
  • [fix][meta] Oxia metadta store: Convert error to MetadataStoreException if operation failed (#23154)
  • [fix][misc] Log Conscrypt security provider initialization warnings at debug level (#23364)
  • [improve][misc] Improve AES-GCM cipher performance (#23122)
  • [improve][misc] Optimize TLS performance by omitting extra buffer copies (#23115)
  • [improve][pip] PIP-366: Support to specify different config for Configuration and Local Metadata Store (#23041)
  • [improve][proxy] Reuse authentication instance in pulsar-proxy (#23113)

Tests & CI

  • [fix][test] Fix flaky SubscriptionSeekTest.testSeekIsByReceive (#23170)
  • [fix][test] Fix flaky UnloadSubscriptionTest.testMultiConsumer (#23243)
  • [fix][test] Fix flaky test LeaderElectionTest.revalidateLeaderWithinSameSession (#22383)
  • [fix][test] Fixed many tests of pulsar-proxy are not running (#23118)
  • [fix][build] Fix problem where git.commit.id.abbrev is missing in image tagging (#23337)
  • [fix][build] Remove unnecessary Oracle maven repository from pom.xml (#23132)
  • [improve][build] Use amazoncorretto:21-alpine image instead of apk installation (#22973)
  • [improve][ci] Switch to Java 21 as default JVM version for CI (#23373)
