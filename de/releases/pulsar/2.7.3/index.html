Pulsar v2.7.3

Makler

  • Verspätete Nachrichten beheben. #11374
  • Fehlende Replikatormetriken beheben. #11264
  • Branch-2.7-Test behoben. #11254 – Behebung des Byteratenbegrenzers für den Broker-Versand #11249 – WebSocket-TLS-Fehler behoben #11243 – Init WebSocketService mit ClusterData behoben #11234 – Fix der Buch-Rollover-Scheduler-Aufgabe #11226 – Entfernen Sie den nicht verwendeten Listener, um die Erstellung eines Executor-Pools zu reduzieren #11215 – Machen Sie das Timeout der Komprimierungsphase eins konfigurierbar #11206
  • Behebung eines fehlgeschlagenen Authentifizierungstests. #11186 – Behebung des Deadlocks bei Verwendung von hasMessageAvailableAsync und readNextAsync #11183 – Fehler beim Lesen des Komprimierungseintrags behoben #11175 – Beim Multi-Topic-Consumer sollten wir die partitionierten Metadaten nicht ständig überprüfen #11168 – Behebung, dass die Meldung der Wiedergabethemenrichtlinie nicht funktioniert #11136
  • Behebung des Byteratenbegrenzers für den Broker-Versand. #11135 – Ändern Sie die Testgruppe in „Broker“ für ReplicatorTest und beheben Sie den Test #11134
  • Geplante Aufgabe zur Buchumstellung behoben #11116 – Race-Bedingung des SystemTopicBasedTopicPoliciesService behoben #11097 – Nachrichtenmetadaten drucken, wenn die Nachricht anhand der ID abgerufen wird #11092 – Flaky-Test testEnableAndDisableTopicDelayedDelivery #11009 behoben – Behebung möglicher Datenverluste im Systemthema, wenn die Themenkomprimierung noch nicht ausgelöst wurde #11003 – Direkten Speicherverlust in getLastMessageId #10977 beheben – Behebung des Backlog-Problems mit --precise-backlog=true #10966 – Behebung der NonRecoverableLedgerException beim Abrufen der letzten Nachrichten-ID durch den Leser #10957 – Behebung, dass die Komprimierung für das Systemthema #10941 nicht funktioniert. – Behebung eines Problems, bei dem Key_Shared-Konsumenten hängen bleiben konnten #10920 – Wenn der Replikator aktiviert ist, wird beim Aktualisieren der Anzahl der Partitionen kein ManagedLedger erstellt #10910 – Behandeln Sie die Erstellung mehrerer Themen für denselben Themennamen im Broker #10847
  • Geben Sie OpAddEntry.data frei, wenn der Eintrag kopiert und verworfen wird #10773 – Behebung des Problems, dass die Nachrichtenreihenfolge bei der erneuten Zustellung von Nachrichten im Key_Shared-Abonnement unterbrochen werden konnte #10762 – Lösung zur Verhinderung von Race-Bedingungen zwischen Timeout und Abschluss behoben #10740 – Abbrechen geplanter Aufgaben als erster Schritt beim Schließen #10739 – GERINGER: Fehlermeldung zu setMaxPendingMessagesAcrossPartitions hinzufügen #10709
  • Machen Sie PrometheusMetricsTest. testAuthMetrics gibt CI weiter #10699 – Behebung eines Problems, bei dem StackOverflowError auftritt, wenn versucht wird, eine große Anzahl bereits bestätigter Nachrichten erneut zuzustellen #10696
  • Zurücksetzen „Das Erstellen eines Themas wartet nicht auf das Erstellen des Cursors von Replikatoren“ #10674 – Einzelne Instanz des Parsers verwenden #10664 – Stellen Sie sicher, dass alle ReadHandle bei Cache-Ungültigmachung ordnungsgemäß geschlossen werden #10659 – Korrigieren Sie, dass ConcurrentOpenLongPairRangeSet alle Bereiche entfernt #10656 – TopicPoliciesTest.testMaxSubscriptionsFailFast schlägt fehl #10640 – Fügen Sie Metriken für den Bereich nicht zusammenhängender gelöschter Nachrichten hinzu #10638 – Fehlendes ZK-Caching beim Abrufen einer Liste von Namespaces für einen Mandanten behoben #10594 – OpAddEntry.toString() robuster gegenüber Nullen gemacht, um NPEs zu verhindern #10548 – Fehler bei der Themenprüfung bei partitionierten Systemen behoben #10529 – FailPendingMessages aus dem ProducerImpl-Objekt-Mutex aufrufen lassen #10528 – Deadlock im Überwachungsthread behoben, der durch LeaderService.isLeader() blockiert wurde #10512 – Fix: Das Laden des Themas schlägt ohne Fehler fehl, wenn die Replikator-Initialisierung fehlschlägt #10432 – Fix: hasMessageAvailable gibt „true“ zurück, kann die Nachricht jedoch nicht lesen #10414 – Weitere Komponententests zur JavaInstanceTest-Klasse hinzugefügt #10369 – Autorisierungsfehler behoben, wenn die Partitionsnummer des partitionierten Themas aktualisiert wird. #10333 – Behebung der Inkonsistenz von AdvertisedAddress #10312
  • Fehlenden LoggerFactoryPtr-Typ behoben. #10164 – Stellen Sie sicher, dass die Lesesperre nicht kontinuierlich für einen Abschnitt gehalten wird, während über gleichzeitige Karten iteriert wird #9787 – Zookeeper-Verbindungen überwachen Daten #9778 – Ändern Sie die getWorkerService-Methode, um UnsupportedOperationException #9738 auszulösen. – Fehlerhafte Unit-Tests behoben #9262 – Debug-Protokoll für OpAddEntry bereitstellen #9239

Abhängigkeits-Upgrade

  • Upgrade von Jetty auf 9.4.42.v20210604 #10907

Proxy

– Durch Proxy partitioniertes AutoTopicCreationType aktivieren #8048

Pulsar-Administrator

– Fix zum Erstellen eines partitionierten Themas im replizierten Namespace #11140 – Autorisierendes Flag für Themenrichtlinie hinzufügen, um Umleitungsschleife zu vermeiden #11131 – Fehler beim Abrufen partitionierter Metadaten für nicht persistente Themen bei der Erkennung behoben #10806 – Kinesis-Sink-Backoff-Klasse wurde nicht gefunden #10744 behoben

Docker

– K8s-Funktionsnamenlängenprüfung lässt ungültiges StatefulSet zu #10531

Client

  • [Java] Code in GenericJsonRecord #10527 bereinigt – [C++] Vermeiden Sie das Senden von Flow-Anfragen ohne Berechtigungen #10506

Funktionen und Pulsar IO

– Behebung eines Problems, bei dem der Kinesis-Sink-Connector keine Nachrichten bestätigt #10769 – Verweis auf ProducerSpec aus Pulsar Functions GO entfernen #10635 – Der asynchrone Prozess führt zu demselben ausführbaren Java-Thread #10618

pulsar v2.7.3

Broker

  • Fix Delayed Messages. #11374
  • Fix missing replicator metrics. #11264

  • Fix broker dispatch byte rate limiter #11249
  • Fix websocket TLS bug #11243
  • Fix init WebSocketService with ClusterData #11234
  • Fix ledger roll over scheduler task #11226
  • Remove unused listener to reduce creating executor pool #11215
  • Make the compaction phase one loop timeout configurable #11206
  • Fix failing auth test. #11186
  • Fix the dead lock when using hasMessageAvailableAsync and readNextAsync #11183
  • Fix compaction entry read exception #11175
  • On multi-topic consumer, we shouldn't keep checking the partitioned metadata #11168
  • Fix replay topic policy message not work #11136
  • Fix broker dispatch byte rate limiter. #11135
  • Change test group to broker for ReplicatorTest and fix the test #11134
  • Fix ledger rollover scheduled task #11116
  • Fix race condition of the SystemTopicBasedTopicPoliciesService #11097
  • Print message metadata when getting message by id #11092
  • Fix flaky test testEnableAndDisableTopicDelayedDelivery #11009
  • Fix potential data lost on the system topic when topic compaction has not triggered yet #11003
  • Fix direct memory leak in getLastMessageId #10977
  • Fix the backlog issue with --precise-backlog=true #10966
  • Fix NonRecoverableLedgerException when get last message ID by Reader #10957
  • Fix compaction not working for system topic #10941
  • Fix issue where Key_Shared consumers could get stuck #10920
  • When the Replicator is enabled, no managedLedger is created when updating the number of partitions #10910
  • Handle multiple topic creation for the same topic-name in broker #10847
  • Release OpAddEntry.data when entry is copied and discarded #10773
  • Fix issue that message ordering could be broken when redelivering messages on Key_Shared subscription #10762
  • Fix solution for preventing race conditions between timeout and completion #10740
  • Cancel scheduled tasks as the first step in closing #10739
  • MINOR: Add error message to setMaxPendingMessagesAcrossPartitions #10709
  • Make PrometheusMetricsTest. testAuthMetrics pass on CI #10699
  • Fix issue where StackOverflowError occurs when trying to redeliver a large number of already acked messages #10696
  • Revert "Creating a topic does not wait for creating cursor of replicators" #10674
  • Use single instance of parser #10664
  • Ensure all the ReadHandle gets properly closed on cache invalidation #10659
  • Fix ConcurrentOpenLongPairRangeSet remove all ranges #10656
  • TopicPoliciesTest.testMaxSubscriptionsFailFast fails #10640
  • Add metrics for non-contiguous deleted messages range #10638
  • Fixed missed ZK caching when fetching a list of namespaces for a tenant #10594
  • Made OpAddEntry.toString() more robust to nulls to prevent NPEs #10548
  • Fix partitioned system topic check bug #10529
  • Make failPendingMessages called from within the ProducerImpl object mutex #10528
  • Fix deadlock on Monitoring thread blocked by LeaderService.isLeader() #10512
  • Fix: Topic loading fails without any error when replicator init fails #10432
  • Fix hasMessageAvailable return true but can't read message #10414
  • Added more unit tests to the JavaInstanceTest class #10369
  • Fix authorization error if partition number of partitioned topic is updated. #10333
  • Fix the inconsistency of AdvertisedAddress #10312
  • Fix missing LoggerFactoryPtr type. #10164
  • Ensure read-lock is not continuously held on a section while iterating over concurrent maps #9787
  • Zookeeper connections monitor data #9778
  • Change getWorkerService method to throw UnsupportedOperationException #9738
  • Fix flaky unit test #9262
  • Supply debug log for OpAddEntry #9239
