Nanobot v0.2.0

🐈 Nanobot v0.2.0 ist da 🎉 – 105 PRs zusammengeführt, 20 neue Mitwirkende. Der Agent hat gelernt, ein Ziel zu halten. Die Überschrift lautet /goal. Markieren Sie einen Thread mit long_task als dauerhaftes Ziel, und das aktive Ziel bleibt in jeder Runde im Laufzeitkontext angeheftet – übersteht die Komprimierung, überlebt lange Werkzeugketten, überlebt die eigene Vergesslichkeit des Modells – bis Sie complete_goal aufrufen. Das Timeout der Wanduhr verlängert sich automatisch, während ein Ziel aktiv ist; Streaming-Anfragen fallen auf ein Leerlauf-Timeout statt auf eine harte Wand zurück, sodass ein Modell, das immer noch denkt, nicht mitten im Denken getötet wird. Die zweite Geschichte ist das Erwachsenwerden der WebUI. Nach mehreren Veröffentlichungen als reine Quellvorschau wird es jetzt im Rad ausgeliefert – pip install nanobot-ai und Sie haben es. Einstellungen und BYOK wurden komplett neu gestaltet, die Slash-Palette wurde lokalisiert, der LAN-Zugriff wird durch ein Token gesperrt, Begründungsströme werden live in den Chat übertragen und ein brandneues Tool zur Bildgenerierung verwandelt „Draw Me X“ in eine Inline-Vorschau, ohne die Konversation zu verlassen. Die dritte Etage ist der Maschinenraum. Die Agentenschleife erhielt eine echte Umgestaltung – AgentLoop.from_config() für saubere Einbettung, _process_message wurde als funktionale Zustandsmaschine umgeschrieben, archivierte Zusammenfassung wurde in die Systemeingabeaufforderung für KV-Cache-Stabilität verschoben, Tools wurden in eine selbstbeschreibende Plugin-Architektur umgewandelt, ask_user und GlobTool wurden zugunsten saubererer Ersetzungen eingestellt. Fünf neue Anbieter (AWS Bedrock Converse, NVIDIA NIM, LongCat, Atomic Chat, MiMo) schließen sich dem Angebot an, mit fallback_models als Sicherheitsnetz, damit ein einzelner schwankender Endpunkt keinen Ausfall verkraften kann. Plus vier [security]-Korrekturen – SSRF, Medienpfadbeschränkung, weichere Arbeitsbereichsgrenzen – und Chat-natives Pairing, damit DM-Genehmigungen endlich im Chat statt in einer Konfigurationsdatei erfolgen.

Highlights

  • /goal und lang laufende Aufgaben – Agent mit einer Erinnerung an warum – Das neue long_task-Tool, gepaart mit /goal und complete_goal, markiert einen Thread als dauerhaftes Ziel. Das aktive Ziel wird in jeder Runde im Laufzeitkontext gespiegelt, sodass der Agent auch nach der Komprimierung verankert bleibt, die WebUI das Ziel im Chat-Header anzeigt und das LLM-Wall-Timeout automatisch erweitert wird, während ein Ziel aktiv ist, sodass längere Argumentationsdurchgänge nicht mitten im Gedanken abgebrochen werden. Sowohl Kernagenten als auch Unteragenten berücksichtigen das längere Budget; Streaming-Anfragen greifen auf ein Leerlauf-Timeout statt auf eine harte Wanduhr zurück, sodass ein Modell, das noch Token ausgibt, nicht vorzeitig abgeschaltet wird. (#3788, #3855)
  • Bildgenerierung, End-to-End – Mit einem neuen Bildgenerierungstool und einem WebUI-Bildmodus können Sie von der Eingabeaufforderung zum Bild wechseln, ohne den Chat zu verlassen. Erzeugte Bilder werden inline mit abgerundeten Vorschauen gerendert; Replay-Window- und Dedup-Pfade wurden verschärft, damit Bilder bei langen Sitzungen nicht doppelt übermittelt werden, und der Konsolidierungsdurchlauf berücksichtigt jetzt das Replay-Fenster, wenn der Verlauf ausgeblendet wird. (#3695, #3687)
  • WebUI im Lieferumfang enthalten + ein Jahr lang Politur – pip install nanobot-ai bündelt jetzt die WebUI: Aktivieren Sie den WebSocket-Kanal, führen Sie nanobot gateway aus, öffnen Sie den Browser. Kein cd webui && bun run build erforderlich. Nach mehreren Veröffentlichungen unter dem Label „Vorschau“ ist die WebUI nun eine verpackte Oberfläche. Darin enthalten: neu gestaltete Einstellungen und BYOK-Fluss (einschließlich BYOK-Websuche), lokalisierte Slash-Palette, Modellvoreinstellungs-Badge, das über Slash-Befehle und Konfigurationsneuladungen hinweg synchron bleibt, gestreamte Argumentation, die live gerendert wird, Bildvorschauen, durch tokenIssueSecret gesperrter LAN-Zugriff, Standard-zu-neuer-Chat beim Laden, Scroll-Beibehaltung bei Rückkehr zu Einstellungen, ein crypto.randomUUID-Shim für LAN-Nutzung in nicht-sicherem Kontext und entferntes Eager-Markdown-Preload auf Reduzieren Sie die Kosten für den ersten Anstrich. (#3653, #3661, #3703, #3709, #3656, #3658, #3733, #3759, #3782)
  • Fünf neue Anbieter und ein Fallback-Sicherheitsnetz – Native AWS Bedrock Converse landet als erstklassiger Anbieter (#3574), mit einem Follow-up, das die Bedrock-Tool-Konfiguration über die gesamte Geschichte hinweg beibehält (#3758). NVIDIA NIM (#3707), LongCat über OpenAI-kompatibles Routing (#3114), Atomic Chat als lokales OpenAI-kompatibles Ziel (#3750) und MiMo mit richtiger Denk-Steuerungsverkabelung (#3734, #3851) runden das Angebot ab. Zusätzlich zum breiteren Stapel können Sie mit fallback_models sekundäre Modelle auflisten, die übernehmen, wenn das primäre ausfällt (#3756), der DeepSeek-Argumentationsverlauf wird zurückgefüllt statt gelöscht (#3616, #3560), Codex-Eingabeaufforderungs-Cache-Schlüssel werden stabilisiert (#3793) und Anthropic greift bei Fehlern bei langen Anfragen automatisch auf Streaming zurück (#3579).
  • Modellvoreinstellungen und Laufzeitwechsel – Mit ModelPresetConfig können Sie Modell- und Anbieterpakete in der Konfiguration benennen und zur Laufzeit über /model (oder das WebUI-Badge) zwischen ihnen wechseln. Voreinstellungen werden über Slash-Befehle, Konfigurationsneuladungen und Einstellungsänderungen hinweg synchronisiert, sodass das Modellabzeichen immer mit dem übereinstimmt, was in der nächsten Runde passieren wird. (#3714)
  • Kernrefaktor – eine sauberere Agentenschleife, eine kleinere Oberfläche – AgentLoop.from_config() zentralisiert die Schleifenassemblierung, sodass Einbetter nicht mehr in private Interna greifen (#3708). _process_message wurde als funktionale Zustandsmaschine mit expliziten Übergängen anstelle verschachtelter Zweige umgeschrieben (#3715). Die archivierte Konversationszusammenfassung wurde in die Systemeingabeaufforderung verschoben, um die KV-Caches über Komprimierungen hinweg stabil zu halten (#3711). Tools wurden zu einer selbstbeschreibenden Plugin-Architektur (#3729). ask_user wurde zugunsten der strukturierten message-Tool-Auswahlmöglichkeiten entfernt (#3757) und GlobTool wurde zugunsten der read_file-Glob-Unterstützung eingestellt (#3841). Der durch Vulture und Coverage verifizierte tote Code wurde herausgeschnitten (#3755, #3719). Die Protokollierung behält jetzt Tracebacks bei und überträgt den Kanalkontext (#3651, #3678). Ruff F-Regeln werden in CI vollständig durchgesetzt (#3672) und die Agent-Testsuite wurde erweitert und umstrukturiert (#3766). Die neuen CLAUDE.md- und .agent/-Anleitungen bieten KI-Mitwirkenden einen stabilen Einstieg (#3534, #3860).
  • Pairing, DM-Genehmigungen und Sicherheitsverstärkung – Chat-natives Pairing (#3774) ermöglicht es Ihnen, DMs aus dem Chat heraus zu genehmigen, anstatt die Konfiguration zu bearbeiten. Was die Sicherheit anbelangt: SSRF in ausgehenden DingTalk-Medien blockiert (#3569), von Feishu heruntergeladene Mediendateinamen auf sichere Pfade beschränkt (#3789), lokale Medienanhänge auf das Nachrichtentool beschränkt (#3842), SSRF-Guard-Wiederherstellung abgemildert, sodass ein vorübergehender Fehlschlag nachfolgende Runden nicht beeinträchtigt (#3635) und Arbeitsbereichsgrenzenverletzungen erhalten eine durch Wiederholungen gedrosselte Softwarnung, anstatt die Schleife zum Absturz zu bringen (#3614). Telegram ignoriert unbefugte Absender stillschweigend, anstatt Fehlerantworten preiszugeben (#3629).
  • Speicher, Traum und Sitzungsdauerhaftigkeit – Cron jobs.json erlangte atomare Schreibvorgänge mit der Erkennung korrupter Speicher (#3606). Der Dream-Cursor bewegt sich nur bei abgeschlossenen Stapeln weiter (#3631) und stellt den Speicherstatus beim Fortsetzen korrekt wieder her (#3660). Der im Wiedergabefenster ausgeblendete Verlauf wird jetzt ordnungsgemäß konsolidiert (#3687). Arbeitsbereichs- und Werkzeugstatusänderungen überstehen Neustarts zuverlässiger und durchgängig.
  • Kanal- und Plattformkorrekturen – Feishu-Gruppenthreads berücksichtigen Antwortketten und Themenisolation (#3547, #3704, #3747, #3775), Matrix überspringt Ereignisse vor dem Start und stoppt die Synchronisierungsschleife bei nicht wiederherstellbarer Authentifizierung (#3575, #3578), WhatsApp-Sprachnachrichten werden sauber heruntergeladen (#3607), Wecom behält echte Dateinamen bei (#3751), Telegram unterdrückt Unbefugte Absender (#3629) und Weixin meldet bei Sendefehlern eine Meldung, damit Nachrichten nicht stillschweigend gelöscht werden (#3659). Unter Windows: UNC-Pfadunterstützung bei der Shell-Extraktion (#3764). Auf dem CLI: Ersatzcodepunkte werden vor dem Nachrichtenbus bereinigt (#3697), Wiederholungswartenachrichten verfälschen die interaktive Ausgabe nicht mehr (#3705, #3609) und nanobot provider logout landet als richtiger Befehl (#3612).
  • Kleinere Dinge, die Sie spüren werden – Konfigurierbares bot_name / bot_icon (#3730), konfigurierbares toolHintMaxLength (#3641), echtes SSE-Streaming auf dem OpenAI-kompatiblen API wiederhergestellt (#3677), Wiederholungsversuche der Whisper-Transkription bei vorübergehenden Fehlern (#3646), sequenzieller MCP-Server verbindet sich, um CPU-Spin zu stoppen (#3640), MCP HTTP Probe vor der Verbindung (#3740), Brave-Such-Backoff unter Ratengrenzen (#3840), sender_id im Laufzeitkontext für benutzerbezogene Antworten (#3549), Laufzeitkontext, der nach Benutzerinhalten für Cache-Stabilität angehängt wird (#3844), origin_message_id ausgehende Deduplizierung (#3561) und ein Python SDK RunResult, das schließlich tools_used und offenlegt messages (#3620).

Gemeinschaft

Herzlichen Dank an alle, die v0.2.0 verschickt haben – 105 PRs, 33 Mitwirkende und ein großes Willkommen an 20 Erstmitwirkende. Jede Überprüfung, jeder Patch und jeder Fehlerbericht hat geholfen; Diese Veröffentlichung ist ein gemeinsamer Gewinn. 🎉

nanobot v0.2.0

🐈 nanobot v0.2.0 is here 🎉 — 105 PRs merged, 20 new contributors. The agent learned to hold a goal.

The headline is /goal. Mark a thread as a sustained objective with long_task, and the active goal stays pinned in Runtime Context every turn — surviving compaction, surviving long tool chains, surviving the model's own forgetfulness — until you call complete_goal. The wall-clock timeout widens automatically while a goal is active; streaming requests fall back to an idle timeout instead of a hard wall, so a model that's still thinking doesn't get killed mid-thought.

The second story is the WebUI growing up. After several releases as a source-only preview, it now ships inside the wheel — pip install nanobot-ai and you have it. Settings and BYOK got a full redesign, the slash palette is localized, LAN access is gated by a token, reasoning streams live to the chat, and a brand-new image-generation tool turns "draw me X" into an inline preview without leaving the conversation.

The third story is the engine room. The agent loop got a real refactor — AgentLoop.from_config() for clean embedding, _process_message rewritten as a functional state machine, archived summary moved into the system prompt for KV cache stability, tools converted to a self-describing plugin architecture, ask_user and GlobTool retired in favor of cleaner replacements. Five new providers (AWS Bedrock Converse, NVIDIA NIM, LongCat, Atomic Chat, MiMo) join the lineup with fallback_models as a safety net so a single flaky endpoint can't take a turn down. Plus four [security] fixes — SSRF, media path confinement, softer workspace boundaries — and chat-native pairing so DM approvals finally happen in the chat instead of in a config file.

Highlights

  • /goal and long-running tasks — agent with a memory of why — The new long_task tool, paired with /goal and complete_goal, marks a thread as a sustained objective. The active goal is mirrored in Runtime Context every turn so the agent stays anchored even after compaction, the WebUI surfaces the goal in the chat header, and the LLM wall timeout is automatically widened while a goal is active so longer reasoning passes don't get killed mid-thought. Core agents and subagents both honor the longer budget; streaming requests fall back to an idle timeout instead of a hard wall clock so a model that's still emitting tokens won't be prematurely cut off. (#3788, #3855)

  • Image generation, end to end — A new image-generation tool plus a WebUI image mode let you go from prompt to picture without leaving the chat. Generated images render inline with rounded previews; replay-window and dedup paths were tightened so images don't double-deliver across long sessions, and the consolidation pass now respects the replay window when hiding history. (#3695, #3687)

  • WebUI shipped in the wheel + a year's worth of polish — pip install nanobot-ai now bundles the WebUI: enable the WebSocket channel, run nanobot gateway, open the browser. No cd webui && bun run build required. After several releases under a "preview" label, the WebUI is now a packaged surface. Inside it: redesigned settings and BYOK flow (including BYOK web search), localized slash palette, model preset badge that stays in sync across slash commands and config reloads, streamed reasoning rendered live, image previews, LAN access gated by tokenIssueSecret, default-to-new-chat on load, scroll preservation on settings return, a crypto.randomUUID shim for non-secure-context LAN use, and dropped eager markdown preload to cut first-paint cost. (#3653, #3661, #3703, #3709, #3656, #3658, #3733, #3759, #3782)

  • Five new providers and a fallback safety net — Native AWS Bedrock Converse lands as a first-class provider (#3574), with a follow-up that preserves Bedrock tool config across history (#3758). NVIDIA NIM (#3707), LongCat via OpenAI-compatible routing (#3114), Atomic Chat as a local OpenAI-compatible target (#3750), and MiMo with proper thinking-control wiring (#3734, #3851) round out the lineup. On top of the wider stack, fallback_models lets you list secondary models that take over when the primary fails (#3756), DeepSeek reasoning history is back-filled instead of dropped (#3616, #3560), Codex prompt cache keys stabilized (#3793), and Anthropic auto-falls back to streaming on long-request errors (#3579).

  • Model presets and runtime switching — ModelPresetConfig lets you name model + provider bundles in config and swap between them at runtime via /model (or the WebUI badge). Presets sync across slash commands, config reloads, and settings changes, so the model badge always matches what the next turn will hit. (#3714)

  • Core refactor — a cleaner agent loop, a smaller surface — AgentLoop.from_config() centralizes loop assembly so embedders stop reaching into private internals (#3708). _process_message was rewritten as a functional state machine with explicit transitions instead of nested branches (#3715). The archived conversation summary moved into the system prompt to keep KV caches stable across compactions (#3711). Tools became a self-describing plugin architecture (#3729). ask_user was removed in favor of structured message-tool choices (#3757), and GlobTool was retired in favor of read_file glob support (#3841). Vulture- and coverage-verified dead code was excised (#3755, #3719). Logging now preserves tracebacks and carries channel context (#3651, #3678). Ruff F rules are fully enforced in CI (#3672), and the agent test suite was expanded and restructured (#3766). New CLAUDE.md and .agent/ guides give AI contributors a stable on-ramp (#3534, #3860).

  • Pairing, DM approvals, and security hardening — Chat-native pairing (#3774) lets you approve DMs from inside chat instead of editing config. On the safety front: SSRF blocked in DingTalk outbound media (#3569), Feishu downloaded-media filenames confined to safe paths (#3789), local media attachments confined for the message tool (#3842), SSRF guard recovery softened so a transient miss doesn't poison subsequent turns (#3635), and workspace boundary violations get a retry-throttled soft warning instead of crashing the loop (#3614). Telegram silently ignores unauthorized senders instead of leaking error responses (#3629).

  • Memory, dream, and session durability — Cron jobs.json gained atomic writes with corrupt-store detection (#3606). Dream cursor only advances on completed batches (#3631) and restores correctly with memory state on resume (#3660). Replay-window hidden history is now properly consolidated (#3687). Workspace and tool-state changes survive restarts more reliably end-to-end.

  • Channel and platform fixes — Feishu group threads honor reply chains and topic isolation (#3547, #3704, #3747, #3775), Matrix skips pre-startup events and stops the sync loop on irrecoverable auth (#3575, #3578), WhatsApp voice messages download cleanly (#3607), Wecom preserves real filenames (#3751), Telegram quiets unauthorized senders (#3629), and Weixin raises on send failures so messages don't silently drop (#3659). On Windows: UNC path support in shell extraction (#3764). On the CLI: surrogate code points sanitized before the message bus (#3697), retry-wait messages no longer garble interactive output (#3705, #3609), and nanobot provider logout lands as a proper command (#3612).

  • Smaller things you'll feel — Configurable bot_name / bot_icon (#3730), configurable toolHintMaxLength (#3641), real SSE streaming restored on the OpenAI-compatible API (#3677), Whisper transcription retries on transient failures (#3646), sequential MCP server connects to stop CPU spin (#3640), MCP HTTP probe before connect (#3740), Brave search backoff under rate limits (#3840), sender_id in Runtime Context for user-aware responses (#3549), runtime context appended after user content for cache stability (#3844), origin_message_id outbound deduplication (#3561), and a Python SDK RunResult that finally exposes tools_used and messages (#3620).
