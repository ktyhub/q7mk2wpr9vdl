Was hat sich geändert?

  • Refactor(a2a-server): Implementierung der Migrationslogik für Einstellungen von V1 zu V2 von @jvargassanchez-dot in https://github.com/google-gemini/gemini-cli/pull/29450
  • fix(acp): Überbrückung von PromptResponse.usage und Ausgabe von Usage_Update-Benachrichtigungen (#29389) von @elberthc-byte in https://github.com/google-gemini/gemini-cli/pull/29549
  • Changelog für v0.63.0-preview.0 von @gemini-cli-robot in https://github.com/google-gemini/gemini-cli/pull/29565
  • fix(cli): Der Status des aufgelösten Ordners trust wird im Headless-Modus (#29031) von @amelidev in https://github.com/google-gemini/gemini-cli/pull/29528 weitergegeben
  • Chore(Release): Bump-Version auf 0.64.0-nightly.20260929.gd75234cae von @gemini-cli-robot in https://github.com/google-gemini/gemini-cli/pull/29567
  • fix(cli): Verhindert CPU-Hang und Quote-Swallowing bei @ im Code (#29434) durch @elberthc-byte in https://github.com/google-gemini/gemini-cli/pull/29557
  • fix(core): Datei-Tool-Operationen serialisieren und Schreibvorgänge atomar machen (#29078) durch @elberthc-byte in https://github.com/google-gemini/gemini-cli/pull/29499
  • fix(core): Implementieren Sie Delta-Patching nur mit Anhängen und begrenztes Verlaufsfenster in ChatRecordingService von @jvargassanchez-dot in https://github.com/google-gemini/gemini-cli/pull/29568
  • fix(cli): Status atomar beibehalten und bei Beschädigung durch @urielefrenvirtusa in https://github.com/google-gemini/gemini-cli/pull/29558 aus dem Backup wiederherstellen
  • fix(cli): Stellen Sie sicher, dass der Notfallabbruch mit Strg+C den Abbruchhandler während aktiver Vorgänge von @urielefrenvirtusa in https://github.com/google-gemini/gemini-cli/pull/29586 erreicht
  • fix(cli): @file:line-Referenzen auflösen und Geistertextumbruch durch @jesussamuel-byte in https://github.com/google-gemini/gemini-cli/pull/29581 verhindern
  • fix(ui): Stellen Sie sicher, dass Windows ConPTY die IME-Cursorposition um @jesussamuel-byte in https://github.com/google-gemini/gemini-cli/pull/29560 weiterleitet
  • fix(cli): Verzeichnisentfernung bei Windows-Sperrfehlern während Erweiterungsaktualisierungen durch @jesussamuel-byte in https://github.com/google-gemini/gemini-cli/pull/29540 erneut versuchen
  • fix(acp): Sitzung anhand der genauen ID auflösen und Listener-Bereinigung bei Sitzungsfehler durch @diegogodinezr in https://github.com/google-gemini/gemini-cli/pull/29580 durchführen
  • fix(cli): Scroll-Position und Partition beibehalten, bis das Höhenbudget von @luisfelipe-alt in https://github.com/google-gemini/gemini-cli/pull/29520 aussteht
  • fix(cli): Stellen Sie sicher, dass die Eingabetaste und die Leertaste die Auswahllistenoptionen von @ugorla-dev in https://github.com/google-gemini/gemini-cli/pull/29502 zuverlässig bestätigen
  • Fix(Patch): Wählen Sie 2ce1a69 zum Freigeben/v0.64.0-preview.0-pr-29672 zum Patchen der Version v0.64.0-preview.0 aus und erstellen Sie die Version 0.64.0-preview.1 von @gemini-cli-robot in https://github.com/google-gemini/gemini-cli/pull/29696 Vollständig Changelog: https://github.com/google-gemini/gemini-cli/compare/v0.63.0...v0.64.0

gemini-cli v0.64.0

What's Changed

  • refactor(a2a-server): implement V1 to V2 settings migration logic by @jvargassanchez-dot in https://github.com/google-gemini/gemini-cli/pull/29450
  • fix(acp): bridge PromptResponse.usage and emit usage_update notifications (#29389) by @elberthc-byte in https://github.com/google-gemini/gemini-cli/pull/29549
  • Changelog for v0.63.0-preview.0 by @gemini-cli-robot in https://github.com/google-gemini/gemini-cli/pull/29565
  • fix(cli): propagate resolved folder trust state in headless mode (#29031) by @amelidev in https://github.com/google-gemini/gemini-cli/pull/29528
  • chore(release): bump version to 0.64.0-nightly.20260929.gd75234cae by @gemini-cli-robot in https://github.com/google-gemini/gemini-cli/pull/29567
  • fix(cli): prevent CPU hang and quote swallowing on @ within code (#29434) by @elberthc-byte in https://github.com/google-gemini/gemini-cli/pull/29557
  • fix(core): serialize file tool operations and make writes atomic (#29078) by @elberthc-byte in https://github.com/google-gemini/gemini-cli/pull/29499
  • fix(core): implement append-only delta patching and bounded history windowing in ChatRecordingService by @jvargassanchez-dot in https://github.com/google-gemini/gemini-cli/pull/29568
  • fix(cli): persist state atomically and recover from backup on corruption by @urielefrenvirtusa in https://github.com/google-gemini/gemini-cli/pull/29558
  • fix(cli): ensure Ctrl+C emergency abort reaches cancellation handler during active operations by @urielefrenvirtusa in https://github.com/google-gemini/gemini-cli/pull/29586
  • fix(cli): resolve @file:line references and prevent ghost text wrap hang by @jesussamuel-byte in https://github.com/google-gemini/gemini-cli/pull/29581
  • fix(ui): ensure Windows ConPTY forwards IME cursor position by @jesussamuel-byte in https://github.com/google-gemini/gemini-cli/pull/29560
  • fix(cli): retry directory removal on Windows locking errors during extension updates by @jesussamuel-byte in https://github.com/google-gemini/gemini-cli/pull/29540
  • fix(acp): resolve session by exact id and handle listener cleanup on session failure by @diegogodinezr in https://github.com/google-gemini/gemini-cli/pull/29580
  • fix(cli): preserve scroll position and partition pending height budget by @luisfelipe-alt in https://github.com/google-gemini/gemini-cli/pull/29520
  • fix(cli): ensure Enter and Spacebar reliably confirm selection list options by @ugorla-dev in https://github.com/google-gemini/gemini-cli/pull/29502
  • fix(patch): cherry-pick 2ce1a69 to release/v0.64.0-preview.0-pr-29672 to patch version v0.64.0-preview.0 and create version 0.64.0-preview.1 by @gemini-cli-robot in https://github.com/google-gemini/gemini-cli/pull/29696

Full Changelog: https://github.com/google-gemini/gemini-cli/compare/v0.63.0...v0.64.0
