AstrBot v4.18.2

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

AstrBot v4.18.2

Was hat sich geändert?

Neu

– Es wurde die Möglichkeit hinzugefügt, die Agentensitzung zu stoppen, und der Verarbeitungsprozess der Stoppanforderung wurde optimiert, um den Befehl /stop zu unterstützen, um die Ausführung des Agenten zu beenden und zu versuchen, die laufenden Ausgabeergebnisse nicht zu verlieren. (#5380). – Unterstützung für Computer-Tools im SubAgent-Übergabeszenario hinzugefügt (#5399). – Möglichkeit hinzugefügt, Tool-Aufrufergebnisse während der Agentenausführung anzuzeigen, um die Beobachtbarkeit des Ausführungsprozesses zu verbessern (#5388). – Plug-in-Lade-/Entlade-Hook hinzugefügt, um die Plug-in-Lebenszyklusfunktionen zu erweitern (#5331). – Hot-Reload-Funktion nach einem Plug-In-Ladefehler hinzugefügt, um die Plug-In-Entwicklungs- und Wiederherstellungseffizienz zu verbessern (#5334). – Unterstützung für die Eingabe von SubAgent-Bild-URLs/lokalen Pfaden hinzugefügt (#5348). – Konfigurierbares Element für die Dashboard-Veröffentlichungs-Jump-Basis-URL hinzugefügt (#5330).

Beheben

  • Fest codiertes 6-Sekunden-Timeout für Tavily-Anfragen behoben. – Problem behoben, bei dem der OneBot v11-Adapter weiterhin eine Verbindung herstellte, nachdem er ausgeschaltet wurde (#5412). – Die Protokollverarbeitung, wenn die Plattform in der Kontextsitzung fehlt, wurde korrigiert, eine Warnung hinzugefügt und Informationen zur Fehlerbehebung verbessert. – Das Problem, dass Einbettungsdimensionen nicht transparent an den Anbieter API übermittelt wurden, wurde behoben (#5411). – Korrigieren Sie die Verarbeitungslogik der Dateikomponenten und verbessern Sie die Pfadkompatibilität der OneBot-Treiberschicht (#5391). – Das Problem wurde behoben, bei dem das Sandbox-Dateiübertragungstool keine Überprüfung der Administratorberechtigungen durchführte (#5402). – Das Problem der zirkulären Abhängigkeit, das durch Pipeline und from ... import * verursacht wurde, wurde behoben (#5353). – Das Parsing-Problem behoben, wenn die Konfigurationsdatei UTF-8-BOM enthält (#5376). – Das Problem des fehlenden Kopier-Rollback-Pfads und der unklaren Fehlermeldung in ChatUI wurde behoben (#5352). – Korrigieren Sie die Verarbeitungslogik zum Beibehalten des Plug-in-Verzeichnisses, um abnormales Verhalten des Plug-in-Verzeichnisses zu vermeiden (#5369). – Das Problem wurde behoben, bei dem Nachrichtensegmente der ChatUI-Datei nicht beibehalten werden konnten (#5386). – Das Problem, dass .dockerignore versehentlich das Verzeichnis changelogs ausschloss, wurde behoben. – Das Problem wurde behoben, bei dem qq-botpy einen Fehler aufgrund einer veralteten Version von aiohttp meldete (#5316).

Optimierung

– Internationalisierung der SubAgent-Layoutseite abgeschlossen und mehrsprachige Unterstützung hinzugefügt (#5400). – Tests im Zusammenhang mit der Nachrichtenereignisverarbeitung hinzugefügt und die Fixtures/Mocks-Abdeckung des Test-Frameworks verbessert (#5355, #5354).

Was hat sich geändert (EN)

Neue Funktionen

– Unterstützung für Computertools in Subagenten-Übergabeszenarien hinzugefügt (#5399). – Unterstützung für die Anzeige von Werkzeugaufrufergebnissen während der Agentenausführung zur besseren Beobachtbarkeit hinzugefügt (#5388). – Plugin-Lade-/Entlade-Hooks hinzugefügt, um die Plugin-Lebenszyklusfunktionen zu erweitern (#5331). – Hot-Reload-Unterstützung hinzugefügt, wenn das Laden des Plugins fehlschlägt, wodurch die Wiederherstellung während der Plugin-Entwicklung verbessert wird (#5334). – Unterstützung für die Eingabe von Bild-URLs/lokalen Pfaden für Unteragenten hinzugefügt (#5348). – Stoppsteuerung für aktive Agentensitzungen hinzugefügt und verbesserte Verarbeitung von Stoppanforderungen (#5380). – Konfigurierbare Basis-URL für Dashboard-Release-Weiterleitungen hinzugefügt (#5330).

Korrekturen

– Das Protokollierungsverhalten bei fehlenden Plattforminformationen in Kontextsitzungen wurde korrigiert, mit klareren Warnungen und Diagnosen. – Fehlende Einbettungsdimensionen wurden behoben, die an den Anbieter APIs übergeben wurden (#5411). – Stabilitätsprobleme beim Herunterfahren im aiocqhttp-Adapter behoben (#5412). – Die Handhabung von Dateikomponenten wurde korrigiert und die Pfadkompatibilität in der OneBot-Treiberebene verbessert (#5391). – Fehlender Admin-Schutz für Sandbox-Dateiübertragungstools behoben (#5402). – Zirkuläre Importprobleme im Zusammenhang mit der Pipeline- und from ... import *-Nutzung behoben (#5353). – Probleme beim Parsen der Konfiguration behoben, wenn Dateien UTF-8-BOM enthalten (#5376). – Fehlender Kopier-Rollback-Pfad und unklare Fehlermeldungen in ChatUI behoben (#5352). – Die Behandlung reservierter Plugin-Verzeichnisse wurde korrigiert, um abnormales Plugin-Pfadverhalten zu vermeiden (#5369). – Probleme mit der Persistenz von ChatUI-Dateisegmenten behoben (#5386).

  • Versehentliches Ausschließen des Verzeichnisses changelogs in .dockerignore behoben. – Kompatibilitätsprobleme behoben, die durch ein fest codiertes 6-Sekunden-Timeout in Tavily-Anfragen verursacht wurden. – qq-botpy-Laufzeitfehler behoben, die durch zu neue aiohttp-Versionen verursacht wurden (#5316).

Verbesserungen

– Internationalisierung für die Subagent-Orchestrierungsseite abgeschlossen (#5400). – Eine breitere Testabdeckung für Nachrichtenereignisse und verbesserte Fixtures/Mocks im Test-Framework hinzugefügt (#5355, #5354). – README-Inhalt aktualisiert und Repository-weite Formatierungsbereinigung (Ruff-Format) angewendet (#5375).

Englisches Original / English original

AstrBot v4.18.2

Highlights

  • Agent control and observability — /stop can terminate active Agent sessions while aiming to preserve already-produced output, and tool-call results can now be displayed during execution. This makes long-running agents easier to interrupt and diagnose (#5380, #5388).
  • Richer SubAgent handoffs — SubAgents now accept image URLs and local paths, while computer-use tools are available during handoffs. This enables multimodal and browser/desktop workflows rather than text-only delegation (#5348, #5399).
  • Plugin lifecycle management — New load/unload hooks let plugins coordinate initialization and cleanup, while failed plugin loads support hot reload for faster development and recovery. Reserved plugin-directory handling was also corrected (#5331, #5334, #5369).
  • Sandbox permissions tightened — File-transfer tools now enforce administrator privileges. Integrations running under unprivileged identities must use an authorized account or adjust their permission model (#5402).
  • Integration and configuration fixes — Embedding dimensions now reach provider APIs, so verify that configured dimensions match your model and existing vector indexes (#5411). OneBot/aiocqhttp shutdown and file-path handling are more robust (#5412, #5391), Dashboard release redirects now support a configurable base URL (#5330), and UTF-8 BOM configuration files parse correctly (#5376).
  • Compatibility — No breaking changes are announced.

What's Changed

新增

  • 新增 Agent 会话停止能力，并优化 stop 请求处理流程，支持 /stop 指令终止 Agent 运行并尽量不丢失已运行输出的结果。 (#5380)。
  • 新增 SubAgent 交接场景下的 computer-use 工具支持 (#5399)。
  • 新增 Agent 执行过程中展示工具调用结果的能力，提升执行过程可观测性 (#5388)。
  • 新增插件加载/卸载 Hook，扩展插件生命周期能力 (#5331)。
  • 新增插件加载失败后的热重载能力，提升插件开发与恢复效率 (#5334)。
  • 新增 SubAgent 图片 URL/本地路径输入支持 (#5348)。
  • 新增 Dashboard 发布跳转基础 URL 可配置项 (#5330)。

修复

  • 修复 Tavily 请求的硬编码 6 秒超时。
  • 修复 OneBot v11 适配器关闭之后仍然在连接的问题(#5412)。
  • 修复上下文会话中平台缺失时的日志处理，补充 warning 并改进排查信息。
  • 修复 embedding 维度未透传到 provider API 的问题 (#5411)。
  • 修复 File 组件处理逻辑并增强 OneBot 驱动层路径兼容性 (#5391)。
  • 修复 sandbox 文件传输工具缺少管理员权限校验的问题 (#5402)。
  • 修复 pipeline 与 from ... import * 引发的循环依赖问题 (#5353)。
  • 修复配置文件存在 UTF-8 BOM 时的解析问题 (#5376)。
  • 修复 ChatUI 复制回滚路径缺失与错误提示不清晰的问题 (#5352)。
  • 修复保留插件目录处理逻辑，避免插件目录行为异常 (#5369)。
  • 修复 ChatUI 文件消息段无法持久化的问题 (#5386)。
  • 修复 .dockerignore 误排除 changelogs 目录的问题。
  • 修复 aiohttp 版本过新导致 qq-botpy 报错的问题 (#5316)。

优化

  • 完成 SubAgent 编排页面国际化，补齐多语言支持 (#5400)。
  • 增补消息事件处理相关测试，并完善测试框架的 fixtures/mocks 覆盖 (#5355, #5354)。

What's Changed (EN)

New Features

  • Added computer-use tools support in sub-agent handoff scenarios (#5399).
  • Added support for displaying tool call results during agent execution for better observability (#5388).
  • Added plugin load/unload hooks to extend plugin lifecycle capabilities (#5331).
  • Added hot reload support when plugin loading fails, improving recovery during plugin development (#5334).
  • Added image URL/local path input support for sub-agents (#5348).
  • Added stop control for active agent sessions and improved stop request handling (#5380).
  • Added configurable base URL for dashboard release redirects (#5330).

Fixes

  • Fixed logging behavior when platform information is missing in context sessions, with clearer warning and diagnostics.
  • Fixed missing embedding dimensions being passed to provider APIs (#5411).
  • Fixed shutdown stability issues in the aiocqhttp adapter (#5412).
  • Fixed File component handling and improved path compatibility in the OneBot driver layer (#5391).
  • Fixed missing admin guard for sandbox file transfer tools (#5402).
  • Fixed circular import issues related to pipeline and from ... import * usage (#5353).
  • Fixed config parsing issues when files contain UTF-8 BOM (#5376).
  • Fixed missing copy rollback path and unclear error messaging in ChatUI (#5352).
  • Fixed reserved plugin directory handling to avoid abnormal plugin path behavior (#5369).
  • Fixed ChatUI file segment persistence issues (#5386).
  • Fixed accidental exclusion of the changelogs directory in .dockerignore.
  • Fixed compatibility issues caused by a hard-coded 6-second timeout in Tavily requests.
  • Fixed qq-botpy runtime errors caused by overly new aiohttp versions (#5316).

Improvements

  • Completed internationalization for the sub-agent orchestration page (#5400).
  • Added broader message-event test coverage and improved fixtures/mocks in the test framework (#5355, #5354).
  • Updated README content and applied repository-wide formatting cleanup (ruff format) (#5375).
