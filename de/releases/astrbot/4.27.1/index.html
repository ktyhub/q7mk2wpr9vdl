AstrBot v4.27.1

[4.27.1] – 02.08.2026

Per aspera ad astra.

Hinzugefügt

– -y / --yes zu astrbot init hinzugefügt, sodass unbeaufsichtigte Bereitstellungen die Installationsbestätigungsaufforderung überspringen können. (#9514) – Ein unabhängiger zustandsloser Responses API-Anbieter für OpenAI-kompatible Endpunkte hinzugefügt, einschließlich OpenAI- und DeepSeek-Vorlagen, vollständige Verlaufswiedergabe für Argumentation und Toolaufrufe sowie Responses API als Standard für neue xAI-Anbieter. (#9515) – Persistenter Gruppennachrichtenverlauf mit konfigurierbarer Aufbewahrung, normalisiertem Speicher und einem LLM-Tool zum Suchen und Abrufen von Nachrichten aus der aktuellen Gruppe hinzugefügt. (#9465) – Verwaltete lokale Shell-Sitzungen mit inkrementeller Ausgabe, stdin-Schreibvorgängen, Unterbrechung, Beendigung, Zeitüberschreitungen und Lebenszyklusbereinigung hinzugefügt; Windows-Sitzungen verwenden jetzt PowerShell und zeilenorientierte Programme unterstützen explizite Zeilenschreibvorgänge. (#9470, #9471, #9501) – Es wurde eine einheitliche Erweiterungs- und Persona-Verwaltungserfahrung mit gemeinsamen Funktionsselektoren, weitergeleiteten Plugin-Arbeitsbereichen und klarerer MCP-Server-, Tool- und Skill-Herkunft und -Status hinzugefügt. (#9499)

  • Integrierte skill-creator-, documents-, pdf- und spreadsheets-Skills zum Erstellen wiederverwendbarer Skills und zum Arbeiten mit Office-Dokumenten, PDFs und Tabellenkalkulationen hinzugefügt. – Installation und Updates für Plugins hinzugefügt, die in generischen Git-Repositorys im HTTP(S-), SSH- und SCP-Stil gehostet werden. (#9493) – Konvertiertes ChatUI fügt mehr als 10.000 Zeichen in Textanhänge ein. (#9496) – Sensible API-Schlüsselunterbereiche für Administrator-Chat-Zugriff und Administrator-Konfigurationsänderungen hinzugefügt sowie eine Referenzdokumentation für den Bereich bis zum Endpunkt erstellt. (#9503)

Geändert

  • Verbesserte Qualität des Wissensdatenbankabrufs durch normalisierte Dense/Spärlich-Relative-Score-Fusion und Quelldokument-Diversifizierung. (#9455)
  • Erweiterte Wissensdatenbank-Einbettungen mit Dokumentkontext und beibehaltenen Überschriftenpfaden. (#9457) – Zentralisierte Kern-, Dashboard- und Plugin-Update-Abläufe hinter einer sichereren Updater-Architektur mit Paket- und Metadatenüberprüfung. (#9493) – Vorhandene veraltete APIs mit Laufzeitwarnungen formalisiert und der Name der OpenAI-Tool-Call-Konvertierungsmethode korrigiert, wobei ein abwärtskompatibler Alias beibehalten wurde. (#9468, #9469)
  • Die Skills-Karten, die Persona-Verwaltung, der Erweiterungsarbeitsbereich und die Layouts für den Projekt-Chat-Composer wurden verfeinert. – Verwendung kompakter, zeitstempelbasierter transienter Dateinamen und klarerer arbeitsraumbezogener Pfadführung, um die Verwendung von Werkzeugpfad-Token zu reduzieren. (#9505) – Es wurden präzise Klartext-Ergebnisse für abgeschlossene lokale Shell-Befehle zurückgegeben, während die Metadaten der verwalteten Sitzung für aktive Befehle beibehalten wurden. (#9507)

Behoben

– Enthalten die integrierten Fähigkeiten skill-creator, documents, pdf und spreadsheets, die in v4.27.0 in den Quell- und Docker-Distributionen angekündigt wurden, mit schreibgeschützter voreingestellter Erkennung und lokaler Override-Unterstützung. (#9517)

  • Die Farben der Fähigkeitschips im Dunkelmodus wurden korrigiert. – Der BM25-Abhängigkeitsimport wurde verschoben, damit AstrBot den FTS5-Abruf auf CPUs starten und verwenden kann, die mit dem installierten NumPy-Build nicht kompatibel sind. (#9435) – Die Wissensdatenbank-Rangfolgefusion wurde deterministisch gemacht und vLLM-Reranking-Antwortfehler wurden sichtbar. (#9454)
  • ChatUI-Streaming-Antwortenden wurden beibehalten und verhindert, dass die offiziellen QQ-Streaming-Puffer führende Zeichen verlieren. (#9439, #9444)
  • Lokalisierte zukünftige Aufgabenzeitstempel mit der Systemzeitzone. (#9462) – Isolierte verwaltete lokale Shell-Sitzungen nach Absender, während Konversationsadministratoren gleichzeitig die Verwaltung von Sitzungen in ihrer Konversation ermöglichen. (#9479) – Gehärtete API-Schlüsselautorisierungsgrenzen für Administratoridentitäten, vertrauliche Konfigurationen und Projektarbeitsbereichspfade. (#9503) – Anhaltende Terminal-Tool-Aufrufe, Ergebnisse und trusted-Token-Nutzung, wenn keine Assistentenantwort erzeugt wird. (#9500) – Es wurde verhindert, dass erweiterte ChatUI-Ersteller, Antworten und Anhänge die neuesten Nachrichten überlappen. (#9496)
  • Die doppelte Bildlaufleiste wurde aus dem Konfigurationsdialog des mobilen Plugins entfernt. (#9491) – Das Tool-Image-Cache-Verzeichnis wurde nach der Speicherbereinigung neu erstellt, sodass weiterhin neue Bilder gespeichert werden können. (#9490)
  • Ausgehendes TTS- und QQ-offizielles Audio blieb bis zur globalen Bereinigung temporärer Dateien verfügbar, damit asynchrone Downloads nicht fehlschlagen. (#9506)

Dokumentation

  • QQ-Community-Gruppen 15 und 16 zur Community-Dokumentation hinzugefügt.

Wartung

  • Die API-Testvorrichtungen von Responses sind mit dem neuesten OpenAI SDK-Token-Nutzungsschema kompatibel. – Ein ungenutzter Tool-Image-Bereinigungspfad wurde zugunsten des globalen temporären Verzeichnisreinigers entfernt. (#9504)

Englisches Original / English original

AstrBot v4.27.1

Highlights

  • Responses API provider is now first-class — and the default for new xAI providers — #9515 adds a stateless OpenAI-compatible Responses API provider (OpenAI and DeepSeek templates, full replay of reasoning and tool-call history). If you configure xAI today, new providers default to Responses API, so verify tool-calling and reasoning traces still behave before rolling out; existing endpoint configs aren't auto-migrated.

  • Agent tooling got substantially more capable, with security-relevant side effects — #9470/#9471/#9501 add managed local shell sessions (incremental output, stdin, interrupt/terminate, timeouts, lifecycle cleanup), with Windows now using PowerShell instead of cmd; #9479 isolates sessions per sender but lets conversation admins manage peers' sessions. #9465 adds persisted group message history with configurable retention plus an LLM tool to search it. If you exposed shell tools to untrusted group members, re-check who counts as a "conversation administrator" after upgrade.

  • Migration items for API/plugin authors — #9503 hardens API key authorization: administrator chat access and admin config changes now require separate sensitive sub-scopes, so existing admin keys used by automation may get rejected until re-scoped. #9468/#9469 add runtime warnings to deprecated APIs and rename LLMResponse.to_openai_to_calls_model to to_openai_tool_calls_model (backward-compatible alias kept) — update plugins now to avoid warning noise, and treat the warnings as your deprecation timeline.

  • 4.27.1 specifically is a packaging fix, not a feature release — #9517 is the only substantive delta over 4.27.0: the built-in skill-creator, documents, pdf, and spreadsheets Skills announced in 4.27.0 were missing from source and Docker distributions and are now included with read-only preset discovery plus local override. If you already pulled 4.27.0 and expected those Skills, you're on a broken build — go straight to 4.27.1. The rest is chore: bump version (#9509, #9520).

  • Also worth knowing, and who should upgrade — KB retrieval is meaningfully better (#9455 relative-score fusion + source diversification, #9457 context-enriched embeddings with heading paths), #9435 fixes startup on CPUs whose NumPy build breaks BM25 so FTS5 retrieval works again, and plugin installs now support generic HTTP(S)/SSH/SCP git repos through a centralized updater with package/metadata verification (#9493). Upgrade if you run knowledge bases, Windows shell tools, multi-user group bots, or self-hosted plugin repos. You can skip the urgency if you're a single-user Linux deployment with no KB, no shell tools, and no admin API automation — nothing here forces a change, though you'll miss the streaming-tail fixes (#9439, #9444) and the audio-cleanup race fix (#9506).

4.27.1 - 2026-08-02

Per aspera ad astra.

Added

  • Added -y / --yes to astrbot init so unattended deployments can skip the installation confirmation prompt. (#9514)

  • Added an independent stateless Responses API provider for OpenAI-compatible endpoints, including OpenAI and DeepSeek templates, full-history replay for reasoning and tool calls, and Responses API as the default for new xAI providers. (#9515)

  • Added persistent group message history with configurable retention, normalized storage, and an LLM tool for searching and retrieving messages from the current group. (#9465)

  • Added managed local shell sessions with incremental output, stdin writes, interruption, termination, timeouts, and lifecycle cleanup; Windows sessions now use PowerShell and line-oriented programs support explicit line writes. (#9470, #9471, #9501)

  • Added a unified extension and persona management experience with shared capability selectors, routed plugin workspaces, and clearer MCP server, tool, and Skill provenance and status. (#9499)

  • Added built-in skill-creator, documents, pdf, and spreadsheets Skills for creating reusable Skills and working with office documents, PDFs, and spreadsheets.

  • Added installation and updates for plugins hosted in generic HTTP(S), SSH, and SCP-style Git repositories. (#9493)

  • Converted ChatUI pastes longer than 10,000 characters into text attachments. (#9496)

  • Added sensitive API key sub-scopes for administrator chat access and administrator configuration changes, plus generated scope-to-endpoint reference documentation. (#9503)

Changed

  • Improved knowledge base retrieval quality with normalized dense/sparse relative-score fusion and source-document diversification. (#9455)
  • Enriched knowledge base embeddings with document context and preserved heading paths. (#9457)
  • Centralized core, dashboard, and plugin update flows behind a safer updater architecture with package and metadata verification. (#9493)
  • Formalized existing deprecated APIs with runtime warnings and corrected the OpenAI tool-call conversion method name while retaining a backward-compatible alias. (#9468, #9469)
  • Refined the Skills cards, persona management, extension workspace, and project chat composer layouts.
  • Used compact timestamp-based transient filenames and clearer workspace-relative path guidance to reduce tool path token usage. (#9505)
  • Returned concise plain-text results for completed local shell commands while retaining managed-session metadata for active commands. (#9507)

Fixed

  • Included the built-in skill-creator, documents, pdf, and spreadsheets Skills announced in v4.27.0 in source and Docker distributions, with read-only preset discovery and local override support. (#9517)

  • Corrected capability chip colors in dark mode.

  • Deferred the BM25 dependency import so AstrBot can start and use FTS5 retrieval on CPUs incompatible with the installed NumPy build. (#9435)

  • Made knowledge base rank fusion deterministic and surfaced vLLM rerank response failures. (#9454)

  • Preserved ChatUI streaming response tails and prevented QQ Official streaming buffers from losing leading characters. (#9439, #9444)

  • Localized future task timestamps with the system timezone. (#9462)

  • Isolated managed local shell sessions by sender, while allowing conversation administrators to manage sessions in their conversation. (#9479)

  • Hardened API key authorization boundaries for administrator identities, sensitive configuration, and project workspace paths. (#9503)

  • Persisted terminal tool calls, results, and trusted token usage when no assistant response is produced. (#9500)

  • Prevented expanded ChatUI composers, replies, and attachments from overlapping the latest messages. (#9496)

  • Removed the double scrollbar from the mobile plugin configuration dialog. (#9491)

  • Recreated the tool image cache directory after storage cleanup so new images can still be saved. (#9490)

  • Kept outbound TTS and QQ Official audio available until global temporary-file cleanup so asynchronous downloads do not fail. (#9506)

Documentation

  • Added QQ community groups 15 and 16 to the community documentation.

Maintenance

  • Kept Responses API test fixtures compatible with the latest OpenAI SDK token-usage schema.

  • Removed an unused tool image cleanup path in favor of the global temporary-directory cleaner. (#9504)

  • 新增管理员聊天访问和管理员配置修改的敏感 API Key 子权限，并生成权限到接口的参考文档。 (#9503)

变更

  • 通过归一化稠密/稀疏相对分数融合和来源文档去重，提升知识库检索质量。 (#9455)
  • 使用文档上下文增强知识库 Embedding，并保留标题层级路径。 (#9457)
  • 将核心、Dashboard 和插件更新流程统一到更安全的更新架构中，并增加安装包与元数据校验。 (#9493)
  • 为已有废弃 API 增加运行时警告，修正 OpenAI 工具调用转换方法名，同时保留向后兼容别名。 (#9468, #9469)
  • 优化 Skill 卡片、人格管理、扩展工作区和项目聊天输入区的布局。
  • 使用紧凑的时间戳临时文件名并明确工作区相对路径指引，减少工具路径占用的 Token。 (#9505)
  • 对已完成的本地 Shell 命令返回精简纯文本结果，对运行中的命令继续保留托管会话元数据。 (#9507)

修复

  • 将 v4.27.0 公告中的内置 skill-creator、documents、pdf 和 spreadsheets Skills 实际加入源码与 Docker 发行版，支持作为只读预置能力自动发现，并允许同名本地 Skill 覆盖。 (#9517)

  • 修正深色模式下的能力标签颜色。

  • 延迟导入 BM25 依赖，使安装的 NumPy 与 CPU 不兼容时，AstrBot 仍可启动并使用 FTS5 检索。 (#9435)

  • 确保知识库排名融合结果稳定，并正确暴露 vLLM 重排序响应错误。 (#9454)

  • 保留 ChatUI 流式响应末尾内容，并避免 QQ 官方机器人流式缓冲丢失开头字符。 (#9439, #9444)

  • 使用系统时区处理未来任务时间。 (#9462)

  • 按发送者隔离本地托管 Shell 会话，同时允许会话管理员管理所在会话中的 Shell 会话。 (#9479)

  • 加固 API Key 对管理员身份、敏感配置和项目工作区路径的授权边界。 (#9503)

  • 在没有助手回复时，仍持久化终端工具调用、结果和可信 Token 用量。 (#9500)

  • 避免展开后的 ChatUI 输入区、回复和附件遮挡最新消息。 (#9496)

  • 移除移动端插件配置弹窗中的双重滚动条。 (#9491)

  • 存储清理后自动重建工具图片缓存目录，确保仍可保存新图片。 (#9490)

  • 将 TTS 和 QQ 官方机器人出站音频保留到全局临时文件清理，避免异步下载失败。 (#9506)

文档

  • 在社区文档中新增 QQ 群 15 和 16。

维护

  • 使 Responses API 测试数据兼容最新 OpenAI SDK 的 Token 用量结构。

  • 移除未使用的工具图片独立清理逻辑，统一交由全局临时目录清理器管理。 (#9504)
