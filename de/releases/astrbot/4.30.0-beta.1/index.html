AstrBot v4.30.0-beta.1

[4.30.0-beta.1] – 18.11.2026

**Diese Version ist eine Beta-Version und kann Instabilitäts- oder Kompatibilitätsprobleme aufweisen. Es wird empfohlen, es zunächst in einer Testumgebung zu überprüfen. Dieses Mal umfasst die Migration der Konversationsdatenbank, der Agentenkonfiguration und der Sitzungseinstellungen. Bitte sichern Sie Daten und Konfiguration vor dem Upgrade. Beim Rollback auf die alte Version müssen Sie vor dem gleichzeitigen Upgrade die Sicherung wiederherstellen. **

Updates seit v4.30.0-alpha.1

  • Wenn der Benutzer eine Anweisung hinzufügt (Steering), wird der wartende Tool-Aufruf automatisch in die Hintergrundaufgabe verschoben und der Vordergrund verarbeitet weiterhin neue Eingaben. (#11142) – Das Problem wurde behoben, bei dem die Streaming-Antworten des offiziellen QQ-Gruppenchats zusammengeführt wurden. (#11229) – Der offizielle QQ-Adapter unterstützt das Abrufen der Namen privater Chat-Benutzer, und den Anzeigenamen von Gruppenchats wird durch die Verwendung der Spitznamen der Benutzer in der Gruppe Vorrang eingeräumt. (#11184)
  • Upgrade der Plug-in-Ansichtsfunktion: ChatUI fügt eine neue Paging-Workbench und residente Plug-in-Ansichten hinzu, die das Öffnen von Ansichten über „+“, das Ziehen zum Anpassen der Breite, den Vollbildmodus und das Wiederherstellen von Registerkarten und Layouts pro Sitzung unterstützen. (#11218)
  • Upgrade der Plug-in-Ansichtsfunktion: Plug-ins können interaktive HTML-Komponenten in Chat-Nachrichten anzeigen, diese über Befehle, Nachrichtenprozessoren oder Modelltools erstellen und Benutzervorgänge verarbeiten; Andere Plattformen behalten den Text-Fallback bei. (#11179)
  • Upgrade der Plug-in-Ansichten: Plug-in-Ansichten werden einheitlich in metadata.yaml und views deklariert. (#11218)
  • ChatUI unterstützt die Sprachtranskription in bearbeitbare Entwürfe; Über der Modellkonfigurationsseite in ChatUI wird ein Kategorieeintrag „Konversation/Sprache zu Text/Text zu Sprache“ hinzugefügt. (#11170)
  • Ändern Sie die Chat-Begründungsseitenleiste so, dass laufende Details innerhalb der Nachricht einklappbar sind und Gedanken, Toolaufrufe und Zwischenantworten in Gruppen angezeigt werden. Wenn das Backend weiter ausgeführt wird, kann durch eine Aktualisierung oder erneute Verbindung die laufende Konversation fortgesetzt und nachfolgende Antworten beibehalten werden. (#11166)
  • Unterstützt die Inferenzintensitätskonfiguration der Gemini 4-Serie, verbessert das Vorschaumodell und fordert Parameterkompatibilität an. (#11219)
  • Reduzieren Sie wiederholte Berechnungen der Kontext-Token-Schätzung und -Kürzung, führen Sie Sitzungsmetadaten und idempotente Abfragen zusammen und optimieren Sie die Leistung. (#11167, #11199) – Wenn geplante Aufgaben und Hintergrundaufgaben aktiviert werden, werden Benachrichtigungen nur über explizite Messaging-Tools gesendet, um ein zusätzliches automatisches Senden von Abschlusszusammenfassungen zu vermeiden. (#11198) – Behalten Sie Inferenzdetails in OpenRouter-Nicht-Streaming-Antworten bei. (#11168) – Korrigieren Sie die URL-Audioverarbeitung in Gemini-Verlaufsnachrichten und behalten Sie den benutzerdefinierten Benutzeragenten unter SDK 3.4 bei. (#11143, #11196)
  • DashScope TTS unterstützt Qwen-Audio-TTS. (#10495) – Die boolesche Beurteilung von System One unterstützt optionale wahre und falsche Beurteilungsbedingungen und behebt das Problem, dass einige kompatible Endpunktverbindungstests HTTP 400 zurückgeben. (#11062) – Das Problem mit dem Blinken der Begrüßungsseite beim Wechseln von Chatsitzungen wurde behoben und die veraltete VoceChat-Symbolreferenz entfernt. (#11182, #11186) – Isolieren Sie Testkonfigurationen von lokalen AstrBot-Daten, verbessern Sie die Windows-Datenbankbereinigung und deaktivieren Sie explizit die Git-Signierung in Projektbereitstellungstests. (#11231, #11222) – Aktualisierte QQ-Gruppeninformationen in der Plug-in-Entwicklungsdokumentation. (#11178)

Speichern Sie Nachrichten und Toolaufrufe inkrementell und verbessern Sie die Verlaufsverarbeitung nach Ausführungsunterbrechungen.   • Unterstützen Sie die Platzierung des Chat-Eingangs in der Seitenleiste in den Darstellungseinstellungen. (#11090)

  • Die KI-Entwicklungsdokumentation wurde neu organisiert und Beispiele und Screenshots zur Plug-in-Konfigurationssteuerung hinzugefügt. (#11154)

AstrBot v4.30.0-beta.1

Highlights

  • Migrate before you upgrade (breaking) — This beta moves conversation storage to an event-sourcing backend and relocates Agent and session configuration (#10077, #11158, #11162). It is not a drop-in patch: back up data and config first, and note that rolling back to 4.29.x requires restoring that pre-upgrade backup, not just downgrading the binary. Given the beta label, validate in a test environment before touching production.

  • New Agent runtime and reworked subagents — Plugins now drive turns through ctx.agent.run_turn() (#10934, #10936, #11052), while subagents are rebuilt as background tasks with independent context, follow-up input, and result delivery. Their management moves out of the sidebar to Config → AI → Capabilities → Subagents and is per-profile (#11053), so existing subagent setups need reconfiguration — the single biggest behavioral change for Agent authors.

  • Plugin Views become first-class — Plugins declare views in metadata.yaml under views and can render interactive HTML components inside chat messages, created from commands, handlers, or model tools, with text fallback on other platforms (#11179, #11218). ChatUI adds a tabbed workbench with resizable, fullscreen, per-session-restored panels (#11218). This is a genuine UI/platform expansion, but it changes how plugin configuration is declared.

  • Steering and resumable runs — Follow-up input now pushes pending native tool calls into the background while preserving caller identity, permissions, and complete results, cancelling transferred work when the session stops (#11142). The reasoning sidebar is replaced by collapsible inline run details (thinking, tool calls, intermediate replies), and active conversations resume after refresh/reconnect while the backend stays up (#11166). Worth exercising explicitly in long-running sessions.

  • Model and provider coverage — Gemini 4 reasoning-effort is configurable without bumping google-genai (#11219); OpenAI Decisions adds choice/boolean/scoring models (#10968), DeepSeek adds STT/TTS (#11118), DashScope adds Qwen-Audio-TTS (#10495), and OpenRouter non-streaming replies retain reasoning details (#11168). Watch the switch to explicit message tools for cron/background wakeups (#11198) — automated tasks no longer emit extra completion summaries.

  • Performance and Windows sandbox — Context token estimation/truncation is de-duplicated and conversation metadata plus idempotency lookups are merged (#11167, #11199), targeting write amplification introduced by the new event-sourced store; a Windows AppContainer sandbox adds workspace isolation with code-execution and network controls (#10466).
