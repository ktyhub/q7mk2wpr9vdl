Was hat sich geändert?

Dies ist die Hotfix-Version von v4.23.0: v4.23.1

  • Downgrade der python-ripgrep-Abhängigkeit auf 0.0.8 und Behebung des Problems, dass die Versionen Python, 3.13 und 3.14 nicht normal starten können. (#7514) – Das Problem wurde behoben, bei dem die Plattformroute nicht im Dashboard angezeigt werden konnte, wenn die Sitzungs-ID den Doppelpunkt : enthielt. (#7517)
  • Angepasst an DeerFlow 2.0, aktualisierter DeerFlow Runner, API Client, Sitzungsbefehle, Provider-Verwaltungslogik, Konfigurationsdokumente und zugehörige Tests. (#7500)
  • Entfernen Sie unnötigen Rand vom Dashboard v-main. Durch den zusätzlichen Rand wird die Hintergrundfarbe sichtbar, sodass es optisch so aussieht, als gäbe es auf der rechten Seite einen zusätzlichen Rand. (#7481) – Das Beurteilungsproblem, das durch ein inkonsistentes Format bei der Überprüfung des Plug-in-Installationsstatus verursacht wurde, wurde behoben. (#7493)
  • Die Hervorhebung von Codeblöcken im Dashboard wurde auf Shiki umgestellt, die Darstellung von Dunkel-/Hellthemen wurde synchronisiert und der Anzeigeeffekt von Codeblöcken in README, Aktualisierungsprotokollen und Chatnachrichten wurde optimiert. (#7497)

Hinzugefügt (v4.23.0)

  • Unterstützt das Lesen (Lesen), Schreiben (Schreiben), Bearbeiten (Bearbeiten) von Dateien, die Grep-Suche (Ripgrep) und den nach Sitzungen isolierten Arbeitsbereich für Computernutzungsfunktionen. (#7402)
  • Der WeChat-Adapter für persönliche Konten unterstützt das Parsen von Referenznachrichten. (#7380)
  • Das Websuchtool Brave Search wurde hinzugefügt und die alte Standardimplementierung der Websuche entfernt. (#6847)
  • Unterstützung für Mattermost-Plattformadapter hinzugefügt. (#7369)
  • NVIDIA Rerank Provider hinzugefügt. (#7227)
  • LongCat LLM-Anbieter hinzugefügt. (#7360) – Unterstützung für die Audioeingabemodi OpenAI und Gemini hinzugefügt und Probleme im Zusammenhang mit der ChatUI-Aufzeichnung behoben. (#7378) – Die Discord-Plattform fügt eine neue Filterkonfiguration für Bot-Nachrichten hinzu, mit der Sie steuern können, ob Sie Nachrichten von anderen Bots erhalten. (#6505) – LLMs Fähigkeit hinzugefügt, wiederholte Werkzeugaufrufe anzuleiten, um die Situation zu reduzieren, in der das Modell in wiederholte Werkzeugaufrufe gerät. (#7388)
  • QQ-Beamter API fügt einen Wiederholungsmechanismus für den Datei-Upload hinzu, um die Stabilität des Dateiversands zu verbessern. (#7430)

Optimierung (v4.23.0)

  • Rekonstruieren Sie den ChatUI-Stil, die Nachrichtenwiedergabe und das Eingabeerlebnis, um die allgemeine Wartbarkeit und Interaktionskonsistenz der Chat-Schnittstelle zu verbessern. (#7485)
  • Führen Sie Cron-bezogene Tools in einem einheitlichen Verwaltungstool zusammen und fügen Sie Funktionen zur Bearbeitung von Cron-Aufgaben hinzu. (#7445)
  • Rekonstruieren Sie die integrierte Tool-Verwaltungslogik, um die Wartung der in AstrBot integrierten Tool-Registrierung und -Aufrufe zu verbessern. (#7418) – Die meisten der integrierten Niederfrequenzbefehle wurden entfernt und die Befehlsfunktionen integriert, diese Befehle wurden in das Plug-in builtin-command-extension verschoben und die Dokumentation aktualisiert. (#7478) – Die Standardimplementierung der Websuche wurde entfernt und durch einen neuen Suchtool-Link ersetzt. (#7416) – Die Abhängigkeiten lxml und beautifulsoup4 wurden entfernt, um die Installationsgröße und die Komplexität der Abhängigkeiten zu reduzieren. (#7449) – MCP stdio-Konfigurationsüberprüfung hinzugefügt, um Startfehler und Fehlerbehebungskosten aufgrund ungültiger Konfigurationen zu reduzieren. (#7477) – Docker aktiviert no-new-privileges in der laufenden Konfiguration, um die Standardsicherheit des Containers zu verbessern. (commit)
  • Reduzieren Sie die Häufigkeit der Statusabfragen des MCP-Servers und reduzieren Sie den Overhead von Hintergrundanfragen. (#7399)
  • Hilfebefehle ignorieren interne gültige Befehle wie dashboard_update, um den Lärm der Hilfeliste zu reduzieren. (commit) – Das Pfad-Splicing-Beispiel im Dokument wurde korrigiert, um zu verhindern, dass Plug-in-Entwicklungsspeicherdokumente Benutzer irreführen. (#7448)
  • Matrix-Plattformkonstanten, Plattformsymbole und zugehörige Dokumentation ergänzt. (#7368)

Highlights

  • Python 3.13/3.14 startup fix (the reason for this hotfix) — python-ripgrep is pinned back to 0.0.8 (#7514) because the newer resolution broke startup on Python 3.13/3.14; if v4.23.0 crashed on boot for you, this is the fix. The same PR widens the smoke-test matrix across OSes and Python versions and adds a startup-check script, so this class of dependency regression should be caught earlier. Watch out: treat the pin as a compatibility ceiling and don't bump python-ripgrep independently.

  • Computer Use gains real filesystem tools — v4.23.0 adds local read/write/edit/Grep (ripgrep) tools plus a per-session isolated workspace (#7402). This is what moves "computer use" from demo to usable, and the per-session workspace boundary matters most for multi-tenant bots — it's what stops one session's agent touching another's files. It's also why the ripgrep dependency above is load-bearing, not incidental.

  • Search stack replaced — action required — The old default web search implementation is removed (#7416) and replaced by a new Brave Search tool (#6847). This is effectively breaking: agents that relied on built-in search lose web access until you configure Brave Search and supply a Brave API key. Related cleanup drops lxml and beautifulsoup4 (#7449), so any plugin that was leaning on those transitively must now declare them itself.

  • Built-in commands and Cron tools reorganized — migration required — Most low-frequency built-in commands were pulled out of core into the builtin_commands_extension plugin (#7478); install that plugin if you need them back. Cron tools were consolidated into one management tool and gained task editing (#7445), so callers invoking the old separate cron tools need updating, and the built-in tool registration refactor (#7418) may affect custom tool integrations.

  • Providers, platforms, and behavior changes — New LongCat LLM (#7360) and NVIDIA Rerank (#7227) providers, a Mattermost adapter (#7369), OpenAI/Gemini audio input (#7378), and configurable Discord bot-message filtering (#6505) widen the surface. Behavioral changes to test in your flows: disabled STT/TTS providers now return None instead of being resolved (#7363), and repeated-tool-call guidance (#7388) tries to break agents out of tool loops. DeerFlow 2.0 support also lands in this hotfix (#7500) — DeerFlow users should re-verify their runner/API-client/provider integration.

  • Dashboard and stability polish — Code-block highlighting moves to Shiki with synced dark/light themes (#7497), platform routes now display when session IDs contain a colon : (#7517), and plugin install-status checks were corrected (#7493). Startup/runtime hardening includes deferred faiss import (#7400), a corrected Docker image name in compose (#7488), no-new-privileges enabled for Docker (#68a195e12) — which can break containers that relied on gaining privileges — and Telegram/Discord fixes for polling recovery and 10062 Unknown interaction errors (#7468, #7474).
