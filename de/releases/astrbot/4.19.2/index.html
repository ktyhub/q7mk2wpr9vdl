AstrBot v4.19.2

Was hat sich geändert?

Neu

  • Integrierter KOOK-Plattformadapter (#5658).
  • Discord-Pre-React-Emoji-Unterstützung hinzugefügt (#5609).
  • Telegram-Unterstützung für sendMessageDraft-Streaming-Echtzeitausgabe API hinzugefügt (#5726) – Unterstützt die Nachrichtenverfolgungsfunktion, wenn der Agent ausgeführt wird, und die Folgenachrichten werden in Echtzeit in den Agenten eingefügt (#5484).
  • Integrieren Sie DeerFlow Agent Runner und optimieren Sie das Streaming (#5581). – Neue Shell hinzugefügt, ipython-Tool, das Betriebssysteminformationen enthält, um die Erfolgsrate von Tool-Aufrufen unter Windows zu verbessern (#5677). – Sandbox-Unterstützung für Shipyard-neo – Unterstützung für die Selbstiteration von Fertigkeiten (#5028).
  • ChatUI WebSocket-Übertragungsmodusauswahl hinzugefügt, OpenAPI Chat API unterstützt WebSocket-Verbindung (#5410). – Unterstützen Sie die benutzerdefinierte Fehlermeldung und Ausweichlogik von Persona (#5547). – Packen Sie statische WebUI-Dateien ins Wheel und ersetzen Sie die Protokolle von astrbot CLI durch Englisch (#5665). – Verbesserte Chat-Oberfläche und mobile Reaktionserfahrung (#5635). – Optimierung der Plug-in-Fehlerbehandlungslogik und erweiterte Listeninteraktionserfahrung (#5535).

Beheben

– Nicht übereinstimmende Parameterschlüsselwörter für MCP-Initialisierungszeitüberschreitung behoben (#5743). – Die Race-Bedingung des MCP-Tools, die den Fehler „Abschluss kann nicht geparst werden“ verursachte, wurde behoben (#5534).

  • Das Problem der direkten transparenten Übertragung von Nicht-HTTPS-URLs im LINE-Adapter wurde behoben (#5697). – Das Problem des instabilen benutzerdefinierten Status der WebUI-Seitenleiste wurde behoben (#5670). – Das Problem wurde behoben, bei dem der KOOK-Adapter beim Empfang von Nachrichten und Heartbeat-Antworten redundante Debug-Protokolle ausgab. – Es wurde ein Problem behoben, bei dem die Umgebungsvariable DEMO_MODE nicht korrekt als boolescher Wert analysiert wurde (#5676). – Das Problem, dass der Subagent den Pfad des lokalen Bildes (Referenzbild) nicht korrekt empfangen konnte, wurde behoben (#5579). – Der Befehl /model wurde behoben, der zu irreführendem Verhalten beim Wechsel zu einem anderen Anbietermodell führte (#5578). – Es wurde ein Problem in Konversationsaufzeichnungen behoben, bei dem der UTC-Zeitzonenversatz nicht behandelt wurde, was zu Zeitstempelausnahmen führte (#5580). – Es wurde ein Problem behoben, bei dem doppelte Plattformstatistiken beim Importieren von Backups Ausnahmen verursachten (#5594). – Behoben, dass die max_agent_step-Konfiguration nicht auf untergeordnete Agenten angewendet wurde (#5608).
  • Sortierung der Plugin-Liste und Suchfilterlogik korrigiert (#5559). – Das Problem wurde behoben, bei dem die Node.js-Umgebung bei Verwendung von uv sync nicht erforderlich war.

Was hat sich geändert (EN)

Neue Funktionen

  • Integrierter KOOK-Plattformadapter (#5658). – Integrierter DeerFlow Agent Runner mit optimierter Streaming-Unterstützung (#5581).
  • feat(telegram): unterstützt sendMessageDraft API (#5726)
  • Integrierte Fähigkeit zur Selbstiteration von Neo-Skills mit vollständiger Lebenszyklusverwaltung (Kandidat, Freigabe, Löschung) über die Shipyard Neo-Sandbox (#5028).
  • Unterstützung für Discord-Pre-Ack-Emojis hinzugefügt (#5609). – Auswahl des WebSocket-Transportmodus für die Chat-Schnittstelle hinzugefügt (#5410). – Betriebssysteminformationen zu Toolbeschreibungen mit Unit-Test-Abdeckung hinzugefügt (#5677).
  • Verarbeitung von Folgenachrichten in ToolLoopAgentRunner hinzugefügt (#5484). – Unterstützung für benutzerdefinierte Persona-Fehlerantwortnachrichten mit Fallback-Logik hinzugefügt (#5547). – Statische WebUI-Dateien im Wheel-Paket gebündelt und astrbot CLI-Protokolle durch Englisch ersetzt (#5665). – Optimierte asynchrone E/A-Leistung und zusätzliche Benchmark-Abdeckung (#5737). – Die Erstellung des API-Schlüssels wurde überarbeitet und Komponententests für offene API-Routen hinzugefügt. – Verbesserte Fehlermeldungen für KI-Ausführungsfehler in Agent-Runnern.
  • Verbesserte Chat-Oberfläche und mobile Reaktionsfähigkeit (#5635). – Verbesserte Plugin-Fehlerbehandlung und Erweiterungslisten-UX (#5535).

Fehlerbehebungen

– Nicht übereinstimmendes MCP-Initialisierungs-Timeout-Schlüsselwort behoben (#5743). – Die Race-Bedingung der MCP-Tools, die den Fehler completion 无法解析 verursachte, wurde behoben (#5534). – LINE-Adapter behoben, der die direkte Durchleitung von Nicht-HTTPS-URLs ermöglicht (#5697). – Der instabile Anpassungsstatus der Seitenleiste in der WebUI wurde behoben (#5670). – Übermäßige Debug-Protokollierung im KOOK-Adapter für empfangene Nachrichten und Heartbeat-Antworten behoben. – Problem behoben, bei dem die Umgebungsvariable DEMO_MODE nicht korrekt als boolescher Wert analysiert wurde (#5676). – Problem behoben, bei dem der Subagent die Pfade für lokale Bilder (Referenzbilder) nicht korrekt empfangen konnte (#5579).

  • Irreführendes Verhalten des Befehls /model beim Wechsel zu einem Modell eines anderen Anbieters behoben (#5578). – Unbehandelter UTC-Zeitzonenversatz behoben, der zu falschen Zeitstempeln in Konversationsaufzeichnungen führte (#5580). – Fehler beim Backup-Import aufgrund doppelter Plattformstatistikeinträge behoben (#5594). – Behoben, dass die max_agent_step-Konfiguration nicht auf Subagenten angewendet wurde (#5608).
  • Sortierung der Plugin-Liste und Suchfilterlogik korrigiert (#5559).
  • Fehlende Node.js-Umgebungsanforderung während uv sync behoben.

Englisches Original / English original

AstrBot v4.19.2

Highlights

  • New platforms and transports — Adds a KOOK platform adapter (#5658), Discord pre-ack emoji support (#5609), Telegram sendMessageDraft streaming (#5726), and WebSocket transport selection for ChatUI/OpenAPI Chat API (#5410). These are additive: upgrade if you deploy on KOOK/Discord/Telegram or use the web chat API; existing users on other platforms won't see behavior changes.

  • Agent runtime and skill sandbox — Running Agents can now receive follow-up messages injected at runtime via ToolLoopAgentRunner (#5484), DeerFlow Agent Runner is integrated with optimized streaming (#5581), Shipyard-neo sandbox gives Skills a self-iteration lifecycle (candidate/release/deletion, #5028), shell/ipython tools now carry OS info to improve Windows tool-call success (#5677), and max_agent_step finally applies to sub-agents (#5608). Sub-agent users also get fixes for local reference-image paths (#5579) and misleading /model cross-provider switching (#5578). Relevant if you build multi-agent or tool-using bots.

  • Stability and security fixes — MCP init timeout keyword mismatch (#5743) and an MCP tools race condition producing completion 无法解析 (#5534) are fixed; LINE adapter now only passes HTTPS URLs through (#5697); DEMO_MODE parses correctly as a boolean (#5676); backup import survives duplicate platform stats (#5594); conversation records fix unhandled UTC offsets (#5580). Generally worth taking — the LINE and backup bugs can break existing deployments.

  • WebUI and plugin UX — WebUI static files are bundled into the wheel and astrbot CLI logs switched to English (#5665), sidebar customization state is stabilized (#5670), mobile responsiveness improved (#5635), and plugin list sorting/search plus failure handling are fixed (#5559, #5535). Plugin and WebUI users benefit; headless API-only deployments can skip the UI-specific changes.

  • No breaking changes; not a re-tag — No breaking changes or migration steps are documented for v4.18.3 → v4.19.2, and the release contains ~25 real PRs rather than being metadata-only. Upgrade if you use KOOK/Discord/Telegram, MCP, LINE, sub-agents, backups, or the WebUI; otherwise it's low-risk but optional.

What's Changed

新增

  • 集成 KOOK 平台适配器 (#5658)。
  • 新增 Discord pre-react Emoji 支持 (#5609)。
  • 新增 Telegram 支持 sendMessageDraft 流式实时输出 API (#5726)
  • 支持在 Agent 运行时进行消息跟进能力，跟进的消息实时注入给 Agent (#5484)。
  • 集成 DeerFlow Agent Runner 并优化流式处理 (#5581)。
  • 新增 shell, ipython tool 中包含操作系统信息，提高 windows 下 tool call 成功率 (#5677)。
  • Sandbox 支持 Shipyard-neo - 支持 Skills 自迭代 (#5028)。
  • 新增 ChatUI WebSocket 传输模式选择，OpenAPI Chat API 支持 WebSocket 连接 (#5410)。
  • 支持 Persona 自定义报错回复消息与兜底逻辑 (#5547)。
  • 将 WebUI 静态文件打包至 wheel，并将 astrbot CLI 日志替换为英文 (#5665)。
  • 增强聊天界面与移动端响应式体验 (#5635)。
  • 优化插件失败处理逻辑与扩展列表交互体验 (#5535)。

修复

  • 修复 MCP 初始化超时参数关键字不匹配的问题 (#5743)。
  • 修复 MCP 工具竞态条件导致"completion 无法解析"错误 (#5534)。
  • 修复 LINE 适配器中非 HTTPS URL 直接透传的问题 (#5697)。
  • 修复 WebUI 侧边栏自定义状态不稳定的问题 (#5670)。
  • 修复 KOOK 适配器收到消息和心跳响应时输出多余调试日志的问题。
  • 修复 DEMO_MODE 环境变量未正确解析为布尔值的问题 (#5676)。
  • 修复子 Agent 无法正确接收本地图片（参考图）路径的问题 (#5579)。
  • 修复 /model 命令切换至不同 Provider 模型时产生误导性行为的问题 (#5578)。
  • 修复对话记录中 UTC 时区偏移未处理导致时间戳异常的问题 (#5580)。
  • 修复备份导入时重复平台统计数据导致异常的问题 (#5594)。
  • 修复 max_agent_step 配置未应用到子 Agent 的问题 (#5608)。
  • 修复插件列表排序和搜索过滤逻辑 (#5559)。
  • 修复 uv sync 时未要求 Node.js 环境的问题。

What's Changed (EN)

New Features

  • Integrated KOOK platform adapter (#5658).
  • Integrated DeerFlow Agent Runner with optimized streaming support (#5581).
  • feat(telegram): supports sendMessageDraft API (#5726)
  • Integrated Neo skill self-iteration capability with full lifecycle management (candidate, release, deletion) via Shipyard Neo sandbox (#5028).
  • Added Discord pre-ack emoji support (#5609).
  • Added WebSocket transport mode selection for the chat interface (#5410).
  • Added OS information to tool descriptions with unit test coverage (#5677).
  • Added follow-up message handling in ToolLoopAgentRunner (#5484).
  • Added support for persona custom error reply messages with fallback logic (#5547).
  • Bundled WebUI static files into the wheel package and replaced astrbot CLI logs with English (#5665).
  • Optimized async IO performance and added benchmark coverage (#5737).
  • Refactored API key creation and added unit tests for open API routes.
  • Improved error messaging for AI execution failures in agent runners.
  • Enhanced chat interface and mobile responsiveness (#5635).
  • Improved plugin failure handling and extension list UX (#5535).

Bug Fixes

  • Fixed MCP initialization timeout keyword mismatch (#5743).
  • Fixed MCP tools race condition causing completion 无法解析 error (#5534).
  • Fixed LINE adapter allowing non-HTTPS URLs to pass through directly (#5697).
  • Fixed unstable sidebar customization state in WebUI (#5670).
  • Fixed excessive debug logging in KOOK adapter for received messages and heartbeat responses.
  • Fixed DEMO_MODE environment variable not being parsed correctly as a boolean (#5676).
  • Fixed sub-agent failing to correctly receive local image (reference image) paths (#5579).
  • Fixed misleading behavior of the /model command when switching to a model from a different provider (#5578).
  • Fixed unhandled UTC timezone offset causing incorrect timestamps in conversation records (#5580).
  • Fixed backup import failure due to duplicate platform stats entries (#5594).
  • Fixed max_agent_step config not being applied to sub-agents (#5608).
  • Fixed plugin list sorting and search filtering logic (#5559).
  • Fixed missing Node.js environment requirement during uv sync.
