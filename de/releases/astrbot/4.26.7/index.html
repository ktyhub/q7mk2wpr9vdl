Hinzugefügt

  • ChatUI-inline-interaktive GenUI-Unterstützung hinzugefügt. (#8712)

  • Kompensiert für teilweise fehlgeschlagene Uploads der Wissensdatenbank. (#9007, #9246) – Doppelte Plattformprotokolle aus dem Dashboard entfernt. (#9291) – Das Kopieren von Codeblöcken auf unsicheren HTTP-Ursprüngen wurde wiederhergestellt. (#9267)
  • ChatUI-Folgenachrichten wurden korrekt behandelt. (#9309)
  • Absturz von python-ripgrep auf Python 3.14 vermieden. (#9244)
  • Es wurde verhindert, dass Zweckerklärungen vor jedem Werkzeugaufruf angezeigt wurden. – Der Befehls-Tooltip wurde ausgeblendet, während das Vorschlagsfenster geöffnet ist. (#9312) – Die Zuordnung von Plugin-Repository-URLs als Plugin-Namen wurde gestoppt. (#9314) – Akzeptierte UTF-8-Stücklistenmarkierungen in Plugin-Schemas. (#9223)
  • Plugin-Handler-Bindung idempotent gemacht, um doppelte self-Argumente zu verhindern. (#9316)

Englisches Original / English original

AstrBot v4.26.7

Highlights

  • Interactive ChatUI responses — Inline GenUI support (#8712) lets chat responses render interactive generated UI instead of relying solely on text. Corrected follow-up handling (#9309) is also important for multi-turn interactions with those UI elements.

  • Agent observability and context control — Statistics now stream after each LLM call (#9260), giving developers incremental visibility into agent execution. A configured context limit takes precedence when available (#9263), making effective prompt budgeting more predictable.

  • Expanded retrieval configuration — A TEI rerank provider (#9274) adds another backend option for retrieval pipelines, while configurable embedding-dimension send modes (#9245) help match different provider contracts. Verify your selected dimensions and mode before switching providers.

  • Asynchronous configuration persistence — Snapshot saves are now asynchronous and revision-aware (#9300), avoiding event-loop stalls and preventing older saves from overwriting newer state. Integrations that assumed immediate save completion should account for asynchronous behavior.

  • Fewer plugin integration failures — Handler binding is now idempotent, preventing duplicate self arguments (#9316). Plugin schemas can contain UTF-8 BOM markers (#9223), and repository URLs are no longer mistaken for plugin names (#9314).

  • Runtime and failure-path hardening — The python-ripgrep crash on Python 3.14 is fixed (#9244), partial knowledge-base upload failures receive compensation (#9007, #9246), and dashboard API errors have a catch-all handler (#9271). Compensation improves recovery but should not be treated as a guarantee that every document was indexed.

No breaking changes announced.

4.26.7 - 2026-07-18

Added

  • Added ChatUI inline interactive GenUI support. (#8712)
  • Added streaming agent statistics after each LLM call. (#9260)
  • Added a rerank provider for Text Embeddings Inference (TEI). (#9274)
  • Added configurable embedding dimension send modes. (#9245)

Changed

  • Streamlined and simplified the WebUI sidebar. (#9233, #9313)
  • Made configuration snapshot saves asynchronous and revision-aware to avoid blocking event loops and overwriting newer state. (#9300)
  • Optimized repeated tool call detection by comparing tool names and arguments. (#9311)
  • Translated core logs into English. (#9318)

Fixed

  • Prioritized the configured context limit when one is available. (#9263)
  • Removed unsaved provider sources locally when they are deleted. (#9264)
  • Corrected Skills download archive filenames for versioned skill names. (#9270)
  • Added a catch-all exception handler for dashboard API errors. (#9271)
  • Compensated for partial knowledge base upload failures. (#9007, #9246)
  • Removed duplicate platform logs from the dashboard. (#9291)
  • Restored code block copying on insecure HTTP origins. (#9267)
  • Handled ChatUI follow-up messages correctly. (#9309)
  • Avoided a python-ripgrep crash on Python 3.14. (#9244)
  • Prevented purpose explanations from appearing before every tool call.
  • Hid the command tooltip while the suggestion panel is open. (#9312)
  • Stopped matching plugin repository URLs as plugin names. (#9314)
  • Accepted UTF-8 BOM markers in plugin schemas. (#9223)
  • Made plugin handler binding idempotent to prevent duplicate self arguments. (#9316)
