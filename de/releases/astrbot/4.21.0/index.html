AstrBot v4.21.0

Was hat sich geändert?

Neu

  • Kategoriefilter und optimierte Schnittstellenkomponenten für den Plug-in-Markt hinzugefügt. (#6762)
  • Kimi Coding Plan Provider hinzugefügt (kompatibel mit Anthropic API). (#6559)
  • Vereinheitlichte und umbenannte skill.md-Dateien in SKILL.md. (#6757)
  • Ollama-Aus-Denkmodus-Schalter hinzugefügt. (#5941)
  • Xiaomi MiMo TTS- und STT-Anbieter hinzugefügt. (#6643)
  • Multimodale Kontext-Token-Zählfunktionen hinzugefügt (Bilder, Audio und Gedankenketten). (#6596) – Es wurde die Möglichkeit hinzugefügt, Plug-ins anhand des Namens der Metainformationen zu installieren und importierbare Identifikatoren zu überprüfen. (#6530)

Optimierung

  • kook_type in StrEnum auf (str, Enum) gesenkt, um die Kompatibilität mit der älteren Version Python zu gewährleisten. (#6512)
  • Optimieren Sie die Verarbeitung von WebChat-Nachrichten: Speichern Sie Nachrichten im Voraus und verbessern Sie den Abschluss des Streamings. (#6698)
  • Optimieren Sie das Layout der mobilen Persona-Auswahl im Dashboard. (#5907)
  • Optimieren Sie das Dashboard, reduzieren Sie den Schriftbereich der MDI-Symbole und hosten Sie Google Fonts selbst. (#6532)
  • Verwenden Sie Pydantic, um das Datenmodell des KOOK-Adapters zu rekonstruieren, um die Analyse- und Überprüfungsleistung der Nachrichtenstruktur zu verbessern. (#5719)
  • Passen Sie die Terminologie und Ausdrücke des Dokuments an (ändern Sie „Nachrichtenplattform“ in „Roboter“ usw.) und optimieren und aktualisieren Sie den Beschreibungstext. (#6568)

Beheben

– Das Problem wurde behoben, bei dem deaktivierte Systemfunktionen in Websuchtools nicht korrekt wirksam wurden. (#6584)

  • Überspringen Sie die Einbettungsstapel leerer Wissensdatenbanken, um unnötige Berechnungen zu vermeiden. (#6106) – Es wurde ein Problem behoben, bei dem Feishu-Opusdateien in Whisper API STT-Szenarien nicht korrekt konvertiert wurden. (#6078)
  • Der Erstellungs- und Wiederaufnahmeprozess der Lark-Karte wurde behoben, wenn der Tool-Aufruf unterbrochen wurde. (#6743) – Problem mit der Kompatibilität der Skilldatei-Kodierung in der Windows-Umgebung behoben. (#6058) – Es wurde ein Problem behoben, bei dem separat von WebChat gerenderte HTML-Antworten falsch angezeigt wurden. (#6074) – Das Problem des fehlenden Felds items im Gemini-Array-Schema wurde behoben. (#6051) – Es wurde ein Problem mit Fertigkeiten behoben, die hartcodierte Arbeitsbereichspfade verwendeten und stattdessen die echten Sandbox-Pfade im Cache verwendeten. (#6331)
  • Zeitüberschreitung bei der Zustellung von Subagent-Tool-Aufrufen behoben, tool_call_timeout behoben und Standard-Zeitüberschreitung von 60 Sekunden auf 120 Sekunden erhöht. (#6713) – Das Problem wurde behoben, dass die Bildbeschreibung nicht eingefügt wurde, wenn extra_user_content_parts unter skills-like fehlte. (#6710)
  • Das Problem der Weiterverarbeitung nachfolgender Folgenachrichten nach /stop wurde behoben. (#6704) – Das Verhalten des Kernprozesses, der das Warten des Subagenten-Tools unterbrach, wenn er angehalten wurde, wurde behoben. (#5850) – Das Problem des fehlenden stdio MCP-Dienstes PATHEXT auf der Windows-Plattform wurde behoben. (#5822)
  • Der Mechanismus zum Neustart der Telegrammabfrage wurde behoben, um die Schleife automatisch fortzusetzen, wenn sie fehlschlägt. (#6648) – Das Problem wurde behoben, dass der Folgestatus nach /stop nicht gelöscht wurde, was dazu führte, dass nachfolgende Trigger weiter ausgeführt wurden. (#6656) – Das OpenAI-Konfigurationsprotokoll wurde korrigiert, um die Lesbarkeit und Fehlerbehebungsfunktionen des Agenten und der API-Basis zu verbessern. (#6669) – Das Problem der Kürzungslogik wurde behoben, wodurch versehentlich die einzige Benutzernachricht in langen Tool-Aufrufen gelöscht wurde. (#6198) – Das Problem wurde behoben, bei dem der Truncater eindeutige Benutzernachrichten entfernte, was dazu führte, dass einige Anbieter 400 zurückgaben. (#6581) – Das Problem wurde behoben, bei dem der Kopiertext der Eingabeaufforderung unklar war, wenn die ID-Whitelist leer war. (#6611) – Das Problem mit der fehlenden OpenAI-Token-Nutzung unter der offiziellen Version von MoonshotAI API wurde behoben. (#6618)
  • Verbessern Sie die Lesbarkeit und Geschwindigkeit des Wecom AI Bot-Streamings (aktuell begrenzte Verarbeitung) und verbessern Sie die Verzögerung und das Anzeigeerlebnis. (#6610)
  • Das Problem, dass die Wecom-Antwort bei einer langen Verbindung verschwand, wurde behoben. (#6606) – Das Problem mit der Konfiguration der Pip-/nativen Build-Umgebung während der Windows-Paketlaufzeit wurde behoben. (#6575) – Korrektur, um die Einbettung von dimensions nur bei expliziter Konfiguration zu übergeben, um Störungen durch ungültige Parameter zu vermeiden. (#6432)
  • Behebung von NameError, verursacht durch register_agent-Dekorator. (#5765) – Das Problem des Subagenten-Abfragefehlers im Standard-Persona-Szenario wurde behoben. (#5672)
  • Das Problem, dass das Lesen von Fertigkeiten unter Windows fehlschlug, wurde behoben. (#6490)
  • Problem beim Parsen mehrzeiliger Frontmatter SKILL.md behoben. (#6460) – Das SQLite database is locked-Problem wurde behoben und eine Auslastungs-Timeout-Verarbeitung hinzugefügt. (#6474)
  • Workflow-Einschränkung behoben, die nur von vorgelagerten Lagern ausgelöste Fehlerszenarien zulässt. (#6531)

Was hat sich geändert (EN)

Neue Funktionen

  • Kategoriefilterung für Markt-Plugins und verbesserte UI-Komponenten hinzugefügt.
  • Normalisierte und umbenannte skill.md-Dateien in SKILL.md. – Ein Schalter zum Deaktivieren des Denkmodus in Ollama wurde hinzugefügt.
  • Xiaomi MiMo TTS- und STT-Anbieter hinzugefügt.
  • Kimi Coding Plan-Anbieter mit Anthropic API-Kompatibilität hinzugefügt. – Unterstützung für die Zählung von Kontext-Token für multimodale Inhalte (Bilder, Audio und Gedankenkette) hinzugefügt.
  • Plugin-Installation nach Metadatennamen und validierten importierbaren Identifikatoren hinzugefügt.

Verbesserungen

  • StrEnum zu (str, Enum) in kook_type umgestaltet, um Abwärtskompatibilität zu gewährleisten.
  • Verbesserte WebChat-Nachrichtenverarbeitung mit proaktiver Speicherung und Streaming-Vervollständigung.
  • Vereinfachtes Layout der Dashboard-Persona-Auswahl für mobile Bildschirme.
  • Teilmenge der MDI-Symbolschriftart und selbstgehosteter Google-Schriftarten im Dashboard. – Implementierung von Pydantic-Datenmodellen für den KOOK-Adapter für eine bessere Abfrage und Schemavalidierung.
  • Aktualisierter Dokumentationstext für unvollständige Aktualisierungen der Terminologie.

Fehlerbehebungen

  • Leere Einbettungsstapel für die Wissensdatenbank wurden übersprungen.
  • Konvertierte Feishu-Opusdateien für Whisper API STT.

  • Abgelehnte Folgenachrichten nach /stop-Anfrage. – Unterbrochenes Subagent-Tool wartet auf Stopp. – PATHEXT für Standard-MCP-Server unter Windows beibehalten.
  • Automatischer Neustart für die Telegram-Abfrageschleife bei Fehler hinzugefügt. – Nachfolge-Persistenzlogik nach /stop-Trigger behoben.
  • Verbesserte OpenAI-Proxy/API-Basisprotokollierung. – Es wurde verhindert, dass durch die Kürzungslogik die einzige Benutzernachricht in langen Tool-Aufrufkonversationen entfernt wurde. – Die Kürzung wurde behoben, indem bei einigen Anbietern die einzige Benutzernachricht entfernt und 400 zurückgegeben wurde.
  • Aktualisierter Hinweistext zur ID-Whitelist bei leerer Konfiguration.
  • Die Token-Nutzung mit dem offiziellen MoonshotAI API wurde behoben.
  • Verbesserte Lesbarkeit und Geschwindigkeit des Wecom AI Bot-Streamings durch Drosselung.
  • Es wurde verhindert, dass die Antworten des Wecom AI Bot bei langer Verbindung verschwinden. – Legen Sie die gepackte Windows-Laufzeit-Build-Umgebung für native Pip-Builds fest.
  • Übergeben Sie Einbettungsdimensionen nur, wenn sie explizit konfiguriert sind.
  • register_agent-Dekorator NameError behoben. – Fehler bei der Suche nach Subagenten bei Verwendung der Standardpersona behoben.
  • Lesefähigkeiten unter Windows korrigiert.

AstrBot v4.21.0

Highlights

  • Skill packaging migration — Legacy skill.md files are normalized to SKILL.md (#6757), so existing skills should migrate automatically; plugin authors should still audit case-sensitive references. Multiline frontmatter, Windows encoding, and cached-sandbox path fixes (#6460, #6058, #6331) make skill loading more reliable across environments.
  • Provider and plugin expansion — Kimi Coding Plan adds Anthropic-compatible access (#6559), Xiaomi MiMo adds TTS/STT (#6643), and Ollama can now disable thinking (#5941). Plugin-market category filtering and metadata-name installation with import-identifier validation (#6762, #6530) make discovery and installation less error-prone.
  • OpenAI-compatible configuration — The provider label becomes “OpenAI Compatible” (#6707). Embedding requests send dimensions only when explicitly configured (#6432), and OpenAI embedding base URLs no longer receive an automatic /v1 suffix (#6669); custom endpoints that relied on implicit suffixing must include it explicitly.
  • Cancellation and subagent lifecycle — /stop now rejects follow-ups, clears persisted follow-up state, and interrupts subagent tool waits (#6704, #6656, #5850). tool_call_timeout now reaches handoff, cron, and background tasks, with the default raised from 60s to 120s (#6713)—long-running jobs get more headroom, but automations must treat /stop as terminal for pending follow-ups.
  • Context and integration reliability — Token accounting now covers images, audio, and chain-of-thought (#6596); truncation preserves the sole user message to prevent provider 400 responses (#6198, #6581), and Gemini array schemas always include items (#6051). SQLite busy timeouts, Telegram polling recovery, Windows MCP/native-build fixes, and KOOK’s Pydantic and older-Python compatibility changes reduce platform-specific failures (#6474, #6648, #5822, #6575, #5719, #6512).
  • Compatibility — No declared breaking changes.

What's Changed

新增

  • 为插件市场新增分类筛选并优化界面组件。（#6762）
  • 新增 Kimi Coding Plan Provider（兼容 Anthropic API）。（#6559）
  • 统一并重命名 skill.md 文件为 SKILL.md。（#6757）
  • 新增 Ollama 关闭思考模式开关。（#5941）
  • 新增小米 MiMo TTS 与 STT Provider。（#6643）
  • 新增多模态上下文 token 计数能力（图片、音频与思维链）。（#6596）
  • 新增按元信息名称安装插件并校验可导入标识符。（#6530）

优化

  • 降低 kook_type 中 StrEnum 到 (str, Enum) 以兼容旧版本 Python。（#6512）
  • 优化 WebChat 消息处理：提前保存消息并增强流式补全。（#6698）
  • 优化 Dashboard 中移动端 persona 选择器布局。（#5907）
  • 优化 Dashboard，减少 MDI icon font 范围并自托管 Google Fonts。（#6532）
  • 使用 Pydantic 重构 KOOK 适配器数据模型以提升消息结构解析与校验性能。（#5719）
  • 调整文档术语与表达（“消息平台”改为“机器人”等）并优化更新说明文字。（#6568）

修复

  • 修复 web search tools 中被禁用系统函数时未正确生效的问题。（#6584）
  • 跳过空的知识库嵌入批次，避免不必要计算。（#6106）
  • 修复 Feishu opus 文件在 Whisper API STT 场景下未正确转换的问题。（#6078）
