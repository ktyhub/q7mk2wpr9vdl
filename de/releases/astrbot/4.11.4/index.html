AstrBot v4.11.4

Was hat sich geändert?

Korrekturen

– Bild-MIME-Typ aus Binärdaten für Anthropic API erkennen (#4426)

  • Korrigieren Sie das doppelte Wort in der Agent-Logger-Warnung (#4390)
  • LLM-Kontext nach Modalitäten desinfizieren (#4367) – Problem behoben, bei dem die Listenkonfiguration nach dem Löschen als [""] statt als [] gespeichert wurde (#4401)

Verbesserungen

  • EULA hinzugefügt.
  • Antwortfunktion erweitern, um ausgewählte Textzitate zu unterstützen (#4387) – Stellen Sie die atomare Erstellung der Wissensdatenbank mit ordnungsgemäßer Bereinigung bei Fehlern sicher (#4406) – Nullprüfung für Plugin-Liste in der Konfiguration hinzugefügt, um das Problem mit leeren Listen zu beheben (#4392)
  • Bildplatzhalter für Nicht-Vision-Modelle hinzugefügt, um zu beheben, dass im privaten Chat keine Antwort erfolgt (#4411)
  • Versionsnummer-Tag an Protokolle der Stufen WARN und ERROR anhängen (#4388)
  • Plugin-Readme-Markdown-Rendering optimieren und überflüssigen Code entfernen (#4415)
  • Ungültige Plattform-IDs beim Laden bereinigen (#4432)
  • Gesunder LLM-Modus (#4431)

  • fix(webui): unerwartete Erweiterung aller Zeilen in der Werkzeugtabelle durch @letr007 in https://github.com/AstrBotDevs/AstrBot/pull/4366 behoben
  • Fix: wenn session_id „:“ von @stevessr in https://github.com/AstrBotDevs/AstrBot/pull/4380 enthält
  • Fix: Nullprüfung für Plugin-Liste in der Konfiguration hinzugefügt, um das Problem mit leeren Listen von @advent259141 in https://github.com/AstrBotDevs/AstrBot/pull/4392 zu beheben
  • fix(core): doppeltes Wort in der Agent-Logger-Warnung von @letr007 in https://github.com/AstrBotDevs/AstrBot/pull/4390 korrigiert
  • Fix: Bildplatzhalter für Nicht-Vision-Modelle hinzugefügt, um zu beheben, dass im privaten Chat von @advent259141 in https://github.com/AstrBotDevs/AstrBot/pull/4411 keine Antwort erfolgt
  • feat(context): Bereinigen Sie den LLM-Kontext durch Modalitäten von @Futureppo in https://github.com/AstrBotDevs/AstrBot/pull/4367

  • Kunststück (Sicherheit): LLM-Gesundheitsmodus von @Soulter in https://github.com/AstrBotDevs/AstrBot/pull/4431

AstrBot v4.11.4

What's Changed

Fixes

  • detect image MIME type from binary data for Anthropic API (#4426)
  • correct duplicate word in agent logger warning (#4390)
  • sannitize llm context by modalities (#4367)
  • fix list config being saved as [""] instead of [] after deletion (#4401)

Improvements

  • Added EULA.
  • enhance reply functionality to support selected text quoting (#4387)
  • ensure atomic creation of knowledge base with proper cleanup on failure (#4406)
  • add null check for plugin list in config to fix empty list issue (#4392)
  • add image placeholder for non-vision models to fix no response in private chat (#4411)
  • append version number tag to WARN and ERROR level logs (#4388)
  • optimize plugin readme markdown rendering and remove redundant code (#4415)
  • sanitize invalid platform IDs on load (#4432)
  • LLM healthy mode (#4431)
