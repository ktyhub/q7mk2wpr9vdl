<img width="1865" height="1147" alt="Gruppe 115" src="https://github.com/user-attachments/assets/1f72ed6f-1f2b-4f89-a033-66b572c6bd90" /> > ⚠️ **Zeitstempel enthalten Millisekunden.** Auf PostgreSQL und SQLite enthalten Datums- und Zeitwerte in API-Antworten, Webhook-Payloads und CSV-Exporte jetzt Millisekunden (`12:34:56.000+00:00`). Überprüfen Sie Integrationen, die Datumsangaben in einem festen Format lesen. > **MCP listet jedes Tool auf.** Der MCP-Server bei `/mcp` listet jetzt jedes Tool auf. Wenn Windsurf oder VS Code Copilot zu viele Tools anzeigt, verbinden Sie es erneut mit der `/mcp-discovery`-URL. [Weitere Informationen](https://docs.nocodb.com/docs/mcp#clients-that-cap-the-tool-list) > **Passwortänderungen melden Ihre Apps ab.** Wenn Sie Ihr Passwort ändern, werden Ihre API-Tokens gelöscht und Apps, die Sie mit OAuth autorisiert haben, werden getrennt. [Weitere Informationen](https://nocodb.com/docs/product/account-settings/api-tokens#password-changes-delete-your-tokens) ## Verbesserungen - **Klassische Apps auf Telefonen** – Veröffentlichte klassische Apps passen auf Telefonbildschirme, einschließlich Seitenleiste, Symbolleisten, Datensatzformulare, Dashboard-Gruppen und Pivot-Widgets. - **Nach mehr Feldtypen gruppieren** – Klassische App-Seiten werden nach Feldern für Links, Formel, Suche, Rollup und Linkanzahl gruppiert, und Listen-Widgets erhalten eine Gruppierung nach Einstellung. [Weitere Informationen](https://docs.nocodb.com/docs/classic-apps/layouts/table#grid) - **Spaltengröße in klassischen Apps ändern** - Ziehen Sie einen Spaltenrand in einem Listen-Widget, um dessen Größe zu ändern. Bauherren sparen die Breite für alle. [Weitere Informationen](https://docs.nocodb.com/docs/classic-apps/layouts/table#list) - **Datensätze über Ansichts-Widgets öffnen** – Kalender-, Zeitleisten- und Gantt-Widgets auf einem Dashboard können einen Datensatz öffnen, wenn Sie ihn markieren. [Weitere Informationen](https://docs.nocodb.com/docs/classic-apps/layouts/dashboard#configuring-widgets) - **Widget-Titel ausblenden** – Daten-, Diagramm- und Zahlen-Widgets in einer klassischen App verfügen über einen Schalter *Titel anzeigen*. - **Schaltflächensichtbarkeit nach Rolle** – Seitenschaltflächen in einer klassischen App können nur für die von Ihnen ausgewählten Rollen angezeigt werden. [Weitere Informationen](https://docs.nocodb.com/docs/classic-apps/elements#buttons) - **Benutzerfilter-Registerkarten neu anordnen** – Builder ziehen Benutzerfilter-Registerkarten in eine neue Reihenfolge. [Weitere Informationen](https://docs.nocodb.com/docs/classic-apps/elements#user-filters) - **Einzelauswahl nach Optionsreihenfolge sortieren** – Eine Sortierung in einem Einzelauswahlfeld kann der Reihenfolge seiner Optionen statt A bis Z folgen. [Weitere Informationen](https://docs.nocodb.com/docs/product/tables/table-operations/sort#sort-a-single-select-field-by-option-order) - **Von anderen Geräten abmelden** - *Konto* > *Sicherheit* meldet Sie überall ab, außer im aktuellen Browser in der NocoDB Cloud. [Weitere Informationen](https://docs.nocodb.com/docs/product/account-settings/authentication/sign-out-other-devices) - **Vorlagen auf der Startseite** – Auf der Startseite und auf der Seite „Neues Projekt“ wird eine Vorlagengalerie in der NocoDB Cloud angezeigt. Mit KI erstellte Projekte beginnen mit einigen Beispieldatensätzen. [Weitere Informationen](https://docs.nocodb.com/docs/product/projects/create-project#from-template) - **Griechisch** – NocoDB ist jetzt auf Griechisch verfügbar. [Weitere Informationen](https://docs.nocodb.com/docs/product/account-settings/language) - **MCP-Ratenlimits** – MCP hat sein eigenes Limit pro Konto. Einem client, ​​der darüber geht, wird mitgeteilt, wie lange er warten soll. - **Mit MCP verbundene Apps** – Die Liste der verbundenen Apps zeigt, wann jede App zuletzt verwendet wurde. [Weitere Informationen](https://docs.nocodb.com/docs/mcp/connections#managing-and-removing-access) - **OAuth-Zustimmungsbildschirm** – Der Zustimmungsbildschirm zeigt, wohin Sie weitergeleitet werden, und warnt, wenn eine App nicht von NocoDB überprüft wird. - **Live-Updates** – Galerie, Kanban, Karte, Dashboards und klassische App-Datensatzüberprüfung werden direkt aktualisiert, wenn Mitarbeiter Änderungen vornehmen. ## Was wurde behoben? - **Workflows und Webhooks** - *Bei Datensatzaktualisierung* werden Workflows und Aktualisierungs-Webhooks ausgeführt, wenn Datensätze über API, Einfügen oder eine Fremdschlüsseländerung verknüpft oder aufgehoben werden. [Weitere Informationen](https://docs.nocodb.com/docs/workflows/nodes/trigger-nodes/record-updated#how-it-works) - **Formeln** – Formeln mit `?` im Text werden ausgewertet, Kontrollkästchenwerte fungieren in PostgreSQL-Formeln als 1 und 0 und XOR-Ergebnisse können gefiltert werden. - **Filter** – *ist leer* Filter für Rollups funktionieren und *Gefällt mir*-Filter für Benutzerfelder stimmen nur mit Namen überein. - **Links** – Selbstverknüpfende Eins-zu-eins-Felder zeigen den verknüpften Datensatz an und duplizierte Projekte behalten ihre Links. - **Daten kopieren** – Beim Duplizieren und Importieren eines Projekts bleiben Langtext- und JSON-Werte länger als 100.000 Zeichen erhalten. - **Klassische Apps** – Suche im Builder, Linkauswahl in Formularen, Zeitleistenbeschriftungen, Standardseitennamen, nicht ausgeblendete Formularfelder, Listen-Bildlaufleisten und bedingte Zeilenfarben verhalten sich wie erwartet. - **Teilen** – Der klassische App-Dialog *Teilen* kann einem bestehenden Mitglied eine höhere Rolle zuweisen, und eine zweite Einladung sorgt dafür, dass der erste Einladungslink funktioniert. - **Anhänge** – Escape- und Pfeiltasten funktionieren in der Anhangvorschau überall dort, wo sie geöffnet wird. - **Tabellen** – Eine neue Tabelle kann den Namen einer gelöschten Tabelle annehmen, sogar in der Nähe der Längenbeschränkung des Datenbanknamens. - **SQL Server und Oracle** – Sortierungen, die ein Feld wiederholen, funktionieren auf SQL Server, und auf Oracle wird ein Zahlenfeld in eine Dezimalzahl konvertiert und Textformeln werden sortiert. - **KI-Chat** – Der Chat funktioniert mit den Integrationen Claude Opus 5.5, Sonnet 5.5 und Fable 5.1. - **Anmelden** – Wenn Sie Ihr Passwort vergessen, werden Sie nicht mehr abgemeldet und bei Anmeldefehlern wird für jeden Fall eine Meldung angezeigt. ## Hinweise zum Selbsthosting - **Erste Anmeldung** – Bei einer neuen lizenzierten Installation erhält der erste Superadministrator den Standardarbeitsbereich und die Standardorganisation ohne Neustart. - **Lizenzaktualisierung** – Durch *Aktualisieren* auf der Lizenzseite oder einen Neustart wird eine Lizenz aktiviert, die als ausstehend angezeigt wird. [Weitere Informationen](https://docs.nocodb.com/docs/self-hosting/license-activation#refresh-license) - **Sichere Anhänge** – Wenn Sie nur `NC_ATTACHMENT_ACCESS_CONTROL_ENABLED=true` festlegen, werden jetzt sichere Anhänge aktiviert, sodass `/download` und `/dl` keine Dateien mehr bereitstellen. Verwenden Sie die signierten URLs, die von Anhangantworten zurückgegeben werden. [Weitere Informationen](https://docs.nocodb.com/docs/self-hosting/environment-variables#storage) - **Lokale Datenbanken** – ClickHouse in einem privaten Netzwerk und MySQL oder PostgreSQL über einen Unix-Socket, benötigen `NC_ALLOW_LOCAL_EXTERNAL_DBS=true`. [Weitere Informationen](https://docs.nocodb.com/docs/self-hosting/environment-variables#product-configuration) - **MCP-Tokens** – MCP-Token-Geheimnisse werden gehasht gespeichert und nur einmal angezeigt. Token, die sich bereits in Ihren MCP clients befinden, funktionieren weiterhin. - **Lange Tabellennamen** – Neue SQL Server- und Oracle-Tabellennamen sind auf 125 Zeichen beschränkt. - **Sicherheitshärtung** – Anmeldung, Einladungen, OAuth, freigegebene Ansichten, Datenexporte, Datenbankverbindungen und gespeicherte Geheimnisse werden gehärtet und Abhängigkeiten werden gepatcht. --- Weitere Einzelheiten zu den in 2026.10.0 eingeführten Funktionen finden Sie unter [2026.10.0 changelog](https://docs.nocodb.com/docs/changelog/2026.10.0). – [**geschlossen**] Das Ändern des Passworts zeichnet ein doppeltes Anmeldeüberwachungsereignis auf und bricht die aktuelle Sitzung ab, wenn der Widerruf des OAuth-Tokens fehlschlägt [#14939](https://github.com/nocodb/nocodb/issues/14939) - nocodb 2026.10.1

<img width="1865" height="1147" alt="Group 115" src="https://github.com/user-attachments/assets/1f72ed6f-1f2b-4f89-a033-66b572c6bd90" />

⚠️ Timestamps include milliseconds. On PostgreSQL and SQLite, date and time values in API responses, webhook payloads and CSV exports now include milliseconds (12:34:56.000+00:00). Check integrations that read dates in a fixed format.

MCP lists every tool. The MCP server at /mcp now lists every tool. If Windsurf or VS Code Copilot shows too many tools, connect it again with the /mcp-discovery URL. Learn more

Password changes sign out your apps. Changing your password deletes your API tokens and disconnects apps you authorized with OAuth. Learn more

Improvements

  • Classic apps on phones - Published classic apps fit phone screens, including the sidebar, toolbars, record forms, dashboard groups and pivot widgets.
  • Group by more field types - Classic app pages group by Links, Formula, Lookup, Rollup and link count fields, and List widgets get a group by setting. Learn more
  • Resize columns in classic apps - Drag a column edge in a List widget to resize it. Builders save the width for everyone. Learn more
  • Open records from view widgets - Calendar, Timeline and Gantt widgets on a dashboard can open a record when you click it. Learn more
  • Hide widget titles - Data, chart and number widgets in a classic app have a Show title switch.
  • Button visibility by role - Page buttons in a classic app can show only to the roles you choose. Learn more
  • Reorder user filter tabs - Builders drag user filter tabs into a new order. Learn more
  • Sort Single Select by option order - A sort on a Single Select field can follow the order of its options instead of A to Z. Learn more
  • Sign out of other devices - Account > Security signs you out everywhere except the current browser on NocoDB Cloud. Learn more
  • Templates on Home - Home and the New project page show a template gallery on NocoDB Cloud, and projects built with AI start with a few sample records. Learn more
  • Greek - NocoDB is now available in Greek. Learn more
  • MCP rate limits - MCP has its own limit per account. A client that goes over it is told how long to wait.
  • MCP connected apps - The list of connected apps shows when each app was last used. Learn more
  • OAuth consent screen - The consent screen shows where you will be sent and warns when an app is not verified by NocoDB.
  • Live updates - Gallery, Kanban, Map, dashboards and classic app record review refresh in place when collaborators edit.

What's Fixed

  • Workflows and webhooks - When record updated workflows and update webhooks run when records are linked or unlinked through the API, paste or a foreign key change. Learn more
  • Formulas - Formulas with ? inside text evaluate, Checkbox values act as 1 and 0 in PostgreSQL formulas, and XOR results can be filtered.
  • Filters - is blank filters on Rollups work, and like filters on User fields match names only.
  • Links - Self-linking one-to-one fields show the linked record, and duplicated projects keep their links.
  • Copying data - Duplicating and importing a project keeps Long Text and JSON values longer than 100,000 characters.
  • Classic apps - Search in the builder, link pickers in forms, Timeline labels, default page names, unhidden form fields, list scrollbars and conditional row colors behave as expected.
  • Sharing - The classic app Share dialog can give an existing member a higher role, and a second invite keeps the first invite link working.
  • Attachments - Escape and arrow keys work in the attachment preview everywhere it opens.
  • Tables - A new table can take a trashed table's name, even near the database name length limit.
  • SQL Server and Oracle - Sorts that repeat a field work on SQL Server, and on Oracle a Number field converts to Decimal and text formulas sort.
  • AI chat - Chat works with Claude Opus 5.5, Sonnet 5.5 and Fable 5.1 integrations.
  • Sign-in - Forgetting your password no longer signs you out, and sign-in errors show one message for every case.

Self-Hosting Notes

  • First sign-up - On a new licensed install, the first super admin gets the default workspace and organization without a restart.
  • License refresh - Refresh on the License page, or a restart, activates a license that shows as pending. Learn more
  • Secure attachments - Setting only NC_ATTACHMENT_ACCESS_CONTROL_ENABLED=true now turns on secure attachments, so /download and /dl stop serving files. Use the signed URLs that attachment responses return. Learn more
  • Local databases - ClickHouse on a private network, and MySQL or PostgreSQL over a Unix socket, need NC_ALLOW_LOCAL_EXTERNAL_DBS=true. Learn more
  • MCP tokens - MCP token secrets are stored hashed and shown only once. Tokens already in your MCP clients keep working.
  • Long table names - New SQL Server and Oracle table names are limited to 125 characters.
  • Security hardening - Sign-up, invitations, OAuth, shared views, data exports, database connections and stored secrets are hardened, and dependencies are patched.

For more details on the features introduced in 2026.10.0, see the 2026.10.0 changelog.
