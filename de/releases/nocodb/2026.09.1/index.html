<img width="1865" height="1147" alt="image" src="https://github.com/user-attachments/assets/c97fae32-5349-432f-beaf-1e8559e60a2f" /> ## Verfügbarkeit | Funktion | Community-Edition | Cloud-kostenloser Plan | Bezahlte Pläne in der Cloud/vor Ort | | --- | :---: | :---: | :---: | | Kontoweite MCP-Verbindungen | – | ✅ | ✅ | | Tischwerkzeuge | ✅ | ✅ | ✅ | | In der Zeitleistenansicht zusammenfassen | – | – | ✅ | | Verfolgen Sie bestimmte Felder in „Zuletzt geändert“ | ✅ | ✅ | ✅ | | YouTrack-Synchronisierung | – | – | ✅ | Für die Timeline-Ansicht ist der Business-Plan und höher auf NocoDB Cloud erforderlich, und für App Sync ist der Plus-Plan und höher erforderlich. ## Kontoweite MCP-Verbindungen Eine MCP-Verbindung erreicht jetzt jede Basis, die Sie auswählen, mit den von Ihnen zugelassenen Tools und nie mehr als Ihrer eigenen Rolle. Der Server verfügt jetzt über 199 Tools, 50 mehr als 2026.09.0, einschließlich Mitglieder- und Teamverwaltung, Hochladen von Anhängen, Upsert, Audit-Protokolle, Wiederherstellung des Papierkorbs und Veröffentlichung. <img width="2264" height="1566" alt="image" src="https://github.com/user-attachments/assets/6cfb0af9-0919-4810-a616-9c5252761860" /> [Erfahren Sie mehr über MCP →](https://nocodb.com/docs/apis-and-mcp/mcp) ## Tabellentools Eine einzelne Tools-Schaltfläche in der Ansichtssymbolleiste öffnet Felder, Beziehungen, Berechtigungen, Webhooks und alle anderen Tabellentools in einem Panel. <img width="1922" height="500" alt="image" src="https://github.com/user-attachments/assets/570cdf6d-06d5-4ea0-8abc-b3350e2ae68b" /> --- <img width="2498" height="1564" alt="image" src="https://github.com/user-attachments/assets/c75842b4-dd8e-4ec2-970a-1b7e4ecff9bf" /> [Erfahren Sie mehr über Tabellentools →](https://nocodb.com/docs/product/tables/table-operations/table-details) ## In der Zeitleistenansicht zusammenfassen Zeigen Sie unter jedem Tag, jeder Woche oder jedem Monat einer Zeitleiste eine Anzahl, Summe, einen Durchschnitt oder eine andere Zusammenfassung an. <img width="1924" height="1210" alt="image" src="https://github.com/user-attachments/assets/d94328a2-a098-43a6-8669-43b1172fdfa8" /> [Erfahren Sie mehr über „Zusammenfassen“ →](https://nocodb.com/docs/product/tables/views/view-types/timeline#summarize) ## Verfolgen Sie bestimmte Felder in „Zuletzt geändert“. Die Felder „Letzte Änderungszeit“ und „Zuletzt geändert von“ können nur die von Ihnen ausgewählten Felder überwachen. <img width="2290" height="1188" alt="image" src="https://github.com/user-attachments/assets/e8c45986-7db4-4d18-92f5-73a1f44dda71" /> [Weitere Informationen zum Verfolgen bestimmter Felder →](https://nocodb.com/docs/product/tables/fields/field-types/date-time-based/last-modified-time#track-specific-fields) ## YouTrack-Synchronisierung Synchronisieren Sie [YouTrack](https://www.jetbrains.com/youtrack/)-Probleme, Kommentare und Benutzer mit NocoDB zusammen mit den anderen Ticketing-Quellen. <img width="2554" height="1596" alt="image" src="https://github.com/user-attachments/assets/688a9a8f-3128-4123-b7e2-25088f5dbdf4" /> [Erfahren Sie mehr über die YouTrack-Synchronisierung →](https://nocodb.com/docs/product/sync/app-sync/ticketing#youtrack) ## Verbesserungen - **Einladungslinks** – Teilen Sie einen Link, um Personen mit der von Ihnen gewählten Rolle in eine Basis oder einen Arbeitsbereich zu bringen. [Weitere Informationen](https://nocodb.com/docs/product/collaboration/invite-links) - **Basiseinstellungen als Modal** – Einstellungen werden über Ihrer aktuellen Ansicht mit Suche geöffnet. [Weitere Informationen](https://nocodb.com/docs/product/bases/actions-on-base) - **Integrationsseite** – Zuerst Ihre Verbindungen, dann ein Katalograster mit Kategoriefiltern. [Weitere Informationen](https://nocodb.com/docs/product/integrations) - **Webhook-Triggerfelder** – Wählen Sie in späteren Schritten einzelne Text-, Header- und Abfragewerte aus. [Weitere Informationen](https://nocodb.com/docs/workflows/nodes/trigger-nodes/webhook) - **Variablen in E-Mail-Links** - E-Mail-Links senden können Workflow-Daten als Adresse verwenden. [Weitere Informationen](https://nocodb.com/docs/workflows/nodes/action-nodes/send-email) - **Schnittstellenformulare** – Felder als *erforderlich* markieren, den geöffneten Datensatz aus einem Formular aktualisieren und die Formulare einer Schaltfläche direkt verwalten. [Weitere Informationen](https://nocodb.com/docs/interfaces/layouts/form) - **Schnittstellenfilter** - Größerer *Filtern nach*-Editor mit Kopieren und Einfügen zwischen Komponenten. - **Abkürzung für große Zahlen** – In den Feldern „Zahl“, „Dezimal“ und „Währung“ kann 1.234.567 als 1,2 Mio. angezeigt werden. [Weitere Informationen](https://nocodb.com/docs/product/tables/fields/field-types/numerical/number#large-number-abbreviation) - **Excel-Exporte** – Währungs- und Dezimalexport als reelle Zahlen. [Weitere Informationen](https://nocodb.com/docs/product/tables/table-operations/download) - **Schnellere Menüs** – Dropdown-Menüs werden sofort geöffnet. - **Drag-and-Drop in der Listenansicht** – Drops werden sofort angewendet. - **Massenaktualisierung** - Neu gestaltetes Bedienfeld *Ausgewählte Datensätze aktualisieren*. ## Was wurde behoben? - **Gruppierte Raster** – Zeilen bleiben nach Echtzeitaktualisierungen in der richtigen Gruppe. - **Optionen auswählen** – Durch das Hinzufügen einer neuen Option durch Einfügen oder Eingeben bleiben vorhandene Optionen erhalten. - **Importe, Snapshots und Duplizierung** – Große Tabellen und synchronisierte Tabellen werden vollständig kopiert und Benutzerwerte werden über Arbeitsbereiche hinweg übertragen. - **Schnittstellen** – Linkwerte, Sichtbarkeitsregeln, Linkauswahl, Downloads von Anhängen und Übersichts-Coverbilder funktionieren wie erwartet. Veröffentlichte Seiten funktionieren weiterhin, nachdem ein Feld gelöscht wurde, und eingefügte Linkwerte bleiben in neuen Zeilen erhalten. - **Massenaktualisierung** – Das Aktualisieren aller Datensätze löst Webhooks und Workflow-Trigger aus. - **Kanban** – Das Neuanordnen von Karten innerhalb eines Stapels wird gespeichert. - **Workflows** – Schritte innerhalb einer Iterate-Schleife rufen beim Testen den aktuellen Datensatz ab und Felder, die mehrere Variablen kombinieren, werden korrekt aufgelöst. - **Ansichten** – Kalender- und Zeitleistenansichten ohne Datumsbereich werden korrekt dupliziert und gemeinsame Listenansichten werden geöffnet. - **Umbenannte Tabellen** – Formelanzeigewerte funktionieren nach einer Tabellenumbenennung weiterhin. - **Audit-Protokoll** – Das Filtern nach *Daten*-Ereignissen liefert Ergebnisse. - **Dokumente** – Markdown mit leeren Tabellenzellen wird korrekt eingefügt. - **API** – `null` für ein v3-Linkfeld lässt Links unverändert, v2 `in`-Filter mit mehreren Datumsangaben geben jede Übereinstimmung zurück und basisbezogene Token können ihre Basen auflisten. - **MCP** – Durch das Entfernen einer Person aus einer Basis werden nur die Verbindungen dieser Basis widerrufen, Schreibtools akzeptieren, was ihre Lesetools zurückgeben, und Datensätze, die aus einer Vorlage erstellt wurden, behalten ihre Links. - **Einladungen** – Einladungs-E-Mails zu selbst gehosteten und Community Edition-Bereitstellungen melden Personen korrekt an, Workspace-Einladungen in der Community Edition senden eine E-Mail und das erneute Senden einer Basiseinladung funktioniert. - **Anmelden** – Kurze Netzwerkfehler melden Sie nicht mehr ab und selbstgehostete SSO-Schaltflächen werden wieder angezeigt. - **SQL Server** – Einzelargument `CONCAT` funktioniert. - **Airtable-Import** – Ein fehlerhaftes Element stoppt den Import nicht mehr und unidirektionale Links und verschachtelte Filter werden korrekt importiert. ## Hinweise zum Selbsthosting - **Schnelleres Laden** – Statische Dateien werden zwischengespeichert und komprimiert, sodass die ersten Ladevorgänge etwa 3.6-mal kleiner sind. - **Zustand des Lizenzservers** – Superadministratoren sehen eine Warnung mit *Jetzt erneut versuchen*, wenn der Lizenzserver nicht erreichbar ist. [Weitere Informationen](https://nocodb.com/docs/self-hosting/license-activation) – **v3 API-Feldänderungen** – Währungsoptionen verwenden `currency_code` und `currency_locale` und die Formularvalidatoren `minValue`, `maxValue` und `custom` werden abgelehnt. - **CSV-Währungsexporte** – Währungswerte enthalten kein Tausendertrennzeichen mehr. - **Sicherheitsverstärkung** - Strengerer Audit-Log-Zugriff, bereinigte Dateinamen und gepatchte Abhängigkeiten. --- Weitere Einzelheiten zu den in 2026.09.0 eingeführten Funktionen finden Sie unter [2026.09.0 changelog](https://nocodb.com/docs/changelog/2026.09.0). ----------- - [**geschlossen**] 🐛 Fehler: Die Webseite wird unglaublich langsam geladen. Timeline View requires the Business plan and above on NocoDB Cloud, and App Sync requires the Plus plan and above.

Account-Wide MCP Connections

One MCP connection now reaches every base you pick, with the tools you allow and never more than your own role. The server now has 199 tools, 50 more than 2026.09.0, including member and team management, attachment upload, upsert, audit logs, trash restore, and publishing.

Improvements

  • Invite links - Share one link to bring people into a base or workspace at the role you choose. Learn more
  • Base settings as a modal - Settings open over your current view, with search. Learn more
  • Integrations page - Your connections first, then one catalog grid with category filters. Learn more
  • Webhook trigger fields - Pick individual body, header, and query values in later steps. Learn more
  • Variables in email links - Send Email links can use workflow data as the address. Learn more
  • Interface forms - Mark fields Required, update the open record from a form, and manage a button's forms in place. Learn more
  • Interface filters - Larger Filter by editor, with copy and paste between components.
  • Large number abbreviation - Number, Decimal, and Currency fields can display 1,234,567 as 1.2M. Learn more
  • Excel exports - Currency and Decimal export as real numbers. Learn more
  • Faster menus - Dropdowns open instantly.
  • List View drag and drop - Drops apply immediately.
  • Bulk update - Redesigned Update selected records panel.

What's Fixed

  • Grouped grids - Rows stay in the right group after realtime updates.
  • Select options - Adding a new option by paste or typing keeps existing options.
  • Imports, snapshots, and duplication - Large tables and synced tables copy completely, and User values carry across workspaces.
  • Interfaces - Link values, visibility rules, link pickers, attachment downloads, and overview cover images work as expected. Published pages keep working after a field is deleted, and pasted link values stay on new rows.
  • Bulk Update - Updating all records fires webhooks and workflow triggers.
  • Kanban - Reordering cards within a stack is saved.
  • Workflows - Steps inside an Iterate loop get the current record when tested, and fields that combine several variables resolve correctly.
  • Views - Calendar and Timeline views without a date range duplicate correctly, and shared List views open.
  • Renamed tables - Formula display values keep working after a table rename.
  • Audit log - Filtering by Data events returns results.
  • Documents - Markdown with empty table cells pastes correctly.
  • API - null for a v3 link field leaves links unchanged, v2 in filters with several dates return every match, and base-scoped tokens can list their bases.
  • MCP - Removing someone from a base revokes only that base's connections, write tools accept what their read tools return, and records created from a template keep their links.
  • Invites - Invite emails on self-hosted and Community Edition deployments sign people up correctly, workspace invites in the Community Edition send an email, and resending a base invite works.
  • Sign-in - Brief network errors no longer sign you out, and self-hosted SSO buttons show again.
  • SQL Server - Single-argument CONCAT works.
  • Airtable import - One failing item no longer stops the import, and one-way links and nested filters import correctly.

Self-Hosting Notes

  • Faster loading - Static files are cached and compressed, so first loads are about 3.6 times smaller.
  • License server health - Super admins see a warning with Retry now when the license server is unreachable. Learn more
  • v3 API field changes - Currency options use currency_code and currency_locale, and form validators minValue, maxValue, and custom are rejected.
  • CSV currency exports - Currency values no longer include a thousands separator.
  • Security hardening - Stricter audit log access, sanitized filenames, and patched dependencies.

For more details on the features introduced in 2026.09.0, see the 2026.09.0 changelog.
