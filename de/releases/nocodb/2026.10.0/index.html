**Datenintegrität** – Durch das Aufheben der Verknüpfung mit dem falschen übergeordneten Element bleibt die echte Verknüpfung erhalten, und Verknüpfungsschreibvorgänge sind auf SQLite und MySQL erfolgreich. - **Felder und Formeln** – Formeln bei der Suche nach einem Link funktionieren, `ISBLANK` funktioniert auf SQL Server und Dauerwerte behalten ihre Sekunden, wenn eine Tabelle, ein Feld oder ein Projekt dupliziert oder importiert wird. - **Filter** – *ist leer* und `in`-Filter funktionieren auf mehr Feldtypen und Datenbanken, der API akzeptiert *liegt zwischen* bei Zahlen und DateTime-Filter berücksichtigen die Zeitzone. - **Anhänge** – Anhänge, die über v3 API und Skripte geschrieben wurden, werden gespeichert und PDFs werden in mobilen Browsern in der Vorschau angezeigt. - **Importe und Duplizierung** – Beim CSV-Import in eine Verknüpfungsspalte mit einem einzelnen Datensatz wird die Zelle als ein Wert behandelt. - **Workflows** – Iterierte Filter stimmen mit den richtigen Zeilen überein und serverseitige Skripte sorgen dafür, dass der Projektzugriff länger als 60 Sekunden dauert. - **Webhooks** – Webhooks, die bestimmte Felder verfolgen, werden nur ausgelöst, wenn sich diese Felder ändern. - **Klassische Apps** – Datensatzseiten berücksichtigen den Anzeigewert eines Linkfelds und Zahlen-Widgets aggregieren numerische Formeln. - **MCP** – Formularerstellung meldet, was nicht angewendet werden kann, anstatt es zu verwerfen. - **Stabilität** – Durch die Navigation geht kein Speicher mehr verloren und mehrere Dialoge und Popups werden ohne Fehler geschlossen. - **Abrechnung** – Rechnungen werden korrekt ungültig, wenn ein Mahnzyklus abgebrochen wird, und aktualisierte Arbeitsbereiche erhalten keine E-Mails mehr zur Zahlungsfrist. ## Hinweise zum Selbsthosting – **Knoten 24.22.1** – Docker-Bilder werden für die Knotensicherheitsversion vom Oktober 2026 auf Knoten 24.22.1 verschoben. - Resource Allocation in Timeline View

Timeline View now shows how much of each person's working hours their scheduled tasks use, for every day, week, or month on screen. Overbooked periods turn red. The calculation allows for working days, time off from a linked table, and tasks shared by several people.

Play Back a Workflow Run

Step through a past workflow run on the canvas without running anything again. Run history filters by status, date range, and runs that need attention, and a running workflow can be stopped, paused, resumed, or retried.

Improvements

  • Five levels of grouping - Grid View now groups up to five levels deep, and dragging a record into another group changes its grouped value. Learn more
  • Members and teams in one place - Workspace members and teams share one Members & teams page, and each team shows the workspace role its members inherit. Learn more
  • New project page - Every New project entry point opens one page, with a prompt box when NocoAI is on. Learn more
  • Sign-in screens - Sign in, sign up, two-factor, password reset, SSO and invite screens are redesigned, and a badge marks the sign-in method you used last.
  • Phones - Grids, inputs, and calendar month view work properly on iPhone and Android.
  • Share a classic app - Share in the classic app builder invites people by email or private link to the app only. Learn more
  • Report abuse on public pages - Shared views, forms, classic apps and dashboards carry a Report abuse link, and super admins on self-hosted instances review reports in the Admin Panel. Learn more
  • Who can export - With Allow export to CSV on, a classic app page can limit the export by role, user or team. Learn more
  • Add linked records from a form - Classic app link fields can open a form to create a record and link it in one step. Learn more
  • Airtable import from a shared view - Import a publicly shared view link with no personal access token. Learn more
  • Freeze more fields - Grid View freezes as many fields as fit the window, no longer capped at three. Learn more
  • Rollups - Count All counts every linked record, and Min and Max over a date return a date. Learn more
  • Link filters - A dynamic condition can match linked records that share a link with the current record. Learn more
  • Default values in new records - The expanded form shows a field's default before you save.
  • Live updates - Grids refresh in place when collaborators edit, and grouped views keep their open groups.
  • Change the display value by dragging - Drag any column in Grid View onto the display value to make it the display value.
  • Record counts on user filters - Classic app user-filter tabs show the number of records behind each tab.
  • Email display names - Emails such as Jane Example <jane@example.com> open as mailto links.
  • More currencies - The Currency field accepts 19 more ISO 4217 codes. Learn more
  • Database SSL modes - External connections choose between No, Preferred, Required and Required-CA. Learn more
  • API token permissions - Fine-grained tokens can read and manage teams and read the workspace. Learn more
  • MCP tools - Document comment tools, a dry run for field type changes, and a skill guide with a SKILL.md entry point. Learn more
  • MCP fallback in chat - The chat agent falls back to MCP tools when it has no dedicated tool for what you asked.
  • More cloud credits - Every NocoDB Cloud plan includes more credits, from 1,000 on Free. Learn more
  • Environments and per-user credentials - Both now require the Scale plan.
  • A clearer update notification - The in-app update notification has been redesigned.

What's Fixed

  • Grid and views - Search, grouping, and Calendar month view behave as expected, and multi-level List views keep their rows on scroll.
  • Data integrity - Unlinking from the wrong parent keeps the real link, and link writes succeed on SQLite and MySQL.
  • Fields and formulas - Formulas on a lookup of a link work, ISBLANK works on SQL Server, and Duration values keep their seconds when a table, field, or project is duplicated or imported.
  • Filters - is empty and in filters work on more field types and databases, the API accepts is between on numbers, and DateTime filters respect the timezone.
  • Attachments - Attachments written through the v3 API and scripts are saved, and PDFs preview on mobile browsers.
  • Imports and duplication - CSV import into a single-record link column treats the cell as one value.
  • Workflows - Iterate filters match the right rows, and server-side scripts keep project access past 60 seconds.
  • Webhooks - Webhooks that track specific fields fire only when those fields change.
  • Classic apps - Record pages honor a link field's display value, and Number widgets aggregate numeric formulas.
  • MCP - Form authoring reports what it cannot apply instead of dropping it.
  • Stability - Navigation no longer leaks memory, and several dialogs and popups close without errors.
  • Billing - Invoices void correctly when a dunning cycle is cancelled, and upgraded workspaces stop getting grace-period emails.

Self-Hosting Notes

  • Node 24.22.1 - Docker images move to Node 24.22.1 for the October 2026 Node security release.
  • Seat limits - A seat cap applies only where an on-premises license sets one.
  • Grace periods - The API and automation grace periods now start as intended, and the automation grace cap is lower.
  • MCP response changes - Some MCP responses changed shape, such as shared view types as strings. The REST v3 API is unchanged.
  • Security hardening - Private integrations stay private, webhooks and uploads by URL refuse private network addresses, and dependencies are patched.

For more details on the features introduced in 2026.09.1, see the 2026.09.1 changelog.
