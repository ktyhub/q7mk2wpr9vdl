Echtzeitpräsenz im Raster

Verfügbarkeit

| Funktion | Community-Edition | Cloud-kostenloser Plan | Bezahlte Pläne in der Cloud/vor Ort | | --- | --- | --- | --- | | Echtzeitpräsenz | ✅ | ✅ | ✅ | | Ordner | ✅ | ✅ | ✅ | | Mehrere Felder einfrieren | ✅ | ✅ | ✅ | | Verschachtelte Datensätze in der Listenansicht | – | – | ✅ | | Berechtigungen für Dashboards | – | – | ✅ | ##Echtzeitpräsenz im Raster Mit der Echtzeitpräsenz können Sie Ihr Team im Raster sehen. Jeder Mitarbeiter erhält eine Farbe, die ihm von Zelle zu Zelle folgt, und die von ihm geöffneten Aufzeichnungen tragen ein Anwesenheitsabzeichen. Während eines Anrufs gemeinsam Daten überprüfen? Click Gehen Sie dorthin und Sie landen genau dort, wo sie arbeiten. Erfahren Sie mehr über Echtzeitpräsenz →

Ordner

Mit Ordnern können Sie Tabellen, Dokumente und Dashboards in reduzierbaren Ordnern gruppieren. Gleiches gilt für Ansichten innerhalb einer Tabelle. Verfügbar für alle Pläne, für NocoDB Cloud und selbst gehostete Bereitstellungen. Erfahren Sie mehr über Ordner →

Mehrere Felder einfrieren

In Rasteransichten können jetzt bis zu drei Felder, einschließlich des Anzeigewerts, angeheftet bleiben, während Sie horizontal scrollen. Ziehen Sie den Teiler, um auszuwählen, wie viele Felder eingefroren bleiben. Eingefrorene Felder werden auch auf Schnittstellenseiten unterstützt, die die Rastervisualisierung verwenden. Weitere Informationen

Verschachtelte Datensätze in der Listenansicht

Listen können jetzt Datensätze unter ihren übergeordneten Listen verschachteln, indem sie ein Linkfeld verwenden, das auf dieselbe Tabelle verweist: Denken Sie an Aufgaben mit Unteraufgaben, Kategorien mit Elementen oder ein Organigramm. Verschachtelte Datensätze sind auch auf Schnittstellenseiten verfügbar, die die Listenvisualisierung verwenden. Weitere Informationen

Einstellungen aus einer vorhandenen Ansicht kopieren

Beim Erstellen einer Schnittstellentabellen- oder Datensatzüberprüfungsseite bietet der Schritt „Mit einer Tabelle verbinden“ jetzt die Option „Einstellungen aus einer Ansicht kopieren“, mit der die neue Seite aus einer vorhandenen Ansicht erstellt wird. Weitere Informationen – Mehr Kontrolle über Schnittstellenfelder – Datensatzseiten und Formulare erhalten eine Option pro Feld Größe, um wichtige Eingaben zu skalieren. Einzelauswahlfelder auf Datensatzseiten können als Stepper angezeigt werden, der click für Punkt mit Punkt- oder Nummernindikatoren durch die Optionen geht, und der Feldbereich unterstützt jetzt die Neuordnung per Drag-and-Drop in jeder Visualisierung.

  • Dashboard-Berechtigungen – Dashboards erhalten pro Dashboard die Berechtigungen Sichtbarkeit und Bearbeitung, wobei dasselbe Berechtigungssystem wie bei Tabellen und Feldern verwendet wird, sodass Sie steuern können, wer jedes Dashboard sieht oder bearbeitet. Weitere Informationen
  • Nach Systembenutzern filtern – Die Filter „Erstellt von“ und „Zuletzt geändert von“ listen jetzt NocoDBs eigene Dienstakteure auf: Automatisierung, Synchronisierung, Workflow und Anonym für öffentliche Formularübermittlungen. - Anhänge von URLs in Workflows – Die Workflow-Knoten „Datensatz erstellen“ und „Datensatz aktualisieren“ können jetzt Anhangsfelder von URLs aus füllen. – API-Verbesserungen – Der v3-Datensatz-Upsert-Endpunkt akzeptiert jetzt Linkfelder inline und löst verknüpfte Datensätze nach ID oder Anzeigewert auf, und das v3-Feldschema macht jetzt das aufgelöste Währungssymbol für Währungsfelder verfügbar.

Was wurde behoben?

  • Zwei-Faktor-Anmeldung in der installierten App – Die Zwei-Faktor-Authentifizierung funktioniert jetzt reibungslos, wenn NocoDB als App (PWA) installiert ist.
  • Geplante Snapshot-Namen – Automatische Snapshots werden jetzt nach der Zeitzone des Zeitplans benannt, sodass ein nächtlicher Snapshot das Datum trägt, an dem er tatsächlich in Ihrer Zeitzone ausgeführt wurde.
  • Rich-Text-Vorschau im Raster – Lange Textfelder mit aktiviertem Rich-Text werden jetzt sauber in der Rastervorschau dargestellt, wobei Sonderzeichen korrekt angezeigt werden und Link-URLs erhalten bleiben.
  • Wiederherstellung der Antwort des KI-Assistenten – Eine Antwort, die durch eine unterbrochene Verbindung oder eine Seitenaktualisierung unterbrochen wurde, wird jetzt an der Stelle fortgesetzt, an der sie aufgehört hat.
  • Feldaktualisierungen über API behalten abhängige Felder bei – Die Aktualisierung eines Felds über API wird jetzt als Teilaktualisierung behandelt, wobei QR-Code- und Barcode-Felder, die darauf verweisen, erhalten bleiben.
  • Feldberechtigungen verknüpfen – Feldbearbeitungsberechtigungen werden jetzt beim Verknüpfen von Datensätzen über API erzwungen, einschließlich verschachtelter Einfügungen und Aktualisierungen, und die Linkauswahl berücksichtigt schreibgeschützte Linkfelder.
  • Korrekturen für den Schnittstellen-Builder – Datensatzdetaillayouts können unabhängig von ihrer Seite gelöscht werden, aus einer Ansicht kopierte Filter werden im Builder angezeigt, das Formular für neue Datensätze einer Schaltfläche beginnt mit den eigenen Feldern der Seite und durch Doppelklicken auf einen Datensatz auf einer Seite, auf der die Inline-Bearbeitung deaktiviert ist, kann Datensätze inline bearbeiten aktiviert werden.
  • Schnittstellenberechtigungen – Schnittstellenseiten berücksichtigen jetzt die auf der Basis konfigurierten Feldbearbeitungsberechtigungen, schreibgeschützte Vorschauen zeigen einen Hinweis an, wenn Sie versuchen, sie zu bearbeiten, und durch das Entfernen eines Mitglieds aus einem Arbeitsbereich wird auch dessen Schnittstellenzugriff entfernt. Der über Teams gewährte Zugriff wird jetzt korrekt aufgelistet und durchgesetzt, und die Rollenoptionen im Freigabedialog enthalten Hilfetexte, die erklären, was jede Rolle tun kann.
  • Verfeinerung des Schnittstellenlayouts – Schnittstellenseiten können durch Ziehen in der Seitenleiste neu angeordnet werden, Gruppen in Datensatzformularen können durch Ziehen neu angeordnet werden, Formulareingaben werden in geteilten Zeilen unter ihren eigenen Beschriftungen angezeigt, Listenvisualisierungsspalten behalten nach der Größenänderung ihre Breite und die Tastaturnavigation in Listen sorgt dafür, dass der ausgewählte Datensatz sichtbar bleibt.
  • Rasterlinien im hellen Modus – Zeilen- und Spaltenlinien sind im hellen Modus sowohl in der Raster- als auch in der Listenansicht besser zu erkennen.
  • Neue Felder in persönlichen und gesperrten Ansichten - Persönliche und gesperrte Ansichten behalten ihre konfigurierte Feldliste: Zur Tabelle hinzugefügte Felder bleiben verborgen, bis der Eigentümer der Ansicht sie anzeigt.
  • Sichtbarkeitsbedingungen für Schaltflächen – Die Sichtbarkeitsbedingungen für Schaltflächenfelder bleiben erhalten, wenn die Felder, auf die sie verweisen, bearbeitet werden.
  • Workflow-Korrekturen – Verzweigungen nach einem Bedingungsknoten folgen jetzt dem Port, den der Knoten tatsächlich ausgegeben hat, Anhangs-URLs mit Kommas werden als einzelner Anhang behandelt, das Verknüpfen von Datensätzen anhand ihres Anzeigewerts funktioniert mit Anführungszeichen und anderen Sonderzeichen, dynamische (variable) Filter können jetzt für Formelfelder verwendet werden und Filter-Popovers bleiben vollständig im Fenster sichtbar.
  • Bearbeitbarkeit von Smart Text – Vorhandene Smart Text-Felder bleiben in Bereitstellungen bearbeitbar, in denen neue Smart Text-Felder nicht aktiviert werden können.
  • Konvertieren von UUID- und AutoNumber-Feldern – Durch das Konvertieren eines Felds weg von UUID oder AutoNumber wird nun sein schreibgeschützter Status gelöscht und die NULL-Zulässigkeit der zugrunde liegenden Spalte bleibt mit den Feldeinstellungen synchronisiert.
  • SSO-Anmeldefehler – Bei einer fehlgeschlagenen SSO-Anmeldung wird jetzt eine klare Fehlerseite angezeigt, auf der erläutert wird, was schief gelaufen ist.
  • Datenbankduplizierung mit Anhängen – Datenbanken werden zuverlässig dupliziert, selbst wenn sie Anhänge enthalten, die von anderen Mitgliedern hochgeladen wurden.

Hinweise zum Selbsthosting

– Legacy-API-Tokens – Die Erstellung neuer Legacy-API-Tokens wird bei lizenzierten selbstgehosteten Bereitstellungen nicht mehr unterstützt. Vorhandene ältere API-Tokens funktionieren weiterhin; Verwenden Sie feinkörnige API-Tokens für neue Integrationen. Weitere Informationen – Umbenannte Codeausführungs- und Websuchvariablen – Die E2B- und Exa-Umgebungsvariablen wurden umbenannt:

  • Änderungen des Umgebungsnamens | ALTE UMGEBUNGSVARIABLE | NEUE UMGEBUNGSVARIABLE | | --- | --- | | E2B_API_KEY | NC_COMPUTE_E2B_API_KEY | | E2B_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_SCRIPT | | E2B_CHAT_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_CHAT | | EXA_API_KEY | NC_WEB_EXA_API_KEY | Wenn Sie diese verwendet haben, werden die alten Umgebungsvariablen nicht mehr gelesen: Aktualisieren Sie sie bei einem Upgrade oder bei der Skriptausführung, der AI-Codeanalyse und der AI-Websuche. Die Template-Variablen sind nun optional und greifen auf NocoDBs eigene Templates zurück. Weitere Informationen

Dokumentation wird überarbeitet

  • Da NocoDB weiter wächst, waren wir der Meinung, dass dies der richtige Zeitpunkt ist, unsere Dokumentationen zu überarbeiten. Dedizierte Registerkarten umfassen Produkt, Workflows, Schnittstellen, APIs & MCP, Selbsthosting und Changelog, und die Produktseitenleiste gruppiert jetzt Seiten unter „Kern“, „Verwalten“ und „Verbinden“, sodass verwandte Themen zusammengehören. Jede vorherige URL in Dokumenten wird korrekt auf die richtige Seite umgeleitet.
  • Ask AI in Dokumenten – Jede Dokumentseite enthält jetzt einen Ask AI-Assistenten, der Fragen im Klartext beantwortet und dabei die Dokumentation als Quelle verwendet, sodass Sie fragen können „Wie mache ich X?“, anstatt Seiten durchzusuchen.

Weitere Einzelheiten zu den in 2026.08.0 eingeführten Funktionen finden Sie unter 2026.08.0 changelog.

Realtime Presence in Grid

Availability

| Feature | Community Edition | Cloud Free Plan | Paid Plans In Cloud/On-Prem | | --- | --- | --- | --- | | Realtime Presence | ✅ | ✅ | ✅ | | Folders | ✅ | ✅ | ✅ | | Freeze multiple fields | ✅ | ✅ | ✅ | | Nested records in List View | – | – | ✅ | | Permissions for Dashboards | – | – | ✅ |

##Realtime Presence in Grid

Realtime Presence lets you see your team inside the grid. Each collaborator gets a colour that follows them from cell to cell, and records they have open carry a presence badge. Reviewing data together on a call? Click Go there and you land exactly where they're working.

Learn more about Realtime Presence →

Folders

Folders lets you group tables, documents, and dashboards into collapsible folders. Same applies to views within a table. Available on all plans, on NocoDB Cloud and self-hosted deployments.

Learn more about Folders →

Freeze multiple fields

Grid views can now keep up to three fields, including the display value, pinned while you scroll horizontally. Drag the divider to choose how many fields stay frozen. Frozen fields are also supported on interface pages that use the Grid visualization. Learn more

Nested records in List View

Lists can now nest records under their parents using a link field that points back to the same table: think tasks with subtasks, categories with items, or an org chart. Nested records are also available on interface pages that use the List visualization. Learn more

Copy settings from an existing view

When creating an interface Table or Record review page, the Connect to a table step now offers a Copy settings from a view option that seeds the new page from an existing view. Learn more

- More control over interface fields - Record pages and forms gain a per-field Size option to scale up important inputs, Single Select fields on record pages can display as a Stepper that walks through options one click at a time with dot or numbered indicators, and the Fields pane now supports drag-and-drop reordering across every visualization.

  • Dashboard permissions - Dashboards gain per-dashboard Visibility and Editing permissions, using the same permission system as tables and fields, so you can control who sees or edits each dashboard. Learn more
  • Filter by system users - Created By and Last Modified By filters now list NocoDB's own service actors: Automation, Sync, Workflow, and Anonymous for public form submissions.

- Attachments from URLs in workflows - The create record and update record workflow nodes can now fill attachment fields from URLs.

  • API improvements - The v3 records upsert endpoint now accepts link fields inline, resolving linked records by ID or display value, and the v3 field schema now exposes the resolved currency symbol for Currency fields.

What's Fixed

  • Two-factor sign-in in the installed app - Two-factor authentication now works smoothly when NocoDB is installed as an app (PWA).
  • Scheduled snapshot names - Automatic snapshots are now named using the schedule's timezone, so a nightly snapshot carries the date it actually ran in your timezone.
  • Rich text preview in grid - Long Text fields with rich text enabled now render cleanly in the grid preview, with special characters displayed correctly and link URLs preserved.
  • AI assistant response recovery - A response interrupted by a dropped connection or a page refresh now resumes where it left off.
  • Field updates via API keep dependent fields - Updating a field through the API is now treated as a partial update, preserving QR code and Barcode fields that reference it.
  • Link field permissions - Field edit permissions are now enforced when linking records through the API, including nested inserts and updates, and the link picker respects read-only link fields.
  • Interface builder fixes - Record detail layouts can be deleted independently of their page, filters copied from a view show up in the builder, a button's new-record form starts from the page's own fields, and double-clicking a record on a page where inline editing is off offers to turn on Edit records inline.
  • Interface permissions - Interface pages now respect the field edit permissions configured on the base, read-only previews show a notice when you try to edit, and removing a member from a workspace also removes their interface access. Access granted through teams is now listed and enforced correctly, and the role options in the share dialog carry help text explaining what each role can do.
  • Interface layout polish - Interface pages can be reordered by dragging them in the sidebar, groups on record forms can be reordered by dragging, form inputs sit under their own labels in split rows, List visualization columns keep their widths after resizing, and keyboard navigation in lists keeps the selected record visible.
  • Grid lines in light mode - Row and column lines are easier to see in light mode, in both Grid and List views.
  • New fields in personal and locked views - Personal and locked views keep their configured field list: fields added to the table stay hidden until the view's owner shows them.
  • Button visibility conditions - Visibility conditions on Button fields are preserved when the fields they reference are edited.
  • Workflow fixes - Branches after a condition node now follow the port the node actually emitted, attachment URLs containing commas are handled as a single attachment, linking records by their display value works with quotes and other special characters, dynamic (variable) filters can now be used on Formula fields, and filter popovers stay fully visible within the window.
  • Smart Text editability - Existing Smart Text fields stay editable on deployments where new Smart Text fields cannot be enabled.
  • Converting UUID and AutoNumber fields - Converting a field away from UUID or AutoNumber now clears its read-only state, and the underlying column's nullability stays in sync with the field settings.
  • SSO sign-in errors - A failed SSO sign-in now shows a clear error page explaining what went wrong.
  • Base duplication with attachments - Bases duplicate reliably even when they contain attachments uploaded by other members.

Self-Hosting Notes

  • Legacy API tokens - Creation of new legacy API tokens is no longer supported on licensed self-hosted deployments. Existing legacy API tokens continue to work; use fine-grained API tokens for new integrations. Learn more
  • Renamed code-execution and web-search variables - The E2B and Exa environment variables are renamed:
  • Environment name changes

| OLD ENVIRONMENT VARIABLE | NEW ENVIRONMENT VARIABLE | | --- | --- | | E2B_API_KEY | NC_COMPUTE_E2B_API_KEY | | E2B_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_SCRIPT | | E2B_CHAT_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_CHAT | | EXA_API_KEY | NC_WEB_EXA_API_KEY |

If you were using these, the old environment variables are no longer read: update them when upgrading, or script execution, AI code analysis, and AI web search. The template variables are now optional and fall back to NocoDB's own templates. Learn more

Documentation Get A Revamp

  • As NocoDB continues to grow -we felt this is the right time revamp our documentations. Dedicated tabs cover Product, Workflows, Interfaces, APIs & MCP, Self Hosting, and Changelog, and the Product sidebar now groups pages under Core, Manage, and Connect so related topics sit together. Every previous URL in docs will be redirected correctly to the right page.

  • Ask AI in docs - Every docs page now includes an Ask AI assistant that answers questions in plain language using the documentation as its source, so you can ask "how do I do X" instead of hunting through pages.

For more details on the features introduced in 2026.08.0, see the 2026.08.0 changelog.
