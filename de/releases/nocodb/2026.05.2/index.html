<img width="1865" height="1147" alt="image" src="https://github.com/user-attachments/assets/5e6661ab-4490-4cc8-87ec-114aedc2dc7d" /> ## Verfügbarkeit | Funktion | CE / Kostenlos | Bezahlt / Unternehmen | |---|:---:|:---:| | Gantt-Ansicht | – | ✅ | | Geteilte Seiten | – | ✅ | | Erweitertes Record-Seitenfeld | ✅ | ✅ | ## Gantt-Ansicht <img width="2880" height="1570" alt="image" src="https://github.com/user-attachments/assets/c194cf78-7b4c-4c50-a782-523525bd9e04" /> **Gantt-Ansicht** verwandelt jede datumsbasierte Tabelle in einen Live-Projektplan: Datensätze werden zu verschiebbaren Balken, Abhängigkeiten werden zu Pfeilen und Schlüsseldaten werden zu Meilenstein-Diamanten. Ganz gleich, ob Sie eine Produkteinführung planen, eine Roadmap erstellen oder Projektphasen koordinieren: Es zeigt, was wann läuft und was was blockiert. Ziehen Sie, um einen neuen Termin festzulegen, verknüpfen Sie Aufgaben über den Griff einer Leiste und zoomen Sie von einem einwöchigen Sprintout zu einer fünfjährigen Roadmap. [Erfahren Sie mehr über die Gantt-Ansicht →](https://nocodb.com/docs/product-docs/views/view-types/gantt) ## Geteilte Seiten <img width="2004" height="1520" alt="image" src="https://github.com/user-attachments/assets/9e57a046-ee17-46ea-a9ab-3e9fa1cb1c30" /> **Sie können jetzt eine NocoDocs-Seite öffentlich teilen** als schreibgeschützten Link, den jeder in einem Browser öffnen kann, kein NocoDB-Konto erforderlich. Unabhängig davon, ob Sie Produktdokumente, eine Projektbeschreibung oder ein internes Wiki teilen, können Sie ein Dokument direkt aus dem Editor an eine gemeinsam nutzbare URL übertragen oder es an anderer Stelle mit einem Iframe-Snippet einbetten. Schalten Sie den Schalter aus, um die Verknüpfung in Sekundenschnelle zu widerrufen. [Weitere Informationen zum Teilen von Dokumenten →](https://nocodb.com/docs/noco-docs/share-document) ## Erweiterter Datensatz-Seitenbereich in der Community Edition <img width="2622" height="1568" alt="image" src="https://github.com/user-attachments/assets/56d078c3-c44f-4ab0-902f-f6ffe275ceee" /> Das **Erweiterte Record Side Panel**, das in 2026.05.1 eingeführt wurde, wird jetzt in der Community Edition ausgeliefert. Wenn Sie einen Datensatz öffnen, wird er rechts neben dem Raster angedockt und nicht im Vollbildmodus, sodass Ihre Daten im Blick bleiben, während Sie Felder bearbeiten, Kommentare lesen oder den Revisionsverlauf scannen. Es ist das Standard-Desktop-Layout für alle Editionen. öffentliche und geteilte Ansichten sind weiterhin als zentriertes Modal offen. [Erfahren Sie mehr über den erweiterten Datensatz →](https://nocodb.com/docs/product-docs/records/expand-record) ## Kontosicherheit - **Eine aktive Sitzung pro Konto.** Wenn Sie sich auf einem neuen Gerät oder Browser anmelden, wird die vorherige Sitzung abgemeldet, und zwar über alle Anmeldepfade, einschließlich SSO. Standardmäßig in allen Editionen aktiviert; API-Tokens sind nicht betroffen. - **Workspace 2FA deckt jetzt auch Eigentümer ab.** Eigentümer sind nicht mehr von der arbeitsbereichsweiten 2FA-Durchsetzung ausgenommen. Daher werden Eigentümer bei Unternehmensarbeitsplätzen, die 2FA erfordern, aufgefordert, sich anzumelden, bevor sie fortfahren. ## Verbesserungen und Korrekturen - **Leere Felder in einem erweiterten Datensatz suchen und ausblenden.** In einem erweiterten Datensatz können Sie jetzt nach jedem Feld oder Wert suchen, was nützlich ist, wenn Sie viele Felder haben. Außerdem besteht die Möglichkeit, leere Felder auszublenden. - **Angeheftete Filter für Datumsfelder.** Die Felder „Datum“, „DatumUhrzeit“, „Erstellungszeit“ und „Letzte Änderungszeit“ können jetzt als kompakte Pillen an die Symbolleiste angeheftet werden (genaues Datum, Tage her, letzte N Tage). - **Farbpaletten für Dashboard-Diagramme.** Auf Cloud-Dashboards erhalten Balken-, Linien-, Kreis-, Donut- und Streuungs-Widgets eine Palettenauswahl und Messgeräte erhalten eine vollständige Farbauswahl für Bereichsfarben. - **Pfeiltasten bewegen sich in numerischen Formularfeldern.** Die Aufwärts- und Abwärtspfeile erhöhen und verringern jetzt die Felder „Ganzzahl“, „Dezimal“ und „Prozent“ in Formularen, was dem Verhalten von „Währung“ entspricht. - **AutoNumber für leere Tabellen.** Das Hinzufügen eines AutoNumber-Felds zu einer leeren Tabelle führt nicht mehr zu einem Fehler. Die Sequenz wird korrekt initialisiert. - **Die Zeilenfärbung bleibt auch bei Ansichtswechseln bestehen.** Der Wert einer Zeilenfarbbedingung bleibt jetzt erhalten, wenn Sie die Ansicht wechseln, anstatt ihn zurückzusetzen. - **Verbindungstabellen vom Tabellenlimit ausgeschlossen.** Verborgene Many-to-Many-Link-Tabellen werden nicht mehr zum Tabellenlimit einer Basis gezählt, wodurch die beabsichtigte Anzahl der für den Benutzer sichtbaren Tabellen wiederhergestellt wird. - **Versteckte Pflichtfelder schlagen nicht länger stillschweigend fehl.** Das Ausblenden eines Pflichtfeldes (NICHT NULL) gibt jetzt eine Warnung aus, markiert es im Menü „Felder“, erweitert ausgeblendete Felder beim Hinzufügen eines Datensatzes automatisch und zeigt einen eindeutigen Speicherfehler an, anstatt die Zeile zu löschen. - **Kalender- und Datumsfelder berücksichtigen die Zeitzone der Spalte.** Beim Ziehen, Ändern der Größe und Anzeigen in Kalenderansichten wird für MySQL DateTime- und Zeitzonen-konfigurierte Spalten nicht mehr der falsche Offset angezeigt. ## Hinweise zum Selbsthosting - **Wenn Sie `NC_CONNECTION_ENCRYPT_KEY` und 2FA verwendet haben, lesen Sie bitte weiter.** Auf Instanzen, die mit festgelegtem `NC_CONNECTION_ENCRYPT_KEY` ausgeführt wurden, hatte TOTP aufgrund des Ver-/Entschlüsselungs-Roundtrips Probleme bei der Überprüfung des Codes, was dazu führte, dass jede 2FA-Überprüfung mit „Ungültiger Überprüfungscode“ fehlschlug. Das ist behoben. Wenn Sie 2FA verwendet haben, müssen Sie es deaktivieren und erneut registrieren. Beachten Sie, dass 2FA nur für E-Mail- und passwortbasierte Anmeldungen gilt, nicht für SSO. - **Privater Netzwerkzugriff für Datenbanken und Webhooks.** SSRF-Schutz wird standardmäßig erzwungen. Wenn Ihre Instanz eine Verbindung zu einer Datenbank herstellt oder Webhooks in einem privaten oder lokalen Netzwerk sendet, müssen Sie sich möglicherweise mit den entsprechenden Umgebungsvariablen (`NC_ALLOW_LOCAL_EXTERNAL_DBS`, `NC_WEBHOOK_ALLOW_PRIVATE_NETWORK` / `NC_ALLOW_LOCAL_HOOKS`) anmelden oder die SSRF-Filterung global mit `NC_DISABLE_SSRF_PROTECTION` deaktivieren. NocoDB Cloud erzwingt immer den SSRF-Schutz. - **Sicherheitsabhängigkeitsprüfung.** Diese Version löscht eine große Menge von Abhängigkeitssicherheitshinweisen im gesamten Stapel (einschließlich `axios`, `next` und `mermaid`), ohne Änderungen an öffentlichen APIs. ------ ### Geschlossene Probleme - Gantt View

<img width="2880" height="1570" alt="image" src="https://github.com/user-attachments/assets/c194cf78-7b4c-4c50-a782-523525bd9e04" />

Gantt View turns any date-based table into a live project schedule: records become draggable bars, dependencies become arrows, and key dates become milestone diamonds. Whether you're planning a product launch, mapping a roadmap, or coordinating project phases, it shows what runs when and what blocks what. Drag to reschedule, link tasks from a bar's handle, and zoom from a one-week sprint out to a five-year roadmap.

Learn more about Gantt View →

Shared Pages

<img width="2004" height="1520" alt="image" src="https://github.com/user-attachments/assets/9e57a046-ee17-46ea-a9ab-3e9fa1cb1c30" />

You can now publicly share a NocoDocs page as a read-only link that anyone can open in a browser, no NocoDB account required. Whether you're sharing product docs, a project brief, or an internal wiki, you can take a document straight from the editor to a shareable URL, or embed it elsewhere with an iframe snippet. Switch the toggle off to revoke the link in seconds.

Learn more about sharing documents →

Expanded Record Side Panel in Community Edition

<img width="2622" height="1568" alt="image" src="https://github.com/user-attachments/assets/56d078c3-c44f-4ab0-902f-f6ffe275ceee" />

The Expanded Record Side Panel, introduced in 2026.05.1, now ships in Community Edition. Opening a record docks it to the right of the grid instead of a full-screen modal, so your data stays in view while you edit fields, read comments, or scan revision history. It's the default desktop layout across all editions; public and shared views still open as a centered modal.

Learn more about the Expanded Record →

Account Security

  • One active session per account. Signing in on a new device or browser signs out the previous session, across every sign-in path including SSO. On by default in all editions; API tokens are unaffected.
  • Workspace 2FA now covers owners. Owners are no longer exempt from workspace-wide 2FA enforcement, so on Enterprise workspaces that require 2FA, owners are prompted to enroll before continuing.

Improvements & Fixes

  • Search and hide blank fields in an expanded record. In an expanded record you can now search for any field or value, useful when you have lots of fields. Plus the ability to hide blank fields too.
  • Pinned filters for date fields. Date, DateTime, Created time, and Last modified time fields can now be pinned to the toolbar as compact pills (exact date, days ago, past N days).
  • Dashboard chart color palettes. On Cloud dashboards, bar, line, pie, donut, and scatter widgets gain a palette picker, and gauges get a full color picker for range colors.
  • Arrow keys step numeric form fields. Up and Down arrows now increment and decrement Integer, Decimal, and Percent fields in forms, matching how Currency already behaved.
  • AutoNumber on empty tables. Adding an AutoNumber field to an empty table no longer throws an error; the sequence initializes correctly.
  • Row coloring persists across view switches. A row-color condition's value is now retained when you switch views instead of resetting.
  • Junction tables excluded from the table limit. Hidden many-to-many link tables are no longer counted toward a base's table limit, restoring the intended number of user-visible tables.
  • Hidden required fields no longer fail silently. Hiding a required (NOT NULL) field now warns, flags it in the Fields menu, auto-expands hidden fields when adding a record, and shows a clear save error instead of dropping the row.
  • Calendar and date fields respect the column timezone. Drag, resize, and display on Calendar views no longer show the wrong offset for MySQL DateTime and timezone-configured columns.

Self-Hosting Notes

  • If you were using NC_CONNECTION_ENCRYPT_KEY and 2FA, please do read. On instances running with NC_CONNECTION_ENCRYPT_KEY set, TOTP had issues while verifying the code due to the encrypt/decrypt round-trip, causing every 2FA verification to fail with "Invalid verification code". This is fixed. If you were using 2FA, you will need to disable and re-enroll. Note that 2FA only applies to email and password based logins, not to SSO.
  • Private-network access for databases and webhooks. SSRF protection is enforced by default. If your instance connects to a database or sends webhooks on a private or local network, you may need to opt in with the relevant environment variables (NC_ALLOW_LOCAL_EXTERNAL_DBS, NC_WEBHOOK_ALLOW_PRIVATE_NETWORK / NC_ALLOW_LOCAL_HOOKS), or disable SSRF filtering globally with NC_DISABLE_SSRF_PROTECTION. NocoDB Cloud always enforces SSRF protection.
  • Security dependency audit. This release clears a large batch of dependency security advisories across the stack (including axios, next, and mermaid) with no changes to public APIs.
