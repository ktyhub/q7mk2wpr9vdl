Stirling-PDF_0.33.1 Docker Nabenverschiebung zu stirlingtools v3.1.0

Wieder einmal einige große Änderungen in dieser Version! Das Gruppensignieren (Stirling Sign genannt) verlässt die Alpha-Phase und ist jetzt standardmäßig für neue Benutzer aktiviert. Damit können Sie PDFs in Ihrer gesamten Organisation teilen, verfolgen und signieren. Es verfügt außerdem über eine brandneue Signier-Benutzeroberfläche, die das Benutzererlebnis beim Signieren drastisch verbessert. Bitte teilen Sie uns mit, wenn Sie Probleme damit haben!

Wir liefern außerdem ein neues eingebettetes Konvertierungstool namens „Stirling Office Convert“ aus, das wir testen. Es zielt darauf ab, schneller und mit weniger Speicher bessere Konvertierungsergebnisse zu erzielen. Dies ist eine Betaversion, also vergleichen Sie bitte und lassen Sie es uns wissen! (Aktivieren Sie es standardmäßig unter „Erweitert“ > „Funktionsflags“).

Wir haben eine Menge weiterer Funktionen in dieser Version:

  • Der Texteditor unterstützt das Bearbeiten von Tabellen direkt in der Datei!
  • Der Texteditor unterstützt die Bearbeitung von OCR-gekennzeichneten Bild-PDFs!
  • Verbesserungen der Benutzeroberfläche und UX des Texteditors
  • Verbesserungen bei der Unterstützung von Anhängen (Hinzufügen, Umbenennen, Extrahieren, Löschen usw.)
  • Mehrere Abhängigkeitsaktualisierungen

Und um es noch einmal zu erwähnen:

  • Brandneue Benutzeroberfläche zum Signieren von Gruppen
  • Neues PDF-Konvertierungstool, das hoffentlich das alte Tool in Zukunft ersetzen wird (und bald auf dem nativen Desktop verfügbar sein wird!)
  • Verbesserungen des Sign-Tools

Wir haben auch einige Fehler behoben, darunter

  • Bestimmte Übersetzungen fehlen
  • Die Kontoverknüpfung funktioniert bei bestimmten Versionen nicht
  • Die automatische Drehung funktioniert auf dem Desktop nicht – Selfhost-Benutzern wurde ein ungültiges Teams-Menü angezeigt
  • Der Desktop aktualisiert sich manchmal nicht richtig

Stirling-PDF_0.33.1 Docker hub move to stirlingtools v3.1.0

Highlights

  • Stirling Sign V1 goes default-on — Group signing is out of alpha and enabled by default for new users, so orgs can share, track, and sign PDFs without opting into an experimental feature (#8189). The Sign tool was rebuilt around a saved signature with a new UI (#8208), and signing sessions now wait for a signed-in user before fetching (#8227). If you manage existing accounts, expect the default to apply to new users rather than silently flipping everyone.
  • Stirling Office Convert is an opt-in beta (#8219) — A new embedded converter promising faster, lower-memory Office conversion, intended to eventually replace the old pipeline and ship to native desktop. It's off by default: enable it under Advanced > Feature Flags and compare output against the legacy converter before standardizing on it, since "better results" is still trial-stage.
  • The v2 text editor is now a real editor — Acrobat-style object manipulation (Backspace delete, drag-select, text-box resize, shapes, Shift-resize) landed in #8325, table detection and in-place table editing in #8335, and the ability to edit text on OCR'd scanned PDFs in #8314. Workbench files also now open at the viewer's zoom instead of a hard-coded 150% (#8311). Together these remove the common round-trip of exporting a scanned PDF to another tool just to fix a table or a word.
  • Attachments get full CRUD, self-hosting gets easier — A complete add/rename/extract/delete UI for PDF attachments arrives in #7333. Stock self-hosted images can now link to Stirling with no extra config (#8338), the self-hosted Users menu visibility is fixed (#8316), desktop updates and version display work across connection modes (#8315), and Auto Rotate now has a cloud fallback when local OCR is missing (#8327). Expect noticeably less setup friction if you run the community Docker image.
  • Access control tightened, dependencies patched — Sensitive endpoints are now restricted to authenticated human users (#7306) and guest accounts no longer trigger server file listings (#8229). This is the change most likely to surprise automations: any bot or unauthenticated integration relying on those endpoints will start getting rejected, so audit API clients and guest flows. The release also pulls security-relevant bumps to axios 1.20.0 (#8296), dompurify 3.4.16 (#8319), the OWASP HTML sanitizer (#8254), and Spring Security SAML 7.1.1 (#8332), alongside viewer/library performance work that cuts redundant rescans and thumbnail rewrites (#8037, #8134).
  • Breaking changes — None formally documented; the main behavioral change to audit is the authenticated-user restriction in #7306.

Some big changes in this release yet again! Group signing (Called Stirling Sign) is moving out of alpha and is now being enabled by default for new users, with it, you can share, track, and sign PDFs across your org. It also comes with a brand new sign UI, drastically improving the user experience of signing. Please let us know if you have any issues with it!

We are also shipping a new embedded conversion tool called "Stirling Office Convert" which we are trialing, It aims to give better conversion results faster and with less memory. This is a beta, so please compare and let us know! (Enable it by default under Advanced > Feature Flags)

We have a ton of other features in this release:

  • Text editor supports editing tables directly in file!
  • Text editor supports editing OCRed image PDFs!
  • Text editor UI and UX improvements
  • Attachments Support improvements (Add, rename, extract, delete etc)
  • Several Dependency updates

And to mention again:

  • Brand new Group signing UI
  • New PDF conversion tool, hopefully to replace the old tool in the future (and coming to native desktop soon!)
  • Sign tool improvements

We also fixed some bugs including

  • Certain translations missing
  • Account linking not working for certain versions
  • Auto rotate not working on desktop
  • Selfhost users shown invalid teams menu
  • Desktop not correctly updating itself sometimes
