Stirling-PDF_0.33.1 Docker Nabenwechsel zu Stirlingtools v3.0.2

Diese Version enthält Fehlerbehebungen und verschiedene andere Verbesserungen Verbesserungen:

  • Unterstützung für selektives Zuschneiden von Seiten hinzufügen
  • Bessere Tool-Empfehlung basierend auf der Benutzernutzung
  • Fügen Sie beim Neuordnen der Seite visuelles Feedback hinzu

Behobene Fehler:

  • Übersetzungen fehlen
  • Bestimmte Sprachen werden nicht richtig geladen – Der Prozessor wird in bestimmten Versionen der App nicht korrekt geladen
  • Latest-Fat hat Probleme beim Hochladen von Dateien
  • Standardmodus als Viewer/Reader funktioniert nicht richtig

Stirling-PDF_0.33.1 Docker hub move to stirlingtools v3.0.2

Highlights

  • Editing improvements — Selective page cropping (PR #7753) lets users crop only chosen pages, while page reordering now provides visual feedback (PR #6289). Local tool-usage tracking (PR #8207) also improves recommendations. Worth upgrading for anyone who regularly crops or reorganizes PDFs.
  • More predictable processing and downloads — parsePageList consistently skips malformed page tokens, Downloads no longer gets stuck on Reading or a file, and unrepairable documents return HTTP 422 instead of 500 (PR #8083). API clients should recognize 422 as invalid/unrepairable input rather than a server failure.
  • Packaging and runtime defaults — Docker Hub publication moves to stirlingtools, so deployments should update their image references. Server builds now ship the processor by default and hide its links when unavailable (PR #8280); latest-fat no longer enables the AI engine by default (PR #8276), addressing upload issues. Re-enable AI explicitly if your workflow depended on that default.
  • Localization and startup reliability — Translations are synchronized across 40 locales, Serbian loads under the canonical sr-Latn-RS tag, previously hardcoded UI/service/error text is translated, and startup views plus desktop session restoration are fixed. Particularly worthwhile for non-English users and deployments relying on viewer/reader default mode.
  • Upgrade verdict — No explicit breaking changes or configuration migrations are listed beyond updating Docker Hub image references. Users hitting the fixed bugs or using the new editing features should upgrade; unaffected, stable deployments can skip. The dependency and toolchain updates shown in PR history are explicitly not shipped in this release.

This release contains bug fixes and various other improvements Enhancements:

  • add support for selective page cropping
  • better tool recommendation based on user usage
  • add visual feedback during page reordering

Bugs fixed:

  • translations missing
  • Certain languages not loading correctly
  • Processor not correctly loading in certain versions of the app
  • latest-fat having file upload issues
  • Default mode as viewer/reader not correctly working
