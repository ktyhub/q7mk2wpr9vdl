Stirling-PDF_0.33.1 Docker hub move to stirlingtools v3.2.2

Highlights

  • Docker Hub namespace move — The release ships under a new stirlingtools registry location. Anyone pinning the image in Compose, Helm, or Kubernetes manifests must update the image reference before pulling v3.2.2; otherwise deployments will silently keep resolving the old tag and never pick up these fixes.

  • Viewer font rendering + zoom controls — PR #8629 fixes non-embedded fonts rendering with mismatched widths, eliminating text/line-wrap drift on PDFs that depend on system fonts — important if you generate screenshots or visual-regression baselines. PR #8485 adds fit-to-width and fit-to-page buttons, so wide/tall documents are navigable without manual zoom fiddling.

  • New annotation tools — PR #8578 adds Arrow and Polyline annotation shapes, expanding what can be marked up without leaving the app. Useful for review workflows (callouts, flow/connection annotations) that previously required workarounds like freehand strokes or external editors.

  • QR code stamp type — PR #8492 introduces QR-code stamping, letting users embed machine-readable links or identifiers directly onto pages during bulk stamping. Worth noting for provenance/tracking use cases; check that any QR content you stamp is validated upstream since it becomes part of the output document.

  • Frontend restructure for fork maintainers — PR #7062 (folder restructure) and PR #8616 (path alias rename) change frontend layout and import aliases. Downstream forks carrying frontend customizations will need to rebase and fix import paths; end users of the stock image are unaffected.

  • Dependency and reliability upkeep — Notable is dompurify 3.4.16→3.4.17 (#8631), a security-relevant sanitizer patch in the frontend, plus fast-uri/ip-address bumps and backend reliability fixes with the version bump in #8617. These strengthen the case to upgrade even aside from the feature work.

  • Breaking changes — None to the public API or document behavior; the migration items above are deployment/repository-level, not runtime breaking changes.

Another small release with some bug fixes

  • Fix for some viewer rendering issues
  • New auto fit to width button for viewer
  • New annotation shape options like arrow and polyline
  • QR code stamp types
