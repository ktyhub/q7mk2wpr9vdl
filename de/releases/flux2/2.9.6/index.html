#flux2 v2.9.6

Highlights

Flux v2.9.6 ist eine Patch-Version, die verhindert, dass der Helm-Controller bei jedem Upgrade Karten-CRDs erneut anwendet, wenn die serverseitige Anwendung aktiviert ist, und HelmReleases wiederherstellt, die nach einem fehlgeschlagenen Status-Patch mit einer abweichenden Ready=Unknown-Bedingung zurückbleiben. Der Quellcontroller normalisiert die Azure Blob-Liste der ETags, sodass unveränderte Container nicht mehr bei jedem Abgleich erneut heruntergeladen werden, und entfernt veraltete Helm-Repository-Indexeinträge aus dem Cache, sodass Repositorys mit häufig wechselnden Indizes nicht mehr mit „Cache ist voll“ fehlschlagen. kustomize-controller erweitert die Redaktion von SOPS-Entschlüsselungsfehlern auf spec.postBuild.substituteFrom-Werte, sodass ersetzte Geheimnisse, die in API-Validierungsfehlern zurückgegeben werden, aus Statusbedingungen und Ereignissen ausgeblendet werden, und fügt das Opt-in-Feature-Gate DisableCommitStatusEvent hinzu. Benutzern wird empfohlen, ein Upgrade durchzuführen, um das beste Erlebnis zu erzielen. ℹ️ Bitte befolgen Sie das Upgrade-Verfahren für Flux v2.7+ für ein reibungsloses Upgrade von Flux v2.6 auf die neueste Version. Korrekturen: – Stoppen Sie die erneute Anwendung von Karten-CRDs bei Upgrades, wenn Sie die serverseitige Anwendung mit der Standardrichtlinie Create (Helm-Controller) verwenden.

  • Wiederherstellen von HelmReleases, die nach einem fehlgeschlagenen Status-Patch (Helm-Controller) mit einem verschobenen Ready=Unknown-Zustand gestrandet sind.
  • Ignorieren Sie NotFound beim Löschen des HelmChart (Helm-Controller) – Normalisieren Sie die Azure Blob-Auflistung der ETags, sodass unveränderte Container nicht bei jedem Abgleich erneut heruntergeladen werden (Quellcontroller). – Entfernen Sie veraltete Helm-Repository-Indexeinträge aus dem Cache, um „Cache ist voll“-Fehler zu vermeiden (Quellcontroller)
  • Erweitern Sie die Redaktion von SOPS-Entschlüsselungsfehlern auf spec.postBuild.substituteFrom-Werte (kustomize-controller) Verbesserungen: – Fügen Sie das Opt-in-Feature-Gate DisableCommitStatusEvent hinzu (kustomize-controller)

Englisches Original / English original

flux2 v2.9.6

Highlights

Flux v2.9.6 is a patch release that stops helm-controller from reapplying chart CRDs on every upgrade when server-side apply is enabled, and recovers HelmReleases left with a drifted Ready=Unknown condition after a failed status patch. source-controller normalizes Azure Blob listing ETags so unchanged containers are no longer re-downloaded on every reconcile, and evicts stale Helm repository index entries from the cache so repositories with frequently changing indexes no longer fail with "Cache is full". kustomize-controller extends SOPS decryption error redaction to spec.postBuild.substituteFrom values, so substituted secrets echoed back in API validation errors are masked out of status conditions and events, and adds the opt-in DisableCommitStatusEvent feature gate. Users are encouraged to upgrade for the best experience.

ℹ️ Please follow the Upgrade Procedure for Flux v2.7+ for a smooth upgrade from Flux v2.6 to the latest version.

Fixes:

  • Stop reapplying chart CRDs on upgrades when using server-side apply with the default Create policy (helm-controller)
  • Recover HelmReleases stranded with a drifted Ready=Unknown condition after a failed status patch (helm-controller)
  • Ignore NotFound when deleting the HelmChart (helm-controller)
  • Normalize Azure Blob listing ETags so unchanged containers are not re-downloaded on every reconcile (source-controller)
  • Evict stale Helm repository index entries from the cache to avoid "Cache is full" errors (source-controller)
  • Extend SOPS decryption error redaction to spec.postBuild.substituteFrom values (kustomize-controller)

Improvements:

  • Add the opt-in DisableCommitStatusEvent feature gate (kustomize-controller)
