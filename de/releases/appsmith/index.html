11/19
v2.7.2 Patch MT

The bundled Java runtime is now Eclipse Temurin 25.0.5.1. This fixes CVE-2026-114938 ('Java4Shell') in the Java runtime. All earlier Appsmith images include an affected Java version. Self-hosted instances should upgrade.

v2.7.1 Patch MT

Embed allowlist: APPSMITH_ALLOWED_FRAME_ANCESTORS must be a list of CSP frame-ancestors source expressions. A saved value that is not in that form is served as 'self' after the next restart.

v2.7.0 Minor MT

Wenn Sie den Fehlerschwellenwert für den alten 60-Sekunden-Zeitraum eingestellt haben, legen Sie auch periodSeconds: 60 fest.
