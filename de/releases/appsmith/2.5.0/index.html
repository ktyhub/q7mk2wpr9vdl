appsmith v2.5.0

🗑️ Erinnerung an die Entfernung von Funktionen – 30. September 2026 – EOL

Appsmith AI hat am 30. September 2026 das Ende seiner Lebensdauer erreicht.

Sie können keine neuen Appsmith AI-Datenquellenverbindungen oder -abfragen mehr hinzufügen. Vorhandene Abfragen funktionieren nicht mehr, unabhängig davon, ob Sie ein Upgrade durchgeführt haben oder nicht.

Migrieren Sie verbleibende Appsmith AI-Abfragen zu einer direkten Anbieterdatenquelle wie OpenAI, Anthropic oder Google AI.

⚠️ Wichtige Upgrade-Hinweise

– Mit Git verbundene Anwendungen werden beim nächsten Öffnen auf Serverschema 13 aktualisiert. Dies kann zu einem einmaligen System-Commit führen. Aus dieser Version exportierte Anwendungen können nicht in einen älteren Server importiert werden, der nur Schema 12 unterstützt. (#42322) – Wenn Sie eine Datenquellenverbindungseinstellung ändern, müssen Sie die Anmeldeinformationen für die aktiven Authentifizierungs-, TLS- und SSH-Einstellungen erneut eingeben. Bei unveränderten Verbindungen können weiterhin gespeicherte Anmeldeinformationen verwendet werden. (#42339) – Elasticsearch-Körperbindungen verwenden jetzt die typisierte JSON-Ersetzung. Überprüfen Sie Abfragen, die serialisierte JSON einfügen, einen Teil einer JSON-Zeichenfolge erstellen oder dynamische Pfade erstellen. Ungültige Bindungen geben jetzt einen Abfragefehler zurück. (#42342)

🔐 Sicherheit

– Aktualisierte gebündelte Abhängigkeiten, um gemeldete Schwachstellen zu beheben. (#42314, #42324, #42331) – Die Wiederverwendung von Datenquellen-Anmeldeinformationen ist jetzt an die gespeicherte Verbindungskonfiguration gebunden, und Datenquellen-Test-, Struktur- und Trigger-Anfragen verwenden strengere Berechtigungsprüfungen. (#42339) – Anfragen aus der Evaluierungsumgebung behalten jetzt den Schutz vor dem Auslassen von Anmeldeinformationen bei, auch wenn sich der globale Anfragekonstruktor ändert. (#42355) – Anmelderatenbegrenzungen verwenden jetzt dieselbe normalisierte Kontoidentität wie die Authentifizierung. (#42337) – Datenquellenaktualisierungen bewahren jetzt die Identität der von der Anfrage ausgewählten Datenquelle. (#42356) – Elasticsearch-Abfragen validieren jetzt ersetzte JSON- und dynamische Pfadwerte vor der Ausführung. (#42342)

🛠️ Zuverlässigkeit

– Vorbereitete MySQL-Aufrufe gespeicherter Prozeduren können jetzt mit einer abschließenden Abfrage ausgeführt werden und gebundene Werte als Daten behalten. (#42329) – Bei fehlgeschlagenen OAuth2- und SSO-Anmeldungen kehren Benutzer jetzt zur Anmeldeseite der Instanz zurück. (#42330) – Zonen in Karten, Registerkarten, Blättern und Listenelementen nutzen jetzt die gesamte verfügbare Breite, anstatt sich in einer schmalen Spalte zusammenzufassen. (#42364) – Beim Erstellen einer MCP-Datenquelle kann der Server jetzt die richtige Umgebung auswählen. (#42341)

✨ Neue Funktionen und Verbesserungen

– Bewerbungen können jetzt eine optionale Beschreibung haben, die auf Bewerbungskarten erscheint. (#42312) – Listen-Widgets verfügen jetzt über die Option Auswahl deaktivieren für Apps, die keine Zeilenauswahl oder kein Item-click-Verhalten benötigen. (#42261) – MCP kann jetzt strukturierte JS-Objekte erstellen und aktualisieren, mehr MongoDB-Filtertypen verwenden, mehr Widget-Einstellungen patchen, JS-Funktionsaufrufe verbinden und häufige Layoutprobleme erkennen. (#42311)

🎨 Verbesserungen der Benutzeroberfläche und des Widgets

– Tabellenspalten verfügen jetzt über eine optionale Einstellung Kopfzeilenumbruch für lange Spaltentitel. (#42354) – Tabellenüberschriften unterstützen jetzt konfigurierbare Schriftstärke, kursiven Text und Unterstreichungen. (#42323) – Die Anwendungsseite bleibt jetzt unter dem fehlenden Basis-URL-Banner, sodass die Arbeitsbereichssteuerelemente weiterhin sichtbar sind. (#42319)

🔧 Git, Bereitstellung und Konfiguration

– MCP-Protokolle zeichnen jetzt das tatsächliche Ergebnis jedes Tool-Aufrufs auf und behalten die korrekte Anforderungs-ID bei zugehörigen Backend-Aufrufen bei. (#42350)

appsmith v2.5.0

Highlights

  • Appsmith AI has reached end of life — migrate off it first — As of September 30, 2026 you cannot create new Appsmith AI datasources or queries, and existing queries have stopped working whether or not you upgrade. There is no compatibility path: rewrite remaining queries against a direct provider datasource (OpenAI, Anthropic, or Google AI) before relying on any AI-driven app. This is the single most urgent item in the release and it is not gated on adopting v2.5.0.

  • Server schema 13 changes Git and export portability — Git-connected applications are silently upgraded to server schema 13 the next time they are opened, which can produce a one-time system commit you'll see in history (#42322). More importantly, apps exported from this release cannot be imported into a schema-12 server — so coordinate any control-plane upgrade and avoid round-tripping exports to older instances. Treat this as a one-way, version-locked migration.

  • Datasource credentials are now bound to the exact connection config — Changing any active authentication, TLS, or SSH setting means re-entering credentials; unchanged connections keep using saved secrets (#42339). The hardening also tightens permissions on datasource test/structure/trigger requests, preserves the datasource identity chosen by the request on updates (#42356), and keeps the credential-omission guard in evaluation-environment requests even if the global request constructor is swapped (#42355). Expect interactive re-auth in scripts that previously mutated connection settings in place.

  • Elasticsearch bindings are now strictly typed — Substitution uses typed JSON and validates substituted values and dynamic paths before execution, so queries that insert serialized JSON, assemble partial JSON strings, or build dynamic paths can now fail at query time instead of silently producing odd results (#42342). Audit your ES queries before rollout — this is a behavioral break that surfaces only when those queries actually run.

  • MCP becomes substantially more useful for agentic app building — MCP can now create and update structured JS objects, handle more MongoDB filter types, patch a wider range of widget settings, wire JS function calls, and flag common layout problems (#42311); datasource creation lets the server pick the correct environment (#42341); and logs now record the real result of each tool call with the correct request ID on related backend calls (#42350). The logging change in particular makes MCP-driven runs far easier to debug.

  • Reliability and UI fixes worth noting for existing apps — MySQL stored-procedure calls now accept a trailing query while keeping bound values as data (#42329); failed OAuth2/SSO logins return users to the instance login page instead of dead-ending (#42330); and zones in cards, tabs, sheets, and list items finally use full available width rather than collapsing into a narrow column (#42364). On the widget side, tables gain header wrapping (#42354) and header font weight/italic/underline controls (#42323), List widgets gain a Disable selection option (#42261), and apps can carry a description shown on application cards (#42312).

🗑️ Feature Removal Reminder - September 30, 2026 - EOL

Appsmith AI reached end of life on September 30, 2026.

You can no longer add new Appsmith AI datasource connections or queries. Existing queries have stopped working, whether or not you have upgraded.

Migrate remaining Appsmith AI queries to a direct provider datasource, such as OpenAI, Anthropic, or Google AI.

⚠️ Important Upgrade Notes

  • Git-connected applications update to server schema 13 when they are next opened. This can create a one-time system commit. Applications exported from this release cannot be imported into an older server that supports only schema 12. (#42322)
  • When you change a datasource connection setting, you must enter the credentials again for the active authentication, TLS, and SSH settings. Unchanged connections can continue to use saved credentials. (#42339)
  • Elasticsearch body bindings now use typed JSON substitution. Review queries that insert serialized JSON, build part of a JSON string, or construct dynamic paths. Invalid bindings now return a query error. (#42342)

🔐 Security

  • Updated bundled dependencies to address reported vulnerabilities. (#42314, #42324, #42331)
  • Datasource credential reuse is now tied to the saved connection configuration, and datasource test, structure, and trigger requests use stricter permission checks. (#42339)
  • Requests from the evaluation environment now keep the credential-omission guard even if the global request constructor changes. (#42355)
  • Login rate limits now use the same normalized account identity as authentication. (#42337)
  • Datasource updates now preserve the identity of the datasource selected by the request. (#42356)
  • Elasticsearch queries now validate substituted JSON and dynamic path values before execution. (#42342)

🛠️ Reliability

  • Prepared MySQL stored procedure calls can now run with a trailing query and keep bound values as data. (#42329)
  • Failed OAuth2 and SSO logins now return users to the instance login page. (#42330)
  • Zones in cards, tabs, sheets, and list items now use the full available width instead of collapsing into a narrow column. (#42364)
  • MCP datasource creation now lets the server select the correct environment. (#42341)

✨ New Features & Enhancements

  • Applications can now have an optional description that appears on application cards. (#42312)
  • List widgets now have a Disable selection option for apps that do not need row selection or item-click behavior. (#42261)
  • MCP can now create and update structured JS objects, use more MongoDB filter types, patch more widget settings, wire JS function calls, and detect common layout issues. (#42311)

🎨 UI & Widget Improvements

  • Table columns now have an optional Header wrapping setting for long column titles. (#42354)
  • Table headers now support configurable font weight, italic text, and underlining. (#42323)
  • The Applications page now stays below the missing base URL banner, so workspace controls remain visible. (#42319)

🔧 Git, Deployment & Configuration

  • MCP logs now record the actual result of each tool call and keep the correct request ID on related backend calls. (#42350)
