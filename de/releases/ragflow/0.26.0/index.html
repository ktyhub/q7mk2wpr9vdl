Ragflow v0.26.0

Zusammenfassung

Neue Funktionen

  • Modellanbieter
    • Implementiert automatisch ausgefüllte Modelllisten für mehrere Anbieter, wodurch die manuelle Eingabe von Modellnamen entfällt. Diese Funktion unterstützt derzeit: Ollama, OpenRouter, vLLM, OpenAI-API-Compatible, LM-Studio, VolcEngine, Xinference, LocalAI, BaiduYiyan, GPUStack und Fish Audio. – Ermöglicht die Konfiguration mehrerer API-Schlüssel für denselben Modellanbieter. #14595
    • Füllt die Dropdown-Listen zur Modellauswahl in der Benutzeroberfläche dynamisch aus, indem die aktuell verfügbaren Modelle direkt von Remote-Modellanbietern abgerufen werden. #15711
  • Datenquellen-Konnektoren: Implementiert neue Datenquellen-Konnektoren für Outlook, OneDrive, Microsoft Teams, Slack, SharePoint, Salesforce und Azure Blob Storage. #15333#15330#15332#15188#15190#15462#15466
  • Datensatz – Implementiert eine Checkpoint- und Resume-Funktion für die Community-Extraktion und Entitätsauflösung, die teuersten und zeitaufwändigsten Teile der GraphRAG-Indizierungspipeline. #15518#15523

Verbesserungen

– Entfernt die <think>-Textpufferung, um sicherzustellen, dass sich Modelle, die zur Argumentation fähig sind, bei Interaktionen schneller und transparenter anfühlen. #15891 – Markiert MySQL-Migrationen als angewendet. #15504

Modellunterstützung

  • Vier neue SiliconFlow-Modelle #15383
  • MiniMax-M3-Modell #15513
  • Neueste Anthropic-Modelle #15516
  • Modellfamilie Voyage 4 #15516
  • Cohere-Modellliste. #15576

i18n

  • Vervollständigt die koreanische Übersetzung. #15863
  • Vervollständigt die italienische Übersetzung. #15729

Fehlerbehebungen

  • Der Denkmodus von MiniMax-Modellen wurde nicht korrekt aktiviert. #15496
  • Endlosschleifen wurden ausgelöst, als der Denkmodus für die Modelle Qwen3.5 und Qwen3.6 aktiviert wurde. #15101 – Gestreamte Antworten wurden dupliziert, wenn der OpenAI-kompatible Chat-Abschluss-Endpunkt API verwendet wurde. #15286#15443 – Bei Chat-Abschlüssen wurden Serialisierungsfehler verursacht, wenn ungültige numerische Werte wie NaN (Keine Zahl) oder Inf (Unendlich) an den JSON-Encoder übergeben wurden. #15245#15266 – Chat-Abschlüsse mit LiteLLM-Anbietern schlugen fehl, weil unbekannte interne Konfigurationsparameter nicht herausgefiltert wurden, bevor sie die externen APIs erreichten. #15427#15432 – Die OpenAI-kompatiblen Chat-Abschlüsse API verwendeten standardmäßig gestreamte Antworten. #15356#15394 – Leere AND-Ergebnisse wurden während der Metadatenfilterung fälschlicherweise verworfen. #15477
  • Sich wiederholende Seitenchrome, wie Kopf- und Fußzeilen, wurden vom MinerU-Parser fälschlicherweise als Haupttext extrahiert. #15335#15387
  • Bei der Dokumentenextraktion im DeepDoc-Modul fehlten englische Diagrammtitel. #15481 – Leere Ausgaben wurden vom TitleChunker für die Upstream-Formate json und chunks zurückgegeben #14247#15396
  • Es fehlte eine Fehlermeldung, als der Versuch, eine .tsv-Datei hochzuladen, fehlschlug. #15284 – Bei API-Tokens fehlten Betawerte, was zu Fehlern beim Token-Abruf führte. #15405 – Begrenzt die maximale Seitengröße, um Systemabstürze oder Verlangsamungen durch große Abfragen zu beheben. #15292 – Client-Fehler wurden dadurch verursacht, dass der OpenAI-kompatible Chat-Abschluss API fälschlicherweise standardmäßig gestreamte Antworten verwendete. #15356#15394 – Es wurden interne HTTP 500-Serverfehler anstelle der standardmäßigen 4xx client-Fehler ausgelöst, wenn Benutzer versuchten, fehlende Dateien aus dem Speicher-Backend herunterzuladen. #15369#15371
  • Das Ranking der GraphRAG-Entitäten war fehlerhaft. #15795#15797

ragflow v0.26.0

Summary

New features

  • Model providers
    • Implements auto-populated model lists for multiple providers, eliminating the need to type model names manually. This feature currently supports: Ollama, OpenRouter, vLLM, OpenAI-API-Compatible, LM-Studio, VolcEngine, Xinference, LocalAI, BaiduYiyan, GPUStack, and Fish Audio.
    • Allows configuring multiple API keys for the same model provider. #14595
    • Dynamically populates model selection dropdowns in the UI by fetching the currently available models directly from remote model providers. #15711
  • Data source connectors: Implements new data source connectors for Outlook, OneDrive, Microsoft Teams, Slack, SharePoint, Salesforce, and Azure Blob Storage. #15333#15330#15332#15188#15190#15462#15466
  • Dataset - Implements a checkpoint and resume feature for community extraction and entity resolution, the most expensive and time-consuming parts of the GraphRAG indexing pipeline. #15518#15523

Improvements

  • Removes <think> text buffering to ensure reasoning-capable models feel faster and more transparent during interactions. #15891
  • Marks MySQL migrations as applied. #15504

Model Support

  • Four new SiliconFlow models #15383
  • MiniMax-M3 model #15513
  • Latest Anthropic models #15516
  • Voyage 4 model family #15516
  • Cohere model list. #15576

i18n

  • Completes Korean translation. #15863
  • Completes Italian translation. #15729

Bug fixes

  • The thinking mode of MiniMax models was not correctly enabled. #15496
  • Infinite loops were triggered when the thinking mode was enabled for Qwen3.5 and Qwen3.6 models. #15101
  • Streamed answers were being duplicated when using the OpenAI-compatible chat completions API endpoint. #15286#15443
  • Serialization errors were caused during chat completions when invalid numeric scores like NaN (Not-a-Number) or Inf (Infinity) were passed to the JSON encoder. #15245#15266
  • Chat completions using LiteLLM providers were failing because unrecognized internal configuration parameters were not being filtered out before reaching the external APIs. #15427#15432
  • The OpenAI-compatible chat completions API was defaulting to streamed responses. #15356#15394
  • Empty AND results were incorrectly dropped during metadata filtering. #15477
  • Repetitive page chrome, such as headers and footers, was incorrectly extracted as main text by the MinerU parser. #15335#15387
  • English chart titles were missing during document extraction in the DeepDoc module. #15481
  • Empty outputs were returned by the TitleChunker for json and chunks upstream formats #14247#15396
  • An error message was missing when a .tsv file upload attempt failed. #15284
  • API tokens missing beta values caused token retrieval errors. #15405
  • Caps the maximum page size to fix system crashes or slowdowns from large queries. #15292
  • Client errors were caused by the OpenAI-compatible chat completion API incorrectly defaulting to streamed responses. #15356#15394
  • HTTP 500 internal server errors were triggered instead of standard 4xx client errors when users attempted to download missing files from the storage backend. #15369#15371
  • GraphRAG entity ranking was broken. #15795#15797
