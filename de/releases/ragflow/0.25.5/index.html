Ragflow v0.25.5

Zusammenfassung

Veröffentlicht am 20. Mai 2026.

Neue Funktionen

  • Fügt lokale und SSH-Anbieter im Admin-Bereich hinzu. #15039

Verbesserungen

  • Beschleunigter Suchpfad für Datensätze, wodurch die Latenz um 50–100 % reduziert wird, indem teure Schritte zum Abrufen von Vektoren und zur Neuordnung der Ähnlichkeitsberechnung entfallen. #14970 – Verschiebt Metadatenfilter auf „Unendlich“, wodurch die Metadatenfilterung erheblich beschleunigt wird. #14974
  • Redis-Caching für TTS hinzugefügt. #14851
  • Aktualisierungen des atomaren Dokumentzählers #14867 – Verbesserte Startgeschwindigkeit und Speichernutzung des Servers #14973 – Agent: Strukturierte Ausgabeaggregation #13384 #14848
  • Agent: Wiederverwendung von Metadatenfiltern. #14849
  • Optimiert das Connector-Dashboard. #14979

ragflow v0.25.5

Summary

Released on May 20, 2026.

New features

  • Adds local & SSH providers in admin panel. #15039

Improvements

  • Accelerated dataset search path, reducing latency by 50–100% by removing expensive vector fetch and rerank similarity computation steps. #14970
  • Pushes metadata filters down to Infinity, significantly speeding up metadata filtering. #14974
  • added Redis caching for TTS. #14851
  • atomic document counter updates #14867
  • Improved server startup speed and memory usage #14973
  • Agent: structured output aggregation #13384 #14848
  • Agent: metadata filter reuse. #14849
  • Optimizes connector dashboard. #14979
