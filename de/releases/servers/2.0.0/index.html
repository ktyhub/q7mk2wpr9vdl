Python-Server: Änderungen für clients

mcp-server-fetch, mcp-server-git und mcp-server-time haben kein CHANGELOG, daher ändert sich Folgendes für einen client in 2026.10.19. Sie basieren jetzt auf dem High-Level-MCPServer des MCP Python SDK (#5175).

  • Unbekanntes Tool: ein JSON-RPC -32602-Fehler (Unknown tool: <name>) in beiden Protokollepochen, wie in der Spezifikation erforderlich. Früher war es ein isError-Ergebnis.
  • Werkzeugfehler lauten Error executing tool <name>: <message>. Argumentvalidierungsfehler verwenden jetzt den Wortlaut von pydantic. Bei beiden handelt es sich immer noch um isError-Ergebnisse.
  • Funktionen: Jeder Server bietet jetzt die Funktionen prompts und resources an (mit listChanged: false). Die fetch-Eingabeaufforderung von fetch ist der einzige Eintrag in diesen Listen.
  • Zeit: get_current_time und convert_time deklarieren einen outputSchema und geben structuredContent zurück. Der Textinhalt bleibt unverändert.
  • Abrufen: Der description eines prompts/get-Ergebnisses ist jetzt immer die registrierte Beschreibung der Eingabeaufforderung.
  • Erfordert mcp>=2.3,<3.

Python servers: changes for clients

mcp-server-fetch, mcp-server-git and mcp-server-time have no CHANGELOG, so here is what changes for a client in 2026.10.19. They are now built on the MCP Python SDK's high-level MCPServer (#5175).

  • Unknown tool: a JSON-RPC -32602 error (Unknown tool: <name>) in both protocol eras, as the spec requires. It used to be an isError result.
  • Tool errors read Error executing tool <name>: <message>. Argument-validation errors now use pydantic's wording. Both are still isError results.
  • Capabilities: each server now advertises prompts and resources capabilities (with listChanged: false). fetch's fetch prompt is the only entry in those lists.
  • time: get_current_time and convert_time declare an outputSchema and return structuredContent. The text content is unchanged.
  • fetch: a prompts/get result's description is now always the prompt's registered description.
  • Requires mcp>=2.3,<3.

mcp-server-fetch 2026.10.19
