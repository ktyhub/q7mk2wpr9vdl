Upgrade-Protokoll

Dieses Upgrade rüstet langchain4j auf 1.3.0 auf, stärkt die KI-Funktionen, fügt MCP- und Plug-in-Unterstützung hinzu, ermöglicht Geschäftsvorgänge im Chat-Stil (z. B. „Benutzer in einem Satz erstellen“) und erweitert die KI-Chat- und Prozessorchestrierungsfunktionen. Integrieren Sie Anthropic (Claude), Netzwerksuch- und Argumentationsmodelle, um die Deep-Thinking-Fähigkeiten des Systems zu verbessern. Das Upgrade von POI auf Version 5 wurde abgeschlossen und Systemverwaltungsfunktionen wie Benutzer, Abteilungen und Mandanten optimiert. Ab v3.9.0+ wird das gleichzeitige Upgrade auf Spring Boot Version 2 gestoppt.

Verbesserung der KI-Funktion
  • Aktualisieren Sie langchain4j auf die Version 1.3.0. – KI-Anwendungen bieten Unterstützung für MCP und Plug-Ins.
  • Die KI-Chat-Funktion unterstützt MCP und Plug-in-Erweiterungen. – KI-Prozessorchestrierung fügt MCP- und Plug-in-Unterstützung hinzu.
  • Unterstützen Sie den KI-Chat zur Geschäftsabwicklung (zum Beispiel: Erstellen Sie einen Benutzer in einem Satz)
  • Unterstützung für Anthropic (Claude)-Modellanbieter hinzugefügt.
  • AI-Chat unterstützt Argumentationsmodelle, um die Fähigkeit zum tiefgreifenden Denken zu verbessern.
  • Der KI-Prozess unterstützt Export- und Importfunktionen – Der AI-Skriptknoten unterstützt das Schreiben in der Sprache Python
  • AI-Chat integriert das Qianwen-Modell und unterstützt die Online-Suchfunktion
  • Unterstützt über 2000 dimensionale Vektoren, die pgvector-Version muss größer als 0.7 sein
Upgrade der funktionalen Architektur
  • Ab der Version v3.9.0+ wird die Version Spring Boot 2 nicht mehr gleichzeitig aktualisiert.
  • Änderungsprotokolle stapelweise löschen, um die Lesbarkeit des Codes zu verbessern
  • POI auf Version 5 aktualisiert.
  • Aktualisieren Sie die Nebenversionsnummer des abhängigen Pakets in package.json
  • Der Bausteinbericht wird auf die neueste Version v2.2.0 aktualisiert.
  • Building Block BI wurde auf die neueste Version v2.2.0 aktualisiert, mit einer neuen Multi-Screen-Umschaltfunktion und das Großbild-Design unterstützt Export und Import.
  • Integrieren Sie vite-plugin-pwa, um Progressive Web Applications (PWA) zu implementieren und so die Ladegeschwindigkeit des ersten Bildschirms erheblich zu verbessern.
  • Systemressourcen werden asynchron geladen und Menüs reagieren schneller.
  • Das Login-Passwort wird mittels AES-Verschlüsselung übertragen, um eine Klartextübertragung zu verhindern und die Sicherheit zu erhöhen.
  • Unterstützt die separate Einstellung der Gültigkeitsdauer von APP- und PC-Anmeldesitzungen.
  • Unterstützung der flexiblen Konfiguration von Anmelderegeln:
  • Ob die gleichzeitige Anmeldung desselben Kontos von mehreren Orten aus zulässig ist.
  • Ob die Standard-Passwort-Anmeldeerinnerung aktiviert werden soll.
  • Ob die Überprüfung des Anmeldebestätigungscodes aktiviert werden soll.
  • Anmeldebenutzer unterstützen differenzierende Anmelderegeln (Unterscheidung zwischen PC und APP) und zeichnen Endgeräteinformationen auf, um die Implementierung der APP-Push-Funktion zu erleichtern.
  • Die Abteilungsleitung hat die Funktion zur Anzeige von Abteilungsleitern hinzugefügt.
  • Das Abteilungsmanagement unterstützt die Drag-and-Drop-Anpassung der Beziehungen zwischen Vorgesetzten und Untergebenen der Abteilung, um den Betriebskomfort zu verbessern.
  • Benutzerpositionen werden an eine relationale Tabellenstruktur angepasst, um die Datenzuordnungsverwaltung zu optimieren.
  • Die Benutzeroberfläche meines Mandanten wurde überarbeitet, um das Benutzererlebnis insgesamt zu verbessern.
  • Optimieren Sie die Standard-Passwortregeln, um die Sicherheit zu erhöhen.
  • Unterstützt das Ausblenden von Benutzerkontaktinformationen zum Schutz der Privatsphäre.
  • Rich-Text-Editor-Optimierung: Bilder in Artikeln, die aus Blogs kopiert wurden, werden automatisch heruntergeladen und in den Cloud-Speicher hochgeladen
  • Abteilungsauswahlfunktion zur Anmeldeseite hinzugefügt – Die Listenseite „BasicTable“ unterstützt die Angabe von Exportspalten beim Exportieren nach Excel
  • Uniapp-Push-Funktion unterstützt Online- und Offline-Nachrichten (bereits mit Systemankündigungen verbunden) – Die Protokollebene wird von „Info“ auf „Debug“ angepasst, um die Menge der Protokollausgabe zu reduzieren.
  • Optimieren Sie einige Funktionsfehler, die durch verzögertes Laden verursacht werden, und beheben Sie den Fehler bei ignorierten Anmerkungen.
  • Generierte Codes werden einheitlich in das XLSX-Format exportiert
  • „Meine Nachrichten“ unterstützt das Stapellöschen gelesener Nachrichten – Aktualisieren Sie shardingsphere-jdbc auf 5.5.0, um die Konfiguration der ShardingSphere-Datenquelle zu vereinfachen
  • Benutzerverwaltung unterstützt die Abfrage von Benutzern nach Organisationsstruktur (unterstützt Mehrfachauswahl)
  • Die Benutzerverwaltung wird um neue Sortierfelder erweitert und Funktionen wie Personenauswahlkomponenten und Adressbücher werden entsprechend der Sortierfelder angezeigt.

JeecgBoot v3.9.0

Highlights

  • AI model stack — langchain4j moves to 1.3.0, adding Anthropic/Claude support, Qwen web search, and reasoning-model chat. Revalidate provider credentials, model activation, and custom chains after upgrading; model activation and test-connection regressions are also addressed (#8955, #8972, #9071).
  • Tool-enabled AI workflows — MCP and plugins now extend AI apps, chat, and flow orchestration; flows support import/export, and script nodes support Python. Because chat can perform business writes such as creating users, enforce server-side authorization and auditing on tools rather than relying on prompts, and verify the Python execution environment before enabling untrusted workflows.
  • Runtime and dependency baseline — From v3.9.0+, Spring Boot 2 no longer receives synchronized releases, so Boot 2 deployments should plan migration to the Spring Boot 3 line. POI 5, ShardingSphere JDBC 5.5.0, and JimuReport/JimuBI 2.2.0 warrant regression testing of custom export templates, datasource configuration, and report imports.
  • Authentication behavior — Login passwords are AES-encrypted in transit, with separate PC/APP session lifetimes, configurable concurrent-login/captcha/default-password rules, and device tracking. Custom clients and gateways must accommodate the new password payload and session policies; review password-change brute-force protections following #8805.
  • Schema and vector prerequisites — User-position data adopts a relationship-table structure, so audit custom joins and data-migration scripts involving user/post assignments. Embeddings above 2,000 dimensions require pgvector newer than 0.7 (0.8+); plan dimension and index migrations before increasing embedding size.
  • Online low-code reliability — Fixes cover the systemic query-form failure (#8790), Java-enhancement regressions (#8859, #8951), MySQL bigint mapping (#8909), and SQL Server pagination requirements. Generated exports are now uniformly XLSX, and BasicTable supports column-selective export (#9052); update automation that assumes older formats or generated types.
