#JecgBoot v3.9.2

Upgrade-Protokoll

**v3.9.2 ist das bedeutendste Versions-Upgrade von JeecgBoot seit dem Start der AI-Route. ** Low Code hat sich erneut weiterentwickelt und ist offiziell in die v2.0-Ära eingetreten – von „Drag and Drop“ zu „einem Satz natürlicher Sprache“. Mit vollständiger Unterstützung von Skills können Sie ein Geschäft in einem Satz aufbauen und manuelle Konfiguration gehört der Vergangenheit an! Low Code ist nicht mehr nur „Drag and Drop zum Generieren von CRUD“. Mit JeecgBoot ist es zur Realität geworden, in einem Satz einen großen Bildschirm zu erstellen, in einem Satz die OA-Genehmigung aufzubauen und in einem Satz das gesamte System zu generieren! Dieses Upgrade verbessert außerdem umfassend die Low-Code-Entwicklungserfahrung und umfasst die systematische Optimierung von Formularen, Diagrammen, großen Bildschirmen, Sicherheit und Front-End-Leistung, das gleichzeitige Öffnen des Online-Front-End-Quellcodes und das Hinzufügen eines neuen Online-Diagrammmoduls.

✨ Die „Höhe“ dieser Veröffentlichung

1. Fähigkeiten: Machen Sie KI zu Ihrem Entwicklungspartner
  • Claude Code Skills verbindet sich mit Low Code: Codegenerierung, Online-Formulare, Berichte, große Bildschirme und Prozesse sind vollständig in Claude Skills integriert, keine Notwendigkeit, den Codegenerator manuell zu bedienen – KI generiert Code in einem Satz, generiert das gesamte System in einem Satz, erstellt Online-Formulare in einem Satz, erstellt Online-Berichte in einem Satz, entwirft große Bildschirme in einem Satz, konfiguriert Wörterbücher in einem Satz, erstellt Menüs und vervollständigt die Autorisierung – alles auf Knopfdruck.
2. KI-Anwendungsoptimierung
  • Chat2BI / Chart2BI-Docking-Online-Formular: Generieren Sie paginierte Tabellen, Berichte und Diagrammkonfigurationen in einem Satz und öffnen Sie den gesamten Link zur Datenanalyse.
  • Die Fähigkeiten zur Orchestrierung von KI-Prozessen explodieren: Mit neuem Lesen und Schreiben von Variablen, Speicherabruf, Schleifenvariablen, strukturierter JSON-Ausgabe, Zuordnung von Eingabeaufforderungswortlisten, Startknoten für den Datei-Upload usw. hat sich AiFlow zu einer vollständigen visuellen Agenten-Orchestrierungsplattform entwickelt.
  • Whitelist für KI-Anwendungstools + mandantenübergreifende Isolierung: Die Öffnung von Funktionen und die Berechtigungskontrolle werden gleichzeitig implementiert, und die SaaS-Sicherheitsgrenze für mehrere Mandanten ist fest etabliert.
  • Die unterstützenden AI Assistant Network Search und AI Process Search Engine Node werden gestartet, sodass der KI-Prozess nicht nur „wissen kann, wie man Werkzeuge verwendet“, sondern auch „weiß, wie man Informationen nachschlägt“.
  • Langchain4j 1.12.2-Upgrade: Definiert die Grenzen der Java-KI-Anwendungsfunktionen neu – der KI-Assistent verlässt sich nicht mehr auf manuelle Eingabeaufforderungs-Wort-Blind-Anpassungsschnittstellen und unterstützt außerdem Skills-Metadaten, um Geschäftsfunktionen automatisch auszuwählen und aufzurufen.
3. KI multimodale Produktivität (Bild / Audio / Video / Kleidung wechseln)
  • Echte KI generierte Audio/Video/Bild, keine Demo mehr
  • KI-Kleiderwechsel gibt gleichzeitig Bilder und Videos aus
  • Das Google-Bildgenerierungsmodell, die lokale Sprachsynthese und Beispiele für gemischte Bilder sind vorhanden
  • Vervollständigung der Modellmatrix: VLLM / Xinference / LMStudio / qwen-vl-ocr / qwen3.5-plus / Tongyi Qianwen / Qianfan
4. Online-Dreierset (Formular/Bericht/Diagramm) einmalige Optimierung
  • Der Frontend-Quellcode des Online-Moduls ist vollständig Open Source. Im KI-Zeitalter können Benutzer frei und flexibel expandieren, und es gibt keine Schwelle für eine sekundäre Entwicklung.
  • Neues Online-Diagrammmodul wurde hinzugefügt, um das Diagrammfeld schnell zu konfigurieren und Benutzern mehr Visualisierungsoptionen zu bieten.
  • Neuer LongText-Feldtyp und link_table / link_table_field-Typ (Vue3 eins zu viele zugeordnete Datensätze, tabellenübergreifende Feldverweise)
  • Untertabellen unterstützen Klassifizierungswörterbuchbäume und benutzerdefinierte Wörterbuchbäume, wodurch die hierarchische Datenkonfiguration flexibler wird
  • Viele Jahre hartnäckiger Probleme behoben: Online-Konfigurationsverzögerung (QQYUN-14177), Online-Öffnung langsam, Kleine Bildschirmfeldpositionierung ist nicht sichtbar und andere Erfahrungsprobleme wurden vollständig behoben
  • Neues Dokument zur Spezifikation des Online-Formularschemas wurde hinzugefügt, um eine solide Grundlage für die KI zu schaffen, um Online-Metadaten tiefgreifend zu verstehen.
5. Vollständiges On-Demand-Laden, Verschlankung des Frontends
  • antd / unplugin-icons / Jvxetable / Vxetable / TinyMCE / JEasyCron / codemirror / Chat-Modul, alles bei Bedarf geladen – Die Größe und Ladegeschwindigkeit des ersten Bildschirms wurden deutlich reduziert, wodurch KI-Assistenten den Weg freimachen, die Unternehmensseite online aufzurufen.
6. Sicherheitsverstärkung
  • AI Poster SSRF (#9579), AI Attachment Path Traversal (#9519), AiragApp Cross-Tenant Writing (#9462), Unberechtigter Token-Zugriff (#9518), RCE #9335 und viele andere Schwachstellen mit hohem Risiko wurden zentral behoben
  • Umfassende Berechtigungsüberprüfung für MCP / zugrunde liegende sensible Tools

🎯 Was bedeutet die Low-Code-Ära v2.0?

Mit Skills können die auf der Low-Code-Plattform gesammelten Formulare, Prozesse, Berichte und großen Bildschirme automatisch zu Geschäftsfunktionen werden, die direkt von der KI aufgerufen werden können – es sind keine handschriftlichen Tools oder Sekundärentwicklung erforderlich, natürliche Sprache kann die automatisierte Ausführung eines vollständigen Satzes von Geschäftsprozessen vorantreiben und sogar das gesamte System in einem Satz generieren. | Dimension | v3.9.1 und früher (Drag-and-Drop-Ära) | v3.9.2 (Ein-Satz-Ära) | |---|---|---| | Low-Code-Positionierung | Formular-/Prozess-/Codegenerierung/Bericht und Großbilddesign | Export von KI-nativen Geschäftsfunktionen | | Interaktiver Modus | Drag & Drop + manuelle Konfiguration | Ein Satz natürlicher Sprache, alles ist möglich | | Geschäftsaufbau | Komponenten manuell ziehen, Felder konfigurieren und Prozesse einrichten | **Entwerfen Sie Formulare und zeichnen Sie Prozesse in einem Satz/Bericht/Großbildschirm/Menü ** | | KI-Nutzung | Komplett manuelle Erstellung: Formulare manuell konfigurieren, Prozesse zeichnen, Zuordnungen erstellen, Menüs konfigurieren und Schritt-für-Schritt-Autorisierung | KI kann Formulare erstellen, Prozesse zeichnen, Assoziationen verknüpfen, Menüs erstellen und Berechtigungen in einem Satz vervollständigen, alles in einem Schritt | | Geschäftszugang zu KI | Sekundäre Entwicklung handschriftlicher Werkzeuge erforderlich | Online-Formular-/Prozessknoten = natürliche Fähigkeit | | Multimodal | Nur Text | Vollständige modale Abdeckung von Text/Bild/Audio/Video/Kompetenzen | | Sicherheit | Dezentrale Schwachstellenreparatur | Spezialisierte Schwachstellenreparatur + Berechtigungskontrolle + Mandantenisolierung und -verstärkung |

Skills-Funktionsmodul (neues unabhängiges Lager jeecgboot/skills)

Ein neues unabhängiges Warehouse jeecgboot/skills, das gleichzeitig mit der Hauptversion von v3.9.2 veröffentlicht wird – eine Sammlung von KI-Fähigkeiten basierend auf Claude Code, gesteuert durch natürliche Sprache, die Code, Formulare, Prozesse, Berichte, Diagramme, große Bildschirme und Dashboards in einem Satz generiert.

  • jeecg-codegen: Codegenerator – ein vollständiger Satz von CRUD für die Generierung natürlicher Sprache (Java + Vue3 + SQL)
  • jeecg-onlform: Online-Formulargenerator – metadatengesteuerte Erstellung von CRUD-Formularen
  • jeecg-onlreport: Online-Berichtsgenerator – SQL-gesteuerter Datenbericht
  • jeecg-desform: Designer-Formulargenerator - Unterstützt die Screenshot-Erkennung zum Generieren von Formularen JSON
  • jeecg-onlchart: Online-Diagrammgenerator – generiert automatisch Datenvisualisierungsdiagramme
  • jeecg-bpmn: BPM-Prozessgenerator – generiert automatisch einen Flowable BPMN XML-Genehmigungsprozess
JimuReport Drei Fähigkeiten
  • jimureport: Baustein-Berichtsgenerator – Berichte mehrerer Typen + Screenshot-Erkennung und -Generierung
  • jimubi-bigscreen: Großbildgenerator – 1920×1080 Vollbild-Datenvisualisierung
  • jimubi-dashboard: Dashboard-Generator – Daten-Dashboard mit 24-Spalten-Rasterlayout

JeecgBoot v3.9.2

Highlights

  • Low-code v2.0 ships as Claude Code Skills — A separate repo, jeecgboot/skills, is released alongside 3.9.2. Six JeecgBoot skills (jeecg-codegen, jeecg-onlform, jeecg-onlreport, jeecg-desform, jeecg-onlchart, jeecg-bpmn) plus three JimuReport skills (jimureport, jimubi-bigscreen, jimubi-dashboard) let you generate CRUD (Java + Vue3 + SQL), forms, reports, BPMN XML and 1920×1080 screens from natural language; jeecg-desform and jimureport even accept screenshots as input. Requires Python 3.12+ and Claude Code, with Claude / DeepSeek-v4 / MiniMax 2.7 backends. The shift that matters: Online forms and flow nodes become natively callable "business capabilities," so teams no longer hand-write Tools to expose low-code artifacts to AI.

  • Breaking: AI starter renamed and Langchain4j jumped to 1.12.2 — jeecg-boot-starter-chatgpt is now jeecg-boot-starter-ai, so any module declaring the old Maven coordinate must be updated before compiling. The Langchain4j 1.12.2 upgrade adds Agent Skills metadata auto-selection (models pick business capabilities automatically instead of blind prompt tuning) and adds deepseek-v4 compatibility (#9585). Watch model-specific API requirements when upgrading: qwen3.5-plus needs incremental_output enabled (#9446), qwen-vl-ocr needs extra config (#8 / #9359 family), and PR #9539 handles Tongyi Qianwen rejecting null message content.

  • Online becomes extensible and AI-readable — The Online frontend source is fully open-sourced, a new Online chart module adds configurable visualization panels, and a published Online form Schema spec gives AI a stable metadata contract to reason over. Data-model additions: LongText (#9366) plus link_table / link_table_field for Vue3 one-to-many related records and cross-table field references, dictionary-tree support in sub-tables (#7633), and external-link forms for anonymous fill/edit. Long-standing performance complaints are targeted directly (config lag QQYUN-14177, slow open, small-screen field positioning). For adopters this is the main reason to upgrade if you were blocked on二次开发 or on representing hierarchical/relational data in Online.

  • AiFlow graduates from chatbot to visual Agent orchestration — New variable read/write, memory read/write, loop-variable and structured-JSON-output nodes, prompt-table binding on LLM nodes, file-upload start nodes, and a search-engine node plus web search for the AI assistant. Post-publish read-only node inspection and fixed HTTP request timeout handling (#9533) make flows safer to run in production. Combined with tool/AI-app whitelisting and cross-tenant isolation, this is what turns AiFlow into a platform you can actually delegate multi-step work to, rather than a demo.

  • Security hardening makes 3.9.2 a mandatory upgrade for multi-tenant deployments — High-severity fixes cover AI poster SSRF (#9579, rejects loopback/link-local), attachment path traversal (#9519, path normalization + sandbox enforcement), AiragApp cross-tenant write (#9462), token privilege escalation via getUserSectionInfoByToken (#9518), RCE (#9335), and JDBC URL injection from an incomplete blacklist/missing datasource endpoint permission (#9468). MCP and sensitive underlying tools now require permission checks (#9483, #9464). If you expose AI endpoints to tenants, audit which ones were reachable before patching — several of these were direct cross-tenant data paths.

  • Frontend on-demand loading cuts first paint and enables in-page AI — antd (via unplugin-vue-components), unplugin-icons, Jvxetable/Vxetable, TinyMCE, JEasyCron, codemirror and the chat module are all lazy-loaded; login registration/QR/forgot-password components and AppSearch no longer hit the initial bundle. JCronValidator and custom basicForm components moved out of the global load. One caveat worth flagging to your team: after the Jvxetable conversion, internal self-references are disallowed or the page will hang — check custom tables before rollout (#9452 also addressed Online styles leaking into the host project).
