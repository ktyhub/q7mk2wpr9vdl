Druide Druide-0.8.2

Aktualisierung von 0.8.1

Wenn Sie Union Queries verwenden, stellen Sie bitte sicher, dass Sie die Brokerknoten aktualisieren, bevor Sie historische Knoten, Echtzeitknoten oder Indexierungsdienste aktualisieren. Andernfalls können Sie die Standardverfahren für fortlaufende Updates befolgen.

Neue Funktionen

– #1744 Memcached-Verbindungspooling – #1753 SegmentMetadataQuery erlauben, Kardinalitäts- und Größenberechnungen zu überspringen

  • #1609 Experimenteller kafa einfacher verbraucherbasierter Feuerwehrschlauch – #1800 Experimenteller Hybrid-L1/L2-Cache

Verbesserungen

– #1821 Cache-Zeitstempel für maximale Daten im QueryableIndexStorageAdapter – #1765 CPUTimeMetricQueryRunner zu ClientQuerySegmentWalker hinzufügen – #1776 Der Twitter-Firehose wurde geändert, um mehr Eigenschaften zu verarbeiten – #1748 Ermöglicht ForkingTaskRunner javaOpts, Argumente in Anführungszeichen zu haben, die Leerzeichen enthalten

  • #1759 Bessere, schnellere, kleinere Bitmaps – #1755 Update druid-api zur Beschleunigung der Zeitstempel-Analyse – #1756 Verbesserung der Nachrichtenübermittlung, wenn der Indexdienst nicht gefunden wird – #1739 Erlauben Sie SegmentAnalyzer, Spalten aus dem StorageAdapter zu lesen, und erlauben Sie SegmentMetadataQuery, IncrementalIndexSegments auf dem Echtzeitknoten abzufragen – #1732 Unterstützung für einen konfigurierbaren Standard-Segmentverlaufszeitraum für segmentMetadata-Abfragen und GET /datasources/<datasourceName>-Suchen hinzugefügt – #1695 Erlaubt das Schreiben von InputRowParser-Erweiterungen, die Hadoop/beliebige Bibliotheken verwenden
  • #1688 Mehr zwischengespeicherte Metriken – #1712 Dimensionsextraktionsfunktion zu SearchQuery hinzugefügt – #1696 CPU-Zeit zu den Metriken für das Segment-Scannen hinzugefügt. – #1718 Fügt der Indexerkonsole eine Aufgabendauer für abgeschlossene Aufgaben hinzu. – #1725 Prüfen Sie nicht auf Sortierung, wenn wir bereits wissen, dass GenericIndexedWriter nicht sortiert ist – #1699 Zusammenstellen des Emittermoduls zur gemeinsamen Verwendung mehrerer Emitter
  • #1639 Neuer Klempner – #1604 Zulassen, dass die Aufgabe ForkingTaskRunner-Tunings und jvm-Einstellungen überschreibt – #1542 Endpunkt hinzugefügt, um den Regelverlauf für alle Datenquellen abzurufen – #1682 Unterstützt das Parsen von BytesWritable-Strings in HadoopDruidIndexerMapper – #1622 Unterstützung für das Smile-Format JSON für EventReceiverFirehoseFactory – #1654 Möglichkeit hinzugefügt, taskResource für IndexTask bereitzustellen.

  • #1811 IPv6-freundlicher Servererkennungsselektor – #1823 Verwenden Sie für dataSource inputSpec in der Hadoop-Batchaufnahme die konfigurierte Abfragegranularität zum Lesen vorhandener Segmente anstelle von NONE
  • #1818 HashCode und Equals zu Aktiensuchen hinzufügen
  • #1812 Erhöhen Sie die Servermetriken auf 0.2.5, um einige Korrekturen vorzunehmen. – #1806 Die Indexüberschreitungsmeldung wurde korrigiert, um auch maxRowCount anzugeben
  • #1801 Korrigieren Sie ClientInfoResource
  • #1795 Versuchen Sie, AnnouncerTest etwas vorhersehbarer zu machen – #1797 Segment Firehose ut aufnehmen – #1798 Aktualisieren Sie httpcomponents und aws-sdk – #1792 GroupByQueryRunnerTest für hyperUnique finalisierende Post-Aggregatoren

druid druid-0.8.2

Updating from 0.8.1

If you are using union queries, please make sure to update broker nodes prior to updating any historical nodes, realtime nodes, or indexing service.

Otherwise, you can follow standard rolling update procedures.

New Features

  • #1744 Memcached connection pooling
  • #1753 Allow SegmentMetadataQuery to skip cardinality and size calculations
  • #1609 Experimental kafa simple consumer based firehose
  • #1800 Experimental Hybrid L1/L2 cache

Improvements

  • #1821 cache max data timestamp in QueryableIndexStorageAdapter
  • #1765 Add CPUTimeMetricQueryRunner to ClientQuerySegmentWalker
  • #1776 Modified the Twitter firehose to process more properties
  • #1748 Allow ForkingTaskRunner javaOpts to have quoted arguments which contain spaces
  • #1759 better faster smaller roaring bitmaps
  • #1755 update druid-api for timestamp parsing speedup
  • #1756 improving msging when indexing service is not found
  • #1739 Allow SegmentAnalyzer to read columns from StorageAdapter, allow SegmentMetadataQuery to query IncrementalIndexSegments on realtime node
  • #1732 Add support for a configurable default segment history period for segmentMetadata queries and GET /datasources/<datasourceName> lookups
  • #1695 Allow writing InputRowParser extensions that use hadoop/any libraries
  • #1688 More memcached metrics
  • #1712 Add dimension extraction functionality to SearchQuery
  • #1696 Add CPU time to metrics for segment scanning.
  • #1718 Adds task duration to indexer console for completed tasks.
  • #1725 Don't check for sortedness if we already know GenericIndexedWriter isn't sorted
  • #1699 composing emitter module to use multiple emitters together
  • #1639 New plumber
  • #1604 Allow task to override ForkingTaskRunner tunings and jvm settings
  • #1542 add endpoint to fetch rule history for all datasources
  • #1682 Support parsing of BytesWritable strings in HadoopDruidIndexerMapper
  • #1622 Support for JSON Smile format for EventReceiverFirehoseFactory
  • #1654 Add ability to provide taskResource for IndexTask.
