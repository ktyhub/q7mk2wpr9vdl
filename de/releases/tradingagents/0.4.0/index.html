TradingAgents v0.4.0

Zusammenfassung

Vorausschauende und punktuelle Korrekturen auf den Daten- und Speicherebenen, klarere Entscheidungssignale, funktionierender CLI-Checkpoint-Lebenslauf und die Modelle GPT-5.6 / GLM-5.3.

Point-in-Time-/Look-Ahead-Integrität

– FRED-Makro-Anfragen heften den Datenjahrgang jetzt an das Standdatum, sodass bei einem Backtest keine späteren Revisionen mehr erkannt werden (#1275).

  • Soziale Stimmung (StockTwits, Reddit) wird über eine gemeinsame UTC-Fensterregel, die von News wiederverwendet wird, auf das Analysefenster gekürzt, anstatt den heutigen Chatter anzuzeigen (#1220).
  • Entscheidungsprotokollspeicher zeichnet auf, wann jedes Ergebnis bekannt wurde, und fügt nur Lektionen ein, die bis zum Handelsdatum gelöst wurden (#1251); Eine Entscheidung wird nicht mehr getroffen, bevor ihr Haltefenster vollständig gehandelt wurde (#1169).
  • Der neueste OHLCV-Balken wird nicht mehr stillschweigend gelöscht, wenn sein Schlusskurs NaN beträgt, und die Daten sind normalisierte DST- und Nicht-US-Markt-sicher (#1201).

Ehrlichere Entscheidungssignale

  • Eine nicht analysierbare Portfoliomanager-Bewertung zeigt einen REVIEW-Sentinel anstelle eines handelbaren Haltens an (#1170).
  • Debatteneröffner fabrizieren nicht länger das Argument des Gegners, wenn keines vorgebracht wurde (#1176).
  • Der Händler erhält nun den technischen Marktbericht, sodass die Einstiegs-/Stoppniveaus an der realen Preisstruktur verankert sind (#1167).

Robustheit der Ausführung

– --checkpoint wird tatsächlich fortgesetzt auf dem CLI-Pfad und eine Wiederaufnahme dupliziert keine Nachrichten mehr (#1249). – Eine konfigurierbare Ausgabe-Token-Obergrenze (TRADINGAGENTS_MAX_TOKENS) begrenzt ein Modell, das unbegrenzte Argumentation ausgibt (#1204). – DeepSeek, das über OpenRouter (deepseek/<id>) weitergeleitet wird, verwendet jetzt die nativen DeepSeek-Funktionen wieder (#1199).

Modelle

  • Die GPT-5.6-Familie (gpt-5.6 / gpt-5.6-terra / gpt-5.6-luna) und GLM-5.3 (glm-5.3, glm-5.3-flash) hinzugefügt; Die Standardeinstellungen sind jetzt gpt-5.6 (tief) / gpt-5.6-luna (schnell).

Die vollständige Liste, einschließlich der Danksagungen der Mitwirkenden, finden Sie unter CHANGELOG.md.

Englisches Original / English original

TradingAgents v0.4.0

Highlights

  • Point-in-time data integrity (backtest correctness) — FRED macro series now pin to the as-of vintage (#1275) and social sentiment (StockTwits/Reddit) is clipped to the analysis window via a single UTC window rule shared with news (#1220), closing two look-ahead leaks that could have inflated historical performance. Decision-log memory now timestamps when each outcome became known and only injects lessons resolved by the trade date (#1251), and a decision isn't settled until its full holding window has traded (#1169). Re-run backtests and expect metrics to move — usually down — as the bias disappears; also drop any date/NaN workarounds you added, since the latest OHLCV bar is preserved when close is NaN and dates are DST- and non-US-market-safe (#1201).
  • More honest decision signals (downstream contract watch) — An unparseable Portfolio Manager rating now emits a REVIEW sentinel instead of a tradeable Hold (#1170), so any consumer that treats ratings as actionable must handle REVIEW explicitly or risk trading on a non-signal. Debate openers no longer fabricate the opponent's argument when none exists (#1176), and the Trader now receives the technical market report so entries and stops anchor to real price structure (#1167) — better grounding, but expect different levels than before.
  • Execution robustness and cost control — --checkpoint now genuinely resumes on the CLI path and no longer duplicates messages (#1249), making long or interrupted runs practically resumable for the first time. Set TRADINGAGENTS_MAX_TOKENS (#1204) in CI or cost-sensitive deployments to bound models that emit unbounded reasoning and prevent runaway spend. DeepSeek routed through OpenRouter (deepseek/<id>) now reuses native DeepSeek capabilities (#1199), so that path's behavior converges with direct DeepSeek use.
  • Model lineup and new defaults — GPT-5.6 (gpt-5.6 / gpt-5.6-terra / gpt-5.6-luna) and GLM-5.3 (glm-5.3 / glm-5.3-flash) are added, with defaults moved to gpt-5.6 (deep) and gpt-5.6-luna (quick). Pin model IDs explicitly if you need reproducible outputs or to preserve existing cost/quality profiles; otherwise budget for changed results and pricing on upgrade.

No breaking changes were formally declared for v0.4.0.

Summary

Look-ahead and point-in-time fixes across the data and memory layers, clearer decision signals, working CLI checkpoint resume, and the GPT-5.6 / GLM-5.3 models.

Point-in-time / look-ahead integrity

  • FRED macro requests now pin the data vintage to the as-of date, so a backtest no longer sees later revisions (#1275).
  • Social sentiment (StockTwits, Reddit) is trimmed to the analysis window instead of showing today's chatter, via one shared UTC window rule reused by news (#1220).
  • Decision-log memory records when each outcome became known and only injects lessons resolved by the trade date (#1251); a decision is no longer settled before its holding window fully trades (#1169).
  • The latest OHLCV bar is no longer silently dropped when its close is NaN, and dates are normalized DST- and non-US-market safe (#1201).

More honest decision signals

  • An unparseable Portfolio Manager rating surfaces a REVIEW sentinel instead of a tradeable Hold (#1170).
  • Debate openers no longer fabricate the opponent's argument when none has been made (#1176).
  • The Trader now receives the technical market report, so entry/stop levels anchor to real price structure (#1167).

Execution robustness

  • --checkpoint actually resumes on the CLI path, and a resume no longer duplicates messages (#1249).
  • A configurable output-token cap (TRADINGAGENTS_MAX_TOKENS) bounds a model that emits unbounded reasoning (#1204).
  • DeepSeek routed through OpenRouter (deepseek/<id>) now reuses the native DeepSeek capabilities (#1199).

Models

  • Added the GPT-5.6 family (gpt-5.6 / gpt-5.6-terra / gpt-5.6-luna) and GLM-5.3 (glm-5.3, glm-5.3-flash); the defaults are now gpt-5.6 (deep) / gpt-5.6-luna (quick).

See CHANGELOG.md for the full list, including contributor acknowledgments.
