nacos 3.2.0

Nacos 3.2.0 ist eine Hauptversion, die sich auf die Verbesserung der Plugin-Architektur, die Erweiterung der KI-Registrierung, die Modernisierung von API und Verbesserungen der Codequalität konzentriert. Zu den wichtigsten Highlights gehören:

  • AI Registry vervollständigt die „KI-Triade“: Skill Registry und Prompt Registry schließen sich dem bestehenden MCP/Agent Registry an, mit Nacos Copilot-Integration für KI-gestütztes Management
  • Modernisierung der Plugin-Architektur: Umfassende SPI-basierte Plugin-Verwaltung mit Konsolen-UI, Cluster-weiter Synchronisierung und PostgreSQL-Verbesserungen
  • API-Bereinigung: Legacy-UDP-PUSH-Unterstützung entfernt, /v1- und /v2-HTTP-APIs zur späteren Entfernung in Submodule extrahiert
  • Sicherheit und Codequalität: OIDC/OAuth2-Authentifizierungs-Plugin, mehrere FindBugs-Korrekturen, Entfernung von totem Code und JDK 17+-Kompatibilitätsverbesserungen
  • Konsolenmodernisierung: Duale UI-Unterstützung für den Wechsel zwischen neuen und älteren Konsolen mit verbesserter Benutzererfahrung

⚠️ Aktuelle Änderungen und Migrationshinweise

Änderungen am Datenbankschema (wichtig)

Aktion erforderlich: Diese Version führt erhebliche Änderungen am Datenbankschema ein und umfasst mehrere neue Tabellen für die Plugin-Verwaltung, AI Registry (Skill/Prompt) und erweiterte Prüffunktionen. Vor dem Upgrade müssen Sie das neue Schema anwenden:

  1. Sichern Sie Ihre vorhandene Datenbank
  2. Wenden Sie das Schema-Upgrade-Skript conf/schema.sql (für MySQL) oder das entsprechende Skript für Ihren Datenbanktyp an
  3. Starten Sie den Nacos-Server nach der Schemamigration neu Wenn die Schemaänderungen nicht angewendet werden, kann dies dazu führen, dass die Plugin-Verwaltung, AI Registry und andere neue Funktionen nicht ordnungsgemäß funktionieren.

API Legacy-Adapter-Plugin

Das api-legacy-adapter-Plugin und die alten /v1- und /v2-HTTP-APIs wurden aus dieser Version entfernt, um den Platzbedarf zu verringern. Wenn Ihre Bereitstellung immer noch von den älteren /v1- oder /v2-APIs abhängt, können Sie das Kompatibilitäts-Plugin manuell einführen über: https://github.com/nacos-group/nacos-api-legacy-adapter Bitte laden Sie das Plugin herunter und platzieren Sie es in Ihrem plugins-Verzeichnis, um die Kompatibilität mit der alten API wiederherzustellen.

Benennungsmodul: UDP PUSH-Unterstützung entfernt

Das Benennungsmodul hat die alte UDP PUSH-Unterstützung entfernt und ist auf eine sauberere HTTP-API-Architektur umgestiegen. Clients, die auf UDP-basierte Diensterkennungsaktualisierungen angewiesen sind, müssen auf HTTP-basierte Mechanismen migrieren.

📚 Was ist neu in AI Registry?

Skill-Registrierung

  • Zentralisierte Verwaltung: Fertigkeiten über die Benutzeroberfläche oder API mit changelogs erstellen, aktualisieren und versionieren
  • Skill-Zusammensetzung: Verketten Sie mehrere MCP-Tools zu geschäftsrelevanten Funktionen (z. B. „user_onboarding“ = verify_email + create_profile + send_welcome_email)
  • MCP-Integration: Skills deklarieren explizit Abhängigkeiten von registrierten MCP-Tools mit Integritätsvalidierung
  • Ordnerbasierte Organisation: Fähigkeiten werden zur besseren Organisation in einer mehrstufigen Ordnerstruktur angezeigt
  • Agentenfreundliche APIs: REST/gRPC APIs für Agenten-Frameworks (LangChain, CrewAI usw.) zum Entdecken und Abonnieren von Fähigkeiten
  • Upload-Unterstützung: Laden Sie Skill-Pakete (ZIP-Format, max. 10 MB) mit Authentifizierung hoch
  • Sicherheitsscannen: Integrierter Skill-Scanner zur Sicherheitsvalidierung von KI-Skills
  • Zugriff auf Datenebene: Detaillierte Sichtbarkeit und Zugriffskontrolle (Phase 2 und 3)

Prompt-Registrierung

  • Erstklassige Konfiguration: Speichern Sie Eingabeaufforderungen mit Metadaten (Agent-ID, Modell-ID, Version, Tags) als versionierte Konfigurationsartefakte
  • Multi-Versions-Management: Unterstützt paralleles Multi-Versions-Management mit Vorlagen- und Commit-Nachrichtenverfolgung
  • Tag-basiertes Abonnement: Abonnieren Sie Eingabeaufforderungen nach Tags für dynamische Updates
  • Interaktives Debugging: Testen und vergleichen Sie Eingabeaufforderungsausgaben verschiedener Versionen direkt in der Konsole
  • AI Client Proxy: Einheitliche HTTP/gRPC client-Schnittstelle für sofortige Vorgänge

Nacos-Copilot

  • KI-gestützter Assistent: Integrierter KI-Assistent zur Optimierung und Erstellung von Eingabeaufforderungen und Fertigkeiten
  • Intelligente Erkennung: Finden Sie automatisch relevante vorhandene Fähigkeiten aus der Registrierung
  • Konsolenintegration: Direkter Zugriff über die Nacos-Konsole für einen nahtlosen Workflow

⚠️ Breaking Changes & Migration Notes

Database Schema Changes (Important)

Action Required: This release introduces significant database schema changes with multiple new tables added for plugin management, AI Registry (Skill/Prompt), and enhanced audit capabilities.

Before upgrading, you must apply the new schema:

  1. Backup your existing database
  2. Apply the schema upgrade script: conf/schema.sql (for MySQL) or corresponding script for your database type
  3. Restart Nacos server after schema migration

Failure to apply the schema changes may result in plugin management, AI Registry, and other new features not functioning correctly.

API Legacy Adapter Plugin

The api-legacy-adapter plugin and the legacy /v1 and /v2 HTTP APIs have been removed from this release to reduce footprint.

If your deployment still depends on the legacy /v1 or /v2 APIs, you can manually introduce the compatibility plugin from:

https://github.com/nacos-group/nacos-api-legacy-adapter

Please download and place the plugin into your plugins directory to restore legacy API compatibility.

Naming Module: UDP PUSH Support Removed

The naming module has removed legacy UDP PUSH support, moving to a cleaner HTTP API architecture. Clients relying on UDP-based service discovery updates must migrate to HTTP-based mechanisms.

📚 What's New in AI Registry

Skill Registry

  • Centralized Management: Create, update, and version skills via UI or API with changelogs
  • Skill Composition: Chain multiple MCP tools into business-meaningful capabilities (e.g., "user_onboarding" = verify_email + create_profile + send_welcome_email)
  • MCP Integration: Skills explicitly declare dependencies on registered MCP tools with integrity validation
  • Folder-based Organization: Skills displayed in multi-level folder structure for better organization
  • Agent-Friendly APIs: REST/gRPC APIs for agent frameworks (LangChain, CrewAI, etc.) to discover and subscribe to skills
  • Upload Support: Upload skill packages (zip format, max 10MB) with authentication
  • Security Scanning: Integrated skill-scanner for AI Skill security validation
  • Data Level Access: Fine-grained visibility and access control (Phase 2 & 3)

Prompt Registry

  • First-Class Configuration: Store prompts with metadata (agentId, modelId, version, tags) as versioned config artifacts
  • Multi-Version Management: Support parallel multi-version management with template and commit message tracking
  • Tag-Based Subscription: Subscribe to prompts by tags for dynamic updates
  • Interactive Debugging: Test and compare prompt outputs across versions directly in console
  • AI Client Proxy: Unified HTTP/gRPC client interface for prompt operations

Nacos Copilot

  • AI-Powered Assistant: Integrated AI assistant to help optimize and create Prompts and Skills
  • Intelligent Discovery: Automatically find relevant existing skills from the registry
  • Console Integration: Accessible directly from Nacos console for seamless workflow
