nacos 1.4.1

Patch Veröffentlicht14. Jan. 2021 Quellealibaba/nacos Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

nacos 1.4.1

Diese Version unterstützt hauptsächlich das IPv6-Dienstregister und UDP-Push für Csharp client. Darüber hinaus können Sie einige Konsolenfunktionen hinzufügen, um die Nutzung durch die Benutzer zu verbessern. Und viele Fehler beheben und viele Umgestaltungen und Verbesserungen vornehmen, um die Stabilität zu erhöhen. Details siehe unten:

Funktionen

-[#978] Unterstützt IPv6. -[#3917] Metadatenfilter auf der Service-Detailseite hinzufügen. -[#4132] Dienstliste API Parameter Gruppenname unterstützt „*“, um alle Gruppendienstnamen abzurufen. -[#4670] Unterstützt Udp-Push für CSharp client.

Verbesserung

-[#3607][#4078][#4170] Die Konfiguration des Datenquellenpools kann konfiguriert werden. -[#3832] Wenn der Nacos-Server nicht startet, fahren Sie alle http clients herunter. -[#3907] Wenn bei „publishConfig“ der Typ fehlt, legen Sie den Standardwert „text“ fest. -[#4066] Stellen Sie sicher, dass serviceNameList die Reihenfolge der Zeichenfolgen einhält. -[#4090] Änderungen an der Konfigurationsdatei werden nicht wirksam. -[#4286] Wenn die Authentifizierung geöffnet ist, verwenden Sie den Ressourcen-Parser-Cache, um die Ressource zu analysieren. -[#4291] Im Standalone-Modus aktiviert das Servicemodul das Raft-Protokoll nicht. -[#4355] Versuchen Sie die Synchronisierung der Distribution nicht noch einmal, wenn das Mitglied entfernt wurde. -[#4463] Authentifizierungsprüfung für SQL-Abfrage der Config-Derby-Datenbank hinzugefügt. -[#4513] Überprüfen Sie vor der Registrierung den ungültigen Heartbeat-Parameter der Instanz. -[#4593] Serveridentität hinzufügen, um die Whitelist für Benutzeragenten zu ersetzen. -[#4662] Wählen Sie einfach einen zwischen dem NacosDomain-Modus und dem Servermodus.

Refaktorierung und Codequalität

-[#3831] Löschen Sie den alten http-client-Code. -[#3832] Gemeinsame http-client-Abschaltmethode hinzufügen. -[#4093][#4125][#4310][#4346] Nicht verwendete Codes entfernen. -[#4166] NotifyCenter-Codeoptimierung. -[#4225] Ersetzen Sie http client in HttpHealthCheckProcessor. -[#4232] Verwenden Sie EnvUtil, um ApplicationUtils für den Env-Betrieb zu ersetzen. -[#4293] Env-Operationscode in ApplicationUtils entfernen. -[#4275] Ersetzen Sie com.alibaba.nacos.config.server.result.ResultBuilder durch RestResultUtil. -[#4344] Optimierung der CacheMap-Eigenschaft. -[#4567] nacos-client Load Logging-Konfigurationscode umgestalten. -[#4594][#4596] E/A-Schließproblem Art/Codequalität Art/Refactor behoben -[#4631] Timer entfernen, ScheduledThreadPoolExecutor verwenden ersetzt.

BugFix

-[#3005] ClusterController 403 behoben und einige Anzeigen falsch angezeigt. -[#3406] Problem mit fehlgeschlagener Passwortänderung behoben. -[#3524][#4262] Problem mit der Berechtigung für den öffentlichen Namespace behoben. -[#3880] NamingService Client unterstützt pushEmptyProtection. -[#4073] Beheben Sie das Problem, dass die Standardzeitzone der Konfiguration möglicherweise falsch ist. -[#4136] Fix ServiceInfo kann nicht korrekt aus der Cache-Datei instanziiert werden. -[#4181] Fix Auth funktioniert möglicherweise nicht, wenn contextPath „/“ ist. -[#4187] Fix: ProtocolManager#onEvent spürt nicht, wie sich Knoten ausdehnen. -[#4199] Behebung des neuen Problems mit der Patch-Methode „http client unterstützt nicht“. -[#4236] ProtocolException für Apache http client Content-Length behoben. -[#4245] SQL-Injection-Fehler behoben. -[#4264] Fix: Eigenschaft immer laden, wenn contextPath „/“ ist. -[#4282] Serviceliste behoben. Abfrage nach Gruppenname nicht möglich. -[#4311] Behebung einer Ausnahme, die auftritt, wenn die SQL LIMIT enthält, wenn eine eingebettete Datenquelle verwendet wird. -[#4320] Behebung des Problems, dass das Naming-Konsistenz-Modul nicht im Cluster-Modus gestartet werden konnte. -[#4333] Behebung, dass PaginationHelper im Cluster-Modus abnormal ist. -[#4342] Fix nacos.core.protocol.raft.data.read_index_type hat keine Auswirkung. –[#4364] Fix Der Cluster-Mitgliedsstatus wird nicht auf „DOWN“ aktualisiert, nachdem der Knoten ausgefallen ist. -[#4415] Fehler bei der WatchDirJob-Zählung des NOW_WATCH_JOB_CNT-Datensatzes behoben. -[#4424] Problem behoben, bei dem Nullwerte nicht in Basisparameter konvertiert werden konnten. -[#4429] Fix mcp kann nicht geöffnet werden. -[#4436] Fehler beim Parsen des Label-Ausdrucks behoben. -[#4450] Fix: memberAddressInfos zeichnen den Up-Status nicht auf, wenn der Mitgliedsstatus aktualisiert wird. -[#4467] Fix: Instanz-ID wird bei zweimaliger Registrierung ersetzt. -[#4477] Fehlerinformationen zur Rückgabe der Dienstliste behoben, wenn fromIndex > toIndex. -[#4541][#4556] Behebung des Problems beim Laden der Konfigurationsdatei. -[#4570] Der Konfigurationstyp der Cluster-Modus-Abfrage wurde behoben, der null ist. -[#4583] Behebung, dass nacos client im DOMAIN-Modus keinen erneuten Versuch durchführt. -[#4643] Jraft-Antwortinstanzfehler behoben. -[#4701] Problem mit der Umgehungsauthentifizierung (Identität) behoben.

Andere

-[#3102] Apache commons-lang3-Abhängigkeit entfernen. -[#4179] Index für db.user und db.password hinzufügen. -[#4339] Aktualisieren Sie jraft auf 1.3.5. -[#4476] Hinweiswörter in der Konfigurationsliste aktualisieren Fuzzy-Abfrage. -[#4632] Axios-Version auf 0.21.1 aktualisieren.

Englisches Original / English original

nacos 1.4.1

This version mainly support IPv6 service register and support udp push for Csharp client. What's more, add some console features to enhance users' usage. And Fix many bugs and do many refactor and enhancement to increase stability.

Details see following:

Features

-[#978] Support IPv6. -[#3917] Add metadata filter in service detail page. -[#4132] Service list API param groupName support '*' to get all group serviceName. -[#4670] Support Udp push for CSharp client.

Enhancement

-[#3607][#4078][#4170] Datasource pool configuration can be configured. -[#3832] When the nacos-server fails to start, shutdown all http clients. -[#3907] When publishConfig, if type is absent, set default value 'text'. -[#4066] Make serviceNameList followed string order. -[#4090] Configuration file changes do not take effect. -[#4286] When auth open, use resource parser cache to parse resource. -[#4291] In stand-alone mode, the service module does not enable the Raft protocol. -[#4355] Do not retry distro sync again if member has removed. -[#4463] Add auth check for SQL query of config derby database. -[#4513] Check instance illegal heart beat param before register. -[#4593] Add server identity to replace user-agent white list. -[#4662] Just choose one between nacosDomain mode and servers mode.

Refactor & Code Quality

-[#3831] Delete the old http client code. -[#3832] Add common http client shutdown method. -[#4093][#4125][#4310][#4346] Remove unused codes. -[#4166] NotifyCenter code optimization. -[#4225] Replace http client in HttpHealthCheckProcessor. -[#4232] Use EnvUtil to replace ApplicationUtils about env operation. -[#4293] Remove env operation code in ApplicationUtils. -[#4275] Replace com.alibaba.nacos.config.server.result.ResultBuilder to RestResultUtil. -[#4344] CacheMap property optimization. -[#4567] Refactor nacos-client Load Logging Configuration code. -[#4594][#4596] Fix IO close problem kind/code quality kind/refactor -[#4631] Remove timer,Use ScheduledThreadPoolExecutor replaced.

BugFix

-[#3005] Fix ClusterController 403 and some display wrong. -[#3406] Fix change self's password fail problem. -[#3524][#4262] Fix public namespace permission problem. -[#3880] NamingService Client support pushEmptyProtection. -[#4073] Fix the problem for config default time zone may be wrong. -[#4136] Fix ServiceInfo cann't correctlly instantiate from cache file. -[#4181] Fix Auth may not work if contextPath is '/'. -[#4187] Fix ProtocolManager#onEvent can't feel nodes extend. -[#4199] Fix new http client do not support patch method problem. -[#4236] Fix ProtocolException for apache http client Content-Length. -[#4245] Fix sql injection bug. -[#4264] Fix always load property when the contextPath is '/'. -[#4282] Fix Service list Cannot query by group name. -[#4311] Fix an exception will occur if the SQL include LIMIT, when use embedded data source. -[#4320] Fix the Naming consistency module could not start in cluster mode. -[#4333] Fix PaginationHelper will be abnormal in cluster mode. -[#4342] Fix nacos.core.protocol.raft.data.read_index_type isn't effect. -[#4364] Fix Cluster member state isn't updated to 'DOWN' after the node becomes down. -[#4415] Fix NOW_WATCH_JOB_CNT record WatchDirJob count error. -[#4424] Fixed issue where null values could not be converted to base parameters. -[#4429] Fix mcp can't be open. -[#4436] Fix parse label expression error problem. -[#4450] Fix memberAddressInfos do not record Up State when member status updated. -[#4467] Fix instanceId will be replaced when register twice. -[#4477] Fix service list return error information if fromIndex > toIndex. -[#4541][#4556] Fix the configuration file loading issue. -[#4570] Fix cluster mode query config type is null. -[#4583] Fix nacos client do not retry in DOMAIN mode. -[#4643] Fix jraft response instance error. -[#4701] Fix bypass authentication(identity) problem.

Other

-[#3102] Remove apache commons-lang3 dependency. -[#4179] Add index for db.user and db.password. -[#4339] Upgrade jraft to 1.3.5. -[#4476] Update hint words in config list Fuzzy query. -[#4632] Upgrade axios version to 0.21.1.
