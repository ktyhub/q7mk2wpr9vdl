nacos 2.2.0

Diese Version ist eine wichtige Version, die einige große Änderungen enthält. Die erste wichtige Änderung besteht darin, die alten redundanten Codes zur 1.x-Benennung zu entfernen und relative Codes doppelt zu schreiben. Nach der Änderung kann die 2.2.0-Version nicht vom Nacos 1.X-Server aktualisiert werden, sondern nur von mindestens der Version 2.0.0. Die Änderungen wirken sich nicht auf die Anforderung zur Anpassung für 1.X client aus. Benutzer können weiterhin 1.X client mit der 2.2.0-Version verwenden. Die zweite wichtige Änderung ist das Hinzufügen mehrerer Plugins: – Datenquellen-Plugin, das vom Asoc 2022-Projekt hinzugefügt wurde, um andere Datenbanken zu unterstützen.

  • Benutzerdefiniertes Umgebungs-Plugin, das von der Community hinzugefügt wurde, um Konfigurationen des Nacos-Servers zu verwalten, z. B. das Entschlüsseln des Datenbankkennworts.
  • Verbindungslimit-Plugin, das vom alten Limit-Modul umgestaltet wurde, um mehr Fähigkeiten zum Schutz des Nacos-Servers unter hohem Druck zu bieten. Die dritte wichtige Änderung besteht darin, die Beta-Funktionen Tracing plugin und batch register zu verbessern, wodurch sie benutzerfreundlicher werden. Detail siehe:

Englisches Original / English original

nacos 2.2.0

This version is an important version which include some large changes.

The first important change is remove the old redundant codes about 1.x naming and double write relative codes. After changed, The 2.2.0 version will can't upgraded from Nacos 1.X server, only can upgraded from at least version 2.0.0. The changes will not effect the adapt for 1.X client request, users can still use 1.X client with 2.2.0 version.

The second important change is adding several plugins:

  • datasource plugin, which added by Asoc 2022 project to support other DBs.
  • custom environment plugin, which added by community to handle configurations of Nacos server, such as decrypt database password.
  • connection limit plugin, which refactored from old limit module, to extend more abilities to protect Nacos server under high pressure.

The third important change is to enhance the beta feature Tracing plugin and batch register, which make them more easy to use.

Detail see:
