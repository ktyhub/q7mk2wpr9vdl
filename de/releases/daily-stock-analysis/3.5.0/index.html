daily_stock_analysis v3.5.0

Minor Veröffentlicht12. März 2026 QuelleZhuLinsen/daily_stock_analysis Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

daily_stock_analysis v3.5.0

Hinzugefügt

  • 📊 Vollständige Berichtsschublade der Web-Benutzeroberfläche (Behebung Nr. 214) – Die Verlaufsseite fügt die Schaltfläche „Vollständiger Bericht“ hinzu, um den vollständigen Markdown-Analysebericht in einer seitlichen Schublade anzuzeigen. neuer GET /api/v1/history/{record_id}/markdown-Endpunkt
  • 📊 LLM-Kostenverfolgung – alle LLM-Anrufe (Analyse, Agent, Marktüberprüfung) werden in der Tabelle llm_usage aufgezeichnet; Der neue GET /api/v1/usage/summary?period=today|month|all-Endpunkt gibt die aggregierte Token-Nutzung nach Anruftyp und -modell zurück
  • 🔍 SearXNG-Suchanbieter (Fixes #550) – Quotenfreier Fallback für die selbst gehostete Suche; Priorität: Bocha > Tavily > Brave > SerpAPI > MiniMax > SearXNG
  • 🔍 MiniMax-Websuchanbieter – MiniMaxSearchProvider mit Leistungsschalter (3 Fehler → 300 Sekunden Abklingzeit) und doppelter Zeitfilterung; konfiguriert über MINIMAX_API_KEYS
  • 🤖 Agent-Modellerkennung API – GET /api/v1/agent/models gibt verfügbare Modellbereitstellungen (primär/Fallback/Quelle/api_base) für die Web-UI-Modellauswahl zurück
  • 🤖 Agenten-Chat exportieren und senden (#495) – Konversation in .md-Datei exportieren; an konfigurierte Benachrichtigungskanäle senden; neue POST /api/v1/agent/chat/send
  • 🤖 Agent-Hintergrundausführung (#495) – Analyse wird beim Seitenwechsel fortgesetzt; Badge-Benachrichtigung bei Abschluss; Automatischer Abbruch des laufenden Streams beim Sitzungswechsel
  • 📝 Report Engine P0 – Pydantic-Schemavalidierung für LLM JSON; Jinja2-Vorlagen (Markdown/Wechat/Brief) mit Legacy-Fallback; Inhaltsintegritätsprüfungen mit Wiederholung; Kurzzeitmodus (REPORT_TYPE=brief); Verlaufssignalvergleich
  • 📦 Intelligenter Import – Multi-Quellen-Import aus Bild/CSV/Excel/clipboard; Vision LLM extrahiert Code+Name+Konfidenz; Name→Code-Resolver (lokale Karte + Pinyin + AkShare); Vertrauensbasierte Bestätigung
  • ⚙️ GitHub Actions LiteLLM config – Workflow unterstützt LITELLM_CONFIG/LITELLM_CONFIG_YAML für eine flexible KI-Anbieterkonfiguration
  • ⚙️ Config Engine Refactor & System API (#602) – einheitliche Konfigurationsregistrierung, Validierung und API-Offenlegung
  • 📖 LLM-Konfigurationsanleitung – neues docs/LLM_CONFIG_GUIDE.md mit dreistufiger Konfiguration, Schnellstart, Vision/Agent/Fehlerbehebung

Behoben

  • 🐛 analyze_trend meldet immer „Keine historischen Daten“ (#600) – ruft jetzt von DB/DataFetcher statt vom defekten get_analysis_context ab
  • 🐛 Chip-Struktur-Fallback, wenn LLM es weglässt (#589) – füllt sich automatisch aus den Chip-Daten der Datenquelle für eine konsistente Anzeige über alle Modelle hinweg
  • 🐛 Verlaufs-Sniper-Punkte zeigen Rohtext an (#452) – priorisiert Originalzeichenfolgen gegenüber komprimierten numerischen Werten
  • 🐛 GitHub-Aktionen ENABLE_CHIP_DISTRIBUTION konfigurierbar (#617) – nicht mehr fest codiert, unterstützt das Überschreiben von Variablen/Geheimnissen
  • 🐛 Beim Speichern mit .env bleiben Kommentare und Leerzeilen erhalten – Webeinstellungen zerstören die .env-Formatierung nicht mehr
  • 🐛 Korrekturen für die Erkennung von Agentenmodellen – Legacy-Modus umfasst LiteLLM-native Anbieter; Quellenerkennung im Einklang mit der Laufzeit; Fallback-Bereitstellungen werden nicht mehr pro Schlüssel erweitert
  • 🐛 Stooq US-Aktien-Semantik des vorherigen Schlusskurses – missbraucht den Eröffnungspreis nicht mehr als vorherigen Schlusskurs
  • 🐛 Aktiennamen-Prefetch-Regression – priorisiert lokale STOCK_NAME_MAP vor Remote-Abfragen
  • 🐛 Berechnung des AkShare-Limits nach oben/unten (#555) – feste Marktanalysestatistiken
  • 🐛 AkShare Tencent-Quellfeldindex und ETF-Kurszuordnung (#579)
  • 🐛 Pytdx-Aktiennamen-Cache-Paginierung (#573) – verhindert Cache-Überlauf
  • 🐛 PushPlus übergroße Berichts-Chunking (#489) – segmentiert lange Inhalte automatisch
  • 🐛 Agent-Chat abbrechen und wechseln (#495) – Abbrechen wird nicht mehr fälschlicherweise als Fehler gemeldet; Der schnelle Wechsel überschreibt den Stream-Status nicht mehr
  • 🐛 MiniMax-Suchstatus im Befehl /status (#587)
  • 🐛 config_registry duplikat BOCHA_API_KEYS – doppelter Dict-Eintrag entfernt, der die Konfiguration stillschweigend überschrieb

Geändert

  • 🔎 Beobachtbarkeit von Fetcher-Fehlern – protokolliert den Start/Erfolg/Fehler des Datensatzes mit verstrichener Zeit und Failover-Übergängen; Efinance/Akshare umfasst Upstream-Endpunkt- und klassifizierte Fehlerkategorien
  • ♻️ Belastbarkeit und Bereinigung von Datenquellen (#602) – Optimierung der Fallback-Kette
  • ♻️ Bildextrakt API-Antworterweiterung – neues items-Feld (Code/Name/Konfidenz); codes wird aus Gründen der Abwärtskompatibilität beibehalten
  • ♻️ Parse-Fehlermeldungen importieren – spezifische Fehlergründe für Excel/CSV; Verbesserte Protokollierung mit Dateityp und -größe

Dokumente

  • 📖 LLM-Konfigurationsanleitung aus Gründen der Übersichtlichkeit überarbeitet (#583)
  • 📖 image-extract-prompt.md mit vollständiger Prompt-Dokumentation
  • 📖 AkShare-Fallback-Cache-TTL-Dokumentation

Englisches Original / English original

daily_stock_analysis v3.5.0

Added

  • 📊 Web UI full report drawer (Fixes #214) — history page adds "Full Report" button to display the complete Markdown analysis report in a side drawer; new GET /api/v1/history/{record_id}/markdown endpoint
  • 📊 LLM cost tracking — all LLM calls (analysis, agent, market review) recorded in llm_usage table; new GET /api/v1/usage/summary?period=today|month|all endpoint returns aggregated token usage by call type and model
  • 🔍 SearXNG search provider (Fixes #550) — quota-free self-hosted search fallback; priority: Bocha > Tavily > Brave > SerpAPI > MiniMax > SearXNG
  • 🔍 MiniMax web search provider — MiniMaxSearchProvider with circuit breaker (3 failures → 300s cooldown) and dual time-filtering; configured via MINIMAX_API_KEYS
  • 🤖 Agent models discovery API — GET /api/v1/agent/models returns available model deployments (primary/fallback/source/api_base) for Web UI model selector
  • 🤖 Agent chat export & send (#495) — export conversation to .md file; send to configured notification channels; new POST /api/v1/agent/chat/send
  • 🤖 Agent background execution (#495) — analysis continues when switching pages; badge notification on completion; auto-cancel in-progress stream on session switch
  • 📝 Report Engine P0 — Pydantic schema validation for LLM JSON; Jinja2 templates (markdown/wechat/brief) with legacy fallback; content integrity checks with retry; brief mode (REPORT_TYPE=brief); history signal comparison
  • 📦 Smart import — multi-source import from image/CSV/Excel/clipboard; Vision LLM extracts code+name+confidence; name→code resolver (local map + pinyin + AkShare); confidence-tiered confirmation
  • ⚙️ GitHub Actions LiteLLM config — workflow supports LITELLM_CONFIG/LITELLM_CONFIG_YAML for flexible AI provider configuration
  • ⚙️ Config engine refactor & system API (#602) — unified config registry, validation and API exposure
  • 📖 LLM configuration guide — new docs/LLM_CONFIG_GUIDE.md covering 3-tier config, quick start, Vision/Agent/troubleshooting

Fixed

  • 🐛 analyze_trend always reports No historical data (#600) — now fetches from DB/DataFetcher instead of broken get_analysis_context
  • 🐛 Chip structure fallback when LLM omits it (#589) — auto-fills from data source chip data for consistent display across models
  • 🐛 History sniper points show raw text (#452) — prioritizes original strings over compressed numeric values
  • 🐛 GitHub Actions ENABLE_CHIP_DISTRIBUTION configurable (#617) — no longer hardcoded, supports vars/secrets override
  • 🐛 .env save preserves comments and blank lines — Web settings no longer destroys .env formatting
  • 🐛 Agent model discovery fixes — legacy mode includes LiteLLM-native providers; source detection aligned with runtime; fallback deployments no longer expanded per-key
  • 🐛 Stooq US stock previous close semantics — no longer misuses open price as previous close
  • 🐛 Stock name prefetch regression — prioritizes local STOCK_NAME_MAP before remote queries
  • 🐛 AkShare limit-up/down calculation (#555) — fixed market analysis statistics
  • 🐛 AkShare Tencent source field index & ETF quote mapping (#579)
  • 🐛 Pytdx stock name cache pagination (#573) — prevents cache overflow
  • 🐛 PushPlus oversized report chunking (#489) — auto-segments long content
  • 🐛 Agent chat cancel & switch (#495) — cancel no longer misreports as failure; fast switch no longer overwrites stream state
  • 🐛 MiniMax search status in /status command (#587)
  • 🐛 config_registry duplicate BOCHA_API_KEYS — removed duplicate dict entry that silently overwrote config

Changed

  • 🔎 Fetcher failure observability — logs record start/success/failure with elapsed time, failover transitions; Efinance/Akshare include upstream endpoint and classified failure categories
  • ♻️ Data source resilience & cleanup (#602) — fallback chain optimization
  • ♻️ Image extract API response extension — new items field (code/name/confidence); codes preserved for backward compatibility
  • ♻️ Import parse error messages — specific failure reasons for Excel/CSV; improved logging with file type and size

Docs

  • 📖 LLM config guide refactored for clarity (#583)
  • 📖 image-extract-prompt.md with full prompt documentation
  • 📖 AkShare fallback cache TTL documentation
