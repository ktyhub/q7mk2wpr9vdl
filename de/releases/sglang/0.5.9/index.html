sglang v0.5.9

Patch Veröffentlicht24. Feb. 2026 Quellesgl-project/sglang Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

umgangssprachlich v0.5.9

Highlights

  • Überschneidung der LoRA-Gewichtsbelastung mit der Berechnung: Überlappung der LoRA-Gewichtsbelastung mit der Berechnung während der Inferenz, wodurch TTFT um ~78 % und TPOT um ~34.88 % bei großen Adaptern reduziert werden: #15512
  • TRT-LLM NSA-Kernel-Integration für DeepSeek V3.2: Integrieren Sie TRT-LLM-DSA-Kernel für Native Sparse Attention und steigern Sie die Leistung von DeepSeek V3.2 auf Blackwell-Plattformen um das Drei- bis Fünffache mit trtllm sowohl für --nsa-prefill-backend als auch --nsa-decode-backend (mit geringfügigem Genauigkeitsabfall): #16758, #17662, #18389
  • Flashinfer All-to-All MoE Dispatcher: Fügen Sie den Flashinfer All-to-All MoE-Dispatcher für effiziente Experten-Parallelitätskommunikation hinzu und ermöglichen Sie optimiertes Routing in MoE-Modellen: #14668
  • FA4 (FP4 Attention)-Unterstützung für multimodale Encoder: Einführung des FP4-Attention-Backends und der Attention-Funktion variabler Länge für multimodale Encoder, die eine Inferenz mit geringerer Genauigkeit für Vision-Language-Modelle ermöglichen: #13539
  • Anthropic-kompatibler API-Endpunkt: Fügen Sie SGLang native Anthropic API-Kompatibilität hinzu, was eine direkte Integration mit Tools und clients ermöglicht, die für das Anthropic API-Format erstellt wurden: #18630
  • Erweiterte SGLang-Diffusion-Optimierungen: Produktionsreife Verbesserungen, einschließlich Sequenz-Sharding auf Token-Ebene, parallele VAE-Dekodierung, verschmolzene Kernel, Nunchaku- und FP8-Unterstützung sowie mehrere neue Modelle im ComfyUI-Plugin: Blog
  • Kritische Fehlerbehebung in Spec V2: Behebung eines Fehlers außerhalb des Index, der durch die Torch-Garbage-Collection in der spekulativen Dekodierung v2 verursacht wurde, wodurch die Zuverlässigkeit der spekulativen Verifizierung verbessert wurde: #18958
  • Bereitstellung von DeepSeek auf GB300 NVL72: Optimierungsarbeiten für Long-Context-Inferenz mithilfe von Prefill-Decode-Disaggregation und anderen SGLang-Funktionen auf NVIDIAs neuester GB300-Plattform: Blog
  • Änderung der AITER-Version auf 0.1.10.post3: Unterstützt FP8 Prefill/Decode/KV Cache
  • Commit-zu-Version-Suche in docs.sglang.io: Finden Sie ganz einfach die früheste offizielle Version, die eine bestimmte PR oder ein bestimmtes Commit enthält, und optimieren Sie die Release-Nachverfolgung für Benutzer und Entwickler: #18450, Link

sglang v0.5.9

Highlights

  • LoRA Weight Loading Overlap with Computation: Overlap LoRA weight loading with computation during inference, reducing TTFT by ~78% and TPOT by ~34.88% on large adaptors: #15512

  • TRT-LLM NSA Kernel Integration for DeepSeek V3.2: Integrate TRT-LLM DSA kernels for Native Sparse Attention, boosting DeepSeek V3.2 performance by 3x-5x on Blackwell platforms with trtllm for both --nsa-prefill-backend and --nsa-decode-backend (with minor accuracy drop): #16758, #17662, #18389

  • Flashinfer All-to-All MoE Dispatcher: Add the Flashinfer all-to-all MoE dispatcher for efficient expert parallelism communication, enabling optimized routing in MoE models: #14668

  • FA4 (FP4 Attention) Support for Multimodal Encoder: Introduce FP4 attention backend and variable-length attention function for multimodal encoders, enabling lower-precision inference for vision-language models: #13539

  • Anthropic Compatible API Endpoint: Add native Anthropic API compatibility to SGLang, allowing direct integration with tools and clients built for the Anthropic API format: #18630

  • SGLang-Diffusion Advanced Optimizations: Production-ready improvements including token-level sequence sharding, parallel VAE decoding, fused kernels, Nunchaku and FP8 support, and multiple new models in the ComfyUI plugin: blog

  • Spec V2 Critical bug fix: Fix out-of-index bug caused by torch garbage collection in speculative decoding v2, improving reliability of speculative verification: #18958

  • Deploying DeepSeek on GB300 NVL72: Optimization work for long-context inference using prefill-decode disaggregation and other SGLang features on NVIDIA's latest GB300 platform: blog

  • Bump AITER version to 0.1.10.post3: Support FP8 Prefill/Decode/KV Cache

  • Commit-to-Version Lookup in docs.sglang.io: Easily find the earliest official version that includes a given PR or commit, streamlining release tracking for users and developers: #18450, link
