sglang v0.5.15

Patch Veröffentlicht10. Juli 2026 Quellesgl-project/sglang Englisches Original

umgangssprachlich v0.5.15

Highlights

GLM-5.2 NVFP4, abgestimmt auf die Produktion: Wir haben uns in diesem Zyklus die Zeit genommen, GLM-5.2 NVFP4 auf Blackwell für eine optimierte Produktionsbereitstellung abzustimmen. Es läuft jetzt mit 500+ Token/s/Benutzer auf 8x B300, 450 auf 4x GB300 (BS=1). Führen Sie GLM-5.2 mit unserem Kochbuch aus.

  • Spec V2 standardmäßig: Planung ohne Overhead über CUDA-grafische DSA-Draft-Extend, entfallene D2H/H2D-Synchronisierungen, fusionierte Metadatenoperationen. +11 % End-to-End-TPS (#29413, #29343, #29166, #29077).
  • IndexShare MTP: Verwendet den Top-K-Indexer über Entwurfsschritte hinweg wieder, bis zu 1,9-mal niedrigere Entwurfsschrittkosten bei langem Kontext (#29959, #29787, #29654).
  • TopK V2: verschmilzt die Top-K-Auswahl mit der Seitentabellentransformation, Laufzeit k bis zu 2048 (#30274, #26788).
  • Indexer-Prolog-Fusion: 12 Kernel auf 4, ~8 % schnellere Dekodierung bei bs=1 (#27705).
  • GEMM: formspezialisierter JIT-Router GEMM + CuteDSL BF16 GEMM für Blackwell (#21531, #30117).
  • FlashInfer-Autotune: Deckt jetzt Entwurfsmodelldiagramme ab (#29595). Unterstützung für neue Modelle: Hunyuan 3 (Hy3), Hierarchical Reasoning Model (HRM-Text), NVIDIA LocateAnything-3B, Baidu Unlimited-OCR, JoyEcho Multi-Shot A/V, plus Qwen3.6 NVFP4-Unterstützung. Native Websuche (Exa): Integrierte web_search-Unterstützung, unterstützt von Exa (#29342). Breakable CUDA Graph standardmäßig aktiviert: Breakable CUDA Graph ist jetzt der Standard-Erfassungspfad, wodurch der Kernel-Start-Overhead pro Schritt reduziert wird (#29458); Die vollständige CUDA-Graph-Unterstützung für die Vorfüllphase gilt als experimentell (#27988). Linear-Attention-Kernel (KDA/GDN): Neues FlashKDA-Prefill-Backend für Safe-Gate-KDA-Linear-Attention (#29472), plus ReplaySSM-gepufferte Nur-Ausgabe-Dekodierung für Linear-Attention (#28451). FlashInfer A2A für geroutetes MoE: Fügt FlashInfer all-to-all mit dem flashinfer_trtllm_routed MoE-Runner hinzu (#22394). DeepSeek-V4-Optimierung:
  • Optimiert die Zuweisung des C128-Statuspools mithilfe des Anforderungsstatuspools (#28612).
  • FlashMLA Sparse Prefill ist jetzt standardmäßig für DeepSeek-V4 aktiviert und erreicht einen Durchsatzgewinn von >10 % bei langem Kontext. (#29775).
  • Nicht ausgelagerte Indexerunterstützung für das Vorfüllen langer Kontexte mit >5 % e2e-Durchsatzgewinn.(#29619). Kontextparallelität dekodieren: Kontextparallelitätsländer für MLA-Modelle dekodieren, einschließlich der Serien DeepSeek V3 und Kimi K2 (#14194). Abhängigkeits-Upgrades: transformers wurde auf 5.12.1 erhöht (#29393); tvm-ffi / sgl-deep-gemm / tilelang aktualisiert (#29554). Und . Siehe das DeepSeek-V4-Kochbuch. Vollständige release notes nach Kategorie unten.

sglang v0.5.15

Highlights

GLM-5.2 NVFP4, tuned for production: We took time this cycle to tune GLM-5.2 NVFP4 on Blackwell for optimized production serving. It now runs at 500+ tok/s/user on 8x B300, 450 on 4x GB300 (bs=1). Run GLM-5.2 with our cookbook.

  • Spec V2 by default: zero-overhead scheduling via CUDA-graphable DSA draft-extend, dropped D2H/H2D syncs, fused metadata ops. +11% end-to-end TPS (#29413, #29343, #29166, #29077).
  • IndexShare MTP: reuses the indexer top-k across draft steps, up to 1.9x lower draft-step cost at long context (#29959, #29787, #29654).
  • TopK V2: fuses top-k selection with the page-table transform, runtime k up to 2048 (#30274, #26788).
  • Indexer prologue fusion: 12 kernels to 4, ~8% faster decode at bs=1 (#27705).
  • GEMM: shape-specialized JIT router GEMM + CuteDSL BF16 GEMM for Blackwell (#21531, #30117).
  • FlashInfer autotune: now covers draft-model graphs (#29595).

New Model Support: Hunyuan 3 (Hy3), Hierarchical Reasoning Model (HRM-Text), NVIDIA LocateAnything-3B, Baidu Unlimited-OCR, JoyEcho multi-shot A/V, plus Qwen3.6 NVFP4 support.

Native web search (Exa): Built-in web_search support backed by Exa (#29342).

Breakable CUDA Graph on by default: Breakable CUDA Graph is now the default capture path, reducing per-step kernel-launch overhead (#29458); full CUDA Graph support for the prefill phase lands as experimental (#27988).

Linear-attention kernels (KDA / GDN): New FlashKDA prefill backend for safe-gate KDA linear attention (#29472), plus ReplaySSM buffered output-only decode for linear attention (#28451).

FlashInfer A2A for routed MoE: Adds FlashInfer all-to-all with the flashinfer_trtllm_routed MoE runner (#22394).

DeepSeek-V4 Optimization:

  • Optimizes C128 state-pool allocation using the request state pool (#28612).
  • FlashMLA sparse prefill is now enabled by default for DeepSeek-V4, reaching >10% throghput gain on long context. (#29775).
  • Non paged indexer support for long context prefill, with >5% e2e throughput gain.(#29619).

Decode Context Parallelism: decode context parallelism lands for MLA models, including DeepSeek V3 and Kimi K2 series (#14194).

Dependency upgrades: transformers bumped to 5.12.1 (#29393); tvm-ffi / sgl-deep-gemm / tilelang upgraded (#29554). and . See the DeepSeek-V4 cookbook.
