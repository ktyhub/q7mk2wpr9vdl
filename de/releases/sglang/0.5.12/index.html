sglang v0.5.12

Patch Veröffentlicht16. Mai 2026 Quellesgl-project/sglang Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

umgangssprachlich v0.5.12

Highlights

  • DeepSeek V4-Unterstützung: Vollständiger Inferenzpfad für DeepSeek-V4 (#23882), einschließlich: Tag-0-Funktionen: #23882
    • Parallelität: Tensor-Parallelität/Experten-Parallelität/Kontext-Parallelität/Daten-Parallelität
    • Hardware: Nvidia B300/B200/H200/H100/GB200/GB300, AMD MI35X
    • Prefill-Decode-Disaggregation – HiSparse zum Auslagern des inaktiven KV-Cache in den CPU-Speicher
    • Reasoning-Parser und Tool Call Parser
    • DeepGemm- und FlashMLA-Kernel für DeepSeek V4, einschließlich MegaMoE Ergänzungen nach Tag 0: – HiCache für DeepSeek V4 unter einheitlichem Radix Tree [UnifiedTree]: #24691
    • W4A4 MegaMoE-Kernel – höhere Geschwindigkeit bei vernachlässigbarem Genauigkeitsabfall: #25052
    • Marlin/FlashInfer W4A8 MoE-Kernel auf Hopper: #24816 #24986 – Schnellere V2-Fused-Komprimierungskerne: #24890
    • TP16-Unterstützung auf H100/H20: #24949 – Fused SiLU+clamp+FP8 Quant-Kernel: #24897 – Optimierte MHC + DeepGemm-Pipeline (fusionierte Norm, fusionierter hc_head): #24775 – Unterstützung nicht standardmäßiger Chat-Vorlagen für DSv4: #23915
    • Multi-Detokenizer-Unterstützung: #24944 – Pipeline-Parallelität + PD-Unterstützung für DeepSeek-V4: #24700
    • Ein einheitliches docker-Tag lmsysorg/sglang:v0.5.12 für alle Nvidia-GPUs Weitere Einzelheiten finden Sie im LMSYS-Blog und im DeepSeek-V4-Kochbuch.
  • TokenSpeed MLA-Aufmerksamkeits-Backend (Blackwell, FP8-KV-Cache): Neue MLA-Vorfüll-/Dekodierungskerne, die als Aufmerksamkeits-Backend auf SM100 integriert sind, mit FP8-KV-Cache-Unterstützung für MLA-Bereitstellung mit geringer Latenz: #24925
  • DSv3.2 / GLM-5 FP4-Low-Latency-Leistung: PDL über DSv3.2 / GLM-5-Kernel hinweg aktiviert, torch.mm für den DeepSeek V3.2-Indexer GEMM und ein Reland des Cute-DSL FP4 Dense GEMM – deutliche Reduzierung des Low-Latency-Overheads auf FP4-Pfaden: #23965, #23856, #23590, #25311
  • Unterstützung neuer Modelle: DeepSeek V4 #23882, Intern-S2-Preview #24875, MiniCPM-V 4.6 #24855, Laguna-XS.2 #24204, Ring-2.6-1T #25360 und Gemma 4 MTP #24436 – mit Kochbuchrezepten für optimierte Bereitstellungsbefehle. Siehe docs.sglang.io/cookbook
  • HiCache + UnifiedRadixTree: HiCache-Framework-Unterstützung für UnifiedRadixTree (mit SWA), HiCache für DeepSeek V4, SSD-Offload über den Mooncake-Store und Stabilitätskorrekturen für Kaskadenräumung, Tombstone-Wiedergabe und Teilübereinstimmungspfade: #23316, #23391, #24691, #24277, #24943, #24972, #25068, #25277
  • Speculative Decoding V2-Reifung: Adaptive Spec V2, EAGLE-3 SWA + neuere Drafter, Kimi K2.5 EAGLE-3 MLA, Gemma 3/4 + EAGLE-3 und ein umfassender Refactor für Benennung/Formhandhabung über Draft-Extend-Pfade hinweg: #23336, #24663, #24664, #24826, #23976, #24859
  • CUDA 13 DeepEP-Migration: Die Gateway-DeepEP-Quelle wurde von einem Community-Fork auf deepseek-ai/DeepEP@hybrid-ep umgestellt, sodass DeepEP sauber auf dem CUDA 13-Standard erstellt und ausgeführt werden kann; FlashInfer wurde bei 0.6.11.post1 zusammen mit einem gpt-oss-Triton-Kernel-Fix angeheftet: #25113

sglang v0.5.12

Highlights

  • DeepSeek V4 support: Full inference path for DeepSeek-V4 (#23882), including:

    Day-0 Features: #23882

    • Parallelism: Tensor Parallelism/Expert Parallelism/Context Parallelism/Data Parallel Attention
    • Hardware: Nvidia B300/B200/H200/H100/GB200/GB300, AMD MI35X
    • Prefill-Decode Disaggregation
    • HiSparse for offloading inactive KV cache to CPU memory
    • Reasoning parser and Tool Call Parser
    • DeepGemm and FlashMLA kernels for DeepSeek V4, including MegaMoE

    Post-Day-0 additions:

    • HiCache for DeepSeek V4 under unified Radix Tree [UnifiedTree]: #24691
    • W4A4 MegaMoE kernels — faster speed with negligible accuracy drop: #25052
    • Marlin/FlashInfer W4A8 MoE kernels on Hopper: #24816 #24986
    • Faster V2 fused compression kernels: #24890
    • TP16 support on H100/H20: #24949
    • Fused SiLU+clamp+FP8 quant kernel: #24897
    • Optimized MHC + DeepGemm pipeline (fused norm, fused hc_head): #24775
    • Non-standard chat template support for DSv4: #23915
    • Multi-detokenizer support: #24944
    • Pipeline Parallelism + PD support for DeepSeek-V4: #24700
    • A unified docker tag lmsysorg/sglang:v0.5.12 for all Nvidia GPUs

    See the LMSYS blog and the DeepSeek-V4 cookbook for more details.

  • TokenSpeed MLA attention backend (Blackwell, FP8 KV cache): New MLA prefill/decode kernels integrated as an attention backend on SM100, with FP8 KV cache support for low-latency MLA serving: #24925

  • DSv3.2 / GLM-5 FP4 low-latency perf: PDL enabled across DSv3.2 / GLM-5 kernels, torch.mm for the DeepSeek V3.2 indexer GEMM, and a reland of the Cute-DSL FP4 dense GEMM — materially trimming low-latency overheads on FP4 paths: #23965, #23856, #23590, #25311

  • New Model Support: DeepSeek V4 #23882, Intern-S2-Preview #24875, MiniCPM-V 4.6 #24855, Laguna-XS.2 #24204, Ring-2.6-1T #25360, and Gemma 4 MTP #24436 — with cookbook recipes for tuned deployment commands. See docs.sglang.io/cookbook

  • HiCache + UnifiedRadixTree: HiCache framework support for UnifiedRadixTree (with SWA), HiCache for DeepSeek V4, SSD offload through Mooncake store, and stability fixes across cascade eviction, tombstone replay, and partial-match paths: #23316, #23391, #24691, #24277, #24943, #24972, #25068, #25277

  • Speculative Decoding V2 maturation: Adaptive Spec V2, EAGLE-3 SWA + newer drafters, Kimi K2.5 EAGLE-3 MLA, Gemma 3/4 + EAGLE-3, and an extensive naming / shape-handling refactor across draft-extend paths: #23336, #24663, #24664, #24826, #23976, #24859

  • CUDA 13 DeepEP migration: Gateway DeepEP source swapped from a community fork to deepseek-ai/DeepEP@hybrid-ep so DeepEP builds and runs cleanly on the CUDA 13 default; FlashInfer pinned at 0.6.11.post1 alongside a gpt-oss triton-kernel fix: #25113
