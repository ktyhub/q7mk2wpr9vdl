sglang v0.5.10

Patch Veröffentlicht6. Apr. 2026 Quellesgl-project/sglang Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

umgangssprachlich v0.5.10

Highlights

  • Stückweises CUDA-Diagramm standardmäßig aktiviert: Die stückweise CUDA-Diagrammerfassung ist jetzt der Standardausführungsmodus, wodurch der Speicheraufwand reduziert und der Durchsatz für Modelle mit komplexen Kontrollflussmustern verbessert wird: #16331
  • Elastic EP für Teilfehlertoleranz: Integrieren Sie Elastic NIXL-EP in SGLang und ermöglichen Sie Teilfehlertoleranz für DeepSeek MoE-Bereitstellungen – wenn eine GPU ausfällt, weist das System Expertengewichtungen zu und setzt die Bereitstellung ohne vollständigen Neustart fort: #19248, #17374, #12068 Blog
  • GPU-Staging-Puffer für PD-Disaggregation: Sammelt verstreute Head-Slices im zusammenhängenden Speicher für Massen-RDMA-Übertragungen, wodurch die Anzahl der RDMA-Anfragen bei GQA-Modellen um das ~1000-fache reduziert wird. TPS/GPU bei großer Parallelität um etwa das Fünffache erhöht mit Prefill TP4+Decode DEP4 auf Qwen3.5: #19890
  • HiSparse für spärliche Aufmerksamkeit: Integrieren Sie das HiSparse-Backend für spärliche Aufmerksamkeit für effiziente Rückschlüsse auf lange Kontexte mit reduziertem Rechenaufwand durch sparsity-bewusste Aufmerksamkeit: #20343
  • SGLang-Diffusions-Update:
    • Modellunterstützung: LTX-2, Hunyuan3D-2, Helios
    • Leistungsverbesserungen beim Qwen-Bild, Z-Bild um das 1,5-fache erhöht
    • Neue Plattform: macOS
    • Neue Funktion: Verbessern Sie die Leistung des Diffusor-Backends durch die Integration aller Optimierungen von Cache-DiT
    • FÄHIGKEITEN: Erkunden Sie gerne die kuratierten Fähigkeiten zur Entwicklung und Optimierung der Sglang-Verbreitung!
  • FlashInfer MXFP8-Kernel-Unterstützung: Integrieren Sie FlashInfer mxfp8-Kernel für GEMM- und MoE-Vorgänge und ermöglichen Sie FP8-Inferenz mit gemischter Genauigkeit und höherer Genauigkeit durch Mikroskalierung für RL und allgemeine Workloads: #19537
  • Transformers 5.3.0-Upgrade: Großes Upgrade von den Transformatoren 4.57.1 auf 5.3.0, wodurch die Unterstützung für die neuesten Modellarchitekturen und Funktionen von HuggingFace freigeschaltet wird. Das GLM-5-Modell wird jetzt in diesem Image anstelle des benutzerdefinierten Images unterstützt: #17784
  • DeepSeek V3.2 / GLM-5-Optimierung: GLM-5 läuft auf dem Hauptzweig (mit aktualisierten Transformatoren). Fused Triton-Kernel zum Vorfüllen des KV-Cache-Abrufs, NSA-Fuse-Store-Indexer für K-Cache, TRT-LLM-Vorfüllen/Decodieren von DSA-Kerneln als Standard auf SM100/SM103 und IndexCache für einen um mehr als 10 % verbesserten Durchsatz bei hohen Arbeitslasten: #19319, #19148, #20062, #21914, #21405
  • Qwen3.5 GDN/KDA-Optimierung: Transponieren Sie das lineare Aufmerksamkeitszustandslayout von [N, HV, K, V] nach [N, HV, V, K] und verschmelzen Sie Split-/Reshape-/Cat-Ops in der GDN-Projektion mit Triton-Kernel, plus CuTeDSL-KDA-Dekodierungskernel-Unterstützung für verbesserte Qwen3.5-Leistung: #20283, #21019, #21203
  • LoRA-Unterstützung für MoE-Ebenen: Fügen Sie LoRA-Feinabstimmungsunterstützung für Mixture-of-Experts-Ebenen mit JIT-Ausrichtungskernen, fusionierten Triton-Kerneln, TP-Unterstützung, CUDA-Graph-Unterstützung und automatischer Erkennung von LoRA-Zielmodulen hinzu – was eine effiziente, adapterbasierte Abstimmung auf MoE-Modellen wie DeepSeek ermöglicht: #19710, #19711, #14105, #21439, #21647
  • Prefill Context Parallel for MHA (Qwen3): Aktivieren Sie Kontextparallelität während des Prefill für Multi-Head-Attention-Modelle wie Qwen3 MoE und verteilen Sie lange Sequenzen auf GPUs, um den Speicher pro GPU zu reduzieren und das Prefill zu beschleunigen: #18233
  • Unterstützung der offiziellen Flash Attention 4-Bibliothek: Upgrade auf das offizielle FlashAttention 4-Paket mit den neuesten Attention-Optimierungen und Blackwell-GPU-Unterstützung: #20303
  • Skip-Softmax-Aufmerksamkeit für FlashInfer-TRT-LLM-Kernel: Reduzieren Sie den Rechenaufwand in Aufmerksamkeitsschichten durch Überspringen redundanter Softmax-Normalisierung: #19089
  • Spekulative Dekodierung mit FA4-Backend: Aktivieren Sie die spekulative Dekodierung für das FA4-Aufmerksamkeits-Backend und kombinieren Sie spekulative Inferenz mit Flash-Aufmerksamkeit der nächsten Generation für eine schnellere Generierung: #21080
  • MM Attention FA4 Standard auf SM100: Multimodale Aufmerksamkeit verwendet jetzt FA4 standardmäßig auf Blackwell-Hardware für eine verbesserte VLM-Leistung: #21595
  • Stärkeres Transformers-Modellierungs-Backend: Verbessertes Transformers-Backend mit vollständiger TP-, PP-, MoE-, VLM-Unterstützung und Torch.compile-Kompatibilität: #19163
  • sglang-kernel 0.4.1: Hauptversion des Kernel-Pakets mit umbenanntem Paket (sgl-kernel → sglang-kernel), konsolidierten Kerneln und Bereinigung veralteter Operationen: #20440, #22009
  • Natives MLX-Backend für Apple Silicon: Fügen Sie ein natives MLX-Ausführungs-Backend hinzu, das es SGLang ermöglicht, Inferenz direkt auf Apple Silicon Macs ohne CUDA auszuführen: #20342

sglang v0.5.10

Highlights

  • Piecewise CUDA Graph Enabled by Default: Piecewise CUDA graph capture is now the default execution mode, reducing memory overhead and improving throughput for models with complex control flow patterns: #16331

  • Elastic EP for Partial Failure Tolerance: Integrate Elastic NIXL-EP into SGLang, enabling partial failure tolerance for DeepSeek MoE deployments — when a GPU fails, the system redistributes expert weights and continues serving without full restart: #19248, #17374, #12068 blog

  • GPU Staging Buffer for PD Disaggregation: Gathers scattered head slices into contiguous memory for bulk RDMA transfer, reducing RDMA request count on GQA models by ~1000x. TPS/GPU on large concurrency increased by ~5x with Prefill TP4+Decode DEP4 on Qwen3.5: #19890

  • HiSparse for Sparse Attention: Integrate HiSparse sparse attention backend for efficient long-context inference with reduced compute through sparsity-aware attention: #20343

  • SGLang-Diffusion Update:

    • Model support: LTX-2, Hunyuan3D-2, Helios
    • Performance improvements on Qwen-image, Z-image increased by 1.5x
    • New platform: macOS
    • New feature: enhance the performance of diffusers backend by integrating all optimization from Cache-DiT
    • SKILLs: feel free to explore the curated skill for developing and optimizing sglang-diffusion!

  • FlashInfer MXFP8 Kernel Support: Integrate FlashInfer mxfp8 kernels for GEMM and MoE operations, enabling mixed-precision FP8 inference with higher accuracy through microscaling for RL and general workloads: #19537

  • Transformers 5.3.0 Upgrade: Major upgrade from transformers 4.57.1 to 5.3.0, unlocking support for the latest model architectures and features from HuggingFace. GLM-5 model is now supported in this image instead of the custom built image: #17784

  • DeepSeek V3.2 / GLM-5 Optimization: GLM-5 runnable on main branch (with upgraded transformers). Fused Triton kernel for prefill KV cache fetching, NSA fuse store indexer for K cache, TRT-LLM prefill/decode DSA kernels as default on SM100/SM103, and IndexCache for improved throughput by more than 10% on high workloads: #19319, #19148, #20062, #21914, #21405

  • Qwen3.5 GDN/KDA Optimization: Transpose linear attention state layout from [N, HV, K, V] to [N, HV, V, K] and fuse split/reshape/cat ops in GDN projection with Triton kernel, plus CuTeDSL KDA decode kernel support for improved Qwen3.5 performance: #20283, #21019, #21203

  • LoRA Support for MoE Layers: Add LoRA fine-tuning support for Mixture-of-Experts layers with JIT alignment kernels, fused Triton kernels, TP support, CUDA graph support, and auto-detection of LoRA target modules — enabling efficient adapter-based tuning on MoE models like DeepSeek: #19710, #19711, #14105, #21439, #21647

  • Prefill Context Parallel for MHA (Qwen3): Enable context parallelism during prefill for multi-head attention models like Qwen3 MoE, distributing long sequences across GPUs to reduce per-GPU memory and accelerate prefill: #18233

  • Flash Attention 4 Official Library Support: Upgrade to the official FlashAttention 4 package, bringing the latest attention optimizations and Blackwell GPU support: #20303

  • Skip-Softmax Attention for FlashInfer TRT-LLM Kernels: Reduce computation overhead in attention layers by skipping redundant softmax normalization: #19089

  • Speculative Decoding with FA4 Backend: Enable speculative decoding for the FA4 attention backend, combining speculative inference with next-generation flash attention for faster generation: #21080

  • MM Attention FA4 Default on SM100: Multi-modal attention now uses FA4 by default on Blackwell hardware for improved VLM performance: #21595

  • Stronger Transformers Modeling Backend: Enhanced transformers backend with full TP, PP, MoE, VLM support, and torch.compile compatibility: #19163

  • sglang-kernel 0.4.1: Major kernel package release with renamed package (sgl-kernel → sglang-kernel), consolidated kernels, and cleanup of deprecated ops: #20440, #22009

  • Native MLX Backend for Apple Silicon: Add native MLX execution backend enabling SGLang to run inference directly on Apple Silicon Macs without CUDA: #20342
