Was ist neu?

  • DeepSeek-V4.1 erreicht bis zu 2,3-mal mehr Durchsatz pro GPU auf H200 und läuft jetzt auf AMD MI350X/MI355X mit bis zu 1,9-fachem Durchsatz von DSpark (#41251, #41308).
  • Qwen3.8-Flash-Next dekodiert 12 % schneller auf B200 und GLM-5.3-Flash mit DFlash 10 % schneller auf B300 (#42175, #42489).
  • MiMo-V2.6-Pro erreicht mit DFlash auf B300 einen 1,85-fachen Dekodierungsdurchsatz (#41886).
  • Modelle werden mit dem neuen InstantTensor-Loader (#40453) 10x schneller geladen.
  • PD-Disaggregation sorgt für bis zu 27 % mehr Durchsatz und die Hälfte der p95-TTFT bei Workloads mit langer Eingabeaufforderung (#40703).
  • HiSparse unterstützt jetzt EAGLE und MTP für die Bereitstellung langer Kontexte mit dem KV-Cache im CPU-Speicher (#37771).
  • GLM-5.2 und GLM-5.3 können jetzt Decodierungskontextparallelität mit MTP kombinieren, mit bis zu 2,1-mal schnellerer Decodierung auf GLM-5.3 (#43735).
  • SGLang läuft jetzt auf Apple Silicon Macs mit dem Standard-PyTorch-Backend neben MLX (#36780).
  • MiniMax-H3 und Qwen-Image 2.1 laufen jetzt in ComfyUI mit SGLang Diffusion, wodurch auch Community-GGUF-Checkpoints und LoRAs geladen werden (#43504, #43581, #42556, #39523, #42174).
  • Wichtiger Fix: Hybride lineare Modelle konnten aus falschen Mamba-Zuständen wieder aufgenommen werden, wenn spekulative Dekodierung und strukturierte Ausgabe zusammen verwendet wurden. Vielen Dank an @Wirick und Baseten für die Suche (#43029).

Wichtige Änderungen und Upgrade-Hinweise

  • SGLang erfordert Python 3.11 oder neuer. Auf Python 3.10 schlägt pip install sglang nicht fehl; Es wird auf die letzte Version aufgelöst, die 3.10 unterstützte. Wechseln Sie zu Python 3.11+ (zum Beispiel vom Ubuntu 22.04-System Python), um diese und spätere Versionen zu erhalten: #43021
  • --enable-dp-attention ist veraltet; Verwenden Sie --attn-dp-size N. --dp-size zählt jetzt nur Modellreplikate. Der alte --dp-size N --enable-dp-attention wird immer noch mit einer Warnung in --attn-dp-size N aufgelöst; Das Kombinieren von Replikaten mit Aufmerksamkeits-DP oder das Übergeben beider Schreibweisen wird beim Start abgelehnt: #41818. Unter DeepSeek-Kontextparallelität bedeutet --dp-size N immer noch Aufmerksamkeits-DP, gibt aber jetzt eine Warnung aus und wird nach dem 31.12.2026 abgelehnt: #42348
  • --disaggregation-decode-host-receive-threshold ändert seine Kodierung. 1 (die neue Standardeinstellung) deaktiviert den Host-Empfang und 0 bedeutet jetzt, immer auf dem Host zu empfangen. Konfigurationen, die 0 zum Deaktivieren bestanden haben, müssen 1 bestehen: #43407
  • ChunkCache wurde entfernt. Mit --disable-radix-cache führen Hybrid-SWA- und Mamba-Modelle mit voller Aufmerksamkeit UnifiedRadixCache im deaktivierten Modus aus und reine SWA-Modelle führen PureSWARadixCache aus (#43198, #43199, #43200, #42354, #43201). Streaming-Sitzungen starten jetzt nur auf UnifiedRadixCache; Pure-SWA-, FlexKV- und Plugin-Tree-Caches schlagen beim Start mit dem Fehler „nicht verifiziert“ fehl (#42295) und die Beam-Suche lehnt auch Mamba-Modelle mit --disable-radix-cache ab (#42354)
  • Das tc_piecewise-Prefill-CUDA-Graph-Backend wurde entfernt. Die Übergabe von --cuda-graph-backend-prefill tc_piecewise oder einer tc_compiler-Einstellung löst jetzt einen Fehler aus; CUDA behält breakable als Standard-Vorausfüllungsdiagramm-Backend bei und andere Plattformen verwenden standardmäßig kein Vorausfüllungsdiagramm: #42287
  • Umbenannte und zurückgezogene Umgebungsvariablen. SGLANG_AITER_MLA_DCP_DECODE_BACKEND wird zu SGLANG_AITER_MLA_DECODE_BACKEND und seine Standardeinstellung ändert sich von gluon zu asm (#34537); SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW wird zu SGLANG_OPT_RELEASE_PREFILL_SWA (#42657); Die alten Namen funktionieren weiterhin mit einer Verfallswarnung. SGLANG_DSPARK_FAST_SAMPLING, SGLANG_DSPARK_FOLDED_SAMPLING und SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV sind veraltet und bewirken nichts mehr (#43622, #43668), und SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE ist veraltet: #43444
  • OpenAI-Chat-Antworten wurden in drei kleinen Punkten geändert. tool_choice: "none" zeigt keine Tool-Schemata mehr für DeepSeek-Modelle an (#43006), ein fehlendes tool_calls-Feld wird weggelassen statt als null zurückgegeben (#43027) und ein Stream behält einen created-Zeitstempel für seine gesamte Lebensdauer: #43026
  • --enable-layernorm-sp wird mit Pipeline-Parallelität abgelehnt. Beim ersten Vorabfüllen ist ein Fehler aufgetreten: #43458
  • Für Modell- und Plugin-Autoren: ModelRunner.tp_group wurde entfernt; Lesen Sie get_parallel().tp_group in dem Bereich, in dem der Code ausgeführt wird (#41817). Ungelesene Platzierungsattribute wie model.tp_size sind verschwunden; lesen Sie get_parallel() (#41812). Ein Modell, das Stufengrenzen deklariert und unter Pipeline-Parallelität läuft, muss seine gemeinsame Stufendeklaration (stage_facts) an make_layers/make_pp_layers übergeben: #43460

What's new

  • DeepSeek-V4.1 gets up to 2.3x more throughput per GPU on H200, and now runs on AMD MI350X / MI355X with up to 1.9x throughput from DSpark (#41251, #41308).
  • Qwen3.8-Flash-Next decodes 12% faster on B200, and GLM-5.3-Flash with DFlash 10% faster on B300 (#42175, #42489).
  • MiMo-V2.6-Pro gets 1.85x decode throughput with DFlash on B300 (#41886).
  • Models load 10x faster with the new InstantTensor loader (#40453).
  • PD disaggregation gets up to 27% more throughput and half the p95 TTFT on long-prompt workloads (#40703).
  • HiSparse now supports EAGLE and MTP for long-context serving with the KV cache in CPU memory (#37771).
  • GLM-5.2 and GLM-5.3 can now combine decode context parallelism with MTP, with up to 2.1x faster decoding on GLM-5.3 (#43735).
  • SGLang now runs on Apple Silicon Macs with the standard PyTorch backend, alongside MLX (#36780).
  • MiniMax-H3 and Qwen-Image 2.1 now run in ComfyUI with SGLang Diffusion, which also loads community GGUF checkpoints and LoRAs (#43504, #43581, #42556, #39523, #42174).
  • Important fix: Hybrid linear models could resume from wrong mamba states when speculative decoding and structured output were used together. Thanks to @Wirick and Baseten for finding it (#43029).

Breaking Changes & Upgrade Notes

  • SGLang requires Python 3.11 or newer. On Python 3.10, pip install sglang does not fail; it resolves to the last release that supported 3.10. Move to Python 3.11+ (for example off the Ubuntu 22.04 system Python) to get this and later releases: #43021
  • --enable-dp-attention is deprecated; use --attn-dp-size N. --dp-size now counts model replicas only. The old --dp-size N --enable-dp-attention still resolves to --attn-dp-size N with a warning; combining replicas with attention DP, or passing both spellings, is rejected at startup: #41818. Under DeepSeek context parallelism, --dp-size N still means attention DP but now warns and will be rejected after 2026-12-31: #42348
  • --disaggregation-decode-host-receive-threshold flips its encoding. 1 (the new default) disables host receive and 0 now means always receive on host. Configurations that passed 0 to disable it must pass 1: #43407
  • ChunkCache is removed. With --disable-radix-cache, full-attention, hybrid-SWA and Mamba models run UnifiedRadixCache in disabled mode and pure-SWA models run PureSWARadixCache (#43198, #43199, #43200, #42354, #43201). Streaming sessions now start only on UnifiedRadixCache; pure-SWA, FlexKV and plugin tree caches fail at startup with a "not verified" error (#42295), and beam search rejects Mamba models with --disable-radix-cache too (#42354)
  • The tc_piecewise prefill CUDA graph backend is removed. Passing --cuda-graph-backend-prefill tc_piecewise or a tc_compiler setting now raises an error; CUDA keeps breakable as the default prefill graph backend, and other platforms default to no prefill graph: #42287
  • Renamed and retired environment variables. SGLANG_AITER_MLA_DCP_DECODE_BACKEND becomes SGLANG_AITER_MLA_DECODE_BACKEND and its default changes from gluon to asm (#34537); SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW becomes SGLANG_OPT_RELEASE_PREFILL_SWA (#42657); the old names keep working with a deprecation warning. SGLANG_DSPARK_FAST_SAMPLING, SGLANG_DSPARK_FOLDED_SAMPLING and SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV are deprecated and no longer do anything (#43622, #43668), and SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE is deprecated: #43444
  • OpenAI chat responses changed in three small ways. tool_choice: "none" no longer shows tool schemas to DeepSeek models (#43006), an absent tool_calls field is omitted instead of returned as null (#43027), and a stream keeps one created timestamp for its whole lifetime: #43026
  • --enable-layernorm-sp is rejected with pipeline parallelism. It failed on the first prefill before: #43458
  • For model and plugin authors: ModelRunner.tp_group is removed; read get_parallel().tp_group in the scope the code runs in (#41817). Unread placement attributes such as model.tp_size are gone; read get_parallel() (#41812). A model that declares stage boundaries and runs under pipeline parallelism must pass its shared stage declaration (stage_facts) to make_layers / make_pp_layers: #43460
