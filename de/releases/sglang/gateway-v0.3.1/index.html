Sglang-Gateway-v0.3.1

🚀 SMG v0.3.1 veröffentlicht!

Wir freuen uns, SMG v0.3.1 ankündigen zu können – eine bahnbrechende Version mit 10- bis 12-facher Leistungsverbesserung und 99 % Speicherreduzierung beim Cache-bewussten Routing sowie Sicherheit auf Unternehmensniveau!

🌲 Radix Tree / Cache-Aware Routing: 10–12x schneller + 99 % weniger Speicher ⚡

Komplette Optimierungsüberarbeitung unserer Cache-fähigen Routing-Engine mit beeindruckenden Leistungs- und Speichergewinnen:

Leistungsverbesserungen

– Unser Cache-fähiges Routing kann jetzt über 216.000 Cache-Einfügungen pro Sekunde verarbeiten (vorher 18.900), wobei die Latenz von 52.9 Mikrosekunden auf nur 4.6 Mikrosekunden pro Vorgang sinkt. – Beim Präfixabgleich über 10.000 Baumeinträge hinweg stieg der Durchsatz von 41.000 auf 124.000 Vorgänge pro Sekunde.

  • Unter gleichzeitiger Last mit 64 Threads verarbeitet das System 474.000 Vorgänge pro Sekunde – eine 7,9-fache Verbesserung gegenüber den vorherigen 59.000 Vorgängen/Sek.

Datenverarbeitung

  • INSERT-Vorgänge verarbeiten jetzt 440 MB/s (vorher 38 MB/s),
  • MATCH-Vorgänge verarbeiten 253 MB/s (vorher 83 MB/s).

Speicherverbesserungen:

  • ~99 % Speicherreduzierung pro Baumknoten:
  • Vorher: ~180 KB pro Knoten (DashMap-Standardkonfiguration auf 170-Core-Maschinen) – Nachher: ~1.4 KB pro Knoten Ergebnis: Stellen Sie 100x mehr Cache-Einträge bei gleichem Speicherbedarf bereit! Bei einer typischen Bereitstellung mit 10.000 zwischengespeicherten Präfixen sinkt die Speichernutzung von ~1.8 GB auf nur ~14 MB – wodurch Ressourcen für tatsächliche Inferenzarbeitslasten frei werden. Auswirkung: Cache-bewusstes Routing ist jetzt 10-12x schneller und verbraucht 99 % weniger Speicher. Dies ist für groß angelegte Multi-Tenant-Bereitstellungen von entscheidender Bedeutung.

🔐 JWT/OIDC-Authentifizierung

Sicherheit auf Produktionsniveau für APIs der Steuerungsebene mit nativer Unterstützung für branchenübliche OIDC-Anbieter: Google, Azure, Oracle, GitHub und mehr. Schützen Sie die Tokenizer-Verwaltung, die Worker-Registrierung und Admin-Endpunkte mit der Unternehmensauthentifizierungsinfrastruktur, die Sie bereits nutzen. Entscheidend für Unternehmensbereitstellungen – integrieren Sie SMG nahtlos in Ihre vorhandenen Identitäts- und Zugriffsverwaltungssysteme.

📊 Klassifizierung API-Unterstützung

Native Unterstützung für Klassifizierungs-Workloads! Stellen Sie Klassifizierungsmodelle zusammen mit Ihrer bestehenden Inferenzflotte mit dedizierten Pipeline-Stufen und Protokolltypen bereit und stellen Sie sie bereit.

✨ Zusätzliche Funktionen

  • PrefixHash Load Balancing: Neue KV-Cache-fähige Lastausgleichsrichtlinie mit Präfix-Hashing für verbesserte Cache-Trefferraten in Umgebungen mit mehreren Mandanten.
  • Nemotron Nano V3 Parser
  • Metriken zum Anforderungsalter während der Übertragung: Verfolgen Sie das Anforderungsalter während der Übertragung für eine bessere Beobachtbarkeit und SLA-Überwachung.

🛠️ Verbesserungen

Entwicklererfahrung:

– CLI-Argumente in logische Gruppen organisiert

  • Verkürzte Protokollierungsziele (sgl_model_gateway → smg)
  • Umfassende Einbettungskorrektheitstests gegen HuggingFace
  • Protobuf-Dateien während des Radaufbaus automatisch generieren

Zuverlässigkeit:

– Korrigieren Sie das IGW-Routing für externe OpenAI-Worker

  • Umgehen Sie verwaiste Prozessprobleme
  • Verhindern Sie mögliche Hänger bei der Verarbeitung von Unterprozessen
  • Verwenden Sie 504 Gateway Timeout für Upstream-Timeouts (richtige HTTP-Semantik).

🐛 Fehlerbehebungen

  • Absturz beim Einbetten der Worker-Gesundheitsprüfung behoben
  • Der Tokenizer wurde an die spezielle Token-Verwaltung der Transformatoren angepasst
  • Problem mit der Darstellung des Alters-Buckets behoben – Die HTTP-Header-Whitelist für Nicht-PD-Router wurde korrigiert – Doppeltes Klassifizierungspräfix in der Antwort-ID behoben – WASM-Testfehler auf Maschinen mit vielen Kernen behoben

⚡ Auf Geschwindigkeit ausgelegt. Maßgeschneidert. Produktionserprobt.

sglang gateway-v0.3.1

🚀 SMG v0.3.1 Released!

We're excited to announce SMG v0.3.1 – a game-changing release with 10-12x performance improvement and 99% memory reduction in cache-aware routing, plus enterprise-grade security!

🌲 Radix Tree / Cache-Aware Routing: 10-12x Faster + 99% Less Memory ⚡

Complete optimization overhaul of our cache-aware routing engine with stunning performance and memory gains:

Performance Improvements

  • Our cache-aware routing can now handle over 216,000 cache insertions per second (up from 18,900), with latency dropping from 52.9 microseconds to just 4.6 microseconds per operation.
  • For prefix matching across 10,000 tree entries, throughput jumped from 41,000 to 124,000 operations per second.
  • Under concurrent load with 64 threads, the system processes 474,000 operations per second – a 7.9x improvement over the previous 59,000 ops/sec.

Data processing

  • INSERT operations now process 440 MB/s (up from 38 MB/s),
  • MATCH operations handle 253 MB/s (up from 83 MB/s).

Memory Improvements:

  • ~99% memory reduction per tree node:
  • Before: ~180 KB per node (DashMap default config on 170-core machines)
  • After: ~1.4 KB per node Result: Deploy 100x more cache entries in the same memory footprint! For a typical deployment with 10,000 cached prefixes, memory usage drops from ~1.8 GB to just ~14 MB – freeing up resources for actual inference workloads. Impact: Cache-aware routing is now 10-12x faster and uses 99% less memory. This is critical for large-scale multi-tenant deployments.

🔐 JWT/OIDC Authentication

Production-grade security for control plane APIs with native support for industry-standard OIDC providers: Google, Azure, Oracle, GitHub, and more. Protect tokenizer management, worker registration, and admin endpoints with enterprise authentication infrastructure you already use. Critical for enterprise deployments – seamlessly integrate SMG into your existing identity and access management systems.

📊 Classification API Support

Native support for classification workloads! Deploy and serve classification models alongside your existing inference fleet with dedicated pipeline stages and protocol types.

✨ Additional Features

  • PrefixHash Load Balancing: New KV cache-aware load balancing policy using prefix hashing for improved cache hit rates in multi-tenant environments.
  • Nemotron Nano V3 Parser
  • In-Flight Request Age Metrics: Track request age in-flight for better observability and SLA monitoring.

🛠️ Enhancements

Developer Experience:

  • Organized CLI arguments into logical groups
  • Shortened logging targets (sgl_model_gateway → smg)
  • Comprehensive embedding correctness tests against HuggingFace
  • Auto-generate protobuf files during wheel build

Reliability:

  • Fix IGW routing for external OpenAI workers
  • Work around orphan process problems
  • Prevent potential hangs in subprocess handling
  • Use 504 Gateway Timeout for upstream timeouts (proper HTTP semantics)

🐛 Bug Fixes

  • Fixed embedding worker health check crash
  • Fixed tokenizer to match transformers special token handling
  • Fixed age bucket rendering issue
  • Fixed non-PD router HTTP header whitelist
  • Fixed duplicate classify prefix in response ID
  • Fixed WASM test errors on machines with many cores

⚡ Built for speed. Engineered for scale. Production-proven.
