Hauptmerkmale

  • PD-Instanzen können im laufenden Betrieb zwischen Vorfüllung und Dekodierung wechseln, kein Neustart erforderlich (#28403).
  • Der Präfix-Cache läuft jetzt standardmäßig auf einem Rust-Kern (#39627).
  • DeepSeek-V4.1 erhält 22 % schnelleres erstes Token bei langen Eingabeaufforderungen (#40352).
  • Kimi K3 erzielt einen um 20.6 % höheren Prefill-Durchsatz bei der PD-Bereitstellung (#40045).
  • GLM-5.3-Flash läuft jetzt auf AMD MI355X, mit FP8/MXFP4 MoE und spekulativer MTP-Dekodierung (#38546, #39341, #39778).
  • Genauere Ergebnisse unter PP, DP Attention und CP, wobei die Layer-Kommunikation jetzt von SGLang verwaltet wird (guide, #41557).
  • Neue Entscheidungen API (/v1/decisions) verwandelt einen LLM/VLM in einen Klassifikator und Scorer mit geringer Latenz (docs, #41208).
  • Score API (/v1/score) bewertet alle Kandidaten in einer Anfrage (#38965, #41188).
  • Führen Sie MiniMax-H3 mit SGLang Diffusion in ComfyUI aus (#35990).

Wichtige Änderungen und Upgrade-Hinweise

  • Der einheitliche Basisbaum verwendet standardmäßig den Rust-Kern. Konfigurationen, die der Rust-Kern nicht unterstützt, greifen automatisch auf Python zurück; Setzen Sie SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python, um den Python-Kern überall zu erzwingen: #39627
  • FlashInfer MoE Fused Finalize ist aus Gründen der numerischen Genauigkeit standardmäßig deaktiviert. Dies kostet eine gewisse W4A4-MoE-Latenz; Setzen Sie SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1, um die verschmolzene atomare Finalisierung wiederherzustellen: #40105
  • PD-Dekodierung verschiebt jetzt standardmäßig die KV-Freigabe beim Abbruch auf den Mooncake- und NIXL-Backends und hält Seiten an, bis jeder Prefill-Rang bestätigt wird (30 s Timeout, SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT). Stellen Sie SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False ein, um die sofortige Veröffentlichung wiederherzustellen: #41023
  • Auf Anfrage bereitgestellte Chat-Vorlagen werden abgelehnt. Ein chat_template-Schlüssel in chat_template_kwargs auf /v1/chat/completions oder /v1/tokenize gibt jetzt einen Fehler zurück, es sei denn, der Server startet mit --trust-request-chat-template; andere chat_template_kwargs bleiben unverändert: #28135
  • Veraltete Endpunkte, Umgebungsvariablen und Aliase werden entfernt. Verwenden Sie /model_info anstelle von /get_weight_version und /weight_version, /v1/loads anstelle von /get_load und POST /hicache/storage-backend/clear anstelle von /clear_hicache_storage_backend. SGLANG_NSA_*-Aliase weichen SGLANG_DSA_*, SGLANG_ENABLE_SPEC_V2 ist weg, --elastic-ep-rejoin wird zu --elastic-ep-join-mode recover, --kv-cache-dtype fp4_e2m1 wird zu fp4_mx_block16 und python -m sglang.bench_offline_throughput / sglang.bench_one_batch werden zu sglang.benchmark.offline_throughput / sglang.benchmark.one_batch verschoben: #40795
  • Legacy-Radix-Cache-Implementierungen werden entfernt. Der experimentelle C++-Radix-Baum (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) ist verschwunden (#40775) und SGLANG_ENABLE_UNIFIED_RADIX_TREE führt keine Aktionen mehr aus, gibt jedoch weiterhin eine Verfallswarnung aus (#40780). Code, der SWARadixCache, MambaRadixCache oder HiRadixCache importiert, muss nach UnifiedRadixCache verschoben werden: #40313, #40787
  • Benutzerdefinierte Logit-Prozessoren müssen Protokolle in voller Form zurückgeben. Ein CustomLogitProcessor, der eine reduzierte Form wie (1, vocab) zurückgegeben hat und auf Broadcasting basiert, wird jetzt zum Zeitpunkt der Dekodierung ausgelöst. Die eingebauten Prozessoren sind davon nicht betroffen: #39234
  • RL-Gewichtsaktualisierungen werden innerhalb einer Sitzung ausgeführt. update_weights_from_tensor und update_weights_from_distributed müssen zwischen begin_weight_update() und end_weight_update() aufgerufen werden. UpdateWeightsFromTensorReqInput.disable_draft_model wird durch selector="target" ersetzt und ChecksumInfo.parallelism_info ist jetzt eine Liste mit einem Eintrag pro Rolle: #40777
  • Parallel-State-Getter sind veraltet. Sie werden nicht mehr von sglang.srt.distributed erneut exportiert; Gruppen über get_parallel() lesen (zum Beispiel get_parallel().tp_group) oder direkt aus parallel_state importieren: #40342, #40344, #40707
  • Ascend A2 (910b)-Bilder werden nicht mehr veröffentlicht. Veröffentlichungs- und Nachtbilder werden nur für A3 und 950 (A5) auf CANN 9.1.0 mit Python 3.12 ausgeliefert: #40524

Key features

  • PD instances can switch between prefill and decode on the fly, no restart needed (#28403).
  • The prefix cache now runs on a Rust core by default (#39627).
  • DeepSeek-V4.1 gets 22% faster first token on long prompts (#40352).
  • Kimi K3 gets 20.6% higher prefill throughput in PD serving (#40045).
  • GLM-5.3-Flash now runs on AMD MI355X, with FP8 / MXFP4 MoE and MTP speculative decoding (#38546, #39341, #39778).
  • More accurate results under PP, DP attention, and CP, with layer communication now handled by SGLang (guide, #41557).
  • New Decisions API (/v1/decisions) turns an LLM / VLM into a low-latency classifier and scorer (docs, #41208).
  • Score API (/v1/score) scores all candidates in one request (#38965, #41188).
  • Run MiniMax-H3 with SGLang Diffusion inside ComfyUI (#35990).

Breaking Changes & Upgrade Notes

  • The unified radix tree uses the Rust core by default. Configurations the Rust core does not support fall back to Python automatically; set SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python to force the Python core everywhere: #39627
  • FlashInfer MoE fused finalize is off by default for numerical accuracy. This costs some W4A4 MoE latency; set SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 to restore the fused atomic finalize: #40105
  • PD decode now defers KV release on abort by default on the Mooncake and NIXL backends, holding pages until every prefill rank acks (30 s timeout, SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT). Set SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False to restore immediate release: #41023
  • Request-supplied chat templates are rejected. A chat_template key inside chat_template_kwargs on /v1/chat/completions or /v1/tokenize now returns an error unless the server starts with --trust-request-chat-template; other chat_template_kwargs are unchanged: #28135
  • Deprecated endpoints, env vars, and aliases are removed. Use /model_info instead of /get_weight_version and /weight_version, /v1/loads instead of /get_load, and POST /hicache/storage-backend/clear instead of /clear_hicache_storage_backend. SGLANG_NSA_* aliases give way to SGLANG_DSA_*, SGLANG_ENABLE_SPEC_V2 is gone, --elastic-ep-rejoin becomes --elastic-ep-join-mode recover, --kv-cache-dtype fp4_e2m1 becomes fp4_mx_block16, and python -m sglang.bench_offline_throughput / sglang.bench_one_batch move to sglang.benchmark.offline_throughput / sglang.benchmark.one_batch: #40795
  • Legacy radix cache implementations are removed. The experimental C++ radix tree (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) is gone (#40775), and SGLANG_ENABLE_UNIFIED_RADIX_TREE no longer does anything, though it still prints a deprecation warning (#40780). Code importing SWARadixCache, MambaRadixCache, or HiRadixCache must move to UnifiedRadixCache: #40313, #40787
  • Custom logit processors must return full-shape logits. A CustomLogitProcessor that returned a reduced shape such as (1, vocab) and relied on broadcasting now raises at decode time. The built-in processors are unaffected: #39234
  • RL weight updates run inside a session. update_weights_from_tensor and update_weights_from_distributed must be called between begin_weight_update() and end_weight_update(). UpdateWeightsFromTensorReqInput.disable_draft_model is replaced by selector="target", and ChecksumInfo.parallelism_info is now a list with one entry per role: #40777
  • Parallel-state getters are deprecated. They are no longer re-exported from sglang.srt.distributed; read groups through get_parallel() (for example get_parallel().tp_group) or import from parallel_state directly: #40342, #40344, #40707
  • Ascend A2 (910b) images are no longer published. Release and nightly images ship for A3 and 950 (A5) only, on CANN 9.1.0 with Python 3.12: #40524
