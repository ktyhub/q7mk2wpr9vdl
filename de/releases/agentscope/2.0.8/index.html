agentscope v2.0.8

Hervorheben

  • Echtzeit-Sprachagent: Einführung eines Echtzeit-Sprachagenten mit DashScope-Backends und lokaler Transportunterstützung.
  • A2A-Protokollunterstützung: A2AAgent-Klasse zum Agentenmodul hinzugefügt, um die Kommunikation zwischen Agenten zu ermöglichen.
  • Neues Pipeline-Modul: Ein neues Pipeline-Modul mit einer GoalPipeline-Klasse für zielgerichtete Agenten-Workflows hinzugefügt.
  • Agentengesteuerte Kontextkomprimierung: Einführung eines Kontextkomprimierungstools, mit dem Agenten ihr eigenes Kontextfenster verwalten können.
  • LLM-Reranking für RAG: LLM-basierte Reranking-Unterstützung hinzugefügt, um die RAG-Abrufqualität zu verbessern.
  • Volcengine Ark-Modell: Unterstützung für das Volcengine Ark-Chat-Modell hinzugefügt.
  • MCP-Verbesserungen: Unterstützung von Laufzeit-MCP-Headern in Docker-Arbeitsbereichen und verbesserte MCP-Verbindungsbereinigung.
  • Polierte Web-Benutzeroberfläche: Verbesserungen des Chat-Erlebnisses, einschließlich automatischer Sitzungsbenennung, Abfrage-Caching und besserer Unterstützung für den Dunkelmodus.

agentscope v2.0.8

Highlights

  • Realtime voice agent — A new realtime voice path lands in #2547 with DashScope backends and a local transport, so you can build low-latency speech apps without rolling your own audio loop. Mind the naming: it was refactored to align with the base Agent API in #2550, so use the final class/API names rather than copying early example snippets.
  • A2A protocol support — A2AAgent (#2142) makes agents first-class peers in the Agent-to-Agent ecosystem, enabling delegation across independently deployed agents. If you were bridging agent systems with bespoke HTTP shims, this is the standard-protocol replacement and the main reason to upgrade for multi-agent composition.
  • GoalPipeline — The new pipeline module (#2428) adds GoalPipeline for goal-driven, verifier-backed workflows: you define the success criterion and the loop runs until it is met instead of a fixed step count. An early verifier-context-reset bug was fixed in #2544, so verify verifier state isn't leaking between attempts if you tested a pre-release build.
  • Agent-driven context compression — Agents can now summarize and trim their own context window (#2143), with compression usage recorded in context (#2433). This matters for long-running agents where token growth would otherwise stall execution or exhaust the budget; expect new compaction behavior and usage entries in your traces.
  • RAG reranking and score semantics — LLM-based reranking (#1975) is now available to sharpen retrieval, but #2486 flips distance-score normalization so higher now means more relevant. This is the watch-out item: code that sorts ascending or hardcodes "lower is closer" thresholds will silently invert, so audit RAG filtering and ranking logic when upgrading.
  • MCP and multimodal tool results — Runtime MCP headers in Docker workspaces (#2456) plus cleanup of cancelled connections (#2499) make per-request-authenticated MCP servers practical. Together with native multimodal tool outputs (#2389) and stable tool-result identifiers (#2165), image/audio-bearing tool results now round-trip instead of being flattened — re-check any custom formatter that assumed text-only results.

No breaking changes.

Highlight

  • Realtime Voice Agent: Introduced a realtime voice agent with DashScope backends and local transport support.
  • A2A Protocol Support: Added A2AAgent class to the agent module, enabling agent-to-agent communication.
  • New Pipeline Module: Added a new pipeline module with a GoalPipeline class for goal-driven agent workflows.
  • Agent-Driven Context Compression: Introduced a context compression tool that allows agents to manage their own context window.
  • LLM Rerank for RAG: Added LLM-based reranking support to improve RAG retrieval quality.
  • Volcengine Ark Model: Added support for Volcengine Ark chat model.
  • MCP Enhancements: Support runtime MCP headers in Docker workspaces and improved MCP connection cleanup.
  • Web UI Polish: Chat experience improvements including session auto-naming, query caching, and better dark mode support.
