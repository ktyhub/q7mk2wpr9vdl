Cherry Studio 2.1.8 – Bearbeitungs-, Sprach- und Integrationsaktualisierungen

✨ Neue Funktionen

  • [Dateibearbeitung] Isolieren Sie Entwürfe über Notizen, Fähigkeiten und Artefakte hinweg, behalten Sie fehlgeschlagene Bearbeitungen für einen erneuten Versuch bei und unterstützen Sie bis zu 8 MiB Textbearbeitung und Vorschau.
  • [Sprache] Fügen Sie italienische (it-IT) UI-Unterstützung mit vollständigen Übersetzungen und Emoji-Auswahl hinzu.
  • [Sprache] Halten Sie die Maustaste in einer Texteingabe gedrückt, um das Diktat zu starten, und lassen Sie sie los, um zu transkribieren.
  • [Sprache] Streaming-Sprachsynthese mit Echtzeit-Audiowiedergabe.
  • [Websuche] Tencent Yuanbao Search als integrierten Anbieter hinzufügen.
  • [Geplante Aufgaben] Erstellen und verwalten Sie geplante Aufgaben über einen Agenten-Chat mit einer interaktiven Aufgabenkarte.
  • [Screenshot] Kopieren Sie die Aufnahme auf clipboard, während Sie das Overlay geöffnet lassen.
  • [Auswahl] Wählen Sie Text an einer beliebigen Stelle aus, um ihn automatisch zu kopieren und eine Symbolleiste für schnelle Anführungszeichen anzuzeigen.
  • [Composer] Datei- und Link-Tokens werden an der Textzeile ausgerichtet, zeigen Dateisymbole pro Typ an und laden Favicons während der Bearbeitung.
  • [RTF] Vorschau von Rich Text Format-Dateien als formatierte Dokumente.
  • [Feishu] Konfigurieren Sie, ob der Bot nur auf @Erwähnungen in Gruppenchats antwortet.
  • [Fernzugriff] Legen Sie einen benutzerdefinierten Hostnamen, eine IP oder einen Port für die Kopplung von Einladungen fest.
  • [Assistent] Denken Sie bei zukünftigen Archiven an die Auswahl „Auch archivbezogene Themen“.

🐛 Fehlerbehebungen

  • [Notizen] Korrigieren Sie, dass Notizinhalte beim Wechseln zwischen zwischengespeicherten Notizen überschrieben werden.
  • [Skills] Zeigt lokalisierte Fehlermeldungen an, wenn in einer ZIP-Datei oder einem Ordner SKILL.md fehlt, ohne dass temporäre Pfade verloren gehen.
  • [Chat] Lange Benutzernachrichten standardmäßig erweitern; Halten Sie Folgewarteschlangen unabhängig von Lesebestätigungen.
  • [Proxy] Entspricht kurzen Wildcard-IP-Bypass-Regeln wie 192.168.* unter Windows.
  • [Claude Code] Behalten Sie das 1-Millionen-Kontextbudget beim Routing über das interne Gateway bei.
  • [Tab-Leiste] Durch Schließen des letzten Tabs wird das Launchpad geöffnet, anstatt die App zu beenden.
  • [Dateivorschau] Lesestatus beim Aktualisieren von Dateien beibehalten; Zeilenabstand für Word-Dokumente korrigieren.
  • [Seitenleiste] Ausgewählte Einträge verwenden neutral gefüllte Symbole sowohl in hellen als auch in dunklen Themen.
  • [Chat-Layout] Isolieren Sie den Erweiterungsstatus der Listengruppe pro Fenster.
  • [Gemälde] Begrenzen Sie die Ladegitterdichte, um Leistungsproblemen vorzubeugen.
  • [MCP] Behalten Sie literale #-Zeichen in gespeicherten Headern und Umgebungswerten bei.
  • [Wissen] Versenden Sie einen Basis-SQLite-VEC-Build für Linux x64.
  • [Sprache] Diagnose für Betriebsfehler und Stream-Timeouts hinzufügen.
  • [Agentensitzung] Setzen Sie den Zielarbeitsbereich fort, wenn Sie mehrere Agenten erstellen. Fehler bei der Oberflächenverdichtung.
  • [Meldungen] Löschen historischer Werkzeugteile mit inkompatiblen Wiedergabeeingaben.
  • [Virtuelle Liste] Übergeben Sie klebrige Kopfzeilen an die Unterseite des angehefteten Stapels.
  • [Notizen] Es wurde ein Problem behoben, bei dem das Schließen des Konfliktdialogs „Notiz auf Festplatte geändert“ dazu führte, dass die Editorsitzung hängen blieb und alle späteren Umbenennungen, Löschungen und Verschiebungen von Notizen mit irreführenden Fehlern fehlschlugen.

🔒 Sicherheit

  • [Electron] Upgrade auf 44.9.3 für Korrekturen der Zertifikatssicherheit.
</details>

<details> <summary>Release Notes</summary>

Cherry Studio 2.1.8 - Editing, Voice, and Integration Updates

✨ New Features

  • [File Editing] Isolate drafts across notes, skills and artifacts, retain failed edits for retry, and support up to 8 MiB text editing and previews.
  • [Language] Add Italian (it-IT) UI support with full translations and emoji picker.
  • [Voice] Hold the mouse button in a text input to start dictation, release to transcribe.
  • [Voice] Streaming speech synthesis with real-time audio playback.
  • [Web Search] Add Tencent Yuanbao Search as a built-in provider.
  • [Scheduled Tasks] Create and manage scheduled tasks through an agent chat with an interactive task card.
  • [Screenshot] Copy the capture to clipboard while keeping the overlay open.
  • [Selection] Select text anywhere to automatically copy it and show a quick-quote toolbar.
  • [Composer] File and link tokens align with the text line, show per-type file icons, and load favicons while editing.
  • [RTF] Preview Rich Text Format files as formatted documents.
  • [Feishu] Configure whether the bot only replies to @mentions in group chats.
  • [Remote Access] Set a custom hostname, IP or port for pairing invitations.
  • [Assistant] Remember the “Also archive related topics” choice for future archives.

🐛 Bug Fixes

  • [Notes] Fix note content being overwritten when switching between cached notes.
  • [Skills] Show localized error messages when a ZIP or folder is missing SKILL.md, without leaking temporary paths.
  • [Chat] Expand long user messages by default; keep follow-up queues independent of read receipts.
  • [Proxy] Match short wildcard IP bypass rules like 192.168.* on Windows.
  • [Claude Code] Keep the 1M context budget when routing through the internal gateway.
  • [Tab Bar] Closing the last tab opens the Launchpad instead of quitting the app.
  • [File Preview] Preserve reading state when refreshing files; fix line spacing for Word documents.
  • [Sidebar] Selected entries use neutral filled icons in both light and dark themes.
  • [Chat Layout] Isolate list-group expansion state per window.
  • [Paintings] Cap loading grid density to prevent performance issues.
  • [MCP] Keep literal # characters in saved headers and environment values.
  • [Knowledge] Ship a baseline sqlite-vec build for Linux x64.
  • [Voice] Add diagnostics for operation failures and stream timeouts.
  • [Agent Session] Continue the target workspace when creating across agents; surface compaction failures.
  • [Messages] Drop historical tool parts with incompatible replay inputs.
  • [Virtual List] Hand sticky headers over at the pinned stack bottom.
  • [Notes] Fixed an issue where dismissing the "note changed on disk" conflict dialog left the editor session stuck, failing all later note renames, deletions, and moves with misleading errors.

🔒 Security

  • [Electron] Upgrade to 44.9.3 for certificate security fixes.
