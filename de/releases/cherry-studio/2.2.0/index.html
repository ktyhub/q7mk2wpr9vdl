Cherry Studio 2.2.0 – Skill Marketplace, Benachrichtigungen und Agent Runtime

✨ Neue Funktionen

  • [Marktplatz] Durchsuchen Sie Fertigkeitskataloge, externe Fertigkeitsquellen, Agentenvorlagen und MCP-Ressourcen in einem Marktplatz, mit geführter Installation und gezielter MCP- und Fertigkeitsverwaltung.
  • [Benachrichtigungen] Eine neue Benachrichtigungsschublade neben der Seitenleiste sammelt Aufgabenergebnisse und offizielle Ankündigungen, mit Ungelesen-Anzeigen, Antwortvorschauen und Ankündigungen, die in Ihrer Sprache angezeigt werden.
  • [Geplante Aufgaben] Geplante Aufgaben verfügen jetzt über eine eigene Seitenleiste mit Aufgabengesprächen, paginiertem Ausführungsverlauf und Verwaltung für abgeschlossene oder verpasste Aufgaben. Die doppelte Einstellungsseite wurde entfernt.
  • [Cherry Cloud] Abonnementnutzung und monatliche Kontingente werden in den Einstellungen und im Kontobereich angezeigt, mit Planabzeichen, Abonnementeinstiegspunkten, einem Kontingenthinweis über der Eingabe und einem Hinweis, wenn ein Abonnement aktiv wird.
  • [Auswahlassistent] Agent fragen und agentengebundene Aktionen öffnen ein spezielles Agentenfenster für den ausgewählten Text. Fenster können in Kapseln zusammengeklappt werden, den Regeln für das automatische Schließen folgen und die Sitzung im Hauptfenster fortsetzen. – [Agent] Neue Agenten verwenden standardmäßig die Pi-Durable-Laufzeitumgebung, die Sitzungen nativ beibehält und Hintergrund-Subagenten unabhängig streamt. Sitzungen können an abgeschlossenen Kontrollpunkten verzweigt werden, während der unabhängige Status erhalten bleibt.
  • [Agent] Agentenspeicher in der Agentenkonfiguration anzeigen und bearbeiten.
  • [Agent] Sitzungsdetails zeigen gruppierte Subagenten, den Aufgabenfortschritt und die Kontextnutzung auf einer kompakten Karte.
  • [Agent] Bearbeiten und erneut senden ersetzt jetzt die Nachricht und entfernt alles danach, ohne eine weitere Verlaufsversion zu erstellen. Dateien werden nicht wiederhergestellt; Geben Sie zuerst den Fork ein, um die ursprüngliche Konversation beizubehalten.
  • [Chat] CliKlicken Sie auf den Verzweigungszähler einer Nachricht, um zwischen alternativen Antworten zu wechseln, mit Vorschau im Umschalter.
  • [Chat] Generierte Bilder bieten die Verwendung als Referenz für Modelle, die Bildeingaben akzeptieren.
  • [Gemälde] GPT-Bild 2.6 Flare und Sunburst unterstützen Szenenkomplexität und animierte GIF-Ausgabe, und ComfyUI-Workflows können angehängte Eingabebilder verwenden. – [Modelle] LongCat 2.5 und Hunyuan 4 mit Bildeingabe hinzugefügt, plus Argumentationsaufwandskontrollen für Qwen 3.8 Flash Next.
  • [Dateien] Kopieren Sie eine Datei oder einen Ordner selbst aus dem Agent-Dateibereich in das System clipboard.
  • [Notizen] Speichern Sie den ausgewählten Konversationstext in Notizen und verweisen Sie mit @ auf Notizen aus der Chat-Eingabe.
  • [Übersetzen] Kopieren Sie eine fertige Übersetzung als PNG-Bild in voller Länge.
  • [Exportieren] Exportieren Sie MCP-Serverkonfigurationen als JSON und exportieren Sie mehrere Assistenten als eine Datei.
  • [Skills] Wählen Sie aus, welche verwalteten Skills für externe Agenten nach ~/.agents/skills exportiert werden.
  • [Verknüpfungen] Zahlenverknüpfungen wechseln zwischen Konversationen und Registerkarten und neue Verknüpfungen wechseln zwischen Assistenten und Themen; Alles kann in den Einstellungen angepasst werden.
  • [Konversationen] Löschen Sie Konversationen dauerhaft aus den Menüs „Liste“, „Mehr“ und „Verlauf“ und löschen Sie Besitzer aus Listen- und Gruppenmenüs, nachdem das Element durch eine Bestätigung benannt wurde.
  • [Markdown] Bloße Bild-URLs in Antworten werden jetzt als Inline-Bilder gerendert.
  • [Mini Apps] Der Katalog verfügt über neue Kreativ- und Produktivitätsseiten und über das Menü „Mehr“ kann eine MiniApp neu gestartet werden.
  • [HTML-Artefakt] Kopieren Sie die Quelle eines HTML-Artefakts aus seiner Inline-Quellensymbolleiste.

💄 Verbesserungen

  • [Chat] Regenerate ist unterhalb von Benutzernachrichten verfügbar und verwendet das aktuell ausgewählte Modell.
  • [Chat] Gesprächsanker erscheinen ab der ersten Runde; Die separate seitliche Navigationssymbolleiste wurde zugunsten des unteren Pfeils eingestellt. – [Agent] Die Kontextnutzung meldet Laufzeitkapazität, geschätzte Kategorien und Ressourcen konsistent über Laufzeiten hinweg, einschließlich Subagenten.
  • [Agent] Das Wechseln des Berechtigungsmodus während der Ausführung einer Aufgabe gilt für den nächsten Tool-Aufruf, anstatt auf die nächste Nachricht zu warten. – Die Modi „[Agent] Plan“ und „Ziel“ sind als explizite Quick Panel-Aktionen verfügbar und nicht unterstützte Verlaufsaktionen sind deaktiviert.
  • [Benutzeroberfläche] Kontextmenü-Verknüpfungen werden als kompakte Tastenkappen dargestellt, Größenänderungsgriffe verwenden neutrale Farben und clippped-Unterlängen für Buchstaben wurden behoben.
  • [Dateivorschau] Word-Vorschauen passen in den Bereich und mehr Dateitypen zeigen die richtigen Symbole und Beschriftungen an. – [Modelle] Qwen AI Platform und Qwen Cloud-Branding, Links und Standard-API-Endpunkte werden aktualisiert. Qwen-Token-Plan-Schlüssel funktionieren jetzt mit der Bildgenerierung.
  • [Claude] Das Runtime-Download-Banner wird korrekt angezeigt und die Runtime heißt Claude.
  • [Einstellungen] Beim Zurücksetzen eines benutzerdefinierten Anbieters fragt der API-Host nach einer Bestätigung.
  • [Über] Vereinfachte Produktinformationen mit einer Sternschaltfläche, E-Mail-Kontakt und unten angedockten DevTools.
  • [Websuche] Eine Warnung nennt jetzt den Anbieter, der tatsächlich eine Suche durchgeführt hat, wenn er zurückgreift.

Cherry Studio 2.2.0 - Skill Marketplace, Notifications, and Agent Runtime

✨ New Features

  • [Marketplace] Browse skill catalogs, external skill sources, Agent templates, and MCP resources in one Marketplace, with guided installation and focused MCP and skill management.
  • [Notifications] A new notification drawer beside the sidebar gathers task results and official announcements, with unread indicators, reply previews, and announcements shown in your language.
  • [Scheduled Tasks] Scheduled tasks now have a dedicated sidebar page with task conversations, paginated run history, and management for completed or missed tasks. The duplicate Settings page was removed.
  • [Cherry Cloud] Subscription usage and monthly quotas appear in Settings and the account panel, with plan badges, subscribe entry points, a quota notice above the input, and a notice when a subscription becomes active.
  • [Selection Assistant] Ask Agent and agent-bound actions open a dedicated agent window for the selected text. Windows can collapse into capsules, follow auto-close rules, and continue the session in the main window.
  • [Agent] New agents default to the Pi Durable runtime, which persists sessions natively and streams background subagents independently. Sessions can fork at completed checkpoints while keeping independent state.
  • [Agent] View and edit agent memory from Agent configuration.
  • [Agent] Session details show grouped subagents, task progress, and context usage in a compact card.
  • [Agent] Edit and resend now replaces the message and removes everything after it without creating another history version. Files are not restored; fork first to keep the original conversation.
  • [Chat] Click the branch counter on a message to jump between alternate replies, with previews in the switcher.
  • [Chat] Generated images offer Use as Reference for models that accept image input.
  • [Paintings] GPT Image 2.6 Flare and Sunburst support scene complexity and animated GIF output, and ComfyUI workflows can use attached input images.
  • [Models] Added LongCat 2.5 and Hunyuan 4 with image input, plus reasoning-effort controls for Qwen 3.8 Flash Next.
  • [Files] Copy a file or folder itself to the system clipboard from the Agent file pane.
  • [Notes] Save selected conversation text to Notes, and reference Notes from the chat input with @.
  • [Translate] Copy a completed translation as a full-length PNG image.
  • [Export] Export MCP server configurations as JSON and export multiple assistants as one file.
  • [Skills] Choose which managed skills are exported to ~/.agents/skills for external agents.
  • [Shortcuts] Number shortcuts switch conversations and tabs, and new shortcuts switch assistants and topics; all can be customized in Settings.
  • [Conversations] Permanently delete conversations from list, More, and History menus, and delete owners from list and group menus, after a confirmation that names the item.
  • [Markdown] Bare image URLs in responses now render as inline images.
  • [Mini Apps] The catalog has new creative and productivity sites, and the More menu can restart a MiniApp.
  • [HTML Artifact] Copy an HTML artifact's source from its inline source toolbar.

💄 Improvements

  • [Chat] Regenerate is available below user messages and uses the currently selected model.
  • [Chat] Conversation anchors appear from the first turn; the separate side navigation toolbar was retired in favor of the bottom arrow.
