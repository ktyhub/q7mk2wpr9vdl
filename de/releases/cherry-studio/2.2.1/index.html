Cherry Studio 2.2.1 – Remote-Aufgaben, Suchanbieter und Agent-Korrekturen

✨ Neue Funktionen

  • [Aufgaben] Remote-clients können Konversationen über geplante Aufgabenergebnisse erkennen und Aufgabenpläne, den Ausführungsverlauf und begrenzte Zusammenfassungen abfragen. Aufgabenkonversationen bleiben nach der Bereinigung der Ausführungsdatensätze erkennbar.
  • [Modelle] Rapid-MLX ist als integrierter, schlüsselloser lokaler Anbieter erhältlich.
  • [Websuche] SerpKite- und StepFun-Schlüsselwortsuchanbieter hinzugefügt, und Exa kann jetzt den Inhalt einer URL über seine Inhalte API abrufen.
  • [Dateien] Wenn Sie eine Markdown-Datei (.md, .markdown, .mdx) im App-Fenster ablegen, wird sie in der schreibgeschützten Vorschau geöffnet.
  • [Agent] System- und globale Paketinstallationen erfordern jetzt eine Genehmigung im normalen Modus und werden im Vollzugriff ausgeführt, anstatt in jedem Modus blockiert zu werden.
  • [Agent] Agenten und Assistenten können ein hochgeladenes Bild als ihren Avatar verwenden, der in Katalogen, Selektoren, Konversationen, Nachrichtenkopfzeilen und Symbolen auf der Registerkarte „Arbeit“ angezeigt wird. Bestehende Emoji-Avatare bleiben unverändert.
  • [Agent] Arbeitsbereich und Agentengruppen können im oberen Bereich „Angeheftet“ angeheftet werden, während ihre Aufgaben erweiterbar bleiben.
  • [Agent] Computernutzungsaufrufe zeigen die von ihnen betriebenen Anwendungen an, und in den Sitzungsdetails werden dieselben App-Symbole angezeigt.
  • [Agent] Subagentenaufrufe können sowohl einen Anbieter als auch ein Modell benennen, und die Unteraufgabenzeile zeigt das angeforderte Modell.
  • [Composer] Wenn das Rendern von Markdown-Eingaben aktiviert ist, wird Markdown live in der Vorschau angezeigt, während Sie Chat, Agent und die Auswahlleiste zum Verfassen eingeben. Markierungen werden angezeigt, wenn die Einfügemarke sie erreicht und der gesendete Text unverändert bleibt.
  • [Composer] In der Markdown-Vorschau kann ausgewählter Text mit Cmd/Strg+B, Cmd/Strg+I und einem Backtick fett, kursiv oder im Inline-Code dargestellt werden.
  • [Composer] In der Markdown-Vorschau werden eingezäunte Codeblöcke als hervorgehobener Codebereich gerendert, wobei Enter eine neue Zeile einfügt, Tabulatoreinzug erfolgt, automatische Klammerpaarung erfolgt und Variablen oder Verknüpfungen literal innerhalb des Zauns bleiben.
  • [Browser] Neue Registerkarten im integrierten Browser können mit einer leeren Seite, der zuletzt geöffneten Seite oder einer benutzerdefinierten URL beginnen.
  • [Wissen] OpenDocument-Dateien (.odt, .odp, .ods) und RTF-Dateien (.rtf) können als Wissensquellen hinzugefügt werden.
  • [API Gateway] CherryAI-Abonnementmodelle sind für externe clients und Code Mate über das Gateway unter Verwendung des Kontingents des angemeldeten Kontos verfügbar.

💄 Verbesserungen – [Agent] Pi und Pi Durable nutzen die native Komprimierung ihrer Laufzeiten und behalten die Fehlerdetails des Anbieters bei.

  • [Agent] In den Sitzungsdetails werden die Anwendungen aufgelistet, die ein Agent steuert, mit ihrem Status und einer Stop-Aktion.
  • [Chat] Die Zweigkarte lokalisiert den aktiven Zweigknoten und kann beim Scrollen verschoben werden.
  • [Modelle] Der Schieberegler für den Denkaufwand folgt dem Ziehen reibungslos, stellt sich auf die Aufwandsstufen ein und berücksichtigt die Einstellungen für reduzierte Bewegung.
  • [Modelle] Abgeschnittene Modellnamen in der Modellauswahl zeigen den vollständigen Namen an, wenn Sie mit der Maus darüber fahren, und die Karte mit den Modelldetails zeigt sie nicht mehr an.
  • [Geplante Aufgaben] Die Ankernavigation bleibt ausgerichtet, während der Verlauf geladen wird, und Zusammenfassungen fehlgeschlagener Ausführungen zeigen Fehlerdetails in einer QuickInfo an.
  • [Dateien] Dateilisten und Raster zeigen den Quellpfad jeder Datei im Namens-Tooltip an, sodass Dateien mit demselben Namen unterschieden werden können.
  • [Prompt Polish] Zeigt das Standardmodell mit einem Link zu seinen Einstellungen an und unterscheidet Zeitüberschreitungen, fehlende Modelle, leere Antworten und Anbieterfehler.
  • [Feedback] Das Anhängen von Diagnosen an einen Problembericht ist jetzt optional.
  • [macOS] Das DMG-Installationsprogramm hat einen neuen Hintergrund und ein größeres, zentriertes Drag-to-Applications-Layout.
  • [Assistent] Der englische Standardassistent heißt jetzt „Cherie“.
  • [UI] Erweiterte Benachrichtigungsstapel clip ihre Schatten nicht mehr.

🐛 Fehlerbehebungen – [Agent] Verschachtelte Shell-, Datei- und Artefakt-Tool-Ergebnisse im Pi- und Pi-Durable-Codemodus werden erneut angezeigt, auch nach dem erneuten Öffnen einer Konversation.

  • [Agent] Pi-Shell-Befehle ohne explizites Timeout warten nicht mehr auf unbestimmte Zeit.
  • [Agent] Das Schließen einer Sitzung unterbricht zuerst die Arbeit von Claude und bei unterbrochenen Claude-Code-Runden wird nicht mehr „Keine Antwort angefordert“ angezeigt. Platzhalter. – [Agent] Fork und Edit & Resend funktionieren nach einer /compact-Grenze und Fork lehnt eine gesunde Claude-Sitzung mit leeren Rahmenlinien nicht mehr ab.
  • [Agent] Im Schrittfenster wird eine abgeschlossene Runde nicht mehr als ausgeführt angezeigt und vom Agenten gelöschte Aufgaben verschwinden aus der Liste.
  • [Agent] In der oberen Leiste des Agenten werden nach der ersten Nachricht der Name des Arbeitsbereichs und die Aktion zum Öffnen des Verzeichnisses angezeigt.
  • [Agent] Die Ausgabe des Subagenten und die Fortsetzung des Hauptagenten werden im offenen Gespräch in der richtigen Reihenfolge angezeigt. – [Agent] Ziele werden abgeschlossen, wenn das verifizierende Modell sein Urteil in einen Codeblock oder zusätzlichen Text einschließt.
  • [Agent] Fehler bei der Bearbeitung von Agent-Nachrichten zeigen vollständige, dauerhafte Erklärungen mit kopierbaren Diagnosen an.
  • [Agent] Das Kontextnutzungsfeld zeigt konfigurierte MCP-Servernamen anstelle von IDs an.
  • [Agent] Agentenübergreifende Sitzungskarten benennen den Zielagenten.
  • [Agent] Assistant-Antworten in Arbeitskonversationen bieten nicht mehr „Löschen“ an, da durch das Löschen das Laufzeittranskript nicht entfernt werden kann.
  • [Agent] Beim Bearbeiten einer Nachricht wird eine Bestätigung verlangt, bevor der spätere Konversationsverlauf ersetzt wird. – [Agent] Markdown-Artefakte können in einer Agentenkonversation in der Vorschau angezeigt werden, auch wenn der Arbeitsbereich leer ist.
  • [Agent] Die Symbole der Registerkarte „Arbeit“ werden aktualisiert, wenn sich der Agenten-Avatar ändert, während die Registerkarte ausgeblendet ist.
  • [Chat] Links in gesendeten Nachrichten können reibungslos und ohne versehentliche Navigation ausgewählt werden.
  • [Chat] Beim Bearbeiten einer Nachricht werden keine Zeichen mehr gelöscht, die direkt nach dem Klicken auf „Bearbeiten“ eingegeben wurden.
  • [Chat] Ein in älteren Nachrichten zweimal gespeicherter Fehler zeigt jetzt eine Fehlerkarte an.
  • [Chat] Leere oder fehlerhafte API-Antworten zeigen eine klare Diagnose mit Wiederholungsanweisungen anstelle eines unbekannten Fehlers.
  • [Chat] Die Branch-Switch-Warnung „Nachricht wird noch synchronisiert“ ist lokalisiert.
  • [Hinweise] Die Hervorhebung der Codesyntax verschwindet nicht mehr im Editor.
  • [Verknüpfungen] Verknüpfungen für Konversationsnummern funktionieren nach dem ersten Wechsel weiter, ohne dass das Fenster neu fokussiert wird.
  • [Browser] Seitenladefehler verwenden eine generische Meldung, anstatt darauf hinzuweisen, dass ein lokaler Server gestoppt wurde.
  • [Mini Apps] Website-MiniApp-Anmelde-Popups bleiben in ihrer dauerhaften Sitzung.
  • [Wissen] Fehlgeschlagene Wissenselemente zeigen den Fehlergrund an und leere Extraktionsmeldungen werden lokalisiert.
  • [Geplante Aufgaben] Cron-Timeouts funktionieren mit Gemini-kompatiblen Laufzeiten und das Löschen einer Aufgabe mit mehr als etwa 32.000 Sitzungen schlägt nicht mehr fehl. – [Anbieter] Anfragen schlagen nicht mehr fehl, wenn ein client-Tool einen leeren Namen hat. – [Claude] Claude Code erstellt seinen Laufzeitordner, bevor ein Download bereitgestellt wird, sodass Installationen bei einem fehlenden Ordner nicht mehr fehlschlagen.
  • [Gemälde] SiliconFlow MOSS-Bildanfragen schlagen nicht mehr fehl, wenn keine Bildgröße ausgewählt ist.
  • [Code] Codex CLI behält das Kontextfenster und die Komprimierungsgrenze des ausgewählten Modells bei, wenn seine Konfiguration neu erstellt wird.
  • [UI] Agent-Sitzungsdetails überfüllen den Inhalt nicht mehr und überlappen nicht mehr die Dateivorschau.

⚡ Leistung

  • [Agent] Zweigwechsel und Nachrichtenbearbeitung sind in langen Sitzungen schneller.

<details> <summary>Release Notes</summary>

Cherry Studio 2.2.1 - Remote Tasks, Search Providers, and Agent Fixes

✨ New Features

  • [Tasks] Remote clients can discover scheduled-task result conversations and query task schedules, run history, and bounded summaries. Task conversations remain discoverable after run records are cleaned up.
  • [Models] Rapid-MLX is available as a built-in, keyless local provider.
  • [Web Search] Added SerpKite and StepFun keyword search providers, and Exa can now fetch the content of a URL through its Contents API.
  • [Files] Dropping a Markdown file (.md, .markdown, .mdx) onto the app window opens it in the read-only preview.
  • [Agent] System and global package installs now ask for approval in normal modes and run in Full Access, instead of being blocked in every mode.
  • [Agent] Agents and assistants can use an uploaded image as their avatar, shown in catalogs, selectors, conversations, message headers, and Work tab icons. Existing emoji avatars are unchanged.
  • [Agent] Workspace and agent groups can be pinned to the top Pinned section while their tasks stay expandable.
  • [Agent] Computer Use calls show the applications they operated, and session details show the same app icons.
  • [Agent] Subagent calls can name both a provider and a model, and the subtask row shows the requested model.
  • [Composer] With Markdown input rendering enabled, Markdown is previewed live while typing in Chat, Agent, and the selection compose bar; markers appear when the caret reaches them and the sent text is unchanged.
  • [Composer] In the Markdown preview, selected text can be made bold, italic, or inline code with Cmd/Ctrl+B, Cmd/Ctrl+I, and a backtick.
  • [Composer] In the Markdown preview, fenced code blocks render as a highlighted code region, with Enter inserting a newline, Tab indenting, automatic bracket pairing, and variables or shortcuts staying literal inside the fence.
  • [Browser] New tabs in the built-in browser can start from a blank page, the last opened page, or a custom URL.
  • [Knowledge] OpenDocument (.odt, .odp, .ods) and RTF (.rtf) files can be added as knowledge sources.
  • [API Gateway] CherryAI subscription models are available to external clients and Code Mate through the gateway using the signed-in account's quota.

💄 Improvements

  • [Agent] Pi and Pi Durable use their runtimes' native compaction and keep provider error details.
  • [Agent] Session details list the applications an agent is controlling, with their status and a Stop action.
  • [Chat] The branch map locates the active branch node and can be panned on scroll.
  • [Models] The reasoning-effort slider follows dragging smoothly, settles onto effort levels, and respects reduced-motion settings.
  • [Models] Truncated model names in the model selector show the full name on hover, and the model details card no longer clips them.
  • [Scheduled Tasks] Anchor navigation stays aligned while history loads, and failed run summaries show error details in a tooltip.
  • [Files] File lists and grids show each file's source path in the name tooltip so same-name files can be distinguished.
  • [Prompt Polish] Shows the default model with a link to its settings and distinguishes timeouts, missing models, empty responses, and provider failures.
  • [Feedback] Attaching diagnostics to a problem report is now optional.
  • [macOS] The DMG installer has a new background and a larger, centered drag-to-Applications layout.
  • [Assistant] The English default assistant is now named "Cherie".
  • [UI] Expanded notification stacks no longer clip their shadows.

🐛 Bug Fixes

  • [Agent] Nested shell, file, and artifact tool results in Pi and Pi Durable codemode are shown again, including after reopening a conversation.
  • [Agent] Pi shell commands without an explicit timeout no longer wait indefinitely.
  • [Agent] Closing a session interrupts Claude work first, and interrupted Claude Code turns no longer show a "No response requested." placeholder.
  • [Agent] Fork and Edit & Resend work after a /compact boundary, and fork no longer rejects a healthy Claude session with blank framing lines.
  • [Agent] The Step panel no longer shows a finished turn as running, and tasks deleted by the agent leave the list.
  • [Agent] The Agent top bar keeps the workspace name and open-directory action after the first message.
  • [Agent] Subagent output and the main agent's continuation appear in the correct order in the open conversation.
  • [Agent] Goals complete when the verifying model wraps its verdict in a code block or extra text.
  • [Agent] Agent message edit failures show complete, persistent explanations with copyable diagnostics.
  • [Agent] The context usage panel shows configured MCP server names instead of IDs.
  • [Agent] Cross-agent session cards name the target agent.
  • [Agent] Assistant replies in Work conversations no longer offer Delete, because deleting them cannot remove the runtime transcript.
  • [Agent] Editing a message asks for confirmation before replacing later conversation history.
  • [Agent] Markdown artifacts can be previewed from an Agent conversation even when the workspace is empty.
  • [Agent] Work tab icons update when the agent avatar changes while the tab is hidden.
  • [Chat] Links in sent messages can be selected smoothly, without accidental navigation.
  • [Chat] Editing a message no longer drops characters typed right after clicking Edit.
  • [Chat] An error saved twice in older messages now shows one error card.
  • [Chat] Empty or malformed API responses show a clear diagnosis with retry guidance instead of an unknown error.
  • [Chat] The "message is still syncing" branch-switch warning is localized.
  • [Notes] Code syntax highlighting no longer disappears in the editor.
  • [Shortcuts] Conversation number shortcuts keep working after the first switch without refocusing the window.
  • [Browser] Page-load failures use a generic message instead of suggesting that a local server stopped.
  • [Mini Apps] Website MiniApp sign-in popups stay in their persistent session.
  • [Knowledge] Failed knowledge items show the failure reason, and empty extraction messages are localized.
  • [Scheduled Tasks] Cron timeouts work with Gemini-compatible runtimes, and deleting a task with more than about 32,000 sessions no longer fails.
  • [Providers] Requests no longer fail when a client tool has a blank name.
  • [Claude] Claude Code creates its runtime folder before staging a download, so installs no longer fail on a missing folder.
  • [Paintings] SiliconFlow MOSS Image requests no longer fail when no image size is selected.
  • [Code] Codex CLI keeps the selected model's context window and compaction limit when its configuration is rebuilt.
  • [UI] Agent Session Details no longer crowds its content or overlaps the file preview.

⚡ Performance

  • [Agent] Branch switching and message editing are faster in long sessions.
