cherry-studio v1.7.1

Highlights

  • Streaming tool-call assembly — PR #11533 now matches tool-call chunks by tool ID instead of arrival order. For anyone building on agentic, multi-tool workflows, this prevents argument fragments from concurrent calls being merged into the wrong invocation — the kind of silent corruption that yields malformed tool inputs under parallel execution. Re-test streaming tool use if you lean on it heavily.
  • Reasoning-effort semantics split — PR #11562 separates undefined (omit the field, defer to provider default) from none (explicitly disable reasoning). Collapsing those two could send unsupported values upstream or silently toggle thinking on models where it should be off, so this is a behavioral correctness fix, not cosmetic. Combined with NaN thinking-timer guards (#11556) and corrected trace token accounting (#11575), reasoning-model output and usage/cost telemetry get materially more reliable.
  • Gateway and provider endpoint compatibility — PR #11543 fixes Gemini API-version detection for Cloudflare Gateway URLs, whose rewritten paths can drop the version segment. #11545 comments out the Anthropic CONTEXT_100M_HEADER and moves it under user preferences, so the 1M-context flag is no longer injected unconditionally — important if you proxy or gate Anthropic traffic. #11552 addresses doubao model inference. If you route through a gateway, re-validate your provider connections after upgrading.
  • Windows non-ASCII username fix — PR #11550 sets CLAUDE_CONFIG_DIR explicitly to sidestep path-encoding failures on Windows accounts with non-ASCII characters. Previously that broke Claude Code subprocess config paths; it's a real unblock for international/Windows-based teams.
  • State loss and diagnostics — PR #11558 persists composer text via a global variable cache so switching tabs no longer discards what you've typed, and #11577 makes the API-check path surface stream errors instead of masking them — connection tests now fail loudly rather than reporting false success. Rounding it out: JPEG image copy (#11529), home scroll stability (#11576), always-visible knowledge-base tool (#11553), and BashTool command display / ToolTitle layout (#11572).

No breaking changes.
