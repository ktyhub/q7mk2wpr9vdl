cherry-studio v1.7.25

Highlights

  • Model & provider coverage — Adds GPT-5.4 support with auto-fallback for future GPT-5.x sub-versions (#13293), improves Qwen 3.5 reasoning detection and thinking-param handling (#13235), and corrects Gemini reasoning params for "none" effort and Gemini 3 thinkingLevel (#13388) while persisting thought signatures for conversation replay (#13100). Extended thinking and the API server now also work with local providers ollama, new-api and aihubmix (#12796), and new options arrive via MiniMax Global, Z.ai, MiniMax Agent/IMA mini apps (#13099) and the Querit search provider (#13050). Matters if you rely on current models — several fixes target incorrect reasoning/thinking params that would otherwise silently degrade output quality.
  • xAI search & OpenClaw/Agent changes (migration attention) — xAI web search is migrated off the deprecated Live Search to the Responses API (#12812); anyone with an xAI search config should re-verify it. OpenClaw is refactored to a unified openclaw package with openclaw-zh removed (#13436), plus binary-download install, auto-update checks and a gateway refactor (#13165), and agents.db now resolves to the same path in dev and prod (#13392). No formal breaking-change notice, but users of openclaw-zh or custom agent DB paths should check their setup after upgrading.
  • API server & tool-permission hardening — Chat completion validation is relaxed for tool-calling messages (#13279) and reasoning_effort is auto-converted to reasoningEffort for OpenAI-compatible providers (#12831). On the agent side, hub invoke/exec now checks underlying tool permissions (#13282), approval countdown timers are replaced by system notifications (#13281), abort correctly stops agent tool status (#13111), and built-in filesystem MCP root handling is secured (#13294). Note: app launch is now tracked as an analytics event on startup (#13334) — relevant if you care about telemetry.
  • Dependencies & stability — Electron is upgraded 40.6.1 → 40.8.0 (#13288) and @anthropic-ai/claude-agent-sdk 0.2.56 → 0.2.71 (#13339), alongside fixes for single-conversation renderer memory leaks (#13113), auto backup deferring during streaming (#13307), knowledge-base toast storms (#13284), and Windows spawn ENOENT for Code Tools (#13405). Worth upgrading for anyone hitting those crashes/leaks or wanting current security patches.
  • Upgrade verdict — This is a genuine feature-and-fix release, not a no-op, re-tag or metadata-only change. Recommended for users who want the new model support (GPT-5.4, Gemini 3, Qwen 3.5) or OpenClaw/agent improvements; those stable on v1.7.24 with no need for these models or features can safely skip. The only items likely to need manual follow-up are the xAI Live Search → Responses API migration, removal of openclaw-zh, and the agents.db path change — no other breaking changes are flagged.
