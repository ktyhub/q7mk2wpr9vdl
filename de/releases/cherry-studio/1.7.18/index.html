cherry-studio v1.7.18

Highlights

  • Agent tooling — Adds OpenCode CLI support, external-editor access for agent workspaces, an AskUserQuestion tool renderer, and loading of CLAUDE.local.md. Agent workflows also get clearer Claude Code language instructions and more reliable scrolling after sending messages; upgrade if you use these agent features.
  • Models and reasoning — Adds Claude Opus 4.6 and PPIO painting models, adds qwen3-max reasoning support, normalizes Fireworks model IDs, refines Together and DashScope reasoning controls, and removes the DeepSeek v3.1+ provider whitelist. Kimi K2.5 now has temperature and top_p disabled. Breaking change: generation settings for Kimi K2.5 must be changed elsewhere rather than supplied through those controls.
  • Compatibility and reliability — Fixes Gemini OpenAI-compatible thought signatures and missing tool_call indexes, corrects the openai-compatible strictJsonSchema patch, fixes WriteTool streaming and duplicate React keys, and adds PP-OCRv5 support with corrupted-PDF handling. Particularly worth upgrading if these integrations previously failed.
  • Windows and data safety — Improves Dock/Finder npm detection, avoids Windows MAX_PATH, EPERM, and stale shell-environment problems, adds an OpenClaw Git check, moves agents.db into the Data/ directory, and isolates Cherry Studio’s OpenClaw configuration. Windows users and anyone backing up or reinstalling should upgrade; no manual migration is stated.
  • Workflow and UI polish — Adds Excel export for Markdown tables, JSON custom-parameter linting through CodeEditor, safer edited-code copying, layout/animation fixes, and token-usage analytics for streaming and non-streaming completions. Upgrade for these productivity gains; users unaffected by the listed integrations or bugs can reasonably skip.
