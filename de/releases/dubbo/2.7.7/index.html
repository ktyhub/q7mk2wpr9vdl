dubbo 2.7.7

Patch Veröffentlicht15. Mai 2020 Quelleapache/dubbo Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

dubbo dubbo-2.7.7

Funktionen

  • [Lösung] So integrieren Sie Apache Dubbo mit der Nacos-Authentifizierung #5956
  • [Dubbo-5130] vollständiger LFU-Cache-Vorschlag #5734
  • [Funktion] Um die Anwendung zu unterstützen, wählen Sie die bevorzugte Netzwerkschnittstelle #5795
  • [Dubbo-Performance] Hessian2Output- und Hessian2Input-Instanzen wiederverwenden, um den Speicher zu reduzieren… #5889
  • @Reference和@Service Naming issues #6074
  • Unterstützt Timeout-Pass und Countdown in der RPC-Anrufkette. #6008
  • Neue Loadbalance-Strategie #6064 hinzufügen

Verbesserung

  • onThrowable aufrufen, wenn RPC-Aufruf fehlschlägt (#5828)
  • Aktualisieren Sie fastjson auf 1.2.68 #5941
  • hessian-lite auf 3.2.7 #5964 aktualisieren
  • [Feature] ThreadPoolExhaustedEvent veröffentlichen, wenn der Thread-Pool erschöpft ist #5958
  • [Dubbo-5855] ReferenceConfig(null) wird beim FINALIZE #5863 nicht ZERSTÖRT
  • Registrieren Sie die angegebene URL im Anbietermodell, unabhängig davon, ob der Anbieter auf verzögerte Veröffentlichung konfiguriert ist oder nicht #5757
  • [Verbesserung] Übernehmen Sie die Eigenschaft „name“ von Dubbo Config als Spring Bean, wenn die Eigenschaft „id“ leer ist #6063
  • [Verbesserung] Hinzufügen eines Build-Tools-Moduls für Apache-Lizenz #6060
  • [Verbesserung] Refactoring des Parsers von Dubbo Config BeanDefinitions in der XML-Konfiguration #6039
  • [Refactor] Extrahieren der Eigenschaft „parameters“ in eine neue abstrakte Dubbo-Konfigurationsklasse #6043
  • [Refactor] Benennen Sie den Klassennamen von ServiceAnnotationBeanPostProcessor #6070 um
  • [Verbesserung] Hinzufügen der überschreibenden Regel für ExtensionLoader #6068
  • [Verbesserung] Auflösen der Platzhalter von XML BeanDefinition in der Konfigurationsklasse #6079
  • Deserilisierung ignorieren, wenn Dienst/Methode nicht gefunden wird #5733
  • DynamicConfiguration: Standardwert zurückgeben, wenn nicht implementiert. #6086
  • [Dubbo-Optimierung] ändert das Synchronisierungsmonitorobjekt auf endgültig #6081
  • Unterstützung für Fusion bei Verwendung von @Method oder @DubboReference #6092
  • Das Modul „dubbo-build-tools“ wird zu einem nicht einsetzbaren Modul. #6115

Fehlerbehebungen

  • Zipkin-Ablaufverfolgungsfilter verursacht Deadlock #5955
  • Korrigieren Sie die Nummer des ausgewählten Aufrufers #5875
  • Behebt, dass die Loadbalance-Strategie für mehrere Registrierungsabonnements nicht ordnungsgemäß funktioniert. #5686
  • [Dubbo-5871][Dubbo-5885][Dubbo-5899] Behebung des Fehlers, dass die Nacos-Registrierung seit 2.7.6 #5902 nicht funktioniert
  • Die Korrektur der Standardkonfiguration funktioniert nicht wie erwartet. #5952
  • Mögliche ConcurrentModificationException #6031 beheben
  • ComputeIfAbsent für JDK-bezogenen Fehler Nr. 6032 zurücksetzen
  • Tomcat9-Unterstützung behoben. #5711 #6066
  • Alibaba RpcContext setAttachment(String,String) #6052 beheben
  • Javax-Unterstützung hinzufügen, wenn jdk11 #154 verwendet wird
  • Verwenden Sie im Anforderungspaket Nr. 6138 den richtigen Dienstnamen

Kompatibilität

  • kompatibel mit niedrigeren Versionen, die „Standard“ registrieren. Schlüssel #5950

Sicherheitslücke

https://lists.apache.org/thread.html/rd4931b5ffc9a2b876431e19a1bffa2b4c14367260a08386a4d461955%40%3Cdev.dubbo.apache.org%3E

Englisches Original / English original

dubbo dubbo-2.7.7

Features

  • [Solution] How to integrate Apache Dubbo with Nacos authentication #5956
  • [Dubbo-5130] complete lfu cache proposal #5734
  • [Feature] To support the application choose the preferred network interface #5795
  • [Dubbo-Performance] Reuse Hessian2Output and Hessian2Input instance to reduce memor… #5889
  • @Reference和@Service Naming issues #6074
  • support timeout pass and count down on RPC call chain. #6008
  • add new loadbalance strategy #6064

Enhancement

  • call onThrowable when RPC call fail (#5828)
  • upgrade fastjson to 1.2.68 #5941
  • update hessian-lite to 3.2.7 #5964
  • [feature] publish ThreadPoolExhaustedEvent when thread pool exhausted #5958
  • [Dubbo-5855] ReferenceConfig(null) is not DESTROYED when FINALIZE #5863
  • register stated url to provider model, no matter the provider is configured to delay-published or not #5757
  • [Enhancement] Take the "name" property of Dubbo Config as Spring Bean If its "id" property is blank #6063
  • [Enhancement] Adding a build tools module for Apache License #6060
  • [Enhancement] Refactoring the parser of dubbo config BeanDefinitions in XML configuration #6039
  • [Refactor] Extracting the "parameters" property to a new abstract Dubbo config class #6043
  • [Refactor] Rename the class name of ServiceAnnotationBeanPostProcessor #6070
  • [Enhancement] Adding the overriding rule for ExtensionLoader #6068
  • [Enhancement] Resolving the placeholders of XML BeanDefinition in the Configuration Class #6079
  • Ignore deserilization when service/method not found #5733
  • DynamicConfiguration: return default value if not implemented. #6086
  • [Dubbo-Optimization] modify the synchronize monitor object to final #6081
  • support for merger when use @Method or @DubboReference #6092
  • Making "dubbo-build-tools" module to be non-deployable one. #6115

Bugfixes

  • zipkin tracing filter cause deadlock #5955
  • correct the number of selected invoker #5875
  • Fixes multi-registry subscription loadbalance strategy does not work properly. #5686
  • [Dubbo-5871][Dubbo-5885][Dubbo-5899] Fix nacos registry not work bug since 2.7.6 #5902
  • Fix default config does not work as expected. #5952
  • fix potential ConcurrentModificationException #6031
  • revert computeIfAbsent for jdk related bug #6032
  • fix tomcat9 support. #5711 #6066
  • fix alibaba RpcContext setAttachment(String,String) #6052
  • add javax support when use jdk11 #154
  • Use the correct service name in the request package #6138

Compatibility

  • compatible with lower versions registering "default." keys #5950

Vulnerability

https://lists.apache.org/thread.html/rd4931b5ffc9a2b876431e19a1bffa2b4c14367260a08386a4d461955%40%3Cdev.dubbo.apache.org%3E
