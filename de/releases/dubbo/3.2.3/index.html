dubbo 3.2.3

Patch Veröffentlicht13. Juni 2023 Quelleapache/dubbo Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

dubbo dubbo-3.2.3

Was hat sich geändert?

Funktion

  • Unterstützt das Timeout beim Schließen der Konfiguration durch @AlbumenJ in https://github.com/apache/dubbo/pull/12386
  • Metriken fügen gleitende Zeitfensterstatistiken von @jojocodeX in https://github.com/apache/dubbo/pull/12364 hinzu
  • Unterstützt standardmäßige Metriken, wenn prometheus von @hujun-w-2 in https://github.com/apache/dubbo/pull/12273 fehlt
  • Verwenden Sie Dubbo Proxy anstelle von Spring Proxy von @AlbumenJ in https://github.com/apache/dubbo/pull/12439
  • Dauer als SIMPLE_TYPE hinzufügen und von @conghuhu in https://github.com/apache/dubbo/pull/12469 konvertieren
  • Fügen Sie den Metrik-Aktivierungsschalter von @finefuture in https://github.com/apache/dubbo/pull/12389 hinzu
  • Modul-Deployer-Statusereignis von @AlbumenJ in https://github.com/apache/dubbo/pull/12477 veröffentlichen
  • Springboot-Starter für Nacos und zookeeper von @conghuhu in https://github.com/apache/dubbo/pull/12488 hinzufügen
  • Path Matcher&Invoker an Benutzer von @suncairong163 in https://github.com/apache/dubbo/pull/12482 exportieren
  • Verarbeitungsmetrik Fun of Name von @songxiaosheng in https://github.com/apache/dubbo/pull/12461 hinzugefügt

Bugfix

  • Zeitüberschreitung beim Schließen des Servers netty4 durch @AlbumenJ in https://github.com/apache/dubbo/pull/12387 behoben
  • Behebung des PojoUtils NPE-Problems von @CrazyHZM in https://github.com/apache/dubbo/pull/12380
  • Korrektur von Alibaba AbstractLoadBalance Compact von @AlbumenJ in https://github.com/apache/dubbo/pull/12396
  • NPE beheben, wenn der Name in PojoUtils von @AlbumenJ in https://github.com/apache/dubbo/pull/12404 nicht übereinstimmt
  • Fügen Sie Alibaba RpcContext getInvocation kompakt von @AlbumenJ in https://github.com/apache/dubbo/pull/12416 hinzu
  • Bootstarter hinzufügen und Endpunktfehler beheben von @songxiaosheng in https://github.com/apache/dubbo/pull/12408
  • Korrigieren Sie invocation.getServiceKey möglicherweise null durch @wxbty in https://github.com/apache/dubbo/pull/12425
  • Fix entfernt ConditionalOnDubboTracingEnable matchIfMissing von @conghuhu in https://github.com/apache/dubbo/pull/12409
  • Korrektur von Alibaba Filter / Result Compact von @AlbumenJ in https://github.com/apache/dubbo/pull/12440
  • Standardaktivierung für Protokoll und Histogramm von @wxbty in https://github.com/apache/dubbo/pull/12137 hinzugefügt
  • Wiederherstellung des Aufrufers durch @AlbumenJ in https://github.com/apache/dubbo/pull/12445 behoben
  • Fox-Build-String-Fehler durch @icodening in https://github.com/apache/dubbo/pull/12427
  • Fix Wenn die Serialisierung fehlschlägt, wird der Codewert in RpcException von @wxbty in https://github.com/apache/dubbo/pull/12357 falsch festgelegt
  • Einführung von DelegateURL zur Proxy-Apache-URL zur Alibaba-URL von @AlbumenJ in https://github.com/apache/dubbo/pull/12449
  • Behebung, dass die tatsächliche Ausnahme durch @icodening in https://github.com/apache/dubbo/pull/12446 nicht abgefangen werden konnte
  • Setzen Sie alle aktiven Streams bei geschlossener Verbindung durch @icodening in https://github.com/apache/dubbo/pull/12451 zurück
  • Registrieren Sie Dienste, nachdem das Modul von @AlbumenJ in https://github.com/apache/dubbo/pull/12450 gestartet wurde
  • Überprüfen Sie die Referenz nach der Registrierung durch @AlbumenJ in https://github.com/apache/dubbo/pull/12472
  • Lösen Sie Konflikte von Spring Bean von @AlbumenJ in https://github.com/apache/dubbo/pull/12474
  • Invoker-Prüfung injvm durch @AlbumenJ in https://github.com/apache/dubbo/pull/12479 behoben
  • HashCode-Änderung in 2.6 ConsistentHashLoadBalance durch @wegod in https://github.com/apache/dubbo/pull/12468 behoben
  • Lange Wartezeit in ThreadlessExecutor von @AlbumenJ in https://github.com/apache/dubbo/pull/12484 behoben
  • Überprüfen Sie die Registrierung in checkAndUpdateSubConfigs von @AlbumenJ in https://github.com/apache/dubbo/pull/12486
  • Fügen Sie einige Nacos-Verbindungsprotokolle von @AlbumenJ in https://github.com/apache/dubbo/pull/12494 hinzu
  • Unterstützt das ordnungsgemäße Herunterfahren von client durch @AlbumenJ in https://github.com/apache/dubbo/pull/12504
  • Protokoll für Remote-Konfiguration hinzufügen. von @chickenlj in https://github.com/apache/dubbo/pull/12294
  • Schnell, schnell, wenn Protokollkonfigurationsfehler von @wxbty in https://github.com/apache/dubbo/pull/12361
  • Router-Übereinstimmungsbedingung von @chickenlj in https://github.com/apache/dubbo/pull/12491 behoben
  • Korrigieren Sie die AbstractProxyProtocol-Kompatibilität von @AlbumenJ in https://github.com/apache/dubbo/pull/12507
  • Behebung, dass ServiceConfig Ref nicht in der Lage ist, toString von @AlbumenJ in https://github.com/apache/dubbo/pull/12511 zu erstellen
  • Das Ereignis „Kanal schließen“ wurde behoben, das dazu führte, dass der Thread von @AlbumenJ in https://github.com/apache/dubbo/pull/12503 hängen blieb

What's Changed

Feature

  • Support config close timeout by @AlbumenJ in https://github.com/apache/dubbo/pull/12386
  • Metrics add sliding time window statistics by @jojocodeX in https://github.com/apache/dubbo/pull/12364
  • Support metrics default if prometheus absent by @hujun-w-2 in https://github.com/apache/dubbo/pull/12273
  • Use Dubbo Proxy instead of Spring Proxy by @AlbumenJ in https://github.com/apache/dubbo/pull/12439
  • Add Duration as SIMPLE_TYPE and Convert by @conghuhu in https://github.com/apache/dubbo/pull/12469
  • Add metrics enable switch by @finefuture in https://github.com/apache/dubbo/pull/12389
  • Publish Module deployer state event by @AlbumenJ in https://github.com/apache/dubbo/pull/12477
  • Add springboot-starter for nacos and zookeeper by @conghuhu in https://github.com/apache/dubbo/pull/12488
  • Export path matcher&invoker to user by @suncairong163 in https://github.com/apache/dubbo/pull/12482
  • Add processing metric fun of name by @songxiaosheng in https://github.com/apache/dubbo/pull/12461

Bugfix

  • Fix netty4 server close timeout by @AlbumenJ in https://github.com/apache/dubbo/pull/12387
  • Fix PojoUtils NPE problem by @CrazyHZM in https://github.com/apache/dubbo/pull/12380
  • Fix alibaba AbstractLoadBalance compact by @AlbumenJ in https://github.com/apache/dubbo/pull/12396
  • Fix NPE if name not match in PojoUtils by @AlbumenJ in https://github.com/apache/dubbo/pull/12404
  • Add alibaba RpcContext getInvocation compact by @AlbumenJ in https://github.com/apache/dubbo/pull/12416
  • Add bootstarter and fix endpoints bug by @songxiaosheng in https://github.com/apache/dubbo/pull/12408
  • Fix invocation.getServiceKey maybe null by @wxbty in https://github.com/apache/dubbo/pull/12425
  • Fix remove ConditionalOnDubboTracingEnable matchIfMissing by @conghuhu in https://github.com/apache/dubbo/pull/12409
  • Fix alibaba Filter / Result Compact by @AlbumenJ in https://github.com/apache/dubbo/pull/12440
  • Add default enable for protocol and histogram by @wxbty in https://github.com/apache/dubbo/pull/12137
  • Fix invoker recovery by @AlbumenJ in https://github.com/apache/dubbo/pull/12445
  • Fox build string error by @icodening in https://github.com/apache/dubbo/pull/12427
  • Fix When serialization fails, the code value in RpcException is set incorrectly by @wxbty in https://github.com/apache/dubbo/pull/12357
  • Introduce DelegateURL to proxy apache URL to alibaba URL by @AlbumenJ in https://github.com/apache/dubbo/pull/12449
  • Fix unable to catch actual exception by @icodening in https://github.com/apache/dubbo/pull/12446
  • Reset all active stream on connection close by @icodening in https://github.com/apache/dubbo/pull/12451
  • Register services after module started by @AlbumenJ in https://github.com/apache/dubbo/pull/12450
  • Check reference after register by @AlbumenJ in https://github.com/apache/dubbo/pull/12472
  • Resolve conflicts of spring bean by @AlbumenJ in https://github.com/apache/dubbo/pull/12474
  • Fix injvm invoker check by @AlbumenJ in https://github.com/apache/dubbo/pull/12479
  • Fix hashCode change in 2.6 ConsistentHashLoadBalance by @wegod in https://github.com/apache/dubbo/pull/12468
  • Fix long time await in ThreadlessExecutor by @AlbumenJ in https://github.com/apache/dubbo/pull/12484
  • Check registry in checkAndUpdateSubConfigs by @AlbumenJ in https://github.com/apache/dubbo/pull/12486
  • Add some nacos connection logs by @AlbumenJ in https://github.com/apache/dubbo/pull/12494
  • Support client gracefully shutdown by @AlbumenJ in https://github.com/apache/dubbo/pull/12504
  • Add log for remote configuration. by @chickenlj in https://github.com/apache/dubbo/pull/12294
  • Fast fast when protocol configure error by @wxbty in https://github.com/apache/dubbo/pull/12361
  • Fix router match condition by @chickenlj in https://github.com/apache/dubbo/pull/12491
  • Fix AbstractProxyProtocol compatibility by @AlbumenJ in https://github.com/apache/dubbo/pull/12507
  • Fix ServiceConfig Ref unable to toString by @AlbumenJ in https://github.com/apache/dubbo/pull/12511
  • Fix channel close event cause hanging thread by @AlbumenJ in https://github.com/apache/dubbo/pull/12503
