dubbo 3.2.12

Was hat sich geändert?

Bugfix

  • Aktualisieren Sie gültige Aufrufer nach der Konnektivitätsprüfung durch @AlbumenJ in https://github.com/apache/dubbo/pull/13773
  • Problem mit der Portvereinheitlichung im Triple- und Dubbo-Protokoll von @namelessssssssssss in https://github.com/apache/dubbo/pull/13696 behoben
  • NPE in DefaultTypeBuilder von @AlbumenJ in https://github.com/apache/dubbo/pull/13732 behoben
  • Behebung, dass ConsistentHashLoadBalance nicht auf Argumenten von @AlbumenJ in https://github.com/apache/dubbo/pull/13753 basiert
  • ModuleEnvironment#getDynamicGlobalConfiguration von @JoeCqupt in https://github.com/apache/dubbo/pull/13781 behoben
  • Die Lazy-Eigenschaft von serviceBeanDefinition wurde von @laywin in https://github.com/apache/dubbo/pull/13787 auf „false“ gesetzt
  • URL-Problem von @namelessssssssssss in https://github.com/apache/dubbo/pull/13807 behoben
  • Korrigiert, dass die lokalen RpcContext-Adressinformationen beim benutzerdefinierten Filter von @aofall in https://github.com/apache/dubbo/pull/13751 null werden
  • Speicherleck in ScopeBeanFactory von @AlbumenJ in https://github.com/apache/dubbo/pull/13901 behoben
  • Die Add-Bedingung wurde korrigiert, damit sie mit serviceKey im cd-Befehl von @kazetyan in https://github.com/apache/dubbo/pull/13869 übereinstimmt
  • Falscher Rest-Antwort-Header und Demo-Doppelpfadfehler von @suncairong163 in https://github.com/apache/dubbo/pull/13789 behoben

What's Changed

Bugfix

  • Refresh valid invokers after connectivity check by @AlbumenJ in https://github.com/apache/dubbo/pull/13773
  • Fix port unification issue in triple and dubbo protocol by @namelessssssssssss in https://github.com/apache/dubbo/pull/13696
  • Fix NPE in DefaultTypeBuilder by @AlbumenJ in https://github.com/apache/dubbo/pull/13732
  • Fix ConsistentHashLoadBalance not base on arguments by @AlbumenJ in https://github.com/apache/dubbo/pull/13753
  • Fix ModuleEnvironment#getDynamicGlobalConfiguration by @JoeCqupt in https://github.com/apache/dubbo/pull/13781
  • fix lazy property of serviceBeanDefinition to false by @laywin in https://github.com/apache/dubbo/pull/13787
  • Fix URL issue by @namelessssssssssss in https://github.com/apache/dubbo/pull/13807
  • Fix RpcContext local address info get null on custom filter by @aofall in https://github.com/apache/dubbo/pull/13751
  • Fix memory leak in ScopeBeanFactory by @AlbumenJ in https://github.com/apache/dubbo/pull/13901
  • Fix add condition to match serviceKey in cd command by @kazetyan in https://github.com/apache/dubbo/pull/13869
  • Fix incorrect rest response header and demo double path error by @suncairong163 in https://github.com/apache/dubbo/pull/13789
