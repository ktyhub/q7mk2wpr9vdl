dubbo 3.2.2

Patch Veröffentlicht20. Mai 2023 Quelleapache/dubbo Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

dubbo dubbo-3.2.2

Was hat sich geändert?

Funktion

  • RestEasy Response-Anpassung von @jojocodeX in https://github.com/apache/dubbo/pull/12264
  • Dubbo-spring-boot-tracing-otel-otlp-starter von @conghuhu in https://github.com/apache/dubbo/pull/12299 hinzugefügt
  • Unterstützung für die Deaktivierung der 2.6.x-URL-Konfiguratoren von @AlbumenJ in https://github.com/apache/dubbo/pull/12332
  • Unterstützt das Festlegen des standardmäßigen Serialisierungsprüfstatus durch @AlbumenJ in https://github.com/apache/dubbo/pull/12333
  • P50- und P90-RT-Metriken von @MartinDai in https://github.com/apache/dubbo/pull/12156 hinzufügen
  • Export von Metriken und Metadatendiensten bei Bedarf durch @AlbumenJ in https://github.com/apache/dubbo/pull/12346
  • Metrikoption zur Verwendung der globalen Registrierung von @wxbty in https://github.com/apache/dubbo/pull/12238 hinzugefügt

Bugfix

  • Behebung des ConcurrentHashMapUtils-Sperrfehlers von @looly in https://github.com/apache/dubbo/pull/11987
  • Fix: Wenn die Ausnahmebehandlungsklasse nicht abgerufen werden kann, sollte sie die Basisklasse rekursiv nach @iqinning in https://github.com/apache/dubbo/pull/12246 durchsuchen
  • Rpc-Ausnahmetypfehler von @wxbty in https://github.com/apache/dubbo/pull/12274
  • Die Erkennung der Dubbo-Version durch @AlbumenJ in https://github.com/apache/dubbo/pull/12278 wurde behoben
  • Bereinigen Sie den RpcContext in ThreadLocal nach dem QoS-Aufruf und rufen Sie das Ergebnis synchron ab, während der asynchrone Start durch @trytocatch in https://github.com/apache/dubbo/pull/12291 erfolgt
  • Fix erlaubt nicht serialisierbare Prüfung durch @AlbumenJ in https://github.com/apache/dubbo/pull/12267
  • Behebung der durch den Filter von 2.x verursachten ClassCastException in einer bestimmten Bedingung durch @wegod in https://github.com/apache/dubbo/pull/12286
  • Korrigieren Sie den Standardwert von k8s client http2Disable, der von @AYue-94 in https://github.com/apache/dubbo/pull/12328 falsch ist
  • Fehler beim Start von DefaultModuleDeployer behoben, aber MetadataService von @AYue-94 in https://github.com/apache/dubbo/pull/12316 exportieren
  • Korrigieren Sie, dass die Metriken des Registrierungsverzeichnisses nur num_valid_total von @wxbty in https://github.com/apache/dubbo/pull/12351 anzeigen
  • Fix prometheus-Init schlug beim Start durch @songxiaosheng in https://github.com/apache/dubbo/pull/12349 fehl
  • Fehler bei der Übertragung in injvm incoke von @PhoenixBackendon in https://github.com/apache/dubbo/pull/12347 behoben
  • NPE bei Restannotationsprüfung durch @CodePlayer in https://github.com/apache/dubbo/pull/12293 behoben
  • PortUnification+encodeInIOThread=false behoben, was dazu führte, dass der Puffer der Serverantwort von @AYue-94 in https://github.com/apache/dubbo/pull/12355 leer war

What's Changed

Feature

  • RestEasy Response adaptation by @jojocodeX in https://github.com/apache/dubbo/pull/12264
  • Add dubbo-spring-boot-tracing-otel-otlp-starter by @conghuhu in https://github.com/apache/dubbo/pull/12299
  • Support disable 2.6.x url configurators by @AlbumenJ in https://github.com/apache/dubbo/pull/12332
  • Support set default serialize check status by @AlbumenJ in https://github.com/apache/dubbo/pull/12333
  • Add P50 and P90 RT metrics by @MartinDai in https://github.com/apache/dubbo/pull/12156
  • Metrics and Metadata Service Export when needed by @AlbumenJ in https://github.com/apache/dubbo/pull/12346
  • Add metrics option for use global registry by @wxbty in https://github.com/apache/dubbo/pull/12238

Bugfix

  • Fix ConcurrentHashMapUtils lock bug by @looly in https://github.com/apache/dubbo/pull/11987
  • Fix When the exception handling class cannot be obtained, it should recursively search the base class by @iqinning in https://github.com/apache/dubbo/pull/12246
  • Rpc exception type bug by @wxbty in https://github.com/apache/dubbo/pull/12274
  • Fix dubbo version detect by @AlbumenJ in https://github.com/apache/dubbo/pull/12278
  • Cleanup the RpcContext in ThreadLocal after QoS invoke, synchronously get the result while async started by @trytocatch in https://github.com/apache/dubbo/pull/12291
  • Fix allow non-serializable check by @AlbumenJ in https://github.com/apache/dubbo/pull/12267
  • Fix ClassCastException caused by 2.x's filter in some condition by @wegod in https://github.com/apache/dubbo/pull/12286
  • Fix k8s client http2Disable default value is wrong by @AYue-94 in https://github.com/apache/dubbo/pull/12328
  • Fix DefaultModuleDeployer start fail, but export MetadataService by @AYue-94 in https://github.com/apache/dubbo/pull/12316
  • Fix registry directory metrics only show num_valid_total by @wxbty in https://github.com/apache/dubbo/pull/12351
  • Fix prometheus init failed when start by @songxiaosheng in https://github.com/apache/dubbo/pull/12349
  • Fix broadcast failed in injvm incoke by @PhoenixBackendon in https://github.com/apache/dubbo/pull/12347
  • Fix NPE in rest annotation check by @CodePlayer in https://github.com/apache/dubbo/pull/12293
  • Fix PortUnification+encodeInIOThread=false cause server response empty buffer by @AYue-94 in https://github.com/apache/dubbo/pull/12355
