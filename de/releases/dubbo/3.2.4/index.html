dubbo 3.2.4

Patch Veröffentlicht30. Juni 2023 Quelleapache/dubbo Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

dubbo dubbo-3.2.4

Was hat sich geändert?

Funktion

  • Unterstützung für die Festlegung der tatsächlichen Inhaltslänge auf inv/res-Attribute durch @AlbumenJ in https://github.com/apache/dubbo/pull/12521
  • Unterstützung für Alibaba GenericService aus dem Spring-Kontext von @AlbumenJ in https://github.com/apache/dubbo/pull/12585
  • Aktivieren Sie Spring Bean Autowired, um das Scope-Modell im Voraus von @AlbumenJ in https://github.com/apache/dubbo/pull/12608 abzurufen

Bugfix

  • Korrigiert den Methodennamen vom Aufruf durch @AlbumenJ in https://github.com/apache/dubbo/pull/12519
  • Korrigieren Sie doppelte Methoden in der Registrierung von @wegod in https://github.com/apache/dubbo/pull/12527
  • Deaktivieren Sie alle Filter für den internen Dienst von @AlbumenJ in https://github.com/apache/dubbo/pull/12515
  • Korrigiert, dass die Registry-Benachrichtigung dieselbe Ereigniszeit von @AlbumenJ in https://github.com/apache/dubbo/pull/12556 verwendet
  • Korrigieren Sie die Protokollebene der Konfigurationscenter-Eigenschaften von @AlbumenJ in https://github.com/apache/dubbo/pull/12555
  • Benennen Sie getModelEnvironment in modelEnvironment von @AlbumenJ in https://github.com/apache/dubbo/pull/12551 um
  • Korrigiert die lokale Aufruf-Consumer-URL-Überschreibung durch @AlbumenJ in https://github.com/apache/dubbo/pull/12553
  • Zusätzlicher Verzeichnismetrikdaten-Push von @wxbty in https://github.com/apache/dubbo/pull/12539
  • InterfaceClass im Voraus zwischenspeichern, um IndexOutOfBoundsException durch @AlbumenJ in https://github.com/apache/dubbo/pull/12567 zu verhindern
  • Überprüfen Sie, ob die Jackson2-Sicherheitsabhängigkeit von @AlbumenJ in https://github.com/apache/dubbo/pull/12568 vorhanden war
  • Behebung, dass AppName in InjvmInvoker von @AlbumenJ in https://github.com/apache/dubbo/pull/12574 nicht abgerufen werden konnte
  • Überprüfung ignorierter Erweiterungen von @AlbumenJ in https://github.com/apache/dubbo/pull/12571 überspringen
  • Transient zu einem überschriebenen Feld von @AlbumenJ in https://github.com/apache/dubbo/pull/12570 hinzufügen
  • Deaktivieren Sie die Registrierung, wenn die Registrierung die Registrierung von @AlbumenJ in https://github.com/apache/dubbo/pull/12579 deaktiviert
  • Korrektur des wiederholten Exports desselben Dienstes in der Registrierung durch @AlbumenJ in https://github.com/apache/dubbo/pull/12578
  • Triple-Set-Resolution-Fallback-Aktivierung als Standard von @AlbumenJ in https://github.com/apache/dubbo/pull/12575
  • Alibaba Rpc Compact von @AlbumenJ in https://github.com/apache/dubbo/pull/12581 behoben
  • Erweitern Sie den Registertyp von ServiceConfig um @AlbumenJ in https://github.com/apache/dubbo/pull/12583
  • Verwenden Sie serviceKey, wenn Sie ServiceSubscribeEvent von @wxbty in https://github.com/apache/dubbo/pull/12586 metadaten
  • Wiederholungszeiten von @AlbumenJ in https://github.com/apache/dubbo/pull/12593 auf „Unendlich“ ändern
  • SkipFailbackWrapperException in NacosRegistry von @AlbumenJ in https://github.com/apache/dubbo/pull/12594 überspringen
  • Heartbeat vom Dienstprogramm lesen, wenn die URL in ExchangeClient von @AlbumenJ in https://github.com/apache/dubbo/pull/12605 neu erstellt wird
  • Füllnull in Metriken aufgrund von Leistungsproblemen von @AlbumenJ in https://github.com/apache/dubbo/pull/12624 vorübergehend entfernen
  • Future in RpcContext löschen, wenn sync (#12493) von @xlq20080808 in https://github.com/apache/dubbo/pull/12534 aufgerufen wird

What's Changed

Feature

  • Support set actual content length to inv/res attributes by @AlbumenJ in https://github.com/apache/dubbo/pull/12521
  • Support get alibaba GenericService from spring context by @AlbumenJ in https://github.com/apache/dubbo/pull/12585
  • Enable spring bean autowired to get scope model in advance by @AlbumenJ in https://github.com/apache/dubbo/pull/12608

Bugfix

  • Fix get method name from invocation by @AlbumenJ in https://github.com/apache/dubbo/pull/12519
  • Fix duplicated methods in registry by @wegod in https://github.com/apache/dubbo/pull/12527
  • Disable all filters for internal service by @AlbumenJ in https://github.com/apache/dubbo/pull/12515
  • Fix Registry Notification use same event time by @AlbumenJ in https://github.com/apache/dubbo/pull/12556
  • Fix config center properties log level by @AlbumenJ in https://github.com/apache/dubbo/pull/12555
  • Rename getModelEnvironment to modelEnvironment by @AlbumenJ in https://github.com/apache/dubbo/pull/12551
  • Fix local invoke consumer url override by @AlbumenJ in https://github.com/apache/dubbo/pull/12553
  • Supplementary dirctory metrics data push by @wxbty in https://github.com/apache/dubbo/pull/12539
  • Cache interfaceClass in advance to prevent IndexOutOfBoundsException by @AlbumenJ in https://github.com/apache/dubbo/pull/12567
  • Check if jackson2 security dependency existed by @AlbumenJ in https://github.com/apache/dubbo/pull/12568
  • Fix unable to getAppName in InjvmInvoker by @AlbumenJ in https://github.com/apache/dubbo/pull/12574
  • Skip check ignored extensions by @AlbumenJ in https://github.com/apache/dubbo/pull/12571
  • Add transient to some overrided field by @AlbumenJ in https://github.com/apache/dubbo/pull/12570
  • Disable register if registry disable register by @AlbumenJ in https://github.com/apache/dubbo/pull/12579
  • Fix registry repeat export same service by @AlbumenJ in https://github.com/apache/dubbo/pull/12578
  • Triple set resolve fallback enable as default by @AlbumenJ in https://github.com/apache/dubbo/pull/12575
  • Fix alibaba Rpc compact by @AlbumenJ in https://github.com/apache/dubbo/pull/12581
  • Enhance register type of ServiceConfig by @AlbumenJ in https://github.com/apache/dubbo/pull/12583
  • Use serviceKey when to metadata ServiceSubscribeEvent by @wxbty in https://github.com/apache/dubbo/pull/12586
  • Change retry times to forever by @AlbumenJ in https://github.com/apache/dubbo/pull/12593
  • Skip catch SkipFailbackWrapperException in NacosRegistry by @AlbumenJ in https://github.com/apache/dubbo/pull/12594
  • Read heartbeat from util when recreate url in ExchangeClient by @AlbumenJ in https://github.com/apache/dubbo/pull/12605
  • Temporally remove fill zero in metrics due to performance issue by @AlbumenJ in https://github.com/apache/dubbo/pull/12624
  • Clear future in RpcContext when calling sync (#12493) by @xlq20080808 in https://github.com/apache/dubbo/pull/12534
