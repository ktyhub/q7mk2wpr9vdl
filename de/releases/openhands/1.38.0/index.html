Die App ist noch nicht mit einer Apple-Entwickler-ID signiert, daher ruft macOS möglicherweise eine auf Heruntergeladener Build „beschädigt“ – es handelt sich um Gatekeeper-Quarantäne, keine fehlerhafte Datei. Nachdem Sie die App in „Anwendungen“ verschoben haben, löschen Sie die Markierung einmal und öffnen Sie sie dann normal:

OpenHands v1.38.0

Highlights

  • Automations become a first-class install path — mode=automation plus a new POST /plugin-spec endpoint lets you install a build pre-wired for automation runs (#18699, toward #18793), while prompt/plugin presets can now be driven from an agent profile (#19421). Script bundles also survive export/import (#19330), and org admins/owners can edit other users' automations (#19307). Watch the new plugin-spec contract if you script fleet installs — this is the surface to target going forward.
  • /launch links get permissive — Message-only /launch links no longer require a plugin (#18734), executable plugin config is editable directly from automation help (#19453), and project conversations now show a resolved banner (#19494). Net effect: canned task links are far less brittle, though the no-plugin path means you can no longer assume anything about the recipient's plugin environment.
  • Docker/CI reliability and persistence — The bundled agent-server moves to 1.61.0 (#19572) alongside two fail-fast guards: the container exits non-zero when the agent-server stops responding (#19275) and aborts immediately on unwritable bind mounts, with the permission fix documented (#16512). Conversation workspaces also stay in the persisted volume (#18975). For CI, the non-zero exit is the headline — silent hangs now fail jobs instead of idling.
  • Agent-control behavior changes — Composer Stop now interrupts the running agent instead of pausing the Cloud sandbox (#19546), a real semantic shift if you built pause/resume workflows. ACP picks are saved to their own profile rather than the shared default (#19384), the active LLM profile is re-reconciled against the backend model with a race fix (#19568), and self-hosted instances that disable Agent Profiles now hide the profile switcher (#19471).
  • Frontend toolchain takes several majors — TypeScript 7 (#19414), Electron 45 (#19541), framer-motion 14 (#19455), and HeroUI 3 (#16654) land together; expect breakage if you vendor or build against the Canvas frontend. Cosmetic but visible: the new Paper theme (#19445) and the completed Light+/Solarized contrast pass (#17730).
  • macOS Gatekeeper friction — The desktop build is still unsigned, so macOS may report the download as "damaged." Clear the quarantine flag once after moving it to Applications: xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app". Signing and notarization are tracked in #16774.

No breaking changes in this release.

macOS install note

The app isn't signed with an Apple Developer ID yet, so macOS may call a downloaded build "damaged" — it's Gatekeeper quarantine, not a bad file. After moving the app to Applications, clear the flag once, then open normally:

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

Signing + notarization is tracked in OpenHands/OpenHands#16774.
