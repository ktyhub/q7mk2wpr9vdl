Leuchtturm v5.1.0

5.1.0 (30.05.2019)

Voll Changelog

Neue Mitwirkende!

Danke an unsere neuen Mitwirkenden 👽🐷🐰🐯🐻! @thebengeu @boyney123

Kern

  • Gather-Runner: NO_FCP als pageLoadError behandeln (#8340)
  • Protokollierung: Protokollmeldungen für die Erfassung und den Trace-Abruf ändern (#9029)
  • tap-targets: Absolute Elemente der sichtbaren Position nicht von der Prüfung ausschließen (#7778)
  • Budget: Fehler bei doppelten Budgettypen auslösen (#8915)
  • config: Konfigurationshelfer aufteilen (#9003)
  • Gather-Runner: Scroll-Position immer zurücksetzen (zurückgesetzt) (#8625)
  • Bildelemente: Spritesheet-Logik löschen (#8940)
  • Gather-Runner-Kontrollfluss umgestalten (#8964)
  • perf: getNodePath beschleunigen (#9055)
  • performance-budget: MP-FID als Budgetmetrik hinzufügen (#8905)
  • Runner: Fehlende Timing-Eigenschaften im Browser beheben (#9072)

Bericht

  • zwei Zeilen für Filmstreifen auf Mobilgeräten (#8563)
  • Gauge-Stile in das Haupt-Stylesheet verschieben (#8893)
  • Metrikbeschreibungen standardmäßig anzeigen, wenn Fehler vorliegen (#9054)
  • Feuerwerk nur anzeigen, wenn alle Kernkategorien einen Wert von 100 erreichen (#9073)
  • Machen Sie die Schriftgröße und Positionierung des Messgeräts dynamisch (#9057)
  • Kontrollkästchen für Filter von Drittanbietern ausblenden, wenn alle Zeilen von Drittanbietern stammen (#8966)
  • Wortumbrüche im Anzeigetext behoben, Metrik-Haftungsausschluss verschoben (#9030)
  • nodeLabel für DOM-Knoten zusätzlich zum Snippet anzeigen (#8961)

Clients

  • devtools: Topbar aus scrollbarem Container verschieben (#9077)
  • devtools: Sticky-Header, obere Leiste und Berichts-UI-Funktionen aktivieren (#9023)
  • devtools: Medienabfrage im Dunkelmodus ignorieren (#9082)
  • devtools: Version in Tests auf linker Seite aktualisieren (#8819)
  • lr: Assets zu Protokollierungszwecken in lhr einfügen (#9002)

CLI

  • Flags: Akzeptieren Sie durch Kommas getrennte Array-Werte (#8933)

Dokumente

  • Plugins: Link zum Field-Performance-Plugin hinzufügen (#9051)
  • Plugins: Benennen Sie Google AdSpeed Insights in Publisher Ads Audit um (#8906)
  • Lighthouse-Plugin-Field-Performance zu Plugins hinzufügen (#9049)
  • Leistungsbudgets zu verwandten Projekten hinzufügen (#8971)

I18n

  • kleinere Übersetzungsaktualisierungen für fr und ta (#8999)

Sonstiges

  • Assets: Veraltete Erweiterungs-Screenshots entfernen (#9015)
  • dot-js require() überall (#9006)
  • Nicht benötigte ReportCategories aus LH.ReportResult entfernen (#9001)
  • Minify-Trace-Skripte aktualisieren; Extrahieren nach lib/ (#8968)
  • Fix Master: TMP-Rücksetzung der Scroll-Änderung in #8625 (#9059)

Tests

  • lint: Dateierweiterung in require() erforderlich (#9017)
  • Alle 11 Jahre Beispielartefakte aktualisieren (#9010)
  • Compile-Devtools auf Travis entfernen (#8988)
  • Smoke: Dialogaufforderung erneut aktivieren (#8894)

lighthouse v5.1.0

5.1.0 (2019-05-30)

Full Changelog

New contributors!

Thanks to our new contributors 👽🐷🐰🐯🐻! @thebengeu @boyney123

Core

  • gather-runner: treat NO_FCP as a pageLoadError (#8340)
  • logging: change log messages for gathering and trace retrieval (#9029)
  • tap-targets: don't exclude visible position absolute elements from audit (#7778)
  • budget: throw error on duplicate budget types (#8915)
  • config: split out config helpers (#9003)
  • gather-runner: always reset scroll position (reverted) (#8625)
  • image-elements: drop spritesheet logic (#8940)
  • refactor gather-runner control flow (#8964)
  • perf: speed up getNodePath (#9055)
  • performance-budget: add MP-FID as budget metric (#8905)
  • runner: fix missing timing properties in the browser (#9072)

Report

  • two rows for filmstrip on mobile (#8563)
  • move gauge styles to main stylesheet (#8893)
  • show metric descriptions by default when errors exist (#9054)
  • show fireworks only if all core categories score 100 (#9073)
  • make gauge font size and positioning dynamic (#9057)
  • hide 3rd party filter checkbox if all rows are 3rd party (#8966)
  • fix word breaking of display text, move metric disclaimer (#9030)
  • show nodeLabel for DOM nodes in addition to snippet (#8961)

Clients

  • devtools: move topbar out of scrollable container (#9077)
  • devtools: enable sticky header, top bar, and report ui features (#9023)
  • devtools: ignore dark mode media query (#9082)
  • devtools: update version in tests on lh roll (#8819)
  • lr: insert assets in lhr for logging purposes (#9002)

CLI

  • flags: accept comma-separated array values (#8933)

Docs

  • plugins: add link to field-performance plugin (#9051)
  • plugins: rename Google AdSpeed Insights to Publisher Ads Audit (#8906)
  • add lighthouse-plugin-field-performance to plugins (#9049)
  • add performance-budgets to related projects (#8971)

I18n

  • minor fr and ta translation updates (#8999)

Misc

  • assets: remove outdated extension screenshots (#9015)
  • dot-js require() everywhere (#9006)
  • remove unneeded reportCategories from LH.ReportResult (#9001)
  • update minify-trace scripts; extract to lib/ (#8968)
  • fix master: tmp revert of scroll change in #8625 (#9059)

Tests

  • lint: require file extension in require() (#9017)
  • update a11y sample artifacts (#9010)
  • remove compile-devtools on travis (#8988)
  • smoke: re-enable dialog prompt (#8894)
