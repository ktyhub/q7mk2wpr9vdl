Commit-Nachricht

🚀 LobeHub-Veröffentlichung (20261018)

Veröffentlichungsdatum: 18. Oktober 2026
Seit v2.2.19: 419 zusammengeführte PRs · 14 Mitwirkende

Agenten erreichen jetzt eine größere Reichweite auf Ihren Geräten und die App wird schneller geöffnet. Themen, Dokumente und Gerätedaten werden zuerst von lokalen Kopien geladen, und Serverausführungen können Modelle verwenden, die nur auf Ihrem Gerät vorhanden sind.

✨ Highlights

  • Ziele mit Batch-Rollout – Ein Ziel bleibt ein Entwurf, bis Sie es starten, und ein Ziel kann eine wiederholte Aufgabe in Batches ausrollen. Jede Charge stoppt an einem Entscheidungspunkt, den der Eigentümer überprüfen kann. (#20840, #20704, #20917, #20833)
  • Widgets und Dashboards – Home- und Projekt-Dashboards, ein Agenten-Widget-Tool, Chat-Vorschauen und neue lh widget/lh dashboard-Befehle. (#20421, #20771)
  • LLM-Weiterleitung an Ihr Gerät – Serverseitige Ausführungen, voreingestellte Aufgaben, Modelllisten und Ollama-Downloads können jetzt Modelle verwenden, die nur in Ihrem Browser-Tab oder Ihrer Desktop-App verfügbar sind. (#20453, #20454, #20455, #20456, #20457)
  • Remote-Terminals und Gerätewartung – Öffnen Sie interaktive Shells auf verbundenen Geräten über das Internet und aktualisieren oder starten Sie CLI-Daemons über die Geräteeinstellungen neu. (#20600, #20527, #20528)
  • Lokales Laden zuerst – Themen, Agentendokumente, Geräte, Git-Status und Home-Letzte werden zuerst von lokalen Replikaten geladen, sodass Seiten Inhalte anzeigen, bevor das Netzwerk antwortet. (#20449, #20869, #20838, #20841, #20851)
  • Agent-Dokumentordner – Ordner, Stapelverschiebungen, Dokumente als übergeordnete Dokumente und Sortierung nach Name, Erstellungs- oder Änderungszeit. (#20761, #20926)
  • Speicher aus Ihren Materialien – Speicher kann Regeln aus eingefügten Texten, Dateien, Dokumenten und Gesprächen extrahieren. (#20266)
  • Fork aus einer Antwort – Starten Sie ein neues Thema aus einer beliebigen Assistentennachricht. (#20610)

🏗️ Kernagent und Architektur

– Unteragenten laufen über den übergeordneten Executor, und afterToolCall-Steuerelemente können Tool-Ergebnisse steuern. (#20446, #20297)

  • Im Composer oder CLI ausgewählte Fähigkeiten werden bei Serverläufen eingefügt. Durch das Hinzufügen eines Agenten werden die Market-Skills installiert, auf die er verweist. (#20961, #21059)
  • Bei Agent-zu-Agent-Nachrichten wird jetzt angezeigt, welcher Agent sie gesendet hat. (#20548)
  • Weniger wiederholte Geräte- und Marktsuchen bei jedem Versand und Projektversand werden sofort angezeigt. (#20465, #20897, #20628)

📱 Plattformen / Integrationen

  • Heterogene Agenten: DeepSeek Harness-Adapter. Der Codex-App-Server kann auf verbundenen Geräten (hinter Labs) ausgeführt werden. Codex-Benutzernachrichten können bearbeitet und erneut gesendet werden. Codex und Pi können jedes Tool-fähige LobeHub-Modell verwenden. Droid und OpenCode unterstützen Server-Standardmodelle. (#18333, #20820, #20467, #20612, #20965, #20963)
  • Desktop: Gebündelte Computernutzungs-App unter macOS, geführte macOS-Datenschutzberechtigungen, Dock-Menü mit laufenden Themen, Tab-Ziehen mit Anheften/Entfernen und sofortiger Themenwechsel. (#20780, #20932, #20635, #20650, #21001)
  • Modelle: Claude Haiku 5.5, fal H3 Max und Seedance 2.5 Video. (#20517, #20210)
  • OpenAPI: Asynchroner IM-Kanal und Push-Token-REST-Ressourcen. (#20440)

🖥️ CLI & Benutzererfahrung

  • Aufgaben: Archivieren, Aufgaben aus Kanban-Spalten erstellen und Aufgaben über das Befehlsmenü erstellen oder suchen. (#20990, #21020, #21000, #21002)
  • Seitenleistenthemen können innerhalb eines Projekts nach Gerät, Zeit, Status oder Agent gruppiert werden. (#20811, #20592, #20715)
  • Projekte können ein Logo haben und der Papierkorb kann nach Projekt gefiltert werden. (#20641, #20739)
  • lh connect --auv bietet Computernutzung an und lh connect service install akzeptiert --workspace. (#20983, #20818)
  • Die Einstellungssuche ordnet die Ergebnisse besser und verarbeitet IME-Eingaben. (#20620)

🔒 Sicherheit und Zuverlässigkeit

  • Sicherheit: Desktop kann Sicherheitsupdates erfordern und prüft den ersten Start von Canary-Builds. Anmeldeinformationen werden über ein sicheres Formular erfasst. nodemailer wurde auf ^9.1.1 aktualisiert. (#20168, #20469, #20338)
  • Zuverlässigkeit: OAuth durchläuft keine E-Mail-Validierung mehr und Replikate ignorieren Hydrate und Fehler, die zu spät eintreffen. (#20545, #20754)

Changes

Commit Message

🚀 LobeHub Release (20261018)

Release Date: October 18, 2026
Since v2.2.19: 419 merged PRs · 14 contributors

Agents now reach further across your devices, and the app opens faster. Topics, documents and device data load from local copies first, and server runs can use models that only exist on your device.

✨ Highlights

  • Goals with batch rollout — A goal stays a draft until you start it, and a Goal can roll out one repeated task in batches. Each batch stops at a decision gate for the owner to review. (#20840, #20704, #20917, #20833)
  • Widgets & dashboards — Home and project dashboards, an agent widget tool, chat previews, and new lh widget / lh dashboard commands. (#20421, #20771)
  • LLM relay to your device — Server-side runs, preset tasks, model lists and Ollama downloads can now use models that are only available in your browser tab or desktop app. (#20453, #20454, #20455, #20456, #20457)
  • Remote terminals & device maintenance — Open interactive shells on connected devices from the web, and update or restart CLI daemons from device settings. (#20600, #20527, #20528)
  • Local-first loading — Topics, agent documents, devices, git status and home recents load from local replicas first, so pages show content before the network responds. (#20449, #20869, #20838, #20841, #20851)
  • Agent document folders — Folders, batch moves, documents as parents, and sorting by name, created or modified time. (#20761, #20926)
  • Memory from your materials — Memory can extract rules from pasted text, files, documents and conversations. (#20266)
  • Fork from a reply — Start a new topic from any assistant message. (#20610)

🏗️ Core Agent & Architecture

  • Sub-agents run through the parent's executor, and afterToolCall controls can gate tool results. (#20446, #20297)
  • Skills selected in the composer or CLI are injected on server runs. Adding an agent installs the Market skills it references. (#20961, #21059)
  • Agent-to-agent messages now show which agent sent them. (#20548)
  • Fewer repeated device and Market lookups on each send, and project sends appear right away. (#20465, #20897, #20628)

📱 Platforms / Integrations

  • Heterogeneous agents: DeepSeek Harness adapter. Codex app-server can run on connected devices (behind Labs). Codex user messages can be edited and resent. Codex and Pi can use any tool-capable LobeHub model. Droid and OpenCode support server-default models. (#18333, #20820, #20467, #20612, #20965, #20963)
  • Desktop: Bundled Computer Use app on macOS, guided macOS privacy permissions, Dock menu with running topics, tab drag with pin/unpin, and instant topic switching. (#20780, #20932, #20635, #20650, #21001)
  • Models: Claude Haiku 5.5, fal H3 Max and Seedance 2.5 video. (#20517, #20210)
  • OpenAPI: Async IM channel and push-token REST resources. (#20440)

🖥️ CLI & User Experience

  • Tasks: archiving, creating tasks from Kanban columns, and creating or searching tasks from the command menu. (#20990, #21020, #21000, #21002)
  • Sidebar topics can be grouped by device, time, status or agent within a project. (#20811, #20592, #20715)
  • Projects can have a logo, and the trash can be filtered by project. (#20641, #20739)
  • lh connect --auv offers Computer Use, and lh connect service install accepts --workspace. (#20983, #20818)
  • Settings search ranks results better and handles IME input. (#20620)

🔒 Security & Reliability

  • Security: Desktop can require security updates and checks the first launch of Canary builds. Credentials are collected through a secure form. nodemailer is updated to ^9.1.1. (#20168, #20469, #20338)
  • Reliability: OAuth no longer goes through email validation, and replicas ignore hydrates and errors that arrive late. (#20545, #20754)
