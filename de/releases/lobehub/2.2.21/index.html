Commit-Nachricht

🚀 LobeHub-Veröffentlichung (20261029)

Veröffentlichungsdatum: 29. Oktober 2026
Seit v2.2.20: 616 zusammengeführte PRs · 16 Mitwirkende

Projekte werden zum Ort, an dem Arbeit stattfindet – Gespräche, Kanäle, Aufgaben und Akzeptanz leben in ihnen – während Bots lernen, wann sie sich zu Wort melden müssen, Ziele eine vollständige Überprüfungsschleife erhalten und Ressourcen zu Dokumenten werden.

✨ Highlights

  • Projekte als Arbeitsbereiche – Führen Sie Konversationen und Aufgaben innerhalb eines Projekts aus, mit einem Projekt-Home-Composer, Mitglieder- und Bibliothekseinstellungen, einem austauschbaren Hauptagenten, Themen, die nach Agenten gruppiert und nach Status und Gerät gefiltert werden, Projekten, die per Drag-and-drop neu angeordnet werden können, und innerhalb von Projekten gruppierten Kanälen. (#21370, #21345, #21344, #21483, #21382, #21398, #21490, #21752)
  • Multi-Agent-Kanäle – Agenten arbeiten in Kanälen zusammen, jeder Kanal erbt das Gerät und das Verzeichnis seines Agenten und die neu gestalteten Kanaleinstellungen behalten den Antwortstil und die Emojis pro Kanal bei. (#21545, #21782, #21658, #21757)
  • Bot-Wake – Bots entscheiden basierend auf ihren Pflichten, wann sie antworten, können zuerst bestätigen und in einem Thread antworten, werden bei Änderungen aktiviert, die sie @-erwähnen, halten sich aus Threads mit mehreren Teilnehmern heraus und die Entscheidung, nicht zu antworten, wird als eigener Status dargestellt. Verfügbar auf Discord, Slack und Feishu / Lark. (#21585, #21726, #21719, #21756, #21728, #21727, #21825)
  • Zielarbeitsbereich – Eine agentenübergreifende Zielseite, Entscheidungsoptionsbäume, ein Bereitstellungsbericht zur Überprüfung vor der Freigabe, Kopieren von Zielen zwischen persönlichen und Arbeitsbereichsbereichen sowie North-Star-Metrikdiagramme. (#21221, #21560, #21773, #21665, #21126)
  • Dokumente und Favoriten – Ressourcen werden in Dokumente mit Seitenleistenansichtsoptionen und Artefakt-Rendering umstrukturiert; Sie können eine beliebige Seite an einen Favoritenbereich in der Seitenleiste anheften. (#21373, #21548, #21572)
  • Canvas – HTML-Artefakte mit mehreren Dateien, gerendert mit Lobe-*-Elementen, Code-Hervorhebung, einer expliziten Schaltfläche zum Teilen und einheitlicher Canvas/HTML-CLI-Veröffentlichung. (#21326, #21506, #21589, #21671)
  • Editor 7.0 – Warnungen, Diagramme und Fußnoten in Dokumenten und das Slash-Menü sowie ein Seiteninhaltsverzeichnis im Notion-Stil. (#21799, #21826, #21321)
  • Lineare Integration – Verbinden Sie Linear über OAuth und synchronisieren Sie Linear-Probleme mit Projektaufgaben. (#21036, #21723)

🏗️ Kernagent und Architektur

  • Subagenten laufen im Hintergrund und übermitteln ihre Ergebnisse als Nachrichten. (#20862)
  • Entscheidungsmodelle über OpenRouter und die nativen Entscheidungen API von OpenAI, konfigurierbar pro Kanal und in den neu gestalteten Servicemodelleinstellungen, zusammen mit dem Verifizierermodell. (#20836, #21359, #21788, #21480, #21774) – Neue Anbieter und Modelle: Magpie, TypeSafe, MiniMax M3.1 Flash und jeder Fal-Endpunkt mit seiner Bild-/Video-Modellliste. (#21644, #21444, #21216, #21238) – Für übergroße Anfragen wird eine Kontextkomprimierung angeboten und der Verlauf wird beibehalten, wenn die Komprimierungszusammenfassung fehlschlägt. (#21504, #21590)
  • Stdio MCP-Sitzungen bleiben über Tool-Aufrufe hinweg aktiv und zeigen umsetzbare Startfehler an; MCP handelt moderne HTTP-Protokollversionen aus. (#21031, #21110, #21743)
  • Gefilterte Nachrichtensuche, Zielsuche und lh recall. (#21188) – Große Server-Router, Dienste und Datenbankmodelle wurden in fokussierte Module aufgeteilt, und viele client-Stores sind auf @lobechat/replica umgestiegen, um schnellere Stale-First-Paints zu ermöglichen. (#21085, #21132, #21145, #21200, #21118)

📱 Plattformen / Integrationen

  • OpenAPI: Chatgruppen bei /api/v1/chat-groups, führen Sie jetzt eine Aufgabe aus und lesen Sie ihre Ausführungen bei /api/v1/tasks/{id}/runs und Endpunkten für Benachrichtigungseinstellungen. (#21280, #21470, #21538)
  • IM: hochgeladene Nachrichtenanhänge, Chat-Bilder, die für das Model beim Lesen der Nachricht sichtbar sind, und Discord-Antworten, die tatsächlich Personen @-erwähnen. (#21581, #21758, #21736)
  • Externe Agenten: Datei-/Bild-Upload im +-Menü, Claude Code sieht claude.ai-Konnektoren und gerätegebundene Läufe werden bei einem erneuten Versuch fortgesetzt, anstatt die Runde zu löschen. (#21794, #21294, #21494)
  • Desktop: Betriebssystembenachrichtigung, wenn ein Workspace-Mitglied Sie erwähnt, und schwebende Link-URLs in der Statusleiste. (#21436, #21291)
  • Mobil: Desktop-Oberflächen kommen ins mobile Web. (#21503)
  • CLI: lh gen json, lh gen decide, lh read <url>, lh notification, Workspace-Slugs für --workspace, ein wiederverbindbarer WebSocket anstelle von SSE und das Browser-Tool auf lh connect-Geräten. (#21413, #21835, #21514, #21539, #21540, #20501, #21422)
  • SDK: OAuth-Helfer für native Apps und ein AccessToken-Anbieter. (#21435)

🖥️ Benutzererfahrung

  • Akzeptanz gewinnt an Arbeitsbereich, Projektbindung, Endbeweis und Feedbackübergabe an den ursprünglichen Agenten. (#21432, #21392, #21734, #21619)
  • Der Speicher ersetzt die Kontextseite durch Entitätsseiten, die auf echten Speicherdaten basieren. (#21347)
  • Finden Sie ein Thema mit Mod+F, Hover-Prefetch von Themenseiten und einen Workspace-Papierkorb. (#21530, #21724, #21537)
  • Generierte Avatare für Agenten, Personen und Arbeitsbereiche ohne einen solchen sowie eine Agentenlisten-Badge-Wand. (#21778, #21632, #21786, #21815) – Konnektoren werden als Liste → Detailseiten geöffnet, mit einer Arbeitsbereichseinstellung, wer sie verwaltet. (#21684, #21653)
  • Klarere chinesische Benutzeroberflächenkopie mit korrigierten Fehlübersetzungen. (#21505)

🔒 Sicherheit und Zuverlässigkeit

  • Sicherheit: JWKS-Schlüsselrotation für Authentifizierung. (#21431)
  • Sicherheit: Speicher-Webhooks erfordern eine Authentifizierungskonfiguration und die Anmeldeinformationen des Anbieterendpunkts sind isoliert. (#21254, #21255)
  • Sicherheit: @modelcontextprotocol/sdk wurde aufgrund einer Sicherheitswarnung aktualisiert, Marktplatz-OAuth-MCP-Installationen sind autorisiert und MCP-Protokolle schwärzen vertrauliche Metadaten. (#21351, #21367, #21423)
  • Sicherheit: Das sichere Anmeldeinformationsformular kann nicht mehr über Benachrichtigungsoberflächen genehmigt werden. (#20580)
  • Zuverlässigkeit: Websitzungen bleiben mit verzögerter Sitzungsaktualisierung am Leben. (#21707)
  • Zuverlässigkeit: SSRF-sichere Fetch-Streams übertragen Antworttexte, anstatt sie zu puffern. (#21701)
  • Selbsthosting: Diese Version enthält mehrere Datenbankmigrationen (Favoriten, lineare Synchronisierung, Kanallebenszyklus, Projektseiten und Mitgliedsrollen); Sie werden beim Start automatisch ausgeführt. (#21792, #21722, #21691, #21290)

Commit Message

🚀 LobeHub Release (20261029)

Release Date: October 29, 2026
Since v2.2.20: 616 merged PRs · 16 contributors

Projects become the place where work happens — conversations, channels, tasks and acceptance live inside them — while bots learn when to speak up, goals gain a full review loop, and Resources become Docs.

✨ Highlights

  • Projects as workspaces — Run conversations and tasks inside a project, with a project home composer, members and libraries settings, a swappable main agent, topics grouped by agent and filtered by status and device, drag-to-reorder projects, and channels grouped inside projects. (#21370, #21345, #21344, #21483, #21382, #21398, #21490, #21752)
  • Multi-agent channels — Agents collaborate in channels, each channel inherits its Agent's device and directory, and the redesigned channel settings keep reply style and emoji per channel. (#21545, #21782, #21658, #21757)
  • Bot wake — Bots decide when to reply based on their duties, can acknowledge first and answer in a thread, wake on edits that @-mention them, stay out of multi-party threads, and the choice not to reply renders as its own state. Available on Discord, Slack and Feishu / Lark. (#21585, #21726, #21719, #21756, #21728, #21727, #21825)
  • Goals workspace — A cross-agent goals page, decision option trees, a delivery report to review before sign-off, copying goals between personal and workspace scopes, and north-star metric charts. (#21221, #21560, #21773, #21665, #21126)
  • Docs and Favorites — Resources are restructured into Docs with sidebar view options and artifact rendering; pin any page to a sidebar Favorites section. (#21373, #21548, #21572)
  • Canvas — Multi-file HTML artifacts rendered with lobe-* elements, code highlighting, an explicit share button, and unified Canvas/HTML CLI publishing. (#21326, #21506, #21589, #21671)
  • Editor 7.0 — Alerts, charts and footnotes in documents and the slash menu, plus a Notion-style page table of contents. (#21799, #21826, #21321)
  • Linear integration — Connect Linear via OAuth and sync Linear issues into project tasks. (#21036, #21723)

🏗️ Core Agent & Architecture

  • Sub-agents run in the background and deliver their results as messages. (#20862)
  • Decision models via OpenRouter and OpenAI's native Decisions API, configurable per channel and in the redesigned Service Model settings, along with the verifier model. (#20836, #21359, #21788, #21480, #21774)
  • New providers and models: Magpie, TypeSafe, MiniMax M3.1 Flash, and any fal endpoint with its image/video model list. (#21644, #21444, #21216, #21238)
  • Context compaction is offered for oversized requests, and history is kept when the compaction summary fails. (#21504, #21590)
  • Stdio MCP sessions stay alive across tool calls and show actionable startup errors; MCP negotiates modern HTTP protocol versions. (#21031, #21110, #21743)
  • Filtered message search, goal search and lh recall. (#21188)
  • Large server routers, services and database models split into focused modules, and many client stores moved onto @lobechat/replica for faster stale-first paints. (#21085, #21132, #21145, #21200, #21118)

📱 Platforms / Integrations

  • OpenAPI: chat groups at /api/v1/chat-groups, run a task now and read its runs at /api/v1/tasks/{id}/runs, and notification settings endpoints. (#21280, #21470, #21538)
  • IM: uploaded message attachments, chat images visible to the model in message reads, and Discord replies that actually @-mention people. (#21581, #21758, #21736)
  • External agents: file/image upload in the + menu, Claude Code sees claude.ai connectors, and device-bound runs resume on retry instead of wiping the turn. (#21794, #21294, #21494)
  • Desktop: OS notification when a workspace member mentions you, and hovered link URLs in the status bar. (#21436, #21291)
  • Mobile: desktop surfaces come to the mobile web. (#21503)
  • CLI: lh gen json, lh gen decide, lh read <url>, lh notification, workspace slugs for --workspace, a reconnectable WebSocket in place of SSE, and the browser tool on lh connect devices. (#21413, #21835, #21514, #21539, #21540, #20501, #21422)
  • SDK: OAuth helpers for native apps and an accessToken provider. (#21435)

🖥️ User Experience

  • Acceptance gains workspace scope, project binding, terminal evidence and feedback hand-off to the original agent. (#21432, #21392, #21734, #21619)
  • Memory replaces the contexts page with entity pages built on real memory data. (#21347)
  • Find in topic with Mod+F, hover prefetch of topic pages, and a workspace recycle bin. (#21530, #21724, #21537)
  • Generated avatars for agents, people and workspaces without one, and an agent list badge wall. (#21778, #21632, #21786, #21815)
  • Connectors open as list → detail pages, with a workspace setting for who manages them. (#21684, #21653)
  • Clearer Chinese UI copy with mistranslations corrected. (#21505)

🔒 Security & Reliability

  • Security: JWKS key rotation for auth. (#21431)
  • Security: memory webhooks require authentication configuration, and provider endpoint credentials are isolated. (#21254, #21255)
  • Security: @modelcontextprotocol/sdk updated for a security advisory, marketplace OAuth MCP installations are authorized, and MCP logs redact sensitive metadata. (#21351, #21367, #21423)
  • Security: the secure credential form can no longer be approved from notification surfaces. (#20580)
  • Reliability: web sessions stay alive with deferred session refresh. (#21707)
  • Reliability: SSRF-safe fetch streams response bodies instead of buffering them. (#21701)
  • Self-hosting: this release ships several database migrations (favorites, Linear sync, channel lifecycle, project sites and member roles); they run automatically on startup. (#21792, #21722, #21691, #21290)
