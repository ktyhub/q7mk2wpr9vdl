Hyperframes v0.9.71

HyperFrames v0.9.71

Veröffentlicht am 19.11.2026. Durch das Abbrechen eines Rendervorgangs wird nun dessen Kompilierung gestoppt, und für Dateien, die beim Kompilieren heruntergeladen werden, gilt eine Größenbeschränkung und eine gemeinsame Frist. Rendert gelesene Frames aus MP4s, deren Suchindex den ersten Keyframe auslässt, und SVG-lastige Kompositionen bleiben innerhalb der Kompilierungsgrößenbeschränkung.

Korrekturen

  • Engine: Extrahieren Sie Frames aus MP4s, deren Suchindex den ersten Keyframe auslässt (9813a6cbe, #8252).
  • Mediennutzung: Duck-, Cut-, Transkribierungs-, Dither- und Audioskripte drucken Steuerzeichen als Escapezeichen (98f548447, #8235). – Kern: Attributwert-Escapes schreiben „<“, sodass Stiltext nicht vorzeitig enden kann (9e7835367, #8250).
  • Mediennutzung: Provider-Fehlerzeilen drucken Steuerzeichen als Escapes (77134c927, #8249).
  • Kern: Halten Sie das Wachstum des SVG-Selektor-Alias ​​innerhalb des Kompilierungsbudgets (6bd0b5d87, #8238).
  • Lint: Den Start eines Medienfensters durch den Parser lesen (a7d7a6075, #8133).
  • Produzent: Das Abbrechen eines Rendervorgangs stoppt dessen Kompilierung (765883195, #8242).
  • Produzent: Remote-Downloads zur Kompilierungszeit begrenzen, ihnen eine Frist geben und sie bei Abbruch stoppen (77ea9d80c, #8195).
  • Kern: Stoppt den Absturz bei SVG-Elementen mit dem Namen „Vorlage“ (d106f9c8c, #8241).
  • Kern: Selektor-Aliase nur aus dem lesen, was der Compiler geschrieben hat (def770ed9, #8240).
  • Kern: Seitenlaufzeiten enthalten keine Breitzeichen, daher bleiben Seiten ein Byte pro Zeichen (01a5e948b, #8239).
  • Mediennutzung: Erneutes Einfrieren eines Rezeptarchivs nur unter einer Ganzzahlversion (e383abf47, #8201).

Dokumente und Beispiele

  • Anwender: ViralMint hinzufügen (78d8ad037, #7738).

Katalog

  • CLI: Einen leeren Katalog --type= als Nutzungsfehler melden (c2911adc8, #8130).

Intern

  • CLI: Die Telefon-clip-Offload-Tests bestehen, wenn sie zusammen ausgeführt werden (3f3a6205a, #8071).

hyperframes v0.9.71

HyperFrames v0.9.71

Released on 2026-11-19.

Cancelling a render now stops its compile, and files a compile downloads have a size cap and one shared deadline. Renders read frames from MP4s whose seek index leaves out the first keyframe, and SVG-heavy compositions stay within the compile size limit.

Fixes

  • Engine: Extract frames from MP4s whose seek index leaves out the first keyframe (9813a6cbe, #8252).
  • Media Use: Duck, cut, transcribe, dither and audio scripts print control characters as escapes (98f548447, #8235).
  • Core: Attribute-value escapes write '<' so style text can't end early (9e7835367, #8250).
  • Media Use: Provider error lines print control characters as escapes (77134c927, #8249).
  • Core: Keep SVG selector alias growth within the compile budget (6bd0b5d87, #8238).
  • Lint: Read a media window's start through the parser (a7d7a6075, #8133).
  • Producer: Cancelling a render stops its compile (765883195, #8242).
  • Producer: Cap compile-time remote downloads, give them one deadline and stop them on cancel (77ea9d80c, #8195).
  • Core: Stop crashing on SVG elements named template (d106f9c8c, #8241).
  • Core: Read selector aliases only from what the compiler wrote (def770ed9, #8240).
  • Core: Page runtimes carry no wide characters, so pages stay one byte a char (01a5e948b, #8239).
  • Media Use: Re-freezing a recipe archives only under an integer version (e383abf47, #8201).

Docs & Examples

  • Adopters: Add ViralMint (78d8ad037, #7738).

Catalog

  • CLI: Report an empty catalog --type= as a usage error (c2911adc8, #8130).

Internal

  • CLI: The phone-clip offload tests pass when run together (3f3a6205a, #8071).
