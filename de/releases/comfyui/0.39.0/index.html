ComfyUI v0.39.0

Highlights

  • Offline & node-source flags — #16672 adds --offline and --disable-partner-nodes and deprecates --disable-api-nodes. This is the lever for air-gapped installs and for pinning which node families load at startup; audit launch scripts still passing the old flag, since it keeps working but is now on the deprecation path.
  • Output encoding defaults changed — Save Video gets higher-quality encoding defaults (#16663), and Save EXR gains 16-bit float support with the exr option's default bit depth raised to 16-bit float (#16706, #16715). Workflows that never touched these nodes will emit different, likely larger files, so check storage budgets and any downstream tool that assumes integer bit depth.
  • Partner Nodes expand — with two walk-backs — New model nodes land for Anthropic Sonnet 5.5 (#16647), Ideogram 4.5 (#16689), HeyGen Video 1.0 (#16695), BFL FLUX 3 (#16716), Grok imagine-video-1.5-lite (#16721), and ElevenLabs Eleven v4 / v4 Turbo (#16737). At the same time, Luma Ray 2 nodes are deprecated (#16741) and GPT Image 2 loses its transparent-background output (#16744) — revisit any workflow depending on those two behaviors.
  • MiniMax H3 gets cheaper to run — LynnReal light Minimax-H3 VAE support (#16657), a VAE offload fix (#16698), and release of embedding temporaries before blocks (#16677) jointly reduce peak VRAM for H3 pipelines. If you previously had to over-reserve memory or force aggressive offload, it's worth re-tuning.
  • Asset scans stop blocking saves — The largest theme of the release is SQLite contention cleanup: the assets DB switches to WAL with synchronous=NORMAL and short transactions (#16748), prune/offline marking and scan inserts are batched (#16696, #16748), scans pause during the folder walk and resume once the prompt queue drains (#16764, #16765), and no DB lock is taken at all when assets are off (#16742). Net effect: long model-folder scans no longer lock out uploads and output saves. Also included are cross-volume upload copies (#16722), tolerant category scans (#16658), and record recovery when a drive returns with hashing disabled (#16646).
  • Attention, GPU, and crash fixes — comfy_attention / AttentionTensorContainer coverage expands to more models (#16766); pinned memory is auto-disabled on integrated GPUs (#16746); and the int8/int4 cache crash in Qwen Image 2.1 is fixed (#16667). iGPU users get a safer out-of-the-box default, and mixed-precision Qwen users can retry quantized caches.

No breaking changes in this release.
