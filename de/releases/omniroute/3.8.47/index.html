Highlights

  • Routing controls and budget enforcement — auto/* combos add opt-in strict budget enforcement through X-OmniRoute-Budget-Fallback: strict or config.budgetFallback: "strict"; over-cap requests return HTTP 402 instead of silently selecting a potentially still-over-budget target (#3470). Combo context requirements (#6907), parameter filtering learned from upstream 400s (#6649), and manual context-window overrides (#4125) reduce avoidable routing failures. ClinePass offers both OAuth and BYOK under the corrected cp routing alias (#6126), giving organization-managed and API-key-based accounts a supported connection path.

Use it deliberately for diagnostics or collaborative workflows rather than as a transparent replacement for normal routing.
