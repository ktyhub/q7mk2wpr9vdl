agno v2.4.8

Changelog

Neue Funktionen:

  • CEL-Unterstützung für Workflow-Schritte: Verwenden Sie CEL-Ausdrücke (Common Expression Language) als Evaluatoren in Bedingungs-, Schleifen- und Router-Schritten. CEL-Ausdrücke sind Zeichenfolgen, wodurch Workflow-Schritte vollständig serialisierbar sind.
  • Neosantara-Modellanbieter: fügt Unterstützung für Neosantara hinzu, ein indonesisches LLM-Gateway, das einen OpenAI-kompatiblen API bereitstellt
  • Studio: Visueller Editor zum Erstellen von Agenten, Teams und Workflows in AgentOS. Drag-and-Drop-Schnittstelle mit einer Registry zur Verwaltung von Tools, Modellen, Datenbanken und Schemata.

Verbesserungen:

  • Workflow-Router-Schritt: Es wurde die Möglichkeit hinzugefügt, den Namen des Schritts anstelle des Schritts selbst zurückzugeben, sowie die Unterstützung, eine Gruppe von Schritten als Auswahl für den Router zurückzugeben
  • WebsiteReader Chunking: Verwendet jetzt standardmäßig FixedSizeChunking anstelle von Semantic, um die Notwendigkeit eines OpenAI API-Schlüssels zu beseitigen, wenn kein bestimmter Chunker festgelegt wird.
  • Fähigkeiten: Fügen Sie Shebang-Parsing und Windows-Befehlserstellung für die Skriptausführung hinzu

Fehlerbehebungen:

  • LanceDB: Abwärtskompatibilität für veraltetes table_names() hinzugefügt
  • Parallelschritt: Der parallele Schritt in Workflows wurde so korrigiert, dass er auch den Namen als erstes Positionsargument akzeptiert. – AzureOpenAI: Die AzureOpenAI-Authentifizierung wurde so korrigiert, dass sie azure_ad_token_provider enthält
  • Agentic State Tool: Das Tool update_session_state wurde korrigiert, um session_state korrekt aus run_context zu extrahieren, nachdem _session_state aus der Funktionsklasse in Agno 2.4.0 entfernt wurde.
  • LearningMachine: Benutzernachricht zu SessionContextStore hinzufügen, um Claude/Gemini-Kompatibilität zu gewährleisten.

agno v2.4.8

Highlights

  • Serializable workflow control flow — Condition, Loop, and Router evaluators now accept CEL strings, and workflow step containers support serialization (#6101). Saved workflows can carry routing logic as data instead of Python callables; verify CEL semantics when migrating existing evaluators.
  • More composable Router choices — selectors can return a step name or a group of steps as one choice (#6215), enabling reusable steps and composite routes without manually expanding them into separate routers.
  • Studio visual builder and registry rename — AgentOS Studio adds drag-and-drop creation for Agents, Teams, and Workflows, plus management of tools, models, databases, and schemas. RegistryContentType is renamed to RegistryResourceType (#6285); update imports and type references accordingly.
  • WebsiteReader no longer requires OpenAI by default — the default changes from semantic chunking to FixedSizeChunking (#6091), removing the API-key requirement. Chunk boundaries and retrieval quality may differ; explicitly select semantic or custom chunking if preserving previous behavior matters.
  • Authentication and workflow-runtime corrections — AzureOpenAI now supports azure_ad_token_provider (#6092), update_session_state reads from run_context after the Agno 2.4.0 Function change (#6260), and executor events propagate workflow session_id for consistent streaming (#6272). Revalidate token-based Azure deployments, state-mutating tools, and session-scoped event handling.
  • Broader provider and platform support — Neosantara adds an OpenAI-compatible Indonesian model gateway (#6290), while script Skills gain shebang parsing and Windows command construction (#6241). Test provider-specific tool calling and executable Skills on Windows before broad deployment.

Changelog

New Features:

  • CEL Support for Workflow Steps: Use CEL (Common Expression Language) expressions as evaluators in Condition, Loop, and Router steps. CEL expressions are strings, making workflow steps fully serializable.
  • Neosantara model provider: adds support for Neosantara, an Indonesian LLM gateway that provides an OpenAI-compatible API
  • Studio: Visual editor for building Agents, Teams, and Workflows in AgentOS. Drag-and-drop interface with a Registry for managing tools, models, databases, and schemas.

Improvements:

  • Workflow Router Step: Added the ability to return name of the Step instead of the step itself as well as support to return a group of steps as a choice for the router
  • WebsiteReader Chunking: Now uses FixedSizeChunking instead of Semantic by default to remove the need for an OpenAI API key when not setting any specific chunker.
  • Skills: Add shebang parsing and Windows command building for script execution

Bug Fixes:

  • LanceDB: Added backward compatibility for deprecated table_names()
  • Parallel Step: Fixed parallel step in workflows to also accept name as first positional arg.
  • AzureOpenAI: Fixed AzureOpenAI authentication to include azure_ad_token_provider
  • Agentic State Tool: Fixed update_session_state tool to correctly extract session_state from run_context after _session_state was removed from the Function class in Agno 2.4.0.
  • LearningMachine: Add user message to SessionContextStore for Claude/Gemini compatibility.
