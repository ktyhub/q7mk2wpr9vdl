🌐 Englisch | 中文

💬 Verbesserungen der Webkonsole

Diese Version fügt der Webkonsole mehrere visuelle Verwaltungsfunktionen hinzu, sodass mehr Konfigurationen in der Benutzeroberfläche vorgenommen werden können, ohne dass Dateien bearbeitet werden müssen:

  • Verwaltung geplanter Aufgaben: Anzeigen, Bearbeiten, Aktivieren/Deaktivieren und Löschen aller geplanten Aufgaben direkt in der Konsole. Die Aufgabenliste wird zuerst nach dem aktivierten Status und dann nach der nächsten Ausführungszeit sortiert. Danke @HnBigVolibear (#2892)
  • Wissensdatenbankkategorien und Dokumentenverwaltung: Die Wissensdatenbank kann jetzt nach Kategorien organisiert werden, wobei Dokumente unter jeder Kategorie in der Benutzeroberfläche verwaltet werden. Danke @yangziyu-hhh (#2893)
  • Mehrere benutzerdefinierte Modellanbieter: Konfigurieren Sie mehrere OpenAI-kompatible Anbieter und wechseln Sie den aktiven Anbieter mit einem einzigen click, vollständig kompatibel mit der vorhandenen Konfiguration. Danke @kirs-hi (#2877)
  • Sitzungsumbenennung: Sitzungen manuell umbenennen, um parallele Aufgaben zu unterscheiden (#2897)
  • Bash-Streaming-Ausgabe: Bash-Befehle mit langer Laufzeit streamen ihren Fortschritt jetzt in Echtzeit. Danke @yangziyu-hhh (#2879)

🧬 Verbesserungen der Selbstentwicklung

Diese Version baut auf der in der vorherigen Version eingeführten Selbstentwicklung auf und verfeinert sie weiter:

  • Niedrigere Auslöseschwellenwerte: Die standardmäßigen Überprüfungsschwellenwerte werden gesenkt, sodass die tägliche Zusammenarbeit schneller zu Verbesserungen führt
  • Keine gleichzeitigen Überprüfungen: Wenn eine einzelne Runde lange dauert, wird die Leerlaufüberprüfung nicht mehr versehentlich ausgelöst, wodurch eine Beeinträchtigung der aktiven Konversation vermieden wird
  • Bessere Rezensionszusammenfassung: Die Zusammenfassungsaufforderung wurde verfeinert, um Zusammenfassungen prägnant zu halten, ihre Informationsdichte zu erhöhen und sie in der Konversationssprache auszugeben

Dokumentation: Selbstentwicklung

🤖 Neue Modelle

  • kimi-k2.7-code: Hinzugefügt und als Standard-Kimi-Modell festgelegt, wobei auch kimi-k2.7-code-highspeed verfügbar ist
  • glm-5.2: Hinzugefügt und als Standard-GLM-Modell festgelegt

Dokumentation: Modellübersicht

🏢 WeCom Smart-Bot-Rückrufmodus

Der WeCom Smart-Bot-Kanal fügt neben der bestehenden langen Verbindung einen HTTP-Rückrufmodus hinzu, sodass Bereitstellungen, die keine lange Verbindung offen halten können, dennoch zuverlässig eine Verbindung herstellen können:

  • Modusumschaltung: Wechsel zwischen websocket (lange Verbindung) und webhook (Rückruf) über wecom_bot_mode
  • Verschlüsselter Transport: Der Rückrufmodus unterstützt vollständig die URL-Überprüfung, Nachrichtenentschlüsselung und passive Antwortverschlüsselung
  • Stabilitätskorrekturen: Antwortunterbrechung, vorzeitige Stream-Beendigung und vorübergehende Bilddateilecks behoben

Danke @6vision (#2896 #2869)

Dokumentation: WeCom Smart Bot

🔒 Sicherheitshärtung

  • Vision-Tool SSRF-Schutz: Validiert die Zieladresse vor der Auflösung einer Bild-URL und blockiert Anfragen an interne, Loopback- und Cloud-Server-Metadatenendpunkte. Danke @kirs-hi (#2886)
  • Web-Abruf-SSRF-Schutz: web_fetch validiert die Zieladresse vor dem Abrufen und validiert jeden Umleitungs-Hop erneut, um zu verhindern, dass Weiterleitungen die Prüfung umgehen, um interne Adressen zu erreichen. Danke @christop (#2900)
  • Skill-Installationspfad-Traversal-Schutz: Validiert den Pfad bei der Installation eines Skills und verhindert so, dass ein bösartiger Skill-Name durch Pfaddurchquerung und Schreiben an einen nicht autorisierten Speicherort aus dem skills/-Verzeichnis austritt. Danke @kirs-hi (#2886)

🛠 Verbesserungen und Korrekturen

  • CLI-Selbstneustart: Der Befehl cow self-restart wurde hinzugefügt, damit der Agent seinen eigenen Prozess neu starten kann
  • Windows-Kompatibilität: Behalten Sie das Cow-Verzeichnis CLI im Benutzerpfad bei; python -c-Langbefehle behoben, die die Längenbeschränkung von cmd.exe überschritten; Vermeiden Sie es, während der Installation ein Greenlet aus der Quelle zu erstellen
  • Benutzerdefinierte Rollen: Das Rollen-Plugin unterstützt die Anpassung über eigenständige Eingabeaufforderungsdateien unter roles/*.json. Danke @sufan721 (#2891)
  • Stabilitätskorrekturen: Ein KeyError auf /cancel und eine Endlosschleife bei der Bildkomprimierung wurden behoben (Danke @kirs-hi #2888)
  • Installationsverbesserungen: Das Startskript und die Standardkonfiguration wurden aktualisiert; ASR/TTS-Standardeinstellungen, das Self-Evolution-Flag und Installationsabstürze behoben
  • Stabilität des Vision-Tools: Das Timeout und die max_tokens des Vision-Tools wurden erhöht
  • Speicherdestillation: Die Ausgabelängenbegrenzung in der Deep-Dream-Destillation wurde entfernt, um das Abschneiden eines großen MEMORY.md zu vermeiden

📦 Upgrade

Quellcode-Bereitstellungen können cow update für ein click-Upgrade ausführen oder den neuesten Code abrufen und manuell neu starten. Einzelheiten finden Sie im Upgrade-Leitfaden.

Englisches Original / English original

chatgpt-on-wechat 2.1.2

Highlights

  • Web Console management — Scheduled tasks and category-organized knowledge-base documents can now be managed entirely in the UI (#2892, #2893), while multiple OpenAI-compatible providers can be configured and switched without rewriting existing configuration (#2877). This reduces file-editing overhead for day-to-day administration.
  • New default models — kimi-k2.7-code—with kimi-k2.7-code-highspeed available—and glm-5.2 become the respective Kimi and GLM defaults. Upgrade deployments that depend on a specific model should explicitly pin the previous model until they revalidate model-specific behavior.
  • Self-evolution behavior — Lower review thresholds make routine collaboration trigger improvements sooner, while long active turns now suppress accidental concurrent idle reviews. Summaries also follow the conversation language; expect more frequent review activity, but without reviews competing with an ongoing turn.
  • WeCom callback mode — Set wecom_bot_mode=webhook to replace the long connection with an HTTP callback when persistent outbound connections are impractical. Callback mode supports URL verification, message decryption, and encrypted passive replies; reply interruption, premature stream termination, and image-file leaks are also fixed (#2896, #2869).
  • SSRF and install hardening — Vision and web_fetch now reject internal, loopback, and cloud-metadata targets, with redirects revalidated at every hop (#2886, #2900). Integrations that fetch private resources may need approved external endpoints; skill installation also blocks path traversal outside skills/ (#2886).
  • Compatibility — No breaking changes are declared.

🌐 English | 中文

💬 Web Console Improvements

This release adds several visual management capabilities to the Web Console, so more configuration can be done in the UI without editing files:

  • Scheduled task management: View, edit, enable/disable, and delete any scheduled task directly in the console. The task list is sorted by enabled status first, then by next run time. Thanks @HnBigVolibear (#2892)
  • Knowledge base categories and document management: The knowledge base can now be organized by category, with documents under each category managed in the UI. Thanks @yangziyu-hhh (#2893)
  • Multiple custom model providers: Configure multiple OpenAI-compatible providers and switch the active one with a single click, fully compatible with existing configuration. Thanks @kirs-hi (#2877)
  • Session renaming: Rename sessions manually to tell parallel tasks apart (#2897)
  • Bash streaming output: Long-running Bash commands now stream their progress in real time. Thanks @yangziyu-hhh (#2879)

🧬 Self-Evolution Improvements

Building on the Self-Evolution introduced in the previous release, this version refines it further:

  • Lower trigger thresholds: The default review thresholds are lowered, so everyday collaboration turns into improvements sooner
  • No concurrent reviews: When a single turn runs long, the idle review no longer fires by mistake, avoiding interference with the active conversation
  • Better review summary: Refined the summary prompt to keep summaries concise, raise their information density, and output them in the conversation language

Documentation: Self-Evolution

🤖 New Models

  • kimi-k2.7-code: Added and set as the default Kimi model, with kimi-k2.7-code-highspeed also available
  • glm-5.2: Added and set as the default GLM model

Documentation: Models Overview

🏢 WeCom Smart-Bot Callback Mode

The WeCom smart-bot channel adds an HTTP callback mode alongside the existing long connection, so deployments that cannot keep a long connection open can still connect reliably:

  • Mode switching: Switch between websocket (long connection) and webhook (callback) via wecom_bot_mode
  • Encrypted transport: Callback mode fully supports URL verification, message decryption, and passive-reply encryption
  • Stability fixes: Fixed reply interruption, premature stream termination, and temporary image file leaks

Thanks @6vision (#2896 #2869)

Documentation: WeCom Smart Bot

🔒 Security Hardening

  • Vision tool SSRF protection: Validates the target address before resolving an image URL, blocking requests to internal, loopback, and cloud server metadata endpoints. Thanks @kirs-hi (#2886)
  • Web fetch SSRF protection: web_fetch validates the target address before fetching and re-validates every redirect hop, preventing redirects from bypassing the check to reach internal addresses. Thanks @christop (#2900)
  • Skill install path traversal protection: Validates the path when installing a skill, preventing a malicious skill name from escaping the skills/ directory through path traversal and writing to an unauthorized location. Thanks @kirs-hi (#2886)

🛠 Improvements & Fixes

  • CLI self-restart: Added the cow self-restart command so the agent can restart its own process
  • Windows compatibility: Persist the cow CLI directory to the user PATH; fixed python -c long commands exceeding the cmd.exe length limit; avoid building greenlet from source during install
  • Custom roles: The role plugin supports customization via standalone prompt files under roles/*.json. Thanks @sufan721 (#2891)
  • Stability fixes: Fixed a KeyError on /cancel and an infinite loop in image compression (Thanks @kirs-hi #2888)
  • Install improvements: Updated the startup script and default config; fixed ASR/TTS defaults, the self-evolution flag, and install hangs
  • Vision tool stability: Increased the vision tool timeout and max_tokens
  • Memory distillation: Removed the output length cap in deep-dream distillation to avoid truncating a large MEMORY.md

📦 Upgrade

Source-code deployments can run cow update for a one-click upgrade, or pull the latest code and restart manually. See the Upgrade Guide for details.
