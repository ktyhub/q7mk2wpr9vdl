Ketzer v2.0.0

Breaking Changes

Heretic 2.0 ist eine Hauptversion, die die Abwärtskompatibilität beeinträchtigt:

  • Für Heretic 1.x erstellte Konfigurationsdateien sind nicht kompatibel mit Heretic 2.0! Im Migrationsleitfaden erfahren Sie, was Sie ändern müssen, damit Ihre alten Konfigurationen funktionieren.
  • Forschungsfunktionen wurden entfernt. Der vorgesehene Ersatz ist Lophius.

heretic v2.0.0

Breaking Changes

Heretic 2.0 is a major release that breaks backwards compatibility:

  • Configuration files made for Heretic 1.x are not compatible with Heretic 2.0! See the migration guide for what you need to change in order to make your old configurations work.
  • Research features have been removed. The intended replacement is Lophius.
