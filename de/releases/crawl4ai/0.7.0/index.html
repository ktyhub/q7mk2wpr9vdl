🚀 Crawl4AI v0.7.0: Das Adaptive Intelligence Update

28. Januar 2025 • 10 Minuten Lesezeit

Heute veröffentliche ich Crawl4AI v0.7.0 – das Adaptive Intelligence Update. Diese Version führt grundlegende Verbesserungen bei der Bewältigung moderner Webkomplexität durch Crawl4AI durch adaptives Lernen, intelligente Inhaltserkennung und erweiterte Extraktionsfunktionen ein.

🎯 Das Neue auf einen Blick

  • Adaptives Crawling: Ihr Crawler lernt jetzt Website-Muster und passt sich diesen an
  • Unterstützung für virtuelles Scrollen: Vollständige Inhaltsextraktion aus unendlich scrollbaren Seiten
  • Linkvorschau mit 3-Layer-Scoring: Intelligente Linkanalyse und Priorisierung
  • Asynchroner URL-Seeder: Entdecken Sie Tausende von URLs in Sekundenschnelle mit intelligenter Filterung
  • PDF-Analyse: Daten aus PDF-Dokumenten extrahieren
  • Leistungsoptimierungen: Erhebliche Geschwindigkeits- und Speicherverbesserungen

🧠 Adaptives Crawlen: Intelligenz durch Musterlernen

Das Problem: Websites ändern sich. Klassennamen verschieben sich. Ausweise verschwinden. Ihre sorgfältig erstellten Selektoren brechen um 3 Uhr morgens ab und Sie wachen mit leeren Datensätzen und verärgerten Stakeholdern auf.

Meine Lösung: Ich habe ein adaptives Lernsystem implementiert, das Muster beobachtet, Vertrauenswerte erstellt und Extraktionsstrategien im laufenden Betrieb anpasst. Es ist, als hätte man einen Nachwuchsentwickler, der seinen Job mit jeder Seite, die er durchsucht, besser macht.

Technischer Deep-Dive

Der Adaptive Crawler verwaltet einen dauerhaften Status für jede Domain und verfolgt Folgendes:

  • Mustererfolgsraten
  • Selektorstabilität im Laufe der Zeit
  • Variationen der Inhaltsstruktur
  • Extraktions-Konfidenzwerte
from crawl4ai import AdaptiveCrawler, AdaptiveConfig, CrawlState

# Initialize with custom learning parameters
config = AdaptiveConfig(
    confidence_threshold=0.7,    # Min confidence to use learned patterns
    max_history=100,            # Remember last 100 crawls per domain
    learning_rate=0.2,          # How quickly to adapt to changes
    patterns_per_page=3,        # Patterns to learn per page type
    extraction_strategy='css'   # 'css' or 'xpath'
)

adaptive_crawler = AdaptiveCrawler(config)

# First crawl - crawler learns the structure
async with AsyncWebCrawler() as crawler:
    result = await crawler.arun(
        "https://news.example.com/article/12345",
        config=CrawlerRunConfig(
            adaptive_config=config,
            extraction_hints={  # Optional hints to speed up learning
                "title": "article h1",
                "content": "article .body-content"
            }
        )
    )
    
    # Crawler identifies and stores patterns
    if result.success:
        state = adaptive_crawler.get_state("news.example.com")
        print(f"Learned {len(state.patterns)} patterns")
        print(f"Confidence: {state.avg_confidence:.2%}")

# Subsequent crawls - uses learned patterns
result2 = await crawler.arun(
    "https://news.example.com/article/67890",
    config=CrawlerRunConfig(adaptive_config=config)
)
# Automatically extracts using learned patterns!

Erwartete Auswirkungen in der Praxis:

  • Nachrichtenaggregation: Behalten Sie eine Extraktionsgenauigkeit von über 95 % bei, auch wenn Nachrichtenseiten ihre Vorlagen aktualisieren
  • E-Commerce-Überwachung: Verfolgen Sie Produktänderungen in Hunderten von Geschäften ohne ständige Wartung
  • Erfassung von Forschungsdaten: Erstellen Sie robuste akademische Datensätze, die Website-Neugestaltungen überstehen
  • Reduzierter Wartungsaufwand: Verkürzung der Selektoraktualisierungszeit um 80 % für häufig wechselnde Standorte

🌊 Virtuelle Schriftrolle: Vollständige Inhaltserfassung

Das Problem: Moderne Web-Apps rendern nur das, was sichtbar ist. Scrollen Sie nach unten, neue Inhalte erscheinen, alte Inhalte verschwinden im Nichts. Herkömmliche Crawler erfassen das erste Ansichtsfenster und übersehen 90 % des Inhalts. Es ist, als würde man von jedem Buch nur die erste Seite lesen.

Meine Lösung: Ich habe eine Virtual Scroll-Unterstützung entwickelt, die das Surfverhalten von Menschen nachahmt, Inhalte beim Laden erfasst und speichert, bevor der Garbage Collector des Browsers zuschlägt.

Implementierungsdetails

from crawl4ai import VirtualScrollConfig

# For social media feeds (Twitter/X style)
twitter_config = VirtualScrollConfig(
    container_selector="[data-testid='primaryColumn']",
    scroll_count=20,                    # Number of scrolls
    scroll_by="container_height",       # Smart scrolling by container size
    wait_after_scroll=1.0,             # Let content load
    capture_method="incremental",       # Capture new content on each scroll
    deduplicate=True                   # Remove duplicate elements
)

# For e-commerce product grids (Instagram style)
grid_config = VirtualScrollConfig(
    container_selector="main .product-grid",
    scroll_count=30,
    scroll_by=800,                     # Fixed pixel scrolling
    wait_after_scroll=1.5,             # Images need time
    stop_on_no_change=True            # Smart stopping
)

# For news feeds with lazy loading
news_config = VirtualScrollConfig(
    container_selector=".article-feed",
    scroll_count=50,
    scroll_by="page_height",           # Viewport-based scrolling
    wait_after_scroll=0.5,
    wait_for_selector=".article-card",  # Wait for specific elements
    timeout=30000                      # Max 30 seconds total
)

# Use it in your crawl
async with AsyncWebCrawler() as crawler:
    result = await crawler.arun(
        "https://twitter.com/trending",
        config=CrawlerRunConfig(
            virtual_scroll_config=twitter_config,
            # Combine with other features
            extraction_strategy=JsonCssExtractionStrategy({
                "tweets": {
                    "selector": "[data-testid='tweet']",
                    "fields": {
                        "text": {"selector": "[data-testid='tweetText']", "type": "text"},
                        "likes": {"selector": "[data-testid='like']", "type": "text"}
                    }
                }
            })
        )
    )
    
    print(f"Captured {len(result.extracted_content['tweets'])} tweets")

Hauptfunktionen:

  • DOM Recycling Awareness: Erkennt und verarbeitet das virtuelle DOM-Element recycling
  • Smart Scroll Physics: Drei Modi – Containerhöhe, Seitenhöhe oder feste Pixel
  • Inhaltserhaltung: Erfasst Inhalte, bevor sie zerstört werden
  • Intelligentes Stoppen: Stoppt, wenn kein neuer Inhalt angezeigt wird
  • Speichereffizient: Streamt Inhalte, anstatt alles im Speicher zu halten

Erwartete Auswirkungen in der Praxis:

  • Social-Media-Analyse: Erfassen Sie ganze Twitter-Threads mit Hunderten von Antworten, nicht nur die Top 10
  • E-Commerce Scraping: Extrahieren Sie mehr als 500 Produkte aus unzähligen Scroll-Katalogen im Vergleich zu 20–50 mit herkömmlichen Methoden
  • Nachrichtenaggregation: Erhalten Sie alle Artikel von modernen Nachrichtenseiten, nicht nur „above thefold“-Inhalte
  • Forschungsanwendungen: Vollständige Datenextraktion aus akademischen Datenbanken mithilfe virtueller Paginierung

🔗 Linkvorschau: Intelligente Linkanalyse und -bewertung

Das Problem: Sie crawlen eine Seite und erhalten 200 Links. Welche sind wichtig? Was führt zu den Inhalten, die Sie tatsächlich wollen? Herkömmliche Crawler zwingen Sie dazu, alles zu verfolgen oder komplexe Filter zu erstellen.

Meine Lösung: Ich habe ein dreistufiges Bewertungssystem implementiert, das Links wie ein Mensch analysiert – unter Berücksichtigung ihrer Position, ihres Kontexts und ihrer Relevanz für Ihre Ziele.

Das dreistufige Bewertungssystem

from crawl4ai import LinkPreviewConfig

# Configure intelligent link analysis
link_config = LinkPreviewConfig(
    # What to analyze
    include_internal=True,
    include_external=True,
    max_links=100,              # Analyze top 100 links
    
    # Relevance scoring
    query="machine learning tutorials",  # Your interest
    score_threshold=0.3,        # Minimum relevance score
    
    # Performance
    concurrent_requests=10,     # Parallel processing
    timeout_per_link=5000,      # 5s per link
    
    # Advanced scoring weights
    scoring_weights={
        "intrinsic": 0.3,       # Link quality indicators
        "contextual": 0.5,      # Relevance to query
        "popularity": 0.2       # Link prominence
    }
)

# Use in your crawl
result = await crawler.arun(
    "https://tech-blog.example.com",
    config=CrawlerRunConfig(
        link_preview_config=link_config,
        score_links=True
    )
)

# Access scored and sorted links
for link in result.links["internal"][:10]:  # Top 10 internal links
    print(f"Score: {link['total_score']:.3f}")
    print(f"  Intrinsic: {link['intrinsic_score']:.1f}/10")  # Position, attributes
    print(f"  Contextual: {link['contextual_score']:.1f}/1")  # Relevance to query
    print(f"  URL: {link['href']}")
    print(f"  Title: {link['head_data']['title']}")
    print(f"  Description: {link['head_data']['meta']['description'][:100]}...")

Bewertungskomponenten:

  1. Intrinsischer Score (0-10): Basierend auf Linkqualitätsindikatoren

    • Position auf der Seite (Navigation, Inhalt, Fußzeile)
    • Linkattribute (rel, Titel, Klassennamen)
    • Qualität und Länge des Ankertextes
    • URL-Struktur und -Tiefe

  2. Kontextbewertung (0-1): Relevanz für Ihre Anfrage

    • Semantische Ähnlichkeit durch Einbettungen
    • Keyword-Übereinstimmung in Linktext und Titel
    • Meta-Beschreibungsanalyse
    • Bewertung der Inhaltsvorschau

  3. Gesamtpunktzahl: Gewichtete Kombination für die endgültige Rangliste

Erwartete Auswirkungen in der Praxis:

  • Forschungseffizienz: Finden Sie relevante Artikel 10x schneller, indem Sie nur Links mit hoher Punktzahl folgen
  • Wettbewerbsanalyse: Identifizieren Sie automatisch wichtige Seiten auf Websites von Mitbewerbern
  • Content Discovery: Erstellen Sie themenorientierte Crawler, die auf dem richtigen Weg bleiben
  • SEO-Audits: Identifizieren und priorisieren Sie hochwertige interne Verlinkungsmöglichkeiten

🎣 Asynchroner URL-Seeder: Automatisierte URL-Erkennung im großen Maßstab

Das Problem: Sie möchten eine gesamte Domain crawlen, haben aber nur die Homepage. Oder schlimmer noch, Sie möchten bestimmte Inhaltstypen auf Tausenden von Seiten. Manuelle URL-Erkennung? Das ist eine Aufgabe für Maschinen, nicht für Menschen.

Meine Lösung: Ich habe Async URL Seeder entwickelt – eine turbogeladene URL-Erkennungs-Engine, die mehrere Quellen mit intelligenter Filterung und Relevanzbewertung kombiniert.

Technische Architektur

from crawl4ai import AsyncUrlSeeder, SeedingConfig

# Basic discovery - find all product pages
seeder_config = SeedingConfig(
    # Discovery sources
    source="sitemap+cc",        # Sitemap + Common Crawl
    
    # Filtering
    pattern="*/product/*",      # URL pattern matching
    ignore_patterns=["*/reviews/*", "*/questions/*"],
    
    # Validation
    live_check=True,           # Verify URLs are alive
    max_urls=5000,             # Stop at 5000 URLs
    
    # Performance  
    concurrency=100,           # Parallel requests
    hits_per_sec=10           # Rate limiting
)

seeder = AsyncUrlSeeder(seeder_config)
urls = await seeder.discover("https://shop.example.com")

# Advanced: Relevance-based discovery
research_config = SeedingConfig(
    source="crawl+sitemap",    # Deep crawl + sitemap
    pattern="*/blog/*",        # Blog posts only
    
    # Content relevance
    extract_head=True,         # Get meta tags
    query="quantum computing tutorials",
    scoring_method="bm25",     # Or "semantic" (coming soon)
    score_threshold=0.4,       # High relevance only
    
    # Smart filtering
    filter_nonsense_urls=True,  # Remove .xml, .txt, etc.
    min_content_length=500,     # Skip thin content
    
    force=True                 # Bypass cache
)

# Discover with progress tracking
discovered = []
async for batch in seeder.discover_iter("https://physics-blog.com", research_config):
    discovered.extend(batch)
    print(f"Found {len(discovered)} relevant URLs so far...")

# Results include scores and metadata
for url_data in discovered[:5]:
    print(f"URL: {url_data['url']}")
    print(f"Score: {url_data['score']:.3f}")
    print(f"Title: {url_data['title']}")

Erkennungsmethoden:

  • Sitemap Mining: Analysiert robots.txt und alle verknüpften Sitemaps
  • Common Crawl: Fragt den Common Crawl-Index nach historischen URLs ab
  • Intelligentes Crawling: Verfolgt Links mit intelligenter Tiefenkontrolle
  • Musteranalyse: Erlernt URL-Strukturen und generiert Variationen

Erwartete Auswirkungen in der Praxis:

  • Migrationsprojekte: Entdecken Sie mehr als 10.000 URLs von älteren Websites in weniger als 60 Sekunden
  • Marktforschung: Kartieren Sie automatisch komplette Wettbewerber-Ökosysteme
  • Akademische Forschung: Erstellen Sie umfassende Datensätze ohne manuelle URL-Erfassung
  • SEO-Audits: Finden Sie jede indexierbare Seite mit Inhaltsbewertung
  • Inhaltsarchivierung: Stellen Sie sicher, dass bei Site-Migrationen kein Inhalt zurückbleibt

🔗 Link Preview: Intelligent Link Analysis and Scoring

The Problem: You crawl a page and get 200 links. Which ones matter? Which lead to the content you actually want? Traditional crawlers force you to follow everything or build complex filters.

My Solution: I implemented a three-layer scoring system that analyzes links like a human would—considering their position, context, and relevance to your goals.

The Three-Layer Scoring System

from crawl4ai import LinkPreviewConfig

# Configure intelligent link analysis
link_config = LinkPreviewConfig(
    # What to analyze
    include_internal=True,
    include_external=True,
    max_links=100,              # Analyze top 100 links
    
    # Relevance scoring
    query="machine learning tutorials",  # Your interest
    score_threshold=0.3,        # Minimum relevance score
    
    # Performance
    concurrent_requests=10,     # Parallel processing
    timeout_per_link=5000,      # 5s per link
    
    # Advanced scoring weights
    scoring_weights={
        "intrinsic": 0.3,       # Link quality indicators
        "contextual": 0.5,      # Relevance to query
        "popularity": 0.2       # Link prominence
    }
)

# Use in your crawl
result = await crawler.arun(
    "https://tech-blog.example.com",
    config=CrawlerRunConfig(
        link_preview_config=link_config,
        score_links=True
    )
)

# Access scored and sorted links
for link in result.links["internal"][:10]:  # Top 10 internal links
    print(f"Score: {link['total_score']:.3f}")
    print(f"  Intrinsic: {link['intrinsic_score']:.1f}/10")  # Position, attributes
    print(f"  Contextual: {link['contextual_score']:.1f}/1")  # Relevance to query
    print(f"  URL: {link['href']}")
    print(f"  Title: {link['head_data']['title']}")
    print(f"  Description: {link['head_data']['meta']['description'][:100]}...")

Scoring Components:

  1. Intrinsic Score (0-10): Based on link quality indicators

    • Position on page (navigation, content, footer)
    • Link attributes (rel, title, class names)
    • Anchor text quality and length
    • URL structure and depth

  2. Contextual Score (0-1): Relevance to your query

    • Semantic similarity using embeddings
    • Keyword matching in link text and title
    • Meta description analysis
    • Content preview scoring

  3. Total Score: Weighted combination for final ranking

Expected Real-World Impact:

  • Research Efficiency: Find relevant papers 10x faster by following only high-score links
  • Competitive Analysis: Automatically identify important pages on competitor sites
  • Content Discovery: Build topic-focused crawlers that stay on track
  • SEO Audits: Identify and prioritize high-value internal linking opportunities

🎣 Async URL Seeder: Automated URL Discovery at Scale

The Problem: You want to crawl an entire domain but only have the homepage. Or worse, you want specific content types across thousands of pages. Manual URL discovery? That's a job for machines, not humans.

My Solution: I built Async URL Seeder—a turbocharged URL discovery engine that combines multiple sources with intelligent filtering and relevance scoring.

Technical Architecture

from crawl4ai import AsyncUrlSeeder, SeedingConfig

# Basic discovery - find all product pages
seeder_config = SeedingConfig(
    # Discovery sources
    source="sitemap+cc",        # Sitemap + Common Crawl
    
    # Filtering
    pattern="*/product/*",      # URL pattern matching
    ignore_patterns=["*/reviews/*", "*/questions/*"],
    
    # Validation
    live_check=True,           # Verify URLs are alive
    max_urls=5000,             # Stop at 5000 URLs
    
    # Performance  
    concurrency=100,           # Parallel requests
    hits_per_sec=10           # Rate limiting
)

seeder = AsyncUrlSeeder(seeder_config)
urls = await seeder.discover("https://shop.example.com")

# Advanced: Relevance-based discovery
research_config = SeedingConfig(
    source="crawl+sitemap",    # Deep crawl + sitemap
    pattern="*/blog/*",        # Blog posts only
    
    # Content relevance
    extract_head=True,         # Get meta tags
    query="quantum computing tutorials",
    scoring_method="bm25",     # Or "semantic" (coming soon)
    score_threshold=0.4,       # High relevance only
    
    # Smart filtering
    filter_nonsense_urls=True,  # Remove .xml, .txt, etc.
    min_content_length=500,     # Skip thin content
    
    force=True                 # Bypass cache
)

# Discover with progress tracking
discovered = []
async for batch in seeder.discover_iter("https://physics-blog.com", research_config):
    discovered.extend(batch)
    print(f"Found {len(discovered)} relevant URLs so far...")

# Results include scores and metadata
for url_data in discovered[:5]:
    print(f"URL: {url_data['url']}")
    print(f"Score: {url_data['score']:.3f}")
    print(f"Title: {url_data['title']}")

Discovery Methods:

  • Sitemap Mining: Parses robots.txt and all linked sitemaps
  • Common Crawl: Queries the Common Crawl index for historical URLs
  • Intelligent Crawling: Follows links with smart depth control
  • Pattern Analysis: Learns URL structures and generates variations

Expected Real-World Impact:

  • Market Research: Map entire competitor ecosystems automatically
  • Academic Research: Build comprehensive datasets without manual URL collection
