photocraft v0.23.1

Was hat sich geändert?

  • fix(ui): Den Farbsampler-Cursor beibehalten, während ein Sampler von @RickiNano in https://github.com/storytold/photocraft/pull/13212 gezogen wird (#13063).
  • fix(ui): Der beliebige Winkel rundet in f64 und behält diesen Wert (#13067) von @RickiNano in https://github.com/storytold/photocraft/pull/13217
  • Tool entfernen: 19-Pixel-Pinsel nach dem Zurücksetzen des Tools und bei der ersten Verwendung durch @rmsff in https://github.com/storytold/photocraft/pull/13151
  • Veröffentlichung: PhotoCraft v0.23.0 auf der Hauptseite von @FredApps in https://github.com/storytold/photocraft/pull/13345
  • Entfernen: Warnung auf einer Pixelebene mit „Alle sperren“ von @rmsff in https://github.com/storytold/photocraft/pull/13171
  • Stift: Wenn Sie einen Pfad nach Abschluss rückgängig machen, wird er wieder an den Stift zurückgegeben, anstatt ihn zu löschen (#6619) von @marmitoTH in https://github.com/storytold/photocraft/pull/6413
  • ci: Verwenden Sie die von StepSecurity verwalteten Aktionen von @dylanmtaylor in https://github.com/storytold/photocraft/pull/13337
  • macOS-Signierung: Dekodieren Sie das Zertifikat in eine exklusive temporäre Datei von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11028
  • Ort: Verweigern Sie eine Skalierung, die dazu führt, dass das platzierte Bild die Renderpixelgrenze von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11229 überschreitet
  • Automatisierung: save_bytes liest niemals verknüpfte Dateien von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11233
  • Escape-Steuerzeichen in Protokollzeilen und Diagnoseausgaben aus Dateien und Plug-Ins von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11218
  • Text: Laden Sie die Ausgabekacheln des Rasterizers auf, nicht nur seine Pixel von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11047
  • fix(engine): Wenden Sie die Metadatenauswahl auf WebP Quick Export von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11058 an
  • fix(compose): Gradientenstopps halbieren, übergroße Effektkarten entfernen, leere Distanztransformationen überspringen von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11056
  • Camera Raw: Lesen Sie jede Quellzeile einmal, wenn Sie den Vorschau-Proxy von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11064 erstellen
  • fix(cms): Entschlüsselte CLUT-Werte gegen ein Pro-Profil-Budget von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11055 berechnen
  • Speichern: Ein Ersatz in einer anderen Gruppe erweitert den Gruppenzugriff von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11232 nicht
  • fix(ui-egui): Das erneute Lesen von RAW wurde gebunden, und symbolisch verknüpfte Namen werden so behandelt, wie sie im Batch-Export von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11204 übernommen wurden
  • fix(algo): Rohfilterparameter in ihren Bereichen halten (Water Paper, Box Blur, Lanczos, Camera Raw Noise) von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11199
  • fix(algo): gebundene EXIF-Textdekodierung, Warp-Scans, Galeriefenster, Inpaint-Größen, Pyramidentiefe von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11161
  • Codecs: Listen Sie jede Cryptomatte-Ebene einmal auf und indizieren Sie Streams nach Namen von @dylanmtaylor in https://github.com/storytold/photocraft/pull/10978
  • fix(gpu): Plan-Akku-Slots und Gradient-Lookup-Tabellen von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11061 begrenzen
  • fix(io): Gebühr für Importeure für die gesamten Fliesenoberflächen, die von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11144 verwaltet werden
  • fix(format,engine): zstd-Fenster einschränken, Bundle-Modi über das Handle festlegen, symbolisch verknüpfte Voreinstellungen von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11145 ablehnen
  • Fix(Codecs): überprüfte Größen in Encodern, EXR-Namenssuche, FITS-Float-Limit, VP8-Flugzeugkopien, EXIF-Thumbnail-Bytes von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11164
  • Fix(Engine): gebundene, spärliche Neuzuordnung, skalierte Klonquellen, Pfadlesevorgänge, Exportformat, Namenssuche durch @dylanmtaylor in https://github.com/storytold/photocraft/pull/11181
  • fix(engine): Autorisierung für verschachtelte Scratch-Sitzungen und voreingestellte Aufrufe, CSV- und PostScript-Text escaping von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11188
  • Aktionen: Übersprungene Schritte dem Wiedergabebudget hinzufügen, Batch-Verschachtelung einschränken, clip die festgelegte Überschreibung durch @dylanmtaylor in https://github.com/storytold/photocraft/pull/10969
  • Engine: Überprüfen Sie dichte Arbeitspuffer anhand eines Budgets, bevor Sie spärlichen Inhalt von @dylanmtaylor in https://github.com/storytold/photocraft/pull/10964 erweitern
  • Farbe: Lehne einen sequentiellen Tupferstrich ab, dessen Arbeitskopie zu groß ist von @dylanmtaylor in https://github.com/storytold/photocraft/pull/11070
  • CI: nächtlicher Probelauf zur Veröffentlichung durch @FredApps in https://github.com/storytold/photocraft/pull/13374
  • Zoom-Werkzeug: Schaltflächen für den Vergrößerungs-/Verkleinerungsmodus (#12066) von @RickiNano in https://github.com/storytold/photocraft/pull/13013
  • Ankerpunkt löschen: Alt-click an einem Anker wählt seinen gesamten Unterpfad durch @rmsff in https://github.com/storytold/photocraft/pull/13188 aus
  • Punkt konvertieren: Ziehen Sie ein Segment, wie es die Direktauswahl von @rmsff in https://github.com/storytold/photocraft/pull/13141 macht
  • Freiformstift: Schließen Sie einen Strich nur innerhalb von 3 Pixeln vor seinem Start auf jeder Achse von @rmsff in https://github.com/storytold/photocraft/pull/13313
  • Linienwerkzeug: Pfeilspitzen mit einer Gewichtung von 1 px und 5 × 10 px standardmäßig und nach Reset Tool (#13241) von @RickiNano in https://github.com/storytold/photocraft/pull/13305
  • Tool-Optionsleiste zählen: jedes Steuerelement von Anfang an in der Referenzreihenfolge, Tooltips und Grautöne, Beschriftungen in Scrubby-Größe (#11765) von @hectorviov in https://github.com/storytold/photocraft/pull/12206
  • Paint: Zwei Stroke-Tests prüfen das Ergebnis, das der Stroke jetzt von @dylanmtaylor in https://github.com/storytold/photocraft/pull/13378 zurückgibt
  • Polygon-Werkzeug: Ein abgerundeter Stern rundet nur seine Außenpunkte ab (#13308) von @RickiNano in https://github.com/storytold/photocraft/pull/13342
  • Typoptionsleiste: Schaltfläche „Zeichen- und Absatzfenster umschalten“ von @slafebre in https://github.com/storytold/photocraft/pull/13020
  • Linienwerkzeug: Ein Ziehen ist ein Verlaufsschritt mit dem Namen „Linienwerkzeug“ (#13244) von @NaufalDzz in https://github.com/storytold/photocraft/pull/13303
  • Ankerpunkt löschen behält seinen Pfad beim ersten Escape bei und lässt einen Drag allein (#13072) von @Raghav2012Code in https://github.com/storytold/photocraft/pull/13176
  • Ankerpunkt hinzufügen: Ein zu einem geraden Segment hinzugefügter Anker ist glatt, mit Griffen (#12706) von @TrevorBrown-dev in https://github.com/storytold/photocraft/pull/13215
  • fix(ui): Beim Ziehen perspektivischer Zuschnitte ohne Bereich bleiben die cli-eckigen Ecken (#13065) von @Raghav2012Code in https://github.com/storytold/photocraft/pull/13234 erhalten
  • ci: Headless-GPU-Backend-Tests mit der nächsthöheren GPU-Gruppe von @davidmann4 in https://github.com/storytold/photocraft/pull/13257 begrenzen
  • Perspektivischer Zuschnitt: W, H und Auflösung werden mit Warnungen von @hectorviov in https://github.com/storytold/photocraft/pull/12237 auf die gemessenen Bereiche beschränkt
  • Flatpak-Updates behoben und auf 0.23.1 von @dylanmtaylor in https://github.com/storytold/photocraft/pull/13322 umgestellt Voll Changelog: https://github.com/storytold/photocraft/compare/v0.23.0...v0.23.1

photocraft v0.23.1

What's Changed

  • fix(ui): keep the Color Sampler cursor while a sampler is dragged (#13063) by @RickiNano in https://github.com/storytold/photocraft/pull/13212
  • fix(ui): the Arbitrary angle rounds in f64 and keeps that value (#13067) by @RickiNano in https://github.com/storytold/photocraft/pull/13217
  • Remove tool: 19 px brush after Reset Tool and on first use by @rmsff in https://github.com/storytold/photocraft/pull/13151
  • Release: PhotoCraft v0.23.0 on main by @FredApps in https://github.com/storytold/photocraft/pull/13345
  • Remove: alert on a pixel layer with Lock All by @rmsff in https://github.com/storytold/photocraft/pull/13171
  • Pen: Undo after finishing a path gives it back to the Pen instead of deleting it (#6619) by @marmitoTH in https://github.com/storytold/photocraft/pull/6413
  • ci: use StepSecurity's maintained actions by @dylanmtaylor in https://github.com/storytold/photocraft/pull/13337
  • macOS signing: decode the certificate into an exclusive temp file by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11028
  • Place: refuse a scale that makes the placed image exceed the render pixel limit by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11229
  • automation: save_bytes never reads linked files by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11233
  • Escape control characters in log lines and diagnostic output taken from files and plug-ins by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11218
  • text: charge the rasterizer's output tiles, not only its pixels by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11047
  • fix(engine): apply the metadata choice to WebP Quick Export by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11058
  • fix(compose): bisect gradient stops, evict oversized effect maps, skip empty distance transforms by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11056
  • Camera Raw: read each source row once when building the preview proxy by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11064
  • fix(cms): charge decoded CLUT values against a per-profile budget by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11055
  • Save: a replacement in another group does not widen group access by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11232
  • fix(ui-egui): bound the RAW re-read and treat symlinked names as taken in batch export by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11204
  • fix(algo): hold raw filter parameters to their ranges (Water Paper, Box Blur, Lanczos, Camera Raw noise) by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11199
  • fix(algo): bound EXIF text decoding, warp scans, gallery windows, inpaint sizes, pyramid depth by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11161
  • codecs: list each Cryptomatte layer once and index streams by name by @dylanmtaylor in https://github.com/storytold/photocraft/pull/10978
  • fix(gpu): cap plan accumulator slots and gradient lookup tables by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11061
  • fix(io): charge importers for the whole tiles surfaces keep by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11144
  • fix(format,engine): limit zstd windows, set bundle modes via the handle, refuse symlinked presets by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11145
  • fix(codecs): checked sizes in encoders, EXR name lookup, FITS float limit, VP8 plane copies, EXIF thumbnail bytes by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11164
  • fix(engine): bound sparse remap, scaled clone sources, path reads, export format, name lookups by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11181
  • fix(engine): authorization for nested scratch sessions and preset calls, CSV and PostScript text escaping by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11188
  • Actions: charge skipped steps to the playback budget, bound batch nesting, clip the set override by @dylanmtaylor in https://github.com/storytold/photocraft/pull/10969
  • Engine: check dense working buffers against a budget before expanding sparse content by @dylanmtaylor in https://github.com/storytold/photocraft/pull/10964
  • paint: refuse a sequential-dab stroke whose working copy is too large by @dylanmtaylor in https://github.com/storytold/photocraft/pull/11070
  • CI: nightly release dry run by @FredApps in https://github.com/storytold/photocraft/pull/13374
  • Zoom tool: Zoom In / Zoom Out mode buttons (#12066) by @RickiNano in https://github.com/storytold/photocraft/pull/13013
  • Delete Anchor Point: Alt-click on an anchor selects its whole subpath by @rmsff in https://github.com/storytold/photocraft/pull/13188
  • Convert Point: drag a segment as Direct Selection does by @rmsff in https://github.com/storytold/photocraft/pull/13141
  • Freeform Pen: close a stroke only within 3 px of its start on each axis by @rmsff in https://github.com/storytold/photocraft/pull/13313
  • Line tool: Weight 1 px and 5 × 10 px arrowheads by default and after Reset Tool (#13241) by @RickiNano in https://github.com/storytold/photocraft/pull/13305
  • Count tool options bar: every control from the start in the reference order, tooltips and greying, scrubby size captions (#11765) by @hectorviov in https://github.com/storytold/photocraft/pull/12206
  • paint: two stroke tests check the result the stroke now returns by @dylanmtaylor in https://github.com/storytold/photocraft/pull/13378
  • Polygon tool: a rounded star rounds only its outer points (#13308) by @RickiNano in https://github.com/storytold/photocraft/pull/13342
  • Type options bar: Toggle Character and Paragraph panels button by @slafebre in https://github.com/storytold/photocraft/pull/13020
  • Line tool: a drag is one History step named "Line Tool" (#13244) by @NaufalDzz in https://github.com/storytold/photocraft/pull/13303
  • Delete Anchor Point keeps its path on the first Escape, and leaves a drag alone (#13072) by @Raghav2012Code in https://github.com/storytold/photocraft/pull/13176
  • Add Anchor Point: an anchor added to a straight segment is smooth, with handles (#12706) by @TrevorBrown-dev in https://github.com/storytold/photocraft/pull/13215
  • fix(ui): a Perspective Crop drag with no area keeps the clicked corners (#13065) by @Raghav2012Code in https://github.com/storytold/photocraft/pull/13234
  • ci: cap headless GPU backend tests with the nextest gpu group by @davidmann4 in https://github.com/storytold/photocraft/pull/13257
  • Perspective Crop: W, H and Resolution clamp to the measured ranges with alerts by @hectorviov in https://github.com/storytold/photocraft/pull/12237
  • Fix Flatpak updates and bump to 0.23.1 by @dylanmtaylor in https://github.com/storytold/photocraft/pull/13322
