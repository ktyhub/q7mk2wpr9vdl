DeepTutor v1.2.4 Release Notes

Veröffentlichungsdatum: 2026.04.25

Highlights

Unterstützt weitere Anhangsformate im Chat

Die v1.2.3-Pipeline für Dokumentanhänge wurde über Office-Dateien hinaus erweitert. Chat-Anhänge akzeptieren jetzt dieselben textähnlichen Formate wie der Wissensdatenbank-Aufnahmerouter: Markdown, einfacher Text, Protokolle, JSON/YAML/TOML, CSV/TSV, LaTeX/BibTeX, HTML/XML/SVG, Stylesheets, Skripte und allgemeine Quellcodedateien (.py, .js, .ts, .tsx, .java, .cpp, .go, .rs, .sql, .sh und mehr).

  • Backend-Parität mit KB-Routing – deeptutor/utils/document_extractor.py importiert FileTypeRouter.TEXT_EXTENSIONS, sodass Chat-Anhänge und KB-Uploads eine gemeinsame Quelle der Wahrheit für Text-/Codeformate haben. FileTypeRouter.decode_bytes() zentralisiert die Fallback-Kette UTF-8 / UTF-8-BOM / GBK / GB18030 / Latin-1 / CP1252.
  • SVG als lesbare Quelle – .svg wurde dem RAG-Texterweiterungssatz hinzugefügt und wird als Dokumentanhang statt als Visionsbild behandelt, sodass das LLM die XML-Quelle prüfen kann, während das Frontend weiterhin eine sichere Miniaturvorschau rendert.
  • Typisierte Anhang-UX – web/lib/doc-attachments.ts stellt jetzt OFFICE_EXTS, TEXT_LIKE_EXTS, SVG-Erkennung, umfassenderes MIME-/Erweiterungs-Fallback und kategoriespezifische Symbole für Code, Shell, JSON, Konfiguration, Daten, Markup, Stylesheets, Nur-Text, Office-Dokumente und SVG bereit.
  • Composer-Kopie aktualisiert – der Drag-and-Drop-Hinweis wirbt jetzt mit „Bilder, Office-Dokumente, Code und Text“ anstelle der älteren Nur-Office-Liste.

Ein-Befehl-Setup-Tour

scripts/start_tour.py hat sich von einem reinen Konfigurationsassistenten zu einem 7-stufigen Neuinstallationspfad entwickelt, der die lokale Umgebung erkennen, Abhängigkeiten installieren und dann die Anbieterkonfiguration steuern kann.

  • Abhängigkeitsinstallationsschritt – die Tour prüft Python, uv, Node.js und npm; Installiert die Backend-Anforderungen, installiert DeepTutor im bearbeitbaren Modus und führt das Frontend npm install mit Live-Terminalausgabe aus.
  • uv pip-Kompatibilität (#376) – Die Python-Abhängigkeitsinstallation bevorzugt jetzt uv pip, sofern verfügbar, und bindet --python <current-interpreter>, sodass Pakete im Interpreter landen, der die Tour ausführt, und nicht in einem nicht verwandten .venv / $VIRTUAL_ENV.
  • Windows npm-Erkennung (#381) – npm-Aufrufe verwenden npm.cmd unter Windows, wodurch Versionsprüfungen und Installationsbefehle auf Systemen behoben werden, auf denen npm als Befehls-Shim und nicht als ausführbare Datei verfügbar gemacht wird.
  • Anbieterregistrierungsgesteuerte LLM-Auswahl – der Assistent liest jetzt aus der vollständigen PROVIDERS-Registrierung, gruppiert Anbieter nach Modus, hebt allgemeine Dienste hervor und umfasst neuere Optionen wie custom_anthropic, OpenRouter, SiliconFlow, Volcengine/BytePlus-Codierungsanbieter, GitHub Copilot, OpenAI Codex, llama.cpp, OVMS, MiniMax, Mistral, Qianfan, Step Fun und Xiaomi MiMo.
  • Such- und Konfigurationshinweise – Serper ist in der Suchanbieterliste verfügbar; Azure/API-Versions- und Proxy-Eingabeaufforderungen zeigen jetzt Inline-Anleitungen sowohl auf Englisch als auch auf Chinesisch an.
  • Terminal-UX für lange Listen – scripts/_cli_kit.py rendert lange Auswahlmenüs in einem Scrollfenster mit „mehr darüber/unten“-Anzeigen und verhindert so veraltete Terminalzeilen, wenn die Anbieterliste die Bildschirmhöhe überschreitet.

Chat-Markdown-Export

Auf der Chat-Seite gibt es jetzt neben „Im Notizbuch speichern“ und „Neuer Chat“ die Aktion Markdown herunterladen. web/lib/chat-export.ts serialisiert die aktuelle Konversation als Markdown mit einem Titel, einem ISO-Export-Zeitstempel, Rollenüberschriften, Fähigkeitsbezeichnungen und Anhangsmetadaten und lädt sie dann mit einem bereinigten Dateinamen mit Datumsstempel herunter. Dies bietet Benutzern einen einfachen lokalen Exportpfad zum Teilen, Archivieren oder Verschieben einer Konversation in externe Notizen.

Knowledge Base Management UI Polnisch

Die Wissensseite wurde für eine kompaktere Verwaltung im Alltag gestrafft:

  • Erstellungs- und Upload-Drop-Zones sind jetzt einfachere gestrichelte Karten mit prägnanten Zusammenfassungen der Inline-Upload-Richtlinien. – KB-Karten wurden von vier großen Statistikfeldern in kompakte Zeilen verschoben, die die Anzahl der Dokumente, die Indexbereitschaft, den Zeitpunkt der letzten Aktualisierung, den Anbieter, das Einbettungsmodell, den Live-Fortschritt und den Speicherpfad anzeigen.
  • Standard-/Löschaktionen wurden optisch vereinfacht, wodurch die Kartenhöhe verringert und das Scannen großer KB-Listen erleichtert wurde.

Aktualisierung der Dokumentation und Lokalisierung

Die README-Familie wurde aktualisiert, um sie an die neue Installationsgeschichte und Anbieteroberfläche anzupassen:

  • Polnische README – assets/README/README_PL.md fügt eine vollständige polnische Übersetzung der Projekt-README (#379) hinzu.
  • Setup-Dokumente – Die Haupt-README-Datei und die mehrsprachigen README-Dateien beschreiben jetzt die geführte Tour als den empfohlenen Fresh-Clone-Pfad: Erstellen Sie eine Python-Umgebung, führen Sie python scripts/start_tour.py aus und verwenden Sie dann python scripts/start_web.py für den täglichen Start.
  • Anbieterdokumente – Anbietertabellen wurden für die v1.2.3-Anbieterregistrierung aktualisiert, einschließlich custom_anthropic, der kanonischen Endpunkte von MiniMax, Coding-Plan-Anbietern, lokalen Anbietern und klareren Authentifizierungshinweisen für OpenAI Codex / GitHub Copilot.
  • Release-/News-Abschnitte – mehrsprachige READMEs enthalten jetzt Zusammenfassungen von v1.2.2 und v1.2.3, einen Beitragsleitfaden und den Meilenstein der 20.000-Star-Community.

UI- und Theme-Korrekturen

  • Themenbezogene Popovers – Composer-Funktions-/Werkzeug-/Referenz-/Skill-Menüs verwenden jetzt --popover plus Hintergrundunschärfe anstelle von --card, wodurch der Kontrast im Glass-Design und in dunklen Popover-Kontexten verbessert wird.
  • Hinweise zu nativen Farbschemata – Die Theme-Wurzeln „Hell“, „Dunkel“, „Schnee“ und „Glas“ deklarieren das korrekte color-scheme, wodurch native Steuerelemente und vom Browser gerenderte Oberflächen verbessert werden.
  • Smooth-Scroll-Hydration – globales Smooth-Scrolling ist jetzt hinter html[data-scroll-behavior="smooth"] geschützt, wobei das Attribut durch das Root-Layout festgelegt wird, um eine unbeabsichtigte Anwendung zu vermeiden.
  • Größe des Seitenleisten-Logos – Seitenleisten-Logo-Bilder pinnen jetzt explizit gerenderte Breiten-/Höhenklassen an, um kleine Layoutverschiebungen zu verhindern.

Aufräumen

Der veraltete nanobot-Submodulzeiger und der veraltete scripts/extract_numbered_items.sh-Stub wurden aus dem Repository entfernt. Die v1.2.x-Codebasis basiert jetzt auf der In-Tree-Dokumentextraktion und den RAG-Routing-Pfaden anstelle dieses alten Hilfsprogramms.

Erweiterung der Testsuite

  • Backend-Dokumentextraktion – tests/utils/test_document_extractor.py deckt jetzt Nur-Text, Python-Quelle, JSON, CSV, Markdown, UTF-8-BOM-Eingabe, GBK-Fallback-Dekodierung und SVG-Quellenextraktion ab.
  • Frontend-Anhangsklassifizierung – web/tests/doc-attachments.test.ts deckt jetzt die Text-/Code-Akzeptanz, SVG-als-Dokument-Routing, die Erkennung von SVG-Dateinamen ohne Berücksichtigung der Groß-/Kleinschreibung und die neuen Symbolkategorien für Code, JSON, Konfiguration, Shell, Daten, Markup, Stylesheets und SVG ab.

DeepTutor v1.2.4

DeepTutor v1.2.4 Release Notes

Release Date: 2026.04.25

Highlights

Support More Attachment Formats in Chat

The v1.2.3 document-attachment pipeline has been expanded beyond Office files. Chat attachments now accept the same text-like formats as the Knowledge Base ingestion router: Markdown, plain text, logs, JSON/YAML/TOML, CSV/TSV, LaTeX/BibTeX, HTML/XML/SVG, stylesheets, scripts, and common source-code files (.py, .js, .ts, .tsx, .java, .cpp, .go, .rs, .sql, .sh, and more).

  • Backend parity with KB routing — deeptutor/utils/document_extractor.py imports FileTypeRouter.TEXT_EXTENSIONS, so chat attachments and KB uploads share one source of truth for text/code formats. FileTypeRouter.decode_bytes() centralizes the UTF-8 / UTF-8-BOM / GBK / GB18030 / Latin-1 / CP1252 fallback chain.
  • SVG as readable source — .svg was added to the RAG text extension set and is treated as a document attachment instead of a vision image, letting the LLM inspect the XML source while the frontend still renders a safe thumbnail preview.
  • Typed attachment UX — web/lib/doc-attachments.ts now exposes OFFICE_EXTS, TEXT_LIKE_EXTS, SVG detection, richer MIME/extension fallback, and category-specific icons for code, shell, JSON, config, data, markup, stylesheets, plain text, Office docs, and SVG.
  • Composer copy updated — the drag-and-drop hint now advertises "Images, Office docs, code & text" instead of the older Office-only list.

One-Command Setup Tour

scripts/start_tour.py has evolved from a pure configuration wizard into a 7-step fresh-install path that can detect the local environment, install dependencies, and then guide provider configuration.

  • Dependency installation step — the tour checks Python, uv, Node.js, and npm; installs backend requirements, installs DeepTutor in editable mode, and runs frontend npm install with live terminal output.
  • uv pip compatibility (#376) — Python dependency installation now prefers uv pip when available, and binds --python <current-interpreter> so packages land in the interpreter running the tour instead of an unrelated .venv / $VIRTUAL_ENV.
  • Windows npm detection (#381) — npm invocations use npm.cmd on Windows, fixing version checks and install commands on systems where npm is exposed as a command shim rather than an executable.
  • Provider registry-driven LLM choices — the wizard now reads from the full PROVIDERS registry, groups providers by mode, highlights common services, and includes newer options such as custom_anthropic, OpenRouter, SiliconFlow, Volcengine / BytePlus coding providers, GitHub Copilot, OpenAI Codex, llama.cpp, OVMS, MiniMax, Mistral, Qianfan, Step Fun, and Xiaomi MiMo.
  • Search and config hints — Serper is available in the search-provider list; Azure/API-version and proxy prompts now show inline guidance in both English and Chinese.
  • Long-list terminal UX — scripts/_cli_kit.py renders long select menus inside a scrolling window with "more above/below" indicators, preventing stale terminal rows when the provider list exceeds the screen height.

Chat Markdown Export

The chat page now has a Download Markdown action next to "Save to Notebook" and "New Chat". web/lib/chat-export.ts serializes the current conversation as Markdown with a title, ISO export timestamp, role headings, capability labels, and attachment metadata, then downloads it with a sanitized date-stamped filename. This gives users a lightweight local export path for sharing, archiving, or moving a conversation into external notes.

Knowledge Base Management UI Polish

The Knowledge page was tightened up for denser day-to-day management:

  • Creation and upload drop zones are now simpler dashed cards with concise inline upload-policy summaries.
  • KB cards moved from four large stat panels to compact rows showing document count, index readiness, last-updated time, provider, embedding model, live progress, and storage path.
  • Default/delete actions were simplified visually, reducing card height and making large KB lists easier to scan.

Documentation and Localization Refresh

The README family was updated to match the new install story and provider surface:

  • Polish README — assets/README/README_PL.md adds a complete Polish translation of the project README (#379).
  • Setup docs — the main README and multilingual READMEs now describe the guided tour as the recommended fresh-clone path: create a Python environment, run python scripts/start_tour.py, then use python scripts/start_web.py for daily launch.
  • Provider docs — provider tables were refreshed for the v1.2.3 provider registry, including custom_anthropic, MiniMax's canonical endpoints, coding-plan providers, local providers, and clarified authentication notes for OpenAI Codex / GitHub Copilot.
  • Release/news sections — multilingual READMEs now include v1.2.2 and v1.2.3 summaries, a contributing-guide callout, and the 20k-star community milestone.

UI and Theme Fixes

  • Theme-aware popovers — composer capability/tool/reference/skill menus now use --popover plus backdrop blur instead of --card, improving contrast in the Glass theme and dark popover contexts.
  • Native color-scheme hints — light, dark, Snow, and Glass theme roots declare the correct color-scheme, improving native controls and browser-rendered surfaces.
  • Smooth-scroll hydration — global smooth scrolling is now gated behind html[data-scroll-behavior="smooth"], with the attribute set by the root layout to avoid applying it unintentionally.
  • Sidebar logo sizing — sidebar logo images now pin explicit rendered width/height classes to prevent small layout shifts.

Cleanup

Removed the stale nanobot submodule pointer and the deprecated scripts/extract_numbered_items.sh stub from the repository. The v1.2.x codebase now relies on the in-tree document extraction and RAG routing paths instead of that legacy helper.

Test Suite Expansion

  • Backend document extraction — tests/utils/test_document_extractor.py now covers plain text, Python source, JSON, CSV, Markdown, UTF-8-BOM input, GBK fallback decoding, and SVG source extraction.
  • Frontend attachment classification — web/tests/doc-attachments.test.ts now covers text/code acceptance, SVG-as-document routing, case-insensitive SVG filename detection, and the new icon categories for code, JSON, config, shell, data, markup, stylesheets, and SVG.

What's Changed

  • fix(scripts): prefer uv pip over python -m pip in start_tour.py by @rogercsi in https://github.com/HKUDS/DeepTutor/pull/376
  • docs: add Polish translation of README by @kKamUL in https://github.com/HKUDS/DeepTutor/pull/379
