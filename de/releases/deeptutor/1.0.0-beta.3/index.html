DeepTutor v1.0.0-beta.3 Release Notes

Veröffentlichungsdatum: 2026.04.08

Highlights

LiteLLM-Abhängigkeit entfernen

Die litellm-Abstraktionsebene wurde durch native openai- und anthropic-SDKs sowohl auf der Dienst- als auch auf der TutorBot-Ebene ersetzt. Ein neues OpenAICompatProvider (das OpenAI, DeepSeek, Mistral, StepFun, XiaoMi-MiMo, Qianfan, oVMS und mehr abdeckt) und ein dediziertes AnthropicProvider hinzugefügt. Die Benutzeroberfläche der Einstellungen enthält jetzt ein Anbieter-Dropdown-Menü mit automatischer Basis-URL-Ausfüllung. Automatischer Fallback auf Streaming wird ausgelöst, wenn Formatfehler beim Toolaufruf auftreten (behebt #265).

Windows Math Animator-Kompatibilität

Die SelectorEventLoop-Inkompatibilität unter Windows wurde behoben, indem asyncio.create_subprocess_exec durch subprocess.Popen + Reader-Threads + asyncio.Queue ersetzt wurde, wodurch die zeilenweise Fortschrittsausgabe in Echtzeit erhalten blieb. Außerdem wurde die ProactorEventLoop-Richtlinie für die Unterprozessunterstützung unter Windows angewendet.

Robustes JSON-Parsing für LLM-Ausgaben

Sieben Agentenmodule (Planer, Idee, Design, Notiz, Berichterstellung, Zitat, Datenstrukturen) verwenden jetzt parse_json_response() anstelle des rohen json.loads() und verarbeiten LLM-Antworten, die in Markdown-Code-Zäune eingeschlossen sind, korrekt. Für den Fallback-Parameter wurde ein _UNSET-Sentinel eingeführt, sodass Aufrufer explizit None als Fehlerwert anfordern können.

Geführte Lernkorrekturen

– Die mathematische Darstellung von KaTeX wurde durch die Konfiguration der Trennzeichen $...$ und $$...$$, das Entfernen fehlerhafter SRI-Integritäts-Hashes und das Hinzufügen von Fallback-Rendering für übergeordnete Fenster für bloße LaTeX-Textknoten korrigiert. – Die Backend-Umfrage (fetchPageStatuses) hat die Tab-Navigation des Benutzers überschrieben, indem current_index nur dann akzeptiert wurde, wenn der Benutzer noch nicht navigiert hat. – Guide-Agent max_tokens von 8192 auf 16384 erhöht, um HTML-Kürzungen zu verhindern.

Vollständige Internationalisierung

Die i18n-Abdeckung für die Web-Benutzeroberfläche wurde abgeschlossen – alle hartcodierten Zeichenfolgen auf Arbeitsbereichs-, Dienstprogramm-, Seitenleisten- und Komponentenseiten sind jetzt mit vollständigen englischen und chinesischen Gebietsschemadateien mit Übersetzungsschlüssel versehen.

  • Windows-Kompatibilität für den Math Animator-Renderer von @kevinmw in https://github.com/HKUDS/DeepTutor/pull/256 behoben
  • Fix: Windows-Kompatibilität + Guided Learning-Verbesserungen von @kevinmw in https://github.com/HKUDS/DeepTutor/pull/266
  • Dokumente: Klärung der Anmeldesemantik des Copilot-Anbieters github von @LocNguyenSGU in https://github.com/HKUDS/DeepTutor/pull/262

DeepTutor v1.0.0-beta.3

DeepTutor v1.0.0-beta.3 Release Notes

Release Date: 2026.04.08

Highlights

Remove LiteLLM Dependency

Replaced the litellm abstraction layer with native openai and anthropic SDKs across both the services and TutorBot layers. Added a new OpenAICompatProvider (covering OpenAI, DeepSeek, Mistral, StepFun, XiaoMi-MiMo, Qianfan, oVMS, and more) and a dedicated AnthropicProvider. The settings UI now includes a provider dropdown with auto base-URL filling. Auto-fallback to streaming is triggered when tool-call format errors occur (fixes #265).

Windows Math Animator Compatibility

Fixed SelectorEventLoop incompatibility on Windows by replacing asyncio.create_subprocess_exec with subprocess.Popen + reader threads + asyncio.Queue, preserving real-time line-by-line progress output. Also applied ProactorEventLoop policy for subprocess support on Windows.

Robust JSON Parsing for LLM Outputs

Seven agent modules (planner, idea, design, note, reporting, citation, data structures) now use parse_json_response() instead of raw json.loads(), correctly handling LLM responses wrapped in markdown code fences. A _UNSET sentinel was introduced for the fallback parameter so callers can explicitly request None as the failure value.

Guided Learning Fixes

  • Fixed KaTeX math rendering by configuring $...$ and $$...$$ delimiters, removing broken SRI integrity hashes, and adding parent-window fallback rendering for bare LaTeX text nodes.
  • Fixed backend poll (fetchPageStatuses) overwriting user's tab navigation by only accepting current_index when the user hasn't navigated yet.
  • Increased guide agent max_tokens from 8192 to 16384 to prevent HTML truncation.

Full Internationalization

Completed i18n coverage for the web UI — all hardcoded strings across workspace, utility, sidebar, and component pages are now translation-keyed with full English and Chinese locale files.

What's Changed

  • fix(start-tour): tolerate non-UTF-8 subprocess output by @2023Anita in https://github.com/HKUDS/DeepTutor/pull/259
  • fix: use parse_json_response for LLM outputs to handle markdown fences by @kagura-agent in https://github.com/HKUDS/DeepTutor/pull/263
  • Fix Windows compatibility for Math Animator renderer by @kevinmw in https://github.com/HKUDS/DeepTutor/pull/256
  • fix: Windows compatibility + Guided Learning improvements by @kevinmw in https://github.com/HKUDS/DeepTutor/pull/266
  • docs: clarify github copilot provider login semantics by @LocNguyenSGU in https://github.com/HKUDS/DeepTutor/pull/262

New Contributors

  • @kevinmw made their first contribution in https://github.com/HKUDS/DeepTutor/pull/256
