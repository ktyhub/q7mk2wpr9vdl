DeepTutor v1.5.11

DeepTutor v1.5.11 Release Notes

Veröffentlichungsdatum: 2026.08.10 Bei v1.5.10 ging es um die Pfade unter einer Anfrage, die sich zurückhielt; Hier geht es darum, was passiert, während die Antwort noch geschrieben wird. Prosa, das eine Runde mit einem Tool-Aufruf teilte, der zum Verschwinden im Trace verwendet wurde, eine abgeschnittene Generation wurde gelesen, als das Modell entschied, dass sie fertig war, und die lokale Indizierung befand sich in der Ereignisschleife, alles andere, was benötigt wurde. Die Einstellungsleiste hört auch auf, das zu wiederholen, was Ihnen die Seite „Modelle“ bereits mitteilt, und beginnt mit der Anzeige der einzigen Zahl, die nichts anderes getan hat: was DeepTutor tatsächlich im Speicher verbraucht. Drop-in – keine Migrationen, nichts, was neu indiziert werden muss.

Was ist neu?

Text um einen Werkzeugaufruf geht nicht mehr verloren

Der Anthropic-kompatible Endpunkt von DeepSeek verschachtelt benutzerorientierte Prosa und DSML-Tool-Call-Markup in einem einzigen Content-Stream. Bei der alten Handhabung ging es um alles oder nichts: Sobald der Inhaltskanal einer Runde DSML-Markup anzeigte, wurde der Rest dieser Runde auf den Denkkanal umgeleitet, sodass jede Erklärung, die das Modell zu seinem Aufruf schrieb, aus der Antwort verschwand. Ein Streaming-Filter entfernt jetzt nur den DSML-Umschlag und die invoke-Blöcke inkrementell – Text vor, zwischen und nach einem Anruf wird gestreamt und bleibt als Teil der Antwort bestehen. Ein unvollständiger Aufruf wird beim Flush wörtlich freigegeben und nicht verschluckt, und eine Obergrenze von 512 Zeichen bedeutet, dass ein verirrter < in normaler Prosa den Live-Stream nicht ewig auf eine schließende Klammer warten lassen kann.

DSML-Array- und Objektargumente werden korrekt dekodiert

DeepSeek markiert im Wesentlichen alle enthaltenen DSML-Parameter-Arrays und -Objekte string="true", JSON, sodass ein Containerargument als Zeichenfolge JSON beim Tool ankommt. Bei der Parameterdecodierung wird jetzt das deklarierte Toolschema konsultiert: Ein Parameter mit den Schematypen array oder object wird analysiert, wenn die Nutzlast tatsächlich übereinstimmt, und der String-Vertrag des Anbieters hat weiterhin überall sonst Vorrang. Der Schemakatalog bleibt auch dann erhalten, wenn ein Anbieter natives tools ablehnt und die Schleife auf DSML zurückgreift, was genau dann der Fall ist, wenn der Parser ihn benötigt.

Eine verkürzte Generation verlangt nach einer Fortsetzung

Ein length-Finish ist eine unvollständige Generation, nicht das Modell, das sich entschieden hat, aufzuhören – aber es wurde als Finish behandelt, sodass die Antwort mitten im Satz endete. Die Schleife behält nun das sichtbare Präfix und fordert eine Fortsetzung an, und die zusammengesetzte Antwort überträgt das Präfix bis zur Persistenz und dem SDK. Das Rundenbudget wurde umstrukturiert, um dies sicher zu machen: Erkundungsrunden, dann ein kleines begrenztes Abrechnungsfenster, dann ein einzelnes hartes Finish ohne Werkzeug, sodass wiederholte Kürzungen und fehlerhafte Werkzeugzyklen eine absolute Obergrenze von exploration + 4 haben.

Live-Speichernutzung in den Einstellungen

Die Einstellungsstatusleiste enthielt Backend, LLM, Einbettung und Suche – drei davon bekräftigten, was die Seiten „Modelle“ und „Chat“ bereits besitzen. Es enthält jetzt die beiden Laufzeitfakten, die auf der Seite mit den Einstellungen nicht angezeigt werden: ob das Backend aktiv ist, und residenter Speicher im gesamten DeepTutor-Prozessbaum – Backend, Next.js-Server und alle aktiven Sandboxen und Subagenten CLIs – mit einer Inline-Aufteilung pro Prozess und einem Druckpunkt, der über zwei Drittel des Grenzwerts hinaus gelb wird. Es wird von einem neuen GET /api/v1/system/memory bedient; psutil liest den Baum und wird träge mit einem /proc-Fallback importiert, sodass ein fehlendes Rad den Streifen und nicht die App kostet. Nicht-Administratoren und Plattformen, auf denen der Baum nicht gelesen werden kann, erhalten {available: false} und keinen Strip.

Durch die lokale LightRAG-Indizierung wird alles andere nicht mehr blockiert

Die lokalen Speicher-Backends von RAG-Anything führen die synchrone Diagrammzusammenführung und die JSON-Serialisierung innerhalb asynchroner Methoden durch, so dass die Indizierung eines Dokuments in der Service-Ereignisschleife nicht verwandte API- und LLM-Arbeiten für die Dauer einfriert. Die Indizierung läuft jetzt in der eigenen Ereignisschleife eines Arbeitsthreads mit einer schmalen Brücke, die LLM-, Vision- und Einbettungsaufrufe zurück an die Anforderungsschleife weiterleitet und eine Kopie des Aufruferkontexts enthält, sodass das anforderungslokale Modell und die Benutzerkonfiguration sichtbar bleiben. Remote-LightRAG-Server sind nicht betroffen.

Meisterschaft basiert auf der hartnäckigen Frage, nicht auf der Nacherzählung des Modells

Eine gestellte Frage wird nun in einen kleinen öffentlichen Auftrag umgewandelt – Eingabeaufforderung, Typ und die Option Beschriftung/Bodymap –, der durch Registrierung, Präsentation und Bewertung geteilt wird, wobei die erwartete Antwort serverseitig bleibt. ask_user rendert diesen beibehaltenen Zustand, anstatt Daten anzuzeigen, die das Modell neu erstellt hat, sodass die Auswahlmöglichkeiten, die ein Lernender sieht, auch die Auswahlmöglichkeiten sind, die bewertet werden. Durch die Registrierung wird die Quizform validiert, anstatt stillschweigend eine widersprüchliche Form zu akzeptieren: Ein fehlender Typ wird aus der Nutzlast abgeleitet, short/open-Fragen lehnen Optionen ab und eine Auswahlfrage muss echte Optionskörper anstelle der bloßen A/B/C-Beschriftungen enthalten.

Sortiert

  • Verbundene Wissensdatenbanken antworten ehrlich zu lokalen Dateien. Eine verlinkte externe Ressource hat kein von DeepTutor verwaltetes raw/-Verzeichnis; Das Auflisten seiner Dateien gibt eine leere Sammlung zurück, anstatt eine zu erfinden, und Endpunkte, die eine lokale Datei erfordern, geben ein explizites 409 zurück.
  • Generierte Ausgabeartefakte werden anforderungsbezogen bereitgestellt. Ein neuer /api/outputs-Endpunkt löst und autorisiert einen Pfad in einem Vorgang und schlägt fehl, mit einem 404 geschlossen zu werden, wenn kein Anforderungsbenutzer vorhanden ist, sodass eine Authentifizierungskontext-Regression das Artefakt eines Administrators nicht an eine normale Anforderung übergeben kann.
  • Visualisieren Sie sowohl das Schrumpfen als auch das Wachsen von IFrames – die Höhenbrücke misst den Körperinhalt anstelle einer Stammhöhe, die der Host bereits gedehnt hat, und fügt Berichte in einem Animationsframe zusammen.
  • Die Modellliste der Chat-Seite wird einmal abgerufen. Das Laden von Optionen wurde in einen Hook mit Single-Flight-Deduplizierung verschoben, sodass gleichzeitige Bereitstellungen und eine Aktualisierung mit Tab-Fokus keine identischen Anforderungen mehr stapeln.

Upgrade-Hinweise

pip install -U deeptutor; Docker-Benutzer ziehen ghcr.io/hkuds/deeptutor:latest. Keine Schemaänderungen, keine Neuindizierung, keine Migration.

  • psutil ist eine neue Abhängigkeit und wird mit dem Upgrade installiert. Es wird träge hinter einem /proc-Fallback importiert – wenn Ihre Umgebung es nicht bereitstellen kann, bleibt der Speicherstreifen verborgen und sonst ändert sich nichts. DeepTutor v1.5.11

Highlights

  • Tool-call streams and arguments — DeepSeek’s Anthropic-compatible DSML responses now preserve user-facing prose before, between, and after tool calls instead of diverting it into the thinking channel. Array/object arguments are decoded against the tool schema, including when rejected native tool definitions force DSML fallback; incomplete calls are flushed rather than silently dropped.
  • Truncated generations continue — A length finish now preserves the visible prefix and requests a continuation through persistence and the SDK. Exploration, settlement, and a final tool-less attempt share an absolute round limit of exploration + 4, preventing repeated truncation or malformed tool cycles from running indefinitely.
  • Local indexing no longer blocks the event loop — LightRAG’s synchronous graph and JSON work moves to a worker-thread event loop, with model, vision, and embedding calls bridged back to the request loop. Caller context is copied so request-local model and user configuration remain intact; remote LightRAG deployments are unaffected.
  • Quiz answers come from persisted questions — ask_user now renders and grades the same registered prompt, type, and option bodies, preventing the model’s retelling from changing answer choices. Validation infers missing types, rejects options on short/open questions, and requires substantive choice bodies rather than bare labels.
  • Runtime diagnostics and artifact isolation — GET /api/v1/system/memory reports process-tree memory with per-process detail to authorized admins; the new lazy psutil dependency has a /proc fallback, and unavailable data simply hides the strip. Generated artifacts now use request-scoped /api/outputs authorization and fail closed with 404 when no request user exists.
  • Upgrade — No breaking changes or migrations; run pip install -U deeptutor or pull ghcr.io/hkuds/deeptutor:latest. No re-indexing is required.

DeepTutor v1.5.11 Release Notes

Release Date: 2026.08.10

v1.5.10 was about the paths underneath a request holding up; this one is about what happens while the answer is still being written. Prose that shared a round with a tool call used to vanish into the trace, a truncated generation was read as the model deciding it had finished, and local indexing sat on the event loop everything else needed. The settings strip also stops restating what the Models page already tells you and starts showing the one number nothing else did: what DeepTutor is actually costing in memory. Drop-in — no migrations, nothing to re-index.

What's New

Text around a tool call is no longer lost

DeepSeek's Anthropic-compatible endpoint interleaves user-facing prose and DSML tool-call markup in a single content stream. The old handling was all-or-nothing: once a round's content channel showed DSML markup, the rest of that round was diverted to the thinking channel, so any explanation the model wrote around its call disappeared from the answer. A streaming filter now removes only the DSML envelope and the invoke blocks, incrementally — text before, between, and after a call streams and persists as part of the reply. An incomplete call is released verbatim on flush rather than swallowed, and a 512-character ceiling means a stray < in ordinary prose cannot make the live stream wait forever for a closing bracket.

DSML array and object arguments decode correctly

DeepSeek marks essentially every DSML parameter string="true", JSON arrays and objects included, so a container argument arrived at the tool as a string of JSON. Parameter decoding now consults the declared tool schema: a parameter the schema types as array or object is parsed when the payload actually matches, and the provider's string contract still wins everywhere else. The schema catalog is kept even when a provider rejects native tools and the loop falls back to DSML, which is exactly when the parser needs it.

A truncated generation asks for a continuation

A length finish is an incomplete generation, not the model choosing to stop — but it was treated as a finish, so the reply ended mid-sentence. The loop now keeps the visible prefix and asks for a continuation, and the assembled answer carries the prefix through to persistence and the SDK. The round budget was restructured to make this safe: exploration rounds, then a small bounded settlement window, then a single tool-less hard finish, so repeated truncation and malformed tool cycles share one absolute upper bound of exploration + 4.

Live memory usage in Settings

The settings status strip carried Backend, LLM, Embedding, and Search — three of which restated what the Models and Chat pages already own. It now carries the two runtime facts no settings page shows: whether the backend is up, and resident memory across the whole DeepTutor process tree — backend, the Next.js server, and whatever sandboxes and subagent CLIs are alive — with a per-process split inline and a pressure dot that turns amber past two thirds of the limit. It is served by a new GET /api/v1/system/memory; psutil reads the tree and is imported lazily with a /proc fallback, so a missing wheel costs the strip and not the app. Non-admins and platforms where the tree cannot be read get {available: false} and no strip.

Local LightRAG indexing stops stalling everything else

RAG-Anything's local storage backends do synchronous graph merging and JSON serialization from inside async methods, so indexing a document on the service event loop froze unrelated API and LLM work for its duration. Indexing now runs on a worker thread's own event loop, with a narrow bridge that forwards LLM, vision, and embedding calls back to the request's loop, carrying a copy of the caller's context so request-local model and user configuration stays visible. Remote LightRAG servers are unaffected.

Mastery works from the persisted question, not the model's retelling

A posed question now projects into a small public contract — prompt, type, and the option label/body map — shared by registration, presentation, and grading, with the expected answer staying server-side. ask_user renders that persisted state instead of display data the model re-authored, so the choices a learner sees are the choices that will be graded. Registration validates the quiz shape rather than silently accepting a contradictory one: a missing type is inferred from the payload, short/open questions reject options, and a choice question must carry real option bodies instead of bare A/B/C labels.

Assorted

  • Connected knowledge bases answer honestly about local files. A linked external resource has no DeepTutor-managed raw/ directory; listing its files returns an empty collection instead of inventing one, and endpoints that require a local file return an explicit 409.
  • Generated output artifacts are served request-scoped. A new /api/outputs endpoint resolves and authorizes a path in one operation and fails closed with a 404 when there is no request user, so an auth-context regression cannot hand an administrator's artifact to an ordinary request.
  • Visualize iframes shrink as well as grow — the height bridge measures body content instead of a root height the host had already stretched, and coalesces reports into one animation frame.
  • The chat page's model list is fetched once. Option loading moved into a hook with single-flight de-duplication, so concurrent mounts and a tab-focus refresh no longer stack up identical requests.

Upgrade Notes

pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest. No schema changes, no re-index, no migration.

  • psutil is a new dependency and installs with the upgrade. It is imported lazily behind a /proc fallback — if your environment cannot provide it, the memory strip stays hidden and nothing else changes.
