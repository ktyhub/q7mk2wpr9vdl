DeepTutor v1.6.13 Release Notes

Veröffentlichungsdatum: 2026.10.04

Aufbauend auf v1.6.12 erweitert v1.6.13 die Lese-, Hör- und Fragenbankpraxis, verbessert das Parsen von Dokumenten und die Sprachkonfiguration und bringt Polnisch sowie weitere Modellanbieter. Chat-Anhänge folgen jetzt dem ausgewählten Arbeitsbereich, wobei vorhandene Uploads und URLs während des Übergangs beibehalten werden.

Was ist neu?

Lesen, hören und noch einmal Revue passieren lassen

Immersive Reading erhält natürliche Vorlese-Audio- und Quiz-Star-Belohnungen. Immersive Watching erhält zeitgestempelte Markierungen, Notizen und vorgeschlagene Überprüfungspunkte. Bei der PDF-Größenänderung und der EPUB-Kapitelnavigation bleibt die Leseposition zuverlässiger erhalten. Lernende können explizit zugewiesene Bücher und Lesematerialien im Rahmen ihres gewährten Zugriffs öffnen.

Üben Sie anhand Ihrer Fragendatenbank

Beginnen Sie mit dem Üben direkt aus der Fragendatenbank und wählen Sie mehrere gespeicherte Fragen für einen Chat aus. Guided Learning mischt Multiple-Choice-Optionen und vermeidet, dass richtige Antworten durch Optionsbriefe oder Abrufaufforderungen preisgegeben werden. Mit Co-Writer können Sie das Modell für eine Bearbeitung auswählen.

Zuverlässigerer Dokumentenabruf

Wählen Sie ein unabhängiges Visionsmodell für Dokumentbildbeschreibungen; Erfolgreiche Beschreibungen werden pro Arbeitsbereich zwischengespeichert, mit optionaler begrenzter Stapelverarbeitung. Das Cloud-Parsing von MinerU zerlegt übergroße PDFs und setzt abgeschlossene Teile fort, während lokale Fehler umsetzbare Ursachen melden. Die optionale Tiny-Scan-Normalisierung, die Suche nach nummerierten Übungen und eine bessere Figurerhaltung verbessern das Auffinden von Lehrbüchern. deeptutor kb eval misst die Abrufqualität anhand eines lokalen Bewertungsdatensatzes.

Spracheinstellungen, die Fehler erklären

Sprachmodelle verfügen über ein konfigurierbares Synthese-Timeout, das von Vorschau und Wiedergabe verwendet wird. DashScope Qwen-Audio und Qwen3 TTS verwenden ihre jeweiligen Endpunkte, Stimmen, Formate und regionalen Anforderungen. Vorschaufehler unterscheiden zwischen Authentifizierung, Berechtigungen, Parametern, Kontingenten, Netzwerkfehlern und Zeitüberschreitungen. Die Antwortwiedergabe behält die Mathematik bei, bricht veraltete Anfragen ab und verhindert überlappende Audiodaten.

Arbeitsbereiche und Verbindungen

Neue Chat-Uploads werden im chat/attachments-Verzeichnis des ausgewählten Arbeitsbereichs gespeichert, sodass Arbeitsbereichstools sie finden können. Frühere Uploads werden dorthin verschoben, wenn ihre Konversation verwendet oder ihre Daten migriert werden. Vorhandene Anhangs-URLs bleiben lesbar. SearXNG-Verbindungstests erklären die Docker-Adressierung, die deaktivierte JSON-Ausgabe und leere Suchergebnisse. Webquellen können zweisprachige Inhalte koppeln und Wissensdatenbankprüfungen verwenden Sonden wieder, ohne den API zu blockieren.

Partner, Sprachen und Anbieter

Exportieren Sie Partnergruppengespräche als Markdown und konfigurieren Sie Telegram-Antwortrichtlinien pro Chat. Feishu-Zustellung und Telegram-Codeblöcke sind zuverlässiger. Zu den Schnittstellensprachen gesellt sich Polnisch; Requesty, API Route und FutureInfra schließen sich den LLM-Anbietern mit nativer MiniMax-Sprachunterstützung und voreingestellter Sprachunterstützung für Xiaomi MiMo v2.5 an.

Chat-Wiederherstellung und alltägliche Korrekturen

Die Verlaufssuche überprüft vollständige Gesprächsprotokolle und schließt wiederverwendete Sitzungen aus. Lange Konversationsverzweigungen, erneut verbundene Einreichungen, LaTeX-Auswahlen und Lernerrouten werden zuverlässiger wiederhergestellt. Bildnutzlasten erhöhen die Tokenschätzungen nicht mehr, GLM-Begründungsoptionen stimmen mit den unterstützten Einstellungen überein und deeptutor doctor berücksichtigt den konfigurierten Anbieter und das Tokenbudget.

Aktualisierte Setup- und Funktionsdokumentation begleitet die Veröffentlichung unter deeptutor.info.

Upgrade-Hinweise

Führen Sie pip install -U deeptutor aus; Docker-Benutzer ziehen ghcr.io/hkuds/deeptutor:latest.

  • Anhänge: Es ist kein manuelles Verschieben erforderlich. Frühere Uploads werden bei Bedarf in den ausgewählten Arbeitsbereich verschoben; Behalten Sie die vorhandenen Anwendungsdaten während des Upgrades bei.
  • Sprache: legt Anforderungszeitlimit (Sekunden) im Sprachmodell fest, wenn die Synthese mehr Zeit benötigt; Der Standardwert beträgt 60 Sekunden, der unterstützte Bereich liegt zwischen 5 und 600 Sekunden. Verwenden Sie Vorschaustimme, um die Synthese zu testen; Durch das Abrufen einer Modellliste allein wird eine Stimme nicht validiert.
  • DashScope Qwen-Audio TTS: Verwenden Sie eine Beijing API-Taste und eine Stimme, die vom ausgewählten Modell unterstützt wird. Eine Basis-URL des Anbieters API wählt automatisch den passenden Sprachendpunkt aus. Qwen3 TTS verwendet seine eigenen Stimmen und WAV-Ausgabe.
  • Dokumentbilder: Wählen Sie in den Dokumentparsing-Einstellungen ein Bildbeschreibungsmodell aus, wenn das Hauptmodell keine Bilder prüfen kann. Batchverarbeitung und Tiny-Scan-Normalisierung sind optional; Ältere indizierte Inhalte müssen erneut analysiert und indiziert werden, um neu generierte Beschreibungen oder Abbildungsdatensätze zu erhalten.
  • Lernbücher: Administratoren müssen die Bücheroberfläche gewähren und explizit ein Buch zuweisen; Der Zugriff der Lernenden bleibt auf diese Aufgaben beschränkt.
  • Systemd-Installationen: Stoppen Sie den Dienst, aktualisieren Sie DeepTutor in seiner Python-Umgebung und starten Sie den Dienst neu.

DeepTutor v1.6.13

Highlights

  • Workspace-scoped chat attachments — New uploads now live in the selected workspace’s chat/attachments, making them available to workspace tools. Earlier uploads move there when needed, and existing URLs remain readable; keep your application data mounted during upgrade—no manual file migration is required.

  • More resilient document retrieval — An independent vision model can describe document images, with successful results cached per workspace and optional bounded batching to control cost. MinerU cloud parsing now slices oversized PDFs and resumes completed sections. Re-parse and re-index older documents to benefit from new image descriptions and figure records.

  • Configurable and safer speech playback — Synthesis timeout is configurable from 5–600 seconds, defaulting to 60, and applies to both previews and playback. Error messages distinguish authentication, permissions, parameters, quota, network failures, and timeouts; stale playback requests are cancelled to prevent overlapping audio. Test voices with Preview voice—fetching the model list does not validate synthesis.

  • DashScope speech requires provider-specific configuration — Qwen-Audio TTS needs a Beijing API key and a voice supported by the selected model; Qwen3 TTS uses separate endpoints, voices, and WAV output. Check these settings when migrating existing DashScope configurations rather than assuming the providers are interchangeable.

  • Question-bank practice with stronger assessment integrity — Learners can start practice directly from saved questions and select multiple questions for chat. Guided Learning now shuffles multiple-choice options and avoids leaking answers through option letters or retrieval prompts, reducing predictable answer cues.

  • Retrieval evaluation and expanded provider support — deeptutor kb eval measures retrieval quality against a local evaluation dataset, enabling repeatable checks after indexing changes. Requesty, API Route, and FutureInfra join the LLM providers, while MiniMax speech and Xiaomi MiMo v2.5 speech presets broaden deployment options.

  • Breaking changes — None are explicitly called out in this release.

DeepTutor v1.6.13 Release Notes

Release Date: 2026.10.04

Building on v1.6.12, v1.6.13 expands reading, listening, and question-bank practice, improves document parsing and speech configuration, and brings Polish plus more model providers. Chat attachments now follow the selected workspace, with existing uploads and URLs preserved during the transition.

What's New

Read, listen, and revisit

Immersive Reading gains natural read-aloud audio and quiz star rewards. Immersive Watching gains timestamped marks, notes, and suggested review points. PDF resizing and EPUB chapter navigation preserve reading position more reliably; learners can open explicitly assigned books and reading materials within their granted access.

Practice from your question bank

Start practice directly from the Question Bank and select multiple saved questions for a chat. Guided Learning shuffles multiple-choice options and avoids exposing correct answers through option letters or retrieval prompts. Co-Writer lets you choose the model for an edit.

More reliable document retrieval

Choose an independent vision model for document image descriptions; successful descriptions are cached per workspace, with optional bounded batching. MinerU cloud parsing slices oversized PDFs and resumes completed parts, while local failures report actionable causes. Optional tiny-scan normalization, numbered-exercise lookup, and better figure retention improve textbook retrieval. deeptutor kb eval measures retrieval quality against a local evaluation dataset.

Speech settings that explain failures

Speech models have a configurable synthesis timeout used by previews and playback. DashScope Qwen-Audio and Qwen3 TTS use their respective endpoints, voices, formats, and regional requirements. Preview errors distinguish authentication, permissions, parameters, quota, network failures, and timeouts. Reply playback preserves math, cancels stale requests, and prevents overlapping audio.

Workspaces and connections

New chat uploads live in the selected workspace's chat/attachments directory so workspace tools can find them. Earlier uploads move there when their conversation is used or its data is migrated; existing attachment URLs remain readable. SearXNG connection tests explain Docker addressing, disabled JSON output, and empty search results. Web sources can pair bilingual content, and knowledge-base checks reuse probes without blocking the API.

Partners, languages, and providers

Export Partner group conversations as Markdown and configure Telegram response policies per chat. Feishu delivery and Telegram code blocks are more reliable. Polish joins the interface languages; Requesty, API Route, and FutureInfra join LLM providers, with native MiniMax speech and Xiaomi MiMo v2.5 preset speech support.

Chat recovery and everyday fixes

History search checks full conversation transcripts and excludes recycled sessions. Long conversation branches, reconnecting submissions, LaTeX selections, and learner routes recover more reliably. Image payloads no longer inflate token estimates, GLM reasoning options match supported settings, and deeptutor doctor honors the configured provider and token budget.

Updated setup and feature documentation accompanies the release at deeptutor.info.

Upgrade Notes

Run pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest.

  • Attachments: no manual move is required. Earlier uploads are relocated into the selected workspace when needed; keep existing application data mounted during the upgrade.
  • Speech: set Request timeout (seconds) in the speech model when synthesis needs more time; the default is 60 seconds, with a supported range of 5–600 seconds. Use Preview voice to test synthesis; fetching a model list alone does not validate a voice.
  • DashScope Qwen-Audio TTS: use a Beijing API key and a voice supported by the selected model. A provider API base URL selects the matching speech endpoint automatically; Qwen3 TTS uses its own voices and WAV output.
  • Document images: select an image-description model in Document Parsing settings if the main model cannot inspect images. Batching and tiny-scan normalization are optional; older indexed content needs re-parsing and reindexing to gain newly generated descriptions or figure records.
  • Learner books: administrators must grant the Books surface and explicitly assign a book; learner access stays scoped to those assignments.
  • systemd installs: stop the service, upgrade DeepTutor in its Python environment, and restart the service.
