echarts 6.0.0

Major Veröffentlicht30. Juli 2025 Quelleapache/echarts Englisches Original

echarts 6.0.0

  • [Feature] [Theme] Neues Theme für ECharts 6.0. #20865 #21097 #21114 (Ovilia)
  • [Feature] [Akkord] Neue Akkordserie. #20522 (Ovilia)
  • [Feature] [Matrix&Kalender] Neues Matrixkoordinatensystem. Und alle Serien und Komponenten (einschließlich anderer Koordinatensysteme wie grid (kartesisch), geo, polar usw.) werden für die deklarative Anordnung in den Zellen des Matrix- und Kalenderkoordinatensystems unterstützt. #19807 #21093 (Ovilia) #21005 #21108 (100pah)
  • [Funktion] [Benutzerdefiniert] Unterstützt wiederverwendbare benutzerdefinierte Serien. #20226 (Ovilia)
  • [Funktion] [kartesisch] Führen Sie einen neuen Layoutmechanismus ein, um zu verhindern, dass kartesische (d. h. grid-Komponente) Achsenbeschriftungen und Achsennamen über die Leinwand hinauslaufen, verhindern Sie, dass Achsennamen sich mit Achsenbeschriftungen überlappen, und machen Sie sie zur Standardeinstellung. #21059 (100pah) #19534 (robin-gerling) #16825 (konrad-amtenbrink)
  • [Feature] [Scatter] Unterstützt Jitter für Scatter-Serien. #19941 #21067 (Ovilia)
  • [Feature] [Achse] Stützbruch auf der Achse. #19459 (Ovilia) #20857 (100pah)
  • [Feature] [Theme] Unterstützt die dynamische Registrierung und den Wechsel von Themes. #20705 (Ovilia)
  • [Funktion] [Roam] Verbesserung der Roaming-Infrastruktur – Unterstützung für Benutzer bei der Angabe des Roaming-Bereichs durch roamTrigger; unterstützt clip auf geo und series.map; Unterstützt die Änderung des Cursor-Stils, wenn Sie mit der Maus über den Roaming-Bereich fahren. unterstützt preserveAspect auf geo, series.map und series.graph; Fixieren Sie die prozentuale Basis von center auf geo, series.map, series.graph und series.tree. Verbessern Sie das Verhalten bei Überlappung von Roaming-Bereichen. #19807#issuecomment-2974437299 (100pah)
  • [Funktion] [Miniaturansicht] Unterstützt Miniaturansichten für die Diagrammserie. #19807#issuecomment-3013454598 (100pah) #17471 (Lruler)
  • [Feature] [Marker] Unterstützt die Option z für markPoint/markLine/markArea. #21117 (sz-p)
  • [Feature] [Marker] Unterstützt die Option z2 für markPoint/markLine/markArea. #20782 (sz-p)
  • [Feature] [Stack] Unterstützt das Umkehren der Stapelreihenfolge. #20998 (Justin-ZS)
  • [Feature] [sankey] Unterstützt Roaming für Sankey-Serien. #20321 (Ovilia)
  • [Funktion] [Benutzerdefiniert] Unterstützt CompoundPath in der benutzerdefinierten Serie renderItem. #20402 #21040 (Ovilia)
  • [Feature] [Marker] Unterstützt die Option relativeTo zur Angabe des relativen Ziels der Markerposition. #20166 #21042 (Ovilia)
  • [Funktion] [Achse] Unterstützt Tooltip für die Bezeichnung angleAxis. #20986 (plainheart)
  • [Funktion] [Tooltip] Unterstützt die Option displayTransition, um zu steuern, ob der Tooltip-Anzeigeübergang aktiviert werden soll. #20966 (jqqin)
  • [Feature] [visualMap] Unterstützt die Option unboundedRange. #21113 (100pah)
  • [Feature] [Legende] Unterstützt die Option triggerEvent. #18164 #20907 (sz-p)
  • [Funktion] [Benutzerdefiniert] Unterstützt tooltipDisabled für benutzerdefinierte Serien. #20447 (Ovilia)
  • [Feature] [i18n] Norwegische Bokmål-Übersetzung (nb-NO) hinzufügen. #20792 (joakimono)
  • [Feature] [i18n] Griechische (EL) Übersetzung hinzufügen. #21119 (tassosgeo)
  • [Fix] [Label] Fix: Rich-Label-Stil erbt nicht den einfachen Label-Stil. #20977 (plainheart) #21016 (100pah)
  • [Fix] [Label] Korrigieren Sie den Rand des Etikettenlayouts. #21103 (100pah)
  • [Fix] [dataZoom] Datenformverteilung für die Zeitachse korrigieren. #16978 (andrearoota) #21043 #21039 (Ovilia)
  • [Fix] [Tooltip] Fix: Nullwertelement auf der Kategorieachse sollte Tooltip anzeigen können. #20777 (Justin-ZS)
  • [Fix] [visualMap] Behebung einiger Textstile, die in visualMap nicht funktionieren. #20961 (plainheart)
  • [Fix] [dataZoom] Bereich auf brushEnd einschränken. #20814 (mortalYoung)
  • [Fix] [Heatmap] Fix Beschriftungen, die nicht im Kalenderbereich liegen, werden unerwartet angezeigt. #20699 (plainheart)
  • [Fix] [Serie] Nicht übereinstimmender Dimensionsindex behoben. #20682 (Justin-ZS)
  • [Fix] [bar] Fix Polar Bar sollte roundCap aktualisieren, wenn sich Änderungen ergeben. #20582 (Ovilia)
  • [Fix] [pie] Fix labelLine wird möglicherweise nicht entfernt und verursacht einen Fehler, wenn die Position eines einzelnen Etiketts nicht außen liegt. #20906 (plainheart)
  • [Fix] [sankey] Browser-Absturz behoben, wenn emphasis.focus bei großen Datenmengen 'trajectory' ist. #20959 (plainheart)
  • [Fix] [benutzerdefiniert] Mögliches NPE bei der Anwendung des Urlaubsübergangs behoben. #20920 (plainheart)
  • [Fix] [Tooltip] Beheben Sie potenzielle Speicherverluste durch explizites Aufheben der Bindung von Ereignis-Listenern. #21087 (seaheart)
  • [Fix] [Achse] [Protokoll] Falsche Rundungsverwendung behoben und Daten mit großem negativen Exponenten unterstützt. #21107 (SihongShen) #21120 (100pah)
  • [Fix] [Achse] Fix Extrem kleine Zahlen können aufgrund der ungeeigneten Rundungsgenauigkeit nicht kartesisch angezeigt werden. #21120 (100pah) (SihongShen)
  • [Fix] [dataZoom] MoveHandler-Cursor auf Standard ändern. #20304 (ribeirompl)
  • [Fix] [Tooltip] Koordinatentransformationsmarkierungen im Korrekturstil werden nicht entfernt, nachdem der Tooltip entfernt wurde. #20987 (plainheart)
  • [Fix] [bar] Nicht verwendete Option startValue aus der BarSeriesOption-Schnittstelle entfernen. #20901 (plainheart)
  • [Fix] [Titel] Fix: Die Breite des Titeltextstils sollte keine Zeichenfolge enthalten. #20800 (sz-p)
  • [Fix] [Radar] Fix blur.itemStyle funktioniert nicht. #21081 (mustcanbedo) #21124 (Ovilia)
  • [Fix] [roam] RoamControllerHost-Importpfad korrigieren. #20313 (Ovilia)
  • [Fix] [svg] SVG-Unterstützungsprüfung in getSvgDataURL entfernen. #20760 (plainheart)
  • [Pause] Wichtige Änderungen gegenüber v5.6.0:
  • Das Standardthema wurde geändert, einschließlich des visuellen Stils und der Standardpositionseinstellungen von Komponenten und Serien. Beispielsweise befindet sich die Standardposition der Legende jetzt am unteren Rand der Leinwand. Die neuen Standardeinstellungen sind sinnvoller, aber wenn sie sich auf die bestehende Nutzung auswirken, verwenden Sie echarts/theme/v5.js, um den alten visuellen Stil und die Standorteinstellungen wiederherzustellen. Siehe #20865.
    • Die Version 5 echarts/src/theme/light.ts ist jetzt auf echarts/theme/rainbow.js migriert.
    • Die Position der kartesischen Achsen kann sich leicht verschieben, wenn die Achsennamen oder -beschriftungen zuvor über die Leinwand hinausgingen oder sich überlappten, da die Anti-Überlauf- und Anti-axisLabel-axisName-overlap-Mechanismen standardmäßig aktiviert sind. In den meisten Fällen sind diese Veränderungen mit bloßem Auge nicht erkennbar. Wenn jedoch eine unangemessene Änderung auftritt, können Sie die Option grid.outerBoundsMode: 'none' verwenden, um den Anti-Überlauf-Mechanismus zu deaktivieren, und/oder die Option xAxis/yAxis.axisLabel.nameMoveOverlap: false verwenden, um den Anti-axisLabel-axisName-overlap-Mechanismus zu deaktivieren. Siehe #21059.
    • Die prozentuale Basis der Option center (z. B. die Basis von '33%') auf geo, series.map, series.graph und series.tree wird geändert. Die vorherige Prozentbasis ist falsch. Wenn Sie jedoch eine Wiederherstellung durchführen müssen, legen Sie legacyViewCoordSysCenterBase: true fest (auf der Stammebene einer Echarts-Option). Siehe #19807#issuecomment-2974437299.
    • Jetzt werden Beschriftungsstile (fontStyle, fontWeight, fontSize, fontFamily, textShadowColor, textShadowBlur, textShadowOffsetX, textShadowOffsetY) geändert, um die einfachen Beschriftungsstile zu erben. Sie können richInheritPlainLabel: false (auf der Stammebene einer Echarts-Option oder auf derselben Ebene der Beschriftungsstiloptionen) verwenden, um es wiederherzustellen. Siehe #20977

Englisches Original / English original

echarts 6.0.0

  • [Feature] [theme] New theme for ECharts 6.0. #20865 #21097 #21114 (Ovilia)
  • [Feature] [chord] New chord series. #20522 (Ovilia)
  • [Feature] [matrix&calendar] New matrix coordinate system. And all series and components (including other coordinate systems, such as grid(Cartesian), geo, polar, etc.) are supported to be declaratively laid out in the cells of matrix and calendar coordinate system. #19807 #21093 (Ovilia) #21005 #21108 (100pah)
  • [Feature] [custom] Support reusable custom series. #20226 (Ovilia)
  • [Feature] [cartesian] Introduce new layout mechanism to avoid Cartesian (i.e., grid component) axis labels and axis names overflowing the canvas, prevent axis names from overlapping with axis labels, and make them the default. #21059 (100pah) #19534 (robin-gerling) #16825 (konrad-amtenbrink)
  • [Feature] [scatter] Support jittering for scatter series. #19941 #21067 (Ovilia)
  • [Feature] [axis] Support break on the axis. #19459 (Ovilia) #20857 (100pah)
  • [Feature] [theme] Support dynamically registering and switching themes. #20705 (Ovilia)
  • [Feature] [roam] Roaming infrastructure enhancement - support users specifying roaming area by roamTrigger; support clip on geo and series.map; support cursor style change when hovering on the roaming area; support preserveAspect on geo, series.map and series.graph; fix the percent base of center on geo, series.map, series.graph and series.tree; enhance the behavior for roaming area overlapping. #19807#issuecomment-2974437299 (100pah)
  • [Feature] [thumbnail] Support thumbnail for the graph series. #19807#issuecomment-3013454598 (100pah) #17471 (Lruler)
  • [Feature] [marker] Support z option for markPoint/markLine/markArea. #21117 (sz-p)
  • [Feature] [marker] Support z2 option for markPoint/markLine/markArea. #20782 (sz-p)
  • [Feature] [stack] Support reversing the stack order. #20998 (Justin-ZS)
  • [Feature] [sankey] Support roaming for sankey series. #20321 (Ovilia)
  • [Feature] [custom] Support compoundPath in custom series renderItem. #20402 #21040 (Ovilia)
  • [Feature] [marker] Support relativeTo option for specifying the relative target of marker position. #20166 #21042 (Ovilia)
  • [Feature] [axis] Support tooltip for angleAxis label. #20986 (plainheart)
  • [Feature] [tooltip] Support displayTransition option to control whether to enable the tooltip display transition. #20966 (jqqin)
  • [Feature] [visualMap] Support unboundedRange option. #21113 (100pah)
  • [Feature] [legend] Support triggerEvent option. #18164 #20907 (sz-p)
  • [Feature] [custom] Support tooltipDisabled for custom series. #20447 (Ovilia)
  • [Feature] [i18n] Add Norwegian Bokmål (nb-NO) translation. #20792 (joakimono)
  • [Feature] [i18n] Add Greek (EL) translation. #21119 (tassosgeo)
  • [Fix] [label] Fix label rich style does not inherit the plain label style. #20977 (plainheart) #21016 (100pah)
  • [Fix] [label] Fix label layout margin. #21103 (100pah)
  • [Fix] [dataZoom] Fix data shape distribution for time axis. #16978 (andrearoota) #21043 #21039 (Ovilia)
  • [Fix] [tooltip] Fix null value item on category axis should be able to show tooltip. #20777 (Justin-ZS)
  • [Fix] [visualMap] Fix some text style can't work on visualMap. #20961 (plainheart)
  • [Fix] [dataZoom] Restrict range on brushEnd. #20814 (mortalYoung)
  • [Fix] [heatmap] Fix labels not in calendar range are unexpectedly displayed. #20699 (plainheart)
  • [Fix] [series] Fix mismatched dimension index. #20682 (Justin-ZS)
  • [Fix] [bar] Fix polar bar should update roundCap when changes. #20582 (Ovilia)
  • [Fix] [pie] Fix labelLine may be not removed and cause error when single label position is not in outside. #20906 (plainheart)
  • [Fix] [sankey] Fix browser crash when emphasis.focus is 'trajectory' with large data. #20959 (plainheart)
  • [Fix] [custom] Fix potential NPE when applying leave transition. #20920 (plainheart)
  • [Fix] [tooltip] Fix potential memory leakage by explicitly unbinding event listeners. #21087 (seaheart)
  • [Fix] [axis] [log] Fix incorrect rounding usage, and support data with big negative exponent. #21107 (SihongShen) #21120 (100pah)
  • [Fix] [axis] Fix extreme small numbers can not be displayed in Cartesian due to the inappropriate rounding precision. #21120 (100pah) (SihongShen)
  • [Fix] [dataZoom] Change moveHandler cursor to default. #20304 (ribeirompl)
  • [Fix] [tooltip] Fix style coord transform markers are not removed after the tooltip is disposed. #20987 (plainheart)
  • [Fix] [bar] Remove unused startValue option from the BarSeriesOption interface. #20901 (plainheart)
  • [Fix] [title] Fix title text style width type should not include string. #20800 (sz-p)
  • [Fix] [radar] Fix blur.itemStyle not working. #21081 (mustcanbedo) #21124 (Ovilia)
  • [Fix] [roam] Fix RoamControllerHost importing path. #20313 (Ovilia)
  • [Fix] [svg] Remove SVG support check in getSvgDataURL. #20760 (plainheart)
  • [Break] Breaking changes against v5.6.0:
    • The default theme has been changed, including the visual style and the default location settings of components and series. For example, the default legend position is now at the bottom of the canvas. The new default settings are more reasonble, but if they affect the existing usage, use echarts/theme/v5.js to restore the old visual style and location settings. See #20865.
    • The v5 echarts/src/theme/light.ts is now migrated to echarts/theme/rainbow.js.
    • The position of Cartesian axes might shift slightly if the axis names or labels previously overflowed the canvas or overlapped, as anti-overflow and anti-axisLabel-axisName-overlap mechanism are enabled by default. In most cases that changes will be indiscernible to the naked eye. But if any unreasonable change occurs, you can use option grid.outerBoundsMode: 'none' to disable the anti-overflow mechanism, and/or use option xAxis/yAxis.axisLabel.nameMoveOverlap: false to disable the anti-axisLabel-axisName-overlap mechanism. See #21059.
    • The percent base of the option center (such as the base of '33%') on geo, series.map, series.graph and series.tree are changed. The previous percent base is incorrect. But if you need to restore, set legacyViewCoordSysCenterBase: true (on the root level of an echarts option). See #19807#issuecomment-2974437299.
    • Now label rich styles (fontStyle, fontWeight, fontSize, fontFamily, textShadowColor, textShadowBlur, textShadowOffsetX, textShadowOffsetY) are changed to inherit the plain label styles. You can use richInheritPlainLabel: false (on the root level of an echarts option, or at the same level of the label style options) to restore it. See #20977
