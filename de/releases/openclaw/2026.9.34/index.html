openclaw v2026.9.34

Dies ist eine reine Gateway-Version von extended-stable, die unser aktuelles Äquivalent zu LTS ist. Bei dieser Version handelt es sich um OpenClaw von Ende September 2026, plus wichtige Sicherheitsupdates, Zuverlässigkeits- und Leistungskorrekturen sowie Funktionen wie die Unterstützung neuer Modelle. Die neueste Version von OpenClaw zum Zeitpunkt dieser Veröffentlichung ist 2026.10.6

2026.9.34

Highlights

  • Sicherere Agent-Dateibearbeitungen: apply_patch validiert jetzt einen geordneten Umschlag, bevor der Arbeitsbereich geändert wird, sodass ein späterer ungültiger Block keine Dateien löschen kann, die durch einen früheren Vorgang geändert wurden. (#160409) Danke @masatohoshino, @obviyus und @RomneyDa.
  • Zuverlässigere verwaltete Upgrades: App-eigene Updates führen jetzt offizielle Plugins neben dem Kern zusammen und behalten die Reparaturdiagnose bei. Behebt #174120. (#174257) Danke @kazuyuki-eguchi und @RomneyDa.
  • Speicher-Wiki-Datensicherheit: Beim erneuten Import des OKF-Konzepts bleiben nun von Menschen erstellte Notizen erhalten. Behebt #175700. (#175707) Danke @YangManBOBO und @RomneyDa.
  • Zuverlässiger Modellstart und -auswahl: Der Gateway-Start überlebt jetzt den Besitzerwechsel durch Modellaktualisierung und die Katalogbereitschaft berücksichtigt die konfigurierte Konto-PIN des effektiven primären Modells. Behebt #178502. (#173366, #178522) Danke @ericcaiwx-star, @eduardonunesfreire-rgb und @RomneyDa.
  • Gateway- und Integrationsstabilität: Die Protokollrotation dreht sich nicht mehr auf einem gelöschten /tmp, das Schließen des Buzz-Relays verlässt das Gateway während der Authentifizierung nicht mehr und das OpenRouter-Onboarding akzeptiert gültige Anmeldeinformationen. Behebt #147269. (#160433, #170591, #173292) Danke @masatohoshino, @jarvis-modern-mail, @chandraveshchaudhari, @RomneyDa und @WadeOwenWatts.
  • Plugin-Hooks wiederhergestellt: before_tool_call-Hooks laufen jetzt unter openclaw agent exec. Behebt #158824. (#159333) Danke @joseairosa und @RomneyDa.

Änderungen

  • Verwaltete Update-Konvergenz: Offizielle Plugins werden bei Upgrades mit der von der App verwalteten Kernversion abgeglichen, wobei die Diagnose für Reparaturpfade beibehalten wird. Behebt #174120. (#174257) Danke @kazuyuki-eguchi und @RomneyDa.

Korrekturen

  • Agent-Patch-Atomizität: Preflight hat apply_patch-Umschläge vor der Mutation angeordnet, sodass spätere ungültige Hunks frühere Dateien nicht zerstören können. (#160409) Danke @masatohoshino, @obviyus und @RomneyDa.
  • Bewahrung von Memory-Wiki-Notizen: Behalten Sie von Menschen erstellte Notizen bei, wenn OKF-Konzepte erneut importiert werden. Behebt #175700. (#175707) Danke @YangManBOBO und @RomneyDa.
  • Modelllebenszyklus und Authentifizierungsauswahl: Halten Sie den Startvorgang durch Ersetzen durch Modellaktualisierung am Leben und berücksichtigen Sie die konfigurierte primäre Konto-PIN während der Katalogbereitschaft. Behebt #178502. (#173366, #178522) Danke @ericcaiwx-star, @eduardonunesfreire-rgb und @RomneyDa.
  • Gateway-Protokollierung und Buzz-Stabilität: verhindert CPU-Spin bei gelöschten Protokollzielen und verhindert, dass das NIP-42-Relay-Schließen das Gateway verlässt. Behebt #147269. (#160433, #170591) Danke @masatohoshino, @jarvis-modern-mail, @RomneyDa und @WadeOwenWatts.
  • OpenRouter-Onboarding: akzeptiert gültige API-Schlüssel während der Routenüberprüfung. (#173292) Danke @chandraveshchaudhari und @RomneyDa.
  • Agent-Plugin-Hooks: before_tool_call-Ausführung für openclaw agent exec wiederherstellen. Behebt #158824. (#159333) Danke @joseairosa und @RomneyDa.
  • Releaseübergreifende Updater-Kompatibilität: Behalten Sie die 2026.10.1-Startbeobachtung und Updater-Laufzeitexporte während des Extended-Stable-Ersatzes bei und lehnen Sie unveränderliche Installationsmutationen in dieser älteren Release-Reihe konservativ ab. (#160663) Danke @RomneyDa.
  • Laufzeitgrenzen für gepatchte Knoten: erfordern Knoten >=24.22.1 <25 || >=26.12.1 für Installation, Aktualisierung, Docker-Images und die Laufzeitprüfung der macOS-App, sodass Upgrades anfällige Laufzeiten mit einem klaren nächsten Schritt ablehnen. (#181073) Danke @RomneyDa.
  • Abhängigkeitshinweise: Patch zod (GHSA-mrhx-c7xc-m3w5), body-parser und andere Produktionshinweise zu dieser Release-Reihe. (#181341) Danke @RomneyDa.
  • Sitzungsdauerhaftigkeit: überspringt die Materialisierung leerer Transkriptarchive und begrenzt die erste Erstellung während des Transkriptabgleichs. (#170122) Danke @RomneyDa.
  • Claude CLI-Sitzungskontinuität: Subagenten-Abschlüsse setzen die Claude CLI-Sitzung nicht mehr zurück und verlieren den vorherigen Kontext. (#178955) Danke @Marvinthebored und @RomneyDa.
  • Update-Wiederherstellung: Schließen Sie die Wiederherstellung unterbrochener Updates sicher ab und behalten Sie die Gründe für die Aufnahmeunterbrechung für die ärztliche Nachuntersuchung bei. (#181503, #181870) Danke @RomneyDa.
  • Backup-, Linux- und macOS-Reparaturen: enthalten Backup- und Plattformdienstreparaturen, die für diese Versionslinie erforderlich sind, einschließlich des alten macOS Gateway-Statuspfads. (#181466) Danke @RomneyDa.
  • Release-Validierungskompatibilität: Gleicht branchnative Update-Zulassung, Deklarationsoberflächen, Sicherheitsgrundlinien und Testvorrichtungen ab, die für die aktuelle Toolchain zur vollständigen Release-Validierung erforderlich sind. (#180988) Danke @RomneyDa.

Englisches Original / English original

openclaw v2026.9.34

This is a gateway-only extended-stable release, which is our current equivalent to LTS. This release is OpenClaw from the end of September 2026, plus critical security updates, reliability and performance fixes, and features like new model support. The latest version of OpenClaw at the time of this release is 2026.10.6

2026.9.34

Highlights

  • Safer agent file edits: apply_patch now validates an ordered envelope before mutating the workspace, so a later invalid hunk cannot delete files changed by an earlier operation. (#160409) Thanks @masatohoshino, @obviyus, and @RomneyDa.
  • More reliable managed upgrades: app-owned updates now converge official plugins alongside core and retain repair diagnostics. Fixes #174120. (#174257) Thanks @kazuyuki-eguchi and @RomneyDa.
  • Memory Wiki data safety: OKF concept re-imports now preserve human-authored notes. Fixes #175700. (#175707) Thanks @YangManBOBO and @RomneyDa.
  • Reliable model startup and selection: Gateway startup now survives model-refresh ownership replacement, and catalog readiness honors the effective primary model's configured account pin. Fixes #178502. (#173366, #178522) Thanks @ericcaiwx-star, @eduardonunesfreire-rgb, and @RomneyDa.
  • Gateway and integration stability: log rotation no longer spins on a deleted /tmp, Buzz relay closure no longer exits the Gateway during authentication, and OpenRouter onboarding accepts valid credentials. Fixes #147269. (#160433, #170591, #173292) Thanks @masatohoshino, @jarvis-modern-mail, @chandraveshchaudhari, @RomneyDa, and @WadeOwenWatts.
  • Plugin hooks restored: before_tool_call hooks now run under openclaw agent exec. Fixes #158824. (#159333) Thanks @joseairosa and @RomneyDa.

Changes

  • Managed update convergence: official plugins are reconciled to the app-managed core version during upgrades, with diagnostics retained for repair paths. Fixes #174120. (#174257) Thanks @kazuyuki-eguchi and @RomneyDa.

Fixes

  • Agent patch atomicity: preflight ordered apply_patch envelopes before mutation so later invalid hunks cannot destroy earlier files. (#160409) Thanks @masatohoshino, @obviyus, and @RomneyDa.
  • Memory Wiki note preservation: retain human-authored notes when OKF concepts are imported again. Fixes #175700. (#175707) Thanks @YangManBOBO and @RomneyDa.
  • Model lifecycle and auth selection: keep startup alive through model-refresh replacement and honor the configured primary account pin during catalog readiness. Fixes #178502. (#173366, #178522) Thanks @ericcaiwx-star, @eduardonunesfreire-rgb, and @RomneyDa.
  • Gateway logging and Buzz stability: avoid deleted-log-target CPU spin and prevent NIP-42 relay closure from exiting the Gateway. Fixes #147269. (#160433, #170591) Thanks @masatohoshino, @jarvis-modern-mail, @RomneyDa, and @WadeOwenWatts.
  • OpenRouter onboarding: accept valid API keys during route verification. (#173292) Thanks @chandraveshchaudhari and @RomneyDa.
  • Agent plugin hooks: restore before_tool_call execution for openclaw agent exec. Fixes #158824. (#159333) Thanks @joseairosa and @RomneyDa.
  • Cross-release updater compatibility: retain the 2026.10.1 launchd observation and updater runtime exports during extended-stable replacement, and conservatively refuse immutable-install mutation on this older release line. (#160663) Thanks @RomneyDa.
  • Patched Node runtime floors: require Node >=24.22.1 <25 || >=26.12.1 across install, update, Docker images, and the macOS app runtime check, so upgrades refuse vulnerable runtimes with a clear next step. (#181073) Thanks @RomneyDa.
  • Dependency advisories: patch zod (GHSA-mrhx-c7xc-m3w5), body-parser, and other production advisories on this release line. (#181341) Thanks @RomneyDa.
  • Session durability: skip empty transcript archive materialization and fence the first creation during transcript reconciliation. (#170122) Thanks @RomneyDa.
  • Claude CLI session continuity: subagent completions no longer reset the Claude CLI session and lose prior context. (#178955) Thanks @Marvinthebored and @RomneyDa.
  • Update recovery: complete interrupted update recovery safely and preserve admission interruption reasons for Doctor follow-up. (#181503, #181870) Thanks @RomneyDa.
  • Backup, Linux, and macOS repairs: carry backup and platform service repairs needed by this release line, including the legacy macOS Gateway status path. (#181466) Thanks @RomneyDa.
  • Release validation compatibility: reconcile branch-native update admission, declaration surfaces, safety baselines, and test fixtures required by the current full-release validation toolchain. (#180988) Thanks @RomneyDa.
