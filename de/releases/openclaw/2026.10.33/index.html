openclaw v2026.10.33

Dies ist eine reine Gateway-Version von extended-stable, die unser aktuelles Äquivalent zu LTS ist. Bei dieser Version handelt es sich um OpenClaw von Ende Oktober 2026, plus wichtige Sicherheitsupdates, Zuverlässigkeits- und Leistungskorrekturen sowie Funktionen wie die Unterstützung neuer Modelle. Die neueste Version von OpenClaw zum Zeitpunkt dieser Veröffentlichung ist 2026.11.5

2026.10.33

Diese erweiterte, stabile Version bringt seit 2026.9.37 kumulative Gateway- und Kern-Plugin-Verbesserungen sowie ausgewählte Wartungskorrekturen für die genehmigte Produktbasislinie 2026.11.4. Die Verteilung umfasst das npm-Kernpaket, passende offizielle npm-Plugins und Gateway-Docker-Images. Native-App-Releases sind nicht enthalten.

(#194066, #196158, #195459, #196480, #176737, #181289) Verfasst von @steipete. Danke @RomneyDa, @vincentkoc, @ericcaiwx-star, @obviyus, @garrytan und @oxen-horse. – Unterbrochene Updates werden wiederhergestellt, wenn ihr Executor ausfällt, anstatt das Gateway offline zu lassen, während Versionsabweichungsprüfungen den Schutzstatus überprüfen, der noch von einem installierten Dienst verwendet wird. (#181695, #186971, #187819) Verfasst von @steipete. Danke @RomneyDa, @PonySlayer28, @tomdailey55, @jalehman, @fuller-stack-dev und @vincentkoc.
  • Antworten überstehen mehr Neustart- und Wiederherstellungspfade, behalten die ursprünglichen Eingabeaufforderungen bei, stellen Telegram-Antworten wieder her und vermeiden verlorene WhatsApp-Antworten oder übersprungene Signal-Nachrichten. openclaw v2026.10.33

This is a gateway-only extended-stable release, which is our current equivalent to LTS. This release is OpenClaw from the end of October 2026, plus critical security updates, reliability and performance fixes, and features like new model support. The latest version of OpenClaw at the time of this release is 2026.11.5

2026.10.33

This extended-stable release brings cumulative Gateway and core-plugin improvements since 2026.9.37, plus the selected maintenance fixes on the approved 2026.11.4 product baseline. Distribution covers the core npm package, matching official npm plugins, and Gateway Docker images; native-app releases are not included.

Highlights

  • Long conversations and large session stores use bounded export and recovery work, reducing out-of-memory failures during chat, memory export, Doctor repair, and Gateway startup. (#194066, #196158, #195459, #196480, #176737, #181289) Authored by @steipete. Thanks @RomneyDa, @vincentkoc, @ericcaiwx-star, @obviyus, @garrytan, and @oxen-horse.
  • Interrupted updates recover when their executor dies instead of leaving the Gateway stuck offline, while version-skew checks protect state still used by an installed service.
