openclaw v2026.10.9

2026.10.9

Highlights

  • Patchen Sie anfällige Laufzeitabhängigkeiten: Fast-uri 4.2.3 lehnt fehlerhafte URI-Schemata und Hosts bei der MCP-Schemavalidierung ab, übergroße Zod-Sammlungen werden frühzeitig in A2UI und der in Discord eingebetteten App SDK abgelehnt, die IMAP-Absenderanalyse verwendet den Nodemailer 10.1.4, sodass gefälschte Absender das Absender-Token-Gate nicht passieren können, und Microsoft Teams verwendet den gepatchten MSAL-Knoten 7.1.1. (#187294) Danke @RomneyDa. – Wenden Sie tools.fs.workspaceOnly auf vom Gateway erstellte Tools an, sodass Delegiertenänderungen weiterhin eine Genehmigung erfordern und Medientools im Arbeitsbereich verbleiben. (#185094) Danke @eleqtrizit, @RomneyDa und @shakkernerd.
  • Halten Sie Live-Anmeldeinformationen von der MCP CLI-Inspektion fern und maskieren Sie Google OAuth client-Geheimnisse in Protokollen. (#180321, #180308, #183193) Danke @brandon-julio-t, @wr-web, @LeizhenZhang und @RomneyDa.
  • Machen Sie fehlgeschlagene Update-Rollbacks sicher: Git-Source-Rollbacks behalten Bedieneränderungen bei, anstatt den Checkout zurückzusetzen, und npm-Rollbacks versuchen vorübergehende Windows-Ablehnungen erneut und melden die genaue Verschiebung, die eine bootfähige Installation wiederherstellt, anstatt das Paketstammverzeichnis zu stranden. (#185201, #184887, #185160, #184889) Danke @wr-web, @syxscott, @LiuwqGit, @shakkernerd und @RomneyDa.
  • Stellen Sie intakte Agentendatenbanken und veraltete Volltextindizes nach Änderungen am SQLite-Tokenizer wieder her, einschließlich Update-Snapshots. (#176234, #176220, #176833, #181206) Danke @ndakota79 und @RomneyDa. – Reparieren Sie Aktualisierungen, bei denen die Veröffentlichung abgeschlossen ist, nach einem erneuten Bereitstellen, während Sie den ursprünglichen Launcher und den versiegelten Wiederherstellungshelfer beibehalten. (#186557, #186527) Danke @ericcaiwx-star, @sennyhoney und @RomneyDa.
  • Migrieren Sie große Transkriptarchive, ohne die Zeichenfolgenbeschränkungen Node.js zu überschreiten. (#170853, #170847) Danke @iamonlv426 und @RomneyDa. – Ermöglichen Sie Agenten die Wiederherstellung nach einer vollen Festplatte, sobald Speicherplatz verfügbar wird, ohne dass ein Neustart erforderlich ist. (#176902) Danke @RomneyDa.

Änderungen

Der Schwerpunkt dieser Wartungsversion liegt auf Patches für Sicherheitsabhängigkeiten, Wiederherstellung, Datenerhaltung und Zuverlässigkeitskorrekturen.

Korrekturen

– Lösen Sie lokale Medien in Codex-Lenknachrichten aus dem eigenen Arbeitsbereich der Sitzung statt aus dem Standardarbeitsbereich des Agenten auf. (#181528) Danke @RomneyDa. – Melden Sie eine unsichere Prozessbereinigung von gepufferten Befehlen, wie z. B. lokale CLI-Sprachanbieter, anstatt sie als gewöhnlichen Befehlsfehler darzustellen. (#184270, #184237) Danke @shakkernerd und @RomneyDa.

  • Halten Sie erneut genehmigte Knotenverbindungen aufrecht, indem Sie die Genehmigung mit den festgeschriebenen Paarungsfakten veröffentlichen, bevor die Anforderung fortgesetzt wird. Danke @RomneyDa.
  • Stellen Sie gestoppte Gateways wieder her, wenn die Dienstaktivierung nicht überprüft werden kann. Behalten Sie das Wiederherstellungsverhalten in der Windows-Triage bei. (#172784, #181577, #181698) Danke @SMF12138 und @RomneyDa. – Vermeiden Sie die Deinstallation eines Gateway-Dienstes während eines passiven macOS-Stopps, wenn kein Dienst installiert ist. (#181257) Danke @shakkernerd, @LiuwqGit, @eleqtrizit, @syxscott und @RomneyDa.
  • Stellen Sie die Laufzeiten des CLI-Knotens wieder her, wenn Sie vom Dateisystem-Root aus gestartet werden, einschließlich gestarteter Jobs. (#178112, #177739) Danke @downingkeys und @RomneyDa. – Starten Sie neue ACP-Sitzungen im angeforderten Arbeitsverzeichnis statt im Standardarbeitsbereich. (#176852, #123557) Danke @yinx65588-boop, @crappier und @RomneyDa. – Verhindern Sie, dass überlappende Modellaktualisierungen fehlschlagen. (#179144) Danke @RomneyDa. – Berücksichtigen Sie einen expliziten SSH-Port 22 in openclaw gateway probe --ssh anstelle des konfigurierten Ports des Alias. (#171092) Danke @zhangguiping-xydt, @obviyus und @RomneyDa. – Behalten Sie Skill-Metadaten wie Symbole und Homepages bei, wenn ein Inline-Metadatenwert YAML einen nachgestellten Kommentar hat. (#171224) Danke @zhangguiping-xydt, @Takhoffman und @RomneyDa. – Vom Anbieter ignorierte Optionen im openclaw infer video generate-Text und in der JSON-Ausgabe anzeigen. (#171172) Danke @ly85206559, @obviyus und @RomneyDa.

openclaw v2026.10.9

2026.10.9

Highlights

  • Patch vulnerable runtime dependencies: fast-uri 4.2.3 rejects malformed URI schemes and hosts in MCP schema validation, oversized Zod collections are rejected early in A2UI and the Discord embedded app SDK, IMAP sender parsing uses nodemailer 10.1.4 so spoofed senders cannot pass the sender token gate, and Microsoft Teams uses patched MSAL Node 7.1.1. (#187294) Thanks @RomneyDa.
  • Apply tools.fs.workspaceOnly to Gateway-built tools, so delegate changes still require approval and media tools stay inside the workspace. (#185094) Thanks @eleqtrizit, @RomneyDa, and @shakkernerd.
  • Keep live credentials out of MCP CLI inspection and mask Google OAuth client secrets in logs. (#180321, #180308, #183193) Thanks @brandon-julio-t, @wr-web, @LeizhenZhang, and @RomneyDa.
  • Make failed update rollbacks safe: Git-source rollbacks preserve operator edits instead of resetting the checkout, and npm rollbacks retry transient Windows denials and report the exact move that restores a bootable install instead of stranding the package root. (#185201, #184887, #185160, #184889) Thanks @wr-web, @syxscott, @LiuwqGit, @shakkernerd, and @RomneyDa.
  • Recover intact agent databases and stale full-text indexes after SQLite tokenizer changes, including update snapshots. (#176234, #176220, #176833, #181206) Thanks @ndakota79 and @RomneyDa.
  • Repair publication-complete updates after a remount while retaining the original launcher and sealed recovery helper. (#186557, #186527) Thanks @ericcaiwx-star, @sennyhoney, and @RomneyDa.
  • Migrate large transcript archives without exceeding Node.js string limits. (#170853, #170847) Thanks @iamonlv426 and @RomneyDa.
  • Allow agents to recover after a full disk once space becomes available, without requiring a restart. (#176902) Thanks @RomneyDa.

Changes

This maintenance release focuses on security dependency patches, recovery, data preservation, and reliability fixes.

Fixes

  • Resolve local media in Codex steering messages from the session's own workspace instead of the agent's default workspace. (#181528) Thanks @RomneyDa.
  • Report uncertain process cleanup from buffered commands, such as local CLI speech providers, instead of presenting it as an ordinary command failure. (#184270, #184237) Thanks @shakkernerd and @RomneyDa.
  • Keep reapproved node connections alive by publishing the approval with its committed pairing facts before the request resumes. Thanks @RomneyDa.
  • Recover stopped Gateways when service activation cannot be verified; retain untouched-recovery behavior in Windows triage. (#172784, #181577, #181698) Thanks @SMF12138 and @RomneyDa.
  • Avoid uninstalling a Gateway service during a passive macOS stop when no service is installed. (#181257) Thanks @shakkernerd, @LiuwqGit, @eleqtrizit, @syxscott, and @RomneyDa.
  • Recover CLI Node runtimes when launched from the filesystem root, including launchd jobs. (#178112, #177739) Thanks @downingkeys and @RomneyDa.
  • Start new ACP sessions in the requested working directory instead of the default workspace. (#176852, #123557) Thanks @yinx65588-boop, @crappier, and @RomneyDa.
  • Prevent overlapping model refreshes from failing requests. (#179144) Thanks @RomneyDa.
  • Honor an explicit SSH port 22 in openclaw gateway probe --ssh instead of the alias's configured port. (#171092) Thanks @zhangguiping-xydt, @obviyus, and @RomneyDa.
  • Keep skill metadata such as icons and homepages when an inline YAML metadata value has a trailing comment. (#171224) Thanks @zhangguiping-xydt, @Takhoffman, and @RomneyDa.
  • Show provider-ignored options in openclaw infer video generate text and JSON output. (#171172) Thanks @ly85206559, @obviyus, and @RomneyDa.
