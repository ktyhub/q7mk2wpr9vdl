<!-- co:release-notes:career-ops-v1.35.0 -->

Diese Veröffentlichung erweitert den Blickwinkel von Career Ops: neun neue Jobquellen, von den Bewerbersystemen der US-Schulbezirke bis hin zu OCC Mundial in Mexiko. Es trägt die Arbeit von 86 Personen, von denen 50 zum ersten Mal einen Beitrag leisten.

Highlights

  • Neun neue Jobquellen. AppliTrack, NEOGOV, Red Rover und SchoolSpring, verwendet von US-K-12-Bezirken und Community Colleges, von @raymondwilliamskc (#4360). HiringRoom von @cRolandoJr (#4460), OCC Mundial von @VictorMeneses77 (#3748) und Eploy, PeopleSoft Candidate Gateway und PrevueAPS von @Schlaflied (#4055, #3739, #3919). BambooHR, bereits unterstützt, ist jetzt Teil des vollständigen Scans (scan:full), von @ilyakanevskiy (#4365).
  • Ein Master-Karriereprofil, das Sie Fakt für Fakt überprüfen. node career-profile.mjs import --review liest Ihren Lebenslauf und lässt Sie jeden Fakt genehmigen, bearbeiten oder überspringen; Es werden nur genehmigte Fakten gespeichert und validate prüft das Ergebnis. Auch als /career-ops master-profile erhältlich. Von @Kilaa13 (#4456).
  • Lebenslaufdetails. Eine optionale Berufsbezeichnung unter Ihrem Namen von @Zoubeir23 (#3763), ein optionales einzeiliges context für jeden Berufserfahrungseintrag von @lesiashu (#4049) und ein Schutz, der generate-pdf daran hindert, Berufserfahrung in chronologischer Reihenfolge zu drucken, von @abp002, der #2343 (#4489) von @kmichels abgeholt hat.
  • Ihr Datenstamm, in mehr Skripten. Wenn sich Ihre Daten außerhalb des Code-Checkouts (CAREER_OPS_ROOT) befinden, finden sie jetzt in Lebenslauf- und Anschreiben-PDFs von @shaurya20335 (#4486) und @marcosfemonteiro (#4314) sowie set-status von @abankar1 (#3988), hired-share, reply-watch, paste-reply und batch-tailor von @alejandra-dahl (#4571, #4570) und fix-slugs und validate-portals von @SulimanAbdulrazzaq (#4287).
  • Installieren und aktualisieren. npm install schlägt auf Linux-Distributionen ohne apt-get, wie z. B. Fedora, von @Zoubeir23 (#4233) nicht mehr fehl. npx @santifer/career-ops init schlägt bei npm install unter Windows nicht mehr fehl, von @samintisar (#4572). node update-system.mjs status druckt Ihre Version und Ihr Commit von @Shaamak (#3897).

Aktualisierung

Ihr Agent bietet dieses Update zu Beginn Ihrer nächsten Sitzung an. Wenn dies nicht der Fall ist, führen Sie Folgendes einmal in Ihrem Career-Ops-Ordner aus:

node update-system.mjs apply --confirm

Bei 1.33 oder früher wird in der Eingabeaufforderung möglicherweise angezeigt, dass Ihre Systemdateien unterschiedlich sind: Sagen Sie „Ja“. Dieses erste Update, das von 1.33 oder früher stammt, installiert das aktuelle main und nicht diese Version. Ihr Lebenslauf, Ihr Profil, Ihr Tracker und Ihre Berichte bleiben davon unberührt und es gibt nichts anderes zu tun. Wenn Sie nach der Veröffentlichung von 1.34.0 ein Update von 1.33 oder früher durchgeführt haben, meldet Ihre Installation möglicherweise 1.34.0, während ein späterer Snapshot von main ausgeführt wird. Dieses Update verschiebt es auf die Version 1.35.0. Neuinstallationen: npx @santifer/career-ops init.

<!-- co:release-notes:career-ops-v1.35.0 -->

This release widens where career-ops looks: nine new job sources, from the applicant systems of US school districts to OCC Mundial in Mexico. It carries work from 86 people, 50 of them contributing for the first time.

Highlights

  • Nine new job sources. AppliTrack, NEOGOV, Red Rover and SchoolSpring, used by US K-12 districts and community colleges, by @raymondwilliamskc (#4360). HiringRoom by @cRolandoJr (#4460), OCC Mundial by @VictorMeneses77 (#3748), and Eploy, PeopleSoft Candidate Gateway and PrevueAPS by @Schlaflied (#4055, #3739, #3919). BambooHR, already supported, is now part of the full scan (scan:full), by @ilyakanevskiy (#4365).
  • A master career profile you review fact by fact. node career-profile.mjs import --review reads your CV and lets you approve, edit or skip each fact; only approved facts are saved, and validate checks the result. Also available as /career-ops master-profile. By @Kilaa13 (#4456).
  • CV details. An optional professional title under your name by @Zoubeir23 (#3763), an optional one-line context for each experience entry by @lesiashu (#4049), and a guard that stops generate-pdf from printing work experience out of chronological order, by @abp002, who picked up @kmichels' #2343 (#4489).
  • Your data root, in more scripts. If your data lives outside the code checkout (CAREER_OPS_ROOT), CV and cover letter PDFs now find it, by @shaurya20335 (#4486) and @marcosfemonteiro (#4314), and so do set-status by @abankar1 (#3988), hired-share, reply-watch, paste-reply and batch-tailor by @alejandra-dahl (#4571, #4570), and fix-slugs and validate-portals by @SulimanAbdulrazzaq (#4287).
  • Install and update. npm install no longer fails on Linux distributions without apt-get, such as Fedora, by @Zoubeir23 (#4233). npx @santifer/career-ops init no longer fails at npm install on Windows, by @samintisar (#4572). node update-system.mjs status prints your version and commit, by @Shaamak (#3897).

Updating

Your agent offers this update at the start of your next session. If it doesn't, run this once in your career-ops folder:

node update-system.mjs apply --confirm

On 1.33 or earlier the prompt may say your system files differ: say yes. Coming from 1.33 or earlier, that first update installs the current main rather than this release. Your CV, profile, tracker and reports are not touched, and there is nothing else to do.

If you updated from 1.33 or earlier after 1.34.0 came out, your install may report 1.34.0 while running a later snapshot of main. This update moves it forward to the 1.35.0 release.

New installs: npx @santifer/career-ops init.
