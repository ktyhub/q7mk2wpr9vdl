Codex rust-v0.163.0

Neue Funktionen

  • Öffnen Sie /config, um Einstellungen kategorienübergreifend zu durchsuchen, unterstützte Einstellungen sofort zu ändern und zu sehen, welche Änderungen einen Neustart erfordern. (#52990, #53429)
  • Senden Sie ein Follow-up, während Codex antwortet, um es sofort zu steuern. Das Unterbrechen einer Drehung stoppt auch aktive Codemoduszellen und ihre verschachtelten Werkzeugaufrufe. (#51812, #51835)
  • Konfigurieren Sie einen Leader-Schlüssel in /keymap. Der Standardwert ist Ctrl+X, Verknüpfungshinweise bleiben geöffnet, bis Sie auswählen oder abbrechen, und die Sprachstummschaltung wechselt zu F9. (#52273)
  • Starten Sie einen verwalteten Hintergrundserver von /daemon aus neu. Codex warnt vor Arbeiten, die durch den Neustart unterbrochen werden könnten, und stellt dann automatisch die Verbindung wieder her. (#53173)
  • Codex kann unabhängige schreibgeschützte Tools parallel ausführen, einschließlich der Suche nach Fähigkeiten, Gedächtnis und Konversationsverlauf. (#52245)
  • Daybreak ist für berechtigte Konten standardmäßig aktiviert. codex exec kann es auch mit einem OpenAI API-Schlüssel auswählen, wenn der Server Zugriff bietet. (#53701, #53717)

Fehlerbehebungen

– Durch das Fortsetzen eines gespeicherten Threads werden dessen Berechtigungen und Netzwerkgenehmigungen wiederhergestellt, wobei explizite Außerkraftsetzungen und die aktuell verwaltete Richtlinie berücksichtigt werden. (#53150, #53419, #53424) – Der Netzwerk-Proxy überprüft jetzt die Berechtigung vor einer DNS-Suche, lehnt doppelte Host-Header ab und verhindert, dass Anmeldeinformations-Aliase Inspektions-Hooks umgehen. (#51650, #52661, #53506)

  • Kehren Sie nach dem Threadwechsel zu einer bestehenden Nebenkonversation mit /side zurück. Antworten auf ausstehende Fragen gehen ebenfalls an den Thread zurück, der die Frage gestellt hat. (#52184, #53436)
  • Unter Windows fügen Ctrl+V und Shift+Insert sowohl Text als auch Bilder ein. Unter WSL wird bei wiederholten Einfügungen der clipboard-Reader wiederverwendet, und bei Kopierversuchen kommt es zu Zeitüberschreitungen, anstatt zu hängen. (#53224, #52967, #53453) – Lokale Befehle werden sofort beendet, wenn ein Kind eine Ausgabepipe offen hält. Remote-Befehle bewahren verspätet eintreffende Ausgaben auf, sodass sie bei der letzten Abfrage noch erfasst werden können. (#52652, #53331, #53622) – codex exec druckt denselben Dateiunterschied nach einem nicht verwandten Befehl nicht mehr erneut aus. (#53444)

Dokumentation

– Die gebündelten OpenAI Docs-Anleitungen für Migrationen zur GPT-6-Familie wurden aktualisiert, einschließlich modellspezifischer Überlegungen, Tool-Nutzung und Überlegungen zur Datenresidenz. (#51768) – Es wurde klargestellt, wie die Linux-Sandbox Bubblewrap für die Dateisystemisolierung und Seccomp für die Systemaufruffilterung verwendet. (#52610)

Aufgaben

– Codex verwendet jetzt seinen Standard-Shell-Executor und bündelt kein gepatchtes zsh mehr. Konfigurationen, die die zurückgezogenen Shell-Flags verwenden, erhalten eine Migrationsbenachrichtigung. (#52160, #52213) – Reduzierte Paketgröße für Linux- und macOS-Releases, indem Symbole aus gepackten Binärdateien entfernt und gleichzeitig in den ursprünglichen Build-Ausgaben beibehalten wurden. (#52178)

codex rust-v0.163.0

New Features

  • Open /config to search preferences across categories, change supported settings immediately, and see which changes require a restart. (#52990, #53429)
  • Send a follow-up while Codex is responding to steer it immediately. Interrupting a turn also stops active Code Mode cells and their nested tool calls. (#51812, #51835)
  • Configure a leader key in /keymap. The default is Ctrl+X, shortcut hints stay open until you choose or cancel, and voice mute moves to F9. (#52273)
  • Restart a managed background server from /daemon. Codex warns about work the restart could interrupt, then reconnects automatically. (#53173)
  • Codex can run independent read-only tools in parallel, including skill, memory, and conversation-history lookups. (#52245)
  • Daybreak is enabled by default for eligible accounts. codex exec can also select it with an OpenAI API key when the server offers access. (#53701, #53717)

Bug Fixes

  • Resuming a saved thread restores its permissions and network approvals, while respecting explicit overrides and current managed policy. (#53150, #53419, #53424)
  • The network proxy now checks permission before a DNS lookup, rejects duplicate Host headers, and prevents credential aliases from bypassing inspection hooks. (#51650, #52661, #53506)
  • Return to an existing side conversation with /side after switching threads. Answers to pending prompts also go back to the thread that asked. (#52184, #53436)
  • On Windows, Ctrl+V and Shift+Insert paste text as well as images. On WSL, repeated pastes reuse the clipboard reader, and copy attempts time out instead of hanging. (#53224, #52967, #53453)
  • Local commands finish promptly when a child keeps an output pipe open. Remote commands preserve late-arriving output so the final poll can still collect it. (#52652, #53331, #53622)
  • codex exec no longer prints the same file diff again after an unrelated command. (#53444)

Documentation

  • Updated the bundled OpenAI Docs guidance for migrations to the GPT-6 family, including model-specific reasoning, tool use, and data residency considerations. (#51768)
  • Clarified how the Linux sandbox uses bubblewrap for filesystem isolation and seccomp for syscall filtering. (#52610)

Chores

  • Codex now uses its standard shell executor and no longer bundles a patched zsh. Configurations using the retired shell flags receive a migration notice. (#52160, #52213)
  • Reduced Linux and macOS release package size by stripping symbols from packaged binaries while preserving them in the original build outputs. (#52178)
