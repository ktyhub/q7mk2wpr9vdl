codex rust-v0.168.0

Release Veröffentlicht13. Nov. 2026 Quelleopenai/codex Englisches Original

Diese Seite ist maschinell übersetzt. Maßgeblich ist der englische Originaltext.

Codex rust-v0.168.0

Neue Funktionen

  • Durchsuchen Sie Modellanbieter unter Sitzungen → Modellanbieter und wählen Sie die Standardeinstellung für neue Chats. (#59541, #59722)
  • Aktivieren Sie features.tui_workspace, um neben dem Hauptchat eine Nebenkonversation anzuzeigen. Ziehen Sie die Trennlinie, um die Größe der Bereiche zu ändern, oder drücken Sie leader z, um den fokussierten Bereich zu vergrößern. (#58992, #59527, #59595)
  • Fügen Sie Aufnahmen bei, wenn Sie ein audiofähiges Modell verwenden. Codex überspringt bestätigte abgelehnte Aufnahmen in späteren Runden und verwendet die Dauer von clip, um kürzere Aufnahmen im Kontext zu halten. (#59234, #59268)
  • Aktivieren Sie features.image_generation_animation zum Generieren oder Bearbeiten animierter GIFs mit optionaler Bildanzahl und Zeitsteuerung. (#59073)
  • Vollbild-Codex zeigt Bildvorschauen und Haustiere in tmux auf Ghostty und Kitty mit allow-passthrough all an. (#59579, #59580)
  • Legen Sie tui.notification_method = "osc777" für Terminalbenachrichtigungen fest. Genehmigungsbenachrichtigungen zeigen längere Befehlsvorschauen und unterscheiden Terminaleingaben von Netzwerkzugriffsanfragen. (#59256)

Fehlerbehebungen

  • Lokaler TUI-Verlauf und Lebenslaufauswahl filtern neu erstellte Threads nach dem angemeldeten ChatGPT-Konto. (#58918)
  • Offene und fortgesetzte Chats verwenden ihren gespeicherten Modellanbieter, nachdem Sie die Standardeinstellung für neue Chats geändert haben. (#59503) – Die TUI stellt Antworten, die durch Tool-Aufrufe unterbrochen wurden, als einzelne Markdown-Nachricht dar und stellt die Zusammenfassungen der Begründungen wieder her, wenn eine Konversation wiedergegeben wird. (#59698, #59700)
  • Steuerungsnachrichten erreichen laufende Runden, wenn sie während der letzten Speicherung des Transkripts oder nach dem Zurückwechseln zu einem Chat mit langer Laufzeit gesendet werden. (#58877, #58998)
  • Durch die Fuzzy-Dateisuche werden Dateinamenübereinstimmungen stärker gewichtet, sodass es weniger wahrscheinlich ist, dass übereinstimmende übergeordnete Verzeichnisse sie verdrängen. (#59709) – Inaktive lokale MCP-Server unter Windows lassen die E/A des Dateisystems für den Rest von Codex verfügbar. (#59726)

Dokumentation

– Die App-Server-Referenz behandelt das Auflisten von Modellanbietern, das Erstellen benutzerdefinierter Gateways und das Aktualisieren von Gateway-, Bedrock- und GCP-Einstellungen. (#58845, #58876)

Aufgaben

– Codex warnt, wenn features.multi_agent explizit konfiguriert ist, und verweist auf agents.enabled zum Deaktivieren von Subagent-Tools. (#59479) – Mitwirkende können Bazel CI-Jobs lokal ohne BuildBuddy-Anmeldeinformationen ausführen. (#59055)

codex rust-v0.168.0

New Features

  • Browse model providers under Sessions → Model providers and choose the default for new chats. (#59541, #59722)
  • Enable features.tui_workspace to view a side conversation beside the main chat. Drag the divider to resize the panes or press leader z to zoom the focused pane. (#58992, #59527, #59595)
  • Attach recordings when using an audio-capable model. Codex skips confirmed rejected recordings on later turns and uses clip duration to keep more short recordings in context. (#59234, #59268)
  • Enable features.image_generation_animation to generate or edit animated GIFs with optional frame count and timing controls. (#59073)
  • Fullscreen Codex displays image previews and pets in tmux on Ghostty and Kitty with allow-passthrough all. (#59579, #59580)
  • Set tui.notification_method = "osc777" for terminal notifications. Approval notifications show longer command previews and distinguish terminal input from network access requests. (#59256)

Bug Fixes

  • Local TUI history and resume pickers filter newly created threads by the signed-in ChatGPT account. (#58918)
  • Open and resumed chats use their saved model provider after you change the default for new chats. (#59503)
  • The TUI renders replies interrupted by tool calls as a single Markdown message and restores reasoning summaries when replaying a conversation. (#59698, #59700)
  • Steering messages reach running turns when sent during the final transcript save or after switching back to a long-running chat. (#58877, #58998)
  • Fuzzy file search gives filename matches more weight so matching parent directories are less likely to crowd them out. (#59709)
  • Idle local MCP servers on Windows leave filesystem I/O available to the rest of Codex. (#59726)

Documentation

  • The app-server reference covers listing model providers, creating custom gateways, and updating gateway, Bedrock, and GCP settings. (#58845, #58876)

Chores

  • Codex warns when features.multi_agent is explicitly configured and points to agents.enabled for disabling subagent tools. (#59479)
  • Contributors can run Bazel CI jobs locally without BuildBuddy credentials. (#59055)
