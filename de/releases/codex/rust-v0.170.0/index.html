Codex rust-v0.170.0

Neue Funktionen

  • WebRTC-Aushandlung für Echtzeit-Sprachanrufe in der TUI hinzugefügt. (#61172) – Automatisch aktualisierte Authentifizierungsheader für OpenTelemetry-HTTP-Exporteure hinzugefügt. (#61028) – Experimentelle Unterstützung für die Verwendung identisch benannter MCP-Server in verschiedenen Umgebungen hinzugefügt. (#60905)

Fehlerbehebungen

– Übergroße WebSocket-Anfragen werden jetzt ohne unnötige Wiederholungsversuche auf HTTP zurückgesetzt. (#60840, #60841) – MCP-OAuth-Anmeldeinformationsrennen beim Abbrechen, Anmelden und Abmelden wurden behoben. (#60849, #60981)

  • Verbesserte automatische Wiederverbindung für Cloud-Konversationen und Beibehaltung aktiver Wiederherstellungsrunden, wenn clients die Verbindung wiederherstellen. (#60969, #61014) – Das Ersetzen von Windows-Dateien, die Beibehaltung der Sandbox-Berechtigungen und die Wiederherstellung der Laufzeitregistrierung wurden behoben. (#60872, #60943, #60944) – Problem mit Berechtigungsaktualisierungen und untergeordneten Threads, die bestehende Sandbox-Einschränkungen verloren haben, behoben. (#60936, #61134)
  • Suchergebnisse für doppelte Dateien entfernt und Thread-Suchausschnitte für Abfragen mit Leerzeichen korrigiert. (#60845, #60846)

Dokumentation

– Aktualisierte Sandbox-Dokumentation zur Erläuterung von Berechtigungsprofilen und Dateisystemregeln. (#61133)

Englisches Original / English original

codex rust-v0.170.0

New Features

  • Added WebRTC negotiation for realtime voice calls in the TUI. (#61172)
  • Added automatically refreshed authentication headers for OpenTelemetry HTTP exporters. (#61028)
  • Added experimental support for using identically named MCP servers across environments. (#60905)

Bug Fixes

  • Oversized WebSocket requests now fall back to HTTP without unnecessary retries. (#60840, #60841)
  • Fixed MCP OAuth credential races during cancellation, login, and logout. (#60849, #60981)
  • Improved automatic reconnection for Cloud conversations and preserved active recovery turns when clients reconnect. (#60969, #61014)
  • Fixed Windows file replacement, sandbox permission preservation, and runtime registration recovery. (#60872, #60943, #60944)
  • Fixed permission updates and child threads losing existing sandbox restrictions. (#60936, #61134)
  • Removed duplicate file search results and fixed thread search snippets for queries containing whitespace. (#60845, #60846)

Documentation

  • Updated sandbox documentation to explain permission profiles and filesystem rules. (#61133)
