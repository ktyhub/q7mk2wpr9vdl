🌟 Codename: Every Run, Intact gehalten

🧭 26 PRs · 13 contributors · 1 Tag – Ein Lauf sollte die Realität überdauern
Welt, nicht nur der glückliche Weg. Nachladen, Folgefragen, Vorschau von Änderungen
und die ersten Starts waren früher die Momente, in denen die Arbeit ihren Platz verlieren konnte; jetzt die
Das Projekt behält es im Griff. 🚀

🔥 Highlights

  • 🧵 Gespräche bleiben erhalten, wenn die Arbeit weitergeht. Planung
    Antworten, Live-Aufgabenfortsetzungen, Entscheidungen über blockierte Aufgaben und wiederhergestellte Ausgaben
    Bleiben Sie bei der Aufgabe, die sie erzeugt hat – auch nach einem Neuladen oder einer Nachverfolgung.
    Verzweigte Chats beginnen sauber, anstatt die Arbeit einer anderen Konversation zu übernehmen.
    Eine reine Planungsantwort endet nun als die Antwort, die Sie erhalten haben, und nicht als rote Fehlschlag
    laufen. (#8322, #8195, #8008, #8007, #8172, #8029, #8158) Danke @itscheems,
    @lefarcen.
  • 🖼️ Ihre aktuelle Vorschau bleibt die Vorschau, die Sie ausgewählt haben. Echte Seiten nicht mehr
    in leere Snapshots verwandeln, und ein veralteter Datei-Leser kann die Chat-Vorschau nicht stehlen
    während Sie etwas anderes inspizieren. (#7125, #8067) Danke @huynextlevel.
  • 🃏 Reichhaltige Antworten kommen als Antworten, nicht als Markup. Open Design dekodiert Karten
    im Denkstrom und lässt eine fehlerhafte Karte sicher fallen, anstatt etwas zu verschütten
    seine Rohdaten in die Konversation ein. (#8258, #8264) Danke @lefarcen.
  • 🪟 Eine neue Windows-Installation gelangt beim ersten Mal zur App. Die gepackte App
    verwechselt seinen anfänglichen Nutzlaststatus nicht mehr mit einer fehlgeschlagenen Übergabe, so das Web
    Die Schnittstelle kann beim ersten Start eine Verbindung zu ihrer lokalen Engine herstellen. (#7520) Danke
    @lorenzozanee.
  • 🔑 Novita AI ist im BYOK-Picker bereit. Wählen Sie Novita AI, bringen Sie Ihr mit
    Schlüssel und wählen Sie aus den aktuellen Versionen DeepSeek, MiniMax, Qwen, GLM, Kimi und GPT-OSS
    Modelle ohne manuelle Erstellung des Anbieter-Setups. (#6327) Danke @jax-novita.

🧠 Agenten, Laufzeiten und Sandbox

– Workspace-Abonnements werden sauber zurückgesetzt, wenn Sie Profile ändern, wobei das beibehalten wird
Projekte und Kontostatus werden vor Ihnen synchron mit Ihrem Arbeitsbereich angezeigt
tatsächlich ausgewählt. (#8020) Danke @AmyShang-alt. – Wenn beide installiert sind, bevorzugt die lokale Agentenerkennung den direkten Copiloten CLI
über die Bootstrap-Kopie von VS Code. (#7974) Danke @tony-box.

  • od automation create und od automation update können wieder annehmen
    Komma-getrennter Skill-Kontext, ohne dass ein Fehler auftritt, bevor der Befehl ausgeführt wird.
    (#7612) Danke @johnkattenhorn.
  • od media generate --help zeigt jetzt Hilfe an, ohne zu versuchen, eine Generation zu starten.

    Das Cover-Rendering erreicht einen klaren Endzustand, anstatt einen irreführenden Zustand zu hinterlassen
    Ergebnis zurück. (#7586, #8061) Danke @arccat-114.

🐛 Behoben

🧠 Agenten, Laufzeiten und Gespräche

  • Wiederhergestellte Gespräche behalten die richtigen Aufgabenurteile, Ergebnisse und Planung bei
    Absicht über Neuladungen und Fortsetzungen hinweg. (#8195, #8008, #8007, #8172)
  • Durch das Verzweigen einer Konversation werden die Quellartefakte nicht mehr in die Konversation übertragen
    neuer Chat. (#8029) Danke @lefarcen.
  • Ein fortgesetztes Gespräch bricht eine unbeantwortete Frage zusammen, ohne etwas vorzutäuschen
    es wurde beantwortet. (#8158)
  • Eine Ablehnung in der Planungsphase, die Ihnen dennoch eine nützliche Antwort gab, bleibt beim Normalen
    Status „Fertig“, anstatt eine fehlgeschlagene Karte anzuzeigen; echte Produktionsfehler
    tauchen immer noch als Misserfolge auf. (#8322) Danke @itscheems.

🎨 Studio, Vorschau und Export

  • Vorschau-Snapshots behalten den echten Seiteninhalt bei, verzögerte Dateilesevorgänge hingegen nicht
    Ersetzen Sie die Vorschau, die Sie aktiv verwenden. (#7125, #8067) Danke
    @huynextlevel.
  • Gültige Thinking-Stream-Karten werden als Karten gerendert; ungültige bleiben sicher draußen
    des Gesprächs. (#8258, #8264) Danke @lefarcen.

🌍 Lokalisierung

  • Die französische Kopie ist im gesamten Design-System-Flow, in der Bibliothek und im Speicher vollständig.
    (#7906, #7756) Danke @davezfr.

🖥️ Desktop

– Neue Windows-Installationen schließen die lokale Desktop-Übergabe ab und können geladen werden
die App normal. (#7520) Danke @lorenzozanee.

open-design open-design-v0.24.0

🌟 Codename: Every Run, Kept Intact

🧭 26 PRs · 13 contributors · 1 day — A run should survive the real
world, not just the happy path. Reloads, follow-up questions, preview changes
and first launches used to be the moments work could lose its place; now the
project keeps hold of it. 🚀

🔥 Highlights

  • 🧵 Conversations keep their thread when the work keeps moving. Planning
    answers, live task continuations, blocked-task decisions and recovered output
    stay with the task that produced them—even after a reload or a follow-up.
    Forked chats start clean instead of inheriting another conversation’s work.
    A planning-only reply now ends as the answer you received, not as a red failed
    run. (#8322, #8195, #8008, #8007, #8172, #8029, #8158) Thanks @itscheems,
    @lefarcen.
  • 🖼️ Your current preview stays the preview you chose. Real pages no longer
    turn into blank snapshots, and a stale file read cannot steal the chat preview
    while you are inspecting something else. (#7125, #8067) Thanks @huynextlevel.
  • 🃏 Rich answers arrive as answers, not markup. Open Design decodes cards
    in the thinking stream and safely drops a malformed card instead of spilling
    its raw data into the conversation. (#8258, #8264) Thanks @lefarcen.
  • 🪟 A fresh Windows install gets to the app, first time. The packaged app
    no longer mistakes its initial payload state for a failed handoff, so the web
    interface can connect to its local engine on first launch. (#7520) Thanks
    @lorenzozanee.
  • 🔑 Novita AI is ready in the BYOK picker. Choose Novita AI, bring your
    key, and pick from its current DeepSeek, MiniMax, Qwen, GLM, Kimi and GPT-OSS
    models without hand-building the provider setup. (#6327) Thanks @jax-novita.

✨ Added

🔑 BYOK, models and media

  • Novita AI joins the BYOK provider presets with its model catalog and API-key
    management link. (#6327) Thanks @jax-novita.

🔁 Changed

🧠 Agents, runtimes and sandbox

  • Workspace subscriptions reset cleanly when you change profiles, keeping the
    projects and account state in front of you in sync with the workspace you
    actually selected. (#8020) Thanks @AmyShang-alt.
  • When both are installed, local Agent detection prefers the direct Copilot CLI
    over VS Code’s bootstrap copy. (#7974) Thanks @tony-box.
  • od automation create and od automation update can again accept
    comma-separated skill context without failing before the command runs.
    (#7612) Thanks @johnkattenhorn.
  • od media generate --help now shows help without trying to start a generation.
    (#8066)

🎨 Studio, editing and canvas

  • Manifest-backed Markdown artifacts now count as real run output, and late
    cover rendering reaches a clear final state instead of leaving a misleading
    result behind. (#7586, #8061) Thanks @arccat-114.

🐛 Fixed

🧠 Agents, runtimes and conversations

  • Recovered conversations keep the right task verdicts, outputs and planning
    intent across reloads and continuations. (#8195, #8008, #8007, #8172)
  • Forking a conversation no longer carries its source run artifacts into the
    new chat. (#8029) Thanks @lefarcen.
  • A continued conversation collapses an unanswered question without pretending
    it was answered. (#8158)
  • A planning-stage refusal that still gave you a useful reply keeps the normal
    Done state instead of showing a failed-run card; genuine production failures
    still surface as failures. (#8322) Thanks @itscheems.

🎨 Studio, previews and export

  • Preview snapshots retain real page content, and delayed file reads cannot
    replace the preview you are actively using. (#7125, #8067) Thanks
    @huynextlevel.
  • Valid thinking-stream cards render as cards; invalid ones remain safely out
    of the conversation. (#8258, #8264) Thanks @lefarcen.

🌍 Localization

  • French copy is complete across the Design System flow, Library and Memory.
    (#7906, #7756) Thanks @davezfr.

🖥️ Desktop

  • Fresh Windows installations complete the local desktop handoff and can load
    the app normally. (#7520) Thanks @lorenzozanee.

🙏 Thanks to everyone who shipped 0.24.0

@AmyShang-alt · @arccat-114 · @davezfr · @huynextlevel · @itscheems · @jax-novita · @johnkattenhorn · @lefarcen · @lorenzozanee · @maoxin1234 · @nettee · @Siri-Ray · @tony-box
