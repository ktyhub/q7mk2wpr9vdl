Hervorgehobene Änderungen

AnythingLLM Desktop Assistant ist live!

Jetzt ist AnythingLLM Desktop ein direkter Ersatz für kostenpflichtige Tools wie Granola, Otter, Fireflies und mehr.

  • Läuft vollständig auf Ihrem Gerät, kann Besprechungen aufzeichnen, ohne beizutreten, oder beliebige Dateien zusammenfassen
  • Unterstützt durch NVIDIA Parakeet + AnythingLLMs On-Device-Orchastration
  • Kann jedes Agententool, MCP oder alles andere aufrufen, das Sie bereits mit AnythingLLM verwenden!
  • Benutzerdefinierte Zusammenfassungsvorlagen, Chat mit dem Transkript und sogar Sprecheridentifizierung.
  • Desktop-Benachrichtigung „Teilgenommener Besprechung“, um eine neue Aufzeichnung mit einem click zu starten. Für jede Meeting-Software (Zoom, Slack, Discord, Teams usw.)
  • Keine Ratenbegrenzungen, Nutzungsobergrenzen oder Einschränkungen https://github.com/user-attachments/assets/355ad2fc-cca1-4e9d-8f08-4a1a08dac48d

AnythingLLM Mobile ist live bei Google Play

Die [Android AnythingLLM Mobile App] (https://play.google.com/store/apps/details?id=com.anythingllm) ist jetzt bei Google Play verfügbar. Dies wird sowohl mit der Cloud-/selbstgehosteten als auch mit der Desktop-Version von AnythingLLM synchronisiert. https://github.com/user-attachments/assets/e4232dfa-e42e-4d15-af9e-d58f2f0245f9

Bemerkenswerte weitere Änderungen

  • Onboarding-Seite „Arbeitsbereich erstellen“ entfernt -> geht jetzt direkt zur Startseite mit neuem Arbeitsbereich in der Muttersprache des Benutzers
  • Workspace-Dateiauswahl überarbeitet, um leistungsfähiger zu sein – Migration von Azure OpenAI zum einheitlichen v1 api mit vollständiger Agentenunterstützung
  • Paginierungsfehler in paperless-ngx behoben – Problem behoben, bei dem der undokumentierte YouTube API verändert wurde und der YT-Scraper kaputt ging
  • Cohere als Agentenanbieter implementiert
  • Eine Reihe von Abhängigkeitsstörungen
  • Fehler behoben, bei dem XSLX-Dateien, die per Drag-and-Drop in den Chat gezogen wurden, für das Modell nicht „sichtbar“ waren – MCP-Korrekturen für Pfade auf Nicht-Windows-Maschinen
  • Docker Bildunebenheiten und -flecken für einen gesunden Scout-Score (B) – Fehlergrenze zur Benutzeroberfläche hinzugefügt, um Abstürze bei Whitepages zu verhindern

anything-llm v1.10.0

Highlights

  • On-device Desktop Assistant — AnythingLLM Desktop now positions itself as a local, no-cap alternative to Granola/Otter/Fireflies: it records and summarizes meetings entirely on-device using NVIDIA Parakeet plus AnythingLLM's own orchestration, and — critically for adopters — it can invoke your existing agent tools and MCP servers rather than producing siloed notes. Adds custom summary templates, transcript chat, speaker identification, and a "Joined Meeting" desktop notification that starts recording across Zoom/Slack/Discord/Teams. Why it matters: transcription and summarization stay inside your environment with no rate limits or usage caps, which removes the data-residency blocker that kept many teams from adopting hosted meeting bots.
  • First-party Android client — The mobile app is now live on Google Play and syncs with both Cloud/self-hosted and Desktop instances. Signals that mobile is a supported surface rather than a community wrapper; worth confirming your self-hosted instance's API reachability and auth before rolling it out to field users.
  • Azure OpenAI moves to the unified v1 API — PR #4744 migrates Azure OpenAI to the v1 API with full agent support and streaming for reasoning models. This is a real migration point for Azure shops: re-verify deployments/model names and streaming configuration after upgrading, since the integration path changes rather than just gaining a feature.
  • Agent providers and connectors get meaningful fixes — Cohere lands as an agent provider (#4703) and AWS Bedrock agents gain streaming support (#4850), alongside an AWS-credential fix for Docker (#4842). On ingestion, XLSX files dropped into chat are finally "visible" to the model by combining sheets (#4847), the YouTube scraper was repaired after an undocumented upstream API change (#4820), paperless-ngx pagination was corrected (#4757), and Ollama embedding requests can now carry an auth token (#4766). Watch for changed behavior in these connectors rather than assuming pure bugfix parity.
  • Under-the-hood migrations to smoke-test — A notable wave of dependency and internal shifts: bcrypt → bcryptjs (#4767) with bcrypt removed from the collector (#4747), Multer 2.0.0 (#4768), Express 4.21.2 (#4760), MCP SDK 1.24.3 (#4773), Docker base to Ubuntu 24 (#4754), and a VectorDB class migration (#4787). Multiple ESM import patches (#4819, #4867) and a lazy-loaded LanceDB (#4764) round it out. Custom plugins, scripts, and Docker-based deployments should be regression-tested against these changes.
  • Reliability and onboarding polish — A global Error Boundary (#4765) prevents full white-page crashes, stale-user-permission and session fixes (#4751, #4770) harden auth state, and chat input now gets validation (#4811). The onboarding "Create workspace" page is removed (#4823) so new users land straight on the home screen with a workspace in their native language, while the workspace file picker was refactored for performance (#4740). Lower-risk changes, but they improve first-run experience and reduce support tickets.

Highlighted Changes

AnythingLLM Desktop Assistant is live!

Now, AnythingLLM Desktop is a drop-in replacement for paid tools like Granola, Otter, Fireflies, and more.

  • Runs entirely on your device, can record meetings without joining or summarize arbitrary files
  • Powered by NVIDIA Parakeet + AnythingLLM's on-device orchastration
  • Can call any agent tool, MCP, or anything else you already use with AnythingLLM!
  • Custom summary templates, chat with the transcript, and even speaker identification.
  • "Joined Meeting" Desktop notification to start a new recording with a click. For any meeting software (Zoom, Slack, Discord, Teams, etc)
  • No rate limits, usage caps, or restrictions

https://github.com/user-attachments/assets/355ad2fc-cca1-4e9d-8f08-4a1a08dac48d

AnythingLLM Mobile is live on Google Play

The Android AnythingLLM Mobile App is live on Google Play now. This syncs with both Cloud/Self-hosted and Desktop versions of AnythingLLM.

Notable other changes

  • Removed onboarding "Create workspace" page -> goes straight to home now with new workspace in user native language
  • Refactored Workspace file picker to be more performant
  • Migrated Azure OpenAI to unified v1 api with full agent support
  • Fixed Pagination bug in paperless-ngx
  • Fixed issue where the undocumented YouTube API changed and broke the YT scraper
  • Implemented Cohere as an agent provider
  • A bump of dependency bumps
  • Fixed bug where XSLX files dragged and dropped into chat weren't "visible" to the model
  • MCP fixes for paths on non-Windows machines
  • Docker image bumps and patches for a healthy Scout score (B)
  • Added Error Boundary to UI to prevent white-page crashes
