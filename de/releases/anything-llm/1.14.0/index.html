anything-llm v1.14.0

Highlights

  • Agent tool calling flips to opt-out — BREAKING behavior change — PR #5783 makes all model providers call tools by default; agents that previously worked without tool calling will now invoke tools unless you explicitly opt out. This is the headline change: agent users get better performance out of the box, but anyone who depended on tools being off must now configure the opt-out before upgrading (#5716 also fixes a related provider-override/context-limit detection issue).
  • Embeds now deny-by-default — BREAKING, needs migration — PR #5759 makes embeds with no allowlist opt-in/denied by default. If you run public or embedded chat widgets without an allowlist, they will stop working until you add one — set an allowlist before upgrading. This is a security hardening change, not a silent no-op.
  • Default chat thread is retired on new-thread creation — PR #5739 kills the default thread when you create a new thread; existing chats on it remain accessible, but new workspaces or workspaces with no chats there no longer show it. Minor UX behavior shift — harmless for most, relevant only if you relied on the default thread as a persistent scratchpad.
  • New providers and speech support — Adds Cerebras as an LLM provider (#5699), server-side STT via OpenAI (#5596, plus Deepgram, GenericOAI, Lemonade), KokoroTTS for TTS (#5679), and GenericOAI improvements (#5746). Worth upgrading specifically if you want these integrations; otherwise this alone is not a reason to move.
  • Content pipeline and reliability improvements — Scraped HTML now converts to Markdown for lower-context, better research chats (#5742); the agent summary tool is overhauled with transparency and a prompt before long summaries (#5719); better LaTeX (#5779), 24-hour SystemVariables formats (#5778), and a configurable document-sync stale-after interval (#5747). Solid bug fixes round it out — SEARXNG double-encoding (#5723), universal fetch timeouts (#5721), stripping XML-illegal characters from generated docs (#5760), and Windows uninstall/tray fixes. Broader users benefit most here; this is a substantive release, not a re-tag or metadata-only bump.

Improvements

  • [x] Cerebres provider
  • [x] The default chat thread is now killed when you create a new thread. If you have chats on the default thread, it will be available still. New workspaces or workspaces with no chats on default will no longer show it.
  • [x] All model providers are now opt-out of tool calling by default. Everything will call tools by default unless you opt-out offering better performance for agents everywhere
  • [x] STT Support for Deepgram, GenericOAI, Lemonade, & OpenAI
  • [x] TTS Support for KokoroTTS
  • [x] Web-scraping now will convert to markdown for better parsing and chat followup tasks with minimal context bloat
  • [x] Summary tool was overhauled. Now it will so better summaries with transparency as well as ask before continuing for longer summaries
  • [x] Improvements to the GenericOAI provider
  • [x] 24hour system variable formats
  • [x] Better LaTex rendering support

Bug Fixes

  • [x] Context limit detection issue for agents: https://github.com/Mintplex-Labs/anything-llm/pull/5716
  • [x] SEARXNG double encoding: https://github.com/Mintplex-Labs/anything-llm/pull/5723
  • [x] Timeouts for all fetch requests https://github.com/Mintplex-Labs/anything-llm/pull/5721
  • [x] Escape illegal XML in word docs, etc https://github.com/Mintplex-Labs/anything-llm/pull/5760
  • [x] (Windows) On unisntall, checkbox to remove all AnythingLLM data is now present
  • [x] Tray Fixes when app starts in background or Desktop Assistant feature is toggled.
