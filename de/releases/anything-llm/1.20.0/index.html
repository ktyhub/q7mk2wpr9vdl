#irgendetwas-llm v1.20.0

Aktualisierte Browsererweiterung

Die Browsererweiterung wurde über ihre ursprüngliche Funktion, nur Dokumente zu sammeln, hinaus verbessert und ist jetzt eine vollwertige UI-Chatleiste mit der Möglichkeit, rechts click -> Kontext (Text und Bild) hinzuzufügen und direkt in Chrome zu chatten. Diese Seitenleiste sollte hinsichtlich der Tools und mehr weitgehend mit der herkömmlichen Chat-Benutzeroberfläche identisch sein. Obwohl es abwärts- und aufwärtskompatibel ist, wird die volle Funktionalität nur erwartet, wenn der Server und die Erweiterung die Version 1.20.0 oder höher haben. Der Chrome-Webstore wurde ebenfalls auf diese Version aktualisiert. https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

Überarbeitung des PowerPoint-Tools

<img width="1990" height="1099" alt="pptx-generation" src="https://github.com/user-attachments/assets/05689972-1296-4869-b208-dd9301222dd3" /> Das PowerPoint-Tool des Agenten wurde von Grund auf neu entwickelt, um übersichtlichere und besser aussehende Präsentationen zu erstellen. - **Themen und Layouts:** Decks verwenden neue Farbthemen und eine Reihe von Layouts, die so ausgewählt werden, dass sie zum Inhalt jeder Folie passen, sodass das gleiche Layout nicht Folie für Folie wiederholt wird. - **Live-Folienvorschau:** Folien werden im Chat angezeigt, während sie erstellt werden, sodass Sie zusehen können, wie der Stapel zusammenkommt. Cli Klicken Sie auf eine Vorschau, um es in voller Größe zu sehen. - **Fundierte Inhalte:** Zahlen, Diagrammwerte und Zitate werden nur dann beibehalten, wenn Ihre Gliederung, Recherche oder Konversation sie enthält und der Text so dimensioniert ist, dass er auf jede Folie passt. ### E-Mail-Genehmigungskarten für Gmail und Outlook <img width="1990" height="1099" alt="email-drafting" src="https://github.com/user-attachments/assets/0b571869-c43b-454f-bdf1-0e2e3d4b4beb" /> Wenn ein Agent eine E-Mail mit den Tools [Gmail](https://docs.anythingllm.com/agent/usage/gmail-agent) oder [Outlook](https://docs.anythingllm.com/agent/usage/outlook-agent) senden oder entwerfen möchte, wird die Genehmigungsanfrage jetzt als E-Mail-Karte angezeigt. Sie können die Empfänger, Cc, Bcc, Betreff und Text direkt in der Karte bearbeiten, bevor Sie sie genehmigen. Der Genehmigungstimer pausiert, während Sie die E-Mail bearbeiten, und Sie können eine gesendete E-Mail erweitern, um genau zu sehen, was herausgekommen ist. ### MCP-Verbesserungen - **Identitätsweiterleitung:** MCP-Server können jetzt den Arbeitsbereich und den Benutzer empfangen, der sie aufruft. Melden Sie sich pro Server mit `anythingllm.forwardIdentity` an. anything-llm v1.20.0

Updated browser extension

The browser extension has been improved beyond its original function of just collecting documents to now a full fledged UI chat bar with the ability to right click -> Add context (text and image) and chat directly in Chrome. This sidebar should have mostly full parity for tooling and more with the traditional chat UI.

While it is backward and forward compatible, only full functionality is expected when the server and extension are on version 1.20.0 or later. The Chrome webstore has been updated to this version as well.

https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

PowerPoint tool overhaul

<img width="1990" height="1099" alt="pptx-generation" src="https://github.com/user-attachments/assets/05689972-1296-4869-b208-dd9301222dd3" />

The agent's PowerPoint tool has been rebuilt from the ground up to produce cleaner, better looking presentations.

  • Themes and layouts: decks use new color themes and a set of layouts that are picked to fit each slide's content, so the same layout is not repeated slide after slide.
  • Live slide previews: slides appear in the chat as they are built, so you can watch the deck come together. Click a preview to see it full size.
  • Grounded content: figures, chart values and quotes are only kept when your outline, research or conversation contains them, and text is sized to fit each slide.

Email approval cards for Gmail and Outlook

<img width="1990" height="1099" alt="email-drafting" src="https://github.com/user-attachments/assets/0b571869-c43b-454f-bdf1-0e2e3d4b4beb" />

When an agent wants to send or draft an email with the Gmail or Outlook tools, the approval request is now shown as an email card. You can edit the recipients, Cc, Bcc, subject and body right in the card before you approve it. The approval timer pauses while you edit, and you can expand a sent email to see exactly what went out.

MCP improvements

  • Identity forwarding: MCP servers can now receive the workspace and user that is calling them. Opt in per server with anythingllm.forwardIdentity. See Forwarding identity to MCP servers.
  • Per-server timeouts: set anythingllm.timeout (in seconds) on an MCP server to control how long its tool calls can run. The default is 60 seconds.
  • Developer API: new /v1/mcp-servers endpoints let you list, add, update, delete, start, stop and reload MCP servers, and turn individual tools on or off.
  • MCP servers with many tools now load every page of tools, starting one server also picks up any newly saved servers, and disconnected servers can be deleted.
