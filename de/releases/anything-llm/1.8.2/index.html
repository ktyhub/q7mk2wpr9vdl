anything-llm v1.8.2

Highlights

  • Mid-chat model swapping & prompt history — You can now switch model or provider without leaving the conversation via Cmd/Ctrl+Shift+L, which opens a swap tooltip (#3969); a chat prompt-history menu (#3770) and locally stored system-prompt revisions let you jump back to earlier prompts. This makes prompt tuning a reversible, in-session workflow: A/B the same workspace prompt across providers without losing context. Watch model-map staleness/fallback behavior after a swap (#3971), since cached model capabilities are now refreshed.

  • AWS Bedrock refactor — The provider was rewritten for multi-modal inputs and corrected token limits (#3714), with IAM-role authentication added (#2632). Bedrock users should re-check chunk and context sizing: corrected token limits can change how documents are split and how much context fits, and IAM roles introduce a new credential path that can replace static keys.

  • Vector store & connector expansion — pgvector is now a supported vector database backend (#3788), joined by new connectors for Obsidian (#3798), GitLab wiki fetching (#3271), and a Dell Pro AI Studio provider (#3829), plus Drupal connector fixes (#3878, #3893). This broadens self-hosting storage choices — pgvector is notable for teams already on PostgreSQL — and adds several enterprise data sources.

  • Agent flows gain API parity & composability — The API-call block now supports PUT/PATCH (#3937), a JSON parser block was added (#3863), flows support direct output (#3873), and flows can be imported from the community hub (#3867). apiChatHandler now includes agent chats (#3905), and the inputVariable requirement on LLM Instruction blocks was removed (#3954) — simpler authoring, but re-test existing flows that assumed that field was mandatory.

  • Smarter context & reliability fixes — Automatic context-window detection (#3817) now handles invalid probe responses gracefully (#3896), alongside an MCP environment-inheritance fix (#3909), disabled message send while content is embedding (#3832), filtering of malformed post-processed docs from the file picker (#3853), and a redesigned embedded chat widget (#3899). These cut configuration guesswork and embedding-related races; the widget redesign may require CSS review if you've customized embeds.

  • Breaking changes — None in this release.
