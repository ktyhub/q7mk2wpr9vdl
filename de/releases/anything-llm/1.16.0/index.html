#irgendetwas-llm v1.16.0

Bemerkenswerte Änderungen

Bildgenerierung

Jetzt können Sie Bilder über /img generieren, wenn ein unterstützter Anbieter eingerichtet ist.

Dieser Ablauf ermöglicht auch Bildanhänge für Bearbeitungen, Nachverfolgungen oder Kombinationsaufforderungen, wenn Ihr Anbieter die Bildbearbeitung unterstützt.

<img width="2254" height="986" alt="image" src="https://github.com/user-attachments/assets/9286ba43-c8fe-43f9-a18d-6c2814f6907f" />

Die Möglichkeit eines Agenten-Tools zum Generieren von Bildern folgt im nächsten Update.

Bessere Dateiauswahl-UX

Jetzt können Sie in der Dateiauswahl ganze Ordner ziehen und ihre Hierarchie bleibt im Upload-Bereich erhalten. Dadurch werden nur die Dateien der obersten Ebene im Ordner importiert – sie werden in einem späteren Update tiefgreifend und rekursiv sein.

Sie können eine Datei jetzt auch direkt per Drag & Drop in einen vorhandenen Ordner ziehen, ohne sie verschieben zu müssen.

Schließlich müssen Sie https nicht mehr in den URL-Abrufer eingeben – er nimmt einfach https an, wenn er weggelassen wird.

Wir haben auch einige große Leistungsverbesserungen vorgenommen, wie z. B. das verzögerte Laden von Ordnern für Benutzer mit Tausenden von Dokumenten in einem Ordner.

Tool „Mitten in der Sitzung umschalten“.

Jetzt können Sie während Agenten-Chats die Tools nach Belieben ein- und ausschalten, ohne dass Sie sie neu laden oder eine neue Sitzung starten müssen. Es sind nur Tools verfügbar, die konfiguriert wurden (sofern eine Konfiguration erforderlich ist).

Generierung stoppen

Eine große Verbesserung besteht nun darin, dass eine aborting-Antwort die Inferenz auch vollständig beendet, sodass die Ghost-Inferenz nicht fortgesetzt wird, wenn sie mitten im Stream nicht mehr gewünscht wird.

anything-llm v1.16.0

Highlights

  • Image generation arrives via /img — PR #5904 adds image generation when a supported provider is configured, with image attachments for edits/followups/combination prompts if that provider supports image editing. It's the headline feature but a practical no-op until you set up such a provider, and agent-tool-driven image generation is explicitly pushed to the next update.
  • Agent sessions become controllable mid-flight — PR #5856 lets you toggle tools on/off during a live agentic chat without reloading or starting a new session (only configured tools appear), and PR #6063/#5970 make Stop Generation abort inference end-to-end so "ghost inference" no longer runs after you stop. New create-scheduled-job agent tool (PR #5916) and You.com web search provider (PR #6058) broaden what agents can do — strong reason to upgrade if you run agentic chats.
  • File/data handling improves for large workspaces — PR #6027 preserves folder hierarchy when dragging folders into the document manager, though it imports only top-level files (recursive import deferred); you can drop files directly into an existing folder, the URL fetcher now assumes https when omitted, and lazy-loading helps with thousands of documents. New Gitea data connector (PR #6087) and GitHub Enterprise URL support in the GitHub connector (PR #6117) add ingest sources.
  • Breaking/behavioral changes to check before upgrading — Workspace profile picture support was removed (PR #6010), Workspace System Prompt Override is now gated in Workspace.new() (PR #5971), default fallback models for OpenAI/Anthropic changed (PR #5949), and workspace update payloads are now validated so malformed requests no longer return a misleading 200 (PR #6070); AWS Bedrock (PR #6081) and FoundryLocal (PR #6119) were "overhauled." No explicit migration steps are documented, so re-verify provider/model config if you depend on these areas.
  • Upgrade recommendation — This is a substantive minor release, not a re-tag or metadata-only change: most v1.15.0 users should upgrade for the agent controls, real stop-generation, image generation, and provider/connector fixes. You can reasonably skip if you rely on workspace profile pictures, the previous OpenAI/Anthropic fallback models, or none of the agent/image/connector features — the only real migration cost is rechecking config after the Bedrock, FoundryLocal, and fallback-model changes.

Notable Changes

Image Generation

Now you can generate images via /img when a supported provider is set up.

This flow also allows image attachments for edits, followups, or combination prompts if your provider supports image editing.

<img width="2254" height="986" alt="image" src="https://github.com/user-attachments/assets/9286ba43-c8fe-43f9-a18d-6c2814f6907f" />

Ability for an agent-tool to generate images is coming next update.

Better File Picker UX

Now in the file picker you can drag entire folders and their hierarchy will be preserved in the upload panel. This will only import the top level files in the folder — it will be deep and recursive in a later update.

You can also now drag and drop a file into an existing folder directly without needing to move it.

Lastly, you no longer need to type https in the URL fetcher - it will just assume https when left out.

We also made some large performance improvements, like lazy-loading of folders, for those with thousands of documents in a folder.

Tool Toggle Mid-Session

Now, during agentic chats you can freely toggle tools on/off at will without needing to reload or start a new session. Only tools that have been configured (if configuration is required) are available.

Stop Generation

A large improvement is now that aborting a response actually fully kills the inference as well so that ghost inference does not continue when no longer wanted mid-stream.
