#irgendetwas-llm v1.16.2

Neue Funktionen

– [x] LLMman – OSS ist jetzt als lokaler LLM-Anbieter verfügbar und ersetzt Docker Model Runner

  • [x] Google Vertex AI ist jetzt als LLM-Anbieter verfügbar
  • [x] Neuer generate-image-Agenten-Skill zum Erstellen von Bildern aus dem Chat
  • [x] You.com ist jetzt der Standard-Websuchanbieter für umfangreichere Websuchen mit Zero Data Retention – [x] Agentenflussvariablen unterstützen jetzt optionale Argumente
  • [x] Unterstützung für Hindi, Bulgarisch und Schwedisch hinzugefügt
  • [x] GenieX unter Windows auf ARM listet jetzt Modelle auf, die in Ihrem lokalen Modellverzeichnis gefunden wurden, und ermöglicht es Ihnen, Modelle direkt aus Hugging Face in der Benutzeroberfläche abzurufen
  • [x] Cli Klicken Sie auf das Versions-Tag oben im Fenster, um einfacher zu Ihren Protokollen und Ihrem Speicherverzeichnis zu springen

Verbesserungen

  • [x] Das Surfen im Internet ist jetzt standardmäßig für Agenten aktiviert
  • [x] Lokale Anbieter melden jetzt den Modellladestatus im Chat, sodass Sie wissen, warum die erste Antwort langsam ist
  • [x] Die Ollama-Laufzeit wurde mit einer aktualisierten gebündelten Modellliste auf 0.33.3 erhöht
  • [x] Für ein übersichtlicheres Desktop-Layout wurden die Ränder um den Hauptinhaltsbereich entfernt
  • [x] Das modale Layout „Neue Funktion“ wurde neu gestaltet
  • [x] Datumsangaben in Tabellen werden jetzt in einem für Menschen lesbaren Format angezeigt
  • [x] Scraped-Webseiten behalten jetzt Tabellen, geordnete Listen und Codeblöcke bei, anstatt sie zu reduzieren
  • [x] PDF-Seiten werden jetzt mit Zeilenumbrüchen verbunden, sodass Wörter nicht über Seitengrenzen hinweg verschmelzen
  • [x] Mistral-Einbettungen erfolgen jetzt stapelweise, was die Einbettung großer Dokumente erheblich beschleunigt
  • [x] Die Dokumentensuche findet Ihre Begriffe jetzt wörtlich statt als regulären Ausdruck
  • [x] Überwachte Dokumente löschen jetzt veraltete Vektoren bei der Synchronisierung
  • [x] AnySearch als Websuchanbieter
  • [x] Der KoboldCPP-Anbieter wurde überarbeitet und modernisiert, um ihn an den Rest unserer Anbieter anzupassen
  • [x] Keenable als Websuchanbieter hinzugefügt
  • [x] Auswahl der OpenRouter-Serviceebene zur Steuerung von Routing-Kosten und -Priorität
  • [x] LocalAI-Bildbearbeitung über Referenzbilder

anything-llm v1.16.2

New Features

  • [x] LLMman - OSS is now available as a local LLM provider, replacing Docker Model Runner
  • [x] Google Vertex AI is now available as an LLM provider
  • [x] New generate-image agent skill for creating images from chat
  • [x] You.com is now the default web search provider for richer web-searches with Zero Data Retention
  • [x] Agent flow variables now support optional arguments
  • [x] Hindi, Bulgarian, and Swedish language support added
  • [x] GenieX on Windows on ARM now lists models found in your local model directory and lets you pull models directly from Hugging Face in the UI
  • [x] Click the version tag in the top of the window to jump to your logs and storage directory more easily

Improvements

  • [x] Web browsing is now enabled by default for agents
  • [x] Local providers now report model loading status in chat so you know why the first response is slow
  • [x] Ollama runtime bumped to 0.33.3 with an updated bundled model list
  • [x] Removed the borders around the main content area for a cleaner desktop layout
  • [x] Redesigned the "new feature" modal layout
  • [x] Dates in tables are now shown in a human-readable format
  • [x] Scraped web pages now preserve tables, ordered lists, and code blocks instead of flattening them
  • [x] PDF pages are now joined with newlines so words don't fuse across page boundaries
  • [x] Mistral embeddings are now batched, making large document embedding significantly faster
  • [x] Document search now matches your terms literally instead of as a regular expression
  • [x] Watched documents now clear stale vectors on sync
  • [x] AnySearch as a web-search provider
  • [x] KoboldCPP provider overhauled and modernized to match the rest of our providers
  • [x] Keenable added as a web search provider
  • [x] OpenRouter service tier selection for controlling routing cost and priority
  • [x] LocalAI image editing via reference images
