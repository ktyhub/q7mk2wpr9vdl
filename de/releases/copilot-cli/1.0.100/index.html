Copilot-cli v1.0.100

19.10.2026 – Fügen Sie das Flag --disable-client-telemetry hinzu, um client-Telemetrie-Uploads vom CLI zu deaktivieren – Fügen Sie den Ordner „--trust“ für einmalige Sitzungen im Eingabeaufforderungsmodus hinzu, die mit „-p“ oder „stdin“ über Pipes gestartet werden

  • Installieren Sie verifizierte Skills und Plugins von GitHub-Installationslinks über die Copilot-Plugin-Installation „ghapp://air/install?...“ – Öffnen Sie /share ohne Argumente, um ein Vollbild-Aktionsmenü zum Teilen der aktuellen Sitzung anzuzeigen – Sandbox-Hostregelverkehr berücksichtigt jetzt HTTPS_PROXY und HTTP_PROXY, wenn kein Sandbox-Proxy konfiguriert ist
  • Beim Sprachdiktieren werden keine Sprachmarkierungen wie <en-US> mehr in den Transkripttext eingefügt – Verwaltete Plugins aktualisieren die Aktivierung in vorhandenen Sitzungen, wenn sich die verwalteten Richtlinien ändern – Sitzungen bleiben nicht mehr minutenlang stehen, wenn ein MCP-Server beim Laden von Tools hängt. – Gemini-Tool-Aufrufe schlagen nicht mehr fehl, wenn Array-Parameter Aufzählungswerte definieren – Gemini-Chats schlagen nicht mehr fehl, wenn frühere Tool-Ergebnisse keinen lesbaren Inhalt enthalten. – Sandboxed-Shell-Befehle erklären jetzt Fehler im Anmeldeinformations-Proxy-Zertifikat trust und können eine genehmigte Wiederholung außerhalb der Sandbox anbieten.
  • Behalten Sie gespeicherte /diff-Überprüfungskommentare bei, wenn Sie ein unverändertes Diff in derselben Sitzung erneut öffnen, mit einer expliziten Verwerfen-Aktion. – Aktionen zum Aktivieren, Deaktivieren, Aktualisieren und Deinstallieren von Plugins werden jetzt zuverlässig weitergeleitet, nachdem der Plugin-Bestand aktualisiert wurde. – Antworten, die nur auf Begründungsmaximierung basieren, durchlaufen nicht länger eine Endlosschleife und enden jetzt mit einem eindeutigen Fehler, wenn kein Fortschritt erzielt wird
  • Zeigen Sie eine deutliche Warnung an und halten Sie die Anzeige des aktiven Modells synchron, wenn ein gespeichertes Modell beim Fortsetzen automatisch ersetzt wird. – Sandbox-Befehle unter Linux werden zuverlässiger gestartet, ohne dass es zu zeitweiligen Fehlern bei der Loopback-Einrichtung kommt
  • Zurück von MCP-Ressourcendetails bleiben während Live-Metadatenaktualisierungen in der Liste
  • Native Chats können gestartet und beendet werden, während optionale verwaltete Plugin-Downloads im Hintergrund fortgesetzt werden.
  • Doppelte Strg+C-Taste wird sofort beendet, auch wenn die CLI-Benutzeroberfläche beschäftigt ist – Katalogsuche meldet Proxy-Authentifizierungsanforderungen für CONNECT-Proxy-Herausforderungen
  • HydraFusion behält einen Pass erweitert bei, während die Überprüfung läuft. Pässe, die nicht aufbewahrt wurden, bleiben erweiterbar, bis Sie die Sitzung wechseln oder fortfahren, und Pässe aus einer abgebrochenen Runde geben an, ob sie beibehalten wurden
  • Warnungen zu Richtlinien für verwaltete Konten und zum Umgehungsmodus bleiben auch nach dem Kontowechsel korrekt, selbst wenn ein Richtlinien-Cache-Fehler auftritt. – Vermeiden Sie falsche Kontextausschöpfung und Rollover-Verweigerung, wenn Werkzeugdefinitionen zurückgestellt werden – Benutzerdefinierte Agents, die die dokumentierten Tool-Aliase search, web oder todo deklarieren oder github-mcp-server/web_search nennen, erhalten jetzt die passenden Tools
  • CLI-Hilfe und Versionsflags werden nach dem Drucken ihrer Ausgabe zuverlässig beendet – Vom Unternehmen verwaltete Abfrageberechtigungen im unterstützten Modus ermöglichen jetzt sichere Aktionen ohne unnötige Bestätigungsaufforderungen.
  • Lassen Sie Ihr ausgewähltes Microsoft Entra-Konto während der Anmeldung und Token-Erneuerung angeheftet
  • Von den Kopfzeilenaktionen in der Seitenleiste der Sitzungen werden bis zur letzten sichtbaren Sitzung umgebrochen
  • Plan-, Autopilot- und Shell-Modus-Badges bleiben sichtbar, während Startkomponenten geladen werden und der Agent arbeitet. Das Abzeichen ersetzt das Modussuffix, das früher dem Aktivitätstext folgte (Working - plan), und die Startzeile Loading: kürzt jetzt ihre Diagnosen, um die Statuszeile in einer Zeile zu belassen – Sandbox-Befehle können Pakete schreiben und Caches erstellen, wenn der Zugriff auf das Entwicklertool aktiviert ist. – Windows CLI Git-Befehle werden jetzt nach Startfehlern mit verweigertem Thread-Zugriff wiederhergestellt. – Eine Skill-allowed-tools-Regel behält Kommas in ihren Argumenten, anstatt sie aufzuteilen. Wenn die Struktur einer Liste mehrdeutig ist, werden die Regeln ohne Bereichseinschränkung jetzt aufgefordert, statt gewährt zu werden. – Das MCP-Ressourcen-Dashboard bleibt interaktiv, während die Inventaradapter aktualisiert werden
  • Wiederholen Sie bildtragende Antwortanfragen mit kleineren Nutzlastgrenzen, wenn Anbieter übergroße Körper ablehnen – In der vollständigen Nutzungsberichterstattung werden nach der Wiederaufnahme, wenn die Rechnungsdaten vollständig sind, nicht mehr der Teilstatus oder Phantomausgaben angezeigt, die nicht zugeordnet werden können. – Unterstützte Berechtigungen senden verschachtelte PowerShell- und bash -c-Befehle, die nur Klardaten-Umgebungsvariablen, PowerShell in einfachen Anführungszeichen sowie PowerShell-Variablen- und Alias-Anweisungen erweitern, an den Berechtigungsrichter, anstatt eine unnötige manuelle Genehmigung zu erfordern – Pfadspezifische Anweisungsdateien im Repository-Stammverzeichnis .github/instructions werden jetzt automatisch angewendet, wenn der Agent eine passende Datei liest oder bearbeitet – Starten Sie Git, Shell-Befehle und MCP-Server unter Windows, wenn die Thread-Aufzählung des Prozess-Snapshots fehlschlägt – Verwenden Sie standardmäßig den einheitlichen Sitzungsbrowser für /sessions, /session und /resume. – Das Durchsuchen von Sitzungen begrenzt die Kontoerkennung jetzt auf 500 Datensätze und berücksichtigt Retry-After-Hinweise für den automatischen Aktualisierungszeitpunkt. – Aufforderung zur Aktualisierung der Sandbox-Proxy-Zertifizierungsstelle, wenn sich maskierte Hosts ändern – Zeigen Sie einen deutlichen Hinweis an, wenn vom Administrator verwaltete Einstellungen Ihr ausgewähltes Modell überschreiben
  • Aktivieren Sie standardmäßig die Suche nach semantischem Code für Online-Sitzungen. – Verbessern Sie /login für Microsoft Entra, indem Sie ein zwischengespeichertes Konto auswählen oder sich explizit mit einem anderen Konto anmelden können – Sandbox-Git auf github.com kann Ihr konfiguriertes GITHUB_TOKEN aus credentials.envVars verwenden – /sandbox kann Sandboxing für die aktuelle Sitzung aktiviert lassen, ohne es global zu aktivieren
  • Trusted-Repository-Plugins werden automatisch installiert und aktualisiert, bevor der Chat ausgeführt wird. – Benennen Sie das integrierte Browser-Plugin in „browser-use“ um und behalten Sie die bestehenden Browser-Plugin-Einstellungen nach dem Upgrade bei – Sandbox ermöglicht standardmäßig den lokalen Netzwerkzugriff, sodass Befehle lokale Host- und private Netzwerkdienste erreichen können.

copilot-cli v1.0.100

2026-10-19

  • Add --disable-client-telemetry flag to turn off client telemetry uploads from the CLI
  • Add --trust-folder for one-off prompt-mode sessions started with -p or piped stdin
  • Install verified Skills and plugins from GitHub install links via copilot plugin install "ghapp://air/install?..."
  • Open /share without arguments to view a full-screen action menu for sharing the current session
  • Sandbox host-rule traffic now honors HTTPS_PROXY and HTTP_PROXY when no sandbox proxy is configured
  • Voice dictation no longer inserts language markers like <en-US> into transcript text
  • Managed plugins update activation in existing sessions when managed policy changes
  • Sessions no longer stall for minutes when an MCP server hangs while loading tools.
  • Gemini tool calls no longer fail when array parameters define enum values
  • Gemini chats no longer fail after earlier tool results contain no readable content.
  • Sandboxed shell commands now explain credential-proxy certificate trust failures and can offer an approved rerun outside the sandbox.
  • Keep saved /diff review comments when reopening an unchanged diff in the same session, with an explicit discard action.
  • Plugin enable, disable, update, and uninstall actions now route reliably after plugin inventory refreshes.
  • Reasoning-only max-token responses no longer loop indefinitely and now end with a clear error when no progress is made
  • Show a clear warning and keep the active model display in sync when a saved model is automatically replaced on resume.
  • Sandboxed commands on Linux start more reliably without intermittent loopback setup failures
  • Back from MCP resource details stays on the list during live metadata refreshes
  • Native chats can start and finish while optional managed plugin downloads continue in the background.
  • Double Ctrl+C exits immediately even when the CLI UI is busy
  • Catalog search reports proxy authentication requirements for CONNECT proxy challenges
  • HydraFusion keeps a pass expanded while its review runs, passes that were not kept stay expandable until you switch sessions or resume, and passes from an aborted turn say whether they were kept
  • Managed account policy and bypass-mode warnings stay accurate after switching accounts, even when a policy cache miss happens.
  • Avoid false context exhaustion and rollover refusal when tool definitions are deferred
  • Custom agents that declare the documented search, web or todo tool aliases, or name github-mcp-server/web_search, now receive the matching tools
  • CLI help and version flags exit reliably after printing their output
  • Enterprise-managed ask permissions in Assisted mode now allow safe actions without unnecessary confirmation prompts.
  • Keep your selected Microsoft Entra account pinned during sign-in and token renewal
  • Up from sessions sidebar header actions wraps to the last visible session
  • Plan, autopilot, and shell mode badges stay visible while startup components load and the agent works. The badge replaces the mode suffix that used to trail the activity text (Working - plan), and the startup Loading: row now truncates its diagnostics to keep the status row on one line
  • Sandboxed commands can write package and build caches when developer tool access is enabled.
  • Windows CLI Git commands now recover from thread-access-denied startup failures.
  • A skill allowed-tools rule keeps commas inside its arguments instead of being split apart. Where a list's structure is ambiguous, its unscoped rules now prompt instead of being granted.
  • MCP resource dashboard stays interactive while inventory adapters refresh
  • Retry image-bearing Responses requests with smaller payload limits when providers reject oversized bodies
  • Complete usage reporting no longer shows partial status or phantom unattributed spend after resume when billing data is complete.
  • Assisted permissions send nested PowerShell and bash -c commands that only expand plain-data environment variables, single-quoted PowerShell, and PowerShell variable and alias statements to the permission judge instead of requiring unnecessary manual approval
  • Path-specific instruction files in the repository root .github/instructions are now applied automatically when the agent reads or edits a matching file
  • Start git, shell commands, and MCP servers on Windows when process snapshot thread enumeration fails
  • Use the unified Sessions browser by default for /sessions, /session, and /resume.
  • Session browsing now caps account discovery at 500 records and respects Retry-After hints for automatic refresh timing.
  • Prompt to update the sandbox proxy certificate authority when masked hosts change
  • Show a clear notice when administrator-managed settings override your selected model
  • Enable semantic code search by default for online sessions.
  • Improve /login for Microsoft Entra by letting you choose a cached account or explicitly sign in with a different account
  • Sandboxed git on github.com can use your configured GITHUB_TOKEN from credentials.envVars
  • /sandbox can keep sandboxing enabled for the current session without enabling it globally
  • Trusted repository plugins install and update automatically before chat runs.
  • Rename the built-in browser plugin to browser-use and keep existing browser plugin preferences working after upgrade
  • Sandbox allows local network access by default so commands can reach localhost and private-network services.
