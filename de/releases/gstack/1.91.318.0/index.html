gstack v1.91.318.0

gstack v1.91.318.0 (regular release)

76 versions since v1.91.242.0, one line each. Compare or read the full changelog.

Team-mode installs follow the stable branch, which now points here; gstack-config set update_channel main follows every merge instead (docs/releases.md).

  • 1.91.317.0 (2026-10-29): In OpenClaw, Hermes and other agent tools, each registered gstack skill opens with when to use it, and OpenClaw lists the main task skills (review, investigate, qa, ship, plan-eng-review) directly. (#3555)
  • 1.91.316.0 (2026-10-29): /ship takes a token cap (--token-cap) and stops cleanly when it reaches it, and long runs hand heavy steps to fresh subagents. (#3593)
  • 1.91.315.0 (2026-10-29): After a stacked PR's parent merges and the child is retargeted to main, the child keeps its /ship review as long as its own changes are unchanged. (#3572)
  • 1.91.314.0 (2026-10-29): When a later /autoplan approval question asks nothing new, gstack reuses the owner's earlier answer instead of asking again. (#3583)
  • 1.91.313.0 (2026-10-29): The PII scanner stops flagging two kinds of ordinary text: a bare power-of-two or hash constant in code, and a package@version-style filename. (#3578)
  • 1.91.312.0 (2026-10-29): An install check run from inside /ship no longer upgrades gstack under it. (#3573)
  • 1.91.311.0 (2026-10-29): A sealed-files policy can block sealed/<set>/tasks.json while allowing the MANIFEST.json next to it, and can match HELDOUT/ regardless of case. (#3556)
  • 1.91.308.0 (2026-10-29): gstack's version renumbering no longer cuts a four-part package.json version to three parts in a repository that uses four. (#3557)
  • 1.91.307.0 (2026-10-29): /ship's review depth now matches what the diff can break: light, standard or full. (#3567)
  • 1.91.306.0 (2026-10-29): /ship's review record now survives a base merge that only regenerates generated files, and a rebase onto the code it reviewed. (#3564)
  • 1.91.305.0 (2026-10-29): You can now render gstack with whole skills, skill sections, model overlays or preamble pieces left out, as a byte-exact tree with a lock file, so an eval can measure which instructions a model actually needs. (#3554)
  • 1.91.304.0 (2026-10-29): Running the Capy installer for a second workflow on the same machine no longer revokes the first workflow's install check. (#3563)
  • 1.91.303.0 (2026-10-29): gstack-pr-shots no longer edits your .gitignore in the middle of /ship, which made /ship's checks go stale and its final record fail to write. (#3562)
  • 1.91.298.0 (2026-10-28): Support for the Dia browser is removed: gstack no longer imports cookies from it. (#3551)
  • 1.91.297.0 (2026-10-28): The terminal agent on Windows no longer waits on PowerShell to learn its own start time, so it boots in about a second and a slow PowerShell can no longer leave it without an identity. (#3545)
  • 1.91.295.0 (2026-10-28): Deleting or renaming a test no longer makes /ship's test check fail with no test to run. (#3534)
  • 1.91.294.0 (2026-10-28): gstack-doctor and setup's hook check start far fewer processes, which makes them much faster on Windows. (#3540)
  • 1.91.293.0 (2026-10-28): gstack-harness errors print again, and register qm says plainly that QM cannot import gstack yet. (#3532)
  • 1.91.292.0 (2026-10-28): A fix for a regression on the stable channel can skip the 72-hour wait, like a security fix. (#3533)
