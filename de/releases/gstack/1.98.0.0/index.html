gstack v1.98.0.0

gstack v1.98.0.0

Neuinstallationen folgen nun der getesteten stabilen Version, zwei wenig genutzte Fähigkeiten werden eingestellt und mehrere lokale Dienste und die Remote-Kopplung des Browsers werden gesperrt.

Was ist neu?

  • Ein neues git clone plus ./setup folgt jetzt dem stabilen Kanal, sodass neue Benutzer die getestete Version anstelle jeder Änderung auf dem Hauptkanal erhalten; Vorhandene Installationen und Mitwirkenden-Checkouts folgen weiterhin „main“, und das Setup gibt den Befehl zum Wechseln aus. Auf Capy aktualisiert sich gstack jetzt mindestens einmal am Tag auf die neueste Hauptversion, es sei denn, Sie pinnen es mit einem Grund #4091 an.
  • /autoplan verfügt über ein Opt-in-Gate (./setup --autoplan-gate oder gstack-config set autoplan_gate on), das verhindert, dass die Sitzung beendet wird, bis jede Planungsphase ihren Bericht veröffentlicht hat und der letzte Genehmigungsschritt geschrieben ist #4100.
  • /plan-eng-review ist nicht mehr installiert, da zwei Evaluierungen ergeben haben, dass es gegenüber dem einfachen Opus 5.5 nichts hinzugefügt hat; /autoplan führt immer noch seine technische Überprüfungsphase durch, und der nächste ./setup entfernt den alten Eintrag, lässt aber einen Skill, den Sie unter diesem Namen geschrieben haben, allein #4108.
  • /investigate wird nicht mehr installiert, nachdem eine Evaluierung von 18 echten Fehlerbehebungen keinen Nutzen daraus ergeben hat; Der nächste ./setup entfernt den alten Eintrag auf die gleiche Weise #4110.

Korrekturen

– Unter Capy aktualisiert eine Gstack-Installationsüberprüfung, die mitten in einem offenen /ship oder Review ausgeführt wird, den darunter liegenden Gstack nicht mehr, und der Upgrade-Pfad funktioniert jetzt ohne die flock-Binärdatei #4095. – Das /plan-ceo-review-Gate beurteilt eine Sitzung nicht mehr, bevor Claude Code das Schreiben seines Transkripts abgeschlossen hat, sodass eine abgeschlossene Überprüfung nicht mehr versehentlich festgehalten wird #4102. – Die Prüfung, die die Sitzung eines Skills anhält, bis die erforderlichen Schritte abgeschlossen sind, wartet jetzt auch darauf, dass Claude Code das Schreiben des Transkripts beendet, sodass ein abgeschlossener Lauf nicht mehr versehentlich blockiert wird #4104. – Die Wartevorgänge von gstack auf Pull-Anfragen überprüfen GitHub jetzt höchstens einmal pro Minute und warten auf Ratenlimits, sodass das gemeinsame GitHub-API-Kontingent nicht mehr ausgeschöpft wird #4109. – /ship behandelt jetzt als Lit- oder HTM-Vorlagen in einer .ts- oder .js-Datei geschriebene Benutzeroberflächen als Frontend, sodass diese Änderungen die Designprüfung erhalten, anstatt sie stillschweigend zu überspringen #4112.

  • /autoplan erkennt jetzt die gleiche Lit- und HTM-Vorlagen-Benutzeroberfläche und Wörter wie Zeile, Auswahl und Menü, sodass diese Pläne eine Entwurfsphase erhalten und eine schnelle Ausführung nicht mehr besagt, dass eine übersprungene Entwurfsphase zusammengeführt wurde #4121.
  • /make-pdf liest lokale Bilder nur aus dem eigenen Ordner des Dokuments und nur echte Bilddateien; Alles andere wird als sichtbarer „Bild blockiert“-Platzhalter gerendert #4113. – Über den /pair-agent-Tunnel kann ein Remote-Agent jetzt nur Webseiten öffnen: Er kann keine lokalen Dateien lesen, keinen Pfad auf Ihrer Festplatte auswählen oder den Browser veranlassen, dort Screenshots zu speichern #4116. – Die Designboard- und iOS-QA-Hintergrunddienste beantworten jetzt nur lokale Anfragen, die direkt an sie gerichtet werden, und Designboard-Links enthalten jetzt ein privates Geheimnis in der URL #4117. – /setup-gbrain übergibt Ihre gbrain-Datenbank-URL, die ihr Passwort enthält, nicht mehr in der Befehlszeile, wo andere lokale Benutzer sie sehen könnten, und die Schwärzungsprüfung von gstack erfasst jetzt mehr Arten von Anmeldeinformationen #4114. – Das Capy-Installationsprogramm lädt nicht mehr bunfig.toml oder .env Ihres Projekts, während es die Bun- und Node-Versionen des Projekts liest #4115.

Änderungen für Betreuer

  • Die Überprüfungsbuchhaltung von /ship hat mehrere Korrekturen erhalten: Folgeüberprüfungen und vom Eigentümer gewährte zusätzliche Runden werden jetzt korrekt gezählt, Versions- und Dokumentbearbeitungen nach einer Überprüfung erzwingen nicht mehr eine weitere Runde, ein abgelehnter Überprüfungsdatensatz gibt jetzt an, von welchem Commit er stammt, und ein Prüferbefund, der mit „Ergebnis 1“ geöffnet wird, behält seinen eigenen Schweregrad #4089 #4093 #4096 #4099 #4101 #4106. – Ein /ship-Lauf, der an einen neuen Thread übergeben wird, behält ein Ausgabenbudget bei, und ein durch die Fernprüfung gelöschtes CI-Ergebnis erfüllt jetzt den lokalen Testschritt von /ship für genau diesen Baum #4088 #4098. – Testvorrichtungen lassen /ship nicht länger denken, dass ein Prüfer aus dem Netzwerk geholt wurde, und die Update-Channel-Tests können nicht mehr die echte Gstack-Konfiguration eines Entwicklers schreiben #4105 #4094. – Agent-Thread-Pull-Anfragen zeigen jetzt, ob sie ihren Planungsschritt hatten, und ein Repo kann dies vor der Zusammenführung verlangen #4118. – Drei /ship-Tooling-Fehler wurden behoben: Der Versand der Überprüfung des zweiten Modells stimmt mit dem Überprüfungsplan überein, und die Ergebnisse der Prüfung vor dem Zusammenführen überdauern auch eine reine Testwiederholung und einen verschobenen Basiszweig #4124. – Die Dots und generischen Harness-Ziele registrieren das zurückgezogene /plan-eng-review nicht mehr und seine alten bezahlten Testfälle haben jeweils ein aufgezeichnetes Schicksal #4111. gstack v1.98.0.0

gstack v1.98.0.0

New installs now follow the tested stable release, two little-used skills are retired, and several local services and the browser's remote pairing are locked down.

What's new

  • A fresh git clone plus ./setup now follows the stable channel, so new users get the tested release instead of every change on main; existing installs and contributor checkouts keep following main, and setup prints the command to switch. On Capy, gstack now updates itself to the latest main at least once a day unless you pin it with a reason #4091.
  • /autoplan has an opt-in gate (./setup --autoplan-gate, or gstack-config set autoplan_gate on) that keeps the session from ending until every planning phase has published its report and the final approval step is written #4100.
  • /plan-eng-review is no longer installed, because two evals found it added nothing over plain Opus 5.5; /autoplan still runs its engineering review phase, and the next ./setup removes the old entry but leaves a skill you wrote under that name alone #4108.
  • /investigate is no longer installed, after an eval on 18 real bug fixes found no gain from it; the next ./setup removes the old entry the same way #4110.

Fixes

  • On Capy, a gstack install check that runs in the middle of an open /ship or review no longer upgrades gstack underneath it, and the upgrade path now works without the flock binary #4095.
  • The /plan-ceo-review gate no longer judges a session before Claude Code has finished writing its transcript, so a finished review is no longer held by mistake #4102.
  • The check that holds a skill's session until its required steps are done now also waits for Claude Code to finish writing the transcript, so a finished run is no longer blocked by mistake #4104.
  • gstack's waits on pull requests now check GitHub at most once a minute and wait out rate limits, so they stop using up the shared GitHub API quota #4109.
  • /ship now treats UI written as Lit or htm templates inside a .ts or .js file as frontend, so those changes get the design check instead of skipping it silently #4112.
  • /autoplan now recognizes the same Lit and htm template UI and words like row, picker and menu, so those plans get a Design phase, and a quick run no longer says it merged a Design phase it skipped #4121.
  • /make-pdf reads local images only from the document's own folder and only real image files; anything else renders as a visible "image blocked" placeholder #4113.
  • Over the /pair-agent tunnel, a remote agent can now only open web pages: it can't read local files, pick a path on your disk, or make the browser save screenshots there #4116.
  • The design board and iOS QA background services now answer only local requests made directly to them, and design board links now include a private secret in the URL #4117.
  • /setup-gbrain no longer passes your gbrain database URL, which holds its password, on the command line where other local users could see it, and gstack's redaction check now catches more kinds of credentials #4114.
  • The Capy installer no longer loads your project's bunfig.toml or .env while it reads the project's Bun and Node versions #4115.

Changes for maintainers

  • /ship's review bookkeeping got several fixes: follow-up reviews and owner-granted extra rounds now count correctly, version and docs edits after a review no longer force another round, a refused review record now says which commit it came from, and a reviewer finding that opens with "Finding 1" keeps its own severity #4089 #4093 #4096 #4099 #4101 #4106.
  • A /ship run handed to a new thread keeps one spending budget, and a CI result cleared by the remote check now satisfies /ship's local test step for that exact tree #4088 #4098.
  • Test fixtures no longer make /ship think a reviewer fetched from the network, and the update-channel tests can no longer write a developer's real gstack config #4105 #4094.
  • Agent-thread pull requests now show whether they had their planning step, and a repo can require it before merge #4118.
  • Three /ship tooling bugs are fixed: the second-model review dispatch matches the review plan, and pre-merge check results survive a test-only rerun and a moved base branch #4124.
  • The dots and generic harness targets no longer register the retired /plan-eng-review, and its old paid test cases each have a recorded fate #4111.
