gstack v1.91.242.0 (weekly release)

First tagged release: the 96 versions since v1.91.146.0 (the week before it), one line each; the full changelog has every earlier one.

Team-mode installs follow the stable branch, which now points here; gstack-config set update_channel main follows every merge instead (docs/releases.md).
