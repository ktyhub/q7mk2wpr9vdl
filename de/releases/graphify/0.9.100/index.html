graphify v0.9.100

0.9.100 (01.11.2026)

  • Fix: IDs eines Typs und einer Funktion, deren Namen sich nur in der Groß-/Kleinschreibung unterscheiden (Foo die Klasse, foo die Funktion), erhalten unterschiedliche Knoten-IDs, anstatt zu kollidieren (was einen Knoten fallen ließ und eine falsche Selbstschleife erzeugte) (#4904, #4908, danke @bercedev).
  • Fix: php ein Scope::MEMBER-Zugriff in einem Initialisierer auf Klassenebene (ein konstanter Wert, ein Eigenschaftsstandard oder ein Parameter/hochgestufter Konstruktor-Standard) gibt eine references_constant-Kante aus; self::/static::/parent:: werden übersprungen und unbekannte Bereiche prägen keinen Stub (#4648, #4895, danke @Jitendarmahara). – Fix: Hooks git rev-parse-Ausgabe wird als UTF-8 dekodiert, sodass ein verknüpfter Arbeitsbaum unter einem Nicht-ASCII-Pfad unter Windows korrekt aufgelöst wird statt unter Mojibake (#4903, danke @LukeTheoJohnson).
  • Fix: Analysieren in einem Nur-Code-Diagramm. Der Grund für die isolierte Knotenfrage lautet „möglicherweise fehlende Kanten“, anstatt auf Dokumentationslücken zu verweisen, die nicht zutreffen können (#4887, danke @oleksii-tumanov).
  • Leistung: Referenzkanten auflösen werden einmal nach Quelle indiziert, sodass die JS/TS-Importauflösung nicht mehr jede Kante pro Import erneut durchläuft (Ausgabe unverändert) (#4909, #4913, danke @Deepjyoti-Sarmah).
  • Dokumente: Skill Der Skill sagt jetzt über alle generierten Hosts hinweg, wann es sich lohnt, ein Diagramm zu erstellen, wobei die Invariante „Wenn der Benutzer /graphify aufgerufen hat, tun Sie es wie gewünscht“ beibehalten wird (#4829, #4906, danke @TanmayShah29).
  • Fix: benötigt die zusätzlichen video-Kapiteln für PyAV unter 19 (av>=11,<19), da PyAV 19 das metadata_errors-Argument entfernt hat, das beim Öffnen von Audio bedingungslos durch Faster-Whisper geht; Ohne die Obergrenze konnte eine Neuinstallation auf Python 3.12+ nicht transkribiert werden (#4842, danke @SyedFahad7).
  • Fix: r setClass/setRefClass S4/R5-Vererbung, die mit contains= deklariert wurde, gibt jetzt eine Vererbungskante aus (zuvor wurde nur inherit= von R6Class erkannt) (#4902, danke @ayushcodes10).
  • Fix: elixir ein bloßer Funktionsaufruf wird vor anderen Modulen in eine Funktion im eigenen Modul des Aufrufers aufgelöst, anstatt an die zuletzt durchgegangene gleichnamige Definition zu binden (#4900, danke @ayushcodes10).
  • Fix: Dart eine Mixin-on A, B-Klausel löst jede Oberklassenbeschränkung auf, nicht nur die erste (#4899, danke @ayushcodes10).
  • Fix: Fortran extends(base) eines abgeleiteten Typs gibt eine erbliche Kante aus, wodurch Fortran mit den anderen OOP-Extraktoren in Einklang gebracht wird (#4897, danke @ayushcodes10). – Fix: Scala ein extension (x: T) def m ist auf seinen Empfängertyp T beschränkt (eine method-Kante zu T), anstatt in den Dateibereich zu gelangen (#2044, #4856, danke @divakantpandey). – Fix: Terraform ein Knoten behält seinen ursprünglichen Geltungsbereich bei, sodass IDs stabil bleiben, wenn ein zwischengespeichertes Projektverzeichnis verschoben wird, anstatt den Geltungsbereich erneut vom neuen Pfad abzuleiten (#4858, #4861, danke @yUm1k4).
  • Fix: Extrahieren (JVM) Java- und Kotlin-Importe, extends/implements und Member-Aufrufe werden datei- und sprachübergreifend aufgelöst, wenn ein geschriebener FQN genau einen Quelltyp benennt (#4874, #4879, danke @Deepjyoti-Sarmah).
  • Fix: Beim Exportieren eines Pfad-/Explain-/Wiki-Renderings werden alle parallelen Beziehungen zwischen zwei Knoten aufgelistet (über edge_datas), und ein roher --no-cluster-Schreibvorgang markiert den Graphen multigraph, sodass parallele Kanten das erneute Laden überstehen (#4794, danke @ensell-yes).
  • Fix: Export einer teilweisen oder fehlgeschlagenen Sicherung wird als keine Sicherung gemeldet und beim nächsten Durchlauf erneut versucht, anstatt als falscher Erfolg aufgezeichnet zu werden (#3769, #4834, danke @barlowa124).
  • Fix: betroffen graphify affected (und query --seed) lösen die gleichen path::Symbol- und gepunkteten Referenzformen auf, die explain akzeptiert, verwenden den Resolver von EXPLAIN wieder und beenden einen Wert ungleich Null (3 mehrdeutig / 4 nicht gefunden) bei einem Startwert, der nicht aufgelöst wird (#4792, #4797, danke @dupeisen).
  • Fix: install graphify uninstall entfernt den User-Scope-Skill jeder Plattform (13 blieben zurück) und den globalen Befehl Kilo; und graphify kilo uninstall entfernt den references/-Sidecar des Kilo-Skills (#4782, #4789, danke @bercedev).
  • Feat: llm das Claude-Backend speichert seine (stabile, große) Systemeingabeaufforderung mit cache_control zwischen, zählt die zwischengespeicherten Token zurück in input_tokens und GRAPHIFY_CLAUDE_PROMPT_CACHE=0 deaktiviert es für Gateways, die cache_control ablehnen (#4835, #4855, #4880, danke @Jvxoq und @1akashkalita).
  • Fix: Eingabeaufforderung Die Node-ID-Formatbeschreibung in der Extraktionsaufforderung stimmt mit dem überein, was ids.py tatsächlich erzeugt (Wortzeichen bleiben erhalten, Nicht-ASCII-Buchstaben/Ziffern bleiben erhalten, ASCII-Kleinbuchstaben) anstelle der veralteten Formulierung „nur [a-z0-9_]“ (#4432, #4799, danke @dupeisen).
  • Dokumente: So funktioniert es Die Anzahl der unterstützten Sprachen wird aktualisiert (ca. 40: 33 Baumsitter-Grammatiken plus 7 integrierte Parser) und in Durchgang 3 wird beschrieben, dass das konfigurierte LLM-Backend ausgeführt wird, nicht nur Claude (#4873, danke @SyedFahad7).

Englisches Original / English original

graphify v0.9.100

0.9.100 (2026-11-01)

  • Fix: ids a type and a function whose names differ only in case (Foo the class, foo the function) get distinct node ids instead of colliding (which dropped one node and minted a bogus self-loop) (#4904, #4908, thanks @bercedev).
  • Fix: php a Scope::MEMBER access in a class-level initializer (a const value, a property default, or a parameter/promoted-constructor default) emits a references_constant edge; self::/static::/parent:: are skipped and unknown scopes mint no stub (#4648, #4895, thanks @Jitendarmahara).
  • Fix: hooks git rev-parse output is decoded as UTF-8, so a linked worktree under a non-ASCII path resolves correctly on Windows instead of mojibake (#4903, thanks @LukeTheoJohnson).
  • Fix: analyze on a code-only graph the isolated-node question reason says "possible missing edges" rather than referencing documentation gaps that cannot apply (#4887, thanks @oleksii-tumanov).
  • Perf: resolve reference edges are indexed by source once, so JS/TS import resolution no longer re-walks every edge per import (output unchanged) (#4909, #4913, thanks @Deepjyoti-Sarmah).
  • Docs: skill the skill now says when a graph is worth building, across all generated hosts, while preserving the "if the user invoked /graphify, do it as asked" invariant (#4829, #4906, thanks @TanmayShah29).
  • Fix: deps the video extra caps PyAV below 19 (av>=11,<19), because PyAV 19 removed the metadata_errors argument that faster-whisper passes unconditionally when opening audio; without the cap a fresh install on Python 3.12+ failed to transcribe (#4842, thanks @SyedFahad7).
  • Fix: r setClass/setRefClass S4/R5 inheritance declared with contains= now emits an inherits edge (previously only R6Class's inherit= was recognised) (#4902, thanks @ayushcodes10).
  • Fix: elixir a bare function call resolves to a function in the caller's own module before other modules, instead of binding to the last-walked same-named definition (#4900, thanks @ayushcodes10).
  • Fix: dart a mixin on A, B clause resolves every superclass constraint, not just the first (#4899, thanks @ayushcodes10).
  • Fix: fortran a derived type's extends(base) emits an inherits edge, bringing Fortran in line with the other OOP extractors (#4897, thanks @ayushcodes10).
  • Fix: scala an extension (x: T) def m is scoped to its receiver type T (a method edge to T) instead of leaking to file scope (#2044, #4856, thanks @divakantpandey).
  • Fix: terraform a node carries its original scope so ids stay stable when a cached project directory is moved, instead of re-deriving the scope from the new path (#4858, #4861, thanks @yUm1k4).
  • Fix: extract (JVM) Java and Kotlin imports, extends/implements and member calls resolve across files and across the two languages when a written FQN names exactly one sourced type (#4874, #4879, thanks @Deepjyoti-Sarmah).
  • Fix: export a path/explain/wiki rendering lists every parallel relation between two nodes (via edge_datas), and a raw --no-cluster write marks the graph multigraph so parallel edges survive reload (#4794, thanks @ensell-yes).
  • Fix: export a partial or failed backup is reported as no backup and retried on the next run, instead of being recorded as a false success (#3769, #4834, thanks @barlowa124).
  • Fix: affected graphify affected (and query --seed) resolve the same path::Symbol and dotted reference forms explain accepts, reusing explain's resolver, and exit non-zero (3 ambiguous / 4 not-found) on a seed that does not resolve (#4792, #4797, thanks @dupeisen).
  • Fix: install graphify uninstall removes every platform's user-scope skill (13 were left behind) and the kilo global command; and graphify kilo uninstall removes the kilo skill's references/ sidecar (#4782, #4789, thanks @bercedev).
  • Feat: llm the Claude backend caches its (stable, large) system prompt with cache_control, counting the cached tokens back into input_tokens, and GRAPHIFY_CLAUDE_PROMPT_CACHE=0 disables it for gateways that reject cache_control (#4835, #4855, #4880, thanks @Jvxoq and @1akashkalita).
  • Fix: prompt the node-id format description in the extraction prompt matches what ids.py actually produces (word characters kept, non-ASCII letters/digits preserved, ASCII lowercased) instead of the stale "[a-z0-9_] only" wording (#4432, #4799, thanks @dupeisen).
  • Docs: how-it-works the supported-language count is updated (about 40: 33 tree-sitter grammars plus 7 built-in parsers) and Pass 3 is described as running the configured LLM backend, not Claude only (#4873, thanks @SyedFahad7).
