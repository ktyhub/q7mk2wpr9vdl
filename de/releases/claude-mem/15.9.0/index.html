claude-mem v15.9.0

Was ist neu?

Devin-Unterstützung. npx claude-mem install kann jetzt Devin CLI und Devin Desktop einrichten: Hooks werden für Sie geschrieben, Devins Tool-Namen werden verstanden und die Speichersuchtools werden registriert. (#5172, #5276 von @patrickballard und @ssthormess) Meine Arbeit wird zu Ihren Bedingungen aktualisiert. Meine Arbeit und mein früherer Fokus verfügen über die Schaltfläche „Jetzt aktualisieren“ (#5249 von @Kirat0201). Neue Einstellungen wählen das Aktualisierungsmodell pro Anbieter: CLAUDE_MEM_WORK_VIEW_CLAUDE_MODEL, CLAUDE_MEM_WORK_VIEW_CODEX_MODEL und CLAUDE_MEM_WORK_VIEW_GEMINI_MODEL (#5236 von @LucianVane). Remote-Mitarbeiter. Neue CLAUDE_MEM_WORKER_URL-Einstellung. Ein ungültiger Wert schlägt mit einem eindeutigen Fehler fehl, anstatt einen Fehler zu machen, und jeder Worker, der sich nicht auf Ihrem eigenen Computer befindet, muss https verwenden. (#5285 von @Kirat0201)

Datenschutz und Sicherheit

  • Durch das Deaktivieren der Fehlerberichterstattung wird nun auch verhindert, dass bereits auf der Festplatte gespeicherte Fehler gesendet werden. (#5272 von @thedotmack) – Weitere Geheimnisse werden geschwärzt, bevor sie gespeichert werden: Slack- und Discord-Webhook-URLs, Stripe-Webhook-Geheimnisse, PyPI, SendGrid, DigitalOcean, Shopify, Docker Hub und GitLab-Tokens, Basisanmeldeinformationen nach Autorisierungsheadern und CLI-Flags wie --auth-token und --client-secret. (#5277, #5207, #5204, #5224, #5222, #5197 von @kevin9327; #5205 von @parveen0029) – Andere Websites, die auf localhost ausgeführt werden, können keine Schreibvorgänge mehr über die Work-State-, Dedup-, Corpus- und Advisor-Routen an den Worker senden. (#5200 von @DeryFerd)
  • Das Backup der Kimi-Konfiguration ist jetzt nur für Sie lesbar. (#5290 von @patrickballard)

Korrekturen, die Ihnen möglicherweise auffallen

Speicher und Suche

  • Durch den Wechsel des Beobachteranbieters mitten im Gespräch werden keine Beobachtungen mehr dupliziert. (#5227 von @liuyinchu)
  • Wiederholte Rundenzusammenfassungen stapeln sich nicht mehr. (#5228 von @Dev-0710) – Der Transkriptbeobachter verliert nicht länger eine Sitzungsendezusammenfassung, die er nicht in die Warteschlange stellen konnte. (#5246 von @liuyinchu)
  • Dateisuchen stimmen mit der Schreibweise der Pfadtrennzeichen überein: src/a.ts oder src\a.ts. (#5214 von @rudycelekli) – Alle Ziffern-Suchwerte dateStart und dateEnd werden als Epochen-Millisekunden gelesen. (#5234 von @vinirib)
  • Beim Neustart des Workers während eines Chroma-Neuaufbaus werden fertige Dokumente nicht mehr erneut eingebettet. (#5238 von @vinirib)
  • Für zusammengeführte Projekte erstellte Korpora behalten die übernommenen Speicher und bei einem fehlgeschlagenen Neuaufbau geht der gespeicherte Korpus nicht mehr verloren. (#5235 von @liuyinchu; #5291 von @rudycelekli) – Beobachtungen mit einem vereinzelten schließenden Tag am Typ werden weiterhin gelesen und Batches überleben Überprüfungssperren. (#5221 von @Montinou; #5252 von @Kirat0201)
  • Die Kontextaktualisierung behält selbst geschriebene Markierungsbeispiele bei und die CLAUDE.md-Generierung überprüft doppelte Pfadsegmente nur ab dem Projektordner. (#5203 von @rudycelekli; #5232 von @vinirib) Meine Arbeit und Betrachter – Rezensionen, die ein paar Zeichen über einem Grenzwert liegen, schlagen nicht mehr während der gesamten Aktualisierung fehl und übergroße Rezensionen werden nach einem erneuten Versuch wiederhergestellt. (#5230 von @juelpb; #5286 von @Kirat0201) – „Meine Arbeit“ verlangsamt andere Worker-Anfragen in großen Datenbanken nicht mehr und beim Speichern von Regeln oder Fokus wird die Ansicht einmal statt zweimal neu erstellt. (#5284 von @Kirat0201; #5239 von @LucianVane)
  • Viewer-Filter halten Fallvariantensitzungen in Projektfiltern und ausgewählten Kategorien auf Null. (#5213, #5215 von @rudycelekli) Verlauf und Token-Nutzung importieren
  • Claude-Transkripte mit Leerzeichen in ihrem JSON werden nicht mehr übersprungen. (#5289 von @rudycelekli) – Codex- und Gemini-Eingabeaufforderungen werden nicht mehr zweimal importiert, und die Nutzung älterer Gemini wird bei migrierten Kopien nicht mehr zweimal gezählt. (#5292, #5217, #5295 von @rudycelekli) – Die Token-Nutzung bleibt teilweise bestehen und schlägt nicht fehl, wenn eine Transkriptquelle nicht gelesen werden kann. (#5294 von @rudycelekli) Anbieter und Konten – Worker-Recycles werden nicht mehr als Authentifizierungsfehler gemeldet. (#5278 von @2023Anita)
  • macOS: Der Worker versucht den Anmeldeschlüsselbund direkt erneut und bietet eine bessere Diagnose, wenn die Suche nach Anmeldeinformationen fehlschlägt. Dies behebt möglicherweise nicht jeden Fall in #5250. (#5258 von @Kirat0201)
  • OpenRouter: Endpunkte, die eine Argumentation erfordern, verlieren den Batch nicht mehr; Die Anfrage wird ohne die Einstellung einmal erneut gesendet. (#5267 von @markjoin123) – Ein abgelehnter Überschreitungszeitraum einer zugestellten Anfrage wird nicht mehr als Ablehnung behandelt. (#5223 von @beckman55) Installieren und CLI
  • npx claude-mem adopt --help und npx claude-mem cleanup --help drucken jetzt Hilfe. Vorher führten sie den Befehl aus. Noch nicht behoben: Der claude-mem-Launcher auf Ihrem PATH führt sie weiterhin aus. Verwenden Sie daher npx, um ihre Hilfe zu lesen. (#5288 von @WhitePepperLambSoup)
  • macOS 27: Ein Launcher, der das Betriebssystem zerstört hat, wird neu erstellt, anstatt als fremd zu bleiben. (#5253 von @REI-330)
  • Windows: Der Launcher installiert kurze Wiederholungsdateisperren und claude.exe von npm wird anstelle des SH-Shims verwendet. (#5256 von @HoneyTyagii; #5198 von @balabommablock-cpu)
  • Codex: CODEX_HOME wird respektiert und die zitierten TOML-Einstellungen werden korrekt aktualisiert. (#5216, #5212 von @rudycelekli)
  • T3-Code: Standard-Claude- und Codex-Anbieter werden gefunden, auch wenn T3 sie nie gespeichert hat. (#5283 von @balabommablock-cpu) – OpenCode: Erwartete Setup-Aufrufe, die nur auf die Registrierung beschränkt sind, warnen nicht mehr. (#5264 von @Bl0ck154)
  • Hermes: Der zwischengespeicherte Projektschlüssel für einen Checkout läuft jetzt ab, kann also nicht veralten. (#5287 von @DeryFerd)
  • claude-md:regenerate liest die Datenbank von CLAUDE_MEM_DATA_DIR. (#5210 von @Bortlesboat)

Für Entwickler und gehostete Benutzer

– Servermodus-Hooks senden contentSessionId bei semantischer Injektion. (#5281 von @rich-murphey)

  • Die Token-Nutzung des Claude-Beobachters pro Runde wird jetzt protokolliert. (#5293 von @Kirat0201) – Claude Duet-Cloud-Sitzungen, die cmem.ai nicht erreichen können, werden auf den Claude-Mem-Connector verwiesen. (#5243 von @thedotmack)
  • CI- und Testverbesserungen. (#5201, #5202 von @DeryFerd; #5254, #5257 von @xunguangzlj-cloud)
  • Aktualisierungen der chinesischen README-Terminologie. (#5208 von @SaigyoujYuyuko)

Bei dieser Veröffentlichung handelt es sich größtenteils um Community-Arbeit. Danke an @rudycelekli, @Kirat0201, @kevin9327, @vinirib, @DeryFerd, @patrickballard, @liuyinchu, @LucianVane, @balabommablock-cpu, @xunguangzlj-cloud, @ssthormess, @rich-murphey, @2023Anita, @WhitePepperLambSoup, @markjoin123, @Bl0ck154, @HoneyTyagii, @REI-330, @Dev-0710, @parveen0029, @beckman55, @juelpb, @Montinou, @Bortlesboat und @SaigyoujYuyuko. claude-mem v15.9.0

What's new

Devin support. npx claude-mem install can now set up Devin CLI and Devin Desktop: hooks are written for you, Devin's tool names are understood, and the memory search tools are registered. (#5172, #5276 by @patrickballard and @ssthormess)

My Work refresh on your terms. My Work and Past Focus have a "Refresh now" button (#5249 by @Kirat0201). New settings choose the refresh model per provider: CLAUDE_MEM_WORK_VIEW_CLAUDE_MODEL, CLAUDE_MEM_WORK_VIEW_CODEX_MODEL and CLAUDE_MEM_WORK_VIEW_GEMINI_MODEL (#5236 by @LucianVane).

Remote workers. New CLAUDE_MEM_WORKER_URL setting. A bad value fails with a clear error instead of falling back, and any worker that isn't on your own machine must use https. (#5285 by @Kirat0201)

Privacy and security

  • Turning off error reporting now also stops errors already saved on disk from being sent. (#5272 by @thedotmack)
  • More secrets are redacted before they are stored: Slack and Discord webhook URLs, Stripe webhook secrets, PyPI, SendGrid, DigitalOcean, Shopify, Docker Hub and GitLab tokens, Basic credentials after Authorization headers, and CLI flags like --auth-token and --client-secret. (#5277, #5207, #5204, #5224, #5222, #5197 by @kevin9327; #5205 by @parveen0029)
  • Other websites running on localhost can no longer send writes to the worker through the work-state, dedup, corpus and advisor routes. (#5200 by @DeryFerd)
  • The Kimi config backup is now readable only by you. (#5290 by @patrickballard)

Fixes you may notice

Memory and search

  • Switching observer providers mid-conversation no longer duplicates observations. (#5227 by @liuyinchu)
  • Repeated turn summaries no longer pile up. (#5228 by @Dev-0710)
  • The transcript watcher no longer loses an end-of-session summary it could not queue. (#5246 by @liuyinchu)
  • File searches match whichever way the path separators are written, src/a.ts or src\a.ts. (#5214 by @rudycelekli)
  • All-digit dateStart and dateEnd search values are read as epoch milliseconds. (#5234 by @vinirib)
  • Restarting the worker during a Chroma rebuild no longer embeds finished documents again. (#5238 by @vinirib)
  • Corpora built for merged projects keep the adopted memories, and a failed rebuild no longer loses the saved corpus. (#5235 by @liuyinchu; #5291 by @rudycelekli)
  • Observations with a stray closing tag on the type are still read, and batches survive verification holds. (#5221 by @Montinou; #5252 by @Kirat0201)
  • Context refresh keeps marker examples you wrote yourself, and CLAUDE.md generation checks duplicate path segments only from the project folder down. (#5203 by @rudycelekli; #5232 by @vinirib)

My Work and viewer

  • Reviews a few characters over a limit no longer fail the whole refresh, and oversized reviews recover after one retry. (#5230 by @juelpb; #5286 by @Kirat0201)
  • My Work no longer slows other worker requests on large databases, and saving rules or focus rebuilds the view once instead of twice. (#5284 by @Kirat0201; #5239 by @LucianVane)
  • Viewer filters keep case-variant sessions in project filters and selected categories at zero count. (#5213, #5215 by @rudycelekli)

Importing history and token usage

  • Claude transcripts with whitespace in their JSON are no longer skipped. (#5289 by @rudycelekli)
  • Codex and Gemini prompts are no longer imported twice, and legacy Gemini usage is no longer counted twice across migrated copies. (#5292, #5217, #5295 by @rudycelekli)
  • Token usage stays partial instead of failing when one transcript source can't be read. (#5294 by @rudycelekli)

Providers and accounts

  • Worker recycles are no longer reported as authentication failures. (#5278 by @2023Anita)
  • macOS: the worker retries the login keychain directly and gives better diagnostics when a credential lookup fails. This may not fix every case in #5250. (#5258 by @Kirat0201)
  • OpenRouter: endpoints that require reasoning no longer lose the batch; the request is resent once without the setting. (#5267 by @markjoin123)
  • A rejected overage bucket on a request that was served is no longer treated as a refusal. (#5223 by @beckman55)

Install and CLI

  • npx claude-mem adopt --help and npx claude-mem cleanup --help now print help. Before, they ran the command. Not fixed yet: the claude-mem launcher on your PATH still runs them, so use npx to read their help. (#5288 by @WhitePepperLambSoup)
  • macOS 27: a launcher the OS killed is rebuilt instead of being kept as foreign. (#5253 by @REI-330)
  • Windows: launcher installs retry short file locks, and npm's claude.exe is used instead of the sh shim. (#5256 by @HoneyTyagii; #5198 by @balabommablock-cpu)
  • Codex: CODEX_HOME is respected, and quoted TOML settings are updated correctly. (#5216, #5212 by @rudycelekli)
  • T3 Code: default Claude and Codex providers are found even when T3 never saved them. (#5283 by @balabommablock-cpu)
  • OpenCode: expected registry-only setup calls no longer warn. (#5264 by @Bl0ck154)
  • Hermes: the cached project key for a checkout now expires, so it can't go stale. (#5287 by @DeryFerd)
  • claude-md:regenerate reads the database from CLAUDE_MEM_DATA_DIR. (#5210 by @Bortlesboat)

For developers and hosted users

  • Server-mode hooks send contentSessionId on semantic injection. (#5281 by @rich-murphey)
  • Claude observer per-turn token usage is now logged. (#5293 by @Kirat0201)
  • Claude Duet cloud sessions that can't reach cmem.ai are pointed at the Claude-Mem connector. (#5243 by @thedotmack)
  • CI and test improvements. (#5201, #5202 by @DeryFerd; #5254, #5257 by @xunguangzlj-cloud)
  • Chinese README terminology updates. (#5208 by @SaigyoujYuyuko)

Thank you

This release is mostly community work. Thanks to @rudycelekli, @Kirat0201, @kevin9327, @vinirib, @DeryFerd, @patrickballard, @liuyinchu, @LucianVane, @balabommablock-cpu, @xunguangzlj-cloud, @ssthormess, @rich-murphey, @2023Anita, @WhitePepperLambSoup, @markjoin123, @Bl0ck154, @HoneyTyagii, @REI-330, @Dev-0710, @parveen0029, @beckman55, @juelpb, @Montinou, @Bortlesboat and @SaigyoujYuyuko.
