Muse Spark Open

<img width="2400" height="1296" alt="image" src="https://github.com/user-attachments/assets/bf34ea27-0edf-4ded-ba6f-905b04096126" />

Muse Spark Open ist ein multimodales Expertenmodell von Meta, das Text, Bilder, Audio und Video als Eingabe verwendet und Text generiert. Es verfügt über insgesamt 816 B Parameter (42 B aktiv pro Token) und ein Kontextfenster von bis zu 1.048.576 Token, die von allen Modalitäten gemeinsam genutzt werden. Es ist für Agenten-Codierungsaufgaben wie die Bearbeitung mehrerer Dateien, das Debuggen und die Verwendung von Tools geschult. Checkpoints sind in den Formaten BF16 und NVFP4 verfügbar.

Ling 3.0

Ling 3.0 Flash ist ein hybrides Mixture-of-Experts-Sprachmodell von InclusionAI. Sein Decoder gruppiert fünf Kimi Delta Attention (KDA)-Schichten mit einer Multi-Head Latent Attention (MLA)-Schicht. Die MLA-Blöcke verwenden verschachtelte rotierende Einbettungen und ein kopfweises Ausgangsgatter, und die Feed-Forward-Blöcke kombinieren geroutete und gemeinsam genutzte Experten. Es wird in Transformers nativ als BailingHybridForCausalLM unterstützt, sodass es ohne trust_remote_code=True geladen wird.

Links: Dokumentation

  • [Modell] Native Ling 3.0 Flash-Unterstützung hinzufügen (#49446) von @icavan in #49446

Kolibri1

Kolibri 1 ist das Kombinations-Experten-Argumentationsmodell von Aleph Alpha mit Schwerpunkt auf Deutsch und Englisch. Jede seiner 50 Schichten leitet jedes Token mithilfe von Sigmoid-Routing an 6 von 384 Experten weiter und fügt einen gemeinsamen Experten hinzu. Vier Sliding-Window-Aufmerksamkeitsschichten wechseln sich mit einer Vollaufmerksamkeitsschicht ab, und RoPE wird nur in den Sliding-Window-Schichten angewendet.

Links: Dokumentation

  • Kolibri 1 (#49463) von @lucamotz in #49463 hinzufügen

MiniCPM-V 4.7

MiniCPM-V ist eine Reihe effizienter multimodaler großer Sprachmodelle, die von OpenBMB entwickelt wurden. Wie MiniCPM-V 4.6 kombiniert die MiniCPM-V 4.7-Architektur einen SigLIP-Vision-Encoder mit Fenster-Aufmerksamkeits-Merger mit einem Qwen3.5-Sprachmodell-Backbone und unterstützt sowohl 4x- als auch 16x-visuelle Downsampling-Modi.

Die wichtigste Ergänzung gegenüber 4.6 ist Canvas M-RoPE: Anstatt visuelle Token entlang einer einzelnen 1D-Sequenz zu nummerieren, legt das Modell jedes Bild auf einer 2D-Leinwand an und weist jedem visuellen Token eine (temporal, height, width)-Position zu, sodass Abschnitte desselben Bildes ihre räumliche Beziehung und Videobilder ihre zeitliche Reihenfolge behalten.

UnlimitedOcr

UnlimitedOcr ist ein einzelnes 3B-Parameter-OCR-Modell von Baidu mit einer standardmäßigen Kontextlänge von 32.768 Token. Es baut auf DeepSeek OCR auf und ersetzt alle Decoder-Aufmerksamkeitsebenen durch Reference Sliding Window Attention (R-SWA). Dadurch bleibt der KV-Cache während der Dekodierung konstant, sodass das Modell Dutzende Seiten in einem einzigen Vorwärtsdurchlauf transkribieren kann. Es unterstützt den „Gundam“-Modus (640 x 640-Kacheln mit dynamischem Zuschneiden) und den „Basis“-Modus (eine einzelne 1024 x 1024-Ansicht) und kann Regionserkennungen mit Begrenzungsrahmen ausgeben.

UltraBERT

UltraBERT ist eine Familie bidirektionaler Textencoder, die mit einer Kombination aus Maskierungsverhältnissen, Bereinigung und Destillation für Klassifizierungs- und Abrufaufgaben trainiert wurden. Die veröffentlichten Encoder unterstützen Sequenzen von bis zu 32.768 Token. Sie verwenden Rotationspositionseinbettungen, RMSNorm, SwiGLU-Feedforward-Schichten und abwechselnde lokale und globale Aufmerksamkeit (jede dritte Schicht ist global). Zu den Prüfpunkten gehören UltraBERT-150M und UltraBERT-380M für die Modellierung und Feinabstimmung maskierter Sprachen sowie UltraBERT-Embed-150M für Texteinbettungen.

Links: Dokumentation | Papier

MOSS-Transkribieren-Diarisieren

MOSS-Transcribe-Diarize 0.9B ist ein End-to-End-Audio-Verständnismodell für die Langform-Transkription mehrerer Sprecher, die Diarisierung von Sprechern und Zeitstempel. Es kombiniert einen Whisper-Encoder, einen 4×-Frame-Merge-Schritt, einen multimodalen Projektor und ein Qwen3-Sprachmodell. Es erzeugt eine gemeinsame Transkription und Diarisierung in einem einzigen Durchgang, wobei die Segmente als [start][S01]text[end] formatiert sind. Es unterstützt Langform-Audio durch Whisper-Window-Chunking im Prozessor, aufforderungsgesteuerte Transkription mit Hotword-Bias und mehr als 50 Sprachen.

🚨 Allgemeiner aktueller Hinweis, dass die Schlussfolgerung mit EP zu Geschwindigkeitsrückgängen führt; Wir arbeiten daran, das Problem so schnell wie möglich zu beheben! 🚨

Veraltete Prüfungen und Methoden wurden aus cache_utils.py entfernt (betroffen sind Modelle wie minimax_m3_vl und pi0), daher muss jeder Code, der diese veralteten Cache-Methoden noch aufruft, zum aktuellen Cache API wechseln.

Die minimale kernels-Version ist jetzt 0.17.2, was use_fallback=KernelizeFallback.ALL ermöglicht, sodass bei einem fehlgeschlagenen Kernel-Ladevorgang auf die ursprüngliche Implementierung zurückgegriffen wird, anstatt einen Fehler auszulösen. Aktualisieren Sie kernels auf 0.17.2 oder höher.

Ein neues SubConfigSpec zentralisiert die Initialisierung von Unterkonfigurationen, sodass Standard-Unterkonfigurationen aus Datenklassenfeldern erfasst werden, anstatt die Klasse zu instanziieren. Dies betrifft die Konfigurationsdienstprogramme und viele Modellkonfigurationen. Benutzerdefinierte oder vorhandene verschachtelte Konfigurationen müssen möglicherweise aktualisiert werden, um ihre Unterkonfigurationen über diesen Mechanismus zu deklarieren.

  • :rotating_light: SubConfigSpec für zentralisierte Init von Subconfigs (#48282) von @zucchini-nlp

Die LUKE- und mLUKE-Tokenizer behandeln jetzt spezielle Entity-Token wie <ent> als spezielle Token (nicht geteilt, berücksichtigt durch skip_special_tokens, normalisiert) und behalten beim Dekodieren den gleichen Abstand wie normale Vokabular-Token bei. Tokenisierungs- und Dekodierungsausgaben, die diese Tokens beinhalten, können daher von zuvor abweichen. Überprüfen Sie daher alle Codes oder gespeicherten Ausgaben, die vom alten Verhalten abhängen.

Exporteure

Transformers-Exporteure unterstützen jetzt die Quantisierung direkt während des Exports über Dynamo, ONNX, OpenVINO und ExecuTorch. Die neue einheitliche Quantisierung API integriert PT2E-, ONNX Runtime- und NNCF-Quantisierer und ermöglicht statische und dynamische Quantisierung sowie reine Gewichtungskomprimierung (INT8/INT4) mit konfigurierbaren Kalibrierungsworkflows. Dies erleichtert den Export optimierter Modelle für eine effiziente Inferenz über verschiedene Backends hinweg.

Weitere Informationen finden Sie in den Dokumenten: https://huggingface.co/docs/transformers/exporters_quantization

Release v5.20.0

New Model additions

Muse Spark Open

<img width="2400" height="1296" alt="image" src="https://github.com/user-attachments/assets/bf34ea27-0edf-4ded-ba6f-905b04096126" />

Muse Spark Open is a multimodal mixture-of-experts model from Meta that takes text, images, audio, and video as input and generates text. It has 816B total parameters (42B active per token) and a context window of up to 1,048,576 tokens shared across modalities. It is trained for agentic coding tasks such as multi-file editing, debugging, and tool use. Checkpoints are available in BF16 and NVFP4 formats.

Links: Documentation | Blog Post

  • Add Muse Spark Open (#49644) by @guarin in #49644

Ling 3.0

Ling 3.0 Flash is a hybrid Mixture-of-Experts language model from InclusionAI. Its decoder groups five Kimi Delta Attention (KDA) layers with one Multi-head Latent Attention (MLA) layer. The MLA blocks use interleaved rotary embeddings and a head-wise output gate, and the feed-forward blocks combine routed and shared experts. It is natively supported in Transformers as BailingHybridForCausalLM, so it loads without trust_remote_code=True.

Links: Documentation

  • [Model] Add native Ling 3.0 Flash support (#49446) by @icavan in #49446

Kolibri1

Kolibri 1 is Aleph Alpha's mixture-of-experts reasoning model, focused on German and English. Each of its 50 layers routes every token to 6 of 384 experts using sigmoid routing, and adds one shared expert. Four sliding-window attention layers alternate with one full-attention layer, and RoPE is applied only in the sliding-window layers.

Links: Documentation

  • Add Kolibri 1 (#49463) by @lucamotz in #49463

MiniCPM-V 4.7

MiniCPM-V is a series of efficient multimodal large language models developed by OpenBMB. Like MiniCPM-V 4.6, the MiniCPM-V 4.7 architecture pairs a SigLIP vision encoder that has a window-attention merger with a Qwen3.5 language model backbone, and supports both 4x and 16x visual downsampling modes.

The main addition over 4.6 is canvas M-RoPE: instead of numbering visual tokens along a single 1-D sequence, the model lays every image out on a 2-D canvas and assigns each visual token a (temporal, height, width) position, so slices of the same image keep their spatial relationship and video frames keep their temporal order.

  • Fix more stuff (#48979) by @zucchini-nlp in #48979

UnlimitedOcr

UnlimitedOcr is a single 3B-parameter OCR model from Baidu with a standard 32,768-token context length. It builds on DeepSeek OCR and replaces all decoder attention layers with Reference Sliding Window Attention (R-SWA). This keeps the KV cache constant during decoding, so the model can transcribe dozens of pages in a single forward pass. It supports "gundam" mode (640x640 tiles with dynamic cropping) and "base" mode (a single 1024x1024 view), and it can output region detections with bounding boxes.

Links: Documentation | Paper

  • Add Unlimited OCR (#46836) by @guarin in #46836

UltraBERT

UltraBERT is a family of bidirectional text encoders trained with a combination of masking ratios, pruning, and distillation for classification and retrieval tasks. The released encoders support sequences of up to 32,768 tokens. They use rotary position embeddings, RMSNorm, SwiGLU feed-forward layers, and alternating local and global attention (every third layer is global). Checkpoints include UltraBERT-150M and UltraBERT-380M for masked language modeling and fine-tuning, and UltraBERT-Embed-150M for text embeddings.

Links: Documentation | Paper

  • Integrate the UltraBERT architecture (#49596) by @tomaarsen in #49596

MOSS-Transcribe-Diarize

MOSS-Transcribe-Diarize 0.9B is an end-to-end audio understanding model for long-form multi-speaker transcription, speaker diarization, and timestamps. It combines a Whisper-style encoder, a 4× frame merge step, a multi-modal projector, and a Qwen3 language model. It produces joint transcription and diarization in a single pass, with segments formatted as [start][S01]text[end]. It supports long-form audio through Whisper-window chunking in the processor, promptable transcription with hotword biasing, and 50+ languages.

Links: Documentation

  • Add MOSS-Transcribe-Diarize model (#48386) by @itazap in #48386

Breaking changes

🚨 General breaking notice that inference with EP has regressions in speed; we are working on fixing this ASAP! 🚨

Deprecated checks and methods have been removed from cache_utils.py (affecting models such as minimax_m3_vl and pi0), so any code still calling those deprecated cache methods must switch to the current cache API.

  • 🚨 Remove deprecated cache utils methods (#49605) by @guarin

Accidental imports from other models were removed from several model files (e.g. embedding_gemma2, ijepa, lightglue), and the modular converter now avoids adding such cross-model imports. If you imported these names through those model modules, import them from their original modules instead.

  • 🚨 Remove imports from other models (#49473) by @guarin

The minimum kernels version is now 0.17.2, which allows use_fallback=KernelizeFallback.ALL so that a failed kernel load falls back to the original implementation instead of raising an error. Upgrade kernels to 0.17.2 or later.

  • 🚨 Bump min kernels to 0.17.2 for better fallback (#49235) by @SunMarc

A new SubConfigSpec centralizes the initialization of sub-configs, so default sub-configs are collected from dataclass fields instead of by instantiating the class, and this touches the configuration utilities and many model configs. Custom or existing nested configs may need to be updated to declare their sub-configs through this mechanism.

  • :rotating_light: SubConfigSpec for centralized init of subconfigs (#48282) by @zucchini-nlp

The LUKE and mLUKE tokenizers now treat entity special tokens such as <ent> as special tokens (not split, honored by skip_special_tokens, normalized) while keeping the same spacing as regular vocabulary tokens when decoding. Tokenization and decoding output involving these tokens may therefore differ from before, so check any code or saved outputs that depend on the old behavior.

  • 🚨🚨🚨 luke fixe (#48408) by @itazap

Exporters

Transformers exporters now support quantization directly during export across Dynamo, ONNX, OpenVINO, and ExecuTorch. The new unified quantization API integrates PT2E, ONNX Runtime, and NNCF quantizers, enabling static and dynamic quantization as well as weight-only compression (INT8/INT4), with configurable calibration workflows. This makes it easier to export optimized models for efficient inference across different backends.

For more information see the docs: https://huggingface.co/docs/transformers/exporters_quantization
