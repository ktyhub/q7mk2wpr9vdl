druida druida-0.8.1

Actualizando desde 0.8.0

No debería haber problemas de actualización y se pueden seguir procedimientos de actualización estándar para actualizaciones continuas.

Nuevas características

  • #1259 Experimental Búsquedas en tiempo de consulta (QTL) -– Capacidad para realizar uniones limitadas en el momento de la consulta. Un ejemplo de caso de uso simple es el de Código de país a Nombre de país.
  • #1374 Experimental Reindexación por lotes de Hadoop e ingesta de Delta. La reindexación le permite ingerir segmentos de druidas existentes utilizando un nuevo esquema con ciertas columnas eliminadas, granularidad modificada, etc. La ingestión "Delta" permite agregar datos al intervalo existente en una fuente de datos. Consulte las nuevas dataSource inputSpec y multi inputSpec para obtener más información.

Mejoras

  • #1465 Leer el archivo de configuración de Hadoop desde HDFS
  • #1472 Compatibilidad con el uso del combinador para la ingesta de Hadoop
  • #1506 Mejor soporte para filas de entrada nulas durante la ingesta
  • #1518 Se agregó más soporte para Azure Deep Store
  • #1550 Agregar opción de configuración para imprimir todas las solicitudes HTTP para iniciar sesión
  • #1563 #1602 Rendimiento de fusión mejorado en Broker
  • #1567 #1568 Registro de errores mejorado para actividades de segmento
  • #1596 Consola coordinadora mejorada, ahora una dependencia maven separada en lugar de un volcado de código gigante
  • #1601 Se redujo la contención de bloqueo durante el escaneo de segmentos.
  • #1603 Rendimiento mejorado de TopN lexicográficos
  • #1643 causa útil que explica por qué SegmentDescriptorInfo no existía Cobertura de prueba mejorada para puntos finales de servicio de indexación, ingesta y coordinador

Corrección de errores

  • #1406 Arreglar grupo rompiéndose al exceder el máximo de filas intermedias
  • #1441 Se corrigieron errores de descarga que se suprimen al cerrar flujos de salida
  • #1469 Se corrigieron nombres de propiedades inconsistentes para druid.metadata.* properties
  • #1484 JobHelper.ensurePaths establecerá las propiedades de la configuración correctamente
  • #1499 Grupo de reparación mediante almacenamiento en caché con agregadores renombrados
  • #1503 Se corrigió la fuga de nodos de estado del servicio de indexación en ZK
  • #1534 Se corrigió el almacenamiento en caché para histogramas aproximados.
  • #1616 Se corrigió el error de dependencia en la tarea de índice local
  • #1627 Se corrigió que las tareas en tiempo real se atascaran al apagarse incluso después de que el estado se mostrara como ÉXITO
  • #1634 Permitir que IrcFirehoseFactory se apague limpiamente
  • #1640 Extensiones de paquete en el tarball de lanzamiento + script para ejecutar servidores druidas
  • #1653 Se corrigió el indicador de éxito emitido en las métricas de consulta del enrutador
  • #1659 en el segmento de eliminación, no deje la versión, el intervalo y el directorio de origen de datos en HDFS
  • #1681 Se corrigió que los segmentos superpuestos no funcionaran para la manguera contra incendios de segmentos de ingesta

Documentación

  • Nueva documentación para mangueras contra incendios, evaluación de Druida y muchas correcciones.
  • Documentación mejorada para trabajar con CDH.

original en inglés / English original

druid druid-0.8.1

Updating from 0.8.0

There should be no update concerns and standard updating procedures can be followed for rolling updates

New Features

  • #1259 Experimental Query Time Lookups (QTL) -– Ability to do limited joins at query time. Simple example use case is Country Code to Country Name.
  • #1374 Experimental Hadoop batch re-indexing and Delta ingestion. Re-Indexing allows you to ingest existing druid segments using a new schema with certain columns removed, changed granularity etc. "Delta" Ingestion allows appending data to existing interval in a datasource. See the new dataSource inputSpec and multi inputSpec for more information.

Improvements

  • #1465 Read Hadoop configuration file from HDFS
  • #1472 Support using combiner for Hadoop ingestion
  • #1506 Better support for null input rows during ingestion
  • #1518 More support added for Azure deep store
  • #1550 Add configuration option to print all HTTP requests to log
  • #1563 #1602 Improved merging performance on Broker
  • #1567 #1568 Improved error logging for segment activities
  • #1596 Improved coordinator console, now a separate maven dependency instead of giant code dump
  • #1601 Reduced lock contention during segment scan
  • #1603 Improved performance of Lexicographic TopNs
  • #1643 helpful cause explaining why SegmentDescriptorInfo did not exist

Improved test coverage for indexing service, ingestion, and coordinator endpoints

Bug Fixes

  • #1406 Fix groupBy breaking when exceeding max intermediate rows
  • #1441 Fix flush errors being suppressed when closing output streams
  • #1469 Fix inconsistent property names for druid.metadata.* properties
  • #1484 JobHelper.ensurePaths will set properties from config properly
  • #1499 Fix groupBy caching with renamed aggregators
  • #1503 Fix leaking indexing service status nodes in ZK
  • #1534 Fix caching for approximate histograms
  • #1616 Fix dependency error in local index task
  • #1627 Fix realtime tasks getting stuck on shutdown even after status being shown as SUCCESS
  • #1634 Allow IrcFirehoseFactory to shutdown cleanly
  • #1640 Package extensions in release tarball + script to run druid servers
  • #1653 Fix success flag emitted in router query metrics
  • #1659 on kill segment, don't leave version, interval and dataSource dir behind on HDFS
  • #1681 Fix overlapping segments not working for ingest segment firehose

Documentation

  • New documentation for firehoses, evaluating Druid, and plenty of fixes.
  • Improved documentation for working with CDH
  • Added instructions for PostgreSQL metadata store
  • More documentation on how to use ApproximateHistograms

The full list of changes can be found here

Thanks

Special thanks to everyone that contributed (code, docs, etc.) to this release!
