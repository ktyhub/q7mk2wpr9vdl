appsmith v1.73

Highlights

  • executeOnLoad → runBehavior migration — This release is dominated by a codebase-wide rename: executeOnLoad was replaced with runBehavior in all action config settings (#40339) and across all frontend instances (#40358), with a third change updating references to runBehaviour (#40361) — note the inconsistent spelling, which is worth checking if you script against these keys. Backend support for backwards compatibility with "execute on load" was added in #40644, so existing apps should keep working; if you build tooling around action payloads or config keys, verify against the new names.

  • Breaking: Google Shared Drive flag removed — #40617 removes usage of the Google Shared Drive flag entirely. Anyone whose integration depended on that flag being honored must review their setup before upgrading; this is the one explicit breaking change in the release.

  • Session expiry now enforced mid-navigation — #40718 logs out users whose session expired between page navigations, closing a gap where a stale session could survive route changes. A meaningful correctness/security improvement — a reason to upgrade if session handling matters.

  • Table widget and reactive query stability — Infinite-scroll column merging in TableWidgetV2 was overhauled (#40610), offline data handling for infinite-scroll tables improved (#40632), and table search now excludes system columns (#40647). On the reliability side, #40481 fixes cyclic dependencies introduced by run-behavior changes in reactive queries and #40480 fixes JSFunctionSettings unit tests — mostly internal hardening tied to the runBehavior migration.

  • Upgrade verdict — Worth upgrading for users hitting session-expiry or infinite-scroll table issues, and for anyone wanting to align with the new runBehavior config model (backwards compat is in place). Those relying on the Google Shared Drive flag should validate first; otherwise this is a low-risk maintenance release with no new features beyond the rename plumbing — teams not using affected areas can safely skip.

Fixes

  • Logged out users automatically if their session has expired between page navigations. (#40718)
  • Updated styles for the JS settings popover. (#40660)
  • Improved offline data handling for data tables with infinite scroll enabled. (#40632)
  • Refined table search by excluding system columns from search results. (#40647)
  • Removed usage of the Google Shared Drive flag. (#40617)
  • Resolved cyclic dependencies caused by run behavior changes in reactive queries. (#40481)
  • Fixed unit test failures in JSFunctionSettings. (#40480)

Features

  • Added backend support for backwards compatibility in "execute on load" functionality. (#40644)
  • Improved infinite scroll column merging in TableWidgetV2. (#40610)
  • Replaced all frontend instances of executeOnLoad with runBehavior. (#40358)
  • Replaced executeOnLoad with runBehavior in all action config settings. (#40339)
  • Updated references across the codebase from executeOnLoad to runBehaviour. (#40361)
