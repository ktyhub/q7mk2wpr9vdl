redis 8.12-rc1

Esta es la primera versión candidata de Redis 8.12 en código abierto Redis.

Las versiones candidatas son versiones preliminares con funciones completas. Los prelanzamientos no son adecuados para uso en producción.

Titulares:

Redis 8.12 presenta nuevas funciones y mejoras de rendimiento.

Sistemas operativos en los que probamos Redis 8.12

  • Ubuntu 22.04 (Jammy Jellyfish), 24.04 (Noble Numbat), 26.04 (Resolute Raccoon) -Rocky Linux 8.10, 9.7, 10.1 -AlmaLinux 8.10, 9.7, 10.1
  • Debian 12.13 (ratón de biblioteca), Debian 13.4 (Trixie)
  • Alpino 3.23
  • macOS 14.8.4 (Sonoma), 15.7.4 (Sequoia), 26.3 (Tahoe) - para Intel y ARM

Correcciones de seguridad

  • RediSsearch/RediSsearch#10073 El hash de valores indexados ahora es resistente a colisiones, lo que evita la degradación del índice estilo HashDoS debido a entradas adversas. (MOD-14459)
  • RediSsearch/RediSsearch#11202 Los caracteres UTF-8 incompletos ya no se leen fuera de los límites en los campos de TEXTO indexados. (MOD-18088)

Nuevas funciones

  • #15331 Mapas de bits comprimidos: rugido redis integrado en el núcleo Redis para un menor uso de memoria y operaciones de mapas de bits más rápidas. ¡Un agradecimiento especial a Antonio, el creador original de redis-roaring, por contribuir con esta capacidad! https://redisroaring.com/redis-merge/#/1;
  • #15986 Nuevo comando: BITRANGEINTARRAY equivalente al R.RANGEINTARRAY de redis-roaring, para devolver desplazamientos de bits establecidos dentro de un rango específico

  • #15829 CLUSTER MIGRATION STATUS ahora informa el progreso de las fases de migración instantánea y incremental.
  • #15556 TLS los grupos con nombre ahora se pueden configurar usando tls-groups

redis 8.12-rc1

This is the first Release Candidate of Redis 8.12 in Redis Open Source.

Release Candidates are feature-complete pre-releases. Pre-releases are not suitable for production use.

Headlines:

Redis 8.12 introduces new features and performance improvements.

Operating systems we test Redis 8.12 on

  • Ubuntu 22.04 (Jammy Jellyfish), 24.04 (Noble Numbat), 26.04 (Resolute Raccoon)
  • Rocky Linux 8.10, 9.7, 10.1
  • AlmaLinux 8.10, 9.7, 10.1
  • Debian 12.13 (Bookworm), Debian 13.4 (Trixie)
  • Alpine 3.23
  • macOS 14.8.4 (Sonoma), 15.7.4 (Sequoia), 26.3 (Tahoe) - for both Intel and ARM

Security fixes

  • RediSearch/RediSearch#10073 Indexed value hashing is now collision-resistant, preventing HashDoS-style index degradation from adversarial input. (MOD-14459)
  • RediSearch/RediSearch#11202 Incomplete UTF-8 characters no longer reads out of bounds in indexed TEXT fields. (MOD-18088)

New Features
