AutoGPT autogpt-platform-beta-v0.6.13

Highlights

  • Execution engine goes async-first — #10138 makes the engine async-first, #10142 adds depth-first execution ordering, and #10066 moves output processing out of the node executor into the graph executor. If you write custom blocks or depend on node-level output handling, revisit your assumptions: outputs now resolve at graph scope, and depth-first traversal changes the order in which side-effectful blocks fire. This is the most consequential internal shift in the release.
  • Retries and UI consistency — #10183 adds automatic request retries on block execution and RPC calls, so transient network failures no longer abort a run outright. Make sure custom blocks are idempotent, since a retried block can re-run side effects. #10149 fixes stale execution UI updates so the graph view stays in sync with what the engine is actually doing.
  • Auth and self-hosting config — #10117 adds Google Sign-in, while #10102 fixes password-reset links to honor FRONTEND_BASE_URL and #10103 clears a perpetual loading state on reset. Self-hosters should verify FRONTEND_BASE_URL is set correctly or reset emails will point at the wrong host; #10143 and #10124 also stop the account menu lingering after logout and quiet cookie warnings.
  • More model and provider options — #9996 brings AI/ML API support to LLM blocks, #10144 adds VEO3 to the AI video generator, and #10145 reduces the price of the O3 model. Adopters gain another provider path and a lower O3 cost, but the new AI/ML block surface is worth testing against your own quota and rate-limit assumptions.
  • Security and toolchain upkeep — #10148 bumps requests from 2.31.0 to 2.32.4 to pick up upstream security fixes, and #10123 hardens the security module. On the frontend, #10179 moves the design system to Storybook 9 — a major bump that contributors should expect to affect local tooling — alongside lint/TypeScript cleanup in #10182 and new design-token docs (#10155, #10157, #10158).
  • Breaking changes — None flagged in this release.
