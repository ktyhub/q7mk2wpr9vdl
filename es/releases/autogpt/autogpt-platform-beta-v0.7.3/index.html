AutoGPT autogpt-platform-beta-v0.7.3

Highlights

  • Notification architecture overhaul — The email system is replaced by a Briefing/Alert/Verdict/Ops model (#14003), changing how platform events are classified and surfaced. Integrations that consume email-based notifications should be reviewed and migrated to the new notification surfaces.
  • Copilot interaction and state reliability — Users can now choose from predefined ask_question options, and a new “Needs-You” prompting rule drives required follow-ups (#14156). Live compaction progress clarifies long-running conversations (#14143), while stale-proof expert delegation and team-state handling (#14155) reduce the risk of actions operating on outdated state.
  • Tool UX graduates from feature flags — The new-tool-ui flag is removed, making the redesigned tool chain the default experience (#14164). Additional expert-team tools and chat refinements remain behind flags (#14099), so deployments should verify which experimental capabilities are enabled.
  • Safer identity and database access — The platform User row is now provisioned on the first authenticated request (#14147), addressing incomplete user records after authentication. Read-only Cypher queries are routed through GRAPH.RO_QUERY (#14145), enforcing a read-only execution path instead of the general graph-query endpoint.
  • MCP OAuth compatibility fix — Popup-based OAuth no longer fails with “Sign-in window was closed” for providers using Cross-Origin-Opener-Policy headers (#14141). Teams connecting MCP servers through COOP/COEP-secured environments should no longer need a workaround.
  • CI and analytics follow-ups — GitHub artifact and Docker actions receive major-version bumps (#12261, #12352, #12353); self-hosted workflows should check action compatibility. The onboarding and signup DataFast goals are corrected to the funnel’s expected names, including signup (#14167, #14173), improving attribution without requiring user-side changes.

No breaking changes are called out in this release.
