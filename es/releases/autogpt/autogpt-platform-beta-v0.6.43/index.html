AutoGPT autogpt-platform-beta-v0.6.43

Highlights

  • Hybrid search unified across all content — PRs #11721, #11767, and #11782 combine vector embeddings with BM25 keyword ranking for store listings, docs, blocks, and chat, and backfill embeddings for existing content so nothing needs a manual reindex. This materially improves retrieval recall, but the backfill is a one-time job that can spike load on your embedding provider — watch it on large corpora.
  • Copilot becomes an agent-building tool, not just a chatbot — The hackathon extractions (#11717, #11719) plus agent-generator tools (#11781) and chat search with BM25 reranking (#11782) let the copilot scaffold and retrieve agents conversationally. It's freshly extracted code, so expect edge-case roughness; treat it as a capability preview rather than a stable API.
  • Explicit safe-mode and HITL toggles — #11756 makes human-in-the-loop and sensitive-action gating configurable rather than implicit. Action item: audit your graph configs, because flows that previously executed automatically may now pause for approval once these toggles are set.
  • Observability shifts to Langfuse v3 — #11803 migrates tracing to the v3 SDK with @observe decorators, and #11759 adds an endedAt field while correcting analytics timestamps. If you consume Langfuse traces or execution analytics downstream, re-verify dashboards and parsers — the SDK and timestamp semantics changed.
  • Credentials UI consolidated with deterministic selection — #11801 unifies input behind a single CredentialsGroupedView, while #11763, #11815, and #11795 fix auto-selection and make chat credential type selection deterministic. Recheck any tests or automation that depended on the old builder's selection behavior.
  • Infrastructure hardening — #11775 and #11817 make Redis lazy and tolerant of connection failures (no more crash-on-boot during a Redis outage), #11805/#11818 fix pgvector type qualification, and #11764/#11812 harden graph execution and settings validation against nulls. These are quiet reliability wins that reduce startup and query-failure risk.

No breaking changes are reported in this release.
