AutoGPT autogpt-platform-beta-v0.6.2

Highlights

  • Anonymous agent-store access — #9710 makes agent-store data available without authentication, enabling public discovery but removing authentication as a privacy boundary. Audit exposed metadata, links, and access-control assumptions before upgrading.
  • Live execution feedback — #9695 brings real-time execution updates to platform/library views, #9740 adds a live step counter, and #9755 lets users jump from a run into the builder. This shortens the debug-and-edit loop; review custom polling logic to avoid redundant refreshes.
  • Webhooks and typed inputs — #9584 adds a reusable webhook block for event-driven integrations, while #9700 and #9762 introduce input-subtype UI in the builder and onboarding. Validate custom input widgets, subtype-specific fields, and defaults.
  • Execution-state isolation — #9793 fixes unintended block I/O value sharing, and #9794 deep-copies schemas to limit cross-input mutations. Workflows that accidentally relied on shared mutable values should be retested.
  • Secrets, diagnostics, and dependencies — #9764 fixes ProviderName handling during secret loading; verify credential resolution across providers. Sentry/uvicorn logging (#9756, #9742) improves production visibility, but requires reviewing captured data for sensitive values. Dependency updates include Sentry JS 9.6.0 (#9646), psutil 7.0.0 (#9686), and a Next.js security patch (#9767), warranting targeted regression tests.
  • Breaking changes — None are explicitly listed in this changelog.
