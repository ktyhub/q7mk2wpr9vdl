AutoGPT autogpt-platform-beta-v0.8.2

Highlights

  • AutoPilot gating and approvals — Ask First, Auto, and Unsupervised modes (#14209) are backed by chat-, Expert-, and team-scoped rules (#14931). Bare-tool approvals can be remembered or delegated to Otto (#14980), held calls have a dedicated review dialog (#14999), and workflows pause before actions marked irreversible (#14817). Configure approval scope explicitly rather than assuming previous tool grants apply globally.
  • Policy-driven tool and data access — AutoPilot can run read-only and workspace operations without prompting (#14837), classifies MCP calls using per-server effect maps, and asks on first use of unknown tools (#14839). External reads are screened before reaching the model, with instruction-bearing reads held (#14834), while paid reads require approval after a chat exceeds its spend ceiling (#14841). Accurate effect maps and spend limits now directly govern execution.
  • Sandbox credential isolation — Every E2B box now egresses through a credential-swap proxy (#14645), and one-time secrets are excluded from session replays (#15022). Self-hosted operators should verify that network policies and egress monitoring account for the new proxy path.
  • New workflow and integration primitives — AnySearch adds search, parallel-search, and extract blocks (#14792); Copilot @ mentions can resolve connected integrations (#14775); and PostHog plus self-hostable OpenSEO MCP integrations are available (#14859, #14971). web_fetch now preserves main page content and warns on JavaScript-only shells (#14875), reducing silent empty extractions.
  • Model routing changes — The standard tier defaults to Claude Sonnet 5.5 (#15014), fast/standard routing moves from gpt-5.6-luna to gpt-6-luna (#14949), and the advanced-tier Opus alias is corrected to claude-opus-5.5 (#14855). Expect shifts in cost, latency, and output behavior; pin explicit model IDs where consistency matters.
  • Marketplace migration — Listings now require a short, CTA-style sub_heading; update publishing templates and run the supplied backfill script for existing listings (#14494). No explicit breaking changes are listed.
