AutoGPT autogpt-platform-beta-v0.6.40

Highlights

  • Expanded integration surface — Google Sheets/Drive now use unified credentials (#11520), while new spreadsheet blocks (#11574) and four GitHub webhook triggers (#11588) simplify data-processing and event-driven agent workflows.

  • Better execution diagnostics — Execution-accuracy alerts (#11562), improved error extraction (#11527), and treating ValueError as a known block error (#11537) give operators clearer signals for identifying and triaging failing agent runs.

  • More reliable builder authoring — Inline graph-validation errors (#11524), automatic node-collision resolution (#11506), expandable text editors (#11510), and file inputs with variants/base64 support (#11533) reduce configuration mistakes and manual cleanup. Host-scoped credentials (#11546) also constrain credential selection to the relevant integration host.

  • Real-time, version-aware Library workflows — The new Library uses WebSockets (#11526), exposes templates and triggers (#11580), and synchronizes flowVersion into the URL (#11585). Deep links therefore preserve the loaded graph version, while trigger and empty-task transition fixes (#11589, #11600) improve navigation reliability.

  • Proxy authentication and security fixes — Proxies now forward X-API-Key (#11530), and credential types from the SDK registry reach the integrations API (#11544), addressing authenticated integrations behind proxies and credential-registration mismatches. The bundled Next.js upgrade from 15.4.7 to 15.4.8 (#11536) also incorporates upstream security fixes.

  • Behavioral changes to test — Copied graphs moved from local storage to the clipboard (#11578), so tooling reading old local copies needs updating and clipboard permissions may now apply. Markdown rendering disables single-dollar LaTeX mode (#11598); templates and user content relying on $...$ inline math should be revised.

No breaking changes are declared in this release.
