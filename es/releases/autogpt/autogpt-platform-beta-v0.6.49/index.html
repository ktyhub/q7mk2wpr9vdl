AutoGPT autogpt-platform-beta-v0.6.49

Highlights

  • MCP comes first-class — #12011 adds an MCP tool block with OAuth, tool discovery, and integration with the standard credential store. For developers this means external MCP servers are now a supported extension point rather than a bespoke integration, and creds reuse the existing credential machinery instead of a parallel secret store. Watch the OAuth setup path: discovery and credential wiring must be configured before blocks can be used.

  • The legacy builder is gone — plan a migration — #12081 replaces the old builder with the new flow editor, with #12082 removing the old builder code and monitoring components and #12088 dropping the NEW_AGENT_RUNS feature flag. This is the release's real breaking change: the flag-based rollback path no longer exists, so existing graphs and any tooling that toggled or targeted the legacy builder need to be validated against the flow editor before upgrading.

  • Workspace becomes the durable file layer — #12073 persists sandbox files to the workspace, #12164 adds workspace file tools/context reconstruction and transcript-upload protection, #12166 handles workspace:// URLs inside normal markdown links, and #12153 scopes GCSWorkspaceStorage per worker (#12190 fixes file listing). Artifacts now survive beyond a single run and can be referenced in markdown, but the storage model and per-worker GCS lifecycle changed — check any code that assumed sandbox-local files or a shared storage instance.

  • CoPilot execution moves to a microservice, adds Claude Agent SDK — #12057 extracts a Copilot Executor Microservice, #12103 integrates the Claude Agent SDK for CoPilot, and #12216 adds fpdf2 for PDF operations. This changes the deployment topology: there is a new service to run and a new SDK/dependency surface, so self-hosters need to account for the extra component and its runtime deps rather than treating this as a drop-in library update.

  • Credential and API changes that will break integrations — #12143 renames LINEAR_API_KEY to COPILOT_LINEAR_API_KEY to stop global access (update env vars and secrets), and #12092 removes the default expiration date from the API-key credential form. On the API side, #12208 adds POST /graphs and #12112 adds a delete-chat-session endpoint. The Linear env-var rename is the one to catch in CI before it silently disables the integration.

  • Execution semantics shifted toward concurrency and resilience — #12165 runs parallel tool calls concurrently, while #12159/#12173/#12175/#12205 rework streaming (reconnection, timeout removal, error propagation), #12171/#12191 wire the stop button to task cancellation, and #12177 adds collision detection and session locking for concurrent message saves. Behaviorally, #12108 enables WebSearch while blocking WebFetch and consolidates tool constants, and #12139 returns SuggestedGoalResponse for vague or unachievable goals. Expect faster runs and fewer stuck sessions, but audit any workflow that relied on WebFetch or on serialized tool-call and stream timing.
