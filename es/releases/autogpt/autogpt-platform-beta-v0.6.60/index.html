AutoGPT autogpt-platform-beta-v0.6.60

Highlights

  • Workflow triggers and chat integrations — “Trigger On Anything” broadens workflow entry points (#12740), while the new Slack SendSlackMessageBlock (#13008) and Discord thread, mention, and bot-to-bot support (#13039) bring agents into team communication tools. Discord bot setup now requires server-manager permissions (#13092), so plan setup accordingly.

  • Model routing is configuration-sensitive — OpenAI models can auto-route through OpenRouter when configured (#13029), and the main client can switch between OpenRouter and Anthropic-direct (#13034). Anthropic’s automatic OpenRouter reroute was removed (#13041), while CHAT_USE_OPENROUTER defaults back to true (#13066); verify provider settings, observability, and billing expectations before upgrading.

  • Billing and entitlement enforcement changed — Preflight estimates now use historical averages and 30-day production usage (#13031, #13074), while block billing and paywall enforcement are centralized across execute routes with a NO_TIER bypass (#13023, #13045). Reconciliation can produce negative balances (#13043), and subscription credit grants are off by default with deduplicated Stripe events (#13093), so validate credit assumptions.

  • AutoPilot has explicit concurrency ceilings — The queue caps workloads at 5 running plus 15 in-flight tasks (#13069), with at most 15 concurrent turns per user (#13064). Excess work queues rather than scaling freely; related safeguards bound LLM calls, reap orphan node_execs (#13051), retry notifications before dead-lettering (#13049), and retry transient Redis cluster errors (#13076).

  • Chat experience and history loading — Copilot reaches first output sooner (#12828), generated artifacts auto-open (#12997), and sessions can be exported as Markdown (#13070). Eager-loaded chat history is capped at the 1,000 most recent messages (#13047), so review integrations that assume the eager-loaded transcript contains complete history.

  • Breaking changes — None explicitly listed.
