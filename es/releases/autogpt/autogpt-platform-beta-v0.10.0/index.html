Highlights

  • Self-hosted Docker Compose requires migration (#15970) — Service passwords are now generated per install, and PostgreSQL, RabbitMQ, Redis, FalkorDB, and ClamAV bind to 127.0.0.1 only; self-hosters must run make init-env (or the installer) before docker compose up. Existing installs should follow Upgrading: service passwords are generated per install; managed/cloud users can skip this step.

  • External API v1 deprecation has a long runway (#12206) — External API v2 ships in this release, while v1 remains working until 2027-01-31. Teams with external API integrations should plan migration to v2 now; if you don’t use the external API, this change can be ignored.

  • Security and abuse-resistance improvements are the strongest upgrade reason — OAuth callbacks are restricted to registered redirect_uri values (#15057), org members can join only by accepting an invitation (#16175), user-supplied regex/HTTP bodies/template formatting get time or size limits (#16240, #16242, #16241), chat warns on secret-like content (#15952), and read-injection checks gain their own flag with shadow mode (#15549). Security-conscious operators and multi-user/self-hosted deployments should upgrade; audit any integrations that depended on permissive redirects or unbounded user-controlled input.

  • New models and integrations are useful but not urgent — This release adds Kimi K3.1 Pro (#16096), GPT-6.1 Terra (#16261), Cloudflare to the MCP catalog (#16217), and API-key last-used tracking (#15990), plus onboarding/chat UX improvements. Upgrade if you want these capabilities; otherwise stable deployments can wait for a quieter release window.

  • Large frontend design-system migration needs UI validation — A broad DS2/DS3/DS5/DS7 refactor moves components onto role/text tokens, adds data-slot attributes, and runs Tailwind CSS 4 with Tailwind 3’s theme and output (#16156), with stated visual parity intent. Upgrade if you can smoke-test key UI flows; teams prioritizing frontend stability should stage the rollout due to regression risk from the scope of the change.
