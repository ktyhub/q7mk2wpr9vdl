AutoGPT autogpt-platform-beta-v0.7.2

Highlights

  • Expert memory is isolated and privacy now fails closed — #14031 isolates memory per expert, #14032 adds an admin viewer, and #14071 exposes a user-facing memory settings page, while #14034 makes non-private experts fail closed. Migration note: memory is no longer shared across experts, and any expert that relied on a permissive visibility setting will now error — audit expert privacy flags before rolling out.

  • The expert lifecycle becomes a first-class workflow — "raise your own expert" v1 (#14041), a reworked raise flow with attachments/budget/skills (#14069), day-one kickoff after hire (#14039), writing-style capture during hiring (#14027), "fire" with clean archive UX (#14029), pods/named expert groups (#14042), and an expert work surface with work cards and a work tab (#14043). Expect existing hire/instantiation automations to need rework against these new flows.

  • Machine payments get real settlement paths — Stripe Link wallet blocks arrive with a device-code OAuth flow for headless auth (#14062), can pay MPP merchants (#14066), now handle requires_action on the enriched approval sheet (#14063), and are joined by Stripe subscription webhook trigger blocks (#13435). Watch out: payment flows can now surface an interactive approval step, so automations that assumed single-step charges must be ready to resume after requires_action.

  • Entitlement and transport access are enforced at runtime — #14070 makes the AutoPilot transport an explicit choice, #14058 stops the codex transport reaching non-entitled users, #14060 fails runs denied by entitlement, and #14076 aggregates sub-graph credentials in copilot run/trigger tools. This is the most migration-sensitive area: set the transport explicitly and verify entitlements, or previously working runs will now fail closed.

  • New surfaces: Teams, incident blocks, and a briefing-first home — a Microsoft Teams bot adapter (#14054), a DataForB2B enrichment provider (#13383), and All Quiet incident-management blocks (#14053) expand the catalog, while the briefing-first /home ships behind the hire-experts flag (#13926) with persisted UserBriefing plus live delta (#14017), AI-voice narrative (#14021), and the Copilot home repurposed as a briefing recap (#14016). The new home is flag-gated — opt in to see it.

  • Breaking changes — None formally labeled in this release; the changes above are additive or hardening behavior changes.
