AutoGPT autogpt-platform-beta-v0.6.64

Highlights

  • Proactive Copilot and outbound delivery — The Copilot stops being purely reactive: a background "dream" pass (#13243), webhook triggers with preset lifecycle management (#13298), a post_to_discord tool (#13349), and an outbound channel/thread delivery RPC (#13348) let it initiate work and push results on its own schedule. The reliability fixes are what make this safe to adopt: tool outputs are now paired by name and input instead of name alone (#13372), so parallel invocations no longer cross-wire results; setup_requirements card delivery is hardened (#13350); and connect_integration now explicitly enumerates supported providers (#13362).

  • Builder navigation and shared graphs — AutoPilot Context Panel V1 adds a shell with a Files tab (#13228), Cmd+K becomes a global command palette on every platform page (#13360), and builder search is faster (#13290). The standout for teams is read-only Builder mode for non-owned graphs (#13238): you can inspect and debug someone else's graph without any mutation risk, which is especially useful for support and fork-before-edit workflows.

  • MCP argument expansion — @@agptfile references now expand inside MCP tool arguments (#13373). This makes referencing large files in tool calls practical instead of inlining blobs, but it changes what a tool sees at runtime — anything parsing raw arguments now receives expanded content, so validate tools that assume literal argument strings.

  • Atomic graph saves — Graph saves are now atomic with clearer credential error surfacing (#13264). A failing credential mid-save can no longer leave a partially written graph, but integrations that depended on partial-write behavior or scraped specific error text should re-check their handling.

  • Security hardening — Baseline security response headers (#13370), static-font CORS scoped to the app's own origin (#13371), and webhook ownership enforced on the ping endpoint (#13368). The webhook change is the one to watch: automations that pinged webhooks without proper ownership context will now be rejected.

  • Provider, scheduler, and billing reliability — Fixes cover the OpenAI Responses "Omit" mapping crash (#13335), Anthropic temperature deprecation breaking dream recombine (#13342), warm-context reranker 400s via a higher max_tokens (#13337), and dream cron registration crashing on timezone lookup in Prisma-less processes (#13336) — collectively the fixes that decide whether scheduled Copilot runs survive in production. Also note default billing is now monthly (#13363) and paywall flows tolerate half-dead sessions (#13333); audit any billing automation.

No breaking changes were introduced in this release.
