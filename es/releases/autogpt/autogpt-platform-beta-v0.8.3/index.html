AutoGPT autogpt-platform-beta-v0.8.3

Highlights

  • Durable chat streaming and resume semantics — Stream entries now have stable IDs, persistence checkpoints, and cursor-based resume support (#15084), while persisted stream rows expose drift from the frontend (#15088). Clients should key updates by entry ID and reconnect from the saved cursor rather than assuming one uninterrupted event sequence. Copilot error retries now start a new turn (#15166), so retry handling must not treat them as continuations.

  • Native chat approvals with tighter guardrails — Linked Discord, Slack, Teams, and Telegram chats can present approval cards as native buttons (#15069); button clicks wake and judge the turn like web clicks (#15131), and bots no longer wait on cards their channel cannot render (#15068). Routine sandbox work no longer prompts, but outward commands and unrequested deletion of user files still require approval (#15053)—reducing friction without removing the high-risk gates.

  • Verified email becomes an onboarding prerequisite — Signup now provisions the platform User immediately, but the first session requires a verified email (#15135). Update onboarding and integration tests for this split. Production can use ENABLE_USER_NOTIFICATIONS to send authentication emails only (#15138), while the new consent language, marketing opt-out, and gated MailerLite writes change signup-side effects (#15152, #15141).

  • More reliable background and parallel execution — Scheduled run_agent calls now reach the database through DatabaseManager and alert on failed turns (#15125); schedules use the account selected when they were created (#15132). Wide graph fan-outs no longer exhaust the Redis connection pool (#15197), and AutoPilot sub-agents stay in the foreground so their work reaches the final reply (#15127).

  • Expanded connector and model coverage — The catalog adds official PayPal and Canva MCP servers (#14951, #15134), GitHub repository traffic and Hacker News blocks (#15188, #15191), plus GPT-6.1 Sol and several Mistral models (#15070, #15203, #15210). Conductor integrations now accept prompt IDs as Get Session cursors, expose next_after, and report an explicit workspace base branch (#15114, #15108), supporting more predictable automation and pagination.

  • Model and tool removals require migration — Mistral Medium 3.1 and Small 3.2 are retired; pinning workflows must move to Medium 3.5 or Small 4 (#15210). The CLI’s ListAgents and SendMessage tools are disallowed in production and development (#15109, #15117), so replace any automation that depends on those interfaces.
