AutoGPT autogpt-platform-beta-v0.6.17

Highlights

  • New workflow blocks — ReadSpreadsheetBlock gains Excel support and introduces FileReadBlock; new Gmail thread, Replicate model, ReverseListOrderBlock, and enabled Google blocks expand automation options. Upgrade if you need these integrations.
  • Performance and reliability — Large execution-update payloads are truncated, spreadsheet reads are faster, NodeExecutionProgress output is thread-safe, and new database indexes plus prefetch queries improve performance. An alert now flags agents stuck running for over a day, helping operators recover stalled workflows.
  • Deployment changes—review before upgrading — DatabaseManager moves out of the REST API into a standalone service, and NotificationManager moves from the REST API pod to the scheduler pod. The missing DatabaseManager process in self-hosted Docker mode is fixed, but no migration steps are documented; self-hosters should verify their container configuration.
  • Beta features and UI fixes — Beta blocks are gated through LaunchDarkly, with initialization fixes on both server and client. Navbar/profile issues, empty-string Agent Input defaults, cursor jumping, and WebSocket handling on logout are fixed; an agent activity dropdown is added.
  • Upgrade recommendation — This is a substantive release worth taking for users of the new blocks, self-hosted deployments, or affected UI/reliability fixes. Unaffected users can skip, but should regression-test Pinecone, WebSocket, and YouTube integration code because pinecone (5.4.2 → 7.3.0), websockets (14.2 → 15.0.1), and youtube-transcript-api (0.6.3 → 1.1.1) receive major version bumps. No explicit breaking changes are declared.
