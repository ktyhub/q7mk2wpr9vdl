¿Qué hay de nuevo?

  • DeepSeek-V4.1 obtiene hasta 2,3 veces más rendimiento por GPU en H200 y ahora se ejecuta en AMD MI350X/MI355X con hasta 1,9 veces más rendimiento que DSpark (#41251, #41308).
  • Qwen3.8-Flash-Next decodifica un 12% más rápido en B200 y GLM-5.3-Flash con DFlash un 10% más rápido en B300 (#42175, #42489).
  • MiMo-V2.6-Pro obtiene un rendimiento de decodificación de 1,85x con DFlash en B300 (#41886).
  • Los modelos se cargan 10 veces más rápido con el nuevo cargador InstantTensor (#40453).
  • La desagregación de PD obtiene hasta un 27 % más de rendimiento y la mitad del TTFT p95 en cargas de trabajo rápidas de larga duración (#40703).
  • HiSparse ahora admite EAGLE y MTP para servicio de contexto prolongado con el caché KV en la memoria de la CPU (#37771).
  • GLM-5.2 y GLM-5.3 ahora pueden combinar el paralelismo de contexto de decodificación con MTP, con una decodificación hasta 2,1 veces más rápida en GLM-5.3 (#43735).
  • SGLang ahora se ejecuta en Apple Silicon Macs con el backend estándar PyTorch, junto con MLX (#36780).
  • MiniMax-H3 y Qwen-Image 2.1 ahora se ejecutan en ComfyUI con SGLang Diffusion, que también carga puntos de control GGUF comunitarios y LoRA (#43504, #43581, #42556, #39523, #42174).
  • Solución importante: los modelos lineales híbridos podrían reanudarse desde estados mamba incorrectos cuando se usaban juntos la decodificación especulativa y la salida estructurada. Gracias a @Wirick y Baseten por encontrarlo (#43029).

Para actualizar

uv pip install --prerelease=allow sglang==0.5.22

Cambios importantes y notas de actualización

  • SGLang requiere Python 3.11 o posterior. En Python 3.10, pip install sglang no falla; se resuelve en la última versión que admitía 3.10. Vaya a Python 3.11+ (por ejemplo, fuera del sistema Ubuntu 22.04 Python) para obtener esta y otras versiones posteriores: #43021
  • --enable-dp-attention está en desuso; use --attn-dp-size N. --dp-size ahora cuenta solo réplicas de modelos. El antiguo --dp-size N --enable-dp-attention todavía se resuelve en --attn-dp-size N con una advertencia; combinar réplicas con atención DP o pasar ambas grafías se rechaza al inicio: #41818. Según el paralelismo del contexto de DeepSeek, --dp-size N todavía significa atención DP, pero ahora advierte y será rechazado después del 31 de diciembre de 2026: #42348
  • --disaggregation-decode-host-receive-threshold cambia su codificación. 1 (el nuevo valor predeterminado) desactiva la recepción del host y 0 ahora significa recibir siempre en el host. Las configuraciones que pasaron 0 para deshabilitarlo deben pasar 1: #43407
  • Se eliminó ChunkCache. Con --disable-radix-cache, los modelos de atención total, SWA híbrido y Mamba ejecutan UnifiedRadixCache en modo deshabilitado y los modelos SWA puro ejecutan PureSWARadixCache (#43198, #43199, #43200, #42354, #43201). Las sesiones de transmisión ahora comienzan solo en UnifiedRadixCache; Las cachés de Pure-SWA, FlexKV y del árbol de complementos fallan al inicio con un error "no verificado" (#42295), y la búsqueda de haz también rechaza los modelos Mamba con --disable-radix-cache (#42354)
  • Se eliminó el backend del gráfico CUDA de precarga tc_piecewise. Pasar --cuda-graph-backend-prefill tc_piecewise o una configuración tc_compiler ahora genera un error; CUDA mantiene breakable como el backend de gráfico de precarga predeterminado, y otras plataformas no tienen ningún gráfico de precarga predeterminado: #42287
  • Variables de entorno renombradas y retiradas. SGLANG_AITER_MLA_DCP_DECODE_BACKEND se convierte en SGLANG_AITER_MLA_DECODE_BACKEND y su valor predeterminado cambia de gluon a asm (#34537); SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW se convierte en SGLANG_OPT_RELEASE_PREFILL_SWA (#42657); los nombres antiguos siguen funcionando con una advertencia de obsolescencia. SGLANG_DSPARK_FAST_SAMPLING, SGLANG_DSPARK_FOLDED_SAMPLING y SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV están en desuso y ya no hacen nada (#43622, #43668), y SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE está en desuso: #43444
  • Las respuestas del chat de OpenAI cambiaron en tres pequeñas formas. tool_choice: "none" ya no muestra esquemas de herramientas para los modelos de DeepSeek (#43006), se omite un campo tool_calls ausente en lugar de devolverse como null (#43027) y una transmisión mantiene una marca de tiempo created durante toda su vida útil: #43026
  • --enable-layernorm-sp se rechaza con paralelismo de canalización. Falló en el primer llenado previo antes: #43458
  • Para autores de modelos y complementos: ModelRunner.tp_group se elimina; lea get_parallel().tp_group en el ámbito en el que se ejecuta el código (#41817). Los atributos de ubicación no leídos, como model.tp_size, desaparecieron; lea get_parallel() (#41812). Un modelo que declara límites de etapa y se ejecuta bajo paralelismo de canalización debe pasar su declaración de etapa compartida (stage_facts) a make_layers/make_pp_layers: #43460

Breaking Changes & Upgrade Notes

  • SGLang requires Python 3.11 or newer. On Python 3.10, pip install sglang does not fail; it resolves to the last release that supported 3.10. Move to Python 3.11+ (for example off the Ubuntu 22.04 system Python) to get this and later releases: #43021
  • --enable-dp-attention is deprecated; use --attn-dp-size N. --dp-size now counts model replicas only. The old --dp-size N --enable-dp-attention still resolves to --attn-dp-size N with a warning; combining replicas with attention DP, or passing both spellings, is rejected at startup: #41818. Under DeepSeek context parallelism, --dp-size N still means attention DP but now warns and will be rejected after 2026-12-31: #42348
  • --disaggregation-decode-host-receive-threshold flips its encoding. 1 (the new default) disables host receive and 0 now means always receive on host. Configurations that passed 0 to disable it must pass 1: #43407
  • ChunkCache is removed. With --disable-radix-cache, full-attention, hybrid-SWA and Mamba models run UnifiedRadixCache in disabled mode and pure-SWA models run PureSWARadixCache (#43198, #43199, #43200, #42354, #43201). Streaming sessions now start only on UnifiedRadixCache; pure-SWA, FlexKV and plugin tree caches fail at startup with a "not verified" error (#42295), and beam search rejects Mamba models with --disable-radix-cache too (#42354)
  • The tc_piecewise prefill CUDA graph backend is removed. Passing --cuda-graph-backend-prefill tc_piecewise or a tc_compiler setting now raises an error; CUDA keeps breakable as the default prefill graph backend, and other platforms default to no prefill graph: #42287
  • Renamed and retired environment variables. SGLANG_AITER_MLA_DCP_DECODE_BACKEND becomes SGLANG_AITER_MLA_DECODE_BACKEND and its default changes from gluon to asm (#34537); SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW becomes SGLANG_OPT_RELEASE_PREFILL_SWA (#42657); the old names keep working with a deprecation warning. SGLANG_DSPARK_FAST_SAMPLING, SGLANG_DSPARK_FOLDED_SAMPLING and SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV are deprecated and no longer do anything (#43622, #43668), and SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE is deprecated: #43444
  • OpenAI chat responses changed in three small ways. tool_choice: "none" no longer shows tool schemas to DeepSeek models (#43006), an absent tool_calls field is omitted instead of returned as null (#43027), and a stream keeps one created timestamp for its whole lifetime: #43026
  • --enable-layernorm-sp is rejected with pipeline parallelism. It failed on the first prefill before: #43458
  • For model and plugin authors: ModelRunner.tp_group is removed; read get_parallel().tp_group in the scope the code runs in (#41817). Unread placement attributes such as model.tp_size are gone; read get_parallel() (#41812). A model that declares stage boundaries and runs under pipeline parallelism must pass its shared stage declaration (stage_facts) to make_layers / make_pp_layers: #43460
