sglang v0.5.9

Parche Publicado24 feb 2026 Fuentesgl-project/sglang original en inglés

jerga v0.5.9

Destacados

  • Superposición de carga de peso LoRA con cálculo: superponga la carga de peso LoRA con el cálculo durante la inferencia, lo que reduce TTFT en ~78 % y TPOT en ~34.88 % en adaptadores grandes: #15512
  • Integración del kernel TRT-LLM NSA para DeepSeek V3.2: Integre los kernels TRT-LLM DSA para Native Sparse Attention, aumentando el rendimiento de DeepSeek V3.2 entre 3 y 5 veces en plataformas Blackwell con trtllm tanto para --nsa-prefill-backend como para --nsa-decode-backend (con una caída menor de precisión): #16758, #17662, #18389
  • Despachador MoE todo a todos Flashinfer: agregue el despachador MoE todo a todos Flashinfer para una comunicación de paralelismo experta eficiente, lo que permite un enrutamiento optimizado en modelos MoE: #14668
  • Soporte FA4 (Atención FP4) para codificador multimodal: introduzca el backend de atención FP4 y la función de atención de longitud variable para codificadores multimodales, lo que permite una inferencia de menor precisión para modelos de lenguaje visual: #13539
  • Punto final API compatible con Anthropic: agregue compatibilidad nativa con Anthropic API a SGLang, lo que permite la integración directa con herramientas y clients creados para el formato Anthropic API: #18630
  • Optimizaciones avanzadas de SGLang-Diffusion: mejoras listas para producción que incluyen fragmentación de secuencias a nivel de token, decodificación VAE paralela, núcleos fusionados, compatibilidad con Nunchaku y FP8, y múltiples modelos nuevos en el complemento ComfyUI: blog
  • Corrección de errores críticos de la especificación V2: Corrección del error fuera de índice causado por la recolección de basura de la antorcha en la decodificación especulativa v2, mejorando la confiabilidad de la verificación especulativa: #18958
  • Implementación de DeepSeek en GB300 NVL72: trabajo de optimización para inferencia de contexto prolongado mediante desagregación de decodificación previa al llenado y otras funciones SGLang en la última plataforma GB300 de NVIDIA: blog
  • Mejora la versión de AITER a 0.1.10.post3: admite precarga/decodificación/caché KV de FP8
  • Búsqueda de compromiso de versión en docs.sglang.io: encuentre fácilmente la versión oficial más antigua que incluya un PR o compromiso determinado, lo que agiliza el seguimiento de lanzamientos para usuarios y desarrolladores: #18450, enlace

sglang v0.5.9

Highlights

  • LoRA Weight Loading Overlap with Computation: Overlap LoRA weight loading with computation during inference, reducing TTFT by ~78% and TPOT by ~34.88% on large adaptors: #15512

  • TRT-LLM NSA Kernel Integration for DeepSeek V3.2: Integrate TRT-LLM DSA kernels for Native Sparse Attention, boosting DeepSeek V3.2 performance by 3x-5x on Blackwell platforms with trtllm for both --nsa-prefill-backend and --nsa-decode-backend (with minor accuracy drop): #16758, #17662, #18389

  • Flashinfer All-to-All MoE Dispatcher: Add the Flashinfer all-to-all MoE dispatcher for efficient expert parallelism communication, enabling optimized routing in MoE models: #14668

  • FA4 (FP4 Attention) Support for Multimodal Encoder: Introduce FP4 attention backend and variable-length attention function for multimodal encoders, enabling lower-precision inference for vision-language models: #13539

  • Anthropic Compatible API Endpoint: Add native Anthropic API compatibility to SGLang, allowing direct integration with tools and clients built for the Anthropic API format: #18630

  • SGLang-Diffusion Advanced Optimizations: Production-ready improvements including token-level sequence sharding, parallel VAE decoding, fused kernels, Nunchaku and FP8 support, and multiple new models in the ComfyUI plugin: blog

  • Spec V2 Critical bug fix: Fix out-of-index bug caused by torch garbage collection in speculative decoding v2, improving reliability of speculative verification: #18958

  • Deploying DeepSeek on GB300 NVL72: Optimization work for long-context inference using prefill-decode disaggregation and other SGLang features on NVIDIA's latest GB300 platform: blog

  • Bump AITER version to 0.1.10.post3: Support FP8 Prefill/Decode/KV Cache

  • Commit-to-Version Lookup in docs.sglang.io: Easily find the earliest official version that includes a given PR or commit, streamlining release tracking for users and developers: #18450, link
