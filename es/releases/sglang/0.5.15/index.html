jerga v0.5.15

Destacados

GLM-5.2 NVFP4, optimizado para producción: Nos tomamos tiempo en este ciclo para ajustar GLM-5.2 NVFP4 en Blackwell para optimizar el servicio de producción. Ahora se ejecuta a 500+ tok/s/usuario en 8x B300, 450 en 4x GB300 (bs=1). Ejecute GLM-5.2 con nuestro libro de recetas.

  • Especificación V2 de forma predeterminada: programación sin gastos generales a través de extensión de borrador DSA gráfica CUDA, sincronizaciones D2H/H2D eliminadas, operaciones de metadatos fusionados. +11 % de TPS de extremo a extremo (#29413, #29343, #29166, #29077).
  • IndexShare MTP: reutiliza el indexador top-k en los pasos del borrador, hasta 1,9 veces menos costo del paso del borrador en un contexto largo (#29959, #29787, #29654).
  • TopK V2: fusiona la selección top-k con la transformación de tabla de páginas, tiempo de ejecución k hasta 2048 (#30274, #26788).
  • Fusión del prólogo del indexador: 12 núcleos a 4, decodificación ~8 % más rápida en bs=1 (#27705).
  • GEMM: enrutador JIT especializado en formas GEMM + CuteDSL BF16 GEMM para Blackwell (#21531, #30117).
  • Ajuste automático de FlashInfer: ahora cubre gráficos de modelo preliminar (#29595). Compatibilidad con nuevos modelos: Hunyuan 3 (Hy3), modelo de razonamiento jerárquico (HRM-Text), NVIDIA LocateAnything-3B, Baidu Unlimited-OCR, JoyEcho A/V multidisparo, además de compatibilidad con NVFP4 Qwen3.6. Búsqueda web nativa (Exa): compatibilidad integrada con web_search respaldada por Exa (#29342). Breakable CUDA Graph activado de forma predeterminada: Breakable CUDA Graph ahora es la ruta de captura predeterminada, lo que reduce la sobrecarga de inicio del kernel por paso (#29458); El soporte completo de CUDA Graph para la fase de precarga llega como experimental (#27988). Núcleos de atención lineal (KDA/GDN): Nuevo backend de precarga de FlashKDA para atención lineal de KDA de puerta segura (#29472), además de decodificación de solo salida almacenada en búfer ReplaySSM para atención lineal (#28451). FlashInfer A2A para MoE enrutado: Agrega FlashInfer todo-a-todo con el corredor MoE flashinfer_trtllm_routed (#22394). Optimización DeepSeek-V4:
  • Optimiza la asignación del grupo de estados C128 utilizando el grupo de estados de solicitud (#28612).
  • El relleno previo disperso de FlashMLA ahora está habilitado de forma predeterminada para DeepSeek-V4, alcanzando >10% de ganancia de rendimiento en contexto largo. (#29775).
  • Compatibilidad con indexador no paginado para relleno previo de contexto largo, con >5 % de ganancia de rendimiento e2e.(#29619). Paralelismo de contexto de decodificación: el paralelismo de contexto de decodificación llega a los modelos MLA, incluidas las series DeepSeek V3 y Kimi K2 (#14194). Actualizaciones de dependencia: transformers pasó a 5.12.1 (#29393); tvm-ffi / sgl-deep-gemm / tilelang actualizado (#29554). y . Consulte el libro de recetas de DeepSeek-V4. release note completos por categoría a continuación.

sglang v0.5.15

Highlights

GLM-5.2 NVFP4, tuned for production: We took time this cycle to tune GLM-5.2 NVFP4 on Blackwell for optimized production serving. It now runs at 500+ tok/s/user on 8x B300, 450 on 4x GB300 (bs=1). Run GLM-5.2 with our cookbook.

  • Spec V2 by default: zero-overhead scheduling via CUDA-graphable DSA draft-extend, dropped D2H/H2D syncs, fused metadata ops. +11% end-to-end TPS (#29413, #29343, #29166, #29077).
  • IndexShare MTP: reuses the indexer top-k across draft steps, up to 1.9x lower draft-step cost at long context (#29959, #29787, #29654).
  • TopK V2: fuses top-k selection with the page-table transform, runtime k up to 2048 (#30274, #26788).
  • Indexer prologue fusion: 12 kernels to 4, ~8% faster decode at bs=1 (#27705).
  • GEMM: shape-specialized JIT router GEMM + CuteDSL BF16 GEMM for Blackwell (#21531, #30117).
  • FlashInfer autotune: now covers draft-model graphs (#29595).

New Model Support: Hunyuan 3 (Hy3), Hierarchical Reasoning Model (HRM-Text), NVIDIA LocateAnything-3B, Baidu Unlimited-OCR, JoyEcho multi-shot A/V, plus Qwen3.6 NVFP4 support.

Native web search (Exa): Built-in web_search support backed by Exa (#29342).

Breakable CUDA Graph on by default: Breakable CUDA Graph is now the default capture path, reducing per-step kernel-launch overhead (#29458); full CUDA Graph support for the prefill phase lands as experimental (#27988).

Linear-attention kernels (KDA / GDN): New FlashKDA prefill backend for safe-gate KDA linear attention (#29472), plus ReplaySSM buffered output-only decode for linear attention (#28451).

FlashInfer A2A for routed MoE: Adds FlashInfer all-to-all with the flashinfer_trtllm_routed MoE runner (#22394).

DeepSeek-V4 Optimization:

  • Optimizes C128 state-pool allocation using the request state pool (#28612).
  • FlashMLA sparse prefill is now enabled by default for DeepSeek-V4, reaching >10% throghput gain on long context. (#29775).
