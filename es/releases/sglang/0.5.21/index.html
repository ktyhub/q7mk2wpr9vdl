Funciones clave

  • Las instancias PD pueden cambiar entre precompletar y decodificar sobre la marcha, no es necesario reiniciar (#28403).
  • La caché de prefijo ahora se ejecuta en un núcleo Rust de forma predeterminada (#39627).
  • DeepSeek-V4.1 obtiene el primer token un 22 % más rápido en mensajes largos (#40352).
  • Kimi K3 obtiene un rendimiento de precarga 20.6 % mayor en servicio de PD (#40045).
  • GLM-5.3-Flash ahora se ejecuta en AMD MI355X, con FP8/MXFP4 MoE y decodificación especulativa MTP (#38546, #39341, #39778).
  • Resultados más precisos bajo PP, atención DP y CP, con comunicación de capa ahora manejada por SGLang (guía, #41557).
  • New Decisions API (/v1/decisions) convierte un LLM/VLM en un clasificador y anotador de baja latencia (docs, #41208).
  • La puntuación API (/v1/score) puntúa a todos los candidatos en una sola solicitud (#38965, #41188).
  • Ejecute MiniMax-H3 con SGLang Diffusion dentro de ComfyUI (#35990).

Cambios importantes y notas de actualización

  • El árbol de base unificado utiliza el núcleo Rust de forma predeterminada. Configuraciones que el núcleo Rust no admite el retorno automático a Python; configure SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python para forzar el núcleo Python en todas partes: #39627
  • La finalización fusionada de FlashInfer MoE está desactivada de forma predeterminada para mayor precisión numérica. Esto cuesta algo de latencia MoE W4A4; configure SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 para restaurar la finalización atómica fusionada: #40105
  • La decodificación PD ahora difiere la liberación de KV al cancelar de forma predeterminada en los backends Mooncake y NIXL, manteniendo las páginas hasta que se confirma cada rango de precarga (tiempo de espera de 30 s, SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT). Configure SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False para restaurar la liberación inmediata: #41023
  • Se rechazan las plantillas de chat proporcionadas por solicitud. Una clave chat_template dentro de chat_template_kwargs en /v1/chat/completions o /v1/tokenize ahora devuelve un error a menos que el servidor comience con --trust-request-chat-template; otros chat_template_kwargs no cambian: #28135
  • Se eliminan los puntos finales, variables de entorno y alias obsoletos. Utilice /model_info en lugar de /get_weight_version y /weight_version, /v1/loads en lugar de /get_load y POST /hicache/storage-backend/clear en lugar de /clear_hicache_storage_backend. Los alias SGLANG_NSA_* dan paso a SGLANG_DSA_*, SGLANG_ENABLE_SPEC_V2 desaparece, --elastic-ep-rejoin se convierte en --elastic-ep-join-mode recover, --kv-cache-dtype fp4_e2m1 se convierte en fp4_mx_block16 y python -m sglang.bench_offline_throughput / sglang.bench_one_batch pasan a sglang.benchmark.offline_throughput / sglang.benchmark.one_batch: #40795
  • Se eliminaron las implementaciones de caché de base heredadas. El árbol de base experimental de C++ (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) desapareció (#40775) y SGLANG_ENABLE_UNIFIED_RADIX_TREE ya no hace nada, aunque todavía imprime una advertencia de obsolescencia (#40780). El código que importa SWARadixCache, MambaRadixCache o HiRadixCache debe pasar a UnifiedRadixCache: #40313, #40787
  • Los procesadores logit personalizados deben devolver logits de forma completa. Un CustomLogitProcessor que devolvió una forma reducida como (1, vocab) y dependía de la transmisión ahora se genera en el momento de la decodificación. Los procesadores integrados no se ven afectados: #39234
  • Las actualizaciones de peso de RL se ejecutan dentro de una sesión. update_weights_from_tensor y update_weights_from_distributed deben llamarse entre begin_weight_update() y end_weight_update(). UpdateWeightsFromTensorReqInput.disable_draft_model se reemplaza por selector="target" y ChecksumInfo.parallelism_info ahora es una lista con una entrada por función: #40777
  • Los captadores de estado paralelo están en desuso. Ya no se reexportan desde sglang.srt.distributed; leer grupos a través de get_parallel() (por ejemplo get_parallel().tp_group) o importar desde parallel_state directamente: #40342, #40344, #40707
  • Las imágenes de Ascend A2 (910b) ya no están publicadas. Las imágenes de lanzamiento y nocturnas se envían solo para A3 y 950 (A5), en CANN 9.1.0 con Python 3.12: #40524

Breaking Changes & Upgrade Notes

  • The unified radix tree uses the Rust core by default. Configurations the Rust core does not support fall back to Python automatically; set SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python to force the Python core everywhere: #39627
  • FlashInfer MoE fused finalize is off by default for numerical accuracy. This costs some W4A4 MoE latency; set SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 to restore the fused atomic finalize: #40105
  • PD decode now defers KV release on abort by default on the Mooncake and NIXL backends, holding pages until every prefill rank acks (30 s timeout, SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT). Set SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False to restore immediate release: #41023
  • Request-supplied chat templates are rejected. A chat_template key inside chat_template_kwargs on /v1/chat/completions or /v1/tokenize now returns an error unless the server starts with --trust-request-chat-template; other chat_template_kwargs are unchanged: #28135
  • Deprecated endpoints, env vars, and aliases are removed. Use /model_info instead of /get_weight_version and /weight_version, /v1/loads instead of /get_load, and POST /hicache/storage-backend/clear instead of /clear_hicache_storage_backend. SGLANG_NSA_* aliases give way to SGLANG_DSA_*, SGLANG_ENABLE_SPEC_V2 is gone, --elastic-ep-rejoin becomes --elastic-ep-join-mode recover, --kv-cache-dtype fp4_e2m1 becomes fp4_mx_block16, and python -m sglang.bench_offline_throughput / sglang.bench_one_batch move to sglang.benchmark.offline_throughput / sglang.benchmark.one_batch: #40795
  • Legacy radix cache implementations are removed. The experimental C++ radix tree (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) is gone (#40775), and SGLANG_ENABLE_UNIFIED_RADIX_TREE no longer does anything, though it still prints a deprecation warning (#40780). Code importing SWARadixCache, MambaRadixCache, or HiRadixCache must move to UnifiedRadixCache: #40313, #40787
  • Custom logit processors must return full-shape logits. A CustomLogitProcessor that returned a reduced shape such as (1, vocab) and relied on broadcasting now raises at decode time. The built-in processors are unaffected: #39234
  • RL weight updates run inside a session. update_weights_from_tensor and update_weights_from_distributed must be called between begin_weight_update() and end_weight_update(). UpdateWeightsFromTensorReqInput.disable_draft_model is replaced by selector="target", and ChecksumInfo.parallelism_info is now a list with one entry per role: #40777
  • Parallel-state getters are deprecated. They are no longer re-exported from sglang.srt.distributed; read groups through get_parallel() (for example get_parallel().tp_group) or import from parallel_state directly: #40342, #40344, #40707
  • Ascend A2 (910b) images are no longer published. Release and nightly images ship for A3 and 950 (A5) only, on CANN 9.1.0 with Python 3.12: #40524
