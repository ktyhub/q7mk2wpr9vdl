🚀 ¡Lanzamiento del SMG v0.3.1!

Nos complace anunciar SMG v0.3.1, una versión innovadora con una mejora de rendimiento de 10 a 12 veces y una reducción de memoria del 99 % en enrutamiento con reconocimiento de caché, ¡además de seguridad de nivel empresarial!

🌲 Árbol Radix / Enrutamiento compatible con caché: 10 a 12 veces más rápido + 99 % menos memoria ⚡

Revisión completa de la optimización de nuestro motor de enrutamiento con reconocimiento de caché con sorprendentes ganancias de rendimiento y memoria:

Mejoras de rendimiento

  • Nuestro enrutamiento con reconocimiento de caché ahora puede manejar más de 216 000 inserciones de caché por segundo (frente a 18 900), con una latencia que cae de 52.9 microsegundos a solo 4.6 microsegundos por operación.
  • Para la coincidencia de prefijos en 10 000 entradas de árbol, el rendimiento saltó de 41 000 a 124 000 operaciones por segundo.
  • Bajo carga simultánea con 64 subprocesos, el sistema procesa 474.000 operaciones por segundo, una mejora de 7,9 veces con respecto a las 59.000 operaciones/seg anteriores.

Procesamiento de datos

  • Las operaciones INSERT ahora procesan 440 MB/s (antes 38 MB/s),
  • Las operaciones MATCH manejan 253 MB/s (antes 83 MB/s).

Mejoras en la memoria:

  • ~99 % de reducción de memoria por nodo del árbol:
  • Antes: ~180 KB por nodo (configuración predeterminada de DashMap en máquinas de 170 núcleos)
  • Después: ~1.4 KB por nodo Resultado: ¡Implemente 100 veces más entradas de caché en el mismo espacio de memoria! Para una implementación típica con 10 000 prefijos almacenados en caché, el uso de memoria cae de ~1.8 GB a solo ~14 MB, lo que libera recursos para cargas de trabajo de inferencia reales. Impacto: el enrutamiento basado en caché ahora es entre 10 y 12 veces más rápido y utiliza un 99 % menos de memoria. Esto es fundamental para implementaciones multiinquilino a gran escala.

🔐 Autenticación JWT/OIDC

Seguridad de nivel de producción para los API del plano de control con soporte nativo para proveedores de OIDC estándar de la industria: Google, Azure, Oracle, GitHub y más. Proteja la gestión de tokenizadores, el registro de trabajadores y los puntos finales de administración con la infraestructura de autenticación empresarial que ya utiliza. Crítico para implementaciones empresariales: integre perfectamente SMG en sus sistemas de gestión de acceso e identidad existentes.

📊 Clasificación API Soporte

¡Soporte nativo para cargas de trabajo de clasificación! Implemente y proporcione modelos de clasificación junto con su flota de inferencia existente con etapas de canalización y tipos de protocolos dedicados.

✨ Funciones adicionales

  • Equilibrio de carga PrefixHash: nueva política de equilibrio de carga con reconocimiento de caché de KV que utiliza hash de prefijo para mejorar las tasas de aciertos de caché en entornos multiinquilino.
  • Analizador Nemotron Nano V3
  • Métricas de antigüedad de solicitudes en vuelo: realice un seguimiento de la antigüedad de las solicitudes en vuelo para una mejor observabilidad y monitoreo de SLA.

🛠️ Mejoras

Experiencia del desarrollador:

  • Argumentos organizados de CLI en grupos lógicos.
  • Objetivos de registro acortados (sgl_model_gateway → smg)
  • Pruebas integrales de corrección de incrustación contra HuggingFace
  • Generar automáticamente archivos protobuf durante la construcción de la rueda.

Fiabilidad:

  • Se corrigió el enrutamiento IGW para trabajadores externos de OpenAI.
  • Evitar problemas de procesos huérfanos
  • Prevenir posibles bloqueos en el manejo de subprocesos.
  • Utilice 504 Gateway Timeout para tiempos de espera ascendentes (semántica HTTP adecuada)

🐛 Corrección de errores

  • Se corrigió el fallo en la verificación de salud del trabajador al incorporarlo.
  • Se corrigió el tokenizador para que coincida con el manejo especial de tokens de los transformadores.
  • Se solucionó el problema de renderizado del depósito de edad.
  • Se corrigió la lista blanca de encabezados HTTP del enrutador que no es PD
  • Se corrigió el prefijo de clasificación duplicado en el ID de respuesta.
  • Se corrigieron errores de prueba WASM en máquinas con muchos núcleos.

⚡ Creado para la velocidad. Diseñado para escala. Probado en producción.

sglang gateway-v0.3.1

🚀 SMG v0.3.1 Released!

We're excited to announce SMG v0.3.1 – a game-changing release with 10-12x performance improvement and 99% memory reduction in cache-aware routing, plus enterprise-grade security!

🌲 Radix Tree / Cache-Aware Routing: 10-12x Faster + 99% Less Memory ⚡

Complete optimization overhaul of our cache-aware routing engine with stunning performance and memory gains:

Performance Improvements

  • Our cache-aware routing can now handle over 216,000 cache insertions per second (up from 18,900), with latency dropping from 52.9 microseconds to just 4.6 microseconds per operation.
  • For prefix matching across 10,000 tree entries, throughput jumped from 41,000 to 124,000 operations per second.
  • Under concurrent load with 64 threads, the system processes 474,000 operations per second – a 7.9x improvement over the previous 59,000 ops/sec.

Data processing

  • INSERT operations now process 440 MB/s (up from 38 MB/s),
  • MATCH operations handle 253 MB/s (up from 83 MB/s).

Memory Improvements:

  • ~99% memory reduction per tree node:
  • Before: ~180 KB per node (DashMap default config on 170-core machines)
  • After: ~1.4 KB per node Result: Deploy 100x more cache entries in the same memory footprint! For a typical deployment with 10,000 cached prefixes, memory usage drops from ~1.8 GB to just ~14 MB – freeing up resources for actual inference workloads. Impact: Cache-aware routing is now 10-12x faster and uses 99% less memory. This is critical for large-scale multi-tenant deployments.

🔐 JWT/OIDC Authentication

Production-grade security for control plane APIs with native support for industry-standard OIDC providers: Google, Azure, Oracle, GitHub, and more. Protect tokenizer management, worker registration, and admin endpoints with enterprise authentication infrastructure you already use. Critical for enterprise deployments – seamlessly integrate SMG into your existing identity and access management systems.

📊 Classification API Support

Native support for classification workloads! Deploy and serve classification models alongside your existing inference fleet with dedicated pipeline stages and protocol types.

✨ Additional Features

  • PrefixHash Load Balancing: New KV cache-aware load balancing policy using prefix hashing for improved cache hit rates in multi-tenant environments.
  • Nemotron Nano V3 Parser
  • In-Flight Request Age Metrics: Track request age in-flight for better observability and SLA monitoring.

🛠️ Enhancements

Developer Experience:

  • Organized CLI arguments into logical groups
  • Shortened logging targets (sgl_model_gateway → smg)
  • Comprehensive embedding correctness tests against HuggingFace
  • Auto-generate protobuf files during wheel build

Reliability:

  • Fix IGW routing for external OpenAI workers
  • Work around orphan process problems
  • Prevent potential hangs in subprocess handling
  • Use 504 Gateway Timeout for upstream timeouts (proper HTTP semantics)

🐛 Bug Fixes

  • Fixed embedding worker health check crash
  • Fixed tokenizer to match transformers special token handling
  • Fixed age bucket rendering issue
  • Fixed non-PD router HTTP header whitelist
  • Fixed duplicate classify prefix in response ID
  • Fixed WASM test errors on machines with many cores

⚡ Built for speed. Engineered for scale. Production-proven.
