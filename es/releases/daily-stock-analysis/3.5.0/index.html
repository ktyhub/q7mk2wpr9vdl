análisis_de_stock_diario v3.5.0

Agregado

  • 📊 Cajón de informes completos de la interfaz de usuario web (Correcciones #214): la página de historial agrega el botón "Informe completo" para mostrar el informe completo del análisis de Markdown en un cajón lateral; nuevo punto final GET /api/v1/history/{record_id}/markdown
  • 📊 Seguimiento de costos de LLM: todas las llamadas de LLM (análisis, agente, revisión de mercado) registradas en la tabla llm_usage; El nuevo punto final GET /api/v1/usage/summary?period=today|month|all devuelve el uso agregado de tokens por tipo y modelo de llamada.
  • 🔍 Proveedor de búsqueda SearXNG (Correcciones #550): respaldo de búsqueda autohospedado sin cuotas; prioridad: Bocha > Tavily > Brave > SerpAPI > MiniMax > SearXNG
  • 🔍 Proveedor de búsqueda web MiniMax — MiniMaxSearchProvider con disyuntor (3 fallas → 300 segundos de enfriamiento) y filtrado de tiempo dual; configurado a través de MINIMAX_API_KEYS
  • 🤖 Descubrimiento de modelos de agentes API: GET /api/v1/agent/models devuelve implementaciones de modelos disponibles (primario/alternativo/fuente/api_base) para el selector de modelos de interfaz de usuario web
  • 🤖 Exportación y envío del chat del agente (#495): exporta la conversación a un archivo .md; enviar a canales de notificación configurados; nuevo POST /api/v1/agent/chat/send
  • 🤖 Ejecución en segundo plano del agente (#495): el análisis continúa al cambiar de página; notificación de insignia al finalizar; cancelar automáticamente la transmisión en progreso al cambiar de sesión
  • 📝 Report Engine P0: validación del esquema Pydantic para LLM JSON; Plantillas Jinja2 (markdown/wechat/brief) con respaldo heredado; comprobaciones de integridad del contenido con reintento; modo breve (REPORT_TYPE=brief); comparación de señales históricas
  • 📦 Importación inteligente: importación de múltiples fuentes desde imagen/CSV/Excel/clipboard; Vision LLM extrae código+nombre+confianza; nombre → resolución de código (mapa local + pinyin + AkShare); confirmación por niveles de confianza
  • ⚙️ Configuración GitHub Actions LiteLLM: el flujo de trabajo admite LITELLM_CONFIG/LITELLM_CONFIG_YAML para una configuración flexible del proveedor de IA
  • ⚙️ Refactorización del motor de configuración y sistema API (#602): registro de configuración unificado, validación y exposición de API
  • 📖 Guía de configuración LLM: nuevo docs/LLM_CONFIG_GUIDE.md que cubre configuración de 3 niveles, inicio rápido, Vision/Agent/solución de problemas

Fijo

  • 🐛 analyze_trend siempre informa que no hay datos históricos (#600): ahora obtiene datos de DB/DataFetcher en lugar de get_analysis_context roto
  • 🐛 Retroceso de la estructura del chip cuando LLM lo omite (#589): se completa automáticamente a partir de los datos del chip de la fuente de datos para una visualización consistente en todos los modelos.
  • 🐛 Los puntos de francotirador del historial muestran texto sin formato (#452): prioriza las cadenas originales sobre los valores numéricos comprimidos
  • 🐛 GitHub Acciones ENABLE_CHIP_DISTRIBUTION configurables (#617): ya no está codificado, admite anulación de vars/secrets
  • 🐛 El guardado .env conserva los comentarios y las líneas en blanco: la configuración web ya no destruye el formato .env
  • 🐛 Correcciones en el descubrimiento del modelo de agente: el modo heredado incluye proveedores nativos de LiteLLM; detección de fuente alineada con el tiempo de ejecución; Las implementaciones alternativas ya no se expanden por clave.
  • 🐛 Semántica del cierre anterior de las acciones de Stooq US: ya no hace un mal uso del precio de apertura como cierre anterior
  • 🐛 Regresión de captación previa de nombres de acciones: prioriza el STOCK_NAME_MAP local antes que las consultas remotas
  • 🐛 Cálculo del límite arriba/abajo de AkShare (#555) — estadísticas de análisis de mercado fijo
  • 🐛 Índice de campo fuente de AkShare Tencent y mapeo de cotizaciones de ETF (#579)
  • 🐛 Paginación de caché de nombre de stock de Pytdx (#573): evita el desbordamiento de caché
  • 🐛 fragmentación de informes de gran tamaño de PushPlus (#489): segmenta automáticamente el contenido extenso
  • 🐛 Cancelación y cambio de chat de agente (#495): la cancelación ya no se informa erróneamente como falla; El cambio rápido ya no sobrescribe el estado de la transmisión.
  • 🐛 Estado de búsqueda MiniMax en el comando /status (#587)
  • 🐛 config_registry duplicado BOCHA_API_KEYS: se eliminó la entrada de dictado duplicada que sobrescribía silenciosamente la configuración

Cambiado

  • 🔎 Observabilidad de fallas del buscador: registra el inicio/éxito/fallo del registro con el tiempo transcurrido, transiciones de conmutación por error; Efinance/Akshare incluye puntos finales ascendentes y categorías de fallas clasificadas
  • ♻️ Resiliencia y limpieza de fuentes de datos (#602): optimización de la cadena de respaldo
  • ♻️ Extensión de respuesta API de extracto de imagen — nuevo campo items (código/nombre/confianza); codes preservado para compatibilidad con versiones anteriores
  • ♻️ Importar mensajes de error de análisis: motivos de error específicos para Excel/CSV; registro mejorado con tipo y tamaño de archivo

Documentos

  • 📖 Guía de configuración de LLM refactorizada para mayor claridad (#583)
  • 📖 image-extract-prompt.md con documentación rápida completa
  • 📖 Documentación TTL de caché alternativa de AkShare

daily_stock_analysis v3.5.0

Added

  • 📊 Web UI full report drawer (Fixes #214) — history page adds "Full Report" button to display the complete Markdown analysis report in a side drawer; new GET /api/v1/history/{record_id}/markdown endpoint
  • 📊 LLM cost tracking — all LLM calls (analysis, agent, market review) recorded in llm_usage table; new GET /api/v1/usage/summary?period=today|month|all endpoint returns aggregated token usage by call type and model
  • 🔍 SearXNG search provider (Fixes #550) — quota-free self-hosted search fallback; priority: Bocha > Tavily > Brave > SerpAPI > MiniMax > SearXNG
  • 🔍 MiniMax web search provider — MiniMaxSearchProvider with circuit breaker (3 failures → 300s cooldown) and dual time-filtering; configured via MINIMAX_API_KEYS
  • 🤖 Agent models discovery API — GET /api/v1/agent/models returns available model deployments (primary/fallback/source/api_base) for Web UI model selector
  • 🤖 Agent chat export & send (#495) — export conversation to .md file; send to configured notification channels; new POST /api/v1/agent/chat/send
  • 🤖 Agent background execution (#495) — analysis continues when switching pages; badge notification on completion; auto-cancel in-progress stream on session switch
  • 📝 Report Engine P0 — Pydantic schema validation for LLM JSON; Jinja2 templates (markdown/wechat/brief) with legacy fallback; content integrity checks with retry; brief mode (REPORT_TYPE=brief); history signal comparison
  • 📦 Smart import — multi-source import from image/CSV/Excel/clipboard; Vision LLM extracts code+name+confidence; name→code resolver (local map + pinyin + AkShare); confidence-tiered confirmation
  • ⚙️ GitHub Actions LiteLLM config — workflow supports LITELLM_CONFIG/LITELLM_CONFIG_YAML for flexible AI provider configuration
  • ⚙️ Config engine refactor & system API (#602) — unified config registry, validation and API exposure
  • 📖 LLM configuration guide — new docs/LLM_CONFIG_GUIDE.md covering 3-tier config, quick start, Vision/Agent/troubleshooting

Fixed

  • 🐛 analyze_trend always reports No historical data (#600) — now fetches from DB/DataFetcher instead of broken get_analysis_context
  • 🐛 Chip structure fallback when LLM omits it (#589) — auto-fills from data source chip data for consistent display across models
  • 🐛 History sniper points show raw text (#452) — prioritizes original strings over compressed numeric values
  • 🐛 GitHub Actions ENABLE_CHIP_DISTRIBUTION configurable (#617) — no longer hardcoded, supports vars/secrets override
  • 🐛 .env save preserves comments and blank lines — Web settings no longer destroys .env formatting
  • 🐛 Agent model discovery fixes — legacy mode includes LiteLLM-native providers; source detection aligned with runtime; fallback deployments no longer expanded per-key
  • 🐛 Stooq US stock previous close semantics — no longer misuses open price as previous close
  • 🐛 Stock name prefetch regression — prioritizes local STOCK_NAME_MAP before remote queries
  • 🐛 AkShare limit-up/down calculation (#555) — fixed market analysis statistics
  • 🐛 AkShare Tencent source field index & ETF quote mapping (#579)
  • 🐛 Pytdx stock name cache pagination (#573) — prevents cache overflow
  • 🐛 PushPlus oversized report chunking (#489) — auto-segments long content
  • 🐛 Agent chat cancel & switch (#495) — cancel no longer misreports as failure; fast switch no longer overwrites stream state
  • 🐛 MiniMax search status in /status command (#587)
  • 🐛 config_registry duplicate BOCHA_API_KEYS — removed duplicate dict entry that silently overwrote config

Changed

  • 🔎 Fetcher failure observability — logs record start/success/failure with elapsed time, failover transitions; Efinance/Akshare include upstream endpoint and classified failure categories
  • ♻️ Data source resilience & cleanup (#602) — fallback chain optimization
  • ♻️ Image extract API response extension — new items field (code/name/confidence); codes preserved for backward compatibility
  • ♻️ Import parse error messages — specific failure reasons for Excel/CSV; improved logging with file type and size

Docs

  • 📖 LLM config guide refactored for clarity (#583)
  • 📖 image-extract-prompt.md with full prompt documentation
  • 📖 AkShare fallback cache TTL documentation
