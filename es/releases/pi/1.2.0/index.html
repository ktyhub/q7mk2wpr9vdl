#piv1.2.0

Nuevas características

  • Listas de modelos OpenRouter por clave: con una clave OpenRouter, Pi enumera solo los modelos que esa clave puede usar, con el tamaño del contexto de la clave, la salida máxima y los precios, incluidos los puntos finales regionales establecidos en models.json. Consulte OpenRouter.
  • Esquemas de configuración publicados: agregue $schema a settings.json, models.json, combinaciones de teclas y temas para la validación y finalización del editor. Consulte Configuración, Modelos, Combinaciones de teclas y Temas.
  • Copias de la placa Cli en sesiones remotas: PI_CLIPBOARD_OSC52=1 envía texto copiado a una placa client remota cuando Pi no puede detectar la sesión remota, como un multiplexor conectado desde otra máquina. Consulte Configuración del proceso Pi.
  • Mejoras en el modo de código: las declaraciones de herramientas muestran restricciones de entrada como entero, mínimo/máximo y predeterminado, y las filas del modo de código muestran el tiempo total y transcurrido. Consulte Modo de código.
  • before_agent_start para ejecuciones activadas por extensión: las ejecuciones iniciadas por pi.sendMessage(..., { triggerTurn: true }) pasan por la misma configuración que las indicaciones. Consulte Eventos y simultaneidad.

Cambios importantes

  • Esquemas de configuración generados publicados para modelos, configuraciones, combinaciones de teclas y temas en https://pi.dev/schemas/*.schema.json. El esquema del tema se trasladó a https://pi.dev/schemas/theme.schema.json; Los temas cargados durante el inicio ahora reciben la misma validación de esquema que las recargas posteriores. Actualice las referencias del tema $schema, defina colores reutilizables en vars y elimine metadatos no compatibles (#9880, #10751 por @christianklotz)
  • Se modificó before_agent_start para que también se active en ejecuciones iniciadas por pi.sendMessage(..., { triggerTurn: true }) mientras está inactivo. BeforeAgentStartEvent ahora es una unión de messageType: los eventos "user" llevan prompt y images, y los eventos "custom" llevan el message inicial y no prompt. Los mensajes devueltos por los controladores se agregan a ambos tipos de ejecución y los mensajes deliverAs: "nextTurn" pendientes se entregan con la ejecución de mensajes personalizados. Los controladores que deben actuar solo según las indicaciones del usuario deben verificar event.messageType === "user" (#10267, #5581, #10739 por @davidbrai)
  • Se cambió la sesión para que cuente como ocupada mientras comienza una ejecución, incluso durante los controladores before_agent_start: ctx.isIdle() es falso, pi.sendMessage() se pone en cola en la ejecución inicial en lugar de iniciar una segunda ejecución que falló con "El agente ya está procesando", pi.sendUserMessage() requiere deliverAs y una cancelación solicitada mientras tanto cancela la ejecución una vez que comienza (#10739 por @davidbrai)
  • Se modificó pi mcp list --json para informar resources: true para servidores que ofrecen recursos en lugar de recuentos de resources y resourceTemplates; Pi ya no enumera recursos al conectarse (#10526)

Agregado

  • Se agregó reachesTools a las definiciones de herramientas, para que las herramientas que llegan a otras herramientas (como codemode y tool_search) declaren a qué herramientas puede llegar una llamada; la extensión MCP lo utiliza para esperar a los servidores que necesita una llamada y para decidir si una herramienta codemode o tool_search de reemplazo puede llegar a las herramientas MCP
  • Se agregó aliases a los espacios de nombres de herramientas; describeNamespace() de codemode y la opción namespace de searchTools() coinciden, y los espacios de nombres MCP usan el nombre del servidor
  • Se agregaron listas de modelos OpenRouter por clave: con una clave OpenRouter, Pi enumera solo los modelos de chat que esa clave puede usar, con el tamaño del contexto de la clave, la salida máxima y los precios, incluidas las barreras de seguridad y los puntos finales regionales establecidos como la URL base en models.json. La lista se guarda y se utiliza sin conexión (#10353, #10672 por @davidbrai)
  • Se agregó PI_CLIPBOARD_OSC52=1 para enviar texto copiado al terminal con OSC 52 después de la escritura de la placa cli local, de modo que las copias lleguen a la placa cli de un client remoto cuando Pi no puede detectar la sesión remota, como conexiones de multiplexor desde otra máquina o demonios IDE remotos (#10826, #10835, #10114)
  • Se agregó el tiempo transcurrido mientras se ejecuta un script en modo de código y su tiempo total una vez finalizado en la fila de la herramienta de modo de código, como filas bash (#10708)

Cambiado

  • Se cambió la configuración de showHardwareCursor para usar solo el cursor del terminal en lugar de dibujar también el cursor de video inverso de Pi.
  • Se cambiaron las declaraciones de la herramienta de modo de código para mostrar restricciones de entrada como entero, mínimo/máximo, longitud, patrón y valor predeterminado como etiquetas @ en los comentarios de propiedad, de modo que los scripts los vean sin que la herramienta los repita en las descripciones (#10707)
  • Se cambiaron las declaraciones de modo de código de las herramientas MCP para detallar el tipo de resultado (content, structuredContent, isError) en lugar de hacer referencia a CallToolResult<T>, que describeTool(), searchTools() y ALL_TOOLS mostraban sin definirlo; la descripción del modo de código ya no incluye los tipos de MCP compartidos
  • Se modificó serializeConversation() (compactación, resúmenes de ramas, informes de errores) para omitir bloques de pensamiento; El pensamiento repetido a menudo no está en el contexto real, por lo que incluirlo podría hacer que una solicitud de resumen sea más grande que el contexto que resume y fallar.

Fijo

  • Se corrigió el modo de código que ignoraba una línea // @options: que no es la primera línea del script, que ejecutaba el script sin el timeout_ms solicitado; la llamada ahora falla con un error antes de que se ejecute el script (#10631)
  • Se corrigió que las transmisiones de Mistral fueran abortadas a mitad de generación (por ejemplo, durante un pensamiento prolongado) después del tiempo de espera de la solicitud; el tiempo de espera ahora se aplica solo a la espera de encabezados de respuesta (#10609)
  • Se corrigió un AGENTS.md con enlace simbólico en un árbol de trabajo de git anidado dentro de su repositorio principal que causaba que no se cargara ningún archivo de contexto del proyecto (#10681)
  • Se corrigió la descripción de la herramienta del modo de código que afirmaba que cada llamada fallida a la herramienta era rechazada; una herramienta que declara un esquema de salida también se resuelve con su valor en caso de falla (por ejemplo, bash con una salida distinta de cero)
  • Se corrigieron las ejecuciones iniciadas por pi.sendMessage(..., { triggerTurn: true }) que eliminaban las secciones de mensajes del sistema agregadas en before_agent_start después de su primera llamada a la herramienta, lo que cambió el mensaje a mitad de ejecución y rompió el caché de mensajes del proveedor dos veces por ejecución (#10267, #10739 por @davidbrai)
  • Se corrigió el modo de código que bloqueaba el proceso durante segundos o minutos después de secuencias de comandos con muchas llamadas text(); unir los elementos de salida era cuadrático (#10678)
  • Se corrigió el modo de impresión (-p) que salía de 0 sin previo aviso cuando la respuesta final se cortaba en el límite del token de salida del modelo; ahora imprime el texto parcial, escribe una advertencia en stderr y sale 1 (#10799)
  • Se corrigieron los documentos pi mcp login --help y CLI que describían --timeout como solo la espera del navegador; limita todo el inicio de sesión (#10636)
  • Se corrigió que ~ no se expandiera en las entradas !pattern, +path y -path de las configuraciones extensions, skills, prompts y themes, por lo que entradas como !~/skills/pdf no coincidían con nada (#10765)
  • Se corrigieron los servidores MCP con recursos que no registraban herramientas hasta que se enumeraran todos los recursos; Pi ya no enumera los recursos al conectarse, por lo que /mcp y pi mcp list muestran que un servidor ofrece recursos en lugar de contarlos (#10526)
  • Se corrigió el error en las llamadas a la herramienta MCP cuando el servidor devuelve contenido estructurado que no es un objeto (una matriz, null o una primitiva, según lo permite MCP 2026-07-28); Las declaraciones de modo de código de herramientas MCP sin un esquema de salida ahora escriben structuredContent como unknown en lugar de un objeto (#10416)
  • Se corrigió el error de lectura o escritura de auth.json en Windows con EPERM cuando la carpeta de bloqueo anterior aún se estaba eliminando; Pi ahora reintenta brevemente antes de informar el error (#10801)
  • Se corrigieron los modelos de enrutador OpenRouter como openrouter/auto que mostraban un costo de -$1,000,000 por 1 millón de tokens; Los precios de marcador de posición negativos de OpenRouter ahora son 0 (#10672 por @davidbrai)
  • Se corrigió que las solicitudes antrópicas fallaran cuando el proveedor rechaza el conjunto estricto de herramientas para el tamaño de la gramática, el recuento de herramientas o los límites de unión; Pi ahora reintenta una vez con las herramientas preferidas no estrictas (#10409)
  • Se corrigió "El proveedor ascendente devolvió un error" que no se reintentaba como un error de proveedor transitorio (#10842)
  • Se corrigieron superposiciones enfocadas en pantalla completa que bloqueaban el desplazamiento de la transcripción con la rueda del mouse (#10769)
  • Se corrigió el color fragmentado del terminal en las respuestas que filtraban valores hexadecimales en el mensaje y abrían el editor externo (informes relacionados: #10256, #10657)
  • Se corrigieron las imágenes en línea que no se representaban en Herdr desde 1.1.0 (#10774 por @ogulcancelik)
  • Se corrigieron las combinaciones de teclas que nombran un símbolo desplazado, como + o ctrl++, que no coinciden según el protocolo de teclado Kitty o modifican otras teclas (#9880 por @christianklotz)
  • Se corrigió el indicador de estado de compactación incrustado en un editor personalizado usando los colores apagados predeterminados en lugar del borde del editor o el color del nivel de pensamiento, como lo hace el indicador de trabajo (#10809, #10810 por @Jay-Madden)
  • Se corrigieron las llamadas a la herramienta MCP que se cancelaron o se agotó el tiempo de espera mientras se esperaba una actualización de OAuth y que aún se enviaban al servidor una vez finalizada la actualización (#10598)
  • Se corrigió el inicio de sesión de MCP OAuth al aceptar una respuesta de autorización con un parámetro iss que no se podía verificar porque no se descubrieron metadatos del servidor de autorización; El inicio de sesión ahora falla porque el emisor no coincide. Reportado por @AizenvoltPrime
  • Se corrigió el error del modo de código con un error de puente roto cuando Pi se ejecuta bajo node --watch en el nodo 24 o 26 (#10725)

Eliminado

  • Se eliminó el servidor experimental inédito, client, y la pila de complementos (src/experimental, src/cli/experimental) y sus exportaciones de código fuente únicamente ./client y ./experimental/plugin; nada de eso era parte del paquete publicado. Los paquetes @earendil-works/pi-client, @earendil-works/pi-protocol y @earendil-works/pi-server que utilizó se eliminaron y ya no se publican
  • Se eliminó la dependencia de @earendil-works/chord.

pi v1.2.0

New Features

  • Per-key OpenRouter model lists: with an OpenRouter key, Pi lists only the models that key may use, with the key's context size, max output, and prices, including regional endpoints set in models.json. See OpenRouter.
  • Published configuration schemas: add $schema to settings.json, models.json, keybindings, and themes for editor validation and completion. See Settings, Models, Keybindings, and Themes.
  • Clipboard copies over remote sessions: PI_CLIPBOARD_OSC52=1 sends copied text to a remote client's clipboard when Pi cannot detect the remote session, such as a multiplexer attached from another machine. See Pi Process Configuration.
  • Codemode improvements: tool declarations show input constraints such as integer, minimum/maximum, and default, and codemode rows show elapsed and total time. See Codemode.
  • before_agent_start for extension-triggered runs: runs started by pi.sendMessage(..., { triggerTurn: true }) go through the same setup as prompts. See Events and concurrency.

Breaking Changes

  • Published generated configuration schemas for models, settings, keybindings, and themes at https://pi.dev/schemas/*.schema.json. The theme schema moved to https://pi.dev/schemas/theme.schema.json; themes loaded during startup now receive the same schema validation as later reloads. Update theme $schema references, define reusable colors under vars, and remove unsupported metadata (#9880, #10751 by @christianklotz)
  • Changed before_agent_start to also fire for runs started by pi.sendMessage(..., { triggerTurn: true }) while idle. BeforeAgentStartEvent is now a union on messageType: "user" events carry prompt and images, and "custom" events carry the starting message and no prompt. Messages returned by handlers are added to both kinds of run, and pending deliverAs: "nextTurn" messages are delivered with the custom-message run. Handlers that should act only on user prompts must check event.messageType === "user" (#10267, #5581, #10739 by @davidbrai)
  • Changed the session to count as busy while a run starts, including during before_agent_start handlers: ctx.isIdle() is false, pi.sendMessage() queues into the starting run instead of starting a second run that failed with "Agent is already processing", pi.sendUserMessage() requires deliverAs, and an abort requested meanwhile aborts the run once it starts (#10739 by @davidbrai)
  • Changed pi mcp list --json to report resources: true for servers that offer resources instead of resources and resourceTemplates counts; Pi no longer lists resources when connecting (#10526)

Added

  • Added reachesTools to tool definitions, so tools that reach other tools (such as codemode and tool_search) declare which tools a call may reach; the MCP extension uses it to wait for the servers a call needs and to decide whether a replacement codemode or tool_search tool can reach MCP tools
  • Added aliases to tool namespaces; codemode's describeNamespace() and the namespace option of searchTools() match them, and MCP namespaces use the server name
  • Added per-key OpenRouter model lists: with an OpenRouter key, Pi lists only the chat models that key may use, with the key's context size, max output, and prices, including guardrails and regional endpoints set as the base URL in models.json. The list is saved and used offline (#10353, #10672 by @davidbrai)
  • Added PI_CLIPBOARD_OSC52=1 to send copied text to the terminal with OSC 52 after the local clipboard write, so copies reach a remote client's clipboard when Pi cannot detect the remote session, such as multiplexer attaches from another machine or remote IDE daemons (#10826, #10835, #10114)
  • Added elapsed time while a codemode script runs and its total time once finished to the codemode tool row, like bash rows (#10708)

Changed

  • Changed the showHardwareCursor setting to use only the terminal cursor instead of also drawing Pi's reverse-video cursor
  • Changed codemode tool declarations to show input constraints such as integer, minimum/maximum, length, pattern, and default as @ tags on property comments, so scripts see them without the tool repeating them in descriptions (#10707)
  • Changed codemode declarations of MCP tools to spell out the result type (content, structuredContent, isError) instead of referring to CallToolResult<T>, which describeTool(), searchTools(), and ALL_TOOLS showed without defining it; the codemode description no longer includes the shared MCP types
  • Changed serializeConversation() (compaction, branch summaries, bug reports) to omit thinking blocks; replayed thinking is often not in the live context, so including it could make a summarization request larger than the context it summarizes and fail

Fixed

  • Fixed codemode ignoring a // @options: line that is not the first line of the script, which ran the script without the requested timeout_ms; the call now fails with an error before the script runs (#10631)
  • Fixed Mistral streams being aborted mid-generation (e.g. during long thinking) after the request timeout; the timeout now applies only to waiting for response headers (#10609)
  • Fixed a symlinked AGENTS.md in a git worktree nested inside its main repo causing no project context file to load (#10681)
  • Fixed the code mode tool description claiming every failed tool call rejects; a tool that declares an output schema resolves with its value on failure too (e.g. bash with a nonzero exit)
  • Fixed runs started by pi.sendMessage(..., { triggerTurn: true }) removing system prompt sections added in before_agent_start after their first tool call, which changed the prompt mid-run and broke the provider prompt cache twice per run (#10267, #10739 by @davidbrai)
  • Fixed codemode blocking the process for seconds to minutes after scripts with many text() calls; joining the output items was quadratic (#10678)
  • Fixed print mode (-p) exiting 0 without a warning when the final response was cut off at the model's output token limit; it now prints the partial text, writes a warning to stderr, and exits 1 (#10799)
  • Fixed pi mcp login --help and the CLI docs describing --timeout as only the wait for the browser; it limits the whole sign-in (#10636)
  • Fixed ~ not being expanded in !pattern, +path, and -path entries of the extensions, skills, prompts, and themes settings, so entries like !~/skills/pdf matched nothing (#10765)
  • Fixed MCP servers with resources registering no tools until every resource was listed; Pi no longer lists resources when connecting, so /mcp and pi mcp list show that a server offers resources instead of counting them (#10526)
  • Fixed MCP tool calls failing when the server returns structured content that is not an object (an array, null, or a primitive, as MCP 2026-07-28 allows); codemode declarations of MCP tools without an output schema now type structuredContent as unknown instead of an object (#10416)
  • Fixed reading or writing auth.json on Windows failing with EPERM when the previous lock folder was still being deleted; Pi now retries briefly before reporting the error (#10801)
  • Fixed OpenRouter router models such as openrouter/auto showing a cost of -$1,000,000 per 1M tokens; OpenRouter's negative placeholder prices are now 0 (#10672 by @davidbrai)
  • Fixed Anthropic requests failing when the provider rejects the strict tool set for grammar size, tool count, or union limits; Pi now retries once with preferred tools non-strict (#10409)
  • Fixed "The upstream provider returned an error" not being retried as a transient provider error (#10842)
  • Fixed focused fullscreen overlays blocking mouse-wheel scrolling of the transcript (#10769)
  • Fixed fragmented terminal color replies leaking hex values into the prompt and opening the external editor (related reports: #10256, #10657)
  • Fixed inline images not rendering in Herdr since 1.1.0 (#10774 by @ogulcancelik)
  • Fixed key bindings that name a shifted symbol, such as + or ctrl++, not matching under the Kitty keyboard protocol or modifyOtherKeys (#9880 by @christianklotz)
  • Fixed the compaction status indicator embedded in a custom editor using the default muted colors instead of the editor border or thinking-level color, as the working indicator does (#10809, #10810 by @Jay-Madden)
  • Fixed MCP tool calls that were cancelled or timed out while waiting for an OAuth refresh still being sent to the server once the refresh finished (#10598)
  • Fixed MCP OAuth sign-in accepting an authorization response with an iss parameter that could not be checked because no authorization server metadata was discovered; sign-in now fails with an issuer mismatch. Reported by @AizenvoltPrime
  • Fixed codemode failing with a broken bridge error when Pi runs under node --watch on Node 24 or 26 (#10725)

Removed

  • Removed the unreleased experimental server, client, and plugin stack (src/experimental, src/cli/experimental) and its source-only ./client and ./experimental/plugin exports; none of it was part of the published package. The @earendil-works/pi-client, @earendil-works/pi-protocol, and @earendil-works/pi-server packages it used are removed and no longer released
  • Removed the dependency on @earendil-works/chord
