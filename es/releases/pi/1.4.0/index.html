pi v1.4.0

#piv1.4.0

Nuevas características

  • Entrada de imagen para clasificadores: el modo de código models.classify() acepta images para los modelos Jev de TypeSafe y Clef de Cloudflare en typesafe, cloudflare-workers-ai y OpenRouter. Consulte Usar modelos de clasificador y Modo de código.
  • Referencia de configuración de modelos: cada proveedor, modelo, anulación de modelo y campo de compatibilidad de models.json, generado a partir de su esquema. Consulte Configuración de modelos.
  • Resúmenes sin límite de salida fijo: los resúmenes de compactación y rama utilizan el límite de salida del modelo, por lo que el razonamiento prolongado ya no los hace fallar. Consulte Compactación.
  • Codemode espera a un trabajador libre: scripts paralelos y subagentes en proceso se ponen en cola en lugar de fallar, y PI_CODEMODE_MAX_WORKERS aumenta el límite. Consulte Límites del modo de código.
  • Compatibilidad con terminal Rex: hipervínculos OSC 8, color verdadero e imágenes en línea.

Agregado

  • Se agregó una referencia de configuración de modelos generada a partir del esquema models.json, que enumera todos los campos de proveedor, modelo, anulación de modelo y compatibilidad (#10790).
  • Codemode models.classify() ahora acepta images para los modelos Jev de TypeSafe y Clef de Cloudflare en typesafe, cloudflare-workers-ai y OpenRouter, y enumera Clef Omni y Jev 1.14 en Workers AI.
  • El nivel de proveedor compat en models.json ahora también se aplica a los modelos de clasificador, con los campos System One imageInput y sendImageOptInHeader para servidores proxy que sirven a los clasificadores de otro servicio. Los modelos de clasificador de extensión también aceptan compat.
  • Se agregó MiniMax-M3.1-Flash a los proveedores minimax y minimax-cn, con niveles de pensamiento desde bajo hasta máximo (#11121)
  • Se agregó soporte para el terminal Rex: hipervínculos OSC 8, color verdadero e imágenes en línea (#11131, #11150 por @petrroll, #11183 por @nihaals)

Cambiado

  • Los encabezados de atribución de proveedores ahora provienen de la identidad client de pi-ai. Los controladores before_provider_headers de Extensions ya no ven los encabezados de atribución OpenRouter, NVIDIA NIM y OpenCode; devolver null por uno todavía lo elimina. Las solicitudes de Cloudflare envían el User-Agent detallado de pi en lugar de pi-coding-agent, al igual que las verificaciones de lanzamiento de GitHub para descargas de herramientas, y las solicitudes de OpenCode envían x-opencode-client siempre que la atribución esté habilitada, no solo con una sesión.
  • generateSummary() y generateSummaryWithUsage() ahora ignoran su parámetro reserveTokens. En su lugar, las solicitudes de resumen utilizan el límite de salida del modelo.
  • Se cambió el modelo de copiloto GitHub predeterminado de gpt-5.4, que Copilot retiró, a gpt-6.1-sol.
  • Se cambió el modelo predeterminado de NVIDIA a nvidia/nemotron-3.5-super-vl-120b-a12b (#10910 por @cv)
  • Se cambió el modelo predeterminado de Xiaomi a mimo-v2.6-pro para los proveedores xiaomi y Xiaomi Token Plan, ya que mimo-v2.5-pro salió del catálogo.
  • Grok 4.3 y Grok 4.5 en el proveedor xai ahora ofrecen el nivel de pensamiento xhigh.
  • Iniciar sesión con ChatGPT: los errores de límite de uso del espacio de trabajo de ChatGPT Business no se vuelven a intentar y le indican al usuario que solicite al administrador de su espacio de trabajo que aumente el límite.

Fijo

  • Se corrigió el error de compactación y resúmenes de rama con "la generación alcanzó el límite del token" cuando el razonamiento usaba la mayor parte del límite de salida de resumen fijo. Los resúmenes ahora usan el límite de salida del modelo y compaction.reserveTokens solo controla cuándo comienza la compactación (#9512, #9075).
  • Se corrigieron las descripciones faltantes de models.schema.json para los campos de proveedor y modelo, por lo que los editores no mostraron sugerencias para ellos (#10790)
  • Se corrigió el error de pi update con "Falta el marcador de instalación administrada o no es válido" cuando managed-install.json comienza con una lista de materiales UTF-8, que Windows PowerShell 5.1 agrega cuando reescribe el archivo.
  • Se corrigió la exportación de HTML que mostraba asteriscos literales para Markdown en negrita y cursiva junto a la puntuación CJK (#3353, #10154)
  • Se corrigió que el terminal permaneciera en los modos de seguimiento del mouse, informe de enfoque, teclado Kitty y pantalla alternativa cuando pi sale sin su desmontaje normal del terminal, lo que inundaba el indicador de shell con secuencias de escape (#11170)
  • Se corrigieron los diálogos de extensión concurrentes select/confirm/input/editor y los componentes en línea custom() en modo interactivo: un segundo diálogo reemplazó al primero y la primera promesa nunca se cumplió; al cerrar el cuadro de diálogo visible ahora se muestra el anterior nuevamente (#11166, #9909)
  • Se corrigió que el pegado en el shell se colgara después de copiar texto en pi y suspenderlo con Ctrl+Z en Linux: el proceso en segundo plano wl-copy/xclip/xsel que sigue sirviendo al clipboard se suspendió junto con pi (#11179)
  • Se corrigieron los scripts de modo de código que fallaban inmediatamente cuando ambos trabajadores de modo de código estaban ocupados, por ejemplo, con llamadas de modo de código paralelas o subagentes en proceso. Los scripts ahora esperan hasta 60 segundos por un trabajador libre y PI_CODEMODE_MAX_WORKERS aumenta el límite de dos trabajadores (#11184)
  • Se corrigió que las extensiones no se cargaran al importar @earendil-works/pi-ai/models (por ejemplo, para clampThinkingLevel) al exponer la ruta secundaria a través de los alias del cargador de extensiones y los módulos virtuales (#11156)
  • Se corrigieron los archivos mcp.json que comienzan con una lista de materiales UTF-8 que no se pudo analizar, lo que omitió todos sus servidores MCP e hizo que pi mcp add/pi mcp remove fallara (#11191)
  • Se corrigió que /compact <instructions> ignorara las instrucciones al resumir el inicio de un giro que la compactación se divide. Cuando el giro dividido fue el único contenido nuevo desde la última compactación, las instrucciones se ignoraron por completo (#11058)
  • Se corrigieron las sesiones reanudadas y la navegación /tree que dejaban las herramientas de extensión inactivas cuando la sucursal registraba sus herramientas antes de que se registraran, como las herramientas de las extensiones instaladas después de que comenzara la sesión. Las herramientas de extensión que la rama nunca agregó ni eliminó ahora están activas a menos que estén registradas con defaultActive: false (#11062, #11075)
  • Se corrigió la interrupción de las sesiones después de la recuperación de una respuesta cortada en el límite de salida: la llamada a la herramienta truncada se omitió pero los resultados de la herramienta se mantuvieron, por lo que los proveedores rechazaron todas las solicitudes posteriores (#11227, #11233 por @petrroll)
  • Se corrigió la herramienta grep después de RIPGREP_CONFIG_PATH, donde opciones como --fixed-strings cambiaban silenciosamente las búsquedas de expresiones regulares a literales. La herramienta ahora ejecuta rg --no-config (#11203, #11230 por @petrroll)
  • Se corrigió la detección de shell de Windows que rechazaba los alias de shell ejecutables de Microsoft Store (#9504 por @petrroll)
  • Se corrigió la detección de shell de Windows que faltaba PowerShell fuera de PATH y el iniciador WSL bash.exe heredado cuando Windows no está instalado en C:\Windows. pi ahora verifica %ProgramFiles%\PowerShell\7, %SystemRoot%\System32\WindowsPowerShell\v1.0 y %SystemRoot% (#9501 por @petrroll)
  • Se corrigieron sesiones de copiloto GitHub con cuerpos de solicitud grandes, como muchas imágenes, que fallaban con HTTP 413 failed to parse request en lugar de compactar y volver a intentar (#11016 por @petrroll)
  • Se corrigió el proveedor openai-codex que ofrece gpt-5.5 y gpt-5.3-codex-spark, que siempre falla para las cuentas ChatGPT (#11173 por @lucasmeijer)
  • Se corrigió la salida de la herramienta de solo espacios en blanco (por ejemplo, un \r\n simple de bash) que hacía que las completaciones de OpenAI, las respuestas de OpenAI y las solicitudes de Google fallaran con un 400 (#8720)
  • Se corrigió el reintento automático que no se activaba en caso de más fallas ascendentes de la puerta de enlace, errores stream disconnected before completion transmitidos por los proxies Codex CLI y fallas transitorias de actualización del token Google Vertex OAuth, y errores de reintento debido a dígitos dentro de los identificadores de solicitud o recuentos de bytes (#10920, #11057. #10996)
  • Se corrigieron los modelos de OpenAI Responses que perdían el caché de mensajes en cada carga de herramienta diferida después de que se eliminaba una herramienta (#10940)
  • Se corrigió el precio del clasificador de IA de Cloudflare Workers: Clef Flash cuesta $0.038 y Jev $0.042 por millón de tokens de entrada en lugar de que Jev aparezca como gratuito.
  • Se corrigió un bloque matemático de visualización $$ no cerrado que tragaba o corrompía todas las tablas de Markdown posteriores (#11159)
  • Se corrigió que Markdown negrita y cursiva no se mostrara junto a la puntuación CJK (#10730 por @theBucky)
  • Se corrigió el autocompletado del archivo @ que no devolvía resultados para consultas que contenían metacaracteres de expresiones regulares como [ o ( (#10972)

original en inglés / English original

pi v1.4.0

New Features

  • Image input for classifiers: codemode models.classify() accepts images for TypeSafe's Jev and Cloudflare's Clef models on typesafe, cloudflare-workers-ai, and OpenRouter. See Use classifier models and Codemode.
  • Models Configuration reference: every provider, model, model override, and compatibility field of models.json, generated from its schema. See Models Configuration.
  • Summaries without a fixed output cap: compaction and branch summaries use the model's output limit, so long reasoning no longer makes them fail. See Compaction.
  • Codemode waits for a free worker: parallel scripts and in-process subagents queue instead of failing, and PI_CODEMODE_MAX_WORKERS raises the limit. See Codemode limits.
  • Rex terminal support: OSC 8 hyperlinks, truecolor, and inline images.

Added

  • Added a Models Configuration reference generated from the models.json schema, listing all provider, model, model override, and compatibility fields (#10790)
  • Codemode models.classify() now accepts images for TypeSafe's Jev and Cloudflare's Clef models on typesafe, cloudflare-workers-ai, and OpenRouter, and lists Clef Omni and Jev 1.14 on Workers AI.
  • Provider-level compat in models.json now also applies to classifier models, with the System One fields imageInput and sendImageOptInHeader for proxies that serve another service's classifiers. Extension classifier models accept compat too.
  • Added MiniMax-M3.1-Flash to the minimax and minimax-cn providers, with thinking levels low through max (#11121)
  • Added support for the Rex terminal: OSC 8 hyperlinks, truecolor, and inline images (#11131, #11150 by @petrroll, #11183 by @nihaals)

Changed

  • Provider attribution headers now come from pi-ai's client identity. Extensions' before_provider_headers handlers no longer see the OpenRouter, NVIDIA NIM, and OpenCode attribution headers; returning null for one still removes it. Cloudflare requests send pi's detailed User-Agent instead of pi-coding-agent, as do GitHub release checks for tool downloads, and OpenCode requests send x-opencode-client whenever attribution is enabled, not only with a session.
  • generateSummary() and generateSummaryWithUsage() now ignore their reserveTokens parameter. Summary requests use the model's output limit instead.
  • Changed the default GitHub Copilot model from gpt-5.4, which Copilot retired, to gpt-6.1-sol.
  • Changed the default NVIDIA model to nvidia/nemotron-3.5-super-vl-120b-a12b (#10910 by @cv)
  • Changed the default Xiaomi model to mimo-v2.6-pro for the xiaomi and Xiaomi Token Plan providers, since mimo-v2.5-pro left the catalog.
  • Grok 4.3 and Grok 4.5 on the xai provider now offer the xhigh thinking level.
  • Sign in with ChatGPT: ChatGPT Business workspace usage-limit errors are not retried and tell the user to ask their workspace admin to increase the limit.

Fixed

  • Fixed compaction and branch summaries failing with "generation hit the token cap" when reasoning used most of the fixed summary output limit. Summaries now use the model's output limit, and compaction.reserveTokens only controls when compaction starts (#9512, #9075).
  • Fixed models.schema.json missing descriptions for provider and model fields, so editors showed no hints for them (#10790)
  • Fixed pi update failing with "Managed install marker is missing or invalid" when managed-install.json starts with a UTF-8 BOM, which Windows PowerShell 5.1 adds when it rewrites the file.
  • Fixed HTML export showing literal asterisks for Markdown bold and italic next to CJK punctuation (#3353, #10154)
  • Fixed the terminal staying in mouse-tracking, focus-reporting, Kitty keyboard, and alternate-screen modes when pi exits without its normal terminal teardown, which flooded the shell prompt with escape sequences (#11170)
  • Fixed concurrent extension select/confirm/input/editor dialogs and inline custom() components in interactive mode: a second dialog replaced the first and the first promise never settled; closing the visible dialog now shows the previous one again (#11166, #9909)
  • Fixed pasting in the shell hanging after copying text in pi and suspending it with Ctrl+Z on Linux: the background wl-copy/xclip/xsel process that keeps serving the clipboard was suspended along with pi (#11179)
  • Fixed codemode scripts failing immediately when both codemode workers are busy, for example with parallel codemode calls or in-process subagents. Scripts now wait up to 60 seconds for a free worker, and PI_CODEMODE_MAX_WORKERS raises the limit of two workers (#11184)
  • Fixed extensions failing to load when importing @earendil-works/pi-ai/models (e.g. for clampThinkingLevel) by exposing the subpath through the extension loader aliases and virtual modules (#11156)
  • Fixed mcp.json files that start with a UTF-8 BOM failing to parse, which skipped all their MCP servers and made pi mcp add/pi mcp remove fail (#11191)
  • Fixed /compact <instructions> ignoring the instructions when summarizing the start of a turn that compaction splits. When the split turn was the only new content since the last compaction, the instructions were ignored entirely (#11058)
  • Fixed resumed sessions and /tree navigation leaving extension tools inactive when the branch recorded its tools before they were registered, such as tools from extensions installed after the session started. Extension tools the branch never added or removed are now active unless they are registered with defaultActive: false (#11062, #11075)
  • Fixed sessions breaking after recovery from a response cut off at the output limit: the truncated tool call was omitted but its tool results were kept, so providers rejected every later request (#11227, #11233 by @petrroll)
  • Fixed the grep tool following RIPGREP_CONFIG_PATH, where options such as --fixed-strings silently changed regex searches into literal ones. The tool now runs rg --no-config (#11203, #11230 by @petrroll)
  • Fixed Windows shell detection rejecting runnable Microsoft Store shell aliases (#9504 by @petrroll)
  • Fixed Windows shell detection missing PowerShell outside PATH and the legacy WSL bash.exe launcher when Windows is not installed in C:\Windows. pi now checks %ProgramFiles%\PowerShell\7, %SystemRoot%\System32\WindowsPowerShell\v1.0, and %SystemRoot% (#9501 by @petrroll)
  • Fixed GitHub Copilot sessions with large request bodies, such as many images, failing with HTTP 413 failed to parse request instead of compacting and retrying (#11016 by @petrroll)
  • Fixed the openai-codex provider offering gpt-5.5 and gpt-5.3-codex-spark, which always fail for ChatGPT accounts (#11173 by @lucasmeijer)
  • Fixed whitespace-only tool output (for example a bare \r\n from bash) making OpenAI Completions, OpenAI Responses, and Google requests fail with a 400 (#8720)
  • Fixed automatic retry not triggering for more gateway upstream failures, stream disconnected before completion errors relayed by Codex CLI proxies, and transient Google Vertex OAuth token refresh failures, and retrying errors because of digits inside request ids or byte counts (#10920, #11057, #10996)
  • Fixed OpenAI Responses models losing the prompt cache on every deferred tool load after a tool was removed (#10940)
  • Fixed Cloudflare Workers AI classifier pricing: Clef Flash costs $0.038 and Jev $0.042 per million input tokens instead of Jev being listed as free.
  • Fixed an unclosed $$ display-math block swallowing or corrupting every Markdown table after it (#11159)
  • Fixed Markdown bold and italic not rendering next to CJK punctuation (#10730 by @theBucky)
  • Fixed @ file autocomplete returning no results for queries containing regex metacharacters such as [ or ( (#10972)
