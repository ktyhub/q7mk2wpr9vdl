#piv1.0.0

Nuevas características

  • Pantalla completa de forma predeterminada: la TUI ahora se ejecuta en pantalla completa. Configure tuiMode en "regular" para mantener el desplazamiento hacia atrás normal del terminal. Consulte Terminal y pantalla.
  • Modo de código más eficiente: aproximadamente un 40 % menos de tokens de aviso y errores que le indican al modelo cómo recuperarse. Consulte Modo de código.
  • Generación de imágenes en modo código: los scripts llaman a models.generateImages() con las credenciales de la sesión. Consulte Generar imágenes y Usar modelos de imágenes.
  • Radius en /login: inicie sesión con Radius y configure su servidor MCP en un solo paso. Consulte Radio.
  • Inicio de sesión con código de copia antrópica: inicie sesión cuando el navegador se ejecute en otra máquina. Consulte Autenticarse interactivamente.
  • Reforzamiento de MCP OAuth: comprobaciones oauth.authServerMetadataUrl, RFC 9207 iss, credenciales por servidor e inicio de sesión avanzado que mantiene los alcances otorgados. Consulte Autenticar con OAuth.
  • Inicio silencioso solo con encabezado: quietStartup: "header" mantiene la versión y las sugerencias clave y oculta el resto. Consulte Terminal y pantalla.

Agregado

  • Se agregó una configuración oauth.authServerMetadataUrl para servidores MCP que anuncian un servidor de autorización OAuth incorrecto o ninguno. Pi utiliza el documento de metadatos configurado en lugar del descubrimiento (#10172).
  • Se agregó quietStartup: "header", que mantiene el encabezado de inicio con la versión y sugerencias clave, pero oculta la línea de alcance del modelo y la lista de recursos cargados.
  • Se agregó models.generateImages() a los scripts en modo de código. Ejecuta modelos de imágenes como OpenRouter con las credenciales de la sesión y devuelve bloques de imágenes base64 que image() adjunta al resultado; el uso cuenta para el costo de la sesión como models.classify(). Las extensiones pueden llamar a ctx.modelRegistry.generateImages(). Consulte Usar modelos de imagen.
  • Se agregó un método de inicio de sesión con copia de código a Anthropic /login para configuraciones sin cabeza donde el navegador se ejecuta en otra máquina (#10194 por @lucasmeijer).

Cambiado

  • Se cambió el modo TUI predeterminado a pantalla completa. Configure tuiMode en "regular" o pase --tui-mode regular para mantener el desplazamiento hacia atrás normal del terminal.
  • /login ahora ofrece "Iniciar sesión con Radius" en el nivel superior, como última opción, con su estado. Después de iniciar sesión en Radius, /login ofrece configurar el servidor Radius MCP en el mcp.json global con "auth": { "provider": "radius" } y recargas. Al cancelar un inicio de sesión se regresa al menú desde el que se inició.
  • La página de documentos del proveedor pasa a llamarse Proveedores, su sección "Proveedores de nube" ahora es "Configuración específica del proveedor" y documenta Radius primero.
  • Las credenciales de MCP OAuth ahora se almacenan por nombre de servidor y URL, por lo que los servidores MCP con la misma URL pueden iniciar sesión con diferentes cuentas. Las credenciales almacenadas solo por URL se mueven al primer servidor que las utiliza (#10252).
  • El modo de código cuesta muchos menos tokens de aviso: con las herramientas predeterminadas y el modo de código activo, una solicitud GPT-5.6 se reduce de aproximadamente 5300 a 3300 tokens. La descripción de codemode enumera los scripts globales en una línea cada uno y apunta a la nueva referencia Codemode para models API, que el modelo lee cuando lo necesita. Las herramientas declaradas dicen en una línea cómo las llaman los scripts y en qué se resuelve la llamada, en lugar de repetir su declaración completa, y la guía del modo de código del sistema y la sección del servidor MCP son más breves.
  • Los errores de modo de código ahora dicen cómo recuperarse: leer una herramienta o miembro models que no existe nombra las coincidencias cercanas (tools.Bash sugiere tools.bash), models.classify() y models.generateImages() rechazan argumentos mal formados con la forma esperada, un modelo desconocido apunta a models.getAvailableOfType(), un valor store() sobredimensionado explica para qué sirve la tienda y un script que genera imágenes sin mostrarlas recibe una nota. Los scripts que buscaron una herramienta con typeof tools.name deben usar "name" in tools.
  • /login y /logout ahora etiquetan a los proveedores sin credenciales como "no configurados" en lugar de "no configurados".
  • Las páginas del navegador OAuth ahora muestran el logotipo de Pi en color.

Fijo

  • Se corrigió el inicio de sesión de MCP OAuth al aceptar una respuesta de autorización cuyo parámetro iss nombra otro servidor de autorización; el código ahora se rechaza antes de intercambiarse (RFC 9207).
  • Se corrigió el error de inicio de sesión de MCP OAuth con Invalid scope cuando la respuesta del token contiene "scope": "", y fallas similares para otros campos OAuth vacíos o opcionales de null (#10266).
  • Se corrigió que la URL de inicio de sesión impresa por /mcp login no fuera clickable cuando se ajusta (#10186).
  • Se corrigió --provider sin que --model fuera ignorado silenciosamente y ejecutara el modelo predeterminado de otro proveedor; ahora falla con un error (#10236).
  • Se corrigieron los servidores MCP que solicitaban más alcance (insufficient_scope) solicitando inicio de sesión una y otra vez. El nuevo inicio de sesión solicitó solo los ámbitos que faltaban, por lo que el nuevo token perdió el acceso que tenía el anterior; ahora mantiene los alcances otorgados.
  • Se corrigieron los mensajes de usuario en la transcripción manteniendo dos copias de ancho completo de cada línea renderizada; se quedan con uno, con rendimiento idéntico.
  • Se corrigió que /login y /logout etiquetaran cada inicio de sesión de OAuth, incluido Radius, como una suscripción; solo los proveedores respaldados por suscripción dicen "suscripción", otros inicios de sesión de OAuth dicen "cuenta".
  • Se corrigió la representación del logotipo del encabezado de inicio con espacios en la Terminal Apple; ahora muestra un "Pi" coloreado con la versión.
  • Se corrigieron las herramientas MCP diferidas que cargaba tool_search y se eliminaban al reanudar y /reload incluso cuando su servidor se reconectaba antes del siguiente mensaje, porque la sesión restauró sus herramientas antes de que los servidores MCP se volvieran a conectar.
  • Se corrigió el tema del sistema haciendo que las paletas de colores pastel como Catppuccin Frappe sean mucho más vívidas; los colores de la paleta ahora mantienen su croma (#10255, #10293 por @dgtlntv).
  • Se corrigió que el autocompletado del comando de barra diagonal no se activara cuando la entrada comienza con espacios en blanco (#10218 por @haoqixu).
  • Se corrigió que el color se desvaneciera más allá de las selecciones del mouse y los aspectos destacados de búsqueda en el modo de pantalla completa cuando un token con estilo termina en el límite de resaltado (#10169).
  • Se corrigió la memoria retenida por mensaje renderizado en la transcripción; un mensaje de asistente largo conserva aproximadamente una quinta parte del montón que guardaba antes.

pi v1.0.0

New Features

  • Fullscreen by default — The TUI now runs fullscreen. Set tuiMode to "regular" to keep the terminal's normal scrollback. See Terminal and display.
  • Leaner codemode — About 40% fewer prompt tokens, and errors that tell the model how to recover. See Codemode.
  • Image generation in codemode — Scripts call models.generateImages() with the session's credentials. See Generate images and Use image models.
  • Radius in /login — Sign in with Radius and set up its MCP server in one step. See Radius.
  • Anthropic copy code login — Sign in when the browser runs on another machine. See Authenticate interactively.
  • MCP OAuth hardening — oauth.authServerMetadataUrl, RFC 9207 iss checks, credentials per server, and step-up sign-in that keeps granted scopes. See Authenticate with OAuth.
  • Header-only quiet startup — quietStartup: "header" keeps the version and key hints and hides the rest. See Terminal and display.

Added

  • Added an oauth.authServerMetadataUrl setting for MCP servers that advertise a wrong OAuth authorization server or none. Pi uses the configured metadata document instead of discovery (#10172).
  • Added quietStartup: "header", which keeps the startup header with version and key hints but hides the model scope line and loaded-resource listing.
  • Added models.generateImages() to codemode scripts. It runs image models such as OpenRouter's with the session's credentials and returns base64 image blocks that image() attaches to the result; usage counts toward the session cost like models.classify(). Extensions can call ctx.modelRegistry.generateImages(). See Use image models.
  • Added a copy code login method to Anthropic /login for headless setups where the browser runs on another machine (#10194 by @lucasmeijer).

Changed

  • Changed the default TUI mode to fullscreen. Set tuiMode to "regular" or pass --tui-mode regular to keep the terminal's normal scrollback.
  • /login now offers "Sign in with Radius" at the top level, as the last option, with its status. After a Radius sign-in, /login offers to configure the Radius MCP server in the global mcp.json with "auth": { "provider": "radius" } and reloads. Cancelling a login returns to the menu it was started from.
  • The provider docs page is renamed to Providers, its "Cloud Providers" section is now "Provider Specific Config", and it documents Radius first.
  • MCP OAuth credentials are now stored per server name and URL, so MCP servers with the same URL can sign in with different accounts. Credentials stored by URL alone move to the first server that uses them (#10252).
  • Codemode costs far fewer prompt tokens: with the default tools and codemode active, a GPT-5.6 request shrinks from about 5,300 to 3,300 tokens. The codemode description lists the script globals in one line each and points to the new Codemode reference for the models API, which the model reads when it needs it. Declared tools say in one line how scripts call them and what the call resolves to, instead of repeating their full declaration, and the system prompt's codemode guidance and MCP server section are shorter.
  • Codemode errors now say how to recover: reading a tool or models member that does not exist names the close matches (tools.Bash suggests tools.bash), models.classify() and models.generateImages() reject malformed arguments with the expected shape, an unknown model points to models.getAvailableOfType(), an oversized store() value explains what the store is for, and a script that generates images without showing them gets a note. Scripts that probed for a tool with typeof tools.name must use "name" in tools.
  • /login and /logout now label providers without credentials as "not configured" instead of "unconfigured".
  • OAuth browser pages now show the color Pi logo.

Fixed

  • Fixed MCP OAuth sign-in accepting an authorization response whose iss parameter names another authorization server; the code is now rejected before it is exchanged (RFC 9207).
  • Fixed MCP OAuth sign-in failing with Invalid scope when the token response contains "scope": "", and similar failures for other empty or null optional OAuth fields (#10266).
  • Fixed the sign-in URL printed by /mcp login not being clickable when it wraps (#10186).
  • Fixed --provider without --model being silently ignored and running the default model from another provider; it now fails with an error (#10236).
  • Fixed MCP servers that ask for more scope (insufficient_scope) requesting sign-in over and over. The new sign-in requested only the missing scopes, so the new token lost access the previous one had; it now keeps the granted scopes.
  • Fixed user messages in the transcript keeping two full-width copies of every rendered line; they keep one, with identical output.
  • Fixed /login and /logout labeling every OAuth sign-in, including Radius, as a subscription; only subscription-backed providers say "subscription", other OAuth sign-ins say "account".
  • Fixed the startup header logo rendering with gaps in Apple Terminal; it now shows a colored "Pi" with the version instead.
  • Fixed deferred MCP tools that tool_search loaded being dropped on resume and /reload even when their server reconnected before the next prompt, because the session restored its tools before the MCP servers reconnected.
  • Fixed the system theme making pastel palettes such as Catppuccin Frappe much more vivid; palette colors now keep their chroma (#10255, #10293 by @dgtlntv).
  • Fixed slash command autocompletion not triggering when the input starts with whitespace (#10218 by @haoqixu).
  • Fixed color bleeding past mouse selections and search highlights in fullscreen mode when a styled token ends at the highlight boundary (#10169).
  • Fixed memory retained per rendered message in the transcript; a long assistant message keeps about a fifth of the heap it kept before.
