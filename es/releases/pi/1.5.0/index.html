#piv1.5.0

Nuevas características

  • Actualización de extensión changelogs: vea qué cambió en los paquetes de extensión instalados en el próximo lanzamiento nuevo después de una actualización. Los autores de paquetes pueden elegir la ruta changelog y collapseChangelog condensa los avisos. Consulte Mostrar un changelog.
  • Transmisión más rápida: las llamadas a herramientas grandes se analizan de forma incremental, y las respuestas con mucho código y las filas de herramientas reutilizan el resaltado y el Markdown renderizado en lugar de repetir el trabajo en cada actualización. Consulte [Seguir renderizando con capacidad de respuesta] (https://github.com/earendil-works/pi/blob/v1.5.0/packages/coding-agent/docs/tui.md#keep-rendering-responsive).
  • Comandos de actualización automática personalizados: use PI_SELF_UPDATE_COMMAND o selfUpdateCommand para actualizar pi a través de un contenedor u otro administrador de paquetes. Consulte Comando de actualización personalizada.
  • GPT-6.1 Terra: disponible a través de OpenAI, Azure OpenAI Responses y OpenAI Codex, con búsqueda de herramientas, cambios en el nivel de pensamiento a mitad de una conversación y pensamiento off. Codex ofrece una ventana de contexto de 500K. Consulte Modelos.

Cambios importantes

  • La validación de argumentos de la herramienta se ejecuta en @earendil-works/pi-schema. Las funciones de TypeBox fuera del esquema JSON (Type.Refine(), Type.BigInt(), Type.Undefined(), códecs, formatos Format.Set()) ya no se aplican a los argumentos de la herramienta; consulte Esquemas de parámetros de herramientas y TypeBox. Las herramientas de esquema simples JSON, incluidas las herramientas MCP, ahora obtienen la misma coerción que las herramientas TypeBox, como convertir cadenas numéricas y envolver un valor único en una matriz. Las fallas de validación que el modelo ve enumeran los mensajes del esquema pi (- path: missing, - limit: expected number, got string) en lugar de los de TypeBox (must have required properties path, must be number).

Agregado

  • Los paquetes de extensión ahora pueden mostrar su changelog después de una actualización. Pi lee pi.changelogPath del package.json del paquete, o CHANGELOG.md en la raíz del paquete, y en el próximo lanzamiento nuevo muestra entradas más recientes que la última versión vista en "Actualizaciones de extensiones". La configuración collapseChangelog condensa esto en una línea por paquete (#5958, #8790)
  • pi.exec() acepta una opción maxBuffer que limita stdout y stderr combinados, y su resultado tiene un campo truncated que es verdadero cuando la salida excede el límite (#11360)
  • El inicio de sesión con código de dispositivo (por ejemplo, GitHub Copilot) ahora abre la página de verificación y copia el código cuando presiona Enter. Los proveedores pueden desactivar cualquiera de las acciones con openBrowserOnConfirm: false o copyCodeOnConfirm: false (#9282, #9301)
  • pi update puede actualizar Pi a través de un contenedor u otro administrador de paquetes. Configure PI_SELF_UPDATE_COMMAND (por ejemplo mise use -g npm:{packageName}@{version}) o la configuración global selfUpdateCommand; pi update lo ejecuta cuando pi.dev informa una versión más reciente y completa {packageName}, {version} y {installSpec} de esa versión. Consulte Comando de actualización personalizado (#7756, #5607)
  • Las extensiones pueden formatear las combinaciones de teclas configuradas por el usuario con keyText() y keyHint() desde el contexto de representación de la herramienta y las opciones de representación de mensajes y entradas. Importar estas funciones desde @earendil-works/pi-coding-agent puede resolver la propia copia del paquete de la extensión, que no ve las combinaciones de teclas de pi, por lo que sugerencias como keyHint("app.tools.expand", "to expand") se representan sin la clave. Los documentos ahora recomiendan las funciones inyectadas (#4748)
  • Se agregaron entradas de sesión persistentes messageId e ISO timestamp a MarkdownTransformContext. Están disponibles al renderizar entradas guardadas y no definidas para renderizado en vivo (#7952 por @vipentti)
  • Se agregó una opción blocked para incorporar componentes ctx.ui.custom() para que las solicitudes de aprobación y otros cuadros de diálogo personalizados puedan informar que pi está esperando la entrada del usuario. Las superposiciones ignoran la opción. Consulte Pantallas y superposiciones personalizadas (#11428)
  • Se agregó Usage.cost.totalFromProvider para distinguir los totales facturados de las estimaciones del catálogo en SDK y los datos de uso de la extensión; el uso combinado se marca como informado por el proveedor solo cuando cada parte está (#11178)
  • Se agregaron metadatos responseModel concretos a los mensajes de proveedores de mensajes pi como Radius, incluso cuando se solicita un modelo virtual. Consulte Mensaje del asistente (#11265)
  • Se agregó GPT-6.1 Terra para OpenAI, Azure OpenAI Responses y OpenAI Codex, con búsqueda de herramientas y cambios en el nivel de pensamiento a mitad de la conversación. Soporta el pensamiento off; Codex ofrece una ventana de contexto de 500K

Cambiado

  • Las extensiones siguen importando Type, Static y TSchema desde @earendil-works/pi-ai: mapas Pi que se importan a la entrada compatible de pi-ai más el TypeBox que incluye, ahora que pi-ai ya no reexporta TypeBox, y su StringEnum sigue siendo un TypeBox TUnsafe<T>. Las fábricas de herramientas integradas (createReadTool() y otras) devuelven TypeBoxAgentTool<typeof schema>, que mantiene params escrito para TypeBox.
  • Aviso del sistema ajustado
  • pi update para instalaciones desde el instalador pi.dev ya no pasa de --min-release-age=0 a npm ci. El archivo de bloqueo de versión fija cada paquete, por lo que la marca no tuvo ningún efecto y los escáneres de seguridad que lo bloquean detuvieron la actualización (#11262)
  • /model y /scoped-models ahora muestran el nombre de un modelo junto a su ID cuando el nombre agrega palabras de las que carece el ID, como una anulación de models.json renombrado (#5916, #11347)
  • El inicio de sesión de MCP OAuth ahora utiliza el documento de metadatos de ID Client de pi de forma predeterminada cuando el servidor de autorización lo admite para clients públicos y, de lo contrario, registra un client dinámicamente, como Codex, Claude Code y opencode. Clients registrados antes de permanecer en uso mientras su URI de redireccionamiento coincida. El nuevo oauth.clientRegistration: "auto" predeterminado se registra cuando se configura clientName o un callbackUrl no predeterminado; "dcr" siempre se registra. pi mcp add --oauth-client-registration establece el modo (#11426)
  • Se cambió el modelo OpenAI predeterminado de gpt-5.5 a gpt-6.1-sol, incluso después del inicio de sesión en ChatGPT cuando no se selecciona ningún modelo (#11442)
  • Se actualizó el catálogo de modelos integrado a models.dev v2. Los modelos en tiempo real y de sólo imágenes ya no se ofrecen como modelos de chat; Se incluyen modelos de chat más nuevos de OpenAI y Google.

Fijo

  • Coincidencia global actualizada para evitar la denegación de servicio debido a patrones globales amplificados.
  • Se corrigió una decisión guardada "No trust" que se ignoraba para proyectos sin recursos que requieren trust, por ejemplo, una carpeta con solo AGENTS.md. pi auto-trust eliminó dichos proyectos, por lo que ctx.isProjectTrusted() devolvió verdadero y los comandos del paquete los trataron como trusted. Una decisión guardada en trust.json ahora tiene prioridad; auto-trust se aplica solo cuando no se guarda ninguna decisión (#10947)
  • Se corrigió que Shift+Enter pusiera en cola un seguimiento en lugar de insertar una nueva línea en las configuraciones de la Terminal Apple que envían ESC + Return. pi ahora verifica el estado de la tecla Shift local para esa secuencia, como ya lo hizo para Return simple; Alt+Enter sin Shift todavía pone en cola un seguimiento (#11559)
  • Se corrigió el estado de trabajo (OSC 7501) que desaparecía en Rex e iTerm2 durante las ejecuciones en modo TUI normal. Los mensajes renderizados escribieron marcadores de aviso OSC 133 en el terminal, que el terminal trata como un nuevo aviso de shell; el modo normal ya no los escribe (#11519)
  • Se corrigió la compactación, los resúmenes de ramas y los resúmenes de informes de errores en las sesiones SDK que pasaban el token OAuth almacenado al tiempo de ejecución del modelo como una clave API explícita. La autenticación del proveedor que trata las claves explícitas de manera diferente a las de OAuth almacenadas ahora ve el inicio de sesión de OAuth, como lo hacen las indicaciones normales (#11520)
  • Se corrigió una actualización redundante del sistema (herramientas, reglas) cuando una extensión configuraba las mismas herramientas activas en un orden diferente, por ejemplo, una lista pi.setActiveTools() invertida. Las herramientas que permanecen activas ahora mantienen su orden y se agregan las herramientas recién activadas (#11495)
  • Se corrigió el bloqueo de pi de pi.exec() con RangeError: Invalid string length cuando un comando imprimió más resultados de los que caben en una cadena. El límite de salida predeterminado es el menor entre 256 MiB y el límite de cadena de tiempo de ejecución; más allá del límite, el comando finaliza y el resultado tiene truncated: true y un código de salida distinto de cero (#11360)
  • Se corrigió que pi.exec() nunca regresara cuando un comando ignoraba SIGTERM después de un tiempo de espera o una cancelación. pi ahora envía SIGKILL 5 segundos después, como estaba previsto
  • Se corrigió que pi install y pi remove agregaran entradas anidadas cada vez más profundas al npm package-lock.json cuando se accede al directorio del agente a través de un enlace simbólico, como ~/.pi vinculado a un repositorio de archivos de puntos. pi ahora pasa la ruta real resuelta a npm (#11358)
  • El inicio de sesión de MCP ahora rechaza los puntos finales de autorización y otras URL de metadatos de OAuth que no sean http: o https:. Antes, un servidor MCP malicioso podía proporcionar un file: o una URL de protocolo personalizado, que pi pasaba al controlador de URL de la plataforma.
  • Las descargas automáticas de fd y rg ya no obtienen archivos binarios x86-64 en ARM32 y otras arquitecturas sin una versión prediseñada. pi ahora advierte y recomienda instalar la herramienta con el administrador de paquetes del sistema (#11209)
  • Se corrigieron las letras de clasificación de búsqueda de /model esparcidas en una parte anterior de una entrada encima de una coincidencia real, por ejemplo, opus que enumera gpt-oss-120b y claude-sonnet-4.5 antes de claude-opus-4.1 (#11220, #11296)
  • Se corrigió la búsqueda de /resume que coincidía con letras dispersas en cualquier lugar de los mensajes e ID de la sesión, por ejemplo, que 1024 coincidiera dentro de un UUID de sesión. Los nombres de las sesiones y los directorios de trabajo aún no coinciden; Los ID y el texto del mensaje ahora coinciden solo como subcadenas exactas (#11220, #11024, #11296)
  • Se corrigió la exportación de HTML que mostraba una página en blanco para sesiones con miles de entradas (#11225, #11293)
  • Se corrigió la exportación de HTML que no mostraba mensajes del sistema: el indicador y las herramientas del sistema, y actualizaciones de secciones posteriores, como después de /reload. pi --export ahora también incluye el indicador del sistema y herramientas (#11261, #3464, #11290)
  • Se corrigió la cancelación de un comando bash en macOS que a veces ejecutaba el siguiente comando de una lista como long_step; next_step. pi ahora detiene el grupo de procesos antes de matarlo (#11252, #11289)
  • Se corrigieron grandes llamadas a herramientas transmitidas que consumían demasiado tiempo de CPU y memoria porque cada delta volvía a analizar los argumentos acumulados. Los proveedores y los flujos de proxy de agente ahora analizan cada delta una vez, las herramientas gramaticales ya no copian toda su entrada por delta y los renderizadores de herramientas interactivas se ejecutan como máximo una vez por cuadro (#9265)
  • Se corrigió el cuadro de diálogo de inicio de sesión que abría URL de inicio de sesión que no son URL web e imprimía caracteres de control de URL de inicio de sesión, código de dispositivo e información, lo que podía finalizar un hipervínculo del terminal y enviar secuencias de escape al terminal.
  • Se corrigió que tui.select.pageUp y tui.select.pageDown se ignoraran en el comando de barra diagonal y el autocompletado de archivos, /settings y los selectores de modelo, modelos con alcance, inicio de sesión, bifurcación, /mcp y llama.cpp. En el modo de pantalla completa, RePág/AvPág ahora mueve una lista abierta o un menú de autocompletar en lugar de desplazarse por la transcripción, y una tecla de página vinculada a Ctrl+V autocompleta las páginas en lugar de pegar una imagen (#7629, basado en #7680 de @muyiyr)
  • Se corrigió la salida de la herramienta y la salida del comando ! que mostraban los parámetros de las secuencias de control con un prefijo <, = o > como texto, por ejemplo 35;59;1M de un informe del mouse ESC[<35;59;1M o 0;276;0c de una respuesta de terminal ESC[>0;276;0c. El texto después de las secuencias en modo teclado ESC= y ESC> aún se conserva (#11377)
  • Se corrigió que pi -e npm:<pkg> permaneciera en la versión de la primera descarga. En cada inicio y /reload, pi ahora reinstala un paquete npm -e sin una versión exacta cuando el registro tiene una versión coincidente más nueva. pi -e git:<repo>@<branch> también permaneció en su primer pago y ahora se recupera y se restablece en la sucursal; una referencia de hash de confirmación que ya está desprotegida no se recupera. El modo sin conexión y las comprobaciones fallidas mantienen la copia en caché (#11375, #11590)
  • Se corrigieron las rutas de Windows que se comparan entre mayúsculas y minúsculas. Cuando el directorio de trabajo y el directorio de inicio diferían solo en las mayúsculas de las letras de las unidades (c:\Users\me frente a C:\Users\me), las habilidades en ~/.agents/skills se cargaron dos veces, como habilidades de proyecto y de usuario, y se informaron como colisiones de nombres. La misma discrepancia también volvió a solicitar el proyecto guardado trust, ocultó sesiones en un directorio de sesión personalizado de --continue y /resume, e impidió que pi remove coincidiera con los paquetes locales configurados (#10488)
  • Se corrigieron las rutas al lado del directorio de inicio que se muestran con un prefijo ~ roto, por ejemplo, /home/me2/project se muestra como ~2/project cuando el inicio es /home/me.
  • Se corrigió que pi mcp login -l y pi mcp logout -l fallaran con Unknown option --local. aunque pi mcp add y pi mcp remove aceptan -l. Con -l, ahora requieren que el servidor sea un servidor de proyectos. Las opciones desconocidas ahora se informan como escritas y un nombre de servidor mal escrito recibe una sugerencia, por ejemplo Did you mean "gurker"?
  • Se corrigió el nombre pnpm de pi update para instalaciones que solo se encuentran bajo PNPM_HOME, por ejemplo, un contenedor bajo $PNPM_HOME/global-nub/. pi dijo "no administrado por una instalación global de pnpm"; ahora nombra el administrador de paquetes solo cuando ese administrador es propietario de la instalación (#7756)
  • Se corrigió que la imagen al pegar, copiar y abrir el navegador para iniciar sesión fallara silenciosamente en WSL cuando el directorio de trabajo es profundo. Los programas de Windows como powershell.exe y explorer.exe no pueden iniciarse desde un directorio cuya ruta \\wsl.localhost\... supere los 260 caracteres; pi ahora inicia estos ayudantes desde / (#11592)
  • Se corrigió que el editor externo fallara silenciosamente, por ejemplo, cuando el comando del editor era incorrecto o un editor de Windows no podía iniciarse desde un directorio WSL profundo. pi ahora muestra un mensaje de estado como External editor exited with code 1; prompt unchanged (#11592)
  • Se corrigió que tool_search y el modo de código searchTools() clasificaran una herramienta debajo de las herramientas que solo mencionan su nombre en sus descripciones, por ejemplo, peekaboo app clasificaba a mcp__peekaboo__app en el puesto 14. Una herramienta que coincide con más palabras de la consulta ahora se clasifica por encima de una que coincide con menos, una palabra de consulta en el nombre de una herramienta obtiene más que cualquier número de menciones en su descripción, una herramienta cuyo nombre completo está en la consulta obtiene una gran bonificación y las instrucciones largas del servidor ya no reducen las puntuaciones de las herramientas de ese servidor (#11331)
  • Se corrigió que tool_search y el modo de código searchTools() no encontraran nada para consultas en chino, japonés, tailandés y otras consultas que no sean ASCII, porque el tokenizador conservaba solo letras y dígitos ASCII. Las palabras en cualquier escritura ahora coinciden, el texto sin espacios entre palabras como 搜索记录 se divide en palabras y el texto canónicamente equivalente como café y cafe\u0301 coincide (#10816, #11037 por @haoqixu)
  • Se corrigió que pi update se detuviera con git clean -fdx failed with code 1 en Windows cuando otra sesión de pi tenía abierto el módulo nativo o ejecutable de una extensión git. Windows no puede eliminar dichos archivos, por lo que la actualización dejó el nuevo código con las dependencias antiguas. pi ahora advierte, instala las dependencias de todos modos y vuelve a intentar la limpieza en la próxima actualización (#11597)
  • Se corrigieron filas de herramientas y respuestas transmitidas que resaltaban el mismo código nuevamente en cada rediseño. Una fila de modo de código en ejecución resaltó su script completo en cada actualización de progreso y tic del temporizador, una fila write completa, su archivo completo en cada actualización y alternancia de expansión, un write transmitido sus primeras 50 líneas en cada delta y una respuesta transmitida en cada bloque de código anterior en cada delta. Las filas ahora reutilizan su último resaltado hasta que el código, el tema o las gramáticas cargadas cambien, y los mensajes del asistente mantienen sus bloques Markdown renderizados durante la transmisión (#10971)
  • Se corrigió que las fotos redimensionadas se enviaran como PNG de varios megabytes incluso cuando JPEG era mucho más pequeño, lo que provocaba que las solicitudes grandes fallaran o se agotaran el tiempo de espera. El cambio de tamaño de la imagen ahora prueba primero la codificación más pequeña (#11551)
  • Se corrigió el éxito del informe pi update --extensions sin previo aviso cuando los metadatos de registro obsoletos de npm dejaban un paquete en su versión anterior. pi ahora informa las versiones instaladas y esperadas (#11536)
  • Se corrigieron las advertencias de validación de habilidades que estaban etiquetadas como [Skill conflicts] incluso cuando no había colisión de nombres. Ahora se muestran en [Skill warnings] (#11521)
  • Se corrigieron las descripciones de las herramientas de modo de código que incluyen tipos de salida de unión completa y de múltiples líneas en cada solicitud. Las uniones de objetos ahora resumen sus campos y discriminadores; otros tipos de líneas múltiples apuntan a describeTool() para obtener la declaración completa (#11501)
  • Se corrigió el aviso de inicio del alcance del modelo que quedaba en el shell después de salir del modo de pantalla completa. Ahora aparece dentro del encabezado de pantalla completa de pi (#11508)
  • Se corrigió el inicio desde un directorio de trabajo eliminado que fallaba con un seguimiento de pila uv_cwd no detectado. pi ahora le pide al usuario que cambie a un directorio existente (#11509)
  • Se corrigieron las escrituras fallidas de sesiones que dejaban entradas en la memoria que estaban ausentes del disco, por lo que las entradas posteriores apuntaban a padres faltantes y las sesiones reanudadas perdían el historial y las herramientas anteriores (#11460)
  • Se corrigieron los resúmenes de la rama /tree que ignoraban el nivel de pensamiento de la sesión, lo que podía hacer que los modelos de razonamiento rechazaran solicitudes de resumen con un esfuerzo none no compatible (#11444)
  • Se corrigió el pensamiento oculto con una etiqueta vacía de pensamiento oculto que aún agrega filas en blanco antes de las respuestas y las llamadas a herramientas (#11402)
  • Se corrigió la instalación y eliminación de paquetes que imprimían asesoramiento sobre financiación y auditoría de npm, incluidas instrucciones npm audit fix que podrían instalar una segunda copia de pi en el directorio del paquete (#11409)
  • Se corrigió el reemplazo de un editor de extensión mientras un cuadro de diálogo estaba abierto, ocultando el cuadro de diálogo y dejándolo sin respuesta. El nuevo editor ahora aparece después de que se cierra el cuadro de diálogo (#11431)
  • Se corrigió que las líneas de contexto grep se desplazaran de los números de línea coincidente de ripgrep cuando un archivo contiene un único retorno de carro (#11398)
  • Se corrigió el error --model <provider>/<id> para los ID de proveedores que contenían barras, como los ID de proveedores de llama.cpp derivados de URL (#11394)
  • Se corrigió la bifurcación de sesión lenta en sistemas de archivos donde abrir archivos es costoso al escribir la bifurcación a través de un identificador de archivo (#11253)
  • Se corrigió que pi.exec() corrompiera caracteres UTF-8 divididos en fragmentos stdout o stderr (#11312)
  • Se corrigió que pi.exec() devolviera stderr vacío cuando no se podía generar un comando, como por ejemplo un ejecutable faltante. Ahora conserva el mensaje de error de generación (#11257 por @muyiyr)
  • Se corrigió un paquete configurado que no se podía instalar y fallaba en el inicio. pi ahora omite el paquete, informa una advertencia de extensión y vuelve a intentarlo en el siguiente inicio o /reload; Los comandos explícitos de instalación y actualización aún fallan con una salida distinta de cero (#11304 por @Lincoln504)
  • Se corrigió el ejemplo de la extensión de tareas que bloqueaba la TUI cuando una llamada de herramienta fallaba en la validación de argumentos (#8057 por @cyzlmh)
  • Se actualizó undici a 8.12.3 y el ejemplo de extensión Gondolin a 0.14.0 para avisos de seguridad.
  • Se corrigieron los totales de costos de OpenRouter utilizando estimaciones de catálogo en lugar de facturación informada por finalización de chat y mensajes antrópicos. Los totales de BYOK incluyen tanto los cargos de OpenRouter como los costos ascendentes informados; los costos de los componentes siguen siendo estimaciones del catálogo (#9980)

Ahora se convierten a esquemas enum de valor único sin reescribir datos literales en valores predeterminados, ejemplos o valores de enumeración, ni perder propiedades denominadas __proto__ (#11308)

Ahora envían el esfuerzo de razonamiento correcto, conservan el pensamiento anterior, aceptan herramientas agregadas a mitad de la conversación y utilizan los precios de la familia K3.
  • Se corrigió que las solicitudes Flash de OpenCode DeepSeek V4.1 fallaran cuando la retención prolongada de caché enviaba el parámetro prompt_cache_retention no admitido.
  • Se corrigió que GPT-5.4 y GPT-5.5 fallaran con Missing namespace for function_call después de cambiar de un modelo que había llamado herramientas (#11415)
  • Se corrigió que las solicitudes de Bedrock Claude fallaran cuando las herramientas estrictas preferidas exceden los límites de herramientas estrictas del proveedor. Las solicitudes ahora se reintentan una vez con las herramientas preferidas no estrictas y al mismo tiempo se mantienen estrictas las herramientas requeridas (#11416)
  • Se corrigió que los alias ~anthropic/claude-*-latest de OpenRouter perdieran el pensamiento anterior después de llamadas a herramientas mediante el uso de Anthropic Messages API (#9534)
  • Se corrigieron los títulos de terminales que contenían caracteres de control que podían inyectar secuencias de escape de terminales y flujos de mensajes pi que aceptaban índices de bloques de contenido no válidos.
  • Se corrigió la selección de doble click en pantalla completa que dividía rutas y tokens en ~, ., \ y +; los caracteres de palabra ahora coinciden con los valores predeterminados de iTerm2 (#10980)
  • Se corrigió que las matemáticas de visualización fueran más anchas que el área de contenido dividida por ajuste de línea; ahora recurre a LaTeX sin formato (#11483)
  • Se corrigieron las palabras con estilo que terminaban exactamente en el ancho de la línea ajustada agregando un espacio inicial en la línea siguiente y el tachado se filtraba en el relleno de la línea ajustada (#10925)
  • Se corrigieron los resúmenes de la rama /tree que incluían respuestas fallidas del asistente y contenido original que las ediciones de contexto habían ocultado o reemplazado. Los resúmenes ahora respetan las mismas ediciones de contexto que las solicitudes en vivo y la compactación (#11602)

Eliminado

  • Se eliminó el ejemplo de extensión nativa del sistema operativo sandbox/ y su dependencia. Utilice el ejemplo de Gondolin o la guía de contenedorización.

pi v1.5.0

New Features

  • Extension update changelogs: see what changed in installed extension packages on the next fresh launch after an update. Package authors can choose the changelog path, and collapseChangelog condenses the notices. See Show a changelog.
  • Faster streaming: large tool calls are parsed incrementally, and code-heavy answers and tool rows reuse highlighting and rendered Markdown instead of repeating the work on every update. See Keep rendering responsive.
  • Custom self-update commands: use PI_SELF_UPDATE_COMMAND or selfUpdateCommand to update pi through a wrapper or another package manager. See Custom update command.
  • GPT-6.1 Terra: available through OpenAI, Azure OpenAI Responses, and OpenAI Codex, with tool search, mid-conversation thinking-level changes, and thinking off. Codex offers a 500K context window. See Models.

Breaking Changes

  • Tool argument validation runs on @earendil-works/pi-schema. TypeBox features outside JSON Schema (Type.Refine(), Type.BigInt(), Type.Undefined(), codecs, Format.Set() formats) no longer apply to tool arguments; see Tool parameter schemas and TypeBox. Plain JSON Schema tools, including MCP tools, now get the same coercion as TypeBox tools, such as converting numeric strings and wrapping a single value into an array. Validation failures the model sees list pi-schema's messages (- path: missing, - limit: expected number, got string) instead of TypeBox's (must have required properties path, must be number).

Added

  • Extension packages can now show their changelog after an update. Pi reads pi.changelogPath from the package's package.json, or CHANGELOG.md in the package root, and on the next fresh launch shows entries newer than the last seen version under "Extension Updates". The collapseChangelog setting condenses this to one line per package (#5958, #8790)
  • pi.exec() accepts a maxBuffer option that limits stdout and stderr combined, and its result has a truncated field that is true when output exceeded the limit (#11360)
  • Device-code login (for example GitHub Copilot) now opens the verification page and copies the code when you press Enter. Providers can turn either action off with openBrowserOnConfirm: false or copyCodeOnConfirm: false (#9282, #9301)
  • pi update can update Pi through a wrapper or another package manager. Set PI_SELF_UPDATE_COMMAND (for example mise use -g npm:{packageName}@{version}) or the global selfUpdateCommand setting; pi update runs it when pi.dev reports a newer release and fills {packageName}, {version}, and {installSpec} from that release. See Custom update command (#7756, #5607)
  • Extensions can format the user's configured keybindings with keyText() and keyHint() from the tool render context and the message and entry renderer options. Importing these functions from @earendil-works/pi-coding-agent can resolve the extension's own copy of the package, which does not see pi's keybindings, so hints such as keyHint("app.tools.expand", "to expand") rendered without the key. The docs now recommend the injected functions (#4748)
  • Added persisted session-entry messageId and ISO timestamp to MarkdownTransformContext. They are available when rendering saved entries and undefined for live rendering (#7952 by @vipentti)
  • Added a blocked option to inline ctx.ui.custom() components so approval prompts and other custom dialogs can report that pi is waiting for user input. Overlays ignore the option. See Custom screens and overlays (#11428)
  • Added Usage.cost.totalFromProvider to distinguish billed totals from catalog estimates in SDK and extension usage data; combined usage is marked provider-reported only when every part is (#11178)
  • Added concrete responseModel metadata to messages from pi-messages providers such as Radius, including when a virtual model is requested. See AssistantMessage (#11265)
  • Added GPT-6.1 Terra for OpenAI, Azure OpenAI Responses, and OpenAI Codex, with tool search and mid-conversation thinking-level changes. It supports thinking off; Codex offers a 500K context window

Changed

  • Extensions keep importing Type, Static and TSchema from @earendil-works/pi-ai: Pi maps that import to pi-ai's compat entry plus the TypeBox it bundles, now that pi-ai itself no longer re-exports TypeBox, and its StringEnum there stays a TypeBox TUnsafe<T>. The built-in tool factories (createReadTool() and the others) return TypeBoxAgentTool<typeof schema>, which keeps params typed for TypeBox.
  • Tightened system prompt
  • pi update for installs from the pi.dev installer no longer passes --min-release-age=0 to npm ci. The release lockfile pins every package, so the flag had no effect, and security scanners that block it stopped the update (#11262)
  • /model and /scoped-models now show a model's name next to its ID when the name adds words the ID lacks, such as a renamed models.json override (#5916, #11347)
  • MCP OAuth sign-in now uses pi's Client ID Metadata Document by default when the authorization server supports it for public clients, and registers a client dynamically otherwise, like Codex, Claude Code, and opencode. Clients registered before stay in use while their redirect URI matches. The new default oauth.clientRegistration: "auto" registers when clientName or a non-default callbackUrl is set; "dcr" always registers. pi mcp add --oauth-client-registration sets the mode (#11426)
  • Changed the default OpenAI model from gpt-5.5 to gpt-6.1-sol, including after ChatGPT sign-in when no model is selected (#11442)
  • Updated the built-in model catalog to models.dev v2. Realtime and image-only models are no longer offered as chat models; newer OpenAI and Google chat models are included

Fixed

  • Updated glob matching to prevent denial of service from amplified glob patterns.
  • Fixed a saved "Do not trust" decision being ignored for projects without trust-requiring resources, for example a folder with only AGENTS.md. pi auto-trusted such projects, so ctx.isProjectTrusted() returned true and package commands treated them as trusted. A saved decision in trust.json now takes precedence; auto-trust applies only when no decision is saved (#10947)
  • Fixed Shift+Enter queueing a follow-up instead of inserting a newline in Apple Terminal setups that send ESC + Return. pi now checks the local Shift key state for that sequence, as it already did for plain Return; Alt+Enter without Shift still queues a follow-up (#11559)
  • Fixed the working status (OSC 7501) disappearing in Rex and iTerm2 during runs in regular TUI mode. Rendered messages wrote OSC 133 prompt markers to the terminal, which the terminal treats as a new shell prompt; regular mode no longer writes them (#11519)
  • Fixed compaction, branch summaries, and bug-report summaries in SDK sessions passing the stored OAuth token back to the model runtime as an explicit API key. Provider auth that treats explicit keys differently from stored OAuth now sees the OAuth login, as normal prompts do (#11520)
  • Fixed a redundant system prompt update (tools, rules) when an extension set the same active tools in a different order, for example a reversed pi.setActiveTools() list. Tools that stay active now keep their order and newly activated tools are appended (#11495)
  • Fixed pi.exec() crashing pi with RangeError: Invalid string length when a command printed more output than fits in a string. The default output cap is the smaller of 256 MiB and the runtime string limit; past the cap, the command is terminated and the result has truncated: true and a nonzero exit code (#11360)
  • Fixed pi.exec() never returning when a command ignored SIGTERM after a timeout or abort. pi now sends SIGKILL 5 seconds later, as intended
  • Fixed pi install and pi remove adding ever deeper nested entries to the npm package-lock.json when the agent directory is reached through a symlink, such as ~/.pi linked into a dotfiles repo. pi now passes the resolved real path to npm (#11358)
  • MCP sign-in now rejects authorization endpoints and other OAuth metadata URLs that are not http: or https:. Before, a malicious MCP server could supply a file: or custom protocol URL, which pi passed to the platform URL handler.
  • Automatic fd and rg downloads no longer fetch x86-64 binaries on ARM32 and other architectures without a prebuilt release. pi now warns and recommends installing the tool with the system package manager (#11209)
  • Fixed /model search ranking letters scattered over an earlier part of an entry above a real match, for example opus listing gpt-oss-120b and claude-sonnet-4.5 before claude-opus-4.1 (#11220, #11296)
  • Fixed /resume search matching scattered letters anywhere in session messages and IDs, for example 1024 matching inside a session UUID. Session names and working directories still match fuzzily; IDs and message text now match only as exact substrings (#11220, #11024, #11296)
  • Fixed HTML export showing a blank page for sessions with thousands of entries (#11225, #11293)
  • Fixed HTML export not showing system messages: the system prompt and tools, and later section updates such as after /reload. pi --export now includes the system prompt and tools too (#11261, #3464, #11290)
  • Fixed aborting a bash command on macOS sometimes running the next command of a list such as long_step; next_step. pi now stops the process group before killing it (#11252, #11289)
  • Fixed large streamed tool calls taking excessive CPU time and memory because every delta re-parsed the accumulated arguments. Providers and agent proxy streams now parse each delta once, grammar tools no longer copy their entire input per delta, and interactive tool renderers run at most once per frame (#9265)
  • Fixed the login dialog opening sign-in URLs that are not web URLs, and printing control characters from sign-in, device-code, and info URLs, which could end a terminal hyperlink and send escape sequences to the terminal
  • Fixed tui.select.pageUp and tui.select.pageDown being ignored in slash command and file autocomplete, /settings, and the model, scoped models, login, fork, /mcp, and llama.cpp selectors. In fullscreen mode, PageUp/PageDown now move an open list or autocomplete menu instead of scrolling the transcript, and a page key bound to Ctrl+V pages autocomplete instead of pasting an image (#7629, based on #7680 by @muyiyr)
  • Fixed tool output and ! command output showing the parameters of control sequences with a <, = or > prefix as text, for example 35;59;1M from a mouse report ESC[<35;59;1M or 0;276;0c from a terminal reply ESC[>0;276;0c. Text after the keypad-mode sequences ESC= and ESC> is still kept (#11377)
  • Fixed pi -e npm:<pkg> staying on the version from the first download. On each start and /reload, pi now reinstalls an -e npm package without an exact version when the registry has a newer matching version. pi -e git:<repo>@<branch> likewise stayed on its first checkout and is now fetched and reset to the branch; a commit-hash ref that is already checked out is not fetched. Offline mode and failed checks keep the cached copy (#11375, #11590)
  • Fixed Windows paths being compared case-sensitively. When the working directory and home directory differed only in drive-letter casing (c:\Users\me vs C:\Users\me), skills in ~/.agents/skills loaded twice, as project and user skills, and were reported as name collisions. The same mismatch also re-asked for saved project trust, hid sessions in a custom session directory from --continue and /resume, and stopped pi remove from matching configured local packages (#10488)
  • Fixed paths next to the home directory being shown with a broken ~ prefix, for example /home/me2/project shown as ~2/project when home is /home/me
  • Fixed pi mcp login -l and pi mcp logout -l failing with Unknown option --local. although pi mcp add and pi mcp remove accept -l. With -l, they now require the server to be a project server. Unknown options are now reported as typed, and a mistyped server name gets a suggestion, for example Did you mean "gurker"?
  • Fixed pi update naming pnpm for installs that only live under PNPM_HOME, for example a wrapper under $PNPM_HOME/global-nub/. pi said "not managed by a global pnpm install"; it now names the package manager only when that manager owns the install (#7756)
  • Fixed image paste, copy, and opening the browser for sign-in failing silently on WSL when the working directory is deep. Windows programs such as powershell.exe and explorer.exe cannot start from a directory whose \\wsl.localhost\... path exceeds 260 characters; pi now starts these helpers from / (#11592)
  • Fixed the external editor failing silently, for example when the editor command is wrong or a Windows editor cannot start from a deep WSL directory. pi now shows a status message such as External editor exited with code 1; prompt unchanged (#11592)
  • Fixed tool_search and codemode searchTools() ranking a tool below tools that only mention its name in their descriptions, for example peekaboo app ranking mcp__peekaboo__app 14th. A tool matching more of the query's words now ranks above one matching fewer, a query word in a tool's name scores more than any number of mentions in its description, a tool whose whole name is in the query gets a large bonus, and long server instructions no longer lower the scores of that server's tools (#11331)
  • Fixed tool_search and codemode searchTools() finding nothing for Chinese, Japanese, Thai, and other non-ASCII queries, because the tokenizer kept only ASCII letters and digits. Words in any script now match, text without spaces between words such as 搜索记录 is split into words, and canonically equivalent text such as café and cafe\u0301 matches (#10816, #11037 by @haoqixu)
  • Fixed pi update stopping with git clean -fdx failed with code 1 on Windows when another pi session had a git extension's native module or executable open. Windows cannot delete such files, so the update left the new code with the old dependencies. pi now warns, installs the dependencies anyway, and retries the clean on the next update (#11597)
  • Fixed tool rows and streamed answers highlighting the same code again on every redraw. A running codemode row highlighted its whole script on every progress update and timer tick, a complete write row its whole file on every update and expand toggle, a streamed write its first 50 lines on every delta, and a streamed answer every earlier code block on every delta. Rows now reuse their last highlighting until the code, theme, or loaded grammars change, and assistant messages keep their rendered Markdown blocks while streaming (#10971)
  • Fixed resized photos being sent as multi-megabyte PNGs even when JPEG was much smaller, causing large requests to fail or time out. Image resizing now tries the smaller encoding first (#11551)
  • Fixed pi update --extensions reporting success without warning when npm's stale registry metadata left a package at its old version. pi now reports the installed and expected versions (#11536)
  • Fixed skill validation warnings being labeled [Skill conflicts] even when there was no name collision. They are now shown under [Skill warnings] (#11521)
  • Fixed codemode tool descriptions including entire union and multi-line output types in every request. Object unions now summarize their fields and discriminators; other multi-line types point to describeTool() for the full declaration (#11501)
  • Fixed the model-scope startup notice being left in the shell after exiting fullscreen mode. It now appears inside pi's fullscreen header (#11508)
  • Fixed startup from a deleted working directory crashing with an uncaught uv_cwd stack trace. pi now asks the user to change to an existing directory (#11509)
  • Fixed failed session writes leaving entries in memory that were absent from disk, so later entries pointed to missing parents and resumed sessions lost earlier history and tools (#11460)
  • Fixed /tree branch summaries ignoring the session's thinking level, which could make reasoning models reject summary requests with an unsupported none effort (#11444)
  • Fixed hidden thinking with an empty hidden-thinking label still adding blank rows before answers and tool calls (#11402)
  • Fixed package installation and removal printing npm audit and funding advice, including npm audit fix instructions that could install a second copy of pi into the package directory (#11409)
  • Fixed replacing an extension editor while a dialog was open hiding the dialog and leaving it unanswerable. The new editor now appears after the dialog closes (#11431)
  • Fixed grep context lines being offset from ripgrep's match line numbers when a file contains a lone carriage return (#11398)
  • Fixed --model <provider>/<id> failing for provider IDs containing slashes, such as URL-derived llama.cpp provider IDs (#11394)
  • Fixed slow session forking on filesystems where opening files is expensive by writing the fork through one file handle (#11253)
  • Fixed pi.exec() corrupting UTF-8 characters split across stdout or stderr chunks (#11312)
  • Fixed pi.exec() returning empty stderr when a command could not be spawned, such as a missing executable. It now preserves the spawn error message (#11257 by @muyiyr)
  • Fixed a configured package failing to install crashing startup. pi now skips the package, reports an extension warning, and retries on the next start or /reload; explicit install and update commands still fail with a nonzero exit (#11304 by @Lincoln504)
  • Fixed the todo extension example crashing the TUI when a tool call failed argument validation (#8057 by @cyzlmh)
  • Updated undici to 8.12.3 and the Gondolin extension example to 0.14.0 for security advisories
  • Fixed OpenRouter cost totals using catalog estimates instead of reported billing for Chat Completions and Anthropic Messages. BYOK totals include both OpenRouter charges and reported upstream costs; component costs remain catalog estimates (#9980)
  • Fixed OpenCode Zen and OpenCode Go requests using shared endpoints instead of their protocol-specific OpenAI, Anthropic, Google, and System One endpoints (#11434 by @vimtor)
  • Fixed Zhipu/Z.ai usage-limit errors (code 1308) being treated as transient HTTP 429 errors, causing automatic retries that cannot succeed until the usage cap resets (#11537)
  • Fixed LiteLLM's ContextWindowExceededError not being recognized as context overflow (#11492)
  • Fixed Gemini tool schemas sending unsupported const keywords. They are now converted to single-value enum schemas without rewriting literal data in defaults, examples, or enum values, or losing properties named __proto__ (#11308)
  • Fixed the faux provider counting simulated cache-write tokens as both input and cache writes
  • Fixed Orca terminals falling back to text for inline images. Orca is now recognized as supporting true color and hyperlinks, and Kitty images when it advertises ORCA_IMAGE_PROTOCOL=kitty (#9329 by @XRX193)
  • Fixed bare Markdown URLs swallowing following CJK punctuation and text; explicit Markdown links and angle autolinks are unchanged (#10934 by @haoqixu)
  • Fixed Kitty-protocol F1–F12 shortcuts, including modified function keys, not being recognized, and F13+ and other functional keys inserting invisible private-use characters into the editor (#11419, #11345)
  • Fixed Kitty images inside padded or colored boxes disappearing when their first row scrolled above the fullscreen viewport. Partially visible images are now cropped correctly, including beside other text
  • Fixed deeply nested Markdown blockquotes producing exponentially many lines, hanging or crashing rendering once their borders exhausted the available width (#11272)
  • Fixed Claude sessions failing with role 'system' must precede an 'assistant' message when a system update was followed by an empty or reasoning-only assistant reply (#11091)
  • Fixed Claude mid-conversation thinking-level changes failing with Invalid effort level on accounts whose organization caps effort below high (#10063)
  • Fixed Kimi K3.1 Pro models using Kimi K2 request settings on Kimi Coding, Moonshot, and OpenCode Go. They now send the correct reasoning effort, preserve earlier thinking, accept tools added mid-conversation, and use K3-family pricing
  • Fixed OpenCode DeepSeek V4.1 Flash requests failing when long cache retention sent the unsupported prompt_cache_retention parameter
  • Fixed GPT-5.4 and GPT-5.5 failing with Missing namespace for function_call after switching from a model that had called tools (#11415)
  • Fixed Bedrock Claude requests failing when preferred strict tools exceed the provider's strict-tool limits. Requests now retry once with preferred tools non-strict while keeping required strict tools strict (#11416)
  • Fixed OpenRouter's ~anthropic/claude-*-latest aliases losing earlier thinking after tool calls by using the Anthropic Messages API (#9534)
  • Fixed terminal titles containing control characters being able to inject terminal escape sequences, and pi-messages streams accepting invalid content-block indices
  • Fixed fullscreen double-click selection splitting paths and tokens at ~, ., \, and +; word characters now match iTerm2's defaults (#10980)
  • Fixed display math wider than the content area being split apart by line wrapping; it now falls back to raw LaTeX (#11483)
  • Fixed styled words ending exactly at the wrap width adding a leading space on the next line, and strikethrough leaking into wrapped-line padding (#10925)
  • Fixed /tree branch summaries including failed assistant replies and original content that context edits had hidden or replaced. Summaries now honor the same context edits as live requests and compaction (#11602)

Removed

  • Removed the native OS sandbox/ extension example and its dependency. Use the Gondolin example or the containerization guide.
