#piv0.99.2

Nuevas características

  • Los servidores MCP se mantienen alejados: los servidores con la exposición predeterminada codemode ya no aparecen en la descripción de codemode y ya no bloquean el primer mensaje. Aparecen en una breve sección de avisos del sistema y los scripts encuentran sus herramientas con searchTools() y describeNamespace(). Consulte [Controlar la exposición de la herramienta] (https://github.com/earendil-works/pi/blob/v0.99.2/packages/coding-agent/docs/mcp.md#control-tool-exposure).
  • Más opciones de autenticación MCP: oauth.clientName para servidores que solo aceptan OAuth clients conocidos y "auth": { "provider": "<provider>" } para autenticar servidores HTTP con el token /login de un proveedor. Consulte Autenticar con OAuth.
  • Federación de identidades de carga de trabajo Anthropic a partir de las variables de entorno Anthropic SDK. Consulte Usar una clave API del entorno.
  • /reload habilita herramientas recién agregadas a la configuración defaultTools. Consulte Herramientas.

Agregado

  • Se agregó un campo description para servidores MCP (pi mcp add --description), que se muestra con el servidor en el indicador del sistema y se usa para clasificar sus herramientas en la búsqueda de herramientas, y un asistente de modo de código describeNamespace(name) que devuelve las instrucciones de un espacio de nombres y los nombres de las herramientas. describeNamespace() y searchTools() aceptan un espacio de nombres como mcp__dev-radius, mcp__dev_radius, dev-radius o dev_radius.
  • Se agregó una configuración oauth.clientName para servidores MCP (pi mcp add --oauth-client-name) para cambiar el nombre client enviado durante el registro de OAuth client, ​​para servidores que solo aceptan clients conocidos (#10226).
  • Se agregó "auth": { "provider": "<provider>" } para que los servidores HTTP MCP envíen el token /login actual de un proveedor como token de portador en lugar de usar MCP OAuth. El token se lee en cada solicitud, por lo que se aplican las actualizaciones del proveedor. Solo se permite en el mcp.json global y desde extensiones, y requiere https excepto en hosts de bucle invertido.
  • Se agregó una federación de identidades de carga de trabajo antrópica de las variables de entorno ANTHROPIC_FEDERATION_RULE_ID, ANTHROPIC_ORGANIZATION_ID y ANTHROPIC_IDENTITY_TOKEN_FILE (consulte Proveedores) (#10177, #10242 por @philfreo).
  • /reload ahora habilita herramientas recién agregadas a la configuración defaultTools. Las herramientas eliminadas permanecen habilitadas, las herramientas desactivadas durante la sesión permanecen desactivadas a menos que se agreguen recientemente, y --tools, --no-tools y --no-builtin-tools aún anulan la configuración (#10245).

Cambiado

  • Los servidores MCP con la exposición predeterminada codemode ya no aparecen en la descripción de codemode; Los scripts los encuentran con searchTools(). codemode-deferred ahora es un alias de codemode. Utilice la exposición direct para las herramientas que el modelo debería ver sin buscar (#10212).
  • La descripción codemode ya no incluye herramientas diferidas, recuentos de herramientas ni instrucciones del servidor MCP, por lo que ya no cambia cuando los servidores MCP se conectan o cambian sus herramientas. La descripción tool_search ya no enumera los servidores cuyas herramientas puede cargar, por la misma razón. En cambio, los servidores se enumeran en una sección de mensajes del sistema mcp_servers con un resumen de una línea, actualizado al comienzo de cada mensaje; se adjunta una sección modificada a la conversación. Los scripts leen las instrucciones del servidor con describeNamespace() (#10212).
  • El primer mensaje ya no espera a los servidores MCP sin las herramientas direct. Se conectan en segundo plano y se les espera cuando un script de modo de código los nombra, un script busca herramientas o se ejecuta tool_search (#10212).

Fijo

  • Se corrigieron nuevas sesiones que ignoraban intermitentemente el modelo predeterminado guardado o advertían que no había modelos disponibles cuando pertenecían a un proveedor nativo registrado en una extensión con una credencial almacenada (#9962, #10190 por @davidbrai).
  • Se corrigió que la URL de inicio de sesión de /mcp no fuera clickable cuando cruzaba líneas, al emitirla como un hipervínculo de terminal con una línea Cmd/Ctrl+click to open como /login (#10186).
  • Se corrigió el modo de código image() que aceptaba datos base64 con formato incorrecto o tipos de imágenes no compatibles, lo que persistía en un bloque de imagen no válido que hacía que todas las solicitudes posteriores del proveedor fallaran con HTTP 400 (#10215).
  • Se corrigió que el modo de código no pudiera iniciar su script de trabajo desde el ejecutable independiente de Windows (#10204).
  • Se corrigió que el envío de mensajes se ralentizara con la duración de la sesión, porque al resolver la selección de modelo de la sesión se buscaba el catálogo de modelos una vez por mensaje del asistente (#10198).
  • Se corrigió que las búsquedas de modelos se ralentizaran para los proveedores con un catálogo pi.dev actualizado, porque la fusión de modelos de catálogo remotos tomaba un tiempo cuadrático.
  • Se corrigieron los ejemplos de extensión built-in-tool-renderer.ts y minimal-mode.ts eliminando los resúmenes y pautas de las herramientas integradas del indicador del sistema (#10072, #10193 por @christianklotz).
  • Se corrigió la detección de desbordamiento de contexto para los errores Prompt exceeds max length del terminal Z.AI CN (#10208).
  • Se corrigieron errores en las solicitudes antrópicas cuando el esquema de una herramienta utiliza palabras clave. El uso estricto de herramientas antrópicas rechaza, como minimum/maximum; dichas herramientas ahora se envían de forma no estricta (#9953).
  • Se corrigió que el proveedor reintenta activarse inmediatamente cuando un encabezado Retry-After contiene una fecha que no se puede analizar; ahora usan retroceso exponencial (#9571).
  • Se corrigieron los comandos de extensión registrados sin un nombre de cadena o controlador que bloqueaban pi al escribir /; la extensión ahora no se carga y genera un error (#10054).
  • Se corrigieron los resultados de las herramientas codemode y MCP colapsados ​​que llenaban la pantalla cuando la salida era una línea larga, como JSON minimizado. Al igual que la salida de bash, la vista previa ahora se limita a líneas ajustadas en lugar de líneas lógicas.
  • Se corrigió que codemode.mode: "only" incluyera read, bash, edit y write en la lista de herramientas del indicador del sistema, aunque las solicitudes solo declaran codemode (#10192).
  • Se corrigieron los scripts de modo de código que llamaban a la herramienta MCP incorrecta cuando dos nombres de herramientas difieren solo en - y _, como read-file y read_file. Al igual que en Codex, los nombres de espacios de nombres y herramientas MCP ahora reemplazan - con _ (mcp__my-server__x ahora es mcp__my_server__x), todas las herramientas en colisión de un servidor obtienen un sufijo hash y los nombres de servidores que difieren solo en - y _ se rechazan (#10239).

pi v0.99.2

New Features

  • MCP servers stay out of the way: servers with the default codemode exposure are no longer listed in the codemode description and no longer block the first prompt. They appear in a short system prompt section, and scripts find their tools with searchTools() and describeNamespace(). See Control tool exposure.
  • More MCP authentication options: oauth.clientName for servers that only accept known OAuth clients, and "auth": { "provider": "<provider>" } to authenticate HTTP servers with a provider's /login token. See Authenticate with OAuth.
  • Anthropic workload identity federation from the Anthropic SDK environment variables. See Use an API key from the environment.
  • /reload enables tools newly added to the defaultTools setting. See Tools.

Added

  • Added a description field for MCP servers (pi mcp add --description), shown with the server in the system prompt and used to rank its tools in tool search, and a describeNamespace(name) codemode helper that returns a namespace's instructions and tool names. describeNamespace() and searchTools() accept a namespace as mcp__dev-radius, mcp__dev_radius, dev-radius, or dev_radius.
  • Added an oauth.clientName setting for MCP servers (pi mcp add --oauth-client-name) to change the client name sent during OAuth client registration, for servers that only accept known clients (#10226).
  • Added "auth": { "provider": "<provider>" } for HTTP MCP servers to send a provider's current /login token as the bearer token instead of using MCP OAuth. The token is read on every request, so provider refreshes apply. Only allowed in the global mcp.json and from extensions, and requires https except on loopback hosts.
  • Added Anthropic workload identity federation from the ANTHROPIC_FEDERATION_RULE_ID, ANTHROPIC_ORGANIZATION_ID, and ANTHROPIC_IDENTITY_TOKEN_FILE environment variables (see Providers) (#10177, #10242 by @philfreo).
  • /reload now enables tools newly added to the defaultTools setting. Tools removed from it stay enabled, tools turned off during the session stay off unless newly added, and --tools, --no-tools, and --no-builtin-tools still override the setting (#10245).

Changed

  • MCP servers with the default codemode exposure no longer appear in the codemode description; scripts find them with searchTools(). codemode-deferred is now an alias for codemode. Use direct exposure for tools the model should see without searching (#10212).
  • The codemode description no longer includes deferred tools, tool counts, or MCP server instructions, so it no longer changes when MCP servers connect or change their tools. The tool_search description no longer lists the servers whose tools it can load, for the same reason. Servers are listed instead in an mcp_servers system prompt section with a one-line summary, updated at the start of each prompt; a changed section is appended to the conversation. Scripts read server instructions with describeNamespace() (#10212).
  • The first prompt no longer waits for MCP servers without direct tools. They connect in the background and are waited for when a codemode script names them, a script searches tools, or tool_search runs (#10212).

Fixed

  • Fixed new sessions intermittently ignoring the saved default model, or warning that no models are available, when it belongs to an extension-registered native provider with a stored credential (#9962, #10190 by @davidbrai).
  • Fixed the /mcp sign-in URL not being clickable when it wraps across lines, by emitting it as a terminal hyperlink with a Cmd/Ctrl+click to open line like /login (#10186).
  • Fixed codemode image() accepting malformed base64 data or unsupported image types, which persisted an invalid image block that made every later provider request fail with HTTP 400 (#10215).
  • Fixed codemode failing to start its script worker from the standalone Windows executable (#10204).
  • Fixed prompt submission slowing down with session length, because resolving the session's model selection looked up the model catalog once per assistant message (#10198).
  • Fixed model lookups slowing down for providers with a refreshed pi.dev catalog, because merging remote catalog models took quadratic time.
  • Fixed the built-in-tool-renderer.ts and minimal-mode.ts extension examples removing the built-in tools' summaries and guidelines from the system prompt (#10072, #10193 by @christianklotz).
  • Fixed context overflow detection for Z.AI CN endpoint Prompt exceeds max length errors (#10208).
  • Fixed Anthropic requests failing when a tool schema uses keywords Anthropic strict tool use rejects, such as minimum/maximum; such tools are now sent non-strict (#9953).
  • Fixed provider retries firing immediately when a Retry-After header contains an unparseable date; they now use exponential backoff (#9571).
  • Fixed extension commands registered without a string name or handler crashing pi when typing /; the extension now fails to load with an error instead (#10054).
  • Fixed collapsed codemode and MCP tool results filling the screen when the output is one long line, such as minified JSON. Like bash output, the preview is now limited to wrapped lines instead of logical lines.
  • Fixed codemode.mode: "only" listing read, bash, edit, and write in the system prompt's tool list although requests only declare codemode (#10192).
  • Fixed codemode scripts calling the wrong MCP tool when two tool names differ only in - and _, such as read-file and read_file. Like in Codex, MCP tool and namespace names now replace - with _ (mcp__my-server__x is now mcp__my_server__x), colliding tools of a server all get a hash suffix, and server names that differ only in - and _ are rejected (#10239).
