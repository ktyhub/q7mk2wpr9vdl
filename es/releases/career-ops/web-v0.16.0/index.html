career-ops web-v0.16.0

Highlights

  • Safer, more accurate application automation — Apply now stays inside its project-scoped browser rather than touching your Chrome (#5499), isolates failed CV uploads from other file fields (#5089), and inserts typed text instead of simulating keystrokes so newlines cannot accidentally submit forms (#5770).
  • New application and CV workflows — Each application gains an apply checklist with PDF readiness and follow-up seeds (#5131, #5304), while CV Studio adds review, customization, and per-bullet rewriting through your configured AI CLI (#5233, #5234). Agent CLI choices for doctor, ranker, and web are now remembered (#5467).
  • Broader automation and discovery — Scheduled scans come to macOS and Linux with actual failure reasons recorded (#5401, #5661), and opt-in China employer discovery is available without changing existing presets (#5431). Explore sampling now covers each source rather than only its alphabetical prefix (#5465).
  • Configuration paths behave consistently — CAREER_OPS_PROFILE is now honored for profile reads and writes, and resolved paths are named in agent prompts (#5096, #5588). CAREER_OPS_PORTALS is honored by the portals UI, API, and doctor (#5360, #5310); comment-only YAML no longer crashes (#5464), and portal filter saves preserve comments (#5646).
  • Security and operational hardening — Next.js moves to 16.4.1 for three GHSAs (#5771), and Next.js telemetry is disabled (#5596). Scheduled-job and chat locks adopt the shared directory-lock protocol (#5390); large trackers keep search responsive, and transcript metering reads only appended bytes (#5504, #5503).
  • Metrics and state handling are less misleading — Rates are omitted rather than shown as 0.0% with no applications, and a single application no longer produces a vendor rate (#5371, #5372). Failed status confirmations persist for manual retry (#5422), crashed pipeline writers are reported instead of added:0 (#5636), and “remember” now confirms before writing to your profile (#5456).

No breaking changes.
