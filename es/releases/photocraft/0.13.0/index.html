#fotografía v0.13.0

[!NOTA] FreeBSD aarch64 se elimina de esta versión. Tuvimos que eliminar las versiones y no podemos crear este objetivo dentro del límite de CI de 5 horas para ninguna de las aplicaciones Craft, por lo que lo eliminaremos por ahora. Este es un bloqueador conocido, marcado para una solución futura en storytold/craft-common-actions#39. Se incluyen FreeBSD x86_64 y todas las demás plataformas.
