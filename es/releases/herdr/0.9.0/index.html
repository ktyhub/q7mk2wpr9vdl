herdr v0.9.0

Menor Publicado7 sept 2026 Fuenteherdrdev/herdr original en inglés

pastor v0.9.0

Agregado

  • Administre máquinas SSH locales y guardadas desde una ventana de Herdr, con una lista de agentes combinada, navegación específica de la máquina, notificaciones y reconexiones automáticas. Agregue y administre conexiones con herdr machine; una máquina desconectada no interrumpe a las demás. (#3670)
  • Varios clients ahora pueden ver diferentes espacios de trabajo y pestañas de forma independiente. Diferentes pestañas se adaptan a sus clients de visualización; cuando clients comparte una pestaña, el último en interactuar con ella controla su tamaño. (#3526)
  • Se agregó detección de agente Muse para estados inactivo, en funcionamiento, de aprobación y de pregunta. (#2489, gracias @ohk)
  • El texto de la barra lateral y los tokens de metadatos ahora pueden cambiar de color, negrita y atenuación según sus valores, usando texto ordenado o reglas numéricas. (#3693)
  • Los temas personalizados ahora pueden definir anulaciones de colores claros y oscuros por separado cuando el cambio automático de tema está habilitado. (#2324, gracias @aneym)
  • ui.pane_borders = "always" ahora puede enmarcar un solo panel cuando los bordes exteriores están habilitados. "auto" mantiene los bordes solo divididos, "off" los oculta y los valores booleanos existentes siguen funcionando. (#3234, gracias @rsmdt)

Cambiado

  • Las actualizaciones de Client ahora pueden dejar intactos los servidores compatibles y sus agentes en ejecución. Las funciones faltantes del servidor desactivan solo la acción afectada en lugar de impedir la conexión. Los servidores anteriores a la generación 1 de endpoints necesitan una actualización única. Reemplazar un servidor remoto pregunta antes de detener los procesos de su panel, con No como respuesta predeterminada; la transferencia experimental sigue siendo voluntaria. (#3509)
  • La interfaz de usuario del terminal ahora se ejecuta en cada client, lo que reduce el trabajo de redibujado en sesiones ocupadas de múltiples client y mantiene los temas, menús, modo de copia y otras configuraciones de presentación locales en la máquina de visualización. (#3487)
  • El desplazamiento hacia atrás del terminal inactivo ahora usa menos memoria sin reducir el historial retenido ni cambiar las lecturas ni cambiar el tamaño. (#3556)
  • Las imágenes del panel y los gráficos API ahora están habilitados por defecto en terminales compatibles. Configure terminal.kitty_graphics = false para desactivarlos; la antigua configuración experimental.kitty_graphics sigue siendo aceptada.
  • Cerrar un espacio de trabajo principal con espacios de trabajo de árbol de trabajo abiertos ahora requiere una intención de grupo explícita: workspace close --group o workspace.close con close_group: true. De lo contrario, todo el grupo permanece abierto. (#2874)
  • Las nuevas suscripciones a eventos del ciclo de vida ahora comienzan con eventos en vivo en lugar de reproducir el historial retenido. API clients deben suscribirse antes de tomar su instantánea inicial para evitar perder cambios. (#1270)

Fijo

  • Las selecciones del mouse ahora permanecen visibles y copiables mientras continúa la salida del terminal, incluso con la copia automática desactivada. Ctrl+C y Cmd+C copian una selección incluso antes de soltar el mouse con retraso, y una copia fallida ya no interrumpe al agente. Los aspectos destacados de la selección también permanecen visibles cuando los colores del host no están disponibles. (#3100, #2708, #3684, gracias @moret y @Pimpmuckl)
  • Las copias del tablero Wayland cli ya no congelan a Herdr mientras wl-copy sirve la selección. (#3014)
  • La transferencia en vivo ahora conserva el reenvío del mouse para ejecutar aplicaciones del panel. (#3000, gracias @xkrogen)
  • Las salidas del panel interrumpidas durante el apagado del host ya no reemplazan la sesión guardada con una sesión vacía o un nuevo espacio de trabajo predeterminado. (#3415)
  • SSH clients cuyo terminal desaparece ahora se desconecta en lugar de cambiar el tamaño de los paneles en ejecución a un tamaño alternativo y desencadenar un costoso reflujo del historial. (#3519)
  • Al enfocar un espacio de trabajo ahora se desplaza la barra lateral para mantenerla visible. (#3554)
  • La eliminación de un espacio de trabajo del árbol de trabajo en segundo plano ya no cambia el foco a su principal. Los árboles de trabajo de Windows también se pueden eliminar mientras se ejecutan los paneles de agente, sin que un shell de reemplazo bloquee nuevamente la caja. (#3098, #3532)
  • Los comandos de Worktree ahora pueden trust un repositorio verificado para una solicitud con --trust-repository, incluidos repositorios de Windows accesibles propiedad de otro SID, sin cambiar la configuración global de Git. (#3044)
  • Las imágenes de Kitty de gran tamaño ya no impiden que aparezcan imágenes más pequeñas y los reemplazos de imágenes ya no se vuelven a dibujar ni desaparecen una fila a la vez. Los gráficos directos permanecen vinculados al client que los posee. (#3033, #3166, #3549, gracias @kataokatsuki)
  • Las coordenadas del mouse de píxeles permanecen correctas cuando las aplicaciones del panel reafirman los informes del mouse SGR. (#3295)
  • Las vinculaciones de prefijos como prefix+| ahora reconocen caracteres producidos por macOS Option y diseños de teclado personalizados, mientras que los acordes exactos mantienen la prioridad. La navegación con flechas también funciona cuando terminales como Alacritty adjuntan texto a informes de claves especiales. (#3079, #3328, gracias @vlcinsky)
  • Las conexiones directas de terminal ahora respetan ui.mouse_capture y conservan los pegados de varias líneas como un solo pegado en lugar de enviar cada línea por separado. (#2992, #3054)
  • agent prompt ahora envía de manera confiable el mensaje y Enter antes de informar el envío exitoso. Con --wait, los avisos enviados a un agente que no funciona requieren actividad observada en funcionamiento o bloqueada, por lo que los cambios de estado no relacionados no pueden completar la espera. Los envíos pendientes fallan limpiamente si se cierra la terminal. (#3506, #3685)
  • Las indicaciones largas del Codex en Windows ahora esperan el tiempo suficiente para que llegue el texto antes de enviar Enter. Los envíos vencidos en cola se rechazan antes de que comience a escribirse. (#3187)
  • Las lecturas recientes del panel ahora incluyen resultados que aún no se han desplazado fuera de la ventana gráfica, en lugar de devolver texto vacío. (#3444)
  • pane report-agent y pane report-agent-session ahora aceptan opciones antes del ID del panel y los argumentos --option=value. (#2926)
  • herdr agent explain --file ahora informa archivos ilegibles como errores JSON estructurados en lugar de errores Rust sin formato. (#3022)
  • La ejecución de servidores con nombre ahora recoge los manifiestos de detección descargados por otro servidor sin necesidad de reiniciar. (#2711)
  • Los agentes que configuran el título o el progreso de su terminal una vez al inicio ya no pierden esa señal de detección cuando se los reconoce por primera vez. (#3326, gracias @aneym)
  • Claude Code ahora reconoce la actividad visible de los agentes en segundo plano y de turno cuando los títulos de la terminal no están disponibles y permanece funcionando mientras continúan las tareas de MCP en segundo plano. Un mensaje inactivo con solo un shell en segundo plano ejecutándose ya no sigue funcionando. (#1630, #3090, #3414)
  • Las preguntas de Claude Code MCP y los mensajes de aprobación de Bash ahora permanecen bloqueados mientras se espera una respuesta, incluidos diferentes diseños de opciones y posiciones del cursor. (#3283, #3383, #2650, #3615, gracias @caner-akca)
  • Los ganchos de Claude Code ahora ignoran los eventos compatibles con Claude del Cursor, lo que impide que las sesiones del Cursor se guarden como sesiones de Claude. (#2832)
  • Codex ya no aparece bloqueado porque la salida anterior cita un mensaje de confirmación y su cuadro de diálogo de actualización de inicio ahora informa correctamente que está bloqueado. Las sesiones reanudadas explícitamente se guardan antes del primer mensaje, por lo que sobreviven al reinicio del servidor. (#3301, #3632, #3517)
  • GitHub Copilot CLI ahora permanece funcionando mientras espera a los agentes en segundo plano. (#3291, #3403, gracias @LaneBirmingham)
  • Oh My Pi ahora continúa funcionando durante las continuaciones ya programadas en lugar de informar brevemente como inactivo y finalizar agent wait antes de tiempo. (#2851, #3122, gracias @caner-akca y @taoeffect)
  • El permiso de agente secundario de OpenCode y las preguntas ya no dejan el panel principal bloqueado después de que continúa el trabajo. (#3669, gracias @markjaquith)
  • Las lecturas del directorio de trabajo en primer plano ahora siguen al líder del grupo de procesos en primer plano en lugar de a un descendiente, manteniendo los nuevos paneles en el directorio deseado. (#3270, #3386, gracias @caner-akca)
  • Los archivos de referencia de Git de gran tamaño o ilegibles ya no causan lecturas de estado repetidas y pesadas ni hacen que los espacios de trabajo utilicen datos de referencia obsoletos. (#3343, #3373, gracias @caner-akca)
  • Los comandos de estado de la barra de pestañas ya no muestran fragmentos de escape ANSI perdidos y las respuestas de la paleta del host se aplican juntas para evitar actualizaciones redundantes. (#3001, #3580)
  • Los paneles de complementos de Unix ahora mantienen PWD alineado con su directorio de trabajo solicitado a menos que se anule explícitamente. Los paneles de complementos de Windows ahora resuelven los comandos relativos desde la raíz del complemento y manejan las rutas de inicio correctamente. (#2984, #3024)
  • Los controladores de enlaces de complementos ahora reciben OSC 8 file:// clicks coincidentes; Los enlaces de archivos no coincidentes aún no inician el abridor de URL del sistema. (#2941)
  • Los paneles de Windows ahora conservan el texto desplazado fuera de EE. UU., las teclas físicas modificadas, Ctrl+/ y la composición de teclas muertas en las aplicaciones de teclado Kitty. (#3045, #2954, #3546, #3503)
  • Las sesiones de Windows OpenSSH ahora reciben la entrada del mouse de manera confiable sin perder informes ni fragmentos de escape que se filtren en los paneles. Los pegados multilínea remotos y solo LF conservan sus nuevas líneas y su orden. (#2810, #3459, #3209, #3172)
  • Los paneles de Windows ahora mantienen detectados los inicios del cursor y del Pi incluido, y las correcciones del agente de PowerShell aceptan argumentos nativos. Codex ya no hereda la identidad de Windows Terminal que provocaba un repintado excesivo y saltos de desplazamiento durante la reanudación. (#3032, #3205, #3455, #3127, gracias @Pimpmuckl)
  • Los ganchos antigravedad ahora se ejecutan correctamente en Windows y la configuración de integración de Devin utiliza el directorio de configuración de Windows correcto. (#3348, #2724)
  • Las instalaciones de Windows ya no necesitan un tiempo de ejecución de Visual C++ instalado por separado. Las rutas del instalador siguen siendo detectables en las sesiones OpenSSH y los valores del entorno heredado con formato incorrecto se rechazan de forma segura. (#3089, #3611, #3430)
  • Los usuarios de Windows cuya seguridad de punto final bloquea la instalación de PowerShell sin archivos pueden usar un arranque local install.cmd con descargas verificadas por suma de comprobación. (#2751)
  • Las sesiones remotas de WSL ahora pueden pegar imágenes desde el tablero cli de Windows. (#3376)
  • Las instalaciones de Nix ahora obtienen cajas a través de la CDN estática, evitando errores de descarga desde el punto final anterior. (#3505)
  • El instalador de Unix ahora explica que Android/Termux no es compatible en lugar de instalar un binario de Linux que no puede ejecutarse allí. (#3571)

Eliminado

  • Se eliminó el modo --no-session de proceso único. Todos los inicios de la interfaz de usuario del terminal ahora se conectan a un servidor en segundo plano; detach deja los paneles en ejecución, mientras server stop finaliza la sesión.

herdr v0.9.0

Added

  • Manage Local and saved SSH machines from one Herdr window, with a combined agent list, machine-scoped navigation, notifications, and automatic reconnects. Add and manage connections with herdr machine; a disconnected machine does not interrupt the others. (#3670)
  • Multiple clients can now view different workspaces and tabs independently. Different tabs fit their viewing clients; when clients share a tab, the last one to interact with it controls its size. (#3526)
  • Added Muse agent detection for idle, working, approval, and question states. (#2489, thanks @ohk)
  • Sidebar text and metadata tokens can now change color, boldness, and dimming based on their values, using ordered text or numeric rules. (#3693)
  • Custom themes can now define separate light and dark color overrides when automatic theme switching is enabled. (#2324, thanks @aneym)
  • ui.pane_borders = "always" can now frame a single pane when outer borders are enabled. "auto" keeps split-only borders, "off" hides them, and existing boolean values keep working. (#3234, thanks @rsmdt)

Changed

  • Client updates can now leave compatible servers and their running agents untouched. Missing server features disable only the affected action instead of preventing connection. Servers older than endpoint generation 1 need a one-time upgrade. Replacing a remote server asks before stopping its pane processes, with No as the default answer; experimental handoff remains opt-in. (#3509)
  • The terminal UI now runs in each client, reducing redraw work in busy multi-client sessions and keeping themes, menus, copy mode, and other presentation settings local to the viewing machine. (#3487)
  • Idle terminal scrollback now uses less memory without reducing retained history or changing reads and resizing. (#3556)
  • Pane images and the graphics API are now enabled by default in compatible terminals. Set terminal.kitty_graphics = false to disable them; the old experimental.kitty_graphics setting remains accepted.
  • Closing a primary workspace with open worktree workspaces now requires explicit group intent: workspace close --group or workspace.close with close_group: true. Otherwise the whole group stays open. (#2874)
  • New lifecycle event subscriptions now start with live events rather than replaying retained history. API clients should subscribe before taking their initial snapshot to avoid missing changes. (#1270)

Fixed

  • Mouse selections now stay visible and copyable while terminal output continues, including with automatic copying disabled. Ctrl+C and Cmd+C copy a selection even before a delayed mouse release, and a failed copy no longer interrupts the agent. Selection highlights also remain visible when host colors are unavailable. (#3100, #2708, #3684, thanks @moret and @Pimpmuckl)
  • Wayland clipboard copies no longer freeze Herdr while wl-copy serves the selection. (#3014)
  • Live handoff now preserves mouse forwarding for running pane applications. (#3000, thanks @xkrogen)
  • Interrupted pane exits during host shutdown no longer replace the saved session with an empty session or a new default workspace. (#3415)
  • SSH clients whose terminal disappears now detach instead of resizing running panes to a fallback size and triggering expensive history reflow. (#3519)
  • Focusing a workspace now scrolls the sidebar to keep it visible. (#3554)
  • Removing a background worktree workspace no longer changes focus to its parent. Windows worktrees can also be removed while their agent panes are running, without a replacement shell locking the checkout again. (#3098, #3532)
  • Worktree commands can now trust a verified repository for one request with --trust-repository, including accessible Windows repositories owned by another SID, without changing global Git configuration. (#3044)
  • Oversized Kitty images no longer prevent smaller images from appearing, and image replacements no longer redraw or disappear one row at a time. Direct graphics stay bound to the client that owns them. (#3033, #3166, #3549, thanks @kataokatsuki)
  • Pixel mouse coordinates remain correct when pane applications reassert SGR mouse reporting. (#3295)
  • Prefix bindings such as prefix+| now recognize characters produced by macOS Option and custom keyboard layouts, while exact chords keep priority. Arrow navigation also works when terminals such as Alacritty attach text to special-key reports. (#3079, #3328, thanks @vlcinsky)
  • Direct terminal attaches now honor ui.mouse_capture and preserve multiline pastes as one paste instead of submitting each line separately. (#2992, #3054)
  • agent prompt now reliably sends the prompt and Enter before reporting successful submission. With --wait, prompts sent to a non-working agent require observed working or blocked activity, so unrelated state changes cannot complete the wait. Pending submissions fail cleanly if the terminal exits. (#3506, #3685)
  • Long Codex prompts on Windows now wait long enough for the text to arrive before submitting Enter. Expired queued submissions are rejected before typing starts. (#3187)
  • Recent pane reads now include output that has not yet scrolled off the viewport, instead of returning empty text. (#3444)
  • pane report-agent and pane report-agent-session now accept options before the pane ID and --option=value arguments. (#2926)
  • herdr agent explain --file now reports unreadable files as structured JSON rather than raw Rust errors. (#3022)
  • Running named servers now pick up detection manifests downloaded by another server without needing a restart. (#2711)
  • Agents that set their terminal title or progress once at startup no longer lose that detection signal when first recognized. (#3326, thanks @aneym)
  • Claude Code now recognizes visible turn and background-agent activity when terminal titles are unavailable, and remains working while background MCP tasks continue. An idle prompt with only a background shell running no longer stays working. (#1630, #3090, #3414)
  • Claude Code MCP questions and Bash approval prompts now stay blocked while waiting for an answer, including different option layouts and cursor positions. (#3283, #3383, #2650, #3615, thanks @caner-akca)
  • Claude Code hooks now ignore Cursor's Claude-compatible events, preventing Cursor sessions from being saved as Claude sessions. (#2832)
  • Codex no longer appears blocked because earlier output quotes a confirmation prompt, and its startup update dialog now correctly reports blocked. Explicitly resumed sessions are saved before the first prompt, so they survive a server restart. (#3301, #3632, #3517)
  • GitHub Copilot CLI now stays working while it waits for background agents. (#3291, #3403, thanks @LaneBirmingham)
  • Oh My Pi now stays working through already-scheduled continuations instead of briefly reporting idle and ending agent wait early. (#2851, #3122, thanks @caner-akca and @taoeffect)
  • OpenCode child-agent permission and question prompts no longer leave the parent pane stuck as blocked after work continues. (#3669, thanks @markjaquith)
  • Foreground working-directory reads now follow the foreground process-group leader rather than a descendant, keeping new panes in the intended directory. (#3270, #3386, thanks @caner-akca)
  • Oversized or unreadable Git ref files no longer cause repeated heavy status reads or make workspaces use stale ref data. (#3343, #3373, thanks @caner-akca)
  • Tab bar status commands no longer display stray ANSI escape fragments, and host palette replies are applied together to avoid redundant updates. (#3001, #3580)
  • Unix plugin panes now keep PWD aligned with their requested working directory unless explicitly overridden. Windows plugin panes now resolve relative commands from the plugin root and handle launch paths correctly. (#2984, #3024)
  • Plugin link handlers now receive matching OSC 8 file:// clicks; unmatched file links still do not launch the system URL opener. (#2941)
  • Windows panes now preserve non-US shifted text, physical modified keys, Ctrl+/, and dead-key composition in Kitty keyboard applications. (#3045, #2954, #3546, #3503)
  • Windows OpenSSH sessions now receive mouse input reliably without dropped reports or escape fragments leaking into panes. Remote and LF-only multiline pastes retain their newlines and order. (#2810, #3459, #3209, #3172)
  • Windows panes now keep Cursor and bundled Pi launches detected, and PowerShell agent shims accept native arguments. Codex no longer inherits Windows Terminal identity that caused excessive repainting and scroll jumps during resume. (#3032, #3205, #3455, #3127, thanks @Pimpmuckl)
  • Antigravity hooks now run correctly on Windows, and Devin integration setup uses the correct Windows config directory. (#3348, #2724)
  • Windows installations no longer need a separately installed Visual C++ runtime. Installer paths remain discoverable in OpenSSH sessions, and malformed inherited environment values are rejected safely. (#3089, #3611, #3430)
  • Windows users whose endpoint security blocks fileless PowerShell installation can use a local install.cmd bootstrap with checksum-verified downloads. (#2751)
  • WSL remote sessions can now paste images from the Windows clipboard. (#3376)
  • Nix installations now fetch crates through the static CDN, avoiding download failures from the previous endpoint. (#3505)
  • The Unix installer now explains that Android/Termux is unsupported instead of installing a Linux binary that cannot run there. (#3571)

Removed

  • Removed the single-process --no-session mode. All terminal UI launches now attach to a background server; detach leaves panes running, while server stop ends the session.
