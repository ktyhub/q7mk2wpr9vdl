Nuevos modelos

Mistral Grande 4 (Le Chonk)

<img width="1329" height="780" alt="image" src="https://github.com/user-attachments/assets/1cff9ca7-19e3-4622-8db6-fb1cfa842579" />

Mistral Large 4 es el modelo más grande y capaz de Mistral hasta la fecha: un modelo de mezcla de expertos multimodal nativo de 1 billón de parámetros con 49 mil millones de parámetros activos por token (52 mil millones incluyendo incrustaciones y capas de salida), entrenado desde cero en 3.800 GPU NVIDIA Grace Blackwell en los propios centros de datos de Mistral en Europa.

Mistral Large 4 unifica el seguimiento de instrucciones, el razonamiento, la codificación y los flujos de trabajo agentes en un único conjunto de pesos. Si bien es un modelo generalista, muestra un desempeño especialmente bueno en cargas de trabajo como ciberseguridad, finanzas y derecho, y supera los modelos de frontera cerrada en términos visuales. Habla con fluidez nativa más de 160 idiomas, incluidos todos los idiomas oficiales de la Unión Europea.

Características clave

Mistral Large 4 incluye las siguientes opciones arquitectónicas:

  • ~1T en total / ~52B parámetros activos: combinación granular de expertos con 128 expertos enrutados (4 activos por token) y 1 experto compartido.
  • Longitud de contexto de 1 millón, para cargas de trabajo de contexto largo.
  • Entrada multimodal: acepta entrada de texto e imagen, con salida de texto. Codificador de visión estilo Pixtral entrenado para manejar tamaños de imagen y relaciones de aspecto variables.
  • Funcionalidades de instrucción y razonamiento con llamadas a funciones, esfuerzo de razonamiento configurable por solicitud.

Mistral Large 4 ofrece las siguientes capacidades:

  • Modo de razonamiento: tres esfuerzos de razonamiento: low, medium, high (predeterminado), para que el mismo modelo pueda responder una respuesta rápida de chat o trabajar en una ejecución agente compleja.
  • Visión: analiza imágenes, gráficos, dibujos técnicos y documentos, con una base visual de última generación entre pesos abiertos.
  • Multilingüe: habla con fluidez nativa más de 160 idiomas, incluidos todos los idiomas oficiales de la Unión Europea.
  • Mensaje del sistema: fuerte adherencia y soporte para los avisos del sistema.
  • Agentic: llamada a funciones nativas, salida JSON y aplicación estricta del esquema JSON.
  • Ciberseguridad: lo último en modelos abiertos para trabajos de seguridad, rechazando solicitudes maliciosas.
  • Ventana de contexto grande: admite una ventana de contexto de 1M.

El modelo se lanza bajo la Licencia de peso abierto del ecosistema Mistral: una versión modificada de la licencia MIT, para uso comercial y no comercial; operar un negocio de modelo como servicio requiere una licencia comercial separada con Mistral.

Configuración recomendada

  • Esfuerzo de razonamiento:
    • 'low' / 'medium' / 'high': el valor predeterminado es 'high'.
    • Utilice reasoning_effort="high" para indicaciones complejas y uso agente, 'low' para respuestas rápidas al chat y 'medium' para el uso diario.
  • Muestreo: para todos los esfuerzos de razonamiento, recomendamos los siguientes parámetros de muestreo:
    • temperature=1.0
    • top_p=0.95
  • Mensaje del sistema: defina un entorno claro y un caso de uso, incluida orientación sobre cómo aprovechar eficazmente las herramientas en sistemas agentes.
  • Herramientas: mantener bien definido el conjunto de herramientas y limitar su número al mínimo requerido para el caso de uso.
  • Contexto: el punto de control admite una ventana de contexto de 1M.

Cambios importantes

  • 🚨 Separe la lógica EP en su propio archivo (#49679) por @3outeille

Cuantización

Los modelos cuantificados del FP8 ahora se pueden utilizar para el entrenamiento de adaptadores (como LoRA con PEFT). Se agregaron pases hacia atrás a los densos y agrupados matmuls FP8, y is_trainable ahora es True. Hacia atrás también descuantifica a los expertos en fragmentos y omite la autogradación en la inferencia, lo que reduce la memoria máxima en la capa MoE hacia atrás de aproximadamente 28.9 GiB a 2.8 GiB en 8k tokens. transformers v5.22.0

New Models

Mistral Large 4 (Le Chonk)

<img width="1329" height="780" alt="image" src="https://github.com/user-attachments/assets/1cff9ca7-19e3-4622-8db6-fb1cfa842579" />

Mistral Large 4 is Mistral's largest and most capable model to date: a 1 trillion-parameter natively multimodal Mixture-of-Experts model with 49 billion active parameters per token (52 billion including embeddings and output layers), trained from scratch on 3,800 NVIDIA Grace Blackwell GPUs in Mistral's own datacenters in Europe.

Mistral Large 4 unifies instruction following, reasoning, coding, and agentic workflows in a single set of weights. While a generalist model, it shows especially good performance on workloads such as cybersecurity, finance, and law, and it surpasses frontier closed models on visual grounding. It is natively fluent in 160+ languages, including every official language of the European Union.

Key Features

Mistral Large 4 includes the following architectural choices:

  • ~1T total / ~52B active parameters: granular Mixture-of-Experts with 128 routed experts (4 active per token) and 1 shared expert.
  • 1M context length, for long-context workloads.
  • Multimodal input: accepts text and image input, with text output. Pixtral-style vision encoder trained to handle variable image sizes and aspect ratios.
  • Instruct and Reasoning functionalities with function calls, reasoning effort configurable per request.

Mistral Large 4 offers the following capabilities:

  • Reasoning Mode: three reasoning efforts — low, medium, high (default) — so the same model can answer a quick chat reply or work through a complex agentic run.
  • Vision: analyzes images, charts, technical drawings, and documents, with state-of-the-art visual grounding among open weights.
  • Multilingual: natively fluent in 160+ languages, including all official languages of the European Union.
  • System Prompt: strong adherence and support for system prompts.
  • Agentic: native function calling, JSON output, and strict JSON schema enforcement.
  • Cybersecurity: state of the art among open-weight models for security work, while refusing malicious requests.
  • Large Context Window: supports a 1M context window.

The model is released under the Mistral Ecosystem Open-Weight License: a modified version of the MIT license, for both commercial and non-commercial use — operating a Model-as-a-Service business requires a separate commercial license with Mistral.

Recommended Settings

  • Reasoning Effort:
    • 'low' / 'medium' / 'high' — default is 'high'.
    • Use reasoning_effort="high" for complex prompts and agentic usage, 'low' for fast chat replies and 'medium' for day to day usage.
  • Sampling: for all reasoning efforts, we recommend the following sampling parameters:
    • temperature=1.0
    • top_p=0.95
  • System Prompt: define a clear environment and use case, including guidance on how to effectively leverage tools in agentic systems.
  • Tools: keep the set of tools well-defined and limit their number to the minimum required for the use case.
  • Context: the checkpoint supports a 1M context window.

Breaking changes

  • 🚨 Separate EP logic into its own file (#49679) by @3outeille

Quantization

FP8 quantized models can now be used for adapter training (such as LoRA with PEFT). Backward passes were added to the dense and grouped FP8 matmuls, and is_trainable is now True. Backward also dequantizes experts in chunks and skips autograd at inference, which cuts peak memory in the MoE layer backward from about 28.9 GiB to 2.8 GiB at 8k tokens.
