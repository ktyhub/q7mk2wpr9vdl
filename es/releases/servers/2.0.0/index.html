Servidores Python: cambios para clients

mcp-server-fetch, mcp-server-git y mcp-server-time no tienen CHANGELOG, así que esto es lo que cambia para un client en 2026.10.19. Ahora están construidos sobre el MCPServer de alto nivel del MCP Python SDK (#5175).

  • Herramienta desconocida: un error JSON-RPC -32602 (Unknown tool: <name>) en ambas eras del protocolo, como lo requiere la especificación. Solía ​​ser un resultado isError.
  • Errores de herramientas lee Error executing tool <name>: <message>. Los errores de validación de argumentos ahora utilizan la redacción de Pydantic. Ambos siguen siendo resultados de isError.
  • Capacidades: cada servidor ahora anuncia las capacidades prompts y resources (con listChanged: false). El mensaje fetch de fetch es la única entrada en esas listas.
  • hora: get_current_time y convert_time declaran un outputSchema y devuelven structuredContent. El contenido del texto no se modifica.
  • fetch: el description de un resultado prompts/get ahora es siempre la descripción registrada del mensaje.
  • Requiere mcp>=2.3,<3.

Python servers: changes for clients

mcp-server-fetch, mcp-server-git and mcp-server-time have no CHANGELOG, so here is what changes for a client in 2026.10.19. They are now built on the MCP Python SDK's high-level MCPServer (#5175).

  • Unknown tool: a JSON-RPC -32602 error (Unknown tool: <name>) in both protocol eras, as the spec requires. It used to be an isError result.
  • Tool errors read Error executing tool <name>: <message>. Argument-validation errors now use pydantic's wording. Both are still isError results.
  • Capabilities: each server now advertises prompts and resources capabilities (with listChanged: false). fetch's fetch prompt is the only entry in those lists.
  • time: get_current_time and convert_time declare an outputSchema and return structuredContent. The text content is unchanged.
  • fetch: a prompts/get result's description is now always the prompt's registered description.
  • Requires mcp>=2.3,<3.
