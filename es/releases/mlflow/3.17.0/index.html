mlflow v3.17.0

MLflow 3.17.0 incluye varias características y mejoras importantes.

Nuevas características importantes

  • Decisiones de Jev a través de evaluación, puerta de enlace y seguimiento: use modelos TypeSafe en evaluadores integrados y jueces personalizados con comentarios booleanos o categóricos escritos. (#26100, @B-Step62)
  • Permisos específicos para recursos compartidos: controle el acceso a los tipos de recursos contenidos, incluidas ejecuciones, seguimientos y versiones, con concesiones de comodines y DENEGAR explícito. (#26157, @rrrkharse)
  • Análisis más rápidos para conjuntos de datos de seguimiento grandes: reduzca la sobrecarga de las consultas de análisis SQL con resúmenes diarios opcionales y respaldo de consultas sin formato. (#25991, @HumairAK)
  • Resultados de evaluación más claros: asocie métricas de evaluación agregadas del modelo registrado con el conjunto de datos administrado que las produjo. (#25927, @joshuawong-db)
  • Mejoras del Asistente para servidores compartidos: mantenga las conversaciones guardadas dirigidas al usuario que inició sesión y restablezca la sesión activa cuando cambien las cuentas. (#26009, @kriscon-db)

Actualización de la base de datos: Los servidores respaldados por SQL requieren una actualización coordinada del esquema con todos los escritores detenidos y una copia de seguridad restaurable, incluso cuando los resúmenes diarios permanecen deshabilitados. Ejecute mlflow db upgrade <database-url> antes de reiniciar todas las réplicas en la nueva versión de MLflow. No se admiten actualizaciones graduales de versiones mixtas. Siga las instrucciones de actualización de la base de datos.

mlflow v3.17.0

MLflow 3.17.0 includes several major features and improvements.

Major New Features

  • Jev Decisions Across Evaluation, Gateway, and Tracing: Use TypeSafe models in built-in scorers and custom judges with typed Boolean or categorical feedback. (#26100, @B-Step62)
  • Fine-Grained Permissions for Shared Resources: Control access to contained resource types, including runs, traces, and versions, with wildcard grants and explicit DENY. (#26157, @rrrkharse)
  • Faster Analytics for Large Trace Datasets: Reduce SQL analytics query overhead with opt-in daily summaries and raw-query fallback. (#25991, @HumairAK)
  • Clearer Evaluation Results: Associate aggregate logged-model evaluation metrics with the managed dataset that produced them. (#25927, @joshuawong-db)
  • Assistant Improvements for Shared Servers: Keep saved conversations scoped to the signed-in user and reset the active session when accounts change. (#26009, @kriscon-db)

Database upgrade: SQL-backed servers require a coordinated schema upgrade with all writers stopped and a restorable backup, even when daily rollups remain disabled. Run mlflow db upgrade <database-url> before restarting all replicas on the new MLflow version. Mixed-version rolling upgrades are not supported. Follow the database upgrade instructions.
