LightRAG v1.3.4

Highlights

  • WebUI now renders Markdown and Mermaid — Mermaid rendering waits until streaming finishes (#1426, #1453), avoiding repeated parsing of incomplete output; diagrams will appear only when the response settles.
  • Retrieval tests support query-mode prefixes — Developers can exercise different retrieval strategies directly in the WebUI and compare behavior without manually rewriting requests (#1433).
  • LLM integration is more configurable and reliable — Custom tokenizer support helps align token handling with your model stack (#1396), while the system_prompt fix restores intended placeholder interpolation (#1402). Extraction and relationship-weight logic are also friendlier to low-capability models (#1423); revalidate prompts and evaluations after upgrading.
  • Concurrent ingestion and graph traversal are sturdier — Parallel document processing (#1447), the FAISS deadlock fix (#1465), custom PostgreSQL AGE BFS (#1446), and degree-prioritized NetworkX BFS (#1468) target stalls and slow graph exploration. Benchmark under your normal ingestion concurrency to confirm the gains.
  • Ingestion and status APIs are easier to automate — PGKVStorage.get_all() adds storage enumeration (#1392), aget_docs_by_ids() supports document-status checks (#1419), and ainsert_custom_chunks no longer omits a required key (#1389), reducing manual state inspection in bulk-ingestion and recovery workflows.
  • Compatibility — No breaking changes are declared; update custom chunk-context parsers that assume CSV, because the format is now JSON for better LLM compatibility (#1412).
