garra abierta v2026.10.33

Esta es una versión extended-stable solo de puerta de enlace, que es nuestro equivalente actual a LTS. Esta versión es OpenClaw de finales de octubre de 2026, además de actualizaciones de seguridad críticas, correcciones de confiabilidad y rendimiento, y características como compatibilidad con nuevos modelos. La última versión de OpenClaw en el momento de este lanzamiento es 2026.11.5 ##2026.10.33 Esta versión estable extendida trae mejoras acumulativas de Gateway y complementos principales desde 2026.9.37, además de las correcciones de mantenimiento seleccionadas en la línea base del producto aprobado 2026.11.4. La distribución cubre el paquete principal de npm, los complementos oficiales de npm y las imágenes de Gateway Docker; Las versiones de aplicaciones nativas no están incluidas.

Destacados

  • Las conversaciones largas y los grandes almacenes de sesiones utilizan un trabajo de recuperación y exportación limitado, lo que reduce los fallos por falta de memoria durante el chat, la exportación de memoria, la reparación del Doctor y el inicio de la puerta de enlace. (#194066, #196158, #195459, #196480, #176737, #181289) Escrito por @steipete. Gracias @RomneyDa, @vincentkoc, @ericcaiwx-star, @obviyus, @garrytan y @oxen-horse.
  • Las actualizaciones interrumpidas se recuperan cuando su ejecutor muere en lugar de dejar la puerta de enlace desconectada, mientras que las comprobaciones de versión sesgada protegen el estado que aún utiliza un servicio instalado. (#181695, #186971, #187819) Escrito por @steipete. Gracias @RomneyDa, @PonySlayer28, @tomdailey55, @jalehman, @fuller-stack-dev y @vincentkoc.
  • Las respuestas sobreviven a más rutas de reinicio y reconexión, conservando las indicaciones originales, recuperando las respuestas de Telegram y evitando la pérdida de respuestas de WhatsApp o mensajes de Signal omitidos. (#187157, #195400, #168778, #187667) Gracias @shakkernerd, @jason-allen-oneal, @mcaxtr, @HermanZeng y @obviyus.
  • La privacidad de las sesiones compartidas es más sólida: el chat lateral permanece privado para el espectador, las indicaciones del modelo interno no aparecen en la salida mostrada y la compactación redacta las credenciales en los resúmenes citados. (#185390, #173460, #197349) Escrito por @steipete. Gracias @Satoshi-Kusumoto, @RomneyDa, @zhangguiping-xydt, @Patrick-Erichsen y @obviyus.
  • Las automatizaciones pueden reaccionar a condiciones sondeadas y eventos MCP, ejecutar scripts repetibles y utilizar servidores MCP explícitamente permitidos. (#101195, #165399, #160996, #160995) Escrito por @steipete. Gracias @obviyus.
  • Las habilidades instaladas se pueden buscar y leer a pedido, lo que ayuda a los agentes a encontrar instrucciones relevantes sin tener que incluir todas las habilidades instaladas en el mensaje. (#158089, #158090, #158091, #160538) Escrito por @steipete. Gracias @RomneyDa y @vincentkoc.
  • Las sesiones pueden importar transcripciones existentes de Claude Code o Codex y moverse entre entornos locales y de nube, con recetas de repositorio y un progreso de inicio de nube más claro. (#161955, #171690, #170862, #170895) Escrito por @steipete. Gracias @joshavant y @RomneyDa.

openclaw v2026.10.33

This is a gateway-only extended-stable release, which is our current equivalent to LTS. This release is OpenClaw from the end of October 2026, plus critical security updates, reliability and performance fixes, and features like new model support. The latest version of OpenClaw at the time of this release is 2026.11.5

2026.10.33

This extended-stable release brings cumulative Gateway and core-plugin improvements since 2026.9.37, plus the selected maintenance fixes on the approved 2026.11.4 product baseline. Distribution covers the core npm package, matching official npm plugins, and Gateway Docker images; native-app releases are not included.

Highlights

  • Long conversations and large session stores use bounded export and recovery work, reducing out-of-memory failures during chat, memory export, Doctor repair, and Gateway startup. (#194066, #196158, #195459, #196480, #176737, #181289) Authored by @steipete. Thanks @RomneyDa, @vincentkoc, @ericcaiwx-star, @obviyus, @garrytan, and @oxen-horse.
  • Interrupted updates recover when their executor dies instead of leaving the Gateway stuck offline, while version-skew checks protect state still used by an installed service. (#181695, #186971, #187819) Authored by @steipete. Thanks @RomneyDa, @PonySlayer28, @tomdailey55, @jalehman, @fuller-stack-dev, and @vincentkoc.
  • Replies survive more restart and reconnect paths, preserving original prompts, recovering Telegram responses, and avoiding lost WhatsApp replies or skipped Signal messages. (#187157, #195400, #168778, #187667) Thanks @shakkernerd, @jason-allen-oneal, @mcaxtr, @HermanZeng, and @obviyus.
  • Shared-session privacy is stronger: Side chat stays private to its viewer, internal model prompts stay out of displayed output, and compaction redacts credentials in quoted summaries. (#185390, #173460, #197349) Authored by @steipete. Thanks @Satoshi-Kusumoto, @RomneyDa, @zhangguiping-xydt, @Patrick-Erichsen, and @obviyus.
  • Automations can react to polled conditions and MCP events, run repeatable scripts, and use explicitly allowed MCP servers. (#101195, #165399, #160996, #160995) Authored by @steipete. Thanks @obviyus.
  • Installed skills can be searched and read on demand, helping agents find relevant instructions without putting every installed skill into the prompt. (#158089, #158090, #158091, #160538) Authored by @steipete. Thanks @RomneyDa and @vincentkoc.
  • Sessions can import existing Claude Code or Codex transcripts and move between local and cloud environments, with repository recipes and clearer cloud-startup progress. (#161955, #171690, #170862, #170895) Authored by @steipete. Thanks @joshavant and @RomneyDa.

Additional maintenance fixes

  • Provider continuity: preserve server compaction checkpoints across credential or model changes on the same provider API and endpoint, avoiding unnecessary history replay. (#200063, #200208) Thanks @obviyus.
  • macOS installation: preserve the controlling terminal during shell installation so onboarding can install plugins without detached Node subprocesses aborting. (#200247) Thanks @miguelbranco80.
  • Update recovery: record successful Gateway startup writes for the next Doctor run without accepting changes that predate startup. (#200260) Thanks @RomneyDa.
  • Existing device folders: recognize models using the implicit OpenClaw runtime without turning that default into an explicit session override. (#190065) Thanks @obviyus.
