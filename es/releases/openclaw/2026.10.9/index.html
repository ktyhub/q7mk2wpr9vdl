##2026.10.9

Destacados

  • Parche de dependencias de tiempo de ejecución vulnerables: fast-uri 4.2.3 rechaza esquemas de URI y hosts con formato incorrecto en la validación del esquema MCP, las colecciones de Zod de gran tamaño se rechazan temprano en A2UI y la aplicación integrada de Discord SDK, el análisis del remitente IMAP usa el nodemailer 10.1.4 para que los remitentes falsificados no puedan pasar la puerta del token del remitente, y Microsoft Teams usa el nodo MSAL parcheado 7.1.1. (#187294) Gracias @RomneyDa.
  • Aplique tools.fs.workspaceOnly a las herramientas creadas por Gateway, de modo que los cambios delegados aún requieran aprobación y las herramientas multimedia permanezcan dentro del espacio de trabajo. (#185094) Gracias @eleqtrizit, @RomneyDa y @shakkernerd.
  • Mantenga las credenciales activas fuera de la inspección de MCP CLI y enmascare los secretos de Google OAuth client en los registros. (#180321, #180308, #183193) Gracias @brandon-julio-t, @wr-web, @LeizhenZhang y @RomneyDa.
  • Haga que las reversiones de actualizaciones fallidas sean seguras: las reversiones de Git-source conservan las ediciones del operador en lugar de restablecer el pago, y las reversiones de npm reintentan denegaciones transitorias de Windows e informan el movimiento exacto que restaura una instalación de arranque en lugar de bloquear la raíz del paquete. (#185201, #184887, #185160, #184889) Gracias @wr-web, @syxscott, @LiuwqGit, @shakkernerd y @RomneyDa.
  • Recupere bases de datos de agentes intactas e índices de texto completo obsoletos después de cambios en el tokenizador SQLite, incluidas instantáneas de actualización. (#176234, #176220, #176833, #181206) Gracias @ndakota79 y @RomneyDa.
  • Repare las actualizaciones completas de la publicación después de volver a montarlas, conservando al mismo tiempo el iniciador original y el asistente de recuperación sellado. (#186557, #186527) Gracias @ericcaiwx-star, @sennyhoney y @RomneyDa.
  • Migre archivos de transcripciones de gran tamaño sin exceder los límites de cadena Node.js. (#170853, #170847) Gracias @iamonlv426 y @RomneyDa.
  • Permitir que los agentes se recuperen después de un disco lleno una vez que haya espacio disponible, sin necesidad de reiniciar. (#176902) Gracias @RomneyDa.

Cambios

Esta versión de mantenimiento se centra en parches de dependencia de seguridad, recuperación, preservación de datos y correcciones de confiabilidad.

Correcciones

  • Resolver los medios locales en los mensajes de dirección del Codex desde el propio espacio de trabajo de la sesión en lugar del espacio de trabajo predeterminado del agente. (#181528) Gracias @RomneyDa.
  • Informar de una limpieza de procesos incierta a partir de comandos almacenados en el búfer, como los proveedores de voz locales CLI, en lugar de presentarlo como una falla de comando normal. (#184270, #184237) Gracias @shakkernerd y @RomneyDa.
  • Mantenga vivas las conexiones de nodos reaprobadas publicando la aprobación con sus datos de emparejamiento confirmados antes de que se reanude la solicitud. Gracias @RomneyDa.
  • Recuperar puertas de enlace detenidas cuando no se puede verificar la activación del servicio; conservar el comportamiento de recuperación intacto en la clasificación de Windows. (#172784, #181577, #181698) Gracias @SMF12138 y @RomneyDa.
  • Evite desinstalar un servicio de Gateway durante una parada pasiva de macOS cuando no hay ningún servicio instalado. (#181257) Gracias @shakkernerd, @LiuwqGit, @eleqtrizit, @syxscott y @RomneyDa.
  • Recuperar los tiempos de ejecución del nodo CLI cuando se inicia desde la raíz del sistema de archivos, incluidos los trabajos de lanzamiento. (#178112, #177739) Gracias @downingkeys y @RomneyDa.
  • Inicie nuevas sesiones de ACP en el directorio de trabajo solicitado en lugar del espacio de trabajo predeterminado. (#176852, #123557) Gracias @yinx65588-boop, @crappier y @RomneyDa.
  • Evite la superposición de actualizaciones de modelos debido a solicitudes fallidas. (#179144) Gracias @RomneyDa.
  • Respete un puerto SSH 22 explícito en openclaw gateway probe --ssh en lugar del puerto configurado del alias. (#171092) Gracias @zhangguiping-xydt, @obviyus y @RomneyDa.
  • Mantenga los metadatos de habilidades, como íconos y páginas de inicio, cuando un valor de metadatos YAML en línea tenga un comentario final. (#171224) Gracias @zhangguiping-xydt, @Takhoffman y @RomneyDa.
  • Mostrar opciones ignoradas por el proveedor en el texto openclaw infer video generate y la salida JSON. (#171172) Gracias @ly85206559, @obviyus y @RomneyDa.

openclaw v2026.10.9

2026.10.9

Highlights

  • Patch vulnerable runtime dependencies: fast-uri 4.2.3 rejects malformed URI schemes and hosts in MCP schema validation, oversized Zod collections are rejected early in A2UI and the Discord embedded app SDK, IMAP sender parsing uses nodemailer 10.1.4 so spoofed senders cannot pass the sender token gate, and Microsoft Teams uses patched MSAL Node 7.1.1. (#187294) Thanks @RomneyDa.
  • Apply tools.fs.workspaceOnly to Gateway-built tools, so delegate changes still require approval and media tools stay inside the workspace. (#185094) Thanks @eleqtrizit, @RomneyDa, and @shakkernerd.
  • Keep live credentials out of MCP CLI inspection and mask Google OAuth client secrets in logs. (#180321, #180308, #183193) Thanks @brandon-julio-t, @wr-web, @LeizhenZhang, and @RomneyDa.
  • Make failed update rollbacks safe: Git-source rollbacks preserve operator edits instead of resetting the checkout, and npm rollbacks retry transient Windows denials and report the exact move that restores a bootable install instead of stranding the package root. (#185201, #184887, #185160, #184889) Thanks @wr-web, @syxscott, @LiuwqGit, @shakkernerd, and @RomneyDa.
  • Recover intact agent databases and stale full-text indexes after SQLite tokenizer changes, including update snapshots. (#176234, #176220, #176833, #181206) Thanks @ndakota79 and @RomneyDa.
  • Repair publication-complete updates after a remount while retaining the original launcher and sealed recovery helper. (#186557, #186527) Thanks @ericcaiwx-star, @sennyhoney, and @RomneyDa.
  • Migrate large transcript archives without exceeding Node.js string limits. (#170853, #170847) Thanks @iamonlv426 and @RomneyDa.
  • Allow agents to recover after a full disk once space becomes available, without requiring a restart. (#176902) Thanks @RomneyDa.

Changes

This maintenance release focuses on security dependency patches, recovery, data preservation, and reliability fixes.

Fixes

  • Resolve local media in Codex steering messages from the session's own workspace instead of the agent's default workspace. (#181528) Thanks @RomneyDa.
  • Report uncertain process cleanup from buffered commands, such as local CLI speech providers, instead of presenting it as an ordinary command failure. (#184270, #184237) Thanks @shakkernerd and @RomneyDa.
  • Keep reapproved node connections alive by publishing the approval with its committed pairing facts before the request resumes. Thanks @RomneyDa.
  • Recover stopped Gateways when service activation cannot be verified; retain untouched-recovery behavior in Windows triage. (#172784, #181577, #181698) Thanks @SMF12138 and @RomneyDa.
  • Avoid uninstalling a Gateway service during a passive macOS stop when no service is installed. (#181257) Thanks @shakkernerd, @LiuwqGit, @eleqtrizit, @syxscott, and @RomneyDa.
  • Recover CLI Node runtimes when launched from the filesystem root, including launchd jobs. (#178112, #177739) Thanks @downingkeys and @RomneyDa.
  • Start new ACP sessions in the requested working directory instead of the default workspace. (#176852, #123557) Thanks @yinx65588-boop, @crappier, and @RomneyDa.
  • Prevent overlapping model refreshes from failing requests. (#179144) Thanks @RomneyDa.
  • Honor an explicit SSH port 22 in openclaw gateway probe --ssh instead of the alias's configured port. (#171092) Thanks @zhangguiping-xydt, @obviyus, and @RomneyDa.
  • Keep skill metadata such as icons and homepages when an inline YAML metadata value has a trailing comment. (#171224) Thanks @zhangguiping-xydt, @Takhoffman, and @RomneyDa.
  • Show provider-ignored options in openclaw infer video generate text and JSON output. (#171172) Thanks @ly85206559, @obviyus, and @RomneyDa.
