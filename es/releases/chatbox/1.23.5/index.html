chatbox v1.23.5

Highlights

  • MCP one-click setup from a cold start — External "add MCP server" links now open the prefilled configuration dialog even when the app was not already running. The old failure was effectively a startup-ordering bug: the deep-link payload arrived before there was a window to host the dialog, so the link was dropped. If you distribute MCP server configs via web links, this is the fix that makes that onboarding path reliable without instructing users to launch the app first.
  • Editable Work Mode output — You can now edit the final output segment of an assistant reply in Work Mode. This is the only net-new capability in an otherwise all-fix patch and matters if you treat agent/workflow replies as artifacts you refine in place: correcting the last chunk avoids regenerating the whole run and preserves the preceding steps.
  • No more silent chat loss on undo — Undoing a newly created topic could delete the previous conversation instead of just the new topic. That is a data-loss-class bug in the undo/reset state logic, where rollback restored the wrong conversation snapshot. If you experiment with new topics and rely on undo, prioritize this upgrade; it protects prior history, though backing up before bulk edits remains prudent.
  • Image Creator history no longer white-screens — Incomplete or partially written image records previously left the history view blank or stuck loading. The fix makes the loader tolerate malformed/partial entries rather than failing the entire list render — a robustness win for anyone with older or interrupted generations in their local store, and a sign the history now degrades gracefully on a single bad row instead of hard-failing.
  • Cleaner input on nine-key keyboards — Pasting into the composer while using a T9/nine-key IME could leave a string of stray digits in the input field. The fix clears stale composing state after paste; this mainly affects mobile or virtual-keyboard users typing Chinese on a numeric keypad, while desktop QWERTY users are unaffected.
  • Breaking changes — None; v1.23.5 is a backwards-compatible patch with no migration steps.

What’s Changed

  3. 修复图片创作历史记录不完整时页面白屏或无法继续加载的问题
  4. 修复新建话题后撤销会误删原来聊天记录的问题
  5. 修复九键输入过程中粘贴后输入框出现一串数字的问题
