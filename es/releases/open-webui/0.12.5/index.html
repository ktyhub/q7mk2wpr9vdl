open-webui v0.12.5

Added

  • 🧭 Analytics session explorer. Administrators can now open a Sessions tab in Admin Analytics that lists each chat with its tokens, responses, errors and time span, filters them by search, model, token range or sub-agents, and shows a chat's saved replies and tool calls with their timing and outcome, as long as "ENABLE_ADMIN_CHAT_ACCESS" is on. Commit
  • 📑 Pages in notes. Notes can now hold several pages and subpages, which you can add, rename, reorder, move under another page, download, link to and delete from the page tabs, and search results and the model now work with notes page by page. Commit
  • 👀 Live presence in notes. A note now shows who else has it open, and clicking a person jumps to the page and spot they are working on. Commit
  • ✏️ Rename from chat menu. The menu next to an open chat's title now has Rename, which turns the title at the top of the page into a text box, so a chat can be renamed without finding it in the sidebar first. #33177, #33176, #33246, #33339, #33338, Commit, Commit
  • 🖼️ Generated images in terminals. When a terminal is selected in a chat, generated and edited images are now also saved to its working folder, so the model can keep working on them with the terminal's tools. Commit
  • 🗃️ Models show chat files. Models can now show a file attached in the chat or stored in an attached knowledge base right in the reply with the built-in display_file tool, which until now only worked for terminal files. #32471, Commit, Commit
  • 💾 Chat model choice saved. Changing the model in a chat is now saved with the chat right away, so the chat reopens with that model even when no message was sent after the change. Commit
  • ⌨️ Unassign single shortcuts. Settings > Keyboard now shows a small x beside every assigned shortcut that unassigns only that one, so a shortcut such as Regenerate Response on Ctrl+R or Cmd+R can be switched off while all others keep working. #33185, #31463, Commit
  • 🎚️ Slider for number Valves. Plugin authors can now show a number Valve or UserValve as a slider with a number box beside it, whose ends come from the field's minimum and maximum, so users see the allowed range while picking a value. #33179, #32045, Commit
  • 📇 Provider details for models. Administrators editing a model now see a Provider details section with the input and output types, context window, maximum output and supported parameters that the provider reports for it. Commit
  • 🧲 Embedding prefixes in settings. Administrators can now set the query and content prefixes that some embedding models need under Admin Settings > Documents, where they could only be set with the "RAG_EMBEDDING_QUERY_PREFIX" and "RAG_EMBEDDING_CONTENT_PREFIX" environment variables. Commit
  • ⏱️ Terminal start timeout. Open WebUI now waits up to 60 seconds by default when it asks a terminal for its skills, AGENTS.md file or uploads, so a terminal that is still starting can answer, with "AIOHTTP_CLIENT_TIMEOUT_TERMINAL" to change the limit and a message naming the terminal when it still times out. Commit
  • 🚨 Automation failure notifications. Automation run failed is now an event users can pick for their notification targets under Settings > Notifications, so the owner hears about every failed run with the automation's name and error. #33331, #33228, Commit
