argo-rollouts v1.9.0

Highlights

  • BlueGreen analysis gating — PR #4604 fixes analysis prematurely succeeding when the new ReplicaSet becomes unsaturated (e.g., pods evicted or scaled down mid-run). If you gate promotions on AnalysisTemplates, this closes a false-positive that could promote a bad revision: analyses will now wait for the RS to re-saturate instead of passing early.
  • Traffic-routing ordering and weights — Several routing fixes change when traffic moves: #4639 pushes the early SetWeight to run only after checkReplicasAvailable, #4564 sets weight before the hash for a new canary, and #4612 ensures the Istio DestinationRule is updated before SetWeight on rollback. Together they stop traffic shifting to subsets/replicas that aren't ready. Watch rollback behavior and any custom maxTrafficWeight configs, since #4646 now honors that value instead of a hardcoded 100 in checkReplicasAvailable (matters if you cap traffic below 100).
  • DestinationRule tracking and RPC stability — #4560 makes ReplicaSetReferenced actually check Istio DestinationRules; previously stale references could go unnoticed and risk premature cleanup during scale-down. #4613 caches the RPC client to eliminate the recurring "Stdout already set" error (#3918) on repeated plugin/traffic-router calls — relevant if you run the router as an external plugin.
  • Controller progress and analysis-run behavior — #4619 unblocks rollouts where the canary count exceeds desired (common with HPAs or scale-ups), preventing a stalled rollout. #4544 makes the controller skip AnalysisRuns when no templates are specified — a behavioral change: empty/placeholder analysis steps no longer create AnalysisRun objects, so any automation keyed on those objects needs adjusting.
  • Config API and a reverted change — #4551 switches clusterScope to a *bool, letting the controller distinguish "unset" from explicit false; verify any manifests or code that read/serialize this field. Also note the revert of PR #4074 in #4553 — if you relied on that behavior from earlier RCs, it is gone in the final 1.9.0.
  • Platform baseline refresh — Kubernetes libraries and Go are bumped to currently supported versions (#4497), the image base moves Debian 11 → 12 (#4652), and CVE-2023-46402 is addressed (#4083). Expect changed dependency compatibility and image-scan results; downstream custom images and go.mod consumers should re-verify builds.

No breaking changes in this release.
