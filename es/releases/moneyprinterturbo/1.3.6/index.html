<h2 id="es-v1.3.6">Aspectos destacados</h2>
  • Se agregó generación de video nativo Volcano Engine Ark Seedance para generar la fuente clips directamente a partir de segmentos de script.
  • Se agregó soporte de texto a video multimodelo de OFox, lo que permite que Seedance, Wan y otros modelos compartan una clave API.
  • Se agregó soporte de texto a video Metaso MiniMax H3 con salida 768P/2K, clips de 4 a 15 segundos y relaciones de aspecto 9:16, 16:9 y 1:1.
  • Se agregó una fuente de material de texto a imagen compatible con OpenAI para retransmisiones en la nube y puertas de enlace locales.
  • Se agregaron OpenRouter y APIMart como proveedores de LLM compatibles con OpenAI.
  • Se agregó una pestaña de configuración de publicación automática de WebUI para cargar y publicar, con una clave API más clara y una guía de configuración de cuenta.
  • Se agregó el modo de manifiesto por lotes CLI y se aplicaron configuraciones de WebUI guardadas como valores predeterminados de CLI cuando se omiten los valores de la línea de comandos.
  • Se agregaron modos de ajuste de fuente configurables clip: cover llena el marco recortando los bordes sobrantes, mientras que contain preserva la fuente completa con formato tipo formato letterbox.
  • Se agregaron traducciones completas de WebUI en francés y coreano.
  • Configuración de fuente de material reorganizada, fuentes de video agrupadas por capacidad y credenciales de proveedor de video de IA centralizadas en la configuración de WebUI.

Seguridad

  • Acceso restringido del navegador entre orígenes API a solicitudes del mismo origen de forma predeterminada. Las interfaces de navegador independientes Trust se pueden habilitar explícitamente con CORS_ALLOWED_ORIGINS.
  • Se agregaron certificaciones de procedencia y SBOM a las imágenes de contenedores publicadas.

Correcciones y mejoras

  • Duración de la narración medida a partir del archivo de audio generado en lugar de depender únicamente de las señales de los subtítulos.
  • Se ancló la línea de tiempo de los subtítulos de SiliconFlow a la duración completa del audio.
  • Se aseguró que los recursos AudioFileClip estén cerrados en las rutas de ElevenLabs, Chatterbox y Fish Audio.
  • Se evitó que la limpieza de secuencias de comandos eliminara con avidez el texto entre corchetes o paréntesis no relacionado.
  • Se eliminó una advertencia de reintento engañosa después del último intento de LLM.
  • Se corrigieron las URL de Redis cuando no se configura ninguna contraseña.
  • Registros de registro conservados cuando la raíz del proyecto y el destino del registro están en montajes diferentes.
  • Se corrigió la salida de la consola Unicode después de una generación exitosa de CLI en Windows.
  • Se agregaron nombres de archivos de descarga portátiles y seguros, incluidas citas compatibles con RFC y protección contra nombres reservados de Windows.
  • Se mejoró el comportamiento de vista previa de WebUI en servidores sin cabeza al recurrir a la reproducción y descarga del navegador.
  • Configuración de carga y publicación desacoplada de la publicación automática para que la configuración se pueda guardar sin habilitar las cargas.
  • Manejo de imágenes reforzado compatible con OpenAI: 200 respuestas con formato incorrecto ahora omiten solo la palabra clave afectada, mientras que las fallas de almacenamiento local detienen más solicitudes pagas.

Notas de actualización

  • El acceso al navegador API ahora tiene como valor predeterminado solicitudes del mismo origen. Las interfaces web independientes deben declarar sus orígenes trusted a través de CORS_ALLOWED_ORIGINS; Los clients del lado del servidor como curl, Postman y n8n no se ven afectados.
  • Los comandos CLI ahora heredan la configuración de WebUI guardada para las opciones omitidas. Los argumentos CLI explícitos y los valores del manifiesto por lotes siguen teniendo prioridad.

MoneyPrinterTurbo v1.3.6

Highlights

  • More video-generation backends — Native Volcano Engine Ark Seedance (#1276), OFox multi-model generation with one API key (#1292), and Metaso MiniMax H3 (44ce430) add direct script-to-video options; H3 supports 768P/2K, 4–15 second clips, and three aspect ratios.
  • OpenAI-compatible ecosystem — The new text-to-image source (#1291) works with cloud relays and local gateways, while OpenRouter (#1277) and APIMart expand LLM provider choices without requiring dedicated integrations.
  • Batch automation and publishing — CLI manifest mode (#1243) enables batch runs, and omitted CLI options now inherit saved WebUI settings (#1225). Explicit CLI arguments and manifest values override those defaults, so review saved settings before upgrading. Upload-Post credentials can now be stored without enabling automatic uploads (#1259).
  • More reliable timing and cost control — Narration duration now comes from the generated audio (#1263), SiliconFlow subtitles span the full audio (#1268), and TTS clips are closed reliably (#1269). Malformed image responses skip only the affected keyword, while local storage failures halt further paid requests (#1296).
  • Breaking browser API default — Cross-origin browser access now requires explicitly trusted origins in CORS_ALLOWED_ORIGINS; separately hosted frontends must configure this before upgrading. curl, Postman, and n8n are unaffected. Published container images also add provenance and SBOM attestations (#1140).

<h2 id="en-v1.3.6">Highlights</h2>
  • Added native Volcano Engine Ark Seedance video generation for generating source clips directly from script segments.
  • Added OFox multi-model text-to-video support, allowing Seedance, Wan, and other models to share one API key.
  • Added Metaso MiniMax H3 text-to-video support with 768P/2K output, 4–15 second clips, and 9:16, 16:9, and 1:1 aspect ratios.
  • Added an OpenAI-compatible text-to-image material source for cloud relays and local gateways.
  • Added OpenRouter and APIMart as OpenAI-compatible LLM providers.
  • Added a WebUI Auto-Publish settings tab for Upload-Post, with clearer API key and account setup guidance.
  • Added CLI batch manifest mode and applied saved WebUI settings as CLI defaults when command-line values are omitted.
  • Added configurable source clip fit modes: cover fills the frame by cropping excess edges, while contain preserves the complete source with letterboxing.
  • Added complete French and Korean WebUI translations.
  • Reorganized material source settings, grouped video sources by capability, and centralized AI video provider credentials in the WebUI settings.

Security

  • Restricted browser cross-origin API access to same-origin requests by default. Trusted standalone browser frontends can be enabled explicitly with CORS_ALLOWED_ORIGINS.
  • Added provenance and SBOM attestations to published container images.

Fixes and Improvements

  • Measured narration duration from the generated audio file instead of relying only on subtitle cues.
  • Anchored the SiliconFlow subtitle timeline to the complete audio duration.
  • Ensured AudioFileClip resources are closed in ElevenLabs, Chatterbox, and Fish Audio paths.
  • Prevented script cleanup from greedily removing unrelated bracketed or parenthesized text.
  • Removed a misleading retry warning after the final LLM attempt.
  • Fixed Redis URLs when no password is configured.
  • Preserved log records when the project root and log destination are on different mounts.
  • Fixed Unicode console output after successful CLI generation on Windows.
  • Added safe, portable download filenames, including RFC-compatible quoting and protection from Windows-reserved names.
  • Improved WebUI preview behavior on headless servers by falling back to browser playback and download.
  • Decoupled Upload-Post configuration from automatic publishing so settings can be saved without enabling uploads.
  • Hardened OpenAI-compatible image handling: malformed 200 responses now skip only the affected keyword, while local storage failures stop further paid requests.

Upgrade Notes

  • Browser API access now defaults to same-origin requests. Standalone web frontends must declare their trusted origins through CORS_ALLOWED_ORIGINS; server-side clients such as curl, Postman, and n8n are unaffected.
  • CLI commands now inherit saved WebUI settings for omitted options. Explicit CLI arguments and batch manifest values still take precedence.

安全性

  • 浏览器跨域 API 访问现在默认遵循同源策略；如需使用独立网页前端，可以通过 CORS_ALLOWED_ORIGINS 显式配置可信来源。
  • 发布的容器镜像新增构建来源证明和 SBOM 软件物料清单证明。

修复与改进

  • 改为从真实生成的音频文件测量旁白时长，不再仅依赖字幕时间轴。
  • 将 SiliconFlow 字幕时间轴末尾与完整音频时长对齐。
  • 确保 ElevenLabs、Chatterbox 和 Fish Audio 链路始终关闭 AudioFileClip 资源。
  • 修复脚本文本清理可能贪婪删除多组括号内容的问题。
  • 移除大语言模型最后一次重试结束后误导性的“正在重试”日志。
  • 修复 Redis 未配置密码时生成错误鉴权片段的问题。
  • 修复项目目录和日志目录位于不同挂载点时日志记录丢失的问题。
  • 修复 Windows 终端无法编码 Unicode 时，CLI 在视频成功生成后异常退出的问题。
  • 改进下载文件名的安全性和跨平台兼容性，包括标准引用编码以及 Windows 保留名称保护。
  • 无图形桌面的服务器环境下，WebUI 会回退到浏览器播放和下载视频。
  • 将 Upload-Post 配置与自动发布开关解耦，允许用户保存配置但不立即启用上传。
  • 加强 OpenAI 兼容文生图异常处理：HTTP 200 返回损坏图片时仅跳过当前关键词，本地存储失败时则停止后续付费请求。

升级说明

  • 浏览器调用 API 现在默认遵循同源策略。独立网页前端需要通过 CORS_ALLOWED_ORIGINS 配置可信来源；curl、Postman、n8n 等服务端调用不受影响。
  • CLI 未显式传入参数时，会继承 WebUI 保存的设置；明确传入的 CLI 参数和批量清单字段仍拥有更高优先级。
