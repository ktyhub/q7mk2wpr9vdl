MoneyPrinterTurbo v1.2.9

Highlights

  • Advanced script control in the WebUI — v1.2.9 exposes script paragraph count, freeform custom requirements, and an optional full custom system prompt. This is the biggest workflow change: power users can now override the entire generation prompt rather than tweaking outputs post-hoc, which means you own the expected output schema — if your custom prompt drops required fields, downstream TTS/subtitle stages may break. The team added regression coverage for these settings and verified them end-to-end through script generation → TTS → Pexels download → subtitles → final video, so the path is at least smoke-tested upstream.
  • Two new providers: Xiaomi MiMo LLM and MiMo TTS — provider choice widens beyond the existing set, letting you standardize script generation and voice synthesis on one vendor. Treat these as opt-in: they'll need their own credentials/quotas, and mixing a new LLM with an existing TTS config is where subtle voice/tone mismatches tend to show up. Worth validating output quality before switching a production pipeline.
  • Ollama base URL handling for Docker — a targeted fix for self-hosters whose Ollama runs alongside the app in containers. Default base URL resolution now accounts for Docker networking, removing the common "connection refused" from inside the container reaching the host's Ollama. If you previously hard-coded a workaround URL, revisit it — the default may now do the right thing.
  • WebUI no longer binds to all interfaces — webui.sh now defaults to 127.0.0.1 instead of 0.0.0.0. This is a behavioral/security change worth flagging: if you relied on reaching the WebUI from another machine on your LAN, it will stop working until you explicitly re-enable external binding. For local-only users this quietly removes an unintended network exposure.
  • Media and platform fixes that unblock edge cases — custom BGM paths now resolve correctly in both WebUI and API flows; string video concat mode is handled in downloads; long-text subtitle wrapping, Edge TTS signed-zero rate formatting, and Windows launcher robustness are corrected, along with missing Turkish keys and a README-en code-fence typo. None are headline features, but they remove specific failure modes (URL paths, concatenation, formatting, launch on Windows) that would otherwise break otherwise-normal runs.
  • Breaking changes — None in this release.

What's Changed

New features

  • Added advanced script settings in WebUI:
    • script paragraph count
    • custom script requirements
    • optional full custom system prompt for advanced users
  • Added Xiaomi MiMo LLM provider support.
  • Added Xiaomi MiMo TTS provider support.
  • Improved Ollama default base URL handling for Docker environments.

Fixes and improvements

  • Fixed custom BGM path handling for WebUI and API flows.
  • Fixed Windows WebUI launcher robustness.
  • Fixed webui.sh to bind/open 127.0.0.1 by default instead of opening 0.0.0.0.
  • Fixed string video concat mode handling in downloads.
  • Fixed subtitle wrapping for long text.
  • Fixed Edge TTS signed-zero rate formatting.
  • Added missing Turkish translation keys.
  • Fixed README-en ImageMagick code fence.

Testing

  • Added regression coverage for LLM provider behavior, local TTS/video task paths, video concat mode handling, and advanced script prompt settings.
  • Verified advanced script settings end-to-end with real script generation, TTS, Pexels material download, subtitle generation, and final video synthesis.
