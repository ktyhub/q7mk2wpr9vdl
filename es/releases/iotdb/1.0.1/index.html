#iotdbv1.0.1

Nuevas características

  • [IOTDB-5102] El soporte explica los SQL usando la cláusula align by device
  • [IOTDB-5282] Agregue variables de visualización SQL, que pueden mostrar las variables del clúster actual

Mejoras

  • [IOTDB-4595] Agregar datos de monitoreo en tiempo real para la fusión de tsfile
  • [IOTDB-5125] Detenga el proceso cuando el puerto ya esté en uso al iniciar ConfigNode o DataNode
  • [IOTDB-5185] Se corrigió que la instantánea anterior no se elimina en IoTConsensus
  • [IOTDB-5202] Soporte para mostrar regiones con respecto a la base de datos
  • [IOTDB-5205] Construya el protocolo de inicio del nodo del clúster, rechace la solicitud de inicio o reinicio de ConfigNode o DataNode cuando utilice datos incorrectos
  • [IOTDB-5208] Se corrigió el aumento de identificadores de archivos cuando TsFileResource se degrada y compacta con un rendimiento rápido
  • [IOTDB-5223] Causa que el inicio de DataNode falle cuando se configuran varios discos en el directorio de datos y el protocolo de consenso de la región de datos utiliza Ratis
  • [IOTDB-5232] Agregar monitor de métrica de uso de memoria de esquema
  • [IOTDB-5249] Agregar interfaz para configurar el tipo de datos cuando los usuarios personalizan el formateador de carga útil de mqtt
  • [IOTDB-5258] Agregar parámetro de tiempo de espera para la herramienta ExportCSV/ExportTsFile
  • [IOTDB-5306] Cambiar el puerto predeterminado de ConfigNode y DataNode
  • [IOTDB-5326] Agregue el parámetro nombre_clúster para distinguir diferentes clústeres
  • [IOTDB-5389] Causa que el inicio de DataNode falle cuando wal_mode está deshabilitado en IoTConsensus

Corrección de errores

  • [IOTDB-4978] Se corrigió un posible bloqueo muerto al usar seleccionar en
  • [IOTDB-5090] Se corrigió el NPE al ejecutar stop-datanode.sh
  • [IOTDB-5116] Se corrigió el resultado vacío incorrecto establecido en la consulta de agregación mientras no hay datos en la serie temporal consultada
  • [IOTDB-5118] Se corrigió que el nodo de datos abre demasiados identificadores de archivos (TYPE DIR)
  • [IOTDB-5174] Se corrigió el error de reinicio cuando el nombre de host de IoTConsensus contenía '-'
  • [IOTDB-5126] Se corrigió que show-regions mostrara IP en lugar de nombre de host aunque se use el nombre de host al registrarse
  • [IOTDB-5135] Soluciona el error de sincronización de la instantánea (también bloquea la instantánea de ConfigNode) cuando el archivo de sincronización está vacío
  • [IOTDB-5141] Soluciona el error del programador de compactación rápida
  • [IOTDB-5144] Se corrigió classCastException en IoTDBDatabaseMetadata de jdbc
  • [IOTDB-5158] Se solucionó el error al obtener dispositivos desde tsfile
  • [IOTDB-5170] Soluciona el problema por el cual el nodo de datos se cierra al ejecutar stop-confignode.bat en la plataforma Windows
  • [IOTDB-5210] Se corrigió el error simultáneo causado por el inicio y el cierre del controlador.
  • [IOTDB-5212] Actualice un mensaje de verificación CQ ilegal de v0.14.0 a v1.0
  • [IOTDB-5215] Se corrigió el uso incorrecto de chunkPointNumLowerBound en IoTDBDescriptor
  • [IOTDB-5216] La corrección del orden por serie temporal no tiene efecto en la última consulta alineada
  • [IOTDB-5222] Se corrigió la carga de algunas configuraciones relacionadas con métricas
  • [IOTDB-5231] Se corrigió que Datanode no podía iniciarse al vincular el error 9091
  • [IOTDB-5233] Corregir el mensaje de interfaz de ahorro no compatible de la plantilla de esquema
  • [IOTDB-5236] Arreglar DeleteData Python API no puede funcionar
  • [IOTDB-5240] Se corrige el error de lectura/escritura de la serie temporal de la plantilla de esquema después del reinicio
  • [IOTDB-5261] Se corrige la cantidad de clients en el grupo client de AsyncIoTConsensusServiceClient que no se puede cambiar a través de dn_max_connection_for_internal_service
  • [IOTDB-5266] Refina el código del selector cruzado y corrige el error al usar FileTImeIndex
  • [IOTDB-5269] Se deben eliminar los datos incorrectos de los dispositivos después de ejecutar delete from sql
  • [IOTDB-5277] Se corrigió el error de reinicio de DataNode cuando SchemaRegion cargaba la instantánea
  • [IOTDB-5278] Arreglar que el controlador JDBC no se pueda conectar al dbeaver
  • [IOTDB-5285] Se solucionó el error de TimePartition al reiniciar con una configuración de partición de tiempo diferente
  • [IOTDB-5286] Los archivos de destino de reparación se seleccionan para participar en otra tarea de compactación
  • [IOTDB-5313] La solución Python client no maneja REDIRECTION_RECOMMEND correctamente
  • [IOTDB-5452] Agregue el examen de lessDataRegionGroupNumSetByUser para garantizar que el sistema no cambie lessDataRegionGroupNum
  • [IOTDB-5498] Soluciona el problema de OOM de SessionPool cuando el número de dispositivos y sesiones es grande
  • [IOTDB-5501] Solucionar pérdida de memoria en MemoryPool
  • [IOTDB-5525] Soluciona el error de partición del dispositivo después de la recuperación de partición

iotdb v1.0.1

New Features

  • [IOTDB-5102] Support explain the sqls using align by device clause
  • [IOTDB-5282] Add SQL show variables, which can display the current cluster variables

Improvements

  • [IOTDB-4595] Add real-time monitoring data for tsfile merge
  • [IOTDB-5125] Stop the process when port is already in use when launching ConfigNode or DataNode
  • [IOTDB-5185] Fixed that old snapshot is not deleted in IoTConsensus
  • [IOTDB-5202] Support showing regions regarding database
  • [IOTDB-5205] Construct Cluster Node startup protocol, reject start or restart request of ConfigNode or DataNode when using wrong data
  • [IOTDB-5208] Fix increase of file handles when TsFileResource is degraded and compacted with fast performer
  • [IOTDB-5223] Cause DataNode startup to fail when multiple disks are configured in the data directory and the dataRegion consensus protocol uses Ratis
  • [IOTDB-5232] Add Schema Memory Usage metric monitor
  • [IOTDB-5249] Add interface to set datatype when users customize the payload formatter of mqtt
  • [IOTDB-5258] Add timeout parameter for ExportCSV/ExportTsFile Tool
  • [IOTDB-5306] Change the default port of ConfigNode and DataNode
  • [IOTDB-5326] Add cluster_name parameter to distinguish different cluster
  • [IOTDB-5389] Cause DataNode starup to fail when wal_mode is disabled in IoTConsensus

Bug Fixes

  • [IOTDB-4978] Fix possible deadLock while using select into
  • [IOTDB-5090] Fix the NPE when executing stop-datanode.sh
  • [IOTDB-5116] Fix wrong empty result set in aggregation query while there is no data in queried timeseries
  • [IOTDB-5118] Fix that datanode opens too many file handles （TYPE DIR）
  • [IOTDB-5174] Fixed restart failure when IoTConsensus hostname containing '-'
  • [IOTDB-5126] Fix that show-regions show IP rather than hostname even though the hostname is used when registering
  • [IOTDB-5135] Fix the Sync snapshot failure (also blocks ConfigNode snapshot) when sync file is empty
  • [IOTDB-5141] Fix fast compaction scheduler bug
  • [IOTDB-5144] Fix classCastException in IoTDBDatabaseMetadata of jdbc
  • [IOTDB-5158] Fix failure of getting devices from tsfile
  • [IOTDB-5170] Fix the problem that datanode is closed when executing stop-confignode.bat on Windows platform
  • [IOTDB-5210] Fix concurrent bug caused by init and close of driver
  • [IOTDB-5212] Upgrade an illegal CQ verification prompt from v0.14.0 to v1.0
  • [IOTDB-5215] Fix the wrong usage of chunkPointNumLowerBound in IoTDBDescriptor
  • [IOTDB-5216] Fix order by timeseries doesn't take effect in aligned last query
  • [IOTDB-5222] Fix the load of some metric related configuration
  • [IOTDB-5231] Fix that Datanode could not start when binding 9091 error
  • [IOTDB-5233] Correct the message of unsupported thrift interface of schema template
  • [IOTDB-5236] Fix DeleteData Python API cannot work
  • [IOTDB-5240] Fix schema template timeseries read/write error after restart
  • [IOTDB-5261] Fix the number of clients in client pool of AsyncIoTConsensusServiceClient can not be changed through dn_max_connection_for_internal_service
  • [IOTDB-5266] Refine the code of cross selector and fix the bug when using FileTImeIndex
  • [IOTDB-5269] Fix wrong data of devices ought to be deleted after executing delete from sql
  • [IOTDB-5277] Fix DataNode restart failure when SchemaRegion loading snapshot
  • [IOTDB-5278] Fix JDBC Driver cannot connect to the dbeaver
  • [IOTDB-5285] Fix TimePartition error when restarting with different time partition configuration
  • [IOTDB-5286] Fix target files are selected to participate in other compaction task
  • [IOTDB-5313] Fix Python client doesn't handle REDIRECTION_RECOMMEND correctly
  • [IOTDB-5452] Add leastDataRegionGroupNumSetByUser examination to ensure that leastDataRegionGroupNum will not be changed by system
  • [IOTDB-5498] Fix SessionPool OOM problem when the number of devices and sessions is large
  • [IOTDB-5501] Fix memory leak in MemoryPool
  • [IOTDB-5525] Fix the partition error of device after partition fetcher
