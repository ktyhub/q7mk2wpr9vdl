#iotdbv0.12.1

Corrección de errores

  • [GITHUB-3373] Elimine la conexión líder en caché rota y optimice el método insertRecords en la sesión
  • [IOTDB-1433] Se corrigió el error en getMetadataAndEndOffset al consultar un dispositivo no existente
  • [IOTDB-1432] datos de pérdida de compactación de nivel fijo
  • [IOTDB-1427] Se corrigió el bloqueo de compactación con consulta
  • [IOTDB-1420] Soluciona el error de compactación ttl
  • [IOTDB-1419] Elimine el clearCompactionStatus redundante y corrija que la compactación continua no tenga efecto cuando enablePartition
  • [IOTDB-1415] Se corrigió OOM causado por ChunkCache
  • [IOTDB-1414] Se produjo NPE cuando se llamó al método getStorageGroupNodeByPath() usando una ruta que no existe
  • [IOTDB-1412] Se genera un mensaje de excepción poco claro al ejecutar InsertTabletPlan vacío
  • [IOTDB-1411] Se corrigió thriftMaxFrameSize y thriftDefaultBufferSize no tiene efecto.
  • [IOTDB-1398] No seleccione archivos unseq cuando haya archivos unseq antiguos sin compactar
  • [IOTDB-1390] Se corrigió un error de pérdida de datos por compactación unseq
  • [IOTDB-1384] Arreglar grupo por error
  • [ISSUE-3378] Se corrigió NPE al borrar la carpeta de actualización; Corregir algunas estadísticas faltantes de encabezado de página actualizadas
  • [GITHUB-3339] Intente arreglar el bloqueo de sg
  • [GITHUB-3329] Se corrigió la actualización de NPE y DeadLock
  • [GITHUB-3319] La herramienta de actualización de reparación no puede cerrar el lector de archivos
  • [IOTDB-1212] Solución El mensaje de error proporcionado no es correcto al ejecutar select sin(non_existence) desde root.sg1.d1
  • [IOTDB-1219] Soluciona un posible problema de NPE en el módulo UDF
  • [IOTDB-1286] Se corrigieron 4 puntos de fuga de memoria de C++
  • [IOTDB-1294] Se corrigió que la operación de eliminación dejara de ser válida después de la compactación
  • [IOTDB-1313] Se corrigió la pérdida de precisión de tiempo al importar csv con formato de marca de tiempo no compatible
  • [IOTDB-1316] La herramienta importCsv debería continuar insertando si una parte de la inserción falla
  • [IOTDB-1317] El registro de corrección CatchUp siempre fallaba debido a que no se verificaba el índice de coincidencias del seguidor
  • [IOTDB-1323] Se corrigió que devolviera un mensaje de éxito cuando se encontrara RuntimeException durante el proceso de inserción.
  • [IOTDB-1325] Se corrigió la excepción de StackOverflow en la consulta de grupo por mes natural
  • [IOTDB-1330] Se corrigió el error al cargar tsfile cuando el tsfile de la partición multipartición solo tiene una página
  • [IOTDB-1348] Arreglar que el último plan no funciona en modo clúster
  • [IOTDB-1376] Se corrigió BatchProcessException no se manejaba correctamente en BaseApplier
  • [ISSUE-3277] Se corrigió que TotalSeriesNumber en MManager contaba dos veces al recuperarse
  • [ISSUE-3116] Se corrigió el error al usar la unidad de mes natural en el intervalo de tiempo en grupo por consulta
  • [ISSUE-3309] Arreglar que InsertRecordsOfOneDevice funciona demasiado lento
  • Se corrigió que el índice del plan siempre fuera cero cuando se usa la interfaz insertRecords para ejecutar el clúster.
  • Agregar verificación de autoridad para que los usuarios creen series temporales usando la interfaz de ejecución de Batch sin el privilegio
  • Se corrigió versionInfo NPE al consultar la actualización de 0.11 tsfile
  • La herramienta de actualización de reparación no puede cargar el archivo ts antiguo si la partición de tiempo está habilitada en 0.11
  • Se corrigió el lanzamiento de import csv ArrayOutOfIndexError cuando el último valor en una línea es nulo
  • La herramienta de actualización de reparación no puede cerrar el lector de archivos

Mejoras

  • [GITHUB-3399] Cambie el tamaño de matriz primitiva predeterminado a 32
  • [IOTDB-1387] Compatibilidad sin Null ALL en la cláusula de alineación por dispositivo, Filtrar RowRecord automáticamente si alguna columna es nula o todas las columnas son nulas
  • [IOTDB-1385] Extrae el superusuario a la configuración
  • [IOTDB-1315] ExportCsvTool debería admitir la marca de tiempo yyyy-MM-dd'T'HH:mm:ss.SSSZ
  • [IOTDB-1339] optimizar TimeoutChangeableTSnappyFramedTransport
  • [IOTDB-1356] Separe unseq_file_num_in_each_level de la selección del archivo candidato en la compactación unseq
  • [IOTDB-1357] La compactación utiliza la estrategia de combinación de fragmentos adjuntos cuando el fragmento ya es lo suficientemente grande
  • [IOTDB-1380] Cierra automáticamente el conjunto de datos mientras no haya más datos
  • Optimizar el líder de sincronización para meta

Nuevas características

  • [GITHUB-3389] TTL se puede configurar en cualquier ruta
  • [GITHUB-3387] Agregar parámetro compaction_interval=10000ms
  • [IOTDB-1190] Totalmente compatible con el conjunto de caracteres de URL HTTP en la ruta de la serie temporal
  • [IOTDB-1321][IOTDB-1322] Filtrar RowRecord automáticamente si alguna columna es nula o todas las columnas son nulas
  • [IOTDB-1357] La compactación utiliza la estrategia de combinación de fragmentos agregados cuando el fragmento ya es grande
  • [ISSUE-3089] Hacer posible que los grupos de almacenamiento tengan nombres con guión

Cambios varios

  • [GITHUB-3346] actualice netty y excluya reclamos para verificación de cumplimiento
  • [IOTDB-1259] actualiza libthrift de 0.12.0/0.13.0 a 0.14.1 *Descomentar las configuraciones menos utilizadas
  • Habilitar la configuración concurrent_writing_time_partition

iotdb v0.12.1

Bug Fixes

  • [GITHUB-3373] Remove the broken cached leader connection & optimize the insertRecords method in session
  • [IOTDB-1433] Fix bug in getMetadataAndEndOffset when querying non-exist device
  • [IOTDB-1432] fix level compaction loss data
  • [IOTDB-1427] Fix compaction lock with query
  • [IOTDB-1420] Fix compaction ttl bug
  • [IOTDB-1419] Remove redundant clearCompactionStatus, fix continuous compaction doesn't take effect when enablePartition
  • [IOTDB-1415] Fix OOM caused by ChunkCache
  • [IOTDB-1414] NPE occurred when call getStorageGroupNodeByPath() method using not exist path
  • [IOTDB-1412] Unclear exception message thrown when executing empty InsertTabletPlan
  • [IOTDB-1411] Fix thriftMaxFrameSize and thriftDefaultBufferSize does not in effect
  • [IOTDB-1398] Do not select unseq files when there are uncompacted old unseq files
  • [IOTDB-1390] Fix unseq compaction loss data bug
  • [IOTDB-1384] Fix group by bug
  • [ISSUE-3378] Fix NPE when clear upgrade folder; Fix some upgraded pageHeader missing statistics
  • [GITHUB-3339] Try to fix sg dead lock
  • [GITHUB-3329] Fix upgrade NPE and DeadLock
  • [GITHUB-3319] Fix upgrade tool cannot close file reader
  • [IOTDB-1212] Fix The given error message is not right when executing select sin(non_existence) from root.sg1.d1
  • [IOTDB-1219] Fix a potential NPE issue in UDF module
  • [IOTDB-1286] Fix 4 C++ mem-leak points
  • [IOTDB-1294] Fix delete operation become invalid after compaction
  • [IOTDB-1313] Fix lossing time precision when import csv with unsupported timestamp format
  • [IOTDB-1316] The importCsv tool should continue inserting if a part of insertion failed
  • [IOTDB-1317] Fix log CatchUp always failed due to not check the follower's match index
  • [IOTDB-1323] Fix return a success message when encounter RuntimeException during the insertion process
  • [IOTDB-1325] Fix StackOverflow Exception in group by natural month query
  • [IOTDB-1330] Fix the load tsfile bug when the cross multi partition's tsfile only have one page
  • [IOTDB-1348] Fix Last plan not work in cluster mode
  • [IOTDB-1376] Fix BatchProcessException was not correctly handled in BaseApplier
  • [ISSUE-3277] Fix TotalSeriesNumber in MManager counted twice when recovering
  • [ISSUE-3116] Fix bug when using natural month unit in time interval in group by query
  • [ISSUE-3309] Fix InsertRecordsOfOneDevice runs too slow
  • Fix the plan index is always zero when using insertRecords interface to run the cluster
  • Add authority check for users create timeseries using executeBatch interface without the privilege
  • Fix versionInfo NPE when query upgrading 0.11 tsfile
  • Fix upgrade tool cannot load old tsfile if time partition enabled in 0.11
  • Fix import csv throw ArrayOutOfIndexError when the last value in a line is null
  • Fix upgrade tool cannot close file reader

Improvements

  • [GITHUB-3399] Change the default primitive array size to 32
  • [IOTDB-1387] Support Without Null ALL in align by device clause, Filter RowRecord automatically if any column in it is null or all columns are null
  • [IOTDB-1385] Extract the super user to the configuration
  • [IOTDB-1315] ExportCsvTool should support timestamp yyyy-MM-dd'T'HH:mm:ss.SSSZ
  • [IOTDB-1339] optimize TimeoutChangeableTSnappyFramedTransport
  • [IOTDB-1356] Separate unseq_file_num_in_each_level from selecting candidate file in unseq compaction
  • [IOTDB-1357] Compaction use append chunk merge strategy when chunk is already large enough
  • [IOTDB-1380] Automatically close the dataset while there is no more data
  • Optimize sync leader for meta

New Features

  • [GITHUB-3389] TTL can be set to any path
  • [GITHUB-3387] Add parameter compaction_interval=10000ms
  • [IOTDB-1190] Fully support HTTP URL char set in timeseries path
  • [IOTDB-1321][IOTDB-1322] Filter RowRecord automatically if any column in it is null or all columns are null
  • [IOTDB-1357] Compaction use append chunk merge strategy when chunk is already large
  • [ISSUE-3089] Make it possible for storage groups to have name with hyphen

Miscellaneous changes

  • [GITHUB-3346] upgrade netty and claim exclusion for enforcer check
  • [IOTDB-1259] upgrade libthrift from 0.12.0/0.13.0 to 0.14.1
  • Uncomment the less used configurations
  • Enable the configration concurrent_writing_time_partition
