PaddleOCR v2.9.0

Highlights

  • PaddlePaddle 3.0 readiness — Much of the non-doc work is a 3.0 compatibility layer: benchmark support (#13574), runtime fixes (#13568), and PIR (the new program intermediate representation) dy2st-training and while-op fixes (#13853, #14016). If you use static-graph training or export inference models, these are silent correctness fixes inside graph rewriting — validate exported models on 3.0 before rolling out, even if you aren't upgrading immediately.
  • PaddleX becomes the recommended path — Main-branch PaddleX support (#13523), the reframing of "all-in-one" tooling as low-code development (#13979, #13932–#13934), and a PaddleX-based quickstart (#13936) show the project moving toward pipeline APIs and away from hand-edited YAML. Docs were consolidated onto a new MkDocs site with versioned docs (#13375, #13957) while older application/dataset docs were deleted (#13551, #13662, #13700), so update deep links — old doc URLs will 404.
  • LaTeX formula recognition enters the main pipeline — New LaTeXOCR support (#13401) is wired into PP-Structure alongside PDF-to-Markdown export (#13868, #13942), the first end-to-end document→Markdown-with-math path in this release. The chain of follow-ups (#13750, #13920, and a last-minute reset in #14047) hints the feature was still stabilizing at tag time; pin the exact version if you need reproducible output.
  • More scripts — but verify model availability — Dictionaries/corpora added for Hebrew (#13797), Syriac (#13800), Vietnamese (#13698), and Bengali (#13373). Adding a dictionary is not the same as shipping a trained recognition checkpoint, so confirm a matching rec model exists before treating these as production-ready rather than mere tokenizer coverage.
  • Leaner installs, new versioning scheme — Dependency pruning (#13461), disabled automatic albumentations version checks (#13583), a MANIFEST.in fix for setuptools 72.2.0 (#13670), and a switch to setuptools-scm for version extraction (#13716). Watch for code relying on transitive imports — the tools.infer import failure needed an explicit fix (#13348), so similar breakage can surface in downstream scripts.
  • Inference and deploy behavior to watch — C++ inference now honors --enable_mkldnn=false (#13539) and the flag is renamed onednn (#13757), so update deploy scripts. --image_dir is now a required CLI argument (#13896). Fixes also landed for hubserving (#13918), multi-GPU model downloads (#13610), SRN/SLANet inference (#13851, #13861), and GPU memory growth (#14044) — remove any workarounds you pinned for those.

No formally declared breaking changes in this release.
