PaddleOCR v3.2.0

2025.8.21 v3.2.0 lanzado

  • Adiciones importantes al modelo:

    • Se introdujo la capacitación, la inferencia y la implementación de modelos de reconocimiento PP-OCRv5 en inglés, tailandés y griego. El modelo PP-OCRv5 en inglés ofrece una mejora del 11 % en escenarios en inglés en comparación con el modelo principal PP-OCRv5, y los modelos de reconocimiento tailandés y griego logran precisiones de 82.68% y 89.28%, respectivamente.

  • Mejoras de la capacidad de implementación:

    • Soporte completo para las versiones del framework PaddlePaddle 3.1.0 y 3.1.1.
    • Actualización integral de la solución de implementación local PP-OCRv5 C++, que ahora admite Linux y Windows, con paridad de funciones y precisión idéntica a la implementación Python.
    • La inferencia de alto rendimiento ahora es compatible con CUDA 12 y la inferencia se puede realizar utilizando los backends Paddle Inference u ONNX Runtime.
    • La solución de implementación orientada a servicios de alta estabilidad ahora es completamente de código abierto, lo que permite a los usuarios personalizar las imágenes Docker y SDK según sea necesario.
    • La solución de implementación orientada a servicios de alta estabilidad también admite la invocación a través de solicitudes HTTP construidas manualmente, lo que permite el desarrollo de código del lado cli en cualquier lenguaje de programación.

  • Soporte de referencia:

    • Todas las líneas de producción ahora admiten evaluaciones comparativas detalladas, lo que permite medir el tiempo de inferencia de un extremo a otro, así como datos de latencia por capa y por módulo para ayudar con el análisis de rendimiento.
    • La documentación se actualizó para incluir métricas clave para configuraciones comúnmente utilizadas en hardware convencional, como latencia de inferencia y uso de memoria, lo que proporciona referencias de implementación para los usuarios.

  • Corrección de errores:

    • Se resolvió el problema del error al guardar registros durante el entrenamiento del modelo.
    • Se actualizó el componente de aumento de datos para modelos de fórmulas para compatibilidad con versiones más recientes de la dependencia de albumentaciones y se corrigieron advertencias de interbloqueo al usar el paquete de tokenizadores en escenarios de múltiples procesos.
    • Se corrigieron inconsistencias en el comportamiento de los interruptores (por ejemplo, use_chart_parsing) en los archivos de configuración de PP-StructureV3 en comparación con otras canalizaciones.

  • Otras mejoras:

    • ** Dependencias principales y opcionales separadas. Sólo se requieren dependencias básicas mínimas para el reconocimiento de texto básico; Se pueden instalar dependencias adicionales para el análisis de documentos y la extracción de información según sea necesario.**
    • Compatibilidad habilitada para tarjetas gráficas NVIDIA RTX serie 50 en Windows; los usuarios pueden consultar la guía de instalación para las versiones correspondientes del marco PaddlePaddle.
    • Los modelos de la serie PP-OCR ahora admiten la devolución de coordenadas de un solo carácter.
    • Se agregaron AIStudio, ModelScope y otras fuentes de descarga de modelos, lo que permite a los usuarios especificar la fuente para las descargas de modelos.
    • Se agregó soporte para la conversión de gráfico a tabla a través del módulo PP-Chart2Table.
    • Descripciones de documentación optimizadas para mejorar la usabilidad.

2025.8.21 v3.2.0 发布

  • 重要模型新增：

    • 新增 PP-OCRv5 英文、泰文、希腊文识别模型的训练、推理、部署。其中 PP-OCRv5 英文模型较 PP-OCRv5 11%, 11%, 82.68%, 89.28%.

  • 部署能力升级:

    • 全面支持飞桨框架 3.1.0 y 3.1.1 版本。
    • 全面升级 PP-OCRv5 C++ compatible con Linux, Windows, compatible con Python y compatible con Python.
    • 高性能推理支持 CUDA 12,可使用 Paddle Inference,ONNX Runtime 后端推理。
    • 高稳定性服务化部署方案全面开源，支持用户根据需求对 Docker 镜像和 SDK进行定制化修改。

  • La solución de implementación basada en servicios de alta estabilidad admite la invocación mediante la construcción manual de solicitudes HTTP, lo que permite escribir el código del cliente en cualquier lenguaje de programación.

  • Soporte de referencia:

    • **Todas las líneas de producción admiten el punto de referencia detallado de la línea de producción, que puede medir el tiempo de inferencia de un extremo a otro de la línea de producción, así como los datos que consumen mucho tiempo capa por capa y módulo por módulo, que se pueden utilizar para ayudar en el análisis del rendimiento de la línea de producción. **
    • **El documento complementa los indicadores clave de las configuraciones comúnmente utilizadas de cada línea de producción en el hardware convencional, incluido el tiempo de inferencia y el uso de memoria, etc., para proporcionar una referencia para la implementación del usuario. **

  • Corrección de errores:

    • Se solucionó el problema de no guardar los registros de entrenamiento durante el entrenamiento del modelo.
    • La parte de mejora de datos del modelo de fórmula se ha actualizado para compatibilidad de versiones para adaptarse a la nueva versión de la dependencia de albumentaciones, y se ha solucionado una advertencia de interbloqueo que aparece al usar el paquete de dependencia de tokenizadores en múltiples procesos.
    • Se solucionó el problema de que el comportamiento de interruptores como use_chart_parsing en el archivo de configuración PP-StructureV3 no es consistente con otras líneas de producción.

  • Otras actualizaciones:

    • **Separe las dependencias necesarias y las dependencias opcionales. Cuando se utiliza la función básica de reconocimiento de texto, solo es necesario instalar unas pocas dependencias principales; Si se requieren funciones como el análisis de documentos y la extracción de información, los usuarios pueden optar por instalar dependencias adicionales según sea necesario. **
    • ** Admite que los usuarios de Windows utilicen tarjetas gráficas de la serie NVIDIA 50 y pueden instalar la versión correspondiente del marco de paleta de acuerdo con la documentación de instalación. **
    • **Los modelos de la serie PP-OCR admiten la devolución de coordenadas de texto único. **
    • Se agregan al modelo nuevas fuentes de descarga como AIStudio y ModelScope. Puede especificar la fuente de descarga relevante para descargar el modelo correspondiente.
    • Admite la capacidad de razonamiento del módulo de función única PP-Chart2Table de conversión de gráfico a tabla.
    • Optimice las descripciones en algunos documentos de uso para mejorar la facilidad de uso.

PaddleOCR v3.2.0

Highlights

  • Expanded PP-OCRv5 recognition — English, Thai, and Greek models now cover training, inference, and deployment. The English model improves 11% over the main PP-OCRv5 model in English scenarios; Thai and Greek accuracies are reported at 82.68% and 89.28%.
  • Broader inference and deployment support — PaddlePaddle 3.1.0 and 3.1.1 are fully supported. The PP-OCRv5 C++ deployment now runs on Linux and Windows with Python-equivalent functionality and accuracy, while high-performance inference adds CUDA 12 and either Paddle Inference or ONNX Runtime backends.
  • Customizable production serving — The high-stability service deployment is fully open-source, enabling modifications to Docker images and SDKs. Direct HTTP invocation lets clients integrate from any programming language without depending on the bundled SDK.
  • Leaner dependency footprint — Core and optional dependencies are separated. Existing document-parsing or information-extraction environments may need their optional extras explicitly installed after upgrading.
  • Fine-grained performance profiling — Every production pipeline supports end-to-end, per-layer, and per-module timing, with published latency and memory baselines for common hardware configurations to guide capacity planning.
  • Richer pipeline outputs and corrected flags — PP-OCR models can return single-character coordinates, and PP-Chart2Table adds standalone chart-to-table inference. PP-StructureV3 switches such as use_chart_parsing now behave consistently with other pipelines, so verify configuration-driven results after upgrading.

No breaking changes declared.

2025.8.21 v3.2.0 released

  • Significant Model Additions:

    • Introduced training, inference, and deployment for PP-OCRv5 recognition models in English, Thai, and Greek. The PP-OCRv5 English model delivers an 11% improvement in English scenarios compared to the main PP-OCRv5 model, with the Thai and Greek recognition models achieving accuracies of 82.68% and 89.28%, respectively.

  • Deployment Capability Upgrades:

    • Full support for PaddlePaddle framework versions 3.1.0 and 3.1.1.
    • Comprehensive upgrade of the PP-OCRv5 C++ local deployment solution, now supporting both Linux and Windows, with feature parity and identical accuracy to the Python implementation.
    • High-performance inference now supports CUDA 12, and inference can be performed using either the Paddle Inference or ONNX Runtime backends.
    • The high-stability service-oriented deployment solution is now fully open-sourced, allowing users to customize Docker images and SDKs as required.
    • The high-stability service-oriented deployment solution also supports invocation via manually constructed HTTP requests, enabling client-side code development in any programming language.

  • Benchmark Support:

    • All production lines now support fine-grained benchmarking, enabling measurement of end-to-end inference time as well as per-layer and per-module latency data to assist with performance analysis.
    • Documentation has been updated to include key metrics for commonly used configurations on mainstream hardware, such as inference latency and memory usage, providing deployment references for users.

  • Bug Fixes:

    • Resolved the issue of failed log saving during model training.
    • Upgraded the data augmentation component for formula models for compatibility with newer versions of the albumentations dependency, and fixed deadlock warnings when using the tokenizers package in multi-process scenarios.
    • Fixed inconsistencies in switch behaviors (e.g., use_chart_parsing) in the PP-StructureV3 configuration files compared to other pipelines.

  • Other Enhancements:

    • Separated core and optional dependencies. Only minimal core dependencies are required for basic text recognition; additional dependencies for document parsing and information extraction can be installed as needed.
    • Enabled support for NVIDIA RTX 50 series graphics cards on Windows; users can refer to the installation guide for the corresponding PaddlePaddle framework versions.
    • PP-OCR series models now support returning single-character coordinates.
    • Added AIStudio, ModelScope, and other model download sources, allowing users to specify the source for model downloads.
    • Added support for chart-to-table conversion via the PP-Chart2Table module.
    • Optimized documentation descriptions to improve usability.

2025.8.21 v3.2.0 发布

  • 重要模型新增：

    • 新增 PP-OCRv5 英文、泰文、希腊文识别模型的训练、推理、部署。其中 PP-OCRv5 英文模型较 PP-OCRv5 主模型在英文场景提升 11%，泰文识别模型精度 82.68%，希腊文识别模型精度 89.28%。

  • 部署能力升级：

    • 全面支持飞桨框架 3.1.0 和 3.1.1 版本。
    • 全面升级 PP-OCRv5 C++ 本地部署方案，支持 Linux、Windows，功能及精度效果与 Python 方案保持一致。
    • 高性能推理支持 CUDA 12，可使用 Paddle Inference、ONNX Runtime 后端推理。
    • 高稳定性服务化部署方案全面开源，支持用户根据需求对 Docker 镜像和 SDK 进行定制化修改。
    • 高稳定性服务化部署方案支持通过手动构造HTTP请求的方式调用，该方式允许客户端代码使用任意编程语言编写。

  • Benchmark支持：

    • 全部产线支持产线细粒度 benchmark，能够测量产线端到端推理时间以及逐层、逐模块的耗时数据，可用于辅助产线性能分析。
    • 文档中补充各产线常用配置在主流硬件上的关键指标，包括推理耗时和内存占用等，为用户部署提供参考。

  • Bug修复：

    • 修复模型训练时训练日志保存失败的问题。
    • 对公式模型的数据增强部分进行了版本兼容性升级，以适应新版本的 albumentations 依赖，并修复了在多进程使用 tokenizers 依赖包时出现的死锁警告。
    • 修复 PP-StructureV3 配置文件中的 use_chart_parsing 等开关行为与其他产线不统一的问题。

  • 其他升级：

    • 分离必要依赖与可选依赖。使用基础文字识别功能时，仅需安装少量核心依赖；若需文档解析、信息抽取等功能，用户可按需选择安装额外依赖。
    • 支持 Windows 用户使用英伟达 50 系显卡，可根据安装文档安装对应版本的 paddle 框架。
    • PP-OCR 系列模型支持返回单文字坐标。
    • 模型新增 AIStudio、ModelScope 等下载源。可指定相关下载源下载对应的模型。
    • 支持图表转表 PP-Chart2Table 单功能模块推理能力。
    • 优化部分使用文档中的描述，提升易用性。
