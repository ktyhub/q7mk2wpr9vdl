Interruptor CC v4.0.32

Esta versión agrega Descargar actualizaciones automáticamente en segundo plano: después de activar "Descargar actualizaciones automáticamente" en "Configuración → Acerca de", la nueva versión se descargará y verificará en segundo plano. Aparecerá un mensaje emergente en la esquina inferior derecha preguntándole si desea instalarlo. No se reiniciará sin confirmación. "Configuración → Red" ha agregado detección de IP, que le permite ver la IP de salida y la región cuando se accede a CC Switch a través de un proxy global, un proxy temporal o la red actual. Además, hemos solucionado problemas como cuando Codex continúa una sesión anterior a través de proveedores de enrutamiento y conmutación, el upstream primero devuelve 200 y luego informa "No se puede descifrar", lo que provoca que se descarte toda la ronda; Codex solicita el informe 422 al conectarse a Mistral AI mediante enrutamiento o agregación; después de que una operación dentro de CC Switch falla, la bandeja se vacía y el proveedor no se puede cambiar hasta que se reinicie; Las herramientas instaladas con mise muestran dos registros de instalación en la página "Aplicación". Inglés → | Versión japonesa →

Agregar

Descargar actualizaciones automáticamente en segundo plano

"Configuración → Acerca de" agrega el interruptor "Descargar actualizaciones automáticamente", que está desactivado de forma predeterminada y se puede configurar individualmente para cada dispositivo.

  • Después de encenderlo, CC Switch lo comprobará un minuto después de iniciarse y luego cada seis horas. Si hay una nueva versión, se descargará y verificará en segundo plano.
  • Después de la descarga, se le preguntará si desea instalarlo en la esquina inferior derecha de la interfaz principal. La instalación reiniciará CC Switch y las solicitudes que pasen por el enrutamiento local se interrumpirán, por lo que deberá hacer clic en "Instalar y reiniciar" para continuar; esto se indicará en el mensaje cuando el enrutamiento esté activado.
  • Al hacer clic en "Más tarde" ya no se le solicitará esta versión. El punto rojo en la configuración, el botón en la página "Acerca de" y el nuevo "Reiniciar y actualizar a vX" en el menú de la bandeja y el panel de acceso directo aún se pueden instalar.
  • El paquete de instalación deb/rpm de la versión portátil y Linux no se puede instalar automáticamente. El interruptor aparecerá atenuado y se explicará el motivo.

Detección de IP

"Configuración → Red" agrega una detección de IP bajo el proxy global (#9449, consulte #9448 para conocer los requisitos): seleccione el proxy global guardado o complete un proxy temporal (solo se usa para esta detección, no se guarda). Después de hacer clic en "Detectar IP", se mostrará la IP de salida, si los resultados de los dos servicios de detección son consistentes e información como país o región, ciudad, operador, etc. Cuando no hay un proxy global, se utiliza el proxy del sistema o una conexión directa para la detección; cuando se especifica un proxy, no se utilizará la conexión directa si el proxy no puede conectarse.

  • Solo se ejecuta después de hacer clic, visitará icanhazip.com, ipify.org y enviará la IP medida a ipwho.is para consultar la ubicación.
  • Lo que se mide es la salida del propio CC Switch por esta línea, que no necesariamente es igual a la salida de clientes como Claude Code y Codex.

Otros

  • La tarjeta de proveedor inverso de GitHub Copilot muestra la cuenta GitHub vinculada (#9228, para conocer los requisitos, consulte #9480): anteriormente, solo se mostraba la dirección del sitio web oficial de GitHub Copilot y era difícil distinguir entre varias cuentas. Si no está vinculado, se mostrará la cuenta predeterminada del centro de autorización. Cuando se completa el comentario, el comentario tiene prioridad.

Arreglar

  • Cuando Codex continúa la sesión anterior a través del proveedor de conmutación, el flujo ascendente primero devuelve 200 y luego informa "El contenido de salida de la función cifrada no se pudo descifrar ni decodificar". Después de que Codex se vuelva a conectar cinco veces, esta ronda se descarta (#9476): cuando la solicitud contiene el registro de pensamiento o el contenido cifrado generado por el proveedor anterior, CC Switch esperará a que el flujo ascendente comience a generarse antes de entregarlo. Codex, si en este momento es rechazado, elimina estos contenidos y automáticamente vuelve a intentarlo en la misma empresa, y la sesión puede continuar. Las solicitudes sin dicho contenido se transmitirán como de costumbre.
  • Cuando el Codex está conectado a Mistral AI a través de enrutamiento o agregación, la solicitud informa 422 extra_forbidden (#9507): el campo especial Respuestas que lleva el Codex, los parámetros de pensamiento agregados automáticamente para el modelo DeepSeek/GLM en Mistral y el reasoning_content llevado en cada ronda después de usar la herramienta se eliminarán cuando se envíen a api.mistral.ai. Otros ríos arriba no se ven afectados.
  • Después de que una operación interna de CC Switch falla una vez, el menú de la bandeja queda vacío, el proveedor no se puede cambiar y la conexión directa no se puede restaurar al salir. Solo se puede reiniciar (#9472, #9483, consulte #8058): la base de datos, la configuración, la escritura del archivo de configuración, MCP, mensajes de aviso, precios, copias de seguridad y otras operaciones ahora se pueden restaurar después de una falla, y los cambios no finalizados en el momento de la falla se revertirán.
  • Cuando se utiliza Claude Code/Claude Desktop a través de GitHub Copilot, los modelos como Grok que solo admiten la interfaz Responses en Copilot informaron "no accesibles a través del punto final /chat/completions" (#6954, #9473): este tipo de modelo ahora usa la interfaz Responses y los modelos admitidos por ambas interfaces permanecen sin cambios.
  • Cuando Antigravity selecciona Orchestrator, todo el uso se registra bajo el nombre de un modelo virtual y el costo es 0 (#9493, #9494): ahora el precio se basa en el modelo real utilizado en cada paso y se agrega el precio de Gemini 4 Hydrogen. El historial de Antigravity importado se volverá a analizar y se compensará el costo.
  • Después de activar el "Historial de sesiones del Codex unificado" o migrar el historial, las sesiones de hace unos meses ocupan el primer lugar en codex resume (#3866, #9471): al reescribir archivos de sesión .jsonl normales, se conservará la hora de modificación original y se conservarán los archivos comprimidos. La hora de modificación modificada no se restaurará.
  • Para los proveedores eliminados en Hermes, el botón de eliminar en CC Switch siempre es gris (#4816, #9470): Los proveedores que ya no existen en Hermes ahora se pueden editar y eliminar; todavía están bloqueados cuando no se puede leer la configuración de Hermes.
  • Al agregar un proveedor de OpenClaw desde un ajuste preestablecido, /model enumera los modelos que vienen con el ajuste preestablecido, no el último guardado en el formulario (#9474, consulte #6729): Los modelos eliminados en el formulario no volverán a aparecer y los modelos recién agregados también se pueden seleccionar; al guardar directamente sin cambiar el ajuste preestablecido, se registrarán todos los modelos preestablecidos. La edición de un proveedor existente aún no se sincroniza, todavía se sigue el punto 6729.
  • Herramientas instaladas con mise, la página "Aplicación" muestra dos registros de instalación (uno de ellos está marcado como homebrew cuando mise se instala con Homebrew) (#9515): el shim de mise ahora cuenta como la instalación a la que realmente apunta.
  • Cuando la ventana es corta, el botón de confirmación del cuadro de diálogo "Abrir terminal" sale de la pantalla y no se puede hacer clic (#9478): el contenido del cuadro de diálogo se puede desplazar de forma independiente y el botón está fijo en la parte inferior; También puede abrir directamente el terminal presionando Enter en el cuadro de entrada "Parámetros adicionales (opcionales)".
  • Al estado del tipo de cambio en la página de uso le falta un punto y está relacionado con la siguiente descripción (#9436).

cc-switch v4.0.32

Highlights

  • Automatic update downloads, manual installation — Enable the opt-in setting to check one minute after launch, then every six hours; updates are downloaded and verified in the background. Installation still requires confirmation and restarts CC Switch, interrupting requests through its local router. Portable and Linux deb/rpm builds cannot auto-install. “Later” suppresses the prompt for that version without removing the other update entry points.
  • Proxy-aware IP diagnostics (#9449) — Check the exit IP and geolocation for a saved global proxy or an unsaved temporary proxy. Results show agreement between two IP services, and a failed selected proxy does not fall back to direct access. Note that this measures CC Switch’s own route, not necessarily Claude Code’s or Codex’s traffic.
  • Reliable Codex provider routing (#9476, #9507) — If a new provider rejects encrypted content from a previous provider after starting a 200 response, CC Switch strips that content and retries once with the same provider. Requests to Mistral AI also omit Responses-only fields, model-specific thinking parameters, and stale reasoning_content, eliminating 422 extra_forbidden errors.
  • Copilot model compatibility and account visibility (#9473, #9228) — Models such as Grok that Copilot exposes only through Responses are routed to that endpoint instead of failing on /chat/completions. Provider cards now distinguish accounts using the bound GitHub identity or a custom note.
  • Crash recovery and accurate accounting (9472, #9483, #9494) — Database, settings, configuration, MCP, prompt, pricing, and backup operations can recover after an internal crash and roll back incomplete writes, preventing a broken tray and direct-connect state. Antigravity Orchestrator usage is now charged to the model used at each step, and imported history is reparsed to backfill costs.
  • Provider management fixes — Hermes providers deleted externally become editable and removable (#9470); new OpenClaw providers now register the models actually saved in the form (#9474), though editing existing providers still does not sync them. Codex history ordering is also corrected by preserving original .jsonl modification times (#9471).

No breaking changes.

CC Switch v4.0.32

本版本新增后台自动下载更新：在「设置 → 关于」打开「自动下载更新」后，新版本会在后台下载并校验好，右下角弹出提示问你是否安装，不会未经确认就重启。「设置 → 网络」新增 IP 检测，可以查看 CC Switch 经全局代理、临时代理或当前网络访问时的出口 IP 和所在地区。

另外修复了 Codex 经路由换供应商续接旧会话后，上游先回 200 再报「无法解密」导致整轮报废；Codex 经路由或聚合接 Mistral AI 时请求报 422；CC Switch 内部某个操作崩溃一次后，托盘变空、切不了供应商，直到重启；用 mise 装的工具在「应用」页显示两条安装记录等问题。

新增

后台自动下载更新

「设置 → 关于」新增「自动下载更新」开关，默认关闭，每台设备单独设置。

  • 打开后，CC Switch 启动一分钟后检查一次，之后每六小时检查一次，有新版本就在后台下载并校验。
  • 下载好后，主界面右下角会问你是否安装。安装会重启 CC Switch，正在经本地路由的请求会中断，所以一定要你点「安装并重启」才会进行；路由开着时提示里会写明这一点。
  • 点「稍后」只是不再为这个版本弹提示，设置里的红点、「关于」页的按钮，以及托盘菜单和快捷面板里新增的「重启并更新到 vX」仍然可以安装。
  • 便携版和 Linux 的 deb / rpm 安装包不能自动安装，开关会置灰并说明原因。

IP 检测

「设置 → 网络」在全局代理下方新增 IP 检测（#9449，需求见 #9448）：选已保存的全局代理或填一个临时代理（只用于这次检测，不保存），点「检测 IP」后会显示出口 IP、两个检测服务的结果是否一致，以及国家或地区、城市、运营商等信息。没设全局代理时，按系统代理或直连检测；指定了代理时，代理连不上不会改用直连。

  • 只在点击后运行，会访问 icanhazip.com、ipify.org，并把测得的 IP 发给 ipwho.is 查询位置。
  • 测的是 CC Switch 自己经这条线路的出口，不一定等于 Claude Code、Codex 等客户端的出口。

其他

  • GitHub Copilot 反代供应商卡片显示绑定的 GitHub 账号（#9228，需求见 #9480）：以前只显示 GitHub Copilot 的官网地址，多个账号时分不清。没绑定时显示授权中心的默认账号，填了备注时备注优先。

修复

  • Codex 经路由换供应商续接旧会话时，上游先回 200、再报「Encrypted function output content could not be decrypted or decoded」，Codex 重连五次后这一轮报废（#9476）：请求里带着上一家生成的思考记录或加密内容时，CC Switch 会先等上游开始输出再交给 Codex，这时被拒就去掉这些内容后在同一家自动重试一次，会话可以继续。不带这类内容的请求照常直接流式返回。
  • Codex 经路由或聚合接 Mistral AI 时，请求报 422 extra_forbidden（#9507）：Codex 带的 Responses 专用字段、为 Mistral 上的 DeepSeek / GLM 模型自动加的思考参数，以及用过工具之后每轮都带的 reasoning_content，发往 api.mistral.ai 时都会去掉。其他上游不受影响。
  • CC Switch 内部某个操作崩溃一次后，托盘菜单变空、切不了供应商，退出时也恢复不了直连，只能重启（#9472、#9483，见 #8058）：数据库、设置、配置文件写入、MCP、提示词、价格、备份等操作现在都能在崩溃后恢复，崩溃时没写完的改动会回滚。
  • 经 GitHub Copilot 用 Claude Code / Claude Desktop 时，Grok 这类在 Copilot 里只支持 Responses 接口的模型报「not accessible via the /chat/completions endpoint」（#6954、#9473）：这类模型现在改走 Responses 接口，两种接口都支持的模型不变。
  • Antigravity 选 Orchestrator 时，用量全部记在一个虚拟模型名下、费用为 0（#9493、#9494）：现在按每一步实际使用的模型计价，并新增 Gemini 4 Hydrogen 的价格。已导入的 Antigravity 历史会重新解析一次，补上费用。
  • 开启「统一 Codex 会话历史」或迁移历史后，几个月前的会话在 codex resume 里排到了最前面（#3866、#9471）：改写普通 .jsonl 会话文件时会保留原来的修改时间，压缩过的文件本来就会保留。已经被改乱的修改时间不会恢复。
  • 在 Hermes 里删掉的供应商，CC Switch 里删除按钮一直是灰的（#4816、#9470）：Hermes 里已经没有的供应商现在可以编辑和删除；读不到 Hermes 配置时仍然锁定。
  • 从预设新增 OpenClaw 供应商时，/model 里列的是预设自带的模型，不是表单里最后保存的（#9474，见 #6729）：在表单里删掉的模型不会再出现，新加的模型也能选；不改动预设直接保存时，会登记预设的全部模型。编辑已有供应商时还不会同步，#6729 仍在跟进。
  • 用 mise 安装的工具，「应用」页显示两条安装记录（mise 用 Homebrew 安装时其中一条标成 homebrew）（#9515）：mise 的 shim 现在算作它实际指向的那个安装。
  • 窗口较矮时，「打开终端」对话框的确认按钮被挤出屏幕，点不到（#9478）：对话框内容可以单独滚动，按钮固定在底部；在「附加参数（可选）」输入框里按回车也可以直接打开终端。
  • 用量页的汇率状态缺句号，和后面的说明连在一起（#9436）。
