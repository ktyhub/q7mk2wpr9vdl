mempalace v3.3.4

  • La configuración se volvió inteligente y un modelo de idioma local hace el trabajo de forma gratuita. Mempalace init ahora usa un LLM local si tiene uno en ejecución, Ollama o LM Studio o llama.cpp, lo que prefiera. Cero llamadas en la nube, sin clave API para configurar, nada cuesta nada. Si no tiene uno en ejecución, retrocede con gracia y nunca se bloquea. Nunca estás estancado esperando algo que no está ahí.
  • El palacio ahora conecta ideas entre proyectos. Los túneles temáticos entre alas son una característica nueva donde, cuando dos proyectos hablan sobre el mismo tema, como un marco que usas en todas partes o una persona que aparece en todos los dominios, el palacio los vincula. Entonces, cuando un LLM escanea sus recuerdos en busca de un proyecto, puede seguir el hilo hacia proyectos relacionados sin que usted tenga que configurar nada.
  • La configuración y la primera ingesta ahora son un solo paso. Cuando ejecuta mempalace init, le pregunta si desea extraer el directorio inmediatamente después de la incorporación y primero le muestra una estimación del tamaño para que no le sorprenda una ingesta prolongada. Un comando, dos cosas hechas, sin una segunda pasada manual.
  • Una solución de almacenamiento hizo que los grandes palacios fueran dramáticamente más pequeños. Hubo un error por el cual los palacios activos podían aumentar a muchos gigabytes en el disco con el tiempo. Un colaborador informó que su palacio cayó de unos treinta gigabytes a menos de cuatrocientos megabytes después de que se implementó la solución, y las operaciones que antes se estaban agotando ahora responden instantáneamente. El número es el informe de campo de una persona, pero la solución subyacente existe para todos.
  • Los ganchos en segundo plano ahora reconocen correctamente las conversaciones de Claude Code. Los ganchos que guardan automáticamente sus sesiones solían tratar las transcripciones de conversaciones como si fueran código fuente, lo que causaba confusión en la indexación. Ahora están etiquetadas correctamente como conversaciones, lo que significa un almacenamiento más limpio y una mejor recuperación cuando buscas lo que dijiste.
  • Las promesas no se han movido. Cada palabra almacenada exactamente. Todo permanece en tu máquina. Nada va a ninguna parte si no le hemos dicho explícitamente que vaya. Sin telemetría. Cero. Cada versión agudiza lo que ya existe en lugar de pedirte que renuncies a algo que te importa.

mempalace v3.3.4

  • Setup got smart and a local language model does the work for free. Mempalace init now uses a local LLM if you have one running, Ollama or LM Studio or llama.cpp, whichever you prefer. Zero cloud calls, no API key to set up, nothing costs anything. If you do not have one running, it falls back gracefully and never blocks. You are never stuck waiting on something that is not there.

  • The palace now connects ideas across projects. Cross wing topic tunnels are a new feature where, when two projects talk about the same theme, like a framework you use everywhere or a person who shows up across domains, the palace links them together. So when an LLM scans your memories for one project, it can follow the thread into related projects without you having to set anything up.

  • Setup and first ingest are now one step. When you run mempalace init, it asks if you want to mine the directory right after onboarding, and shows you a size estimate first so you are not surprised by a long ingest. One command, two things done, no manual second pass.

  • A storage fix made big palaces dramatically smaller. There was a bug where active palaces could bloat into many gigabytes on disk over time. One contributor reported their palace dropped from about thirty gigabytes down to under four hundred megabytes after the fix landed, and operations that were timing out before now respond instantly. The number is one person's field report, but the underlying fix is in place for everyone.

  • Background hooks now correctly recognize Claude Code conversations. The hooks that auto save your sessions used to treat conversation transcripts as if they were source code, which caused indexing confusion. Now they are tagged correctly as conversations, which means cleaner storage and better recall when you go looking for what you said.

  • The promises have not moved. Every word stored exactly. Everything stays on your machine. Nothing goes anywhere we have not explicitly told it to go. No telemetry. Zero. Each release sharpens what is already there instead of asking you to give up something you care about.
