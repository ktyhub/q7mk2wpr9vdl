código-claude v2.1.251

¿Qué ha cambiado?

  • Se agregaron eventos de enlace PreModelSwitch y PostModelSwitch (bloquear, confirmar o anotar un cambio de modelo); Los ganchos de reanudación de SessionStart ahora reciben el estancamiento de la sesión y el costo estimado de volver a almacenar en caché
  • Se agregó transmisión en vivo de las llamadas de herramientas y los resultados de un subagente en primer plano al control remoto clients (los subagentes en segundo plano, el valor predeterminado, todavía muestran solo el estado)
  • Se agregó una barra de límite de gasto a /usage y un campo de línea de estado rate_limits.spend_limit para desarrolladores detrás de una puerta de enlace de aplicaciones Claude con límites de gasto.
  • Se agregó una línea de caché de avisos por sesión a /cost (proporción de aciertos, errores, tokens almacenados nuevamente en caché, tibio/frío) y un objeto prompt_cache coincidente para los scripts de la línea de estado.
  • Se agregaron attach, logs, stop, respawn y rm a claude --help; el mensaje --resume para una sesión en segundo plano ahora nombra exactamente el comando claude attach <id>
  • Se corrigieron las herramientas de archivos (Leer, Escribir, Editar) siguiendo un enlace simbólico intercambiado dentro del directorio de trabajo después de la verificación de permisos, que podía leer o escribir fuera de la ubicación aprobada.
  • Se corrigieron los comandos de complementos declarados en una entrada del mercado que podían apuntar fuera del directorio de complementos; dichos caminos ahora se rechazan con un error de recorrido de camino
  • Se corrigió la configuración del proyecto que permite habilitar el rastreo beta detallado o el registro del cuerpo API sin procesar, y un punto final de rastreo beta de menor alcance que evita un recopilador OTLP fijado por la configuración administrada o una aplicación host.
  • Se corrigió la herramienta de flujo de trabajo que leía (y citaba errores) un scriptPath fuera de lo que la sesión podía leer antes de que se ejecutara la verificación de permisos.
  • Se corrigió que Grep y Glob no aplicaran reglas de denegación Read(...) a archivos alcanzados a través de una ruta de búsqueda con enlace simbólico.
  • Se corrigió que las conversaciones se atascaran en errores de "los bloques de contenido de texto no deben estar vacíos" después de un turno en el que el modelo solo producía pensamientos.
  • Se corrigió el primer inicio en una instalación nueva que comenzaba en modo predeterminado en lugar del modo automático para cuentas cuyo inicio predeterminado es el modo automático.
  • Se corrigió que las solicitudes de Opus 5 fallaran con "el esfuerzo... no se admite cuando el pensamiento está deshabilitado" cuando el esfuerzo era xhigh/max y el pensamiento estaba desactivado; El esfuerzo ahora se envía como high en ese caso.
  • Se corrigió la respuesta a un mensaje que Claude Desktop entregó desde otra sesión: SendMessage a esa identificación de sesión ahora se entrega a través de Claude Desktop en lugar de fallar con "no accesible"
  • Se corrigió el retraso de TUI con muchos subagentes paralelos: los ticks de progreso por segundo ahora reemplazan a su predecesor en lugar de acumularse en la transcripción.
  • Equipos de agentes fijos: la respuesta final de un compañero de equipo no llega al líder del equipo; ahora llega en la notificación inactiva en lugar de un aviso "disponible" sin contenido
  • Se corrigió que los subagentes en segundo plano no pudieran responder a un mensaje de un hermano o agente principal no identificado (from era el tipo de agente, que no es una dirección).
  • Se corrigió la configuración administrada de disableAutoMode que llegaba a mitad de la sesión y no movía una sesión en modo automático que ya se estaba ejecutando al modo predeterminado.
  • Se corrigió el consejo de "cambiar a Opus 1M para obtener 5 veces más contexto" que aparecía incluso cuando el modelo Opus actual ya tiene una ventana de contexto de 1M.
  • Se corrigieron las sesiones de puerta de enlace de aplicaciones de Claude que trataban un perfil antrópico almacenado (por ejemplo, un inicio de sesión en la consola) como activo: incluirlo en /status y volver a intentar la puerta de enlace 401 con él, aunque las solicitudes nunca lo usan.
  • Se corrigieron las sesiones en la nube que le decían a Claude que el modelo había cambiado cuando el anfitrión solo estaba configurando el modelo inicial de la sesión.
  • Se corrigió el control remoto que informaba una falla cuando la política de una organización lo desactiva; ahora muestra un único aviso silencioso
  • Se corrigió /mcp reconnect en el control remoto que mostraba un error genérico de detalles retenidos en lugar del remedio real cuando un servidor estaba deshabilitado en otra sesión.
  • Se corrigió --input-format stream-json: las llamadas de la herramienta asistente inyectada con client enviadas sin una identificación de mensaje se fusionaron con la primera y sus resultados se perdieron, incluso al reanudar sesiones anteriores.
  • Se corrigió que las transcripciones de sesión se sobrescribieran silenciosamente cuando un cambio de directorio reubicaba una sesión en una transcripción del mismo ID existente.
  • Se corrigieron las sesiones en segundo plano y sus subagentes que no podían editar archivos dentro de un árbol de trabajo de git que crearon con git worktree add.
  • Se corrigieron sesiones en segundo plano que ocasionalmente comenzaban sin ningún conocimiento de complementos (y permanecían así) cuando otro proceso de Claude Code estaba actualizando el mercado de complementos al mismo momento.
  • Se corrigió la selección de texto en una sesión abierta en segundo plano dentro de tmux a través de SSH: ahora se copia al búfer de tmux como una sesión en primer plano en lugar de recurrir a OSC 52.
  • Se corrigieron las sesiones de SDK y de nube que se bloqueaban indefinidamente cuando se perdía el reconocimiento del protocolo de enlace de un servidor MCP SDK; la espera ahora se agota después de 70 segundos y marca solo que el servidor falló
  • Se corrigió que el corredor autohospedado dejara los procesos de la herramienta Bash de una sesión bloqueada ejecutándose después de que la sesión se detuviera por la fuerza.
  • Se corrigió /usage-credits para miembros de Team y Enterprise cuyo administrador estableció el límite de crédito de uso de la organización en $0: ahora ofrece preguntarle al administrador en lugar de decir que se alcanzó un límite.
  • Se corrigió --worktree --tmux con un número de solicitud de fusión en un origen gitlab.com intentando primero una búsqueda condenada al estilo GitHub en lugar de buscar la referencia GitLab directamente
  • Se corrigió el error de Ctrl+G con "Emacs se cerró inesperadamente" en sesiones en segundo plano para editores que abren /dev/tty, como emacs -nw y micro.
  • Se corrigió una entrada additionalDirectories que contenía un byte nulo que bloqueaba el inicio o interrumpía /add-dir y actualizaciones de configuración posteriores cuando provenía de un host, IDE o gancho SDK; ahora se omite
  • Se corrigió el acceso directo de copia del menú del servidor MCP: ahora dice cómo se copió la URL de inicio de sesión en lugar de afirmar siempre que fue exitoso
  • Se corrigió el texto en cursiva (como la línea de resumen de la sesión) que se representaba como bloques resaltados en la pantalla GNU y en sesiones tmux usando un tipo de terminal screen.
  • Se corrigió el texto de ayuda de claude mcp add --header y claude mcp add-json que nombraba los transportes incorrectos.
  • Se corrigió que claude ultrareview y /ultrareview esperaran los 30 minutos completos cuando la sesión en la nube no se iniciaba; ahora paran temprano e informan el motivo
  • Se corrigió el permiso de Bash que verifica los comandos de aprobación automática que asignan una expresión aritmética a una variable de shell entera (por ejemplo, OPTIND=1/0, RANDOM=2+2); estos ahora solicitan aprobación
  • Se corrigieron sesiones en segundo plano (←, /background, --bg) que perdían una puerta de enlace Vertex/Bedrock (ANTHROPIC_*_BASE_URL + CLAUDE_CODE_SKIP_*_AUTH) exportada en el shell, por lo que todas las solicitudes fallaban.
  • Se corrigió que claude --bg --model fable en los planes Max dejara de solicitar créditos de uso mientras la sesión interactiva en la misma cuenta todavía tenía la asignación de Fable.
  • Se corrigió la oferta única de "hacer que el modo automático sea el predeterminado" que aparecía en sesiones desatendidas (por ejemplo, paneles de agente-compañero de equipo), donde una pulsación de tecla perdida podía aceptarlo sin leer.
  • Se corrigió que el mensaje de aprobación de la configuración administrada reapareciera después de iniciar sesión nuevamente en la misma puerta de enlace de aplicaciones de Claude cuando la configuración no se modifica.
  • Se corrigieron /bug y /share deshabilitados que informaban que /feedback estaba deshabilitado; Las sugerencias, /help y los mensajes de rechazo ya no sugieren /feedback cuando una política de organización o una variable de entorno lo desactiva.
  • Se corrigió la creación de una sesión en la nube que indicaba la configuración del GitHub después de una falla transitoria en la conexión del GitHub; el mensaje ahora dice que se debe volver a intentar
  • Se mejoró el uso de la CPU durante los turnos en sesiones interactivas al eliminar las reproducciones redundantes de la interfaz de usuario.
  • Tamaño de instalación mejorado: el binario nativo es aproximadamente 5 MB más pequeño
  • Sesiones en la nube mejoradas: cuando el proxy de red de la sesión interrumpe una conexión durante un comando Bash, el resultado de la herramienta ahora nombra el host y el motivo en lugar de solo "restablecer la conexión".
  • Se mejoró /schedule para explicar que los servidores MCP configurados en Claude Code no se pueden conectar a rutinas en la nube, en lugar de un mensaje simple "No hay conectores MCP".
  • Marco mejorado de los mensajes de sus propios subagentes: se le dice a Claude que el remitente es un trabajador dentro de esta sesión, no una sesión de Claude no relacionada.
  • Se mejoró el marcador de posición para que diga "Mensaje @nombre..." mientras se visualiza un subagente en segundo plano o una transcripción bifurcada abierta desde el panel de subagente o /tasks.
  • Mejora de la desinfección de los nombres de los servidores MCP en mensajes de error, menús y resultados de comandos.
  • Inicio de sesión de Amazon Bedrock mejorado en CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST (por ejemplo, Claude Desktop): una sesión con un ID de modelo Bedrock o ARN ya no espera el descubrimiento del perfil de inferencia
  • Se mejoró el cuadro de diálogo de aprobación de configuraciones administradas para enumerar solo las configuraciones que cambiaron desde la última vez que las aprobó.
  • Reintento mejorado cuando la llamada a la herramienta del modelo tiene un formato incorrecto: la salida rota ahora se elimina del contexto de reintento, incluso en Bedrock, Vertex y Foundry.
  • Se modificó /radio para que esté disponible en Bedrock, Vertex AI, Foundry y Claude Platform en AWS, y cuando la telemetría esté deshabilitada.
  • Se modificó Claude en Chrome para que las acciones del navegador siempre pasen por las verificaciones de permisos de Claude Code, incluso en sesiones con telemetría deshabilitada, que anteriormente usaban las propias indicaciones de la extensión de Chrome.
  • Se modificó CLAUDE_CODE_SUBAGENT_MODEL para establecer el modelo de subagente predeterminado en lugar de anular todo: el model: de una definición de agente y un modelo explícito por generación ahora tienen prioridad sobre él.
  • Se cambió el avance de confirmación predeterminado a Co-Authored-By: Claude Code cuando el modelo activo no es un modelo Claude reconocido (por ejemplo, modelos de terceros detrás de un ANTHROPIC_BASE_URL personalizado).
  • Se cambió el modelo predeterminado para las suscripciones Enterprise basadas en asientos a Opus 5, coincidiendo con otros planes premium
  • Se modificó /effort para guardar su nivel de esfuerzo predeterminado por modelo, de modo que cada modelo mantenga su propia configuración cuando cambie
  • Se cambiaron los análisis para que ya no se desactiven antes de iniciar sesión únicamente porque la configuración administrada fuerza el inicio de sesión en la puerta de enlace (o no se puede leer); permanecen apagados una vez que inician sesión en la puerta de enlace o a través de DISABLE_TELEMETRY
  • Se cambió la insignia PR del pie de página en Bedrock, Vertex y Foundry, y cuando la telemetría está desactivada, para llamar al GitHub API directamente (a través de gh auth token, GH_TOKEN o GITHUB_TOKEN) en lugar de gh pr view.
  • Se modificó la forma en que se crean y leen los archivos de salida de los comandos Bash cuando los comandos se ejecutan en el entorno sandbox, por lo que un comando en el entorno sandbox no puede redirigirlos ni reemplazarlos.
  • Se cambiaron las sugerencias de instalación de complementos/LSP y la oferta predeterminada del modo automático para esperar hasta que hayas enviado o borrado lo que estás escribiendo, de modo que el Enter que envía tu mensaje no pueda responderlas.
  • Se cambiaron las configuraciones administradas por el servidor que finalizan el TLS del sandbox, enrutan el tráfico del sandbox a través de su propio proxy, inyectan credenciales o debilitan el aislamiento del sandbox para requerir aprobación antes de que se apliquen.
  • Se modificó ANTHROPIC_CUSTOM_HEADERS de la configuración administrada o del proyecto para requerir aprobación cuando establece una credencial, organización/inquilino, enrutamiento o encabezado de comportamiento API (por ejemplo, Authorization, Host).
  • Se modificó el nivel de proyecto .claude/settings.json env para que ya no configure CLAUDE_CONFIG_DIR, CLAUDE_CODE_TMPDIR o TMPDIR/TMP/TEMP; configúrelos en su shell, usuario o configuración administrada en su lugar
  • Se eliminó el resaltado de sintaxis para seis idiomas de uso poco frecuente (1c, gml, isbl, mathematica, maxima, sqf); el binario es 2.5 MB más pequeño
  • [VSCode] Se corrigió el botón "Bedrock, Foundry o Vertex" de la pantalla de inicio de sesión que abría los documentos en la parte superior de la página en lugar de la sección de configuración del proveedor externo.
  • [VSCode] Se cambió el banner de Control remoto a una pastilla de pie de página (que se muestra mientras el Control remoto está activado o ha fallado) que abre la sesión en claude.ai/code; enciéndelo o apágalo con /remote-control

claude-code v2.1.251

What's changed

  • Added PreModelSwitch and PostModelSwitch hook events (block, confirm, or annotate a model switch); SessionStart resume hooks now receive session staleness and the estimated re-cache cost
  • Added live streaming of a foreground subagent's tool calls and results to Remote Control clients (background subagents, the default, still show status only)
  • Added a Spend limit bar to /usage and a rate_limits.spend_limit status line field for developers behind a Claude apps gateway with spend limits
  • Added a per-session prompt-cache line to /cost (hit ratio, misses, tokens re-cached, warm/cold) and a matching prompt_cache object for status line scripts
  • Added attach, logs, stop, respawn, and rm to claude --help; the --resume message for a running background session now names the exact claude attach <id> command
  • Fixed file tools (Read, Write, Edit) following a symlink swapped inside the working directory after the permission check, which could read or write outside the approved location
  • Fixed plugin commands declared in a marketplace entry being able to point outside the plugin directory; such paths are now rejected with a path-traversal error
  • Fixed project settings being able to enable detailed beta tracing or raw API body logging, and a lower-scope beta tracing endpoint bypassing an OTLP collector pinned by managed settings or a host app
  • Fixed the Workflow tool reading (and quoting in errors) a scriptPath outside what the session may read before the permission check ran
  • Fixed Grep and Glob not applying Read(...) deny rules to files reached through a symlinked search path
  • Fixed conversations getting stuck on "text content blocks must be non-empty" errors after a turn where the model produced only thinking
  • Fixed the first launch on a fresh install starting in default mode instead of auto mode for accounts whose startup default is auto mode
  • Fixed Opus 5 requests failing with "effort … is not supported when thinking is disabled" when effort was xhigh/max and thinking was turned off; effort is now sent as high in that case
  • Fixed replying to a message Claude Desktop delivered from another session: SendMessage to that session id now delivers through Claude Desktop instead of failing with "not reachable"
  • Fixed TUI lag with many parallel subagents: per-second progress ticks now replace their predecessor instead of piling up in the transcript
  • Fixed agent teams: a teammate's final answer not reaching the team lead — it now arrives in the idle notification instead of a content-free "available" notice
  • Fixed background subagents being unable to reply to a message from an unnamed sibling or parent agent (from was the agent type, which is not an address)
  • Fixed managed-settings disableAutoMode arriving mid-session not moving an already-running auto-mode session back to default mode
  • Fixed a "switch to Opus 1M for 5x more context" tip that appeared even when the current Opus model already has a 1M context window
  • Fixed Claude apps gateway sessions treating a stored Anthropic profile (e.g. a Console sign-in) as active: listing it in /status and retrying gateway 401s with it, though requests never use it
  • Fixed cloud sessions telling Claude the model had changed when the host was only setting the session's initial model
  • Fixed Remote Control reporting a failure when an organization's policy disables it; it now shows a single quiet notice instead
  • Fixed /mcp reconnect on Remote Control showing a generic withheld-detail error instead of the real remedy when a server was disabled in another session
  • Fixed --input-format stream-json: client-injected assistant tool calls sent without a message id were merged into the first one and their results lost, including when resuming older sessions
  • Fixed session transcripts being silently overwritten when a directory change relocated a session onto an existing same-ID transcript
  • Fixed background sessions and their subagents being unable to edit files inside a git worktree they created with git worktree add
  • Fixed background sessions occasionally starting without any plugin skills (and staying that way) when another Claude Code process was refreshing the plugin marketplace at the same moment
  • Fixed selecting text in an opened background session inside tmux over SSH: it now copies to the tmux buffer like a foreground session instead of falling back to OSC 52
  • Fixed SDK and cloud sessions hanging indefinitely when an SDK MCP server's handshake acknowledgment was lost; the wait now times out after 70 seconds and marks only that server failed
  • Fixed self-hosted runner leaving a stuck session's Bash tool processes running after the session was force-stopped
  • Fixed /usage-credits for Team and Enterprise members whose admin set the org's usage-credit limit to $0: it now offers to ask the admin instead of saying a cap was reached
  • Fixed --worktree --tmux with a merge-request number on a gitlab.com origin trying a doomed GitHub-style fetch first instead of fetching the GitLab ref directly
  • Fixed Ctrl+G failing with "Emacs quit unexpectedly" in background sessions for editors that open /dev/tty, such as emacs -nw and micro
  • Fixed an additionalDirectories entry containing a null byte crashing startup, or breaking /add-dir and later settings updates when it came from an SDK host, IDE, or hook; it is now skipped
  • Fixed the MCP server menu's copy shortcut: it now says how the sign-in URL was copied instead of always claiming success
  • Fixed italic text (such as the session recap line) rendering as highlighted blocks in GNU screen and in tmux sessions using a screen terminal type
  • Fixed claude mcp add --header and claude mcp add-json help text naming the wrong transports
  • Fixed claude ultrareview and /ultrareview waiting the full 30 minutes when the cloud session fails to start; they now stop early and report the reason
  • Fixed Bash permission checks auto-approving commands that assign an arithmetic expression to an integer shell variable (e.g. OPTIND=1/0, RANDOM=2+2); these now prompt for approval
  • Fixed backgrounded sessions (←, /background, --bg) losing a Vertex/Bedrock gateway (ANTHROPIC_*_BASE_URL + CLAUDE_CODE_SKIP_*_AUTH) exported in the shell, so every request failed
  • Fixed claude --bg --model fable on Max plans stopping to ask for usage credits while the interactive session on the same account still had Fable allowance
  • Fixed the one-time "make auto mode your default" offer appearing in unattended sessions (e.g. agent-team teammate panes), where a stray keypress could accept it unread
  • Fixed the managed-settings approval prompt re-appearing after signing in again to the same Claude apps gateway when the settings are unchanged
  • Fixed disabled /bug and /share reporting that /feedback was disabled; tips, /help, and refusal messages no longer suggest /feedback when an org policy or env var turns it off
  • Fixed cloud session creation advising GitHub setup after a transient GitHub connection failure — the message now says to retry instead
  • Improved CPU usage during turns in interactive sessions by cutting redundant UI re-renders
  • Improved install size: the native binary is about 5 MB smaller
  • Improved cloud sessions: when the session's network proxy drops a connection during a Bash command, the tool result now names the host and reason instead of only "connection reset"
  • Improved /schedule to explain that MCP servers configured in Claude Code can't be attached to cloud routines, instead of a bare "No MCP connectors" message
  • Improved framing of messages from your own subagents: Claude is told the sender is a worker inside this session, not an unrelated Claude session
  • Improved the prompt placeholder to read "Message @name…" while viewing a background subagent or fork transcript opened from the subagent panel or /tasks
  • Improved sanitization of MCP server names in error messages, menus, and command results
  • Improved Amazon Bedrock session start under CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST (e.g. Claude Desktop): a session given a Bedrock model ID or ARN no longer waits for inference-profile discovery
  • Improved the managed settings approval dialog to list only the settings that changed since you last approved them
  • Improved retry when the model's tool call is malformed: the broken output is now dropped from the retry context, including on Bedrock, Vertex, and Foundry
  • Changed /radio to be available on Bedrock, Vertex AI, Foundry, and Claude Platform on AWS, and when telemetry is disabled
  • Changed Claude in Chrome so browser actions always go through Claude Code's permission checks, including in sessions with telemetry disabled, which previously used the Chrome extension's own prompts
  • Changed CLAUDE_CODE_SUBAGENT_MODEL to set the default subagent model rather than override everything: an agent definition's model: and an explicit per-spawn model now take precedence over it
  • Changed the default commit trailer to Co-Authored-By: Claude Code when the active model isn't a recognized Claude model (e.g. third-party models behind a custom ANTHROPIC_BASE_URL)
  • Changed the default model for seat-based Enterprise subscriptions to Opus 5, matching other premium plans
  • Changed /effort to save your default effort level per model, so each model keeps its own setting when you switch
  • Changed analytics to no longer turn off before sign-in solely because managed settings force gateway login (or cannot be read); they stay off once signed in to the gateway or via DISABLE_TELEMETRY
  • Changed the footer PR badge on Bedrock, Vertex, and Foundry, and when telemetry is off, to call the GitHub API directly (via gh auth token, GH_TOKEN, or GITHUB_TOKEN) instead of gh pr view
  • Changed how Bash command output files are created and read back when commands run in the sandbox, so a sandboxed command cannot redirect or replace them
  • Changed plugin/LSP install suggestions and the auto-mode default offer to wait until you've sent or cleared what you're typing, so the Enter that sends your prompt can't answer them
  • Changed server-managed settings that terminate sandbox TLS, route sandbox traffic through your own proxy, inject credentials, or weaken sandbox isolation to require approval before they apply
  • Changed ANTHROPIC_CUSTOM_HEADERS from managed or project settings to require approval when it sets a credential, org/tenant, routing, or API-behavior header (e.g. Authorization, Host)
  • Changed project-level .claude/settings.json env to no longer set CLAUDE_CONFIG_DIR, CLAUDE_CODE_TMPDIR, or TMPDIR/TMP/TEMP; set them in your shell, user, or managed settings instead
  • Removed syntax highlighting for six rarely used languages (1c, gml, isbl, mathematica, maxima, sqf); the binary is 2.5 MB smaller
  • [VSCode] Fixed the sign-in screen's "Bedrock, Foundry, or Vertex" button opening the docs at the top of the page instead of the third-party provider setup section
  • [VSCode] Changed the Remote Control banner to a footer pill (shown while Remote Control is on or has failed) that opens the session on claude.ai/code; turn it on or off with /remote-control
