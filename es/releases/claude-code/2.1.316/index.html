código-claude v2.1.316

¿Qué ha cambiado?

  • Se agregó CLAUDE_CODE_DISABLE_ULTRATHINK, que desactiva la palabra clave ultrathink.
  • Se agregaron presupuestos grupales agrupados al portal de aplicaciones de Claude: un presupuesto mensual que los miembros de un grupo comparten, además del límite de cada miembro, establecido con pooled_budget en el administrador de límites de gasto API.
  • Se agregó CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP para mantener los certificados cruzados del sistema que se certifican entre sí en un bucle, para servidores cuya CA privada necesita uno.
  • Se agregó CLAUDE_CODE_SUBAGENT_EFFORT para establecer el nivel de esfuerzo en el que se ejecutan los subagentes cuando nada más nombra uno, en lugar de heredar el de la sesión.
  • Se agregó managed.policy_mode: layered a la puerta de enlace de aplicaciones de Claude: se aplican todas las políticas que coinciden con un desarrollador, cada una fusionada con las que se enumeran debajo, no solo la primera.
  • Se agregó guardrail.input_tagging en la puerta de enlace de aplicaciones de Claude Bedrock upstreams, que incluye mensajes en las etiquetas de entrada que necesita el filtro de ataques rápidos de una barandilla de Amazon Bedrock; all_messages_and_system también etiqueta el indicador del sistema.
  • Modo rápido obsoleto para Opus 4.8 a partir del 30 de octubre de 2026; se eliminará el 30 de noviembre de 2026. Después de la eliminación, las solicitudes de modo rápido en Opus 4.8 devuelven un error y no recurren al Opus 4.8 estándar. Migre a Opus 5.5 para mantener la aceleración
  • Se corrigieron los comandos de shell que se dejaban ejecutando en macOS y Linux cuando Claude Code se cierra solo, por ejemplo, cuando se rechazan las credenciales o se archiva una sesión en la nube.
  • Se corrigieron los alias de bash con saltos de línea en su valor (excepto en Git Bash) y funciones cuyos nombres comienzan con un guión, que se confunden o se pierden en el shell de la herramienta Bash.
  • Se corrigieron los scripts de bash que comenzaban desde la herramienta Bash y se detenían después de su primer comando cuando se exportaba SHELLOPTS.
  • Se corrigieron los ganchos de PowerShell que no se bloquean en el código de salida 2 cuando el comando comienza con un tipo de conversión, param, using o un atributo.
  • Se corrigieron algunas solicitudes de red que se bloqueaban cuando una respuesta comprimida se cortaba o se corrompía.
  • Se corrigió que sonnet, opus y haiku en Vertex AI y Amazon Bedrock mostraran un error a mitad de sesión en lugar de cambiar a un modelo anterior cuando el más nuevo aún no está disponible para la cuenta o región.
  • Se corrigió que la puerta de enlace de aplicaciones de Claude no verificara todos los modelos y nombres de solicitud con availableModels, deniedModels y models; una solicitud que nombra un modelo bloqueado ahora obtiene un 400 al nombrar el campo
  • Se corrigió que claude auth login se negara a ejecutarse cuando las configuraciones administradas requieren una puerta de enlace de aplicaciones Claude; en una terminal ahora muestra el inicio de sesión de la puerta de enlace
  • Se corrigieron las sesiones --restricted que cargaban archivos desde fuera de los directorios de trabajo cuando una regla de permiso de lectura los cubría.
  • Se corrigieron mensajes que contenían caracteres invisibles que necesitaban un segundo Enter para enviarse; Las indicaciones simples ahora se envían limpias en la primera entrada y los comandos aún esperan revisión.
  • Se corrigieron los subagentes que heredaban el modelo de un subagente principal y se movían al modelo principal cuando un trabajo en segundo plano o un mensaje los despertaba.
  • Se corrigió una lista autoMode.allow administrada sin que "$defaults" recuperara las excepciones integradas del --settings de una aplicación host, una primera regla agregada en /permissions o /auto-mode-setup.
  • Se corrigieron las sesiones en la nube y las tareas programadas en la nube que no se marcaban como fallidas cuando el modo automático detenía un turno porque el servidor no arrojaba ningún veredicto de seguridad.
  • Se corrigió la salida de texto de claude -p que a veces no decía por qué el modo automático detenía un giro cuando un agente en segundo plano aún se estaba ejecutando.
  • Se corrigió que CLAUDE_CODE_AUTO_MODE_SERVER=1 se ignorara en sesiones iniciadas por una aplicación host (como Claude Desktop) detrás de un proxy o puerta de enlace LLM con las versiones beta experimentales desactivadas.
  • Se corrigieron los scripts del complemento MCP headersHelper que recibían un CLAUDE_PLUGIN_ROOT y una URL del servidor dañados cuando una variable de entorno con nombre de credencial se configuraba en un valor de cambio como 1.
  • Se corrigió la solicitud de control SDK register_repo_root que no cargaba el CLAUDE.md de un directorio fuera del directorio de trabajo (con CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1)
  • Se corrigió la herramienta Artifact que mostraba ? para las reglas de acceso a la base de datos de artefactos en el nivel self, y no citaba esas reglas cuando rechazaba una republicación que las eliminaría.
  • Se corrigió que /model <id> no avisara cuando esta versión no reconoce el modelo y la autocompactación asumirá una ventana de contexto de 200K.
  • Se corrigió la sugerencia de "mantener espacio para hablar" que usaba sus tres presentaciones en una sesión y mostraba una tecla vacía cuando pulsar para hablar no está vinculado.
  • Se corrigió que Grep y Glob nunca regresaran cuando el proceso de búsqueda finaliza en el tiempo de espera pero no sale, como se ve en Windows.
  • Se corrigió un caso raro en el que reanudar una conversación no restablecía su plan, cuando /clear o /resume se ejecutaban mientras parte de esa conversación aún se estaba guardando.
  • Se corrigió la configuración de primera ejecución que eliminaba palabras de las notas de seguridad y la explicación de la configuración del terminal en terminales angostos.
  • Se corrigió que la tarjeta de encuesta Enterprise tomara un 1 o 0 después de una breve pausa; una respuesta escrita ahora necesita Enter
  • Corredor autohospedado: se corrigió un mensaje enviado mientras Claude estaba trabajando y que se respondía después de una parada, una vez que se había reemplazado el proceso de la sesión.
  • Ejecutor autohospedado: se corrigió que el interruptor de encendido/apagado de un servidor MCP a veces se perdiera cuando una sesión se movía a una nueva máquina.
  • Windows: Se corrigió que la herramienta Bash perdiera sus alias y funciones en Git Bash cuando el archivo rc establece errexit y pipefail y solo se definen alias winpty, o ninguno.
  • /code-review mejorado se inició desde la pestaña Código en Claude Desktop o en la web: las sesiones en la nube y claude remote-control ahora muestran la tarjeta de hallazgos, no una lista de texto sin formato.
  • /diff mejorado en repositorios grandes: cada actualización generalmente ejecuta un comando git menos para el repositorio completo, y las actualizaciones se espacian cuando git es lento
  • Se mejoraron los mensajes que se muestran cuando /ultrareview, una sesión en la nube o un agente en la nube no encuentra ningún control remoto GitHub: ahora dicen que se cree un repositorio en https://github.com/new, y /ultrareview ya no sugiere un comando gh que gh rechaza.
  • Errores de certificados SSL mejorados para nombrar las causas probables, entre ellas un servidor que omite un certificado intermedio y la solución para cada uno.
  • Se cambió el modo automático para que una lista autoMode.allow sin "$defaults" ya no elimine la regla integrada en las indicaciones de tareas programadas.
  • Se cambiaron las configuraciones administradas por el servidor para los inicios de sesión Team y Enterprise: las configuraciones obtenidas del API de Anthropic ahora se aplican sin un mensaje de aprobación, y se rechaza una copia almacenada que no se verifica
  • [VSCode] Se agregó inicio de sesión en una puerta de enlace de aplicaciones de Claude desde el panel de chat, sin necesidad de terminal
  • [VSCode] Se cambió ultrathink para que ejecute su turno con el esfuerzo de xhigh y se muestre en un arcoíris en el cuadro de chat, como en la terminal.
  • [VSCode] Se corrigió el control deslizante Esfuerzo, el interruptor Ultracode y el nombre del modelo que faltaban cuando la configuración del modelo tiene la etiqueta [1m], como opus[1m].
  • [VSCode] Se corrigió que el historial de preguntas secundarias guardadas de /btw se eliminara demasiado pronto mientras un archivo de configuración tenía errores
  • [VSCode] Se corrigió una conversación que regresaba al modo automático después de una recarga o reinicio cuando su plan se aprobó con "Sí, y aprobar ediciones manualmente".
  • [Sesiones en la nube] Se agregó una tarjeta de formulario a las sesiones en la nube, para que pueda completar o decline un formulario que solicita un servidor MCP en lugar de cancelar la solicitud sin que usted la vea.
  • [Sesiones en la nube] Se agregó una línea "Ponerse al día..." que muestra mientras una sesión en la nube o de Control remoto a la que vuelves a cambiar todavía actualiza sus mensajes.
  • [Sesiones en la nube] Se cambiaron los secretos de red para que los miembros empresariales puedan agregarlos y eliminarlos en sus propios entornos de nube, en lugar de solo verlos.
  • [Sesiones en la nube] Se mejoró el panel de cambios para las sesiones en la nube: la nota sobre lo que la lista omite ahora es una insignia al lado del nombre de la rama, no una fila encima de la diferencia.
  • [Sesiones en la nube] Se corrigió la búsqueda de archivos en el panel Archivos de una sesión en la nube que muestra las carpetas como rutas ../.. después de que Claude cambió de directorio; Los resultados ahora muestran su ruta desde la raíz del proyecto.
  • [Etiqueta de Claude] Se corrigió que Claude se negara a editar o agregar a un lienzo que creó en un canal de Slack, desde ese canal, una vez que el lienzo también se compartió con otro canal o un DM.
  • [Etiqueta de Claude] Se corrigieron las respuestas sin etiqueta que quedaban sin respuesta en un hilo de Slack Connect cuando ambas organizaciones instalaron Claude y Slack entregó la respuesta a la aplicación de la otra organización.
  • [Claude Tag] Se corrigió que la lista de verificación de estado en vivo de una tarea programada en la nube en Slack permaneciera a medio hacer; una ejecución ahora puede editar los mensajes de nivel superior que publicó durante esa ejecución
  • [Claude Tag] Se cambió el cambio automático de Responder de un canal de Slack a la opción "Cómo participa Claude" en la página de configuración del canal y en la configuración de administración de Claude Tag.
  • [Revisión de código] Se agregó una tarjeta de hallazgos por gravedad a la página de análisis de Revisión de código, que muestra los hallazgos totales del período, un gráfico diario ordenado por gravedad y el recuento de cada gravedad.

claude-code v2.1.316

What's changed

  • Added CLAUDE_CODE_DISABLE_ULTRATHINK, which turns the ultrathink keyword off
  • Added pooled group budgets to the Claude apps gateway: one monthly budget that a group's members share, on top of each member's own limit, set with pooled_budget on the spend limits admin API
  • Added CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP to keep system cross-certificates that certify each other in a loop, for servers whose private CA needs one
  • Added CLAUDE_CODE_SUBAGENT_EFFORT to set the effort level subagents run at when nothing else names one, instead of inheriting the session's
  • Added managed.policy_mode: layered to the Claude apps gateway: every policy that matches a developer applies, each merged over the ones listed below it, not only the first
  • Added guardrail.input_tagging on Claude apps gateway Bedrock upstreams, which wraps prompts in the input tags that an Amazon Bedrock guardrail's prompt attacks filter needs; all_messages_and_system also tags the system prompt
  • Deprecated fast mode for Opus 4.8 as of October 30, 2026; it will be removed on November 30, 2026. After removal, fast mode requests on Opus 4.8 return an error and do not fall back to standard Opus 4.8. Migrate to Opus 5.5 to keep the speedup
  • Fixed shell commands being left running on macOS and Linux when Claude Code exits by itself, for example when credentials are refused or a cloud session is archived
  • Fixed bash aliases with line breaks in their value (except in Git Bash), and functions whose names start with a dash, being garbled or lost in the Bash tool's shell
  • Fixed bash scripts started from the Bash tool stopping after their first command when SHELLOPTS is exported
  • Fixed PowerShell hooks not blocking on exit code 2 when the command begins with a type cast, param, using or an attribute
  • Fixed some network requests hanging when a compressed response was cut off or corrupted
  • Fixed sonnet, opus and haiku on Vertex AI and Amazon Bedrock showing an error mid-session instead of switching to an older model when the newest is not yet available to the account or region
  • Fixed the Claude apps gateway not checking every model a request names against availableModels, deniedModels and models; a request that names a blocked model now gets a 400 naming the field
  • Fixed claude auth login refusing to run where managed settings require a Claude apps gateway; in a terminal it now shows the gateway sign-in
  • Fixed --restricted sessions uploading files from outside the working directories when a Read allow rule covered them
  • Fixed prompts containing invisible characters needing a second Enter to send; plain prompts now send cleaned on the first Enter, and commands still wait for review
  • Fixed sub-agents that inherited a parent sub-agent's model moving to the main model when a background job or message woke them
  • Fixed a managed autoMode.allow list without "$defaults" getting the built-in exceptions back from a host app's --settings, a first rule added in /permissions, or /auto-mode-setup
  • Fixed cloud sessions and cloud scheduled tasks not being marked as failed when auto mode stopped a turn because the server returned no safety verdict
  • Fixed claude -p text output sometimes not saying why auto mode stopped a turn when a background agent was still running
  • Fixed CLAUDE_CODE_AUTO_MODE_SERVER=1 being ignored in sessions started by a host application (such as Claude Desktop) behind a proxy or LLM gateway with experimental betas turned off
  • Fixed plugin MCP headersHelper scripts receiving a corrupted CLAUDE_PLUGIN_ROOT and server URL when a credential-named environment variable was set to a switch value such as 1
  • Fixed the SDK register_repo_root control request not loading the CLAUDE.md of a directory outside the working directory (with CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1)
  • Fixed the Artifact tool showing ? for artifact database access rules at the self level, and not quoting those rules back when it refuses a republish that would drop them
  • Fixed /model <id> not warning when the model isn't recognized by this version and auto-compact will assume a 200K context window
  • Fixed the "hold space to speak" hint using up its three showings in one session, and showing an empty key when push-to-talk is unbound
  • Fixed Grep and Glob never returning when the search process is killed at the timeout but does not exit, seen on Windows
  • Fixed a rare case where resuming a conversation did not restore its plan, when /clear or /resume had been run while part of that conversation was still being saved
  • Fixed first-run setup dropping words from the security notes and the terminal-setup explanation in narrow terminals
  • Fixed the Enterprise survey card taking a typed 1 or 0 after a short pause; a typed answer now needs Enter
  • Self-hosted runner: Fixed a message sent while Claude was working being answered after a Stop, once the session's process had been replaced
  • Self-hosted runner: Fixed an MCP server's on/off switch sometimes being lost when a session moved to a new machine
  • Windows: Fixed the Bash tool losing your aliases and functions in Git Bash when the rc file sets errexit and pipefail and only winpty aliases, or none, are defined
  • Improved /code-review started from the Code tab in Claude Desktop or on the web: cloud and claude remote-control sessions now show the findings card, not a plain-text list
  • Improved /diff on large repositories: each refresh usually runs one fewer full-repository git command, and refreshes are spaced out when git is slow
  • Improved the messages shown when /ultrareview, a cloud session or a cloud agent finds no GitHub remote: they now say to create a repository at https://github.com/new, and /ultrareview no longer suggests a gh command that gh rejects
  • Improved SSL certificate errors to name the likely causes, among them a server that leaves out an intermediate certificate, and the fix for each
  • Changed auto mode so that an autoMode.allow list without "$defaults" no longer removes the built-in rule on scheduled-task prompts
  • Changed server-managed settings for Team and Enterprise logins: settings fetched from Anthropic's API now apply without an approval prompt, and a stored copy that doesn't verify is refused
  • [VSCode] Added sign-in to a Claude apps gateway from the chat panel, with no terminal needed
  • [VSCode] Changed ultrathink to run its turn at xhigh effort and show in a rainbow in the chat box, as in the terminal
  • [VSCode] Fixed the missing Effort slider, Ultracode switch and model name when the model setting has the [1m] tag, such as opus[1m]
  • [VSCode] Fixed saved /btw side-question history being deleted too early while a settings file has errors
  • [VSCode] Fixed a conversation coming back in Auto mode after a reload or restart when its plan was approved with "Yes, and manually approve edits"
  • [Cloud sessions] Added a form card to cloud sessions, so you can fill in or decline a form an MCP server asks for instead of the request being canceled without you seeing it
  • [Cloud sessions] Added a "Catching up…" line that shows while a cloud or Remote Control session you switch back to is still bringing its messages up to date
  • [Cloud sessions] Changed network secrets so Enterprise members can add and delete them on their own cloud environments, instead of only viewing them
  • [Cloud sessions] Improved the Changes pane for cloud sessions: the note about what the list leaves out is now a badge beside the branch name, not a row above the diff
  • [Cloud sessions] Fixed file search in a cloud session's Files pane showing folders as ../.. paths after Claude changed directory; results now show their path from the project's root
  • [Claude Tag] Fixed Claude refusing to edit or append to a canvas it made in a Slack channel, from that channel, once the canvas was also shared to another channel or a DM
  • [Claude Tag] Fixed untagged replies going unanswered in a Slack Connect thread when both organizations have installed Claude and Slack delivered the reply to the other organization's app
  • [Claude Tag] Fixed a cloud scheduled task's live status checklist in Slack staying half-done; a run can now edit the top-level messages it posted during that run
  • [Claude Tag] Changed a Slack channel's Respond automatically switch to a "How Claude participates" choice on the channel's Configure page and in Claude Tag admin settings
  • [Code Review] Added a findings-by-severity card to the Code Review analytics page, showing the period's total findings, a daily chart stacked by severity, and each severity's count
