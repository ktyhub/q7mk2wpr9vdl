código-claude v2.1.259

¿Qué ha cambiado?

  • Se agregó la configuración administrada managedMcpServers: las organizaciones pueden proporcionar servidores HTTP/SSE MCP a cada usuario (la misma forma de entrada que .mcp.json); las entradas que nombran un comando para ejecutar se omiten
  • Se agregó --permission-prompts none para hosts sin cabeza desatendidos: cualquier cosa que solicite se niega automáticamente mientras el modo de permiso activo (incluido el modo automático) sigue decidiendo
  • Se agregó reconocimiento de glab mr create/merge/close/reopen/note/update para que las solicitudes de fusión de GitLab se muestren como MR !N en el resumen de la herramienta contraído y actualicen la insignia MR del pie de página.
  • Se agregó --json a claude plugin validate para un informe de validación legible por máquina.
  • Se corrigieron sesiones simultáneas que revertían silenciosamente los cambios ~/.claude.json de cada uno: el espacio de trabajo trust ya no se reinicia y el estado de MCP/proyecto ya no se pierde cuando se ejecutan muchas sesiones a la vez.
  • Se corrigió una conversación cuyo pensamiento era rechazado una vez y se rechazaba nuevamente en cada turno posterior.
  • Se corrigieron las reglas de denegación de Bash Read() que no cubrían archivos proporcionados como valores de opción (--ignore-revs-file=.env, -f.env, @file), operandos de archivos git diff/git grep o compuestos cd DIR && cat FILE; grep -r/cp -r sobre un directorio que contiene un archivo denegado ahora pregunta
  • Se corrigió que el caché del mensaje se invalidara cuando el token de OAuth se actualizaba en sesiones con la telemetría deshabilitada.
  • Se corrigió el modo de pantalla completa que mostraba una conversación en blanco después de un turno largo con cientos de llamadas de herramientas.
  • Se corrigió el modo automático que ejecutaba un turno en un modelo que no era compatible cuando el frontmatter de un comando o habilidad model: nombraba uno; el turno ahora mantiene el modelo de sesión
  • Se corrigió que CLAUDE_CODE_MAX_CONTEXT_TOKENS se ignorara para los ID de modelo estilo Vertex (sufijo @YYYYMMDD) de versiones de modelo que Claude Code no reconoce.
  • Se corrigió la vista previa de salida en vivo de un comando de shell en ejecución que ocultaba sus líneas más nuevas cuando se ajustaba una línea anterior.
  • Se corrigió una verificación de conexión en segundo plano de GitHub que se ejecutaba en cada inicio para los usuarios de claude.ai; el resultado ahora se recuerda en todos los lanzamientos
  • Se corrigió el fallo de --resume (y --continue abriendo una conversación vacía) cuando una sesión guardada contiene una entrada adjunta sin carga útil.
  • Se corrigió el frontmatter model: en comandos personalizados y habilidades que se ignoraban en sesiones interactivas.
  • Se corrigió que la publicación de artefactos fallara una vez con un error de "parámetro inesperado note" en conversaciones continuadas desde una versión anterior.
  • Se corrigió que forceRemoteSettingsRefresh administrado se ignorara al inicio cuando ya se había ejecutado un asistente de políticas configurado por MDM o el archivo de configuración administrado.
  • Se corrigió el aislamiento del árbol de trabajo que rechazaba los árboles de trabajo creados con ganchos en máquinas donde git rev-parse falla con un mensaje que no es "no es un repositorio de git".
  • Se corrigieron métricas y eventos de OpenTelemetry de sesiones en la nube a los que les faltaban los atributos user.email, organization.id y user.account_uuid.
  • Se corrigieron los servidores MCP que se desconectaban mientras sus herramientas se enumeraban al inicio y se mostraban como conectados sin herramientas en lugar de informar el error.
  • Se corrigió el cuadro de diálogo de permiso de edición de archivos que a veces mostraba una línea modificada cortada sin indicación
  • Se corrigió la detección de repositorio que eliminaba una identidad de repositorio conocida después de una falla transitoria de la sonda git
  • Se corrigió que las configuraciones administradas dejaran de aplicarse silenciosamente cuando el archivo de configuración administrada, un menú desplegable, la lista MDM o el valor HKLM no se pueden analizar: Claude Code ahora se niega a iniciarse y nombra la fuente
  • Se corrigió que Stop no detuviera realmente los agentes en segundo plano y los flujos de trabajo en sesiones de control remoto: las tareas canceladas ahora permanecen visibles y se pueden volver a detener hasta que sus procesos finalicen.
  • Se corrigió la reanudación de una ejecución de flujo de trabajo mientras su ejecución detenida anterior aún estaba saliendo, lo que podía ejecutar copias duplicadas de sus agentes.
  • Se corrigieron las URL de repositorios del mercado en github.com con una barra diagonal o ?/# colgando, lo que producía una URL de clonación de .git inutilizable.
  • Se corrigió el bloqueo de los ganchos de parada que causaban que el turno después de un bloqueo perdiera el razonamiento del modelo de ese turno y, en algunos modelos, perdiera el caché de indicaciones.
  • Se corrigieron sesiones remotas (claude.ai) que tardaban 60 segundos en iniciar un turno después de que la página de un servidor MCP alojado en el navegador había desaparecido.
  • Se corrigieron sesiones aisladas del árbol de trabajo que rechazaban bucles Bash comunes, canalizaciones xargs y comandos envueltos en el iniciador que no podían llegar a la caja principal.
  • Se mejoró el cambio de tamaño del terminal y el rendimiento del primer renderizado para respuestas largas mediante la reutilización de medidas de texto.
  • Detalle mejorado del agente /workflows: los resultados de JSON están impresos con colores de sintaxis y saltos de línea reales, y los resultados largos se pliegan detrás de un botón de expansión.
  • Inicio de sesión mejorado sin cabeza/SDK: el primer turno comienza hasta 50 ms antes cuando los servidores MCP terminan de conectarse
  • Se mejoró /install-github-app para explicar que es solo para GitHub y señalar los documentos de CI/CD de GitLab cuando se ejecuta dentro de un repositorio de GitLab.
  • Se mejoraron los resultados anidados de los subagentes en segundo plano para que se guarden en la transcripción del subagente principal, de modo que los subagentes reanudados los conserven y las transcripciones compartidas muestren la entrega.
  • Se modificó allowedMcpServers para controlar solo los servidores que los usuarios agregan: un servidor managed-mcp.json literal que su lista de permitidos solía filtrar ahora se carga en la actualización; use deniedMcpServers para mantenerlo apagado
  • [VSCode] Se agregó un filtro rápido activo y un menú de filtro de estado (Necesita entrada, En funcionamiento, Completado) a la barra lateral de la lista de sesiones.
  • Se corrigieron sesiones remotas y programadas que no hacían nada después de que se aprobara una solicitud de permiso de la herramienta del conector mientras la sesión estaba en pausa.

claude-code v2.1.259

What's changed

  • Added managedMcpServers managed setting: organizations can provide HTTP/SSE MCP servers to every user (same entry shape as .mcp.json); entries that name a command to run are skipped
  • Added --permission-prompts none for unattended headless hosts: anything that would prompt is denied automatically while the active permission mode (including auto mode) keeps deciding
  • Added recognition of glab mr create/merge/close/reopen/note/update so GitLab merge requests show as MR !N in the collapsed tool summary and refresh the footer MR badge
  • Added --json to claude plugin validate for a machine-readable validation report
  • Fixed concurrent sessions silently reverting each other's ~/.claude.json changes — workspace trust no longer resets and MCP/project state is no longer lost when running many sessions at once
  • Fixed a conversation whose thinking was rejected once being rejected again on every later turn
  • Fixed Bash Read() deny rules not covering files given as option values (--ignore-revs-file=.env, -f.env, @file), git diff/git grep file operands, or cd DIR && cat FILE compounds; grep -r/cp -r over a directory holding a denied file now asks
  • Fixed the prompt cache being invalidated when the OAuth token refreshed in sessions with telemetry disabled
  • Fixed fullscreen mode showing a blank conversation after a long turn with hundreds of tool calls
  • Fixed auto mode running a turn on a model it doesn't support when a command or skill's frontmatter model: named one; the turn now keeps the session model
  • Fixed CLAUDE_CODE_MAX_CONTEXT_TOKENS being ignored for Vertex-style model IDs (@YYYYMMDD suffix) of model versions Claude Code doesn't recognize
  • Fixed the live output preview of a running shell command hiding its newest lines when an earlier line wrapped
  • Fixed a background GitHub connection check that ran on every launch for claude.ai users; the result is now remembered across launches
  • Fixed --resume failing (and --continue opening an empty conversation) when a saved session contains an attachment entry with no payload
  • Fixed frontmatter model: on custom commands and skills being ignored in interactive sessions
  • Fixed Artifact publishing failing once with an "unexpected parameter note" error in conversations continued from an older version
  • Fixed managed forceRemoteSettingsRefresh being ignored at startup when a policy helper configured by MDM or the managed settings file had already run
  • Fixed worktree isolation refusing hook-created worktrees on machines where git rev-parse fails with a message other than "not a git repository"
  • Fixed OpenTelemetry metrics and events from cloud sessions missing the user.email, organization.id, and user.account_uuid attributes
  • Fixed MCP servers that disconnect while their tools are being listed at startup showing as connected with no tools instead of reporting the error
  • Fixed the file edit permission dialog sometimes showing a changed line cut short with no indication
  • Fixed repository detection dropping a known repo identity after a transient git probe failure
  • Fixed managed settings silently going unenforced when the managed-settings file, a drop-in, the MDM plist, or the HKLM value cannot be parsed: Claude Code now refuses to start and names the source
  • Fixed Stop not actually stopping background agents and workflows in remote-control sessions: killed tasks now stay visible and re-stoppable until their processes exit
  • Fixed resuming a workflow run while its previous stopped run was still exiting, which could run duplicate copies of its agents
  • Fixed marketplace repo URLs on github.com with a trailing slash or dangling ?/# producing an unusable .git clone URL
  • Fixed blocking Stop hooks causing the turn after a block to lose the model's reasoning from that turn and, on some models, miss the prompt cache
  • Fixed remote (claude.ai) sessions taking 60 seconds to start a turn after a browser-hosted MCP server's page had gone away
  • Fixed worktree-isolated sessions refusing common Bash loops, xargs pipelines and launcher-wrapped commands that cannot reach the main checkout
  • Improved terminal resize and first-render performance for long responses by reusing text measurements
  • Improved /workflows agent detail: JSON outcomes are pretty-printed with syntax colors and real line breaks, and long outcomes fold behind an expand toggle
  • Improved headless/SDK session start: the first turn begins up to 50 ms sooner when MCP servers finish connecting
  • Improved /install-github-app to explain it is GitHub-only and point to the GitLab CI/CD docs when run inside a GitLab repository
  • Improved nested background subagent results to be saved in the parent subagent's transcript, so resumed subagents keep them and shared transcripts show the delivery
  • Changed allowedMcpServers to govern only servers users add: a literal managed-mcp.json server your allowlist used to filter out now loads on upgrade; use deniedMcpServers to keep it off
  • [VSCode] Added an Active quick filter and a status filter menu (Needs input, Working, Completed) to the session list sidebar
  • Fixed remote and scheduled sessions doing nothing after a connector-tool permission prompt was approved while the session was paused
