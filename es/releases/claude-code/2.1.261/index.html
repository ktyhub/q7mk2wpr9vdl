claude-code v2.1.261

código-claude v2.1.261

¿Qué ha cambiado?

  • Se agregó una línea de "Política de organización" a /status y claude doctor que indica por qué no se pudo cargar la política de su organización, como por ejemplo un proxy que no pasa el punto final.
  • Se agregaron configuraciones bashOutputMaxChars y taskOutputMaxChars para aumentar la cantidad de comandos y resultados de tareas en segundo plano que Claude recibe en línea antes de guardarlos en un archivo, hasta 128 000 caracteres.
  • Se agregó --append-subagent-system-prompt-file para leer el mensaje del sistema del subagente desde un archivo, para mensajes demasiado grandes para pasar en la línea de comando.
  • Se agregó /skill-doctor para mostrar qué habilidades cargadas no se utilizan y cuánto cuestan en contexto, para que puedas eliminarlas.
  • Se corrigieron los caracteres escritos o pegados que ocasionalmente aparecían fuera de orden o se eliminaban durante la entrada rápida o la repetición de teclas.
  • Se corrigió que /add-dir <subdirectory> imprimiera un error falso "no se pudo resolver" cuando el directorio de trabajo está en un montaje automático de /net.
  • Se corrigió que el asistente de configuración de Bedrock se bloqueara cuando AWS o un asistente de credenciales de AWS nunca responde (ahora se agota con un error claro) y sus comprobaciones de modelo fallan detrás de un proxy de inspección TLS.
  • Se corrigieron las sesiones en la nube que descartaban un complemento sincronizado desde claude.ai cuando la configuración administrada obligaba a habilitarlo en enabledPlugins y luego recurría a un clon del mercado que podía fallar.
  • Se corrigió la imposibilidad de eliminar el carácter inmediatamente antes de un chip [Image #N] en línea en la entrada del mensaje.
  • Se corrigió que al reanudar una sesión se perdiera la salida del enlace y otro contexto en torno a las llamadas a herramientas paralelas, lo que cambió la solicitud reanudada.
  • Se corrigió el control remoto que mostraba un modo de permiso obsoleto cuando un teléfono, navegador o aplicación claude.ai se conecta a una sesión de terminal o después de que el modo cambia en el terminal.
  • Se corrigieron las sesiones de control remoto que mostraban que aún funcionaban (la ruleta y el botón Detener se atascaban) después de detener un giro desde un teléfono o navegador conectado, o después de un comando de barra local como /clear.
  • Se corrigió que SDK y las sesiones en la nube ignoraran una parada o interrupción enviada justo después del primer mensaje, antes de que comenzara el turno; el turno ahora se detiene en lugar de completarse
  • Se corrigió que el control remoto cargara una sesión extraída con /teleport en la sesión conectada, que aparecía adjunta al original en el teléfono y en la web.
  • Se corrigió que el flujo de eventos entrantes de Control remoto fallara detrás de los servidores proxy corporativos de inspección TLS en Windows nativo.
  • Se corrigieron las sesiones de control remoto que mostraban el nivel de esfuerzo predeterminado en claude.ai cuando el esfuerzo proviene de la configuración.
  • Se corrigió que gcpAuthRefresh abriera un navegador al inicio cuando la verificación de credenciales de Google era lenta, a pesar de que la credencial aún era válida.
  • Se corrigieron los conectores claude.ai que permanecían ausentes durante toda la sesión cuando se agotaba el tiempo de recuperación del conector de inicio; el CLI ahora vuelve a intentarlo en segundo plano.
  • Se corrigió el uso elevado y sostenido de la CPU cuando no se podía reanudar un agente en segundo plano y se reintentaba su reactivación en un bucle cerrado.
  • Se corrigieron los indicadores de funciones vinculados a una versión más nueva que ocasionalmente se aplicaban a una versión anterior de Claude Code que se ejecutaba en la misma máquina.
  • Se corrigió que /usage y el panel de uso de VS Code dejaran caer una fila de límite semanal específica del modelo cuando el punto final de uso tiene una tasa limitada o cuando se abre inmediatamente después del inicio.
  • Se corrigió que claude -p --resume <file> adoptara una ID de sesión con formato incorrecto registrada en la transcripción; ahora se reanuda con una nueva ID de sesión
  • Se corrigió el indicador de progreso del terminal (iTerm2, Ghostty, ConEmu) que mostraba la sesión como finalizada mientras un flujo de trabajo en segundo plano o un agente aún se estaba ejecutando.
  • Se corrigió un problema de diseño poco común por el cual un cuadro podía renderizarse con la altura incorrecta después de que su contenedor cambiaba entre la dirección de fila y columna.
  • Se corrigió la IP de la puerta de enlace de aplicaciones de Claude client cuando un proxy trust agrega un puerto a X-Forwarded-For; con una lista de acceso configurada, una entrada ilegible ahora obtiene 403
  • Se corrigió la puerta de enlace de aplicaciones de Claude que le indicaba a Claude Desktop que exportara OpenTelemetry como JSON incluso cuando el terminal CLI usa protobuf, por lo que los recopiladores solo de protobuf rechazaron los datos de Desktop.
  • Se corrigió que el escritorio y la web mostraran una sesión como ocupada mientras solo observa un artefacto en busca de actualizaciones.
  • Se corrigió que Claude en Chrome file_upload fallara con "rutas: matriz esperada, recibida indefinida" en sesiones de Cowork locales ejecutadas desde la aplicación de escritorio Claude.
  • Se corrigió SendMessage para una sesión de control remoto fuera de línea en otra máquina leyendo tal como se entregó; el resultado ahora dice que la entrega está en cola hasta que la máquina se vuelva a conectar
  • Se corrigieron las sugerencias de instalación de complementos de CLI que se ejecutan en comandos Bash en segundo plano: ahora se detectan y la etiqueta <claude-code-hint> sin formato ya no se filtra en la conversación.
  • Se corrigió que los compañeros de equipo del agente en proceso reenviaran su herramienta del primer turno y anuncios de habilidades en el segundo turno, lo que cambiaba el prefijo de solicitud y omitía el caché de mensajes.
  • Se mejoró el selector /model y la píldora de modelo VS Code para mostrar el nombre de un modelo en lugar de su ID de puerta de enlace Bedrock, Vertex AI o LLM sin procesar cuando Claude Code lo reconoce.
  • Inicio mejorado en Google Vertex AI cuando se configura GOOGLE_APPLICATION_CREDENTIALS: la creación de API client ya no vuelve a ejecutar el descubrimiento de proyectos de Google Cloud ni genera procesos gcloud adicionales.
  • Rendimiento de transmisión mejorado: los bloques ya renderizados ya no se vuelven a verificar por diseño en cada actualización
  • Se mejoró el aviso de seguridad peligroso-rm para detectar también rm -rf en parámetros posicionales y dentro de scripts sh -c entre comillas dobles.
  • Manejo mejorado cuando el API no envía encabezados de respuesta: el reintento ahora espera hasta API_TIMEOUT_MS (10 minutos de forma predeterminada) en lugar de otros 3 minutos, y los mensajes dicen qué cambiar
  • Se modificó una puerta de enlace de aplicaciones de Claude 403 en la carga de la configuración administrada (al inicio o después de /login) para decir que es posible que Claude Code no esté habilitado para la organización, en lugar de recomendar un nuevo inicio de sesión.
  • Se cambiaron las máquinas cuyas configuraciones administradas fijan forceLoginMethod: "gateway" para ignorar una clave API sobrante o el inicio de sesión de claude.ai y solicitan /login; Las sesiones de Bedrock, Vertex AI y Foundry no se ven afectadas
  • Se modificó el modo automático para tratar un enlace que incluye contenido en la URL de un renderizador de diagrama público como una carga en ese sitio: ya no se aprueba automáticamente a menos que usted lo solicite.
  • Se cambiaron las teclas de edición de palabras del mensaje para que coincidan con Bash: Ctrl+W elimina nuevamente los espacios en blanco, Alt+F y Alt+D se detienen al final de la palabra, la puntuación separa las palabras; keybindingFlavor ya no tiene ningún efecto
  • Se modificó el conteo de tokens /context para usar una estimación local cuando el conteo de tokens API no está disponible, en lugar de solicitudes de modelos extra pequeños.
  • [VSCode] Se agregó un tutorial sobre "Crear un estilo personalizado" al menú Estilos de salida que escribe un archivo de estilo de salida personalizado y lo enumera de inmediato.
  • [VSCode] Se agregó un formulario Agregar servidor y una acción Eliminar al cuadro de diálogo de servidores MCP, para que los servidores MCP se puedan agregar y eliminar sin salir del IDE.
  • [VSCode] Se agregó un anillo hueco en la lista de sesiones para las sesiones abiertas en una terminal, otra ventana de VS Code o Claude Desktop, para que ya no parezcan cerradas.
  • [VSCode] Se agregó un botón para doblar permisos y preguntas para que la conversación detrás de ellas se pueda leer sin descartarlas; el espacio al lado del mensaje ahora desplaza la conversación
  • [VSCode] Se agregó "Archivar sesión" al menú derecho click de la lista de sesiones y se le dio a Desarchivar su propio ícono
  • [VSCode] Se corrigió una sesión teletransportada desde Claude Code en la web que trataba una pregunta que se cortó cuando la sesión en la nube se cerró como declined
  • [VSCode] Se corrigió que el cuadro Cambiar nombre de la pestaña de la sesión se abriera vacío para una pestaña restaurada con la ventana; ahora comienza con el nombre actual
  • [VSCode] Se corrigieron las secciones colapsadas en el panel de la lista de sesiones que se mostraban brevemente expandidas cada vez que se cargaba el panel.
  • [VSCode] Se corrigió la vista de enfoque que mostraba que una llamada de herramienta aún se estaba ejecutando después de que Claude había seguido adelante, como mientras una pregunta esperaba su respuesta.
  • [VSCode] Se corrigió que el resaltado de la fila activa de la lista de sesiones se volviera obsoleto cuando se corrige el ID de sesión de una pestaña Claude desenfocada
  • [VSCode] Se corrigió la reapertura de Cmd/Ctrl+Shift+T y se abre un vínculo profundo colocando la pestaña de Claude fuera del grupo del editor de Claude cuando una pestaña de Claude tiene el foco
  • [VSCode] Se corrigió "Agregar al grupo" de la pestaña de sesión, colocando una sesión abierta desde Claude Code en la Web en dos grupos; ahora mueve la entrada que muestra la lista de sesiones
  • [VSCode] Se corrigió el selector de modelos que mostraba los modelos que una organización había deshabilitado desde entonces hasta que la ventana se recargó dos veces.
  • [VSCode] Se corrigió una pestaña abierta desde la lista de sesiones que regresaba a esa sesión, y una pestaña abierta desde una sesión web que reiniciaba su teletransporte o permanecía vacía, después de que VS Code recarga la vista de la pestaña
  • [VSCode] Se corrigió el historial de preguntas secundarias de /btw de sesiones anteriores que se sobrescribían cuando se hacía una pregunta justo después de recargar la ventana o mientras un archivo de configuración tenía errores.
  • [VSCode] Se corrigió que la tarjeta de preguntas pendientes no reapareciera después de que el panel de Claude se recarga cuando se inicia sesión con una cuenta de Claude.ai o Consola.
  • [VSCode] Se corrigieron las funciones exclusivas de claude.ai que permanecían visibles en los otros paneles de Claude de una ventana después de que un panel eligiera un proveedor externo de un archivo de configuración.
  • [VSCode] Se corrigió la pantalla de inicio de sesión que aparece a pesar de la configuración Desactivar mensaje de inicio de sesión cuando Claude Code informa que no hay inicio de sesión o una solicitud falla por falta de uno.
  • [VSCode] Se corrigió el siguiente mensaje de permiso en cola manteniendo el texto escrito en el mensaje anterior y aceptando un segundo mensaje inmediato click
  • [VSCode] Se corrigieron los enlaces de instalación del complemento que abrían la barra lateral de Claude sin el cuadro de diálogo de instalación en una ventana donde solo se mostraba la lista de sesiones.
  • [VSCode] Se corrigió que el medidor de uso de la barra lateral permaneciera vacío en una nueva ventana hasta que se abriera el cuadro de diálogo Cuenta y uso, y se dejara fuera del medidor un límite de uso del 0%.
  • [VSCode] Se corrigió que "Iniciar nueva sesión en este grupo" perdía el grupo después de una nueva conversación y faltaba un punto no leído para una sesión que finalizó antes de que se cargara la lista de no leídos de la barra lateral.
  • [VSCode] Se corrigió la insignia de la pestaña del editor que mostraba no leído durante un turno en ejecución o faltaba en una pestaña abierta desde la lista de sesiones, y "Agregar pestaña de sesión al grupo" no hacía nada para una sesión archivada.

claude-code v2.1.261

What's changed

  • Added an "Organization policy" line to /status and claude doctor that says why your organization's policy could not be loaded, such as a proxy not passing the endpoint through
  • Added bashOutputMaxChars and taskOutputMaxChars settings to raise how much command and background-task output Claude receives inline before it is saved to a file, up to 128K characters
  • Added --append-subagent-system-prompt-file to read the subagent system prompt from a file, for prompts too large to pass on the command line
  • Added /skill-doctor to show which loaded skills go unused and what they cost in context, so you can prune them
  • Fixed typed or pasted characters occasionally landing out of order or being dropped during fast input or key repeat
  • Fixed /add-dir <subdirectory> printing a false "couldn't be resolved" error when the working directory is on a /net automount
  • Fixed the Bedrock setup wizard hanging when AWS or an AWS credential helper never responds (it now times out with a clear error), and its model checks failing behind a TLS-inspecting proxy
  • Fixed cloud sessions discarding a plugin synced from claude.ai when managed settings force-enable it in enabledPlugins, then falling back to a marketplace clone that could fail
  • Fixed being unable to delete the character immediately before an inline [Image #N] chip in the prompt input
  • Fixed resuming a session losing hook output and other context around parallel tool calls, which changed the resumed request
  • Fixed Remote Control showing a stale permission mode when a phone, browser, or claude.ai app attaches to a terminal session or after the mode changes in the terminal
  • Fixed Remote Control sessions showing as still working (stuck spinner and Stop button) after stopping a turn from a connected phone or browser, or after a local slash command like /clear
  • Fixed SDK and cloud sessions ignoring a Stop or interrupt sent just after the first prompt, before the turn had started; the turn now stops instead of running to completion
  • Fixed Remote Control uploading a session pulled with /teleport into the connected session, which appeared appended to the original on phone and web
  • Fixed Remote Control's inbound event stream failing behind TLS-inspecting corporate proxies on native Windows
  • Fixed Remote Control sessions showing the default effort level on claude.ai when the effort comes from settings
  • Fixed gcpAuthRefresh opening a browser at startup when the Google credential check was slow, even though the credential was still valid
  • Fixed claude.ai connectors staying absent for the whole session when the startup connector fetch timed out — the CLI now retries in the background
  • Fixed sustained high CPU usage when a background agent could not be resumed and its wake-up was retried in a tight loop
  • Fixed feature flags gated to a newer version occasionally applying to an older Claude Code version running on the same machine
  • Fixed /usage and the VS Code usage panel dropping a model-specific weekly limit row when the usage endpoint is rate limited or when opened right after startup
  • Fixed claude -p --resume <file> adopting a malformed session ID recorded in the transcript; it now resumes under a fresh session ID instead
  • Fixed the terminal progress indicator (iTerm2, Ghostty, ConEmu) showing the session as finished while a background workflow or agent was still running
  • Fixed a rare layout glitch where a box could render with the wrong height after its container switched between row and column direction
  • Fixed Claude apps gateway client IP when a trusted proxy appends a port to X-Forwarded-For; with an access list set, an unreadable entry now gets 403
  • Fixed Claude apps gateway telling Claude Desktop to export OpenTelemetry as JSON even when the terminal CLI uses protobuf, so protobuf-only collectors rejected Desktop's data
  • Fixed Desktop and web showing a session as busy while it only watches an artifact for updates
  • Fixed Claude in Chrome file_upload failing with "paths: expected array, received undefined" in local Cowork sessions run from the Claude Desktop app
  • Fixed SendMessage to an offline Remote Control session on another machine reading as delivered; the result now says delivery is queued until that machine reconnects
  • Fixed plugin install hints from CLIs run in background Bash commands: they are now detected, and the raw <claude-code-hint> tag no longer leaks into the conversation
  • Fixed in-process agent-team teammates re-sending their first-turn tool and skill announcements on the second turn, which changed the request prefix and missed the prompt cache
  • Improved the /model picker and the VS Code model pill to show a model's name instead of its raw Bedrock, Vertex AI, or LLM gateway ID when Claude Code recognizes it
  • Improved startup on Google Vertex AI when GOOGLE_APPLICATION_CREDENTIALS is set: API client creation no longer re-runs Google Cloud project discovery or spawns extra gcloud processes
  • Improved streaming performance: already-rendered blocks are no longer re-checked by layout on each update
  • Improved the dangerous-rm safety prompt to also catch rm -rf on positional parameters and inside double-quoted sh -c scripts
  • Improved handling when the API sends no response headers: the retry now waits up to API_TIMEOUT_MS (10 minutes by default) instead of another 3 minutes, and the messages say what to change
  • Changed a Claude apps gateway 403 on the managed settings load (at startup or after /login) to say Claude Code may not be enabled for the organization, instead of advising a new sign-in
  • Changed machines whose managed settings pin forceLoginMethod: "gateway" to ignore a leftover API key or claude.ai login and ask for /login; Bedrock, Vertex AI, and Foundry sessions are unaffected
  • Changed auto mode to treat a link that packs content into a public diagram renderer's URL as an upload to that site: no longer auto-approved unless you asked for it
  • Changed the prompt's word-editing keys to match Bash: Ctrl+W deletes back to whitespace, Alt+F and Alt+D stop at word end, punctuation separates words; keybindingFlavor no longer has any effect
  • Changed /context token counting to use a local estimate when the token-counting API is unavailable, instead of extra small-model requests
  • [VSCode] Added a "Build a custom style" walkthrough to the Output styles menu that writes a custom output style file and lists it right away
  • [VSCode] Added an Add server form and a Remove action to the MCP servers dialog, so MCP servers can be added and removed without leaving the IDE
  • [VSCode] Added a hollow ring in the session list for sessions open in a terminal, another VS Code window, or Claude Desktop, so they no longer look closed
  • [VSCode] Added a fold button to permission and question prompts so the conversation behind them can be read without dismissing them; the space beside the prompt now scrolls the conversation
  • [VSCode] Added "Archive session" to the session list's right-click menu and gave Unarchive its own icon
  • [VSCode] Fixed a session teleported from Claude Code on the web treating a question that was cut off when the cloud session shut down as declined
  • [VSCode] Fixed the session tab's Rename box opening empty for a tab restored with the window; it now starts with the current name
  • [VSCode] Fixed collapsed sections in the session list panel briefly showing expanded each time the panel loaded
  • [VSCode] Fixed Focus view showing a tool call as still running after Claude had moved on, such as while a question waited for your answer
  • [VSCode] Fixed the session list's active-row highlight going stale when an unfocused Claude tab's session ID is corrected
  • [VSCode] Fixed Cmd/Ctrl+Shift+T reopen and deep-link opens placing the Claude tab outside the Claude editor group when a Claude tab has focus
  • [VSCode] Fixed the session tab's "Add to group" putting a session opened from Claude Code on the Web in two groups; it now moves the entry the session list shows
  • [VSCode] Fixed the model picker showing models an organization has since disabled until the window was reloaded twice
  • [VSCode] Fixed a tab opened from the session list jumping back to that session, and a tab opened from a Web session restarting its teleport or staying empty, after VS Code reloads the tab's view
  • [VSCode] Fixed /btw side-question history from earlier sessions being overwritten when a question is asked right after a window reload or while a settings file has errors
  • [VSCode] Fixed the pending question card not reappearing after the Claude panel reloads when signed in with a Claude.ai or Console account
  • [VSCode] Fixed claude.ai-only features staying visible in a window's other Claude panels after one panel picked up a third-party provider from a settings file
  • [VSCode] Fixed the sign-in screen appearing despite the Disable Login Prompt setting when Claude Code reports no login or a request fails for lack of one
  • [VSCode] Fixed the next queued permission prompt keeping text typed on the previous prompt and accepting an immediate second click
  • [VSCode] Fixed install-plugin links opening the Claude sidebar without the install dialog in a window where only the session list had been shown
  • [VSCode] Fixed the sidebar usage meter staying empty on a new window until the Account & usage dialog was opened, and a 0% usage limit being left out of the meter
  • [VSCode] Fixed "Start new session in this group" losing the group after New conversation, and a missing unread dot for a session that finished before the sidebar's unread list loaded
  • [VSCode] Fixed the editor tab badge showing unread during a running turn or missing on a tab opened from the session list, and "Add Session Tab to Group" doing nothing for an archived session
  • [VSCode] Fixed "Enable Remote Control for all sessions" so flipping it also applies right away to sessions open in other VS Code windows
  • [VSCode] Fixed the session list's Open filter for sessions continued from claude.ai whose tab was still recorded under the web session, and labeled the filter menu's sections for screen readers
  • [VSCode] Changed the model picker to one flat list of every model, with rows kept for older model spellings listed last
