código-claude v2.1.280

¿Qué ha cambiado?

  • Se agregó Claude Opus 5.5 (claude-opus-5-5), ahora el modelo Opus predeterminado: contexto de 1 millón, $4/$20 por Mtok con lecturas de caché de $0.20/Mtok.
  • Se agregó compatibilidad con el mouse a más listas en modo de pantalla completa: la rueda se desplaza por la lista /skills y las opciones de estado de una habilidad en /plugin se pueden seleccionar cli.
  • Se agregó CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH para cambiar el límite de 2048 caracteres en las descripciones de las herramientas MCP y las instrucciones del servidor para cada servidor MCP en la sesión.
  • Se agregaron tamaños de salida de gancho y la cantidad de salidas de gran tamaño guardadas en un archivo para el evento hook_execution_complete OpenTelemetry
  • Se corrigieron las escrituras a través de una ruta con enlace simbólico que se juzgaba por su ortografía en el árbol: los nombres de los mensajes donde aterriza la escritura, y acceptEdits, permiten reglas y el modo automático ya no aprueba un aterrizaje externo.
  • Se corrigió el modo automático que reintentaba una acción una y otra vez cuando un control de seguridad debía revisarla; la acción ahora se deniega una vez, teniendo en cuenta que volver a intentarlo no ayudará
  • Se corrigió el modo automático que negaba acciones una y otra vez sin pausa cuando una verificación de seguridad no daba respuesta; Los reintentos ahora retroceden y el turno se detiene con un mensaje después de diez seguidos.
  • Se corrigieron las llamadas de escritura que fallaban en la validación cuando un modelo envía path, file_text, file_content o un description perdido en lugar de file_path y content.
  • Se corrigió Ctrl+C o Ctrl+D presionado dos veces en la mayoría de los cuadros de diálogo (/model, /effort, /config, /status, /usage, /plugin, /sandbox, /permissions, /artifacts, /mobile, /login, /upgrade, /usage-credits, /install-github-app, /setup-bedrock, /setup-vertex) saliendo de Claude Code en lugar de cerrar el diálogo
  • Se corrigió un click que solo traía la ventana del terminal al frente y también activaba el elemento debajo del puntero: en selectores de búsqueda, barras de pestañas, filas de agente/flujo de trabajo, enlaces de comando de barra diagonal y menús desplegables de sugerencias.
  • Se corrigió un n perdido cerrando los diálogos y un y perdido confirmándolos; Ingrese y Esc acepte y cancele (vincule y/n a confirm:yes/confirm:no en keybindings.json para restaurar)
  • Se corrigieron los campos de texto en los cuadros de diálogo que perdían una letra, dígito o espacio escrito debido a una combinación de teclas en esa tecla.
  • Se corrigió la línea de aviso que permanecía codificada en terminales Windows después de que se eliminaran los caracteres invisibles en Enter; la pantalla ahora está repintada para que puedas revisar el texto exacto que se enviará
  • Se corrigió la limpieza de caracteres invisibles eliminando el no conector de ancho cero que el texto persa y árabe usa para adjuntar un sufijo a una palabra o número latino, como el plural de "PDF".
  • Se corrigió que el dictado de voz no se detuviera con Ctrl+C (el mensaje se borraba pero el micrófono seguía grabando), Esc no se cancelaba mientras se procesaba una transcripción y se mantenía la barra espaciadora al iniciar el dictado desde la vista de transcripción y el modo vim NORMAL.
  • Se corrigió un cambio de modelo realizado desde una aplicación host (Claude Desktop, VS Code, SDK) mientras Claude estaba trabajando, lo que provocaba una pérdida de caché en el siguiente mensaje.
  • Se corrigió que los subagentes de bifurcación reanudados reconstruyeran su lista de herramientas en lugar de volver a enviar la que usaron por primera vez, lo que rompía el almacenamiento en caché para ese agente.
  • Se corrigieron los mensajes de devolución del subagente que mostraban un preámbulo de procedencia interna cuando se expandían fuera del modo detallado.
  • Se corrigió que installed_plugins.json mantuviera la confirmación en el momento de la instalación después de actualizar un complemento desde un repositorio GitHub o una URL de git que rastrea una rama o etiqueta.
  • Se corrigieron las habilidades en ~/.claude/skills/ que se movían a ~/.claude/skills/.trash/ cuando un manifest.json en esa carpeta enumeraba sus nombres.

claude-code v2.1.280

What's changed

  • Added Claude Opus 5.5 (claude-opus-5-5), now the default Opus model — 1M context, $4/$20 per Mtok with $0.20/Mtok cache reads
  • Added mouse support to more lists in fullscreen mode: the wheel scrolls the /skills list, and a skill's state options in /plugin can be clicked
  • Added CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH to change the 2,048-character cap on MCP tool descriptions and server instructions for every MCP server in the session
  • Added hook output sizes and the number of oversized outputs saved to a file to the hook_execution_complete OpenTelemetry event
  • Fixed writes through a symlinked path being judged by their in-tree spelling: the prompt names where the write lands, and acceptEdits, allow rules and auto mode no longer approve one landing outside
  • Fixed auto mode retrying an action over and over when a safety check declined to review it; the action is now denied once, noting that retrying won't help
  • Fixed auto mode denying actions over and over without pause when a safety check gave no answer; retries now back off, and the turn stops with a message after ten in a row
  • Fixed Write calls failing validation when a model sends path, file_text, file_content or a stray description instead of file_path and content
  • Fixed Ctrl+C or Ctrl+D pressed twice in most dialogs (/model, /effort, /config, /status, /usage, /plugin, /sandbox, /permissions, /artifacts, /mobile, /login, /upgrade, /usage-credits, /install-github-app, /setup-bedrock, /setup-vertex) quitting Claude Code instead of closing the dialog
  • Fixed a click that only brought the terminal window to the front also triggering the item under the pointer — in search pickers, tab bars, agent/workflow rows, slash-command links and suggestion dropdowns
  • Fixed a stray n closing dialogs and a stray y confirming them; Enter and Esc accept and cancel (bind y/n to confirm:yes/confirm:no in keybindings.json to restore)
  • Fixed text fields in dialogs losing a typed letter, digit or Space to a keybinding on that key
  • Fixed the prompt line staying scrambled on Windows terminals after invisible characters were removed on Enter; the screen is now repainted so you review the exact text that will be sent
  • Fixed the invisible-character cleanup removing the zero-width non-joiner that Persian and Arabic text uses to attach a suffix to a Latin word or number, such as the plural of "PDF"
  • Fixed voice dictation not stopping on Ctrl+C (the prompt cleared but the microphone kept recording), Esc not cancelling while a transcript was processing, and held Space starting dictation from the transcript view and vim NORMAL mode
  • Fixed a model switch made from a host app (Claude Desktop, VS Code, SDK) while Claude is working causing a prompt-cache miss on the next prompt
  • Fixed resumed fork subagents rebuilding their tool list instead of re-sending the one they first used, which broke prompt caching for that agent
  • Fixed subagent hand-back messages showing an internal provenance preamble when expanded outside verbose mode
  • Fixed installed_plugins.json keeping the install-time commit after updating a plugin from a GitHub repository or git URL that tracks a branch or tag
  • Fixed skills in ~/.claude/skills/ being moved to ~/.claude/skills/.trash/ when a manifest.json in that folder listed their names
  • Fixed the session feedback survey showing no hover highlight on light and ANSI themes
  • Fixed /workflows briefly showing a one-row list before opening the only run
  • Fixed the mouse wheel not scrolling selection lists with hidden options (such as /model and /permissions) in fullscreen mode
