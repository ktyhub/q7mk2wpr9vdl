código-claude v2.1.311

¿Qué ha cambiado?

  • Se agregaron --hold-idle-file y --max-hold-min a self-hosted-runner, para mantener una sesión inactiva mientras el host informa que los procesos que dejó en ejecución
  • Se agregó un consejo para el estilo de salida explicativo, que se muestra cuando le pides explicaciones a Claude.
  • Se corrigieron bloqueos prolongados al inicio y después de leer o editar archivos cuando un archivo CLAUDE.md contiene un elemento de lista muy largo.
  • Se corrigió que la interrupción de Claude no surtiera efecto hasta que se agotara el tiempo de espera mientras un servidor MCP no había respondido a una lectura de recurso o una habilidad aún se estaba descargando.
  • Se corrigieron sesiones de contexto estándar que se detenían con "Créditos de uso requeridos para 1 millón de contexto" cuando una solicitud superaba los 200 000 tokens; Claude Code ahora compacta la conversación y continúa
  • Se corrigió que la escritura y la edición se detuvieran por hasta 5 segundos después de ejecutarse y reportaran 0 líneas cambiadas al cambiar miles de líneas en un archivo.
  • Se corrigió que los subagentes no pudieran usar herramientas MCP de servidores que terminaban de conectarse después de que se iniciaba el subagente.
  • Se corrigió que Claude viera contenido obsoleto de MEMORY.md y CLAUDE.md justo después de la compactación automática cuando esos archivos se editaron anteriormente en la sesión.
  • Se corrigieron las sesiones claude -p y SDK que guardaban los mensajes transcritos fuera de orden o mantenían los mensajes que fueron retirados.
  • Se corrigieron los ganchos SubagentStop que se ejecutan aproximadamente dos veces por minuto para cada subagente en ejecución en lugar de una vez cuando finaliza.
  • Se corrigió el selector de archivos @ que ignoraba las reglas de negación .ignore/.rgignore que vuelven a incluir archivos ignorados por git.
  • Se corrigió que el árbol de trabajo aislado de un subagente se eliminara mientras un subagente en segundo plano que inició todavía estaba trabajando en él.
  • Se corrigieron los agentes en segundo plano en modo automático que esperan en sus propios caparazones iniciando una nueva conversación principal y se activan cada vez que se despiertan.
  • Se corrigió la descripción de la herramienta Bash que afirmaba que el directorio de trabajo siempre persiste entre llamadas.
  • Se corrigió el bloque de entorno que nombraba comandos de shell en los que no se ejecutaban, como fish cuando la herramienta Bash usa zsh.
  • Se corrigió que claude mcp add, claude mcp remove y /mcp nombraran la carpeta actual en lugar de la entrada del proyecto en ~/.claude.json que contiene un servidor de alcance local cuando se ejecuta debajo de una raíz de repositorio.
  • Se corrigió que claude mcp list y claude mcp get mostraran el código de error dos veces en líneas de conexión fallidas (por ejemplo, ENOENT: ENOENT: …).
  • Se corrigieron las sesiones de control remoto que permanecían en "Conectando" durante aproximadamente dos minutos cuando un proxy de red bloquea una solicitud de inicio.
  • Se corrigieron los mensajes que Claude envía a una nube o sesión de Control remoto que aparecen como su propio mensaje en las aplicaciones móviles de Claude.
  • Se corrigió que a Claude no se le dijera la causa cuando un archivo adjunto a un mensaje enviado a través de Control remoto o a una sesión en la nube no se podía guardar porque el disco estaba lleno, o que los archivos adjuntos de un mensaje más allá de los primeros 20 se omitían.
  • Se corrigió que WebFetch y WebSearch colgaran en una respuesta estancada en sesiones de nube de Cowork; una solicitud incompleta ahora falla después de 300 segundos
  • Se corrigió una sesión en segundo plano que fallaba entre turnos y no se reiniciaba mientras estaba adjunta, fijada o tenía una tarea programada o activación configurada.
  • Se corrigió el error "el servicio en segundo plano no respondió" que sugería el claude daemon restart deshabilitado; ahora sugiere claude daemon stop --any y dice que finaliza las sesiones en segundo plano.
  • Se corrigió que claude respawn <id> iniciara el servicio en segundo plano antes de informar que ninguna sesión en segundo plano coincide con la identificación.
  • Se corrigió que /effort no advirtiera sobre una falla de caché en el modo de plan cuando el modelo de plan difiere del modelo de sesión.
  • Se corrigió /ide que decía que la extensión VS Code se instaló antes de que finalizara la instalación o cuando fallaba.
  • Se corrigió la vista previa del archivo de la herramienta de escritura que omitía filas y contaba mal líneas ocultas cuando una línea es más ancha que el terminal.
  • Se corrigió ↑ en la pestaña de chat de un agente que recordaba un mensaje que aún estaba esperando ser entregado, por lo que al reenviarlo se enviaba una segunda copia.
  • Se corrigieron las sesiones de nube de Cowork que perdían sus conectores y la mayoría de las herramientas después de un reinicio cuando un complemento o su configuración nombraba agent; Las sesiones de cowork en la nube ahora ignoran esa configuración
  • Se corrigieron las sesiones de equipos de agentes que mostraban una lista de tareas vacía al regresar con --resume, --continue, /resume o --session-id, incluso después de /clear o un bloqueo, y /branch escribiendo en la lista de la sesión original.
  • Se corrigió el pegado de texto que menciona un archivo de imagen, como ! open /tmp/shot.png o /review look at /tmp/shot.png, adjuntando la imagen y eliminando su ruta desde el mensaje.

claude-code v2.1.311

What's changed

  • Added --hold-idle-file and --max-hold-min to self-hosted-runner, to keep an idle session while your host reports processes it left running
  • Added a tip for the Explanatory output style, shown when you ask Claude for explanations
  • Fixed long freezes at startup and after reading or editing files when a CLAUDE.md file holds a very long list item
  • Fixed interrupting Claude not taking effect until a timeout while an MCP server had not answered a resource read or a skill was still downloading
  • Fixed standard-context sessions stopping with "Usage credits required for 1M context" when a request ran over 200K tokens; Claude Code now compacts the conversation and continues
  • Fixed Write and Edit stalling for up to 5 seconds after they ran, and reporting 0 lines changed, when changing thousands of lines in a file
  • Fixed subagents being unable to use MCP tools from servers that finish connecting after the subagent starts
  • Fixed Claude seeing stale MEMORY.md and CLAUDE.md content right after automatic compaction when those files were edited earlier in the session
  • Fixed claude -p and SDK sessions saving transcript messages out of order or keeping messages that were taken back
  • Fixed SubagentStop hooks running about twice a minute for each running subagent instead of once when it finishes
  • Fixed the @ file picker ignoring .ignore/.rgignore negation rules that re-include git-ignored files
  • Fixed a subagent's isolated worktree being removed while a background subagent it started was still working in it
  • Fixed background agents in auto mode that wait on their own shells starting a new main conversation turn on every wake
  • Fixed the Bash tool description claiming the working directory always persists between calls
  • Fixed the environment block naming a shell commands don't run in, such as fish when the Bash tool uses zsh
  • Fixed claude mcp add, claude mcp remove and /mcp naming the current folder instead of the project entry in ~/.claude.json that holds a local-scope server when run below a repository root
  • Fixed claude mcp list and claude mcp get showing the error code twice on failed-connection lines (for example ENOENT: ENOENT: …)
  • Fixed Remote Control sessions staying on "Connecting" for about two minutes when a network proxy blocks a startup request
  • Fixed messages that Claude sends to a cloud or Remote Control session appearing as your own message in the Claude mobile apps
  • Fixed Claude not being told the cause when a file attached to a message sent over Remote Control or to a cloud session could not be saved because the disk was full, or that a message's attachments past the first 20 were left out

  • Fixed the feedback draft card showing its 1/2/0 and Esc shortcuts while the prompt has text, when those keys act on the prompt instead of the card

  • Fixed agent teammates compacting their history when DISABLE_COMPACT is set
  • Fixed the rewind menu offering "Summarize from here" and "Summarize up to here" when DISABLE_COMPACT is set
  • Fixed a finished /code-review, or another skill that runs in a sub-agent, running a second time when a cloud or background session restarts
  • Fixed long hidden thinking being cut off as idle on Google Vertex AI, Microsoft Foundry and Claude Platform on AWS, where the endpoint sends thinking progress updates

  • Fixed Claude Pro and Max subscribers being told to ask their admin when their subscription can't be used; the message now points to billing settings
  • Fixed the diff pane opening by itself after an edit in wide fullscreen terminals when it had nothing to show
  • Fixed /mcp showing a remote server as failed after "Clear authentication" when the server works without sign-in
  • Fixed /mcp showing "authenticated" for a remote server that Claude Code sends no credentials to
  • Fixed a --plugin-dir folder of plugins loading as one plugin when an empty .mcp.json was at its top

  • Fixed status line links staying plain text in background sessions after you open them from a terminal that supports links
