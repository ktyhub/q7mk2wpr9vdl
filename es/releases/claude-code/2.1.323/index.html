¿Qué ha cambiado?

  • Modo de código agregado, una opción experimental en la que Claude escribe JavaScript para llamar a sus herramientas; consulte https://code.claude.com/docs/en/code-mode para activarlo o desactivarlo para una organización.
  • Se agregó engines["claude-code"] a plugin.json: los complementos fuera del rango de versiones indicado en Claude Code no se instalan, actualizan ni cargan, y para instalar y actualizar, elija la versión más nueva que se ajuste
  • Se agregó verificación de tipo del módulo de ganchos TypeScript de un complemento a claude plugin validate; cada hallazgo es una advertencia y --strict falla
  • Se agregaron a claude plugin validate los sustantivos $ y el gancho engine.create de un mod agrega, retiene o reemplaza
  • Se agregó soporte para CLAUDE_CODE_AUTO_MODE_MODEL en la configuración administrada para sesiones de Claude Desktop en proveedores externos (entra en vigencia una vez que Claude Desktop incluya esta versión)
  • Se agregó un menú de opciones (detener, cambiar a créditos de uso, actualizar) cuando un modelo necesita créditos de uso que están desactivados o agotados.
  • Se agregó un latido de progreso cada 30 segundos mientras los ganchos se ejecutan durante mucho tiempo en las sesiones claude -p y SDK, por lo que un host como Claude Desktop no finalizará el turno como colgado (una vez que incluya esta versión).
