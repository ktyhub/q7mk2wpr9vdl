claude-code v2.1.214

código-claude v2.1.214

¿Qué ha cambiado?

  • Se corrigió el segmento único dir/** que permite reglas como Edit(src/**) que aprueban automáticamente escrituras en directorios dir/ anidados en cualquier parte del árbol en lugar de solo <cwd>/dir.
  • Se corrigió una omisión de verificación de permisos que afectaba a los comandos ejecutados en sesiones de Windows PowerShell 5.1.
  • Se corrigieron las comprobaciones de permisos de Bash que fallaban al cerrarse en formularios de redirección de descriptores de archivos que bash analiza de manera diferente que el analizador de permisos.
  • Se corrigieron las comprobaciones de permisos de Bash que juzgaban mal los comandos muy largos: los comandos de más de 10,000 caracteres ahora siempre aparecen en lugar de ejecutarse automáticamente.
  • Se corrigieron las comprobaciones de permisos de Bash que tratan los subíndices y modificadores de variables zsh en comparaciones [[ ]] como texto inerte; estos comandos ahora solicitan aprobación
  • Se corrigieron las comprobaciones de permisos de Bash para que ya no aprobaran automáticamente ciertos comandos help y man que podrían ejecutar opciones inseguras, sustituciones de comandos o rutas de barra invertida.
  • Se corrigieron las solicitudes de permiso en sesiones remotas que podían continuar antes del cuadro de diálogo de confirmación local.
  • Se agregó la herramienta EndConversation: Claude puede finalizar sesiones con usuarios altamente abusivos o intentos de jailbreak, como en claude.ai desde 2025 — ver https://www.anthropic.com/research/end-subset-conversations
  • Se agregó un latido de progreso periódico para llamadas de herramientas de larga duración que anteriormente permanecían en silencio.
  • Se agregó una marca de tiempo ISO modified al frontmatter del archivo de memoria.
  • Se agregaron los atributos message.uuid, client_request_id y tool_source a los eventos de registro de OpenTelemetry para correlación a nivel de mensajes y procedencia de herramientas.
  • Se agregó CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH para configurar el límite de truncamiento de 60 KB en los atributos de contenido de OpenTelemetry.
  • Se agregó esfuerzo de razonamiento a la carga útil subagentStatusLine, para que las filas de agentes personalizadas puedan representar el modelo y el esfuerzo.
  • Se agregaron solicitudes de permiso para los comandos docker (incluido el shim Podman docker) que llevan indicadores de redireccionamiento de demonio (--url, --connection, --identity y el modo remoto de Podman) que anteriormente se ejecutaban sin uno.
  • Se corrigió un fallo cuando una función de GrowthBook se evaluaba como nula y un error por el cual una carga útil de indicadores con formato incorrecto podía borrar los indicadores de funciones almacenados en caché.
  • Se corrigió la herramienta Bash que mataba la sesión de Claude cuando un patrón pkill -f coincidía accidentalmente con el propio proceso del CLI (Linux).
  • Se corrigió el crecimiento ilimitado de la memoria cuando --settings apunta a un archivo de dispositivo o a un archivo de varios GB; Los archivos de configuración de gran tamaño (>2 MiB) ahora fallan al inicio con un error claro
  • Se corrigió el error de transmisión por secuencias con "Socket cerrado" detrás de servidores proxy corporativos en Windows.
  • Se corrigió el truncamiento de salida de stream-json en la salida para consumidores de SDK/pipeline de lectura lenta; el drenaje de salida ahora escala con bytes en cola en lugar de un límite plano de 2 segundos
  • Se corrigieron las tareas programadas que rechazaban su propio mensaje configurado como entrada untrusted: el mensaje activado ahora se entrega como la tarea asignada de la sesión.
  • Se corrigieron los comandos de la herramienta PowerShell que se bloqueaban hasta el tiempo de espera cuando un proceso secundario esperaba una entrada estándar (Windows)
  • Se corrigieron los scripts Python en la herramienta PowerShell que fallaban con UnicodeDecodeError al leer datos que no eran UTF-8 desde la entrada estándar (Windows)
  • Se corrigieron los scripts Python ejecutados a través de la herramienta PowerShell que fallaban con UnicodeEncodeError en salidas que no eran ASCII y mensajes de error de PowerShell 7 que contenían secuencias de escape ANSI sin formato (Windows)
  • Se corrigió la herramienta PowerShell que informaba where.exe, fc.exe y diff.exe como errores cuando devolvían una respuesta negativa válida (Windows).
  • Se corrigió que > y >> bajo la herramienta PowerShell en Windows PowerShell 5.1 escribieran archivos UTF-16LE que otras herramientas no podían leer como UTF-8.
  • Se corrigió un demonio en segundo plano desplazado que eliminaba el zócalo de control de su sucesor al apagarse, lo que hacía que el siguiente client matara al demonio de reemplazo saludable.
  • Se corrigieron las sesiones en segundo plano estacionadas con ← o /background y dejadas inactivas manteniendo el demonio en segundo plano y un proceso de trabajo vivos indefinidamente.
  • Se corrigió que las sesiones en segundo plano completadas fueran imposibles de eliminar a través de claude rm o la vista del agente una vez que el servicio en segundo plano había quedado inactivo.
  • Se corrigió que las sesiones en segundo plano enviadas desde una carpeta que no era de git fueran imposibles de eliminar de la vista de agentes.
  • Se corrigió que al reabrir una sesión en segundo plano detenida no se pudiera restaurar la conversación guardada cuando existía una carpeta ilegible en el almacén de sesiones.
  • Se corrigió la notificación push de "sesión lista" de Control remoto que se activaba para sesiones en las que el Control remoto no estaba habilitado explícitamente.
  • Se corrigió el bloqueo del menú de configuración de /install-github-app y /mcp en sesiones de vista de agente; ahora se rechazan solo en sesiones en segundo plano sin terminal conectado.
  • Se corrigieron los complementos habilitados a través del indicador --settings CLI que no se cargaban (regresión desde v2.1.181)
  • Se corrigió que los indicadores de funciones quedaran obsoletos en sesiones de larga duración después de que el token de OAuth rotara.
  • Se corrigió que /ultrareview se negara a ejecutarse en repositorios sin base de fusión; ahora ofrece revisar todos los archivos rastreados.
  • Se corrigió que claude update y claude doctor colgaran silenciosamente y que la sección de diagnóstico del sistema /status quedara en blanco cuando una ruta de configuración de shell es un directorio.
  • Se corrigieron los valores iniciales de la memoria que se truncaban silenciosamente en un # en línea cuando se guardan los archivos de memoria.
  • Se corrigió el costo de la sesión y el doble conteo de telemetría de tokens en transmisiones que emiten múltiples fotogramas message_delta acumulativos.
  • Se corrigió una advertencia falsa de "verifique su red" que aparecía mientras el asesor estaba pensando
  • Se corrigieron los ganchos con código de salida 2 que no se bloquean como se documenta cuando la salida estándar JSON del gancho falla en la validación del esquema.
  • Se corrigieron los eventos de registro de OTel emitidos fuera del contexto asíncrono del turno sin el contexto de seguimiento del intervalo de interacción.
  • Se corrigieron errores transitorios de MCP durante la actualización de mensajes/recursos al borrar los comandos y recursos de barra diagonal del servidor.
  • Se mejoró el error claude rc workspace-trust en el directorio de inicio para decir que trust nunca se guardó y sugerir ejecutar desde un directorio de proyecto.
  • Se cambiaron las condiciones del gancho if: de un solo segmento para que coincidan solo con <cwd>/dir; escriba **/dir/** para una coincidencia de cualquier profundidad. Las reglas de permiso deny/ask mantienen su coincidencia de cualquier profundidad.
  • Se cambiaron los comandos file usando -m/--magic-file o -f/--files-from para requerir permiso en lugar de permitirse automáticamente como de solo lectura.
  • Se modificó la agrupación de conexiones de mantenimiento de conexión para deshabilitarla después de un error de conexión obsoleta, por lo que se vuelve a intentar abrir un socket nuevo.
  • Se cambiaron los ganchos de SessionStart para informar la fuente "fork" cuando una sesión comienza como una bifurcación en lugar de "resume".

claude-code v2.1.214

What's changed

  • Fixed single-segment dir/** allow rules like Edit(src/**) auto-approving writes to nested dir/ directories anywhere in the tree instead of only <cwd>/dir
  • Fixed a permission-check bypass affecting commands run in Windows PowerShell 5.1 sessions
  • Fixed Bash permission checks to fail closed on file-descriptor redirect forms that bash parses differently than the permission analyzer
  • Fixed Bash permission checks misjudging very long commands — commands over 10,000 characters now always prompt instead of running automatically
  • Fixed Bash permission checks treating zsh variable subscripts and modifiers in [[ ]] comparisons as inert text — these commands now prompt for approval
  • Fixed Bash permission checks to no longer auto-approve certain help and man commands that could run unsafe options, command substitutions, or backslash paths
  • Fixed permission prompts on remote sessions that could proceed before the local confirmation dialog
  • Added the EndConversation tool: Claude can end sessions with highly abusive users or jailbreak attempts, as on claude.ai since 2025 — see https://www.anthropic.com/research/end-subset-conversations
  • Added a periodic progress heartbeat for long-running tool calls that previously went silent
  • Added an ISO modified timestamp to memory file frontmatter
  • Added message.uuid, client_request_id, and tool_source attributes to OpenTelemetry log events for message-level correlation and tool provenance
  • Added CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH to configure the 60 KB truncation limit on OpenTelemetry content attributes
  • Added reasoning effort to the subagentStatusLine payload, so custom agent rows can render model and effort
  • Added permission prompts for docker commands (including the Podman docker shim) carrying daemon-redirect flags (--url, --connection, --identity, and Podman's remote mode) that previously ran without one
  • Fixed a crash when a GrowthBook feature evaluates to null, and a bug where a malformed flag payload could wipe the cached feature flags
  • Fixed Bash tool killing the Claude session when a pkill -f pattern accidentally matched the CLI's own process (Linux)
  • Fixed unbounded memory growth when --settings points at a device file or multi-GB file; oversized (>2 MiB) settings files now fail at startup with a clear error
  • Fixed streaming turns failing with "Socket is closed" behind corporate proxies on Windows
  • Fixed stream-json output truncation at exit for slow-reading SDK/pipeline consumers; the exit drain now scales with queued bytes instead of a flat 2s cap
  • Fixed scheduled tasks refusing their own configured prompt as untrusted input — the fired prompt is now delivered as the session's assigned task
  • Fixed PowerShell tool commands hanging until timeout when a child process waited on standard input (Windows)
  • Fixed Python scripts under the PowerShell tool crashing with UnicodeDecodeError when reading non-UTF-8 data from standard input (Windows)
  • Fixed Python scripts run via the PowerShell tool crashing with UnicodeEncodeError on non-ASCII output, and PowerShell 7 error messages containing raw ANSI escape sequences (Windows)
  • Fixed the PowerShell tool reporting where.exe, fc.exe, and diff.exe as errors when they return a valid negative answer (Windows)
  • Fixed > and >> under the PowerShell tool on Windows PowerShell 5.1 writing UTF-16LE files that other tools couldn't read as UTF-8
  • Fixed a displaced background daemon deleting its successor's control socket on shutdown, which made the next client kill the healthy replacement daemon
  • Fixed background sessions parked with ← or /background and left idle keeping the background daemon and a worker process alive indefinitely
  • Fixed completed background sessions being impossible to remove via claude rm or the agent view once the background service had gone idle
  • Fixed background sessions dispatched from a non-git folder being impossible to delete from the agents view
  • Fixed reopening a stopped background session failing to restore its saved conversation when an unreadable folder exists in the session store
  • Fixed the Remote Control "session ready" push notification firing for sessions where Remote Control was not explicitly enabled
  • Fixed /install-github-app and the /mcp settings menu being blocked in agent-view sessions — they're now refused only in background sessions with no terminal attached
  • Fixed plugins enabled via the --settings CLI flag not loading (regression since v2.1.181)
  • Fixed feature flags going stale in long-running sessions after the OAuth token rotates
  • Fixed /ultrareview refusing to run in repos with no merge base — it now offers to review all tracked files
  • Fixed claude update and claude doctor hanging silently, and the /status System diagnostics section going blank, when a shell-config path is a directory
  • Fixed memory frontmatter values being silently truncated at an inline # when memory files are saved
  • Fixed session cost and token telemetry double-counting on streams that emit multiple cumulative message_delta frames
  • Fixed a spurious "check your network" warning that appeared while the advisor was thinking
  • Fixed hooks with exit code 2 not blocking as documented when the hook's stdout JSON fails schema validation
  • Fixed OTel log events emitted outside the turn's async context missing the interaction span's trace context
  • Fixed MCP transient errors during prompts/resources refresh clearing the server's slash commands and resources
  • Improved the claude rc workspace-trust error in the home directory to say trust there is never saved and to suggest running from a project directory
  • Changed single-segment dir/** hook if: conditions to match only <cwd>/dir; write **/dir/** for any-depth matching. deny/ask permission rules keep their any-depth match.
  • Changed file commands using -m/--magic-file or -f/--files-from to require permission instead of being auto-allowed as read-only
  • Changed keep-alive connection pooling to disable after a stale-connection error, so retries open a fresh socket
  • Changed SessionStart hooks to report source "fork" when a session begins as a fork instead of "resume"
