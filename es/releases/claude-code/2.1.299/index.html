código-claude v2.1.299

¿Qué ha cambiado?

  • Se agregó la variable de entorno CLAUDE_CODE_DISABLE_FILE_MENTIONS: Claude obtiene las rutas de las menciones del archivo @ para leer con sus herramientas de archivos, no con el contenido de los archivos.
  • Se agregó compactación inactiva en la terminal: una conversación de más de 200 000 tokens que se deja inactiva durante aproximadamente 54 minutos se compacta antes de que caduque su caché de mensajes de una hora, por lo que su próximo mensaje no lo reprocesa todo.
  • Se agregó CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS para cambiar el mínimo de 200 000 tokens de compactación inactiva; "idleCompaction": false en configuración. json lo apaga. Ambos necesitan v2.1.290 o posterior
  • Se agregó $.prompt.media para que un enlace prompt.submit de un mod instalado mediante la configuración administrada pueda leer los bytes de una imagen o documento adjunto al mensaje.
  • Se agregó $.session.identity() para mods instalados mediante configuraciones administradas: cómo se inicia sesión en la sesión y su organización y correo electrónico cuando se administra forceLoginOrgUUID enumera esa organización
  • Se agregaron size, weight, mono y tabular al Text de un mod y se nombraron pasos de espaciado (xs a xl) a su Box; bold está en desuso en favor de weight
  • Se agregó --shutdown-drain-sec a claude self-hosted-runner orchestrator: en SIGTERM detiene el sondeo y realiza el sondeo en vuelo y ejecuta ganchos de generación hasta esa cantidad de segundos para finalizar.
  • Se agregó el frontmatter de la habilidad, la fuente, el nombre del complemento y la ruta del archivo a lo que recibe el gancho skill.prompt de un mod.
  • Se agregaron /effort y /fast en la vista del agente para establecer con qué comienzan las nuevas sesiones; un /model, /effort o /fast desnudo ahora se abre un selector
  • Se agregó una línea de "modo seguro" al panel de vista de los agentes para las sesiones en segundo plano iniciadas con --safe-mode.
  • Se agregó una nota única cuando el modo de plan no preguntará antes de la mayoría de las ediciones o comandos porque los permisos de omisión están disponibles
  • Se agregaron --disallow-tools y un campo de caso disallowed_tools a claude plugin eval para mantener herramientas integradas específicas, como Agent, fuera de las ejecuciones de evaluación.
  • Se agregó soporte para desactivar el bloque de atribución en la pestaña Código de Claude Desktop: establezca CLAUDE_CODE_ATTRIBUTION_HEADER=0 en el env de la política code de una puerta de enlace de aplicaciones de Claude.
  • Se agregó un campo al bloque de atribución en las sesiones de Claude Code detrás de una puerta de enlace de aplicaciones de Claude; quitar el bloque con CLAUDE_CODE_ATTRIBUTION_HEADER=0
  • Se agregó una puerta queue al gancho de mod session.append, para que un mod pueda hacer que los registros de la cola de transcripción difieran del mensaje enviado
  • Se agregó una nota en /plugin y claude plugin validate que nombra los ganchos de un mod que se omiten cuando una organización administra Claude Code.
  • Se agregaron advertencias /usage para máximo esfuerzo, flujos de trabajo, contexto siempre activo y resultados de herramientas grandes.
  • Se corrigió el error de una sesión en la nube denegada, que podría apuntar a la organización incorrecta cuando se estaba usando una clave de apiKeyHelper.

  • Changed MCP tool descriptions and server instructions from Anthropic's first-party MCP servers at api.anthropic.com to reach Claude in full instead of being cut at 4,096 characters
  • Changed auto mode in Cowork cloud sessions: a PermissionRequest hook can no longer approve shell commands or subagents; those prompts wait or are denied
  • Changed the resume command printed at exit: it names the session by its ID and no longer by its name, so that nothing in a session name can run when the line is pasted

  • Changed /btw side questions in non-interactive sessions to return a timeout error when still unanswered after 11 minutes
  • Changed UserPromptSubmit hooks to run before a skill or custom slash command expands, so a hook that blocks the prompt now also stops its embedded shell commands
  • Changed a skill's own front-matter UserPromptSubmit hook to first run on the prompt after the one that invokes the skill
  • Changed the turn.start mod hook to also hear subagents' and teammates' turns, not only the main loop's; tell them apart by e.agentId (absent on the main loop)
  • Changed the errors shown when /ultrareview can't upload a repository to stop suggesting git add ., which could stage or commit untracked files such as .env

  • [VSCode] Fixed unused blank chats keeping a background Claude process running after starting a new conversation
  • [VSCode] Fixed the mic button showing an internal error message when you are signed out of claude.ai; it now offers to sign you in
  • [VSCode] Improved startup time in workspaces without a Python environment by starting Claude while the Python extension loads
  • [VSCode] Improved startup: the model picker and slash command menu now fill in right away in a new window on a folder you've opened before
  • [Cloud sessions] Fixed a memory spike that could crash a session when many of its existing output files were re-sent to it at once
  • [Cloud sessions] Fixed saving an edited routine silently moving it to a different environment when its own had been deleted or wasn't in the list; the routine now keeps its environment
  • [Cloud sessions] Fixed Sessions search in a self-hosted environment's admin details finding nothing when you paste the session ID from a session's link
  • [Cloud sessions] Fixed the Sessions and Runners lists in a self-hosted environment's admin details saying the list is empty when a search just has no matches
  • [Cloud sessions] Improved the deploy command shown when you create a self-hosted environment or environment key: it shows in full, wraps between arguments, and has a visible copy button
  • [Cloud sessions] Changed deleting a self-hosted environment to turn off its routines right away, with the reason shown on each routine, instead of leaving their runs to fail

  • [Claude Tag] Fixed Claude in Slack staying silent on untagged posts that a channel's own instructions tell it to answer, such as posts that tag someone else, in channels with guests
