código-claude v2.1.233

¿Qué ha cambiado?

  • Se agregó soporte de URL de solicitud de fusión GitLab al indicador --worktree y a la vista claude agents (donde los MR se muestran como !N).
  • Se agregó una configuración de puerta de enlace de aplicaciones forward_user_identity en canales ascendentes de Anthropic que envía la identidad del usuario que inició sesión como encabezados, de modo que un proxy detrás de la puerta de enlace pueda atribuir el gasto por usuario.
  • Se agregó soporte de grupo de memoria opcional para los comandos de la herramienta Bash en Linux (CLAUDE_CODE_TOOL_MEMORY_LIMIT) para que una compilación fuera de control no pueda detener la sesión.
  • Se agregó la variable de entorno CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS para configurar el TTL de la caché de URL de la sesión WebFetch (valor predeterminado sin cambios: 15 minutos)
  • Se corrigió que las sesiones en la nube ocasionalmente se marcaran como perdidas cuando el entorno se cerraba mientras Claude esperaba una solicitud de permiso.
  • Se corrigieron las conexiones MCP v2 que reabren interminablemente las suscripciones/transmisiones de escucha contra servidores que finalizan las transmisiones retenidas durante mucho tiempo en un tiempo de espera fijo (por ejemplo, hosts sin servidor).
  • Se corrigieron los ganchos de notificación que no se activaban cuando se solicitaban permisos cuando se ejecutaban en Claude Desktop o VS Code.
  • Se corrigieron sesiones inactivas en Linux que a veces mantenían un núcleo de CPU al 100% cuando el espacio aislado estaba habilitado.
  • Se corrigieron alias de habilidades incluidas como /checkup y /review que informaban "comando desconocido" en el modo -p o con complementos/MCP cargados cuando una habilidad de usuario o proyecto sigue la habilidad incluida.
  • Se corrigió la sustitución de argumentos de habilidad/comando para evitar que los valores de los argumentos se vuelvan a expandir como marcadores de plantilla.
  • Se corrigieron las rutas de Windows escritas con el prefijo de dispositivo NT \??\ que omitían la validación de ruta UNC, cerrando un vector de fuga de credenciales NTLM.
  • Hora de inicio de sesión claude self-hosted-runner mejorada: la rama de sesión ahora se crea sin reescribir el árbol de trabajo y dos viajes de ida y vuelta al servidor ya no bloquean el inicio del agente.
  • Reenvío de errores de puerta de enlace de aplicaciones mejorado: los errores 400/413 de Vertex, Foundry y Claude Platform en los canales ascendentes de AWS ahora llevan el propio mensaje del canal ascendente; corrige un error con la compactación automática en la puerta de enlace de aplicaciones
  • claude plugin validate mejorado para verificar un directorio .claude/skills desnudo, informando archivos SKILL.md cuyo frontmatter no se puede analizar
  • Modo de lector de pantalla mejorado: el selector /effort se muestra como una lista numerada con un mensaje de número escrito, y el texto de sugerencia y diálogo ya no aparece cli.
  • Diagnóstico del modo de impresión mejorado: se escribe una línea [claude-code:unrecognized_model] en stderr cuando se envía una solicitud para un ID de modelo que Claude Code no reconoce; mapearlo con modelOverrides para silenciarlo
  • Se modificó el consejo de configuración de la aplicación GitHub para que ya no aparezca en los repositorios cuyo origen remoto esté en gitlab.com o bitbucket.org; el consejo del mercado empresarial ahora cubre hosts git internos que no son GitHub
  • Las herramientas de seguimiento de tareas/todo (TaskCreate/Get/Update/List, TodoWrite) ya no están disponibles en Opus 4.8, Sonnet 5, Fable 5, Mythos 5 y modelos más nuevos; configure CLAUDE_CODE_ENABLE_TODO_TOOLS=1 para traerlos de vuelta
  • Windows: modo automático fijo que se detenía repetidamente para aprobación manual en comandos Bash cd <dir> && <command> > file normales (una regresión 2.1.232)
  • Se revirtieron los cambios de permisos de Bash 2.1.232 para enlaces simbólicos estilo Cygwin en Windows y para redirecciones de entrada (< file); una versión más limitada regresará en una versión posterior

claude-code v2.1.233

What's changed

  • Added GitLab merge request URL support to the --worktree flag and the claude agents view (where MRs display as !N)
  • Added an opt-in forward_user_identity apps gateway setting on Anthropic upstreams that sends the signed-in user's identity as headers, so a proxy behind the gateway can attribute spend per user
  • Added opt-in memory cgroup support for Bash tool commands on Linux (CLAUDE_CODE_TOOL_MEMORY_LIMIT) so a runaway build can't stall the session
  • Added CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS environment variable to configure the WebFetch session URL cache TTL (default unchanged: 15 minutes)
  • Fixed cloud sessions occasionally being marked as lost when the environment shut down while Claude was waiting on a permission prompt
  • Fixed MCP v2 connections endlessly reopening the subscriptions/listen stream against servers that terminate long-held streams on a fixed timeout (e.g. serverless hosts)
  • Fixed Notification hooks not firing for permission prompts when running under Claude Desktop or VS Code
  • Fixed idle sessions on Linux sometimes keeping one CPU core at 100% when sandboxing is enabled
  • Fixed bundled skill aliases like /checkup and /review reporting "Unknown command" in -p mode or with plugins/MCP loaded when a user or project skill shadows the bundled skill
  • Fixed skill/command argument substitution to prevent argument values from being re-expanded as template markers
  • Fixed Windows paths spelled with the NT \??\ device prefix bypassing UNC path validation, closing an NTLM credential-leak vector
  • Improved claude self-hosted-runner session start time: the session branch is now created without rewriting the working tree, and two server round trips no longer block the agent's launch
  • Improved apps gateway error forwarding: 400/413 errors from Vertex, Foundry, and Claude Platform on AWS upstreams now carry the upstream's own message; fixes a bug with auto-compact on apps gateway
  • Improved claude plugin validate to check a bare .claude/skills directory, reporting SKILL.md files whose frontmatter fails to parse
  • Improved screen reader mode: the /effort selector renders as a numbered list with a typed-number prompt, and hint and dialog text is no longer clipped
  • Improved print mode diagnostics: a [claude-code:unrecognized_model] line is written to stderr when a request goes out for a model ID Claude Code doesn't recognize; map it with modelOverrides to silence
  • Changed the GitHub app setup tip to no longer appear in repositories whose origin remote is on gitlab.com or bitbucket.org; the enterprise marketplace tip now covers non-GitHub internal git hosts
  • Todo/task-tracking tools (TaskCreate/Get/Update/List, TodoWrite) are no longer available on Opus 4.8, Sonnet 5, Fable 5, Mythos 5, and newer models; set CLAUDE_CODE_ENABLE_TODO_TOOLS=1 to bring them back
  • Windows: fixed auto mode repeatedly stopping for manual approval on ordinary cd <dir> && <command> > file Bash commands (a 2.1.232 regression)
  • Reverted the 2.1.232 Bash permission changes for Cygwin-style symlinks on Windows and for input redirections (< file); a narrower version will return in a later release
