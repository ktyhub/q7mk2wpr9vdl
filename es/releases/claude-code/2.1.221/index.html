código-claude v2.1.221

¿Qué ha cambiado?

  • [VSCode] Se agregó vista de enfoque: un menú de chat para alternar que oculta la actividad de la herramienta detrás de un resumen expandible por turno con un indicador de herramienta en ejecución en vivo, que se alterna con Ctrl+Alt+F o el comando "Claude Code: alternar vista de enfoque".
  • Se agregó mode: "mask" para archivos de credenciales de sandbox en Linux y WSL: los comandos de sandbox leen una copia centinela (el archivo completo o solo los intervalos capturados por una expresión regular extract) mientras que el proxy de sandbox sustituye el valor real en la salida; en macOS el enmascaramiento de archivos vuelve a ser deny
  • Se agregaron advertencias a claude plugin validate cuando la sincronización del mercado administrado de Claude Desktop rechaza el nombre de un mercado o complemento.
  • Se agregó un subcomando prompt-audit a la habilidad claude-api para auditar indicaciones y descripciones de herramientas para patrones escritos para modelos más antiguos.
  • Se corrigió una omisión de verificación de permisos de la herramienta Bash donde zsh podía ejecutar comandos ocultos en los condicionales de expresiones regulares [[ ]]; Los comandos afectados ahora solicitan permiso.
  • Se corrigió el permiso de PowerShell que verifica el mal manejo de rutas que contienen comillas en Windows; tales caminos ahora requieren aprobación
  • Se corrigió que el cambio de pensamiento no tuviera efecto durante el resto de una sesión que comenzaba con pensar; La desactivación de una conexión intermedia del servidor MCP ya no se revierte silenciosamente.
  • Se corrigió que los servidores MCP de --mcp-config no estuvieran conectados antes del primer turno en modo de impresión (-p), lo que hacía que el modelo emitiera llamadas a herramientas como texto literal.
  • Se corrigió que los archivos @-mencionados se soltaran silenciosamente al presionar Esc para retirar un mensaje y volver a enviarlo.
  • Se corrigió un error al preparar solicitudes API para herramientas MCP SDK con nombres de propiedades de objetos integradas, como constructor.
  • Se corrigió la falla de WebSearch con un error 400 en el esfuerzo xhigh/max cuando el pensamiento está deshabilitado.
  • Se corrigieron cargas grandes en el espacio aislado que fallaban con errores TLS a través del proxy del espacio aislado
  • Se corrigió el mensaje de límite de gasto de equipo y empresa que culpaba incorrectamente al límite mensual de la organización en lugar de a su límite de gasto individual.
  • Se corrigió el error de autenticación de Bedrock con perfiles con nombre de AWS SSO en sesiones administradas por escritorio en máquinas Windows que configuraban una variable de entorno HOME perdida.
  • Se corrigió que CLAUDE_CODE_RESUME_INTERRUPTED_TURN=0 no deshabilitara la reanudación automática de giros interrumpidos; Ahora se respetan los valores falsos.
  • Se corrigió una rara carrera de despertar del sueño donde dos procesos de Claude Code podían actualizar el mismo conector MCP o token WIF OAuth a la vez, lo que obligaba a volver a autenticarse.
  • Se corrigió el cambio de nombre de una sesión desde Claude Code Desktop o claude.ai que no actualizaba el nombre de la sesión del CLI; Los nombres de sesión de cada superficie de cambio de nombre ahora están desinfectados.
  • Se corrigieron las habilidades entregadas por complementos y organizaciones con nombres integrados solo en la terminal (por ejemplo, /help, /feedback) que no se podían invocar en sesiones no interactivas.
  • Se corrigió la notificación "Complementos cambiados" que persistía después de que los complementos se recargaban en lugar de borrarse.
  • Modo Vim fijo: el registro de extracción ahora sobrevive a los diálogos, la búsqueda del historial y la vista de transcripción en lugar de vaciarse silenciosamente.
  • Modo Vim fijo: deshacer el regreso a un mensaje vacío ahora activa la confirmación "presione ← nuevamente" antes de regresar a la vista del agente
  • Herramienta de búsqueda mejorada en Google Vertex AI: reactivada para Claude 4.5-generation y modelos más nuevos
  • Modo automático mejorado: las comprobaciones de permisos para llamadas a herramientas paralelas ahora son eficientes en caché y el cambio de modo mientras hay una verificación pendiente indica de manera confiable en lugar de aplicar el resultado obsoleto.
  • Reducción de los costos de caché de aviso para verificaciones de permisos en modo automático al reutilizar el prefijo de conversación almacenado en caché en todas las decisiones.
  • Panel de estadísticas mejorado para contar los tokens de caché en sus totales de tokens, con un desglose por entrada, salida, lectura de caché y escritura de caché
  • Mensajes de error /ultrareview mejorados cuando un repositorio no comparte historial con su base: un pago sin ramas ahora se rechaza de antemano con consejos para crear uno, y las sugerencias de rechazo ya no sugieren git fetch --unshallow en clones que ya están completos.
  • Inicio de Windows mejorado: los tiempos de creación de procesos ahora se leen a través de una llamada nativa de kernel32 en lugar de generar PowerShell, por lo que las herramientas de seguridad de endpoints que bloquean powershell.exe ya no solicitan
  • Se cambiaron las sesiones en segundo plano para comprometerse y presionar para preservar el trabajo, abrir un borrador de relaciones públicas solo cuando la tarea lo requiera, seguir las instrucciones de CLAUDE.md git y terminar siempre informando dónde se encuentra el trabajo.
  • Se modificó /plugin install para actualizar un catálogo de mercado obsoleto y volver a intentarlo antes de informar que no se encontró un complemento.
  • Se modificaron los complementos instalados desde /plugin para que se activen inmediatamente cuando sea seguro, en lugar de requerir siempre /reload-plugins.
  • Se cambiaron los complementos para aceptar "." como ruta skills, y el error de validación de nivel raíz SKILL.md ahora sugiere usar la raíz del complemento.
  • Se modificó /status para mostrar el tipo de sesión: interactive, o un trabajo en segundo plano que es attached o unattended.
  • Se modificó el autocompletado de emoji para aceptar códigos cortos alternativos comunes como :thumbsup:, :thumbsdown: y :love:.
  • Se modificaron las sesiones bifurcadas con /fork para crear un nuevo árbol de trabajo propio en lugar de trabajar en el proceso de pago de la sesión original.
  • Se modificó Claude en Chrome para cerrar las pestañas del navegador que abre una vez que ya no las necesita.
  • Se cambió el modo rápido para informar sobre la transmisión cuando los créditos de uso se agotan a mitad de la sesión, en lugar de fallar silenciosamente.
  • Monitor modificado: un reloj que sale sin producir ningún resultado ahora lo dice en lugar de informar "transmisión finalizada".
  • Se modificó la validación del campo Gateway model: los valores que no son cadenas se rechazan con un 400 en lugar de reenviarse
  • Se eliminó el aviso repetido "El modo de permiso cambió mientras la llamada del clasificador en modo automático estaba en cola" de las solicitudes de aprobación.

claude-code v2.1.221

What's changed

  • [VSCode] Added Focus view: a chat-menu toggle that hides tool activity behind an expandable per-turn summary with a live running-tool indicator, toggled with Ctrl+Alt+F or the "Claude Code: Toggle Focus view" command
  • Added mode: "mask" for sandbox credential files on Linux and WSL — sandboxed commands read a sentinel copy (the whole file, or just the spans captured by an extract regex) while the sandbox proxy substitutes the real value on egress; on macOS file masking falls back to deny
  • Added warnings to claude plugin validate when a marketplace or plugin name would be rejected by Claude Desktop's managed marketplace sync
  • Added a prompt-audit subcommand to the claude-api skill for auditing prompts and tool descriptions for patterns written for older models
  • Fixed a Bash tool permission-check bypass where zsh could execute hidden commands in [[ ]] regex conditionals; affected commands now prompt for permission
  • Fixed PowerShell permission checks mishandling paths containing quote characters on Windows; such paths now prompt for approval
  • Fixed the thinking toggle having no effect for the rest of a session that started with thinking off; disabling an MCP server mid-connect no longer silently reverts
  • Fixed MCP servers from --mcp-config not being connected before the first turn in print mode (-p), which made the model emit tool calls as literal text
  • Fixed @-mentioned files being silently dropped when pressing Esc to retract a prompt and resubmitting it
  • Fixed a crash when preparing API requests for SDK MCP tools named after built-in object properties such as constructor
  • Fixed WebSearch failing with a 400 error at effort xhigh/max when thinking is disabled
  • Fixed sandboxed large uploads failing with TLS errors through the sandbox proxy
  • Fixed Team and Enterprise spend-limit message incorrectly blaming the org's monthly limit instead of your individual spend limit
  • Fixed Bedrock authentication with AWS SSO named profiles failing in desktop-managed sessions on Windows machines that set a stray HOME environment variable
  • Fixed CLAUDE_CODE_RESUME_INTERRUPTED_TURN=0 not disabling interrupted-turn auto-resume; falsy values are now honored
  • Fixed a rare wake-from-sleep race where two Claude Code processes could both refresh the same MCP connector or WIF OAuth token at once, forcing re-authentication
  • Fixed renaming a session from Claude Code Desktop or claude.ai not updating the CLI's session name; session names from every rename surface are now sanitized
  • Fixed plugin- and org-delivered skills named after terminal-only built-ins (e.g. /help, /feedback) being un-invocable in non-interactive sessions
  • Fixed the "Plugins changed" notification lingering after plugins were reloaded instead of clearing
  • Fixed Vim mode: the yank register now survives dialogs, history search, and the transcript view instead of being silently emptied
  • Fixed Vim mode: undoing back to an empty prompt now arms the "press ← again" confirm before returning to the agent view
  • Improved tool search on Google Vertex AI: re-enabled for Claude 4.5-generation and newer models
  • Improved auto mode: permission checks for parallel tool calls are now cache-efficient, and switching modes while a check is pending reliably prompts instead of applying the stale result
  • Reduced prompt-cache costs for auto-mode permission checks by reusing the cached conversation prefix across decisions
  • Improved Stats panel to count cache tokens in its token totals, with a breakdown by input, output, cache read, and cache write
  • Improved /ultrareview error messages when a repo shares no history with its base: a checkout with no branches is now refused up front with advice to create one, and refusal hints no longer suggest git fetch --unshallow on clones that are already complete
  • Improved Windows startup: process creation times are now read via a native kernel32 call instead of spawning PowerShell, so endpoint security tools that gate powershell.exe no longer prompt
  • Changed background sessions to commit and push to preserve work, open a draft PR only when the task calls for one, follow your CLAUDE.md git instructions, and always end by reporting where the work lives
  • Changed /plugin install to refresh a stale marketplace catalog and retry before reporting a plugin not found
  • Changed plugins installed from /plugin to activate immediately when safe, instead of always requiring /reload-plugins
  • Changed plugins to accept "." as a skills path, and the root-level SKILL.md validation error now suggests using the plugin root
  • Changed /status to show the session kind: interactive, or a background job that is attached or unattended
  • Changed emoji autocomplete to accept common alternate shortcodes like :thumbsup:, :thumbsdown:, and :love:
  • Changed sessions forked with /fork to create a new worktree of their own instead of working in the original session's checkout
  • Changed Claude in Chrome to close the browser tabs it opens once it no longer needs them
  • Changed fast mode to report on the stream when usage credits run out mid-session, instead of failing silently
  • Changed Monitor: a watch that exits without producing any output now says so instead of reporting "stream ended"
  • Changed the Gateway model field validation: non-string values are rejected with a 400 instead of being forwarded
  • Removed the repeated "Permission mode changed while the auto-mode classifier call was queued" notice from approval prompts
