código-claude v2.1.290

¿Qué ha cambiado?

  • Se agregó serverToolUses al resultado del gancho turn.step de un mod: la herramienta llama al API que se ejecutó (el asesor), cada uno con su identificación, nombre, entrada, inicio y fin.
  • Se agregó agentId al evento tool.check de los enlaces de complementos, para que un enlace pueda distinguir la verificación de permisos de un subagente de la de la sesión principal.
  • Se agregó ceiling a la pregunta y veredicto que lee el gancho tool.check de un mod, nombrando la aprobación que una organización requiere para una herramienta.
  • Se agregaron tipos ThemeKey y Color a los tipos de ganchos del complemento, por lo que un editor enumera los colores del tema que el dibujo de un mod puede nombrar
  • Agregado a claude plugin validate: cada gancho que un mod registra en un sitio de acceso se enumera si tiene un .catch (gatingHooks bajo --json)
  • Se agregó un botón Denegar a la página de aprobación de inicio de sesión de la puerta de enlace de aplicaciones de Claude: finaliza el inicio de sesión pendiente, por lo que el terminal en espera se detiene en segundos.
  • Se agregaron claude attach <name> y claude logs <name>: parte del nombre de una sesión funciona en lugar de la identificación.
  • Se agregó /claude-api managed-agents-onboard <url> para configurar el patrón de agentes administrados que una página describe como archivos ant apply.
  • Se agregó /claude-api managed-agents-onboard <quickstart-name> para crear una plantilla de inicio rápido de consola, como deep-researcher, con ant CLI.
  • Se agregó una advertencia cuando un archivo de configuración administrada es un enlace a un archivo fuera de la carpeta de configuración administrada.
