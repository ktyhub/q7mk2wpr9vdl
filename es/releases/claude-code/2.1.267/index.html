código-claude v2.1.267

¿Qué ha cambiado?

  • Configuración maxEffortLevel agregada (nivel superior o por modelo en modelSettings): limita el nivel de esfuerzo en cada proveedor, incluidos Bedrock, Vertex y Foundry; los usuarios aún pueden elegir un nivel inferior
  • Se agregó --system-prompt-snapshot off para mostrar el mensaje del sistema actualizado en cada solicitud en lugar de reutilizar el mensaje grabado de la conversación (para iterar en el texto del mensaje).
  • Se corrigieron tareas programadas de Cowork en la nube que fallaban al inicio para organizaciones cuyas configuraciones administradas requieren espacio aislado
  • Se corrigió que /context y otros comandos locales salieran en blanco en clients móviles.
  • Se corrigió que Mayús+entrar y opción+retroceso no funcionaran después de volver a conectarse a una sesión tmux o ssh dentro de una vista de agente.
  • Se corrigió el encabezado tenue del último mensaje que no aparecía en la parte superior de la conversación cuando se desplazaba hacia arriba en modo de pantalla completa.
  • Se corrigieron las llamadas de flujo de trabajo agent() con esquemas de salida grandes que se rechazaban en modo automático en lugar de ser verificadas por el clasificador de seguridad.
  • Se corrigió un caso en el que una ruta de entrada al mercado que contenía una barra invertida podía pasar por alto la verificación de contención para los mercados recuperados en macOS y Linux.
  • Se corrigieron las credenciales caducadas de AWS o Google Cloud en una aplicación host como Claude Desktop, que se reintentaba diez veces con una "solicitud fallida" genérica antes de que apareciera el error de nueva autenticación.
  • Se corrigió la reanudación de una sesión después de que /compact u otro comando de barra se ejecutara a través de -p --resume: un falso "Continuar desde donde lo dejó". el turno ya no está insertado
  • Se corrigió la reanudación de una sesión grande (transcripción de más de 5 MB): las llamadas a herramientas paralelas y su salida de enlace ya no se eliminan de la conversación recargada.
  • Se corrigieron allowedHttpHookUrls, httpHookAllowedEnvVars y allowedChannelPlugins administrados para admitir nada, no todo, cuando son ilegibles.
  • Se corrigió /login en máquinas cuyas configuraciones administradas requieren el inicio de sesión en la puerta de enlace de aplicaciones de Claude: Esc ahora cierra el cuadro de diálogo en lugar de no hacer nada.
  • Se corrigieron las publicaciones de artefactos cortadas por una conexión interrumpida durante la carga: ahora reintentan una vez cuando Claude Code puede indicar que la carga nunca se completó, en lugar de informar un resultado desconocido.
  • Se corrigió el front-matter de effort: en comandos personalizados, habilidades y subagentes que se ignoraban en modelos cuyo esfuerzo predeterminado aún estaba fijado (Opus 4.7, Opus 4.8, Fable 5).
  • Se corrigió el error de publicación de artefactos con un error inútil cuando el archivo de página no es UTF-8 válido o contiene un carácter de reemplazo (U+FFFD); el error ahora nombra la línea y la columna a corregir
  • Se corrigió el menú del directorio claude agents @ que no enumeraba los repositorios creados después del inicio de la sesión.
  • Se corrigieron los clients de control remoto que se unían a una sesión de Claude Desktop o VS Code que mostraban un modo de permiso obsoleto hasta que se cambiaba nuevamente.
  • Se corrigió que claude remote-control saliera y abandonara cada sesión adjunta cuando su credencial de servidor expira (aproximadamente 30 días después del inicio); el anfitrión ahora se vuelve a registrar y continúa
  • Se corrigió la advertencia de límite de uso que parpadeaba durante una sesión cuando las solicitudes de diferentes modelos o modos informaban diferentes ventanas de límite
  • Se corrigió el razonamiento anterior que se eliminaba cuando un servidor MCP reenviaba, o una herramienta incorporada volvía a renderizar, una herramienta que el modelo ya había cargado.
  • Se corrigió una herramienta que desaparecía en mitad de una conversación, desde un servidor MCP desconectado o una actualización, reescribiendo la lista de herramientas y descartando pensamientos anteriores.
  • Se corrigió un trabajador en segundo plano bifurcado de una conversación al agregar EnterWorktree al bloque de herramientas de la conversación a mitad de sesión, lo que interrumpió la reutilización de la caché de avisos.
  • Se corrigió la adición de herramientas MCP y complementos a mitad de sesión a la lista de herramientas en sesiones sin ToolSearch, lo que interrumpió la reutilización de la caché de avisos; Los modelos compatibles ahora las reciben como definiciones diferidas.
  • Se corrigió el cambio de modelos con /model reenviando cada definición de herramienta (un error en el aviso de caché); El texto de confirmación y atribución de relaciones públicas ahora llega como una nota de conversación que actualiza los cambios del modelo.
  • Se corrigieron las sesiones reanudadas que reescribían el conjunto de herramientas en línea cuando un conector MCP se reconecta en un momento diferente al anterior.
  • Se corrigieron las sesiones reanudadas que volvían a renderizar descripciones de herramientas en lugar de reproducir las grabadas cuando el primer turno ejecutó una herramienta.
  • Se corrigieron errores de caché de aviso y se eliminó el pensamiento extendido cuando las herramientas de un conector claude.ai cambian entre una sesión y su reanudación.
  • Se corrigieron las sesiones reanudadas que reescribían anuncios anteriores de herramientas MCP (y eliminaban el pensamiento extendido) antes de que sus conectores se volvieran a conectar.
  • Se corrigió una interrupción del caché de aviso cuando una conversación en modo de impresión (-p) se reanuda de forma interactiva: el prefijo de aviso del sistema ya no cambia
  • Mejorado el panel /diff: ya no parpadea "0 archivos cambiados" y una rueda antes de establecerse, y su estado vacío está centrado en el panel
  • Se mejoró la guía de descripción de la herramienta Bash para que Claude describa lo que hace un comando con palabras sencillas en lugar de repetir el comando.
  • Guía de sandbox mejorada para que Claude sugiera /copy cuando los comandos del tablero cli como pbcopy fallan dentro del sandbox
  • Tiempo de primer renderizado de --resume mejorado para sesiones con muchas llamadas a herramientas Bash
  • Capacidad de respuesta de entrada rápida mejorada: las pulsaciones de teclas ya no esperan ocasionalmente un cuadro detrás del control giratorio o los repintados de transmisión
  • Estabilidad de caché de avisos mejorada: los subagentes y las sesiones iniciadas con --system-prompt o --append-system-prompt ahora registran el aviso del sistema y las definiciones de herramientas una vez en lugar de volver a renderizarlas.
  • Errores de publicación de la herramienta Artifact mejorados: cuando se rechaza una publicación, el mensaje ahora dice por qué y qué hacer al respecto.
  • Ejecutor autohospedado: se modificó --use-anthropic-git-proxy para que se informe al servidor en el momento del registro y para imprimir una advertencia para cada sesión que aún se clona a través del proxy git heredado.
  • Puerta de enlace: se modificó el flujo ascendente de forward_user_identity para devolver un 429 tal como está a un desarrollador cuyo correo electrónico se reenvió, en lugar de conmutar por error al siguiente flujo ascendente, por lo que se mantienen los límites por usuario del proxy.
  • [VSCode] Se corrigió que el host de la extensión se colgara al 100% de la CPU al bifurcar, editar un mensaje anterior o rebobinar una conversación cuya transcripción guardada contiene un enlace principal cyclic.
  • [VSCode] Se corrigió al pegar una captura de pantalla en WSL2/WSLg insertando bytes de imagen sin procesar en la entrada del chat; la imagen ahora se adjunta cuando la placa clipboard la proporciona; de lo contrario, se ignora el pegado
  • [VSCode] Se corrigieron los bloques de diferencias de chat que siempre se mostraban con un tema de editor oscuro; ahora siguen el tema de color activo de VS Code, incluido el alto contraste
  • [VSCode] Se corrigió la representación de texto mixto de derecha a izquierda y en inglés en el orden incorrecto al escribir la entrada del mensaje.
  • [VSCode] Se corrigió el error al aceptar una edición en la vista de diferencias en un archivo con finales de línea de Windows (CRLF) con "Cadena no encontrada en el archivo".
  • [VSCode] Se corrigieron @-menciones que eliminan archivos cuyas rutas contienen espacios
  • [VSCode] Se corrigió la vista de lista de sesiones que no se cargaba en Windows conectadas a través de SSH remoto cuando la carpeta del espacio de trabajo existe solo en el host remoto.
  • [VSCode] Se corrigieron procesos de ripgrep fuera de control al visualizar archivos en espacios de trabajo grandes o con muchos enlaces simbólicos.
  • [Código Claude en la web] Se corrigieron las sesiones del servidor empresarial GitHub que mostraban su cuenta GitHub como desconectada una vez que su token expiraba; Las operaciones de relaciones públicas y problemas ahora lo actualizan automáticamente
  • [Código Claude en la web] Se corrigieron llamadas gh y GitHub API que fallaban en organizaciones sin la aplicación Claude GitHub; ahora usan su cuenta GitHub conectada y lo dicen cuando no hay ninguna conectada
  • [Claude Tag] Se agregó un enlace "Usar un conector personalizado" a los formularios de conexión preestablecidos en la configuración de administración de Claude Tag, para que puedas cambiar a una conexión personalizada sin comenzar de nuevo.
  • [Etiqueta de Claude] Se corrigió que Claude respondiera "El API rechazó la solicitud por considerarla no válida" cuando la organización se quedó sin créditos de uso; la respuesta ahora lo dice y explica cómo agregar más
  • [Etiqueta de Claude] Se corrigió que las solicitudes de hilo para editar o eliminar un mensaje que Claude publicó en el nivel superior del canal fueran respondidas con una corrección en lugar de llegar a la sesión que lo publicó.
  • [Claude Tag] Se corrigió Conectar en solicitudes de acceso a herramientas en Configuración de administrador > Revisar solicitudes que fallaban con "Error de autorización" o mostraban el paquete de acceso solicitado como eliminado

claude-code v2.1.267

What's changed

  • Added maxEffortLevel setting (top-level or per model under modelSettings): caps the effort level on every provider, including Bedrock, Vertex and Foundry; users can still pick a lower level
  • Added --system-prompt-snapshot off to render the system prompt fresh on every request instead of reusing the conversation's recorded prompt (for iterating on prompt text)
  • Fixed Cowork scheduled tasks in the cloud failing at startup for organizations whose managed settings require sandboxing
  • Fixed /context and other local command output rendering blank on mobile clients
  • Fixed shift+enter and option+backspace not working after reconnecting to a tmux or ssh session inside an agent view
  • Fixed the dim last-prompt header not appearing at the top of the conversation when scrolling up in fullscreen mode
  • Fixed Workflow agent() calls with large output schemas being refused in auto mode instead of being checked by the safety classifier
  • Fixed a case where a marketplace entry path containing a backslash could bypass the containment check for fetched marketplaces on macOS and Linux
  • Fixed expired AWS or Google Cloud credentials under a host app such as Claude Desktop retrying ten times with a generic "request failed" before the re-authenticate error appeared
  • Fixed resuming a session after /compact or another slash command ran via -p --resume: a spurious "Continue from where you left off." turn is no longer inserted
  • Fixed resuming a large session (transcript over 5 MB): parallel tool calls and their hook output are no longer dropped from the reloaded conversation
  • Fixed managed allowedHttpHookUrls, httpHookAllowedEnvVars and allowedChannelPlugins to admit nothing, not everything, when unreadable
  • Fixed /login on machines whose managed settings require Claude apps gateway sign-in: Esc now closes the dialog instead of doing nothing
  • Fixed artifact publishes cut off by a dropped connection mid-upload: they now retry once when Claude Code can tell the upload never completed, instead of reporting an unknown outcome
  • Fixed effort: frontmatter on custom commands, skills, and subagents being ignored on models whose default effort is still pinned (Opus 4.7, Opus 4.8, Fable 5)
  • Fixed artifact publish failing with an unhelpful error when the page file isn't valid UTF-8 or contains a replacement character (U+FFFD); the error now names the line and column to fix
  • Fixed claude agents @ directory menu not listing repositories created after the session started
  • Fixed Remote Control clients that join a Claude Desktop or VS Code session showing a stale permission mode until it was changed again
  • Fixed claude remote-control exiting and dropping every attached session when its server credential expires (about 30 days after start); the host now re-registers and keeps going
  • Fixed the usage-limit warning flickering on and off during a session when requests for different models or modes report different limit windows
  • Fixed earlier reasoning being dropped when an MCP server re-sends, or a built-in tool re-renders, a tool the model already loaded
  • Fixed a tool that disappears mid-conversation, from a disconnected MCP server or an upgrade, rewriting the tool list and discarding earlier thinking
  • Fixed a background worker forked from a conversation adding EnterWorktree to the conversation's tool block mid-session, which broke prompt-cache reuse
  • Fixed mid-session MCP and plugin tools being added to the tool list in sessions without ToolSearch, which broke prompt-cache reuse; supported models now receive them as deferred definitions
  • Fixed switching models with /model re-sending every tool definition (a prompt-cache miss); commit and PR attribution text now arrives as a conversation note that updates on model changes
  • Fixed resumed sessions rewriting the inline tool set when an MCP connector reconnects at a different moment than before
  • Fixed resumed sessions re-rendering tool descriptions instead of replaying the recorded ones when the first turn ran a tool
  • Fixed prompt-cache misses and dropped extended thinking when a claude.ai connector's tools change between a session and its resume
  • Fixed resumed sessions rewriting earlier MCP tool announcements (and dropping extended thinking) before their connectors reconnect
  • Fixed a prompt-cache break when a print-mode (-p) conversation is resumed interactively: the system prompt prefix no longer changes
  • Improved the /diff panel: it no longer flashes "0 files changed" and a spinner before settling, and its empty state is centered in the panel
  • Improved the Bash tool's description guidance so Claude describes what a command does in plain words instead of echoing the command
  • Improved sandbox guidance so Claude suggests /copy when clipboard commands such as pbcopy fail inside the sandbox
  • Improved --resume first-render time for sessions with many Bash tool calls
  • Improved prompt input responsiveness: keystrokes no longer occasionally wait a frame behind spinner or streaming repaints
  • Improved prompt-cache stability: subagents and sessions started with --system-prompt or --append-system-prompt now record the system prompt and tool definitions once instead of re-rendering them
  • Improved Artifact tool publish errors: when a publish is refused, the message now says why and what to do about it
  • Self-hosted runner: Changed --use-anthropic-git-proxy to be reported to the server at registration and to print a warning for each session that still clones through the legacy git proxy
  • Gateway: Changed forward_user_identity upstreams to return a 429 as-is to a developer whose email was forwarded, instead of failing over to the next upstream, so the proxy's per-user limits hold
  • [VSCode] Fixed the extension host hanging at 100% CPU when forking, editing an earlier message, or rewinding in a conversation whose saved transcript contains a cyclic parent link
  • [VSCode] Fixed pasting a screenshot on WSL2/WSLg inserting raw image bytes into the chat input; the image is now attached when the clipboard provides it, otherwise the paste is ignored
  • [VSCode] Fixed chat diff blocks always rendering with a dark editor theme; they now follow the active VS Code color theme, including high contrast
  • [VSCode] Fixed mixed right-to-left and English text rendering in the wrong order while typing in the message input
  • [VSCode] Fixed accepting an edit in the diff view on a file with Windows (CRLF) line endings failing with "String not found in file"
  • [VSCode] Fixed @-mentions dropping files whose paths contain spaces
  • [VSCode] Fixed the sessions list view failing to load in windows connected over Remote-SSH when the workspace folder exists only on the remote host
  • [VSCode] Fixed runaway ripgrep processes when viewing files in large or symlink-heavy workspaces
  • [Claude Code on the web] Fixed GitHub Enterprise Server sessions showing your GitHub account as disconnected once its token expired; PR and issue operations now refresh it automatically
  • [Claude Code on the web] Fixed gh and GitHub API calls failing in organizations without the Claude GitHub App; they now use your connected GitHub account and say so when none is connected
  • [Claude Tag] Added a "Use a custom connector" link to the preset connection forms in Claude Tag admin settings, so you can switch to a custom connection without starting over
  • [Claude Tag] Fixed Claude replying "The API rejected the request as invalid" when the organization has run out of usage credits; the reply now says so and explains how to add more
  • [Claude Tag] Fixed thread requests to edit or delete a message Claude posted at the channel's top level being answered with a correction instead of reaching the session that posted it
  • [Claude Tag] Fixed Connect on Tool access requests under Admin settings > Review requests failing with "Authorization failed" or showing the requested access bundle as deleted
