código-claude v2.1.309

¿Qué ha cambiado?

  • Se corrigieron los comandos Bash en el espacio aislado en macOS y Linux ejecutando los archivos de inicio del shell fuera del espacio aislado antes de cada comando.
  • Se corrigió que los patrones globales denyWrite del sandbox de macOS no se aplicaran en la ubicación real de una ruta cuando se llega a la carpeta del patrón a través de un enlace simbólico.
  • Se corrigieron los comandos de espacio aislado y las ediciones aceptadas automáticamente que podían modificar el archivo de configuración de MCP pasado con --mcp-config.
  • Se corrigió que un servidor MCP deshabilitado se reconectara mediante un mensaje de permiso posterior en sesiones de impresión y SDK.
  • Se corrigió la verificación de permisos de Bash trust al establecer una variable establecida por un comando cuya redirección puede no abrirse
  • Se corrigieron las comprobaciones de permisos de Bash que no solicitaban algunos comandos compuestos que cambiaban de directorio antes de ejecutar git cuando cd estaba ajustado o prefijado, como lo hacen para un cd simple.
  • Se corrigió una regla de denegación de Edit(path) que no bloqueaba una redirección de Bash a esa ruta en algunos comandos que también contenían un subshell.
  • Se corrigieron sesiones aisladas del árbol de trabajo que aceptaban algunos comandos con prefijo local que el guardia de aislamiento debería rechazar.
  • Se corrigieron sesiones aisladas del árbol de trabajo en zsh que aceptaban algunos comandos aritméticos que el guardia de aislamiento debería rechazar.
  • Se corrigieron los árboles de trabajo y las sucursales que crea Claude Code para que ignoren las referencias de reemplazo de git, como ya lo hacen sus otras operaciones de git.
  • Se corrigió la protección contra escritura del almacén de perfiles que no se aplica cuando se accede al directorio de configuración a través de un enlace simbólico.
  • Se corrigió la compactación repetida de sesiones después de leer archivos en un CLAUDE.md anidado muy grande; un CLAUDE.md anidado por encima del límite de tamaño ahora carga solo su inicio
  • Se corrigió que Ctrl+Intro (enviar ahora) solo ponía en cola un mensaje cuando se presionaba antes de que comenzara la respuesta, y reiniciaba los enlaces de un mensaje mientras se dejaba el mensaje en cola cuando se presionaba mientras esos enlaces se estaban ejecutando.
  • Se corrigieron los comandos de barra diagonal que se ejecutan en el shell desde el modo !.
  • Se corrigió que Ctrl+o no mostrara mensajes de otros agentes y sesiones que aún están esperando ser entregadas; ahora aparecen completos debajo de la transcripción, marcados como en espera
  • Se corrigieron las vistas previas largas de salida de herramientas que se cortaban a través de un emoji, dejando transcripciones de sesión que jq no podía analizar.
  • Se corrigió el informe de lectura "El archivo no existe" para rangos de páginas PDF en entornos limitados de Linux que comparten el /proc principal.
  • Se corrigieron los mensajes de una sesión alojada en Claude Desktop que a veces se perdían cuando se actualizaba la conexión.
  • Se corrigieron funciones que faltaban en las sesiones de Claude Code en la aplicación de escritorio de Claude cuando el terminal en la misma computadora iniciaba sesión en una cuenta u organización diferente.
  • Se corrigió la línea de estado de claude remote-control que mostraba HEAD como la rama de una carpeta que no está en un repositorio de git.
  • Se corrigió que los compañeros de equipo de los agentes del panel dividido no heredaran la herramienta denegar y las reglas --tools proporcionadas en la línea de comando del líder.
  • Se corrigió el cambio de nombre de las sesiones con /rename apareciendo en otras sesiones con un nombre generado después de una recarga de la ventana de VS Code o un --resume no interactivo.
  • Se corrigió la lista /rewind que mostraba "Sin cambios de código" para un turno que cambiaba archivos con puntos de control a través de /code-review --fix, un subagente o un comando de shell.
  • Se corrigió /privacy-settings que mostraba un valor desactualizado "Ayuda a mejorar nuestros modelos de IA"; Ahora también dice cuando no se puede recuperar la configuración.
  • Se corrigieron los comentarios que decían "inténtalo de nuevo más tarde" cuando tu organización no acepta comentarios; ahora muestra el motivo del servidor y dónde informar un error
  • Se corrigieron errores en los informes de comentarios/de gran tamaño en lugar de reenviarse sin la transcripción
  • Se corrigió que una habilidad en una carpeta --add-dir fuera inalcanzable cuando otra habilidad ya tenía su nombre; ahora se ofrece como <folder>:<name>
  • Se corrigió que /verify y /code-review no encontraran la habilidad propia de un paquete anidado cuando sus archivos se cambiaban desde el shell.
  • Se corrigió la habilidad /claude-api que decía que ant beta:worker poll --on-work pasa el contexto de seguimiento al comando.
  • Se corrigió la configuración de seguimiento de C# de la habilidad /claude-api que faltaba en la plataforma en la nube clients.
  • Se corrigió la habilidad /claude-api que decía que API abarca solicitudes a Claude Platform en AWS y no puede unirse al seguimiento de la persona que llama.
  • Se corrigieron los ganchos que se ejecutan en PowerShell que no se bloquean cuando el programa del gancho sale con el código 2, y en Windows los ganchos PreToolUse y PermissionRequest con "shell": "powershell" no se abren cuando Git para Windows no está instalado.
  • Se corrigió el gancho turn.step de un mod que nombra un modelo por alias, como haiku, fallando cada solicitud con un error de modelo: el alias ahora se resuelve en su modelo
  • Se corrigieron los complementos y habilidades sincronizados desde claude.ai que se eliminaban, a veces a mitad de sesión, después de un error de lectura del disco.
  • Se corrigió el rechazo de publicaciones y actualizaciones de artefactos para algunas páginas comunes, como páginas con ciertos scripts minimizados o artefactos que Claude no pudo leer primero.
  • Se corrigió que Claude pidiera permiso en cada actualización de artefacto por el resto de un turno después de que la conversación fuera compactada en ese turno.
  • Se corrigió que la transmisión de herramientas detalladas permaneciera desactivada en Amazon Bedrock cuando ANTHROPIC_BEDROCK_BASE_URL está configurado en el punto final predeterminado bedrock-runtime.<region>.amazonaws.com.
  • Se corrigió la sugerencia "Esperando respuesta API" que parpadeaba detrás de las puertas de enlace que solo envían pings de mantenimiento de actividad: las rutas fuera del backend de Anthropic ahora esperan 45 segundos.
  • Se corrigió que Claude notificara a usuarios GitHub no relacionados escribiendo nombres de roles y marcadores de posición como menciones en relaciones públicas, problemas y comentarios.
  • Linux: Se corrigió la escritura en la zona de pruebas que niega el levantamiento cuando un comando en segundo plano sobrevivió a la sesión
  • Windows: Se corrigieron las comprobaciones de permisos de PowerShell que aprueban automáticamente algunos comandos Set-Location o cd que apuntan al directorio actual y contienen argumentos adicionales; estos ahora solicitan aprobación
  • macOS: se corrigió el cuadro de diálogo "Instalar herramientas de desarrollo de línea de comandos" que se abría cada vez que Claude Code se inicia en una Mac sin Xcode o las herramientas de línea de comandos.
  • Ejecutor autohospedado: se corrigió que --startup-timeout-min detuviera una sesión cuyo primer mensaje, como /code-review, todavía estaba funcionando en un subagente; un proceso congelado todavía está detenido
  • Se mejoró la velocidad de muchos comandos de git que Claude Code ejecuta por sí solo en Windows; En todas las plataformas, los errores de esos comandos ahora se muestran en inglés incluso cuando git está configurado en otro idioma.
  • Se mejoró el error cuando un módulo de ganchos está anidado demasiado profundo para cargarlo: ahora nombra el archivo en lugar de mostrar un mensaje de desbordamiento de pila simple.
  • Manejo mejorado de disco lleno: un comando Bash cortado por un disco lleno ahora lo dice y nombra la carpeta para liberar, y al comenzar con un volumen temporal completo se imprime un mensaje claro, no un error ENOSPC sin formato.
  • Se mejoró la habilidad /claude-api para ofrecer el rastreo API junto con el rastreo SDK cuando se le solicita agregar OpenTelemetry.
  • Se mejoró la habilidad /claude-api para verificar los documentos en vivo antes de decir que una función no es compatible.
  • Ejecutor autohospedado: sesiones mejoradas que pasan a un nuevo ejecutor: Claude ahora ve la llamada a la herramienta que se interrumpió, marcada como resultado desconocido
  • Se actualizó la habilidad de visualización de datos incluida para aceptar APCA como medida de contraste de texto (manteniendo las proporciones WCAG 2 cuando se requiere conformidad AA), agregar una función apca(text, background) a sus secuencias de comandos de validación de paleta y decir si una etiqueta dentro de un relleno de gráfico de color debe ser blanca o casi negra.
  • Se actualizó la habilidad /claude-api: las claves de cuenta de servicio y los tokens de Workload Identity Federation ahora pueden administrar destinos OpenTelemetry.
  • Se modificó sed -i para obtener el mensaje Bash estándar y ejecutarlo tal como está escrito, no una vista previa simulada de edición de archivos; Al igual que otras ediciones de Bash, /rewind ya no lo restaura.
  • Se modificó claude ultrareview para requerir el espacio de trabajo trust: pregunta en una terminal, de lo contrario se niega; los scripts pasan --trust-workspace, que no toma ningún valor (ponga un número PR o una rama base antes), o configura CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1
  • Se cambiaron los peligrosos mensajes rm y rmdir en el modo de omisión de permisos en la aplicación de escritorio y VS Code para denegar el comando de inmediato con una sugerencia de reescritura, para que las sesiones desatendidas continúen.
  • Se cambiaron los comandos que la configuración excluye del sandbox para preguntar antes de escribir en sus rutas de lista de escritura mientras el sandbox está habilitado pero no se puede ejecutar; el respaldo sin espacio aislado se rechaza allí
  • Se modificó la creación y reutilización del árbol de trabajo para que git ya no busque objetos bajo demanda, en clones ordinarios y en clones parciales con un entorno limitado de Bash configurado; un clon tan parcial los trae primero
  • Se modificó la habilidad /claude-api para crear equipos de subagentes de agentes administrados en multiagent_20261001 con flujos de trabajo dinámicos activados de forma predeterminada, en lugar de coordinator.
  • [VSCode] Se agregó una advertencia de registro que dice qué hacer cuando el dictado o las solicitudes propias de la extensión fallan en la verificación del certificado, como detrás de un proxy de inspección TLS.
  • [VSCode] Se corrigió que el panel Claude permaneciera en blanco después de que el editor almacenara en caché una copia incompleta de sus archivos; ahora se recupera solo o dice qué salió mal y cómo solucionarlo
  • [VSCode] Se corrigió que el historial de sesiones se llenara con sesiones vacías "Sin título" cada vez que inicias una nueva sesión sin enviar un mensaje
  • [VSCode] Se corrigieron mensajes largos con comandos de barra diagonal como /goal que llenaban el panel de chat; ahora se pliegan detrás Mostrar más como otras indicaciones (anthropics/claude-code#97469)
  • [VSCode] Se corrigieron los mensajes largos que no se pliegan detrás de Mostrar más después de que el panel de chat se haga más estrecho
  • [VSCode] Se corrigió Ctrl+J en la entrada del chat que siempre insertaba una nueva línea: ahora se deja en manos de VS Code y el sistema operativo cuando "ctrl+j" se establece en nulo en el contexto de chat de ~/.claude/keybindings.json
  • [VSCode] Se corrigió la etiqueta "Desde el... complemento" de un mod encima del mensaje que se dibuja sobre el comando de barra diagonal y los menús @-mention (anthropics/claude-code#102981)
  • [VSCode] Se corrigió un elemento de lista, párrafo o bloque de código vacío y elementos de lista renumerados de 1, al pegar matemáticas LaTeX copiadas.
  • [VSCode] Se corrigió el error de comentarios que mostraba solo un estado HTTP cuando su organización no acepta comentarios
  • [VSCode] Velocidad de edición y escritura mejorada en el panel de chat: la espera por nuevos problemas después de cada edición ahora es de 0.75 segundos en la mayoría de los casos, en comparación con 1 a 1.5 segundos.
  • [Sesiones en la nube] Se corrigió la lista Agregar conector en formularios de rutina que indicaba que no había conectores disponibles mientras aún se estaban cargando.
  • [Sesiones en la nube] Se corrigió que el editor del entorno de la nube mezclara variables de entorno y agregara barras invertidas a los valores que contienen ambos tipos de comillas.
  • [Sesiones en la nube] Se corrigió el cuadro de diálogo de detalles del entorno autohospedado en la configuración de administrador para que su título, pestañas y botones permanezcan visibles mientras solo se desplaza el contenido.
  • [Sesiones en la nube] Se corrigió la fila de la herramienta "leer documentación" en las sesiones en la nube, que mostraba JSON escapado en lugar de una página legible.
  • [Sesiones en la nube] Se mejoró el panel de cambios de una sesión en la nube, que ahora indica cuándo enumera solo las confirmaciones enviadas o solo las ediciones de Claude.
  • [Etiqueta de Claude] Se corrigió que Claude en Slack publicara por error un borrador que usted aprobó para un canal en su DM; una publicación sin canal ahora se rechaza para que pueda ir al canal aprobado
  • [Etiqueta de Claude] Se corrigió Permitir y Denegar en las tarjetas de aprobación de Claude en Slack sin hacer nada cuando la sesión se había detenido; tu respuesta ahora reinicia la sesión
  • [Etiqueta de Claude] Se corrigió que Claude ignorara los mensajes sin etiquetar en un canal de Slack después de que su espacio de trabajo se moviera a una organización de Claude diferente, incluidos los canales no compartidos en Enterprise Grid.
  • [Etiqueta de Claude] Se corrigió que Claude en un canal de Slack publicara una respuesta en un hilo antes de leer un mensaje más nuevo que alguien acababa de agregar a ese hilo.
  • [Claude Tag] Se corrigió la página de Slack en la configuración de administración de Claude Tag que decía que no había espacios de trabajo conectados cuando la lista no se cargaba; ahora muestra un error con un botón Reintentar
  • [Revisión de código] Se corrigió una revisión terminada que mostraba que no se verificaba la solicitud de extracción cuando los intentos anteriores de crearla fallaron; un último intento ahora agrega una verificación completa
  • [Revisión de código] Se corrigió un envío en cola detrás de una revisión en ejecución que aún iniciaba una revisión después de @claude review stop; su cheque ahora se cierra y dice por qué

claude-code v2.1.309

What's changed

  • Fixed sandboxed Bash commands on macOS and Linux running the shell's startup files outside the sandbox before each command
  • Fixed macOS sandbox denyWrite glob patterns not applying at a path's real location when the pattern's folder is reached through a symlink
  • Fixed sandboxed commands and auto-accepted edits being able to modify the MCP config file passed with --mcp-config
  • Fixed a disabled MCP server being reconnected by a later permission prompt in print and SDK sessions
  • Fixed the Bash permission check trusting a variable set by a command whose redirect can fail to open
  • Fixed Bash permission checks not prompting for some compound commands that change directory before running git when the cd is wrapped or prefixed, as they do for a plain cd
  • Fixed an Edit(path) deny rule not blocking a Bash redirect to that path in some commands that also held a subshell
  • Fixed worktree-isolated sessions accepting some locale-prefixed commands the isolation guard should refuse
  • Fixed worktree-isolated sessions on zsh accepting some arithmetic commands that the isolation guard should refuse
  • Fixed worktrees and branch checkouts that Claude Code creates so they ignore git replace refs, as its other git operations already do
  • Fixed profile store write protection not applying when the config directory is reached through a symlink
  • Fixed sessions compacting repeatedly after reading files under a very large nested CLAUDE.md; a nested CLAUDE.md over the size limit now loads only its start
  • Fixed ctrl+enter (send now) only queuing a message when pressed before the response had started, and restarting a prompt's hooks while leaving the message queued when pressed while those hooks were running
  • Fixed key-bound slash commands running in the shell from ! mode
  • Fixed ctrl+o not showing messages from other agents and sessions that are still waiting to be delivered; they now appear in full under the transcript, marked as waiting
  • Fixed long tool output previews being cut through an emoji, leaving session transcripts that jq could not parse
  • Fixed Read reporting "File does not exist" for PDF page ranges in Linux sandboxes that share the parent's /proc
  • Fixed messages from a Claude Desktop-hosted session sometimes being lost when its connection refreshed
  • Fixed features missing from Claude Code sessions in the Claude desktop app when the terminal on the same computer was signed in to a different account or organization
  • Fixed the claude remote-control status line showing HEAD as the branch for a folder that is not in a git repository
  • Fixed split-pane agent teammates not inheriting the tool deny and --tools rules given on the leader's command line
  • Fixed sessions renamed with /rename appearing to other sessions under a generated name after a VS Code window reload or a non-interactive --resume
  • Fixed the /rewind list showing "No code changes" for a turn that changed checkpointed files through /code-review --fix, a subagent or a shell command
  • Fixed /privacy-settings showing an out-of-date "Help improve our AI models" value; it now also says when the setting can't be fetched
  • Fixed feedback saying "try again later" when your organization does not accept feedback; it now shows the server's reason and where to report a bug
  • Fixed oversized /feedback reports failing instead of being resent without the transcript
  • Fixed a skill in an --add-dir folder being unreachable when another skill already held its name; it is now offered as <folder>:<name>
  • Fixed /verify and /code-review not finding a nested package's own skill when its files were changed from the shell
  • Fixed the /claude-api skill saying that ant beta:worker poll --on-work passes trace context to the command
  • Fixed the /claude-api skill's C# tracing setup missing spans from the cloud platform clients
  • Fixed the /claude-api skill saying that API spans for requests to Claude Platform on AWS can't join the caller's trace
  • Fixed hooks that run in PowerShell not blocking when the hook's program exits with code 2, and on Windows PreToolUse and PermissionRequest hooks with "shell": "powershell" failing open when Git for Windows isn't installed
  • Fixed a mod's turn.step hook that names a model by alias, such as haiku, failing every request with a model error: the alias now resolves to its model
  • Fixed plugins and skills synced from claude.ai being removed, sometimes mid-session, after a disk read error
  • Fixed artifact publishes and updates being refused for some ordinary pages, such as pages with certain minified scripts or artifacts Claude could not read first
  • Fixed Claude asking for permission on each artifact update for the rest of a turn after the conversation was compacted in that turn
  • Fixed fine-grained tool streaming staying off on Amazon Bedrock when ANTHROPIC_BEDROCK_BASE_URL is set to the default bedrock-runtime.<region>.amazonaws.com endpoint
  • Fixed the "Waiting for API response" hint flickering behind gateways that send only keepalive pings: routes off Anthropic's backend now wait 45 seconds
  • Fixed Claude notifying unrelated GitHub users by writing role names and placeholders as mentions in PRs, issues and comments
  • Linux: Fixed sandbox write denies lifting when a background command outlived the session
  • Windows: Fixed PowerShell permission checks auto-approving some Set-Location or cd commands that target the current directory and carry extra arguments; these now prompt for approval
  • macOS: Fixed the "Install Command Line Developer Tools" dialog opening each time Claude Code starts on a Mac without Xcode or the Command Line Tools
  • Self-hosted runner: Fixed --startup-timeout-min stopping a session whose first prompt, such as /code-review, was still working in a subagent; a frozen process is still stopped
  • Improved the speed of many git commands Claude Code runs for itself on Windows; on every platform, errors from those commands now show in English even when git is set to another language
  • Improved the error when a hooks module is nested too deep to load: it now names the file instead of showing a bare stack-overflow message
  • Improved disk-full handling: a Bash command cut off by a full disk now says so and names the folder to free up, and starting on a full temp volume prints a clear message, not a raw ENOSPC error
  • Improved the /claude-api skill to offer API tracing alongside SDK tracing when asked to add OpenTelemetry
  • Improved the /claude-api skill to check the live docs before saying a feature is unsupported
  • Self-hosted runner: Improved sessions that move to a new runner: Claude now sees the tool call that was interrupted, marked as outcome unknown
  • Updated the bundled dataviz skill to accept APCA as a text-contrast measure (keeping WCAG 2 ratios where AA conformance is required), add an apca(text, background) function to its palette validator scripts, and say whether a label inside a colored chart fill should be white or near-black
  • Updated the /claude-api skill: service account keys and Workload Identity Federation tokens can now manage OpenTelemetry destinations
  • Changed sed -i to get the standard Bash prompt and run as written, not a simulated file-edit preview; like other Bash edits, it is no longer restored by /rewind
  • Changed claude ultrareview to require workspace trust: it asks on a terminal, else refuses; scripts pass --trust-workspace, which takes no value (put a PR number or base branch before it), or set CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1
  • Changed the dangerous rm and rmdir prompt in bypass permissions mode in the Desktop app and VS Code to deny the command at once with a rewrite hint, so unattended sessions keep going
  • Changed commands the settings exclude from the sandbox to ask before writing to its write-list paths while the sandbox is enabled but cannot run; the unsandboxed fallback is refused there
  • Changed worktree creation and reuse so git no longer fetches objects on demand, in ordinary clones and in partial clones with a Bash sandbox configured; such a partial clone fetches them first
  • Changed the /claude-api skill to build Managed Agents subagent teams on multiagent_20261001 with dynamic workflows on by default, instead of coordinator
  • [VSCode] Added a log warning that says what to do when dictation or the extension's own requests fail certificate verification, such as behind a TLS-inspecting proxy
  • [VSCode] Fixed the Claude panel staying blank after the editor cached an incomplete copy of its files; it now recovers by itself, or says what went wrong and how to fix it
  • [VSCode] Fixed Session history filling up with empty "Untitled" sessions each time you start a new session without sending a message
  • [VSCode] Fixed long slash-command messages such as /goal filling the chat panel; they now fold behind Show more like other prompts (anthropics/claude-code#97469)
  • [VSCode] Fixed long messages not folding behind Show more after the chat panel is made narrower
  • [VSCode] Fixed Ctrl+J in the chat input always inserting a newline: it is now left to VS Code and the OS when "ctrl+j" is set to null in the Chat context of ~/.claude/keybindings.json
  • [VSCode] Fixed a mod's "From the … plugin" label above the prompt being drawn over the slash command and @-mention menus (anthropics/claude-code#102981)
  • [VSCode] Fixed an empty list item, paragraph or code block, and list items renumbered from 1, when pasting copied LaTeX math
  • [VSCode] Fixed the feedback error showing only an HTTP status when your organization does not accept feedback
  • [VSCode] Improved Edit and Write speed in the chat panel: the wait for new problems after each edit is now 0.75 seconds in most cases, down from 1 to 1.5 seconds
  • [Cloud sessions] Fixed the Add connector list in routine forms saying no connectors were available while they were still loading
  • [Cloud sessions] Fixed the cloud environment editor shuffling environment variables and adding backslashes to values that contain both kinds of quote
  • [Cloud sessions] Fixed the self-hosted environment details dialog in admin settings so its title, tabs and buttons stay in view while only the content scrolls
  • [Cloud sessions] Fixed the "read documentation" tool row in cloud sessions, which showed escaped JSON instead of a readable page
  • [Cloud sessions] Improved a cloud session's Changes pane, which now says when it lists only pushed commits or only Claude's edits
  • [Claude Tag] Fixed Claude in Slack posting a draft you approved for a channel into your DM by mistake; a post with no channel is now refused so it can go to the approved channel
  • [Claude Tag] Fixed Allow and Deny on Claude's approval cards in Slack doing nothing when the session had stopped; your answer now restarts the session
  • [Claude Tag] Fixed Claude ignoring untagged messages in a Slack channel after its workspace moved to a different Claude organization, including unshared channels on Enterprise Grid
  • [Claude Tag] Fixed Claude in a Slack channel posting a threaded reply before reading a newer message someone had just added to that thread
  • [Claude Tag] Fixed the Slack page in Claude Tag admin settings saying no workspaces were connected when the list failed to load; it now shows an error with a Retry button
  • [Code Review] Fixed a finished review showing no check on the pull request when earlier tries to create it failed; a final try now adds a completed check
  • [Code Review] Fixed a push queued behind a running review still starting a review after @claude review stop; its check now closes and says why
