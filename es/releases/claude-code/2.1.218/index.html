código-claude v2.1.218

¿Qué ha cambiado?

  • Se modificó /code-review para que se ejecute como subagente en segundo plano, por lo que el trabajo de revisión ya no llena su conversación y mantiene los comandos de barra diagonal apilados como objetivo de revisión.
  • Se agregaron anuncios en el lector de pantalla de texto eliminado para eliminaciones de palabras y líneas (Option+Delete, Ctrl+W, Cmd+Backspace, Ctrl+U, Ctrl+K) en el modo --ax-screen-reader.
  • Se corrigieron rutas de Windows con segmentos con el prefijo \u (como C:\Users\unicorn) que se corrompían en caracteres CJK en las entradas de herramientas, lo que hacía que esos archivos fueran inaccesibles.
  • Se corrigió la tecla de flecha izquierda que descartaba la conversación sin deshacer: al presionarla justo después de editar ahora se solicita confirmación y Esc en la vista del agente regresa a la conversación en segundo plano.
  • Se agregó estado HTTP y texto de error a claude mcp list y /mcp cuando un servidor no se conecta, y una advertencia para los valores de configuración de MCP con espacios en blanco ocultos al principio o al final.
  • Se corrigió que el pegado de varias líneas colapsara en una sola línea con j en lugar de nuevas líneas en terminales que codifican las nuevas líneas pegadas como Ctrl+J.
  • Se corrigió que /context informara el uso de token precompacto obsoleto después de compactar desde el selector de mensajes.
  • Se corrigió el error de /ultrareview en argumentos descriptivos como "revisar mis cambios de autenticación". Ahora ejecutan una revisión de su rama actual con el texto aplicado como una nota a los hallazgos.
  • Se corrigió que /code-review ultra ejecutara silenciosamente una revisión local en sesiones no interactivas; ahora inicia la revisión en la nube.
  • Se corrigió la medición del gasto de la puerta de enlace para fijar el precio de los ARN del perfil de inferencia de aplicaciones de Bedrock y otros ID de modelos ascendentes asignados por configuración a las tarifas del modelo configurado.
  • Se corrigió mojibake cuando una selección larga de IDE se truncaba en medio de un emoji, y un caso en el que un error del ejecutor de herramientas podía eliminarse silenciosamente.
  • Se corrigió una carrera de desmontaje del motor que podía iniciar y abandonar un giro fantasma, y la entrada empujada después de cerrar se rechazaba constantemente
  • Se corrigieron mensajes falsos "[Solicitud interrumpida por el usuario]" después de llamadas de herramientas interrumpidas y un bloque tool_use no emparejado que quedaba en la transcripción cuando una herramienta cancelaba a mitad de respuesta.
  • Se corrigió que VoiceOver leyera "nueva línea" en lugar de hacer eco del espacio escrito al final de la entrada en el modo --ax-screen-reader.
  • Se corrigieron los paneles de configuración y complementos que no movían el cursor del terminal a la fila enfocada, para que los lectores de pantalla y las lupas puedan seguir la navegación con las teclas de flecha.
  • Se corrigieron fallas (se superó la pila de llamadas máxima) cuando se eliminaba o movía un árbol de directorios supervisado profundamente anidado y al renderizar árboles de interfaz de usuario profundamente anidados.
  • Se corrigieron los eventos de solicitud de extracción que ocasionalmente se perdían cuando una sesión salía inmediatamente después de crear o vincular un PR
  • Se corrigió que el asistente de configuración de Bedrock fallara en la verificación del perfil para perfiles que asumen roles en regiones de AWS particionadas y en redes de solo proxy.
  • Se corrigieron mediciones raras de duración de giro negativas o incorrectas después de un ajuste del reloj del sistema al cronometrar los giros con un reloj monótono.
  • Se corrigió el aviso de inicio "Los servidores N MCP necesitan autenticación" que contaba en exceso los conectores de claude.ai que no están conectados en claude.ai.
  • Se corrigieron las entradas del historial que se eliminaban o duplicaban cuando las escrituras del historial se aceleraban o fallaban.
  • Se corrigió un bucle de reintento que reenviaba solicitudes idénticas condenadas después de un error de desbordamiento de contexto con un gran presupuesto de pensamiento; El fondo Ctrl+B ahora aplica los mismos límites de fondo que otras rutas
  • Se corrigieron los ganchos de frontmatter del agente que se ejecutan desde carpetas untrusted: los ganchos ahora requieren que la propia carpeta del archivo del agente haya aceptado el espacio de trabajo trust
  • Se corrigió que el linaje de la sesión de bifurcación se perdiera después de la compactación en sesiones sin cabeza y SDK.
  • Se corrigió una sesión reanudada que fallaba en cada turno o fallaba al reanudarse, cuando su historial contenía un archivo adjunto delta mal formado.
  • Se mejoró la respuesta del error /ultrareview para que Claude pueda corregir un argumento no válido en lugar de volver a intentarlo sin cambios.
  • Modo automático mejorado: las comprobaciones de rm peligroso, fondo-& y ruta sospechosa de Windows ya no abren cuadros de diálogo de permisos; el clasificador en modo automático los adjudica en su lugar
  • Restricciones de comando de sandbox mejoradas para interacciones IDE
  • Cuadros de diálogo trust mejorados para nombrar la raíz del repositorio que cubre la subvención.
  • Se modificó /deep-research para que se inicie solo cuando se invoca manualmente; Claude ya no lo lanza solo
  • Se cambió el modo de plan con automático para que ya no solicite comandos Bash; el analizador estático no puede resultar de solo lectura; el clasificador en modo automático los juzga en su lugar
  • Se agregó un anuncio cuando el modo rápido cambia como resultado de cambiar de modelo mediante /config model=<x> o control remoto
  • Se modificó la configuración administrada por el servidor para que las funciones benignas y los cambios de costos ya no activen el mensaje de aprobación de configuración.
  • Se cambiaron los archivos de rebajas de agentes para rechazar nombres de agentes que contengan :, que está reservado para el espacio de nombres de complementos.
  • Se cambiaron las habilidades con context: fork para que se ejecuten en segundo plano de forma predeterminada; optar por no participar por habilidad con background: false
  • Se agregaron yes/no/on/off/1/0 (no distingue entre mayúsculas y minúsculas) como valores aceptados para los valores booleanos de front-matter de habilidades y complementos, junto con true/false.
  • Se corrigió que las sesiones remotas continuaran enviando latidos después de que su trabajador fuera reemplazado, lo que dejaba a los procesos IDE y de escritorio de larga duración reintentando una solicitud rechazada cada pocos segundos para siempre.

claude-code v2.1.218

What's changed

  • Changed /code-review to run as a background subagent, so review work no longer fills your conversation and keeps stacked slash commands as its review target
  • Added screen-reader announcements of deleted text for word and line deletions (Option+Delete, Ctrl+W, Cmd+Backspace, Ctrl+U, Ctrl+K) in --ax-screen-reader mode
  • Fixed Windows paths with \u-prefixed segments (like C:\Users\unicorn) being corrupted into CJK characters in tool inputs, which made those files inaccessible
  • Fixed the left arrow key discarding the conversation with no undo: presses right after editing now ask to confirm, and Esc in the agent view returns to the conversation it backgrounded
  • Added HTTP status and error text to claude mcp list and /mcp when a server fails to connect, and a warning for MCP config values with hidden leading or trailing whitespace
  • Fixed multi-line paste collapsing into one line with j in place of newlines in terminals that encode pasted newlines as Ctrl+J
  • Fixed /context reporting stale pre-compact token usage after compacting from the message picker
  • Fixed /ultrareview failing on descriptive arguments like "review my auth changes" — they now run a review of your current branch with the text applied as a note to the findings
  • Fixed /code-review ultra silently running a local review in non-interactive sessions — it now launches the cloud review
  • Fixed gateway spend metering to price Bedrock application-inference-profile ARNs and other config-mapped upstream model IDs at the configured model's rates
  • Fixed mojibake when a long IDE selection was truncated mid-emoji, and a case where a tool executor error could be silently dropped
  • Fixed an engine teardown race that could start and abandon a phantom turn, and made input pushed after close consistently rejected
  • Fixed spurious "[Request interrupted by user]" messages after interrupted tool calls, and an unpaired tool_use block left in the transcript when a tool aborted mid-response
  • Fixed VoiceOver reading "new line" instead of echoing the typed space at the end of the input in --ax-screen-reader mode
  • Fixed plugin and settings panels not moving the terminal cursor to the focused row, so screen readers and magnifiers can follow arrow-key navigation
  • Fixed crashes (maximum call stack exceeded) when a deeply nested watched directory tree was deleted or moved, and when rendering deeply nested UI trees
  • Fixed pull request events occasionally being lost when a session exited immediately after creating or linking a PR
  • Fixed the Bedrock setup wizard failing profile verification for assume-role profiles in partitioned AWS regions and on proxy-only networks
  • Fixed rare negative or incorrect turn duration measurements after a system clock adjustment by timing turns with a monotonic clock
  • Fixed the "N MCP servers need authentication" startup notice over-counting claude.ai connectors that aren't connected in claude.ai
  • Fixed prompt history entries being dropped or duplicated when history writes raced or failed
  • Fixed a retry loop that re-sent identical doomed requests after a context-overflow error with a large thinking budget; Ctrl+B backgrounding now applies the same background-shell caps as other paths
  • Fixed agent frontmatter hooks running from untrusted folders: hooks now require the agent file's own folder to have accepted workspace trust
  • Fixed fork-session lineage being lost after compaction in headless and SDK sessions
  • Fixed a resumed session failing every turn, or crashing on resume, when its history held a malformed delta attachment
  • Improved /ultrareview error feedback so Claude can correct an invalid argument instead of retrying it unchanged
  • Improved auto mode: the dangerous-rm, background-&, and suspicious-Windows-path checks no longer open permission dialogs; the auto-mode classifier adjudicates them instead
  • Improved sandbox command restrictions for IDE interactions
  • Improved trust dialogs to name the repository root the grant covers
  • Changed /deep-research to start only when invoked manually; Claude no longer launches it on its own
  • Changed plan mode with auto to no longer prompt for Bash commands the static analyzer can't prove read-only; the auto-mode classifier judges them instead
  • Added an announcement when fast mode changes as a result of switching models via /config model=<x> or Remote Control
  • Changed server-managed settings so benign feature and cost toggles no longer trigger the settings-approval prompt
  • Changed agent markdown files to reject agent names containing :, which is reserved for plugin namespacing
  • Changed skills with context: fork to run in the background by default; opt out per skill with background: false
  • Added yes/no/on/off/1/0 (case-insensitive) as accepted values for skill and plugin frontmatter booleans, alongside true/false
  • Fixed remote sessions continuing to send heartbeats after their worker was replaced, which left long-lived desktop and IDE processes retrying a rejected request every few seconds forever
