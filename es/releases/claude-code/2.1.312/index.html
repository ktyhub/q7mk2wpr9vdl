código-claude v2.1.312

¿Qué ha cambiado?

  • Se agregó oidc.user_id_claim a la puerta de enlace de aplicaciones de Claude, para identificar personas mediante un reclamo id_token distinto de sub, como oid de Microsoft Entra ID.
  • Se agregó click para enviar: en pantalla completa, cli al marcar la sugerencia "para enviar ahora" debajo de un mensaje en cola lo envía de inmediato, como lo hace su clave.
  • Se corrigió que la configuración administrada y la política de la organización no se recuperaran durante el resto de la sesión después de iniciar sesión desde la extensión VS Code.
  • Se corrigió que Claude sobrescribiera un CLAUDE.md muy grande, un archivo de reglas o un archivo incluido @ en un subdirectorio después de ver solo su inicio; Write now le pide a Claude que lo lea todo o lo edite en su lugar
  • Se corrigieron las habilidades por directorio y paths: que no se encontraban después de un Bash cd más profundo en un repositorio de git.
  • Se corrigió un caso raro en el que la primera respuesta después de reanudar una sesión en el terminal podía faltar la próxima vez que se reanudara la sesión.
  • Se corrigió un comando con un nombre no válido que detenía la carga de todos los comandos, lo que podía dejar a claude -p sin salida.
  • Se corrigió que la herramienta de lectura a veces fallara en páginas PDF con "pdftoppm falló: no se pudo escribir la imagen" cuando se ejecutaba la limpieza de archivos de sesión antiguos al mismo tiempo.
  • Se corrigió la rueda giratoria, los valores OpenTelemetry effort y las transcripciones que nombraban un nivel de esfuerzo recién seleccionado durante una tarea antes de que el modelo lo aplicara; ahora muestran el nivel vigente
  • Se corrigió la advertencia de caché de /model y /effort que decía que la relectura espera su próximo mensaje; un cambio realizado mientras Claude está trabajando puede activarlo antes
  • Se corrigieron algunas sesiones que aparecían como esperándote cuando el último mensaje solo mencionaba elementos esperándote a mitad de la oración.
  • Se corrigió la vista del agente que restauraba el texto ingresado en el siguiente inicio después de que se borrara con Ctrl+C justo antes de salir.
  • Se corrigió la reapertura de la vista del agente en modo shell después de salir con Ctrl+D desde una entrada ! vacía.
  • Se corrigió el modo vim d, c y y con un recuento de gj o gk mayor que las líneas dejadas eliminando o copiando texto; Al igual que Vim, ahora solo mueven el cursor.
  • Se corrigió que /verify mostrara una descripción larga destinada a Claude en /help y el menú de comandos de / en lugar de una corta.
  • Se mejoró el indicador de esfuerzo del mensaje: un cambio realizado a mitad de una tarea ahora dice que puede esperar su próximo mensaje y la nota se borra cuando ya no se aplica
  • Errores de WebFetch mejorados en sesiones en la nube: un host que no se resuelve ahora se explica como posiblemente fuera de los dominios de red permitidos, por lo que Claude nombra el host para permitirlo.
  • Se cambiaron Bedrock, Vertex, Foundry y Mantle para usar el mensaje del sistema más corto para nombres de modelos que Claude Code no reconoce, como nombres de implementación personalizados y ARN de perfil de inferencia, incluso cuando están delante de Sonnet o Haiku; configure CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 para mantener el mensaje completo
  • Se cambiaron los cambios automáticos de modelos después de un mensaje marcado para cubrir también los nombres de modelos que Claude Code no reconoce, como los nombres de implementación personalizados; configure CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1 para apagarlos
  • Se cambiaron los mensajes de límite de uso para llamar a la ventana de 5 horas "límite de 5 horas" en lugar de "límite de sesión".
  • Se cambiaron las sesiones en la nube iniciadas desde CLI para obtener sus nombres y nombres de sucursales del servidor.
  • Se cambiaron los enlaces de mensajes y agentes para que se ejecuten como máximo 24 a la vez por sesión, incluidos los subagentes, además de un máximo de 12 que han esperado más que el tiempo de espera de su evento; un timeout de menos de 1 segundo ahora cuenta como 1 segundo
  • Se cambió el autoCompactWindow de un subagente para reducir la ventana establecida por CLAUDE_CODE_AUTO_COMPACT_WINDOW, donde antes no tenía ningún efecto; todavía nunca levanta esa ventana
  • Se modificó OpenTelemetry mcp_server.name para informar el nombre real de los servidores MCP remotos de URL fija declarados por complementos del mercado oficial de Anthropic, en lugar de custom.
  • Se modificó Claude Code para dejar de enviar el evento claude_code.safety_event OpenTelemetry.
  • [VSCode] Se corrigieron las sesiones que finalizaban con un código de salida simple cuando la configuración de su organización no se podía cargar o se rechazaba al inicio; la pestaña ahora dice por qué y ofrece Reintentar o Iniciar sesión nuevamente
  • [VSCode] Se modificó el restablecimiento del límite de uso para mostrar la hora del reloj ("Se reinicia a las 3:10 p. m.") y decir "límite de 5 horas".
  • [Sesiones en la nube] Se agregó un nivel de esfuerzo al selector de modelo cuando creas o editas una rutina que se ejecuta en la nube.
  • [Sesiones en la nube] Se agregó un editor Bash con colores, números de línea y un botón Copiar al cuadro de configuración del script en la configuración del entorno de la nube.
  • [Sesiones en la nube] Se mejoró el paso que se muestra cuando Claude agrega un repositorio a una sesión en la nube: al abrirlo ahora se muestra una breve tabla de lo que sucedió en lugar de JSON sin formato.
  • [Sesiones en la nube] Se corrigió el reenvío de un mensaje sin cambios después de un envío fallido en una sesión en la nube que a veces se ejecutaba dos veces.
  • [Sesiones en la nube] Se corrigió una creación fallida del entorno de la nube que mostraba su error solo como un brindis fuera del cuadro de diálogo abierto; ahora aparece dentro del cuadro de diálogo
  • [Sesiones en la nube] Se corrigió la edición en el menú de una rutina en la página Rutinas, yendo a la página de la rutina sin abrir su cuadro de diálogo de edición.
  • [Control remoto] Se corrigió una sesión de control remoto no archivada que se mostraba funcionando hasta que se reconectaba una computadora; ahora se muestra como inactivo
  • [Claude Tag] Se mejoró el aviso de reintento de Claude Tag en Slack para nombrar el modelo en uso o decir que se alcanzaron los límites de velocidad, en lugar de un error genérico API.
  • [Claude Tag] Se corrigió el interruptor de encendido/apagado de un canal Claude Tag y la configuración del agente volviendo a los valores predeterminados del espacio de trabajo cuando un canal privado antiguo de Slack se vuelve público y obtiene una nueva identificación.
  • [Etiqueta de Claude] Se corrigió que Claude en Slack no respondiera en canales cuyo entorno tiene acceso a la red configurado en Ninguno.
  • [Etiqueta de Claude] Se corrigió que Claude en Slack a veces publicaba un archivo en el hilo equivocado cuando estaba respondiendo en otro hilo del mismo canal.
  • [Revisión de código] Se corrigió la revisión de código que revisaba una confirmación desactualizada, o ninguna, cuando GitHub entregaba un evento push tarde; ahora revisa la confirmación actual de la solicitud de extracción

claude-code v2.1.312

What's changed

  • Added oidc.user_id_claim to the Claude apps gateway, to identify people by an id_token claim other than sub, such as Microsoft Entra ID's oid
  • Added click to send: in fullscreen, clicking the "to send now" hint under a queued message sends it right away, as its key does
  • Fixed managed settings and organization policy not being fetched for the rest of the session after signing in from the VS Code extension
  • Fixed Claude overwriting a very large CLAUDE.md, rules file or @-included file in a subdirectory after seeing only its start; Write now asks Claude to read it all or edit in place
  • Fixed per-directory and paths: skills not being found after a Bash cd deeper into a git repository
  • Fixed a rare case where the first reply after resuming a session in the terminal could be missing the next time the session was resumed
  • Fixed a command with an invalid name stopping all commands from loading, which could leave claude -p with no output
  • Fixed the Read tool sometimes failing on PDF pages with "pdftoppm failed: Could not write image" when the clean-up of old session files ran at the same time
  • Fixed the spinner, OpenTelemetry effort values and transcripts naming a newly picked effort level during a task before the model applied it; they now show the level in force
  • Fixed the /model and /effort cache warning saying the re-read waits for your next message; a change made while Claude is working can trigger it sooner
  • Fixed some sessions showing as waiting on you when the last message only mentioned items waiting on you mid-sentence
  • Fixed agent view restoring input text on the next launch after it was cleared with Ctrl+C just before exiting
  • Fixed agent view reopening in shell mode after exiting with Ctrl+D from an empty ! input
  • Fixed vim mode d, c and y with a gj or gk count larger than the lines left deleting or copying text; like Vim, they now only move the cursor
  • Fixed /verify showing a long description meant for Claude in /help and the / command menu instead of a short one
  • Improved the prompt's effort indicator: a change made mid-task now says it may wait for your next message, and the note clears when it no longer applies
  • Improved WebFetch errors in cloud sessions: a host that does not resolve is now explained as possibly outside the allowed network domains, so Claude names the host to allow
  • Changed Bedrock, Vertex, Foundry and Mantle to use the shorter system prompt for model names Claude Code doesn't recognize, such as custom deployment names and inference profile ARNs, even when they front Sonnet or Haiku; set CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 to keep the full prompt
  • Changed automatic model switches after a flagged message to also cover model names Claude Code doesn't recognize, such as custom deployment names; set CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1 to turn them off
  • Changed usage limit messages to call the 5-hour window the "5-hour limit" instead of the "session limit"
  • Changed cloud sessions started from the CLI to get their names and branch names from the server
  • Changed prompt and agent hooks to run at most 24 at a time per session, sub-agents included, plus at most 12 that have waited longer than their event's timeout; a timeout under 1 second now counts as 1 second
  • Changed a subagent's autoCompactWindow to lower the window set by CLAUDE_CODE_AUTO_COMPACT_WINDOW, where it had no effect before; it still never raises that window
  • Changed OpenTelemetry mcp_server.name to report the real name of fixed-URL remote MCP servers declared by plugins from the official Anthropic marketplace, instead of custom
  • Changed Claude Code to stop sending the claude_code.safety_event OpenTelemetry event
  • [VSCode] Fixed sessions ending on a bare exit code when your organization's settings couldn't be loaded or were refused at startup; the tab now says why and offers Retry or Sign in again
  • [VSCode] Changed usage limit resets to show a clock time ("Resets at 3:10 PM") and to say "5-hour limit"
  • [Cloud sessions] Added an effort level to the model picker when you create or edit a routine that runs in the cloud
  • [Cloud sessions] Added a Bash editor with colors, line numbers and a Copy button to the setup script box in cloud environment settings
  • [Cloud sessions] Improved the step shown when Claude adds a repository to a cloud session: opening it now shows a short table of what happened instead of raw JSON
  • [Cloud sessions] Fixed resending an unchanged message after a failed send in a cloud session sometimes running it twice
  • [Cloud sessions] Fixed a failed cloud environment creation showing its error only as a toast outside the open dialog; it now appears inside the dialog
  • [Cloud sessions] Fixed Edit in a routine's menu on the Routines page going to the routine's page without opening its edit dialog
  • [Remote Control] Fixed an unarchived Remote Control session showing as working until a computer reconnected; it now shows as idle
  • [Claude Tag] Improved Claude Tag's retry notice in Slack to name the model in use, or say rate limits were hit, instead of a generic API error
  • [Claude Tag] Fixed a Claude Tag channel's on/off switch and agent settings falling back to workspace defaults when an older private Slack channel goes public and gets a new ID
  • [Claude Tag] Fixed Claude in Slack not replying in channels whose environment has network access set to None
  • [Claude Tag] Fixed Claude in Slack sometimes posting a file in the wrong thread when it was answering in another thread of the same channel
  • [Code Review] Fixed Code Review reviewing an outdated commit, or none at all, when GitHub delivered a push event late; it now reviews the pull request's current commit
