código-claude v2.1.217

¿Qué ha cambiado?

  • Se agregó autocompletar código corto de emoji en la entrada del mensaje: escriba :heart: para insertar ❤️, o :hea para sugerencias; desactívelo con la configuración emojiCompletionEnabled
  • Se agregaron advertencias cuando las escrituras de transcripciones fallan (por ejemplo, disco lleno) o cuando el guardado de la sesión está desactivado debido a una variable de entorno heredada, en lugar de perder las transcripciones silenciosamente.
  • Se corrigió una pérdida de memoria donde las salidas truncadas de la herramienta MCP mantenían el resultado completo no truncado en la memoria durante el resto de la sesión.
  • Se corrigieron fallas de actualización automática de Windows que podían hacer que claude.exe desapareciera; Las actualizaciones fallidas ahora restauran automáticamente el ejecutable conservado.
  • Se corrigió el aislamiento de sesiones en segundo plano que no canonicalizaba los directorios de trabajo con enlaces simbólicos, lo que podía permitir que las sesiones escaparan de su carpeta de espacio de trabajo.
  • Se corrigió que la autocompactación nunca se activara para Claude Opus 4.8 en Bedrock y /compact fallaba una vez que se sobrepasaba el límite.
  • Se corrigió que las configuraciones corporativas de mTLS, verificación de TLS, alcance de OAuth y proxy se ignoraran en las sesiones de Claude Desktop.
  • Se corrigió que el anuncio de inicio del modo lector de pantalla se cortara en el primer mensaje y la fila de estado de pensamiento se volviera a representar cada pocos segundos para actualizar el tiempo transcurrido y el recuento de tokens.
  • Se corrigieron las configuraciones administradas que configuraban que OTEL_EXPORTER_OTLP_ENDPOINT no gobierna todas las señales: las anulaciones específicas de señales de alcance inferior ya no redirigen la telemetría fuera del punto final administrado
  • Se corrigió que --resume/--continue y /resume fallaran con un TypeError cuando una transcripción tiene una entrada adjunta con formato incorrecto
  • Se corrigieron las sesiones de control remoto que no mostraban un mensaje o diálogo de permiso pendiente a los espectadores que se conectaban después de que aparecía.
  • Se corrigió que los shells en segundo plano a veces se volvieran imposibles de detener después de que una sesión se envía al fondo (/background o ←) o cuando la sesión se cierra en una máquina muy cargada, más visible en Windows.
  • Se corrigió un valor frontal de las rutas CLAUDE.md o SKILL.md con muchos grupos de llaves que mataban o detenían el CLI en el inicio; la expansión de llaves ahora está limitada por el presupuesto
  • Se corrigió la vista previa de la transcripción que quedaba al ras del área de entrada al adjuntarla a una sesión inicial en segundo plano; ahora deja el mismo espacio de una línea que el diseño en vivo, por lo que la transcripción ya no cambia cuando la sesión toma el control.
  • Se mejoraron los enlaces de las insignias PR del pie de página para que sean hipervínculos clickable incluso cuando no se puede detectar el soporte del terminal (por ejemplo, a través de ssh/tmux); configure FORCE_HYPERLINK=0 para optar por no participar
  • Se modificó la advertencia de vencimiento del inicio de sesión para que aparezca 3 días antes del vencimiento en lugar de 5
  • Se limitó la sugerencia de sugerencia del complemento de diseño de interfaz a 3 impresiones de por vida en lugar de repetirse indefinidamente.
  • Se agregó un límite a los subagentes que se ejecutan simultáneamente (predeterminado 20, anular con CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS) para que un mensaje no pueda desplegar agentes en segundo plano ilimitados.
  • Se cambiaron los subagentes para que ya no generen subagentes anidados de forma predeterminada; configure CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH para permitir un anidamiento más profundo
  • Se corrigió que --max-budget-usd no detuviera a los subagentes en segundo plano: una vez que se alcanza el límite, se niegan las nuevas apariciones y se detiene la ejecución de agentes en segundo plano.

claude-code v2.1.217

What's changed

  • Added emoji shortcode autocomplete in the prompt input: type :heart: to insert ❤️, or :hea for suggestions — disable with the emojiCompletionEnabled setting
  • Added warnings when transcript writes are failing (e.g. disk full) or when session saving is off due to an inherited environment variable, instead of losing transcripts silently
  • Fixed a memory leak where truncated MCP tool outputs kept the full untruncated result in memory for the rest of the session
  • Fixed Windows auto-update failures that could leave claude.exe missing; failed updates now restore the preserved executable automatically
  • Fixed background session isolation not canonicalizing symlinked working directories, which could let sessions escape their workspace folder
  • Fixed auto-compact never triggering for Claude Opus 4.8 on Bedrock and /compact failing once over the limit
  • Fixed corporate mTLS, TLS-verify, OAuth scope, and proxy settings being ignored in Claude Desktop sessions
  • Fixed screen reader mode's startup announcement being cut off by the first prompt render, and the thinking status row re-rendering every few seconds to update elapsed time and token counts
  • Fixed managed settings that set OTEL_EXPORTER_OTLP_ENDPOINT not governing all signals — lower-scope signal-specific overrides no longer redirect telemetry away from the managed endpoint
  • Fixed --resume/--continue and /resume failing with a TypeError when a transcript has a malformed attachment entry
  • Fixed Remote Control sessions not showing a pending permission prompt or dialog to viewers that connected after it appeared
  • Fixed background shells sometimes becoming impossible to stop after a session is sent to the background (/background or ←) or when the session exits on a heavily loaded machine, most visible on Windows
  • Fixed a CLAUDE.md or SKILL.md paths frontmatter value with many brace groups OOM-killing or stalling the CLI at startup — brace expansion is now budget-bounded
  • Fixed the transcript preview sitting flush against the input area when attaching to a starting background session; it now leaves the same one-line gap as the live layout, so the transcript no longer shifts when the session takes over
  • Improved footer PR badge links to be clickable hyperlinks even when terminal support can't be detected (e.g. over ssh/tmux); set FORCE_HYPERLINK=0 to opt out
  • Changed the login-expiry warning to appear 3 days before expiry instead of 5
  • Capped the frontend-design plugin suggestion tip at 3 lifetime impressions instead of repeating indefinitely
  • Added a cap on concurrently-running subagents (default 20, override with CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS) so one message can't fan out unbounded background agents
  • Changed subagents to no longer spawn nested subagents by default; set CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH to allow deeper nesting
  • Fixed --max-budget-usd not stopping background subagents: once the cap is reached, new spawns are denied and running background agents are halted
