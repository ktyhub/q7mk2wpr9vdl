código-claude v2.1.247

¿Qué ha cambiado?

  • Se agregó la herramienta SendFeedback: cuando algo sale mal en una sesión, Claude puede redactar un informe de comentarios para que usted lo revise y lo envíe desde /feedback (desactívelo con la configuración feedbackDrafts)
  • Se agregaron entradas {id, text, cooldownSessions, priority}, tipsFile y label a spinnerTipsOverride, para que las organizaciones puedan rotar sus propios consejos junto con los integrados.
  • Se agregó un consejo sobre las solicitudes de permiso de Bash que apuntan al modo automático, con la opción "Sí, y cambiar al modo automático" con solo presionar una tecla.
  • Se agregó /claude-api cost-optimize para perfilar el gasto de Claude API de un proyecto existente y trabajar a través de palancas de costos (almacenamiento en caché, higiene de tokens, lotes, esfuerzo, elección de modelo), un cambio medido a la vez.
  • Se actualizó la habilidad /claude-api con cobertura de administrador API (miembros de la organización, invitaciones, espacios de trabajo, claves API, informes de límite de velocidad, federación de identidades de carga de trabajo, CMEK)
  • Se corrigió la tecla de flecha rápida + Ingresar secuencias que actúan en la fila arriba de la que navegó en la búsqueda del historial, /config, /mcp, /skills, tareas en segundo plano y /model.
  • Se corrigió que los subagentes fallecieran en un modelo 404 de primera llamada: ahora usan la cadena de modelo alternativo de la sesión y el error devuelto al padre incluye el tipo de error, el estado, la identificación de la solicitud y el modelo.
  • Se corrigió un gancho o agente en segundo plano que imprimía megabytes de resultados de error, pudiendo desbordar la conversación y bloquear la sesión en "El mensaje es demasiado largo".
  • Se corrigieron los atajos de teclado Ctrl que no se activaban en diseños de teclado no latinos (por ejemplo, cirílico) en terminales de protocolo Kitty.
  • Se corrigió que se insertara texto como <35;150;7M en el mensaje cuando llegaba un informe del mouse dividido en lecturas justo después del prefijo de escape.
  • Se corrigió la limpieza posterior al comando del sandbox de Bash que eliminaba un enlace simbólico ~/.claude/settings.json administrado por un archivo de puntos (nix/home-manager, stow) cuando se redireccionaba fuera del área de escritura del sandbox.
  • Se corrigió que /terminal-setup sobrescribiera todo su Zed keymap.json en lugar de fusionarlo en su combinación de teclas.
  • Se corrigió /rename que confirmaba silenciosamente cuando el registro de la sesión no se podía actualizar; Ahora dice que es posible que otras sesiones aún muestren el nombre anterior.
  • Se corrigió /compact y "Resumir desde aquí" en sesiones iniciadas con --agent resumiendo bajo el mensaje predeterminado del sistema en lugar del propio de la conversación.
  • Se corrigió una sesión en segundo plano que mostraba "abriendo..." para siempre en claude agents después de que su proceso de host terminal muriera; la fila ahora falla en segundos con el motivo y Enter la reinicia
  • Se corrigió el crecimiento ilimitado de la memoria cuando no se podía escribir el archivo de salida de un gancho o de una tarea en segundo plano; el archivo ahora indica dónde se perdió la salida
  • Se corrigió /install-github-app sobre SSH: el acceso directo de copia ahora dice cómo se copió la URL de inicio de sesión en lugar de afirmar siempre que fue exitosa, y la URL aparece inmediatamente cuando ningún navegador puede abrirse.
  • Se corrigieron los comandos de shell transferidos desde el primer plano que registraban un error interno o mostraban una línea [exited with code -1] engañosa cuando terminaban en sesiones en segundo plano.
  • Se corrigió que el directorio de caché en vivo de un complemento de mercado sin versión se eliminara y se recreara en una instalación de segundo alcance, lo que podría interrumpir una sesión en ejecución al usarlo.
  • Se corrigieron las sesiones de control remoto iniciadas con /remote-control que no informaban la diferencia del árbol de trabajo a los clients conectados.
  • Se corrigieron sesiones de ejecución autohospedadas que informaban running antes de que comenzara Claude Code, lo que podría desencadenar una notificación prematura "Claude está esperando su entrada" desde la aplicación de escritorio de Claude.
  • Se corrigió que la configuración de primera ejecución saliera con "No se puede conectar a los servicios de Anthropic" cuando las configuraciones administradas configuran el inicio de sesión de la puerta de enlace de aplicaciones de Claude y los puntos finales de Anthropic son inaccesibles
  • Se corrigieron las sesiones en la nube (Claude Code en la web, aplicaciones de escritorio y móviles) que a veces mostraban el modo de permiso anterior cuando cambias de modo inmediatamente después de enviar un mensaje.
  • Se corrigió que las sesiones en la nube se silenciaran cuando el contenedor de la sesión se reinicia entre turnos mientras un agente, shell o monitor en segundo plano aún se está ejecutando; la sesión reanudada ahora informa el trabajo perdido
  • Mejora del refuerzo del mercado de complementos: los nombres que contienen caracteres de control o invisibles se rechazan, y el texto proporcionado por el mercado en la salida /plugin y claude plugin es seguro para escapar.
  • Sesiones mejoradas de Bedrock, Vertex y Foundry (y cualquiera con telemetría deshabilitada): ahora se le avisa a Claude cuando un servidor MCP configurado no pudo conectarse, en lugar de concluir que sus herramientas no existen.
  • Se cambió la ventana de autocompactación predeterminada de Sonnet 5 a su contexto completo de 1M, por lo que las sesiones en la ventana de 1M ahora se autocompactan en aproximadamente 967 000 tokens en lugar de aproximadamente 934 000.
  • Se cambiaron los mensajes entre pares de sesiones para que se colapsen de forma predeterminada en una vista previa de una línea Message from @<sender>: <first line>; Ctrl+O expande el cuerpo completo
  • Hipervínculos de terminal modificados en la reducción representada: los destinos de enlace que apuntan a una red o ruta de montaje automático, contienen un carácter de control o conducen con un carácter invisible ahora se representan como texto sin formato.
  • Se cambió la insignia PR del pie de página para omitir la nueva verificación GitHub al reenfocar el terminal cuando la última verificación tiene menos de un minuto.
  • Se cambiaron los análisis para permanecer fuera del inicio, no solo después de iniciar sesión, cuando la configuración administrada fuerza el inicio de sesión de la puerta de enlace o se configura una implementación OAuth personalizada.
  • Se modificaron las solicitudes de inicio de sesión de la puerta de enlace de aplicaciones de Claude para identificar el Código de Claude (un parámetro de autorización de dispositivo surface=claude_code y un agente de usuario claude-code/<version>).
  • Se modificó la aplicación del inicio de sesión de la organización para salir al inicio cuando la configuración administrada por el administrador no se puede leer, incluso si existen configuraciones de registro de Windows proporcionadas por el host o por usuario.

claude-code v2.1.247

What's changed

  • Added the SendFeedback tool: when something goes wrong in a session, Claude can draft a feedback report for you to review and send from /feedback (turn off with the feedbackDrafts setting)
  • Added {id, text, cooldownSessions, priority} entries, tipsFile, and label to spinnerTipsOverride, so organizations can rotate their own tips alongside the built-in ones
  • Added a tip on Bash permission prompts pointing to auto mode, with a one-keystroke "Yes, and switch to auto mode" option
  • Added /claude-api cost-optimize to profile an existing project's Claude API spend and work through cost levers (caching, token hygiene, batch, effort, model choice) one measured change at a time
  • Updated the /claude-api skill with Admin API coverage (organization members, invites, workspaces, API keys, rate limit reports, workload identity federation, CMEK)
  • Fixed fast arrow-key + Enter sequences acting on the row above the one you navigated to in history search, /config, /mcp, /skills, background tasks, and /model
  • Fixed sub-agents dying on a first-call model 404: they now use the session's fallback model chain, and the error returned to the parent includes the error type, status, request id, and model
  • Fixed a hook or background agent that printed megabytes of error output being able to overflow the conversation and wedge the session on "Prompt is too long"
  • Fixed Ctrl keyboard shortcuts not firing under non-Latin (e.g. Cyrillic) keyboard layouts in kitty-protocol terminals
  • Fixed text like <35;150;7M being inserted into the prompt when a mouse report arrived split across reads right after the escape prefix
  • Fixed the Bash sandbox's after-command cleanup deleting a dotfile-managed ~/.claude/settings.json symlink (nix/home-manager, stow) when it is repointed outside the sandbox's writable area
  • Fixed /terminal-setup overwriting your entire Zed keymap.json instead of merging in its keybinding
  • Fixed /rename silently confirming when the session registry could not be updated; it now says other sessions may still show the old name
  • Fixed /compact and "Summarize from here" in sessions started with --agent summarizing under the default system prompt instead of the conversation's own
  • Fixed a background session showing "opening…" forever in claude agents after its terminal host process died; the row now fails within seconds with the reason, and Enter restarts it
  • Fixed unbounded memory growth when a hook's or background task's output file could not be written; the file now notes where output was lost
  • Fixed /install-github-app over SSH: the copy shortcut now says how the sign-in URL was copied instead of always claiming success, and the URL appears immediately when no browser can open
  • Fixed shell commands carried over from the foreground logging an internal error or showing a misleading [exited with code -1] line when they finish in background sessions
  • Fixed a version-less marketplace plugin's live cache directory being deleted and recreated on a second-scope install, which could disrupt a running session using it
  • Fixed Remote Control sessions started with /remote-control not reporting the working-tree diff to connected clients
  • Fixed self-hosted runner sessions reporting running before Claude Code had started, which could trigger a premature "Claude is waiting for your input" notification from the Claude desktop app
  • Fixed first-run setup exiting with "Unable to connect to Anthropic services" when managed settings configure Claude apps gateway sign-in and Anthropic endpoints are unreachable
  • Fixed cloud sessions (Claude Code on the web, desktop and mobile apps) sometimes showing the previous permission mode when you switch modes right after sending a message
  • Fixed cloud sessions going silent when the session's container restarts between turns while a background agent, shell, or monitor is still running — the resumed session now reports the lost work
  • Improved plugin marketplace hardening: names containing control or invisible characters are rejected, and marketplace-supplied text in /plugin and claude plugin output is escape-safe
  • Improved Bedrock, Vertex, and Foundry sessions (and any with telemetry disabled): Claude is now told when a configured MCP server failed to connect, instead of concluding its tools don't exist
  • Changed Sonnet 5's default auto-compact window to its full 1M context, so sessions on the 1M window now auto-compact at about 967K tokens instead of about 934K
  • Changed cross-session peer messages to collapse by default to a one-line Message from @<sender>: <first line> preview; Ctrl+O expands the full body
  • Changed terminal hyperlinks in rendered markdown: link targets that point at a network or automounter path, contain a control character, or lead with an invisible character now render as plain text
  • Changed the prompt-footer PR badge to skip its GitHub re-check on terminal refocus when the last check is under a minute old
  • Changed analytics to stay off from startup, not only after login, when managed settings force gateway login or a custom OAuth deployment is configured
  • Changed Claude apps gateway sign-in requests to identify Claude Code (a surface=claude_code device-authorization parameter and a claude-code/<version> User-Agent)
  • Changed organization sign-in enforcement to exit at start when the administrator's managed settings cannot be read, even if host-supplied or per-user Windows registry settings exist
