código-claude v2.1.301

¿Qué ha cambiado?

  • Se agregó CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS para que el modo de reintento desatendido (CLAUDE_CODE_RETRY_WATCHDOG) finalice una solicitud en un límite de uso que se reinicia demasiado lejos en lugar de esperar.
  • Se agregó guía de rastreo OpenTelemetry a la habilidad claude-api, incluida la configuración de destinos de rastreo con ant CLI.
  • Se agregó el movimiento % al modo vim: salta al soporte correspondiente, solo o con d/c/y
  • Se agregó rows al Input de un mod: un campo de texto de varias líneas en la terminal, donde Enter envía y Shift+Enter o una barra invertida antes de que Enter comience una nueva línea.
  • Se agregaron classifier_verdict y permission_mode a los eventos OpenTelemetry tool_decision, para que las decisiones del clasificador en modo automático se puedan diferenciar de las reglas de permisos.
  • Se agregaron eventos classifier_category a OpenTelemetry tool_decision, nombrando a la regla incorporada un bloque clasificador que coincida, cuando OTEL_LOG_TOOL_DETAILS=1
  • Se corrigió la eliminación de un árbol de trabajo creado por un gancho WorktreeCreate sin preguntar cuándo puede contener confirmaciones no enviadas.
  • Se corrigió el error de alias del modelo fable (y best) en el Anthropic API cuando el modelo Fable más nuevo no está disponible para su organización: Claude Code ahora reintenta una vez en el modelo Fable anterior.
  • Se corrigió un error engañoso "Ejecute /iniciar sesión" cuando un disco lleno impide que se actualice el inicio de sesión; el error ahora nombra el disco y dice que elimine archivos
  • Se corrigió que Grep y Glob no informaran coincidencias cuando el programa de búsqueda fallaba inesperadamente antes de devolver resultados; Ahora devuelven un error que dice que la búsqueda falló.
  • Se corrigió que los agentes de flujo de trabajo a veces se saltaran su paso y la ejecución aún informara de éxito; después de leer el arnés, tenga en cuenta que el texto de su tarea no tiene autoridad de usuario.
  • Se corrigió el rechazo de actualizaciones de artefactos cuando un gancho PreToolUse cubre Editar o Escribir; Claude ahora edita el archivo y luego lo vuelve a publicar en lugar de cambiarlo en la llamada de publicación.
  • Se corrigieron habilidades y comandos con muchos o muy largos nombres de argumentos que se detenían durante segundos cuando se invocaban; ahora solo se completan los primeros 64 nombres, cada uno de hasta 64 caracteres
  • Se corrigieron habilidades, comandos y ganchos que usaban cantidades muy grandes de memoria cuando sus argumentos llenaban muchos marcadores de posición.
  • Se corrigieron caracteres perdidos como >0q que cubrían el mensaje de la carpeta trust y >4m antes del mensaje de shell al salir, en terminales construidos en VTE anteriores a 0.53, como MATE Terminal en RHEL 8.
  • Se corrigió el texto perdido GOK que aparecía en el mensaje al inicio en algunas versiones de iTerm2
  • Se corrigió el cambio a un modelo cuyo nombre contiene application-inference-profile ejecutando el comando awsAuthRefresh y retrasando los ganchos de cambio de modelo cuando el proveedor no es Bedrock.
  • Se corrigieron los tiempos de espera de actualización de inicio de sesión y cierres de sesión inesperados después de que un comando corto como claude auth status o claude plugin list saliera en medio de una actualización de token.
  • Se corrigió una llamada de herramienta interrumpida por un mensaje enviado a mitad de turno durante su verificación de permiso que se informaba al modelo como rechazado por el usuario.
  • Se corrigió un caso en el que cambiar a un modelo con una ventana de contexto más pequeña podía gastar créditos de uso en un resumen del modelo anterior sin preguntar primero.
  • Se corrigieron las conversaciones que se compactaban una y otra vez, en un modelo que no elegiste, detrás de una puerta de enlace LLM cuyas respuestas nombran un modelo diferente al solicitado.
  • Se corrigió que el modo vim a veces permaneciera en INSERT después de Escape en una máquina lenta u ocupada
  • Se corrigió que Esc descartara una respuesta AskUserQuestion escrita en modo vim: el campo de texto libre ahora admite el modo vim NORMAL y Esc cancela solo desde NORMAL.
  • Se corrigió la herramienta de lectura que leía archivos binarios como .xlsm, .parquet, .epub y .heic como texto.
  • Se corrigió una tabla de Markdown con solo una fila de encabezado que no dibujaba nada cuando era demasiado ancha para la terminal, incluso en los planos en la tarjeta de aprobación del plan.
  • Se corrigió la habilidad /claude-api que decía que los puntos finales de clave externa CMEK no están disponibles en Claude Platform en AWS
  • Se corrigieron las habilidades que ya no aparecen en el modelo después de usar /rewind.
  • Se corrigió la fila de compactación en una sesión reanudada que ofrecía ctrl+o para el historial que no está cargado; ahora dice dónde se guardan los mensajes anteriores y también se muestra en pantalla completa
  • Se corrigió la sugerencia "¿nueva tarea? /borrar para guardar tokens" que regresaba justo después de interrumpir una respuesta.
  • Se corrigió el mensaje de permiso para la decisión ask de un complemento o gancho de habilidad que no mostraba de qué complemento o habilidad proviene el gancho.
  • Se corrigió que /diff no notara una selección conflictiva o una reversión en repositorios reftables cuando una de sus comprobaciones de git expiró o falló.
  • Se corrigieron los scripts de flujo de trabajo que pedían permiso o eran rechazados cuando se leían, editaban o volvían a ejecutar después de un Bash cd en la misma sesión.
  • Se corrigió el texto tenue en el tema ANSI oscuro y terminales de 16 colores: tenue dentro de cuadros llenos, no tenue bajo selección y búsqueda resaltada, y descripciones de lista atenuadas como otro texto secundario
  • Se corrigió el $.model.fork de un mod que devolvía nothing-to-fork cuando se llamaba antes de que finalizara la primera respuesta de un nuevo proceso de Claude Code, como en las ejecuciones de claude -p y sesiones en la nube.
  • Modo de pantalla completa: se corrigió /compact y la autocompactación congela brevemente la interfaz de usuario mientras se reconstruye la transcripción visible.
  • Ejecutor autohospedado: Se corrigió que las sesiones iniciadas desde Slack no pudieran encontrar o adjuntar un repositorio cuando la configuración administrada restringe los servidores MCP; use deniedMcpServers para mantener esas herramientas apagadas
  • Ejecutor autohospedado: Se corrigió que las sesiones se informaran como si tuvieran una rama de origen eliminada, y no se reintentaran, cuando una configuración no relacionada o una falla de sesión citaban la redacción de referencia faltante de git.
  • Ejecutor autohospedado: se corrigió el registro que prometía un reintento de una liberación de sesión fallida o declined para una sesión que está finalizando; Los fallos repetidos ahora muestran un recuento.
  • Windows: Se corrigieron los comandos de PowerShell en segundo plano detenidos a los que les faltaba la línea de cierre [killed] en su archivo de salida.
  • Cambio mejorado a un modelo con una ventana de contexto más pequeña: una conversación demasiado larga para el nuevo modelo ahora se resume primero en el modelo anterior.
  • Rendimiento de renderizado mejorado mientras trabaja un subagente de larga duración: su registro de progreso ahora se actualiza de forma incremental en lugar de reprocesarse por completo en cada renderizado.
  • Artefactos mejorados: las páginas que escribe Claude ahora pintan la banda encima de un encabezado adhesivo, por lo que el texto desplazado ya no se muestra allí en las aplicaciones móviles.
  • Modificaciones mejoradas: en VS Code y en las aplicaciones de escritorio y móviles, un árbol dibujado encima del cuadro de diálogo de preguntas ahora puede contener Markdown y hasta 48 filas; el terminal mantiene 12 filas simples
  • Se cambió el controlador .catch de un gancho mod para que se ejecute solo cuando el gancho se lanza o se agota el tiempo de espera; los eventos generados bajo las propias llamadas del gancho ahora saltan ese gancho sin preguntarle a su .catch
  • Se cambió el $.env.set de un mod para que se resuelva con {} una vez que la variable está configurada o desarmada, o con { deny } diciendo por qué cuando no se realiza la escritura.
  • [VSCode] Se agregó representación matemática LaTeX en las respuestas de Claude, incluidos bloques $$ y \[ … \] multilínea y matemáticas $…$ y \(…\) en línea.
  • [VSCode] Se agregó un enlace "Obtener más uso" al banner de límite de uso para los planes Pro y Max en los paneles VS Code y JetBrains.
  • [VSCode] Se corrigió una conversación que bloquea o congela el panel que se vuelve a abrir en cada recarga.
  • [VSCode] Se corrigió que el panel de chat se ralentizara durante el pensamiento prolongado: ya no vuelve a analizar todo el texto del pensamiento en cada actualización.
  • [VSCode] Se corrigió el diagnóstico que mostraba "[objeto Objeto]" en lugar del código de regla (por ejemplo, MD013) para algunos servidores de idiomas.
  • [VSCode] Se corrigió el módulo de audio de dictado nativo que se cargaba para verificar el permiso del micrófono, donde no se ofrece dictado (inicios de sesión que no son de claude.ai, ventanas remotas)

claude-code v2.1.301

What's changed

  • Added CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS so unattended retry mode (CLAUDE_CODE_RETRY_WATCHDOG) ends a request at a usage limit that resets too far away instead of waiting
  • Added OpenTelemetry tracing guidance to the claude-api skill, including setting up trace destinations with the ant CLI
  • Added the % motion to vim mode: jump to the matching bracket, alone or with d/c/y
  • Added rows to a mod's Input: a text field of several lines in the terminal, where Enter submits and Shift+Enter or a backslash before Enter starts a new line
  • Added classifier_verdict and permission_mode to OpenTelemetry tool_decision events, so auto mode classifier decisions can be told apart from permission rules
  • Added classifier_category to OpenTelemetry tool_decision events, naming the built-in rule a classifier block matched, when OTEL_LOG_TOOL_DETAILS=1
  • Fixed quitting removing a worktree made by a WorktreeCreate hook without asking when it may hold unpushed commits
  • Fixed the fable (and best) model alias erroring on the Anthropic API when the newest Fable model is not available to your organization: Claude Code now retries once on the previous Fable model
  • Fixed a misleading "Please run /login" error when a full disk keeps the login from being refreshed; the error now names the disk and says to delete files
  • Fixed Grep and Glob reporting no matches when the search program failed unexpectedly before returning any results; they now return an error saying the search failed
  • Fixed workflow agents sometimes skipping their step, and the run still reporting success, after reading the harness note that their task text carries no user authority
  • Fixed artifact updates being refused where a PreToolUse hook covers Edit or Write; Claude now edits the file and then republishes instead of changing it in the publish call
  • Fixed skills and commands with very many or very long argument names stalling for seconds when invoked; only the first 64 names, each up to 64 characters, are now filled in
  • Fixed skills, commands and hooks using very large amounts of memory when their arguments fill many placeholders
  • Fixed stray characters such as >0q covering the folder trust prompt, and >4m before the shell prompt at exit, in terminals built on VTE older than 0.53 such as MATE Terminal on RHEL 8
  • Fixed stray GOK text appearing in the prompt at startup in some versions of iTerm2
  • Fixed switching to a model whose name contains application-inference-profile running your awsAuthRefresh command and delaying model-switch hooks when the provider is not Bedrock
  • Fixed sign-in refresh timeouts and unexpected sign-outs after a short command such as claude auth status or claude plugin list exited in the middle of a token refresh
  • Fixed a tool call cut off by a message sent mid-turn during its permission check being reported to the model as rejected by the user
  • Fixed a case where switching to a model with a smaller context window could spend usage credits on a summary by the previous model without asking first
  • Fixed conversations being compacted over and over, on a model you didn't pick, behind an LLM gateway whose responses name a different model than the one requested
  • Fixed vim mode sometimes staying in INSERT after Escape on a slow or busy machine
  • Fixed Esc discarding a typed AskUserQuestion answer in vim mode: the free-text field now supports vim NORMAL mode, and Esc cancels only from NORMAL
  • Fixed the Read tool reading binary files such as .xlsm, .parquet, .epub and .heic as text
  • Fixed a Markdown table with only a header row drawing nothing when too wide for the terminal, including in plans on the plan approval card
  • Fixed the /claude-api skill saying CMEK external-key endpoints aren't available on Claude Platform on AWS
  • Fixed skills no longer being listed to the model after using /rewind
  • Fixed the compaction row in a resumed session offering ctrl+o for history that is not loaded; it now says where the earlier messages are saved, and also shows in fullscreen
  • Fixed the "new task? /clear to save tokens" hint coming back right after you interrupt a response
  • Fixed the permission prompt for a plugin or skill hook's ask decision not showing which plugin or skill the hook comes from
  • Fixed /diff not noticing a conflicted cherry-pick or revert in reftable repositories when one of its git checks timed out or failed
  • Fixed workflow scripts asking for permission or being refused when read, edited or re-run after a Bash cd in the same session
  • Fixed dim text on the dark ANSI theme and 16-color terminals: faint inside filled boxes, not faint under selection and search highlights, and list descriptions dimmed like other secondary text
  • Fixed a mod's $.model.fork returning nothing-to-fork when called before the first response of a new Claude Code process had finished, as in claude -p runs and cloud sessions
  • Fullscreen mode: Fixed /compact and auto-compact briefly freezing the UI while the visible transcript is rebuilt
  • Self-hosted runner: Fixed sessions started from Slack being unable to find or attach a repository when managed settings restrict MCP servers; use deniedMcpServers to keep those tools off
  • Self-hosted runner: Fixed sessions being reported as having a deleted source branch, and not retried, when an unrelated setup or session failure quoted git's missing-ref wording
  • Self-hosted runner: Fixed the log promising a retry of a failed or declined session release for a session that is ending; repeated failures now show a count
  • Windows: Fixed stopped background PowerShell commands missing the closing [killed] line in their output file
  • Improved switching to a model with a smaller context window: a conversation too long for the new model is now summarized by the previous model first
  • Improved rendering performance while a long-running subagent works: its progress trail now updates incrementally instead of being reprocessed in full on every render
  • Improved artifacts: pages Claude writes now paint the band above a sticky header, so scrolled text no longer shows there in the mobile apps
  • Improved mods: in VS Code and the desktop and mobile apps, a tree drawn above the question dialog can now hold Markdown and up to 48 rows; the terminal keeps 12 plain rows
  • Changed a mod hook's .catch handler to run only when the hook throws or times out; events raised beneath the hook's own calls now skip that hook without asking its .catch
  • Changed a mod's $.env.set to resolve with {} once the variable is set or unset, or with { deny } saying why when the write is not made
  • [VSCode] Added LaTeX math rendering in Claude's responses, including $$ and multi-line \[ … \] blocks and inline $…$ and \(…\) math
  • [VSCode] Added a "Get more usage" link to the usage-limit banner for Pro and Max plans in the VS Code and JetBrains panels
  • [VSCode] Fixed a conversation that crashes or freezes the panel being reopened on every reload
  • [VSCode] Fixed the chat panel slowing down during long thinking: it no longer re-parses the whole thinking text on every update
  • [VSCode] Fixed diagnostics showing "[object Object]" instead of the rule code (e.g. MD013) for some language servers
  • [VSCode] Fixed the native dictation audio module being loaded, to check microphone permission, where dictation is not offered (non-claude.ai sign-ins, remote windows)
