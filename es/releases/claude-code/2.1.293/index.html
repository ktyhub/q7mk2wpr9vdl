código-claude v2.1.293

¿Qué ha cambiado?

  • Se agregó Claude Haiku 5.5 (claude-haiku-5-5), ahora el modelo de Haiku predeterminado en el Anthropic API - contexto 1M, $0.10/$0.50 por Mtok ($0.50/$2.50 para mensajes de más de 100K)
  • Se agregó agentType a la carga útil subagentStatusLine, para que los scripts puedan diferenciar los tipos de subagente personalizados.
  • Se agregó isDeferred a $.tool.register para modificaciones: false enumera el esquema de la herramienta en el mensaje desde el principio en lugar de detrás de la búsqueda de herramientas.
  • Se corrigió que Claude a veces tratara sus últimas acciones antes de una compactación de contexto como si se hubieran hecho después, y se retractara o rehaciera el trabajo terminado.
  • Se corrigió una pérdida de memoria donde una conexión HTTP MCP mantenía cada solicitud que había enviado hasta que se cerraba
  • Se corrigió un mensaje enviado mientras Claude estaba trabajando que se perdía cuando ← movía la sesión a un segundo plano; Si un mensaje en cola no se puede mover, ← ahora se queda quieto y lo dice.
  • Se corrigió el esfuerzo /model ←/→ que pasaba del nivel más alto o más bajo, lo que podría guardar accidentalmente Bajo como esfuerzo predeterminado del modelo.
  • Se corrigió que /tui desconectara a Claude en Chrome en una sesión iniciada con --chrome e ignorara --no-chrome.
  • Se corrigió que a Claude se le dijera que continuara o enviara mensajes a subagentes con SendMessage en sesiones, incluidas las reanudadas, donde un host, una regla de permiso o una lista de --tools eliminaban esa herramienta.
  • Se corrigió que a los subagentes y sesiones --agent se les dijera que una herramienta incorporada estaba deshabilitada para toda la sesión cuando solo su propia lista de herramientas la omitía.
  • Se corrigió la descripción editada de una habilidad sincronizada con claude.ai que a veces no llegaba al modelo hasta una nueva conversación o /clear.
  • Se corrigió que claude logs, stop, kill, rm y claude daemon status, stop, uninstall a veces cerraran sesión cuando su inicio de sesión había caducado o estaba a punto de hacerlo.
  • Se corrigió que el recuento de agentes del pie de página desapareciera después de una falla momentánea al leer la carpeta de sesiones (por ejemplo, demasiados archivos abiertos).
  • Se corrigió que un agente personalizado llamado worker se mostrara como "Agente" cuando se inicia, y el título del cuadro de diálogo de detalles del agente perdía el tipo de agente una vez que el agente termina.
  • Se corrigió la fila de transcripción de la herramienta Artefacto que decía brevemente Artifact("(unprintable path)") mientras aún se transmitía una llamada de publicación.
  • Se corrigió la carga de /ultrareview en Linux que rechazaba erróneamente algunos repositorios, como uno dentro de otro proceso de pago, sobre un archivo de configuración que "no se podía analizar" mientras se ejecutaba un comando en el espacio aislado.
  • Se corrigió el rechazo de la carga de /ultrareview sobre archivos con índice dividido, advirtiendo un comando git que podría dejar a git incapaz de leer su índice.
  • Se corrigieron las respuestas en sesiones muy largas de control remoto y en la nube que aún podían aparecer un bloque a la vez en lugar de transmitirse
  • Se corrigió que el control remoto cargara nuevamente el historial de inicio de una sesión después de cada recuperación de credenciales.
  • Se corrigió el informe PushNotification "Control remoto inactivo" en sesiones iniciadas con claude remote-control
  • Se corrigieron los ganchos de un mod en los eventos classic.* que se omitían mientras el trabajador de ganchos del complemento se reinicia, lo que dejaba que los ganchos de configuración respondieran sin ellos.
  • Se corrigió el fallo de claude plugin test para mods que llaman a $.session.append; Las pruebas pueden leer las filas adjuntas con el nuevo mock.session.
  • Se corrigió que claude plugin eval rechazara todas las ejecuciones de concesión de Bash en Mac con escritorio Docker (enlaces en ~/.docker/bin); el rechazo ahora indica qué parte de un almacén de credenciales contenía el enlace
  • Se corrigió que la puerta de enlace de aplicaciones de Claude se negara a iniciarse cuando una política desktop establece las claves integradas del navegador de Claude Desktop, como builtinBrowserEnabled.
  • Se corrigió que claude agents ofreciera permisos de omisión que las sesiones en segundo plano luego ignoraban cuando el consentimiento se guardaba solo en .claude/settings.local.json o en un archivo --settings; ahora solicita primero el consentimiento y una sesión que ignora la omisión muestra un breve aviso que permanece
  • Se corrigió que ← pusiera en segundo plano una sesión después de 10 segundos mientras el mensaje contenía texto no enviado (ahora cancela el movimiento) o una pregunta estaba esperando su respuesta.
  • Se corrigió Esc, o No sin respuesta, en un mensaje de permiso que no detenía el giro cuando se acababa de presionar ← para mover la sesión al fondo.
  • Se corrigió la vista de agentes reemplazando brevemente la lista de sesiones con filas de marcador de posición cuando la carpeta de sesiones no se podía leer (por ejemplo, demasiados archivos abiertos)
  • Se corrigieron las reglas con alcance de ruta y los archivos CLAUDE.md anidados que no se cargaban cuando Claude ve un archivo con un comando cat, head, tail, sed -n o grep de un solo archivo en la herramienta Bash en lugar de la herramienta Leer.
  • Se corrigió el texto pegado que comienza y termina con las mismas palabras que a veces se envían a Claude como si hubieran sido escritas.
  • Se corrigió que el nombre de una habilidad en el texto pegado se tratara como escrito cuando se escribía o pegaba un acento justo después de que el pegado se fusionara con su última letra.
  • Se corrigió que /feedback regresara a la lista de borradores después de Ctrl+O o Ctrl+Z mientras se enviaba un informe, lo que hacía imposible cancelar el envío.
  • Se corrigió que claude purge se detuviera silenciosamente (salida 0 o bloqueo en una terminal) cuando no se podía eliminar un archivo o carpeta; ahora elimina el resto, enumera lo que no pudo eliminar y sale 1
  • Se corrigieron las comprobaciones de combinaciones de teclas.json: una sola " " (tecla de espacio) ya no se informa como un error, y teclas como "ctrl+ k" ahora reciben una advertencia.
  • Se corrigió el modo vim >> y << en una línea de solo espacios dejando el cursor más allá del final de la línea, donde el siguiente x no eliminaba nada.
  • Modo vim fijo: después de eliminar líneas completas en modo Visual (V y luego d), el cursor aterriza en la primera línea que no está en blanco, y . después actúa en la línea del cursor.
  • Windows: se corrigió la detención de una línea de estado, un enlace o un comando de shell que a veces terminaba un proceso no relacionado al que se le había asignado el mismo ID de proceso.
  • Se revirtió el cambio del mensaje de denegación del modo automático de 2.1.281 que le decía a Claude que una denegación cubre el resultado, no solo el comando exacto.
  • Se revirtió la solución 2.1.290 para sesiones en la nube que permanecían inactivas después de que un reinicio del contenedor perdiera una activación pendiente de /loop o una tarea programada; A Claude ya no se le dice y la sesión permanece dormida.
  • Inicio mejorado para organizaciones Team y Enterprise: la política y la configuración administrada se recuperan antes y una solicitud detenida se vuelve a intentar después de 3 segundos.
  • Claude mejorado en Chrome: se rechazan menos acciones de página cuando el navegador tarda en informar sus pestañas
  • Se mejoró el mensaje de Claude en Chrome en sesiones en la nube cuando no se puede acceder al navegador: si pertenece a más de una organización, ahora dice que la extensión debe iniciar sesión en la misma y cómo cambiar eso.
  • Se mejoró la nota de diferenciación de edición de Bash para indicar que los archivos enumerados cambiaron mientras se ejecutaba el comando, lo que puede incluir escrituras de otros procesos.
  • Artefactos mejorados: Claude fija bibliotecas en versiones exactas de dos semanas o más
  • Se modificó la sincronización de habilidades de claude.ai para verificar los cambios aproximadamente cada 40 minutos, en lugar de cada 10, mientras no haya ninguna sesión en uso.
  • Se cambió el orden de las listas de agentes y de los servidores MCP anunciados al modelo: los nombres con caracteres no ASCII ahora se ordenan después de los nombres ASCII.
  • Se modificó el registro OpenTelemetry claude_code.at_mention para emitir como máximo 100 eventos de agente y 100 eventos de recursos MCP cada vez que se lee un mensaje.
  • Ejecutor autohospedado: se cambió el orquestador para que duerma de 4 a 6 segundos entre sondeos en lugar de 5 constantes, por lo que varias réplicas de un entorno dejan de sondear al mismo tiempo.
  • [Etiqueta de Claude] Se corrigió que Claude en Slack dijera que un espacio de trabajo no está configurado en los canales Enterprise Grid compartidos entre espacios de trabajo cuando Slack etiqueta un mensaje con un espacio de trabajo que no está conectado.
  • [Etiqueta de Claude] Se corrigió que Claude en Slack se detuviera a mitad de una tarea en un canal cuando un administrador cambiaba los conectores, complementos, habilidades o reglas del canal; el cambio ahora se aplica una vez que Claude termina
  • [Etiqueta de Claude] Se corrigió pedirle a Claude en Slack que ejecutara la rutina de un hilo ahora con notas adicionales que iniciaban una ejecución separada que no se podía publicar; La carrera ahora continúa en ese hilo.
  • [Claude Tag] Se corrigió el cuadro de diálogo Agregar un conector de un paquete de acceso en la configuración de administración de Claude Tag que muestra cada conector de Google como conectado después de un inicio de sesión de Google.
  • [Claude Tag] Se mejoró la configuración de administración de Claude Tag para mostrar un Enterprise Grid que aún no está conectado, con un botón Conectar.
  • [Etiqueta de Claude] Se cambió Claude en Slack para unirse a los canales de anuncios, donde solo los administradores pueden publicar, sin publicar su introducción.
  • [Claude Tag] Se cambió el límite de las reglas del canal en la configuración de administración de Claude Tag de 20 a 50 para cada espacio de trabajo y para la página de Slack de toda la organización.
  • [Revisión de código] Se mejoró el cuadro de diálogo Agregar un repositorio de Revisión de código para enumerar cada repositorio que no se pudo agregar y por qué, como por ejemplo, falta el acceso de escritura GitHub.

claude-code v2.1.293

What's changed

  • Added Claude Haiku 5.5 (claude-haiku-5-5), now the default Haiku model on the Anthropic API — 1M context, $0.10/$0.50 per Mtok ($0.50/$2.50 for prompts over 100K)
  • Added agentType to the subagentStatusLine payload, so scripts can tell custom subagent types apart
  • Added isDeferred to $.tool.register for mods: false lists the tool's schema in the prompt from the start instead of behind tool search
  • Fixed Claude sometimes treating its own last actions before a context compaction as done after it, and retracting or redoing finished work
  • Fixed a memory leak where an HTTP MCP connection kept every request it had sent until it closed
  • Fixed a message sent while Claude was working being lost when ← moved the session to the background; if a queued message can't move, ← now stays put and says so
  • Fixed /model effort ←/→ wrapping past the highest or lowest level, which could accidentally save Low as a model's default effort
  • Fixed /tui disconnecting Claude in Chrome in a session started with --chrome, and ignoring --no-chrome
  • Fixed Claude being told to continue or message subagents with SendMessage in sessions, including resumed ones, where a host, a permission rule or a --tools list removed that tool
  • Fixed subagents and --agent sessions being told a built-in tool was disabled for the whole session when only their own tool list left it out
  • Fixed a claude.ai-synced skill's edited description sometimes not reaching the model until a new conversation or /clear
  • Fixed claude logs, stop, kill, rm and claude daemon status, stop, uninstall sometimes signing you out when your login had expired or was about to
  • Fixed the footer's agents count disappearing after a momentary failure to read the sessions folder (for example, too many open files)
  • Fixed a custom agent named worker being shown as "Agent" when it starts, and the agent detail dialog's title losing the agent type once the agent finishes
  • Fixed the Artifact tool's transcript row briefly reading Artifact("(unprintable path)") while a publish call was still streaming in
  • Fixed the /ultrareview upload on Linux wrongly refusing some repositories, such as one inside another checkout, over a settings file that "could not be parsed" while a sandboxed command was running
  • Fixed the /ultrareview upload's refusal over split-index files advising a git command that could leave git unable to read its index
  • Fixed replies in very long Remote Control and cloud sessions that could still appear a block at a time instead of streaming in
  • Fixed Remote Control uploading a session's starting history again after every credential recovery
  • Fixed PushNotification reporting "Remote Control inactive" in sessions started with claude remote-control
  • Fixed a mod's hooks on classic.* events being skipped while the plugin hooks worker restarts, which left settings hooks to answer without them
  • Fixed claude plugin test failing for mods that call $.session.append; tests can read the appended rows back with the new mock.session
  • Fixed claude plugin eval refusing every Bash-granting run on Macs with Docker Desktop (links under ~/.docker/bin); the refusal now names which part of a credential store held the link
  • Fixed the Claude apps gateway refusing to start when a desktop policy sets Claude Desktop's built-in browser keys, such as builtinBrowserEnabled
  • Fixed claude agents offering bypass permissions that background sessions then ignored when consent was saved only in .claude/settings.local.json or a --settings file; it now asks for consent first, and a session that ignores bypass shows a short notice that stays
  • Fixed ← backgrounding a session after 10 seconds while the prompt held unsent text (it now cancels the move) or a question was waiting for your answer
  • Fixed Esc, or No without feedback, on a permission prompt not stopping the turn when ← had just been pressed to move the session to the background
  • Fixed the agents view briefly replacing the session list with placeholder rows when the sessions folder could not be read (for example, too many open files)
  • Fixed path-scoped rules and nested CLAUDE.md files not loading when Claude views a file with a single-file cat, head, tail, sed -n or grep command in the Bash tool instead of the Read tool
  • Fixed pasted text that begins and ends with the same words sometimes being sent to Claude as if it had been typed
  • Fixed a skill name in pasted text being treated as typed when an accent typed or pasted right after the paste merged into its last letter
  • Fixed /feedback returning to the drafts list after Ctrl+O or Ctrl+Z while a report was sending, leaving the send impossible to cancel
  • Fixed claude purge stopping silently (exit 0, or a hang in a terminal) when a file or folder could not be deleted; it now deletes the rest, lists what it could not delete, and exits 1
  • Fixed keybindings.json checks: a lone " " (space key) is no longer reported as an error, and keys like "ctrl+ k" now get a warning
  • Fixed vim mode >> and << on a line of only spaces leaving the cursor past the end of the line, where a following x deleted nothing
  • Fixed vim mode: after deleting whole lines in Visual mode (V then d) the cursor lands on the first non-blank, and . after it acts on the cursor's line
  • Windows: Fixed stopping a status line, hook, or shell command sometimes terminating an unrelated process that had been given the same process ID
  • Reverted the auto mode denial message change from 2.1.281 that told Claude a denial covers the outcome, not only the exact command
  • Reverted the 2.1.290 fix for cloud sessions staying asleep after a container restart lost a pending /loop wakeup or scheduled task; Claude is no longer told, and the session stays asleep
  • Improved startup for Team and Enterprise organizations: policy and managed settings are fetched earlier, and a stalled request is retried after 3 seconds
  • Improved Claude in Chrome: fewer page actions are refused when the browser is slow to report its tabs
  • Improved the Claude in Chrome message in cloud sessions when the browser can't be reached: if you belong to more than one organization, it now says the extension must be signed in to the same one, and how to change that
  • Improved the Bash edit diff note to say the listed files changed while the command ran, which can include writes by other processes
  • Improved artifacts: Claude pins libraries to exact versions two weeks old or older
  • Changed claude.ai skill syncing to check for changes about every 40 minutes, instead of every 10, while no session is in use
  • Changed the order of agent lists and of MCP servers announced to the model: names with non-ASCII characters now sort after ASCII names
  • Changed OpenTelemetry claude_code.at_mention logging to emit at most 100 agent and 100 MCP-resource events each time a prompt is read
  • Self-hosted runner: Changed the orchestrator to sleep 4 to 6 seconds between polls instead of a constant 5, so several replicas for one environment stop polling at the same moment
  • [Claude Tag] Fixed Claude in Slack saying a workspace isn't set up in Enterprise Grid channels shared across workspaces when Slack labels a message with a workspace that isn't connected
  • [Claude Tag] Fixed Claude in Slack stopping mid-task in a channel when an admin changed the channel's connectors, plugins, skills or rules; the change now applies once Claude finishes
  • [Claude Tag] Fixed asking Claude in Slack to run a thread's routine now with extra notes starting a separate run that couldn't post back; the run now continues in that thread
  • [Claude Tag] Fixed an access bundle's Add a connector dialog in Claude Tag admin settings showing every Google connector as connected after one Google sign-in
  • [Claude Tag] Improved Claude Tag admin settings to list an Enterprise Grid that isn't connected yet, with a Connect button
  • [Claude Tag] Changed Claude in Slack to join announcement channels, where only admins can post, without posting its intro
  • [Claude Tag] Changed the limit on channel rules in Claude Tag admin settings from 20 to 50 for each workspace and for the organization-wide Slack page
  • [Code Review] Improved Code Review's Add a repository dialog to list each repository that couldn't be added and why, such as missing GitHub write access
