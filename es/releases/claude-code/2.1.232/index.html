código-claude v2.1.232

¿Qué ha cambiado?

  • La bifurcación de subagente ahora está activada de forma predeterminada: un subagente subagent_type: "fork" hereda la conversación completa y el caché de mensajes, y el agente que no es compañero de equipo se genera en sesiones interactivas que ahora se ejecutan en segundo plano de forma predeterminada.
  • Escriba @ en el mensaje para mencionar otra sesión de Claude por su nombre; Claude luego usa SendMessage para llegar a esa sesión directamente.
  • SendMessage ahora ofrece un nombre simple que coincide exactamente con una sesión en vivo, en lugar de pedir confirmación primero con un árbitro.
  • Las sesiones interactivas en una máquina ahora mantienen nombres únicos: iniciar o cambiar el nombre de una sesión a un nombre que ya usa otra sesión en vivo le otorga una variante name-word-word y le informa
  • Se agregaron filas /config para "Caducidad del diálogo" y "Mensajes de sus otras sesiones" (aceptación/retención/rechazo de entrada entre sesiones)
  • Se agregó redacción secreta para las familias de tokens GitLab (glrt-, gloas-, glptt-, glagent-, glimt-, glsoat-, glcbt-, glft-, glffct-) y redacción completa de tokens enrutables glpat-/gldt-; el almacén de configuración glab CLI obtiene la misma zona de pruebas y protección de ruta de credenciales que gh
  • Se agregó compatibilidad con GitLab a los mercados de complementos: las URL de repositorio desnudas de gitlab.com (incluidos los subgrupos anidados) ahora se clonan como las URL de github.com, y las sugerencias de falla de autenticación de clonación nombran su host git real
  • Configuración: additionalMarketplaces y allowedMarketplaces ahora se aceptan como alias más amigables para extraKnownMarketplaces y strictKnownMarketplaces.
  • Política empresarial: una entrada blockedMarketplaces escrita en una URL para una URL de repositorio simple sigue bloqueando esa URL cuando CLI la clasifica como un clon de git.
  • Puerta de enlace: la superposición desktop: ahora acepta todas las configuraciones de escritorio publicadas (antes eran 11 claves enumeradas manualmente), validadas en el arranque con el esquema propio del escritorio; claves desconocidas o no válidas fallan en el arranque
  • Puerta de enlace: las entradas managed.policies[].match.groups/admin.admin_groups vacías y los valores email_domain con formato incorrecto (vacíos o que contienen @, espacios en blanco o comas) ahora fallan en el arranque en lugar de no coincidir silenciosamente con nadie o otorgar acceso de administrador.
  • Fable 5 se ofrece nuevamente como asesor en /advisor para organizaciones con acceso a Fable, con el consentimiento de créditos de uso configurado a través de /model fable.
  • Se corrigió una omisión de permisos de PowerShell donde los parámetros de escritura de variables podían sobrescribir silenciosamente $PSDefaultParameterValues y redirigir el acceso a archivos de comandos posteriores.
  • Se corrigió una omisión de permisos de Windows donde Git Bash seguía enlaces simbólicos estilo Cygwin que la validación de ruta veía como archivos normales; escribir a través de ellos ahora requiere aprobación de permiso
  • Se corrigieron los repositorios git anidados que heredaban trust de un directorio principal; cada repositorio ahora requiere su propia confirmación trust
  • Se corrigieron las conexiones MCP que se bloqueaban durante el tiempo de espera de conexión de 30 segundos completo cuando un servidor no responde o envía una respuesta con formato incorrecto a la sonda de versión del protocolo.
  • Se corrigieron las sesiones de control remoto alojadas por un puente dentro de una sesión en la nube que heredaba la transcripción o las credenciales de esa sesión.
  • Se corrigieron las sesiones de control remoto iniciadas desde Claude Desktop o un IDE que aparecían como una nueva sesión de claude.ai cada vez que se reanudaba la sesión local; ahora se vuelven a unir al existente
  • Se corrigieron las sesiones de control remoto que parecían inalcanzables para los clients recién conectados mientras estaban inactivos.
  • Se corrigieron las sesiones del puente de control remoto que no restauraban el historial de conversaciones cuando se reinicia el trabajador de la sesión.
  • Control remoto: reanudar una conversación cuya sesión fue eliminada de claude.ai o la aplicación ahora inicia un reemplazo en lugar de fallar con un mensaje sobre su inicio de sesión (regresado en v2.1.227)
  • Se corrigió que la puerta de enlace en la nube /login saliera silenciosamente o dejara un terminal que no respondía después de "Presionar Enter para continuar" cuando la configuración administrada no se cargaba; ahora se muestra el motivo
  • Se corrigió que el modo de voz en las versiones nativas se atascara en "escuchar..." cuando el servicio de voz rechazaba la conexión; el rechazo ahora se muestra inmediatamente
  • Se corrigió la rotación del certificado mTLS client que requería un reinicio; Claude Code ahora recarga automáticamente el certificado y la clave rotados en caso de errores de conexión
  • Se corrigieron valores de región de AWS o Vertex con formato incorrecto que se usaban para crear URL de solicitud; ahora vuelven a la región predeterminada
  • Se corrigieron errores de tiempo de espera de inactividad de la transmisión que fallaban en la solicitud en lugar de recuperarse en implementaciones de Bedrock, Vertex y puerta de enlace.
  • Se corrigieron superposiciones de tamaño de contenido que contenían texto truncado que hacía que una columna fuera demasiado ancha y el texto truncado al inicio se colapsaba en puntos suspensivos.
  • Se corrigió un carácter confuso perdido donde una vista previa larga de un comando de shell o una descripción del agente se cortaba a mitad del emoji.
  • Se corrigió una carrera de inicio que podía cancelar silenciosamente el registro de un mercado de complementos debido a escrituras simultáneas en known_marketplaces.json.
  • Se corrigió que /update y /tui se negaran a reiniciarse mientras se ejecutaba el trabajo que sobrevive al reinicio.
  • Se corrigió la guía de límite de uso que sugería comandos de barra no disponibles en SDK y sesiones remotas.
  • Se corrigió el mensaje de consentimiento para los inicios interactivos de --advisor fable, que le indicaba que ejecutara /model fable en una sesión interactiva que acababa de salir.
  • Transmisión en pantalla completa mejorada: las sesiones largas siguen respondiendo porque toda la conversación ya no se vuelve a normalizar con cada actualización.
  • Se mejoró el cuadro de diálogo de aprobación de la configuración administrada: muestra las URL de los terminales, utiliza una redacción más clara para los cambios solo de telemetría, omite las opciones rutinarias de OpenTelemetry y requiere aprobación para las anulaciones binarias de sandbox administradas por el servidor (sandbox.bwrapPath, sandbox.socatPath, sandbox.ripgrep).
  • /feedback y /bug ahora se abren inmediatamente cuando se invocan mientras Claude está respondiendo, en lugar de esperar a que termine el turno.
  • /plugin install plugin@marketplace ahora actualiza primero el mercado, por lo que los complementos recién publicados se instalan sin una actualización manual del mercado.
  • /code-review con esfuerzo alto, xalto y máximo ahora se ejecuta en un agente en segundo plano como los otros niveles
  • Las imágenes pegadas y del tablero cli se leen sin bloquear el bucle de eventos
  • El control remoto ahora continúa reconectándose durante aproximadamente 30 minutos después de un fallo en la red y ya no se desconecta después de algunos fallos repartidos a lo largo de una hora.
  • Control remoto: reanudar una conversación ya no quita silenciosamente el control remoto de otro Claude Code en la misma máquina que todavía lo tiene; ejecuta /remote-control allí para moverlo
  • Panel de agentes actualizado: los subagentes completados se ocultan inmediatamente con una sugerencia de pie de página /tasks y el indicador de desbordamiento "↓ N más" se movió hacia la izquierda para mayor visibilidad.
  • Control remoto: el terminal ahora dice si una sesión fue asumida por otro dispositivo, finalizada desde otra aplicación o eliminada, y deja de sugerir una reconexión que la desharía.
  • Las redirecciones de entrada de Bash (< file) ahora se verifican con permisos al igual que la ortografía de sus argumentos en todas las plataformas.
  • Se acortó el mensaje que se muestra al reanudar un agente en segundo plano completado.
  • Las sesiones de cowork ya no incluyen importaciones @ externas desde archivos de memoria del alcance del usuario.
  • Se ha reforzado el directorio de socket de mensajería entre sesiones generado automáticamente en el /tmp compartido: ahora se rechaza un enlace simbólico preinstalado o el directorio de otro usuario en lugar de usarse.
  • Se fortaleció el entorno limitado del sistema de archivos de Linux frente a una omisión de ruta protegida.
  • Se modificó sandbox.ripgrep para que se respete solo desde la configuración de usuario, administrada y --settings; La configuración del proyecto ya no puede anular el binario ripgrep del sandbox.
  • Se eliminó el consejo de inicio que sugería crear subagentes personalizados y el empujón correspondiente en el recorrido /powerup.

claude-code v2.1.232

What's changed

  • Subagent forking is now on by default: a subagent_type: "fork" subagent inherits the full conversation and prompt cache, and non-teammate agent spawns in interactive sessions now run in the background by default
  • Type @ in the prompt to mention another Claude session by name; Claude then uses SendMessage to reach that session directly
  • SendMessage now delivers to a bare name that exactly matches one live session, instead of asking to confirm with a ref first
  • Interactive sessions on one machine now keep unique names: starting or renaming a session to a name another live session already uses gives it a name-word-word variant and tells you
  • Added /config rows for "Dialog expiry" and "Messages from your other sessions" (cross-session inbound accept/hold/refuse)
  • Added secret redaction for GitLab token families (glrt-, gloas-, glptt-, glagent-, glimt-, glsoat-, glcbt-, glft-, glffct-) and full redaction of routable glpat-/gldt- tokens; the glab CLI config store gets the same sandbox and credential-path protection as gh
  • Added GitLab support to plugin marketplaces: bare gitlab.com repo URLs (including nested subgroups) now clone like github.com URLs, and clone auth-failure hints name your actual git host
  • Settings: additionalMarketplaces and allowedMarketplaces are now accepted as friendlier aliases for extraKnownMarketplaces and strictKnownMarketplaces
  • Enterprise policy: a url-typed blockedMarketplaces entry for a bare repo URL keeps blocking that URL when the CLI classifies it as a git clone
  • Gateway: the desktop: overlay now accepts every released Desktop setting (was 11 hand-listed keys), validated at boot against Desktop's own schema; unknown or invalid keys fail boot
  • Gateway: empty managed.policies[].match.groups/admin.admin_groups entries and malformed email_domain values (empty, or containing @, whitespace, or commas) now fail at boot instead of silently matching no one or granting admin access
  • Fable 5 is offered as an advisor in /advisor again for organizations with Fable access, with usage-credits consent set up through /model fable
  • Fixed a PowerShell permission bypass where variable-writing parameters could silently overwrite $PSDefaultParameterValues and redirect later commands' file access
  • Fixed a Windows permission bypass where Git Bash followed Cygwin-style symlinks that path validation saw as regular files; writes through them now require permission approval
  • Fixed nested git repositories inheriting trust from a parent directory; each repository now requires its own trust confirmation
  • Fixed MCP connections hanging for the full 30-second connect timeout when a server fails to answer or sends a malformed reply to the protocol-version probe
  • Fixed Remote Control sessions hosted by a bridge inside a cloud session inheriting that session's transcript or credentials
  • Fixed Remote Control sessions started from Claude Desktop or an IDE appearing as a new claude.ai session each time the local session was resumed; they now reattach to the existing one
  • Fixed Remote Control sessions appearing unreachable to newly attached clients while idle
  • Fixed Remote Control bridge sessions not restoring conversation history when the session worker restarts
  • Remote Control: resuming a conversation whose session was deleted from claude.ai or the app now starts a replacement instead of failing with a message about your login (regressed in v2.1.227)
  • Fixed Cloud gateway /login exiting silently or leaving an unresponsive terminal after "Press Enter to continue" when managed settings failed to load; the reason is now shown
  • Fixed voice mode on native builds getting stuck on "listening…" when the voice service rejected the connection; the rejection is now shown immediately
  • Fixed mTLS client certificate rotation requiring a restart; Claude Code now reloads the rotated cert and key automatically on connection errors
  • Fixed malformed AWS or Vertex region values being used to build request URLs; they now fall back to the default region
  • Fixed stream idle timeout errors failing the request instead of recovering on Bedrock, Vertex, and gateway deployments
  • Fixed content-sized overlays containing truncated text rendering one column too wide, and start-truncated text collapsing to an ellipsis
  • Fixed a stray garbled character where a long shell-command or agent-description preview was cut off mid-emoji
  • Fixed a startup race that could silently unregister a plugin marketplace due to concurrent writes to known_marketplaces.json
  • Fixed /update and /tui refusing to restart while work that survives the relaunch was running
  • Fixed usage-limit guidance suggesting unavailable slash commands in SDK and remote sessions
  • Fixed the consent message for interactive --advisor fable launches, which told you to run /model fable in an interactive session that had just exited
  • Improved fullscreen streaming: long sessions stay responsive because the whole conversation is no longer re-normalized on every update
  • Improved the managed settings approval dialog: shows endpoint URLs, uses clearer wording for telemetry-only changes, skips routine OpenTelemetry options, and requires approval for server-managed sandbox binary overrides (sandbox.bwrapPath, sandbox.socatPath, sandbox.ripgrep)
  • /feedback and /bug now open immediately when invoked while Claude is responding, instead of waiting for the turn to finish
  • /plugin install plugin@marketplace now refreshes the marketplace first, so newly published plugins install without a manual marketplace update
  • /code-review at high, xhigh, and max effort now runs in a background agent like the other levels
  • Pasted and clipboard images are read without blocking the event loop
  • Remote Control now keeps reconnecting for about 30 minutes after a network blip and no longer drops after a few blips spread across an hour
  • Remote Control: resuming a conversation no longer silently takes Remote Control away from another Claude Code on the same machine that still has it; run /remote-control there to move it
  • Updated agent panel: completed subagents hide immediately with a /tasks footer hint, and the "↓ N more" overflow indicator moved left for visibility
  • Remote Control: the terminal now says whether a session was taken over by another device, ended from another app, or deleted, and stops suggesting a reconnect that would undo it
  • Bash input redirections (< file) are now permission-checked like their argument spellings on all platforms
  • Shortened the message shown when resuming a completed background agent
  • Cowork sessions no longer inline external @-imports from user-scope memory files
  • Hardened the auto-generated cross-session messaging socket directory on shared /tmp: a pre-planted symlink or another user's directory is now refused instead of used
  • Hardened the Linux filesystem sandbox against a protected-path bypass
  • Changed sandbox.ripgrep to be honored only from user, managed, and --settings settings; project settings can no longer override the sandbox's ripgrep binary
  • Removed the startup tip suggesting you create custom subagents, and the matching nudge in the /powerup tour
