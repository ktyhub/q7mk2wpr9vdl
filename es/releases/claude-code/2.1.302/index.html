claude-code v2.1.302

código-claude v2.1.302

¿Qué ha cambiado?

  • Se agregó CLAUDE_CODE_AUTO_MODE_MODEL para elegir el modelo que utiliza el clasificador de modo automático del lado opuesto cli; no cambia el modelo para el modo automático del lado del servidor
  • Se agregó una fila Idle compaction a /config para activar o desactivar la compactación inactiva; Los avisos que se muestran después de una compactación inactiva ahora dicen cómo apagarla.
  • Se agregó un aviso a /design-sync y /design-login de que Claude Design independiente (claude.ai/design) cierra antes del 14 de diciembre de 2026.
  • Se corrigió el error "El mensaje es demasiado largo" al detener un turno mientras se compactaba la conversación.
  • Se corrigieron las solicitudes que fallaban con "diagnóstico: no se permiten entradas adicionales" después de cambiar a Vertex o Bedrock a mitad de sesión.
  • Se corrigió la herramienta de lectura que cargaba un archivo de imagen de cualquier tamaño, o una tubería o dispositivo con nombre como imagen, completamente en la memoria; Las fuentes de imágenes de más de 128 MB ahora se rechazan.
  • Se corrigió que /autocompact y /effort se guardaran en el modelo incorrecto cuando una puerta de enlace nombra Opus 4 o 4.1 con un prefijo, como anthropic/claude-opus-4-1.
  • Se corrigió un error de caché cuando una herramienta agregada a mitad de sesión se cargaba nuevamente a través de ToolSearch o después de la compactación.
  • Se corrigió que claude plugin y otros subcomandos a veces salieran antes de que finalizara una configuración en cola o una escritura de configuración, lo que podría perder el cambio o dejar un archivo .tmp.
  • Se corrigió la clonación de los mercados de complementos en cada actualización, y los complementos de git recién instalados mostraban una versión "desconocida", cuando git tiene por defecto el formato reftable ref.
  • Se corrigió que la herramienta PowerShell no encontrara comandos en la carpeta bin/ de un complemento y reportara un error cuando una búsqueda que no encuentra nada (rg, grep, findstr, git grep) se canaliza a Select-Object u otro cmdlet de formato.
  • Se corrigió que Claude en la aplicación de escritorio lo indicara a la configuración de claude.ai o /mcp para autorizar o reconectar un servidor MCP donde esa opción no está disponible.
  • Se corrigió que las publicaciones de artefactos a veces fallaran cuando Claude enviaba una lista vacía de ediciones, y Claude reintentaba una actualización de artefacto de manera incorrecta después de que una versión más nueva del artefacto lo rechazaba.
  • Se corrigió que classifier_category faltara en los eventos OpenTelemetry tool_decision para la mayoría de los bloques clasificadores en modo automático, y nuevos atributos tool_decision expulsaban a tool_use_id, tool_source y tool_parameters cuando OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT estaba bajo.
  • Se corrigieron las filas en la vista de agentes que permanecían en blanco después de moverse hacia abajo en una lista larga o doblar una sección
  • Se corrigió que claude remote-control --help no imprimiera su uso y saliera cuando no había iniciado sesión.
  • Se corrigió que /design consent y /design revoke sugirieran /design-login cuando fallaban en una sesión en la nube, donde no estaba disponible; el mensaje ahora apunta a claude.ai/design/settings
  • Se corrigieron los servidores MCP que no mostraban herramientas, o fallaban todas las llamadas a herramientas, cuando el servidor negocia la versión del protocolo 2026-07-28 pero omite resultType, ttlMs o cacheScope.
  • Se corrigieron las sugerencias de gasto de créditos de uso en modelos que su plan paga solo con créditos: ahora se omiten después de una respuesta facturada a créditos.
  • Se corrigió que las URL escritas con comillas invertidas fueran clickable solo en su primera fila cuando se ajustaban; la URL completa ahora es un enlace en terminales que admiten hipervínculos
  • Se corrigió claude plugin details <name>@builtin que sugería claude plugin list, que nunca muestra complementos integrados, cuando no se encuentra el complemento; ahora apunta a /plugin
  • Se corrigió un emoji en el que un enlace comienza dentro envolviendo una columna demasiado ancha, lo que lo ocultaba en las vistas previas de las preguntas y convertía las tablas en listas.
  • Se corrigió el aislamiento del árbol de trabajo que se negaba a crear o reanudar árboles de trabajo bajo git 2.56 o posterior cuando un archivo .git perdido apunta a un directorio que no existe.
  • Se corrigió el costo y el uso de una sesión en la nube que se reiniciaba desde cero después de que la sesión se reanudaba en un nuevo proceso.
  • Ejecutor autohospedado: Se corrigió que las recuperaciones de git fallaran con "referencias/cabezales de objetos incorrectos" en sesiones que reutilizan un pago almacenado en el formato reftable de git.
  • Windows: se corrigió cada escritura de archivo rechazada o solicitada para proyectos en unidades exFAT o FAT32, incluso en sesiones iniciadas con --plugin-dir
  • Tiempo de inicio mejorado con muchos complementos habilitados: los archivos de agentes y comandos de complementos ahora requieren muchas menos llamadas al sistema de archivos para cargarse, sobre todo en Windows.
  • Modo automático mejorado con el clasificador del lado del servidor: una conversación demasiado larga para la verificación de seguridad ahora se compacta, en lugar de rechazar cada llamada a la herramienta verificada.
  • Se mejoró el mensaje cuando se vuelve a abrir una sesión en segundo plano desde otra carpeta que no tiene puerta de enlace LLM: ahora dice por qué, en lugar de "No he iniciado sesión".
  • Se cambiaron las sesiones de claude -p y Agent SDK sin modo de permiso para iniciar en modo default en proveedores externos, con telemetría desactivada o en una instalación nueva; --permission-mode auto se mantiene automático
  • Se cambiaron los subagentes de bifurcación (subagent_type: "fork") para que estén activados de forma predeterminada en claude -p, el Agente SDK, la aplicación de escritorio y VS Code, como ya están en la terminal; CLAUDE_CODE_FORK_SUBAGENT=0 los apaga y claude mcp serve nunca los ofrece
  • Se cambió la aplicación de escritorio y VS Code para ejecutar siempre los subagentes de la conversación principal en segundo plano, como lo hace la terminal, en lugar de dejar que Claude elija; Las llamadas del propio agente de un subagente en claude -p, el agente SDK, la aplicación de escritorio y VS Code ahora se ejecutan en primer plano de forma predeterminada.
  • Se cambió la sugerencia del pie de página de ← for agents para ocultarla 10 segundos después de que se abre una sesión; El recuento de agentes que te esperan todavía se muestra.
  • Se modificó la ubicación de las instrucciones de Claude en Chrome en el mensaje del sistema para que las nuevas conversaciones puedan leerlas desde el caché de mensajes compartido.
  • Se cambiaron los enlaces de avisos y agentes para que se ejecuten como máximo 12 de un evento a la vez; el resto espera su turno
  • Se modificó el mensaje que se muestra cuando la política de su organización desactiva /feedback: ahora apunta a problemas de GitHub en lugar de a un administrador de la organización.
  • [VSCode] Se corrigió el texto después de un bloque de código abierto en una lista que se muestra como texto sin formato mientras se transmite una respuesta y luego se convierte en código.
  • [VSCode] Se corrigió el inicio de sesión del servidor MCP desde el panel que abre una página de autorización rota cuando la URL del servidor contiene una cadena de consulta
  • [VSCode] Se corrigió el banner @browser que decía "Navegador conectado" cuando no se podía acceder a ningún navegador con la extensión Claude.
  • [Sesiones en la nube] Se agregó un banner en la página de una rutina que dice por qué no se inició su última ejecución, como por ejemplo si su organización alcanzó su límite de sesiones simultáneas en la nube.
  • [Sesiones en la nube] Se corrigió el error "Rebobinar hasta aquí" en todos los mensajes excepto en el más nuevo en las sesiones en la nube; los corredores autohospedados necesitan el código Claude v2.1.246 o posterior
  • [Sesiones en la nube] Se corrigió la barra de estado de la solicitud de extracción en las sesiones en la nube, lo que hacía que una solicitud de extracción con conflictos de fusión volviera a estar lista mientras GitHub la volvía a verificar.
  • [Sesiones en la nube] Se corrigió que las ejecuciones de rutina se mostraran como Completadas después de que su sesión en la nube se detuviera inesperadamente y como Canceladas cuando se archivaban antes de comenzar, en lugar de fallar.
  • [Sesiones en la nube] Se corrigió la vista de diferencias en las sesiones en la nube que faltaban cambios o no se cargaban después de que se cambió el nombre o se movió el repositorio GitHub de la sesión.
  • [Sesiones en la nube] Se corrigió una ejecución de rutina programada que fallaba a mitad de camino y se ejecutaba nuevamente desde el inicio una hora o más después, lo que podía repetir el trabajo, como publicar el mismo informe dos veces.
  • [Sesiones en la nube] Se corrigió una sesión en la nube abierta que a veces no mostraba mensajes enviados desde otro dispositivo hasta que recargabas la página o cli eliminabas y regresabas.
  • [Sesiones en la nube] Se mejoró el error que se muestra cuando una sesión en la nube no se inicia: ahora dice "Conexión perdida" o "Error del servidor" en lugar de "Algo salió mal".
  • [Control remoto] Se corrigió que el panel de un subagente girara para siempre en una sesión de Control remoto después de que su computadora se desconecta; Ahora dice que el control remoto está desconectado.
  • [Etiqueta de Claude] Se corrigió que "está pensando..." permanecía debajo de una mención en un canal de Slack o DM después de que Claude respondiera editando uno de sus mensajes anteriores.
  • [Etiqueta de Claude] Se corrigieron las URL en bloques de código debajo de un paso numerado o con viñetas de las respuestas de Claude en Slack que estaban entre corchetes angulares, lo que rompía los comandos copiados.
  • [Etiqueta de Claude] Se corrigieron las imágenes HEIC, SVG, TIFF y BMP adjuntas en Slack que nunca llegaban a Claude; ahora llegan como archivos en sus archivos de trabajo, al igual que otros tipos de archivos
  • [Claude Tag] Se corrigió que los nuevos administradores de canales perdieran acceso a Claude en Slack en organizaciones que restringen Claude Tag por función; el rol de administrador ahora también otorga a Claude Tag en Slack
  • [Claude Tag] Se corrigieron los conectores personalizados cuyos servidores MCP comparten un host y se muestran como un único conector en la configuración de administración de Claude Tag; cada servidor es ahora su propio conector
  • [Etiqueta de Claude] Se corrigió que Claude en Slack a veces respondiera un mensaje directo con "Los mensajes directos no están disponibles temporalmente" y lo dejara caer cuando una sola búsqueda en Slack se detenía; ahora lo vuelve a intentar primero
  • [Etiqueta de Claude] Se corrigieron los mensajes directos con Claude en Slack Enterprise Grid ignorando el menú desplegable del espacio de trabajo de Slack; ahora se ejecutan en el espacio de trabajo conectado en el que abriste a Claude por última vez.
  • [Etiqueta de Claude] Se corrigió el aviso de Claude en Slack sobre el límite de gasto mensual de un canal que decía que un administrador de canal puede aumentarlo; ahora nombra al propietario de una organización y vincula la página de uso
  • [Etiqueta de Claude] Se corrigieron los enlaces en las respuestas de Claude en Slack que absorbían las marcas finales en negrita o cursiva, o puntuación de ancho completo, justo después de ellas, lo que rompía el enlace y el formato.
  • [Claude Tag] Búsqueda de repositorio mejorada en la configuración de administración de Claude Tag para cubrir hasta 100 cuentas GitHub conectadas y encontrar repositorios privados más allá de los primeros 5000 de una instalación de la aplicación GitHub
  • [Claude Tag] Mejorado Agregar lugar en la configuración de administración de Claude Tag para enumerar un canal que escribe o pega de inmediato, en lugar de hacerlo solo después de que se haya cargado la lista completa de canales de su organización.
  • [Claude Tag] Se mejoró Agregar > Dominio en la página de un espacio de trabajo o canal en la configuración de administración de Claude Tag para que esté disponible una vez que se cargue la página, no solo después de que se hayan cargado todos los canales.
  • [Claude Tag] Se modificó la configuración de administración de Claude Tag para organizar el acceso de Claude en cuatro pestañas: Paquetes, Conectores, Habilidades y complementos, y Canales.
  • [Claude Tag] Se cambió la página Roles en la configuración de la organización para agrupar los roles creados para los administradores de canales de Claude Tag en una sección contraída debajo de los roles propios de su organización.
  • [Revisión de código] Se corrigió que la configuración de la revisión de código no se reanudara después de salir para conectar GitHub; De nuevo en la configuración de administrador, ahora se vuelve a abrir en el selector de repositorio.

claude-code v2.1.302

What's changed

  • Added CLAUDE_CODE_AUTO_MODE_MODEL to choose the model the client-side auto mode classifier uses; it does not change the model for server-side auto mode
  • Added an Idle compaction row to /config for turning idle compaction off or back on; the notices shown after an idle compaction now say how to turn it off
  • Added a notice to /design-sync and /design-login that standalone Claude Design (claude.ai/design) closes by December 14, 2026
  • Fixed a "Prompt is too long" error when stopping a turn while the conversation was being compacted
  • Fixed requests failing with "diagnostics: Extra inputs are not permitted" after switching to Vertex or Bedrock mid-session
  • Fixed the Read tool loading an image file of any size, or a pipe or device named like an image, entirely into memory; image sources over 128 MB are now refused
  • Fixed /autocompact and /effort saving to the wrong model when a gateway names Opus 4 or 4.1 with a prefix, such as anthropic/claude-opus-4-1
  • Fixed a prompt cache miss when a tool added mid-session was loaded again through ToolSearch or after compaction
  • Fixed claude plugin and other subcommands sometimes exiting before a queued settings or config write finished, which could lose the change or leave a .tmp file behind
  • Fixed plugin marketplaces re-cloning on every refresh, and newly installed git plugins showing version "unknown", when git defaults to the reftable ref format
  • Fixed the PowerShell tool not finding commands in a plugin's bin/ folder, and reporting an error when a search that finds nothing (rg, grep, findstr, git grep) is piped into Select-Object or another formatting cmdlet
  • Fixed Claude in the desktop app pointing you to claude.ai settings or /mcp to authorize or reconnect an MCP server where that option isn't available
  • Fixed artifact publishes sometimes failing when Claude sent an empty list of edits, and Claude retrying an artifact update the wrong way after a newer version of the artifact turned it away
  • Fixed classifier_category missing from OpenTelemetry tool_decision events for most auto mode classifier blocks, and new tool_decision attributes pushing out tool_use_id, tool_source and tool_parameters when OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT is low
  • Fixed rows in the agents view staying blank after moving down a long list or folding a section
  • Fixed claude remote-control --help not printing its usage and exiting when not signed in
  • Fixed /design consent and /design revoke suggesting /design-login when they fail in a cloud session, where it isn't available; the message now points to claude.ai/design/settings
  • Fixed MCP servers showing no tools, or every tool call failing, when the server negotiates protocol version 2026-07-28 but omits resultType, ttlMs or cacheScope
  • Fixed prompt suggestions spending usage credits on models your plan pays for only with credits: they are now skipped after a reply billed to credits
  • Fixed URLs written in backticks being clickable only on their first row when they wrap; the whole URL is now one link in terminals that support hyperlinks
  • Fixed claude plugin details <name>@builtin suggesting claude plugin list, which never shows built-in plugins, when the plugin isn't found; it now points to /plugin
  • Fixed an emoji that a link starts inside wrapping one column too wide, which hid it in question previews and turned tables into lists
  • Fixed worktree isolation refusing to create or resume worktrees under git 2.56 or later when a stray .git file points at a directory that doesn't exist
  • Fixed a cloud session's cost and usage restarting from zero after the session resumed in a new process
  • Self-hosted runner: Fixed git fetches failing with "bad object refs/heads" in sessions that reuse a checkout stored in git's reftable format
  • Windows: Fixed every file write being refused or asked about for projects on exFAT or FAT32 drives, including in sessions started with --plugin-dir
  • Improved startup time with many plugins enabled: plugin command and agent files now take far fewer file system calls to load, most of all on Windows
  • Improved auto mode with the server-side classifier: a conversation too long for the safety check is now compacted, instead of every checked tool call being denied
  • Improved the message when a background session reopened from another folder has no LLM gateway: it now says why, instead of "Not logged in"
  • Changed claude -p and Agent SDK sessions with no permission mode to start in default mode on third-party providers, with telemetry off or on a fresh install; --permission-mode auto keeps auto
  • Changed fork subagents (subagent_type: "fork") to be on by default in claude -p, the Agent SDK, the desktop app and VS Code, as they already are in the terminal; CLAUDE_CODE_FORK_SUBAGENT=0 turns them off, and claude mcp serve never offers them
  • Changed the desktop app and VS Code to always run the main conversation's subagents in the background, as the terminal does, rather than let Claude choose; a subagent's own Agent calls in claude -p, the Agent SDK, the desktop app and VS Code now run in the foreground by default
  • Changed the ← for agents footer hint to hide 10 seconds after a session opens; the count of agents waiting on you still shows
  • Changed where the Claude in Chrome instructions sit in the system prompt so that new conversations can read them from the shared prompt cache
  • Changed prompt and agent hooks so that at most 12 of one event run at a time; the rest wait their turn
  • Changed the message shown when your organization's policy turns off /feedback: it now points to GitHub issues instead of an organization admin
  • [VSCode] Fixed text after an unclosed code block in a list showing as plain text while a reply streams, then turning into code
  • [VSCode] Fixed MCP server sign-in from the panel opening a broken authorization page when the server URL contains a query string
  • [VSCode] Fixed the @browser banner saying "Browser connected" when no browser with the Claude extension can be reached
  • [Cloud sessions] Added a banner on a routine's page that says why its last run didn't start, such as your organization reaching its limit on concurrent cloud sessions
  • [Cloud sessions] Fixed "Rewind to here" failing on every message except the newest in cloud sessions; self-hosted runners need Claude Code v2.1.246 or later
  • [Cloud sessions] Fixed the pull request status bar in cloud sessions flipping a pull request with merge conflicts back to ready while GitHub rechecked it
  • [Cloud sessions] Fixed routine runs showing as Completed after their cloud session stopped unexpectedly, and as Cancelled when archived before they started, instead of failed
  • [Cloud sessions] Fixed the diff view in cloud sessions missing changes or failing to load after the session's GitHub repository was renamed or moved
  • [Cloud sessions] Fixed a scheduled routine run that failed partway being run again from the start an hour or more later, which could repeat work such as posting the same report twice
  • [Cloud sessions] Fixed an open cloud session sometimes not showing messages sent from another device until you reloaded the page or clicked away and back
  • [Cloud sessions] Improved the error shown when a cloud session fails to start: it now says "Connection lost" or "Server error" instead of "Something went wrong"
  • [Remote Control] Fixed a subagent's pane spinning forever in a Remote Control session after your computer goes offline; it now says Remote Control is disconnected
  • [Claude Tag] Fixed "is thinking…" staying up under a mention in a Slack channel or DM after Claude answered it by editing one of its earlier messages
  • [Claude Tag] Fixed URLs in code blocks under a numbered or bulleted step of Claude's Slack replies being wrapped in angle brackets, which broke copied commands
  • [Claude Tag] Fixed HEIC, SVG, TIFF and BMP images attached in Slack never reaching Claude; they now arrive as files in its working files, like other file types
  • [Claude Tag] Fixed new channel managers losing access to Claude in Slack in organizations that restrict Claude Tag by role; the manager role now also grants Claude Tag in Slack
  • [Claude Tag] Fixed custom connectors whose MCP servers share one host showing as a single connector in Claude Tag admin settings; each server is now its own connector
  • [Claude Tag] Fixed Claude in Slack sometimes answering a direct message with "DMs are temporarily unavailable" and dropping it when a single Slack lookup stalled; it now retries first
  • [Claude Tag] Fixed direct messages with Claude on a Slack Enterprise Grid ignoring Slack's workspace dropdown; they now run under the connected workspace you last opened Claude in
  • [Claude Tag] Fixed Claude in Slack's notice for a channel's monthly spend limit saying a channel manager can raise it; it now names an organization owner and links the usage page
  • [Claude Tag] Fixed links in Claude's Slack replies absorbing the closing bold or italic marks, or full-width punctuation, right after them, which broke the link and the formatting
  • [Claude Tag] Improved repository search in Claude Tag admin settings to cover up to 100 connected GitHub accounts and find private repositories past the first 5,000 of a GitHub App install
  • [Claude Tag] Improved Add place in Claude Tag admin settings to list a channel you type or paste right away, instead of only after your organization's full channel list has loaded
  • [Claude Tag] Improved Add > Domain on a workspace's or channel's page in Claude Tag admin settings to be available once that page loads, not only after every channel has loaded
  • [Claude Tag] Changed Claude Tag admin settings to organize Claude's access into four tabs: Bundles, Connectors, Skills and plugins, and Channels
  • [Claude Tag] Changed the Roles page in organization settings to group the roles created for Claude Tag channel managers in a collapsed section below your organization's own roles
  • [Code Review] Fixed Code Review setup not resuming after you leave to connect GitHub; back in admin settings, it now reopens at the repository picker
