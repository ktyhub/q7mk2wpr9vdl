código-claude v2.1.212

¿Qué ha cambiado?

  • /fork ahora copia tu conversación en una nueva sesión en segundo plano (su propia fila en claude agents) mientras sigues trabajando; el subagente en sesión que solía lanzar ahora es /subtask
  • Se agregó claude auto-mode reset para restaurar la configuración predeterminada del modo automático, con un mensaje de confirmación (pase --yes para omitir)
  • Se agregó un límite para toda la sesión en las llamadas a la herramienta WebSearch (predeterminado 200, ajustable a través de CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION) para detener los bucles de búsqueda descontrolados.
  • Se agregó un límite por sesión en la generación de subagentes (predeterminado 200, anulado con CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION) para detener los bucles de delegación descontrolados; /clear restablece el presupuesto
  • Las llamadas a la herramienta MCP que duran más de 2 minutos ahora pasan a un segundo plano automáticamente para que la sesión siga siendo utilizable; configurar el umbral o desactivar con CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS
  • Al escribir /resume en la vista del agente ahora se abre un selector de sesiones pasadas (incluidas las sesiones eliminadas de la lista) y se reanuda la selección como sesión en segundo plano.
  • Se corrigió el modo de plan de ejecución automática de comandos Bash de modificación de archivos (por ejemplo, touch, rm) sin solicitud de permiso o devolución de llamada SDK canUseTool.
  • Se corrigió la creación del árbol de trabajo siguiendo un enlace simbólico confirmado por el repositorio en .claude/worktrees, que podría crear archivos fuera del repositorio.
  • Se corrigió que un gancho continue:false se detuviera cuando la herramienta fallaba o se completaba a mitad de proceso, y los errores de infraestructura del gancho se informaban erróneamente como rechazos del usuario.
  • Se corrigió SIGTERM durante la ejecución de una herramienta Bash que dejaba huérfano el árbol de procesos del comando en modo print/SDK; el CLI ahora aborta el giro, mata el árbol y sale 143
  • Se corrigió el error /background y claude --bg con "EUNKNOWN: error desconocido, uv_spawn" en Windows cuando la Política de grupo bloquea PowerShell 5.1; el demonio ahora prefiere PowerShell 7
  • Se corrigió el modo Shell (!) que no ejecutaba comandos que contenían rutas de archivos mientras la ventana emergente de autocompletar ruta estaba abierta
  • Se corrigieron las notificaciones de denegación en modo automático que mostraban caracteres rotos cuando un motivo de denegación prolongado se truncaba a mitad del emoji.
  • Se corrigió que Ctrl+J no insertara una nueva línea en la entrada de despacho de la vista del agente en terminales con informes de clave extendidos y apareció el acceso directo de nueva línea en la superposición de ayuda de ?.
  • Se corrigió que /ultrareview rechazara referencias de relaciones públicas como #123, PR 123 y URL de relaciones públicas pegadas; Las sugerencias de error ahora nombran el comando que realmente escribiste.
  • Se corrigió que /ultrareview <branch> no recuperara la rama desde el origen cuando existía de forma remota; ahora sugiere el nombre de la sucursal más cercana en caso de errores tipográficos.
  • Se corrigió que /ultrareview omitiera la confirmación de facturación en una nueva conversación después de /clear.
  • Se corrigió el error "no es un repositorio git" de /ultrareview en Claude Desktop que ahora sugiere la carpeta del repositorio del proyecto en lugar de comandos de terminal.
  • Se corrigieron errores en las sesiones alojadas (administradas por el host) en el inicio cuando la configuración del repositorio configuraba certificados mTLS, paquetes de CA adicionales o alcances OAuth; estas configuraciones de transporte ahora se ignoran con una advertencia
  • Se corrigió un falso error "El archivo aún no se ha leído" al editar un archivo que se había leído con desplazamiento/límite antes de reanudar una sesión.
  • Se corrigió el error de ExitWorktree con "ninguna sesión activa de EnterWorktree" después de reanudar una sesión con --continue/--resume en modo de impresión/SDK.
  • Se corrigió que la cuadrícula del agente de flujo de trabajo permaneciera vacía para los clients de control remoto que se unen a una sesión a mitad de ejecución.
  • Se corrigió que las solicitudes de control del modo de transmisión se marcaran como completas antes de que terminara su controlador, lo que podría perder la solicitud al reiniciar la sesión.
  • Se corrigieron sesiones en segundo plano creadas con /fork que perdían su protección de padres en vivo después de una falla de escritura de estado.
  • Se corrigió que la reapertura de una sesión en segundo plano detenida desde la vista del agente fallara silenciosamente: ahora reanuda la sesión o muestra por qué no puede y le permite forzar un reinicio.
  • Se corrigieron los equipos de agentes: un compañero de equipo que se detenía podía enviar al líder notificaciones inactivas duplicadas cuando la inicialización del equipo se volvía a ejecutar dentro de una sesión.
  • Se corrigió el pie de página del cuadro de diálogo de aprobación del plan que separaba "ctrl+g para editar en <editor>" cuando la ruta del archivo es larga.
  • Se corrigió que el banner de bienvenida mantuviera el ancho del panel anterior después de cambiar el tamaño del terminal combinado de ancho y alto en modo de pantalla completa.
  • Se corrigieron las vistas previas de diferencias que perdían sus números de línea y marcadores +/- en diseños estrechos
  • Se corrigieron @-menciones que no adjuntaban nada después de una lectura parcial del archivo, desinstalación del complemento dirigida al mercado equivocado y falso "Se agotó el tiempo de espera del comando" en el código de salida 143.
  • Se corrigió que las exportaciones HTTP OpenTelemetry fueran rechazadas con 411/400 por Azure Monitor y otros puntos finales que no aceptan codificación de transferencia fragmentada.
  • Se corrigieron los registros de eventos de OTLP que faltaban trace_id/span_id cuando TRACEPARENT estaba configurado en SDK/modo sin cabeza.
  • Se corrigieron conversaciones con muchas imágenes que fallaban incorrectamente con errores de "Solicitud demasiado grande" y se mejoró el mensaje de error para explicar la causa real.
  • Se corrigió que la búsqueda web y la recuperación web devolvieran el texto "Error API" como resultados de búsqueda o contenido de la página cuando el API estaba sobrecargado.
  • Búsqueda web mejorada y confiabilidad de recuperación web al reintentar errores 529 y solicitudes de velocidad limitada con retroceso limitado
  • Almacenamiento en caché de avisos mejorado: el bloque del sistema a mitad de la conversación ahora funciona detrás de puertas de enlace LLM y URL base personalizadas (Bedrock, Vertex, 1P)
  • Adjuntar agente en segundo plano mejorado: la conexión en frío ahora muestra instantáneamente la transcripción formateada mientras se inicia la sesión, en lugar de una espera en blanco.
  • Uso reducido de tokens en la mensajería entre agentes: los cuerpos de SendMessage ya no se duplican en el historial reproducido ni en los resultados de las herramientas.
  • Se cambió /fork para nombrar la copia después de su mensaje cuando la sesión no tiene título, para que la fila sea reconocible en la vista del agente.
  • Se modificó /btw para reabrir el panel de preguntas secundarias en su intercambio más reciente para que pueda buscar respuestas anteriores.
  • Se cambió la sugerencia del pie de página de ← para que pulse N done por un momento cuando un agente en segundo plano finaliza mientras nada necesita su intervención.
  • Se desaprobó el parámetro mode de la herramienta Tarea (ahora se ignora); Los subagentes heredan el modo de permiso de la sesión principal de forma predeterminada.
  • Se modificó Enterprise forceLoginMethod para que se aplique a los inicios de sesión de extensión VS Code, SDK, setup-token y install-github-app, no solo para el terminal.
  • Se modificaron las transcripciones de las sesiones para registrar el nivel de esfuerzo de razonamiento en cada mensaje del asistente.
  • Se cambiaron las sesiones sin cabeza/SDK para aplicar una solicitud de control de set_model a mitad de turno; el siguiente modelo de ida y vuelta utiliza el nuevo modelo en lugar de esperar el siguiente turno
  • Se modificó la vista del agente/claude agents --json: las sesiones en espera en un entorno de pruebas, entrada de MCP o mensaje de configuración administrada ahora se muestran como "Necesita entrada" en lugar de "Trabajando".
  • Se actualizó el título del panel de estado de autenticación de "Autenticación en la nube" a "Autenticación".
  • Se corrigió un release note (2.1.200) anterior: tmux a través de la serie 3.6 carece de salida sincronizada; El tmux más nuevo con soporte se detecta automáticamente.

claude-code v2.1.212

What's changed

  • /fork now copies your conversation into a new background session (its own row in claude agents) while you keep working; the in-session subagent it used to launch is now /subtask
  • Added claude auto-mode reset to restore the default auto-mode configuration, with a confirmation prompt (pass --yes to skip)
  • Added a session-wide limit on WebSearch tool calls (default 200, tunable via CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION) to stop runaway search loops
  • Added a per-session cap on subagent spawns (default 200, override with CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION) to stop runaway delegation loops; /clear resets the budget
  • MCP tool calls running longer than 2 minutes now move to the background automatically so the session stays usable; configure the threshold or disable with CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS
  • Typing /resume in the agent view now opens a picker of past sessions — including sessions deleted from the list — and resumes your pick as a background session
  • Fixed plan mode auto-running file-modifying Bash commands (e.g. touch, rm) without a permission prompt or SDK canUseTool callback
  • Fixed worktree creation following a repository-committed symlink at .claude/worktrees, which could create files outside the repository
  • Fixed a continue:false hook's halt being dropped when the tool fails or completes mid-stream, and hook infrastructure errors being misreported as user rejections
  • Fixed SIGTERM during a running Bash tool orphaning the command's process tree in print/SDK mode; the CLI now aborts the turn, kills the tree, and exits 143
  • Fixed /background and claude --bg failing with "EUNKNOWN: unknown error, uv_spawn" on Windows when Group Policy blocks PowerShell 5.1; the daemon now prefers PowerShell 7
  • Fixed shell mode (!) not executing commands containing file paths while the path autocomplete popup was open
  • Fixed auto-mode denial notifications rendering broken characters when a long denial reason was truncated mid-emoji
  • Fixed Ctrl+J not inserting a newline in the agent view dispatch input on terminals with extended key reporting, and surfaced the newline shortcut in the ? help overlay
  • Fixed /ultrareview rejecting PR references like #123, PR 123, and pasted PR URLs; error hints now name the command you actually typed
  • Fixed /ultrareview <branch> not fetching the branch from origin when it exists remotely; it now suggests the closest branch name on typos
  • Fixed /ultrareview skipping the billing confirmation in a new conversation after /clear
  • Fixed /ultrareview's "not a git repository" error on Claude Desktop now suggesting the project's repository folder instead of terminal commands
  • Fixed hosted (host-managed) sessions failing at startup when repository settings configured mTLS certs, extra CA bundles, or OAuth scopes; these transport settings are now ignored with a warning
  • Fixed a spurious "File has not been read yet" error when editing a file that had been read with offset/limit before resuming a session
  • Fixed ExitWorktree failing with "no active EnterWorktree session" after resuming a session with --continue/--resume in print/SDK mode
  • Fixed the workflow agent grid staying empty for Remote Control clients that join a session mid-run
  • Fixed streaming-mode control requests being marked complete before their handler finished, which could lose the request on session restart
  • Fixed background sessions created with /fork losing their live-parent protection after a state write failure
  • Fixed reopening a stopped background session from the agent view failing silently — it now resumes the session, or shows why it can't and lets you force a restart
  • Fixed agent teams: a stopping teammate could send the leader duplicate idle notifications when team initialization re-ran within a session
  • Fixed the plan-approval dialog footer splitting "ctrl+g to edit in <editor>" apart when the file path is long
  • Fixed the welcome banner keeping its old panel widths after a combined width+height terminal resize in fullscreen mode
  • Fixed diff previews losing their line numbers and +/- markers in narrow layouts
  • Fixed @-mentions attaching nothing after a partial file read, plugin uninstall targeting the wrong marketplace, and false "Command timed out" on exit code 143
  • Fixed OpenTelemetry HTTP exports being rejected with 411/400 by Azure Monitor and other endpoints that don't accept chunked transfer encoding
  • Fixed OTLP event log records missing trace_id/span_id when TRACEPARENT is set in SDK/headless mode
  • Fixed conversations with many images incorrectly failing with "Request too large" errors, and improved the error message to explain the actual cause
  • Fixed web search and web fetch returning "API Error" text as search results or page content when the API was overloaded
  • Improved web search and web fetch reliability by retrying 529 errors and rate-limited requests with bounded backoff
  • Improved prompt caching: the mid-conversation system block now works behind LLM gateways and custom base URLs (Bedrock, Vertex, 1P)
  • Improved background agent attach: cold-attaching now instantly shows the formatted transcript while the session boots, instead of a blank wait
  • Reduced token usage in inter-agent messaging: SendMessage bodies are no longer duplicated into replayed history and tool results
  • Changed /fork to name the copy after your prompt when the session has no title, so the row is recognizable in the agent view
  • Changed bare /btw to reopen the side-question panel on your most recent exchange so you can browse earlier answers
  • Changed the ← footer hint to pulse N done for a moment when a background agent finishes while nothing needs your input
  • Deprecated the Task tool's mode parameter (now ignored); subagents inherit the parent session's permission mode by default
  • Changed Enterprise forceLoginMethod to be enforced for VS Code extension, SDK, setup-token, and install-github-app logins, not just the terminal
  • Changed session transcripts to record the reasoning effort level on each assistant message
  • Changed headless/SDK sessions to apply a set_model control request mid-turn; the next model round-trip uses the new model instead of waiting for the next turn
  • Changed agent view / claude agents --json: sessions waiting on a sandbox, MCP-input, or managed-settings prompt now show as "Needs input" instead of "Working"
  • Updated the auth status panel title from "Cloud authentication" to "Authentication"
  • Corrected an earlier release note (2.1.200): tmux through the 3.6 series lacks synchronized output; newer tmux with support is detected automatically
