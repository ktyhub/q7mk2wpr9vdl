go-ethereum v1.17.2

<!-- Supresor EMF (v1.17.2) -->

Esta es una versión de mantenimiento con varias correcciones de errores importantes. En particular, un problema crítico en debug_executionWitness podría dañar previamente los datos del nodo; se recomienda encarecidamente a los usuarios que dependen de este punto final RPC que lo actualicen.

Geth ahora también admite la sincronización con cadenas donde se ha eliminado la historia anterior a Praga y permite eliminarla explícitamente a través de geth prune-history --history.chain postprague.

Geth

  • Establezca el tamaño de caché predeterminado en 4 GB en todas las redes (#33836, #33975)
  • Se agregó soporte para el historial de la cadena de poda antes de la bifurcación de Praga (#33657, #34036)
  • Se agregó el comando fetchpayload para crear testigos de ejecución para bloques específicos (#33919)
  • Importación optimizada del historial de Era con inserción por lotes (#33894)
  • Se agregó objetivo womir para el portero (#34079)
  • Se agregó soporte para iterar un único intento de almacenamiento en geth snapshot traverse-state y geth snapshot traverse-rawstate (#34051)

Núcleo

  • Actualizaciones de la bifurcación de Amsterdam:
    • EIP-8024: Cambiar a normalización sin sucursales y ampliar EXCHANGE (#33869)
    • EIP-7778: Bloquear contabilidad de gas sin reembolsos (#33593)
    • EIP-7954: Aumentar el tamaño máximo del contrato (#33832)
    • EIP-7708: las transferencias ETH ahora emiten registros (#33645)
    • Orden de medición de gas reelaborada (requisito previo para EIP-7928) (#33648)
  • Creación de carga útil mejorada mediante el precalentamiento de los nodos trie para el cálculo del hash de estado (#33945)
  • Varias mejoras en los intentos binarios (#33951, #33961, #33989, #34021, #34032, #34022, #34056)
  • Se actualizó go-eth-kzg a v1.5.0, lo que reduce significativamente las asignaciones en VerifyCellProofBatch (#33963)
  • Base de datos de estado refactorizada en preparación para la integración de prueba binaria (#33816)
  • Se habilitó la retención del historial de nodos trie en nodos existentes (#33934)
  • Indexador de estado histórico optimizado con procesamiento por lotes (#33640)
  • Se corrigió un posible punto muerto en txlookup (#34039)
  • Se agregaron nuevos RLP API (#34052, #34048)
  • Se corrigió la falla de dir.Sync() en el congelador en Windows (#34115)

Redes

  • Evite conexiones duplicadas omitiendo marcaciones entrantes/salientes simultáneas (#33198)
  • Se corrigió la falta de coincidencia de claves de sesión mediante el uso de un manejo consistente de direcciones remotas en las pruebas de discv5 (#34031)
  • Se agregó resolución de nombre de host DNS para nodos de arranque (#34101)

RPC

  • Se solucionó el problema de corrupción estatal en debug_executionWitness; debug_executionWitnessByHash en desuso (#33931)
  • Se agregó el campo MaxUsedGas a la respuesta eth_simulateV1 (#32789)
  • Se corrigió el manejo de la tapa de gasolina en eth_simulateV1 (#33952)
  • Se corrigió el caso de reversión nonce durante la creación del contrato en tracer (#33978)
  • Se corrigió que eth_createAccessList devolviera una lista vacía en lugar de nula para las claves de almacenamiento (#33976)
  • eth_getFilterLogs ahora devuelve un error si el segmento de cadena solicitado ha sido podado (#33823)
  • Se corrigió la codificación del número de ranura en las respuestas RPC (#34005)
  • Aplicar límites de llamadas RPC para eth_simulateV1 (#34616)
  • Aplicar límites de espacio de almacenamiento para pruebas en eth_getProof (#34617)

Observabilidad

  • Varias correcciones de OpenTelemetry (#33927, #33955)
  • Se agregó soporte OpenTelemetry para la creación de carga útil (#33773)

Construir

  • Se corrigieron problemas de compilación en FreeBSD (#34008)

Para obtener un resumen completo de los cambios, consulte el hito del lanzamiento de Geth 1.17.2.

Como con todos nuestros lanzamientos anteriores, puede encontrar:

  • Binarios prediseñados para todas las plataformas en nuestra [página de descargas] (https://geth.ethereum.org/downloads/).
  • Imágenes Docker publicadas bajo ethereum/client-go (use la etiqueta "estable").
  • Paquetes de Ubuntu en nuestro [repositorio PPA de Launchpad] (https://launchpad.net/~ethereum/+archive/ubuntu/ethereum).
  • Paquetes de macOS en nuestro repositorio Homebrew Tap.

go-ethereum v1.17.2

<!-- EMF Suppressor (v1.17.2) -->

This is a maintenance release with several important bug fixes. Notably, a critical issue in debug_executionWitness could previously corrupt node data, users relying on this RPC endpoint are strongly advised to upgrade.

Geth now also supports syncing with chains where pre-Prague history has been pruned, and allows explicitly removing it via geth prune-history --history.chain postprague.

Geth

  • Set default cache size to 4GB across all networks (#33836, #33975)
  • Added support for pruning chain history prior to the Prague fork (#33657, #34036)
  • Added fetchpayload command to build execution witnesses for specific blocks (#33919)
  • Optimized Era history import with batched insertion (#33894)
  • Added womir target for keeper (#34079)
  • Added support for iterating a single storage trie in geth snapshot traverse-state and geth snapshot traverse-rawstate (#34051)

Core

  • Amsterdam fork updates:
    • EIP-8024: Switch to branchless normalization and extend EXCHANGE (#33869)
    • EIP-7778: Block gas accounting without refunds (#33593)
    • EIP-7954: Increase maximum contract size (#33832)
    • EIP-7708: ETH transfers now emit logs (#33645)
    • Reworked gas measurement order (prerequisite for EIP-7928) (#33648)
  • Improved payload building by prewarming trie nodes for state hash computation (#33945)
  • Various binary trie improvements (#33951, #33961, #33989, #34021, #34032, #34022, #34056)
  • Upgraded go-eth-kzg to v1.5.0, significantly reducing allocations in VerifyCellProofBatch (#33963)
  • Refactored state database in preparation for binary trie integration (#33816)
  • Enabled trie node history retention on existing nodes (#33934)
  • Optimized historical state indexer with batch processing (#33640)
  • Fixed potential deadlock in txlookup (#34039)
  • Added new RLP APIs (#34052, #34048)
  • Fix dir.Sync() failure in freezer on Windows (#34115)

Networking

  • Avoid duplicate connections by skipping simultaneous inbound/outbound dials (#33198)
  • Fixed session key mismatch by using consistent remote address handling in discv5 tests (#34031)
  • Added DNS hostname resolution for bootstrap nodes (#34101)

RPC

  • Fixed state corruption issue in debug_executionWitness; deprecated debug_executionWitnessByHash (#33931)
  • Added MaxUsedGas field to eth_simulateV1 response (#32789)
  • Fixed gas cap handling in eth_simulateV1 (#33952)
  • Fixed nonce revert edge case during contract creation in tracer (#33978)
  • Fixed eth_createAccessList to return an empty list instead of null for storage keys (#33976)
  • eth_getFilterLogs now returns an error if the requested chain segment has been pruned (#33823)
  • Fixed slot number encoding in RPC responses (#34005)
  • Enforce RPC call limits for eth_simulateV1 (#34616)
  • Enforce storage slot limits for proofs in eth_getProof (#34617)

Observability

  • Various OpenTelemetry fixes (#33927, #33955)
  • Added OpenTelemetry support for payload building (#33773)

Build

  • Fixed build issues on FreeBSD (#34008)

For a full rundown of the changes please consult the Geth 1.17.2 release milestone.

As with all our previous releases, you can find the:

  • Pre-built binaries for all platforms on our downloads page.
  • Docker images published under ethereum/client-go (use "stable" tag).
  • Ubuntu packages in our Launchpad PPA repository.
  • macOS packages in our Homebrew Tap repository.
