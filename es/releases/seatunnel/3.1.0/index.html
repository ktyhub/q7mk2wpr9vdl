3.1.0 Release Note

¡Esta es otra versión importante para Apache SeaTunnel después de la versión 3.0.0!

La versión 3.1.0 incluye 395 PR y 11 conectores nuevos, centrándose en la estabilidad del motor Zeta y la corrección de los datos del Conector V2. También mejora la implementación, las operaciones y la transformación de datos para hacer que los trabajos de integración de datos de producción sean más confiables.

Gracias a todos los contribuyentes por su arduo trabajo en esta actualización. Creemos que la versión 3.1.0 brindará a la comunidad una experiencia de integración de datos más estable y confiable.

Destacados

  • Modo de aplicación nativo Kubernetes: implemente un maestro dedicado y una cantidad fija de trabajadores por trabajo, con limpieza automática de recursos cuando finaliza el trabajo, proporcionando aislamiento de recursos y liberación de recursos bajo demanda para trabajos de procesamiento de datos únicos y equipos que ejecutan cargas de trabajo por lotes a gran escala.
  • Versión mínima de Java elevada a 11, con soporte hasta Java 17.

3.1.0 Release Note

This is another important release for Apache SeaTunnel following version 3.0.0!

Version 3.1.0 includes 395 PRs and 11 new connectors, with a focus on Zeta engine stability and Connector-V2 data correctness. It also improves deployment, operations, and data transformation to make production data integration jobs more reliable.

Thank you to all contributors for their hard work on this update. We believe version 3.1.0 will bring the community a more stable and reliable data integration experience.

Highlights

  • Native Kubernetes Application Mode: Deploy a dedicated Master and a fixed number of Workers per job, with automatic resource cleanup when the job finishes, providing resource isolation and on-demand resource release for one-off data processing jobs and teams running large-scale batch workloads.
  • Minimum Java version raised to 11, with support up to Java 17.
