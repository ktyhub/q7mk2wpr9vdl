orca v1.4.254

Git Graph, dictado por teléfono y preguntas paralelas en el chat ✨

  • 🌳 Ver el repositorio completo: Una nueva pestaña de Git Graph muestra ramas y etiquetas locales y remotas, con los detalles de cada confirmación y los archivos modificados. Los espacios de trabajo de carpetas ahora obtienen Control de código fuente, con una tarjeta para cada repositorio adjunto, y el nombre de la rama en Control de código fuente cambia o crea una rama en su lugar.
  • 💬 Pregunta sin descarrilar un chat: En la interfaz de usuario del chat, /btw hace una pregunta secundaria en una bifurcación al lado del chat mientras el original sigue ejecutándose, y /fork se bifurca desde la última respuesta. Los chats que se abren o envían a una solicitud de extracción muestran una línea corta cuando su CI pasa o falla.
  • 🎙️ Dice desde cualquier lugar: Los teléfonos pueden convertir la voz en texto en el dispositivo (iPhone con iOS 26 o posterior, y Android), con la computadora como alternativa. La computadora, los teléfonos y la web client pueden dictar al mismo tiempo, y el dictado en el dispositivo se ejecuta en su propio proceso, por lo que una falla o bloqueo del motor de voz ya no hace que Orca caiga.
  • 📱 Un teléfono que se aferra a tu trabajo: El chat envía cola mientras el escritorio está inaccesible y sale en orden cuando regresa. Los borradores de chat, los archivos adjuntos, las ediciones de archivos no guardados y los borradores de automatización sobreviven a la eliminación de la aplicación y las pantallas se vuelven a abrir desde lo que ya tiene el teléfono.
  • ⌨️ No más retrasos al escribir en las cuentas del Codex: La escritura podría retrasarse en Orca mientras vinculaba el historial del Codex entre cuentas. Ese trabajo ya no bloquea la aplicación. Los terminales remotos también envían una única pulsación de tecla de inmediato y leen la salida comprimida de los hosts remotos.
  • 🔐 Emparejamiento más seguro y trust: Un código de emparejamiento deja de funcionar una vez que el dispositivo que lo usó guarda su propio inicio de sesión, las conexiones de escritorio y CLI a servidores remotos usan el cifrado más nuevo, y orca serve rechaza conexiones de direcciones públicas de Internet a menos que haya una razón para permitirlas. Orca pregunta una vez por nuevo repositorio antes de enviarlo a los agentes.
  • 🎨 Haz tuyo Orca: Importa el ícono de tu propia aplicación, deja que los complementos del tema reproduzcan un video de fondo en bucle y envíen sus propias fuentes, y lee Configuración en tarjetas tituladas. Claude Code puede coincidir con el tema de tu terminal Orca si dices que sí.
  • 🤖 Mejor soporte para agentes: Los chats antigravedad se pueden ejecutar en la propia plataforma del anfitrión, incluidos los chats de acceso completo, y Muse muestra su cuota de suscripción en la barra de estado.

Destacados

  • Chat: /btw hace una pregunta paralela en un tenedor y /fork bifurca a partir de la última respuesta, con una rueda giratoria mientras se abre el tenedor. Los chats muestran resultados de CI para las solicitudes de extracción que abrieron o enviaron, y cada mensaje, comando y dirección en espera ahora se encuentra en una cola ordenada que puede mover, eliminar o enviar.
  • Teléfono: Envíe mientras el escritorio está desconectado, guarde borradores, archivos adjuntos, ediciones de archivos y borradores de automatización en todas las aplicaciones y vea la lista del espacio de trabajo, las pestañas de sesión y Revisar desde la memoria mientras se actualizan. Las carpetas grandes cargan 500 entradas a la vez con Buscar todo, Revisar precarga el archivo anterior y siguiente, y una línea delgada debajo del encabezado muestra cuándo se actualizan los datos almacenados en caché.
  • Dictado: Los teléfonos pueden transcribir en el dispositivo y cada dispositivo puede dictar a la vez. En el escritorio, el modelo de voz se carga antes del primer dictado (una nueva configuración elige cuándo descargarlo), el dictado se detiene después de un minuto de silencio y conserva lo que usted dijo, el texto dictado recibe un espacio antes y el texto que no se puede insertar se copia en su lugar. La web emparejada client puede dictar a través del host.
  • Control de código fuente y editor: Git Graph, control de código fuente para espacios de trabajo de carpetas y un selector de ramas in situ en el encabezado del control de código fuente. Los archivos completamente nuevos y eliminados muestran un tono limpio, Markdown mantiene sus colores de sintaxis bajo los temas de los complementos, las vistas previas HTML se abren en el propio grupo de pestañas del editor y Copiar como PNG dice cuando una imagen es demasiado grande en lugar de reclamar que se copió.
  • Agentes y cuentas: Se corrigió el retraso en la escritura del historial de cuentas del Codex. Los chats de Antigravity se pueden ejecutar en la plataforma del host cuando éste inicia sesión, las sesiones de Antigravity en AI Vault pueden revelar su carpeta de artefactos y Muse muestra su cuota y mantiene los paneles funcionando mientras se ejecutan los subagentes en segundo plano. El menú de inicio de nueva pestaña es más simple, el selector de agentes busca modelos en sus submenús y, después de reiniciar, se les indica a los agentes que finalicen la tarea original.
  • Hosts remotos: Los terminales remotos responden antes a las pulsaciones de teclas, los chats de escritorio en hosts remotos transmiten solo el texto nuevo y el sondeo se ralentiza mientras la ventana de Orca está visible pero no enfocada. Los servidores SSH administrados se recuperan después de un inicio de sesión lento en ProxyCommand y en más casos de servidores inactivos, y las automatizaciones para un host SSH administrado van a su propio servidor Orca.
  • Apariencia: Importe un ícono de aplicación personalizado, use menús temáticos y controles segmentados más claros, y use fuentes web y videos de fondo en bucle desde complementos. Los complementos de temas también pueden diseñar el texto y la selección del chat, que ahora es más fácil de leer en modo oscuro. Las pestañas de archivos y del navegador se ajustan a sus títulos, por lo que se ajustan más antes de que se desplace la tira de pestañas.

Notas de compatibilidad y actualización

  • Coincidencia de temas de Claude Code: Orca ahora puede hacer coincidir el tema de Claude Code con el tema de su terminal Orca. Está desactivado para todos, incluidos los perfiles nuevos. La próxima vez que se ejecute Claude Code, Orca pregunta una vez en un brindis. Nada en ~/.claude/settings.json cambia a menos que usted acepte, y puede cambiarlo más tarde en Configuración>Apariencia>Terminal.
  • Atajo de búsqueda: Los nuevos perfiles de Mac abren la búsqueda con Cmd+K y no tienen un atajo predeterminado para borrar el terminal. Los nuevos perfiles de Windows y Linux utilizan Ctrl+K. Los perfiles existentes conservan sus accesos directos, incluidos los personalizados y los deshabilitados.
  • Carpeta de agente trust: La primera vez que inicia un agente en un nuevo repositorio, Orca pregunta si trust el repositorio o deja que cada agente pregunte por sí mismo. Los repositorios que ya utilizas siguen funcionando como antes, sin aviso. Puede cambiar la respuesta en la configuración del repositorio.
  • Códigos de emparejamiento de un solo uso: Cuando un teléfono, navegador u Orca actualizado se empareja con una computadora de escritorio actualizada, cambia a su propio inicio de sesión y el código QR o enlace que usó deja de funcionar. Los dispositivos con aplicaciones más antiguas siguen funcionando y Configuración marca los dispositivos que todavía usan el código de emparejamiento original o el cifrado anterior para que sepas cuál actualizar.
  • orca serve y direcciones públicas: orca serve acepta conexiones localhost, LAN y Tailscale de forma predeterminada y acepta direcciones públicas de Internet solo cuando hay un motivo para hacerlo. Las configuraciones existentes siguen conectándose.
  • Memoria del modelo de voz: Con la voz activada, Orca ahora carga el modelo de voz en el dispositivo antes de su primer dictado. Utilice la nueva configuración Descargar modelo de voz en Configuración > Voz para liberar esa memoria antes. El dictado de escritorio ahora también se detiene solo después de un minuto de silencio.
  • Peso de fuente de terminal de Windows: El texto de terminal en Windows ahora usa el peso de fuente Regular de forma predeterminada en lugar de Medio, que Windows dibujó como SemiBold. macOS y Linux no cambian.
  • Menú de inicio de nueva pestaña: Los permisos y argumentos ya no están en el menú de inicio del agente de nueva pestaña. Todavía provienen de la configuración del Agente.
  • Incorporación: El botón de instalación de Antigravity en la incorporación desapareció. Antigravity tiene el mismo enlace de instrucciones de instalación que cualquier otro agente.

orca v1.4.254

Git Graph, on-phone dictation & side questions in chat ✨

  • 🌳 See the whole repository: A new Git Graph tab shows local and remote branches and tags, with each commit's details and changed files. Folder workspaces now get Source Control, with a card for each attached repo, and the branch name in Source Control switches or creates a branch in place.
  • 💬 Ask without derailing a chat: In Chat UI, /btw asks a side question in a fork beside the chat while the original keeps running, and /fork branches from the latest response. Chats that open or push to a pull request show a short line when its CI passes or fails.
  • 🎙️ Dictate from anywhere: Phones can turn speech into text on the device (iPhone on iOS 26 or later, and Android), with the computer as fallback. The computer, phones and web client can dictate at the same time, and on-device dictation runs in its own process, so a speech engine crash or hang no longer takes Orca down.
  • 📱 A phone that holds on to your work: Chat sends queue while the desktop is unreachable and go out in order when it's back. Chat drafts, attachments, unsaved file edits and automation drafts survive the app being killed, and screens reopen from what the phone already has.
  • ⌨️ No more typing lag from Codex accounts: Typing could lag across Orca while it linked Codex history between accounts. That work no longer blocks the app. Remote terminals also send a lone keystroke right away and read compressed output from remote hosts.
  • 🔐 Safer pairing and trust: A pairing code stops working once the device that used it saves its own sign-in, desktop and CLI connections to remote servers use the newer encryption, and orca serve refuses connections from public internet addresses unless there's a reason to allow them. Orca asks once per new repo before trusting it for agents.
  • 🎨 Make Orca yours: Import your own app icon, let theme plugins play a looping background video and ship their own fonts, and read Settings in titled cards. Claude Code can match your Orca terminal theme if you say yes.
  • 🤖 Better agent support: Antigravity chats can run on the host's own agy, including Full access chats, and Muse shows its subscription quota in the status bar.

Highlights

  • Chat: /btw asks a side question in a fork and /fork forks from the latest response, with a spinner while the fork opens. Chats show CI results for the pull requests they opened or pushed to, and every waiting message, command and steer now sits in one ordered queue you can move, delete or send from.
  • Phone: Send while the desktop is offline, keep drafts, attachments, file edits and automation drafts across app kills, and see the workspace list, session tabs and Review from memory while they refresh. Large folders load 500 entries at a time with Search all, Review prefetches the next and previous file, and a thin line under the header shows when cached data is refreshing.
  • Dictation: Phones can transcribe on the device, and every device can dictate at once. On desktop the speech model loads before your first dictation (a new setting chooses when to unload it), dictation stops after a minute of silence and keeps what you said, dictated text gets a space before it, and text that can't be inserted is copied instead. The paired web client can dictate through the host.
  • Source control & editor: Git Graph, Source Control for folder workspaces, and an in-place branch picker in the Source Control header. Wholly new and deleted files show one clean tint, Markdown keeps its syntax colors under plugin themes, HTML previews open in the editor's own tab group, and Copy as PNG says when an image is too large instead of claiming it copied.
  • Agents & accounts: The Codex account-history typing lag is fixed. Antigravity chats can run on the host's agy when it's signed in, Antigravity sessions in AI Vault can reveal their artifacts folder, and Muse shows its quota and keeps panes working while background subagents run. The new-tab launch menu is simpler, the agent picker finds models from its submenus, and after a restart agents are told to finish the original task.
  • Remote hosts: Remote terminals respond to keystrokes sooner, desktop chats on remote hosts stream only the new text, and polling slows down while the Orca window is visible but not focused. Managed SSH servers recover after a slow ProxyCommand login and in more dead-server cases, and automations for a managed SSH host go to its own Orca server.
  • Look & feel: Import a custom app icon, use themed menus and clearer segmented controls, and use web fonts and looping background videos from plugins. Theme plugins can also style chat text and selection, which is now easier to read in dark mode. File and browser tabs fit their titles, so more fit before the tab strip scrolls.

Compatibility & upgrade notes

  • Claude Code theme matching: Orca can now match Claude Code's theme to your Orca terminal theme. It is off for everyone, including new profiles. The next time Claude Code runs, Orca asks once in a toast. Nothing in ~/.claude/settings.json changes unless you accept, and you can change it later in Settings › Appearance › Terminal.
  • Search shortcut: New Mac profiles open search with Cmd+K and have no default shortcut for clearing the terminal. New Windows and Linux profiles use Ctrl+K. Existing profiles keep their shortcuts, including custom and disabled ones.
  • Agent folder trust: The first time you start an agent in a new repo, Orca asks whether to trust the repo or let each agent ask for itself. Repos you already use keep working as before, with no prompt. You can change the answer in the repo's settings.
  • Single-use pairing codes: When an updated phone, browser or Orca pairs with an updated desktop, it switches to its own sign-in and the QR code or link it used stops working. Devices on older apps keep working, and Settings marks devices that still use the original pairing code or older encryption so you know which to update.
  • orca serve and public addresses: orca serve accepts localhost, LAN and Tailscale connections by default and accepts public internet addresses only when there's a reason to. Existing setups keep connecting.
  • Speech model memory: With voice on, Orca now loads the on-device speech model ahead of your first dictation. Use the new Unload Speech Model setting in Settings › Voice to free that memory sooner. Desktop dictation now also stops by itself after a minute of silence.
  • Windows terminal font weight: Terminal text on Windows now uses the font's Regular weight by default instead of Medium, which Windows drew as SemiBold. macOS and Linux are unchanged.
