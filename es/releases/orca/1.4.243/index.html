orca v1.4.243

Extensiones de Chrome en el navegador de Orca, compatibilidad con iPhone Duo y conversión en vivo de una sesión de agente de terminal en una interfaz de usuario de chat 🧩

Esta versión trae extensiones de Chrome al navegador de Orca en fase experimental, permite que una conversación continúe en Chat una vez que sale de su agente en la terminal y muestra sus árboles de trabajo locales más pronto después de reiniciar. También agrega soporte para el iPhone Duo plegable, menús compactos de estilo nativo, temas claros y oscuros en el teléfono y correcciones para terminales Windows, hosts SSH y actualizaciones.

La versión corta

  • Extensiones de Chrome (experimental): Agregue extensiones desde Chrome Web Store con Agregar a Orca, para que los administradores de contraseñas como Bitwarden y 1Password puedan completar los inicios de sesión en el navegador de Orca. Desactivado de forma predeterminada.
  • Convierta una sesión de agente de terminal en vivo en una interfaz de usuario de chat: Una vez que salga de Claude o Codex en una terminal, la misma conversación puede continuar en Chat mientras la pestaña de la terminal permanece abierta. Los chats de Claude también mantienen su opción de aprobación guardada a través de cambios de modelo, y cerrar un chat que todavía está funcionando pregunta primero.
  • Árboles de trabajo antes de reiniciar: Los árboles de trabajo locales se cargan antes de que se restauren los terminales y la barra lateral dice que el descubrimiento aún se está ejecutando en lugar de mostrar una lista vacía.
  • Terminales más estables: Los terminales de Windows mantienen su historial a través de cambios de ancho, los terminales inactivos se activan en la carpeta que dejó, el bash integrado de macOS mantiene el seguimiento de comandos en orden después de un cambio de trampa DEBUG y la copia desde pi en un host remoto llega a su clipboard.
  • Orquestación: Elija el intervalo de latidos del trabajador o desactívelos y reduzca el uso de la CPU evitando que los trabajadores asentados soliciten comandos.
  • Pulir donde importa: Menús compactos de estilo nativo, resaltado de Markdown estilo VS Code con títulos fijos y comprobaciones de actualización a través de su proxy de configuración.
  • Correcciones de la comunidad: Salir y detener todas las sesiones, matemáticas en chats, copiar URL remota con rangos de líneas, resaltado de IME en terminales, fnm en Windows y traducciones al japonés y al chino funcionan mejor. Actualizaciones telefónicas y web: Los teléfonos obtienen temas claros y oscuros, compatibilidad con el iPhone Duo plegable, archivos PDF en Vista rápida y botones de copia en los chats. Muchas pantallas de teléfonos siguen ahora las reglas de escritorio para chats, control de fuente y terminales, y escribir y desplazarse en chats largos se mantiene rápido.

Notas de compatibilidad y actualización

  • Host de terminal nuevo: Los terminales nuevos comienzan en un host de terminal nuevo, por lo que se aplican las correcciones de terminal de esta versión, incluida la continuación de un chat después de que sale el agente de terminal. Los terminales que ya están abiertos antes de la actualización continúan ejecutándose y permanecen conectados en el host anterior hasta que los cierre.
  • Extensiones del navegador (experimental): Active Configuración → Experimental → Extensiones del navegador, reinicie y luego abra Chrome Web Store en una pestaña del navegador Orca. Las extensiones se ejecutan únicamente en perfiles de navegador locales. Los bloqueadores de anuncios se instalan pero aún no bloquean y algunas extensiones, como Tampermonkey, no funcionan.
  • Latidos del trabajador: Los latidos permanecen activados cada 5 minutos de forma predeterminada. Los cambios en Configuración → Orquestación de agentes se aplican a los trabajadores recién asignados; los trabajadores que ya se están ejecutando mantienen su breve tiempo y los hosts más antiguos mantienen su tiempo de 5 minutos.
  • Navegación del subagente de Claude: El ojo que marcó al subagente que estás viendo desapareció. La fila del subagente vista utiliza el resaltado normal de la fila actual.

orca v1.4.243

Chrome extensions in Orca’s browser, iPhone Duo support, and Convert a terminal agent session live into a chat ui 🧩

This release brings Chrome extensions to Orca’s browser under experimental, lets a conversation continue in Chat once you quit its agent in the terminal, and shows your local worktrees sooner after a restart. It also adds support for the folding iPhone Duo, compact native-style menus, light and dark themes on the phone, and fixes for Windows terminals, SSH hosts and updates.

The short version

  • Chrome extensions (experimental): Add extensions from the Chrome Web Store with Add to Orca, so password managers like Bitwarden and 1Password can fill logins in Orca’s browser. Off by default.
  • Convert a terminal agent session live into a chat ui: Once you quit Claude or Codex in a terminal, the same conversation can continue in Chat while the terminal tab stays open. Claude chats also keep their saved approval choice across model changes, and closing a chat that’s still working asks first.
  • Worktrees sooner after a restart: Local worktrees load before terminals restore, and the sidebar says discovery is still running instead of showing an empty list.
  • Steadier terminals: Windows terminals keep their history through width changes, slept terminals wake in the folder you left, macOS’s built-in bash keeps command tracking in order after a DEBUG trap change, and copying from pi on a remote host reaches your clipboard.
  • Orchestration: Choose the worker heartbeat interval or turn heartbeats off, and reduce CPU use by stopping settled workers from polling for commands.
  • Polish where it counts: Compact native-style menus, VS Code–style Markdown highlighting with sticky headings, and update checks through your Settings proxy.
  • Fixes from the community: Quit and Stop All Sessions, math in chats, Copy Remote URL with line ranges, IME highlighting in terminals, fnm on Windows, and Japanese and Chinese translations all work better.

Phone & web updates: Phones get light and dark themes, support for the folding iPhone Duo, PDFs in Quick Look and copy buttons in chats. Many phone screens now follow desktop’s rules for chats, Source Control and terminals, and typing and scrolling in long chats stay fast.

Compatibility & upgrade notes

  • Fresh terminal host: New terminals start on a fresh terminal host so this release’s terminal fixes apply, including continuing a chat after its terminal agent exits. Terminals already open before you update keep running, and stay attached, on the previous host until you close them.
  • Browser extensions (experimental): Turn on Settings → Experimental → Browser extensions, restart, then open the Chrome Web Store in an Orca browser tab. Extensions run in local browser profiles only. Ad blockers install but don’t block yet, and some extensions, such as Tampermonkey, don’t work.
  • Worker heartbeats: Heartbeats stay on every 5 minutes by default. Changes in Settings → Agent Orchestration apply to newly dispatched workers; workers already running keep their brief, and older hosts keep 5 minutes.
  • Claude subagent navigation: The eye that marked the subagent you’re viewing is gone. The viewed subagent row uses the normal current-row highlight.
