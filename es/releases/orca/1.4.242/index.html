orca v1.4.242

Con menos memoria, Claude subagente a un click de distancia y servidores remotos que recuerdan 🪄

Esta versión tiene menos memoria, con un menor uso de memoria en el host del terminal y las conexiones WSL, además de un menor uso de CPU inactiva en los terminales. También le permite abrir subagentes de Claude directamente desde la barra lateral, hace que los chats de Codex en modo Preguntar pregunten antes de editar y ayuda a los servidores emparejados, hosts SSH y WSL a mantener sus pestañas y explicar las fallas. Esta versión también soluciona problemas en Windows, Linux y macOS.

La versión corta

  • Abrir subagentes de Claude desde la barra lateral: Click una fila de subagente de Claude en la barra lateral o el panel para abrir su transcripción en la misma terminal, luego click el padre para regresar. Un ojo marca lo que estás viendo.
  • Chats que preguntan primero: Los chats de Codex en el modo Preguntar ahora preguntan antes de editar su espacio de trabajo, los terminales Claude remotos en servidores emparejados pueden continuar en el Chat y los chats que no pueden iniciar le dicen por qué.
  • Los agentes se reanudan como los dejaste: Las sesiones de Claude reanudadas mantienen su nivel de esfuerzo y lanzan indicadores, Codex mantiene el último permiso que le diste y el Historial de sesiones encuentra chats en más carpetas y servidores.
  • Servidores remotos que recuerdan: Los servidores emparejados mantienen sus pestañas durante los reinicios, las pestañas cerradas permanecen cerradas, los hosts WSL dejan de volver a emparejarse después de cada reinicio y las fallas de SSH indican lo que realmente salió mal.
  • Más ligero en memoria: Los terminales usan mucha menos CPU inactiva, el host del terminal usa menos memoria la próxima vez que se reinicia, las conexiones WSL necesitan mucha menos memoria y el panel de recursos ahora coincide con el Monitor de actividad en macOS.
  • Correcciones de la comunidad: Las rutas espaciadas del iniciador de Windows, la entrada en coreano, el horario de verano en las automatizaciones, el enfoque-sigue-el-mouse, el arrastre de pestañas y los paquetes de Linux funcionan mejor. Actualizaciones telefónicas y web: Los teléfonos ahora indican una computadora inalcanzable en lugar de estar girando para siempre, y las respuestas en streaming y los chats web largos se vuelven a dibujar menos. Los programas de terminal que le hacen una pregunta al terminal también siguen funcionando mientras el teléfono mira en el tamaño de un escritorio.

Notas de compatibilidad y actualización

  • Chats de Codex en modo Preguntar: Preguntar ahora se ejecuta en modo de solo lectura y pregunta antes de editar el espacio de trabajo; Aprobar por mí y Acceso completo no cambian, y el trabajo que ya se está ejecutando mantiene su concesión. Los chats en un servidor emparejado mantienen el comportamiento anterior hasta que se actualiza ese servidor.
  • Navegación del subagente de Claude: Activado de forma predeterminada con enlaces de estado de Claude. Orca carga su complemento solo en los paneles de Orca y agrega un acceso directo, el primero libre de Ctrl+Alt+G, H o V, a keybindings.json en cada carpeta Claude que usa. Desactívelo en Configuración → Agentes → Navegación de subagente Claude para eliminar ese acceso directo. Las sesiones de Claude que ya se están ejecutando necesitan un nuevo lanzamiento.
  • Servidores emparejados: Mover un panel a una nueva pestaña y continuar con un terminal Claude remoto en Chat necesita el servidor para ejecutar esta versión. En servidores más antiguos, el movimiento permanece solo en esta ventana, como antes, y Continuar en la interfaz de usuario del chat se muestra deshabilitado con una sugerencia de actualización.
  • Cambio de cuenta de Claude: Cambiar de cuenta ahora también ofrece reiniciar las sesiones que se ejecutan en la carpeta Claude predeterminada del sistema cuando esa carpeta inicia sesión en la cuenta anterior. El cuadro de diálogo agrupa las sesiones en aquellas de la cuenta anterior, otras y aquellas que no puede mover.
  • Hosts WSL: Las conexiones al servidor de un host WSL ahora pasan por bash y recurren a Node cuando falta bash o es demasiado antiguo. Esto no necesita actualización del servidor y funciona con cualquier versión del servidor.

orca v1.4.242

Lighter on memory, Claude subagents a click away, and remote servers that remember 🪄

This release is lighter on memory, with lower memory use in the terminal host and WSL connections, plus less idle CPU use in terminals. It also lets you open Claude subagents straight from the sidebar, makes Codex chats in Ask mode ask before editing, and helps paired servers, SSH and WSL hosts keep your tabs and explain failures. This release also fixes problems across Windows, Linux and macOS.

The short version

  • Open Claude subagents from the sidebar: Click a Claude subagent row in the sidebar or dashboard to open its transcript in the same terminal, then click the parent to go back. An eye marks the one you’re viewing.
  • Chats that ask first: Codex chats in Ask mode now ask before editing your workspace, remote Claude terminals on paired servers can continue in Chat, and chats that can’t start tell you why.
  • Agents resume as you left them: Resumed Claude sessions keep their effort level and launch flags, Codex keeps the permission you last gave it, and Session History finds chats in more folders and on servers.
  • Remote servers that remember: Paired servers keep your tabs across restarts, closed tabs stay closed, WSL hosts stop re-pairing after each restart, and SSH failures say what actually went wrong.
  • Lighter on memory: Terminals use far less idle CPU, the terminal host uses less memory once it next restarts, WSL connections need much less memory, and the resource panel now matches Activity Monitor on macOS.
  • Fixes from the community: Spaced Windows launcher paths, Korean input, DST in automations, focus-follows-mouse, tab dragging and Linux packages all work better.

Phone & web updates: Phones now explain an unreachable computer instead of spinning forever, and streaming replies and long web chats redraw less. Terminal programs that ask the terminal a question also keep working while a phone watches at desktop size.

Compatibility & upgrade notes

  • Codex chats in Ask mode: Ask now runs read-only and asks before workspace edits; Approve for me and Full access are unchanged, and work already running keeps its grant. Chats on a paired server keep the old behavior until that server is updated.
  • Claude subagent navigation: On by default with Claude status hooks. Orca loads its plugin only into Orca panes and adds one shortcut, the first free of Ctrl+Alt+G, H or V, to keybindings.json in each Claude folder it uses. Turn it off in Settings → Agents → Claude subagent navigation to remove that shortcut. Claude sessions already running need a fresh launch.
  • Paired servers: Moving a pane into a new tab and continuing a remote Claude terminal in Chat need the server to run this release. On older servers the move stays in this window only, as before, and Continue in Chat UI shows disabled with an update hint.
  • Claude account switching: Switching accounts now also offers to restart sessions running in your System default Claude folder when that folder is signed in to the old account. The dialog groups sessions into those on the old account, others, and ones it can’t move.
  • WSL hosts: Connections to a WSL host’s server now go through bash and fall back to Node when bash is missing or too old. This needs no server update and works with any server version.
