orca v1.4.239

¡Dos lanzamientos hoy! Echa un vistazo a los v1.4.238 release note también. Esa versión trajo ediciones compartidas no guardadas en espacios de trabajo, chats de agentes más completos y configuración remota de cuentas, un navegador más capaz y controles telefónicos más fluidos.

Tu espacio de trabajo, trabajando juntos 🐳

Configure las habilidades del agente en un click, mantenga las sesiones del navegador separadas entre proyectos y muévase más fácilmente entre el chat y la terminal. Esta versión también fortalece lo esencial: los archivos compartidos permanecen sincronizados, las sesiones SSH se recuperan de manera más confiable y las interacciones telefónicas se sienten más predecibles.

La versión corta

  • Habilidades, listas dondequiera que trabajes: Instale las habilidades de Orca en un click desde las pantallas de configuración e instálelas o actualícelas en servidores emparejados y hosts SSH con el propio instalador de Orca.
  • Un navegador que se adapta a sus proyectos: Elija perfiles compartidos, por repositorio o por espacio de trabajo para nuevas pestañas. Mantenga separados los inicios de sesión de las aplicaciones locales, utilice un menú contextual de página familiar y obtenga explicaciones más claras cuando una página no se pueda cargar.
  • Conversaciones con agentes más fluidas: divídase en un chat nuevo al lado del actual, continúe con un agente de terminal desde el encabezado del panel y mantenga intactos los mensajes en cola y múltiples archivos adjuntos de imágenes.
  • Ediciones más seguras, trabajo en segundo plano más silencioso: Las vistas de archivos compartidos permanecen actualizadas después de deshacerlas y descartarlas. Los archivos que no son UTF-8 preguntan antes de la conversión, la visualización de archivos se recupera después de una desaceleración y Orca observa menos archivos no relacionados.
  • Trabajo remoto con retorno: recupere servidores SSH administrados compatibles desde un bloqueo obsoleto en Configuración, restaure terminales después del inicio de sesión con contraseña y mantenga el enlace de acceso SSH de un servidor emparejado durante los reinicios.
  • Mejor desde tu teléfono: Al tocar una notificación se abre el agente que la envió, las pestañas de chat del agente pueden iniciar el dictado, los comandos de copia del terminal llegan al teléfono clipboard y el desplazamiento de Android mantiene el teclado fuera del camino.
  • Pulido cotidiano, en todos los idiomas: Mejor entrada en coreano, representación de terminal en bengalí y otros idiomas índicos, traducciones más completas, selectores de usuarios de Jira y enlaces de comentarios de relaciones públicas que van directamente al editor. Actualizaciones del teléfono: La actualización de Orca en la computadora que atiende su teléfono actualiza la interfaz servida. Las mejoras nativas en descarga, progreso y navegación requieren una aplicación de teléfono nativa actualizada.

Notas de compatibilidad y actualización

  • Perfiles del navegador: Elija Configuración → Navegador → Perfil para pestañas nuevas. Compartido sigue siendo el valor predeterminado; Los perfiles por repositorio y por espacio de trabajo se aplican a las pestañas nuevas. Las páginas de servidores emparejados utilizan los propios perfiles del servidor.
  • Chat nativo (experimental): Actualice los hosts SSH y emparejados junto con Orca para obtener las últimas correcciones de chat y lanzamiento. La disponibilidad del chat ahora verifica el tiempo de ejecución del chat por separado del terminal CLI, incluidas las configuraciones Antigravity compatibles.
  • Recuperación SSH: Recuperar servidor… está disponible para hosts SSH Linux administrados compatibles que informan un rechazo de bloqueo inactivo. Comprueba el bloqueo y le pide que confirme que ninguna otra máquina que comparte esa casa esté ejecutando Orca antes de borrarlo. Los teléfonos le dirigen a la configuración del escritorio.
  • Base experimental: La base del propietario del diseño permanece deshabilitada. Las acciones de inicio del grupo vacío y el cambio de estado del espacio de trabajo secundario se revirtieron antes del lanzamiento.

orca v1.4.239

Two releases today! Check out the v1.4.238 release notes too. That release brought shared unsaved edits across workspaces, richer agent chats and remote account setup, a more capable browser, and smoother phone controls.

Your workspace, working together 🐳

Set up agent skills in one click, keep browser sessions separate between projects, and move more easily between chat and terminal. This release also strengthens the essentials: shared files stay in sync, SSH sessions recover more reliably, and phone interactions feel more predictable.

The short version

  • Skills, ready wherever you work: Install Orca’s skills in one click from setup screens, and install or update them on paired servers and SSH hosts with Orca’s own installer.
  • A browser that fits your projects: Choose shared, per-repo or per-workspace profiles for new tabs. Keep local app logins separate, use a familiar page context menu, and get clearer explanations when a page cannot load.
  • More fluid agent conversations: Split into a fresh chat beside your current one, continue with a terminal agent from the pane header, and keep queued messages and multiple image attachments intact.
  • Safer edits, quieter background work: Shared file views stay current after undo and discard. Non-UTF-8 files ask before conversion, file watching recovers after slowdowns, and Orca watches fewer unrelated files.
  • Remote work with a way back: Recover supported managed SSH servers from a stale lock in Settings, restore terminals after password sign-in, and keep a paired server’s SSH access link through restarts.
  • Better from your phone: Tapping a notification opens the agent that sent it, agent chat tabs can start dictation, terminal copy commands reach the phone clipboard, and Android scrolling keeps the keyboard out of the way.
  • Everyday polish, across languages: Better Korean input, Bengali and other Indic terminal rendering, more complete translations, Jira user pickers, and PR comment links that jump straight to the editor.

Phone updates: Updating Orca on the computer serving your phone updates the served interface. Native download, progress and navigation improvements require an updated native phone app.

Compatibility & upgrade notes

  • Browser profiles: Choose Settings → Browser → Profile for new tabs. Shared remains the default; per-repo and per-workspace profiles apply to new tabs. Paired-server pages use the server’s own profiles.
  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat and launch fixes. Chat availability now checks the chat runtime separately from the terminal CLI, including supported Antigravity setups.
  • SSH recovery: Recover server… is available for supported managed Linux SSH hosts reporting a stale-lock refusal. It checks the lock and asks you to confirm that no other machine sharing that home is running Orca before clearing it. Phones point you to desktop Settings.
  • Experimental groundwork: The layout-owner groundwork remains disabled. The empty-group launch actions and child-workspace status toggle were reverted before release.
