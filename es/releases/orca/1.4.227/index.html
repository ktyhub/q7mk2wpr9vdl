orca v1.4.227

¡Muchas gracias por usar Orca y por su continuo apoyo! ❤️

La versión corta

  • Los chats nativos tienen su propio modo de permiso. Elija permisos para cada nuevo chat de Claude o Codex en Configuración → Chat → Comportamiento; los chats existentes mantienen el modo que ya estaban usando y cambiar de modelo ya no lo restablece.
  • Las sesiones de chat nativo son más fáciles de continuar. Puede reanudar conversaciones de terminal grandes en un nuevo chat nativo, recuperar chats cuyo único trabajo se ejecutó en segundo plano después de un reinicio y ver todos los proveedores de chat compatibles con precisión en el Historial de sesiones.
  • Las cuentas de Claude y la configuración del chat de Codex son más fluidas. Las cuentas de Claude nuevamente usan carpetas separadas, el enlace de inicio de sesión se puede copiar, los chats de Codex requieren la versión 0.136.0 o posterior y Codex Ultrafast está disponible como una opción de velocidad.
  • La automatización del navegador le devuelve el teclado de manera confiable. Los comandos del navegador del agente apuntan a la página deseada y las ventanas emergentes del navegador se comportan más como Chrome.
  • Además: la limpieza del árbol de trabajo es más segura, las notificaciones de lectura de macOS desaparecen del Centro de notificaciones, los chats largos se cargan mejor en los teléfonos y las lecturas frías del historial de sesiones evitan reindexaciones innecesarias.

Limpieza más segura del árbol de trabajo, notificaciones de macOS más ordenadas y pequeña limpieza de traducciones.

orca v1.4.227

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chats have their own permission mode. Choose permissions for each new Claude or Codex chat from Settings → Chat → Behavior; existing chats keep the mode they were already using, and changing models no longer resets it.
  • Native chat sessions are easier to continue. You can resume large terminal conversations in a new native chat, recover chats whose only work ran in the background after a restart, and see every supported chat provider accurately in Session History.
  • Claude accounts and Codex chat setup are smoother. Claude accounts again use separate folders, the sign-in link can be copied, Codex chats require version 0.136.0 or later, and Codex Ultrafast is available as a speed choice.
  • Browser automation gives your keyboard back reliably. Agent browser commands target the intended page, and browser popups behave more like Chrome.
  • Also: worktree cleanup is safer, read macOS notifications disappear from Notification Center, long chats load better on phones, and cold session-history reads avoid unnecessary reindexing.
