orca v1.4.238

Más trabajo conectado, ediciones más seguras 🐳

Esta versión facilita el movimiento entre agentes, archivos, navegadores y máquinas remotas. Las pestañas del mismo archivo ahora comparten ediciones no guardadas, los chats nativos retoman turnos realizados en otros lugares y el teléfono obtiene gestos de terminal más confiables y controles de pestañas más completos.

La versión corta

  • Tus ediciones permanecen juntas: Las pestañas del mismo archivo comparten texto no guardado en todos los espacios de trabajo. La revisión de conflictos ve que el texto activo, la eliminación del espacio de trabajo enumera los archivos no guardados y las ediciones obsoletas de Markdown o del cuaderno ya no sobrescriben el trabajo más nuevo.
  • Chats que siguen el ritmo: Codex y Pi muestran turnos realizados fuera del chat. Los pegados largos pueden convertirse en archivos adjuntos de texto, las preguntas del Codex obtienen tarjetas de respuestas y OMP obtiene el envío de imágenes y tarjetas de revisión de planes procesables.
  • Más control sobre los agentes: Elija chat o terminal al crear un espacio de trabajo, establezca esa opción para su agente predeterminado, agregue cuentas de Claude y Codex en servidores remotos compatibles e instale habilidades compartidas para 11 agentes más.
  • Un navegador más capaz: Una nueva pestaña que tiene en cuenta el espacio de trabajo, sugerencias en la barra de direcciones, permisos de sitios recordados, apariencia y zoom por sitio y progreso de carga de páginas en computadoras de escritorio y teléfonos.
  • Una experiencia telefónica más fluida: Vea la actividad del agente en pestañas, cambie el nombre con un doble toque, retroceda a través de mensajes de chat anteriores, seleccione el texto del terminal de manera más natural y regrese a la posición de lectura del terminal después de continuar.
  • Mejor visibilidad y recuperación: Inspeccione los terminales locales en Resource Manager, use SSH simple cuando el movimiento de un host a un servidor Orca esté bloqueado y mantenga los emparejamientos a través de actualizaciones y recuperación del servidor administrado.
  • Pulido diario: portugués brasileño, selección de idioma durante la incorporación, compilaciones de lanzamiento con capacidad de búsqueda, progreso de escaneo del historial más claro y Resolución con IA para fusiones, rebases y selecciones en pausa, incluso después de que se solucionen los conflictos de archivos. Actualizaciones del teléfono: La actualización de Orca en la computadora que atiende su teléfono actualiza la interfaz servida. La nueva entrada Inicio → Nuevo espacio de trabajo y las correcciones de dictado nativo de iOS requieren una aplicación de teléfono nativa actualizada; la entrada de la pantalla de inicio se envía con la siguiente versión de la aplicación.

Notas de compatibilidad y actualización

  • Cuentas remotas: Actualice el servidor emparejado para el nuevo flujo Agregar cuenta de Claude y Codex. Los servidores Windows y los hosts más antiguos conservan la guía orca account add. Las credenciales permanecen en el servidor; la reautenticación remota de una cuenta existente está fuera de este cambio.
  • Chat nativo (experimental): Actualice los hosts SSH y emparejados junto con Orca para obtener las últimas correcciones de chat. Las comprobaciones de versiones del agente ahora aceptan versiones más recientes y preliminares que cumplan con el mínimo requerido; una versión anterior conocida muestra una guía de actualización.
  • Administrador de recursos: La nueva vista de PTY cubre terminales locales. Finalizar una terminal requiere soporte del host para verificar la sesión seleccionada; Los hosts más antiguos rechazan la terminación sin control.
  • Archivos HTML: En esta versión se revirtió la apertura de HTML en la vista previa de forma predeterminada.
  • Base experimental: Los cambios en el propietario del diseño y en la barra lateral que se enumeran a continuación permanecen deshabilitados. Los nuevos controles opcionales de escritura de agentes no tienen habilitados a ningún llamante existente.

orca v1.4.238

More connected work, safer edits 🐳

This release makes it easier to move between agents, files, browsers and remote machines. Tabs of the same file now share unsaved edits, native chats pick up turns made elsewhere, and the phone gets more dependable terminal gestures and richer tab controls.

The short version

  • Your edits stay together: Tabs of the same file share unsaved text across workspaces. Conflict review sees that live text, workspace deletion lists unsaved files, and stale Markdown or notebook edits no longer overwrite newer work.
  • Chats that keep up: Codex and Pi show turns made outside the chat. Long pastes can become text attachments, Codex questions get answer cards, and OMP gains image sending and actionable plan-review cards.
  • More control over agents: Pick chat or terminal when creating a workspace, set that choice for your default agent, add Claude and Codex accounts on supported remote servers, and install shared skills for 11 more agents.
  • A more capable browser: A workspace-aware new tab, address-bar suggestions, remembered site permissions, per-site appearance and zoom, and page-loading progress on desktop and phone.
  • A smoother phone experience: See agent activity in tabs, rename with a double-tap, scroll back through earlier chat messages, select terminal text more naturally, and return to your terminal reading position after resuming.
  • Better visibility and recovery: Inspect local terminals in Resource Manager, use plain SSH when a host’s move to an Orca server is blocked, and keep pairings through managed-server updates and recovery.
  • Everyday polish: Brazilian Portuguese, language selection during onboarding, searchable release builds, clearer history-scan progress, and Resolve with AI for paused merges, rebases and cherry-picks—even after file conflicts are fixed.

Phone updates: Updating Orca on the computer serving your phone updates the served interface. The new Home → New Workspace entry and native iOS dictation fixes require an updated native phone app; the home-screen entry ships with the next app build.

Compatibility & upgrade notes

  • Remote accounts: Update the paired server for the new Claude and Codex Add Account flow. Windows servers and older hosts retain the orca account add guidance. Credentials stay on the server; remote re-authentication of an existing account is outside this change.
  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat fixes. Agent version checks now accept newer releases and prereleases that meet the required minimum; a known older version shows update guidance.
  • Resource Manager: The new PTYs view covers local terminals. Ending a terminal requires host support for verifying the selected session; older hosts refuse unchecked termination.
  • HTML files: Opening HTML in preview by default was reverted for this release.
  • Experimental groundwork: Layout-owner and sidebar changes listed below remain disabled. The new optional agent-write controls have no existing callers enabled.
