orca v1.4.241

Chats y un navegador que se comportan como esperas 🧭

Esta versión hace que los chats sigan la configuración de su agente, incorpora herramientas estilo Chrome al navegador integrado y ayuda a recuperar las conexiones SSH y los servidores administrados. También encontrará una configuración de fuente de chat, navegación de agentes en vivo y terminales Hermes, Kimi, Kiro y Windows más estables.

La versión corta

  • Chats que siguen su configuración: Los chats nuevos usan el permiso de cada agente desde Configuración → Agentes, los chats renombrados mantienen sus nombres en el Historial de sesiones y un chat no escribirá una conversación si el terminal aún está en ejecución.
  • Un navegador más cercano a Chrome: Coloque DevTools dentro del panel, silencie las pestañas que reproducen sonido, vea la URL de un enlace al pasar el cursor y use los atajos de Orca y el avance y retroceso del mouse dentro de las páginas.
  • Observa la navegación de los agentes: Un cursor y una insignia muestran dónde está cli un agente escribiendo o escribiendo, el chat te lleva a la página y los enlaces desde las terminales y el chat se abren junto a su fuente.
  • SSH con menos callejones sin salida: El puerto guardado reenvía el retorno después de un reinicio y explica las fallas, los hosts solo con certificado se conectan a través de su sistema ssh y los servidores administrados se actualizan sin cerrar terminales.
  • Agentes que se inician y reanudan de manera confiable: Los paneles Hermes y Kimi se reanudan después de un reinicio, Kiro informa el estado de su motor V3 y las claves escritas mientras se inicia un agente se mantienen como borrador.
  • Polaco donde importa: Elija una fuente para chatear, haga zoom con Cmd/Ctrl + + en teclados fuera de EE. UU., abra archivos solo en la nube desde terminales macOS y obtenga terminales y pegado de Windows más estables. Actualizaciones telefónicas y web: Los teléfonos ya no eliminan partes de la salida del terminal, y los cambios de nombre de los chats y el modo de permiso de cada chat ahora se muestran allí. Las pestañas de sesión también siguen funcionando y lo necesitan para los agentes de Windows que nunca establecen un título.

Notas de compatibilidad y actualización

  • Host de terminal nuevo: Los terminales nuevos comienzan en un host de terminal nuevo, por lo que se aplican las correcciones de terminal de esta versión. Los terminales que ya están abiertos antes de la actualización continúan ejecutándose y permanecen conectados en el host anterior hasta que los cierre.
  • Permisos de chat: Configuración → El chat ya no tiene su propio menú desplegable de permisos; configúrelo por agente en Configuración → Agentes. Los chats existentes mantienen su permiso guardado y el menú de permisos propio de un chat cambia solo ese chat.
  • Conversaciones abiertas en una terminal: Si es posible que una terminal aún esté escribiendo una conversación, su chat no se enviará y le pedirá que salga del agente allí o cierre esa terminal. Cerrar esa terminal permite que se realice el siguiente envío.
  • Servidores SSH administrados: Actualizar de todos modos mantiene los terminales en ejecución durante la actualización. La oferta para reanudar los chats después de un reinicio necesita un servidor que ya esté ejecutando esta versión.
  • Selecciones de modelos de OpenCode: OpenCode 2.0.14, 2.0.15, 2.0.17 y 2.0.18 dejan el primer mensaje sin enviar cuando se elige un modelo, por lo que Orca rechaza las selecciones de modelos en esas versiones.

orca v1.4.241

Chats and a browser that behave the way you expect 🧭

This release makes chats follow your agent settings, brings Chrome-style tools to the built-in browser, and helps SSH connections and managed servers recover. You’ll also find a chat font setting, live agent browsing, and steadier Hermes, Kimi, Kiro and Windows terminals.

The short version

  • Chats that follow your settings: New chats use each agent’s permission from Settings → Agents, renamed chats keep their names in Session History, and a chat won’t write a conversation a terminal is still running.
  • A browser closer to Chrome: Dock DevTools inside the pane, mute tabs playing sound, see a link’s URL on hover, and use Orca shortcuts and mouse back/forward inside pages.
  • Watch agents browse: A cursor and badge show where an agent is clicking or typing, chat jumps you to the page, and links from terminals and chat open beside their source.
  • SSH with fewer dead ends: Saved port forwards return after a restart and explain failures, certificate-only hosts connect through your system ssh, and managed servers update without closing terminals.
  • Agents that start and resume reliably: Hermes and Kimi panes resume after a restart, Kiro reports status on its V3 engine, and keys typed while an agent starts are kept as a draft.
  • Polish where it counts: Pick a font for chat, zoom with Cmd/Ctrl + + on non-US keyboards, open cloud-only files from macOS terminals, and get steadier Windows terminals and pasting.

Phone & web updates: Phones no longer drop pieces of terminal output, and chat renames and each chat’s permission mode now show there. Session tabs also keep Working and Needs You for Windows agents that never set a title.

Compatibility & upgrade notes

  • Fresh terminal host: New terminals start on a fresh terminal host so this release’s terminal fixes apply. Terminals already open before you update keep running, and stay attached, on the previous host until you close them.
  • Chat permissions: Settings → Chat no longer has its own permission dropdown; set it per agent in Settings → Agents. Existing chats keep their saved permission, and a chat’s own permission menu changes only that chat.
  • Conversations open in a terminal: If a terminal might still be writing a conversation, its chat won’t send and asks you to quit the agent there or close that terminal. Closing that terminal lets the next send go through.
  • Managed SSH servers: Update anyway keeps running terminals going through the update. The offer to resume chats after a restart needs a server already running this release.
  • OpenCode model picks: OpenCode 2.0.14, 2.0.15, 2.0.17 and 2.0.18 leave the first message unsent when a model is picked, so Orca refuses model picks on those versions.
