orca v1.4.265

Lanzamiento anterior: 1.4.264: los comandos de chat encuentran su espacio de trabajo, manteniendo el navegador funcionando con el chat correcto.

Presentamos Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" />

Los Orca Bots funcionan como compañeros de equipo de primera clase: cada sesión de agente administrada obtiene sus herramientas e identidad, los bots pueden compartir en nombre del propietario, siguen los hilos de Slack y los activadores de Gmail de manera más confiable, y conectarlos es más claro y seguro.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" /> Cada sesión de bot obtiene sus herramientas e identidad: Las sesiones de agentes administrados ya no se limitan a Claude y Codex; cada uno comienza con las herramientas y la identidad que necesita.
  • 🔗 Los bots pueden compartir, al igual que el propietario: Las personas que llaman al agente CLI pueden usar Compartir de la misma manera que lo hace el propietario.
  • 💬 Los hilos de Slack muestran lo que está haciendo un bot: Un hilo ahora refleja en qué está trabajando su turno y las respuestas largas llegan enteras en lugar de cortadas.
  • 📬 Los activadores de Gmail coinciden con el remitente real: Los activadores coinciden con la dirección real del remitente, no con un nombre para mostrar que puede diferir.
  • 🛡️ Advertencias de acceso más claras: El cuadro de diálogo de confirmación de acceso ahora explica lo que estás permitiendo antes de conectar un bot.

Destacados

Bots, conectores y acceso. Conecte un bot a través de un selector de conector más rápido con íconos de categorías, un cuadro de diálogo de conexión de Slack recortado que muestra cómo mencionar el bot una vez instalado y una advertencia de control de acceso más clara. Otras conversaciones se enumeran como referencia solo en el contexto de un agente, por lo que un bot permanece enfocado en aquella sobre la que se le preguntó. Las alertas de finalización y los informes de detención de trabajadores llevan la respuesta que agrega una transcripción leída y se les indica a los agentes qué tipo de correo configurar, incluso sobre --on. Un escritorio más liviano para chats y terminales ocupados. Las tiras de pestañas largas muestran solo la región visible, la sesión guarda las entradas modificadas, los mensajes nuevos se transmiten mientras se transmiten otros chats y se corrige un bucle de desplazamiento del terminal que podría congelar la ventana. Envía mientras otros chats se transmiten. El trabajo de envío de un nuevo chat tiene prioridad sobre las escrituras de transmisión en segundo plano. Los compositores ocultos también dejan de escuchar cada pulsación de tecla y los chats cerrados liberan filas de estado que ya no necesitan. Estos cambios reducen el trabajo competitivo cuando hay varias conversaciones activas. Lea el estado sin perder el hilo. Expanda las filas de actividad para obtener más detalles o abra la vista de un subagente. El texto antes de una pregunta permanece visible después de que se pliega el turno, los diagramas retenidos sobreviven a los cambios de espacio de trabajo y muchos mensajes anteriores fallidos ofrecen Reintentar. Utilice el agente en el host correcto. La instalación de Claude y Codex sigue el host donde se ejecuta el chat. Tiene prioridad una instalación personal existente; Las copias gestionadas de Orca también están disponibles para sus terminales. Los controles remotos de cuentas y las pantallas de uso también reciben correcciones. Elija actualizaciones automáticas de escritorio. Habilite Actualizaciones automáticas en Configuración → General → Acerca de para permitir que Orca descargue, instale y reinicie usando su cadencia, canal y retraso de actualización. Por defecto está desactivado. La instalación automática espera si terminaría un terminal activo o en proceso de inicio, si hay un movimiento WSL activo o no se puede guardar el estado de la ventana. Compatibilidad de teléfono. Los cambios de teléfono que se enumeran a continuación son cambios de fuente incluidos en este límite de versión. La instalación de esta actualización de escritorio no instala una actualización de la aplicación móvil; esas características requieren la compilación móvil correspondiente.

orca v1.4.265

Previous release: 1.4.264 — Chat commands find their workspace, keeping browser work with the right chat.

Introducing Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" />

Orca Bots work like first-class teammates: every managed agent session gets its tools and identity, bots can share on the owner's behalf, they follow Slack threads and Gmail triggers more reliably, and connecting them is clearer and safer.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" /> Every bot session gets its tools and identity: Managed agent sessions are no longer limited to Claude and Codex; each one starts with the tools and identity it needs.
  • 🔗 Bots can share, just like the owner: Agent CLI callers can use Sharing the same way the owner does.
  • 💬 Slack threads show what a bot is doing: A thread now reflects what its turn is working on, and long answers arrive whole instead of cut up.
  • 📬 Gmail triggers match the real sender: Triggers match the sender's actual address, not a display name that can differ.
  • 🛡️ Clearer access warnings: The access confirm dialog now spells out what you are allowing before you connect a bot.

Highlights

Bots, connectors and access. Connect a bot through a faster connector picker with category icons, a trimmed Slack connect dialog that shows how to mention the bot once it is installed, and a clearer access-control warning. Other conversations are listed for reference only in an agent's context, so a bot stays focused on the one it was asked about. Finish alerts and worker stop reports carry the reply a transcript read adds, and agents are told which mail type to set, including over --on.

A lighter desktop for busy chats and terminals. Long tab strips render only the visible region, session saves write changed entries, new messages get through while other chats stream, and a terminal scroll loop that could freeze the window is fixed.

Send while other chats stream. A new chat’s sending work gets priority over background streaming writes. Hidden composers also stop listening to every keystroke, and closed chats release status rows they no longer need. These changes reduce competing work when several conversations are active.

Read status without losing the thread. Expand activity rows for details or open a subagent’s own view. Text before a question remains visible after the turn folds, retained diagrams survive workspace switches, and failed loads of earlier messages offer Retry.

Use the agent on the right host. Claude and Codex installation follows the host where the chat runs. An existing personal installation takes precedence; Orca’s managed copies are available to its terminals too. Remote account controls and usage displays also receive fixes.

Choose automatic desktop updates. Enable Automatic updates in Settings → General → About to let Orca download, install and relaunch using your update cadence, channel and delay. It defaults to off. Automatic installation waits if it would terminate a live or launching in-process terminal, a WSL move is active, or window state cannot be saved.

Phone compatibility. The phone changes listed below are source changes included in this release boundary. Installing this desktop update does not install a mobile app update; those features require the corresponding mobile build.
