orca v1.4.250

¡Hicimos dos lanzamientos hoy! Asegúrese de revisar los v1.4.249 release note, que incluyen una configuración más sencilla de Chat o Terminal, más control sobre las conversaciones y un teléfono Home rediseñado.

Menor uso de memoria del terminal, cambios de chat más claros y un administrador de contraseñas compatible con Chrome ✨

  • ⚡ Reducir el uso de memoria del terminal: Deje de leer y analizar repetidamente archivos de fuentes para detectar ligaduras de terminales, solucionar una fuente de uso elevado de memoria y ejecutar fallas en sesiones con muchos terminales.
  • ⚡ Cambio de árbol de trabajo más rápido: Las mejoras de rendimiento hacen que el cambio entre árboles de trabajo sea más rápido.
  • 📝 Vea qué agentes cambiaron: Los turnos de chat muestran archivos modificados y recuentos de líneas, con parches disponibles en línea en el escritorio y el teléfono.
  • 🔐 Administrador de contraseñas compatible con Chrome: Habilítelo en Configuración → Navegador para guardar, completar, importar contraseñas de Chrome y administrar inicios de sesión, cifrados localmente con el almacenamiento seguro de su sistema operativo.
  • 💬 La interfaz de usuario del chat se mantiene al día con su agente: Los turnos largos y con muchas herramientas permanecen conectados en la interfaz de usuario del chat, y los chats nuevos siguen la configuración del modelo propio de su agente, a menos que usted elija un modelo.
  • 🖥️ Terminales y hosts más confiables: Evite textos perdidos en la secuencia de escape después de brechas en la salida del terminal y haga que los trabajadores de servidores emparejados y las encuestas de uso estén disponibles en hosts sin cabeza.
  • 📱 Mejor continuidad del teléfono: Envía chat con Cmd/Ctrl+Entrar y mantén los dispositivos vinculados siguiendo las pestañas que abren.

Destacados

  • Rendimiento: El cambio de árbol de trabajo es más rápido. Las ligaduras de terminales ya no analizan una fuente completa para cada terminal. En la prueba de Windows del PR con Commit Mono, 32 terminales se relanzaron sin el fallo anterior por falta de memoria; Los resultados dependen de las fuentes y la carga de trabajo. Cerrar una herramienta en un turno largo de agente también evita escanear todas las demás herramientas activas.
  • Chat: Las ediciones exitosas de Claude y Codex aparecen como resúmenes de archivos modificados en la conversación, con detalles del parche cargados al seleccionarlos. La interfaz de usuario del chat ya no interrumpe el turno de un agente que de otro modo estaría en buen estado cuando supera las 128 entradas de herramientas o texto en vivo. Los chats del Codex muestran las duraciones de espera solicitadas y admiten la pausa, reanudación y eliminación de objetivos.
  • Navegador: Guarde y complete los inicios de sesión en el navegador de Orca y adminístrelos en la configuración del navegador. Las contraseñas utilizan cifrado respaldado por el sistema operativo; la bóveda no está disponible cuando el almacenamiento seguro no está disponible.
  • Terminal y hosts remotos: La recuperación del flujo de terminal evita la impresión de secuencias de escape parciales después de espacios en la salida. Los hosts sin cabeza inician los servicios necesarios para los trabajadores de servidores emparejados y el sondeo de uso.
  • Espacio de trabajo e incorporación: Elija la interfaz de usuario de Chat durante la incorporación, oculte la lista de verificación de incorporación, busque árboles de trabajo ocultos descubiertos fuera de la agrupación de proyectos y utilice la interfaz mejorada de limpieza del espacio de trabajo inactivo.

Notas de compatibilidad y actualización

  • Ligaduras terminales: Las ligaduras comunes siguen estando disponibles. Es posible que las ligaduras específicas de fuentes fuera de la lista integrada ya no se unan al renderizador de GPU.
  • Contraseñas del navegador: La bóveda está disponible en el navegador de escritorio, incluidas las páginas del espacio de trabajo local y SSH; Las páginas de servidor emparejado transmitidas y la web client no tienen una bóveda. Se requiere cifrado seguro del sistema operativo.
  • Valores predeterminados del modelo de chat: Un nuevo chat sin una elección de modelo explícita utiliza la configuración del agente. El valor predeterminado mostrado puede estar obsoleto hasta que el agente inicie e informe su modelo.
  • Recuperación de terminal: Las transmisiones en tiempo de ejecución remota conservan su comportamiento de recuperación existente.

orca v1.4.250

We did two releases today! Be sure to check out the v1.4.249 release notes, which include easier Chat or Terminal setup, more control over conversations, and a redesigned phone Home.

Lower terminal memory use, clearer chat changes & a Chrome-compatible password manager ✨

  • ⚡ Lower terminal memory use: Stop repeatedly reading and parsing font files for terminal ligatures, fixing a source of high memory use and launch crashes in sessions with many terminals.
  • ⚡ Faster worktree switching: Performance improvements make switching between worktrees faster.
  • 📝 See what agents changed: Chat turns show changed files and line counts, with patches available inline on desktop and phone.
  • 🔐 Chrome-compatible password manager: Enable in Settings → Browser to save, fill, import Chrome passwords, and manage logins, encrypted locally with your OS’s secure storage.
  • 💬 Chat UI keeps up with your agent: Long, tool-heavy turns stay connected in Chat UI, and new chats follow your agent’s own model configuration unless you choose a model.
  • 🖥️ More reliable terminals and hosts: Prevent stray escape-sequence text after terminal output gaps, and make paired-server workers and usage polling available on headless hosts.
  • 📱 Better phone continuity: Send chat with Cmd/Ctrl+Enter and keep paired devices following the tabs they open.

Highlights

  • Performance: Worktree switching is faster. Terminal ligatures no longer parse an entire font for every terminal. In the PR’s Windows test with Commit Mono, 32 terminals relaunched without the previous out-of-memory crash; results depend on fonts and workload. Closing a tool in a long agent turn also avoids scanning every other live tool.
  • Chat: Successful Claude and Codex edits appear as changed-file summaries in the conversation, with patch details loaded on selection. Chat UI no longer interrupts an otherwise healthy agent turn when it exceeds 128 live text or tool entries. Codex chats show requested wait durations and support goal pause, resume and clear.
  • Browser: Save and fill logins in Orca’s browser and manage them in browser settings. Passwords use OS-backed encryption; the vault is unavailable when secure storage is unavailable.
  • Terminal & remote hosts: Terminal stream recovery avoids printing partial escape sequences after output gaps. Headless hosts start the services needed for paired-server workers and usage polling.
  • Workspace & onboarding: Choose Chat UI during onboarding, hide the onboarding checklist, find hidden discovered worktrees outside project grouping, and use the improved inactive workspace cleanup interface.

Compatibility & upgrade notes

  • Terminal ligatures: Common ligatures remain available. Font-specific ligatures outside the built-in list may no longer join with the GPU renderer.
  • Browser passwords: The vault is available in the desktop browser, including local and SSH workspace pages; streamed paired-server pages and the web client do not have a vault. Secure OS encryption is required.
  • Chat model defaults: A new chat without an explicit model choice uses the agent’s configuration. The displayed default can be stale until the agent starts and reports its model.
  • Terminal recovery: Remote-runtime streams retain their existing recovery behavior.
