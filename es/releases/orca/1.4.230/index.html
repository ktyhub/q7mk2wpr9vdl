orca v1.4.230

¡Muchas gracias por usar Orca y por su continuo apoyo! ❤️

La versión corta

  • Chat nativo (experimental): Utilice Antigravity en el chat, elija qué agentes se abren como chats e instale un agente faltante desde el propio chat. Pegue archivos copiados como archivos adjuntos, ponga en cola imágenes y vea comentarios más claros mientras los archivos adjuntos y las acciones en cola estén pendientes.
  • Cuentas y agentes: Después de cambiar de cuenta de Claude, reinicie las sesiones en la nueva cuenta. Elimine los tiempos de ejecución del agente descargados desde Configuración y edite o elimine comentarios lineales a través de Orca CLI.
  • Teléfono: Edite los mensajes en cola en el lugar, siga las ejecuciones de la herramienta con tarjetas estilo escritorio y vea su conversación inmediatamente cuando la reanude desde el historial. Los teléfonos horizontales colocan pestañas de sesión en la barra superior y Tareas deja claro qué escritorio estás usando.
  • SSH y espacios de trabajo remotos: La desconexión permanece desconectada, los espacios de trabajo inactivos permanecen inactivos y las pestañas cerradas permanecen cerradas después de volver a conectarse. Los mensajes de actualización y emparejamiento del servidor más claros lo ayudan a recuperar una conexión.
  • Pulido diario: Los atajos de comando rápido siguen la división enfocada, las vistas previas de pestañas esperan el retraso completo y los encabezados de archivos ofrecen Revelar en Finder. La limpieza del espacio de trabajo protege mejor los proyectos que siguen la misma ruta en otras máquinas.

Notas de compatibilidad y actualización

Chat nativo (experimental): Algunas funciones de chat requieren soporte del host remoto. Mantenga el host actualizado junto con Orca para utilizar las últimas capacidades. El comando orca en hosts SSH: Los hosts existentes conservan las preferencias de control CLI guardadas explícitamente; una preferencia no establecida se migra a desactivada. Para permitir que los comandos en un host SSH conectado abran y controlen las pestañas del navegador Orca de este escritorio para los espacios de trabajo de ese host, habilite Permitir que la orca CLI de este host controle Orca en Configuración → Hosts SSH → editar el host → Conexión avanzada.

orca v1.4.230

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chat (experimental): Use Antigravity in chat, choose which agents open as chats, and install a missing agent from the chat itself. Paste copied files as attachments, queue images, and see clearer feedback while attachments and queue actions are pending.
  • Accounts & agents: After switching Claude accounts, restart running sessions on the new account. Remove downloaded agent runtimes from Settings, and edit or delete Linear comments through the Orca CLI.
  • Phone: Edit queued messages in place, follow tool runs with desktop-style cards, and see your conversation immediately when resuming from history. Landscape phones put session tabs in the top bar, and Tasks makes clear which desktop you’re using.
  • SSH & remote workspaces: Disconnect stays disconnected, sleeping workspaces stay asleep, and closed tabs stay closed after reconnecting. Clearer server update and re-pairing messages help you recover a connection.
  • Everyday polish: Quick Command shortcuts follow the focused split, tab previews wait for the full hover delay, and file headers offer Reveal in Finder. Workspace cleanup better protects same-path projects on other machines.

Compatibility & upgrade notes

Native chat (experimental): Some chat features require support from the remote host. Keep the host updated alongside Orca to use the latest capabilities.

The orca command on SSH hosts: Existing hosts retain explicitly saved CLI control preferences; an unset preference is migrated to off. To allow commands on a connected SSH host to open and control this desktop’s Orca browser tabs for that host’s workspaces, enable Allow this host’s orca CLI to control Orca under Settings → SSH Hosts → edit the host → Advanced Connection.
