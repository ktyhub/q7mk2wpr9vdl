orca v1.4.229

¡Muchas gracias por usar Orca y por su continuo apoyo! ❤️

La versión corta

  • Chat nativo (experimental): Revise las ediciones paso a paso en línea, expanda los diagramas para desplazarse y hacer zoom, comparta imágenes del chat con un click y vea los objetivos de Claude y el uso del contexto del Codex. Las respuestas del teclado, un divisor de no leídos y Copiar al seleccionar hacen que las conversaciones largas sean más fáciles de navegar.
  • Habilidades compartidas: La instalación de habilidades compartidas ahora admite 20 agentes adicionales, con un descubrimiento WSL más amplio y las ubicaciones de instalación adecuadas para herramientas como Kiro, Qoder y CodeBuddy.
  • Teléfono: Los filtros, agrupaciones y clasificaciones del espacio de trabajo ahora siguen las opciones compartidas del escritorio. Mantenga presionado para ver problemas y notas vinculados, trabajar con espacios de trabajo del servidor y páginas del navegador, o continuar un chat compatible en una nueva conversación de terminal.
  • SSH y terminales remotos: Las correcciones de reconexión conservan los paneles divididos, el orden de pegado y los grupos de proyectos de servidor administrado. Los agentes durmientes reanudan sus conversaciones y la eliminación del proyecto de una máquina deja en paz a su contraparte en el mismo camino.
  • Espacios de trabajo y pulido cotidiano: abra un sitio web desde Cmd/Ctrl+J, observe el progreso del pago a medida que se crea un árbol de trabajo y limpie los espacios de trabajo con una confirmación explícita antes de detener la ejecución de agentes.
  • Planificación de Jira: Cambie entre listas de problemas y tableros, concéntrese en el sprint actual, reutilice los favoritos JQL y Jira guardados e inicie espacios de trabajo desde el escritorio o el teléfono. Sus agentes también pueden leer y actualizar tickets de Jira a través de Orca CLI.

Problemas conocidos

Chat nativo (experimental): Las funciones que dependen de un host remoto están disponibles cuando ese host las admite. Actualice el host junto con Orca para obtener las últimas capacidades. El comando orca en hosts SSH: Los hosts existentes mantienen su preferencia de control Orca CLI guardada. Para permitir que los agentes administren espacios de trabajo o controlen el navegador de escritorio, active Permitir que la orca CLI de este host controle Orca en Configuración → Hosts SSH → editar el host → Conexión avanzada.

orca v1.4.229

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chat (experimental): Review turn-by-turn edits inline, expand diagrams to pan and zoom, share chat visuals with a click, and see Claude goals and Codex context usage. Keyboard answers, an unread divider and Copy on Select make long conversations easier to navigate.
  • Shared skills: Shared-skill installation now supports 20 additional agents, with broader WSL discovery and the right install locations for tools such as Kiro, Qoder and CodeBuddy.
  • Phone: Workspace filters, grouping and sorting now follow the desktop’s shared choices. Long-press for linked issues and notes, work with server workspaces and browser pages, or continue a supported chat in a new terminal conversation.
  • SSH and remote terminals: Reconnect fixes preserve split panes, paste order and managed-server project groups. Sleeping agents resume their conversations, and removing one machine’s project leaves its same-path counterpart alone.
  • Workspaces and everyday polish: Open a website from Cmd/Ctrl+J, watch checkout progress as a worktree is created, and clean up workspaces with an explicit confirmation before stopping running agents.
  • Jira planning: Switch between issue lists and boards, focus on the current sprint, reuse saved JQL and Jira favourites, and start workspaces from desktop or phone. Your agents can read and update Jira tickets through the Orca CLI, too.

Known issues

Native chat (experimental): Features that depend on a remote host are available when that host supports them. Update the host alongside Orca to get the latest capabilities.

The orca command on SSH hosts: Existing hosts keep their saved Orca CLI control preference. To let agents there manage workspaces or control the desktop browser, turn on Allow this host’s orca CLI to control Orca under Settings → SSH Hosts → edit the host → Advanced Connection.
