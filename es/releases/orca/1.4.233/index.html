orca v1.4.233

¡Muchas gracias por usar Orca y por su continuo apoyo! ❤️ ¡Enviamos dos lanzamientos hoy! Si te lo perdiste, mira también los v1.4.232 release note. Los aspectos más destacados incluyen permisos de agente Manual/Automático/Yolo, OpenCode 2 en el chat nativo, un mejor compositor de teléfono con archivos adjuntos y habilidades en línea, recuperación SSH más fluida y una aplicación más pequeña con actualizaciones de Mac más rápidas. Actualizaciones del teléfono: La actualización de Orca en su escritorio también actualiza la aplicación en su teléfono conectado; el teléfono la carga directamente desde su escritorio.

La versión corta

  • SSH y espacios de trabajo remotos: La conexión a un host SSH funciona cuando ninguna máquina puede descargar Node.js, con un espejo de un click, Orca recuerda y vuelve a intentar. Los hosts de Windows más antiguos (Windows 10 1809 y Server 2019) pueden ejecutar el servidor de Orca y los túneles se recuperan cuando un puerto está retenido por una conexión SSH antigua.
  • Servidores remotos en Configuración: Los servidores remotos de Orca son una lista en lugar de seis secciones, y los hosts SSH se pueden eliminar de forma masiva y permanecer eliminados. Orca le indica cuándo se guardó el mismo servidor dos veces y, al agregar un servidor que ya guardó, lo actualiza.
  • Teléfono: Crear un espacio de trabajo desde el teléfono es mucho más rápido, la lista del espacio de trabajo se mantiene en sintonía con el escritorio y los íconos de las pestañas de sesión mantienen su tamaño junto a los títulos largos.
  • Editor: Orca se niega a guardar los cambios realizados en un archivo en el disco que no has visto, y Recargar y Deshacer se comportan de manera predecible después.
  • Pulido diario: Los proyectos con el mismo nombre en diferentes máquinas mantienen nombres cortos y muestran en qué máquina se encuentran. Las conversaciones guardadas durante mucho tiempo utilizan mucha menos memoria cuando Orca las escanea en busca del historial de sesiones.

orca v1.4.233

Thank you so much for using Orca and for your continued support! ❤️

We shipped two releases today! If you missed it, check out the v1.4.232 release notes too. Highlights include Manual / Auto / Yolo agent permissions, OpenCode 2 in native chat, a better phone composer with file attachments and inline skills, smoother SSH recovery, and a smaller app with faster Mac updates.

Phone updates: Updating Orca on your desktop also updates the app on your connected phone—the phone loads it directly from your desktop.

The short version

  • SSH & remote workspaces: Connecting to an SSH host works when neither machine can download Node.js, with a one-click mirror Orca remembers and retries. Older Windows hosts (Windows 10 1809 and Server 2019) can run Orca's server, and tunnels recover when a port is held by an old SSH connection.
  • Remote servers in Settings: Remote Orca Servers is one list instead of six sections, and SSH hosts can be removed in bulk and stay removed. Orca tells you when the same server was saved twice, and adding a server you already saved updates it instead.
  • Phone: Creating a workspace from the phone is much faster, the workspace list stays in step with the desktop, and session tab icons keep their size beside long titles.
  • Editor: Orca refuses to save over changes made to a file on disk that you haven't seen, and Reload and Undo behave predictably afterwards.
  • Everyday polish: Projects with the same name on different machines keep short names and show which machine they're on. Long saved conversations use far less memory when Orca scans them for Session History.
