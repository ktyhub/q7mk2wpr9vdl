Estudio de voz v0.5.4

Motores que funcionan, audio de formato largo más fluido e integraciones locales útiles. CosyVoice repara su tiempo de ejecución y preserva el contexto del habla con los Transformers más nuevos. Las historias y los audiolibros obtienen uniones de audio más limpias, mejores controles de guiones e importaciones de EPUB más confiables. La configuración y el diagnóstico de electrones facilitan la recuperación de fallas sin descartar modelos descargados o proyectos existentes.

¿Ya estás usando Electron? Instálelo sobre su aplicación existente y conserve sus datos. Si se le solicita, elija Instalar tiempo de ejecución local para actualizar sus dependencias. ¿Te mudas desde Tauri? Haga una copia de seguridad de su directorio de datos con la aplicación cerrada, instale Electron, luego verifique sus voces y proyectos antes de eliminar Tauri. Siga la guía de migración. Tauri v0.5.3 sigue siendo el lanzamiento final de Tauri; su actualizador no puede instalar Electron.

Aspectos destacados

  • Reparar la generación de CosyVoice y varias rutas de instalación del motor sin eliminar los modelos descargados (#2258, #2240, #2243)
  • Uniones de historias y audiolibros más limpias, controles de guiones e importaciones de EPUB (#2259, #2216, #2203, #2228)

  • Conserve el diálogo, la sincronización y el audio de fondo mediante doblaje e importaciones de subtítulos (#2222, #2224, #2242)

VoiceStudio v0.5.4

Highlights

  • Tauri → Electron is a manual migration, not an in-place update — Tauri v0.5.3 is the final Tauri build and its updater cannot install Electron, so auto-update won't carry users across. Back up the data directory with the app closed, install Electron, verify voices/projects before removing Tauri, and pick Install local runtime when prompted; this is the one change that needs operator action rather than just relaunching.
  • Engine repair no longer costs you your downloaded models — CosyVoice restores missing runtime dependencies, preserves speech context on newer Transformers, and matches float32 weights/inputs off-CUDA to kill worker-thread dtype failures (#2096); IndexTTS installs under Python 3.11 and repairs broken environments on retry without deleting cached weights (#2098). Also watch the dots.tts path/pin fixes (#2101) and VoxCPM2's native control format, which changes style delivery (#2093).
  • Clean-install engine installs finally work — The backend now points at its bundled uv instead of relying on PATH: the packaged binary sits in app resources (on no PATH) and GUI launches inherit no shell PATH additions, which previously made one-click installs fail preflight with "uv was not found" (#2221, #2215). Combined with dependency validation before reusing a desktop runtime (#2176), this removes the classic "works in a terminal, fails in the app" case.
  • Long-form audio joins and script defaults changed — Per-line engine padding is trimmed and replaced with an explicit, adjustable gap between lines and paragraphs (#2216), and Paste & Split now defaults to Paragraphs instead of one take per sentence (#2217) — expect existing projects to render with different pacing. EPUB import now honors the book's declared start and TOC, skipping teaser/copyright/footnote pages as front/back matter (#2228, #2208), while a one-step Clear script keeps the cast (#2203).
  • Dubbing and subtitle fidelity tightened — Rolling-caption dubs speak each line once while preserving intentional repeated dialogue (#2222), and background preservation works with newer FFmpeg that dropped the legacy filter-file option (#2236). Subtitles now keep milliseconds across second boundaries (#2074), retain cues containing --> or I <3 you intact in exports (#2226), decode entities (#2223), and stop tab-through from resnapping segment times (#2224).
  • Local toolchain and diagnostics level up — Export local n8n speech workflows (#2261) and wire Claude Code/Cursor to the current backend via MCP setup pages (#2257). Completed generations are no longer discarded when worker completion races the timeout check (#2264), and failures now carry the backend error class into reports (#2197) with actionable messages for unsupported GPUs or blocked files instead of generic "Generation failed" text (#2195, #2177).

Working engines, smoother long-form audio, and useful local integrations. CosyVoice repairs its runtime and preserves speech context with newer Transformers. Stories and audiobooks gain cleaner audio joins, better script controls, and more reliable EPUB imports. Electron setup and diagnostics make failures easier to recover from without discarding downloaded models or existing projects.
