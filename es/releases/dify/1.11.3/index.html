dify 1.11.3

🚀 ¿Qué hay de nuevo en v1.11.3?

Nuestra última versión, v1.11.3, le ofrece una gran cantidad de correcciones de errores y funciones centradas en el rendimiento, la funcionalidad y la experiencia del usuario. He aquí un vistazo a lo que ha cambiado:

🎬 Nuevas funciones

  • Mejoras de la herramienta MCP: se agregó soporte para embeddedResource y las herramientas MCP se muestran directamente para un acceso más rápido por parte de @IthacaDream y @fatelei en #30261 y #30019.
  • Operaciones por lotes: @fatelei introdujo la operación de reindexación en operaciones por lotes de documentos en el n.º 30275.
  • Actualizaciones de agentes y flujos de trabajo: el nuevo AgentMaxIterationError y las mejoras en las comprobaciones del modo de aplicación hacen que los flujos de trabajo y los agentes sean más sólidos por @fatelei.
  • Integración de OAuth: el inicio de sesión en la interfaz ahora admite el indicador oauth_new_user de @zyssyz123 en el n.° 30370.
  • Extracción de PDF: extractor RAG mejorado para admitir la extracción de imágenes de archivos PDF por @yangzq50 en #30399.
  • Almacenamiento y archivo: almacenamiento de archivos agregado client y configuraciones de configuración por @hjlarry en #30422.
  • Traducción e internacionalización: se agregó soporte RSC inicial para traducciones para una audiencia global por @hyoban en #30596.

🛠️ Corrección de errores

  • Redis y caché: canalizaciones utilizadas para optimizar las eliminaciones de caché de Redis, mejorando la velocidad y la confiabilidad por @fatelei en #30159.
  • Correcciones de UI/UX: desde prevenir fallas de página debido a errores de permiso hasta corregir el tamaño de los botones, varios contribuyentes han abordado múltiples problemas relacionados con la UI.
  • Operaciones de datos: Se corrigieron errores de acceso al conjunto de datos y se mejoró el manejo de errores en operaciones por lotes por parte de @zhaobingshuang y otros.
  • Rendimiento: Se publicaron referencias de estado de tiempo de ejecución bajo carga alta para evitar posibles pérdidas de memoria por parte de @SherlockShemol en el n.° 30236.
  • Seguridad: Se rectificaron problemas de CORS y SSL que podrían haber afectado las integraciones de bots y las operaciones de Celery.
  • Internacionalización: @sangyun-han actualizó las traducciones y el contenido coreano para mayor precisión en el n.° 30347.

🔧 Debajo del capó

  • CI/CD y mejoras de compilación: acciones GitHub mejoradas y procesos de compilación para una mayor confiabilidad y menos tiempo de inactividad por parte de @bowenliang123 y @hyoban.
  • Optimización de código y consultas: se abordaron ineficiencias en consultas SQL y manejo de datos en flujos de trabajo y el API, mejorando la estabilidad general.

Esta versión hace hincapié en optimizar las operaciones backend, fortalecer la seguridad y enriquecer la interfaz de usuario para una experiencia más fluida y productiva. ¡Gracias a todos los contribuyentes por perfeccionar Dify e impulsar nuestra plataforma! 🛠️💡

Guía de actualización

Docker Redactar implementaciones

  1. Haga una copia de seguridad de su archivo docker-compose YAML personalizado (opcional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Obtenga el código más reciente de la rama principal.

    git checkout main
git pull origin main

  3. Detenga el servicio. Ejecute en el directorio docker

    docker compose down

  4. Hacer una copia de seguridad de los datos

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Servicios de actualización

    docker compose up -d

Implementaciones de código fuente

  1. Detenga el servidor API, el trabajador y el servidor frontend web.

  2. Obtenga el código más reciente de la rama de lanzamiento:

    git checkout 1.11.3

  3. Actualice las dependencias de Python:

    cd api
uv sync

  4. Luego, ejecutemos el script de migración:

    uv run flask db upgrade

  5. Finalmente, ejecute nuevamente el servidor API, el trabajador y el servidor frontend web.

🚀 What's New in v1.11.3?

Our latest release, v1.11.3, brings to you a slew of bug fixes and features focused on performance, functionality, and user experience. Here's a look at what's changed:

🎬 New Features

  • MCP Tool Enhancements: Added support for embeddedResource and made MCP tools display directly for quicker access by @IthacaDream and @fatelei in #30261 and #30019.
  • Batch Operations: Introduced re-index operation in document batch operations by @fatelei in #30275.
  • Agent and Workflow Updates: New AgentMaxIterationError and enhancements in app mode checks make workflows and agents more robust by @fatelei.
  • OAuth Integration: Frontend login now supports oauth_new_user flag by @zyssyz123 in #30370.
  • PDF Extraction: Improved RAG extractor to support image extraction from PDFs by @yangzq50 in #30399.
  • Storage and Archive: Added archive storage client and config settings by @hjlarry in #30422.
  • Translation and Internationalization: Added initial RSC support for translations for a global audience by @hyoban in #30596.

🛠️ Bug Fixes

  • Redis and Cache: Used pipelines to optimize Redis cache deletions, enhancing speed and reliability by @fatelei in #30159.
  • UI/UX Fixes: From preventing page crashes due to permission errors to fixing flicking button sizes, multiple UI-related issues have been addressed by various contributors.
  • Data Operations: Fixed dataset access errors and improved error handling in batch operations by @zhaobingshuang and others.
  • Performance: Released runtime state references under high load to prevent potential memory leaks by @SherlockShemol in #30236.
  • Security: Rectified CORS and SSL issues that could've affected bot integrations and Celery operations.
  • Internationalization: Korean translations and content were updated for accuracy by @sangyun-han in #30347.

🔧 Under the Hood

  • CI/CD and Build Enhancements: Enhanced GitHub actions and build processes for better reliability and less downtime by @bowenliang123 and @hyoban.
  • Code & Query Optimization: Addressed inefficiencies in SQL queries and data handling in workflows and the API, improving overall stability.

This release emphasizes streamlining backend operations, fortifying security, and enriching the user interface for a smoother, more productive experience. Thank you to all contributors for refining Dify and pushing our platform forward! 🛠️💡

Upgrade Guide

Docker Compose Deployments

  1. Back up your customized docker-compose YAML file (optional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Get the latest code from the main branch

    git checkout main
git pull origin main

  3. Stop the service. Please execute in the docker directory

    docker compose down

  4. Back up data

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Upgrade services

    docker compose up -d
