shardingsphere 5.3.0

fragmentaciónesfera 5.3.0

API Cambios

  1. DistSQL: sintaxis de refactorización API, consulte el manual del usuario
  2. Proxy: cambie el estilo de configuración de la regla global, elimine el signo de exclamación
  3. Proxy: permite el inicio sin configuración, habilita la cuenta raíz/raíz predeterminada cuando no hay configuración de autoridad
  4. Proxy: elimine el logback.xml predeterminado y use la inicialización API
  5. JDBC: elimine la configuración de Spring y use la configuración Driver + YAML en su lugar

Mejoras

  1. DistSQL: nueva sintaxis ACTUALIZAR METADATOS DE LA BASE DE DATOS, actualizar los metadatos de la base de datos lógica
  2. Kernel: admite DistSQL ACTUALIZAR METADATOS DE LA BASE DE DATOS para cargar la configuración desde el centro de gobierno y reconstruir MetaDataContext
  3. Admite configuración de nivel de aislamiento de transacciones postgresql/openGauss
  4. Escalado: aumentar la frecuencia de actualización del progreso de las tareas de inventario
  5. Escalado: verificación de coherencia DATA_MATCH compatible con reanudación del punto de interrupción
  6. Escalado: soporte para trabajos de verificación de consistencia a través de DistSQL
  7. Escalado: cambie el nombre de la columna de sharding_total_count a job_item_count en la respuesta DistSQL de la lista de trabajos
  8. Escalado: agregue una columna de fragmentación en la tarea incremental SQL para evitar el enrutamiento de transmisión
  9. Escalado: la columna de fragmentación podría actualizarse al generar SQL
  10. Escalado: mejorar el lector de valores de columna para verificar la coherencia de DATA_MATCH
  11. DistSQL: optimización de la sintaxis de Cifrado DistSQL, compatible con algoritmos de consulta similares
  12. DistSQL: Agregar verificación de valor de propiedades al REGISTRAR LA UNIDAD DE ALMACENAMIENTO
  13. DistSQL: elimina algoritmos inútiles al mismo tiempo que DROP RULE
  14. DistSQL: EXPORTAR CONFIGURACIÓN DE BASE DE DATOS admite tablas de transmisión
  15. DistSQL: REGISTRAR LA UNIDAD DE ALMACENAMIENTO admite fuentes de datos heterogéneas
  16. Cifrar: admite la función Cifrar LIKE
  17. Inicie automáticamente transacciones distribuidas al ejecutar declaraciones DML en múltiples fragmentos
  18. Kernel: soporte client \d para PostgreSQL y openGauss
  19. Kernel: admite seleccionar grupo por, ordenar por declaración cuando la columna contiene valores nulos
  20. Kernel: admite la cláusula RETURNING de análisis de PostgreSQL/openGauss Insert
  21. Kernel: mejora del rendimiento de SQL HINT
  22. Kernel: admite el caso mysql cuando se analiza la declaración
  23. Kernel: admite puerta de enlace de base de datos heterogénea a nivel de fuente de datos
  24. Fragmentación (experimental): agregar complemento de caché de fragmentación
  25. Proxy: admite más formatos de fecha y hora PostgreSQL
  26. Proxy: compatible con MySQL COM_RESET_CONNECTION
  27. Escalado: Mejore MySQLBinlogEventType.valueOf para admitir tipos de eventos desconocidos
  28. Kernel: caso de soporte para la federación

Corrección de errores

  1. Escalado: reparar el nodo de barrera creado al eliminar el trabajo
  2. Escalado: corregir parte del valor de las columnas podría ignorarse en la verificación de coherencia de DATA_MATCH
  3. Escalado: los parámetros de URL de jdbc fijos no se actualizan en la verificación de coherencia
  4. Escalado: el tipo de algoritmo de fragmentación de tablas reparado INLINE distingue entre mayúsculas y minúsculas
  5. Escalado: corregir la tarea incremental en MySQL requiere permiso de la base de datos del sistema mysql
  6. Proxy: corrige el NPE al ejecutar SQL seleccionado sin nodo de almacenamiento
  7. Proxy: admite verificación de permisos DATABASE_PERMITTED en escenarios de unidifusión
  8. Kernel: corrija el valor incorrecto de ID de trabajador en los nodos de cálculo de visualización
  9. Kernel: corrige el error de ruta cuando la cantidad de fuentes de datos legibles y las configuraciones de peso del algoritmo de peso no son iguales
  10. Kernel: corrige varios grupos de división de lectura y escritura que hacen referencia al mismo nombre del balanceador de carga y el balanceador de carga falla.
  11. Kernel: La solución no puede deshabilitar y habilitar el problema del nodo de cálculo
  12. JDBC: la fuente de datos reparada se cierra en el modo de clúster ShardingSphereDriver cuando hay un problema de inicio
  13. Kernel: corrige el resultado de reescritura incorrecto cuando parte del nombre de la tabla lógica de la tabla vinculante es consistente con el nombre de la tabla real y algunos son inconsistentes.
  14. Kernel: corrige la excepción de inicio cuando se usa SpringBoot sin configurar reglas
  15. Cifrar: corrige la excepción del puntero nulo cuando el valor de cifrado es nulo
  16. Kernel: el análisis de Oracle reparado no admite el tipo especificado varchar2
  17. Kernel: corrige el error de evaluación del indicador de serie dentro de la transacción
  18. Kernel: corrige el error de búsqueda del cursor causado por el cambio wasNull
  19. Kernel: se corrige el error de alterar la regla de transacción al actualizar los metadatos
  20. Cifrar: corrige la conversión de EncryptRule a la excepción TransparentRule que se produce cuando se ejecuta la instrucción del procedimiento de llamada en el escenario Encrypt.
  21. Cifrar: corrige la excepción causada por ExpressionProjection en la proyección taquigráfica
  22. Proxy: Corrige la decodificación incorrecta del valor negativo del Proxy int2 de PostgreSQL
  23. Proxy: el soporte de PostgreSQL/openGauss describe la cláusula de devolución de inserción
  24. Proxy: Reparar gsql 3.0 puede estar bloqueado al conectar el Proxy
  25. Proxy: se omiten parámetros de corrección al verificar SQL en el backend de Proxy
  26. Proxy: habilite el proxy MySQL para codificar paquetes grandes
  27. Kernel: corrige el comentario de análisis de Oracle sin error de espacios en blanco
  28. DistSQL: Se corrigió mostrar crear tabla para cifrar la tabla

Refactorizar

  1. Escalado: invierta el nombre de la tabla y el nombre de la columna al generar SQL si es una palabra clave SQL
  2. Escalado: mejorar el manejo incremental de fallas en las tareas
  3. Kernel: ajuste del nodo del centro de gobernanza, joroba unificada para subrayar

original en inglés / English original

shardingsphere 5.3.0

API Changes

  1. DistSQL: Refactor syntax API, please refer to the user manual
  2. Proxy: Change the configuration style of global rule, remove the exclamation mark
  3. Proxy: Allow zero-configuration startup, enable the default account root/root when there is no Authority configuration
  4. Proxy: Remove the default logback.xml and use API initialization
  5. JDBC: Remove the Spring configuration and use Driver + YAML configuration instead

Enhancements

  1. DistSQL: New syntax REFRESH DATABASE METADATA, refresh logic database metadata
  2. Kernel: Support DistSQL REFRESH DATABASE METADATA to load configuration from the governance center and rebuild MetaDataContext
  3. Support postgresql/openGauss setting transaction isolation level
  4. Scaling: Increase inventory task progress update frequency
  5. Scaling: DATA_MATCH consistency check support breakpoint resume
  6. Scaling: Support drop consistency check job via DistSQL
  7. Scaling: Rename column from sharding_total_count to job_item_count in job list DistSQL response
  8. Scaling: Add sharding column in incremental task SQL to avoid broadcast routing
  9. Scaling: Sharding column could be updated when generating SQL
  10. Scaling: Improve column value reader for DATA_MATCH consistency check
  11. DistSQL: Encrypt DistSQL syntax optimization, support like query algorithm
  12. DistSQL: Add properties value check when REGISTER STORAGE UNIT
  13. DistSQL: Remove useless algorithms at the same time when DROP RULE
  14. DistSQL: EXPORT DATABASE CONFIGURATION supports broadcast tables
  15. DistSQL: REGISTER STORAGE UNIT supports heterogeneous data sources
  16. Encrypt: Support Encrypt LIKE feature
  17. Automatically start distributed transactions when executing DML statements across multiple shards
  18. Kernel: Support client \d for PostgreSQL and openGauss
  19. Kernel: Support select group by, order by statement when column contains null values
  20. Kernel: Support parse RETURNING clause of PostgreSQL/openGauss Insert
  21. Kernel: SQL HINT performance improvement
  22. Kernel: Support mysql case when then statement parse
  23. Kernel: Supporting data source level heterogeneous database gateway
  24. (Experimental) Sharding: Add sharding cache plugin
  25. Proxy: Support more PostgreSQL datetime formats
  26. Proxy: Support MySQL COM_RESET_CONNECTION
  27. Scaling: Improve MySQLBinlogEventType.valueOf to support unknown event type
  28. Kernel: Support case when for federation

Bug Fix

  1. Scaling: Fix barrier node created at job deletion
  2. Scaling: Fix part of columns value might be ignored in DATA_MATCH consistency check
  3. Scaling: Fix jdbc url parameters are not updated in consistency check
  4. Scaling: Fix tables sharding algorithm type INLINE is case-sensitive
  5. Scaling: Fix incremental task on MySQL require mysql system database permission
  6. Proxy: Fix the NPE when executing select SQL without storage node
  7. Proxy: Support DATABASE_PERMITTED permission verification in unicast scenarios
  8. Kernel: Fix the wrong value of worker-id in show compute nodes
  9. Kernel: Fix route error when the number of readable data sources and weight configurations of the Weight algorithm are not equal
  10. Kernel: Fix multiple groups of readwrite-splitting refer to the same load balancer name, and the load balancer fails problem
  11. Kernel: Fix can not disable and enable compute node problem
  12. JDBC: Fix data source is closed in ShardingSphereDriver cluster mode when startup problem
  13. Kernel: Fix wrong rewrite result when part of logical table name of the binding table is consistent with the actual table name, and some are inconsistent
  14. Kernel: Fix startup exception when use SpringBoot without configuring rules
  15. Encrypt: Fix null pointer exception when Encrypt value is null
  16. Kernel: Fix oracle parsing does not support varchar2 specified type
  17. Kernel: Fix serial flag judgment error within the transaction
  18. Kernel: Fix cursor fetch error caused by wasNull change
  19. Kernel: Fix alter transaction rule error when refresh metadata
  20. Encrypt: Fix EncryptRule cast to TransparentRule exception that occurs when the call procedure statement is executed in the Encrypt scenario
  21. Encrypt: Fix exception which caused by ExpressionProjection in shorthand projection
  22. Proxy: Fix PostgreSQL Proxy int2 negative value decoding incorrect
  23. Proxy: PostgreSQL/openGauss support describe insert returning clause
  24. Proxy: Fix gsql 3.0 may be stuck when connecting Proxy
  25. Proxy: Fix parameters are missed when checking SQL in Proxy backend
  26. Proxy: Enable MySQL Proxy to encode large packets
  27. Kernel: Fix oracle parse comment without whitespace error
  28. DistSQL: Fix show create table for encrypt table

Refactor

  1. Scaling: Reverse table name and column name when generating SQL if it's SQL keyword
  2. Scaling: Improve increamental task failure handling
  3. Kernel: Governance center node adjustment, unified hump to underscore

Change Log

  1. MILESTONE
