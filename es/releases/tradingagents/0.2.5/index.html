Agentes comerciales v0.2.5

Resumen

TradingAgents v0.2.5 incluye Sentiment Analyst conectado a tierra, soporte de doble región Qwen/GLM/MiniMax, configurabilidad de env-var `TRADINGAGENTS_*` con detección automática de clave API, soporte remoto de Ollama, puntos de referencia alfa configurables para tickers fuera de EE. UU. y una solución de recorrido de ruta de ticker.

Analista de sentimiento

El Sentiment Analyst renombrado ahora lee datos reales de Yahoo News, StockTwits y Reddit antes de generar su informe, reemplazando el flujo anterior que podría fabricar publicaciones sociales bajo presión inmediata. El nuevo nombre fluye a través del menú desplegable CLI, el panel de estado y los informes finales; `AnalystType.SOCIAL = "social"` se mantiene para la retrocompatibilidad de la configuración guardada.

Cobertura del proveedor

  • MiniMax con el catálogo M2.x completo (contexto 204K), además de región dual Global (`MINIMAX_API_KEY`) y China (`MINIMAX_CN_API_KEY`).
  • Qwen y GLM de doble región con claves separadas por región (`DASHSCOPE_`, `ZHIPU_`), elegidas mediante un mensaje de región secundaria para que el menú desplegable del proveedor principal permanezca limpio.
  • Actualización del catálogo en todos los proveedores: GPT-5.5 frontier, Claude Opus 4.7, Gemini 3.1 Flash-Lite GA, Grok 4.20, Qwen 3.6 line. Solo identificaciones versionadas; Los alias de cambio automático se movieron a la opción "ID de modelo personalizado".
  • La salida estructurada ahora funciona en DeepSeek V4 / Reasoner y MiniMax M2.x: esos proveedores rechazan `tool_choice`; el flujo de enlace ahora lo omite automáticamente.

Configuración a través del entorno

`TRADINGAGENTS_*` env vars anula las claves `DEFAULT_CONFIG` con coerción con reconocimiento de tipo (string / int / bool): `llm_provider`, ID de modelo profundo/rápido, `backend_url`, `output_language`, recuentos de rondas de debate, el indicador de punto de control y el ticker de referencia. Cuando falta la clave API de un proveedor seleccionado, el CLI la solicita y conserva el valor en `.env` para que la ejecución continúe sin reiniciar.

##Ollama

`OLLAMA_BASE_URL` hace que el `ollama-serve` remoto sea de primera clase tanto para el CLI como para los usuarios programáticos. El CLI imprime el punto final resuelto después de seleccionar Ollama y advierte sobre entradas comunes con formato incorrecto. Una nueva opción "ID de modelo personalizado" permite a los usuarios elegir cualquier modelo que hayan obtenido a través de `ollama pull`.

Reflexión

Alpha ahora se calcula con respecto a un punto de referencia regional para tickers fuera de EE. UU.: `.NS` (^NSEI), `.T` (^N225), `.HK` (^HSI), `.L` (^FTSE), `.TO` (^GSPTSE), `.AX` (^AXJO), `.BO` (^BSESN), SPY para listados de EE. UU. Elimina la deriva del tipo de cambio que domina la cifra alfa para cotizaciones distintas al USD. `benchmark_ticker` anula el mapa de sufijos cuando se establece explícitamente.

Los parámetros de búsqueda de noticias (límite de artículo por ticker, límite de titulares de macro, ventana retrospectiva, consultas de búsqueda de macro) ahora se exponen a través de `DEFAULT_CONFIG` para un ajuste específico de la estrategia.

Varios idiomas

`output_language` ahora se propaga a todos los agentes que interactúan con el usuario (investigadores, debatientes de riesgos, gerentes de investigación y comerciantes), poniendo fin a los informes anteriores de localización parcial donde solo los analistas y el administrador de cartera respetaban el entorno.

Correcciones

  • Seguridad: validación de recorrido de ruta de ticker en cada sitio de ruta del sistema de archivos.
  • Las instalaciones de `pip install .` ahora seleccionan el proyecto `.env` cuando se ejecuta CLI como script de consola.
  • Los informes se guardan de un extremo a otro: los fragmentos transmitidos anteriormente se eliminaban de `complete_report.md`.
  • El mensaje de teletipo conserva los sufijos de intercambio (`.SH`, `.SZ`, `.SS`, `.HK`, `.T`, etc.).
  • Errores de permisos Docker ya no bloquean la escritura de primera ejecución en `~/.tradingagents/`.
  • El estado de configuración ya no se filtra entre ejecuciones cuando se modifican los subdictados.
  • La configuración `max_recur_limit` realmente se aplica al propagador.
  • Error de clave faltante-API nombra la var de entorno exacta a configurar.
  • Inicio más silencioso: se suprimió la ruidosa advertencia de desuso del punto de control de langgraph ascendente.

Consulte CHANGELOG.md para obtener la lista completa por elemento con referencias de relaciones públicas/problemas.

TradingAgents v0.2.5

Highlights

  • Grounded Sentiment Analyst — Reports now draw on actual Yahoo News, StockTwits, and Reddit data instead of relying on prompts that could invent social posts (#557, #607). The UI and final reports use the new name consistently, while AnalystType.SOCIAL = "social" preserves compatibility with saved configurations.
  • More providers, safer structured output — MiniMax M2.x adds 204K-context models with separate Global/China keys; Qwen and GLM now support regional credentials through a secondary selector (#758). DeepSeek V4/reasoner and MiniMax M2.x automatically skip unsupported tool_choice parameters, avoiding structured-output failures. The refreshed catalog pins versioned model IDs, so users of floating aliases should switch to Custom model ID.
  • Environment-driven deployment and remote Ollama — TRADINGAGENTS_* variables override DEFAULT_CONFIG with string/int/bool coercion (#602); missing provider keys are prompted for and persisted to .env without restarting. OLLAMA_BASE_URL supports remote ollama-serve and arbitrary pulled model IDs (#648, #768), while console-script installs now load the project .env (#747). output_language also reaches researchers, risk debators, the research manager, and trader, eliminating mixed-language final reports (#575).
  • Regional alpha benchmarks — Non-US tickers are now evaluated against .NS/^NSEI, .T/^N225, .HK/^HSI, .L/^FTSE, .TO/^GSPTSE, .AX/^AXJO, and .BO/^BSESN rather than SPY, reducing FX distortion (#628, #684). Set benchmark_ticker to override the mapping; historical alpha figures will differ, so align benchmarks when comparing runs. Exchange suffixes are also preserved in prompts (#770).
  • Security and run integrity — Ticker validation now protects cache, checkpoint, and result paths from traversal (#618). Streamed reports are no longer truncated in complete_report.md (#719, #736), nested config mutations no longer leak between runs (#788), and max_recur_limit now reaches the propagator (#764)—fixes that matter for untrusted tickers, auditability, and repeatable execution.
  • Breaking changes — None.

Summary

TradingAgents v0.2.5 ships the grounded Sentiment Analyst, Qwen/GLM/MiniMax dual-region support, `TRADINGAGENTS_*` env-var configurability with API-key auto-detection, remote Ollama support, configurable alpha benchmarks for non-US tickers, and a ticker path-traversal fix.

Sentiment Analyst

The renamed Sentiment Analyst now reads real Yahoo News, StockTwits, and Reddit data before generating its report, replacing the prior flow that could fabricate social posts under prompt pressure. The new name flows through the CLI dropdown, status panel, and final reports; `AnalystType.SOCIAL = "social"` is kept for saved-config back-compat.

Provider Coverage

  • MiniMax with the full M2.x catalog (204K context), plus dual-region Global (`MINIMAX_API_KEY`) and China (`MINIMAX_CN_API_KEY`).
  • Dual-region Qwen and GLM with separate keys per region (`DASHSCOPE_`, `ZHIPU_`), chosen via a secondary region prompt so the main provider dropdown stays clean.
  • Catalog refresh across every provider: GPT-5.5 frontier, Claude Opus 4.7, Gemini 3.1 Flash-Lite GA, Grok 4.20, Qwen 3.6 line. Versioned IDs only; auto-shifting aliases moved to a "Custom model ID" option.
  • Structured output now works on DeepSeek V4 / reasoner and MiniMax M2.x — those providers reject `tool_choice`; the binding flow now skips it automatically.

Configuration via Environment

`TRADINGAGENTS_*` env vars override `DEFAULT_CONFIG` keys with type-aware coercion (string / int / bool) — `llm_provider`, deep/quick model IDs, `backend_url`, `output_language`, debate-round counts, the checkpoint flag, and the benchmark ticker. When a selected provider's API key is missing, the CLI prompts for it and persists the value to `.env` so the run continues without restart.

Ollama

`OLLAMA_BASE_URL` makes remote `ollama-serve` first-class for both the CLI and programmatic users. The CLI prints the resolved endpoint after selecting Ollama and warns on common malformed inputs. A new "Custom model ID" option lets users pick any model they have pulled via `ollama pull`.

Reflection

Alpha is now computed against a regional benchmark for non-US tickers — `.NS` (^NSEI), `.T` (^N225), `.HK` (^HSI), `.L` (^FTSE), `.TO` (^GSPTSE), `.AX` (^AXJO), `.BO` (^BSESN), SPY for US listings. Eliminates FX drift dominating the alpha figure for non-USD listings. `benchmark_ticker` overrides the suffix map when set explicitly.

News-fetch parameters (per-ticker article limit, macro headline limit, lookback window, macro search queries) are now exposed via `DEFAULT_CONFIG` for strategy-specific tuning.

Multi-language

`output_language` now propagates to every user-facing agent — researchers, risk debators, research manager, and trader — ending the previous partial-localization reports where only analysts and the portfolio manager respected the setting.

Fixes

  • Security: ticker path-traversal validation at every filesystem-path site.
  • `pip install .` installations now pick up the project `.env` when running the CLI as a console script.
  • Reports save end-to-end — streamed chunks were previously dropped from `complete_report.md`.
  • Ticker prompt preserves exchange suffixes (`.SH`, `.SZ`, `.SS`, `.HK`, `.T`, etc.).
  • Docker permission errors no longer block first-run write to `~/.tradingagents/`.
  • Config state no longer leaks between runs when sub-dicts are mutated.
  • `max_recur_limit` config actually applies to the propagator.
  • Missing-API-key error names the exact env var to set.
  • Quieter startup — suppressed the noisy upstream langgraph-checkpoint deprecation warning.

See CHANGELOG.md for the full per-item list with PR / issue references.
