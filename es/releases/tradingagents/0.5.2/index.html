Agentes comerciales v0.5.2

Analistas paralelos, ejecuciones desatendidas de CLI, informes que registran lo que los produjo, y las ejecuciones pasadas solo sirvieron lo que se sabía en su fecha.

Agregado

  • Analistas paralelos. Los analistas seleccionados se ejecutan al mismo tiempo, por lo que la fase de analista dura aproximadamente tanto como la más lenta; el CLI muestra el progreso y el tiempo de cada analista a medida que finaliza, y el debate comienza cuando se reciben todos los informes. (#1255, #433)
  • Ejecuciones CLI desatendidas. Los indicadores responden a las preguntas por ejecución y las variables TRADINGAGENTS_* el resto, por lo que un trabajo o script programado no pregunta nada: tradingagents --ticker NVDA --date 2026-09-26 --analysts market,news --save --no-show. Sin una terminal, una respuesta faltante detiene la ejecución antes de que comience y nombra qué configurar. (#1127, #1133)
  • Los informes registran lo que los produjo. Cada informe se abre con la fecha del análisis, la versión, el proveedor, los modelos, los analistas, las rondas y los proveedores de datos; el registro estatal los mantiene como run_settings. (#752, #1197)
  • Carpeta de datos Docker. TRADINGAGENTS_DATA_DIR mantiene los resultados, los informes y el registro de memoria en una carpeta host. (#865)
  • Un límite en las llamadas de herramientas de un analista. Después de las rondas max_tool_rounds (predeterminado 20, TRADINGAGENTS_MAX_TOOL_ROUNDS), el analista escribe su informe a partir de lo que tiene. (#1420)
  • tradingagents backtest muestra cada celda a medida que comienza y --run-id para continuar; --analysts acepta sentiment.
  • Benchmarks de Taiwán, Corea, Singapur y las principales bolsas europeas. (#1392)
  • Soporte Python 3.14; la imagen Docker ejecuta Python 3.13.

Modelos

  • deepseek-flash se trata como un modelo de pensamiento, por lo que la salida estructurada funciona. (#1388)

Actualización desde 0.5.1

  • Se requiere Python 3.11 o posterior; pandas 3 está instalado.
  • Versiones mínimas: yfinance 1.7.0, langchain-core 1.6.5, langchain-openai 1.6.6, langchain-anthropic 1.7.4, langchain-google-genai 4.4.0, langgraph 1.2.12, langgraph-checkpoint-sqlite 3.1.1, langchain-aws 1.7.9 (bedrock adicional).
  • Las declaraciones se envían por defecto a SEC EDGAR y luego a Yahoo (fundamental_data = "sec_edgar,yfinance").
  • Una ejecución con fecha pasada no recibe declaraciones de Yahoo o Alpha Vantage ni intercambios de información privilegiada, que no llevan fecha de presentación, y solo el nombre actual de la empresa, marcado como tal.
  • El registro de memoria es el paquete tradingagents.memory (antes tradingagents.decision_log); el asentamiento y la reflexión se trasladaron allí desde tradingagents.graph, y Reflector ya no se exporta desde tradingagents.graph.
  • Se elimina process_signal; la calificación es el segundo valor de propagate() o final_state["final_rating"].
  • Una calificación se lee únicamente desde su etiqueta Rating:; una decisión de texto libre sin uno es REVIEW.
  • Las funciones de capa de datos toman as_of_date= (antes curr_date=); build_instrument_context y resolve_instrument_context toman trade_date=.
  • VendorRateLimitError es VendorUnavailableError.
  • Las herramientas de datos toman el instrumento del estado de ejecución; Las llamadas a herramientas ya no llevan symbol o ticker.
  • Registro de estado: trader_investment_plan (antes trader_investment_decision), judge_decision eliminado, final_rating y run_settings agregados.
  • Los puntos de control de 0.5.1, o guardados con diferentes configuraciones, no se reanudan.

Fijo

  • Las herramientas de datos sirven al instrumento de ejecución, incluso cuando el modelo pasa por otro símbolo.
  • Una solicitud de proveedor fallida se informa como no disponible, no como un símbolo faltante o eliminado de la lista; La falta de datos de un proveedor ya no habla de una cadena en la que otro falló. (#1386)
  • La calificación es propia del Gestor de Cartera, no de sus cotizaciones de tesis (#1383); su línea mantiene una etiqueta en inglés en otros idiomas de salida (#1435).
  • Las celdas de backtest se ejecutan dos veces una vez (#1415) y la liquidación compara una decisión con su punto de referencia en las mismas fechas.
  • Una instantánea de un símbolo sin precios ya no finaliza la ejecución.
  • Las ejecuciones simultáneas ya no descartan entradas de registro de memoria.
  • Se sirven cifras trimestrales de SEC EDGAR presentadas sólo en lo que va del año, etiquetadas con su lapso.
  • El rendimiento de los dividendos de Yahoo y la relación deuda-capital se imprimen como porcentajes. (#1414)
  • La línea de cambio FRED nombra las fechas que abarca. (#1397)
  • stream_run ofrece la configuración propia del gráfico a sus herramientas.
  • El conjunto de pruebas permanece fuera de la red y de los archivos del usuario, y pasa en cualquier orden; pruebas de integración ejecutadas con -m integration. (#1395)

TradingAgents v0.5.2

Highlights

  • Parallel analysts & unattended CLI — Analysts fan out concurrently, so the phase costs roughly the slowest analyst instead of the sum, with per-analyst progress/time in the CLI and the debate gated on all reports being in (#1255, #433). For scheduling, flag answers plus TRADINGAGENTS_* env vars make runs fully non-interactive, and without a TTY a missing answer aborts before start and names the variable to set (#1127, #1133). Watch the new max_tool_rounds cap (default 20, TRADINGAGENTS_MAX_TOOL_ROUNDS): an analyst that hits it writes a report from partial data (#1420).

  • Reports become reproducible artifacts — Each report now opens with date, version, provider, models, analysts, rounds, and vendors, persisted in the state log as run_settings (#752, #1197). Pair this with TRADINGAGENTS_DATA_DIR, which pins results, reports, and the memory log to a host folder (#865) — the combination makes Docker runs auditable and gives you a clean way to diff two runs.

  • Breaking: runtime and dependency floors — Python 3.11+ is mandatory (3.14 added; Docker image moves to 3.13), pandas 3 is installed, and minimums jump across yfinance 1.7.0, langchain-core 1.6.5, langgraph 1.2.12, langgraph-checkpoint-sqlite 3.1.1, and the other langchain integrations. Plan a lockfile bump before upgrading.

  • Breaking: API and module renames — The memory log is now tradingagents.memory (was tradingagents.decision_log); settlement and reflection moved there from tradingagents.graph, and Reflector is no longer exported from it. process_signal is removed — use propagate()'s second value or final_state["final_rating"]. Ratings parse only from the Rating: label (free text becomes REVIEW), VendorRateLimitError becomes VendorUnavailableError, data-layer curr_date= becomes as_of_date=, and context builders now take trade_date=. Grep your call sites.

  • Breaking: point-in-time data and state schema — Past-dated runs intentionally drop Yahoo/Alpha Vantage statements and insider trades (no filing date) and label the company's current name as current; statements default to sec_edgar,yfinance. Data tools read the instrument from run state and ignore a model-supplied symbol. The state log renames trader_investment_decision → trader_investment_plan, drops judge_decision, and adds final_rating and run_settings. Most important: 0.5.1 checkpoints — and any checkpoint saved under different settings — will not resume, so expect to start fresh.

  • Correctness fixes that shift results — Vendor failures now surface as "unavailable" rather than missing/delisted symbols and one vendor's "no data" no longer masks another's failure (#1386); the rating is the PM's own output, not one its thesis quotes (#1383); duplicate backtest cells run once (#1415); and concurrent runs stop dropping memory entries. Treat backtest numbers from this release as a new baseline rather than directly comparable to 0.5.1.

Parallel analysts, unattended CLI runs, reports that record what produced them, and past runs served only what was known on their date.

Added

  • Parallel analysts. The selected analysts run at the same time, so the analyst phase takes about as long as the slowest one; the CLI shows each analyst's progress and time as it finishes, and the debate starts when all reports are in. (#1255, #433)
  • Unattended CLI runs. Flags answer the per-run questions, and TRADINGAGENTS_* variables the rest, so a scheduled job or script asks nothing: tradingagents --ticker NVDA --date 2026-09-26 --analysts market,news --save --no-show. Without a terminal, a missing answer stops the run before it starts and names what to set. (#1127, #1133)
  • Reports record what produced them. Each report opens with the analysis date, version, provider, models, analysts, rounds and data vendors; the state log keeps them as run_settings. (#752, #1197)
  • Docker data folder. TRADINGAGENTS_DATA_DIR keeps results, reports and the memory log in a host folder. (#865)
  • A cap on an analyst's tool calls. After max_tool_rounds rounds (default 20, TRADINGAGENTS_MAX_TOOL_ROUNDS) the analyst writes its report from what it has. (#1420)
  • tradingagents backtest shows each cell as it starts and the --run-id to continue; --analysts accepts sentiment.
  • Benchmarks for Taiwan, Korea, Singapore and the main European exchanges. (#1392)
  • Python 3.14 support; the Docker image runs Python 3.13.

Models

  • deepseek-flash is treated as a thinking model, so structured output works. (#1388)

Upgrading from 0.5.1

  • Python 3.11 or later is required; pandas 3 is installed.
  • Minimum versions: yfinance 1.7.0, langchain-core 1.6.5, langchain-openai 1.6.6, langchain-anthropic 1.7.4, langchain-google-genai 4.4.0, langgraph 1.2.12, langgraph-checkpoint-sqlite 3.1.1, langchain-aws 1.7.9 (bedrock extra).
  • Statements default to SEC EDGAR, then Yahoo (fundamental_data = "sec_edgar,yfinance").
  • A past-dated run gets no Yahoo or Alpha Vantage statements or insider trades, which carry no filing date, and only the company's current name, marked as such.
  • The memory log is the tradingagents.memory package (was tradingagents.decision_log); settlement and reflection moved there from tradingagents.graph, and Reflector is no longer exported from tradingagents.graph.
  • process_signal is removed; the rating is propagate()'s second value or final_state["final_rating"].
  • A rating is read only from its Rating: label; a free-text decision without one is REVIEW.
  • Data-layer functions take as_of_date= (was curr_date=); build_instrument_context and resolve_instrument_context take trade_date=.
  • VendorRateLimitError is VendorUnavailableError.
  • Data tools take the instrument from the run's state; tool calls no longer carry symbol or ticker.
  • State log: trader_investment_plan (was trader_investment_decision), judge_decision removed, final_rating and run_settings added.
  • Checkpoints from 0.5.1, or saved under different settings, are not resumed.

Fixed

  • Data tools serve the run's instrument, even when the model passes another symbol.
  • A failed vendor request is reported as unavailable, not as a missing or delisted symbol; one vendor's "no data" no longer speaks for a chain in which another failed. (#1386)
  • The rating is the Portfolio Manager's own, not one its thesis quotes (#1383); its line keeps an English label in other output languages (#1435).
  • Backtest cells given twice run once (#1415), and settlement compares a decision with its benchmark over the same dates.
  • A snapshot for a symbol with no prices no longer ends the run.
  • Concurrent runs no longer drop memory log entries.
  • SEC EDGAR quarterly figures filed only year to date are served, labelled with their span.
  • Yahoo dividend yield and debt-to-equity print as percentages. (#1414)
  • The FRED change line names the dates it spans. (#1397)
  • stream_run serves the graph's own config to its tools.
  • The test suite stays off the network and out of the user's files, and passes in any order; integration tests run with -m integration. (#1395)
