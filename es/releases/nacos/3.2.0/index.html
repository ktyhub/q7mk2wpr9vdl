#nacos 3.2.0 Nacos 3.2.0 es una versión importante centrada en la mejora de la arquitectura de complementos, la expansión del Registro AI, la modernización de API y mejoras en la calidad del código. Los aspectos más destacados incluyen:

  • AI Registry completa la "Tríada AI": Skill Registry y Prompt Registry se unen al MCP/Agent Registry existente, con integración de Nacos Copilot para una gestión asistida por IA.
  • Modernización de la arquitectura de complementos: gestión integral de complementos basada en SPI con interfaz de usuario de consola, sincronización en todo el clúster y mejoras de PostgreSQL
  • Limpieza de API: Se eliminó la compatibilidad con UDP PUSH heredado, /v1 y /v2 HTTP API extraídos a submódulos para su futura eliminación.
  • Seguridad y calidad del código: complemento de autenticación OIDC/OAuth2, múltiples correcciones de FindBugs, eliminación de códigos muertos y mejoras de compatibilidad con JDK 17+
  • Modernización de la consola: compatibilidad con interfaz de usuario dual para cambiar de consola nueva/heredada con una experiencia de usuario mejorada

⚠️ Cambios importantes y notas de migración

Cambios en el esquema de la base de datos (importantes)

Acción requerida: Esta versión presenta cambios significativos en el esquema de la base de datos con múltiples tablas nuevas agregadas para la administración de complementos, Registro AI (habilidad/solicitud) y capacidades de auditoría mejoradas. Antes de actualizar, debes aplicar el nuevo esquema:

  1. Haga una copia de seguridad de su base de datos existente
  2. Aplique el script de actualización del esquema: conf/schema.sql (para MySQL) o el script correspondiente para su tipo de base de datos.
  3. Reinicie el servidor Nacos después de la migración del esquema Si no se aplican los cambios de esquema, es posible que la administración de complementos, el Registro AI y otras funciones nuevas no funcionen correctamente.

Complemento adaptador heredado API

El complemento api-legacy-adapter y los /v1 y /v2 HTTP API heredados se eliminaron de esta versión para reducir el espacio ocupado. Si su implementación aún depende de los /v1 o /v2 API heredados, puede introducir manualmente el complemento de compatibilidad desde: https://github.com/nacos-group/nacos-api-legacy-adapter Descargue y coloque el complemento en su directorio plugins para restaurar la compatibilidad heredada de API.

Módulo de nombres: soporte UDP PUSH eliminado

El módulo de nombres ha eliminado la compatibilidad con UDP PUSH heredado y ha pasado a una arquitectura HTTP API más limpia. Clients que dependen de actualizaciones de descubrimiento de servicios basadas en UDP deben migrar a mecanismos basados ​​en HTTP.

📚 Novedades del Registro AI

Registro de habilidades

  • Gestión centralizada: cree, actualice y versione habilidades a través de la interfaz de usuario o API con changelog.
  • Composición de habilidades: encadene múltiples herramientas MCP en capacidades significativas para el negocio (por ejemplo, "user_onboarding" = verificar_email + create_profile + send_welcome_email)
  • Integración MCP: las habilidades declaran explícitamente dependencias en herramientas MCP registradas con validación de integridad
  • Organización basada en carpetas: las habilidades se muestran en una estructura de carpetas de varios niveles para una mejor organización
  • API aptos para agentes: REST/gRPC API para marcos de agentes (LangChain, CrewAI, etc.) para descubrir habilidades y suscribirse a ellas.
  • Soporte de carga: cargue paquetes de habilidades (formato zip, máximo 10 MB) con autenticación
  • Escaneo de seguridad: escáner de habilidades integrado para la validación de seguridad de habilidades de IA
  • Acceso a nivel de datos: visibilidad detallada y control de acceso (fases 2 y 3)

Registro rápido

  • Configuración de primera clase: almacena mensajes con metadatos (Id. de agente, Id. de modelo, versión, etiquetas) como artefactos de configuración versionados.
  • Administración de múltiples versiones: admite la administración paralela de múltiples versiones con plantilla y seguimiento de mensajes de confirmación
  • Suscripción basada en etiquetas: suscríbase a mensajes mediante etiquetas para obtener actualizaciones dinámicas
  • Depuración interactiva: pruebe y compare los resultados de los mensajes entre versiones directamente en la consola
  • AI Client Proxy: interfaz HTTP/gRPC client unificada para operaciones rápidas

Copiloto Nacos

  • Asistente impulsado por IA: asistente de IA integrado para ayudar a optimizar y crear indicaciones y habilidades
  • Descubrimiento inteligente: busque automáticamente habilidades existentes relevantes en el registro
  • Integración de consola: accesible directamente desde la consola de Nacos para un flujo de trabajo fluido

⚠️ Breaking Changes & Migration Notes

Database Schema Changes (Important)

Action Required: This release introduces significant database schema changes with multiple new tables added for plugin management, AI Registry (Skill/Prompt), and enhanced audit capabilities.

Before upgrading, you must apply the new schema:

  1. Backup your existing database
  2. Apply the schema upgrade script: conf/schema.sql (for MySQL) or corresponding script for your database type
  3. Restart Nacos server after schema migration

Failure to apply the schema changes may result in plugin management, AI Registry, and other new features not functioning correctly.

API Legacy Adapter Plugin

The api-legacy-adapter plugin and the legacy /v1 and /v2 HTTP APIs have been removed from this release to reduce footprint.

If your deployment still depends on the legacy /v1 or /v2 APIs, you can manually introduce the compatibility plugin from:

https://github.com/nacos-group/nacos-api-legacy-adapter

Please download and place the plugin into your plugins directory to restore legacy API compatibility.

Naming Module: UDP PUSH Support Removed

The naming module has removed legacy UDP PUSH support, moving to a cleaner HTTP API architecture. Clients relying on UDP-based service discovery updates must migrate to HTTP-based mechanisms.

📚 What's New in AI Registry

Skill Registry

  • Centralized Management: Create, update, and version skills via UI or API with changelogs
  • Skill Composition: Chain multiple MCP tools into business-meaningful capabilities (e.g., "user_onboarding" = verify_email + create_profile + send_welcome_email)
  • MCP Integration: Skills explicitly declare dependencies on registered MCP tools with integrity validation
  • Folder-based Organization: Skills displayed in multi-level folder structure for better organization
  • Agent-Friendly APIs: REST/gRPC APIs for agent frameworks (LangChain, CrewAI, etc.) to discover and subscribe to skills
  • Upload Support: Upload skill packages (zip format, max 10MB) with authentication
  • Security Scanning: Integrated skill-scanner for AI Skill security validation
  • Data Level Access: Fine-grained visibility and access control (Phase 2 & 3)

Prompt Registry

  • First-Class Configuration: Store prompts with metadata (agentId, modelId, version, tags) as versioned config artifacts
  • Multi-Version Management: Support parallel multi-version management with template and commit message tracking
  • Tag-Based Subscription: Subscribe to prompts by tags for dynamic updates
  • Interactive Debugging: Test and compare prompt outputs across versions directly in console
  • AI Client Proxy: Unified HTTP/gRPC client interface for prompt operations

Nacos Copilot

  • AI-Powered Assistant: Integrated AI assistant to help optimize and create Prompts and Skills
  • Intelligent Discovery: Automatically find relevant existing skills from the registry
  • Console Integration: Accessible directly from Nacos console for seamless workflow
