difusores v0.42.0

[!CONSEJO] Esta versión trae FLUX.3 Image Klein, Bria Fibo 2.0, Kandinsky 6, SANA-WM y RFD4-Proteína a los difusores, junto con nueva compatibilidad con adaptadores, integraciones de hardware y canalizaciones modulares. 🚨 Ahora se requiere Python 3.11 o más reciente.

FLUX.3 Imagen Klein

FLUX.3 Image Klein de Black Forest Labs admite la generación y edición de texto a imagen con una o más imágenes de referencia. Tanto los puntos de control básicos como los destilados por pasos están disponibles a través de ModularPipeline, con un muestreador rápido integrado que convierte solicitudes breves en subtítulos detallados y admite instrucciones de diseño con cuadros delimitadores. La integración también incluye carga de transformador de archivo único y puntos de control BFL FP8r y NVFP4.

Cargue la tubería con ModularPipeline.from_pretrained(...), luego cargue sus pesos con load_components(...). Consulte la documentación de FLUX.3 para obtener ejemplos y orientación sobre el muestreo rápido, la edición y el uso de la memoria.

Bria Fibo 2.0

Bria Fibo 2.0 admite la generación de imágenes a partir de subtítulos estructurados JSON y la edición con hasta cinco imágenes de referencia a través de BriaFibo2Pipeline. La integración incluye el punto de control de desarrollo y el punto de control de edición turbo, que se ejecuta en cuatro pasos sin guía sin clasificador. Consulte la [documentación de Fibo 2.0] (https://huggingface.co/docs/diffusers/main/en/api/pipelines/bria_fibo2) para conocer los formatos de aviso admitidos.

Se incluyen ejemplos de carga de LoRA y entrenamiento de DreamBooth LoRA para conversión de texto a imagen y edición de imágenes. Gracias a @muhammadali-afridi por la integración del modelo (#14991).

Kandinski 6

Kandinsky 6 genera vídeo con audio sincronizado a partir de texto o una imagen de referencia a través de Kandinsky6TI2VAPipeline. Un Kandinsky6SRPipeline independiente proporciona superresolución de vídeo. La integración admite puntos de control de generación Pro y Lite, incluidas variantes destiladas, e introduce PiflowScheduler para los modelos destilados. Consulte la documentación de Kandinsky 6 para conocer las configuraciones específicas de los puntos de control y los requisitos de superresolución. Gracias a @lefff por la integración del modelo (#14949).

##SANA-WM

SANA-WM genera video a partir de una imagen inicial, un mensaje de texto y la trayectoria de una cámara. Controle la cámara con poses explícitas o una cadena de acción WASD/IJKL y, opcionalmente, refine la salida con el refinador LTX-2 independiente. Consulte la documentación de SANA-WM para conocer el flujo de trabajo de dos etapas.

Gracias a @lawrence-cj por la integración (#13881).

RFD4-Proteína

RFD4-Proteína del Baker Lab y NVIDIA lleva el diseño biomolecular a los Difusores. Genera conjuntamente secuencias de proteínas y estructuras de todos los átomos mientras se acondiciona en el contexto molecular, como objetivos, motivos o ligandos de unión. La integración incluye la canalización, el transformador, el codificador automático, los programadores y la carga de LoRA. La preparación de entradas de modelo y la escritura de archivos CIF utilizan el paquete independiente rfd4-proteina-prep; ver la documentación RFD4-Proteína.

Gracias a @kierandidi por la integración (#15088).

Otros aspectos destacados

  • Qwen-Image 2.1: nuevas tuberías modulares y soporte para paralelismo tensorial. (#14976, #14865)
  • Más soporte de hardware: La integración de TorchTPU cubre ejecución ansiosa, torch.compile y paralelismo tensorial. El paralelismo tensorial también obtiene soporte para Intel XPU. (#14039, #15013)
  • Adaptadores LoKr: carga adaptadores de productos LyCORIS Kronecker para Z-Image y FLUX.2, incluido Klein. (#14163)
  • Control de movimiento LTX-2: motion_speed controla la base de tiempo posicional independientemente de la velocidad de fotogramas de reproducción. Utilice un adaptador compatible para velocidades alejadas de las predeterminadas, como el control de cámara lenta LoRA LTX-2.5. (#14967)
  • KVAE-Audio: AutoencoderKLKVAEAudio agrega codificación y decodificación para audio de 48 kHz. (#14384)
  • Almacenamiento en caché: MagCache ahora es compatible con FLUX.2. (#14756)
  • Correcciones del adaptador: Z-Image respeta la escala LoRA en joint_attention_kwargs, Qwen-Image aplica la escala .alpha a los puntos de control lora_A/lora_B y los codificadores de texto informan correctamente los adaptadores activos. (#15015, #15016, #14961)
  • Correcciones de canalización: conserva pasos de tiempo explícitos en FlowMatchEulerDiscreteScheduler, corrige las exportaciones del codificador de texto Anima y la eliminación de ruido del núcleo independiente, y conserva el retorno de tres valores de InpaintProcessor.preprocess cuando no se proporciona ninguna máscara. (#14956, #14943, #14481)

Depreciaciones y compatibilidad

  • La compatibilidad con Python 3.10 ya no existe. Actualice a Python 3.11 o una versión posterior antes de instalar esta versión. (#15030)
  • Salidas latentes modulares: FLUX, Krea 2 y LTX-Video ahora descomprimen las latentes en sus grupos principales de eliminación de ruido. Los flujos de trabajo personalizados deben pasar latentes desempaquetadas a sus bloques de decodificación. El respaldo para latentes empaquetadas está obsoleto para su eliminación en 0.47.0. (#14737)
  • Compatibilidad de hub: la gama huggingface_hub compatible ahora es >=1.32.0,<3.0. (#14863)
  • Importaciones de TorchAO: tener instalada una versión de TorchAO anterior a 0.15 ya no interrumpe las importaciones de modelos. La cuantización de TorchAO aún requiere la versión 0.15 o posterior. (#15095)

¡Gracias a todos los que contribuyeron a este lanzamiento!

diffusers v0.42.0

[!TIP] This release brings FLUX.3 Image Klein, Bria Fibo 2.0, Kandinsky 6, SANA-WM, and RFD4-Proteína to Diffusers, alongside new adapter support, hardware integrations, and modular pipelines. 🚨 Python 3.11 or newer is now required.

FLUX.3 Image Klein

FLUX.3 Image Klein from Black Forest Labs supports text-to-image generation and editing with one or more reference images. Both the base and step-distilled checkpoints are available through ModularPipeline, with an integrated prompt upsampler that turns short requests into detailed captions and supports layout instructions with bounding boxes. The integration also includes single-file transformer loading and BFL FP8r and NVFP4 checkpoints.

Load the pipeline with ModularPipeline.from_pretrained(...), then load its weights with load_components(...). See the FLUX.3 documentation for examples and guidance on prompt upsampling, editing, and memory use.

Bria Fibo 2.0

Bria Fibo 2.0 supports image generation from structured JSON captions and editing with up to five reference images through BriaFibo2Pipeline. The integration includes the dev checkpoint and the edit-turbo checkpoint, which runs in four steps without classifier-free guidance. See the Fibo 2.0 documentation for the supported prompt formats.

LoRA loading and DreamBooth LoRA training examples are included for text-to-image and image editing. Thanks to @muhammadali-afridi for the model integration (#14991).

Kandinsky 6

Kandinsky 6 generates video with synchronized audio from text or a reference image through Kandinsky6TI2VAPipeline. A separate Kandinsky6SRPipeline provides video super-resolution. The integration supports Pro and Lite generation checkpoints, including distilled variants, and introduces PiflowScheduler for the distilled models. See the Kandinsky 6 documentation for checkpoint-specific settings and super-resolution requirements. Thanks to @lefff for the model integration (#14949).

SANA-WM

SANA-WM generates video from a starting image, a text prompt, and a camera trajectory. Control the camera with explicit poses or a WASD/IJKL action string, then optionally refine the output with the separate LTX-2 refiner. See the SANA-WM documentation for the two-stage workflow.

Thanks to @lawrence-cj for the integration (#13881).

RFD4-Proteína

RFD4-Proteína from the Baker Lab and NVIDIA brings biomolecular design to Diffusers. It jointly generates protein sequences and all-atom structures while conditioning on molecular context such as binding targets, motifs, or ligands. The integration includes the pipeline, transformer, autoencoder, schedulers, and LoRA loading. Preparing model inputs and writing CIF files uses the separate rfd4-proteina-prep package; see the RFD4-Proteína documentation.

Thanks to @kierandidi for the integration (#15088).

Other highlights

  • Qwen-Image 2.1: new modular pipelines and tensor parallelism support. (#14976, #14865)
  • More hardware support: TorchTPU integration covers eager execution, torch.compile, and tensor parallelism. Tensor parallelism also gains Intel XPU support. (#14039, #15013)
  • LoKr adapters: load LyCORIS Kronecker-product adapters for Z-Image and FLUX.2, including Klein. (#14163)
  • LTX-2 motion control: motion_speed controls the positional time base independently of playback frame rate. Use a compatible adapter for speeds far from the default, such as the LTX-2.5 slow-motion control LoRA. (#14967)
  • KVAE-Audio: AutoencoderKLKVAEAudio adds encoding and decoding for 48 kHz audio. (#14384)
  • Caching: MagCache now supports FLUX.2. (#14756)
  • Adapter fixes: Z-Image honors the LoRA scale in joint_attention_kwargs, Qwen-Image applies .alpha scaling to lora_A/lora_B checkpoints, and text encoders correctly report active adapters. (#15015, #15016, #14961)
  • Pipeline fixes: preserve explicit timesteps in FlowMatchEulerDiscreteScheduler, fix Anima text encoder exports and standalone core denoising, and preserve the three-value return from InpaintProcessor.preprocess when no mask is supplied. (#14956, #14943, #14481)

Deprecations and compatibility

  • Python 3.10 support is dropped. Upgrade to Python 3.11 or newer before installing this release. (#15030)
  • Modular latent outputs: FLUX, Krea 2, and LTX-Video now unpack latents in their core denoise groups. Custom workflows should pass unpacked latents to their decode blocks. The fallback for packed latents is deprecated for removal in 0.47.0. (#14737)
  • Hub compatibility: the supported huggingface_hub range is now >=1.32.0,<3.0. (#14863)
  • TorchAO imports: having a TorchAO version older than 0.15 installed no longer breaks model imports. TorchAO quantization still requires version 0.15 or newer. (#15095)

Thanks to everyone who contributed to this release!
