Ganso v1.22.0 Release Note

Publicado: 29 de enero de 2026

✨ Nuevas funciones

  • Bifurcación de sesiones: bifurca sesiones existentes para crear nuevas ramas de conversación (#5882) por @wpfleger96
  • Navegación por chat plegable - La navegación por chat ahora es plegable para una interfaz de usuario más limpia (#6649) por @zanesq
  • Habilidad de documentación de Goose - Habilidad incorporada para hacer referencia a documentación de Goose (#6534) por @lifeizhou-ap
  • Soporte de suscripción de Codex - Se agregó soporte para suscripciones de Codex (#6600) por @michaelneale
  • Compatibilidad con editores externos - Utilice editores externos como vim, helix, etc. (#5823) por @peterwilli
  • Visor de diagnósticos - Nuevo visor de diagnósticos para depuración (#6770) por @DOsinga
  • Proveedor de IA de OVHcloud - Añadida IA de OVHcloud como nueva opción de proveedor (#6527) por @rbeuque74
  • Receta Max Turns - Agregue la configuración max_turns a recetas y subagentes (#6687) por @jhult
  • Extensiones de contenedor - Opción para ejecutar extensiones en un contenedor (#6590) por @jamadeo
  • Indicador de autenticación de proveedor personalizado - Indicador requires_auth para proveedores personalizados sin autenticación (#6705) por @rabi
  • AWS Bearer Token para Bedrock - Compatibilidad con la variable de entorno AWS_BEARER_TOKEN_BEDROCK (#6739) por @andreswebs
  • Encabezados personalizados antrópicos - Compatibilidad con encabezados personalizados con el proveedor Antrópico (#6774) por @DOsinga
  • Habilidades en modo de código - Las habilidades ahora están disponibles en modo de código (#6763) por @michaelneale
  • OSS Skills Marketplace - Nuevo mercado de habilidades de código abierto (#6752) por @EbonyLouis
  • Aplicaciones Vibe MCP - Nueva funcionalidad de aplicaciones MCP (#6569) por @DOsinga
  • Revisión de código PR - Funcionalidad de revisión de código (#6043) por @valeriikot

  • bucle de llavero de macOS - Se corrigió el bucle de aviso infinito para el llavero de macOS (#6620) por @sheikhlimon

  • Ancho de entrada del chat - Se corrigió el texto que aparece debajo de los botones de acción en ciertos anchos (#6751) por @zanesq

  • Esfuerzo de razonamiento del Codex - Conversión del esfuerzo de razonamiento corregida (#6523) por @fgsch
  • GCP Vertex AI Global Endpoint - Se corrigió el soporte de endpoint global para los modelos Gemini 3 (#6187) por @clouatre

  • Clave API de ElevenLabs - Se corrigió que la clave API no persistiera (#6557) por @Abhijay007
  • Lanzamiento Flatpak - Se corrigió el flujo de trabajo de lanzamiento que no encontraba el archivo Flatpak (#6696) por @The-Best-Codes
  • Ancho de la aplicación MCP - Respete el parámetro de ancho en las notificaciones de cambio de tamaño de la aplicación MCP (#6376) por @Abhijay007
  • Normalización de nombres de extensiones - Normaliza los nombres de extensiones de manera consistente en ExtensionManager (#6529) por @rabi
  • Salida de transmisión de Shell - Respete GOOSE_CLI_MIN_PRIORITY para la salida de transmisión de Shell (#6558) por @rabi
  • Esquema JSON de Google - Utilice los parámetros JsonSchema para obtener compatibilidad total con el esquema JSON (#6555) de @rabi
  • Problema de compilación - Problema de compilación de direcciones en principal (#6776) por @alexhancock
  • Números de línea de mensajes de error - Se eliminó el número de línea en los mensajes de error (#6736) por @lifeizhou-ap

Goose v1.22.0 Release Notes

✨ New Features

  • Goose Documentation Skill - Built-in skill for referencing goose documentation (#6534) by @lifeizhou-ap

  • Diagnostics Viewer - New diagnostics viewer for debugging (#6770) by @DOsinga

  • Container Extensions - Option to run extensions in a container (#6590) by @jamadeo
  • Custom Provider Auth Flag - requires_auth flag for custom providers without authentication (#6705) by @rabi
