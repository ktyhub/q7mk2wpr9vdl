6.10.0 (2026-11-20)

Highlights

  • Inspect and extract UEFI firmware volumes, files, and AMI NVRAM with three offline CLI and MCP tools. #12342. Thanks @bartman081523.
  • Inspect Android boot images and OTA payloads, NES 2.0 containers, and Maven, Gradle, and NuGet package metadata. a88c0a5 #9487 #11378 #10674 05be423 #10353 43b9fa8 #10351 #8144. Thanks @Davmunrey, @gensokyo-dev, @jayykernel, @mvanhorn.
  • Evidence revision 2 gives file, process, debugger, and browser observations explicit subject identities. See the migration details below.
  • The verified Ghidra 12.2 lane opens recognized DOS COM files and supports more RISC-V, MIPS32, and PowerPC64 ELF targets. #4811 #4487 #2362 #2338 #12517 #12085. Thanks @abhay-2108, @AurelioB, @Davmunrey, @kaoru0822-kitauji, @Rinkia.

Changes

  • JavaScript semantic indexing uses fixed object shapes for nested evaluation contexts to reduce allocation overhead. #9007. Thanks @mshzy.
  • Inspect ELF dynamic dependencies and required symbol versions, resolve separate debug-file linkage, inspect DWARF compilation units offline, and decode FDO packaging and dlopen notes. e9c72db #7868 54e3918 #9560 637e4cb #8523 #7237 #7235. Thanks @AniketR10, @gensokyo-dev, @mvanhorn.
  • Read cargo-auditable dependencies from WebAssembly and export Go and Rust dependency Evidence as CycloneDX. #5069 237b1ea #8445. Thanks @gensokyo-dev, @kaoru0822-kitauji, @mvanhorn, @yu0809.
  • Decode CPython 3.14 and 3.15 bytecode and use Kuna 1.1000. 1d08253 #10518 #12107. Thanks @abhisheksharma001, @gensokyo-dev, @N0zoM1z0.
  • Managed member inspection retains unresolved_definitions and summarizes unresolved definition coordinates. Native inspection surfaces prototype instruction conflicts, resolves RISC-V initializer pointers, and identifies which Mach-O slices a signature covers. #12462 #8161 #1244 #12109 #11620.
