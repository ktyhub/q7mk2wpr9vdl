#rea rea-agentes-6.8.0

6.8.0 (2026-10-25)

Destacados

  • Cree entornos de agentes locales a partir de capturas de red, escenarios de navegador o un mensaje, luego proporcione lecturas derivadas y escrituras basadas en evidencia y compárelas con capturas de aplicaciones nuevas.
  • Inspeccione más formatos enviados, incluidos objetos de código GPU, BEAM, código de bytes Python, metadatos Unity IL2CPP, Godot PCK, PyInstaller, Node.js SEA, árbol de dispositivos y tablas PE/ELF adicionales.
  • Mantenga enfocadas las investigaciones de gran tamaño con resúmenes retenidos, consultas de hechos seleccionados, límites de recuperación configurables y exportaciones CLI orientadas a filas. La evidencia completa permanece disponible.

6.8.0 (2026-10-25)

Highlights

  • Build local agent environments from network captures, browser scenarios, or a prompt, then serve derived reads and evidence-gated writes and compare them with fresh application captures.
  • Inspect more shipped formats, including GPU code objects, BEAM, Python bytecode, Unity IL2CPP metadata, Godot PCK, PyInstaller, Node.js SEA, devicetree, and additional PE/ELF tables.
  • Keep large investigations focused with retained summaries, selected fact queries, configurable recovery limits, and row-oriented CLI exports. Complete Evidence remains available.
