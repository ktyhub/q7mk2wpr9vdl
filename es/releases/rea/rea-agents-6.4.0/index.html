#rea rea-agentes-6.4.0

6.4.0 (2026-10-11)

Destacados

  • Android: inspección de dispositivos agregada, adquisición de APK dividido, registros, capturas de pantalla, transferencias de archivos y acciones explícitas del ciclo de vida de la aplicación a través de ADB, además de decodificación de cadenas localizadas y de manifiesto con Apktool. (#1552, #1556) Gracias @3QL.
  • JEB: explora unidades de proyecto y descompila elementos seleccionados a través de un servidor JEB MCP local iniciado por la persona que llama. (#1536) Gracias @3QL.
  • Análisis grandes: descubra evidencia retenida sin cargar cada carga útil e inspeccione gráficos, diseños binarios y expedientes de funciones de JavaScript a través de resúmenes y vistas seleccionadas. (#1682, #1568, #1570, #1345, #1507, #1247) Gracias @jhuang-tw, @kaoru0822-kitauji, @N0zoM1z0.
  • JavaScript: aísla el análisis de origen en un proceso propio con límites de tiempo de espera y almacenamiento dinámico configurables; retener hechos completos e incógnitas explícitas cuando el análisis se queda sin recursos. (#1651, #1563, #1565) Gracias @N0zoM1z0, @peter-research.
  • Ghidra: configura el lenguaje de importación/especificaciones del compilador y funciones semilla, código y etiquetas antes del análisis automático. (#1667) Gracias @sqmagellan.
  • Descubrimiento de RPC: reconoce llamadas tRPC admitidas, URL de enlace HTTP y operaciones GraphQL con nombre en aplicaciones y paquetes web JavaScript. (#1670) Gracias @pompiliodonatoapp.

Cambios

  • Se habilitaron set_address_name y set_addresses_names para sesiones de Ghidra con autoridad de mutación, incluidas etiquetas de datos que reconocen el espacio de nombres y resultados por lotes por dirección. (#1635, #1634) Gracias @giri256.
  • Se recuperaron patrones de tabla de salto relativos AArch64 firmados adicionales. (#1592) Gracias @RishTheFish21.
  • Se agregó inspección de recursos PE y análisis de metadatos NativeAOT de solo lectura para entradas x64 PE32+/.NET 8 RTR 9.1 compatibles. El flujo de trabajo Ghidra del host de Windows del analizador NativeAOT permanece sin verificar en un host de Windows real. (#1482, 76d8f68, #1254) Gracias @N0zoM1z0, @thangldw.
  • Se agregó la configuración de Pi, Hermes y Qwen Code, incluida la compatibilidad con el perfil activo de Hermes. (#1376, #1403, #1415, #1409) Gracias @rasatpetabit, @yiliang114, @zaydiscold.
  • Se agregó REA_MCP_INPUT_SCHEMA_PROFILE=compact para MCP clients con límite de tamaño como Kimi/Moonshot, al tiempo que se conserva la validación del tiempo de ejecución canónico. (#1514, #1580, #1484, #1581) Gracias @haythemsellami, @N0zoM1z0.
  • Se agregó el progreso de captura de procesos en vivo y finalization_ms opcional para capturar la salida del apagado antes de que aumente el tiempo de espera; la cancelación sigue siendo inmediata. (#1483, #1583, #1252, #1253, modelcontextprotocol/typescript-sdk#2997) Gracias @N0zoM1z0, @nikolay-dementiev, @sathariels.
  • Se mejoró la incorporación y recuperación del Codex de client, ​​PATH y bloqueadores de proveedores observados. (#1613) Gracias @N0zoM1z0.
  • Se redujo el JSON redirigido y el tamaño de salida del terminal, y se pospusieron las importaciones pesadas hasta que sus comandos las necesiten. (#1413, #1450, #1439, 21dbcf7) Gracias @kaoru0822-kitauji.

⚠ CAMBIOS ÚLTIMOS

  • Resultados de WebSocket: utilice network.websocket_connections en lugar de network.websocket_events. Las conexiones contienen request_id, url y events; permita payload_bytes: null cuando se desconozca el tamaño. No queda ningún alias heredado. (db4e360)
  • Recursos directos API: pasar un ArtifactResourceScope propiedad de la persona que llama al inventario/extracción, análisis de JavaScript, importaciones de referencia y exportaciones web; retenerlo durante la limpieza/apagado. Para readJavaScriptArtifactFiles, el alcance es el argumento tres y la señal de cancelación es el argumento cuatro. Mantenga el único propietario de limpieza de cada fuente de inventario raíz. Utilice propietarios de OwnedFileHandle, identificadores ASAR fd/read inyectados en lugar de createReadStream, valores VCS Result y el objeto de opciones de WebScriptExportError. Las entradas CLI/MCP para las operaciones con alcance no cambian. (ffe0574, 53e7fad, 684199b, be75ed5, be6272f, e0e49e9, 95a77b6)
  • Gráficos de referencia guardados: las exclusiones requieren que coincidan con pattern y distinguen project-ignored de default-ignored. Vuelva a importar los gráficos a los que les falta esa procedencia. (6585293)
  • Capturas de terminal: mantenga los buffers iniciales y redimensionados dentro de 1.000.000 de celdas usando columns × (rows + scrollback); Los escenarios de gran tamaño se rechazan antes del lanzamiento. (f9ea9a9)
  • Informes opcionales de verificación de agentes: acepte la versión 4 del esquema, anulables expectedFirstTool y targetClarificationPassed. Los contratos de producción CLI/MCP no cambian. (#1613)
  • Capturar comparaciones: recapture ambos lados con la semántica literal-replacements-v1 coincidente cuando se utilizan patrones de normalización personalizados. Las capturas de patrones heredadas no versionadas siguen siendo legibles, pero no se pueden comparar con capturas de patrones nuevos; las capturas sin patrones no se ven afectadas. (#1456, 2b6f14f) Gracias @Madhavan006, @N0zoM1z0.
  • Bordes del gráfico de artefactos: lee los ID de los artefactos secundarios y las rutas de la aparición seleccionada por occurrence_id, no los campos de borde child_artifact_id/logical_path. La evidencia del inventario anterior ya no se valida con el nuevo compromiso. (#1493) Gracias @kaoru0822-kitauji.
  • Esquema de gráfico semántico: los nodos y las relaciones ya no incluyen identifier_strategy y los ID de relación ya no lo codifican. La evidencia anterior ya no se valida con este esquema. (#1474) Gracias @kaoru0822-kitauji.
  • Identidades semánticas: seleccione ID del gráfico principal; lea nombres de eventos exactos de event_name, puntos finales de endpoint y valores literales de properties.value. Los nuevos análisis utilizan ID basadas en resúmenes para nombres de eventos y puntos finales largos/reservados y claves de función literales value-sha256, con etiquetas más cortas; Las etiquetas literales de cadena ahora dicen string literal. Los gráficos almacenados previamente conservan sus ID originales y siguen siendo entradas de flujo de trabajo válidas. (#1427, #1423, #1407) Gracias @N0zoM1z0.

rea rea-agents-6.4.0

6.4.0 (2026-10-11)

Highlights

  • Android: added device inspection, split-APK acquisition, logs, screenshots, file transfers and explicit app lifecycle actions through ADB, plus manifest and localized-string decoding with Apktool. (#1552, #1556) Thanks @3QL.
  • JEB: browse project units and decompile selected items through a caller-started local JEB MCP server. (#1536) Thanks @3QL.
  • Large analyses: discover retained Evidence without loading every payload, and inspect JavaScript graphs, binary layouts and function dossiers through summaries and selected views. (#1682, #1568, #1570, #1345, #1507, #1247) Thanks @jhuang-tw, @kaoru0822-kitauji, @N0zoM1z0.
  • JavaScript: isolate source analysis in an owned process with configurable heap and timeout limits; retain completed facts and explicit unknowns when analysis runs out of resources. (#1651, #1563, #1565) Thanks @N0zoM1z0, @peter-research.
  • Ghidra: configure import language/compiler specifications and seed functions, code and labels before auto-analysis. (#1667) Thanks @sqmagellan.
  • RPC discovery: recognize supported tRPC calls, HTTP-link URLs and named GraphQL operations in JavaScript applications and web bundles. (#1670) Thanks @pompiliodonatoapp.

Changes

  • Added Ghidra support for Windows PE DLLs and bounded MIPS ELF analysis, including carved MIPS inputs with incomplete section tables. Windows P0 remains read-only. (#1303, #1362, #1629, #1290, #718, #1619) Thanks @bqw371, @jaelliot, @kvalls, @N0zoM1z0.
  • Enabled set_address_name and set_addresses_names for Ghidra sessions with mutation authority, including namespace-aware data labels and per-address batch results. (#1635, #1634) Thanks @giri256.
  • Recovered additional signed AArch64 relative jump-table patterns. (#1592) Thanks @RishTheFish21.
  • Added PE resource inspection and read-only NativeAOT metadata parsing for supported x64 PE32+/.NET 8 RTR 9.1 inputs. The NativeAOT parser’s Windows-host Ghidra workflow remains unverified on a real Windows host. (#1482, 76d8f68, #1254) Thanks @N0zoM1z0, @thangldw.
  • Added Pi, Hermes and Qwen Code setup, including Hermes active-profile support. (#1376, #1403, #1415, #1409) Thanks @rasatpetabit, @yiliang114, @zaydiscold.
  • Added REA_MCP_INPUT_SCHEMA_PROFILE=compact for size-capped MCP clients such as Kimi/Moonshot, while retaining canonical runtime validation. (#1514, #1580, #1484, #1581) Thanks @haythemsellami, @N0zoM1z0.
  • Added live process-capture progress and optional finalization_ms to capture shutdown output before timeout escalation; cancellation remains immediate. (#1483, #1583, #1252, #1253, modelcontextprotocol/typescript-sdk#2997) Thanks @N0zoM1z0, @nikolay-dementiev, @sathariels.
  • Improved Codex onboarding and recovery from observed client, PATH and provider blockers. (#1613) Thanks @N0zoM1z0.
  • Reduced redirected JSON and terminal output size, and deferred heavy imports until their commands need them. (#1413, #1450, #1439, 21dbcf7) Thanks @kaoru0822-kitauji.

⚠ BREAKING CHANGES

  • WebSocket results: use network.websocket_connections instead of network.websocket_events. Connections contain request_id, url and events; allow payload_bytes: null when size is unknown. No legacy alias remains. (db4e360)
  • Direct resource APIs: pass a caller-owned ArtifactResourceScope to inventory/extraction, JavaScript analysis, reference imports and web exports; retain it through cleanup/shutdown. For readJavaScriptArtifactFiles, scope is argument three and abort signal is argument four. Keep each root inventory source’s single cleanup owner. Use OwnedFileHandle owners, injected ASAR fd/read handles instead of createReadStream, VCS Result values, and WebScriptExportError’s options object. CLI/MCP inputs for the scoped operations are unchanged. (ffe0574, 53e7fad, 684199b, be75ed5, be6272f, e0e49e9, 95a77b6)
  • Saved reference graphs: exclusions require their matching pattern and distinguish project-ignored from default-ignored. Re-import graphs missing that provenance. (6585293)
  • Terminal captures: keep initial and resized buffers within 1,000,000 cells using columns × (rows + scrollback); oversized scenarios are rejected before launch. (f9ea9a9)
  • Optional agent-verification reports: accept schema version 4, nullable expectedFirstTool and targetClarificationPassed. Production CLI/MCP contracts are unchanged. (#1613)
  • Capture comparisons: recapture both sides with matching literal-replacements-v1 semantics when custom normalization patterns are used. Legacy unversioned pattern captures remain readable but cannot be compared with new pattern captures; captures without patterns are unaffected. (#1456, 2b6f14f) Thanks @Madhavan006, @N0zoM1z0.
  • Artifact graph edges: read child artifact IDs and paths from the occurrence selected by occurrence_id, not edge fields child_artifact_id/logical_path. Earlier inventory Evidence no longer validates against the new commitment. (#1493) Thanks @kaoru0822-kitauji.
  • Semantic graph schema: nodes and relations no longer include identifier_strategy, and relation IDs no longer hash it. Earlier Evidence no longer validates against this schema. (#1474) Thanks @kaoru0822-kitauji.
  • Semantic identities: select IDs from the parent graph; read exact event names from event_name, endpoints from endpoint and literal values from properties.value. New analyses use digest-based IDs for long/reserved event and endpoint names and value-sha256 literal role keys, with shorter labels; string literal labels now read string literal. Previously stored graphs retain their original IDs and remain valid workflow inputs. (#1427, #1423, #1407) Thanks @N0zoM1z0.
