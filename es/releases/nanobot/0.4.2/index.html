nanobot v0.4.2

#nanobot v0.4.2

Cambios

  • Conéctese a través de SSH a puertas de enlace que también anuncian una URL pública de WebSocket. Usar la configuración SSH existente ahora es compatible con hosts de Windows donde Python 3 está disponible como python. El comando de emparejamiento rápido sigue siendo exclusivo de Linux; TLS nativo de puerta de enlace y trustedProxyAuth aún no son compatibles con SSH. #6682
  • Ver la actividad más reciente cuando un turno está colapsado y ver qué mensajes de seguimiento aún están esperando al agente. La reconexión también preserva el estado de los giros en marcha de manera más confiable. #6664, #6719, #6726, #6715
  • Encuentre herramientas, habilidades y plataformas de chat en un catálogo de Aplicaciones. Elija el esfuerzo de razonamiento para su próximo mensaje del compositor, sin cambiar el ajuste preestablecido compartido. #6700, #6441
  • Los mensajes largos que envíes pueden contraerse para que la conversación sea más fácil de analizar. Amplíelos con Mostrar más o copie el texto completo sin expandirlo. #6739
  • Alinee los controles del pie de página en la barra lateral de configuración y mantenga abierto el selector de modelo cuando lo vuelva a abrir rápidamente después de cambiar los ajustes preestablecidos. Corrección de la barra lateral de configuración, #6743
  • Dream puede organizar conocimientos detallados en una wiki de Markdown y mantener un breve resumen de la memoria en contexto. Los archivos de memoria existentes y las guías Dream personalizadas siguen siendo compatibles. #4477

Notas de actualización

  • Para una actualización manual, detenga nanobot, haga una copia de seguridad de su configuración y espacio de trabajo, y actualice la puerta de enlace utilizando el método de instalación original. Si utiliza una WebUI client independiente con una puerta de enlace remota, actualice ambas a la misma versión. Guía de actualización
  • Servidor API independiente: nanobot serve, sus puntos finales /v1 y el servicio nanobot-api Compose están retirados. Detenga el proceso o contenedor anterior antes de actualizar y conserve los volúmenes de datos. No existe ningún reemplazo HTTP directo. La puerta de enlace, WebUI, Python SDK y las conexiones del modelo saliente aún funcionan; Las conversaciones antiguas del API se pueden leer a través del Python SDK. #6614
  • Configuración del proveedor OpenAI: Si seleccionó explícitamente un API usando la configuración anterior apiType o api_type, guarde su configuración con v0.4.1 antes de actualizar o migre al campo api actual. Actualice las variables de entorno del iniciador antiguas por separado. El antiguo auto predeterminado no necesita ninguna acción. #6615
  • Sesión compartida global: unifiedSession y unified_session ahora se ignoran. Los datos de la sesión existente permanecen en su lugar; Los mensajes nuevos utilizan rutas de temas por chat o seleccionadas explícitamente. #6621
  • Esta versión admite la instalación manual. Las actualizaciones automáticas dentro de la aplicación no están habilitadas para ello.

original en inglés / English original

nanobot v0.4.2

Changes

  • Connect over SSH to gateways that also advertise a public WebSocket URL. Use existing SSH settings now supports Windows hosts where Python 3 is available as python. The quick-pairing command remains Linux-only; gateway-native TLS and trustedProxyAuth are still unsupported over SSH. #6682
  • See the latest activity when a turn is collapsed, and see which follow-up messages are still waiting for the agent. Reconnecting also preserves the state of running turns more reliably. #6664, #6719, #6726, #6715
  • Find Tools, Skills, and Chat Platforms in one Apps catalog. Choose the reasoning effort for your next message from the composer, without changing the shared preset. #6700, #6441
  • Long messages you send can collapse to keep the conversation easier to scan. Expand them with Show more, or copy the full text without expanding. #6739
  • Align the footer controls in the settings sidebar, and keep the model picker open when you reopen it quickly after switching presets. Settings sidebar fix, #6743
  • Dream can organize detailed knowledge in a Markdown wiki and keep a short memory summary in context. Existing memory files and custom Dream guides remain supported. #4477

Upgrade notes

  • For a manual update, stop nanobot, back up your configuration and workspace, and update the gateway using the original installation method. If you use a separate WebUI client with a remote gateway, update both to the same version. Update guide
  • Standalone API server: nanobot serve, its /v1 endpoints, and the nanobot-api Compose service are retired. Stop the old process or container before upgrading and keep the data volumes. There is no drop-in HTTP replacement. The gateway, WebUI, Python SDK, and outbound model connections still work; old API conversations can be read through the Python SDK. #6614
  • OpenAI provider settings: If you explicitly selected an API using the old apiType or api_type setting, save your configuration with v0.4.1 before upgrading, or migrate to the current api field. Update any old launcher environment variables separately. The old default auto needs no action. #6615
  • Global shared session: unifiedSession and unified_session are now ignored. Existing session data stays in place; new messages use per-chat or explicitly selected topic routes. #6621
  • This release supports manual installation. In-app automatic updates are not enabled for it.
