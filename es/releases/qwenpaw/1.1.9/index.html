QwenPaw v1.1.9

¿Qué ha cambiado?

✨ Agregado

Escritorio e IDE

  • Aplicación de escritorio Tauri 2.x: Nueva aplicación de escritorio nativa basada en Tauri para macOS y Windows (#3813)
  • Modo de codificación: nuevo IDE web con un diseño de tres paneles: árbol de archivos, editor con pestañas con revisión de diferencias en línea y un panel Git para ramificar, preparar y confirmar (#4578, #4671) Habilidades y proveedores
  • Skill Market: busque e instale habilidades de múltiples proveedores (Aliyun, ClawHub, ModelScope) a través de una nueva página de Skill Market con búsqueda entre proveedores (#4518, #4623)
  • Proveedor OpenCode Go: OpenCode y OpenCode Go ahora comparten un único proveedor con puntos finales API intercambiables (#4536, #4549)
  • Advertencia del navegador sin encabezado: los inicios del navegador sin encabezado ahora incluyen una advertencia con instrucciones para cambiar al modo con encabezado si aparecen páginas de verificación (#4603) Sistema de agentes
  • Tiempo de espera de tarea en segundo plano: submit_to_agent ahora acepta un parámetro task_timeout, también disponible a través del indicador CLI --task-timeout (#4547)
  • Contexto de bloqueo de archivos: los bloques de archivos en el contenido del mensaje ahora se procesan y cuentan con tokens junto con los bloques de imagen, audio y video (#4567)
  • Retroalimentación de denegación de Tool Guard: cuando un usuario rechaza una llamada de herramienta, el agente recibe instrucciones explícitas de no volver a intentarlo ni intentar alternativas (#4569)
  • Sesiones Cron aisladas: las tareas cron no compartidas ahora se ejecutan con un contexto limpio mientras el historial se acumula en una sesión unificada por tarea (#4602) Chat y consola
  • Descarga de archivos en el escritorio: Clicking tarjetas de archivos en el chat ahora funciona correctamente en la aplicación de escritorio pywebview (#4566)
  • Persistencia del borrador de entrada de chat: el texto de entrada de chat y la posición del cursor se guardan y restauran en la navegación de la página (#4598)
  • Resumen de memoria en el historial de chat: el historial de chat ahora incluye el resumen de memoria (#4658) Canales
  • Control de acceso unificado: sistema de lista blanca/lista negra/aprobación pendiente por canal con una interfaz de usuario de consola para administrar el acceso de los usuarios en todos los canales (#4565)
  • Tarjeta de aprobación de QQ Tool Guard: Tarjetas interactivas con botones de teclado para aprobar/denegar acciones en el canal QQ (#4667)

🔄 Cambiado

  • IU del Administrador de complementos: página del administrador de complementos rediseñada con descripciones compatibles con i18n, filtros de tipos, búsqueda de nombres y recarga automática después de la instalación/desinstalación (#4545, #4588)
  • Validación del contenido de habilidades: las habilidades importadas desde zip o guardadas a través del editor ahora se validan antes de ser aceptadas (#4591)
  • Actualización de la interfaz de usuario de la consola: diseño de navegación del encabezado actualizado y páginas de configuración de entornos y seguridad (#4654, #4657)

🐛 Fijo

Canales

  • Confiabilidad de los mensajes de WeChat: se agregó deduplicación basada en contenido para detectar duplicados en las encuestas; omitir envíos en context_token vencidos; informar fallas precisas para mensajes iniciados por API (#4576, #4597, #4618, #4627)
  • Nombres de archivos chinos de DingTalk: los nombres de archivos chinos codificados por porcentaje en los envíos de archivos ahora se decodifican correctamente (#4600)
  • Clave de webhook DM de DingTalk: las claves de la tienda de webhook DM ahora incluyen sender_id para evitar colisiones cuando diferentes conversaciones comparten el mismo sufijo conversation_id (#4665) Consola y interfaz de usuario
  • Enrutamiento de clave MCP Client: enrutamiento fijo para claves MCP client que contienen / (#4560)
  • QwenPaw Pet: Se corrigió la compatibilidad con Windows, la mascota se quedó atascada en el estado Listo en conversaciones consecutivas y se cambió el inicio automático predeterminado para optar por participar (#4564, #4626)
  • Visibilidad en modo oscuro: Se corrigió el encabezado invisible del panel del plano y la zona de colocación de importación de mascotas en modo oscuro (#4570, #4599)
  • Botón de voz Whisper: la página de chat ahora espera la verificación del proveedor de Whisper antes de mostrar el botón de voz, lo que evita un breve destello de voz en el navegador cuando Whisper está configurado (#4601) Proveedores y seguridad
  • Proxy Client IP: la lista blanca de omisión de autenticación ahora resuelve la IP real de client en lugar de usar la dirección del proxy (#4562)
  • Gemini max_tokens: el proveedor Gemini ahora asigna correctamente max_tokens a max_output_tokens (#4621)

🧪 Pruebas

  • Integration Test Suite: pruebas de integración refactorizadas y ampliadas con una cobertura más amplia (#4561)

QwenPaw v1.1.9

Highlights

  • Native desktop and coding workflow — The new Tauri 2.x app brings QwenPaw to macOS and Windows, while Coding Mode adds a three-panel Web IDE for browsing files, reviewing inline diffs, and performing Git operations without leaving the application (#3813, #4578).

  • Skill marketplace with validation — Cross-provider search and installation from Aliyun, ClawHub, and ModelScope expand the available skill ecosystem, but ZIP imports and editor-saved skills are now validated. Existing custom skills should be checked for compliance before upgrading (#4518, #4591).

  • Simplified provider configuration — OpenCode and OpenCode Go now use one provider with switchable endpoints, so review existing provider settings rather than maintaining duplicate configurations. The Gemini max_tokens → max_output_tokens mapping is also corrected, making token limits effective again (#4536, #4621).

  • More controllable agent execution — submit_to_agent and CLI --task-timeout let callers bound background work; file blocks now count toward context limits; denied tool calls explicitly stop retries; and non-shared cron jobs start with clean context while retaining unified history. These changes reduce runaway jobs, unexpected tool activity, and context contamination (#4547, #4567, #4569, #4602).

  • Channel access and delivery hardening — Unified whitelists, blacklists, and pending approval centralize access control, with QQ approval cards for interactive tool authorization. WeChat deduplication and expired-token handling improve delivery reliability, while DingTalk fixes address encoded filenames and colliding DM webhook keys. IP-based auth-bypass rules now evaluate the resolved client address instead of the proxy address (#4565, #4562, #4667).

  • Compatibility — No breaking changes were announced; desktop pet auto-start is now opt-in.

What's Changed

✨ Added

Desktop & IDE

  • Tauri 2.x Desktop App: New Tauri-based native desktop app for macOS and Windows (#3813)
  • Coding Mode: New Web IDE with a three-panel layout — file tree, tabbed editor with inline diff review, and a Git panel for branching, staging, and committing (#4578, #4671)

Skills & Providers

  • Skill Market: Browse and install skills from multiple providers (Aliyun, ClawHub, ModelScope) via a new Skill Market page with cross-provider search (#4518, #4623)
  • OpenCode Go Provider: OpenCode and OpenCode Go now share a single provider with switchable API endpoints (#4536, #4549)
  • Browser Headless Warning: Headless browser launches now include a warning with instructions to switch to headed mode if verification pages appear (#4603)

Agent System

  • Background Task Timeout: submit_to_agent now accepts a task_timeout parameter, also available via the CLI --task-timeout flag (#4547)
  • File Block Context: File blocks in message content are now processed and token-counted alongside image, audio, and video blocks (#4567)
  • Tool Guard Deny Feedback: When a user denies a tool call, the agent receives explicit instructions not to retry or attempt alternatives (#4569)
  • Isolated Cron Sessions: Non-shared cron jobs now execute with clean context while history accumulates in a unified per-job session (#4602)

Chat & Console

  • File Download on Desktop: Clicking file cards in chat now works correctly in the pywebview desktop app (#4566)
  • Chat Input Draft Persistence: Chat input text and cursor position are saved and restored across page navigation (#4598)
  • Memory Summary in Chat History: Chat history now includes the memory summary (#4658)

Channels

  • Unified Access Control: Per-channel whitelist / blacklist / pending-approval system with a console UI for managing user access across all channels (#4565)
  • QQ Tool Guard Approval Card: Interactive keyboard-button cards for approve / deny actions in QQ channel (#4667)

🔄 Changed

  • Plugin Manager UI: Redesigned plugin manager page with i18n-aware descriptions, kind filters, name search, and auto-reload after install / uninstall (#4545, #4588)
  • Skill Content Validation: Skills imported from zip or saved via the editor are now validated before being accepted (#4591)
  • Console UI Refresh: Updated header navigation layout and Environments & Security settings pages (#4654, #4657)

🐛 Fixed

Channels

  • WeChat Message Reliability: Added content-based dedup to catch duplicates across polls; skip sends on expired context_token; report accurate failures for API-initiated messages (#4576, #4597, #4618, #4627)
  • DingTalk Chinese Filenames: Percent-encoded Chinese filenames in file sends are now decoded correctly (#4600)
  • DingTalk DM Webhook Key: DM webhook store keys now include sender_id to prevent collision when different conversations share the same conversation_id suffix (#4665)

Console & UI

  • MCP Client Key Routing: Fixed routing for MCP client keys containing / (#4560)
  • QwenPaw Pet: Fixed Windows compatibility, pet stuck in Done state on consecutive conversations, and changed auto-start default to opt-in (#4564, #4626)
  • Dark Mode Visibility: Fixed invisible plan panel header and pet import drop zone in dark mode (#4570, #4599)
  • Whisper Speech Button: Chat page now waits for the Whisper provider check before showing the speech button, preventing a brief flash of browser speech when Whisper is configured (#4601)

Providers & Security

  • Proxy Client IP: Auth bypass whitelist now resolves the real client IP instead of using the proxy's address (#4562)
  • Gemini max_tokens: The Gemini provider now correctly maps max_tokens to max_output_tokens (#4621)

🧪 Testing

  • Integration Test Suite: Refactored and expanded integration tests with broader coverage (#4561)
