QwenPaw v1.1.6

✨ Agregado

Sistema de agentes

  • Diagnóstico de Windows: qwenpaw doctor ahora comprueba problemas del entorno específicos de Windows, incluida la compatibilidad con rutas largas, el modo de idioma PowerShell y la longitud de la ruta del directorio de trabajo (#4032)
  • Estado del agente API: Nuevo estado de tiempo de ejecución del agente de informes de terminal GET /agents/{agentId}/agent-status, recuento de tareas en ejecución y marcas de tiempo de las tareas (#4107)
  • Aislamiento de sesión cron: las tareas cron ahora admiten una opción share_session: cuando está deshabilitada, cada ejecución programada crea un contexto de sesión aislado con un ID de tarea cron (#4117)
  • Complemento GPT Image 2: Nuevo complemento de herramienta para generar imágenes a través de GPT Image 2 API de OpenAI (#3911)
  • Nombre del agente basado en configuración: use el nombre del perfil del agente configurado en lugar de un valor predeterminado codificado (#4140) Chat y consola
  • Entrada de voz Whisper: Se reemplazó Web Speech nativo del navegador API con transcripción Whisper del lado del servidor para una entrada de voz más confiable en todos los navegadores (#3574)
  • Títulos de sesiones generados por el LLM: las sesiones de chat ahora las titula automáticamente el LLM en segundo plano después del primer mensaje. Configurable mediante la opción "Generar títulos de sesión automáticamente" en Configuración del agente (#3829)
  • Tendencias de uso de tokens: se agregaron gráficos de líneas de tendencia por modelo y por tipo de token a la página de configuración de uso de tokens para visualizar el uso a lo largo del tiempo (#4080, #4094)
  • Operaciones de habilidades por lotes: se agregaron botones Activar y Desactivar a la barra de herramientas de operaciones por lotes de habilidades con informes de errores por habilidad (#4091)
  • Representación de diagramas de sirena: los bloques de código Markdown con la etiqueta de idioma mermaid ahora se representan como diagramas interactivos en el chat y en las vistas previas de archivos (#4146)
  • Portugués brasileño (pt-BR): se agregó compatibilidad total con la configuración regional pt-BR para la interfaz de usuario de la consola y la configuración de idioma del backend (#4009, #4143) Proveedores
  • Proveedor de Volcano Engine: se agregó Volcano Engine como proveedor integrado compatible con OpenAI con puntos finales estándar y del plan de codificación (#3994)
  • Selección de región de DashScope: la URL base de DashScope ahora se puede modificar desde puntos finales de región preestablecidos (#4074)
  • Proveedor del plan de token Aliyun: se agregó el plan de token Aliyun como proveedor integrado (#4122)
  • Tokens máximos predeterminados de Anthropic: se aumentó el max_tokens predeterminado para los modelos compatibles con Anthropic a 16,384 (#4054) Canales
  • Tarjetas de aprobación interactivas de Feishu: las solicitudes de aprobación de protección de herramientas en Feishu ahora se representan como tarjetas de botones interactivas que se actualizan en el lugar al aprobar/rechazar, con una sugerencia de enlace de documentación cuando la devolución de llamada de acción de la tarjeta no está suscrita (#3941, #3982)
  • Compartir sesión grupal de WeCom: se agregó la opción share_session_in_group para controlar si los miembros del chat grupal comparten una sola sesión u obtienen aislamiento por miembro (#3948)
  • Contexto del remitente Feishu: el apodo del remitente Feishu ahora se pasa al contexto del entorno del agente (#4098)
  • Tarjetas de aprobación interactivas de WeCom: las solicitudes de aprobación de protección de herramientas en WeCom ahora se representan como tarjetas de plantilla interactivas (#4112) Seguridad
  • Protección transversal de rutas de archivos estáticos: el servicio de archivos estáticos de la consola ahora rechaza rutas absolutas para evitar la omisión de cruce de rutas (#3973)
  • Denegación automática a nivel de regla: ahora se pueden configurar reglas de seguridad individuales para denegar automáticamente las llamadas a herramientas (#4046) Habilidades y CLI
  • Prueba de habilidades CLI: nuevo comando qwenpaw skills test para validar el contenido de las habilidades y ejecutar análisis de seguridad (#3999)
  • Instalación/desinstalación de habilidades CLI: nuevos comandos qwenpaw skills install y qwenpaw skills uninstall para administrar habilidades desde la línea de comandos, admitiendo instalaciones de espacio de trabajo por agente y a nivel de grupo (#4053)

⚡ Rendimiento

  • Representación de consola: se eliminaron reproducciones duplicadas al estabilizar las comparaciones de estados de sondeo de aprobación y memorizar las opciones de tiempo de ejecución del chat (#4052, #4110, #4153)
  • Navegación del historial de chat: omita la búsqueda del historial de chat para teclas que no sean de flecha y almacene en caché las listas de mensajes de usuario para evitar exploraciones repetidas en cada pulsación de tecla (#4130)
  • Limpieza de sondeo QR: detenga inmediatamente el sondeo de códigos QR y borre los indicadores de estado al completar la autenticación o expirar el código (#4148)

🐛 Fijo

Canales

  • WeCom Stream Keepalive: mantenga activo el flujo de marcador de posición "Pensando..." con actualizaciones periódicas para evitar indicadores de estado bloqueados en WeCom (#3950)
  • WeCom Reconnect Race: Se corrigió la programación de doble reconexión y la desconexión de bucle entre eventos en el manejo de WeCom WebSocket (#3963)
  • Reintento de red de Telegram: se agregó un retroceso exponencial y una reconexión controlada para errores transitorios de la red de Telegram en lugar de morir silenciosamente (#4039)
  • WeChat Cron Buffer Flush: Vacíe el búfer de combinación de WeChat inmediatamente para envíos cron/proactivos que omiten la ruta de finalización normal (#4106)
  • División de tablas de rebajas: preserva la estructura de la tabla de rebajas en los fragmentos de mensajes repitiendo las filas de encabezado y separador en cada fragmento (#4119) Sistema de agentes
  • Tiempo de espera del agente externo: Se agregó un tiempo de espera predeterminado seguro (60 s) para delegate_external_agent para evitar bloqueos indefinidos (#3928)
  • Recarga de configuración del agente: los cambios en el archivo de configuración del agente ahora activan una recarga elegante con drenaje de tareas en lugar de una reinstalación ligera (#4064)
  • Persistencia de la configuración del agente: se corrigió que el editor de configuración del agente de la consola eliminara las configuraciones anidadas al guardar, preservando la estructura de configuración completa (#4157) MCP
  • Tiempo de espera de ejecución de MCP: use sse_read_timeout como tiempo de espera de ejecución de la herramienta MCP en lugar del tiempo de espera de conexión HTTP más corto (#4058, #4061)
  • Fuga del ciclo de vida de MCP Client: Se corrigió una fuga de tarea de ciclo de vida donde close() podía omitir la detención de una tarea de reconexión en segundo plano (#4152) Consola y interfaz de usuario
  • Seguridad del sustituto de SSE: evite la falla de la transmisión de SSE en texto sustituto con formato incorrecto desinfectando el contenido no codificable antes de la serialización (#3553)
  • Ajuste de línea CodeMirror: ajuste de línea fijo en bloques de entrada/salida de llamada de herramienta (#3960)
  • Nombre para mostrar del agente predeterminado: respete el nombre personalizado para el agente predeterminado en todas las superficies de la interfaz de usuario (#4073)
  • Rutas de vista previa de archivos: Se corrigió la eliminación de prefijos de URL redundantes en las rutas de vista previa de archivos que podrían causar URL rotas (#4089) Infraestructura
  • Restauración de copia de seguridad Docker: restaure correctamente los secretos en los puntos de montaje del volumen Docker intercambiando el contenido del directorio en lugar de cambiar el nombre (#3916)
  • Rutas de bloqueo de audio: devuelve la ruta del sistema de archivos resuelta para los bloques de audio URL file:// y elimina el código de manejo de archivos redundante (#4021, #4048)
  • Rotación de registros: use RotatingFileHandler para la rotación de registros en todas las plataformas (#4076)
  • Omisión de proxy de bucle invertido: omita las variables de entorno del proxy para las comprobaciones de estado del bucle invertido API para evitar fallas de conexión detrás de los servidores proxy corporativos (#4092)
  • Conda Packaging: restaure las herramientas de empaquetado de Conda antes de ejecutar conda-pack para evitar roturas en el proceso de empaquetado (#4093)

📝 Documentación

  • Preguntas frecuentes sobre el tiempo de espera de WSL2: se agregó una entrada de preguntas frecuentes para manejar APITimeoutError cuando se ejecuta en modo WSL2 NAT (#4005)
  • Actualización de documentación: documentación del sitio web actualizada para reflejar nuevas funciones (#4013)

🧪 Pruebas y CI

  • Pruebas unitarias de consola: se agregó la configuración de Vitest con pruebas unitarias y de componentes que cubren Chat, capa API y componentes compartidos (#3559, #4121)
  • Pruebas de humo de integración: Se agregaron pruebas de humo de variables de entorno y configuración y inicio de la aplicación (#4081)

QwenPaw v1.1.6

Highlights

  • Agent observability & config lifecycle — GET /agents/{agentId}/agent-status (#4107) exposes runtime status, running-task count, and task timestamps, giving orchestration and health checks a first-class probe instead of log scraping. Config edits now trigger a graceful reload with task draining (#4064) rather than lightweight reinstantiation, and the console editor stops dropping nested settings on save (#4157). Watch: config changes take effect only after in-flight tasks drain, so expect a delay under load.
  • Session isolation controls — Cron jobs gain a share_session toggle (#4117); when disabled, each scheduled run gets an isolated session keyed by cron job ID. WeCom adds share_session_in_group (#3948) to choose between one shared group session and per-member isolation. This is a real multi-tenant correctness lever — if you relied on continuity across scheduled runs or group members, review these flags after upgrading.
  • Voice input moves server-side — Browser-native Web Speech API is replaced by server-side Whisper transcription (#3574). Expect consistent, more reliable behavior across browsers, but audio now leaves the client: budget for transcription latency/cost and check your deployment's privacy posture. Integrations that assumed client-side speech-recognition semantics need revisiting.
  • First-class Skills CLI — New qwenpaw skills test (#3999) validates skill content and runs security scans, while skills install/uninstall (#4053) manage skills at both pool and per-agent workspace scopes. Skills are now scriptable and CI-friendly — worth wiring skills test into your skill development pipeline.
  • More providers, higher Anthropic default — Volcano Engine (#3994) and Aliyun Token Plan (#4122) arrive as built-in OpenAI-compatible providers, and DashScope's base URL is now region-selectable (#4074). Note that Anthropic-compatible models now default to max_tokens 16,384 (#4054): if you depended on the old default, expect larger outputs and higher token spend, so set an explicit cap.
  • Operational hardening — MCP tool execution now uses sse_read_timeout instead of the short HTTP connect timeout (#4058, #4061), so long-running tools stop being cut off; delegate_external_agent gets a 60s default timeout (#3928), Telegram gains exponential backoff (#4039), and MCP close() no longer leaks its reconnect task (#4152). Security-wise, static file serving rejects absolute paths (#3973) and individual rules can auto-deny tool calls (#4046). Watch the 60s delegate default — genuinely long external-agent tasks may need an explicit override.

No breaking changes were reported in this release.

✨ Added

Agent System

  • Windows Diagnostics: qwenpaw doctor now checks Windows-specific environment issues including long path support, PowerShell language mode, and working directory path length (#4032)
  • Agent Status API: New GET /agents/{agentId}/agent-status endpoint reporting agent runtime status, running task count, and task timestamps (#4107)
  • Cron Session Isolation: Cron jobs now support a share_session option — when disabled, each scheduled run creates an isolated session context with a cron job ID (#4117)
  • GPT Image 2 Plugin: New tool plugin for generating images via OpenAI's GPT Image 2 API (#3911)
  • Config-Driven Agent Name: Use the configured agent profile name instead of a hardcoded default (#4140)

Chat & Console

  • Whisper Voice Input: Replaced browser-native Web Speech API with server-side Whisper transcription for more reliable, cross-browser voice input (#3574)
  • LLM-Generated Session Titles: Chat sessions are now automatically titled by the LLM in the background after the first message. Configurable via the "Auto-generate session titles" toggle in Agent Config (#3829)
  • Token Usage Trends: Added per-model and per-token-type trend line charts to the Token Usage settings page for visualizing usage over time (#4080, #4094)
  • Batch Skill Operations: Added Enable and Disable buttons to the skill batch operation toolbar with per-skill error reporting (#4091)
  • Mermaid Diagram Rendering: Markdown code blocks with mermaid language tag are now rendered as interactive diagrams in chat and file previews (#4146)
  • Brazilian Portuguese (pt-BR): Added full pt-BR locale support for both the Console UI and backend language settings (#4009, #4143)

Providers

  • Volcano Engine Provider: Added Volcano Engine as a built-in OpenAI-compatible provider with standard and Coding Plan endpoints (#3994)
  • DashScope Region Selection: DashScope base URL can now be modified from preset region endpoints (#4074)
  • Aliyun Token Plan Provider: Added Aliyun Token Plan as a built-in provider (#4122)
  • Anthropic Default Max Tokens: Raised default max_tokens for Anthropic-compatible models to 16,384 (#4054)

Channels

  • Feishu Interactive Approval Cards: Tool-guard approval requests in Feishu are now rendered as interactive button cards that update in-place on approve/deny, with a documentation link hint when the card action callback is not subscribed (#3941, #3982)
  • WeCom Group Session Sharing: Added share_session_in_group toggle to control whether group chat members share a single session or get per-member isolation (#3948)
  • Feishu Sender Context: Feishu sender nickname is now passed to the agent environment context (#4098)
  • WeCom Interactive Approval Cards: Tool-guard approval requests in WeCom are now rendered as interactive template cards (#4112)

Security

  • Static File Path Traversal Protection: Console static file serving now rejects absolute paths to prevent path traversal bypass (#3973)
  • Rule-Level Auto Deny: Individual security rules can now be configured to automatically deny tool calls (#4046)

Skills & CLI

  • Skill Test CLI: New qwenpaw skills test command to validate skill content and run security scans (#3999)
  • Skill Install/Uninstall CLI: New qwenpaw skills install and qwenpaw skills uninstall commands for managing skills from the command line, supporting both pool-level and per-agent workspace installs (#4053)

⚡ Performance

  • Console Rendering: Eliminated duplicate re-renders by stabilizing approval polling state comparisons and memoizing chat runtime options (#4052, #4110, #4153)
  • Chat History Navigation: Skip chat history lookup for non-arrow keys and cache user-message lists to avoid repeated scans on every keystroke (#4130)
  • QR Polling Cleanup: Immediately stop QR code polling and clear status indicators on auth completion or code expiry (#4148)

🐛 Fixed

Channels

  • WeCom Stream Keepalive: Keep the "Thinking..." placeholder stream alive with periodic refreshes to prevent stuck status indicators in WeCom (#3950)
  • WeCom Reconnect Race: Fixed double reconnect scheduling and cross-event-loop disconnect in WeCom WebSocket handling (#3963)
  • Telegram Network Retry: Added exponential backoff and controlled reconnect for transient Telegram network errors instead of silently dying (#4039)
  • WeChat Cron Buffer Flush: Flush WeChat merge buffer immediately for cron/proactive sends that bypass the normal completion path (#4106)
  • Markdown Table Splitting: Preserve markdown table structure across message chunks by repeating header and separator rows in each fragment (#4119)

Agent System

  • External Agent Timeout: Added safe default timeout (60s) for delegate_external_agent to prevent indefinite hangs (#3928)
  • Agent Config Reload: Agent config file changes now trigger a graceful reload with task draining instead of lightweight reinstantiation (#4064)
  • Agent Config Persistence: Fixed the console agent config editor dropping nested settings on save by preserving the complete config structure (#4157)

MCP

  • MCP Execution Timeout: Use sse_read_timeout as the MCP tool execution timeout instead of the shorter HTTP connect timeout (#4058, #4061)
  • MCP Client Lifecycle Leak: Fixed lifecycle-task leak where close() could skip stopping a background reconnect task (#4152)

Console & UI

  • SSE Surrogate Safety: Avoid SSE stream crash on malformed surrogate text by sanitizing non-encodable content before serialization (#3553)
  • CodeMirror Line Wrapping: Fixed line wrapping in tool call input/output blocks (#3960)
  • Default Agent Display Name: Respect custom name for the default agent in all UI surfaces (#4073)
  • File Preview Paths: Fixed redundant URL prefix stripping in file preview paths that could cause broken URLs (#4089)

Infrastructure

  • Docker Backup Restore: Correctly restore secrets on Docker volume mount points by swapping directory contents instead of renaming (#3916)
  • Audio Block Paths: Return resolved filesystem path for file:// URL audio blocks and remove redundant file handling code (#4021, #4048)
  • Log Rotation: Use RotatingFileHandler for log rotation on all platforms (#4076)
  • Loopback Proxy Bypass: Bypass proxy environment variables for loopback API health checks to prevent connection failures behind corporate proxies (#4092)
  • Conda Packaging: Restore conda packaging tools before running conda-pack to prevent broken packaging pipeline (#4093)

📝 Documentation

  • WSL2 Timeout FAQ: Added FAQ entry for handling APITimeoutError when running in WSL2 NAT mode (#4005)
  • Documentation Update: Updated website documentation to reflect new features (#4013)

🧪 Testing & CI

  • Console Unit Tests: Added Vitest setup with unit and component tests covering Chat, API layer, and shared components (#3559, #4121)
  • Integration Smoke Tests: Added app startup and settings/environment variable smoke tests (#4081)
