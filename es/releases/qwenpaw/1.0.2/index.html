QwenPaw v1.0.2

✨ Agregado

Núcleo

  • Complementos: instale extensiones desde la carpeta plugins/ de su espacio de trabajo (#3101, #3131, #3132).
  • copaw task: Ejecute trabajos únicos desde el terminal sin servidor web (#3031).
  • /model en el chat: cambie de modelo, enumere lo que está disponible, restablezca los valores predeterminados e inspeccione un modelo, sin abrir Configuración (#3133). Modelos y proveedores
  • SiliconFlow: puntos finales internacionales y de China listos para usar para API compatible con OpenAI de SiliconFlow (#2886).
  • CoPaw Local: modelos con capacidad de imagen y video, configuraciones más ricas en la consola y descargas y detección de capacidad más confiables en Windows (#3021, #3087, #3140). Seguridad
  • Secretos guardados más seguros: las claves API y valores similares están cifrados en el disco; siempre que sea posible, la clave de cifrado permanece en el llavero del sistema operativo (#3025). Consola y UI
  • Historial de entrada de chat: explora líneas de usuario anteriores con las teclas de flecha (#2466).
  • Búsqueda de chat: busca el texto del mensaje entre sesiones (#2842).
  • Sesiones fijadas: Fija los hilos para que permanezcan en la parte superior de la lista (#3137).
  • Chat por agente: restaura el último chat abierto cuando cambias de agente (#3155).
  • Pulido visual: íconos para herramientas integradas y logotipos de proveedores junto a los modelos (#3061, #3130). Habilidades y herramientas
  • Comandos de habilidad: /skills muestra lo que está habilitado para el canal; escriba /<skill name> para abrir una habilidad o ejecutarla con su mensaje (#3150).
  • Etiquetas para habilidades del grupo: Organiza el grupo compartido con etiquetas (#2837, #3069).
  • Descubrimiento de herramientas MCP: consulte cada servidor MCP conectado para conocer los nombres, descripciones y parámetros de sus herramientas a través de HTTP API (#3149). Canales
  • QQ: envíe archivos y medios enriquecidos de manera consistente en todos los tipos de mensajes (#3012).
  • WeCom: los mensajes entrantes mantienen el contexto de cita/respuesta para que el agente vea a qué se hizo referencia (#3024).

🔄 Cambiado

  • Selector de zona horaria: los nombres de las regiones siguen el idioma de la interfaz de usuario seleccionado (#2497).
  • Tamaños de archivo: tamaños legibles por humanos en toda la consola (#2808).
  • Inicio de la consola: las páginas de configuración más pesadas se cargan según demanda, por lo que la primera pantalla se abre más rápido (#3122).
  • Listas de habilidades grandes: desplazamiento e interacción más suaves cuando tienes muchas habilidades en grupo (#3141, #3158).
  • Pruebas de conexión del proveedor: los mensajes de estado aparecen en su idioma (#2913).
  • Código de error: códigos de error más consistentes en todos los canales, API y CLI (#3110).

  • Discord: Las respuestas largas del asistente ya no rompen los bloques de código Markdown a mitad de camino (#2976).
  • Feishu: La reconexión y ejecución de varios agentes ya no provoca bloqueos compartidos o bucles de eventos mezclados (#3095, #3145). Herramientas y habilidades
  • MCP: cerrar o volver a conectar clients después de la recarga ya no provoca un uso descontrolado de la CPU (#3106).
  • Automatización del navegador: Clicking elementos cuando existen duplicados apunta al correcto; los documentos explican los selectores más claramente (#3023).
  • Herramienta Shell: los comandos con texto entre comillas mantienen intactos los saltos de línea (#3070).
  • Habilidades: los metadatos de habilidades corruptos o que no son objetos ya no bloquean el análisis de requisitos (#3072).

QwenPaw v1.0.2

Highlights

  • Security and channel access — API keys and similar saved secrets are now encrypted on disk, using the OS keychain where possible, and iMessage private chats now honor DM policies and allowlists (#3025, #2491). Users storing credentials or exposing iMessage bots should upgrade; migration behavior for existing plaintext secrets is not documented, so confirm they remain accessible afterward.
  • Headless workflows and extensibility — copaw task runs one-off terminal jobs without a web server, workspace plugins/ folders install extensions, and /model plus /skills / /<skill name> bring common controls into chat (#3031, #3131, #3132, #3133, #3150). MCP tools can also be discovered over the HTTP API with their names, descriptions, and parameters (#3149). CLI, plugin, and MCP-heavy users have concrete reasons to upgrade.
  • Model providers and local inference — SiliconFlow gains ready-to-use China and International endpoints, while CoPaw Local adds image/video-capable models, richer console settings, and more reliable Windows downloads and capability detection (#2886, #3021, #3087, #3140). Upgrade if you use these providers or run local models on Windows; otherwise this alone may not justify updating.
  • Reliability fixes — Feishu reconnects and multi-agent operation avoid shared-lock and event-loop failures, Discord long replies preserve Markdown fences, and MCP clients no longer cause runaway CPU after reload or reconnect (#3095, #3145, #2976, #3106). Fixes for duplicate browser elements, quoted shell line breaks, and malformed skill metadata also remove realistic failure modes (#3023, #3070, #3072). Anyone encountering these issues should upgrade.
  • Console UX and compatibility — Chat input history, cross-session search, pinned sessions, per-agent chat restoration, and lazy-loaded settings improve daily use (#2466, #2842, #3137, #3155, #3122). No breaking change is explicitly announced, but more consistent error codes across channels, APIs, and CLI (#3110) mean integrations matching specific codes should be regression-tested; satisfied UI-only users can skip.

✨ Added

Core

  • Plugins: Install extensions from your workspace plugins/ folder (#3101, #3131, #3132).
  • copaw task: Run one-off jobs from the terminal with no web server (#3031).
  • /model in chat: Switch models, list what is available, reset to the default, and inspect a model—without opening Settings (#3133).

Models and providers

  • SiliconFlow: Ready-to-use China and International endpoints for SiliconFlow’s OpenAI-compatible API (#2886).
  • CoPaw Local: Image and video capable models, richer settings in the console, and more reliable downloads and capability detection on Windows (#3021, #3087, #3140).

Security

  • Safer saved secrets: API keys and similar values are encrypted on disk; where possible the encryption key stays in the OS keychain (#3025).

Console and UI

  • Chat input history: Browse previous user lines with the arrow keys (#2466).
  • Chat search: Search message text across sessions (#2842).
  • Pinned sessions: Pin threads so they stay at the top of the list (#3137).
  • Per-agent chat: Restore the last open chat when you switch agents (#3155).
  • Visual polish: Icons for built-in tools and provider logos next to models (#3061, #3130).

Skills and Tools

  • Skill commands: /skills shows what is enabled for the channel; type /<skill name> to open a skill or run it with your message (#3150).
  • Tags for pool skills: Organize the shared pool with tags (#2837, #3069).
  • MCP tool discovery: Query each connected MCP server for its tool names, descriptions, and parameters over the HTTP API (#3149).

Channels

  • QQ: Send files and rich media consistently across message types (#3012).
  • WeCom: Incoming messages keep quote/reply context so the agent sees what was referenced (#3024).

🔄 Changed

  • Timezone picker: Region names follow your selected UI language (#2497).
  • File sizes: Human-readable sizes everywhere in the console (#2808).
  • Console startup: Heavier settings pages load on demand so the first screen opens faster (#3122).
  • Large skill lists: Smoother scrolling and interaction when you have many pool skills (#3141, #3158).
  • Provider connection tests: Status messages appear in your language (#2913).
  • Error Code: More consistent error codes across channels, APIs, and CLI (#3110).

🐛 Fixed

Channels

  • iMessage: Private chats now respect your DM policy and allowlist the same way as other channels (#2491).
  • Discord: Long assistant replies no longer break Markdown code blocks mid-fence (#2976).
  • Feishu: Reconnecting and running several agents no longer trips over shared locks or mixed-up event loops (#3095, #3145).

Tools and skills

  • MCP: Closing or reconnecting clients after reload no longer causes runaway CPU usage (#3106).
  • Browser automation: Clicking elements when duplicates exist targets the right one; the docs explain selectors more clearly (#3023).
  • Shell tool: Commands with quoted text keep their line breaks intact (#3070).
  • Skills: Corrupt or non-object skill metadata no longer crashes requirement parsing (#3072).
