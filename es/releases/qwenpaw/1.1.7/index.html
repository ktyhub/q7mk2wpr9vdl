QwenPaw v1.1.7

✨ Agregado

Herramientas y MCP

  • Uso del navegador: acciones por lotes: ejecute varios pasos del navegador (navegar, click, escribir, captura de pantalla, etc.) en una sola llamada de herramienta (#4139)
  • Uso del navegador — Descarga de archivos: descargue archivos cli seleccionando elementos de la página o obteniendo URL directamente (#4261)
  • Imágenes de referencia de GPT Image 2: admite la carga de 1 a 16 imágenes de referencia a través de URL o ruta local en el complemento GPT Image 2 (#4194)
  • Ejecución asíncrona del agente externo: delegate_external_agent admite transmisión asíncrona con listado de tareas y consultas de estado y tiempo de espera configurable (#4197)
  • Configuración ejecutable de Shell: elija qué shell ejecuta comandos a través de la opción de configuración (#4215)
  • OAuth 2.1 para servidores MCP remotos: autenticar servidores MCP remotos a través de OAuth 2.1 con PKCE (#4256) Complementos
  • Administración de complementos de consola: instale y desinstale complementos desde la interfaz de usuario de configuración mediante la ruta local, carga ZIP o URL (#4214, #4266)
  • Complementos Qwen-Image & Wan 2.7: Nuevos complementos para generación/edición de imágenes y generación de videos (#4248)
  • Enrutador HTTP API del complemento: los complementos pueden registrar puntos finales HTTP API personalizados (#4255) Chat y consola
  • Varios archivos adjuntos: la entrada de chat ahora admite la selección de varios archivos en un solo mensaje (#4206)
  • Idioma indonesio: compatibilidad total con la configuración regional de Bahasa Indonesia para la interfaz de usuario de la consola y el backend (#4219)
  • Bandeja de entrada: Nueva bandeja de entrada centralizada con pestañas de Aprobaciones y Mensajes push para administrar las aprobaciones de protección de herramientas y ver los resultados de la ejecución cron con seguimientos (#4210, #4305)
  • Mejora de trabajos cron: los trabajos cron ahora admiten la ejecución programada única, una vista de calendario para visualizar las próximas ejecuciones, plantillas integradas para una creación rápida, historial de ejecución por trabajo con seguimientos de ejecución detallados y entrega de guardado en la bandeja de entrada (#4210) Canales
  • Burbujas de voz de Feishu: los archivos de audio enviados a través de Feishu ahora se muestran como burbujas de voz nativas (#4202)
  • Mensajes citados de DingTalk: las respuestas con mensajes citados en DingTalk ahora incluyen texto y medios citados en el contexto del agente (#4209)
  • Creación de bot de código QR Feishu: cree un bot Feishu/Lark escaneando un código QR en la interfaz de usuario de configuración de canales (#4236)
  • Salida de transmisión de WeCom: respuestas de transmisión opcionales para el canal WeCom con entrega de mensajes en tiempo real y compatibilidad con indicadores de razonamiento (#4271)

🔄 Cambiado

  • Rediseño del selector de modelo: se reemplazó el menú desplegable al pasar el mouse por una lista plana con capacidad de búsqueda agrupada por proveedor (#3876)
  • Botón de chat flotante: la navegación del chat se movió del menú de la barra lateral a un botón adhesivo al lado del selector de agentes (#4240, #4273)
  • Descubrimiento de sesión de estadísticas del agente: búsqueda de archivos de sesión simplificada recorriendo los subdirectorios del canal directamente (#4250)

⚡ Rendimiento

  • Dependencias Async FastAPI: dependencias del administrador de proveedores y modelos convertidas a asíncronas, eliminando el envío innecesario de grupos de subprocesos (#4229)
  • Límite de tamaño de lectura de archivos: tamaño máximo de lectura de archivos reducido a 200 MB (de 1 GB) con asignación previa basada en el tamaño real del archivo (#4272, #4276)
  • Tiempo de espera del llavero: las operaciones del llavero ahora tienen un tiempo de espera de 10 segundos para evitar que el administrador de credenciales bloquee el inicio (#4263)

QwenPaw v1.1.7

Highlights

  • Browser automation becomes practical for real workloads — Batch Actions (#4139) collapse navigate/click/type/screenshot sequences into a single tool call, cutting the round-trip and token overhead that made multi-step browsing fragile and expensive; File Download (#4261) closes a gap anyone scraping or retrieving generated artifacts has hit. Expect agent loops to get faster and cheaper, but verify element selectors still resolve when steps run in one batch rather than observing each intermediate state.
  • Remote MCP authentication is now enterprise-grade — OAuth 2.1 with PKCE for remote MCP servers (#4256) means hosted MCP endpoints that require delegated auth are finally reachable without credential workarounds. If you self-host MCP servers behind an identity provider, this is the change that unblocks adoption; plan for an initial auth/config pass rather than assuming existing token-based setups carry over.
  • The extension surface expands beyond chat — delegate_external_agent gains async streaming, task listing/status queries, and configurable timeouts (#4197), so integrations that previously depended on synchronous polling can be redesigned around streamed results — set the timeout deliberately or long-running delegations will be cut short. Plugins can also register custom HTTP API endpoints (#4255), which turns plugins into real services you can wire into external tooling, not just in-process capabilities.
  • Plugin installation moves into the Console — Install/uninstall via local path, ZIP upload, or URL from Settings (#4214, #4266), plus new Qwen-Image and Wan 2.7 plugins for image and video generation (#4248). This lowers the bar for distributing private plugins to non-CLI users, but introduces a new install surface worth locking down if your Console is shared — treat plugin URLs as trusted inputs.
  • Concurrency and startup hardening — Model/provider manager dependencies are now async (#4229), removing thread-pool dispatch that added latency under load; file reads are capped at 200 MB down from 1 GB with size-based pre-allocation (#4272, #4276) — workloads that routinely read very large files need to chunk them explicitly now; and a 10-second keyring timeout (#4263) prevents a slow credential manager from hanging startup, though it may surface as a credential miss on unusually slow backends.
  • UI and session behavior changes to watch — The model selector is now a searchable flat list grouped by provider (#3876) and chat navigation moves to a sticky button by the agent selector (#4240, #4273), so muscle-memory and any UI automation/screenshots will need updating. More importantly, session history routing was fixed so messages stop disappearing or landing in the wrong session (#4203), the streaming parser now drops malformed tool-use blocks with null IDs or empty names (#4234), and newlines in user messages are preserved (#4231) — all of which change observable behavior in ways worth re-testing your prompts and session flows.

No breaking changes in this release.

✨ Added

Tools & MCPs

  • Browser Use — Batch Actions: Execute multiple browser steps (navigate, click, type, screenshot, etc.) in a single tool call (#4139)
  • Browser Use — File Download: Download files by clicking page elements or fetching URLs directly (#4261)
  • GPT Image 2 Reference Images: Support uploading 1–16 reference images via URL or local path in the GPT Image 2 plugin (#4194)
  • External Agent Async Execution: delegate_external_agent supports async streaming with task listing and status queries and configurable timeout (#4197)
  • Shell Executable Configuration: Choose which shell runs commands via the config option (#4215)
  • OAuth 2.1 for Remote MCP Servers: Authenticate remote MCP servers via OAuth 2.1 with PKCE (#4256)

Plugins

  • Console Plugin Management: Install and uninstall plugins from the Settings UI via local path, ZIP upload, or URL (#4214, #4266)
  • Qwen-Image & Wan 2.7 Plugins: New plugins for image generation/editing and video generation (#4248)
  • Plugin HTTP API Router: Plugins can register custom HTTP API endpoints (#4255)

Chat & Console

  • Multiple File Attachments: Chat input now supports selecting multiple files in a single message (#4206)
  • Indonesian Language: Full Bahasa Indonesia locale support for Console UI and backend (#4219)
  • Inbox: New centralized Inbox with Approvals and Push Messages tabs for managing tool-guard approvals and viewing cron execution results with traces (#4210, #4305)
  • Cron Job Enhancement: Cron jobs now support one-time scheduled execution, a calendar view for visualizing upcoming runs, built-in templates for quick creation, per-job execution history with detailed run traces, and save-to-inbox delivery (#4210)

Channels

  • Feishu Voice Bubbles: Audio files sent via Feishu now render as native voice bubbles (#4202)
  • DingTalk Quoted Messages: Replies with quoted messages in DingTalk now include quoted text and media in the agent context (#4209)
  • Feishu QR Code Bot Creation: Create a Feishu/Lark bot by scanning a QR code in the Channels setup UI (#4236)
  • WeCom Streaming Output: Optional streaming replies for WeCom channel with real-time message delivery and reasoning indicator support (#4271)

🔄 Changed

  • Model Selector Redesign: Replaced the hover dropdown with a searchable flat list grouped by provider (#3876)
  • Floating Chat Button: Chat navigation moved from sidebar menu to a sticky button next to the agent selector (#4240, #4273)
  • Agent Stats Session Discovery: Simplified session file lookup by walking channel subdirectories directly (#4250)

⚡ Performance

  • Async FastAPI Dependencies: Model and provider manager dependencies converted to async, eliminating unnecessary thread pool dispatch (#4229)
  • File Read Size Limit: Maximum file read size reduced to 200 MB (from 1 GB) with pre-allocation based on actual file size (#4272, #4276)
  • Keyring Timeout: Keyring operations now have a 10-second timeout to prevent credential manager hangs from blocking startup (#4263)

🐛 Fixed

Providers & Models

  • Volcengine Model IDs: Corrected model IDs to match actual API endpoints and updated capability flags (#4169)
  • Provider Meta Preservation: Provider metadata is no longer dropped when retrieving provider info (#4200)
  • Malformed Tool Use Filtering: Streaming parser now filters out tool-use blocks with null IDs or empty names (#4234)

Channels

  • WeCom Approval Card Operator: Resolved approval cards now display the operator name (#4233)
  • Feishu WebSocket Keepalive: Detect and recover from silent WebSocket connection loss (#4241)

Console & UI

  • Session History Routing: Fixed session history disappearing and messages being routed to wrong sessions (#4203)
  • Plan Panel Dark Mode: Improved text contrast in Plan Panel dark mode (#4190)
  • Mobile Sidebar: Sidebar auto-collapses on narrow screens (#4225)
  • User Message Newlines: User messages now preserve line breaks (#4231)
  • Token Usage Date Labels: Chart labels now show year prefix when the date range crosses a year boundary (#4268)
  • Desktop External Links: Links now open correctly in desktop builds (#4270)
