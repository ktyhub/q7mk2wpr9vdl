QwenPaw v1.1.3

✨ Agregado

Sistema de agentes

  • Copia de seguridad y restauración: sistema de copia de seguridad y restauración: cree instantáneas específicas de agentes, habilidades, memoria y sesiones con selección por agente, importe/exporte como archivos zip (#3534, #3655)
  • Servidor ACP: exponer los agentes QwenPaw como puntos finales ACP (Protocolo de comunicación de agentes) sobre stdio a través de qwenpaw acp (#3487, #3589, #3595)
  • Mensajería proactiva del agente: los agentes pueden enviar mensajes proactivamente, utilizando la memoria de sesión y el contexto de la pantalla para proporcionar información oportuna (#3466, #3643)
  • Normalización de mensajes entre proveedores: cambie fácilmente de proveedor de LLM en medio de una conversación: los campos de mensajes específicos del proveedor se limpian y normalizan automáticamente al cambiar de modelo (#3530) Consola y interfaz de usuario
  • Sistema de complementos de consola: arquitectura de complementos extensible para la consola: los complementos de terceros pueden insertar páginas de la barra lateral, registrar rutas y compartir módulos de host (#3357, #3512, #3631)
  • Página de estadísticas del agente: nuevo panel con gráficos de tendencias de sesiones y mensajes, uso de tokens a lo largo del tiempo y gráficos circulares de desglose de canales (#3365, #3608, #3632) Habilidades
  • Mejoras en la página de habilidades: páginas rediseñadas de habilidades y conjunto de habilidades con selección/administración por lotes, búsqueda separada y controles de filtro (#3616, #3634)
  • Cambio de idioma de habilidades integradas: todas las habilidades integradas ahora se envían con variantes en inglés y chino. Cambie de idioma desde la página Grupo de habilidades, con soporte de idioma predeterminado al importar habilidades a los agentes (#3558, #3644) Seguridad
  • Shell Evasion Guard: Nuevo guardián de Tool Guard que detecta patrones de ofuscación de comandos de shell (#3400, #3668)
  • Respuesta mejorada de protección de herramientas: los mensajes de protección de herramientas ahora incluyen el nivel de gravedad del riesgo y una explicación localizada de por qué se bloqueó una llamada de herramienta o requiere aprobación (#3515) Proveedores
  • Administración de modelos locales: configure puertos de servidor personalizados para modelos locales (llama.cpp) y monitoree los registros del servidor en tiempo real (#3596, #3604)
  • Detección multimodal de OpenRouter: los modelos OpenRouter ahora informan automáticamente capacidades multimodales (soporte de imagen/vídeo) desde el registro de modelos (#3584, #3604)
  • Aliyun Coding Plan International: Se agregó soporte regional internacional para el proveedor del Aliyun Coding Plan (#3609) Canales
  • Reconocimiento instantáneo de QQ: respuesta instantánea configurable para el canal QQ: reconoce al usuario inmediatamente mientras el agente procesa la solicitud (#3246)
  • Indicador de escritura de Telegram: el indicador de escritura ahora permanece activo durante la ejecución de la herramienta, proporcionando retroalimentación visual continua mientras el agente trabaja (#3585)
  • DingTalk @Mention on Reply: @menciona automáticamente al remitente original al responder en los chats grupales de DingTalk (#3591)
  • Comprobación y reinicio del estado del canal API: puntos finales HTTP por agente para verificar el estado de salud del canal individual y reiniciar canales en caliente (#3649) CLI
  • Actualizar URL base de proveedores: qwenpaw providers update ahora admite la actualización de URL base de proveedores desde la línea de comando (#3536)

🔄 Cambiado

  • Rediseño de la página de depuración: se reubicó la página de depuración en Configuración con una estructura de componentes mejorada, un visor de registros dedicado y correcciones de estilo en modo oscuro (#3539, #3547, #3590)
  • Actualización de la habilidad make_plan: se limpiaron las referencias de documentación obsoletas y se simplificó la habilidad make_plan (#3535)
  • Directorio de medios de canal unificado: todos los canales ahora resuelven media_dir desde el espacio de trabajo del agente de manera consistente, lo que garantiza el almacenamiento de archivos aislado en todos los tipos de canales (#3610)

QwenPaw v1.1.3

Highlights

  • Portable agent state — Scoped ZIP snapshots cover agents, skills, memory, and sessions, enabling migration and rollback without rebuilding an agent from scratch. Use per-agent selection when moving a single agent to avoid exporting unrelated session data (#3534, #3655).
  • ACP and console extensibility — qwenpaw acp exposes agents over stdio through the Agent Communication Protocol, while console plugins can inject sidebar pages, register routes, and reuse host modules. These provide agent-level and UI-level integration points without forking QwenPaw (#3487, #3357).
  • Cross-provider continuity — Provider-specific message fields are cleaned and normalized when switching models mid-conversation, reducing failures caused by incompatible conversation history. OpenRouter models also report image/video capabilities from the registry, allowing clients to gate multimodal inputs against the selected model (#3530, #3584).
  • Stronger tool-call screening — The new Shell Evasion Guard detects obfuscated shell commands, while Tool Guard responses now include severity and localized explanations. Operators can distinguish policy enforcement from execution failures, but shell-heavy workflows should watch for additional blocks or approval prompts (#3400, #3515).
  • Channel operations and media isolation — Per-agent HTTP endpoints support automated channel health checks and hot restarts. All channels now resolve media_dir from the agent workspace, improving storage isolation; verify existing custom paths and attachment access after upgrading (#3649, #3610).
  • Compatibility — No breaking changes are listed.

✨ Added

Agent System

  • Backup & Restore: Backup and restore system — create scoped snapshots of agents, skills, memory, and sessions with per-agent selection, import/export as zip files (#3534, #3655)
  • ACP Server: Expose QwenPaw agents as ACP (Agent Communication Protocol) endpoints over stdio via qwenpaw acp (#3487, #3589, #3595)
  • Proactive Agent Messaging: Agents can proactively send messages, using session memory and screen context to provide timely information (#3466, #3643)
  • Cross-Provider Message Normalization: Seamlessly switch LLM providers mid-conversation — provider-specific message fields are automatically cleaned and normalized when changing models (#3530)

Console & UI

  • Console Plugin System: Extensible plugin architecture for the console — third-party plugins can inject sidebar pages, register routes, and share host modules (#3357, #3512, #3631)
  • Agent Statistics Page: New dashboard with session and message trend charts, token usage over time, and channel breakdown pie charts (#3365, #3608, #3632)

Skills

  • Skill Page Improvements: Redesigned Skills and Skill Pool pages with batch select/manage, separated search and filter controls (#3616, #3634)
  • Builtin Skill Language Switch: All builtin skills now ship with English and Chinese variants. Switch language from the Skill Pool page, with default language support when importing skills to agents (#3558, #3644)

Security

  • Shell Evasion Guard: New Tool Guard guardian that detects shell command obfuscation patterns (#3400, #3668)
  • Enhanced Tool Guard Response: Tool guard messages now include risk severity level and a localized explanation of why a tool call was blocked or requires approval (#3515)

Providers

  • Local Model Management: Configure custom server ports for local models (llama.cpp) and monitor server logs in real-time (#3596, #3604)
  • OpenRouter Multimodal Detection: OpenRouter models now automatically report multimodal capabilities (image/video support) from the model registry (#3584, #3604)
  • Aliyun Coding Plan International: Added international region support for the Aliyun Coding Plan provider (#3609)

Channels

  • QQ Instant Acknowledgment: Configurable instant reply for QQ channel — acknowledge the user immediately while the agent processes the request (#3246)
  • Telegram Typing Indicator: Typing indicator now stays active during tool execution, providing continuous visual feedback while the agent works (#3585)
  • DingTalk @Mention on Reply: Automatically @mention the original sender when replying in DingTalk group chats (#3591)
  • Channel Health Check & Restart API: Per-agent HTTP endpoints to check individual channel health status and hot-restart channels (#3649)

CLI

  • Update Provider Base URLs: qwenpaw providers update now supports updating provider base URLs from the command line (#3536)

🔄 Changed

  • Debug Page Redesign: Relocated the Debug page under Settings with improved component structure, dedicated log viewer, and dark mode styling fixes (#3539, #3547, #3590)
  • make_plan Skill Update: Cleaned up stale documentation references and streamlined the make_plan skill (#3535)
  • Unified Channel Media Directory: All channels now resolve media_dir from the agent workspace consistently, ensuring isolated file storage across channel types (#3610)

🐛 Fixed

Console & UI

  • Preview URL Prefix: Fixed duplicated URL prefixes in file preview paths (#3355)
  • Markdown Rendering: Fixed markdown rendering and code block copy styling in workspace file editor (#3639)
  • Table Scrolling: Fixed table scrolling on Sessions and Cron Jobs pages (#3654)

Channels

  • WeCom Attachment Access: Fixed WeCom attachment access failing in server deployments (#3079)
  • WeCom File Upload: Fixed event loop blocking in WeCom file uploads and added relative path support for send_file_to_user (#3128)
  • WeCom Duplicate Messages: Fixed duplicate chat entries for WeCom group messages (#3529)
  • WeCom Screenshot Filename: Fixed CJK characters in WeCom screenshot filenames causing download failures (#3633)
