QwenPaw v1.1.1

✨ Agregado

Proveedores y Modelos

  • Proveedor OpenRouter: proveedor OpenRouter integrado con descubrimiento de modelos, exploración de series y filtrado por modalidad y precio (#1192)
  • Proveedor OpenCode: proveedor OpenCode (Zen) compatible con OpenAI integrado con modelos gratuitos (#2463)
  • Autocompletar ID de modelo: menú desplegable de autocompletar para la selección de ID de modelo al agregar modelos, con descubrimiento de modelo habilitado de forma predeterminada para todos los proveedores (#3175, #3341) Sistema multiagente
  • Herramientas de colaboración de agentes integradas: nuevas herramientas integradas list_agents y chat_with_agent con una habilidad dedicada y comandos de agente CLI optimizados para la comunicación entre agentes (#3292) Canales
  • Matrix Channel Rewrite: cifrado de extremo a extremo (E2EE), manejo de menciones, soporte de historial de mensajes y representación de rebajas (#2509)
  • Mensajes citados de Feishu: manejo de mensajes de cadena de respuesta con extracción de texto, publicaciones, imágenes y contenido de archivos (#3207)
  • Autenticación QR de DingTalk: autenticación de flujo de dispositivo con código QR para la configuración del canal DingTalk en la consola (#3315) Seguridad
  • Guardias de comando de Shell extendidas: nuevas reglas de protección que cubren la inyección $IFS, caracteres de control, espacios en blanco Unicode, acceso a /proc/*/environ, indicadores peligrosos de jq y funciones integradas riesgosas específicas de Zsh (#3303) Herramientas y habilidades
  • Requisitos de habilidades de ClawHub: compatibilidad con requisitos de habilidades en formato ClawHub con resolución de espacio de nombres de metadatos múltiples (#3310)
  • Visualización de URL de medios: las herramientas view_image y view_video ahora aceptan URL HTTP/HTTPS para visualización directa de medios sin descarga (#3358)

  • Pestañas de configuración del agente: página de configuración del agente refactorizada desde tarjetas apiladas a una interfaz con pestañas (#3354)
  • IU de selección de habilidades: selección de habilidades mejorada con sugerencias de etiquetas, información sobre herramientas para nombres largos, comportamiento de carga refinado y acciones de selección masiva (#3320, #3362, #3373)

QwenPaw v1.1.1

Highlights

  • Model provider onboarding is broader and safer — OpenRouter adds discovery, series browsing, and modality/pricing filters; OpenCode (Zen) adds OpenAI-compatible access to free models; model-ID autocomplete now defaults discovery across providers (#1192, #2463, #3175, #3341). A unified multimodal probe reduces false image-capability positives across Anthropic, Gemini, and OpenAI, helping avoid runtime failures on incorrectly enabled models (#3367).
  • Provider switching now preserves multimodal context — Messages are normalized at request time so media attachments survive in-memory model switches; Anthropic tool results deduplicate repeated base64 payloads into placeholders to avoid message-size limits (#3359, #3372). The compatibility fix that omits tool_choice=auto also prevents HTTP 400s on vLLM deployments lacking --enable-auto-tool-choice (#3295).
  • Browser lifecycle is now managed by default — Browser startup switches to managed CDP, including Chromium detection, port allocation, and process lifecycle management (#3164). Adopters relying on a manually started browser should review their launch and cleanup assumptions.
  • Enterprise channels gain encryption, authentication, and richer replies — The Matrix rewrite brings E2EE, mentions, history, and Markdown; DingTalk adds QR device-flow setup and moves to the official Alibaba Cloud SDK, with reactions and media delivery in AI Card mode; Feishu handles quoted reply chains across text, posts, images, and files (#2509, #3315, #3207, #3236, #3337, #3374).
  • Tooling is more composable, with tighter shell boundaries — list_agents and chat_with_agent enable built-in inter-agent communication, ClawHub-compatible requirements support multiple metadata namespaces, and media tools accept HTTP/HTTPS URLs directly (#3292, #3310, #3358). Shell guards now cover $IFS injection, control characters, Unicode whitespace, /proc/*/environ, dangerous jq flags, and risky Zsh builtins, so existing command templates may need hardening (#3303).

No breaking changes declared.

✨ Added

Providers and Models

  • OpenRouter Provider: Built-in OpenRouter provider with model discovery, series browsing, and filtering by modality and pricing (#1192)
  • OpenCode Provider: Built-in OpenAI-compatible OpenCode (Zen) provider with free models (#2463)
  • Model ID Autocomplete: Autocomplete dropdown for model ID selection when adding models, with model discovery enabled by default for all providers (#3175, #3341)

Multi-Agent System

  • Built-in Agent Collaboration Tools: New list_agents and chat_with_agent built-in tools with a dedicated skill and streamlined CLI agent commands for inter-agent communication (#3292)

Channels

  • Matrix Channel Rewrite: End-to-end encryption (E2EE), mention handling, message history support, and markdown rendering (#2509)
  • Feishu Quoted Messages: Reply-chain message handling with text, post, image, and file content extraction (#3207)
  • DingTalk QR Authentication: QR code device-flow authentication for DingTalk channel setup in console (#3315)

Security

  • Extended Shell Command Guards: New guard rules covering $IFS injection, control characters, Unicode whitespace, /proc/*/environ access, dangerous jq flags, and Zsh-specific risky builtins (#3303)

Tools & Skills

  • ClawHub Skill Requirements: Support for skill requirements in ClawHub format with multiple metadata namespace resolution (#3310)
  • Media URL Viewing: view_image and view_video tools now accept HTTP/HTTPS URLs for direct media viewing without download (#3358)

🔄 Changed

Providers and Models

  • Multimodal Probe Unification: Image support probing across Anthropic, Gemini, and OpenAI providers now shares a single evaluation path with improved false-positive detection (#3367)
  • Message Normalization for Model Switching: Messages are normalized at request time so media attachments are preserved in memory when switching between model providers (#3359)
  • Anthropic Media Deduplication: Duplicate base64 media in tool results is replaced with text placeholders to prevent exceeding Anthropic's message size limit (#3372)

Channels

  • DingTalk SDK Migration: Channel migrated to the official Alibaba Cloud SDK with emoji reaction feedback during processing and media delivery in AI Card mode (#3236, #3337, #3374)
  • Feishu WebSocket Stability: Event loop handling refactored for improved cross-thread reliability during reconnections (#3360)
  • WeChat Reply Limit Warning: Channel settings now display a warning about the context_token reply limit for WeChat iLink (#3376)

Tools & Skills

  • Browser Managed CDP: Default browser start strategy changed to managed CDP with automatic Chromium detection, port allocation, and process lifecycle management (#3164)

Console & UI

  • Model Management Redesign: Provider model management modal redesigned with capability tags, model searching, and simplified card layout (#3273, #3294)
  • Agent Config Tabs: Agent configuration page refactored from stacked cards to a tabbed interface (#3354)
  • Skill Selection UI: Improved skill selection with tag suggestions, tooltips for long names, refined loading behavior, and bulk select actions (#3320, #3362, #3373)
  • Downloads Page: Website downloads page reworked with stable and preview version grouping (#3353)

🐛 Fixed

Channels

  • QQ WebSocket Shutdown: stop() no longer blocks for 8 seconds by force-closing the WebSocket on shutdown (#3188)

Console & UI

  • Fixed chat session pin button contrast in dark mode (#3267)
  • Markdown links in header now navigate in-app instead of opening new tabs (#3186)
  • Website contributors layout alignment for Chinese locale (#3332)

Providers

  • Fixed local model download failure on Windows ([Errno 22] Invalid argument) (#3321)
  • Omit tool_choice=auto for vLLM compatibility to avoid 400 errors on deployments without --enable-auto-tool-choice (#3295)

📚 Documentation

  • RESTful API Tutorial: Comprehensive REST API tutorial covering chat endpoints, authentication, multi-turn sessions, streaming, and agent switching (#3335)
  • Skill Chat Commands: Added skill chat command reference to commands documentation (#3330)

New Contributors
