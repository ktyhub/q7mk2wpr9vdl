#AstrBot v4.25.4

¿Qué ha cambiado?

Arreglar

  • Revertir algunos cambios y solucionar el problema ocasional de Database is locked. (#8639)
  • Se solucionó el problema por el cual las tareas asincrónicas de Pipeline podían ser recolectadas como basura debido a la falta de referencias sólidas y se mejoró la estabilidad del procesamiento de eventos. (#8618)
  • Se solucionó un problema por el cual, al usar la herramienta de búsqueda web en WebChat, las palabras de referencia se agregaban repetidamente al mensaje del sistema después de varias llamadas a la herramienta en la misma ronda de conversación, para evitar dañar el caché de contexto. (#8642)
  • Sincronice la configuración de anulaciones en el Panel pnpm-lock.yaml para corregir la inconsistencia entre el archivo de bloqueo y la configuración del espacio de trabajo. (#8637)

Optimización

  • Aumente el tiempo de espera de la solicitud HTTP API de la cuenta pública de WeChat de 15 segundos a 120 segundos para reducir la probabilidad de que se produzca un error en el tiempo de espera al descargar archivos con una respuesta lenta de la red o de la interfaz. (#8643)
  • El formulario de inicio de sesión del panel permite completar automáticamente las credenciales completas, lo que mejora la experiencia del administrador de contraseñas del navegador. (#8631) <a id="inglés"></a>

Qué ha cambiado (ES)

Corrección de errores

  • Se corrigió el mensaje repetido de citas de búsqueda web que se agrega en WebChat después de múltiples llamadas a herramientas dentro de la misma interacción, lo que evita la invalidación del caché de contexto. (#8642)
  • Se corrigió que las tareas asíncronas de Pipeline pudieran ser recolectadas como basura debido a la falta de referencias sólidas, lo que mejoró la estabilidad del procesamiento de eventos. (#8618)
  • El panel sincronizado pnpm-lock.yaml se anula con la configuración del espacio de trabajo. (#8637)
  • Se revirtió el cambio de reintento de bloqueo de SQLite de estadísticas del proveedor para evitar regresiones relacionadas. (#8639)
  • Se revirtieron los cambios de compatibilidad de macOS SQLAlchemy para evitar regresiones en la inicialización de la base de datos y las rutas de almacenamiento vectorial. (#8638)

Mejoras

  • Aumentó el tiempo de espera de solicitud HTTP API de la cuenta oficial de WeChat de 15 segundos a 120 segundos, lo que reduce las fallas de tiempo de espera en redes más lentas o respuestas API. (#8643)
  • Se habilitó el autocompletado completo de credenciales en el formulario de inicio de sesión del Panel para mejorar la compatibilidad con el administrador de contraseñas del navegador. (#8631)

AstrBot v4.25.4

Highlights

  • WebChat context caching — #8642 stops Web-search citation prompts from being appended repeatedly during multi-tool turns. This prevents redundant system-message content from inflating token usage and invalidating provider context caches.

  • Pipeline task reliability — #8618 adds strong references to asynchronous Pipeline tasks, reducing the risk of in-flight event processing being garbage-collected. Bots running concurrent or long-lived pipelines should see fewer silently dropped tasks, with no handler changes required.

  • Provider stats and macOS rollbacks — #8639 reverts the Provider stats SQLite lock-retry change associated with intermittent Database is locked errors, while #8638 reverts macOS SQLAlchemy adjustments affecting database initialization and vector-storage paths. These changes prioritize regressions over new behavior; affected users should not expect the reverted fixes to resolve their issues.

  • WeChat API timeout — #8643 raises the Official Account HTTP API timeout from 15 to 120 seconds, making slow file downloads and API responses less likely to fail. The trade-off is that stalled requests can now wait up to 120 seconds before timing out, so account for this in operational timeout budgets.

  • Dashboard and dependency consistency — #8631 enables full credential autofill for browser password managers, while #8637 aligns pnpm-lock.yaml overrides with workspace configuration to reduce dependency-resolution drift.

  • Breaking changes — None.

What's Changed

修复

  • 回滚部分改动，修复偶现的 Database is locked 的问题。(#8639)
  • 修复 Pipeline 异步任务可能因缺少强引用而被垃圾回收的问题，提升事件处理稳定性。(#8618)
  • 修复 WebChat 使用 Web 搜索工具时，引用提示词在同一轮对话多次工具调用后被重复追加到系统消息的问题，避免破坏上下文缓存。(#8642)
  • 同步 Dashboard pnpm-lock.yaml 中的 overrides 配置，修复锁文件与工作区配置不一致的问题。(#8637)

优化

  • 将微信公众号 HTTP API 请求超时时间从 15 秒提升到 120 秒，降低较慢网络或接口响应下下载文件超时失败概率。(#8643)
  • Dashboard 登录表单启用完整凭据自动填充，改善浏览器密码管理器的使用体验。(#8631)

<a id="english"></a>

What's Changed (EN)

Bug Fixes

  • Fixed repeated Web search citation prompt appends in WebChat after multiple tool calls within the same interaction, preventing context cache invalidation. (#8642)
  • Fixed Pipeline async tasks potentially being garbage-collected due to missing strong references, improving event processing stability. (#8618)
  • Synced Dashboard pnpm-lock.yaml overrides with the workspace configuration. (#8637)
  • Reverted the Provider stats SQLite lock retry change to avoid related regressions. (#8639)
  • Reverted the macOS SQLAlchemy compatibility changes to avoid regressions in database initialization and vector storage paths. (#8638)

Improvements

  • Increased the WeChat Official Account HTTP API request timeout from 15 seconds to 120 seconds, reducing timeout failures on slower networks or API responses. (#8643)
  • Enabled full credential autofill on the Dashboard login form for better browser password manager support. (#8631)
