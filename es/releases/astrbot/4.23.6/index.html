#AstrBot v4.23.6

  • Registro de actualización (chino simplificado)
  • Changelog(inglés) <a id="chino"></a>

¿Qué ha cambiado?

Nuevo

  • Se agregó el comando /stats para ver las estadísticas de uso del token de la sesión actual y mostrarlas por separado por cantidad total, entrada (caché), entrada (otra) y salida. (#7831)
  • Se agregaron herramientas de búsqueda web y extracción de páginas web de Firecrawl para respaldar el procesamiento de resultados de búsqueda, extracción de contenido de páginas web, administración de sesiones, verificación de solicitudes y pruebas relacionadas. (#7764)
  • Los mensajes de texto del servicio de atención al cliente de WeChat ahora se deduplican en 15 segundos para reducir el procesamiento de mensajes duplicados. (#7788)

Optimización

  • Optimice el rendimiento de la interfaz de configuración del proveedor y la visualización responsiva, y mejore la experiencia de fuente y diseño de los componentes relacionados. (#7772)
  • Optimice la lógica de cálculo de TPM en la página de estadísticas. TPM ahora solo cuenta los tokens de salida y actualiza la redacción relacionada. (#7827)
  • Optimice la lógica de filtrado de mensajes del asistente vacío del proveedor compatible con OpenAI. Las rutas de transmisión y no transmisión manejan cadenas vacías y contenidos de listas vacías de manera uniforme para evitar el rechazo estricto del proveedor de mensajes históricos. (#7758)

Arreglar

  • Se corrigió el procesamiento relacionado con el contenido de razonamiento en DeepSeek v4, se admitió el contenido de razonamiento de cadena vacía y se conservó el campo de razonamiento en el mensaje del asistente. (#7823, #7830)
  • Se solucionó el problema del nombre de atributo incorrecto del campo de razonamiento de OpenRouter. (#7821)
  • Se solucionó un problema por el cual las imágenes de gran tamaño sin comprimir podían causar un procesamiento posterior anormal y se reutilizó la herramienta de verificación del tamaño máximo de imagen. (#7807)
  • Se solucionó el problema por el cual MiniMax TTS genera MP3 de forma predeterminada, lo que causaba errores de RIFF en la conversión de voz en la plataforma oficial QQ. El formato de salida predeterminado se cambia a WAV. (#7797)
  • Se solucionó un problema por el cual las descargas de imágenes de la zona de pruebas de la computadora no se enviaban como imágenes. (#7785)
  • Se solucionó el problema de la falla de verificación de certificados para algunas solicitudes HTTPS en el entorno de Windows y se utilizó el contexto SSL de certificación para mejorar la compatibilidad. (#7778)
  • Se solucionó el problema de que la función de copia no está disponible en contextos no seguros o en algunos cuadros de diálogo, se extrajo la herramienta del portapapeles compartido y se agregó respaldo. (#7747)
  • Se solucionó el problema del posible recorrido de ruta en la carga de archivos y se limpiaron los bytes NUL en los nombres de los archivos cargados. (#7751) <a id="inglés"></a>

Qué ha cambiado (ES)

Nuevas características

  • Se agregó un comando /stats para mostrar el uso de tokens para la conversación actual, incluidos los tokens totales, los tokens de entrada almacenados en caché, otros tokens de entrada y los tokens de salida. (#7831)
  • Se agregaron herramientas de búsqueda web y extracción web de Firecrawl con manejo de resultados, extracción de contenido, administración de sesiones, validación de carga útil y pruebas. (#7764)
  • Se agregó deduplicación de 15 segundos para mensajes de texto WeChat kefu para reducir el manejo de mensajes duplicados. (#7788)

Mejoras

  • Se mejoró el rendimiento de la interfaz de usuario de configuración del proveedor y el diseño responsivo, incluidas actualizaciones de estilo de fuentes y componentes. (#7772)
  • Cálculo de TPM de la página de estadísticas actualizado para que TPM solo cuente los tokens de salida, con actualizaciones de etiquetas coincidentes. (#7827)
  • Se mejoró el filtrado de mensajes del asistente vacío para proveedores compatibles con OpenAI al compartir la lógica entre rutas de transmisión y no transmisión y manejar cadenas vacías o contenido de listas vacías. (#7758)

Corrección de errores

  • Se corrigió DeepSeek v4 y el manejo de contenido de razonamiento al admitir contenido de razonamiento de cadena vacía y preservar el campo de razonamiento en los mensajes del asistente. (#7823, #7830)
  • Se corrigió el atributo del campo de razonamiento utilizado para OpenRouter. (#7821)
  • Se corrigió el manejo de imágenes de gran tamaño al reducir la escala de imágenes grandes y compartir el asistente de verificación de tamaño máximo de imagen. (#7807)
  • Se corrigió la salida MiniMax TTS para la conversión de voz oficial de QQ cambiando el formato de salida predeterminado de MP3 a WAV. (#7797)
  • Se corrigieron las descargas de imágenes de la zona de pruebas de la computadora para que se envíen como imágenes. (#7785)
  • Se corrigieron problemas de verificación de certificados HTTPS en Windows mediante el uso de un contexto SSL de certificación. (#7778)
  • Se corrigieron acciones de copia en contextos y cuadros de diálogo inseguros mediante la extracción de una utilidad compartida clipboard con comportamiento alternativo. (#7747)
  • Se corrigieron los riesgos de cruce de rutas en las cargas de archivos y se eliminaron los bytes NUL incrustados de los nombres de archivos cargados. (#7751)

AstrBot v4.23.6

Highlights

  • Token telemetry gains a command — and a TPM semantics change — The new /stats command (#7831) surfaces per-conversation usage split into total, cached input, other input, and output tokens, giving developers a built-in way to debug cost and cache-hit behavior without instrumenting the provider layer. Watch the behavioral shift in #7827: stats-page TPM now counts only output tokens, so any dashboards, budgets, or alerts calibrated against the old figure will read lower — recalibrate thresholds before treating the trend as a real drop in traffic.

  • Reasoning-model compatibility is hardened — A cluster of fixes targets reasoning-capable providers: DeepSeek v4 now accepts empty-string reasoning_content and preserves the reasoning field on assistant messages (#7823, #7830); OpenRouter's incorrect reasoning_key attribute is corrected (#7821); and empty assistant messages are filtered consistently across both streaming and non-streaming paths (#7758), so strict providers stop rejecting replayed conversation history. Net effect: fewer 400s and less silent loss of reasoning metadata when you switch models mid-conversation.

  • Firecrawl becomes a first-class retrieval tool — #7764 adds Firecrawl-backed web search and page extraction, complete with result processing, session management, and payload validation. For agent builders this means a validated, stateful scraping path out of the box rather than hand-rolling extraction and request sanitization.

  • Messaging-platform behavior you'll actually notice — WeChat kefu text messages are now deduplicated within a 15-second window (#7788), so bots that (intentionally or not) relied on rapid duplicate events will see fewer deliveries. MiniMax TTS now defaults to WAV instead of MP3 to eliminate QQ Official RIFF errors (#7797) — if you depended on MP3, set the output format explicitly. Computer sandbox image downloads are now delivered as images rather than generic files (#7785).

  • Security and transport fixes worth upgrading for — #7751 closes a path-traversal vector in file uploads and strips embedded NUL bytes from filenames; if the dashboard is public-facing, this is the strongest reason to patch. #7778 moves Windows HTTPS requests onto a certifi SSL context to fix verification failures, #7747 adds an execCommand clipboard fallback for insecure contexts and dialogs, and #7807 downscales oversized images via a shared size-check helper to prevent downstream failures.

No breaking changes reported.

What's Changed

新增

  • 新增 /stats 命令，可查看当前会话的 Token 使用统计，并按总量、输入（缓存）、输入（其他）与输出拆分展示。（#7831）
  • 新增 Firecrawl Web 搜索与网页提取工具，支持搜索结果处理、网页内容提取、会话管理、请求校验与相关测试。（#7764）
  • 微信客服文本消息新增 15 秒内去重，减少重复消息处理。（#7788）

优化

  • 优化 Provider 配置界面性能与响应式显示，改善相关组件的字体和布局体验。（#7772）
  • 优化统计页 TPM 计算逻辑，TPM 现在仅统计输出 Token，并更新相关文案。（#7827）
  • 优化 OpenAI 兼容 Provider 的空 assistant 消息过滤逻辑，流式与非流式路径统一处理空字符串和空列表内容，避免严格 Provider 拒绝历史消息。（#7758）

修复

  • 修复 DeepSeek v4 与 reasoning content 相关处理，支持空字符串 reasoning 内容，并在 assistant 消息中保留 reasoning 字段。（#7823, #7830）
  • 修复 OpenRouter reasoning 字段属性名不正确的问题。（#7821）
  • 修复超大图片未压缩可能导致后续处理异常的问题，并复用图片最大尺寸检查工具。（#7807）
  • 修复 MiniMax TTS 默认输出 MP3 导致 QQ 官方平台语音转换出现 RIFF 错误的问题，默认输出格式改为 WAV。（#7797）
  • 修复 Computer 沙盒图片下载未按图片发送的问题。（#7785）
  • 修复 Windows 环境下部分 HTTPS 请求证书校验失败的问题，使用 certifi SSL context 提升兼容性。（#7778）
  • 修复非安全上下文或部分对话框中复制功能不可用的问题，抽取共享剪贴板工具并增加 fallback。（#7747）
  • 修复文件上传可能存在路径穿越的问题，并清理上传文件名中的 NUL 字节。（#7751）

What's Changed (EN)

New Features

  • Added a /stats command to show token usage for the current conversation, including total tokens, input cached tokens, input other tokens, and output tokens. (#7831)
  • Added Firecrawl web search and web extract tools with result handling, content extraction, session management, payload validation, and tests. (#7764)
  • Added 15-second deduplication for WeChat kefu text messages to reduce duplicate message handling. (#7788)

Improvements

  • Improved the Provider configuration UI performance and responsive layout, including font and component styling updates. (#7772)
  • Updated stats-page TPM calculation so TPM only counts output tokens, with matching label updates. (#7827)
  • Improved empty assistant message filtering for OpenAI-compatible providers by sharing the logic across streaming and non-streaming paths and handling empty string or empty list content. (#7758)

Bug Fixes

  • Fixed DeepSeek v4 and reasoning content handling by supporting empty-string reasoning content and preserving the reasoning field in assistant messages. (#7823, #7830)
  • Fixed the reasoning field attribute used for OpenRouter. (#7821)
  • Fixed oversized image handling by downscaling large images and sharing the image max-size check helper. (#7807)
  • Fixed MiniMax TTS output for QQ Official voice conversion by changing the default output format from MP3 to WAV. (#7797)
  • Fixed Computer sandbox image downloads so they are sent as images. (#7785)
  • Fixed HTTPS certificate verification issues on Windows by using a certifi SSL context. (#7778)
  • Fixed copy actions in insecure contexts and dialogs by extracting a shared clipboard utility with fallback behavior. (#7747)
  • Fixed path traversal risks in file uploads and removed embedded NUL bytes from upload filenames. (#7751)
