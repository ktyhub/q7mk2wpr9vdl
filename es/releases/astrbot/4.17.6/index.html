#AstrBot v4.17.6

¿Qué ha cambiado?

Nuevo

  • Se agregó verificación de permisos de administrador para la herramienta de ejecución Python/Shell para mejorar la seguridad de operaciones de alto riesgo (#5214).
  • Se agregó soporte de verificación de requisitos de versión de plataforma y complemento astrbot-version, y capacidades mejoradas de administración de compatibilidad de complementos (#5235).
  • Se agregó la verificación "Confirmar nueva contraseña" en el proceso de modificación de la contraseña de la cuenta para reducir los problemas de configuración causados ​​por una entrada incorrecta (#5247).

Arreglar

  • Se solucionó el problema por el cual la herramienta MCP estaba completamente expuesta al Agente principal e ignoraba la selección de la herramienta de personalidad (#5252).
  • Se mejoró el mecanismo de procesamiento pasivo de respuestas de las cuentas públicas de WeChat, se introdujo el almacenamiento en búfer y las respuestas fragmentadas y se optimizó el comportamiento del tiempo de espera para mejorar la estabilidad de las respuestas (#5224).
  • Se solucionó un problema por el cual se podía activar un error de respuesta de mensaje vacío al enviar solo el segmento de mensaje JSON (#5208).
  • Se solucionó el problema de respuesta obsoleta causado por eventos activos que no finalizaban cuando se restablecía/creaba/eliminaba la sesión (#5225).
  • Se solucionó el problema por el cual el proveedor podía retener contenido JSON en el escenario dict formato content (#5250).
  • Se solucionó el problema de configuración de additionalProperties en el atributo de esquema de herramienta (#5253).
  • Optimice las indicaciones de error de edición y verificación de la cuenta, simplifique y unifique la información de devolución cuando el nombre de usuario/contraseña esté vacío.

Optimización

  • Optimice el diseño de PersonaForm y la visualización de selección de herramientas, y mejore la visualización localizada del estado de desactivación de herramientas.

Otros

  • Se eliminó la canalización de Electron Desktop y se movió al repositorio de Tauri (#5226).
  • Actualice los enlaces de almacén relevantes y la copia de la plantilla de solicitud de funciones para unificar las expresiones en chino e inglés.
  • Se eliminó el archivo de documentación obsoleto heihe.md.

AstrBot v4.17.6

Highlights

  • Admin-gated code execution (#5214) — Python/Shell execution tools (the "computer use" feature) now sit behind a configurable admin-permission check. High-risk operations are no longer implicitly available to every agent, so before upgrading, verify your admin roles/config or legitimate automation will silently lose execution capability — the gate fails closed for non-admin contexts until explicitly granted.
  • Plugin compatibility metadata (#5235) — Plugins can now declare astrbot-version plus platform requirements, which the host validates at load time. Plugin authors should add these fields to manifests to get clean compatibility errors instead of opaque runtime crashes; operators gain an early signal when a plugin targets a mismatched core. It's opt-in for existing plugins, but adopting it is what makes the ecosystem manageable.
  • MCP tools fully exposed to the main agent (#5252) — Persona-level tool selection no longer filters MCP tools out of the main agent; the full MCP toolset is now exposed. This is a real behavioral change: personas that relied on tool selection to constrain capabilities will suddenly see more tools, so re-audit persona configs for prompt bloat and unintended tool access. The same release also drops additionalProperties from tool-schema properties (#5253), fixing validation against strict providers — relevant if you hand-author tool schemas.
  • WeChat OA passive replies reworked (#5224) — Passive replies now use buffering plus chunked responses with tuned timeout behavior. For WeChat Official Account bots this directly cuts dropped/duplicated replies under slow generation; watch chunk-boundary behavior if your bot emits large payloads, since responses now arrive in pieces rather than one shot.
  • Session lifecycle and message reliability (#5225, #5208, #5250) — Reset/new/delete now terminate active events, killing stale in-flight responses so they can't leak into a fresh conversation — deterministic state for anyone driving sessions programmatically, but note that previously-cancelable work is now actively killed. Companion fixes cover empty-message errors when only JSON segments are sent (#5208) and residual JSON leaking through dict-format content (#5250), tightening message handling end to end.
  • Desktop shifts from Electron to Tauri (#5226) — The Electron desktop pipeline has been removed and desktop development moved to the Tauri repository. This is the main migration item in the release: Electron-based builds or forks pinned to this repo will no longer get updates here, so track the new Tauri repo if you ship or depend on the desktop app.

What's Changed

新增

  • 新增 Python / Shell 执行工具的管理员权限校验，提升高风险操作安全性 (#5214)。
  • 新增插件 astrbot-version 与平台版本要求校验支持，增强插件兼容性管理能力 (#5235)。
  • 账号密码修改流程新增“确认新密码”校验，减少误输导致的配置问题 (#5247)。

修复

  • 修复 MCP 工具完整暴露给主 Agent，无视人格 tool 选择的问题 (#5252)。
  • 改进微信公众号被动回复处理机制，引入缓冲与分片回复并优化超时行为，提升回复稳定性 (#5224)。
  • 修复仅发送 JSON 消息段时可能触发空消息回复报错的问题 (#5208)。
  • 修复会话重置/新建/删除时未终止活动事件导致的陈旧响应问题 (#5225)。
  • 修复 provider 在 dict 格式 content 场景下可能残留 JSON 内容的问题 (#5250)。
  • 修复工具 schema 属性中的 additionalProperties 配置问题 (#5253)。
  • 优化账号编辑校验错误提示，简化并统一用户名/密码为空场景返回信息。

优化

  • 优化 PersonaForm 布局与工具选择展示，并完善工具停用状态的本地化显示。

其他

  • 移除 Electron Desktop 流水线并迁移到 Tauri 仓库 (#5226)。
  • 更新相关仓库链接与功能请求模板文案，统一中英文表达。
  • 移除过时文档文件 heihe.md。

What's Changed (EN)

New Features

  • Added admin permission checks for Python/Shell execution tools to improve safety for high-risk operations (#5214).
  • Added support for astrbot-version and platform requirement checks for plugins to improve compatibility management (#5235).
  • Added password confirmation when changing account passwords to reduce misconfiguration caused by typos (#5247).

Fixes

  • Improved passive reply handling for WeChat Official Accounts with buffering/chunking and timeout behavior optimizations for better stability (#5224).
  • Fixed an empty-message reply error when only JSON message segments were sent (#5208).
  • Fixed stale responses by terminating active events on reset/new/delete operations (#5225).
  • Fixed residual JSON content issues in provider handling when content was in dict format (#5250).
  • Fixed incomplete exposure of MCP tools to the main agent (#5252).
  • Fixed additionalProperties handling in tool schema properties (#5253).
  • Simplified and unified account-edit validation error responses for empty username/password scenarios.

Improvements

  • Enhanced PersonaForm layout and tool selection display, and improved localized labels for inactive tools.

Others

  • Removed the Electron desktop pipeline and switched to the Tauri repository (#5226).
  • Updated related repository links and refined feature request template wording in both Chinese and English.
  • Removed outdated documentation file heihe.md.
