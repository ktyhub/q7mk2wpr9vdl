#AstrBot v4.21.0

¿Qué ha cambiado?

Nuevo

  • Se agregaron filtros de categorías y componentes de interfaz optimizados para el mercado de complementos. (#6762)
  • Se agregó el proveedor del plan de codificación Kimi (compatible con Anthropic API). (#6559)
  • Archivos unificados y renombrados skill.md a SKILL.md. (#6757)
  • Se agregó el interruptor del modo de pensamiento de Ollama. (#5941)
  • Se agregó el proveedor Xiaomi MiMo TTS y STT. (#6643)
  • Se agregaron capacidades de conteo de tokens de contexto multimodal (imágenes, audio y cadenas de pensamiento). (#6596)
  • Se agregó la capacidad de instalar complementos por nombre de metainformación y verificar identificadores importables. (#6530)

Optimización

  • Se redujo kook_type en StrEnum a (str, Enum) para compatibilidad con la versión anterior Python. (#6512)
  • Optimice el procesamiento de mensajes de WebChat: guarde los mensajes con anticipación y mejore la finalización de la transmisión. (#6698)
  • Optimice el diseño del selector de personas móviles en el Panel de control. (#5907)
  • Optimice el Panel, reduzca el rango de fuentes de los íconos MDI y hospede automáticamente las fuentes de Google. (#6532)
  • Utilice Pydantic para reconstruir el modelo de datos del adaptador KOOK para mejorar el rendimiento de verificación y análisis de la estructura de mensajes. (#5719)
  • Ajustar la terminología y expresiones del documento (cambiar "plataforma de mensajes" por "robot", etc.) y optimizar y actualizar el texto de descripción. (#6568)

AstrBot v4.21.0

Highlights

  • Skill packaging migration — Legacy skill.md files are normalized to SKILL.md (#6757), so existing skills should migrate automatically; plugin authors should still audit case-sensitive references. Multiline frontmatter, Windows encoding, and cached-sandbox path fixes (#6460, #6058, #6331) make skill loading more reliable across environments.
  • Provider and plugin expansion — Kimi Coding Plan adds Anthropic-compatible access (#6559), Xiaomi MiMo adds TTS/STT (#6643), and Ollama can now disable thinking (#5941). Plugin-market category filtering and metadata-name installation with import-identifier validation (#6762, #6530) make discovery and installation less error-prone.
  • OpenAI-compatible configuration — The provider label becomes “OpenAI Compatible” (#6707). Embedding requests send dimensions only when explicitly configured (#6432), and OpenAI embedding base URLs no longer receive an automatic /v1 suffix (#6669); custom endpoints that relied on implicit suffixing must include it explicitly.
  • Cancellation and subagent lifecycle — /stop now rejects follow-ups, clears persisted follow-up state, and interrupts subagent tool waits (#6704, #6656, #5850). tool_call_timeout now reaches handoff, cron, and background tasks, with the default raised from 60s to 120s (#6713)—long-running jobs get more headroom, but automations must treat /stop as terminal for pending follow-ups.
  • Context and integration reliability — Token accounting now covers images, audio, and chain-of-thought (#6596); truncation preserves the sole user message to prevent provider 400 responses (#6198, #6581), and Gemini array schemas always include items (#6051). SQLite busy timeouts, Telegram polling recovery, Windows MCP/native-build fixes, and KOOK’s Pydantic and older-Python compatibility changes reduce platform-specific failures (#6474, #6648, #5822, #6575, #5719, #6512).
  • Compatibility — No declared breaking changes.

What's Changed

新增

  • 为插件市场新增分类筛选并优化界面组件。（#6762）
  • 新增 Kimi Coding Plan Provider（兼容 Anthropic API）。（#6559）
  • 统一并重命名 skill.md 文件为 SKILL.md。（#6757）
  • 新增 Ollama 关闭思考模式开关。（#5941）
  • 新增小米 MiMo TTS 与 STT Provider。（#6643）
  • 新增多模态上下文 token 计数能力（图片、音频与思维链）。（#6596）
  • 新增按元信息名称安装插件并校验可导入标识符。（#6530）

优化

  • 降低 kook_type 中 StrEnum 到 (str, Enum) 以兼容旧版本 Python。（#6512）
  • 优化 WebChat 消息处理：提前保存消息并增强流式补全。（#6698）
  • 优化 Dashboard 中移动端 persona 选择器布局。（#5907）
  • 优化 Dashboard，减少 MDI icon font 范围并自托管 Google Fonts。（#6532）
  • 使用 Pydantic 重构 KOOK 适配器数据模型以提升消息结构解析与校验性能。（#5719）
  • 调整文档术语与表达（“消息平台”改为“机器人”等）并优化更新说明文字。（#6568）

修复

  • 修复 web search tools 中被禁用系统函数时未正确生效的问题。（#6584）
  • 跳过空的知识库嵌入批次，避免不必要计算。（#6106）
  • 修复 Feishu opus 文件在 Whisper API STT 场景下未正确转换的问题。（#6078）
  • 修复 Lark 在工具调用中断时卡片创建与重续流程。（#6743）
  • 修复 Windows 环境下 skill 文件编码兼容问题。（#6058）
  • 修复 WebChat 单独渲染的 HTML 回复被错误显示的问题。（#6074）
  • 修复 Gemini 数组 schema 缺少 items 字段的问题。（#6051）
