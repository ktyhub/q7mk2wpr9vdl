#AstrBot v4.29.3

[4.29.3] - 2026-10-24

La vida es como una caja de bombones.

Nuevo

  • Seguimiento de mensajes: mejorar aún más la capacidad de seguimiento de mensajes, admitiendo el registro y observación de todos los eventos de mensajes entrantes, así como las llamadas de complemento y llamadas de Agente correspondientes a los eventos. (Primero debe activarse en la configuración en la esquina inferior izquierda de WebUI) (#10614)
  • Exportación de diagnóstico: admite la exportación de un paquete de diagnóstico del sistema no sensible desde la consola y la configuración del sistema, incluidos registros, seguimiento, configuración, estado del complemento, entorno y otra información. (#10418, #10659)
  • Script de instalación: se agregó un proceso de instalación en varios idiomas y compatibilidad con imágenes de China continental. (#10629)

Arreglar

  • Copia de seguridad: complete la copia de seguridad y recuperación de tareas programadas, archivos persistentes y directorios de datos relacionados para evitar la pérdida de datos. (#10644, #10661)
  • Gemini: admite parámetros de generación personalizados de modelos, conservando valores cero establecidos explícitamente; soluciona el problema de incompatibilidad del esquema de herramientas causado por la enumeración sin cadenas. (#10719, #10635)
  • NVIDIA Rerank: conserva las rutas de los puntos finales API específicas del modelo para evitar solicitar la dirección universal incorrecta. (#10732)
  • Uso de PC: Se corrigió el análisis de los resultados de ejecución de Shipyard Bay y la limpieza de procesos secundarios en el tiempo de espera o cancelación de Windows Shell. (#10671, #10729)
  • WebUI: Se corrigió la pérdida de metadatos del modelo después de la actualización de la configuración, la selección del modelo de chat predeterminado, la localización del nombre de la barra lateral del complemento, las notificaciones de actualización del escritorio y los valores predeterminados del campo de la plantilla de configuración. (#10522, #10663, #10576, #10622, #10517)
  • WebUI: optimice la visualización de instrucciones de configuración y opciones condicionales, corrija la ventana emergente de instalación de Pip en el registro de pantalla completa, registre la conexión de flujo en espera y los registros duplicados después de cambiar de página, y aclare el rango de filtrado del complemento. (#10647, #10608, #10666, #10694, #10691)
  • Base de datos: utilice expresiones de consulta JSON compatibles con bases de datos cruzadas. (#10664)

Agregado

  • Seguimiento de mensajes: seguimiento mejorado para registrar e inspeccionar todos los eventos de mensajes entrantes y sus complementos asociados y llamadas de agentes. Habilítelo primero en Configuración en la esquina inferior izquierda de la WebUI. (#10614)
  • Diagnóstico: exporte paquetes de diagnóstico del sistema con soporte de redacción desde la consola y la configuración del sistema, incluidos registros, seguimientos, configuración, estado del complemento e información del entorno. (#10418, #10659)
  • Instalador: Se agregó configuración multilingüe y espejos de China continental. (#10629)

Fijo

  • Copias de seguridad: incluya tareas programadas, archivos persistentes y directorios de datos relacionados en las operaciones de copia de seguridad y restauración. (#10644, #10661)
  • Gemini: respeta los parámetros de generación específicos del modelo y los valores cero explícitos, y maneja enumeraciones que no son cadenas en esquemas de herramientas. (#10719, #10635)
  • NVIDIA Rerank: preserva las rutas de los puntos finales específicas del modelo en lugar de sustituir un punto final genérico. (#10732)
  • Uso de la computadora: analiza correctamente los sobres de ejecución de Shipyard Bay y limpia los procesos secundarios del shell de Windows en caso de tiempo de espera o cancelación. (#10671, #10729)
  • WebUI: conserva los metadatos del modelo recuperado después de la actualización de la configuración; restaurar la selección del modelo de chat predeterminado; localizar los nombres de la barra lateral de los complementos; corregir avisos de actualización de escritorio y valores predeterminados de campos de plantilla. (#10522, #10663, #10576, #10622, #10517)
  • WebUI: aclara sugerencias de configuración y configuraciones condicionales; mantenga el cuadro de diálogo Pip visible en los registros de pantalla completa; vaciar los encabezados de los flujos de registro rápidamente; evitar registros duplicados después de la navegación; aclarar el alcance del filtro del complemento. (#10647, #10608, #10666, #10694, #10691)
  • Base de datos: utilice expresiones de consulta JSON portátiles. (#10664)

AstrBot v4.29.3

Highlights

  • End-to-end message tracing — Inbound events now link to their plugin and Agent calls, making multi-step message flows easier to debug. Tracing is opt-in via the WebUI’s lower-left Settings and adds bounded SQLite history to limit local growth (#10614).
  • Redacted diagnostic bundles — Export logs, traces, configuration, plugin status, and environment details from the console or system settings, with sensitive data redacted for support tickets and bug reports (#10418, #10659).
  • More complete backups — Scheduled tasks, persistent files, and associated data directories are now included in backup/restore operations. Recreate backup artifacts after upgrading if you previously relied on incomplete archives (#10644, #10661).
  • Gemini generation and tool-schema fixes — Model-specific generation parameters now apply, including explicitly set zero values that were previously discarded. Non-string enum handling also prevents incompatible tool schemas, reducing failures in function-calling workflows (#10719, #10635).
  • Provider endpoint and execution fixes — NVIDIA Rerank retains model-specific endpoint paths rather than falling back to a generic URL (#10732). Computer-use fixes correctly unwrap Shipyard Bay execution envelopes (#10671) and clean up Windows shell child processes on timeout or cancellation (#10729).
  • WebUI and cross-database reliability — Model metadata survives configuration refresh, default chat-model selection is restored, and SSE/log handling avoids delayed streams and duplicate entries after navigation (#10522, #10663, #10666, #10694). Portable JSON queries improve compatibility across database backends (#10664).

No breaking changes.

[4.29.3] - 2026-10-24

Life is like a box of chocolates.

新增

  • 消息追踪：进一步完善消息追踪能力，支持记录和观测所有入站消息事件，以及事件对应的插件调用和 Agent 调用。（需要先在 WebUI 左下角设置中开启） (#10614)
  • 诊断导出：支持从控制台和系统设置导出支持脱敏的系统诊断包，包含日志、追踪、配置、插件状态和环境等信息。 (#10418, #10659)
  • 安装脚本：新增多语言安装流程和中国大陆镜像支持。 (#10629)

修复

  • 备份：补全定时任务、持久化文件和相关数据目录的备份与恢复，避免数据遗漏。 (#10644, #10661)
  • Gemini：支持模型自定义生成参数，保留显式设置的零值；修复非字符串枚举导致工具 Schema 不兼容的问题。 (#10719, #10635)
  • NVIDIA Rerank：保留模型专属 API 端点路径，避免请求错误的通用地址。 (#10732)
  • 电脑使用：修复 Shipyard Bay 执行结果的解析，以及 Windows Shell 超时或取消时的子进程清理。 (#10671, #10729)
  • WebUI：修复配置刷新后模型元数据丢失、默认聊天模型选择、插件侧栏名称本地化、桌面更新通知和配置模板字段默认值。 (#10522, #10663, #10576, #10622, #10517)
  • WebUI：优化配置说明与条件选项显示，修复全屏日志中的 Pip 安装弹窗、日志流连接等待和页面切换后的重复日志，并明确插件筛选范围。 (#10647, #10608, #10666, #10694, #10691)
  • 数据库：使用跨数据库兼容的 JSON 查询表达式。 (#10664)

Added

  • Message tracing: Improved tracing to record and inspect all incoming message events and their associated plugin and Agent calls. Enable it first in Settings in the lower-left corner of the WebUI. (#10614)
  • Diagnostics: Export system diagnostic bundles with redaction support from the console and system settings, including logs, traces, configuration, plugin status, and environment information. (#10418, #10659)
  • Installer: Added multilingual setup and mainland China mirrors. (#10629)

Fixed

  • Backups: Include scheduled tasks, persistent files, and related data directories in backup and restore operations. (#10644, #10661)
  • Gemini: Honor model-specific generation parameters and explicit zero values, and handle non-string enums in tool schemas. (#10719, #10635)
  • NVIDIA Rerank: Preserve model-specific endpoint paths instead of substituting a generic endpoint. (#10732)
  • Computer use: Parse Shipyard Bay execution envelopes correctly and clean up Windows shell child processes on timeout or cancellation. (#10671, #10729)
  • WebUI: Preserve fetched model metadata after configuration refresh; restore default chat model selection; localize plugin sidebar names; fix desktop update notices and template field defaults. (#10522, #10663, #10576, #10622, #10517)
  • WebUI: Clarify configuration hints and conditional settings; keep the Pip dialog visible in fullscreen logs; flush log stream headers promptly; prevent duplicate logs after navigation; clarify plugin filter scope. (#10647, #10608, #10666, #10694, #10691)
  • Database: Use portable JSON query expressions. (#10664)
