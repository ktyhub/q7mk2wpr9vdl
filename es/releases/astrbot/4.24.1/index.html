#AstrBot v4.24.1

  • Registro de actualización (chino simplificado)
  • Changelog(inglés) <a id="chino"></a>

Lanzaremos una mejor plataforma de gestión e intercambio de complementos de AstrBot, ¡así que estad atentos!

¿Qué ha cambiado?

Nuevo

  • Se agregó la capacidad de que los complementos personalicen las páginas WebUI (Páginas de complementos). Los complementos pueden exponer páginas personalizadas al Panel a través del directorio pages/ y rutas web registradas. Consulte la documentación de desarrollo para obtener más detalles. (#5940)
  • Se agregó soporte de internacionalización de complementos. El complemento puede proporcionar nombres, descripciones y textos de configuración en varios idiomas en .astrbot-plugin/i18n, y el componente Panel se analizará y mostrará según el idioma actual. Consulte la documentación de desarrollo para obtener más detalles. (#7919)
  • Se agregó soporte para habilidades de complementos, y los complementos pueden proporcionar habilidades a través de skills/. (#7945). Consulte la documentación de desarrollo para obtener más detalles.
  • Se agregó la marca de contenido temporal extra_user_content_parts. Los complementos pueden usar TextPart(...).mark_as_temp() para permitir que contenido adicional participe solo en esta ronda de solicitudes de LLM sin escribir en el historial de la sesión. (#7976). Consulte la documentación de desarrollo del complemento para obtener más detalles.
  • Se agregó la página de detalles del complemento, una breve descripción del complemento, la parte superior del complemento y la capacidad de descargar complementos a través del almacenamiento oficial de complementos de AstrBot para mejorar la instalación del complemento y la experiencia de navegación. (#7896, #7918, #7930, #7931)
  • Configuración fallback_max_context_tokens agregada. Cuando faltan metadatos del modelo y max_context_tokens es 0, se puede utilizar el límite superior de la ventana de contexto predeterminado para participar en el juicio de compresión. El valor predeterminado es 128k. (#7942)
  • Admite la visualización y edición de archivos de habilidades en la página de habilidades de WebUI. (#7903)
  • Se agregó el tiempo de ejecución de CUA Computer Use sandbox, que admite GUI de escritorio, capturas de pantalla, teclado, mouse, proceso de inicio del navegador, Shell frontal y posterior, procesamiento de reversión de archivos y control de permisos, y complementa la documentación y las pruebas de uso. (#7828)
  • Se agregó ejecución de comandos de Shell en segundo plano, redirección de salida y soporte de tiempo de espera, y se agregó un parámetro de tiempo de espera para la herramienta Python. (#7835, #7953)
  • Se agregaron capacidades de control de Markdown a nivel de mensajes de la plataforma oficial QQ. (#6980)
  • Se agregaron eventos para guardar archivos adjuntos para el enrutamiento de chat y chat en vivo, y la interfaz puede detectar los resultados de persistencia de los archivos adjuntos. (#7869)
  • Se agregó un nuevo script de implementación para admitir la instalación con un solo clic de Linux/macOS/WSL y Windows PowerShell, y se publicó el script en el directorio público de documentos. (#7631)

Optimización

  • Optimice el diseño, el estilo de la tarjeta, el rendimiento responsivo y la redacción en varios idiomas de la extensión del Panel de control, la base de conocimientos, MCP, las habilidades y las páginas de configuración. (#7903)
  • Optimice la representación de llamadas a herramientas en el historial de sesiones. Los mensajes de herramientas ya no se representan directamente en Markdown como burbujas ordinarias, sino que se agregan en tarjetas de herramientas correspondientes al asistente para evitar el retraso de la página causado por resultados de herramientas grandes. (#7937)
  • Estrategia de compresión y gestión de contexto optimizada, que incluye algoritmo de truncamiento, solución de problemas de eliminación de mensajes de usuario, identificación de errores de longitud de contexto PPIO y descripción de la interfaz de configuración del orden de ejecución. (#7888, #7920)
  • Optimice la lógica de adición del modelo del proveedor, la persistencia del conmutador de habilitación del modelo, los mensajes de falla de la prueba del proveedor y las advertencias de inicio cuando el proveedor predeterminado falta o no es válido. (#7865, #7498, #7934)
  • Optimice las indicaciones y la tolerancia a fallas de send_message_to_user en modo seguro, cronifique tareas y escenarios activos sin formato de sesión completo y agregue información de sesión a la carga útil de cron. (#7907, #7911)
  • Optimice el elemento de configuración de lista+opciones, use v-autocomplete en su lugar y almacene en caché los candidatos para mejorar la experiencia de selección de listas largas. (#7884, #7885)
  • Optimice la visualización de descripciones de comandos y herramientas, y las descripciones truncadas en WebUI ahora se pueden ver a través de información sobre herramientas. (#7838)
  • Estadísticas de indicadores de optimización, legibilidad de registros, documentos de base de conocimientos, documentos de Word de indicaciones del sistema e instrucciones de desarrollo previas a la confirmación en AGENTS.md. (#7838, #7962)

Arreglar

  • Corrija la regresión de representación de la plantilla de texto T2I, restaure la representación del texto original, inyecte el tiempo de ejecución de Shiki de forma predeterminada y ajuste las plantillas integradas y las vistas previas de WebUI. (#7875, #7587)
  • Se solucionó el problema de compatibilidad entre los tipos httpx http_client y SDK de proveedor OpenAI. (#7773)
  • Se solucionó el problema por el cual el controlador posterior continúa ejecutándose después de stop_event() y el estado de detención se restablece debido a clear_result(). (#7900, #7922)
  • Se solucionó el problema por el cual se reportaba un error al inyectar mensajes de personalidad o habilidades cuando system_prompt se cambiaba a None. (#7880)
  • Se corrigió la detección de preparación del sandbox de Shipyard Neo y la limpieza elegante para evitar excepciones al continuar ejecutando o cerrando procesos cuando no está listo. (#7881)
  • Se solucionó el problema de simultaneidad en la instalación del complemento de escritorio; el proceso de instalación ahora está protegido por bloqueo de núcleo. (#7872)
  • Se solucionó el problema por el cual el envío activo del chat privado oficial de QQ omitía el envío cuando faltaba el caché msg_id, mientras se conservaba la verificación del caché del chat grupal. (#7904, #7914)
  • Se corrigió la compatibilidad con mensajes de archivos de servicio al cliente de WeChat y se eliminó el texto del marcador de posición de los mensajes de archivos corporativos de WeChat. (#7923)
  • Se solucionó el problema por el cual la tarea DingTalk SDK salía de manera anormal o no se reconectaba automáticamente después de que se agotaba el tiempo de conexión. (#7924)

AstrBot v4.24.1

Highlights

  • Plugin platform expansion — Plugin Pages expose Dashboard UI through pages/, with asset authentication, bridge integration and back-navigation handling (#5940). Plugins can also ship localized metadata/configuration via .astrbot-plugin/i18n (#7919) and synchronized, configuration-aware skills through skills/ (#7945), making plugins more self-contained extensions rather than backend-only add-ons.

  • Request-only LLM context — TextPart(...).mark_as_temp() adds content to the current LLM request without persisting it in conversation history (#7976). This is useful for transient retrieval results or one-turn hints; content needed in later turns or audit history must still be persisted normally.

  • Computer-use and shell automation — The CUA sandbox adds desktop GUI control, screenshots, keyboard/mouse input, browser startup, filesystem fallbacks and permission handling (#7828). Background shell execution, output redirection, command timeouts and a Python-tool timeout parameter support longer-running workflows (#7835, #7953); adopters should explicitly constrain permissions and execution limits.

  • Security boundary for user messaging — send_message_to_user no longer lets ordinary users target arbitrary sessions; they are restricted to the current session, while administrators retain cross-session targeting (#7824). Workflows that allowed end users to select another session must be redesigned, but this closes a direct cross-session messaging vulnerability.

  • Context and provider resilience — fallback_max_context_tokens now supplies a configurable compression limit—defaulting to 128k—only when model metadata is missing and max_context_tokens is 0 (#7942). Set it to the actual model window to avoid delayed compression on smaller-context models. Related fixes improve truncation, PPIO context-length detection, Anthropic parallel tool-result merging and Anthropic/OpenAI httpx compatibility (#7888, #7920, #7875, #7773).

  • Tool-selection and cancellation semantics — tool_choice is temporarily omitted to avoid incompatible providers (#7862), so workflows relying on provider-enforced tool selection need verification. Separately, stop_event() now prevents later handlers from running, and clear_result() no longer resets the stopped state (#7900, #7922); plugins should review cancellation logic that depended on the previous behavior.

  • 新增插件自定义 WebUI 页面（Plugin Pages）能力，插件可通过 pages/ 目录和注册 Web 路由来向 Dashboard 暴露自定义页面。详见开发文档。（#5940）
  • 新增插件国际化支持，插件可在 .astrbot-plugin/i18n 中提供多语言名称、描述和配置文本，Dashboard 组件会按当前语言解析展示。详见开发文档。（#7919）
  • 新增插件技能支持，插件可通过 skills/ 提供 skills。（#7945）。详见开发文档。
  • 新增 extra_user_content_parts 临时内容标记，插件可使用 TextPart(...).mark_as_temp() 让追加内容只参与本轮 LLM 请求而不写入会话历史。（#7976）。详见插件开发文档。
  • 新增插件详情页、插件短描述、插件置顶，以及通过 AstrBot 官方插件存储下载插件的能力，改善插件安装与浏览体验。（#7896, #7918, #7930, #7931）
  • 新增 fallback_max_context_tokens 配置，当模型元数据缺失且 max_context_tokens 为 0 时，可使用默认上下文窗口上限参与压缩判断。该值默认为 128k。（#7942）
  • 支持在 WebUI Skills 页中查看并编辑技能文件。（#7903）
  • 新增 CUA Computer Use 沙盒运行时，支持桌面 GUI、截图、键盘、鼠标、浏览器启动流程、前后台 Shell、文件回退处理与权限控制，并补充使用文档和测试。（#7828）
  • 新增后台 Shell 命令执行、输出重定向和超时支持，并为 Python 工具增加 timeout 参数。（#7835, #7953）
  • 新增 QQ 官方平台消息级 Markdown 控制能力。（#6980）
  • 新增 Chat 与 Live Chat 路由的附件保存事件，前端可感知附件持久化结果。（#7869）
  • 新增部署脚本，支持 Linux/macOS/WSL 与 Windows PowerShell 一键安装，并将脚本发布到 docs public 目录。（#7631）

优化

  • 优化 Dashboard 扩展、知识库、MCP、技能和配置页面的布局、卡片样式、响应式表现与多语言文案。（#7903）
  • 优化会话历史中的工具调用渲染，工具消息不再作为普通气泡直接进行 Markdown 渲染，而是聚合到对应 assistant 的工具卡片中，避免大工具结果导致页面卡顿。（#7937）
  • 优化上下文管理与压缩策略，包括截断算法、用户消息删除问题修复、PPIO 上下文长度错误识别，以及配置界面对执行顺序的说明。（#7888, #7920）
  • 优化 Provider 模型添加逻辑、模型启用开关持久化、Provider 测试失败提示，以及默认 Provider 缺失或无效时的启动警告。（#7865, #7498, #7934）
  • 优化 send_message_to_user 在安全模式、cron 主动任务和无完整 session 格式场景下的提示与容错，并为 cron payload 增加 session 信息。（#7907, #7911）
  • 优化 list+options 配置项，改用 v-autocomplete 并缓存候选项，改善长列表选择体验。（#7884, #7885）
  • 优化命令与工具描述显示，WebUI 中被截断的描述现在可通过 tooltip 查看。（#7838）
  • 优化指标统计、日志可读性、知识库文档、系统提示词文档，以及 AGENTS.md 中的 pre-commit 开发说明。（#7838, #7962）

修复

  • 修复 send_message_to_user 可被普通用户指定任意 session 发送消息的安全问题；普通用户只能发送到当前会话，管理员仍可指定 session。（#7822, #7824）
  • 修复 T2I 文本模板渲染回归，恢复原始文本渲染，默认注入 Shiki runtime，并调整内置模板和 WebUI 预览。（#7789）
  • 修复 IME 输入法组合状态下按 Enter 会误发送聊天的问题。（#7845）
  • 修复 Anthropic 并行工具结果合并、自定义请求头和 system prompt 兼容性，避免多 httpx 安装导致 client 类型不匹配，并使用列表格式 system 参数提升代理兼容性。（#7875, #7587）
  • 修复 OpenAI Provider 的 http_client 与 SDK httpx 类型兼容问题。（#7773）
  • 修复 stop_event() 后后续 handler 仍继续执行，以及 clear_result() 导致停止状态被重置的问题。（#7900, #7922）
  • 修复 system_prompt 为 None 时注入人格或 skills prompt 会报错的问题。（#7880）
  • 修复 Shipyard Neo 沙盒就绪检测和优雅清理，避免未就绪时继续运行或关闭流程异常。（#7881）
  • 修复桌面端插件安装并发问题，安装过程现在受核心锁保护。（#7872）
  • 修复 QQ 官方私聊主动推送在缺少缓存 msg_id 时跳过发送的问题，同时保留群聊缓存校验。（#7904, #7914）
  • 修复微信客服文件消息支持，并移除企业微信文件消息占位文本。（#7923）
  • 修复钉钉 SDK 任务异常退出或连接超时后无法自动重连的问题。（#7924）
  • 修复 PowerShell 安装脚本 BOM、部署脚本路径、.gitignore 与公开目录同步问题。
  • 修复工具调用 tool_choice 相关调试问题，暂时注释该参数以规避部分 Provider 不兼容。（#7853, #7856, #7862）

What's Changed (EN)

New Features

  • Added the CUA Computer Use sandbox runtime with desktop GUI, screenshots, keyboard, mouse, browser startup flow, foreground/background shell support, filesystem fallbacks, permission handling, docs, and tests. (#7828)
  • Added Plugin Pages, allowing plugins to expose Dashboard pages through a pages/ directory with asset authentication, bridge script, back-button behavior, docs, and security tests. (#5940)
  • Added plugin internationalization support through .astrbot-plugin/i18n, including localized names, descriptions, config text, Dashboard integration, docs, and tests. (#7919)
  • Added plugin-provided skills with synchronization, metadata enrichment, plugin detail display, and configuration-aware filtering. (#7945)
  • Added the plugin detail page, plugin short descriptions, plugin pinning, and support for downloading plugins from AstrBot official plugin storage. (#7896, #7918, #7930, #7931)
  • Added background shell command execution with output redirection and timeout support, and added a timeout parameter to the Python tool. (#7835, #7953)
  • Added fallback_max_context_tokens, used when model metadata is missing and max_context_tokens is set to 0. (#7942)
  • Added message-level Markdown control for QQ Official. (#6980)
  • Added attachment saved events for Chat and Live Chat routes. (#7869)
  • Added Linux/macOS/WSL and Windows PowerShell deployment scripts, published through the docs public directory. (#7631)
  • Added temporary extra_user_content_parts; plugins can use TextPart(...).mark_as_temp() to include content in the current LLM request without persisting it into conversation history. (#7976)

Improvements

  • Improved the Dashboard extension, knowledge base, MCP, skills, and config pages with better layouts, card styles, responsiveness, translations, and skill-file editing in WebUI. (#7903)
  • Improved tool rendering in conversation history by grouping tool messages into the assistant tool card instead of rendering large tool results as normal Markdown bubbles. (#7937)
  • Improved context management and compression, including truncation behavior, user-message retention, PPIO context-length error detection, and clearer UI copy for execution order. (#7888, #7920)
  • Improved Provider model adding logic, model enable-toggle persistence, failed provider-test feedback, and startup warnings for missing or invalid default providers. (#7865, #7498, #7934)
  • Improved send_message_to_user prompts and tolerance in safety mode, cron proactive tasks, and incomplete session formats; cron payloads now include session information. (#7907, #7911)
  • Improved list+options config fields by switching to v-autocomplete and memoizing select items for better long-list selection. (#7884, #7885)
  • Improved truncated command and tool descriptions in WebUI by adding tooltip access. (#7838)
  • Improved metrics, log clarity, knowledge base docs, system prompt docs, and AGENTS.md pre-commit setup guidance. (#7838, #7962)

Bug Fixes

  • Fixed a security issue where normal users could ask send_message_to_user to send messages to arbitrary sessions; normal users are now restricted to the current session while admins can still target other sessions. (#7822, #7824)
  • Fixed T2I text template rendering by restoring raw text rendering, injecting Shiki runtime by default, and updating built-in templates and preview behavior. (#7789)
  • Fixed Enter key handling during IME composition in chat input. (#7845)
  • Fixed Anthropic parallel tool-result merging, custom headers, and system prompt compatibility by using default_headers and list-format system prompts. (#7875, #7587)
  • Fixed OpenAI Provider http_client compatibility with SDK httpx. (#7773)
  • Fixed stop_event() allowing later handlers to continue, and fixed stop-state reset caused by clear_result(). (#7900, #7922)
  • Fixed persona and skills prompt injection when system_prompt is None. (#7880)
  • Fixed Shipyard Neo readiness gating and graceful sandbox cleanup. (#7881)
  • Fixed concurrent desktop plugin installation by protecting installs with the core lock. (#7872)
  • Fixed QQ Official private proactive push being skipped when cached msg_id is missing, while preserving group-message cache validation. (#7904, #7914)
  • Fixed WeChat kefu file messages and removed the WeCom file-message placeholder. (#7923)
  • Fixed DingTalk reconnect failures after SDK task exits or connection timeouts. (#7924)
  • Fixed the PowerShell install script BOM, deploy script paths, .gitignore, and public-directory sync issues.
  • Fixed provider incompatibilities around tool_choice by temporarily commenting out the parameter for debugging. (#7853, #7856, #7862)
