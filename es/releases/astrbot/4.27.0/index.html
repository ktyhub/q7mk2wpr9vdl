#AstrBot v4.27.0

[4.27.0] - 2026-08-02

Per aspera ad astra.

Agregado

  • Se agregó un historial de mensajes grupales persistentes con retención configurable, almacenamiento normalizado y una herramienta LLM para buscar y recuperar mensajes del grupo actual. (#9465)
  • Se agregaron sesiones de shell locales administradas con salida incremental, escrituras estándar, interrupción, terminación, tiempos de espera y limpieza del ciclo de vida; Las sesiones de Windows ahora usan PowerShell y los programas orientados a líneas admiten escrituras de líneas explícitas. (#9470, #9471, #9501)
  • Se agregó una extensión unificada y una experiencia de administración de personas con selectores de capacidades compartidas, espacios de trabajo de complementos enrutados y un servidor MCP, herramientas y procedencia y estado de habilidades más claros. (#9499)
  • Se agregaron habilidades skill-creator, documents, pdf y spreadsheets integradas para crear habilidades reutilizables y trabajar con documentos de Office, PDF y hojas de cálculo.
  • Se agregó instalación y actualizaciones para complementos alojados en repositorios Git genéricos de estilo HTTP(S), SSH y SCP. (#9493)
  • ChatUI convertido pega más de 10.000 caracteres en archivos adjuntos de texto. (#9496)
  • Se agregaron subámbitos clave API sensibles para el acceso al chat del administrador y cambios de configuración del administrador, además de documentación de referencia generada desde el alcance hasta el punto final. (#9503)

Cambiado

  • Calidad de recuperación de la base de conocimientos mejorada con fusión normalizada de puntuación relativa densa/escasa y diversificación del documento fuente. (#9455)
  • Incorporaciones de base de conocimientos enriquecidas con contexto de documento y rutas de encabezado preservadas. (#9457)
  • La actualización centralizada del núcleo, el panel y los complementos fluye detrás de una arquitectura de actualización más segura con verificación de paquetes y metadatos. (#9493)
  • Formalizó los API obsoletos existentes con advertencias de tiempo de ejecución y corrigió el nombre del método de conversión de llamada a la herramienta OpenAI manteniendo un alias compatible con versiones anteriores. (#9468, #9469)
  • Se refinaron las tarjetas de habilidades, la gestión de personas, el espacio de trabajo de extensión y los diseños del compositor de chat de proyectos.
  • Se utilizaron nombres de archivos transitorios compactos basados ​​en marcas de tiempo y una guía de ruta relativa al espacio de trabajo más clara para reducir el uso de token de ruta de herramienta. (#9505)
  • Se devolvieron resultados concisos en texto sin formato para los comandos de shell locales completados y al mismo tiempo se conservaron los metadatos de la sesión administrada para los comandos activos. (#9507)

Fijo

  • Se pospuso la importación de dependencias BM25 para que AstrBot pueda iniciar y usar la recuperación FTS5 en CPU incompatibles con la compilación NumPy instalada. (#9435)
  • Se hizo determinista la fusión de rangos de la base de conocimientos y se detectaron fallas de respuesta de reordenamiento de vLLM. (#9454)
  • Se conservaron las colas de respuesta de transmisión de ChatUI y se evitó que los buffers de transmisión oficiales de QQ perdieran caracteres principales. (#9439, #9444)
  • Marcas de tiempo de tareas futuras localizadas con la zona horaria del sistema. (#9462)
  • Sesiones de shell locales administradas aisladas por remitente, al tiempo que se permite a los administradores de conversaciones administrar sesiones en su conversación. (#9479)
  • Límites de autorización de claves API reforzados para identidades de administrador, configuración confidencial y rutas de espacio de trabajo de proyectos. (#9503)
  • Llamadas persistentes a herramientas de terminal, resultados y uso de token trusted cuando no se produce ninguna respuesta del asistente. (#9500)
  • Se evitó que los compositores, respuestas y archivos adjuntos ampliados de ChatUI se superpusieran con los mensajes más recientes. (#9496)
  • Se eliminó la doble barra de desplazamiento del cuadro de diálogo de configuración del complemento móvil. (#9491)
  • Se recreó el directorio de caché de imágenes de la herramienta después de la limpieza del almacenamiento para que aún se puedan guardar nuevas imágenes. (#9490)
  • Se mantuvo disponible el audio oficial TTS y QQ saliente hasta la limpieza global de archivos temporales para que las descargas asincrónicas no fallen. (#9506)

AstrBot v4.27.0

Highlights

  • Durable group context — AstrBot now persists group message history with configurable retention and exposes an LLM tool for searching and retrieving the current group’s messages, enabling assistants to recall prior conversations without retaining history indefinitely. (#9465)
  • Managed shell execution — Local tools can now run interactive sessions with incremental output, stdin writes, interruption, termination, and timeouts. Sessions are isolated by sender while conversation administrators retain management access; Windows switches to PowerShell, so shell-dependent prompts and scripts should be reviewed for cross-platform behavior. (#9470, #9471, #9479, #9501)
  • Better knowledge retrieval — Embeddings now include document context and preserve heading paths, while deterministic normalized dense/sparse score fusion and source-document diversification improve relevance and stability. vLLM rerank failures are now surfaced instead of silently degrading results. (#9454, #9455, #9457)
  • Broader installation sources, safer updates — Plugins can be installed and updated from generic HTTP(S), SSH, and SCP-style Git repositories. Core, dashboard, and plugin updates now share a unified updater with package and metadata verification; review custom repository and update workflows against this new architecture. (#9493)
  • Extension and capability management — A unified extension/persona interface adds routed plugin workspaces and shared capability selectors, alongside clearer MCP server, tool, and Skill provenance. Built-in skill-creator, documents, pdf, and spreadsheets Skills add reusable Skill authoring and office-document workflows out of the box. (#9499)
  • Security and migration notes — API keys now enforce sub-scopes for administrator chat and configuration access, with hardened authorization for sensitive settings and project paths; audit existing tokens and grant only required scopes. Deprecated APIs now emit runtime warnings, and to_openai_to_calls_model is renamed to to_openai_tool_calls_model with a compatibility alias retained. (#9468, #9469, #9503)
  • No breaking changes.

4.27.0 - 2026-08-02

Per aspera ad astra.

Added

  • Added persistent group message history with configurable retention, normalized storage, and an LLM tool for searching and retrieving messages from the current group. (#9465)
  • Added managed local shell sessions with incremental output, stdin writes, interruption, termination, timeouts, and lifecycle cleanup; Windows sessions now use PowerShell and line-oriented programs support explicit line writes. (#9470, #9471, #9501)
  • Added a unified extension and persona management experience with shared capability selectors, routed plugin workspaces, and clearer MCP server, tool, and Skill provenance and status. (#9499)
  • Added built-in skill-creator, documents, pdf, and spreadsheets Skills for creating reusable Skills and working with office documents, PDFs, and spreadsheets.
  • Added installation and updates for plugins hosted in generic HTTP(S), SSH, and SCP-style Git repositories. (#9493)
  • Converted ChatUI pastes longer than 10,000 characters into text attachments. (#9496)
  • Added sensitive API key sub-scopes for administrator chat access and administrator configuration changes, plus generated scope-to-endpoint reference documentation. (#9503)

Changed

  • Improved knowledge base retrieval quality with normalized dense/sparse relative-score fusion and source-document diversification. (#9455)
  • Enriched knowledge base embeddings with document context and preserved heading paths. (#9457)
  • Centralized core, dashboard, and plugin update flows behind a safer updater architecture with package and metadata verification. (#9493)
  • Formalized existing deprecated APIs with runtime warnings and corrected the OpenAI tool-call conversion method name while retaining a backward-compatible alias. (#9468, #9469)
  • Refined the Skills cards, persona management, extension workspace, and project chat composer layouts.
  • Used compact timestamp-based transient filenames and clearer workspace-relative path guidance to reduce tool path token usage. (#9505)
  • Returned concise plain-text results for completed local shell commands while retaining managed-session metadata for active commands. (#9507)

Fixed

  • Deferred the BM25 dependency import so AstrBot can start and use FTS5 retrieval on CPUs incompatible with the installed NumPy build. (#9435)
  • Made knowledge base rank fusion deterministic and surfaced vLLM rerank response failures. (#9454)
  • Preserved ChatUI streaming response tails and prevented QQ Official streaming buffers from losing leading characters. (#9439, #9444)
  • Localized future task timestamps with the system timezone. (#9462)
  • Isolated managed local shell sessions by sender, while allowing conversation administrators to manage sessions in their conversation. (#9479)
  • Hardened API key authorization boundaries for administrator identities, sensitive configuration, and project workspace paths. (#9503)
  • Persisted terminal tool calls, results, and trusted token usage when no assistant response is produced. (#9500)
  • Prevented expanded ChatUI composers, replies, and attachments from overlapping the latest messages. (#9496)
  • Removed the double scrollbar from the mobile plugin configuration dialog. (#9491)
  • Recreated the tool image cache directory after storage cleanup so new images can still be saved. (#9490)
  • Kept outbound TTS and QQ Official audio available until global temporary-file cleanup so asynchronous downloads do not fail. (#9506)

Documentation

  • Added QQ community groups 15 and 16 to the community documentation.

Maintenance

  • Removed an unused tool image cleanup path in favor of the global temporary-directory cleaner. (#9504)
