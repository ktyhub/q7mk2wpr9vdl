¿Qué ha cambiado?

Optimización

  • Fortalezca la seguridad de inicio de sesión y contraseña del Panel: genere una contraseña inicial aleatoria segura en el primer inicio, actualice el almacenamiento de contraseñas a PBKDF2, conserve el antiguo proceso de actualización compatible con MD5 y guíe a los usuarios para completar las actualizaciones de seguridad cuando sea necesario. (#7338)
  • Las capacidades mejoradas de internacionalización de páginas de complementos, las páginas de complementos, las páginas de extensión y la copia del Panel de control relacionada se pueden mostrar mejor en el idioma actual. (#7998)
  • Se agregó la configuración del interruptor del indicador WebUI disable_metrics, que puede desactivar las estadísticas del indicador en el Panel. (#7946)
  • Se agregó persistencia del interruptor de desplazamiento automático de la consola para retener las selecciones del usuario después de actualizar la página. (#8024)
  • Se agregó separación visual entre el contenido del pensamiento y la respuesta final para mejorar la experiencia de lectura del mensaje. (#8059)
  • Optimice la instalación de complementos, la copia de seguridad y la recuperación y el manejo de conflictos de rutas, agregue lógica de autorreparación y reduzca los residuos de directorios temporales y los falsos positivos de seguimiento de errores. (#7737, #8148)
  • Optimice la normalización del directorio raíz zip de Windows Updater y el procesamiento de codificación de la herramienta Python para mejorar la compatibilidad con el entorno de Windows. (#8019)
  • Optimice la lógica de carga de archivos CUA y utilice la interfaz de archivos nativa para manejar las cargas. (#8069)
  • Optimice la capacidad de caducidad de la sesión inactiva de la zona de pruebas de CUA y exponga la configuración del tiempo de espera de inactividad de CUA en el Panel. (#8074, #8075)
  • Optimice el proveedor Gemini para utilizar httpx client administrado. (#8112)
  • Optimice el diseño móvil del panel, la alineación del nivel de registro de la consola y la lógica de visualización del botón de operación de elementos de lista. (#7988, #8081)

Arreglar

  • Se solucionó el problema por el cual la base de conocimientos aún activaba la recuperación bajo un mensaje vacío. (#8073)
  • Se solucionó un problema que afectaría el inicio de la plataforma cuando la sincronización de comandos de Discord alcanza la cuota. (#8061)
  • Se solucionó el problema del nombre de archivo de recursos incorrecto en la URL de descarga alternativa de GitHub. (#8046)
  • Se solucionó el problema de que la relación con los padres se perdiera después de cambiar el nombre de la carpeta. (#7974)
  • Se solucionó el problema por el cual falta websearch_firecrawl_key en la configuración y el campo clave aún se muestra cuando se cierra la búsqueda de Baidu. (#8012, #7992)
  • Se solucionó un problema por el cual el contenido de la plantilla T2I no verificada podía provocar la inyección de Jinja2 SSTI. (#8077)
  • Se corrigió el número máximo de imágenes de contribuyente, ejemplo de documento clave API, descripción del límite de 16 MB de la versión del complemento, insignia README y múltiples errores de documentación de desarrollo del complemento. (#8000, #7977, #8108, #8079, #7979, #8001, #8129, #8166) <a id="inglés"></a>

Qué ha cambiado (ES)

Nuevas características

  • Se agregó el complemento changelog y un sistema de actualización de complementos, lo que permite que las páginas de detalles del complemento muestren información de actualización de la versión y admitan un flujo de actualización de complementos más completo.
  • Internacionalización mejorada de la página de complementos para que las páginas de complementos, las vistas de extensión y la copia del Panel de control relacionada puedan seguir mejor el idioma actual. (#7998)
  • Se agregó la opción de configuración WebUI disable_metrics para deshabilitar la recopilación de métricas desde el Panel. (#7946)
  • Se agregó preferencia de desplazamiento automático de consola persistente. (#8024)
  • Se agregó un separador visual entre el contenido del pensamiento y la respuesta final. (#8059)
  • Se agregó la caducidad de inactividad para las sesiones de espacio aislado de CUA y se expuso la configuración del tiempo de espera de inactividad de CUA en el Panel. (#8074, #8075)

Mejoras

  • Autenticación del Panel de control y seguridad de contraseñas reforzadas: las contraseñas iniciales se generan aleatoriamente, el almacenamiento de contraseñas se actualiza a PBKDF2, la compatibilidad MD5 heredada se conserva para las actualizaciones y los usuarios son guiados a través de las actualizaciones de seguridad cuando es necesario. (#7338)
  • Instalación de complementos mejorada, restauración de copias de seguridad y manejo de conflictos de rutas con comportamiento de autorreparación y menos restos de directorios temporales o informes de errores falsos. (#7737, #8148)
  • Se mejoró la normalización zip-root del actualizador de Windows y el manejo de codificación de la herramienta Python para una mejor compatibilidad con Windows. (#8019)
  • Cargas de CUA mejoradas mediante el uso de interfaces de archivos nativos. (#8069)
  • Se mejoró el proveedor Gemini para usar un httpx client administrado. (#8112)
  • Diseño móvil del panel mejorado, alineación a nivel de registro de la consola y visibilidad del botón de acción de los elementos de la lista. (#7988, #8081)

Corrección de errores

  • Se corrigió la validación faltante para el contenido de la plantilla T2I que podría permitir la inyección de Jinja2 SSTI. (#8077)

AstrBot v4.24.4

Highlights

  • Dashboard password security & MD5→PBKDF2 migration — #7338 replaces MD5 password storage with PBKDF2, generates a random initial password on first launch, and keeps a legacy-MD5 compatibility path for existing installs. What matters for adopters: upgrading won't lock you out, but you'll be guided through a one-time security upgrade — plan for that step and rotate the generated bootstrap password immediately.
  • T2I template SSTI hardening — #8077 adds validation to text-to-image template content that could previously be abused for Jinja2 server-side template injection. If your deployment lets users or plugins supply templates, treat this as a security-boundary fix and prioritize the upgrade.
  • Plugin update system + i18n — plugin detail pages now surface version/changelog information with a fuller update flow, and #7998 extends internationalization to plugin/extension pages and Dashboard copy. For plugin authors and multilingual deployments this improves update discoverability and localization consistency; watch for changed wording in the plugin UI.
  • Privacy: metrics opt-out — #7946 adds the disable_metrics WebUI config to stop anonymous usage collection from the Dashboard. Relevant if you deploy under privacy or data-residency policies — the setting is new, so existing installs may still be reporting telemetry until you flip it.
  • CUA sandbox lifecycle changes — #8074/#8075 add idle expiration for CUA sandbox sessions and expose a CUA idle timeout in the Dashboard, while #8069 moves uploads to native file interfaces. Behavioral change to watch: idle sessions now get reclaimed on a timer, so long-lived agent sandboxes may need the timeout raised.
  • Behavioral reliability fixes — Gemini chat now uses a managed httpx client (#8112), Discord startup no longer aborts when the command-sync quota is hit (#8061), knowledge-base retrieval is skipped for blank prompts (#8073), and folder renames preserve parent relationships (#7974). These alter runtime behavior, not just crash handling — regression-test any workflows that depend on them.

No breaking changes.

优化

  • 优化插件安装、备份恢复与路径冲突处理，增加自愈逻辑并减少临时目录残留和错误追踪误报。（#7737, #8148）

  • 优化 CUA 空闲沙盒会话过期能力，并在 Dashboard 暴露 CUA idle timeout 配置。（#8074, #8075）
  • 优化 Gemini Provider，使其使用受管理的 httpx client。（#8112）
  • 优化 Dashboard 移动端布局、控制台日志级别对齐，以及列表项操作按钮显示逻辑。（#7988, #8081）

修复

  • 修复知识库在空 prompt 下仍触发检索的问题。（#8073）

What's Changed (EN)

New Features

  • Added plugin changelogs and a plugin update system, allowing plugin detail pages to show version update information and supporting a more complete plugin update flow.
  • Enhanced plugin page internationalization so plugin pages, extension views, and related Dashboard copy can better follow the current language. (#7998)
  • Added the disable_metrics WebUI config option to disable metrics collection from the Dashboard. (#7946)
  • Added persisted console auto-scroll preference. (#8024)
  • Added a visual separator between thinking content and the final response. (#8059)
  • Added idle expiration for CUA sandbox sessions and exposed the CUA idle timeout setting in the Dashboard. (#8074, #8075)

Improvements

  • Strengthened Dashboard authentication and password security: initial passwords are generated randomly, password storage is upgraded to PBKDF2, legacy MD5 compatibility is preserved for upgrades, and users are guided through security upgrades when required. (#7338)
  • Improved plugin installation, backup restore, and path-conflict handling with self-healing behavior and fewer temporary-directory leftovers or false error reports. (#7737, #8148)
  • Improved Windows updater zip-root normalization and Python tool encoding handling for better Windows compatibility. (#8019)
  • Improved CUA uploads by using native file interfaces. (#8069)
  • Improved the Gemini Provider to use a managed httpx client. (#8112)
  • Improved Dashboard mobile layout, console log-level alignment, and list-item action-button visibility. (#7988, #8081)

Bug Fixes

  • Fixed missing validation for T2I template content that could allow Jinja2 SSTI injection. (#8077)
  • Fixed knowledge base retrieval being triggered for blank prompts. (#8073)
  • Fixed Discord startup being interrupted by command quota handling. (#8061)
  • Fixed incorrect asset filenames in GitHub fallback download URLs. (#8046)
  • Fixed folder parent relationships being lost on rename. (#7974)
  • Fixed missing websearch_firecrawl_key in the default config and hidden Baidu web-search keys when disabled. (#8012, #7992)
  • Fixed contributor image limits, API Key examples, plugin publishing size-limit docs, README badges, and multiple plugin development guide issues. (#8000, #7977, #8108, #8079, #7979, #8001, #8129, #8166)
