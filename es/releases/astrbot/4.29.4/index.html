#AstrBot v4.29.4

[4.29.4] - 2026-10-31

Nuevo

  • Botón de mensaje: se agrega un nuevo componente de botón multiplataforma, que admite enlaces, envío de mensajes y devoluciones de llamadas de complementos, y proporciona indicaciones de tiempo de espera de interacción. Los tipos de botones admitidos por cada plataforma están sujetos a documentación. (#9809)
  • Modelo de decisión: se agregaron el proveedor de decisiones y el adaptador System One que son independientes del modelo de chat para que los complementos llamen a la selección estructurada, el juicio booleano y la puntuación. (#10775)
  • Búsqueda web: acceda a SerpApi Google News, fuente de noticias compatible, autor, hora de publicación y visualización de citas en WebUI. (#10773)
  • Selección de sesión y usuario: unifique la ventana emergente de selección de fuente de sesión, admita búsqueda de apodos, identificación de plataforma, paginación y copia de identificación; Registre la información del remitente y complete los nombres de los grupos oficiales de Feishu y QQ. La entrada de configuración del administrador cambia de "Agregar más → Editar elementos de la lista" a "Seleccionar usuario"; el cuadro desplegable de la sesión original y la entrada de edición de la lista se unifican en "Seleccionar fuente de sesión" y "Sesión conocida" se cambia a "Fuente de sesión grabada". (#10747)
  • Gestión de robots: al eliminar un robot, puede optar por limpiar configuraciones, tareas programadas, conversaciones, registros de mensajes, datos de seguimiento y uso; Las conversaciones y los datos históricos se conservan de forma predeterminada. (#10761)
  • Tareas programadas: admite la visualización de la lista de tareas compartidas dentro del grupo y permite a los administradores eliminar tareas del grupo. (#10785)
  • Configuración de red: Se agregaron selector de espejo PyPI y funciones de medición de velocidad. (#10657)

Optimización y reparación

  • Estabilidad: se solucionó un problema por el cual WebUI y WebChat podían dejar de responder cuando se bloquea la salida del registro y proporcionar estadísticas de descarte de registros de la consola en el paquete de diagnóstico. (#10902)
  • Compresión de contexto: simplifique la configuración, cambie "Método de manejo cuando el historial alcanza el límite superior o la ventana de contexto es estrecha" a "Estrategia de compresión" y "ID del proveedor del modelo de compresión de contexto" a "Modelo de compresión"; el número máximo de rondas, el número de rondas descartadas, las instrucciones de compresión, la relación de contexto reciente y el tamaño de la ventana alternativa se mueven a "Más configuraciones", conservando la configuración existente y el comportamiento de ejecución. (#10753)
  • Servicio modelo: conserva el encabezado de solicitud de clave API requerido por los servicios compatibles con Anthropic; solucione el problema por el cual la configuración del tiempo de espera del agente DashScope no tiene efecto. (#10787, #10868)
  • Gemini: proporciona plantillas de acceso directo a parámetros nativos y corrige las indicaciones de configuración de herramientas nativas. (#10771, #10875)
  • Complementos y habilidades: se corrigió el error de instalación del complemento causado por el conflicto entre el directorio temporal y el archivo de marca .astrbot en NAS y otros entornos; error de recarga de configuración del complemento informado; Dio prioridad al uso de la herramienta de lectura de archivos al cargar habilidades. (#10784, #10788, #10789)
  • Seguridad: habilite la verificación del certificado TLS para la imagen PyPI predeterminada. (#10685)
  • Audio: Admite audio Tencent SILK con prefijo 0x03. (#10744)
  • ChatUI: el panel de archivos utiliza el directorio de trabajo de la sesión actual. (#10883)
  • WebUI: optimice la actualización en tiempo real de la lista de seguimiento, unifique el estilo del formulario de configuración, elimine la opción "todos" no admitida en las reglas personalizadas y limite el estilo de la barra de desplazamiento nativa para que solo tenga efecto en Firefox. (#10748, #10755, #10757, #10760)

Agregado

  • Botones de mensajes: se agregaron componentes de botones portátiles para enlaces, envío de mensajes y devoluciones de llamadas de complementos, con avisos de tiempo de espera de interacción. Los tipos de acciones admitidas varían según la plataforma; ver la documentación. (#9809)
  • Modelos de decisión: se agregó un proveedor de decisiones independiente de los modelos de chat y un adaptador System One para opciones estructuradas, preguntas booleanas y puntuaciones en complementos. (#10775)
  • Búsqueda web: SerpApi Google News integrado con editor, autor, hora de publicación y citas de WebUI. (#10773)
  • Selección de sesión y usuario: selección unificada de fuente de sesión con búsqueda de apodos, etiquetas de plataforma, paginación y copia de ID; información del remitente registrada y nombres de grupos oficiales de Lark y QQ enriquecidos. La configuración del administrador pasa de Agregar más → Editar elementos de la lista a Seleccionar usuarios. Los menús desplegables de sesiones anteriores y los editores de listas se convierten en Seleccionar fuentes de sesión; Las sesiones conocidas se convierten en fuentes de sesiones grabadas. (#10747)
  • Gestión de bots: se agregó limpieza selectiva de configuración, tareas programadas, conversaciones, historial de mensajes, seguimientos y datos de uso al eliminar un bot. Las conversaciones y los datos históricos se conservan de forma predeterminada. (#10761)
  • Tareas programadas: listas de tareas grupales compartidas y administradores permitidos para eliminar tareas grupales. (#10785)
  • Configuración de red: se agregó un selector de espejos PyPI y pruebas de velocidad. (#10657)

AstrBot v4.29.4

Highlights

  • Portable message buttons — Plugins can use one component for links, message sends, and callbacks, with interaction timeout feedback. Supported actions vary by platform, so verify adapter capabilities and provide fallbacks rather than assuming parity (#9809).
  • Decision models outside chat — The new Decision Provider and System One adapter support structured choices, boolean judgments, and scores without routing requests through a conversational model. Plugins can configure this provider independently and account for its usage separately (#10775).
  • Google News with citations — SerpApi Google News adds publisher, author, publication time, and WebUI citations, making news-backed responses easier to verify. Treat SerpApi as an external dependency with separate credentials and quotas (#10773).
  • Dashboard control migration — User and session-source selection is consolidated under “Select users” and “Select session sources,” adding nickname search, platform labels, pagination, ID copying, and richer Lark/QQ Official group identities (#10747). Context-compression controls are renamed and advanced options move to “More Settings”; existing values and runtime behavior are preserved, but UI automation and documentation may need updated selectors (#10753).
  • Safer bot deletion and shared schedules — Bot deletion now offers opt-in cleanup of configuration, scheduled tasks, conversations, history, traces, and usage data. Conversations and history remain by default, so confirm the cleanup scope before purging (#10761). Administrators can also view and delete shared group tasks (#10785).
  • Runtime and integration hardening — Blocked console output no longer stalls WebUI/WebChat, and diagnostic exports include dropped-log counters (#10902). Anthropic-compatible API-key headers are preserved (#10787), DashScope Agent timeouts now take effect (#10868), and the default PyPI mirror enforces TLS verification (#10685); proxy or custom-certificate environments need a valid trust chain.

No breaking changes.

[4.29.4] - 2026-10-31

新增

  • 消息按钮：新增跨平台按钮组件，支持链接、消息发送和插件回调，并提供交互超时提示。各平台支持的按钮类型以文档为准。 (#9809)
  • 决策模型：新增独立于聊天模型的 Decision Provider 和 System One 适配器，供插件调用结构化选择、布尔判断和评分。 (#10775)
  • 网络搜索：接入 SerpApi Google News，支持新闻来源、作者、发布时间和 WebUI 引用展示。 (#10773)
  • 会话与用户选择：统一会话来源选择弹窗，支持昵称搜索、平台标识、分页及 ID 复制；记录发送者信息并补全飞书、QQ 官方群名称。管理员配置入口由“添加更多 → 编辑列表项”改为“选择用户”；原会话下拉框和列表编辑入口统一为“选择会话来源”，“已知会话”改为“已记录的会话来源”。 (#10747)
  • 机器人管理：删除机器人时可选择清理配置、定时任务、会话、消息记录、追踪和用量数据；默认保留对话与历史数据。 (#10761)
  • 定时任务：支持查看群内共享任务列表，并允许管理员删除群任务。 (#10785)
  • 网络设置：新增 PyPI 镜像选择器与测速功能。 (#10657)

优化与修复

  • 稳定性：修复日志输出受阻时 WebUI 和 WebChat 可能无响应的问题，并在诊断包中提供控制台日志丢弃统计。 (#10902)
  • 上下文压缩：简化设置，将“历史记录达到上限或上下文窗口紧张时的处理方式”改为“压缩策略”，“上下文压缩模型提供商 ID”改为“压缩模型”；最大轮数、丢弃轮数、压缩指令、近期上下文比例及回退窗口大小移至“更多设置”，保留现有配置和运行行为。 (#10753)
  • 模型服务：保留 Anthropic 兼容服务所需的 API Key 请求头；修复 DashScope Agent 超时配置未生效的问题。 (#10787, #10868)
  • Gemini：提供原生参数快捷模板，并修正原生工具配置提示。 (#10771, #10875)
  • 插件与技能：修复 NAS 等环境中临时目录与 .astrbot 标记文件冲突导致的插件安装失败；报告插件配置重载失败；加载技能时优先使用文件读取工具。 (#10784, #10788, #10789)
  • 安全：为默认 PyPI 镜像启用 TLS 证书校验。 (#10685)
  • 音频：支持带 0x03 前缀的腾讯 SILK 音频。 (#10744)
  • ChatUI：文件面板使用当前会话的工作目录。 (#10883)
  • WebUI：优化追踪列表实时更新、统一配置表单样式、移除自定义规则中不受支持的“全部”选项，并限制原生滚动条样式仅在 Firefox 生效。 (#10748, #10755, #10757, #10760)

Added

  • Message buttons: Added portable button components for links, sending messages, and plugin callbacks, with interaction timeout notices. Supported action types vary by platform; see the documentation. (#9809)
  • Decision models: Added a Decision Provider independent of chat models and a System One adapter for structured choices, boolean questions, and scores in plugins. (#10775)
  • Web search: Integrated SerpApi Google News with publisher, author, publication time, and WebUI citations. (#10773)
  • Session and user selection: Unified session-source selection with nickname search, platform labels, pagination, and ID copying; recorded sender information and enriched Lark and QQ Official group names. Administrator settings move from Add More → Edit List Items to Select users. Previous session dropdowns and list editors become Select session sources; Known sessions becomes Recorded session sources. (#10747)
  • Bot management: Added selective cleanup of configuration, scheduled tasks, conversations, message history, traces, and usage data when deleting a bot. Conversations and historical data are retained by default. (#10761)
  • Scheduled tasks: Shared group task lists and allowed administrators to delete group tasks. (#10785)
  • Network settings: Added a PyPI mirror picker and speed tests. (#10657)

Improved and Fixed

  • Stability: Fixed WebUI and WebChat becoming unresponsive when console output is blocked, and included console log drop counters in diagnostic exports. (#10902)
  • Context compression: Renamed Handling for History Limits or Context Window Pressure to Compression Strategy, and Model Provider ID for Context Compression to Compression Model. Moved maximum turns, discarded turns, compression instruction, recent-context ratio, and fallback context window size into More Settings, preserving existing configuration and runtime behavior. (#10753)
  • Model providers: Preserved API key headers for Anthropic-compatible providers and honored the configured DashScope Agent timeout. (#10787, #10868)
  • Gemini: Added native parameter quick templates and corrected native tool configuration hints. (#10771, #10875)
  • Plugins and skills: Fixed plugin installation when temporary directories conflict with the .astrbot marker file on NAS and similar environments; reported plugin configuration reload failures; preferred file-reading tools when loading skills. (#10784, #10788, #10789)
  • Security: Enabled TLS certificate verification for the default PyPI mirror. (#10685)
  • Audio: Supported Tencent SILK audio with a 0x03 prefix. (#10744)
  • ChatUI: Used the active session workspace in the file panel. (#10883)
  • WebUI: Smoothed live trace updates, unified configuration form styling, removed the unsupported All option from custom rules, and scoped native scrollbar styles to Firefox. (#10748, #10755, #10757, #10760)
