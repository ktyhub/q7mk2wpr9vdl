¿Qué ha cambiado?

Nuevo

  • Se agregó el proveedor vllm_rerank para admitir rerank_api_suffix configurable, que puede adaptarse de manera flexible a diferentes rutas de API. (#7278)
  • Adapte el soporte de extracción de uso de tokens de llama.cpp para mejorar las estadísticas de tokens y las capacidades de análisis de facturación. (#7358)
  • WebUI incluye los archivos de trabajo de Monaco Editor para evitar errores de descarga desde CDN. (#7249)
  • Nuevo panel de estadísticas de descripción general del modelo/plataforma. (#7152)

Optimización

  • Optimice el procesamiento de mensajes de OpenAI; si la lista content está vacía, configúrela en None y reduzca la tasa de excepciones con contenido vacío. (#6551)
  • Optimice el diseño y el estilo de la página del proveedor para mejorar la coherencia del diseño de la página de configuración general. (#7248)
  • Cuando el usuario inicia sesión, la página de bienvenida saltará directamente, reduciendo los pasos para ingresar nuevamente a la página de inicio de sesión. (comprometer)

Arreglar

  • Se solucionó el problema por el cual el ejecutor MCP en Windows no heredaba las variables de entorno completas del sistema, lo que provocaba una excepción de inicio. (#7054)
  • Se solucionó un problema por el cual los fragmentos de reflexión de Gemini se filtraban a enlaces de mensajes visibles para el usuario. (#7196)
  • Se corrigió el error 400 Invalid argument causado por el requisito de formato function_response en Gemini (OpenAI compatible con API). (#7216
  • Se corrigieron mensajes de error y problemas de recuperación cuando falla la inicialización de la base de conocimientos. (#7243)
  • Se corrigió la compatibilidad de Bailian Rerank con formatos de respuesta nuevos y antiguos para evitar fallas de análisis. (#7217)
  • La imagen Docker complementa la dependencia del codificador AMR y soluciona el problema de la falta de transcodificación de audio en algunos escenarios de implementación. (#7247)
  • Se solucionó el problema de indisponibilidad del proxy SOCKS5 causado por la falta de dependencia pysocks en la instalación de pip. (#7221)
  • Reparar la lógica de procesamiento de cached_tokens en _extract_usage para evitar confusión en las estadísticas de los tokens. (#6719)
  • Mejore la protección contra desconexión SSE, envíe activamente latidos bajo transmisión comprimida y reduzca las desconexiones accidentales de WebChat. (#7003)
  • Se corrigió el error 400 causado por un mensaje de asistente vacío bajo el estricto API. (#7202)
  • Se agregó reparación de dependencia qrcode para la función de código QR faltante y se restauró la función de generación de código QR. (comprometer)
  • Se corrigió el problema de la experiencia interactiva del componente de entrada digital del configurador para evitar desviaciones de procesamiento en escenarios de entrada anormales. (#7153)
  • Se corrigió que Record.path se tratara incorrectamente como un campo obligatorio en Pydantic v2. (#7048) <a id="inglés"></a>

AstrBot v4.22.3

Highlights

  • Token accounting for self-hosted stacks — llama.cpp now emits token usage (#7358) and _extract_usage stops mangling cached_tokens (#6719), so billing/cost analytics finally reflect real prompt-cache behavior. If you meter local inference, expect usage numbers to shift — recalibrate dashboards or budget alerts built on the old, noisier counts.

  • Gemini behavior changes — thinking parts are stripped from user-facing message chains (#7196): a privacy/UX win, but anything downstream that consumed reasoning fragments will no longer see them. In the same vein, function_response payloads are reshaped to satisfy Gemini's schema, removing 400 Invalid argument on tool-result turns (#7216).

  • Strict-API payload hygiene — empty OpenAI content lists are normalized to None (#6551) and empty assistant messages are filtered before dispatch (#7202), eliminating the zero-content 400s strict endpoints throw. Custom providers that assumed an empty list would be passed should verify they now handle None.

  • Rerack deployment flexibility — vllm_rerank gains a configurable rerank_api_suffix (#7278), so non-default API paths no longer require a fork, and Bailian rerank parses both legacy and current response formats (#7217) — a safe upgrade for anyone still pinned to the older shape.

  • Dependency and deployment repairs — Docker images bundle an AMR encoder (#7247), pip installs pull pysocks so SOCKS5 proxies actually work (#7221), and the missing qrcode dep restores QR generation (commit 5886c437). Windows MCP runners inherit full system env vars (#7054), fixing launches that failed when tooling lived in PATH.

  • WebUI and plugin-author fixes — Monaco workers are bundled locally (#7249), so code editing survives CDN outages; a new model/platform stats dashboard (#7152) and provider-page restyle (#7248) ship alongside SSE heartbeats under compression to cut WebChat false disconnects (#7003). For plugin developers: Record.path is no longer wrongly required under Pydantic v2 (#7048), and Discord/Misskey hot reload was fixed by correcting client_self_id misuse (#7331).

No breaking changes are noted in this release.

What's Changed

新增

  • 新增 vllm_rerank 提供商支持可配置的 rerank_api_suffix，可灵活适配不同 API 路径。（#7278）
  • 适配 llama.cpp 的 token 用量提取支持，增强 token 统计与计费分析能力。（#7358）
  • WebUI 捆绑 Monaco Editor 的 worker 文件，防止从 CDN 下载失败。（#7249）
  • 全新的模型/平台总览统计面板。（#7152）

优化

  • 优化 OpenAI 消息处理，若 content 列表为空时将其置为 None，并降低空内容下的异常率。（#6551）
  • 优化 provider page 布局与样式，提升整体设置页面排版一致性。（#7248）
  • 用户已登录时将直接跳转欢迎页，减少再次进入登录页的步骤。（commit）

修复

  • 修复 Windows 下 MCP runner 未继承完整系统环境变量导致启动异常的问题。（#7054）
  • 修复 Gemini 思考片段泄露到用户可见消息链路的问题。（#7196）
  • 修复 Gemini(OpenAI 兼容 API) 下，function_response 格式要求导致的 400 Invalid argument 错误。（#7216
  • 修复知识库初始化失败时的错误提示与恢复问题。（#7243）
  • 修复 Bailian Rerank 对新旧响应格式兼容性，避免解析失败。（#7217）
  • Docker 镜像补充 AMR 编码器依赖，修复部分部署场景下的音频转码缺失问题。（#7247）
  • 修复 pip 安装缺少 pysocks 依赖导致的 SOCKS5 代理不可用问题。（#7221）
  • 修复 cached_tokens 在 _extract_usage 中的处理逻辑，避免 token 统计错乱。（#6719）
  • 增强 SSE 断开保护，压缩传输下主动发送心跳，减少 WebChat 误断连。（#7003）
  • 修复严格 API 下空 assistant 消息导致的 400 错误。（#7202）
  • 新增二维码功能缺失的 qrcode 依赖修复，恢复二维码生成功能。（commit）
  • 修复配置器数字输入组件的交互体验问题，避免异常输入场景下的处理偏差。（#7153）
  • 修复 Record.path 在 Pydantic v2 下被错误视为必填字段的问题。（#7048）
