#AstrBot v4.18.0

¿Qué ha cambiado?

Nuevo

  • Se agregó AstrBot HTTP API, que admite capacidades de diálogo, consulta de sesión, consulta de configuración, carga de archivos y envío de mensajes instantáneos basadas en la clave API. Consulte AstrBot HTTP API (Beta) (#5280) para obtener más detalles.
  • Se agregó la capacidad de registrar alias de comandos de Telegram, y los alias se pueden mostrar simultáneamente en el menú de comandos de Telegram (#5234).
  • Se agregó la configuración de parámetros de pensamiento adaptativo antrópico (tipo/esfuerzo) para mejorar la controlabilidad de las estrategias de pensamiento (#5209).

Arreglar

  • Se solucionó el problema del envío anormal de mensajes en el canal oficial de QQ y se mejoró la estabilidad de la entrega de mensajes (#5287).
  • Se solucionó el problema por el cual ChatUI todavía usa la configuración predeterminada cuando se usa una conversación de perfil no predeterminada (#5292).

Optimización

  • Optimice la visualización de soporte de plataforma de tarjetas de mercado de complementos y mejore la usabilidad móvil y la experiencia interactiva (#5271).
  • Reconstruir el campo puente del tiempo de ejecución del escritorio del Panel y migrarlo uniformemente de isElectron a isDesktop para mejorar la coherencia semántica entre extremos (#5269).

Qué ha cambiado (ES)

Nuevas funciones

  • Se agregó AstrBot HTTP API con soporte clave API para chat, listado de sesiones, listado de configuraciones, carga de archivos y envío de mensajes instantáneos. Consulte AstrBot HTTP API (Beta) (#5280).
  • Se agregó el registro de alias de comando de Telegram para que los alias también puedan aparecer en el menú de comandos de Telegram (#5234).
  • Se agregaron parámetros de pensamiento adaptativo antrópico (type/effort) para un control de la estrategia de razonamiento más flexible (#5209).

Correcciones

  • Se corrigieron errores de envío de mensajes oficiales del gremio QQ para mejorar la estabilidad de la entrega (#5287).
  • Se corrigieron fallas de enlace de configuración de chat causadas por ID de sesión faltantes al crear nuevos chats y se mejoró la tolerancia a fallas de almacenamiento local (#5292).

Mejoras

  • Visualización mejorada de la tarjeta del mercado de complementos para compatibilidad de plataforma, con mejor accesibilidad e interacción móvil (#5271).
  • Campos de puente de tiempo de ejecución de escritorio refactorizados en el tablero de isElectron a isDesktop para una semántica multiplataforma más clara (#5269).

AstrBot v4.18.0

Highlights

  • HTTP API turns AstrBot into a programmable service (Beta) — #5280 adds an API-Key-authenticated HTTP surface covering chat, session/config listing, file upload, and outbound IM messages. This is the release's architectural headline: you can now drive the bot from scripts, CI, or external systems instead of only through chat platforms. It's explicitly Beta, so expect the contract to shift — but it's the integration hook most adopters will build against.

  • Finer Anthropic reasoning control, plus a quiet bonus provider — #5209 exposes adaptive thinking parameters (type/effort) so you can tune reasoning depth rather than accept provider defaults. Worth reading the PR directly: its title also mentions an "Anthropic Claude Code OAuth provider" that the release summary omits — relevant if you've been waiting on Claude Code credential support.

  • Dashboard bridge rename is a migration for extension authors — #5269 replaces the isElectron runtime bridge field with isDesktop. It sounds cosmetic, but any custom dashboard code or plugin that branches on isElectron will silently fall through after upgrade. Audit those checks before rolling out.

  • ChatUI config selection now actually sticks — #5292 fixes two related defects: chats opened with a non-default config were silently still using the default config, and new chats could fail config binding because of a missing session ID (localStorage handling was also hardened). If you run multiple config profiles, conversations you believed were isolated may have been misrouted — re-verify after upgrading.

  • Channel and marketplace polish — #5234 lets Telegram command aliases register into the native command menu, improving discoverability with no client-side config needed; #5287 stabilizes QQ official guild message delivery; and #5271 improves plugin-marketplace platform badges and mobile layout. The Telegram change alters what end users see in-client, so it's the one to sanity-check visually.

What's Changed

新增

  • 新增 AstrBot HTTP API，支持基于 API Key 的对话、会话查询、配置查询、文件上传与 IM 消息发送能力。详见AstrBot HTTP API (Beta) (#5280)。
  • 新增 Telegram 指令别名注册能力，别名可同步展示在 Telegram 指令菜单中 (#5234)。
  • 新增 Anthropic 自适应思考参数配置（type/effort），增强思考策略可控性 (#5209)。

修复

  • 修复 QQ 官方频道消息发送异常问题，提升消息下发稳定性 (#5287)。
  • 修复 ChatUI 使用非 default 配置文件对话时仍然使用 default 配置的问题 (#5292)。

优化

  • 优化插件市场卡片的平台支持展示，改进移动端可用性与交互体验 (#5271)。
  • 重构 Dashboard 桌面运行时桥接字段，从 isElectron 统一迁移至 isDesktop，提升跨端语义一致性 (#5269)。

What's Changed (EN)

New Features

  • Added AstrBot HTTP API with API Key support for chat, session listing, config listing, file upload, and IM message sending. See AstrBot HTTP API (Beta) (#5280).
  • Added Telegram command alias registration so aliases can also appear in the Telegram command menu (#5234).
  • Added Anthropic adaptive thinking parameters (type/effort) for more flexible reasoning strategy control (#5209).

Fixes

  • Fixed QQ official guild message sending errors to improve delivery stability (#5287).
  • Fixed chat config binding failures caused by missing session IDs when creating new chats, and improved localStorage fault tolerance (#5292).

Improvements

  • Improved plugin marketplace card display for platform compatibility, with better mobile accessibility and interaction (#5271).
  • Refactored desktop runtime bridge fields in the dashboard from isElectron to isDesktop for clearer cross-platform semantics (#5269).
