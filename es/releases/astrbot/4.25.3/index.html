#AstrBot v4.25.3

  • Registro de actualización (chino simplificado)
  • Changelog(inglés) <a id="chino"></a>

¿Qué ha cambiado?

Actualizaciones clave

  • Se solucionó el problema de no poder continuar reconectándose después de que la tarea DingTalk Stream finaliza de manera anormal y se mejoró la estabilidad de la conexión larga del adaptador DingTalk. (#8610)
  • El inicio de sesión en el panel agrega autenticación TOTP de dos factores. (#8189)
  • Se agrega una nueva entrada WebUI de complemento a la barra lateral del Panel y admite íconos MDI; la página del complemento ahora se sincronizará con el tema del Panel. (#8569, #8390)
  • Optimice la interfaz de usuario de tareas futuras y mejore el nivel de producción de "Crear tarea". (#8559)
  • Se agregó el comando /name para nombrar umo y mostrarlo en la interfaz de usuario. (#8575)
  • MiniMax Token Plan admite la obtención dinámica de la lista de modelos y el modelo predeterminado se actualiza a M3. (#8475, #8505)
  • Optimice la compresión de contexto para mejorar la calidad de la compresión y la tasa de aciertos de la caché KV. (#8530, #8226)

Arreglar

  • Se solucionó el problema por el cual las estadísticas del proveedor no se reintentaban cuando se encontraba un bloqueo de SQLite. (comprometer)
  • Se solucionó un problema por el cual las modalidades vacías se trataban como capacidades configuradas, lo que provocaba que las solicitudes de imágenes principales se enrutaran incorrectamente al respaldo visual. (#8451)
  • Se solucionó el problema por el cual el campo adicional del componente Responder toDict causaba que no se enviara el mensaje privado. (#8477)
  • Se solucionó el problema de procesamiento cuando se usaba el componente Responder para activar el robot y el mensaje del usuario estaba vacío. (#8461)
  • Se solucionó el problema de que el adaptador aiocqhttp no podía analizar la voz y se agregó la verificación de existencia del archivo de audio. (#8523, #8529)
  • Se solucionó el problema de parámetros no válidos de incrustación de OpenAI en modelos de incrustación de SiliconFlow que no son Qwen. (#8508)
  • Se solucionó el problema por el cual el texto por lotes de incrustación de Gemini se colapsaba en gemini-embedding-2. (#8537)
  • Se solucionó el problema del procesamiento de espacios en blanco al extraer texto sin formato de la cadena de mensajes de WeCom AI. (#8563)
  • Se solucionó el problema por el cual el encabezado de seguridad del marco era demasiado estricto cuando el Panel se ejecuta en el iniciador. (#8554)
  • Se corrigió la visualización del error de instalación del pip de la consola y en su lugar se usó el mensaje del sistema. (#8462)
  • Optimizar los problemas relacionados con la configuración de la plantilla. (#8228)

Optimización e Ingeniería

  • Mejorar el procesamiento de los componentes de registro de la cadena de mensajes de respuesta. (#8527)
  • Whisper STT cerrará el identificador del archivo de audio después de llamar a la interfaz de transcodificación OpenAI. (#8528)
  • Evitar que los comandos de activación se registren como contexto de chat grupal. (#8536)
  • Se corrigió la terminología del token en el texto chino. (#8465)
  • 更新 Acciones GitHub 依赖。(#8533) <a id="inglés"></a>

Qué ha cambiado (ES)

Destacados

  • Se corrigió la recuperación de la tarea DingTalk Stream para que el adaptador siga reconectándose después de que la tarea SDK salga inesperadamente. (#8610)
  • Se agregó autenticación TOTP de dos factores para iniciar sesión en el Panel. (#8189)
  • Se agregaron entradas de WebUI del complemento a la barra lateral del Panel con soporte para íconos MDI y se sincronizó el estilo del tema del Panel en las páginas del complemento. (#8569, #8390)
  • Se agregó la interfaz de usuario de tareas futuras y se introdujo /name para nombrar las entradas umo que se muestran en la interfaz de usuario. (#8559, #8575)
  • MiniMax Token Plan ahora puede recuperar listas de modelos dinámicamente, con el modelo predeterminado actualizado a M3. (#8475, #8505)
  • Memoria a largo plazo mejorada y calidad de compresión de contexto, incluidas mejores tasas de aciertos de caché KV. (#8530, #8226)

Corrección de errores

  • Las estadísticas del proveedor reintentadas leen cuando SQLite está bloqueado. (comprometer)
  • Se trataron las modalidades vacías como no configuradas para que las solicitudes de imágenes no se dirijan incorrectamente al respaldo de visión. (#8451)
  • Se corrigieron fallas en el envío de mensajes privados causadas por campos adicionales en la salida del componente de respuesta toDict. (#8477)
  • Se corrigió que el bot se despertara con un componente de Respuesta y un mensaje de usuario vacío. (#8461)
  • Se corrigió el análisis de voz en el adaptador aiocqhttp y se agregó una verificación de existencia de archivos de audio. (#8523, #8529)
  • Se corrigieron parámetros de incrustación de OpenAI no válidos para modelos de incrustación de SiliconFlow que no son Qwen. (#8508)
  • Se empaquetó textos de incrustación por lotes de Gemini en Contenido para evitar el colapso en gemini-embedding-2. (#8537)
  • Se corrigió el manejo de espacios en blanco al extraer texto sin formato de las cadenas de mensajes de WeCom AI. (#8563)
  • Encabezados de seguridad del marco del panel de control relajados cuando se ejecutan bajo el iniciador. (#8554)
  • Se muestran errores de instalación de pip de la consola con mensajes de brindis. (#8462)
  • Manejo optimizado de la configuración de la plantilla. (#8228)

Mejoras y Mantenimiento

  • Manejo mejorado de la cadena de respuesta para componentes de registro. (#8527)
  • Manejadores de archivos de audio cerrados después de llamadas de transcripción OpenAI en Whisper STT. (#8528)
  • Se evitó que los comandos de activación se registraran como contexto de chat grupal. (#8536)
  • Se corrigió la terminología de tokens chinos. (#8465)
  • Dependencias de acciones GitHub actualizadas. (#8533)

AstrBot v4.25.3

<a id="chinese"></a>

What's Changed

重点更新

  • 修复钉钉 Stream 任务异常退出后无法持续重连的问题，提升钉钉适配器长连接稳定性。(#8610)
  • Dashboard 登录新增 TOTP 双因素认证。(#8189)
  • Dashboard 侧边栏新增插件 WebUI 入口，并支持 MDI 图标；插件页面现在会同步 Dashboard 主题。(#8569, #8390)
  • 优化未来任务 UI，提高 “创建任务” 的产品化程度。(#8559)
  • 新增 /name 命令用于命名 umo 且在 UI 中展示。 (#8575)
  • MiniMax Token Plan 支持动态获取模型列表，默认模型升级为 M3。(#8475, #8505)
  • 优化上下文压缩，提高压缩质量和 KV-cache 命中率。(#8530, #8226)

修复

  • 修复 Provider 统计遇到 SQLite lock 时未重试的问题。(commit)
  • 修复空 modalities 被当作已配置能力，导致核心图片请求错误路由到视觉 fallback 的问题。(#8451)
  • 修复 Reply 组件 toDict 额外字段导致私聊消息发送失败的问题。(#8477)
  • 修复带 Reply 组件唤醒机器人且用户提示为空时的处理问题。(#8461)
  • 修复 aiocqhttp 适配器无法解析语音的问题，并增加音频文件存在性检查。(#8523, #8529)
  • 修复 OpenAI Embedding 在 SiliconFlow 非 Qwen embedding 模型上的无效参数问题。(#8508)
  • 修复 Gemini Embedding 批量文本在 gemini-embedding-2 上被折叠的问题。(#8537)
  • 修复 WeCom AI 消息链提取纯文本时的空白处理问题。(#8563)
  • 修复 Dashboard 在 launcher 下运行时 frame 安全头过于严格的问题。(#8554)
  • 修复控制台 pip 安装错误展示，改为使用 toast 提示。(#8462)
  • 优化模板配置相关问题。(#8228)

优化与工程

  • 增强 Reply 消息链对 Record 组件的处理。(#8527)
  • Whisper STT 调用 OpenAI 转写接口后会关闭音频文件句柄。(#8528)
  • 防止唤醒命令被记录为群聊上下文。(#8536)
  • 修正中文文本中的 token 术语。(#8465)
  • 更新 GitHub Actions 依赖。(#8533)

<a id="english"></a>

What's Changed (EN)

Highlights

  • Fixed DingTalk Stream task recovery so the adapter keeps reconnecting after unexpected SDK task exits. (#8610)
  • Added TOTP two-factor authentication for Dashboard login. (#8189)
  • Added plugin WebUI entries to the Dashboard sidebar with MDI icon support, and synchronized Dashboard theme styling into plugin pages. (#8569, #8390)
  • Added the future task UI and introduced /name for naming umo entries shown in the UI. (#8559, #8575)
  • MiniMax Token Plan can now fetch model lists dynamically, with the default model upgraded to M3. (#8475, #8505)
  • Improved long-term memory and context compression quality, including better KV-cache hit rates. (#8530, #8226)

Bug Fixes

  • Retried provider stats reads when SQLite is locked. (commit)
  • Treated empty modalities as unconfigured so image requests do not incorrectly route to vision fallback. (#8451)
  • Fixed private message sending failures caused by extra fields in Reply component toDict output. (#8477)
  • Fixed waking the bot with a Reply component and an empty user prompt. (#8461)
  • Fixed voice parsing in the aiocqhttp adapter and added an audio file existence check. (#8523, #8529)
  • Fixed invalid OpenAI Embedding parameters for SiliconFlow non-Qwen embedding models. (#8508)
  • Wrapped Gemini batch embedding texts in Content to avoid collapse on gemini-embedding-2. (#8537)
  • Fixed whitespace handling when extracting plain text from WeCom AI message chains. (#8563)
  • Relaxed Dashboard frame security headers when running under the launcher. (#8554)
  • Displayed console pip-install errors with toast messages. (#8462)
  • Optimized template config handling. (#8228)

Improvements and Maintenance

  • Enhanced Reply chain handling for Record components. (#8527)
  • Closed audio file handles after OpenAI transcription calls in Whisper STT. (#8528)
  • Prevented wake commands from being recorded as group chat context. (#8536)
  • Fixed Chinese token terminology. (#8465)
  • Updated GitHub Actions dependencies. (#8533)
