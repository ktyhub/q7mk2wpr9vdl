Vibe-Trading v0.1.7

🛡️ v0.1.7 — Refuerzo de los límites de seguridad + pulido del flujo de trabajo de investigación

v0.1.7 es una versión de mantenimiento centrada en la seguridad para Vibe-Trading. Fortalece los límites predeterminados de API, archivo, URL, código generado, herramienta de shell, Docker, CLI/Web y MCP/ClawHub, al tiempo que preserva el flujo de trabajo de host local de baja fricción para usuarios normales de CLI y Web UI. Esta versión está disponible en las versiones PyPI, ClawHub y GitHub.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Destacados

🛡️ Refuerzo de los límites de seguridad

El objetivo principal de esta versión es hacer que Vibe-Trading sea más seguro de forma predeterminada sin convertir los flujos de trabajo de investigación locales en trabajos de configuración.

  • Autenticación y protección de lectura API: el uso no local de API ahora es mucho más estricto de forma predeterminada, y las rutas sensibles de lectura de ejecución/sesión/enjambre están protegidas de manera consistente.
  • Límites de carga y archivos locales: las herramientas de manejo de carga y lectura de archivos locales ahora utilizan límites de ruta/tipo más estrictos, con pruebas de regresión que cubren las rutas que antes eran riesgosas.
  • Lectores de documentos y URL: las lecturas de documentos locales y las lecturas de URL salientes ahora imponen controles de seguridad más estrictos.
  • Herramientas compatibles con Shell: las herramientas de ejecución de Shell están controladas por punto de entrada/opción explícita, lo que reduce la exposición accidental en implementaciones Web/API/Docker/MCP.
  • Carga de estrategia generada: la prueba retrospectiva generada y el código de estrategia de la cuenta sombra se validan antes de la ejecución/importación.
  • Línea base de Docker: la imagen en tiempo de ejecución ahora se ejecuta como un usuario vibe no root y los valores predeterminados de Docker Compose son localhost-first.
  • Durabilidad: el refuerzo está respaldado por pruebas de regresión en autenticación, carga, seguridad de ruta, lectura de documentos, lectura web, registro de herramientas, carga de prueba retrospectiva y generación de código de cuenta sombra. Gracias a lemi9090 (S2W) por el informe de seguridad coordinado y la rápida validación de la cobertura de la solución antes del lanzamiento.

⚙️ Configuración de la interfaz de usuario web

Las nuevas superficies de configuración hacen que el proveedor/modelo, la URL base, el esfuerzo de razonamiento y el estado de las credenciales de la fuente de datos sean manejables desde la interfaz de usuario web, respaldados por configuraciones locales/protegidas por autenticación API y metadatos del proveedor basados en datos. (#57)

🔥 Mapa de calor de correlación

El nuevo panel de correlación/API calcula correlaciones de rendimiento continuas y genera un mapa de calor de ECharts para el análisis de carteras y símbolos. Las correcciones de seguimiento alinearon el proxy frontal y los bloqueadores de revisión de relaciones públicas. (#64, #66)

🔐 Proveedor OAuth del Codex OpenAI

Vibe-Trading ahora admite el proveedor OpenAI Codex a través del inicio de sesión ChatGPT OAuth (vibe-trading provider login openai-codex), con metadatos de configuración y pruebas del adaptador del proveedor. (#65)

🧭 Habilidad de filtro previo a ST de acción A

Nueva habilidad ashare-pre-st-filter para la detección de riesgos ST/*ST de acciones A, con filtrado de relevancia de seguimiento para que las menciones de la lista de cuentas de valores no inflen los recuentos de penalizaciones E2. (#63)

🖥️ CLI UX interactivo

El modo interactivo ahora tiene una barra de estado inferior en vivo para proveedor/modelo, duración de la sesión, latencia de la última ejecución y estadísticas acumulativas de llamadas de herramientas, además de navegación rápida del historial y edición del cursor a través de prompt_toolkit. (#69)

🧩 Inspección preestablecida de enjambre

vibe-trading --swarm-inspect <preset> y la plomería relacionada facilitan la inspección de los ajustes preestablecidos de enjambre antes de ejecutar flujos de trabajo de múltiples agentes. (#73)

📈 Habilidad de análisis de dividendos

Se agregó la habilidad combinada dividend-analysis para acciones de ingresos, sostenibilidad de pagos, crecimiento de dividendos, rendimiento para los accionistas, mecánica ex dividendos y controles de trampa de rendimiento.

🧰 Flujo de trabajo de desarrollo local

Se agregó un flujo de trabajo de desarrollo local de un solo comando a través de scripts/dev up|open|logs|stop, además de compatibilidad con Codespaces y ergonomía de desarrollo frontend/backend. Esto tiene como objetivo facilitar mucho las pruebas y demostraciones locales limpias.

Vibe-Trading v0.1.7

🛡️ v0.1.7 — Security boundary hardening + research workflow polish

v0.1.7 is a security-focused maintenance release for Vibe-Trading. It strengthens the default API, file, URL, generated-code, shell-tool, Docker, CLI/Web, and MCP/ClawHub boundaries while preserving the low-friction localhost workflow for normal CLI and Web UI users.

This release is available on PyPI, ClawHub, and GitHub Releases.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Highlights

🛡️ Security boundary hardening

The main goal of this release is to make Vibe-Trading safer by default without turning local research workflows into configuration work.

  • API authentication and read protection: non-local API use is now much stricter by default, and sensitive run/session/swarm read paths are protected consistently.
  • Upload and local-file boundaries: upload handling and local file-reading tools now use tighter path/type boundaries, with regression tests covering the previously risky paths.
  • Document and URL readers: local document reads and outbound URL reads now enforce stronger safety checks.
  • Shell-capable tools: shell execution tools are gated by entry point / explicit opt-in, reducing accidental exposure in Web/API/Docker/MCP deployments.
  • Generated strategy loading: generated backtest and Shadow Account strategy code is validated before execution/import.
  • Docker baseline: the runtime image now runs as a non-root vibe user, and Docker Compose defaults are localhost-first.
  • Durability: the hardening is backed by regression tests across auth, upload, path safety, document reading, web reading, tool registry, backtest loading, and Shadow Account codegen.

Thanks to lemi9090 (S2W) for the coordinated security report and fast validation of the fix coverage before release.

⚙️ Web UI Settings

New Settings surfaces make provider/model, base URL, reasoning effort, and data-source credential state manageable from the Web UI, backed by local/auth-protected settings APIs and data-driven provider metadata. (#57)

🔥 Correlation heatmap

The new correlation dashboard/API computes rolling return correlations and renders an ECharts heatmap for portfolio and symbol analysis. Follow-up fixes aligned the frontend proxy and PR review blockers. (#64, #66)

🔐 OpenAI Codex OAuth provider

Vibe-Trading now supports the OpenAI Codex provider via ChatGPT OAuth login (vibe-trading provider login openai-codex), with Settings metadata and provider adapter tests. (#65)

🧭 A-share pre-ST filter skill

New ashare-pre-st-filter skill for A-share ST/*ST risk screening, with follow-up relevance filtering so securities-account list mentions do not inflate E2 penalty counts. (#63)

🖥️ Interactive CLI UX

Interactive mode now has a live bottom status bar for provider/model, session duration, last-run latency, and cumulative tool-call stats, plus prompt history navigation and cursor editing through prompt_toolkit. (#69)

🧩 Swarm preset inspection

vibe-trading --swarm-inspect <preset> and related plumbing make it easier to inspect swarm presets before running multi-agent workflows. (#73)

📈 Dividend analysis skill

Added the dividend-analysis bundled skill for income stocks, payout sustainability, dividend growth, shareholder yield, ex-dividend mechanics, and yield-trap checks.

🧰 Local dev workflow

Added a one-command local dev workflow through scripts/dev up|open|logs|stop, plus Codespaces support and frontend/backend dev ergonomics. This is intended to make clean local testing and demos much easier.

0.1.7 maintenance

  • Release metadata: PyPI package, CLI banner, Web UI footer, Docker OCI labels, and ClawHub manifest are synced to 0.1.7.
  • CLI: vibe-trading --version now reports the installed version.
  • ClawHub: manifest now reflects 74 bundled finance skills and the current MCP command surface.
  • Frontend build deps: raised vite, postcss, and related lockfile floors to audited patched versions.
  • Docs: README news was refreshed across all language variants before this release, while older entries remain collapsed.
  • Tests: focused security, CLI, registry, packaging, and frontend build checks passed before publishing.

| Channel | Command | |---|---| | PyPI | pip install -U vibe-trading-ai | | uv tool | uv tool install --reinstall vibe-trading-ai | | ClawHub (Claude Desktop / OpenClaw / MCP clients) | clawhub install vibe-trading or update the installed skill | | Docker | docker compose pull && docker compose up -d |
