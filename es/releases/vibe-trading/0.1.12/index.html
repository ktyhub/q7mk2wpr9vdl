Vibe-Trading v0.1.12

🌀 v0.1.12 — Cronograma del régimen de correlación, tres nuevos proveedores, MetaTrader 5 + una ola de confiabilidad

v0.1.12 acumula casi dos semanas de trabajo desde 0.1.11 (10 de julio de 2026): los titulares: una línea de tiempo del régimen de correlación que responde "¿cuándo se fusionó el mercado en un bloque y estamos en ese estado ahora?", tres nuevos proveedores de LLM más una resolución de punto final basada en catálogo que hace que cada proveedor trabaje con solo una clave, el conector de broker MetaTrader 5 (Exness) (12 brokers), el Habilidad de Gerente de Desarrollo de Estrategia, Binance USD-M perpetuos con financiamiento histórico y una amplia ola de confiabilidad: estricto-JSON/endurecimiento finito, robustez de sesión/diario, una vectorización de 80× y la solución de transmisión nativa zai. Esta versión está disponible en las versiones PyPI, ClawHub y GitHub.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Destacados

🌀 Cronología del régimen de correlación

Un nuevo punto final aditivo GET /correlation/regime y una franja opcional "Cronología del régimen" en la pestaña Correlación (#756, cierra #719, gracias @ebujinovch). Reutiliza los mismos datos de precios que /correlation ya obtiene: las correlaciones por pares se reducen a un escalar de densidad de borde por barra (la fracción de pares de activos cuyo |ρ| supera un umbral), la serie se suaviza causalmente (ventana final: nunca lee el futuro) y una máquina de estado de histéresis de dos umbrales marca episodios FUSED contiguos, con una banda muerta que suprime la charla. Comparte el presupuesto de límite de tasa y autenticación de /correlation, reduce la ventana para que los plazos cortos no puedan volver vacíos y es explícitamente contexto de riesgo descriptivo, no una señal comercial. Respaldado por la habilidad correlation-regime (#557).

🔌 Tres nuevos proveedores de LLM + sólida resolución de endpoints

Adaptadores nativos para SiliconFlow (CN + Global, #565, gracias @UNHNQ), iFlytek Spark (#537, gracias @FenjuFu) y nativo Anthropic Messages API (#695, gracias @jelech; pip install "vibe-trading-ai[anthropic]"), además de puntos finales regionales MiniMax (#731, gracias @octo-patch). Debajo, las credenciales del proveedor se resuelven a través de una ruta centralizada (#563, gracias @shadowinlife), y se solucionan dos problemas de larga data (#758): cuando no se configura ningún *_BASE_URL, el backend ahora recurre al punto final del catálogo canónico de cada proveedor (la misma configuración web predeterminada que ya se usa) en lugar de usar silenciosamente de forma predeterminada api.openai.com, por lo que un proveedor trabaja solo con una clave, y un punto final que transmite cero fragmentos vuelve a un invocación sin transmisión en lugar de generar errores, con una sugerencia de página de error HTML cuando una URL base está mal configurada.

📈 Conector MetaTrader 5 (Exness) + fuente de datos mt5 — 12 corredores

Un conector de corredor MetaTrader 5 de primera clase (#481, gracias @StaniellG): superficie de lectura completa más colocación de pedidos en una terminal que se ejecuta localmente, con un protector de identidad bidireccional (perfil en papel ⇔ demostración trade_mode, inicio de sesión fijado, concurso rechazado) y límites de nivel de conector max_order_volume / max_order_notional_usd en demostración Y en vivo. La puerta de mandatos en vivo obtiene vocabulario de instrumentos forex/cfd y un gancho de tamaño con reconocimiento de lote para que los límites en USD se vinculen en órdenes de tamaño de lote (0.1 lote EURUSD ≈ $10,800, nunca 0.1 × cotización). El cargador mt5 encabeza la cadena de respaldo de Forex (símbolos exactos del corredor con descubrimiento de sufijo Exness, barras de 1m a 1D). Conectores de intermediario: 11 → 12; fuentes de datos de mercado → 23.

🧬 Gerente de Desarrollo de Estrategia

sdm_register / sdm_status / sdm_decay_scan convierten artículos académicos e investigaciones de intermediarios en factores y estrategias registrados (#457, cierra #455, gracias @shadowinlife), respaldados por un almacén de artefactos SQLite persistente (UNIQUE(name, universe)) y un monitoreo automatizado de deterioro de IC/Sharpe que impulsa un ciclo de vida de active → monitoring → decayed → disabled. Se envía con OCR conectable para read_document (RapidOCR local de forma predeterminada; Qwen-VL en la nube es solo de suscripción explícita, nunca se selecciona automáticamente).

₿ Perpetuos de Binance USD-M

Enrutamiento BTC-USDT-PERP explícito con separación de precio de ejecución/marca (falla cerrada cuando los dos no están sincronizados con la marca de tiempo) y liquidaciones de fondos históricas (#470/#716, gracias @honginp). Los soportes de mantenimiento se desacoplan de la recuperación autenticada en vivo y se suministran como un artefacto validado con contenido hash (#757), por lo que una prueba retrospectiva simple de -PERP sigue siendo credencial cero: la regresión en la que cada recuperación de delincuentes requería una clave Binance API ya no existe.

👁️ OCR conectable + extracción de visión LLM

read_document obtiene una arquitectura de motor de OCR conectable con extracción de visión LLM opcional y un umbral de densidad de texto configurable (#548, gracias @shadowinlife): local de forma predeterminada, los motores en la nube solo se activan, nunca se seleccionan automáticamente.

🧰 Plataforma y seguridad

  • Corrección del sesgo de anticipación en los cinco optimizadores de cartera (#487, gracias @YZY0108): las ponderaciones ejecutadas en la apertura de una barra ya no incluyen el retorno de cierre de esa barra. Además de métricas de rotación de cartera realizadas para cada optimizador (n.º 478, gracias @Robin1987China).
  • Reforzamiento de la seguridad: se cerraron los 10 hallazgos de la auditoría externa del 10 de julio de 2026 (n.° 476): zona de pruebas retrospectiva reforzada con AST, tickets de autenticación SSE de corta duración, redacción reforzada, limitación de velocidad + autenticación /correlation, encabezados de seguridad, dependencias bloqueadas mediante hash y acciones fijadas por SHA.
  • 80× vectorización de alineación de señal (#698, gracias @shadowinlife) y almacenamiento en caché de descubrimiento de herramientas MCP enjambre (#704) cortan el reloj de pared en paneles anchos y ejecuciones de múltiples trabajadores.
  • Modo TAP opcional para Alpaca (n.° 377, gracias @0xZKnw), grupo de conexiones locales de subprocesos de IBKR + citas de instantáneas (n.° 636, gracias @MikeCer), cableado Robinhood account_number (n.° 726, gracias @nareshkps), el proveedor de puerta de enlace Requesty (n.° 474, gracias @Thibaultjaigu) y descubrimiento de ajustes preestablecidos de enjambre de usuarios (#570, gracias @darkknight4563).
  • Dos nuevos factores académicos: apuestas contra beta de Frazzini-Pedersen (#480, gracias @YogeshModi24) y academic_corr_rewire (#705, gracias @ebujinovch): Alpha Zoo 460 → 462 en 5 familias.

🛠️ Ola de confiabilidad y corrección

  • Estricto-JSON/endurecimiento de números finitos en el backtest + conjunto de herramientas (gracias @santhreal): los índices de riesgo permanecen finitos cuando el capital cruza cero (#765) o anualiza una trayectoria explosiva (#739/#740); las métricas escalares (#766), el factor IC std (#767) y el patrón de tendencia-pendiente (#764) emiten el estricto RFC-8259 JSON (null, nunca NaN/Infinity); Los ayudantes de Black-Scholes tratan el punto/strike no positivo como intrínseco (#744).
  • Robustez de la sesión/diario: una línea session.json corrupta (#762) o una línea messages.jsonl con un esquema incorrecto (#763) ya no anula la lista/lectura; Los códigos A-share con cadenas flotantes de Excel (#770), los rangos de páginas PDF con guión Unicode (#769), las líneas dotenv export KEY= (#768) y las barras 1m de Google (#761) se analizan correctamente.
  • Amplia confiabilidad: la cancelación se realiza antes de la primera iteración de AgentLoop (#641, cierra #638), se corrige una carrera DOM de transmisión insertBefore en la interfaz (#717, gracias @Marnie0415), el motor compuesto recurre a símbolos desconocidos (#734), las fallas HTTP del flujo de códice se clasifican para un reintento correcto (#663) y #584 (gracias @xkam7ar) cierra un lote de problemas de packaging/web/scheduler/swarm/CLI.

🙌 Ciclo de colaborador

~90 correcciones de corrección/confiabilidad y características de una amplia cohorte de contribuyentes: @santhreal (un barrido de corrección de 30 PR), @xkam7ar (confiabilidad + endurecimiento de QVeris), @shadowinlife (SDM, OCR, vectorización), @ebujinovch (cronología del régimen), @honginp (delincuentes de Binance), @StaniellG (MetaTrader 5) y muchos más. Los créditos completos por persona se encuentran en la sección README Colaboradores y en CHANGELOG. Gracias también a @GabbaTauchi por el informe de error de zai (#758).

Vibe-Trading v0.1.12

🌀 v0.1.12 — Correlation regime timeline, three new providers, MetaTrader 5 + a reliability wave

v0.1.12 rolls up nearly two weeks of work since 0.1.11 (2026-07-10) — the headlines: a correlation regime timeline that answers "when did the market fuse into one bloc, and are we in that state now?", three new LLM providers plus catalog-based endpoint resolution that makes every provider work with just a key, the MetaTrader 5 (Exness) broker connector (12 brokers), the Strategy Development Manager skill, Binance USD-M perpetuals with historical funding, and a broad reliability wave — strict-JSON/finite hardening, session/journal robustness, an 80× vectorization, and the native zai streaming fix.

This release is available on PyPI, ClawHub, and GitHub Releases.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Highlights

🌀 Correlation regime timeline

A new additive GET /correlation/regime endpoint and an opt-in "Regime timeline" strip on the Correlation tab (#756, closes #719, thanks @ebujinovch). It reuses the same price data /correlation already fetches: rolling pairwise correlations reduce to an edge-density scalar per bar (the fraction of asset pairs whose |ρ| clears a threshold), the series is causally smoothed (trailing window — never reads the future), and a two-threshold hysteresis state machine marks contiguous FUSED episodes, with a dead band that suppresses chatter. It shares /correlation's auth + rate-limit budget, floors the window so short timelines can't return empty, and is explicitly descriptive risk context, not a trading signal. Backed by the correlation-regime skill (#557).

🔌 Three new LLM providers + robust endpoint resolution

Native adapters for SiliconFlow (CN + Global, #565, thanks @UNHNQ), iFlytek Spark (#537, thanks @FenjuFu), and the native Anthropic Messages API (#695, thanks @jelech; pip install "vibe-trading-ai[anthropic]"), plus MiniMax regional endpoints (#731, thanks @octo-patch). Underneath, provider credentials are resolved through one centralized path (#563, thanks @shadowinlife), and two long-standing rough edges are fixed (#758): when no *_BASE_URL is set, the backend now falls back to each provider's canonical catalog endpoint (the same default Web Settings already used) instead of silently defaulting to api.openai.com — so a provider works with just a key — and an endpoint that streams zero chunks falls back to a non-streaming invoke rather than erroring, with an HTML-error-page hint when a base URL is misconfigured.

📈 MetaTrader 5 (Exness) connector + mt5 data source — 12 brokers

A first-class MetaTrader 5 broker connector (#481, thanks @StaniellG) — full read surface plus order placement against a locally running terminal, with a bidirectional identity guard (paper profile ⇔ demo trade_mode, login pinned, contest rejected) and connector-level max_order_volume / max_order_notional_usd caps on demo AND live. The live mandate gate gains forex/cfd instrument vocabulary and a lot-aware sizing hook so USD caps bind on lot-sized orders (0.1 lot EURUSD ≈ $10,800, never 0.1 × quote). The mt5 loader heads the forex fallback chain (broker-exact symbols with Exness suffix discovery, 1m–1D bars). Broker connectors: 11 → 12; market-data sources → 23.

🧬 Strategy Development Manager

sdm_register / sdm_status / sdm_decay_scan turn academic papers and broker research into registered factors and strategies (#457, closes #455, thanks @shadowinlife), backed by a persistent SQLite artifact store (UNIQUE(name, universe)) and automated IC/Sharpe decay monitoring driving an active → monitoring → decayed → disabled lifecycle. Ships with pluggable OCR for read_document (local RapidOCR by default; cloud Qwen-VL is explicit opt-in only, never auto-selected).

₿ Binance USD-M perpetuals

Explicit BTC-USDT-PERP routing with execution/mark price separation (fail-closed when the two aren't timestamp-synchronized) and historical funding settlements (#470/#716, thanks @honginp). Maintenance brackets are decoupled from the live authenticated fetch and supplied as a validated, content-hashed artifact instead (#757), so a plain -PERP backtest stays zero-credential — the regression where every perp fetch required a Binance API key is gone.

👁️ Pluggable OCR + LLM-vision extraction

read_document gains a pluggable OCR engine architecture with optional LLM-vision extraction and a configurable text-density threshold (#548, thanks @shadowinlife) — local by default, cloud engines opt-in only, never auto-selected.

🧰 Platform & safety

  • Look-ahead-bias fix across all five portfolio optimizers (#487, thanks @YZY0108) — weights executed at a bar's open no longer include that bar's close-to-close return. Plus realized portfolio turnover metrics for every optimizer (#478, thanks @Robin1987China).
  • Security hardening — all 10 findings from the 2026-07-10 external audit closed (#476): AST-hardened backtest sandbox, short-lived SSE auth tickets, hardened Compose, /correlation auth + rate limiting, security headers, hash-locked dependencies, and SHA-pinned Actions.
  • 80× signal-alignment vectorization (#698, thanks @shadowinlife) and swarm MCP tool-discovery caching (#704) cut wall-clock on wide panels and multi-worker runs.
  • Opt-in TAP mode for Alpaca (#377, thanks @0xZKnw), IBKR thread-local connection pool + snapshot quotes (#636, thanks @MikeCer), Robinhood account_number wiring (#726, thanks @nareshkps), the Requesty gateway provider (#474, thanks @Thibaultjaigu), and user swarm-presets discovery (#570, thanks @darkknight4563).
  • Two new academic factors — Frazzini-Pedersen betting-against-beta (#480, thanks @YogeshModi24) and academic_corr_rewire (#705, thanks @ebujinovch): Alpha Zoo 460 → 462 across 5 families.

🛠️ Reliability & correctness wave

  • Strict-JSON / finite-number hardening across the backtest + tools stack (thanks @santhreal) — risk ratios stay finite when equity crosses zero (#765) or annualizes an explosive path (#739/#740); scalar metrics (#766), factor IC std (#767), and pattern trend-slope (#764) emit strict RFC-8259 JSON (null, never NaN/Infinity); Black-Scholes helpers treat non-positive spot/strike as intrinsic (#744).
  • Session / journal robustness — one corrupt session.json (#762) or schema-bad messages.jsonl line (#763) no longer aborts listing/reading; Excel float-stringified A-share codes (#770), unicode-dash PDF page ranges (#769), export KEY= dotenv lines (#768), and yahoo 1m bars (#761) all parse correctly.
  • Broad reliability — cancellation is honored before the first AgentLoop iteration (#641, closes #638), a frontend insertBefore streaming DOM-race is fixed (#717, thanks @Marnie0415), the composite engine falls back for unknown symbols (#734), codex stream HTTP failures are classified for correct retry (#663), and #584 (thanks @xkam7ar) closes a batch of packaging/web/scheduler/swarm/CLI issues.

🙌 Contributor cycle

~90 correctness/reliability fixes and features from a wide contributor cohort — @santhreal (a 30-PR correctness sweep), @xkam7ar (reliability + QVeris hardening), @shadowinlife (SDM, OCR, vectorization), @ebujinovch (regime timeline), @honginp (Binance perps), @StaniellG (MetaTrader 5), and many more. Full per-person credits live in the README Contributors section and the CHANGELOG. Thanks also to @GabbaTauchi for the zai bug report (#758).

Install / upgrade

| Channel | Command | |---|---| | PyPI | pip install -U vibe-trading-ai | | uv tool | uv tool install --reinstall vibe-trading-ai | | ClawHub (Claude Desktop / OpenClaw / MCP clients) | clawhub install vibe-trading or update the installed skill | | Docker | docker compose pull && docker compose up -d |

Remote API/Web deployments should set API_AUTH_KEY and explicit trusted CORS origins; local CLI and localhost Web UI workflows stay low-friction.

By the numbers

Numbers at 0.1.12: 8 backtest engines + options_portfolio · 462 alphas / 5 families · 88 skills · 30 swarm presets · 23 market-data sources · 12 broker connectors · 75 free-mode tools (78 with QVeris) · 54 MCP tools · 5 optimizers · 16 IM adapters.

Validation

Full backend suite 6,019 passed (only pre-existing env/network fails, confirmed against clean main); frontend build + 310 vitest green; wheel verified (vibe_trading_ai-0.1.12, contents spot-checked). Protected agent core (src/agent, src/session, src/providers) reviewed for every change.
