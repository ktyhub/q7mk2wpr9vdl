papelclip v2026.525.0

#v2026.525.0

Publicado: 2026-05-25

Destacados

  • El proveedor de entorno de pruebas modal ahora es un complemento propio - Paperclip incluye un complemento de proveedor de entorno de pruebas Modal para que las empresas puedan ejecutar agentes en los entornos de pruebas administrados de Modal junto con E2B, Cloudflare y Daytona, con publicación de CI y tiempos de espera de sonda compatibles con inicio en frío conectados. (#6245, #6289, #6290, @devinfoley)
  • Las diferencias del espacio de trabajo son un complemento de visualización de primera clase - El nuevo complemento de diferenciación del espacio de trabajo representa cambios preparados, no preparados, principales, renombrados, binarios, de gran tamaño y sin seguimiento a través de servicios de host y ranuras para complementos, con paneles divididos/unificados, encabezados fijos y referencias base predeterminadas confiables. (#6071, #6383, @cryppadotta)
  • Las rutinas pueden contener sus propios secretos - El entorno de rutina ahora fluye a través del contrato de tiempo de ejecución con revisiones persistentes, precedencia agent < project < routine y metadatos secretos seguros en la interfaz de usuario/historial de rutina, sin exponer valores secretos en registros o eventos de acceso. (#6212, @cryppadotta)
  • La sincronización local de Cloud Upstream está disponible - Se incluye un nuevo flujo de Cloud Upstream con tipos compartidos, rutas de servidor, esquema de ejecución persistente, asistentes de sincronización CLI, una interfaz de usuario de placa y puntos de entrada de configuración para que los operadores puedan obtener una vista previa, resolver conflictos y activar sincronizaciones locales a la nube. (#6548, @cryppadotta)
  • El adaptador ACPX-Claude funciona perfectamente desde el primer momento - El adaptador acpx_local ahora resuelve ID de modelo Claude desnudo, muestra detalles de diagnóstico reales en lugar de registros opacos de "Error interno" y respeta los permisos del usuario ~/.claude/settings.json para que los agentes ACPX locales de Claude que se ejecuten por primera vez no se queden varados. (#6590, @devinfoley)

Mejoras

  • Permisos de agentes con alcance y controles de asignación: las mutaciones de asignaciones de agentes y problemas ahora se ejecutan a través de un servicio de autorización real con cumplimiento de asignaciones protegidas, complemento SDK/host API para espacios de configuración de la empresa y administración de políticas/subvenciones, posibilidades de reintento ahora en problemas bloqueados y un respaldo incremental de compatibilidad de acceso principal. (#6386, @cryppadotta)
  • La configuración de la bóveda del proveedor de AWS es fácil de usar para el operador - La página Secretos ahora ofrece descubrimiento de la bóveda del proveedor de AWS con relleno previo, flujos de eliminación y cobertura de Storybook, por lo que la configuración de la bóveda externa ya no requiere metadatos escritos a mano. (#6381, @cryppadotta)
  • SecretBindingPicker está conectado a los formularios de configuración del complemento - Los campos de referencia secreta del esquema JSON (E2B, Modal, Cloudflare, Daytona,...) ahora muestran el selector de secretos canónico en lugar de una simple entrada de contraseña, por lo que vincular secretos almacenados ya no requiere copiar y pegar UUID. (#6339, @devinfoley)
  • Las invitaciones de agentes externos se trasladaron al modo Agregar agente - La incorporación de Traiga su propio agente ahora se encuentra junto a la creación de agentes locales/administrados con una vista de resultados orientada al agente y navegación hacia atrás, en lugar de esconderse detrás de la configuración de invitación de la empresa específica de OpenClaw. (#6183, @aronprins)
  • Los flujos del tablero móvil se sienten más fluidos - Se han pulido la altura del diálogo de nuevos temas móviles, el desbordamiento de prioridad, la configuración de navegación de la empresa, la selección de la ruta del complemento en la barra lateral, los controles del navegador en el modo de aplicación de pantalla de inicio y los pequeños errores de desplazamiento de menú/desplazamiento de destino táctil. (#6550, #6384, @cryppadotta)
  • El tiempo de ejecución del complemento tiene un alcance más estricto para su empresa - Las llamadas de trabajador a host del complemento ahora propagan el contexto de invocación propiedad del host, performAction transporta el contexto de actor autenticado, el alcance de invocación de la empresa se aplica en las llamadas puente y los problemas de operación del complemento permanecen fuera de las superficies de problemas normales. (#6547, @cryppadotta)
  • Las rutas de importación de inquilinos y tiempo de ejecución son más confiables - Postgres integrado ahora arranca el tiempo de ejecución nativo antes del inicio de CLI/servidor/prueba, los trabajos de importación de inquilinos asíncronos tienen validación diferida y las importaciones de inquilinos en la nube trusted ya no fallan en la protección de origen del navegador para el tráfico legítimo de servidor a servidor. (#6549, #6378, @cryppadotta)
  • Las transiciones de estado del plano de control son más estrictas - La paginación se clasifica limpiamente en listas de problemas actualizadas, los comentarios de reintento programados se comportan, las migraciones de complementos pendientes se vuelven a aplicar en la recarga en caliente, las semillas del árbol de trabajo del esquema de complementos se restauran de forma segura, las confirmaciones de solicitudes obsoletas caducan después de los comentarios del usuario y la exportación de comentarios se apaga sin bucles de base de datos no disponibles. (#6380, @cryppadotta)
  • El modelo de recuperación barato está aislado del trabajo real - La recuperación de solo estado ahora incluye un contexto de protección explícito, los guardias de ruta bloquean las mutaciones entregables durante las ejecuciones económicas y las sugerencias de perfil económico ya no se filtran en los reintentos normales del trabajo en origen. (#6371, @cryppadotta)
  • Flujo de invitaciones, proyectos y pulido del espacio de trabajo desde la sucursal del 17 de mayo - El aterrizaje de invitaciones reutiliza el asistente de consultas de empresas compartidas, se restaura el comportamiento de invitación de los miembros existentes y el respaldo de copia, la selección de espacios de trabajo reutilizables se selecciona correctamente, la autenticación del árbol de trabajo y el respaldo de SPA estático se corrigen, el ajuste de rebajas y el registro de espacios de complementos se confirman, y la clasificación de páginas de proyectos aterriza. (#6604, #6210, @cryppadotta)
  • Los complementos del proveedor de Sandbox ya no saturan la configuración de la instancia - Los complementos solo para controladores (E2B, exe.dev, Modal) están ocultos del grupo de la barra lateral por complemento, ya que no tienen una página de configuración propia y ya redirigen a Entornos. (#6341, @devinfoley)
  • Las filas de la bandeja de entrada están más limpias - La píldora ámbar "Planificación" se eliminó de IssueRow; El modo de planificación en sí, la alternancia del compositor y el contrato del modo de trabajo no se modifican. (#6269, @cryppadotta)
  • La guía de creación de complementos refleja los recursos administrados - Los documentos de creación de complementos se actualizan para el modelo actual de capacidades administradas, de modo que los autores de complementos no escriban en contra de una guía obsoleta. (#6261, @cryppadotta)

Correcciones

  • Los latidos de E2B dejan de fallar a los 5/11 minutos - La carga de tar del espacio de trabajo ahora elimina los encabezados PAX LIBARCHIVE.xattr.* de macOS que GNU tar rechazó en Linux, y timeoutMs/sleepAfter se actualizan por ejecución para que los entornos limitados de E2B y Cloudflare no caduquen entre latidos. (#6560, @devinfoley)
  • La página de invitación ya no queda en blanco después de iniciar sesión - CompanyProvider y la página de inicio de invitación ahora comparten una única forma de consulta de empresas, lo que soluciona el bloqueo de companiesQuery.data?.some is not a function debido a la colisión clave-clave de React Query. (#6433, @aronprins)
  • La creación de la empresa sobrevive a las colisiones de prefijos envueltos - El detector de reintentos ahora recorre la cadena de causa del error Drizzle 0.45.x para la restricción única companies_issue_prefix_idx, por lo que las colisiones de prefijos generados reintentan en lugar de 500-ing. (#6423, @aronprins)
  • Autocompletar funciona dentro del cuadro de diálogo de nueva edición - Los menús flotantes de autocompletar representados a través de portales a nivel de cuerpo ahora están marcados como interfaz de usuario externa al cuadro de diálogo permitido, por lo que los elementos de finalización se pueden seleccionar dentro de Radix Dialog sin que se consuman eventos de puntero. (#6311, @cryppadotta)
  • paperclip worktree init --force ya no borra <repo>/.paperclip/worktrees/ - La ruta de inicio dejó de eliminar de forma recursiva todo el directorio <repo>/.paperclip/ y ahora solo reescribe config.json y .env. (#6240, @devinfoley)
  • El nuevo formulario secreto sigue siendo utilizable con valores largos - La primitiva Textarea compartida ahora aplica min-w-0 max-w-full, por lo que un secreto largo e irrompible ya no empuja los botones Crear/Cancelar fuera de la pantalla. (#6222, @devinfoley)
  • Las sondas de entorno aislado de arranque en frío ya no tienen tiempo de espera - El tiempo de espera de RPC del trabajador environmentProbe se eleva a 120 segundos para que Modal (y otros proveedores de arranque en frío) terminen de iniciarse antes de que falle la sonda. (#6289, @devinfoley)
  • Docker compilaciones encuentra link-plugin-dev-sdk.mjs - La etapa Dockerfile deps ahora copia el script antes de pnpm install, por lo que el enlace posterior a la instalación de plugin-workspace-diff no falla con Cannot find module. (#6338, @devinfoley)

paperclip v2026.525.0

v2026.525.0

Released: 2026-05-25

Highlights

  • Modal sandbox provider is now a first-party plugin - Paperclip ships a Modal sandbox-provider plugin so companies can run agents on Modal's managed sandboxes alongside E2B, Cloudflare, and Daytona, with CI publishing and cold-start-friendly probe timeouts wired in. (#6245, #6289, #6290, @devinfoley)
  • Workspace diffs are a first-class viewer plugin - The new workspace diff plugin renders staged, unstaged, head, renamed, binary, oversized, and untracked changes through host services and plugin slots, with split/unified panes, sticky headers, and reliable default base refs. (#6071, #6383, @cryppadotta)
  • Routines can carry their own secrets - Routine env now flows through the runtime contract with persisted revisions, agent < project < routine precedence, and safe secret metadata in routine UI/history — without exposing secret values in logs or access events. (#6212, @cryppadotta)
  • Local Cloud Upstream sync is in - A new Cloud Upstream flow ships with shared types, server routes, persisted run schema, CLI sync helpers, a board UI, and settings entry points so operators can preview, resolve conflicts, and activate local-to-cloud syncs. (#6548, @cryppadotta)
  • ACPX-Claude adapter works seamlessly out of the box - The acpx_local adapter now resolves bare Claude model IDs, surfaces real diagnostic detail instead of opaque "Internal error" logs, and respects user ~/.claude/settings.json permissions so first-run Claude Local ACPX agents don't strand. (#6590, @devinfoley)

Improvements

  • Scoped agent permissions and assignment controls - Issue and agent assignment mutations now run through a real authorization service with protected-assignment enforcement, plugin SDK/host APIs for company settings slots and policy/grant management, retry-now affordances on blocked issues, and an incremental principal-access compatibility backfill. (#6386, @cryppadotta)
  • AWS provider vault setup is operator-friendly - The Secrets page now offers AWS provider vault discovery with prefill, removal flows, and Storybook coverage so external vault configuration no longer requires hand-typed metadata. (#6381, @cryppadotta)
  • SecretBindingPicker is wired into plugin config forms - JSON-schema secret-ref fields (E2B, Modal, Cloudflare, Daytona, …) now render the canonical secret picker instead of a plain password input, so binding stored secrets no longer requires copy-pasting UUIDs. (#6339, @devinfoley)
  • External agent invites moved into the add-agent modal - Bring-your-own-agent onboarding now lives next to local/managed agent creation with an agent-oriented prompt result view and Back navigation, instead of hiding behind OpenClaw-specific company invite settings. (#6183, @aronprins)
  • Mobile board flows feel smoother - Mobile new-issue dialog height, priority overflow, company settings nav, plugin-route sidebar selection, browser controls in home-screen app mode, and small touch-target/menu scroll bugs are all polished. (#6550, #6384, @cryppadotta)
  • Plugin runtime is scoped tighter to its company - Plugin worker-to-host calls now propagate host-owned invocation context, performAction carries authenticated actor context, company invocation scope is enforced on bridge calls, and plugin operation issues stay out of normal issue surfaces. (#6547, @cryppadotta)
  • Runtime and tenant import paths are more reliable - Embedded Postgres now bootstraps native runtime before CLI/server/test startup, async tenant import jobs have deferred validation, and trusted Cloud tenant imports no longer fail the browser-origin guard for legitimate server-to-server traffic. (#6549, #6378, @cryppadotta)
  • Control-plane state transitions are tighter - Pagination sorts cleanly on updated issue lists, scheduled retry comments behave, pending plugin migrations re-apply on hot reload, plugin-schema worktree seeds restore safely, stale request confirmations expire after user comments, and feedback export shutdown drains without database-unavailable loops. (#6380, @cryppadotta)
  • Cheap recovery model is fenced off from real work - Status-only recovery now carries explicit guard context, route guards block deliverable mutations during cheap runs, and cheap-profile hints no longer leak into normal source-work retries. (#6371, @cryppadotta)
  • Invite flow, projects, and workspace polish from the May 17 branch land - Invite landing reuses the shared companies query helper, existing-member invite behavior and copy fallback are restored, reusable workspace selection picks correctly, worktree auth and static SPA fallback are fixed, markdown wrapping and plugin slot registration are firmed up, and projects page sorting lands. (#6604, #6210, @cryppadotta)
  • Sandbox-provider plugins no longer clutter Instance Settings - Driver-only plugins (E2B, exe.dev, Modal) are hidden from the per-plugin sidebar group since they have no own settings page and already redirect to Environments. (#6341, @devinfoley)
  • Inbox rows are cleaner - The amber "Planning" pill is removed from IssueRow; planning mode itself, the composer toggle, and the work-mode contract are untouched. (#6269, @cryppadotta)
  • Plugin authoring guide reflects managed resources - The plugin authoring docs are updated for the current managed-capabilities model so plugin authors aren't writing against stale guidance. (#6261, @cryppadotta)

Fixes

  • E2B heartbeats stop failing at 5/11 minutes - The workspace tar upload now strips macOS LIBARCHIVE.xattr.* PAX headers that GNU tar rejected on Linux, and timeoutMs/sleepAfter are refreshed per execute so E2B and Cloudflare sandboxes don't expire between heartbeats. (#6560, @devinfoley)
  • Invite page no longer goes blank after sign-in - CompanyProvider and the invite landing page now share a single companies query shape, fixing the companiesQuery.data?.some is not a function crash from the React Query key-key collision. (#6433, @aronprins)
  • Company creation survives wrapped prefix collisions - The retry detector now walks the Drizzle 0.45.x error cause chain for the companies_issue_prefix_idx unique constraint, so generated-prefix collisions retry instead of 500-ing. (#6423, @aronprins)
  • Autocomplete works inside the new-issue dialog - Floating autocomplete menus rendered through body-level portals are now marked as allowed dialog-external UI, so completion items are selectable inside Radix Dialog without pointer events being eaten. (#6311, @cryppadotta)
  • paperclip worktree init --force no longer wipes <repo>/.paperclip/worktrees/ - The init path stopped recursively removing the whole <repo>/.paperclip/ directory and now only rewrites config.json and .env. (#6240, @devinfoley)
  • New secret form stays usable with long values - The shared Textarea primitive now applies min-w-0 max-w-full, so a long unbreakable secret no longer pushes the Create/Cancel buttons off-screen. (#6222, @devinfoley)
  • Cold-start sandbox probes no longer time out - environmentProbe worker RPC timeout is raised to 120s so Modal (and other cold-start providers) finish booting before the probe fails. (#6289, @devinfoley)
  • Docker builds find link-plugin-dev-sdk.mjs - The Dockerfile deps stage now copies the script before pnpm install, so the plugin-workspace-diff postinstall hook doesn't fail with Cannot find module. (#6338, @devinfoley)

Contributors

Thank you to everyone who contributed to this release!

@aronprins
