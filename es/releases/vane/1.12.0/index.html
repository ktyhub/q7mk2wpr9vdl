paleta v1.12.0

¿Qué ha cambiado?

Este es un lanzamiento importante que presenta una revisión arquitectónica completa. Eliminamos Langchain en favor de una implementación personalizada para un control de bajo nivel sobre la transmisión, la generación y las funciones específicas del proveedor. Esta refactorización sienta las bases para nuevas capacidades en próximas versiones.

Actualizaciones generales

  • Proveedores renombrados a conexiones para una mejor UX. Se agregó un campo de configuración de interruptor, personalización y preferencias separadas.
  • Se corrigieron errores de compilación e inicio de SearxNG.
  • Se agregaron nuevos agentes DIR, sugerencias migradas, agentes de video y audio.
  • Se agregaron tipos de mensajes y fragmentos para una mejor seguridad de tipos.
  • Se agregó representación de bloques de código con resaltado de sintaxis.
  • Se agregó el número de versión y el enlace GitHub en la configuración.
  • Varias mejoras en la interfaz de usuario con animaciones a través de Framer Motion, se corrigieron inconsistencias en el tema y se actualizaron numerosos detalles pequeños pero notables. En general, la interfaz de usuario ahora es más reactiva.

Eliminación de Langchain y sistema de proveedor personalizado

Se eliminó Langchain e implementó clases base y de proveedor personalizadas con los métodos streamText, streamObject, generateText y generateObject. También implementamos llamadas a funciones con transmisión parcial, por lo que la aplicación ahora las usa en lugar del análisis XML (era caótico).

Langchain se elimina para obtener un control de bajo nivel sobre cómo se transmiten las cosas, cómo se generan, etc. Esto nos permite agregar características específicas del proveedor, como salidas estructuradas, y ajustar el proceso de generación.

Nuevo administrador de sesión

Se agregó un nuevo administrador de sesiones donde cada sesión tiene una identificación y se registra durante 30 minutos. Las sesiones se pueden restaurar a través del ID si su página se actualiza o la transmisión se desconecta. El administrador incluye métodos para bloquear transmisión, reproducción, múltiples oyentes, etc.

Reconexión automática de la transmisión: si la página se actualiza o la transmisión se desconecta, ahora podrás volver a conectarte automáticamente a la transmisión. La aplicación continúa desde donde lo dejó el LLM y transmite toda la respuesta que se generó antes, lo que permite que los mensajes continúen sin esperar a que se completen.

##Aparatos

Se agregaron widgets que se extraen y ejecutan en paralelo a la investigación. Obtienen tipos específicos de datos como el clima, información bursátil y resultados calculados (próximamente habrá más widgets). Cada widget está representado con una tarjeta UI específica que mejora la UX.

Reproductores disponibles actualmente:

  • Información meteorológica
  • Datos del mercado de valores
  • Cálculos matemáticos

Clasificación de consultas e investigador con acciones

Clasificación de consultas: cada consulta ahora se clasifica antes de que comience la investigación, lo que garantiza fuentes adecuadas y extracción de información de widgets.

Clase de investigador con acciones: el investigador utiliza acciones (que utilizan llamadas a herramientas), junto con acciones específicas para razonar. Esto permite al investigador tener muchas acciones como búsqueda web, scraping, búsqueda de sitios web específicos, búsqueda de discusiones, búsqueda de carga de archivos, etc. Permite la posibilidad de agregar más acciones e integraciones como Google Workspace (Calendario, Gmail, etc.) en futuras versiones.

Modo de investigación profunda (Beta)

Se agregó un modo de búsqueda de calidad (investigación profunda) donde el LLM razona de manera iterativa sobre los datos recopilados para predecir la siguiente acción. Toma las medidas adecuadas hasta que está seguro de que tiene suficiente información para responder y luego prepara un informe largo y completo. Esto permite una exploración más profunda de los temas y la preparación de informes detallados.

Nota: La investigación profunda se encuentra actualmente en versión beta. Hay mucho más por venir en esta función, como la creación de documentos, imágenes, archivos, gráficos, etc. para preparar informes adecuados.

Modos de investigación actualizados

Modo equilibrado: ahora también obliga al LLM a razonar (aunque solo tiene un número máximo limitado de acciones para el uso controlado de tokens).

Modo de velocidad: se ejecuta sin ningún razonamiento para respuestas rápidas.

Transmisión basada en parches Block y JSON

Ahora todos y cada uno de los pasos del LLM se transmiten para que pueda ver lo que está haciendo el LLM, para que no se sienta estancado. Esto proporciona visibilidad en tiempo real del proceso de investigación.

Nuevo administrador de carga y búsqueda de archivos mejorada

Se agregó un nuevo administrador de carga y una tienda de carga para manejar la carga de archivos y realizar búsquedas. Admite archivos PDF, DOCX y de texto sin límites estrictos de tamaño o número de archivos (dentro de límites razonables).

El administrador permite buscar en varios archivos con consultas que luego se reclasifican y seleccionan mediante RRF (Reciprocal Rank Fusion), lo que mejora significativamente la calidad de la recuperación.

Sistema fuente rediseñado

Los modos de enfoque se eliminan y se reemplazan con 3 fuentes: web, académica y discusiones. Permiten buscar lo que dicen, se pueden alternar individualmente y puedes usar los 3 a la vez o desactivar por completo las fuentes de datos externas para trabajar solo con los archivos cargados.

Vane v1.12.0

Highlights

  • Langchain out, custom provider core in — v1.12.0 is an architectural rewrite: Langchain is replaced by hand-rolled base and provider classes exposing streamText, streamObject, generateText, and generateObject. The payoff is low-level control over streaming/generation and support for provider-specific features like structured outputs, but the integration layer is effectively rewritten from 1.11.x — budget time to re-test any custom provider wiring rather than assuming a drop-in upgrade.

  • Function calling replaces XML tool parsing — Tool use now runs through function calling with partial streaming instead of the old XML parsing the team calls "chaotic." This is both a capability and a compatibility change: you gain incremental argument streams, but anything keyed to the legacy XML tool format breaks.

  • Session manager with automatic stream reconnection — Sessions now carry an ID and are recorded for 30 minutes, with replay, block streaming, and multi-listener support. On a page refresh or dropped stream the app reconnects by ID and replays everything generated so far, letting responses resume instead of restarting. Meaningful reliability win — worth testing against your own refresh/timeout patterns.

  • Source system redesign (breaking) — "Focus modes" are removed and replaced by three independently toggleable sources: web, academic, and discussions. You can enable all three or disable them entirely to work only with uploaded files. Any automation, config, or docs referencing the old focus-mode names need updating.

  • Query classification, action-based researcher, and Deep Research beta — Every query is classified before research so sources and widgets are selected correctly, and the researcher now acts via tool calling (web search, scraping, site/discussion search, file search — with room for Gmail/Calendar-style integrations later). Balanced mode now forces limited reasoning, Speed mode drops reasoning for fast answers, and the new Deep Research beta reasons iteratively until it has enough to produce a long report — still beta, so expect churn.

  • Block/JSON Patch streaming, new upload manager, and widgets — Each LLM step is streamed (block + JSON Patch), so the UI shows live progress instead of looking stuck. A new upload manager/store handles PDF, DOCX, and text with no hard size or count ceiling (within reason) and reranks multi-file results via RRF for better retrieval. Widgets (weather, stock, calculations) are extracted and executed in parallel with research as UI cards. Also note providers are renamed to "connections," with a new switch config field and personalization/preferences split — a config-level change to watch on upgrade.

What's Changed

This is a major release featuring a complete architectural overhaul. We've removed Langchain in favor of a custom implementation for low-level control over streaming, generation, and provider-specific features. This refactor lays the groundwork for new capabilities in upcoming releases.

General Updates

  • Renamed providers to connections for better UX. Added switch config field, separated personalization and preferences.
  • Fixed SearxNG build and startup errors.
  • Added new agents DIR, migrated suggestions, video and audio agents.
  • Added message and chunk types for better type safety.
  • Added code block rendering with syntax highlighting.
  • Added version number and GitHub link in settings.
  • Various UI improvements with animations via Framer Motion, fixed theme inconsistencies, and updated numerous small but noticeable details. Overall the UI is more reactive now.

Langchain Removal & Custom Provider System

Removed Langchain and implemented custom base and provider classes with streamText, streamObject, generateText and generateObject methods. We've also implemented function calling with partial streaming so the app now uses it instead of XML parsing (was a chaotic one).

Langchain is removed to get low-level control over how things are streamed, how things are generated, etc. This allows us to add provider-specific features like structured outputs and fine-tune the generation process.

New Session Manager

Added a new session manager where each session has an ID and is recorded for 30 minutes. Sessions can be restored via the ID if your page refreshes or the stream disconnects. The manager includes methods for block streaming, replaying, multiple listeners, etc.

Automatic Stream Reconnection: If the page gets refreshed or the stream is disconnected, you'll now be able to automatically reconnect to the stream. The app resumes from where the LLM left off and streams back the entire response that was generated before, allowing messages to continue without waiting for completion.

Widgets

Added widgets that are extracted and executed in parallel to the research. They fetch specific types of data like weather, stock information, and calculated results (more widgets coming soon). Each widget is represented with a specific UI card which enhances the UX.

Widgets currently available:

  • Weather information
  • Stock market data
  • Mathematical calculations

Query Classification & Researcher with Actions

Query Classification: Each query is now classified before research begins, ensuring proper sources and widget information extraction.

Researcher Class with Actions: The researcher uses actions (which use tool calling), along with specific actions for reasoning. This allows the researcher to have many actions like web search, scraping, specific website search, discussion search, file uploads search, etc. It enables the possibility of adding more actions and integrations like Google Workspace (Calendar, Gmail, etc.) in future releases.

Deep Research Mode (Beta)

Added quality search mode (deep research) where the LLM reasons iteratively over the collected data to predict the next action. It takes appropriate actions until it's confident it has enough information to answer, then prepares a long, comprehensive report. This allows deeper exploration of topics and preparing detailed reports.

Note: Deep research is currently in beta. There's a lot more to come in this feature like creating documents, images, files, charts, etc. to prepare proper reports.

Updated Research Modes

Balanced Mode: Now also forces the LLM to reason (though it only has a limited maximum number of actions for controlled token usage).

Speed Mode: Runs without any reasoning for fast responses.

Block & JSON Patch Based Streaming

Now each and every step of the LLM is streamed so you can see what the LLM is doing, so it doesn't feel stuck. This provides real-time visibility into the research process.

New Upload Manager & Enhanced File Search

Added a new upload manager and upload store for handling file uploads and searching. It supports PDF, DOCX, and text files with no hard limits on file size or number (within reasonable limits).

The manager allows searching across multiple files with queries that are then reranked and selected via RRF (Reciprocal Rank Fusion), enhancing retrieval quality significantly.

Redesigned Source System

Focus modes are removed and replaced with 3 sources: web, academic, and discussions. They allow searching for what they say, can be toggled individually, and you can use all 3 at once or disable external data sources entirely to work only with uploaded files.
