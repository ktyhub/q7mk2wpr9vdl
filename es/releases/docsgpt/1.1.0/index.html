DocsGPT 1.1.0

Highlights

  • Lower-cost multi-turn inference — Responses prompt caching now persists across conversation turns, with replayed reasoning included in accounting; /v1 usage also reports cached prompt tokens, making cache savings auditable in API integrations (#3033, #3064).
  • Artifacts survive the full workflow — Word artifacts are richer, API clients can download generated artifacts, and attachments can be reference-only (#3060). Paused turns retain attachments and execution state when resumed (#3063), while chat artifact cards and previews make outputs easier to inspect (#3095).
  • Incremental ingestion and context controls — Reingestion now re-embeds only changed material, and manage_source_files sync replaces a source’s files in place rather than rebuilding everything (#3170). A new context-limit feature adds explicit control over retrieval context (#3175); whole-source ingestion is routed to a dedicated Celery queue to isolate long-running jobs (#3124).
  • Optional model-driven retrieval and safety layers — Model-scored reranking and decision prescreening are available but off by default, so enabling them adds model calls, latency, and cost that should be benchmarked before production rollout (#3097). The decision harness, API mode, injection checks, model-based prompt-injection scanning, and conversation analytics are likewise opt-in capabilities (#3092, #3117, #3121).
  • More connectors, narrower Drive permissions — New MCP presets cover CoinGecko, Alpha Vantage, Neon, Context7, and Airtable; scheduled and webhook agent runs can also use the code executor (#3079, #3039, #3056, #3059, #2950, #3081). Google Drive now requests drive.file access, reads folders through a service account, and links Drive, SharePoint, and Confluence citations to original files—existing folder integrations should verify their service-account setup and OAuth scopes (#3169, #3155).
  • Client and pipeline upgrades need attention — Published widget libraries have reached 0.13.0, adding translated UI, a JavaScript API, conversation history, sidebar layout, and suggested questions; update embed scripts and test custom styling/configuration against the new release (#3139, #3153). Retrieval chunking now supports token overlap, so re-ingested sources may produce different boundaries (#2919). Python integrations using PyPDF2 directly should migrate to pypdf, as PyPDF2 has been dropped (#3150).

No explicit breaking changes are called out in this release.
