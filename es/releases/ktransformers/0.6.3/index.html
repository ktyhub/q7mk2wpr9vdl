ktransformadores v0.6.3

KTransformers: MiniMax-M3 y GLM-5.2 Soporte del día 0

Nos complace anunciar la compatibilidad del día 0 con dos nuevos modelos MoE grandes: MiniMax-M3 y GLM-5.2 en KTransformers + SGLang (sglang-kt). Ambos modelos ahora están disponibles para inferencia heterogénea CPU-GPU a través de kt-kernel. Esta actualización también incluye servicio KT LoRA de extremo a extremo para Qwen3.5 MoE.

🚀 Aspectos destacados principales

  • Soporte MiniMax-M3 Day0: soporte completo de inferencia para la arquitectura MoE dispersa de 128 enrutados expertos de MiniMax (MiniMaxAI/MiniMax-M3-MXFP8). Se ejecuta en una única GPU de 96 GB o se escala a 8 × GPU con descarga experta de CPU kt-kernel.
  • Soporte GLM-5.2 Día 0: soporte de inferencia completo para GLM-5.2 (zai-org/GLM-5.2, zai-org/GLM-5.2-FP8) de Zhipu AI, con precisión FP8 y BF16, backend de atención de la NSA y actualizaciones dinámicas de expertos a través de kt-kernel.
  • Servicio de KT LoRA: flujo de trabajo de servicio de KT LoRA Qwen3.5 MoE de extremo a extremo: entrene con KT SFT, convierta una vez, sirva a través de SGLang con una única ruta de adaptador fusionada.

📌 KT LoRA sirviendo para Qwen3.5 MoE

Un nuevo flujo de trabajo de ajuste fino de servicio de extremo a extremo para Qwen3.5 MoE con LoRA experto en KT:

  • Canalización de adaptador unificada: salida sin procesar de KT SFT → convert_kt_to_sglang_adapter.py → directorio de adaptador fusionado → servicio SGLang --lora-paths.
  • LoRA experto + no experto: el servidor divide automáticamente los pesos LoRA expertos y no expertos internamente; los usuarios sirven una única ruta de adaptador fusionada.
  • Mejoras del kernel SFT: kernels AMX SFT MoE refactorizados, actualizaciones de la base AVX2 MoE y ayudantes SFT MoE paralelos al tensor.
  • Documentos: Bucle de inferencia y ajuste fino de KT-FT (EN) | 中文

📌GLM-5.2

GLM-5.2 es el último modelo MoE de Zhipu AI con NSA (Native Sparse Attention). KTransformers lo apoya con:

  • Precisión FP8 y BF16: Se admiten tanto zai-org/GLM-5.2-FP8 como zai-org/GLM-5.2.
  • Backend de atención de la NSA: atención dispersa nativa con indexador activado por skip_topk para capas DSA.
  • Actualizaciones dinámicas de expertos: --kt-enable-dynamic-expert-update con estrategia de ubicación uniforme.
  • Llamadas y razonamiento de herramientas: analizador de llamadas de herramientas glm47 y analizador de razonamiento glm45. 👉 Tutorial completo

📌MiniMax-M3

MiniMax-M3 es un modelo MoE disperso de 128 expertos enviado de forma nativa en MXFP8 (escala fp8 e4m3 + uint8 ue8m0 1×32). KTransformers admite M3 de extremo a extremo con:

  • Híbrido KT-Kernel: descarga de CPU experta con copia de bytes MXFP8 y vista GPU Shadow FP8; validado en 8×H20 y H20 simple.
  • MXFP8: ruta de inferencia directa de MXFP8 en GPU Hopper a través del backend Triton MoE.
  • Llamada de herramientas: analizador de llamada de función minimax-m3 (matriz nativa <minimax:tool_call> XML → OpenAI tool_calls).
  • Modo de pensamiento: control de nivel de solicitud a través de chat_template_kwargs.thinking_mode — enabled / disabled / adaptive. 👉 Tutorial completo

📥 Instalación

# Option A: One-click install (from ktransformers root)
git clone https://github.com/kvcache-ai/ktransformers.git
cd ktransformers
git submodule update --init --recursive
cd kt-kernel && ./install.sh
cd .. && ./install.sh

# Option B: pip install
pip install sglang-kt
pip install kt-kernel

Requiere CUDA 12.0+; CUDA 12.8+ recomendado para implementaciones FP8/MXFP8.

ktransformers v0.6.3

KTransformers: MiniMax-M3 & GLM-5.2 Day0 Support

We're excited to announce Day0 support for two new large MoE models: MiniMax-M3 and GLM-5.2 in KTransformers + SGLang (sglang-kt). Both models are now available for CPU-GPU heterogeneous inference via kt-kernel. This update also ships end-to-end KT LoRA serving for Qwen3.5 MoE.

🚀 Core Highlights

  • MiniMax-M3 Day0 Support: Full inference support for MiniMax's 128-routed-expert sparse MoE architecture (MiniMaxAI/MiniMax-M3-MXFP8). Runs on a single 96 GB GPU or scales to 8×GPU with kt-kernel CPU expert offload.
  • GLM-5.2 Day0 Support: Full inference support for Zhipu AI's GLM-5.2 (zai-org/GLM-5.2, zai-org/GLM-5.2-FP8), with FP8 and BF16 precision, NSA attention backend, and dynamic expert updates via kt-kernel.
  • KT LoRA Serving: End-to-end Qwen3.5 MoE KT LoRA serving workflow — train with KT SFT, convert once, serve through SGLang with a single merged adapter path.

📌 KT LoRA Serving for Qwen3.5 MoE

A new end-to-end fine-tuning-to-serving workflow for Qwen3.5 MoE with KT expert LoRA:

  • Unified adapter pipeline: KT SFT raw output → convert_kt_to_sglang_adapter.py → merged adapter directory → SGLang --lora-paths serving.
  • Expert + non-expert LoRA: the server auto-splits expert and non-expert LoRA weights internally; users serve a single merged adapter path.
  • SFT kernel improvements: refactored AMX SFT MoE kernels, AVX2 MoE base updates, and tensor-parallel MoE SFT helpers.
  • Docs: KT-FT Fine-Tuning and Inference Loop (EN) | 中文

📌 GLM-5.2

GLM-5.2 is Zhipu AI's latest MoE model with NSA (Native Sparse Attention). KTransformers supports it with:

  • FP8 and BF16 precision: Both zai-org/GLM-5.2-FP8 and zai-org/GLM-5.2 are supported.
  • NSA attention backend: Native sparse attention with skip_topk-gated indexer for DSA layers.
  • Dynamic expert updates: --kt-enable-dynamic-expert-update with uniform placement strategy.
  • Tool calling & reasoning: glm47 tool-call parser and glm45 reasoning parser.

👉 Full Tutorial

📌 MiniMax-M3

MiniMax-M3 is a 128-expert sparse MoE model shipped natively in MXFP8 (fp8 e4m3 + uint8 ue8m0 1×32 scale). KTransformers supports M3 end-to-end with:

  • KT-Kernel hybrid: CPU expert offload with MXFP8 byte-copy and GPU shadow FP8 view; validated on 8×H20 and single H20.
  • MXFP8: Direct MXFP8 inference path on Hopper GPUs via Triton MoE backend.
  • Tool calling: minimax-m3 function-call parser (native <minimax:tool_call> XML → OpenAI tool_calls array).
  • Thinking mode: Request-level control via chat_template_kwargs.thinking_mode — enabled / disabled / adaptive.
