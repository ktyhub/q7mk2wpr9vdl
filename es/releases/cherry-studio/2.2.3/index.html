<summary>Release Note</summary> Cherry Studio 2.2.3: clasificación de conversaciones, nuevos modelos y confiabilidad de los agentes ✨ Nuevas características - [Conversaciones] Agrupar y ordenar ahora son independientes. Ordene por última actualización, fecha de creación, nombre (con orden de números naturales) u orden manual, y se conservan los pedidos personalizados existentes. - [Agente] Importe exportaciones de DeepSeek v3 a un Agente DeepSeek creado automáticamente, manteniendo el historial, las ramas, el razonamiento, los registros de búsqueda y los archivos adjuntos disponibles. - [Agente] Se sugiere un siguiente mensaje breve después de las respuestas: presione Tab para aceptar sin enviar, o Escape para descartar. Las sugerencias se pueden desactivar en la configuración de entrada. - [Agente] Puedes cargar una imagen de avatar mientras creas un Agente. - [Agente] La aprobación automática de comandos ahora analiza Bash y PowerShell con reglas de riesgo compartidas y pregunta antes de cada comando riesgoso. Las tarjetas de aprobación muestran la tarea solicitante, el directorio de trabajo y el motivo. (Acción requerida: revise los modos de permiso si confía en las indicaciones existentes; los comandos incomparables se ejecutan automáticamente, mientras que las denegaciones obligatorias aún se aplican en Acceso completo). - [Navegador] Las barras laterales de conversación admiten múltiples pestañas retenidas con estilos unificados y menús contextuales, usan la página de inicio configurada y cierran con su última página. - [Vista previa del archivo] Las presentaciones de diapositivas PPTD ahora tienen una vista previa en la aplicación con navegación de página, zoom, miniaturas, actualización y una vista de origen. - [Archivos] Rutas de archivos y enlaces de Markdown con números de línea saltan y resaltan la línea a la que se hace referencia en la vista previa. - [Archivos] El cuadro de diálogo de selección de archivos se abre en la carpeta del último archivo que seleccionó durante la sesión actual. - [Chat] Se agregó una preferencia Apariencia → Mensajes, "Desplazarse hasta el último mensaje al enviar" (activado de forma predeterminada). - [Chat] Las listas largas de archivos entregables muestran los primeros tres archivos y le permiten expandir o contraer el resto. - [Chat] Ctrl + rueda del mouse hace zoom en la interfaz, muestra el nivel de zoom mientras se desplaza y Ctrl+0 lo restablece. - [Conocimiento] La fuente de URL acepta varios enlaces a la vez (separados por nuevas líneas, comas o espacios), agrega cada URL válida por separado e informa entradas no válidas individualmente. - [Pinturas] Las imágenes generadas muestran el modelo y el tamaño devuelto, y se guardan en su formato original en lugar de convertirse siempre a PNG. - [Uso de la computadora] Un nuevo interruptor de "Entrada global" exclusivo de Linux (desactivado de forma predeterminada) permite a los agentes controlar el puntero del mouse compartido y el teclado del sistema. - [Modelos] Se agregaron GPT-6.2 Astra y Sol, Gemini 4 Carbon and Hydrogen con controles de razonamiento, Tencent Hunyuan 4 Flash y Mistral Large 4 controles de razonamiento. - [Modelos] Las estimaciones de costos propios de DeepSeek ahora utilizan tarifas pico y valle de lunes a viernes, manteniendo precios personalizados. (Acción requerida: revise las estimaciones de costos locales si se basó en estimaciones solo para horas pico). - [Modelos] Los proveedores habilitados ahora aparecen primero en la lista de servicios de modelos y los selectores de modelos principales se pueden abrir en un modo de diálogo recordado. - [Mercado] Las habilidades seleccionadas se pueden filtrar por categoría, con búsqueda y navegación por categorías horizontales. - [Compositor] Al pegar carpetas copiadas en las conversaciones del Agente se agregan referencias a carpetas en lugar de archivos adjuntos fallidos. - [Exportar] Las exportaciones de obsidiana etiquetan cada mensaje del asistente con el modelo que lo produjo. - [Atajos] Los atajos numéricos (1 a 9) tienen un ajuste preestablecido de desactivación explícito en Configuración → Atajos. - [Voz] El modelo de reconocimiento ahora tiene una opción Desactivada que desactiva el dictado local sin eliminar el idioma guardado ni las teclas de acceso rápido. - [Código CLI] Qwen Code 1.0 se puede instalar desde su versión GitHub. - [Aplicación] Se agregó soporte para el idioma checo (cs-CZ). 🐛 Corrección de errores - [Chat] El contenido desplazable anidado, como vistas previas de código, editores y artefactos incrustados, se desplaza de forma independiente mientras se desplaza la lista de mensajes. - [Chat] Conversaciones restauradas desde Configuración → Archivo abiertas con sus mensajes en lugar de una conversación vacía. - [Chat] Las respuestas transmitidas interrumpidas se informan como errores de conexión y se guarda una salida parcial para volver a intentarlo, en lugar de una respuesta AI no válida. - [Chat] Las pestañas plegables de varios modelos muestran nuevamente el nombre de cada modelo, con un cambio para volver a las pestañas compactas. - [Chat] Las solicitudes de chat que exceden la ventana de contexto del modelo se recuperan de manera más confiable. - [Notas] LaTeX escrito con \[ … \] y \( … \) se representa nuevamente en el editor de Notas. - [Chat] La barra de cambio de tamaño del panel lateral del navegador se puede arrastrar a lo largo de toda su altura. - [Agente] El texto del Asistente emitido antes o entre llamadas a herramientas es visible nuevamente en las sesiones del Agente. - [Agente] Pi Durable: Detener mantiene la sesión abierta y la respuesta en pausa; la reapertura después de salir continúa una respuesta interrumpida o muestra su resultado real; los mensajes enviados mientras el agente trabaja se guardan y responden en orden; un mensaje retirado se marca como "Detenido antes de enviar" con Reenviar y Editar. - [Agente] Los mensajes enviados mientras se ejecuta un turno se reconocen y se actúa en consecuencia en lugar de ignorarse silenciosamente. - [Agente] Una aprobación pendiente se borra cuando finaliza su tarea en segundo plano, por lo que la respuesta ya no permanece en Pendiente. - [Agente] La selección del modelo tiene como alcance cada sesión, por lo que cambiar una sesión ya no cambia las sesiones hermanas. - Las conversaciones de [Agente] Claude Code se pueden bifurcar o editar después de reintentar o compactar la herramienta cuando el SDK puede preservar su contexto. - [Agente] En el modo Aceptar ediciones, Claude Code pregunta antes de ejecutar un comando Bash escalado en lugar de ejecutarlo automáticamente por su primera palabra. - [Agente] El historial de sesiones del agente repara los árboles de mensajes durante la actualización y evita modificaciones en las entregas en vuelo. - [Agente] Un turno de Agente se recupera cuando un directorio ocupa su nombre de almacén duradero en lugar de fallar con un error de red. - [Agente] Los controles de esfuerzo de razonamiento, nivel de servicio y rápido permanecen disponibles al editar y reenviar un mensaje histórico. - [Agente] Los mensajes históricos siguen el avatar actual del Agente y se aplica un avatar elegido tarde durante la creación. - [Agente] Asistente de selección: las ventanas reutilizadas ya no se abren en el tamaño completo de la conversación, una ventana cerrada ya no deja una cápsula perdida y el panel se abre encima de la aplicación activa. - [Agente] Las solicitudes de agente enviadas a través de HTTP o puertas de enlace en proceso mantienen los metadatos del protocolo, la configuración de Gemini, los archivos generados y el estado de continuación. - [Agente] Los resultados ilegibles de la herramienta de automatización almacenados se informan al modelo como una nota en lugar de interrumpir la conversación. - [Agente] NO_PROXY ya no incluye entradas CIDR IPv6 o IPv6 entre corchetes que interrumpieron Python HTTP clients en las sesiones del Agente. - [Modelos] Las comprobaciones de conexión de modelos ahora utilizan la transmisión para modelos con capacidad de transmisión y detectan respuestas incompletas o fallidas. - [Modelos] Los parámetros de muestreo no admitidos y las penalizaciones ya no se envían a los proveedores, y los rangos de muestreo declarados se aplican después de las anulaciones de solicitudes. - [Modelos] Las llamadas a la herramienta Gemini ya no fallan cuando un esquema contiene nombres de propiedades. - [Modelos] Un rechazo único de cuota de Cherry Cloud ya no bloquea un modelo mientras permanece la cuota del plan; el servidor decide las negativas y muestra su espera sugerida. - [Modelos] Los puntos finales del modelo guardado de CherryIN se actualizan automáticamente desde el servidor y mantienen los valores locales cuando falla el descubrimiento. - [Modelos] CherryAI aparece primero con una suscripción paga y al final sin ella. - [Modelos] Los rechazos de solicitudes de proveedores sin estado HTTP se informan como errores de solicitud en lugar de interrupciones de la red. - [Modelos] Las estadísticas de uso recuperan depósitos de caché del proveedor y los costos calculados localmente se etiquetan como estimaciones. - [Modelos] Las sesiones del agente en modelos compatibles con OpenAI, vLLM o llama.cpp informan hasta qué punto una solicitud excede la ventana de contexto. - [Modelos] Los turnos de proveedores cancelados ahora fallan en lugar de informar una parada exitosa. - [Archivos] Los íconos de tipos de archivos se muestran sin conexión y se mantienen consistentes en todos los árboles de archivos, vistas previas y archivos adjuntos. - [Archivos] Los árboles de archivos y las vistas previas se mantienen actualizados, muestran el progreso y los errores de guardado y admiten la actualización del alcance sin perder los borradores locales. - [Conocimiento] El cuadro de diálogo Agregar URL rechaza inmediatamente las direcciones que no sean http(s). - [Conocimiento] Tareas MinerU 4.1 autohospedadas El análisis API es compatible mientras que los protocolos más antiguos aún funcionan. - [Comentarios] Los informes de problemas nuevamente incluyen registros, registros de actividad e historial de chat de las últimas 24 horas; Se eliminaron los interruptores de accesorios individuales. - [Tareas programadas] El historial de ejecución registrado antes de 2.2.0, o cuya conversación se eliminó, se puede abrir y muestra el resultado almacenado. - [Habilidades] Las habilidades integradas exclusivas de Cherry ya no se exportan al directorio compartido ~/.agents/skills. - [Agentes] Reduce los fallos por falta de memoria cuando los subagentes procesan muchas imágenes en paralelo. - [Cherry AI] Cargue el catálogo de modelos desde el servidor y muestre los requisitos de inicio de sesión, suscripción o autorización AMD; detectar modelos eliminados de la lista. Cherry Studio 2.2.3 - Conversation Sorting, New Models, and Agent Reliability

✨ New Features

  • [Conversations] Grouping and sorting are now independent. Sort by last updated, creation date, name (with natural number order), or manual order, and existing custom orders are preserved.
  • [Agent] Import DeepSeek v3 exports into an automatically created DeepSeek Agent, keeping history, branches, reasoning, search records, and available attachments.
  • [Agent] A short next prompt is suggested after replies: press Tab to accept without sending, or Escape to dismiss. Suggestions can be turned off in input settings.
  • [Agent] You can upload an image avatar while creating an Agent.
  • [Agent] Automatic command approval now parses Bash and PowerShell with shared risk rules and asks before each risky command. Approval cards show the requesting task, working directory, and reason. (action required: review permission modes if you rely on the existing prompts; unmatched commands run automatically, while mandatory denials still apply in Full Access.)
  • [Browser] Conversation sidebars support multiple retained tabs with unified styling and context menus, use the configured homepage, and close with their last page.
  • [File Preview] PPTD slide decks now preview in the app with page navigation, zoom, thumbnails, refresh, and a source view.
  • [Files] File paths and Markdown links with line numbers jump to and highlight the referenced line in the preview.
  • [Files] The file selection dialog opens in the folder of the last file you selected during the current session.
  • [Chat] Added an Appearance → Messages preference, "Scroll to the latest message on send" (on by default).
  • [Chat] Long deliverable file lists show the first three files and let you expand or collapse the rest.
  • [Chat] Ctrl + mouse wheel zooms the interface, shows the zoom level while scrolling, and Ctrl+0 resets it.
  • [Knowledge] The URL source accepts several links at once (separated by newlines, commas, or spaces), adds each valid URL separately, and reports invalid entries individually.
  • [Paintings] Generated images show the model and returned size, and are saved in their original format instead of always being converted to PNG.
  • [Computer Use] A new Linux-only "Global input" switch (off by default) lets agents control the shared mouse pointer and system keyboard.
  • [Models] Added GPT-6.2 Astra and Sol, Gemini 4 Carbon and Hydrogen with reasoning controls, Tencent Hunyuan 4 Flash, and Mistral Large 4 reasoning controls.
  • [Models] DeepSeek first-party cost estimates now use weekday peak and off-peak rates while keeping custom prices. (action required: review local cost estimates if you relied on peak-only estimates.)
  • [Models] Enabled providers now appear first in the model service list, and primary model pickers can open in a remembered dialog mode.
  • [Marketplace] Curated skills can be filtered by category, with search and horizontal category navigation.
  • [Composer] Pasting copied folders into Agent conversations adds folder references instead of failing file attachments.
  • [Export] Obsidian exports label each assistant message with the model that produced it.
  • [Shortcuts] Number shortcuts (1–9) have an explicit Off preset in Settings → Shortcuts.
  • [Voice] The recognition model now has an Off option that disables local dictation without removing the saved language or hotkeys.
  • [Code CLI] Qwen Code 1.0 can be installed from its GitHub release.
  • [App] Added Czech (cs-CZ) language support.

🐛 Bug Fixes

  • [Chat] Nested scrollable content such as code previews, editors, and embedded artifacts scrolls independently while the message list scrolls.
  • [Chat] Conversations restored from Settings → Archive open with their messages instead of an empty conversation.
  • [Chat] Interrupted streamed responses are reported as connection errors with partial output kept for retry, instead of an invalid AI response.
  • [Chat] Multi-model fold tabs show every model name again, with a toggle back to compact tabs.
  • [Chat] Chat requests that exceed the model context window recover more reliably.
  • [Notes] LaTeX written with [ … ] and ( … ) renders again in the Notes editor.
  • [Chat] The browser side-panel resize bar is draggable along its full height.
  • [Agent] Assistant text emitted before or between tool calls is visible again in Agent sessions.
  • [Agent] Pi Durable: Stop keeps the session open and the reply paused; reopening after quitting continues an interrupted reply or shows its real result; messages sent while the agent works are saved and answered in order; a withdrawn message is marked "Stopped before sending" with Resend and Edit.
  • [Agent] Messages sent while a turn is running are acknowledged and acted on instead of being silently ignored.
  • [Agent] A pending approval is cleared when its background task ends, so the reply no longer stays on Pending.
  • [Agent] Model selection is scoped to each session, so changing one session no longer changes sibling sessions.
  • [Agent] Claude Code conversations can be forked or edited after tool retries or compaction when the SDK can preserve their context.
  • [Agent] In Accept Edits mode, Claude Code asks before running an escalated Bash command instead of auto-running it by its first word.
  • [Agent] Agent session history repairs message trees during upgrade and prevents edits to in-flight deliveries.
  • [Agent] An Agent turn recovers when a directory occupies its durable store name instead of failing with a network error.
  • [Agent] Reasoning-effort, service-tier, and Fast controls stay available when editing and resending a historical message.
  • [Agent] Historical messages follow the Agent's current avatar, and an avatar chosen late during creation is applied.
  • [Agent] Selection assistant: reused windows no longer open at full conversation size, a closed window no longer leaves a stray capsule, and the panel opens above the active app.
  • [Agent] Agent requests delivered through HTTP or in-process gateways keep protocol metadata, Gemini configuration, generated files, and continuation state.
  • [Agent] Unreadable stored automation tool results are reported to the model as a note instead of breaking the conversation.
  • [Agent] NO_PROXY no longer includes bracketed IPv6 or IPv6 CIDR entries that broke Python HTTP clients in Agent sessions.
  • [Models] Model connection checks now use streaming for streaming-capable models and detect incomplete or failed responses.
  • [Models] Unsupported sampling parameters and penalties are no longer sent to providers, and declared sampling ranges apply after request overrides.
  • [Models] Gemini tool calls no longer fail when a schema contains propertyNames.
  • [Models] A single Cherry Cloud quota refusal no longer locks a model while plan quota remains; the server decides refusals and shows its suggested wait.
  • [Models] CherryIN saved model endpoints refresh automatically from the server while keeping local values when discovery fails.
  • [Models] CherryAI appears first with a paid subscription and last without one.
  • [Models] Provider request rejections without an HTTP status are reported as request errors instead of network interruptions.
  • [Models] Usage stats recover provider cache buckets, and locally computed costs are labeled as estimates.
  • [Models] Agent sessions on OpenAI-compatible, vLLM, or llama.cpp models report how far a request exceeds the context window.
  • [Models] Aborted provider turns now fail instead of reporting a successful stop.
  • [Files] File type icons render offline and stay consistent across file trees, previews, and attachments.
  • [Files] File trees and previews stay current, show save progress and failures, and support scoped refresh without losing local drafts.
  • [Knowledge] The Add URL dialog rejects non-http(s) addresses immediately.
  • [Knowledge] Self-hosted MinerU 4.1 Tasks API parsing is supported while older protocols still work.
  • [Feedback] Problem reports again include logs, activity records, and chat history for the last 24 hours; individual attachment switches were removed.
  • [Scheduled Tasks] Run history recorded before 2.2.0, or whose conversation was deleted, can be opened and shows its stored result.
  • [Skills] Cherry-only built-in skills are no longer exported to the shared ~/.agents/skills directory.
  • [Feishu] Initial channel connections retry with backoff instead of staying stopped after a failed handshake.
  • [UI] Empty assistant, agent, and notes sidebars explain that they are empty instead of showing a blank panel.
  • [Agent] Fixed agent sessions with background subagents slowing down a little more every round.
  • [Agents] Preserve subagent rate-limit error details and show consistent retry status for Pi and Pi Durable tasks.
  • [Agents] Reduce out-of-memory crashes when subagents process many images in parallel.
  • [Cherry AI] Load the model catalog from the server and show sign-in, subscription or AMD authorization requirements; detect delisted models. Built-in Qwen now requires Cherry AI sign-in (action required for users who previously used it signed out).
