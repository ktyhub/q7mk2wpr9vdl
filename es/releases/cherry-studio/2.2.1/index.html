Cherry Studio 2.2.1: tareas remotas, proveedores de búsqueda y correcciones de agentes

✨ Nuevas funciones

  • [Tareas] Los clients remotos pueden descubrir conversaciones de resultados de tareas programadas y consultar programaciones de tareas, historial de ejecución y resúmenes acotados. Las conversaciones de tareas siguen siendo detectables después de que se limpian los registros de ejecución.
  • [Modelos] Rapid-MLX está disponible como proveedor local integrado sin llave.
  • [Búsqueda web] Se agregaron los proveedores de búsqueda de palabras clave SerpKite y StepFun, y Exa ahora puede recuperar el contenido de una URL a través de su Contenido API.
  • [Archivos] Al colocar un archivo Markdown (.md, .markdown, .mdx) en la ventana de la aplicación, se abre en la vista previa de solo lectura.
  • [Agente] Las instalaciones de sistemas y paquetes globales ahora solicitan aprobación en modos normales y se ejecutan en acceso completo, en lugar de bloquearse en todos los modos.
  • [Agente] Los agentes y asistentes pueden usar una imagen cargada como avatar, que se muestra en catálogos, selectores, conversaciones, encabezados de mensajes e íconos de la pestaña Trabajo. Los avatares emoji existentes no cambian.
  • [Agente] El espacio de trabajo y los grupos de agentes se pueden anclar a la sección Anclada superior mientras sus tareas permanecen expandibles.
  • Las llamadas de [Agente] Uso de computadora muestran las aplicaciones que operaron y los detalles de la sesión muestran los mismos íconos de aplicaciones.
  • [Agente] Las llamadas de subagente pueden nombrar tanto un proveedor como un modelo, y la fila de subtarea muestra el modelo solicitado.
  • [Compositor] Con la representación de entrada de Markdown habilitada, se obtiene una vista previa de Markdown en vivo mientras se escribe en Chat, Agente y la barra de redacción de selección; Los marcadores aparecen cuando el cursor los alcanza y el texto enviado no cambia.
  • [Compositor] En la vista previa de Markdown, el texto seleccionado se puede poner en negrita, cursiva o código en línea con Cmd/Ctrl+B, Cmd/Ctrl+I y un acento grave.
  • [Compositor] En la vista previa de Markdown, los bloques de código delimitados se representan como una región de código resaltada, con Enter insertando una nueva línea, sangría de tabulación, emparejamiento automático de corchetes y variables o atajos que permanecen literales dentro del delimitador.
  • [Navegador] Las pestañas nuevas en el navegador integrado pueden comenzar desde una página en blanco, la última página abierta o una URL personalizada.
  • [Conocimiento] Se pueden agregar archivos OpenDocument (.odt, .odp, .ods) y RTF (.rtf) como fuentes de conocimiento.
  • [API Gateway] Los modelos de suscripción CherryAI están disponibles para clients y Code Mate externos a través de la puerta de enlace utilizando la cuota de la cuenta iniciada.

💄 Mejoras

  • [Agente] Pi y Pi Durable usan la compactación nativa de sus tiempos de ejecución y mantienen los detalles de los errores del proveedor.
  • [Agente] Los detalles de la sesión enumeran las aplicaciones que controla un agente, con su estado y una acción de detención.
  • [Chat] El mapa de la sucursal localiza el nodo de la sucursal activa y se puede desplazar al desplazarse.
  • [Modelos] El control deslizante de esfuerzo de razonamiento sigue el arrastre suavemente, se establece en los niveles de esfuerzo y respeta las configuraciones de movimiento reducido.
  • [Modelos] Los nombres de modelos truncados en el selector de modelos muestran el nombre completo al pasar el mouse y la tarjeta de detalles del modelo ya no los muestra.
  • [Tareas programadas] La navegación ancla permanece alineada mientras se carga el historial, y los resúmenes de ejecución fallida muestran detalles del error en una información sobre herramientas.
  • [Archivos] Las listas y cuadrículas de archivos muestran la ruta de origen de cada archivo en la información sobre herramientas del nombre para que se puedan distinguir los archivos con el mismo nombre.
  • [Prompt Polish] Muestra el modelo predeterminado con un enlace a su configuración y distingue tiempos de espera, modelos faltantes, respuestas vacías y fallas del proveedor.
  • [Comentarios] Adjuntar diagnósticos a un informe de problema ahora es opcional.
  • [macOS] El instalador de DMG tiene un nuevo fondo y un diseño más grande y centrado para arrastrar a Aplicaciones.
  • [Asistente] El asistente predeterminado en inglés ahora se llama "Cherie".
  • [UI] Las pilas de notificaciones ampliadas clip ya no tienen sombras.

🐛 Corrección de errores

  • [Agente] Los resultados de herramientas anidadas de shell, archivos y artefactos en el modo de código Pi y Pi Durable se muestran nuevamente, incluso después de reabrir una conversación.
  • [Agente] Los comandos de Pi Shell sin un tiempo de espera explícito ya no esperan indefinidamente.
  • [Agente] Cerrar una sesión interrumpe primero el trabajo de Claude y los turnos interrumpidos de Claude Code ya no muestran el mensaje "No se solicita respuesta". marcador de posición.
  • [Agente] Bifurca y Edita y reenvía el trabajo después de un límite /compact, y la bifurcación ya no rechaza una sesión de Claude saludable con líneas de marco en blanco.
  • [Agente] El panel Paso ya no muestra un turno finalizado como en ejecución y las tareas eliminadas por el agente abandonan la lista.
  • [Agente] La barra superior del Agente mantiene el nombre del espacio de trabajo y la acción de abrir directorio después del primer mensaje.
  • La salida de [Agente] El subagente y la continuación del agente principal aparecen en el orden correcto en la conversación abierta.
  • [Agente] Los objetivos se completan cuando el modelo de verificación incluye su veredicto en un bloque de código o texto adicional.
  • [Agente] Los errores de edición de mensajes del agente muestran explicaciones completas y persistentes con diagnósticos copiables.
  • [Agente] El panel de uso contextual muestra los nombres de los servidores MCP configurados en lugar de los ID.
  • [Agente] Las tarjetas de sesión entre agentes nombran al agente objetivo.
  • Las respuestas del asistente de [Agente] en las conversaciones de trabajo ya no ofrecen Eliminar, porque al eliminarlas no se puede eliminar la transcripción del tiempo de ejecución.
  • [Agente] Al editar un mensaje se solicita confirmación antes de reemplazar el historial de conversaciones posterior.
  • [Agente] Los artefactos de Markdown se pueden obtener una vista previa de una conversación del Agente incluso cuando el espacio de trabajo está vacío.
  • [Agente] Los íconos de la pestaña Trabajo se actualizan cuando el avatar del agente cambia mientras la pestaña está oculta.
  • [Chat] Los enlaces en los mensajes enviados se pueden seleccionar sin problemas, sin navegación accidental.
  • [Chat] Al editar un mensaje ya no se eliminan los caracteres escritos justo después de clicking Edit.
  • [Chat] Un error guardado dos veces en mensajes anteriores ahora muestra una tarjeta de error.
  • [Chat] Las respuestas API vacías o con formato incorrecto muestran un diagnóstico claro con guía de reintento en lugar de un error desconocido.
  • [Chat] La advertencia de cambio de rama "el mensaje aún se está sincronizando" está localizada.
  • [Notas] El resaltado de sintaxis del código ya no desaparece en el editor.
  • [Atajos] Los atajos de números de conversación siguen funcionando después del primer cambio sin volver a enfocar la ventana.
  • [Navegador] Los errores de carga de página utilizan un mensaje genérico en lugar de sugerir que un servidor local se detuvo.
  • [Mini aplicaciones] Las ventanas emergentes de inicio de sesión de MiniApp del sitio web permanecen en su sesión persistente.
  • [Conocimiento] Los elementos de conocimiento fallidos muestran el motivo del error y se localizan los mensajes de extracción vacíos.
  • [Tareas programadas] Los tiempos de espera de cron funcionan con tiempos de ejecución compatibles con Gemini y eliminar una tarea con más de 32 000 sesiones ya no falla.
  • [Proveedores] Las solicitudes ya no fallan cuando una herramienta client tiene un nombre en blanco.
  • [Claude] Claude Code crea su carpeta de tiempo de ejecución antes de realizar una descarga, por lo que las instalaciones ya no fallan en una carpeta faltante.
  • [Pinturas] Las solicitudes de imágenes de SiliconFlow MOSS ya no fallan cuando no se selecciona ningún tamaño de imagen.
  • [Código] Codex CLI mantiene la ventana de contexto del modelo seleccionado y el límite de compactación cuando se reconstruye su configuración.
  • [UI] Los detalles de la sesión del agente ya no abarrotan su contenido ni se superponen a la vista previa del archivo.

⚡ Rendimiento

  • [Agente] El cambio de sucursal y la edición de mensajes son más rápidos en sesiones largas.

<details> <summary>Release Notes</summary>

Cherry Studio 2.2.1 - Remote Tasks, Search Providers, and Agent Fixes

✨ New Features

  • [Tasks] Remote clients can discover scheduled-task result conversations and query task schedules, run history, and bounded summaries. Task conversations remain discoverable after run records are cleaned up.
  • [Models] Rapid-MLX is available as a built-in, keyless local provider.
  • [Web Search] Added SerpKite and StepFun keyword search providers, and Exa can now fetch the content of a URL through its Contents API.
  • [Files] Dropping a Markdown file (.md, .markdown, .mdx) onto the app window opens it in the read-only preview.
  • [Agent] System and global package installs now ask for approval in normal modes and run in Full Access, instead of being blocked in every mode.
  • [Agent] Agents and assistants can use an uploaded image as their avatar, shown in catalogs, selectors, conversations, message headers, and Work tab icons. Existing emoji avatars are unchanged.
  • [Agent] Workspace and agent groups can be pinned to the top Pinned section while their tasks stay expandable.
  • [Agent] Computer Use calls show the applications they operated, and session details show the same app icons.
  • [Agent] Subagent calls can name both a provider and a model, and the subtask row shows the requested model.
  • [Composer] With Markdown input rendering enabled, Markdown is previewed live while typing in Chat, Agent, and the selection compose bar; markers appear when the caret reaches them and the sent text is unchanged.
  • [Composer] In the Markdown preview, selected text can be made bold, italic, or inline code with Cmd/Ctrl+B, Cmd/Ctrl+I, and a backtick.
  • [Composer] In the Markdown preview, fenced code blocks render as a highlighted code region, with Enter inserting a newline, Tab indenting, automatic bracket pairing, and variables or shortcuts staying literal inside the fence.
  • [Browser] New tabs in the built-in browser can start from a blank page, the last opened page, or a custom URL.
  • [Knowledge] OpenDocument (.odt, .odp, .ods) and RTF (.rtf) files can be added as knowledge sources.
  • [API Gateway] CherryAI subscription models are available to external clients and Code Mate through the gateway using the signed-in account's quota.

💄 Improvements

  • [Agent] Pi and Pi Durable use their runtimes' native compaction and keep provider error details.
  • [Agent] Session details list the applications an agent is controlling, with their status and a Stop action.
  • [Chat] The branch map locates the active branch node and can be panned on scroll.
  • [Models] The reasoning-effort slider follows dragging smoothly, settles onto effort levels, and respects reduced-motion settings.
  • [Models] Truncated model names in the model selector show the full name on hover, and the model details card no longer clips them.
  • [Scheduled Tasks] Anchor navigation stays aligned while history loads, and failed run summaries show error details in a tooltip.
  • [Files] File lists and grids show each file's source path in the name tooltip so same-name files can be distinguished.
  • [Prompt Polish] Shows the default model with a link to its settings and distinguishes timeouts, missing models, empty responses, and provider failures.
  • [Feedback] Attaching diagnostics to a problem report is now optional.
  • [macOS] The DMG installer has a new background and a larger, centered drag-to-Applications layout.
  • [Assistant] The English default assistant is now named "Cherie".
  • [UI] Expanded notification stacks no longer clip their shadows.

🐛 Bug Fixes

  • [Agent] Nested shell, file, and artifact tool results in Pi and Pi Durable codemode are shown again, including after reopening a conversation.
  • [Agent] Pi shell commands without an explicit timeout no longer wait indefinitely.
  • [Agent] Closing a session interrupts Claude work first, and interrupted Claude Code turns no longer show a "No response requested." placeholder.
  • [Agent] Fork and Edit & Resend work after a /compact boundary, and fork no longer rejects a healthy Claude session with blank framing lines.
  • [Agent] The Step panel no longer shows a finished turn as running, and tasks deleted by the agent leave the list.
  • [Agent] The Agent top bar keeps the workspace name and open-directory action after the first message.
  • [Agent] Subagent output and the main agent's continuation appear in the correct order in the open conversation.
  • [Agent] Goals complete when the verifying model wraps its verdict in a code block or extra text.
  • [Agent] Agent message edit failures show complete, persistent explanations with copyable diagnostics.
  • [Agent] The context usage panel shows configured MCP server names instead of IDs.
  • [Agent] Cross-agent session cards name the target agent.
  • [Agent] Assistant replies in Work conversations no longer offer Delete, because deleting them cannot remove the runtime transcript.
  • [Agent] Editing a message asks for confirmation before replacing later conversation history.
  • [Agent] Markdown artifacts can be previewed from an Agent conversation even when the workspace is empty.
  • [Agent] Work tab icons update when the agent avatar changes while the tab is hidden.
  • [Chat] Links in sent messages can be selected smoothly, without accidental navigation.
  • [Chat] Editing a message no longer drops characters typed right after clicking Edit.
  • [Chat] An error saved twice in older messages now shows one error card.
  • [Chat] Empty or malformed API responses show a clear diagnosis with retry guidance instead of an unknown error.
  • [Chat] The "message is still syncing" branch-switch warning is localized.
  • [Notes] Code syntax highlighting no longer disappears in the editor.
  • [Shortcuts] Conversation number shortcuts keep working after the first switch without refocusing the window.
  • [Browser] Page-load failures use a generic message instead of suggesting that a local server stopped.
  • [Mini Apps] Website MiniApp sign-in popups stay in their persistent session.
  • [Knowledge] Failed knowledge items show the failure reason, and empty extraction messages are localized.
  • [Scheduled Tasks] Cron timeouts work with Gemini-compatible runtimes, and deleting a task with more than about 32,000 sessions no longer fails.
  • [Providers] Requests no longer fail when a client tool has a blank name.
  • [Claude] Claude Code creates its runtime folder before staging a download, so installs no longer fail on a missing folder.
  • [Paintings] SiliconFlow MOSS Image requests no longer fail when no image size is selected.
  • [Code] Codex CLI keeps the selected model's context window and compaction limit when its configuration is rebuilt.
  • [UI] Agent Session Details no longer crowds its content or overlaps the file preview.

⚡ Performance

  • [Agent] Branch switching and message editing are faster in long sessions.
