<detalles> <summary>inglés</summary> Cherry Studio 2.0.13: nuevas funciones, correcciones y mejoras ✨ Nuevas características - [Modelos] Agregue compatibilidad con GPT-6 Astra con límites de contexto, controles de razonamiento, modo rápido, búsqueda web nativa, precios escalonados y el ícono del modelo oficial. - [Modelos] Agregue TokenDance como proveedor de modelo integrado con autorización de clave API basada en navegador. - [Tareas programadas] Los ajustes preestablecidos diarios, entre semana y semanales ahora admiten varias horas al día (por ejemplo, 09:00 y 18:00). - [Chat] Muestra títulos de temas y sesiones, cambia de rama desde el encabezado y exporta ramas individuales como Markdown. - [Habilidades] Agregue filtros de fuente de habilidades instaladas y un interruptor de diseño de columna simple/doble en la configuración de Habilidades. - [Panel rápido] Las acciones de administración ahora permanecen en un pie de página accesible en indicaciones, habilidades, MCP, notas, base de conocimientos y personalización de la barra de herramientas. - [Compositor] Agregue un atajo Ctrl+I / Cmd+I configurable para enfocar la entrada. - [Exportación de imágenes] La exportación de imágenes de mensajes ahora utiliza el compositor de Chromium para obtener resultados con píxeles perfectos que coincidan con lo que ves en la pantalla. - [Traducir] Renderice la salida transmitida con formato Markdown enriquecido. 🐛 Corrección de errores - [Modelos] Se corrigieron los proveedores de modelos personalizados que rechazan los encabezados de atribución automática de Cherry Studio. - [Modelos] Se corrigieron las solicitudes de Moonshot Kimi K2.5+ que fallaban cuando la configuración de muestreo personalizada estaba habilitada. - [Modelos] Se corrigieron las solicitudes de Kimi K3 que fallaban cuando se seleccionaba un esfuerzo de razonamiento no respaldado. - [Modelos] Retiró el proveedor Yi (01.AI) luego del cierre de su servicio. - [Modelos] Los perfiles migrados desde la versión 1 ahora conservan el acceso a todos los proveedores y modelos, independientemente de la edición instalada. - [Chat] Se corrigió un tema que fallaba permanentemente con un error 400 después de una llamada a la herramienta cuando el proveedor devolvía una identificación de artículo no estándar. - [Chat] Se corrigió el cambio entre respuestas multimodelo mientras se transmite una respuesta. - [Chat] Corrige errores normales de autenticación de chat que no se pueden vincular a la configuración del proveedor después de reintentos automáticos. - [Chat] Las citas de búsqueda web nativas devueltas por los proveedores ahora se muestran en las respuestas del chat. - [Chat] Las sesiones de agente completadas ahora muestran el uso de tokens no disponibles en lugar de un cero engañoso. - [Chat] Las fallas de autenticación de certificados del agente client ahora muestran una guía de recuperación de proxy y SSL. - [Chat] Los errores de inicio de sesión del Agente de Claude Code ahora se vinculan a la configuración del proveedor necesaria para la recuperación. - [Chat] Agregue una acción de recuperación de la configuración del proveedor a errores HTTP 400 genéricos. - [Chat] Arreglar las citas de mensajes que se dirigen a la ventana incorrecta. - [Tareas programadas] Se corrigió que el registro de ejecución de tareas perdiera su enlace "ver sesión" cuando la ejecución de un agente programado fallaba, se agotaba el tiempo de espera o se cancelaba. - [Agente] Se corrigió que los agentes sin tareas desaparecieran de la lista de agentes cuando las sesiones se muestran a la derecha. - [Agente] Repara fallas de la herramienta Bash etiquetadas como errores en lugar de salida de comando. - [Agente] Se corrigieron las llamadas a herramientas para que los argumentos reparados y reproducidos mantengan su forma esperada JSON. - [Agente] Restaura la protección de bucle de repetición de comandos de Claude Code cuando RTK reescribe comandos Bash. - [Agente] Evite que los agentes modifiquen archivos SQLite de datos de usuario de Cherry Studio a través de herramientas nativas. - Las fallas del proceso de [Agente] Claude Code ahora muestran una causa procesable y una referencia de diagnóstico. - [Agente] El indicador de uso del contexto ahora avanza en vivo durante una tarea en lugar de solo al finalizar. - [DeepSeek] Las sesiones web de DeepSeek Harness ahora se inician correctamente cuando el tiempo de ejecución requiere su URL autenticada mediante token. - [Pi] Reanudar las tareas de Pi después de respuestas de longitud limitada por el contexto con un intento limitado de compactación y reintento. - [OpenCode] Los títulos de conversaciones automáticas de OpenCode Go ahora conservan la identidad de la sesión. - [Contexto] Se corrigió el selector del modelo de compresión de contexto para que los usuarios puedan volver a "Seguir el modelo actual". - [Configuración] Se corrigió la lista de modelos de proveedores que congelaba la aplicación cuando un proveedor tiene muchos modelos. - [Configuración] Arreglar la configuración del Asistente que interrumpe el guardado automático con valores de tokens Max inseguros. - [Configuración] La incorporación de la edición China ahora vuelve a utilizar el inicio de sesión CherryIN de forma predeterminada. - [Configuración] AMD GPU Cloud ya no muestra mensajes promocionales "Gratis" o de crédito diario. - [Asistente rápido] Se corrigió la selección integrada de acciones rápidas para llamar a las herramientas MCP cuando se configura un QuickAssistant con MCP. - [Traducir] Se corrigió el botón de copiar que mostraba sus comentarios en el panel incorrecto. - [Traducir] Se corrigió que el historial de traducción comience a abrir detalles en lugar de alternar cuando se horizontales ahora son visibles en el contenido desbordado dentro del Markdown. - [Navegador MCP] Evita que las páginas integradas del navegador ocultas o inactivas reproduzcan medios audibles. - [Copia de seguridad] Corrige el engañoso “Error de formato de archivo de copia de seguridad” al restaurar una copia de seguridad creada con una versión más reciente. - [Copia de seguridad] Se corrigió la copia de seguridad, restauración, administración y limpieza de retención de Qiniu Cloud S3 cuando se usan puntos finales regionales. - [Región] El enrutamiento dependiente de la región ahora recurre a puntos finales globales cuando falla la detección de la región IP en lugar de tratar el error como China continental. - [Región] Se corrigió la detección de región al reutilizar una Cherry Studio 2.0.13 - New Features, Fixes, and Improvements

✨ New Features

  • [Models] Add GPT-6 Astra support with context limits, reasoning controls, Fast mode, native web search, tiered pricing, and the official model icon.
  • [Models] Add TokenDance as a built-in model provider with browser-based API key authorization.
  • [Scheduled Tasks] Daily, weekdays, and weekly presets now support multiple times per day (e.g. 09:00 and 18:00).
  • [Chat] Show topic and session titles, switch branches from the header, and export individual branches as Markdown.
  • [Skills] Add installed-skill source filters and a single/double-column layout switch in Skills settings.
  • [Quick Panel] Management actions now stay in an accessible footer across prompts, skills, MCP, Notes, Knowledge Base, and toolbar customization.
  • [Composer] Add a configurable Ctrl+I / Cmd+I shortcut to focus the input.
  • [Image Export] Message image export now uses Chromium's compositor for pixel-perfect output matching what you see on screen.
  • [Translate] Render streamed output with rich Markdown formatting.

🐛 Bug Fixes

  • [Models] Fix custom model providers that reject Cherry Studio's automatic attribution headers.
  • [Models] Fix Moonshot Kimi K2.5+ requests failing when custom sampling settings are enabled.
  • [Models] Fix Kimi K3 requests failing when an unsupported reasoning effort was selected.
  • [Models] Retired the Yi (01.AI) provider following its service shutdown.
  • [Models] Profiles migrated from v1 now retain access to all providers and models regardless of the installed edition.
  • [Chat] Fix a topic permanently failing with a 400 error after a tool call when the provider returns a non-standard item id.
  • [Chat] Fix switching between multi-model answers while a response is streaming.
  • [Chat] Fix normal chat authentication errors failing to link to provider settings after automatic retries.
  • [Chat] Native web search citations returned by providers are now displayed in chat responses.
  • [Chat] Completed Agent sessions now show unavailable token usage instead of a misleading zero.
  • [Chat] Agent client-certificate authentication failures now show proxy and SSL recovery guidance.
  • [Chat] Claude Code Agent sign-in failures now link to the provider settings needed for recovery.
  • [Chat] Add a provider settings recovery action to generic HTTP 400 errors.
  • [Chat] Fix message quotes routing to the wrong window.
  • [Scheduled Tasks] Fixed the task run log losing its “view session” link when a scheduled agent run failed, timed out, or was cancelled.
  • [Agent] Fix taskless agents disappearing from the agent list when sessions are displayed on the right.
  • [Agent] Fix Bash tool failures labeled as errors instead of command output.
  • [Agent] Fix tool calls so repaired and replayed arguments keep their expected JSON shape.
  • [Agent] Restore Claude Code's repeat-command loop guard when RTK rewrites Bash commands.
  • [Agent] Prevent agents from modifying Cherry Studio user-data SQLite files through native tools.
  • [Agent] Claude Code process failures now show an actionable cause and diagnostic reference.
  • [Agent] The context-usage indicator now advances live during a task instead of only at completion.
  • [DeepSeek] DeepSeek Harness Web sessions now start correctly when the runtime requires its token-authenticated URL.
  • [Pi] Resume Pi tasks after context-clamped length responses with a bounded compact-and-retry attempt.
  • [OpenCode] OpenCode Go automatic conversation titles now preserve session identity.
  • [Context] Fixed the context compression model selector so users can switch back to “Follow current model”.
  • [Settings] Fix the provider model list freezing the app when a provider has many models.
  • [Settings] Fix Assistant settings breaking auto-save with unsafe Max tokens values.
  • [Settings] China-edition onboarding now uses CherryIN login by default again.
  • [Settings] AMD GPU Cloud no longer shows promotional “Free” or daily-credit messaging.
  • [Quick Assistant] Fix built-in selection quick actions to call MCP tools when a quickAssistant with MCP is configured.
  • [Translate] Fixed the copy button showing its feedback on the wrong pane.
  • [Translate] Fixed translation history stars opening details instead of toggling when activated with Enter or Space.
  • [Web Search] Keep valid Querit results when individual items omit optional metadata.
  • [Word Export] Word export now renders four-space-indented code blocks, numbered lists, image alt text, strikethrough, and fixes empty blockquote errors.
  • [Markdown] Horizontal scrollbars are now visible on overflowing content inside markdown.
  • [Browser MCP] Prevent hidden or inactive built-in browser pages from playing audible media.
  • [Backup] Fix misleading “Backup file format error” when restoring a backup created by a newer version.
  • [Backup] Fixed Qiniu Cloud S3 backup, restore, management, and retention cleanup when using regional endpoints.
  • [Region] Region-dependent routing now falls back to global endpoints when IP region detection fails instead of treating failure as mainland China.
  • [Region] Fix region detection reusing an in-flight request from a different proxy.
  • [Mini Apps] Fixed Mini Apps search failing to find apps by their translated display names.
  • [Mini Apps] Remove raw permission key tooltips that showed untranslated strings.
  • [Notes] Fixed note and folder rename fields closing before users could enter a new name.
  • [PDF Preview] Fixed PDF page input retaining an out-of-range number when submitting.
  • [Cherry Cloud] Bring Cherry Studio to the foreground after sign-in completes.
  • [Portable] Fix Windows portable deep links opening a second app instance that can lose packaged resources.
  • [Windows] Fix garbled localized default application names in the Open with menu.
  • [macOS] Repair macOS keychain signing.

💄 Improvements

  • [Image Generation] Disable automatic retries to avoid duplicate billable requests.
  • [Image Generation] Probe edit-only image models via edit mode.
  • [Agent Channels] Begin processing incoming messages after a one-second batching delay.

⚡ Performance

  • [Code Editor] CodeMirror theme catalog is now loaded only when a code editor is opened.
  • [HTML Artifacts] HTML artifact previews skip full-element layout sweeps for scrollable content.

Cherry Studio 2.0.13 - 新功能、修复与改进

✨ 新功能

  • [模型] 新增 GPT-6 Astra 支持，包括上下文限制、推理控制、快速模式、原生联网搜索、分层定价和官方模型图标。
  • [模型] 新增 TokenDance 内置模型服务商，支持浏览器 API 密钥授权。
  • [定时任务] 每天、工作日和每周预设现在支持每天多个时间点（如 09:00 和 18:00）。
  • [对话] 显示话题和会话标题，从标题栏切换分支，并将单个分支导出为 Markdown。
  • [技能] 技能设置中新增已安装技能来源过滤和单/双列布局切换。
  • [快捷面板] 管理操作现在固定在可访问的页脚，涵盖提示词、技能、MCP、笔记、知识库和工具栏自定义。
  • [输入框] 新增可配置的 Ctrl+I / Cmd+I 快捷键聚焦输入框。
  • [图片导出] 对话消息图片导出现在使用 Chromium 合成器，输出像素完美匹配屏幕显示。
  • [翻译] 翻译输出使用富 Markdown 格式渲染。
