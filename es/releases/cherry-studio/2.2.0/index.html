Cherry Studio 2.2.0: mercado de habilidades, notificaciones y tiempo de ejecución del agente

✨ Nuevas funciones

  • [Marketplace] Explore catálogos de habilidades, fuentes de habilidades externas, plantillas de agentes y recursos de MCP en un Marketplace, con instalación guiada y gestión de habilidades y MCP enfocada.
  • [Notificaciones] Un nuevo cajón de notificaciones al lado de la barra lateral recopila resultados de tareas y anuncios oficiales, con indicadores no leídos, vistas previas de respuestas y anuncios que se muestran en su idioma.
  • [Tareas programadas] Las tareas programadas ahora tienen una página de barra lateral dedicada con conversaciones de tareas, historial de ejecución paginado y administración de tareas completadas o no realizadas. Se eliminó la página de configuración duplicada.
  • [Cherry Cloud] El uso de la suscripción y las cuotas mensuales aparecen en Configuración y en el panel de la cuenta, con insignias del plan, puntos de entrada de suscripción, un aviso de cuota encima de la entrada y un aviso cuando se activa una suscripción.
  • [Asistente de selección] Preguntar al agente y las acciones vinculadas al agente abren una ventana de agente dedicada para el texto seleccionado. Windows puede colapsar en cápsulas, seguir reglas de cierre automático y continuar la sesión en la ventana principal.
  • [Agente] Los nuevos agentes utilizan de forma predeterminada el tiempo de ejecución Pi Durable, que persiste las sesiones de forma nativa y transmite subagentes en segundo plano de forma independiente. Las sesiones pueden bifurcarse en puntos de control completados mientras mantienen un estado independiente.
  • [Agente] Ver y editar la memoria del agente desde la configuración del Agente.
  • [Agente] Los detalles de la sesión muestran subagentes agrupados, el progreso de la tarea y el uso del contexto en una tarjeta compacta.
  • [Agente] Editar y reenviar ahora reemplaza el mensaje y elimina todo lo que sigue sin crear otra versión del historial. Los archivos no se restauran; fork primero para mantener la conversación original.
  • [Chat] Click el contador de sucursales en un mensaje para saltar entre respuestas alternativas, con vistas previas en el conmutador.
  • [Chat] Oferta de imágenes generadas Uso como referencia para modelos que aceptan entrada de imágenes.
  • [Pinturas] La imagen GPT 2.6 Flare y Sunburst admiten la complejidad de la escena y la salida GIF animada, y los flujos de trabajo de ComfyUI pueden usar imágenes de entrada adjuntas.
  • [Modelos] Se agregaron LongCat 2.5 y Hunyuan 4 con entrada de imágenes, además de controles de esfuerzo de razonamiento para Qwen 3.8 Flash Next.
  • [Archivos] Copie un archivo o carpeta al sistema clipboard desde el panel de archivos del Agente.
  • [Notas] Guarde el texto de la conversación seleccionada en Notas y haga referencia a las Notas de la entrada del chat con @.
  • [Traducir] Copie una traducción completa como una imagen PNG completa.
  • [Exportar] Exporte configuraciones del servidor MCP como JSON y exporte varios asistentes como un solo archivo.
  • [Habilidades] Elija qué habilidades administradas se exportan a ~/.agents/skills para agentes externos.
  • [Atajos] Los atajos numéricos cambian conversaciones y pestañas, y los nuevos atajos cambian asistentes y temas; todo se puede personalizar en Configuración.
  • [Conversaciones] Eliminar permanentemente conversaciones de los menús de lista, Más e Historial, y eliminar propietarios de los menús de lista y grupo, después de una confirmación que nombra el elemento.
  • [Markdown] Las URL de imágenes desnudas en las respuestas ahora se muestran como imágenes en línea.
  • [Mini Apps] El catálogo tiene nuevos sitios creativos y de productividad, y el menú Más puede reiniciar una MiniApp.
  • [Artefacto HTML] Copie el código fuente de un artefacto HTML desde su barra de herramientas de código fuente en línea.

💄 Mejoras

  • [Chat] Regenerar está disponible debajo de los mensajes de usuario y utiliza el modelo seleccionado actualmente.
  • [Chat] Los anclajes de conversación aparecen desde el primer turno; La barra de herramientas de navegación lateral separada se eliminó en favor de la flecha inferior.
  • [Agente] El uso del contexto informa la capacidad del tiempo de ejecución, las categorías estimadas y los recursos de manera consistente en todos los tiempos de ejecución, incluidos los subagentes.
  • [Agente] El cambio del modo de permiso mientras se ejecuta una tarea se aplica a la siguiente llamada a la herramienta en lugar de esperar el siguiente mensaje.
  • Los modos [Agente] Plan y Objetivo están disponibles como acciones explícitas del Panel rápido y las acciones del historial no admitidas están deshabilitadas.
  • [UI] Los atajos del menú contextual se representan como teclas compactas, los controladores de cambio de tamaño usan colores neutros y los clidescensores de letras con omisiones son fijos.
  • [Vista previa de archivo] Las vistas previas de Word se ajustan al panel y más tipos de archivos muestran iconos y etiquetas adecuados.
  • [Modelos] Se actualizan la marca, los enlaces y los puntos finales API predeterminados de Qwen AI Platform y Qwen Cloud. Las claves del Qwen Token Plan ahora funcionan con la generación de imágenes.
  • [Claude] El banner de descarga del tiempo de ejecución se muestra correctamente y el tiempo de ejecución se llama Claude.
  • [Configuración] Restablecer un host API de proveedor personalizado solicita confirmación.
  • [Acerca de] Información de producto simplificada con un botón Estrella, contacto de correo electrónico y DevTools acoplados en la parte inferior.
  • [Búsqueda web] Una advertencia ahora nombra el proveedor que realmente ejecutó una búsqueda cuando vuelve a aparecer.

Cherry Studio 2.2.0 - Skill Marketplace, Notifications, and Agent Runtime

✨ New Features

  • [Marketplace] Browse skill catalogs, external skill sources, Agent templates, and MCP resources in one Marketplace, with guided installation and focused MCP and skill management.
  • [Notifications] A new notification drawer beside the sidebar gathers task results and official announcements, with unread indicators, reply previews, and announcements shown in your language.
  • [Scheduled Tasks] Scheduled tasks now have a dedicated sidebar page with task conversations, paginated run history, and management for completed or missed tasks. The duplicate Settings page was removed.
  • [Cherry Cloud] Subscription usage and monthly quotas appear in Settings and the account panel, with plan badges, subscribe entry points, a quota notice above the input, and a notice when a subscription becomes active.
  • [Selection Assistant] Ask Agent and agent-bound actions open a dedicated agent window for the selected text. Windows can collapse into capsules, follow auto-close rules, and continue the session in the main window.
  • [Agent] New agents default to the Pi Durable runtime, which persists sessions natively and streams background subagents independently. Sessions can fork at completed checkpoints while keeping independent state.
  • [Agent] View and edit agent memory from Agent configuration.
  • [Agent] Session details show grouped subagents, task progress, and context usage in a compact card.
  • [Agent] Edit and resend now replaces the message and removes everything after it without creating another history version. Files are not restored; fork first to keep the original conversation.
  • [Chat] Click the branch counter on a message to jump between alternate replies, with previews in the switcher.
  • [Chat] Generated images offer Use as Reference for models that accept image input.
  • [Paintings] GPT Image 2.6 Flare and Sunburst support scene complexity and animated GIF output, and ComfyUI workflows can use attached input images.
  • [Models] Added LongCat 2.5 and Hunyuan 4 with image input, plus reasoning-effort controls for Qwen 3.8 Flash Next.
  • [Files] Copy a file or folder itself to the system clipboard from the Agent file pane.
  • [Notes] Save selected conversation text to Notes, and reference Notes from the chat input with @.
  • [Translate] Copy a completed translation as a full-length PNG image.
  • [Export] Export MCP server configurations as JSON and export multiple assistants as one file.
  • [Skills] Choose which managed skills are exported to ~/.agents/skills for external agents.
