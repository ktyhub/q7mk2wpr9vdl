cherry-studio v1.5.10

Highlights

  • Toolchain & build changes — Vite is pinned down to 7.1.5 (#9794), TypeScript config/scripts were reworked (#9792), and electron.vite.config.ts external dependencies were streamlined (#9835), alongside an improved Linux system-OCR build (#9775). These land together, so maintainers of forks or source builds should re-baseline and watch for dependency-resolution differences once externals change — this cluster is the most likely source of unexpected build breakage.
  • Settings migrations on upgrade — Migration logic moves to version 145 and enforces the showMessageOutline default (#9805), while showWorkspace relocates from global settings into the notes module (#9814). Expect these values to be reset or moved on first launch after upgrading; anything scripted against the old settings schema needs updating.
  • Recoverable chat failures — Loading states no longer block the input, and a "Retry failed messages" button was added (#9513). This is a real behavioral shift for chat flows: failed sends can now be retried in place instead of disrupting the conversation.
  • Richer link previews — OG metadata from URLs is now parsed and merged into preview content (#9752), and iframe captures now include animations and fonts (#9800). Consumers of message/link rendering get more complete previews, but should watch for layout shifts as the extra metadata and fonts resolve.
  • MCP integration fixes — Servers added via JSON now have their parameters transformed correctly (#9850), and streamable-HTTP detection switched to an includes http check (#9865). The latter is worth verifying if you use custom endpoints whose URLs don't literally contain "http" — detection behavior has changed.
  • New capabilities — The KnowledgeFiles component gains file selection and upload (#9815), Gemini 2.5 Flash Image now auto-enables the image-generation button (#9787), and a NavigationService init-timing fix ships alongside tab drag-reordering (#9700).

No breaking API changes in this release.
