JeecgBoot v3.7.1

Highlights

  • Security: xxl-job 2.4.1 closes CVE-2024-24113 — The clearest imperative to act: xxl-job is bumped specifically to mitigate CVE-2024-24113. If you run an older 2.x scheduler, prioritizing this dependency upgrade (and verifying scheduler/executor compatibility) is the main security driver for adopting v3.7.1.

  • Nacos 2.3.2 and first-class Dameng support — Microservice deployments move to Nacos 2.3.2 and gain out-of-the-box support for the domestic Dameng (达梦) database, so teams standardizing on domestic stacks can drop homegrown compatibility shims. Treat the registry/config version bump seriously: validate Nacos connection and config format against 2.3.2 during rollout rather than assuming a drop-in swap.

  • Code generator rebuilt around nested packages and new controls — Generated scaffolding now supports multi-level subpackages, emits the frontend v-auth permission directive, adds the JPopupDict control and year/month/week/quarter defaults, and ships redesigned date/number/amount range pickers. It also clears long-standing output bugs — int columns not rendering as numeric inputs, stray commas in Vue select code, validation-scroll failures, and one-to-many exports dumping all rows when no master row is selected. Regenerated code will differ structurally from older output, so diff against a clean target before merging.

  • JimuReport/JimuBI gain data-entry forms and a dashboard refresh — 积木报表 is upgraded to the latest build with form-design/填报 (data-entry) capability, turning the report module from read-only into a lightweight collection tool; 积木仪表盘 gets a new UI, paginated lists, configurable query conditions, custom category trees, and pyramid-funnel/radar charts with improved drill-down and linking. Note the fixes for drill-down parameters being ignored (#2702) and dead route jumps (#6852) — re-test existing dashboards after the bump.

  • Permission, auth, and data-scope behavior changes — Editing a logged-in user's permissions now takes effect immediately without re-login; whitelist management moves to a request-annotation model; and a new jeecg.firewall.disableSelectAll yml switch blocks * queries in Online reports. Several multi-tenant/login fixes land alongside: orgCode injection for WeCom login (#6634), DingTalk default-tenant leakage (#6652), Swagger/Knife auth under tenant isolation (#6987), and @IgnoreAuth not applying in new microservice controllers (#7081). Audit whitelist configs and any reports using * before rollout.

  • Migration and operational stability — A Flyway script (V3.7.1__all_upgrade.sql) must be applied; a Redis lock leak that caused deadlocks and QPS spikes is fixed (#6876); and one-click Docker startup for both monolith and microservices arrives with simplified gateway config (copy/soft-delete/recycle bin). Watch the fresh Docker MySQL-image fix (#7119) if you adopt that path, and note that Online image export now emits text rather than image files — downstream consumers expecting images will need adjustment.

No breaking changes were formally declared in this release.
