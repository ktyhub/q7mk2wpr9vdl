dubbo 3.3.0-beta.1

Pre-release Publicado7 oct 2023 Fuenteapache/dubbo original en inglés

Esta página está traducida automáticamente. El texto original en inglés es la referencia.

dubbo dubbo-3.3.0-beta.1

Estamos muy emocionados de anunciar la primera versión beta de la rama 3.3.x, una versión que tiene algunas características muy interesantes que revelar.

Se recomienda encarecidamente permanecer en 3.2.x para uso en producción y solo actualizar a 3.3.x después de que esté disponible la primera versión estable (sin sufijo beta).

Nuevas características

  • Nuevo protocolo triple, totalmente compatible con gRPC y al mismo tiempo admite acceso directo desde cURL y navegador.
  • Soporte de programación estilo Rest (Spring MVC y JAX-RS) y comunicación (aplicación/json), mucho más fácil para que la aplicación Dubbo sirva como un servidor web estándar.
  • Un montón de elementos básicos para una fácil gestión de dependencias al desarrollar con Spring Boot (Zookeeper, Nacos, Sentinel, etc.).
  • Compatibilidad con imágenes nativas GraalVM con Dubbo AOT.
  • Totalmente compatible con JDK 21 y modelo de hilo de telar de proyecto.
  • Mejora de métricas y seguimiento.

dubbo dubbo-3.3.0-beta.1

We are very excited to announce the first beta release of the 3.3.x branch, a release that has some very exciting features to reveal.

It is highly recommended to stay on 3.2.x for production usage and only upgrade to 3.3.x after the first stable release is available (with no beta suffix).

New Features

  • New Triple protocol, fully compatible with gRPC while supporting direct access from cURL and browser.
  • Rest-style programming (Spring MVC and JAX-RS) and communication (application/json) support, much easier for Dubbo application to serve as a standard web server.
  • A bunch of starters for easy dependency management when developing with Spring Boot (Zookeeper, Nacos, Sentinel, etc.).
  • GraalVM Native Image support with Dubbo AOT.
  • Fully JDK 21 support and project loom thread model.
  • Metrics and tracing improvement.
