dubbo 2.7.11

dubbo dubbo-2.7.11

Optimización

  • Utilice nodeCache en lugar de treeCache. (#7466)
  • Cuando obtengaServiceAppMapping por primera vez, reduzca el transporte de red único. (#7298)
  • Optimizar código para condición de bucle (#7480)
  • Compatible con cambio al descubrimiento de servicios a nivel de interfaz cuando el registro no admite la arquitectura de introspección de servicios (#7506)
  • Optimización genérica, liberación y generalización (#7520)
  • Utilice el método contenedor de @SPI para informar un error de excepción de puntero nulo (#7326)
  • Lanzar una excepción cuando el enlace de datos desde el archivo de propiedades encuentra un error (#4757)
  • Simplificar OptionUtil#prefixEndOf (#5833)
  • La contraseña reparada se imprimirá en texto sin formato (#6931)
  • Optimizar algún código relacionado con el cónsul (#7523)
  • Mover ContextFilter al orden más bajo (#7533)
  • Cuando se produce un error en getRegistry, se registra el error. (#7545)
  • Agregar ClusterRules LoadbalanceRules a dubbo common (#7534)
  • Utilice métodos CollectionUtils para realizar la validación nula de la colección (#7559)
  • Ajuste del nombre predeterminado de SPI (#7557)
  • Fusionar excepciones, eliminar implementaciones de interfaz redundantes (#4730)
  • Optimizar código para eliminar objetos inútiles (#7582)
  • Utilice la doble verificación para obtener elementos del caché (#7583)
  • Eliminar referencias redundantes (#7604)
  • La configuración predeterminada de reparación no es válida (#7607)
  • Optimizar la creación del ejecutor para ThreadPoolExecutor en ZookeeperDynamicConfiguration (#7617)
  • Al realizar una solicitud de servicio dubbo genérica, establecer la verificación en verdadero podría causar pérdidas de memoria (#7599)
  • Eliminar métodos de llamada duplicados metadataInfo#calAndGetRevision (#7630)
  • Eliminar el uso de EventListener en DubboBootstrap (#7638)
  • Convierta la IllegalArgumentException generada por PojoUtils.realize en GenericFilter a RpcException (#7643)
  • Solucionar el problema de ProtocolConfig que requiere un parámetro de nombre en las nuevas versiones de Dubbo (#7624)
  • Hacer que Dubbo2.7.x no registre la información de serviceNameMapping en el registro de forma predeterminada. (#7672)

Características

  • Agregar mecanismo de configuración de opciones para JdkCompiler. (#7232)
  • Agregar enrutador de argumentos a ConditionRouter (#7378)
  • Resuelva el problema de registrar repetidamente el BeanDefinition del proveedor (#7494)
  • Agregar campo de anotaciones a la definición de matedata (#7660)

Corrección de errores

  • Se corrigió el manejo incorrecto de URLBuilder que causaba que se generara la URL incorrecta (#7501)
  • Se corrigió el error al exportar la excepción de ignorar asíncrono (#7507)
  • Se solucionó el problema de que la versión DubboReference * no es válida (#7489)
  • Se corrigió StatItem.isAllowable() que siempre deja pasar 1 solicitud más (#4141)
  • Borrar invocadores destruidos en AbstractProxyProtocol (#4738)
  • Establecer por defecto needReconnect verdadero cuando el canal no está conectado (#6873)
  • Se corrigió el registro del conjunto etcd 'grupo' que no se puede aislar (#4825)
  • Se corrigió el bloqueo en DubboProtocol#getSharedClient (#6018)
  • Se corrigió el tipo de código en ExceptionFilter (#6932)
  • Crear parámetro genérico como grupo, versión manejada en org.apache.dubbo.rpc.cluster.support.ClusterUtils (#6900)
  • Resolver el clúster de transmisión significa que se llamarán varias máquinas, que no se convierten al protocolo jvm en este momento. (#7365)
  • Se corrigió la repetición de agregar parámetros a la URL (#7498)
  • Se corrigió la definición incorrecta del nombre de la variable de instancia (#7547)
  • Se corrigió la compilación en la arquitectura de CPU ARM64 de Linux (#7408)
  • La etiqueta de configuración del consumidor anula la configuración de la etiqueta privada (#5975)
  • Arreglar el registrador de protocolo de registro (#7546)
  • Solucionar el problema de clave no coincidente al no escuchar. (#7465)
  • Se solucionó el problema que podría provocar múltiples inicios en MetadataReportInstance#init (#7586)
  • El campo de corrección puede ser nulo, evite generar NullPointerException (#7620)
  • El método de reparación puede ser nulo en RpcUtils, evite lanzar NullPointerException (#7627)
  • Reparar la dirección local puede ser nula, evitar lanzar NullPointerException (#7622)
  • El método de reparación puede ser nulo y se generará NullPointerException en MethodUtils (#7606)
  • Arreglar RegistroProtocolo registroStatedUrl NPE. (#7610)
  • Arreglar setSkyWalkingDynamicField(java.lang.Object) no encontrado (#7517)
  • Se corrigió que la eliminación de la última configuración no surtiera efecto (#6964)
  • Se corrigió que RemoteMap pudiera ser nulo para evitar que se genere NullPointerException (#7654)
  • Se corrigió que EtcdServiceDiscovery no anulara el método getUrl, lo que provocaba que la suscripción generara una excepción (#7659)
  • Se corrigió que el registro de Dubbo zookeeper no pudiera volver a suscribirse (#7669)
  • ZookeeperServiceDiscovery curador client admite múltiples direcciones. (#7285)

Actualizaciones de dependencia

  • Actualización del artefacto org.javassist.javassist:3.23.1-GA #7516
  • Actualización del artefacto com.alibaba.nacos.nacos-client:1.4.1 #7676

dubbo dubbo-2.7.11

Optimization

  • Use nodeCache to take place of treeCache. (#7466)
  • When first getServiceAppMapping, reduce one time network transport. (#7298)
  • Optimize code for loop condition (#7480)
  • Compatible Switch to interface level service discovery when the registry does not support service introspection architecture (#7506)
  • Optimization generic releaize and generalize (#7520)
  • Use @SPI's wrapper method to report a null pointer exception bug (#7326)
  • Throw exception when data bind from properties file encounter error (#4757)
  • Simplify OptionUtil#prefixEndOf (#5833)
  • Fix password be print in plain text (#6931)
  • Optimize some code related to consul (#7523)
  • Move ContextFilter to lowest order (#7533)
  • When getRegistry error, log error. (#7545)
  • Add ClusterRules LoadbalanceRules to dubbo common (#7534)
  • Use CollectionUtils methods to perform Collection null validation (#7559)
  • SPI default name adjustment (#7557)
  • Merge exceptions, remove redundant interface implementations (#4730)
  • Optimize code to remove useless objects (#7582)
  • Use double-check to get elements from the cache (#7583)
  • Remove redundant references (#7604)
  • Fix default config is invalid (#7607)
  • Optimize the creation of executor for ThreadPoolExecutor in ZookeeperDynamicConfiguration (#7617)
  • When making a generic dubbo service request, setting check to true could cause memory leaks (#7599)
  • Remove duplicate calling metadataInfo#calAndGetRevision methods (#7630)
  • Remove EventListener usage in DubboBootstrap (#7638)
  • Convert the IllegalArgumentException generated by PojoUtils.realize in GenericFilter to RpcException (#7643)
  • Fix the problem of ProtocolConfig requiring a name parameter in new versions of Dubbo (#7624)
  • Make Dubbo2.7.x not register serviceNameMapping information with the registry by default. (#7672)

Features

  • Add options configuration mechanism for JdkCompiler. (#7232)
  • Add arguments router to ConditionRouter (#7378)
  • Solve the problem of repeatedly registering the BeanDefinition of the provider (#7494)
  • Add annotations field to matedata definition (#7660)

Bugfixs

  • Fix incorrect handling of the URLBuilder caused the wrong URL to be generated (#7501)
  • Fix bug for export async ignore exception (#7507)
  • Fix the DubboReference * version is invalid issue (#7489)
  • Fix the StatItem.isAllowable() always lets 1 more request pass (#4141)
  • Clear destroyed invokers in AbstractProxyProtocol (#4738)
  • Set default needReconnect true when channel is not connected (#6873)
  • Fix registry of etcd set 'group' cannot isolate (#4825)
  • Fix lock in DubboProtocol#getSharedClient (#6018)
  • Fix code type in ExceptionFilter (#6932)
  • Make generic param as group,version handled in org.apache.dubbo.rpc.cluster.support.ClusterUtils (#6900)
  • Solve Broadcast cluster means that multiple machines will be called,which is not converted to injvm protocol at this time. (#7365)
  • Fix repeat adding parameters to the URL (#7498)
  • Fix incorrect definition of instance variable name (#7547)
  • Fix the build on Linux ARM64 CPU architecture (#7408)
  • Consumer config tag override privode tag config (#5975)
  • Fix RegistryProtocol Logger (#7546)
  • Fix unlisten mismatch key problem. (#7465)
  • Fix issue that could lead to multiple init in MetadataReportInstance#init (#7586)
  • Fix field may be null, avoid throwing NullPointerException (#7620)
  • Fix method may be null in RpcUtils,avoid throwing NullPointerException (#7627)
  • Fix localAddress may be null,avoid throwing NullPointerException (#7622)
  • Fix method may be null, and NullPointerException will be thrown in MethodUtils (#7606)
  • Fix RegistryProtocol registerStatedUrl NPE. (#7610)
  • Fix setSkyWalkingDynamicField(java.lang.Object) not found (#7517)
  • Fix delete last config not take effect (#6964)
  • Fix remoteMap may be null to avoid NullPointerException being thrown (#7654)
  • Fix EtcdServiceDiscovery not overriding the getUrl method, causing subscribe to throw an exception (#7659)
  • Fix Dubbo zookeeper registry failed to re-subscribe (#7669)
  • ZookeeperServiceDiscovery curator client support multi address. (#7285)

Dependency Upgrades

  • Upgrading the artifact org.javassist.javassist:3.23.1-GA #7516
  • Upgrading the artifact com.alibaba.nacos.nacos-client:1.4.1 #7676
