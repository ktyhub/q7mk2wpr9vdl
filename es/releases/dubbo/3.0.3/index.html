Características

  • Adjunto de soporte cuando la respuesta triple es una excepción (#8488)
  • Extraiga DubboSpringInitializer y admita la inicialización personalizada (#8495)
  • Admite flujo de servidor triple (#8542)
  • Mejorar y corregir la configuración de verificación (#8483)
  • Flujo de soporte del compilador Dubbo (#8566)
  • Admite interfaces de red ignoradas (#8616)
  • Admite respuesta de triple anulación (#8608)
  • Agregar servicio de salud interior triple (#8644)
  • Instancia múltiple Soporte (#8662,#8669,#8684,#8717,#8728,#8736,#8737,#8766,#8779,#8789 ,#8786,#8810,#8818,#8819,#8825,#8823,#8829,#8831,#8824,#8835,#8832）
  • Compatible con la configuración de HTTP2 (#8700)

Corrección de errores

  • Evitar que los recursos no se liberen durante la llamada a destruir (#8459)
  • Se corrigió cuando el uso del protocolo triple no disponible devuelve una excepción real (#8458)
  • Triple: elimina el ajuste automático cuando el archivo adjunto es una instancia de objeto (#8473)
  • Resolver el problema de entrega de direcciones en escenarios de descubrimiento de servicios (#8492)
  • Se corrigió la dirección en el error usado del puerto 2181 (#8466)
  • Se corrigió el error en el formato del registro de transmisión (#8484)
  • Reparar TLS usando el esquema HTTP cuando se usa el protocolo TRI (#8497)
  • Corregir algunos comentarios (#8526)
  • Se corrigió el error de conversión de clase y se agregó una prueba unitaria para ZoneAwareClusterInvoker (#8503)
  • Se corrigió que el grupo nacos fuera inviable en el lado del consumidor (#8533)
  • Se corrigió NPE en la verificación de serialización cuando se agotó el tiempo de espera de la solicitud (#8547)
  • Compacto con dubbo-all sin farbic-io（#8546）
  • Corregir error de BroadcastClusterInvoker y agregar casos de prueba (#8532)
  • Reparar fuga de conexiones de MetadataService (#8555)
  • Arreglar la configuración simulada: verdadera (#8558)
  • Arreglar inicio de configuración duplicado (#8578)
  • Ignorar servicios de nacos que no sean Dubbo（#8573）
  • El error de corrección en los filtros no se puede devolver a client (#8615)
  • Actualización de la versión del compilador a la versión 0.0.3 (#8687)
  • La solución client no puede reconocer solo trailers (#8664)
  • Se corrigió el error de aserción aleatoria (#8703)
  • Arreglar el método tri stream no puede encontrar el métodoDescriptor（#8705）
  • Se corrigió el NPE del modelo de consumidor en TripleClientHandler (#8734)
  • Se corrigió el método de coincidencias de nombre de interfaz ignorado (#8723)
  • Se corrigió que el consumidor y el proveedor tuvieran la misma etiqueta, pero no se encontró ningún proveedor (#8763)
  • Reparar Triple Classloader y agregar versiones anteriores de ServiceMetadata (#8800)
  • Arreglar el estado de DubboProtocol y arreglar NPE cuando se destruye (#8809)
  • Reparar que el consumidor que utiliza una conexión URL directa no pueda obtener ServerContext（#8757）
  • Reparar ClassPath de Javaassist ClassPool (#8828)
  • Se corrigió que el protocolo de administración de nacos no pudiera obtener el nombre de la interfaz (#8782)

Optimización

  • Optimice la constante del encabezado triple y evite el encabezado triple en los archivos adjuntos (#8481)
  • Triple: optimiza la conexión y elimina el ejecutor (#8486)
  • Compacto con algún registro sin dirección (#8496)
  • Cambiar la estructura de cal de revisión de información de servicio (#8478)

  • Optimizar: ejemplo agregar demostración de protocolo triple (#8643)

  • Limpieza de recursos antes de destruirlos o detenerlos (#8636)
  • Juzgue si tuvo éxito o no según la perspectiva del usuario en el mapeo interfaz-nombre de la aplicación (#8721)

  • Eliminar código similar (#8671)
  • Agregar salida de registro cuando se notifique el error (#8729)

  • Eliminar bloque de captura duplicado (#8750)

  • Calcular la capacidad en el constructor predeterminado de InternalThreadLocalMap（#8697）
  • DefaultFuture desactiva la optimización de registro para el canal (#8775)
  • Cierre client inmediatamente cuando destruya el invocador no utilizado (#8755)
  • Usos ineficientes de las colecciones de Java (#8784)
  • Utilice el servidor de captura de promesa para enviar una excepción de encabezado grande (#8774)
  • Refactorizar AbstractRegistryFactory (campo estático exacto) (#8808)
