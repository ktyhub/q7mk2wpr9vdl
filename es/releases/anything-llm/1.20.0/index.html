cualquier cosa-llm v1.20.0

Extensión de navegador actualizada

La extensión del navegador se ha mejorado más allá de su función original de simplemente recopilar documentos y ahora cuenta con una barra de chat de interfaz de usuario completa con la capacidad de seleccionar click -> Agregar contexto (texto e imagen) y chatear directamente en Chrome. Esta barra lateral debería tener una paridad total para las herramientas y más con la interfaz de usuario de chat tradicional. Si bien es compatible con versiones anteriores y posteriores, solo se espera una funcionalidad completa cuando el servidor y la extensión tienen la versión 1.20.0 o posterior. La tienda web de Chrome también se ha actualizado a esta versión. https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

Revisión de la herramienta PowerPoint

<img width="1990" height="1099" alt="pptx-generación" src="https://github.com/user-attachments/assets/05689972-1296-4869-b208-dd9301222dd3" /> La herramienta PowerPoint del agente ha sido reconstruida desde cero para producir presentaciones más limpias y con mejor apariencia. - **Temas y diseños:** las presentaciones utilizan nuevos temas de color y un conjunto de diseños que se seleccionan para adaptarse al contenido de cada diapositiva, de modo que el mismo diseño no se repita diapositiva tras diapositiva. - **Vistas previas de diapositivas en vivo:** las diapositivas aparecen en el chat a medida que se crean, para que puedas ver cómo se arman las presentaciones. Cli Consulta una vista previa para verla en tamaño completo. - **Contenido fundamentado:** las cifras, los valores de los gráficos y las citas solo se conservan cuando su esquema, investigación o conversación los contienen, y el tamaño del texto se adapta a cada diapositiva. ### Tarjetas de aprobación de correo electrónico para Gmail y Outlook <img width="1990" height="1099" alt="email-drafting" src="https://github.com/user-attachments/assets/0b571869-c43b-454f-bdf1-0e2e3d4b4beb" /> Cuando un agente desea enviar o redactar un correo electrónico con las herramientas [Gmail](https://docs.anythingllm.com/agent/usage/gmail-agent) o [Outlook](https://docs.anythingllm.com/agent/usage/outlook-agent), la solicitud de aprobación ahora se muestra como una tarjeta de correo electrónico. Puede editar los destinatarios, CC, CCO, asunto y cuerpo directamente en la tarjeta antes de aprobarla. El cronómetro de aprobación se detiene mientras editas y puedes expandir un correo electrónico enviado para ver exactamente qué salió. ### Mejoras en MCP - **Reenvío de identidad:** Los servidores MCP ahora pueden recibir el espacio de trabajo y el usuario que los llama. Regístrese por servidor con `anythingllm.forwardIdentity`. Consulte [Reenvío de identidad a servidores MCP] (https://docs.anythingllm.com/mcp-compatibility/forward-identity). - **Tiempos de espera por servidor:** configure `anythingllm.timeout` (en segundos) en un servidor MCP para controlar cuánto tiempo se pueden ejecutar las llamadas a su herramienta. El valor predeterminado es 60 segundos. - **Desarrollador API:** los nuevos puntos finales `/v1/mcp-servers` le permiten enumerar, agregar, actualizar, eliminar, iniciar, detener y recargar servidores MCP, y activar o desactivar herramientas individuales. - Los servidores MCP con muchas herramientas ahora cargan cada página de herramientas, al iniciar un servidor también se seleccionan los servidores recién guardados y los servidores desconectados se pueden eliminar. ---- ## ¿Qué ha cambiado? * corrección: envolver tablas de rebajas en un contenedor de desplazamiento para pantallas anything-llm v1.20.0

Updated browser extension

The browser extension has been improved beyond its original function of just collecting documents to now a full fledged UI chat bar with the ability to right click -> Add context (text and image) and chat directly in Chrome. This sidebar should have mostly full parity for tooling and more with the traditional chat UI.

While it is backward and forward compatible, only full functionality is expected when the server and extension are on version 1.20.0 or later. The Chrome webstore has been updated to this version as well.

https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

PowerPoint tool overhaul

<img width="1990" height="1099" alt="pptx-generation" src="https://github.com/user-attachments/assets/05689972-1296-4869-b208-dd9301222dd3" />

The agent's PowerPoint tool has been rebuilt from the ground up to produce cleaner, better looking presentations.

  • Themes and layouts: decks use new color themes and a set of layouts that are picked to fit each slide's content, so the same layout is not repeated slide after slide.
  • Live slide previews: slides appear in the chat as they are built, so you can watch the deck come together. Click a preview to see it full size.
  • Grounded content: figures, chart values and quotes are only kept when your outline, research or conversation contains them, and text is sized to fit each slide.

Email approval cards for Gmail and Outlook

<img width="1990" height="1099" alt="email-drafting" src="https://github.com/user-attachments/assets/0b571869-c43b-454f-bdf1-0e2e3d4b4beb" />

When an agent wants to send or draft an email with the Gmail or Outlook tools, the approval request is now shown as an email card. You can edit the recipients, Cc, Bcc, subject and body right in the card before you approve it. The approval timer pauses while you edit, and you can expand a sent email to see exactly what went out.

MCP improvements

  • Identity forwarding: MCP servers can now receive the workspace and user that is calling them. Opt in per server with anythingllm.forwardIdentity. See Forwarding identity to MCP servers.
  • Per-server timeouts: set anythingllm.timeout (in seconds) on an MCP server to control how long its tool calls can run. The default is 60 seconds.
  • Developer API: new /v1/mcp-servers endpoints let you list, add, update, delete, start, stop and reload MCP servers, and turn individual tools on or off.
  • MCP servers with many tools now load every page of tools, starting one server also picks up any newly saved servers, and disconnected servers can be deleted.
