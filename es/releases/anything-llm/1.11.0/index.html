anything-llm v1.11.0

Highlights

  • Desktop overlay (headline feature) — AnythingLLM Desktop gains a free, OS-level application-aware panel that opens on a single keystroke and can ingest the currently open application into your existing chat/document/RAG/agents workflows. It is desktop-only and positioned as the recommended daily-use mode; desktop users should upgrade for this alone, while web/Docker-only deployments get nothing from it.

  • Breaking changes & migration — PR #4958 migrates system preferences to a field-based endpoint and removes the deprecated endpoint, so any scripts/clients calling the old endpoint must be updated; PR #4922 switches AzureOpenAI tool calling from function to tool; PR #4828 standardizes username constraints (with #4914 cleaning up the "username already exists" error), which can affect existing names; and PR #4909/#4908 refactor Ollama context-window settings. If you integrate against those APIs or rely on custom usernames, test before upgrading.

  • Expanded model & provider support — New SambaNova (#4943) and PrivateModeAI (#4937) integrations, LMStudio LLM/embedder API-token support (#4948), custom headers for Generic OpenAI LLMs (#4999), configurable embedder output dimensions for LocalAI and Gemini gemini-embedding-001 (#4980), UAE-region Bedrock models (#4964), and an Ollama SDK bump from 0.5.10 to 0.6.3 (#4977). Worth upgrading if you use any of these backends; otherwise irrelevant.

  • UI polish and bug fixes — New login page (#4862), chat-history scroll-to-top/bottom shortcuts (#4870), web push notifications (#4942), persisted thinking-block toggle state (#4916), fix for Citations UI glitching during streaming chats (#4897), multiple sidebar fixes (#4881, #4965, #4970), agent workspace settings no longer loading forever (#4956), and the ability to edit existing SQL agent connections (#4848). Quality-of-life improvements for daily users, but not a reason to upgrade on their own.

  • Upgrade verdict — This is a substantive feature release, not a no-op, re-tag, or metadata-only change. Desktop users and anyone needing the new providers/APIs should upgrade; teams depending on the removed system-preferences endpoint or AzureOpenAI function-style tool calling must migrate first. Server-only users happy with their current providers can safely skip this one.

AnythingLLM Desktop overlay is live!

this is a free & desktop specific feature!

Now, AnythingLLM Desktop has an OS-level and application aware panel that opens in a single keystroke. Seamlessly ingest your current open applications alongside all other chat functionality you use like document chat, RAG, agents, and more.

This panel is such a smoother and more convenient way to use AnythingLLM - we highly recommend this for daily use!
