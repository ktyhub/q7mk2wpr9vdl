cualquier cosa-llm v1.16.2

Nuevas características

  • [x] LLMman - OSS ahora está disponible como proveedor local de LLM, reemplazando a Docker Model Runner
  • [x] Google Vertex AI ahora está disponible como proveedor de LLM
  • [x] Nueva habilidad del agente generate-image para crear imágenes desde el chat
  • [x] You.com es ahora el proveedor de búsqueda web predeterminado para búsquedas web más completas con retención de datos cero
  • [x] Las variables de flujo de agentes ahora admiten argumentos opcionales
  • [x] Se agregó compatibilidad con los idiomas hindi, búlgaro y sueco.
  • [x] GenieX en Windows en ARM ahora enumera los modelos que se encuentran en su directorio de modelos local y le permite extraer modelos directamente desde Hugging Face en la interfaz de usuario.
  • [x] Cli Marque la etiqueta de versión en la parte superior de la ventana para saltar a sus registros y directorio de almacenamiento más fácilmente

Mejoras

  • [x] La navegación web ahora está habilitada de forma predeterminada para los agentes
  • [x] Los proveedores locales ahora informan el estado de carga del modelo en el chat para que sepas por qué la primera respuesta es lenta
  • [x] El tiempo de ejecución de Ollama pasó a 0.33.3 con una lista de modelos incluidos actualizada
  • [x] Se eliminaron los bordes alrededor del área de contenido principal para un diseño de escritorio más limpio.
  • [x] Rediseñado el diseño modal de "nueva característica"
  • [x] Las fechas en las tablas ahora se muestran en un formato legible por humanos.
  • [x] Las páginas web raspadas ahora conservan tablas, listas ordenadas y bloques de código en lugar de aplanarlos
  • [x] Las páginas PDF ahora están unidas con nuevas líneas para que las palabras no se fusionen entre los límites de la página.
  • [x] Las incrustaciones de Mistral ahora se realizan por lotes, lo que hace que la incrustación de documentos grandes sea mucho más rápida
  • [x] La búsqueda de documentos ahora coincide con sus términos literalmente en lugar de como una expresión regular
  • [x] Los documentos observados ahora borran los vectores obsoletos al sincronizarse
  • [x] AnySearch como proveedor de búsqueda web
  • [x] Proveedor KoboldCPP revisado y modernizado para que coincida con el resto de nuestros proveedores
  • [x] Keenable agregado como proveedor de búsqueda web
  • [x] Selección de nivel de servicio OpenRouter para controlar el costo y la prioridad del enrutamiento
  • [x] Edición de imágenes LocalAI a través de imágenes de referencia

anything-llm v1.16.2

New Features

  • [x] LLMman - OSS is now available as a local LLM provider, replacing Docker Model Runner
  • [x] Google Vertex AI is now available as an LLM provider
  • [x] New generate-image agent skill for creating images from chat
  • [x] You.com is now the default web search provider for richer web-searches with Zero Data Retention
  • [x] Agent flow variables now support optional arguments
  • [x] Hindi, Bulgarian, and Swedish language support added
  • [x] GenieX on Windows on ARM now lists models found in your local model directory and lets you pull models directly from Hugging Face in the UI
  • [x] Click the version tag in the top of the window to jump to your logs and storage directory more easily

Improvements

  • [x] Web browsing is now enabled by default for agents
  • [x] Local providers now report model loading status in chat so you know why the first response is slow
  • [x] Ollama runtime bumped to 0.33.3 with an updated bundled model list
  • [x] Removed the borders around the main content area for a cleaner desktop layout
  • [x] Redesigned the "new feature" modal layout
  • [x] Dates in tables are now shown in a human-readable format
  • [x] Scraped web pages now preserve tables, ordered lists, and code blocks instead of flattening them
  • [x] PDF pages are now joined with newlines so words don't fuse across page boundaries
  • [x] Mistral embeddings are now batched, making large document embedding significantly faster
  • [x] Document search now matches your terms literally instead of as a regular expression
  • [x] Watched documents now clear stale vectors on sync
  • [x] AnySearch as a web-search provider
  • [x] KoboldCPP provider overhauled and modernized to match the rest of our providers
  • [x] Keenable added as a web search provider
  • [x] OpenRouter service tier selection for controlling routing cost and priority
  • [x] LocalAI image editing via reference images
