Stirling-PDF_0.33.1 Docker movimiento del cubo a Stirlingtools v3.0.0

¡Stirling PDF V3.0 ya está disponible! Con esta actualización, presentamos muchos cambios nuevos e interesantes: un nuevo sistema de automatización, OAuth SSO gratuito para todos, un nuevo editor de texto y un montón de funciones nuevas, correcciones de errores y correcciones de seguridad.

Tenemos un nuevo sistema junto con el "Editor de PDF" llamado "Procesador de PDF" El procesador PDF toma las herramientas que ya utiliza en Stirling PDF y le permite ejecutarlas en una gran cantidad de archivos con una variedad de fuentes (Carpetas/FTP/S3, etc.) La idea es que, si necesita OCR 10,000 archivos, comprimir una carpeta completa o convertir una biblioteca de documentos completa, esta debería ser una herramienta que pueda ayudarlo con eso y permitirle escuchar y ejecutar archivos futuros a medida que lleguen. Esta es la primera versión importante de Processor y la mejoraremos rápidamente según cómo lo use la gente. Guía completa del procesador con ejemplos La IA también está disponible como parte opcional del Procesador. Puede utilizar la IA para comprender documentos, clasificarlos, extraer información y ayudar a automatizar el procesamiento. La IA es completamente opcional (y está desactivada de forma predeterminada) y puede usar varios modelos, incluidos modelos locales o autohospedados, según su configuración. La automatización ahora incluye 1000 archivos PDF por mes gratis. Esta asignación se aplica al procesamiento automatizado a través del Procesador, API y funciones de IA. Vincular su servidor a Stirling.com le brinda 500 archivos PDF adicionales por mes y acceso a nuestra IA alojada (si no desea alojar la suya propia). El uso normal de PDF Editor sigue siendo gratuito e ilimitado. Además, también vamos a hacer que OAuth SSO sea gratuito para todos los usuarios.

V3.0 también incluye mejoras importantes en el lado del editor de PDF:

  • El SSO gratuito de OAuth ya mencionado
  • Nuevo editor de texto, ahora fuera de la versión alfa, deberías esperar una interfaz de usuario, un rendimiento y una compatibilidad drásticamente mejores
  • Editor de formularios mejorado y creación de formularios.
  • Detección automática de formularios
  • Nueva barra de acceso rápido
  • Rotación automática
  • Mejoras importantes en la redacción.
  • Conversión PDF/UA (WIP)
  • Soporte de cartera PDF
  • Vista de lector dedicado
  • Regístrate desde tu teléfono usando un código QR
  • Marcas de tiempo RFC3161
  • Busque en todos los PDF de Stirling
  • Mejoras en la interfaz de usuario móvil
  • Se mejoró el manejo de archivos y el historial de archivos para el escritorio, por lo que los archivos eliminados se eliminan en la interfaz de usuario de Stirling.
  • Biblioteca de archivos completamente nueva
  • Nuevas carpetas de escritorio para montar carpetas desde el disco en Stirling para ejecutar la automatización (se ampliará en futuras actualizaciones)
  • Nueva página de configuración
  • Sugerencias de herramientas más inteligentes basadas en el uso anterior de herramientas
  • Mejoras generales en la interfaz de usuario y corrección de errores.
  • ¡Varias correcciones de errores y mejoras de seguridad!

Pruebe la versión 3.0 y díganos lo que piensa. Enviaremos correcciones, mejoras y nuevas capacidades de procesador y editor durante las próximas semanas y se espera que los lanzamientos sean casi semanales, con un mayor enfoque en las relaciones públicas de la comunidad en el futuro.

Stirling-PDF_0.33.1 Docker hub move to stirlingtools v3.0.0

Highlights

  • PDF Processor ships as a v1 automation engine — A second system alongside the Editor runs existing Stirling tools across thousands of files from folders, FTP, S3 and MCP sources (#6795), with watched folders that process files as they arrive — aimed squarely at bulk OCR/compress/convert jobs. It's explicitly billed as a first major release, and the fix list bears that out: circular dependencies in watched folders (#7308), locking files until processing completes (#8120), mounted-subfolder processing (#8141), and removal of the Automate operation timeout (#7082) all landed here, so treat it as fast-moving rather than stable. AI document classification and extraction are wired in but fully optional and off by default, with self-hosted model support.
  • Automation is now quota-metered — the key behavioral change — Processor/API/AI automation gets 1,000 PDFs/month free; linking your instance to stirling.com adds 500/month plus hosted AI, while normal Editor usage stays free and unlimited. Anyone running large batch or automated workflows must now budget allowance or link their server before relying on Processor in production — operationally the most significant change in the release despite being buried in the intro.
  • OAuth SSO is free for everyone — Previously gated behind paid tiers, SSO is now open to all users, removing a common adoption blocker and materially improving the self-hosted enterprise story.
  • Text Editor exits alpha; editor surface expands — The rebuilt text editor is out of alpha with major UI, performance and compatibility gains, joined by an improved form editor with auto-detection, quick access bar, redaction overhaul, PDF Portfolio support, RFC3161 timestamps, QR-code sign-from-phone and a dedicated reader view. PDF/UA conversion is still WIP — don't depend on it for accessibility compliance yet. Supporting fixes include signature placement (#7093), viewer search reporting "0 of 0" (#7228), and PDF preview/worker memory leaks (#7281).
  • Security and operational hardening worth upgrading for — Share-link route tokens are now constrained to UUID length (#7626), Telegram bot tokens are masked in settings output (#6822), the signup page is removed from self-hosted builds (#7406), SMTP timeouts are bounded so a wedged relay can't park a thread (#7879), and partial admin saves are merged instead of clobbered (#7545). Deployment note: the Docker Hub image has moved to the stirlingtools namespace — update your image references and pull policies.
