bootstrap v5.3.0-alpha2

Highlights

  • Color modes are now theme-map driven — Dark-mode text, subtle backgrounds, and subtle borders are generated through Sass maps, making customized $theme-colors propagate more consistently without separate tint/shade overrides (#37843). color-scheme: dark now themes native controls such as scrollbars, while form controls and validation states correctly follow the active mode (#37734, #37893, #38044).

  • Links and navigation gain reusable primitives — .icon-link handles icon/text alignment, while .link-opacity-*, .link-offset-*, .link-underline-*, .link-underline-opacity-*, .link-body-emphasis, and .nav-underline replace common custom CSS (#37762, #37833, #33126). Colored links now manipulate RGB and underline CSS variables instead of hard-resetting color; check contrast when using reduced link opacity.

  • Focus styling becomes a shared customization API — .focus-ring and .focus-ring-* use global Sass/CSS variables for width, opacity, color, offsets, and blur, allowing runtime overrides without duplicating shadows (#33125, #38095). Nav focus moves to :focus-visible (#37784). Alpha1 custom CSS referencing --bs-focus-ring-box-shadow must be rebuilt from the individual variables because that aggregate variable was removed.

  • Accessibility fixes change markup and keyboard behavior — Progress bars move role and ARIA attributes onto .progress; stacked bars use .progress-stacked. Legacy markup still renders, but may not announce zero-width values to assistive technology (#36831). Tabs now generate valid bare IDs in aria-labelledby, without a leading # (#38223). Modal and Offcanvas Escape handling is unified, and Modal no longer calls preventDefault(), so custom keyboard handlers inspecting defaultPrevented need retesting (#38025).

  • Alpha-to-alpha migration requires variable and class updates — Rename CSS --bs-{color}-text to --bs-{color}-text-emphasis, and Sass $…-text/$…-text-dark to $…-text-emphasis/$…-text-emphasis-dark (#37907, #38176). The short-lived --bs-form-control-bg and --bs-form-control-disabled-bg variables are removed (#37893). .text-muted/$text-muted and .dropdown-menu-dark are deprecated; use .text-body-secondary/$body-secondary-color and data-bs-theme="dark" (#37890, #37862). Border-width utilities also set border-width directly again, so custom overrides relying on inherited --bs-border-width need review (#37999).

  • Sass and package consumers get concrete fixes — $color-mode-type: media-query now compiles correctly (#37687), and npm publishes js/index.esm.js and js/index.umd.js, which may require updating direct-import paths or packaging allowlists (#37565). The Utilities API also gains SCSS test coverage, improving confidence for projects that extend $utilities (#36029).
