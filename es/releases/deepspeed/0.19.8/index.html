DeepSpeed v0.19.8

Highlights

  • Legacy feature removals require config cleanup — Progressive Layer Dropping (#8562) and elastic training (#8563) are removed; APEX AMP (#8564), legacy curriculum learning (#8566), LoCo Zero++ (#8534), sparse_gradients (#8504), compression-library remnants (#8535), and graph harvesting (#8579) are deprecated or removed. Audit configs, imports, and training scripts before upgrading—removed paths can fail at startup rather than silently fall back.
  • AutoTP now shards vocabulary matrices and tied models — Vocab-parallel embeddings (#8582) and LM heads (#8309), eager row-parallel output heads (#8538), tied-embedding support (#8680), and AutoEP + AutoTP folding under ZeRO-3 (#8670) reduce per-rank memory pressure for large-vocabulary models. Liger vocabulary-parallel cross-entropy remains opt-in (#8540), so verify its dependency and runtime requirements before enabling it.
  • Muon is hardened for ZeRO, gradient accumulation, and offload — ZeRO-3 now runs Muon once per optimizer step instead of once per micro-batch (#8600), while fixes cover CPU offload with bounded gathers (#8464), mixed parameter shapes (#8628), and FP16 loss scaling without truncating update size (#8655). BF16_Optimizer gains Muon with FP32 gradient accumulation (#8526), and per-head Newton-Schulz paths now understand attention and linear-attention geometry (#8384, #8436).
  • AutoEP reduces per-layer MoE overhead — A single DeepEP buffer is shared across MoE layers (#8557), the default combine drops a redundant FP32 copy (#8621), and split planning overlaps token packing (#8359), limiting memory growth and data movement in deep MoE stacks. Opt-in GC policy, regional compilation, an activation registry, fused row weighting, and a MiniMax-M3 preset provide further tuning options (#8451, #8380, #8650, #8644, #8651); checkpoint replay also fixes cache lifetime and layout handling (#8581, #8636).
  • ZeRO correctness fixes prevent silent training and checkpoint failures — This release addresses dropped CPU gradient buckets in ZeRO-1/2 (#8382), incomplete asynchronous gathers in ZeRO-3 (#8539), FP32 and non-floating buffer preservation (#8699, #8515), and duplicate shard destinations during checkpoint conversion (#8624). Also audit two behavioral changes: DeepSpeedCPUAdam now rejects unsupported amsgrad instead of ignoring it (#8694), and rollout rejects shared prefill with continuous batching (#8583).
  • NPU and Triton backend coverage expands — NPU gains graph operations (#8605), fused Lion/Lamb/quantizer kernels (#8627), and native pinned host-memory registration (#8532). Triton fixes restore FlashAttention/MatMul autotuning compatibility and use 64-bit program IDs in SwiGLU/AutoEP restore kernels (#8679, #8591), while opt-in fused RMSNorm and RoPE target Llama-style Hugging Face models (#8645, #8663).
