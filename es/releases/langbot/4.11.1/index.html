LangBot v4.11.1

Highlights

  • Monitoring reliability — Session queries are optimized, terminal task states are corrected, and historical image storage/migration compatibility is improved. This is a maintenance release with no breaking changes or migration steps called out.
  • Message and plugin fixes — Message filtering, explicit attachment delivery, platform-specific message handling, and plugin-installation diagnostics are fixed. Users hitting attachment failures, incorrect filtering, or unclear plugin-install errors should upgrade.
  • SDK compatibility and efficiency — langbot-plugin is pinned to ==0.7.16, and plugins without event listeners no longer receive unnecessary event RPC calls. This reduces avoidable plugin execution overhead, but plugin developers should note the exact SDK version.
  • Upgrade recommendation — Worth upgrading if you rely on affected messaging, monitoring, storage, or plugin behavior. Users without those issues can safely skip; PyPI packages, dual-architecture Docker images, source ZIP, and fnOS FPK passed publication/readback and clean-start verification.

LangBot 是一个开源的 AI 聊天机器人与智能体平台，支持多种即时通讯平台、大语言模型、知识库和插件，帮助你构建、部署和管理 AI 助手。 LangBot is an open-source AI chatbot and agent platform that connects messaging platforms, large language models, knowledge bases, and plugins to help you build, deploy, and manage AI assistants.

LangBot v4.11.1

本次更新改进监控性能、消息处理和插件兼容性。 This maintenance release improves monitoring performance, message handling, and plugin compatibility.

Highlights / 主要更新

  • 监控与存储 / Monitoring and storage：优化会话查询，修复任务终态处理，改进历史图片存储和迁移兼容性。Optimize session queries, fix terminal execution states, and improve historical image storage and migration compatibility.
  • 消息与插件 / Messages and plugins：修复消息过滤、插件安装诊断、显式附件发送及部分平台消息处理。Fix message filtering, plugin installation diagnostics, explicit attachment delivery, and platform-specific message handling.
  • SDK：精确固定 langbot-plugin==0.7.16，避免对无事件监听器的插件执行不必要的事件 RPC。Pin langbot-plugin==0.7.16 and avoid unnecessary event RPC calls for plugins without event listeners.

Release verification / 发布验证

PyPI 包、双架构 Docker 镜像、源码 ZIP 和 fnOS FPK 已发布并读回验证；全新安装与隔离 Linux 启动检查通过。 PyPI packages, dual-architecture Docker images, the source ZIP, and fnOS FPK were published and verified. Clean installation and isolated Linux startup checks passed.
