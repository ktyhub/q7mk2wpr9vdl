#jadxv1.5.4

Características principales

CLI:

  • Implementar la carga y guardado del archivo de configuración (#1731)

GUI:

  • Cambie el tamaño de las fuentes con el zoom de la interfaz de usuario, use el paquete de fuentes FlatLaf
  • Utilice FontUtils.getCompositeFont() que admita CJK (PR #2751)

Complementos:

  • El complemento de secuencias de comandos ahora es externo y no está incluido en el paquete de lanzamiento. Consulte jadx-script-kotlin para obtener detalles de instalación.
  • Admite archivos '.apks' (PR #2647)
  • Permitir usar .zip como artefacto de complemento (con frascos dentro)
  • Informar excepciones del complemento al proyecto github del complemento

jadx v1.5.4

Main features

CLI:

  • Implement config file load and save (#1731)

GUI:

  • Change fonts size with UI zoom, use FlatLaf fonts bundle
  • Use FontUtils.getCompositeFont() that supports CJK (PR #2751)

Plugins:

  • Scripting plugin now external and not included in release bundle. Check jadx-script-kotlin for installation details.
  • Support '.apks' files (PR #2647)
  • Allow to use .zip as plugin artifact (with jars inside)
  • Report plugin exceptions to plugin github project
