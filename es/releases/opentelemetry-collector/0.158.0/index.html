Usuario final Changelog

🚀 Nuevos componentes 🚀

  • processor/queuebatch: Nuevo queuebatchprocessor para reemplazar el heredado batchprocessor. (#15047, #13582, #12022, #11308, #8272, #6046) La nueva implementación se basa en exporterhelper y utiliza la misma configuración que sending_queue.

💡 Mejoras 💡

  • cmd/mdatagen: agregue alias de tipo extendido de primera clase (int64, duración, opaque_string, id, opaque_map, etc.) a los esquemas de configuración en metadata.yaml (#15513) Los autores ahora pueden escribir type: int64, type: duration, type: opaque_string, type: id o type: opaque_map directamente como tipo de propiedad en la sección config: de metadata.yaml. Cada alias se expande automáticamente a la representación de esquema JSON y al tipo Go correctos. Los usos existentes de los tipos de esquemas estándar JSON, format: y x-customType: siguen siendo compatibles. sin migración.
  • extension/memory_limiter: Promocionar la extensión del limitador de memoria a estabilidad beta. (#14533)

🧰 Corrección de errores 🧰

  • cmd/mdatagen: Elimina la línea adicional en el archivo document.md alrededor de la descripción (#15664)
  • cmd/mdatagen: habilita automáticamente las métricas v1 cuando la métrica heredada está habilitada y la puerta de funciones v1 está activada (#15650) Cuando la puerta de funciones v1 está habilitada y una métrica heredada está habilitada, la correspondiente La métrica v1 ahora está habilitada mediante programación para que los usuarios no necesiten agregar la métrica v1 a su configuración.
  • cmd/mdatagen: Se corrigió la advertencia de colisión incorrecta para métricas versionadas con diferentes nombres emitidos (#15648) Se estaba utilizando la detección de colisiones del mismo nombre (verificaciones de tipo/atributo) para métricas versionadas con diferentes nombres. Esto provocó que la métrica heredada se deshabilitara, lo cual era incorrecto y también se estaba registrando incorrectamente un mensaje de advertencia que indicaba que las métricas tenían el mismo nombre cuando estaban en De hecho tenían diferentes nombres.
  • cmd/mdatagen: Las métricas versionadas no manejan atributos renombrados con el mismo tipo (#15595) Las métricas versionadas deben admitir la emisión de atributos heredados y más recientes cuando el nombre de la métrica es el mismo pero el Los nombres de los atributos difieren. Esto no funcionó cuando el nombre de los atributos cambió pero el tipo siguió siendo el mismo. Aquí agregamos soporte para métricas versionadas con atributos renombrados donde esos atributos tienen el mismo tipo.
  • exporter/debug: Se corrigió el formato de atributos de muestra de perfil para valores que no son cadenas (#15647) Anteriormente, los valores que no eran cadenas producían resultados con formato incorrecto, como %!s(int64=42). Los atributos de muestra de perfil ahora utilizan el formato de atributo escrito del exportador de depuración, como Int(42). Esto también cambiará las cadenas de hello-world a Str(hello-world).
  • pkg/config/configtls: Se corrige la fuga de rutinas y descriptores de archivos cuando client_ca_file_reload está habilitado (#9221) Cada llamada a ServerConfig.LoadTLSConfig con client_ca_file_reload habilitado iniciaba un rutina de vigilancia de archivos que nunca se pudo detener, ya que no se podía acceder al recargador del *tls.Config devuelto. Ahora se comprueba si hay cambios en el archivo CA client mientras se ejecuta TLS. Los apretones de manos se sirven, como máximo una vez por segundo, igualando cómo reload_interval ya recarga el certificado del servidor. No se inicia ninguna rutina en segundo plano, por lo que no queda nada. detrás cuando un servidor es derribado y recreado.

opentelemetry-collector v0.158.0

Images and binaries here: https://github.com/open-telemetry/opentelemetry-collector-releases/releases/tag/v0.158.0

End User Changelog

🚀 New components 🚀

  • processor/queuebatch: New queuebatchprocessor to replace the legacy batchprocessor. (#15047, #13582, #12022, #11308, #8272, #6046) New implementation is based exporterhelper, uses same configuration as sending_queue.

💡 Enhancements 💡

  • cmd/mdatagen: Add first-class extended type aliases (int64, duration, opaque_string, id, opaque_map, etc.) to config schemas in metadata.yaml (#15513) Authors can now write type: int64, type: duration, type: opaque_string, type: id, or type: opaque_map directly as a property type in the config: section of metadata.yaml. Each alias expands to the correct JSON Schema representation and Go type automatically. Existing uses of standard JSON Schema types, format:, and x-customType: remain supported without migration.

  • extension/memory_limiter: Promote the memory limiter extension to beta stability. (#14533)

🧰 Bug fixes 🧰

  • cmd/mdatagen: Removes the extra line in the documentation.md around description (#15664)

  • cmd/mdatagen: Auto-enable v1 metrics when legacy metric is enabled and v1 feature gate is on (#15650) When the v1 feature gate is enabled and a legacy metric is enabled, the corresponding v1 metric is now programmatically enabled so users don't need to add the v1 metric to their config.

  • cmd/mdatagen: Fix incorrect collision warning for versioned metrics with different emitted names (#15648) Same name collision detection (type/attribute checks) was being used for versioned metrics with different names. This caused the legacy metric to be disabled which was incorrect and also a warning msg was being incorrectly logged that stated the metrics had the same name when in fact they had different names.

  • cmd/mdatagen: Versioned metrics don't handle renamed attributes with same type (#15595) Versioned metrics need to support emitting legacy and latest attributes when the metric name is the same but the attributes names differ. This was not working when the attributes name changed but the type remained the same. Here we add support to versioned metrics with renamed attributes where those attributes have the same type.

  • exporter/debug: Fix profile sample attribute formatting for non-string values (#15647) Previously, non-string values produced malformed output such as %!s(int64=42). Profile sample attributes now use the debug exporter's typed attribute format, such as Int(42). This will also change strings from hello-world to Str(hello-world).

  • pkg/config/configtls: Fix goroutine and file descriptor leak when client_ca_file_reload is enabled (#9221) Every call to ServerConfig.LoadTLSConfig with client_ca_file_reload enabled started a file watcher goroutine that could never be stopped, since the reloader was not reachable from the returned *tls.Config. The client CA file is now checked for changes while TLS handshakes are served, at most once per second, matching how reload_interval already reloads the server certificate. No background goroutine is started, so nothing is left behind when a server is torn down and recreated.
