aplastar v0.102.0

Canales, mensajes personalizados y refuerzo del servidor

Hay muchas cosas buenas en esta versión y estamos muy orgullosos de todas ellas. Siga leyendo para obtener más información.

Avisos BYO

Por fin, puedes reemplazar las indicaciones del sistema con… lo que quieras. Y no solo el agente principal, sino también solicitudes de subagentes, planificación, compactación, títulos de sesión y crush init:

option prompt coder ~/.config/crush/prompts/coder.md.tpl
option prompt summary prompts/summary.md

Puede configurar el mensaje en la configuración global, anular por proyecto en la configuración local o anular el mensaje con --prompt name=path. Para obtener más información sobre las indicaciones, consulte los documentos.

Montar en la noche

Crush ahora viene con un tema KITT inspirado en Knight Rider, cortesía de @cdancy. Rosé Pine Classic, Moon y Dawn ahora también están disponibles.

crush v0.102.0

Channels, custom prompts and server hardening

There's so much good stuff in this release and we're really proud of all of it. Read on for more.

BYO Prompts

At last, you can replace the system prompts with…whatever you want. And not just the main agent but prompts for subagents, planning, compaction, session titles and crush init:

option prompt coder ~/.config/crush/prompts/coder.md.tpl
option prompt summary prompts/summary.md

You can set prompt in the global config, override per project in local config, or override the prompt with --prompt name=path.

For more on prompts, see the docs.

Riding in the Night

Crush now ships with a Knight Rider-inspired KITT theme courtesy @cdancy. Rosé Pine Classic, Moon and Dawn are now available, too.

<p><img width="730" height="528" alt="image" src="https://github.com/user-attachments/assets/2c139b67-92a3-4600-9278-761c813699ed" /></p>

Nerd out with Nerd Fonts

At last, nerd fonts! Support is detected automatically, so they'll never break your terminal, too! Crush now uses their icons, LSP status and Git included. Note that if you're running Crush over SSH you'll need to enable Nerd fonts option ui nerd-fonts true.

# Hate nerd fonts? You can turn 'em off, too.
option ui nerd-fonts false

Channels

Channels are an experimental MCP feature from Claude, now available in Crush thanks to the fine work of @joestump. In short, channels allow MCP servers to push events into your session as they happen.

crush --channels server:webhook --channels server:signal

Or turn one on permanently in your crushrc:

# crushrc
mcp add webhook \
    --type http \
    --url https://example.com/mcp \
    --channel true

Crush uses the same protocol as Claude Channels, so existing channel servers should just work™.

Server Hardening

Client-server mode is now now sturdier than ever. It's now more secure and has a ton of small improvements, correctness fixes, nad bugfixes, especially on Windows.

And So Much More

  • Sysadmin mode is no longer one <kbd>shift+tab</kbd> past yolo.
  • Queued prompts show up in the pill the moment you submit them.
  • The model can use sudo, so you can approve with Touch ID.
  • Content refusals are retried automatically.
  • Sessions that Claude kept rejecting work again.
  • Ollama models that can't call tools no longer show up in the model list.
  • Commands that leave child processes behind no longer hang.
  • Timers tick together, and running tool timers keep going until the tool replies.
  • Switching themes no longer re-renders the whole conversation.
  • Deleting a session keeps your place in the list.
  • Replayed messages keep their whitespace, and plan cards line up properly.

Good luck, Charm XX 🌤️
