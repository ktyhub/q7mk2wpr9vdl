Cambios más importantes

  • Soporte para serializar y deserializar registros Java, en Java ≥ 16. (#2201)

  • Agregar métodos de visualización JsonArray.asList y JsonObject.asMap (#2225)

  • Se corrigió que TypeAdapterRuntimeTypeWrapper no detectaba TreeTypeAdapter y FutureTypeAdapter reflectantes (#1787)

  • Mejorar JsonReader.skipValue() (#2062)

  • Realizar conversión numérica para adaptadores de tipo numérico primitivo (#2158)

  • Agregar sobrecargas Gson.fromJson(..., TypeToken) (#1700)

  • Se corrigieron cambios en GsonBuilder que afectaban instancias Gson existentes (#1815)

  • Hacer que los métodos de conversión JsonElement sean más consistentes y corregir javadoc (#2178)

  • Lanza UnsupportedOperationException cuando JsonWriter.jsonValue no sea compatible (#1651)

  • No permitir JsonObject Entry.setValue(null) (#2167)

  • Se corrigió TypeAdapter.toJson que arrojaba AssertionError para IOException personalizada (#2172)

  • Convertir nulo a JsonNull para JsonArray.set (#2170)

  • Se corrigió el uso nulo de Safe. (#1555)

  • Validar argumentos TypeToken.getParameterized (#2166)

  • Solución #1702: Gson.toJson crea CharSequence que no implementa toString (#1703)

  • Prefiere el adaptador existente para llamadas Gson.getAdapter simultáneas (#2153)

  • Mejorar ArrayTypeAdapter para Object[] (#1716)

  • Mejorar el rendimiento de AppendableWriter (#1706)

Most important changes

  • Support for serializing and deserializing Java records, on Java ≥ 16. (#2201)

  • Add JsonArray.asList and JsonObject.asMap view methods (#2225)

  • Fix TypeAdapterRuntimeTypeWrapper not detecting reflective TreeTypeAdapter and FutureTypeAdapter (#1787)

  • Improve JsonReader.skipValue() (#2062)

  • Perform numeric conversion for primitive numeric type adapters (#2158)

  • Add Gson.fromJson(..., TypeToken) overloads (#1700)

  • Fix changes to GsonBuilder affecting existing Gson instances (#1815)

  • Make JsonElement conversion methods more consistent and fix javadoc (#2178)

  • Throw UnsupportedOperationException when JsonWriter.jsonValue is not supported (#1651)

  • Disallow JsonObject Entry.setValue(null) (#2167)

  • Fix TypeAdapter.toJson throwing AssertionError for custom IOException (#2172)

  • Convert null to JsonNull for JsonArray.set (#2170)

  • Fixed nullSafe usage. (#1555)

  • Validate TypeToken.getParameterized arguments (#2166)

  • Fix #1702: Gson.toJson creates CharSequence which does not implement toString (#1703)

  • Prefer existing adapter for concurrent Gson.getAdapter calls (#2153)

  • Improve ArrayTypeAdapter for Object[] (#1716)

  • Improve AppendableWriter performance (#1706)
