DeepTutor v1.4.11 Release Note

Fecha de lanzamiento: 2026.06.23 Una continuación de arreglos y pulido de v1.4.10: herramienta nativa que llama ahora se ilumina en todos los proveedores de nube compatibles con OpenAI, la página de usuarios administradores es reconstruido, las opciones del cuestionario renderizan LaTeX y la historia del contenedor se vuelve configurable enlace del host. Sin cita previa, sin migraciones.

¿Qué hay de nuevo?

Herramienta nativa que recurre a todos los proveedores de nube compatibles con OpenAI

Proveedores de nube que carecían de una entrada de capacidad dedicada: SiliconFlow, Gemini, Zhipu, Qianfan, NVIDIA NIM, los planes de codificación Volc/BytePlus: ahora use nativo llamada de función en lugar de volver silenciosamente a la prosa. La llamada a funciones es parte del contrato API compatible con OpenAI, por lo que cualquier proveedor de nube registrado es se supone que es compatible con herramientas a menos que se excluya explícitamente. Esto es lo que permite a KB recuperación y las herramientas de capacidad realmente se activan contra esos proveedores. Servidores locales (Ollama, vLLM, LM Studio, llama.cpp, Lemonade,…) todavía recurren a la prosa, ya que El soporte de herramientas allí depende del modelo cargado.

Página de gestión de usuarios rediseñada

La página de administración Usuarios se reconstruye con avatares, un cuadro de búsqueda de nombre de usuario y un esqueleto. estados de carga y un diálogo de confirmación con estilo antes de acciones destructivas en lugar de el mensaje del navegador sin formato.

LaTeX en las opciones de prueba

Las opciones de respuesta ahora representan Markdown y matemáticas, por lo que $…$ y las fórmulas aparecen en el opciones de la misma manera que ya lo hicieron en el texto de la pregunta.

Enlace de host de contenedor configurable

BACKEND_HOST y FRONTEND_HOST ahora son configurables por el entorno, por lo que en Linux host de red, puede mantener ambos servicios en bucle invertido (127.0.0.1) en lugar de exponiéndolos en cada interfaz. supervisord ahora se ejecuta como root para que se inicien los servicios correctamente bajo Docker rooteado y la infraestructura muerta gosu / libcap2-bin desapareció: el contenedor sigue un modelo único de supervisión raíz. Ver CONTENERIZACIÓN.md.

Al abrir una conversación, se cae la barra de progreso simulada que llegó a un 99% falso. durante ~24 segundos y en su lugar muestra una ruleta indeterminada honesta; el La conversación ahora aparece en el momento en que se resuelve la búsqueda, con un mensaje "Aún cargando..." pista después de 8 segundos.

DeepTutor v1.4.11

Highlights

  • Native tool calling by default — All cloud OpenAI-compatible providers are now assumed tool-capable unless explicitly opted out, including SiliconFlow, Gemini, Zhipu, Qianfan, NVIDIA NIM, and Volc/BytePlus plans. This enables KB retrieval and capability tools that previously degraded silently to prose; review provider behavior if you relied on that fallback.
  • Local tool behavior unchanged — Ollama, vLLM, LM Studio, llama.cpp, Lemonade, and other local servers still use prose fallback because tool support depends on the loaded model. Enabling native calling in the cloud does not change local inference behavior.
  • Container networking and startup changes — Set BACKEND_HOST=127.0.0.1 and FRONTEND_HOST=127.0.0.1 to avoid exposing services on every interface when using Linux host networking. Containers now use a single root-supervisord model for rootful Docker compatibility, with gosu and libcap2-bin removed; revisit entrypoint overrides or health checks that assume non-root services.
  • LaTeX supported in quiz options — Answer choices now render Markdown and math ($…$) consistently with question text. Existing options containing math should display correctly without rewriting them as plain text.
  • Honest conversation loading — The simulated 24-second progress bar and fake 99% state are replaced by an indeterminate spinner. Content appears immediately when the fetch resolves, with a “Still loading…” hint after eight seconds; UI tests should no longer expect synthetic progress milestones.
  • Upgrade — No breaking changes or migrations; run pip install -U deeptutor or pull ghcr.io/hkuds/deeptutor:latest.

DeepTutor v1.4.11 Release Notes

Release Date: 2026.06.23

A fixes-and-polish follow-up to v1.4.10: native tool calling now lights up on every cloud OpenAI-compatible provider, the admin Users page is rebuilt, quiz options render LaTeX, and the container story gains configurable host binding. Drop-in — no migrations.

What's New

Native tool calling on every cloud OpenAI-compatible provider

Cloud providers that lacked a dedicated capability entry — SiliconFlow, Gemini, Zhipu, Qianfan, NVIDIA NIM, the Volc/BytePlus coding plans — now use native function calling instead of silently falling back to prose. Function calling is part of the OpenAI-compatible API contract, so any registered cloud provider is assumed tool-capable unless it's explicitly opted out. This is what lets KB retrieval and the capability tools actually fire on those providers. Local servers (Ollama, vLLM, LM Studio, llama.cpp, Lemonade, …) still fall back to prose, since tool support there depends on the loaded model.

Redesigned User Management page

The admin Users page is rebuilt with avatars, a username search box, skeleton loading states, and a styled confirm dialog before destructive actions in place of the raw browser prompt.

LaTeX in quiz options

Answer choices now render Markdown and math, so $…$ and formulas show up in the options the same way they already did in question text.

Configurable container host binding

BACKEND_HOST and FRONTEND_HOST are now environment-configurable, so on Linux host networking you can keep both services on loopback (127.0.0.1) instead of exposing them on every interface. supervisord now runs as root so services start correctly under rootful Docker, and the dead gosu / libcap2-bin infrastructure is gone — the container follows a single root-supervisord model. See CONTAINERIZATION.md.

Honest session-loading overlay

Opening a conversation drops the simulated progress bar that crept to a fake 99% over ~24 seconds and shows an honest indeterminate spinner instead; the conversation now appears the moment the fetch resolves, with a "Still loading…" hint after 8 seconds.

Upgrade Notes

Drop-in from v1.4.10: pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest. No migrations, no configuration changes. The one behavior change is native tool calling defaulting on for cloud OpenAI-compatible providers — almost always what you want, since it's what makes KB retrieval and capability tools fire.
