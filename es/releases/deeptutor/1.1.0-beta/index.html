#DeepTutor v1.1.0-beta

DeepTutor v1.1.0-beta Release Note

Fecha de lanzamiento: 2026.04.14

Destacados

Enrutamiento de chat basado en URL

Se migró la experiencia de chat de los ID de sesión de parámetros de consulta (/?session=xxx) a una ruta general dedicada /chat/[[...sessionId]]. La página raíz ahora redirige a /chat y la carga de la sesión se realiza completamente mediante la ruta URL; no más restauración de sessionStorage en el montaje. Los flujos de navegación de la barra lateral, nuevo chat y selección de sesión apuntan a /chat o /chat/<id>, lo que hace que las sesiones se puedan marcar y compartir.

Tema de nieve

Se agregó un nuevo tema Nieve: una paleta limpia y de color blanco puro con detalles en azul pizarra y tonos primarios cálidos y sutiles. El ciclo temático ahora es nieve → claro → oscuro → vidrio. El ThemeScript, la página de configuración, las claves i18n y las variables CSS incluyen la nueva opción.

WebSocket Heartbeat y reconexión automática

El UnifiedWSClient ahora envía un ping de latido del lado izquierdo del cli cada 30 segundos y trata 45 segundos de silencio como una conexión inactiva. En caso de desconexión inesperada, el client reintenta con un retroceso exponencial (base de 200 ms, hasta 5 intentos) y envía un mensaje resume_from con el último turn_id / seq para que el servidor pueda reproducir los eventos perdidos.

Tiempo de espera de inactividad de transmisión

UnifiedChatContext ejecuta un temporizador en segundo plano que detecta sesiones de transmisión sin eventos entrantes durante 60 segundos. Las sesiones obsoletas fallan automáticamente con un error de tiempo de espera visible para el usuario y sus ejecutores WebSocket se limpian.

Optimización del rendimiento de ChatComposer

ChatComposer envuelto en React.memo e internalizado en estado input, showAtPopup y textareaRef. El valor del área de texto y el efecto de diseño de cambio de tamaño automático ya no activan la repetición de renderización principal, lo que elimina graves retrasos en la entrada en conversaciones largas.

Incorporación de revisión del registro de proveedores

Se reemplazó el diccionario plano EMBEDDING_PROVIDER_DEFAULTS con una clase de datos EmbeddingProviderSpec escrita que contiene label, default_api_base, adapter, default_model y default_dim. La configuración API ahora devuelve un menú desplegable de proveedores de incrustación dedicado (separado de la lista LLM) y, al seleccionar un proveedor, se completa automáticamente la dimensión de incrustación predeterminada.

Proveedor de búsqueda Serper

Se restauró Serper como proveedor de búsqueda de primera clase (anteriormente obsoleto). Se agregó el respaldo de entorno SERPER_API_KEY, se registró el módulo del proveedor y se actualizaron todos los mensajes de obsolescencia.

Resiliencia de informes de investigación profunda

La escritura de secciones en el agente de informes ahora vuelve a la salida LLM sin procesar cuando falla el análisis de JSON, en lugar de cancelar todo el informe. El respaldo elimina los contenedores JSON de la respuesta y registra una advertencia.

Corrección del bloque de código del renderizador Markdown

Se corrigió la detección de código en línea versus en bloque en SimpleMarkdownRenderer. El contenido de varias líneas ahora se representa dentro de un bloque con estilo <pre>, mientras que el código de una sola línea se representa como un elemento <code> en línea, resolviendo casos en los que las comillas invertidas en línea producían bloques de código completos.

Soporte de respuesta de incorporación de Ollama

El adaptador de incrustación compatible con OpenAI ahora maneja la clave singular "embedding" (vector plano) de Ollama, además de las formas de respuesta existentes "data"/"embeddings".

Lanzador .env.local Generación automática

start_web.py y start_tour.py ahora escriben web/.env.local con el puerto de backend resuelto, por lo que el frontend selecciona el NEXT_PUBLIC_API_BASE correcto incluso cuando se inicia de forma independiente a través de npm run dev.

Expansión del conjunto de pruebas

Se agregaron 11 nuevos módulos de prueba que cubren UnifiedContext, StreamBus, ChatOrchestrator, ContextBuilder, TurnRuntime, RAGTool, WebSearch, CircuitBreaker, JSONParser, EmbeddingExtraction y un conftest.py compartido con accesorios comunes.

Corrección del retraso de entrada

Se resolvió un retraso grave en las pulsaciones de teclas en conversaciones largas virtualizando la representación de la lista de mensajes y eliminando el rebote de las actualizaciones de posición de desplazamiento.

DeepTutor v1.1.0-beta

DeepTutor v1.1.0-beta Release Notes

Release Date: 2026.04.14

Highlights

URL-based Chat Routing

Migrated the chat experience from query-parameter session IDs (/?session=xxx) to a dedicated /chat/[[...sessionId]] catch-all route. The root page now redirects to /chat, and session loading is driven entirely by the URL path — no more sessionStorage restore on mount. Sidebar navigation, new-chat, and session-select flows all point to /chat or /chat/<id>, making sessions bookmarkable and shareable.

Snow Theme

Added a new Snow theme — a clean, pure-white palette with slate-blue accents and subtle warm primary tones. The theme cycle is now snow → light → dark → glass. The ThemeScript, settings page, i18n keys, and CSS variables all include the new option.

WebSocket Heartbeat & Auto-Reconnect

The UnifiedWSClient now sends a client-side heartbeat ping every 30 seconds and treats 45 seconds of silence as a dead connection. On unexpected disconnection, the client retries with exponential backoff (200 ms base, up to 5 attempts) and sends a resume_from message with the last turn_id / seq so the server can replay missed events.

Streaming Idle Timeout

UnifiedChatContext runs a background timer that detects streaming sessions with no incoming events for 60 seconds. Stale sessions are automatically failed with a user-visible timeout error and their WebSocket runners are cleaned up.

ChatComposer Performance Optimization

Wrapped ChatComposer in React.memo and internalized input, showAtPopup, and textareaRef state. The textarea value and auto-resize layout effect no longer trigger parent re-renders, eliminating severe input lag in long conversations.

Embedding Provider Registry Overhaul

Replaced the flat EMBEDDING_PROVIDER_DEFAULTS dictionary with a typed EmbeddingProviderSpec dataclass carrying label, default_api_base, adapter, default_model, and default_dim. The settings API now returns a dedicated embedding provider dropdown (separate from the LLM list), and selecting a provider auto-fills the default embedding dimension.

Serper Search Provider

Restored Serper as a first-class search provider (previously deprecated). Added SERPER_API_KEY env fallback, registered the provider module, and updated all deprecation messages.

Deep Research Reporting Resilience

Section writing in the reporting agent now falls back to raw LLM output when JSON parsing fails, instead of aborting the entire report. The fallback strips JSON wrappers from the response and logs a warning.

Markdown Renderer Code Block Fix

Fixed inline vs. block code detection in SimpleMarkdownRenderer. Multi-line content now renders inside a styled <pre> block, while single-line code renders as an inline <code> element — resolving cases where inline backticks produced full code blocks.

Ollama Embedding Response Support

The OpenAI-compatible embedding adapter now handles Ollama's singular "embedding" key (flat vector), in addition to the existing "data" / "embeddings" response shapes.

Launcher .env.local Auto-Generation

start_web.py and start_tour.py now write web/.env.local with the resolved backend port, so the frontend picks up the correct NEXT_PUBLIC_API_BASE even when started independently via npm run dev.

Test Suite Expansion

Added 11 new test modules covering UnifiedContext, StreamBus, ChatOrchestrator, ContextBuilder, TurnRuntime, RAGTool, WebSearch, CircuitBreaker, JSONParser, EmbeddingExtraction, and a shared conftest.py with common fixtures.

Input Lag Fix

Resolved severe keystroke lag in long conversations by virtualizing the message list rendering and debouncing scroll-position updates.
