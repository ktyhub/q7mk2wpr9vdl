#DeepTutor v1.6.0

DeepTutor v1.6.0 Release Note

Fecha de lanzamiento: 2026.08.27 v1.5.17 hizo que los socios fueran personales y permitió que las bases de conocimiento rastrearan GitHub. v1.6.0 conecta el resto del espacio de trabajo de aprendizaje: lectura fiel a la fuente, cursos y subprocesos de Little Tutor, un modo de hacer preguntas, sincronización de fuente web limitada y libros compartidos sin compartir el estado de aprendizaje del lector. Los datos existentes permanecen vigentes; Los administradores multiusuario solo necesitan otorgar acceso al Libro donde lo deseen.

¿Qué hay de nuevo?

La lectura inmersiva se convierte en un lector completo

EPUB se une a PDF en una vista fiel a la fuente, con esquemas que reconocen el formato y posición de lectura guardada. Los selectores de texto del W3C mantienen los aspectos destacados adjuntos mediante reflujo, Recogito genera anotaciones, las vistas de texto extraído obtienen controles de color y tipografía persistentes, y las extensiones de lectura instaladas reciben solo texto visible verificado o selecciones a través de un protocolo limitado.

Cursos, pequeño tutor y preguntas

Learning Space ahora organiza las conversaciones en Cursos, con controles de anclar, archivar, mover, filtrar y de hilos de tutor anidados. Seleccione texto en una conversación para abrir un hilo de Little Tutor independiente y basado en fuentes que permanece bajo su padre y hereda el curso. Hacer preguntas comienza con una tarjeta de aclaración contextual y luego completa la solicitud original a partir de las respuestas.

Bases de conocimiento rastrean sitios de documentación

Además de los repositorios GitHub, una base de conocimiento puede registrar una URL de documentación con límites explícitos de profundidad de rastreo y recuento de páginas. Las diferencias de hash de sincronización bajo demanda agregaron, cambiaron y eliminaron páginas antes de volver a indexarlas. Serply agrega modos de búsqueda web, de noticias y académicos, mientras que los modelos compatibles de OpenAI Responses pueden usar su búsqueda web nativa del lado del servidor.

Los libros compartidos mantienen el aprendizaje en privado

Los administradores pueden compartir libros canónicos por usuario como none, read o colaborativo edit, controlar por separado la creación de libros personales y mantener la eliminación solo para administradores. El progreso, los marcadores, los intentos de cuestionarios, los enlaces de Page Chat y la bandeja de entrada revisable de Learning Capture permanecen privados para el lector. Las ediciones compartidas utilizan comprobaciones de revisión para que un editor obsoleto se actualice en lugar de sobrescribir a un colaborador.

Lectura, tutoría y confiabilidad de sesiones largas

Los esquemas del lector y la navegación secuencial mantienen su lugar, las extensiones de lectura con formato incorrecto o con tiempo de espera agotado permanecen aisladas y los anclajes de anotación sobreviven a los encabezados y se redistribuyen. La base de datos del tutor de selección y los seguimientos de las pruebas siguen siendo duraderos; Mastery rechaza las alternativas de los cuestionarios de texto plano y distingue la aclaración de una respuesta; la compactación de conversaciones se mantiene dentro de los presupuestos limitados y los controles Unicode invisibles decodificados ya no se filtran en la pantalla.

Fortalecimiento de proveedores y plataformas

llama.cpp informa su ventana de contexto real, los modelos de codificación Kimi reciben parámetros compatibles, LightRAG preserva el contexto de incrustación asimétrico y las fallas de Codex TLS permanecen cerradas. La compatibilidad del ejecutor, la herramienta, la ruta y las pruebas de Windows recibió una amplia limpieza. Los flujos de trabajo de lanzamiento ahora rechazan etiquetas engañosas o que no sean de versión antes de que puedan desplazar la última versión estable.

Notas de actualización

pip install -U deeptutor; Los usuarios de Docker extraen ghcr.io/hkuds/deeptutor:latest. No se requiere migración manual ni reindexación.

  • Los libros de administración compartidos no tienen acceso por defecto. Los libros personales existentes permanecen privados y sin cambios. En una implementación multiusuario, abra /admin/users, expanda un usuario y configure Acceso a libros solo para los libros administradores que deben leer o editar.
  • Las ediciones compartidas son optimistas. Si otro editor avanza primero una revisión del libro, actualice el libro y aplique el cambio nuevamente; DeepTutor no sobrescribirá silenciosamente la revisión más reciente.
  • Las fuentes web y GitHub siguen siendo voluntarias. Las bases de conocimiento existentes no cambian hasta que registre una fuente y ejecute la sincronización.
  • La búsqueda sigue siendo opcional. Seleccione Serply durante deeptutor init o configúrelo más tarde en Configuración → Modelos → Buscar; La configuración de búsqueda existente continúa funcionando.
  • Las guías en inglés y chino se actualizaron juntas en deeptutor.info. Changelog completo: https://github.com/HKUDS/DeepTutor/compare/v1.5.17...v1.6.0

DeepTutor v1.6.0

Highlights

  • Source-faithful EPUB reader — EPUB now joins PDF with format-aware outlines, saved reading positions, W3C text-selector highlights that survive reflow, and Recogito annotations. Extracted-text views retain typography and colour controls, while Reading extensions receive only verified visible text or selections through a bounded protocol.

  • Course-scoped tutoring — Courses add pin, archive, move, filter, and nested tutor-thread controls to Learning Space. Selecting text opens an independent, source-grounded Little Tutor thread that inherits its course; Ask Questions gathers clarifications before completing the original request.

  • Bounded documentation sync — Knowledge bases can register documentation URLs with explicit crawl-depth and page-count limits. On-demand sync hash-diffs added, changed, and removed pages before re-indexing, avoiding unnecessary work. Serply adds web, news, and scholar search, while compatible OpenAI Responses models can use native server-side web search.

  • Private, collaborative Books — Admins can grant canonical Books per user as none, read, or edit, control personal Book creation, and reserve deletion for admins; learning state remains private per reader. Shared admin Books default to no access, so configure Book access under /admin/users. Optimistic revision checks make stale editors refresh instead of overwriting collaborators.

  • Behavioral and provider hardening — Mastery rejects plain-text quiz fallbacks and distinguishes clarification from answers; conversation compaction stays within bounded budgets, and invisible Unicode controls are sanitized. Provider fixes report llama.cpp’s real context window, preserve LightRAG’s asymmetric embedding context, pass compatible Kimi parameters, and keep Codex TLS failures fail-closed.

  • Upgrade — No breaking changes or manual migrations: run pip install -U deeptutor or pull ghcr.io/hkuds/deeptutor:latest; no re-index is required.

DeepTutor v1.6.0 Release Notes

Release Date: 2026.08.27

v1.5.17 made Partners personal and let knowledge bases track GitHub. v1.6.0 connects the rest of the learning workspace: source-faithful reading, Courses and Little Tutor threads, an Ask Questions mode, bounded web-source sync, and Books shared without sharing a reader's learning state. Existing data stays in place; multi-user admins only need to grant Book access where wanted.

What's New

Immersive Reading becomes a full reader

EPUB joins PDF in a source-faithful view, with format-aware outlines and saved reading position. W3C text selectors keep highlights attached through reflow, Recogito renders annotations, extracted-text views gain persistent typography and colour controls, and installed Reading extensions receive only verified visible text or selections through a bounded protocol.

Courses, Little Tutor, and Ask Questions

Learning Space now organizes conversations into Courses, with pin, archive, move, filter, and nested tutor-thread controls. Select text in a conversation to open an independent, source-grounded Little Tutor thread that stays under its parent and inherits the course. Ask Questions starts with a context-aware clarification card, then completes the original request from the answers.

Knowledge bases track documentation sites

Alongside GitHub repositories, a KB can register a documentation URL with explicit crawl-depth and page-count bounds. On-demand sync hash-diffs added, changed, and removed pages before re-indexing. Serply adds web, news, and scholar search modes, while compatible OpenAI Responses models can use their native server-side web search.

Shared Books keep learning private

Admins can share canonical Books per user as none, read, or collaborative edit, separately control personal Book creation, and keep deletion admin-only. Progress, bookmarks, quiz attempts, Page Chat links, and the reviewable Learning Capture inbox stay private per reader. Shared edits use revision checks so a stale editor refreshes instead of overwriting a collaborator.

Reading, tutoring, and long-session reliability

Reader outlines and sequential navigation keep their place, malformed or timed-out Reading extensions stay isolated, and annotation anchors survive headings and reflow. Selection Tutor grounding and quiz follow-ups remain durable; Mastery rejects plain-text quiz fallbacks and distinguishes clarification from an answer; conversation compaction stays within bounded budgets and decoded invisible Unicode controls no longer leak into display.

Provider and platform hardening

llama.cpp reports its real context window, Kimi coding models receive compatible parameters, LightRAG preserves asymmetric embedding context, and Codex TLS failures remain fail-closed. Windows runner, tool, path, and test compatibility received a broad cleanup. Release workflows now reject misleading or non-version tags before they can displace the latest stable release.

Upgrade Notes

pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest. No manual migration or re-index is required.

  • Shared admin Books default to no access. Existing personal Books remain private and unchanged. In a multi-user deployment, open /admin/users, expand a user, and configure Book access only for the admin Books they should read or edit.
  • Shared edits are optimistic. If another editor advances a Book revision first, refresh the Book and apply the change again; DeepTutor will not silently overwrite the newer revision.
  • Web and GitHub sources remain opt-in. Existing knowledge bases are unchanged until you register a source and run sync.
  • Search remains optional. Select Serply during deeptutor init or configure it later under Settings → Models → Search; existing search settings continue to work.
  • The English and Chinese guides have been updated together at deeptutor.info.
