angular v22.0.6

Highlights

  • Signal diagnostics — Required signal queries now receive the debugName transform, while template checking detects uninvoked signals inside ternary-bound expressions. This improves query identification and catches missed signal calls that could previously slip through type checking.
  • Template type-checking accuracy — Generated TCBs now use standard optional chaining for safe function calls, better matching JavaScript semantics for conditionally available callables and reducing diagnostic inconsistencies in templates that use them.
  • Reactive forms compatibility — extractValue is now reactive for compatible AbstractControl values. Signal forms integrations wrapping legacy controls should therefore track value changes instead of potentially returning stale reactive reads.
  • Migration reliability — NgModule pruning now preserves transitive references, reducing the chance that automated migrations remove indirectly required modules. The model/output migration also removes stale model imports; review generated diffs before committing.
  • Router map hardening — Outlets named __proto__ are handled safely in segment-group maps, and query-parameter parsing now checks own properties. This prevents prototype-key edge cases from interfering with outlet resolution or query parsing.
  • Compatibility — No breaking changes.
