open_clip v4.2.2

La primera versión 4.x en PyPI y agrega modelos de audio-texto oficiales preentrenados NaFlex CLAP. También traslada la formación a una nueva pila y agrega varias familias de modelos. Los números de versión anteriores 4.x eran solo versiones de desarrollo. Se pretende que la inferencia de imagen y texto previamente entrenada siga siendo compatible, pero es necesario revisar los scripts de capacitación y las integraciones posteriores. Consulte la guía de migración. Para permanecer en 3.x, ejecute pip install 'open_clip_torch<4'.

Destacados

  • NaFlex CLAP: cinco modelos de audio-texto Apache 2.0 (parámetros de 27M a 340M) que toman audio de longitud variable, entrenados en LAION-Audio-XL: XXS, XS, S, M, L
  • NaFlex CLIP: torres de imágenes de resolución y aspecto variables con procesamiento por lotes de presupuesto simbólico
  • NaFlex GenLIP / GenLAP: subtítulos de imagen y audio generativos con atención de prefijo LM (configuraciones de entrenamiento, aún no hay pesos previamente entrenados)
  • Torres de texto modernas: opciones RoPE, SwiGLU/ReLU² y RMSNorm, texto de longitud variable por lote y torres Hugging Face ModernBERT
  • MaMMUT y CoCa v2: MaMMUT con los pesos LAION publicados, además de configuraciones coca2_* corregidas
  • Pila de entrenamiento: contenedores TrainingTask, lotes basados en dict, estrategias FSDP2 (--fsdp), torch.compile y agrupamiento de longitud
  • Carga de puntos de control más segura: todas las cargas de puntos de control usan weights_only=True y los pesos OpenAI ahora se cargan desde Hugging Face Hub en lugar de archivos JIT

Notas de actualización

  • PyPI ahora requiere torch>=2.6 (antes >=2.0)
  • El --precision predeterminado ahora es amp_bf16 (antes amp), y el --loss-dist-impl de SigLIP ahora es gather por defecto.
  • Se eliminan --horovod, --torchscript y --trace.
  • Se eliminan load_openai_model, list_openai_models, build_model_from_openai_state_dict y trace_model; usar create_model_from_pretrained(..., pretrained='openai') para pesas OpenAI
  • Los cargadores de datos ahora emiten lotes de dictados y el código de entrenamiento debe pasar un TrainingTask en lugar de un modelo y pérdida separados.
  • python -m open_clip_train.legacy_main sigue estando disponible como ruta de compatibilidad para scripts de entrenamiento de imagen y texto más antiguos. Consulte la guía de migración para obtener la lista completa de cambios.

open_clip v4.2.2

The first 4.x release on PyPI, and it adds official pretrained NaFlex CLAP audio-text models. It also moves training to a new stack and adds several model families. Earlier 4.x version numbers were development versions only.

Pretrained image-text inference is intended to remain compatible, but training scripts and downstream integrations need review. See the migration guide. To stay on 3.x, run pip install 'open_clip_torch<4'.

Highlights

  • NaFlex CLAP: five Apache 2.0 audio-text models (27M to 340M parameters) that take variable-length audio, trained on LAION-Audio-XL: XXS, XS, S, M, L
  • NaFlex CLIP: variable-resolution and variable-aspect image towers with token-budget batching
  • NaFlex GenLIP / GenLAP: generative image and audio captioning with prefix-LM attention (training configs, no pretrained weights yet)
  • Modern text towers: RoPE, SwiGLU/ReLU², and RMSNorm options, per-batch variable-length text, and Hugging Face ModernBERT towers
  • MaMMUT and CoCa v2: MaMMUT with the released LAION weights, plus corrected coca2_* configs
  • Training stack: TrainingTask wrappers, dict-based batches, FSDP2 (--fsdp), torch.compile strategies, and length bucketing
  • Safer checkpoint loading: all checkpoint loads use weights_only=True, and OpenAI weights now load from the Hugging Face Hub instead of JIT archives

Upgrade notes

  • PyPI now requires torch>=2.6 (was >=2.0)
  • The default --precision is now amp_bf16 (was amp), and SigLIP's --loss-dist-impl now defaults to gather
  • --horovod, --torchscript, and --trace are removed
  • load_openai_model, list_openai_models, build_model_from_openai_state_dict, and trace_model are removed; use create_model_from_pretrained(..., pretrained='openai') for OpenAI weights
  • Dataloaders now emit dict batches, and training code should pass a TrainingTask instead of a separate model and loss
  • python -m open_clip_train.legacy_main remains available as a compatibility path for older image-text training scripts

See the migration guide for the full list of changes.
