#v2.8.0

¡Firecrawl v2.8.0 ya está aquí!

Firecrawl v2.8.0 aporta importantes mejoras a los flujos de trabajo de los agentes, las herramientas de desarrollo y las implementaciones autohospedadas en los API y SDK, incluida nuestra nueva habilidad.

  • Agentes paralelos para ejecutar miles de consultas /agent simultáneamente, impulsados ​​por nuestro nuevo modelo Spark 1 Fast.
  • Firecrawl CLI con soporte completo para comandos de raspado, búsqueda, rastreo y mapas.
  • Habilidad Firecrawl para permitir que los agentes de IA (Claude Code, Codex, OpenCode) utilicen Firecrawl de forma autónoma.
  • Tres nuevos modelos impulsan /agent: Spark 1 Fast para recuperación instantánea (actualmente solo disponible en Playground), Spark 1 Mini para consultas de investigación complejas y Spark 1 Pro para tareas de extracción avanzadas.
  • Mejoras de agentes que incluyen webhooks, selección de modelos y nuevas herramientas de servidor MCP.
  • Mejoras de rendimiento en toda la plataforma, incluida una ejecución de búsqueda más rápida y llamadas Redis optimizadas.
  • Mejoras en SDK, incluida la compatibilidad con Zod v4.

Y mucho más, ¡compruébalo a continuación!

Nuevas características

  • Agentes paralelos
    Ejecute miles de consultas /agent en paralelo con manejo automático de fallas y ejecución inteligente en cascada. Desarrollado por Spark 1-Fast para recuperación instantánea, actualizándose automáticamente a Spark 1 Mini para consultas complejas que requieren una investigación completa.

  • Ruta de fuego CLI
    Nueva interfaz de línea de comandos para Firecrawl con soporte completo para comandos de raspado, búsqueda, rastreo y mapas. Instalar con npm install -g firecrawl-cli.

  • Habilidad de rastreo de fuego
    Permite que agentes como Claude Cursor, Codex y OpenCode utilicen Firecrawl para scraping web y extracción de datos, instalable mediante npx skills add firecrawl/cli.

  • Familia de modelos Spark
    Tres nuevos modelos impulsan /agent: Spark 1 Fast para recuperación instantánea (actualmente disponible en Playground), Spark 1 Mini (predeterminado) para tareas de extracción diarias a un costo 60% menor y Spark 1 Pro para investigaciones complejas de múltiples dominios que requieren máxima precisión. Spark 1 Pro logra una recuperación de ~50 % mientras que Mini ofrece una recuperación de ~40 %; ambas herramientas superan significativamente a las herramientas que cuestan entre 4 y 7 veces más por tarea.

  • Herramientas del agente del servidor Firecrawl MCP
    Nuevas herramientas firecrawl_agent y firecrawl_agent_status para la recopilación autónoma de datos web a través de agentes habilitados para MCP.

  • Webhooks del agente
    El punto final del agente ahora admite webhooks para notificaciones en tiempo real sobre la finalización y el progreso del trabajo.

  • Selección de modelo de agente
    El punto final del agente ahora acepta un parámetro model e incluye información del modelo en las respuestas de estado.

  • Imágenes Docker de múltiples arcos
    Las implementaciones autohospedadas ahora admiten la arquitectura linux/arm64 además de amd64.

  • Modo de rastreo solo para mapas del sitio
    Nueva opción de rastreo para utilizar exclusivamente las URL del mapa del sitio sin seguir enlaces.

  • Parámetro de mapa ignoreCache
    Nueva opción para omitir los resultados almacenados en caché al asignar URL.

  • Encabezados personalizados para /map
    El punto final del mapa ahora admite encabezados de solicitud personalizados.

  • Extracción de imágenes de fondo
    Scraper ahora extrae imágenes de fondo de estilos CSS.

  • Mensajes de error mejorados
    Todos los mensajes de error de cara al usuario ahora incluyen explicaciones detalladas para ayudar a diagnosticar problemas.

API Mejoras

  • Búsqueda sin límites de simultaneidad: los scraps en la búsqueda ahora se ejecutan directamente sin sobrecarga de cola.
  • Devuelve 400 para acciones no admitidas con errores claros cuando las acciones solicitadas no son compatibles con los motores disponibles.
  • La identificación del trabajo ahora se incluye en los metadatos de búsqueda para facilitar el seguimiento.
  • Las respuestas de metadatos ahora incluyen la zona horaria detectada.
  • Rellene el título de los metadatos de og:title o twitter:title cuando falte.
  • Conserve el parámetro gid al reescribir las URL de Google Sheets.
  • Se corrigió la ruta v2 en la paginación del estado de raspado por lotes.
  • Validar la propiedad del equipo al agregarlo a rastreos existentes.
  • Las capturas de pantalla con ventana gráfica personalizada o configuración de calidad ahora omiten el caché.
  • Llamadas Redis optimizadas en todos los puntos finales.
  • Se redujo la búsqueda y el análisis excesivos de robots.txt.
  • El parámetro de tiempo de espera mínimo de solicitud ahora es configurable.

SDK Mejoras

JavaScript SDK

  • Compatibilidad con Zod v4: la conversión de esquemas ahora funciona con Zod v4 con detección de errores mejorada.
  • Exportaciones de Watcher: Watcher y WatcherOptions ahora se exportan desde el punto de entrada SDK.
  • Soporte de webhook para agentes: nuevas opciones de webhook para llamadas de agentes.
  • Error de reintento de sondeo: SDK vuelve a intentar el sondeo después de errores transitorios.
  • ID de trabajo en Excepciones: las excepciones de error ahora incluyen jobId para la depuración.

Python SDK

  • Ayudantes de paginación manual para iterar los resultados.
  • Se agregó soporte de webhook para agentes al agente client.
  • El punto final del agente ahora acepta el parámetro de selección de modelo.
  • Los metadatos ahora incluyen información sobre el límite de simultaneidad.
  • Se corrigió el manejo de max_pages en solicitudes de rastreo.

Mejoras en el panel

  • Ahora se admite el modo oscuro.
  • En la página de uso, ahora puedes ver el uso de crédito desglosado por día.
  • En la página de registros de actividad, ahora puede filtrar por la clave API que se utilizó.
  • El formato de salida "imágenes" ahora es compatible con Playground.
  • Todos los administradores ahora pueden administrar las suscripciones de su equipo.

Calidad y rendimiento

  • Omita las comprobaciones de conversión de rebajas para documentos HTML grandes.
  • Exporte Google Docs como HTML en lugar de PDF para mejorar el rendimiento.
  • Formato de marca mejorado con mejor detección de logotipos y mensajes de error para archivos PDF y documentos.
  • Rendimiento de carga de metadatos mejorado de lopdf.
  • Módulo html-to-markdown actualizado con múltiples correcciones de errores.
  • Aumento del límite del cuerpo del servicio de rebajas y registro de ID de solicitud agregado.
  • Mejor filtrado de Sentry para trabajos cancelados y errores del motor.
  • Se corrigieron las condiciones de carrera del extracto y el manejo de la píldora venenosa RabbitMQ.
  • Configuración centralizada de Firecrawl en todo el código base.
  • Múltiples correcciones de vulnerabilidades de seguridad, incluidas CVE-2025-59466 y contaminación del prototipo lodash.

Mejoras autohospedadas

  • Soporte de URL API personalizado de CLI a través de firecrawl --api-url http://localhost:3002 para instancias locales.
  • Compatibilidad con ARM64 Docker a través de imágenes de múltiples arcos para servidores Apple Silicon y ARM.
  • Se corrigieron las credenciales de la base de datos docker-compose listas para usar.
  • Se corrigió el inicio del servicio Playwright causado por problemas de ruta de Chromium.
  • Actualizado Node.js a la versión principal 22 en lugar de una menor fijada.
  • Se agregó el punto final de verificación de estado de RabbitMQ.
  • Se corrigió la exposición del puerto PostgreSQL en docker-compose.

firecrawl v2.8.0

v2.8.0

Firecrawl v2.8.0 is here!

Firecrawl v2.8.0 brings major improvements to agent workflows, developer tooling, and self-hosted deployments across the API and SDKs, including our new Skill.

  • Parallel Agents for running thousands of /agent queries simultaneously, powered by our new Spark 1 Fast model.
  • Firecrawl CLI with full support for scrape, search, crawl, and map commands.
  • Firecrawl Skill for enabling AI agents (Claude Code, Codex, OpenCode) to use Firecrawl autonomously.
  • Three new models powering /agent: Spark 1 Fast for instant retrieval (currently only available in Playground), Spark 1 Mini for complex research queries, and Spark 1 Pro for advanced extraction tasks.
  • Agent enhancements including webhooks, model selection, and new MCP Server tools.
  • Platform-wide performance improvements including faster search execution and optimized Redis calls.
  • SDK improvements including Zod v4 compatibility.

And much more, check it out below!

New Features

  • Parallel Agents
    Execute thousands of /agent queries in parallel with automatic failure handling and intelligent waterfall execution. Powered by Spark 1-Fast for instant retrieval, automatically upgrading to Spark 1 Mini for complex queries requiring full research.

  • Firecrawl CLI
    New command-line interface for Firecrawl with full support for scrape, search, crawl, and map commands. Install with npm install -g firecrawl-cli.

  • Firecrawl Skill
    Enables agents like Claude Cursor, Codex, and OpenCode to use Firecrawl for web scraping and data extraction, installable via npx skills add firecrawl/cli.

  • Spark Model Family
    Three new models powering /agent: Spark 1 Fast for instant retrieval (currently available in Playground), Spark 1 Mini (default) for everyday extraction tasks at 60% lower cost, and Spark 1 Pro for complex multi-domain research requiring maximum accuracy. Spark 1 Pro achieves ~50% recall while Mini delivers ~40% recall, both significantly outperforming tools costing 4-7x more per task.

  • Firecrawl MCP Server Agent Tools
    New firecrawl_agent and firecrawl_agent_status tools for autonomous web data gathering via MCP-enabled agents.

  • Agent Webhooks
    Agent endpoint now supports webhooks for real-time notifications on job completion and progress.

  • Agent Model Selection
    Agent endpoint now accepts a model parameter and includes model info in status responses.

  • Multi-Arch Docker Images
    Self-hosted deployments now support linux/arm64 architecture in addition to amd64.

  • Sitemap-Only Crawl Mode
    New crawl option to exclusively use sitemap URLs without following links.

  • ignoreCache Map Parameter
    New option to bypass cached results when mapping URLs.

  • Custom Headers for /map
    Map endpoint now supports custom request headers.

  • Background Image Extraction
    Scraper now extracts background images from CSS styles.

  • Improved Error Messages
    All user-facing error messages now include detailed explanations to help diagnose issues.

API Improvements

  • Search without concurrency limits — scrapes in search now execute directly without queue overhead.
  • Return 400 for unsupported actions with clear errors when requested actions aren't supported by available engines.
  • Job ID now included in search metadata for easier tracking.
  • Metadata responses now include detected timezone.
  • Backfill metadata title from og:title or twitter:title when missing.
  • Preserve gid parameter when rewriting Google Sheets URLs.
  • Fixed v2 path in batch scrape status pagination.
  • Validate team ownership when appending to existing crawls.
  • Screenshots with custom viewport or quality settings now bypass cache.
  • Optimized Redis calls across endpoints.
  • Reduced excessive robots.txt fetching and parsing.
  • Minimum request timeout parameter now configurable.

SDK Improvements

JavaScript SDK

  • Zod v4 Compatibility — schema conversion now works with Zod v4 with improved error detection.
  • Watcher Exports — Watcher and WatcherOptions now exported from the SDK entrypoint.
  • Agent Webhook Support — new webhook options for agent calls.
  • Error Retry Polling — SDK retries polling after transient errors.
  • Job ID in Exceptions — error exceptions now include jobId for debugging.

Python SDK

  • Manual pagination helpers for iterating through results.
  • Agent webhook support added to agent client.
  • Agent endpoint now accepts model selection parameter.
  • Metadata now includes concurrency limit information.
  • Fixed max_pages handling in crawl requests.

Dashboard Improvements

  • Dark mode is now supported.
  • On the usage page, you can now view credit usage broken down by day.
  • On the activity logs page, you can now filter by the API key that was used.
  • The "images" output format is now supported in the Playground.
  • All admins can now manage their team's subscriptions.

Quality & Performance

  • Skip markdown conversion checks for large HTML documents.
  • Export Google Docs as HTML instead of PDF for improved performance.
  • Improved branding format with better logo detection and error messages for PDFs and documents.
  • Improved lopdf metadata loading performance.
  • Updated html-to-markdown module with multiple bug fixes.
  • Increased markdown service body limit and added request ID logging.
  • Better Sentry filtering for cancelled jobs and engine errors.
  • Fixed extract race conditions and RabbitMQ poison pill handling.
  • Centralized Firecrawl configuration across the codebase.
  • Multiple security vulnerability fixes, including CVE-2025-59466 and lodash prototype pollution.

Self-Hosted Improvements

  • CLI custom API URL support via firecrawl --api-url http://localhost:3002 for local instances.
  • ARM64 Docker support via multi-arch images for Apple Silicon and ARM servers.
  • Fixed docker-compose database credentials out of the box.
  • Fixed Playwright service startup caused by Chromium path issues.
  • Updated Node.js to major version 22 instead of a pinned minor.
  • Added RabbitMQ health check endpoint.
  • Fixed PostgreSQL port exposure in docker-compose.
