🌐 Inglés | 中文

🖥 Escritorio Client

Presentamos CowAgent Desktop client para macOS y Windows: su súper asistente de IA local, realmente listo para usar desde el primer momento.

Descargar: Escritorio CowAgent

<img width="750" src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/desktop-chat-demo-en.png" alt="CowAgent Desktop client" />

Aspectos destacados:

  • Listo para usar: se incluye el tiempo de ejecución completo del Agente: se inicia inmediatamente después de la instalación, no es necesario configurar Python u otras dependencias.
  • Experiencia de chat completa: transmisión de respuestas, gestión de sesiones, visualización de pasos de llamada de herramientas, renderizado Markdown, además de envío y vista previa de imágenes/vídeos/archivos.
  • Gestión visual: la configuración, los modelos, la base de conocimientos, las tareas programadas, las habilidades y las páginas de memoria reflejan la consola web, todo gestionable en la interfaz de usuario nativa.
  • Incorporación de canales: conecta canales de mensajería escaneando un código QR directamente dentro de la aplicación
  • Actualización automática: comprobaciones automáticas de versiones y actualizaciones one-click, con velocidad de descarga optimizada en todas las regiones
  • Experiencia nativa: incorporación de primera ejecución, seguimiento del idioma del sistema e interacciones de ventana adaptables a la plataforma

📚 Base de conocimientos

  • Crear e importar documentos: cree nuevos documentos o importe documentos externos directamente desde la interfaz de usuario
  • Mantenimiento automático del índice: el índice de la base de conocimientos se reconstruye automáticamente a partir del árbol de directorios real, lo que evita la deriva del índice o la pérdida de documentos.
  • Solución de vectorización: el índice ahora reutiliza el proveedor de incrustación unificado, lo que garantiza vectores semánticos reales en lugar de recurrir a la búsqueda de palabras clave.

Gracias @yangziyu-hhh

Documentos: Base de conocimientos

🔌 Recuperación de herramientas MCP bajo demanda

Para abordar la sobrecarga de contexto cuando hay muchas herramientas MCP conectadas, agregamos recuperación de herramientas bajo demanda: las herramientas MCP relevantes se cargan bajo demanda a través de la búsqueda de vectores RAG según la tarea actual, lo que reduce el contexto ocupado por herramientas irrelevantes.

Gracias @fengyl07

Documentos: Herramientas MCP

🌏 Soporte chino tradicional

La consola web, los registros y la documentación ahora admiten chino tradicional (zh-Hant); El idioma de la interfaz puede seguir el sistema o cambiarse manualmente.

Gracias @anomixer (#2935)

🤖 Nuevos Modelos

  • Se agregó soporte para claude-sonnet-5 y claude-fable-5
  • Se agregó soporte para doubao-seed-2-1-pro y doubao-seed-2-1-turbo

Documentos: Modelos

🔒 Refuerzo de la seguridad

  • Protección de lectura de archivos confidenciales: acceso reforzado a credenciales y otros archivos confidenciales para evitar lecturas omitidas. Gracias @fengyl07 (#2936)
  • Protección de acceso al navegador: bloquea las solicitudes del navegador dirigidas a la red interna y a los puntos finales internos del servidor en la nube, lo que reduce el riesgo de ser engañado para llegar a los servicios internos. Gracias @Jiangrong-W
  • Análisis de configuración más seguro: el contenido de la configuración se analiza de una manera más segura para evitar posibles riesgos de ejecución de código. Gracias @shunfeng8421

🛠 Mejoras y correcciones

  • Soporte de proveedor personalizado: los modelos de visión e incrustación ahora pueden utilizar proveedores personalizados; También solucionó un problema de consulta de memoria en Windows. Gracias @HnBigVolibear
  • Edición de archivos más confiable: conserva mejor la sangría original y la coincidencia aproximada ya no toca contenido no relacionado. Gracias @weijun-xia (#2942)
  • Corrección de codificación de salida de comando: se corrigieron caracteres chinos confusos cuando un comando produce una salida grande. Gracias @weijun-xia (#2941)
  • Correcciones de Azure OpenAI: salida de transmisión fija y problemas de configuración relacionados para Azure OpenAI. Gracias @Tunello
  • WeCom Smart Bot: se agregaron documentos de canal para el modo webhook (devolución de llamada). Gracias @6vision
  • Alternar Deep Dream: se agregó un interruptor deep_dream_enabled dedicado para habilitar o deshabilitar la destilación de Deep Dream de forma independiente.
  • Estabilidad: conexión mejorada recycling en el servicio web y se solucionaron varios problemas de autoevolución (#2924 Gracias @santipongth, #2904 Gracias @YLChen-007)

📦 Cómo actualizar

  • Escritorio client: obtenga la última versión desde la página de descargas.
  • Implementación de origen: ejecute cow update para una actualización de un click, o extraiga el código más reciente y reinicie. Consulte la guía de actualización.

CowAgent 2.1.3

Highlights

  • Native desktop app — macOS and Windows builds bundle the full Agent runtime, eliminating Python and dependency setup for desktop users. Streaming chat, tool-step visibility, media previews, native management pages, QR channel onboarding, and auto-update make local deployment substantially easier. Source installs can upgrade with cow update or by pulling and restarting.
  • Retrieval and knowledge-base correctness — MCP tools are now loaded per task through RAG vector search instead of consuming context upfront; validate retrieval coverage for critical tools. Knowledge indexes rebuild from the actual directory tree and use the unified embedding provider, preventing drift and silent fallbacks to keyword search.
  • Security hardening (#2936) — Sensitive-file checks close credential-read bypasses, safer config parsing reduces code-execution risk, and browser requests to internal or cloud-internal endpoints are blocked. Workflows that intentionally browse private network services may need adjustment.
  • Model and provider support — Adds claude-sonnet-5, claude-fable-5, doubao-seed-2-1-pro, and doubao-seed-2-1-turbo. Custom embedding/vision providers and Azure OpenAI streaming/configuration fixes expand routing options and reduce provider-specific integration friction.
  • Automation and localization fixes — File edits preserve indentation and constrain fuzzy matching to avoid collateral changes (#2942); large Chinese command output no longer garbles (#2941), and Windows memory queries are fixed. The Web console, logs, and documentation also add Traditional Chinese (zh-Hant) support (#2935).
  • Breaking changes — None announced.

🌐 English | 中文

🖥 Desktop Client

Introducing the CowAgent Desktop client for macOS and Windows — your local super AI assistant, truly ready to use out of the box.

Download: CowAgent Desktop

<img width="750" src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/desktop-chat-demo-en.png" alt="CowAgent Desktop client" />

Highlights:

  • Out of the box: the full Agent runtime is bundled — launch right after install, no need to set up Python or other dependencies
  • Full chat experience: streaming replies, session management, tool-call step display, Markdown rendering, plus sending and previewing images / videos / files
  • Visual management: configuration, models, knowledge base, scheduled tasks, skills, and memory pages mirror the Web console, all manageable in the native UI
  • Channel onboarding: connect messaging channels by scanning a QR code right inside the app
  • Auto update: automatic version checks and one-click updates, with download speed optimized across regions
  • Native experience: first-run onboarding, follows the system language, and platform-adaptive window interactions

📚 Knowledge Base

  • Create & import documents: create new documents or import external ones directly from the UI
  • Automatic index maintenance: the knowledge base index is rebuilt automatically from the actual directory tree, preventing index drift or lost documents
  • Vectorization fix: the index now reuses the unified embedding provider, ensuring real semantic vectors instead of falling back to keyword search

Thanks @yangziyu-hhh

Docs: Knowledge Base

🔌 On-demand MCP Tool Retrieval

To address context bloat when many MCP tools are connected, we added on-demand tool retrieval: relevant MCP tools are loaded on demand via RAG vector search based on the current task, reducing the context taken up by irrelevant tools.

Thanks @fengyl07

Docs: MCP Tools

🌏 Traditional Chinese Support

The Web console, logs, and documentation now support Traditional Chinese (zh-Hant); the interface language can follow the system or be switched manually.

Thanks @anomixer (#2935)

🤖 New Models

  • Added support for claude-sonnet-5 and claude-fable-5
  • Added support for doubao-seed-2-1-pro and doubao-seed-2-1-turbo

Docs: Models

🔒 Security Hardening

  • Sensitive file read protection: hardened access to credential and other sensitive files to prevent bypass reads. Thanks @fengyl07 (#2936)
  • Browser access protection: blocks browser requests targeting internal network and cloud server internal endpoints, reducing the risk of being tricked into reaching internal services. Thanks @Jiangrong-W
  • Safer config parsing: config content is parsed in a safer way to avoid potential code execution risks. Thanks @shunfeng8421

🛠 Improvements & Fixes

  • Custom provider support: embedding and vision models can now use custom providers; also fixed a memory query issue on Windows. Thanks @HnBigVolibear
  • More reliable file editing: better preserves original indentation, and fuzzy matching no longer touches unrelated content. Thanks @weijun-xia (#2942)
  • Command output encoding fix: fixed garbled Chinese characters when a command produces large output. Thanks @weijun-xia (#2941)
  • Azure OpenAI fixes: fixed streaming output and related configuration issues for Azure OpenAI. Thanks @Tunnello
  • WeCom Smart Bot: added channel docs for the webhook (callback) mode. Thanks @6vision
  • Deep Dream toggle: added a dedicated deep_dream_enabled switch to enable or disable Deep Dream distillation independently.
  • Stability: improved connection recycling in the Web service and fixed several Self-Evolution issues (#2924 Thanks @santipongth, #2904 Thanks @YLChen-007)

📦 How to Upgrade

  • Desktop client: get the latest version from the download page.
  • Source deployment: run cow update for a one-click upgrade, or pull the latest code and restart. See the upgrade guide.
