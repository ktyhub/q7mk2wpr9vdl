pulsar v4.0.5

2025-05-22

Actualizaciones de la biblioteca

  • [arreglo][seg] Actualice Jetty a 9.4.57.v20241219 para mitigar CVE-2024-6763 (#24232)
  • [mejorar] Actualice Netty a 4.1.121.Final (#24214)
  • [mejorar] Actualizar las versiones de la biblioteca Apache Commons a versiones compatibles (#24205)
  • [mejorar] Actualice pulsar-client-python a 3.7.0 en la imagen Docker (#24302)
  • [mejorar][compilar] Actualizar la versión commons-compress de 1.27.0 a 1.27.1 (#24270)
  • [mejorar][construir] Actualice Lombok a 1.18.38 para que sea compatible con JDK 24 (#24237)

Corredor

  • [solución][broker] El consumidor se atascó cuando falló la eliminación de la suscripción __compactation (#23980)
  • [fix][broker] Soluciona el retraso en el cierre del broker resolviendo las comprobaciones de estado que bloqueaban (#24210)
  • [fix][broker] Repara la pérdida de memoria de ByteBuf en REST API para publicar mensajes (#24228)
  • [arreglar][corredor] Corregir el nivel de clúster OffloadedReadPriority para el contable primero no funciona (#24151)
  • [arreglar][broker] Corregir la condición incorrecta del registro del servicio de compactación (#24207)
  • [arreglo][broker] arregla ExtensibleLoadManager para anular las propiedades simultáneamente sin bloquear el hilo del administrador de carga (#24156)
  • [arreglar][broker] Arreglar la fuga de HashedWheelTimer en PulsarService deteniéndolo durante el apagado (#24275)
  • [arreglar][corredor] Corregir el punto muerto de HealthChecker al apagar (#24216)
  • [arreglar][broker] Corregir NPE del iterador incorrecto en el trabajo de limpieza de propiedad (solo ExtensibleLoadManagerImpl) (#24196)
  • [fix][broker] Soluciona un posible bloqueo al crear un tema particionado (#24313)
  • [solución] [corredor] Soluciona algunos problemas al calcular totalAvailableBookies en el método getExcludedBookiesWithIsolationGroups cuando algunas casas de apuestas pertenecen a múltiples grupos de aislamiento. (#24091)
  • [arreglar][broker] Corregir la creación y actualización de inquilinos con valor nulo (#24209)
  • [arreglar] [broker] corrige el nombre del método incorrecto checkTopicExists. (#24293)
  • [fix][broker] Corrige la vista ServiceUnitStateData inconsistente (solo ExtensibleLoadManagerImpl) (#24186)
  • [arreglo][broker] Esquema huérfano después de deshabilitar un clúster para un espacio de nombres (#24223)
  • [arreglo][broker] La característica brokerDeleteInactivePartitionedTopicMetadataEnabled deja políticas de temas y esquemas de temas huérfanos (#24150)
  • [solución][broker] Anular el registro de recopiladores de métricas no estáticas registradas en el registro predeterminado Prometheus (#24257)
  • [arreglar][broker]Corregir la prioridad incorrecta entre las políticas de temas y las políticas de temas globales (#24254)
  • [arreglar][broker]arreglar pérdida de memoria, mensajes perdidos, estado de replicación incorrecto si se usan múltiples versiones de esquema (auto_produce) (#24178)
  • [fix][admin] La política de cuota de trabajo pendiente es nula, lo que provoca una NPE (#24192)
  • [fix][ml] Soluciona el problema de bloqueo de subprocesos de ML en internalGetPartitionedStats API (#24167)
  • [fix][ml] Omitir la eliminación del cursor si ya se eliminó antes de cancelar la suscripción (#24098)

Client

  • [arreglar][client] Corregir productor.getPendingQueueSize incorrecto debido a una implementación de cola incompleta (#24184)
  • [solución][client] Se corrigió que la publicación del productor se atascara después de que se descartara un mensaje con un esquema incompatible (#24282)
  • [mejorar][client] validar ClientConfigurationData antes para evitar fugas de recursos (#24187)
  • [improve][client]Mejorar el registro de transacciones cuando se agota el tiempo de espera de un comando TXN (#24230)

Pulsar IO y funciones Pulsar

  • [fix][io] Corregir advertencia de sintaxis en las funciones de Pulsar Python (#24297)
  • [improve][io] Agregar parámetro de configuración para deshabilitar la agregación para Kinesis Producers (#24289)
  • [mejorar][io] admite transformaciones y predicados de Kafka Connect (#24221)
  • [mejorar][io] Actualizar Kafka client y la versión compatible de la plataforma Confluent (#24201)
  • [improve][io][kca] admite nombres de temas completos en registros fuente (#24248)

Otros

  • [limpieza] Eliminar la configuración no utilizada autoShrinkForConsumerPendingAcksMap (#24315)
  • [limpieza] elimina el mensaje de configuración no utilizadoPublishBufferCheckIntervalInMillis (#24252)
  • [limpieza] Eliminar campos estáticos no utilizados en BrokerService (#24251)
  • [limpieza][misc] Agregar anotación de anulación (#24033)
  • [limpieza][prueba] Eliminar el parámetro no utilizado del método deleteNamespaceWithRetry en MockedPulsarServiceBaseTest (#24283)
  • Tarea [solución]: eliminar precisionTopicPublishRateLimiterEnable no utilizado (#24249)
  • [arreglar][misc] Arreglar la fuga de ByteBuf en SchemaUtils (#24274)
  • [arreglar][misc] Corrija las fugas de ByteBuf en las pruebas haciendo que ByteBufPair.coalesce libere el ByteBufPair de entrada (#24273)
  • [solución][misc]: ignorar el libro mayor eliminado al derribar el clúster (#23831)
  • [fix][proxy] Corrige el error client incorrecto al llamar a obtener metadatos del tema (#24181)
  • [arreglo][proxy] Propagar indicadores de funciones de conexión client a través de Pulsar Proxy al Broker (#24158)
  • [solución][esquema] Rechazar tipos de esquema Avro no admitidos durante el registro del esquema (#24103)
  • [mejorar][cli] Hacer que la terminación pulsar-perf tenga mayor capacidad de respuesta mediante el uso del estado de interrupción del subproceso (#24309)
  • [mejorar][misc] Migrar desde múltiples bibliotecas de anotaciones de nulidad a anotaciones JSpecify (#24239)

pulsar v4.0.5

2025-05-22

Library updates

  • [fix][sec] Upgrade Jetty to 9.4.57.v20241219 to mitigate CVE-2024-6763 (#24232)
  • [improve] Upgrade Netty to 4.1.121.Final (#24214)
  • [improve] Upgrade Apache Commons library versions to compatible versions (#24205)
  • [improve] Upgrade pulsar-client-python to 3.7.0 in Docker image (#24302)
  • [improve][build] Upgrade commons-compress version from 1.27.0 to 1.27.1 (#24270)
  • [improve][build] Upgrade Lombok to 1.18.38 to support JDK 24 (#24237)

Broker

  • [fix][broker] Consumer stuck when delete subscription __compaction failed (#23980)
  • [fix][broker] Fix broker shutdown delay by resolving hanging health checks (#24210)
  • [fix][broker] Fix ByteBuf memory leak in REST API for publishing messages (#24228)
  • [fix][broker] Fix cluster level OffloadedReadPriority to bookkeeper-first does not work (#24151)
  • [fix][broker] Fix compaction service log's wrong condition (#24207)
  • [fix][broker] fix ExtensibleLoadManager to override the ownerships concurrently without blocking load manager thread (#24156)
  • [fix][broker] Fix HashedWheelTimer leak in PulsarService by stopping it in shutdown (#24275)
  • [fix][broker] Fix HealthChecker deadlock in shutdown (#24216)
  • [fix][broker] Fix NPE from the wrong iterator in the ownership cleanup job(ExtensibleLoadManagerImpl only) (#24196)
  • [fix][broker] Fix potential deadlock when creating partitioned topic (#24313)
  • [fix][broker] Fix some problems in calculate totalAvailableBookies in method getExcludedBookiesWithIsolationGroups when some bookies belongs to multiple isolation groups. (#24091)
  • [fix][broker] Fix tenant creation and update with null value (#24209)
  • [fix][broker] fix wrong method name checkTopicExists. (#24293)
  • [fix][broker] Fixes Inconsistent ServiceUnitStateData View (ExtensibleLoadManagerImpl only) (#24186)
  • [fix][broker] Orphan schema after disabled a cluster for a namespace (#24223)
  • [fix][broker] The feature brokerDeleteInactivePartitionedTopicMetadataEnabled leaves orphan topic policies and topic schemas (#24150)
  • [fix][broker] Unregister non-static metrics collectors registered in Prometheus default registry (#24257)
  • [fix][broker]Fix incorrect priority between topic policies and global topic policies (#24254)
  • [fix][broker]fix memory leak, messages lost, incorrect replication state if using multiple schema versions(auto_produce) (#24178)
  • [fix][admin] Backlog quota's policy is null which causes a NPE (#24192)
  • [fix][ml] Fix ML thread blocking issue in internalGetPartitionedStats API (#24167)
  • [fix][ml] Skip deleting cursor if it was already deleted before calling unsubscribe (#24098)

Client

  • [fix][client] Fix incorrect producer.getPendingQueueSize due to incomplete queue implementation (#24184)
  • [fix][client] Fix producer publishing getting stuck after message with incompatible schema is discarded (#24282)
  • [improve][client] validate ClientConfigurationData earlier to avoid resource leaks (#24187)
  • [improve][client]Improve transaction log when a TXN command timeout (#24230)

Pulsar IO and Pulsar Functions

  • [fix][io] Fix SyntaxWarning in Pulsar Python functions (#24297)
  • [improve][io] Add configuration parameter for disabling aggregation for Kinesis Producers (#24289)
  • [improve][io] support kafka connect transforms and predicates (#24221)
  • [improve][io] Upgrade Kafka client and compatible Confluent platform version (#24201)
  • [improve][io][kca] support fully-qualified topic names in source records (#24248)

Others

  • [cleanup] Remove unused config autoShrinkForConsumerPendingAcksMap (#24315)
  • [cleanup] remove unused config messagePublishBufferCheckIntervalInMillis (#24252)
  • [cleanup] Remove unused static fields in BrokerService (#24251)
  • [cleanup][misc] Add override annotation (#24033)
  • [cleanup][test] Remove unused parameter from deleteNamespaceWithRetry method in MockedPulsarServiceBaseTest (#24283)
  • [fix] chore: remove unused preciseTopicPublishRateLimiterEnable (#24249)
  • [fix][misc] Fix ByteBuf leak in SchemaUtils (#24274)
  • [fix][misc] Fix ByteBuf leaks in tests by making ByteBufPair.coalesce release the input ByteBufPair (#24273)
  • [fix][misc]: ignore deleted ledger when tear down cluster (#23831)
  • [fix][proxy] Fix incorrect client error when calling get topic metadata (#24181)
  • [fix][proxy] Propagate client connection feature flags through Pulsar Proxy to Broker (#24158)
  • [fix][schema] Reject unsupported Avro schema types during schema registration (#24103)
  • [improve][cli] Make pulsar-perf termination more responsive by using Thread interrupt status (#24309)
  • [improve][misc] Migrate from multiple nullness annotation libraries to JSpecify annotations (#24239)

Tests & CI

  • [improve][build] Upgrade SpotBugs to 4.9.x (#24243)
  • [improve][build] Upgrade to jacoco 0.8.13 (#24240)
  • [improve][build] Upgrade zstd version from 1.5.2-3 to 1.5.7-3 (#24263)
  • [improve][ci] Add Netty leak detection reporting to Pulsar CI (#24272)
  • [improve][ci] Disable detailed console logging for integration tests in CI (#24266)
