pulsar v3.0.14

2025-09-27

Actualizaciones de la biblioteca

  • [arreglo][seg] Actualice la versión bouncycastle bcpkix-fips a 1.79 para abordar CVE-2025-8916 (#24650)
  • [arreglo][seg] Actualice Netty a 4.1.127.Final para abordar CVE (#24717)
  • [arreglar][seg] Actualice a Netty 4.1.124.Final para dirigirse a CVE-2025-55163 (#24637)
  • [mejorar][construir] Bump org.apache.commons:commons-lang3 de 3.17.0 a 3.18.0 (#24514)
  • [mejorar][io] Actualizar AWS SDK v1 y v2, versiones Kinesis KPL y KPC (#24661)
  • [arreglar][misc] Actualizar dependencias para corregir vulnerabilidades críticas de seguridad (#24532)
  • [mejorar][construir] Actualice Lombok a 1.18.42 para que sea totalmente compatible con JDK25 (#24763)

Corredor

  • [arreglo][broker] Agregue doble verificación para la creación de cursores no duraderos (#24643)
  • [solución][broker] Garantiza que el consumidor del modo fijo de KeyShared respete los rangos asignados (#24730)
  • [arreglo][broker] La primera entrada se omitirá si se abre NonDurableCursor mientras se agrega la primera entrada al libro mayor recortado. (#24738)
  • [solución][broker] La solución no puede cerrar correctamente el broker por parte del administrador api (#24731)
  • [arreglar][corredor] Corregir el registro de observador duplicado después de que se restablezca la sesión (#24621)
  • [arreglar][broker] Corregir pérdida de memoria cuando las métricas se actualizan en un hilo que no sea FastThreadLocalThread (#24719)
  • [arreglo][broker] Se corrigió la condición de carrera en MetadataStoreCacheLoader causando un almacenamiento en caché inconsistente de la lista de brokers disponibles (#24639)
  • [fix][broker] Fix REST API para generar mensajes para temas con partición única (#24450)
  • [arreglo][broker] Una expresión regular no válida en PulsarLedgerManager hace que se ignore la notificación de datos de zk (#23977)
  • [solución][corredor] Evitar errores inesperados de reciclaje en la devolución de llamada de lectura del despachador (#24741)
  • [fix][broker][branch-3.0] Corrige métricas de antigüedad de trabajo pendiente incorrectas cuando la posición de eliminación de la marca apunta a un libro mayor eliminado (#24518) (#24671)
  • [fix][broker][branch-3.0] Previene NPE enownedBundlesCountPerNamespace en la primera carga del paquete (#24758)
  • [solución][broker]Se solucionó el problema de la versión incorrecta del almacén de metadatos que nunca se recuperó si se recibió una respuesta grande de ZK (#24580)
  • [fix][ml]Se corrige EOFException después de la descarga de temas habilitados (#24753)
  • [mejorar][corredor] Elija un hilo aleatorio para consumerFlow en PersistentDispatcherSingleActiveConsumer (#20522)
  • [mejorar][corredor] Si hay un punto muerto en el servicio, la sonda debería devolver un error porque es posible que el servicio no esté disponible (#23634)
  • [mejorar][broker] Optimizar y limpiar la agregación de estadísticas de temas (#21361)

Client

  • [arreglo][client] Evite reciclarcling el mismo ConcurrentBitSetRecyclable entre diferentes hilos (#24725)
  • [arreglar][client] corrige ArrayIndexOutOfBoundsException en SameAuthParamsLookupAutoClusterFailover (#24662)
  • [arreglar][client] Corregir ArrayIndexOutOfBoundsException cuando se usa SameAuthParamsLookupAutoClusterFailover (#23336)
  • [solución][client] Se corrigió el escalado automático de la cola del receptor sin límite de memoria (#24743)
  • [solución][client] Reintentar para excepciones desconocidas al crear un productor o consumidor (#24599)
  • [solución][client] Omitir la validación del esquema al enviar mensajes a DLQ para evitar un bucle infinito cuando la validación del esquema falla en un mensaje entrante (#24663)
  • [solución][client]Evita que ZeroQueueConsumer reciba mensajes por lotes cuando usa MessagePayloadProcessor (#24610)
  • [arreglo][client]TopicListWatcher no se cierra al llamar al método PatternMultiTopicsConsumerImpl.closeAsync() (#24698)
  • [arreglo][client] reversión del comportamiento de reintento de TopicListWatcher (#24752)
  • [mejorar][client] Admite carga de clave privada RSA PKCS#8 (#24582)

Pulsar IO y funciones Pulsar

  • [arreglar][io] Mejorar la lógica de vaciado de compensación de fuente de Kafka Connect (#24654)
  • [mejorar][io] Agregar información del nombre del archivo de dependencia al mensaje de error cuando la validación del archivo .nar falla con ZipException (#24604)
  • [mejorar][io] Compatibilidad con la especificación de la ruta binaria nativa de Kinesis KPL con la ruta específica de la versión 1.0 (#24669)

Otros

  • [arreglar][proxy] Corregir TooLongFrameException con Pulsar Proxy (#24626)
  • [solución][misc] Se corrigió la infracción del contrato compareTo para NamespaceBundleStats, TimeAverageMessageData y ResourceUnitRanking (#24772)
  • [improve][doc] Mejorar los JavaDocs de sendAsync para evitar un uso inadecuado (#24601)
  • [arreglar][descargar] Excluir dependencias innecesarias del proveedor de almacenamiento por niveles/descargador de archivos nar (#24649)

Pruebas y CI

  • [mejorar][compilar] Utilice org.apache.nifi:nifi-nar-maven-plugin:2.1.0 con skipDocGeneration=true (#24668)
  • [fix][ci] Corregir métricas de cobertura de código en Pulsar CI (#24595)
  • [arreglar][prueba] Corregir ConcurrentModificationException en Ipv4Proxy (#24632)

  • [arreglar][prueba]arreglar el problema ZeroQueueSizeTest.testZeroQueueGetExceptionWhenReceiveBatchMessage (#24630)
  • [arreglar][corredor] Arreglar testReplicatorsInflightTaskListIsEmptyAfterReplicationFinished (#24590)
  • [mejorar][compilar] Deshabilitar el error de compilación de javadoc (#24594)
  • [mejorar][compilar] Aumentar el tiempo de espera del contexto de sincronización del solucionador maven (#24666)
  • [mejorar][prueba] Agregar prueba para el tema de mensajes no entregados con bloqueo máximo de mensajes no registrados (#24535)
  • [mejorar][prueba] Refactorizar la forma en que se parchea el archivo nar pulsar-io-debezium-oracle al crear la imagen de prueba (#24586)

pulsar v3.0.14

2025-09-27

Library updates

  • [fix][sec] Upgrade bouncycastle bcpkix-fips version to 1.79 to address CVE-2025-8916 (#24650)
  • [fix][sec] Upgrade Netty to 4.1.127.Final to address CVEs (#24717)
  • [fix][sec] Upgrade to Netty 4.1.124.Final to address CVE-2025-55163 (#24637)
  • [improve][build] Bump org.apache.commons:commons-lang3 from 3.17.0 to 3.18.0 (#24514)
  • [improve][io] Upgrade AWS SDK v1 & v2, Kinesis KPL and KPC versions (#24661)
  • [fix][misc] Upgrade dependencies to fix critical security vulnerabilities (#24532)
  • [improve][build] Upgrade Lombok to 1.18.42 to fully support JDK25 (#24763)

Broker

  • [fix][broker] Add double-check for non-durable cursor creation (#24643)
  • [fix][broker] Ensure KeyShared sticky mode consumer respects assigned ranges (#24730)
  • [fix][broker] First entry will be skipped if opening NonDurableCursor while trimmed ledger is adding first entry. (#24738)
  • [fix][broker] Fix cannot shutdown broker gracefully by admin api (#24731)
  • [fix][broker] Fix duplicate watcher registration after SessionReestablished (#24621)
  • [fix][broker] Fix memory leak when metrics are updated in a thread other than FastThreadLocalThread (#24719)
  • [fix][broker] Fix race condition in MetadataStoreCacheLoader causing inconsistent availableBroker list caching (#24639)
  • [fix][broker] Fix REST API to produce messages to single-partitioned topics (#24450)
  • [fix][broker] Invalid regex in PulsarLedgerManager causes zk data notification to be ignored (#23977)
  • [fix][broker] Prevent unexpected recycle failure in dispatcher's read callback (#24741)
  • [fix][broker][branch-3.0] Fix wrong backlog age metrics when the mark delete position point to a deleted ledger (#24518) (#24671)
  • [fix][broker][branch-3.0] Prevent NPE in ownedBundlesCountPerNamespace on first bundle load (#24758)
  • [fix][broker]Fix never recovered metadata store bad version issue if received a large response from ZK (#24580)
  • [fix][ml]Fix EOFException after enabled topics offloading (#24753)
  • [improve][broker] Choose random thread for consumerFlow in PersistentDispatcherSingleActiveConsumer (#20522)
  • [improve][broker] If there is a deadlock in the service, the probe should return a failure because the service may be unavailable (#23634)
  • [improve][broker] Optimize and clean up aggregation of topic stats (#21361)

Client

  • [fix][client] Avoid recycling the same ConcurrentBitSetRecyclable among different threads (#24725)
  • [fix][client] fix ArrayIndexOutOfBoundsException in SameAuthParamsLookupAutoClusterFailover (#24662)
  • [fix][client] Fix ArrayIndexOutOfBoundsException when using SameAuthParamsLookupAutoClusterFailover (#23336)
  • [fix][client] Fix receiver queue auto-scale without memory limit (#24743)
  • [fix][client] Retry for unknown exceptions when creating a producer or consumer (#24599)
  • [fix][client] Skip schema validation when sending messages to DLQ to avoid infinite loop when schema validation fails on an incoming message (#24663)
  • [fix][client]Prevent ZeroQueueConsumer from receiving batch messages when using MessagePayloadProcessor (#24610)
  • [fix][client]TopicListWatcher not closed when calling PatternMultiTopicsConsumerImpl.closeAsync() method (#24698)
  • [fix][client] rollback TopicListWatcher retry behavior (#24752)
  • [improve][client] Support load RSA PKCS#8 private key (#24582)

Pulsar IO and Pulsar Functions

  • [fix][io] Improve Kafka Connect source offset flushing logic (#24654)
  • [improve][io] Add dependency file name information to error message when .nar file validation fails with ZipException (#24604)
  • [improve][io] Support specifying Kinesis KPL native binary path with 1.0 version specific path (#24669)

Others

  • [fix][proxy] Fix TooLongFrameException with Pulsar Proxy (#24626)
  • [fix][misc] Fix compareTo contract violation for NamespaceBundleStats, TimeAverageMessageData and ResourceUnitRanking (#24772)
  • [improve][doc] Improve the JavaDocs of sendAsync to avoid improper use (#24601)
  • [fix][offload] Exclude unnecessary dependencies from tiered storage provider / offloader nar files (#24649)

Tests & CI

  • [improve][build] Use org.apache.nifi:nifi-nar-maven-plugin:2.1.0 with skipDocGeneration=true (#24668)
  • [fix][ci] Fix code coverage metrics in Pulsar CI (#24595)
  • [fix][test] Fix ConcurrentModificationException in Ipv4Proxy (#24632)
  • [fix][test] Flaky-test: BrokerServiceTest.testShutDownWithMaxConcurrentUnload (#24769)
  • [fix][test]fix flaky ZeroQueueSizeTest.testZeroQueueGetExceptionWhenReceiveBatchMessage (#24633)
  • [fix][test]fix flaky ZeroQueueSizeTest.testZeroQueueGetExceptionWhenReceiveBatchMessage (#24630)
  • [fix][broker] Fix flaky testReplicatorsInflightTaskListIsEmptyAfterReplicationFinished (#24590)
  • [improve][build] Disable javadoc build failure (#24594)
  • [improve][build] Increase maven resolver's sync context timeout (#24666)
  • [improve][test] Add test for dead letter topic with max unacked messages blocking (#24535)
  • [improve][test] Refactor the way way pulsar-io-debezium-oracle nar file is patched when building the test image (#24586)
  • [fix][build] Import isNotBlank
  • [fix][ci] Fix CI for Java 25 including upgrade of Gradle Develocity Maven extension (#24767)

For the complete list, check the full changelog.
