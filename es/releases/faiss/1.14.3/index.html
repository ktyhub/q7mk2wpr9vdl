faiss v1.14.3

Destacados

  • Expansión de backend de GPU de metal: nuevo MetalIndexIVFFlat con kernels de escaneo/fusión IVF y soporte top-k ampliado (#5202); El metal ahora está habilitado de forma predeterminada en las máquinas Apple Silicon (#5280)
  • TurboQuant en ScalarQuantizer — Algoritmo 2 completo (etapa QJL) con SIMD y optimizaciones (#5170)
  • Optimizaciones de Sapphire Rapids (SPR): ScalarQuantizer L2/IP (#5173), HammingComputer basado en VPOPCNTDQ (#5183) y kernel RaBitQ basado en VPOPCNTDQ (#5149)
  • faiss-gpu pip wheels — nuevo paquete de ruedas GPU (#5131); Ruedas musllinux reactivadas para faiss-cpu (#5299)
  • Soporte vamana estático SVS (#5224)
  • Modo HNSW is_similarity para métricas de IP/similitud (#5246, #5226)
  • Rendimiento de búsqueda HNSW: reserve capacidad de VisitedTableSet para evitar repeticiones (#5290), search_from_candidate_unbounded con plantilla para la desvirtualización de VisitedTable (#5270) y comprobaciones de tiempo de ejecución evitadas en VisitedTable (#5234).
  • NEON FINE_SIZE=2 especializaciones para Index2LevelDecoderImpl y IndexPQDecoder (#5255)
  • cuVS actualizado a 26.06 (#5240); CI actualizado a ROCm 7 (#5196)
  • Refuerzo de deserialización: validación de campo bool (#5279) y rechazo de índice interno nulo en IDMap/BinaryFromFloat (#5239)
  • Construir solidez: corrige la importación SIGILL que no es AVX2 a través de las tablas de partición .rodata (#5298), la corrección de compilación NEON de Windows ARM64 (MSVC) (#5274) y la corrección de envío AVX512_SPR en AMD (#5281)

faiss v1.14.3

Highlights

  • Metal GPU backend expansion — new MetalIndexIVFFlat with IVF scan/merge kernels and expanded top-k support (#5202); Metal now enabled by default on Apple Silicon machines (#5280)
  • TurboQuant in ScalarQuantizer — full Algorithm 2 (QJL stage) with SIMD and optimizations (#5170)
  • Sapphire Rapids (SPR) optimizations — ScalarQuantizer L2/IP (#5173), VPOPCNTDQ-based HammingComputer (#5183), and VPOPCNTDQ-based RaBitQ kernel (#5149)
  • faiss-gpu pip wheels — new GPU wheel packaging (#5131); musllinux wheels re-enabled for faiss-cpu (#5299)
  • SVS static vamana support (#5224)
  • HNSW is_similarity mode for IP/similarity metrics (#5246, #5226)
  • HNSW search performance — reserve VisitedTableSet capacity to avoid rehashes (#5290), search_from_candidate_unbounded templatized for VisitedTable devirtualization (#5270), and runtime checks avoided in VisitedTable (#5234)
  • NEON FINE_SIZE=2 specializations for Index2LevelDecoderImpl and IndexPQDecoder (#5255)
  • cuVS upgraded to 26.06 (#5240); CI updated to ROCm 7 (#5196)
  • Deserialization hardening — bool-field validation (#5279) and null inner-index rejection in IDMap / BinaryFromFloat (#5239)
  • Build robustness — fix non-AVX2 import SIGILL via .rodata partitioning tables (#5298), Windows ARM64 (MSVC) NEON build fix (#5274), and AVX512_SPR dispatch fix on AMD (#5281)
