ant-design 6.6.0

Highlights

  • High-performance lists — New Listy adds virtualization with grouping, sticky headers, and imperative scrolling, reducing the need to build custom list infrastructure for large datasets (#58724).

  • Centralized configuration — ConfigProvider now controls the focusOutline token, input variant defaults, and Tooltip/Popover/Popconfirm hover delays globally. This lets design systems enforce consistent focus styling and interaction timing without per-component overrides (#58647, #58784, #58892).

  • Better DOM and TypeScript integration — nativeElement refs now expose root DOM nodes across many components, while missing public Props and Ref types are exported. This simplifies measurement, focus management, and typed wrapper components without relying on internal imports (#58700, #58798).

  • Style precedence correction — Semantic styles now resolve consistently when ConfigProvider and component-level style/styles are combined. Apps that layer theme and component overrides should visually recheck affected components, as the corrected cascade may change rendered appearance without any prop changes (#58550, #58564).

  • Deeper component customization — Tree gains useTree and auto-expanding scrollTo; Table adds eagerly rendered expandable content and customizable page-size controls; Mentions and Tabs gain popup render hooks. Use expandable.forceRender selectively because it mounts hidden content before expansion, increasing initial render work (#58841, #58860, #58831, #58582, #58651).

  • Breaking changes — None reported.
