bóveda v2.0.3

SEGURIDAD:

  • auth/radius: Se agregó la opción case_inSENSENTITION_NAMES para evitar colisiones de nombres de usuario y permitir el manejo de usuarios que no distinguen entre mayúsculas y minúsculas.
  • core/acl: corrige la omisión de LIST ACL donde una solicitud de barra diagonal podría omitir una regla de denegación más específica.
  • núcleo: utilizar comparación de tokens de recuperación en tiempo constante
  • secrets/spiffe (empresa): asegúrese de que los valores de la plantilla tengan escapes adecuados.
  • transformar (empresa): agregue citas específicas de db apropiadas y escaping. CAMBIOS:
  • auth/cf: Actualizar complemento a v0.23.1
  • core/acl: las solicitudes LIST con una barra diagonal ahora respetan correctamente políticas de denegación más específicas. Anteriormente, se podía omitir una denegación en path "kv/*" { deny } para LIST kv/private/ si también existía una autorización más amplia para path "kv/*". Es posible que ahora se rechacen las políticas que se basan en el comportamiento anterior (incorrecto).
  • principal: Vault ahora redirigirá rutas no canonicalizadas (que contienen /./, /../ o //) a una ruta limpia, en lugar de rechazar estas solicitudes.
  • secrets/azure: Actualización del complemento a v0.26.5+ent CARACTERÍSTICAS:
  • Soporte para agentes de IA (Beta/Enterprise): agrega soporte beta para agentes de IA de primera clase. Agrega un Registro de agentes para registrar agentes y agrega soporte para usar Vault como servidor de recursos OAuth para entidades de agentes registrados. Cuando está configurado, permite utilizar OAuth 2.0 JWT para autorizar directamente solicitudes a Vault, sin necesidad de un token de Vault. MEJORAS:
  • facturación de consumo: agregue un nuevo punto final sys/billing/config para permitir la configuración de la retención de datos de facturación (mínimo 13 meses, máximo 6 años).
  • core (Enterprise): haga que la detección de interbloqueo en sealwrap sea configurable agregando "sealwrap" a la configuración existente detect_deadlocks.
  • identidad/scim (empresa): actualice las operaciones de PATCH en scim/v2/Usuarios para permitir múltiples modificaciones en la misma llamada de parche, soporte para operaciones de parche en los metadatos y el nombre del usuario además del estado activo, y permita especificar el valor path en las operaciones de parche
  • sdk/helper/keysutil: la función GetPolicy del administrador de bloqueos ahora siempre devuelve una política bloqueada, incluso cuando el almacenamiento en caché está activado. habilitado. La estructura PolicyRequest tiene un nuevo campo para indicar si la persona que llama requiere un bloqueo de escritura en la política.
  • ui (empresa): migre gráficos de gráficos lineales a gráficos de carbono en la descripción general de uso de Client y en el panel de uso de Vault. CORRECCIÓN DE ERRORES:
  • core/rotationMgr: corrigió el enrutamiento de almacenamiento para montajes locales en espacios de nombres para evitar la replicación de metadatos y garantizar el cumplimiento de GDPR.
  • kmip (empresa): corrige un error que impide que la CA heredada funcione en un oyente con nombre.
  • secret-sync (empresa): corrige la persistencia de la política de replicación de GCP Secret Manager en los reinicios de Vault.
  • secrets/database/mssql: cancela el registro de configuraciones TLS obsoletas cuando la configuración TLS de la conexión MySQL cambia o la conexión se cierra, lo que evita que se acumulen grupos de certificados retenidos.
  • secretos/pki: corrige la emisión de certificados PKI no después de un tiempo para respetar el TTL máximo.
  • secretos/tránsito: agregue compatibilidad con claves administradas al punto final de reencapsulado de Transit.
  • almacenamiento/balsa: rechazar valores performance_multiplier menores o iguales a cero

vault v2.0.3

SECURITY:

  • auth/radius: Added case_insensitive_names toggle to prevent username collisions and enable case-insensitive user handling.
  • core/acl: Fix LIST ACL bypass where a trailing-slash request could skip a more-specific deny rule.
  • core: Use constant-time recovery token comparison
  • secrets/spiffe (enterprise): Ensure template values are properly escaped.
  • transform (enterprise): Add appropriate db specific quoting and escaping.

CHANGES:

  • auth/cf: Update plugin to v0.23.1
  • core/acl: LIST requests with a trailing slash now correctly respect more-specific deny policies. Previously, a deny on path "kv/*" { deny } could be bypassed for LIST kv/private/ if a broader allow path "kv/*" also existed. Policies relying on the previous (incorrect) behavior may now be denied.
  • core: Vault will now redirect non-canonicalized paths (containing /./, /../, or //) to a cleaned path, instead of rejecting these requests
  • secrets/azure: Update plugin to v0.26.5+ent

FEATURES:

  • AI Agent Support (Beta/Enterprise): Adds beta support for first-class AI agents. Adds an Agent Registry to register agents, and adds support for using Vault as an OAuth resource server for registered agent entities. When configured, allows OAuth 2.0 JWTs to be used to directly authorize requests to Vault, without needing a Vault token.

IMPROVEMENTS:

  • consumption-billing: Add a new sys/billing/config endpoint to allow configuration of billing data retention (min 13 months, max 6 years).
  • core (Enterprise): Make deadlock detection in sealwrap configurable by adding "sealwrap" to existing configuration detect_deadlocks.
  • identity/scim (enterprise): Update PATCH operations on scim/v2/Users to allow multiple modifications in the same patch call, support for patch operations on user metadata and name in addition to active status, and allow specifying path value in patch operations
  • sdk/helper/keysutil: The lock manager's GetPolicy function now always returns a locked Policy, even when caching is enabled. The PolicyRequest struct has a new field to indicate whether the caller requires a write lock on the policy.
  • ui (enterprise): Migrate charts from Lineal to Carbon Charts in the Client usage overview and Vault usage dashboard.

BUG FIXES:

  • core/rotationMgr: Fix storage routing for local mounts in namespaces to prevent metadata replication and ensure GDPR compliance.
  • kmip (enterprise): Fix a bug that prevents the legacy CA from working on a named listener.
  • secret-sync (enterprise): Fix GCP Secret Manager replication policy persistence across Vault restarts.
  • secrets/database/mssql: Deregister stale TLS configurations when MySQL connection TLS settings change or the connection is closed, preventing retained certificate pools from accumulating.
  • secrets/pki: Fix PKI certificate issuance not_after time to respect max TTL.
  • secrets/transit: Add managed key support to Transit rewrap endpoint.
  • storage/raft: reject performance_multiplier values less than or equal to zero
