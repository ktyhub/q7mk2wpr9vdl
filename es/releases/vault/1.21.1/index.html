##1.21.1

20 de noviembre de 2025

SEGURIDAD:

  • auth/aws: soluciona un problema por el cual un usuario podía omitir la autenticación en Vault debido a un almacenamiento en caché incorrecto de AWS client
  • ui: deshabilita el análisis de bufanda para compilaciones de ui CAMBIOS:
  • auth/kubernetes: Actualización del complemento a v0.23.1
  • auth/saml: Actualizar complemento a v0.7.0
  • auth/saml: complemento de actualización a v0.7.1, que agrega la variable de entorno VAULT_SAML_DENY_INTERNAL_URLS para evitar que los campos idp_metadata_url, idp_sso_url o acs_urls contengan URL que se resuelvan en direcciones IP internas
  • núcleo: versión Bump Go para 1.25.4
  • secrets/azure: Actualización del complemento a v0.25.0+ent
  • secretos/pki: los puntos finales firmados textualmente ya no ignoran la extensión de restricciones básicas en los CSR, usándolas en los certificados generados si isCA=false o devolviendo un error si isCA=true MEJORAS:
  • Actualice github.com/dvsekhvalnov/jose2go para corregir la vulnerabilidad de seguridad CVE-2025-63811.
  • api: Se agregó el punto final sys/reporting/scan con permiso sudo que generará un conjunto de archivos que contienen información sobre el estado de Vault en la ubicación especificada por el elemento de configuración reporting_scan_directory.
  • auth/ldap: requiere contraseñas que no estén vacías en el comando de inicio de sesión para evitar el acceso no autenticado a Vault.
  • núcleo/métricas: la lectura y el listado de una instantánea ahora se rastrean a través de las métricas vault.route.read-snapshot.{mount_point} y vault.route.list-snapshot.{mount_point}.
  • Informes de utilización de licencias (empresarial): agregue métricas para la cantidad de certificados PKI emitidos.
  • políticas: agregar advertencia sobre la comparación de listas cuando se usan parámetros_permitidos o parámetros_denegados
  • sincronización secreta: agregue soporte de paralelización para sincronizar y desincronizar operaciones para asociaciones de granularidad de clave secreta
  • secretos/pki: incluya el AuthorityKeyID del certificado en los campos de respuesta para los puntos finales API que emiten, firman o recuperan certificados.
  • sys (empresa): agregue el punto final sys/billing/certificates API para recuperar la cantidad de certificados PKI emitidos.
  • ui/actividad (empresa): agregue texto aclaratorio para explicar que la columna "Uso inicial" solo tendrá marcas de tiempo para clients utilizados inicialmente después de actualizar a la versión 1.21
  • ui/actividad (empresa): permite la consulta manual del uso de client si hay un problema al recuperar la hora de inicio de la licencia.
  • ui/actividad (empresa): reduzca las solicitudes a la exportación de actividad API al obtener datos nuevos solo cuando el panel se carga inicialmente o se actualiza manualmente.
  • ui/actividad (empresa): admite el filtrado de meses desplegables por marca de tiempo ISO o valor de visualización.
  • ui/actividad: muestra el total en lugar de los nuevos clients mensuales para clústeres administrados por HCP
  • ui/pki: agrega soporte para configurar los parámetros server_flag, client_flag, code_signing_flag y email_protection_flag para crear/actualizar una función. CORRECCIÓN DE ERRORES:
  • actividad (empresa): sys/internal/counters/activity genera el tipo de montaje correcto cuando se llama desde un espacio de nombres no raíz
  • auth/approle (empresa): el parámetro de función alias_metadata ahora completa el campo de metadatos personalizados de alias en lugar de metadatos de alias.
  • auth/aws (empresa): el parámetro de función alias_metadata ahora completa el campo de metadatos personalizados de alias en lugar de metadatos de alias.
  • auth/cert (empresa): el parámetro de función alias_metadata ahora completa el campo de metadatos personalizados de alias en lugar de metadatos de alias.
  • auth/github (empresa): el parámetro de función alias_metadata ahora completa el campo de metadatos personalizados de alias en lugar de metadatos de alias.
  • auth/ldap (empresa): el parámetro de función alias_metadata ahora completa el campo de metadatos personalizados de alias en lugar de metadatos de alias.
  • auth/okta (empresa): el parámetro de función alias_metadata ahora completa el campo de metadatos personalizados de alias en lugar de metadatos de alias.
  • auth/radius (empresa): el parámetro de función alias_metadata ahora completa el campo de metadatos personalizados de alias en lugar de metadatos de alias.
  • auth/scep (empresa): el parámetro de función alias_metadata ahora completa el campo de metadatos personalizados de alias en lugar de metadatos de alias.
  • autenticación/contraseña de usuario (empresa): el parámetro de función alias_metadata ahora completa el campo de metadatos personalizados de alias en lugar de metadatos de alias.
  • auth: se corrigió el pánico al proporcionar un número entero como lease_id en la renovación.
  • núcleo/rotación: evite cambiar zonas horarias ignorando cron.SpecSchedule
  • núcleo: interpreta todos los nuevos horarios de rotación del administrador de rotación como UTC para evitar el uso inadvertido de tz-local
  • secrets/azure: garantice la instalación adecuada del complemento de secretos empresariales de Azure.
  • secrets/pki: Devuelve error al emitir/firmar certificados cuyo NotAfter es anterior a NotBefore o cuyo período de validez no está contenido en las CA.
  • ui (empresa): Se corrigió que KV v2 no mostrara secretos en los espacios de nombres.
  • ui (empresa): corrige el formulario de inicio de sesión para que la entrada se represente correctamente cuando el token es el método de inicio de sesión preferido para un espacio de nombres.
  • ui/pki: corrige el análisis de certificados de la extensión key_usage para que los detalles reflejen con precisión los valores del certificado.
  • ui/pki: corrige la creación y actualización de un rol para que basic_constraints_valid_for_non_ca esté configurado correctamente.
  • ui: corrige el error en la solicitud de lista de metadatos de KV v2 para políticas sin una barra diagonal en la ruta.
  • ui: se resolvió una regresión que impedía que los usuarios con permisos de creación y actualización de secretos de KV v1 abrieran la vista de edición. La interfaz de usuario ahora reconoce correctamente estas capacidades y permite editar sin requerir acceso de lectura completo.
  • ui: actualice la tabla registrada de cuentas LDAP para mostrar bibliotecas LDAP jerárquicas
  • ui: actualiza el recuento de la biblioteca LDAP para reflejar el número total de nodos en lugar del número de directorios

vault v1.21.1

1.21.1

November 20, 2025

SECURITY:

  • auth/aws: fix an issue where a user may be able to bypass authentication to Vault due to incorrect caching of the AWS client
  • ui: disable scarf analytics for ui builds

CHANGES:

  • auth/kubernetes: Update plugin to v0.23.1
  • auth/saml: Update plugin to v0.7.0
  • auth/saml: Update plugin to v0.7.1, which adds the environment variable VAULT_SAML_DENY_INTERNAL_URLS to allow prevention of idp_metadata_url, idp_sso_url, or acs_urls fields from containing URLs that resolve to internal IP addresses
  • core: Bump Go version to 1.25.4
  • secrets/azure: Update plugin to v0.25.0+ent
  • secrets/pki: sign-verbatim endpoints no longer ignore basic constraints extension in CSRs, using them in generated certificates if isCA=false or returning an error if isCA=true

IMPROVEMENTS:

  • Update github.com/dvsekhvalnov/jose2go to fix security vulnerability CVE-2025-63811.
  • api: Added sudo-permissioned sys/reporting/scan endpoint which will output a set of files containing information about Vault state to the location specified by the reporting_scan_directory config item.
  • auth/ldap: Require non-empty passwords on login command to prevent unauthenticated access to Vault.
  • core/metrics: Reading and listing from a snapshot are now tracked via the vault.route.read-snapshot.{mount_point} and vault.route.list-snapshot.{mount_point} metrics.
  • license utilization reporting (enterprise): Add metrics for the number of issued PKI certificates.
  • policies: add warning about list comparison when using allowed_parameters or denied_parameters
  • secret-sync: add parallelization support to sync and unsync operations for secret-key granularity associations
  • secrets/pki: Include the certificate's AuthorityKeyID in response fields for API endpoints that issue, sign, or fetch certs.
  • sys (enterprise): Add sys/billing/certificates API endpoint to retrieve the number of issued PKI certificates.
  • ui/activity (enterprise): Add clarifying text to explain the "Initial Usage" column will only have timestamps for clients initially used after upgrading to version 1.21
  • ui/activity (enterprise): Allow manual querying of client usage if there is a problem retrieving the license start time.
  • ui/activity (enterprise): Reduce requests to the activity export API by only fetching new data when the dashboard initially loads or is manually refreshed.
  • ui/activity (enterprise): Support filtering months dropdown by ISO timestamp or display value.
  • ui/activity: Display total instead of new monthly clients for HCP managed clusters
  • ui/pki: Adds support to configure server_flag, client_flag, code_signing_flag, and email_protection_flag parameters for creating/updating a role.

BUG FIXES:

  • activity (enterprise): sys/internal/counters/activity outputs the correct mount type when called from a non root namespace
  • auth/approle (enterprise): Role parameter alias_metadata now populates alias custom metadata field instead of alias metadata.
  • auth/aws (enterprise): Role parameter alias_metadata now populates alias custom metadata field instead of alias metadata.
  • auth/cert (enterprise): Role parameter alias_metadata now populates alias custom metadata field instead of alias metadata.
  • auth/github (enterprise): Role parameter alias_metadata now populates alias custom metadata field instead of alias metadata.
  • auth/ldap (enterprise): Role parameter alias_metadata now populates alias custom metadata field instead of alias metadata.
  • auth/okta (enterprise): Role parameter alias_metadata now populates alias custom metadata field instead of alias metadata.
  • auth/radius (enterprise): Role parameter alias_metadata now populates alias custom metadata field instead of alias metadata.
  • auth/scep (enterprise): Role parameter alias_metadata now populates alias custom metadata field instead of alias metadata.
  • auth/userpass (enterprise): Role parameter alias_metadata now populates alias custom metadata field instead of alias metadata.
  • auth: fixed panic when supplying integer as a lease_id in renewal.
  • core/rotation: avoid shifting timezones by ignoring cron.SpecSchedule
  • core: interpret all new rotation manager rotation_schedules as UTC to avoid inadvertent use of tz-local
  • secrets/azure: Ensure proper installation of the Azure enterprise secrets plugin.
  • secrets/pki: Return error when issuing/signing certs whose NotAfter is before NotBefore or whose validity period isn't contained by the CA's.
  • ui (enterprise): Fix KV v2 not displaying secrets in namespaces.
  • ui (enterprise): Fixes login form so input renders correctly when token is a preferred login method for a namespace.
  • ui/pki: Fixes certificate parsing of the key_usage extension so details accurately reflect certificate values.
  • ui/pki: Fixes creating and updating a role so basic_constraints_valid_for_non_ca is correctly set.
  • ui: Fix KV v2 metadata list request failing for policies without a trailing slash in the path.
  • ui: Resolved a regression that prevented users with create and update permissions on KV v1 secrets from opening the edit view. The UI now correctly recognizes these capabilities and allows editing without requiring full read access.
  • ui: Update LDAP accounts checked-in table to display hierarchical LDAP libraries
  • ui: Update LDAP library count to reflect the total number of nodes instead of number of directories
