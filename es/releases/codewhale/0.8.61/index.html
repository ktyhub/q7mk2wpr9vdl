código ballena v0.8.61

CodeWhale es el proyecto canónico, el comando, el paquete npm y nombre del activo de liberación. El paquete npm heredado deepseek-tui es está en desuso y no recibe más versiones. Usuarios provenientes de Los nombres deepseek / deepseek-tui heredados de v0.8.x deben migrar con docs/REBRAND.md.

Instalar

Recomendado: npm (un comando, ambos binarios)

npm install -g codewhale

El contenedor descarga ambos archivos binarios de esta versión y los coloca en el mismo directorio.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.61

La imagen incluye el despachador codewhale y el tiempo de ejecución codewhale-tui. La etiqueta latest también se actualiza en el momento del lanzamiento.

Carga (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Se requieren ambas cajas: codewhale-cli produce el despachador codewhale y codewhale-tui produce el tiempo de ejecución interactivo en el que delega el despachador. La instalación de solo un binario fallará en tiempo de ejecución con un error MISSING_COMPANION_BINARY.

./install.sh

¿Qué hay en v0.8.61?

Esta versión aterriza en el plano de control de tiempo de ejecución para el trabajo con múltiples agentes: la TUI permanece receptivos mientras los subagentes corren, los subagentes convergen hacia trabajadores duraderos estilo flota con enrutamiento por modelo de rol, y las rutas de proveedor/modelo están aisladas por sesión. También se pliega en varias contribuciones de la comunidad.

Agregado

  • Fundamentos de tiempo de ejecución de WhaleFlow: perfiles de tiempo de ejecución de trabajadores (rol/permisos/shell/ herramientas / ruta modelo, con derivación secundaria no escalable), un registro de modelo entre proveedores con hidratación del catálogo fuera de línea y preparación del proveedor / presupuesto-contexto / adaptador-proveedor / Servicios de telemetría de recursos. (#3217, #3071, #3072, #3073)
  • Enrutamiento de subagentes por rol y modelo heterogéneo: a los subagentes se les puede asignar un modelo y proveedor por rol (por ejemplo, explorador versus síntesis; los verificadores dirigen a un modelo rápido). (#2027, #1768)
  • Modo de objetivo duradero: progreso del objetivo entre turnos con contabilidad de token/tiempo y un puerta de verificador como juez antes de que se pueda completar una meta. (#3215, #891, #1976, #2058, #2029)
  • Contrato de interacción entre padres y trabajadores visible: una acción recomendada por trabajador. (#3226)
  • Mantenedor de habilidades de flujo de trabajo GitHub; Se preparó la presentación del registro de la ACP. (#3192)
  • Punto final /v1/chat/completions compatible con OpenAI en el transporte HTTP del servidor de aplicaciones heredado, Proveedor neutral, con resolución de registro de modelo y reenvío de credenciales configurado.

Cambiado

  • Los subagentes convergen hacia trabajadores duraderos estilo flota: los estados reales del ciclo de vida de los trabajadores son proyectado en la barra lateral en lugar de un "en ejecución" codificado, y un subagente devuelve un mensaje estructurado Necesita un puesto de control de entrada en lugar de estacionamiento. (#3226, #3096, #3154)
  • La etiqueta de tiempo de ejecución por turno expone la postura de capacidad en lugar de etiquetas de modo de cara humana. (#3213)
  • El trabajo independiente de shell y verificador se realiza de manera predeterminada en trabajos en segundo plano con esperas sin bloqueo y una notificación de finalización; el bloqueo ahora requiere una espera explícita. (#3212)
  • Los lanzamientos de subagente ahora exponen controles model_strength y thinking explícitos al modelo. en lugar de enrutamiento automático de modelo secundario oculto; El trabajo explore está documentado como una buena opción para modelos más rápidos y thinking: "off".
  • El modo Plan es estrictamente de solo lectura (sin herramientas de shell), consistente con su postura en tiempo de ejecución.
  • /swarm está cerrado detrás del sustrato de trabajo duradero. (#3218)
  • La ruta de instalación/actualización heredada de deepseek se resuelve en codewhale. (#2960, #2924, #2917)

Fijo

  • TUI se congela cuando aparecen múltiples subagentes (bloqueador de lanzamiento) — la bomba de entrada del terminal funciona fuera del hilo de renderizado, los eventos AgentProgress se fusionan y los subagentes ya no se estacionan en entrada sin orquestador para responder; una prueba de estrés de seis trabajadores protege la entrada/presentación/cancelación vivacidad. (#3216, #3096)
  • Las notificaciones de finalización de subagente inactivo ahora reanudan el turno de los padres en lugar de esperar una mensaje de usuario posterior; gracias @giovanni-paolilla por el informe de punto muerto (#3266).
  • Aislamiento de ruta de proveedor/modelo: el estado del proveedor y del modelo es local de sesión y un La tupla proveedor+modelo no coincidente se rechaza en el límite de la ruta. (#3227)
  • Metadatos de ventana de contexto de ruta efectiva, verificación previa de límite superior y recuperación limitada de context_length_exceeded en lugar de volver a repetirlo. (#3204)
  • Las herramientas síncronas (file_search, grep_files, list_dir) son cancelables y ya no se mantienen un turno abierto contra cancelación. (#1791)
  • Los mensajes de inicio del proxy MCP stdio ya no bloquean las ejecuciones YOLO/no interactivas. (#2475)
  • Recuperación de shell en segundo plano estancada/fallida; Tiempo de espera del subagente configurable API. (#1737, #1786, #1806)
  • Compositor: dirección en cola confiable + Ctrl+S enviar (#3203, #3224); indicador de pie de página ocupado/inactivo (#2982); ajuste de palabras CJK (#963); cliDestinos de parada de barra lateral seleccionables (#3028); rendimiento del token en vivo (#3190); tarjetas de subagente de terminal con vencimiento automático (#3078).
  • Comprobación previa de glibc de Linux en la ruta de instalación/actualización con un error claro. (#3207, #1067)
  • La actualización automática reintenta fallas transitorias de metadatos/activos del GitHub y retrocede desde el GitHub REST API al redireccionamiento público releases/latest antes de crear las URL de activos de lanzamiento. (#3232)
  • El selector de proveedores enumera los proveedores en orden alfabético neutral en lugar de codificar primero DeepSeek; el proveedor activo permanece preseleccionado. (#3076)
  • La barra lateral de trabajo ya no muestra filas de estrategias obsoletas phase now: / phase next: una vez que aparece la lista de verificación está 100% completo.
  • El modo Plan ya no abrevia la investigación para solicitudes que nombran un repositorio, URL, versión, lanzamiento, estado de compilación, punto de referencia, error, PR, problema, superficie API o ruta de código local.
  • El texto pegado de gran tamaño permanece editable en el compositor, con una copia de seguridad del archivo adjunta al enviar tiempo para acceder al modelo; gracias @idling11 (#3267, cierra #3263).
  • Las teclas de dígitos simples 1-8 ahora insertan texto en lugar de activar las ranuras de la barra de acceso rápido; utilizar Alt+digit para acciones de la barra de acceso rápido. Gracias @wjq2026 por el informe y @DieMoe233 por la nota de ruta de pegado (#3243).
  • Los esquemas de herramientas Kimi/Moonshot normalizan los parámetros de función vacíos a un esquema de objeto raíz; gracias @jghwwnq para la reproducción del proveedor (#3265).
  • Novita utiliza de forma predeterminada su punto final /openai/v1 compatible con OpenAI, por lo que ya no se pueden completar chats. 404 listo para usar; gracias @buko por el informe y la verificación del punto final (#3255).
  • Seguridad de dependencia: ws anclado a 8.21.0 en todos los paquetes npm para cerrar el agotamiento de la memoria remota DoS (bot dependiente).

Codewhale v0.8.61

Highlights

  • Durable multi-agent runtime — Worker profiles now encode roles, permissions, tools, and model routes with non-escalating child derivation. Durable goals track token/time budgets across turns and require verifier approval before completion; the sidebar reports real worker states and structured needs-input checkpoints instead of a generic “running” status. /swarm now requires this worker substrate. (#3217, #3215, #3226, #3218)
  • Responsive background execution — The multi-agent TUI freeze is fixed by moving input handling off the render thread and coalescing progress events, guarded by a six-worker liveness test. Shell and verifier work now default to background jobs, and idle sub-agent completion resumes the parent automatically; integrations that assumed implicit blocking must explicitly wait. Cancellation also reaches synchronous file tools. (#3216, #3212, #3266, #1791)
  • Explicit model routing and session isolation — Sub-agents can use different providers/models by role, with model_strength and thinking exposed instead of hidden child-model auto-routing—fast models with thinking disabled are a documented fit for exploration. Provider/model state is now session-local, mismatched routes are rejected, and context-window preflight plus bounded recovery prevents context_length_exceeded retry loops. (#2027, #1768, #3227, #3204)
  • CodeWhale migration and paired binaries — codewhale is now the canonical package, command, and release name; deprecated deepseek-tui receives no further releases, so follow docs/REBRAND.md. npm archives install both binaries, but Cargo users must install both codewhale-cli and codewhale-tui; a missing companion fails with MISSING_COMPANION_BINARY. CODEWHALE_HOME is now the primary configuration home. (#2960, #2924, #2917)
  • Changed TUI and plan-mode contracts — Plan mode is strictly read-only, with no shell tools and no investigation shortcuts for repository, URL, version, or code-path requests. Bare keys 1–8 now insert text; hotbar actions require Alt+digit, so existing keyboard workflows need updating. Runtime tags now describe capability posture rather than user-facing mode labels. (#3213, #3243)
  • Broader provider and integration surface — The legacy app-server gains a provider-neutral OpenAI-compatible /v1/chat/completions endpoint with registry resolution and credential forwarding. Provider fixes include normalized Kimi/Moonshot tool schemas, a working Novita default endpoint, and DeepInfra support; ws is pinned to 8.21.0 to address a remote memory-exhaustion DoS. (#3265, #3255, #3235)

CodeWhale is the canonical project, command, npm package, and release-asset name. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Install

Recommended — npm (one command, both binaries)

npm install -g codewhale

The wrapper downloads both binaries from this Release and places them in the same directory.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.61

The image ships the codewhale dispatcher and codewhale-tui runtime. The latest tag is also updated on release.

Cargo (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Both crates are required — codewhale-cli produces the codewhale dispatcher and codewhale-tui produces the interactive runtime that the dispatcher delegates to. Installing only one binary will fail at runtime with a MISSING_COMPANION_BINARY error.

Manual download — platform archives (recommended)

Each archive below contains both the codewhale dispatcher and codewhale-tui runtime, plus an install script:

| Platform | Archive | Install script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (installer) | CodeWhaleSetup.exe | NSIS setup | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portable) | codewhale-windows-x64-portable.zip | — |

Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • For the installer path, run CodeWhaleSetup.exe; it installs both binaries under %LOCALAPPDATA%\Programs\CodeWhale\bin and adds that directory to the current-user PATH.
  • Extract codewhale-windows-x64.zip
  • Run install.bat (copies to %USERPROFILE%\bin)
  • Add %USERPROFILE%\bin to your PATH

The portable Windows archive skips the install script — extract and run from any directory. The NSIS installer is currently unsigned and may trigger Windows SmartScreen until a signing certificate is wired into the release pipeline.

Each platform also has bare, unarchived binaries attached below (codewhale-<platform> and codewhale-tui-<platform>) — these are what the npm wrapper and the in-app codewhale update download, whereas the .tar.gz / .zip archives above are the recommended manual download and additionally bundle an install script. The legacy npm package deepseek-tui is deprecated and is not republished. For migration from v0.8.x legacy binary names, see docs/REBRAND.md.

What's in v0.8.61

This release lands the runtime control plane for multi-agent work: the TUI stays responsive while sub-agents run, sub-agents converge toward fleet-style durable workers with per-role model routing, and provider/model routes are isolated per session. It also folds in several community contributions.

Added

  • WhaleFlow runtime foundations — worker runtime profiles (role / permissions / shell / tools / model-route, with non-escalating child derivation), a cross-provider model registry with offline catalog hydration, and provider-readiness / context-budget / provider-adapter / resource-telemetry services. (#3217, #3071, #3072, #3073)
  • Per-role, heterogeneous-model sub-agent routing — sub-agents can be assigned a model and provider per role (e.g. scout vs. synthesis; verifiers route to a fast model). (#2027, #1768)
  • Durable goal mode — cross-turn goal progress with token/time accounting and a verifier-as-judge gate before a goal may complete. (#3215, #891, #1976, #2058, #2029)
  • Parent-visible worker interaction contract — a recommended action per worker. (#3226)
  • Maintainer GitHub workflow skills; ACP registry submission prepared. (#3192)
  • OpenAI-compatible /v1/chat/completions endpoint on the legacy app-server HTTP transport, provider-neutral, with model registry resolution and configured-credential forwarding.

Changed

  • Sub-agents converge toward fleet-style durable workers — real worker lifecycle states are projected to the sidebar instead of a hardcoded "running", and a sub-agent returns a structured needs-input checkpoint instead of parking. (#3226, #3096, #3154)
  • The per-turn runtime tag exposes capability posture instead of human-facing mode labels. (#3213)
  • Independent shell and verifier work defaults to background jobs with nonblocking waits and a completion notification; blocking now requires an explicit wait. (#3212)
  • Sub-agent launches now expose explicit model_strength and thinking controls to the model instead of hidden child-model auto-routing; explore work is documented as a good fit for faster models and thinking: "off".
  • Plan mode is strictly read-only (no shell tools), consistent with its runtime posture.
  • /swarm is gated behind the durable worker substrate. (#3218)
  • Legacy deepseek install/update path resolves to codewhale. (#2960, #2924, #2917)

Fixed

  • TUI freeze when multiple sub-agents spawn (launch blocker) — the terminal input pump runs off the render thread, AgentProgress events are coalesced, and sub-agents no longer park on input with no orchestrator to answer; a six-worker stress test guards input/render/cancel liveness. (#3216, #3096)
  • Idle sub-agent completion notifications now resume the parent turn instead of waiting for a later user message; thanks @giovanni-paolilla for the deadlock report (#3266).
  • Provider/model route isolation — provider and model state is session-local, and a mismatched provider+model tuple is rejected at the route boundary. (#3227)
  • Route-effective context-window metadata, over-limit preflight, and bounded recovery from context_length_exceeded instead of re-looping. (#3204)
  • Synchronous tools (file_search, grep_files, list_dir) are cancellable and no longer hold a turn open against cancellation. (#1791)
  • MCP stdio proxy startup prompts no longer strand YOLO / non-interactive runs. (#2475)
  • Stalled / failed background-shell recovery; configurable sub-agent API timeout. (#1737, #1786, #1806)
  • Composer: reliable queued steering + Ctrl+S send (#3203, #3224); footer busy/idle indicator (#2982); CJK word-wrap (#963); clickable sidebar stop targets (#3028); live token throughput (#3190); auto-expiring terminal sub-agent cards (#3078).
  • Linux glibc preflight in the installer/update path with a clear error. (#3207, #1067)
  • Self-update retries transient GitHub metadata/asset failures and falls back from the GitHub REST API to the public releases/latest redirect before constructing release asset URLs. (#3232)
  • Provider picker lists providers in neutral alphabetical order instead of hard-coding DeepSeek first; the active provider stays pre-selected. (#3076)
  • Work sidebar no longer shows stale phase now: / phase next: strategy rows once the checklist is 100% complete.
  • Plan mode no longer shortcuts investigation for requests that name a repository, URL, version, release, build state, benchmark, bug, PR, issue, API surface, or local code path.
  • Oversized pasted text stays editable in the composer, with a file backup appended at submit time for model access; thanks @idling11 (#3267, closes #3263).
  • Bare digit keys 1-8 now insert text instead of firing hotbar slots; use Alt+digit for hotbar actions. Thanks @wjq2026 for the report and @DieMoe233 for the paste-path note (#3243).
  • Kimi/Moonshot tool schemas normalize empty function parameters to a root object schema; thanks @jghwwnq for the provider repro (#3265).
  • Novita defaults to its OpenAI-compatible /openai/v1 endpoint so chat completions no longer 404 out of the box; thanks @buko for the report and endpoint verification (#3255).
  • Dependency security: ws pinned to 8.21.0 across npm packages to close remote memory-exhaustion DoS (dependabot).

Community contributions

  • Non-DeepSeek model pricing — thanks @mvanhorn (#3201)
  • Telegram polling transport — thanks @cyq1017 (#3195)
  • Mobile event history — thanks @RobertEmprechtinger (#3220)
  • Runtime-API session save — thanks @gaord (#3199)
  • Whale-accent rename — thanks @nightt5879 (#3197)
  • DEEPSEEK_BASE_URL / MODEL honored in exec — thanks @hongchen1993 (#3221)
  • VS Code read-only API documentation — thanks @cyq1017 (#3013)

  • DeepInfra provider support and release-surface follow-through — thanks @idling11 (#3235, closes #3231) and @nightt5879 (#3236)
