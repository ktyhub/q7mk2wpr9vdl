Código ballena v0.9.10

Codewhale es el producto público de Shannon Labs. El codewhale Los nombres de comando, paquete npm y activos de lanzamiento permanecen en minúsculas técnicas identificadores. El paquete npm heredado deepseek-tui está en desuso y no recibe más comunicados. Usuarios provenientes del legado v0.8.x deepseek / Los nombres deepseek-tui deben migrar con docs/REBRAND.md.

Instalar

Recomendado: npm (un comando, ambos puntos de entrada)

npm install -g codewhale

El contenedor descarga los recursos de comando codewhale y codew coincidentes. de esta versión. Ambos contienen el mismo tiempo de ejecución compilado.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.10

La imagen muestra el mismo tiempo de ejecución que codewhale y codew. el La etiqueta latest también se actualiza en el momento del lanzamiento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

El paquete Cargo instala codewhale. Cargo no puede crear un segundo comando alias de un objetivo binario; los usuarios que quieran una ortografía más corta pueden agregar una Enlace simbólico codew a ese ejecutable instalado. El npm, Homebrew, archivo, El instalador de shell y los canales de contenedor instalan ambos nombres de comando directamente.

  • Para la ruta del instalador, ejecute CodeWhaleSetup.exe; se instala codewhale.exe, codew.exe y codewhale.bat bajo %LOCALAPPDATA%\Programs\CodeWhale\bin, agrega ese directorio al RUTA del usuario actual y crea un acceso directo al menú Inicio que prefiere Terminal de Windows (wt.exe) cuando esté instalado.

Gracias @AiurArtanis y @formp3 por identificar las superficies afectadas.
  • registry_sync ya no incluye el catálogo completo del Registro MCP en el conversación. Toma una consulta requerida, califica la instantánea local del lado anfitrión, y regresa como máximo ocho partidos; el catálogo completo permanece encendido disco, y las exenciones de compactación y derrames que permiten a varios cientos de El volcado de kilobytes llega al modelo sin cambios.
  • Proveedores que reflejan el marcador de posición de repetición saliente (reasoning omitted) De regreso como un delta razonante ya no tengo ese eco ingerido como real. pensando: el marcador de posición de transporte exacto se elimina al llegar, así que vive Las sesiones dejan de mostrar un flujo de bloques de razonamiento de marcador de posición y se guardan. las transcripciones permanecen libres de ellos.
  • Las caídas de conexión a mitad de camino durante un turno interactivo ya no persisten Mensaje de usuario sintético [runtime]. El estado de reintento es un tipo interno del motor. descriptor; una caída que solo piensa vuelve a emitir la solicitud sin reclamar un se conservó la respuesta parcial, el presupuesto de reintento se aplica en el mecanismo y La recuperación produce exactamente una respuesta final autorizada.

Codewhale v0.9.10 es una versión de retención, identidad y claridad del producto: la cáscara y la transcripción ya no puede retener la salida ilimitada de la herramienta en la memoria o en el disco, Las inserciones del historial a mitad de turno ya no dejan varadas las filas de herramientas en vuelo, cada agente que ejecutó esta sesión es visible desde /agents list, la aceptación de PTY El carril tiene un perro guardián de pérdida y pasos de CI limitados, los resultados de aprobación son duradero y cerrado ante fallos (cyq1017, #5360), y se detectan tres fugas de disco $HOME reclamado. Las superficies de extensión ahora nombran su estado real y actúan solo a través de los flujos de instalación y trust revisados, y subagente, shell, tarea, y el estado del flujo de trabajo es propiedad de la sesión que lo creó (#5518). prueba Los subprocesos obtienen una pila de 8 MiB, por lo que la suite lib ya no puede abortar bajo carga.

Fijo

  • La primera ejecución comienza nuevamente en la pantalla de bienvenida. Ya no falta una llave omite la bienvenida y abre automáticamente la lista de proveedores locales: ingrese camina hasta el explicación tranquila del proveedor, luego Enter abre el selector para que aparezca una primera tecla API se puede configurar. Devolver la recuperación de clave faltante aún abre el selector lanzamiento.
  • Se vuelve a limitar un comando bash en primer plano que no nombró ningún tiempo de espera. el La herramienta bash orientada al modelo dejó un timeout_ms omitido en el interior techo (~24.8 días) en lugar de los 120 s predeterminados, su propio esquema anuncia, por lo que un CLI que se bloqueó en un mensaje interactivo o en un mensaje colgado llamada de red mantuvo el turno abierto indefinidamente: un informe se encontraba en un solo llamada CLI no autenticada durante más de dos horas con la fila de herramientas simplemente contando segundos. Ahora se aplica el valor predeterminado anunciado, lo que arma al recuperación existente: el proceso finaliza y se le indica al modelo que se vuelva a ejecutar con background=true y encuesta con action="wait". Un explícito timeout_ms todavía es honrado por su trabajo en primer plano genuinamente largo, y Las ejecuciones interactivas y de fondo mantienen su propia vida útil.
  • El Marketplace de Extensiones (/plugin) ya no es una lista de solo lectura. Cada recomendación y candidato almacenado nombra su estado veraz y acción principal (Agregar, Habilitar, Configurado o No disponible) e Ingresar o un mouse click ejecuta esa acción a través del archivo /mcp add revisado existente recomendado, /mcp enable, and /plugin install/trust controladores, por lo que no existe una segunda ruta trust. Codewhale v0.9.10

Highlights

  • Rebrand and migration path — deepseek-tui is deprecated and gets no further releases; v0.8.x deepseek/deepseek-tui users must follow docs/REBRAND.md, while DEEPSEEK_* env names survive only as 0.9.x compatibility aliases beside the new Codewhale-owned identifiers for build metadata, hook session/tool-call IDs, and sandbox markers (#5443). npm install -g codewhale now wires both codewhale and codew; Cargo installs only codewhale, so add a codew symlink yourself. Watch out: the Windows NSIS installer is unsigned and trips SmartScreen until signing lands.

  • registry_sync is now query-scoped (breaking) — the tool requires a query, scores the on-disk snapshot host-side, and returns at most eight matches instead of shipping the full MCP Registry catalog into the conversation; the compaction/spillover exemptions that let a multi-hundred-kilobyte dump reach the model unchanged are gone. Anything automating against the full catalog will break — rework it around queries, in exchange for a much smaller context footprint.

  • Foreground bash timeout finally matches its schema — an omitted timeout_ms was left at the internal ceiling (~24.8 days) rather than the advertised 120 s, so a CLI hanging on an interactive prompt or unauthenticated call could hold a turn open for hours. The 120 s default now applies and arms the existing recovery (kill the process, rerun with background=true, poll via action="wait"); an explicit timeout_ms is still honored. Long foreground work that relied on the old bug must now set an explicit timeout.

  • Bounded tool-output retention (#5472) — raw streams cap at 16 MiB in flight and release delivered output, and retained tool output is capped at 64 KiB per record / 8 MiB per transcript, fixing cases where a 1.1 MB Bash call stayed resident for over an hour; the three $HOME disk leaks (orphaned session dirs, unbounded audit.log, stranded writer temp files) are also reclaimed. Expect real ceilings now — oversized outputs are truncated in transcripts by design.

  • Session-scoped state and fail-closed approvals (#5518, #5360) — sub-agent handoffs, background shell jobs, durable tasks, delayed continuations, and workflow controls now carry immutable root-session ownership, stale completion-channel payloads are rejected before dedup, and legacy ownerless jobs fail closed; approval receipts are committed to a session-owned log before execution, so unpersistable evidence blocks the tool and resume reconstructs closed/interrupted approvals. This kills multi-session cross-talk but means any persisted state without an owner will stop working.

  • Transport and model-call hardening (#5516, #5518, #4683, #5515) — the resolved route envelope now reaches every outbound call under one wire/reservation budget with provider input limits honored, and switching models on the same protocol no longer inherits the previous model's limits; pre-header HTTP/2/SSE failures get one bounded HTTP/1.1 retry while auth/provider-semantic failures stay fail-closed; mirrored (reasoning omitted) placeholders are dropped instead of being ingested as real thinking, mid-stream drops yield exactly one authoritative final answer without a synthetic [runtime] message, and MCP tools/call images travel as bounded typed content rather than base64 in model-visible JSON.

Codewhale is the public product from Shannon Labs. The codewhale command, npm package, and release-asset names remain lowercase technical identifiers. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Install

Recommended — npm (one command, both entrypoints)

npm install -g codewhale

The wrapper downloads the matched codewhale and codew command assets from this Release. Both contain the same compiled runtime.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.10

The image exposes the same runtime as both codewhale and codew. The latest tag is also updated on release.

Cargo (Linux / macOS)

cargo install codewhale-cli --locked

The Cargo package installs codewhale. Cargo cannot create a second command alias from one binary target; users who want the shorter spelling can add a codew symlink to that installed executable. The npm, Homebrew, archive, shell-installer, and container channels install both command names directly.

What's in v0.9.10

  • Show the full slash-command or /model completion row in a bounded, wrapping hover popover whenever narrow terminals truncate it, closing the remaining scoped gap from #998. Thanks @AiurArtanis and @formp3 for identifying the affected surfaces.
  • registry_sync no longer ships the full MCP Registry catalog into the conversation. It takes a required query, scores the local snapshot host-side, and returns at most eight matches; the complete catalog stays on disk, and the compaction and spillover exemptions that let a multi-hundred- kilobyte dump reach the model unchanged are gone.
  • Providers that mirror the outgoing (reasoning omitted) replay placeholder back as a reasoning delta no longer have that echo ingested as real thinking: the exact transport placeholder is dropped on arrival, so live sessions stop showing a stream of placeholder reasoning blocks and saved transcripts stay free of them.
  • Mid-stream connection drops during an interactive turn no longer persist a synthetic [runtime] user message. Retry state is a typed engine-internal descriptor; a thinking-only drop re-issues the request without claiming a partial reply was preserved, the retry budget is enforced in mechanism, and recovery produces exactly one authoritative final answer.

Codewhale v0.9.10 is a retention, identity, and product-clarity release: the shell and transcript can no longer retain unbounded tool output in memory or on disk, mid-turn history inserts no longer strand in-flight tool rows, every agent that ran this session is visible from /agents list, the PTY acceptance lane has a stall watchdog and bounded CI steps, approval outcomes are durable and fail closed (cyq1017, #5360), and three $HOME disk leaks are reclaimed. Extension surfaces now name their real state and act only through the reviewed install and trust flows, and sub-agent, shell, task, and workflow state is owned by the session that created it (#5518). Test threads get an 8 MiB stack so the lib suite can no longer abort under load.

Fixed

  • First run starts on the welcome screen again. A missing key no longer skips Welcome and auto-opens the local-provider list: Enter walks to the calm provider explanation, then Enter opens the picker so a first API key can be set. Returning missing-key recovery still opens the picker on launch.
  • A foreground bash command that named no timeout is bounded again. The model-facing bash tool left an omitted timeout_ms at the internal ceiling (~24.8 days) instead of the 120 s default its own schema advertises, so a CLI that blocked on an interactive prompt or a hung network call held the turn open indefinitely — one report sat on a single unauthenticated CLI call for over two hours with the tool row simply counting seconds. The advertised default now applies, which arms the existing recovery: the process is killed and the model is told to rerun with background=true and poll with action="wait". An explicit timeout_ms is still honored for genuinely long foreground work, and background and interactive runs keep their own lifetimes.
  • The Extensions (/plugin) Marketplace is no longer a read-only list. Every recommendation and stored candidate names its truthful state and primary action — Add, Enable, Configured, or Unavailable — and Enter or a mouse click runs that action through the existing reviewed /mcp add recommended, /mcp enable, and /plugin install/trust controllers, so no second trust path exists. Browser Use and Sandbox Runtime stay honestly Unavailable with their real setup routing instead of implying an install Codewhale cannot perform.
  • The Extensions MCP tab now renders one honest inventory: the header count and the visible rows derive from the same configured-server set, so MCP (6) can no longer sit above two rendered rows. Disabled servers stay visible and labeled disabled instead of silently disappearing, and configured servers absent from the live snapshot list as not-yet-inspected with their own explicit reload affordance through the MCP command controller.

  • Sub-agent handoffs and rosters, background shell jobs, durable tasks, delayed continuations, and workflow controls are now scoped to the session that owns them. Records carry immutable root-session ownership, stale completion-channel payloads are rejected before deduplication, background work drains and reports only to its owning session, and legacy ownerless jobs fail closed (#5518 failure class reported by @hxfhd; the report's exact JavaScript provenance was not claimed as reproduced).
  • The resolved route envelope now reaches every outbound model call: all wire dialects and auxiliary calls clamp at the shared transport seam under one wire/reservation budget, provider input limits are honored, and switching models on the same protocol no longer inherits the previous model's limits (#5516, #5518).
