código ballena v0.8.57

CodeWhale es el proyecto canónico, el comando, el paquete npm y nombre del activo de liberación. El paquete npm heredado deepseek-tui es está en desuso y no recibe más versiones. Usuarios provenientes de Los nombres deepseek / deepseek-tui heredados de v0.8.x deben migrar con docs/REBRAND.md.

Instalar

Recomendado: npm (un comando, ambos binarios)

npm install -g codewhale

El contenedor descarga ambos archivos binarios de esta versión y los coloca en el mismo directorio.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.57

La imagen incluye el despachador codewhale y el tiempo de ejecución codewhale-tui. La etiqueta latest también se actualiza en el momento del lanzamiento.

Carga (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Se requieren ambas cajas: codewhale-cli produce el despachador codewhale y codewhale-tui produce el tiempo de ejecución interactivo en el que delega el despachador. La instalación de solo un binario fallará en tiempo de ejecución con un error MISSING_COMPANION_BINARY.

Descarga manual: archivos de plataforma (recomendado)

Cada archivo a continuación contiene tanto el despachador codewhale como el tiempo de ejecución codewhale-tui, además de un script de instalación: | Plataforma | Archivo | Instalar script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | MacOS x64 | codewhale-macos-x64.tar.gz | install.sh | | BRAZO macOS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (instalador) | CodeWhaleSetup.exe | Configuración de NSIS | | Ventanas x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portátil) | codewhale-windows-x64-portable.zip | — | Unix (Linux/macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • Para la ruta del instalador, ejecute CodeWhaleSetup.exe; instala ambos binarios en %LOCALAPPDATA%\Programs\CodeWhale\bin y agrega ese directorio a la RUTA del usuario actual.
  • Extracto codewhale-windows-x64.zip
  • Ejecute install.bat (copias a %USERPROFILE%\bin)
  • Añade %USERPROFILE%\bin a tu RUTA El archivo portátil de Windows omite el script de instalación: extráigalo y ejecútelo desde cualquier directorio. El instalador de NSIS actualmente no está firmado y puede activar Windows SmartScreen hasta que se conecte un certificado de firma al proceso de lanzamiento. Los binarios individuales también se adjuntan a continuación para secuencias de comandos y el contenedor npm. El paquete npm heredado deepseek-tui está obsoleto y no se vuelve a publicar. Para la migración desde nombres binarios heredados v0.8.x, consulte docs/REBRAND.md.

¿Qué hay en v0.8.57?

Agregado

  • Los turnos ahora sobreviven a la suspensión del sistema. Cuando el host se suspende a mitad de la transmisión, el la conexión solía morir al activarse con Error de lectura de transmisión: error de decodificación cuerpo de respuesta y se perdió el turno (#2990). El motor ahora estampa corriente progresar con el tiempo tanto monótono como de reloj de pared; una gran divergencia en un El error de transmisión identifica un ciclo de suspensión/activación y la solicitud se realiza de forma silenciosa. reeditado (hasta el presupuesto existente de 3 reintentos) en lugar de fallar el turno.
  • Preparación de lanzamiento con un solo comando. ./scripts/release/prepare-release.sh X.Y.Z aumenta la versión del espacio de trabajo, cada pin de dependencia de la caja interna, el npm contenedor y los ejemplos de etiquetas de instalación README, actualiza Cargo.lock, regenera el segmento TUI changelog incorporado y los datos web, y ejecuta check-versions.sh: el lanzamiento de v0.8.56 necesitaba nueve confirmaciones de seguimiento para exactamente estos puntos de sincronización.
  • .github/CODEOWNERS y .github/dependabot.yml (carga semanal + Actualizaciones de acciones github, npm mensuales para web/).

Cambiado

  • El changelog se puso a dieta. Root CHANGELOG.md ahora incluye datos recientes lanzamientos (v0.8.40+); las entradas más antiguas se trasladaron a docs/CHANGELOG_ARCHIVE.md. crates/tui/CHANGELOG.md, integrado en cada binario para /change, es un segmento generado de 15 versiones (scripts/sync-changelog.sh), ya no es un Copia manual byte por byte de 357 KB (~300 KB binarios más pequeños).
  • Los cuerpos de versión GitHub se generan a partir del changelog de la versión etiquetada. sección (scripts/release/generate-release-body.sh) en lugar de una Blob de flujo de trabajo codificado con una lista de colaboradores pegada a mano.
  • check-versions.sh ahora también controla web/lib/facts.generated.ts y el Ejemplos de etiquetas de instalación README; el canal espejo de CNB valida el envío etiqueta contra Cargo.toml antes de generar release note.
  • Documentos reorganizados: notas de diseño interno movidas a docs/rfcs/; rancio Se eliminaron los documentos internos (auditorías antiguas, transferencias, notas de VM específicas de la región).
  • Pulido de cara al agente: los informes de bloqueo del entorno del indicador del sistema codewhale_version (antes deepseek_version), el legado La ruta .deepseek/instructions.md ya no se anuncia en el mensaje (todavía honrado por la compatibilidad con versiones anteriores), y los archivos de instrucciones de gran tamaño son truncado con un marcador […truncated: N bytes omitted] explícito en su lugar de una elipsis desnuda.

Fijo

  • Las imágenes Docker se compilan nuevamente. El trabajo de lanzamiento de docker falló para v0.8.56 porque el archivo Docker todavía copiaba el deepseek previo al cambio de marca / binarios deepseek-tui; ahora son enlaces simbólicos a los binarios de Codewhale. dentro de la imagen, para que los puntos de entrada de los contenedores heredados sigan funcionando.
  • .devcontainer/devcontainer.json usó el nombre del contenedor previo al cambio de marca, ruta de montaje y usuario remoto deepseek.
  • Ejemplos obsoletos de --bin deepseek, cadenas DeepSeek-TUI en /change resultados y comentarios de documentos previos al cambio de marca.

Eliminado

  • Dependencias no utilizadas: tracing-appender y zeroize (caja TUI), rustls (caja de liberación); el archivo de bloqueo huérfano vendor/schemaui-0.12.0 sobrantes y un scripts/verify_task.sh único y específico para la máquina. Los créditos de los contribuyentes para este lanzamiento se encuentran en la entrada changelog anterior: Gracias a todos cuyos informes, relaciones públicas, reseñas y reproducciones le dieron forma. Consulte CHANGELOG.md para obtener notas completas y docs/CHANGELOG_ARCHIVE.md para versiones anteriores.

Codewhale v0.8.57

Highlights

  • Sleep/wake stream recovery — Turns interrupted by system suspend now detect the wall-clock jump and silently reissue the request within the existing three-retry budget, rather than losing work to a stream decoding error. Retries still consume that budget (#2990).
  • Package and binary migration — codewhale replaces the legacy deepseek / deepseek-tui naming, and deepseek-tui receives no further releases. Update install scripts and automation; Cargo users must install both codewhale-cli and codewhale-tui, since a lone binary fails with MISSING_COMPANION_BINARY. See docs/REBRAND.md.
  • One-command release preparation — ./scripts/release/prepare-release.sh X.Y.Z synchronizes workspace versions, internal dependency pins, the npm wrapper, README examples, Cargo.lock, embedded changelog data, and generated web facts before running version checks. GitHub release bodies are now generated from the tagged changelog, reducing the manual sync failures seen in v0.8.56.
  • Smaller TUI binaries — The embedded /change history is now a generated 15-release slice instead of a 357 KB manual copy, reducing binaries by roughly 300 KB. Older history remains available in docs/CHANGELOG_ARCHIVE.md.
  • Container compatibility restored — Docker images again build after the rebrand: legacy deepseek / deepseek-tui entrypoints are preserved as symlinks, while devcontainer names, mounts, and users are corrected. The Windows NSIS installer remains unsigned, so SmartScreen warnings are still possible.
  • Agent context changes — The system prompt now reports codewhale_version instead of deepseek_version; update tooling that parses this field. Oversized instruction files receive an explicit truncation marker, while the legacy .deepseek/instructions.md path remains supported for backward compatibility.

CodeWhale is the canonical project, command, npm package, and release-asset name. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Install

Recommended — npm (one command, both binaries)

npm install -g codewhale

The wrapper downloads both binaries from this Release and places them in the same directory.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.57

The image ships the codewhale dispatcher and codewhale-tui runtime. The latest tag is also updated on release.

Cargo (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Both crates are required — codewhale-cli produces the codewhale dispatcher and codewhale-tui produces the interactive runtime that the dispatcher delegates to. Installing only one binary will fail at runtime with a MISSING_COMPANION_BINARY error.

Manual download — platform archives (recommended)

Each archive below contains both the codewhale dispatcher and codewhale-tui runtime, plus an install script:

| Platform | Archive | Install script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (installer) | CodeWhaleSetup.exe | NSIS setup | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portable) | codewhale-windows-x64-portable.zip | — |

Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • For the installer path, run CodeWhaleSetup.exe; it installs both binaries under %LOCALAPPDATA%\Programs\CodeWhale\bin and adds that directory to the current-user PATH.
  • Extract codewhale-windows-x64.zip
  • Run install.bat (copies to %USERPROFILE%\bin)
  • Add %USERPROFILE%\bin to your PATH

The portable Windows archive skips the install script — extract and run from any directory. The NSIS installer is currently unsigned and may trigger Windows SmartScreen until a signing certificate is wired into the release pipeline.

Individual binaries are also attached below for scripting and the npm wrapper. The legacy npm package deepseek-tui is deprecated and is not republished. For migration from v0.8.x legacy binary names, see docs/REBRAND.md.

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt

What's in v0.8.57

Added

  • Turns now survive system sleep. When the host suspends mid-stream, the connection used to die on wake with Stream read error: error decoding response body and the turn was lost (#2990). The engine now stamps stream progress with both monotonic and wall-clock time; a large divergence on a stream error identifies a sleep/wake cycle, and the request is silently re-issued (up to the existing 3-retry budget) instead of failing the turn.
  • One-command release prep. ./scripts/release/prepare-release.sh X.Y.Z bumps the workspace version, every internal crate dependency pin, the npm wrapper, and the README install-tag examples, refreshes Cargo.lock, regenerates the embedded TUI changelog slice and web facts, and runs check-versions.sh — the v0.8.56 release needed nine follow-up commits for exactly these sync points.
  • .github/CODEOWNERS and .github/dependabot.yml (weekly cargo + github-actions updates, monthly npm for web/).

Changed

  • The changelog went on a diet. Root CHANGELOG.md now carries recent releases (v0.8.40+); older entries moved to docs/CHANGELOG_ARCHIVE.md. crates/tui/CHANGELOG.md — embedded into every binary for /change — is a generated 15-release slice (scripts/sync-changelog.sh), no longer a 357 KB manual byte-for-byte copy (~300 KB smaller binaries).
  • GitHub Release bodies are generated from the tagged version's changelog section (scripts/release/generate-release-body.sh) instead of a hardcoded workflow blob with a hand-pasted contributor list.
  • check-versions.sh now also gates web/lib/facts.generated.ts and the README install-tag examples; the CNB mirror pipeline validates the pushed tag against Cargo.toml before generating release notes.
  • Docs reorganized: internal design notes moved under docs/rfcs/; stale internal docs (old audits, handoffs, region-specific VM notes) removed.
  • Agent-facing polish: the system prompt environment block reports codewhale_version (was deepseek_version), the legacy .deepseek/instructions.md path is no longer advertised in the prompt (still honored for back-compat), and oversized instruction files are truncated with an explicit […truncated: N bytes omitted] marker instead of a bare ellipsis.

Fixed

  • Docker images build again. The release docker job failed for v0.8.56 because the Dockerfile still copied the pre-rebrand deepseek / deepseek-tui binaries; they are now symlinks to the codewhale binaries inside the image, so legacy container entrypoints keep working.
  • .devcontainer/devcontainer.json used the pre-rebrand container name, mount path, and deepseek remote user.
  • Stale --bin deepseek examples, DeepSeek-TUI strings in /change output, and pre-rebrand doc comments.

Removed

  • Unused dependencies: tracing-appender and zeroize (TUI crate), rustls (release crate); the orphaned vendor/schemaui-0.12.0 lockfile leftover and a machine-specific one-off scripts/verify_task.sh.

Contributor credits for this release live in the changelog entry above — thank you to everyone whose reports, PRs, reviews, and reproductions shaped it.

See CHANGELOG.md for full notes and docs/CHANGELOG_ARCHIVE.md for older releases.
