Características

  • Se agregaron chips encima del compositor de Web Shell para flujos de trabajo en segundo plano, shells, monitores y agentes locales sin terminar, reemplazando la píldora de tareas de la barra de estado. (#16813) por @qqqys
  • Se agregó localización en chino para mensajes de eventos del canal GitHub en sesiones vinculadas a relaciones públicas cuando el idioma de la interfaz de usuario del canal es chino, mientras que otros idiomas siguen siendo inglés. (#16773) por @wenshao
  • El MCP administrado ahora cuenta solo hasta 32 selecciones en vivo, retiene las entradas eliminadas para recuperación, mantiene el límite habilitado de 16 y limita las instantáneas retenidas a 96 entradas. (#15161) por @yiliang114
  • Se agregaron SPI de agente administrado que permiten que las aplicaciones integradas importen revisiones exactas de habilidades o extensiones de fuentes externas y almacenen archivos compilados en un almacenamiento privado. (#16882) por @doudouOUC
  • Permite a los Mods reescribir las filas de respuesta mostradas en el terminal OpenTUI a través de ui.render mientras conserva el texto del mensaje almacenado y la salida de copia. (#16873) por @qqqys
  • Registra los estados de las solicitudes de extracción de listados reducidos y pasa sus claves al reloj para que las solicitudes de extracción cerradas puedan dejar la rotación de visualización correctamente. (#16847) por @wenshao
  • Agrega un canal dingtalk-webhook de solo envío que publica notificaciones y resultados de tareas exitosas como Markdown para los robots de grupo personalizados de DingTalk configurados. (#16802) por @jkxiao
  • Las listas de sesiones de la barra lateral ahora amplían diez sesiones por click, con etiquetas que muestran el recuento restante, en lugar de mostrarlas todas a la vez. (#16830) por @wenshao
  • Las sesiones administradas ahora almacenan recursos de gran tamaño y diarios cerrados compactados en el almacenamiento de objetos, preservando la recuperación y las lecturas normales. (#16868) por @doudouOUC
  • Agrega primitivas internas de bus de eventos para el bucle de agente unificado sin cambiar el comportamiento actual. (#16935) por @wenshao
  • Agrega la configuración del webhook de DingTalk en Web Shell y permite que las tareas programadas elijan destinos de canales guardados. (#16804) por @jkxiao
  • Permite que los hosts integrados agreguen encabezado y contenido por modelo al selector de modelos del compositor, preservando al mismo tiempo la búsqueda, la selección y el comportamiento del teclado nativos. (#16933) por @callmeYe
  • Agrega la opción AgentLoopOptions.useEventBus para ejecutar el bucle de agente compartido en los controladores de bus de eventos sin cambiar el comportamiento observable. (#16938) por @wenshao
  • El flujo de espacio aislado/verificar ahora profundiza el proceso de pago para incluir el historial base y de relaciones públicas necesario antes de la verificación, lo que mejora el manejo de las notificaciones forzadas y las confirmaciones faltantes. (#16781) por @wenshao
  • Hazaña (cli): habilita el bucle del agente de bus de eventos sin cabeza detrás de una configuración experimental (#16994) por @wenshao
  • Cuando experimental.unifiedAgentLoop está habilitado, las rondas del modelo AgentCore ahora se ejecutan a través del bucle de agente compartido. (#16880) por @qqqys
  • hazaña (flujos de trabajo): permitir ejecuciones en segundo plano solicitadas por el modelo en sesiones ACP (#16876) por @qqqys
  • Hazaña (núcleo): ejecutar lotes de herramientas de AgentCore en el bucle de agente compartido (#17035) por @qqqys
  • hazaña: enlace PR de sesión manual (comando/pr + cuadro de diálogo Web Shell) (#16877) por @wenshao
  • Los lectores de diarios de agentes administrados ahora resuelven los registros desalojados de los paquetes de diarios, lo que habilita qwen.managed-agent.session-resources.deletion-enabled. (#17047) por @doudouOUC
  • Las sesiones administradas ahora almacenan activaciones de bucle/a su propio ritmo de forma duradera en el diario de la sesión para que sobrevivan a los reinicios y las tomas de control. (#16835) por @wenshao

qwen-code v0.27.3

<!-- qwen-release-notes:v1 -->

Highlights

See the complete change list below.

Breaking Changes

No known breaking changes.

Complete Change List

Features

  • Added chips above the Web Shell composer for unfinished background workflows, shells, monitors, and local agents, replacing the status-bar task pill. (#16813) by @qqqys
  • Added Chinese localization for GitHub channel event prompts in PR-bound sessions when the channel UI language is Chinese, while other languages remain English. (#16773) by @wenshao
  • Managed MCP now counts only up to 32 live selections, retains removed entries for recovery, keeps the 16-enabled limit, and caps retained snapshots at 96 entries. (#15161) by @yiliang114
  • Added managed-agent SPIs that let embedding applications import exact Skill or extension revisions from external sources and store compiled archives in private storage. (#16882) by @doudouOUC
  • Enables Mods to rewrite displayed reply rows in the OpenTUI terminal via ui.render while preserving stored message text and /copy output. (#16873) by @qqqys
  • Records pull request states from slim listings and passes their keys to the watch so closed pull requests can leave view rotation correctly. (#16847) by @wenshao
  • Adds a sending-only dingtalk-webhook channel that posts notifications and successful task results as Markdown to configured DingTalk custom group robots. (#16802) by @jkxiao
  • Sidebar session lists now expand ten sessions per click, with labels showing remaining count, instead of showing all at once. (#16830) by @wenshao
  • Managed Sessions now store oversized resources and compacted closed journals in object storage, preserving recovery and normal reads. (#16868) by @doudouOUC
  • Adds internal event-bus primitives for the unified agent loop without changing current behavior. (#16935) by @wenshao
  • Adds DingTalk webhook configuration in Web Shell and lets Scheduled Tasks pick saved Channel destinations. (#16804) by @jkxiao
  • Lets embedding hosts add header and per-model content to the composer model picker while preserving native search, selection, and keyboard behavior. (#16933) by @callmeYe
  • Adds opt-in AgentLoopOptions.useEventBus to run the shared agent loop on event-bus handlers without changing observable behavior. (#16938) by @wenshao
  • The sandboxed /verify flow now deepens the checkout to include the PR and base history needed before verification, improving handling of force-pushes and missing commits. (#16781) by @wenshao
  • feat(cli): enable the event-bus agent loop on headless behind an experimental setting (#16994) by @wenshao
  • When experimental.unifiedAgentLoop is enabled, AgentCore model rounds now run through the shared agent loop. (#16880) by @qqqys
  • feat(workflows): allow model-requested background runs in ACP sessions (#16876) by @qqqys
  • feat(core): run AgentCore's tool batches on the shared agent loop (#17035) by @qqqys
