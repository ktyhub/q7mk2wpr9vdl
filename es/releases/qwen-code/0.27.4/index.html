código qwen v0.27.4

<!-- qwen-notas-de-lanzamiento:v1 -->

Destacados

  • Las sesiones del agente administrado pueden acceder a directorios locales otorgados y abrir una terminal web administrada interactiva sin credenciales ni rutas persistentes. (#16844, #16866)
  • Envíe resultados a webhooks Feishu y WeCom, con respuestas largas de canal administrado entregadas como segmentos ordenados en lugar de truncarse. (#17012, #17013, #17223, #17224, #17002)
  • El modo automático ahora requiere autorización explícita para acciones riesgosas, revisa los tiempos de espera del clasificador, evita búsquedas en el sistema de archivos URL HTTP(S) y marca visiblemente el acceso total. (#16858, #17127, #17146, #17100)
  • La página de objetivos de Web Shell puede fusionar objetivos de espacios de trabajo trusted, mostrar insignias de espacios de trabajo y apuntar a un espacio de trabajo seleccionado al crear objetivos. (#17230)
  • Administre la memoria con controles de memoria/CLI restaurados, configuraciones de espacio de trabajo persistentes y SDK API escritos para obtener una vista previa, enviar, inspeccionar, cancelar y volver a intentar las importaciones de memoria del Codex. (#17162, #17213)
  • Las pestañas de terminal, las vistas previas web, los comandos locales y los comandos de barra siguen funcionando a través de HTTP simple cuando la compatibilidad con UUID nativo no está disponible. (#17196)

Cambios importantes

No se conocen cambios importantes.

qwen-code v0.27.4

<!-- qwen-release-notes:v1 -->

Highlights

  • Managed Agent sessions can access granted local directories and open an interactive Managed Web Terminal without persisting credentials or paths. (#16844, #16866)
  • Send outputs to Feishu and WeCom webhooks, with long managed-channel replies delivered as ordered segments instead of being truncated. (#17012, #17013, #17223, #17224, #17002)
  • Auto Mode now requires explicit authorization for risky actions, reviews classifier timeouts, avoids HTTP(S) URL filesystem lookups, and visibly marks Full Access. (#16858, #17127, #17146, #17100)
  • Web Shell Goals page can merge goals from trusted workspaces, show workspace badges, and target a selected workspace when creating goals. (#17230)
  • Manage memory with restored CLI /memory controls, persistent workspace settings, and typed SDK APIs to preview, submit, inspect, cancel, and retry Codex memory imports. (#17162, #17213)
  • Terminal tabs, web previews, local commands, and slash commands keep working over plain HTTP when native UUID support is unavailable. (#17196)

Breaking Changes

No known breaking changes.

Complete Change List

Features

  • Managed Agent sessions can use the browser user's local filesystem through temporary directory grants, without persisting credentials or paths. (#16844) by @wenshao
  • Long managed-channel replies are split into ordered delivery segments instead of being truncated, with a visible truncation notice if the segment limit is exceeded. (#17002) by @wenshao
  • With experimental.unifiedAgentLoop enabled, each AgentCore round runs model and tool batch in one runAgentLoop call, optionally on the event-bus kernel. (#17059) by @qqqys
  • feat(cli): run each OpenTUI round in one runAgentLoop call (#17104) by @qqqys
  • feat(channels): add Feishu custom bot webhook delivery (#17012) by @jkxiao
  • Auto Mode now lets the session model review a fast-classifier timeout once when identifiers differ, allowing or blocking the action under existing policy. (#17146) by @callmeYe
  • Exposes a typed workspace-bound SDK API for previewing, submitting, inspecting, canceling, and retrying Codex memory imports. (#17162) by @callmeYe
  • Runs each Ink TUI round in one runAgentLoop call when experimental.unifiedAgentLoop is enabled, aligning TUI loop execution. (#17160) by @qqqys
  • Adds per-turn Hook execution records, read-only Hook pages, SDK access, summaries, and signed snapshots for session history. (#17015) by @callmeYe
  • Makes cancelled runs publish loop.cancelled and finish within a 10-second bound, preserving completed batch results when possible. (#17145) by @qqqys
  • Adds a send-only Feishu Webhook connection method with secret URL, optional signing secret, channel control, and scheduled group delivery. (#17013) by @jkxiao
  • Adds nightly E2E loop rollout legs for kernel and OpenTUI, including forced parity arms, while push runs keep their current legs. (#17050) by @wenshao
  • Enables the serve daemon's PR-state watch to observe and deliver PR updates promptly by provisioning its dependencies and adding resume delivery. (#17032) by @wenshao
  • Improves web-shell session search with a dedicated centered dialog, clearer results, keyboard selection, loading and retry states, and responsive layouts. (#16779) by @deggs7
  • Adds an interactive Managed Web Terminal to Managed Agent sessions, using a short-lived ticket for authenticated WebSocket access and keeping the runtime active while attached. (#16866) by @wenshao
  • feat(managed-agent): fixed-interval /loop schedules for Managed Sessions (#17088) by @wenshao
  • With experimental.unifiedAgentLoop enabled, each ACP round runs in one runAgentLoop call; experimental.eventBusAgentLoop uses the event-bus kernel. (#17181) by @qqqys
  • When experimental.unifiedAgentLoop is enabled, speculation model rounds now use the shared agent loop; otherwise behavior is unchanged. (#17029) by @wenshao
  • Experimental loop switches now resolve per surface and can be forced on or off by environment overrides such as 1, 0, or headless,acp=0. (#17055) by @wenshao
  • Adds a send-only WeCom group webhook Channel that can deliver Notify outputs, prompt results, and supported scheduled-task results to a configured WeCom group. (#17223) by @jkxiao
  • Adds a send-only WeCom Webhook connection method with group URL configuration, channel control, and scheduled delivery selection. (#17224) by @jkxiao
  • Makes PR watch operator-owned by adding the operator-only serve.sessionPrWatch setting and retiring GitHub channel state-transition delivery. (#17214) by @wenshao

  • Adds experimental.unifiedAgentLoop hosted surface so Hosted Harness model rounds can use the shared agent loop while the legacy path remains default. (#17264) by @wenshao
