código qwen v0.28.4

<!-- qwen-notas-de-lanzamiento:v2 -->

Destacados

  • El modo demonio local de Web Shell agrega una página de biblioteca de artefactos en el espacio de trabajo con escaneo progresivo y actualizaciones de transmisión. (#18071)
  • El chat Web Shell agrega una ChatSurface compartida, insignias de Continuar, fichas de sugerencias y correcciones de diseño móvil para las sesiones. (#17952, #18044, #17918, #17883, #18011)
  • Core agrega valores predeterminados de razonamiento integrados en Gemini 4. (#18039)
  • Local Runtime ahora crea su directorio de estado en el proceso de generación con permisos privados del propietario. (#17964)
  • La migración de comandos crea destinos Markdown exclusivamente y conserva el TOML original en conflictos de destino. (#17873)
  • Las extensiones ahora cargan manifiestos guardados con una lista de materiales UTF-8. (#15786)

Cambios importantes

No se conocen cambios importantes.

Carcasa web

Mejora la experiencia de chat de Web Shell con continuación de sesión, exploración de artefactos, diseño móvil, chips de sugerencias y señales de estado más claras.

  • web-shell: mantener móvil Enviar teclado de software anterior (#17883)
  • Agrega un chip de sugerencias que se puede tocar en los compositores de Web Shell para que los usuarios táctiles puedan insertar y editar sugerencias de seguimiento antes de enviarlas. (#17918)
  • Web Shell ahora genera reescrituras Mod de filas de pensamiento expandidas mientras conserva el pensamiento almacenado original y la línea de pensamiento Listo colapsada. (#17920)
  • web-shell: actualiza el logotipo de la barra lateral para el tema oscuro (#17935)
  • Web Shell agrega una columna de chat ChatSurface compartida que muestra la transcripción, las aprobaciones, las preguntas y el compositor del estado de la sesión. (#17952)
  • web-shell: mensajes de activación automática compactos (#17970)
  • Proporciona más espacio a los títulos de sesión en dispositivos móviles y de escritorio al mover acciones de fila opcionales al menú Más. (#18011)
  • La barra lateral de Web Shell ahora muestra una insignia Continuar para las sesiones cuyo último turno fue interrumpido y necesita continuación. (#18044)
  • web-shell: el alcance de la admisión de ChatSurface se bloquea en la sesión propietaria y vincula loadOlder (#18066)
  • web-shell: alinea el estado de desplazamiento de la sesión con las señales de estado de la fila (#18070)
  • Agrega la página de la biblioteca de artefactos del espacio de trabajo en el modo demonio local de Web Shell, con escaneo progresivo y actualizaciones de transmisión. (#18071)
  • web-shell: usa color continuo para trabajo activo (#18072)

Agente administrado y arnés alojado

Corrige carreras de sesiones alojadas, configuración de verificación previa, permisos, canales de telemetría e identificadores de almacenamiento para entornos de agentes administrados.

  • agente administrado: cierra los recursos con nombres de registros config_install (#17468)
  • Se corrige una carrera de arnés alojada al usar un candado al construir, cerrar y adoptar el client construido de manera perezosa. (#17961)
  • La verificación previa del agente administrado ahora trata un espacio de trabajo en blanco cwd como no configurado en lugar de usar el directorio de trabajo actual, y los documentos ahora coinciden con las reglas del directorio de estado enviado. (#17965)
  • Los dispositivos de verificación previa duraderos ahora saltan claramente cuando no se puede resolver a nadie, usan permisos 0755 explícitos y los documentos aclaran las expectativas de propiedad del usuario del servicio. (#18020)
  • Agrega un valor de canal de telemetría administrado client para que las sesiones del agente administrado se puedan distinguir del tráfico de demonio ordinario. (#18022)
  • Los objetos OSS de agente administrado ahora usan identificadores legibles de inquilino, espacio de trabajo y sesión en claves, lo que hace que el contenido del depósito sea más fácil de inspeccionar. (#18048)

Modelos y tiempo de ejecución principal

Actualiza la migración de comandos, los permisos de estado de tiempo de ejecución local, la recuperación de resultados de herramientas, el rendimiento de la transcripción y los valores predeterminados de razonamiento de Gemini 4.

  • La migración de comandos ahora crea destinos Markdown exclusivamente y conserva el TOML original cuando existe un conflicto de destino. (#17873)
  • núcleo: proteger la recuperación de salida de herramienta persistente (#17875)
  • Almacena en caché los índices de transcripción de gran tamaño en una clase delimitada separada para que los índices grandes ya no bloqueen la retención de enlaces de sesiones pequeñas. (#17910)
  • Crea el directorio de estado de tiempo de ejecución local en el proceso de generación con permisos privados del propietario en lugar de durante la creación del proveedor. (#17964)
  • núcleo: agrega valores predeterminados de razonamiento integrados de Gemini 4 (#18039)

Extensiones y canales

Mejora la carga del manifiesto de extensión y el manejo de la actividad del canal ACP para agentes ocupados.

  • extensiones: cargar manifiestos de extensión guardados con una lista de materiales UTF-8 (#15786)
  • Permite que la actividad del canal ACP trate a los agentes ocupados como saludables por más tiempo y registre evidencia cuando los canales están cerrados. (#18028)

Sesiones y aprobaciones

  • Los documentos ahora indican que la ejecución de sesiones interactivas detecta automáticamente los cambios de mcpServers, y el reinicio se mantiene solo como alternativa para la resolución de problemas. (#17743)
  • servir: refinar las aprobaciones del espacio de trabajo create_sub_session (#17863)

Evidencia de reparación automática

Elimina los caracteres de control del terminal y las anulaciones Unicode Bidi de la evidencia de verificación fallida de Autofix antes de su visualización.

  • La evidencia de verificación fallida de corrección automática ahora elimina los caracteres de control del terminal y las anulaciones de Unicode Bidi de los extractos del registro antes de su visualización. (#16748)

qwen-code v0.28.4

<!-- qwen-release-notes:v2 -->

Highlights

  • Web Shell local daemon mode adds a workspace artifact library page with progressive scanning and streaming updates. (#18071)
  • Web Shell chat adds a shared ChatSurface, Continue badges, suggestion chips, and mobile layout fixes for sessions. (#17952, #18044, #17918, #17883, #18011)
  • Core adds built-in Gemini 4 reasoning defaults. (#18039)
  • Local Runtime now creates its state directory at process spawn with owner-private permissions. (#17964)
  • Command migration creates Markdown destinations exclusively and preserves the original TOML on destination conflicts. (#17873)
  • Extensions now load manifests saved with a UTF-8 BOM. (#15786)

Breaking Changes

No known breaking changes.

Web Shell

Improves the Web Shell chat experience with session continuation, artifact browsing, mobile layout, suggestion chips, and clearer status cues.

  • web-shell: keep mobile Send above software keyboard (#17883)
  • Adds a tappable suggestion chip in Web Shell composers so touch users can insert and edit follow-up suggestions before sending. (#17918)
  • Web Shell now renders Mod rewrites of expanded thinking rows while preserving the original stored thought and collapsed Done thinking line. (#17920)
  • web-shell: update sidebar logo for dark theme (#17935)
  • Web Shell adds a shared ChatSurface chat column that renders transcript, approvals, questions, and composer from session state. (#17952)
  • web-shell: compact automatic trigger messages (#17970)
  • Gives session titles more space on mobile and desktop by moving optional row actions into the More menu. (#18011)
  • Web Shell sidebar now shows a Continue badge for sessions whose last turn was interrupted and needs continuation. (#18044)
  • web-shell: scope ChatSurface admission locks to the owning session and bind loadOlder (#18066)
  • web-shell: align session hover status with the row's status cues (#18070)
  • Adds the workspace artifact library page in Web Shell local daemon mode, with progressive scanning and streaming updates. (#18071)
  • web-shell: use running color for active work (#18072)

Managed Agent and Hosted Harness

Fixes hosted session races, preflight configuration, permissions, telemetry channels, and storage identifiers for Managed Agent environments.

  • managed-agent: close over the resources a config_install record names (#17468)
  • Fixes a Hosted Harness race by using one lock when building, closing, and adopting the lazily built client. (#17961)
  • Managed-agent preflight now treats a blank workspace-cwd as unconfigured instead of using the current working directory, and docs now match shipped state-directory rules. (#17965)
  • Durable preflight fixtures now skip cleanly when nobody cannot be resolved, use explicit 0755 permissions, and docs clarify service-user ownership expectations. (#18020)
  • Adds a managed telemetry client-channel value so Managed Agent sessions can be distinguished from ordinary daemon traffic. (#18022)
  • Managed-agent OSS objects now use readable tenant, workspace, and session identifiers in keys, making bucket contents easier to inspect. (#18048)

Core runtime and models

Updates command migration, local Runtime state permissions, tool-output recovery, transcript performance, and Gemini 4 reasoning defaults.

  • Command migration now creates Markdown destinations exclusively and preserves the original TOML when a destination conflict exists. (#17873)
  • core: protect persisted tool-output recovery (#17875)
  • Caches oversized transcript indexes in a separate bounded class so large indexes no longer block small-session hook retention. (#17910)
  • Creates the local Runtime state directory at process spawn with owner-private permissions instead of during provider creation. (#17964)
  • core: add built-in Gemini 4 reasoning defaults (#18039)

Extensions and channels

Improves extension manifest loading and ACP channel liveness handling for busy agents.

  • extensions: load extension manifests saved with a UTF-8 BOM (#15786)
  • Lets ACP channel liveness treat busy agents as healthy longer and records evidence when channels are closed. (#18028)

Sessions and approvals

  • Docs now state that running interactive sessions automatically pick up mcpServers changes, with restart kept only as a troubleshooting fallback. (#17743)
  • serve: refine create_sub_session workspace approvals (#17863)

Autofix evidence

Strips terminal control characters and Unicode Bidi overrides from Autofix failed-check evidence before display.

  • Autofix failed-check evidence now strips terminal control characters and Unicode Bidi overrides from log excerpts before display. (#16748)

Other Changes

  • ci: use live review bot for manual re-review (#17848)
  • Stabilizes the required Managed Agent check name as Managed Agent gate and prevents skipped or no-suite review runs from overwriting real results. (#17865)
  • Replaces the receipt-catalog SpotBugs exclusion with an explicit assertion while keeping the HTTP 400 contract for missing receipt bytes unchanged. (#17919)
  • Updates identity de-hash design docs to correct workspace and storage budgets and record duplicate-key constraints before VARCHAR conversion. (#17960)
  • Makes RocketMQ stop checks wait for listeners to clear instead of immediately rebinding ports, reducing flaky CI failures. (#17967)
  • Release retries can resume after a partial publish by reusing a matching release branch and publishing remaining packages; divergent same-version trees are still rejected. (#17951)
  • Managed-agent identity storage removes redundant same-row hash key columns and rebuilds affected unique keys and indexes on raw identity columns without changing column order. (#18019)
  • ci: isolate verify scratch in runner temp (#17879)
  • web-shell: deliver per-turn assistant feedback to telemetry (#18021)
  • refactor(managed-agent): drop dead and redundant schema objects (#18041)
  • test(channels): make four managed DingTalk witnesses exclude what they claim (#17968)
  • CI verification now fails clearly when the scratch directory is not prepared instead of silently using shared OS temp space. (#18040)
  • The DingTalk recent-window cap test timeout is raised to 120 seconds and pinned to reduce flaky CI failures. (#17837)
  • The CLI restart-recovery crash test now waits for transcript and partial-response state before killing the daemon. (#18049)
  • Documentation now proposes a read-only workspace artifact library page for Web Shell local daemon mode. (#18036)
  • Adds bilingual design documentation for managed-agent Action parking in stateless Hosted Harness Phase 4. (#18047)
  • Marks the workspace artifact library design as accepted but not yet implemented in bilingual documentation. (#18063)
  • Restores green CI builds by updating the document export renderer size budget for ChatSurface copy. (#18067)
  • Fixes nightly desktop release checks by re-pinning the RHEL 10 rpm build root to a current CentOS Stream 10 digest. (#18069)
  • Fixes macOS e2e tests for qwen serve assistant feedback telemetry by using real workspace transcript paths. (#18074)
  • test(managed-agent): gate the four durable existing-dir preflight tests to Linux (#18076)
  • refactor(managed-agent): move publication OSS scope naming to the contract (#18085)
  • test(integration): deflake the SIGKILL restart-recovery case (#18055) (#18057)
  • test(cli): deflake the admitted-mutation idle-timer case (#18053) (#18056)
  • Updates design docs to mark the automatic-trigger message as landed and align renderer-budget history with implemented behavior. (#18080)
  • Makes self-hosted Java CI jobs rebuild a writable job-local Maven repository and safely fall back when cache reuse fails. (#18065)
