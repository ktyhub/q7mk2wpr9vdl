Agente Hermes v0.21.7

Fecha de lanzamiento: 11 de octubre de 2026

Lanzamiento del parche. Esta etiqueta agrupa los ~204 PR fusionados desde v0.21.6 en una versión estable para la aplicación de escritorio (macOS Apple Silicon, Windows), Microsoft Store y MSIX, el instalador, Docker y Hermes Cloud. Notas seleccionadas completas para este barco de ventana con v0.22.0.

<!-- HERMES_BUILDS_TABLE -->

Lo que incluye este parche para las instalaciones de origen (hermes update y el actualizador de la aplicación de escritorio en una compra de git):

  • Las actualizaciones ahora siguen a las versiones etiquetadas. Una instalación fuente del repositorio oficial actualiza la última versión publicada de vX.Y.Z en lugar de cada confirmación en main. Una instalación que ya es más reciente que la última versión permanece donde está y espera la siguiente; nada se mueve hacia atrás. Para seguir siguiendo cada confirmación: hermes update --set-channel main. Las horquillas y los espejos siguen a main. Las instalaciones de tienda, MSIX y de escritorio incluidas no se modifican.
  • Elija el canal en la aplicación de escritorio. Configuración ▸ Acerca de ▸ Actualizaciones tiene un interruptor Actualizar canal (Versiones estables/Cada confirmación) para instalaciones de origen, y el cuadro de diálogo de actualización ahora muestra en qué canal se encuentra.
  • El razonamiento sobrevive al currículum. Las repeticiones de pensamiento firmadas después de hermes chat --resume y en el siguiente turno de entrada, y los modelos de razonamiento de Bedrock Converse ya no se rechazan en las sesiones reanudadas.
  • Las actualizaciones ya no fallan detrás de algunos firewalls. Las instalaciones en main ya no obtienen un registro de versión que los firewalls regionales podrían responder con 403. La verificación estable utiliza su token GitHub cuando hay uno configurado (GITHUB_TOKEN o gh auth login) e informa un límite de tasa GitHub como límite de tasa.

Acerca de esta versión

Medida en la confirmación 1fd18277267152893a8a24792b79213e7ca3f899, la ventana desde v0.21.6 contiene 740 confirmaciones sin fusión en 4,156 archivos modificados (+86,775 / −26,980), 204 PR fusionados y 69 problemas cerrados.

También en la ventana, no documentados aquí a propósito: complementos que ejecutan acciones integradas en la aplicación de escritorio (ctx.runAction) y un complemento de burbuja mascota SDK (ctx.pet.say); solicitudes de Codex creadas centralmente para que los complementos nunca retengan el token; habilidades instaladas a mitad de sesión para llegar al modelo sin una reconstrucción inmediata; Krea 2 Medium Turbo como línea de imagen predeterminada para nuevos suscriptores pagos, con un respaldo FAL cuando Krea administrada rechaza una solicitud; actualizaciones de escritorio más rápidas (el paso del compilador React se almacena en caché por contenido, el renderizador compilado se reutiliza cuando solo se cambia el sello de instalación, las entradas nativas sin cambios se dejan en su lugar); instalaciones fijadas que verifican solo el pin; marcas de compactación emitidas al Relevo; y nuevos complementos comunitarios que incluyen Memory-Shield, Command-ledger, Memoria, Model Router, Wyoming-voice-bridge, Codex-Account-Switch y Redline.

Los release note completamente seleccionados para esta ventana se envían con v0.22.0, que documentarán todo desde v0.21.0 en adelante: aspectos destacados, áreas destacadas y créditos completos de los contribuyentes. No se omite nada en esta ventana.

hermes-agent v0.21.7

Hermes Agent v0.21.7

Release Date: October 11, 2026

Patch release. This tag rolls up the ~204 PRs merged since v0.21.6 into a stable release for the desktop app (macOS Apple silicon, Windows), the Microsoft Store and MSIX, the installer, Docker and Hermes Cloud. Full curated notes for this window ship with v0.22.0.

<!-- HERMES_BUILDS_TABLE -->

What this patch ships for source installs (hermes update and the desktop app's updater on a git checkout):

  • Updates now follow tagged releases. A source install of the official repository updates to the latest published vX.Y.Z release instead of every commit on main. An install already newer than the latest release stays where it is and waits for the next one; nothing is moved back. To keep following every commit: hermes update --set-channel main. Forks and mirrors keep following main. Store, MSIX and bundled desktop installs are unchanged.
  • Choose the channel in the desktop app. Settings ▸ About ▸ Updates has an Update channel switch (Stable releases / Every commit) for source installs, and the update dialog now shows which channel you are on.
  • Reasoning survives resume. Signed thinking replays after hermes chat --resume and on the next gateway turn, and Bedrock Converse reasoning models no longer get rejected on resumed sessions.
  • Updates no longer fail behind some firewalls. Installs on main no longer fetch a release record that regional firewalls could answer with 403. The stable check uses your GitHub token when one is set (GITHUB_TOKEN or gh auth login) and reports a GitHub rate limit as a rate limit.

About this release

Measured at commit 1fd18277267152893a8a24792b79213e7ca3f899, the window since v0.21.6 contains 740 non-merge commits across 4,156 changed files (+86,775 / −26,980), 204 merged PRs and 69 closed issues.

Also in the window, undocumented here on purpose: plugins running built-in Desktop app actions (ctx.runAction) and a plugin SDK pet bubble (ctx.pet.say); core-made Codex requests so plugins never hold the token; skills installed mid-session reaching the model without a prompt rebuild; Krea 2 Medium Turbo as the default image lane for new paid subscribers, with a FAL fallback when managed Krea refuses a request; faster desktop updates (the React Compiler pass cached by content, the compiled renderer reused when only the install stamp changed, unchanged native inputs left in place); pinned installs that check out only the pin; compaction marks emitted to Relay; and new community plugins including memory-shield, command-ledger, Memoria, Model Router, wyoming-voice-bridge, codex-account-switch and redline.

Full curated release notes for this window ship with v0.22.0, which will document everything from v0.21.0 onward — highlights, feature areas, and complete contributor credits. Nothing in this window is skipped.

Updating

  • Desktop app: updates itself. Microsoft Store installs update through the Store.
  • CLI: hermes update, or re-run the installer one-liner.
  • Docker / Hermes Cloud: nousresearch/hermes-agent:stable (or :latest).
