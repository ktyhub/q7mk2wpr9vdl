agente-hermes v2026.4.23

Agente Hermes v0.11.0 (v2026.4.23)

Fecha de lanzamiento: 23 de abril de 2026 Desde v0.9.0: 1,556 confirmaciones · 761 RP fusionados · 1,314 archivos modificados · 224,174 inserciones · 29 contribuyentes de la comunidad (290 incluidos los coautores)

El lanzamiento de la interfaz: una reescritura completa de React/Ink del CLI interactivo, una arquitectura de transporte conectable debajo de cada proveedor, soporte nativo de AWS Bedrock, cinco nuevas rutas de inferencia, una plataforma de mensajería número 17 (QQBot), una superficie de complementos dramáticamente ampliada y GPT-5.5 a través de Codex OAuth. Esta versión también incluye todos los aspectos destacados diferidos de v0.10.0 (que solo envió Nous Tool Gateway), por lo que cubre aproximadamente dos semanas de trabajo en toda la pila.

✨ Destacados

  • Nueva TUI basada en tinta: hermes --tui es ahora una reescritura completa de React/Ink del CLI interactivo, con un backend Python JSON-RPC (tui_gateway). Compositor pegajoso, transmisión en vivo con soporte para tablero OSC-52 cli, teclas de selección estables, barra de estado con cronómetro por turno y rama git, confirmación /clear, preajuste de tema claro y una superposición de observabilidad de generación de subagente. ~310 se compromete a ui-tui/ + tui_gateway/. (@OutThisLife + Teknio)
  • Transporte ABC + AWS Bedrock nativo: la conversión de formato y el transporte HTTP se extrajeron de run_agent.py a una capa agent/transports/ conectable. AnthropicTransport, ChatCompletionsTransport, ResponsesApiTransport y BedrockTransport poseen cada uno su propia conversión de formato y forma API. El soporte nativo de AWS Bedrock a través de Converse API se suma a la nueva abstracción. (#10549, #13347, #13366, #13430, #13805, #13814 — @kshitijk4poor + Teknium)
  • Cinco nuevas rutas de inferencia: NVIDIA NIM nativo (#11774), Arcee AI (#9276), Plan de pasos (#13893), Google Gemini CLI OAuth (#11270) y Vercel ai-gateway con precios + descubrimiento dinámico (#13223 - @jerilynzheng). Además, Gemini se enruta a través del AI Studio API nativo para un mejor rendimiento (#12674).
  • GPT-5.5 sobre Codex OAuth: el nuevo modelo de razonamiento GPT-5.5 de OpenAI ahora está disponible a través de ChatGPT Codex OAuth, con descubrimiento de modelos en vivo conectado al selector de modelos para que las nuevas versiones de OpenAI aparezcan sin actualizaciones del catálogo. (#14720)
  • QQBot — 17.ª plataforma compatible — Adaptador QQBot nativo a través de QQ Official API v2, con asistente de configuración de escaneo para configuración de QR, cursor de transmisión, reacciones emoji y control de políticas de DM/grupo que coincide con la paridad WeCom/Weixin. (#9364, #11831)
  • Superficie de complemento ampliada: los complementos ahora pueden registrar comandos de barra (register_command), enviar herramientas directamente (dispatch_tool), bloquear la ejecución de herramientas desde ganchos (pre_tool_call puede vetar), reescribir resultados de herramientas (transform_tool_result), transformar la salida del terminal (transform_terminal_output), enviar backends image_gen y agregar pestañas de panel personalizadas. El complemento de limpieza de disco incluido está habilitado de forma predeterminada como implementación de referencia. (#9377, #10626, #10763, #10951, #12929, #12944, #12972, #13799, #14175)
  • /steer: empujones del agente en mitad de la ejecución: /steer <prompt> inyecta una nota que el agente en ejecución ve después de su siguiente llamada a la herramienta, sin interrumpir el turno ni romper el caché de avisos. Para cuando desee corregir el rumbo de un agente durante el vuelo. (#12116)
  • Enganches de Shell: conecte cualquier script de Shell como un gancho de ciclo de vida de Hermes (pre_tool_call, post_tool_call, on_session_start, etc.) sin escribir un complemento Python. (#13296)
  • Modo de entrega directa de Webhook: las suscripciones a Webhook ahora pueden reenviar cargas útiles directamente a un chat de plataforma sin pasar por el agente: notificaciones push sin LLM para alertas, comprobaciones de tiempo de actividad y transmisiones de eventos. (#12473)
  • Delegación más inteligente: los subagentes ahora tienen una función orchestrator explícita que puede generar sus propios trabajadores, con max_spawn_depth configurable (plano predeterminado). Los subagentes hermanos simultáneos comparten el estado del sistema de archivos a través de una capa de coordinación de archivos para que no obstaculicen las ediciones de los demás. (#13691, #13718)
  • Modelos auxiliares: interfaz de usuario configurable + modelo principal primero: hermes model tiene una pantalla dedicada "Configurar modelos auxiliares" para anulaciones por tarea (compresión, visión, búsqueda de sesiones, generación de títulos). El enrutamiento auto ahora se enruta de forma predeterminada al modelo principal para tareas secundarias entre todos los usuarios (anteriormente, los usuarios del agregador eran enrutados silenciosamente a un valor predeterminado económico del lado del proveedor). (#11891, #11900)
  • Sistema de complemento del panel de control + cambio de tema en vivo: el panel web ahora es extensible. Los complementos de terceros pueden agregar pestañas, widgets y vistas personalizados sin bifurcarse. Junto con un sistema de temas de cambio en vivo (los temas ahora controlan los colores, las fuentes, el diseño y la densidad) para que los usuarios puedan cambiar la apariencia del tablero en caliente sin tener que volver a cargarlo. Misma disciplina temática que tiene el CLI, ahora en la web. (#10951, #10687, #14725)
  • Pulido del panel: i18n (inglés + chino), diseño de barra lateral de enrutador de reacción, capacidad de respuesta móvil, implementación de Vercel, seguimiento de llamadas API reales por sesión y botones de reinicio de puerta de enlace y actualización one-click. (#9228, #9370, #9453, #10686, #13526, #14004 — @austinpickett + @DeployFaith + Teknium)

Hermes Agent v0.11.0 (v2026.4.23)

Release Date: April 23, 2026 Since v0.9.0: 1,556 commits · 761 merged PRs · 1,314 files changed · 224,174 insertions · 29 community contributors (290 including co-authors)

The Interface release — a full React/Ink rewrite of the interactive CLI, a pluggable transport architecture underneath every provider, native AWS Bedrock support, five new inference paths, a 17th messaging platform (QQBot), a dramatically expanded plugin surface, and GPT-5.5 via Codex OAuth.

This release also folds in all the highlights deferred from v0.10.0 (which shipped only the Nous Tool Gateway) — so it covers roughly two weeks of work across the whole stack.

✨ Highlights

  • New Ink-based TUI — hermes --tui is now a full React/Ink rewrite of the interactive CLI, with a Python JSON-RPC backend (tui_gateway). Sticky composer, live streaming with OSC-52 clipboard support, stable picker keys, status bar with per-turn stopwatch and git branch, /clear confirm, light-theme preset, and a subagent spawn observability overlay. ~310 commits to ui-tui/ + tui_gateway/. (@OutThisLife + Teknium)

  • Transport ABC + Native AWS Bedrock — Format conversion and HTTP transport were extracted from run_agent.py into a pluggable agent/transports/ layer. AnthropicTransport, ChatCompletionsTransport, ResponsesApiTransport, and BedrockTransport each own their own format conversion and API shape. Native AWS Bedrock support via the Converse API ships on top of the new abstraction. (#10549, #13347, #13366, #13430, #13805, #13814 — @kshitijk4poor + Teknium)

  • Five new inference paths — Native NVIDIA NIM (#11774), Arcee AI (#9276), Step Plan (#13893), Google Gemini CLI OAuth (#11270), and Vercel ai-gateway with pricing + dynamic discovery (#13223 — @jerilynzheng). Plus Gemini routed through the native AI Studio API for better performance (#12674).

  • GPT-5.5 over Codex OAuth — OpenAI's new GPT-5.5 reasoning model is now available through your ChatGPT Codex OAuth, with live model discovery wired into the model picker so new OpenAI releases show up without catalog updates. (#14720)

  • QQBot — 17th supported platform — Native QQBot adapter via QQ Official API v2, with QR scan-to-configure setup wizard, streaming cursor, emoji reactions, and DM/group policy gating that matches WeCom/Weixin parity. (#9364, #11831)

  • Plugin surface expanded — Plugins can now register slash commands (register_command), dispatch tools directly (dispatch_tool), block tool execution from hooks (pre_tool_call can veto), rewrite tool results (transform_tool_result), transform terminal output (transform_terminal_output), ship image_gen backends, and add custom dashboard tabs. The bundled disk-cleanup plugin is opt-in by default as a reference implementation. (#9377, #10626, #10763, #10951, #12929, #12944, #12972, #13799, #14175)

  • /steer — mid-run agent nudges — /steer <prompt> injects a note that the running agent sees after its next tool call, without interrupting the turn or breaking prompt cache. For when you want to course-correct an agent in-flight. (#12116)

  • Shell hooks — Wire any shell script as a Hermes lifecycle hook (pre_tool_call, post_tool_call, on_session_start, etc.) without writing a Python plugin. (#13296)

  • Webhook direct-delivery mode — Webhook subscriptions can now forward payloads straight to a platform chat without going through the agent — zero-LLM push notifications for alerting, uptime checks, and event streams. (#12473)

  • Smarter delegation — Subagents now have an explicit orchestrator role that can spawn their own workers, with configurable max_spawn_depth (default flat). Concurrent sibling subagents share filesystem state through a file-coordination layer so they don't clobber each other's edits. (#13691, #13718)

  • Auxiliary models — configurable UI + main-model-first — hermes model has a dedicated "Configure auxiliary models" screen for per-task overrides (compression, vision, session_search, title_generation). auto routing now defaults to the main model for side tasks across all users (previously aggregator users were silently routed to a cheap provider-side default). (#11891, #11900)

  • Dashboard plugin system + live theme switching — The web dashboard is now extensible. Third-party plugins can add custom tabs, widgets, and views without forking. Paired with a live-switching theme system — themes now control colors, fonts, layout, and density — so users can hot-swap the dashboard look without a reload. Same theming discipline the CLI has, now on the web. (#10951, #10687, #14725)

  • Dashboard polish — i18n (English + Chinese), react-router sidebar layout, mobile-responsive, Vercel deployment, real per-session API call tracking, and one-click update + gateway restart buttons. (#9228, #9370, #9453, #10686, #13526, #14004 — @austinpickett + @DeployFaith + Teknium)
