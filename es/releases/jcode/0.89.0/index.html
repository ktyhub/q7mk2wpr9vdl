jcode v0.89.0

Entrada de voz integrada, subprogramas de agente y una línea de estado de sesión fijada

Destacados

  • Entrada de voz integrada para el CLI, con captura de micrófono nativa en macOS y Windows y vocabulario de dictado con reconocimiento de codificación
  • La línea de estado de la sesión (directorio, rama, estado de git, contexto, proveedor y modelo) permanece fijada debajo de la entrada, con widgets de información que muestran los detalles detrás de ella.
  • Los agentes pueden mostrar subprogramas interactivos y los enjambres pueden enviarse mensajes entre sí con etiquetas únicas.

Mejoras

  • El widget de Cambios enumera primero los archivos sucios más nuevos con recuentos de líneas y marca los archivos que editó el agente.
  • Las herramientas MCP se cargan a través de la carga diferida nativa del proveedor, por lo que agregar o usar servidores MCP ya no arruina el caché de mensajes.
  • Las cuentas tienen un grupo de cambio automático persistente y la conmutación por error rota en el orden elegido.
  • Muestra una tarjeta de actualización y asignaciones de funciones diarias cuando se alcanza el límite del plan Jcode
  • El demonio detecta errores de caché de KV y los informa a cada client
  • Las sesiones sin título reciben el nombre de su primer mensaje y las etiquetas guardadas nombran la sesión.
  • Mantenga su posición de lectura a través de cambios de tamaño de terminal
  • Admite comandos de barra diagonal integrados y múltiples en un solo mensaje
  • El primer Ctrl+C borra la entrada y el segundo sale.
  • Agregar transformadores de entrada previos a la herramienta
  • Agregue el proveedor Yolo-Auto, grok-4.7 y grok-4.6 en Cursor y soporte de imágenes OpenRouter desde el catálogo de modelos.
  • Bloquea el modo de suspensión con cierre de tapa en macOS y Windows mientras las sesiones están funcionando
  • Los Rust y TypeScript SDK admiten identidades SSH por conexión y claves de host fijadas

Correcciones

  • Las cuentas de consumidores de Antigravity ya no llegan a 429 desde el punto final incorrecto
  • Los límites de uso de Claude se comparten entre procesos y mantienen los últimos valores buenos cuando se aceleran
  • Los servidores MCP ya no detienen el inicio ni generan duplicados, y las solicitudes pendientes fallan cuando se cierra un servidor stdio
  • La recarga sale con un error cuando el nuevo servidor nunca está listo
  • El cambio de modelos se valida con el proveedor de destino y los modelos predeterminados configurados con un prefijo de proveedor coinciden correctamente
  • El chip de esfuerzo sigue los cambios del modelo y la sugerencia de entrada alternativa respeta el modo de cola y los conflictos del mapa de teclas.
  • Ctrl+Arriba en el historial de mensajes mantiene tu borrador
  • Los ganchos nunca muestran una ventana de consola en Windows
  • Los modelos DeepSeek Flash y MiMo v2.6 mantienen su ventana de contexto completa changelog completo: https://github.com/1jehuang/jcode/compare/v0.88.0...v0.89.0

jcode v0.89.0

Built-in voice input, agent applets, and a pinned session status line

Highlights

  • Built-in voice input for the CLI, with native microphone capture on macOS and Windows and coding-aware dictation vocabulary
  • The session status line (directory, branch, git status, context, provider, and model) stays pinned below the input, with info widgets showing the detail behind it
  • Agents can show interactive applets, and swarms can message each other across swarms with unique labels

Improvements

  • The Changes widget lists dirty files newest first with line counts and marks the files the agent edited
  • MCP tools load through provider-native deferred loading, so adding or using MCP servers no longer busts the prompt cache
  • Accounts have a persistent auto-switch pool, and failover rotates through it in your chosen order
  • Show an upgrade card and daily feature allowances when a Jcode plan limit is reached
  • The daemon detects KV cache misses and reports them to every client
  • Untitled sessions are named after their first prompt, and save labels name the session
  • Keep your reading position across terminal resizes
  • Support embedded and multiple slash commands in one message
  • The first Ctrl+C clears the input and the second quits
  • Add pre-tool input transformers
  • Add the Yolo-Auto provider, grok-4.7 and grok-4.6 on Cursor, and OpenRouter image support from the model catalog
  • Block lid-close sleep on macOS and Windows while sessions are working
  • Rust and TypeScript SDKs support per-connection SSH identities and pinned host keys

Fixes

  • Antigravity consumer accounts no longer hit 429s from the wrong endpoint
  • Claude usage limits are shared across processes and keep the last good values when throttled
  • MCP servers no longer stall startup or spawn duplicates, and pending requests fail when a stdio server exits
  • Reload exits with an error when the new server never becomes ready
  • Switching models validates against the target provider, and configured default models with a provider prefix match correctly
  • The effort chip follows model changes, and the alternate-enter hint respects queue mode and keymap conflicts
  • Ctrl+Up into prompt history keeps your draft
  • Hooks never flash a console window on Windows
  • DeepSeek Flash and MiMo v2.6 models keep their full context window

Full changelog: https://github.com/1jehuang/jcode/compare/v0.88.0...v0.89.0
