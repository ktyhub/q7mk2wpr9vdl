La opción de almacenamiento BanyanDB está lista para gran escala

BanyanDB es una base de datos de SkyWalking nativa que se centra completamente en los casos de uso de SkyWalking. BanyanDB demuestra un potencial significativo para mejorar el rendimiento y optimizar la utilización de recursos. En escenarios de implementación típicos que involucran alrededor de 200 servicios y más de 200 llamadas por segundo, un clúster configurado con 2 nodos de enlace y 2 nodos de datos, cada uno equipado con 4 vCPU y 8 GB de memoria, ofrece un rendimiento estable y eficiente. BanyanDB también admite muestreo de seguimiento completo, proporcionando capacidades de recopilación de seguimiento de hasta el 100%, lo que garantiza una observabilidad integral sin comprometer la estabilidad del sistema.

Nuevo modelo de seguimiento en BanyanDB

Optimicé la implementación del modelo Trace para BanyanDB 0.9.0, reduciendo significativamente la frecuencia de consultas entre OAP y BanyanDB. Se introdujeron nuevas vistas de consultas basadas en las últimas funciones de consulta, lo que redujo en gran medida la latencia de la página.

BanyanDB Storage Option is large-scale ready

BanyanDB is a native-built SkyWalking database that focuses entirely on SkyWalking use cases. BanyanDB demonstrates significant potential in improving performance and optimizing resource utilization. In typical deployment scenarios involving around 200 services and 200+ calls per second, a cluster configured with 2 liaison nodes and 2 data nodes—each equipped with 4 vCPUs and 8 GB memory—delivers stable and efficient performance. BanyanDB also supports full tracing sampling, providing trace collection capabilities up to 100%, ensuring comprehensive observability without compromising system stability.

New Trace Model in BanyanDB

Optimized the Trace model implementation for BanyanDB 0.9.0, significantly reducing query frequency between OAP and BanyanDB. Introduced new query views based on the latest query features, greatly reducing page latency.
