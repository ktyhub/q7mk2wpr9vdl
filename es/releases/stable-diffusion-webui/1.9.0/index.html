difusión-estable-webui v1.9.0

##1.9.0

Características:

  • Realice el cambio de refinador según los pasos de tiempo del modelo en lugar de los pasos de muestreo (#14978)
  • agregar una opción para tener una vista de directorio de estilo antiguo en lugar de una vista de árbol; cambios estilísticos para controles adicionales de clasificación/búsqueda de red
  • agregar interfaz de usuario para reordenar las devoluciones de llamadas, soporte para especificar el orden de las devoluciones de llamadas en los metadatos de la extensión (#15205)
  • Programador uniforme Sgm para modelos SDXL-Lightning (#15325)
  • Selección del programador en la interfaz de usuario principal (#15333, #15361, #15394)

Menor:

  • El botón "abrir directorio de imágenes" ahora abre el directorio real (#14947)
  • Soporta inferencia con redes LyCORIS BOFT (#14871, #14973)
  • hacer que la descripción de la tarjeta de red adicional sea texto sin formato de forma predeterminada, con una opción para volver a habilitar HTML como estaba
  • controlador de cambio de tamaño para redes adicionales (#15041)
  • argumentos cmd: --unix-filenames-sanitization y --filenames-max-length (#15031)
  • mostrar parámetros de redes adicionales en la tabla HTML en lugar de JSON sin formato (#15131)
  • Agregue soporte DoRA (descomposición de peso) para LoRA/LoHa/LoKr (#15160, #15283)
  • Agregue los argumentos cmd '--no-prompt-history' para deshabilitar el historial de solicitudes de última generación (#15189)
  • actualizar la vista previa en Reemplazar vista previa (#15201)
  • solo recupera actualizaciones para las ramas de git activas de las extensiones (#15233)
  • poner una interfaz de usuario de posprocesamiento de lujo en un acordeón (#15223)
  • Admite arrastrar y soltar URL para leer texto informativo (#15262)
  • utilizar la biblioteca diskcache para el almacenamiento en caché (#15287, #15299)
  • Permitir PNG-RGBA para la pestaña Extras (#15334)
  • Admite imágenes de portada integradas en metadatos de tensores de seguridad (#15319)
  • interrupción más rápida cuando se utiliza NN exclusivo (#15380)
  • Escalador de extras: un campo de entrada para limitar la longitud lateral máxima de la imagen de salida (#15293, #15415, #15417, #15425)
  • agregue una opción para ocultar las opciones de posprocesamiento en la pestaña Extras

Extensiones y API:

  • ResizeHandleRow: permite anular el parámetro de escala de columna (#15004)
  • llamar a script_callbacks.ui_settings_callback antes; corrige la extensión incorporada de la sección de opciones adicionales que mata la interfaz de usuario si se usa una configuración que no existe
  • hace posible utilizar zoom.js fuera del contexto webui (#15286, #15288)
  • permitir variantes para el nombre de la extensión en metadata.ini (#15290)
  • hacer que la recarga de scripts de UI sea opcional al realizar Reload UI, y esté desactivada de forma predeterminada
  • poner solicitud: gr.Request al inicio de la función img2img similar a txt2img
  • open_folder como utilidad (#15442)
  • hace posible importar archivos de script de extensiones como import scripts.<filename> (#15423)

Rendimiento:

  • optimización del rendimiento para páginas HTML de redes adicionales
  • optimización para filtrado de redes adicionales
  • optimización para clasificación de redes adicionales

Corrección de errores:

  • evita que el botón de escape provoque una interrupción cuando aún no se ha realizado ninguna generación
  • [error] evitar doble escalado en inpaint (#14966)
  • Posible solución para el botón de recarga que no aparece en algunos casos para redes adicionales.
  • solución: el parámetro split_threshold no funciona cuando se ejecutan imágenes divididas de gran tamaño (#15006)
  • Se corrigió la visibilidad del controlador de cambio de tamaño para el diseño vertical (móvil) (#15010)
  • Register_tmp_file también para mtime (#15012)
  • Proteger alphas_cumprod durante el cambio de refinador (#14979)
  • Se corrigió la orientación EXIF en la carga de imágenes API (#15062)
  • Solo anula el énfasis si realmente se usa en el mensaje (#15141)
  • Se corrigió el texto informativo de énfasis que faltaba en params.txt (#15142)
  • corregir extract_style_text_from_prompt #15132 (#15135)
  • Se corrigió Soft Inpaint para AnimateDiff (#15148)
  • atención de edición: anule la selección de los espacios en blanco circundantes (#15178)
  • tarea: arreglar la fuente no cargada (#15183)
  • use clasificación natural en redes adicionales al ordenar por ruta
  • Corrige errores del sistema lora integrado causados por torch.nn.MultiheadAttention (#15190)
  • Evitar error de Ninguno en get_learned_conditioning (#15191)
  • Agregar entrada a MassFileLister después de escribir metadatos (#15199)
  • soluciona el problema con los estilos cuando se utiliza el mensaje Contratar (#15269, #15276)
  • Elimina los comentarios de las contrataciones y corrige el mensaje (#15263)
  • Hacer que el navegador de detectores de eventos del visor de imágenes sea coherente (#15261)
  • Se corrigió AttributeError en OFT al intentar obtener el peso de MultiheadAttention (#15260)
  • Agregar .mean() faltante nuevamente (#15239)
  • Se corrigió el botón "Restaurar progreso" (#15221)
  • corrige la configuración de interfaz de usuario para InputAccordion [custom_script_source] (#15231)
  • manija 0 rueda deltaY (#15268)
  • impedir el menú alternativo para Firefox (#15267)
  • corrección: corrige errores de sintaxis (#15179)
  • restaurar ruta de salidas (#15307)
  • Escape del nombre de archivo btn_copy_path (#15316)
  • Se corrigieron botones de redes adicionales cuando el nombre de archivo contiene un apóstrofo (#15331)
  • corchetes de escape en el generador de mensajes aleatorios lora (#15343)
  • corrección: versión Python verifica la compatibilidad de instalación de PyTorch (#15390)
  • corregir error tipográfico en call_queue.py (#15386)
  • solución: cuando encuentre el modelo ya cargado, elimine el cargado por índice de matriz (#15382)
  • corrección de errores menores en la gestión de memoria del modelo SD (#15350)
  • Corregir el peso de CodeFormer (#15414)
  • Solución: Eliminar devoluciones de llamada de script enorder_callbacks_map (#15428)
  • corrige la escritura de archivos limitada (gracias, Sylwia)
  • Se corrigió el error de imagen extra única API que no se escalaba (#15465)
  • error al manejar los invocables de paste_field (#15470)

Hardware:

  • Agregar soporte de capacitación y cambiar lspci para Ascend NPU (#14981)
  • Actualización a ROCm5.7 y PyTorch (#14820)
  • Mejor solución para Navi1, eliminando --pre para Navi3 (#15224)
  • Página wiki de Ascend NPU (#15228)

Otro:

  • Actualice el comentario para el mensaje de Pad/mensaje negativo v0 para agregar una advertencia sobre el truncamiento, haga que anule la implementación v1
  • admite columnas de tamaño variable para pantalla táctil (tabletas) (#15002)
  • Corrección #14591 usando contenido traducido para hacer mapeo de categorías (#14995)

stable-diffusion-webui v1.9.0

1.9.0

Features:

  • Make refiner switchover based on model timesteps instead of sampling steps (#14978)
  • add an option to have old-style directory view instead of tree view; stylistic changes for extra network sorting/search controls
  • add UI for reordering callbacks, support for specifying callback order in extension metadata (#15205)
  • Sgm uniform scheduler for SDXL-Lightning models (#15325)
  • Scheduler selection in main UI (#15333, #15361, #15394)

Minor:

  • "open images directory" button now opens the actual dir (#14947)
  • Support inference with LyCORIS BOFT networks (#14871, #14973)
  • make extra network card description plaintext by default, with an option to re-enable HTML as it was
  • resize handle for extra networks (#15041)
  • cmd args: --unix-filenames-sanitization and --filenames-max-length (#15031)
  • show extra networks parameters in HTML table rather than raw JSON (#15131)
  • Add DoRA (weight-decompose) support for LoRA/LoHa/LoKr (#15160, #15283)
  • Add '--no-prompt-history' cmd args for disable last generation prompt history (#15189)
  • update preview on Replace Preview (#15201)
  • only fetch updates for extensions' active git branches (#15233)
  • put upscale postprocessing UI into an accordion (#15223)
  • Support dragdrop for URLs to read infotext (#15262)
  • use diskcache library for caching (#15287, #15299)
  • Allow PNG-RGBA for Extras Tab (#15334)
  • Support cover images embedded in safetensors metadata (#15319)
  • faster interrupt when using NN upscale (#15380)
  • Extras upscaler: an input field to limit maximul side length for the output image (#15293, #15415, #15417, #15425)
  • add an option to hide postprocessing options in Extras tab

Extensions and API:

  • ResizeHandleRow - allow overriden column scale parametr (#15004)
  • call script_callbacks.ui_settings_callback earlier; fix extra-options-section built-in extension killing the ui if using a setting that doesn't exist
  • make it possible to use zoom.js outside webui context (#15286, #15288)
  • allow variants for extension name in metadata.ini (#15290)
  • make reloading UI scripts optional when doing Reload UI, and off by default
  • put request: gr.Request at start of img2img function similar to txt2img
  • open_folder as util (#15442)
  • make it possible to import extensions' script files as import scripts.<filename> (#15423)

Performance:

  • performance optimization for extra networks HTML pages
  • optimization for extra networks filtering
  • optimization for extra networks sorting

Bug Fixes:

  • prevent escape button causing an interrupt when no generation has been made yet
  • [bug] avoid doble upscaling in inpaint (#14966)
  • possible fix for reload button not appearing in some cases for extra networks.
  • fix: the split_threshold parameter does not work when running Split oversized images (#15006)
  • Fix resize-handle visability for vertical layout (mobile) (#15010)
  • register_tmp_file also for mtime (#15012)
  • Protect alphas_cumprod during refiner switchover (#14979)
  • Fix EXIF orientation in API image loading (#15062)
  • Only override emphasis if actually used in prompt (#15141)
  • Fix emphasis infotext missing from params.txt (#15142)
  • fix extract_style_text_from_prompt #15132 (#15135)
  • Fix Soft Inpaint for AnimateDiff (#15148)
  • edit-attention: deselect surrounding whitespace (#15178)
  • chore: fix font not loaded (#15183)
  • use natural sort in extra networks when ordering by path
  • Fix built-in lora system bugs caused by torch.nn.MultiheadAttention (#15190)
  • Avoid error from None in get_learned_conditioning (#15191)
  • Add entry to MassFileLister after writing metadata (#15199)
  • fix issue with Styles when Hires prompt is used (#15269, #15276)
  • Strip comments from hires fix prompt (#15263)
  • Make imageviewer event listeners browser consistent (#15261)
  • Fix AttributeError in OFT when trying to get MultiheadAttention weight (#15260)
  • Add missing .mean() back (#15239)
  • fix "Restore progress" button (#15221)
  • fix ui-config for InputAccordion [custom_script_source] (#15231)
  • handle 0 wheel deltaY (#15268)
  • prevent alt menu for firefox (#15267)
  • fix: fix syntax errors (#15179)
  • restore outputs path (#15307)
  • Escape btn_copy_path filename (#15316)
  • Fix extra networks buttons when filename contains an apostrophe (#15331)
  • escape brackets in lora random prompt generator (#15343)
  • fix: Python version check for PyTorch installation compatibility (#15390)
  • fix typo in call_queue.py (#15386)
  • fix: when find already_loaded model, remove loaded by array index (#15382)
  • minor bug fix of sd model memory management (#15350)
  • Fix CodeFormer weight (#15414)
  • Fix: Remove script callbacks in ordered_callbacks_map (#15428)
  • fix limited file write (thanks, Sylwia)
  • Fix extra-single-image API not doing upscale failed (#15465)
  • error handling paste_field callables (#15470)

Hardware:

  • Add training support and change lspci for Ascend NPU (#14981)
  • Update to ROCm5.7 and PyTorch (#14820)
  • Better workaround for Navi1, removing --pre for Navi3 (#15224)
  • Ascend NPU wiki page (#15228)

Other:

  • Update comment for Pad prompt/negative prompt v0 to add a warning about truncation, make it override the v1 implementation
  • support resizable columns for touch (tablets) (#15002)
  • Fix #14591 using translated content to do categories mapping (#14995)
  • Use absolute path for normalized filepath (#15035)
  • resizeHandle handle double tap (#15065)
  • --dat-models-path cmd flag (#15039)
  • Add a direct link to the binary release (#15059)
  • upscaler_utils: Reduce logging (#15084)
  • Fix various typos with crate-ci/typos (#15116)
  • fix_jpeg_live_preview (#15102)
  • [alternative fix] can't load webui if selected wrong extra option in ui (#15121)
  • Error handling for unsupported transparency (#14958)
  • Add model description to searched terms (#15198)
  • bump action version (#15272)
  • PEP 604 annotations (#15259)
  • Automatically Set the Scale by value when user selects an Upscale Model (#15244)
  • move postprocessing-for-training into builtin extensions (#15222)
  • type hinting in shared.py (#15211)
  • update ruff to 0.3.3
  • Update pytorch lightning utilities (#15310)
  • Add Size as an XYZ Grid option (#15354)
  • Use HF_ENDPOINT variable for HuggingFace domain with default (#15443)
  • re-add update_file_entry (#15446)
  • create_infotext allow index and callable, re-work Hires prompt infotext (#15460)
  • update restricted_opts to include more options for --hide-ui-dir-config (#15492)
