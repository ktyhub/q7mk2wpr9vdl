coredns v1.15.0

Esta versión mejora el almacenamiento en caché, el reenvío y la confiabilidad del transporte de DNS. con correcciones para el manejo de caché obsoleto, conexiones ascendentes, correcciones de fallos/carreras, así como mejoras de bastantes complementos. El reenvío ahora admite flujos ascendentes de DNS sobre QUIC. Las nuevas características adicionales incluyen registro de consultas JSON opcional, actualizaciones de DNS dinámicas RFC 2136 autenticadas, soporte SIIT, plantillas expr-lang y metadatos del protocolo PROXY v2. La versión está construida con Go 1.27.3, que cubre CVE-2026-56865, CVE-2026-56864, CVE-2026-33818, CVE-2026-97032, CVE-2026-78659, CVE-2026-97031 y CVE-2026-111943, junto con otras correcciones de seguridad.

coredns v1.15.0

This release improves DNS caching, forwarding, and transport reliability, with fixes for stale-cache handling, upstream connections, crashes/race fixes, as well as enhancemence from quite a few plugins.

Forwarding now supports DNS-over-QUIC upstreams. Additional new features include optional JSON query logging, authenticated RFC 2136 dynamic DNS updates, SIIT support, expr-lang templates, and PROXY protocol v2 metadata.

The release is built with Go 1.27.3, covering CVE-2026-56865, CVE-2026-56864, CVE-2026-33818, CVE-2026-97032, CVE-2026-78659, CVE-2026-97031, and CVE-2026-111943, along with other security fixes.
