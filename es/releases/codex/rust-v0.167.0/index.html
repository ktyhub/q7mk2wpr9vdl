códice rust-v0.167.0

Nuevas funciones

  • Abra el centro de comando del agente con codex agents --no-daemon. El centro de comando y el selector de sesiones ahora marcan los resultados no leídos (#58238, #58239, #58263, #58264).
  • Cambie entre backends conectados desde el selector de sesión del terminal y conserve sus borradores al cambiar (#58280, #58457).
  • Obtenga una vista previa de los archivos adjuntos de imágenes locales mientras redacta en terminales compatibles y abra las imágenes locales visualizadas desde rutas de transcripción clickable (#58261, #58446).
  • Busque las opciones de clave API y proveedor de nube en "Iniciar sesión de otra manera". Habilite gcp_setup_wizard para configurar Google Cloud Vertex AI con credenciales predeterminadas de la aplicación o un archivo de credenciales (#57857, #58427).
  • Opte por la configuración del proxy del sistema macOS o Windows desde /experimental (#58157).
  • Expanda los detalles del parche directamente en la transcripción mientras esté abierto un mensaje de aprobación (#58281).

Corrección de errores

  • Los chats guardados permanecen visibles después de cambiar de proveedor de modelo. Si un chat no se puede reanudar, puede leer su transcripción y preparar un mensaje editable para continuar en un nuevo chat (#58202).
  • Ctrl+L borra la pantalla del terminal mientras mantiene los mensajes anteriores disponibles a través de Ctrl+T (#58266).
  • Eliminar texto que expone un ! inicial mantiene un borrador normal en el modo de chat (#58412).
  • Los avisos de aprobación de la red se cierran cuando finalizan sus solicitudes. Las solicitudes simultáneas al mismo punto final se solicitan una a la vez (#58350, #58351).
  • Las conversaciones largas en tiempo real V3 guardan el discurso completo en el historial de chat a medida que crece la transcripción (#58221).
  • La compactación automática del contexto ahora tiene en cuenta la salida retenida de respuestas fallidas y respuestas a las que les faltan datos de uso de tokens (#58404).

Documentación

  • El archivo README del servidor de aplicaciones cubre las restricciones de red administradas según las reglas de comando [permissions.network] y prompt-user que requieren una nueva aprobación humana (#58045, #58182).
  • La habilidad openai-docs recomienda el reemplazo documentado al migrar desde un modelo obsoleto (#58134).

Tareas

  • Los manifiestos de DotSlash ahora hacen referencia a los paquetes Cargo enviados con la versión (#58717, #58757).

codex rust-v0.167.0

New Features

  • Open the agent command center with codex agents --no-daemon. The command center and session picker now mark unread results (#58238, #58239, #58263, #58264).
  • Switch between connected backends from the terminal session picker and keep your drafts when switching (#58280, #58457).
  • Preview local image attachments while composing on supported terminals, and open viewed local images from clickable transcript paths (#58261, #58446).
  • Find API key and cloud provider options under “Sign in another way.” Enable gcp_setup_wizard to set up Google Cloud Vertex AI with Application Default Credentials or a credential file (#57857, #58427).
  • Opt into macOS or Windows system proxy settings from /experimental (#58157).
  • Expand patch details directly in the transcript while an approval prompt is open (#58281).

Bug Fixes

  • Saved chats stay visible after you switch model providers. If a chat can’t resume, you can read its transcript and prepare an editable prompt to continue in a new chat (#58202).
  • Ctrl+L clears the terminal display while keeping earlier messages available through Ctrl+T (#58266).
  • Deleting text that exposes a leading ! keeps an ordinary draft in chat mode (#58412).
  • Network approval prompts close when their requests end. Concurrent requests to the same endpoint prompt one at a time (#58350, #58351).
  • Long realtime V3 conversations save completed speech to chat history as the transcript grows (#58221).
  • Automatic context compaction now accounts for retained output from failed responses and responses with missing token usage data (#58404).

Documentation

  • The app-server README covers managed network constraints under [permissions.network] and prompt-user command rules that require fresh human approval (#58045, #58182).
  • The openai-docs skill recommends the documented replacement when migrating away from a deprecated model (#58134).

Chores

  • DotSlash manifests now reference the Cargo packages shipped with the release (#58717, #58757).
  • Linux musl builds use fewer allocator arenas to reduce idle memory after conversations unload (#58399).
