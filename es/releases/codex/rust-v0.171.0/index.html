Nuevas funciones

  • Se agregó GPT-6.2 Sol y Astra a los catálogos de modelos, con Sol como selección de catálogo predeterminada. (#62106)
  • Se habilitó el espacio de trabajo de TUI de forma predeterminada, con vistas previas de documentos con capacidad de búsqueda, vistas previas de imágenes y transcripciones de subagente junto con la conversación principal. (#61352, #61888, #61889, #61919, #62157)
  • Se agregaron atajos configurables para deshacer y rehacer al compositor de mensajes que no son de Vim, incluida la restauración de archivos adjuntos y pegados grandes. (#61954)
  • Se agregó codex exec --remote <ADDR> para iniciar o reanudar sesiones no interactivas en un servidor de aplicaciones existente. (#61707)
  • Se agregaron /rc y /remote para administrar el control remoto local y mostrar códigos de emparejamiento de dispositivos desde la TUI. (#62121)
  • Se agregó selección y creación de línea de estado de MCP personalizada a través de /statusline cuando tui_extensions_statusline está habilitado. (#61979, #61988, #62037)

Corrección de errores

  • Borradores conservados, seguimientos en cola y entradas interrumpidas con sus hilos originales al cambiar o reanudar sesiones. (#61216)
  • Mantuvo intactos los perfiles de permisos al cambiar los directorios de trabajo. (#61195)
  • Se evitó que los eventos de finalización tardía cancelaran las aprobaciones para un turno más nuevo. (#61801)
  • Se conservaron ediciones anteriores en diferencias agregadas al realizar un giro activo. (#61820)
  • Se corrigió el desplazamiento que insertaba caracteres perdidos, saltos de intercalación del compositor y redibujos usando dimensiones de terminal obsoletas. (#62139, #62174, #62175)
  • Se corrigió el inicio de sesión de MCP empresarial para proveedores de identidad que emiten tokens de identificación sin tokens de actualización. (#62129)

New Features

  • Added GPT-6.2 Sol and Astra to model catalogs, with Sol as the default catalog selection. (#62106)

  • Added /rc and /remote to manage local remote control and display device pairing codes from the TUI. (#62121)
  • Added custom MCP status line selection and authoring through /statusline when tui_extensions_statusline is enabled. (#61979, #61988, #62037)

Bug Fixes

  • Preserved drafts, queued follow-ups, and interrupted input with their original threads when switching or resuming sessions. (#61216)
  • Kept permission profiles intact when changing working directories. (#61195)
  • Prevented late completion events from cancelling approvals for a newer turn. (#61801)
  • Preserved earlier edits in aggregate diffs when steering an active turn. (#61820)
  • Fixed scrolling that inserted stray characters, composer caret jumps, and redraws using stale terminal dimensions. (#62139, #62174, #62175)
  • Fixed enterprise MCP sign-in for identity providers that issue ID tokens without refresh tokens. (#62129)

Chores

  • Updated source builds and release tooling to Rust 1.99.1. (#61205)
  • Updated XML dependencies and removed obsolete security advisory exceptions. (#62068)
