códice rust-v0.166.0

Nuevas funciones

  • Se agregó selección de transcripciones mediante teclado con movimientos de palabras, líneas y páginas, búsqueda integrada y atajos configurables. (#57221, #57222, #57223, #57224)
  • Se representó Markdown de manera consistente en preguntas, opciones, respuestas y transcripciones de respuestas asincrónicas. (#57259, #57292)
  • Se agregó GPT-6.1 Terra a los catálogos de modelos incluidos, Vertex AI y Amazon Bedrock. (#57293)
  • Se agregó codex queue --resume para reanudar los hilos descargados después de poner en cola un mensaje. (#57232)
  • Se agregaron explicaciones más claras sobre los bloques de seguridad e indicaciones de seguimiento más seguras seleccionables en la TUI. (#57363, #57365)
  • Se agregó codex doctor --network-only para configuración, conectividad y diagnóstico de WebSocket enfocados. (#57606)

Corrección de errores

  • Se conserva la configuración de permisos y aprobación reconocida al reanudar o bifurcar hilos. (#57227)
  • Se conservan los archivos adjuntos de imágenes locales al restaurar el texto del compositor eliminado. (#57502)
  • Se corrigió la limpieza de la versión independiente en macOS cuando las instalaciones están en uso o las rutas contienen caracteres que no son ASCII. (#57503)
  • Se restauraron los hilos descendientes generados al desarchivar a sus padres. (#57635)
  • Se corrigieron las carreras de inicio y cierre de subprocesos del servidor de aplicaciones y se publicaron los tiempos de ejecución completados con prontitud. (#57787, #57788)
  • Recuperación de reconexión TUI mejorada, incluido el manejo fuera de línea de /quit y /exit. (#57820)
  • Se conservó la contabilidad de tokens de razonamiento en el currículum y la bifurcación para evitar la compactación prematura. (#57839)

codex rust-v0.166.0

New Features

  • Added keyboard-driven transcript selection with word, line, and page motions, integrated search, and configurable shortcuts. (#57221, #57222, #57223, #57224)
  • Rendered Markdown consistently in async questions, choices, answers, and transcript replies. (#57259, #57292)
  • Added GPT-6.1 Terra to the bundled, Vertex AI, and Amazon Bedrock model catalogs. (#57293)
  • Added codex queue --resume to resume unloaded threads after queueing a message. (#57232)
  • Added clearer safety-block explanations and selectable safer follow-up prompts in the TUI. (#57363, #57365)
  • Added codex doctor --network-only for focused configuration, connectivity, and WebSocket diagnostics. (#57606)

Bug Fixes

  • Preserved acknowledged approval and permission settings when resuming or forking threads. (#57227)
  • Preserved local image attachments when restoring killed composer text. (#57502)
  • Fixed standalone release cleanup on macOS when installations are in use or paths contain non-ASCII characters. (#57503)
  • Restored spawned descendant threads when unarchiving their parent. (#57635)
  • Fixed app-server thread startup and shutdown races and released completed runtimes promptly. (#57787, #57788)
  • Improved TUI reconnection recovery, including offline /quit and /exit handling. (#57820)
  • Preserved reasoning-token accounting across resume and fork to avoid premature compaction. (#57839)

Chores

  • Switched Bazel to source-built V8 with target-matched Rust bindings and native Windows MSVC archive support. (#57164, #57269, #57644, #57832)
  • Shipped the standalone executor in canonical CLI and app-server release packages. (#57837)
  • Standardized development and release builds on Node.js 24.22.1 and Rust 1.95.0. (#57168, #57373)
