Características

🛠️ TRL ahora se entrena en AWS Trainium

<img width="1672" height="941" alt="Neon Warehouse_ Soporte para AWS y Trainium" src="https://github.com/user-attachments/assets/dcb6e2a1-0f7c-4635-819b-a1ec6f5e143b" /> El cabezal LM fusionado de v1.15 es lo que hizo que Neuron fuera manejable; las lagunas restantes se cierran aquí. Hay una [guía](https://huggingface.co/docs/trl/neuron) que lo acompaña. Neuron se vuelve a compilar una vez por forma de entrada, por lo que una ejecución sin relleno se detiene aproximadamente un minuto en cada nueva longitud de secuencia. `pad_to_multiple_of` ahora tiene como valor predeterminado `"auto"`: 128 en Neuron, `None` en otros lugares, por lo que nada cambia en la GPU. Trainium2, Qwen3-0.6B SFT, 20 pasos: **130 s con el valor predeterminado frente a 260 s sin**. * Agregar una guía para capacitación en AWS Trainium por @qgallouedec en https://github.com/huggingface/trl/pull/7729 * `pad_to_multiple_of` predeterminado a `"auto"` por @qgallouedec en https://github.com/huggingface/trl/pull/7724 * Ejecute el cabezal LM fusionado y los núcleos de destilación en dispositivos sin Triton por @qgallouedec en https://github.com/huggingface/trl/pull/7669 *Reporte del dispositivo Neuron en `trl env` y telemetría por @qgallouedec en https://github.com/huggingface/trl/pull/7672 *Soporta cualquier acelerador en descarga de activación por @qgallouedec en https://github.com/huggingface/trl/pull/7670 ### 🌳 Atención de árbol para AsyncGRPO AsyncGRPO ahora empaqueta cada fila de microlotes como un **árbol de prefijos** en lugar de una secuencia plana. Los lanzamientos de múltiples turnos y múltiples generaciones repiten muchos prefijos: en un mensaje compartido, esos tokens solían reenviarse una vez por fila. El embalaje del árbol los adelanta una vez. ```text rollout 0: [ prompt ] [ completion A ] prompt ──┬── completion A ── later turn rollout 1: [ prompt ] [ completion B ] => └── completion B rollout 2: [ prompt ] [ completion A ] [ … ] ``` Las cadenas sin bifurcación se colapsan en segmentos, y las consultas de cada segmento atienden al K/V reunido a lo largo de su ruta de raíz a segmento en una única llamada FA3 varlen. Sin tensor de máscara: cada capa, excepto la de atención, se ejecuta una vez por token único, y solo K/V se duplica a lo largo de los prefijos compartidos. Qwen3-1.7B, 32.000 tokens por lanzamiento, adelante + atrás: | diseño | proporción de embalaje | embalaje de secuencia | embalaje de árboles | pico GiB | | --- | --- | --- | --- | --- | | mensaje compartido | 1.00 | 8677 ms | 8737 ms (0.99×) | 35.2 → 35.2 | | mensaje compartido | 2.29 | 8266 ms | **4341 ms (1.90×)** | 35.2 → 18.0 | | mensaje compartido | 3.37 | 8179 ms | **2755 ms (2.97×)** | 35.2 → 13.6 | | horquilla anidada | 1.60 | 8557 ms | 6217 ms (1.38×) | 35.2 → 23.8 | | horquilla anidada | 3.56 | 8172 ms | **2635 ms (3.10×)** | 35.2 → 13.5 | No hay ninguna opción `packing` para elegir: sin nada compartido, una fila de árbol es exactamente la secuencia anterior empaquetada, con un costo de ~1%. por @AmineDiro en https://github.com/huggingface/trl/pull/7328 ### Muse Spark abierto Soporte para [`meta-models/Muse-Spark-Open-816B-A42B`](https://huggingface.co/meta-models/Muse-Spark-Open-816B-A42B): el script de modelo pequeño, cobertura en las pruebas de VLM (SFT, DPO, KTO, utilidades de plantilla de chat, cabezal LM fusionado) y un ejemplo de LoRA SFT en 8 nodos de 8×H100 con `DistributedConfig(fsdp_size=64, ep_size=8)`, envío y empaquetado de tokens. Medido en **14.2 s/paso, 131k tokens/paso, 40.2 GB por GPU**. trl v1.16.0

Features

🛠️ TRL now trains on AWS Trainium

<img width="1672" height="941" alt="Neon Warehouse_ AWS and Trainium Support" src="https://github.com/user-attachments/assets/dcb6e2a1-0f7c-4635-819b-a1ec6f5e143b" />

The fused LM head from v1.15 is what made Neuron tractable; the remaining gaps are closed here. There is a guide to go with it.

Neuron recompiles once per input shape, so an unpadded run stalls about a minute on every new sequence length. pad_to_multiple_of now defaults to "auto": 128 on Neuron, None elsewhere, so nothing changes on GPU. Trainium2, Qwen3-0.6B SFT, 20 steps: 130 s with the default against 260 s without.

  • Add a guide for training on AWS Trainium by @qgallouedec in https://github.com/huggingface/trl/pull/7729
  • Default pad_to_multiple_of to "auto" by @qgallouedec in https://github.com/huggingface/trl/pull/7724
  • Run the fused LM head and distillation kernels on devices without Triton by @qgallouedec in https://github.com/huggingface/trl/pull/7669
  • Report the Neuron device in trl env and telemetry by @qgallouedec in https://github.com/huggingface/trl/pull/7672
  • Support any accelerator in activation offloading by @qgallouedec in https://github.com/huggingface/trl/pull/7670

🌳 Tree attention for AsyncGRPO

AsyncGRPO now packs every micro-batch row as a prefix tree instead of a flat sequence. Multi-turn and multi-generation rollouts repeat a lot of prefix: on a shared prompt, those tokens used to be forwarded once per row. Tree packing forwards them once.

rollout 0:  [ prompt ] [ completion A ]              prompt ──┬── completion A ── later turn
rollout 1:  [ prompt ] [ completion B ]        =>             └── completion B
rollout 2:  [ prompt ] [ completion A ] [ … ]

Chains without a fork collapse into segments, and each segment's queries attend to the K/V gathered along its root-to-segment path in a single FA3 varlen call. No mask tensor: every layer except attention runs once per unique token, and only K/V is duplicated along shared prefixes.

Qwen3-1.7B, 32K tokens per rollout, forward + backward:

| layout | packing ratio | sequence packing | tree packing | peak GiB | | --- | --- | --- | --- | --- | | shared prompt | 1.00 | 8677 ms | 8737 ms (0.99×) | 35.2 → 35.2 | | shared prompt | 2.29 | 8266 ms | 4341 ms (1.90×) | 35.2 → 18.0 | | shared prompt | 3.37 | 8179 ms | 2755 ms (2.97×) | 35.2 → 13.6 | | nested fork | 1.60 | 8557 ms | 6217 ms (1.38×) | 35.2 → 23.8 | | nested fork | 3.56 | 8172 ms | 2635 ms (3.10×) | 35.2 → 13.5 |

There is no packing option to choose: with nothing shared a tree row is exactly the old sequence packing, at a ~1% cost.

by @AmineDiro in https://github.com/huggingface/trl/pull/7328

Muse Spark Open

Support for meta-models/Muse-Spark-Open-816B-A42B: the tiny-model script, coverage in the VLM tests (SFT, DPO, KTO, chat-template utils, fused LM head), and a LoRA SFT example on 8 nodes of 8×H100 with DistributedConfig(fsdp_size=64, ep_size=8), token dispatch and packing. Measured at 14.2 s/step, 131k tokens/step, 40.2 GB per GPU.

Needs transformers>=5.20.0; the adapter save additionally needs transformers#49500 with peft 0.21.2.

by @qgallouedec in https://github.com/huggingface/trl/pull/7536
