OpenHands cloud-1.41.0

Highlights

  • AST-aware file chunking — File context is now chunked using tree-sitter syntax trees instead of arbitrary text boundaries, helping preserve functions, classes, and other structural units when large files enter the agent context (#14699).
  • Parallel tool execution — Agents gain a tool_concurrency_limit setting for parallel tool calls, enabling faster multi-step workflows. Integrations that mutate external systems should verify ordering assumptions and apply suitable limits (#14929).
  • Organization authorization and key controls — Organizations gain an admin conversation dashboard, user.role_id super roles with permission fallback, and a /organizations/{id}/me endpoint exposing caller permissions. API keys now support not_before/expires_at validity windows and an explicit unbound organization scope, making short-lived credentials and cross-organization access easier to express (#14846, #14937, #15048, #15085, #15096).
  • Workspace snapshots and trace attribution — Production app-server workspaces now capture an initial state and are archived before deletion; Laminar traces include repository and branch metadata. This improves post-deletion recovery/auditability and ties agent runs to the code revision being worked on (#14953, #15059).
  • Streaming, runtime, and dependency fixes — Cloud conversations and profile switches now stream LLM tokens, V1 chat no longer duplicates streamed deltas, and sandbox provisioning falls back to defaults when runtime-api reports no warm runtimes. The authlib update fixes CVE-2026-44681; SDK/agent-server packages move to 1.31.1 and dependencies are exactly pinned, so upgrades should include the corresponding database migrations and refreshed lockfile (#15021, #15108, #15141, #14983, #15127, #14384).
  • Compatibility — No breaking changes are listed in this release.
