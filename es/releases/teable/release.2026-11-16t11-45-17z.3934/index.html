lanzamiento de mesa.2026-11-16T11-45-17Z.3934

Actualizaciones de funciones

  • Se agregó una acción "Agregar inicio de sesión" a la barra superior de la aplicación para editores, brindando acceso directo a la configuración de inicio de sesión antes y después de la configuración.
  • Las aplicaciones publicadas ahora se pueden abrir directamente desde la barra de direcciones de vista previa en el modo en vivo.
  • Teable CLI ahora admite compartir informes generados a través de enlaces accesibles al equipo.
  • Los comandos de campo AI e importación CLI ahora están agrupados en campo e importación, respectivamente. El comando de campo ai-status --poll espera a que se complete el procesamiento antes de leer los valores generados. Los nombres de comandos antiguos seguirán siendo compatibles durante una versión y mostrarán una advertencia.
  • Las importaciones de Airtable y Google Sheets CLI ahora se pueden ejecutar en segundo plano y reanudarse utilizando una ID de tarea. Los reintentos reutilizan una importación en curso o completada recientemente para evitar la creación de bases de datos duplicadas; Los comandos proporcionan instrucciones de reanudación mientras continúa el procesamiento.
  • Se agregó el comando de esquema de la aplicación teable con un indicador opcional --check para actualizar el esquema local y teable.md. Las aplicaciones push ahora advierten sobre cambios en el esquema remoto y las pulls informan estos cambios cuando ocurren conflictos sin sobrescribir los archivos locales.
  • Se agregó el comando de inicio de sesión de la aplicación teable para abrir una aplicación desarrollada localmente como el usuario actual de Teable o un usuario de aplicación específico durante una sesión de desarrollo de una hora.
  • El flujo de trabajo de envío de plantillas ahora busca contenido de muestra potencialmente confidencial y permite que los ejemplos retenidos intencionalmente se marquen como seguros. Al eliminar un proyecto de plantilla, también se cancela la publicación de la plantilla y se eliminan los envíos pendientes y sus copias de prueba.
  • La consulta estructurada ahora admite DISTINCT para eliminar duplicados de los resultados seleccionados y al mismo tiempo proporciona totales precisos y paginación consistente. No se permite ordenar por campos fuera de la salida seleccionada.
  • La consulta estructurada ahora admite filtros de nivel raíz cualquiera y ninguno para verificar si existen registros vinculados accesibles, con soporte en API, MCP, clients generados y CLI.
  • La incorporación de plantillas ahora puede completar los pasos correspondientes cuando los usuarios agregan registros y excluye el instalador de plantillas de los pasos relacionados con la invitación.
  • Las solicitudes de informes y gráficos ahora crean artefactos livianos de una sola página de forma predeterminada en lugar de iniciar aplicaciones completas.

Corrección de errores y mejoras

  • Mover una aplicación ahora requiere confirmación antes de cerrar una zona de pruebas activa de App Builder, lo que interrumpe todas las tareas en curso. La medida espera a que el sandbox se cierre correctamente, proporciona mensajes de error claros para reintentos seguros y evita que el sandbox se reutilice en el proyecto original.
  • Se corrigió el filtrado de registros vinculados en formularios compartidos para que las opciones válidas permanezcan disponibles cuando los valores del filtro están incompletos, los campos se han eliminado o las condiciones hacen referencia a otros campos.
  • Coherencia de búsqueda mejorada: ocultar campos fuera del alcance de la búsqueda global ya no actualiza los resultados; Las búsquedas de recursos de roles ya no muestran carpetas o tablas no relacionadas cuando no se encuentran coincidencias.
  • Se corrigió el desplazamiento en menús desplegables y menús dentro de los cuadros de diálogo para que todas las opciones de selección única sean accesibles al agregar registros.
  • Los registros de tabla recién creados ahora se abren en paneles laterales, conservan los borradores cuando los paneles están cerrados y mantienen visible el panel de registro actual cuando hay varios paneles abiertos.
  • Los scripts de automatización generados por IA ahora incluyen las conexiones de cuenta requeridas en su configuración. Las plantillas identifican con mayor precisión las cuentas externas requeridas, solicitan a los usuarios que las conecten y mantienen las automatizaciones relacionadas desactivadas hasta que las conexiones estén disponibles.
  • Las miniaturas de los archivos adjuntos recién generadas utilizan WebP para reducir el tamaño de la descarga y mejorar la velocidad de carga. Las vistas de archivos adjuntos utilizan miniaturas de tamaño adecuado, evitan solicitudes duplicadas y manejan imágenes ultra anchas de manera más confiable. Las miniaturas existentes conservan sus formatos originales.
  • Actualizaciones mejoradas en tiempo real sobre conexiones lentas o interrumpidas, incluida la entrega confiable de actualizaciones de estado de error y finalización.
  • Se mejoró la confiabilidad de deshacer agrupados para operaciones grandes y se conservó el acceso al historial de deshacer elegible de versiones anteriores.
  • Seguridad mejorada y confiabilidad del control de acceso para sesiones de aplicaciones generadas, App Builder, bots, campos de registros vinculados y solicitudes salientes.
  • Los guardados simultáneos de archivos de aplicaciones ahora están coordinados para evitar errores intermitentes y pérdida de cambios. Los proyectos clonados incluyen archivos guardados correctamente, los conflictos de versiones devuelven una respuesta HTTP 409 reintentable y las reversiones utilizan el mismo mecanismo de guardado confiable.
  • App Builder ahora abre el chat de la aplicación seleccionada directamente y las conversaciones cambian automáticamente al cambiar de aplicación. Los usuarios de dispositivos móviles ahora pueden cerrar los chats correctamente.
  • Las pruebas de nodos de automatización de larga duración ahora continúan después de los tiempos de espera de las solicitudes y brindan resultados al finalizar. Las solicitudes repetidas reutilizan la ejecución existente para evitar efectos secundarios duplicados.
  • Se mejoró el recuento de registros y la confiabilidad de las estadísticas de campo para roles restringidos. Los campos ocultos ya no provocan que falle toda la solicitud de estadísticas.
  • Los usuarios anónimos que abren enlaces de tablas no válidos en proyectos compartidos ahora son redirigidos a una tabla accesible, se les muestra un aviso único y se les proporciona una URL corregida que permanece limpia después de la actualización.
  • Se corrigieron errores y faltaban actualizaciones en tiempo real para los usuarios que obtienen acceso al proyecto únicamente a través de la membresía del departamento, incluido el acceso heredado a través de la membresía del subdepartamento.
  • Se corrigió el flujo de confirmación de Vista previa para que cancelar el inicio de sesión ya no cierre el cuadro de diálogo prematuramente y los mensajes de error de inicio de sesión permanezcan visibles.
  • Se corrigieron los flujos de inicio de sesión de Teable, Google y SSO en código desprotegido localmente para que los usuarios regresen a la aplicación localhost después de iniciar sesión en lugar de a la vista previa alojada.
  • Los marcadores de incorporación de aplicaciones ahora se reposicionan cuando los controles del editor los oscurecen, lo que mantiene accesibles las acciones de incorporación sin cambiar los diseños no afectados.
  • Se mejoró la confiabilidad del pegado durante las actualizaciones de la cuadrícula, con filas temporales y en flujos de trabajo de pegado por ID, preservando al mismo tiempo los permisos y el comportamiento de los campos.
  • Formato unificado para títulos de registros, contenido del tablero cli y valores de filtrado y agrupación para hacer que las fechas, zonas horarias, números, fórmulas, búsquedas y valores vacíos sean más consistentes. El autocompletar de IA también evita ejecuciones innecesarias cuando los valores mostrados no han cambiado.
  • Se mejoró la vista previa de App Builder y la confiabilidad de publicación en China para aplicaciones que usan onnxruntime-node.
  • Las exportaciones de cuentas ahora incluyen tablas que están listas e identifican claramente las tablas omitidas. Las exportaciones incompletas bloquean la eliminación permanente de la cuenta; las exportaciones fallidas se detienen limpiamente sin generar archivos corruptos ni enviar notificaciones de éxito.
  • Las solicitudes de instantáneas de tablas por lotes ahora devuelven una respuesta HTTP 400 clara cuando el parámetro ids tiene un formato incorrecto. API clients debe proporcionar identificadores como una matriz.

teable release.2026-11-16T11-45-17Z.3934

Feature Updates

  • Added an “Add Sign-in” action to the top app bar for editors, providing direct access to sign-in configuration before and after setup.
  • Published apps can now be opened directly from the preview address bar in Live mode.
  • Teable CLI now supports sharing generated reports through links accessible to the team.
  • AI field and import CLI commands are now grouped under field and import, respectively. The field ai-status --poll command waits for processing to complete before reading generated values. Old command names will remain supported for one release and display a warning.
  • Airtable and Google Sheets CLI imports can now run in the background and be resumed using a task ID. Retries reuse an ongoing or recently completed import to avoid creating duplicate databases; commands provide resume instructions while processing continues.
  • Added the teable app schema command with an optional --check flag to refresh the local schema and teable.md. App pushes now warn about remote schema changes, and pulls report these changes when conflicts occur without overwriting local files.
  • Added the teable app signin command to open a locally developed app as the current Teable user or a specified app user through a one-hour development session.
  • The template submission workflow now checks for potentially sensitive sample content and allows intentionally retained examples to be marked as safe. Deleting a template project also unpublishes the template and removes pending submissions and their trial copies.
  • Structured Query now supports DISTINCT to remove duplicates from selected results while providing accurate totals and consistent pagination. Sorting by fields outside the selected output is not allowed.
  • Structured Query now supports root-level any and none filters to check whether accessible linked records exist, with support in the API, MCP, generated clients, and CLI.
  • Template onboarding can now complete the corresponding steps when users add records and excludes the template installer from invitation-related steps.
  • Report and chart requests now create lightweight, single-page artifacts by default instead of launching full apps.

Bug Fixes & Improvements

  • Moving an app now requires confirmation before closing an active App Builder sandbox, which interrupts all ongoing tasks. The move waits for the sandbox to close successfully, provides clear failure messages for safe retries, and prevents the sandbox from being reused under the original project.
  • Fixed linked record filtering in shared forms so valid options remain available when filter values are incomplete, fields have been deleted, or conditions reference other fields.
  • Improved search consistency: hiding fields outside the global search scope no longer refreshes results; role resource searches no longer show unrelated folders or tables when no matches are found.
  • Fixed scrolling in dropdowns and menus within dialogs so all single-select options are accessible when adding records.
  • Newly created table records now open in side panels, retain drafts when panels are closed, and keep the current record panel visible when multiple panels are open.
  • AI-generated automation scripts now include required account connections in their configuration. Templates more accurately identify required external accounts, prompt users to connect them, and keep related automations disabled until connections are available.
  • Newly generated attachment thumbnails use WebP to reduce download size and improve loading speed. Attachment views use appropriately sized thumbnails, avoid duplicate requests, and handle ultrawide images more reliably. Existing thumbnails retain their original formats.
  • Improved real-time updates over slow or interrupted connections, including reliable delivery of completion and error status updates.
  • Improved grouped undo reliability for large operations and preserved access to eligible undo history from earlier versions.
  • Improved security and access control reliability for generated app sessions, App Builder, bots, linked record fields, and outbound requests.
  • Concurrent app file saves are now coordinated to prevent intermittent errors and lost changes. Cloned projects include successfully saved files, version conflicts return a retryable HTTP 409 response, and rollbacks use the same reliable save mechanism.
  • App Builder now opens the selected app’s chat directly, and conversations switch automatically when switching apps. Mobile users can now close chats properly.
  • Long-running automation node tests now continue after request timeouts and provide results upon completion. Repeated requests reuse the existing run to avoid duplicate side effects.
  • Improved record count and field statistics reliability for restricted roles. Hidden fields no longer cause the entire statistics request to fail.
  • Anonymous users opening invalid table links in shared projects are now redirected to an accessible table, shown a one-time notice, and given a corrected URL that remains clean after refresh.
  • Fixed errors and missing real-time updates for users who gain project access solely through department membership, including access inherited through subdepartment membership.
  • Fixed the Preview confirmation flow so canceling sign-in no longer closes the dialog prematurely, and sign-in failure messages remain visible.
  • Fixed Teable, Google, and SSO sign-in flows in locally checked-out code so users return to the localhost app after signing in rather than the hosted preview.
  • App onboarding markers now reposition when editor controls would obscure them, keeping onboarding actions accessible without changing unaffected layouts.
  • Improved paste reliability during grid updates, with temporary rows, and in paste-by-ID workflows while preserving permissions and field behavior.
  • Unified formatting for record titles, clipboard content, and filter and grouping values to make dates, time zones, numbers, formulas, lookups, and empty values more consistent. AI autofill also avoids unnecessary runs when display values have not changed.
  • Improved App Builder preview and publishing reliability in China for apps using onnxruntime-node.
  • Account exports now include tables that are ready and clearly identify skipped tables. Incomplete exports block permanent account deletion; failed exports stop cleanly without generating corrupted archives or sending success notifications.
  • Batch table snapshot requests now return a clear HTTP 400 response when the ids parameter is malformed. API clients must provide ids as an array.
