lanzamiento de mesa.2026-11-05T10-37-52Z.3784

Actualizaciones de funciones

  • Las vistas previas de conversión y eliminación de campos ahora muestran las aplicaciones, consultas, campos y fuentes de datos afectados, distinguiendo las versiones publicadas y las más recientes guardadas. Las consultas guardadas informan sobre estados correctos, desviados o rotos con explicaciones más claras. Las vistas previas siguen siendo de solo lectura, requieren confirmación antes de realizar cambios y no modifican automáticamente las aplicaciones afectadas.
  • Los administradores autohospedados pueden asignar dominios personalizados a aplicaciones publicadas con HTTPS automático. La opción Dominio personalizado ahora abre la guía de configuración y los inicios de sesión devuelven a los usuarios al dominio asignado con un recurso alternativo al enlace de la aplicación estándar.
  • Los administradores pueden configurar un proveedor OIDC para toda la instancia para aplicaciones de App Builder. Las aplicaciones pueden ofrecer "Continuar con SSO" y al mismo tiempo conservar las reglas de acceso y los métodos de inicio de sesión existentes. Las aplicaciones existentes pueden requerir que el propietario agregue el botón SSO y las vuelva a publicar.
  • La configuración del token de acceso personal ahora incluye cuatro ajustes preestablecidos de permisos, niveles de lectura/escritura agrupados, permisos individuales con capacidad de búsqueda y un resumen antes de guardar. El acceso puede cubrir todos los espacios y proyectos actuales y futuros o seleccionados. La lista de tokens muestra ajustes preestablecidos, admite clasificación por caducidad y último uso, y resalta tokens caducados o que están a punto de caducar.
  • Se agregó una opción de descarga de aplicaciones móviles al menú de usuario. Los teléfonos siguen utilizando el diseño clásico.

Corrección de errores y mejoras

  • Automatizaciones entre bases restauradas que actualizan campos de registros vinculados bidireccionales. Los flujos de trabajo existentes se reanudan sin volver a publicarlos ni deshabilitarlos y volver a habilitarlos manualmente.
  • Se corrigieron las vistas previas de las plantillas que se atascaban en "Pensar profundamente..." después de fallas en la publicación de aplicaciones que involucraban consultas con nombre. Los fallos iniciales ahora se reintentan, con errores finales más claros cuando fallan los reintentos.
  • Rendimiento mejorado y uso reducido de memoria para actualizaciones de registros masivos de gran tamaño, especialmente en tablas amplias cuando se cambian solo unos pocos campos, al tiempo que se conservan los resultados, permisos y el comportamiento de deshacer/rehacer existentes.
  • Se mejoró la confiabilidad de la paginación de tablas después de conversiones de campos fallidas.
  • Las sesiones de App Builder ahora se renuevan por otros siete días cuando los usuarios vuelven a visitarlas después de al menos una hora, incluso en aplicaciones integradas, respetando la configuración de acceso actual. Las aplicaciones existentes se deben volver a publicar para que este comportamiento surta efecto.
  • Confiabilidad de autenticación mejorada para clients conectados, incluidos errores de inicio de sesión más claros y guía de reintento. Los fallos temporales ya no invalidan innecesariamente las credenciales y el CLI indica claramente a los usuarios que vuelvan a iniciar sesión cuando sea necesario.
  • Las nuevas conversaciones de chat se crean solo después de enviar el primer mensaje, lo que evita que se acumulen chats vacíos. Los borradores no enviados ahora sobreviven a las actualizaciones de la página.
  • Rendimiento de carga inicial mejorado para chats y mesas.
  • Se reorganizó la configuración de administración de IA en secciones numeradas de modelos, chat de IA y creador de aplicaciones con indicadores de estado y orientación de configuración. Diseños, resúmenes, búsqueda y selección de configuración de modelos mejorados, incluida la compatibilidad con modelos de puerta de enlace y de proveedor personalizado en la configuración del chat.
  • Se mejoró el nuevo diseño del espacio en ventanas más pequeñas, incluido el colapso automático de la barra lateral y la posición correcta del mensaje de actualización del diseño.
  • Se corrigió la configuración de Kanban para que el mensaje del campo de agrupación se cierre cuando se complete. Los registros creados dentro de una columna ahora heredan el valor de selección única de esa columna.
  • Tarjetas de importación de proyectos mejoradas con nombres de fuentes y ajuste de texto más claros. Las pestañas de recursos ahora muestran íconos de tablas personalizados cuando están disponibles.
  • Se restauraron los indicadores de progreso de importación de tablas en páginas compartidas editables y se mejoró la seguridad de las páginas compartidas.
  • Arreglado el acceso a artefactos generados por rutinas. Publicar o activar una rutina ahora asigna la propiedad a ese usuario, con notificaciones cuando la propiedad cambia. Los miembros de la tarea elegibles pueden ver los chats en ejecución, mientras que solo el propietario puede continuarlos o administrarlos.
  • Seguridad mejorada y manejo de errores para importaciones basadas en URL.
  • Se corrigieron fallas de publicación de aplicaciones en proyectos que contienen texto grande, consultas generadas o archivos GeoJSON.
  • Se corrigieron errores de verificación de dominio personalizado cuando los resultados de la verificación no están disponibles.
  • Se restauró la navegación con deslizamiento hacia la izquierda de Android desde pestañas y listas de recursos hasta la conversación de origen. Manejo táctil mejorado de la galería móvil para reducir el arrastre accidental mientras se desplaza.

teable release.2026-11-05T10-37-52Z.3784

Feature Updates

  • Field deletion and conversion previews now show affected apps, queries, fields, and data sources, distinguishing published and latest-saved versions. Saved queries report healthy, drifted, or broken status with clearer explanations. Previews remain read-only, require confirmation before changes, and do not automatically modify affected apps.
  • Self-hosted administrators can map custom domains to published apps with automatic HTTPS. The Custom domain option now opens the setup guide, and sign-ins return users to the mapped domain with a fallback to the standard app link.
  • Administrators can configure an instance-wide OIDC provider for App Builder apps. Apps can offer “Continue with SSO” while preserving existing access rules and login methods. Existing apps may require the owner to add the SSO button and republish.
  • Personal access token configuration now includes four permission presets, grouped read/write levels, searchable individual permissions, and a summary before saving. Access can cover all current and future spaces and projects or selected ones. The token list shows presets, supports expiration and last-use sorting, and highlights expired or soon-to-expire tokens.
  • Added a mobile app download option to the user menu. Phones continue to use the classic layout.

Bug Fixes & Improvements

  • Restored cross-base automations that update bidirectional linked-record fields. Existing workflows resume without republishing or manually disabling and re-enabling them.
  • Fixed template previews getting stuck on “Thinking deeply…” after app publishing failures involving named queries. Early failures are now retried, with clearer final errors when retries fail.
  • Improved performance and reduced memory use for large bulk record updates, especially on wide tables when changing only a few fields, while preserving existing results, permissions, and undo/redo behavior.
  • Improved table paging reliability after failed field conversions.
  • App Builder sessions now renew for another seven days when users revisit after at least one hour, including in embedded apps, while respecting current access settings. Existing apps must be republished for this behavior to take effect.
  • Improved authentication reliability for connected clients, including clearer sign-in errors and retry guidance. Temporary failures no longer unnecessarily invalidate credentials, and the CLI clearly directs users to sign in again when needed.
  • New chat conversations are created only after the first message is sent, preventing empty chats from accumulating. Unsent drafts now survive page refreshes.
  • Improved initial loading performance for chats and tables.
  • Reorganized Admin AI Settings into numbered Models, AI Chat, and App Builder sections with status indicators and setup guidance. Improved model configuration layouts, summaries, search, and selection, including support for both gateway and custom-provider models in chat settings.
  • Improved the new space layout in smaller windows, including automatic sidebar collapsing and correct positioning of the layout update prompt.
  • Fixed Kanban setup so the grouping-field prompt closes when complete. Records created within a column now inherit that column’s single-select value.
  • Improved project import cards with clearer source names and text wrapping. Resource tabs now display custom table icons when available.
  • Restored table import progress indicators on editable share pages and improved shared-page security.
  • Fixed access to artifacts generated by routines. Publishing or activating a routine now assigns ownership to that user, with notifications when ownership changes. Eligible task members can view run chats, while only the owner can continue or manage them.
  • Improved security and error handling for URL-based imports.
  • Fixed app publishing failures in projects containing large text, generated query, or GeoJSON files.
  • Fixed custom domain verification errors when verification results are unavailable.
  • Restored Android left-swipe navigation from tabs and resource lists to the originating conversation. Improved mobile gallery touch handling to reduce accidental dragging while scrolling.
