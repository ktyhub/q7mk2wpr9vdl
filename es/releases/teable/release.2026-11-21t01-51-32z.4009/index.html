lanzamiento de mesa.2026-11-21T01-51-32Z.4009

Actualizaciones de funciones

  • Se agregaron puntos finales MCP estrictos y de solo lectura. El punto final estricto separa las acciones de lectura y escritura para que los AI clients compatibles puedan solicitar confirmación antes de realizar cambios. El punto final de solo lectura admite clients que no pueden confirmar escrituras. Las integraciones de MCP existentes no cambian.
  • Se agregó una biblioteca de consultas para cada base. Los miembros pueden guardar, buscar, comparar y compartir revisiones de consultas privadas de forma predeterminada. Las consultas se ejecutan con los permisos de datos actuales de la persona que llama y las aplicaciones publicadas pueden fijar una revisión específica. Revocar el acceso evita que las aplicaciones ejecuten la consulta fijada hasta que se restablezca el acceso o se actualice la aplicación. Esta característica requiere que estén habilitadas tanto la biblioteca de consultas como la ejecución de consultas nativas.
  • El pegado de texto sin formato entre tablas ahora admite enlaces bidireccionales de muchos a muchos. Los títulos pegados coinciden con los registros existentes en la tabla vinculada y los vínculos recíprocos se actualizan sin crear duplicados.
  • Los miembros de la mesa ahora pueden ver si la aceleración de búsqueda está activa, qué campos cubre y cuándo cambia su estado. Las vistas compartidas muestran la disponibilidad solo para los campos visibles en la vista.

Corrección de errores y mejoras

  • Se actualizó el paquete del complemento OpenAI a la versión 1.0.1 y se acortaron las instrucciones de AI para que ya no estén cortadas en Claude Code.
  • Se mejoró la confiabilidad del campo computacional v2 y se redujo la carga innecesaria de la base de datos.
  • Se mejoró la confiabilidad de la restauración y eliminación de recursos, incluida una solución para las tablas v2 restauradas que podrían permanecer en la papelera.
  • El llenado previo de filas ahora mantiene los valores permitidos y omite solo las nuevas opciones de selección que el editor no puede crear. Si el pegado contiene solo una opción restringida, aún devuelve un error de permiso.
  • Se corrigieron fallas cuando los campos se creaban simultáneamente en la misma tabla o mientras una operación de larga duración estaba en progreso. Los nuevos campos ahora aparecen de manera confiable en la lista de campos y en la vista predeterminada.
  • Cuppy ahora explica cuándo se detiene una tarea porque se queda sin memoria. Los pasos completados permanecen visibles y los usuarios de la web pueden continuar desde la última respuesta sin tener que empezar de nuevo.
  • Se corrigieron búsquedas filtradas y resúmenes para que al eliminar registros vinculados se recalculen solo los registros principales afectados. La eliminación también es más rápida para grandes conjuntos de datos vinculados.
  • Seguridad compartida base mejorada para que los visitantes puedan acceder solo al contenido dentro del alcance compartido configurado.
  • Se corrigieron errores en los gráficos del Panel que usan datos de tablas. Los totales de los gráficos ahora reflejan los datos que cada espectador tiene permiso para leer, incluidas las restricciones a nivel de fila.
  • Se mejoró el rendimiento de V2 API para actualizaciones por lotes en múltiples campos de registros vinculados, al mismo tiempo que se preserva el orden de los vínculos y se mantienen sincronizados los vínculos recíprocos.

teable release.2026-11-21T01-51-32Z.4009

Feature Updates

  • Added strict and read-only MCP endpoints. The strict endpoint separates read and write actions so compatible AI clients can ask for confirmation before making changes. The read-only endpoint supports clients that cannot confirm writes. Existing MCP integrations are unchanged.
  • Added a Query Library for each Base. Members can save, find, compare, and share private-by-default query revisions. Queries run with the caller’s current data permissions, and published apps can pin a specific revision. Revoking access prevents apps from running the pinned query until access is restored or the app is updated. This feature requires both Query Library and native query execution to be enabled.
  • Plain-text paste across tables now supports two-way many-to-many links. Pasted titles match existing records in the linked table, and reciprocal links are updated without creating duplicates.
  • Table members can now see whether search acceleration is active, which fields it covers, and when its status changes. Shared views show availability only for fields visible in the view.

Bug Fixes & Improvements

  • Updated the OpenAI plugin package to version 1.0.1 and shortened AI instructions so they are no longer cut off in Claude Code.
  • Improved v2 computed-field reliability while reducing unnecessary database load.
  • Improved resource restore and deletion reliability, including a fix for restored v2 tables that could remain listed in the trash.
  • Row prefilling now keeps permitted values and skips only new select options the editor cannot create. If the paste contains only a restricted option, it still returns a permission error.
  • Fixed failures when fields were created concurrently on the same table or while a long-running operation was in progress. New fields now reliably appear in the field list and default view.
  • Cuppy now explains when a task stops because it runs out of memory. Completed steps remain visible, and web users can resume from the latest reply without starting over.
  • Fixed filtered lookups and rollups so deleting linked records recalculates only the affected parent records. Deletion is also faster for large linked datasets.
  • Improved Base share security so visitors can access only content within the configured share scope.
  • Fixed errors in Dashboard charts that use table data. Chart totals now reflect the data each viewer has permission to read, including row-level restrictions.
  • Improved V2 API performance for batch updates across multiple linked-record fields while preserving link order and keeping reciprocal links in sync.
