lanzamiento de mesa.2026-11-05T08-33-35Z.3779

Actualizaciones de funciones

  • Se agregó una opción de descarga de aplicaciones móviles al menú de usuario.
  • Se agregó soporte de dominio personalizado para aplicaciones publicadas en instancias autohospedadas.
  • Se agregó configuración OIDC en toda la instancia para App Builder, lo que permite que las aplicaciones ofrezcan "Continuar con SSO" junto con los métodos de inicio de sesión existentes.
  • Configuración simplificada del token de acceso personal con cuatro ajustes preestablecidos de permisos, permisos de lectura/escritura agrupados, permisos individuales con capacidad de búsqueda y una cobertura de acceso más clara. Las listas de tokens ahora muestran ajustes preestablecidos, admiten la caducidad y la clasificación por último uso, y resaltan los tokens caducados o que están a punto de caducar.

Corrección de errores y mejoras

  • Se mejoró el diseño del espacio en ventanas más pequeñas con el colapso automático de la barra lateral y mensajes de actualización del diseño ubicados correctamente. Los teléfonos siguen utilizando el diseño clásico.
  • Se corrigió la configuración de Kanban para que el mensaje del campo de agrupación se cierre después de la configuración y los registros creados en una columna hereden su valor de selección única.
  • Tarjetas de importación de proyectos mejoradas con nombres de fuentes más claros, estilo consistente y mejor ajuste de texto. Las pestañas de recursos ahora muestran íconos de tablas personalizados cuando están disponibles.
  • Manejo de errores de autenticación mejorado para que MCP clients pueda solicitar a los usuarios que inicien sesión nuevamente cuando sea necesario sin descartar credenciales válidas durante fallas temporales. Las solicitudes de tokens con velocidad limitada ahora incluyen tiempo de reintento y el CLI proporciona instrucciones de inicio de sesión claras.
  • Los chats nuevos ahora se crean solo cuando se envía el primer mensaje, lo que evita conversaciones vacías en el historial de chat. Los borradores no enviados en conversaciones nuevas sobreviven a las actualizaciones de la página.
  • Rendimiento de carga inicial mejorado para chats y mesas.
  • Se mejoró el rendimiento de las actualizaciones masivas y se redujo el uso de memoria, especialmente para tablas anchas cuando se cambian solo unos pocos campos.
  • Recuperación mejorada después de conversiones de campo fallidas.
  • La opción de dominio personalizado autohospedado ahora abre la guía de configuración en lugar de un cuadro de diálogo no compatible. Se corrigieron redirecciones de inicio de sesión a dominios asignados y errores durante la verificación del dominio.
  • Las sesiones de App Builder ahora se renuevan durante el uso continuo, incluso en aplicaciones integradas, respetando los permisos de acceso actuales y la configuración de inicio de sesión.
  • Se reorganizó la configuración de administración de IA en las secciones Modelos, Chat de IA y Creador de aplicaciones con indicadores de estado, orientación de configuración, resúmenes de configuración más claros y diseños de pantalla estrecha mejorados.
  • Se corrigió la selección del modelo de chat para incluir modelos de puerta de enlace y de proveedor personalizado, agrupados por fuente. Mapeo de modelos mejorado con selecciones más claras, desplazamiento y resultados de búsqueda más relevantes.
  • Se restauraron los indicadores de progreso de importación de tablas en páginas para compartir editables y se mejoraron la privacidad y seguridad de los enlaces compartidos.
  • Se corrigió el acceso a los artefactos generados por las Rutinas. La publicación o activación de una rutina ahora asigna la propiedad a ese usuario, con notificaciones de transferencia cuando la propiedad cambia.
  • Los chats de ejecución rutinaria ahora son visibles para los miembros elegibles de la tarea, mientras que solo el propietario puede continuar o administrar la conversación.
  • Se mejoró la seguridad y confiabilidad de las importaciones basadas en URL.
  • Se corrigieron fallas de publicación de aplicaciones para proyectos que contienen texto grande, consultas generadas o archivos GeoJSON.
  • Se restauró la navegación con deslizamiento hacia la izquierda de Android hasta la conversación original y se mejoró el desplazamiento de la galería móvil para reducir el arrastre accidental de celdas.

teable release.2026-11-05T08-33-35Z.3779

Feature Updates

  • Added a mobile app download option to the user menu.
  • Added custom domain support for published apps on self-hosted instances.
  • Added instance-wide OIDC configuration for App Builder, enabling apps to offer “Continue with SSO” alongside existing sign-in methods.
  • Simplified personal access token configuration with four permission presets, grouped read/write permissions, searchable individual permissions, and clearer access coverage. Token lists now show presets, support expiration and last-use sorting, and highlight expired or soon-to-expire tokens.

Bug Fixes & Improvements

  • Improved the space layout on smaller windows with automatic sidebar collapsing and correctly positioned layout update prompts. Phones continue to use the classic layout.
  • Fixed Kanban setup so the grouping-field prompt closes after configuration and records created in a column inherit its single-select value.
  • Improved project import cards with clearer source names, consistent styling, and better text wrapping. Resource tabs now show custom table icons when available.
  • Improved authentication error handling so MCP clients can prompt users to sign in again when needed without discarding valid credentials during temporary failures. Rate-limited token requests now include retry timing, and the CLI provides a clear sign-in instruction.
  • New chats are now created only when the first message is sent, preventing empty conversations in chat history. Unsent drafts in new conversations survive page refreshes.
  • Improved initial loading performance for chats and tables.
  • Improved large bulk update performance and reduced memory use, especially for wide tables when changing only a few fields.
  • Improved recovery after failed field conversions.
  • The self-hosted Custom domain option now opens the setup guide instead of an unsupported dialog. Fixed sign-in redirects to mapped domains and errors during domain verification.
  • App Builder sessions now renew during continued use, including in embedded apps, while respecting current access permissions and login settings.
  • Reorganized Admin AI Settings into Models, AI Chat, and App Builder sections with status indicators, setup guidance, clearer configuration summaries, and improved narrow-screen layouts.
  • Fixed chat model selection to include both gateway and custom-provider models, grouped by source. Improved model mapping with clearer selections, scrolling, and more relevant search results.
  • Restored table import progress indicators on editable share pages and improved share-link privacy and security.
  • Fixed access to artifacts generated by Routines. Publishing or activating a Routine now assigns ownership to that user, with handover notifications when ownership changes.
  • Routine run chats are now visible to eligible task members, while only the owner can continue or manage the conversation.
  • Improved the security and reliability of URL-based imports.
  • Fixed app publishing failures for projects containing large text, generated query, or GeoJSON files.
  • Restored Android left-swipe navigation back to the originating conversation and improved mobile gallery scrolling to reduce accidental cell dragging.
