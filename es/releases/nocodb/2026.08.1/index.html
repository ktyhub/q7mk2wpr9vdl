Presencia en tiempo real en la cuadrícula

Disponibilidad

| Característica | Edición comunitaria | Plan sin nube | Planes pagos en la nube/local | | --- | --- | --- | --- | | Presencia en tiempo real | ✅ | ✅ | ✅ | | Carpetas | ✅ | ✅ | ✅ | | Congelar múltiples campos | ✅ | ✅ | ✅ | | Registros anidados en Vista de lista | – | – | ✅ | | Permisos para paneles | – | – | ✅ | ##Presencia en tiempo real en la cuadrícula Presencia en tiempo real te permite ver a tu equipo dentro de la cuadrícula. Cada colaborador recibe un color que lo sigue de celda en celda, y los registros que tiene abiertos llevan una insignia de presencia. ¿Revisar datos juntos en una llamada? Click Ve allí y aterrizarás exactamente donde están trabajando. Más información sobre Presencia en tiempo real →

Carpetas

Carpetas le permite agrupar tablas, documentos y paneles en carpetas plegables. Lo mismo se aplica a las vistas dentro de una tabla. Disponible en todos los planes, en NocoDB Cloud y en implementaciones autohospedadas. Más información sobre Carpetas →

Congelar múltiples campos

Las vistas de cuadrícula ahora pueden mantener hasta tres campos, incluido el valor de visualización, fijados mientras se desplaza horizontalmente. Arrastra el divisor para elegir cuántos campos permanecen congelados. Los campos congelados también se admiten en páginas de interfaz que utilizan la visualización de cuadrícula. Más información

Registros anidados en Vista de lista

Las listas ahora pueden anidar registros bajo sus padres usando un campo de enlace que apunta a la misma tabla: piense en tareas con subtareas, categorías con elementos o un organigrama. Los registros anidados también están disponibles en las páginas de la interfaz que utilizan la visualización de Lista. Más información

Copiar la configuración de una vista existente

Al crear una página de revisión de tabla o registro de interfaz, el paso Conectarse a una tabla ahora ofrece una opción Copiar configuración desde una vista que genera la nueva página desde una vista existente. Más información - Más control sobre los campos de la interfaz - Las páginas de registro y los formularios obtienen una opción de Tamaño por campo para ampliar las entradas importantes, los campos de selección única en las páginas de registro se pueden mostrar como un Paso a paso que recorre las opciones de una en una click con indicadores numerados o de puntos, y el panel Campos ahora admite el reordenamiento mediante arrastrar y soltar en cada visualización.

  • Permisos del panel: los paneles obtienen permisos de Visibilidad y Edición por panel, utilizando el mismo sistema de permisos que las tablas y campos, para que pueda controlar quién ve o edita cada panel. Más información
  • Filtrar por usuarios del sistema - Los filtros Creado por y Última modificación por ahora enumeran los actores de servicio propios de NocoDB: Automatización, Sincronización, Flujo de trabajo y Anónimo para envíos de formularios públicos. - Adjuntos de URL en flujos de trabajo - Los nodos de flujo de trabajo de creación y actualización de registros ahora pueden completar campos adjuntos de URL.
  • Mejoras API - El punto final de inserción de registros v3 ahora acepta campos de enlace en línea, resolviendo registros vinculados por ID o valor de visualización, y el esquema de campo v3 ahora expone el símbolo de moneda resuelto para los campos de moneda.

¿Qué está arreglado?

  • Inicio de sesión de dos factores en la aplicación instalada - La autenticación de dos factores ahora funciona sin problemas cuando NocoDB está instalado como una aplicación (PWA).
  • Nombres de instantáneas programadas: las instantáneas automáticas ahora reciben nombres utilizando la zona horaria del programa, por lo que una instantánea nocturna lleva la fecha en que realmente se ejecutó en su zona horaria.
  • Vista previa de texto enriquecido en la cuadrícula - Los campos de texto largo con texto enriquecido habilitado ahora se muestran limpiamente en la vista previa de la cuadrícula, con los caracteres especiales mostrados correctamente y las URL de los enlaces conservadas.
  • Recuperación de respuesta del asistente de IA: una respuesta interrumpida por una conexión interrumpida o una actualización de página ahora se reanuda donde se quedó.
  • Las actualizaciones de campo a través de API mantienen los campos dependientes - La actualización de un campo a través de API ahora se trata como una actualización parcial, preservando el código QR y los campos de código de barras que hacen referencia a él.
  • Permisos de campo de vínculo: los permisos de edición de campo ahora se aplican al vincular registros a través del API, incluidas las inserciones y actualizaciones anidadas, y el selector de vínculo respeta los campos de vínculo de solo lectura.
  • Correcciones del generador de interfaz - Los diseños de detalles de registros se pueden eliminar independientemente de su página, los filtros copiados de una vista se muestran en el generador, el formulario de nuevo registro de un botón comienza desde los propios campos de la página y clihacer doble un registro en una página donde la edición en línea está desactivada ofrece activar Editar registros en línea.
  • Permisos de interfaz: las páginas de interfaz ahora respetan los permisos de edición de campos configurados en la base, las vistas previas de solo lectura muestran un aviso cuando intenta editar y eliminar a un miembro de un espacio de trabajo también elimina su acceso a la interfaz. El acceso otorgado a través de equipos ahora aparece y se aplica correctamente, y las opciones de rol en el cuadro de diálogo para compartir incluyen texto de ayuda que explica lo que puede hacer cada rol.
  • Pulido del diseño de la interfaz: las páginas de la interfaz se pueden reordenar arrastrándolas en la barra lateral, los grupos en los formularios de registros se pueden reordenar arrastrándolos, las entradas de los formularios se ubican bajo sus propias etiquetas en filas divididas, las columnas de visualización de listas mantienen su ancho después de cambiar el tamaño y la navegación con el teclado en las listas mantiene visible el registro seleccionado.
  • Líneas de cuadrícula en modo claro - Las líneas de filas y columnas son más fáciles de ver en modo claro, tanto en la vista de cuadrícula como en la de lista.
  • Campos nuevos en vistas personales y bloqueadas - Las vistas personales y bloqueadas mantienen su lista de campos configurados: los campos agregados a la tabla permanecen ocultos hasta que el propietario de la vista los muestra.
  • Condiciones de visibilidad del botón: las condiciones de visibilidad en los campos del botón se conservan cuando se editan los campos a los que hacen referencia.
  • Correcciones en el flujo de trabajo - Las ramas después de un nodo de condición ahora siguen el puerto que el nodo realmente emitió, las URL de los archivos adjuntos que contienen comas se manejan como un solo archivo adjunto, los registros vinculados por su valor de visualización funcionan con comillas y otros caracteres especiales, ahora se pueden usar filtros dinámicos (variables) en los campos de fórmula y los filtros emergentes permanecen completamente visibles dentro de la ventana.
  • Editabilidad de texto inteligente: los campos de texto inteligente existentes permanecen editables en implementaciones donde no se pueden habilitar nuevos campos de texto inteligente.
  • Conversión de campos UUID y AutoNumber: la conversión de un campo fuera de UUID o AutoNumber ahora borra su estado de solo lectura y la capacidad de nulidad de la columna subyacente permanece sincronizada con la configuración del campo.
  • Errores de inicio de sesión de SSO: un inicio de sesión de SSO fallido ahora muestra una página de error clara que explica qué salió mal.
  • Duplicación de bases con archivos adjuntos - Las bases se duplican de manera confiable incluso cuando contienen archivos adjuntos cargados por otros miembros.

Notas de autohospedaje

  • Tokens API heredados: la creación de nuevos tokens API heredados ya no se admite en implementaciones autohospedadas con licencia. Los tokens API heredados existentes siguen funcionando; utilice tokens API detallados para nuevas integraciones. Más información
  • Variables de ejecución de código y búsqueda web renombradas - Las variables de entorno E2B y Exa cambian de nombre:
  • Cambios de nombre del entorno | VARIABLE DE ENTORNO ANTIGUA | NUEVA VARIABLE DE ENTORNO | | --- | --- | | E2B_API_KEY | NC_COMPUTE_E2B_API_KEY | | E2B_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_SCRIPT | | E2B_CHAT_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_CHAT | | EXA_API_KEY | NC_WEB_EXA_API_KEY | Si los estaba usando, las antiguas variables de entorno ya no se leen: actualícelas al actualizar o ejecución de scripts, análisis de código de IA y búsqueda web de IA. Las variables de plantilla ahora son opcionales y recurren a las propias plantillas de NocoDB. Más información

Documentación renovada

  • A medida que NocoDB continúa creciendo, sentimos que este es el momento adecuado para renovar nuestra documentación. Las pestañas dedicadas cubren Producto, Flujos de trabajo, Interfaces, API y MCP, Autohospedaje y Changelog, y la barra lateral de Producto ahora agrupa páginas en Principal, Administrar y Conectar para que los temas relacionados se mantengan juntos. Cada URL anterior en los documentos se redirigirá correctamente a la página correcta.
  • Pregúntale a AI en documentos: cada página de documentos ahora incluye un asistente Pregunta a AI que responde preguntas en lenguaje sencillo utilizando la documentación como fuente, para que puedas preguntar "cómo hago X" en lugar de buscar entre páginas.

Realtime Presence in Grid

Availability

| Feature | Community Edition | Cloud Free Plan | Paid Plans In Cloud/On-Prem | | --- | --- | --- | --- | | Realtime Presence | ✅ | ✅ | ✅ | | Folders | ✅ | ✅ | ✅ | | Freeze multiple fields | ✅ | ✅ | ✅ | | Nested records in List View | – | – | ✅ | | Permissions for Dashboards | – | – | ✅ |

##Realtime Presence in Grid

Realtime Presence lets you see your team inside the grid. Each collaborator gets a colour that follows them from cell to cell, and records they have open carry a presence badge. Reviewing data together on a call? Click Go there and you land exactly where they're working.

Learn more about Realtime Presence →

Folders

Folders lets you group tables, documents, and dashboards into collapsible folders. Same applies to views within a table. Available on all plans, on NocoDB Cloud and self-hosted deployments.

Learn more about Folders →

Freeze multiple fields

Grid views can now keep up to three fields, including the display value, pinned while you scroll horizontally. Drag the divider to choose how many fields stay frozen. Frozen fields are also supported on interface pages that use the Grid visualization. Learn more

Nested records in List View

Lists can now nest records under their parents using a link field that points back to the same table: think tasks with subtasks, categories with items, or an org chart. Nested records are also available on interface pages that use the List visualization. Learn more

Copy settings from an existing view

When creating an interface Table or Record review page, the Connect to a table step now offers a Copy settings from a view option that seeds the new page from an existing view. Learn more

- More control over interface fields - Record pages and forms gain a per-field Size option to scale up important inputs, Single Select fields on record pages can display as a Stepper that walks through options one click at a time with dot or numbered indicators, and the Fields pane now supports drag-and-drop reordering across every visualization.

  • Dashboard permissions - Dashboards gain per-dashboard Visibility and Editing permissions, using the same permission system as tables and fields, so you can control who sees or edits each dashboard. Learn more
  • Filter by system users - Created By and Last Modified By filters now list NocoDB's own service actors: Automation, Sync, Workflow, and Anonymous for public form submissions.

- Attachments from URLs in workflows - The create record and update record workflow nodes can now fill attachment fields from URLs.

  • API improvements - The v3 records upsert endpoint now accepts link fields inline, resolving linked records by ID or display value, and the v3 field schema now exposes the resolved currency symbol for Currency fields.

What's Fixed

  • Two-factor sign-in in the installed app - Two-factor authentication now works smoothly when NocoDB is installed as an app (PWA).
  • Scheduled snapshot names - Automatic snapshots are now named using the schedule's timezone, so a nightly snapshot carries the date it actually ran in your timezone.
  • Rich text preview in grid - Long Text fields with rich text enabled now render cleanly in the grid preview, with special characters displayed correctly and link URLs preserved.
  • AI assistant response recovery - A response interrupted by a dropped connection or a page refresh now resumes where it left off.
  • Field updates via API keep dependent fields - Updating a field through the API is now treated as a partial update, preserving QR code and Barcode fields that reference it.
  • Link field permissions - Field edit permissions are now enforced when linking records through the API, including nested inserts and updates, and the link picker respects read-only link fields.
  • Interface builder fixes - Record detail layouts can be deleted independently of their page, filters copied from a view show up in the builder, a button's new-record form starts from the page's own fields, and double-clicking a record on a page where inline editing is off offers to turn on Edit records inline.
  • Interface permissions - Interface pages now respect the field edit permissions configured on the base, read-only previews show a notice when you try to edit, and removing a member from a workspace also removes their interface access. Access granted through teams is now listed and enforced correctly, and the role options in the share dialog carry help text explaining what each role can do.
  • Interface layout polish - Interface pages can be reordered by dragging them in the sidebar, groups on record forms can be reordered by dragging, form inputs sit under their own labels in split rows, List visualization columns keep their widths after resizing, and keyboard navigation in lists keeps the selected record visible.
  • Grid lines in light mode - Row and column lines are easier to see in light mode, in both Grid and List views.
  • New fields in personal and locked views - Personal and locked views keep their configured field list: fields added to the table stay hidden until the view's owner shows them.
  • Button visibility conditions - Visibility conditions on Button fields are preserved when the fields they reference are edited.
  • Workflow fixes - Branches after a condition node now follow the port the node actually emitted, attachment URLs containing commas are handled as a single attachment, linking records by their display value works with quotes and other special characters, dynamic (variable) filters can now be used on Formula fields, and filter popovers stay fully visible within the window.
  • Smart Text editability - Existing Smart Text fields stay editable on deployments where new Smart Text fields cannot be enabled.
  • Converting UUID and AutoNumber fields - Converting a field away from UUID or AutoNumber now clears its read-only state, and the underlying column's nullability stays in sync with the field settings.
  • SSO sign-in errors - A failed SSO sign-in now shows a clear error page explaining what went wrong.
  • Base duplication with attachments - Bases duplicate reliably even when they contain attachments uploaded by other members.

Self-Hosting Notes

  • Legacy API tokens - Creation of new legacy API tokens is no longer supported on licensed self-hosted deployments. Existing legacy API tokens continue to work; use fine-grained API tokens for new integrations. Learn more
  • Renamed code-execution and web-search variables - The E2B and Exa environment variables are renamed:
  • Environment name changes

| OLD ENVIRONMENT VARIABLE | NEW ENVIRONMENT VARIABLE | | --- | --- | | E2B_API_KEY | NC_COMPUTE_E2B_API_KEY | | E2B_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_SCRIPT | | E2B_CHAT_TEMPLATE_ID | NC_COMPUTE_E2B_TEMPLATE_CHAT | | EXA_API_KEY | NC_WEB_EXA_API_KEY |

If you were using these, the old environment variables are no longer read: update them when upgrading, or script execution, AI code analysis, and AI web search. The template variables are now optional and fall back to NocoDB's own templates. Learn more

Documentation Get A Revamp

  • As NocoDB continues to grow -we felt this is the right time revamp our documentations. Dedicated tabs cover Product, Workflows, Interfaces, APIs & MCP, Self Hosting, and Changelog, and the Product sidebar now groups pages under Core, Manage, and Connect so related topics sit together. Every previous URL in docs will be redirected correctly to the right page.

  • Ask AI in docs - Every docs page now includes an Ask AI assistant that answers questions in plain language using the documentation as its source, so you can ask "how do I do X" instead of hunting through pages.

For more details on the features introduced in 2026.08.0, see the 2026.08.0 changelog.
