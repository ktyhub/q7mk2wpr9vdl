⚠️ Las marcas de tiempo incluyen milisegundos. En PostgreSQL y SQLite, los valores de fecha y hora en las respuestas de API, las cargas útiles de webhook y las exportaciones CSV ahora incluyen milisegundos (12:34:56.000+00:00). Consulta integraciones que leen fechas en un formato fijo. MCP enumera todas las herramientas. El servidor MCP en /mcp ahora enumera todas las herramientas. Si Windsurf o VS Code Copilot muestra demasiadas herramientas, conéctelo nuevamente con la URL /mcp-discovery. Más información Los cambios de contraseña cierran sesión en tus aplicaciones. Cambiar tu contraseña elimina tus tokens API y desconecta las aplicaciones que autorizaste con OAuth. Más información

Mejoras

  • Aplicaciones clásicas en teléfonos: las aplicaciones clásicas publicadas se adaptan a las pantallas de los teléfonos, incluidas la barra lateral, las barras de herramientas, los formularios de registro, los grupos de paneles y los widgets dinámicos.
  • Agrupar por más tipos de campos: las páginas de aplicaciones clásicas se agrupan por campos de enlaces, fórmulas, búsquedas, resumen y recuento de enlaces, y los widgets de lista obtienen un grupo por configuración. Más información
  • Cambiar el tamaño de las columnas en aplicaciones clásicas - Arrastre el borde de una columna en un widget de Lista para cambiar su tamaño. Los constructores guardan el ancho para todos. Más información
  • Abrir registros desde los widgets de visualización - Los widgets de calendario, línea de tiempo y Gantt en un panel pueden abrir un registro cuando cli lo marca. Más información
  • Ocultar títulos de widgets - Los widgets de datos, gráficos y números en una aplicación clásica tienen un interruptor Mostrar título.
  • Visibilidad de los botones por función: los botones de página en una aplicación clásica solo pueden mostrarse para las funciones que usted elija. Más información
  • Reordenar pestañas de filtro de usuario: los creadores arrastran las pestañas de filtro de usuario a un nuevo orden. Más información
  • Ordenar selección única por orden de opciones - Una clasificación en un campo de selección única puede seguir el orden de sus opciones en lugar de la A a la Z. Más información
  • Cerrar sesión en otros dispositivos - Cuenta > Seguridad cierra sesión en todos lados excepto en el navegador actual en NocoDB Cloud. Más información
  • Plantillas en Inicio - La página Inicio y Nuevo proyecto muestran una galería de plantillas en NocoDB Cloud, y los proyectos creados con IA comienzan con algunos registros de muestra. Más información
  • Griego - NocoDB ahora está disponible en griego. Más información
  • Límites de tasa de MCP - MCP tiene su propio límite por cuenta. A un client que lo repasa se le dice cuánto tiempo debe esperar.
  • Aplicaciones conectadas a MCP: la lista de aplicaciones conectadas muestra cuándo se utilizó por última vez cada aplicación. Más información
  • Pantalla de consentimiento de OAuth: la pantalla de consentimiento muestra dónde será enviado y advierte cuando NocoDB no verifica una aplicación.
  • Actualizaciones en vivo - La galería, Kanban, mapa, paneles y revisión de registros de aplicaciones clásicas se actualizan cuando los colaboradores editan.

¿Qué está arreglado?

  • Flujos de trabajo y webhooks - Cuando se actualiza el registro los flujos de trabajo y los webhooks de actualización se ejecutan cuando los registros se vinculan o desvinculan a través del API, se pegan o se cambia una clave externa. Más información
  • Fórmulas: las fórmulas con ? dentro del texto se evalúan, los valores de las casillas de verificación actúan como 1 y 0 en las fórmulas PostgreSQL y los resultados XOR se pueden filtrar.
  • Filtros - está en blanco los filtros en los resúmenes funcionan y los filtros me gusta en los campos de usuario solo coinciden con los nombres.
  • Enlaces: los campos uno a uno autovinculados muestran el registro vinculado y los proyectos duplicados mantienen sus vínculos.
  • Copiar datos - Duplicar e importar un proyecto mantiene los valores de texto largo y JSON con más de 100.000 caracteres.
  • Aplicaciones clásicas: la búsqueda en el generador, los selectores de enlaces en formularios, las etiquetas de la línea de tiempo, los nombres de páginas predeterminados, los campos de formulario no ocultos, las barras de desplazamiento de listas y los colores de filas condicionales se comportan como se esperaba.
  • Compartir: el cuadro de diálogo Compartir de la aplicación clásica puede otorgarle a un miembro existente un rol superior, y una segunda invitación mantiene funcionando el primer enlace de invitación.
  • Adjuntos - Las teclas Escape y de flecha funcionan en la vista previa del archivo adjunto en todos los lugares donde se abre.
  • Tablas: una nueva tabla puede tomar el nombre de una tabla eliminada, incluso cerca del límite de longitud del nombre de la base de datos.
  • SQL Server y Oracle: las clasificaciones que repiten un trabajo de campo en SQL Server y en Oracle un campo numérico se convierten a clasificación decimal y de fórmulas de texto.
  • Chat AI - El chat funciona con las integraciones de Claude Opus 5.5, Sonnet 5.5 y Fable 5.1.
  • Iniciar sesión: Olvidar tu contraseña ya no cierra la sesión y los errores de inicio de sesión muestran un mensaje para cada caso.

Notas de autohospedaje

  • Primer registro: en una nueva instalación con licencia, el primer superadministrador obtiene el espacio de trabajo y la organización predeterminados sin necesidad de reiniciar.
  • Actualización de licencia - Actualizar en la página Licencia, o reiniciar, activa una licencia que se muestra como pendiente. Más información
  • Adjuntos seguros - Configurar solo NC_ATTACHMENT_ACCESS_CONTROL_ENABLED=true ahora activa los archivos adjuntos seguros, por lo que /download y /dl dejan de servir archivos. Utilice las URL firmadas que devuelven las respuestas de los archivos adjuntos. Más información
  • Bases de datos locales - ClickHouse en una red privada y MySQL o PostgreSQL en un socket Unix, necesitan NC_ALLOW_LOCAL_EXTERNAL_DBS=true. Más información
  • Tokens MCP: los secretos de los tokens MCP se almacenan con hash y se muestran solo una vez. Los tokens que ya están en su MCP clients siguen funcionando.
  • Nombres de tablas largos - Los nuevos nombres de tablas de SQL Server y Oracle están limitados a 125 caracteres.
  • Reforzamiento de la seguridad: se refuerzan el registro, las invitaciones, OAuth, las vistas compartidas, las exportaciones de datos, las conexiones de bases de datos y los secretos almacenados, y se parchean las dependencias.

Para obtener más detalles sobre las funciones introducidas en 2026.10.0, consulte 2026.10.0 changelog.

nocodb 2026.10.1

<img width="1865" height="1147" alt="Group 115" src="https://github.com/user-attachments/assets/1f72ed6f-1f2b-4f89-a033-66b572c6bd90" />

⚠️ Timestamps include milliseconds. On PostgreSQL and SQLite, date and time values in API responses, webhook payloads and CSV exports now include milliseconds (12:34:56.000+00:00). Check integrations that read dates in a fixed format.

MCP lists every tool. The MCP server at /mcp now lists every tool. If Windsurf or VS Code Copilot shows too many tools, connect it again with the /mcp-discovery URL. Learn more

Password changes sign out your apps. Changing your password deletes your API tokens and disconnects apps you authorized with OAuth. Learn more

Improvements

  • Classic apps on phones - Published classic apps fit phone screens, including the sidebar, toolbars, record forms, dashboard groups and pivot widgets.
  • Group by more field types - Classic app pages group by Links, Formula, Lookup, Rollup and link count fields, and List widgets get a group by setting. Learn more
  • Resize columns in classic apps - Drag a column edge in a List widget to resize it. Builders save the width for everyone. Learn more
  • Open records from view widgets - Calendar, Timeline and Gantt widgets on a dashboard can open a record when you click it. Learn more
  • Hide widget titles - Data, chart and number widgets in a classic app have a Show title switch.
  • Button visibility by role - Page buttons in a classic app can show only to the roles you choose. Learn more
  • Reorder user filter tabs - Builders drag user filter tabs into a new order. Learn more
  • Sort Single Select by option order - A sort on a Single Select field can follow the order of its options instead of A to Z. Learn more
  • Sign out of other devices - Account > Security signs you out everywhere except the current browser on NocoDB Cloud. Learn more
  • Templates on Home - Home and the New project page show a template gallery on NocoDB Cloud, and projects built with AI start with a few sample records. Learn more
  • Greek - NocoDB is now available in Greek. Learn more
  • MCP rate limits - MCP has its own limit per account. A client that goes over it is told how long to wait.
  • MCP connected apps - The list of connected apps shows when each app was last used. Learn more
  • OAuth consent screen - The consent screen shows where you will be sent and warns when an app is not verified by NocoDB.
  • Live updates - Gallery, Kanban, Map, dashboards and classic app record review refresh in place when collaborators edit.

What's Fixed

  • Workflows and webhooks - When record updated workflows and update webhooks run when records are linked or unlinked through the API, paste or a foreign key change. Learn more
  • Formulas - Formulas with ? inside text evaluate, Checkbox values act as 1 and 0 in PostgreSQL formulas, and XOR results can be filtered.
  • Filters - is blank filters on Rollups work, and like filters on User fields match names only.
  • Links - Self-linking one-to-one fields show the linked record, and duplicated projects keep their links.
  • Copying data - Duplicating and importing a project keeps Long Text and JSON values longer than 100,000 characters.
  • Classic apps - Search in the builder, link pickers in forms, Timeline labels, default page names, unhidden form fields, list scrollbars and conditional row colors behave as expected.
  • Sharing - The classic app Share dialog can give an existing member a higher role, and a second invite keeps the first invite link working.
  • Attachments - Escape and arrow keys work in the attachment preview everywhere it opens.
  • Tables - A new table can take a trashed table's name, even near the database name length limit.
  • SQL Server and Oracle - Sorts that repeat a field work on SQL Server, and on Oracle a Number field converts to Decimal and text formulas sort.
  • AI chat - Chat works with Claude Opus 5.5, Sonnet 5.5 and Fable 5.1 integrations.
  • Sign-in - Forgetting your password no longer signs you out, and sign-in errors show one message for every case.

Self-Hosting Notes

  • First sign-up - On a new licensed install, the first super admin gets the default workspace and organization without a restart.
  • License refresh - Refresh on the License page, or a restart, activates a license that shows as pending. Learn more
  • Secure attachments - Setting only NC_ATTACHMENT_ACCESS_CONTROL_ENABLED=true now turns on secure attachments, so /download and /dl stop serving files. Use the signed URLs that attachment responses return. Learn more
  • Local databases - ClickHouse on a private network, and MySQL or PostgreSQL over a Unix socket, need NC_ALLOW_LOCAL_EXTERNAL_DBS=true. Learn more
  • MCP tokens - MCP token secrets are stored hashed and shown only once. Tokens already in your MCP clients keep working.
  • Long table names - New SQL Server and Oracle table names are limited to 125 characters.
  • Security hardening - Sign-up, invitations, OAuth, shared views, data exports, database connections and stored secrets are hardened, and dependencies are patched.

For more details on the features introduced in 2026.10.0, see the 2026.10.0 changelog.
