flujo2 v2.9.6

Destacados

Flux v2.9.6 es una versión de parche que impide que el controlador de helm vuelva a aplicar CRD de gráficos en cada actualización cuando la aplicación del lado del servidor está habilitada y recupera HelmReleases que quedaron con una condición Ready=Unknown desviada después de un parche de estado fallido. source-controller normaliza la lista de ETag de Azure Blob para que los contenedores sin cambios ya no se vuelvan a descargar en cada conciliación, y desaloja las entradas de índice del repositorio Helm obsoletas del caché para que los repositorios con índices que cambian con frecuencia ya no fallen con "El caché está lleno". kustomize-controller extiende la redacción del error de descifrado SOPS a los valores spec.postBuild.substituteFrom, por lo que los secretos sustituidos que se repiten en los errores de validación API se enmascaran de las condiciones y eventos de estado, y agrega la puerta de función opcional DisableCommitStatusEvent. Se anima a los usuarios a actualizar para obtener la mejor experiencia. ℹ️ Siga el Procedimiento de actualización para Flux v2.7+ para una actualización sin problemas de Flux v2.6 a la última versión. Correcciones:

  • Deje de volver a aplicar CRD de gráficos en las actualizaciones cuando utilice la aplicación del lado del servidor con la política predeterminada Create (controlador de timón)
  • Recuperar HelmReleases bloqueados con una condición Ready=Unknown desviada después de un parche de estado fallido (controlador de timón)
  • Ignore NotFound al eliminar HelmChart (controlador de timón)
  • Normalizar la lista de ETags de Azure Blob para que los contenedores sin cambios no se vuelvan a descargar en cada conciliación (controlador de fuente)
  • Expulsar del caché las entradas obsoletas del índice del repositorio de Helm para evitar errores de "El caché está lleno" (controlador de origen)
  • Ampliar la redacción del error de descifrado SOPS a valores spec.postBuild.substituteFrom (kustomize-controller) Mejoras:
  • Agregue la puerta de función opcional DisableCommitStatusEvent (controlador personalizado)

flux2 v2.9.6

Highlights

Flux v2.9.6 is a patch release that stops helm-controller from reapplying chart CRDs on every upgrade when server-side apply is enabled, and recovers HelmReleases left with a drifted Ready=Unknown condition after a failed status patch. source-controller normalizes Azure Blob listing ETags so unchanged containers are no longer re-downloaded on every reconcile, and evicts stale Helm repository index entries from the cache so repositories with frequently changing indexes no longer fail with "Cache is full". kustomize-controller extends SOPS decryption error redaction to spec.postBuild.substituteFrom values, so substituted secrets echoed back in API validation errors are masked out of status conditions and events, and adds the opt-in DisableCommitStatusEvent feature gate. Users are encouraged to upgrade for the best experience.

ℹ️ Please follow the Upgrade Procedure for Flux v2.7+ for a smooth upgrade from Flux v2.6 to the latest version.

Fixes:

  • Stop reapplying chart CRDs on upgrades when using server-side apply with the default Create policy (helm-controller)
  • Recover HelmReleases stranded with a drifted Ready=Unknown condition after a failed status patch (helm-controller)
  • Ignore NotFound when deleting the HelmChart (helm-controller)
  • Normalize Azure Blob listing ETags so unchanged containers are not re-downloaded on every reconcile (source-controller)
  • Evict stale Helm repository index entries from the cache to avoid "Cache is full" errors (source-controller)
  • Extend SOPS decryption error redaction to spec.postBuild.substituteFrom values (kustomize-controller)

Improvements:

  • Add the opt-in DisableCommitStatusEvent feature gate (kustomize-controller)
