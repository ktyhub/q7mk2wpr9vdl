flujo2 v2.9.0

Destacados

Flux v2.9.0 es una versión funcional. Se anima a los usuarios a actualizar para obtener la mejor experiencia. Para obtener una descripción general completa de las nuevas funciones y los cambios del API incluidos en esta versión, consulte la [publicación del blog Anuncio de Flux 2.9 GA] (https://fluxcd.io/blog/2026/06/flux-v2.9.0/). Descripción general de las nuevas funciones:

  • Sistema de complementos Flux CLI con los complementos Mirror y Schema (flux plugin)
  • El campo Aplicar del lado del servidor ignora las reglas para un control de deriva detallado (Kustomization)
  • Descifrado SOPS con el cifrado Age post-cuántico (Kustomization)
  • Autenticación de identidad de carga de trabajo Kubernetes para OpenBao y Vault (Kustomization)
  • Estrategias de post-renderizado de Helm, incluida la compatibilidad con ganchos de gráficos (HelmRelease)
  • Modo literal para referencias de valores de Helm que reflejan helm --set-literal (HelmRelease)
  • Permitir tipos vacíos en expresiones de verificación de estado CEL (Kustomization, HelmRelease)
  • Git commit firma y verificación con claves SSH (GitRepository, ImageUpdateAutomation)
  • Autenticación de AWS CodeCommit mediante Workload Identity (GitRepository)
  • Raíz Sigstore trusted personalizada para verificación sin llave en entornos con espacio de aire (OCIRepository)
  • Descubrimiento de directorio de patrones de ruta para monorepos (ArtifactGenerator)
  • Receptores de webhooks sin secretos y protegidos por OIDC (Receiver) ❤️ ¡Muchas gracias a todos los contribuyentes de Flux que nos ayudaron con este lanzamiento!

Compatibilidad con Kubernetes

Esta versión es compatible con las siguientes versiones de Kubernetes: | Versión Kubernetes | Mínimo requerido | |--------------------|------------| | v1.34 | >= 1.34.1 | | v1.35 | >= 1.35.0 | | v1.36 | >= 1.36.0 |

[!NOTA] Tenga en cuenta que el proyecto Flux ofrece soporte solo para las tres últimas versiones menores de Kubernetes. Proveedores como ControlPlane que brindan soporte empresarial para Flux.

Compatibilidad con OpenShift

Flux se puede instalar en el clúster Red Hat OpenShift directamente desde OperadorHub usando Flux Operador. El operador permite la configuración del bloqueo multiinquilino de Flux, políticas de red, almacenamiento persistente, fragmentación, escalado vertical y sincronización del estado del clúster desde repositorios Git, artefactos OCI y almacenamiento compatible con S3.

Procedimiento de actualización

:advertencia: Los Flux APIs image.toolkit.fluxcd.io/v1beta2 y notification.toolkit.fluxcd.io/v1beta2 han llegado al final de su vida útil y han sido eliminados de los CRD. Siga el Procedimiento de actualización para Flux v2.7+ para una actualización sin problemas desde versiones anteriores de Flux a v2.9.

flux2 v2.9.0

Highlights

Flux v2.9.0 is a feature release. Users are encouraged to upgrade for the best experience.

For a compressive overview of new features and API changes included in this release, please refer to the Announcing Flux 2.9 GA blog post.

Overview of the new features:

  • Flux CLI Plugin System with the Mirror and Schema plugins (flux plugin)
  • Server-Side Apply field ignore rules for fine-grained drift control (Kustomization)
  • SOPS decryption with the Age post-quantum cipher (Kustomization)
  • Kubernetes Workload Identity authentication for OpenBao and Vault (Kustomization)
  • Helm post-render strategies, including chart hooks support (HelmRelease)
  • Literal mode for Helm values references mirroring helm --set-literal (HelmRelease)
  • Allow empty kind in CEL health check expressions (Kustomization, HelmRelease)
  • Git commit signing and verification with SSH keys (GitRepository, ImageUpdateAutomation)
  • AWS CodeCommit authentication using Workload Identity (GitRepository)
  • Custom Sigstore trusted root for keyless verification in air-gapped environments (OCIRepository)
  • Path pattern directory discovery for monorepos (ArtifactGenerator)
  • Secret-less, OIDC-secured webhook Receivers (Receiver)

❤️ Big thanks to all the Flux contributors that helped us with this release!

Kubernetes compatibility

This release is compatible with the following Kubernetes versions:

| Kubernetes version | Minimum required | |--------------------|------------------| | v1.34 | >= 1.34.1 | | v1.35 | >= 1.35.0 | | v1.36 | >= 1.36.0 |

[!NOTE] Note that the Flux project offers support only for the latest three minor versions of Kubernetes. Backwards compatibility with older versions of Kubernetes and OpenShift is offered by vendors such as ControlPlane that provide enterprise support for Flux.

OpenShift compatibility

Flux can be installed on Red Hat OpenShift cluster directly from OperatorHub using Flux Operator. The operator allows the configuration of Flux multi-tenancy lockdown, network policies, persistent storage, sharding, vertical scaling and the synchronization of the cluster state from Git repositories, OCI artifacts, and S3-compatible storage.

Upgrade procedure

:warning: The Flux APIs image.toolkit.fluxcd.io/v1beta2 and notification.toolkit.fluxcd.io/v1beta2 have reached end-of-life and have been removed from the CRDs.

Please follow the Upgrade Procedure for Flux v2.7+ for a smooth upgrade from older versions of Flux to v2.9.
