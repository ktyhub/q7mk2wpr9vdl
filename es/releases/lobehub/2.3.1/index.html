Fuente de contribución: asistida por IA

🚀 Lanzamiento de LobeHub v2.3.1

Promocione la instantánea completa de canary actual a main para una versión estable normal, reemplazando la propuesta de revisión cerrada y no fusionada #22186. Esta no es una revisión de dos confirmaciones.

  • Estable anterior: v2.3.0.
  • Instantánea canaria: 1a6ba7ad3853f140cc5795c5baf5ae37f78c9a13.
  • Alcance: 87 confirmaciones/PR ascendentes, incluidos #22122 (aprobación automática) y #22069 (corrección del token de publicación de lanzamiento).
  • La rama de lanzamiento comienza directamente desde esa instantánea de Canary, además del aumento de versión propiedad del bot y la reparación del paquete de Linux en #22190. No se superponen selecciones de revisión ni funciones adicionales de la aplicación.

Destacados

  • Aprobaciones y confiabilidad del agente: cambie a aprobación automática directamente desde la tarjeta de aprobación; Evite envíos de aprobación duplicados, ejecución duplicada de herramientas en el currículum y continuaciones de intervenciones estancadas. (#22122, #22058, #22060, #22068)
  • Tareas y lineal: acciones de selección múltiple y por lotes de listas grandes, filtros de estilo lineal, acciones de creación de grupos de tareas, actividad paginada, sincronización de comentarios lineales, importaciones de problemas completados y confiabilidad de sincronización en segundo plano. (#22055, #22083, #22136, #22155, #22087, #22086, #22050)
  • Páginas, documentos y archivos: edición de título/cuerpo como un solo documento, correcciones de reescritura del agente de página, favoritos de documentos, descargas de unidades y archivos ZIP de carpetas, y carpetas grandes más fluidas. (#22154, #22141, #22147, #22095, #22106)
  • Proyectos, canales y bots: avatares de proyecto y selección de agente principal, confirmación de eliminación de proyecto, selección de miembros del canal, correcciones de restauración/purga, registros de activación paginados y retrospectivas nocturnas de bots. (#22091, #22101, #22161, #22163, #22081, #22098)
  • Búsqueda, paneles y modelos: Búsqueda/rastreo de DeepSeek, tarjetas de widgets HTML en espacio aislado, correcciones de salida estructurada, correcciones de contabilidad de uso/costos y metadatos oficiales de tarjetas de modelo. (#21298, #22123, #21385, #22071, #22079, #22124)
  • Escritorio y CLI: Copiar imagen, listados de accesos directos del escritorio, empaquetado de escritorio más rápido, mejoras en el reinicio/actualización del conector y CLI v0.0.74. (#22067, #22113, #22121, #22165, #22166, #22179)
  • Implementaciones e infraestructura: integración de planes de nuevo nivel y soporte de implementación porcentual; el diseño del carril alternativo permanece detrás de im_layout. La publicación de lanzamiento utiliza explícitamente el token de la aplicación para que puedan comenzar los flujos de trabajo de publicación posteriores. (#22115, #22143, #22003, #22069)

Actualizar y liberar fuentes

  • Esta versión incluye la migración de la base de datos 0199_topic_analyses.sql, agregando la tabla de análisis de temas, claves externas e índices. Los operadores autohospedados deben incluir el procedimiento normal de copia de seguridad/migración de la base de datos al actualizar.
  • Utilice el flujo de inicialización de la versión normal: resuelva y fije la revisión de la nube para esta nueva versión. No heredar el pin de nube de revisión v2.3.0.
  • Mantenga el título exacto 🚀 release: v2.3.1 para que el bot de versión y el flujo de trabajo de etiquetas coincidan en la versión deseada.

Reparación de paquetes de Linux (#22190)

La primera compilación de escritorio de Linux falló porque la plantilla Snap target del constructor de electrones 26.16.1 eliminó chrome-sandbox del directorio compartido linux-unpacked mientras AppImage lo estaba leyendo. Windows pasó; Los trabajos de macOS fueron cancelados por Matrix Fail-Fast.

  • Se actualizó electron-builder a 26.18.0 y se actualizó el archivo de bloqueo de escritorio aislado, incluida la corrección ascendente electron-userland/electron-builder#10333.
  • Se agregó una regresión de integración contra el empaquetador instalado y archivos temporales reales: falla con ENOENT en 26.16.1, pasa en 26.18.0. Las descargas/ejecución del compresor están bloqueadas; Se ejercen mutaciones reales de puesta en escena, filtrado y sistema de archivos. El asistente permanece intacto para otros objetivos, pero queda excluido de las entradas de Snap.
  • Se modificó el archivo lint, las pruebas de regresión y de empaquetado del núcleo integrado (2 aprobadas), la instalación del archivo de bloqueo congelado y git diff --check aprobadas.
  • La reparación se fusionó a través del n.° 22190 porque las sucursales release/* requieren PR; no se eludió ninguna protección de rama.
  • No se necesita una nueva aceptación de la interfaz de usuario para esta reparación de solo la herramienta de compilación. La nueva ejecución de PR CI está volviendo a verificar el paquete multiplataforma completo; las pruebas locales no afirman una compilación o lanzamiento del instalador real.

🚀 LobeHub Release v2.3.1

Promote the complete current canary snapshot to main for a normal Stable release, replacing the closed, unmerged hotfix proposal #22186. This is not a two-commit hotfix.

  • Previous Stable: v2.3.0.
  • Canary snapshot: 1a6ba7ad3853f140cc5795c5baf5ae37f78c9a13.
  • Scope: 87 upstream commits/PRs, including both #22122 (auto approve) and #22069 (release publication token fix).
  • The release branch starts directly from that Canary snapshot, plus the bot-owned version bump and the Linux packaging repair in #22190. No hotfix cherry-picks or additional application features are layered on top.

Highlights

  • Approvals and agent reliability: switch to auto approve directly from the approval card; prevent duplicate approval submissions, duplicate tool execution on resume, and stuck intervention continuations. (#22122, #22058, #22060, #22068)
  • Tasks and Linear: large-list multi-select and batch actions, Linear-style filters, task-group create actions, paged activity, Linear comment sync, completed-issue imports, and background sync reliability. (#22055, #22083, #22136, #22155, #22087, #22086, #22050)
  • Pages, documents and files: title/body editing as one document, page-agent rewrite fixes, document favorites, drive downloads and folder ZIPs, and smoother large folders. (#22154, #22141, #22147, #22095, #22106)
  • Projects, channels and bots: project avatars and main-agent selection, project deletion confirmation, channel member picking, restore/purge fixes, paged wake records, and nightly bot retrospectives. (#22091, #22101, #22161, #22163, #22081, #22098)
  • Search, dashboards and models: DeepSeek search/crawling, sandboxed HTML widget cards, structured-output fixes, usage/cost accounting fixes, and official model-card metadata. (#21298, #22123, #21385, #22071, #22079, #22124)
  • Desktop and CLI: Copy Image, desktop shortcut listings, faster desktop packaging, connector restart/update improvements, and CLI v0.0.74. (#22067, #22113, #22121, #22165, #22166, #22179)
  • Rollouts and infrastructure: new-tier plan integration and percentage rollout support; the alternate rail layout remains behind im_layout. Release publication explicitly uses the App token so downstream publishing workflows can start. (#22115, #22143, #22003, #22069)

Upgrade and release sources

  • This release includes database migration 0199_topic_analyses.sql, adding the topic-analysis table, foreign keys and indexes. Self-hosted operators should include the normal database backup/migration procedure when upgrading.
  • Use the ordinary release initialization flow: resolve and pin the Cloud revision for this new release. Do not inherit the v2.3.0 hotfix Cloud pin.
  • Keep the exact title 🚀 release: v2.3.1 so the version bot and tag workflow agree on the intended version.

Linux packaging repair (#22190)

The first Linux desktop build failed because electron-builder 26.16.1's template Snap target deleted chrome-sandbox from the shared linux-unpacked directory while AppImage was reading it. Windows passed; the macOS jobs were cancelled by matrix fail-fast.

  • Upgraded electron-builder to 26.18.0 and updated the isolated desktop lockfile, including the upstream fix electron-userland/electron-builder#10333.
  • Added an integration regression against the installed packager and real temporary files: fails with ENOENT on 26.16.1, passes on 26.18.0. Downloads/compressor execution are stubbed; real staging, filtering and filesystem mutations are exercised. The helper stays intact for other targets but is excluded from Snap inputs.
  • Changed-file lint, the regression and builtin-core packaging tests (2 passed), frozen-lockfile installation and git diff --check passed.
  • The repair was merged through #22190 because release/* branches require PRs; no branch protection was bypassed.
  • No new UI acceptance is needed for this build-tool-only repair. Full multi-platform packaging is being rechecked by the new PR CI run; the local tests do not claim a real installer build or launch.
