Lanzamiento v2.3.2

Del PR #22430: https://github.com/lobehub/lobehub/pull/22430

Resumen

Fuente de contribución: asistida por IA

🚀 Lanzamiento de LobeHub (20261106)

Fecha de lanzamiento: 6 de noviembre de 2026
Desde v2.3.1: 127 RP fusionados · 11 contribuyentes

El trabajo diario se vuelve más fácil de organizar y de deshacer: las tareas obtienen etiquetas y una papelera de reciclaje, los canales se comportan como conversaciones reales y las vistas interactivas de MCP se abren directamente dentro del chat.

✨ Destacados

  • Etiquetas de tareas: etiquete tareas, filtre por etiqueta y agrupe vistas por etiqueta, desde la interfaz de usuario web, las herramientas del agente o CLI. (#22176, #22175)
  • Deshacer para acciones de tareas por lotes: las acciones por lotes se aplican instantáneamente con un deshacer y las tareas eliminadas van a la papelera de reciclaje. (#22167)
  • Aplicaciones MCP en conversaciones: las vistas interactivas de las aplicaciones MCP se representan dentro de la conversación. (#21231)
  • Canales en la lista de mensajes: las conversaciones se abren como canales, los mensajes aparecen tan pronto como los envías, los miembros mencionados reciben una notificación y @mencionar a alguien fuera de un canal los invita. (#22205, #22325, #22222, #22294)
  • GitHub Copilot CLI como agente heterogéneo: ejecute Copilot CLI junto con los agentes locales existentes. Codex también obtiene preguntas nativas y selección de velocidad según lo que admite la máquina. (#22195, #22287, #22264)
  • Dispositivos en la nube administrados: conecte uno con lh connect --managed, siga sus fases en la lista de dispositivos y déjelo activar antes de enviar el trabajo. (#22269, #22275, #22274, #22276)
  • Entrada de chat más completa: arrastre los documentos del agente a la entrada, @mencione los agentes y las habilidades del mercado y elija cómo se convierte el texto pegado. (#22104, #22194, #22183)
  • Lista de verificación de configuración del proyecto: los proyectos nuevos enumeran sus pasos básicos y ofrecen conexiones cuando las necesita. (#22279)

🏗️ Producto principal y arquitectura

Tareas y objetivos

  • Busque texto en la página de detalles de la tarea con Mod+F y busque descripciones e instrucciones de la tarea desde la búsqueda global. (#22267, #22256)
  • Archivar objetivos y filtrar la lista de objetivos por Archivados; Los objetivos completados se pueden archivar sin aprobación y están etiquetados como Completado. (#22172, #22259)
  • El miembro asignado puede cambiar mientras se ejecuta una tarea, y el botón Archivar permanece utilizable una vez que la tarea deja de ejecutarse. (#22181, #22321)
  • La asignación masiva al agente se agrupa y confirma antes de asignar un agente privado. (#22300)

Chat y agentes

  • El texto pegado se envía palabra por palabra en lugar de reformatearlo como descuento. (#22189)
  • Las cargas del compositor permanecen con su conversación y un mensaje de inicio rechazado permanece en el compositor. (#22329, #22280)
  • Los temas reenviados continúan en el directorio de trabajo de origen. (#22238)
  • Las ejecuciones grupales muestran el progreso por miembro para tareas paralelas. (#22282)
  • Las herramientas que aún se están ejecutando cuando detienes una ejecución se marcan como canceladas. (#22330)
  • El transporte Pi RPC ahora admite eventos Pi 1.x y se pueden obtener una vista previa de las imágenes de resultados de herramientas de ejecuciones de dispositivos remotos. (#22324, #22211)

Modelos y Generación

  • Los modelos de imágenes GPT pueden generar GIF animados. (#22306)
  • El pensamiento DeepSeek V4 está deshabilitado para la salida estructurada antrópica. (#22369)

📱 Plataformas / Integraciones

  • Lineal: importe problemas que no pertenecen a ningún proyecto, vea el recuento total de problemas en el selector de importación, opcionalmente incluya problemas archivados y ejecute rondas de sincronización de reglas en una sola solicitud. (#22301, #22258, #22340, #22263)
  • Bots: el marcador de posición de procesamiento está desactivado de forma predeterminada con un interruptor en cada plataforma, y ​​los nuevos bots comienzan con las reacciones de estado desactivadas. (#21981, #22182)
  • Bots: los bots le dicen al remitente que carecen de permiso cuando la política de grupo está deshabilitada, y la conexión de prueba de Discord marca un bot desinstalado, una intención deshabilitada o una ID de aplicación que no coincide. (#22187, #22178)
  • Escritorio: cambiar de pestaña con Ctrl+número, con cambio rapid fijo. (#22225)
  • Editor de páginas: el encabezado muestra quién más está en una página activa y el límite de caracteres por página también se aplica a las páginas colaborativas. (#22174, #22277)

🖥️ CLI y experiencia de usuario

  • Nuevo grupo de mando lh connector para conectores MCP. (#22193)
  • lh whoami muestra el alcance informado por el servidor y lh doc list explora documentos más antiguos. (#22254, #21720)
  • lh gen image permite que el servidor elija el modelo predeterminado. (#22197)
  • lh de agentes locales utiliza el inicio de sesión del escritorio y nombra lh login cuando falta. (#22114)
  • Las pestañas del navegador se titulan después de la página o elemento abierto. (#22228)

🔧 Herramientas

  • Se crean nuevos árboles de trabajo en ~/.lobehub/worktrees. (#22203)
  • Las cargas canary de escritorio fallidas ahora se pueden recuperar. (#22312)

🔒 Fiabilidad y actualización

  • Confiabilidad: una ráfaga de realojamientos de imágenes ya no bloquea el grupo de bases de datos y las sondas de almacenamiento de archivos se ejecutan fuera de las transacciones de la base de datos. (#22290, #22385)
  • Confiabilidad: un chat que falla antes de su primer byte devuelve un error estructurado. (#22314)
  • Confiabilidad: la afirmación del administrador de objetivos ya no se vuelve a poner en cola para siempre y las ejecuciones simultáneas inactivas hace mucho tiempo dejan de volver a advertir. (#22209, #22208)
  • Autohospedaje: esta versión incluye las migraciones 0200–0205, que se ejecutan automáticamente al inicio. Añaden channels.config, goals.archived_at, project_sites.last_seen_at, tablas de etiquetas de tareas, enlaces de invitación al espacio de trabajo reutilizables y tablas de evaluación de LobeBench. 0204 también hace que workspace_invitations.expires_at sea anulable y agrega una verificación de que las invitaciones no reutilizables caducan. Realice su copia de seguridad habitual de la base de datos antes de actualizar. (#22173, #22171, #22175, #22278, #22245, #22157)

lobehub v2.3.2

Release v2.3.2

From PR #22430: https://github.com/lobehub/lobehub/pull/22430

Summary

Contribution source: AI-assisted

🚀 LobeHub Release (20261106)

Release Date: November 6, 2026
Since v2.3.1: 127 merged PRs · 11 contributors

Everyday work gets easier to organize and easier to undo: tasks gain labels and a recycle bin, channels behave like real conversations, and interactive MCP views open right inside the chat.

✨ Highlights

  • Task labels — Label tasks, filter by label and group views by label, from the Web UI, Agent tools or the CLI. (#22176, #22175)
  • Undo for batch task actions — Batch actions apply instantly with an undo, and deleted tasks go to a recycle bin. (#22167)
  • MCP Apps in conversations — Interactive views from MCP Apps render inside the conversation. (#21231)
  • Channels in the message list — Conversations open as channels, messages appear as soon as you send them, mentioned members get notified, and @mentioning someone outside a channel invites them. (#22205, #22325, #22222, #22294)
  • GitHub Copilot CLI as a heterogeneous Agent — Run Copilot CLI alongside the existing local Agents. Codex also gains native questions and Speed selection based on what the machine supports. (#22195, #22287, #22264)
  • Managed cloud devices — Connect one with lh connect --managed, follow its phases in the device list, and let it wake before work is dispatched. (#22269, #22275, #22274, #22276)
  • Richer chat input — Drag Agent documents into the input, @mention Agents and Skills from the marketplace, and choose how pasted text converts. (#22104, #22194, #22183)
  • Project setup checklist — New projects list their basic steps and offer connections when you need them. (#22279)

🏗️ Core Product & Architecture

Tasks and Goals

  • Find text in the task detail page with Mod+F, and search task descriptions and instructions from global search. (#22267, #22256)
  • Archive goals and filter the goal list by Archived; completed goals can be archived without a sign-off and are labeled Completed. (#22172, #22259)
  • The member assignee can change while a task runs, and the Archive button stays usable once a task stops running. (#22181, #22321)
  • Bulk Assign to Agent is grouped and confirms before assigning a private Agent. (#22300)

Chat and Agents

  • Pasted text is sent verbatim instead of being reformatted as markdown. (#22189)
  • Composer uploads stay with their conversation, and a refused Home message stays in the composer. (#22329, #22280)
  • Forwarded topics continue in the source working directory. (#22238)
  • Group runs show per-member progress for parallel tasks. (#22282)
  • Tools still running when you stop a run are marked as aborted. (#22330)
  • The Pi RPC transport now supports Pi 1.x events, and tool-result images from remote device runs can be previewed. (#22324, #22211)

Models and Generation

  • GPT Image models can output animated GIFs. (#22306)
  • DeepSeek V4 thinking is disabled for Anthropic structured output. (#22369)

📱 Platforms / Integrations

  • Linear: import issues that belong to no project, see the total issue count in the import picker, optionally include archived issues, and run rule sync rounds in one request. (#22301, #22258, #22340, #22263)
  • Bots: the processing placeholder is off by default with a toggle on every platform, and new bots start with status reactions off. (#21981, #22182)
  • Bots: bots tell the sender they lack permission when group policy is disabled, and Discord test connection flags an uninstalled bot, a disabled intent or an app ID mismatch. (#22187, #22178)
  • Desktop: switch tabs with Ctrl+number, with rapid switching fixed. (#22225)
  • Page editor: the header shows who else is on a live page, and the per-page character limit also applies to collaborative pages. (#22174, #22277)

🖥️ CLI & User Experience

  • New lh connector command group for MCP connectors. (#22193)
  • lh whoami shows the server-reported scope, and lh doc list pages through older documents. (#22254, #21720)
  • lh gen image lets the server pick the default model. (#22197)
  • Local Agents' lh uses the desktop sign-in and names lh login when it is missing. (#22114)
  • Browser tabs are titled after the open page or item. (#22228)

🔧 Tooling

  • New worktrees are created under ~/.lobehub/worktrees. (#22203)
  • Failed desktop canary uploads can now be recovered. (#22312)

🔒 Reliability & Upgrade

  • Reliability: a burst of image rehosts no longer deadlocks the database pool, and file storage probes run outside database transactions. (#22290, #22385)
  • Reliability: a chat that fails before its first byte returns a structured error. (#22314)
  • Reliability: the goal manager claim no longer re-queues itself forever, and long-dead concurrent runs stop re-warning. (#22209, #22208)
  • Self-hosting: this release ships migrations 0200–0205, which run automatically on startup. They add channels.config, goals.archived_at, project_sites.last_seen_at, task label tables, reusable workspace invitation links and LobeBench evaluation tables. 0204 also makes workspace_invitations.expires_at nullable and adds a check that non-reusable invitations keep an expiry. Take your usual database backup before upgrading. (#22173, #22171, #22175, #22278, #22245, #22157)

👥 Contributors

Huge thanks to 11 contributors who shipped 127 merged PRs this cycle.

@R0BiN00Z · @fzlzjerry · @rdmclin2 · @tjx666 · @arvinxx · @AmAzing129 · @MarioJames · @Innei · @nekomeowww · @ONLY-yours · @canisminor1990

Plus @lobehub-coder and @lobehubbot for maintenance.
