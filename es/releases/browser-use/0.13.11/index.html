Esta versión incluye conjuntos de herramientas de uso del navegador para Claude, disponibles en browser_use.integrations.toolsets_for_claude. La integración requiere una versión Anthropic SDK que contenga anthropic.tools.browser; el Anthropic SDK público actual aún no lo incluye.

Documentación: https://docs.browser-use.com/open-source/customize/integrations/toolsets-for-claude

browser-use 0.13.11

Highlights

  • Claude browser toolsets (headline, gated) — New browser_use.integrations.toolsets_for_claude plus an Anthropic browser toolset driver (PR 5966) expose Browser Use as native Claude tools, built on corrected Actor input semantics and new CDP primitives (PR 5889). The catch: it requires an Anthropic SDK release containing anthropic.tools.browser, which the current public SDK does not yet ship — so you cannot exercise this against stable packages today. Pin an SDK preview if you want early access, and watch the linked docs for the GA SDK requirement.
  • Security: redaction and MCP gating — Saved agent history now redacts sensitive data nested below list boundaries (PR 5662), closing a leak path if you persist or share transcripts. Separately, the MCP disable-security environment setting is finally honored (PR 5695) — re-verify that env var if you relied on it to gate MCP tooling, since its behavior actually changes in this release.
  • LLM provider correctness fixes — Several behavior changes worth auditing: Gemini requests stop dropping system messages (PR 5664), which can alter agent prompt fidelity; the retired Mistral pixtral-large alias is remapped (PR 5673); DeepSeek/Cerebras API keys are resolved explicitly (PR 5672); Bedrock image URLs with query strings work again (PR 5676); and OpenRouter custom fields now pass through SDK extra_body (PR 5703). Anthropic data URL schemes and media types are also matched case-insensitively (PR 5636).
  • filesystem binary image creation — write_file can now emit tiny binary images (png/gif/jpg/webp) (PR 5280), enabling upload flows directly from the filesystem tool instead of text-only assets — useful for agents that need to attach real image files.
  • DOM, CLI, and telemetry — Hidden code styles are matched case-insensitively (PR 5640), Windows users can invoke the CLI as a module (PR 5552), and cloud events report the canonical LLM model property (PR 5279) — relevant if you key dashboards or billing telemetry off model names.
  • Release pipeline hardening — PyPI publication now runs through a protected workflow requiring separate reviewer approval, with the publish toolchain pinned (PR 5669). Maintainers and forkers should expect a manual approval gate; the pin improves build reproducibility.

No breaking changes are called out in this release.

This release includes Browser Use toolsets for Claude, available at browser_use.integrations.toolsets_for_claude. The integration requires an Anthropic SDK release containing anthropic.tools.browser; the current public Anthropic SDK does not yet include it.

Documentation: https://docs.browser-use.com/open-source/customize/integrations/toolsets-for-claude

PyPI publication runs through the protected release workflow and requires a separate reviewer approval.
