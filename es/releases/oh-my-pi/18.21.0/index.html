oh-my-pi v18.21.0

#oh-mi-pi v18.21.0

@oh-mi-pi/pi-ai

Agregado

  • Se agregó detección automática de capacidades de pensamiento para modelos previamente desconocidos, con resultados persistentes y soporte para formatos de solicitud de esfuerzo alternativo y presupuesto simbólico.

@oh-my-pi/pi-catalogo

Agregado

  • Se agregó Modal como proveedor de inferencia alojado.

Cambiado

  • Se cambió el modelo de voz local de Kokoro a Phonon 31M.
  • Se mejoró la detección de la capacidad de razonamiento al preservar el soporte a nivel de pensamiento no verificado y utilizar resultados de sondeo específicos de endpoints cuando estén disponibles.

Fijo

  • Se corrigió que el modelo xAI Grok OAuth grok-composer-2.5-fast se identificara incorrectamente como sin razonamiento; ahora admite niveles de pensamiento desde mínimo hasta xalto.

@oh-my-pi/pi-coding-agent

Cambios importantes

  • Se actualizó el ciclo de vida de ejecución de AgentSession API: agent_end se emite una vez cuando una ejecución ya no se puede reanudar y agent_pause informa que las ejecuciones se detienen mientras esperan trabajo. Se reemplazaron hasPendingAsyncWork(), settleAsyncWork() y suppressAutoResumeUntilPrompt() por isRunActive, wakeSources y waitForRunEnd(). Llamar a abort() ahora también finaliza las ejecuciones pausadas en el trabajo en segundo plano; Los flujos de impresión, colaboración y extensión RPC, JSON conservan su comportamiento agent_end por bucle existente.

Agregado

  • Se agregó un recorrido previo del subagente automático configurable a través de task.agentPrewalkAuto, lo que permite configuraciones o patrones de modelo de on/off por agente y al mismo tiempo conserva el recorrido previo del subagente incondicional.
  • Los modelos descubiertos y personalizados desconocidos ahora detectan automáticamente el apoyo al razonamiento y recuerdan los niveles de esfuerzo de razonamiento admitidos para sesiones futuras.
  • Se agregaron respuestas de imágenes y páginas web en línea: los terminales compatibles pueden mostrar imágenes locales, de datos y HTTP(S) y páginas incrustadas, mientras que otros terminales reciben respaldos vinculados. Se agregó tui.renderEmbeds para deshabilitar esta representación.
  • Se agregaron páginas integradas interactivas en las respuestas de Tern, incluida la navegación click-to-visit y Escape-to-return; Se aceptan formularios comunes de host, ruta y URL file:.
  • Las redirecciones de Bash ahora pueden escribir en todas las URL internas grabables, incluidos los puntos finales de cancelación de trabajos y las URL agent://, cfg://, ssh:// y xd:// respaldadas por el controlador.
  • Se agregó pegado de imágenes a las notas del formulario ask y opciones de ui.formDialog a través de acceptImages; Las imágenes pegadas se devuelven con marcadores [Image #N] y se describen para modelos de solo texto. Las indicaciones no admitidas ahora rechazan claramente el pegado de imágenes.

Cambiado

  • Se cambió el modelo local predeterminado de texto a voz a Phonon 31M para una síntesis más rápida, descargas más pequeñas y voces adicionales. Las configuraciones de voz existentes de Kokoro migran automáticamente; Las velocidades de conversación ahora oscilan entre 0.8× y 1.3×.
  • Las respuestas de Tern /btw ahora aparecen como notas interactivas plegadas en el punto donde fueron solicitadas, con acciones de seguimiento, copiar, bifurcar, inyectar y detener; /btw sin mensaje todavía abre la vista del historial.
  • Las llamadas Bash superpuestas ahora comparten el estado del shell, incluidas variables, funciones, alias, opciones y trampas, y los trabajos en segundo plano iniciados por esas llamadas continúan ejecutándose de forma independiente.
  • Las extensiones habilitadas o reconfiguradas a través de extensions o disabledExtensions ahora se cargan en la sesión activa sin necesidad de reiniciar.
  • Los pegados de texto enriquecido realizados durante la dirección de aprobación o en los cuadros de diálogo ahora conservan el formato y las imágenes de Markdown cuando se insertan en el editor de chat.
  • Mover una tarea o reanudar una sesión en otro proyecto ahora cambia sus agentes, extensiones, herramientas personalizadas y servidores MCP para que coincidan con el proyecto de destino sin reiniciar.

Fijado

  • Se corrigieron los indicadores de estado que mostraban incorrectamente al agente como inactivo mientras los subagentes o el trabajo en segundo plano aún podían reanudar la ejecución.
  • Se corrigieron los análisis de seguridad y subagentes que se completaban mientras los agentes secundarios todavía estaban ejecutándose o permanecían mensajes de pares en cola.
  • Se corrigió la resolución de la región de conflicto cuando un lado seleccionado está vacío o comparte líneas de borde con el código circundante.
  • Las fallas del servidor MCP stdio antes de una respuesta ahora informan el código de salida del proceso o la señal de terminación en lugar de solo informar la salida estándar cerrada.
  • Se corrigieron las transferencias previas a la caminata para que se conserven los cambios en el modelo y el esfuerzo de razonamiento, y las transferencias automáticas regresan al modelo de planificación cuando la caminata previa automática se cambia o se desactiva.

@oh-mi-pi/pi-mnemopi

Cambiado

  • Se mejoró el rendimiento del banco de memoria de archivos al reducir la sincronización innecesaria del disco durante los puntos de control, lo que reduce la sobrecarga de E/S por turno para los bancos compartidos en múltiples procesos.

@oh-my-pi/pi-nativos

Agregado

  • Se agregó el enlace PhononTts para la conversión de texto a voz Phonon en el dispositivo.
  • Se agregó Shell.adopt(fork) para aplicar variables, funciones, alias, opciones y trampas desde una bifurcación completa a su shell principal. Cuando ambos shells establecen un nombre, se conserva el valor del comando que finalizó en último lugar.

Fijo

  • Se corrigieron llamadas simultáneas de commitCreate() que sobrescribían incorrectamente el asunto y el cuerpo de la confirmación de cada uno.

@oh-mi-pi/pi-tui

Agregado

  • Se agregó soporte para pegar imágenes en notas de opciones de HtmlFormDialog cuando se abren con acceptImages, incluido adjuntar imágenes, eliminarlas y acceder a imágenes retenidas a través de OptionNote.images.
  • Se agregó representación de imágenes y páginas web en vivo en las respuestas del asistente para terminales compatibles, incluidas imágenes en línea y vistas previas de páginas integradas. Se agregó la nota de transcripción /btw para compartir temas secundarios sin interrumpir la conversación principal.

Cambiado

  • Descubrimiento de capacidad de razonamiento mejorado para que los modelos en espera de descubrimiento sigan el pensamiento predeterminado de la sesión y ofrezcan pensamiento automático además de configuraciones deshabilitadas y de nivel de esfuerzo.
  • Se cambió el nombre de los html-form/media API públicos a media, incluidos loadMedia, Media y MAX_MEDIA_BYTES.

Fijo

  • Se corrigió la selección de modelos alternativos para que a los roles solo se les ofrezcan modelos que puedan usar, excluyendo modelos de imagen y voz incompatibles.
  • Se corrigió la asistencia ortográfica, la autocorrección, los reemplazos y la finalización de palabras de macOS para los borradores de shell (!) y Python ($).

@oh-mi-pi/pi-utils

Fijo

  • Se corrigieron las URL desnudas que tragaban la siguiente palabra cuando el texto coreano, japonés o chino seguía a una URL entre paréntesis sin un espacio.

oh-my-pi v18.21.0

@oh-my-pi/pi-ai

Added

  • Added automatic detection of thinking capabilities for previously unknown models, with persistent results and support for alternate effort and token-budget request formats.

@oh-my-pi/pi-catalog

Added

  • Added Modal as a hosted inference provider.

Changed

  • Changed the local speech model from Kokoro to Phonon 31M.
  • Improved reasoning capability detection by preserving unverified thinking-level support and using endpoint-specific probe results when available.

Fixed

  • Fixed xAI Grok OAuth model grok-composer-2.5-fast being incorrectly identified as non-reasoning; it now supports thinking levels from minimal through xhigh.

@oh-my-pi/pi-coding-agent

Breaking Changes

  • Updated the AgentSession run lifecycle API: agent_end is emitted once when a run can no longer resume, and agent_pause reports runs that stop while awaiting work. Replaced hasPendingAsyncWork(), settleAsyncWork(), and suppressAutoResumeUntilPrompt() with isRunActive, wakeSources, and waitForRunEnd(). Calling abort() now also ends runs paused on background work; RPC, JSON print, collaboration, and extension streams retain their existing per-loop agent_end behavior.

Added

  • Added configurable automatic subagent prewalk through task.agentPrewalkAuto, allowing per-agent on/off settings or model patterns while preserving unconditional subagent prewalk.
  • Unknown custom and discovered models now automatically detect reasoning support and remember supported reasoning effort levels for future sessions.
  • Added inline image and web-page replies: supported terminals can display local, data, and HTTP(S) images and embedded pages, while other terminals receive linked fallbacks. Added tui.renderEmbeds to disable this rendering.
  • Added interactive embedded pages in Tern replies, including click-to-visit and Escape-to-return navigation; common host, path, and file: URL forms are accepted.
  • Bash redirects can now write to all writable internal URLs, including job cancellation endpoints and handler-backed agent://, cfg://, ssh://, and xd:// URLs.
  • Added image pasting to ask form notes and ui.formDialog options via acceptImages; pasted images are returned with [Image #N] markers and described for text-only models. Unsupported prompts now clearly reject image pastes.

Changed

  • Changed the default local text-to-speech model to Phonon 31M for faster synthesis, smaller downloads, and additional voices. Existing Kokoro voice settings migrate automatically; speaking rates now range from 0.8× to 1.3×.
  • Tern /btw responses now appear as folded, interactive notes at the point where they were requested, with follow-up, copy, branch, inject, and stop actions; /btw without a prompt still opens the history view.
  • Overlapping Bash calls now share shell state, including variables, functions, aliases, options, and traps, and background jobs started by those calls continue running independently.
  • Extensions enabled or reconfigured through extensions or disabledExtensions now load into the active session without requiring a restart.
  • Rich-text pastes made during approval steering or in dialogs now preserve Markdown formatting and images when inserted into the chat editor.
  • Moving a task or resuming a session in another project now switches its agents, extensions, custom tools, and MCP servers to match the destination project without a restart.

Fixed

  • Fixed status indicators incorrectly showing the agent as idle while subagents or background work could still resume the run.
  • Fixed subagents and security scans completing while child agents were still running or queued peer messages remained.
  • Fixed conflict-region resolution when a selected side is empty or shares edge lines with surrounding code.
  • MCP stdio server failures before a response now report the process exit code or terminating signal instead of only reporting closed stdout.
  • Fixed prewalk handoffs so model and reasoning-effort changes are preserved, and automatic handoffs return to the planning model when automatic prewalk is changed or disabled.

@oh-my-pi/pi-mnemopi

Changed

  • Improved file memory bank performance by reducing unnecessary disk synchronization during checkpointing, lowering per-turn I/O overhead for banks shared across multiple processes.

@oh-my-pi/pi-natives

Added

  • Added the PhononTts binding for on-device Phonon text-to-speech.
  • Added Shell.adopt(fork) to apply variables, functions, aliases, options, and traps from a completed fork back to its parent shell. When both shells set a name, the value from the command that finished last is retained.

Fixed

  • Fixed concurrent commitCreate() calls incorrectly overwriting each other’s commit subject and body.

@oh-my-pi/pi-tui

Added

  • Added support for pasting images into HtmlFormDialog option notes when opened with acceptImages, including image attachment, removal, and access to retained images through OptionNote.images.
  • Added live web-page and image rendering in assistant replies for supported terminals, including inline images and embedded page previews. Added the /btw transcript note for sharing side topics without interrupting the main conversation.

Changed

  • Improved reasoning-capability discovery so models awaiting discovery follow the session's thinking default and offer automatic thinking in addition to disabled and effort-level settings.
  • Renamed the public html-form/media APIs to media, including loadMedia, Media, and MAX_MEDIA_BYTES.

Fixed

  • Fixed fallback model selection so roles are offered only models they can use, excluding incompatible image and speech models.
  • Fixed macOS spelling assistance, autocorrect, replacements, and word completion for shell (!) and Python ($) drafts.

@oh-my-pi/pi-utils

Fixed

  • Fixed bare URLs swallowing the following word when Korean, Japanese, or Chinese text follows a parenthesized URL without a space.
