oh-my-pi v18.18.3

#oh-mi-pi v18.18.3

@oh-my-pi/pi-catalogo

Cambiado

  • Se agregó un sesgo de delegación balanced entre eager y restrained; Los modelos sin una regla delegation-bias ahora se resuelven en ella en lugar de eager.

@oh-my-pi/pi-coding-agent

Cambios importantes

  • La herramienta ask toma un formulario HTML ({ html }) en lugar de questions[]: el modelo escribe un <form> de radios, casillas de verificación, selecciones, entradas de texto y áreas de texto con su recomendación preseleccionada, y recibe los datos del formulario enviado como JSON. AskToolDetails ahora es { answers: { name, question, answer }[]; timedOut? }; QuestionResult, las rutas "Otro", "Chat sobre esto", nota de respuesta e imagen de respuesta de la herramienta se eliminan, y /tree vuelve a responder y vuelve a abrir el formulario original (NavigateTreeResult.reopenAsk lleva html).

Agregado

  • En Tern, a la derecha cli, al seleccionar una respuesta ask se ofrece una nota, que anota esa respuesta sin seleccionarla (#18551 por @H4vC)
  • task.eager (preferred/always) ahora da forma sólo al mensaje del sistema del agente principal; Los subagentes recurren a la propia política de delegación de su modelo en lugar de verse obligados a generar más subagentes.
  • Los formularios ask pueden mostrar imágenes: <img src> de una URL http(s), un URI data: o un archivo local (relativo al directorio de trabajo de la sesión) y diagramas <svg> en línea, dibujados en el formulario de terminal y de forma nativa en Tern.
  • Los formularios ask brindan a cada radio y grupo de casillas de verificación una respuesta de texto libre "Otro": su texto es el valor de la radio o se agrega a la matriz del grupo de casillas de verificación (reserva campo por campo, invitados de colaboración y obtención de ACP incluidos)
  • La interfaz de usuario de la extensión obtiene ui.formDialog(html, options) opcional, que representa un HTML <form> y se resuelve en { data, timedOut? } (indefinido cuando se cancela). La TUI interactiva lo presenta como un diálogo de formulario, los ACP clients con obtención de formulario obtienen una obtención con una propiedad por campo, y los hosts sin ella (RPC) responden a la herramienta ask campo por campo a través de select/input/editor.
  • Las celdas de evaluación pueden ejecutar comandos de shell con sh: sh("git status") en Python, await sh`ls ${dir}` or await sh("make", { cwd }) in JavaScript. Commands run on the embedded bash engine to completion (never auto-backgrounded), return their output, and raise ShellError con el código de salida en caso de falla.
  • omp zsh en Windows ejecuta las utilidades integradas de omp (ls, cat, head, jq,...) para comandos que PATH no tiene, a menos que un command_not_found_handler los maneje (#18532 por @H4vC).

Cambiado

  • Herramienta aclarada y descripciones de URL internas para transcripciones concisas de history://, retención de trabajos y búsquedas de agentes estacionados de proc://, y salida de texto de consulta de read JSON (#18553 por @xiangnan0811)
  • Los modelos sin una regla de delegación (Claude, Gemini,…) ya no son obligados a delegar: la regla "mapear código desconocido mediante tarea" y los empujones "Tarea + exploración" en las descripciones de las herramientas de búsqueda se reemplazan por una ligera sugerencia para explorar subsistemas desconocidos con un explorador
  • En Tern, clicking una respuesta ask y luego Nota ahora anota la respuesta resaltada en la pregunta mostrada en lugar de la que simplemente clicked (#18551 por @H4vC)

Fijo

  • Se corrigieron las notas de ask agregadas con n justo después de elegir una respuesta que aterrizara en la pregunta anterior en lugar de la que se muestra; a Tern click luego Note todavía anota la respuesta solo clicked, y el botón Nota le da nombre (#18317 por @DonMikone)
  • Se corrigió el error de /export en Windows al guardar en el directorio actual, incluidas rutas relativas como sub/../session.html; el mensaje de exportación ahora muestra la ruta completa del archivo escrito (#18369, #18525 por @minhngoc25a).
  • La inicialización de Todo ahora nombra fases vacías Tasks, por lo que las actualizaciones posteriores pueden abordarlas (#18552 por @xiangnan0811)
  • omp zsh y la herramienta bash en Windows: los comandos en segundo plano sin control de trabajo ignoran Ctrl-C (INT y QUIT en zsh) como lo hacen zsh y bash, por lo que Ctrl-C de la consola los deja ejecutándose (#18532 por @H4vC).
  • omp zsh encuentra la biblioteca de funciones del sistema zsh (se carga compinit) en Debian, Ubuntu y Arch, y en Windows desde un MSYS2, Cygwin o Git para Windows zsh (#18532 por @H4vC).
  • omp zsh en Windows: los comandos escritos ya no terminan en ^M, los programas se encuentran a través de Path, los scripts canalizados se ejecutan en cada línea, cd toma C:\…/C:/…, .. y ~ (manteniendo $PWD como C:/…), >/dev/null funciona, el mensaje es % en lugar de root #, $OSTYPE es msys y no se imprime ninguna advertencia de USERNAME (#18532 por @H4vC).
  • omp zsh en Windows edita líneas con ZLE (historial, finalización de tabulación, combinaciones de teclas, $COLUMNS); Ctrl-C abandona la línea, ejecuta una captura INT o interrumpe un read que luego continúa, en lugar de finalizar el shell (#18532 por @H4vC).
  • omp zsh en Windows: Ctrl-C interrumpe el programa en primer plano, jobs, fg y bg funcionan (un trabajo recuperado con fg también obtiene Ctrl-C) y la sustitución de procesos llega a los programas de Windows (diff <(…) <(…), prog >(…)) (#18532 por @H4vC).
  • En Windows, /dev/null funciona en la herramienta bash (>/dev/null, cat /dev/null, [ -c /dev/null ]) (#18532 por @H4vC).
  • En Windows, /dev/tty abre la consola en omp zsh y la herramienta bash (prog >/dev/tty), y un programa MSYS o Cygwin eliminado por Ctrl-C informa el estado 130 en lugar de 512 (#18532 por @H4vC).
  • omp zsh imprime la línea [n] pid para una canalización en segundo plano bajo control de trabajo, como lo hace para un solo comando (#18532 por @H4vC).
  • omp zsh inicia compinit muchas veces más rápido: los elementos de asociación y matriz única se asignan y leen sin copiar todo el parámetro, y autoload -r ya no vuelve a leer los resúmenes de .zwc en $fpath para cada función que resuelve (#18533 por @H4vC).
  • read -k y read -q de omp zsh leen una clave del terminal sin esperar Enter, como lo hace zsh, en lugar de leer la entrada estándar (#18533 por @H4vC).
  • Los listados de finalización de omp zsh marcan los tipos de archivos nuevamente (dir/, exe*), print -c dispone las palabras en columnas sin terminal y ${x?msg} finaliza un shell no interactivo con estado 1 como lo hace zsh (#18533 por @H4vC).
  • Los flotadores omp zsh mantienen total precisión en aritmética (s=$EPOCHREALTIME; print $(( EPOCHREALTIME - s )) ya no se desvía hasta un segundo) y aún imprimen en su estilo -F/-E (#18533 por @H4vC).
  • typeset -U path / typeset -U fpath (y local -U path) de omp zsh eliminan entradas repetidas como lo hace zsh (#18533 por @H4vC).
  • omp zsh y la herramienta bash: $! de una canalización en segundo plano es el pid de su último programa, como en bash y zsh, por lo que kill $! señala ese programa; La línea [n] de omp zsh para una canalización en segundo plano enumera el pid de cada uno de sus procesos, como lo hace zsh (#18547 por @H4vC).
  • omp zsh es más rápido: las llamadas a funciones, los bucles y la aritmética se ejecutan entre 2 y 3 veces más rápido, compinit casi 4 veces más rápido y la creación de una gran matriz o asociación de un elemento a la vez (a+=(x), h[k]=v) o la lectura de $a[i] de una gran matriz ya no se ralentiza con su tamaño (#18565 por @H4vC).

@oh-my-pi/collab-web

Cambiado

  • Las tarjetas de herramientas ask muestran las leyendas del conjunto de campos del formulario HTML y el recuento de campos mientras están pendientes, y cada pregunta con su respuesta enviada (o "(sin respuesta)") una vez respondida, marcando los envíos realizados antes del tiempo de espera.

@oh-mi-pi/pi-tui

Cambios importantes

  • El renderizador de la herramienta ask ahora dibuja llamadas de formulario { html } y resultados de AskToolDetails { answers, timedOut }; Se eliminaron QuestionResult y los campos de detalles de la lista de preguntas.

Agregado

  • Se agregó una entrada de Nota al menú derecho-click de cada fila de respuesta del cuadro de diálogo de pregunta en Tern, anotando esa respuesta sin seleccionarla (#18551 por @H4vC)
  • Se agregó HtmlFormDialog, que representa un formulario HTML como un formulario de terminal interactivo, divide formularios largos en páginas y devuelve las respuestas como JSON. Los <select> individuales son menús desplegables de una fila, los grupos de radio y casillas de verificación obtienen una respuesta de texto libre "Otro", <img> (URL, data: URI o archivo local) y las imágenes <svg> en línea se cargan en segundo plano, un tiempo de espera de inactividad opcional envía los valores actuales y los terminales Tern obtienen el formulario de forma nativa.
  • Se agregó una opción cursor: "start" a Editor.setText para que el texto de varias líneas precargado se abra en la primera línea.

Cambiado

  • La nota del cuadro de diálogo de pregunta justo después de un puntero click ahora anota la respuesta resaltada de la pregunta mostrada en lugar de la respuesta solo clicked, y el botón Nota ya no nombra un destino de redireccionamiento (#18551 por @H4vC)

Fijo

  • Se corrigió el n del cuadro de diálogo de pregunta justo después de una selección de teclado que anotaba la respuesta de la pregunta anterior en lugar de la fila resaltada que se muestra; solo un puntero click aún redirige la Nota a la respuesta que acaba de elegir, y el botón Nota luego le asigna un nombre (#18317 por @DonMikone)

oh-my-pi v18.18.3

@oh-my-pi/pi-catalog

Changed

  • Added a balanced delegation bias between eager and restrained; models without a delegation-bias rule now resolve to it instead of eager

@oh-my-pi/pi-coding-agent

Breaking Changes

  • The ask tool takes one HTML form ({ html }) instead of questions[]: the model writes a <form> of radios, checkboxes, selects, text inputs and textareas with its recommendation preselected, and receives the submitted form data as JSON. AskToolDetails is now { answers: { name, question, answer }[]; timedOut? }; QuestionResult, the "Other", "Chat about this", answer-note and answer-image paths of the tool are removed, and /tree re-answer reopens the original form (NavigateTreeResult.reopenAsk carries html).

Added

  • In Tern, right-clicking an ask answer offers Note, which annotates that answer without picking it (#18551 by @H4vC)
  • task.eager (preferred/always) now shapes only the main agent's system prompt; subagents fall back to their model's own delegation policy instead of being pushed to spawn further subagents
  • ask forms can show pictures: <img src> from an http(s) URL, a data: URI or a local file (relative to the session's working directory), and inline <svg> diagrams, drawn in the terminal form and natively in Tern
  • ask forms give every radio and checkbox group a free-text "Other" answer: its text is the radio's value or is appended to the checkbox group's array (field-by-field fallback, collab guests and ACP elicitation included)
  • Extension UI gains optional ui.formDialog(html, options), which renders an HTML <form> and resolves to { data, timedOut? } (undefined when cancelled). The interactive TUI renders it as a form dialog, ACP clients with form elicitation get one elicitation with a property per field, and hosts without it (RPC) answer the ask tool field by field through select/input/editor.
  • Eval cells can run shell commands with sh: sh("git status") in Python, await sh`ls ${dir}` or await sh("make", { cwd }) in JavaScript. Commands run on the embedded bash engine to completion (never auto-backgrounded), return their output, and raise ShellError with the exit code on failure.
  • omp zsh on Windows runs omp's builtin utilities (ls, cat, head, jq, …) for commands PATH does not have, unless a command_not_found_handler handles them (#18532 by @H4vC).

Changed

  • Clarified tool and internal-URL descriptions for history:// concise transcripts, proc:// job retention and parked-agent lookups, and read JSON query text output (#18553 by @xiangnan0811)
  • Models without a delegation rule (Claude, Gemini, …) no longer get pushed to delegate: the "map unknown code via task" rule and the "Task + scout" nudges in search tool descriptions are replaced by a light suggestion to explore unfamiliar subsystems with a scout
  • In Tern, clicking an ask answer and then Note now annotates the answer highlighted on the question shown instead of the one just clicked (#18551 by @H4vC)

Fixed

  • Fixed ask notes added with n right after picking an answer landing on the previous question instead of the one shown; a Tern click then Note still notes the answer just clicked, and the Note button names it (#18317 by @DonMikone)
  • Fixed /export failing on Windows when saving in the current directory, including relative paths such as sub/../session.html; the export message now shows the full path of the written file (#18369, #18525 by @minhngoc25a).
  • Todo initialization now names empty phases Tasks, so subsequent updates can address them (#18552 by @xiangnan0811)
  • omp zsh and the bash tool on Windows: background commands without job control ignore Ctrl-C (INT, and QUIT in zsh) as zsh and bash do, so the console's Ctrl-C leaves them running (#18532 by @H4vC).
  • omp zsh finds the system zsh's function library (compinit loads) on Debian, Ubuntu and Arch, and on Windows from an MSYS2, Cygwin or Git for Windows zsh (#18532 by @H4vC).
  • omp zsh on Windows: typed commands no longer end in ^M, programs are found through Path, piped scripts run every line, cd takes C:\…/C:/…, .. and ~ (keeping $PWD as C:/…), >/dev/null works, the prompt is % rather than root's #, $OSTYPE is msys, and no USERNAME warning is printed (#18532 by @H4vC).
  • omp zsh on Windows edits lines with ZLE (history, Tab completion, key bindings, $COLUMNS); Ctrl-C abandons the line, runs an INT trap, or interrupts a read that then goes on, instead of ending the shell (#18532 by @H4vC).
  • omp zsh on Windows: Ctrl-C interrupts the foreground program, jobs, fg and bg work (a job brought back with fg gets Ctrl-C too), and process substitution reaches Windows programs (diff <(…) <(…), prog >(…)) (#18532 by @H4vC).
  • On Windows, /dev/null works in the bash tool (>/dev/null, cat /dev/null, [ -c /dev/null ]) (#18532 by @H4vC).
  • On Windows, /dev/tty opens the console in omp zsh and the bash tool (prog >/dev/tty), and an MSYS or Cygwin program killed by Ctrl-C reports status 130 instead of 512 (#18532 by @H4vC).
  • omp zsh prints the [n] pid line for a background pipeline under job control, as it does for a single command (#18532 by @H4vC).
  • omp zsh starts compinit many times faster: single array and association elements are assigned and read without copying the whole parameter, and autoload -r no longer re-reads the .zwc digests in $fpath for every function it resolves (#18533 by @H4vC).
  • omp zsh's read -k and read -q read a key from the terminal without waiting for Enter, as zsh does, instead of reading standard input (#18533 by @H4vC).
  • omp zsh completion listings mark file types again (dir/, exe*), print -c lays words out in columns without a terminal, and ${x?msg} ends a non-interactive shell with status 1 as zsh does (#18533 by @H4vC).
  • omp zsh floats keep full precision in arithmetic (s=$EPOCHREALTIME; print $(( EPOCHREALTIME - s )) no longer drifts by up to a second) and still print in their -F/-E style (#18533 by @H4vC).
  • omp zsh's typeset -U path / typeset -U fpath (and local -U path) drop repeated entries as zsh does (#18533 by @H4vC).
  • omp zsh and the bash tool: $! of a background pipeline is its last program's pid, as in bash and zsh, so kill $! signals that program; omp zsh's [n] line for a background pipeline lists the pid of each of its processes, as zsh does (#18547 by @H4vC).
  • omp zsh is faster: function calls, loops and arithmetic run 2–3× faster, compinit almost 4× faster, and building a large array or association one element at a time (a+=(x), h[k]=v) or reading $a[i] from a large array no longer slows down with its size (#18565 by @H4vC).

@oh-my-pi/collab-web

Changed

  • ask tool cards show the HTML form's fieldset legends and field count while pending, and each question with its submitted answer (or "(no answer)") once answered, flagging submissions made by the timeout

@oh-my-pi/pi-tui

Breaking Changes

  • The ask tool renderer now draws { html } form calls and AskToolDetails { answers, timedOut } results; QuestionResult and the question-list detail fields were removed.

Added

  • Added a Note entry to the right-click menu of each ask dialog answer row in Tern, annotating that answer without picking it (#18551 by @H4vC)
  • Added HtmlFormDialog, which renders an HTML form as an interactive terminal form, splits long forms into pages, and returns the answers as JSON. Single <select>s are one-row dropdowns, radio and checkbox groups get a free-text "Other" answer, <img> (URL, data: URI or local file) and inline <svg> pictures load in the background, an optional inactivity timeout submits the current values, and Tern terminals get the form natively.
  • Added a cursor: "start" option to Editor.setText so prefilled multi-line text opens at its first line.

Changed

  • The ask dialog's Note right after a pointer click now annotates the highlighted answer of the question shown instead of the answer just clicked, and the Note button no longer names a redirect target (#18551 by @H4vC)

Fixed

  • Fixed the ask dialog's n right after a keyboard pick annotating the previous question's answer instead of the highlighted row shown; only a pointer click still redirects Note to the answer just picked, and the Note button then names it (#18317 by @DonMikone)
