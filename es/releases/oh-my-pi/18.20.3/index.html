#oh-mi-pi v18.20.3

@oh-mi-pi/pi-ai

Cambios importantes

  • Se eliminó la exportación pública isXdDevicePath de providers/cursor-pi-args. Las lecturas a distancia de documentos xd:// ahora utilizan el comportamiento estándar del selector de línea.

Fijo

  • Manejo de límite de tarifa fijo para Mistral y otros proveedores compatibles con OpenAI, de modo que las solicitudes sin asignación disponible fallan inmediatamente con un error procesable que sugiere un cambio de modelo o plan.
  • Se corrigieron las solicitudes antrópicas de OAuth para cuentas de Claude agrupadas para informar información precisa del dispositivo y de la cuenta, incluso después de que las credenciales se rotan durante una solicitud.

@oh-my-pi/pi-catalogo

Agregado

  • Se agregaron ayudas de tamaño de imágenes disponibles públicamente para determinar las dimensiones de las imágenes entregadas por el modelo y ajustar las imágenes a un borde largo específico antes del mapeo de coordenadas.

Fijo

  • Se corrigió la eliminación de las entradas de imágenes para DeepSeek V4 Flash, restaurando el soporte consistente de imágenes multimodales.
  • Opciones de esfuerzo de razonamiento restringidas para Mistral GLM 5.3, GLM 5.3 Flash y Mistral Large 4 a los niveles admitidos por esos modelos.

@oh-my-pi/pi-coding-agent

Cambios importantes

  • Se cambió el nombre de la opción tab.clickAt() del navegador de clickCount a count, coincidiendo con tab.click().
  • Las coordenadas de captura de pantalla de la ventana gráfica del navegador ahora usan las coordenadas de la imagen mostrada cuando la captura de pantalla se escala para el modelo; pase css: true (o { x, y, css: true } para puntos de arrastre) para proporcionar píxeles CSS de ventana gráfica explícitamente.
  • Se agregó la opción mnemopi.recallRelevance (off, auto o on; predeterminado off) para filtrar la recuperación automática de memoria según la relevancia de la tarea utilizando la función judge.
  • Se agregaron entradas con alcance de ruta para bash.patterns y bashInterceptor.patterns, resueltas por directorio de trabajo. Las superposiciones de Project y --config ahora anteponen estas reglas a las reglas globales en lugar de reemplazarlas.
  • Se agregaron listas bash.allowedEnvVars y por regla env para permitir prefijos de variables de entorno nombrados explícitamente en reglas allow coincidentes.
  • Los subagentes ahora conservan la fijación del proveedor @upstream en los modelos heredados.
  • Se agregaron opciones --no-judge, --no-spotlight y --offline para restringir los servicios auxiliares al proveedor del modelo activo o deshabilitar los servicios entre proveedores.
  • Se agregó frontmatter TTSR repeatMode por regla (once, after-gap o always) para anular la política de repetición global.
  • Las indicaciones de aprobación de bash compuestas ahora muestran cada segmento de comando por separado, distinguiendo los segmentos permitidos de los que requieren aprobación.
  • Se eliminaron el agente seance, el comando /seance y el parámetro sourceSession de la herramienta de tareas.

Agregado

  • Se agregó la configuración mnemopi.embeddingQueryPrefix y mnemopi.embeddingInputType para modelos de integración asimétricos y ajustados por instrucciones, incluidos los proveedores que requieren un input_type.

Cambiado

  • Las capturas de pantalla del navegador se entregan al modelo en píxeles CSS hasta el tamaño sin escala admitido, lo que hace que las coordenadas de la captura de pantalla de la ventana gráfica se puedan utilizar directamente con las acciones del navegador; La guía de escala permanece para capturas de elementos y de página completa escaladas.
  • Los navegadores waitForUrl, waitForResponse y requests({ filter }) ahora admiten patrones globales * en cadenas URL, mientras que otras cadenas conservan la coincidencia de subcadenas.
  • El motor del navegador WebKit ahora se instala y actualiza automáticamente a la versión estable más reciente de ABKit, con instalaciones versionadas que permiten actualizaciones sin esperar a que se cierren los hosts del navegador existentes.
  • Capacidad de respuesta y recuperación del navegador mejoradas: las páginas WebKit que no responden fallan rápidamente con errores procesables, la navegación puede recuperar páginas ocupadas y las operaciones del navegador brindan diagnósticos más claros para tiempos de espera, pestañas cerradas, detectores de eventos no compatibles, rutas no válidas, datos de cookies y cambios en la ventana gráfica.
  • Al presionar Eliminar al final del campo de búsqueda Ctrl+R se elimina el mensaje seleccionado del historial.
  • /copy ahora funciona mientras se visualiza un subagente y se copia la transcripción de ese subagente.
  • find ahora devuelve coincidencias de palabras clave literales sin clasificar cuando fallan todas las solicitudes de juez.
  • take() y drop() ahora rechazan unidades de trozos inexistentes con un claro error.
  • Los mensajes de rechazo de edit ahora sugieren la etiqueta actual del archivo y las ediciones realizadas antes de la resolución del conflicto se transfieren al archivo resuelto.
  • Los comandos de instalación/desinstalación de /marketplace y Marketplace ahora informan errores de selección y carga de catálogo sin salir de la sesión.
  • Las sesiones de ACP respetan mcp.startupTimeoutMs para los servidores MCP declarados por client, ​​y las solicitudes de formularios de ACP ya no repiten etiquetas de campo innecesariamente.
  • Ahora se conserva el progreso de la tarea de cada paso del subagente task.steps, en lugar de solo el informe del paso final.
  • Al pegar HTML en el compositor ahora se conservan los espacios de los elementos en línea que solo contienen espacios en blanco y la sangría dentro de los bloques <pre>.
  • Los seguimientos en cola editados con Alt+Arriba se restauran como mensajes en cola en lugar de enviarse al turno activo.

Fijo

  • Se corrigió la salida de ida exec en IDA 9.5+ al suprimir las advertencias de obsolescencia del asistente y preservar los metadatos de la función actualizada API.
  • Los inicios de sesión y las cookies de Perplexity caducados ya no devuelven una página de error como respuesta de búsqueda; el proveedor se informa como caducado y la cadena de búsqueda continúa.
  • Se corrigió el descubrimiento e invocación de WebMCP del navegador en Chrome y Chromium 157 y versiones posteriores.
  • Ask y always-ask-cached ahora manejan correctamente los hosts privados escritos con un punto al final antes de que las herramientas de archivos accedan a ellos.
  • Se corrigió la congelación de TUI al cambiar de sesión desde un mensaje de aprobación de herramienta abierta.
  • Se corrigió que /commit y eval commit eliminaran las listas de materiales UTF-8 o manejaran mal los nombres de archivos entre comillas y Unicode durante el seguimiento de cambios y las confirmaciones selectivas.
  • Se corrigieron advertencias engañosas del tablero Wayland cli al pegar una imagen o cuando el tablero cli está vacío.
  • Se corrigió la evaluación de JavaScript después de una actualización de Linux local al mantener a los trabajadores de la sesión vinculados a la compilación de la sesión.
  • Eliminar una sesión que no se puede eliminar ya no elimina su historial de mensajes ni sus estadísticas.
  • Se corrigió el manejo de selectores de línea en read y write en las URL del dispositivo xd://.
  • Se corrigió que eval wait() rechazara o manejara mal los retrasos numéricos; Las esperas del navegador ahora dirigen a los usuarios a los ayudantes de espera apropiados.
  • Se corrigió el navegador open con un perfil Arch Chromium existente, navegación Tern, bloques Tern externos cerrados y emulación de ventana gráfica Tern acoplada.
  • Se corrigieron las llamadas a los navegadores Tern y WebKit que exponían incorrectamente los detectores de eventos de páginas no compatibles API; Los errores ahora identifican las alternativas admitidas.
  • Se corrigieron errores de tiempo de espera del navegador y página ocupada para incluir la URL actual, la pestaña afectada y una guía de recuperación práctica.
  • Se corrigieron fallas de incrustación de Mnemopi que se degradaban silenciosamente a búsqueda de palabras clave; Los errores del proveedor ahora producen una advertencia, incluso en el modo de impresión en stderr.

@oh-mi-pi/pi-mnemopi

Agregado

  • Se agregaron prefijos de consulta de incrustación configurables y tipos de entrada para modelos de incrustación asimétricos y ajustados por instrucciones, incluidos Qwen3-Embedding, E5 y NVIDIA NIM.
  • Se agregó la devolución de llamada embeddings.onRequestFailed, que permite a los hosts manejar y mostrar solicitudes fallidas de incrustación API.

@oh-my-pi/pi-nativos

Fijo

  • La confirmación o escritura de árboles ahora informa correctamente los conflictos de índice no resueltos en lugar de omitir silenciosamente los archivos en conflicto.
  • Se corrigió la compatibilidad del shell con GNU grep para patrones anclados al final de línea, incluidos los modos -o y -z, y se corrigieron las sustituciones de sed en líneas de caracteres multibyte.
  • Se corrigió el manejo de parches y diferencias nativas para nombres de archivos que contienen espacios y otros caracteres que requieren comillas, incluidos cambios binarios.

@oh-mi-pi/pi-utils

Fijo

  • Se corrigió la conversión de HTML a Markdown para HTML recuperado y pegado para preservar los espacios en blanco en los elementos en línea, mantener la sangría del código en bloques preformateados y evitar insertar líneas en blanco perdidas entre los elementos del bloque.

oh-my-pi v18.20.3

@oh-my-pi/pi-ai

Breaking Changes

  • Removed the public isXdDevicePath export from providers/cursor-pi-args. Ranged reads of xd:// documents now use the standard line-selector behavior.

Fixed

  • Fixed rate-limit handling for Mistral and other OpenAI-compatible providers so requests with no available allowance fail immediately with an actionable error suggesting a model or plan change.
  • Fixed Anthropic OAuth requests for pooled Claude accounts to report accurate device and account information, including after credentials are rotated during a request.

@oh-my-pi/pi-catalog

Added

  • Added publicly available image-sizing helpers for determining model-delivered image dimensions and fitting images to a specified long edge before coordinate mapping.

Fixed

  • Fixed image inputs being dropped for DeepSeek V4 Flash, restoring consistent multimodal image support.
  • Restricted reasoning-effort options for Mistral GLM 5.3, GLM 5.3 Flash, and Mistral Large 4 to the levels supported by those models.

@oh-my-pi/pi-coding-agent

Breaking Changes

  • Renamed the browser tab.clickAt() option from clickCount to count, matching tab.click().
  • Browser viewport screenshot coordinates now use the displayed image coordinates when the screenshot is scaled for the model; pass css: true (or { x, y, css: true } for drag points) to provide viewport CSS pixels explicitly.
  • Added opt-in mnemopi.recallRelevance (off, auto, or on; default off) to filter automatic memory recall for task relevance using the judge role.
  • Added path-scoped entries for bash.patterns and bashInterceptor.patterns, resolved per working directory. Project and --config overlays now prepend these rules to global rules instead of replacing them.
  • Added bash.allowedEnvVars and per-rule env lists to permit explicitly named environment-variable prefixes on matching allow rules.
  • Subagents now preserve @upstream provider pinning on inherited models.
  • Added --no-judge, --no-spotlight, and --offline options to restrict auxiliary services to the active model's provider or disable cross-provider services.
  • Added per-rule TTSR repeatMode frontmatter (once, after-gap, or always) to override the global repeat policy.
  • Compound bash approval prompts now show each command segment separately, distinguishing allowed segments from those requiring approval.
  • Removed the seance agent, /seance command, and the task tool's sourceSession parameter.

Added

  • Added mnemopi.embeddingQueryPrefix and mnemopi.embeddingInputType configuration for asymmetric and instruction-tuned embedding models, including providers that require an input_type.

Changed

  • Browser screenshots are delivered to the model in CSS pixels up to the supported unscaled size, making viewport screenshot coordinates directly usable with browser actions; scaling guidance remains for scaled full-page and element captures.
  • Browser waitForUrl, waitForResponse, and requests({ filter }) now support * glob patterns in URL strings, while other strings retain substring matching.
  • The WebKit browser engine now automatically installs and updates to the newest stable ABKit release, with versioned installations that allow updates without waiting for existing browser hosts to exit.
  • Improved browser responsiveness and recovery: unresponsive WebKit pages fail fast with actionable errors, navigation can recover busy pages, and browser operations provide clearer diagnostics for timeouts, closed tabs, unsupported event listeners, invalid routes, cookie data, and viewport changes.
  • Pressing Delete at the end of the Ctrl+R search field removes the selected prompt from history.
  • /copy now works while viewing a subagent and copies from that subagent's transcript.
  • find now returns unranked literal keyword matches when all judge requests fail.
  • take() and drop() now reject nonexistent hunk units with a clear error.
  • edit rejection messages now suggest the file's current tag, and edits made before conflict resolution carry over to the resolved file.
  • /marketplace and marketplace install/uninstall commands now report picker and catalog-load errors without exiting the session.
  • ACP sessions honor mcp.startupTimeoutMs for MCP servers declared by the client, and ACP form elicitations no longer repeat field labels unnecessarily.
  • Task progress from every task.steps subagent step is now preserved, rather than only the final step's report.
  • Pasting HTML into the composer now preserves spaces from whitespace-only inline elements and indentation inside <pre> blocks.
  • Queued follow-ups edited with Alt+Up are restored as queued messages instead of being sent into the active turn.

Fixed

  • Fixed ida exec output on IDA 9.5+ by suppressing helper deprecation warnings and preserving the updated function metadata API.
  • Expired Perplexity logins and cookies no longer return an error page as a search answer; the provider is reported as expired and the search chain continues.
  • Fixed browser WebMCP discovery and invocation on Chrome and Chromium 157 and later.
  • Private hosts written with a trailing dot are now correctly handled by Ask and always-ask-cached before file tools access them.
  • Fixed the TUI freezing when switching sessions from an open tool-approval prompt.
  • Fixed /commit and eval commit dropping UTF-8 BOMs or mishandling quoted and Unicode filenames during change tracking and selective commits.
  • Fixed misleading Wayland clipboard warnings when pasting an image or when the clipboard is empty.
  • Fixed JavaScript evaluation after an in-place Linux upgrade by keeping session workers tied to the session's build.
  • Deleting a session that cannot be removed no longer deletes its prompt history and statistics.
  • Fixed read and write handling of line selectors on xd:// device URLs.
  • Fixed eval wait() rejecting or mishandling numeric delays; browser waits now direct users to the appropriate wait helpers.
  • Fixed browser open with an existing Arch Chromium profile, Tern navigation, closed external Tern blocks, and docked Tern viewport emulation.
  • Fixed Tern and WebKit browser calls that incorrectly exposed unsupported page event-listener APIs; errors now identify the supported alternatives.
  • Fixed browser timeout and busy-page errors to include the current URL, affected tab, and actionable recovery guidance.
  • Fixed Mnemopi embedding failures being silently downgraded to keyword search; provider errors now produce a warning, including in print mode on stderr.

@oh-my-pi/pi-mnemopi

Added

  • Added configurable embedding query prefixes and input types for instruction-tuned and asymmetric embedding models, including Qwen3-Embedding, E5, and NVIDIA NIM.
  • Added the embeddings.onRequestFailed callback, allowing hosts to handle and surface failed embedding API requests.

@oh-my-pi/pi-natives

Fixed

  • Committing or writing trees now correctly reports unresolved index conflicts instead of silently omitting conflicted files.
  • Fixed shell compatibility with GNU grep for end-of-line-anchored patterns, including -o and -z modes, and corrected sed substitutions on multibyte-character lines.
  • Fixed native diff and patch handling for filenames containing spaces and other characters requiring quoting, including binary changes.

@oh-my-pi/pi-utils

Fixed

  • Fixed HTML-to-Markdown conversion for fetched and pasted HTML to preserve whitespace in inline elements, maintain code indentation in preformatted blocks, and avoid inserting stray blank lines between block elements.
