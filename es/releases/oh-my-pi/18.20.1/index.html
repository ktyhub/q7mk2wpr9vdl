  • Se corrigieron las sesiones de Muse después de cambios de credenciales, rotación de claves o reanudación inactiva para que los turnos posteriores puedan continuar normalmente.

@oh-my-pi/pi-coding-agent

Agregado

  • Se agregó /commit para crear confirmaciones que contengan solo los cambios realizados por el agente o un subagente seleccionado, preservando al mismo tiempo el trabajo de otros agentes y del usuario. El flujo de trabajo también está disponible a través del espacio de nombres eval commit, admite repositorios de destino fuera del directorio de sesión, maneja archivos binarios y no UTF-8, enlaces simbólicos, cambios de modo de archivo y confirmaciones iniciales y, opcionalmente, puede omitir enlaces de confirmación con no_verify; utilice commit.enabled para desactivarlo.
  • Se agregó auth.unpausedProviders (la configuración Proveedores no pausados) para volver a habilitar proveedores pausados ​​como Google Antigravity bajo su propio riesgo y al mismo tiempo conservar su estado de inicio de sesión almacenado.
  • Se agregaron recordatorios de tareas pendientes configurables de larga duración a través de todo.midRunNudges, incluidas opciones para deshabilitar recordatorios, limitarlos a dos o continuar con intervalos crecientes.
  • Al pegar contenido con estilo en el compositor ahora se conserva el formato Markdown y se colocan las imágenes incrustadas en sus posiciones originales, mientras que el código copiado de los editores sigue siendo texto sin formato.
  • Se agregó el evento de extensión y gancho session_clear, emitido cuando /clear restablece el contexto de la sesión actual sin cambiar su ID de sesión.
  • Bash con alcance de ruta agregado permite reglas, precedencia de superposición de configuración y proyecto, y controles de variables de entorno a través de bash.allowedEnvVars y configuraciones por regla env.
  • Los subagentes ahora conservan la fijación del proveedor @upstream al heredar modelos.
  • Se agregó la eliminación de mensajes individuales del historial Ctrl+R con la tecla Eliminar.
  • Se agregaron opciones --no-judge, --no-spotlight y --offline para restringir o deshabilitar servicios auxiliares fuera del proveedor del modelo activo.
  • Se agregaron configuraciones TTSR repeatMode por regla (once, after-gap o always) para controlar la repetición de recordatorios.
  • Las indicaciones de aprobación de Bash ahora muestran segmentos de comando compuestos individualmente e identifican qué segmentos están permitidos o requieren aprobación.
  • Las operaciones Todo done, drop y rm ahora aceptan múltiples tareas en una sola solicitud, incluidas entradas separadas por nueva línea, punto y coma, coma o espacio sin dividir las coincidencias exactas de los nombres de las tareas.
  • Las líneas de estado de todo ahora muestran el recuento de tareas cuando hay varios objetivos involucrados.

Cambió

  • /fork y fork-from-transcript ahora cancelan una respuesta activa y se bifurcan inmediatamente.
  • Se redujo la salida predeterminada de grep al mostrar solo líneas coincidentes y limitar las coincidencias por archivo; configure grep.contextBefore y grep.contextAfter para incluir el contexto circundante.
  • Se cambió el nivel predeterminado de spotlight.thinking de low a med para un análisis de resultados más profundo y una clasificación mejorada, a un costo de solicitud más alto.
  • Cuando Spotlight está habilitado, el contenido de la fuente y del problema comúnmente releído o de la solicitud de extracción se muestra de manera más completa antes de delinearlo, incluida la compatibilidad con tipos de archivos de origen adicionales.

Fijo

  • /loop ahora se detiene después de un error del proveedor, como un límite de velocidad, en lugar de volver a enviar el mismo mensaje y adjuntar sus menciones @file nuevamente (#19272).
  • La reanudación de una sesión cuyo directorio se eliminó ahora continúa en el directorio actual con una advertencia en lugar de fallar.
  • Las menciones de modelos y las completaciones de /switch ahora recuperan los modelos descubiertos después de que el descubrimiento del proveedor falla en el inicio, reintentando el descubrimiento cuando es necesario.
  • Los resultados del trabajo en segundo plano que llegan después de que finaliza un mensaje de ACP ahora se trasladan al siguiente mensaje en lugar de iniciar un giro invisible.
  • Las fallas de compactación del servidor OpenAI ahora pasan al siguiente método de compactación disponible en lugar de volver a intentar la compactación del servidor en otro modelo.
  • Los servidores de idiomas ahora reconocen las ediciones realizadas poco después de la creación de un archivo, incluso en macOS.
  • Los comandos Bash mostrados en la vista Pseudo shell ahora siguen siendo precisos mientras se transmiten a través de heredocs, sustituciones, bucles, continuaciones, expresiones aritméticas y ejecución en segundo plano.
  • Reanudar una sesión o revivir a un subagente después de un reintento de reserva con un sufijo de pensamiento (por ejemplo, :xhigh) ahora restaura el nivel de pensamiento del modelo principal en lugar de mantener el de reserva (#19273).

@oh-my-pi/collab-web

Fijo

  • Se agregaron las opciones noVerify a commitCreate() para omitir los enlaces pre-commit y commit-msg, coincidiendo con git commit --no-verify.
  • Se agregó simultaneidad optimista y compatibilidad con índices alternativos a commitCreate(), lo que permite que las confirmaciones utilicen un índice separado y rechacen confirmaciones obsoletas cuando HEAD haya cambiado.

  • Se corrigió el shell cp incorporado para que las opciones de seguimiento de enlaces simbólicos funcionen correctamente con los modos de archivo y copia de directorio sin deshabilitar la recursividad o la preservación de atributos.
  • Se reemplazaron los fallos del shell integrado en cadenas -a/-o muy largas en [] y expresiones de prueba con un error claro para expresiones excesivamente profundas.

oh-my-pi v18.20.1

@oh-my-pi/pi-agent-core

Fixed

  • Corrected context cost estimates for requests that omit reasoning history, so billing estimates now include thinking text only when it is sent or reconstructed for a tool call.

@oh-my-pi/pi-ai

Added

  • Added setUnpausedProviders() to @oh-my-pi/pi-ai/oauth, allowing applications to re-enable providers paused by authentication rules; loaded credential pools and extension logins recognize the change on their next read.

Changed

  • Updated Vertex AI Gemini requests to use the v1beta1 API, restoring support for long Gemini responses.
  • Improved Google Antigravity quota recovery so Gemini 4 Argon access can resume after quota or plan changes when shared Gemini capacity is available.
  • Improved Amazon Bedrock region selection to honor a configured regional endpoint before falling back to us-east-1.

Fixed

  • Fixed Gemini 4 responses that exceed a single output segment across Google, Vertex AI, Gemini CLI, and Antigravity, ensuring long responses continue generating and are delivered as one complete reply.
  • Fixed Cursor conversations so hook-added prompt content remains in the current user message and conversation context is correctly preserved across turns.
  • Fixed Amazon Bedrock streaming so malformed responses fail promptly and interrupted responses are retried rather than treated as complete.
  • Fixed Claude account recovery when usage reports contain only one shared usage window.
  • Fixed OpenRouter conversations with Kimi and DeepSeek so reasoning context is preserved when switching models.
  • Fixed Xiaomi MiMo Token Plan authentication to use the correct regional endpoint, including for models loaded from bundled or cached configuration.
  • Fixed Perplexity sign-in in the login flow and setup wizard, including email-code and browser-based SSO authentication.
  • Stopped native judges from retrying gateway errors caused by exhausted upstream credentials while retaining retries for other transient 502 errors.
  • Fixed simple completion and authenticated gateway chat routes so supported providers receive stop-sequence and frequency-penalty settings.
  • Fixed Muse sessions after credential changes, key rotation, or idle resume so subsequent turns can continue normally.

@oh-my-pi/pi-catalog

Added

  • Added Gemini 4 Hydrogen on Google Antigravity as a single model with selectable low, medium, high, and xhigh thinking levels, priced at $1.50/$7.50 per million tokens.
  • Added Chutes provider support with live model discovery and /login chutes authentication using CHUTES_API_KEY.

Changed

  • Paused Google Antigravity: login is no longer available and stored credentials are not used until the provider is re-enabled. Use GEMINI_API_KEY with Google AI Studio or the google-vertex provider instead (#18341).
  • Updated Command Code model pricing and usage reporting to match the provider's current rates, including long-context pricing tiers for Claude Haiku 5.5, GPT-6.1 Sol and Terra, Grok 4.7, and Claude Sonnet 5.5.
  • Increased the maximum output for Gemini 4 Argon, Carbon, and Hydrogen on the Gemini API and Vertex AI to 262,144 tokens, enabling substantially longer responses.
  • Updated OpenCode Go Claude Haiku 5.5 to support thinking levels from low through max, including explicit thinking disablement.
  • Updated Devin requests to identify as Devin CLI 3000.12.57, the current stable version.

Fixed

  • Fixed Gemini 4 Argon on Command Code so image attachments are preserved and usage is billed correctly at $2 per million input tokens, $10 per million output tokens, and $0.10 per million cache-read tokens (#19125 by @wolfiesch).
  • Fixed Factory Droid GPT-6 models failing on the next turn after changing the thinking level during Bedrock or Snowflake sessions (#19188 by @will-bogusz).
  • Fixed OpenRouter model listings for workspace-restricted API keys so each key shows its correct allowed model roster and maintains an independent model cache (#19013 by @YibaiMeng).
  • Fixed OpenCode Go Muse Spark tool-call turns losing encrypted reasoning between steps (#17748 by @nico2525nn).
  • Fixed Vertex AI Gemini 3 and newer models rejecting replayed or cross-model tool calls that lack a thought signature (#17150 by @duck1eee).
  • Fixed Cursor model listings omitting models available to the provider, including GLM 5.3 and Grok 4.7 (#18248 by @joseotaviorf).

@oh-my-pi/pi-coding-agent

Added

  • Added /commit to create commits containing only changes made by the agent or a selected subagent, while preserving other agents’ and the user’s work. The workflow is also available through the eval commit namespace, supports targeting repositories outside the session directory, handles binary and non-UTF-8 files, symlinks, file mode changes, and initial commits, and can optionally skip commit hooks with no_verify; use commit.enabled to disable it.
  • Added auth.unpausedProviders (the Unpaused Providers setting) to re-enable paused providers such as Google Antigravity at your own risk while preserving their stored login state.
  • Added configurable long-turn todo reminders through todo.midRunNudges, including options to disable reminders, limit them to two, or continue with increasing intervals.
  • Pasting styled content into the composer now preserves Markdown formatting and places embedded images at their original positions, while code copied from editors remains plain text.
  • Added the session_clear hook and extension event, emitted when /clear resets the current session context without changing its session ID.
  • Added path-scoped Bash allow rules, project and configuration overlay precedence, and environment-variable controls through bash.allowedEnvVars and per-rule env settings.
  • Subagents now preserve @upstream provider pinning when inheriting models.
  • Added deletion of individual prompts from Ctrl+R history with the Delete key.
  • Added --no-judge, --no-spotlight, and --offline options to restrict or disable auxiliary services outside the active model’s provider.
  • Added per-rule TTSR repeatMode settings (once, after-gap, or always) to control reminder repetition.
  • Bash approval prompts now show compound command segments individually and identify which segments are allowed or require approval.
  • Todo done, drop, and rm operations now accept multiple tasks in a single request, including newline-, semicolon-, comma-, or space-separated input without splitting exact task-name matches.
  • Todo status lines now display task counts when multiple targets are involved.

Changed

  • /fork and fork-from-transcript now abort an active response and fork immediately.
  • Reduced default grep output by showing only matching lines and limiting matches per file; configure grep.contextBefore and grep.contextAfter to include surrounding context.
  • Changed the default spotlight.thinking level from low to med for deeper result analysis and improved ranking, at a higher request cost.
  • When Spotlight is enabled, commonly reread source and issue or pull-request content is shown more completely before outlining, including support for additional source file types.

Fixed

  • /loop now pauses after a provider error such as a rate limit instead of resubmitting the same prompt and attaching its @file mentions again (#19272).
  • Resuming a session whose directory was deleted now continues in the current directory with a warning instead of failing.
  • Model mentions and /switch completions now recover discovered models after provider discovery fails at startup, retrying discovery when needed.
  • Background job results that arrive after an ACP prompt ends are now carried into the next prompt instead of starting an invisible turn.
  • OpenAI server compaction failures now proceed to the next available compaction method instead of retrying server compaction on another model.
  • Language servers now recognize edits made shortly after a file is created, including on macOS.
  • Bash commands displayed in the Pseudo shell view now remain accurate while streaming through heredocs, substitutions, loops, continuations, arithmetic expressions, and background execution.
  • Resuming a session or reviving a subagent after a retry fallback with a thinking suffix (e.g. :xhigh) now restores the primary model's own thinking level instead of keeping the fallback's (#19273).

@oh-my-pi/collab-web

  • Fixed guests retaining stale agents, tool cards, and working state after a failed rejoin; guests now reliably restore the current session state when reconnecting.

  • Improved grep() and glob() performance for ovnfs checkouts by using the serving daemon when available while preserving native fallback behavior and existing streaming, filtering, and link-following options.

  • Improved shell search across local and network filesystems: local searches avoid unexpectedly traversing network mounts, network-backed searches perform more directory operations concurrently, and fd supports parallel traversal together with ignore, pruning, depth, worker, and error-reporting options.

  • Fixed SVG rendering when a generic font family refers to an unavailable font, preventing <text> elements from disappearing.
  • Fixed worktree add for source checkouts containing read-only files or directories, including cases where tracked directories are replaced by symlinks.
  • Fixed cancelled and timed-out Shell.run calls so they terminate only jobs started by that invocation while preserving the shell session for later runs.
  • Reduced memory usage when visualizing long multi-line shell commands.
  • Fixed the shell cp builtin so symlink-following options work correctly with archive and directory-copy modes without disabling recursion or attribute preservation.
  • Replaced built-in shell crashes on very long -a/-o chains in [ ] and test expressions with a clear error for excessively deep expressions.
