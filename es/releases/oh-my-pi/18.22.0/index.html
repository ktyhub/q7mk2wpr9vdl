oh-my-pi v18.22.0

#oh-mi-pi v18.22.0

@oh-mi-pi/pi-ai

Fijo

  • Se corrigió la transmisión lenta de llamadas a la herramienta Gemma con argumentos grandes.

@oh-my-pi/pi-coding-agent

Cambios importantes

  • Se movió el análisis binario de las herramientas independientes ida y ghidra al espacio de nombres dsm de backend neutral (xd://eval/dsm).
  • Se reemplazaron las configuraciones ida.enabled, ida.maxOpen y ida.idleCloseSec con disassembler.backend, disassembler.maxOpen y disassembler.idleCloseSec; La base de datos de desensamblador compartida API ahora está disponible en @oh-my-pi/pi-coding-agent/disasm.

Agregado

  • Se agregaron comentarios y edición de revisión del plan Tern: planes double-click para editarlos, seleccionar texto para agregar comentarios al estilo de Google Docs y enviar comentarios para Refinar.
  • Se agregó compatibilidad con Ghidra con configuración automática de Ghidra, JDK y PyGhidra cuando se solicita explícitamente el análisis; El modo automático utiliza un IDA Pro instalado cuando está disponible y, de lo contrario, recurre a Ghidra.
  • Se agregó soporte para compartir bases de datos de análisis en vivo con agentes secundarios a través de db.handle() y dsm.open(handle).
  • Se agregó una opción Force Remove a worktree.onExit que elimina los árboles de trabajo creados en sesiones sin preguntar, incluidos los árboles de trabajo con cambios no confirmados; Las nuevas confirmaciones permanecen en la rama del árbol de trabajo.

Cambiado

  • Revisión del plan Tern actualizada con un único control Aprobar, opción Refinar con reconocimiento de comentarios, selección de modelo y una acción Guardar que escribe el plan mientras mantiene la revisión abierta y el modo de plan activo.
  • Las lecturas ejecutables simples ahora muestran metadatos Mach-O, ELF y PE sin abrir una base de datos de análisis ni descargar un backend; solicite una descripción general, detalles de funciones o dsm.open() para comenzar el análisis.
  • Se mejoró el conmutador de modelos (Alt+P / /switch) con filtrado de proveedores y selección de nivel de pensamiento por conmutador. En Tern, ahora se abre encima del compositor con filtros integrados de búsqueda, proveedor y Tarea/Principal, y un control deslizante de nivel de pensamiento.

Fijo

  • Eliminar o mover árboles de directorios grandes dentro de un proyecto ya no detiene la visualización de archivos del servidor de idiomas (#19490 por @H4vC).
  • Reducción del uso de CPU y memoria para subagentes de larga ejecución a medida que crecen sus sesiones (#19486 por @H4vC).
  • Se corrigió que commit.draft() clasificara incorrectamente archivos eliminados o renombrados a través de bash o eval como "No tuyos"; ahora aparecen en Revisar.

Eliminado

  • Se eliminaron las herramientas de desensamblaje independientes heredadas y sus instrucciones asociadas.
  • Se eliminaron los botones Copiar y Editar en el editor de la hoja de revisión del plan de Tern; utilice la copia de selección y la edición doble click en su lugar.

@oh-my-pi/collab-web

Fijo

  • Se mejoró el rendimiento de la transmisión en el visor de colaboración, evitando que las respuestas largas se vuelvan progresivamente más lentas a medida que se reciben.

@oh-my-pi/pi-nativos

Cambios importantes

  • TtyWriter ahora requiere un umbral de drenaje y devolución de llamada y solo admite TTY que se pueden volver a abrir de forma independiente. Sus límites de bytes UTF-8 pendientes se informan de forma conservadora.

Cambiado

  • Los repintados de terminales grandes se manejan de manera más eficiente, lo que reduce el trabajo de las roscas JavaScript y libera buffers de gran tamaño después de los drenajes de salida.

Fijo

  • Se corrigió que los escritores de terminales bloqueados continuaran emitiendo resultados o filtrando descriptores de archivos después del apagado.
  • Se corrigió la salida del terminal que preserva Unicode a través de los límites de los fragmentos y reemplaza de forma segura secuencias sustitutas con formato incorrecto.

@oh-mi-pi/pi-tui

Cambios importantes

  • Los terminales que admiten contrapresión de salida ahora deben implementar onOutputDrain(callback), que devuelve una función de cancelación de suscripción; Los terminales sin contrapresión pueden omitir tanto pendienteOutputBytes como onOutputDrain.
  • Opciones actualizadas de PlanReviewOverlay para usar objetos PlanReviewOverlayChoice e informar los ID de las opciones a onPick y selectOption. Las acciones de Refinar y Guardar ahora reflejan los comentarios del plan y el comportamiento de ahorro; se eliminarondisableIndices y externalEditorName, y se actualizó la descripción para recibir DescribeContext.

Agregado

  • Se agregó ubicación de búsqueda de modelos configurable, alcances de proveedores y un control deslizante de nivel de pensamiento opcional a ModelPickerComponent; Los niveles de pensamiento seleccionados se informan a través de metadatos de onPick. La hoja de selección nativa ahora admite anclaje, estilo de alcance, visualización de niveles y acciones de íconos.
  • Se agregó un documento de revisión de plan nativo y un acoplamiento con planes editables y comentables, anotaciones de cotizaciones, notificaciones de edición de planes, acciones de Aprobar, Guardar y Cancelar, además de selección de modelo.

Cambiado

  • Los ámbitos de proveedores ahora muestran solo los modelos del proveedor seleccionado cuando se elige un proveedor, y el alcance cycling puede volver a la lista completa de modelos.
  • Se actualizaron los controles de nivel de pensamiento para usar las teclas de flecha izquierda y derecha, y se actualizó la presentación del control deslizante y las sugerencias del pie de página.
  • Se cambió el título de la superposición para guardar el plan a "Guardar plan" y se actualizó su etiqueta de acción.

Fijo

  • Se corrigió el desplazamiento lento y la escritura en transcripciones largas de agentes.
  • Se corrigió la lentitud en la escritura y el movimiento del cursor en borradores de más de 256 líneas.

@oh-mi-pi/pi-wire

Agregado

  • Se agregaron íconos de selección opcionales para información sobre herramientas y nombres accesibles, además de una opción para controlar la ubicación de la interfaz de búsqueda.
  • Se agregaron botones, menús y tipos de componentes de documentos, incluidos cambios de estado de acciones de filas de menú y eventos de edición de texto de documentos, comentarios y descomentaciones.

¿Qué ha cambiado?

  • perf(coding-agent): deja de copiar la lista completa de mensajes y el diario por editor descargados por @H4vC en https://github.com/can1357/oh-my-pi/pull/19486
  • perf(tui): detiene el cambio de caché del editor y reconstrucciones completas de la línea visual por @H4vC en https://github.com/can1357/oh-my-pi/pull/19488
  • perf(ai): escanea las llamadas a la herramienta dentro de banda de Gemma de forma incremental mediante @H4vC en https://github.com/can1357/oh-my-pi/pull/19487
  • perf(coding-agent): olvide los directorios desaparecidos en el observador de archivos LSP sin análisis completos por parte de @H4vC en https://github.com/can1357/oh-my-pi/pull/19490
  • perf(collab-web): mantiene el DOM de los bloques Markdown terminados mientras se transmite por @H4vC en https://github.com/can1357/oh-my-pi/pull/19485
  • perf(tui): reutiliza las filas del visor de transcripción del agente entre pinturas por @H4vC en https://github.com/can1357/oh-my-pi/pull/19489 Changelog completo: https://github.com/can1357/oh-my-pi/compare/v18.21.0...v18.22.0

oh-my-pi v18.22.0

@oh-my-pi/pi-ai

Fixed

  • Fixed slow streaming of Gemma tool calls with large arguments.

@oh-my-pi/pi-coding-agent

Breaking Changes

  • Moved binary analysis from the standalone ida and ghidra tools into the backend-neutral dsm namespace (xd://eval/dsm).
  • Replaced the ida.enabled, ida.maxOpen, and ida.idleCloseSec settings with disassembler.backend, disassembler.maxOpen, and disassembler.idleCloseSec; shared disassembler database APIs are now available under @oh-my-pi/pi-coding-agent/disasm.

Added

  • Added Tern plan review editing and comments: double-click plans to edit them, select text to add Google Docs-style comments, and send comments to Refine.
  • Added Ghidra support with automatic setup of Ghidra, JDK, and PyGhidra when analysis is explicitly requested; Auto mode uses an installed IDA Pro when available and otherwise falls back to Ghidra.
  • Added support for sharing live analysis databases with child agents through db.handle() and dsm.open(handle).
  • Added a Force Remove option to worktree.onExit that removes session-created worktrees without prompting, including worktrees with uncommitted changes; new commits remain on the worktree branch.

Changed

  • Updated Tern plan review with a single Approve control, comment-aware Refine option, model selection, and a Save action that writes the plan while keeping review open and plan mode active.
  • Plain executable reads now display Mach-O, ELF, and PE metadata without opening an analysis database or downloading a backend; request an overview, function details, or dsm.open() to begin analysis.
  • Improved the model switcher (Alt+P / /switch) with provider filtering and per-switch thinking-level selection. In Tern, it now opens above the composer with integrated search, provider and Task/Main filters, and a thinking-level slider.

Fixed

  • Deleting or moving large directory trees inside a project no longer stalls language-server file watching (#19490 by @H4vC).
  • Reduced CPU and memory usage for long-running subagents as their sessions grow (#19486 by @H4vC).
  • Fixed commit.draft() incorrectly classifying files deleted or renamed through bash or eval as “Not yours”; they now appear under Review.

Removed

  • Removed the legacy standalone disassembler tools and their associated prompt instructions.
  • Removed the Copy and Edit-in-editor buttons from the Tern plan review sheet; use selection copying and double-click editing instead.

@oh-my-pi/collab-web

Fixed

  • Improved streaming performance in the collab viewer, preventing long replies from becoming progressively slower as they are received.

@oh-my-pi/pi-natives

Breaking Changes

  • TtyWriter now requires a drain threshold and callback and only supports independently reopenable TTYs. Its pending UTF-8 byte bounds are reported conservatively.

Changed

  • Large terminal repaints are handled more efficiently, reducing JavaScript-thread work and releasing oversized buffers after output drains.

Fixed

  • Fixed stalled terminal writers continuing to emit output or leaking file descriptors after shutdown.
  • Fixed terminal output preserving Unicode across chunk boundaries and safely replacing malformed surrogate sequences.

@oh-my-pi/pi-tui

Breaking Changes

  • Terminals that support output backpressure must now implement onOutputDrain(callback), which returns an unsubscribe function; terminals without backpressure can omit both pendingOutputBytes and onOutputDrain.
  • Updated PlanReviewOverlay options to use PlanReviewOverlayChoice objects and report choice IDs to onPick and selectOption. Refine and Save actions now reflect plan feedback and saving behavior; removed disabledIndices and externalEditorName, and updated describe to receive DescribeContext.

Added

  • Added configurable model search placement, provider scopes, and an optional thinking-level slider to ModelPickerComponent; selected thinking levels are reported through onPick metadata. The native picker sheet now supports anchoring, scope styling, level display, and icon actions.
  • Added a native plan review document and dock with editable and commentable plans, quote annotations, plan-edit notifications, Approve, Save, and Cancel actions, plus model selection.

Changed

  • Provider scopes now show only the selected provider's models when a provider is chosen, with scope cycling able to return to the full model list.
  • Updated thinking-level controls to use left and right arrow keys, and refreshed the slider and footer hint presentation.
  • Retitled the plan-saving overlay to “Save plan” and updated its action label.

Fixed

  • Fixed slow scrolling and typing in long agent transcripts.
  • Fixed slow typing and cursor movement in drafts longer than 256 lines.

@oh-my-pi/pi-wire

Added

  • Added optional picker icons for tooltips and accessible names, plus an option to control the placement of the search interface.
  • Added buttons, menu, and document component kinds, including menu-row action state changes and document text editing, commenting, and uncommenting events.

What's Changed

  • perf(coding-agent): stop copying the full message list and journal per publisher flush by @H4vC in https://github.com/can1357/oh-my-pi/pull/19486
  • perf(tui): stop editor wrap-cache thrash and full visual-line rebuilds by @H4vC in https://github.com/can1357/oh-my-pi/pull/19488
  • perf(ai): scan Gemma in-band tool calls incrementally by @H4vC in https://github.com/can1357/oh-my-pi/pull/19487
  • perf(coding-agent): forget vanished directories in the LSP file watcher without full scans by @H4vC in https://github.com/can1357/oh-my-pi/pull/19490
  • perf(collab-web): keep finished Markdown blocks' DOM while streaming by @H4vC in https://github.com/can1357/oh-my-pi/pull/19485
  • perf(tui): reuse the agent transcript viewer's rows between paints by @H4vC in https://github.com/can1357/oh-my-pi/pull/19489
