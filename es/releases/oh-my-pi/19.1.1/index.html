#oh-mi-pi v19.1.1

@oh-my-pi/pi-agent-core

Fijo

  • Se evitó que las transferencias de gran tamaño llegaran al proveedor al detectar cuando el contexto preparado excede la ventana de contexto del modelo objetivo.
  • Estado de error del proveedor preservado, identificadores de error, clasificación de reintentos y marcadores de cancelación en turnos de asistente fallidos o cancelados.
  • Se corrigieron las llamadas de herramientas especulativas que se bloqueaban cuando se descartaban o se abortaban antes de que se completara la ejecución.

@oh-mi-pi/pi-ai

Agregado

  • Se agregó AssistantMessage.requestId, completado a partir del encabezado de respuesta request-id de Anthropic, por lo que las solicitudes fallidas o rechazadas conservan el identificador necesario para el soporte de Anthropic.
  • Se agregó GET /v1/pi/models a omp auth-gateway, ofreciendo el catálogo de modelos de la puerta de enlace (límites, niveles de pensamiento, precios) a clients nativos.

Cambiado

  • La selección de cuentas de Devin ahora prioriza los inicios de sesión con cuota diaria o semanal restante, luego las cuentas financiadas con saldo bajo demanda, mientras se omiten las cuentas sin capacidad disponible. Los inicios de sesión de Devin también rastrean el correo electrónico, la identificación del usuario y la organización, por lo que se pueden distinguir organizaciones separadas en omp usage y auth.accountPolicies; Los inicios de sesión existentes deben volver a autenticarse para completar esta información.
  • Los errores de facturación de los proveedores ahora se tratan como límites de uso, lo que permite reintentos para rotar cuentas y continuar a través de la cadena de respaldo del modelo.
  • Los informes de uso de proveedores registrados por extensiones ahora persisten en todos los procesos omp, evitando comprobaciones repetidas innecesarias de los puntos finales de uso.
  • Las solicitudes que se detienen durante las operaciones del proveedor ahora se clasifican como tiempos de espera, lo que permite el retorno automático a otro modelo.
  • Se redujo el uso de memoria inactiva al cargar datos de perturbación rápida solo cuando la perturbación está habilitada para una solicitud.

Fijo

  • Se corrigió el manejo de llamadas de herramientas divididas para que los modelos configurados con splitToolCalls reciban cada llamada de herramienta junto con su resultado correspondiente en el orden de mensaje correcto.
  • Se corrigió el manejo del motivo de finalización de apple/on-device para que las solicitudes ya no emitan advertencias estándar falsas e informen correctamente las terminaciones de longitud o parada reconocidas.
  • Se mejoró la validación local para solicitudes antrópicas vacías al informar el modelo, el proveedor y el recuento de mensajes recibidos en lugar de un error de proveedor opaco.
  • Se corrigieron las solicitudes de OpenAI y Codex que fallaban en los esquemas de herramientas MCP que contenían patrones de caracteres sin escape no admitidos.
  • Las solicitudes de OpenRouter Responses que terminan en un elemento de razonamiento cifrado no facturado ahora muestran la falla subyacente del proveedor en lugar de completarse silenciosamente.
  • Se corrigió la preservación de las firmas de pensamiento de Gemini en las llamadas a herramientas cuando se usa Portkey o la puerta de enlace de autenticación.
  • Se corrigió que el protector del bucle de pensamiento reintentara incorrectamente las respuestas finales que contenían tablas de Markdown largas o registros JSON de forma similar.
  • Se corrigió la conversión estricta del esquema de herramientas para que las propiedades de los objetos que aceptan campos arbitrarios no se restrinjan incorrectamente a objetos vacíos.
  • Se corrigieron los modelos antigravity-cli que no recibían imágenes devueltas por herramientas como read.
  • Se corrigieron errores transitorios de proxy que interrumpían la transmisión de instantáneas y deshabilitaban los informes de uso durante el resto del proceso.
  • Se corrigieron sesiones simultáneas de Antigravity CLI para la misma cuenta que fallaban durante la preparación de credenciales.
  • Se corrigieron las continuaciones de OpenAI Codex WebSocket para que la información de enrutamiento de giros fijos se conserve para solicitudes posteriores.
  • Recuperación mejorada de un agent.db corrupto para que las credenciales legibles del proveedor se restablezcan cuando sea posible y las credenciales deshabilitadas permanezcan deshabilitadas.

@oh-my-pi/relé-navegador

Fijo

  • La configuración de Conexión del panel lateral ahora muestra el motivo específico del navegador cuando rechaza el host nativo (por ejemplo, porque la política empresarial bloquea la mensajería nativa), en lugar de sugerir incorrectamente que puede faltar el host.

@oh-my-pi/pi-catalogo

Agregado

  • Z.AI (zai) ahora descubre los modelos disponibles para su clave de plan de codificación GLM, por lo que los modelos GLM recién lanzados aparecen sin esperar una actualización del catálogo.
  • Se agregaron getUpstreamPin() y routedModelsAreEqual() a @oh-my-pi/pi-catalog/models para distinguir los modelos de agregadores enrutados a diferentes proveedores ascendentes.
  • Se agregaron @oh-my-pi/pi-catalog/discovery/pi-native y piNativeModelManagerOptions() para leer la lista de modelos de un proveedor desde el GET /v1/pi/models de una puerta de enlace de autenticación.

Fijo

  • Se corrigió que los modelos de Llama 3.x fallaran después de turnos que invocaban múltiples herramientas cuando se entregaban a través de hosts basados en vLLM, incluido CoreWeave a través de OpenRouter.
  • El uso de Devin ahora se mantiene separado para las organizaciones que comparten la misma dirección de correo electrónico.
  • Se actualizó la contabilidad de tokens de imágenes de Devin para que coincida con el cargo publicado de 1089 tokens por imagen de Devin en los modelos de imágenes Gemini compatibles.
  • Se corrigieron los precios de Devin y los límites de contexto para los carriles rápidos GPT-5.6 Sol, Terra y Luna, incluidas las tasas de contexto largo superiores a 272 K de tokens de entrada y el límite estándar de 272 K cuando el contexto extendido está deshabilitado.
  • Se corrigió el precio del cursor para los modelos GPT-5.6 Sol, Terra y Luna para que la salida por encima de 272 000 tokens de entrada utilice la tasa 1.5× documentada.
  • Desactivar el pensamiento para GPT-6.1 Terra ahora utiliza el esfuerzo de razonamiento compatible none.
  • Se corrigió que los modelos GPT-6.2 y posteriores de OpenAI Responses perdieran el contexto de razonamiento después de la poda de sesión y las llamadas a herramientas posteriores.
  • Se corrigieron las opciones de razonamiento y manejo del esfuerzo de Bedrock Kimi K3.1 Pro Highspeed.
  • GitHub Copilot ahora enumera solo los modelos disponibles para la cuenta, incluso después de reiniciar.
  • Los modelos Codex descubiertos antes de ser empaquetados ahora usan sus nombres para mostrar formateados, como GPT-6.2 Sol.

@oh-my-pi/pi-coding-agent

Cambios importantes

  • El shell nativo Rust API ahora almacena variables indexadas como IndexedArray en lugar de Vec; construya valores VarValue::Indexed con items.into().

Agregado

  • Se agregó el segmento de estado opcional tree, que muestra la posición de una sesión en el árbol de sesiones después de un rebobinado o en una rama; en Tern, el segmento se abre /tree cuando clicked.
  • Los proveedores enrutados a través de una puerta de enlace de autenticación (transport: pi-native) ahora enumeran los modelos de la puerta de enlace, por lo que los modelos que la puerta de enlace descubre en tiempo de ejecución (como los nuevos modelos Codex) se pueden seleccionar sin declararlos en models.yml, y los modelos que la puerta de enlace no puede enrutar están ocultos.
  • Se agregó computer.takeover como reemplazo de computer.backgroundFallback, con modos fallback, foreground y always para controlar cuándo la herramienta informática toma el control de la ventana de primer plano. El comportamiento de reserva existente se conserva de forma predeterminada.
  • Se agregó un shell column portátil incorporado con opciones compatibles con util-linux, que incluyen formato de tabla, columnas con nombre, alineación, ocultación, ordenamiento, salida JSON, visualización de árbol y controles de ancho.
  • Se agregó extensión para todos los backends a través de pi.registerTodoBackend() y la configuración todo.backend. Los backends registrados pueden reflejar la lista de tareas completa de la sesión en una tienda externa y se pueden seleccionar y configurar desde /settings → Herramientas → Todos.
  • /wt ahora ejecuta el gancho post-checkout del nuevo árbol de trabajo, muestra el progreso en la TUI y carga habilidades y comandos creados por el gancho. Los ganchos fallidos dejan el árbol de trabajo intacto y muestran una advertencia.

Cambiado

  • La recuperación de parada vacía ahora registra cada reintento con el modelo seleccionado, el proveedor y los metadatos de parada, lo que hace visibles las respuestas repetidas del modelo vacío en el registro de sesión.
  • El selector rápido de modelos actualiza los catálogos de proveedores obsoletos en segundo plano, de modo que las sesiones de larga duración puedan descubrir nuevos modelos disponibles.
  • En Linux, la observación de archivos del servidor de idiomas ahora se adapta al límite de observación de inotify, por lo que es menos probable que los espacios de trabajo grandes interfieran con otros observadores de archivos y servicios del sistema.
  • La herramienta eval ahora documenta su fecha límite de celda predeterminada de 30 segundos en su parámetro de aviso y tiempo de espera.

Fijo

  • Magic Edit mejorado para que pueda buscar y leer el borrador actual, reintentar reemplazos fallidos sin perder ediciones exitosas, validar la sintaxis antes de escribir y admitir modelos que emiten llamadas a herramientas como texto.
  • Se corrigió el manejo de comandos de la herramienta de shell cuando bash se reemplaza por una extensión, incluida la compatibilidad con líneas de comando de solo herramientas con shells remotos o en espacio aislado.
  • Se corrigió la validación y la documentación del desplazamiento del navegador para que los formularios de objetos no válidos expliquen la firma de píxel-delta correcta y la llamada equivalente.
  • Se corrigió el manejo de ask de conjuntos de campos cuyos botones de opción usan nombres diferentes, lo que impide que se envíe una opción preseleccionada junto con la elección del usuario.
  • Se corrigió que la generación de títulos se detuviera cuando un modelo declines explícitamente con <title/> o none, mientras continuaba con el siguiente candidato para errores o respuestas inutilizables.
  • Se corrigió la compactación automática y especulativa para que las solicitudes de transferencia de gran tamaño o no recuperables pasen al siguiente método de compactación disponible en lugar de enviarse repetidamente a un proveedor.
  • wait() en celdas de evaluación ahora acepta ID de subagente mostrados, incluido el formulario agent://id, pero aún rechaza identificadores que pertenecen a otras sesiones.
  • Se corrigió la configuración del modelo de inicio y sesión para que los niveles de pensamiento, el orden de los proveedores de modelos, las listas permitidas de modelos habilitados, las selecciones de enrutamiento y las rutas ascendentes fijadas permanezcan consistentes en todos los cambios de modelo, cycling, restauración, modo de plan y actualizaciones de metadatos.
  • Se corrigieron los mensajes de seguimiento en cola que se perdían cuando se descartaban las respuestas interrumpidas y se corrigieron las interrupciones de TTSR que podían dejar una sesión sin poder continuar.
  • Se corrigieron las sesiones de OpenAI Responses que reescribían los resultados de las herramientas enviadas anteriormente, lo que podría provocar que se rechazaran elementos de razonamiento posteriores.
  • Se corrigieron problemas de edición de archivos relacionados con el formato en escritura y enlaces simbólicos, incluidos errores de escritura incorrecta, instantáneas faltantes, rutas local:// duplicadas y nombres de archivos con enlaces simbólicos incorrectos en vistas previas y diarios.
  • Se corrigieron las descargas del navegador de Windows que ocasionalmente retenían nombres de archivos GUID temporales cuando el archivo descargado se bloqueaba brevemente.
  • Se corrigió el cierre de RPC dejando los subprocesos de MCP ejecutándose después de finalizar la sesión.
  • Se corrigió la salida del asesor y de Spotlight para que los resultados de la herramienta truncados o repetidos se representen con precisión sin perder el contenido original.
  • Se corrigieron las advertencias de inicio de primera ejecución que persistían después de seleccionar un modelo predeterminado.
  • Se corrigió el manejo de transferencias de contexto para que la contabilidad concurrente ya no elimine silenciosamente una transferencia explícita y las transferencias omitidas produzcan una advertencia.
  • /omfg ahora cierra su panel después de guardar exitosamente una regla y muestra la ruta guardada; Los errores mantienen el panel abierto.
  • Se corrigió el manejo del shell de los principales comandos cd que usan glob, brace o expansión de inicio de usuario nombrado.
  • Los agentes de complemento de formato Claude ahora asignan correctamente nombres de herramientas Claude como WebFetch, WebSearch, TodoWrite, AskUserQuestion, MultiEdit y Agent a sus equivalentes OMP.
  • Las notificaciones de extensión de inicio ahora permanecen visibles en lugar de ser sobrescritas por avisos posteriores o el estado de inicio de MCP.
  • Se corrigió el análisis de CLI para que --plan ya no consuma el siguiente indicador CLI como valor durante el inicio, reinicio, bifurcación o enrutamiento de subcomandos.
  • Se corrigió /usage cuando la base de datos de uso estaba bloqueada temporalmente; El historial almacenado permanece visible y se marca como no sincronizado si no se puede actualizar.
  • El descubrimiento de modelos ahora clasifica los modelos de solo voz y de solo transcripción como modelos TTS y STT en lugar de modelos de chat.
  • Los subagentes detenidos por su padre ahora registran que fueron detenidos por el agente principal.

  • Se corrigieron las lecturas de URL de X y YouTube para respetar la configuración de la sesión SDK incluso cuando la configuración global no se ha inicializado.

  • Se corrigió que read se colgara en imágenes y otros archivos que no son de texto cuando la ejecución especulativa y los ganchos beforeToolCall estaban habilitados.
  • Los registros de errores del proveedor ahora incluyen el ID de solicitud necesario para solucionar problemas de rechazo de Anthropic.
  • Las sesiones iniciadas a partir de indicaciones de colaboración ahora reciben títulos automáticos.
  • Se corrigieron las bifurcaciones /tan que terminaban una espera inactiva prematuramente cuando su asignación permanece bloqueada.

oh-my-pi v19.1.1

@oh-my-pi/pi-agent-core

Fixed

  • Prevented oversized handoffs from reaching the provider by detecting when prepared context exceeds the target model’s context window.
  • Preserved provider error status, error identifiers, retry classification, and cancellation markers on failed or cancelled assistant turns.
  • Fixed speculative tool calls hanging when discarded or aborted before execution completed.

@oh-my-pi/pi-ai

Added

  • Added AssistantMessage.requestId, populated from Anthropic’s request-id response header, so failed or refused requests retain the identifier needed for Anthropic support.
  • Added GET /v1/pi/models to omp auth-gateway, serving the gateway's model catalog (limits, thinking levels, pricing) to pi-native clients.

Changed

  • Devin account selection now prioritizes logins with remaining daily or weekly quota, then accounts funded by on-demand balance, while skipping accounts with no available capacity. Devin logins also track email, user ID, and organization so separate organizations are distinguishable in omp usage and auth.accountPolicies; existing logins must be reauthenticated to populate this information.
  • Billing failures from providers are now treated as usage limits, allowing retries to rotate accounts and continue through the model fallback chain.
  • Provider usage reports registered by extensions now persist across omp processes, avoiding unnecessary repeated usage-endpoint checks.
  • Requests that stall during provider operations are now classified as timeouts, allowing automatic fallback to another model.
  • Reduced idle memory usage by loading prompt-perturbation data only when perturbation is enabled for a request.

Fixed

  • Fixed split tool-call handling so models configured with splitToolCalls receive each tool call together with its corresponding result in the correct message order.
  • Fixed apple/on-device finish-reason handling so requests no longer emit spurious stderr warnings and correctly report recognized stop or length completions.
  • Improved local validation for empty Anthropic requests by reporting the model, provider, and received message count instead of an opaque provider error.
  • Fixed OpenAI and Codex requests failing on MCP tool schemas containing unsupported unescaped character patterns.
  • OpenRouter Responses requests that end in an unbilled encrypted reasoning item now surface the underlying provider failure instead of completing silently.
  • Fixed preservation of Gemini thought signatures across tool calls when using Portkey or the authentication gateway.
  • Fixed the thinking-loop guard incorrectly retrying final answers containing long Markdown tables or similarly shaped JSON records.
  • Fixed strict tool-schema conversion so object properties that accept arbitrary fields are not incorrectly restricted to empty objects.
  • Fixed antigravity-cli models failing to receive images returned by tools such as read.
  • Fixed transient proxy errors from disrupting snapshot streaming and disabling usage reporting for the remainder of the process.
  • Fixed concurrent Antigravity CLI sessions for the same account failing during credential staging.
  • Fixed OpenAI Codex WebSocket continuations so sticky turn routing information is preserved for subsequent requests.
  • Improved recovery from a corrupt agent.db so readable provider credentials are restored where possible and disabled credentials remain disabled.

@oh-my-pi/browser-relay

Fixed

  • The side panel’s Connection settings now show the browser’s specific reason when it refuses the native host (for example, because native messaging is blocked by enterprise policy), instead of incorrectly suggesting that the host may be missing.

@oh-my-pi/pi-catalog

Added

  • Z.AI (zai) now discovers the models available to your GLM Coding Plan key, so newly released GLM models appear without waiting for a catalog update.
  • Added getUpstreamPin() and routedModelsAreEqual() to @oh-my-pi/pi-catalog/models for distinguishing aggregator models routed to different upstream providers.
  • Added @oh-my-pi/pi-catalog/discovery/pi-native and piNativeModelManagerOptions() for reading a provider's model roster from an auth gateway's GET /v1/pi/models.

Fixed

  • Fixed Llama 3.x models failing after turns that invoked multiple tools when served through vLLM-based hosts, including CoreWeave through OpenRouter.
  • Devin usage is now kept separate for organizations that share the same email address.
  • Updated Devin image token accounting to match Devin’s published 1,089-token charge per image across supported Gemini image models.
  • Corrected Devin pricing and context limits for GPT-5.6 Sol, Terra, and Luna Fast lanes, including long-context rates above 272K input tokens and the standard 272K limit when Extended Context is disabled.
  • Corrected Cursor pricing for GPT-5.6 Sol, Terra, and Luna models so output above 272K input tokens uses the documented 1.5× rate.
  • Turning thinking off for GPT-6.1 Terra now uses the supported none reasoning effort.
  • Fixed GPT-6.2 and later OpenAI Responses models losing reasoning context after session pruning and subsequent tool calls.
  • Corrected Bedrock Kimi K3.1 Pro Highspeed reasoning options and effort handling.
  • GitHub Copilot now lists only models available to the account, including after restarting.
  • Codex models discovered before being bundled now use their formatted display names, such as GPT-6.2 Sol.

@oh-my-pi/pi-coding-agent

Breaking Changes

  • The native shell Rust API now stores indexed variables as IndexedArray instead of Vec; construct VarValue::Indexed values with items.into().

Added

  • Added the opt-in tree status segment, which shows a session’s position in the session tree after a rewind or on a branch; in Tern, the segment opens /tree when clicked.
  • Providers routed through an auth gateway (transport: pi-native) now list the gateway's models, so models the gateway discovered at runtime (such as new Codex models) can be selected without declaring them in models.yml, and models the gateway cannot route are hidden.
  • Added computer.takeover as the replacement for computer.backgroundFallback, with fallback, foreground, and always modes for controlling when the computer tool takes over the foreground window. Existing fallback behavior is preserved by default.
  • Added a portable column shell builtin with util-linux-compatible options, including table formatting, named columns, alignment, hiding, ordering, JSON output, tree display, and width controls.
  • Added extension todo backends through pi.registerTodoBackend() and the todo.backend setting. Registered backends can mirror the session’s complete todo list to an external store and can be selected and configured from /settings → Tools → Todos.
  • /wt now runs the new worktree’s post-checkout hook, displays progress in the TUI, and loads skills and commands created by the hook. Failed hooks leave the worktree intact and display a warning.

Changed

  • Empty-stop recovery now records each retry with the selected model, provider, and stop metadata, making repeated empty model responses visible in the session log.
  • The quick model picker refreshes stale provider catalogs in the background, so long-running sessions can discover newly available models.
  • On Linux, language-server file watching now adapts to the inotify watch limit so large workspaces are less likely to interfere with other file watchers and system services.
  • The eval tool now documents its default 30-second cell deadline in its prompt and timeout parameter.

Fixed

  • Improved Magic Edit so it can search and read the current draft, retry failed replacements without losing successful edits, validate syntax before writing, and support models that emit tool calls as text.
  • Fixed shell tool command handling when bash is replaced by an extension, including support for tool-only command lines with remote or sandboxed shells.
  • Fixed browser scrolling validation and documentation so invalid object forms explain the correct pixel-delta signature and equivalent call.
  • Fixed ask handling of fieldsets whose radio buttons use different names, preventing a preselected option from being submitted alongside the user’s choice.
  • Fixed title generation to stop when a model explicitly declines with <title/> or none, while continuing to the next candidate for errors or unusable replies.
  • Fixed automatic and speculative compaction so oversized or non-retriable handoff requests move on to the next available compaction method instead of being repeatedly sent to a provider.
  • wait() in eval cells now accepts displayed subagent IDs, including the agent://id form, while still rejecting handles belonging to other sessions.
  • Fixed startup and session model configuration so thinking levels, model-provider ordering, enabled-model allowlists, routed selections, and pinned upstream routes remain consistent across model switches, cycling, restore, plan mode, and metadata refreshes.
  • Fixed queued follow-up messages being lost when interrupted responses are discarded, and fixed TTSR interruptions that could leave a session unable to continue.
  • Fixed OpenAI Responses sessions rewriting previously sent tool results, which could cause later reasoning items to be rejected.
  • Fixed format-on-write and symlink-related file editing issues, including incorrect write failures, missing snapshots, duplicated local:// paths, and incorrect symlinked filenames in previews and journals.
  • Fixed Windows browser downloads occasionally retaining temporary GUID filenames when the downloaded file was briefly locked.
  • Fixed RPC shutdown leaving MCP subprocesses running after the session ended.
  • Fixed advisor and Spotlight output so truncated or repeated tool results are represented accurately without losing the original content.
  • Fixed first-run startup warnings that persisted after a default model had been selected.
  • Fixed context rollover handling so concurrent bookkeeping no longer silently drops an explicit rollover, and skipped rollovers produce a warning.
  • /omfg now closes its panel after successfully saving a rule and shows the saved path; errors keep the panel open.
  • Fixed shell handling of leading cd commands that use glob, brace, or named-user home expansion.
  • Claude-format plugin agents now correctly map Claude tool names such as WebFetch, WebSearch, TodoWrite, AskUserQuestion, MultiEdit, and Agent to their OMP equivalents.
  • Startup extension notifications now remain visible instead of being overwritten by later notices or MCP startup status.
  • Fixed CLI parsing so --plan no longer consumes a following CLI flag as its value during startup, restart, fork, or subcommand routing.
  • Fixed /usage when the usage database is temporarily locked; stored history remains visible and is marked unsynced if it cannot be refreshed.
  • Model discovery now classifies speech-only and transcription-only models as TTS and STT models rather than chat models.
  • Subagents stopped by their parent now record that they were stopped by the parent agent.
  • Fixed SDK and extension imports, examples, and session-specific extension discovery for RPC and ACP sessions.
  • Fixed X and YouTube URL reads to honor SDK session settings even when global settings have not been initialized.
  • Restored sessions now correctly report background jobs whose outcome is unknown, and omp --restore no longer replays completed turns after idle compaction or interruption.
  • Selective commits now preserve the drafted contents and Git clean-filter results for binary, non-text, oversized, and Git LFS files, and avoid overwriting files changed since the draft was created.
  • Fixed read hanging on images and other non-text files when speculative execution and beforeToolCall hooks are enabled.
  • Provider error logs now include the request ID needed for troubleshooting Anthropic refusals.
  • Sessions started from collaboration prompts now receive automatic titles.
  • Fixed /tan forks ending an idle wait prematurely when their assignment remains blocked.
