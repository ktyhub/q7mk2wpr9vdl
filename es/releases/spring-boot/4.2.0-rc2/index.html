bota de resorte v4.2.0-RC2

:star: Nuevas funciones

  • Eliminar soporte de recarga LDAP SSL #52365
  • Se agregó soporte para X-Forwarded-Prefix con Reactor Netty #52316

:lady_beetle: Corrección de errores

  • Configurar management.observations.conventions en open-telemetry no permite ninguna convención semántica #52619
  • PushGatewayTaskScheduler no cierra correctamente el programador de tareas cuando se cierra el contexto #52591
  • ClearCachesApplicationListener no encuentra los métodos clearCache() heredados #52589
  • MongoTransactionManager creado por BatchDataMongoAutoConfiguration no está personalizado por TransactionManagerCustomizers #52572
  • El procesador de configuración no maneja tipos conocidos cuando están completamente calificados #52571
  • Se informa que el host Rabbit AMQP no válido tiene un valor incorrecto #52568
  • Evite el desbordamiento prematuro al convertir duraciones a microsegundos #52561
  • La vinculación de un valor de un árbol de configuración falla después de vincular una colección del mismo tipo de elemento desde el mismo árbol de configuración #52559
  • JsonWriter escribe JSON no válido cuando se usa Pairs con un miembro nombrado #52549
  • El registro estructurado de GELF escribe un mensaje corto nulo cuando el mensaje de registro es nulo #52547
  • KafkaTransactionManager configurado automáticamente no está personalizado por TransactionManagerCustomizers #52542
  • Las capas personalizadas en el complemento Gradle incluyen contenido excluido en lugar de excluirlo #52540
  • Las direcciones RabbitMQ sin puerto utilizan el puerto AMQP cuando SSL está habilitado #52538
  • BasicJsonParser no decodifica secuencias de escape \b, \f, \n, \r, \t y \uXXXX #52534
  • NestedJarFile.getComment() falla con una EOFException cuando el archivo jar no tiene comentarios #52513
  • El volcado de subprocesos de texto sin formato informa que los subprocesos en Object.wait() están estacionados en Java 19+ #52511
  • Cuando se utilizan tanto spring-boot-amqp-rabbitmq como spring-boot-rabbitmq, se pierde la información de salud de este último #52506
  • Las fallas de análisis de JSON ya no producen excepciones DockerOutputParseExceptions #52500
  • El registro estructurado de ECS escribe objetos service y service.node vacíos #52497
  • ConfigurationMetadataAnnotationProcessor produce una salida no repetible si varios puntos finales comparten el mismo ID #52494
  • El cierre ordenado no espera solicitudes activas después de reiniciar Tomcat o Jetty #52490
  • RabbitMQ utiliza el puerto incorrecto de forma predeterminada cuando se configura un paquete SSL #52488
  • R2dbcTransactionManager configurado automáticamente no lo personalizan TransactionManagerCustomizers #52485
  • JsonWriter escribe NaN y valores infinitos como JSON no válidos #52483
  • ZipEndOfCentralDirectoryRecord encuentra la firma del registro dentro del comentario zip #52481
  • La compatibilidad con LLdap Docker Compose no se puede conectar cuando LLDAP_LDAP_USER_DN está configurado #52475
  • ZipContent.Entry hasNameStartingWith ignora el desplazamiento de los nombres de directorios anidados virtualizados #52464
  • ZipContent no puede abrir un archivo zip con datos después del final del registro del directorio central #52461
  • ZipContent lee el comentario zip desde la posición incorrecta cuando el archivo tiene datos con prefijo #52459
  • La configuración del registrador raíz no se puede recuperar y no tiene ningún nivel configurado con Log4j2 #52455
  • La integración Docker Compose OTLP requiere que los puertos gRPC y HTTP estén expuestos cuando solo se usa HTTP #52451
  • La configuración automática de Spring Batch JDBC se conecta a la base de datos al inicio para detectar su tipo, sin forma de configurarla #52449
  • Los cachés de OnAvailableEndpointCondition retienen contextos de aplicaciones cerradas a través de su entorno #52447
  • DataSourceTransactionManagerAutoConfiguration utiliza una propiedad antigua que ya no es compatible para controlar la traducción de excepciones #52445
  • La nueva propiedad 'maxLocaleCount' de Tomcat no se puede configurar fácilmente #52443
  • DevTools filtra un hilo de File Watcher por cada reinicio fallido #52441
  • Los cifrados de paquetes SSL y los protocolos habilitados a veces se ignoran silenciosamente cuando el componente subyacente no admite su configuración #52438
  • AMQP 1.0 no debe configurar ninguna credencial para usar ANÓNIMO de forma predeterminada #52435
  • Puerto RabbitMQ AMQP 1.0 predeterminado en 5671 cuando se configura un paquete SSL #52432
  • Hikari no registra sus propios MBeans cuando se utiliza la recuperación diferida de conexiones con JMX habilitado #52426
  • RabbitMQ clients ignora los cifrados de paquete SSL y los protocolos habilitados #52416
  • Kafka clients ignora los cifrados de paquete SSL y los protocolos habilitados #52413
  • El punto final de salud falla con un error interno para una ruta con un segmento intermedio desconocido #52411
  • La aplicación de servlet no se inicia cuando se configuran las propiedades del servidor de recursos de token opaco y JWT #52409
  • Los corredores se pueden invocar después de que el contexto de la aplicación se haya cerrado durante el inicio #52408
  • La vinculación simultánea de beans @ConfigurationProperties puede dañar BoundConfigurationProperties y fallar la vinculación #52406
  • JavaMailSender configurado automáticamente no aplica cifrados de paquete SSL ni protocolos habilitados #52404
  • La raíz de la ruta de clase no se puede resolver en archivos jar ejecutables después de #52246 #52402
  • La serialización de Kotlin no retrocede cuando JSON-B es el único convertidor JSON #52389
  • Los parámetros de matriz distorsionan los valores pasados para que coincidan con todos los selectores restantes cuando se usa WebMvc o WebFlux #52378
  • Los paquetes SSL de nombre de servidor con nombres de servidor en mayúsculas no se utilizan con Netty #52364
  • Las ubicaciones de datos de configuración con corchetes en su ruta no se cargan correctamente #52360
  • El cierre del contexto puede bloquearse cuando la suspensión del grupo Hikari está habilitada #52359
  • OriginTrackedPropertiesLoader elimina la línea después de un comentario que termina con una barra invertida #52357
  • Cerrar un contexto secundario detiene el hilo de mantener activo #52344
  • Las copias de MimeMappings de DEFAULT están vacías y el igual es asimétrico #52342
  • StringHttpMessageConverter no se puede anular con un personalizador de convertidores de mensajes HTTP #52336
  • ConfigurationPropertyName acepta incorrectamente un corchete de apertura al final de un nombre #52334
  • Los directorios creados por el extracto de herramientas jarmode hacen que las capas Docker no sean reproducibles #52330
  • Las propiedades de actualización del clúster de lechuga se ignoran cuando el clúster no está configurado usando las propiedades spring.data.redis.cluster #52328
  • BasicJsonParser maneja mal las llaves dentro de los valores de cadena #52326
  • MessageSourceMessageInterpolator maneja mal las llaves de cierre desequilibradas #52324
  • BasicJsonParser no ignora los espacios en blanco alrededor de los elementos de una lista #52318
  • ZipContent no maneja nombres de directorios anidados con caracteres de varios bytes #52315
  • RabbitMQ AMQP 1.0 no debería establecer un intercambio vacío de forma predeterminada #52305
  • spring.data.redis.database se ignora al configurar nodos maestros/réplica #52189

:notebook_with_decorative_cover: Documentación

  • Documentar cómo personalizar la ejecución del reempaquetado principal y la clase principal del padre inicial #52556
  • Se corrigieron errores tipográficos y referencias rotas en la documentación gRPC #52543
  • La tabla de ReactiveHealthIndicators configurados automáticamente no incluye el indicador R2DBC #52424
  • Faltan metadatos para algunas propiedades habilitadas para indicadores de estado #52422
  • Documento que prueba clients no se observan #52418
  • Se corrigieron sugerencias de metadatos de configuración obsoletos #52386
  • Se corrigió la referencia externa rota en la documentación de prueba #52384

spring-boot v4.2.0-RC2

:star: New Features

  • Remove LDAP SSL reload support #52365
  • Add support for X-Forwarded-Prefix with Reactor Netty #52316

:lady_beetle: Bug Fixes

  • Setting management.observations.conventions to open-telemetry enables neither semantic convention #52619
  • PushGatewayTaskScheduler does not correctly shutdown task scheduler when context is closed #52591
  • ClearCachesApplicationListener does not find inherited clearCache() methods #52589
  • MongoTransactionManager created by BatchDataMongoAutoConfiguration is not customized by TransactionManagerCustomizers #52572
  • Configuration processor does not handle known types when they are fully-qualified #52571
  • Invalid AMQP Rabbit host is reported with the wrong value #52568
  • Avoid premature overflow when converting durations to microseconds #52561
  • Binding a value from a config tree fails after a collection of the same element type has been bound from the same config tree #52559
  • JsonWriter writes invalid JSON when usingPairs is used with a named member #52549
  • Logback GELF structured logging writes a null short_message when the log message is null #52547
  • Auto-configured KafkaTransactionManager is not customized by TransactionManagerCustomizers #52542
  • Custom layers in the Gradle plugin include excluded content instead of excluding it #52540
  • RabbitMQ addresses without a port use the AMQP port when SSL is enabled #52538
  • BasicJsonParser does not decode \b, \f, \n, \r, \t and \uXXXX escape sequences #52534
  • NestedJarFile.getComment() fails with an EOFException when the jar has no comment #52513
  • Plain text thread dump reports threads in Object.wait() as parking on Java 19+ #52511
  • When using both spring-boot-amqp-rabbitmq and spring-boot-rabbitmq health information from the latter is lost #52506
  • JSON parse failures no longer produce DockerOutputParseExceptions #52500
  • ECS structured logging writes empty service and service.node objects #52497
  • ConfigurationMetadataAnnotationProcessor produces non-repeatable output if multiple endpoints share the same ID #52494
  • Graceful shutdown does not wait for active requests after a restart of Tomcat or Jetty #52490
  • RabbitMQ uses the wrong port by default when an SSL bundle is configured #52488
  • Auto-configured R2dbcTransactionManager is not customized by TransactionManagerCustomizers #52485
  • JsonWriter writes NaN and infinite values as invalid JSON #52483
  • ZipEndOfCentralDirectoryRecord finds the record signature inside the zip comment #52481
  • LLdap Docker Compose support fails to connect when LLDAP_LDAP_USER_DN is configured #52475
  • ZipContent.Entry hasNameStartingWith ignores the offset of virtualized nested directory names #52464
  • ZipContent cannot open a zip with data after the end of central directory record #52461
  • ZipContent reads the zip comment from the wrong position when the archive has prefixed data #52459
  • Root logger configuration cannot be retrieved and has no configured level with Log4j2 #52455
  • Docker Compose OTLP integration requires gRPC and HTTP ports to be exposed when only HTTP is used #52451
  • Spring Batch JDBC auto-configuration connects to the database on startup to detect its type, with no way to configure it #52449
  • OnAvailableEndpointCondition caches retain closed application contexts through their Environment #52447
  • DataSourceTransactionManagerAutoConfiguration uses an old and no-longer-supported property to control exception translation #52445
  • Tomcat's new 'maxLocaleCount' property cannot be easily configured #52443
  • DevTools leaks a File Watcher thread for every failed restart #52441
  • SSL bundle ciphers and enabled protocols are sometimes silently ignored when the underlying component does not support their configuration #52438
  • AMQP 1.0 should not set any credential to use ANONYMOUS by default #52435
  • Default RabbitMQ AMQP 1.0 port to 5671 when an SSL bundle is configured #52432
  • Hikari does not register its own MBeans when lazy connection fetching is used with JMX enabled #52426
  • SSL bundle ciphers and enabled protocols are ignored by RabbitMQ clients #52416
  • SSL bundle ciphers and enabled protocols are ignored by Kafka clients #52413
  • Health endpoint fails with an internal error for a path with an unknown intermediate segment #52411
  • Servlet application fails to start when both JWT and opaque token resource server properties are configured #52409
  • Runners can be invoked after the application context has closed during startup #52408
  • Binding @ConfigurationProperties beans concurrently can corrupt BoundConfigurationProperties and fail the bind #52406
  • Auto-configured JavaMailSender does not apply SSL bundle ciphers or enabled protocols #52404
  • Class path root cannot be resolved in executable jars after #52246 #52402
  • Kotlin Serialization does not back off when JSON-B is the only JSON converter #52389
  • Matrix parameters distort the values passed to a match all remaining selector when using WebMvc or WebFlux #52378
  • Server name SSL bundles with upper-case server names are not used with Netty #52364
  • Config data locations with brackets in their path are not loaded correctly #52360
  • Closing the context can hang when Hikari pool suspension is enabled #52359
  • OriginTrackedPropertiesLoader drops the line following a comment that ends with a backslash #52357
  • Closing a child context stops the keep-alive thread #52344
  • MimeMappings copies of DEFAULT are empty and equals is asymmetric #52342
  • StringHttpMessageConverter cannot be overridden with an HTTP message converters customizer #52336
  • ConfigurationPropertyName incorrectly accepts an opening square bracket at the end of a name #52334
  • Directories created by jarmode tools extract make Docker layers non-reproducible #52330
  • Lettuce cluster refresh properties are ignored when the cluster is not configured using spring.data.redis.cluster properties #52328
  • BasicJsonParser mishandles braces within string values #52326
  • MessageSourceMessageInterpolator mishandles unbalanced closing braces #52324
  • BasicJsonParser does not ignore whitespace around the elements of a list #52318
  • ZipContent does not handle nested directory names with multi-byte characters #52315
  • RabbitMQ AMQP 1.0 should not set an empty exchange by default #52305
  • spring.data.redis.database is ignored when configuring master/replica nodes #52189

:notebook_with_decorative_cover: Documentation

  • Document how to customize the starter parent's repackage execution and main class #52556
  • Fix typos and broken references in gRPC documentation #52543
  • Table of auto-configured ReactiveHealthIndicators does not list the R2DBC indicator #52424
  • Metadata for some health indicator enabled properties is missing #52422
  • Document that test clients are not observed #52418
  • Fix stale configuration metadata hints #52386
  • Fix broken xref in testing documentation #52384

:hammer: Dependency Upgrades

  • Upgrade to ActiveMQ 6.3.3 #52594
  • Upgrade to AspectJ 1.9.27 #52595
  • Upgrade to Byte Buddy 1.18.17 #52596
  • Upgrade to Hibernate 7.4.14.Final #52597
  • Upgrade to Hibernate Validator 9.1.6.Final #52598
  • Upgrade to Infinispan 16.3.1 #52599
  • Upgrade to Jackson 2 Bom 2.21.8 #52600
  • Upgrade to Jackson Bom 3.1.8 #52601
  • Upgrade to Json-smart 2.6.1 #52602
  • Upgrade to Logback 1.6.6 #52603
  • Upgrade to MariaDB 3.5.11 #52604
  • Upgrade to Maven Failsafe Plugin 3.6.1 #52605
  • Upgrade to Maven Surefire Plugin 3.6.1 #52606
  • Upgrade to Micrometer 1.18.0-RC2 #52501
  • Upgrade to Micrometer Tracing 1.8.0-RC2 #52502
  • Upgrade to MSSQL JDBC 13.6.2.jre11 #52607
  • Upgrade to MySQL 26.10.0 #52608
  • Upgrade to Native Build Tools Plugin 1.1.18 #52609
  • Upgrade to Netty 4.2.20.Final #52610
  • Upgrade to Oracle Database 23.26.4.0.0 #52611
  • Upgrade to Pooled JMS 3.2.6 #52613
  • Upgrade to Protobuf Maven Plugin 5.1.12 #52612
  • Upgrade to Spring Framework 7.1.0-RC2 #52503
  • Upgrade to UnboundID LDAPSDK 7.0.6 #52614
