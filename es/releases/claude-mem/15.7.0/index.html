claude-mem v15.7.0

Mi trabajo: la actualización permanece en su agente y un botón de comentarios (#5190)

Cuando la actualización automática de Mi trabajo obtuvo una respuesta de Claude Code que claude-mem rechazó (la mayoría de las veces una revisión de más de 1200 caracteres), toda la actualización pasó al siguiente agente que inició sesión. En máquinas con Codex instalado, eso significaba ejecuciones efímeras de codex exec ocultas en la cuenta ChatGPT del propietario, incluso con CLAUDE_MEM_PROVIDER=claude (#5189: alrededor de 230 ejecuciones en cuatro días).

  • Una respuesta rechazada ahora finaliza la actualización del agente que la dio. La siguiente ejecución programada intenta nuevamente con el mismo agente, con el retraso del error existente. Un agente que no puede ejecutar nada (no ha iniciado sesión, falló) aún así le pasa la ejecución al siguiente.
  • Botón de comentarios en el encabezado Mi trabajo, junto a Estrella. Abre un breve formulario de incidencias "Comentarios de mi trabajo".

Quien toma notas siempre usa el Haiku más nuevo (#5195)

El modelo predeterminado de quien toma notas ahora es el alias de haiku de Claude Code, que siempre se resuelve en el Haiku más nuevo, en lugar de un ID de Haiku 4.5 fijado. Las configuraciones guardadas que aún llevan el ID fijado enviado se mueven al alias en la actualización. Un modelo que usted mismo escribió se deja solo. CLAUDE.md del repositorio ahora establece esto como política: nunca fije una ID de modelo fechada como predeterminada.

Mi Trabajo y el trabajador

  • Las reconstrucciones en segundo plano de Mi trabajo basadas en actividades se fusionan, por lo que una página Mi trabajo abierta ya no se reconstruye en cada confirmación de la base de datos (#5133, mitiga #5124).
  • La vista de trabajo espera a que la base de datos termine de iniciarse antes de compilarse (#5157).
  • El estado de procesamiento del espectador se concilia después de un intervalo de transmisión (#5139).
  • Se eliminan los registros diarios de trabajadores anteriores a CLAUDE_MEM_LOG_RETENTION_DAYS (el valor predeterminado es 30, 0 se mantiene para siempre). Los archivos de hoy y de ayer siempre se conservan (#5186).

Proyectos

  • Los entornos con nombre dentro de un repositorio Git principal pueden declarar herencia explícita, por lo que la memoria principal no relacionada ya no se filtra a su contexto (#5022).
  • Oh My Pi mantiene la memoria transitoria del proyecto en el contexto del modelo (#5183).
  • Claude Duet: captura y recuperación (#5188).

Medios (desactivado de forma predeterminada)

  • Primera fase de observaciones con reconocimiento de imágenes: contratos de medios acotados y un conversor perezoso Sharp 0.35.5 con límites de tamaño, píxeles y fecha límite. CLAUDE_MEM_MEDIA_CAPTURE_ENABLED y CLAUDE_MEM_MEDIA_INFERENCE_ENABLED tienen el valor predeterminado falso (#4341).

Seguridad

  • El descubrimiento de ejecutables nunca busca en el directorio actual (#5148).
  • Las URL del instalador son https y Bun se ejecuta desde un directorio controlado por el propietario (#5149).
  • El trabajador rechaza las escrituras del navegador entre orígenes en los puntos finales de la sesión y en POST /api/memory/ingest (#5162, #5161).
  • Las claves API de Postgres se almacenan como hashes scrypt salados (n.° 5160) y se respetan todos los modos ssl de Postgres (n.° 5152).
  • Las escrituras atómicas utilizan nombres temporales aleatorios de creación exclusiva (#5151).
  • Las etiquetas privadas se eliminan antes que las mayúsculas y se cierra el último turno de Hermes (#5150).
  • La redacción ahora cubre GitLab, Hugging Face y tokens npm (#5174), contraseñas en las credenciales de URL (#5173) y texto de sincronización entrante cuando la redacción local está activada (#5171).

Correcciones

  • La entrada estándar del gancho se enmarca cuando se completa, sin esperar el EOF (#5126).
  • El EPIPE de una sesión cerrada ya no se registra como fatal (#5177).
  • Se explican los rechazos de la zona de pruebas de Windows Codex (#5140).
  • El proveedor compatible con OpenAI lee el estado HTTP de un sobre de error 200 con un código de texto (#5191).
  • SessionStart cuenta el bloque de uso de memoria en su presupuesto sin TeamBrain (#5181).
  • Se expande un ~ inicial en CLAUDE_MEM_DATA_DIR (#5179).
  • Las colas de registro leen sólo líneas completas (#5166).
  • El respaldo de Chroma filtrado se reduce a los ID de fila de SQLite (#5154). changelog completo: https://github.com/thedotmack/claude-mem/compare/v15.6.0...v15.7.0

claude-mem v15.7.0

My Work: refresh stays on your agent, and a Feedback button (#5190)

When My Work's automatic refresh got an answer from Claude Code that claude-mem refused (most often a review over 1,200 characters), the whole refresh moved on to the next logged-in agent. On machines with Codex installed, that meant hidden codex exec --ephemeral runs on the owner's ChatGPT account, even with CLAUDE_MEM_PROVIDER=claude (#5189: about 230 runs in four days).

  • A refused answer now ends that refresh on the agent that gave it. The next scheduled run tries the same agent again, with the existing failure backoff. An agent that can't run at all (not signed in, crashed) still hands the run to the next one.
  • Feedback button in the My Work header, next to Star. It opens a short "My Work feedback" issue form.

Note-taker always uses the newest Haiku (#5195)

The note-taker's default model is now Claude Code's haiku alias, which always resolves to the newest Haiku, instead of a pinned Haiku 4.5 ID. Saved settings that still carry the shipped pinned ID move to the alias on upgrade. A model you typed yourself is left alone. The repo's CLAUDE.md now states this as policy: never pin a dated model ID as a default.

My Work and the worker

  • Activity-driven background rebuilds of My Work are coalesced, so an open My Work page no longer rebuilds on every database commit (#5133, mitigates #5124).
  • Work View waits for the database to finish starting before it builds (#5157).
  • The viewer's processing status reconciles after a stream gap (#5139).
  • Daily worker logs older than CLAUDE_MEM_LOG_RETENTION_DAYS (default 30, 0 keeps forever) are pruned. Today's and yesterday's files are always kept (#5186).

Projects

  • Named environments inside a parent Git repository can declare explicit inheritance, so unrelated parent memory no longer leaks into their context (#5022).
  • Oh My Pi keeps transient project memory in model context (#5183).
  • Claude Duet: capture and recall (#5188).

Media (off by default)

  • First phase of image-aware observations: bounded media contracts and a lazy Sharp 0.35.5 converter with size, pixel and deadline limits. CLAUDE_MEM_MEDIA_CAPTURE_ENABLED and CLAUDE_MEM_MEDIA_INFERENCE_ENABLED both default to false (#4341).

Security

  • Executable discovery never looks in the current directory (#5148).
  • Installer URLs are https, and Bun runs from an owner-controlled directory (#5149).
  • The worker rejects cross-origin browser writes to session endpoints and to POST /api/memory/ingest (#5162, #5161).
  • Postgres API keys are stored as salted scrypt hashes (#5160), and every Postgres sslmode is honored (#5152).
  • Atomic writes use exclusive-create random temp names (#5151).
  • Private tags are stripped before caps, and Hermes' last turn is gated (#5150).
  • Redaction now covers GitLab, Hugging Face and npm tokens (#5174), passwords in URL credentials (#5173), and inbound sync text when local redaction is on (#5171).

Fixes

  • Hook stdin is framed when complete, without waiting for EOF (#5126).
  • A closed session's EPIPE is no longer logged as fatal (#5177).
  • Windows Codex sandbox refusals are explained (#5140).
  • The OpenAI-compatible provider reads the HTTP status from a 200 error envelope with a textual code (#5191).
  • SessionStart counts the memory-use block in its budget without TeamBrain (#5181).
  • A leading ~ in CLAUDE_MEM_DATA_DIR is expanded (#5179).
  • Log tails read only complete lines (#5166).
  • The filtered Chroma fallback narrows to SQLite row ids (#5154).

Full changelog: https://github.com/thedotmack/claude-mem/compare/v15.6.0...v15.7.0
