claude-mem v15.16.0

Nuevo

  • Actualización de Mi trabajo en su proveedor API (optar): configure CLAUDE_MEM_WORK_VIEW_AGENT=api para ejecutar la actualización de Mi trabajo en el proveedor que ya seleccionó (openrouter, openai-compatible o la ortografía heredada cmem). Las instalaciones sin Claude Code, Codex o Gemini CLI (por ejemplo, hosts OpenCode o DSH) ahora pueden usar My Work. Con un proveedor API seleccionado y la configuración vacía, la actualización ya no recurre a un Claude Code que haya iniciado sesión: no se ejecuta ningún agente y no se gasta nada hasta que elija uno (#5674, gracias @bulanovk).
  • Solicitudes de extracción de MCP GitHub en Mi trabajo: las solicitudes de extracción creadas a través de la herramienta oficial MCP create_pull_request de GitHub ahora aparecen como productos de Mi trabajo. Solo se aceptan resultados completos cuya URL coincida con el repositorio solicitado (#5809, gracias @Afloat16).
  • Preajuste de UberLLM: uberllm ahora es un ajuste preestablecido del proveedor openai-compatible (https://api.uberllm.dev/v1, modelo predeterminado deepseek/deepseek-v4.1-flash) (#5706, gracias @PSA-Team-source).
  • Tiempo de espera de transferencia en vivo ajustable: CLAUDE_MEM_HOOK_HANDOFF_TIMEOUT_MS (predeterminado 250) establece el presupuesto para la transferencia en vivo única desde un gancho al trabajador, y una transferencia perdida ahora se registra en WARN en lugar de DEBUG (#5831, gracias @mohitdixit02).

Correcciones notables

  • Limpieza de caché del complemento: el trabajador ahora elimina las carpetas de versiones antiguas que las actualizaciones del mercado de Claude Code dejan en ~/.claude/plugins/cache/thedotmack/claude-mem/ (un informe: 21 versiones, aproximadamente 16 GB). Mantiene la copia en ejecución y la versión registrada, y realiza un barrido después de que se establece el arranque y luego cada hora (#5685, gracias @MaxWang007).
  • Ruido del antivirus de Windows: la instalación, actualización y reconstrucción del iniciador ya no inician un PowerShell oculto cuando la carpeta del iniciador ya está en PATH, el patrón que Kaspersky marcó (#5835, informado por @Ali-Sabri-0).
  • Mi idioma de trabajo: cuando CLAUDE_MEM_WORK_VIEW_TEXT_LANGUAGE está vacío, cada paso de actualización ahora escribe en el idioma de la configuración regional del sistema, por lo que una ejecución ya no mezcla idiomas (#5669, gracias @0xABCD01).
  • Costo de inactividad de Mi trabajo: el sondeo inactivo ya no vuelve a escanear cada fila sincronizada, y la descripción general en vivo, la combinación de áreas de enfoque y los paneles pesados ​​realizan menos trabajo por actualización (#5834).
  • Copias de seguridad: una ejecución de copia de seguridad declined devuelve un error, las copias de seguridad guardadas se informan por separado de los errores de retención, se respetan los intervalos de copia de seguridad más allá del límite del temporizador y la restauración rechaza las instantáneas estampadas que faltan en las tablas de trabajadores (#5750, #5781, #5784, #5684, gracias @Kirat0201).
  • Configuración de Shell: el bloque PATH del iniciador y el alias de desinstalación heredado se escriben de forma atómica, Cowork organiza eventos en spool bajo $HOME cuando el host lo configura y Hermes mantiene los errores HTTP permanentes client fuera de su disyuntor (#5680, #5679, #5677, #5678, gracias @DeryFerd).
  • OpenCode: la herramienta bash se informa como Bash, por lo que se aplica SKIP_BASH_PATTERNS (#5668, gracias @ryrenz).
  • Sincronización: una limpieza de Chroma fallida después de reintentar una eliminación (#5673, gracias @Zhong-fan).
  • Inicio de sesión: los pasos de lectura y redacción de caché comparten un presupuesto de cuerpo, por lo que un cuerpo almacenado en caché se sirve solo cuando cabe (#5686, gracias @Varshith-Kali).

Más correcciones

Aproximadamente 130 correcciones más pequeñas de @Afloat16 en captura, sincronización, búsqueda, contexto, importación, transcripciones, medios, el servidor y las integraciones de Codex, OpenCode, OpenClaw, Hermes, Grok, Kimi, Gemini, Pi, Goose, Notion y Telegram. Reflejos:

  • Búsqueda y contexto: las claves literales del proyecto y las rutas de archivo se conservan mediante recuperación, fusión y almacenamiento en caché; Unicode y las marcas de combinación sobreviven a las palabras de consulta y a los límites de fragmentos; el contexto almacenado en caché caduca después de las restauraciones y reemplazos de filas; Se mantiene el prefijo de línea de tiempo más adecuado.
  • Sincronización y memoria: los títulos de las sesiones se confirman con su mutación de la bandeja de salida y se redactan en el receptor; los guardados manuales y las nuevas indicaciones funcionan después de eliminar una sesión; las revisiones de notas sobreviven a la desduplicación del título.
  • Transcripciones e importación: los mensajes del Codex de varias partes, los resultados de los parches emparejados y las costuras del marco zstd se leen correctamente; el razonamiento queda fuera de las respuestas finales; OpenCode, Gemini y resúmenes restaurados se importan sin duplicados ni mensajes perdidos.
  • Servidor y proveedores: La derivación de clave API permanece fuera del ciclo de solicitud; las cancelaciones se propagan mediante reintentos y compresión; el uso de tokens divididos se mide según las respuestas compatibles; El contenido de la memoria se desinfecta antes del almacenamiento.
  • Medios: se conservan los ordinales de las imágenes, la evidencia de lectura en la ortografía de las rutas y los límites de dimensiones de las imágenes anunciadas; La asignación en línea se cobra solo por las imágenes aceptadas.

También de @ Kirat0201: el historial de archivos sigue las fusiones de proyectos completos, la búsqueda interactiva en la línea de tiempo honra las listas de proyectos y la búsqueda unificada mantiene los valores literales filePath (#5789, #5787, #5785).

claude-mem v15.16.0

New

  • My Work refresh on your API provider (opt-in): set CLAUDE_MEM_WORK_VIEW_AGENT=api to run the My Work refresh on the provider you already selected (openrouter, openai-compatible, or the legacy cmem spelling). Installs with no logged-in Claude Code, Codex or Gemini CLI (for example OpenCode or DSH hosts) can now use My Work. With an API provider selected and the setting empty, the refresh no longer falls back to a logged-in Claude Code: no agent runs and nothing is spent until you choose one (#5674, thanks @bulanovk).
  • GitHub MCP pull requests in My Work: pull requests created through GitHub's official MCP create_pull_request tool now show up as My Work products. Only completed results whose URL matches the requested repository are accepted (#5809, thanks @Afloat16).
  • UberLLM preset: uberllm is now a preset of the openai-compatible provider (https://api.uberllm.dev/v1, default model deepseek/deepseek-v4.1-flash) (#5706, thanks @PSA-Team-source).
  • Tunable live handoff timeout: CLAUDE_MEM_HOOK_HANDOFF_TIMEOUT_MS (default 250) sets the budget for the single live handoff from a hook to the worker, and a missed handoff is now logged at WARN instead of DEBUG (#5831, thanks @mohitdixit02).

Notable fixes

  • Plugin cache cleanup: the worker now prunes old version folders that Claude Code's marketplace updates leave in ~/.claude/plugins/cache/thedotmack/claude-mem/ (one report: 21 versions, about 16 GB). It keeps the running copy and the registered version, and sweeps after boot settles and then hourly (#5685, thanks @MaxWang007).
  • Windows antivirus noise: install, update and launcher rebuilds no longer start a hidden PowerShell when the launcher folder is already on PATH, the pattern Kaspersky flagged (#5835, reported by @Ali-Sabri-0).
  • My Work language: when CLAUDE_MEM_WORK_VIEW_TEXT_LANGUAGE is empty, every refresh step now writes in the system locale's language, so one run no longer mixes languages (#5669, thanks @0xABCD01).
  • My Work idle cost: idle polling no longer rescans every synced row, and the live overview, focus-area merging and heavy panels do less work per update (#5834).
  • Backups: a declined backup run returns a failure, saved backups are reported separately from retention errors, backup intervals beyond the timer limit are honored, and restore rejects stamped snapshots missing worker tables (#5750, #5781, #5784, #5684, thanks @Kirat0201).
  • Shell setup: the launcher PATH block and the legacy uninstall alias are written atomically, Cowork stages spooled events under $HOME when the host sets it, and Hermes keeps permanent HTTP client errors out of its circuit breaker (#5680, #5679, #5677, #5678, thanks @DeryFerd).
  • OpenCode: the bash tool is reported as Bash, so SKIP_BASH_PATTERNS applies (#5668, thanks @ryrenz).
  • Sync: a failed Chroma cleanup after a delete is retried (#5673, thanks @Zhong-fan).
  • SessionStart: the cache read and compose steps share one body budget, so a cached body is served only when it fits (#5686, thanks @Varshith-Kali).

More fixes

About 130 smaller fixes from @Afloat16 across capture, sync, search, context, import, transcripts, media, the server, and the Codex, OpenCode, OpenClaw, Hermes, Grok, Kimi, Gemini, Pi, Goose, Notion and Telegram integrations. Highlights:

  • Search and context: literal project keys and file paths are preserved through recall, merges and caching; Unicode and combining marks survive query words and snippet limits; cached context expires after restores and row replacements; the largest fitting timeline prefix is kept.
  • Sync and memory: session titles commit with their outbox mutation and get receiver redaction; manual saves and new prompts work after a session deletion; note revisions survive title dedup.
  • Transcripts and import: multipart Codex messages, paired patch results and zstd frame seams are read correctly; reasoning stays out of final answers; OpenCode, Gemini and restored summaries import without duplicates or lost prompts.
  • Server and providers: API key derivation stays off the request loop; cancellations propagate through retries and compression; split token usage is metered on compatible replies; memory content is sanitized before storage.
  • Media: image ordinals, Read evidence across path spellings, and advertised image dimension bounds are preserved; inline allowance is charged only for accepted images.

Also from @Kirat0201: file history follows whole project merges, interactive timeline search honors project lists, and unified search keeps literal filePath values (#5789, #5787, #5785).
