claude-mem v15.13.0

Solución crítica

  • Resúmenes del cursor: Las sesiones del cursor no obtuvieron ningún resumen en Windows nativo, o cuando la ruta del espacio de trabajo tenía un _, un espacio o una carpeta de puntos. claude-mem ahora busca la transcripción en la carpeta del proyecto Nombres reales del cursor, por lo que esas sesiones obtienen resúmenes nuevamente (#5544, gracias @tanishqbaweja; el mismo síntoma fue informado por primera vez en #2248 por @wbingli).

Nuevo

  • Borrado automático al 33% del contexto (desactivado de forma predeterminada): actívalo con CLAUDE_MEM_AUTO_CLEAR_ENABLED=true. Cuando una conversación de Claude Code llega a un tercio de la ventana de contexto, Claude guarda su estado de trabajo, claude-mem ejecuta /clear y envía continue, y la nueva conversación retoma el trabajo. No guardar significa no borrar (#5486).
  • Preajuste de Computación estándar para el proveedor compatible con openai (#5492, gracias @henrikdukefoss).
  • PopNow preestablecido para el proveedor compatible con openai (#5434, gracias @kyuminjo).

Correcciones

  • Chroma: eliminar muchas observaciones a la vez ya no acumula limpiezas que bloquean chroma-mcp durante horas; ahora se ejecutan uno a la vez (#5496, gracias @xunguangzlj-cloud; reportado en #5495 por @voyvodka).
  • CLI: claude-mem --help, -h y un comando mal escrito imprimen el uso en lugar de iniciar un trabajador en primer plano (#5491, gracias @ryrenz; informado en #5490 por @ukdataservices-admin).
  • CLI: --flag=value funciona en server api-key, memory ingest y adopt, por lo que --scope=memories:read realmente es una clave de solo lectura (#5469, gracias @rudycelekli).
  • Doctor: npx claude-mem doctor ya no falla al salir de Windows (#5465, gracias @tng7576650-commits).
  • Inicio de sesión en CMEM Pro: cuando cmem.ai rechaza el inicio de sesión sin un mensaje, el instalador muestra el estado HTTP en lugar de un consejo de conectividad (#5498, gracias @xunguangzlj-cloud).
  • Redacción: las claves de proveedor impresas al inicio de una línea en la salida de la herramienta ahora están redactadas (#5521).
  • Cowork: la corrección de Cowork redacta las claves de NVIDIA, Runcrate, Groq, xAI y Perplexity que el trabajador ya redacta (#5483, gracias @DeryFerd).
  • Windsurf: el instalador escribe hooks.json y el archivo de reglas de forma atómica, por lo que una instalación interrumpida no puede dejar a Windsurf con un archivo de ganchos roto (#5542, gracias @DeryFerd).
  • Servidor: los puntos finales del feed del visor vincularon el offset a un client que puede enviar (#5485, gracias @DeryFerd).
  • Instalar: Los archivos de configuración OpenCode, Kimi y Antigravity guardados con una lista de materiales UTF-8 se leen correctamente (#5472, gracias @rudycelekli).
  • Lanzador: un ~ al inicio de CLAUDE_MEM_DATA_DIR se expande cuando se graba una carga útil de gancho vacía, en lugar de crear una carpeta ~ en el proyecto (#5473, gracias @rudycelekli).
  • Importar: volver a importar una exportación mantiene las fusiones de proyectos (merged_into_project) (#5471, gracias @rudycelekli).
  • DSH: las memorias de herramientas ingeridas mantienen el platformSource configurado (#5470, gracias @rudycelekli).
  • CLAUDE.md: en un monorepo, las filas de la carpeta CLAUDE.md están encabezadas con un archivo que está en esa carpeta (#5468, gracias @rudycelekli).
  • Mi trabajo: las confirmaciones realizadas con git commit -m "$(cat <<'EOF' ...)" y cada formato de título de gh pr se leen correctamente (#5480, gracias @rudycelekli).
  • Búsqueda: los filtros de archivos coinciden si las rutas usan / o \ (#5466, gracias @liuyinchu).
  • Hermes: los puntos finales con formato incorrecto y las respuestas truncadas retroceden limpiamente, las sesiones finalizan incluso cuando falla el evento final y la recuperación en mensajes largos se detiene en el límite de consultas (#5462, gracias @Afloat16).

claude-mem v15.13.0

Critical fix

  • Cursor summaries: Cursor sessions got no summary on native Windows, or when the workspace path had a _, a space or a dot folder in it. claude-mem now looks for the transcript in the project folder Cursor actually names, so those sessions get summaries again (#5544, thanks @tanishqbaweja; the same symptom was first reported in #2248 by @wbingli).

New

  • Auto-clear at 33% context (off by default): turn it on with CLAUDE_MEM_AUTO_CLEAR_ENABLED=true. When a Claude Code conversation reaches a third of the context window, Claude saves its work state, claude-mem runs /clear and sends continue, and the fresh conversation picks the work back up. No save means no clear (#5486).
  • Standard Compute preset for the openai-compatible provider (#5492, thanks @henrikdukefoss).
  • PopNow preset for the openai-compatible provider (#5434, thanks @kyuminjo).

Fixes

  • Chroma: deleting many observations at once no longer piles up cleanups that lock chroma-mcp for hours; they now run one at a time (#5496, thanks @xunguangzlj-cloud; reported in #5495 by @voyvodka).
  • CLI: claude-mem --help, -h and a mistyped command print usage instead of starting a foreground worker (#5491, thanks @ryrenz; reported in #5490 by @ukdataservices-admin).
  • CLI: --flag=value works in server api-key, memory ingest and adopt, so --scope=memories:read really makes a read-only key (#5469, thanks @rudycelekli).
  • Doctor: npx claude-mem doctor no longer crashes at exit on Windows (#5465, thanks @tng7576650-commits).
  • CMEM Pro sign-in: when cmem.ai refuses a sign-in start without a message, the installer shows the HTTP status instead of connectivity advice (#5498, thanks @xunguangzlj-cloud).
  • Redaction: vendor keys printed at the start of a line in tool output are now redacted (#5521).
  • Cowork: the Cowork shim redacts the NVIDIA, Runcrate, Groq, xAI and Perplexity keys the worker already redacts (#5483, thanks @DeryFerd).
  • Windsurf: the installer writes hooks.json and the rules file atomically, so an interrupted install can't leave Windsurf with a broken hooks file (#5542, thanks @DeryFerd).
  • Server: the viewer feed endpoints bound the offset a client can send (#5485, thanks @DeryFerd).
  • Install: OpenCode, Kimi and Antigravity config files saved with a UTF-8 BOM are read correctly (#5472, thanks @rudycelekli).
  • Launcher: a ~ at the start of CLAUDE_MEM_DATA_DIR is expanded when recording an empty hook payload, instead of creating a ~ folder in the project (#5473, thanks @rudycelekli).
  • Import: re-importing an export keeps project merges (merged_into_project) (#5471, thanks @rudycelekli).
  • DSH: ingested tool memories keep the configured platformSource (#5470, thanks @rudycelekli).
  • CLAUDE.md: in a monorepo, folder CLAUDE.md rows are headed with a file that is in that folder (#5468, thanks @rudycelekli).
  • My Work: commits made with git commit -m "$(cat <<'EOF' ...)" and every gh pr title form are read correctly (#5480, thanks @rudycelekli).
  • Search: file filters match whether paths use / or \ (#5466, thanks @liuyinchu).
  • Hermes: malformed endpoints and truncated responses fall back cleanly, sessions end even when the final event fails, and recall on long prompts stops at the query limit (#5462, thanks @Afloat16).

Full changelog: https://github.com/thedotmack/claude-mem/compare/v15.12.1...v15.13.0
