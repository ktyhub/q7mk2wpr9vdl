#pymilvus v2.6.16

¿Qué ha cambiado?

Funciones y mejoras

  • Agregar soporte de búsqueda a nivel de elemento (fuente #3208; 2.6 #3491).
  • Agregue soporte dump_messages para recuperación de datos (fuente #3573; 2.6 #3574).
  • Agregar compatibilidad con funciones y descripciones de usuarios en la autenticación API (fuentes #3601 y #3602; 2.6 #3609).
  • Mejorar la interacción de carga de volumen, incluido el comportamiento de simultaneidad y progreso (fuente #3619; 2.6 #3628).

Corrección de errores

  • Fortalecer la sincronización y la recuperación de conexiones asíncronas protegiendo los intercambios de canales de reconexión y validando la recuperación de canales (fuentes #3542, #3564 y #3579; 2.6 #3566, #3571 y #3582).
  • Preservar la configuración del tiempo de espera de la conexión durante la recuperación (fuente #3610; 2.6 #3614).
  • Asigne solo fallas RPC de configuración de conexión a CONNECT_FAILED (fuente #3589; 2.6 #3591).
  • Rechazar valores booleanos en validación de vectores dispersos y mejorar el mensaje de error relacionado (fuente #3624; 2.6 #3625).

Manejo de tipos y partes internas de client

  • Continuar con la migración del modelo de tipo lógico a través de ayudas de matriz, inserción y extracción de filas, resultados de datos de campo y decodificadores anidados, predicados vectoriales y datos de tipo de matriz vectorial (fuentes #3518, #3501, #3536, #3537, #3554, #3604 y #3606; 2.6 #3549, #3551, #3553, #3556, #3558, #3607 y #3612).
  • Retire el extractor de fila muerto V1 (fuente #3561; 2.6 #3563).

Documentación y pruebas

  • Actualización de ejemplos asíncronos de client (fuente #3597; 2.6 #3598).
  • Clasificar conjuntos de pruebas mantenidos (fuente #3592; 2.6 #3596). Changelog completo: https://github.com/milvus-io/pymilvus/compare/v2.6.15...v2.6.16

pymilvus v2.6.16

What's Changed

Features and enhancements

  • Add element-level search support (source #3208; 2.6 #3491).
  • Add dump_messages support for data salvage (source #3573; 2.6 #3574).
  • Add role and user description support in auth APIs (sources #3601 and #3602; 2.6 #3609).
  • Improve volume upload interaction, including concurrency and progress behavior (source #3619; 2.6 #3628).

Bug fixes

  • Harden sync and async connection recovery by protecting reconnect channel swaps and validating channel reclamation (sources #3542, #3564, and #3579; 2.6 #3566, #3571, and #3582).
  • Preserve connection timeout settings during recovery (source #3610; 2.6 #3614).
  • Map only connection-setup RPC failures to CONNECT_FAILED (source #3589; 2.6 #3591).
  • Reject boolean values in sparse vector validation and improve the related error message (source #3624; 2.6 #3625).

Type handling and client internals

  • Continue the logical type model migration across array helpers, row insert and extraction, field-data result and nested decoders, vector predicates, and vector-array dtype facts (sources #3518, #3501, #3536, #3537, #3554, #3604, and #3606; 2.6 #3549, #3551, #3553, #3556, #3558, #3607, and #3612).
  • Remove the dead V1 row extractor (source #3561; 2.6 #3563).

Documentation and tests

  • Update async client examples (source #3597; 2.6 #3598).
  • Classify maintained test suites (source #3592; 2.6 #3596).
