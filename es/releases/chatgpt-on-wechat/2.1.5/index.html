🗂 Espacio de trabajo y vista previa de archivos

La página de chat obtiene una vista visual del espacio de trabajo: los documentos, páginas web e imágenes que produce el Agente se pueden obtener una vista previa en el lugar. Tanto la consola web como el escritorio client lo admiten.

  • Navegación del espacio de trabajo: explora los archivos en el directorio del espacio de trabajo desde el panel, con búsqueda y descarga en local.
  • Vista previa de archivos: las páginas HTML, documentos e imágenes se abren directamente en el panel lateral y las rutas de los archivos en una respuesta se representan como tarjetas clickable.
  • Referencias de archivos: arrastre un archivo del espacio de trabajo a la conversación o use @ en el cuadro de entrada para hacer referencia a archivos y directorios y colocarlos en el contexto.

🔧 Mejoras en las herramientas principales

Un paso sistemático por encima de las herramientas de búsqueda, lectura, escritura, edición y shell de archivos, fortaleciendo las capacidades de codificación y manejo de archivos del Agente.

  • Nueva herramienta de búsqueda de archivos: search_files busca en el espacio de trabajo por contenido o por nombre de archivo, respaldado por ripgrep de forma predeterminada, notablemente más rápido en directorios grandes. Gracias @Maaayhan (#2982)
  • Salida de lectura numerada de línea: la salida read ahora siempre lleva números de línea, lo que facilita la localización y cita de líneas específicas.
  • Ediciones más precisas: edit ya no reescribe la sangría circundante en una coincidencia aproximada y ya no aparece en la ocurrencia incorrecta cuando el texto se repite; se agregó reemplazar todo; un archivo modificado fuera del Agente ahora está marcado.
  • Comprobaciones de sintaxis en tiempo de escritura: write / edit validan el formato de los archivos estructurados antes de escribirlos y analizan los archivos de origen para informar los errores de sintaxis al Agente.
  • Comandos en segundo plano: bash puede ejecutar un comando en segundo plano, para trabajos de larga duración, como iniciar un servicio o seguir registros; Se aumentó el tiempo de espera predeterminado para los comandos de primer plano.
  • La cancelación tiene efecto inmediatamente: cliAl detener o ejecutar /cancel finaliza el comando que se está ejecutando actualmente.

🧠 Gestión del contexto

  • Compactación de contexto: el nuevo comando /compact resume y compacta el contexto de la conversación según demanda, lo que reduce de manera efectiva el uso de tokens.
  • Comandos unificados: /clear ahora borra uniformemente el contexto de la sesión actual, con /context clear mantenido como alias.
  • Ventana predeterminada más grande: se aumentó el límite de contexto predeterminado, por lo que las conversaciones largas comienzan a recortarse más tarde.

Documentos: Gestión de contexto

🖥 Escritorio Client

  • Nativo en Mac: se corrigió el instalador de macOS arm64 que llevaba un backend x64, lo que aceleró sustancialmente el proceso principal y la herramienta de navegación en las máquinas Apple Silicon.
  • Canal Feishu agregado: se corrigió el canal Feishu que faltaba en el client. El Feishu SDK ahora es una dependencia recortada (aproximadamente 1 MB) que se descarga bajo demanda la primera vez que se habilita el canal. Gracias @EvanProgramming (#2988)
  • Mensaje de actualización: el cuadro de diálogo de actualización para una versión determinada solo se abre automáticamente una vez.
  • Backend de búsqueda incluido: Windows client viene con ripgrep, por lo que la búsqueda de archivos funciona de inmediato.

🔒 Refuerzo de la seguridad

  • MCP y refuerzo de escritura de archivos: se corrigió una cadena de ataque explotable mediante inyección rápida: el contenido malicioso podría llevar al Agente a reescribir la configuración de MCP y, desde allí, ejecutar comandos arbitrarios y robar claves. Gracias @Correctover (#2968)
  • Protección de archivos de credenciales: se corrigió que la herramienta edit omitiera la protección de credenciales para leer y escribir ~/.cow/.env.

🛠 Mejoras y correcciones

  • bash config respetado: se corrigió que tools.bash.timeout y tools.bash.safety_mode en config.json se ignoraran. Gracias @EvanProgramming (#2986)
  • Ruta del espacio de trabajo de memoria: se corrigió que la ruta del espacio de trabajo se resolviera incorrectamente en la configuración de memoria global. Gracias @Maaayhan (#2992)
  • Protección del historial de conversaciones: reparación automática del índice de memoria fijo que podría borrar el historial de conversaciones junto con él.
  • Eliminación de sesión: se corrigió una respuesta aún en curso que escribía una sesión eliminada nuevamente en la lista.
  • Inicio del navegador: se corrigió el inicio de una instancia duplicada cuando el navegador ya se estaba ejecutando.
  • Resultados precisos de la herramienta: se corrigieron fallas engañosas de varias herramientas: códigos de salida de grep / find considerados incorrectos, secuencias de comandos del navegador reportadas falsamente como errores de sintaxis, rutas de imágenes relativas que no se resuelven, lo que reduce los reintentos inútiles.

chatgpt-on-wechat 2.1.5

Highlights

  • Prompt-injection & credential hardening — The most urgent reason to upgrade: #2968 severs an attack chain where injected content could rewrite the MCP config and pivot into arbitrary command execution and key theft, and the edit tool no longer bypasses protection to read/write ~/.cow/.env. If you run the Agent over untrusted repos or keep secrets in that env file, treat this as a security patch, not a feature release.

  • File/search/edit tool behavior changes — The biggest workflow-level shift. search_files (#2982) adds ripgrep-backed content and filename search over the workspace, and read now always emits line numbers, so citations and follow-up edits are stable. edit gets stricter: no silent re-indentation on fuzzy matches, no wrong-occurrence hits on repeated text, an explicit replace-all, and a flag when a file was modified outside the Agent. Watch out for automation that depended on loose fuzzy edits or on line-number-free read output; foreground bash timeouts are also raised and bash now supports background commands, so long-running services/log tails no longer block the session.

  • Context compaction & command cleanup — /compact summarizes on demand instead of waiting for automatic trimming, cutting token spend on long sessions; /clear is now the single way to clear the current session, with /context clear kept only as an alias; and the default context window was raised so trimming starts later. Net effect is more work per session and lower cost, and existing /context clear muscle memory or scripts still work.

  • Workspace preview & file references — The chat page now renders generated HTML, docs, and images inline with clickable file-path cards, and you can drag a workspace file or type @ to reference files/directories into context. This changes context gathering from copy-paste to direct grounding, in both Web and desktop; the Web input can also expand a terse prompt into a fuller instruction with custom templates (#2989).

  • Desktop client: Apple Silicon, Feishu, bundled ripgrep — The arm64 installer had been shipping an x64 backend; correcting it is a substantial main-process and browser-tool speedup on M-series Macs, where the win is largest. Feishu returns as a channel with a trimmed ~1 MB SDK fetched on first enable (#2988), Windows now bundles ripgrep so search works out of the box, and a version's update dialog auto-opens only once.

  • Reliability fixes & upgrade path — Several fixes remove wasted agent retries that looked like genuine failures: grep/find exit codes judged wrong, browser scripts falsely reported as syntax errors, and relative image paths failing to resolve. Also, tools.bash.timeout and tools.bash.safety_mode in config.json are finally honored (#2986) and a global-memory workspace path bug is fixed (#2992). Upgrade source installs with cow update (or pull + restart); desktop users get it via the in-client updater or the download page.

No breaking changes in this release.

🗂 Workspace & File Preview

The chat page gains a visual view of the workspace: documents, web pages, and images the Agent produces can be previewed in place. Both the Web console and the desktop client support it.

  • Workspace browsing: browse the files under the workspace directory from the panel, with search and download to local.
  • File preview: HTML pages, documents, and images open directly in the side panel, and file paths in a reply are rendered as clickable cards.
  • File references: drag a workspace file into the conversation, or use @ in the input box to reference files and directories and pull them into the context.

🔧 Core Tool Improvements

A systematic pass over file search, read, write, edit, and shell tools, strengthening the Agent's file handling and coding abilities.

  • New file search tool: search_files searches the workspace by content or by file name, backed by ripgrep by default — markedly faster on large directories. Thanks @Maaayhan (#2982)
  • Line-numbered read output: read output now always carries line numbers, making it easier to locate and cite specific lines.
  • More accurate edits: edit no longer rewrites the surrounding indentation on a fuzzy match, and no longer lands on the wrong occurrence when the text repeats; replace-all was added; a file modified outside the Agent is now flagged.
  • Write-time syntax checks: write / edit validate the format of structured files before writing, and parse source files to report syntax errors back to the Agent.
  • Background commands: bash can run a command in the background, for long-running work such as starting a service or following logs; the default timeout for foreground commands was raised.
  • Cancellation takes effect immediately: clicking stop or running /cancel terminates the command that is currently running.

Docs: File Search

🧠 Context Management

  • Context compaction: the new /compact command summarizes and compacts the conversation context on demand, effectively cutting token usage.
  • Unified commands: /clear now uniformly clears the current session's context, with /context clear kept as an alias.
  • Larger default window: the default context limit was raised, so long conversations start trimming later.

Docs: Context Management

🖥 Desktop Client

  • Native on Mac: fixed the macOS arm64 installer carrying an x64 backend, substantially speeding up the main process and the browser tool on Apple Silicon machines.
  • Feishu channel added: fixed the Feishu channel missing from the client. The Feishu SDK is now a trimmed dependency (about 1 MB) downloaded on demand the first time the channel is enabled. Thanks @EvanProgramming (#2988)
  • Update prompt: the update dialog for a given version only opens automatically once.
  • Bundled search backend: the Windows client ships with ripgrep, so file search works out of the box.

Download: CowAgent Desktop

Docs: Desktop Client

✨ One-Click Prompt Optimization

The Web input box can now expand what you typed into a more complete and explicit instruction, and the optimization rules support custom templates. Thanks @sufan721 (#2989)

🔒 Security Hardening

  • MCP and file-write hardening: fixed an attack chain exploitable through prompt injection — malicious content could lead the Agent into rewriting the MCP config, and from there run arbitrary commands and steal keys. Thanks @Correctover (#2968)
  • Credential file protection: fixed the edit tool bypassing credential protection to read and write ~/.cow/.env.

🛠 Improvements & Fixes

  • bash config honored: fixed tools.bash.timeout and tools.bash.safety_mode in config.json being ignored. Thanks @EvanProgramming (#2986)
  • Memory workspace path: fixed the workspace path being resolved incorrectly in the global memory config. Thanks @Maaayhan (#2992)
  • Conversation history protection: fixed memory index self-repair that could clear conversation history along with it.
  • Session deletion: fixed a reply still in flight writing a deleted session back into the list.
  • Browser launch: fixed launching a duplicate instance when the browser was already running.
  • Accurate tool results: fixed misleading failures from several tools — exit codes from grep / find judged wrong, browser scripts falsely reported as syntax errors, relative image paths failing to resolve — reducing pointless retries.

📦 How to Upgrade

  • Source deployment: run cow update for a one-click upgrade, or pull the latest code and restart. See the upgrade guide.
  • Desktop client: check for updates and update with one click inside the client, or get the latest version from the download page.
