agno v2.6.22

Highlights

  • Video and multimodal embeddings — TwelveLabsTools adds video analysis and multimodal text embeddings (PR #8562), letting agents use video-derived context without a separate integration. Account for video-processing latency when setting agent execution budgets.

  • Search and research toolkits — SearchApiTools provides Google, News, Images, and YouTube search (PR #8553), while SofyaTools adds search, extraction, and research capabilities (PR #8593). Developers can now choose a toolkit by required result type instead of building separate provider wrappers.

  • HTTP timeout controls — The base Toolkit now accepts timeout, with HTTP timeouts wired across existing and additional tools (PRs #8736, #8737). Configure explicit per-tool limits to prevent slow third-party calls from stalling agents; custom toolkits should also propagate the same policy.

  • Airflow path-traversal protection — AirflowTools.save_dag_file and read_dag_file now prevent path traversal (PR #8638). Review code that constructs DAG paths dynamically: attempts to escape the intended directory will fail instead of reading or writing outside it.

  • Fallback responses retained in history — Successful fallback-model responses are now persisted in session history (PR #8732). This makes failover visible during replay, auditing, and debugging; consumers may encounter fallback turns that were previously missing from stored sessions.

  • Response timestamps and DuckDB correctness — ModelResponse.created_at is now stamped per instance rather than at import time (PR #8728), fixing inaccurate timestamps in long-running processes. DuckDB-derived table names are sanitized and full-text-search helpers corrected (PR #8735), improving reliability for generated identifiers and FTS queries.

No breaking changes.

Changelog

New Features

  • TwelveLabs Tools: Added TwelveLabsTools to analyze videos and generate multimodal text embeddings. See docs.
  • Sofya Tools: Added SofyaTools for search, extract, and research.
  • SearchAPI Tool: Added SearchApiTools with Google, News, Images, and YouTube search.

Improvements

  • Toolkit Timeouts: Added timeout to the base Toolkit and wired HTTP timeouts across tools; extended timeout support to more toolkits.

Bug Fixes

  • ModelResponse: Stamp ModelResponse.created_at per instance instead of at import time.
  • AirflowTools: Prevent path traversal in save_dag_file and read_dag_file.
  • Fallback: Persist the fallback model's response in session history.
  • DuckDbTools: Sanitize derived table names and fix full-text search.
