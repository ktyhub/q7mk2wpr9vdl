#Changelog

Nuevas funciones

  • AdvisorTools: se agregó AdvisorTools para solicitar comentarios a los modelos de asesores.
  • OpenRouteService Toolkit: se agregó el kit de herramientas OpenRouteService para enrutamiento preciso.
  • StudioTools: Se agregaron herramientas de programación y parámetros de historial que tienen en cuenta los componentes.
  • FileSystemTools: permite anular el nombre del kit de herramientas FileSystemTools.

Corrección de errores

  • Componentes persistentes: Se corrigió la rehidratación de herramientas calificadas por el kit de herramientas para componentes persistentes.
  • Cohere: Deje de eliminar parámetros de muestreo de valor cero (temperatura, top_k, semilla, frecuencia_penalidad, presencia_penalidad ahora respetan un 0 explícito).
  • HITL: propagar la confirmación de nivel superior a tool_execution en la deserialización de requisitos.
  • Team.load: Se corrigió el fallo en SQLite con un argumento de palabra clave inesperado label.
  • Herramientas de audio: manejo de resultados de herramientas de audio más sólido (y cambió el libro de cocina de IA más pequeño a Gemini).
  • Dependencias: excluye nltk 3.10.1, lo que rompe la cadena de importación unstructured.

agno v2.8.7

Highlights

  • New agent capabilities — AdvisorTools adds model-to-model feedback workflows, while OpenRouteService exposes routing as an agent tool, reducing custom integration work for advisor and location-aware applications (#7196, #9287).
  • Studio scheduling improvements — Component-aware schedule tools and history parameters make scheduled actions more context-aware; moving synchronous scheduler database calls off the event loop also avoids blocking async applications (#9352, #9370).
  • Persistence and human-in-the-loop reliability — Restored components now rehydrate toolkit-qualified tools correctly, and deserialized requirements preserve top-level confirmation settings. This matters for long-running workflows that depend on both tool bindings and approval intent surviving serialization (#9358, #9351).
  • Cohere honors explicit zero values — temperature, top_k, seed, frequency_penalty, and presence_penalty no longer discard 0 and silently fall back to defaults. Review sampling configurations that previously relied on that unintended behavior (#9300).
  • Runtime compatibility fixes — SQLite-backed Team.load no longer crashes on label, audio tool-result handling is more robust, and nltk 3.10.1 is excluded to prevent breaking the unstructured import chain (#9337, #9331, #9320).
  • Breaking changes — None declared.

Changelog

New Features

  • AdvisorTools: Added AdvisorTools for asking advisor models for feedback.
  • OpenRouteService Toolkit: Added OpenRouteService toolkit for accurate routing.
  • StudioTools: Added component-aware schedule tools and history parameters.
  • FileSystemTools: Allow overriding the FileSystemTools toolkit name.

Bug Fixes

  • Persisted Components: Fixed toolkit-qualified tool rehydration for persisted components.
  • Cohere: Stop dropping zero-valued sampling params (temperature, top_k, seed, frequency_penalty, presence_penalty now respect an explicit 0).
  • HITL: Propagate top-level confirmation to tool_execution on requirement deserialization.
  • Team.load: Fixed crash on SQLite with unexpected keyword argument label.
  • Audio Tools: More robust audio tool-result handling (and switched the Smallest AI cookbook to Gemini).
  • Dependencies: Exclude nltk 3.10.1, which breaks the unstructured import chain.
