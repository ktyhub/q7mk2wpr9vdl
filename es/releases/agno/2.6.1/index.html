#Changelog

Nuevas características:

  • Caché de avisos de Claude (multibloque): Tres mejoras de almacenamiento en caché de avisos antrópicos, con alcance en el modelo de Claude (#7662):
    • Nuevo system_prompt_blocks: List[SystemPromptBlock] en Claude: cada bloque tiene text, cache y ttl opcional ("5m" o "1h") que anula el indicador extended_cache_time a nivel de modelo por bloque.
    • Nuevo cache_tools: bool en Claude (Anthropic, AWS Bedrock, VertexAI). Agrega cache_control a la última herramienta para que el prefijo de la herramienta se almacene en caché.
    • Orden de herramientas determinista en Model._format_tools (ordenar por nombre), por lo que los prefijos de solicitud se mantienen estables en todas las ejecuciones y los cachés de avisos realmente llegan. Se aplica en Anthropic, OpenAI, Gemini y Bedrock.
  • Backend MCP paralelo: Se agregó ParallelMCPBackend como un nuevo backend web para WebContextProvider (#7667). Habla con el servidor MCP público de Parallel en search.parallel.ai/mcp, exponiendo web_search + web_fetch (salida de descuento comprimida). Sin llave por defecto; Autenticación de portador a través de PARALLEL_API_KEY para límites de tasas más altos; Punto final OAuth opcional a través de use_oauth=True. El tiempo de espera predeterminado es de 30 segundos (frente a los 10 segundos de MCPTools) porque web_fetch con frecuencia se ejecuta durante más tiempo en páginas grandes.

Mejoras:

  • Cadena de modelo OpenAI: Prefijo de cadena de modelo "openai:" asignado a OpenAIResponses (anteriormente OpenAIChat). Se agregó "openai-chat:" como alternativa para los usuarios que aún necesitan OpenAIChat. Agent(model="openai:gpt-5.4") ahora se resuelve en OpenAIResponses(id="gpt-5.4").

Corrección de errores:

  • A2A: Fijó a2a-sdk>=0.3.0,<1.0 en el flujo de trabajo de lanzamiento. a2a-sdk v1.0 tiene cambios importantes que deben adoptarse en un seguimiento.
  • Libro de cocina:
    • Se corrigieron documentos obsoletos del libro de recetas Redis - se eliminaron los comandos de instalación y configuración de dependencias que ya no son necesarios (#7615).
    • Se corrigió el ejemplo de output_schema para demostrar output_schema con un modelo Pydantic (estaba usando incorrectamente output_model con la búsqueda web).
    • Se corrigió un error tipográfico en cookbook/05_agent_os/README.md que hacía referencia a un agno_agent.py inexistente (corregido a agno_assist.py) (#7663).

agno v2.6.1

Highlights

  • Fine-grained Claude prompt caching — Claude now supports system_prompt_blocks, letting each block opt into caching and override the model-wide extended_cache_time with a "5m" or "1h" TTL. The new cache_tools option adds cache_control to the final tool definition, caching the tool prefix across Anthropic, Bedrock, and Vertex AI requests (#7662).
  • More reliable cache hits across providers — Model._format_tools now sorts tools by name, stabilizing Anthropic, OpenAI, Gemini, and Bedrock request prefixes. This makes caching materially more effective, but note that tool presentation order is now deterministic rather than incidental.
  • openai: switches to the Responses API — This is the main migration consideration: Agent(model="openai:gpt-5.4") now resolves to OpenAIResponses, not OpenAIChat (#7655). Use the new openai-chat: prefix to retain chat-completions behavior, and recheck response handling and tool-call assumptions if your code depended on the old implementation.
  • Parallel adds a high-latency web backend — ParallelMCPBackend brings web_search and compressed-markdown web_fetch to WebContextProvider, with keyless access by default and optional PARALLEL_API_KEY or OAuth authentication (#7667). Its 30-second default timeout—up from MCPTools’ 10 seconds—better accommodates large-page fetches, but configure retries and budget accordingly.
  • A2A releases are temporarily constrained — The release workflow pins a2a-sdk>=0.3.0,<1.0; v1.0 introduces breaking changes slated for a later Agno release. Avoid removing that upper bound until the project provides migration guidance.

Changelog

New Features:

  • Claude Prompt Caching (Multi-Block): Three Anthropic prompt caching enhancements, scoped to the Claude model (#7662):
    • New system_prompt_blocks: List[SystemPromptBlock] on Claude — each block has text, cache, and optional ttl ("5m" or "1h") that overrides the model-level extended_cache_time flag per block.
    • New cache_tools: bool on Claude (Anthropic, AWS Bedrock, VertexAI). Adds cache_control to the last tool so the tool prefix is cached.
    • Deterministic tool ordering in Model._format_tools (sort by name), so request prefixes stay stable across runs and prompt caches actually hit. Applies across Anthropic, OpenAI, Gemini, and Bedrock.
  • Parallel MCP Backend: Added ParallelMCPBackend as a new web backend for WebContextProvider (#7667). Talks to Parallel's public MCP server at search.parallel.ai/mcp, exposing web_search + web_fetch (compressed markdown output). Keyless by default; Bearer-auth via PARALLEL_API_KEY for higher rate limits; optional OAuth endpoint via use_oauth=True. Defaults to a 30s timeout (up from MCPTools' 10s) because web_fetch frequently runs longer on large pages.

Improvements:

  • OpenAI Model String: Mapped "openai:" model string prefix to OpenAIResponses (previously OpenAIChat). Added "openai-chat:" as a fallback for users who still need OpenAIChat. Agent(model="openai:gpt-5.4") now resolves to OpenAIResponses(id="gpt-5.4").

Bug Fixes:

  • A2A: Pinned a2a-sdk>=0.3.0,<1.0 in the release workflow. a2a-sdk v1.0 has breaking changes that need to be adopted in a follow-up.
  • Cookbook:
    • Fixed outdated Redis cookbook docs - removed dependency install and setup commands that are no longer needed (#7615).
    • Fixed output_schema example to demonstrate output_schema with a Pydantic model (it was incorrectly using output_model with web search).
    • Fixed typo in cookbook/05_agent_os/README.md that referenced a non-existent agno_agent.py (corrected to agno_assist.py) (#7663).
