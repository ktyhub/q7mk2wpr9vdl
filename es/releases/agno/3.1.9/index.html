#Changelog

Nuevas características:

  • MCP Tool Runner: POST /mcp/server/tools/{tool_name}/run ejecuta cualquier herramienta listada en la tarjeta del servidor AgentOS a través de HTTP y devuelve su resultado, por lo que se puede probar una herramienta sin un MCP client. Apágalo con MCPConfig(tool_run_endpoint=False). Consulte [libro de cocina] (https://github.com/agno-agi/agno/blob/main/cookbook/05_agent_os/14_mcp/inspect_tools.py).

Corrección de errores:

  • Servidor AgentOS MCP: /mcp y /mcp/server-card ahora aceptan solicitudes del navegador desde orígenes que la política CORS de AgentOS permite, por lo que os.agno.com puede llegar al servidor MCP de un AgentOS local. /info ahora informa la ruta MCP configurada en lugar de siempre /mcp.
  • Métricas de Postgres: la actualización de métricas en una base de datos migrada ya no carga la columna sessions.runs heredada en la memoria.
  • Flujos de trabajo de funciones: una función pasada como steps de un flujo de trabajo ahora se ejecuta una vez cuando su cuerpo genera un TypeError, y las funciones y generadores de sincronización ahora funcionan con arun().
  • AgenticChunking: la fragmentación ya no se bloquea cuando el modelo devuelve un punto de interrupción cero o negativo, y max_chunk_size debe ser mayor que 0.
  • BaiduSearchTools: los títulos y resúmenes en chino se devuelven como texto legible en lugar de escapes \uXXXX.
  • Entrada del usuario Human-in-the-Loop: una herramienta requires_user_input con un parámetro escrito int | None u otro tipo X | Y ahora se detiene limpiamente, y la ejecución pausada se guarda y se reanuda con continue_run(run_id=...).
  • Mistral: Los parámetros timeout, endpoint y safe_mode en MistralChat, y endpoint en MistralEmbedder, ahora funcionan en lugar de elevar un TypeError. safe_mode está en desuso en favor de safe_prompt.

agno v3.1.9

Highlights

  • MCP gains an HTTP tool runner and a browser-facing surface — new POST /mcp/server/tools/{tool_name}/run executes any tool advertised on the AgentOS Server Card over plain HTTP, so tools can be tested without an MCP client; it is on by default, so expose it carefully or disable with MCPConfig(tool_run_endpoint=False). A companion CORS fix lets os.agno.com reach a local AgentOS /mcp and /mcp/server-card, and /info now reports the configured MCP path instead of hardcoding /mcp (PR #10666, #11246). If your AgentOS is network-reachable, this is the one change to review before upgrading.
  • Mistral parameters now actually work — one carries a migration — timeout, endpoint and safe_mode on MistralChat and endpoint on MistralEmbedder were being dropped and raising TypeError; they now map correctly onto the mistralai SDK. Migration: safe_mode is deprecated in favor of safe_prompt, so update any code passing it before the next major (PR #11222). Anyone using custom Mistral endpoints/timeouts should upgrade.
  • Human-in-the-loop unblocks union-typed inputs — a requires_user_input tool whose parameter is int | None (or any X | Y PEP 604 annotation) now pauses cleanly instead of failing, persists the paused run, and resumes via continue_run(run_id=...) (PR #11177). If your approval flows use optional or union types, this is a direct fix.
  • Stability fixes with one behavior change to note — AgenticChunking no longer hangs on zero/negative breakpoints and now enforces max_chunk_size > 0, so configs passing 0 or a negative value will now be rejected rather than silently misbehaving (PR #11231). Also: a function passed as a workflow's steps runs once even when its body raises TypeError, and sync functions/generators work with arun() (PR #11235); Postgres metrics refresh stops loading the legacy sessions.runs column into memory (PR #11190); BaiduSearchTools returns readable Chinese instead of \uXXXX escapes (PR #11229).
  • Verdict: worth upgrading for affected users, otherwise optional — this is a substantive patch, not a no-op or metadata-only re-tag. Upgrade if you use MCP tooling, Mistral with custom params, HITL with union types, or hit any of the chunking/workflow/metrics/search bugs above; you can safely skip if you're on a default setup untouched by those areas. Watch for two non-obvious items: Product-scoped Company tools were renamed (PR #11242), which may break code referencing the old names, and the Company automation cadence moved from every minute to hourly (PR #11221) — an internal scheduling change with no impact on library consumers.

Changelog

New Features:

  • MCP Tool Runner: POST /mcp/server/tools/{tool_name}/run runs any tool listed on the AgentOS Server Card over HTTP and returns its result, so a tool can be tested without an MCP client. Turn it off with MCPConfig(tool_run_endpoint=False). See cookbook.

Bug Fixes:

  • AgentOS MCP Server: /mcp and /mcp/server-card now accept browser requests from origins the AgentOS CORS policy allows, so os.agno.com can reach the MCP server of a local AgentOS. /info now reports the configured MCP path instead of always /mcp.
  • Postgres Metrics: Metrics refresh on a migrated database no longer loads the legacy sessions.runs column into memory.
  • Function Workflows: A function passed as a workflow's steps now runs once when its body raises a TypeError, and sync functions and generators now work with arun().
  • AgenticChunking: Chunking no longer hangs when the model returns a zero or negative breakpoint, and max_chunk_size must be greater than 0.
  • BaiduSearchTools: Chinese titles and abstracts are returned as readable text instead of \uXXXX escapes.
  • Human-in-the-Loop User Input: A requires_user_input tool with a parameter typed int | None or another X | Y type now pauses cleanly, and the paused run is saved and resumes with continue_run(run_id=...).
  • Mistral: The timeout, endpoint and safe_mode parameters on MistralChat, and endpoint on MistralEmbedder, now work instead of raising a TypeError. safe_mode is deprecated in favor of safe_prompt.
