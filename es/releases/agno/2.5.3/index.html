#Changelog

Nuevas características:

  • Conocimiento remoto: Se agregaron puntos finales para admitir la lista de contenidos remotos a través de API. Permite cargar contenido en depósitos S3 a través de AgentOS

Mejoras:

  • Lector de PDF: Se agregó el parámetro sanitize_content a BasePDFReader (habilitado de forma predeterminada) que normaliza la extracción de texto PDF fragmentado, colapsando artefactos de palabra por línea y preservando los saltos de párrafo. Desactívelo con sanitize_content=False para archivos PDF que contengan contenido estructurado, como código o tablas.
  • Lector de PDF: Se agregó un parámetro sanitize_content a BasePDFReader que normaliza el texto PDF extraído al contraer secuencias excesivas de espacios en blanco en espacios individuales.

Corrección de errores:

  • Retriever de conocimientos: Se solucionó el problema por el cual knowledge_retriever se ignoraba cuando search_knowledge=True estaba habilitado.
  • Claude: Se corrigió el recuento doble de métricas de transmisión input_tokens para modelos antrópicos.
  • Búsqueda de conocimientos: Se corrigió la coincidencia de patrones de inclusión/exclusión con el nombre de archivo para el escaneo de directorios.
  • Razonamiento: se corrigió la duplicación de reasoning_content en los pasos de razonamiento.
  • Copia profunda en agente/equipo/flujo de trabajo: se corrigió el error deep_copy para equipos anidados debido a campos de clase de datos que no son iniciales.
  • HITL: se corrigieron los controladores de pausa HITL que eliminaban silenciosamente los cambios session_state en los módulos agent y team .
  • Pasos paralelos del flujo de trabajo: condición de carrera fija en run_context.output_schema en ejecución paralela.

agno v2.5.3

Highlights

  • PDF extraction now sanitizes by default — BasePDFReader adds sanitize_content=True, collapsing fragmented text and excessive whitespace while preserving paragraph breaks. This generally improves prose ingestion, but set sanitize_content=False for code, tables, or other layout-sensitive PDFs. The changelog does not classify this default change as breaking.
  • Remote Knowledge and richer AgentOS listings — New endpoints support listing remote content and uploading S3-backed content through AgentOS; list endpoints also expose is_component, current_version, and stage. Upgrade if you manage external knowledge through AgentOS; no migration is described.
  • Knowledge retrieval correctness — knowledge_retriever is now honored when search_knowledge=True, directory include/exclude patterns correctly match filenames, and list-based FilterExpr filters receive the required linked_to filter. Worth upgrading if custom retrieval or filtered searches return missing or incorrectly scoped results.
  • Stateful and concurrent execution fixes — HITL pauses preserve session_state in both agent and team modules. Fixes also address nested-team deep_copy, races on run_context.output_schema during parallel execution, and reasoning_content duplication. Upgrade if you rely on HITL, nested teams, parallel workflows, or multi-step reasoning.
  • Metrics, serialization, and upgrade guidance — Anthropic streaming no longer double-counts input_tokens; fixes also cover Gemini files missing mime_type, PostgreSQL datetime JSON serialization, SDK session user_id, and WorkflowRunOutput file serialization. No explicit breaking changes are announced. This is a worthwhile patch for affected workloads; otherwise, skipping is reasonable.

Changelog

New Features:

  • Remote Knowledge: Added endpoints to support listing of remote contents via API. Enables uploading of content in S3 buckets via AgentOS

Improvements:

  • PDF Reader: Added sanitize_content parameter to BasePDFReader (enabled by default) that normalizes fragmented PDF text extraction — collapsing word-per-line artifacts while preserving paragraph breaks. Disable with sanitize_content=False for PDFs containing structured content like code or tables.
  • PDF Reader: Added a sanitize_content parameter to BasePDFReader that normalizes extracted PDF text by collapsing excessive whitespace sequences into single spaces.

Bug Fixes:

  • Knowledge Retriever: Fix issue whereknowledge_retriever ignored when search_knowledge=True enabled.
  • Claude: Fixed streaming metrics double-count input_tokens for Anthropic models
  • Knowledge Search: Fixed match include/exclude patterns against filename for directory scanning
  • Reasoning: fixed reasoning_content duplication across reasoning steps.
  • Deepcopy on Agent/Team/Workflow: fixed deep_copy fails for nested teams due to non-init dataclass fields.
  • HITL: fixed HITL pause handlers silently dropping session_state changes in both agent and team modules.
  • Workflow Parallel Steps: fixed race condition on run_context.output_schema in Parallel execution.
