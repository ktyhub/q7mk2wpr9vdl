año v2.7.3

#Changelog

Nuevas funciones:

  • Valkey:
    • Se agregó ValkeyDb como una base de datos rápida en memoria para agentes, equipos y flujos de trabajo. Ver Documentos
    • Se agregó una tienda de vectores ValkeyDB con búsqueda de vectores y palabras clave. Ver Documentos
  • Herramientas de Redmine: se agregó RedmineTools para administrar problemas, comentarios y registros de tiempo en Redmine, una herramienta de administración de proyectos de código abierto.
  • TokenLab: Se agregó TokenLab como nuevo proveedor de modelos compatible con OpenAI.

Mejoras:

  • Contexto de la sesión: omita una llamada de modelo redundante al guardar el contexto de la sesión.
  • AG-UI: confirmación, entrada y retroalimentación humana integrada extendida a AG-UI.
  • Memoria y perfil de usuario: memoria más confiable y extracción de perfiles de las conversaciones.
  • Herramientas MCP:
    • Aparece un error limpio cuando un servidor MCP se vuelve inaccesible.
    • Herramientas de soporte que responden solo con structuredContent.

Corrección de errores:

  • DoclingReader: acepta cadenas de ruta de archivo locales.
  • JSONReader: Respete chunk=False al leer documentos JSON.
  • Lector de PDF:
    • Se corrigió la interpretación incorrecta del número de página para archivos PDF de una sola página.
    • Pruebe automáticamente una contraseña en blanco para archivos PDF cifrados.
  • Salidas estructuradas: analiza de manera confiable las respuestas cuyos valores de campo contienen llaves.
  • Herramientas de codificación y archivos: mantiene la búsqueda y el listado contenidos en la raíz configurada.
  • Antigravity: evita que los archivos con enlaces simbólicos salgan del directorio del agente.
  • Cassandra: deriva la dimensión del vector del incrustador configurado.
  • Mistral: agregue frequency_penalty, presence_penalty y stop, y mantenga parámetros de valor cero como temperature=0.
  • YouTools: corrige búsquedas fallidas y agrega filtros de región, idioma y actualización.
  • Métricas de flujo de trabajo: incluya métricas en WorkflowCompletedEvent.
  • Temporizador: Corrige Timer.elapsed para operaciones muy rápidas.

agno v2.7.3

Highlights

  • New integrations — ValkeyDb adds in-memory persistence for agents, teams, and workflows, while ValkeyDB provides vector and keyword search. RedmineTools manages Redmine issues, comments, and time logs, and TokenLab adds an OpenAI-compatible model provider. These are additive and mainly matter if you plan to use those services.
  • Cheaper, more reliable agent runs — Saving session context no longer triggers a redundant model call, reducing latency and cost. Memory/profile extraction is more reliable, AG-UI gains human-in-the-loop confirmation, input, and feedback, MCP handles unreachable servers and structuredContent-only responses cleanly, and WorkflowCompletedEvent now includes metrics.
  • Document ingestion fixes — DoclingReader accepts local file-path strings, JSONReader honors chunk=False, PDFReader fixes single-page numbering and tries a blank password for encrypted PDFs, and structured outputs correctly handle braces inside string values. Upgrade if these paths affect you; the fixes prevent parsing errors and incorrect document interpretation.
  • Safety and provider corrections — Search/listing tools remain within the configured root, Antigravity blocks symlink escapes, Mistral forwards frequency_penalty, presence_penalty, and stop without dropping zero values such as temperature=0, and YouTools searches and filters are repaired. The ShellTools change relies on documentation and the existing confirmation API—not a new enforced sandbox.
  • Upgrade recommendation — No breaking changes or required migrations are documented. This is a worthwhile maintenance upgrade for anyone using the affected readers, security boundaries, MCP/AG-UI, or providers; users on unaffected paths can skip it. Cassandra users with non-1024 embeddings should verify vector-index compatibility because dimensions now come from the configured embedder.

Changelog

New Features:

  • Valkey:
    • Added ValkeyDb as a fast in-memory database for agents, teams, and workflows. See Docs
    • Added a ValkeyDB vector store with vector and keyword search. See Docs
  • Redmine Tools: Added RedmineTools to manage issues, comments, and time logs in Redmine, an open source project management tool.
  • TokenLab: Added TokenLab as a new OpenAI-compatible model provider.

Improvements:

  • Session Context: Skip a redundant model call when saving session context.
  • AG-UI: Extended human-in-the-loop confirmation, input, and feedback to AG-UI.
  • User Memory & Profile: More reliable memory and profile extraction from conversations.
  • MCP Tools:
    • Surface a clean error when an MCP server becomes unreachable.
    • Support tools that respond with only structuredContent.

Bug Fixes:

  • DoclingReader: Accept local file-path strings.
  • JSONReader: Honor chunk=False when reading JSON documents.
  • PDFReader:
    • Fix incorrect page number interpretation for single page pdf’s.
    • Auto-try a blank password for encrypted PDFs.
  • Structured Outputs: Reliably parse responses whose field values contain braces.
  • File & Coding Tools: Keep search and listing contained to the configured root.
  • Antigravity: Prevent symlinked files from escaping the agent directory.
  • Cassandra: Derive the vector dimension from the configured embedder.
  • Mistral: Add frequency_penalty, presence_penalty, and stop, and keep zero-valued params like temperature=0.
  • YouTools: Fix failing searches and add region, language, and freshness filters.
  • Workflow Metrics: Include metrics on WorkflowCompletedEvent.
  • Timer: Fix Timer.elapsed for very fast operations.
