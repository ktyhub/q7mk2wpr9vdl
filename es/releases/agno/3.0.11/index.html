#año v3.0.11 #Changelog

Nuevas características:

  • Canalización de recuperación de conocimientos: Knowledge.search() ahora ejecuta un canal de recuperación de nivel de conocimiento que puede ampliar el grupo de candidatos antes de que un reclasificador lo reordene, por lo que ya no es necesario implementar reclasificadores por base de datos vectorial.
  • Reranker MMR: se agregó MMRReranker (relevancia marginal máxima) como una estrategia de recuperación que equilibra la relevancia con la diversidad para que los fragmentos casi duplicados no desplacen el conjunto de resultados.
  • Reubicación de la fuente de la página: se agregó Knowledge.inspect_page_source / ainspect_page_source y protegió migrate_page_source / amigrate_page_source para mover una fuente de documentación indexada a un nuevo nombre de host. La migración es un ensayo de forma predeterminada.
  • Reranker reciente: se agregó RecencyReranker, que combina la puntuación de búsqueda con una caída exponencial en una marca de tiempo para que las revisiones más nuevas superen a las reemplazadas. Construido sobre la tubería de nivel de conocimiento, enfocado en pgvector.
  • Resultados de la herramienta de página escrita: se agregaron PageCommandResult y PageFileSystem.run_command_result / arun_command_result con metadatos de error explícito, integridad y truncamiento. Knowledge.get_tools(page_results=True) devuelve objetos SearchResult clasificados, incluso como salida estructurada de MCP.
  • Y-API: Se agregó YAPI como proveedor de modelos compatible con OpenAI.
  • Etapa de cancelación: se agregó un cancellation_stage legible por máquina (PENDING, EXECUTING, INTERRUPTED o desconocido) a RunOutput, TeamRunOutput, WorkflowRunOutput y los esquemas de ejecución API, por lo que clients ya no coincide en el texto del mensaje de cancelación.
  • OpenAIResponses: Se agregó use_previous_response_id para que store=True ya no fuerce el encadenamiento automático de previous_response_id.

Mejoras:

  • Esquemas de herramientas MCP: cada argumento en las herramientas MCP de AgentOS ahora lleva una descripción en su inputSchema, y get_sessions limita limit y page a un mínimo de 1.
  • Detección de razonamiento: los ID de los modelos de modo de pensamiento de DeepSeek se reconocen como modelos de razonamiento cuando se entregan a través de cualquier proveedor OpenAILike, como DashScope.
  • Herramientas: Se eliminaron las entradas Args fantasmas de las cadenas de documentos de herramientas y se corrigieron los nombres de los parámetros de las cadenas de documentos de transmisión en dos clases de modelo.

Corrección de errores:

  • Herramientas: Los enlaces de sincronización que devuelven function_call(**arguments) ahora funcionan en la ruta de ejecución asíncrona. Anteriormente, la cadena trataba la rutina no esperada como el resultado de la herramienta y el cuerpo de la herramienta nunca se ejecutaba.
  • Tarjeta de servidor MCP: mcp=True básico ahora instala la misma capa de enrutamiento que MCPConfig, por lo que la verificación de host y el prefijo de montaje se aplican en ambas grafías. Se eliminaron los encabezados CORS ETag / If-None-Match no implementados.
  • Herramientas MCP: el descubrimiento de herramientas en un ClientSession sin formato ahora recopila todas las páginas de tools/list en lugar de solo la primera.
  • AG-UI: compatible con ag-ui-protocol 1.0, incluido el contenido de resultados de herramientas con valores de lista en el currículum.
  • Flujos de trabajo a través de WebSocket: los envíos fijados por versión ya no se ponen en cola sin su pin, la propiedad de la sesión se verifica en la ruta de escritura y una identificación de sesión faltante genera una nueva sesión como HTTP.
  • JSONReader: Preservar raíces escalares JSON.
  • CSVReader: lee flujos de texto, no solo flujos de bytes.
  • CSVReader y FieldLabeledCSVReader: valide page_size antes de leer, de modo que los valores cero o negativos generen ValueError en lugar de no devolver ningún documento silenciosamente.
  • Análisis de salida estructurada: ignora las llaves de cierre no coincidentes en prosa al extraer objetos JSON de la salida del modelo.
  • GoogleDriveTools: lee texto dentro de formas agrupadas y respeta los saltos de línea al extraer texto .pptx.
  • Archivos UTF-8: read_yaml_file / write_yaml_file, AntigravityTools y AirflowTools ahora leen y escriben archivos como UTF-8 independientemente de la configuración regional.
  • DuckDbTools: Escapar de los delimitadores CSV.
  • TavilyTools: opciones de extracción directa.
  • Libros de cocina y documentos: se reemplazaron enlaces inactivos en fuentes de conocimiento y se corrigió una palabra duplicada en la guía de migración V3. Se agregaron ejemplos de observabilidad de memoria Inspeximus y Confident AI.

Depreciaciones:

  • Reranker de base de datos vectorial: el parámetro reranker en bases de datos vectoriales está obsoleto en favor del reranker en Knowledge, que se aplica a cada base de datos vectorial y admite asíncrono.

agno v3.0.11

Highlights

  • Database-agnostic retrieval pipelines — Knowledge.search() can now widen the candidate pool before reranking, making rerankers portable across vector databases. New MMRReranker balances relevance and diversity, while RecencyReranker favors newer revisions using timestamp decay (currently pgvector-focused). The vector-database reranker parameter is deprecated in favor of Knowledge’s async-capable reranker, so migrate configurations rather than continuing to build per-database rerankers (PRs #10115, #10396, #10385).
  • Safer documentation-source relocation — Knowledge.inspect_page_source() and migrate_page_source() (plus async variants) support moving indexed sources to a new hostname. Migration is guarded and performs a dry run by default; preview the scope before committing the move (PR #10096).
  • Typed, MCP-ready page results — PageCommandResult and run_command_result() expose explicit error, completeness, and truncation metadata. Knowledge.get_tools(page_results=True) returns ranked SearchResult objects, including structured MCP output, making failures and partial results machine-readable instead of relying on free-form text (PR #10097).
  • More reliable cancellation handling — Run outputs and API schemas now expose cancellation_stage values such as PENDING, EXECUTING, and INTERRUPTED. Clients should switch from parsing cancellation messages to this enum, while retaining a fallback for unknown values (PR #10411).
  • OpenAI Responses chaining is now opt-in — store=True no longer automatically chains previous_response_id. Set use_previous_response_id=True where conversation continuity depends on chained responses; otherwise independent response calls will not inherit prior context automatically (PR #10075).
  • Protocol and execution fixes worth validating — Async tool chains now correctly await synchronous hooks that return function_call(...) (PR #10481); bare mcp=True now applies the same host checks and mount prefix as MCPConfig (PR #10418); and WebSocket workflow submissions enforce version pins and session ownership like HTTP (PR #10179). Also verify integrations against ag-ui-protocol 1.0, whose resume flow now accepts list-valued tool-result content (PR #10283).

No breaking changes are explicitly identified.

Changelog

New Features:

  • Knowledge Retrieval Pipeline: Knowledge.search() now runs a knowledge level retrieval pipeline that can widen the candidate pool before a reranker reorders it, so rerankers no longer need to be implemented per vector db.
  • MMR Reranker: Added MMRReranker (Maximal Marginal Relevance) as a retrieval strategy that balances relevance against diversity so near-duplicate chunks do not crowd out the result set.
  • Page Source Relocation: Added Knowledge.inspect_page_source / ainspect_page_source and guarded migrate_page_source / amigrate_page_source to move an indexed documentation source to a new hostname. Migration is a dry run by default.
  • Recency Reranker: Added RecencyReranker, which blends the search score with an exponential decay on a timestamp so newer revisions outrank superseded ones. Built on the knowledge level pipeline, focused on pgvector.
  • Typed Page Tool Results: Added PageCommandResult and PageFileSystem.run_command_result / arun_command_result with explicit error, completeness and truncation metadata. Knowledge.get_tools(page_results=True) returns ranked SearchResult objects, including as MCP structured output.
  • Y-API: Added YAPI as an OpenAI-compatible model provider.
  • Cancellation Stage: Added a machine-readable cancellation_stage (PENDING, EXECUTING, INTERRUPTED, or unknown) to RunOutput, TeamRunOutput, WorkflowRunOutput and the run API schemas, so clients no longer match on the cancellation message text.
  • OpenAIResponses: Added use_previous_response_id so store=True no longer forces automatic previous_response_id chaining.

Improvements:

  • MCP Tool Schemas: Every argument on the AgentOS MCP tools now carries a description in its inputSchema, and get_sessions bounds limit and page to a minimum of 1.
  • Reasoning Detection: DeepSeek thinking-mode model IDs are recognised as reasoning models when served through any OpenAILike provider such as DashScope.
  • Tools: Removed phantom Args entries from tool docstrings and corrected streaming docstring parameter names in two model classes.

Bug Fixes:

  • Tool Hooks: Sync hooks that return function_call(**arguments) now work in the async execution path. Previously the chain treated the unawaited coroutine as the tool result and the tool body never ran.
  • MCP Server Card: Bare mcp=True now installs the same routing layer as MCPConfig, so the Host check and mount prefix apply on both spellings. Dropped the unimplemented ETag / If-None-Match CORS headers.
  • MCP Tools: Tool discovery over a raw ClientSession now collects every tools/list page instead of only the first.
  • AG-UI: Support ag-ui-protocol 1.0, including list-valued tool result content on resume.
  • Workflows over WebSocket: Version-pinned submissions are no longer queued without their pin, session ownership is checked on the write path, and a missing session id mints a new session like HTTP.
  • JSONReader: Preserve scalar JSON roots.
  • CSVReader: Read text streams, not only byte streams.
  • CSVReader & FieldLabeledCSVReader: Validate page_size before reading, so zero or negative values raise ValueError instead of silently returning no documents.
  • Structured Output Parsing: Ignore unmatched closing braces in prose when extracting JSON objects from model output.
  • GoogleDriveTools: Read text inside grouped shapes and honour line breaks when extracting .pptx text.
  • UTF-8 Files: read_yaml_file / write_yaml_file, AntigravityTools and AirflowTools now read and write files as UTF-8 regardless of locale.
  • DuckDbTools: Escape CSV delimiters.
  • TavilyTools: Forward extract options.
  • Cookbooks & Docs: Replaced dead links in knowledge sources and fixed a duplicated word in the V3 migration guide. Added Inspeximus memory and Confident AI observability examples.

Deprecations:

  • Vector DB Reranker: The reranker parameter on vector databases is deprecated in favour of the reranker on Knowledge, which applies to every vector db and supports async.
