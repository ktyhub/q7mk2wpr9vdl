#HyperFrames v0.9.71 Publicado el 19/11/2026. Cancelar una renderización ahora detiene su compilación y los archivos que descarga una compilación tienen un límite de tamaño y una fecha límite compartida. Los renderizados leen fotogramas de MP4 cuyo índice de búsqueda omite el primer fotograma clave, y las composiciones con mucho SVG se mantienen dentro del límite de tamaño de compilación.

Correcciones

  • Motor: Extrae fotogramas de MP4 cuyo índice de búsqueda omite el primer fotograma clave (9813a6cbe, #8252).
  • Uso de medios: Los guiones de audio, corte, transcripción, tramado y audio imprimen caracteres de control como escapes (98f548447, #8235).
  • Núcleo: Los escapes de valor-atributo escriben '<' para que el texto de estilo no pueda finalizar antes (9e7835367, #8250).
  • Uso de medios: Las líneas de error del proveedor imprimen caracteres de control como escapes (77134c927, #8249).
  • Núcleo: Mantener el crecimiento del alias del selector SVG dentro del presupuesto de compilación (6bd0b5d87, #8238).
  • Pelusa: Lee el inicio de una ventana multimedia a través del analizador (a7d7a6075, #8133).
  • Productor: Cancelar un render detiene su compilación (765883195, #8242).
  • Productor: Limite las descargas remotas en tiempo de compilación, déles una fecha límite y deténgalas al cancelarlas (77ea9d80c, #8195).
  • Núcleo: Deja de fallar en elementos SVG llamados plantilla (d106f9c8c, #8241).
  • Núcleo: Lea los alias del selector solo a partir de lo que escribió el compilador (def770ed9, #8240).
  • Principal: Los tiempos de ejecución de páginas no contienen caracteres anchos, por lo que las páginas permanecen en un byte por carácter (01a5e948b, #8239).
  • Uso de medios: Volver a congelar archivos de recetas solo en una versión entera (e383abf47, #8201).

hyperframes v0.9.71

HyperFrames v0.9.71

Released on 2026-11-19.

Cancelling a render now stops its compile, and files a compile downloads have a size cap and one shared deadline. Renders read frames from MP4s whose seek index leaves out the first keyframe, and SVG-heavy compositions stay within the compile size limit.

Fixes

  • Engine: Extract frames from MP4s whose seek index leaves out the first keyframe (9813a6cbe, #8252).
  • Media Use: Duck, cut, transcribe, dither and audio scripts print control characters as escapes (98f548447, #8235).
  • Core: Attribute-value escapes write '<' so style text can't end early (9e7835367, #8250).
  • Media Use: Provider error lines print control characters as escapes (77134c927, #8249).
  • Core: Keep SVG selector alias growth within the compile budget (6bd0b5d87, #8238).
  • Lint: Read a media window's start through the parser (a7d7a6075, #8133).
  • Producer: Cancelling a render stops its compile (765883195, #8242).
  • Producer: Cap compile-time remote downloads, give them one deadline and stop them on cancel (77ea9d80c, #8195).
  • Core: Stop crashing on SVG elements named template (d106f9c8c, #8241).
  • Core: Read selector aliases only from what the compiler wrote (def770ed9, #8240).
  • Core: Page runtimes carry no wide characters, so pages stay one byte a char (01a5e948b, #8239).
  • Media Use: Re-freezing a recipe archives only under an integer version (e383abf47, #8201).

Docs & Examples

  • Adopters: Add ViralMint (78d8ad037, #7738).

Catalog

  • CLI: Report an empty catalog --type= as a usage error (c2911adc8, #8130).

Internal

  • CLI: The phone-clip offload tests pass when run together (3f3a6205a, #8071).
