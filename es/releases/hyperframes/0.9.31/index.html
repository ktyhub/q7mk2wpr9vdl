#HyperFrames v0.9.31 Publicado el 10/11/2026. En Safari, los vídeos largos ya no cargan todo el archivo a la vez y la reproducción de clips conserva su fuente. El servidor de desarrollo de Studio ahora verifica el host en sus rutas API, por lo que un túnel o una configuración remota puede necesitar una configuración.

Correcciones

  • Núcleo: En Safari, un archivo de vídeo pequeño mantiene su precarga y un clip que se está reproduciendo mantiene su fuente (cda84222a, #7498).
  • Studio: El servidor de desarrollo de Studio ahora también verifica el encabezado del Host en sus rutas API, como lo hace el servidor de vista previa desde 0.9.30. Un túnel, Codespaces o host de desarrollo remoto que funcionaba antes ahora puede obtener un 403: nombre el host en HYPERFRAMES_PREVIEW_ALLOWED_HOSTS (separado por comas), que ahora también llega a los hosts permitidos del servidor de desarrollo (b0835262a, #7493).
  • Studio Server: Los enlaces de miniaturas se originan en el servidor y las vistas previas de otros sitios se abren en un espacio aislado (983e865ad, #7492).
  • Productor: Un render que carga el archivo GSAP predeterminado desde la CDN utiliza la copia que el CLI ya incluye, por lo que funciona sin red (5c5799975, #7388).
  • CLI: El mensaje sobre otra instalación que sigue a esta solo nombra una instalación que su administrador de paquetes puede mover (b28bd2b34, #7499).
  • Studio: Los mensajes que cuentan clips o fotogramas clave dicen 1 clip, no 1 clips (ec30de062, #7496).
  • Studio Server: Cuando un archivo aún está cambiando, un reclamo espera su primera copia, por lo que la edición aún se puede deshacer (248f56fba, #7497).

hyperframes v0.9.31

HyperFrames v0.9.31

Released on 2026-11-10.

In Safari, long videos no longer load the whole file at once, and playing clips keep their source. The Studio dev server now checks the Host on its API routes, so a tunnel or remote setup may need one setting.

Fixes

  • Core: In Safari, a small video file keeps its preload, and a clip that is playing keeps its source (cda84222a, #7498).
  • Studio: The Studio dev server now checks the Host header on its API routes too, as the preview server does since 0.9.30. A tunnel, Codespaces or remote dev host that worked before can now get a 403: name the host in HYPERFRAMES_PREVIEW_ALLOWED_HOSTS (comma separated), which now also reaches the dev server's own allowed hosts (b0835262a, #7493).
  • Studio Server: Thumbnail links take their origin from the server, and previews from other sites open sandboxed (983e865ad, #7492).
  • Producer: A render that loads the default GSAP file from the CDN uses the copy the CLI already ships, so it works with no network (5c5799975, #7388).
  • CLI: The message about another install shadowing this one only names an install its package manager can move (b28bd2b34, #7499).
  • Studio: Messages that count clips or keyframes say 1 clip, not 1 clips (ec30de062, #7496).
  • Studio Server: When a file is still changing, a claim waits for its first copy, so the edit can still be undone (248f56fba, #7497).

Performance

  • Core: In Safari, the clips of a long video no longer load the whole file at once (fecde9992, #7436).

Docs & Examples

  • Docs: The adopters list adds DoneCut (0b531bc7a, #5638).

Internal

  • Release: Hardened release build.
