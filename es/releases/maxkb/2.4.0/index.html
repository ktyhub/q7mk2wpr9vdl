#MaxKBv2.4.0

Correcciones de vulnerabilidades de seguridad

  • Se solucionó el problema de omisión de permisos causado por la sobrescritura de archivos del sistema (CVE-2025-66446);
  • Se solucionó el problema de omisión de permisos causado en condiciones simultáneas específicas (CVE-2025-66419). ¡Un agradecimiento especial a los usuarios de GitHub @yck99, @NikoCat233 y @Threonine por descubrir e informar rápidamente las vulnerabilidades anteriores a la comunidad de código abierto MaxKB!

Nuevas características

  • Base de conocimientos: base de conocimientos de flujo de trabajo agregada;
  • Herramientas: herramientas de fuente de datos agregadas;
  • Herramientas: Las herramientas en el Almacén de herramientas admiten dos tipos: "Herramienta" y "Fuente de datos";
  • Modelos: el proveedor de AWS agregó soporte para modelos de visión y modelos de reclasificación;
  • Modelos: los modelos de visión de los proveedores de IA OpenAI, Ollama, vLLM, Xinference y Zhipu admiten la funcionalidad de comprensión de video;
  • Modelos: se agregó soporte para modelos de lenguaje grandes, modelos vectoriales y modelos de reclasificación del proveedor de IA Docker;
  • Aplicaciones: Se agregó "Dirección URL" como método de carga en la configuración de carga de archivos;
  • Aplicaciones: Se agregaron estadísticas de clasificación para "Tokens consumidos por el usuario" y "Recuento de preguntas del usuario" a las estadísticas de monitoreo en la página de descripción general;
  • Autorización de recursos: admitió el filtrado de usuarios por función al autorizar aplicaciones, bases de conocimiento, herramientas y modelos a usuarios por recurso;
  • Autenticación de inicio de sesión (X-Pack): se agregó el método de autenticación de inicio de sesión SAML2.

Optimizaciones de funciones

  • Aplicaciones: los mensajes generados por los nodos de conversación de IA en aplicaciones avanzadas ya no contienen nombres de aplicaciones ni información de descripción;
  • Aplicaciones: parámetros de solicitud de salida admitidos cuando los modelos de IA llaman a herramientas MCP;
  • Aplicaciones: compatible con el uso de teclas de método abreviado para copiar nodos en cuerpos de bucle en orquestación avanzada;
  • Herramientas: admite la importación de tres tipos de recursos: herramientas, MCP y fuentes de datos;
  • Herramientas: se ajustó la entrada del almacén de herramientas a la lista de herramientas;
  • Herramientas: Se eliminaron las herramientas integradas del sistema y se trasladaron a la Tienda de herramientas.

Corrección de errores

  • Página de preguntas y respuestas: se solucionó el problema por el cual los resultados de recuperación de los nodos de recuperación de la base de conocimientos en los cuerpos de los bucles no se mostraban en las fuentes de conocimiento;
  • Aplicaciones: Se corrigió la visualización incorrecta del tiempo de ejecución para los nodos de bucle en los detalles de ejecución;
  • Aplicaciones: Se corrigieron los resultados de recuperación incorrectos cuando el valor de la variable estaba vacío en el nodo de recuperación de etiquetas del documento;
  • Base de conocimientos: se solucionó el problema por el cual el documento original no se podía abrir después de descargarlo luego de reemplazarlo (#4397);
  • Modelos: Se corrigió el error de generación del modelo qwen-image del proveedor Alibaba Cloud BaiLian (#4376);
  • Modelos: Se corrigió el error al agregar el modelo gpt-5-codex del proveedor Azure OpenAI;
  • Modelos: Se corrigió la configuración incorrecta de algunos parámetros para los modelos vLLM (#4403);
  • Roles: se solucionó el problema por el cual el permiso "Acerca de" autorizado a los administradores del espacio de trabajo y a los usuarios comunes no surtía efecto;
  • Usuarios de conversación (X-Pack): se solucionó el problema por el cual se mostraba información no esencial en la interfaz de consulta del usuario de conversación;
  • Documentación API (X-Pack): Se revisaron varias descripciones inexactas en la documentación API.

MaxKB v2.4.0

Highlights

  • Security fixes — prioritize this upgrade — Fixes two permission-bypass vulnerabilities: file-overwrite escalation (CVE-2025-66446) and a race-condition bypass (CVE-2025-66419). No workaround is documented, so upgrade rather than relying on configuration changes.

  • Workflow knowledge bases and data-source tools — Adds workflow knowledge bases and first-class data-source tools. The Tool Store now distinguishes Tool from Data Source, and resource imports cover tools, MCPs, and data sources—useful for integrating live systems into retrieval and orchestration rather than relying only on uploaded documents.

  • Tool inventory changed — check existing workflows — System built-in tools were removed from their previous location and moved to the Tool Store. Audit workflows that reference them and add them explicitly where required; the Tool Store entry has also moved into the tool list.

  • Broader multimodal and reranking support — AWS gains vision and reranking models; OpenAI, Ollama, vLLM, Xinference, and Zhipu vision models now support video understanding; Docker AI adds LLM, embedding, and reranking models. Provider-specific bug fixes include Azure OpenAI gpt-5-codex (#4397 references documents; Azure has no PR listed), Alibaba Cloud qwen-image, and vLLM parameter defaults (#4403). Verify model configuration when switching providers.

  • Application prompt behavior changed — AI conversation nodes in advanced applications no longer inject the application name and description into generated prompts. Prompts depending on that injected context may need those instructions moved into explicit node configuration.

  • X-Pack authentication and operational visibility — SAML2 login is now available for centralized identity management. Application uploads accept URL sources, and overview monitoring adds user token-consumption and question-count rankings for usage analysis.

No explicitly declared breaking API changes.

Security Vulnerability Fixes

  • Fixed the permission bypass issue caused by system file overwriting (CVE-2025-66446);
  • Fixed the permission bypass issue caused under specific concurrent conditions (CVE-2025-66419).

Special thanks to GitHub users @yck99, @NikoCat233, and @Threonine for discovering and promptly reporting the above vulnerabilities to the MaxKB open-source community!

New Features

  • Knowledge Base: Added workflow knowledge base;
  • Tools: Added data source tools;
  • Tools: Tools in the Tool Store support two types: "Tool" and "Data Source";
  • Models: AWS provider added support for vision models and reranking models;
  • Models: Vision models of OpenAI, Ollama, vLLM, Xinference, and Zhipu AI providers support video understanding functionality;
  • Models: Added support for large language models, vector models, and reranking models from the Docker AI provider;
  • Applications: Added "URL Address" as an upload method in the file upload settings;
  • Applications: Added ranking statistics for "User Consumed Tokens" and "User Question Count" to the monitoring statistics on the overview page;
  • Resource Authorization: Supported filtering users by role when authorizing applications, knowledge bases, tools, and models to users by resource;
  • Login Authentication (X-Pack): Added SAML2 login authentication method.

Feature Optimizations

  • Applications: The generated prompts of AI conversation nodes in advanced applications no longer carry application names and description information;
  • Applications: Supported outputting request parameters when AI models call MCP tools;
  • Applications: Supported using shortcut keys to copy nodes into loop bodies in advanced orchestration;
  • Tools: Supported importing three types of resources: tools, MCPs, and data sources;
  • Tools: Adjusted the Tool Store entry to the tool list;
  • Tools: Removed system built-in tools and moved them to the Tool Store.

Bug Fixes

  • Q&A Page: Fixed the issue where retrieval results of knowledge base retrieval nodes in loop bodies were not displayed in knowledge sources;
  • Applications: Fixed the incorrect display of execution time for loop nodes in execution details;
  • Applications: Fixed the incorrect retrieval results when the variable value was empty in the document tag retrieval node;
  • Knowledge Base: Fixed the issue where the original document could not be opened after downloading it following replacement (#4397);
  • Models: Fixed the generation error of the qwen-image model from the Alibaba Cloud BaiLian provider (#4376);
  • Models: Fixed the error when adding the gpt-5-codex model from the Azure OpenAI provider;
  • Models: Fixed the incorrect setting of some parameters for vLLM models (#4403);
  • Roles: Fixed the issue where the "About" permission authorized to workspace administrators and ordinary users did not take effect;
  • Conversation Users (X-Pack): Fixed the issue where non-essential information was displayed in the conversation user query interface;
  • API Documentation (X-Pack): Revised several inaccurate descriptions in the API documentation.
