#MaxKBv0.9.1

Nuevas funciones

  • [Gestión de modelos] Los proveedores de Ollama admiten la descarga automática al agregar/modificar modelos. por @wanghe-fit2cloud en el n.° 6
  • [Acerca de] Se agregó la dirección del proyecto, manual de usuario y entrada de ayuda al foro. por @wanghe-fit2cloud en el n.° 5

  • [Base de conocimientos] Se solucionó el problema de que el documento se cancelaría automáticamente después de ser marcado en la lista de documentos.
  • [Gestión de usuarios] Se corrigió el error al eliminar usuarios.
  • [Gestión de usuarios] Está prohibido modificar el nombre de usuario al editar un usuario.
  • [Gestión de usuarios] Los usuarios deshabilitados para la reparación pueden iniciar sesión.
  • [Gestión de usuarios] Al modificar un nombre de usuario que excede la longitud, el mensaje de error es incorrecto.
  • [Gestión de usuarios] Se solucionó el problema de no poder modificar la información del usuario administrador. por @beijingtl en el n.° 12

MaxKB v0.9.1

Highlights

  • Ollama model provisioning — Adding or editing an Ollama model now supports automatic download (#6), eliminating the separate manual pull step. Ensure the MaxKB host has outbound model access and sufficient disk space during setup.
  • Azure and Qianfan provider options — Azure OpenAI base models support custom configuration, but custom setups must explicitly provide api-version (#9); check existing model records before upgrading. Qianfan now supports official hosted standard models rather than only self-deployed ones, enabling vendor-hosted inference.
  • Q&A behavior and prompt optimization — Quick-question submissions are limited to one at a time, so workflows must avoid overlapping requests. The app also no longer errors when prompt optimization is enabled but the model returns no optimization result (#13).
  • TXT ingestion reliability — TXT files with previously problematic encodings no longer yield empty extracted content (#8). Re-upload or rebuild affected knowledge-base documents, since existing broken records are not guaranteed to repair automatically.
  • User administration and access control — Fixes cover user deletion, disabled-account login, admin profile editing (#12), name-length validation messages, and list reordering after status changes. Usernames are now intentionally non-editable, so remove username updates from admin scripts and integrations.
  • Breaking changes — None declared.

新增功能

  • 【模型管理】Ollama 供应商添加/修改模型时支持自动下载。 by @wanghe-fit2cloud in #6
  • 【关于】增加显示项目地址、用户手册、论坛求助入口。 by @wanghe-fit2cloud in #5

功能优化

  • 【模型管理】Azure OpenAI 的基础模型支持自定义设置，自定义时需要填写 api-version。 by @LucienShui in #9
  • 【模型管理】千帆大模型的基础模型支持自定义输入官方标准的大模型（非自行部署）。

问题修复

  • 【应用】问答提问时同一时间限制只能发出一个快捷问题。
  • 【应用】修复问题优化开启后大模型未返回优化结果时的报错问题。 by @beijingtl in #13
  • 【知识库】修复上传的 TXT 文档编码格式问题导致内容为空的问题。 by @cnliucheng in #8
  • 【知识库】修复文档列表勾选文档后会自动取消的问题。
  • 【用户管理】修复删除用户报错。
  • 【用户管理】编辑用户禁止修改用户名。
  • 【用户管理】修复禁用用户可以登录。
  • 【用户管理】修改用户姓名超过长度时错误提示不对。
  • 【用户管理】修复无法修改 admin 用户信息的问题。 by @beijingtl in #12
  • 【用户管理】修复修改用户状态后用户位置变动的问题。
