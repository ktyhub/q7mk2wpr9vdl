Nuevas características

  • Agente: se actualizó el módulo "Aplicación" al módulo "Agente";
  • Agente: se agregó la función de llamada automática de agentes a agentes simples y se fusionaron herramientas, MCP y agentes en la función "Habilidades";

  • Agente: se admite la creación de agentes mediante plantillas en el Centro de plantillas;
  • Agente: se agregó salida de rama de excepción a todos los nodos de capacidad de IA en agentes avanzados para mejorar la tolerancia a fallas del proceso;
  • Agente: se admite la visualización de información de comentarios completada por los usuarios en los detalles del registro de conversaciones;
  • Agente: el componente de parámetro de entrada del usuario en el nodo Información básica admite cuadros de texto de varias líneas, componentes de pestañas de una sola línea y componentes de pestañas de selección múltiple de una sola línea;
  • Agente: los parámetros de entrada en los nodos de herramientas personalizados admiten el tipo booleano;
  • Página de preguntas y respuestas: usuarios admitidos para completar la información de comentarios al enviar comentarios;
  • Base de conocimientos: se admitió la cancelación del proceso de importación de documentos en las bases de conocimientos del flujo de trabajo;
  • Base de conocimientos: se agregó la función de importación/exportación de flujos de trabajo a las bases de conocimientos de flujos de trabajo;
  • Base de conocimientos: visualización admitida de recursos asociados;
  • Herramientas: visualización admitida de recursos asociados;
  • Herramientas: Se agregaron componentes de cuadro de texto y control deslizante JSON a los tipos de componentes en los cuadros de diálogo de parámetros;
  • Carpetas: clasificación admitida por nombre, hora de creación y orden personalizado de arrastrar y soltar;
  • Modelos: visualización admitida de recursos asociados;
  • Autenticación de inicio de sesión (X-Pack): se agregó la función de asignación de roles predeterminada para usuarios de terceros en la configuración de inicio de sesión;
  • Autenticación de inicio de sesión (X-Pack): función de bloqueo de cuenta agregada después de intentos fallidos de inicio de sesión en la configuración de inicio de sesión;
  • Administración de usuarios: se admite la configuración de permisos de recursos predeterminados al crear usuarios;
  • Administración de usuarios (X-Pack): asignación de roles por lotes admitida y eliminación de usuarios por lotes.

Optimizaciones de funciones

  • Agente: se agregó el grupo de usuarios de conversación {{global.chat_user_group}} al nodo de inicio en agentes avanzados;
  • Base de conocimientos: optimizó la interfaz de prueba de impacto para utilizar solicitudes POST;
  • Carpetas: carpetas de autorización admitidas por roles de usuario;
  • Clave API: Las claves API del sistema optimizadas deben ser aisladas por el usuario;
  • Página de preguntas y respuestas: se eliminó el límite de ver solo 20 registros históricos de chat;
  • Página de preguntas y respuestas: se admite la edición y el reenvío de la última pregunta;
  • Página de preguntas y respuestas (X-Pack): función de cierre de sesión admitida para usuarios de conversaciones de terceros después de iniciar sesión en la página de preguntas y respuestas;
  • Sistema: Optimizada la interfaz UI del sistema.

Corrección de errores

  • Vulnerabilidad de seguridad: se corrigió la vulnerabilidad XSS causada por la carga de archivos;
  • Vulnerabilidad de seguridad: se solucionó el problema por el cual el código Python en el módulo de herramientas cargaba bibliotecas de enlaces dinámicos para evitar las restricciones de seguridad;
  • Vulnerabilidad de seguridad: se solucionó el posible problema de RCE causado por la deserializacion de objetos untrusted mediante pickle en Celery;
  • Herramientas: Se corrigió la falsa interceptación de correos electrónicos enviados a través del protocolo SMTP;
  • Agente: se solucionó el problema por el cual la barra de desplazamiento del cuadro desplegable de herramientas en los nodos MCP no podía desplazarse;
  • Agente: se solucionó el problema de estilo donde los detalles de ejecución de la llamada MCP y los nodos de herramientas excedían la pantalla;
  • Agente: se solucionó el problema por el cual los agentes secundarios no podían recibir archivos de video de los agentes principales (#4568);
  • Base de conocimientos: se solucionó el problema de estilo por el cual los componentes de video en los detalles de segmentación excedían el área de detalles de segmentación (#4542);
  • Base de conocimientos: se solucionó el problema por el cual todos los videos se reproducían automáticamente al abrir la página de detalles de segmentación.

MaxKB v2.5.0

Highlights

  • Agent module replaces "Application"; tools/MCP folded into "Skills" (breaking) — v2.5.0 renames the top-level Application module to Agent and consolidates tools, MCP, and sub-agents under a single Skills concept in both simple and advanced agents. Anything referencing the old Application structure needs remapping. Advanced agents also gain automatic agent-calling on AI Conversation nodes, exception-branch outputs on every AI capability node for process fault tolerance, and {{global.chat_user_group}} in the start node; agents can now be created from Template Center templates.

  • Three security fixes make this a recommended upgrade — patched an XSS vulnerability from file uploads, a tool-module sandbox escape where Python loaded dynamic link libraries to bypass security restrictions, and a potential RCE from pickle-deserializing untrusted objects in Celery. Anyone running v2.4.x with untrusted uploads or tool code exposed should upgrade promptly; this is the strongest reason to move.

  • API-facing behavior changes (breaking for integrators) — the knowledge-base hit-test interface now uses POST instead of GET, and system API Keys are isolated per user. Scripts, SDK wrappers, or CI jobs calling hit-test or sharing a system API key across users must be updated.

  • Knowledge base and resource-management additions — workflow knowledge bases gain import/export and cancellation of in-progress document imports; "view associated resources" now spans Knowledge Base, Tools, and Models; folders support role-based authorization and sorting by name, creation time, or custom drag order. Valuable for teams with large shared libraries, but not a standalone reason to upgrade.

  • X-Pack, Q&A, and UX polish (who can skip) — X-Pack adds default role assignment for third-party users, account lockout after failed logins, batch role assignment/deletion, and Q&A-page logout; the Q&A page removes the 20-record history cap and allows editing/re-submitting the last question. Also fixed: child agents not receiving video from parents (#4568), video overflow in segmentation details (#4542), auto-playing videos, false SMTP interception, and MCP/tool UI glitches. Non-X-Pack users not needing these could defer, but the security fixes above still argue for upgrading.

New Features

  • Agent: Upgraded the "Application" module to the "Agent" module;
  • Agent: Added automatic agent calling function to simple agents, and merged tools, MCP, and agents into the "Skills" function;
  • Agent: Added automatic agent calling function to AI Conversation nodes in advanced agents, and merged tools, MCP, and agents into the "Skills" function;
  • Agent: Supported creating agents via templates in the Template Center;
  • Agent: Added exception branch output to all AI capability nodes in advanced agents to enhance process fault tolerance;
  • Agent: Supported displaying feedback information filled by users in conversation log details;
  • Agent: The user input parameter component in the Basic Information node supports multi-line text boxes, single-line tab components, and single-line multi-select tab components;
  • Agent: Input parameters in custom tool nodes support boolean type;
  • Q&A Page: Supported users to fill in feedback information when submitting feedback;
  • Knowledge Base: Supported canceling the document import process in workflow knowledge bases;
  • Knowledge Base: Added workflow import/export function to workflow knowledge bases;
  • Knowledge Base: Supported viewing associated resources;
  • Tools: Supported viewing associated resources;
  • Tools: Added JSON text box and slider components to the component types in parameter dialogs;
  • Folders: Supported sorting by name, creation time, and custom drag-and-drop order;
  • Models: Supported viewing associated resources;
  • Login Authentication (X-Pack): Added default role assignment function for third-party users in login settings;
  • Login Authentication (X-Pack): Added account lockout function after failed login attempts in login settings;
  • User Management: Supported setting default resource permissions when creating users;
  • User Management (X-Pack): Supported batch role assignment and batch user deletion.

Feature Optimizations

  • Agent: Added conversation user group {{global.chat_user_group}} to the start node in advanced agents;
  • Knowledge Base: Optimized the hit test interface to use POST requests;
  • Folders: Supported authorizing folders by user roles;
  • API Key: Optimized system API Keys to be isolated by user;
  • Q&A Page: Removed the limit of only viewing 20 historical chat records;
  • Q&A Page: Supported editing and re-submitting the last question;
  • Q&A Page (X-Pack): Supported logout function for third-party conversation users after logging into the Q&A page;
  • System: Optimized the system UI interface.

Bug Fixes

  • Security Vulnerability: Fixed the XSS vulnerability caused by file uploads;
  • Security Vulnerability: Fixed the issue where Python code in the tool module loaded dynamic link libraries to bypass security restrictions;
  • Security Vulnerability: Fixed the potential RCE issue caused by deserializing untrusted objects via pickle in Celery;
  • Tools: Fixed the false interception of emails sent via the SMTP protocol;
  • Agent: Fixed the issue where the scroll bar of the tool drop-down box in MCP nodes could not scroll;
  • Agent: Fixed the style issue where execution details of MCP call and tool nodes exceeded the screen;
  • Agent: Fixed the issue where child agents could not receive video files from parent agents (#4568);
  • Knowledge Base: Fixed the style issue where video components in segmentation details exceeded the segmentation detail area (#4542);
  • Knowledge Base: Fixed the issue where all videos automatically played when opening the segmentation details page.
