arthas arthas-all-4.1.9

Highlights

  • ClassLoader-level metaspace diagnostics — The new classloader-metaspace command attributes metaspace and class metadata memory to individual ClassLoader instances (#3188). Use it to isolate leaks in dynamic application, plugin, or framework loaders rather than treating all metaspace growth as one pool.

  • Asynchronous MCP tool execution — MCP Server task mode supports long-running calls with status queries and cancellation, while capping concurrent task sessions (#3140, #3182, #3185). Integrations should poll for completion and handle cancellation and capacity limits instead of relying on one blocking request.

  • External commands bundled in the startup JAR — Arthas can now load external commands directly from its launch JAR, with integration tests covering the behavior (#3177). This enables more self-contained command distributions; verify command discovery and packaging when building custom launchers.

  • More reliable diagnostics and command handling — grep -c/--count reports only the number of matching lines; main_class output no longer includes extra arguments (#3150); tt fragment listing avoids an NPE (#3171); and vmtool accepts array class names such as Object[] directly (#3178). Scripts parsing startup output should expect the corrected main_class value.

  • Expanded platform and runtime support — Native loongarch64 support broadens deployment options (#3164). Tunnel Server also moves to Spring Boot 3.5 (patched to 3.5.14), newer Netty, and Eclipse Temurin base images (#3173, #3179, #3181, #3158); operators should validate custom server extensions and container/JDK assumptions against the upgraded stack.

  • Breaking changes — None announced in this release.

变更概览

  • feat: 新增 classloader-metaspace 命令，支持按 ClassLoader 实例统计 metaspace / class metadata 内存，见 #3188
  • feat: MCP Server 支持 task 模式，支持长时间工具调用的异步执行、查询/取消，并限制并发 task session，见 #3140 #3182 #3185
  • feat: 支持从启动 jar 加载外部命令，并补充外部命令集成测试，见 #3177
  • feat: grep 命令新增 -c, --count 选项，只输出匹配行数
  • feat: 新增 loongarch64 平台支持，见 #3164
  • fix: 修复 Arthas 启动时 main_class 展示额外参数的问题，见 #3150
  • fix: 修复 tt 列出 fragments 时可能出现 NPE 的问题，见 #3171
  • fix: vmtool 支持 Object[] 这类数组 className 写法，见 #3178
  • chore: 升级 Tunnel Server 到 Spring Boot 3.5 / 3.5.14，升级 Netty，Docker 基础镜像切换到 Eclipse Temurin，见 #3173 #3179 #3181 #3158
  • docs: 更新 MCP Server、vmtool、retransform 等文档，见 #3151 #3155 #3159
