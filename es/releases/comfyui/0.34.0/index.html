ComfyUI v0.34.0

Highlights

  • MiniMax-H3 matures into a first-class multimodal engine — PR 15439 adds MiniMaxH3AddGuide, letting you anchor image and audio guides at arbitrary frames instead of fixed positions, while 15375 adds per-token video/audio latent noise masks for regional control. Together with taeh3 VAE support (15695), prompt embeddings (15697), missing special tokens (15808), a thinking-handling fix (15611), and the plain single-image Empty Latent Image node now working with H3 (15677), the stack is finally usable in production — expect to rebuild older H3 graphs around the new guide node.

  • Dynamic VRAM reaches AMD, with better failure diagnostics — 15633 enables dynamic VRAM by default on ROCm 7.14+, and 15722 adds friendly errors to the dynamic-VRAM safetensors loader; 15588 fixes MiniMax Music on non-dynamic-VRAM machines. AMD users will see a real memory-management behavior change on upgrade, so re-verify large-model loads rather than assuming prior VRAM settings carry over.

  • Video output gains HDR/AV1/containers — and a breaking widget type — 15741 adds HDR saving, AV1, MKV and WebM; 15764 adds HDR color-space options to H.264; 15810 adds a colorspace option and converts bit_depth from a free value into a combo. Watch out: 15827 raises the minimum pyav version, and the bit_depth type change in 15810 can break saved workflows or API payloads that pass raw integers — re-check every Save/Create Video node after upgrading.

  • Partner Node removals force workflow migration — 15676 drops the Kling v2 image model, 15851 retires the Tripo Refine node and its v2.0 model, 15751 renames the Ideogram P-Image node, and 15655 removes custom price-extractor logic from x-comfy-credits; saved graphs referencing these will error on load. The additions are the flip side: Wan 3.0 (15843), Seedance 2.5 video extension with 1080p (15579, 15684), Seedream Fast Mode (15750), Flux Video Upscale (15753), Pixverse V6 (15880), Meshy-7 (15807), FishAudio (15612) and Gemini 3.7 Flash (15688).

  • 3D generation broadens, with a higher memory floor — 14718 adds Pixal3d and TRELLIS2 support and 14370 adds Sam3d-body, but 15796 raises the TRELLIS2 memory factor — budget more VRAM than earlier benchmarks suggested before committing to long 3D batches.

  • Environment and platform housekeeping with real upgrade implications — 15874 flags Python 3.10 as nearing EOL (test coverage already accepts Python 3.14 math strings, 15645); 15737 limits multi-GPU visibility on Windows and 15813 defaults Windows to the first CUDA device, so Windows multi-GPU users should re-check device selection; 14539 fixes the default database path when using a custom user directory. API consumers should also note 15369, which stops injecting an opaque alpha channel into API node images.
