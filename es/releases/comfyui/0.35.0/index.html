ComfyUI v0.35.0

Highlights

  • Core stability and memory handling — Upgrade is worthwhile for most local users: ComfyUI now respects container cgroup memory limits, reduces Trellis workflow RAM/VRAM usage, and fixes several backend issues, including MPS crashes from int8 quantization and supports_fp64(None). It also enables PyTorch SDPA attention and FP8 operations on AMD gfx1170/gfx1171.

  • Model deprecations require workflow migration — Breaking change: Partner Nodes drops the retiring Veo 2 and Veo 3.0 models. Replace any workflows or API calls referencing them; the changelog also deprecates other retired models without enumerating them, so audit Partner Nodes dependencies before upgrading. No other required migration steps are explicitly documented.

  • New generation and editing capabilities — This release adds MiniMax-H3 Max/Max Turbo, WAN3-Prime, SenseNova U1.5, and Pixal3D multiview support. MiniMax-H3 also gains PDD LoRA support, optional VAE usage, and reference handling. New nodes include File3DToMesh, VideoTrim, VideoCrop, Sparse Attention, color-space conversion, and LTXV keyframe/latent-guide tools—users of these models or workflows should upgrade.

  • Image correctness fixes — Alpha handling is corrected across RGB/YUV conversion, color adjustment, quantization, text overlay, blending, inversion, Canny edge detection, and Porter-Duff blend modes. This is a strong reason to upgrade if you process transparent images or composite RGBA assets; previously affected outputs may need regeneration.

  • Media and UI improvements — Save Image Advanced now supports AVIF, HEVC is remuxed to hvc1 in MP4/MOV, and missing workflow media no longer breaks loading. The frontend, templates, and embedded docs are updated, resolution selection gains a live preview, and the portable install is smaller. Users who only run unaffected workflows can safely skip unless they want these features.
