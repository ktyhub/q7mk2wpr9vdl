perezoso v0.1.917-beta

Qwen3.8-27B está aquí con GGUF dinámicos v3.1, listos para ejecutarse localmente con Unsloth. Esta versión también trae importantes mejoras de rendimiento, una representación de Glass más fluida, bloques de código y Thinking UI renovados, exportaciones de chat HTML/PDF y nuevas funciones de generación de imágenes y agentes de codificación.

Destacados

  • Nuevo Qwen3.8-27B GGUF dinámicos v3.1.
  • Chats más rápidos: Importantes mejoras de rendimiento en la transmisión, el desplazamiento, los menús y los cuadros de diálogo, especialmente en conversaciones largas.
  • Vidrio más fluido: Reducción del retraso al escribir, desplazarse y generar.
  • Bloques de código y pensamiento renovados: Paneles expandibles de desplazamiento independiente con resaltado de sintaxis mejorado.
  • Exportaciones HTML y PDF: Exporta chats directamente desde el menú de chat.
  • Cola de imágenes: Pon en cola las próximas generaciones de imágenes mientras se procesa otra.
  • Claude Code y Codex en MLX: Ejecute agentes de codificación con modelos MLX a través de unsloth start.

Chat y interfaz de usuario

  • El rendimiento de la transmisión ya no se degrada a medida que crecen las conversaciones.
  • Desplazamiento más fluido con imágenes de fondo, con o sin Glass.
  • Menús, cuadros de diálogo y carga del panel del navegador más rápidos.
  • La lectura en voz alta comienza después de la primera frase en lugar de esperar la respuesta completa.
  • Las preferencias de chat, el formato de hora y el corrector ortográfico ahora se sincronizan con su cuenta.

Imágenes y vídeos

  • FLUX.2 y FLUX.3 utilizan 36–43 % menos VRAM durante la decodificación de imágenes a la misma velocidad.
  • Generaciones de imágenes en cola desde la página Imágenes o API.
  • Los modelos de imagen INT8 y FP8 ahora se cargan en GPU NVIDIA más antiguas, incluida la T4.
  • Se corrigieron las salidas de imágenes en negro con FLUX.3.
  • LTX-2.5 FP8 ahora se ejecuta en GPU de 24 GB.
  • Cosmos3-Nano puede continuar el vídeo clips desde el primer o el último fotograma.

Agentes de codificación y API

  • Ejecute Claude Code y Codex con modelos MLX en Mac usando unsloth start.
  • El nuevo ajuste preestablecido de Unsloth MCP permite a los agentes de codificación acceder a las herramientas de Unsloth.
  • Los modelos Claude API sin un límite de tokens explícito ya no se detienen en 1024 tokens.
  • Los modelos MLX ahora devuelven un error de longitud de contexto adecuado en lugar de una respuesta vacía.

Entrenamiento

  • model.generate() ahora es 2 a 8 veces más rápido en GPU T4 de forma predeterminada en todos los modelos FastModel.
  • Las columnas de vídeo ahora son compatibles correctamente al entrenar modelos de visión.
  • El paralelismo contextual de Ulysses ahora admite los modelos de texto Kimi-Linear, DeepSeek, MiniMax y Gemma 4.

unsloth v0.1.917-beta

Qwen3.8-27B is here with Dynamic v3.1 GGUFs, ready to run locally with Unsloth. This release also brings major performance improvements, smoother Glass rendering, revamped code blocks and Thinking UI, HTML/PDF chat exports, and new image generation and coding agent features.

Highlights

  • New Qwen3.8-27B Dynamic v3.1 GGUFs.
  • Faster chats: Major performance improvements to streaming, scrolling, menus and dialogs, especially in long conversations.
  • Smoother Glass: Reduced lag while typing, scrolling and generating.
  • Revamped code blocks and Thinking: Independently scrolling, expandable panels with improved syntax highlighting.
  • HTML and PDF exports: Export chats directly from the chat menu.
  • Image queue: Queue upcoming image generations while another is rendering.
  • Claude Code and Codex on MLX: Run coding agents with MLX models through unsloth start.

Chat & UI

  • Streaming performance no longer degrades as conversations grow.
  • Smoother scrolling with background images, with or without Glass.
  • Faster menus, dialogs and browser pane loading.
  • Read aloud starts after the first sentence instead of waiting for the entire response.
