Desguace v0.3

Desguace v0.3.0 Release Note

🎉 Lanzamiento principal: revisión completa de la arquitectura Scrapling v0.3 representa la actualización más importante en la historia del proyecto, presentando una reescritura arquitectónica completa, mejoras considerables en el rendimiento y nuevas características potentes, incluida la integración de IA y capacidades interactivas del shell Web Scraping. Esta versión incluye múltiples cambios importantes; revise atentamente los release note.

🚀 Nuevas funciones importantes

Arquitectura basada en sesiones

  • Nuevas clases de sesión: reescritura completa que introduce soporte de sesión persistente
    • FetcherSession: solicitudes HTTP con administración de estado persistente que funciona con código sincronizado y asíncrono
    • DynamicSession/AsyncDynamicSession: automatización del navegador manteniendo el navegador abierto hasta que termines
    • StealthySession/AsyncStealthySession - Navegación sigilosa manteniendo el navegador abierto hasta que termines
  • Administración asíncrona de pestañas del navegador: una nueva función de grupo de pestañas a través del argumento max_pages que rota las pestañas del navegador para búsquedas simultáneas del navegador.
  • Sesiones simultáneas: ejecute varias sesiones aisladas simultáneamente Consulte la sección Fetching en el sitio web para obtener más detalles.

Muchas nuevas capacidades sigilosas/anti-bots

  • 🤖 Cloudflare Solver: Resolución automática del desafío Cloudflare Turnstile en StealthyFetcher y sus clases de sesión
  • Suplantación de huellas dactilares del navegador: imite las huellas digitales TLS de los navegadores reales, los encabezados del navegador que coinciden con las versiones, la compatibilidad con HTTP/3 y más con la nueva clase Fetcher
  • Modo oculto mejorado: el modo oculto para DynamicFetcher y sus clases de sesión ahora es más robusto y confiable (también conocido como PlayWrightFetcher)

Integración de IA y servidor MCP

  • Servidor MCP integrado: servidor de protocolo de contexto modelo para scraping web asistido por IA
  • 6 potentes herramientas: get, bulk_get, fetch, bulk_fetch, stealthy_fetch, bulk_stealthy_fetch
  • Extracción inteligente de contenido: convierta páginas web/elementos a Markdown, HTML o extraiga una versión limpia del contenido de texto.
  • Soporte de selector CSS: use el motor Scrapling para apuntar a elementos específicos con precisión antes de entregar el contenido a la IA.
  • Anti-Bot Bypass: maneja Cloudflare Turnstile y otras protecciones
  • Soporte de proxy: use servidores proxy para anonimato y orientación geográfica
  • Suplantación del navegador: imita navegadores reales con huellas digitales TLS, encabezados de navegador reales que coinciden con esa versión y más
  • Procesamiento paralelo: elimine varias URL simultáneamente para mayor eficiencia
  • y más...

Nuevo shell web interactivo Scraping

  • Un nuevo shell: shell IPython personalizado con muchos atajos inteligentes integrados como get, post, put, delete, fetch y stealthy_fetch.
  • Administración de páginas inteligentes: nuevos comandos page y pages para almacenar automáticamente la página actual y el historial de todas las solicitudes realizadas a través del shell
  • Integración de Curl: convierte los comandos curl de DevTools del navegador con funciones uncurl y curl2fetcher en solicitudes Fetcher
  • y más...

Scrape del terminal sin programar

  • Nuevos comandos de extracción: scraping basado en terminal sin programación
    • scrapling extract get/post/put/delete - Solicitudes HTTP simples
    • scrapling extract fetch - Contenido dinámico scraping
    • scrapling extract stealthy-fetch - Desvío anti-bot
  • Descarga páginas web y guarda su contenido en archivos.
  • Convierte HTML a formatos legibles como Markdown, lo mantiene como HTML o simplemente extrae el contenido de texto de la página.
  • Admite selectores CSS personalizados para extraer partes específicas de la página.
  • Maneja solicitudes HTTP y la recuperación a través de navegadores.
  • Altamente personalizable con encabezados personalizados, cookies, servidores proxy y el resto de opciones. Casi todas las opciones disponibles a través del código también son accesibles a través del terminal.
  • y más...

🔧 Mejoras técnicas

Mejoras de rendimiento

  • Fetcher ahora es 4 veces más rápido - ¡Sí, lo has leído bien!
  • DynamicFetcher ahora es ~60% más rápido - Una versión mucho más rápida dependiendo de tu configuración (especialmente el modo oculto)
  • StealthyFetcher ahora es entre un 20% y un 30% más rápido - Usando la nueva estructura y comenzando a usar nuestra implementación en lugar de la interfaz Camoufox Python
  • 50 %+ de aumento de velocidad combinado en los métodos de selección principales (find_by_text, find_similar, find_by_regex, relocate, etc.) 🚀
  • ~10% de aumento de velocidad de los primeros métodos CSS/XPath - css_first y xpath_first ahora son más rápidos que css y xpath
  • Método get_all_text() un 40% más rápido para extracción de contenido
  • Mejora del 20 % en la velocidad en la reubicación de elementos adaptativos
  • Optimización de las propiedades de navegación: propiedades como next, previous, below_elements y más ahora son notablemente más rápidas.
  • Operaciones de limpieza de texto 5 veces más rápida
  • Mejoras en la eficiencia de la memoria con importaciones optimizadas y gastos generales reducidos
  • ⚡ Importaciones ultrarrápidas: tiempo de inicio reducido con carga de módulo optimizada
  • Mejores puntos de referencia: todas las mejoras de velocidad que obtuvo Scrapling lo hicieron mucho más rápido que antes, en comparación con otras bibliotecas (1775 veces más rápido que BeautifulSoup y 5,1 veces más rápido que AutoScraper, consulte puntos de referencia)

Arquitectura/Código Calidad y Calidad de vida

  • Contexto persistente: todos los buscadores basados en navegador ahora usan contexto persistente de forma predeterminada. (También resuelve el n.° 64)
  • Uso de msgspec para validar todos los buscadores basados en navegador muy rápido antes de ejecutar las solicitudes, por lo que ahora es más fácil depurar errores.
  • Todas las cookies devueltas por los buscadores ahora coinciden con el formato aceptado por el mismo buscador. Para que pueda recuperar cookies y pasarlas nuevamente a todos los recuperadores y sus clases de sesión.
  • Liting y formateo más rápido debido a la migración a ruff
  • Sistema de compilación moderno: migrado de setup.py a pyproject.toml 📦
  • Mejores acciones y flujos de trabajo de GitHub para un desarrollo y pruebas más fluidos
  • 🎨 Sugerencias de tipo mejoradas: cobertura de tipo completa con los modernos estándares Python para una mejor compatibilidad y confiabilidad de IDE
  • Base de código más limpia: se eliminó el código inactivo y se optimizaron las funciones principales 🧹
  • 🚀 Compatibilidad con versiones anteriores: se agregaron atajos para mantener la compatibilidad con el código anterior

Cambios importantes

Versión mínima de Python

  • Python 3.10+ Requerido: Se eliminó el soporte para Python 3.9 e inferiores

Nomenclatura de clases y métodos

Estos cambios de nombre tienen como objetivo mejorar la claridad y la coherencia, especialmente para los nuevos usuarios.

  • Adaptor → Selector: se cambió el nombre de la clase de análisis principal (pero aún se puede importar como Adaptor para compatibilidad con versiones anteriores)
  • Adaptors → Selectors: se cambió el nombre de la clase de colección (pero aún se puede importar como Adaptors para compatibilidad con versiones anteriores)
  • auto_match → adaptive: Parámetro renombrado en todos los métodos
  • adaptor_arguments → selector_config: Parámetro de configuración renombrado
  • automatch_domain → adaptive_domain: parámetro de dominio renombrado
  • additional_arguments → additional_args: nombre de parámetro abreviado
  • ⚠️ text/body → content: el parámetro del constructor del selector ahora acepta el formato str y bytes
  • PlayWrightFetcher → DynamicFetcher: se cambió el nombre de la clase de automatización del navegador (pero aún se puede importar como PlayWrightFetcher para compatibilidad con versiones anteriores)
  • DynamicFetcher ya no tiene la lógica/los argumentos de NSTBrowser ya que de todos modos no tiene sentido dejar esta lógica ahora.
  • El argumento sin cabeza de StealthyFetcher ya no puede aceptar 'virtual' como argumento ya que no estamos usando la biblioteca de Camoufox en este momento para nada más que para obtener la ruta de instalación del navegador y el resto de las opciones de inicio.

🐛 Corrección de errores

  • Se corrigió el conteo de niños anidados en etiquetas ignoradas para get_all_text (#61)
  • Se solucionó el problema con la instalación debido a espacios en la ruta ejecutable de Python (#57)
  • Se resolvieron problemas de subprocesos en el almacenamiento con manejo de recursividad mientras la función adaptativa está habilitada.
  • Se corrigieron problemas de precedencia de argumentos usando el patrón Sentinel en FetcherSession.
  • Manejo de tipo de proxy resuelto en StealthyFetcher
  • Se corrigieron conflictos de argumentos referer y google_search.
  • Se corrigieron problemas de inyección de scripts asíncronos y ocultos. 🙏 Un agradecimiento especial a nuestra comunidad de Discord por todas las pruebas, comentarios y contribuciones continuas durante los últimos cuatro meses

Scrapling v0.3

Scrapling v0.3.0 Release Notes

🎉 Major Release — Complete Architecture Overhaul

Scrapling v0.3 represents the most significant update in the project's history, featuring a complete architectural rewrite, considerable performance improvements, and powerful new features, including AI integration and interactive Web Scraping shell capabilities.

This release includes multiple breaking changes; please review the release notes carefully.

🚀 Major New Features

Session-Based Architecture

  • New Session Classes: Complete rewrite introducing persistent session support
    • FetcherSession - HTTP requests with persistent state management that works with both sync and async code
    • DynamicSession/AsyncDynamicSession - Browser automation while keeping the browser open till you finish
    • StealthySession/AsyncStealthySession - Stealth browsing while keeping the browser open till you finish
  • Async Browser Tabs Management: A new pool of tabs feature through the max_pages argument that rotates browser tabs for concurrent browser fetches
  • Concurrent Sessions: Run multiple isolated sessions simultaneously

Refer to the Fetching section on the website for more details.

A lot of new stealth/anti-bot Capabilities

  • 🤖 Cloudflare Solver: Automatic Cloudflare Turnstile challenge solving in StealthyFetcher and its session classes
  • Browser fingerprint impersonation: Mimic real browsers' TLS fingerprints, version-matching browser headers, HTTP/3 support, and more with the all-new Fetcher class
  • Improved stealth mode: The stealth mode for DynamicFetcher and its session classes is now more robust and reliable (AKA PlayWrightFetcher)

AI Integration & MCP Server

  • Built-in MCP Server: Model Context Protocol server for AI-assisted web scraping
  • 6 Powerful Tools: get, bulk_get, fetch, bulk_fetch, stealthy_fetch, bulk_stealthy_fetch
  • Smart Content Extraction: Convert web pages/elements to Markdown, HTML, or extract a clean version of the text content
  • CSS Selector Support: Use the Scrapling engine to target specific elements with precision before handing the content to the AI
  • Anti-Bot Bypass: Handle Cloudflare Turnstile and other protections
  • Proxy Support: Use proxies for anonymity and geo-targeting
  • Browser Impersonation: Mimic real browsers with TLS fingerprinting, real browser headers matching that version, and more
  • Parallel Processing: Scrape multiple URLs concurrently for efficiency
  • and more...

New Interactive Web Scraping Shell

  • A New Shell: Custom IPython shell with many smart Built-in Shortcuts like get, post, put, delete, fetch, and stealthy_fetch
  • Smart Page Management: New commands page and pages to automatically store the current page and history for all requests done through the shell
  • Curl Integration: Convert browser DevTools curl commands with uncurl and curl2fetcher functions to Fetcher requests
  • and more...

Scrape from the terminal without programming

  • New Extract Commands: Terminal-based scraping without programming
    • scrapling extract get/post/put/delete - Simple HTTP requests
    • scrapling extract fetch - Dynamic content scraping
    • scrapling extract stealthy-fetch - Anti-bot bypass
  • Downloads web pages and saves their content to files.
  • Converts HTML to readable formats like Markdown, keeps it as HTML, or just extracts the text content of the page.
  • Supports custom CSS selectors to extract specific parts of the page.
  • Handles HTTP requests and fetching through browsers.
  • Highly customizable with custom headers, cookies, proxies, and the rest of the options. Almost all the options available through the code are also accessible through the terminal.
  • and more...

🔧 Technical Improvements

Performance Enhancements

  • Fetcher is now 4 times faster - Yes you have read it right!
  • DynamicFetcher is now ~60% faster - A much faster version depending on your config (especially stealth mode)
  • StealthyFetcher is now 20–30% faster - Using the new structure, and starting to use our implementation instead of Camoufox Python interface
  • 50%+ combined speed gains across core selection methods (find_by_text, find_similar, find_by_regex, relocate, etc.) 🚀
  • ~10% CSS/XPath first methods speed increase - css_first and xpath_first are now faster than css and xpath
  • 40% faster get_all_text() method for content extraction
  • 20% speed improvement in adaptive element relocation
  • Navigation properties optimization — Properties like next, previous, below_elements, and more are now noticeably faster
  • 5x faster text cleaning operations
  • Memory efficiency improvements with optimized imports and reduced overhead
  • ⚡ Lightning-fast imports: Reduced startup time with optimized module loading
  • Better benchmarks: All the speed improvements Scrapling got made it much faster than before, compared to other libraries (1775x faster than BeautifulSoup and 5.1x faster than AutoScraper, check benchmarks)

Architecture/Code Quality, and Quality of life

  • Persistent Context: All browser-based fetchers now use persistent context by default. (Solves #64 too)
  • Using msgspec to validate all browser-based fetchers very fast before running the requests, so now it's easier to debug errors.
  • All cookies returned from fetchers are now matching the format accepted by the same fetcher. So you can retrieve cookies and pass them again to all fetchers and their session classes.
  • Faster linting and formatting due to migrating to ruff
  • Modern Build System: Migrated from setup.py to pyproject.toml 📦
  • Better GitHub actions and workflows for smoother development and testing
  • 🎨 Enhanced Type Hints: Complete type coverage with modern Python standards for better IDE support and reliability
  • Cleaner Codebase: Removed dead code and optimized core functions 🧹
  • 🚀 Backward Compatibility: Added shortcuts to maintain compatibility with older code

Highlights

  • Session-based architecture rewrite — The core one-shot fetcher model is replaced with persistent, stateful sessions: FetcherSession (sync + async HTTP with retained state), DynamicSession/AsyncDynamicSession and StealthySession/AsyncStealthySession (browser stays open until you're done), plus concurrent isolated sessions and a max_pages tab pool for concurrent browser fetches. This matters because cookie/session state and browser startup cost are no longer lost between requests — a real shift in how you structure crawlers.

  • Breaking renames and a Python 3.10 floor — Python 3.9 and below are dropped. Classes are renamed Adaptor→Selector, Adaptors→Selectors, PlayWrightFetcher→DynamicFetcher (import aliases keep old names working), but the keyword-argument renames have no such safety net: auto_match→adaptive, adaptor_arguments→selector_config, automatch_domain→adaptive_domain, additional_arguments→additional_args, and text/body→content (now accepts str or bytes). Audit call sites for keyword args, not just imports. Also note DynamicFetcher loses NSTBrowser logic/args, and StealthyFetcher no longer accepts headless='virtual'.

  • Major performance gains — Fetcher is ~4× faster, DynamicFetcher ~60%, StealthyFetcher 20–30%, core selection methods (find_by_text, find_similar, find_by_regex, relocate) 50%+, get_all_text() 40%, text cleaning 5×, with faster imports and lower memory overhead. For high-volume crawlers this is the most immediately felt change; the project cites 1775× BeautifulSoup / 5.1× AutoScraper in its benchmarks.

  • AI/MCP server, interactive shell, and CLI scraping — A built-in MCP server exposes six tools (get, bulk_get, fetch, bulk_fetch, stealthy_fetch, bulk_stealthy_fetch) with Markdown/HTML/text extraction and CSS-selector targeting, letting AI agents scrape with anti-bot bypass, proxies, and browser impersonation. A custom IPython shell adds shortcuts (get, post, fetch, stealthy_fetch), page/pages history, and curl-to-Fetcher conversion via uncurl/curl2fetcher. New scrapling extract commands bring the same options to the terminal without writing code — a meaningful onboarding path for non-programmers and agent workflows.

  • Stronger stealth/anti-bot capabilities — StealthyFetcher and its sessions now auto-solve Cloudflare Turnstile challenges, and the new Fetcher impersonates browser TLS fingerprints with version-matched headers and HTTP/3 support; stealth mode in DynamicFetcher is more robust. The move away from Camoufox's Python interface (now only used for browser install paths/launch options) is why headless 'virtual' was dropped and contributes to the speedups.

  • Behavioral changes and targeted fixes worth checking — All browser fetchers now use persistent context by default (#64), requests are validated up front with msgspec for clearer errors, and returned cookies now round-trip into any fetcher/session. Bug fixes include nested-child counting in get_all_text (#61), installs failing on paths with spaces in the Python executable (#57), adaptive-storage threading recursion, proxy type handling in StealthyFetcher, and referer/google_search conflicts — relevant if you relied on any of those edge cases.

Breaking Changes

Minimum Python Version

  • Python 3.10+ Required: Dropped support for Python 3.9 and below

Class and Method Naming

These renamings are intended to improve clarity and consistency, particularly for new users.

  • Adaptor → Selector: Core parsing class renamed (But still can be imported as Adaptor for backward compatibility)
  • Adaptors → Selectors: Collection class renamed (But still can be imported as Adaptors for backward compatibility)
  • auto_match → adaptive: Parameter renamed across all methods
  • adaptor_arguments → selector_config: Configuration parameter renamed
  • automatch_domain → adaptive_domain: Domain parameter renamed
  • additional_arguments → additional_args: Shortened parameter name
  • ⚠️ text/body → content: Selector constructor parameter is now accepting both str and bytes format
  • PlayWrightFetcher → DynamicFetcher: Browser automation class renamed (But still can be imported as PlayWrightFetcher for backward compatibility)
  • DynamicFetcher doesn't have the NSTBrowser logic/arguments anymore since it's pointless to leave this logic now anyway.
  • StealthyFetcher's headless argument can't accept 'virtual' as an argument anymore since we are not using Camoufox's library right now in anything other than getting the browser installation path and the rest of the launch options

🐛 Bug Fixes

  • Fixed nested children counting in ignored tags for get_all_text (#61)
  • Fixed the issue with installation due to spaces in Python's executable path (#57)
  • Resolved threading issues in storage with recursion handling while the adaptive feature is enabled
  • Fixed argument precedence issues using the Sentinel pattern in FetcherSession
  • Resolved proxy type handling in StealthyFetcher
  • Fixed referer and google_search argument conflicts
  • Fixed async stealth script injection problems
