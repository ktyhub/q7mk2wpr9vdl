grafificar v0.9.102

grafificar 0.9.102

Una gran versión de corrección, rendimiento y flujo de trabajo que abarca los extractores, la capa de consulta, la actualización incremental, los enlaces, el libro de ejecución de habilidades y la instalación.

Resolución de llamadas (extractores)

  • ir: las llamadas de miembros del mismo archivo se resuelven según el tipo de receptor; los receptores pkg.T de paquetes cruzados se vinculan únicamente mediante la importación del archivo; El método de interfaz llama al envío a implementadores implícitos (#4966, #4853, #4934).
  • rust: las llamadas calificadas por módulo (crate::b::helper()) resuelven archivos cruzados; las llamadas dentro de los argumentos de la macro expresión están vinculadas (#4944, #4945).
  • kotlin: las llamadas sobrecargadas y de bloque init {} se resuelven; Se cortan las llamadas heredadas externas inalcanzables (#4956).
  • python: las llamadas a miembros de un singleton a nivel de módulo se resuelven a través de su tipo; una llamada a un método simple ya no se vincula automáticamente (#4972, #4933).
  • js/ts: la clase extends a través de CommonJS requiere resolución; una plantilla etiquetada mecanografiada y una anotación import("mod").T<X> que ya no se analiza a medias ni genera un borde dynamic_import falso; Los métodos de objetos exportados por defecto se resuelven (#4700, #4976, #4967).
  • solidez: las importaciones ../ se resuelven en el archivo real (#4985).
  • cpp: escritura del receptor desde parámetros/campos, vinculación del propietario del encabezado dividido, supresión de llamadas locales, ortografía exacta del alias de tipo (#4946, #4920, #4921, #4951).

Consulta

  • Los nodos de origen se clasifican por encima de las pruebas y los documentos (un peso suave, no una exclusión) y las respuestas se ubican primero en el archivo (#4982).
  • graphify query lee query_budget/query_depth de .graphifyrc y obtiene una bandera --depth (#4760).

Actualización incremental/ver

  • graphify update vuelve a extraer sólo los archivos cuyo contenido cambió, con un gráfico idéntico a una reconstrucción completa; una solicitud incremental en disputa se registra en lugar de descartarse (#4800, #4801, #4802).

Construir/caché

  • La protección contra escritura ya no cuenta los pliegues fantasma o desduplicados intencionales como nodos eliminados; la evidencia semántica de fuentes independientes sobrevive a un pliegue; Las claves de caché conservan mayúsculas y minúsculas (#4957, #4952, #4927, #4950, #4937).

Ganchos

  • Un archivo cuyo contenido no ha cambiado no se vuelve a marcar como obsoleto por mtime; un Grep dedicado está retenido en la estricta puerta de orientación; las búsquedas externas no emiten ninguna pista de proyecto (#4974, #4973, #4979).

Rendimiento

  • Menor pico de memoria en carga, resolución y extracción, y un redireccionamiento entre archivos más rápido, todo con resultados idénticos (#4960, #4958, #4959, #4981).

Habilidad / instalación

  • El runbook --update vuelve a poner en cola los documentos parcialmente leídos en lugar de marcarlos como terminados; Paso 4 hilos --force; se agrega un informe de derivación del concentrador; La desinstalación elimina el registro de habilidades globales (#4816, #4805, #4704, #4975). El esquema de caché AST aumenta a 37; Los cachés calientes vuelven a ejecutar las extracciones afectadas. graphify v0.9.102

graphify 0.9.102

A large correctness, performance and workflow release spanning the extractors, the query layer, incremental update, the hooks, the skill runbook and install.

Call-resolution (extractors)

  • go: same-file member calls resolve through the receiver's type; cross-package pkg.T receivers bind only via the file's import; interface method calls dispatch to implicit implementers (#4966, #4853, #4934).
  • rust: module-qualified calls (crate::b::helper()) resolve cross-file; calls inside expression-macro arguments are linked (#4944, #4945).
  • kotlin: overloaded and init {}-block calls resolve; unreachable external-inherited calls are dropped (#4956).
  • python: a module-level singleton's member calls resolve through its type; a bare method call no longer self-binds (#4972, #4933).
  • js/ts: class extends through a CommonJS require resolves; a typed tagged template and an import("mod").T<X> annotation no longer half-parse or mint a false dynamic_import edge; default-exported object methods resolve (#4700, #4976, #4967).
  • solidity: ../ imports resolve to the real file (#4985).
  • cpp: receiver typing from params/fields, split-header owner binding, local-callable suppression, type-alias exact-spelling (#4946, #4920, #4921, #4951).

Query

  • Source nodes rank above tests and docs (a soft weight, not exclusion), and answers are file-first (#4982).
  • graphify query reads query_budget/query_depth from .graphifyrc and gains a --depth flag (#4760).

Incremental update / watch

  • graphify update re-extracts only the files whose content changed, with a graph identical to a full rebuild; a contended incremental request is recorded instead of dropped (#4800, #4801, #4802).

Build / cache

  • The write guard no longer counts intentional ghost folds or dedup folds as dropped nodes; independently-sourced semantic evidence survives a fold; cache keys are case-preserving (#4957, #4952, #4927, #4950, #4937).

Hooks

  • A file unchanged in content is not re-flagged stale by mtime; a dedicated Grep is held to the strict orientation gate; external searches emit no project hint (#4974, #4973, #4979).

Performance

  • Lower peak memory in load, resolution and extraction, and a faster cross-file repoint — all with identical output (#4960, #4958, #4959, #4981).

Skill / install

  • The --update runbook re-queues partly-read docs instead of stamping them done; Step 4 threads --force; a hub-bypass report is added; uninstall removes the global skill registration (#4816, #4805, #4704, #4975).

The AST cache schema is bumped to 37; warm caches re-run the affected extractions.
