grafificar v0.9.99

0.9.99 (2026-10-30)

  • Proeza: ruta cuando varias rutas coinciden en longitud, graphify path y la herramienta MCP shortest_path informan la más conservadora: entre todas las rutas más cortas, se elige la ruta cuyo salto más débil es el más débil, y el resumen señala que fue la más débil de N rutas de igual longitud. Anteriormente se devolvía una ruta arbitraria de igual longitud, por lo que la confianza podría exagerar la seguridad de la conexión. Esta es la segunda mitad del n.° 4881 (la primera mitad, que mantiene la evidencia más débil de un borde colapsado en also_seen, enviada en 0.9.98 a través del n.° 4891, gracias @SyedFahad7).
  • Solución: go una llamada en un inicializador var a nivel de paquete (incluso dentro de un cierre literal de función, el patrón de gancho intercambiable común) se acredita al nodo de archivo en lugar de descartarse (#2360, #4867, gracias @nothariharan).
  • Solución: go un valor de método pasado como argumento de función (Wrap(s.Health)) está vinculado como indirect_call, lo que lleva a Go a la paridad con Python/JS para devolución de llamada por valor de método; protegido de forma conservadora contra falsos positivos de acceso al campo (#1566, #4868, gracias @nothariharan).
  • Solución: go se escribe el campo de un receptor cuya estructura está declarada en un archivo hermano del mismo paquete, por lo que las llamadas de sus miembros se resuelven a través del diseño habitual de estructura-aquí-métodos-allá Go, y los tipos de campo persisten a través de reconstrucciones incrementales (#3368, #4866, gracias @nothariharan).
  • Solución: python Los valores module.func enumerados en una tabla de distribución ({"a": mod.func_a}, incluidas las colecciones anidadas) se resuelven en las funciones a las que se hace referencia como indirect_call en lugar de eliminarse; Los valores no invocables, de clase y del receptor local se dejan solos (#1566, #4773, gracias @nothariharan).
  • Solución: instalar gemini obtiene su propio directorio de habilidades global (~/.gemini/skills/graphify) en Windows en lugar de colisionar con el directorio de la plataforma agents; se anota una habilidad agents preexistente, no se elimina (#2800, #4770, gracias @nothariharan).
  • Solución: instalar el complemento global OpenCode está escrito en ~/.config/opencode (ubicado junto con la habilidad global) en lugar del directorio actual, con la instalación/desinstalación/actualización mantenida simétrica y las ubicaciones heredadas aún limpias (#3398, #4771, gracias @nothariharan).
  • Documentos: habilidad "Sigue estos pasos en orden. No te saltes los pasos". La instrucción se reformula como "a menos que se aplique la ruta rápida anterior", resolviendo la contradicción con la ruta rápida del gráfico existente en todos los hosts generados (#4061, #4721, gracias @nothariharan).
  • Hazaña: servir path, explain y neighbors/get_neighbors imprimen el confidence_score almacenado de un borde junto con su etiqueta ([INFERRED 0.75]); EXTRACTED permanece desnudo (1.0 por definición) y una puntuación faltante o no finita mantiene la etiqueta desnuda. Se compone con el resumen de la ruta de salto más débil y las etiquetas de evidencia also_seen (#4882, #4888, gracias @SyedFahad7).

graphify v0.9.99

0.9.99 (2026-10-30)

  • Feat: path when several routes tie on length, graphify path and the MCP shortest_path tool report the most conservative one: among all shortest paths, the route whose weakest hop is weakest is chosen, and the summary notes it was the weakest of N equal-length routes. Previously an arbitrary equal-length route was returned, so the confidence could overstate how sure the connection is. This is the second half of #4881 (the first half, keeping a collapsed edge's weaker evidence in also_seen, shipped in 0.9.98 via #4891, thanks @SyedFahad7).
  • Fix: go a call in a package-level var initialiser (including inside a func-literal closure, the common swappable-hook pattern) is credited to the file node instead of being dropped (#2360, #4867, thanks @nothariharan).
  • Fix: go a method value passed as a function argument (Wrap(s.Health)) is linked as an indirect_call, bringing Go to parity with Python/JS for callback-by-method-value; conservatively guarded against field-access false positives (#1566, #4868, thanks @nothariharan).
  • Fix: go a receiver's field whose struct is declared in a sibling file of the same package is typed, so its member calls resolve across the usual struct-here-methods-there Go layout, and the field types persist across incremental rebuilds (#3368, #4866, thanks @nothariharan).
  • Fix: python module.func values listed in a dispatch table ({"a": mod.func_a}, including nested collections) resolve to the referenced functions as indirect_calls instead of being dropped; non-callable, class, and local-receiver values are left alone (#1566, #4773, thanks @nothariharan).
  • Fix: install gemini gets its own global skill dir (~/.gemini/skills/graphify) on Windows instead of colliding with the agents platform's dir; a pre-existing agents skill is noted, not deleted (#2800, #4770, thanks @nothariharan).
  • Fix: install the global OpenCode plugin is written to ~/.config/opencode (co-located with the global skill) instead of the current directory, with install/uninstall/refresh kept symmetric and legacy locations still cleaned up (#3398, #4771, thanks @nothariharan).
  • Docs: skill the "Follow these steps in order. Do not skip steps." instruction is reworded to "unless the fast path above applies," resolving the contradiction with the existing-graph fast path across all generated hosts (#4061, #4721, thanks @nothariharan).
  • Feat: serve path, explain and neighbors/get_neighbors print an edge's stored confidence_score alongside its tag ([INFERRED 0.75]); EXTRACTED stays bare (1.0 by definition) and a missing or non-finite score keeps the bare tag. Composes with the weakest-hop path summary and the also_seen evidence tags (#4882, #4888, thanks @SyedFahad7).
