grafificar v0.9.103

grafificar 0.9.103

Una versión amplia de corrección, rendimiento y solidez en los extractores, la resolución, los enlaces, las rutas de consulta y actualización, la instalación y el libro de ejecución de habilidades.

Extractores

  • C#: las directivas del preprocesador y las ramas #if que descarrilan al cuidador de árboles se borran antes del análisis (preservación de la longitud de bytes), por lo que una directiva ya no cierra una clase antes de tiempo y descarta miembros o llamadas posteriores.
  • Solididad: las llamadas a la biblioteca (Lib.f(), incluidas las importaciones con alias) y emit/revert/require que nombran un evento o error declarado ahora se vinculan al miembro al que nombran, vinculados a un tipo y miembro visibles únicos.
  • YAML: una secuencia de fusión << proporciona la precedencia de anclaje anterior para una clave duplicada, que coincide con la especificación y PyYAML.
  • Markdown: un intervalo de código escrito como un espacio de nombres de barra invertida (\Foo\Bar) o un miembro calificado de tipo (Type::member) se resuelve en el nodo real; ya no se elimina una mención con puntos cuyo nombre de método es un lenguaje incorporado.
  • Python: una llamada incorporada con nombre (raise NotImplementedError(...)) ya no se vincula a una clase con el mismo nombre en otro módulo a menos que se importe.

Resolución

  • Una llamada dentro de un def _main() de nivel superior se atribuye a _main, no al main público con el que choca después de la normalización de ID, sin atribuir erróneamente la referencia de tipo de un miembro de la clase.

Ganchos

  • Un archivo cuyo contenido no ha cambiado no se vuelve a marcar como obsoleto por mtime (el hash de extracción se compara con el manifiesto).
  • Un Grep dedicado se mantiene en la estricta puerta de orientación; una lectura de archivo Bash (cat/head/sed -n) de un archivo de código en el proyecto obtiene el empujón de lectura; una búsqueda cuyos objetivos estén fuera del proyecto no emite ninguna pista del proyecto; el presupuesto de impulso se restablece después de una compactación del Código Claude; y el ancla de nivel superior sigue funcionando cuando se exporta CDPATH.

Rendimiento

  • Menor pico de memoria en carga, resolución y extracción; un repunte de archivos cruzados #3252 más rápido; y el pase de reconciliación de vigilancia resuelve la propiedad de AST una vez por archivo en lugar de volver a leer cada encabezado por nodo, todo con una salida gráfica idéntica.

Actualización/compilación/caché

  • graphify update vuelve a extraer sólo los archivos cuyo contenido cambió (idéntico a una reconstrucción completa); una solicitud incremental en disputa se registra en lugar de descartarse. La protección contra escritura de construcción ya no cuenta los pliegues fantasma/desactivados intencionales como caídas; Las claves de caché mantienen su caso escrito.

Consulta/árbol

  • Los nodos de origen se clasifican por encima de las pruebas y los documentos (un peso suave) con respuestas que priorizan el archivo; query lee query_budget/query_depth de .graphifyrc y gana --depth. export tree limita los elementos secundarios del directorio y al mismo tiempo informa los totales completos.

Instalar/seguridad de subprocesos

  • La habilidad del proyecto Pi está escrita en .pi/skills; La desinstalación elimina el registro de habilidad global que escribió. La raíz del escaneo ambiental se mantiene en un ContextVar para que los llamadores simultáneos de la biblioteca que extraen diferentes raíces no se golpeen entre sí. El esquema de caché AST se eleva a 39; Los cachés calientes vuelven a ejecutar las extracciones afectadas. graphify v0.9.103

graphify 0.9.103

A broad correctness, performance and robustness release across the extractors, resolution, hooks, the query and update paths, install and the skill runbook.

Extractors

  • C#: preprocessor directives and #if branches that derail tree-sitter are blanked before parsing (byte-length preserving), so a directive no longer closes a class early and drops later members or calls.
  • Solidity: library calls (Lib.f(), including aliased imports) and emit/revert/require naming a declared event or error now link to the member they name, gated to a unique visible type and member.
  • YAML: a << merge sequence gives the earlier anchor precedence for a duplicated key, matching the spec and PyYAML.
  • Markdown: a code span written as a backslash namespace (\Foo\Bar) or a type-qualified member (Type::member) resolves to the real node; a dotted mention whose method name is a language builtin is no longer dropped.
  • Python: a bare builtin-named call (raise NotImplementedError(...)) no longer binds to a same-named class in another module unless imported.

Resolution

  • A call inside a top-level def _main() is attributed to _main, not the public main it collides with after id normalization, without misattributing a class member's type reference.

Hooks

  • A file unchanged in content is not re-flagged stale by mtime (the extraction hash is checked against the manifest).
  • A dedicated Grep is held to the strict orientation gate; a Bash file read (cat/head/sed -n) of an in-project code file gets the read nudge; a search whose every target is outside the project emits no project hint; the nudge budget is restored after a Claude Code compaction; and the toplevel anchor keeps working when CDPATH is exported.

Performance

  • Lower peak memory in load, resolution and extraction; a faster #3252 cross-file repoint; and the watch reconcile pass resolves AST ownership once per file instead of re-reading each header per node — all with identical graph output.

Update / build / cache

  • graphify update re-extracts only the files whose content changed (identical to a full rebuild); a contended incremental request is recorded instead of dropped. The build write guard no longer counts intentional ghost/dedup folds as drops; cache keys keep their written case.

Query / tree

  • Source nodes rank above tests and docs (a soft weight) with file-first answers; query reads query_budget/query_depth from .graphifyrc and gains --depth. export tree caps directory children while reporting full totals.

Install / thread-safety

  • The Pi project skill is written to .pi/skills; uninstall removes the global skill registration it wrote. The ambient scan root is held in a ContextVar so concurrent library callers extracting different roots do not clobber each other.

The AST cache schema is bumped to 39; warm caches re-run the affected extractions.
