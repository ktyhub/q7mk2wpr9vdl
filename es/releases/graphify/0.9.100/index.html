grafificar v0.9.100

0.9.100 (2026-11-01)

  • Solución: ids un tipo y una función cuyos nombres difieren solo en caso de que (Foo la clase, foo la función) obtengan identificadores de nodo distintos en lugar de colisionar (lo que eliminó un nodo y generó un auto-bucle falso) (#4904, #4908, gracias @bercedev).
  • Solución: php un acceso Scope::MEMBER en un inicializador de nivel de clase (un valor constante, una propiedad predeterminada o un parámetro/constructor promocionado predeterminado) emite una ventaja references_constant; self::/static::/parent:: se omiten y los visores desconocidos no tienen resguardo (#4648, #4895, gracias @Jitendarmahara).
  • Solución: hooks la salida git rev-parse se decodifica como UTF-8, por lo que un árbol de trabajo vinculado bajo una ruta que no es ASCII se resuelve correctamente en Windows en lugar de mojibake (#4903, gracias @LukeTheoJohnson).
  • Solución: analizar en un gráfico de solo código, el motivo de la pregunta de nodo aislado dice "posibles bordes faltantes" en lugar de hacer referencia a lagunas de documentación que no se pueden aplicar (#4887, gracias @oleksii-tumanov).
  • Rendimiento: resolve los bordes de referencia se indexan por fuente una vez, por lo que la resolución de importación JS/TS ya no recorre cada borde por importación (salida sin cambios) (#4909, #4913, gracias @Deepjyoti-Sarmah).
  • Documentos: habilidad la habilidad ahora dice cuándo vale la pena crear un gráfico, en todos los hosts generados, al tiempo que conserva la invariante "si el usuario invocó /graphify, hágalo como se le pidió" (#4829, #4906, gracias @TanmayShah29).
  • Solución: deps el valor extra de video limita PyAV por debajo de 19 (av>=11,<19), porque PyAV 19 eliminó el argumento de metadata_errors de que el susurro más rápido pasa incondicionalmente al abrir audio; sin el límite, una instalación nueva en Python 3.12+ no pudo transcribir (#4842, gracias @SyedFahad7).
  • Solución: r setClass/setRefClass La herencia S4/R5 declarada con contains= ahora emite una ventaja de herencia (anteriormente solo se reconocía el inherit= de R6Class) (#4902, gracias @ayushcodes10).
  • Solución: elixir una llamada de función simple se resuelve en una función en el propio módulo de la persona que llama antes que otros módulos, en lugar de vincularse a la última definición del mismo nombre recorrida (#4900, gracias @ayushcodes10).
  • Solución: dardo una cláusula mixin on A, B resuelve todas las restricciones de superclase, no solo la primera (#4899, gracias @ayushcodes10).
  • Solución: fortran el extends(base) de un tipo derivado emite una ventaja heredada, lo que alinea a Fortran con los otros extractores de programación orientada a objetos (#4897, gracias @ayushcodes10).
  • Solución: scala un extension (x: T) def m tiene como alcance su tipo de receptor T (un borde method para T) en lugar de filtrarse al alcance del archivo (#2044, #4856, gracias @divakantpandey).
  • Solución: terraform un nodo lleva su alcance original para que los identificadores permanezcan estables cuando se mueve un directorio de proyecto almacenado en caché, en lugar de volver a derivar el alcance de la nueva ruta (#4858, #4861, gracias @yUm1k4).
  • Solución: extraer (JVM) Las importaciones de Java y Kotlin, extends/implements y las llamadas de miembros se resuelven entre archivos y entre los dos idiomas cuando un FQN escrito nombra exactamente un tipo de origen (#4874, #4879, gracias @Deepjyoti-Sarmah).
  • Solución: exportar una representación de ruta/explicación/wiki enumera cada relación paralela entre dos nodos (a través de edge_datas), y una escritura sin formato --no-cluster marca el gráfico multigraph para que los bordes paralelos sobrevivan a la recarga (#4794, gracias @ensell-yes).
  • Solución: exportar una copia de seguridad parcial o fallida se informa como sin copia de seguridad y se vuelve a intentar en la siguiente ejecución, en lugar de registrarse como un éxito falso (#3769, #4834, gracias @barlowa124).
  • Solución: afectado graphify affected (y query --seed) resuelven los mismos formularios de referencia path::Symbol y punteados que acepta explain, reutilizan el solucionador de explicación y salen con un valor distinto de cero (3 ambiguos / 4 no encontrados) en una semilla que no se resuelve (#4792, #4797, gracias @dupeisen).
  • Solución: instalar graphify uninstall elimina la habilidad de alcance de usuario de cada plataforma (13 quedaron atrás) y el comando global kilo; y graphify kilo uninstall elimina el sidecar references/ de la habilidad kilo (#4782, #4789, gracias @bercedev).
  • Hazaña: llm el backend de Claude almacena en caché su indicador del sistema (estable, grande) con cache_control, contando los tokens almacenados en caché nuevamente en input_tokens, y GRAPHIFY_CLAUDE_PROMPT_CACHE=0 lo desactiva para las puertas de enlace que rechazan cache_control (#4835, #4855, #4880, gracias @Jvxoq y @1akashkalita).
  • Solución: mensaje la descripción del formato de ID de nodo en el mensaje de extracción coincide con lo que realmente produce ids.py (caracteres de palabras conservados, letras/dígitos no ASCII preservados, ASCII en minúsculas) en lugar de la redacción obsoleta "solo [a-z0-9_]" (#4432, #4799, gracias @dupeisen).
  • Documentos: cómo funciona se actualiza el recuento de idiomas admitidos (alrededor de 40: 33 gramáticas de cuidado de árboles más 7 analizadores integrados) y se describe que el paso 3 ejecuta el backend de LLM configurado, no solo Claude (#4873, gracias @SyedFahad7).

graphify v0.9.100

0.9.100 (2026-11-01)

  • Fix: ids a type and a function whose names differ only in case (Foo the class, foo the function) get distinct node ids instead of colliding (which dropped one node and minted a bogus self-loop) (#4904, #4908, thanks @bercedev).
  • Fix: php a Scope::MEMBER access in a class-level initializer (a const value, a property default, or a parameter/promoted-constructor default) emits a references_constant edge; self::/static::/parent:: are skipped and unknown scopes mint no stub (#4648, #4895, thanks @Jitendarmahara).
  • Fix: hooks git rev-parse output is decoded as UTF-8, so a linked worktree under a non-ASCII path resolves correctly on Windows instead of mojibake (#4903, thanks @LukeTheoJohnson).
  • Fix: analyze on a code-only graph the isolated-node question reason says "possible missing edges" rather than referencing documentation gaps that cannot apply (#4887, thanks @oleksii-tumanov).
  • Perf: resolve reference edges are indexed by source once, so JS/TS import resolution no longer re-walks every edge per import (output unchanged) (#4909, #4913, thanks @Deepjyoti-Sarmah).
  • Docs: skill the skill now says when a graph is worth building, across all generated hosts, while preserving the "if the user invoked /graphify, do it as asked" invariant (#4829, #4906, thanks @TanmayShah29).
  • Fix: deps the video extra caps PyAV below 19 (av>=11,<19), because PyAV 19 removed the metadata_errors argument that faster-whisper passes unconditionally when opening audio; without the cap a fresh install on Python 3.12+ failed to transcribe (#4842, thanks @SyedFahad7).
  • Fix: r setClass/setRefClass S4/R5 inheritance declared with contains= now emits an inherits edge (previously only R6Class's inherit= was recognised) (#4902, thanks @ayushcodes10).
  • Fix: elixir a bare function call resolves to a function in the caller's own module before other modules, instead of binding to the last-walked same-named definition (#4900, thanks @ayushcodes10).
  • Fix: dart a mixin on A, B clause resolves every superclass constraint, not just the first (#4899, thanks @ayushcodes10).
  • Fix: fortran a derived type's extends(base) emits an inherits edge, bringing Fortran in line with the other OOP extractors (#4897, thanks @ayushcodes10).
  • Fix: scala an extension (x: T) def m is scoped to its receiver type T (a method edge to T) instead of leaking to file scope (#2044, #4856, thanks @divakantpandey).
  • Fix: terraform a node carries its original scope so ids stay stable when a cached project directory is moved, instead of re-deriving the scope from the new path (#4858, #4861, thanks @yUm1k4).
  • Fix: extract (JVM) Java and Kotlin imports, extends/implements and member calls resolve across files and across the two languages when a written FQN names exactly one sourced type (#4874, #4879, thanks @Deepjyoti-Sarmah).
  • Fix: export a path/explain/wiki rendering lists every parallel relation between two nodes (via edge_datas), and a raw --no-cluster write marks the graph multigraph so parallel edges survive reload (#4794, thanks @ensell-yes).
  • Fix: export a partial or failed backup is reported as no backup and retried on the next run, instead of being recorded as a false success (#3769, #4834, thanks @barlowa124).
  • Fix: affected graphify affected (and query --seed) resolve the same path::Symbol and dotted reference forms explain accepts, reusing explain's resolver, and exit non-zero (3 ambiguous / 4 not-found) on a seed that does not resolve (#4792, #4797, thanks @dupeisen).
  • Fix: install graphify uninstall removes every platform's user-scope skill (13 were left behind) and the kilo global command; and graphify kilo uninstall removes the kilo skill's references/ sidecar (#4782, #4789, thanks @bercedev).
  • Feat: llm the Claude backend caches its (stable, large) system prompt with cache_control, counting the cached tokens back into input_tokens, and GRAPHIFY_CLAUDE_PROMPT_CACHE=0 disables it for gateways that reject cache_control (#4835, #4855, #4880, thanks @Jvxoq and @1akashkalita).
  • Fix: prompt the node-id format description in the extraction prompt matches what ids.py actually produces (word characters kept, non-ASCII letters/digits preserved, ASCII lowercased) instead of the stale "[a-z0-9_] only" wording (#4432, #4799, thanks @dupeisen).
  • Docs: how-it-works the supported-language count is updated (about 40: 33 tree-sitter grammars plus 7 built-in parsers) and Pass 3 is described as running the configured LLM backend, not Claude only (#4873, thanks @SyedFahad7).
