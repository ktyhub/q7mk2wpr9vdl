incubadora-seata v0.9.0

La versión se actualiza de la siguiente manera:

característica:

  • [#1608] Base de implementación de Saga en máquina de estados
  • [#1625] admite configuración personalizada y tipo de registro
  • [#1656] admite la configuración de Spring Cloud
  • [#1689] admite el parámetro de inicio -e para especificar el nombre del entorno
  • [#1739] admite reintento cuando falla la confirmación o la reversión de tm

corrección de errores:

  • [#1605] soluciona interbloqueos que pueden ser causados por bloqueos de objetos y bloqueos globales y optimiza la granularidad de los bloqueos.
  • [#1685] corrige pk demasiado largo en la tabla de bloqueo en modo db y optimiza el registro de errores
  • La solución [#1691] no puede acceder al miembro privado de DruidDataSourceWrapper
  • [#1699] corrige el uso 'en' y 'entre' en la condición donde para Oracle y Mysql
  • [#1713] corrige la condición de aserción LockManagerTest.concurrentUseAbilityTest
  • La solución [#1720] no puede actualizar los metadatos de la tabla para Oracle
  • [#1729] soluciona el error de inserción por lotes de Oracle
  • [#1735] limpiar xid cuando falla la confirmación o la reversión
  • [#1749] corrige el soporte para deshacer el metacaché de la tabla Oracle
  • [#1751] corrige el bloqueo de memoria no se libera debido a un conflicto de hash
  • [#1761] corrige el error de reversión de Oracle cuando la tabla tiene un valor Blob Clob nulo
  • [#1759] corrige que el método de servicio saga no admita el parámetro de tipo de interfaz
  • [#1401] corrige que el primer recurso de registro es nulo cuando se inicia RM

optimizar:

  • [#1701] elimina las importaciones no utilizadas
  • [#1705] Basado en optimización Java5
  • [#1706] optimizar la clase interna a clase estática
  • [#1707] el juego de caracteres predeterminado utiliza StandardCharsets.UTF_8 en su lugar
  • [#1712] clase abstracta de administrador de deshacer registros
  • [#1722] simplificar para que los códigos sean más legibles
  • [#1726] mensajes de registro de formato
  • [#1738] agregar los parámetros jvm del servidor
  • [#1743] mejora la eficiencia del registro por lotes
  • [#1747] usa tipos sin formato en lugar de tipos boxing
  • [#1750] tabla abstractaClase de metacaché
  • [#1755] mejora la cobertura de prueba del módulo común de seata
  • [#1756] seguridad: actualice jackson para evitar vulnerabilidades de seguridad
  • [#1657] optimiza el problema del búfer directo grande cuando el archivo se transfiere al modo de almacenamiento de archivos Gracias a estos contribuyentes por sus confirmaciones de código. Por favor informe una omisión no intencionada.

incubator-seata v0.9.0

The version is updated as follows:

feature：

  • [#1608] Saga implementation base on state machine
  • [#1625] support custom config and registry type
  • [#1656] support spring cloud config
  • [#1689] support -e startup parameter for specifying the environment name
  • [#1739] support retry when tm commit or rollback failed

bugfix：

  • [#1605] fix deadlocks that can be caused by object locks and global locks and optimize the granularity of locks
  • [#1685] fix pk too long in lock table on db mode and optimize error log
  • [#1691] fix can't access private member of DruidDataSourceWrapper
  • [#1699] fix use 'in' and 'between' in where condition for Oracle and Mysql
  • [#1713] fix LockManagerTest.concurrentUseAbilityTest assertion condition
  • [#1720] fix can't refresh table meta data for oracle
  • [#1729] fix oracle batch insert error
  • [#1735] clean xid when tm commit or rollback failed
  • [#1749] fix undo support oracle table meta cache
  • [#1751] fix memory lock is not released due to hash conflict
  • [#1761] fix oracle rollback failed when the table has null Blob Clob value
  • [#1759] fix saga service method not support interface type parameter
  • [#1401] fix the first registration resource is null when RM starts

optimize：

  • [#1701] remove unused imports
  • [#1705] Based on Java5 optimization
  • [#1706] optimize inner class to static class
  • [#1707] default charset use StandardCharsets.UTF_8 instead
  • [#1712] abstract undolog manager class
  • [#1722] simplify to make codes more readable
  • [#1726] format log messages
  • [#1738] add server's jvm parameters
  • [#1743] improve the efficiency of the batch log
  • [#1747] use raw types instead of boxing types
  • [#1750] abstract tableMeta cache class
  • [#1755] enhance test coverage of seata-common module
  • [#1756] security: upgrade jackson to avoid security vulnerabilities
  • [#1657] optimize the problem of large direct buffer when file rolling in file storage mode

Thanks to these contributors for their code commits. Please report an unintended omission.
