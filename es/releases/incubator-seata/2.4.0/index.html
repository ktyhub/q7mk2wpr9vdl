incubadora-seata v2.4.0

Apache Seata (incubando) 2.4.0 Lanzado.

Apache Seata (en incubación) es una solución de transacciones distribuidas de código abierto, de alto rendimiento y fácil de usar.

La versión se actualiza de la siguiente manera:

característica:

  • [#7213] admite el modo kingbase XA
  • [#7024] admite control de transacciones en la consola
  • [#7038] admite serializador Fury
  • [#6756] admite límite de velocidad en seata-server
  • [#7114] admite registro en modo balsa en el servidor de nombres
  • [#7157] admite la implementación combinada de consola y servidor de nombres

corrección de errores:

  • [#7104] corrección impl de soportesSourceType no está definida
  • [#7116] prefijo de corrección: seata.server.raft.ssl no debe ser nulo
  • [#7112] elimina la condición de que IPv6 debe comenzar con fe80
  • [#7107] soluciona el problema de no analizar anotaciones en modo TCC cuando el objeto comercial es un objeto proxy.
  • [#7124] corrige GlobalTransactionScanner.afterPropertiesSet necesita realizar una verificación del escáner
  • [#7135] trata un conflicto de índice único durante la reversión como una escritura sucia
  • [#7150] corrige la diferencia horaria entre el nodo balsa y el nodo seguidor no puede sincronizar datos
  • [#7102] corrección modifica la transacción previa a la confirmación del modo XA desde la fase de confirmación hasta la fase anterior al cierre
  • [#7188] corrige el tipo de rama que falta en BusinessActionContext
  • [#7219] corrige que NotSupportException no se puede descartar en algunos casos
  • [#7241] actualice tomcat-embed-core a 9.0.99 para corregir CVE-2025-24813
  • [#7272] corrige que la información de la transacción no se muestra
  • [#7277] arregla el controlador jdbc MySQL no se puede encontrar correctamente
  • [#7355] corrige que los controladores en la carpeta lib no se pueden cargar
  • [#7397] resuelve errores de enlace de puerto y de puntero nulo

  • [#6828] spring boot compatible con file.conf y registro.conf
  • [#7012] cuando el número de claves primarias excede 1000, use unión para concatenar el SQL
  • [#7075] admite falla rápida cuando el canal es nulo

  • [#7088] ampliar las abreviaturas en inglés a palabras completas
  • [#7064] eliminar comprobaciones nulas innecesarias
  • [#7130] expone algunas configuraciones relacionadas con keepalive para Druid, Hikari y DBCP
  • [#7131] eliminar la dependencia de org.codehaus.jackson

  • [#7142] actualiza commons-compress a 1.27.1
  • [#7149] soluciona problemas de visualización de caracteres anormales en ./distribution/NOTICE.md
  • [#7170] optimiza el procesamiento de E/S del seata client ajustando el número de subprocesos
  • [#7187] agrega el complemento dependency-check-maven para detectar posibles vulnerabilidades
  • [#7179] usa EventLoop compartido para TM y RM clients para reducir la sobrecarga de subprocesos y mejorar el rendimiento
  • [#7194] omite automáticamente el proxy para la fuente de datos de tipo AbstractRoutingDataSource
  • [#7215] intercepta solicitudes de escritura no líderes de la operación trx de la consola

incubator-seata v2.4.0

Apache Seata(incubating) 2.4.0 Released.

Apache Seata(incubating) is an easy-to-use, high-performance, open source distributed transaction solution.

The version is updated as follows:

feature:

  • [#7213] support kingbase XA mode
  • [#7024] support transaction control in console
  • [#7038] support fury serializer
  • [#6756] support ratelimit in seata-server
  • [#7114] support raft mode registry to namingserver
  • [#7157] support the console and namingserver combined deployment

bugfix:

  • [#7104] fix impl of supportsSourceType is not defined
  • [#7116] fix prefix: seata.server.raft.ssl should not be null
  • [#7112] remove the condition that IPv6 must start with fe80
  • [#7107] fix the issue of failing to parse annotations in TCC mode when the business object is a proxy object.
  • [#7124] fix GlobalTransactionScanner.afterPropertiesSet need do scanner check
  • [#7135] treating a unique index conflict during rollback as a dirty write
  • [#7150] fix the time difference between the raft node and the follower node cannot synchronize data
  • [#7102] fix modify XA mode pre commit transaction from commit phase to before close phase
  • [#7188] fix missing branchType in BusinessActionContext
  • [#7219] fix NotSupportException can't be thrown out in some cases
  • [#7241] upgrade tomcat-embed-core to 9.0.99 to fix CVE-2025-24813
  • [#7272] fix transaction info not display
  • [#7277] fix MySQL jdbc driver can't be found properly
  • [#7355] fix the drivers in the lib folder cannot be loaded
  • [#7397] resolve NullPointer and port binding errors

optimize:

  • [#6828] spring boot compatible with file.conf and registry.conf
  • [#7012] when the number of primary keys exceeds 1000, use union to concatenate the SQL
  • [#7075] support fast fail when channel is null
