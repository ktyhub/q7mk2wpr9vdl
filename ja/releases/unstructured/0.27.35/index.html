何が変わったのか

その他の変更点

  • 雑務: PR ごとの changelog 編集を、https://github.com/Unstructured-IO/unstructured/pull/4578 の @cragwolfe によって生成された release note に置き換えます。
  • fix(utils): https://github.com/Unstructured-IO/unstructured/pull/4561 の @simpleqt によるページ番号のない要素の境界ボックスを比較
  • fix(chunking): https://github.com/Unstructured-IO/unstructured/pull/4528 で @joaquinhuigomez によって max_tokens が設定されている場合に、トークンの結合しきい値を測定します
  • ci: https://github.com/Unstructured-IO/unstructured/pull/4589 の @cragwolfe による通常の PR をブロックせずにバージョンをガードします。
  • fix(xml): https://github.com/Unstructured-IO/unstructured/pull/4572 で @JackyHsu-X によってテキストを抽出するときに明示的なエンコーディングを尊重する
  • fix(msg): https://github.com/Unstructured-IO/unstructured/pull/4579 の @L4XB により、Cc、Bcc、および Message-ID ヘッダーを大文字小文字で読み取ります。
  • 修正(tsv): https://github.com/Unstructured-IO/unstructured/pull/4513 で @feiiiiii5 によって TSV ファイルをパーティション分割するときに infer_table_struction を優先する
  • 修正(msg): https://github.com/Unstructured-IO/unstructured/pull/4570 の @RaphaelFakhri により、引用符で囲まれた送信者または受信者の名前にカンマを含めます。
  • 修正(xlsx): https://github.com/Unstructured-IO/unstructured/pull/4505 の @wenqiw777 によってセルのテキストを空にするのではなく、N/A や None のようなセル テキストを保持します。
  • 功績: https://github.com/Unstructured-IO/unstructured/pull/4591 の @Ei-Ayw により要素メタデータ内の DOCX 段落スタイル名を公開
  • fix(text): https://github.com/Unstructured-IO/unstructured/pull/4580 の @L4XB により、導入行に続く箇条書きリストをリスト項目として保持します。
  • 修正（画像）: GIF フレームをキャンバス サイズで充電します。ピローは https://github.com/Unstructured-IO/unstructured/pull/4526 の @badGarnet によってそれらをデコードします。
  • fix(utils): https://github.com/Unstructured-IO/unstructured/pull/4507 の @SashaMIT により許容値がゼロの場合にネストされたボックスを認識する
  • perf(pdf): hi_res は、PDF に https://github.com/Unstructured-IO/unstructured/pull/4588 の @CyMule によるテキストが含まれているかどうかを知るためだけに pdfminer ですべてのページを読み取ります
  • fix(csv): 引用符で囲まれた CSV または TSV セル内の改行をリテラルではなく空白として読み取ります \n by @CyberNativeAI (https://github.com/Unstructured-IO/unstructured/pull/4592)
  • ci: PR が https://github.com/Unstructured-IO/unstructured/pull/4594 の @cragwolfe によって凍結された CHANGELOG.md を編集すると、バージョンチェックに失敗します
  • 修正(メトリクス): _mean が兄弟のような未測定のスコアを無視するようにする (https://github.com/Unstructured-IO/unstructured/pull/4510 の @sclfcz による)
  • fix(filetype): https://github.com/Unstructured-IO/unstructured/pull/4599 の @sinnercode228 により、.markdown ファイルをプレーンテキストではなくマークダウンとして検出します
  • 修正（クリーナー）: https://github.com/Unstructured-IO/unstructured/pull/4568 の @sinnercode228 によるテキスト全体ではなく、translate_text 内の各チャンクを翻訳します
  • 修正: https://github.com/Unstructured-IO/unstructured/pull/4602 の @sinnercode228 によるパーティショニングに使用される pdf_image_dpi でのレンダリング解析 Bbox オーバーレイ
  • 修正（チャンク）: https://github.com/Unstructured-IO/unstructured/pull/4605 の @simpleqt による new_after_n_chars での combin_text_under_n_chars のキャップ
  • 修正(電子メール): https://github.com/Unstructured-IO/unstructured/pull/4597 の @sinnercode228 によって AssertionError が発生する代わりに、添付された電子メール (message/rfc822) を分割します。
  • ci: リリース後の開発バンプ PR を自動化 (https://github.com/Unstructured-IO/unstructured/pull/4590 の @cragwolfe による)
  • 修正(パーティション): https://github.com/Unstructured-IO/unstructured/pull/4581 の @SergeevDmitry によってアラバマ州とワイオミング州の住所を認識する
  • fix(md): https://github.com/Unstructured-IO/unstructured/pull/4603 の @feiiiiii5 による空のテキスト本文の要素を返さない
  • 雑用: @cragwolfe による 0.27.35 を https://github.com/Unstructured-IO/unstructured/pull/4606 でリリース
