rust 1.89.0

マイナー 公開日2025年8月7日 出典rust-lang/rust English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#rust 1.89.0 <a id="1.89.0-Language"></a>

言語

  • 明示的に推論された const 引数を安定化する (feature(generic_arg_infer))
  • デフォルトで警告する mismatched_lifetime_syntaxes lint を追加します。 この lint は、関数の引数と戻り値の間で、同じ有効期間が異なる構文カテゴリによって参照される場合を検出します。これは、特に安全でないコードでは、読みにくい場合があります。この lint は、デフォルトで警告される elided_named_lifetimes lint よりも優先されます。
  • unpredictable_function_pointer_comparisons を拡張して、外部マクロ内の関数ポインター比較でも lint を実行できるようにします
  • dangerous_implicit_autorefs lint をデフォルトで拒否するようにする
  • avx512ターゲット機能の安定化
  • x86 の kl および widekl ターゲット機能の安定化
  • x86 の sha512、sm3、sm4 ターゲット機能の安定化
  • LoongArch ターゲット機能 f、d、frecipe、lasx、lbt、lsx、lvz の安定化
  • i128 と u128 を improper_ctypes_definitions から削除
  • repr128 (#[repr(u128)]、#[repr(i128)]) を安定させる
  • どこでも #![doc(test(attr(..)))] を許可
  • タプル構造体およびタプルバリアントコンストラクターも通過するように一時的なライフタイム延長を拡張
  • wasm32-unknown-unknown ターゲットの extern "C" 関数に標準準拠の ABI が追加されました <a id="1.89.0-Compiler"></a>

コンパイラ

  • aarch64-linux の非リーフ フレーム ポインターのデフォルト
  • Arm64EC Windows の非リーフ フレーム ポインターを有効にする
  • アーキテクチャごとに Apple フレーム ポインタを設定する <a id="1.89.0-Platform-Support"></a>

プラットフォームのサポート

  • 新しい Tier-3 ターゲット loongarch32-unknown-none および loongarch32-unknown-none-softfloat を追加
  • x86_64-apple-darwin はホスト ツールにより Tier 2 に降格中です Rust の階層型プラットフォーム サポートの詳細については、Rust の プラットフォーム サポート ページ を参照してください。 <a id="1.89.0-Libraries"></a>

ライブラリ

  • file!のベースパスを指定
  • format_args!()を変数に格納できるようにする
  • #[must_use]を[T; N]::mapに追加
  • Lazy{Cell,Lock}用にDerefMutを実装
  • array::IntoIter用にDefaultを実装
  • slice::ChunkBy用にCloneを実装
  • io::Take用にio::Seekを実装 <a id="1.89.0-Stabilized-APIs"></a>

安定化された API

  • NonZero<char>
  • ここでは列挙されていない x86 の多くの組み込み関数
    • AVX512 組み込み関数
    • SHA512、SM3、SM4 組み込み関数
  • File::lock
  • File::lock_shared
  • File::try_lock
  • File::try_lock_shared
  • File::unlock
  • NonNull::from_ref
  • NonNull::from_mut
  • NonNull::without_provenance
  • NonNull::with_exposed_provenance
  • NonNull::expose_provenance
  • OsString::leak
  • PathBuf::leak
  • Result::flatten
  • std::os::linux::net::TcpStreamExt::quickack
  • std::os::linux::net::TcpStreamExt::set_quickack 以前は安定していたこれらの API は、const コンテキストでも安定するようになりました。
  • <[T; N]>::as_mut_slice
  • <[u8]>::eq_ignore_ascii_case
  • str::eq_ignore_ascii_case <a id="1.89.0-Cargo"></a>

貨物

  • cargo fix および cargo clippy --fix は、他のビルド コマンドと同じ Cargo ターゲット選択をデフォルトで選択するようになりました。 以前は、すべてのターゲット (バイナリ、サンプル、テストなど) に適用されていました。 --edition フラグは引き続きすべてのターゲットに適用されます。
  • doctest-xcompile の安定化 クロスコンパイル時に doctest がテストされるようになりました。他のテストと同様に、runner 設定 を使用してテストを実行します。ターゲットのテストを無効にする必要がある場合は、ignore doctest 属性 を使用して、無視するターゲットを指定できます。 <a id="1.89.0-Rustdoc"></a>

Rustdoc

  • モバイルでは、サイドバーを全幅にして改行します。これにより、長いセクション名や項目名をモバイルで簡単に扱うことができます。 <a id="1.89.0-Compatibility-Notes"></a>

互換性に関する注意事項

  • missing_fragment_specifierを無条件エラーにする
  • aarch64-unknown-none-softfloat で neon ターゲット機能を有効にすると、警告が発生します これは、そのターゲット機能を含むコードと含まないコードの混在が LLVM で適切にサポートされていないためです。
  • サイズ階層: パート I
    • 関連する型射影を含む再帰型の impls の ?Sized 境界に影響する小さな破壊的変更を導入します。既存の公開されたクレートには影響しないと予想されます。関連する型をリファクタリングするか、sized_hierarchy 不安定機能を選択することで修正できます。コード例については、FCP レポート を参照してください。
  • デフォルトで警告される elided_named_lifetimes リントは、デフォルトで警告される mismatched_lifetime_syntaxes リントに置き換えられます。
  • 型チェッカーの以前の再帰的不透明型に関するエラー
  • 配列繰り返し式の要素型を要求することによる型推論の副作用は Copy であり、型チェックの最後でのみ利用できるようになりました
  • 非推奨となった偶発的に安定した std::intrinsics::{copy,copy_nonoverlapping,write_bytes} は、適切な組み込み関数になりました。 UB を保護するデバッグ アサーションはなく、関数ポインターに強制することもできません。
  • 長い間非推奨となっていた std::intrinsics::drop_in_place を削除
  • 整形式述語を共導的でなくする
  • impl メソッドの互換性をチェックするときにハックを削除する
  • 組み込み特性オブジェクトの impls による不要な型推論を削除
  • 非 x86-32 ターゲット上の「stdcall」、「fastcall」、および「cdecl」に対する lint
  • never タイプ (!) に関連する将来の非互換性警告が依存関係で報告されるようになりました
  • std::ptr::copy_* 組み込み関数も静的自己初期化チェックを実行するようにする
  • wasm32-unknown-unknown ターゲットの extern "C" 関数に標準準拠の ABI が追加されました <a id="1.89.0-Internal-Changes"></a>

内部変更

これらの変更は、Rust のパブリック インターフェイスには影響しませんが、rustc および関連ツールのパフォーマンスや内部機能が大幅に向上します。

  • rustc-dev コンポーネントを使用したコンパイラ ソース パスの再マップが正しく解除されました

rust 1.89.0

<a id="1.89.0-Language"></a>

Language

  • Stabilize explicitly inferred const arguments (feature(generic_arg_infer))
  • Add a warn-by-default mismatched_lifetime_syntaxes lint. This lint detects when the same lifetime is referred to by different syntax categories between function arguments and return values, which can be confusing to read, especially in unsafe code. This lint supersedes the warn-by-default elided_named_lifetimes lint.
  • Expand unpredictable_function_pointer_comparisons to also lint on function pointer comparisons in external macros
  • Make the dangerous_implicit_autorefs lint deny-by-default
  • Stabilize the avx512 target features
  • Stabilize kl and widekl target features for x86
  • Stabilize sha512, sm3 and sm4 target features for x86
  • Stabilize LoongArch target features f, d, frecipe, lasx, lbt, lsx, and lvz
  • Remove i128 and u128 from improper_ctypes_definitions
  • Stabilize repr128 (#[repr(u128)], #[repr(i128)])
  • Allow #![doc(test(attr(..)))] everywhere
  • Extend temporary lifetime extension to also go through tuple struct and tuple variant constructors
  • extern "C" functions on the wasm32-unknown-unknown target now have a standards compliant ABI

<a id="1.89.0-Compiler"></a>

Compiler

  • Default to non-leaf frame pointers on aarch64-linux
  • Enable non-leaf frame pointers for Arm64EC Windows
  • Set Apple frame pointers by architecture

<a id="1.89.0-Platform-Support"></a>

Platform Support

  • Add new Tier-3 targets loongarch32-unknown-none and loongarch32-unknown-none-softfloat
  • x86_64-apple-darwin is in the process of being demoted to Tier 2 with host tools

Refer to Rust's platform support page for more information on Rust's tiered platform support.

<a id="1.89.0-Libraries"></a>

Libraries

  • Specify the base path for file!
  • Allow storing format_args!() in a variable
  • Add #[must_use] to [T; N]::map
  • Implement DerefMut for Lazy{Cell,Lock}
  • Implement Default for array::IntoIter
  • Implement Clone for slice::ChunkBy
  • Implement io::Seek for io::Take

<a id="1.89.0-Stabilized-APIs"></a>

Stabilized APIs

  • NonZero<char>
  • Many intrinsics for x86, not enumerated here
    • AVX512 intrinsics
    • SHA512, SM3 and SM4 intrinsics
  • File::lock
  • File::lock_shared
  • File::try_lock
  • File::try_lock_shared
  • File::unlock
  • NonNull::from_ref
  • NonNull::from_mut
  • NonNull::without_provenance
  • NonNull::with_exposed_provenance
  • NonNull::expose_provenance
  • OsString::leak
  • PathBuf::leak
  • Result::flatten
  • std::os::linux::net::TcpStreamExt::quickack
  • std::os::linux::net::TcpStreamExt::set_quickack

These previously stable APIs are now stable in const contexts:

  • <[T; N]>::as_mut_slice
  • <[u8]>::eq_ignore_ascii_case
  • str::eq_ignore_ascii_case

<a id="1.89.0-Cargo"></a>

Cargo

  • cargo fix and cargo clippy --fix now default to the same Cargo target selection as other build commands. Previously it would apply to all targets (like binaries, examples, tests, etc.). The --edition flag still applies to all targets.
  • Stabilize doctest-xcompile. Doctests are now tested when cross-compiling. Just like other tests, it will use the runner setting to run the tests. If you need to disable tests for a target, you can use the ignore doctest attribute to specify the targets to ignore.

<a id="1.89.0-Rustdoc"></a>

Rustdoc

  • On mobile, make the sidebar full width and linewrap. This makes long section and item names much easier to deal with on mobile.

<a id="1.89.0-Compatibility-Notes"></a>

Compatibility Notes

  • Make missing_fragment_specifier an unconditional error
  • Enabling the neon target feature on aarch64-unknown-none-softfloat causes a warning because mixing code with and without that target feature is not properly supported by LLVM
  • Sized Hierarchy: Part I
    • Introduces a small breaking change affecting ?Sized bounds on impls on recursive types which contain associated type projections. It is not expected to affect any existing published crates. Can be fixed by refactoring the involved types or opting into the sized_hierarchy unstable feature. See the FCP report for a code example.
  • The warn-by-default elided_named_lifetimes lint is superseded by the warn-by-default mismatched_lifetime_syntaxes lint.
  • Error on recursive opaque types earlier in the type checker
  • Type inference side effects from requiring element types of array repeat expressions are Copy are now only available at the end of type checking
  • The deprecated accidentally-stable std::intrinsics::{copy,copy_nonoverlapping,write_bytes} are now proper intrinsics. There are no debug assertions guarding against UB, and they cannot be coerced to function pointers.
  • Remove long-deprecated std::intrinsics::drop_in_place
  • Make well-formedness predicates no longer coinductive
  • Remove hack when checking impl method compatibility
  • Remove unnecessary type inference due to built-in trait object impls
  • Lint against "stdcall", "fastcall", and "cdecl" on non-x86-32 targets
  • Future incompatibility warnings relating to the never type (!) are now reported in dependencies
  • Ensure std::ptr::copy_* intrinsics also perform the static self-init checks
  • extern "C" functions on the wasm32-unknown-unknown target now have a standards compliant ABI

<a id="1.89.0-Internal-Changes"></a>

Internal Changes

These changes do not affect any public interfaces of Rust, but they represent significant improvements to the performance or internals of rustc and related tools.

  • Correctly un-remap compiler sources paths with the rustc-dev component
