  • 長時間実行されるツールは、進行状況、延長、キャンセルの制御を使用してバックグラウンドで継続できます (#6151)
  • ツールのワークフローは、結果を再利用し、分岐、ループし、独立したステップを並行して実行できます (#5698)

QwenPaw v2.1.0

Highlights

  • Desktop workspace — QwenPaw OS Shell adds movable/resizable windows, a launcher, taskbar, notifications, and saved layouts, while Chat gains a unified Files workspace for browsing, previewing, editing, comparing, uploading, and downloading files. Worth upgrading for project-heavy users; note that obsolete Coding launch paths were removed from the Shell.

  • Video creation — QwenPaw Creator now supports end-to-end, multi-Agent video production with asynchronous media generation, focused edits, recovery, structured logs, review feedback, and additional rendering formats. This is a major upgrade for video creators and largely irrelevant to chat-only users.

  • Runtime reliability — Provider-specific tool-call data now survives streaming, compaction, history storage, and replay; context-limit errors trigger automatic compaction and one retry. Long-running tools gain background progress, extension, and cancellation controls, alongside fixes for shell hangs, approval inheritance, corrupt configuration, and background-task recovery. Users encountering these failure modes should upgrade.

  • Agent integrations and deployment — Agents can now be powered by Codex or Qoder, and ACP clients can advertise models and supply temporary models, project folders, context/output limits, and MCP services without persisting runtime credentials. MiniMax M3/M2.7 context limits are updated, while custom channel gateways remain opt-in with unchanged defaults.

  • Upgrade guidance and safety — No breaking API changes or required migration steps are declared. The runtime fixes make upgrading worthwhile even without using the new desktop or Creator features; conservative automation users can defer while validating their workflows. Browser-use remains Beta without host-level sandboxing or enforced action policies, and Computer-use requires per-app approval; macOS device-level end-to-end validation is still in progress.

What's Changed

✨ Added

QwenPaw OS Shell

  • Open apps in movable, resizable windows with a launcher, taskbar, notifications, and saved layouts (#6645)
  • Installed and marketplace apps now share one catalog across the App Center and QwenPaw OS Shell (#6718)

Unified Files Workspace

  • Browse, preview, edit, compare, upload, and download workspace files without leaving Chat (#6504)
  • Open the Files workspace directly from QwenPaw OS Shell (#6758)
  • Edit Robot Framework files with syntax highlighting (#6519)

QwenPaw Creator

  • Turn an idea or existing footage into a finished video with a team of specialized Agents (#6284)
  • Select clips, subtitles, effects, assets, or text for focused Agent edits while keeping direct controls (#6740)
  • Create with images, video, voice, subtitles, motion, overlays, and parallel production steps (#6740)
  • Add media task recovery, rendering fixes, structured logs, and review feedback (#6556, #6641)
  • Add a settings center, external Skills, asynchronous media generation, more rendering formats, and improved Windows and narrow-screen support (#6870)

Cross-harness Integration

  • Create Agents powered by Codex or Qoder, with per-session models, permissions, Skills, and MCP services (#6397)
  • ACP clients can pass temporary models, project folders, and MCP services without saving runtime credentials (#6754)
  • ACP sessions now report available and current models to compatible clients (#6531)

Browser-use

  • Browser-use remains in Beta. It can use a separate browser session or connect selected tabs from the user's signed-in Chrome. Browser-side code execution is not protected by a host-level sandbox, and action policies are not yet enforced (#6276, #6157)

Computer-use

  • Add Windows desktop app automation. macOS packaging and signing are complete, while device-level end-to-end validation is still in progress. Operations require per-app approval and stop when the user takes over input (#6424)
  • Native Computer-use adds keyboard sequences, improves Windows modal targeting and text editing, and makes macOS menus, dragging, capture, and focus more reliable (#6891, #6913, #6977)

Context, Recovery & Long-running Work

  • Snapshot and restore conversations, memory, and selected workspace files without changing project Git history (#6269)

  • Visual Compact reduces long-context input for supported multimodal models while keeping source recovery (#6456)
  • Long-running tools can continue in the background with progress, extension, and cancellation controls (#6151)
  • Tool workflows can reuse results, branch, loop, and run independent steps in parallel (#5698)
  • ReMe Light memory search can optionally rerank candidates through an OpenAI-compatible endpoint and falls back gracefully when reranking is unavailable (#6398)
  • ReMe Light adds validated, hot-updatable embedding settings, Daily Paper and service-level schedules, per-Agent runtime status, manual reindex controls, and independent search and notification options (#6772)

  • Explore memory relationships in an interactive 3D graph with focus, filtering, and reduced-motion support (#6922)

  • Saving an enabled built-in channel warns when the same bot identity is already used by another running Agent, while still allowing an explicit override (#6909)
