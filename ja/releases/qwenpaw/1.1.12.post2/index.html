QwenPaw v1.1.12.post2

Highlights

  • Cross-agent queue delivery fix — PR #5371 binds the agent ID at enqueue time instead of at dispatch, closing a race where a queued message could be delivered to the wrong agent after a config or session change; PR #5389 additionally makes the background queue sender use the QueueItem's own userId/channel rather than ambient context. If you run multiple agents over a shared queue, this changes routing correctness — check any custom queue consumers that leaned on the old ambient-context behavior.
  • Session lifecycle hardening — PRs #5376, #5357, and #5388 centralize session-ID resolution and navigation tracking, auto-navigate to a fresh chat after deleting the active session, and release the session-switch lock on embedded-mode completion (bug #5354). Embedders gain a fix for a stuck-switch deadlock; the state centralization is worth a second look if you hook into navigation internals.
  • Scheduler misfire grace raised to 600s — PR #5418 records APScheduler misfires in job history and lifts the default misfire grace window to 600 seconds, and PR #5426 applies the same 600s default to the "dream" scheduler. This is a real behavioral change: jobs previously skipped as too late are now more likely to execute, so review cron and dream schedules for unintended late or duplicate runs.
  • Auth: rate limiting and clearer login errors — PR #5424 adds login rate limiting and improves error handling. Operationally, repeated failed logins will now be throttled — build backoff into automated clients and integration tests that hit the login endpoint heavily.
  • Discord streaming responses — PR #5314 brings streaming replies to the Discord channel via message edits plus a typing indicator. Integrations get near-real-time output instead of a single final message; note it depends on the bot having edit-message permissions.
  • Console goes mobile-first — A coordinated sweep (PRs #5355, #5362, #5364, #5366, #5369, #5381–#5385, #5391, #5397) makes Inbox, ACP, Agent Config, CronJobs, Backups, Sessions, Settings-Models, MCP, Channels, Environments, and Workspace responsive, alongside relative-path file preview support (#5377). Big QA/ops win for administering from a phone; no API surface changes.

No breaking changes in this release.
