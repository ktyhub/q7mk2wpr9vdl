QwenPaw v1.1.8.post1

Highlights

  • OpenCode provider flexibility — PR #4536 registers OpenCode Go through meta.base_url_options, and #4549 disables URL freezing in OpenCode provider configuration, so the provider can target alternate or self-hosted endpoints instead of a locked URL. Note the test-side freeze_url default change in #4555 — re-check any custom provider config after upgrading, since the effective default behavior shifts. First contribution from @DICKQI.

  • Background task timeouts — PR #4547 adds task_timeout support for background task submissions. For the first time you can bound long-running agent jobs at submission time rather than relying on the agent to finish on its own; set it explicitly if you dispatch fire-and-forget work that could otherwise hang indefinitely.

  • MCP key routing — PR #4560 fixes MCP client key routing for keys containing /. If you use namespaced or slash-bearing MCP server keys, they now resolve to the correct client instead of being misrouted — a quiet correctness fix worth validating if you previously saw intermittent MCP lookup failures.

  • Backup un-gated — PR #4563 removes the backup host gate and #4534 documents the backup directory. Backup is no longer restricted to approved hosts, which broadens where you can run it; review your backup paths and destination assumptions since the guard that limited host scope is gone.

  • File handling, desktop pet, and console polish — PR #4574 normalizes file-name handling in message content processing, eliminating cross-platform filename inconsistencies in messages. PR #4564 brings Windows compatibility, improved pet lifecycle UX, and bilingual UI to qwenpaw-pet. Console fixes in #4570 (dark-mode plan panel title invisible), #4573 (chatSession), and #4545 (plugin page) clean up user-facing rough edges.

No breaking changes in this release.
