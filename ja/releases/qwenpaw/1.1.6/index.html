QwenPaw v1.1.6

パッチ 公開日2026年5月9日 出典agentscope-ai/QwenPaw English original

#クウェンパウv1.1.6

✨ 追加しました

エージェントシステム

  • Windows 診断: qwenpaw doctor は、長いパスのサポート、PowerShell 言語モード、作業ディレクトリのパス長など、Windows 固有の環境の問題をチェックするようになりました (#4032)
  • エージェント ステータス API: エージェントのランタイム ステータス、実行中のタスク数、およびタスクのタイムスタンプをレポートする新しい GET /agents/{agentId}/agent-status エンドポイント (#4107)
  • Cron セッション分離: Cron ジョブは share_session オプションをサポートするようになりました。無効にすると、スケジュールされた実行ごとに cron ジョブ ID (#4117) を持つ分離セッション コンテキストが作成されます。
  • GPT Image 2 Plugin: OpenAI の GPT Image 2 API (#3911) 経由で画像を生成するための新しいツール プラグイン
  • 構成主導のエージェント名: ハードコードされたデフォルト (#4140) の代わりに、構成されたエージェント プロファイル名を使用します。 チャットとコンソール
  • ウィスパー音声入力: ブラウザーネイティブの Web スピーチ API をサーバー側のウィスパー文字起こしに置き換え、より信頼性の高いクロスブラウザー音声入力を実現しました (#3574)
  • LLM が生成したセッション タイトル: チャット セッションには、最初のメッセージの後にバックグラウンドで LLM によって自動的にタイトルが付けられるようになりました。エージェント構成の「セッション タイトルの自動生成」トグルで構成可能 (#3829)
  • トークン使用傾向: 時間の経過に伴う使用量を視覚化するために、モデルごとおよびトークン タイプごとの傾向折れ線グラフをトークン使用設定ページに追加しました (#4080、#4094)
  • バッチ スキル操作: スキルごとのエラー レポートを備えたスキル バッチ操作ツールバーに有効化ボタンと無効化ボタンを追加しました (#4091)
  • マーメイド ダイアグラム レンダリング: mermaid 言語タグを含むマークダウン コード ブロックが、チャットおよびファイル プレビューでインタラクティブなダイアグラムとしてレンダリングされるようになりました (#4146)
  • ブラジルポルトガル語 (pt-BR): コンソール UI とバックエンド言語設定の両方に完全な pt-BR ロケール サポートを追加しました (#4009、#4143) プロバイダー
  • Volcano Engine Provider: 標準およびコーディング プラン エンドポイントを備えた組み込みの OpenAI 互換プロバイダーとして Volcano Engine を追加しました (#3994)
  • DashScope 領域の選択: DashScope ベース URL をプリセット領域エンドポイントから変更できるようになりました (#4074)
  • Aliyun トークン プラン プロバイダー: Aliyun トークン プランを組み込みプロバイダーとして追加しました (#4122)
  • Anthropic のデフォルト最大トークン数: Anthropic 互換モデルのデフォルト max_tokens を 16,384 に引き上げました (#4054) チャンネル
  • Feishu インタラクティブ承認カード: Feishu のツールガード承認リクエストは、承認/拒否時にその場で更新されるインタラクティブ ボタン カードとしてレンダリングされるようになりました。カード アクション コールバックがサブスクライブされていない場合はドキュメント リンクのヒントが表示されます (#3941、#3982)
  • WeCom グループ セッション共有: グループ チャット メンバーが単一セッションを共有するか、メンバーごとに分離するかを制御する share_session_in_group トグルを追加しました (#3948)
  • Feishu 送信者コンテキスト: Feishu 送信者のニックネームがエージェント環境コンテキストに渡されるようになりました (#4098)
  • WeCom インタラクティブ承認カード: WeCom のツールガード承認リクエストがインタラクティブ テンプレート カードとしてレンダリングされるようになりました (#4112) セキュリティ
  • 静的ファイル パス トラバーサル保護: コンソールの静的ファイル サービスでは、パス トラバーサル バイパスを防ぐために絶対パスが拒否されるようになりました (#3973)
  • ルールレベルの自動拒否: ツール呼び出しを自動的に拒否するように個別のセキュリティ ルールを構成できるようになりました (#4046) スキルとCLI
  • スキル テスト CLI: スキルの内容を検証し、セキュリティ スキャンを実行するための新しい qwenpaw skills test コマンド (#3999)
  • スキルのインストール/アンインストール CLI: コマンド ラインからスキルを管理するための新しい qwenpaw skills install および qwenpaw skills uninstall コマンド。プールレベルとエージェントごとの両方のワークスペース インストールをサポートします (#4053)

⚡ パフォーマンス

  • コンソール レンダリング: 承認ポーリング状態の比較を安定化し、チャット ランタイム オプションをメモ化することにより、重複した再レンダリングを排除しました (#4052、#4110、#4153)
  • チャット履歴ナビゲーション: 矢印以外のキーのチャット履歴の検索をスキップし、キーストロークごとに繰り返しスキャンされることを避けるためにユーザー メッセージ リストをキャッシュします (#4130)
  • QR ポーリングのクリーンアップ: QR コードのポーリングを直ちに停止し、認証完了またはコードの有効期限が切れたときにステータス インジケーターをクリアします (#4148)

🐛 修正済み

チャンネル

  • WeCom ストリーム キープアライブ: WeCom でステータス インジケーターが停止するのを防ぐために、定期的な更新で「Thinking...」プレースホルダー ストリームを存続させます (#3950)
  • WeCom 再接続レース: WeCom WebSocket 処理における二重再接続スケジュールとクロスイベント ループ切断を修正しました (#3963)
  • Telegram ネットワークの再試行: サイレントに終了するのではなく、一時的な Telegram ネットワーク エラーに対する指数関数的バックオフと制御された再接続を追加しました (#4039)
  • WeChat Cron バッファ フラッシュ: 通常の完了パスをバイパスする cron/プロアクティブ送信のために WeChat マージ バッファを直ちにフラッシュします (#4106)
  • マークダウン テーブルの分割: 各フラグメントでヘッダー行と区切り行を繰り返すことにより、メッセージ チャンク全体でマークダウン テーブル構造を保持します (#4119) エージェントシステム
  • 外部エージェント タイムアウト: 無期限のハングを防ぐために、delegate_external_agent に安全なデフォルト タイムアウト (60 秒) を追加しました (#3928)
  • エージェント構成のリロード: エージェント構成ファイルの変更により、軽量の再インスタンス化ではなくタスク ドレインによる正常なリロードがトリガーされるようになりました (#4064)
  • エージェント構成の永続性: 完全な構成構造を保持することで、コンソール エージェント構成エディターが保存時にネストされた設定を削除する問題を修正しました (#4157) MCP
  • MCP 実行タイムアウト: 短い HTTP 接続タイムアウト (#4058、#4061) の代わりに、MCP ツール実行タイムアウトとして sse_read_timeout を使用します。
  • MCP Client ライフサイクル リーク: close() がバックグラウンド再接続タスクの停止をスキップする可能性があるライフサイクル タスク リークを修正しました (#4152) コンソールと UI
  • SSE サロゲート セーフティ: シリアル化前にエンコード不可能なコンテンツをサニタイズすることで、不正なサロゲート テキストでの SSE ストリーム クラッシュを回避します (#3553)
  • CodeMirror 行折り返し: ツール呼び出し入力/出力ブロックの行折り返しを修正しました (#3960)
  • デフォルトのエージェント表示名: すべての UI サーフェスでデフォルトのエージェントのカスタム名を尊重します (#4073)
  • ファイル プレビュー パス: URL の破損を引き起こす可能性があるファイル プレビュー パスでの冗長な URL プレフィックスの削除を修正しました (#4089) インフラストラクチャ
  • Docker バックアップ復元: 名前を変更する代わりにディレクトリの内容を交換することで、Docker ボリューム マウント ポイントのシークレットを正しく復元します (#3916)
  • オーディオ ブロック パス: file:// URL オーディオ ブロックの解決されたファイル システム パスを返し、冗長なファイル処理コードを削除します (#4021、#4048)
  • ログ ローテーション: すべてのプラットフォームでログ ローテーションに RotatingFileHandler を使用します (#4076)
  • ループバック プロキシ バイパス: 企業プロキシの背後での接続障害を防ぐために、ループバック API ヘルス チェック用のプロキシ環境変数をバイパスします (#4092)
  • Conda Packaging: パッケージング パイプラインの破損を防ぐために、conda-pack を実行する前に conda パッケージング ツールを復元します (#4093)

QwenPaw v1.1.6

Highlights

  • Agent observability & config lifecycle — GET /agents/{agentId}/agent-status (#4107) exposes runtime status, running-task count, and task timestamps, giving orchestration and health checks a first-class probe instead of log scraping. Config edits now trigger a graceful reload with task draining (#4064) rather than lightweight reinstantiation, and the console editor stops dropping nested settings on save (#4157). Watch: config changes take effect only after in-flight tasks drain, so expect a delay under load.
  • Session isolation controls — Cron jobs gain a share_session toggle (#4117); when disabled, each scheduled run gets an isolated session keyed by cron job ID. WeCom adds share_session_in_group (#3948) to choose between one shared group session and per-member isolation. This is a real multi-tenant correctness lever — if you relied on continuity across scheduled runs or group members, review these flags after upgrading.
  • Voice input moves server-side — Browser-native Web Speech API is replaced by server-side Whisper transcription (#3574). Expect consistent, more reliable behavior across browsers, but audio now leaves the client: budget for transcription latency/cost and check your deployment's privacy posture. Integrations that assumed client-side speech-recognition semantics need revisiting.
  • First-class Skills CLI — New qwenpaw skills test (#3999) validates skill content and runs security scans, while skills install/uninstall (#4053) manage skills at both pool and per-agent workspace scopes. Skills are now scriptable and CI-friendly — worth wiring skills test into your skill development pipeline.
  • More providers, higher Anthropic default — Volcano Engine (#3994) and Aliyun Token Plan (#4122) arrive as built-in OpenAI-compatible providers, and DashScope's base URL is now region-selectable (#4074). Note that Anthropic-compatible models now default to max_tokens 16,384 (#4054): if you depended on the old default, expect larger outputs and higher token spend, so set an explicit cap.
  • Operational hardening — MCP tool execution now uses sse_read_timeout instead of the short HTTP connect timeout (#4058, #4061), so long-running tools stop being cut off; delegate_external_agent gets a 60s default timeout (#3928), Telegram gains exponential backoff (#4039), and MCP close() no longer leaks its reconnect task (#4152). Security-wise, static file serving rejects absolute paths (#3973) and individual rules can auto-deny tool calls (#4046). Watch the 60s delegate default — genuinely long external-agent tasks may need an explicit override.

No breaking changes were reported in this release.

✨ Added

Agent System

  • Windows Diagnostics: qwenpaw doctor now checks Windows-specific environment issues including long path support, PowerShell language mode, and working directory path length (#4032)
  • Agent Status API: New GET /agents/{agentId}/agent-status endpoint reporting agent runtime status, running task count, and task timestamps (#4107)
  • Cron Session Isolation: Cron jobs now support a share_session option — when disabled, each scheduled run creates an isolated session context with a cron job ID (#4117)
  • GPT Image 2 Plugin: New tool plugin for generating images via OpenAI's GPT Image 2 API (#3911)
  • Config-Driven Agent Name: Use the configured agent profile name instead of a hardcoded default (#4140)

Chat & Console

  • Whisper Voice Input: Replaced browser-native Web Speech API with server-side Whisper transcription for more reliable, cross-browser voice input (#3574)
  • LLM-Generated Session Titles: Chat sessions are now automatically titled by the LLM in the background after the first message. Configurable via the "Auto-generate session titles" toggle in Agent Config (#3829)
  • Token Usage Trends: Added per-model and per-token-type trend line charts to the Token Usage settings page for visualizing usage over time (#4080, #4094)
  • Batch Skill Operations: Added Enable and Disable buttons to the skill batch operation toolbar with per-skill error reporting (#4091)
  • Mermaid Diagram Rendering: Markdown code blocks with mermaid language tag are now rendered as interactive diagrams in chat and file previews (#4146)
  • Brazilian Portuguese (pt-BR): Added full pt-BR locale support for both the Console UI and backend language settings (#4009, #4143)

Providers

  • Volcano Engine Provider: Added Volcano Engine as a built-in OpenAI-compatible provider with standard and Coding Plan endpoints (#3994)
  • DashScope Region Selection: DashScope base URL can now be modified from preset region endpoints (#4074)
  • Aliyun Token Plan Provider: Added Aliyun Token Plan as a built-in provider (#4122)
  • Anthropic Default Max Tokens: Raised default max_tokens for Anthropic-compatible models to 16,384 (#4054)

Channels

  • Feishu Interactive Approval Cards: Tool-guard approval requests in Feishu are now rendered as interactive button cards that update in-place on approve/deny, with a documentation link hint when the card action callback is not subscribed (#3941, #3982)
  • WeCom Group Session Sharing: Added share_session_in_group toggle to control whether group chat members share a single session or get per-member isolation (#3948)
  • Feishu Sender Context: Feishu sender nickname is now passed to the agent environment context (#4098)
  • WeCom Interactive Approval Cards: Tool-guard approval requests in WeCom are now rendered as interactive template cards (#4112)

Security

  • Static File Path Traversal Protection: Console static file serving now rejects absolute paths to prevent path traversal bypass (#3973)
  • Rule-Level Auto Deny: Individual security rules can now be configured to automatically deny tool calls (#4046)

Skills & CLI

  • Skill Test CLI: New qwenpaw skills test command to validate skill content and run security scans (#3999)
  • Skill Install/Uninstall CLI: New qwenpaw skills install and qwenpaw skills uninstall commands for managing skills from the command line, supporting both pool-level and per-agent workspace installs (#4053)

⚡ Performance

  • Console Rendering: Eliminated duplicate re-renders by stabilizing approval polling state comparisons and memoizing chat runtime options (#4052, #4110, #4153)
  • Chat History Navigation: Skip chat history lookup for non-arrow keys and cache user-message lists to avoid repeated scans on every keystroke (#4130)
  • QR Polling Cleanup: Immediately stop QR code polling and clear status indicators on auth completion or code expiry (#4148)

🐛 Fixed

Channels

  • WeCom Stream Keepalive: Keep the "Thinking..." placeholder stream alive with periodic refreshes to prevent stuck status indicators in WeCom (#3950)
  • WeCom Reconnect Race: Fixed double reconnect scheduling and cross-event-loop disconnect in WeCom WebSocket handling (#3963)
  • Telegram Network Retry: Added exponential backoff and controlled reconnect for transient Telegram network errors instead of silently dying (#4039)
  • WeChat Cron Buffer Flush: Flush WeChat merge buffer immediately for cron/proactive sends that bypass the normal completion path (#4106)
  • Markdown Table Splitting: Preserve markdown table structure across message chunks by repeating header and separator rows in each fragment (#4119)

Agent System

  • External Agent Timeout: Added safe default timeout (60s) for delegate_external_agent to prevent indefinite hangs (#3928)
  • Agent Config Reload: Agent config file changes now trigger a graceful reload with task draining instead of lightweight reinstantiation (#4064)
  • Agent Config Persistence: Fixed the console agent config editor dropping nested settings on save by preserving the complete config structure (#4157)

MCP

  • MCP Execution Timeout: Use sse_read_timeout as the MCP tool execution timeout instead of the shorter HTTP connect timeout (#4058, #4061)
  • MCP Client Lifecycle Leak: Fixed lifecycle-task leak where close() could skip stopping a background reconnect task (#4152)

Console & UI

  • SSE Surrogate Safety: Avoid SSE stream crash on malformed surrogate text by sanitizing non-encodable content before serialization (#3553)
  • CodeMirror Line Wrapping: Fixed line wrapping in tool call input/output blocks (#3960)
  • Default Agent Display Name: Respect custom name for the default agent in all UI surfaces (#4073)
  • File Preview Paths: Fixed redundant URL prefix stripping in file preview paths that could cause broken URLs (#4089)

Infrastructure

  • Docker Backup Restore: Correctly restore secrets on Docker volume mount points by swapping directory contents instead of renaming (#3916)
  • Audio Block Paths: Return resolved filesystem path for file:// URL audio blocks and remove redundant file handling code (#4021, #4048)
  • Log Rotation: Use RotatingFileHandler for log rotation on all platforms (#4076)
  • Loopback Proxy Bypass: Bypass proxy environment variables for loopback API health checks to prevent connection failures behind corporate proxies (#4092)
  • Conda Packaging: Restore conda packaging tools before running conda-pack to prevent broken packaging pipeline (#4093)

📝 Documentation

  • WSL2 Timeout FAQ: Added FAQ entry for handling APITimeoutError when running in WSL2 NAT mode (#4005)
  • Documentation Update: Updated website documentation to reflect new features (#4013)

🧪 Testing & CI

  • Console Unit Tests: Added Vitest setup with unit and component tests covering Chat, API layer, and shared components (#3559, #4121)
  • Integration Smoke Tests: Added app startup and settings/environment variable smoke tests (#4081)
