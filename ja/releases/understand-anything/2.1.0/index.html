何でもわかる v2.1.0

v2.1.0 の新機能

ビジネスドメインナレッジグラフ

コードベースのビジネス ロジック (ドメイン、フロー、プロセス ステップ) をマッピングする新しい ドメイン グラフ ビュー により、ソフトウェアがどのように構築されているかとともに、ソフトウェアが何を行うかを理解できます。

  • 新しい /understand-domain スキルは、専用のドメイン アナライザー エージェントを使用してビジネス ドメインの知識を抽出します
  • ダッシュボードの ドメイン グラフ ビュー。ビュー モード切り替えピルを使用して、アーキテクチャとドメイン グラフを切り替えることができます。
  • カスタム ノード コンポーネント: DomainClusterNode、FlowNode、StepNode (ドメイン対応 NodeInfo サイドバー付き)
  • 長辺ラベルの間隔が自動的に広がるドメインの概要と詳細のドリルダウン ビュー
  • 新しいコア タイプ: domain、flow、step ノード タイプとドメイン固有のエッジ タイプ
  • コア内の saveDomainGraph / loadDomainGraph 永続化関数

バグ修正

  • レイヤー詳細ビューでノード タイプが表示されない — 関数/クラス ノードがレイヤー詳細に正しく表示されるようになりました (#65、#66)
  • 決定的なノード ID の正規化 — 並列バッチ アナライザーの出力は、実行順序に関係なく一貫した ID を生成するようになりました (#65)
  • 13 のノード タイプすべてを処理 — 生成されたグラフのエッジ クロスバリアント解決とドロップ エッジ トレーサビリティ (#65)
  • ステップ ID の正規化 がテスト カバレッジの追加により改善されました
  • 冗長な下部バー (CodeViewer) がノード click (#55) に表示されなくなりました
  • POSIX 互換フック — より広範なシェル サポートのために、bash のヒアストリングを POSIX パイプに置き換えました (#64)
  • 24 件のプロンプト エンジニアリング監査の問題 7 つのエージェントすべてで修正されました
  • ダッシュボード監査の 8 つの問題 がコンポーネント全体で解決されました

新しいプラットフォームのサポート

  • VS Code + GitHub Copilot エージェント スキルのサポート (#52)

ダッシュボードの機能強化

  • PNG エクスポートの修正: foreignObject をクリーンな SVG プリミティブに置き換えました (#50)
  • ノード タイプ フィルター、パス ファインダー、およびツールチップ (#50)
  • ヘッダー凡例がオーバーフロー時に水平方向にスクロール可能になりました

その他

  • CI: ビルド、テスト、型チェックのための PR ワークフローを追加
  • プロンプトの整合性を確保するために、プロンプト テンプレートをエージェント定義に移動しました
  • すべての README 翻訳にわたってドキュメントが更新されました

Understand-Anything v2.1.0

Highlights

  • Business-domain graph — /understand-domain adds a dedicated analyzer, domain/flow/step nodes, drill-down views, and saveDomainGraph/loadDomainGraph persistence. This lets developers inspect business behavior alongside architecture instead of inferring intent from code structure alone.

  • Reliable generated graphs — Deterministic ID normalization makes parallel analyzer output reproducible regardless of execution order, while cross-variant edge resolution now covers all 13 node types and traces dropped edges (#65). Function/class nodes also appear correctly in layer detail (#65, #66), reducing misleading or incomplete dependency analysis.

  • VS Code + GitHub Copilot support — Agent skills now work with Copilot (#52), bringing the project’s analysis workflows to a broader editor integration without requiring a separate migration.

  • More useful dashboard — Node-type filters, tooltips, and path finding improve graph exploration (#50). PNG export now uses SVG primitives instead of foreignObject, avoiding rendering failures from unsupported SVG/HTML features; overflowing legends scroll horizontally (#50).

  • Portability and prompt maintenance — POSIX-compatible hooks replace Bash-only herestrings (#64), improving shell compatibility. Prompt templates now live inside agent definitions, so customizations should target those definitions; CI also checks builds, tests, and types on pull requests.

  • Breaking changes — None listed in v2.1.0.

What's New in v2.1.0

Business Domain Knowledge Graph

A brand new domain graph view that maps your codebase's business logic — domains, flows, and process steps — so you can understand what the software does alongside how it's built.

  • New /understand-domain skill extracts business domain knowledge using a dedicated domain-analyzer agent
  • Domain graph view in the dashboard with a view mode toggle pill to switch between architecture and domain graphs
  • Custom node components: DomainClusterNode, FlowNode, StepNode with domain-aware NodeInfo sidebar
  • Domain overview and detail drill-down views with auto-widened spacing for long edge labels
  • New core types: domain, flow, step node types and domain-specific edge types
  • saveDomainGraph / loadDomainGraph persistence functions in core

Bug Fixes

  • Missing node types in layer detail view — function/class nodes now correctly appear in layer detail (#65, #66)
  • Deterministic node ID normalization — parallel batch analyzer output now produces consistent IDs regardless of execution order (#65)
  • All 13 node types handled — edge cross-variant resolution and dropped edge traceability for generated graphs (#65)
  • Step ID normalization improved with additional test coverage
  • Redundant bottom bar (CodeViewer) no longer appears on node click (#55)
  • POSIX-compatible hooks — replaced bash herestring with POSIX pipe for broader shell support (#64)
  • 24 prompt engineering audit issues fixed across all 7 agents
  • 8 dashboard audit issues addressed across components

New Platform Support

  • VS Code + GitHub Copilot agent skills support (#52)

Dashboard Enhancements

  • PNG export fix: replaced foreignObject with clean SVG primitives (#50)
  • Node type filters, path finder, and tooltips (#50)
  • Header legends now horizontally scrollable on overflow

Other

  • CI: added PR workflow for build, test, and type-check
  • Prompt templates moved into agent definitions for prompt integrity
  • Docs updated across all README translations

Community Contributors

  • @fishinakleinbottle — deterministic normalization for generated graphs (#65)
  • @pablospe — POSIX-compatible hooks fix (#64)
  • @GarfieldHuang — VS Code + GitHub Copilot plugin (#52)
  • @berkcangumusisik — dashboard export, filtering & path finder (#50)
