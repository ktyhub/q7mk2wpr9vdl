#ドルイドドルイド-0.8.1

0.8.0 からの更新

更新に関する懸念はなく、ローリング アップデートの標準的な更新手順に従うことができます。

新機能

  • #1259 実験的 クエリ時ルックアップ (QTL) -- クエリ時に制限付き結合を実行する機能。 簡単な使用例は、国コードから国名への変換です。
  • #1374 実験的 Hadoop バッチ再インデックス作成とデルタ取り込み。 再インデックスを使用すると、特定の列が削除され、粒度が変更された新しいスキーマを使用して、既存の druid セグメントを取り込むことができます。「デルタ」取り込みでは、データソース内の既存の間隔にデータを追加できます。詳細については、新しい dataSource inputSpec および multi inputSpec を参照してください。

改善点

  • #1465 HDFS から Hadoop 構成ファイルを読み取る
  • #1472 Hadoop インジェストのためのコンバイナーの使用をサポート
  • #1506 取り込み中の null 入力行のサポートが向上しました。
  • #1518 Azure ディープ ストアのサポートが追加されました
  • #1550 すべての HTTP リクエストをログに出力する構成オプションを追加しました。
  • #1563 #1602 Broker でのマージ パフォーマンスの向上
  • #1567 #1568 セグメントアクティビティのエラーログの改善
  • #1596 コーディネーター コンソールが改善され、巨大なコード ダンプの代わりに別個の Maven 依存関係が追加されました。
  • #1601 セグメントスキャン時のロック競合を軽減しました。
  • #1603 辞書編集用 TopN のパフォーマンスの向上
  • #1643 SegmentDescriptorInfo が存在しない理由を説明する役立つ原因 インデックスサービス、取り込み、コーディネーターエンドポイントのテストカバレッジの向上

バグ修正

  • #1406 中間行の最大値を超えた場合に groupBy が中断される問題を修正しました。
  • #1441 出力ストリームを閉じるときにフラッシュエラーが抑制される問題を修正しました。
  • #1469 druid.metadata.* プロパティの一貫性のないプロパティ名を修正しました。
  • #1484 JobHelper.ensurePaths は設定からプロパティを適切に設定します
  • #1499 名前変更されたアグリゲーターによる groupBy キャッシュを修正
  • #1503 ZK のインデックス サービス ステータス ノードのリークを修正しました。
  • #1534 近似ヒストグラムのキャッシュを修正しました。
  • #1616 ローカルインデックスタスクの依存関係エラーを修正
  • #1627 ステータスが成功と表示された後でもシャットダウン時にスタックするリアルタイムタスクを修正しました。
  • #1634 IrcFirehoseFactory が正常にシャットダウンできるようにします
  • #1640 druidサーバーを実行するためのリリースtarball +スクリプトのパッケージ拡張機能
  • #1653 ルータークエリメトリクスで生成される成功フラグを修正しました。
  • #1659 セグメントのキルでは、バージョン、間隔、データソース ディレクトリを HDFS に残さないでください
  • #1681 セグメントの取り込み Firehose で動作しない重複セグメントを修正しました

ドキュメント

  • 消防ホースに関する新しいドキュメント、Druid の評価、および多くの修正。
  • CDH を使用するためのドキュメントの改善
  • PostgreSQL メタデータ ストアの手順を追加
  • 近似ヒストグラムの使用方法に関する詳細ドキュメント 変更の完全なリストは [ここ] (https://github.com/druid-io/druid/compare/0.8.0...0.8.1) でご覧いただけます。

druid druid-0.8.1

Updating from 0.8.0

There should be no update concerns and standard updating procedures can be followed for rolling updates

New Features

  • #1259 Experimental Query Time Lookups (QTL) -– Ability to do limited joins at query time. Simple example use case is Country Code to Country Name.
  • #1374 Experimental Hadoop batch re-indexing and Delta ingestion. Re-Indexing allows you to ingest existing druid segments using a new schema with certain columns removed, changed granularity etc. "Delta" Ingestion allows appending data to existing interval in a datasource. See the new dataSource inputSpec and multi inputSpec for more information.

Improvements

  • #1465 Read Hadoop configuration file from HDFS
  • #1472 Support using combiner for Hadoop ingestion
  • #1506 Better support for null input rows during ingestion
  • #1518 More support added for Azure deep store
  • #1550 Add configuration option to print all HTTP requests to log
  • #1563 #1602 Improved merging performance on Broker
  • #1567 #1568 Improved error logging for segment activities
  • #1596 Improved coordinator console, now a separate maven dependency instead of giant code dump
  • #1601 Reduced lock contention during segment scan
  • #1603 Improved performance of Lexicographic TopNs
  • #1643 helpful cause explaining why SegmentDescriptorInfo did not exist

Improved test coverage for indexing service, ingestion, and coordinator endpoints

Bug Fixes

  • #1406 Fix groupBy breaking when exceeding max intermediate rows
  • #1441 Fix flush errors being suppressed when closing output streams
  • #1469 Fix inconsistent property names for druid.metadata.* properties
  • #1484 JobHelper.ensurePaths will set properties from config properly
  • #1499 Fix groupBy caching with renamed aggregators
  • #1503 Fix leaking indexing service status nodes in ZK
  • #1534 Fix caching for approximate histograms
  • #1616 Fix dependency error in local index task
  • #1627 Fix realtime tasks getting stuck on shutdown even after status being shown as SUCCESS
  • #1634 Allow IrcFirehoseFactory to shutdown cleanly
  • #1640 Package extensions in release tarball + script to run druid servers
  • #1653 Fix success flag emitted in router query metrics
  • #1659 on kill segment, don't leave version, interval and dataSource dir behind on HDFS
  • #1681 Fix overlapping segments not working for ingest segment firehose

Documentation

  • New documentation for firehoses, evaluating Druid, and plenty of fixes.
  • Improved documentation for working with CDH
  • Added instructions for PostgreSQL metadata store
  • More documentation on how to use ApproximateHistograms

The full list of changes can be found here
