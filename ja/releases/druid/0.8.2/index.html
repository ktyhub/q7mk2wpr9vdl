#ドルイドドルイド-0.8.2

0.8.1 からの更新

ユニオン クエリ を使用している場合は、履歴ノード、リアルタイム ノード、またはインデックス サービスを更新する前に、必ずブローカー ノードを更新してください。 それ以外の場合は、標準のローリング アップデート手順に従うことができます。

新機能

  • #1744 Memcached 接続プーリング
  • #1753 SegmentMetadataQuery でカーディナリティとサイズの計算をスキップできるようにします
  • #1609 実験用 kafa シンプルな消費者ベースの消防ホース
  • #1800 実験用ハイブリッド L1/L2 キャッシュ

改善点

  • #1821 QueryableIndexStorageAdapter のキャッシュ最大データ タイムスタンプ
  • #1765 CPUTimeMetricQueryRunner を ClientQuerySegmentWalker に追加
  • #1776 より多くのプロパティを処理するように Twitter Firehose を修正しました
  • #1748 ForkingTaskRunner javaOpts にスペースを含む引用符で囲まれた引数を指定できるようにします
  • #1759 より速く、より小さな轟音ビットマップ
  • #1755 タイムスタンプ解析速度向上のために druid-api を更新
  • #1756 インデックスサービスが見つからない場合のメッセージを改善しました。
  • #1739 SegmentAnalyzer が StorageAdapter から列を読み取ることを許可し、SegmentMetadataQuery がリアルタイム ノードで IncrementalIndexSegments をクエリできるようにします
  • #1732segmentMetadata クエリおよび GET /datasources/<datasourceName> ルックアップに対する構成可能なデフォルトのセグメント履歴期間のサポートを追加しました。
  • #1695 hadoop/anyライブラリを使用するInputRowParser拡張機能の作成を許可します
  • #1688 より多くの memcached メトリクス
  • #1712 SearchQueryにディメンション抽出機能を追加
  • #1696 セグメント スキャンのメトリクスに CPU 時間を追加します。
  • #1718 完了したタスクのインデクサーコンソールにタスク期間を追加します。
  • #1725 GenericIndexedWriter がソートされていないことがすでにわかっている場合は、ソートのチェックを行わない
  • #1699 複数のエミッターを一緒に使用するエミッター モジュールを構成する
  • #1639 新しい配管工
  • #1604 タスクが ForkingTaskRunner の調整と jvm 設定をオーバーライドできるようにします
  • #1542 すべてのデータソースのルール履歴をフェッチするエンドポイントを追加します
  • #1682 HadoopDruidIndexerMapper で BytesWritable 文字列の解析をサポート
  • #1622 EventReceiverFirehoseFactory の JSON Smile フォーマットのサポート
  • #1654 IndexTaskにtaskResourceを提供する機能を追加しました。

バグ修正

  • #1855 [GreaterThan、LessThan、Equals] HaveSpecs を修正
  • #1862 インデックスサービスの中間マネージャーへのシャットダウン要求にタイムアウトを追加

  • #1811 サーバー検出セレクター IPv6 対応
  • #1823 Hadoopバッチ取り込みのdataSource inputSpecの場合、既存のセグメントの読み取りにNONEではなく構成されたクエリ粒度を使用します。
  • #1818 株式検索にハッシュコードと等しい値を追加

druid druid-0.8.2

Updating from 0.8.1

If you are using union queries, please make sure to update broker nodes prior to updating any historical nodes, realtime nodes, or indexing service.

Otherwise, you can follow standard rolling update procedures.

New Features

  • #1744 Memcached connection pooling
  • #1753 Allow SegmentMetadataQuery to skip cardinality and size calculations
  • #1609 Experimental kafa simple consumer based firehose
  • #1800 Experimental Hybrid L1/L2 cache

Improvements

  • #1821 cache max data timestamp in QueryableIndexStorageAdapter
  • #1765 Add CPUTimeMetricQueryRunner to ClientQuerySegmentWalker
  • #1776 Modified the Twitter firehose to process more properties

  • #1759 better faster smaller roaring bitmaps
