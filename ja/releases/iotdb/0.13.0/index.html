iotdb v0.13.0

マイナー 公開日2022年3月18日 出典apache/iotdb English original

#iotdbv0.13.0

新機能

  • [IOTDB-924] SQL での複数行の挿入をサポート
  • [IOTDB-959] ストレージ グループの作成文法を追加
  • [IOTDB-1037] JDBC URL のパラメータとして rpc_compression を設定します
  • [IOTDB-1059] タイムスタンプなしの SQL ステートメントの挿入をサポート
  • [IOTDB-1143] 継続的クエリのサポート
  • [IOTDB-1199] 調整された timeseries とスキーマ テンプレートのサポート
  • [IOTDB-1319] サポートトリガー
  • [IOTDB-1391] 新しい集計関数 Extreme (最大絶対値) を追加
  • [IOTDB-1399] 複数のノードを接続するためのセッション インターフェイスを追加する
  • [IOTDB-1400] SELECT 句での算術演算のサポート
  • [IOTDB-1403] TEXT の辞書エンコーディング
  • [IOTDB-1490] 組み込み UDTF を追加: sinh、conh、tanh
  • [IOTDB-1514] insertTablet での null のサポート
  • [IOTDB-1524] SELECT ... INTO ... 句のサポート
  • [IOTDB-1647] SELECT 句のネストされた式
  • [IOTDB-1673] CLI から JLine3 へのアップグレード
  • [IOTDB-1739] 定数時系列生成関数 (const、pi、e)
  • [IOTDB-1760] 塗りつぶしによるグループでの avg、count、extreme、first_value、last_value、max_time、max_value、min_time、min_value、合計集計のサポート
  • [IOTDB-1761] IoTDB のメトリック フレームワークを追加
  • [IOTDB-1775] データ型を変換する CAST 関数を追加
  • [IOTDB-1823] マルチレベルによるグループのサポート
  • [IOTDB-1844] クエリ サポート timeseries のプレフィックスとサフィックスの一致: root.*sg*
  • [IOTDB-1859] REST API のサポート
  • [IOTDB-1860] 新しい Grafana プラグイン
  • [IOTDB-1886] 選択句での定数式のサポート
  • [IOTDB-1973] SELECT 句で集計クエリ、定数、算術ネストされた式をサポート
  • [IOTDB-1986] alisa 句として選択 UDF をサポート
  • [IOTDB-1989] Spark-IoTDB コネクタによるデータの挿入のサポート
  • [IOTDB-2131] 以前の線形定数値フィル関数をサポート 新しいフィル
  • [IOTDB-2593] JDK17 での IoTDB の使用のサポート
  • [ISSUE-3811] 最後のクエリ データセットのデータ型列を提供する
  • Rabbitmq の例を追加

改善点

  • [IOTDB-1280] Antlr 文法ファイルを書き換える
  • [IOTDB-1372] TsFileResource の管理を強化
  • [IOTDB-1428] クエリがタイムアウトした場合、クエリ スレッドに終了を要求する
  • [IOTDB-1450] 削除では関連するタイム パーティションのみを削除する必要があります
  • [IOTDB-1463] Session および SessionPool のビルダー パターンを実装する
  • [IOTDB-1477]generateAlignByDevicePlan() のコード ロジックを最適化します。
  • [IOTDB-1559] IT フレームワークのリファクタリング
  • [IOTDB-1564] ハートビートと選出タイムアウトのパラメータを構成可能にする
  • [IOTDB-1581] 不完全な tsfile の tsFileResource を回復するときに削除を考慮する
  • [IOTDB-1607] トレースの最適化
  • [IOTDB-1613] 書き込み変更が失敗した場合に mods ファイルを復元する
  • [IOTDB-1639] クラスター クラス構造をリファクタリングしてサーバー モジュールとの一貫性を確保
  • [IOTDB-1730] client-cpp、session::insertTablet() などのパフォーマンスを強化
  • [IOTDB-1852] 統計を使用してクエリを高速化する
  • [IOTDB-1857] クラスターモジュールのexecuteNonQueryのCountPlanの不要なハンドルロジックを削除
  • [IOTDB-1884] 合計集計でゼロ値と null 値を区別する
  • [IOTDB-1924] 圧縮終了後にキャッシュをクリアする操作を削除
  • [IOTDB-1950] クエリにブルーム フィルター キャッシュを追加
  • [IOTDB-2001] 冗長な StorageGroupNotReadyException を削除する
  • [IOTDB-2011] 最新の時系列クエリを表示中に最後のキャッシュを更新する
  • [IOTDB-2022] SessionDataSet は AutoCloseable を実装します
  • [IOTDB-2075] スレッド プールを使用して insertTablets のプロセスを高速化する
  • [IOTDB-2119] IoTDB CSV エクスポートツールにタイムスタンプ精度設定機能を追加
  • [IOTDB-2162] リカバリ マージ プロセスを簡素化する
  • [IOTDB-2176] 内部空間圧縮を実行する際のターゲット チャンク サイズを制限する
  • [IOTDB-2193] RaftLogManager の不要なロック操作を減らし、書き込みパフォーマンスを向上させます。
  • [IOTDB-2195] 同時クエリ実行スレッドを制御する
  • [IOTDB-2632] Compaction_write_throughput_mb_per_sec をデフォルトで 16 に設定します
  • [ISSUE-3445] 新しい圧縮戦略と圧縮スケジュール戦略
  • [ISSUE-3856] RaftLogManager の commitTo の例外処理ロジックを改良する
  • [クラスター] 1 つのノードが再起動するときにクラスター自体と握手をする必要はありません

互換性のない変更

  • [IOTDB-1026] パスでワイルドカード ** をサポートし、IOTDB-SQL で PrefixPath の使用を PathPattern に置き換えます
  • [IOTDB-1620] 識別子を引用するバックティック (`) 文字と二重引用符 (") をサポート
  • [IOTDB-1650] SQL コマンドの名前を move から unload に変更します

その他の変更点

  • [IOTDB-1342] FILL 句と組み合わせて使用される LIMIT および OFFSET に関するエラー メッセージを変更する
  • [IOTDB-1372] FileTimeIndex のデバイス フィールドを削除します
  • [IOTDB-1531] リカバリ時に tsfile の作成時間を確認する
  • [IOTDB-1541] 挿入時の wal と memtable のシーケンスを変更する
  • [IOTDB-1923] TSServiceImpl のリクエスト展開と実行処理ロジックを分離する
  • [IOTDB-1969] 古いメトリック フレームワークの統計リソースを iotdb-server から削除します
  • [IOTDB-2014] MicrometerPrometheusReporter#getReporterType が null を返す
  • [IOTDB-2043] リファクタリング: セッションから haveSorted パラメータを削除
  • [IOTDB-2154] TsFileUtils.isTsFileComplete を追加
  • [IOTDB-2206] StorageGroupProcessor の名前を VirtualStorageGroupProcessor に変更
  • [IOTDB-2208] クエリの結果セットヘッダーを生成するプロセスを再構築します
  • [ISSUE-4047] Statistics extend Serializable のジェネリック型
  • キャッシュキーに圧縮バージョンを追加 ※インスタンス化を禁止するIoTDBDescriptorHolderのコンストラクタを追加

  • [IOTDB-1478] 1 つの sg の準備ができていない場合、IoTDB 全体が読み取り/書き込みできません
  • [IOTDB-1562] insertXXX() API の誤った例外処理を修正

iotdb v0.13.0

New Features

  • [IOTDB-924] Support insert multi rows in SQL
  • [IOTDB-959] Add Create Storage Group Grammar
  • [IOTDB-1037] set rpc_compression as a parameter in JDBC URL

  • [IOTDB-1143] Support Continuous query
  • [IOTDB-1199] Support aligned timeseries and schema template
  • [IOTDB-1319] Support Trigger
  • [IOTDB-1391] Add a new Aggregation function extreme (max absolute value)
  • [IOTDB-1399] Add a session interface to connect multiple nodes
  • [IOTDB-1400] Support arithmetic operations in SELECT clauses
  • [IOTDB-1403] Dictionary encoding for TEXT
  • [IOTDB-1490] Add built-in UDTFs: sinh, conh, tanh
  • [IOTDB-1514] Support null in insertTablet
  • [IOTDB-1524] Support SELECT ... INTO ... clause
  • [IOTDB-1647] Nested Expressions in SELECT clauses
  • [IOTDB-1673] CLI upgrade to JLine3
  • [IOTDB-1739] Constant timeseries generating functions (const, pi and e)
  • [IOTDB-1760] Support avg, count, extreme, first_value, last_value, max_time, max_value, min_time, min_value, sum aggregations in group by fill
  • [IOTDB-1761] Add metric framework for IoTDB
  • [IOTDB-1775] Add CAST function to convert data type
  • [IOTDB-1823] Support group by multi level
  • [IOTDB-1844] Query support timeseries prefix and suffix matching: root.*sg*
