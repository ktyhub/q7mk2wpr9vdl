ponytail v4.13.0

マイナー 公開日2026年10月5日 出典DietrichGebert/ponytail English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ポニーテールv4.13.0 このリリースの主な目的は、ポニーテールを設定したレベルに維持することです。 Codex でレベルを切り替えると、新しいレベルのルールが提供されるようになり、各プロジェクトは独自のモードを維持し、オフは実際にはオフを意味し、ステータスライン バッジはプラグインの更新後も存続します。 Kim Code が新しいホストとして加わり、README はスペイン語、韓国語、簡体字中国語、日本語でも提供されるようになり、ZCode のサポートは終了しました。

何が変わったのか

  • fix(hooks): https://github.com/DietrichGebert/ponytail/pull/677 の @l2yujw による無効な引数の保存モード
  • 修正(フック): Qoder レポート専用 /pon で 2 番目の JSON オブジェクトを出力しないようにします… by @adiraj66132 in https://github.com/DietrichGebert/ponytail/pull/617

ponytail v4.13.0

This release is mostly about ponytail staying at the level you set. Switching levels on Codex now delivers the new level's rules, each project keeps its own mode, off really means off, and the statusline badge survives plugin updates. Kimi Code joins as a new host, the README now also comes in Spanish, Korean, Simplified Chinese and Japanese, and ZCode support is dropped.
