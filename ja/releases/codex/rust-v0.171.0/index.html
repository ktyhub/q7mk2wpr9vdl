codex rust-v0.171.0

リリース 公開日2026年11月20日 出典openai/codex English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

コーデックス rust-v0.171.0

新機能

  • GPT-6.2 Sol と Astra をモデル カタログに追加し、Sol をデフォルトのカタログ選択として追加しました。 (#62106)
  • TUI ワークスペースがデフォルトで有効になり、メインの会話に加えて検索可能なドキュメント プレビュー、画像プレビュー、サブエージェントのトランスクリプトが表示されます。 (#61352、#61888、#61889、#61919、#62157)
  • 添付ファイルや大きなペーストの復元を含む、構成可能な元に戻すおよびやり直しのショートカットを非 Vim プロンプト コンポーザーに追加しました。 (#61954)
  • 既存のアプリサーバーで非対話型セッションを開始または再開するための codex exec --remote <ADDR> を追加しました。 (#61707)
  • ローカル リモート コントロールを管理し、TUI からデバイス ペアリング コードを表示するための /rc および /remote を追加しました。 (#62121)
  • tui_extensions_statusline が有効な場合、/statusline を介したカスタム MCP ステータス ラインの選択とオーサリングが追加されました。 (#61979、#61988、#62037)

バグ修正

  • セッションの切り替えまたは再開時に、下書きを保存し、フォローアップをキューに入れ、元のスレッドで入力を中断します。 (#61216)
  • 作業ディレクトリを変更するときに、権限プロファイルがそのまま維持されました。 (#61195)
  • 遅延完了イベントによって新しいターンの承認がキャンセルされるのを防ぎました。 (#61801)
  • アクティブなターンをステアリングするときに、以前の編集が集計差分に保存されます。 (#61820)
  • はぐれ文字を挿入するスクロール、コンポーザー キャレット ジャンプ、および古いターミナルの寸法を使用した再描画を修正しました。 (#62139、#62174、#62175)
  • 更新トークンなしで ID トークンを発行する ID プロバイダーのエンタープライズ MCP サインインを修正しました。 (#62129)

雑用

  • ソース ビルドとリリース ツールを Rust 1.99.1 に更新しました。 (#61205)
  • XML 依存関係を更新し、古いセキュリティ勧告の例外を削除しました。 (#62068)
