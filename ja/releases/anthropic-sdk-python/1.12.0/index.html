anthropic-sdk-python v1.12.0

Highlights

  • New model and typed tool calls — Adds claude-haiku-5-5 alongside typed computer-use and browser toolset tool calls (f6346e6). The typed calls are the real story: you get checked, autocompleted shapes for computer/browser actions instead of hand-built dicts, so adopting them means replacing any loosely-typed tool-call handling — worth doing for the type safety alone.

  • Richer model capability discovery — /v1/models gains lifecycle-stage fields and a lifecycle filter, model objects gain a line field, and capabilities now surface web search, code execution, and a disabled state on thinking types (0c96c02, a85c649, 78d815d). Practically, you can now introspect what a model supports and gate features at runtime instead of hardcoding model-name allowlists — wire this into any model-selection logic.

  • RBAC role field rename — display_name is added to RBAC roles and name is deprecated (f63f99c). Not a hard break, but any code that reads or asserts on role.name should migrate to display_name now; the deprecated field is a countdown to a future major.

  • Query-param and multipart behavior change — The client now sends empty strings in query params and multipart forms (80e69f1), with the previously skipped tests re-enabled (d606929). Watch out: if you passed "" expecting it to be dropped, those requests now carry an explicit empty value, which can change server-side filter behavior. Separately, listing spend limits now sends the beta header by default (e2690b4), so check for callers still adding it manually.

  • Tool/memory upload resilience — Fixes a case where a local edit made after a memory upload was clobbered when the upload response was lost (#990). Relevant if you do optimistic local edits around tool memory operations: the SDK now preserves your local change instead of overwriting it on a dropped response.

  • Managed Agents web_fetch config — Adds url_sources to the web_fetch tool config (78d815d), and docs now pin the agent tools limit at 256 (e4eff6b). Useful if you configure Managed Agents web fetching — you can now scope allowed URL sources, and keep tool sets under the documented cap.

No breaking changes.
