opendataloader-pdf v2.5.1

何が変わったのか

  • ci: https://github.com/opendataloader-project/opendataloader-pdf/pull/641 の @bundolee によるビルド前にデプロイ資格情報を検証するリリース プリフライトを追加
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/637 の @MaximPlusov によるマークダウン出力に < と > の escaping を追加します
  • ドキュメント: エージェント スキルを追加して、エージェントが opendataloader-pdf を正しく使用できるようにします (https://github.com/opendataloader-project/opendataloader-pdf/pull/647 の @hyunhee-jo 作成)
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/648 の @MaximPlusov によるマークダウンおよび HTML 出力のリスト ラベル表現を改善
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/659 の @LonelyMidriya によるカスタム RENDER_DPI を設定するための画像解像度オプションを追加
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/651 の @LonelyMidriya により、struct-tree 要素から Lists に ListNumbering を設定します
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/649 に @LonelyMidriya による空間比オプションを追加
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/653 の @MaximPlusov による TOC 検出を改善
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/667 の @LonelyMidriya による sortPageContents のコンパレータの IllegalArgumentException を修正
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/670 の @LonelyMidriya による needToAddAnnotationToStructTree() の NPE を修正
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/672 の @LonelyMidriya によりログから例外スタック トレースを削除
  • https://github.com/opendataloader-project/opendataloader-pdf/pull/677 の @MaximPlusov により verapdf バージョンを更新
  • 修正 (コア): https://github.com/opendataloader-project/opendataloader-pdf/pull/679 で @bundolee が一時ディレクトリに書き込みできない場合に高速に失敗する
  • chore(deps): python/opendataloader-pdf の Tier 3 パッケージを https://github.com/opendataloader-project/opendataloader-pdf/pull/680 の @bundolee によってバンプします
  • chore(deps)!: バンプ暗号 48 -> 50 および mcp in python/opendataloader-pdf-mcp by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/681
  • chore(deps): Node 24 / pnpm 11 を統合し、https://github.com/opendataloader-project/opendataloader-pdf/pull/682 の @bundolee による postcss オーバーライドを修正
  • 修正(テスト): lorem.json サンプルを https://github.com/opendataloader-project/opendataloader-pdf/pull/687 の @bundolee によって出力された pdfua_tag と同期します
  • 雑務: https://github.com/opendataloader-project/opendataloader-pdf/pull/688 の @bundolee によるスケジュールされたバンプ PR を停止するために、Dependabot 構成を削除します
  • 修正(リリース): https://github.com/opendataloader-project/opendataloader-pdf/pull/689 の @bundolee によってバージョンが注入されたツリー上で pnpm バージョンを実行できるようにする フル Changelog: https://github.com/opendataloader-project/opendataloader-pdf/compare/v2.5.0...v2.5.1

opendataloader-pdf v2.5.1

What's Changed

  • ci: add release preflight to verify deploy credentials before the build by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/641
  • Add escaping for < and > to markdown output by @MaximPlusov in https://github.com/opendataloader-project/opendataloader-pdf/pull/637
  • docs: add an Agent Skill so agents use opendataloader-pdf correctly by @hyunhee-jo in https://github.com/opendataloader-project/opendataloader-pdf/pull/647
  • Improve list label representation in markdown and html output by @MaximPlusov in https://github.com/opendataloader-project/opendataloader-pdf/pull/648
  • Add image-resolution option for setting custom RENDER_DPI by @LonelyMidoriya in https://github.com/opendataloader-project/opendataloader-pdf/pull/659
  • Set ListNumbering in Lists from struct-tree element by @LonelyMidoriya in https://github.com/opendataloader-project/opendataloader-pdf/pull/651
  • Add space-ratio option by @LonelyMidoriya in https://github.com/opendataloader-project/opendataloader-pdf/pull/649
  • Improve TOC detection by @MaximPlusov in https://github.com/opendataloader-project/opendataloader-pdf/pull/653
  • Fix IllegalArgumentException in Comparator for sortPageContents by @LonelyMidoriya in https://github.com/opendataloader-project/opendataloader-pdf/pull/667
  • Fix NPE in needToAddAnnotationToStructTree() by @LonelyMidoriya in https://github.com/opendataloader-project/opendataloader-pdf/pull/670
  • Remove Exception stack trace from logs by @LonelyMidoriya in https://github.com/opendataloader-project/opendataloader-pdf/pull/672
  • Update verapdf version by @MaximPlusov in https://github.com/opendataloader-project/opendataloader-pdf/pull/677
  • fix(core): fail fast when the temporary directory is not writable by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/679
  • chore(deps): bump tier 3 packages in python/opendataloader-pdf by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/680
  • chore(deps)!: bump cryptography 48 -> 50 and mcp in python/opendataloader-pdf-mcp by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/681
  • chore(deps): unify Node 24 / pnpm 11 and fix postcss override by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/682
  • fix(test): sync lorem.json sample with pdfua_tag output by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/687
  • chore: remove Dependabot config to stop scheduled bump PRs by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/688
  • fix(release): let pnpm version run on the version-injected tree by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/689
