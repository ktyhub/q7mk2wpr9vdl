MetaGPT v0.5.0

#メタGPT v0.5.0

リリースのハイライト

全体的に

  1. 多言語サポート (実験的): 中国語と英語の両方、および理論的には他の言語もサポートされるようになりました。
  2. 複数のプログラミング言語のサポート (実験的): さまざまなプログラミング言語のサポートが利用可能になり、JavaScript プロジェクトを自然に生成できるようになりました。ただし、Python では GPT-4-turbo の機能が大幅に強化されており、他のプログラミング言語では改善の余地がかなりあることに注意してください。
  3. 増分開発 (実験的): 要件とバグ修正を段階的に引き上げることができるようになり、生成されたリポジトリをさらに最適化できるようになりました。
  4. CLI サポート: metagpt "make a 2048 game" を使用して、metagpt がコマンド ラインで直接ソフトウェアを作成できるようになりました。 metagpt --help を使用すると、さらに多くの機能のロックを解除できます。
  5. PIP サポート: pip install metagpt を使用して、metagpt をインストールして使用できるようになりました。これにより、metagpt のコマンドライン バージョンに直接アクセスできるようになります。
  6. 強化されたコード レビュー: 生成されたコードは、より包括的なコード レビューを受けるようになり、コードの品質が大幅に向上します。
  7. Git によるファイル管理: 完全な Git 履歴を備えた独立したドキュメント ワークスペースを使用して、履歴コードの変更を記録するようになりました。
  8. 最適化されたメッセージング メカニズム: プライベート化されたロール メモリ。ブロードキャスト、グループ メッセージング、およびプライベート メッセージングをサポートするロール間メッセージング メカニズムを提供します。

何が変わったのか

下位互換性のない変更

  • Role.recv と Role.handle を取り外します。対応するロジックは Role._observe に移動されます
  • Role._publish_message -> Role.publish_message
  • Team.start_project -> Team.run_project。インクリメンタル開発をサポートしているため、プロジェクトを最初から「開始」するのではなく、プロジェクトの実行全般を指すために「実行」を使用します。 インクリメンタル開発 と新しい メッセージング メカニズム については、ドキュメント サイトで説明する予定です。お待ちください。

特徴

  • 重要: 多言語サポート (実験的)、複数のプログラミング言語サポート (実験的)、インクリメンタル開発 (実験的)、CLI サポート、pip サポート、強化されたコード レビュー、ドキュメント メカニズム、@iorisa @geekan #552 による最適化されたメッセージング メカニズム。詳細については、上記のハイライトを確認してください。

MetaGPT v0.5.0

Highlights

  • Breaking API changes — Role.recv and Role.handle were removed; their logic moved to Role._observe. Rename Role._publish_message to Role.publish_message and Team.start_project to Team.run_project. Also migrate BossRequirement to UserRequirement. Custom roles, teams, and integrations must be updated before upgrading.
  • Experimental generation capabilities — Adds multilingual output, JavaScript and other programming-language generation, and incremental development for refining requirements and fixing bugs in an existing generated repository. These are the main reasons to upgrade, but quality varies by language and the changelog explicitly notes stronger Python results with GPT-4-turbo.
  • CLI and installation workflow — Adds pip install metagpt and a Typer-based metagpt CLI, including metagpt "make a 2048 game", --project-path, and --help. Configuration now prioritizes ~/.metagpt/config.yaml, supports METAGPT_PROJECT_ROOT, and defaults to gpt-4-1106-preview; review that model change for cost and output differences.
  • Changed repository and review behavior — Project files and documentation history are managed through FileRepository with Git-backed history, while role memory becomes private and Message is reduced mainly to event notification. Code review is more stringent: code_review_k_times defaults to 2, LGTM/LBTM responses are supported, and review stops on LGTM without rewriting code.
  • Upgrade recommendation — Worth upgrading for CLI users and developers who need incremental or multilingual generation, provided they complete the API migration. Existing API-based Python workflows can skip this release if those capabilities are unnecessary, especially where stable behavior matters more than experimental improvements.

Release Highlights

Overall

  1. Multilingual Support (Experimental): Now supports both Chinese and English, and theoretically other languages.
  2. Multiple Programming Languages Support (Experimental): Support for various programming languages is now available, allowing for the natural generation of JavaScript projects. However, it's noted that GPT-4-turbo has significantly stronger capabilities in Python, and there is considerable room for improvement with other programming languages.
  3. Incremental Development (Experimental): It's now possible to incrementally raise requirements and bug fixes, allowing for further optimization of the generated repo.
  4. CLI Support: You can now use metagpt "make a 2048 game" to let metagpt write software directly in the command line. More features can be unlocked with metagpt --help.
  5. PIP Support: pip install metagpt is now available for installing and using metagpt, enabling direct access to the command-line version of metagpt.
  6. Enhanced Code Review: The generated code now undergoes a more comprehensive code review, which significantly improves code quality.
  7. File Management with Git: An independent documentation workspace with a complete git history is now used to record changes in historical code.
  8. Optimized Messaging Mechanism: Privatized Role memory, providing an inter-Role messaging mechanism that supports broadcasting, group messaging, and private messaging.

What's Changed

Backwards Incompatible Changes

  • Remove Role.recv and Role.handle. Corresponding logic is moved into Role._observe
  • Role._publish_message -> Role.publish_message
  • Team.start_project -> Team.run_project. Given we support incremental development, we use "run" to refer to project execution in general, as opposed to "starting" a project from scratch

We will explain incremental development and the new messaging mechanism on the documentation site, stay tuned!

Features

  • IMPORTANT: Multilingual support (experimental), multiple programming languages support (experimental), incremental development (experimental), CLI support, pip support, enhanced code review, documentation mechanism, optimized messaging mechanism by @iorisa @geekan #552 . Check out the highlights above for details.

Bugfixes and improvements

  • Add gpt-4-turbo and gpt-3-turbo-1106 in openai token count by @WannaTen #548
  • Fix spelling errors in prompt by @0aaryan #554
