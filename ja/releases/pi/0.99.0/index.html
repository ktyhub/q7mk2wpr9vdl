pi v0.99.0

マイナー 公開日2026年9月29日 出典earendil-works/pi English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

パイv0.99.0

新機能

  • コードモードと MCP - MCP サーバーを接続し、ツールを並行して呼び出す JavaScript をモデルに実行させます。 MCP サーバー および コードモードを有効にする を参照してください。
  • システム テーマ — Pi の色は、デフォルトで端末独自のパレットから取得されるようになりました。 端末の色を使用するを参照してください。
  • ChatGPT でサインイン — /login openai を通じて OpenAI プロバイダーで ChatGPT サブスクリプションを使用します。 対話形式で認証する を参照してください。
  • 仮想モデル — 拡張機能は、各リクエストを異なる物理モデルにルーティングできます。 仮想モデル を参照してください。
  • 分類子モデル — コードモード スクリプトから Jev 分類子を実行するか、任意の llama.cpp モデルを分類子として使用します。 コードモードの仕組み および 分類 を参照してください。

追加

  • コードモード、ツール検索、MCP サポートを組み込み拡張機能として追加しました。 codemode ツールは、pi のツールを呼び出す QuickJS サンドボックス内でモデルで記述された JavaScript を実行します。 defaultTools または --tools で有効にし、codemode.mode と codemode.inlineBudget で構成します。 tool_search は、モデルに宣言されていないツールを見つけて宣言します。 OAuth を使用した標準入出力またはストリーミング可能な HTTP 経由の MCP サーバーは、mcp.json (グローバル、または trusted 後のプロジェクトごと) または pi.registerMcpServer() から取得され、/mcp および pi mcp add|remove|list|login|logout で管理されます。 MCP サーバー および コードモードを有効にする (#10040) を参照してください。
  • オーケストレーション ツール用の拡張ツール API を追加しました: exposure (direct、model-only、codemode、deferred、または hidden)、namespace、annotations、outputSchema (structuredContent、isError 結果付き)、ネストされたツール呼び出し用の prepareLoadout()、ctx.executeTool()。 parentToolCallId でイベントを発行し、呼び出しツールの結果に制限付き nestedCalls として記録されます。 工具露出を参照してください。
  • 同じツール、コマンド、またはフラグを登録する拡張機能が組み込み拡張機能 (#10174 by @cristinaponcela) を置き換える場合の警告を追加しました。
  • 実験的な仮想モデルを追加しました。拡張機能はそれらを pi.registerVirtualModel() に登録し、リクエストごとに物理モデルと思考レベルを選択します。フッターにはルーティングされたモデルが表示され、/session には物理モデルごとのコストがリストされ、examples/extensions/jev-router.ts には Jev 分類子を使用したルートが表示されます。 仮想モデル を参照してください。
  • /login の OpenAI プロバイダーに ChatGPT によるサインインを追加しました。これは、OpenAI API で ChatGPT サブスクリプションを使用します。 Pi は安定した deviceId をこのログインのグローバル設定に保存し、バグ レポートから除外します。
  • system テーマを追加しました。現在はデフォルトです。このテーマは、端末の報告された前景、背景、および ANSI パレットから pi の色を導出し、端末が明暗を切り替えるときにそれらを再構築します。 端末の色を使用するを参照してください。
  • テーマ ファイルに #rgb、oklch()、okhsl() の色とオプションの appearance フィールドを追加し、拡張子に theme.style()、theme.colors、theme.appearance を追加しました。 テーマ および TUI を参照してください。
  • すべての llama.cpp チャット モデルに、次のトークンのラベル確率から応答する分類子モデルを追加しました。 分類を参照してください。
  • OpenRouter、Cloudflare Workers AI、Vercel AI Gateway、OpenCode Zen に継承された Jev 分類子モデルを追加しました。
  • 全画面マウス ホイール スクロール用の fullscreenWheelScrollLines 設定と /settings エントリを追加しました。デフォルトの "auto" は、ローカル macOS 端末の外側での高速ホイール スピンを加速します (#9758)。
  • 成功した RPC prompt、steer、follow_up 応答、AgentSession.steer()/followUp()、RpcClient.prompt()/steer()/followUp() に入力ごとの処理を追加しました。 RpcClient.prompt() は streamingBehavior (#9098、#9803) も受け入れます。
  • ModelRuntime にイメージ生成を追加しました: ランタイム解決認証 (保存された資格情報、OAuth、ランタイム API キー、models.json ヘッダー) を備えた generateImages()、および getModelsOfType()、getModelOfType()、getAvailableOfType()、getAllModels()、および getAllAvailable()。 OpenRouter イメージ モデルは openrouter プロバイダーの下にリストされ、その資格情報を共有します。アップストリーム ID には、個別のチャット エントリと画像エントリを含めることができます。 models.json プロバイダーとモデル リストのない拡張機能の登録では、組み込みのイメージ生成が維持されます。拡張モデルのリストには、操作の実装を伴う識別されたチャット、画像、および分類子のエントリを含めることができます。提供されると、すべての操作でプロバイダー カタログが置き換えられます。チャット向け読み取り (getModels()、getAvailableSnapshot()、モデル ピッカー) は変更されません。
  • classify()、分類子モデル アクセサー、ランタイム解決認証、組み込み TypeSafe jev-latest モデルを含む、分類子のサポートを ModelRuntime に追加しました。
  • types=chat,image,classifier を pi.dev モデル カタログ リクエストに追加したため、リモート更新でサポートされているすべてのモデル タイプがオーバーレイされるようになりました。不明なモデル タイプのエントリは無視されます。
  • オプトイン /debug-provider サンプル ビューア (@davidbrai による #9784、#9901) を使用して、正規化前に解析されたプロバイダー イベントを観察するための provider_stream_event 拡張イベントを追加しました。
  • display: false とマークされたカスタム メッセージの HTML エクスポートに表示/非表示切り替え (H) を追加しました。メッセージはデフォルトでは非表示のままですが、サイドバーから表示することもできます (@rwachtler による #8896、#10020)。
  • 適応的思考と 1M コンテキスト ウィンドウを備えた Anthropic の継承された Claude Sonnet 5.5 サポートを追加しました。
  • pi config に組み込みセクションを追加して、組み込み mcp、llama.cpp、codemode、および tool-search 拡張機能をグローバルまたはプロジェクトごとに無効にし、extensions 設定に -builtin:<name> として保存しました。 SDK インライン拡張機能は builtin: true でオプトインされます。
  • +name および -name エントリを defaultTools 設定に追加し、デフォルト ("defaultTools": ["+codemode"] など) を繰り返すことなくツールを追加または削除できるようになりました。このフォームのプロジェクト エントリは、ユーザー設定に加えて適用されます。 MCP なしで codemode を有効にする方法と、コードモード スクリプトから Jev などの分類子モデルを使用する方法を文書化しました。
  • コードモード models.classify() 呼び出しのトークン使用量とコストをコードモード ツールの結果に追加したため、セッション コストにカウントされます。コードモードの結果には、各呼び出しのコストが表示されます。

変更されました

  • ビルドを TypeScript ネイティブ プレビューから ES2024 ターゲットを使用した TypeScript 7.0 に切り替え、ソースから実行するためのノードの組み込みタイプ ストリッピングで tsx を置き換えました (#9965)。
  • 起動バナーから [Themes] セクションを削除しました。カスタム テーマは /settings で引き続き使用でき、テーマの競合は依然として報告されています。
  • 起動ヘッダーを変更して、アプリ名の代わりにバージョンを含む pi ロゴを表示するようにしました。
  • 組み込みの dark および light テーマを、OKHSL で書かれた改訂された pi カラーに変更しました。
  • 最初に報告された背景色を使用し、次に端末の明/暗レポート、次に COLORFGBG を使用するように明/暗端末検出を変更しました。初回セットアップでは、検出された外観が表示されなくなりました。
  • 継承された OpenAI Codex プロバイダーの名前を「OpenAI Codex (legacy)」に変更しました。 OpenAI プロバイダーの ChatGPT を使用したサインインがこれに優先します。
  • TERM=*-direct をトゥルーカラーとして扱うように、継承された端末の検出を変更しました。
  • 組み込みの拡張機能とツールは、エラー、診断、RPC ソース情報、バグ レポートでは、<inline:name> や <builtin:name> ではなく、builtin:<name> (例: builtin:mcp や builtin:read) という名前になります。彼らのスラッシュ コマンドには、[t] オートコンプリート タグが含まれなくなりました。
  • --no-extensions は、llama.cpp プロバイダーを含む組み込み拡張機能も無効にします。 ZZPH100​​ZZ を使用して明示的にロードします (例: pi -ne -e builtin:mcp)。
  • カスタム コール レンダラーを使用しないツール呼び出し (MCP ツールの直接呼び出しを含む) では、引数が表示されます。折りたたまれた場合はタイトル行に key=value ペアとして、展開された場合は引数ごとに 1 つの key: value 行として表示されます。 MCP 呼び出しのタイトルは server/tool で、その結果は 5 行に折りたたまれます。
  • コードモード スクリプトが受け取る bash および powershell 構造化結果は、モデル側の 2000 行または 50KB の代わりに最大 1 MiB の出力を保持し、truncated および full_output_path が追加されました。より長い出力では、最初と最後の 512 KiB が保持されます。空の出力は、(no output) ではなく "" です。

pi v0.99.0

New Features

  • Codemode and MCP — Connect MCP servers and let models run JavaScript that calls tools in parallel. See MCP Servers and Enable codemode.
  • System theme — Pi's colors now come from your terminal's own palette by default. See Use your terminal's colors.
  • Sign in with ChatGPT — Use a ChatGPT subscription with the OpenAI provider through /login openai. See Authenticate interactively.
  • Virtual models — Extensions can route each request to a different physical model. See Virtual Models.
  • Classifier models — Run Jev classifiers from codemode scripts, or use any llama.cpp model as a classifier. See How codemode works and Classification.

Added

  • Added codemode, tool search, and MCP support as built-in extensions. The codemode tool runs model-written JavaScript in a QuickJS sandbox that calls pi's tools; enable it with defaultTools or --tools and configure it with codemode.mode and codemode.inlineBudget. tool_search finds tools that are not declared to the model and declares them. MCP servers over stdio or streamable HTTP, with OAuth, come from mcp.json (global, or per project once trusted) or pi.registerMcpServer() and are managed with /mcp and pi mcp add|remove|list|login|logout. See MCP Servers and Enable codemode (#10040).
  • Added extension tool APIs for orchestrating tools: exposure (direct, model-only, codemode, deferred, or hidden), namespace, annotations, outputSchema with structuredContent, isError results, prepareLoadout(), and ctx.executeTool() for nested tool calls, which emit events with parentToolCallId and are recorded as bounded nestedCalls on the calling tool's result. See Tool exposure.
  • Added a warning when an extension that registers the same tool, command, or flag replaces a built-in extension (#10174 by @cristinaponcela).
  • Added experimental virtual models: extensions register them with pi.registerVirtualModel() and pick a physical model and thinking level for each request. The footer shows the routed model, /session lists cost per physical model, and examples/extensions/jev-router.ts routes with the Jev classifier. See Virtual Models.
  • Added Sign in with ChatGPT to the OpenAI provider in /login, which uses a ChatGPT subscription with the OpenAI API. Pi stores a stable deviceId in the global settings for this login and omits it from bug reports.
  • Added the system theme, now the default, which derives pi's colors from the terminal's reported foreground, background, and ANSI palette and rebuilds them when the terminal switches between light and dark. See Use your terminal's colors.
  • Added #rgb, oklch(), and okhsl() colors and an optional appearance field to theme files, and theme.style(), theme.colors, and theme.appearance for extensions. See Themes and TUI.
  • Added a classifier model for every llama.cpp chat model, answered from next-token label probabilities. See Classification.
  • Added inherited Jev classifier models on OpenRouter, Cloudflare Workers AI, Vercel AI Gateway, and OpenCode Zen.
  • Added the fullscreenWheelScrollLines setting and /settings entry for fullscreen mouse-wheel scrolling. The default "auto" accelerates fast wheel spins outside local macOS terminals (#9758).
  • Added per-input disposition to successful RPC prompt, steer, and follow_up responses, AgentSession.steer()/followUp(), and RpcClient.prompt()/steer()/followUp(); RpcClient.prompt() also accepts streamingBehavior (#9098, #9803).
  • Added image generation to ModelRuntime: generateImages() with runtime-resolved auth (stored credentials, OAuth, runtime API keys, models.json headers), plus getModelsOfType(), getModelOfType(), getAvailableOfType(), getAllModels(), and getAllAvailable(). OpenRouter image models are listed under the openrouter provider and share its credential; an upstream ID can have separate chat and image entries. models.json providers and extension registrations without a model list keep built-in image generation. Extension model lists can include discriminated chat, image, and classifier entries with operation implementations; when supplied, they replace the provider catalog across every operation. Chat-facing reads (getModels(), getAvailableSnapshot(), the model picker) are unchanged.
  • Added classifier support to ModelRuntime, including classify(), classifier model accessors, runtime-resolved authentication, and the built-in TypeSafe jev-latest model.
  • Added types=chat,image,classifier to pi.dev model catalog requests so remote refreshes overlay every supported model type; entries of unknown model types are ignored.
  • Added the provider_stream_event extension event for observing parsed provider events before normalization, with an opt-in /debug-provider example viewer (#9784, #9901 by @davidbrai).
  • Added a show/hide toggle (H) in HTML exports for custom messages marked display: false. Messages remain hidden by default and can also be revealed from the sidebar (#8896, #10020 by @rwachtler).
  • Added inherited Claude Sonnet 5.5 support for Anthropic with adaptive thinking and a 1M context window.
  • Added a Built-in section in pi config to disable the built-in mcp, llama.cpp, codemode, and tool-search extensions globally or per project, stored as -builtin:<name> in the extensions setting. SDK inline extensions opt in with builtin: true.
  • Added +name and -name entries to the defaultTools setting to add or remove tools without repeating the defaults, for example "defaultTools": ["+codemode"]. Project entries of this form apply on top of the user setting. Documented how to enable codemode without MCP and how to use classifier models such as Jev from codemode scripts.
  • Added the token usage and cost of codemode models.classify() calls to the codemode tool result, so they count toward the session cost; the codemode result shows each call's cost.

Changed

  • Switched the build from the TypeScript native preview to TypeScript 7.0 with an ES2024 target, and replaced tsx with Node's built-in type stripping for running from source (#9965).
  • Removed the [Themes] section from the startup banner. Custom themes remain available in /settings, and theme conflicts are still reported.
  • Changed the startup header to show the pi logo with the version instead of the app name.
  • Changed the built-in dark and light themes to the revised pi colors, written in OKHSL.
  • Changed light/dark terminal detection to use the reported background color first, then the terminal's light/dark report, then COLORFGBG. The first-time setup no longer shows the detected appearance.
  • Renamed the inherited OpenAI Codex provider to "OpenAI Codex (legacy)"; Sign in with ChatGPT on the OpenAI provider supersedes it.
  • Changed inherited terminal detection to treat TERM=*-direct as truecolor.
  • Built-in extensions and tools are named builtin:<name> (for example builtin:mcp and builtin:read) in errors, diagnostics, RPC source info, and bug reports, instead of <inline:name> and <builtin:name>. Their slash commands no longer carry a [t] autocomplete tag.
  • --no-extensions also disables the built-in extensions, including the llama.cpp provider. Load one explicitly with -e builtin:<name>, for example pi -ne -e builtin:mcp.
  • Tool calls without a custom call renderer, including direct MCP tool calls, now show their arguments: as key=value pairs on the title line when collapsed and one key: value line per argument when expanded. MCP calls are titled server/tool and their results collapse to 5 lines.
  • bash and powershell structured results, which codemode scripts receive, now hold up to 1 MiB of output instead of the model-facing 2000 lines or 50KB, and add truncated and full_output_path. Longer output keeps its first and last 512 KiB. Empty output is "" instead of (no output).

Fixed

  • Fixed X11 clipboard text being misidentified as an image when the clipboard owner accepts unadvertised image targets (#9786).
  • Prevented managed git packages from automatically installing Pi peer dependencies and added warnings for extension packages that list host-provided modules in dependencies (#9863).
  • Fixed pinned git extensions loaded with -e continuing to use the first downloaded commit after the ref changes (#9982).
  • Fixed RpcClient skipping the next event listener when a listener unsubscribes while handling an event, which could make waitForIdle() time out after collectEvents() (#9990).
  • Fixed full-file read calls rendering as :1 when models send null for omitted offset and limit (#9996).
  • Fixed new sessions being lost when pi exits before the first assistant response. The session file is now created when the first user message is sent (#10000).
  • Fixed unloaded llama.cpp autoload presets overwriting a cached runtime context window with the GGUF training context (#10077, #10158 by @cristinaponcela).
  • Fixed custom themes ignoring terminal.trueColor and other terminal capability overrides and rendering with 256 colors (#9973, #10039 by @christianklotz).
  • Fixed pasting files copied in Finder inserting the file icon image instead of the file paths; paths are quoted in bash mode (#9999, #10136 by @christianklotz).
  • Fixed the startup header, loaded resources, and chat notices keeping their old colors after a theme change.
  • Fixed the Fireworks default model pointing at the removed Kimi K2.6 model; it now defaults to Kimi K3.
  • Fixed the OpenCode Go default model pointing at the removed Kimi K2.6 model; it now defaults to Kimi K3.
  • Fixed the Together default model pointing at the removed Kimi K2.6 model; it now defaults to Kimi K3.
  • Reduced CPU use while streaming in long sessions and when previewing themes: the footer caches session usage totals, collapsed bash results cache their preview, and sanitizeBinaryOutput() no longer splits output into per-character arrays.
  • Fixed the usage of tools called through ctx.executeTool(), for example from codemode scripts, being dropped from the session cost; it is now added to the calling tool's result usage.
  • Fixed inherited /skill autocomplete appearing empty when loaded skill names did not contain the letters in skill (#9944).
  • Fixed inherited path and @ autocomplete not working after opening wrappers such as (, [, {, <, or a backtick.
  • Fixed inherited image stretching in terminals that use the Kitty graphics protocol (#8938, #9957 by @rwachtler).
  • Fixed inherited shell cursor staying hidden after exit when an extension closed an overlay during shutdown (#10026).
  • Fixed inherited keyboard input being lost after a mouse click in a /settings submenu closed it.
  • Fixed inherited 1-hour Anthropic cache writes through Vercel AI Gateway being priced at the 5-minute rate (#9210).
  • Fixed inherited model-level samplingParams being dropped by direct stream()/complete() calls on OpenAI-compatible APIs (#9506).
  • Fixed inherited Mistral GLM requests failing with "Expected at most one leading ThinkChunk" after empty content deltas (#9674).
  • Fixed inherited OpenAI Fast mode requests being priced at the standard rate (#10034).
  • Fixed inherited Mistral reasoning models ignoring the requested thinking level (#9678).
  • Fixed inherited OpenCode Zen and OpenCode Go qwen3.8-flash thinking being replayed as plain text on later turns (#10047).
  • Fixed inherited OpenAI Responses streams from servers that omit output_index, such as llama.cpp, running mixed-up tool calls; such streams now end with an error (#9974).
  • Fixed inherited Anthropic and OpenAI Codex browser sign-in waiting indefinitely after the provider redirected with an authorization error, and Anthropic sign-in failing when its callback port is in use.
  • Fixed inherited GitHub Copilot Claude Opus 5.5 offering unsupported thinking levels when upstream model metadata is incomplete.
