rea rea-agents-6.8.0

6.8.0 (2026-10-25)

ハイライト

  • ネットワーク キャプチャ、ブラウザ シナリオ、またはプロンプトからローカル エージェント環境を構築し、派生読み取りと証拠ゲート型書き込みを提供し、それらを新しいアプリケーション キャプチャと比較します。
  • GPU コード オブジェクト、BEAM、Python バイトコード、Unity IL2CPP メタデータ、Godot PCK、PyInstaller、Node.js SEA、devicetree、追加の PE/ELF テーブルなど、より多くの同梱形式を検査します。
  • 保持される概要、選択されたファクト クエリ、構成可能なリカバリ制限、および行指向の CLI エクスポートにより、大規模な調査に集中し続けることができます。 Complete Evidence remains available.

⚠ 重大な変更

  • 機能分析: analyze_function はデフォルトで要約が保持されるようになりました。 Set detail: "complete" for the previous inline dossier; CLI は完全なデフォルトを保持し、概要を選択するときに --evidence_output を必要とします。 #5660. Thanks @CryptoJones, @gensokyo-dev, @RishTheFish21.
  • Accessibility: Accept JSON numbers and booleans in node value, alongside strings and null.以前はテキストのみの値を想定していたコンシューマーを更新します。 cc90771, #6759, #6467. @coygeek、@gensokyo-dev、@mvanhorn に感謝します。
  • JSON 行: --format jsonl は、オブジェクト コレクション行とそれに続く $rea: "jsonl/v1"、type: "metadata" レコードを出力するようになりました。 scalar selections and unsupported reports are refused.制御レコードを個別に解析し、必要に応じてサポートされる単一のコレクションを選択し、以前の文書全体の出力に --format json を使用します。 JSON ラインフレーミング を参照してください。 #5629, #5487. Thanks @gensokyo-dev, @jayykernel, @vijaykiran06.
  • Interface Builder: Keyed-archive graph identities use decimal table UIDs instead of authored objectID/object-id. Treat authored IDs as attributes and update persisted graph lookups; ibtool およびネイティブ NIBArchive アイデンティティは、ソース セマンティクスを維持します。 6fbe67d.
  • Frida: instrument-with-frida JSON returns the canonical Evidence directly. Read normalized_result.cleanup_error instead of the former top-level wrapper field. 48f700e.
  • 再構成証明: ID アレイ証明記録は検証済みまたは準備済みの台帳を確立しなくなりました。 Supply implementation/revision bindings and individual claim outcomes; handle inapplicable, unavailable, and failed proof diagnostics. f8b65e7.
  • Mach-O imports: Handle a null import name when identity is ambiguous; raw_name および name_status を使用して、観察された式と正確なシンボルを区別します。 5d0d243、169512a。
  • Node.js: ^22.23.4 || ^24.22.1 || >=26.12.1 を満たすランタイムを使用します。ノード 23 と 25 はサポートされていません。 Upgrade Node before installing or updating REA;インストーラーはそれをアップグレードしません。 #6315、#6283。 Thanks @GamerDubz, @gensokyo-dev, @ShikamaruNaaraa.
  • ブラウザ ストレージ: ハッシュされた履歴ストレージは引き続き読み取り可能ですが、両方のキャプチャが新しい表現で再キャプチャされるまで比較は不明のままです。 #6341、#6289。 @coygeek、@gongfpp に感謝します。
  • Environment serving: environment-serve serves derived state by default, including write tools whose effects are confirmed by recorded evidence. Use --replay-only for stateless replay of manifest tools. state_evidence_id ではなく、ストップサマリー state と読みます。 #5351、#6158。 Thanks @earakely-scale, @gensokyo-dev, @kaoru0822-kitauji.
  • MCP スキーマ: 入力アドバタイズメントはデフォルトでコンパクトになります。 Set REA_MCP_INPUT_SCHEMA_PROFILE=full for complete advertised guidance and nested constraints. #5975. @gensokyo-dev に感謝します。
  • ブラウザ コンソール引数: プロトコル引数インベントリが省略されているか形式が不正な場合は、null argument_types および text_capture.status: "unavailable" を受け入れます。その不確実性を保持します。 #6016、#5934。 Thanks @coygeek, @kaoru0822-kitauji.
  • Reconstruction summaries: summary.by_evidence_authority is keyed by Evidence authority;必要な summary.by_source_state から以前のソース状態カウントを読み取ります。 Regenerate ledgers whose closure digests depended on the old projection. #5875, #5838. Thanks @coygeek, @kaoru0822-kitauji.
  • Swift bindings: Conformance type_name and protocol_name may be null; consume typed type_binding/protocol_binding evidence.以前の Objective-C 固有のインポート バインディング タイプ/スキーマを MachoImportBinding に置き換えます。 d0067ba.
  • WebSocket フレーム: null オペコードを受け入れ、未知のフレーム事実を保持します。数値オペコードは 4 ビットのプロトコル範囲に制限されます。 0bc2b42.
  • リソースのみの検査: 証拠の件名と実行可能ダイジェストは null になる可能性があります。実行可能ターゲットを必要とする代わりに、resource_root と各リソースの報告された出所を使用します。 6a6adf7.
  • ブラウザのタイムスタンプ: プロトコルが有限/比較可能な時間を提供しない場合、コンソールおよびセッション タイムラインのタイムスタンプは null になる可能性があります。並べ替えと比較では、不明な時刻を明示的に保ちます。 690fc51, 2a0410f.
  • 参考ソース: "." の合成失敗した子ではなく、rootFailure から失敗したルート列挙を読み取ります。 preserve the top-level source-graph limitation. 6296fdf.
  • ファイルシステムキャプチャ: 前述の理由リテラルに加えて、entry_unavailable および identity_changed 列挙省略の理由も受け入れます。 c85b44e. Thanks @rudrakshagarwal4200-ai.
  • APK ロケール: es-r419 などの従来の数値セレクターを es-419 または b+es+419 に置き換えます。 Two-letter regions remain supported. 29910d1. Thanks @mertkayacs.
  • XML plist スカラー: $plist_type: "unknown" を認識し、element、literal、および reason を読み取ります。未解決の XML スカラーは、以前の実数/null の未知のマーカーや不正な形式のスカラー プレフィックスの代わりに、このラッパーを使用します。サポートされている拡張 UTC 年ではタイムスタンプが保持されます。 3537e58.
