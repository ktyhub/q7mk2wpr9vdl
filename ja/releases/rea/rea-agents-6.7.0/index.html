レア試薬-6.7.0

6.7.0 (2026-10-18)

ハイライト

  • Client 構成の編集は、MCP clients で使用される重複メンバーのセマンティクスに従います。

変更点

  • 6.6.0 の変更と移行に関するメモ が含まれています。そのバージョンはタグ付けされていましたが、npm には公開されませんでした。

修正

  • Client 構成: セットアップは、clients が実際に読み取った値と一致する、最後に繰り返された JSON/JSONC メンバーを編集します。セットアップとアンインストールは、シャドウされた複製を再アクティブ化する削除を拒否し、元の構成を保持します。 (#4957、morluto/rea#4952)。 @kaoru0822-北宇治さん、@xu91102さん、ありがとうございます。 完全な貢献レコード: 4 つのコミットと 1 つのマージされた PR。

6.6.0 (2026-10-18)

ハイライト

  • 呼び出し元が提供する静的分析プロバイダーとして Kuna を追加します。
  • 基礎となる分析を繰り返すことなく、選択した JavaScript ファクトと複数の APK ロケール テーブルをクエリします。
  • Ghidra 分析を Windows ARM PE ターゲットおよび明示的な生の m68k イメージに拡張します。
  • 完了した証拠、キャンセル理由、プロバイダー全体での再試行可能なクリーンアップ、および CLI ファイナライズを保持します。

変更点

  • Kuna 分析: プロシージャ リスト、疑似コード、アセンブリ、呼び出し関係、正確なアドレスの外部参照、およびキャッシュされた文字列検索に、呼び出し側でインストールされた Kuna を使用します。プロジェクトのエクスポートでは、ソース スパンとダイジェストが保持されます。リクエストが繰り返されると、完了した作業が再利用されます。記録された実際のプロバイダー カバレッジでは、Linux 上で Kuna 1.833 を使用します。 Windows、PE、ユニバーサル Mach-O はサポートされていません。 プロバイダー ガイド を参照してください。 (#3832、#3854、#4071、#4095)。 @gensokyo-dev、@kaoru0822-北宇治、@N0zoM1z0 に感謝します。
  • 保持されている JavaScript の事実: inspect_analysis_view を介して、ページングと完全な行証拠を使用して、正確なアプリケーション パス、選択されたプロパティ、およびフィルターされたモジュール参照をクエリします。これらのビューは、完了した分析を再利用し、ソースの選択と不明なカバレッジを保持します。 (#4265、morluto/rea#4190、#4097、morluto/rea#4092)。 @kaoru0822-北宇治さん、@N0zoM1z0さん、ありがとうございます。
  • APK ロケール テーブル: 反復可能な CLI --locales または MCP locales を使用して、1 回のデコードで複数のリソース ロケールをリクエストします。各テーブルはそのステータスとカバレッジを報告します。既存の単一ロケール フィールドは引き続き使用できます。 (#4804、morluto/rea#4777)。 @abhay-2108、@N0zoM1z0 に感謝します。
  • Windows ARM バイナリ: Ghidra は、Windows x64 ホスト レーン上で ARMNT/Thumb-2 および ARM64 PE アプリケーションと DLL を許可します。記録された Ghidra 12.1.4 検証では、WindowsResourceReference を無効にし、起動予算を引き上げて使用しています。デフォルト アナライザーの完了、ARM64EC/ARM64X および Windows-on-Arm ホストは未検証またはサポートされていないままです。 正確なスコープ を参照してください。 (#3965、morluto/rea#2186)。 @N0zoM1z0、@WestLabsAI に感謝します。
  • 生の m68k イメージ: Ghidra の固定 68000 プロファイルと呼び出し元が提供する整列エントリを使用して、明示的に選択されたビッグエンディアンの m68k 生バイナリを分析します。実際の CLI/MCP 検証では、macOS arm64 で Ghidra 12.1.4 を使用しました。 Linux は未検証であり、Windows P0 は m68k を許可しません。 マッピング要件 を参照してください。 (#4018)。ありがとう@icedac。
  • JADX 期限: REA_JADX_OPERATION_TIMEOUT_MS を設定して、APK のロードとアップストリーム操作の期限を一緒に延長します。 Doctor は有効な値を報告し、セットアップは明示的な選択を転送します。 (#4466、morluto/rea#3918)。 @jaychou813、@SandstromPL に感謝します。
  • 電子ウィンドウ オプション: ソースの出自を保持しながら、安定したローカル定数 BrowserWindow オプションを解決します。関連する書き込みとエスケープにより、結果は不明のままになります。 (#4400、morluto/rea#4366)。 @kaoru0822-北宇治さん、@N0zoM1z0さん、ありがとうございます。
  • 言語版: ギリシャ語の Web サイト版とマラヤーラム語のドキュメントを追加し、サイト全体で韓国語のタイポグラフィと翻訳を修正しました。 (#3520、#4792、#3821、morluto/rea#3820、#3799、morluto/rea#3798、#4344、 #3856、#4166)。 @gensokyo-dev、@hi2242、@kalayciburak、@kaoru0822-北宇治、@kraken-503、@kukinghan、@N0zoM1z0、@yeseong0412 に感謝します。

修正

  • キャンセルとクリーンアップ: 完了した観察、正確なキャンセル理由、および最終処理までの元の物理的障害を保持します。クリーンアップが失敗した場合、プロセスまたはファイルの所有者は再試行のために保持されます。回復されたリソースは、元のエラーを置き換えることなく、保留中のクリーンアップ レポートから消えます。 (#4238、morluto/rea#4232、#4274、morluto/rea#3923、3e82366、16924e2、 bbfe6ed、1f23e97、08fbeb8)。ありがとう@coygeek。
  • プロバイダーの起動: シャットダウン前に前提条件のプローブと実行中の準備作業に参加し、型指定されたタイムアウトと JVM メモリ障害を保持し、クリーンアップを通じて起動診断を保持します。 Ghidra は Keg 専用の Homebrew JDK を認識し、起動タイムアウトの原因となる設定に名前を付けます。 (376eeca、ceeff5a、3ad1032、964decd、3fa972a、#4557、morluto/rea#4556、 #4590、モルト/レア#4241)。 @DanielCvz1、@J0UH、@Rinkia、@RishTheFish21、@vadlachary2002 に感謝します。
  • Client 構成: 選択したランチャー、宛先ファイル、呼び出し元のタイムアウトの選択、および未解決の構成証拠を保存します。セットアップ/アンインストールの回復は、公開されたファイルに正確にバインドされたままになり、現在検証されたバックアップを保持し、失敗したクリーンアップの所有権を再試行のために転送します。 (d0253c9、7e4eed9、2fb5e20、8235210、d818c3d、19329e4、dadf909、 333e0ab、c15c206)。ありがとう@Adolanium。
  • 構成形式: 丸めなしで符号付き 64 ビット TOML 整数を読み取り、引数拡散エラーなしで大きな TOML ドキュメントを処理し、JSONC トリビアと Hermes YAML スカラー テキストを保持し、登録環境値の NUL バイトを拒否します。 (#4937、morluto/rea#4917、c43bc0b、4fd28fc、#3568、#4335)。 @alfredo1491、@gensokyo-dev、@kaoru0822-北宇治、@N0zoM1z0、@ShuaixinHuang、@xu91102 に感謝します。
  • クロード コードの構成: セットアップ、ドクター、アンインストールでは、先頭の UTF-8 BOM を含む、クロード コードが読み取る厳密な JSON 形式のみを受け入れるようになりました。コメントと末尾のカンマは、バックアップまたは書き込みの前に拒否されます。 JSONC をサポートする client は、既存の動作を保持します。 (#4944、morluto/rea#4940)。 @kaoru0822-北宇治さん、@xu91102さん、ありがとうございます。
  • CLI の出力とディスパッチ: --flag=value およびスペース指定されたグローバル出力値を受け入れ、フィルタリングされた JSON 内の配列位置を保持し、強制の前に整数トークンを検証し、出力リーダーが閉じるときに静かに終了します。キャンセルはコマンドの終了まで有効です。アプリ バンドルと静的ネイティブ インスペクションにより、目的のワークフローが選択されます。 (#3811、#4823、2ae4e16、8d82579、#3781、279c590、#3511、 morluto/rea#3321、f31b231)。 @arjunprabhulal さん、@coygeek さん、@kaoru0822-北宇治さん、@ShuaixinHuang さん、@Sriram-PR さん、@Tapraj-Pathak さんに感謝します。
  • 更新: 検証済みアップデーターとバインドされた保持パッケージ マネージャー診断を通じて --update をルーティングします。 (4f7b5fb、01cdbbd)。
  • MCP コントラクト: スキーマ プロファイル全体でタプル、配列、ブールおよびネストされた JSON 制約を維持しながら、自己完結型ツール入力をアドバタイズします。スキーマ参照の処理では、リテラルのメタデータは書き換えられなくなりました。カタログ ID には出力スキーマ プロファイルが含まれます。 (5e30969、10aa74d、204b9f3、b3389a5、a2e3016、ba98130、 c5fb86d)。 @akushonkamen、@HarsH-1877、@kaoru0822-北宇治、@xingzihai に感謝します。
  • セッションの順序付け: 同じ接続上で後続の呼び出しよりも先にスナップショット許可を保持し、クリーンアップが成功するまでシャットダウン信号を保持し、調査の公開を通じて検査権限を保持します。 (#3661、morluto/rea#3334、8873b39、663d07f)。 @coygeek、@rudycelekli、@Swatantra-66 に感謝します。
  • JavaScript のエクスポートと解決策: Object.defineProperty で作成された CommonJS エクスポートを保持し、エクスポート レシーバーの有効期間を追跡します。所有するローダーを使用して、スコープ指定されたパッケージ、パッケージ main、JSON が必要、および .mts/.cts インポートを解決します。上書きされた require バインディングと消去されたタイプのみのインポートによって、誤ったランタイム リンクが作成されなくなりました。 (#4725、モルト/レア#4724、#3567、モルト/レア#3541、#4838、モルト/レア#4632、 #3844、モルト/レア#3383、#4164、モルト/レア#3915、#4223、#3801、 morluto/rea#3393、#4165、morluto/rea#3932)。 @Abishek0070、@coygeek、@JNTMTMTM、@kaoru0822-北宇治、@prasad2512、@rodricksz4h5、@xu91102 に感謝します。
  • JavaScript 値フロー: 後の割り当て、保護されたファクトリ フォールスルー、およびネストされた分割の前にキャプチャされた値を保存します。正確なプロパティ キーとセッターの書き込みを追跡します。直接 eval、複合割り当てと受信コールバックは、確実性を生み出すのではなく、未解決の効果を保持します。 (#4196、morluto/rea#3881、#4341、morluto/rea#3963、bfb7ed0、#3480、 #3831、モルト/レア#3312、9ac76d3、#4342、モルト/レア#4206、#4243、 モルト/レア#3880)。 @coygeek、@kaoru0822-北宇治、@maxazure、@N0zoM1z0、@ShuaixinHuang に感謝します。
  • JavaScript 関係: ネットワーク エンドポイントからの Map 読み取りを区別し、読み取りに到達する書き込みのみに応答エンドポイントを関連付け、子プロセスの受信者の所有権と有効な stdio の選択を保持します。バージョン比較により、再配置や不明な関係がアプリケーションの変更とは区別されます。 (fbfdb6a, #4759, morluto/rea#4606, #3819, morluto/rea#3362, #4336, morluto/rea#3355、556504e、4d980d0)。 @Abdooo2235、@coygeek、@kaoru0822-北宇治、@Xinglan233 に感謝します。
  • JavaScript ソースアドミッション: JavaScript を独自の文法で解析し、ブロックせずに FIFO リカバリ入力を拒否し、サイズ超過またはリソーススキップされたファイルを実際の容量とカバレッジ状態とともに報告します。不正な実行時イベントは、ポリシーでフィルタリングされた事実になるのではなく、除外されたままになります。 (#3782、モルト/レア#3780、#3788、モルト/レア#3332、#4757、モルト/レア#4629、 #3852、morluto/rea#3670、#4755、morluto/rea#4685)。 @andresaragon、@coygeek、@kaoru0822-北宇治、@sx4im に感謝します。
