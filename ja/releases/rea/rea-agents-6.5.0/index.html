レア試薬-6.5.0

6.5.0 (2026-10-13)

プロバイダーの前提条件と記録された検証範囲は、テスト ガイド にリストされています。

ハイライト

  • 選択した JavaScript ファイルを分析し、選択したソース スコープを拡張せずにバンドル間の関係を回復します。
  • バイナリ、マネージド、Android、Dart、WASM、およびネットワーク ワークフローにわたるコンパクトな概要とページに保存された証拠を読み取ります。
  • SQLite スナップショット、パケットと信号の記録、WebAssembly、Rust 依存関係メタデータ、電子ヒューズをオフラインで検査します。
  • 分析やクリーンアップが失敗した場合でも、完成した証拠と部分的な観察を利用できるようにしておきます。

変更点

  • JavaScript ソースの選択: 選択したスコープにインポートを拡張せずに、正確なアプリケーション パスを分析します。選択されていないファイルは、アイデンティティと明示的な不明な範囲を保持します。概要の配信は、ソースの選択とは別に行われます。 (#1944、モルト/レア#1848の問題)。 @kaoru0822-北宇治さん、@N0zoM1z0さん、ありがとうございます。
  • コード分割リカバリ: ファイルごとの来歴とダウンストリームのクロスチャンクインポートを保持しながら、選択された複数の入力から関連するバンドルをリカバリします。記録された CLI/MCP カバレッジは、Wakaru 1.14.0 およびソース所有の esbuild/webpack フィクスチャを備えた Linux x64 です。他のホスト、リリース、および任意のアプリケーションの等価性は未検証のままです。 (#1686、モルルート/レア#1605の問題)。 @JingHao-Leon、@pionxzh に感謝します。
  • パッケージ インポート: 兄弟ファイルを推測するのではなく、選択したローダーとパッケージの祖先を使用して、正確なパッケージ インポート エイリアスを解決します。 (#1862、モルト/レア#1838の問題)。 @AWUQAQ、@mvanhorn に感謝します。
  • 保持された分析ビュー: コンパクト インベントリ/WASM、管理されたメタデータ、Android マニフェスト、Dart AOT、Mach-O および EVM の概要をオプトインし、分析を再実行することなくページ保持された証拠を表示します。要約配信では、完全な記録結果とその元のカバレッジが保存されます。 (#2122、#2193、#2413、#2438、#2455、#2634、#2308、 9a18251)。 @kaoru0822-北宇治さん、@N0zoM1z0さん、ありがとうございます。
  • マネージド アセンブリ: メンバーを検査するときに宣言型を選択し、独立したカバレッジで検査された ldstr リテラルをデコードし、保持されたメンバーの概要をページします。呼び出しターゲットとフィールド ターゲットは、サポートされているジェネリック メソッド ターゲットを含む target_declaring_type と field_declaring_type を公開します。未解決のメタデータは不明のままです。 (#1706, #2125, 問題 morluto/rea#2121, #2162, 問題 morluto/rea#2158, #3061, 問題morluto/rea#3010、#2163、morluto/rea#2160 を発行)。 @kaoru0822-北宇治さん、@N0zoM1z0さん、@Nelglorさん、@skoodsterさんに感謝します。
  • パケット キャプチャ: 制限された TShark 出力、コンパクトなキャプチャ サマリー、および保持されたページを使用して保存されたパケットを検査します。インストールされているプロトコル/フィールド定義を検出します。記録された実エンジンのカバレッジでは、Linux と Wireshark 4.6.6 を使用しています。ネイティブの Windows/macOS および Bun の動作は未検証のままです。 (#2318、#2340、#2496)。 @3QL、@N0zoM1z0、@Olorinm に感謝します。
  • 録音された信号: 既存の録音をデコードし、発信者が提供する sigrok-cli 0.7.2 を通じて、インストールされているデコーダー/オプションを検出します。これは Linux のみであり、util-linux prlimit が必要です。ハードウェア サンプルは取得されません。 (#2339、#2487)。 @N0zoM1z0、@Olorinm に感謝します。
  • Web キャプチャ: 未知のものを保持しながら、観測されたクエリ パラメータ名を含む保持された HAR データから、推定されたメソッド/オリジン/パス テンプレート API サーフェスを導出します。クエリ値、ヘッダー、本文は除外されたままになります。 (#1891、#2982、モルルート/レア#2913の問題)。 @mvanhorn、@wunianze666-netizen、@zhangguiping-xydt に感謝します。
  • QUIC キャプチャ: 保持されている aioquic 1.5.0 JSON qlog 0.3 オブジェクトおよびページ トレース/ストリーム/観測を検査します。他の qlog レイアウトはサポートされていないままです。重複および損失の宣言は、再送信またはネットワーク損失を証明するものではありません。 (#2277)。 @LuisTaffelli、@N0zoM1z0 に感謝します。
  • Fiddler キャプチャ: 保持された HTTP 来歴と制限されたデコードを使用してネイティブ SAZ アーカイブを検査します。記録されたプロデューサー カバレッジは、ピン留めされたパブリック エンコーディング コーパスです。現在の Fiddler Everywhere のバリアントと Bun ネイティブの実行は未検証のままです。 (#2409)。 @N0zoM1z0、@zahhak に感謝します。
  • SQLite スナップショット: テーブル/列の選択と限定された証拠を使用して、明示的に選択されたオフライン データベースを検査します。この操作には、ノード 24.x >=24.15、または DatabaseSync.limits を備えた 26+ が必要です。サポートされている Node 22 以前の 24 ランタイムでは使用できません。ライブ データベース/WAL コピーでは、アトミック スナップショットは確立されません。 (#2271)。 @N0zoM1z0、@Y0UW1SH に感謝します。
  • WASM アーティファクト: ローカル モジュールを実行せずに、持ち込みの WABT 1.0.42 で検査します。アクティブな WABT インストールを必要とせずに、2 つの完全なコアモジュール検査証拠レコードからのインポート/エクスポートを比較します。サポートされていない署名や重複した ID は不明のままであり、比較によって実行時の互換性は確立されません。記録された実際のツール検査カバレッジは macOS arm64 です。 (#1533、morluto/rea#884 の問題、#2464、morluto/rea#2356 の問題)。 @matbrgz、@N0zoM1z0、@thangldw に感謝します。
  • Go バイナリ: ファイルにバックアップされたマップされていない Mach-O デバッグ セグメントを含む、埋め込まれたビルド メタデータを検査します。 (#1363、7fb097d)。ありがとう@Y0UW1SH。
  • Flutter APK: スナップショット/エンジン ビルドを識別し、外部エンジンなしで AOT 構造を検査します。記録された実際の APK カバレッジでは、文書化された Flutter Gallery フィクスチャが使用されています。 macOS/Windows および完全なプール セマンティクスは未検証のままであり、プールの適用範囲は部分的なままです。 (#1582)。ありがとう@3QL。
  • HarmonyOS パッケージ: コードを実行せずに HAP/HSP/App Pack 構造をインベントリします。記録された実際のワークフローは、リポジトリで構築された CLI/MCP を介して 1 つの固定された HAP をカバーしています。インストールされたパッケージと実際の HSP/App Pack の適用範囲は未検証のままです。 (#1447)。ありがとう@BaaRai。
  • Ghidra の生の入力と参照: 互換性のある Linux/macOS Ghidra プロファイルは、呼び出し元が選択した生のアーキテクチャ/エントリ情報を受け入れ、型指定された受信参照を正確なアドレスで公開します。 Windows Ghidra P0 は、以下に説明する生の NMOS 6502 プロファイルを許可します。他の生のターゲットと受信参照ファセットは Windows P0 の外部に残ります。 (#1868、morluto/rea#1836 の問題、#1715、morluto/rea#1245 の問題)。 @bugstan、@casesolved-co-uk、@mvanhorn、@N0zoM1z0 に感謝します。
  • Ghidra MIPS: 制限された MIPS32r2/o32 再配置可能オブジェクト、ソフトフロート整数レジスタ ストレージ、許可された MIPS16 共有 ELF、および狭義に許可されたレコードレスのレガシー MIPS32 実行可能プロファイルを追加します。後者は、エンディアンが一致した 32 ビット言語を固定し、推定された o32 を分析の仮定として記録します。入場は、文書化された各 ABI/フラグ/移転境界に従います。 (#1949、morluto/rea#1937 発行、#1950、morluto/rea#1938 発行、#1991、morluto/rea#1851 発行、 #1898、morluto/rea#1620 を発行)。 @AurelioB、@BaaRai、@bqw371、@kaoru0822-北宇治、@N0zoM1z0 に感謝します。
  • Ghidra RISC-V: は、サポートされている double-float ABI を宣言するリトルエンディアン RV32/RV64 ET_EXEC ELF を許可します。再配置可能/共有、ビッグエンディアン、およびその他の ABI プロファイルは拒否されたままです。 プロファイルと記録されたレーン を参照してください。 (#2151)。ありがとう@NIU-123370。
  • PSP 静的 ELF プロファイル: Ghidra プロファイルは Linux x64、文書化された PSP/ABI 宣言と互換性のある呼び出し側でインストールされた Allegrex 拡張機能を備えた、境界付きリトルエンディアン ELF32 ET_EXEC です。 PRX、共有/再配置可能イメージ、PBP/ISO/CSO、およびランタイム エミュレーションは範囲外です。過去の拡張実験は、公共プロバイダーの検証とは別のものです。実際に公開されている Ghidra PSP の報道は未確認のままです。 (#1599)。ありがとう@jaelliot。
  • Ghidra 分析設定: 選択した分析プロファイルを保持しながら、分析前に検証済みのアナライザー オーバーライドを適用します。 (#1913)。 @akushonkamen さん、@kaoru0822-北宇治さん、@N0zoM1z0 さん、ありがとうございます。
  • 添付されたネイティブ IDA MCP: 既存のレガシー/ヘッドレス プロファイルと一緒にオプションのネイティブ ブリッジを追加します。記録されたネイティブ実行では、ナビゲーション修正を備えた Linux IDA Free 9.4 と、ループバック リスナーの変更を備えた Windows IDA Pro 9.3 を使用します。ストック ネイティブ スイッチング、ネイティブ macOS、および Windows IDA Free は未検証のままです。接続されたデータベースは読み取り専用のままで、保存されたり閉じられたりすることはありません。 (#1544)。 @imissapixel、@N0zoM1z0 に感謝します。
  • Frida インストルメンテーション: 明示的なローカル/リモート ターゲットの選択、呼び出し元が提供するスクリプトと保持メッセージを追加し、スクリプト読み取り/入力診断と制限付きメッセージの削除を行います。記録された実際のカバレッジは、Linux ローカル ノード マーカー ワークフローです。 macOS、Windows、およびリモート デバイス/サーバーは未検証のままです。インストルメンテーションは外部コードを実行し、読み取り専用ではなく破壊的です。 (#1359、#2211、morluto/rea#2209 の問題、#2217、morluto/rea#2213 の問題、#2628)。 @dandgabr、@kaoru0822-北宇治、@N0zoM1z0 に感謝します。
  • Client セットアップ: 既存の範囲指定されたセットアップ フローを通じて、Qoder、Trae、ZCode、DeepSeek Harness、Kimi Code、Factory Droid、および WorkBuddy を登録します。 DeepSeek は 6.5.0 から含まれています。過去の npm 6.4 チェックではこれがカバーされていませんでした。 Live Trae と DeepSeek API の統合は未検証のままです。 (#1564、#1572、#1573、#1929、モルト/レア#1839 の問題、#2744、 #2309、#3041、モルト/レア#3040の問題)。 @0xRafie、@BaaRai、@cainiao1992、@IvenKooLab、@whoishaha、@ysntony に感謝します。
  • Web サイト: 維持される言語エディション、永続的/システム対応テーマ、キーボード スタイル、ネストされた証拠インデント、およびリバース エンジニアリング モデル エッセイを追加します。シンプルなホームページと初心者向けの手順では、プラットフォームの前提条件、client/プロバイダーのセットアップ、および提供された最初の調査を接続します。 (#1779、モルト/レア#1022の問題、#1699、#1714、#1894、#2250、 #2432、#2732、#3274)。 @CassieFox23、@kaoru0822-北宇治、@N0zoM1z0 に感謝します。
  • Rust 依存関係メタデータ: ファイルを実行せずに、ELF、PE、および Thin Mach-O に埋め込まれたカーゴ監査可能パッケージ/依存関係レコードを検査します。メタデータの欠落と推定されたコンパイラ ハッシュには明示的な制限が残ります。ユニバーサル マッハ-O には、選択された薄いスライスが必要です。 (#2456)。ありがとう@mvanhorn。
  • 電子ヒューズ: アプリを起動したり変更したりせずに、パッケージ化されたヒューズ バイトとスライスごとのランタイムへの影響を読み取ります。欠落している、切り取られている、不明なワイヤーは明示的なままです。ヒューズの観察は、他の Inspector 有効化パスを証明するものではありません。 (#2399)。 @kaoru0822-北宇治さん、@mvanhornさん、@N0zoM1z0さんに感謝します。
  • Ghidra PowerPC: サポートされている Linux/macOS ホスト上で、明示的な言語プロファイルを持つ制限された ELF32 ビッグエンディアン ET_EXEC PowerPC を許可します。 PPC64、DOL、およびその他のバリアントはこのレーンの外側に残ります。 プロファイルと検証の前提条件 を参照してください。 (#1747)。ありがとう@arielfikru。
  • 参照ソースの概要: コンパクトなマニフェスト、カウント、状態、およびパス アウトラインの出力には、CLI import-reference-source --detail summary を使用します。完全なグラフは引き続き利用可能であり、デフォルトのままです。非表示のアウトライン エントリは別のカバレッジ カウントを保持します。 (#2768、モルト/レア#2442の問題)。 @matbrgz、@To3akaRin に感謝します。
  • 記録された AArch64 クラッシュ: 文書化された呼び出し元が提供する Python 依存関係を使用して、サポートされている Linux ELF64 リトル エンディアン コア ノートからスレッドごとに 34 の ABI レジスタ値をデコードします。これらは記録された事実であり、現在のプロセスやライブラリのアイデンティティの証拠ではありません。 (#2505、モルト/レア#2353の問題)。 @matbrgz、@NIU-123370 に感謝します。
  • Ghidra バイト検索: ワイルドカード、ビット マスク、アドレス境界、およびページングされた結果を使用して、初期化された分析済みメモリを検索します。アンロード、オーバーレイ、および初期化されていないブロックは、スキップされたカバレッジを保持します。これは生ファイルの検索ではありません。 (#2341)。ありがとう@mvanhorn。
  • 生の NMOS 6502 イメージ: 呼び出し元が選択したエントリと 16 ビット アドレス空間内のソース マッピングを使用して、Windows P0 を含む明示的に選択されたヘッダーなしイメージを Ghidra で分析します。カートリッジ解析、リセット ベクトル推論、および 65C02/65816 は、このプロファイルの対象外です。 (#2079)。ありがとう@Zhong-fan。
  • Swift String の観察: Ghidra 関数ドシエは、サポートされている AArch64 Swift String リテラルを、認識された使用サイトの定数レジスタ ペアから派生させ、命令/レジスタの出所と明示的な省略を保持します。これは限定された派生であり、完全な文字列インベントリではありません。 (#2049、モルト/レア#2030の問題)。ありがとう@thefolahan。
  • ヘッドレス IDA プロシージャ ルックアップ: アドレスを正規の包含プロシージャ エントリに解決し、最新のヘッドレス プロファイルでセッションの許可されたプログラム ドキュメントを識別します。不完全な調査はエラーのままです。添付されたプロファイルは、この封じ込め機能を宣伝しません。 (#2374、モルト/レア#2335の問題)。 @nikolay-dementiev に感謝します。
  • パッシブ ブラウザ アタッチメント: 6 つの既存のパッシブ ブラウザ ツールは、HTTP ターゲット検出が利用できない場合、明示的ポート ループバック ブラウザ WebSocket エンドポイントを受け入れます。既存の同意とターゲット/発信元のチェックは引き続き必要です。これによってブラウザが起動したり、ランタイム インストルメンテーションが有効になったりすることはありません。 (#2346)。 @all-black-493 に感謝します。
  • Android DEX リファレンス: 正確なメソッド記述子と、ソース メソッド、DEX エントリ、オペコード、およびコードユニット オフセットを含む個々の直接呼び出しの観察を保持します。これらは静的参照です。使用できない命令の事実は、メソッド レベルの使用量の合計とは分離されたままになります。 (#2439)。ありがとう@LcokHcak。
  • オフライン EVM メタデータ: もっともらしい端末 Solidity CBOR ルートマップ候補からの、制限されたロスのないファクトを保持します。候補者は、Solidity の起源またはソース/コンパイラーのアイデンティティを証明せず、リンクされたメタデータはフェッチされません。 (#2790)。ありがとう@matbrgz。

  • Provider admission: MIPS targets with unresolved GNU ABI attributes are refused. Supply supported ABI declarations. Saved Hopper databases on macOS are unavailable because the launcher cannot run the analysis bridge when opening a database; select an executable target instead. Database support requires a script-capable database launch route. (d4bd65c).

  • Segment extents: binary_overview segment length may be null when Hopper coordinates cannot establish a finite extent in one address space. Preserve unknown rather than converting it to zero or a saturated value. (36db19c).

Results now require replace_requested to record the requested adb install -r mode; replaced is nullable because prior device package state was not observed. Update result readers to accept null instead of treating reinstall intent as proof of replacement. (864314a).

  • Managed/native verification: unresolved P/Invoke results may retain matched_native and candidate facts when module identity is unknown. Interpret status, basis and limitations; module-identity-unknown does not verify correspondence, and unresolved no longer implies empty observations. (3f6b575).
