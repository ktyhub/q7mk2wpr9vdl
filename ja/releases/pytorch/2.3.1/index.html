pytorch v2.3.1

パッチ 公開日2024年6月5日 出典pytorch/pytorch English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

パイトーチ v2.3.1

このリリースは、次の問題 (回帰/サイレント正確性) を修正することを目的としています。

トーチ.コンパイル:

  • torch.__dynamo (https://github.com/pytorch/pytorch/pull/124634) をインポートするときに、JAX/XLA への実行時の依存関係を削除します。
  • Plan failed with a cudnnException 警告を非表示にする (https://github.com/pytorch/pytorch/pull/125790)
  • CUDA メモリ リーク (https://github.com/pytorch/pytorch/pull/124238) (https://github.com/pytorch/pytorch/pull/120756) を修正

配布:

  • no-op として実行される原因となっていた format_utils executable を修正 (https://github.com/pytorch/pytorch/pull/123407)
  • 初期化中にメモリ スパイクを引き起こす 2.3.0 の device_mesh による回帰を修正 (https://github.com/pytorch/pytorch/pull/124780)
  • FSDP + DTensor with ShardingStrategy.SHARD_GRAD_OP (https://github.com/pytorch/pytorch/pull/123617) のクラッシュを修正
  • 少なくとも 1 つの前方/後方パスが実行されていない場合に、分散チェックポイント + FSDP で失敗する問題を修正しました。 (https://github.com/pytorch/pytorch/pull/121544) (https://github.com/pytorch/pytorch/pull/127069)
  • 分散チェックポイント + FSDP、および use_orig_params = False およびアクティブ化チェックポイント (https://github.com/pytorch/pytorch/pull/124698) (https://github.com/pytorch/pytorch/pull/126935) でのエラーを修正
  • 分散チェックポイント機能を備えた非永続バッファーを使用したコンパイル済みモジュールの set_model_state_dict エラーを修正 (https://github.com/pytorch/pytorch/pull/125336) (https://github.com/pytorch/pytorch/pull/125337)

MPS:

  • 大規模 (>4GiB) テンソルを処理する際のデータ破損を修正 (https://github.com/pytorch/pytorch/pull/124635)
  • コンプレックス (https://github.com/pytorch/pytorch/pull/125662) の Tensor.abs() を修正

梱包:

  • Windows .pyi ファイルの UTF-8 エンコーディングを修正 (https://github.com/pytorch/pytorch/pull/124932)
  • Windows (https://github.com/pytorch/pytorch/pull/125684) 上で単一ユーザー用にホイールがインストールされている場合の import torch エラーを修正
  • torchdata 0.7.1 (https://github.com/pytorch/pytorch/pull/122616) との互換性を修正
  • aarch64 docker を https://ghcr.io にパブリッシュする問題を修正 (https://github.com/pytorch/pytorch/pull/125617)
  • aarch64 Linux (https://github.com/pytorch/builder/pull/1803) のパフォーマンス回帰を修正

その他:

  • ROCm 上の DeepSpeed トランス拡張ビルドを修正 (https://github.com/pytorch/pytorch/pull/121030)
  • ipython カーネル (https://github.com/pytorch/pytorch/pull/125154) で ~100 回呼び出した後の tensor.dtype.to_complex() でのカーネル クラッシュを修正しました。 リリース トラッカー https://github.com/pytorch/pytorch/issues/125425 には、このリリースに関連するすべてのプル リクエストと、関連する問題へのリンクが含まれています。

pytorch v2.3.1

This release is meant to fix the following issues (regressions / silent correctness):

Torch.compile:

  • Remove runtime dependency on JAX/XLA, when importing torch.__dynamo (https://github.com/pytorch/pytorch/pull/124634)
  • Hide Plan failed with a cudnnException warning (https://github.com/pytorch/pytorch/pull/125790)
  • Fix CUDA memory leak (https://github.com/pytorch/pytorch/pull/124238) (https://github.com/pytorch/pytorch/pull/120756)

Distributed:

  • Fix format_utils executable, which was causing it to run as a no-op (https://github.com/pytorch/pytorch/pull/123407)
  • Fix regression with device_mesh in 2.3.0 during initialization causing memory spikes (https://github.com/pytorch/pytorch/pull/124780)
  • Fix crash of FSDP + DTensor with ShardingStrategy.SHARD_GRAD_OP (https://github.com/pytorch/pytorch/pull/123617)
  • Fix failure with distributed checkpointing + FSDP if at least 1 forward/backward pass has not been run. (https://github.com/pytorch/pytorch/pull/121544) (https://github.com/pytorch/pytorch/pull/127069)
  • Fix error with distributed checkpointing + FSDP, and with use_orig_params = False and activation checkpointing (https://github.com/pytorch/pytorch/pull/124698) (https://github.com/pytorch/pytorch/pull/126935)
  • Fix set_model_state_dict errors on compiled module with non-persistent buffer with distributed checkpointing (https://github.com/pytorch/pytorch/pull/125336) (https://github.com/pytorch/pytorch/pull/125337)

MPS:

  • Fix data corruption when coping large (>4GiB) tensors (https://github.com/pytorch/pytorch/pull/124635)
  • Fix Tensor.abs() for complex (https://github.com/pytorch/pytorch/pull/125662)

Packaging:

  • Fix UTF-8 encoding on Windows .pyi files (https://github.com/pytorch/pytorch/pull/124932)
  • Fix import torch failure when wheel is installed for a single user on Windows(https://github.com/pytorch/pytorch/pull/125684)
  • Fix compatibility with torchdata 0.7.1 (https://github.com/pytorch/pytorch/pull/122616)
  • Fix aarch64 docker publishing to https://ghcr.io (https://github.com/pytorch/pytorch/pull/125617)
  • Fix performance regression an aarch64 linux (https://github.com/pytorch/builder/pull/1803)

Other:

  • Fix DeepSpeed transformer extension build on ROCm (https://github.com/pytorch/pytorch/pull/121030)
  • Fix kernel crash on tensor.dtype.to_complex() after ~100 calls in ipython kernel (https://github.com/pytorch/pytorch/pull/125154)

Release tracker https://github.com/pytorch/pytorch/issues/125425 contains all relevant pull requests related to this release as well as links to related issues.
