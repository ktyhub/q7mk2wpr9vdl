pulsar v2.11.2

パッチ 公開日2023年7月19日 出典apache/pulsar English original

#パルサーv2.11.2

ブローカー

  • ブローカーの再起動ロジックを修正 #20113
  • 間違った topicName が原因で発生する無限 HTTP 呼び出し getSubscriptions を迅速に修正 #20131
  • getPartitionedStats がサブスクリプションの messageAckRate を見逃していた問題を修正 #19870
  • zkConnection 損失時の zkSessionWatcher のデッドロックを修正 #20122
  • getPartitionedStats の戻り値にサブスクリプション タイプが含まれない問題を修正 #20210
  • レプリケーターによって作成されたプロデューサーがトピック統計に表示されない #20229
  • トピックが閉じられた後のレプリケーターの無限 ACK を修正しました #20232
  • ブローカーが 1 つだけの場合は分割バンドルをスキップ #20190
  • RoaringBitmap.contains が値 65535 をチェックできない問題を修正 #20176
  • NavigableSet から最低の PositionImpl を取得 #18278
  • Key_Shared モードでの遅延メッセージの動作を修正 #20233
  • パブリッシュ レイテンシを記録するためのエラー TimeUnit の使用を修正 #20074
  • BrokerData#getTimeAverageData アクセスのスレッド セーフティの問題を修正 #19889
  • メッセージの値が null の場合に ErrorCommand を送信できない問題を修正 #19899
  • LedgerOffloaderFactory が古い nar #19913 をロードできるようにします
  • リモートクラスターが存在しない場合、レプリケーターカーソルを無視して削除します #19972
  • 認証メトリクスの理由ラベルを修正 #20030
  • TransactionImpl の ack/send future を最適化 #20271
  • トピック公開レートリミッターによって引き起こされる NPE を修正 #20302
  • ブッキー アフィニティの設定中に使用されるデフォルトのバンドル サイズを修正 #20250
  • inactiveLedgerRollOverTimeMs が有効な場合にレジャーが OPEN 状態のままになる問題を修正 #20276
  • メタデータ ストアのデッドロックを修正 #20189
  • クラス名のタイプミス PrecisPublishLimiter を「Precise」に修正 #20310
  • 共有ストリーミング ディスパッチャーの消費スタックを修正 #18315
  • 非永続トピックのエントリ フィルター機能を修正 #20141
  • パーティション化された __change_events トピックがポリシー トピックである問題を修正 #20392
  • 台帳を紛失した場合、カーソルマーク削除位置が前に進めなくなる #18620
  • キーの削除後にメタデータの子キャッシュを無効にする #20363
  • PersistentSubscription.expireMessages ロジック チェック バックログを 2 回回避する #20416
  • zk 操作後にメタデータ ストア スレッドに切り替える #20303
  • ホールメッセージが存在する場合のスキップメッセージ API を修正 #20326
  • シェディング中にシステム トピックをフィルタリングしない #18949
  • 特定のトピックのアンロード競合状態の解決策を復元 #20527
  • 1 つのブローカーに同じ名前の管理台帳が 2 つあります #18688
  • REST Client プロデューサーが TLS のみで失敗する #20535
  • createIfMissing を TopicLoadingContext に保存 #19993
  • 完了例外のラップを解除する #20396
  • トピックが閉じられた後に孤立したレプリケーターを解放する #20582
  • 多数のプロデューサーによるパブリッシュ レイテンシーのスパイク問題を修正 #20607
  • Pulsar Loadbalancer で jdk.internal.platform.Metrics を使用して cgroup v2 をサポート #16832
  • サブスクリプション削除ロジックの早い段階で認証を検証する #20549
  • MessageDeduplication #20647 の競合によるパブリッシュ遅延のスパイクを修正
  • 登録マネージャーに見逃したブック ID を追加 #20641
  • レプリケーターのカーソルを位置によってリセットするときの NPE を修正 #20597
  • リプレイポリシーメッセージに例外がある場合、トピックポリシーが適切に機能しない #20613
  • 通知競合状態により予約情報が失われました #20642
  • バンドル分割後に新しいバンドル範囲をポリシーに更新 #17797
  • readType がリプレイの場合、コンシューマが中止された txn メッセージを受信できる問題を修正 #19815
  • タイムスタンプで位置をクエリするときに最も古い位置を返す問題を修正 #20457

Clients

  • [Java] BinaryProtoLookupService でスケジュールされた実行プログラムを使用する #20043
  • [Java] プライマリコンシューマが閉じられた後に孤立プロデューサを解放する #19858
  • [Java] 複数のメッセージを確認するときの NPE を修正 #19874
  • [Java]ProducerImpl schemaCache で空のスキーマ バージョンをキャッシュする #19929
  • [Java] メッセージリスナー使用時に getMsgNumInReceiverQueue 関数が常に 0 を返す問題を修正 #20245
  • [Java] 複数の IO スレッド使用時のコンシューマのデッドロック問題を修正 #20669
  • [Java]grabCnx() 全体の進行をアトミックにする #20595
  • [Java] コンシューマーが再接続するとメッセージが失われる #20695

パルサー IO とパルサー関数

  • [関数] TopicSchema.newSchemaInstance() の関数クラスローダーを使用して、カスタム SerDe クラス使用時の ClassNotFoundException を修正します #20115
  • [関数] pulsar-admin がパッケージ URL で py/go を更新できるようにする #19897
  • [機能] JavaInstanceStarterの型クラス名推論エラーを修正 #20426
  • [関数] Go 関数は、パーティション化されていないトピック ID によってコンシューマを取得する必要があります #20413
  • [機能] 機能アップデートエラーを修正 #19895
  • [機能] アイドルタイマーを正しくリセット #20450 #20450
  • [関数] Go 関数は k8s ランタイムで静的 grpcPort を使用する必要があります #20404
  • [機能] TLS用のパルサー管理の設定 #20533
  • [機能] ラベルエラーを回避するために、関数の削除中にKubernetesRuntimeが関数テナント、名前空間、名前の文字を変換するようにしました #19584
  • [機能] メインスレッドが例外をスローした場合にJVMを終了する #20689
  • [IO コネクタ] キャッチされなかった例外がある場合は、Kafka ソース コネクタを閉じます #20480
  • [IO コネクタ] Kafka ソース コネクタを閉じるとスタックする #20698

可観測性

  • [ブローカー] パーティション化されたパブリッシャートピック統計集計のバグを修正 #18807
  • [ブローカー] 二重引用符が含まれるトピックで Prometheus 形式が壊れる問題を修正 #20230
  • [ブローカー] JVM 開始時間メトリックを追加 #20381
  • [オフロード] オフロード メトリクス エラーを修正 #20366

CLI

  • [CLI] パルサー-client コンシューマーが複製されたサブスクリプションを作成できるようにする #20316
  • [CLI] 過剰なダウンロードを修正するために nar Maven プラグインのバージョンを更新 #20410
  • [CLI] Pulsar CI ワークフローでの OWASP 依存関係チェックを高速化 #20412
  • [CLI] function-localrunner への追加オープンも満たします #20417
  • [管理者] createCluster のクラスター データで返される BAD_REQUEST が null #20346
  • [管理者] パーティション化されたバックログ内の最も古いメッセージをレポートする #19465

その他

  • [ビルド] サービスをマージするとエントリが重複する #17659
  • [オフロード] クラスが見つからないエラーでファイルシステム オフローダーを使用する #20365
  • [パフォーマンス] PerformanceProducer が予想される数のメッセージを生成しません #19775
  • [SQL] Pulsar SQL の不要な構成を削除 #20605
  • [WS] 不要なピンポン実装を削除 #20605
  • [スキーマ] #20730がある場合のみ例外を処理します

ライブラリの更新

  • SnakeYAML バージョンを 2.0 #20120 にアップグレードします
  • Kotlin バージョンを 1.4.32 から 1.8.20 にアップグレード #20089
  • Jetty サーバーのバージョンを 9.4.51.v20230217 #20226 にアップグレードします。
  • スプリント バージョンを 5.3.27 #20226 にアップグレード
  • Swagger バージョンを 1.6.10 #20226 にアップグレード
  • SQLite JDBC をアップグレードして CVE-2023-32697 #20411 を解決します
  • Netty を 4.1.93.Final #20423 にアップグレードします。
  • CVE-2023-2976 #20459 に対処するために、Guava を 32.0.0 にアップグレードします。
  • Pulsar イメージには Ubuntu 22.04 を使用する #20475
  • 複数の CVE に対処するために snappy-java をアップグレード #20604
  • CVE-2023-2976 #20699 に対処するために、Guava を 32.1.1 にアップグレードします。
