#パルサーv2.9.4

何が変わったのか

  • [branch-2.9] https://github.com/apache/pulsar/pull/16146 の @tjiuming によるメッセージ ACK レートを追加
  • [branch-2.9] チェリーピックの問題を修正。 @mattisonchao 著、https://github.com/apache/pulsar/pull/16346
  • [Branch-2.9][Cherry-pick] バグ修正: bookkeeperClientExposeStatsToPrometheus が https://github.com/apache/pulsar/pull/16343 の @HQebut によって true の場合、管理対象台帳 client 統計を prometheus に公開できない
  • [ブランチ 2.9] 圧縮サブスクリプション承認マーカー メッセージの問題を修正。 @mattisonchao 著、https://github.com/apache/pulsar/pull/16348
  • [Branch-2.9] https://github.com/apache/pulsar/pull/16347 で @mattisonchao が間違った認証データを渡す問題を修正
  • [Branch-2.9][transaction] Cmd-Subscribe および Cmd-Producer は 100 回再試行しても成功しません。 @mattisonchao 著、https://github.com/apache/pulsar/pull/16349
  • [Branch-2.9][Cherry-pick] 名前空間での非永続トピックの取得の問題を修正。 by @Technoboy - https://github.com/apache/pulsar/pull/16517
  • [branch-2.9] https://github.com/apache/pulsar/pull/16628 で @mattisonchao によって例外が発生する MockStatic メソッドを修正しました
  • [branch-2.9] 互換性の問題を修正。 @mattisonchao 著、https://github.com/apache/pulsar/pull/16779
  • [branch-2.9] https://github.com/apache/pulsar/pull/16794 の @mattisonchao による List パラメーターを持つ FutureUtil#waitForAll メソッドと FutureUtil#waitForAny メソッドを追加し直す
  • [ブローカー][監視][修正] https://github.com/apache/pulsar/pull/16866 の @tjiuming による pulsar_subscription_msg_ack_rate を修正
  • [Branch-2.9][fix][client]ProducerImpl で重複していた client のメモリ制限 currentUsage リークとセマフォの解放を修正しました。 @Nicklee007 著、https://github.com/apache/pulsar/pull/16971
  • [改善][ブローカー] msgOutCounter と bytesOutCounter を最適化 (#16214) (#16286) by @nahguam (https://github.com/apache/pulsar/pull/16771)
  • [Branch-2.9][修正][client] createOpSendMsg での MaxQueueSize セマフォのリリース リークを修正。 @Nicklee007 著、https://github.com/apache/pulsar/pull/16958
  • [ブランチ 2.9][修正][ブローカー] log4j2 バージョンを 2.18.0 (#16884) にアップグレード (https://github.com/apache/pulsar/pull/16995 の @liudezhi2098 により)
  • [改善][認証][ブランチ-2.9] https://github.com/apache/pulsar/pull/16987 の @nodece による HTTP パラメータからのトークンの取得のサポート
  • [ブランチ-2.9] https://github.com/apache/pulsar/pull/17246 の @hangc0276 によるブックキーパーとの同期を維持するために、rocksdb バージョンを 6.16.4 にアップグレードします。
  • [branch-2.9] https://github.com/apache/pulsar/pull/17327 の @mattisonchao による PowerMockito によるモック最終クラスをサポート
  • [branch-2.9][fix][load-balancer] loa で誤って設定されたリソース使用量 (>100%) をスキップします…by @heesung-sn in https://github.com/apache/pulsar/pull/17285
  • [修正][ブローカー][ブランチ-2.9] https://github.com/apache/pulsar/pull/17281 の @coderzc によるエントリごとの平均メッセージの計算を修正
  • [branch-2.9] https://github.com/apache/pulsar/pull/17048 の @equanz によってすべてのテストが正しく実行されるように、テスト ファイル名を *Test2.java から *Test.java に変更します。
  • [修正][c++][branch-2.9]間違ったコンシューマー サイズを修正: https://github.com/apache/pulsar/pull/17629 の @coderzc による readerCreatedCallback_ を実行する前に callback を実行
  • [branch-2.9][修正][ブローカー] https://github.com/apache/pulsar/pull/17604 で @poorbarcode によってカーソルが閉じられたときにカーソル情報エラーが持続する
  • [branch-2.9][cherry-pick] プロデューサー/コンシューム権限がスキーマを取得できない問題を修正。 by @Technoboy - https://github.com/apache/pulsar/pull/17730
  • [修正][ブローカー][関数ワーカー] prometheus メトリクスが https://github.com/apache/pulsar/pull/17618 の @marksilcox によってタイプ (#8407、#13865) ごとにグループ化されていることを確認します。
  • [ブランチ-2.9] グループ prometheus メトリクス。 @tjiuming 著、https://github.com/apache/pulsar/pull/17852
  • [branch-2.9] https://github.com/apache/pulsar/pull/17894 の @codelipenghui によるチェリーピックの問題を修正
  • [修正][ブローカー][ブランチ-2.9] https://github.com/apache/pulsar/pull/17986 の @dragonls によるシステム トピック スキーマに互換性がないバグを修正
  • [改善][認証][branch-2.9] https://github.com/apache/pulsar/pull/16944 の @nodece による基本認証設定の取得を改善しました。
  • [修正][client][txn] PulsarClient HashWheelTimer を使用して、https://github.com/apache/pulsar/pull/18058 の @lifepuzzlefun によるプロデューサー バッチ トリガー タスクをスケジュールします。
  • [修正][秒] ファイル階層型ストレージ: https://github.com/apache/pulsar/pull/18105 の @mattisonchao による CVE-2022-40149 を取り除くために、Jettison をアップグレードします。
  • [branch-2.9] インターリーブ遅延によるメッセージのキー共有配信を修正しました。 @mattisonchao 著、https://github.com/apache/pulsar/pull/18108
  • [branch-2.9] https://github.com/apache/pulsar/pull/18117 の @Technoboy- によるライセンス チェックの問題を修正
  • [修正][cpp][branch-2.9] zlibのダウンロードパスを修正。 @shibd 著、https://github.com/apache/pulsar/pull/18127
  • [fix][sec][branch-2.9] kafka と lo によってもたらされた CVE を取り除くための依存関係の更新…by @alpreu in https://github.com/apache/pulsar/pull/18304
  • [cherry-pick][branch-2.9] 名前空間で OffloadThreshold を取得するときの NPE を修正しました。 @congbobo184 著、https://github.com/apache/pulsar/pull/18638
  • [cherry-pick][branch-2.9] Cherry-pick #17736 の問題と DnsResolverTest ライセンス ヘッダー (https://github.com/apache/pulsar/pull/18640 の @congbobo184 による)
  • [cherry-pick][branch-2.9] ResourceGroupService がスケジュールされたタスクを実行するときの NPE を修正しました。 @congbobo184 著、https://github.com/apache/pulsar/pull/18685
  • [cherry-pick][branch-2.9] https://github.com/apache/pulsar/pull/18702 の @congbobo184 によるチェリーピック #17592 の欠落コードと不安定なテスト testFailoverSingleAckedPartitionedTopic を修正
  • [branch-2.9] https://github.com/apache/pulsar/pull/18710 の @gaozhangmin による永続カーソル リークの問題を修正
  • [branch-2.9][fix][broker] https://github.com/apache/pulsar/pull/18762 の @codelipenghui による重複したスキーマ作成 (#18701) を修正しました。
  • [チェリーピック][ブランチ-2.9] https://github.com/apache/pulsar/pull/18793 の @congbobo184 によるチェリーピック #17609 #17957 のインポートを修正
  • [cherry-pick][branch-2.9] getList を非同期にする #16221 by @congbobo184 (https://github.com/apache/pulsar/pull/18811)
  • [cherry-pick][branch-2.9] Cherry-pick #18307 (ネームスペースを強制的に削除できない修正) by @liangyepianzhou in https://github.com/apache/pulsar/pull/18803
  • [cherry-pick][branch-2.9] https://github.com/apache/pulsar/pull/18821 の @congbobo184 によるプロト ライセンス バージョンの変更
  • [cherry-pick][branch-2.9] https://github.com/apache/pulsar/pull/18831 の @congbobo184 によるシステム トピックのクリーン トピック ポリシーの削除 (#18823) を修正しました。 フル Changelog: https://github.com/apache/pulsar/compare/v2.9.3...v2.9.4
