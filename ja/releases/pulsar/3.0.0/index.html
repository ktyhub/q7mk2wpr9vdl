#パルサーv3.0.0

重要なお知らせ

  • RocksDB バージョンを 7.9.2 にアップグレードして、#20072 の BookKeeper の RocksDB 依存関係との同期を維持します。
  • #19502 で複数のトピックのサブスクリプションの負荷を分散するために一貫性のあるハッシュ リングを導入しました。
  • #19486 で Java コンシューマーに DLQ ポリシーを設定するときにデフォルトの 30 秒の ackTimeout を削除しました。
  • #19455 でoriginalPrincipalを設定するには、authRoleがproxyRoleである必要があります
  • #19377 で Elasticsearch シンク アイドル CNX タイムアウトを 30 秒に更新
  • newTransaction 時にチェック例外をビルダーに移動します。 #19356で
  • TokenAuthenticationState: #19314 でトークンを 1 回だけ認証します
  • OneStageAuth 状態: #19295 で authn をコンストラクターの外に移動します
  • #19197 で HTTP 認証を簡素化するために AuthenticationProvider を更新しました。
  • #19182 の 2.7 および 2.9 で非推奨となった AuthorizationProvider メソッドを削除
  • #19180 で AuthorizationService メソッド、AuthorizationProvider メソッドのブロックを非推奨にする
  • 存在しない永続パーティションの作成を拒否します。 #19086で
  • #18997 にブローカー インターセプターがない場合、CommandAck のコピーの作成を省略します。
  • #18712 の TLS trust 証明書に正しいファイル パスを使用します。
  • #18097 でクォーラム サーバーと Netty サーバーの証明書の更新を有効にします
  • #17419 の Prometheus メトリクスからタイムスタンプを削除
  • Revert 5895: #17060 の再配信カウントを修正
  • #16018 でプロデューサー/消費権限が v1/スキーマを取得できない問題を修正
  • #15640 の自動回復デフォルト reppDnsResolverClass から ZkBookieRackAffinityMapping
  • #19432 でマルチアーチ Docker イメージを構築およびプッシュできるようにします
