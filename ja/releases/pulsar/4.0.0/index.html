#パルサーv4.0.0

2024-10-21

3.3.0 リリース準備開始以降の 4.0.0 リリースの変更点。 完全なリストについては、完全な changelog および 完全な PR リスト を確認してください。 Apache Pulsar 4.0 の新機能? では、次のようなトピックについて説明します。

  • 強化された Key_Shared サブスクリプションの実装
  • Alpine Linux および Java 21 に基づく安全な Docker ランタイム
  • マルチテナント展開向けのサービス品質管理の強化
  • マルチテナントリソース管理の基盤としてのレート制限
  • 以前のバージョンからのアップグレード パス
  • Client の互換性と CVE-2024-47561 に対処するための Java clients のアップグレードの重要性
