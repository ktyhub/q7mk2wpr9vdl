pulsar v3.1.2

#パルサーv3.1.2

PIP

  • PIP-318: #21578 の @coderzc によるトピック圧縮中に null キー メッセージを保持しないことをサポートします。

ブローカー

  • #21721 の @heesung-sn により、ServiceUnitStateChannel モニターが非アクティブなバンドル状態のみを廃棄するように修正されました。
  • #21690 の @coderzc による設定キーのタイプミスを修正
  • #21673 の @nodece によるプロデューサー#sendAsync の前に GeoPersistentReplicator.msgOut を記録します。
  • #21651 の @coderzc によってcursorPropertiesが空の場合はrecoverBucketSnapshotログを出力します
  • #21601 の @coderzc によるトピック圧縮中に null キー メッセージを保持しないことをサポート
  • #21595 の @poorbarcode による NPE によるトピックのタイムアウトを削除
  • #21591 で @shibd によって名前空間/トピック ポリシーが更新されると、LedgerOffloader が重複して作成される
  • #21571 の @coderzc による圧縮されたトピックからコンシューマーがコミットされていないメッセージを読み取る問題を修正
  • #21545 の @mattisonchao による、異なる自動作成戦略でトピックを作成すると競合状態が発生する問題を修正しました。
  • #21542 の @poorbarcode による台帳作成タイムアウト チェックの孤立したスケジュールされたタスクを修正
  • #21540 の @poorbarcode による OOM を引き起こした数千の孤立した PersistentTopic を修正
  • #21530 の @mattisonchao による管理台帳を削除するときの未完了のコールバックを修正しました
  • #21510 の @liudezhi2098 による setReplicatedSubscriptionStatus の誤った動作を修正しました。
  • #21508 の @rdhabalia による非アクティブな管理台帳で非永続カーソルを作成する際のエラーを修正
  • #21496 の @lhotari による、brokerShutdownTimeoutMs=0 の場合の PulsarService/BrokerService のシャットダウンを修正しました。
  • #21495 で @liangyepianzhou によってレプリケーションが有効になっていないトピックの場合、レプリケートされたスナップショット マーカーを書き込まないでください。
  • #21486 の @mattisonchao による MultiRolesTokenAuthorizationProvider で null ロールを渡すことを回避します。
  • #21481 の @erobot による Rackaware ポリシーで BookieRackAffinityMapping を使用するときのデッドロックを修正しました
  • #21465 の @coderzc による圧縮されたトピックからコンシューマーがコミットされていないメッセージを読み取る問題を修正
  • #21461 の @AnonHxy による resource_quota_zpath を修正
  • #21445 の @mattisonchao によるアンロード ステータスでスタックした名前空間バンドルを修正
  • エントリがフィルタリングされている場合、CompactorSubscription に対する個別の確認応答を無視します。 @coderzc 著、#21434
  • #21429 の @Technoboy による匿名 clients を使用する場合の MultiRoles トークン プロバイダー NPE を修正しました。
  • #21360 の @TakaHiR07 によるハートビート ネームスペース作成イベント トピックとハートビート トピックを削除できない問題を修正しました。
  • #21348 の @TakaHiR07 によるハートビート名前空間作成トランザクション内部トピックを修正しました。
  • #21332 の @Demogorgon314 による ExtensibleLoadManager を使用するとアンロード操作がスタックする問題を修正しました。
  • #21314 の @Demogorgon314 による拡張ロード マネージャー (#21213) を使用する場合のルックアップ ハートビートと sla 名前空間バンドルを修正しました。
  • #21302 の @lhotari による RangeCache.put および RangeCache.clear に関するスレッド セーフの問題を修正しました。
  • ServiceUnitStateChannel で ConcurrentHashMap を使用し、#21282 の @heesung-sn による再帰的な更新エラーを回避します
  • #21255 の @mattisonchao による一貫性のないトピック ポリシーを修正
  • #21220 の @poorbarcode によって前のリクエストが非アクティブである場合、プロデューサーのリクエストが最初に成功するようにします。
  • #21213 の @Demogorgon314 による拡張可能なロード マネージャーを使用するときのルックアップ ハートビートと sla 名前空間バンドルを修正しました。
  • #21193 の @lifepuzzlefun によって重複排除が無効になっている場合に、非アクティブなプロデューサーのレコードを回避する
  • #21155 の @poorbarcode によって指定されたプロデューサーをオーバーライドできるようにする
  • #20944 で @TakaHiR07 によって bkclient が初期化された後に zk ラック情報を削除すると、Rackaware ポリシーが無効になります
  • スーパー ユーザー ロールが MultiRolesTokenAuthorizationProvider プラグインに含まれていることを確認します (#20939 の @tuteng によって)

Client

  • #21620 の @liangyepianzhou による getTopicName の一貫性のない API アノテーションを修正しました。
  • #21485 で @hanmz によってパーティションを消費するときの印刷エラー ログ「パーティションの自動取得に失敗しました」を修正しました。
  • #21270 の @liangyepianzhou によるテーブル ビューの構築中の多大な時間の消費を回避します。

トランザクション

  • OpRequestSend の再利用の問題により、@TakaHiR07 による tbClient commitTxnOnTopic が予期せずタイムアウトになりました (#21505)
  • #21268 の @liangyepianzhou によるトランザクションでチャンクメッセージを確認するときに、すべてのメッセージ ID を確認します

CI とテスト

  • #21407 の @lhotari によるテストでの LocalBookkeeperEnsemble リソース リークを修正
  • #21391 の @lhotari によるクラスター移行テストを含む新しい CI 単体テスト グループ「ブローカー グループ 4」を追加
  • #21378 の @lhotari による Pulsar Functions テストによるリソース リークを修正
  • #21374 の @lhotari による圧縮テストでのリソース リークの一部を修正
  • #21366 の @lhotari による ClusterMigrationTest でのリソース リークを修正しました。
  • #21365 の @lhotari によりビルド前にさらにディスク領域を解放することで、docker イメージのビルドを修正しました。
  • #21329 の @lhotari による不安定な CompactionTest.testDispatcherMaxReadSizeBytes を修正
  • #21328 の @lhotari による不安定なテスト NarUnpackerTest を修正
  • #21310 の @horizonzy による zookeeper 関連のフラッキー テストを修正
  • #21222 の @poorbarcode による不安定なテスト PatternTopicsConsumerImplTest を修正しました

セキュリティ

  • #21619 の @liangyepianzhou による CVE-2023-46120 に対処するために、rabbitmq client をアップグレードします。
  • #21398 の @lhotari による CVE-2023-44981 に対処するために、Zookeeper を 3.8.3 にアップグレードします。
  • #21397 の @lhotari による CVE-2023-44487 に対処するために、Netty を 4.1.100 にアップグレードします。
  • #21395 の @lhotari による CVE-2023-44487 に対処するために、Jetty を 9.4.53 にアップグレードします。
  • #21338 の @merlimat による匿名 clients を使用する場合の MultiRoles トークン プロバイダーを修正しました。
  • @lhotari による OWASP 依存関係チェックの抑制を #21281 に追加
  • @lhotari による snappy-java を 1.1.10.5 にアップグレード (#21280)

ビルド

  • M1 Mac でステージ Docker イメージが失敗する問題を修正 (@AnonHxy による #21659)
  • #21489 の @lhotari による docker イメージの構築における apt ダウンロードの問題を修正
  • #21447 の @poorbarcode により、schema_example.conf の名前を schema_example.json に変更します。
  • #21278 の @lhotari による JDK21 でのコンパイルをサポートするために、Lombok を 1.18.30 にアップグレードします。

その他

  • [オフロード] オフロードで @zymap による MetaStore 例外が発生した場合、データをクリーンアップしません (#21686)
  • [プロキシ] #21428 の @mattisonchao によりステータス エンドポイントを認証範囲外に移動します
  • [自動回復] #21340 の @horizonzy により、レプリケーション テストを BookKeeper から Pulsar に移行します。
  • [bk-client] #21327 の @horizonzy による bk client MinNumRacksPerWriteQuorum と EnforceMinNumRacksPerWriteQuorum が機能しない問題を修正しました。
  • [SQL] json および avro の UUID をサポート (@liangyepianzhou による #21267)
  • [ログ] #20932 で @poorbarcode によってトピックが見つからなかった場合のあいまいな応答を修正しました

pulsar v3.1.2

PIPs

  • PIP-318: Support not retaining null-key message during topic compaction by @coderzc in #21578

Broker

  • Fixed ServiceUnitStateChannel monitor to tombstone only inactive bundle states by @heesung-sn in #21721

  • Delete topic timeout due to NPE by @poorbarcode in #21595
  • Duplicate LedgerOffloader creation when namespace/topic policies are updated by @shibd in #21591
  • Fix issue with consumer read uncommitted messages from compacted topic by @coderzc in #21571

  • Fix orphan scheduled task for ledger create timeout check by @poorbarcode in #21542

  • Fix unfinished callback when deleting managed ledger by @mattisonchao in #21530
  • Fix setReplicatedSubscriptionStatus incorrect behavior by @liudezhi2098 in #21510
  • Fix failure while creating non-durable cursor with inactive managed-ledger by @rdhabalia in #21508
  • Fix PulsarService/BrokerService shutdown when brokerShutdownTimeoutMs=0 by @lhotari in #21496
  • Do not write replicated snapshot marker when the topic which is not enable replication by @liangyepianzhou in #21495
  • Avoid pass null role in MultiRolesTokenAuthorizationProvider by @mattisonchao in #21486
  • Fix the deadlock when using BookieRackAffinityMapping with rackaware policy by @erobot in #21481
  • Fix issue with consumer read uncommitted messages from compacted topic by @coderzc in #21465
  • Fix resource_quota_zpath by @AnonHxy in #21461

  • Fix lookup heartbeat and sla namespace bundle when using extensible load manager(#21213) by @Demogorgon314 in #21314

  • use ConcurrentHashMap in ServiceUnitStateChannel and avoid recursive update error by @heesung-sn in #21282
  • Fix inconsistent topic policy by @mattisonchao in #21255
  • Let the producer request success at the first time if the previous one is inactive by @poorbarcode in #21220

  • Fix inconsistent API annotations of getTopicName by @liangyepianzhou in #21620
  • Fix print error log 'Auto getting partitions failed' when expend partition by @hanmz in #21485
  • Avert extensive time consumption during table view construction by @liangyepianzhou in #21270

  • Ack all message ids when ack chunk messages with transaction by @liangyepianzhou in #21268

Security

  • Upgrade Zookeeper to 3.8.3 to address CVE-2023-44981 by @lhotari in #21398
