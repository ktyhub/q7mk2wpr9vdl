#パルサーv2.7.4

セキュリティ

  • log4j を 2.17.0 にアップグレード - CVE-2021-45105 #13392
  • commons-compress を 1.21 にアップグレード - CVE-2021-35515、CVE-2021-35516、CVE-2021-35517、および CVE-2021-36090 #11345

ブローカー

  • DispatchRateLimiter が有効にならない問題を修正 #8611
  • precisionTopicPublishRateLimiterEnable=true を使用する場合の set-publish-rate を修正 #10384
  • トピックポリシーの保持ポリシーが機能しない問題を修正 #11021
  • バイナリ ルックアップ サービスでの GetTopicsOfNamespace が認証をチェックしない問題を修正 #11172
  • 圧縮時のキーの保持を修正 #11287
  • ポリシーを取得するためにパーティション化されたトピック名を使用する問題を修正 #11294
  • 永続的なパーティション化されたトピックをアンロードする際の NPE を修正 #11310
  • RateLimiter コンストラクターを削除し、ビルダーの使用法に置き換えます #11599
  • トピックポリシー取得設定にバックオフを追加 #11574
  • デコード圧縮のマネージドレジャー情報データを修正 #11569
  • バックオフなしの一部のトピック ポリシー操作を修正 #11560
  • 最も早い位置を使用してトピックをサブスクライブするときに失われるデータを修正しました #11547
  • スキーマの削除でトピックを削除するときのスキーマの削除を修正しました #11501
  • ハートビート名前空間のシステム トピックを作成しない #11499
  • 管理台帳情報を圧縮 #11490
  • トピックポリシー取得設定にバックオフを追加 #11487
  • 正確なレート制限を解決しても効果がありません #11446
  • レプリケートされたサブスクリプションの直接メモリ リークを修正 #11396
  • クラスターを削除するときにレプリケーターとレプリケーション client を閉じる #11390
  • すべてのカーソルが消費された後に読み取りハンドルを無効にする #11389
  • 永続的なパーティション化されたトピックをアンロードする際の NPE を修正 #11386
  • 圧縮時のキーの保持を修正 #11384
  • クラスター間でのシステム トピックのレプリケートを無効にする #11376
  • パラレル正確なパブリッシュレート制限の修正 #11372
  • Pulsar Admin List サブスクリプションは、パーティション固有のサブスクリプションが作成されるときに、Partition-0 に対して作成されたサブスクリプションのみをリストします #11355
  • 名前空間バンドルキャッシュの一貫性のない動作を修正 #11346
  • znode バージョンの不一致への台帳リストの更新が失敗し、台帳が削除されない問題を修正しました #12015
  • 次の有効な位置が見つからない場合に位置情報を出力 #11969
  • マネージドレジャー層の他のトピックのデータの読み取りを禁止 #11913
  • トピックポリシーを取得するためにパーティション化されたトピック名を使用する問題を修正 #11897
  • トピック レベルのバックログ クォータ ポリシー警告ログを調整 #11863
  • プロデューサーがビジー状態になると、リストから既存のプロデューサーが削除されます #11804
  • 全キー範囲がアクティブなコンシューマでカバーされていない場合の NPE とメモリ リークを処理する #11749
  • 直接のメモリリークを防ぐためにエントリを破棄するときに .release() を呼び出します #11748
  • フェンスされた状態で回復できないトピックを修正しました #11737
  • 非 TLS サービス ポートの無効化をサポート #11724
  • 更新トピック名が既存のトピックに一部として含まれている場合、トピックを更新できないバグを修正 #11686
  • InterceptException #11650 をスローしたときに Pulsar がエラー メッセージに応答しなかった問題を修正
  • オフローダーからオフロード ポリシーを取得するための冗長な呼び出しを回避する #11629
  • ManagedLedger の元帳所有権チェックの最適化 #13222
  • バンドルのアンロード タイムアウトを引き起こす失敗した OpAddEntry オブジェクトを再利用しないでください #12993
  • プロデューサーがトピックのプロデューサー マップから誤って削除される問題を修正 #12846
  • システム トピックのスキーマ互換性ポリシーの構成を許可 #12598
  • すでに削除された名前空間トピックのクリーンアップ #12583
  • 状態チェック後に OpAddEntry を pendingAddEntries に追加 #12570
  • ManagedLedgerImpl を削除するときにスケジュールされたタスクをキャンセルする #12565
  • ManagedLedger が閉じている間の OpAddEntry での NPE #12364
  • クリティカルなスレッドでメタデータへの呼び出しがブロックされる可能性を回避する #12340
  • OpAddEntry のリサイクル後に使用される問題を修正 #12103
  • キャッシュエビクションのメモリ使用量を最適化 #12045
  • 以前のすべてのコンシューマが切断された後、新しいコンシューマに使用される間違ったキー ハッシュ セレクターを修正しました #12035
  • auth_errors のみがエラー レベル #9325 でログに記録されます。

依存関係のアップグレード

  • Boost::System ランタイム依存関係を削除 #9498
  • Jetty を 9.4.43.v20210629 #11660 にアップグレードします
  • maven.restlet.org リポジトリを追加 #13248
  • ZooKeeper バージョンを 3.5.9 #12981 にアップグレードします
  • 画像の公開プロセスから pulsar-dashboard を削除 #12534
  • docker イメージに Java 8 を使用するようにロールバック #12357
  • TestContainers を 1.15.1 #9120 にアップグレードします

Client

  • [Java] 共通ロジックを再利用するためのリファクタリング #9670
  • [Java] 分割されたトピック メッセージを異なるリスナー スレッドで処理する #10017
  • [Java] コンシューマー リスナーがレシーバー キュー サイズを考慮しない問題を修正 #11455
  • [Java] パルサー oauth2 client にオプションの params スコープを追加 #11931
  • [Java] 重複したメッセージを受信するバッチインデックスレベルでのシークを修正しました #11826
  • [Java] マルチトピックコンシューマーの競合状態を修正 #11764
  • [Java] サブスクリプション失敗時に PulsarClient からコンシューマー参照を削除 #11758
  • [Java] Consumer.batchReceive のブロック永久バグを修正 #11691
  • [Java] タイムアウト時に CloseProducer を送信 #13161
  • [Java] Thread.currentThread().interrupt() への無効な呼び出しを削除 #12652
  • [Python] 必須のキー引数を無視するフィールドを修正 #11508
  • [C++] boost::regex の使用を削除 #9533
  • [C++] sendRequestWithId を使用して hasMessageAvailable にタイムアウトを追加する #11600
  • [Pulsar perf] pulsar-admin、pulsar-client、および pulsar-perf のログ レベル設定を修正 #12915

関数とパルサー IO

  • 空の例外リストを公開するソース統計を修正 #11478
  • 関数 API が認証データを使用してスーパーユーザーをチェックできない問題を修正 #11418
  • Pulsar シンクの KEY_BASED バッチ ビルダーの設定をサポート #11710
  • .nar ファイルを検出し、関数起動時のスパム ログを防止 #12665
  • HDF での非推奨の api の使用を削除 #12080

階層型ストレージ

  • BlobStore 読み取りハンドラーの潜在的な競合状態を修正 #12123

ビルド

  • CMake に Python2 #9690 を強制的に検索させます
  • ubuntu 20.04 を docker イメージ ベースとして使用する #12017
  • docker イメージのインストール python3.7-dev の問題を修正 #11942

  • Remove RateLimiter constructors and replace with builder usage #11599

  • Fix decode compression managedLedgerInfo data #11569
  • Fix some topic policy operation without backoff #11560
  • Fix data lost when using earliest position to subscribe to a topic #11547
  • Fix the schema deletion when delete topic with delete schema #11501
  • Do not create system topic for heartbeat namespace #11499
  • Compress managed ledger info #11490
  • Add backoff for setting for getting topic policies #11487
  • Solving precise rate limiting does not take effect #11446
  • Fix replicated subscriptions direct memory leak #11396
  • Close the replicator and replication client when deleting cluster #11390
  • Invalidate the read handle after all cursors are consumed #11389
  • Fix NPE when unloading persistent partitioned topic #11386
  • Fix retention of keys in compaction #11384
  • Disable replicate system topic across clusters #11376
  • Parallel Precise Publish Rate Limiting Fix #11372
  • Pulsar Admin List Subscription lists only subscriptions created for Partition-0 when partition specific subscriptions are created #11355
  • Fix inconsistent behavior for Namespace bundles cache #11346
  • Fix update ledger list to znode version mismatch failed, ledger not delete #12015
  • Print position info when can't find next valid position #11969
  • Forbid to read other topic's data in managedLedger layer #11913

  • Fix the topic in fenced state and can not recover #11737
  • Support disabling non-TLS service ports #11724
  • Fix the bug, can not update topic when the update topicName is contained by an existed topic as a part #11686
  • Fix Pulsar didn't respond error messages when throw InterceptException #11650
  • Avoid redundant calls for getting the offload policies from the offloader #11629
  • Optimize ManagedLedger Ledger Ownership Check #13222

  • Fix producer getting incorrectly removed from topic's producers map #12846
  • Allow to configure schema compatibility policy for system topics #12598

  • Add OpAddEntry to pendingAddEntries after the state check #12570
  • Cancel scheduled tasks when deleting ManagedLedgerImpl #12565
  • NPE on OpAddEntry while ManagedLedger is closing #12364
  • Avoid potentially blocking calls to metadata on critical threads #12340
  • Fix used after recycle issue in OpAddEntry #12103
  • Optimize the memory usage of Cache Eviction #12045
  • Fix wrong key-hash selector used for new consumers after all the previous consumers disconnected #12035
  • Only auth_errors should log at error level #9325

Dependency upgrade

  • Remove Boost::System runtime dependency #9498
  • Upgrade Jetty to 9.4.43.v20210629 #11660
  • Add maven.restlet.org repository #13248
  • Upgrade ZooKeeper version to 3.5.9 #12981
  • Remove pulsar-dashboard from the publish process of images #12534
