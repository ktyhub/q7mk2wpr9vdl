  • [修正][ブローカー] トピックの読み込みがタイムアウトしないように、重複排除カーソルのバックログが長くならないようにしました (#22479)
  • [修正][ブローカー] トピックの読み込みがタイムアウトしないように、重複排除カーソルの長いバックログを防止します (#22479)

  • [修正][ブローカー] キーに alg フィールドが設定されていない JWK で OIDC プロバイダーをサポート (#22421)

  • [改善][ブローカー] 設定 metricsBufferResponse の説明をより効果的にします (#22490)
  • [改善][メタ] エラー後にバックオフを使用して ResourceLock の再検証を再試行します (#22617)
  • [改善][管理者] 権限操作の前にトピックが存在していたかどうかを確認します (#22547)

  • [改善][ブローカー] 出力されるエラー メッセージにトピック名を追加します。 (#22506)
  • [改善][ブローカー] Key_Shared モードを使用するときに読み取りと破棄を繰り返すことを回避します (#22245)

  • [改善][ブローカー] デフォルトで BrokerClientAuthenticationParameters と bookkeeperClientAuthenticationParameters をログに記録しない (#22395)

  • [改善][ブローカー] バックログ クォータ制限超過ログが debug (#22488) に置き換えられました
  • [修正][ml] 終了した管理台帳を回復する際の getValidPositionAfterSkippedEntries の NPE を修正 (#22552)
