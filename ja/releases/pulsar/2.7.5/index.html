#パルサーv2.7.5

ブローカー

  • [修正][ブローカー] OpReadEntry#16966 で台帳 ID が見つからない場合の NPE を修正
  • [修正][ブローカー] ラック名を検証 #16850
  • [修正][ブローカー] ブックリー参加ラックが失敗する原因となった無効なラック名を修正 #16845
  • [修正][ブローカー] PersistentTopic#getMessageTTL #16899 でメタデータへの呼び出しがブロックされる可能性を回避します。
  • [修正][ブローカー] TLS 構成を使用して client を作成する問題を修正 #16326
  • [修正][ブローカー] checkReplication の実行中に欠落しているメタデータ キャッシュのデッドロックを修正しました #16889
  • [修正][ブローカー] Linux 上の間違った NIC 速度の単位を修正 #15770
  • [修正][ブローカー] ping または pong メッセージを送信できない場合に接続を閉じる #15382
  • [修正][ブローカー] MessageDeduplication#inactiveProducers が正しく永続化されない可能性がある問題を修正 #15206
  • [修正][ブローカー] 非アクティブなプロデューサー名を削除する messageDedup を修正 #12493
  • [修正][ブローカー] 元の台帳が削除された圧縮データをリーダーがスキップする問題を修正しました。 #16407
  • [修正][ブローカー] 空のコンパクトレジャーから最後のメッセージIDを取得する問題を修正しました。 #16402
  • [修正][ブローカー] 圧縮カーソルがトピックの最後に到達する間、圧縮された台帳からメッセージ ID を返します。 #16395
  • [修正][ブローカー] リーダー/コンシューマの圧縮データをスキップする問題を修正 #16301
  • [修正][ブローカー] トピックのアンロード中にリーダーが残りの圧縮データをスキップしていた問題を修正 #16300
  • [修正][ブローカー] 間違った認証データの受け渡しを修正 #16201
  • [修正][ブローカー] 負のエントリ ID #16299 を持つ lastconfirmedEntry の間に、誤って返された最後のメッセージ ID を修正しました。
  • [修正][ブローカー] AutoUpdateSchemaEnabled=falseの場合、システムトピックを有効にできない問題を修正。 #15754
  • [修正][ブローカー] 台帳ロールオーバーによるメッセージ消失の問題を修正。 #14703
  • [修正][ブローカー] 失われたメッセージの問題を修正 12221 #12223
  • [修正][ブローカー] TopicPoliciesCacheNotInitException の問題を修正しました。 #14293
  • [修正][ブローカー] key_shared モード使用時のデッドロックを修正 #11965
  • [修正][ブローカー] OverloadShedderを使用しない場合のログ内容のエラーを修正。 #13540
  • [改善][ブローカー] AuthenticationDataHttp インスタンス作成時に不要な DNS 解決をスキップ #15221
  • [改善][ブローカー] トピックが見つからない場合のエラーログを改善 [#13950) #14893
  • [改善][ブローカー] 空白のプレフィックスまたはサフィックス文字列を含む構成値文字列をトリミングします #13984
  • [改善][ブローカー] パススルー構成を介して DLog Bookie、Pulsar、Admin clients を構成 #15818
  • [クリーンアップ][ブローカー] AuthenticationDataHttp インスタンス作成時の DNS 解決のスキップを改善 #15228
  • [クリーンアップ][ブローカー] OpReadEntry#checkReadCompletion での混乱を避けるために、不要なコードを削除します。 #15104
  • [クリーンアップ][ブローカー] 削除マークの位置より前の個別に削除されたメッセージをクリーンアップします #14261

セキュリティ

  • [改善][秒] 基本認証設定の取得を改善 #16947
  • [改善][秒] HTTP パラメータからのトークンの取得のサポート #16892
  • [修正][秒] AuthorizationService はプロバイダーの canLookupAsync メソッドを使用する必要があります #11777
  • [修正][秒] サブスクリプション名の AuthenticationDataSource 突然変異を回避 #16065

  • [cleanup][sec] 設定スクリプトでパスワードを難読化するときに大文字と小文字を無視する #15077

ストレージ

  • [修正][ストレージ] ManagedCursor: メタ台帳の作成が失敗した場合にコールバックなしで削除をマークする #16841

  • [修正][ストレージ] カーソルのリセット中に圧縮プロパティが欠落したために失われた圧縮データを修正します。 #16404
  • [修正][ストレージ] トピックの圧縮中に台帳をトリミングするときに、非永続カーソルの位置を移動させないようにしました。 #16403
  • [修正][ストレージ] 問題を事前に修正NonDurableCursors #10667
  • [修正][ストレージ] ManagedCursorImpl #15031 #15067 の競合状態修正のフォローアップ
  • [修正][ストレージ] lastMarkDeleteEntry フィールドの更新時の競合状態を修正 #15031
  • [修正][ストレージ] カーソル削除時のNPEを修正 #12297
  • [改善][ストレージ] マーク削除操作が失敗した場合、カーソルを「ダーティ」としてマークします #14256

プロキシ

  • [修正][プロキシ] client サービス URL を修正 #16894
  • [修正][プロキシ] 未リリースの lookupRequestSemaphore 許可の漏洩を防止 #13812
  • [修正][プロキシ] LookupProxyHandler で不要なブロッキング DNS ルックアップを削除 #15415
  • [修正][プロキシ] 接続の進行中に受信接続が閉じられるときのプロキシ接続リークを修正しました #15366
  • [修正][プロキシ] Pulsar プロキシのポート枯渇と接続の問題を修正 #14078

  • [修正][プロキシ] JDK DNS キャッシュ設定と一致するように Netty DNS リゾルバーを構成し、プロキシで DNS リゾルバー インスタンスを共有します #15219
  • [リファクタリング][プロキシ] プロキシ コードをリファクタリングし、自動読み取りモードに切り替えることで接続の停止を修正します #14713
  • [改善][プロキシ] BrokerServiceURL にスキームがない場合、プロキシの起動に失敗する #14682
  • [改善][プロキシ] Pulsar プロキシから不要な Pulsar Client の使用を削除 #13836

管理者

  • [修正][管理者] validateGlobalNamespaceOwnership ラップ例外の問題を修正しました。 #14269
  • [クリーンアップ][管理者] パラメータの Swagger アノテーションを更新/修正: 権威 #16222
