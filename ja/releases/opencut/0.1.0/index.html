オープンカット v0.1.0

このアップデートは、パフォーマンス、使いやすさ、標準化に焦点を当てたエディター アーキテクチャの大幅な統合を表しています。 「資産とプロパティ」パネル

  • 新しいコンポーザブル Section アーキテクチャを使用してプロパティ パネルを全面的に見直し、厳格なプロパティ項目を置き換えました。
  • 精密な編集をスピードアップするために、「スクラブ」(ドラッグして変更) とインライン数学評価 (1920/2 など) を備えた NumberField 入力を導入しました。
  • カラー管理 frustration を修正するために、EyeDropper サポート、不透明度スライダー、およびマルチフォーマット解析 (16 進数、RGB、HSL) を備えたプログレードの ColorPicker を実装しました。
  • すべてのアセット サイドバー (メディア、ステッカーなど) を標準化し、一貫したスクロールとヘッダー アクションを実現する共有 PanelView レイアウトを使用します。 タイポグラフィ エンジン
  • 重いフォント読み込みメカニズムをカスタムの「Font Atlas」スプライト システムに置き換えました。
  • 理由: 以前は、何百ものフォント プレビューをレンダリングするとブラウザが停止していました。
  • 結果: ネットワーク ウォーターフォールを使用せずに、AVIF スプライトを介して 1000 以上の Google Font プレビューを即時にレンダリングします。
  • 検索機能を備えた仮想化 FontPicker を追加しました ステッカーとシェイプ
  • ステッカー システムを Iconify からプロバイダーベースのアーキテクチャに分離しました。
  • 既存のアイコン ライブラリに加えて、絵文字、国旗、幾何学的形状 (円、四角など) のネイティブ サポートを追加しました。
  • 将来の無限のプロバイダーをサポートするために、すべての ID 形式を provider:value (例: icons:mdi:home、flags:US) に移行しました。 タイムラインとブックマーク
  • ブックマークを単純なタイムスタンプから、メモ、色、期間を含む「リッチ ブックマーク」にアップグレードしました。これにより、ブックマークがシーン計画のための実際の制作ツールに変わります。
  • ドロップ ロジックをコマンド パターンに移動することで、ドラッグ アンド ドロップに関する重要な元に戻す/やり直しの問題を修正しました。アセットの削除は完全に元に戻せるようになりました。
  • スナップ UX の改善: Shift を押し続けると、移動、サイズ変更、スクラブ中のスナップが一時的に無効になり、要素がグリッド ラインに「くっついている」ように感じられる問題が修正されました。 レンダラーとプレビュー
  • 複数行のテキスト、カスタム行の高さ、文字間隔をサポートするためにテキスト ノードのレンダリングを書き直しました。
  • TransformHandles および SnapGuides がプレビュー キャンバスに直接追加され、プロパティ パネルのみに依存せずに直感的な要素操作 (サイズ変更/回転) が可能になりました。
  • すべてのビジュアル要素のブレンド モード (乗算、スクリーン、オーバーレイなど) をレンダリングするための GlobalCompositeOperation サポートを追加しました。 インフラストラクチャー
  • 新しいリッチ ブックマーク オブジェクトとステッカー ID 形式を処理するために、ストレージを v3 から v6 に移行しました。
  • モーダル アクセシビリティと clipboard の貼り付け (Ctrl+V 画像/オーディオをタイムラインに直接) を処理するために、use-focus-lock および use-paste-media フックを作成しました。
  • ダーク モードでのコントラストの問題を修正するために、UI コンポーネントのスタイル (入力、ポップオーバー、コンテキスト メニュー) を標準化しました。

OpenCut v0.1.0

Highlights

  • Much faster font discovery — The new Font Atlas renders 1,000+ Google Font previews from AVIF sprites instead of triggering individual font loads. Combined with a virtualized picker, this removes browser stalls and network waterfalls when browsing large font libraries.

  • More precise, direct canvas editing — Numeric fields now support drag-to-scrub and inline expressions such as 1920/2, while the upgraded color picker adds Hex/RGB/HSL parsing, opacity controls, and EyeDropper support. On-canvas transform handles and snap guides reduce panel switching; holding Shift temporarily bypasses snapping when fine adjustment is needed.

  • Richer text rendering and compositing — Text nodes now support multiple lines, custom line heights, and letter spacing. GlobalCompositeOperation brings blend modes such as Multiply, Screen, and Overlay to all visual elements, expanding creative options without requiring separate compositing workarounds.

  • Bookmarks become production data; asset drops are undoable — Rich bookmarks now store notes, colors, and duration, making them useful for scene planning rather than simple timestamps. Moving drop handling into the Command pattern also fixes critical drag-and-drop Undo/Redo failures, so imported assets can now be safely repositioned or removed through history.

  • Sticker IDs introduce a breaking integration change — Stickers are no longer tied to Iconify, and IDs now use a provider-based format such as icons:mdi:home or flags:US. Native emojis, country flags, and geometric shapes are supported alongside icons; update hard-coded IDs in integrations, presets, and tooling that consume sticker references.

  • Persisted data requires migration validation — Storage advances from schema v3 to v6 to accommodate rich bookmarks and provider-qualified sticker IDs. Back up existing project data and test older projects before rollout; the changelog does not specify backward compatibility or rollback behavior.

This update represents a major consolidation of the editor architecture, focusing on performance, usability, and standardization.

Assets & Properties Panel

  • Overhauled the Properties panel using a new composable Section architecture to replace the rigid property items.
  • Introduced NumberField inputs with "scrubbing" (drag to change) and inline math evaluation (e.g., 1920/2) to speed up precision editing.
  • Implemented a pro-grade ColorPicker with EyeDropper support, opacity sliders, and multi-format parsing (Hex, RGB, HSL) to fix color management frustrations.
  • Standardized all asset sidebars (Media, Stickers, etc.) to use a shared PanelView layout for consistent scrolling and header actions.

Typography Engine

  • Replaced the heavy font loading mechanism with a custom "Font Atlas" sprite system.
  • Why: Rendering hundreds of font previews previously stalled the browser.
  • Result: Instant rendering of 1000+ Google Font previews via AVIF sprites without network waterfalls.
  • Added a virtualized FontPicker with search

Stickers & Shapes

  • Decoupled the sticker system from Iconify to a provider-based architecture.
  • Added native support for Emojis, Country Flags, and Geometric Shapes (Circle, Square, etc.) alongside the existing Icon library.
  • Migrated all ID formats to provider:value (e.g., icons:mdi:home, flags:US) to support infinite future providers.

Timeline & Bookmarks

  • Upgraded Bookmarks from simple timestamps to "Rich Bookmarks" containing notes, colors, and duration. This turns bookmarks into actual production tools for scene planning.
  • Fixed critical Undo/Redo issues with drag-and-drop by moving drop logic to the Command pattern. Dropping assets is now fully undoable.
  • Improved Snapping UX: Holding Shift now temporarily disables snapping during moves, resizes, and scrubbing, fixing the issue where elements felt "stuck" to grid lines.

Renderer & Preview

  • Rewrote Text Node rendering to support multi-line text, custom line heights, and letter spacing.
  • Added TransformHandles and SnapGuides directly to the preview canvas for intuitive element manipulation (resize/rotate) without relying solely on the properties panel.
  • Added GlobalCompositeOperation support to render blend modes (Multiply, Screen, Overlay, etc.) for all visual elements.

Infrastructure

  • Migrated storage from v3 to v6 to handle the new rich bookmark objects and sticker ID formats.
  • Created use-focus-lock and use-paste-media hooks to handle modal accessibility and clipboard pasting (Ctrl+V images/audio directly to timeline).
  • Standardized UI component styling (Inputs, Popovers, Context Menus) to fix contrast issues in Dark Mode.
