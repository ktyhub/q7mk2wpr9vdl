OpenCut v0.2.0

マイナー 公開日2026年3月2日 出典OpenCut-app/OpenCut English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#オープンカットv0.2.0 このリリースでは、多くの改善と修正とともに、モーションとエフェクトの基盤が追加されています。

特徴

  • 時間の経過とともに要素プロパティをアニメーション化するためのキーフレーム アニメーション システム。
  • 全く新しいエフェクトシステム。エフェクトは、clip ごとに適用することも、スタンドアロン要素としてタイムラインに追加することもできます (最初のエフェクト: Blur!)。
  • サイトに changelog ページを追加しました。
  • リップル編集モード。

改善点

  • 新しいテキスト要素のデフォルトで背景が黒ではなくなりました。
  • プレビューの選択範囲のアウトラインが破線になりました。
  • タイムライン上の隣接する clips の間には小さな隙間ができるようになり、選択した clips が常に明確に表示されます。
  • Esc キーを押すと、現在の要素の選択が解除されます。

修正

  • 1 つのタイムライン トラック上で click アンド ドラッグ選択を行うと、下のトラックから項目が誤って選択される可能性がある問題を修正しました。
  • 特定の要素を選択すると、再生開始時に音声がちらついたり途切れたりする場合がありました。スケジューラは、オーディオを失わずにタイミング スリップから回復するようになりました。
  • clip をタイムラインにドラッグして Ctrl+Z を押すと、2 回元に戻す必要がなく、clip と作成されたトラックの両方が 1 ステップで削除されるようになりました。
  • 以前は、プロパティ パネルのいくつかの値が間違った値を示していました。これは修正されました。
  • タイムライン トリム ハンドルが clip の内側ではなく外側に配置されるようになったため、clip の表示領域は開始位置と終了位置を正確に表します。
  • タイムライン上にドラッグされている Clips は、他の clips の下ではなく、その上にレンダリングされるようになりました。
  • 最初からトリム操作を元に戻すと、clip が右に伸びるのではなく、元の位置と長さに正しく復元されるようになりました。
  • タイムライン上で clip のサイズを変更すると、マウスを放したときに選択が解除されます。 clip はサイズ変更後も選択されたままになります。
  • clip のサイズを変更すると、同じトラック上の別の clip を越えて拡張され、重複が発生する可能性があります。サイズ変更は次の clip の端で停止します。
  • clip を別のトラックにドラッグすると、ドロップ時に選択が解除されます。 clip は移動後も選択されたままになります。
  • サイズ変更を終了するか、空のトラック スペース上でマウスをドラッグすると、clip の選択が解除されます。

OpenCut v0.2.0

Highlights

  • Motion and effects foundation — Keyframes animate element properties over time, while effects can be applied per clip or inserted as standalone timeline elements. Blur is the first effect, introducing a new compositing workflow that supports both clip-local and timeline-level processing.

  • Ripple editing — The new ripple mode helps maintain timeline timing when clips are removed or rearranged, reducing the manual work of closing gaps and shifting downstream content.

  • More precise selection and trimming — Marquee selection is now confined to the intended track, trim handles sit outside clips, and pressing Escape deselects the current element. Clips also remain selected after resizing or moving between tracks, making successive edits less disruptive.

  • Safer timeline manipulation and undo — Resizing now stops at the next clip’s edge to prevent overlaps, while undoing a clip insertion removes its newly created track in the same step. Trimming from the start now restores the original position and length when undone, rather than incorrectly stretching the clip rightward.

  • Playback and editing reliability — The audio scheduler now recovers from timing slips that previously caused flicker or dropouts when certain elements were selected. Dragged clips render above other clips, and previously incorrect property-panel values have been corrected.

  • Visual editing improvements — New text elements no longer default to a black background, selected clips have a dashed outline, and small gaps between adjacent clips make selection boundaries clearer.

  • Compatibility — No breaking changes are listed.

This release adds the foundation for motion and effects, alongside many improvements & fixes.

Features

  • Keyframe animation system for animating element properties over time.
  • Entirely new efects system. Effects can be applied per-clip or added as standalone elements on the timeline (with our first effect: Blur!)
  • Added a changelog page to the site.
  • Ripple editing mode.

Improvements

  • New text elements no longer have a black background by default.
  • Selection outline in the preview is now dashed.
  • Adjacent clips on the timeline now have a small gap between them so selected clips are always clearly visible.
  • Press Escape to deselect the current element.

Fixes

  • Fixed an issue where click-and-drag selection on one timeline track could accidentally select items from the track below.
  • Audio could flicker or cut out at the start of playback when certain elements were selected. The scheduler now recovers from timing slips without losing audio.
  • Dragging a clip onto the timeline and pressing Ctrl+Z now removes both the clip and the track it created in one step, instead of requiring two undos.
  • A few values in the properties panel were previously showing incorrect values. This has been fixed.
  • Timeline trim handles now sit outside the clip instead of inside them, so the clip's visible area accurately represents where it starts and ends.
  • Clips being dragged on the timeline now render on top of other clips instead of underneath them.
  • Undoing a trim-from-start operation now correctly restores the clip to its original position and length, instead of stretching it to the right.
  • Resizing a clip on the timeline would deselect it when the mouse was released. The clip now stays selected after a resize.
  • Resizing a clip could extend it past another clip on the same track, causing an overlap. The resize now stops at the next clip's edge.
  • Dragging a clip to a different track would deselect it on drop. The clip stays selected after moving.
  • Finishing a resize or drag with the mouse over empty track space would deselect the clip.
