caveman v4.0.1

パッチ 公開日2026年10月13日 出典JuliusBrussee/caveman English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#穴居人v4.0.1 Caveman 4.0.1 は、4.0.0 の最初の数時間で発生した問題、つまり Windows のアンインストールのバグ、追いつかない同期、OpenCode 2 と Pi の問題を修正します。

ウィンドウ

  • caveman off --all はクロード コードの設定に Caveman Blocks フックを残し、すべての caveman setup が別のコピーを追加しました。ブロック v0.1.0-rc.5 は、そのバイナリを .exe としてインストールし、rc.4 が書き込んだエントリを認識し、それらを次の caveman setup で置き換えます。
  • ネイティブ .exe に転送する npm .cmd シムが再度起動されます。
  • フックの子プロセスでコンソール ウィンドウがフラッシュされなくなりました。

同期

  • caveman sync は、ローカル スパンの大きなバックログをバッチでアップロードします。以前は、16 MiB のインポート上限を超えるストアは、再試行するたびに「リクエスト本文が設定された制限を超えています」というエラーで失敗していました。
  • ExperimentalWarning: SQLite 行はなくなりました。
  • 既知の問題: caveman sync の実践結果部分は依然として「リクエストが拒否されました」と報告します。これは Caveman Cloud のバグであり、Cloud が修正されれば CLI のアップデートは必要ありません。

オープンコード

  • OpenCode 2 では、サブエージェントがセッションごとにモードをリセットし、「穴居人の停止」と /ultracave を元に戻します。サブエージェント セッションはモードに触れなくなりました。
  • 「プロバイダーがルーティングされていません」という警告は、プロバイダーが実際にリクエストを送信する場所を読み取ります。

円周率

  • caveman enable pi が拡張機能を 2 回ロードし、Pi が終了した後の caveman wrap pi 1。
  • モデルをルーティングしても思考レベルがリセットされなくなりました (--thinking high はセッション開始までのみ維持されました)。
  • Pi 1.1+ カスタム メッセージ ターンで動作します。
  • @caveman-ai/pi 0.3.1: npm パッケージが Caveman 4 の構成とポートを読み取るようになりました。

クロード コードとコーデックス

  • 他のフックと同様に、ホストが完全なペイロードを送信しない場合、プロンプト フックは 2 秒後に中止されます。
  • ブロックは CLAUDE_CONFIG_DIR および CODEX_HOME を尊重します。以前は、フックを ~/.claude に書き込んでいました。
  • caveman status は、別のアカウントにサインインした後に「アカウントがオフラインに更新されます」と表示されなくなりました。

小規模な修正

  • プロキシ: 両方の認証ヘッダーで送信された 1 つのキーがそのベアラーを保持します。 Termux で構築されたプロキシは、Caveman 独自のものとして認識されます。
  • メモリ: SQLite 競合時の再試行時間が長くなります。
  • /caveman-compress は、貼り付けたテキストを即興で作成するのではなく、ファイル パスを要求し、ファイルがモデル プロバイダーに送信されると言います。
  • テスト済みのエージェント ピンは、現在の Claude Code、Codex、OpenCode、Gemini、Kilo、および Qwen リリースに移動されました。

バージョン

  • @caveman-ai/cli 4.0.0 → 4.0.1、バイナリ bin-v4.0.0 → bin-v4.0.1、@caveman-ai/pi 0.3.0 → 0.3.1、ブロック v0.1.0-rc.4 → v0.1.0-rc.5。

コンパニオン リリース

  • 署名付きバイナリ、モジュール インデックス、コンテナ: bin-v4.0.1
  • npm CLI: @caveman-ai/cli@4.0.1
  • npm Pi 拡張子: @caveman-ai/pi@0.3.1

caveman v4.0.1

Highlights

  • Windows hook cleanup and native execution — Blocks v0.1.0-rc.5 recognizes hook entries written by rc.4, removes the stale entry during caveman off --all, and replaces rather than duplicates it on the next caveman setup. Upgrade Blocks and rerun setup to clean existing installations; .cmd shims targeting native .exe binaries and hook console flashing are also fixed.
  • Sync can drain large backlogs — caveman sync now batches local spans instead of submitting oversized requests that repeatedly exceeded the 16 MiB import cap. This turns previously stuck uploads into recoverable progress. Practice-findings sync still reports Request rejected; that is a Cloud-side bug, so waiting for the server fix—not updating the CLI—is the appropriate action.
  • OpenCode 2 preserves session modes — Subagent sessions no longer reset modes globally, so stop caveman and /ultracave survive subagent spawning. The “provider is not routed” warning also now identifies the provider actually sending requests, making routing failures easier to diagnose.
  • Pi extension reliability and state handling — Running caveman wrap pi after caveman enable pi no longer loads the extension twice or exits with status 1. Model routing preserves the selected thinking level, Pi 1.1+ custom-message turns are supported, and @caveman-ai/pi 0.3.1 reads Caveman 4’s config and port—upgrade the extension alongside the CLI.
  • Hook timeouts and configuration paths — The prompt hook now gives up after two seconds when a host sends an incomplete payload, matching the other hooks and preventing stalled execution. Blocks honors CLAUDE_CONFIG_DIR and CODEX_HOME instead of always targeting ~/.claude, and caveman status no longer falsely reports “account refresh offline” after switching accounts.
  • Compatibility — No breaking changes are listed in this patch release.

Caveman 4.0.1 fixes what turned up in the first hours of 4.0.0: a Windows uninstall bug, a sync that could never catch up, and problems on OpenCode 2 and Pi.

Windows

  • caveman off --all left the Caveman Blocks hook in Claude Code's settings, and every caveman setup added another copy. Blocks v0.1.0-rc.5 installs its binary as .exe, recognises the entries rc.4 wrote, and replaces them on the next caveman setup.
  • An npm .cmd shim that forwards to a native .exe launches again.
  • Hook child processes no longer flash a console window.

Sync

  • caveman sync uploads a large backlog of local spans in batches. Before, a store over the 16 MiB import cap failed with "Request body exceeds configured limit" on every retry.
  • The ExperimentalWarning: SQLite line is gone.
  • Known issue: the practice-findings part of caveman sync still reports "Request rejected". That is a Caveman Cloud bug and needs no CLI update once Cloud is fixed.

OpenCode

  • On OpenCode 2, a subagent spawn reset the mode for every session, undoing "stop caveman" and /ultracave. Subagent sessions no longer touch the mode.
  • The "provider is not routed" warning reads where a provider actually sends requests.

Pi

  • caveman wrap pi after caveman enable pi loaded the extension twice and Pi exited 1.
  • Routing a model no longer resets the thinking level (--thinking high stayed only until session start).
  • Works with Pi 1.1+ custom-message turns.
  • @caveman-ai/pi 0.3.1: the npm package now reads Caveman 4's config and port.

Claude Code and Codex

  • The prompt hook gives up after 2 seconds when the host sends no complete payload, like the other hooks.
  • Blocks honors CLAUDE_CONFIG_DIR and CODEX_HOME; it used to write the hook into ~/.claude regardless.
  • caveman status no longer says "account refresh offline" after signing in to a different account.

Smaller fixes

  • Proxy: one key sent in both auth headers keeps its bearer; a Termux-built proxy is recognised as Caveman's own.
  • Memory: longer retry on SQLite contention.
  • /caveman-compress asks for a file path instead of improvising on pasted text, and says that the file goes to your model provider.
  • Tested agent pins moved to current Claude Code, Codex, OpenCode, Gemini, Kilo and Qwen releases.

Versions

  • @caveman-ai/cli 4.0.0 → 4.0.1, binaries bin-v4.0.0 → bin-v4.0.1, @caveman-ai/pi 0.3.0 → 0.3.1, Blocks v0.1.0-rc.4 → v0.1.0-rc.5.

Companion releases

  • Signed binaries, module index and container: bin-v4.0.1
  • npm CLI: @caveman-ai/cli@4.0.1
  • npm Pi extension: @caveman-ai/pi@0.3.1
