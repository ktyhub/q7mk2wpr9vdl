#穴居人v3.0.0 #穴居人3.0.0

現在はすべて Apache-2.0 です

エンジン、プロキシ、ブラウズ、MCP サーバー、シュリンク、cavemem Go コア、共有プラットフォームを含むリポジトリ全体には、3.0.0 以降の Apache-2.0 のライセンスが付与されています。ホスト型サービスの制限や変更日はなく、商用ライセンスも必要ありません。フォークしたり、埋め込んだり、会社のために実行したりできます。詳細はLICENSING.mdにあります。 以前のリリースでは、出荷時に付属していたライセンスが保持されます。外部の貢献者が MIT の下で作成したコードは、MIT の下でも引き続き利用可能です (LICENSE-MIT)。

Caveman Learn 自体が実行されます

  • 自動操縦 セッション終了後、Learn はバックグラウンドで、最大 6 時間ごとに低優先度で履歴を再チェックします。セッションを待機させることはなく、caveman learn autopilot off はセッションを停止します。
  • メモリ ドクター クロード コードがロードされない MEMORY.md ノート (クロード コードは最初の 200 行または 25 KB のみを読み取ります)、欠落したファイルを指す @imports、2 つのファイルからロードされた同じルール、および CLAUDE.md の古いパスを検出します。
  • トレンド 独自のセッションから得た前週比の数値。セッションの中央値が使用され、セッションが 5 つ未満の場合は「データが不足しています」というメッセージが表示されます。
  • 内蔵モデルの価格表には、現在のクロードおよび GPT ラインナップが含まれています。数値は、どのフォルダーから実行したかに依存しなくなりました。
  • すべての修正は依然として最初に質問され、再カウントされ、各メッセージが小さくならなかった場合は元に戻されます。

ミドルウェア 1.0 および SDK 1.2

  • @caveman-ai/middleware および caveman-middleware は 1.0.0 で安定しており、SDK 1.2.0 が必要です。
  • アダプターのフェールオープン: Caveman に問題がある場合、リクエストはそのまま通過し、大きな警告が表示されます。
  • プロキシは、テナント ID、Postgres HA ストア、TLS/mTLS、および HA デプロイ マニフェスト (deploy/) を追加します。
  • @caveman-ai/contracts 2.0.0 は、プロトコル 1.1 スキーマおよび OpenAPI を公開します。

テレメトリ

CLI とそのエージェント フックは、ランダムなインストール ID と IP アドレスを使用して使用状況統計を送信します。これはデフォルトでオンになっています。 caveman telemetry off または DO_NOT_TRACK=1 でオフにすると、CI は送信しなくなります。スキル自体は何も送信しません。 SECURITY.md を参照してください。

caveman v3.0.0

Highlights

  • Apache-2.0 across the board — The entire repo (engine, proxy, browse, MCP server, shrink, the cavemem Go core, shared platform) relicenses from 3.0.0, dropping the hosted-service restriction, Change Date, and commercial-license requirement — a green light for embedding or running it inside a company. Two nuances matter: this is forward-only (earlier releases keep their shipped license, and external MIT contributions stay MIT via LICENSE-MIT), and for SDK consumers it's a genuine breaking change — @caveman-ai/sdk / caveman-sdk move from MIT to Apache-2.0, so review your notice/attribution obligations before shipping.

  • Learn runs unattended — caveman learn now re-checks history in the background after each session at low priority, capped at one pass every 6 hours and never blocking a session (caveman learn autopilot off turns it off). The new memory doctor targets the failures that silently degrade context: notes beyond Claude Code's 200-line/25KB read cutoff, @imports pointing at missing files, rules duplicated across files, and stale paths in CLAUDE.md. Trends report median-session week-over-week numbers but return "not enough data" below 5 sessions, and the built-in model price list is now independent of the directory you run from. Fixes still ask first, get re-counted, and roll back if they don't shrink every message.

  • Middleware 1.0 + SDK 1.2 — @caveman-ai/middleware and caveman-middleware are stable at 1.0.0 but require SDK >= 1.2.0, so plan the two as a paired upgrade. Adapters now fail open — a Caveman fault passes your request through untouched with a loud warning instead of failing calls — which makes it far safer to place in the live request path. The proxy adds tenant identity, a Postgres HA store, TLS/mTLS, and deploy/ HA manifests, while @caveman-ai/contracts 2.0.0 publishes protocol 1.1 schemas plus OpenAPI for client generation.

  • Telemetry is opt-out, not opt-in — The CLI and its agent hooks send usage data (random install ID + IP address) on by default starting in 3.0.0. If that's a concern, disable it with caveman telemetry off or DO_NOT_TRACK=1; CI is excluded automatically and the skill by itself sends nothing. Worth checking SECURITY.md before adopting in regulated or privacy-sensitive environments — the default posture changed from prior releases.

  • Upgrading — One command: npx -y github:JuliusBrussee/caveman. Mind the two breaking points together: the SDK license flip (MIT → Apache-2.0) and middleware 1.0.0's hard floor of SDK 1.2.0 — pin and bump SDK + middleware in lockstep to avoid a version mismatch. Note the artifact-tag mismatch: runtime binaries and the proxy image are tagged bin-v2.0.0 while the release itself is v3.0.0.

Caveman 3.0.0

Everything is Apache-2.0 now

The whole repo, including engine, proxy, browse, MCP server, shrink, the cavemem Go core and shared platform, is licensed Apache-2.0 from 3.0.0 onward. There's no hosted-service restriction and no Change Date, and you don't need a commercial license. Fork it, embed it, run it for your company. LICENSING.md has the details.

Earlier releases keep the license they shipped with. Code that outside contributors wrote under MIT stays available under MIT (LICENSE-MIT).

Caveman Learn runs itself

  • Autopilot. After a session ends, Learn re-checks your history in the background at low priority, at most every 6 hours. It never makes a session wait, and caveman learn autopilot off stops it.
  • Memory doctor. It finds MEMORY.md notes Claude Code never loads (Claude Code only reads the first 200 lines or 25KB), @imports pointing at missing files, the same rule loaded from two files, and stale paths in CLAUDE.md.
  • Trends. Week-over-week numbers from your own sessions. They use the median session, and you get "not enough data" when there are fewer than 5 sessions.
  • Built-in model price list, now including the current Claude and GPT lineups. Numbers no longer depend on which folder you run from.
  • Every fix still asks first, gets re-counted, and is undone if it didn't make each message smaller.

Middleware 1.0 and SDK 1.2

  • @caveman-ai/middleware and caveman-middleware are stable at 1.0.0 and need SDK 1.2.0.
  • Adapters fail open: if Caveman has a problem, your request goes through untouched and you get a loud warning.
  • The proxy adds tenant identity, a Postgres HA store, TLS/mTLS and HA deploy manifests (deploy/).
  • @caveman-ai/contracts 2.0.0 publishes the protocol 1.1 schemas and OpenAPI.

Telemetry

The CLI and its agent hooks send usage stats with a random install ID and your IP address. This is on by default. Turn it off with caveman telemetry off or DO_NOT_TRACK=1, and CI never sends. The skill by itself sends nothing. See SECURITY.md.
