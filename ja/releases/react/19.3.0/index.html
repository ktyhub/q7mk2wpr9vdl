react v19.3.0

マイナー 公開日2026年9月9日 出典facebook/react English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#反応するv19.3.0 以下は、すべての新機能、API、およびバグ修正のリストです。 詳細については、React 19.3 リリース投稿 を参照してください。

React の新機能

  • <ViewTransition />: React の View Transition アニメーションを強化するために <ViewTransition /> および addTransitionType API を追加 (@sebmarkbage、@jackpope、@gaearon: #31975、#31987、#31996、 #31999、#32001、#32002、#32028、#32029、#32031、 #32034、#32038、#32041、#32050、#32090、#32105、 #32254、#32379、#32422、#32462、#32540、#32545、 #32585、#32599、#32611、#32612、#32617、#32651、 #32653、#32656、#32664、#32699、#32723、#32734、 #32751、#32752、#32760、#32761、#32764、#32772、 #32790、#32819、#32820、#32822、#32833、#32849、 #33094、#33191、#33200、#33206、#33293、#33330、 #33331、#33332、#33357、#33362、#33433、#33576、 #34374、#34450、#34481、#34500、#34502、#34510、 #34511、#34539、#35567、#35564、#35485、#35380、 #35063、#35060、#34676、#36917、#35337、#35520)
  • フラグメント参照: コンポーザブル プラットフォームの動作をサポートするために <Fragment /> に参照を追加します (@jackpope、@sebmarkbage、@eps1lon、@Dhakshin2007、@chirokas、@teamleaderleo、@fallintoplace: #32465、#32613、 #32619、#32654、#32660、#32682、#32722、#32813、 #32814、#33056、#33058、#33093、#34069、#34103、 #34544、#34545、#37062、#37061、#37060、#36047、 #36010、#35642、#35641、#35637、#35630、#34935、 #37457、#37408、#37326、#37251、#37171、#37169、 #37168、#37167、#37166、#37165、#37164、#37163、 #37162、#37161、#37160、#37125、#37063)

新しい React DOM 機能

  • browser(): サーバー レンダリング中に使用可能なエラーを返し、ブラウザーで解決する新しい react-dom API。 <Suspense> 境界内の use(browser()) は、回復可能なエラーを報告せずに、サブツリーをブラウザー専用としてマークします (@gnoff: #37143、#37241)
    • サブツリーがブラウザに従う場合を監視するための onBrowserBailout オプションを react-dom/server API に追加しました (@goff #37193)

注目すべき変更点

  • Trusted タイプ API 統合を有効にする (@rickhanlonii #35816)
  • トランジションは、単一のレンダリングに絡み合うのではなく、独立してレンダリングされるようになりました。そのため、遅いトランジションによって無関係なトランジションが滞ることはなくなりました (@acdlite #37290)
  • 条件付きで use() を呼び出すことでコンポーネントがブロック解除されたように見える場合の DEV のみの警告を追加しました (@hoxyq、@eps1lon: #37104、#37203、#37491)
