appsmith v2.7.0

マイナー 公開日2026年11月12日 出典appsmithorg/appsmith English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アプリスミスv2.7.0

⚠️ アップグレードに関する重要な注意事項

  • Helm チャート: いくつかの probes キーを設定すると、設定しなかったキーには新しいデフォルト (10 秒の期間、5 秒のタイムアウト) が適用されます。 failureThreshold を古い 60 年代にチューニングした場合は、periodSeconds: 60 も設定します。正の整数ではないプローブ値は、helm install および helm upgrade で失敗するようになりました。 "5" などの引用符で囲まれた番号は引き続き機能します。 (#42571)
  • パラメータ値にドットが含まれている場合でも、存在しないページ名への navigateTo は「有効な URL またはページ名を入力してください」と失敗するようになりました。以前は、名前が https://OldPage?file=report.pdf などの Web アドレスとして開かれていました。ドット付きパラメータを持つ intranet などの 1 単語のホストも失敗するようになりました。代わりに完全な URL を使用してください。 (#42513)

🔐 セキュリティ

  • 報告された脆弱性に対処するためにバンドルされた依存関係を更新しました。 (#42502)
  • アプリのカスタム JS ライブラリを読み取るには、そのアプリへの読み取りアクセスが必要になりました。 (#42431)
  • アプリケーションをフォーク可能にする をオンにするには、アプリのエクスポート権限が必要になりました。編集アクセス権を持つユーザーは、これをオフにして他の変更を加えることができます。 (#42411)
  • S3 互換データソースと DynamoDB データソースは、REST、GraphQL、Elasticsearch、Redis、SMTP をすでにカバーしている制限付きホスト ポリシーに従うようになりました。エンドポイントホストがブロックされているデータソースは、Host not allowed. (#42527) で保存、テスト、または実行に失敗します。

🛠️ 信頼性

  • Git に接続されたアプリを削除すると、アプリが削除されるとすぐに元に戻ります。その後、ローカル リポジトリのクリーンアップが実行されるため、ディスクが遅いために削除がタイムアウトになり、アプリ カードが所定の位置に残されることがなくなりました。 (#42519)
  • MCP read_pages は、すべてのページに対して layoutId を返します。並列ページ読み取りはトークン チェックによって拒否されなくなり、失敗した読み取りは 1 回再試行され、それでも失敗するページはその理由を報告します。 (#42360、#42529)
  • MCP は、壊れた、または間違った結果をもたらす入力を拒否します。例: wire_event 呼び出し引数の不均衡な中括弧、レイアウト ツールの別のアプリのページ、SQL キーワードのような名前の列の構造化 SQL フィルター。 (#42536、#42537)
  • エージェントがページを読み取った後にページが変更された場合、MCP レイアウトの更新は拒否されます。 (#42538)

✨ 新機能と機能強化

  • 表の自動高さ: 表の 高さ を 自動高さ (または 制限付き自動高さ) に設定し、ページごとの行数を選択します。表はそれらの行に合わせて拡大され、表の代わりにページがスクロールします。既存のテーブルは 固定のままです。 (#42489、#42585)
  • [アプリ設定] → [ナビゲーション] には、共有を表示 と すべてのアプリを表示 の切り替えがあり、公開されたアプリでこれらのボタンを非表示にします。どちらもデフォルトでオンになっています。共有権限は変更されません。 (#42487)
  • ページのエクスポート (ページ メニュー → エクスポート) には、JS オブジェクト、データベース、クエリ、カスタム ライブラリのすべてのセクションで すべて選択 があります。 (#42453)
  • ボタン グループのボタンには、ボタン ウィジェットと同様にツールチップを表示できます。 (#42583)
  • JSON フォームには、[スタイル] → [色] で タイトルのフォントの色 設定があります。 (#42565)
  • MCP 構造化 SQL は、coalesce を使用して NULL 列のフォールバック値を表示できます。 (#42497)
  • MCP 構造化 SQL は、having を使用して集約グループをフィルタリングできます。 (#42503)
  • MCP 構造化 SQL は、PostgreSQL で区切り文字で区切られた列を分割し、各項目をカウントできます。 (#42504)
  • MCP get_action は、エディターで変更した人がいない限り、MCP が作成したクエリの SQL を返します。 (#42505)
  • 新しい MCP ツール set_page_visibility は、ページを非表示または表示します。ホームページを非表示にすることはできません。 (#42506)
  • MCP ナビゲート イベントは、選択された行の ID などの URL パラメータを渡すことができます。 (#42507)
  • ページまたはクエリの削除と同様に、MCP を介してウィジェットを削除するにはユーザーの承認 (prepare_remove_widgets、confirm_remove_widgets) が必要になりました。 (#42509)
  • MCP JS オブジェクトは、行を並べ替え、切り取り、合計、平均、グループ化し、日付を日、週、月ごとにバケット化できます。 (#42511)
  • MCP は、条件付きフォームを構築できます。これは、選択、日付の計算、あるケースでは表示または必須のフィールド、フォームが有効になるまで無効になる送信ボタン、およびサインインしているユーザーの名前または電子メールに依存するデフォルトと制限です。 (#42540)
  • MCPはエディタで書かれたJSオブジェクトを読み込むことができます。承認が設定されている場合は、ユーザーの承認後に承認を置き換えることができます。 (#42538)
  • MCP は、JS オブジェクトを読み取り可能なフォーマットされたコードとして書き込みます。 (#42549)
  • MCP 構造化クエリは、Oracle 上で実行可能な本体を生成し、MongoDB クエリで厳密な値を使用します。 (#42538)

🎨 UI とウィジェットの改善

  • テーブル CSV および Excel のダウンロードでは、生の HTML ではなく、HTML 列のプレーン テキストが書き込まれます。 (#42557)
  • 表セルのアイコン ボタン、メニュー ボタン、およびビデオ コントロールが行の高さに適合するため、ページ分割された表で最後の行に到達するためにスクロールバーが必要なくなりました。 (#42570)
  • テーブルの無限スクロールをオフにしても、行の追加を許可、検索、フィルター、並べ替えはオンになりません。オンにするまでオフのままです。 (#42573)
  • テーブルの [保存/破棄] 列の [無効] フィールドに、完全なバインドが再び表示されます。編集しても、すべての行で保存/破棄が有効になりません。 (#42589)
  • JSON フォームをリセットすると、空の配列フィールドは空のままになるため、フォームは有効なままになります。 (#42226)
  • JSON フォームの必須日付フィールドは、他のフィールドと同様に、ユーザーがタッチした後にのみエラーが表示されます。 (#42514)
  • ワークスペース ロゴ ピッカーは、サーバーが常に拒否した SVG を提供しなくなりました。 JPG ファイルを選択できるようになりました。 (#42594)
  • エディターは、廃止された Appsmith AI データソースとそのクエリを非表示にします。サービスは 2026 年 9 月 30 日に停止されました。Ask AI には影響はありません。 (#42559)

🔧 Git、デプロイメント、構成

  • Helm チャートのヘルス プローブは、5 秒のタイムアウトで 10 秒ごとに実行されるようになりました。 Startup では 600 秒間起動でき、liveness では 180 秒の障害後にコンテナーが再起動され、readiness では 30 秒後にポッドが準備完了としてマークされます。管理設定を保存してサーバーを再起動しても、コンテナーが強制終了されなくなりました。 (#42571)
  • バックアップでは、APPSMITH_BACKUP_EXCLUDE_COLLECTIONS (カンマ区切り) にリストされている MongoDB コレクションをスキップできます。 (#42581)
  • サーバーは、期限切れまたは取り消されたキーなど、MCP トークンを拒否した理由をログに記録します。秘密をログに記録することはありません。 (#42593)

appsmith v2.7.0

Highlights

  • Breaking: navigateTo semantics — (#42513) A page name that no longer exists now fails with "Enter a valid URL or page name" instead of being opened as a web address (https://OldPage?file=report.pdf); one-word hosts like intranet with a dotted parameter also fail. Migrate by replacing such calls with full URLs before upgrading. Worth the upgrade for everyone, but this needs an app audit if you relied on implicit name-to-URL fallback.

  • Breaking: Helm health probes — (#42571) Probes now run every 10 s with a 5 s timeout, startup allows 600 s, liveness restarts after 180 s, readiness unreadies after 30 s, and saving admin settings no longer kills the container. If you previously tuned failureThreshold for the old 60 s period, also set periodSeconds: 60; non-positive-integer probe values now fail helm install/helm upgrade (quoted numbers like "5" still work). Helm operators should read this carefully before upgrading.

  • Security hardening — (#42502, #42431, #42411, #42527) Bundled dependencies are updated for a reported vulnerability, reading an app's custom JS libraries now needs read access to that app, enabling Make application forkable now needs export permission (users with edit access can still disable it), and S3-compatible/DynamoDB datasources now obey the restricted host policy with Host not allowed. on blocked endpoints. This alone justifies upgrading for most deployments; expect possible permission/datasource adjustments.

  • MCP and reliability gains — (#42360, #42529, #42536, #42537, #42538, #42509, #42540, #42519) read_pages returns a layoutId, parallel reads/retries work, invalid inputs are rejected, and stale layout updates are refused; widget removal now needs prepare_remove_widgets/confirm_remove_widgets approval; new capabilities include set_page_visibility, coalesce, having, conditional forms and more; Git-connected app deletes return immediately. Strong upgrade case for MCP/agent users.

  • Enhancements worth noting, safe to skip if unaffected — (#42489, #42585, #42487, #42581, #42559) Table Auto Height, new Show share/Show all apps navigation toggles, APPSMITH_BACKUP_EXCLUDE_COLLECTIONS for backup exclusions, and hiding the retired Appsmith AI datasource (service ended September 30, 2026; Ask AI unaffected). Teams with no MCP usage and no reliance on the two breaking behaviors can defer, but the security fixes make upgrading the better default.

⚠️ Important Upgrade Notes

  • Helm chart: if you set some probes keys, the keys you did not set now take the new defaults (10 s period, 5 s timeout). If you tuned failureThreshold for the old 60 s period, also set periodSeconds: 60. Probe values that are not positive integers now fail helm install and helm upgrade. Quoted numbers such as "5" still work. (#42571)
  • navigateTo to a page name that no longer exists now fails with "Enter a valid URL or page name", even when a parameter value contains a dot. Before, it opened the name as a web address, such as https://OldPage?file=report.pdf. A one-word host such as intranet with a dotted parameter now fails too. Use a full URL instead. (#42513)

🔐 Security

  • Updated bundled dependencies to address a reported vulnerability. (#42502)
  • Reading an app's custom JS libraries now requires read access to that app. (#42431)
  • Turning on Make application forkable now requires export permission on the app. Users with edit access can still turn it off and make other changes. (#42411)
  • S3-compatible and DynamoDB datasources now follow the restricted host policy that already covers REST, GraphQL, Elasticsearch, Redis and SMTP. A datasource whose endpoint host is blocked fails to save, test or run with Host not allowed. (#42527)

🛠️ Reliability

  • Deleting a Git-connected app returns as soon as the app is removed. Local repository cleanup runs afterwards, so a slow disk no longer makes the delete time out and leave the app card in place. (#42519)
  • MCP read_pages returns a layoutId for every page. Parallel page reads are no longer refused by the token check, a failed read is retried once, and a page that still fails reports why. (#42360, #42529)
  • MCP refuses inputs that used to give broken or wrong results. Examples: unbalanced braces in wire_event call arguments, a page from another app in layout tools, and a structured SQL filter on a column named like a SQL keyword. (#42536, #42537)
  • MCP layout updates are refused when the page changed after the agent read it. (#42538)

✨ New Features & Enhancements

  • Table auto height: set the Table's Height to Auto Height (or Auto Height with limits) and choose Rows per page. The table grows to fit those rows and the page scrolls instead of the table. Existing tables stay Fixed. (#42489, #42585)
  • App Settings → Navigation has Show share and Show all apps toggles to hide those buttons in the published app. Both are on by default. Sharing permissions do not change. (#42487)
  • Page export (page menu → Export) has Select All in every section: JS objects, Databases, Queries and Custom libraries. (#42453)
  • Button Group buttons can show a tooltip, as the Button widget does. (#42583)
  • JSON Form has a Title font color setting under Style → Color. (#42565)
  • MCP structured SQL can show a fallback value for a NULL column with coalesce. (#42497)
  • MCP structured SQL can filter aggregated groups with having. (#42503)
  • MCP structured SQL can split a delimited column and count each item, on PostgreSQL. (#42504)
  • MCP get_action returns the SQL of a query that MCP wrote, as long as nobody changed it in the editor. (#42505)
  • New MCP tool set_page_visibility hides or shows a page. The home page cannot be hidden. (#42506)
  • MCP navigate events can pass URL parameters, such as the id of the selected row. (#42507)
  • Removing widgets through MCP now needs the user's approval (prepare_remove_widgets, confirm_remove_widgets), as deleting a page or query already does. (#42509)
  • MCP JS objects can sort, cut, sum, average and group rows, and bucket dates by day, week or month. (#42511)
  • MCP can build conditional forms: defaults and limits that depend on a choice, date math, fields shown or required in one case, a submit button disabled until the form is valid, and the signed-in user's name or email. (#42540)
  • MCP can read JS objects written in the editor. Where approval is set up, it can replace them after the user approves. (#42538)
  • MCP writes JS objects as readable, formatted code. (#42549)
  • MCP structured queries produce a runnable body on Oracle and use strict values in MongoDB queries. (#42538)

🎨 UI & Widget Improvements

  • Table CSV and Excel downloads write plain text for HTML columns, not raw HTML. (#42557)
  • Icon Button, Menu Button and Video controls in Table cells fit the row height, so paginated tables no longer need a scrollbar to reach the last row. (#42570)
  • Turning off infinite scroll in a Table no longer turns on Allow adding a row, search, filters and sort. They stay off until you turn them on. (#42573)
  • The Table Save/Discard column Disabled field shows its full binding again. Editing it no longer enables Save/Discard on every row. (#42589)
  • Resetting a JSON Form keeps an empty Array field empty, so the form stays valid. (#42226)
  • A required date field in JSON Form shows its error only after the user touches it, like other fields. (#42514)
  • The workspace logo picker no longer offers SVG, which the server always rejected. JPG files can now be picked. (#42594)
  • The editor hides the retired Appsmith AI datasource and its queries. The service stopped on September 30, 2026. Ask AI is not affected. (#42559)

🔧 Git, Deployment & Configuration

  • Helm chart health probes now run every 10 s with a 5 s timeout. Startup allows 600 s to boot, liveness restarts the container after 180 s of failure, and readiness marks the pod unready after 30 s. Saving admin settings that restart the server no longer gets the container killed. (#42571)
  • Backups can skip MongoDB collections listed in APPSMITH_BACKUP_EXCLUDE_COLLECTIONS (comma-separated). (#42581)
  • The server logs why it refuses an MCP token, such as an expired or revoked key. It never logs the secret. (#42593)
