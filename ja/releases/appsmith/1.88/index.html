appsmith v1.88

Highlights

  • AWS Lambda plugin gains version/alias discovery — You can now list function versions and aliases from the Lambda plugin (PR #41263). This matters if you pin Lambda invocations to a specific $LATEST vs. a numbered version or alias; previously you had to hardcode the target, so this makes versioned deployments practical without breaking existing config.

  • OAuth2 compatibility with Spring Boot 3.3.13+ — The hd parameter is now forced to a single value (PR #41271). This is the one item with a migration flavor: if you run a custom auth stack on Spring Boot 3.3.13+, this avoids failures caused by multi-valued hd; if you're on an older Spring Boot, the change is harmless. No explicit breaking change or manual migration step is documented.

  • Deployment and storage infrastructure hardening — Several self-hosting pain points are fixed: recreating DP no longer fails under network restrictions (PR #41264), hardcoded Bitnami images in the init container definition are corrected (PR #41257), a Content-MD5 header is added for Object Lock compliance (PR #41241), and the ad-hoc image generation build step is fixed (PR #41262). These are the strongest reasons to upgrade for anyone running their own instance with object-lock/bucket policies or restricted egress.

  • UI polish and clarity changes — Applications and workspaces now sort alphabetically (PR #41253), tab navigation in Fixed Layout no longer breaks from event-listener timing (PR #41256), infinite scroll no longer interferes with the DSL (PR #41217), and a clearer account-suspension message appears when rate limiting triggers (PR #41254). Log cleanup (PR #41275) is maintenance-only. Mostly low-risk quality-of-life improvements.

  • Upgrade recommendation — This is a genuine feature+fix release, not a re-tag or metadata-only update, and no breaking changes or required migration steps are called out. Self-hosters hitting the DP/Bitnami/Object Lock issues or teams using versioned Lambda functions should upgrade; everyone else can reasonably skip to the next release, since the remaining changes are incremental polish rather than capability changes.

Features

  • Added support for listing function versions and aliases in the AWS Lambda Plugin. (PR #41263)
  • Backend enhancement: Applications and workspaces are now sorted alphabetically. (PR #41253)
  • Added an account suspension error message to improve clarity when rate limiting is triggered. (PR #41254)

Fixes

  • Cleaned up logs for better maintenance. (PR #41275)
  • Fixed an issue where recreating DP failed due to network restrictions. (PR #41264)
  • OAuth2: Ensured single-valued hd parameter for compatibility with Spring Boot 3.3.13+. (PR #41271)
  • Fixed tab navigation issues in Fixed Layout caused by event listener timing. (PR #41256)
  • Updated logic to avoid interfering with DSL when infinite scroll is enabled. (PR #41217)
  • Fixed ad-hoc image generation step during build. (PR #41262)
  • Corrected Bitnami image hardcoding in init container definition. (PR #41257)
  • Added Content-MD5 header for Object Lock compliance. (PR #41241)
