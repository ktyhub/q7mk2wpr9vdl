#アプリスミスv2.2

特徴

  • アプリケーション間で API、クエリ、および JavaScript オブジェクトをコピーするためのサポートを追加しました。 (#41919) (#41920)
  • Enterprise Edition で以前に使用されていたデータベースに接続すると、Community Edition が起動できないようにしました。 (#41906)

修正

  • 内部 Appsmith Redis インスタンスへの Redis データソース接続をブロックしました。 (GHSA-qhfj-g87x-m39w) (#41921)
  • 広すぎる minimatch 解像度を削除することで Storybook の問題を修正し、glob v10/v11 が GLOBSTAR を正しくサポートできるようにしました。 (#41949)
  • リリース イメージ スキャン中に特定された 17 件のセキュリティ脆弱性に対処するために、依存関係の更新のバッチを適用しました。 (#41947)
  • 複数の CVE に対処するために、Spring Boot を 3.5.14 に、Netty を 4.1.135 にアップグレードしました。 (#41928)
  • デフォルト ブランチの欠落とSSH キーの構成ミスを区別することにより、Git エラー処理が改善されました。 (#41940)
  • 1 件の追加のセキュリティ脆弱性に対処するために、依存関係の更新を適用しました。 (#41942)
  • クローンページが 一意のウィジェット ID を生成し、ウィジェットの競合を防止するようにしました。 (#41762)
  • 15 件の追加のセキュリティ脆弱性に対処するために、依存関係の更新を適用しました。 (#41913)
  • CVE-2026-48038 に対処するために、joi を 18.2.1 にアップグレードしました。 (GHSA-q7cg-457f-vx79) (#41891)
  • 部分エクスポート中にページが正しいアプリケーションに属していることを確認する検証を追加しました。 (GHSA-9xfc-9f97-x524) (#41832)
  • PropertyPaneTitle F2 アサーションを waitFor でラップすることにより、テストの安定性が向上しました。 (#41888)
  • SSO ログイン リダイレクトが、最初に要求されたアプリケーションではなく /applications に到達する問題を修正しました。 (#41820)
  • セキュリティを向上させるために、innerHTML および dangerouslySetInnerHTML をより安全な代替品に置き換えました。 (#41836)

重大な変更

  • 公開されたイメージ内のハードコードされた IN_DOCKER 環境変数は削除されました。これは、ローカル開発でローカル HTTP および Redis データソースにアクセスするために使用できる新しい環境変数 APPSMITH_DISABLE_SSRF_FILTER に置き換えられました。 (#41921)

appsmith v2.2

Highlights

  • Breaking — SSRF controls replace IN_DOCKER — The hardcoded IN_DOCKER variable is removed from published images; use APPSMITH_DISABLE_SSRF_FILTER instead to reach local HTTP/Redis datasources in development (#41921). Audit any local dev scripts or Compose overrides relying on IN_DOCKER, because those datasource connections will now fail closed. This pairs with a new block on Redis datasources targeting Appsmith's own internal Redis instance (GHSA-qhfj-g87x-m39w, #41921): the release is intentionally shutting SSRF escape routes, so "loopback" datasource configs that used to work should be expected to break.

  • Cross-application copy/paste lands — APIs, queries, and JS objects can now be copied between applications (#41919, #41920). This is a genuine productivity win for teams consolidating or templating workspaces, but copied artifacts may carry hardcoded datasource bindings or name collisions — re-check references in the target app rather than assuming a clean paste.

  • Large security dependency sweep — Three update batches close 33+ vulnerabilities (#41947, #41942, #41913), alongside targeted bumps of Spring Boot to 3.5.14 and Netty to 4.1.135 (#41928) and joi to 18.2.1 for CVE-2026-48038 (#41891). For self-hosters this is the strongest reason to pull the new image. XSS surface is also reduced by replacing innerHTML/dangerouslySetInnerHTML with safer alternatives (#41836).

  • CE/EE database guard — Community Edition now refuses to start against a database previously used by Enterprise Edition (#41906). Preventive against license/feature-state corruption, but it removes the "just downgrade the image on the same volume" path — export your data or provision a clean DB before moving EE→CE.

  • Git, export, and clone correctness — Git errors now distinguish a missing default branch from an SSH key misconfiguration (#41940), which should cut debugging time on broken remotes. Partial exports now validate that pages belong to the requested application (GHSA-9xfc-9f97-x524, #41832), and cloned pages get unique widget IDs (#41762) — both close silent cross-project corruption paths worth verifying if you rely on export/import or page duplication.

  • Smaller usability fixes — SSO redirects now return to the originally requested application instead of dumping users on /applications (#41820), and Storybook builds are repaired by dropping an over-broad minimatch resolution so glob v10/v11 handles GLOBSTAR correctly (#41949).

Features

  • Added support for copying APIs, queries, and JavaScript objects between applications. (#41919) (#41920)
  • Prevented Community Edition from starting when connected to a database previously used by Enterprise Edition. (#41906)

Fixes

  • Blocked Redis datasource connections to the internal Appsmith Redis instance. (GHSA-qhfj-g87x-m39w) (#41921)
  • Fixed Storybook issues by removing an overly broad minimatch resolution, allowing glob v10/v11 to correctly support GLOBSTAR. (#41949)
  • Applied a batch of dependency updates to address 17 security vulnerabilities identified during release image scans. (#41947)
  • Upgraded Spring Boot to 3.5.14 and Netty to 4.1.135 to address multiple CVEs. (#41928)
  • Improved Git error handling by distinguishing a missing default branch from an SSH key misconfiguration. (#41940)
  • Applied dependency updates to address 1 additional security vulnerability. (#41942)
  • Ensured cloned pages generate unique widget IDs, preventing widget conflicts. (#41762)
  • Applied dependency updates to address 15 additional security vulnerabilities. (#41913)
  • Upgraded joi to 18.2.1 to address CVE-2026-48038. (GHSA-q7cg-457f-vx79) (#41891)
  • Added validation to ensure pages belong to the correct application during partial exports. (GHSA-9xfc-9f97-x524) (#41832)
  • Improved test stability by wrapping the PropertyPaneTitle F2 assertion in waitFor. (#41888)
  • Fixed an issue where SSO login redirects landed on /applications instead of the originally requested application. (#41820)
  • Replaced innerHTML and dangerouslySetInnerHTML with safer alternatives to improve security. (#41836)

Breaking changes

  • The hardcoded IN_DOCKER environment variable in the published image has been removed. It has been replaced with a new environment variable APPSMITH_DISABLE_SSRF_FILTER which can be used in local development to reach local HTTP and Redis datasources. (#41921)
