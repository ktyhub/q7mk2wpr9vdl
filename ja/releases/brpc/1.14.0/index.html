特徴:

  • MultiDimension API のジェネリックスをサポート (#3026)、@chenBright により
  • @yanglimingcn による rpc チェックサム (#2967) のサポート
  • RDMA ポーリング モード (#2920) をサポート (@yanglimingcn による)
  • 最初に epoll bthread ディールをサポート (#2819)、@zhengJade による

バグ修正:

  • バグ修正: ランタイム拡張ブロック プール (#2965)、@yanglimingcn による
  • バグ修正: bthread_worker_usage が bthread_worker_count を超える可能性がありました (#3009)、@chenBright により
  • バグ修正: SignalTrace モードにはメモリとデッドロックの問題 (#3019)、@chenBright による
  • バグ修正: Butex が ObjectPool に返されると use-after-poison がトリガーされる (#3012)、@chenBright により
  • バグ修正: save_series フラグが false の場合、LatencyRecorder::expose CHECK が失敗する (#3022)、@chenBright により
  • grpcプロトコルが認証と互換性がないバグを修正(問題:#3001) (#3002)、@Paragrf
  • バグ修正: ヘルスチェックのないソケットは異常にリサイクルされる (#3010)、@chenBright により
  • 修正: バインドと接続のグローバル名前空間の指定 (#3007)、@zhoukangsheng による
  • シャットダウン中に TimerThread がハングする原因となる競合状態を修正 (#2986)、@gitccl により
  • StringSplitter の潜在的な無効なメモリ アクセスを修正 (#2996)、@gitccl により
  • @CodeZHXS による bthread タスク トレーサのデッドロック バグ (#2988) を修正
  • thrift メッセージの開始 (#2984) の誤った seq id 設定を修正 (@chenBright による)
  • <cstdint> インクルードの欠落による GCC 13 での UT コンパイル エラーを修正 (#2979)、@XueSongTap により
  • @chenBright による thrift (#2975) の無効な URL を修正
  • bazel 経由でビルドするときに x86_64 CPU でデフォルトでリンクされる libunwind を修正 (#2973)、@tongke6 により

強化:

  • libibverbs をロードするためのフォールバック コードを最適化 (#3008)、@zhangqiongyu による
  • @wwbmmm による redis 割り当てサイズ制限 (#3035) を追加
  • Opt ログ関数名 (#3017)、@chenBright 作成
  • 単体テストを macOS 上で実行可能にする (#3018)、@gitccl により
  • rwlock.h にインクルード ガードを追加 (#3005)、@xiongjiwei により
  • 一貫性のあるハッシュのサポート サーバー タグ (#2994)、@egolearner による
  • 移動を無効にするマクロをサポート (#2989)、@chenBright による
  • @gitccl による DoublyBufferedData (#2981) のshared_ptr 割り当てを最適化します。

brpc 1.14.0

Highlights

  • New feature surface — Adds generics for MultiDimension APIs (#3026), rpc checksum (#2967), RDMA polling mode (#2920), and epoll bthread-deal-first handling (#2819). These provide additional correctness, performance, and deployment options, although the changelog does not document their defaults or enablement details.

  • Memory safety and concurrency — Fixes use-after-poison when Butex returns to ObjectPool (#3012), invalid memory access in StringSplitter (#2996), SignalTrace memory/deadlock issues (#3019), bthread task tracer deadlocks (#2988), and TimerThread shutdown hangs (#2986). Long-running, highly concurrent, or debug-traced services have strong reasons to upgrade.

  • Protocol correctness — Repairs gRPC authentication incompatibility (issue #3001, #3002), incorrect Thrift sequence IDs and invalid Thrift URLs (#2984, #2975), and abnormal recycling of sockets without health checks (#3010). Deployments using gRPC authentication, Thrift, or disabled health checks should prioritize this release.

  • Resource limits and build hygiene — Corrects cases where bthread_worker_usage exceeds bthread_worker_count (#3009), fixes LatencyRecorder::expose CHECK failures when save_series is false (#3022), and adds a Redis allocation-size limit (#3035). Large Redis-value workloads should verify the new limit, whose threshold is not stated here; GCC 13, Bazel libunwind, and macOS test fixes mainly benefit packagers and CI.

  • Upgrade recommendation — No explicit breaking changes or migration steps are listed; this is primarily an additive feature and bug-fix release. Upgrade if you use the affected protocols, RDMA, Redis, or reliability-sensitive execution paths; otherwise, a stable deployment that avoids these areas can reasonably skip it.

  • Support generics for MultiDimension APIs (#3026), by @chenBright

  • Support RDMA polling mode (#2920), by @yanglimingcn
  • Support epoll bthread deal first (#2819), by @zhengJade

Bug Fix:

  • Bugfix: runtime extend block pool (#2965), by @yanglimingcn
  • Bugfix: bthread_worker_usage could exceed bthread_worker_count (#3009), by @chenBright
  • Bugfix: SignalTrace mode has memory and deadlock issues (#3019), by @chenBright
  • Bugfix: Butex returned to ObjectPool triggers use-after-poison (#3012), by @chenBright
  • Bugfix: LatencyRecorder::expose CHECK fails when save_series flag is false (#3022), by @chenBright
  • Fix the bug that the grpc protocol is incompatible with authentication(issue:#3001) (#3002), by @Paragrf
  • Bugfix: Socket without health check would be abnormally recycled (#3010), by @chenBright
  • Fix: Specifying the global namespace for bind and connect (#3007), by @zhoukangsheng
  • Fix race condition that causes TimerThread to hang during shutdown (#2986), by @gitccl
  • Fix potential invalid memory access in StringSplitter (#2996), by @gitccl
  • Fix bthread task tracer deadlock bug (#2988), by @CodeZHXS
  • Fix incorrect seq id setting in thrift message begin (#2984), by @chenBright
  • Fix UT compilation errors with GCC 13 due to missing <cstdint> includes (#2979), by @XueSongTap
  • Fix invalid url of thrift (#2975), by @chenBright
  • Fix libunwind linked by default on x86_64 cpu when building via bazel (#2973), by @tongke6

Enhancement:

  • Optimize the fallback code for loading libibverbs (#3008), by @zhangqiongyu
  • Add redis allocation size limit (#3035), by @wwbmmm
  • Opt log function name (#3017), by @chenBright
  • Make unit tests runnable on macOS (#3018), by @gitccl
  • Add include guard in rwlock.h (#3005), by @xiongjiwei
  • Consistent hashing support server tag (#2994), by @egolearner
  • Support macro to disable move (#2989), by @chenBright
  • Optimize shared_ptr assignment in DoublyBufferedData (#2981), by @gitccl
