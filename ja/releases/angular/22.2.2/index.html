angular v22.2.2

Highlights

  • Signal Forms reliability — Four targeted fixes harden the signal-forms path: setUpValidators no longer crashes when a control is missing, orphaned fields no longer get class bindings, control bindings are compared with Object.is (correct handling of NaN/-0/object identity rather than ===-style equality), and a pending debounced value is now written when its control is destroyed instead of being lost. If you've adopted signal forms, these remove real crash/data-loss edges in validation, binding updates, and teardown; if you're still on classic forms, this bullet doesn't affect you.

  • Core runtime correctness — afterRenderEffect sequences registered while hooks run are now deferred correctly, avoiding re-entrancy surprises in post-render work; translation strings have reserved characters stripped so locales with special chars don't break; and the onError handler is now wrapped in untrack, preventing "signal write inside a computed/effect" exceptions when an error handler writes to a signal. The onError fix is the one most likely to matter in production — apps with custom error handlers that update signal state should upgrade.

  • Compiler / template correctness — A cluster of namespace-aware fixes: ::ng-deep detection state no longer leaks between rules, directives now match <ng-template> nested in various namespaces, namespaced root nodes of control-flow blocks are matched against ng-content selectors, script elements are stripped regardless of namespace, and @let declarations are ignored in the control-flow content-projection diagnostic (cutting false positives). Entity resolution also avoids prototype lookups and missing-directive extended checks were optimized in compiler-cli. This matters mainly for templates using SVG/MathML or custom namespaces, ng-content with control flow, and ::ng-deep — and it trims some build-time overhead.

  • Router and tooling — Router gains three fixes: protocol-relative URLs now have a serialization fallback, the navigate-event abort listener is removed once it fires (no stale listeners), and internal state is reset on an error-handler redirect after state commit. The language service also adds strictUnclaimedEventNames to the angularCompilerOptions schema, so that flag is now recognized instead of flagged. Relevant if you use custom URL serializers, error-handler-driven redirects, or strict template event-name checking; otherwise low impact.

  • Upgrade guidance — This is a backward-compatible patch release: all 22 entries are fixes plus one perf tweak, with no breaking changes and no migration steps. Worth upgrading if you're on 22.2.x and hit any of the specific issues above (especially signal forms, onError signal writes, or namespaced templates); safe to skip if you're on an unaffected app and not using those features. Nothing here is a re-tag or metadata-only release — there are real code changes, but no new features or API surface.
