angular v22.1.2

Highlights

  • Template compiler correctness — Chained optional navigation now has correct expression generation and SafePropertyRead symbol resolution, fixing nested ?. handling in templates. i18n hasOwnProperty checks also tolerate property renaming, improving compatibility with optimized builds.
  • Script-host hardening — The compiler removes namespaced MathML <script> elements, while core rejects prefixed SVG script hosts. Apps that dynamically generate SVG or MathML should verify they do not rely on these previously accepted nodes.
  • UI state fixes — Corrected loop handling in @defer blocks and kept radio inputs synchronized when their values change. Regression-test deferred repeated content and radio groups with dynamically changing values.
  • HTTP JSON decoding — JSON responses are always decoded as UTF-8, removing charset-dependent behavior for non-ASCII payloads. APIs should return valid UTF-8 JSON rather than rely on another response charset.
  • Router URL handling — Protocol-relative URL handling is now limited to serialization. Review custom URL parsing or serialization code if it depends on the previous broader treatment of //host/path-style values.
  • Compatibility — No breaking changes are announced.
