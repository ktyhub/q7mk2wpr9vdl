🚀 インストール手順

  • 💻 Windows: ダウンロードしたインストール パッケージをダブルクリックし、プロンプトに従ってインストールを完了します。 ARM64 には、新しい Windows 11 に組み込まれている .NET Framework 4.8.1 が必要です。
  • 🍎 Mac (macOS 14 以降): ダウンロードした .dmg イメージを開き、toonflow.app を「アプリケーション」にドラッグし、コピーが完了したら「アプリケーション」から開きます。
  • 🐧 Linux (Debian/Ubuntu): 対応するアーキテクチャの DEB を選択し、ダウンロード ディレクトリで sudo apt install ./toonflow-版本号-linux-架构.deb を実行し、インストール後にアプリケーション メニューから開きます。
  • 📱 Android: 携帯電話で APK を開き、システム プロンプトに従って、このソースによるアプリのインストールを許可します。後続のバージョンは直接上書きしてインストールできます。

Mac アプリと DMG イメージは両方とも、Developer ID アプリケーションで署名され、Apple の公証によって完了します。 macOS では、インターネットからダウンロードしたアプリを初めて開くときに、そのアプリを開くかどうかの確認を求めるメッセージが表示される場合があります。 古い Intel Mac クライアントを統合 SDK バージョンに初めて移行する場合は、完全な DMG オーバーレイ インストールをダウンロードしてください。古い増分更新は直接移行できません。インストールする前に、アプリケーションを終了し、元のデータ ディレクトリをバックアップしてください。

Toonflow-app v2.0.10

Highlights

  • Cross-platform release matrix — v2.0.10 ships seven installers: Windows (x64 + ARM64), macOS (Apple Silicon + Intel), Linux (x64 + ARM64, DEB only), and Android (ARM64, Android 8+). The symmetric x64/ARM64 desktop coverage points to a unified cross-platform runtime; watch the gaps — mobile is ARM64-only (no x86 Android), and Linux has no RPM/AppImage, so plan packaging and device support accordingly.
  • Intel Mac unified-SDK migration — The one concrete migration gotcha: legacy Intel Mac clients on the old incremental-update track cannot upgrade in place. You must download the full DMG and overwrite-install, quit the app, and back up the data directory first. Treat this as a manual, data-preserving migration, not a routine auto-update.
  • Code signing and notarization — Both Mac builds and their DMGs are Developer ID Application-signed and Apple-notarized, which removes most Gatekeeper friction for managed deployments. Expect a first-launch "open from internet" confirmation anyway, so don't assume a fully silent install.
  • Windows ARM64 dependency — The ARM64 installer requires .NET Framework 4.8.1, preinstalled only on newer Windows 11. On older ARM64 Windows builds you'll need to install the framework first or the installer will fail — factor this into image baking.
  • Manual vs. auto-update artifacts — The linked installers are the manual-install path; the remaining release assets feed the in-app updater. If you script or mirror deployments, use the table links and don't assume the two paths are interchangeable — the Intel Mac migration explicitly breaks the incremental-update route.
  • Thin functional changelog — These notes are installation documentation only: no feature/fix list and no PR references, with "Full Changelog" reduced to a v2.0.9→v2.0.10 compare link. You cannot infer what actually changed functionally from this page alone; check the upstream commit compare before adopting.

No breaking API or behavioral changes are documented in this release.

🚀 安装说明

  • 💻 Windows：双击下载的安装包，按提示完成安装。ARM64 需要 .NET Framework 4.8.1，较新的 Windows 11 已内置。
  • 🍎 Mac（macOS 14 及以上）：打开下载的 .dmg 镜像，将 toonflow.app 拖入“应用程序”，复制完成后再从“应用程序”打开。
  • 🐧 Linux（Debian / Ubuntu）：选择对应架构的 DEB，在下载目录执行 sudo apt install ./toonflow-版本号-linux-架构.deb，安装后从应用菜单打开。
  • 📱 Android：在手机上打开 APK，按系统提示允许此来源安装应用。后续版本可直接覆盖安装。

两种 Mac 应用与 DMG 镜像均使用 Developer ID Application 签名，并完成 Apple 公证。首次打开时，macOS 仍可能提示确认打开从互联网下载的应用。 旧版 Intel Mac 客户端首次迁移到统一 SDK 版本时，请下载完整 DMG 覆盖安装；旧版增量更新不能直接迁移。安装前请退出应用并备份原数据目录。
