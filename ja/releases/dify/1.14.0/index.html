コラボレーション

<img width="2632" height="1190" alt="img_v3_02117_67a67218-1ae5-4d68-a45b-3ada592f87fg" src="https://github.com/user-attachments/assets/1d4a3660-8a6a-4b29-9766-4d5b5fd9a51b" />

コラボレーションにより、ワークスペースのメンバーは、同期されたグラフ更新、オンライン プレゼンス、および誰がどこで作業しているかの共有可視性を利用して、同じワークフローを一緒に編集できます。

セルフホスト展開では、コラボレーションはデフォルトでオフになります。次のように設定して有効にします。

ENABLE_COLLABORATION_MODE = true
SERVER_WORKER_CLASS = geventwebsocket.gunicorn.workers.GeventWebSocketWorker
NEXT_PUBLIC_SOCKET_URL = your deployment’s WebSocket URL (e.g., wss://dify.example.com)

詳細については、完全なドキュメント を参照してください。

人間参加型 (HITL)

  • サービス API for HITL — 既存のコンソールの動作に加えて人間参加型フローをプログラムでサポートします。

MCP とプラグイン

  • MCP ツールのメタデータ — 更新後に更新されるため、UI の同期が維持されます。
  • MCP サーバー URL — OAuth と認証 (404) を破壊する可能性がある二重 /v1 を修正します。
  • MCP OAuth Discovery — 不正な形式の JSON を安全に処理します。
  • MCP スキーマ公開 — checkbox および json_object タイプを正しくマップします。
  • プラグイン - 自動アップグレード戦略の永続性、ローカル インストーラーとファイル入力の動作、内部 API エンド ユーザー ルックアップのテナント スコーピング。

マーケットプレイスとOAuth

  • マーケットプレイスと OAuth - マーケットプレイス フローと OAuth サインインを対象とした修正 (GitHub OAuth の null 電子メールなどのエッジ ケースを含む)。

UI キットとフロントエンド プラットフォーム

  • @langgenius/dify-ui - 共有プリミティブ (PreviewCard、Meter など)、デザイン トークン、およびアドホック web/base/ui からパッケージへの広範な移行。
  • アクセシビリティ — 日付と時刻のピッカー、自動更新戦略ピッカー、プラグインおよびモデル セレクターのスクロールバー、および関連する機能の強化。
  • 何でも移動 — 最近のアイテム、/go コマンド、より深いアプリのサブセクション。 Cmd+K を修正 (問題のある動的インポートを削除)。
  • プロンプト エディター — スラッシュでトリガーされる 変数フィルター;変数リストのキーボード 上/下。
  • フォローアップの質問 — 提案された質問の設定とトークン制限が改善されました。
  • モーダル - ApiKey、プロバイダー構成、その他は、テストとの共有 ダイアログ パターンに向けてリファクタリングされました。

可観測性と分析

  • Langfuse — オプションの 最初のトークンまでの時間 (TTFT) レポート。
  • 探索 — バナーのインプレッション追跡。カード上のアプリ プレビュー イベント追跡。

請求と割り当て

  • 製品スタックへの Quota v3 の統合。
  • 請求 UI — メーターベースの使用量のプレゼンテーション。 API の請求が失敗した場合のクリーンアップの回復力が向上しました。
  • ファイル アップローダー — 請求を意識した動作とコピーの更新。

データ、RAG、および知識

  • 概要インデックスと Weaviate — Weaviate で概要インデックスを使用する場合の互換性を修正しました。
  • ベクトル投影 — 該当する場合、デフォルト投影に is_summary および original_chunk_id を含めます。
  • 外部およびバインドされたデータセット — ナレッジ API に対するテナント チェックを強化します。

インフラストラクチャと運用

  • Docker Compose — api、worker、worker_beat の ヘルスチェック;テンプレートと環境サンプルの更新 (S3 アドレス スタイルなど)。
  • Celery — デフォルトのワーカー 同時実行数が 4 に引き上げられました。欠落しているキューの修正。
  • PostgreSQL — 更新されたアプリ DB パスのより高いデフォルト 最大接続数 (200)。
  • Redis — 構成可能なキー プレフィックス; Redis 操作の 再試行 ロジック。
  • TiDB — エンドポイントのサポートおよび関連する認証バインディングの移行 (TiDB 認証バインディング上の Qdrant エンドポイント)。
  • Markdown — 必要に応じてレンダリングされた Markdown でインライン CSS を許可するオプションの ALLOW_INLINE_STYLES 環境変数。

セキュリティ

  • 変更メール フロー — より厳密なフェーズ限定トークンの処理 (GHSA-4q3w-q5mc-45rq)。
  • IDOR 強化 — データ ソース バインディングのテナント検証。データセットと API の所有権は、ギャップが見つかった場所をチェックします。

パフォーマンス

  • グラフ初期化のパフォーマンスが最適化されました。

API とプラットフォームの内部構造

  • Graphon — スタンドアロン Graphon 0.2.2 にアップグレードします (ツリー内の dify_graph の名前とパッケージを置き換えます)。
  • OpenAPI — OpenAPI v2 JSON およびドキュメント ポインターを生成するスクリプト。
  • 非推奨 — 一部のレガシー コンソール API は、新しいパターンを優先して非推奨としてマークされています。
  • 大規模な SQLAlchemy 2.0 select() 移行、多くのコンソールおよびサービス応答用の Pydantic BaseModel、安定性のための testcontainers ベースのテスト。

Collaboration

<img width="2632" height="1190" alt="img_v3_02117_67a67218-1ae5-4d68-a45b-3ada592f87fg" src="https://github.com/user-attachments/assets/1d4a3660-8a6a-4b29-9766-4d5b5fd9a51b" />

Collaboration allows workspace members to edit the same workflow together, with synced graph updates, online presence, and shared visibility into who is working where.

On self-hosted deployments, collaboration is turned off by default. Enable it by setting:

ENABLE_COLLABORATION_MODE = true
SERVER_WORKER_CLASS = geventwebsocket.gunicorn.workers.GeventWebSocketWorker
NEXT_PUBLIC_SOCKET_URL = your deployment’s WebSocket URL (e.g., wss://dify.example.com)

For more details, see Full Documentation

Human-in-the-loop (HITL)

  • Service API for HITL — programmatic support for human-in-the-loop flows alongside existing console behavior.

MCP and plugins

  • MCP tool metadata — refresh after updates so the UI stays in sync.
  • MCP server URL — fix double /v1 that could break OAuth and authorization (404).
