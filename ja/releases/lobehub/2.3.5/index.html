#ローブハブv2.3.5

v2.3.5 をリリース

PR #23632 より: https://github.com/lobehub/lobehub/pull/23632

概要

投稿元：AI支援 シアン、緑、赤のエージェント カバー カラーを #23624 からコミュニティ リリース ブランチにバックポートします。 main を新規インストールすると、宣言された依存関係の範囲内で @lobehub/ui@6.19.0 を解決できます。古い 7 エントリのパレットは、そのバージョンでは型チェックに失敗し、生成された一部のアバターに対して未定義のカバー カラーを返します。 カバーでは、新しい色ごとに対応するテーマ トークンが使用されます。ルックアップのキーの推論では、リリースの既存の依存関係範囲内の古い UI バージョンもサポートされます。 また、トランザクション スコープの共有アップロード ロックのカナリア テストもバックポートします。そのクエリはテスト対象の共有の勧告ロックをカウントするようになり、無関係なセッションが独自のロックを同時に保持できるようになります。

テスト

  • [x] UI ライブラリの実際のアバター ジェネレーターを使用した回帰テストを追加しました。オリジナルのリリースでは、緑色のアバターは undefined を受け取りましたが、テーマでは var(--lobe-green) が指定されていました。
  • [x] 糸くずと関連する 10 のカバーカラー テスト。
  • [x] 元のリリースと UI 6.19.0 を使用したこのコミットに対して同じスタンドアロン ワークスペースの互換性チェックを実行しました。元のバージョンは TS2739 による型チェックに失敗しました。この修正は型チェックと 505 のワークスペース テストすべてに合格しました。
  • [x] リポジトリのタイプチェックを実行しました。
  • [x] 専用の PostgreSQL インスタンス内の別の接続で、無関係な 2 つの勧告ロックを保持しました。古いテストでは 3 つのロックが発生し、失敗しました。バックポートを使用すると、無関係な 2 つのロックが保持されたままになっている間、60 のエージェント共有テストがすべて合格しました。リポジトリの lint と関連テストも合格しました。

承認

実際の /agents ページをリリース ベースと UI 6.19.0 を使用したこのコミットに対して検証しました。ベースでは、生成されたシアン、緑、赤のアバターはすべて同じニュートラルなカード背景を持っていました。修正により、各カードに対応するテーマカラーが追加されました。紫色のコントロールは、両方のビルドで同じ背景を維持しました。 ブラウザーのキャプチャと計算されたスタイル (テスト アカウントのアクセスが必要な場合があります)。

lobehub v2.3.5

Release v2.3.5

From PR #23632: https://github.com/lobehub/lobehub/pull/23632

Summary

Contribution source: AI-assisted

Backport the cyan, green and red agent cover colors from #23624 to the community release branch. A fresh install of main can resolve @lobehub/ui@6.19.0 within the declared dependency range. The old seven-entry palette fails type-checking on that version and returns an undefined cover color for some generated avatars.

The cover uses the corresponding theme token for each new color. Inferring the lookup's keys also supports older UI versions in the release's existing dependency range.

Also backports the canary test for the transaction-scoped share upload lock. Its query now counts the advisory lock for the share under test, allowing unrelated sessions to hold their own locks concurrently.

Tests

  • [x] Added a regression test using the UI library's actual avatar generator. On the original release, a green avatar received undefined where the theme specifies var(--lobe-green).
  • [x] Ran lint and the 10 related cover-color tests.
  • [x] Ran the same standalone workspace compatibility check against the original release and this commit with UI 6.19.0. The original failed type-checking with TS2739; the fix passed type-checking and all 505 workspace tests.
  • [x] Ran the repository type-check.
  • [x] Held two unrelated advisory locks on a separate connection in a dedicated PostgreSQL instance. The old test saw three locks and failed. With the backport, all 60 agent-share tests passed while the two unrelated locks remained held. The repository lint and related tests also passed.

Acceptance

Verified the real /agents page against the release base and this commit with UI 6.19.0. On the base, generated cyan, green and red avatars all had the same neutral card background. With the fix, each card has its corresponding theme color. The purple control kept the same background across both builds. Browser captures and computed styles (testing account access may be required).

Desktop release baseline

Inherits the delivered sources from v2.3.4.
