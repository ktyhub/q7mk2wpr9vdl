#アグノv2.5.15 #Changelog

新機能:

  • スキル: チームにスキルのサポートを追加しました。 ドキュメント を参照してください。
  • ワークフロー: ワークフロー ステップ (ネストされたワークフロー) のサポートとしてワークフローを追加しました。 ドキュメント を参照してください。

改善点:

  • ワークフロー HITL:
    • ワークフロー ステップは、実行後の人間参加レビューをサポートするようになりました。ステップの実行後に一時停止して、レビュー、承認、フィードバックによる拒否と再試行を行うか、続行する前に出力を編集します (ステップ、ルーター、およびループの requires_output_review)。 ドキュメント を参照してください。
    • パラメーターは HumanReview 構成クラスに統合されました - フラット パラメーターの代わりに、Step、Loop、Router に human_review=HumanReview(...) を渡します。完全な下位互換性があります。 ドキュメントを参照
  • トレースバック ログ: log_error および log_warning でのトレースバックの可視性を制御するための AGNO_LOG_TRACEBACKS 環境変数 (オプトイン) を追加しました。デフォルトではオフ (ログがクリーン)、true に設定すると完全なトレースバックになります。
  • SessionsummaryManager: last_n_runs および conversation_limit パラメーターを SessionSummaryManager により、ユーザーはセッション概要を生成するときにどの程度の会話履歴を含めるかを制御できます。

バグ修正:

  • OpenAI: OpenAI および Azure OpenAI モデルへの共有 HTTP/2 client の挿入を停止します。 OpenAI SDK が独自の HTTP client を管理できるようにすることで、同時使用時の一時的な 400 エラーを修正します。
  • メトリクス: OpenAI、Perplexity、および LiteLLM に対して audio_total_tokens が計算されない問題を修正しました。
  • ワークフロー:
    • Condition ステップ タイプで else_steps がコピーされない問題を修正しました。
    • File オブジェクトを適切にシリアル化するために StepInput to_dict を修正しました。
  • SurrealDb: 正しい SurrealDB フレキシブル フィールド構文を更新しました。
  • AgentOS: AgentOS ファイルのアップロードに欠落していた .msg、.xlsx、および .xls の MIME タイプを追加しました。
  • A2A: str 連結の前に Pydantic output_schema コンテンツをシリアル化するように修正されました。
  • チーム: 重複したメッセージを返す TeamSession.get_messages(..) を修正しました。
  • SlackTools: スレッド対応のメッセージング命令を SlackTools に追加するように修正されました。
  • GitHubTool: PR が要求された制限より少ない場合の get_pull_requests の IndexError を修正しました
  • WikipediaTools: Wikipedia DisambiguationError を処理し、設定可能な auto_suggest を追加するように修正されました。

agno v2.5.15

Highlights

  • Composable teams and workflows — Teams can now use skills (#7017), and workflows can be embedded as steps (#6116), enabling reuse of packaged capabilities and multi-step orchestration instead of duplicating workflows.

  • Post-execution human review — Workflow steps can pause after running for approval, rejection with feedback and retry, or output editing via requires_output_review (#7409). HITL configuration is consolidated into human_review=HumanReview(...) (#7428), with support extended to Condition, Steps, and Parallel (#7433); existing flat parameters remain backward compatible, so migration is optional.

  • More reliable OpenAI and Azure concurrency — Agno no longer injects a shared HTTP/2 client into these models (#7328), eliminating transient 400 errors and letting the OpenAI SDK manage connections. Recheck any HTTP transport customization that relied on the previously injected shared client.

  • Bounded summaries and accurate token accounting — SessionSummaryManager gains last_n_runs and conversation_limit (#7401), giving developers direct control over summary context size and cost. Audio token usage is now correctly calculated for OpenAI, Perplexity, and LiteLLM (#7417).

  • Workflow and session correctness — Fixes address missing Condition.else_steps propagation (#7198), improper File serialization in StepInput.to_dict (#7364), and duplicate TeamSession messages (#7372), reducing incorrect branch execution, serialization failures, and repeated model context.

  • Breaking changes — None; the HumanReview configuration consolidation is explicitly backward compatible.

Changelog

New Features:

  • Skills: Added skills support to Team. See docs.
  • Workflow: Added workflow as a workflow step (nested workflow) support. See docs.

Improvements:

  • Workflow HITL:
    • Workflow steps now support post-execution human-in-the-loop review - pause after a step runs to review, approve, reject with feedback and retry, or edit the output before it continues (requires_output_review on Step, Router, and Loop). See docs.
    • Parameters consolidated into HumanReview config class - pass human_review=HumanReview(...) on Step, Loop, and Router instead of flat params. Fully backward compatible. See docs
  • Traceback Logging: Added AGNO_LOG_TRACEBACKS env var (opt-in) to control traceback visibility in log_error and log_warning — off by default (clean logs), full tracebacks when set to true.
  • SessionSummaryManager: Adds last_n_runs and conversation_limit parameters to SessionSummaryManager so users can control how much conversation history is included when generating session summaries.

Bug Fixes:

  • OpenAI: Stop injecting shared HTTP/2 client into OpenAI and Azure OpenAI models. Fixes transient 400 errors under concurrent usage by letting the OpenAI SDK manage its own HTTP client.
  • Metrics: Fixed audio_total_tokens not being computed for OpenAI, Perplexity, and LiteLLM.
  • Workflow:
    • Fixed else_steps not being copied for Condition step type.
    • Fixed StepInput to_dict to properly serialize File objects.
  • SurrealDb: Updated correct SurrealDB flexible field syntax.
  • AgentOS: Added missing MIME types for .msg, .xlsx and .xls in AgentOS file upload.
  • A2A: Fixed to serialize Pydantic output_schema content before str concatenation.
  • Team: Fixed TeamSession.get_messages(..) returning duplicate messages.
  • SlackTools: Fixed to add thread-aware messaging instructions to SlackTools.
  • GitHubTool: Fixed IndexError in get_pull_requests when fewer PRs than requested limit
  • WikipediaTools: Fixed to handle Wikipedia DisambiguationError and add configurable auto_suggest.
