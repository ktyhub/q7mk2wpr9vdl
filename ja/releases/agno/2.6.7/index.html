#アグノv2.6.7 #Changelog

新機能:

  • Gemini インタラクション: Google の新しいステートフル インタラクション API を利用する新しい GeminiInteractions モデル クラスを追加しました。
  • AgentOS: AgentOS 認証エンドポイント用に、オプトインのユーザーごとのデータ分離レイヤー を追加しました。

改善点:

  • ナレッジ リーダー: 送信フェッチを制限するために、URL フェッチ リーダーに allowed_hosts パラメータを追加しました。

バグ修正:

  • Qdrant: Qdrant async_insert で重複するスパース エンコーダー呼び出しを削除するように修正されました。
  • トレース: 両方が trace_id を共有している場合に、親トレースの session_id / agent_id / team_id が子エージェントのスパンによって上書きされないように修正しました。チームがポストフック（例: @hook(run_in_background=True).
  • ワークフロー: 非同期コンテキストで実行されている場合に、対応する非同期関数 acleanup_run を使用するようにワークフローの HITL 継続パスを修正しました。

agno v2.6.7

Highlights

  • Stateful Gemini interactions — The new GeminiInteractions model uses Google’s stateful Interactions API, offering a stateful alternative for conversation continuity without a custom model wrapper (#7926).
  • Opt-in AgentOS user isolation — Authenticated endpoints can now enforce per-user data isolation. Because this is opt-in, existing shared deployments remain unprotected until enabled; multi-tenant workloads should explicitly enable and test it (#7606).
  • URL-reader SSRF controls — URL-fetching knowledge readers accept allowed_hosts, letting teams restrict ingestion to approved domains. Configure an allowlist before fetching user-supplied or untrusted URLs (#7892).
  • Correct trace attribution — Child-agent spans sharing a trace_id no longer overwrite the parent’s session_id, agent_id, or team_id. This is especially important for Teams using background post-hooks, where cross-agent traces could previously be mislabeled (#7796).
  • Async workflow and Qdrant reliability — HITL continuation now calls acleanup_run in async contexts, avoiding a synchronous cleanup call on the async path (#7916). Qdrant async_insert also removes a duplicate sparse-encoder call, reducing unnecessary computation during ingestion (#7893).
  • Breaking changes — None.

Changelog

New Features:

  • Gemini Interactions: Added a new GeminiInteractions model class that makes use of Googles new stateful interactions API
  • AgentOS: Added an opt-in per-user data isolation layer for AgentOS authenticated endpoints.

Improvements:

  • Knowledge Readers: Added allowed_hosts parameter to URL-fetching readers to restrict outbound fetches.

Bug Fixes:

  • Qdrant: Fixed to remove duplicate sparse encoder call in Qdrant async_insert.
  • Traces: Fixed the parent trace's session_id / agent_id / team_id from being overwritten by a child agent's spans when both share a trace_id. Most visible when a Team uses a post-hook (e.g. @hook(run_in_background=True).
  • Workflow: Fixed workflow’s HITL continue path to use corresponding async function acleanup_run if running in an async context.
