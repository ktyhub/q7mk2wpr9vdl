agno v2.6.6

Highlights

  • Slack HITL approvals go multi-row — PR #7574 extends the Slack interface to support multi-row human-in-the-loop approvals across every pause type, not just single-row cases. If you build approval gates into Slack-facing agents, this is the capability that lets one interrupt surface several actionable items at once — worth re-testing your approval handlers against the richer payloads.

  • Two JWT/IDOR security fixes — PRs #7816 and #7817 bind user_id to the JWT subject in the traces and approvals routers and do the same for workflow WebSockets, closing an insecure-direct-object-reference gap. The practical impact is authorization that is now actually enforced: if the user_id you pass diverges from your token's subject, those requests may start being rejected, so verify the two line up before upgrading.

  • Packaging changes that affect installs — PR #7877 disables the agno[mistral] extra because mistralai is quarantined on PyPI, and PR #7869 pins tree-sitter-language-pack<1.8.0 to unblock the chonkie code chunker. If your dependency pipeline requests agno[mistral], it will no longer resolve — you'll need to pin/vendor mistralai yourself — and the tree-sitter cap can constrain other packages in the same environment.

  • Notion databases join the wiki context stack — PR #7914 adds NotionDatabaseBackend to WikiContextProvider, letting you ground agent context in a Notion database rather than only pages/files. For teams already in Notion this removes an ETL hop, but expect new auth/permission setup and a schema shape your data must conform to.

  • Duplicate tool names now warn — PR #7829 makes agent and team registration emit a warning on duplicate tool names. It's a guardrail, not a hard failure, but silent overwrites are a classic source of "why isn't my tool being called?" bugs — treat any new warning as a prompt to audit shared team toolkits.

  • Correctness fixes worth upgrading for — aget_last_run_output no longer returns None when agent.id is auto-generated during arun() (#7840); /continue forwards dependencies and metadata via get_request_kwargs (#7849); and LearningMachine context is injected into the Team system prompt (#7818). The /continue fix especially restores state that stateful continuations rely on.

No breaking changes are called out in this release.

Changelog

New Features:

  • Slack Interface: Added support for HITL multi-row approvals with all pause types.

Improvements:

  • WikiContextProvider: Added NotionDatabaseBackend to wiki context provider.
  • Tools: Updated to warn on duplicate tool names when registering on agent or team.

Bug Fixes:

  • JWT:
    • fixed to bind user_id to JWT subject in traces and approvals routers
    • fixed to bind WebSocket user_id to JWT subject for workflows
  • RunOutput: fixed aget_last_run_output returns None when agent.id is auto-generated during arun().
  • /continue Endpoint: Fixed to forward dependencies and metadata to /continue endpoints via get_request_kwargs.
  • LearningMachine: Fixed to inject LearningMachine context into Team system prompt.
