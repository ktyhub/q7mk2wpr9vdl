#アグノv2.8.1 #Changelog

新機能:

  • TwelveLabsTools: Marengo ビデオ埋め込みのサポートを追加しました。 ドキュメント を参照してください。
  • Slack: ピアエージェント通信用の respond_to_other_agents フラグ。

改善点:

  • ラーニング ストア: 無限ループを防ぐための extraction_tool_call_limit。
  • コンテキスト プロバイダー: stream_sub_agent_events はすべてのプロバイダーでサポートされます。

バグ修正:

  • ファイル ツール: list_files は、ツール スキーマでオプションの directory パラメーターを公開するようになり、エージェントは特定のサブディレクトリを直接一覧表示できるようになりました。
  • チーム:
    • ネストされたチームは、独自のチーム履歴を取得できるようになりました。
    • 明示的に構成されたメンバー ID がそのまま保持されるようになったため、カスタム ID を持つメンバーへの委任が機能します。
  • CSV リーダー: read() は、文字列として渡される CSV ファイル パスをサポートするようになりました。
  • ツール: 空または欠落している引数の呼び出しを修正しました。

重大な変更

  • Scavio ツール: google_search は、適切なローカリゼーションとページングのために、Scavio Google v2 API をターゲットにするようになりました。 ドキュメント を参照してください。

agno v2.8.1

Changelog

New Features:

  • TwelveLabsTools: Added support for Marengo video embeddings. See docs.
  • Slack: respond_to_other_agents flag for peer-agent communication.

Improvements:

  • Learning Stores: extraction_tool_call_limit to prevent infinite loops.
  • Context Providers: stream_sub_agent_events supported across all providers.

Bug Fixes:

  • File Tools: list_files now exposes its optional directory parameter in the tool schema, so agents can list a specific subdirectory directly.
  • Teams:
    • Nested teams now retrieve their own team history.
    • Explicitly configured member IDs are now preserved as-is, so delegation to members with custom IDs works.
  • CSV Reader: read() now supports CSV file paths passed as strings.
  • Tools: Empty/missing argument invocation fix.

Highlights

  • Scavio Google search moves to v2 API — google_search now targets the Scavio Google v2 endpoint, remapping parameters to gl/hl/start for correct localization and paging (PR #9021). This is the release's only breaking change: code that builds search params with the old names or assumes the old response shape will behave differently, especially outside US locales, so audit any direct Scavio calls before upgrading.

  • Team delegation becomes predictable — nested teams now load their own history via a team_id filter in get_team_history (PRs #8968, #8956), and explicitly configured member IDs are preserved verbatim so delegation to members with custom IDs works (PR #9011). Agents created through the AgentOS UI/components API also resolve correctly (PR #9072). For hierarchical teams with hand-assigned IDs, runtime behavior finally matches configuration.

  • Slack peer-agent communication — a new respond_to_other_agents flag lets Slack agents reply to messages authored by other agents (PR #8934), enabling agent-to-agent handoffs in shared channels instead of only human-initiated turns. Watch for reply loops if several agents in one channel enable it.

  • TwelveLabs Marengo video embeddings — TwelveLabsTools adds Marengo video embeddings (PR #8973), extending the toolkit beyond text/audio into native video vectors. If you're indexing video for retrieval, this gives you an embedding path without a separate preprocessing pipeline.

  • Safer learning extraction and consistent streaming — Learning Stores gain extraction_tool_call_limit to cap runaway tool-call loops (PR #9077), and stream_sub_agent_events now works across all context providers (PR #9098), so sub-agent events stream uniformly regardless of backend. Both reduce surprises in long-running or multi-provider deployments.

  • Tool/IO friction removed — list_files now exposes its optional directory parameter in the tool schema so agents can target a subdirectory directly (PR #9078); CSVReader.read() accepts string paths (PR #8822); and tools invoked with empty or missing arguments no longer error (PR #6303). Minor, but they eliminate common agent-call failures.

Breaking Changes

  • Scavio Tools: google_search now targets the Scavio Google v2 API for proper localization and paging. See Docs
