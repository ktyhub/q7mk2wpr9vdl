#アグノv3.0.1 #Changelog

改善点

  • 多くのツールによるエージェントの実行の高速化: ツール スキーマは一度派生され、実行全体でキャッシュされるようになり、大規模なツールキットを運ぶエージェントの実行ごとのオーバーヘッドが削減されます。 (#9771)
  • 長い会話の高速化: セッション履歴はターンごとに段階的に読み込まれるため、会話の長さに応じて変化するのではなく、会話が大きくなっても応答時間は一定のままです。 (#9775)
  • PubMed リクエストのタイムアウト: PubmedTools は timeout を受け入れ、それを両方の NCBI E-utilities リクエストに渡すようになりました。そのため、停止した PubMed レスポンスはツール呼び出しを無期限に保持できません。 (#9463)

バグ修正

  • properties のない厳密モード ツール スキーマ: Function.process_schema_for_strict は、properties を省略したスキーマ (たとえば、逐語的に登録された MCP サーバー スキーマ) で KeyError を生成しなくなりました。 (#9578、#9409 を修正)
  • Gemini ツール結果メディア: ツールから返された画像とドキュメント BLOB は、兄弟 inline_data パーツとして出力されるのではなく、Gemini 3 以降のモデルの FunctionResponse.parts 内にネストされるようになりました。レガシー モデルは以前の表現を保持します。 Vertex AI 上の URI ベースの応答メディアは、MIME タイプがサポートされている場合にのみ送信されます。 (#9647)
  • コアのみのインストールでの場所の検索: agno.utils.location は宣言されていない requests パッケージを使用したため、add_location_to_context=True は追加のインストールなしで ModuleNotFoundError を生成しました。現在はhttpxを使用しています。 (#9793、#9772 を修正)
  • ScheduleManager クリーンアップ: close() は、部分的に構築されたマネージャー (たとえば、deepcopy が失敗した後) を許容するため、ガベージ コレクションによって、欠落している _pool で AttributeError が発生しなくなります。 (#9792)

料理本

  • 確定的な副作用承認フローの例を追加しました。 (#9790)
  • DeepKeep AI ファイアウォールのガードレールの例を追加しました。 (#9784)
  • AgentOS チームの実行状態を文書化しました。 (#9768)
  • Peer Cash MCP エージェントの例を追加しました。 (#9562)
  • ディレクトリの再番号付けおよび MCP サンプルで残った古いクックブック パスを修正しました。 (#9789、#9783)

agno v3.0.1

Highlights

  • Lower overhead for larger agents — Tool schemas are cached across runs (#9771), and session history is loaded incrementally per turn rather than rebuilt in full (#9775). Large toolkits and long-running conversations should see more consistent latency without configuration changes.
  • Gemini tool-result media format — Gemini 3+ receives images and document blobs nested inside FunctionResponse.parts; legacy models retain the previous sibling inline_data representation (#9647). Update custom payload validators accordingly, and note that Vertex AI now omits URI-backed media with unsupported MIME types.
  • Strict-mode MCP compatibility — Schemas that omit properties, including MCP schemas registered verbatim, no longer trigger a KeyError during strict processing (#9578, fixes #9409). This removes a validation failure mode for integrations that previously needed to normalize such schemas themselves.
  • Core-install reliability — Location enrichment with add_location_to_context=True no longer fails with ModuleNotFoundError on minimal installations: agno.utils.location now uses httpx instead of the undeclared requests dependency (#9793, fixes #9772).
  • Safer tool calls and cleanup — PubmedTools exposes a timeout applied to both NCBI E-utilities requests, allowing stalled calls to be bounded (#9463). ScheduleManager.close() also tolerates partially initialized instances, preventing teardown errors after failures such as an unsuccessful deepcopy (#9792).
  • Breaking changes — None declared.

Changelog

Improvements

  • Faster agent runs with many tools: Tool schemas are now derived once and cached across runs, cutting per-run overhead for agents that carry large toolkits. (#9771)
  • Faster long conversations: Session history is loaded incrementally per turn, so response time stays flat as a conversation grows instead of scaling with its length. (#9775)
  • PubMed request timeout: PubmedTools now accepts a timeout and passes it to both NCBI E-utilities requests, so a stalled PubMed response cannot hold a tool call indefinitely. (#9463)

Bug Fixes

  • Strict-mode tool schemas without properties: Function.process_schema_for_strict no longer raises KeyError on schemas that omit properties (for example MCP server schemas registered verbatim). (#9578, fixes #9409)
  • Gemini tool-result media: Images and document blobs returned from tools are now nested inside FunctionResponse.parts for Gemini 3 and later models instead of being emitted as sibling inline_data parts; legacy models keep the previous representation. URI-backed response media on Vertex AI is only sent when the MIME type is supported. (#9647)
  • Location lookup on core-only installs: agno.utils.location used the undeclared requests package, so add_location_to_context=True raised ModuleNotFoundError without extras installed. It now uses httpx. (#9793, fixes #9772)
  • ScheduleManager cleanup: close() tolerates a partially constructed manager (for example after a failed deepcopy), so garbage collection no longer raises AttributeError on a missing _pool. (#9792)

Cookbooks

  • Added a deterministic side-effect approval flow example. (#9790)
  • Added DeepKeep AI Firewall guardrails example. (#9784)
  • Documented AgentOS team run states. (#9768)
  • Added a Peer Cash MCP agent example. (#9562)
  • Fixed stale cookbook paths left over from the directory renumber and in the MCP examples. (#9789, #9783)
