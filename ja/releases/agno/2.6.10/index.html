#アグノv2.6.10

Changelog

新機能

  • モデル プロバイダー: 4 つの新しいモデル プロバイダーを追加しました。
    • Inception Labs モデルの統合
    • Xiaomi MiMo モデル プロバイダー
    • MiniMax モデル プロバイダー (M2.7)
    • Cloudflare AI Gateway モデルプロバイダー
  • YouTools: You.com 検索 API 統合用に YouTools を追加しました。
  • DOCX 生成: DOCX ファイル生成のサポートを追加しました。
  • コンテキスト プロバイダー ストリーミング: コンテキスト プロバイダーからサブエージェント イベントをストリーミングします。
  • レジストリ: レジストリにナレッジとマネージャーのサポートを追加しました。
  • 実行の永続性: キャンセルされた実行を適切に永続化するために、エージェント、チーム、およびワークフローを更新しました。
  • RunCompleted イベント: RunCompleted イベントに files フィールドを追加しました。
  • モデル文字列パーサー: モデル文字列パーサーに google-interactions プロバイダーを追加しました。

改善点

  • DeepSeek: DeepSeek V4 の思考モードとデフォルトを更新しました。
  • クックブック: 無料のエンドポイントを使用するように Parallel MCP を更新しました。洗練されたイメージ検索の README; data_labeling の例をモデル文字列の短縮表現に切り替えました。

バグ修正

  • MCP:
    • エージェントのクラッシュによる MCP 接続障害を防ぎます。
    • MCP ツールに team/agent/run_context パラメータがある場合、kwarg の衝突を回避します。
  • JSON DB: JSON DB ファイルには UTF-8 エンコーディングを使用します。
  • CSV ツールキット: CSV ツールキット ファイルを UTF-8 として読み取ります。
  • 非同期修正:
    • Discord client で requests.get をブロックする代わりに、非同期 Attachment.read() を使用します。
    • _async_create_collection_and_scope のブロック time.sleep を await asyncio.sleep に置き換えます。
    • エンベッダー内の非推奨の asyncio.get_event_loop() を get_running_loop() に置き換えます。
    • YouTube リーダーで実行ループを使用します。
    • フックが構成されていない場合、ツールは非同期実行チェーンで非同期エントリポイントを使用します。
    • CSVReader.async_read は、同期読み取り動作に一致させるために改行結合を使用します。
  • OpenAI Tools: OpenAITools.transcribe_audio のオーディオ ファイル ハンドルを閉じます。
  • チーム:
    • チーム継続実行の依存関係を修正しました。
    • 継続実行 SSE での AttributeError を防ぐための _acontinue_run_background_stream を追加しました。
  • パーサー モデル: parser_model が設定されている場合 (エージェントとチーム)、厳密なツール モードをスキップします。 parser_modelガードをcontinue_run_dispatchとacontinue_run_dispatchに追加しました。
  • RemoteTeam: ナレッジ フィルター属性を追加しました。
  • 埋め込み: NULL 埋め込みのバグを修正しました。
  • ベクター DB: Milvus ベクター DB と contents_db の互換性。非推奨の Tantivy FTS を削除し、Redis hset mypy エラーを修正しました。
  • SeltzTools: 現在の SDK 用に更新されました。
  • Fal: fal.py での配列処理を修正しました。
  • Zendesk: Zendesk ツールの URL エンコード検索クエリ。
  • メモリ: DB バックエンド間の memory_topics 署名の不一致を修正しました。
  • セッション: 非同期データベースで呼び出された場合、delete_session で ValueError を発生させます。
  • ファイル アップロード: ファイル アップロード メディアの処理を修正しました。
  • Slack HITL: Slack のサイレント拒否を防ぐために HITL カード本体を切り詰めます。

agno v2.6.10

Highlights

  • Provider expansion — agno adds four drop-in model providers: Inception Labs (#5431), Xiaomi MiMo (#8125), MiniMax M2.7 (#7014), and Cloudflare AI Gateway (#7598), plus google-interactions in the model-string parser (#8082). The practical win is configurability: you can switch model backends via model strings without rewriting agent code, and the Cloudflare option routes traffic through a gateway for caching/observability instead of hitting vendor APIs directly.

  • Search and DOCX output — YouTools wraps You.com's Search API (#7727), and DOCX generation (#7768) gives pipelines a native Word-document emitter. If you've been hand-rolling a search tool or post-processing markdown into .docx, this removes that glue code; DOCX is additive, so existing PDF/text output paths are untouched.

  • Streaming and run-state fidelity — context providers can now stream sub-agent events (#7924), RunCompleted gains a files field (#8104), and cancelled runs are properly persisted for agents, teams, and workflows (#5996). For SSE-driven UIs or run auditing, this means sub-agent activity and generated files surface on the event stream, and cancellation no longer leaves ghost/unfinished records in storage.

  • Async correctness sweep — a batch of fixes removes event-loop blocking and deprecated APIs: Attachment.read() replaces blocking requests.get in the Discord client (#8186), time.sleep → await asyncio.sleep (#8158), asyncio.get_event_loop() → get_running_loop() in embedders (#8111), the running loop in the YouTube reader (#8078), and tools using the async entrypoint when no hooks are configured (#7765). If you run agno under async frameworks at concurrency, expect lower tail latency and less Python 3.12+ deprecation noise — worth re-profiling hot paths.

  • MCP reliability — MCP connection failures no longer crash agents (#8112), and kwarg collisions are avoided when MCP tools declare team/agent/run_context params (#8066). Previously fatal startup and tool-call paths become recoverable — important if you register many third-party MCP servers where a single bad server could take down an entire agent.

  • Behavior changes to watch — not labeled breaking, but check before upgrading: deprecated Tantivy FTS was removed (#8146), delete_session now raises ValueError with an async DB (#8059), JSON DB and CSV toolkit files use UTF-8 (#8096, #8107), DeepSeek V4 thinking defaults were refreshed (#8147), and strict tool mode is skipped when a parser_model is set on Agent/Team (#8123, #8130, with dispatch guards in #8102). Callers depending on Tantivy, sync-style session deletion, or exact DeepSeek defaults should adjust.

No breaking changes.

Changelog

New Features

  • Model Providers: Added four new model providers:
    • Inception Labs model integration
    • Xiaomi MiMo model provider
    • MiniMax model provider (M2.7)
    • Cloudflare AI Gateway model provider
  • YouTools: Added YouTools for You.com Search API integration.
  • DOCX Generation: Added DOCX file generation support.
  • Context Provider Streaming: Stream sub-agent events from context providers.
  • Registry: Added knowledge and managers support in registry.
  • Run Persistence: Updated agent, team, and workflow to properly persist cancelled runs.
  • RunCompleted Event: Added files field on RunCompleted event.
  • Model String Parser: Added google-interactions provider to model string parser.

Improvements

  • DeepSeek: Refreshed DeepSeek V4 thinking mode and defaults.
  • Cookbook: Updated Parallel MCP to use free endpoint; polished image_search README; switched data_labeling examples to model string shorthand.

Bug Fixes

  • MCP:
    • Prevent MCP connection failures from crashing agents.
    • Avoid kwarg collision when MCP tools have team/agent/run_context params.
  • JSON DB: Use UTF-8 encoding for JSON DB files.
  • CSV Toolkit: Read CSV toolkit files as UTF-8.
  • Async Fixes:
    • Use async Attachment.read() instead of blocking requests.get in Discord client.
    • Replace blocking time.sleep with await asyncio.sleep in _async_create_collection_and_scope.
    • Replace deprecated asyncio.get_event_loop() with get_running_loop() in embedders.
    • Use running loop in YouTube reader.
    • Tools use async entrypoint in async execution chain when no hooks configured.
    • CSVReader.async_read uses newline join to match sync read behavior.
  • OpenAI Tools: Close audio file handle in OpenAITools.transcribe_audio.
  • Team:
    • Fixed team continue run dependencies;
    • Added _acontinue_run_background_stream to prevent AttributeError on continue-run SSE.
  • Parser Model: Skip strict tool mode when a parser_model is set (Agent and Team); added parser_model guard to continue_run_dispatch and acontinue_run_dispatch.
  • RemoteTeam: Added knowledge filter attributes.
  • Embeddings: Fixed NULL embeddings bug.
  • Vector DBs: Milvus vector DB compatibility with contents_db; removed deprecated Tantivy FTS, fixed Redis hset mypy error.
  • SeltzTools: Updated for current SDK.
  • Fal: Fixed array handling in fal.py.
  • Zendesk: URL-encode search query in Zendesk tool.
  • Memory: Fixed memory_topics signature mismatch across DB backends.
  • Sessions: Raise ValueError in delete_session when called with async db.
  • File Upload: Fixed file upload media handling.
  • Slack HITL: Truncate HITL card body to prevent silent Slack rejection.
