agno v2.6.5

#アグノv2.6.5 #Changelog

新機能:

  • Gemini マルチモーダル ファイル検索: Gemini ファイル検索 API (google-genai≥1.75.0 用) にマルチモーダル サポートが追加されました。 クックブックを参照してください。
  • コンテキスト プロバイダー: 既存のプロバイダー (GDrive、Slack、データベース) と同じパターンに従って、GmailContextProvider と CalendarContextProvider を追加しました。また、GDriveContextProvider を更新して、サービス アカウント認証に加えて OAuth をサポートします。
  • スケジューラ: AgentOS の cron でエージェント、チーム、ワークフローを実行するための Mongo および AsyncMongo DB のスケジューラ サポートを追加しました。
  • ワークフロー条件ステップ: on_error 処理を Condition ワークフロー ステップに追加しました。これにより、条件内のサブステップが失敗した場合のエラーの処理方法をユーザーが制御できるようになります。

改善点:

  • LLMsTxt ツール: allowed_hosts パラメータを追加したため、エージェントは trust のホストからのみフェッチします。
  • SlackContextProvider: ファイルのダウンロード/アップロードを制御するために enable_media_tools フラグ (デフォルト: False) を追加します。
    • 読み取りツールに download_file を追加しました
    • upload_file が書き込みツールに追加されました

バグ修正:

  • MCP IDOR: テナント間の読み取りおよび書き込みを防ぐために、AgentOS MCP ツール ハンドラーの user_id を認証された JWT サブジェクトにバインドするように修正されました。
  • ツールキットの説明: ツールキット内で使用したときに有効になるように @tool(instructions=...) を修正しました。
  • メトリクス: パーサー、出力、およびメンバーのメトリクスをチーム run_response に蓄積するように修正されました。
  • ワークフロー: ワークフロー実行の途中キャンセルを永続化するように修正されました。
  • SQLTools: describe_table に列のデフォルトを含めるように更新されました。
  • Slack インターフェイス: Slack ボットの @mention を削除するのではなく表示名に置き換えるよう修正しました。
  • GoogleDriveTools: GoogleDriveTools のバイナリ ファイル エラー + Office 抽出 + 共有ドライブ パラメータを修正しました。
  • ChromaDb: 非同期バッチ更新/挿入をワーカー スレッドにオフロードするように修正されました。
  • メモリ: update_memory および delete_memory ツールのインクルード ID フィールドを修正しました。

agno v2.6.5

Highlights

  • MCP tenant isolation (#7811) — AgentOS MCP tool handlers now bind user_id to the authenticated JWT subject instead of trusting a caller-supplied value, closing an IDOR that allowed cross-tenant reads and writes. Multi-tenant deployments should treat this as a priority upgrade; the watch-out is that any integration passing its own user_id will now be silently overridden by the token identity.
  • Gmail and Calendar context providers (#7747, #7702) — New GmailContextProvider and CalendarContextProvider follow the existing GDrive/Slack/Database pattern, and GDriveContextProvider gains OAuth alongside service-account auth. SlackContextProvider adds enable_media_tools (default False) gating download_file/upload_file, so existing agents don't unexpectedly acquire file I/O — you must opt in explicitly.
  • Gemini multimodal file search (#7788) — Gemini's File Search API now handles multimodal uploads, but the capability requires google-genai>=1.75.0. If you're pinned to an older client the feature is unavailable, so check the cookbook example before planning image ingestion.
  • Cron scheduling on MongoDB (#6938) — The AgentOS scheduler now supports Mongo and AsyncMongo backends for running agents, teams, and workflows on a cron. Mongo-backed deployments can drop external cron orchestration; validate scheduler writes against your existing collections and indexes first.
  • Workflow condition error handling (#7214) — Condition steps can now define on_error handling for failures in nested sub-steps. Previously a failing branch aborted with little control; now you can build fallback or compensation logic into conditional workflows.
  • LLMsTxt allowed_hosts (#7759) — A new allowlist restricts which hosts agents will fetch when using LLMsTxt tools. Since these tools pull remote llms.txt files by default, pin trusted hosts before exposing them to user-controlled input to avoid SSRF.

No breaking changes were declared in this release.

Changelog

New Features:

  • Gemini Multimodal File Search: Added multimodal support in the Gemini File Search API (for google-genai≥1.75.0). See cookbook.
  • Context Providers: Added GmailContextProvider and CalendarContextProvider following the same pattern as existing providers (GDrive, Slack, Database). Also updates GDriveContextProvider to support OAuth in addition to service account auth.
  • Scheduler: Added scheduler support for Mongo and AsyncMongo Db to run agents, teams, and workflows on a cron in AgentOS.
  • Workflow Condition Step: Added on_error handling to the Condition workflow step, allowing users to control how errors are handled when sub-steps within a condition fail.

Improvements:

  • LLMsTxt Tools: Added an allowed_hosts param so agents only fetch from hosts you trust.
  • SlackContextProvider: Add enable_media_tools flag (default: False) to control file download/upload.
    • download_file added to read tools
    • upload_file added to write tools

Bug Fixes:

  • MCP IDOR: Fixed to bind the user_id on AgentOS MCP tool handlers to the authenticated JWT subject to prevent cross-tenant reads and writes.
  • Toolkit Instructions: Fixed @tool(instructions=...) to take effect when used inside a Toolkit.
  • Metrics: Fixed to accumulate parser, output, and member metrics in team run_response.
  • Workflow: Fixed to persist mid-step workflow run cancellation.
  • SQLTools: Updated to include column default in describe_table.
  • Slack Interface: Fixed to replace Slack bot @mention with display name instead of stripping.
  • GoogleDriveTools: Fixed binary file errors + Office extraction + Shared Drive params in GoogleDriveTools.
  • ChromaDb: Fixed to offload async batch upsert/insert to worker thread.
  • Memory: Fixed include identity fields in update_memory and delete_memory tools.
