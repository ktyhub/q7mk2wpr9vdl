#アグノv2.6.8 #Changelog

新機能:

  • Antigravity: Google の Antigravity API のファーストパーティ サポートを 2 つの形式で追加しました。AntigravityAgent (ネイティブ セッション/ストリーミング/UI を備えた AgentOS を通じて提供される BaseExternalAgent) と AntigravityTools (Agno エージェントがマネージド Antigravity サンドボックスにサブタスクを委任できる Toolkit) です。
  • Gemini マネージド エージェント: Google のマネージド エージェントに対する GeminiInteractions サポートを追加しました。Deep Research (引用付きの自律型リサーチ、再接続/last_event_id 再開によるバックグラウンド ストリーミング) および Antigravity (マネージド Linux サンドボックス内の汎用エージェント) です。新しい agent / agent_config / environment フィールド、エージェントごとの background および store の強制、およびエージェント パスでの mcp_servers + file_search_store_names のサポート。
  • クックブック - データ ラベル付け: テキスト、画像、オーディオ、ビデオ、ドキュメント、および合成 (審査員としての LLM、品質レビュー) ラベル付けプリミティブをカバーする 18 の自己完結型ワークフローを備えた cookbook/data_labeling/ を追加しました。
  • クックブック - Slack HITL: tool_choice="required" による構造化された一時停止、user_input エコー、stop_after_tool_call=True によるクリーンな終了を示す決定論的な Slack HITL インシデント コマンダー デモを追加しました。

改善点:

  • パス セーフティ (セキュリティ): パス セーフティを safe_join および safe_join_subpath を備えた新しい agno.utils.path_safety モジュールに集中化します。パス トラバーサル、シンボリック リンク エスケープ、制御文字インジェクション、Windows MagicDot、および Unicode 正規化攻撃に対する FileGenerationTools、SlackTools、Toolkit._check_path、agno.skills.utils.is_safe_path、および FileTools.check_escape が強化されました。 PathSecurityError が導入されました (FileGenerationSecurityError は非推奨エイリアスとして保持されます)。 requires-python を >=3.9,<4 に変更しました。
  • Parallel MCP: ParallelMCPBackend はリクエストごとに User-Agent: agno/<version> を送信するようになり、Parallel はトラフィックを agno に帰属させることができます。
  • Evals Config: 未使用の available_models フィールドを EvalsDomainConfig から削除しました。最上位の AgentOSConfig.available_models が、Evals UI ドロップダウンでサポートされる唯一のソースになりました。
  • Chonkie: Chonkie 依存関係ピンを更新しました (#7869 へのフォローアップ)。
  • クックブック: Gemini Interactions クックブック全体で gemini-3-flash-preview から gemini-3.5-flash に名前変更されました。

バグ修正:

  • AG-UI チーム: AG-UI 経由で実行しているチームが、約 7 か月間、すべての中間ストリーミング イベント (ライフサイクル、推論、ツール呼び出し、メンバーの委任) をサイレントにドロップする原因となっていたタイプミス (stream_steps → stream_events) を修正しました。
  • Slack Extra: aiohttp>=3.7.3,<4 を slack オプションの追加に追加しました — AsyncWebClient はモジュールのロード時に aiohttp をインポートするため、pip install agno[slack] はすべての Slack 操作で壊れていました。
  • Google ドライブ: GoogleDriveTools.search_files() からドライブ API incompleteSearch フラグを表示し、corpora="allDrives" の呼び出し元がドライブがすべてのドライブを検索しなかった時期を検出できるようにしました。
  • GeminiInteractions: 高度なコントロール (top_k、presence_penalty など) 用の generation_config パススルー フィールドを追加し、履歴処理を修正しました。previous_interaction_id が設定されている場合、完全な履歴を再生するのではなく、新しいターンのみが送信されます。実際にサーバー側のステートフル性を活用するようになりました。
  • Anthropic サーバー ツール: server_tool_use およびコード実行コンテンツ ブロックがメッセージ履歴に保存されるため、複数ターンのサーバー ツール フローがターンをまたいで中断されなくなりました。
  • 人為的強化: 上記のフォローアップ — 正規の redacted_thinking タイプ リテラル (SDK は redacted_reasoning_content を拒否) に切り替え、ストリーミング開始イベントで両方のスペルを受け入れ、ラウンドトリップされたサーバー ツール ブロックに重複除去ガードを追加し、強制エラーを log_warning 経由で表示できるようにし、非ブロック ツール結果項目をテキストに強制しました。
  • Gemini エラー: 一般的な Gemini エラーには、str(error) が空または弱い場合の例外タイプが含まれるようになり、invoke / invoke_stream / ainvoke / ainvoke_stream 全体でエラー コンテキストが維持されます。
  • N1N: 欠落していた n1n プロバイダー マッピングを get_model() に追加したため、Agent(model="n1n:...") モデル文字列パスが正しく解決されるようになりました。

agno v2.6.8

Highlights

  • Managed Google agents — Adds AntigravityAgent for AgentOS-hosted external agents and AntigravityTools for delegated sandbox tasks. GeminiInteractions gains Deep Research and Antigravity support, including resumable background streaming via last_event_id, mcp_servers, and file search. Worth upgrading if you need these capabilities; otherwise they are additive and can be skipped.

  • Filesystem security hardening — Centralizes validation in agno.utils.path_safety and addresses traversal, symlink escapes, control-character injection, Windows MagicDot, and Unicode normalization attacks across file, Slack, and skills tooling. Code catching filesystem security exceptions should use PathSecurityError; FileGenerationSecurityError remains a deprecated alias. Upgrade promptly if these tools process untrusted paths. Packaging now declares requires-python >=3.9,<4.

  • AG-UI and Slack reliability — Fixes stream_steps → stream_events, restoring previously dropped AG-UI Teams lifecycle, reasoning, tool-call, and delegation events. Also adds aiohttp>=3.7.3,<4 to the slack extra so pip install agno[slack] works correctly. These fixes alone justify upgrading for affected deployments.

  • Provider correctness fixes — GeminiInteractions now sends only the new turn when using previous_interaction_id, passes through generation_config, and preserves useful error context. Anthropic multi-turn server-tool flows retain required content blocks and use the canonical redacted_thinking type. Google Drive exposes incompleteSearch, and Agent(model="n1n:...") now resolves through get_model(). Users of these integrations should upgrade for correctness, not just new features.

  • Migration and upgrade verdict — Breaking change: EvalsDomainConfig.available_models was removed; move Evals dropdown configuration to AgentOSConfig.available_models. The gemini-3-flash-preview → gemini-3.5-flash rename applies only to Gemini Interactions cookbooks. The 18 data-labeling workflows and Slack HITL demo are reference material, not runtime changes. Overall, this is a substantive release worth taking for security or affected integrations; unaffected users can reasonably defer.

Changelog

New Features:

  • Antigravity: Added first-party support for Google's Antigravity API in two shapes — AntigravityAgent (a BaseExternalAgent served through AgentOS with native sessions/streaming/UI) and AntigravityTools (a Toolkit that lets any Agno agent delegate a sub-task to a managed Antigravity sandbox).
  • Gemini Managed Agents: Added GeminiInteractions support for Google's managed agents — Deep Research (autonomous research with citations, background streaming with reconnect/last_event_id resume) and Antigravity (general-purpose agent in a managed Linux sandbox). New agent / agent_config / environment fields, per-agent forcing of background and store, and support for mcp_servers + file_search_store_names on the agent path.
  • Cookbook - Data Labeling: Added cookbook/data_labeling/ with 18 self-contained workflows covering text, image, audio, video, document, and composed (LLM-as-judge, quality review) labeling primitives.
  • Cookbook - Slack HITL: Added a deterministic Slack HITL incident-commander demo showing structured pauses via tool_choice="required", user_input echo, and clean termination via stop_after_tool_call=True.

Improvements:

  • Path Safety (Security): Centralized path-safety into a new agno.utils.path_safety module with safe_join and safe_join_subpath. Hardened FileGenerationTools, SlackTools, Toolkit._check_path, agno.skills.utils.is_safe_path, and FileTools.check_escape against path traversal, symlink escape, control-char injection, Windows MagicDot, and Unicode normalization attacks. Introduced PathSecurityError (FileGenerationSecurityError kept as deprecation alias). Bumped requires-python to >=3.9,<4.
  • Parallel MCP: ParallelMCPBackend now sends User-Agent: agno/<version> on every request so Parallel can attribute traffic to agno.
  • Evals Config: Dropped the unused available_models field from EvalsDomainConfig; the top-level AgentOSConfig.available_models is now the only supported source for the Evals UI dropdown.
  • Chonkie: Updated chonkie dependency pin (follow-up to #7869).
  • Cookbook: Renamed gemini-3-flash-preview to gemini-3.5-flash across the Gemini Interactions cookbooks.

Bug Fixes:

  • AG-UI Teams: Fixed a typo (stream_steps → stream_events) that caused teams running via AG-UI to silently drop all intermediate streaming events (lifecycle, reasoning, tool calls, member delegations) for ~7 months.
  • Slack Extra: Added aiohttp>=3.7.3,<4 to the slack optional extra — AsyncWebClient imports aiohttp at module load, so pip install agno[slack] was broken for all Slack operations.
  • Google Drive: Surfaced the Drive API incompleteSearch flag from GoogleDriveTools.search_files() so corpora="allDrives" callers can detect when Drive did not search every drive.
  • GeminiInteractions: Added a generation_config passthrough field for advanced controls (top_k, presence_penalty, etc.) and fixed history handling — when previous_interaction_id is set, only the new turn is sent rather than replaying the full history. Now actually leverages server-side statefulness.
  • Anthropic Server Tools: Preserved server_tool_use and code-execution content blocks in message history so multi-turn server-tool flows no longer break across turns.
  • Anthropic Hardening: Follow-up to the above — switched to the canonical redacted_thinking type literal (the SDK rejects redacted_reasoning_content), accepted both spellings on the streaming start event, added a dedup guard on round-tripped server tool blocks, made coercion failures visible via log_warning, and coerced non-block tool-result items to text.
  • Gemini Errors: Generic Gemini errors now include the exception type when str(error) is empty or weak, preserving error context across invoke / invoke_stream / ainvoke / ainvoke_stream.
  • N1N: Added the missing n1n provider mapping in get_model() so Agent(model="n1n:...") model-string paths now resolve correctly.
