#アグノv2.7.4 #Changelog

新機能:

  • Superserve ツール: 長期実行エージェント用の Firecracker ベースのサンドボックス プラットフォームである Superserve で、エージェントが生成したコードを実行し、ファイルを管理するための SuperserveTools を追加しました。 ドキュメント を参照してください。
  • Plivo ツール: Plivo で SMS の送信、音声通話、電話番号検索を行うための PlivoTools を追加しました。 ドキュメント を参照してください。
  • The Context Company: The Context Company で実行されるエージェントを追跡するための可観測性統合が追加されました。 ドキュメント を参照してください。

改善点:

  • agno create の機能強化: インタラクティブなスターター テンプレートとプロジェクト名のプロンプト、4 つの新しいスターター (Azure、Helm、Modal、Render)、および自動 .env シード。
  • テレグラム ツール: pin_message、get_chat、get_file、react_with_emoji、さらに save_downloads と output_directory を追加して、ダウンロードしたファイルをディスクに保存します。
  • Tavily ツール: ドメイン、日付範囲、トピック、および国フィルターを検索に追加します。
  • Google ツール: Gmail、カレンダー、ドライブ、スライドにページネーションを追加します。
  • Oxylabs ツール: ページ全体のコンテンツをマークダウンとして返します。
  • ワークフロー: ルーター セレクターと条件エバリュエーターで run_context を受け入れ、session_state は非推奨になります。

バグ修正:

  • チーム:
    • 実行中に複数回一時停止するメンバーにユーザー入力を配信します。
    • メディアまたはメンバーの応答がすでに辞書になっている実行出力をシリアル化します。
  • エージェントOS:
    • チームの応答をストリーミングするときに、蓄積された実行出力をスキップします。
    • 履歴を上書きするのではなく、既存の ID を使用したセッションの作成を拒否します。
  • ワークフローとチームセッション: ゼロおよびマイナスの履歴制限を尊重します。
  • ワークフロー: ワークフローが途中で失敗した場合に、根本的なエラーを明らかにします。
  • Slack: チャネルごとにセッションの範囲を設定するため、チャネルが履歴を共有しなくなります。
  • Tavily ツール: 構成された抽出深さを適用します。
  • OpenRouter: 画像モデルから生成された画像を返します。
  • PostgresDb: コンポーネントがテーブル名をオーバーライドする場合は、create_schema=False を尊重します。
  • PubMed、Firecrawl、Spider ツール: 設定された通話ごとの結果制限を尊重します。
  • FixedSizeChunking: 重複部分がコンテンツを超える場合は、短いドキュメントを保持します。
  • CSVReader および ExcelReader: 各リーダーに独自のデフォルトの行チャンクを与えます。

agno v2.7.4

Highlights

  • Superserve sandbox tools and new integrations — SuperserveTools (PR #8584) runs agent-generated code and manages files in Superserve, a Firecracker microVM sandbox built for long-running agents — a meaningful primitive if you let agents write and execute code. Alongside it: PlivoTools (PR #8868) adds SMS, voice calls and number lookup, and The Context Company integration (PR #8955) adds run tracing.
  • Workflows: run_context supersedes session_state — Router selectors and Condition evaluators now accept run_context, while session_state is deprecated (PR #9018). If your workflows read session_state, start migrating; it still works but is on its way out.
  • Session behavior you'll notice — POST /sessions is now idempotent: creating with an existing id is rejected instead of silently overwriting history (PR #8646). Slack sessions are scoped per channel (PR #8933), so channels no longer share history, and zero/negative history limits in Workflow/Team sessions are finally honored (PR #8942). Audit code that relied on overwriting sessions or cross-channel context.
  • Team and AgentOS streaming fixes — Team SSE streams skip accumulated run outputs instead of replaying them (PR #8236); paused member runs are persisted for multi-round human-in-the-loop flows (PR #8937); and TeamRunOutput.to_dict now handles already-serialized dicts in media and member responses (PR #8966). Most relevant to multi-agent apps with HITL on AgentOS.
  • Silent data-loss and shared-state bugs fixed — FixedSizeChunking no longer drops short documents when overlap ≥ content length (PR #8943); CSV/Excel readers no longer share one mutable default RowChunking (PR #8922); and PostgresDb respects create_schema=False when components override table names (PR #7547). RAG and ingestion pipelines have concrete reasons to upgrade.
  • Google pagination: read the fine print — The changelog advertises pagination across Gmail, Calendar, Drive and Slides, but the Gmail pagination / max_results_per_request PR (#8462) was reverted in PR #9025. Don't assume Gmail paging is live in this release — verify before depending on it.

No breaking changes in this release.

Changelog

New Features:

  • Superserve Tools: Added SuperserveTools to run agent-generated code and manage files in Superserve, a Firecracker-based sandbox platform for long-running agents. See docs.
  • Plivo Tools: Added PlivoTools to send SMS, make voice calls, and look up phone numbers with Plivo. See docs.
  • The Context Company: Added an observability integration to trace agent runs with The Context Company. See docs

Improvements:

  • agno create Enhancements: Interactive starter template and project name prompts, four new starters (Azure, Helm, Modal, Render), and automatic .env seeding.
  • Telegram Tools: Add pin_message, get_chat, get_file, and react_with_emoji, plus save_downloads and output_directory to save downloaded files to disk.
  • Tavily Tools: Add domain, date range, topic, and country filters to searches.
  • Google Tools: Add pagination to Gmail, Calendar, Drive, and Slides.
  • Oxylabs Tools: Return full page content as Markdown.
  • Workflows: Accept run_context in Router selectors and Condition evaluators, deprecating session_state.

Bug Fixes:

  • Teams:
    • Deliver user input to members that pause more than once in a run.
    • Serialize run outputs whose media or member responses are already dicts.
  • AgentOS:
    • Skip accumulated run outputs when streaming team responses.
    • Reject creating a session with an existing id instead of overwriting its history.
  • Workflow & Team Sessions: Honor zero and negative history limits.
  • Workflows: Surface the underlying error when a workflow fails mid-stream.
  • Slack: Scope sessions per channel so channels no longer share history.
  • Tavily Tools: Apply the configured extract depth.
  • OpenRouter: Return generated images from image models.
  • PostgresDb: Respect create_schema=False when components override table names.
  • PubMed, Firecrawl & Spider Tools: Respect configured and per-call result limits.
  • FixedSizeChunking: Keep short documents when the overlap exceeds the content.
  • CSVReader & ExcelReader: Give each reader its own default row chunking.
