#アグノv2.5.4 #Changelog

新機能:

  • PgVector: 最小類似性スコアで検索結果をフィルタリングするための similarity_threshold パラメーターを追加しました。
  • チーム: TeamMode.tasks のストリーミング イベント サポートを追加し、自律タスクの実行中にリアルタイム イベントの発行を可能にしました。

  • メトリクス: メトリクス システムを再設計して、エージェント/チーム/ワークフローのライフサイクル全体にわたってモデルごと、コンポーネントごとの詳細な追跡を提供します。

  • SeltzTools: Seltz SDK 0.1.3 を使用するように更新されました。

  • AWS Bedrock: boto3 セッションを使用する場合、Bedrock リクエストごとに AWS 認証情報を更新するように修正されました。
  • @tool デコレータ: エージェント/チーム タイプのアノテーションで失敗しないように @tool デコレータを修正しました
  • Pydantic モデルのシリアル化: ツール キャッシュ内の Pydantic モデルのシリアル化を修正しました。

agno v2.5.4

Highlights

  • Step-level workflow HITL — Individual workflow steps can now pause for confirmation or user input, enabling approval and correction gates inside a run rather than only at workflow boundaries. Adopters should add handlers to resume paused steps (PR #6211).
  • Streaming TeamMode.tasks events — Autonomous team tasks now emit streaming events, allowing progress UIs and event-driven consumers to react before execution finishes. Review handlers that previously relied only on final outputs (PR #6622).
  • Granular lifecycle metrics — Metrics now track usage per model and per component across agents, teams, and workflows. RunMetrics replaces heavyweight RunOutput collectors, and team session metrics include member responses; custom dashboards and collectors should be checked against this new data flow (PR #6405, #6703, #6704).
  • Search result controls — PgVector adds similarity_threshold to enforce a minimum similarity score, giving retrieval callers a direct precision/recall tradeoff. DuckDuckGoTools also exposes timelimit, region, and backend for finer search tuning (PR #6216, #6650).
  • Runtime and tooling fixes — Bedrock now refreshes AWS credentials on every request when using a boto3 session, reducing failures with rotating credentials. Fixes also cover Agent/Team annotations in @tool, Pydantic serialization in the tool cache, and hook/PII guardrail hardening (PR #6657, #6610, #6678, #6483).
  • Breaking changes — None announced.

Changelog

New Features:

  • PgVector: added similarity_threshold parameter for filtering search results by minimum similarity score.
  • Team: Added streaming event support for TeamMode.tasks, enabling real-time event emission during autonomous task execution.
  • Workflows HITL: Add support for HITL in workflows at Step level to pause for confirmation and user input. See docs

Improvements:

  • Metrics: Redesigns the metrics system to provide per-model, per-component granular tracking across the entire agent/team/workflow lifecycle.
  • WebsearchTools: expose timelimit, region and backend params in DuckDuckGoTools
  • SeltzTools: Updated to use Seltz SDK 0.1.3

Bug Fixes:

  • AWS Bedrock: Fixed to refresh AWS credentials on every Bedrock request when using boto3 session.
  • @tool decorator: Fixed @tool decorator to not fail for Agent/Team type annotations
  • Pydantic model serialization: Fixed Pydantic model serialization in tool cache.
