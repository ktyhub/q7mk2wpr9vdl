#アグノv2.6.19 #Changelog

新機能:

  • チェックポイント: ツールのバッチ レベルのチェックポイントを追加し、実行の再生成とフォーク用に /continue を統合しました。セッションのフォークのサポートも追加されました。 クックブックを参照してください。
  • 動的エージェント、チーム、ワークフロー構成用の新しいツールキット StudioTool を追加します。

改善点:

  • Gemini: GeminiInteractions は遅延インポートされるようになったため、Gemini は google-genai 2.0. を必要としなくなりました。
  • PII ガードレール: custom_patterns は生の正規表現文字列を受け入れるようになりました。
  • ベクター DB: ClickHouse と Pinecone は、サポートされている検索タイプを get_supported_search_types() 経由で報告するようになりました。

バグ修正:

  • FileTools: すべてのプラットフォーム上の FileTools および関連ファイル ツールからスラッシュ パスを返します。
  • チームのキャンセル: 非同期チームの委任は、非同期キャンセル チェックを使用するようになりました。
  • AccuracyEval: None スコアを返すように空の結果を修正しました。
  • Gemini: ガイダンスの再試行では、再試行可能なエラー後の retry_with_guidance_limit が考慮されるようになりました。
  • シリアル化: 非 ASCII テキストはエスケープされずに保存されるようになりました。
  • ファイル: テキスト ファイルがセッション履歴から正しくリロードされるようになりました。
  • チーム: ネストされたチームのポストフック イベントが応答コンテンツに漏れなくなりました。
  • イベントの実行: ストリーミング コンテンツ イベントによって image フィールドがドロップされなくなりました。
  • OpenAILike: OpenAILike プロバイダーの Chat サフィックスは避けてください。
  • SentenceTransformerReranker: 提供されたクロス エンコーダーを許可します。
  • HackerNews: 正しい API フィールドからユーザー ID を読み取ります。

何が変わったのか

  • 修正（ハッカーニュース）: https://github.com/agno-agi/agno/pull/8422 の @devYRPauli による正しい API フィールドからユーザー ID を読み取る
  • [修正] https://github.com/agno-agi/agno/pull/8415 の @YankhangSIT によって提供された SentenceTransformerReranker クロス エンコーダーを許可します
  • 修正: https://github.com/agno-agi/agno/pull/8428 の @mattholy による OpenAILike プロバイダーのチャット サフィックスを回避
  • 修正: https://github.com/agno-agi/agno/pull/8493 での @kausmeows による検証

agno v2.6.19

Highlights

  • Checkpointing & dynamic composition — Added tool-batch-level checkpointing, unified /continue for regeneration and run forking, session forking, and StudioTool for dynamically composing agents, teams, and workflows. Upgrade if you need resumable tool execution or runtime composition; existing users can skip these additive features.
  • Gemini dependency fix — GeminiInteractions is lazily imported, so the main Gemini path no longer forces google-genai>=2.0.0; the changelog also reports compatibility with google-genai 2.9.0 and correct enforcement of retry_with_guidance_limit. Upgrade if dependency conflicts or retry-limit bypasses affect you.
  • Integration & data-integrity fixes — FileTools now returns forward-slash paths across platforms, text files reload correctly from session history, serialization preserves non-ASCII text, and ClickHouse/Pinecone expose get_supported_search_types(). Async team cancellation and nested post-hook event leakage are also fixed—worth upgrading if you rely on these paths.
  • Streaming & provider correctness — Streaming events no longer drop image, OpenAILike avoids adding a Chat suffix to provider names, SentenceTransformerReranker accepts supplied cross encoders, PIIDetectionGuardrail.custom_patterns accepts raw regex strings, and AccuracyEval empty results return None scores. No breaking changes or migration steps are called out; users unaffected by these fixes can safely skip this patch.

Changelog

New Features:

  • Checkpointing: Added tool batch level checkpointing and unified /continue for regenerate and forking a run. Also added support for forking sessions. See cookbooks.
  • Add a new toolkit StudioTool for dynamic agent, team , workflow composition.

Improvements:

  • Gemini: GeminiInteractions is now lazily imported, so Gemini no longer requires google-genai 2.0.
  • PII Guardrail: custom_patterns now accepts raw regex strings.
  • Vector DBs: ClickHouse and Pinecone now report their supported search types via get_supported_search_types()

Bug Fixes:

  • FileTools: Return forward-slash paths from FileTools and related file tools on all platforms.
  • Team Cancellation: Async team delegation now uses the async cancellation check.
  • AccuracyEval: Fixed empty results to return None scores.
  • Gemini: Guidance retries now respect retry_with_guidance_limit after a retryable error.
  • Serialization: Non-ASCII text is now preserved instead of being escaped.
  • Files: Text files now reload correctly from session history.
  • Teams: Nested team post-hook events no longer leak into response content.
  • Run Events: Streaming content events no longer drop the image field.
  • OpenAILike: Avoid Chat suffix for OpenAILike providers.
  • SentenceTransformerReranker: Allow supplied cross encoder.
  • HackerNews: Read user ID from the correct API field.
