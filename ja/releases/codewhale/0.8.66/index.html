コードホエール v0.8.66

CodeWhale は正規のプロジェクト、コマンド、npm パッケージであり、 リリースアセット名。従来の npm パッケージ deepseek-tui は 非推奨となり、今後のリリースはありません。からのユーザー v0.8.x のレガシー deepseek / deepseek-tui 名は移行する必要があります docs/REBRAND.md で。

インストール

推奨 — npm (1 つのコマンド、両方のバイナリ)

npm install -g codewhale

ラッパーは、一致するランタイム バイナリをこのリリースからダウンロードし、同じディレクトリに配置します。

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.66

このイメージには、codewhale ディスパッチャ、codew シム、および codewhale-tui ランタイムが同梱されています。 latest タグもリリース時に更新されます。

カーゴ (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

両方のクレートが必要です。codewhale-cli は codewhale ディスパッチャーと codew シムを生成し、codewhale-tui はディスパッチャーが委任する対話型ランタイムを生成します。クレートを 1 つだけインストールすると、実行時に MISSING_COMPANION_BINARY エラーが発生して失敗します。

手動ダウンロード — プラットフォーム アーカイブ (推奨)

以下の各アーカイブには、codewhale ディスパッチャ、codew シム、codewhale-tui ランタイムに加えて、インストール スクリプトが含まれています。 |プラットフォーム |アーカイブ |スクリプトをインストールする | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (インストーラー) | CodeWhaleSetup.exe | NSIS セットアップ | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (ポータブル) | codewhale-windows-x64-portable.zip | — | Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • インストーラー パスの場合は、CodeWhaleSetup.exe を実行します。 codewhale.exe、codew.exe、および codewhale-tui.exe を %LOCALAPPDATA%\Programs\CodeWhale\bin の下にインストールし、そのディレクトリを現在のユーザーの PATH に追加します。
  • codewhale-windows-x64.zipの抽出
  • install.bat を実行します (%USERPROFILE%\bin にコピー)
  • %USERPROFILE%\bin を PATH に追加します ポータブル Windows アーカイブはインストール スクリプトをスキップし、任意のディレクトリから抽出して実行します。 NSIS インストーラーは現在署名されていないため、署名証明書がリリース パイプラインに組み込まれるまで Windows SmartScreen をトリガーする可能性があります。 各プラットフォームには、ベア、アーカイブされていない バイナリ (codewhale-<platform>、codew-<platform>、および codewhale-tui-<platform>) が以下に添付されています。npm ラッパーとアプリ内 codewhale update は一致するランタイム バイナリをダウンロードしますが、上記の .tar.gz / .zip アーカイブは推奨される手動ダウンロードであり、さらにインストール スクリプトがバンドルされています。従来の npm パッケージ deepseek-tui は非推奨となり、再公開されません。 v0.8.x のレガシー バイナリ名からの移行については、docs/REBRAND.md を参照してください。

確認する (推奨)

このリリースからチェックサム マニフェストをダウンロードし、次のことを確認します。

sha256sum -c codewhale-bundles-sha256.txt

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt

# macOS

  • モード権限は、単一の権限を通じて承認プロンプトを解決するようになりました。 サーフェスごとのチェックではなくソース (#3795)。

修正済み

  • いつでもユーザーに表示される移行通知により、レガシー状態の再配置が表示されます ~/.deepseek/<state> は ~/.codewhale/<state> に移動またはコピーされるため、 アップグレードされたユーザーは、自分のデータが保存され、正規の状態がどこにあるかを知ることができます。 現在は生きています (#3726)。
  • アップグレードされたインストールで従来の .deepseek/sessions の表示を復元しました。 コピーすることにより、空の ~/.codewhale/sessions ディレクトリがすでに存在していました。 プライマリ CodeWhale セッション ストアにレガシー セッション エントリがありません 新しいデータを上書きせずに実行できます (#3724)。
  • 読み取り専用シェルコマンドなどの承認リスク分類を冷静にしました。 codewhale --version、codewhale --help、git status --porcelain なので モーダルは、証明された読み取り専用シェルを破壊的であるとラベル付けしなくなりました (#3730)。
  • /cache ターン テレメトリにプロバイダー/モデル ルート列を追加しました。 キャッシュヒット回帰は自動ルート変更と相関関係がある可能性があります (#3738)。
  • ランタイム API 承認処理が修正され、ワークスペース trust が自動解決されなくなりました 通常のツールの承認。 trust はフルアクセスの再試行にのみ参加するようになりました YOLO/自動承認は承認バイパスのままです (#3736)。

  • パブリッシュのようなシェルアクションのための耐久性のあるレビュー安全フロアを維持しました。 YOLO モード、つまり cargo publish、npm publish、タグ/リリースで強制的にプッシュ サイレント自動承認ではなく承認を行います (#3735)。
  • CodeWhale のターミナル入力ポンプの場所で Ctrl+O 外部エディタがフリーズする問題を修正 Vim/エディターが端末を所有している間、特に次の場合にキーを読み取り続ける可能性がありました。 Windows mintty/cygwin シェル。正確な再現 (#3657) をしてくれた @buko に感謝します。
  • 一時的な貨物レジストリ EOF に対する OHOS 依存関係ドリフト チェックを強化しました。 CI が失敗する前にディペンデンシー グラフ プローブを再試行します。

Codewhale v0.8.66

Highlights

  • Rebrand and legacy-state migration — deepseek-tui and the deepseek binaries are deprecated in favor of codewhale/codew; legacy users must follow docs/REBRAND.md. The new codewhale doctor --json (#3727) audits ~/.deepseek vs ~/.codewhale dual-root state and flags unmigrated paths, while relocation now prints a visible migration notice (#3726) and backfills missing legacy sessions without overwriting newer data (#3724). Run doctor before deleting old directories — silent history loss was the risk this closes.
  • Install paths and the companion-binary trap — npm install -g codewhale drops both binaries in one step; Cargo users must install both codewhale-cli and codewhale-tui or hit MISSING_COMPANION_BINARY at runtime. The native codew shim now ships in archives, Windows installer inputs, and checksum manifests, so manual installs match Cargo. Verify with the sha256 manifests; note the Windows NSIS installer is unsigned (expect a SmartScreen prompt) and the portable zip skips the install script entirely.
  • New providers and real context budgets — Sakana AI Fugu joins as a first-class OpenAI-compatible provider (sakana/fugu aliases, FUGU_API_KEY/SAKANA_API_KEY, harvested from #3748), alongside OpenModel as an Anthropic Messages provider (#3585). New provider-level context_window overrides (#3545) let OpenAI-compatible gateways and self-hosted backends budget against their actual model window instead of a hardcoded default — relevant if you saw premature truncation or odd cache misses behind a gateway.
  • Approval and mode behavior shifts — Auto mode is deferred from the picker, cycle, hotbar, /mode, and thread overrides until it has a distinct prompt and auto-review; existing auto config now folds back to Agent (#3730, #3733). Approvals resolve through a single authority source (#3795) and render inline/bottom-anchored (#3799); workspace trust no longer auto-resolves ordinary tool approvals (#3736), leaving YOLO/auto-approve as the only bypass — and even YOLO now force-approves cargo publish, npm publish, and tag pushes (#3735). Plan mode enforces its "no writes" promise at the turn loop (#3734), read-only commands like git status --porcelain are no longer flagged as destructive (#3730), and the Agent shell defaults to approval-gated on (#3756). Watch for automation that relied on trust-based auto-approval — it will now prompt.
  • Fleet/WhaleFlow and UI defaults — WhaleFlow-to-Fleet launch validation caps plans at 100 agents and 5 recursive rings, requires bounded loops/expands before launch, and preserves per-slot model selection; Fleet is now framed as the durable sub-agent config layer and WhaleFlow as the orchestration plan. Hotbar gains Alt+1–Alt+8 quick slots (#3796, #3788) but is hidden until you opt in (#3807). Also new: a read-only /config ask-rules view (#3569) and a typed [verifier] table with verdict_policy = "hunt" (#2093).
  • Cost, telemetry, and sub-agent throughput — The scorecard command (#3388) enables offline release gating, baseline regression checks, and per-turn cost visibility; stream-JSON exec now reports input_analysis and visible_final_answer_chars (#2956, #2957) so harnesses can measure transcript growth and answer bloat, and /cache gains provider/model route columns (#3738). CODEWHALE_TOOL_SURFACE=shell-only now hides native tools from the model-visible catalog and warns on unknown values instead of silently falling back (#2954), while sub-agent fanout and lock hot paths were reworked for parallel dispatch and off-lock disk I/O (#3783, #3801–#3805).

No breaking changes in this release.

CodeWhale is the canonical project, command, npm package, and release-asset name. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Install

Recommended — npm (one command, both binaries)

npm install -g codewhale

The wrapper downloads the matched runtime binaries from this Release and places them in the same directory.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.66

The image ships the codewhale dispatcher, codew shim, and codewhale-tui runtime. The latest tag is also updated on release.

Cargo (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Both crates are required — codewhale-cli produces the codewhale dispatcher and codew shim, while codewhale-tui produces the interactive runtime that the dispatcher delegates to. Installing only one crate will fail at runtime with a MISSING_COMPANION_BINARY error.

Manual download — platform archives (recommended)

Each archive below contains the codewhale dispatcher, codew shim, and codewhale-tui runtime, plus an install script:

| Platform | Archive | Install script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (installer) | CodeWhaleSetup.exe | NSIS setup | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portable) | codewhale-windows-x64-portable.zip | — |

Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • For the installer path, run CodeWhaleSetup.exe; it installs codewhale.exe, codew.exe, and codewhale-tui.exe under %LOCALAPPDATA%\Programs\CodeWhale\bin and adds that directory to the current-user PATH.
  • Extract codewhale-windows-x64.zip
  • Run install.bat (copies to %USERPROFILE%\bin)
  • Add %USERPROFILE%\bin to your PATH

The portable Windows archive skips the install script — extract and run from any directory. The NSIS installer is currently unsigned and may trigger Windows SmartScreen until a signing certificate is wired into the release pipeline.

Each platform also has bare, unarchived binaries attached below (codewhale-<platform>, codew-<platform>, and codewhale-tui-<platform>) — the npm wrapper and the in-app codewhale update download the matched runtime binaries, whereas the .tar.gz / .zip archives above are the recommended manual download and additionally bundle an install script. The legacy npm package deepseek-tui is deprecated and is not republished. For migration from v0.8.x legacy binary names, see docs/REBRAND.md.

# Linux — individual binaries

# macOS

  • Added WhaleFlow-to-Fleet launch-shape validation: the default Fleet workflow contract allows up to 100 total agents and 5 recursive rings, requires bounded loops/expands before launch, and preserves per-slot model selection.
  • Added a read-only /config ask-rules view for the resolved permissions.toml path, file status, rule count, and configured tool/command/path ask rules. Merged from #3569 by @greyfreedom.
  • Added provider-level context_window overrides so OpenAI-compatible gateways and self-hosted providers can budget against their real model context window (#3545).
  • Added the native codew shim to release archives, Windows installer inputs, local release-asset preparation, and checksum verification so manual installs receive the same short command that Cargo installs build.
  • Added OpenModel as a first-class Anthropic Messages provider, with config, CLI, provider picker, docs, and registry coverage. Harvested from #3585 by @noaft.
  • Added WeCom Bridge deployment and security documentation, with shipped runtime/bridge commands and approval-timeout environment guidance. Harvested from #3640 by @pkeging.
  • Added a token/cache/cost scorecard command for offline release gating, baseline regression checks, and per-turn cost visibility (#3388). Stream-JSON exec metadata now also reports conservative input_analysis and visible_final_answer_chars, so benchmark harnesses can measure transcript growth and final-answer bloat without guessing (#2956, #2957).
  • Added a release evidence ledger for v0.8.66 and opened the external ACP registry submission for CodeWhale after validating the published codewhale@0.8.65 ACP auth handshake against the upstream registry checker (#3192).
  • Added a typed [verifier] config table for the verifier-preview lane, with enabled and the shipped verdict_policy = "hunt" mapping documented and validated (#2093).
  • Added Hotbar Alt+1–Alt+8 quick-slot switching with decision-card key disambiguation, plus an introductory card that explains and can dismiss the Hotbar (#3796, #3788).
  • Release/docs hygiene: guarded public install/version snippets and the npm codewhaleBinaryVersion pointer against drift, made check-docs/check-facts fail on stale snippets or unmapped providers, and stopped sync-changelog from dropping a release when only [Unreleased] exists (#3767, #3768, #3769, #3770, #3771, #3772).

Changed

  • Deferred Auto mode from the user-facing mode picker, cycle, hotbar, /mode command, and runtime-thread mode overrides until it has a distinct prompt and auto-review behavior; existing auto mode text now folds back to Agent instead of selecting a hollow mode, and approval modal copy no longer implies the current mode is YOLO (#3730, #3733).
  • Clarified the Fleet setup surface and docs so Fleet is treated as the durable sub-agent configuration layer while WhaleFlow is the agent-authored orchestration plan that selects and monitors Fleet slots.
  • Slimmed the default Constitution prompt while keeping its required structural anchors under regression coverage, reducing the static prompt footprint for cache-sensitive turns (#2953).
  • Made the approval prompt inline and bottom-anchored instead of a full-screen takeover, so context and controls stay visible while a tool awaits a decision (#3799).
  • The Hotbar is now hidden by default until explicit setup opt-in (#3807); the interactive Agent shell also defaults to approval-gated on with a shared baseline (#3756).
  • Mode authority now resolves approval prompts through a single authority source instead of per-surface checks (#3795).

Fixed

  • Surfaced legacy state relocation with a user-visible migration notice whenever ~/.deepseek/<state> is moved or copied into ~/.codewhale/<state>, so upgraded users know their data was preserved and where the canonical state now lives (#3726).
  • Restored legacy .deepseek/sessions visibility for upgraded installs where an empty ~/.codewhale/sessions directory already existed, by copying missing legacy session entries into the primary CodeWhale session store without overwriting newer data (#3724).
  • Calmed approval risk classification for read-only shell commands such as codewhale --version, codewhale --help, and git status --porcelain so the modal no longer labels proven read-only shell as destructive (#3730).
  • Added provider/model route columns to /cache turn telemetry so DeepSeek cache-hit regressions can be correlated with Auto route changes (#3738).
  • Fixed runtime API approval handling so workspace trust no longer auto-resolves ordinary tool approvals; trust now only participates in full-access retry decisions while YOLO/auto-approve remains the approval bypass (#3736).
  • Fixed modal surfaces so the shared view stack paints an opaque backdrop before any overlay, while Plan/request-input popup interiors stay opaque and the Plan confirmation footer keeps action choices visible on narrow terminals (#3732).
  • Added a turn-loop Plan-mode guard for file-writing tools and write-capable MCP tools so Plan's "no writes" promise is enforced before approval or execution, not only by the sandbox/catalog layer (#3734).
  • Preserved the durable review safety floor for publish-like shell actions in YOLO mode, so cargo publish, npm publish, and tag/release pushes force approval instead of silently auto-approving (#3735).
  • Fixed Ctrl+O external-editor freezes where CodeWhale's terminal input pump could keep reading keys while Vim/editor owned the terminal, especially in Windows mintty/cygwin shells. Thanks @buko for the precise repro (#3657).
  • Hardened the OHOS dependency drift check against transient Cargo registry EOFs by retrying the dependency graph probe before failing CI.
  • Updated the /links provider fallback to the current CodeWhale docs URL and added a Baidu Qianfan docs link. Harvested from #3621 by @noaft.
  • Hardened CODEWHALE_TOOL_SURFACE=shell-only for benchmark/exec runs: the shell-only surface hides native tools from the model-visible catalog, and unknown CODEWHALE_TOOL_SURFACE values now warn instead of silently falling back to the full tool surface (#2954).
  • Sub-agent fanout and lock hot paths: preserved event-channel headroom for progress events (#3783, thanks @cyq1017), let independent sub-agent starts join a single parallel dispatch batch instead of serializing (#3801), rendered the sub-agent sidebar/ListSubAgents from a read-only snapshot with bounded cleanup (#3803), used nonblocking best-effort sends for ListSubAgents refresh while still awaiting critical events (#3802), moved sub-agent state persistence disk I/O off the manager write lock (#3805), and used try_lock for shell-manager refresh in async UI paths (#3804).
  • Provenance: runtime continuations and SubAgentHandoff now inherit standing YOLO authority, while MemoryRecall, ImportedTranscript, and AssistantGenerated inputs remain guarded (#3817).
  • Approval honesty: labeled session-scoped approvals accurately instead of "always", and surfaced approval decisions in tool results (#3766).
