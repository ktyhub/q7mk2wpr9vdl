Codewhale v0.9.13

Highlights

  • Rebrand and binary-name migration — The public product is now Codewhale, and the legacy npm package deepseek-tui is deprecated with no further releases. Anything pinned to v0.8.x deepseek/deepseek-tui names must migrate via docs/REBRAND.md; the codewhale-tui-<platform> assets shipped since v0.9.5 are byte-identical compatibility copies meant only to let v0.9.4 clients cross the single-binary transition, not a third runtime. Mainstream channels install both codewhale and codew, but Cargo (cargo install codewhale-cli --locked) installs only codewhale — you must add a codew symlink yourself. codewhale update keeps newer builds; an occupied install directory needs the fresh-directory procedure in INSTALL.md.

  • /pet takes over the viewport; the Watch panel is gone — /pet (or /pet on) now claims the full content viewport on every accepted turn, shows what the Engine is doing, and reveals the answer/error on completion; Escape returns to the composer without cancelling, and /pet off stops automatic entry while the durable companion stays alive. This is a breaking UI change: the workbar pet, the Watch panel, and /workbar watch were removed (#6109, #6110), so scripts or workflows wired to them need to move to /pet.

  • DeepSeek V4.1 Flash is the default; reasoning and context budgets change — deepseek-flash becomes the default DeepSeek model, and reasoning-capable routes keep reasoning out of the user-visible answer even when the model id carries no version number — watch this if you parse streaming output. Custom and gateway providers can override context limits per exact model (#6108), so changing models also changes the meter and compaction budget, and clock-based DeepSeek pricing now shows the live peak/off-peak tier beside session cost. Automatic compaction also runs quietly from live context pressure, preserving the current task and recent tool exchanges, saving history and handoff before replacement, and retaining the conversation if compaction fails or is canceled (#5620, #6047).

  • Sub-agent and workflow hardening for multi-agent builders — Operate can run structured workflows with named phases, Fleet model assignments, prerequisite results and shared budgets; independent steps run together, dependent work waits on gates, and detached runs hand outcomes back to the owning conversation. On the delegation side, malformed/unreadable/duplicate saved profiles now fail before any child request and never silently fall back to the parent's route (#6117), delegation depth stays absolute through profiles and continuations, per-call token/step/time limits only narrow inherited limits, declared output files are validated, overlapping writers get real conflict details, and read-only shell analysis requires an enforcing native sandbox. Completion receipts now carry measured worker/descendant token usage and count each continuation once.

  • Integrity fixes for terminal, ACP and MCP clients — For regressions introduced in 0.9.12 that matter to automation: multiline paste is a single paste again, truncated tool arguments can no longer execute, strict ACP clients reconnect, and concurrent instances stop clobbering each other's queued text. /mcp reload no longer freezes the UI during reconnects, and the model-facing start tool can reconnect an existing configured name after login without rotating its credential key or restarting healthy siblings (#6030) — a decreasing token-expiry countdown no longer looks like a new login from another session.

  • Computer Use 0.3.1 ships as a notarized Mac app — It's a separate download from codewhale.net/computer-use or the v0.3.1 release, with the bundled plugin and first-party marketplace pinning the same sources so app, plugin and /mcp agree. The accessibility-first pointer no longer steals focus when you switch apps mid-action, background typing/scrolling/selection use semantic input, and screenshots stay scoped to the target app. A registered macOS helper stays in charge via Pause/Stop, and a missing helper now errors instead of silently bypassing those controls. Note the NSIS installer is still unsigned (SmartScreen prompts), and plugin trust/automation deletion now require confirmation bound to the exact reviewed content (#6039).

Codewhale is the public product from Shannon Labs. The codewhale command, npm package, and release-asset names remain lowercase technical identifiers. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Fixed

  • Five of the load-flaky tests tracked in #5929 no longer depend on shared state or live local daemons. Background-hook capture tests wait for the capture file to hold bytes instead of merely existing (the shell's > redirection creates the file empty before cat writes, which read as valid JSON: EOF under load); the session-picker acceptance test drives the real picker over a private store instead of a process-global CODEWHALE_HOME redirect that concurrent tests could observe mid-flight; the DeepSeek-Anthropic translate test holds the test env barrier so its request-time and assertion-time max_tokens reads cannot straddle another test's CODEWHALE_MAX_OUTPUT_TOKENS override; the unit-test binary no longer probes a real local Ollama daemon (127.0.0.1:11434) from the fire-and-forget provider catalog refresh, whose merged tags could flip another test's live-snapshot assertions; and the tmux clipboard test's attach/OSC 52 wait bounds tolerate a fully loaded machine (3s -> 30s) without changing what they verify (#5929).
