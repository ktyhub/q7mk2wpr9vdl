何が変わったのか

  • 修正: https://github.com/continuedev/continue/pull/11804 の @RomneyDa によって Groq プロバイダーから Llama 3.1 405B を削除
  • 修正: https://github.com/continuedev/continue/pull/11801 の @RomneyDa による YAML 完了オプション スキーマに keepAlive を追加
  • 修正(llama.cpp): https://github.com/continuedev/continue/pull/11803の@RomneyDaによる完了リクエスト本文にモデル名を含める
  • 修正 (ムーンショット): https://github.com/continuedev/continue/pull/11806 の @RomneyDa により、キミ モデルのreasoning_content フィールドのサポートを追加
  • 修正: https://github.com/continuedev/continue/pull/11807 の @RomneyDa による YAML モデル構成の contextLength を尊重します。
  • fix(gemini): https://github.com/continuedev/continue/pull/11805 の @RomneyDa による順序付けエラーを修正するために、連続する同じ役割のメッセージをマージします。
  • 雑用: プレリリースで jb 64 がバンプ、コード 35 が https://github.com/continuedev/continue/pull/11834 の @RomneyDa により修正
  • 修正: https://github.com/continuedev/continue/pull/11836 の @RomneyDa による不要なリクエストを減らすために Ollama /api/show を遅延ロードする
  • 修正: デフォルトでインストールをスキップせず、https://github.com/continuedev/continue/pull/11837 で @RomneyDa によるロック ファイルを同期する
  • chore(deps-dev): https://github.com/continuedev/continue/pull/11838 の @dependabot[bot] により、ピコマッチを /extensions/cli の 2.3.1 から 2.3.2 にバンプします
  • 雑用(deps): https://github.com/continuedev/continue/pull/11839の@dependabot[bot]により、/packages/hub内のyamlを2.8.1から2.8.3にバンプします
  • chore(deps-dev): https://github.com/continuedev/continue/pull/11840 の @dependabot[bot] により、/packages/hub 内の 2.3.1 から 2.3.2 にピコマッチをバンプします
  • chore(deps): https://github.com/continuedev/continue/pull/11842 の @dependabot[bot] によるピコマッチを 2.3.1 から 2.3.2 にバンプします
  • 特技: https://github.com/continuedev/continue/pull/11809 の @RomneyDa による応答 API をオプトアウトする useResponsesApi オプションを追加
  • chore(deps-dev): https://github.com/continuedev/continue/pull/11849 の @dependabot[bot] による /packages/ continue-sdk/typescript でピコマッチを 2.3.1 から 2.3.2 にバンプします
  • chore(deps-dev): https://github.com/continuedev/continue/pull/11850 の @dependabot[bot] により、/packages/terminal-security でピコマッチを 4.0.3 から 4.0.4 にバンプします
  • chore(deps-dev): https://github.com/continuedev/continue/pull/11846 の @dependabot[bot] により、/packages/fetch でピコマッチを 2.3.1 から 2.3.2 にバンプします
  • 修正: https://github.com/continuedev/continue/pull/11852 の @RomneyDa により、MCP ツールの引数がスキーマ文字列タイプと一致するように強制されました。
  • 修正: https://github.com/continuedev/continue/pull/11847 の @RomneyDa によるコンテンツではなく、reasoning-delta をreasoning_content にマップしました。
  • chore(deps-dev): https://github.com/continuedev/continue/pull/11844 の @dependabot[bot] により、/packages/config-yaml でピコマッチを 2.3.1 から 2.3.2 にバンプします
  • chore(deps): https://github.com/continuedev/continue/pull/11845 の @dependabot[bot] により、/packages/openai-adapters で yaml を 2.8.2 から 2.8.3 にバンプします
  • 修正: https://github.com/continuedev/continue/pull/11853 の @RomneyDa による config.yaml で同じタイプの複数のコンテキスト プロバイダーを許可します
  • chore(deps): https://github.com/continuedev/continue/pull/11855 の @dependabot[bot] により、/gui でピコマッチを 2.3.1 から 2.3.2 にバンプします
  • chore(deps): https://github.com/continuedev/continue/pull/11859 の @dependabot[bot] により、/packages/ continue-sdk で yaml を 2.8.1 から 2.8.3 にバンプします
  • feat(openrouter): https://github.com/continuedev/continue/pull/11857 の @RomneyDa によってアプリを識別するために HTTP-Referer ヘッダーと X-Title ヘッダーを送信します。
  • chore(deps-dev): https://github.com/continuedev/continue/pull/11860 の @dependabot[bot] により、/docs 内のピコマッチを 2.3.1 から 2.3.2 にバンプします
  • chore(deps): https://github.com/continuedev/continue/pull/11862 の @dependabot[bot] により、/packages/config-yaml で yaml を 2.8.2 から 2.8.3 にバンプします
  • 修正: https://github.com/continuedev/continue/pull/11215 の @guoyi-smh による非無料トライアル モデルの CLI 無料トライアル ポーリングを停止
  • 修正: https://github.com/continuedev/continue/pull/11869 の @RomneyDa によるツール命令の散文からインライン バックティック フェンスを削除
  • 修正: JetBrains リリース アーティファクト ステップで複数の zip ファイルを処理 (https://github.com/continuedev/continue/pull/11873 の @RomneyDa による)
  • 修正: https://github.com/continuedev/continue/pull/11874 の @RomneyDa による空の思考コンテンツの思考インジケーターを非表示にしました
  • 修正 (openrouter): Gemini 3 ツールのサポート、サフィックス ストリッピング、thought_signature、https://github.com/continuedev/continue/pull/11856 の @RomneyDa によるオートコンプリート エンドポイント
  • 修正: https://github.com/continuedev/continue/pull/11863 で @RomneyDa によってオートコンプリートで読み取られたリスナー リークと冗長ファイルを修正
  • ドキュメント: @RomneyDa による Ollama メモリ エラーのトラブルシューティングを https://github.com/continuedev/continue/pull/11864 に追加
  • ドキュメント: https://github.com/continuedev/continue/pull/11865 の @RomneyDa によってシークレットがどこからテンプレート化できるかを明確にします
  • 修正: https://github.com/continuedev/continue/pull/11866 の @RomneyDa による思考モデルがテキスト コンテンツを返さない場合にツール呼び出しを保持する
  • 修正: @RomneyDa による xAI/Gemini の無効なキーを https://github.com/continuedev/continue/pull/11854 に入力した後、API キーを修正できるようにしました。
  • 修正: Ollama が https://github.com/continuedev/continue/pull/11870 の @RomneyDa によるツール呼び出しの解析に失敗した場合に実用的なエラーを表示
  • 修正: vLLM プロバイダーはユーザー設定の contextLength と https://github.com/continuedev/continue/pull/11868 の @RomneyDa によるモデルを尊重する必要があります
