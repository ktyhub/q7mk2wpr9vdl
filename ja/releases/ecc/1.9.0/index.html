ECC v1.9.0

ハイライト

ECC Tools Pro が公開されました。 GitHub アプリには、プライベート リポジトリ分析、月 50 件の分析、AgentShield 支援スキャンの Pro レベル (1 シートあたり月額 19 ドル) での Stripe 課金が含まれています。パブリック リポジトリの無料利用枠は引き続き 10 分析/月です。 github.com/apps/ecc-tools でインストールし、ecc.tools/pricing でアップグレードします。 選択インストールはこちらです。 --with および --without フラグを使用して必要なものだけをインストールします。 ecc install --profile developer --with lang:typescript --with agent:security-reviewer --without skill:continuous-learning。エージェントとスキルのコンポーネント ファミリがインストール マニフェストに含まれるようになりました。 12 の言語エコシステム。 C#、Rust、Java、Kotlin、C++、Go、Python、TypeScript、Perl、PyTorch、Nuxt 4、および Flutter には、専用のルール、エージェント、またはスキルが追加されました。 AgentShield v1.4.0 は同梱されています。 誤検知スキャンが修正されました。 CVE データベースには 25 以上の既知の MCP 脆弱性があります。サプライチェーンの検証。ランタイム監視。ウォッチモード。 PR セキュリティゲート。組織全体のポリシーの適用。 https://github.com/user-attachments/assets/eece2c76-7eb9-4865-a58b-f11247fd774e

新機能

エージェント (合計 28 名、+9 名が新規)

  • typescript-reviewer — TypeScript/JavaScript コードレビュー
  • pytorch-build-resolver — PyTorch ビルド エラーの解決
  • java-build-resolver — Maven/Gradle ビルド解像度
  • java-reviewer — Java コードレビュー
  • rust-reviewer — Rust コードレビュー
  • flutter-reviewer — Flutter/Dart コードのレビュー
  • harness-optimizer — クロスハーネスの最適化
  • kotlin-build-resolver — Kotlin ビルド解像度
  • kotlin-reviewer — Kotlin コードレビュー

スキル (合計 116、+15 新規)

  • pytorch-patterns — PyTorch のベスト プラクティス
  • nuxt4-patterns — Nuxt 4 フロントエンド パターン
  • codebase-onboarding — 新しい貢献者のオンボーディング
  • architecture-decision-records — ADR ワークフロー
  • agent-eval — コーディング エージェントの直接比較
  • documentation-lookup — ドキュメント検索パターン
  • bun-runtime — Bun ランタイム パターン
  • nextjs-turbopack — Next.js ターボパック パターン
  • さらに 7 つの言語固有のスキルを追加

ルール (6 つの新しい言語パック)

  • C# (コーディングスタイル、パターン、セキュリティ、テスト、フック)
  • Rust、Java、C++、Perl 言語ルール
  • フラッター/ダーツのルール

インフラストラクチャ

  • --with/--without CLI フラグを使用した選択的インストール
  • 遅延読み込みによるエージェントの説明の圧縮
  • 繰り返し発生する障害パターンを検出するためのスキル検査ロジック
  • ガバナンスイベントキャプチャフック
  • 自動再接続を備えた MCP ヘルスチェック フック
  • セッション/スキル/意思決定追跡のための SQLite 状態ストア
  • 正規スナップショット用のセッション アダプター
  • Codex 同期は AGENTS.md を置き換えるのではなくマージします

バグ修正

  • Windows CI が完全にグリーン (38 個のマトリックス ジョブがすべて合格)
  • SessionStart ANSI エスケープ コードのサニタイズ
  • スロットルによるオブザーバーのメモリ爆発
  • Windows での Flaky Observer bash テストがスキップされました
  • カタログ数の検証が修正されました
  • プラグインルート自動検出フォールバック

ECC ツール アプリ

  • Stripe ライブ請求 (Pro $19/シート、エンタープライズ連絡先)
  • GitHub OAuth チェックアウト フロー
  • アナライザーの品質の向上 (7 件の爬虫類の発見が修正されました)
  • べき等性による重複 PR 防止
  • 管理リポジトリの自動分析スキップリスト
  • プッシュのクールダウンが 7 日間に延長されました

AgentShield (v1.4.0)

  • 誤検知の修正: 拒否ルールとブロックフックが脅威としてフラグ付けされなくなりました
  • 25 以上の既知の MCP 脆弱性を含む CVE データベース
  • MCP ツールの説明 ポイズニング検出 (5 つの新しいルール)
  • 設定ドリフト検出による連続スキャン (--watch モード)
  • ツール呼び出しの実行時監視デーモン
  • MCP npm パッケージのサプライ チェーン検証
  • PR セキュリティ ゲートとベースライン比較
  • 組織全体のセキュリティ ポリシーの適用
  • CLAUDE.md ファイルシステムの権限チェック
  • 1,609 件のテストに合格

統計

  • v1.8.0 以降、219 件のコミット
  • 30 名以上の貢献者
  • 88,000 個以上の GitHub スター
  • すべてのプラットフォームにわたって 1,540 以上のテストに合格

ECC v1.9.0

Highlights

ECC Tools Pro is live. The GitHub App now has Stripe billing with a Pro tier ($19/seat/month) for private repo analysis, 50 analyses/month, and AgentShield-backed scanning. Free tier remains at 10 analyses/month for public repos. Install at github.com/apps/ecc-tools, upgrade at ecc.tools/pricing.

Selective install is here. Install only what you need with --with and --without flags. ecc install --profile developer --with lang:typescript --with agent:security-reviewer --without skill:continuous-learning. Agent and skill component families are now in the install manifest.

12 language ecosystems. C#, Rust, Java, Kotlin, C++, Go, Python, TypeScript, Perl, PyTorch, Nuxt 4, and Flutter now have dedicated rules, agents, or skills.

AgentShield v1.4.0 ships alongside. False positive scanning fixed. CVE database with 25+ known MCP vulnerabilities. Supply chain verification. Runtime monitoring. Watch mode. PR security gate. Org-wide policy enforcement.

https://github.com/user-attachments/assets/eece2c76-7eb9-4865-a58b-f11247fd774e

  • Plugin root auto-detection fallback

ECC Tools App

  • GitHub OAuth checkout flow
  • Analyzer quality improvements (7 greptile findings fixed)
  • Duplicate PR prevention with idempotency
  • Auto-analysis skip list for managed repos
  • Push cooldown increased to 7 days

  • CVE database with 25+ known MCP vulnerabilities
  • MCP tool description poisoning detection (5 new rules)
  • Continuous scanning with config drift detection (--watch mode)
  • Runtime monitoring daemon for tool calls
  • Supply chain verification for MCP npm packages
  • PR security gate with baseline comparison
  • Organization-wide security policy enforcement
  • CLAUDE.md filesystem permission check
  • 1,609 tests passing
