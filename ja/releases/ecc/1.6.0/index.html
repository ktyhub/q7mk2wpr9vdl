ECC v1.6.0

ECC v1.6.0 — コーデックス版

** 309 コミット。 30 のコミュニティ PR が統合されました。検査数は978件。 4 つのプラットフォーム** Claude Code のすべてが Claude Code、Cursor、OpenCode、Codex をサポートするようになりました。これは、単一の構成ソースからのすべての主要な AI コーディング ツールです。

https://github.com/user-attachments/assets/f2959480-42a0-4068-85f5-4e6e78c938a7

ハイライト

  • コーデックス サポート - 新しい codex-setup コマンドおよび命令ジェネレーターを介した OpenAI Codex CLI との完全な互換性
  • 7 つの新しいスキル — analyze-repo、skill-creator、instinct-creator、hook-creator、workflow-discovery、pattern-detection、learning-dna
  • AgentShield 統合 — すべての保護層にわたる 102 のセキュリティ ルール、912 のテスト
  • GitHub マーケットプレイス — github.com/marketplace/ecc-tools にリストされ、インストール可能です。
  • プロモーション ビデオ — 実際のデモ映像を使用したプロフェッショナル Remotion レンダリングの 1080p プロモーション

新しいコマンド

|コマンド |説明 | |----------|---------------| | /codex-setup | OpenAI Codex CLI 用に ECC を構成する | | /skill-creator | AI を活用したリポジトリ分析からのスキル生成 | | /instinct-creator |リポジトリ パターンから本能を作成する | | /hook-creator |会話分析からフックを生成 | | /update-codemaps |コードベース マップを自動生成 | | /update-docs |ドキュメントをコードの変更と同期する |

バグ修正

  • エージェント数の表示を修正 (15→13 アクティブエージェント)
  • スキル数固定（32→43スキル）
  • コマンド数固定（30→31コマンド）
  • すべてのドキュメントの貢献者数を修正しました
  • いくつかのスキル出力におけるマークダウンレンダリングを修正しました
  • Codex 統合とのフック権限の競合を解決しました

コミュニティ

  • このリリース サイクルで 30 のコミュニティ PR が統合されました
  • PR #268、#265 が統合されました。 #272、#271 閉店
  • 10 を超える未解決の問題に関する活発なディスカッション
  • 44 人の貢献者全員に感謝します

ECC v1.6.0

ECC v1.6.0 — Codex Edition

309 commits. 30 community PRs merged. 978 tests. 4 platforms.

Everything Claude Code now supports Claude Code, Cursor, OpenCode, and Codex — every major AI coding tool from a single config source.

https://github.com/user-attachments/assets/f2959480-42a0-4068-85f5-4e6e78c938a7

Highlights

  • Codex Support — Full compatibility with OpenAI Codex CLI via new codex-setup command and instructions generator
  • 7 New Skills — analyze-repo, skill-creator, instinct-creator, hook-creator, workflow-discovery, pattern-detection, learning-dna
  • AgentShield Integration — 102 security rules, 912 tests across all protection layers
  • GitHub Marketplace — Listed and installable at github.com/marketplace/ecc-tools
  • Promo Video — Professional Remotion-rendered 1080p promo with real demo footage

New Commands

| Command | Description | |---------|-------------| | /codex-setup | Configure ECC for OpenAI Codex CLI | | /skill-creator | AI-powered skill generation from repo analysis | | /instinct-creator | Create instincts from repository patterns | | /hook-creator | Generate hooks from conversation analysis | | /update-codemaps | Auto-generate codebase maps | | /update-docs | Sync documentation with code changes |

Bug Fixes

  • Fixed agent count display (15→13 active agents)

  • Fixed command count (30→31 commands)
  • Corrected contributor count across all docs
  • Fixed markdown rendering in several skill outputs
  • Resolved hook permission conflicts with Codex integration

Community
