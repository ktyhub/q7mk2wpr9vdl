ECC v1.0.0

🚀 クロードコードプラグインとして利用可能になりました

単一のコマンドでインストールします。

/plugin marketplace add affaan-m/everything-claude-code
/plugin install everything-claude-code@everything-claude-code

または、~/.claude/settings.json に追加します。

{
  "extraKnownMarketplaces": {
    "everything-claude-code": {
      "source": { "source": "github", "repo": "affaan-m/everything-claude-code" }
    }
  },
  "enabledPlugins": {
    "everything-claude-code@everything-claude-code": true
  }
}

含まれるもの

|コンポーネント |カウント | |----------|----------| | エージェント | 9 つの特殊なサブエージェント | | スキル | 11 のワークフロー定義 | | コマンド | 11 個のスラッシュ コマンド | | フック | 10 の自動化 | | ルール | 6つのガイドラインセット |

このリリースの新機能

  • プラグイン パッケージング - コレクション全体を数秒でインストールします
  • メモリ永続フック - コンテキストはセッション間でも存続します
  • 戦略的圧縮 - 論理境界での手動 /compact
  • 継続的な学習 - セッションからパターンを自動抽出
  • 検証ループ - チェックポイントと評価のワークフロー

  • 短縮ガイド (6.1K ❤️)
  • 長編ガイド ワークフローに役立つ場合は、スター ⭐ を付けてください。

ECC v1.0.0

Highlights

  • Plugin-based distribution — v1.0.0 ships as a Claude Code plugin, so adoption is now a two-command flow (/plugin marketplace add affaan-m/everything-claude-code, then /plugin install everything-claude-code@everything-claude-code) rather than cloning a repo and hand-copying config. For teams, the extraKnownMarketplaces + enabledPlugins stanza in ~/.claude/settings.json is the more durable path: it lives in dotfiles and pins the whole toolchain declaratively. The trade-off is that updates now arrive via Claude Code's plugin manager, so you'll want to review or pin versions instead of silently tracking upstream.

  • Memory persistence hooks — 10 hooks include context that survives across sessions, which changes the adoption mental model: you no longer need to re-prime the agent with project conventions at every start. Watch out that "auto-remembered" context is real state written to disk — review it periodically and keep secrets out of early sessions, since anything the hooks capture can be replayed later.

  • Strategic compaction over automatic compaction — The release deliberately pushes manual /compact at logical boundaries instead of letting context window summarization fire whenever Claude Code decides. For developers this is a control win: compacting between phases (e.g., after research, before implementation) preserves decisions that an untimely auto-compaction would flatten. It does mean you own the discipline of choosing those boundaries on long-running sessions.

  • Continuous learning — Sessions are mined automatically for reusable patterns, which over time grows the effective skill/rule set beyond the shipped 9 agents, 11 skills, 11 commands, 10 hooks, and 6 rules. Treat the generated output as a proposal, not gospel: review anything promoted into shared rules before it becomes a team-wide convention, or you'll encode one session's one-off decisions as policy.

  • Verification loops — Checkpoint and eval workflows add an explicit verify step between "agent says it's done" and actually calling it done — the most useful addition here for anyone running agents autonomously. Expect slightly longer task cycles in exchange for a catch point before bad output lands; wire these into CI-style checks if you want the eval gate to be enforceable rather than advisory.

  • No breaking changes are noted in this release.

🚀 Now Available as a Claude Code Plugin

Install with a single command:

/plugin marketplace add affaan-m/everything-claude-code
/plugin install everything-claude-code@everything-claude-code

Or add to your ~/.claude/settings.json:

{
  "extraKnownMarketplaces": {
    "everything-claude-code": {
      "source": { "source": "github", "repo": "affaan-m/everything-claude-code" }
    }
  },
  "enabledPlugins": {
    "everything-claude-code@everything-claude-code": true
  }
}
