キャリアオプス キャリアオプス-v1.34.0

<!-- co:release-notes:career-ops-v1.34.0 -->

これは、私がキャリアオプスにフルタイムで取り組み始めて以来、初めてのリリースです。更新プロンプトは、新しいバージョンが実際にリリースされた場合にのみ表示されるようになりました。これまでは、main に変更が加えられると、ほとんどの場合、毎日この変更がトリガーされる可能性がありました。このリリースには 63 名からの作品も掲載されており、そのうち 43 名が初めて貢献しました。

ハイライト

  • 新しいバージョンに対してのみ更新プロンプトを表示します。 update-system.mjs は、main の代わりに最新の公開リリースをインストールします。check は、新しいリリースが存在する場合にのみ尋ね、「いいえ」と答えると、永久ではなく次のバージョンまで続きます。 main の追跡は、--channel main でも引き続き利用できます。 #3845 の @obielin のリリース解像度に基づいて構築されています。
  • クローズ済みとしてマークされたライブオファーが減少しました。 Liveness は、パブリック API を介して Greenhouse gh_jid、SmartRecruiters、Arbeitsagentur、および We Work Remotely を使用して企業ページをチェックするようになり (#4444)、iframe に ATS をロードする採用ページはデッド ポスティングとして読み取られなくなりました (#4439) (どちらも @luochen211 による)。
  • より鮮明なスキャン。 @vaishaldsouza によるアグリゲーターの再投稿のドメイン レベルの検出 (#4263)、@Zoubeir23 による空の場所でフェイル クローズされるオプトインの厳密な場所フィルター (#4033)、ドメイン全体をカバーできるブラックリスト行 (#4169)、および単一の成功応答なしでポータルがジョブを返さない場合の警告 (#4441)、両方とも@luochen211。
  • 新しいソース。 @lasithadilshan による Python.org 求人プロバイダー (#4173)、@ConnorCloze によるゼネラリスト世界掲示板プロバイダー (#4100)、および @duathron (#4001) による明示的な Personio テナント ピン、これら 3 つはすべて最初の寄稿です。

更新中

エージェントは、次のセッションの開始時にこのアップデートを提供します。以前に更新プロンプトを解除したことがある場合は、これを 1 回実行して更新プロンプトを取得します。

node update-system.mjs apply --confirm

新規インストール: npx @santifer/career-ops init。

career-ops career-ops-v1.34.0

<!-- co:release-notes:career-ops-v1.34.0 -->

This is the first release since I started working on career-ops full time. The update prompt now shows up only when a new version is actually out. Until now, almost any change landing on main could trigger it, often every day. This release also carries work from 63 people, 43 of them contributing for the first time.

Highlights

  • Update prompts only for new versions. update-system.mjs installs the latest published release instead of main, check asks only when a newer release exists, and saying no lasts until the next version instead of forever. Tracking main stays available with --channel main. Built on @obielin's release resolution in #3845.
  • Fewer live offers marked as closed. Liveness now checks company pages with a Greenhouse gh_jid, SmartRecruiters, Arbeitsagentur and We Work Remotely through their public APIs (#4444), and a careers page that loads its ATS in an iframe is no longer read as a dead posting (#4439), both by @luochen211.
  • Sharper scans. Domain-level detection of aggregator reposts by @vaishaldsouza (#4263), an opt-in strict location filter that fails closed on empty locations by @Zoubeir23 (#4033), blacklist rows that can cover a whole domain (#4169), and a warning when a portal returns zero jobs without a single successful response (#4441), both by @luochen211.
  • New sources. A Python.org Jobs provider by @lasithadilshan (#4173), a generalist-world board provider by @ConnorCloze (#4100) and an explicit Personio tenant pin by @duathron (#4001), all three first contributions.

Updating

Your agent offers this update at the start of your next session. If you declined an update prompt before, run this once to pick it up:

node update-system.mjs apply --confirm

New installs: npx @santifer/career-ops init.
