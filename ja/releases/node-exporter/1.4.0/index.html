node_exporter v1.4.0

ノードエクスポーター v1.4.0

  • [変更] テキストファイルコレクター #2475 でメトリクスの説明をマージ
  • [機能] [node-mixin] mixin に Darwin ダッシュボードを追加 #2351
  • [機能] Linux 上の CPU コレクターに「分離」メトリックを追加 #2251
  • [機能] cgroup サマリー コレクター #2408 を追加
  • [機能] selinux コレクター #2205 を追加
  • [機能] スラブ情報コレクター #2376 を追加
  • [機能] sysctl コレクター #2425 を追加
  • [機能] OpenBSD システムの CPU スピン時間も追跡します #1971
  • [機能] MacOS バージョン #2471 のサポートを追加
  • [機能強化] [node-mixin] 不足しているセレクターを追加 #2426
  • [機能強化] [node-mixin] 現在のデータソースを grafana のデフォルト #2281 に変更します
  • [機能強化] [node-mixin] ディスク グラフをディスク テーブル #2364 に変更
  • [機能強化] [node-mixin] IO 時間単位を %util に変更 #2375
  • [機能強化] *bsd #2266 の user_wired_bytes および landry_bytes の広告
  • [機能強化] darwin #2240 の vm_stat メモリ メトリクスを追加
  • [機能強化] ARP コレクター #2254 にデバイス フィルター フラグを追加します。
  • [機能強化] デバイス フラグを含むディスク統計と除外するディスク統計を追加 #2417
  • [機能強化] node_softirqs_total メトリクス #2221 を追加
  • [機能強化] rapl ゾーン名ラベル オプション #2401 を追加
  • [機能強化] slabinfo コレクター #1799 を追加
  • [機能強化] ユーザーが NTP サーバー上のポートを選択して #2270 をクエリできるようにします
  • [機能強化] コレクター/ディスク統計: udev #2404 からラベルとメトリックを追加
  • [機能強化] 古い macOS SDK #2327 に対するビルドを有効にする
  • [機能強化] qdisk-linux: インターフェイス名 #2432 の除外フラグと包含フラグを追加
  • [機能強化] systemd: systemd マイナー バージョン #2282 を公開する
  • [機能強化] tcpstat コレクター #2322 にネットリンクを使用する
  • [機能強化] netlink を使用して netdev 統計を取得する #2074
  • [機能強化] 停止したフロントエンド/バックエンド サイクル用のパフォーマンス カウンターを追加 #2191
  • [機能強化] btrfs デバイス エラー統計 #2193 を追加
  • [バグ修正] [node-mixin] fsSpaceAvailableCriticalThreshold と fsSpaceAvailableWarning #2352 を修正
  • [バグ修正] ethtool コレクターの同時実行の問題を修正 #2289
  • [バグ修正] netdev コレクターの同時実行の問題を修正 #2267
  • [バグ修正] セクター サイズが異なるディスクの diskstat の読み取りおよび書き込みメトリクスを修正 #2311
  • [バグ修正] 非推奨警告 #2292 によって壊れた MacOS の iostat を修正
  • [バグ修正] NodeFileDescriptorLimit アラート #2340 を修正
  • [バグ修正] rapl ゾーン名をサニタイズ #2299
  • [バグ修正] テスト #2447 で安全に閉じるファイル記述子を追加
  • [バグ修正] os_release.go の競合状態を修正 #2454
  • [バグ修正] パスが欠落している場合は ZFS IO メトリクスをスキップ #2451
