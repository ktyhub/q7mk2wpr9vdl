#フォトクラフトv0.11.1

何が変わったのか

  • perf(canvas): プロパティ パネルの調整ドラッグによりビューのみが更新されます。4.2 倍高速 (#6839) by @skylartaylor in https://github.com/storytold/photocraft/pull/7155
  • Linux: https://github.com/storytold/photocraft/pull/7168 の @Higgs32584 による、ファイルを xdg-open に渡さないことを明らかにする (#7166)
  • スタック モード: 尖度と歪度は Windows と Linux で同じビットを与えます (https://github.com/storytold/photocraft/pull/7126 の @dotCooCoo により)
  • コンテンツに応じた塗りつぶしワークスペース (https://github.com/storytold/photocraft/pull/2376 の @Unemars による Photoshop と同様)
  • perf(stack): 統計ごとに 1 つのループ、最大 2.2 倍高速、ビットごとに同じ (https://github.com/storytold/photocraft/pull/7118 の @nicolasfalesy による)
  • トラップ: ロックされたレイヤーを拒否する (#5623) by @davidmann4 (https://github.com/storytold/photocraft/pull/5624)
  • レンズ フレア: 1.0 (#5785) より上の 32 ビット ピクセルを暗くしないでください (https://github.com/storytold/photocraft/pull/5786 の @davidmann4 による)
  • Duotone: https://github.com/storytold/photocraft/pull/6855 の @davidmann4 によるマルチチャンネル変換 (#6854) のようなビューとフラット エクスポート クランプ インク密度
  • カスタム フィルター: CMYK で正のオフセットが明るくなります (#7076) by @davidmann4 (https://github.com/storytold/photocraft/pull/7077)
  • 測定スケール: 大きなピクセル長は実際の値 (#7016) を出力します (@davidmann4 による https://github.com/storytold/photocraft/pull/7017)

  • 修正(エンジン): https://github.com/storytold/photocraft/pull/6902 の @wewtech による予約 (wasm32) 前に定義ブラシの先端サイズの乗算を確認

  • アクション: Paint Bucket ステップは、https://github.com/storytold/photocraft/pull/7208 の @Korg1ch による .atn (#7199) を通じて明示的なカラーを維持します。
  • EXR: ACEScg 設定は、https://github.com/storytold/photocraft/pull/6783 の @davidmann4 によるファイルを開くすべての方法 (#6782) に適用されます。
  • タイプ: Lorem Ipsum インサートを、https://github.com/storytold/photocraft/pull/5660 の @davidmann4 による「layer」 (#5659) という名前のタイプ レイヤーに貼り付けます。
