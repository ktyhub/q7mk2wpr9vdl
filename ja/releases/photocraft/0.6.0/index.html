#フォトクラフトv0.6.0

何が変わったのか

  • モーション ブラー: 6 倍から 70 倍高速 (1 つのマージされたカーネルが行全体に適用) (https://github.com/storytold/photocraft/pull/902 の @Ar-maan05 による)
  • テキスト データ セットを適用すると、文字レイヤーを空白にするのではなく再レンダリングします (#990) (https://github.com/storytold/photocraft/pull/1025 の @ianswope による)
  • PSD: 仕様順序マスク レコードは、その読み取りが信じられない場合でも、Photoshop の順序として誤って読み取られません (#949) by @wstock in https://github.com/storytold/photocraft/pull/1129
  • ui.window.open: 無効なドキュメント インデックスはエラーであり、https://github.com/storytold/photocraft/pull/1133 の @Elvis33LE による副作用ではありません
  • fix(ui): https://github.com/storytold/photocraft/pull/1261 の @Ni-zav によって以前に適用された新しいガイド レイアウトの値を記憶します
  • fix(ui): https://github.com/storytold/photocraft/pull/1262 の @Ni-zav による最後の多角形なげなわポイントの削除を許可
  • PSD エクスポート: https://github.com/storytold/photocraft/pull/1290 の @DWAA1660 により、空のレイヤーとマスク チャンネルを生として書き込みます
  • 修正 #1286: 選択ツールの右側の click メニューの選択範囲の削除と塗りつぶし (https://github.com/storytold/photocraft/pull/1331 の @b flatastic による)
  • #1275 の一部: Studio テーマでは、https://github.com/storytold/photocraft/pull/1333 の @b flatastic による移動ツールの自動選択トグルが表示されます
  • 修正 #1323: https://github.com/storytold/photocraft/pull/1332 の @b flatastic により、ボックスが折りたたまれる前にコーナーの歪みが停止します。
  • 雑用: https://github.com/storytold/photocraft/pull/1155 の @ArianPashae により、誤ってコミットされた fb-.log ファイルを削除し、.log を無視する
  • フィルター › 最後のフィルターは、フィルターが最初に実行されたレイヤー (#1270) ではなく、アクティブなレイヤーに適用されます (https://github.com/storytold/photocraft/pull/1307 の @marcardenas)
  • グラデーション ツール: 10% スケールのフロア ストップを超えてドラッグされたハンドル。もう一方のハンドルはそのままです (#1243) by @marcardenas (https://github.com/storytold/photocraft/pull/1306)
  • fix(ui): https://github.com/storytold/photocraft/pull/1268 の @Ni-zav によるキャンバス入力を非表示のガイドがインターセプトするのを防止
  • 修正(ui): https://github.com/storytold/photocraft/pull/1269 の @Ni-zav により、[ファイル] メニューに設定されたクイック エクスポート形式を表示します。
  • 修正(エクスポート): https://github.com/storytold/photocraft/pull/1279 の @Ni-zav により WebP 品質コントロールをエクスポート設定に追加
  • PSD テキストの塗りつぶし: Photopea で編集したテキストが塗りつぶしを維持できるように、FillFlag を保持し、https://github.com/storytold/photocraft/pull/1368 で @ragedotdev による @b flatastic による #1240 を保持します。
  • 自由変換: W/H フィールドと X/Y フィールドは大きなドキュメントに達し、https://github.com/storytold/photocraft/pull/1340 で @marcardenas による @b flatastic による #1295 が伝送されます。
  • を選択 › 変更: キャンバスの境界に効果を適用し、https://github.com/storytold/photocraft/pull/1339 で @marcardenas による @b flatastic による #1296 を実行します
  • レイヤー パネル: ブレンド モードにホバーすると、キャンバス上でライブ プレビューが表示されます (#970) by @b flatastic (https://github.com/storytold/photocraft/pull/1081)
  • ドキュメント: craftrules は公開されていません — リンクする代わりにそう言ってください (#493) by @bfenty in https://github.com/storytold/photocraft/pull/779
  • i18n: https://github.com/storytold/photocraft/pull/833 の @RicSchonfelder による pt-br ラベルの衝突 (フェザー/拡散、液化/ディゾルブ) を修正
  • 敵対的な番号ではクラッシュしない: LUT サイズ、クイック選択ポイント、https://github.com/storytold/photocraft/pull/869 の @tanish2k09 によるリンク グループ ID
  • 境界はあるがチャネル データがない PSD レイヤーが、https://github.com/storytold/photocraft/pull/885 の @ianswope による 360 GB 割り当て (#755) で中止されなくなりました。
  • 新しいドキュメント: https://github.com/storytold/photocraft/pull/891 の @jason4short による clipboard 画像のサイズを備えた Clipboard プリセット
  • レイヤー コピーには番号が付けられます: 「レイヤー 1 コピー コピー」ではなく、「レイヤー 1 コピー 2」 (https://github.com/storytold/photocraft/pull/897 の @jason4short)
  • 300000x300000 の file.new は、返される前に ~360 GB のタイルを埋めなくなりました (#705) by @ianswope (https://github.com/storytold/photocraft/pull/900)
  • https://github.com/storytold/photocraft/pull/991 の @Ni-zav により、整数オーバーフローを発生させずにワイドスライス長方形を分割します。

  • image.crop は、パニックする代わりに、i32 内で移動できない起点または遠端を拒否します (#959) (https://github.com/storytold/photocraft/pull/1013 の @mnmlyw による)
  • スケール マーカーを配置: 高さ 8 ピクセル未満のドキュメントはパニックではなくエラーを返します (#932) (https://github.com/storytold/photocraft/pull/1014 の @mnmlyw による)
  • タイムライン: 範囲外の継続時間と fps は拒否され、ステッピングは決してパニックになりません (#1009) by @mnmlyw (https://github.com/storytold/photocraft/pull/1023)

  • リンク層は、https://github.com/storytold/photocraft/pull/1022 の @mnmlyw によって、オーバーフローできないグループ ID (#961) を割り当てます。
  • 中央値、ダスト、スクラッチ: 実行時間は半径に応じて直線的に増加し、8、16、32 ビット (#498) での同一出力 (https://github.com/storytold/photocraft/pull/901 の @Ar-maan05 による)

  • オプション バー: エアブラシ、スムージング オプション、対称ボタンが機能する (#1177) by @ChrisWaldenDev (https://github.com/storytold/photocraft/pull/1214)
