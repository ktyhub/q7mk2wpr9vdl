redis 8.12.0

マイナー 公開日2026年11月22日 出典redis/redis English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#redis 8.12.0 これは、Redis オープン ソースの Redis 8.12 の一般公開リリースです。

8.10と比較した主な変更点

  • 圧縮ビットマップ — redis-roaring を Redis コアに統合し、メモリ使用量を削減し、ビットマップ操作を高速化します。 この機能に貢献してくれた redis-roaring のオリジナル作成者である Antonio Viggiano に感謝します。
  • 新しい B+ ツリー エンコーディングによる大規模なソート セットのメモリの大幅な削減
  • 新しいコマンド: redis-roaring の R.RANGEINTARRAY に相当する BITRANGEINTARRAY、指定された範囲内の設定されたビット オフセットを返す
  • セット メンバーの有効期限: 新しいコマンド: SEXPIRE、SPEXPIRE、SEXPIREAT、SPEXPIREAT - セット メンバーの有効期限を設定します。 STTL、SPTTL、SEXPIRETIME、SPEXPIRETIME - 残りの TTL または有効期限タイムスタンプを取得します。 SETPERSIST - メンバーの有効期限を削除します
  • 新しいコマンド: BLESS - 指定されたキーの削除を回避します。
  • 新しいコマンド: ZMOVE、BZMOVE、および「ZMOVEMEMBER」 - セットの終わりのバッチおよび宛先条件に対するアトミックなソートセットの移動
  • 最小スケッチ数の拡張機能
  • JSONディープパスを自動作成
  • オプトイン SQ8 の新しい圧縮が HNSW ベクトル インデックスで利用可能になりました
  • CLUSTER MIGRATION STATUS は、スナップショットと増分移行フェーズの両方の進行状況を報告するようになりました。
  • Redis クエリ エンジン: FT.ALTER は、スキーマ追加中の不必要なドキュメントの再インデックス作成を回避します。
  • Redis クエリ エンジン: EXPLAINSCORE が FT.HYBRID でサポートされるようになりました。
  • Redis クエリ エンジン: ローカル FT.HYBRID 実行で RETURN_STRICT タイムアウト処理が有効になりました。

バグ修正 (8.12 RC-3 との比較)

  • #16252 HOTKEYS GET が 2^31 ミリ秒後に間違った collection-duration-ms を報告しました
  • #16219 HPERSIST は、ローカル クロックがすでに期限切れになっていたフィールドのレプリケートまたは AOF 永続を無視しました
  • #16207 レプリケーション圧縮が有効になっているときにレプリカが誤動作する
  • #16267 BITCOUNT が、大規模な高密度ビットマップの AArch64 で間違った結果を返しました
  • #16081 クラスターバスでアナウンスされた住所と名前が検証なしで受け入れられました
  • RedisTimeSeries/RedisTimeSeries#2234 無効な集計タイプで永続化された圧縮ルールをロードするときのクラッシュを修正しました (MOD-20881)。
  • RedisJSON/RedisJSON#1692 検証エラーを返す前に配列を部分的に変更する JSON.ARRINSERT を修正しました (MOD-9116)。
  • RedisBloom/RedisBloom#1090 シード ジェネレーターを 1 回初期化し、コマンドごとのランダム シード生成のオーバーヘッドを削減することで、TopK 書き込みパフォーマンスを向上させます。

redis 8.12.0

This is the General Availability release of Redis 8.12 in Redis Open Source.

Major changes compared to 8.10

  • Compressed bitmaps — Integrated redis-roaring into Redis core for lower memory usage and faster bitmap operations. Special thanks to Antonio Viggiano, the original creator of redis-roaring, for contributing this capability!
  • Substantial memory reduction for large sorted set with a new B+ tree encoding
  • New command: BITRANGEINTARRAY equivalent to redis-roaring’s R.RANGEINTARRAY, to return set bit offsets within a specified range
  • Set member expiration: New commands: SEXPIRE,SPEXPIRE,SEXPIREAT,SPEXPIREAT - set expiration of a Set member; STTL, SPTTL, SEXPIRETIME,SPEXPIRETIME - retrieve remaining TTLs or expiration timestamps; SETPERSIST - remove the expiration of members
  • New command: BLESS - avoid eviction of specified keys
  • New commands: ZMOVE, BZMOVE and ‘ZMOVEMEMBER‘ - atomic sorted-set moves for end-of-set batches and destination conditions
  • Count-min-sketch extensions
  • Auto create JSON deep path
  • Opt-in SQ8 new compression is now available for HNSW vector indexes
  • CLUSTER MIGRATION STATUS now reports progress for both the snapshot and incremental migration phases
  • Redis query engine: FT.ALTER avoids unnecessary document reindexing during schema additions
  • Redis query engine: EXPLAINSCORE is now supported for FT.HYBRID
  • Redis query engine: RETURN_STRICT timeout handling is now enabled for local FT.HYBRID execution

Bug fixes (compared to 8.12 RC-3)

  • #16252 HOTKEYS GET reported a wrong collection-duration-ms after 2^31 milliseconds
  • #16219 HPERSIST ignored a replicated or AOF persist of a field the local clock had already expired
  • #16207 Replicas misbehaved when replication compression was enabled
  • #16267 BITCOUNT returned wrong results on AArch64 for large dense bitmaps
  • #16081 Addresses and names announced on the cluster bus were accepted without validation
  • RedisTimeSeries/RedisTimeSeries#2234 Fix a crash when loading persisted compaction rules with an invalid aggregation type (MOD-20881).
  • RedisJSON/RedisJSON#1692 Fix JSON.ARRINSERT partially modifying arrays before returning a validation error (MOD-9116).
  • RedisBloom/RedisBloom#1090 Improve TopK write performance by initializing the seed generator once, reducing per-command random-seed generation overhead.
