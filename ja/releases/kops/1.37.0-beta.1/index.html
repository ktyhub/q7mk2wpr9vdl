#コップv1.37.0-beta.1

重大な変更や非推奨を含む詳細については、完全な kOps 1.37 release notes を参照してください。

何が変わったのか

  • ドキュメント: https://github.com/kubernetes/kops/pull/18592 の @hakman による 1.36 release notes の更新
  • 修正: https://github.com/kubernetes/kops/pull/18595 の @hakman による kops delete cluster のクラウド リソースのリストを再試行します
  • ハック: GitHub リリース プロモーションを並列化し、https://github.com/kubernetes/kops/pull/18594 に @hakman によるチェックサム検証を追加
  • feat(linode): VPC モデルをより広範なネットワーク モデルにリファクタリングし、https://github.com/kubernetes/kops/pull/18590 の @moshevayner によるサブネット タスクを追加します。
  • 雑用: https://github.com/kubernetes/kops/pull/18598 の @hakman による Kubernetes 1.31 のサポートを削除
  • ドキュメント: @hakman による https://github.com/kubernetes/kops/pull/18599 のリリース後に 1.36 release note を更新
  • ノードアップ: https://github.com/kubernetes/kops/pull/18600 で @hakman によってオーセンティケーター構成をクリアするときにクラスター仕様を変更しないでください。
  • Azure: https://github.com/kubernetes/kops/pull/18604 の @hakman により、kindnet ポッド CIDR が kube-apiserver に到達することを許可します。
  • https://github.com/kubernetes/kops/pull/18609 の @hakman による gsutil を gcloud storage に置き換えます
  • build(deps): https://github.com/kubernetes/kops/pull/18611 の @dependabot[bot] によるアクション/セットアップを 6.5.0 から 7.0.0 にバンプします。
