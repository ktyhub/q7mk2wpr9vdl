mflux v.0.23.0

mflux v.0.23.0

0.23.0

新しい

  • mflux-generate-flux3 および mflux-generate-flux3-edit は FLUX 3 Image Klein (蒸留およびベース) を実行し、テキストから画像への変換、最大 10 個の参照画像による編集、および 4、6、および 8 ビットの量子化を実行します。 (#878)
  • mflux-generate-flux3 および mflux-generate-flux3-edit は、ComfyUI/ai-toolkit (BFL)、ディフューザー/PEFT、および kohya キー形式で、--lora を使用して FLUX 3 Image Klein LoRA をロードするようになりました。 (#881)
  • mflux-generate-qwen-2.1、-edit、-controlnet は Qwen-Image-2.1-Turbo を 8 ステップ (--model qwen-image-2.1-turbo) で実行するようになりました。 mflux-save は、text-to-image コマンドと edit コマンドの両方がロードする 1 つの Qwen-Image-2.1 チェックポイントを書き込むようになりました。 (#859)
  • 新しいコマンド mflux-generate-krea2-controlnet: 深さ ControlNet を備えた Krea 2 Turbo。写真 (Depth Pro が深度を推定します) または既製の深度マップを与えます。 LoRA と -q は mflux-generate-krea2 と同様に機能します。 (#864)

改善されました

  • 組み込みモデルは固定された HuggingFace コミットからロードされるようになり、すべてのインストールで同じ重みが実行されます。別のコミットからキャッシュされたモデルを切り替えるには、オンラインで 1 回の実行が必要です。すでにディスク上にある重みが再利用されます。 (#872)
  • Qwen Image 2.1 の融合アテンション プロローグは、ストライド投影を処理し、MLX RMSNorm の精度と丸めを維持しながら、アテンション レイアウトを直接生成するようになりました。生成されたピクセルは、以前の融合実装とは異なる場合があります。サポートされていない構成では、構成されたパスが保持されます。 (#846)
  • Qwen Image 2.1 は、生成中に互換性のある高密度アテンションとフィードフォワード投影をパックし、チェックポイントの互換性を維持しながら投影のオーバーヘッドを削減します。量子化されたアダプターを含む投影は、元のパスを保持します。 (#847)

変更されました

  • 出力ファイルを書き込めない場合（権限エラー、ディスクがいっぱい、ボリュームが見つからない）、エラーをログに記録して終了するのではなく、イメージ保存の実行が失敗するようになりました。 (#861)

ドキュメント

  • Qwen-Image-2.1 README に mflux-generate-qwen-2.1-controlnet: コントロール タイプ、ターボ、マスクによる修復、コントロール イメージのサイズ設定方法が文書化されました。 (#880)
  • mlx-teacache の README エントリでは、ステップをスキップするモデルに FLUX.1 dev と Krea、FLUX.2 Klein ベース、Z-Image ベース、および Qwen-Image (オリジナル チェックポイント) という名前が付けられています。 (#855)
  • docs/plugins.md は、mflux.extras にコマンドを追加するプラグインを検索、インストール、作成する方法を示します。 README へのリンクがあります。 (#856)

内部

  • 新しい /mflux-pr-docs エージェント スキルは、開発者が承認するための PR 本文と release note を書き込みます。 .claude/skills/ のクロード コード、カーソル、GitHub 副操縦士のスキ​​ルを更新します。 (#837)
  • /mflux-pr-docs は開発者が承認したタイトルを gh pr create に渡すようになったので、クロード コードから動作します。オープン PR は、開発者が変更しない限り、そのタイトルを保持します。 (#854)
  • Krea 2、Qwen-Image、Qwen-Image-2.1、FIBO lite、ERNIE-Image 用にゴールデン テスト参照が再生成され、FIBO Edit および HuggingFace LoRA ID 用に修正されたゴールデン テスト ヘルパー。生成された画像は変わりません。 (#871)

mflux v.0.23.0

0.23.0

New

  • mflux-generate-flux3 and mflux-generate-flux3-edit now run FLUX 3 Image Klein (distilled and Base), with text-to-image, editing with up to ten reference images, and 4, 6 and 8 bit quantization. (#878)
  • mflux-generate-flux3 and mflux-generate-flux3-edit now load FLUX 3 Image Klein LoRAs with --lora, in the ComfyUI/ai-toolkit (BFL), diffusers/PEFT and kohya key formats. (#881)
  • mflux-generate-qwen-2.1, -edit and -controlnet now run Qwen-Image-2.1-Turbo in 8 steps (--model qwen-image-2.1-turbo). mflux-save now writes one Qwen-Image-2.1 checkpoint that both the text-to-image and edit commands load. (#859)
  • New command mflux-generate-krea2-controlnet: Krea 2 Turbo with a depth ControlNet. Give it a photo (Depth Pro estimates the depth) or a ready-made depth map. LoRAs and -q work as in mflux-generate-krea2. (#864)

Improved

  • Built-in models now load from a pinned HuggingFace commit, so every install runs the same weights. A model cached from another commit needs one online run to switch; the weights already on disk are reused. (#872)
  • Qwen Image 2.1’s fused attention prologue now handles strided projections and preserves MLX RMSNorm precision and rounding while producing the attention layout directly. Generated pixels may differ from the previous fused implementation; unsupported configurations retain the composed path. (#846)
  • Qwen Image 2.1 packs compatible dense attention and feed-forward projections during generation, reducing projection overhead while preserving checkpoint compatibility. Quantized and adapter-bearing projections retain their original path. (#847)

Changed

  • Image saving now fails the run when the output file cannot be written (permission error, full disk, missing volume) instead of logging the error and exiting 0. (#861)

Docs

  • The Qwen-Image-2.1 README now documents mflux-generate-qwen-2.1-controlnet: control types, Turbo, inpainting with a mask, and how to size the control image. (#880)
  • The README entry for mlx-teacache now names the models where it skips steps: FLUX.1 dev and Krea, FLUX.2 Klein base, Z-Image base and Qwen-Image (original checkpoint). (#855)
  • docs/plugins.md tells how to find, install and write a plugin that adds commands under mflux.extras. The README links to it. (#856)

Internal

  • The new /mflux-pr-docs agent skill writes the PR body and the release note for the developer to approve. Update skills for Claude Code, Cursor & GitHub Copilot in .claude/skills/. (#837)
  • /mflux-pr-docs now passes a developer-approved title to gh pr create, so it works from Claude Code. An open PR keeps its title unless the developer changes it. (#854)
  • Golden test references regenerated for Krea 2, Qwen-Image, Qwen-Image-2.1, FIBO lite and ERNIE-Image, and the golden test helper fixed for FIBO Edit and HuggingFace LoRA ids. Generated images don't change. (#871)
