ray 2.59.1

#レイレイ-2.59.1

セキュリティ修正

eMudhra 中間 CA 侵害

eMudhra 中間 CA キーは、2026 年 10 月 20 日に侵害されたと報告されました。 pip trust はシステム ストアに加えて独自のベンダー証明書バンドルを作成するため、OS ca-certificates を更新するだけでは pip は保護されません。このリリースでは、Ray が CA バンドルをインストールまたはバンドルするすべての場所が修正リリースに移動されます。

  • Docker イメージ: すべての Python バージョンの pip 26.2.2、conda およびサイト パッケージの証明書 2026.10.19、uv 0.13.4 (#67295、#67350、pick #67487)。
  • virtualenv 21.14.12、runtime_env virtualenv の pip 26.2.2 をバンドルします。これにより、packaging が 26.3 に、typing-extensions が 4.16.0 に、distlib が 0.4.3 に、python-discovery が 1.6.1 に移動されます (#67301、#67487 を選択)。
  • Ray のセキュリティ要件の certifi>=2026.10.19 フロア (#67305、#67487 を選択)。
  • Windows および macOS ホイール ビルドの pip 26.2.2 および uv 0.13.4 (#67298、#67487 を選択)。出荷されたホイールには CA バンドルが含まれていないため、影響を受けません。

aiohttp

  • バンドルされた runtime_env エージェントの依存関係、ray[default]、およびイメージ内の aiohttp 3.14.3 → 3.14.4 (および yarl 1.23.0 → 1.25.1)。 CVE-2026-111064、CVE-2026-111066、および GHSA-2g87-pp6c-29x5 を修正しました (#67304、#67487 を選択; #67302 で報告)。

バグ修正

光線データ

  • Arrow ブロック上のパンダのメタデータをパンダが読み取れるようにします。 pandas が解析できない Dtype 名は `object` として書き込まれるようになったため、それらのブロックまたはファイルを pandas に変換して戻すことは失敗しなくなりました (#67576、#67649 を選択)。

レイサーブ

  • Ingress リクエスト ルーターの展開では、プロキシが実行されるノード上にプロキシが保持されなくなりました。これらのノードは通常どおりスケールダウンできるようになりました (#65824、#67633 を選択)。

ray ray-2.59.1

Security fixes

eMudhra intermediate CA compromise

The eMudhra intermediate CA keys were reported compromised on October 20, 2026. pip trusts its own vendored certifi bundle in addition to the system store, so updating OS ca-certificates alone doesn't protect pip. This release moves every place Ray installs or bundles a CA bundle to the fixed releases:

  • Docker images: pip 26.2.2 on every Python version, conda and site-packages certifi 2026.10.19, uv 0.13.4 (#67295, #67350, pick #67487).
  • virtualenv 21.14.12, which bundles pip 26.2.2 for runtime_env virtualenvs. This also moves packaging to 26.3, typing-extensions to 4.16.0, distlib to 0.4.3 and python-discovery to 1.6.1 (#67301, pick #67487).
  • certifi>=2026.10.19 floor in Ray's security requirements (#67305, pick #67487).
  • pip 26.2.2 and uv 0.13.4 in the Windows and macOS wheel builds (#67298, pick #67487). The shipped wheels don't vendor a CA bundle and are unaffected.

aiohttp

  • aiohttp 3.14.3 → 3.14.4 (and yarl 1.23.0 → 1.25.1) in the bundled runtime_env agent dependencies, ray[default], and the images. Fixes CVE-2026-111064, CVE-2026-111066 and GHSA-2g87-pp6c-29x5 (#67304, pick #67487; reported in #67302).

Bug fixes

Ray Data

  • Keep the pandas metadata on Arrow blocks readable by pandas. Dtype names that pandas can't parse are now written as `object`, so converting those blocks or files back to pandas no longer fails (#67576, pick #67649).

Ray Serve

  • Ingress request router deployments no longer keep proxies on the nodes they run on. Those nodes can now scale down normally (#65824, pick #67633).
