opentelemetry-java-instrumentation v2.31.0

opentelemetry-java-instrumentation v2.31.0

このリリースは、OpenTelemetry SDK 1.65.0 を対象としています。

多くのアーティファクトには、今後も重大な変更が加えられることを反映して、バージョン番号に -alpha というサフィックスが付いていることに注意してください。詳細については、VERSIONING.md を参照してください。

⚠️ 不安定な API に対する重大な変更

  • 非推奨の ConfigPropertiesBackedConfigProvider とその create(ConfigProperties) 互換 API を宣言型構成ブリッジから削除します。 (#19305)
  • ライブラリ インストルメンテーション コンパイル クラスパスで opentelemetry-instrumentation-api-incubator を公開するのをやめます。 (#19612)

🚫 非推奨

  • otel.instrumentation.experimental.span-suppression-strategy を廃止し、Experimental.setSpanSuppressionStrategy(...) を採用します。 (#19180)
  • HostIdResource.REGISTRY_QUERY を非推奨にし、HostIdResource で使用される絶対パス reg.exe ルックアップを採用します。 (#19293)
  • MessagingOperationType を優先して MessageOperation を廃止し、対応する MessagingOperationType API を優先して、MessagingAttributesExtractor、MessagingConsumerMetrics、MessagingProducerMetrics、MessagingSpanKindExtractor、MessagingSpanNameExtractor の MessageOperation オーバーロードを廃止します。 (#19357)
  • otel.traces.exporter=zipkin を廃止して otel.traces.exporter=otlp を、otel.exporter.zipkin.endpoint を廃止して otel.exporter.otlp.traces.endpoint を廃止します。 (#19400)
  • OpenTelemetryMeterRegistryBuilder#setMicrometerHistogramGaugesEnabled(boolean) を廃止し、Experimental#setMicrometerHistogramGaugesEnabled(OpenTelemetryMeterRegistryBuilder, boolean) を採用します。 (#19404)
  • レガシー gRPC メタデータ、メッセージング ヘッダー、サーブレット リクエスト パラメーター キャプチャ プロパティと API を廃止し、セレクター ベースの .included / .excluded 構成と IncludeExclude API を採用します。 (#19494、#19522、#19523、#19638)
  • otel.instrumentation.runtime-telemetry.experimental.prefer-jfr を廃止して otel.instrumentation.runtime-telemetry.experimental.jfr-metrics.included を、setPreferJfrMetrics(...) を廃止して setJfrMetrics(RuntimeTelemetryBuilder, IncludeExclude) を廃止します。 (#19495)
  • MDC/コンテキスト データ、マップ メッセージ、キーと値のペア、ロガー コンテキスト、Logstash マーカー、および構造化引数のブール値およびキャプチャ リスト構成を非推奨にし、.included / .excluded セレクターおよび IncludeExclude API を優先します。 (#19519、#19520、#19521、#19599、#19600、#19605、 #19609、#19610)
  • 宣言型構成フィールド general.semconv_stability.opt_in を廃止して general.stability_opt_in_list を、general.sanitization.url.sensitive_query_parameters/development を廃止して general.sanitization.url.sensitive_query_parameters を廃止します。 (#19561)
  • otel.instrumentation.graphql.add-operation-name-to-span-name.enabled を廃止して otel.instrumentation.graphql.operation-name-in-span-name.enabled を、otel.instrumentation.runtime-telemetry.package-emitter.enabled / jars-per-second を廃止して otel.instrumentation.runtime-telemetry.experimental.package-emitter.enabled / jars-per-second を廃止します。 (#19573)
  • セレクターベースの requestHeaders(IncludeExclude) および responseHeaders(IncludeExclude) API を優先して、HTTP ライブラリ インストルメンテーション全体でキャプチャされたリクエストおよびレスポンス ヘッダー ビルダー メソッドを非推奨にします。 (#19598、#19601、#19602、#19603、#19604、#19606、 #19607、#19608)
  • otel.instrumentation.micrometer.histogram-gauges.enabled を廃止し、otel.instrumentation.micrometer.experimental.histogram-gauges.enabled を採用します。 (#19613)

🌟 新しい Javaagent インストルメンテーション

  • オブジェクト プール メトリック用の Apache Commons Pool 2 インストルメンテーションを追加します。 (#19091)
  • Apache HBase client 1.0 javaagent インストルメンテーションを追加します。 (#19243)
  • 3.26+ の Redisson 接続プール メトリックを追加します。 (#19392)
  • Java エージェントに OpenTelemetry API 1.65 インキュベーター メトリックのサポートを追加します。 (#19456)
  • データベース プール メトリック用の Tomcat DBCP 8.0 Javaagent インストルメンテーションを追加します。 (#19472)

📈 機能強化

  • 選択したインストルメンテーション、API、および SDK 拡張アーティファクトにオプトイン OSGi バンドル メタデータを追加して、OSGi ランタイムで直接使用できるようにします。 (#18995)
  • 飛行中の Cassandra 圧縮用に cassandra.compaction.progress.completed および cassandra.compaction.progress.size ゲージを追加します。 (#19290)
  • AWS SQS および Lambda、JMS、Kafka、NATS、Pulsar、RabbitMQ、RocketMQ、Spring Integration、Spring メッセージング インストルメンテーションにわたる、otel.semconv-stability.opt-in=messaging の背後にある今後の 3.0 メッセージング セマンティック規約をプレビューします。 (#19347、#19348、#19349、#19350、#19351、#19353、 #19354、#19355、#19356、#19476、#19477、#19478、 #19479、#19480、#19481、#19482、#19486、#19487、 #19499、#19500、#19504、#19505、#19507、#19508、 #19535、#19544、#19565、#19567、#19639、#19640)
  • otel.semconv-stability.opt-in=rpc の背後にある今後の 3.0 RPC セマンティック規約では、DubboProtocol.getInvoker() より前にデコードが失敗した場合でも、未知のサービスへの Dubbo リクエストはサーバー スパンを発行し、元のメソッドを rpc.method_original に記録します。 (#16668)
  • Log4j コンテキスト データには、現在のスパンがない場合でも baggage.* エントリが含まれるようになりました。 (#19378)
  • otel.instrumentation.common.v3-preview=true の場合、マイクロメーター ブリッジは Timer および DistributionSummary 用の .max ゲージをエクスポートしなくなりました。 (#19397)
  • 含まれるグロブ パターンと除外されるグロブ パターンに対して文字列を照合するために、IncludeExclude セレクター API を opentelemetry-instrumentation-api に追加します。 (#19451)
  • Cassandra ドライバー 3 の一貫性、コーディネーター、ページ サイズ、冪等性、および投機的実行属性を出力します。 (#19629)
  • otel.semconv-stability.opt-in=database の背後にある今後の 3.0 データベース セマンティック規則を拡張します。これには、Couchbase、Redis clients、Elasticsearch、R2DBC、JDBC、ClickHouse、MongoDB、および HBase の操作名、名前空間、コレクション名、操作パラメーター、バッチ テレメトリ、およびエラー タイプが含まれます。 (#19616、#19623、#19664、#19665、#19668、#19670、 #19704、#19705、#19706、#19707、#19708)
  • InfluxDB クエリのサニタイズを制御するために otel.instrumentation.influxdb.query-sanitization.enabled を追加し、otel.instrumentation.common.db.query-sanitization.enabled よりも優先します。 (#19703)

🛠️ バグ修正

  • 名前のない Alibaba Druid、c3p0、Tomcat JDBC、HikariCP、および Vibur 接続プールには、安定したデータベース由来のメトリック名を使用します。 (#19108、#19159、#19173、#19470、#19471)
  • Apache DBCP 2.0 メトリクスは、JMX 登録がなくてもプールの開始時に登録され、close() で登録解除されるようになりました。 (#19160)
  • otel.javaagent.enabled=true が設定されていない限り、$JAVA_HOME/bin から起動される JDK ツールのインストルメントをスキップします。 (#19203)
  • 選択呼び出し数に対して jetty.io.select.count ではなく jetty.select.count を出力するように Jetty JMX メトリクスを修正しました。 (#19249)
  • 待機中の非同期コマンドがキャンセルされると、Redisson 接続プールでリークが許可される問題を修正しました。 (#19340)
  • Spring WebFlux ルート検出を修正し、コントローラー スパンが JDK 21 以降で読み取り可能なルート名を維持できるようにしました。 (#19365)
  • IPv6 JDBC server.address 値を括弧で囲まれたリテラルではなく裸のアドレスに正規化します。 (#19366)
  • ヘルパー クラスとして io.lettuce.core.protocol.OtelCommandArgsUtil を挿入することで、Indy での Lettuce 5.1 インストルメンテーションを修正しました。 (#19373)
  • host.id リソース検出に 2 秒のタイムアウトを追加し、遅い検索コマンドによって SDK の起動がブロックされなくなりました。 (#19377)
  • OpenTelemetry API を使用しないアプリケーションでも Azure SDK トレースを取得できるように、azure-core インストルメンテーションを修正しました。 (#19387)
  • MySQL JDBC URL 解析は、非標準 URL 形式のホスト、ポート、およびクエリ パラメーターをより確実に処理できるようになりました。 (#19394)
  • エージェントの起動時に MethodHandle$1 をプリロードして、invokedynamic 呼び出しサイトのリンクを中断する可能性がある JDK 17 上の ClassCircularityError を回避します。 (#19398)
  • AWS SigV4 クエリ パラメーター、AWS Lambda API ゲートウェイおよび Elasticsearch REST URL、埋め込み URL 認証情報、およびプロセス コマンド ラインからの機密データを秘匿化します。 (#19422、#19424、#19425、#19514)
  • Micrometer のカスタム メーターの命名を修正し、関連する機器またはレジストリ間でメトリックの説明が漏洩するのを防ぎます。 (#19463、#19466、#19467)
  • % 値を単位のない分数に変換するように activemq.destination.temp.utilization を修正しました。 (#19512)
  • {thread} の代わりに {job} ユニットを使用するように jetty.thread.queue.size を修正しました。 (#19513)
  • OpenTelemetry Micrometer レジストリが複合レジストリの一部である場合、またはメトリック値を返せない場合の Spring Boot Actuator メトリック エンドポイントを修正します。 (#19515、#19541)
  • Host ヘッダー内の IPv6 アドレスが、括弧で囲まれたポートも含めて正しく解析されるようになりました。 (#19540)
  • 受信テレメトリが無効になっている場合に、抽出されたプロデューサー コンテキストに対して抑制を評価するように、従来のメッセージング セマンティック規約に基づいて Pulsar 受信スパンを修正しました。 (#19592)
  • コンシューマ レジストリ アドレスを取得するときに、Dubbo の ClusterInvoker タイプを保持します。 (#19568)
  • 対応する .included または .excluded の代替品も構成されている場合、非推奨のセレクター ベースのキャプチャ設定に関する警告を停止します。 (#19571)
  • 従来の db.name および R2DBC スパンの安定した db.namespace では、構成されたデータベース名の元の大文字と小文字が保持されます。 (#19615)
  • Vert.x SQL client で明示的に準備されたクエリのスパンをキャプチャすることで、PreparedStatement.query() の実行で正しい db.system と接続オプションが維持されます。 (#19619)
  • Cassandra 3 SimpleStatement のサニタイズを修正して、バインドされた値が検出され、db.statement で非表示になるようにしました。 (#19620)
  • 失敗した JDBC commit および rollback 操作の例外イベントとログを出力します。 (#19621)
  • executeBatch() および executeLargeBatch() の後の JDBC バッチ テレメトリ状態をクリアして、後続のバッチ スパンが古いバッチ内容を報告しないようにします。 (#19622)
  • CoordinatorException からコーディネーターを抽出して、失敗した Cassandra 3 操作用に server.address と server.port を保持します。 (#19627)
  • SQL クエリ テキストが db.system.name でサニタイズされるようになったため、二重引用符で囲まれた識別子は、識別子として扱われるデータベースではそのまま残ります。 (#19632)
  • AWS Lambda RequestHandler インストルメンテーションを修正して、void を返す handleRequest メソッドが正しく処理されるようにしました。 (#19714)

opentelemetry-java-instrumentation v2.31.0

This release targets the OpenTelemetry SDK 1.65.0.

Note that many artifacts have the -alpha suffix attached to their version number, reflecting that they will continue to have breaking changes. Please see VERSIONING.md for more details.

⚠️ Breaking changes to non-stable APIs

  • Remove the deprecated ConfigPropertiesBackedConfigProvider and its create(ConfigProperties) compatibility API from the declarative config bridge. (#19305)
  • Stop exposing opentelemetry-instrumentation-api-incubator on library instrumentation compile classpaths. (#19612)

🚫 Deprecations

  • Deprecate otel.instrumentation.experimental.span-suppression-strategy in favor of Experimental.setSpanSuppressionStrategy(...). (#19180)
  • Deprecate HostIdResource.REGISTRY_QUERY in favor of the absolute-path reg.exe lookup used by HostIdResource. (#19293)
  • Deprecate MessageOperation in favor of MessagingOperationType, and the MessageOperation overloads of MessagingAttributesExtractor, MessagingConsumerMetrics, MessagingProducerMetrics, MessagingSpanKindExtractor, and MessagingSpanNameExtractor in favor of the corresponding MessagingOperationType APIs. (#19357)
  • Deprecate otel.traces.exporter=zipkin in favor of otel.traces.exporter=otlp, and otel.exporter.zipkin.endpoint in favor of otel.exporter.otlp.traces.endpoint. (#19400)
  • Deprecate OpenTelemetryMeterRegistryBuilder#setMicrometerHistogramGaugesEnabled(boolean) in favor of Experimental#setMicrometerHistogramGaugesEnabled(OpenTelemetryMeterRegistryBuilder, boolean). (#19404)
  • Deprecate legacy gRPC metadata, messaging header, and servlet request-parameter capture properties and APIs in favor of selector-based .included / .excluded configuration and IncludeExclude APIs. (#19494, #19522, #19523, #19638)
  • Deprecate otel.instrumentation.runtime-telemetry.experimental.prefer-jfr in favor of otel.instrumentation.runtime-telemetry.experimental.jfr-metrics.included, and setPreferJfrMetrics(...) in favor of setJfrMetrics(RuntimeTelemetryBuilder, IncludeExclude). (#19495)
  • Deprecate boolean and capture-list configuration for MDC/context data, map messages, key-value pairs, logger context, Logstash markers, and structured arguments in favor of .included / .excluded selectors and IncludeExclude APIs. (#19519, #19520, #19521, #19599, #19600, #19605, #19609, #19610)
  • Deprecate the declarative configuration field general.semconv_stability.opt_in in favor of general.stability_opt_in_list, and general.sanitization.url.sensitive_query_parameters/development in favor of general.sanitization.url.sensitive_query_parameters. (#19561)
  • Deprecate otel.instrumentation.graphql.add-operation-name-to-span-name.enabled in favor of otel.instrumentation.graphql.operation-name-in-span-name.enabled, and otel.instrumentation.runtime-telemetry.package-emitter.enabled / jars-per-second in favor of otel.instrumentation.runtime-telemetry.experimental.package-emitter.enabled / jars-per-second. (#19573)
  • Deprecate captured request and response header builder methods across HTTP library instrumentations in favor of selector-based requestHeaders(IncludeExclude) and responseHeaders(IncludeExclude) APIs. (#19598, #19601, #19602, #19603, #19604, #19606, #19607, #19608)
  • Deprecate otel.instrumentation.micrometer.histogram-gauges.enabled in favor of otel.instrumentation.micrometer.experimental.histogram-gauges.enabled. (#19613)

🌟 New javaagent instrumentation

  • Add Apache Commons Pool 2 instrumentation for object pool metrics. (#19091)
  • Add Apache HBase client 1.0 javaagent instrumentation. (#19243)
  • Add Redisson connection pool metrics for 3.26+. (#19392)
  • Add support for OpenTelemetry API 1.65 incubator metrics in the Java agent. (#19456)
  • Add Tomcat DBCP 8.0 javaagent instrumentation for database pool metrics. (#19472)

📈 Enhancements

  • Add opt-in OSGi bundle metadata for selected instrumentation, API, and SDK extension artifacts so they can be consumed directly in OSGi runtimes. (#18995)
  • Add cassandra.compaction.progress.completed and cassandra.compaction.progress.size gauges for in-flight Cassandra compactions. (#19290)
  • Preview the upcoming 3.0 messaging semantic conventions behind otel.semconv-stability.opt-in=messaging across AWS SQS and Lambda, JMS, Kafka, NATS, Pulsar, RabbitMQ, RocketMQ, Spring Integration, and Spring messaging instrumentations. (#19347, #19348, #19349, #19350, #19351, #19353, #19354, #19355, #19356, #19476, #19477, #19478, #19479, #19480, #19481, #19482, #19486, #19487, #19499, #19500, #19504, #19505, #19507, #19508, #19535, #19544, #19565, #19567, #19639, #19640)
  • Under the upcoming 3.0 RPC semantic conventions behind otel.semconv-stability.opt-in=rpc, Dubbo requests to unknown services emit server spans even when decoding fails before DubboProtocol.getInvoker(), and record the original method in rpc.method_original. (#16668)
  • Log4j context data now includes baggage.* entries even when there is no current span. (#19378)
  • When otel.instrumentation.common.v3-preview=true, the Micrometer bridge no longer exports .max gauges for Timer and DistributionSummary. (#19397)
  • Add the IncludeExclude selector API to opentelemetry-instrumentation-api for matching strings against included and excluded glob patterns. (#19451)
  • Emit Cassandra driver 3 consistency, coordinator, page size, idempotence, and speculative execution attributes. (#19629)
  • Expand the upcoming 3.0 database semantic conventions behind otel.semconv-stability.opt-in=database, including operation names, namespaces, collection names, operation parameters, batch telemetry, and error types for Couchbase, Redis clients, Elasticsearch, R2DBC, JDBC, ClickHouse, MongoDB, and HBase. (#19616, #19623, #19664, #19665, #19668, #19670, #19704, #19705, #19706, #19707, #19708)
  • Add otel.instrumentation.influxdb.query-sanitization.enabled to control InfluxDB query sanitization, taking precedence over otel.instrumentation.common.db.query-sanitization.enabled. (#19703)

🛠️ Bug fixes

  • Use stable database-derived metric names for unnamed Alibaba Druid, c3p0, Tomcat JDBC, HikariCP, and Vibur connection pools. (#19108, #19159, #19173, #19470, #19471)
  • Apache DBCP 2.0 metrics now register when the pool starts even without JMX registration, and they unregister on close(). (#19160)
  • Skip instrumenting JDK tools launched from $JAVA_HOME/bin unless otel.javaagent.enabled=true is set. (#19203)
  • Fix Jetty JMX metrics to emit jetty.select.count instead of jetty.io.select.count for select-call counts. (#19249)
  • Fix Redisson connection pool permits leaking when a waiting async command is cancelled. (#19340)
  • Fix Spring WebFlux route detection so controller spans keep a readable route name on JDK 21+. (#19365)
  • Normalize IPv6 JDBC server.address values to bare addresses instead of bracketed literals. (#19366)
  • Fix Lettuce 5.1 instrumentation with indy by injecting io.lettuce.core.protocol.OtelCommandArgsUtil as a helper class. (#19373)
  • Add a 2-second timeout to host.id resource detection so slow lookup commands no longer block SDK startup. (#19377)
  • Fix azure-core instrumentation so applications that do not use the OpenTelemetry API still get Azure SDK tracing. (#19387)
  • MySQL JDBC URL parsing now handles hosts, ports, and query parameters in non-standard URL forms more reliably. (#19394)
  • Preload MethodHandle$1 during agent startup to avoid ClassCircularityError on JDK 17 that can break invokedynamic call site linking. (#19398)
  • Redact sensitive data from AWS SigV4 query parameters, AWS Lambda API Gateway and Elasticsearch REST URLs, embedded URL credentials, and process command lines. (#19422, #19424, #19425, #19514)
  • Fix Micrometer custom meter naming and prevent metric descriptions from leaking between related instruments or registries. (#19463, #19466, #19467)
  • Fix activemq.destination.temp.utilization to convert % values to a unitless fraction. (#19512)
  • Fix jetty.thread.queue.size to use the {job} unit instead of {thread}. (#19513)
  • Fix Spring Boot Actuator metric endpoints when the OpenTelemetry Micrometer registry is part of a composite registry or cannot return metric values. (#19515, #19541)
  • IPv6 addresses in Host headers are now parsed correctly, including bracketed ports. (#19540)
  • Fix Pulsar receive spans under legacy messaging semantic conventions to evaluate suppression against the extracted producer context when receive telemetry is disabled. (#19592)
  • Preserve Dubbo's ClusterInvoker type when capturing the consumer registry address. (#19568)
  • Stop warning about deprecated selector-based capture settings when the corresponding .included or .excluded replacement is also configured. (#19571)
  • Preserve the configured database name's original case in legacy db.name and stable db.namespace for R2DBC spans. (#19615)
  • Capture spans for explicit prepared queries in Vert.x SQL client so PreparedStatement.query() execution keeps the correct db.system and connection options. (#19619)
  • Fix Cassandra 3 SimpleStatement sanitization so bound values are detected and hidden in db.statement. (#19620)
  • Emit exception events and logs for failed JDBC commit and rollback operations. (#19621)
  • Clear JDBC batch telemetry state after executeBatch() and executeLargeBatch() so subsequent batch spans no longer report stale batch contents. (#19622)
  • Keep server.address and server.port for failed Cassandra 3 operations by extracting the coordinator from CoordinatorException. (#19627)
  • SQL query text is now sanitized with db.system.name, so double-quoted identifiers stay intact for databases that treat them as identifiers. (#19632)
  • Fix AWS Lambda RequestHandler instrumentation so void-returning handleRequest methods are handled correctly. (#19714)
