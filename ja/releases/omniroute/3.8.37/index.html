OmniRoute v3.8.37

Highlights

  • Three new providers, one important caveat — DGrid AI gateway (api.dgrid.ai/v1, alias dgrid, passthrough models, free tier 10 RPM/100 RPD rising to 20 RPM/1,000 RPD after a $5 top-up, #4931), Pioneer AI (alias pn, X-API-Key, 10 serverless open models, $75 free credits, #4909), and xAI Grok inbound translators plus a thinking patcher that normalizes Grok reasoning modes across clients (#4910). What matters: Grok's reasoning semantics are now client-agnostic, but Pioneer's enterprise Claude/GPT/Gemini models are deliberately excluded from the catalog because they require prior fine-tuning — don't design routing that assumes those IDs are selectable.

  • Codex onboarding and apply_patch get a real fix — POST /api/oauth/codex/import accepts multiple Codex OAuth credentials in one call (#4914), aimed at multi-account pools. More consequential is #4862: custom/freeform tools (apply_patch, type:"custom" with no parameters) are normalized to a { input: string } schema instead of an empty one, which previously made models invoke apply_patch with {} and broke the Codex runtime; custom_tool_call input items and apply_patch delta/done events are now streamed too. If you had a workaround for empty-schema apply_patch, it's time to remove it.

  • Combo behavior becomes tunable — with a state caveat — The opt-in comboAutoPromoteEnabled (#4852) reorders a combo's persisted model list so the last successful model moves to position #1; useful for sticky failover, but it mutates saved config, so be deliberate on shared deployments. Embedding combos gain a dimensions override to pin output vector size per target (#4913), essential when one combo feeds backends with different dimensionality. Also new: x-omniroute-strip-reasoning to drop reasoning_content from upstream responses (#4678) and toggleable tool-source diagnostics for tool-routing debugging (#4856).

  • Streaming output is now deterministic and correctly ordered — #4906 rebuilds response.completed so response.output items are stably sorted by recorded output_index (via a recorded-as-emitted accumulator) rather than reconstructed from unordered state dicts, replaces fragile parseInt with normalizeOutputIndex, and drops superseded tool calls replaced at the same index mid-stream. This is a genuine correctness win for clients replaying Responses output. Companion fixes: concatenable Kiro tool_calls.arguments deltas (#4855) and closing the reasoning block before message content so reasoning and answer render in the right order (#4848).

  • Tool schemas and fallback paths are hardened (and one behavior change) — Kiro now strips unsupported JSON-Schema keywords and hash-truncates >64-char tool names before dispatch (#4847); Antigravity translation preserves the required array so models stop calling tools without mandatory args (#4843) and drops enumDescriptions (#4813/#4740); json_schema falls back for providers without structured outputs (#4766). On failures, malformed HTTP-200 responses (#4942) and Qoder's SSE error envelope (#4850) are unwrapped so combo fallback actually fires, Antigravity retries transient errors (#4941), and WS-bridge client disconnects no longer trip the provider circuit breaker (#4870). Watch out: forwarding a kr/*[1m] 1M-context model to Kiro now returns a clear error instead of a malformed Bedrock request (#4816) — route those through a direct Anthropic provider.

  • Operational fixes worth upgrading for — The Engine Combos editor dropdown now derives from the same canonical engine map as the API schema, so selecting headroom/session-dedup/ccr/llmlingua no longer produces a silently swallowed 400 (#5062, closes #4955). CLI installs now persist lazily-installed native deps with --save-exact so --tray no longer prunes better-sqlite3 and triggers "No SQLite driver available" (#4841), and sql-wasm.wasm is trace-included for standalone SQLite-WASM builds (#4839). HuggingFace tokens are validated via whoami-v2 so fine-grained Inference tokens aren't falsely rejected (#4819), and the Headroom compression proxy gains lifecycle management plus a dashboard UI with Docker sidecar support (#4649).

No breaking changes noted in this release.
