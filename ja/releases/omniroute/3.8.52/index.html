OmniRoute v3.8.52

Highlights

  • Claude Opus 5.5 goes GA across Anthropic surfaces — Added to the Anthropic API, Claude OAuth, Bedrock and Vertex catalogs with native 1M context, 128K output, five effort tiers (default medium), $4/$20 pricing, Fast Mode and Opus 5 fallback; disabled thinking, manual budgets and forced tool_choice are normalized before dispatch because 5.5 rejects them (#14546). Watch-out: the cc/ Opus CLI default stays on claude-opus-5, and connections synced before launch reject 5.5 until their model list is refreshed (Refs #14612).
  • nadir adds a decision-API auto-router — Opt-in config.routerStrategy: "nadir" asks Nadir which candidate model a prompt needs while rules still pick the connection, so it layers on existing routing instead of replacing it. It fails open with a 30 s cooldown and sends only the last user turn plus model IDs off-box — a real privacy boundary for teams wary of shipping full transcripts to a third-party router (#13051).
  • Reasoning Replay is now opt-out — The new REASONING_REPLAY_ENABLED flag (Settings → Feature flags) ships on by default and stops Reasoning Replay from caching and re-injecting real reasoning text across turns; with it off, upstreams that require a reasoning field on replay turns still get the internal placeholder (#12486). If anything downstream relied on original reasoning surviving into later turns, audit this first — the conservative behavior is now the default.
  • Quota and capacity controls get sharper — modelConcurrency ceilings can be set per connection in rateLimitOverrides as an atomic fourth gate alongside the global/provider/account semaphores, with local queueing; unconfigured connections are unchanged (#13700). The same PR repairs executionMaxWaitMs, which the schema accepted but the DB allowlist silently dropped — re-save overrides if you assumed it was set, and note dashboard saves now preserve API-set values. For billing, USAGE_LIMIT_IGNORE_UNPRICED (off by default) stops per-key USD quotas from failing closed on unpriced/subscription models (#14799), and OMNIROUTE_API_KEY_WEEKLY_WINDOW=calendar moves weekly caps to a local Monday-00:00 week instead of the earliest upstream reset (#14603).
  • Claude Code requests stop dying on non-thinking local models — A new retry drops whichever reasoning field the body actually carries (reasoning_effort, reasoning, thinking, think) when an upstream rejects thinking by naming the model instead of the field — the exact shape Ollama returns for Instruct-only models like Qwen3-Coder ("Qwen3-Coder:latest" does not support thinking) (#13868). Previously every Claude Code request with a thinking block failed against a self-hosted non-thinking model, with the 400 passed straight to the client.
  • Breaking changes — None in this release.
