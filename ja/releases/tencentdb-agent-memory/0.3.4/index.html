TencentDB-Agent-Memory v0.3.4

TencentDB-エージェント-メモリ v0.3.4

[0.3.4] - 2026-05-12

🚀 新機能

  • オフロード ローカル モード: ローカル モードでのオフロードの実行をサポートし、リモート バックエンドに依存しません。
  • Docker 統合イメージ (Dockerfile.hermes): 単一コンテナーにバンドルされた Hermise Agent +memory_tencentdb プラグイン + TDAI メモリ ゲートウェイ、統合 MODEL_* 環境変数ドライバー

✨ 改善点

  • VDB HTTP リクエスト レベルのタイミング: tcvdb-client はリクエストごとに情報タイミング ログ (/document/hybridSearch 85ms) を生成し、再試行/失敗の詳細はデバッグ レベルのままです。
  • 誤解を招く起動パス ログは DEBUG にダウングレード: ストア マニフェストの不一致、SQLite スキーマの移行、プロファイル同期 MD5 の不一致などの通常のシナリオでは、AI の誤った判断を避けるために warn/info が実行されなくなります。
  • L1 抽出デバッグ ログ: LLM コール チェーンの問題の特定を容易にするために、[l1-debug] シリーズ (RESOLVE / INVOKE / RESULT / EMPTY_DUMP / ENTRY / NO_JSON) を追加しました。
  • オフロード ログは Backend プレフィックスを削除し、デフォルトのタイムアウトは 120 秒です

🐛修正

  • v2026.4.7 より前の OpenClaw バージョンと互換性あり L1 は空の出力を抽出します。古いホストは systemPromptOverride をサポートしておらず、システム プロンプトは extraSystemPrompt フォールバックを通じて挿入されます。
  • TCVDB ハイブリッドは冗長な二重 HTTP 呼び出しをリコールします。nativeHybridSearch ショート サーキットを追加し、1 回の呼び出しで密 + スパース + RRF を完了し、リコール時間が半分になります (~50 ～ 120 ミリ秒)。
  • L2 パーサー アライメント Go バックエンド: マーメイド フォールバックを追加し、first{...last} JSON 抽出ロジックを修正

🔧 互換性の適応

  • OC 2026.4.23 Zod スキーマ互換パッチ スクリプト (scripts/bugfix-20260423/): .strict() によって拒否された allowConversationAccess のワンクリック修復 (軽量バージョン スクリプト、完全自動スクリプト、手動 SOP ドキュメントを含む)

TencentDB-Agent-Memory v0.3.4

Highlights

  • Local-first offload — Offload can now run entirely in local mode without a remote backend, simplifying offline development and reducing infrastructure dependencies.
  • Single-container deployment — Dockerfile.hermes bundles Hermes Agent, memory_tencentdb, and TDAI Memory Gateway into one image, with all model configuration driven by MODEL_* environment variables.
  • Faster hybrid recall — nativeHybridSearch replaces redundant TCVDB HTTP calls with one dense + sparse + RRF request, roughly halving recall latency to ~50–120 ms.
  • OpenClaw 2026.4.23 migration required — The host’s .strict() Zod schema rejects allowConversationAccess. Affected deployments should run the lightweight or automated patch in scripts/bugfix-20260423/, or follow its manual SOP.
  • Broader host compatibility — OpenClaw versions before 2026.4.7 now receive system prompts through extraSystemPrompt when systemPromptOverride is unavailable, preserving L1 extraction behavior on older hosts.
  • Improved diagnostics, less startup noise — Per-request VDB timing is logged at INFO while retry details remain DEBUG; [l1-debug] traces expose the L1 LLM call chain. Benign manifest, schema-migration, and profile-sync messages are downgraded, while offload logs drop the Backend prefix and use a 120-second default timeout.

[0.3.4] - 2026-05-12

🚀 新功能

  • Offload Local Mode：支持本地模式运行 offload，不依赖远端后端
  • Docker 一体化镜像（Dockerfile.hermes）：单容器捆绑 Hermes Agent + memory_tencentdb 插件 + TDAI Memory Gateway，统一 MODEL_* 环境变量驱动

✨ 改进

  • VDB HTTP 请求级计时：tcvdb-client 每次请求打一条 info 计时日志（/document/hybridSearch 85ms），retry/失败细节保持 debug 级别
  • 启动路径误导性日志降级为 DEBUG：store manifest 不一致、sqlite schema migration、profile-sync MD5 mismatch 等正常场景不再打 warn/info，避免 AI 误判
  • L1 提取调试日志：新增 [l1-debug] 系列（RESOLVE / INVOKE / RESULT / EMPTY_DUMP / ENTRY / NO_JSON），方便定位 LLM 调用链问题
  • Offload 日志去掉 Backend 前缀，默认超时为 120s

🐛 修复

  • 兼容 OpenClaw v2026.4.7 以下版本 L1 抽取空输出：旧宿主不支持 systemPromptOverride，通过 extraSystemPrompt 回退注入系统提示
  • TCVDB hybrid 召回冗余双重 HTTP 调用：新增 nativeHybridSearch 短路，单次调用完成 dense + sparse + RRF，recall 耗时减半（~50-120ms）
  • L2 parser 对齐 Go 后端：增加 mermaid fallback，修复 first{...last} JSON 提取逻辑

🔧 兼容性适配

  • OC 2026.4.23 Zod schema 兼容 patch 脚本（scripts/bugfix-20260423/）：一键修复 allowConversationAccess 被 .strict() 拒绝的问题，含轻量版脚本、全自动脚本、手动 SOP 文档
