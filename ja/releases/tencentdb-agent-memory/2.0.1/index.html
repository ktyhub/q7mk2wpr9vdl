TencentDB-エージェント-メモリ v2.0.1

[2.0.1] - 2026-08-25

製品のポジショニング: エージェントのエクスペリエンス、ドキュメント、コードを次のエージェントにとって再利用可能な資産にします ファイルを直接読み取ります。詳細については、README_CN.md を参照してください。

🚀 より多くのエージェント クライアントをサポートする

どのコーディング エージェントを使用しても、チームのメモリに直接接続できるようになりました。

  • OpenCode クライアント アクセスを追加しました
  • DeepSeek ハーネス (dsh) アクセスを追加 - DeepSeek 公式エージェント ハーネス Web UI セッションをプロキシに直接接続して、チームのメモリ/スキル/知識を自動的に取得できます。
  • Codex CLI アクセスを追加しました
  • WorkBuddy クライアント アクセスを追加し、すぐに使用できるようになりました
  • 複数のクライアントの最初の起動とリセットのエクスペリエンスが一貫しているため、切り替えがスムーズになります。

🤖 セッション内で直接コマンドを与える

パネルに切り替える必要はなく、ダイアログで一般的な操作を完了できます。

  • セッション中にバインディングをワンクリックでリセット (チームの変更/エージェントの変更/タスクの変更)
  • 会話内でタスクを直接作成/更新
  • コマンドに対する応答が速くなり、待ち時間が少なくなります

🧠 コールドスタートは追加設定なしで機能します

  • チームまたはユーザーを作成すると、デフォルトのエージェントが自動的に生成され、手動構成は必要ありません
  • 管理者はデフォルトのエージェント テンプレートをカスタマイズでき、新しいユーザーはコールド スタート中に自動的にそれを適用します。
  • IDE の既存のエージェントからのアセットのワンクリック インポートをサポートし、クイック スタートを実現します
  • タスクはアクセス後にデフォルトでバインドされており、箱から出してすぐに使用できます

🔄 セッションバインディングがより安定しました

  • セッション バインディングは永続的に保存され、再起動後も失われません。
  • エージェントを切り替えると、メモリとスキルが正しく切り替わり、シーンに表示されなくなります。
  • 一部のクライアント履歴の再生が誤って判定される問題を修正しました

🧰 スキル経験のアップグレード

  • セッション中に作成された新しいスキルはすぐに取得でき、「検索デッドゾーン」はなくなりました。 -スキルID表示とワンクリックコピーを復元 -オンライン編集をサポートするスキル
  • 新しいアクセス ウィザード スキル: ガイドに従って段階的に設定するか、1 つのコマンドでプロキシ アクセスを自動的に完了します

🎛️ メモリーハブパネル

  • ドット マトリクスの波及効果を追加した、まったく新しいログイン ページ
  • チーム編集/削除ポータルがチームスイッチャーに統合され、操作がよりスムーズになり、切り替えの異常が修正されました。
  • 管理者はアカウント作成時に User_Key をカスタマイズできます
  • 新しい会話メモリ検索: クロスセッションのセマンティックおよびキーワードの取得、権限に応じた表示範囲の正確な制御。 単層メモリの直接上書きと変更をサポート
  • アセット ID は直接表示され、コピーできます。リストは完全にロードされ、ページングの切り捨てによる不完全な表示の問題が修正されます。

⚙️ ワンクリック導入の強化

  • 起動スクリプトは対話型構成をサポートし、LLM チャネルとポートの占有を自動的に事前チェックして、展開の落とし穴を回避します。
  • クライアント アクセス アドレスをワンクリックでコピーし、スタンドアロン展開下のホスト アドレスに自動的に解決できます。外部クライアントは直接接続できます。

⚡ パフォーマンスの最適化

  • ナレッジベースのリストの読み込みが速くなり、頻繁に使用されるパスの応答が速くなります
  • Wiki ページは同時に構築され、単一ページの失敗は自動的に再試行され、大量のドキュメントのインポート時間が大幅に短縮されます。

📚 ドキュメント

  • クライアントごとに独立したアクセス文書を分割し、各エージェントには明確なアクセスガイドがあります
  • 新しいパネルと API の使用法ドキュメントを追加しました
  • 英語パネルのスクリーンショットと README の更新を追加

🐛修正

  • マルチエージェントシナリオでの空のメモリ取得の問題を修正しました
  • アセット数が多い場合、アセットのバインド解除が反映されず、メモリタブが失われる問題を修正しました。
  • インポートされた履歴セッションの時間の混乱を修正し、元のタイムラインを復元しました
  • シーン編集時に一部のコンテンツが繰り返し展開される問題を修正しました
  • macOS での展開スクリプトの互換性の問題を修正しました
  • 依存関係の欠落によって引き起こされるインストールエラーを修正 -古いバージョンでの一部のクライアントの最初のブート フォームの互換性の問題を修正しました
  • 会話メモリをクリアする機能を追加し、一括削除に対応しました

TencentDB-Agent-Memory v2.0.1

Highlights

  • More coding-agent entry points — Adds OpenCode, DeepSeek Harness (dsh), Codex CLI, and WorkBuddy integrations. Notably, dsh Web UI sessions can connect through the Proxy and automatically receive team memory, skills, and knowledge injection.
  • Safer, persistent session context — Bindings now survive restarts, and switching agents keeps memory and skills correctly isolated. Fixes for empty multi-agent retrieval and historical-replay misclassification reduce context leakage; in-chat binding reset and task create/update also simplify switching teams or tasks.
  • Lower-friction onboarding and deployment — New teams and users automatically receive a configurable default agent and task binding. The startup script now prechecks LLM connectivity and port conflicts, resolves host addresses for external clients, and fixes macOS compatibility—reducing common self-hosting setup failures.
  • More predictable skill lifecycle — Skills created during a session become searchable immediately, eliminating the previous search blind spot. Online editing, restored skill-ID display/copy, and guided or one-command Proxy setup make skills easier to manage and reuse.
  • Permission-scoped cross-session memory search — Memory Hub adds semantic and keyword search across conversations, with results constrained by permissions, plus direct single-layer memory overwrite and batch deletion. The write operations are powerful but should be handled carefully in administrative automation.
  • Breaking changes — None are listed for this release.

[2.0.1] - 2026-08-25

产品定位：让 Agent 的经验、文档、代码沉淀成可复用资产，让下一位 Agent 直接读档。详见 README_CN.md。

🚀 支持更多 Agent 客户端

现在无论你用哪款 coding agent，都能直接挂上团队记忆：

  • 新增 OpenCode 客户端接入
  • 新增 DeepSeek Harness (dsh) 接入 —— DeepSeek 官方 agent harness 的 Web UI 会话可直接接入 Proxy，自动获得团队记忆 / skill / 知识注入
  • 新增 Codex CLI 接入
  • 新增 WorkBuddy 客户端接入，开箱即用
  • 多款客户端的首次引导与重置体验保持一致，切换更顺畅

🤖 会话内直接下指令

不用切到面板，在对话里就能完成常用操作：

  • 会话中途一键重置绑定（换团队 / 换 Agent / 换任务）
  • 对话内直接创建 / 更新任务
  • 指令响应更快，减少等待

🧠 冷启动开箱即用

  • 创建团队或用户即自动生成默认 Agent，无需手工配置
  • 管理员可自定义默认 Agent 模板，新用户冷启动自动套用
  • 支持从 IDE 里已有的 Agent 一键导入资产，快速起步
  • 接入后默认绑定任务，即开即用

🔄 会话绑定更稳定

  • 会话绑定持久化保存，重启不丢失
  • 切换 Agent 后记忆与技能正确跟随切换，不再串场
  • 修复部分客户端历史回放被误判的问题

🧰 技能（Skill）体验升级

  • 会话里新建的技能立即可被检索到，不再有"搜索盲区"
  • 恢复技能 ID 的展示与一键复制
  • 技能支持在线编辑
  • 新增接入向导技能：跟着引导一步步配置，或一条命令自动完成 Proxy 接入

🎛️ Memory Hub 面板

  • 全新登录页，加入点阵波纹动效
  • 团队编辑 / 删除入口整合到团队切换器，操作更顺手、修复切换异常
  • 管理员创建账号时可自定义 User_Key
  • 新增对话记忆搜索：跨会话的语义与关键字检索，按权限精确控制可见范围； 支持对单层记忆直接覆盖修改
  • 资产 ID 直接展示并可复制；列表完整加载，修复分页截断显示不全的问题

⚙️ 一键部署增强

  • 启动脚本支持交互式配置，自动预检 LLM 通路与端口占用，避免部署踩坑
  • 客户端接入地址一键复制，单机部署下自动解析为宿主机地址，外部客户端可直接连接

⚡ 性能优化

  • 知识库列表加载提速，常用路径更快响应
  • Wiki 页面并发构建，单页失败自动重试，大批量文档导入时间大幅缩短

📚 文档

  • 按客户端拆分独立接入文档，各 agent 各有一份清晰的接入指南
  • 新增面板与 API 使用文档
  • 补充英文面板截图与 README 更新

🐛 修复

  • 修复多 Agent 场景下记忆检索为空的问题
  • 修复资产解绑不生效、资产较多时记忆 tab 丢失的问题
  • 修复导入历史会话时间错乱，恢复原始时间线
  • 修复编辑场景时部分内容被重复展开的问题
  • 修复 macOS 下部署脚本的兼容性问题
  • 修复依赖缺失导致的安装报错
  • 修复部分客户端首次引导表单在老版本上的兼容性问题
  • 新增清空对话记忆功能，支持批量删除
