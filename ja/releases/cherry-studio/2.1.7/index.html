<summary>Release Note</summary> Cherry Studio 2.1.7 - 音声、クラウド、モデルのアップデート ✨ 新機能 - [音声] Windows x64、Linux、macOS 用の 103 音声を備えた Kokoro 中国語-英語 TTS、および Apple Silicon 用の Qwen3-TTS を追加します。初めて使用する前に、[設定] > [ローカル モデル] からモデルをダウンロードします。 - [音声] 音声再生およびディクテーション コントロールでライブ オーディオ スペクトルを表示します。空のディクテーションの後、マイクを元に戻します。 - [音声] Windows、Linux、macOS にローカル FunASR 音声文字起こしを追加します。 - [Cherry Cloud] サブスクリプション プランとクォータ使用量の可視性をグローバル エディションに追加し、管理対象モデルの期間限定無料クォータと使い果たされたクォータの説明を追加します。 - [Cherry Cloud] コンパクトなアンカー付きサイドバーアカウントメニューを追加します。アバターとニックネームは個人情報設定を開きます。 「外観」と「ログイン」はメニューに残ります。 - [Cherry Cloud] 一時的な接続または更新の失敗時にログインを保持します。 - [自動化] より明確な実行フィードバックを備えた永続的な JavaScript を通じて、ブラウザーとコンピューターの使用を調整します。 - [ナレッジベース] グループ間でナレッジベースをドラッグし、グループを並べ替えます。項目列を昇順、降順、およびデフォルトの順序で循環させます。 - [画像] 16:9、9:16、16:10、および 4K 出力用の GPT-Image-2 アスペクト比プリセットを追加します。 - [モデル] 思考レベルと自動長時間出力継続による Gemini 4 Argon サポートを追加します。 - [モデル] マルチモーダル機能と推論制御を備えた Muse Spark オープン モデル認識を追加します。 - [検索] DuckDuckGo をフリーキーワード Web 検索プロバイダーとして追加します。 API キーは必要ありません。 - [ツール] ツールの結果で画像リンクがプレビューされ、clickable Web リンクが表示されるようになりました。 - [エラー] 読み取り可能な診断、展開可能な詳細、会話、プロバイダー チェック、MCP エラーの回復アクションを含む実用的なエラー通知を表示します。 - [チャット] キューに登録されたフォローアップ メッセージが折りたたまれて開始されます。 Cliヘッダーを確認して展開または折りたたむことができます。 - [チャット] 会話の上にマウスを置くと、フルネーム、アクティビティ時間、ワークスペースの詳細が表示されます。 - [注意事項] コードブロック言語を名前で検索します。 🐛 バグ修正 - [添付ファイル] 認識できない拡張子のテキスト ファイル (例: .lrmx) がテキストとして読み込まれない問題を修正しました。 - [OCR] 非ビジョン モデルに画像を送信するときにどの OCR パスが失敗したかを、失敗タイプごとのガイダンスとともに特定します。 - [ウィンドウ] Windows/Linux でトレイ アイコンが使用できない場合にメイン ウィンドウが閉じてウィンドウが非表示になり、復元または終了できない問題を修正しました。 - [メッセージ] 開示状態を保持し、メッセージ表示でストリーム推論に従います。 - [Composer] プロンプトテキストの指示に自動的に従います。ファイル名の先頭にドットを付けます。エージェント表面上のあらゆる種類のファイルを受け入れます。 - [ファイル] ファイルのコンテキスト メニュー アクションを追加します。ファイルのリンクとアイコンをインライン テキストに合わせて配置します。 - [MCP] 5xx エラーでバージョン プローブを拒否するリモート MCP サーバーに接続します。再接続する前に健全性を確認してください。 - [モデル] Null Gemini モデル リストのページネーション トークンを受け入れます。 Gemini モデルの検出とメタデータの更新を改善します。 - [トレイ] ポータブル インストールには安定した Windows トレイ GUID を使用します。 - [音声] コードブロックおよびインラインコード内のテキストをスキップする読み上げを修正しました。 - [エージェント] ユーザーが declining セットアップによってオンボーディングをオフにできるようにします。 - [翻訳] 余分なツールバー行を追加せずに、入力テキストの横にアイドル状態のディクテーションとコピー ボタンを保持します。 - [コンピュータの使用] クロード エージェントの自動化ツール出力の欠落を修正し、大規模な観察が省略されるのを防ぐために構造化されたアクセシビリティ ツリーのページネーションを追加しました。 - [設定] 設定スクロールバーと一貫したレイアウトを復元し、コンピューターの使用許可アクションを明確にし、clipped コンテンツ、MCP タブ オーダー、および不要な使用状況ヒートマップ オーバーフローを修正します。 </詳細> ## Cherry Studio 2.1.7 - Voice, Cloud, and Model Updates

✨ New Features

  • [Voice] Add Kokoro Chinese-English TTS with 103 voices for Windows x64, Linux and macOS, and Qwen3-TTS for Apple Silicon. Download models from Settings > Local Models before first use.
  • [Voice] Show live audio spectra in speech playback and dictation controls. Restore the microphone after empty dictation.
  • [Voice] Add local FunASR speech transcription on Windows, Linux and macOS.
  • [Cherry Cloud] Add subscription plan and quota usage visibility to the Global edition, with limited-time-free and exhausted-quota descriptions for managed models.
  • [Cherry Cloud] Add a compact anchored sidebar account menu. Avatar and nickname open Personal Information settings; Appearance and Login stay in the menu.
  • [Cherry Cloud] Preserve login during temporary connection or refresh failures.
  • [Automation] Orchestrate Browser and Computer Use through persistent JavaScript with clearer execution feedback.
  • [Knowledge Base] Drag knowledge bases between groups and reorder groups; cycle item columns through ascending, descending and default ordering.
  • [Image] Add GPT-Image-2 aspect ratio presets for 16:9, 9:16, 16:10, and 4K output.
  • [Models] Add Gemini 4 Argon support with thinking levels and automatic long-output continuation.
  • [Models] Add Muse Spark Open model recognition with multimodal capabilities and reasoning controls.
  • [Search] Add DuckDuckGo as a free keyword web search provider. No API key required.
  • [Tools] Tool results now preview image links and display clickable web links.
  • [Errors] Show actionable error notifications with readable diagnoses, expandable details, and recovery actions for conversations, provider checks, and MCP failures.
  • [Chat] Queued follow-up messages start collapsed. Click the header to expand or collapse.
  • [Chat] Hover over conversations to see full name, activity time, and workspace details.
  • [Notes] Search code-block languages by name.

🐛 Bug Fixes

  • [Attachments] Fix unrecognized-extension text files (e.g., .lrmx) not being read as text.
  • [OCR] Identify which OCR path failed when sending images to non-vision models, with guidance for each failure type.
  • [Window] Fix main window closing on Windows/Linux hiding the window when the tray icon is unavailable, leaving no way to restore or quit.
  • [Messages] Preserve disclosure state and follow streamed reasoning in message display.
  • [Composer] Automatically follow prompt text direction; keep leading-dot file names; accept any file type on the agent surface.
  • [Files] Add file context menu actions; align file links and icons with inline text.
  • [MCP] Connect to remote MCP servers that reject the version probe with 5xx errors; confirm health before reconnects.
  • [Models] Accept null Gemini model list pagination tokens; improve Gemini model discovery and metadata refresh.
  • [Tray] Use a stable Windows tray GUID for portable installs.
  • [Voice] Fixed read-aloud skipping text in code blocks and inline code.
  • [Agents] Allow users to turn off onboarding by declining setup.
  • [Translation] Keep idle dictation and copy buttons beside the input text without adding an extra toolbar row.
  • [Computer Use] Fixed missing automation tool output for Claude agents and added structured accessibility-tree pagination to prevent oversized observations from being omitted.
  • [Settings] Restore settings scrollbars and consistent layouts, clarify Computer Use permission actions, and fix clipped content, MCP tab order and unnecessary Usage heatmap overflow.
