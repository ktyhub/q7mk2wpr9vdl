#チェリースタジオv1.7.2

何が変わったのか

  • 修正(api): withoutTrailingSharp ユーティリティを追加し、https://github.com/CherryHQ/cherry-studio/pull/11604 の @EurFelux による #ApiHost 形式での処理を修正
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11619 で @f14XuanLv による空の anthropic-beta ヘッダーの送信を回避
  • https://github.com/CherryHQ/cherry-studio/pull/11635 の @DeJeune によるスキーマの修正/入力
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11469 の @ZKunZhang によるスクロール後にコード ブロック内の選択された領域が変更される
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11649 の @Do1e によって最後のトピックを削除した後もトピック名が残る
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11600 の @EurFelux による oauth 用の古い anthropic-beta ヘッダーを削除
  • fix(settings): https://github.com/CherryHQ/cherry-studio/pull/11631 の @EurFelux による OpenAI 設定の as アサーションによって引き起こされた間違った型を修正
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11587 の @DeJeune による動的なテキストエリアの高さ調整をサポートするために、Inputbar コンポーネントを更新しました。
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11611 の @eeee0717 による ollam URL
  • chore(feishu-notify): https://github.com/CherryHQ/cherry-studio/pull/11656 の @EurFelux による通知カードの変更
  • 修正(apiServer): https://github.com/CherryHQ/cherry-studio/pull/11673 の @beyondkmp により、互換性を向上させるために localhost の代わりに 127.0.0.1 を使用します
  • ci(deps): https://github.com/CherryHQ/cherry-studio/pull/11594 の @dependabot[bot] により Peter-evans/repository-dispatch を 3 から 4 に変更
  • 修正(inputbar): https://github.com/CherryHQ/cherry-studio/pull/11672 で @KazooTTT によって生成中に入力送信をブロックする
  • fix(a11y): https://github.com/CherryHQ/cherry-studio/pull/11678 の @0xfullex による aria-label 属性によるスクリーン リーダー (NVDA) のサポートを改善
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11648 の @DeJeune によるディープシーク v3.2 と一致するようにディープシーク ロジックを更新
  • https://github.com/CherryHQ/cherry-studio/pull/11605 の @Copilot による Vercel AI Gateway のカスタム パラメーターの配置を修正
  • 修正(トピック): https://github.com/CherryHQ/cherry-studio/pull/11665 の @Do1e によってトピック メッセージをクリアするときに関連する message_blocks をクリアする
  • 修正(プロンプト): https://github.com/CherryHQ/cherry-studio/pull/11696 の @EurFelux によるエッジケースの言語検出ルールを明確にしました
  • 特技(設定): https://github.com/CherryHQ/cherry-studio/pull/11664 の @EurFelux によるスペルチェックのスロバキア語サポートを追加
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11580 の @EurFelux によるプロバイダー モデル データの正規化
  • 修正: AiProvider のプロバイダー処理と API キー ローテーション ロジックを強化 (https://github.com/CherryHQ/cherry-studio/pull/11586 の @DeJeune による)
  • feat(translate): https://github.com/CherryHQ/cherry-studio/pull/11615 の @EurFelux によるドキュメント ファイルのサポートとファイル読み取りロジックのリファクタリング
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11701 の @Copilot による正しい OVMS API URL パス形成
  • 修正(移行): https://github.com/CherryHQ/cherry-studio/pull/11703 の @DeJeune による AI ゲートウェイのプロバイダー タイプを正規化
  • fix(stream-options): OpenAI API 用のユーザー構成可能なストリーム オプションを追加 (https://github.com/CherryHQ/cherry-studio/pull/11693 の @EurFelux による)
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11377 の @Copilot によるバッチ処理による複数ファイル選択時の UI フリーズを解消
  • 修正(モデル): https://github.com/CherryHQ/cherry-studio/pull/11732 の @EurFelux によるモデル機能の編集時にアシスタントのデフォルト モデルを更新
  • 修正 (Windows): ポータブル インストールの Git Bash 検出を改善 (https://github.com/CherryHQ/cherry-studio/pull/11671 の @beyondkmp による)
  • feat(aihubmix): https://github.com/CherryHQ/cherry-studio/pull/11734 の @DDU1222 によるウェブサイトのドメインを修正
  • スタイル: https://github.com/CherryHQ/cherry-studio/pull/11731 の @EurFelux によるジェミニのロゴ画像を更新
  • feat(エージェント): モデル選択のためのツールチップを追加し、https://github.com/CherryHQ/cherry-studio/pull/11738 の @EurFelux による i18n を改善しました。
  • feat(models): https://github.com/CherryHQ/cherry-studio/pull/11735 の @EurFelux による AI モデル構成を最新バージョンに更新
  • ci(deps): https://github.com/CherryHQ/cherry-studio/pull/11596 の @dependabot[bot] によるアクション/github スクリプトを 7 から 8 にバンプします。
  • ci(deps): https://github.com/CherryHQ/cherry-studio/pull/11595 の @dependabot[bot] によるアクション/チェックアウトを 4 から 6 にバンプします。
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11653 の @xhaihao による NewApiPage の editImageFiles とアップロード UI を同期しました
  • リファクタリング: https://github.com/CherryHQ/cherry-studio/pull/11663 の @EurFelux による温度と top_p パラメータの処理を改善
  • 功績: @jo1yne06 による AiOnly のデフォルト モデルを https://github.com/CherryHQ/cherry-studio/pull/11745 で更新
  • 修正: https://github.com/CherryHQ/cherry-studio/pull/11744 の @defi-failure による gemini-3-pro-image に対する明示的思考トークンのサポートを追加
  • 功績: ImageViewer コンテキスト メニューの UX を改善 (https://github.com/CherryHQ/cherry-studio/pull/11547 の @EurFelux により)
  • https://github.com/CherryHQ/cherry-studio/pull/11071でショートカットアシスタントがショートカットキーを登録できず@SagoLuで呼び出せない問題を修正
