cherry-studio v1.7.15

Highlights

  • Security / credential change — Fixes path traversal in the DXT plugin system (#12377) and removes the bundled mineru API key (#12455). Anyone using DXT plugins should upgrade; potential breaking change: if you relied on bundled MinerU access, you may need to provide your own API access.
  • Provider and MCP compatibility — sendReasoning now applies only to openai-compatible SDK providers, OpenRouter disables strict JSON schema so MCP tools can work, qwen-code base URLs gain /v1, and image-enhancement history plus trailing-slash image-generation URLs are fixed. Upgrade if you use these providers or workflows.
  • New capabilities — Adds Kimi CLI to Code Tools with custom-provider and Windows Terminal fixes, Qwen text embeddings, baichuan-m3 / baichuan-m3-plus, and Word export for Notes. Worth upgrading if these are useful; otherwise optional.
  • Desktop and reliability — Improves Linux support with musl dependencies, tray-focus, icon, and .deb installation fixes, adds a Linux title-bar setting, and fixes an infinite provider-selector re-render loop. Linux users and those experiencing UI stalls should update; unaffected users can skip these fixes.
  • Migration and verdict — Developer hooks moved from Husky to prek, so contributors must adopt the new tooling; the Translate action’s dual-language selector was removed. No public API or data migration is documented. Overall, update for the security and provider fixes; users outside the affected areas can defer.
