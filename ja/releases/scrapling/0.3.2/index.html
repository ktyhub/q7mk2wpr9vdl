v0.3.2用のRelease Note

🚀 新しいもの

  • オプションのフェッチャーの依存関係: すべてのフェッチャーがオプションの依存関係グループの一部となり、コア パッケージのサイズが削減されます。したがって、基本 scrapling モジュールはパーサーのみになり、フェッチャーまたはコマンドライン オプションを使用するには、pip install "scrapling[fetchers]" を実行する必要があります。詳しい取り付け手順は【こちら】からご確認ください(https://scrapling.readthedocs.io/en/latest/#installation)
  • セッション内のページごとの構成: ブラウザー フェッチャーのセッション クラスが、セッション内のページごとの個別の構成をサポートするようになりました。すべてのフェッチレベルのパラメータがセッションレベルのパラメータと同様に検証されるようになりました。詳細については、ドキュメント Web サイト [こちら] (https://scrapling.readthedocs.io/en/latest/fetching/dynamic/#full-list-of-arguments) をご覧ください。 <br>例: 
    with StealthySession(headless=True, solve_cloudflare=True) as session:    page = session.fetch('https://nopecha.com/demo/cloudflare', google_search=False)
  • ブラウザベースのフェッチャーの改善
    • JavaScript の実行がページ単位で完了するまで待機するかどうかを制御する新しいオプション (以前と同様、デフォルトで有効になっています) 
      with DynamicSession(headless=True, disable_resources=False, network_idle=True) as session:   page = session.fetch('https://quotes.toscrape.com/', load_dom=False)
    • DynamicFetcher とそのセッション クラスにおけるステルス モードの信頼性が向上しました。
    • DynamicFetcher と StealthyFetcher の両方で使用するリソースが少なくなりました (Playwright API の永続コンテキストによって開かれたデフォルトのタブを自動的に見つけて閉じます)
    • ブラウザベースのフェッチャーのページローテーションにおける重大なロジックのバグを修正しました。以前のページは新しいページに置き換えられました。 (ローテーションで再利用されるタブは、そのタブで使用されていた以前の設定によって汚染されている可能性があります)
    • StealthyFetcher とそのセッション クラスがわずかに速くなりました (5%)
  • .body プロパティの強化: 渡されたコンテンツを処理せずにそのまま返すようになり、ファイルのダウンロードと非 HTML リクエストの処理が可能になりました。以下は写真をダウンロードする例です。 
    from scrapling.fetchers import Fetcherpage = Fetcher.get('https://raw.githubusercontent.com/D4Vinci/Scrapling/main/images/poster.png')with open(file='poster.png', mode='wb') as f:   f.write(page.body)

🐛 バグ修正

  • エンコーディングの問題が解決されました: パーサー、mcp モード、および抽出コマンドの一部の Web サイトで発生した複数のエンコーディングの問題を修正しました (#80 と #81 も解決します)
  • 解析の高速化: あちこちで多くの変更が加えられたため、ライブラリが高速になり、それが更新されたベンチマークに反映されています。

🔨 その他

  • ベンチマークの更新: 現在の速度の向上を同様のライブラリの最新バージョンと比較するためのパフォーマンス ベンチマークの更新
  • 多くのコードをリファクタリングし、デッドコードをより良い実装に置き換えました: コードが減り、コードがクリーンになり、メンテナンスが容易になりました。
  • YouTube ビデオを追加: MCP ドキュメントのビデオ コンテンツが含まれています。
  • 新しい問題テンプレート: 現在のテンプレートを使用できないユーザーのための簡単な新しいテンプレート。
  • CI ワークフローの最適化: ドキュメント ファイルまたはコード以外のファイルのみが変更された場合、テスト ワークフローの実行がスキップされるようになりました。
  • 依存関係の更新: さまざまな依存関係を最新バージョンに追加しました。
  • コード スタイルの改善: すべてのファイルに新しい ruff ルールを適用しました。
  • Pre-commit フック: Pre-commit 構成を更新しました。

Scrapling v0.3.2

Highlights

  • Install layout changed (breaking) — Fetchers and the CLI are no longer in the base package; scrapling is now parser-only. Anyone using Fetcher, DynamicFetcher, StealthyFetcher, the session classes, or CLI commands must reinstall as pip install "scrapling[fetchers]" or imports will break. This is the main migration step in this release.

  • max_pages removed (breaking) — The max_pages argument was dropped from the sync StealthySession to match DynamicSession (it was meaningless in the sync version). Remove it from any call sites that still pass it.

  • Browser fetchers are more reliable and lighter — A "vital" page-rotation bug is fixed: reused tabs could carry contaminated settings from earlier pages, and are now replaced with fresh ones. Persistent-context default tabs are auto-closed to cut resource use, stealth is more reliable in DynamicFetcher, and StealthyFetcher is ~5% faster. A new load_dom flag controls whether to wait for JS (on by default, preserving old behavior). This matters most for long sessions where leaked tab state produced wrong results.

  • New per-page config and raw .body — Session classes now accept fetch-level parameters on individual fetch() calls (e.g. session.fetch(url, google_search=False)) with the same validation as session-level args. .body now returns content as-is without processing, enabling binary file downloads and non-HTML responses.

  • Encoding/parsing fixes and verdict — Multiple encoding bugs in the parser, MCP mode, and extract commands are resolved (#80, #81), and parsing is faster with refreshed benchmarks. Worth upgrading for fetcher/session users (the install change forces a reinstall anyway), anyone hit by #80/#81, or anyone needing binary downloads. Parser-only users who don't touch the CLI/fetchers and never hit encoding issues can skip — the rest is refactors, benchmarks, and docs.

Release Notes for v0.3.2

🚀 New Stuff

  • Optional fetcher dependencies: All fetchers are now part of optional dependency groups, reducing core package size. So the base scrapling module is now the parser only, and to use the fetchers or the commandline options, you have to do: pip install "scrapling[fetchers]". Check out the detailed installation instructions from here

  • Per-page configuration in sessions: Session classes for browser fetchers now support individual configuration per page in sessions. All fetch-level parameters are now validated like session-level ones. More details on the documentation website here <br>Example:

    with StealthySession(headless=True, solve_cloudflare=True) as session:
    page = session.fetch('https://nopecha.com/demo/cloudflare', google_search=False)

  • Improved browser-based fetchers

    • A new option to control whether to wait for JavaScript execution to finish in pages or not (it's enabled by default now, as it was before) 
      with DynamicSession(headless=True, disable_resources=False, network_idle=True) as session:   page = session.fetch('https://quotes.toscrape.com/', load_dom=False)
    • The Stealth mode is now more reliable in DynamicFetcher and its session classes.
    • Both DynamicFetcher and StealthyFetcher are now using fewer resources (Automatically finding and closing the default tab opened by Persistent contexts in Playwright API)
    • Fixed a vital logic bug in browser-based fetchers' pages rotation - previous pages are now replaced with fresh ones. (Tabs that get reused in rotation are possibly contaminated from previous settings used on them)
    • StealthyFetcher and its session classes are now slightly faster (5%)

  • Enhanced .body property: Now returns the passed content as-is without processing, enabling file downloads and handling non-HTML requests. Below is an example of downloading a photo:

    from scrapling.fetchers import Fetcher

page = Fetcher.get('https://raw.githubusercontent.com/D4Vinci/Scrapling/main/images/poster.png')
with open(file='poster.png', mode='wb') as f:
   f.write(page.body)

🐛 Bug Fixes

  • Encoding issues resolved: Fixed multiple encoding problems that happened with some websites in parser, mcp mode, and extract commands (Also solves #80 and #81)
  • Faster parsing: Due to many changes here and there, the library is now faster, and it's reflected in the updated benchmarks

🔨 Misc

  • Updated benchmarks: Refreshed performance benchmarks to compare the current speed improvements to the latest versions of similar libraries
  • Refactored a lot of the code and replaced dead code with better implementations: Fewer code, cleaner code, easier maintenance
  • Added YouTube video: Included video content for MCP documentation.
  • A new issues template: Easy new template for users who can't use the current templates.
  • CI workflow optimization: Tests workflow now skips runs when only documentation or non-code files are changed.
  • Updated dependencies: Bumped up various dependencies to the latest versions.
  • Code style improvements: Applied new ruff rules across all files.
  • Pre-commit hooks: Updated pre-commit configuration.

🎯 Breaking Changes

  • Removed max_pages parameter from sync StealthySession to match DynamicSession (it's meaningless to have in the sync version)

🙏 Special thanks to our Discord community for all the continuous testing and feedback
