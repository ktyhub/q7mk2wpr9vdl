LlamaFactory v0.9.3

Highlights

  • Multimodal and reasoning model coverage — Qwen3 (#7885), InternVL2.5/3 (#7258), Qwen2.5-Omni (#7537), Kimi-VL (#7719), Llama 4/Gemma 3 (#7273, #7611), and MiMo-VL (#8249) extend shared fine-tuning workflows across text, images, audio, video, and reasoning. Verify model-specific templates, preprocessing, and memory requirements rather than reusing text-only configurations.
  • Inference and deployment choices — SGLang support (#7278), vLLM audio/video batch inference (#7566, #7992, #8264), vLLM-Ascend (#7739), and an official GPU Docker image (#8181) provide more production serving paths. Pin backend and container versions, and validate multimodal payload handling before replacing an existing server.
  • Cloud-scale training resilience — PyTorch Elastic and fault-tolerant launching (#8286), S3/GCS and Ray storage (#7567, #7854), remote folder loading (#8078), and data_shared_file_system (#8179) support restartable distributed jobs with remote datasets. Confirm worker credentials, filesystem visibility, and elastic restart behavior in your cluster.
  • New training controls — Muon (#7749), early stopping (#7797), OmegaConf (#7793), LD-DPO (#8362), and enable_thinking (#7928) expand optimization and configuration options. LD-DPO targets length bias in preference training, while the thinking toggle can materially change outputs; benchmark settings and regression-test template parsing.
  • Quantization backend migration — The GPTQ integration switches to GPTQModel, with AutoGPTQ deprecated (#8108). Update imports, configuration, and CI to the new backend, then revalidate quantized generation and LoRA adapters—particularly alongside the LoRA-on-quantized-models fix (#7456).
  • Correctness changes to validate — Neat-packing attention masks and position IDs are corrected (#7272, #7318, #7754, #8387), multimodal projectors now unfreeze correctly (#7872), and DeepSpeed ZeRO-3 handling for MoE models is repaired (#7826, #7879). Base-model EOS tokens also change (#7911). Re-run packed-sequence, multimodal, and generation-stopping smoke tests before promoting checkpoints.
