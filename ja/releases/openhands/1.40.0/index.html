macOS インストールに関するメモ

アプリはまだ Apple Developer ID で署名されていないため、macOS は ダウンロードされたビルド 「破損」 — これは Gatekeeper の隔離であり、不良ファイルではありません。 アプリを「アプリケーション」に移動した後、フラグを一度クリアしてから、通常どおり開きます。

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

署名と公証は OpenHands/OpenHands#16774 で追跡されます。

OpenHands v1.40.0

Highlights

  • Codex subscription auth guidance (PR #17194) — The only net-new feature in 1.40.0: clearer in-app guidance for authenticating via a Codex subscription, with companion Indonesian translations for the new keys added in PR #19685. Treat this as onboarding/policy polish rather than a new auth flow — the underlying credential mechanism is unchanged — but expect fewer dead-ends if you're onboarding users onto Codex-backed models.

  • Git stops assuming main is the default branch (PR #19604) — The change most likely to alter observable behavior: git operations now resolve a repository's real default branch instead of hardcoding main. Teams on master, trunk, or custom defaults get correct branch targeting, but audit any automation that implicitly relied on the old main assumption before rolling out.

  • Chat history pagination at tied boundaries (PR #19649) — Messages landing exactly on equal history-page boundaries were being dropped or misplaced during paging. If you scroll long sessions or consume paginated conversation APIs, this prevents missing or duplicated messages at boundary offsets.

  • Draft-loss race fixed (PR #19382) — Delayed echo responses could delete newer drafts typed in the meantime — a genuine, if subtle, data-loss bug. Users on slower or high-latency backends benefit most; no migration needed, but worth confirming anyone who'd adopted a manual workaround can drop it.

  • Self-hosted model picker restored when Agent Profiles are off (PR #19682) — Self-hosters who disable Agent Profiles now correctly get the home model picker instead of a blank/broken model state. If you manage a self-managed instance with Profiles disabled, this restores standard model selection.

  • macOS builds still unsigned — manual Gatekeeper step required — Downloads remain unsigned with an Apple Developer ID, so macOS may flag the app as "damaged." After moving it to Applications, run xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app" once; signing/notarization is tracked in #16774, so bake this into any macOS rollout or MDM script until then.

  • Breaking changes — None in this release.

macOS install note

The app isn't signed with an Apple Developer ID yet, so macOS may call a downloaded build "damaged" — it's Gatekeeper quarantine, not a bad file. After moving the app to Applications, clear the flag once, then open normally:

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

Signing + notarization is tracked in OpenHands/OpenHands#16774.
