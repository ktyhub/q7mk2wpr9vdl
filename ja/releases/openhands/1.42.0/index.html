macOS インストールに関するメモ

アプリはまだ Apple Developer ID で署名されていないため、macOS は ダウンロードされたビルド 「破損」 — これは Gatekeeper の隔離であり、不良ファイルではありません。 アプリを「アプリケーション」に移動した後、フラグを一度クリアしてから、通常どおり開きます。

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

署名と公証は OpenHands/OpenHands#16774 で追跡されます。

OpenHands v1.42.0

Highlights

  • Explicit git-provider selection for cloud repos — PR #19762 lets you pin which connected git provider (GitHub, GitLab, etc.) backs a repository instead of relying on auto-detection. If your account has multiple providers connected, this removes ambiguity around which OAuth token and permission scope a repo uses — worth rechecking repos that may have been resolved to the wrong provider before this release.
  • Reachable HTTP origin in verify-openhands — PR #19756 gives every verification run a non-loopback, plain-HTTP origin rather than binding only to 127.0.0.1. This is the change that unblocks CI-driven verification and webhook/browser callbacks that previously failed when the caller wasn't on the host. It's plain HTTP, so put a TLS terminator in front of it before exposing it anywhere beyond a trusted network.
  • Webhook source validation restored in automations — PR #19600 (first contribution from @1kailas) brings back native validation of webhook sources. Automations whose webhook events were being dropped or rejected in v1.41 should start firing again; if you added permissive filters as a workaround, re-audit them, since native validation may now reject payloads those filters were letting through.
  • Graceful clipboard degradation — PR #18583 adds a fallback when the browser Clipboard API is unavailable (insecure contexts, embedded webviews, older browsers). Copy/paste actions now degrade instead of throwing — relevant if you serve the web UI over plain HTTP or run it inside the Electron Canvas webview.
  • macOS Gatekeeper friction persists — Builds are still unsigned/unnotarized (tracking in #16774), so a fresh download may be flagged as "damaged." After moving the app to Applications, clear quarantine once with xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app" before first launch, and expect to repeat it on every new build until signing lands. Smaller behavioral nits: EnumFilterDropdown now closes on Escape (#19817), and the Electron dev dependency moves 45.2.3 → 45.3.0 (#19826) amid routine bumps — worth a desktop smoke test.
  • Breaking changes — None in this release.

macOS install note

The app isn't signed with an Apple Developer ID yet, so macOS may call a downloaded build "damaged" — it's Gatekeeper quarantine, not a bad file. After moving the app to Applications, clear the flag once, then open normally:

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

Signing + notarization is tracked in OpenHands/OpenHands#16774.
