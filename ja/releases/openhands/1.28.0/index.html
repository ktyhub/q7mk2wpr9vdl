OpenHands v1.28.0

Highlights

  • In-conversation secrets and chat polish — The agent can now request a secret through an inline chat modal instead of an out-of-band flow (#18408, #18575), and message output streams at reading pace with word fade-in (#18491). No configuration needed; this is a genuine UX improvement for interactive users, not just polish.
  • Migration: MARS web bridge is now on by default — refactor(mars) (#18349) mounts the web bridge unconditionally and drops the MARS_WEB=1 opt-in, so anyone relying on that flag to gate the bridge must adjust their setup. Separately, fix(plugins) (#18622) now explicitly rejects unsupported Local launch parameters rather than tolerating them — audit Local-launch configs before upgrading, as previously-silent inputs can now fail.
  • Cloud runtime and automations reliability (main reason to upgrade) — Real fixes here: messages are held until the cloud runtime is reachable instead of failing (OHE-3314, #18443), paused cloud sandboxes are woken from Resume rather than calling their runtime (OHE-3407, #18442), launch now fails fast when the automation backend exits during startup (#18311), and self-hosted templates overlapping built-in integrations are hidden (OHE-3611, #18565). Cloud and automation users should upgrade for these alone.
  • verify-openhands tooling + ecosystem changes — The "known bugs" framework matures with executable bugs and a shared contract (#18348, #18355) plus extensive maintenance mapping docs — relevant mainly if you run or contribute to the verifier. Also: fix(library) preserves ESM peer imports in browser hosts (#18619), a Bahasa Indonesia (id) locale was added (#18067), and dependencies moved to agent-server 1.55.1 (#18500) and automation 1.21.0 (#18647).
  • Verdict — Not a no-op: this is a substantive minor release. Worth upgrading for cloud-sandbox users, automation/self-hosted operators, and anyone wanting inline secrets or accessibility fixes (a large contrast/semantic-color sweep, e.g. 4.5:1 error pills #18482, plus RTL and keyboard-accessibility fixes). Users who only use local chat and none of automations/cloud can safely skip, since much of the remaining diff is lint/theme/CI housekeeping. No data-migration steps are called out beyond the MARS_WEB=1 and Local-parameter behavior changes above.
