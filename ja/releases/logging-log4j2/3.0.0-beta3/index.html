logging-log4j2 3.0.0-beta3

メジャー 公開日2024年11月12日 出典apache/logging-log4j2 English original

#logging-log4j2 rel/3.0.0-beta3

このリリースでは、オプションの log4j-core 依存関係を使用するすべてのコードを新しいモジュールに移動することにより、Log4j コアのモジュール化プロセスを終了します。

  • 最近の Windows OS は ANSI エスケープ シーケンスをサポートしているため、JAnsi ライブラリのサポートは削除されました。 詳細については、「Windows での ANSI スタイル設定」(https://logging.apache.org/log4j/3.x/manual/pattern-layout.html#ansi-windows) を参照してください。
  • DisruptorBlockinQueue キュー ファクトリ は、新しい log4j-conversant アーティファクト に移動されました。
  • 高度な圧縮アルゴリズム のサポートは、新しい log4j-compress アーティファクト に移動されました。 Gzip および Zip 形式は、そのままの状態で引き続きサポートされます。

個別のライフサイクル

  • Flume Appender リリースは独自のライフサイクルに従います。
  • Log4j API との間のすべての ロギング ブリッジ は、Log4j Core 3.x リリースから削除されました。 互換性のあるバージョンのロギング ブリッジを常に使用するには、log4j-bom で依存関係を管理してください。

追加

  • RFC5424 レイアウトに useFqdn 構成属性を追加します。 (#1740)
  • log4j-jdbc の JNDI サポートを新しい log4j-jdbc-jndi モジュールに分割 (#1914)
  • Web サイトに 「プラグイン リファレンス」 を追加します。これは、Log4j プラグインに焦点を当てた Javadoc-on-steroids です。 (#1954)
  • 拡張圧縮アルゴリズムのサポートを新しい log4j-compress モジュールに分割しました。 (#2921)

変更されました

  • Windows コンソールが ANSI エスケープをサポートするようになったので、JAnsi ライブラリのサポートを削除します。 (#1736)
  • DisruptorBlockingQueue プラグインを新しい log4j-conversant モジュールに移動します。 (#2914)
  • JAnsi ライブラリなしで動作するように JAnsiTextRenderer を書き換えます。 (#2916)

修正済み

  • MongoDB テストを Docker を使用するように切り替えます。 (#2229)
  • ルックアップとフィルターでのカスタム スレッド コンテキスト データ プロバイダーの処理を修正しました。 (#2331)
  • HTTP(S) ソースからの設定のリロードを修正 (#2937)
  • Log4j Core の Android 関連の問題を修正。 (#3056)
  • ウェブサイトは Antora に移行され、いくつかのフォーマットとリンクが修正されました (#2443)

削除されました

  • UNIX と UNIX_MILLIS を除く、パターン レイアウトの named 日付と時刻の書式設定パターンを削除します (#3150)
  • Flume Appender を独自のリリース ライフサイクルに移動します。 (#2902)
  • ThrowableProxy とその使用法を削除 (#3047)
  • ロギング ブリッジをディストリビューションから削除し、log4j-bom で 2.x の同等のものを参照します。
  • ロガー ラッパーを生成し、構成ファイルを変換するための CLI ツールを削除します。 これらのツールは、Log4j Transform の次のリリースで利用可能になります。
  • 非推奨の org.apache.logging.log4j.core.appender.rolling.action.Duration クラスを削除します。
  • log4j-1.2-api モジュール (#2621) を削除します。
  • log4j-iostreams モジュール (#2630) を取り外します。

logging-log4j2 rel/3.0.0-beta3

This release terminates the modularization process of Log4j Core, by moving all the code that uses optional log4j-core dependencies into new modules:

  • Support for the JAnsi library has been removed since recent Windows OSes support ANSI escape sequences. See ANSI styling on Windows for more details.
  • The DisruptorBlockinQueue queue factory has been moved to a new log4j-conversant artifact.
  • Support for advanced compression algorithms has been moved to a new log4j-compress artifact. The Gzip and Zip formats are still supported out-of-the-box.

Separate lifecycle

  • The Flume Appender releases will follow their own lifecycle.
  • All the logging bridges from and to Log4j API have been removed from the Log4j Core 3.x release. Please manage your dependencies with log4j-bom to always use the compatible version of the logging bridges.

Added

  • Add useFqdn configuration attribute to RFC5424 Layout. (#1740)
  • Split off JNDI support of log4j-jdbc to a new log4j-jdbc-jndi module (#1914)
  • Add "Plugin Reference" to the website. It is a Javadoc-on-steroids focusing on Log4j plugins. (#1954)
  • Split extended compression algorithm support to new log4j-compress module. (#2921)

Changed

  • Remove JAnsi library support, since Windows console supports ANSI escapes now. (#1736)
  • Move DisruptorBlockingQueue plugin to new log4j-conversant module. (#2914)
  • Rewrite JAnsiTextRenderer to work without JAnsi library. (#2916)

Fixed

  • Switch MongoDB tests to use Docker. (#2229)
  • Fix custom thread-context data provider handling in lookups and filters. (#2331)
  • Fix reloading of the configuration from an HTTP(S) source (#2937)
  • Fix Android-related issues in Log4j Core. (#3056)
  • Website is migrated to Antora with several formatting and link fixes (#2443)

Removed

  • Remove named date & time formatting patterns in Pattern Layout, except for UNIX and UNIX_MILLIS (#3150)
  • Move Flume Appender to its own release lifecycle. (#2902)
  • Remove ThrowableProxy and its usages (#3047)
  • Remove logging bridges from distribution and reference their 2.x equivalents in log4j-bom.
  • Remove CLI tools to generate logger wrappers and convert configuration files. These tools will be available in the next release of Log4j Transform.
  • Remove deprecated org.apache.logging.log4j.core.appender.rolling.action.Duration class.
  • Remove log4j-1.2-api module (#2621)
  • Remove log4j-iostreams module (#2630)

Updated

  • Update apache/logging-parent to version `` (#2598)
  • Update com.fasterxml.jackson:jackson-bom to version 2.18.1 (#3136)
  • Update io.fabric8:docker-maven-plugin to version 0.45.1 (#3036)
  • Update org.apache.commons:commons-compress to version 1.27.1 (#2870)
  • Update org.apache.commons:commons-csv to version 1.12.0 (#3020)
  • Update org.apache.commons:commons-dbcp2 to version 2.12.0 (#2342)
  • Update org.apache.logging.log4j:log4j-api to version 2.24.1 (#3035)
  • Update org.jctools:jctools-core to version 4.0.5 (#2638)
  • Update org.jspecify:jspecify to version 1.0.0 (#2750)
  • Update org.mongodb:bson to version 5.2.1 (#3179)
  • Update org.springframework.boot:spring-boot-autoconfigure to version 3.3.5 (#3120)
  • Update org.springframework.cloud:spring-cloud-context to version 4.1.4 (#2733)
  • Update org.springframework:spring-framework-bom to version 6.1.14 (#3102)
