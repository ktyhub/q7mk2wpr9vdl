#AstrBot v4.30.0-alpha.1

[4.30.0-alpha.1] - 2026-11-15

**このバージョンはアルファテストバージョンであり、不安定性や互換性の問題がある可能性があります。まずはテスト環境で検証することをお勧めします。この時間には、会話データベース、エージェント構成、およびセッション設定の移行が含まれます。アップグレードする前に、データと構成をバックアップしてください。古いバージョンにロールバックする場合は、同時にアップグレードする前にバックアップを復元する必要があります。このバージョンを重要な運用環境では使用しないでください。 **

メジャーアップデート

  • セッション バックエンドをイベント ソーシング モードに移行して、コンテキストの繰り返し書き込みと部分的な書き込み増幅を削減し、ストレージ パフォーマンスを最適化します。メッセージとツール呼び出しを段階的に保存し、実行中断後の履歴処理を改善します。 (#10077、#11158、#11162)
  • 新しいエージェント ランタイム モデルの導入。プラグインは、ctx.agent.run_turn() を介してエージェント ターンを呼び出すことができます。詳細については、「既存セッションのエージェントの呼び出し」(https://github.com/AstrBotDevs/AstrBot/blob/739840886c5fbbd439f477ac4b6e8eb7ba3e0649/docs/zh/dev/star/guides/ai/agent.md#%E8%B0%83%E7%94%A8%E7%8E%B0%E6%9C%89%E4%BC%9A%E8%AF%9D%E7%9A%84-agent-run-session-agent) (#10934、#10936、#11052、#11148、#11153) を参照してください。
  • サブエージェントを独立したコンテキストを持つバックグラウンド タスクに再構築し、一般エージェントと特別エージェント、追加の命令、および結果の戻りをサポートします。入り口はサイドバーから **プロファイル → AI → 機能 → サブエージェント ** に移動し、プロファイルによって管理されます。 (#11053)
  • カスタム ルールとセッション管理を [構成ファイル] → [セッション構成マッピングの管理] に統合し、基本的な構成とフィールド カバレッジ、バッチ編集とリカバリの継承をサポートします。モデルの説明書とページは同じ設定を共有します。 (#11097)
  • ワークスペースの分離、コード実行、ネットワーク制御をサポートする Windows AppContainer ネイティブ サンドボックスを追加しました。 (#10466)
  • DeepSeek 音声認識および音声合成プロバイダーを追加しました。 (#11118)
  • OpenAI Decisions 判定モデルを追加し、選択、ブール判定、スコアリングをサポートしました。 (#10968)
  • ようこそページ → 概要: 毎日の使用状況、システム リソース、ロボットの例外が表示されます。 (#11100)
  • 外観設定でサイドバーにチャット入口を配置できるようにしました。 (#11090)
  • アップグレードされた Markdown レンダリング、オンデマンドでのチャットおよび構文ハイライト リソースの読み込み。 (#11138)
  • プラグイン設定は折りたたみ可能なグループをサポートし、デフォルトの折りたたみ状態を宣言できます。 (#11067)
  • プラグイン ページでは、現在のテーマの色とその変更を取得できます。 (#11046)
  • AI 開発ドキュメントを再編成し、プラグイン構成制御の例とスクリーンショットを追加しました。 (#11154)

最適化と修復

  • 操作中の追加入力の保存と継続を改善しました。 (#11141)
  • メインセッションのブロックを避けるために、実行時に使用できないサブエージェント構成をスキップします。 (#11128)
  • 実行時に無効になっている、欠落している、または使用できないサブエージェント構成の選択を解除できるようにします。 (#11147)
  • フル ツール スキーマ モードでのデフォルトのツール呼び出しプロンプト ワードを削除しました。 (#11152) ・最後に成功したモデルのリトライが失敗と判定されてしまう問題を修正しました。 (#10922)
  • Anthropic の非ストリーミング応答で複数のテキスト ブロックが欠落している問題を修正しました。 (#11057)
  • 検索キーの有効期限が切れたり、残高が不足したりした場合は、設定されている他のキーを試してください。 (#10877)
  • Gemini TTS のデフォルト モデルを gemini-3.8-flash-tts に更新しました。 (#10828)
  • 失われた写真、ファイル、その他のメディアに QQ ボタンが応答する問題を修正しました。 (#10903)
  • QQ イメージのアップロードが失敗した場合に完全なイメージ ロードを記録しないようにし、パネルへのログの影響を軽減します。 (#10740)
  • OneBot ストリーミング セグメンテーションを最適化して、長いテキストの繰り返しスキャンを削減します。 (#10989)
  • 送信者がユーザー名を持たない場合、Telegram は表示名を使用します。 (#10715)
  • Firefox でのチャット履歴のスクロールの問題を修正しました。 (#11036) -モデル構成を編集するときにプレビューと機能の識別が一致しない問題を修正しました。 (#10792)
  • WebUI メニューとポップアップ ウィンドウのスタイルを統一し、スクロール バーとクリック フィードバックを最適化します。 (#11107、#11090、#11102)
  • EPUB 解析でリンク テキストが欠落する問題を修正しました。 (#10794)
  • GIF をパズルに変換した後も説明を保持し、歴史的文脈におけるアニメーション情報が失われないようにします。 (#10837)
  • フィルタリングとトラブルシューティングを容易にするために、プラグインのロードと実行の失敗ログを対応するプラグインに関連付けます。 (#10904)
  • スタック接続状態を回避するために、SSE ストリームが閉じられたときにプラグイン ページに通知します。 (#10932)
  • コンソール ログのタイムスタンプは日付ごとに増分されます。 (#9617)

これはアルファ版リリースであり、安定性や互換性の問題が発生する可能性があります。まずテスト環境で検証してください。このリリースでは、会話ストレージ、エージェント構成、およびセッション設定が移行されます。アップグレードする前にデータと構成をバックアップしてください。ダウングレードには、アップグレード前のバックアップの復元も必要です。

ハイライト

  • 会話をイベント ソーシングに移行し、重複したコンテキスト書き込みと一部の書き込み増幅を削減します。メッセージとツール呼び出しを段階的に保持し、実行が中断された後の履歴処理を改善します。 (#10077、#11158、#11162)
  • 新しいエージェント ランタイム モデルを導入します。プラグインは、ctx.agent.run_turn() を通じてエージェント ターンを呼び出すことができます。 (#10934、#10936、#11052、#11148、#11153)
  • サブエージェントを、独立したコンテキスト、汎用または特殊な構成、フォローアップ入力、および結果配信を備えたバックグラウンド タスクとして再構築します。プロファイルごとの設定を使用して、管理をサイドバーから Config → AI → Capabilities → Subagents に移動します。 (#11053)
  • カスタム ルールとセッション管理を [構成] → [セッション マッピングの管理] にマージし、基本プロファイル、フィールド オーバーライド、バッチ編集、復元された継承をサポートします。モデル コマンドとエディターは同じ設定を共有します。 (#11097)
  • ワークスペースの分離、コード実行、ネットワーク制御を備えた Windows AppContainer サンドボックスを追加します。 (#10466)
  • DeepSeek 音声認識および合成プロバイダーを追加します。 (#11118)
  • 選択肢、ブール質問、スコア用の OpenAI Decisions モデルを追加します。 (#10968)
  • ようこそ → 概要 に、毎日の使用状況、システム リソース、ボット エラーが表示されるようになりました。 (#11100)
  • サイドバーにチャットを表示するための外観設定を追加します。 (#11090)
  • Markdown レンダリングをアップグレードし、チャットや構文強調表示のアセットをオンデマンドでロードします。 (#11138)
  • 構成可能な初期状態を持つ折りたたみ可能なプラグイン構成グループを追加します。 (#11067)
  • 現在のテーマの色とその更新をプラグイン ページに公開します。 (#11046)
  • AI 開発ガイドを再構成し、プラグイン構成制御の例とスクリーンショットを追加しました。 (#11154)

  • 成功した最終モデルの再試行が失敗として報告される問題を修正しました。 (#10922)
  • 非ストリーミング Anthropic 応答内のすべてのテキスト ブロックを保持します。 (#11057)
  • キーが無効であるか、そのクォータが使い果たされている場合は、構成されている他の検索キーを試してください。 (#10877)
  • デフォルトの Gemini TTS モデルを gemini-3.8-flash-tts に更新します。 (#10828)
  • 画像、ファイル、その他のメディアを QQ ボタンの応答に保存します。 (#10903)
  • QQ アップロード失敗時の完全な画像ペイロードのログ記録を停止し、ダッシュボードへの影響を軽減します。 (#10740)
  • 長いテキストの繰り返しスキャンを回避することで、OneBot ストリーミング セグメンテーションを改善します。 (#10989)
  • ユーザー名が存在しない場合は、Telegram の表示名を使用します。 (#10715)

  • WebUI のメニューとダイアログを統合し、スクロールバーとプレスのフィードバックを調整します。 (#11107、#11090、#11102)

  • 会話履歴に GIF モンタージュ ガイダンスを保持するため、アニメーション コンテキストが保持されます。 (#10837)
  • ログのフィルタリングを容易にするために、プラグインの読み込みエラーと実行エラーをプラグインに関連付けます。 (#10904)
  • 古い接続状態を避けるために、SSE ストリームが閉じるときにプラグイン ページに通知します。 (#10932)
  • コンソール ログのタイムスタンプに日付を含めます。 (#9617)

AstrBot v4.30.0-alpha.1

[4.30.0-alpha.1] - 2026-11-15

本版本为 Alpha 测试版，可能存在不稳定或兼容性问题，建议先在测试环境验证。本次涉及对话数据库、Agent 配置和会话设置迁移。升级前请备份数据与配置；回退旧版需同时恢复升级前备份。请不要在重要的生产环境使用该版本。

主要更新

  • 将会话后端迁移到事件溯源方式，减少重复上下文写入和部分写放大，优化存储性能；增量保存消息与工具调用，完善执行中断后的历史处理。 (#10077, #11158, #11162)
  • 引入新的 Agent 运行时模型。插件可通过 ctx.agent.run_turn() 唤起 Agent turn。详见 调用现有会话的 Agent (#10934, #10936, #11052, #11148, #11153)
  • 重构子代理为具有独立上下文的后台任务，支持通用与专用 Agent、追加指令和结果回传。入口由侧边栏移至 配置文件 → AI → 能力 → 子代理，按配置文件管理。 (#11053)
  • 将自定义规则与会话管理统一至 配置文件 → 管理会话配置映射，支持基础配置与字段覆盖、批量编辑和恢复继承；模型指令与页面共用同一份设置。 (#11097)
  • 新增 Windows AppContainer 本机沙盒，支持工作区隔离、代码执行与联网控制。 (#10466)
  • 新增 DeepSeek 语音识别与语音合成提供商。 (#11118)
  • 新增 OpenAI Decisions 判断模型，支持选择、布尔判断与评分。 (#10968)
  • 欢迎页 → 总览：展示每日用量、系统资源及机器人异常。 (#11100)
  • 支持在外观设置中将聊天入口放入侧边栏。 (#11090)
  • 升级 Markdown 渲染，按需加载聊天与语法高亮资源。 (#11138)
  • 插件配置支持可折叠分组，并可声明默认收起状态。 (#11067)
  • 插件页面可获取当前主题颜色及其变化。 (#11046)
  • 重整 AI 开发文档，补充插件配置控件示例与截图。 (#11154)

优化与修复

  • 完善运行中追加输入的保存与继续执行。 (#11141)
  • 跳过运行时不可用的子代理配置，避免阻断主会话。 (#11128)
  • 允许取消选择已禁用、缺失或运行时不可用的子代理配置。 (#11147)
  • 移除完整工具 Schema 模式下的默认工具调用提示词。 (#11152)
  • 修复模型最后一次重试成功仍被判定为失败的问题。 (#10922)
  • 修复 Anthropic 非流式响应丢失多个文本块的问题。 (#11057)
  • 搜索密钥失效或额度不足时，尝试其他已配置的密钥。 (#10877)
  • 将 Gemini TTS 默认模型更新为 gemini-3.8-flash-tts。 (#10828)
  • 修复 QQ 按钮回复丢失图片、文件等媒体的问题。 (#10903)
  • 避免 QQ 图片上传失败时记录完整图片载荷，减少日志对面板的影响。 (#10740)
  • 优化 OneBot 流式分段，减少长文本的重复扫描。 (#10989)
  • Telegram 发送者没有用户名时，使用显示名称。 (#10715)
  • 修复 Firefox 中聊天历史滚动跳动的问题。 (#11036)
  • 修复编辑模型配置时预览与能力标识不一致的问题。 (#10792)
  • 统一 WebUI 菜单、弹窗样式，优化滚动条和点击反馈。 (#11107, #11090, #11102)
  • 修复 EPUB 解析丢失链接文字的问题。 (#10794)
  • 保留 GIF 转换为拼图后的说明，避免历史上下文丢失动画信息。 (#10837)
  • 将插件加载及执行失败日志归属到对应插件，方便筛选排查。 (#10904)
  • SSE 流关闭时通知插件页面，避免连接状态滞留。 (#10932)
  • 控制台日志时间戳增加日期。 (#9617)

This is an Alpha release and may have stability or compatibility issues. Validate it in a test environment first. This release migrates conversation storage, Agent configurations, and session settings. Back up data and configuration before upgrading; downgrading also requires restoring the pre-upgrade backup.

Highlights

  • Migrate conversations to event sourcing, reducing duplicate context writes and some write amplification. Persist messages and tool calls incrementally and improve history handling after interrupted execution. (#10077, #11158, #11162)
  • Introduce a new Agent runtime model. Plugins can invoke an Agent turn through ctx.agent.run_turn(). (#10934, #10936, #11052, #11148, #11153)
  • Rebuild subagents as background tasks with independent context, generic or specialized configurations, follow-up inputs, and result delivery. Move management from the sidebar to Config → AI → Capabilities → Subagents, with per-profile settings. (#11053)
  • Merge Custom Rules and Session Management into Config → Manage session mappings, supporting base profiles, field overrides, batch editing, and restored inheritance. Model commands and the editor share the same settings. (#11097)
  • Add a Windows AppContainer sandbox with workspace isolation, code execution, and network controls. (#10466)
  • Add DeepSeek speech recognition and synthesis providers. (#11118)
  • Add OpenAI Decisions models for choices, boolean questions, and scores. (#10968)
  • Welcome → Overview now shows daily usage, system resources, and bot errors. (#11100)
  • Add an Appearance setting to show Chat in the sidebar. (#11090)
  • Upgrade Markdown rendering and load chat and syntax-highlighting assets on demand. (#11138)
  • Add collapsible plugin configuration groups with configurable initial state. (#11067)
  • Expose current theme colors and their updates to plugin pages. (#11046)
  • Reorganize AI development guides and add plugin configuration control examples and screenshots. (#11154)

Improvements and Fixes

  • Improve persistence and continuation of inputs added during execution. (#11141)
  • Skip subagent configurations with unavailable runtimes so they do not block the main conversation. (#11128)
  • Allow deselecting disabled, missing, or runtime-unavailable subagent configurations. (#11147)
  • Remove default tool-call instructions in full-schema mode. (#11152)
  • Fix successful final model retries being reported as failures. (#10922)
  • Preserve all text blocks in non-streaming Anthropic responses. (#11057)
  • Try other configured search keys when a key is invalid or its quota is exhausted. (#10877)
  • Update the default Gemini TTS model to gemini-3.8-flash-tts. (#10828)
  • Preserve images, files, and other media in QQ button replies. (#10903)
  • Stop logging full image payloads on QQ upload failures, reducing their impact on the dashboard. (#10740)
  • Improve OneBot streaming segmentation by avoiding repeated scans of long text. (#10989)
  • Use Telegram display names when usernames are absent. (#10715)
  • Fix Firefox chat history scroll jumps. (#11036)
  • Preserve model previews and capability indicators while editing provider configurations. (#10792)
  • Unify WebUI menus and dialogs and refine scrollbars and press feedback. (#11107, #11090, #11102)
  • Preserve link text when parsing EPUB files. (#10794)
  • Retain GIF montage guidance in conversation history so animation context is preserved. (#10837)
  • Attribute plugin loading and execution errors to their plugins for easier log filtering. (#10904)
  • Notify plugin pages when SSE streams close to avoid stale connection states. (#10932)
  • Include dates in console log timestamps. (#9617)
