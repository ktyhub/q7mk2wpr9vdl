#アストラボットv4.21.0

何が変わったのか

新しい

  • カテゴリ フィルターを追加し、プラグイン マーケット向けに最適化されたインターフェイス コンポーネントを追加しました。 (#6762)
  • キミ コーディング プラン プロバイダー (Anthropic API と互換性あり) を追加しました。 (#6559)
  • skill.md ファイルを統合し、名前を SKILL.md に変更しました。 (#6757)
  • Ollamaオフ思考モードスイッチを追加しました。 (#5941)
  • Xiaomi MiMo TTS および STT プロバイダーを追加しました。 (#6643)
  • マルチモーダル コンテキスト トークン カウント機能 (画像、音声、思考チェーン) を追加しました。 (#6596)
  • メタ情報名によってプラグインをインストールし、インポート可能な識別子を検証する機能を追加しました。 (#6530)

最適化

  • 古いバージョンの Python との互換性のために、StrEnum の kook_type を (str, Enum) に下げました。 (#6512)
  • WebChat メッセージ処理を最適化: メッセージを事前に保存し、ストリーミングの完了を強化します。 (#6698)
  • ダッシュボードのモバイル ペルソナ セレクターのレイアウトを最適化します。 (#5907)
  • ダッシュボードを最適化し、MDI アイコンのフォント範囲を減らし、Google Fonts を自己ホストします。 (#6532)
  • Pydantic を使用して KOOK アダプター データ モデルを再構築し、メッセージ構造の解析と検証のパフォーマンスを向上させます。 (#5719)
  • ドキュメントの用語や表現を調整（「メッセージ プラットフォーム」を「ロボット」に変更するなど）し、説明文を最適化および更新します。 (#6568)

修正

  • Web検索ツールで無効にしたシステム機能が正しく反映されない問題を修正しました。 (#6584)
  • 不要な計算を避けるために、空のナレッジ ベースの埋め込みバッチをスキップします。 (#6106)
  • Whisper API STT シナリオで Feishu opus ファイルが正しく変換されない問題を修正しました。 (#6078)
  • ツール呼び出しが中断された場合の Lark カードの作成と再開のプロセスを修正しました。 (#6743)
  • Windows環境でのスキルファイルエンコーディングの互換性の問題を修正しました。 (#6058)
  • WebChat によって個別にレンダリングされた HTML 返信が正しく表示されない問題を修正しました。 (#6074)
  • Gemini 配列スキーマで items フィールドが欠落している問題を修正しました。 (#6051)
  • ハードコーディングされたワークスペース パスを使用し、代わりにキャッシュ内の実際のサンドボックス パスを使用するスキルの問題を修正しました。 (#6331)
  • サブエージェント ツールの呼び出しタイムアウト配信を修正し、tool_call_timeout を修正し、デフォルトのタイムアウトを 60 秒から 120 秒に増やします。 (#6713)
  • skills-like配下にextra_user_content_partsがない場合、ピクチャの説明が挿入されない問題を修正しました。 (#6710)
  • /stop 以降の後続メッセージの処理が継続される問題を修正しました。 (#6704)
  • コアプロセスが停止時にサブエージェントツールの待機を中断する動作を修正しました。 (#5850)
  • Windows プラットフォームで stdio MCP サービス PATHEXT が見つからない問題を修正しました。 (#5822)
  • 失敗した場合にループを自動的に再開するための Telegram ポーリング再開メカニズムを修正しました。 (#6648)
  • /stop以降の追従ステータスがクリアされず、後続のトリガーが実行され続ける問題を修正しました。 (#6656)
  • OpenAI 構成ログを修正して、エージェントと API ベースの読みやすさとトラブルシューティング機能を向上させました。 (#6669)
  • 長いツール呼び出しで唯一のユーザー メッセージを誤って削除する切り捨てロジックの問題を修正しました。 (#6198)
  • truncator が固有のユーザー メッセージを削除し、一部のプロバイダーが 400 を返す問題を修正しました。 (#6581)
  • ID ホワイトリストが空の場合、プロンプトのコピー テキストが不明瞭になる問題を修正しました。 (#6611)
  • MoonshotAI 公式 API で OpenAI トークンの使用が欠落している問題を修正しました。 (#6618)
  • Wecom AI Bot ストリーミング (電流制限処理) の読みやすさと速度を向上させ、遅延と表示エクスペリエンスを改善します。 (#6610) ・Wecomの長い接続応答が消える問題を修正しました。 (#6606)
  • Windows パッケージング実行時の pip/native ビルド環境構成の問題を修正しました。 (#6575)
  • 無効なパラメーターの干渉を避けるために明示的に設定されている場合にのみ、埋め込み dimensions を渡すように修正しました。 (#6432)
  • register_agent デコレーターによって引き起こされる NameError を修正。 (#5765)
  • デフォルトのペルソナシナリオでサブエージェントクエリが失敗する問題を修正しました。 (#5672)
  • Windowsでスキルの読み込みに失敗する問題を修正しました。 (#6490)
  • SKILL.md の複数行のフロントマター解析の問題を修正しました。 (#6460)
  • SQLite database is locked の問題を修正し、ビジー タイムアウト処理を追加しました。 (#6474)
  • 上流の倉庫によって引き起こされるエラー シナリオのみを許可するワークフロー制限を修正しました。 (#6531)

変更点 (英語)

新機能

  • マーケット プラグインのカテゴリ フィルタリングを追加し、UI コンポーネントを強化しました。
  • 正規化され、skill.md ファイルの名前が SKILL.md に変更されました。
  • Ollama の思考モードを無効にするトグルを追加しました。
  • Xiaomi MiMo TTS および STT プロバイダーを追加しました。
  • Anthropic API との互換性を備えた Kimi コーディング プラン プロバイダーを追加しました。
  • マルチモーダル コンテンツ (画像、音声、思考連鎖) のコンテキスト トークン カウントのサポートを追加しました。
  • メタデータ名によるプラグインのインストールを追加し、インポート可能な識別子を検証しました。

改善点

  • 下位互換性のために、StrEnum を kook_type の (str, Enum) にリファクタリングしました。
  • プロアクティブな保存とストリーミングの完了により、WebChat メッセージ処理が強化されました。
  • モバイル画面用の簡素化されたダッシュボード ペルソナ セレクター レイアウト。
  • ダッシュボードの MDI アイコン フォントと自己ホスト型 Google フォントのサブセット。
  • 検索とスキーマ検証を向上させるために、KOOK アダプター用の Pydantic データ モデルを実装しました。
  • 不完全な更新用語についてドキュメントの文言を更新しました。

バグ修正

  • Web 検索ツールで無効になっていたシステム機能を修正しました。
  • 空のナレッジベース埋め込みバッチをスキップしました。
  • Whisper API STT用にFeishu作品ファイルを変換しました。
  • ツール呼び出しの中断時に Lark カードの作成と更新が延期されました。
  • Windows スキル ファイル エンコーディングのフォールバックを追加しました。
  • スタンドアロン HTML 応答を WebChat のコードとしてレンダリングしました。
  • Gemini 配列スキーマに常に items が含まれるようにしました。
  • ハードコードされたワークスペース ルートの代わりにキャッシュされたサンドボックス パスを使用するようにスキル パス解決を修正しました。
  • tool_call_timeout をサブエージェントのハンドオフ/cron/バックグラウンド タスクに渡し、デフォルトのタイムアウトを 120 秒に増加しました。
  • extra_user_content_parts が欠落している skills-like の再クエリにより画像キャプションが挿入されない問題を修正しました。
  • /stop リクエスト後のフォローアップ メッセージを拒否しました。
  • 中断されたサブエージェント ツールは停止を待機します。
  • Windows 上の標準出力 MCP サーバー用に PATHEXT を保持。
  • 障害時の Telegram ポーリング ループの自動再起動を追加しました。
  • /stop トリガー後のフォローアップ永続ロジックを修正しました。
  • OpenAI プロキシ/API ベースのログ記録を改善しました。
  • 切り捨てロジックにより、ツール呼び出しの長い会話で唯一のユーザー メッセージが削除されるのを防ぎました。
  • 一部のプロバイダーで唯一のユーザー メッセージを削除し、400 を返す切り捨てを修正しました。
  • ID ホワイトリストの空の構成に関するヒントの文言を更新しました。
  • MoonshotAI 公式 API でのトークンの使用法を修正しました。
  • スロットルによる Wecom AI Bot ストリーミングの読みやすさと速度が向上しました。
  • Wecom AI Bot の長い接続応答が消えるのを防ぎました。
  • pip ネイティブ ビルド用のパッケージ化された Windows ランタイム ビルド環境を設定します。
  • 明示的に構成されている場合のみ、埋め込みディメンションを渡します。
  • register_agent デコレーター NameError を修正しました。
  • デフォルトのペルソナを使用する場合のサブエージェント検索の失敗を修正しました。
  • Windows での読書スキルを修正しました。
  • SKILL.md での複数行のフロントマター解析を修正しました。
  • SQLite database is locked のビジータイムアウトを修正しました。
  • ワークフローを上流リポジトリに制限しました。

AstrBot v4.21.0

Highlights

  • Skill packaging migration — Legacy skill.md files are normalized to SKILL.md (#6757), so existing skills should migrate automatically; plugin authors should still audit case-sensitive references. Multiline frontmatter, Windows encoding, and cached-sandbox path fixes (#6460, #6058, #6331) make skill loading more reliable across environments.
  • Provider and plugin expansion — Kimi Coding Plan adds Anthropic-compatible access (#6559), Xiaomi MiMo adds TTS/STT (#6643), and Ollama can now disable thinking (#5941). Plugin-market category filtering and metadata-name installation with import-identifier validation (#6762, #6530) make discovery and installation less error-prone.
  • OpenAI-compatible configuration — The provider label becomes “OpenAI Compatible” (#6707). Embedding requests send dimensions only when explicitly configured (#6432), and OpenAI embedding base URLs no longer receive an automatic /v1 suffix (#6669); custom endpoints that relied on implicit suffixing must include it explicitly.
  • Cancellation and subagent lifecycle — /stop now rejects follow-ups, clears persisted follow-up state, and interrupts subagent tool waits (#6704, #6656, #5850). tool_call_timeout now reaches handoff, cron, and background tasks, with the default raised from 60s to 120s (#6713)—long-running jobs get more headroom, but automations must treat /stop as terminal for pending follow-ups.
  • Context and integration reliability — Token accounting now covers images, audio, and chain-of-thought (#6596); truncation preserves the sole user message to prevent provider 400 responses (#6198, #6581), and Gemini array schemas always include items (#6051). SQLite busy timeouts, Telegram polling recovery, Windows MCP/native-build fixes, and KOOK’s Pydantic and older-Python compatibility changes reduce platform-specific failures (#6474, #6648, #5822, #6575, #5719, #6512).
  • Compatibility — No declared breaking changes.
