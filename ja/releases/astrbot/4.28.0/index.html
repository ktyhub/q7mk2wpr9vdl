#AstrBot v4.28.0

4.28.0 - 2026-09-08

四季折々の景色が異なり、楽しみは尽きません。

それぞれの季節がそれぞれの美しさをもたらし、その楽しさは無限にあります。

📢 一部の設定ファイルの最適化により、アップグレード後にダウングレードすると、一部の設定内容がリセットされます。アップグレード後にダウングレードする場合は注意してください。 構成ファイルの構造の最適化により、アップグレード後にダウングレードすると、一部の構成コンテンツがリセットされます。アップグレード後にダウングレードする場合は注意してください。

主な追加点

  • モデル プロバイダー、ボット、プロファイルの WebUI ページを再設計し、ログ、トレース、会話管理、データを データとログ ページに統合しました。 Agent Runner をモデル プロバイダーから削除し、その設定を各プロファイルに埋め込みました。 (#9820、#9825、#9821、#9883、#9846)
  • デフォルトおよびローカル T2I レンダリングを再設計しました。 (#9803)
  • メッセージング プラットフォーム アダプター全体で強化された統合グループ メタデータ。 (#9851)
  • グループ名やユーザー名など、統一メッセージ送信元 (UMO) の読み取り可能な名前を自動的に記録し、WebUI で見つけやすくします。 (#9909)
  • WebUI およびプラグイン設定の機密値にマスクされたシークレット フィールドを追加しました。 (#9824) ・WebUIスキル管理ページに一括削除機能を追加しました。 (#9906)
  • AnySearch を組み込みの Web 検索プロバイダーとして追加しました。 (#9767)
  • デフォルトでパスワード形式のプラグイン設定フィールドとマスクされた機密プロファイル フィールドのサポートが追加されました。 (#9824)

主な最適化

  • ブラウザのパスワード マネージャーが WebUI ログイン ページを認識する方法が改善されました。 (#9830)
  • モデルプロバイダーのアイコンをダークモードに適合させました。 (#9647)
  • 将来のタスクエージェントのコンテキスト処理が改善されました。 (#9818)
  • 小さな画面でもスキルエディタダイアログの応答性を向上させました。 (#9873)
  • ツールを名前のアルファベット順に並べ替えることで、OpenAI ツール スキーマの順序を安定させました。 (#9798)

主要な修正

  • QR コードをスキャンした後、DingTalk が不明な CREATING 状態のままになり、アプリの作成が続行できなくなる問題を修正しました。 (#9808)
  • コマンドの前にボットのメンションが表示されると、Lark グループのコマンドがトリガーされない問題を修正しました。 (#9872)
  • ユニファイド メッセージ オリジン (UMO) による分離されたレート制限。 (#9814)
  • OpenAI API による Anthropic API ベース URL の処理を調整しました。 /v1 を構成された URL に含める必要があります。 (#9802)
  • Anthropic と Gemini のキャッシュされたトークンの使用状況を修正しました。 (#9880、#9881)
  • max_agent_step 構成をスケジュールされたタスクおよびバックグラウンド タスクのエージェントに適用しました。 (#9801)
  • Lark のテキストと画像が混在したメッセージのテキストが保持されます。 (#9841)
  • モバイルペルソナマネージャーにフォルダー作成ボタンを表示しました。 (#9812)

中国語

主な新規追加

  • WebUIのモデルプロバイダーページ、ロボットページ、設定ファイルページを再設計し、ログ、トラッキング、会話管理、データページを「データとログ」ページに統合します。モデルプロバイダーの「エージェントエグゼキューター」を削除し、各構成ファイルに埋め込みました。 (#9820、#9825、#9821、#9883、#9846)
  • デフォルトおよびネイティブの T2I レンダリング効果を再設計しました。 (#9803)
  • 各メッセージング プラットフォーム アダプターの統合グループ メタデータを強化 (#9851)
  • WebUI でのクエリを容易にするために、ユニファイド メッセージング ソース (UMO) の読み取り可能な名前 (グループ名、ユーザー名など) を自動的に記録します。 (#9909)
  • WebUI およびプラグイン設定の機密値用のマスク キー フィールドを追加しました。 (#9824) ・WebUIスキル管理ページに一括削除機能を追加しました。 (#9906)
  • AnySearch 組み込み Web 検索サービス プロバイダーを追加しました。 (#9767)
  • パスワード効果のあるフィールドを使用するためのプラグイン設定項目をサポートし、デフォルトで設定ファイル内の機密フィールドにパスワード効果を使用します。 (#9824)

主な最適化

  • WebUIログインページにおけるブラウザの自動パスワード記憶機能の認識ロジックを改善しました。 (#9830)
  • モデルプロバイダーアイコンをダークモードに適応させます。 (#9647)
  • 今後のタスク エージェントのコンテキストを最適化します。 (#9818)
  • スキルエディタダイアログを小さな画面に適応させます。 (#9873)
  • OpenAIツールスキーマの順序をツール名の辞書順に安定させました。 (#9798)

主要な修正

・DingTalkにおいて、QRコードを読み取った後に不明なCREATINGステータスが表示され、作成を続行できない場合があります。 (#9808) ・フェイシュグループにおいて、atロボットが前にいてコマンドが後ろにある場合にコマンドが発動できない問題を修正しました。 (#9872)

  • ユニファイド メッセージング オリジン (UMO) による現在のスロットリングを分離します。 (#9814)
  • Anthropic API ベース URL ロジックを OpenAI API と一致させ、/v1 の入力を必要とします。 (#9802)
  • キャッシュ トークンに関する Anthropic と Gemini の使用統計を修正しました。 (#9880、#9881)
  • max_agent_step 設定をスケジュールされたタスクとバックグラウンド タスクのエージェントに適用します。 (#9801)
  • フェイシュのテキストと画像メッセージが混在したメッセージを保存します。 (#9841)
  • モバイルのパーソナリティ マネージャーに新しいフォルダー ボタンを表示します。 (#9812)

4.28.0-beta.1 以降の変更点

追加と最適化

  • WebUI と組み込みプラグインの日本語ローカライズを追加しました。 (#9955)
  • ChatUI の共通言語の構文ハイライトを拡張し、T2I レンダラーに Go ハイライトを追加しました。 (#9892)
  • メトリクスのアップロードに Python バージョンが含まれました。 (#9973)
  • Windows、macOS、および Linux で単体テスト CI を有効にし、クロスプラットフォーム テストの互換性を修正しました。 (#9954)

修正

  • WebUI に欠落していた英語翻訳を追加しました。 (#9896)
  • 中国語プロバイダーの同期翻訳の名前空間を修正しました。 (#9932)
  • Windows ホスト上のリモート サンドボックス スキル アーカイブ パスを修正しました。 (#8182)
  • 同じメタデータ名を持つプラグインについて間違った情報が表示されるプラグイン マーケットの詳細ページを修正しました。 (#9925)
  • ジェミニの思考レベルのシリアル化を修正しました。 (#9899)
  • 辞書型設定項目のユーザー定義コンテンツを保持します。 (#9958)
  • ツール パラメータの再クエリ中に、最初のシステム メッセージを変更する代わりに、既存のコンテキスト プレフィックスを保持しました。 (#9957)
  • 無効な「すべて」ページ サイズ オプションをナレッジ ベースのドキュメント リストから削除しました。 (#9908)
  • send_by_session 経由で送信されるプロアクティブな QQ 公式メッセージにマークダウン レンダリングを適用しました。 (#9914)
  • プロアクティブ エージェントがコンピュータのランタイム設定を尊重し、不足しているランタイム設定を無効として扱うようにしました。 (#9971)
  • デフォルトで履歴リストに WebChat 会話が含まれ、ボット ID フィルターで WebChat が公開されました。 (#9910)
  • イベント ループ ウォッチドッグ スタック ダンプを他のトレースバック出力から分離しました。 (#9941)

4.28.0-beta.1 以降の変更点

新規追加と最適化

  • WebUI と組み込みプラグインの日本語ローカライズを追加しました。 (#9955)
  • ChatUI で一般的に使用される言語のコードの強調表示を拡張し、T2I レンダラーに Go 構文の強調表示を追加します。 (#9892)
  • 統計レポートに Python バージョンを含めます。 (#9973)
  • Windows、macOS、Linux で単体テスト CI を有効にし、テストのクロスプラットフォーム互換性を修正します。 (#9954)

修正

  • WebUI の不足している英語翻訳を完了します。 (#9896)
  • 中国語モデルプロバイダーの同期翻訳のための名前空間を修正しました。 (#9932)
  • Windows ホストからリモート サンドボックスにスキルを同期するときの圧縮パッケージ パスを修正しました。 (#8182)
  • 同じメタデータ名のプラグイン詳細ページにエラー メッセージが表示されるプラグイン マーケットの問題を修正しました。 (#9925)
  • ジェミニの思考レベルのシリアル化を修正。 (#9899)
  • ユーザー定義の内容を辞書型設定項目に保持します。 (#9958)
  • ツール パラメータ完了リクエストは、既存のコンテキスト プレフィックスを保持し、最初のシステム メッセージを変更しません。 (#9957)
  • 無効な「すべて」ページング オプションをナレッジ ベースのドキュメント リストから削除しました。 (#9908)
  • send_by_session 経由で一方的に送信される QQ 公式ボット メッセージにマークダウン レンダリングを適用します。 (#9914)
  • アクティブなエージェントがマシンのランタイム構成を尊重し、マシンのランタイムが欠落している場合はデフォルトで無効にします。 (#9971)
  • デフォルトで会話履歴リストに WebChat 会話を表示し、ボット ID による WebChat のフィルタリングをサポートします。 (#9910)
  • イベント ループ ウォッチドッグのスタック ダンプを他のトレースバック出力から分離します。 (#9941)

AstrBot v4.28.0

Highlights

  • WebUI restructuring — Model provider, bot, and profile management were redesigned, while logs, traces, conversations, and data now live under Data & Logs. Agent Runner settings moved from model providers into individual profiles, so existing deployments need their runner configuration reviewed after upgrading (#9820, #9821, #9883, #9846).
  • Anthropic endpoint migration — API Base URL handling now matches OpenAI’s convention: configured Anthropic URLs must include /v1 (#9802). Update endpoint configuration before upgrading to avoid failed requests.
  • More predictable agent limits and quotas — max_agent_step now applies to scheduled and background agents, not just interactive sessions (#9801), while rate limits are isolated per unified message origin, preventing busy groups or users from exhausting a shared limit (#9814).
  • Search, secrets, and plugin controls — AnySearch is available as a built-in web search provider (#9767); sensitive WebUI and plugin values use masked/password-style fields (#9824); and skills support batch deletion (#9906), improving both integration options and day-to-day administration.
  • More reliable platform and model integrations — Fixes address leading-mention commands and mixed text/image preservation in Lark (#9872, #9841), DingTalk onboarding stuck in CREATING (#9808), Gemini thinking-level serialization (#9899), and Anthropic/Gemini cached-token accounting (#9880, #9881). Tool schemas are now sorted by name for stable OpenAI requests (#9798).
  • Context and runtime correctness — Tool parameter re-querying preserves the existing context prefix instead of rewriting the initial system message (#9957), and proactive agents now honor computer-runtime settings, defaulting to disabled when settings are absent (#9971). Cross-platform unit-test CI also now covers Windows, macOS, and Linux (#9954).
  • No backward compatibility: structural configuration changes mean downgrading can reset some settings.
