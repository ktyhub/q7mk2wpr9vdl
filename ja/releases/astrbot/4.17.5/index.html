#アストラボットv4.17.5

何が変わったのか

新しい

  • QQ 公式ロボット プラットフォームをサポートしてマークダウン メッセージを送信し、リッチ テキスト メッセージのプレゼンテーション機能を向上させます (#5173)。
  • プラグイン マーケットにランダムなプラグインの推奨を統合する機能を追加しました (#5190)。
  • プラグインによる統合例外制御を容易にするカスタム エラー ルーティング処理をサポートするプラグイン エラー フックを追加しました (#5192)。

修正

  • すべての LLM プロバイダーが冗長なエラー報告干渉を削減できない場合にエラー メッセージが繰り返し表示される問題を修正しました (#5183)。 ・「構成ファイルの選択」から構成管理に入った直後にポップアップウィンドウを閉じた場合、間違った構成ファイルが表示される問題を修正しました(#5174)。

最適化

  • テレグラム Voice_messages_forbidden フォールバック ロジックを再構築し、それを共有補助メソッドに抽出し、型付き BadRequest 例外を導入して例外処理の一貫性を向上させます (#5204)。

その他

  • README 関連ドキュメントの内容を更新しました。
  • ruff format コードのフォーマットを実行します。

変更点 (英語)

新機能

  • カスタム エラー ルーティング用のプラグイン エラー フックを追加し、プラグインでの統合例外処理を有効にしました (#5192)。
  • リッチテキスト配信を改善するために、qqofficial のマークダウン メッセージ送信サポートを追加しました (#5173)。
  • MarketPluginCard コンポーネントを追加し、拡張機能マーケットプレイスにランダムなプラグインの推奨事項を統合しました (#5190)。
  • aihubmix プロバイダーのサポートを追加しました。
  • 多言語の README ファイルに LINE サポートに関する注意事項を追加しました。

修正

  • すべての LLM プロバイダーが失敗した場合の重複エラー メッセージを修正し、ノイズの多いエラー出力 (#5183) を削減しました。
  • プロファイル選択から構成管理を開き、ダイアログを直接閉じた後に表示されるプロファイルが正しくない問題を修正しました (#5174)。

改善点

  • Voice_messages_forbidden フォールバック ロジックを共有ヘルパーにリファクタリングし、より一貫性のあるエラー処理のために型付き BadRequest 例外を導入しました (#5204)。

その他

  • README ドキュメントを更新しました。
  • ruff format コード形式を適用しました。

何が変わったのか

  • 特技: https://github.com/AstrBotDevs/AstrBot/pull/5173 の @Soulter による qqofficial でのマークダウン メッセージの送信をサポート
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5183 の @KBVsent によってすべての LLM プロバイダーが失敗した場合の重複エラー メッセージを防止
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5174 の @SnowNightt により、構成ファイルを選択して構成ファイル管理ポップアップ ウィンドウに入り、ポップアップ ウィンドウを直接閉じるときに表示される誤った構成ファイルを修正しました。
  • 功績: MarketPluginCard コンポーネントを追加し、https://github.com/AstrBotDevs/AstrBot/pull/5190 の @Soulter により ExtensionPage にランダム プラグイン機能を統合
  • feat(core): https://github.com/AstrBotDevs/AstrBot/pull/5192 の @Clhikari によるカスタム エラー ルーティング用のプラグイン エラー フックを追加
  • 修正: https://github.com/AstrBotDevs/AstrBot/pull/5204 の @911218sky による、入力された例外とテキスト キャプションを使用して Telegram Voice_messages_forbidden を処理する

AstrBot v4.17.5

Highlights

  • Plugin-wide error routing — The new error hook lets plugins centralize exception handling instead of duplicating recovery logic, giving developers a defined place to route failures and enforce consistent error policy (#5192).
  • Richer QQ Official messages — qqofficial can now send Markdown, enabling formatted, link-rich responses. Update your message-building logic where plain text was previously required, and account for the platform’s Markdown restrictions (#5173).
  • Additional LLM provider and plugin discovery — aihubmix is now supported, expanding provider configuration options; the extension marketplace also gained a MarketPluginCard component and random recommendations for discovering plugins (#5190).
  • More reliable Telegram voice fallback — Voice_messages_forbidden is handled through a shared helper, typed BadRequest exception, and text caption. Telegram integrations should get more consistent behavior when voice delivery is prohibited, with less platform-specific exception handling (#5204).
  • Less noisy failure output and accurate profile state — Exhausted LLM provider chains now report one error instead of repeating it, improving diagnosability (#5183); closing the configuration dialog from profile selection no longer leaves an incorrect profile displayed (#5174).

No breaking changes.

What's Changed

新增

  • 支持 QQ 官方机器人平台发送 Markdown 消息，提升富文本消息呈现能力 (#5173)。
  • 新增在插件市场中集成随机插件推荐能力 (#5190)。
  • 新增插件错误钩子（plugin error hook），支持自定义错误路由处理，便于插件统一异常控制 (#5192)。

修复

  • 修复全部 LLM Provider 失败时重复显示错误信息的问题，减少冗余报错干扰 (#5183)。
  • 修复从“选择配置文件”进入配置管理后直接关闭弹窗时，显示配置文件不正确的问题 (#5174)。

优化

  • 重构 telegram Voice_messages_forbidden 回退逻辑，提取为共享辅助方法并引入类型化 BadRequest 异常，提升异常处理一致性 (#5204)。

其他

  • 更新 README 相关文档内容。
  • 执行 ruff format 代码格式整理。

What's Changed (EN)

New Features

  • Added a plugin error hook for custom error routing, enabling unified exception handling in plugins (#5192).
  • Added Markdown message sending support for qqofficial to improve rich-text delivery (#5173).
  • Added the MarketPluginCard component and integrated random plugin recommendations in the extension marketplace (#5190).
  • Added support for the aihubmix provider.
  • Added LINE support notes to multilingual README files.

Fixes

  • Fixed duplicate error messages when all LLM providers fail, reducing noisy error output (#5183).
  • Fixed incorrect displayed profile after opening configuration management from profile selection and closing the dialog directly (#5174).

Improvements

  • Refactored Voice_messages_forbidden fallback logic into a shared helper and introduced a typed BadRequest exception for more consistent error handling (#5204).

Others

  • Updated README documentation.
  • Applied ruff format code formatting.
