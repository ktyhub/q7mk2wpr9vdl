AstrBot v4.14.0

#アストラボットv4.14.0

変更点 - 大きくて美しいバージョン

以前のバージョンでスキルを使用していた場合は、この更新後にスキル ランタイム関連のオプションを再設定する必要があります。

新しい

  • 🔥 今後のタスクシステムを追加しました。今後のタスクを AstrBot に割り当てて、AstrBot が特定の瞬間に自動的に起動してタスクを完了できるようにします。詳細については、「アクティブなタスク」(https://docs.astrbot.app/use/proactive-agent.html) を参照してください。 (実験的) (#4697)
  • 🔥 サブエージェント オーケストレーターを追加しました。 (実験的)(#4697)
  • 🔥 AstrBot は現在、ツールを呼び出して画像/ファイルをユーザーに直接プッシュできるため、インタラクション効果が大幅に向上します。
  • スキル構成とサンドボックス構成をマージするためのコンピューター使用ランタイム構成を追加しました (#4831)
  • テーマのカスタマイズ機能を追加し、メインカラーと補助カラーを設定できます
  • 設定ページのパーソナリティ ダイアログ ボックスでパーソナリティの編集をサポート (#4826)
  • スイッチの「トレース」機能をサポートします。システム構成でログをログファイルに書き込むかどうかの設定をサポート (#4822)

修正

  • ‼ ️ 最近のバージョンで導入された missing 2 required positional arguments: 'filter1' and 'filter2' 関連のエラー報告の問題を修正します。
  • ‼️ChatUIの写真、思考等の表示異常を修正しました。
  • ️サンドボックスにスキルをアップロードした後、自動的に解凍されず、エージェントが読み取れなくなる問題を修正しました。
  • ‼ ️ 特定のプラグイン セットを構成するときに MCP ツールがフィルターされる問題を修正 (#4825)
  • ‼ ️ ChatUI に付属するプロンプトを削除して、LLM が最終的に質問できるようにします (#4824)
  • ‼ ️ スキルのアップロードに失敗した後も WebUI に成功メッセージが表示されるバグを修正 (#4768)
  • MCPサーバーの名前を変更できない問題を修正しました (#4766)
  • WebUI管理動作において、プラグインツールがソースを参照できない問題を修正(#4776)
  • ‼️スキル風ツールモードでツール呼び出しに失敗する問題を修正(#4775)

最適化

  • WebUI全体のUI効果の最適化
  • 一部のダイアログのタイトルスタイルが統一されました

変更点 (英語)

新機能

  • ワンタイムタスクと強化されたダッシュボード管理を備えた CronJob システムを導入
  • 原色と二次色のオプションによるテーマのカスタマイズを追加
  • スキルサンドボックス実行用のコンピューター使用ランタイム構成を追加 (#4831)
  • ペルソナセレクターダイアログに編集ボタンを追加 (#4826)
  • トレースログの切り替えと設定 UI を追加 (#4822)
  • cron ツール トリガーによるプロアクティブ メッセージング機能の追加
  • 構成可能なツール管理ポリシーを備えた SubAgent オーケストレーターを実装する
  • サンドボックス ファイル パスの解決をサポートし、必要に応じて自動ダウンロードをサポートします
  • MessagePartsRenderer に埋め込み画像と音声スタイルを追加
  • i18n 財団の導入
  • エージェントとの対話履歴を保持する
  • ファイルのダウンロードの成功/削除に関するユーザー通知を追加します

バグ修正

  • ゴーストプラグインの検出精度を向上
  • ゴーストプラグインのクラッシュを防ぐためにエラー処理を追加
  • スキルバンドルが既存のファイルを上書きしないようにする
  • サンドボックス内でのスキルバンドルの解凍エラーを修正
  • 特定のプラグイン セットが設定されている場合にフィルターされる MCP ツールを修正 (#4825)
  • ChatUI ペルソナのポップアップをデフォルトのペルソナにマージ (#4824)
  • 推論ブロックのスタイルを修正
  • truncate_and_compress ヒントに欠落しているカンマを追加
  • 成功メッセージが表示されたままのフロントエンドを修正 (#4768)
  • MCP サーバーの名前を変更できない問題を修正 (#4766)
  • スキルアップロードで残ったサンドボックスランタイム処理を削除 (#4798)
  • ハンドラーモジュールのパス構造を修正 (#4776)
  • スキル系ツールの呼び出しエラーを修正 (#4775)

改善点

  • 実行時のヒントとスキル管理の洗練された UI
  • cron-job ページのパフォーマンスと UX の改善
  • 一般的な WebUI パフォーマンスの向上
  • ドロップダウンのプラグインごとにツールをグループ化します
  • パディングとテキスト スタイルを備えた一貫したダイアログ タイトル
  • コードフォーマットの統一（ruffフォーマット）
  • 4.13.2 へのバージョンのバンプ

その他

  • 古いリマインダーコードを削除します
  • より良いアーキテクチャのためにメインエージェントモジュールを抽出
  • AstrBot_skill ブランチの変更をマージします

AstrBot v4.14.0

What's Changed - BIG AND BEAUTIFUL VERSION

如果在之前版本使用了 Skill，这次更新之后需要重新配置 Skill Runtime 相关选项。

新增

  • 🔥 新增未来任务系统（Future Tasks）。给 AstrBot 布置的未来任务，让 AstrBot 能够在某一时刻自动唤醒，帮你完成任务。详见 主动任务 。（实验性） (#4697)
  • 🔥 新增子代理（SubAgent）编排器。（实验性）(#4697)
  • 🔥 AstrBot 目前可以直接通过调用 tool 将图片 / 文件推送给用户，大大提高交互效果。
  • 新增 Computer Use 运行时配置，以融合 Skill 和 Sandbox 配置 (#4831)
  • 新增主题自定义功能，可设置主色与辅色
  • 支持在配置页下人格对话框的编辑人格 (#4826)
  • 支持开关 “追踪” 功能；支持在系统配置中设置是否将日志写入 log 文件 (#4822)

修复

  • ‼️ 修复近期版本引入的 missing 2 required positional arguments: 'filter1' and 'filter2' 相关报错问题 。
  • ‼️ 修复 ChatUI 图片、思考等显示异常问题。
  • ‼️ 修复 Skill 上传到 Sandbox 后未自动解压导致 Agent 无法读取的问题。
  • ‼️ 修复配置特定插件集时 MCP 工具被过滤的问题 (#4825)
  • ‼️ 移除 ChatUI 自带的让 LLM 最后提出问题的 prompt (#4824)
  • ‼️ 修复 WebUI 在上传 Skill 失败后仍显示成功消息的 bug (#4768)
  • 修复 MCP 服务器无法重命名的问题 (#4766)
  • 修复插件的 tool 无法在 WebUI 管理行为中看到来源的问题 (#4776)
  • ‼️ 修复 skill-like 的 tool 模式下，调用 tool 失败的问题 (#4775)

优化

  • WebUI 整体 UI 效果优化
  • 部分 Dialog 标题样式统一

What's Changed (EN)

New Features

  • Introduce CronJob system with one-time tasks and enhanced dashboard management
  • Add theme customization with primary & secondary color options
  • Add computer-use runtime config for skills sandbox execution (#4831)

  • Introduce i18n foundation
  • Persist agent-interaction history
  • Add user notifications for file-download success/removal

Bug Fixes

  • Improve ghost-plugin detection accuracy
  • Add error handling to prevent ghost-plugin crashes
  • Prevent skills bundle from overwriting existing files
  • Fix skills bundle unzip failure inside sandbox
  • Fix MCP tools being filtered when specific plugin set configured (#4825)
  • Merge ChatUI persona pop-up into default persona (#4824)
  • Fix reasoning block style
  • Add missing comma in truncate_and_compress hint
  • Fix frontend still showing success message (#4768)
  • Fix unable to rename MCP server (#4766)
  • Remove leftover sandbox runtime handling in skill upload (#4798)
  • Fix handler module path construction (#4776)
  • Fix skill-like tool invocation error (#4775)

Improvements

  • Runtime hints & refined UI in skills management
  • Performance and UX improvements on cron-job page
  • General WebUI performance boost
  • Group tools by plugin in dropdown
  • Consistent dialog titles with padding and text styles
  • Code formatting unified (ruff format)
  • Bump version to 4.13.2

Others

  • Remove obsolete reminder code
  • Extract main-agent module for better architecture
  • Merge AstrBot_skill branch changes
