#アストラボットv4.23.5

  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

何が変わったのか

新しい

  • WebUI ChatUIでは、メッセージの再編集、再生成によるAI応答生成、分岐照会パネル(AI応答内容を選択すると表示されます)、セッションチェックポイントのサポートを追加しました。 (#7673)
  • WebUI ChatUI は思考時のツール呼び出しモードに適応し、ループ処理を独立したサイドバー パネルに自動的にマージしてタイムラインに表示するため、ユーザー エクスペリエンスが大幅に向上します。 (#7742)
  • WebUI ChatUI の添付ファイル処理にプレビューと重複排除検証が追加され、アップロード前の添付ファイルの識別と表示エクスペリエンスが向上し、ユーザー メッセージの吹き出しで画像が適切に表示されない問題が修正されました。 (コミット)
  • ナレッジ ベース ドキュメントのアップロードに EPUB サポートを追加し、EPUB 解析、ファイル読み取り、および関連テストを追加しました。 (#7594)
  • 非ストリーミング エージェント ループは、メッセージ プロセスの折りたたみと送信機能を呼び出すための新しい中間ツールを追加します。 (#7627)
  • コマンドを使用したプロバイダー関連情報の管理と表示をサポートするために、/provider コマンドを再構築しました。 (#7691)
  • プラグイン ページに「新しいバージョンが利用可能になったときに一番上に表示する」機能が追加され、この設定の保存がサポートされました。 (#7665)

最適化

  • FileReadTool の説明を最適化し、画像、PDF、DOCX のサポートを明確にし、ツール結果のモーダル機能チェックを強化します。 (#7506)
  • 複数のドキュメント リンクを統合し、CLI、設定、ダッシュボード、およびナレッジ ベース ページのドキュメント エントリを修正します。 (#7709)

修正

  • TLS 証明書チェーン、プロキシ、またはモデル リスト機能の違いにより、一部の国内またはカスタムの OpenAI/Anthropic 互換モデル プロバイダーの構成が利用できない問題を修正しました。 (#7685) ・モデル返信に推理内容が含まれている場合、通常の返信が漏れてしまう場合がある問題を修正しました。 (#7715)
  • DNS または接続一時例外でのリトライ不足により、QQ 公式 API のリクエストが失敗する問題を修正しました。 (#7718)
  • RegexFilter が str と re.Pattern を同時に受け付けられない問題を修正しました。 (#7633)
  • バックアップインポーターがパスを交差するリスクがある問題を修正しました。 (#7681)
  • 古いバージョンの documents_fts テーブルが残っている場合に、ナレッジ ベースの FTS 移行に影響を与える可能性がある問題を修正しました。 (#7706)
  • 構成されたモデルがハードコードされたリストにない場合に MiniMax トークン プラン プロバイダーが直接ブロックする問題を修正し、警告プロンプトに変更しました。 (#7692)
  • MCP スキーマの無効な required フィールドが正規化されず、ツール スキーマ例外が発生する問題を修正しました。 (#6077)
  • ビデオ添付ファイルが LLM に送信されるときの処理の問題を修正し、関連するテストを追加しました。 (#7679) <a id="english"></a>

変更点 (英語)

新機能

  • インライン メッセージ編集、選択したメッセージからの再生成、スレッド パネル、会話チェックポイントのサポートを WebUI チャット ページに追加しました。 (#7673)
  • アップロード前の添付ファイルの認識と表示を改善するために、WebUI にチャット添付ファイルのプレビューとファイル署名チェックを追加しました。 (コミット)
  • 非ストリーミング エージェント ループにバッファリングされた中間メッセージを追加し、ツール呼び出しなどのプロセス メッセージを非ストリーミング シナリオで表示できるようにしました。 (#7627)
  • プロバイダー関連の情報を表示および管理するための組み込みコマンドとして /provider が再導入されました。 (#7691)
  • 永続的な設定ストレージを使用して、インストールされているプラグインと利用可能なアップデートをプラグイン ページの上部に固定するオプションを追加しました。 (#7665)
  • EPUB 解析、ファイル読み取りサポート、テストなど、ナレッジベース ドキュメントのアップロードのための EPUB サポートを追加しました。 (#7594)

改善点

  • FileReadTool の説明を更新して、画像、PDF、および DOCX のサポートについて言及し、ツール結果のモダリティ チェックを改善しました。 (#7506)
  • CLI の出力、構成、ダッシュボード、およびナレッジベースのページにわたる統合ドキュメント リンク。 (#7709)

バグ修正

  • モデル出力に推論コンテンツが含まれている場合に通常の応答が欠落する問題を修正しました。 (#7715)
  • QQ 公式 API フローに一時的な DNS エラーと接続エラーに対する再試行を追加しました。 (#7718)
  • str と re.Pattern の両方を受け入れるように RegexFilter を修正しました。 (#7633)
  • バックアップ インポーターのパス トラバーサルの脆弱性を修正しました。 (#7681)
  • ナレッジベースの FTS 移行の問題を回避するために、レガシー documents_fts テーブルが存在する場合は削除しました。 (#7706)
  • TLS 証明書チェーン、プロキシ処理、またはモデル リスト機能の違いが原因で発生する、一部の国内またはカスタムの OpenAI/Anthropic 互換モデル プロバイダーの構成エラーを修正しました。 (#7685)
  • 構成されたモデルがハードコードされたモデル リストにない場合、ブロックするのではなく警告するように MiniMax トークン プラン プロバイダーの動作を変更しました。 (#7692)
  • ツール スキーマ エラーを回避するために、MCP スキーマ内の無効な required フラグを正規化しました。 (#6077)
  • LLM リクエストのビデオ添付ファイルの処理を修正し、関連テストを追加しました。 (#7679)

AstrBot v4.23.5

Highlights

  • Security fix in the backup importer — PR #7681 closes a path traversal vulnerability (CWE-22), meaning a crafted backup file could previously write outside the intended directory. Anyone who imports backups from untrusted or shared sources should upgrade promptly; if you only ever import your own locally created backups, risk is lower but the fix is still worth taking.

  • ChatUI rework: editing, regeneration, checkpoints, and tool-call timelines — PR #7673 adds inline message editing, regenerating from a selected message, a thread/branch panel (select AI reply text to open it), and conversation checkpoints; PR #7742 restructures reasoning-phase tool calls into a timeline sidebar, and #7627 adds buffered intermediate messages for the non-streaming Agent Loop. This is the headline reason to upgrade if you actively use the WebUI chat page — the interaction model is substantially better, though no breaking changes or migration steps are called out.

  • Provider and compatibility fixes — #7685 fixes configuration failures for domestic/custom OpenAI- and Anthropic-compatible providers caused by TLS certificate chains, proxies, or model-list capability differences; #7692 changes the MiniMax Token Plan Provider to warn instead of hard-blocking when a configured model isn't in its hardcoded list; #7691 reintroduces /provider as a built-in command. If you run a non-standard or China-hosted provider, this is the upgrade that unblocks you.

  • Correctness and reliability fixes worth knowing about — #7715 fixes missing normal replies when output contains reasoning content (affecting models that emit reasoning), #7718 adds DNS/connection retries for the QQ Official API, #6077 normalizes invalid required flags in MCP schemas, #7706 drops stale documents_fts tables to unblock knowledge-base FTS migration, and #7633 makes RegexFilter accept both str and re.Pattern. There are no stated breaking changes or manual migration steps, but the documents_fts table drop and RegexFilter signature relaxation are behavioral changes plugin authors should be aware of.

  • Worth upgrading? Yes for most users: it's a feature-rich patch release (v4.23.2 → v4.23.5) with a real security fix, provider configuration fixes, and meaningful ChatUI improvements — and no migration steps are required. You can skip it only if you don't use the WebUI chat page, don't import backups, run only mainstream well-behaved providers, and aren't affected by the reasoning-content or knowledge-base fixes.

What's Changed

新增

  • WebUI ChatUI 新增消息重新编辑、从重新生成 AI 回复、分支询问面板（划选 AI 回复内容即可看到）与会话 checkpoint 支持。（#7673）
  • WebUI ChatUI 适配思考时的工具调用的模式，并自动将该 Loop 过程合并到独立的侧边栏面板中，以时间线呈现，大幅提升用户体验。(#7742)
  • WebUI ChatUI 附件处理新增预览与 Dedup 校验，改善上传前的附件识别与展示体验，修复用户消息气泡无法正常显示图片的问题。（commit）
  • 知识库文档上传新增 EPUB 支持，并补充 EPUB 解析、文件读取与相关测试。（#7594）
  • 非流式 Agent Loop 新增中间工具调用消息过程折叠发送功能。（#7627）
  • 重新内置 /provider 命令，支持通过命令管理与查看 Provider 相关信息。（#7691）
  • 插件页新增“有新版本时置顶显示”能力，并支持保存该偏好设置。（#7665）

优化

  • 优化 FileReadTool 描述，明确图片、PDF 与 DOCX 支持，并增强工具结果的模态能力检查。（#7506）
  • 统一多处文档链接，修正 CLI、配置、Dashboard 与知识库页面中的文档入口。（#7709）

修复

  • 修复部分国内或自定义 OpenAI/Anthropic 兼容模型提供商因 TLS 证书链、代理或模型列表能力差异导致配置不可用的问题。（#7685）
  • 修复模型回复包含 reasoning content 时可能漏发普通回复的问题。（#7715）
  • 修复 QQ 官方 API 在 DNS 或连接瞬时异常下缺少重试导致请求失败的问题。（#7718）
  • 修复 RegexFilter 不能同时接受 str 与 re.Pattern 的问题。（#7633）
  • 修复备份导入器存在路径穿越风险的问题。（#7681）
  • 修复旧版 documents_fts 表残留时可能影响知识库 FTS 迁移的问题。（#7706）
  • 修复 MiniMax Token Plan Provider 在已配置模型不在硬编码列表中时直接阻塞的问题，改为警告提示。（#7692）
  • 修复 MCP schema 中无效 required 字段未被规范化导致工具 schema 异常的问题。（#6077）
  • 修复视频附件传给 LLM 时的处理问题，并补充相关测试。（#7679）

What's Changed (EN)

New Features

  • Added inline message editing, regeneration from a selected message, a thread panel, and conversation checkpoint support to the WebUI chat page. (#7673)
  • Added chat attachment previews and file signature checks in WebUI to improve attachment recognition and display before upload. (commit)
  • Added buffered intermediate messages for the non-streaming Agent Loop, allowing process messages such as tool calls to be surfaced in non-streaming scenarios. (#7627)
  • Reintroduced /provider as a built-in command for viewing and managing Provider-related information. (#7691)
  • Added an option to pin installed plugins with available updates to the top of the plugin page, with persisted preference storage. (#7665)
  • Added EPUB support for knowledge-base document upload, including EPUB parsing, file reading support, and tests. (#7594)

Improvements

  • Updated the FileReadTool description to mention image, PDF, and DOCX support, and improved modality checks for tool results. (#7506)
  • Unified documentation links across CLI output, configuration, Dashboard, and knowledge-base pages. (#7709)

Bug Fixes

  • Fixed missing normal replies when model output contains reasoning content. (#7715)
  • Added retries for transient DNS and connection errors in the QQ Official API flow. (#7718)
  • Fixed RegexFilter so it accepts both str and re.Pattern. (#7633)
  • Fixed a path traversal vulnerability in the backup importer. (#7681)
  • Dropped legacy documents_fts tables when present to avoid knowledge-base FTS migration issues. (#7706)
  • Fixed configuration failures for some domestic or custom OpenAI/Anthropic-compatible model providers caused by TLS certificate chains, proxy handling, or model-list capability differences. (#7685)
  • Changed MiniMax Token Plan Provider behavior to warn instead of blocking when a configured model is not in the hardcoded model list. (#7692)
  • Normalized invalid required flags in MCP schemas to avoid tool schema errors. (#6077)
  • Fixed video attachment handling for LLM requests and added related tests. (#7679)
