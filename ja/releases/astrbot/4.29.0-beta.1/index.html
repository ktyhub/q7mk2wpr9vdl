#アストラボットv4.29.0-beta.1

4.29.0-beta.1 - 2026-10-01

このプレリリースには、v4.28.0 (a412146401426c0cdff8bbefb8627a03da519da8 のコミット) 以降の変更が含まれています。

主な追加点

  • コンピューターの使用: ローカル実行環境用の OS 固有のサンドボックス サポートが追加されました。シートベルトを備えた macOS とバブルラップを備えた Linux でのみ利用可能です。 (#9472)
  • ChatUI: チャット履歴とサイドバー セッションのページネーション、永続的な入力ドラフト、セッションごとのモデル選択、プロジェクト切り替え時の入力オートフォーカスが追加されました。 (#9667、#10279、#10247、#10301)
  • ChatUI: プロバイダー ソース フィルターとスティッキー グループをモデル選択に追加し、さらにスキル ページと MCP ページでの検索を追加しました。 (#10084、#10217)
  • WebUI: ワークスペース ディレクトリ ピッカーを追加し、デスクトップ アプリでダウンロードの進行状況を更新します。 (#10222、#10227、#10050)
  • デスクトップ: WebUI のサイドバーとトップ バーに macOS の曇りガラス効果を追加しました。 (#10222、#10227、#10050)
  • コア: エージェント ステップ予算リマインダーの追加、従来の制限の移行、デフォルトのエージェント ステップ制限の増加、およびシェル セッション待機の延長。 (#10131、#10133)
  • コア: プロバイダー要求に x-astrbot-conversation-id 会話 ID ヘッダーを追加しました。 (#10218、#10237)

主な最適化

  • サイドバーとトップバーを改良し、より多くの情報を表示するために垂直方向のフットプリントを削減しました。 (#10222、#10227、#10050)
  • データとログ ページの会話データのプレビューが改善されました。 (#10021、#10020、#10023、#10108)
  • メモリ使用量を制限した再開可能なチャンクアップロード、ダッシュボードの静的アセットの圧縮、バンドルされたフォントと図アセットの削減を追加しました。 (#10123、#10187、#10034)
  • ストリーミング応答と推論パネルのスクロールの改善、履歴の読み込み中のスクロール位置の保持、アニメーション フレームごとの合体自動スクロール。 (#10219、#10221、#10243、#10253、#10257、#10271)
  • モデル入力画像の準備が改善され、画像ジオメトリが保存され、エンコードされた画像サイズが制限され、モデルへのアニメーションからフレームへの変換が説明されました。 (#9703、#10071、#10120、#10119)
  • コンソール ログのバッチ レンダリング、プロバイダー ダイアログとトレースの更新の最適化、不要なセッションとレート制限の作業の削除。 (#9990、#10007、#10270、#10273、#10274)

主要な修正

  • 以前のコマンド動作を復元しました。/reset は現在の会話コンテキストをクリアします。 /new は新しい会話を作成し、新しい会話に切り替えます。永続的な会話の削除と履歴のタイトルを修正しました。 (#10118、#10003、#9983)
  • キューに入れられたリクエスト履歴の更新、セッション ロック前の添付ファイルの準備、LLM 処理が無効になった後もキューに入れられたリクエストが継続される問題を修正しました。 (#10238、#10209、#10234)
  • WebChat サイドスレッド モデルの選択、プロアクティブ エージェント モデル フォールバック、WebChat ウェイク プレフィックス ゲーティング、およびストリーミング フォールバック応答を修正しました。 (#10065、#10028、#10245、#10025)
  • スケジュールされたエージェントの失敗レポート、コンテキスト圧縮、プラグイン フィルターを修正しました。無効な編集後のリマインダーの保持、タスクの所有権の明確化、cron の誤起動猶予期間の 300 秒への増加。 (#9987、#9992、#10163、#10075、#10104、#10183)
  • OpenAI 互換のエンドポイント解決、スタックされた SDK 再試行、思考タグ解析、Gemini ナレーション履歴、Azure TTS client ライフタイム、Xinference リランク エラー伝播、および絵文字トークン推定を修正しました。 (#10079、#9669、#10116、#10132、#10101、#10051、#10216)
  • Lark のプライベート メッセージ配信、QQ 公式メンションと C2C ストリームの完了、OneBot ファイル解決、過剰な Telegram ポーリング ログを修正しました。 (#10018、#9705、#10069、#10098、#10046)
  • クリアされたSatoriハートビート/再接続設定とWeChat公式アカウントのタイムアウトフィールドが予期される安全策を無効にする問題を修正しました。 (#10248、#10229)
  • URL およびファイルからのプラグインの更新、Windows の長いパスのプラグインの抽出、およびデフォルトの GitHub ブランチ解決を修正しました。 (#10053、#10193、#10080)
  • Web 検索パラメーターの処理、ナレッジベースの URL レート制限、ファイル編集時のリテラル エスケープ、画像添付ファイルの有効期間とクリーンアップ、応答をドロップするセグメント応答ログの失敗を修正しました。 (#9979、#10015、#10112、#10042、#10090、#10231)
  • SQLModel のアップグレード全体での日時の永続性を修正し、プラットフォーム メッセージ履歴のカットオフを UTC で比較しました。 (#10211、#10246)
  • 古いデスクトップ WebUI アセットと提供されるバージョンの検出、モバイル ドロワーの動作、ダークモード アイコンとコンソールのコントラスト、非表示の会話、レガシー アイコン、アンマウント後の統計タイマーを修正しました。 (#9898、#10156、#10256、#10061、#10135、#10129、#10278、#10272)

中国語

今回の配布バージョンには v4.28.0 (譲渡 a412146401426c0cdff8bbefb8627a03da519da8) からの変更が含まれています。

主要新增

  • 電気使用機能: オペレーティング システムを最適化してローカルで実行する環境 (ローカル) モードに新しく適合しました (macOS シートベルトと Linux bwrap 環境のみをサポートします)。 (#9472)
  • ChatUI: 新しい天気履歴とサイド ミーティングの議事録、入力草の長期化、選択されたモデルのミーティングの承認、および切り替え時の自動フォーカス入力フレーム。 (#9667、#10279、#10247、 #10301)
  • ChatUI: モデル選択ツールが新しくなり、ソース選択とコンテンツが新しくなり、スキルが MCP トップから新しく検索されます。 (#10084、#10217)
  • WebUI: 面端の新しいオペレーション エリア リスト選択およびダウンロード速度の更新。 (#10222、#10227、#10050)
  • セクション: WebUI のサイド エッジと macOS のヘアガラス効果。
  • コア: 新しいエージェントの残りの数を増やし、古いバージョンの数の制限を移し、承認数の上限を増やし、シェル会議などの待機時間を延長します。 (#10131、#10133)
  • コア: モデル プロバイダーが新しい x-astrbot-conversation-id セッション ID 要求を要求します。 (#10218、#10237)

主优化

  • サイドボーダーとトップボーダーが拡張され、情報の密度が増すために長さが短くなります。
  • 「データと日報」のデータ事前通知の効果等を宣伝します。 (#10021、#10020、#10023、#10108)
  • 継続的に転送可能なブロック上での転送をサポートし、内部占有を制御し、WebUI の静的ソースを圧縮し、文字と図表のソースを削減します。 (#10123、#10187、#10034)
  • ストリーム形式の反転と待機パネルの動作を促進し、ロード時に移動位置を保持し、画枠を結合して自動操作します。
  • モデルは、画像処理を入力し、画像の比率を保持し、コード化を制限し、モデルにアニメーション画像が多フレーム画像に変換されたことを示します。 (#9703、#10071、#10120、#10119)
  • 大量汚染制御台の日報、促進モデルプロバイダーの監視と追跡の更新、会議の制限および制限時間の追加の制限を削減します。

主要修复

  • 古いバージョンのコマンド メッセージを追加: /reset は現在のセッション コンテキスト テキストを削除し、/new を作成して新しいミーティング メッセージに切り替えます。久化会メッセージを修正し、履歴を表示します。 (#10118、#10003、#9983)
  • 排除要求のブラシ、警告前のアクセサリ標準、および LLM 処理後の継続実行の問題を修正します。 (#10238、#10209、#10234)
  • WebChat サブラインのモデル選択、ホスト エージェントのモデルのバックグラウンド、WebChat の起動前の制限、およびストリームのバックバックの喪失を修正しました。 (#10065、#10028、#10245、#10025)
  • 定期エージェントの失効記録、上下テキスト圧縮、およびファイルのフィルタリング。非効率的な再起動は行われず、明らかなジョブの制限が行われ、この調整の制限時間が 300 秒に延長されます。 #9992、#10163、#10075、#10104、#10183)
  • 修正 OpenAI 互換インターフェイス地址解析、SDK 再試行追加、思考标签解析、Gemini ツール用前文本历史、Azure TTS ゲスト端末生存期間、Xinference 重排错误伝達及び表情トークン估算。 (#10079, #9669, #10116、#10132、#10101、#10051、#10216)
  • 修正私聊メッセージ投函、QQ 官方机人集団提訴および私聊流式終了フレーム、OneBot 文書解析、および電報轮询日志の多くの問題。 (#10018、#9705、#10069、#10098、 #10046)
  • 清空Satoriのハートビート/再構成およびマイクロ信号超時間構成を修正すると、対応する保護喪失の問題が発生します。 (#10248、#10229)
  • URL およびファイルの更新、Windows の経路パス解決、および GitHub による分割サポートによる修正。 (#10053、#10193、#10080)
  • ネットワーク検索パラメータ処理、知られている URL の消去制限ストリーム、ファイル ファイル内の文字面の変換文字、画像添付ファイルの寿命と消去、および分別日報の損失により、回復が失われる問題が修正されました。 (#9979、#10015、 #10112、#10042、#10090、#10231)
  • SQLModel アップグレード後の日付と時刻の永続性を修正し、プラットフォーム メッセージ履歴の期限を比較するために UTC を統一的に使用します。 (#10211、#10246)
  • デスクトップ上の期限切れの WebUI リソースとバージョンの検出、モバイル ドロワーの動作、ダーク モードのアイコンとコンソールのコントラスト、非表示のセッション、古いバージョンのアイコン、統計コンポーネントがアンインストールされた後もタイマーが開始される問題を修正しました。 (#9898、#10156、#10256、#10061、#10135、#10129、#10278、#10272)

AstrBot v4.29.0-beta.1

Highlights

  • Sandboxed local Computer Use (#9472, #10096) — The local execution environment now runs agent-driven OS actions inside OS-level sandboxes, but only macOS Seatbelt and Linux bubblewrap are supported. If you're on Windows or a non-bwrap Linux distro, this capability simply won't activate — plan around that gap. A related change moves the local-network policy notice into system prompts (#10134), so agents now "know" the boundary they're operating under rather than just being constrained by it.

  • Per-request conversation identity (#10218, #10237) — Provider requests now carry an x-astrbot-conversation-id header, and extra_user_content_parts is forwarded through Context.tool_loop_agent. This is an integration-contract change: if you sit an OpenAI-compatible proxy or gateway in front of AstrBot that rejects unknown headers, you'll need to whitelist it. On the plus side, it gives you a clean key for correlating provider traffic to a conversation in traces and billing data.

  • No more doubled LLM requests (#9669, #10051, #10116) — OpenAI SDK built-in retries are disabled so they no longer stack with AstrBot's own retry layer and multiply request counts (a real cost and rate-limit hazard). Related provider fixes: Xinference rerank failures now propagate as errors instead of silently returning empty results (#10051), and thinking tags are parsed in compatible completions (#10116). Watch request-volume dashboards and error alerts — both will shift after upgrading.

  • /reset and /new are distinct again (#10118, #10003, #9983) — /reset now only clears the current conversation's context; /new creates and switches to a fresh conversation. Any automation or muscle memory built on the old collapsed behavior needs updating. Persisted-conversation deletion and history-title rendering were fixed in the same pass, so stale or undeletable sessions should clear up.

  • More headroom for long-running agents (#10131, #10133, #10183, #10163) — The default agent step limit is raised, legacy limits are migrated to the new scheme, and step-budget reminders are added so agents self-report as they near the cap; shell session waits are extended too. Cron agents gain plugin-filter support, correct task ownership reporting, and a 300-second misfire grace window. Review any explicitly configured step caps — migration may change their effective values.

  • Cleared fields no longer disarm safeguards (#10248, #10229, #10211, #10246) — A subtle but important class of fix: blanking a WeChat Official Account timeout field or Satori heartbeat/reconnect delay used to silently disable the corresponding protection; now empty values fall back to safe defaults. Storage-side, datetime persistence is preserved across SQLModel upgrades and platform history cutoffs are compared in UTC — worth verifying if you run a non-UTC host or have been putting off a schema upgrade.

No breaking changes in this prerelease.
