#アストラボットv4.18.2

何が変わったのか

新しい

  • エージェント セッションを停止する機能が追加され、実行中のエージェントを終了し、実行中の出力結果が失われないようにする /stop コマンドをサポートするように停止要求処理プロセスが最適化されました。 (#5380)。
  • サブエージェントハンドオーバーシナリオにコンピューター使用ツールのサポートを追加しました (#5399)。
  • 実行プロセスの可観測性を向上させるために、エージェントの実行中にツール呼び出しの結果を表示する機能を追加しました (#5388)。
  • プラグインのライフサイクル機能を拡張するために、プラグインのロード/アンロード フックを追加しました (#5331)。
  • プラグインのロード失敗後のホット リロード機能を追加し、プラグインの開発と回復の効率を向上させました (#5334)。
  • サブエージェント画像の URL/ローカル パス入力のサポートを追加しました (#5348)。
  • ダッシュボード公開ジャンプベース URL 設定可能項目 (#5330) を追加しました。

修正

  • Tavily リクエストのハードコードされた 6 秒のタイムアウトを修正しました。
  • OneBot v11 アダプターがオフになった後も接続し続ける問題を修正しました (#5412)。
  • コンテキスト セッションでプラットフォームが見つからない場合のログ処理を修正し、警告を追加し、トラブルシューティング情報を改善しました。
  • 埋め込みディメンションがプロバイダー API (#5411) に透過的に送信されない問題を修正しました。
  • ファイル コンポーネントの処理ロジックを修正し、OneBot ドライバー層のパスの互換性を強化しました (#5391)。
  • サンドボックスファイル転送ツールで管理者権限の確認ができない問題を修正しました (#5402)。
  • パイプラインと from ... import * (#5353) によって引き起こされる循環依存関係の問題を修正しました。
  • 設定ファイルに UTF-8 BOM (#5376) が含まれている場合の解析の問題を修正しました。
  • ChatUI でコピー ロールバック パスが見つからず、不明瞭なエラー メッセージが表示される問題を修正しました (#5352)。 ・プラグインディレクトリの異常動作を回避するため、プラグインディレクトリを保持する処理ロジックを修正しました(#5369)。
  • ChatUI ファイルのメッセージセグメントを永続化できない問題を修正しました (#5386)。
  • .dockerignore が誤って changelogs ディレクトリを除外してしまう問題を修正しました。
  • aiohttp のバージョンが古いために qq-botpy がエラーを報告する問題を修正しました (#5316)。

最適化

  • サブエージェント レイアウト ページの国際化が完了し、多言語サポートが追加されました (#5400)。
  • メッセージ イベント処理に関連するテストを追加し、テスト フレームワーク (#5355、#5354) のフィクスチャ/モック カバレッジを改善しました。

AstrBot v4.18.2

Highlights

  • Agent control and observability — /stop can terminate active Agent sessions while aiming to preserve already-produced output, and tool-call results can now be displayed during execution. This makes long-running agents easier to interrupt and diagnose (#5380, #5388).
  • Richer SubAgent handoffs — SubAgents now accept image URLs and local paths, while computer-use tools are available during handoffs. This enables multimodal and browser/desktop workflows rather than text-only delegation (#5348, #5399).
  • Plugin lifecycle management — New load/unload hooks let plugins coordinate initialization and cleanup, while failed plugin loads support hot reload for faster development and recovery. Reserved plugin-directory handling was also corrected (#5331, #5334, #5369).
  • Sandbox permissions tightened — File-transfer tools now enforce administrator privileges. Integrations running under unprivileged identities must use an authorized account or adjust their permission model (#5402).
  • Integration and configuration fixes — Embedding dimensions now reach provider APIs, so verify that configured dimensions match your model and existing vector indexes (#5411). OneBot/aiocqhttp shutdown and file-path handling are more robust (#5412, #5391), Dashboard release redirects now support a configurable base URL (#5330), and UTF-8 BOM configuration files parse correctly (#5376).
  • Compatibility — No breaking changes are announced.

What's Changed

新增

  • 新增 Agent 会话停止能力，并优化 stop 请求处理流程，支持 /stop 指令终止 Agent 运行并尽量不丢失已运行输出的结果。 (#5380)。
  • 新增 SubAgent 交接场景下的 computer-use 工具支持 (#5399)。
  • 新增 Agent 执行过程中展示工具调用结果的能力，提升执行过程可观测性 (#5388)。
  • 新增插件加载/卸载 Hook，扩展插件生命周期能力 (#5331)。
  • 新增插件加载失败后的热重载能力，提升插件开发与恢复效率 (#5334)。
  • 新增 SubAgent 图片 URL/本地路径输入支持 (#5348)。
  • 新增 Dashboard 发布跳转基础 URL 可配置项 (#5330)。

修复

  • 修复 Tavily 请求的硬编码 6 秒超时。
  • 修复 OneBot v11 适配器关闭之后仍然在连接的问题(#5412)。
  • 修复上下文会话中平台缺失时的日志处理，补充 warning 并改进排查信息。
  • 修复 embedding 维度未透传到 provider API 的问题 (#5411)。
  • 修复 File 组件处理逻辑并增强 OneBot 驱动层路径兼容性 (#5391)。
  • 修复 sandbox 文件传输工具缺少管理员权限校验的问题 (#5402)。
  • 修复 pipeline 与 from ... import * 引发的循环依赖问题 (#5353)。
  • 修复配置文件存在 UTF-8 BOM 时的解析问题 (#5376)。
  • 修复 ChatUI 复制回滚路径缺失与错误提示不清晰的问题 (#5352)。
  • 修复保留插件目录处理逻辑，避免插件目录行为异常 (#5369)。
  • 修复 ChatUI 文件消息段无法持久化的问题 (#5386)。
  • 修复 .dockerignore 误排除 changelogs 目录的问题。
  • 修复 aiohttp 版本过新导致 qq-botpy 报错的问题 (#5316)。

优化

  • 完成 SubAgent 编排页面国际化，补齐多语言支持 (#5400)。
  • 增补消息事件处理相关测试，并完善测试框架的 fixtures/mocks 覆盖 (#5355, #5354)。

What's Changed (EN)

New Features

  • Added computer-use tools support in sub-agent handoff scenarios (#5399).
  • Added support for displaying tool call results during agent execution for better observability (#5388).
  • Added plugin load/unload hooks to extend plugin lifecycle capabilities (#5331).
  • Added hot reload support when plugin loading fails, improving recovery during plugin development (#5334).
  • Added image URL/local path input support for sub-agents (#5348).
  • Added stop control for active agent sessions and improved stop request handling (#5380).
  • Added configurable base URL for dashboard release redirects (#5330).

Fixes

  • Fixed logging behavior when platform information is missing in context sessions, with clearer warning and diagnostics.
  • Fixed missing embedding dimensions being passed to provider APIs (#5411).
  • Fixed shutdown stability issues in the aiocqhttp adapter (#5412).
  • Fixed File component handling and improved path compatibility in the OneBot driver layer (#5391).
  • Fixed missing admin guard for sandbox file transfer tools (#5402).
  • Fixed circular import issues related to pipeline and from ... import * usage (#5353).
  • Fixed config parsing issues when files contain UTF-8 BOM (#5376).
  • Fixed missing copy rollback path and unclear error messaging in ChatUI (#5352).
  • Fixed reserved plugin directory handling to avoid abnormal plugin path behavior (#5369).
  • Fixed ChatUI file segment persistence issues (#5386).
  • Fixed accidental exclusion of the changelogs directory in .dockerignore.
  • Fixed compatibility issues caused by a hard-coded 6-second timeout in Tavily requests.
  • Fixed qq-botpy runtime errors caused by overly new aiohttp versions (#5316).

Improvements

  • Completed internationalization for the sub-agent orchestration page (#5400).
  • Added broader message-event test coverage and improved fixtures/mocks in the test framework (#5355, #5354).
  • Updated README content and applied repository-wide formatting cleanup (ruff format) (#5375).
