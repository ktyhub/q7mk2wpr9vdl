#アストラボットv4.18.3

何が変わったのか

新しい

  • クライアントでの更新プロセスへのアクセスを容易にするデスクトップ ユニバーサル アップデート ブリッジ機能を追加しました (#5424)。

修正

・新規プラットフォームダイアログに回線アダプタが表示されない問題を修正しました。

  • Telegram がビデオを送信できない問題 (#5430) を修正しました。
  • 埋め込みプロバイダーの作成時にベクトル次元が自動的に認識されない問題を修正しました (#5442)。
  • QQ 公式プラットフォームでメディア メッセージを送信するときにマークダウン フィールドがクリーンアップされない問題を修正しました (#5445)。
  • コンテキスト管理ポリシー -> コンテキストの切り捨て時にツールの呼び出し/応答のペアが失われる問題を修正しました (#5417)。
  • セッション更新中にpersona_idが上書きされる問題を修正し、ペルソナ解析ロジックを強化しました。
  • WebUIでGitHubのプロキシアドレスが異常に表示される問題を修正しました(#5438)。
  • 設定ページで新しい開発者 API キーを作成した後にコピーが失敗する問題を修正しました (#5439)。
  • OpenAI STT (OGG を使用) との Telegram 音声メッセージ形式の互換性の問題を修正しました (#5389)。

最適化

  • ナレッジ ベースの取得プロセスを最適化し、バッチ クエリ メタデータに変更し、N+1 クエリのパフォーマンスの問題 (#5463) を修正します。
  • 将来のタスク実行のために Cron のセッション分離機能を最適化し、同時実行の安定性を向上させます。
  • WebUI プラグイン ページのインタラクションを最適化します。

変更点 (英語)

新機能

  • 統合プラグイン拡張ページ状態管理用に useExtensionPage コンポーザブルを追加しました。
  • アプリ内更新ワークフローをサポートするための汎用デスクトップ アプリ アップデーター ブリッジを追加しました (#5424)。

バグ修正

  • 「プラットフォームの追加」ダイアログに回線アダプターが表示されない問題を修正しました。
  • Telegram ビデオ送信の問題を修正しました (#5430)。
  • Pyright の静的型チェック エラー (#5437) を修正しました。
  • 埋め込みプロバイダー作成時の埋め込みディメンションの自動検出を修正しました (#5442)。
  • QQ 公式プラットフォーム経由でメディア メッセージを送信するときの古いマークダウン フィールドを修正しました (#5445)。
  • コンテキスト切り捨て中のツールの呼び出し/応答ペアリングの損失を修正しました (#5417)。
  • 会話の更新中に persona_id が上書きされる問題を修正し、ペルソナ解決ロジックを改善しました。
  • WebUI での誤った GitHub プロキシ表示を修正しました (#5438)。
  • 設定で新しいキーを作成した後の API キーのコピーの失敗を修正しました (#5439)。
  • OGG (#5389) を使用して、OpenAI STT と Telegram 音声フォーマットの互換性を修正しました。

改善点

  • メタデータ クエリをバッチ処理して N+1 クエリ パターン (#5463) を排除することにより、ナレッジ ベースの検索が改善されました。
  • 将来の cron タスクのセッション分離が改善され、同時実行時の安定性が向上しました。
  • WebUI プラグイン ページのインタラクションが改善されました。

AstrBot v4.18.3

Highlights

  • Tool-call context integrity — (#5417) Context truncation could previously split a tool call from its response, leaving malformed message histories that make tool-using models fail or hallucinate. This is a correctness fix for long agent runs, not a cosmetic one: if you use context-truncation strategies, re-test sessions with heavy tool use, since prior conversations may have been silently corrupted. No configuration change required.
  • Embedding provider setup — (#5442) Vector dimensions are now detected automatically when creating an embedding provider, removing a manual step that was a common source of silent vector-search breakage when the configured dimension didn't match the model. Existing providers with hardcoded dimensions are unaffected, but this lowers the risk of new misconfiguration.
  • Knowledge base performance — (#5463) Retrieval now batches metadata lookups instead of issuing one query per document, eliminating the N+1 pattern. Expect materially lower latency on large knowledge bases or remote metadata backends; this is a drop-in improvement with no API or data migration, so there's nothing to adopt beyond upgrading.
  • Persona resolution and session identity — (#5440) Conversation updates no longer overwrite persona_id, and session/conversation persona lookup is unified. If you had workarounds that re-applied a persona after each update, they can now be removed — but check any logic that depended on the old resolution precedence, as persona selection may now resolve differently.
  • Telegram media compatibility — Voice messages are now sent as OGG rather than WAV (#5389), fixing transcription through OpenAI-compatible STT endpoints, and video sending is restored (#5430). If you had custom WAV handling or were avoiding Telegram video entirely, both paths are worth re-validating.
  • Platform and tooling hardening — A generic desktop updater bridge (#5424) gives client integrators a supported in-app update hook, while cron tasks gain better session isolation under concurrency, QQ Official media sends no longer leak stale markdown fields (#5445), and Pyright issues are cleaned up (#5437, #5474) — useful if static type checking gates your builds.
  • Breaking changes — None in this release.

What's Changed

新增

  • 新增桌面端通用更新桥接能力，便于接入客户端内更新流程 (#5424)。

修复

  • 修复新增平台对话框中 Line 适配器未显示的问题。
  • 修复 Telegram 无法发送 Video 的问题 (#5430)。
  • 修复创建 embedding provider 时无法自动识别向量维度的问题 (#5442)。
  • 修复 QQ 官方平台发送媒体消息时 markdown 字段未清理的问题 (#5445)。
  • 修复上下文管理策略 -> 上下文截断时 tool call / response 配对丢失的问题 (#5417)。
  • 修复会话更新时 persona_id 被覆盖的问题，并增强 persona 解析逻辑。
  • 修复 WebUI 中 GitHub 代理地址显示异常的问题 (#5438)。
  • 修复设置页新建开发者 API Key 后复制失败的问题 (#5439)。
  • 修复 Telegram 语音消息格式与 OpenAI STT 兼容性问题（使用 OGG） (#5389)。

优化

  • 优化知识库检索流程，改为批量查询元数据，修复 N+1 查询性能问题 (#5463)。
  • 优化 Cron 未来任务执行的会话隔离能力，提升并发稳定性。
  • 优化 WebUI 插件页的交互。

What's Changed (EN)

New Features

  • Added useExtensionPage composable for unified plugin extension page state management.
  • Added a generic desktop app updater bridge to support in-app update workflows (#5424).

Bug Fixes

  • Fixed the Line adapter not appearing in the "Add Platform" dialog.
  • Fixed Telegram video sending issues (#5430).
  • Fixed Pyright static type checking errors (#5437).
  • Fixed embedding dimension auto-detection when creating embedding providers (#5442).
  • Fixed stale markdown fields when sending media messages via QQ Official Platform (#5445).
  • Fixed tool call/response pairing loss during context truncation (#5417).
  • Fixed persona_id being overwritten during conversation updates and improved persona resolution logic.
  • Fixed incorrect GitHub proxy display in WebUI (#5438).
  • Fixed API key copy failure after creating a new key in settings (#5439).
  • Fixed Telegram voice format compatibility with OpenAI STT by using OGG (#5389).

Improvements

  • Improved knowledge base retrieval by batching metadata queries to eliminate the N+1 query pattern (#5463).
  • Improved session isolation for future cron tasks to increase stability under concurrency.
  • Improved WebUI plugin page interactions.
