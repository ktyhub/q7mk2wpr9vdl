#アストラボットv4.22.1

何が変わったのか

新しい

  • スキルのインストール プロセスが強化され、アップロードされた圧縮パッケージの最上位がディレクトリに制限されなくなりました。中国語スキル名の表示にも対応しました。 (#6952)
  • OpenAI 埋め込みモデル構成は、/v1 ベース パスの自動完成をサポートします。 (#6863)
  • /api/file の GET エンドポイントを追加し、複数のリクエスト メソッドをサポートします。 (#6874)
  • WebUI 設定ページにログとキャッシュのクリーニング機能を追加しました。 (#6822)
  • Lark プラットフォームは、折りたたみ可能な思考パネル機能とメッセージ処理の最適化を追加します。 (#6831)

修正

  • Cron Job またはアクティブにメッセージを送信するときの QQ 公式ロボットの msg_id 関連の負荷処理の問題を修正しました。 (#6604)
  • ポーリングがタイムアウトした後に個人 WeChat がポーリングを停止する問題を修正しました。 (#6915)
  • Silicon Flow プロバイダーがツール呼び出し機能を正しく使用していない問題を修正しました。 (#6829)
  • 一部のプロバイダー ツールがストリーミング インクリメンタル リターンを呼び出すときにインデックスの欠落によって発生する例外を修正しました。 (#6661 ・WebUIでObjectEditorのupdateKeyのインデックスが間違っていることによる「キーが既に存在します」との誤判定を修正しました。 (#6825)
  • UI アイコンの収集とテストの一貫性によって引き起こされる表示の異常を修正しました。 (#6894、#6892)
  • T2I 構成間で有効なテンプレートが同期されない問題を修正しました。 (#6824)
  • 公式ドキュメントの規則に合わせて MIMO TTS スタイルのパラメーターを修正しました。 (#6814)

変更点 (英語)

新機能

  • 複数の最上位フォルダー、重複処理、および中国語のスキル名をサポートするためにスキルのインストールが強化されました。（#6952）
  • OpenAI 埋め込み互換性のために、/v1 を embedding_api_base に自動的に追加します。（#6863）
  • WebUI にプラグイン作成者の表示と固定プラグイン カードのサポートを追加しました。（#6875）
  • /api/file の GET エンドポイントと複数の HTTP メソッドのサポートを追加しました。（#6874）
  • ダッシュボード設定にログとキャッシュのクリーンアップを追加しました。（#6822）
  • Lark に折りたたみ可能な推論パネルとメッセージ処理の改善を追加しました。（#6831）

改善点

  • 偽陰性を避けるために、存在チェックの前に config_path を検証します。（#6722）
  • WebUI でのプロバイダーのバッチ リセット動作と「フォロー」構成の処理を改善しました。（#6825）
  • 互換性のヒントをより明確にするために、i18n ドキュメントの OpenAI 関連のガイダンスを更新しました。（adc252a3)

バグ修正

  • ストリーミング tool_call デルタで欠落していたインデックス フィールドを修正しました。（#6661）
  • QQ API の msg_id ペイロード処理を修正しました。（#6604）
  • インバウンドタイムアウト後も Weixin OC ポーリングをアクティブに保ちました。（#6915）
  • 誤った「キーが存在します」エラーを引き起こす、WebUI ObjectEditor の updateKey インデックスのバグを修正しました。（#6825）
  • UIおよび関連アイコンスキャンテストにおけるアイコンの回帰を修正しました。（#6894、#6892）
  • SiliconFlow プロバイダー ツールの互換性の問題を修正しました。（#6829）
  • すべての構成にわたってアクティブな T2I テンプレートを同期しました。（#6824）
  • MIMO TTS ペイロード スタイルを公式ドキュメントと調整しました。（#6814）
  • テスト中に残されたプライバシーに関わるデータを削除しました。（#6803）

AstrBot v4.22.1

Highlights

  • Tool/function calling repaired across providers — Two fixes directly affect anyone relying on tool calls: the SiliconFlow provider now correctly uses tools (#6829), and streaming tool_call deltas that omitted the index field no longer throw errors (#6661). If you saw broken or crashing tool invocations on these paths, this patch is the reason to upgrade.

  • Provider/API compatibility tightened — OpenAI embedding setup now auto-appends /v1 to embedding_api_base (#6863), MIMO TTS payload style is aligned with official docs (#6814), and the active T2I template is synced across configs (#6824 is TTS; T2I is #6824). These are correctness/convenience fixes, not behavior changes you need to migrate around.

  • Platform messaging stability — QQ official bot now handles msg_id payloads correctly for Cron Jobs and proactive sends (#6604), WeChat (Weixin OC) no longer stops polling after an inbound timeout (#6915), and Lark gains a collapsible reasoning panel plus message handling improvements (#6831). Important if you run scheduled/proactive messages or these specific platforms.

  • WebUI, API, and Skills workflow — A GET endpoint was added to /api/file with broader HTTP method support (#6874); Dashboard settings gained log/cache cleanup (#6822); ObjectEditor's updateKey index bug caused false "key exists" errors and is fixed (#6825); skill installation accepts multiple top-level folders, duplicate handling, and Chinese skill names (#6952). Plugin author display/pinned cards (#6875) and icon fixes (#6894, #6892) round out the UI work.

  • Upgrade verdict — low-risk patch, no breaking changes — v4.22.1 is a bugfix/maintenance release: no breaking changes or migration steps are called out, and no new required configuration is introduced. Worth upgrading for users hitting tool-call errors, QQ/Weixin/Lark messaging issues, or Skills/WebUI annoyances; safe to skip for anyone on a stable setup who doesn't use those paths. Minor housekeeping also removed privacy-sensitive data from tests (#6803).

What's Changed

新增

  • 增强 Skills 安装流程，不再限制上传的压缩包顶级必须是一个目录。并支持中文技能名称显示。（#6952）
  • OpenAI Embedding 模型配置支持自动补齐 /v1 基础路径。（#6863）
  • 为 /api/file 新增 GET 端点并支持多种请求方式。（#6874）
  • WebUI 设置页新增日志与缓存清理能力。（#6822）
  • Lark 平台新增可折叠 Thinking 面板能力与消息处理优化。（#6831）

修复

  • 修复 QQ 官方机器人中，在 Cron Job 或者主动发送消息时的 msg_id 相关负载处理问题。（#6604）
  • 修复 个人微信 在轮询超时后停止轮询的问题。（#6915）
  • 修复 硅基流动 提供商无法正确使用工具调用能力的问题。（#6829）
  • 修复部分提供商工具调用流式增量返回缺少 index 导致的异常。（#6661
  • 修复 WebUI 中 ObjectEditor 的 updateKey 错误索引导致的“键已存在”误判。（#6825）
  • 修复 UI 图标集合及测试一致性导致的展示异常。（#6894、#6892）
  • 修复 T2I 配置间未同步生效模板的问题。（#6824）
  • 修复 MIMO TTS 样式参数以对齐官方文档约定。（#6814）

What's Changed (EN)

New Features

  • Enhanced skill installation to support multiple top-level folders, duplicate handling, and Chinese skill names.（#6952）
  • Automatically append /v1 to embedding_api_base for OpenAI embedding compatibility.（#6863）
  • Added plugin author display and pinned plugin card support in WebUI.（#6875）
  • Added GET endpoint for /api/file and support for multiple HTTP methods.（#6874）
  • Added log and cache cleanup in Dashboard settings.（#6822）
  • Added collapsible reasoning panel and message handling improvements for Lark.（#6831）

Improvements

  • Validate config_path before existence checks to avoid false negatives.（#6722）
  • Improved Provider batch reset behavior and "follow" configuration handling in WebUI.（#6825）
  • Updated OpenAI-related guidance in i18n docs for clearer compatibility hints.（adc252a3)

Bug Fixes

  • Fixed missing index field in streaming tool_call deltas.（#6661）
  • Fixed msg_id payload handling for QQ API.（#6604）
  • Kept Weixin OC polling active after inbound timeout.（#6915）
  • Fixed updateKey index bug in WebUI ObjectEditor that caused false “key exists” errors.（#6825）
  • Fixed icon regressions in UI and related icon scan tests.（#6894、#6892）
  • Fixed SiliconFlow provider tools compatibility issue.（#6829）
  • Synchronized active T2I template across all configs.（#6824）
  • Aligned MIMO TTS payload style with official docs.（#6814）
  • Removed privacy-sensitive data left in tests.（#6803）
