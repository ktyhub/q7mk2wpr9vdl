#アストラボットv4.24.2

  • アップデートログ(簡体字中国語)
  • Changelog(英語) <a id="中国語"></a>

私たちは、より優れた AstBot プラグイン共有および管理プラットフォームをリリースする予定ですので、ご期待ください。

何が変わったのか

新しい

  • WebUI ページ (プラグイン ページ) をカスタマイズするプラグインの機能を追加しました。プラグインは、pages/ ディレクトリおよび登録された Web ルートを通じてカスタム ページをダッシュ​​ボードに公開できます。詳細については、開発ドキュメントを参照してください。 (#5940)
  • プラグインの国際化サポートを追加しました。このプラグインは、.astrbot-plugin/i18n で複数言語の名前、説明、構成テキストを提供でき、ダッシュボード コンポーネントは現在の言語に従って解析されて表示されます。詳細については、開発ドキュメントを参照してください。 (#7919)
  • プラグイン スキルのサポートが追加され、プラグインは skills/ を通じてスキルを提供できるようになりました。 (#7945)。詳細については、開発ドキュメントを参照してください。
  • extra_user_content_parts 一時コンテンツ マークを追加しました。プラグインは TextPart(...).mark_as_temp() を使用して、セッション履歴に書き込まずに、追加のコンテンツがこのラウンドの LLM リクエストにのみ参加できるようにすることができます。 (#7976)。詳細については、プラグイン開発ドキュメントを参照してください。
  • プラグインの詳細ページ、プラグインの簡単な説明、プラグインのトップ、AstrBot 公式プラグイン ストレージ経由でプラグインをダウンロードする機能を追加し、プラグインのインストールとブラウジングのエクスペリエンスを向上させました。 (#7896、#7918、#7930、#7931)
  • fallback_max_context_tokens 構成を追加しました。モデルのメタデータが欠落しており、max_context_tokens が 0 である場合、デフォルトのコンテキスト ウィンドウの上限を使用して圧縮判定に参加できます。値のデフォルトは 128k です。 (#7942)
  • WebUI スキル ページでのスキル ファイルの表示と編集をサポートします。 (#7903)
  • CUA Computer Use サンドボックス ランタイムを追加しました。これは、デスクトップ GUI、スクリーンショット、キーボード、マウス、ブラウザ起動プロセス、フロント シェルとバック シェル、ファイル ロールバック処理と権限制御をサポートし、使用方法のドキュメントとテストを補足します。 (#7828)
  • バックグラウンドでのシェル コマンドの実行、出力リダイレクトとタイムアウトのサポートを追加し、Python ツールのタイムアウト パラメーターを追加しました。 (#7835、#7953)
  • QQ 公式プラットフォームのメッセージレベルのマークダウン制御機能を追加しました。 (#6980)
  • チャットおよびライブ チャット ルーティング用の添付ファイル保存イベントが追加され、フロント エンドは添付ファイルの永続化の結果を感知できます。 (#7869)
  • Linux/macOS/WSL および Windows PowerShell のワンクリック インストールをサポートする新しい展開スクリプトを追加し、スクリプトを docs パブリック ディレクトリに公開しました。 (#7631)

最適化

  • レイアウト、カード スタイル、応答性の高いパフォーマンス、ダッシュボード拡張機能、ナレッジ ベース、MCP、スキル、構成ページの多言語コピーライティングを最適化します。 (#7903)
  • セッション履歴におけるツール呼び出しのレンダリングを最適化します。ツール メッセージは、Markdown で通常のバブルとして直接レンダリングされなくなりましたが、大規模なツール結果によって引き起こされるページ ラグを回避するために、アシスタントに対応するツール カードに集約されます。 (#7937)
  • 最適化されたコンテキスト管理と圧縮戦略。これには、切り捨てアルゴリズム、ユーザー メッセージ削除問題の修正、PPIO コンテキスト長エラーの識別、および実行順序の構成インターフェイスの説明が含まれます。 (#7888、#7920)
  • プロバイダー モデルの追加ロジック、モデルの有効化スイッチの永続性、プロバイダー テストの失敗プロンプト、およびデフォルトのプロバイダーが見つからないか無効な場合の起動警告を最適化します。 (#7865、#7498、#7934)
  • セーフ モードでの send_message_to_user のプロンプトとフォールト トレランスを最適化し、完全なセッション形式を持たない cron アクティブ タスクとシナリオを最適化し、cron ペイロードにセッション情報を追加します。 (#7907、#7911)
  • リスト + オプション構成項目を最適化し、代わりに v-autocomplete を使用し、候補をキャッシュして長いリストの選択エクスペリエンスを改善します。 (#7884、#7885)
  • コマンドとツールの説明の表示を最適化し、WebUI で切り詰められた説明をツールヒントで表示できるようになりました。 (#7838)
  • 最適化インジケーター統計、ログの可読性、ナレッジ ベース ドキュメント、システム プロンプト Word ドキュメント、および AGENTS.md 内のコミット前の開発手順。 (#7838、#7962)

修正

  • 一般ユーザーが send_message_to_user を任意のセッションに送信できるというセキュリティ問題を修正しました。一般のユーザーは現在のセッションにのみメッセージを送信できますが、管理者は引き続きセッションを指定できます。 (#7822、#7824)
  • T2I テキスト テンプレート レンダリングの回帰を修正し、元のテキスト レンダリングを復元し、デフォルトで Shiki ランタイムを挿入し、組み込みのテンプレートと WebUI プレビューを調整します。 (#7789) ・IME入力方式組み合わせ状態でEnterキーを押すと誤ってチャットが送信されてしまう問題を修正しました。 (#7845)
  • Anthropic 並列ツールの結果のマージ、カスタム リクエスト ヘッダー、およびシステム プロンプトの互換性を修正して、複数の httpx インストールによって引き起こされる client タイプの不一致を回避し、リスト形式のシステム パラメータを使用してプロキシの互換性を向上させます。 (#7875、#7587)
  • OpenAI プロバイダーの http_client と SDK httpx タイプの間の互換性の問題を修正しました。 (#7773) ・stop_event()以降も後続ハンドラが実行され続け、clear_result()により停止状態がリセットされる問題を修正しました。 (#7900、#7922)
  • system_prompt を None に変更したときに、性格またはスキルのプロンプトを挿入するとエラーが報告される問題を修正しました。 (#7880)
  • Shipyard Neo サンドボックスの準備状況の検出と正常なクリーンアップを修正し、準備ができていない場合にプロセスの実行を継続したり終了したりする際の例外を回避しました。 (#7881)
  • デスクトップ プラグインのインストールの同時実行の問題が修正され、インストール プロセスがコア ロックによって保護されるようになりました。 (#7872)
  • グループチャットのキャッシュ検証を保持しながら、キャッシュmsg_idが欠落している場合にQQ公式プライベートチャットのアクティブプッシュが送信をスキップする問題を修正しました。 (#7904、#7914)
  • WeChat カスタマー サービス ファイル メッセージのサポートを修正し、企業 WeChat ファイル メッセージのプレースホルダー テキストを削除しました。 (#7923)
  • DingTalk SDK タスクが異常終了するか、接続がタイムアウトした後に自動的に再接続できない問題を修正しました。 (#7924)
  • PowerShell インストール スクリプト BOM、デプロイ スクリプト パス、.gitignore、およびパブリック ディレクトリの同期の問題を修正しました。
  • ツール呼び出し tool_choice に関連するデバッグの問題を修正しました。一部のプロバイダーの非互換性を回避するために、このパラメーターを一時的にコメント化しました。 (#7853、#7856、#7862) <a id="english"></a>

変更点 (英語)

新機能

  • デスクトップ GUI、スクリーンショット、キーボード、マウス、ブラウザ起動フロー、フォアグラウンド/バックグラウンド シェル サポート、ファイル システム フォールバック、権限処理、ドキュメント、およびテストを備えた CUA コンピューター使用サンドボックス ランタイムを追加しました。 (#7828)
  • プラグイン ページを追加し、プラグインがアセット認証、ブリッジ スクリプト、戻るボタンの動作、ドキュメント、セキュリティ テストを含むダッシュボード ページを pages/ ディレクトリ経由で公開できるようにします。 (#5940)
  • .astrbot-plugin/i18n を通じてプラグインの国際化サポートを追加しました。これには、ローカライズされた名前、説明、構成テキスト、ダッシュボードの統合、ドキュメント、テストが含まれます。 (#7919)
  • 同期、メタデータの強化、プラグインの詳細表示、構成に応じたフィルタリングを備えたプラグインが提供するスキルを追加しました。 (#7945)
  • プラグインの詳細ページ、プラグインの簡単な説明、プラグインの固定、AstrBot 公式プラグイン ストレージからのプラグインのダウンロードのサポートを追加しました。 (#7896、#7918、#7930、#7931)
  • 出力リダイレクトとタイムアウトのサポートを備えたバックグラウンド シェル コマンドの実行を追加し、Python ツールにタイムアウト パラメーターを追加しました。 (#7835、#7953)
  • モデルのメタデータが欠落しており、max_context_tokens が 0 に設定されている場合に使用される fallback_max_context_tokens を追加しました。 (#7942)
  • QQ Official にメッセージレベルの Markdown コントロールを追加しました。 (#6980)
  • チャットおよびライブチャットルートの添付ファイル保存イベントを追加しました。 (#7869)
  • Linux/macOS/WSL および Windows PowerShell 展開スクリプトを追加し、docs パブリック ディレクトリを通じて公開されました。 (#7631)
  • 一時的な extra_user_content_parts を追加しました。プラグインは、TextPart(...).mark_as_temp() を使用して、会話履歴に永続化せずに、現在の LLM リクエストにコンテンツを含めることができます。 (#7976)

改善点

  • ダッシュボード拡張機能、ナレッジ ベース、MCP、スキル、構成ページが改善され、WebUI でのレイアウト、カード スタイル、応答性、翻訳、スキル ファイル編集が改善されました。 (#7903)
  • 大きなツールの結果を通常の Markdown バブルとしてレンダリングするのではなく、ツール メッセージをアシスタント ツール カードにグループ化することで、会話履歴でのツールのレンダリングが改善されました。 (#7937)
  • コンテキストの管理と圧縮が改善されました。これには、切り捨て動作、ユーザー メッセージの保持、PPIO コンテキスト長エラー検出、および実行順序の明確な UI コピーが含まれます。 (#7888、#7920)
  • プロバイダー モデルの追加ロジック、モデルの有効化/切り替えの永続性、失敗したプロバイダー テストのフィードバック、欠落または無効なデフォルト プロバイダーに対する起動警告が改善されました。 (#7865、#7498、#7934)
  • セーフティ モード、cron プロアクティブ タスク、および不完全なセッション フォーマットにおける send_message_to_user プロンプトと耐性が改善されました。 cron ペイロードにセッション情報が含まれるようになりました。 (#7907、#7911)
  • v-autocomplete に切り替え、選択項目をメモ化し、長いリストの選択を改善することで、リスト + オプションの設定フィールドを改善しました。 (#7884、#7885)
  • ツールチップへのアクセスを追加することにより、WebUI の短縮されたコマンドとツールの説明が改善されました。 (#7838)
  • メトリクス、ログの明瞭さ、ナレッジ ベースのドキュメント、システム プロンプトのドキュメント、および AGENTS.md のコミット前のセットアップ ガイダンスが改善されました。 (#7838、#7962)

  • 生のテキスト レンダリングを復元し、デフォルトで Shiki ランタイムを挿入し、組み込みテンプレートとプレビュー動作を更新することにより、T2I テキスト テンプレート レンダリングを修正しました。 (#7789)
  • チャット入力での IME 合成中の Enter キーの処理を修正しました。 (#7845)
  • default_headers およびリスト形式のシステム プロンプトを使用することにより、Anthropic 並列ツール結果のマージ、カスタム ヘッダー、およびシステム プロンプトの互換性を修正しました。 (#7875、#7587)
  • OpenAI プロバイダー http_client と SDK httpx の互換性を修正しました。 (#7773)
  • 後のハンドラーが続行できるようにする stop_event() を修正し、clear_result() によって引き起こされる停止状態のリセットを修正しました。 (#7900、#7922)
  • system_prompt が None の場合のペルソナとスキルのプロンプト注入を修正しました。 (#7880)
  • Shipyard Neo の準備ゲートと適切なサンドボックスのクリーンアップを修正しました。 (#7881)
  • コア ロックでインストールを保護することにより、デスクトップ プラグインの同時インストールを修正しました。 (#7872)
  • グループ メッセージ キャッシュの検証を維持しながら、キャッシュされた msg_id が見つからない場合に QQ 公式のプライベート プロアクティブ プッシュがスキップされる問題を修正しました。 (#7904、#7914)
  • WeChat kefu ファイル メッセージを修正し、WeCom ファイル メッセージ プレースホルダーを削除しました。 (#7923)

  • デバッグ用のパラメータを一時的にコメントアウトすることで、tool_choice 周辺のプロバイダーの非互換性を修正しました。 (#7853、#7856、#7862)

AstrBot v4.24.2

Highlights

  • Plugin extensibility graduates to a platform — Plugins can now expose their own Dashboard pages via a pages/ directory with asset auth and a bridge script (#5940), ship localized names/descriptions/config text under .astrbot-plugin/i18n (#7919), and contribute skills that are synchronized and config-filtered (#7945). A plugin detail page, short descriptions, pinning, and downloads from the official plugin store (#7896, #7918, #7930, #7931) complete the picture. If you maintain a plugin, this is the release to re-architect around — these new directories and metadata are the contracts the Dashboard now reads.
  • CUA computer-use sandbox lands, with a real background shell — A new runtime (#7828) gives agents desktop GUI control: screenshots, keyboard/mouse, browser launch flows, foreground/background shell, filesystem fallbacks, and permission handling. Shell commands gain background execution, output redirection, and timeouts, and the Python tool gets a timeout parameter (#7835, #7953). This pushes AstrBot from chat router toward GUI-capable agent host; test the permission model and file-fallback paths first in your deployment.
  • send_message_to_user privilege escalation closed — A normal user could previously name an arbitrary session and push a message into it; now non-admins are confined to the current session and only admins can target others (#7822, #7824). Audit any integration that relied on cross-session pushes from regular users — those calls will now be rejected outside an admin context.
  • Context compression gets a defined fallback — New fallback_max_context_tokens (default 128k) applies when model metadata is missing and max_context_tokens is 0 (#7942), so compression has a window to work against instead of silently doing nothing. Truncation, user-message retention, and PPIO context-length error detection were also reworked (#7888, #7920). If you set max_context_tokens: 0 deliberately, re-check your config — compression decisions will change.
  • Provider compatibility hardened, with one caveat — Anthropic now merges parallel tool results, uses default_headers, and sends system prompts in list format for proxy and multi-httpx-install compatibility (#7875, #7587); OpenAI's http_client httpx type mismatch is fixed (#7773). Watch out: tool_choice has been temporarily commented out to dodge provider incompatibilities (#7853, #7856, #7862), so don't depend on it behaving deterministically yet.
  • Request and handler semantics changed — TextPart(...).mark_as_temp() / extra_user_content_parts lets plugins inject content into the current LLM request without writing it to conversation history (#7976) — the right tool for ephemeral instructions. Separately, stop_event() no longer lets later handlers continue and clear_result() no longer resets the stop state (#7900, #7922); any handler that relied on running after a stop will no longer do so.

No breaking changes in this release.

  • Added background shell command execution with output redirection and timeout support, and added a timeout parameter to the Python tool. (#7835, #7953)
  • Added fallback_max_context_tokens, used when model metadata is missing and max_context_tokens is set to 0. (#7942)

  • Added temporary extra_user_content_parts; plugins can use TextPart(...).mark_as_temp() to include content in the current LLM request without persisting it into conversation history. (#7976)

  • Improved the Dashboard extension, knowledge base, MCP, skills, and config pages with better layouts, card styles, responsiveness, translations, and skill-file editing in WebUI. (#7903)
  • Improved tool rendering in conversation history by grouping tool messages into the assistant tool card instead of rendering large tool results as normal Markdown bubbles. (#7937)
  • Improved context management and compression, including truncation behavior, user-message retention, PPIO context-length error detection, and clearer UI copy for execution order. (#7888, #7920)
  • Improved Provider model adding logic, model enable-toggle persistence, failed provider-test feedback, and startup warnings for missing or invalid default providers. (#7865, #7498, #7934)
  • Improved send_message_to_user prompts and tolerance in safety mode, cron proactive tasks, and incomplete session formats; cron payloads now include session information. (#7907, #7911)
  • Improved list+options config fields by switching to v-autocomplete and memoizing select items for better long-list selection. (#7884, #7885)
  • Improved truncated command and tool descriptions in WebUI by adding tooltip access. (#7838)
  • Improved metrics, log clarity, knowledge base docs, system prompt docs, and AGENTS.md pre-commit setup guidance. (#7838, #7962)

Bug Fixes

  • Fixed a security issue where normal users could ask send_message_to_user to send messages to arbitrary sessions; normal users are now restricted to the current session while admins can still target other sessions. (#7822, #7824)
  • Fixed T2I text template rendering by restoring raw text rendering, injecting Shiki runtime by default, and updating built-in templates and preview behavior. (#7789)
  • Fixed Enter key handling during IME composition in chat input. (#7845)
  • Fixed Anthropic parallel tool-result merging, custom headers, and system prompt compatibility by using default_headers and list-format system prompts. (#7875, #7587)

  • Fixed Shipyard Neo readiness gating and graceful sandbox cleanup. (#7881)
  • Fixed concurrent desktop plugin installation by protecting installs with the core lock. (#7872)
  • Fixed QQ Official private proactive push being skipped when cached msg_id is missing, while preserving group-message cache validation. (#7904, #7914)
  • Fixed WeChat kefu file messages and removed the WeCom file-message placeholder. (#7923)

  • Fixed the PowerShell install script BOM, deploy script paths, .gitignore, and public-directory sync issues.
