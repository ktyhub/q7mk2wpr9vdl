AstrBot v4.29.1

#AstrBot v4.29.1

2026 年 11 月 1 日に、< Python 3.12 バージョンのサポートを終了する予定です。Python バージョンがまだ 3.10、3.11 である場合は、適時に新しい Python バージョンに置き換えてください。
3.12 より前のバージョンの Python のサポートは 11 月 1 日に終了する予定です。現在 Python、3.10、または 3.11 を使用している場合は、新しいバージョンの Python にアップグレードしてください。

[4.29.1] - 2026-10-17

新しい

  • Web 検索: 「Web 検索」機能が追加されました [SerpApi 検索サービス] (https://serpapi.com/) (Google Web 検索、画像検索、学術検索、金融検索)、[DeepSeek 検索サービス] (https://api-docs.deepseek.com/zh-cn/guides/search/) (Web 検索、Web コンテンツ抽出)。 (#10599)
  • プラグイン開発: ローカライズされた subtitles 字幕メタデータをプラグインの単一選択/複数選択構成項目 (リスト型) に追加します。

修正

  • ‼ ️ コンピューターの使用: 一部の環境 (Docker コンテナー環境など) でローカル分離が利用できない場合、ローカル権限を保存できない問題を修正しました。 (#10584)
  • PC の使用: Windows でワークスペース全体のファイルの読み取り、書き込み、編集を復元し、ネイティブ ファイル ハンドル チェックによって再解析ポイントとハード リンク エイリアスを拒否します。 (#10584)
  • コア: 「セッション分離」機能をオンにすることによって発生する可能性のあるメモリ リークを修正します。メッセージ処理パイプラインを登録する前にグループ チャット セッションの分離を完了して、実行中のタスクと停止リクエストが正しいセッションを使用していることを確認します。 (#10581)
  • Telegram: メッセージを変換するときに非表示のリンクを保持します。 (#10557)
  • Discord: すべてのメンバーのメンションを修正しました。 (#10563)
  • WebUI: モバイル端末でプラグインビュー情報をクリックした直後にフローティングレイヤーが閉じてしまう問題を修正しました。 (#10562)
  • Edge TTS: リクエストの失敗を避けるために、ネイティブ クライアントのユーザー エージェントを保持します。 (#10588)
  • スキル: 単一のディレクトリ例外によってエージェント リクエスト全体が失敗することを避けるため、読み取り不可能なローカル ディレクトリとプラグイン スキル ディレクトリをスキップします。 (#10591)

追加

  • Web 検索: SerpApi (Google 検索、Google 画像検索、Google Scholar 検索、Google Finance 検索) および DeepSeek 検索 API (Web 検索およびページ コンテンツ抽出) を追加しました。 (#10599)
  • プラグイン開発: プラグインの単一選択/複数選択構成オプション (タイプ「リスト」) にローカライズされた字幕メタデータを追加しました。

修正済み

  • ‼ ️ コンピューターの使用: Windows でのワークスペース スコープのファイルの読み取り、書き込み、編集が復元されました。ネイティブ ハンドル チェックでは、再解析ポイントとハードリンク エイリアスが拒否されます。 (#10584)
  • コンピューターの使用: 分離が利用できない場合のローカル権限の保存を修正しました。ファイル アクセスは引き続き構成可能です。利用できない分離を必要とする実行は、ツールの実行時にブロックされます。デフォルトでは、メンバーには実行なしでワークスペース ファイルへのアクセスが許可され、管理者にはネットワークを使用して環境全体の実行が許可されます。すべてのアクセスが無効になっている従来の Windows メンバー ポリシーは、元のものが保存されていないために手動で同一に無効になったポリシーを含め、ワークスペース ファイル アクセスに一度移行されます。その後の選択肢は変更されません。 (#10584)
  • コア: 「セッション分離」機能が有効になっている場合に発生する可能性のある潜在的なメモリ リークを修正しました。グループ チャット セッションの分離は、メッセージ処理パイプラインを登録する前に実行されるようになり、進行中のタスクと終了リクエストの両方で正しいセッションが使用されるようになります。 (#10581)
  • Telegram: メッセージの変換時に隠しリンクが保持されます。 (#10557)
  • Discord: 全員のメンションを修正しました。 (#10563)
  • WebUI: モバイルでタップするとプラグイン表示情報のポップオーバーが開きます。 (#10562)
  • Edge TTS: リクエストの失敗を回避するために、ネイティブ client ユーザー エージェントを保持しました。 (#10588)
  • スキル: エージェントのリクエスト全体を失敗させる代わりに、読み取り不可能なローカルおよびプラグインのスキル ディレクトリをスキップしました。 (#10591)

AstrBot v4.29.1

Highlights

  • Web search adds SerpApi and DeepSeek — The search stack gains two providers: SerpApi (Google Web, Images, Scholar, Finance) and DeepSeek Search, which does both web search and page-content extraction (#10599, #10601). Practically, you get more provider choice without changing your search plumbing, and DeepSeek's extraction lets you skip a separate fetch step when you need page text.

  • Python 3.12 becomes mandatory on 2026-11-01 — Support for Python 3.10/3.11 ends then. This patch still runs on older interpreters, but if your deployment is pinned to 3.10 or 3.11, schedule the interpreter upgrade before that date or you'll be stuck on 4.29.x.

  • Computer Use on Windows is back, with new permission defaults — Workspace-scoped file read/write/edit is restored, now guarded by native handle checks that reject reparse points and hardlink aliases (#10584). Watch the policy migration: members default to workspace file access without execution, admins get full-environment execution with networking, and legacy "all access disabled" member policies are migrated once to workspace file access — including ones manually disabled, since their origin wasn't recorded. Audit your Computer Use policies after upgrading.

  • Session isolation fix closes a leak and a correctness bug — Group-chat session isolation now runs before the message-processing pipeline is registered, so in-flight tasks and stop requests resolve against the correct session (#10581). If you run multi-group bots with "session isolation" enabled, this removes cross-session bleed and a potential memory leak.

  • Agent reliability and channel-level polish — Unreadable local/plugin skill directories are now skipped instead of failing the entire agent turn (#10591); Telegram hidden links are preserved when converting messages (#10557), Discord @everyone mentions are corrected (#10563), Edge TTS keeps its native User-Agent to avoid request failures (#10588), and WebUI plugin info popovers stay open on mobile (#10562). Plugin authors also get localized subtitles metadata for list-type single/multi-select config options.

No breaking changes in this patch.

我们计划于 2026 年 11 月 1 日停止支持对 < Python 3.12 版本的支持。如果您的 Python 版本仍然是 3.10, 3.11，请及时更换新的 Python 版本。
We plan to end support for Python versions prior to 3.12 on November 1st. If you are currently using Python 3.10 or 3.11, please upgrade to a newer version of Python.

[4.29.1] - 2026-10-17

新增

  • 网页搜索：“网页搜索” 能力新增 SerpApi 搜索服务 (Google 网页搜索、图片搜索、学术搜索、财经搜索)、DeepSeek 搜索服务（网页搜索、网页内容提取）。 (#10599)
  • 插件开发：为插件的单选/多选配置项（list 类型）添加本地化的 subtitles 副标题元数据。

修复

  • ‼️ 电脑使用：修复部分环境（如 Docker 容器环境）下，本地隔离不可用时，无法保存 Local 权限的问题。(#10584)
  • 电脑使用：恢复 Windows 下工作区范围内的文件读取、写入和编辑，通过原生文件句柄检查拒绝重解析点和硬链接别名。 (#10584)
  • Core：修复开启 “会话隔离” 功能后可能造成的内存泄漏。在注册消息处理流水线之前完成群聊会话隔离，确保运行中的任务及停止请求使用正确的会话。 (#10581)
  • Telegram：转换消息时保留隐藏链接。 (#10557)
  • Discord：修复全体成员提及。 (#10563)
  • WebUI：修复移动端点击插件视图信息后浮层立即关闭的问题。 (#10562)
  • Edge TTS：保留原生客户端的 User-Agent，避免请求失败。 (#10588)
  • Skills：跳过无法读取的本地及插件技能目录，避免单个目录异常导致整轮 Agent 请求失败。 (#10591)

Added

  • Web Search: Added SerpApi (Google Search, Google Image Search, Google Scholar Search and Google Finance Search) and DeepSeek Search API (web search and page content extraction). (#10599)
  • Plugin development: Added localized subtitle metadata for single-select/multi-select configuration options (of type 'list') in plugins.

Fixed

  • ‼️ Computer Use: Restored workspace-scoped file reading, writing, and editing on Windows. Native handle checks reject reparse points and hardlink aliases. (#10584)
  • Computer Use: Fixed saving Local permissions when isolation is unavailable. File access remains configurable; execution requiring unavailable isolation is blocked at tool execution. Defaults now give members workspace file access without execution, and administrators entire-environment execution with networking. Legacy Windows member policies with all access disabled migrate once to workspace file access, including identical manually disabled policies because their origin was not stored; later choices remain unchanged. (#10584)
  • Core: Fixed a potential memory leak that could occur when the "session isolation" feature is enabled. Group chat session isolation is now performed before registering the message-processing pipeline, ensuring that both ongoing tasks and termination requests utilize the correct session. (#10581)
  • Telegram: Preserved hidden links when converting messages. (#10557)
  • Discord: Corrected everyone mentions. (#10563)
  • WebUI: Kept plugin View information popovers open when tapped on mobile. (#10562)
  • Edge TTS: Preserved the native client User-Agent to avoid request failures. (#10588)
  • Skills: Skipped unreadable local and plugin skill directories instead of failing the entire agent request. (#10591)
