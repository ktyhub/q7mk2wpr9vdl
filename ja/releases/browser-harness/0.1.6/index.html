ブラウザハーネス v0.1.6

Browser Harness はブラウザのタスクを記録し、何時間ものエージェントの作業を短い検証可能なビデオに変換できるようになりました。 ビデオでは、実際のブラウザ フレーム、click、カーソル移動、および入力が使用され、簡潔な字幕、正直な間違いと修正の説明、検証された最終結果によって作品が凝縮されています。 ビデオ作成は Browser Harness に直接組み込まれています。別途のスキルやインストールは必要ありません。録音はデフォルトではオフのままですが、グローバルに有効にすることも、「これを録音してください」、「何をしたか見せてください」、「デモを作成してください」などのプロンプトを使用して個々のタスクに対して要求することもできます。

browser-harness v0.1.6

Highlights

  • Recording ships in-band, not as an add-on — Capture is built directly into Browser Harness; upgrading to v0.1.6 is the only adoption step, with no separate skill, package, or install to manage. That keeps the dependency surface flat, but it also couples recording behavior to this harness version — you can't swap the recorder out or upgrade it independently.

  • Off by default, with two opt-in paths — Existing automations see no behavioral, performance, or storage change until you enable capture. You can turn it on globally (always-on audit trail) or per task via natural-language prompts such as "record this," "show me what you did," or "make a demo." The prompt path is convenient but nondeterministic: for CI or scheduled jobs where capture must be reliable, prefer the global setting over relying on the agent recognizing intent.

  • The output is a verification artifact, not a raw screen recording — Clips are assembled from real browser frames plus clicks, cursor movement, and typing, then condensed with concise subtitles, explicit mistake-and-correction narration, and a "verified final outcome." That gives developers a reviewable trace of what the agent actually did — useful for debugging failures, producing QA evidence, and generating demos — but the condensation is lossy and "verified" is the harness's own judgment, so treat these as summaries rather than complete, independently audited logs.

  • No migration work, but thin source detail — Nothing in the release notes indicates an API or config change, so there's nothing to migrate. The upstream tag is a single commit (6d0ac16) with no PR-by-PR breakdown or published PR numbers, so if you need to assess internals or compatibility risk you'll have to diff the tag yourself rather than lean on the changelog.

  • Watch the privacy/cost trade-off of global enablement — Because recordings capture real page frames and input events, switching capture on globally means every task's on-screen content — potentially including sensitive data — is retained as video. Start with per-task opt-in and only flip the global switch once you have a retention and redaction policy in place.

  • Breaking changes — None reported in this release.

Browser Harness can now record browser tasks and turn hours of agent work into short, verifiable videos.

The videos use real browser frames, clicks, cursor movement, and typing—then condense the work with concise subtitles, honest mistake-and-correction explanations, and a verified final outcome.

Video creation is built directly into Browser Harness. No separate skill or installation is required. Recordings remain off by default and can be enabled globally or requested for an individual task with prompts like “record this,” “show me what you did,” or “make a demo.”
