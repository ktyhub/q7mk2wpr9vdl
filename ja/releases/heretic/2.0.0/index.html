heretic v2.0.0

#異端児v2.0.0

重大な変更

Heretic 2.0 は、下位互換性を破壊するメジャー リリースです。

  • Heretic 1.x 用に作成された設定ファイルは、Heretic 2.0 と互換性がありません。古い構成を機能させるために変更する必要があるものについては、移行ガイド を参照してください。
  • 研究機能は削除されました。代替品はロフィウスです。

変更点

  • 修正: https://github.com/p-e-w/heretic/pull/385 で @kali113 によってトライアルを追加する際の合計トライアル数が修正されました。
  • 特技: https://github.com/p-e-w/heretic/pull/387 の @rocker-zhang により、オプティマイザーが 0 max_weight フロアを介して MLP アブレーションを無効にします
  • 修正: https://github.com/p-e-w/heretic/pull/389 の @umran666 によるモデル評価中に Windows で UnicodeEncodeError を解決しました。

heretic v2.0.0

Breaking Changes

Heretic 2.0 is a major release that breaks backwards compatibility:

  • Configuration files made for Heretic 1.x are not compatible with Heretic 2.0! See the migration guide for what you need to change in order to make your old configurations work.
  • Research features have been removed. The intended replacement is Lophius.
