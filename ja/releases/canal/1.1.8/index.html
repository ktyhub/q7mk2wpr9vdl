canal 1.1.8

パッチ 公開日2025年1月16日 出典alibaba/canal English original

#運河運河-1.1.8

新機能

  • MySQL 8.4、Maridb 11、Percona 8.0、PolarDB-X 2.0 #4940 #5231 #5012 のバージョンに適応
  • clickhouse アダプター #4957 を追加
  • PolarDB-X の集中分散統合バージョンの binlog 解析に深く適応し、polarbx-parse #5097 の SQL 解析ツールキットを再利用します。
  • ヘルム チャートのサポートを追加、使用説明書

重要な最適化

  • 運河のデフォルト admin.passwd リスク説明 #4941
  • Spring がリモート構成ファイルを読み取り、RCE 脆弱性 #5154 をトリガーします
  • SSL/TLS プロトコル リンク ソース MySQL ライブラリ #5147 をサポート
  • caching_sha2_password パスワード ポリシー #5301 をサポート
  • Rabbitmq SSL プロトコル認証 #4965 をサポート
  • es8 証明書認証 #5106 をサポート
  • パルサー #5191 のより多くのパラメーター属性をサポート

小さな要件とバグ修正

  • 無駄な高い権限を回避するために docker の起動を修正 #5337
  • MariaDB と互換性あり GTID は空です #5352
  • クラスター モードでの client のメモリ オーバーフロー リスクを最適化 #5290
  • zk がセッション タイムアウトになった場合に複数のコンシューマーを回避するためにクラスター モードでの mq の消費を修正 #5270
  • CanalMsgConsumer を共有するために同じインスタンスを持つ複数のグループを構成する client アダプターを修正し、同時実行の問題が発生しました #5175
  • RCE 脆弱性 #5154 を引き起こすリモート設定ファイルの読み取りスプリングを修正
  • json 形式の解析失敗の問題をいくつか修正 #5130 #5018
  • TableMetaTSDB で発生した DDL キーワード解析エラーを修正 #4899

canal canal-1.1.8

Highlights

  • Broader database support — Adds compatibility for MySQL 8.4, MariaDB 11, Percona 8.0, and PolarDB-X 2.0 (#4940, #5231, #5012), plus deeper binlog parsing for PolarDB-X’s integrated edition through polardbx-parse (#5097). Empty MariaDB GTIDs are also handled (#5352), avoiding replication failures in affected clusters.
  • ClickHouse and Kubernetes — The new ClickHouse adapter (#4957) adds a CDC path to ClickHouse, while the Helm chart standardizes Kubernetes deployment. Docker startup also removes unnecessary elevated privileges (#5337); review chart defaults and container permissions before migrating.
  • Security fixes — Prioritize #5154, which fixes an RCE vulnerability involving Spring remote configuration, and #4941, which highlights risks around the default admin.passwd. Upgrade and replace default credentials, especially if Canal loads configuration from remote sources.
  • Secure source and sink connections — MySQL source TLS (#5147), caching_sha2_password support (#5301), RabbitMQ SSL authentication (#4965), Elasticsearch 8 certificate authentication (#5106), and expanded Pulsar properties (#5191) enable encrypted, authenticated pipelines. Validate certificates and MySQL auth/TLS settings when updating configurations.
  • Cluster and parsing reliability — Fixes reduce cluster-client OOM risk (#5290), prevent duplicate MQ consumers after ZooKeeper session timeouts (#5270), and resolve cross-group concurrency caused by a shared CanalMsgConsumer (#5175). JSON parsing (#5130, #5018) and TableMetaTSDB DDL-keyword handling (#4899) are also more robust.
  • Breaking changes — None are listed in this release.

功能新增

  • 适配MySQL 8.4、Mariadb 11、Percona 8.0、PolarDB-X 2.0的版本 #4940 #5231 #5012
  • 新增clickhouse的adapter #4957
  • 深度适配PolarDB-X集中分布式一体化版的binlog解析，复用polardbx-parse的SQL解析工具包 #5097
  • 新增helm chart支持，使用说明

重要优化

  • canal默认admin.passwd风险说明 #4941
  • spring读取远程配置文件触发RCE漏洞 #5154
  • 支持SSL/TLS协议链接源端MySQL库 #5147
  • 支持caching_sha2_password密码策略 #5301
  • 支持rabbitmq SSL协议认证 #4965
  • 支持es8证书认证 #5106
  • 支持pulsar更多参数属性 #5191

小需求&bugfix

  • 修复docker启动，避免无用的高权限 #5337
  • 兼容MariaDB GTID 为空的情况 #5352
  • 优化集群模式的client的内存溢出风险 #5290
  • 修复集群模式的mq消费，避免zk出现session time out时出现多消费者 #5270
  • 修复client adapter同个instance配置多个group会共享CanalMsgConsumer，导致出现并发问题 #5175
  • 修复spring读取远程配置文件触发RCE漏洞 #5154
  • 修复部分json格式解析失败问题 #5130 #5018
  • 修复TableMetaTSDB遇到的DDL关键字解析失败 #4899
