#モビーdocker-v29.9.1

29.9.1

このリリースのプル リクエストと変更の完全なリストについては、関連する GitHub マイルストーンを参照してください。

  • docker/cli、29.9.1 マイルストーン
  • moby/moby、29.9.1マイルストーン

セキュリティ

v2.4.2 へのcontainerd アップデートには、次のセキュリティ脆弱性の修正が含まれています。

  • CVE-2026-95839: 子記述子に io.containerd.manifest.subject アノテーションと不正な形式のダイジェストが含まれている場合、containerd の転送サービスを通じてイメージをプルまたはインポートすると、containerd がクラッシュする可能性がありました。
  • GHSA-8647-2jxj-p2rc: concurrent_layer_fetch_buffer で並列レイヤーのフェッチが有効になっている場合、細工された Content-Length ヘッダーを返す untrusted レジストリにより、containerd がクラッシュする可能性がありました。
  • GHSA-hc94-p972-ch66:containerd が検証前に受信レイヤー データを宣言されたサイズに制限しなかったため、細工されたイメージをプルしたり、悪意のあるレジストリからプルしたりすると、ホストのディスク領域を使い果たす可能性があります。

バグ修正と機能強化

  • コンテナーを作成するとき、またはコンテナーをネットワークに接続するときに、リンクローカルではないアドレス (169.254.0.0/16 または fe80::/10) を受け入れる --link-local-ip が原因でコンテナーの起動に失敗する問題を修正しました。 モビー/モビー#53923
  • userns-remap が有効な場合、root が所有していないファイルに対してクラシック ビルダーで失敗する COPY --from を修正しました。 モビー/モビー#53859
  • 1 つのコンテナのサイズを計算できない場合、docker ps -s とサイズを含むコンテナのリストが完全に失敗する問題を修正しました。 モビー/モビー#53921
  • イメージに同じレイヤーが複数回含まれている場合に、イメージが削除された後、イメージ レイヤーがディスク上に残る docker save を修正しました (グラフ ドライバー イメージ ストア)。 白鯨/白鯨#53927
  • 接続できない TLS アドレスで fluentd-async が有効になっている fluentd ログ ドライバーを使用する場合のデーモン パニックを修正しました。 モビー/モビー#53922
  • レジストリ ミラーリングは成功したが、後続のレジストリ ルックアップが失敗した場合に失敗するイメージ ダイジェスト解決を修正しました。 モビー/モビー#53933
  • プラグインの取得が失敗した場合に、プラグイン権限の検索が成功を報告する問題を修正しました。 白鯨/白鯨#53934

パッケージの更新

-containerd (静的バイナリ) を v2.4.2 に更新します。 白鯨/白鯨#53936

ネットワーキング

  • iptables と ip6tables が両方とも無効になっている場合は、firewalld の docker ゾーンにブリッジ ネットワーク インターフェイスを追加しないでください。 モビー/モビー#53907
  • ブリッジが docker 以外の firewalld ゾーンにバインドされている場合、ブリッジ ネットワークがデーモン起動時に復元できない問題を修正しました。 モビー/モビー#53907

根無し草

  • ユーザー名前空間とルートレス モードでの --domainname を修正しました。これには、domainname フィールド (runc >= v1.2.0 など) をサポートする OCI ランタイムが必要です。 モビー/モビー#53899
  • RootlessKit を v3.3.0 に更新します。 白鯨/白鯨#53942

moby docker-v29.9.1

29.9.1

For a full list of pull requests and changes in this release, refer to the relevant GitHub milestones:

  • docker/cli, 29.9.1 milestone
  • moby/moby, 29.9.1 milestone

Security

The containerd update to v2.4.2 includes fixes for the following security vulnerabilities:

  • CVE-2026-95839: Pulling or importing an image through containerd's transfer service could crash containerd if a child descriptor contained the io.containerd.manifest.subject annotation and a malformed digest.
  • GHSA-8647-2jxj-p2rc: An untrusted registry returning a crafted Content-Length header could crash containerd when parallel layer fetching was enabled with concurrent_layer_fetch_buffer.
  • GHSA-hc94-p972-ch66: Pulling a crafted image or pulling from a malicious registry could exhaust host disk space because containerd did not limit incoming layer data to the declared size before validation.

Bug fixes and enhancements

  • Fix --link-local-ip accepting addresses that are not link-local (169.254.0.0/16 or fe80::/10) when creating a container or connecting it to a network, which made the container fail to start. moby/moby#53923
  • Fix COPY --from in the classic builder failing for files not owned by root when userns-remap is enabled. moby/moby#53859
  • Fix docker ps -s and container listing with sizes failing entirely when the size of one container cannot be computed. moby/moby#53921
  • Fix docker save leaving image layers on disk after the image is removed, when the image contains the same layer more than once (graph-driver image store). moby/moby#53927
  • Fix a daemon panic when using the fluentd log driver with a TLS address that cannot be connected to and fluentd-async enabled. moby/moby#53922
  • Fix image digest resolution failing when a registry mirror succeeds but a subsequent registry lookup fails. moby/moby#53933
  • Fix plugin privilege lookup reporting success when fetching the plugin fails. moby/moby#53934

Packaging updates

  • Update containerd (static binaries) to v2.4.2. moby/moby#53936

Networking

  • Don't add bridge network interfaces to firewalld's docker zone when iptables and ip6tables are both disabled. moby/moby#53907
  • Fix bridge networks failing to restore on daemon startup when their bridge is bound to a firewalld zone other than docker. moby/moby#53907

Rootless

  • Fix --domainname with user namespaces and rootless mode; this requires an OCI runtime supporting the domainname field (such as runc >= v1.2.0). moby/moby#53899
  • Update RootlessKit to v3.3.0. moby/moby#53942
