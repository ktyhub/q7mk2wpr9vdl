#オープンクローv2026.10.6

2026.10.6

ハイライト

  • パッチ適用されたノード ランタイムが必要: OpenClaw では、24 行のノード 24.22.1+ または 26 行の 26.12.1+ が必要になりました。これらは、2026 年 10 月の Node.js セキュリティ リリースで対処された侵害された証明書キーで署名された TLS チェーンを拒否します。 Docker イメージはノード 24.22.1 を出荷し、インストーラはパッチ適用されたランタイムを選択します。openclaw update は、実行中のインストールを中断するのではなく、古いノードにインストールする前にリカバリ ガイダンスを表示して拒否します。ソースは pnpm 12.15.0 をピンでビルドするようになりました。 (#179992) @joshavant に感謝します。
  • より安全な更新と回復: パッケージ スワップは安全でないサービス状態を拒否するようになり、Windows および macOS のパッケージ マネージャーの更新はプラットフォーム固有の障害から回復し、フリーズした Gateway スタートアップの所有者を完全に廃止できるようになりました。 (#171101、#170940、#171936、#171678) @RomneyDa、@homeworld520、@Yolo521-bot、@stop-time、@AntaresGG、@TommyLei666 に感謝します。
  • データを保持する移行とバックアップ: ドクターおよび移行パスは、不正な形式または損失のあるワークスペースのインポートを拒否し、不正な形式の Notes バイトを保持し、安全でない非 UTF-8 Wiki の書き換えを拒否し、深くネストされた SQLite バックアップを保持し、復元検査が失敗した場合のステージング証拠を保持するようになりました。 (#172293、#172953、#172742、#174573、#168583、#170867、#172028) @wangmiao0668000666、@RomneyDa、@Leon-SK668、@ericcurtin、@Yolo521-bot、@obviyus に感謝します。 @altaywtf
  • 再起動後の信頼性の高い配信: キューに入れられたターン、監視された子の結果、配信不能配信、およびストリーミングされた返信が、消失、重複、または誤った不在回答通知を生成することなく、回復後も存続するようになりました。 (#170384、#169489、#169932、#173798) @RomneyDa、@huyengiang101086-spec、@Yolo521-bot に感謝します。
  • プロバイダーとモデルの復元力: GPT-5.6 ツールの回転、OpenRouter DeepSeek ツールの呼び出し、LM Studio オーバーフロー回復、並列 OpenAI 推論設定、およびモデルの再試行/フォールバック バジェットが一貫して動作するようになりました。 (#176709、#175058、#169189、#169322、#164808) @RomneyDa、@Linux2010、@ZhimingQ、@xpeng5278-web、@anyech に感謝します。
  • Windows とモバイルの安定性: 新しい Windows 状態ストア、プロキシベースの環境、および保存された Anthropic 資格情報により起動がブロックされなくなり、iOS トークおよびチャット接続は最初の応答およびタイムアウトの失敗から回復します。 (#176174、#176194、#174571、#168416、#169912) @RomneyDa、@tjarrau-dev、@skyzhao1223、@easyTeacher、@scalesmart、@masatohoshino、@Takhoffman、@Solvely-Colin に感謝します。
  • エージェントとツール呼び出しの回復: 未完了のツールが目に見えてタイムアウトになり、操作されたツールの結果後にコンテキスト オーバーフローが圧縮され、以前の拒否後に不正な呼び出しが継続され、大きなパッチ ハンクにより引数制限のクラッシュが回避され、停止されたタスクは停止されたままになります。 (#172983、#172019、#170615、#174477、#169453) @RomneyDa、@budzation、@mirasrael、@r3n3x、@freeqaz-openai、@obviyus に感謝します。
