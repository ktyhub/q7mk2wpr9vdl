openclaw v2026.10.33

パッチ 公開日2026年11月18日 出典openclaw/openclaw English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#オープンクローv2026.10.33 これはゲートウェイ専用の extended-stable リリースであり、現在の LTS に相当します。このリリースは、2026 年 10 月末の OpenClaw に、重要なセキュリティ アップデート、信頼性とパフォーマンスの修正、新モデルのサポートなどの機能が追加されたものです。このリリース時点での OpenClaw の最新バージョンは 2026.11.5 です。

2026.10.33

この拡張安定リリースでは、2026.9.37 以降のゲートウェイとコア プラグインの累積的な改善に加え、承認された 2026.11.4 製品ベースラインに対する選択されたメンテナンス修正が行われます。ディストリビューションには、コア npm パッケージ、対応する公式 npm プラグイン、およびゲートウェイ Docker イメージが含まれます。ネイティブアプリのリリースは含まれません。

ハイライト

  • 長時間の会話と大規模なセッション ストアでは、制限されたエクスポートと回復作業が使用され、チャット、メモリ エクスポート、Doctor 修復、およびゲートウェイ起動時のメモリ不足エラーが軽減されます。 (#194066、#196158、#195459、#196480、#176737、#181289) @sreipete によって作成されました。 @RomneyDa、@vincentkoc、@ericcaiwx-star、@obviyus、@garrytan、@oxen-horse に感謝します。
  • 中断された更新は、実行プログラムが停止すると、ゲートウェイがオフラインのままになるのではなく回復します。一方、バージョン スキュー チェックは、インストールされているサービスによってまだ使用されている状態を保護します。 (#181695、#186971、#187819) @sreipete によって作成されました。 @RomneyDa、@PonySlayer28、@tomdailey55、@jalehman、@fuller-stack-dev、@vincentkoc に感謝します。
  • 返信は、より多くの再起動および再接続パスに耐え、元のプロンプトを保持し、Telegram 応答を回復し、WhatsApp 返信の損失や Signal メッセージのスキップを回避します。 (#187157、#195400、#168778、#187667) @shakkernerd、@jason-allen-oneal、@mcaxtr、@HermanZeng、@obviyus に感謝します。
  • 共有セッションのプライバシーが強化されます。サイド チャットは閲覧者に対してプライベートなままであり、内部モデル プロンプトは表示出力に含まれず、圧縮により引用された概要内の資格情報が秘匿化されます。 (#185390、#173460、#197349) @sreipete によって作成されました。 @Satoshi-Kusumoto、@RomneyDa、@zhangguiping-xydt、@Patrick-Erichsen、@obviyus に感謝します。
  • オートメーションは、ポーリングされた条件と MCP イベントに反応し、反復可能なスクリプトを実行し、明示的に許可された MCP サーバーを使用できます。 (#101195、#165399、#160996、#160995) @sreipete によって作成されました。ありがとう@obviyus。
  • インストールされているスキルをオンデマンドで検索して読み取ることができるため、エージェントはインストールされているすべてのスキルをプロンプトに入力しなくても、関連する指示を見つけることができます。 (#158089、#158090、#158091、#160538) @sreipete によって作成されました。 @RomneyDa と @vincentkoc に感謝します。
  • セッションは、既存のクロード コードまたはコーデックスのトランスクリプトをインポートし、リポジトリ レシピとより明確なクラウド起動の進行状況を使用して、ローカル環境とクラウド環境の間を移動できます。 (#161955、#171690、#170862、#170895) @sreipete によって作成されました。 @joshavant と @RomneyDa に感謝します。

追加のメンテナンス修正

  • プロバイダーの継続性: 同じプロバイダー API およびエンドポイントでの資格情報またはモデルの変更にわたってサーバー圧縮チェックポイントを保持し、不要な履歴の再生を回避します。 (#200063、#200208) @obviyus に感謝します。
  • macOS インストール: シェルのインストール中に制御ターミナルを保持するため、オンボードで切り離されたノードのサブプロセスが中止されることなくプラグインをインストールできます。 (#200247) @miguelbranco80 に感謝します。
  • 更新リカバリ: 起動前に行われた変更を受け入れずに、次回の Doctor 実行のために成功した Gateway 起動書き込みを記録します。 (#200260) @RomneyDa に感謝します。
  • 既存のデバイス フォルダー: デフォルトを明示的なセッション オーバーライドにせずに、暗黙的な OpenClaw ランタイムを使用してモデルを認識します。 (#190065) @obviyus に感謝します。
  • プラグインの互換性: 表示されるバージョンを変更したり、プラグイン API の要件を下げたりすることなく、署名付き 2026.11.4 ソース ベースラインをこのリリースの互換性アイデンティティとして保持します。 (#200302) @RomneyDa に感謝します。

修正

  • 更新の回復: 更新実行プログラムが停止した後、オフライン メンテナンスを再利用して、データベースを手動で修復しなくてもゲートウェイを再起動できるようにします。 (#181695) @sreipete によって作成されました。 @RomneyDa と @PonySlayer28 に感謝します。
  • 互換性の更新: 時期尚早の状態移行を回避し、無関係または古いインストール済みサービスが有効な構成や Doctor 操作をブロックしないようにし、長いファイナライズ中にプラグインのライフサイクル所有権を保持します。 (#186971、#187870、#187886、#187966、#190194、#196474、#188404) @sreipete によって作成されました。 @RomneyDa、@vincentkoc、@tomdailey55、@shakkernerd、@Satoshi-Kusumoto に感謝します。
  • インストール診断: Homebrew ブートストラップが失敗すると明らかに失敗し、プライベート CLI インストール パスでシェル文字を処理し、npm-shim インストール後に Windows セットアップを開始し、システムの一時ディレクトリが安全でない場合はプライベート ワークスペースを使用します。 (#187688、#189541、#185309、#187737) @sreipete によって作成されました。 @RomneyDa、@vincentkoc、@McgAtom、@obviyus、@DonnieFi、@Yachiyo1680 に感謝します。
  • 大きな履歴: バインドされたトランスクリプトのトリミング、インデックス作成、メモリ エクスポート、およびドクター修復により、ワーカーまたはゲートウェイのメモリの消耗を回避します。 (#194066、#196158、#195459、#196480) @sreipete によって作成されました。 @RomneyDa、@vincentkoc、@ericcaiwx-star、@obviyus、@garrytan に感謝します。
  • 起動の応答性: 狭いセッションの回復読み取りを行い、大規模なセッション ストアでのプラグインの起動の遅延を回避します。 (#176737、#181289) @sreipete によって作成されました。ありがとう@oxen-horse。
  • 永続的な状態: PostgreSQL コミットの耐久性を保持し、物理的なコミット時に段階的権限を解決し、データベース接続が失われた後にチャットを回復します。 (#180821、#193842、#181661) @sreipete によって作成されました。 @joshavant、@RomneyDa、@vincentkoc に感謝します。
  • ファイル: ワークスペースが置き換えられた後、間違ったワークスペース状態に書き込むのではなく、古い保存を拒否します。 (#178336) @sreipete によって作成されました。 @RomneyDa と @shakkernerd に感謝します。
  • 共有セッションのプライバシー: 別の視聴者のサイド チャットやプライベート モデル プロンプトの投影が表示されたコンテンツに含まれないようにします。 (#185390、#173460) @sreipete によって作成されました。 @Patrick-Erichsen と @obviyus に感謝します。
  • シークレット: 引用符で囲まれた圧縮出力内の資格情報を編集し、スキル ページのキー保存で SecretRef がプレーンテキストに置き換えられないようにします。 (#197349、#197319) @sreipete によって作成されました。 @obviyus と @mmaps に感謝します。
  • 構成の安全性: 予約された割り当てキーを拒否し、フィルタリング後に制限的なホワイトリストを保持し、大文字と小文字が混在するプラグインを無効のままにし、保存された SecretRef の横にあるカタログのインポートを回避します。 (#191389、#190068、#188846、#179802) @sreipete によって作成されました。 @RomneyDa、@obviyus、@vincentkoc、@wangmiao0668000666、@yetval、@masatohoshino、@ensignwesley に感謝します。
  • ツール権限: 委任された変更に対して効果的な承認を要求し、入力ポリシー フックを通じて準備されたイメージをチェックし、遅延または曖昧な機能スコープの添付リクエストを拒否します。 (#196984、#196337、#159106、#190863) @sreipete によって作成されました。 @joshavant、@montrellcruse、@RomneyDa、@vincentkoc、@sallyom、@arpe1618 に感謝します。
  • サンドボックスのアップグレード: ネストされたスキルマウントの書き込み可能な祖先を保護し、最初の起動時に保護されたマウントソースを準備し、マウントの追加後にターンを再開します。 (#180840、#182412、#182789) @sreipete によって作成されました。 @RomneyDa、@eleqtrizit、@momothemage、@akang1798 に感謝します。
  • リポジトリと取り込みの境界: 限られた役割をパブリック リポジトリに制限し、メモリ Wiki の取り込み中に特殊ファイルを拒否します。 (#194830、#187621) @vyctorbrzezowski、@Leon-SK668、@obviyus に感謝します。

  • クラウドの準備: プライベート QA ビルドを正しくブートストラップし、新しいゲスト PR の準備中に保存されていない作業を誤って報告することを回避します。 (#181824、#185777) @sreipete によって作成されました。 @RomneyDa と @shakkernerd に感謝します。
  • ドクターとリカバリ: 競合する従来の実行承認による起動をサポートし、フルディスク上の読み取り専用データベースコピーを回避し、不完全なデータベースポートの成功を拒否し、インポートするものが何も残っていない場合に欠落しているサニタイズされた構成コンパニオンをスキップします。 (#196401、#196346、#194595、#186998) @sreipete によって作成されました。 @RomneyDa、@vincentkoc、@fuller-stack-dev、@ylcn91、@reisball、@AlyaKoni に感謝します。
  • ワークスペースの準備: サンドボックスで作成されたファイルをゲートウェイの準備と間違えず、シャットダウンが失敗した場合でもコマンドの結果を保存します。 (#197248、#188891) @sreipete によって作成されました。 @RomneyDa、@masatohoshin、@obviyus、@mmaps に感謝します。
  • セッション ナビゲーション: タッチ リンクを行アクションから遠ざけ、Doctor 修復によってメイン セッションの名前が内部ハートビート マーカーに変更されるのを防ぎます。 (#194840、#179219) @sreipete によって作成されました。 @VACInc、@Satoshi-Kusumoto、@RomneyDa、@najef1979-code、および @vyctorbrzezowski に感謝します。
  • レスキュー コマンド: コマンドがゼロ以外で終了した場合でも、応答が失われるのではなく、有用な診断結果が保持されます。 (#195451) @sreipete によって作成されました。 @wr-web と @mdarapour に感謝します。

openclaw v2026.10.33

This is a gateway-only extended-stable release, which is our current equivalent to LTS. This release is OpenClaw from the end of October 2026, plus critical security updates, reliability and performance fixes, and features like new model support. The latest version of OpenClaw at the time of this release is 2026.11.5

2026.10.33

This extended-stable release brings cumulative Gateway and core-plugin improvements since 2026.9.37, plus the selected maintenance fixes on the approved 2026.11.4 product baseline. Distribution covers the core npm package, matching official npm plugins, and Gateway Docker images; native-app releases are not included.

Highlights

  • Long conversations and large session stores use bounded export and recovery work, reducing out-of-memory failures during chat, memory export, Doctor repair, and Gateway startup. (#194066, #196158, #195459, #196480, #176737, #181289) Authored by @steipete. Thanks @RomneyDa, @vincentkoc, @ericcaiwx-star, @obviyus, @garrytan, and @oxen-horse.
  • Interrupted updates recover when their executor dies instead of leaving the Gateway stuck offline, while version-skew checks protect state still used by an installed service. (#181695, #186971, #187819) Authored by @steipete. Thanks @RomneyDa, @PonySlayer28, @tomdailey55, @jalehman, @fuller-stack-dev, and @vincentkoc.
  • Replies survive more restart and reconnect paths, preserving original prompts, recovering Telegram responses, and avoiding lost WhatsApp replies or skipped Signal messages. (#187157, #195400, #168778, #187667) Thanks @shakkernerd, @jason-allen-oneal, @mcaxtr, @HermanZeng, and @obviyus.
  • Shared-session privacy is stronger: Side chat stays private to its viewer, internal model prompts stay out of displayed output, and compaction redacts credentials in quoted summaries. (#185390, #173460, #197349) Authored by @steipete. Thanks @Satoshi-Kusumoto, @RomneyDa, @zhangguiping-xydt, @Patrick-Erichsen, and @obviyus.
  • Automations can react to polled conditions and MCP events, run repeatable scripts, and use explicitly allowed MCP servers. (#101195, #165399, #160996, #160995) Authored by @steipete. Thanks @obviyus.
  • Installed skills can be searched and read on demand, helping agents find relevant instructions without putting every installed skill into the prompt. (#158089, #158090, #158091, #160538) Authored by @steipete. Thanks @RomneyDa and @vincentkoc.
  • Sessions can import existing Claude Code or Codex transcripts and move between local and cloud environments, with repository recipes and clearer cloud-startup progress. (#161955, #171690, #170862, #170895) Authored by @steipete. Thanks @joshavant and @RomneyDa.

Additional maintenance fixes

  • Provider continuity: preserve server compaction checkpoints across credential or model changes on the same provider API and endpoint, avoiding unnecessary history replay. (#200063, #200208) Thanks @obviyus.
  • macOS installation: preserve the controlling terminal during shell installation so onboarding can install plugins without detached Node subprocesses aborting. (#200247) Thanks @miguelbranco80.
  • Update recovery: record successful Gateway startup writes for the next Doctor run without accepting changes that predate startup. (#200260) Thanks @RomneyDa.
  • Existing device folders: recognize models using the implicit OpenClaw runtime without turning that default into an explicit session override. (#190065) Thanks @obviyus.
  • Plugin compatibility: retain the signed 2026.11.4 source baseline as this release's compatibility identity without changing its displayed version or lowering plugin API requirements. (#200302) Thanks @RomneyDa.

  • Session context: show task progress in Details, indicate when a chat is waiting on helpers, and open the Subagents panel from the chat's helper count. (#161674, #164190, #166142) Authored by @steipete. Thanks @RomneyDa, @ceckert, @obviyus, @vyctorbrzezowski, and @shakkernerd.
  • Shared conversations: add emoji reactions to prompts and replies and configure when sessions may send or receive messages. (#161053, #162316) Authored by @steipete.

  • Memory providers: use a provider-neutral memory runtime with host-resolved audiences and provider-owned pre-compaction flushes. (#162175, #162176, #162177) Authored by @steipete. Thanks @RomneyDa, @vincentkoc, and @jalehman.
