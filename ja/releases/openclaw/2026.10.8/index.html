#オープンクローv2026.10.8

2026.10.8

ハイライト

  • 終了して回復する更新: 通常の更新後の Doctor 障害では、ゲートウェイが停止したままになるのではなく再起動され、孤立したメンテナンス ワーカーがすべての CLI コマンドとゲートウェイの起動をブロックすることがなくなり、ACL ファイル システム、Windows pnpm オプション依存関係リンク、pnpm 10 グローバル インストール、デバッグ コンソール ログ、またはレガシー OAuth ディレクトリの欠落で更新が中断されることがなくなりました。 (#180668、#181695、#181141、#181596、#181456、#182850、#180174) @hannesrudolph、@SMF12138、@rayluo88、@PonySlayer28、@VN77-77VN に感謝します。
  • ゲートウェイ サービスはすべてのデスクトップにインストールされます: macOS は、plist が削除されたロードされた launchd 登録を回復します。Linux は、Ubuntu のデフォルト umask の下でインストールされ、拒否される代わりにプライベート状態ディレクトリを作成します。また、macOS アップデータは、Doctor が実行される前に、サービスを提供しているゲートウェイがデータベースを解放するのを待ちます。 (#180390、#179538、#182055) @avnishkirnalli と @XiaoPengYouCode に感謝します。
  • 会話はメッセージを受け入れ続けます: 強制終了された実行は再起動回復フェンスを解放し、中断された子セッションと受け入れられたばかりの子セッションはゲートウェイの再起動後に回復し、返信ランタイムが発行できない場合は受信メッセージの再試行が永久に停止され、コントロール UI の送信忘れによる再試行によりオーサリング エラーの代わりに返信が配信されます。 (#181992、#178888、#181871、#181300、#182219) @najef1979-code、@handcraftrc-pixel、@sukhdeepjohar、@teddashh に感謝します。
  • スタートアップとデータベースの回復力: スタートアップ作業は閉じられた SQLite リーダー スコープを継承しなくなり、モデル、チャット メタデータ、チャネル応答は利用可能なままになります。エージェントデータベース起動中の一時的なロック競合は再試行されます。モデル カタログはスキルの実行中も利用可能です。 (#182615、#182446、#182385)
  • セキュリティ強化: 実行許可リスト モードでは test -v オペランド展開の承認が必要で、汎用ノードの呼び出しはブラウザ プロキシ コマンドを拒否し、サンドボックス化されて生成された子はホスト CLI バックエンドを実行できません。秘密の出力プロキシは distrusted eMudhra チェーンを拒否し、Fish Audio および Gradium エラーは API キーを公開しなくなり、深くネストされた Tlon コンテンツはチャネルをストールできなくなります。 (#180880、#179880、#178742、#179249、#178877、#177536) @eleqtrizit と @joshavant に感謝します。
  • Windows exec とプラグイン: Store PowerShell がインストールされている間、agent exec は S4U スケジュールされたタスクの下で動作し、ネイティブ プラグインは Endpoint DLP を備えたマシンにロードされ、Doctor は別のファイル システム上の未解決の依存関係ジャンクションとプラグインを回復します。 (#182898、#179949、#179549、#179445) 修正 #182652 @RomneyDa、@tre1d、@coaiMax、@paulcam206、@JIRBOY、@ceckert に感謝します。
  • プロバイダーとモデルの継続性: Codex ターンは、サイレント フォールバックするのではなく、古いランタイム プラグインを使用して予算を維持します。Codex ネイティブの子推論は起動後に機能します。OpenAI OAuth は古いカタログで機能します。Anthropic PDF 分析はセットアップ トークン OAuth で機能します。タイムアウトした MCP セッションの終了が次のターンで失敗することはなくなり、CLI 履歴所有者の変更は別のプロバイダーでサイレントに再生するのではなく停止します。 (#182995、#176311、#181356、#178420、#182189、#180075) 修正 #181619 ありがとうございます @RomneyDa、@kip-claw、@enki、@sasan1200、@sunlit-deng、@khensthoth、@aniketkrs、@goslingmanagment、 @wr-web と @teddashh。
