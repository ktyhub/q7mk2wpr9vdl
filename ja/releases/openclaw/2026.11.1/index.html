#オープンクローv2026.11.1

2026.11.1

ハイライト

  • より安全な Mac 設定: 失敗した設定保存によってシークレットが上書きされなくなり、Tailscale 公開をオフにしてもゲートウェイ認証はそのまま維持されます。 (#187734、#187664) 修正 #187600、#187597 @anmol0b に感謝します。
  • より信頼性の高いチャネル応答: Telegram、Discord、および Webhook の会話は、リクエスト ハンドラーまたは以前のターンが終了した後もエージェントに届き続けます。 (#179200、#179385、#179704、#189457) 修正 #178554 @sreipete、@LiuwqGit、@jalehman、@vincentkoc に感謝します。
  • 会話はより多くの中断に耐えます: 特大のターンは有用な履歴を保持し、最初のクロード CLI ターンを停止しても次のメッセージが最初から開始されることはなくなりました。 (#191146、#181966、#186380) 修正 #191133、#181945 @Yun-0000、@obviyus、@mirasrael、@holgergruenhagen に感謝します。
  • アップデーターがクラッシュまたはキャンセルされた後に更新の回復が停止し、検証に失敗した後に Windows ゲートウェイを復元し、大規模な状態チェック中に繰り返される完全なデータベースのコピーを回避します。 (#177932、#186787、#189647、#182632、#187921) 修正 #177684、#184893、#189620 ありがとう @duyufansh2008、@RomneyDa、@fuller-stack-dev、@TheAngryPit、@sukhdeepjohar、@sreipete、 @syxscott、および @stephen3303。
  • サブエージェントはモデルとセッションの変更を通じてフォローアップを続けますが、親セッションはカスタム セッション ストアがあっても子の承認を受け取ります。 (#186238、#183501、#189827) 修正 #179289、#189823 @sreipete、@Marvinthebored、@RomneyDa、@ekinnee に感謝します。
  • 互換性のあるゲートウェイを使用した Android エンド トークは、受け入れられたエージェントの作業をキャンセルせずにリッスンを停止するため、応答は引き続きチャットに到着します。明示的なキャンセルは引き続き可能です。 (#172276、#188798) @RomneyDa に感謝します。
  • プロバイダーの回復はプロバイダー指定のレート制限タイミングを尊重し、Gemini Flash テキスト モデルは公式 API キー エンドポイントでデフォルトでインタラクションを使用しますが、カスタム プロキシは既存のデフォルトを保持します。 (#180280、#189395) ありがとう、Ayaan Zaidi、@evomach、@sukhdeepjohar、@RomneyDa。

変更点

  • クロード CLI: 保存されたサブスクリプション アカウントにより、個別のネイティブ ログインなしで構成されたモデルを利用できるようになり、オペレーターは plugins.entries.anthropic.config.managedNativeTools を通じてネイティブ エージェントとワークフロー オーケストレーションをオプトインできます。デフォルトはオフのままで、制限された実行では既存のツール制限が維持されます。 (#179203、#183765) @RomneyDa に感謝します。
  • Anthropic: API キーのセットアップでは、オプションの Anthropic ワークスペース ID を記録できます。既存のワークスペース ヘッダーは保持され、ワー​​クスペース スコープのキーには追加の設定は必要ありません。 (#186976) ありがとう、Ayaan Zaidi、@evomach、@sukhdeepjohar、@RomneyDa。
  • Google: インタラクション リクエストはマネージド プロキシと TLS 設定を尊重し、レート制限後のストリーミング前に対象となる API キーをローテーションし、ネイティブ ビデオ入力を保持し、一貫してニュークリアス サンプリングを転送します。明示的な Gemini キャッシュ ハンドルが必要な場合は、google-generative-ai を選択します。 (#189395、#190695) @RomneyDa に感謝します。
  • Bedrock Mantle: 発見された番号付き OpenAI GPT モデルは応答ルートを自動的に選択しますが、GPT-OSS はチャット完了を保持し、クロードは人為的メッセージを保持します。 @MertBasar0、@anmol0b、@shakkernerd、@kybrcore、@sukhdeepjohar、@potoior、@RomneyDa に感謝します。
  • コントロール UI: モデル ピッカーは、モデルの最大値だけではなく、設定されたアクティブ コンテキスト バジェットを表示し、短いセッション リンクは意図したナビゲーション ターゲットを保持します。 (#180870、#183148) @RomneyDa に感謝します。
  • Google Chat: リモート HTTP(S) 添付ファイルは、キャプションとともに表示されるリンクとして配信されます。ローカル ファイルとネイティブ アップロードは、サービス アカウント認証では引き続きサポートされません。ありがとう@RomneyDa。
  • 更新診断: 詳細な準備状況により、準備ができているコアとチャネルの停止が分離され、HTTP 503 を隠したり、通常のサービス開始チェックを弱めたりすることなく、修復されたアップデーターが名前付きチャネルの警告で終了できるようになります。 @duyufansh2008、@RomneyDa に感謝します。

修正

  • ネットワークとツールの安全性: ClickClack と ClawHub は無関係のプライベート サービスへのリダイレクトを拒否し、Discord CDN ダウンロードはブラウザーのプライベート ネットワーク アクセスを継承しなくなり、FIFO ネイティブ フックの資格情報はエージェントをハングせずに拒否されます。 (#190944、#190939、#191458、#191423) @pgondhi987、@SebTardif、@Leon-SK668 に感謝します。
  • 医師の同意とアクセス ポリシー: 非対話型チェックでは、修復の同意なしにプラグインがダウンロードされなくなり、明示的に空のグループ許可リストは再設定されずに空のままになります。 (#191523、#174787) 修正 #191420、#173826 @brandonulrich、@sreipete、@lockhartheavyindustries に感謝します。
  • リカバリ データ: 不正な形式の UTF-8 レガシー インポートは、元のコンテンツを置き換えるのではなく拒否されます。失敗したスキルの復元ロールバックでは元のコピーが保持され、ワー​​クスペース検査が失敗した場合はクリーンアップで破壊的な作業が拒否されます。 (#180861、#173954、#174195、#176362) #180782、#180795 を修正しました。@RomneyDa、@duyufansh2008、@sreipete、および @wangmiao0668000666 に感謝します。
  • ログ編集: 不正なカスタム エントリによって、有効なルールや組み込みの秘密保護が無効にならなくなりました。安全な編集がアクティブなままであるにもかかわらず、無効なポリシーが報告されます。 (#173471) @skyzhao1223 と @RomneyDa に感謝します。
  • シークレット出力: マネージド プロキシおよびエクスポートされたサブプロセス CA バンドル内の distrusted emSign ECC G3 ルートに依存するチェーンを拒否します。更新後にゲートウェイを再起動し、独立した trust ストアを使用して clients を個別に更新します。 (#179249) @RomneyDa に感謝します。
  • macOS 接続: 構成された資格情報は古いアプリ環境よりも優先され、型指定された環境シークレット参照は正しく解決され、リモート設定はコントロール UI のベース パスを尊重します。 (#191468、#185141、#128175) 修正 #164596 @RomneyDa、@anmol0b、@goldmar に感謝します。
  • Mac ツールとメッセージング: iMessage はアプリの更新後もオートメーションを再付与することなく引き続き使用でき、Peekaboo ウィンドウ インスペクションは有効なスナップショット参照を受け入れ、node exec はタイムアウトなしで構成されたコマンドの結果を保存します。 (#186107、#172116、#190729) 修正 #178719 @aniketkrs、@RomneyDa、@anmol0b、@SharkeyDev、@holgergruenhagen、@LiuwqGit、@etzelm に感謝します。
  • Mac 音声と埋め込みページ: 音声の重複送信や誤送信フィードバックを回避し、空白または古い Mac タブの代わりに回復可能なロード エラーを表示します。 (#186271、#185432) @anmol0b、@etzelm、@RomneyDa に感謝します。
  • ネイティブ音声とキャプチャ: iOS と macOS Talk は、境界付きバッファリング内での遅い音声確認応答を許容し、生成が再生を超えたという理由だけで長い会議の応答が途切れることはありません。また、サイズが大きすぎる Mac の録音は、ノード接続がドロップされるのではなく、サイズ ガイダンスによって失敗します。 @MertBasar0、@anmol0b、@shakkernerd、@kybrcore、@sukhdeepjohar、@potoior、@RomneyDa に感謝します。
  • Android とデスクトップの互換性: Android チャットは、ゲートウェイを切り替えた後、ロールが許可されたエージェント リストを待ちます。また、個別に更新された Mac ノードは、コンピュータ使用コントラクト エラーなしでオプションのカーソル座標を返すことができます。 @MertBasar0、@anmol0b、@shakkernerd、@kybrcore、@sukhdeepjohar、@potoior、@RomneyDa に感謝します。
  • チャネル回復: Slack は、通常の沈黙を障害として扱うことなく、デッド リレー接続を検出します。Tlon は、停止したストリームを再接続して、未確認のイベントを再生できるようにします。また、管理された Tailscale エクスポージャは、デーモンの再起動後に、ローカル認証されたアクセスが利用可能な状態のまま回復します。ありがとう@RomneyDa。
  • チャンネル配信: Feishu は、ツール呼び出しの前後のテキストを同じストリーミング カードに保持します。 Synology は、受信者が一致するメッセージ ID からの配信のみを確認します。 Twitch ターゲットと Zalo のサポートされていないイベント テキストは、使用可能なコンテンツを黙って失うのではなく、チャネルの処理に従います。ありがとう@RomneyDa。
  • チャネルの認証情報と通知: 暗黙的な Slack のデフォルト アカウントは、名前付きアカウントと並んで完全なトップレベルの認証情報を保持し、チャネル シークレットのコンシューマはアカウントのアクティベーションを尊重し、Nostr は承認を取り消すことなく失敗したペアリング通知を報告します。ありがとう@RomneyDa。
  • iMessage ストレージ: リカバリ カーソル キーには PostgreSQL と互換性のない NUL セパレータが含まれなくなり、チャネルが PostgreSQL にバックアップされた状態で開始できるようになりました。 (#184919) 修正 #184862 @duyufansh2008、@RomneyDa、@etzelm に感謝します。
  • セッションとエージェント権限: 1 つのエージェントを削除しても、他のエージェントのツール権限が損なわれることはなくなり、ローカル セッション機能の変更により、すべてのモデルを試行するのではなく、不適切なプロバイダーのフォールバックが阻止されます。 (#174918、#179312) 修正 #179290 @sreipete、@chelsealong、@obviyus、@Marvinthebored に感謝します。
  • プロンプト キャッシュ: セッション ツール定義は、完了、ハートビート、非所有者リクエストを含むターン全体にわたって安定した状態を保ち、不要なプロンプト キャッシュ ミスを回避します。 (#175309、#176167) @obviyus ありがとうございます。
  • 会話の回復: 圧縮により、要約が繰り返されてもアクティブな人間の要求が保持されます。キュー オーバーフロー サマリーは、表示される送信者と会話のコンテキストをそれぞれ保持します。実行完了ガイダンスはオーバーフローを乗り越えます。 (#180214、#187833、#190698、#182188、#184216) @RomneyDa と @aniketkrs に感謝します。
  • コーデックスの継続性: 会話全体の制限は互換性のあるネイティブ スレッドを保持し、一時的な制限は通常の会話バインディングを保持し、記録された履歴を持つ欠落したスレッドは、黙ってやり直す代わりにエラーを報告します。 @skyzhao1223 と @RomneyDa に感謝します。
  • コーデックス応答: 一時的な再試行では、元の要求と完了したツールを再実行せずに要約できます。端末のハンドオフにより、すでに送信されたステアリングに消費を確認する制限された機会が与えられ、不確かな入力が自動的に再生されることはありません。 (#183077、#184062、#181839、#167390) @RomneyDa に感謝します。
  • 共有資格情報とモデルの可用性: 同時 MCP 呼び出し元は不要な排他ロックなしで新しい OAuth トークンを再利用でき、レート制限のクールダウンは何時間ものローカル バックオフを蓄積するのではなくプロバイダーのタイミングに従い、新しいモデルのパブリケーションが置き換えられた更新結果を置き換えます。 (#179997、#180280、#179144) @RomneyDa に感謝します。
  • クロード CLI とスケジュールされた作業: キャンセルされた cron 実行は応答フックを停止し、中断された長時間実行ジョブはスケジューラーの起動を妨げなくなり、サイズが大きすぎるまたは無効な CLI ストリームはサブプロセスを即座にキャンセルし、管理された完了はポリシーでフィルターされたツール カタログを保持します。 (#181245、#191422、#159931、#172026) @sreipete と @fuller-stack-dev に感謝します。
  • セッション履歴とメモリ: 長いトランスクリプトのデコードにより、データベースの読み取りスナップショットが即座に解放され、境界付き履歴ページは要求されたアンカーと隣接するメッセージを保持し、メモリのインデックス作成はアーカイブされたトランスクリプトの具体化を待ちます。 (#164442、#172970、#177937、#182091、#190182、#189284、#188450、#188483、#190690) 修正 #171467 @RomneyDa と @etzelm に感謝します。
  • サブエージェントと再開リカバリ: 生きている子孫は期限切れの親を通信に利用できるようにし、受け入れられたイールドはハンドオフ前に兄弟ツールの結果を解決し、古くなった中断された入力によって新しい人間のメッセージが無期限にブロックされなくなりました。 (#179057、#184021、#180853、#181871、#178888、#184041、#184069、#172959) @RomneyDa に感謝します。
  • エージェントのハンドオフ: 待機中のセッション送信では、短いライフサイクル プレビューのみを返すのではなく、保存されている長い応答が回復され、ACP によって作成されたセッションは、後のプロンプトのために要求された作業ディレクトリを保持します。 (#178271、#176852) @RomneyDa に感謝します。
  • UI リカバリの制御: サイレントに切断されたゲートウェイ接続は、不確実な送信を再実行することなく再接続され、消費されたスラッシュ ステアリング メッセージはキューから残り、ルーチンの再起動通知は簡潔なままになります。 (#179101、#178642、#180024、#172843) @RomneyDa に感謝します。
  • GitHub ワークフロー: アクティブなセッションで再接続フローを開くことができ、失敗したフォローアップ プッシュでは既存の PR が保持され、応答本文の破棄中にリーダーがハングしなくなりました。 (#180200、#187835、#191721) 修正 #187832 @RomneyDa、@anmol0b、@obviyus、および @nocodet888-arch に感謝します。
  • プラグインのライフサイクル: 起動により、マネージド バイナリの再コピーが回避され、インストール ルートの変更後に所有する古いホスト リンクが修復され、許可されたコールバックとクリーンアップのためにプラグインのバックグラウンド リーダーが生きたままになります。内部プラグインのリロード再開は、古い外部受信者を使用するのではなく、現在のセッションに残ります。 (#187865、#181140、#182207、#179031、#181270、#179549、#190982) @Satoshi-Kusumoto、@RomneyDa、@jasonftl、@obviyus に感謝します。
  • ゲートウェイの起動とシャットダウン: 失効クレームのクリーンアップとサイドカーの起動中に一時的なデータベース ロックを再試行し、systemd がリークしたハンドルを持つプロセスを強制終了するのを待つのではなく、クリーン シャットダウン後に終了します。 (#187724、#186920、#191251) #187723、#186875、#191119 を修正しました。@masatohoshino、@obviyus、@speipete、@yousan、@bianyuxia-commits、および @davesanvil に感謝します。
  • 起動と移行の更新: 保持されたワーカー インデックスを使用して回復し、2026.10.7 ～ 2026.10.9 からの自動移行回復でのクラッシュを回避し、回復エラーを保持し、ステージング前に使用できない新しいノードを必要とする Git ターゲットを拒否します。 (#189023、#189713、#191495、#181715) @RomneyDa と @sreipete に感謝します。
  • 修復の更新: 放棄されたキャンセル保管を解放し、修復ループを発生させずに保留中のパッケージ ステップを解決します。検証に失敗した後に、元の失敗の詳細を保持しながら、中断された Windows ゲートウェイ タスクを復元します。 (#177932、#186787、#189647) 修正 #177684、#184893、#189620 @RomneyDa、@fuller-stack-dev、@TheAngryPit、@sukhdeepjohar、@sreipete、@syxscott、および @stephen3303 に感謝します。
  • 更新キャプチャとサービス ハンドオフ: リカバリ キャプチャをリストするときに Finder メタデータを無視し、/ から起動されたときに CLI ノード ランタイムをリカバリし、使用できない自動更新サービス ハンドオフを記録されない障害ではなくスキップされたものとして分類します。 (#186663、#178112、#188405) 修正 #186650、#177739、#188302 @duyufansh2008、@RomneyDa、@sreipete、@woshicby、@downingkeys、および @ARSA31 に感謝します。
  • ドクター移行: 長い Matrix アーカイブ ファイル名をバインドし、移行ガイダンスのみが変更される場合に構成のプロモーションを保持し、明示的に要求されたヘッドレス修復を実行し、必要な作業がスキップされた場合に成功ではなく失敗を返し、実用的な検証で無効なハートビートの静かな時間を保持します。 (#187443、#190665、#187192、#186305) 修正 #187390、#190658、#187122 @RomneyDa、@skyzhao1223、@sreipete、@dakoller、@saariuslystoned、@JordanNewell に感謝します。
