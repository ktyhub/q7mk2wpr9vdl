ベーン v1.11.0

v1.11.0

何が変わったのか

主な機能

  • 新しいセットアップ ウィザード: モデルの選択とプロバイダーのセットアップによる新しい初期構成エクスペリエンス
  • 構成管理のオーバーホール: ライブ アップデートと移行サポートを備えた完全に再設計された構成システム
  • 強化された UI/UX: 新しいサイドバー、改善されたテーマ システム、およびすべてのコンポーネントにわたるレスポンシブ デザインの更新
  • 設定ダイアログ: モデルセレクター、埋め込み構成、およびシステム命令を備えた新しい設定インターフェイス
  • 単一コマンドによるインストール: リポジトリ全体を取得しなくても、単一の Docker コマンドを使用して Perplexica をインストールできるようになりました。

プロバイダーとモデルの更新

  • 最新の AI モデルのサポートを追加しました: GPT-5、GPT-5 Mini、O3、Claude Opus 4.1、および Gemini 2.5 モデル
  • 新しいプロバイダー: AIML API、Lemonade、LM Studio、Transformers (動的読み込みあり)
  • 統合モデルレジストリによる強化されたプロバイダー管理
  • @langchain/groq を使用した Groq 統合の改善
  • モデルはハードコーディングされずに動的にフェッチされるようになりました。

UI の改善

  • 小さな画面でもアクセスしやすくするためのモバイル設定ボタン
  • 地理位置情報サポートとインペリアル/メートル単位を備えた天気ウィジェット
  • トピック選択とプレビュー モードを備えた強化された Discover ページ
  • 軽量テーマとの互換性を備えたファイル添付モーダルの改善
  • スマートスクロールバック検出によるチャットの自動スクロール

開発者エクスペリエンス

  • 不正なリクエストを防ぐための API ルート検証
  • パフォーマンスを向上させるためにメッセージ エンティティを個別に処理する
  • レンダリングが改善された引用コンポーネント
  • 効率的な更新のためのハッシュベースの構成管理
  • ts-node を置き換えるインストルメンテーション ベースの移行

修正

  • 繰り返される最初のトークンと思考タグの処理の問題を修正しました
  • double stringify JSON の解析エラーを解決しました
  • メッセージ書き換え時の誤った履歴を修正
  • DOCファイルのファイルアップロードエラーを修正
  • iOS 入力ズームの問題を修正
  • コンポーネント全体にわたるライトモードの色の問題を解決しました

Vane v1.11.0

Highlights

  • Deployment and onboarding — A new setup wizard guides model and provider selection, while the single-command Docker install removes the need to clone and build the repository for standard deployments. Existing installations should verify provider credentials and persisted configuration after upgrading.

  • Dynamic provider and model registry — Adds GPT-5, GPT-5 Mini, O3, Claude Opus 4.1, Gemini 2.5, and providers including AIML API, Lemonade, LM Studio, and Transformers. Model lists now come from provider APIs instead of a release-time hardcoded catalog, so test connectivity and fallback behavior rather than assuming identical options everywhere.

  • Configuration and migration tooling — The redesigned configuration layer applies updates live, exposes embedding and system-instruction settings, and uses hash-based update tracking. Migrations now run through instrumentation instead of ts-node; validate custom configurations on a staging copy and update deployment scripts that assume the old runner.

  • Stricter API validation — Route validation rejects malformed requests earlier. Audit API clients and integrations for payloads that previously depended on permissive handling, as they may now fail explicitly instead of being partially processed.

  • Streaming and history correctness — Fixes cover duplicate first tokens, think-tag handling, double-stringified JSON parsing, and incorrect history during message rewrites. If you wrap or post-process streamed output, retest those paths—especially reasoning tags and rewrite flows.

  • Breaking changes — None documented.

v1.11.0

What's Changed

Major Features

  • New Setup Wizard: New initial configuration experience with model selection and provider setup
  • Configuration Management Overhaul: Completely redesigned config system with live updates and migration support
  • Enhanced UI/UX: New sidebar, improved theme system and responsive design updates across all components
  • Settings Dialog: New settings interface with model selector, embedding configuration and system instructions
  • Single command installation: Perplexica can be now be installed using a single Docker command without pulling the whole repo.

Provider & Model Updates

  • Added support for latest AI models: GPT-5, GPT-5 Mini, O3, Claude Opus 4.1, and Gemini 2.5 models
  • New providers: AIML API, Lemonade, LM Studio and Transformers (with dynamic loading)
  • Enhanced provider management with unified model registry
  • Improved Groq integration using @langchain/groq
  • Models are now fetched dynamically instead of being hardcoded

UI Improvements

  • Mobile settings button for better accessibility on smaller screens
  • Weather widget with geolocation support and Imperial/Metric units
  • Enhanced Discover page with topic selection and preview mode
  • Improved file attachment modal with light theme compatibility
  • Auto scroll in chat with smart scroll back detection

Developer Experience

  • API route validation to prevent malformed requests
  • Separate message entity handling for better performance
  • Citation component with improved rendering
  • Hash based config management for efficient updates
  • Instrumentation based migrations replacing ts-node

Fixes

  • Fixed repeated first token and think tag handling issues
  • Resolved double stringify JSON parsing errors
  • Fixed wrong history during message rewriting
  • Corrected file upload errors with DOC files
  • Fixed iOS input zoom issues
  • Resolved light mode color issues across components
