サーバー v2.4.0

セキュリティ修正

v2.4.0 は 3 つのサーバーの 6 つの脆弱性を修正します。 @modelcontextprotocol/server-filesystem を 2.3.0 にアップグレードします。 mcp-server-git と mcp-server-fetch から 2026.11.11 まで。 |パッケージ |影響を受ける | | で修正されました | --- | --- | --- | | @modelcontextprotocol/server-filesystem | 2.3.0 より前のすべてのバージョン、および日付バージョン 2025.1.14 から 2026.8.31 | 2.3.0 | | mcp-server-git | 2026.11.4を通して | 2026.11.11 | | mcp-server-fetch | 2026.11.4を通して | 2026.11.11 |

@modelcontextprotocol/server-filesystem 2.3.0

  • 読み取りはチェックされたファイルに残ります (Linux および macOS)。読み取りツールとファイル リソースは、書き込みの場合と同様に、チェックされたディレクトリに相対的なファイルを開くようになりました。そのため、アクセス チェックと読み取りの間でシンボリック リンク用にスワップされたディレクトリは、許可されたディレクトリの外からファイルを返すことができなくなりました。 FIFO、ソケット、またはデバイスは読み取りではなく拒否されます。 **Windows では、書き込み (#5260) (GHSA-p9cv-8g75-4xcg) のように、競合を閉じることなく競合を狭めます。
  • move_file は、チェックしたソースのみを移動します。 1 つのデバイス内での移動では、最初に、新しい名前で独自のチェック済みディレクトリからソースが取り出されます。そのため、シンボリックリンクに交換されたソース ディレクトリは、外部ファイルを許可されたディレクトリに取り込むことができなくなり、読み取り可能になります (GHSA-7m4x-rv66-mxhh)

mcp-server-git 2026.11.11

  • リポジトリ独自の Git 設定では、サーバーでプログラムを実行できなくなりました。 untrusted リポジトリでの git_status などの読み取り専用呼び出しは、.git/config (core.fsmonitor、diff.external、フック、フィルターおよびマージ ドライバー、署名) で指定されたコマンドをサーバーの権限で実行するために使用されていました。すべての Git コマンドはこれらの設定をオーバーライドするようになり、2.31 より古い Git はオーバーライドを無視するため拒否されます (GHSA-6hqx-gqrx-c5r2)
  • --repository 制限は、代替オブジェクト ストア、リンクされたワークツリー、Git ディレクトリ内のリンクを対象とします。 許可されたリポジトリ内のリポジトリは、objects/info/alternates を通じて別のリポジトリのオブジェクトを読み取ったり、リンクされたワークツリーの Git ディレクトリを許可されたリポジトリとして渡すことができます。許可されたリポジトリの外部につながる Git ディレクトリ内のシンボリックリンクと同様に、両方とも拒否されます。 Windows では、ディレクトリ ジャンクションはまだカバーされていません (#5520) (GHSA-q74p-4wrc-q7w6)

mcp-server-fetch 2026.11.11

  • IPv6 サイトローカル アドレスはプライベートです。 プライベート アドレス ガードは、fec0::/10 をパブリックとして読み取ります。現在は拒否されており、IPv4 アドレスを持たないグローバル ユニキャスト (2000::/3) の外側の IPv6 アドレスも拒否されます (GHSA-3rxj-6jhw-qfv7)。
  • robots.txt は、サイトが解決するパスおよび記述されたパスと照合されるため、//private または /x/../private は Disallow: /private (GHSA-f9hh-cmx9-2f23) を超えることができなくなります。

日付バージョンの npm リリースからのアップグレード

TypeScript サーバーは、日付バージョン (2025.x、2026.x) から 1.0.0 のセマンティック バージョンに移行しました。パッケージ マネージャーは、2.3.0 を 2025.x および 2026.x の各バージョンよりも下にランク付けするため、アップグレードとして提供しません。 @modelcontextprotocol/server-filesystem の日付バージョンを使用している場合は、2.3.0 を明示的にインストールします (npm install @modelcontextprotocol/server-filesystem@2.3.0)。

servers v2.4.0

Security fixes

v2.4.0 fixes six vulnerabilities in three servers. Upgrade @modelcontextprotocol/server-filesystem to 2.3.0, and mcp-server-git and mcp-server-fetch to 2026.11.11.

| Package | Affected | Fixed in | | --- | --- | --- | | @modelcontextprotocol/server-filesystem | all versions before 2.3.0, and date versions 2025.1.14 through 2026.8.31 | 2.3.0 | | mcp-server-git | through 2026.11.4 | 2026.11.11 | | mcp-server-fetch | through 2026.11.4 | 2026.11.11 |

@modelcontextprotocol/server-filesystem 2.3.0

  • Reads stay with the file that was checked (Linux and macOS). The read tools and file resources now open a file relative to the directory that was checked, as writes already did, so a directory swapped for a symlink between the access check and the read can no longer return a file from outside the allowed directories. A FIFO, socket or device is refused rather than read. On Windows this narrows the race without closing it, as for writes (#5260) (GHSA-p9cv-8g75-4xcg)
  • move_file moves only the source it checked. A move within one device first takes the source out of its own checked directory under a fresh name, so a source directory swapped for a symlink can no longer bring an outside file into the allowed directories, where it would become readable (GHSA-7m4x-rv66-mxhh)

mcp-server-git 2026.11.11

  • A repository's own Git configuration can no longer make the server run a program. A read-only call such as git_status on an untrusted repository used to run a command named in its .git/config (core.fsmonitor, diff.external, hooks, filter and merge drivers, signing) with the server's privileges. Every Git command now overrides those settings, and a Git older than 2.31, which would ignore the overrides, is refused (GHSA-6hqx-gqrx-c5r2)
  • --repository confinement covers alternate object stores, linked worktrees and links in the Git directory. A repository inside the allowed one could read another repository's objects through objects/info/alternates, or pass a linked worktree's Git directory off as the allowed repository's. Both are refused, as is a symlink in a Git directory that leads outside the allowed repository. On Windows a directory junction is not yet covered (#5520) (GHSA-q74p-4wrc-q7w6)

mcp-server-fetch 2026.11.11

  • IPv6 site-local addresses are private. The private-address guard read fec0::/10 as public. It is now refused, and so is any IPv6 address outside global unicast (2000::/3) that does not carry an IPv4 address (GHSA-3rxj-6jhw-qfv7)
  • robots.txt is matched against the path the site will resolve, as well as the path as written, so //private or /x/../private can no longer get past Disallow: /private (GHSA-f9hh-cmx9-2f23)

Upgrading from a date-versioned npm release

The TypeScript servers moved from date versions (2025.x, 2026.x) to semantic versions in 1.0.0. Package managers rank 2.3.0 below every 2025.x and 2026.x version, so they won't offer it as an upgrade. If you are on a date version of @modelcontextprotocol/server-filesystem, install 2.3.0 explicitly: npm install @modelcontextprotocol/server-filesystem@2.3.0.
