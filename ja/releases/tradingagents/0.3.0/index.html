TradingAgents v0.3.0

トレーディングエージェント v0.3.0

概要

TradingAgents v0.3.0 は、安定化および拡張性のリリースです。検証済みのデータ アクセス コントラクト、拡張されたプロバイダーおよびデータ ベンダー レジストリ、現行世代のモデル カタログ、および CI ゲートです。

検証済みのデータアクセス契約

シンボルの正規化は、すべてのベンダー パス (アイデンティティ、返品、CLI、ニュース) で実行されるようになりました。構成されたベンダー リストは正確な解決チェーン (選択されていないベンダーへのサイレント フォールバックはありません) であり、障害は型指定された VendorError 分類を通じて表面化します。ニュース ウィンドウは先読みセーフであり、古い OHLCV は最新としてレポートされる代わりに拒否され、yfinance の取得には要求された終了日が含まれます。検証済みの市場データのスナップショットにより価格と指標の主張が裏付けられ、ティッカーと企業の決定的な解決により、間違った企業の幻覚が阻止されます。

プロバイダー レジストリ

OpenAI 互換プロバイダーは単一仕様の背後に登録され、汎用 openai_compatible エンドポイントは vLLM、LM Studio、およびリレーをカバーします。 NVIDIA NIM、Kimi (Moonshot)、Groq、Mistral に加えて、ネイティブ Amazon Bedrock client を追加します。

データベンダー

FRED マクロ指標と Polymarket イベント確率は、ニュースやマクロ アナリストに公開されます。オプションのベンダーは、実行を中止するのではなく、データなしセンチネルに低下します。

モデルカタログ

プロバイダー全体で現行世代のラインナップに更新されました。引退した gpt-4.1、クロード ソネット 4.5、およびジェミニ 2.5 ライン。推論の深さは、TRADINGAGENTS_OPENAI_REASONING_EFFORT、TRADINGAGENTS_GOOGLE_THINKING_LEVEL、および TRADINGAGENTS_ANTHROPIC_EFFORT を介して構成でき、それぞれがそれを受け入れるモデルにゲートされます。

構成と CLI

明示的な TRADINGAGENTS_* 値または CLI フラグが、ディベートおよびリスク ラウンド カウント、--checkpoint / --no-checkpoint、および Docker プロバイダー プロファイルの対話型デフォルトよりも優先されるようになりました。無効なブール環境値は大声で失敗します。アナリストは現在の日付を示すプロンプトを表示するため、ツール呼び出しの日付範囲は実行日に固定されます。

ツーリング

GitHub アクションは、Python 3.10-3.13、厳密な ruff、およびパッケージと CLI をインポートするクリーン インストール スモークにわたって pytest スイートを実行します。 TradingAgentsGraph.save_reports() は、ヘッドレス実行および API 実行に対して、CLI が生成するのと同じレポート ツリーを書き込みます。

貢献者の謝辞を含む完全なリストについては、CHANGELOG.md を参照してください。

TradingAgents v0.3.0

Highlights

  • Verified data-access contract — This is the most adoption-sensitive change: the configured vendor list is now the exact resolution chain, with no silent fallback to vendors you didn't select. If your config relied on implicit fallback when a preferred vendor failed, it will now stop instead of quietly succeeding — audit your vendor lists before upgrading. Failures are now typed via a VendorError taxonomy, so callers can branch on error class rather than parsing strings. On the correctness side, symbol normalization runs on every path (identity, returns, CLI, news), news windows are look-ahead-safe (no future leakage in backtests), stale OHLCV is rejected rather than mislabeled as current, yfinance fetches include the requested end date, and deterministic ticker→company resolution removes a classic source of "right ticker, wrong company" hallucination.
  • Provider registry — OpenAI-compatible providers now register behind a single spec, and the generic openai_compatible endpoint covers vLLM, LM Studio, and custom relays, so self-hosted and proxy setups no longer need bespoke wiring. New first-class providers: NVIDIA NIM, Kimi (Moonshot), Groq, and Mistral, plus a native Amazon Bedrock client (not an OpenAI-shim). Net effect: provider switching is largely a config change, though the consolidation means any custom provider integration should be re-registered against the new spec.
  • Data vendors — FRED macro indicators and Polymarket event probabilities are now exposed to the news and macro analysts, adding real macro and prediction-market signals to the decision loop. Importantly, optional vendors degrade to a no-data sentinel instead of aborting the entire run — a resilience win for production pipelines where a single flaky vendor previously killed the job. Watch that downstream analyst logic handles the sentinel explicitly rather than treating it as a valid zero.
  • Model catalog — Refreshed to current-generation lineups, but this is a breaking change for anyone pinning models: gpt-4.1, Claude Sonnet 4.5, and the Gemini 2.5 line are retired, so existing configs referencing them must be updated or runs will fail. Reasoning depth is now tunable via TRADINGAGENTS_OPENAI_REASONING_EFFORT, TRADINGAGENTS_GOOGLE_THINKING_LEVEL, and TRADINGAGENTS_ANTHROPIC_EFFORT — each gated to the models that actually accept it, so mismatched effort/model pairs are ignored rather than erroring at the API.
  • Configuration and CLI — Precedence is now deterministic for automation: explicit TRADINGAGENTS_* values and CLI flags win over interactive defaults for debate/risk round counts, --checkpoint/--no-checkpoint, and the Docker provider profile. This makes CI and headless runs reproducible without prompt interception, but invalid boolean env values now fail loudly instead of being coerced — tighten your env hygiene. Analyst prompts also lead with the current date so tool-call date ranges anchor to the run date, improving time-sensitive data pulls.
  • Tooling and headless parity — CI now gates every PR with pytest across Python 3.10–3.13, strict ruff, and a clean-install smoke test that imports the package and CLI — a meaningful signal that the release is installable and import-safe, not just test-green in a dev env. TradingAgentsGraph.save_reports() now writes the same report tree as the CLI, closing the gap between API/headless runs and CLI runs so downstream consumers can rely on one artifact layout.

Summary

TradingAgents v0.3.0 is a stabilization and extensibility release: a verified data-access contract, an expanded provider and data-vendor registry, a current-generation model catalog, and a CI gate.

Verified Data-Access Contract

Symbol normalization now runs on every vendor path (identity, returns, CLI, news). The configured vendor list is the exact resolution chain (no silent fallback to unselected vendors), and failures surface through a typed VendorError taxonomy. News windows are look-ahead-safe, stale OHLCV is rejected instead of reported as current, and yfinance fetches include the requested end date. A verified market-data snapshot grounds price and indicator claims, and deterministic ticker-to-company resolution stops the wrong-company hallucination.

Provider Registry

OpenAI-compatible providers register behind a single spec, and a generic openai_compatible endpoint covers vLLM, LM Studio, and relays. Adds NVIDIA NIM, Kimi (Moonshot), Groq, and Mistral, plus a native Amazon Bedrock client.

Data Vendors

FRED macro indicators and Polymarket event probabilities are surfaced to the news and macro analysts. Optional vendors degrade to a no-data sentinel instead of aborting a run.

Model Catalog

Refreshed to current-generation lineups across providers; retired gpt-4.1, Claude Sonnet 4.5, and the Gemini 2.5 line. Reasoning depth is configurable via TRADINGAGENTS_OPENAI_REASONING_EFFORT, TRADINGAGENTS_GOOGLE_THINKING_LEVEL, and TRADINGAGENTS_ANTHROPIC_EFFORT, each gated to the models that accept it.

Configuration and CLI

An explicit TRADINGAGENTS_* value or CLI flag now wins over interactive defaults for debate and risk round counts, --checkpoint / --no-checkpoint, and the Docker provider profile; invalid boolean env values fail loudly. Analyst prompts lead with the current date so tool-call date ranges anchor to the run date.

Tooling

GitHub Actions runs the pytest suite across Python 3.10-3.13, strict ruff, and a clean-install smoke that imports the package and CLI. TradingAgentsGraph.save_reports() writes the same report tree the CLI produces, for headless and API runs.

See CHANGELOG.md for the full list, including contributor acknowledgments.
