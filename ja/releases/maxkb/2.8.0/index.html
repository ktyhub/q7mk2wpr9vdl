MaxKB v2.8.0

MaxKB v2.8.0

新機能

  • ツール: ワークフロータイプのツールを追加しました。
  • ツール: 自動 Python コード生成をサポートしました。
  • ナレッジ ベース: ナレッジ ベースのすべてのメタデータのインポートとエクスポートをサポートしました。
  • エージェント: 会話中のモデルと知識ベースの選択をサポートしました。
  • エージェント: 他のフォルダーへの移動またはバッチ削除の実行のためのバッチ選択をサポートしました。
  • エージェント: 高度なエージェントの「画像理解」ノードと「ビデオ理解」ノードの思考プロセスの切り替え設定を追加しました。
  • ナレッジベース: 他のフォルダーへの移動またはバッチ削除を実行するためのバッチ選択をサポートしました。
  • ツール: 他のフォルダーへの移動またはバッチ削除を実行するためのバッチ選択をサポートしました。
  • モデル: Baidu Qianfan プロバイダーからのモデルの再ランキングのサポートを追加しました (#4927)。
  • システム: システム内のすべてのユーザー名表示フィールドを統合して、ユーザーのフルネームを表示します。
  • エージェント: 高度なエージェントの「変数集約」ノードは、dict 型変数への集約をサポートするようになりました (#4904)。
  • エージェント: 高度なエージェントの「変数分割」ノードの分割式コンポーネントを最適化しました (#4961)。

バグ修正

  • エージェント: AI 会話ノードのシステム プロンプトおよびスキル/MCP ツールで vLLM モデルを使用するときのユーザーの質問のエラーを修正しました。
  • エージェント: vLLM モデルと推論フィールドの間の非互換性の問題を修正しました。
  • エージェント: 文書タグ取得ノードを使用した場合の誤った取得結果を修正しました (#4942)。
  • エージェント: 高度なオーケストレーションでループ ノードの折りたたまれた状態が保存されない問題を修正しました (#4996)。
  • エージェント: 画像が途中で送信されずに再度送信される場合の、マルチターン会話中の画像理解ノードのエラーを修正しました (#4999)。
  • エージェント: ECharts 使用時の空白のレンダリングの問題を修正しました (#4966)。
  • エージェント (X-Pack): MaxKB 会話ログからダウンロードした後、WeChat Work 経由で送信された画像を開けない問題を修正しました。
  • エージェント (X-Pack): アドバンスト エージェントでサブエージェントの ID 認証を有効にした後、会話中に認証が実行されない問題を修正しました。
  • ナレッジ ベース: Web サイトのナレッジ ベースの「ナレッジ ソースでのプレビューを許可する」の不正確な説明を修正しました。
  • モデル: Alibaba Cloud Bailian 再ランキング モデルでトークン制限を超えた場合、または残高が不十分な場合に欠落していたエラー メッセージを修正しました (#4928)。
  • モデル (X-Pack): 一般ユーザーが共有モデルで click するときの権限エラーを修正しました。
  • ロール (X-Pack): 通常ユーザーの「バージョン情報」権限をカスタマイズするときに、他の権限が自動的にチェックされる問題を修正しました (#4954)。
  • リソース管理 (X-Pack): リソース管理でリソースを承認するときにユーザー ロールが表示されない問題を修正しました。

セキュリティ脆弱性の修正

  • セキュリティ: 内部制限されたサービスへのアクセスを防ぐために、socket.sendto()+MSG_FASTOPEN を介してサンドボックスの connect() フックをバイパスする SSRF 脆弱性を修正しました (#CVE-2026-39418)。
  • セキュリティ: 環境変数をクリアするための env -i LD_PRELOAD によるサンドボックス エスケープに関するリモート コード実行の脆弱性を修正しました (#CVE-2026-39420)。
  • セキュリティ: サンドボックスの結果検証をバイパスするために、sys.exit(0) による結果のなりすましに対するサンドボックス バイパスの脆弱性を修正しました (#CVE-2026-39419)。
  • セキュリティ: ctypes およびフック解除された SYS_pkey_mprotect によるサンドボックス エスケープに関する重大なリモート コード実行の脆弱性を修正しました (#CVE-2026-39421)。
  • セキュリティ: MCP サーバー構成検証の欠落による、悪意のある構成によるシェル コマンド インジェクションのリモート コード実行の脆弱性を修正しました (#CVE-2026-39417)。
  • セキュリティ: 一般的なストアド クロスサイト スクリプティング (XSS) の脆弱性を修正し、すべてのシナリオにおけるユーザー入力のセキュリティ検証を強化しました (#CVE-2026-39422)。
  • セキュリティ: フィルターされていないユーザー入力によって引き起こされる iframe_render の保存された XSS 脆弱性を修正しました (#CVE-2026-39426)。
  • セキュリティ: フィルタリングされていない HTML タグが原因で、Markdown レンダリング html_rander に保存された XSS の脆弱性を修正しました (#CVE-2026-39425)。
  • セキュリティ: Eval 悪意のあるコード インジェクションによる echarts_rander コンポーネントの保存された XSS 脆弱性を修正しました (#CVE-2026-39423)。
  • セキュリティ: アプリケーション チャット ログを CSV (CVE-2025-4546 の亜種) にエクスポートするときにエスケープされていない特殊文字によって引き起こされる CSV インジェクションの脆弱性を修正しました (#CVE-2026-39424)。

MaxKB v2.8.0

Highlights

  • Workflow tools and Python generation — Workflow-type tools plus automatic Python code generation make reusable, multi-step tooling easier to build. Review generated code and permissions before production use, and regression-test custom tools against the hardened sandbox.

  • Knowledge-base portability and bulk administration — Full metadata import/export supports migration between environments, while batch move/delete now covers agents, knowledge bases, and tools. Treat metadata exports separately from document-content backups, and review bulk deletions carefully.

  • Conversation-time model control and retrieval — Users can switch models and knowledge bases during conversations without rebuilding agents; Baidu Qianfan reranking adds another retrieval option (#4927). vLLM fixes for system prompts with Skills/MCP tools and reasoning fields improve compatibility, but switched contexts still need compatible prompts, tool schemas, and retrieval expectations.

  • Advanced-agent reliability — Dict-type variable aggregation (#4904), improved variable splitting (#4961), and image/video thinking-process toggles expand orchestration options. Ensure downstream nodes handle dict outputs correctly, and re-test split expressions, tag-based retrieval (#4942), image reattachment in multi-turn chats (#4999), and ECharts rendering (#4966).

  • Security hardening — prioritize this upgrade — Fixes close sandbox SSRF, RCE, and result-spoofing escapes (CVE-2026-39418–39421), MCP configuration shell injection (CVE-2026-39417), stored XSS across input/iframe/Markdown/ECharts paths (CVE-2026-39422/23/25/26), and CSV injection in exported chat logs (CVE-2026-39424). Previously accepted MCP configurations and rich content may now be rejected or neutralized; X-Pack also restores sub-agent authentication and shared-resource authorization.

  • Compatibility — No breaking changes are listed; regression-test custom MCP servers, sandboxed Python, rich rendering, and CSV consumers before rollout.

New Features

  • Tools: Added workflow-type tools;
  • Tools: Supported automatic Python code generation;
  • Knowledge Base: Supported importing and exporting all metadata of the knowledge base;
  • Agent: Supported selecting models and knowledge bases during conversation;
  • Agent: Supported batch selection to move to other folders or perform batch deletion;
  • Agent: Added thinking process toggle settings for "Image Understanding" and "Video Understanding" nodes in advanced agents;
  • Knowledge Base: Supported batch selection to move to other folders or perform batch deletion;
  • Tools: Supported batch selection to move to other folders or perform batch deletion;
  • Models: Added support for reranking models from the Baidu Qianfan provider (#4927);
  • System: Unified all username display fields in the system to show the user's full name;
  • Agent: The "Variable Aggregation" node in advanced agents now supports aggregating into dict-type variables (#4904);
  • Agent: Optimized the split expression component of the "Variable Splitting" node in advanced agents (#4961).

Bug Fixes

  • Agent: Fixed an error in user questions when using vLLM models with system prompts and Skills/MCP tools in the AI Conversation node;
  • Agent: Fixed the incompatibility issue between vLLM models and the reasoning field;
  • Agent: Fixed incorrect retrieval results when using the document tag retrieval node (#4942);
  • Agent: Fixed the issue where the collapsed state of loop nodes in advanced orchestration was not saved (#4996);
  • Agent: Fixed an error in the Image Understanding node during multi-turn conversations when images are not sent midway and then sent again (#4999);
  • Agent: Fixed blank rendering issues when using ECharts (#4966);
  • Agent (X-Pack): Fixed the issue where images sent via WeChat Work could not be opened after downloading from MaxKB conversation logs;
  • Agent (X-Pack): Fixed the issue where authentication was not performed during conversations after enabling identity authentication for sub-agents in advanced agents;
  • Knowledge Base: Fixed inaccurate description of "Allow preview in knowledge sources" in the Web Site knowledge base;
  • Models: Fixed the missing error messages when token limit is exceeded or balance is insufficient for Alibaba Cloud Bailian reranking models (#4928);
  • Models (X-Pack): Fixed the permission error when regular users click on shared models;
  • Roles (X-Pack): Fixed the issue where other permissions were automatically checked when customizing the "About" permission for regular users (#4954);
  • Resource Management (X-Pack): Fixed the issue where user roles were not displayed when authorizing resources in resource management.

Security Vulnerability Fixes

  • Security: Fixed SSRF vulnerability bypassing sandbox connect() hook via socket.sendto()+MSG_FASTOPEN to prevent access to internal restricted services (#CVE-2026-39418);
  • Security: Fixed remote code execution vulnerability for sandbox escape via env -i LD_PRELOAD to clear environment variables (#CVE-2026-39420);
  • Security: Fixed sandbox bypass vulnerability for result spoofing via sys.exit(0) to bypass sandbox result verification (#CVE-2026-39419);
  • Security: Fixed critical remote code execution vulnerability for sandbox escape via ctypes and unhooked SYS_pkey_mprotect (#CVE-2026-39421);
  • Security: Fixed remote code execution vulnerability for Shell command injection via malicious configuration due to missing MCP server configuration validation (#CVE-2026-39417);
  • Security: Fixed general stored cross-site scripting (XSS) vulnerability and strengthened user input security validation in all scenarios (#CVE-2026-39422);
  • Security: Fixed stored XSS vulnerability in iframe_render caused by unfiltered user input (#CVE-2026-39426);
  • Security: Fixed stored XSS vulnerability in Markdown rendering html_rander due to unfiltered HTML tags (#CVE-2026-39425);
  • Security: Fixed stored XSS vulnerability in echarts_rander component via Eval malicious code injection (#CVE-2026-39423);
  • Security: Fixed CSV injection vulnerability caused by unescaped special characters when exporting application chat logs to CSV (variant of CVE-2025-4546) (#CVE-2026-39424).
