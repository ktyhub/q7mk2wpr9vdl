MaxKB v1.8.1

Highlights

  • Scoped conversation history — AI chat nodes can now configure which workflow and node context accompanies historical messages (PR #1791), helping multi-step workflows avoid carrying irrelevant conversation state. Set the intended context explicitly where workflow isolation matters.
  • Zhipu vision models — Model management now supports Zhipu AI image-understanding models (PR #1785), adding another managed option for multimodal chat and knowledge-base workflows. Configure an image-capable model before submitting vision prompts.
  • Safer voice playback — Form data is now filtered from spoken responses (PR #1769), preventing input values from being read aloud. Check narration flows that previously depended on speaking form fields.
  • Complete PDF ingestion — Structure-less PDFs are no longer truncated to their first page. Re-index affected documents to rebuild knowledge-base segments from the corrected parsing behavior.
  • Tighter knowledge-base controls — View-only members can no longer export documents (PR #1807) or toggle segment activation, and document status filtering now returns correct results (PR #1800). Audit role-dependent automation that relied on those former permissions.
  • Compatibility — No breaking changes in this release.

新增功能

  • 应用：AI对话节点的历史聊天记录可设置工作流和节点的上下文；by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/1791
  • 模型管理：支持智谱AI供应商的图片理解模型；by @liuruibin in https://github.com/1Panel-dev/MaxKB/pull/1785

功能优化

  • 应用：语音播放时过滤表单数据；by @liuruibin in https://github.com/1Panel-dev/MaxKB/pull/1769
  • 系统：优化部分页面的显示样式。

问题修复

  • 知识库：修复文档按状态筛选结果错误的问题；by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/1800
  • 知识库：修复拥有查看权限的成员可以导出文档的问题； by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/1807
  • 知识库：修复拥有查看权限的成员可以修改分段启用/禁用状态的问题；
  • 知识库：修复上传无目录结构的PDF文件，只能识别第一页内容的问题；
  • 应用：按名称筛选结果后，不加载数据的问题；
  • 应用：修复浮窗图标尺寸过大时会被引导图遮盖的问题；by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/1802
  • 系统管理（X-Pack）：修复Swagger文档中的Web站点知识库缺少参数的问题；by @wxg0103 in https://github.com/1Panel-dev/MaxKB/pull/1810
  • 系统管理（X-Pack）：修复企业微信扫码登录配置错误的问题。by @wxg0103 in https://github.com/1Panel-dev/MaxKB/pull/1782
