MaxKB v1.8.0

Highlights

  • Multimodal Q&A — Applications now accept document and image uploads during user questions, while workflows gain document-content extraction and image-understanding nodes. Together with image-understanding model support for 通义千问, OpenAI, and 腾讯混元, this enables richer document- and image-grounded applications.
  • More capable workflow authoring — New form-collection and embedded-application nodes, checkbox/tab input components, configurable radio-button labels and values, and HTML-rendered opening messages support richer interactive flows. Canvas-wide collapse/expand and one-click layout beautification improve maintainability for larger workflows.
  • Knowledge-base operations and reliability — Creator filtering, bulk addition of conversation logs to knowledge bases, ingestion progress details, and recent-first conversation ordering improve administration and feedback loops. Fixes for PDF special characters, question-generation task dispatch, and website encoding reduce knowledge-ingestion failures.
  • Access controls and enterprise authentication — X-Pack adds OAuth2 SSO and fixes a permissions flaw where members with application-view permission could modify integration settings. Another fix restores knowledge-base visibility for members with knowledge-base management permission; teams relying on these boundaries should prioritize upgrading.
  • Upgrade recommendation — This is a substantive feature release, not a re-tag or metadata-only update. No breaking changes or migration steps are listed. Teams using workflows, multimodal inputs, knowledge ingestion, or X-Pack authentication have clear reasons to upgrade; deployments outside those areas and unaffected by the fixes can reasonably defer.
