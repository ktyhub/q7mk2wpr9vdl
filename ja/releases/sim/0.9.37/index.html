#シムv0.9.37

特徴

  • feat(access-control): 権限項目ごとにアクセス要求を管理します (#9483)
  • feat(docs): 共有 Sim デザイン システムを使用してドキュメントを再構築 (#9459)
  • 特技(拡張機能): Sim リンク リゾルバーを介して型付き SIM/ リンクを開く (#9486)
  • feat(sim-links): sim/<name> リダイレクトを使用した組織 Sim リンク (go links) (#9484)
  • feat(ライブラリ): 2026 年の自動データ レポートに最適な AI エージェント: 4 つのツールの比較 (#9472)
  • feat(ライブラリ): Slack と Discord に最適な AI エージェント プラットフォーム: 4 つのクロスチャネル オプションの比較 (#9473)
  • 偉業(ライブラリ): ドキュメントとツールにわたる社内ナレッジ検索に最適な AI エージェント (#9471)
  • 特技(拡張機能): Sim チャットとページ コンテキストを Chrome に導入 (#9454)
  • feat(mcp): type mcp ブロックは宣言された出力スキーマから応答します (#9466)
  • 特技(ワークフロー): 待機タイムアウト後にバックグラウンドで同期実行を継続させます (#9464)
  • feat(ライブラリ): 自動化された毎日の電子メール ダイジェストのためのベスト AI エージェント ビルダー (#9442)
  • feat(ライブラリ): 会議メモとフォローアップに最適な AI エージェント: 6 つのオプションを比較 (#9443)
  • 特技(検索): 組織の検索とレビューされたアシスタントのアクションを統合 (#9428)
  • feat(files): セッション API 上でワークスペース ファイルをページ、検索、検索、ロールアップします (#9435)
  • feat(db): デフォルトでアカウント トークンをシールし、移行中にバックフィルします (#9425)

改善点

  • 改善(sim-links): リソースレイアウトのクリーンアップと単純化 (#9492)
  • 改善(sim-links): 共有リソーステーブルレイアウトを使用する(#9491)
  • 改善(sim-links): 各リンクの宛先ファビコンを表示 (#9489)
  • 改善(認証): サインインとアクセスページを統合 (#9461)
  • 改善 (比較): Agent Builder のシャットダウン移行で OpenAI AgentKit ページをリードします (#9460)
  • 改善(サンドボックス): アイドル状態のチャット ワークベンチを実行し続けるのではなく一時停止します (#9452)
  • perf(knowledge): ウィンドウ上で 1 回のパスで完了したリストを調整します (#9449)
  • perf(admin): ダッシュボード台帳の使用状況を読み取り、エンティティごとに 1 つの限定スキャン (#9448)
  • perf(db): ワークスペースの使用状況のドリルダウンを、usage_log のインデックスのみで提供します (#9447)
  • perf(audit-logs): ワークスペースごとのキーセット スキャンを通じて時間のみで絞り込まれたリストを読み取ります (#9450)
  • perf(outbox): 前回の実行のバッチが終了した場所から各保持バッチを再開します (#9446)
  • perf(file-search): 主キーによって各バックフィル ページのリビジョンを調査する (#9445)
  • perf(audit-logs): 組織レベルの行にインデックスを付け、それらを 2 つのキーセット部分として読み取ります (#9437)
  • perf(files): ファイル ブラウザをページングし、ワークスペースをリストせずにファイルを解決します (#9436)
  • perf(db): ワークスペースのライブ ファイルをアップロード順にインデックス付けします (#9434)
  • perf(db): ホットパス データベース作業を削減し、コパイロットのクリーンアップ ギャップを埋める (#9419)

バグ修正

  • 修正(ドキュメント): 選択を簡素化し、メディアのインタラクションを検証します (#9493)
  • 修正(検索): Fireflies データ配列応答を受け入れる (#9490)
  • 修正(統合): 接続ヘッダーのアクションを調整する (#9487)
  • 修正(検索): ライブプロバイダーの遅延と部分的な障害をトレースします (#9482)
  • fix(mcp): mcp 出力形状における json スキーマのオープン性を尊重する (#9476)
  • 修正(検索): アシスタントのレビューとアカウント検出を強化します (#9478)
  • 修正(サンドボックス): Pi サイジング ドキュメントの E2B ビルドのデフォルトを修正 (#9477)
  • 修正(拡張機能): 埋め込まれたページを追跡から分離します (#9480)
  • 修正(母艦): --wait-timeout を超えた sim_cli 待機を、失敗ではなく完了として解決します (#9469)
  • 修正(検索): 余分なアシスタント ツール ゲートを削除 (#9468)
  • 修正(executor): バインドされた条件ループと名前のない変数の代入を拒否する (#9463)
  • 修正(検索): ナビゲーションを統合し、アクションのレビュー履歴を保存します (#9467)
  • 修正(請求): 無料プランを実行途中で許容範囲まで保留する (#9462)
  • 修正(統合): 監査によって強制される、カタログ、@ メニュー、および検索にわたる 1 つの統合アクセス判定 (#9457)
  • 修正(検索): インラインアクションのレビューとアカウントメニューの統合 (#9451)
  • 修正(ワークフロー): ワークフロー編集でのサンセット ブロックの新しい配置を拒否する (#9456)
  • 修正(請求): E2B のリソース最大値に関する Pi サイジングの注記を修正 (#9455)
  • 修正(請求): Pi サンドボックスの価格をビルド リソースで設定 (#9453)
  • fix(audit-logs): 組織の監査ログを単一スコープの述語を通じて再度リストします (#9438)
  • 修正(クリーンアップ): 共有チャット ファイルを保持し、プレフィックスによってインライン画像をスイープし、ルームの再取得を待機させます (#9433)
  • 修正(scim): ディレクトリのライフサイクルを強化し、グループのマッピングを明確にしました (#9429)
  • 修正(請求): Gmail の受信トレイの許容量の決定をシリアル化し、エイリアス登録の競合が両方ともそれを維持できないようにします (#9431)
  • fix(ci): ダイジェスト検索エラーでプロモート待機を再試行するのではなく失敗させる (#9430)
  • 修正(ファイル): ルーム配信が再取得を待機する時間を制限しました (#9427)
  • 修正 (ライブラリ): e コマースおよび Zapier の代替投稿の重複セクションと FAQ をマージ (#9424)
  • 修正(デスクトップ): e2e が保留状態をアサートしている間、GitHub 認証情報チェックを開いたままにします (#9420)
  • 修正(請求): 既存アカウントの Gmail エイリアスからの無料枠を差し控える (#9418)
  • fix(ci): 再タグ付け直後の読み取りを trusting する代わりに、プロモートされたアプリのダイジェストを予測します (#9416)

Features

  • feat(extension): open typed sim/ links through the Sim link resolver (#9486)

  • feat(library): Best AI Agents for Automated Data Reports in 2026: 4 Tools Compared (#9472)
  • feat(library): Best AI Agent Platforms for Slack and Discord: 4 Cross-Channel Options Compared (#9473)

  • feat(mcp): type mcp block replies from declared output schemas (#9466)
  • feat(workflows): let a synchronous run continue in the background after a wait timeout (#9464)
