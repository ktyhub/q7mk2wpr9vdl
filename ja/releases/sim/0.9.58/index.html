sim v0.9.58

パッチ 公開日2026年11月15日 出典simstudioai/sim English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シムv0.9.58

特徴

  • 特技(ライブラリ): Microsoft Copilot Studio と Power Automate: どちらを使用する必要がありますか? (#10047)
  • feat(ライブラリ): Microsoft Intune デバイス管理用の管理された AI エージェントを構築するにはどうすればよいですか? (#10045)
  • 特技(デスクトップ): グローバル ショートカット上のクイック チャット ウィンドウ (#10025)

改善点

  • 改善(コンピューター使用): 観測全体にわたって要素の ID を安定に保つ (#10046)
  • 改善(出力): ワークスペースリクエストを組織の出力ゲートウェイ経由でルーティングします (#10040)
  • 改善(検索): 各検索の形状と、各読み取りのソース、種類、サイズをログに記録します (#10042)
  • 改善(api): v2 エラー コード、フィールド、および拒否理由をリクエストの最後の行に記録します (#10033)
  • 改善(チャット): バックグラウンドタスクとスケジュールされたジョブターンをメッセージとして表示 (#10032)

バグ修正

  • 修正(サンドボックス): 前の間隔ティックがまだ飛行中である間は間隔ティックをスキップします (#10063)
  • 修正(リアルタイム): 管理ブロックのロックを書き込みロールのグラフ置換から除外する (#10062)
  • fix(sso): プラグインが解決したプロバイダー ID でのコールバックを許可します (#10054)
  • 修正(copilot): 呼び出し側のない実行をサーバーツールの書き込みに対する読み取り許可まで保留する (#10061)
  • 修正(sso): プロバイダーの検証済みドメイン外へのユーザーの書き込みを拒否する SSO コールバック (#10060)
  • 修正(エグゼキュータ): 一時停止したグラフ上で一時停止したドラフト実行を再開します (#10057)
  • 修正(受信箱): 電子メールがワークスペースメンバーとして機能する前に、認証された送信者が必要です (#10059)
  • 修正(helm): プレースホルダーシークレットを拒否し、サンプル値での配布を停止します (#10052)
  • 修正(webhooks): 未解決の環境変数シークレットを読み取る認証を拒否する (#10055)
  • 修正(ワークスペース): ワークスペース管理者による請求先アカウントの移動を停止します (#10058)
  • 修正(mcp): パブリック API ガバナンスでパブリック ワークフロー MCP サーバーをゲートする (#10056)
  • fix(mcp): v2 コントラクトのようにレガシー mcp サーバー名と説明をバインドしました (#10053)
  • 修正(helm): pii が有効な場合は常に、PII サービスを NetworkPolicy で制限する (#10051)
  • 修正(csp): ワークフロー実行ルートからシャドウされた許可ポリシーを削除 (#10050)
  • 修正(ファイル): Markdown ツールバーと現在の選択内容を比較 (#10049)
  • 修正(コンピューター使用): 上限を超えた閉じたメニュー項目を切り捨てられた状態として報告するのを停止 (#10043)
  • 修正(ファイル): スクロール中に Markdown テーブルを読み取れるようにする (#10041)
  • 修正(統合): 統合スイープに関するリリース レビューの結果に対処します (#10039)
  • 修正(ワークスペース): すべてのファイル ID をバインドせずに、離脱するメンバーのファイルを引き渡す (#10038)
  • 修正(統合): エージェントのツール呼び出し操作を解決し、残りのリクエストをベンダー仕様に合わせます (#10036)
  • 修正(統合): 最終リリース監査の結果に対処します (#10035)
  • 修正(統合): monday、asana、clickup、airtable、notion、supabase、amplitude、box、docusign、dropbox を検証 (#10030)
  • 修正(コンピューター使用): ヘルパーをクラッシュさせる代わりに、フレームなしで無限に報告された要素を読み取ります (#10034)
  • 修正(統合): zendesk、pipedrive、およびインターコムをベンダー仕様と照合して検証 (#10028)
  • 修正(mailchimp): メンバーを正しくアーカイブし、完全な削除を追加し、リクエストをマーケティング api に合わせます (#10031)
  • 修正 (統合): Square、Quickbooks、Oracle Fusion、SAP、Workday を検証します。 oracle fusion アイコンを表示 (#10029)
  • 修正(統合): ServiceNow、Salesforce、および Hubspot をベンダーのドキュメントと照合して検証する (#10027)
  • fix(knowledge,files): ベースごとにナレッジベースドキュメントをカウントし、変更された順序のファイルリストにインデックスを付けます (#10026)

その他の変更点

  • ドキュメント(ライブラリ): Apache-2-0-vs-fair-code を更新 (#10048)
  • docs(ライブラリ): can-ai-agents-talk-to-each-other-multi-agent-communication-explained を更新 (#10044)

sim v0.9.58

Features

  • feat(library): Microsoft Copilot Studio vs Power Automate: Which Should You Use? (#10047)
  • feat(library): How Do You Build a Governed AI Agent for Microsoft Intune Device Management? (#10045)
  • feat(desktop): quick chat window on a global shortcut (#10025)

Improvements

  • improvement(computer-use): keep an element's id stable across observations (#10046)
  • improvement(egress): route workspace requests through the organization's egress gateway (#10040)
  • improvement(search): log the shape of each search and the source, kind, and size of each read (#10042)
  • improvement(api): log the v2 error code, field, and refusal reason on the request's closing line (#10033)
  • improvement(chat): show background task and scheduled job turns as messages (#10032)

Bug Fixes

  • fix(sandbox): skip interval ticks while the previous one is still in flight (#10063)
  • fix(realtime): keep admin block locks out of write-role graph replaces (#10062)
  • fix(sso): admit callbacks under the provider id the plugin resolved (#10054)
  • fix(copilot): hold callerless runs to the read grant for server tool writes (#10061)
  • fix(sso): refuse SSO callback user writes outside the provider's verified domain (#10060)
  • fix(executor): resume a paused draft run on the graph it paused on (#10057)
  • fix(inbox): require an authenticated sender before an email acts as a workspace member (#10059)
  • fix(helm): reject placeholder secrets and stop shipping them in example values (#10052)
  • fix(webhooks): reject auth that reads an unresolved env-var secret (#10055)
  • fix(workspaces): stop workspace admins from moving the billed account (#10058)
  • fix(mcp): gate public workflow MCP servers on public API governance (#10056)
  • fix(mcp): bound legacy mcp server name and description like the v2 contract (#10053)
  • fix(helm): confine the PII service with its NetworkPolicy whenever pii is enabled (#10051)
  • fix(csp): remove shadowed permissive policy from workflow execute routes (#10050)
  • fix(files): compare Markdown toolbars with their current selection (#10049)
  • fix(computer-use): stop reporting closed menu items past the cap as a truncated state (#10043)
  • fix(files): keep Markdown tables readable while scrolling (#10041)
  • fix(integrations): address release review findings on the integration sweep (#10039)
  • fix(workspaces): hand off a departing member's files without binding every file id (#10038)
  • fix(integrations): resolve agent tool-call operations and align remaining requests with vendor specs (#10036)
  • fix(integrations): address the final release audit findings (#10035)
  • fix(integrations): validate monday, asana, clickup, airtable, notion, supabase, amplitude, box, docusign, and dropbox (#10030)
  • fix(computer-use): read elements reported at infinity without a frame instead of crashing the helper (#10034)
  • fix(integrations): validate zendesk, pipedrive, and intercom against vendor specs (#10028)
  • fix(mailchimp): archive members correctly, add permanent delete, and align requests with the marketing api (#10031)
  • fix(integrations): validate square, quickbooks, oracle fusion, sap, and workday; show the oracle fusion icon (#10029)
  • fix(integrations): validate servicenow, salesforce, and hubspot against vendor docs (#10027)
  • fix(knowledge,files): count knowledge base documents per base and index the modified-order file list (#10026)

Other Changes

  • docs(library): update apache-2-0-vs-fair-code (#10048)
  • docs(library): update can-ai-agents-talk-to-each-other-multi-agent-communication-explained (#10044)
