sim v0.9.48

パッチ 公開日2026年11月8日 出典simstudioai/sim English original

#シムv0.9.48

特徴

  • feat(video): fal.ai ビデオ モデルの開始フレーム画像を受け入れる (#9761)
  • feat(着陸): /security および /trust を Trust センターにリダイレクトします (#9780)
  • 特技(ライブラリ): 企業全体で MCP サーバーを標準化する方法: プラットフォームの比較 (#9770)
  • feat(ライブラリ): 2026 年のエンタープライズ運用のためのベスト AI ビジネス プロセス オートメーション プラットフォーム 8 (#9769)
  • 偉業(ライブラリ): 製品分析の自動化に最適な AI エージェント プラットフォーム: Mixpanel、Segment、Amplitude、PostHog (#9768)
  • 特技(ライブラリ): MCP サーバーを AI エージェント ワークフローに接続する方法 (#9767)

改善点

  • 改善(検索): ライブドキュメントIDを短くしました (#9794)
  • 改善(検索): 各検索 MCP 結果ファクトを 1 回送信 (#9778)

バグ修正

  • 修正(デスクトップ): ソース接続 e2e サーバーからアカウント サイトを返す (#9795)
  • 修正(サンドボックス): プールが放棄されるか、バジェット時間が経過すると、実行中のフェッチをドロップします (#9793)
  • 修正(oauth): 接続を開始する前にワークスペースの接続リンクを確認する (#9792)
  • 修正(otp): 正しいコードを単一使用とし、有効期限のないコードを決して比較しないようにしました (#9789)
  • 修正(ドキュメント): 検索の応答性を維持し、サイドバーのスクロールを含めます (#9786)
  • 修正(デスクトップ): Sim クラウドにアクセスできない場合にローカル ネットワークのヒントをスキップする (#9791)
  • 修正(oauth): クロスサイト Instagram ワークスペースの起動を拒否 (#9788)
  • 修正(ビデオ): ビデオ設定をシリアル化するときにアクティブな開始フレーム入力を読み取ります (#9787)
  • fix(otp): コードを比較する前に検証試行をアトミックに予約します (#9774)
  • 修正(デスクトップ): プライベートの自己ホスト型サーバーの macOS ローカル ネットワーク ブロックについて説明します (#9777)
  • 修正(ファイルパーサー): JSZip が保護された領域の外から読み取る ZIP アーカイブを拒否する (#9773)
  • 修正(サンドボックス): タスクタイマーブリッジに上限を設け、ホストタイムアウト時にアイソレートを破棄する (#9776)
  • 修正(oauth): クロスサイトワークスペースのOAuth起動を拒否する (#9772)
  • 修正(実行): 本体 isClientSession ではなく、認証タイプから資格情報アクターを導出する (#9771)

その他の変更点

  • ci(npm): trusted パブリッシングを通じてすべての npm パッケージをパブリッシュ (#9790)
  • ドキュメント (ライブラリ): best-ai-agent-platforms-for-enterprise-teams-2026 を更新 (#9785)
  • ドキュメント (ライブラリ): best-hubspot-alternatives-ai-marketing-automation-2026 を更新 (#9783)
  • ドキュメント(ライブラリ): コードなしで AI-Slackbot を構築する方法を更新 (#9781)
  • ドキュメント(ズーム): アカウントの選択と個別の検索接続を明確にする (#9779)
  • chore(execute): きちんとした資格情報アクターのテストとコメント (#9775)
  • ドキュメント(ライブラリ): 実行アシスタントタスクに最適な AI エージェントを更新 (#9766)

sim v0.9.48

Features

  • feat(video): accept a start frame image for fal.ai video models (#9761)
  • feat(landing): redirect /security and /trust to the Trust Center (#9780)
  • feat(library): How to Standardize MCP Servers Across an Enterprise: Platforms Compared (#9770)
  • feat(library): 8 Best AI Business Process Automation Platforms for Enterprise Operations in 2026 (#9769)
  • feat(library): Best AI Agent Platforms for Product Analytics Automation: Mixpanel, Segment, Amplitude, and PostHog (#9768)
  • feat(library): How to Connect an MCP Server to an AI Agent Workflow (#9767)

Improvements

  • improvement(search): shorter live document IDs (#9794)
  • improvement(search): send each Search MCP result fact once (#9778)

Bug Fixes

  • fix(desktop): return account sites from the source-connect e2e server (#9795)
  • fix(sandbox): drop in-flight fetches once the pool gives up or the time budget passes (#9793)
  • fix(oauth): confirm workspace connect links before starting the connection (#9792)
  • fix(otp): make a correct code single-use and never compare a code without expiry (#9789)
  • fix(docs): keep search responsive and contain sidebar scrolling (#9786)
  • fix(desktop): skip the Local Network hint when Sim Cloud is unreachable (#9791)
  • fix(oauth): reject cross-site Instagram workspace launches (#9788)
  • fix(video): read the active start frame input when serializing video settings (#9787)
  • fix(otp): reserve a verification attempt atomically before comparing the code (#9774)
  • fix(desktop): explain macOS Local Network blocks for private self-hosted servers (#9777)
  • fix(file-parsers): reject ZIP archives JSZip reads from outside the guarded region (#9773)
  • fix(sandbox): cap task timer bridges and dispose isolates on host timeout (#9776)
  • fix(oauth): reject cross-site workspace OAuth launches (#9772)
  • fix(execute): derive credential actor from auth type, not body isClientSession (#9771)

Other Changes

  • ci(npm): publish every npm package through trusted publishing (#9790)
  • docs(library): update best-ai-agent-platforms-for-enterprise-teams-2026 (#9785)
  • docs(library): update best-hubspot-alternatives-ai-marketing-automation-2026 (#9783)
  • docs(library): update how-to-build-ai-slackbot-without-code (#9781)
  • docs(zoom): clarify account selection and separate search connections (#9779)
  • chore(execute): tidy credential-actor tests and comment (#9775)
  • docs(library): update best-ai-agents-for-executive-assistant-tasks (#9766)
