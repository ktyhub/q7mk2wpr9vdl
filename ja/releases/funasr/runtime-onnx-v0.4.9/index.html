FunASR ランタイム-onnx-v0.4.9

スタンドアロン funasr-onnx 0.4.9。これは新しいルート funasr リリースではありません。

このリリースには、#3846 からすでに受け入れられているオフライン VAD 修正が含まれています: 空または サブフレーム入力は、ONNX ランタイムを呼び出すことなく、入力ごとに 1 つの結果を保持します。 ゼロフレーム機能。 #3847: 空の句読点チャンクが返されることも含まれます ストリーミング キャッシュの状態を維持しながら、トークン化や推論を必要としません。

ホストされたスタンドアロン パッケージ ワークフローは、Python で #3847 回帰を実行するようになりました。 3.11と3.12。 Exact-head CI とmerged-main CI はそれぞれ 9 つのリリース契約を通過しました。 6 つのオフライン VAD ケース、5 つの空の句読点ケース、既存のインストール/ランタイム リグレッション、製品サイト、ブラウザ、ドキュメント、ビルド、Twine、およびクリーン パッケージチェック。ローカルのフェールクローズされたプライベート ネットワーク検証も 45 に合格しました ソース/契約テスト、38 個のインストール済みホイール テスト、およびインストール済み SDIST オリジン 検証。

これらは CPU ランタイム ラッパーの修正です。モデルの重みは変更されず、モデルも変更されませんでした このリリース用にダウンロードまたはロードされており、ASR 品質についての主張は行われません。

インストール: pip install -U funasr-onnx==0.4.9。

アセット: これら 2 つのペイロードをカバーするホイール、sdist、および SHA256SUMS。 PyPI は、 最後のアップロードステップは、公式バイトをダウンロードした後にのみ受け入れられます。

FunASR runtime-onnx-v0.4.9

Highlights

  • Offline VAD input handling (#3846) — Empty and sub-frame inputs now produce one result per input while skipping ONNX Runtime for zero-frame features. Existing result indexing remains valid, and degenerate inputs no longer trigger unnecessary runtime calls.
  • Punctuation streaming fast path (#3847) — Empty punctuation chunks return before tokenization or inference while preserving streaming cache state. This avoids wasted work between chunks and maintains continuity for subsequent non-empty input.
  • Release validation — The standalone-package workflow now runs the #3847 regression on Python 3.11 and 3.12. Reported checks cover offline VAD, empty punctuation, installed-wheel/runtime behavior, sdist origin verification, and packaging integrity; wheel and sdist assets include SHA256SUMS.
  • Upgrade path — Run pip install -U funasr-onnx==0.4.9. This updates only the standalone ONNX runtime package, not root funasr; no model weights changed or were downloaded, and no ASR-quality improvement is claimed.
  • Breaking changes — None.

Standalone funasr-onnx 0.4.9. This is not a new root funasr release.

This release includes the already accepted offline VAD fix from #3846: empty or sub-frame inputs preserve one result per input without invoking ONNX Runtime for zero-frame features. It also includes #3847: empty punctuation chunks return without tokenization or inference while preserving streaming cache state.

The hosted standalone-package workflow now runs the #3847 regression on Python 3.11 and 3.12. Exact-head and merged-main CI each passed 9 release contracts, 6 offline VAD cases, 5 empty-punctuation cases, the existing installed/runtime regressions, Product site, browser, documentation, build, Twine, and clean package checks. Local fail-closed private-network validation also passed 45 source/contract tests, 38 installed-wheel tests, and installed-sdist origin verification.

These are CPU runtime-wrapper fixes. No model weights changed, no model was downloaded or loaded for this release, and no ASR-quality claim is made.

Install: pip install -U funasr-onnx==0.4.9.

Assets: wheel, sdist, and SHA256SUMS covering those two payloads. PyPI is the final upload step and is accepted only after downloading the official bytes.
