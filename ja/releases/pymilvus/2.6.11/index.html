#ピミルバスv2.6.11

何が変わったのか

バグ修正

  • 修正: ConnectionManager 戦略で GrpcHandler にアドレスを渡す — @XuanYang-cn による 2.6.10 (#3321、#3323) 以降壊れていた Milvus Lite ローカル パスを修正
  • 修正: 接続回復後に「閉じたチャネルでは RPC を呼び出すことができません」 (#3326、#3345) by @pymilvus-bot
  • 修正: パーティション フィルターのバイパスを引き起こす QueryIterator のパラメーター名の誤字を修正 (#3324、#3330) @pymilvus-bot
  • 修正: AttributeError を防ぐために検索で None 応答を処理します (#3331、#3332) by @pymilvus-bot
  • 修正: 検索パス内のバイト ベクトル型の誤認を解決 (#3334) by @zhuwenxing
  • 修正: None ハンドラーに対して MilvusClient._get_connection をガード (#3337、#3338) by @pymilvus-bot
  • 修正:connections.connect() (#3343、#3353) での None 資格情報の処理 (@pymilvus-bot による)
  • 修正: 検索で numpy 配列の互換性のために明示的な長さチェックを使用する (#3342、#3352) by @pymilvus-bot
  • 修正: UNIMPLEMENTED エラーに対する間違ったポートのガイダンスを明確にする (#3315、#3322) by @pymilvus-bot
  • 修正: SegmentInfo repr で人間が判読できる状態とレベルを表示 (#3336、#3355) by @pymilvus-bot
  • 修正: _types インポートの破損を防ぐために setuptools_scm<9 を固定 (#3348) by @pymilvus-bot

機能と拡張機能

  • feat: support Python 3.14 (#3306, #3318) by @XuanYang-cn

改善点

  • リファクタリング: ディメンション検索の重複を排除するための _get_dim ヘルパーの抽出 (#3344、#3350)
  • リファクタリング: 冗長な raise ex from ex try/excel ブロックを削除 (#3341、#3351)
  • リファクタリング: 重複した common_pb2 インポートを prepare.py に統合 (#3346、#3354)
  • テスト: 単体テスト カバレッジを 83.98% から 90% に改善 (#3313、#3320)
  • 雑用: 廃止された release_event および nightly_ci ワークフローを削除 (#3358) フル Changelog: https://github.com/milvus-io/pymilvus/compare/v2.6.10...v2.6.11

pymilvus v2.6.11

What's Changed

Bug Fixes

  • fix: pass address to GrpcHandler in ConnectionManager strategies — fixed Milvus Lite local path broken since 2.6.10 (#3321, #3323) by @XuanYang-cn
  • fix: prevent "Cannot invoke RPC on closed channel" after connection recovery (#3326, #3345) by @pymilvus-bot
  • fix: correct parameter name typos in QueryIterator causing partition filter bypass (#3324, #3330) by @pymilvus-bot
  • fix: handle None response in search to prevent AttributeError (#3331, #3332) by @pymilvus-bot
  • fix: resolve bytes vector type misidentification in search path (#3334) by @zhuwenxing
  • fix: guard MilvusClient._get_connection against None handler (#3337, #3338) by @pymilvus-bot
  • fix: handle None credentials in connections.connect() (#3343, #3353) by @pymilvus-bot
  • fix: use explicit length check for numpy array compatibility in search (#3342, #3352) by @pymilvus-bot
  • fix: clarify wrong-port guidance for UNIMPLEMENTED errors (#3315, #3322) by @pymilvus-bot
  • fix: display human-readable state and level in SegmentInfo repr (#3336, #3355) by @pymilvus-bot
  • fix: pin setuptools_scm<9 to prevent _types import breakage (#3348) by @pymilvus-bot

Features & Enhancements

  • feat: support Python 3.14 (#3306, #3318) by @XuanYang-cn

Improvements

  • refactor: extract _get_dim helper to deduplicate dimension lookup (#3344, #3350)
  • refactor: remove redundant raise ex from ex try/except blocks (#3341, #3351)
  • refactor: consolidate duplicate common_pb2 import in prepare.py (#3346, #3354)
  • test: improve unit test coverage from 83.98% to 90% (#3313, #3320)
  • chore: remove obsolete release_event and nightly_ci workflows (#3358)

Full Changelog: https://github.com/milvus-io/pymilvus/compare/v2.6.10...v2.6.11
