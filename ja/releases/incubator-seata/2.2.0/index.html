インキュベーターシート v2.2.0

Apache Seata(インキュベート中) 2.2.0 がリリースされました。

Apache Seata(インキュベート) は、使いやすく、高性能な、オープンソースの分散トランザクション ソリューションです。

ダウンロード https://seata.apache.org/download/seata-server

バージョンは以下のように更新されます。

機能:

  • [#6536] ネーミングサーバー client をサポート
  • [#6226] マルチバージョン Seata プロトコルのサポート
  • [#6537] ネーミングサーバーをサポート

incubator-seata v2.2.0

Apache Seata(incubating) 2.2.0 Released.

Apache Seata(incubating) is an easy-to-use, high-performance, open source distributed transaction solution.

Download https://seata.apache.org/download/seata-server
