#チャット開発v1.1.2

重要な変更点

  • ChatDev は OpenAI API を更新し、GPT4-turbo のサポートを追加しました。古い API のサポートは継続していますが、最新のコードを取得し、openai バージョンを更新することを強くお勧めします。
  • online_log モジュールの名前が Visualizer に変更されました。 python3 visualizer/app.py を実行してビジュアライザのデモを開始してください。

新機能

  • Docker サポート (https://github.com/OpenBMB/ChatDev/blob/main/wiki.md#docker-start)
  • インクリメンタル開発サポート ※SRDDデータセット(https://github.com/OpenBMB/ChatDev/tree/main/SRDD)を公開しました

ChatDev v1.1.2

Highlights

  • OpenAI SDK upgrade & GPT-4 Turbo — v1.1.2 moves onto the current OpenAI API and adds a GPT_4_TURBO model option (#277, #262). The legacy API path is retained so existing configs won't hard-fail, but maintainers explicitly recommend pulling latest code and upgrading the openai package — plan that dependency bump and re-verify your model identifier, especially since reported cost is now derived from the selected model (#132), so a turbo swap changes your accounting.

  • Breaking: online_log renamed to visualizer — The demo module was renamed (#303), so any import, script, or path referencing online_log must be updated; launch is now python3 visualizer/app.py. Watch for a naming discrepancy: the changelog says visualizer while PR #303 says chat_visualizer — confirm the actual directory in the tagged tree before wiring anything up.

  • Incremental Development — A new workflow for continuing or extending an existing codebase instead of regenerating from scratch (#246), gated by a config key added in #249. You'll need to add that key or the mode won't activate, and scripts that assume a clean greenfield run may need adjustment.

  • Docker support — A containerized setup path lands in this release (#203, documented in the wiki), removing local Python/dependency friction and making runs reproducible; review how API keys and any GPU needs are handled inside the container.

  • Reliability & logging fixes — ModelBackend now retries GPT-4 calls that hit rate limits/timeouts (#140), reducing flaky long-running generations, and log_arguments string escaping was refactored (#250) — worth a look if anything downstream parses those logs.

  • SRDD dataset — A new requirement/design-document dataset ships alongside the release, useful as a benchmark or fine-tuning corpus for requirement-analysis work.

Important Changes

  • ChatDev now updates the OpenAI API and adds support for GPT4-turbo. While we have retained support for the older API, we highly recommend pulling the latest code and updating the openai version.
  • online_log module is now renamed to visualizer. Please execute python3 visualizer/app.py to start the visualizer demo.

New Feature

  • Docker support (https://github.com/OpenBMB/ChatDev/blob/main/wiki.md#docker-start)
  • Incremental Development support
  • We release a SRDD dataset (https://github.com/OpenBMB/ChatDev/tree/main/SRDD)
