#チャット開発v1.0.1 コミュニティの貢献にとても感謝しています。レビューとテストを行う人員が不足しているため、いくつかの問題を修正し、いくつかの機能を追加しました。その後、できるだけ早く問題に取り組み、更新のペースを維持する予定です。

コミュニティへの貢献

  • 他言語の README: 日本語の README を追加してくださった Eltociear に感謝します。 韓国語の README を追加してくださった Wonhyung Seo に感謝します。
  • GeekyWizKid が初のコミュニティ ソフトウェアを寄稿しました!ルージュっぽいゲームです。
  • Tasha Upchurch は、Windows のテスト フェーズでのエラーの修正に協力してくれました。
  • Munsif Raza も 2 本のソフトウェアを提供しました。
  • コミュニティの貢献者全員に感謝します。

バグ修正と新機能

  • バグ修正：マルチターンチャット（5ターン以上）を実行すると、トークンが制限を超える場合があります。
  • バグ修正: デモを再生すると、Self Improvement フェーズが表示されません。
  • 新機能: 投稿ページを追加。
  • 新機能: ログデモにコピーボタンを追加し、ChatChainVisualizer に色を追加

問題が残っています

コミュニティには、次のような緊急のニーズがまだたくさんあることを私たちは認識しており、私たちはそれに注目し、対処しようとしています。

  • 安全な実行
  • 他のオープンソースまたはローカル LLM のエンドポイント
  • OpenAIサーバーにメッセージを送信する際のさまざまな問題

ChatDev v1.0.1

Highlights

  • Multi-turn token overflow fixed — Chatting beyond five turns could push tokens past the model's limit, causing long agent runs to fail mid-session or silently truncate context. For developers building extended dialogues on ChatDev, this is the most consequential reliability fix in the release: deep, multi-round workflows now complete instead of dying at turn six.

  • SelfImprove phase restored in Replay Demo — The replay viewer previously skipped the SelfImprove phase, so anyone reviewing a run saw an incomplete trace. This matters for debugging and auditing generated software: the iterative refinement loop is now observable end-to-end, making it possible to diagnose why a design converged the way it did.

  • Windows Test Phase error fixed — A platform-specific failure in the Test Phase on Windows (contributed by TashaSkyUp) is resolved. Windows users can now complete the full generate-and-test pipeline rather than hitting a dead end at verification time — worth noting if your CI or local dev box runs Windows.

  • New Contribution Page and demo UX upgrades — A Contribution Page formalizes community recognition, while Log Demo gains a copy button and ChatChainVisualizer gains color coding. For anyone who demos or shares logs, these are practical wins: output is easier to extract, and colored phase chains make the execution flow far quicker to read at a glance.

  • Community signals adoption beyond core team — The first community-contributed software (a roguelike from GeekyWizKid), two more contributions from Munsif Raza, and new Japanese and Korean READMEs show the extension path works and the docs are internationalizing. For adopters, this is evidence that contributed software and non-English onboarding are real, supported routes.

  • Unresolved gaps to plan around — Safe Execution, endpoints for other open-source/local LLMs, and problems sending messages to OpenAI's server are explicitly still open. If your use case depends on sandboxed execution or non-OpenAI backends, treat v1.0.1 as unsuitable for those paths and design workarounds accordingly.

No breaking changes in this release.

We are very grateful for the community's contributions! We are short of people for reviewing and testing and have fixed a few issues and added several features, after which we'll be working on issues as soon as possible and keeping up the pace of updates.

Community Contribution

  • README in other languages: We thank Eltociear for adding the Japanese README. We thank Wonhyeong Seo for adding the Korean README.
  • GeekyWizKid contributed the first community software! It is a rouge-like game.
  • Tasha Upchurch helped us fix an error in the Test Phase on Windows.
  • Munsif Raza also contributed two software.
  • We thank all the community contributors.

Bug Fix & New Feature

  • Bug Fix: When performing multi-turn chatting (more than 5 turns), tokens may exceed the limit.
  • Bug Fix: Replay Demo can't show the SelfImprove Phase.
  • New Feature: Add Contribution Page.
  • New Feature: Add copy button for Log Demo and add color for ChatChainVisualizer

Problems Remained

We know there are still a lot of urgent needs in the community that we have been paying attention to and will try to address, including:

  • Safe Execution
  • Endpoints for other open-source or local LLMs
  • Various problems when sending messages to OpenAI server
