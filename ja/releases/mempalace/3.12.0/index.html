#メンパレスv3.12.0

MemPalace 3.12 は、ソース テキストとバイトをそのまま保持し、中断された再マイニングを回復可能にし、大規模な宮殿の維持に必要な作業を削減します。タイムスタンプとプロジェクト ウィングは、ツールとフック全体で同じルールに従います。 Antigravity にはビジュアルな Palace エクスプローラーが追加され、最終リリース レビューではグラフ ID の衝突、同時チェックポイントの重複、ドキュメント フィルタリング、および最新から順のページネーションが修正されています。

アップグレードに関する注意事項

  • Python 3.10 以降が必要です。 Python 3.9 はサポートされなくなりました。ネイティブ ホイールは Python 3.10+ ABI を使用します。
  • 次の鉱山では、対象となる各ソースを 1 回再読み込みします。 正規化バージョン 3 では、解析とバイト保存の修正が行われます。テキストが変更されていないドロワーは、保存されているベクトルを再利用します。変更されていないファイルには、クローゼットと AAAK サマリーが保持されます。ディスク上に存在しないソースは、既存のドロワーを保持します。アップグレードする前に大きな宮殿をバックアップし、この最初のパスに時間をかけてください。 (#2813)
  • 最初の廊下書き込み時に廊下は SQLite に移行します。 hallways.json はトランザクション的に hallways.sqlite3 にインポートされ、.imported-* 名で保持されます。古いバージョンでは古い JSON ファイルが書き込まれるため、パレスを共有するすべてのインストールをアップグレードしてください。ダウングレード後、mempalace hallways --rebuild を使用して派生廊下を再構築します。 (#2895)
  • 新しいタイムスタンプには明示的な UTC オフセットが含まれます。 従来の単純なタイムスタンプは、書き込まれたときの現地時間として読み取られます。既存のメタデータは書き換えられません。日付のみのフィルターは、依然として現地の暦日を意味します。プロジェクト ウィングでは、CLI、MCP、マイニング、フック全体で 1 つのスラッグ ルールも使用します。フィルタは、保存されている従来のスペルを引き続き検索します。 (#2851、アップグレードの詳細)
  • **ローカル HTTP ハブはトークンなしで実行できます。 ** プレーン ループバック バインドはデフォルトでトークンレスのままで、ブラウザーの起点、ホスト、およびプロキシ ヘッダーのチェックが行われます。プロキシまたはトンネルがトラフィックをハブに転送するたびにトークンを構成します。すべての POST /mcp には Content-Type: application/json が必要になりました。
  • closet_llm 環境変数の名前を、LLM_ENDPOINT、LLM_MODEL、LLM_KEY から MEMPALACE_LLM_ENDPOINT、MEMPALACE_LLM_MODEL、MEMPALACE_LLM_KEY に変更します。外部 LLM エンドポイントには明示的な同意が必要です。 mempalace.dedup と mempalace.onboarding は削除されます。エンベッダーのセットアップには mempalace init --embedding-model ... を使用します。 (#2773)
  • PQL 検索フィルターでは大文字のキーワードが使用されます。 FIND auth IN backend と記述します。小文字の in、limit、source、since、before は検索テキストの一部として残ります。 mempalace_search では、デフォルトの距離カットオフも削除されます。必要な場合は、明示的に max_distance を渡します。 (#2725、完全なアップグレードノート)

ソースの忠実性と回復可能な書き込み

  • 会話マイニングでは、ユーザーのターンが書かれたとおりに保存されます。 スペル修正はデフォルトでオフになっています。 ChatGPT インポートはアクティブな会話ブランチに従い、エクスポートを繰り返すと各ソース ファイルの下にドロワーが保持され、クロード メッセージは空白行が保持され、Gemini テキスト パーツは clients の意図どおりに結合されます。コンテンツを削除または変更する解析ステップは、transforms メタデータに記録されます。 (#2790、#2796、#2800)
  • 非 UTF-8 ソース バイトはマイニングおよびエクスポートに耐えます。 メタデータのエンコーディングにより正確な再構築が可能になります。 MCP client は JSON 互換の表示テキストを受け取りますが、mempalace_get_drawer と include_source_bytes: true は正確なドロワー ソース バイトを Base64 として返します。 NUL 文字と単独のサロゲートはストレージを往復します。 (#2802)
  • 再マイニングは、古いドロワーを削除する前に、代替ドロワーを書き込みます。 書き込みが失敗すると回復可能なテキストが残り、次のマイニングで中断された公開が完了します。日記の取り込みでも同じ順序が使用されます。読めない採掘状態は、空の宮殿と間違われるのではなく、実行を停止するようになりました。 (#2798)
  • ドロワーの更新では、置換されるテキストが保持されます。 以前のテキストとメタデータは置換前に追加され、drawer_revisions.jsonl に同期されます。リビジョンの書き込みが失敗すると、元のドロワーはそのまま残ります。削除すると、対応するリビジョン履歴が削除されます。 PQL ドロワーとダイアリーの書き込みでは、リテラルのエスケープ、スペース、数値に見えるコンテンツも保持されます。 (#2866、#2772)
  • mempalace export <dir> は翼と部屋をマークダウンとしてエクスポートします。 バックエンドの移行と修復では、グラフ データ、クローゼット、サイドカーが保存されます。 (#2779)

パフォーマンスと大きな宮殿

  • sqlite_exact 書き込みは、フルテキスト インデックスのスキャンを停止します。 測定された 336,000 行のパレスでは、50 個のドロワーを追加すると、約 10 秒から 10 ミリ秒に短縮されました。既存のパレスは、次回書き込み可能なオープン時に、不一致のフルテキスト行 ID を 1 回修復します。 (#2744)
  • 廊下の更新により、影響を受ける翼が変更され、記録が変更されます。 830,000 の廊下を備えたコピーされた 228,000 の引き出しの宮殿では、測定された翼のリマイニングは約 20 秒から 1 ～ 4 秒に低下し、ピーク メモリは 3.8 GB から約 150 MB に減少しました。 JSON を初めて輸入する場合でも、一度限りの費用がかかります。 (#2895)
  • インデックス付きの最新順読み取りにより、ウェイクアップとブラウジングが高速化します。 測定された 150,000 ドロワーの sqlite_exact パレスでは、2,000 ドロワーのリーセンシー読み取りが 1.5 秒から 80 ミリ秒に、または翼にスコープを設定した場合は 5 秒から 60 ミリ秒に低下しました。 SQLiteExact および Qdrant メタデータの反復により、オフセット スキャンの繰り返しも回避されます。
  • フォアグラウンドでのフックの消費時間が短縮されます。 ストップフック ダイアリー セーブはバックグラウンドで実行され、ウェイクアップにより、必要になるまで検索スタックのインポートが回避され、stdio MCP サーバーは、変更呼び出しのたびにピア ライター リースを解放して、別のセッションが書き込みできるようにします。 (#2769、#2909)

反重力宮殿の探検家

  • バンドルされた Aux Pane 拡張機能により、Recall、Palace、Graph、Logstream ビューが Antigravity に提供されます。 翼、部屋、トンネルを閲覧し、引き出しを逐語的に検査し、アクティブおよび歴史的な KG の事実を探索し、調整イベントや日記を追跡します。 Recall は、語彙検索、ハイブリッド検索、およびベクトル検索をサポートしており、チャットで引用およびファイルを開くアクションを備えています。 (#2983)
  • 正規プラグイン バンドルは plugins/mempalace にあります。 これには、MCP 設定、リコール ルールとスキル、さらにクロスプラットフォーム Node.js 保存フックとウェイクアップ フックが含まれています。 agy plugin install ./plugins/mempalace を使用してチェックアウトからインストールします。 Python パッケージは依然として前提条件です。 反重力ガイドを参照してください。 (#2984)

リリースレビューによる正確性の修正

  • レガシー グラフのインポートはエンティティのアイデンティティを保持します。 プレビューと適用で正規名を比較し、依存するサブジェクトとオブジェクトの参照を一貫して再マップし、未解決の競合とスキップされたファクトをレポートします。 O'Brien / OBrien および my_project / my project の衝突ケースには、再オープン後の永続性を含む回帰テストがあります。 (#2985)
  • 同時チェックポイントは、互いの重複決定を無効にすることはできません。 重複チェックとドロワーのパブリケーションはシリアル化されたままとなり、埋め込み中に同じメモリが異なるルームに 2 回保存されるのを防ぎます。制御された同時保存回帰が競合をカバーします。 (#2985)
  • Chroma ドキュメント フィルターは元のテキストを評価します。 エスケープされたストレージは、一致する Windows パスを非表示にしたり、エンコード マーカーに一致を作成したりすることがなくなりました。フィルタリングでは、ベクトルクエリの順序が保持され、デコードされたテキストをチェックした後にページネーションが適用されます。 (#2985)
  • Palace ビューア ページは結果セット全体で最新順のままです。 選択されたページは要求された順序でハイドレートされ、Chroma フォールバックはスライスする前に一致するすべてのメタデータを読み取ります。回帰テストは、最適化されたリーダーが使用できないかロックされている場合に、提供されたページネーションのケースと 1,501 個の個別のドロワーの両方をカバーします。 (#2992)
  • Chroma 警告リグレッションは、無関係なクリーンアップ警告を無視します。 CI プローブは、カテゴリおよびメッセージごとに意図された警告をチェックします。 (#2987)

その他の修正とセキュリティ

  • ナレッジ グラフ ツールは 1 つのパス リゾルバーを共有します。 読み取りがサイレントにグラフを切り替えたり、空のグラフを作成したりすることはなくなりました。 mempalace kg import-legacy は明示的なインポートをプレビューし、それを --yes で適用します。 --from はソースを選択します。新しいエンティティ ID では句読点が保持され、エンティティを再追加するとプロパティがマージされ、同一の履歴アサーションの重複が削除されます。 (#2850、#2770、#2605)
  • 新しい Codex ロールアウトが再びマイニングされます。ハブがライター リースを所有している間、ハブ ルートのダイアリー チェックポイントが機能し、完了したフック マイニングは PID スロットを解放します。修復再構築により、FTS5 の整合性が検証され、調整ログが保存されます。 (#2947、#2625、#2943、#2738)
  • モデル プロバイダーは、現在の推論モデル パラメーターを処理します。 人間の呼び出しでは、拒否されたデフォルトの温度が省略されます。 OpenAI 互換の推論は、拒否されたパラメーターなしで再試行を呼び出し、必要な完了トークン フィールドを使用します。 (#2964、#2924)
  • フック、デーモンの子、および serve は、作業ディレクトリのインポートを除外します。 プロジェクト構成の書き込みでは、シンボリック リンクが拒否され、制限された複雑さの一致が無視され、状態ファイルは Windows セーフな再試行で新しい一時ファイルを介して公開されます。
  • 資格情報はリダイレクトと診断テキストから除外されます。 HTTP clients は資格情報を含むリダイレクトを拒否し、エンドポイントのユーザー情報と機密のクエリ パラメーターはマスクされ、外部モデルの呼び出しには明示的な同意が必要です。 (#2858、#2959)
  • MCP と同期の境界により、意図したチェックが強制されます。 ライト サーバー アクションは許可リストに登録され、デーモン ツール ジョブはディスパッチャー ゲートを使用し、ピア イベントとアーティファクトは保存前に検証されます。 Windows ハブはポートを排他的に予約しており、ライターもまた、さまざまなホーム ディレクトリにわたって宮殿に隣接するロックを争っています。
  • ロックされた依存関係は、urllib3、Pillow、pydantic-settings、virtualenv などのアドバイザリ修正を受け取ります。パッケージの要件は変わりません。 (#2960)

mempalace v3.12.0

MemPalace 3.12 keeps source text and bytes intact, makes interrupted re-mines recoverable, and cuts the work needed to maintain large palaces. Timestamps and project wings now follow the same rules across tools and hooks. Antigravity gains a visual Palace explorer, and the final release review fixes graph identity collisions, concurrent checkpoint duplicates, document filtering, and newest-first pagination.

Upgrade notes

  • Python 3.10 or newer is required. Python 3.9 is no longer supported; native wheels use the Python 3.10+ ABI.
  • The next mine re-reads each source it covers once. Normalization version 3 picks up the parsing and byte-preservation fixes. Drawers whose text is unchanged reuse their stored vectors; unchanged files keep their closets and AAAK summaries. Sources no longer on disk keep their existing drawers. Back up a large palace before upgrading and allow time for this first pass. (#2813)
  • Hallways migrate to SQLite on the first hallway write. hallways.json is imported transactionally into hallways.sqlite3 and retained under an .imported-* name. Upgrade every installation sharing the palace, since older versions keep writing the old JSON file. After a downgrade, rebuild derived hallways with mempalace hallways --rebuild. (#2895)
  • New timestamps carry an explicit UTC offset. Legacy naive timestamps are read as local time, as they were written; existing metadata is not rewritten. Date-only filters still mean local calendar dates. Project wings also use one slug rule across CLI, MCP, mining and hooks; filters continue finding stored legacy spellings. (#2851, upgrade details)
  • Local HTTP hubs can run without a token; network access requires one. Plain loopback binds remain tokenless by default, with browser-origin, Host and proxy-header checks. Configure a token whenever a proxy or tunnel forwards traffic to the hub. Every POST /mcp now requires Content-Type: application/json.
  • Rename closet_llm environment variables from LLM_ENDPOINT, LLM_MODEL and LLM_KEY to MEMPALACE_LLM_ENDPOINT, MEMPALACE_LLM_MODEL and MEMPALACE_LLM_KEY. External LLM endpoints require explicit consent. mempalace.dedup and mempalace.onboarding are removed; use mempalace init --embedding-model ... for embedder setup. (#2773)
  • PQL search filters use upper-case keywords. Write FIND auth IN backend; lower-case in, limit, source, since and before stay part of the search text. mempalace_search also drops its default distance cutoff; pass max_distance explicitly when wanted. (#2725, full upgrade notes)

Source fidelity and recoverable writes

  • Conversation mining stores user turns as written. Spell correction is off by default. ChatGPT imports follow the active conversation branch, repeated exports keep drawers under each source file, Claude messages retain their blank lines, and Gemini text parts join as their clients intended. Parsing steps that remove or change content are recorded in transforms metadata. (#2790, #2796, #2800)
  • Non-UTF-8 source bytes survive mining and export. Encoding metadata permits exact reconstruction. MCP clients receive JSON-compatible display text, while mempalace_get_drawer with include_source_bytes: true returns exact drawer source bytes as base64. NUL characters and lone surrogates round-trip through storage. (#2802)
  • Re-mining writes replacement drawers before pruning the old ones. A failed write leaves recoverable text, and the next mine completes interrupted publication. Diary ingestion uses the same ordering; unreadable mining state now stops the run instead of being mistaken for an empty palace. (#2798)
  • Drawer updates preserve the text they replace. Prior text and metadata are appended and synced to drawer_revisions.jsonl before replacement; a failed revision write leaves the original drawer intact. Deletes remove the corresponding revision history. PQL drawer and diary writes also preserve literal escapes, spacing and numeric-looking content. (#2866, #2772)
  • mempalace export <dir> exports wings and rooms as Markdown. Backend migration and repair preserve graph data, closets and sidecars. (#2779)

Performance and large palaces

  • sqlite_exact writes stop scanning the full-text index. On the measured 336,000-row palace, adding 50 drawers dropped from about 10 seconds to 10 milliseconds. Existing palaces repair mismatched full-text row IDs once on their next writable open. (#2744)
  • Hallway updates touch the affected wing and changed records. On a copied 228,000-drawer palace with 830,000 hallways, the measured wing re-mine dropped from about 20 seconds to 1–4 seconds, and peak memory from 3.8 GB to about 150 MB. A first-time JSON import still has a one-off cost. (#2895)
  • Indexed newest-first reads speed up wake-up and browsing. On the measured 150,000-drawer sqlite_exact palace, a 2,000-drawer recency read dropped from 1.5 seconds to 80 milliseconds, or from 5 seconds to 60 milliseconds when scoped to a wing. SQLiteExact and Qdrant metadata iteration also avoid repeated offset scans.
  • Hooks spend less time in the foreground. Stop-hook diary saves run in the background, wake-up avoids importing the search stack until needed, and stdio MCP servers release the peer-writer lease after each mutating call so another session can write. (#2769, #2909)

Antigravity Palace explorer

  • A bundled Aux Pane extension brings Recall, Palace, Graph and Logstream views into Antigravity. Browse wings, rooms and tunnels, inspect verbatim drawers, explore active and historical KG facts, and follow coordination events and diaries. Recall supports lexical, hybrid and vector search, with Cite in Chat and Open File actions. (#2983)
  • The canonical plugin bundle lives at plugins/mempalace. It includes the MCP configuration, recall rules and skills, plus cross-platform Node.js save and wake-up hooks. Install from a checkout with agy plugin install ./plugins/mempalace; the Python package remains a prerequisite. See the Antigravity guide. (#2984)

Correctness fixes from the release review

  • Legacy graph imports preserve entity identity. Preview and apply compare canonical names, remap dependent subject and object references consistently, and report unresolved conflicts and skipped facts. The O'Brien / OBrien and my_project / my project collision cases have regression tests, including persistence after reopening. (#2985)
  • Concurrent checkpoints cannot invalidate each other's duplicate decision. Duplicate checking and drawer publication remain serialized, preventing the same memory from being saved twice into different rooms during embedding. A controlled concurrent-save regression covers the race. (#2985)
  • Chroma document filters evaluate original text. Escaped storage no longer hides matching Windows paths or creates matches on encoding markers. Filtering preserves vector-query order and applies pagination after checking decoded text. (#2985)
  • Palace viewer pages remain newest-first throughout the result set. The selected page is hydrated in the requested order, and a Chroma fallback reads all matching metadata before slicing. Regression tests cover both the supplied pagination cases and 1,501 distinct drawers when the optimized reader is unavailable or locked. (#2992)
  • The Chroma warning regression ignores unrelated cleanup warnings. The CI probe checks the intended warning by category and message. (#2987)

Other fixes and security

  • Knowledge graph tools share one path resolver. Reads no longer silently switch graphs or create an empty graph. mempalace kg import-legacy previews an explicit import and applies it with --yes; --from selects a source. New entity IDs preserve punctuation, re-adding an entity merges properties, and identical historical assertions deduplicate. (#2850, #2770, #2605)
  • Newer Codex rollouts are mined again, hub-routed diary checkpoints work while the hub owns the writer lease, and finished hook mines release their PID slots. Repair rebuilds verify FTS5 integrity and preserve the coordination log. (#2947, #2625, #2943, #2738)
  • Model providers handle current reasoning-model parameters. Anthropic calls omit the rejected default temperature; OpenAI-compatible reasoning calls retry without rejected parameters and use the required completion-token field. (#2964, #2924)
  • Hooks, daemon children and serve exclude working-directory imports. Project configuration writes refuse symbolic links, ignore matching has bounded complexity, and state files publish through fresh temporary files with Windows-safe retries.
  • Credentials stay out of redirects and diagnostic text. HTTP clients refuse redirects carrying credentials, endpoint userinfo and sensitive query parameters are masked, and external model calls require explicit consent. (#2858, #2959)
  • MCP and sync boundaries enforce their intended checks. Light-server actions are allowlisted, daemon tool jobs use the dispatcher gates, and peer events and artifacts are validated before storage. Windows hubs reserve their port exclusively, and writers also contend for a palace-adjacent lock across different home directories.
  • Locked dependencies receive advisory fixes, including urllib3, Pillow, pydantic-settings and virtualenv. Package requirements remain unchanged. (#2960)
