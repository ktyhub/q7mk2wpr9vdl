#2.3.13 Release Note

これは Apache SeaTunnel プロジェクトにとって素晴らしいマイルストーンです。 非常に多くの新機能と修正を備えたバージョン 2.3.13 のリリースにより、ユーザーのデータ統合ワークフローの効率が大幅に向上します。

私たちは、このアップデートに貢献した方々の献身と努力に本当に感銘を受けており、この新しいバージョンがコミュニティに広く歓迎されるものと確信しています。
