#trl v1.10.0

特徴

🎓 DistillationTrainer は安定したトレーナーになりました

データ コントラクト、ロス パス、生成スタック、構成サーフェス、テストを再形成する約 30 PR のリファクタリングの後、DistillationTrainer と DistillationConfig は trl.experimental.distillation から最上位の trl パッケージに卒業します。 SFT / DPO / GRPO / KTO と同じ輸入面。古い実験的なパスはまだ機能しており、FutureWarning (v2.0.0 で削除) を発行します。

# Before
from trl.experimental.distillation import DistillationConfig, DistillationTrainer

# Now
from trl import DistillationConfig, DistillationTrainer

また、trl distillation CLI も着陸し、テストを tests/ に移動します。完全なリファクタリング アーク: 署名列を prompt (非推奨の messages 形式) に切り替え、生成スタックを GRPO に固定し、チャンク化された JSD 損失を接続し、完全なロジット パスを削除し、ライガー パスをクリーンアップしてチャンク化されたパスと抽出を共有し、GRPO の log() / training_step タイミング / _save_checkpoint を採用し、テスト スイートを GRPO 形状に再構築しました。もっとずっと。 約 30 個の PR にわたる @qgallouedec による (#6479、#6480、#6481、#6482、#6484、#6487、#6497、#6508、#6509、#6510、#6511、#6512、#6513、#6521、#6522、#6523、#6524、 #6525、#6526、#6530、#6537、#6604、#6605、#6606、#6607、#6609、#6610、#6611、#6612、#6613、#6614、#6629、#6630、#6632、#6633、#6634、 #6639、#6640、#6641、#6642、#6643、#6644、#6645、#6647、#6653)。

DistillationTrainer は視覚言語モデルをサポートします

卒業と同時に、VLM は DistillationTrainer でエンドツーエンドで動作します。 @qgallouedec 著、https://github.com/huggingface/trl/pull/6650

AsyncGRPO: ループ所有エージェントのトレーニング (OpenEnv ハーネス)

AsyncGRPOTrainer の新しい実験的な ループ所有 (ブラック ボックス) パス - environment_factory ホワイト ボックス パスのように各ターンを駆動する TRL ではなく、独自のツール ループを実行する opencode のような外部エージェントをトレーニングするためのものです。 エージェントは、transparent_proxy モードの OpenEnv セッションで実行されます。サンドボックス内プロキシは、各ターンのトークン ID と logprob をキャプチャします。完了すると、TRL はトレースを読み取り、ターンごとのトレーニング行を再構築し、セッションの verify() でワークスペースにスコアを付けます。呼び出し元が提供する 3 つのポリシー フック (rollout_reward_fn、train_turn_fn、agent_turn_fn) が同梱されているため、フレームワークの補助呼び出し (タイトル ジェネレーター、コンテキスト サマライザー) を削除して、必要なターンのみを強化できます。 Qwen3-4B でエンドツーエンドで検証された、自己完結型の examples/scripts/openenv/opencode.py (ローカル サブプロセス サンドボックス + DeepCoder が保持する stdin/stdout 検証器) が含まれています。 @AmineDiro による https://github.com/huggingface/trl/pull/6420, と HF サンドボックスのバリアント、@sergiopaniego による https://github.com/huggingface/trl/pull/6565

DiffusionGemma ブロック拡散 SFT の例

参照レシピを実装する google/diffusiongemma-26B-A4B-it の新しい SFT 例: ステップごとに 1 つの応答ブロック、t ~ U(eps, 1) による均一なランダムなトークン破損、2 パスの自己調整、キャンバス全体にわたるフラットなクロスエントロピー、およびエンコーダー上の自己回帰共損失。 LoRA は、注意力と高密度の MLP リニアをターゲットとしています。 transformers >= 5.12.0が必要です。 diffusion_gemma.jinja / diffusion_gemma_training.jinja チャット テンプレート ({% generation %} マーカー付き) が同梱されているため、assistant_only_loss=True はそのまま使用できます。 @kashif 著、https://github.com/huggingface/trl/pull/6003

🎓 DistillationTrainer is now a stable trainer

After a ~30-PR refactor that reshaped its data contract, loss path, generation stack, config surface, and tests, DistillationTrainer and DistillationConfig graduate from trl.experimental.distillation to the top-level trl package. Same import surface as SFT / DPO / GRPO / KTO. The old experimental path still works and emits a FutureWarning (removal in v2.0.0).

# Before
from trl.experimental.distillation import DistillationConfig, DistillationTrainer

# Now
from trl import DistillationConfig, DistillationTrainer

Also lands a trl distillation CLI and moves the tests to tests/. The full refactor arc: switched signature columns to prompt (deprecated messages-format), pinned the generation stack to GRPO's, wired the chunked JSD loss and deleted the full-logit path, cleaned the Liger path to share extraction with the chunked path, adopted GRPO's log() / training_step timing / _save_checkpoint, rebuilt the test suite to GRPO shape, and much more.

AsyncGRPO: loop-owning agent training (OpenEnv harness)

New experimental loop-owning (black-box) path for AsyncGRPOTrainer — for training external agents like opencode that run their own tool loop, rather than TRL driving each turn as in the environment_factory white-box path.

The agent runs in an OpenEnv session in transparent_proxy mode; an in-sandbox proxy captures each turn's token ids and logprobs. On completion, TRL reads the trace, rebuilds per-turn training rows, and scores the workspace with the session's verify(). Ships with three caller-supplied policy hooks (rollout_reward_fn, train_turn_fn, agent_turn_fn) so you can drop framework aux calls (title generator, context summarizer) and reinforce only the turns you want.

Includes a self-contained examples/scripts/openenv/opencode.py (local subprocess sandbox + DeepCoder held-out stdin/stdout verifier), validated end-to-end on Qwen3-4B.

by @AmineDiro in https://github.com/huggingface/trl/pull/6420, plus HF-sandbox variant by @sergiopaniego in https://github.com/huggingface/trl/pull/6565
