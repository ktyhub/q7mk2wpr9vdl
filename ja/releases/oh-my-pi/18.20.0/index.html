#オーマイパイv18.20.0

@oh-my-pi/pi-agent-core

変更されました

  • prepareCompaction() は compaction.prepare ループ フェーズとして実行されるため、コールド トークンによる ui.loop-blocked のストールは、「不明」ではなく長いブランチ名の圧縮を経由します (#15027、#18867 by @wolfiesch)

@oh-my-pi/pi-ai

追加

  • Google の Gemini Decisions API (gemini-decision-1) に、テキストと画像入力による google-decisions 判定 API を追加しました (#19060 by @kevcube)
  • oauth.accessById() および oauth.accessAll() からの成功した OAuthAccessResolution 結果に apiKey を追加しました。これは、そのアカウントに対して送信される主要な通常リクエストです。これは、構造化された資格情報を持つプロバイダーの accessToken とは異なります (@Xytronix による #19030)
  • オプションの exemptionAlias を ToolCallLoopGuard に追加し、トランスポート呼び出しが exemptTools のディスパッチされたツール名と一致できるようにしました (#18860)
  • Liquid AI の意思決定モデルに liquid-systemone 判定 API を追加しました。これは、送信前に Liquid の 10,000 の 32×32 パッチ リクエストの上限を超える画像セットを拒否します (@SuperUserA による)
  • Nace の Drex 決定モデルに nace-systemone 判定 API を追加しました。これは画像を Drex のトップレベル images データ URL として送信し、Drex が判定テキストで拒否した Base64 画像、音声、ビデオ、PDF データ URL を説明付きで置き換えます (#18950 by @alphastorm)

修正済み

  • 兄弟が要求されたモデルのみを拒否した場合に、使用済みの Codex アカウントが数日間毎分再試行する問題を修正しました。その短いモデル ポリシー ブロックは、使用可能になった兄弟としてカウントされなくなりました。そのため、使用済みのアカウントのリセットに続いて使用制限の待機が発生し、モデルのフォールバックが引き継ぐことができます (@wolfiesch による #17637、#19019)
  • 認証ゲートウェイ client トークン (serve --clients) は、リクエストの発信者、支払い者、またはゲートウェイがプロバイダーに到達する方法を設定できなくなりました。チャット ルートはリクエスト ヘッダー、userProfileId、initiatorOverride、metadata、serviceTier、cacheRetention、およびその他のゲートウェイのみのオプションをドロップしますが、ゲートウェイ トークンはそれらを保持します。 (#19067 by @alphastorm)
  • 他のチャット ルートが受け入れる認証ゲートウェイの /v1/pi/stream が taskBudget、include、anthropicPrefixMismatchBehavior をドロップする問題を修正しました (#19067 by @alphastorm)
  • Vertex AI Mistral パートナー モデル (mistral-medium-3、mistral-small-2503、codestral-2) へのリクエストが Anthropic のリクエスト形式 (@yuzu-octopus による #19010、#19022) で送信されたために失敗する問題を修正しました。
  • Gemini xhigh の思考レベルを追加しました。これは、Gemini API と、はしごがそれを公開するモデル (Gemini 4 Hydrogen) の Vertex に送信されます。
  • ~/.aws がディレクトリではなくファイルの場合に ENOTDIR: not a directory, stat '~/.aws/credentials' で起動できない omp を修正しました (@iamshatter による #19083)

@oh-my-pi/pi-coding-agent

重大な変更

  • secrets.yml 正規表現ルールは Rust になりました。 regex パターンは線形時間でネイティブに実行されます。ルックアラウンドと後方参照はサポートされなくなり、(?P<secret>…) グループは編集する部分をマークします (周囲のテキストはコンテキストとして残ります)。 \d、\w、および \s は Unicode 対応です。コンパイルされない正規表現ルールは、スキップされるのではなく、ファイルとエントリの命名エラーで起動を停止します。 (?<=password=)\S+ を password=(?P<secret>\S+) に移行します。 docs/secrets.md (#18965 by @H4vC) を参照してください。
  • シークレット プレースホルダーはフレンドリ名の後の 4 つのキャメルケースの単語になりました。 GitHubToken_correctHorseStapleBattery ($$ 区切り文字なし)、およびモデルが書き込んだ場所に実際の値がトランスクリプトに表示されます。古い $$NAME_HASH:CASE$$ フォームのプレースホルダーは、この変更前に保存されたセッションでは、モデルがコピーするツール呼び出しを含め、リテラル テキストのままです。新しいセッションを開始して、動作するプレースホルダーを取得します (#19014 by @H4vC)
  • モデルがプレースホルダーから書き込んだもの (応答、思考、ツール呼び出し、要約) は、書き込まれたものと再生されたものがバイト同一として保存され、思考の署名とプロンプトのキャッシュが有効に保たれます。値を保持しているモデル出力 (リダクションがオフになっている間、またはシークレットが設定される前に書き込まれたもの) は、再生時にリダクションされます。正規表現ルールによって後で検出される値は、以前の履歴を書き換えなくなります。 friendlyName は書かれたとおりにモデルに表示され、それ自体の秘密 (@H4vC による #19014) を詳しく説明する場合にのみ削除されます。
  • withAppleFm = false を使用した Nix ビルドは、ホストの Xcode で Apple Foundation Models ブリッジをコンパイルしなくなりました (#18911)
  • Apple Silicon Nix ビルドには、Apple Foundation Models サポートなしでサイレント ビルドするのではなく、Apple Foundation Models サポートが含まれています (#16584 by @honsunrise)
  • フォーム ダイアログのない RPC ホスト上の ask では、質問のみではなく、フォームの周囲の段落、リスト、事前にフォーマットされたブロック、表を含む各プロンプトが表示されるようになりました (#18927)

  • コンピューター ヘルパーは、不明なオプションとフィルター キーを黙って無視するのではなく拒否するようになりました。これには、選択した wait または要素 press オーバーロードで使用されていないキーも含まれ、有効なキーと可能性のあるスペル修正に名前を付けます (@will-bogusz による #18753)
  • Chromium ベースのブラウザー タブ上のセレクター待機とそのフレームは、ライブ スナップショット参照やナビゲーションにまたがる待機を含む、Puppeteer の visible/hidden フォームとともに state: "attached" | "detached" | "visible" | "hidden" を受け入れるようになり、未知のオプション、無効な値、または競合する表示フラグを黙って無視するのではなく拒否します。フレーム待機タイムアウトは、同じ実行の後でキャッチ可能なままです。 Tern と cmux のタブは変更されていません (#18924 by @will-bogusz)
  • Chromium メインワールドの waitForFunction は、「待機失敗」で拒否するのではなく、初期の待機後にナビゲーション全体で再武装を呼び出します (#18884 by @will-bogusz)
  • Chromium ブラウザのタブでは、非表示の一致の tab.hover および要素ハンドル hover() は、一致が表示されるのを待ち、表示されない場合は、Puppeteer の「ノードが clickable または要素ではありません」ですぐに失敗するのではなく、clicks のように理由 (およびセレクターの一致数) で失敗します。 (#18750 by @will-bogusz)
  • ブラウザ tab.console() または tab.errors() の結果を配列として扱うと、slice is not a function ではなく .entries を読み取るようにというメッセージが表示されて失敗し、ブラウザのドキュメントには { entries, nextSeq, dropped } の形状が記載されています (@will-bogusz による #18738)
  • 印刷されたブラウザー tab.observe() 結果には、tab.run() (elements 配列を持つ任意のオブジェクトではない) を通じて返された完全な観測結果、または JavaScript Eval セルの最後の値として残された結果が含まれており、最初の 100 とそれに続く ... N more items ではなく、すべての要素が 1 行ずつ表示されます。インプレースのプロトタイプ編集を含む、返された後に変更された観測は、すべての要素が含まれたプレーンな検査出力として出力されます (#18772 by @will-bogusz)

変更されました

  • シークレットの編集はリクエストごとに会話全体を再スキャンしなくなりました。以前のリクエストですでに編集されたテキストは、新しいシークレットによって結果が変わるまで再利用され、secrets.yml 正規表現ルールは先頭のリテラルが欠落しているテキストをスキップし、大規模なセッションでの編集をリクエストごとに 17 ～ 55 ミリ秒から約 1 ミリ秒に削減し、ロード後の最初のリクエストは 2 ～ 4 倍に短縮します。
  • デフォルトのシステム プロンプトを削除しました。ツール選択ルールは read、edit、find のみを指すようになりました。推論形式、AST、およびサブエージェント制限のガイダンスはなくなりました (ast_edit/ast_grep は独自の概要で好みを述べています)。ワークフロー、配信、および重要なルールが短くなり、相互に繰り返されなくなりました。ツールの結果がどのように形成されるかについての Spotlight の注記は、最後の段落ではなく、ツール I/O の下の短いリストです。 xd:// デバイスは裸の名前でリストされます
  • edit.modelVariants は、最初のモデル パターンではなく、最長一致するモデル パターンを選択するようになりました。そのため、構成の順序に関係なく、openai/gpt-5 のような特定のキーが gpt よりも優先されます (@DeprecatedLuke による #17835)
  • エンジン ABKit がインストールされている場合 (Windows の ~/.o2/lib/abkit/ABHost、ABHost.exe、Tern も使用する場所、または browser.webkitPath 設定 / PI_BROWSER_WEBKIT_PATH)、マネージド Chromium ではなく、omp 独自のヘッドレス WebKit エンジンでブラウザ タブが開きます。ページには自動化フラグのないフォーカスされたウィンドウが表示され、デフォルトのタブではページ内の omp スクリプトが実行されません (コンソール、エラー、リクエスト ログは、エンジン; route、地理位置情報/ロケール/オフライン エミュレーション、vitals および reactEnable は呼び出されたときにのみページ コードを追加します。 Chromium は依然として headed タブを開き、エンジンがビューアを搭載せず、エンジンが起動できない場合にその理由を表示します。 app: "chromium" は開くときに Chromium を選択し、app: "webkit" には WebKit が必要です (headed: true ではタブがウィンドウで開きます)。browser.webkit 設定または PI_BROWSER_WEBKIT=0 により WebKit がオフになります。 macOS では、エンジンには WebGL、WebGPU、サイレント ビデオとオーディオの再生、Web オーディオ、WebRTC、WebAuthn、ゲームパッド、Web 共有があり、TLS ハンドシェイク、HTTP/2 設定、リクエスト ヘッダーは Safari が送信するものです。
  • omp は、WebKit エンジンである ABKit を build.stencil.so から ~/.o2/lib/abkit (ビルドの SHA-256 と照合してチェック) にダウンロードします (app: "webkit" が見つからない場合、ブラウザがインストールされていないことが判明した場合は Chrome for Testing の前に)。ダウンロードに失敗すると、Chromium で開いたままになり、その理由が表示されます
  • task ツールの説明には、配信ルールのみがリストされるようになりました (結果の自動配信、wait、未検証の completed)。 read proc://、write proc://<id>/kill、job-expiry、および write agent:// 参照は、セッションの最初の生成結果とともに到着します。
  • ask.timeout 設定、README、および RPC スキーマのドキュメントでは、ask ツールが、オプションを自動選択する質問ピッカーではなく、タイムアウト時に現在の値を送信する HTML フォームとして説明されるようになりました。
  • bash ツールの説明には、組み込みシェルのインプロセス ビルトインがシェルから直接リストされているため、すべての PI_DISABLE_* スイッチとプラットフォームに従います。
  • SQLite、アーカイブ、JSON クエリ、実行可能ファイル、ビデオ、SVG 用の read セレクター、および proc://、ssh://、issue:///pr:// のサブパス文法は、すべてのリクエストに同梱されなくなりました。モデルは、xd://read/sources および xd://read/urls でオンデマンドでそれらを読み取り、次の場合にインラインに留まります。 read はオフです
  • /browser visible と /browser headless は、次に開くのを待つのではなく、omp の WebKit タブのウィンドウを一度に表示および非表示にするようになりました。エンジンがビューア (macOS) を出荷する場合、各タブには独自のウィンドウがあり、ユーザーは click、スクロール、入力することもできます。headed: true または browser.headless がオフの場合は、Chromium に送信する代わりにウィンドウで WebKit 上のタブを保持します。 Chromium タブは、次に開くとモードが変わります
  • エンジンが DOM をネイティブに読み取る Tern では、ブラウザー observe、セレクター、clicks、タイピング、要素の読み取りと待機でページ内のスクリプトが実行されなくなりました。エンジンは (フレームおよび閉じたシャドウ ルート全体で) 要素を検索し、すべてのアクションは解決された時点で trusted 入力されます。次に、type は、click が配置するキャレットに入力し、text/ セレクターは大文字と小文字を無視します。
  • ブラウザーのスクリーンショットのテキストは、バイト サイズと形式を含む 4 行ではなく 1 行 (モデルが表示するサイズ、保存されたときのフルサイズのファイル、および tab.clickAt の座標係数) であり、browser.open は、タブ、要求された URL ではない場合に表示されるページ (ナビゲーションの正規化された URL 比較を使用)、およびタイトルを 1 行で報告します (#18776 by @will-bogusz)
  • RPC select リクエストには initialIndex、selectionMarker、checkedIndices、markableCount が含まれるため、ホストは、ユーザーがブラインドで切り替えられるのではなく、どの ask チェックボックス オプションがすでにチェックされているかを表示できます (#18929 by @andrebrait)
  • すべての言語サーバーがファイル監視を omp に渡すようになりました (TypeScript 7 のみでした)。サーバー上に watchFiles: false を設定して、独自のウォッチャーを維持します
  • 失敗した JavaScript Eval セルは、エラー メッセージとセル自体のフレームを出力します。ホスト スタック全体ではなく、omp のランタイム、その依存関係、およびエンジンからの隠れたフレームを 1 行でカウントします。プロジェクトローカルの依存関係フレームは表示されたままになり、ヘッダーがエラーと一致しなくなったキャッシュされたスタックはそのまま残り、フローティング拒否はキャッシュされたスタックがあっても現在のメッセージと missing-await ヒントを保持し、catch 内の print(e.stack) は引き続きすべてのフレームを表示します (@will-bogusz による #18775)
  • Snapcompact 圧縮は、フレーム形状をプリフライトで一度解決し、それを compact() に渡し、auto 形状設定で再導出します。プリフライトはトランスクリプトを 2 回ではなく 1 回スキャンし、compaction.snapcompact ループ フェーズとして実行し、レンダリング前にイベント ループに移行します (@wolfiesch による)
  • 完全なセッション ファイルの書き換え (プルーニング、イメージ ドロップ、レスキュー スタンピング) は session.rewrite ループ フェーズとして実行されるため、そのストールは ui.loop-blocked ログに記録されます (@wolfiesch による #15027、#18867)

修正済み

Breaking Changes

  • secrets.yml regex rules are now Rust regex patterns run natively, in linear time: lookarounds and backreferences are no longer supported, and a (?P<secret>…) group marks the part to redact (text around it is context that stays); \d, \w and \s are Unicode-aware. A regex rule that does not compile stops startup with an error naming the file and entry instead of being skipped. Migrate (?<=password=)\S+ to password=(?P<secret>\S+); see docs/secrets.md (#18965 by @H4vC)
  • Secret placeholders are now four camelCased words after the friendly name, e.g. GitHubToken_correctHorseStapleBattery, with no $$ delimiters, and the transcript shows the real value wherever the model wrote one. Placeholders in the old $$NAME_HASH:CASE$$ form, in sessions saved before this change, stay literal text, including in tool calls the model copies them into; start a new session to get working placeholders (#19014 by @H4vC)
  • What the model writes from placeholders (replies, thinking, tool calls, summaries) is stored as written and replayed byte-identical, keeping thinking signatures and prompt caches valid; model output that still holds a value (written while redaction was off, or before the secret was configured) is redacted on replay. Values a regex rule finds later no longer rewrite earlier history. A friendlyName is shown to the model as written and is dropped only when it spells out its own secret (#19014 by @H4vC)
  • Nix builds with withAppleFm = false no longer compile the Apple Foundation Models bridge with the host's Xcode (#18911)
  • Apple Silicon Nix builds include Apple Foundation Models support instead of silently building without it (#16584 by @honsunrise)
  • ask over RPC hosts without a form dialog now shows each prompt with the form's surrounding paragraphs, lists, preformatted blocks and tables instead of only the question (#18927)

  • Added omp bench --account to benchmark a specific stored OAuth account, and report rejected priority requests instead of silently benchmarking standard speed.
  • Text a browser or computer call types into a page or app, such as a password, no longer appears in plain text in an eval cell's status lines or the session file (#18981 by @will-bogusz)
  • Browser page-script observations in Tern and WebKit now mask password values, including values used as accessible names or descriptions (#18983 by @will-bogusz)

  • On macOS a computer run that ends while secure input is on now starts with a note naming the app holding it and saying the user's Escape and typing go unseen until it ends, instead of nothing while capabilities() still reported globalEscape: true (#18982 by @will-bogusz)

Frame wait timeouts remain catchable later in the same run; Tern and cmux tabs are unchanged (#18924 by @will-bogusz)
  • Chromium main-world waitForFunction calls rearm across navigation after an earlier wait instead of rejecting with "Waiting failed" (#18884 by @will-bogusz)
  • In Chromium browser tabs, tab.hover and element-handle hover() on a hidden match now wait for it to appear and, if it never does, fail with the reason (and a selector's match count), as clicks do, instead of failing at once with Puppeteer's "Node is either not clickable or not an Element" (#18750 by @will-bogusz)
  • Treating the result of browser tab.console() or tab.errors() as an array now fails with a message saying to read its .entries, instead of slice is not a function, and the browser docs state the { entries, nextSeq, dropped } shape (#18738 by @will-bogusz)
  • A printed browser tab.observe() result, including a full observation returned through tab.run() (not arbitrary objects with an elements array), or one left as a JavaScript Eval cell's last value, shows every element, one line each, instead of the first 100 followed by ... N more items; an observation changed after it returned, including in-place prototype edits, prints as plain inspect output, every element included (#18772 by @will-bogusz)

Changed

  • Secret redaction no longer rescans the whole conversation on every request: text already redacted in an earlier request is reused until a new secret changes the outcome, and secrets.yml regex rules skip text missing their leading literal, cutting redaction on a large session from 17–55 ms to about 1 ms per request and the first request after loading by 2–4×
  • Trimmed the default system prompt: the tool-choice rules now only point to read, edit and find; the reasoning-format, AST and subagent-limit guidance is gone (ast_edit/ast_grep state their preference in their own summaries); the workflow, delivery and critical rules are shorter and no longer repeat each other; Spotlight's note on how tool results are shaped is a short list under Tool I/O instead of a paragraph at the end; and xd:// devices are listed by bare name
  • edit.modelVariants now picks the longest matching model pattern instead of the first, so a specific key like openai/gpt-5 wins over gpt whatever the config order (#17835 by @DeprecatedLuke)
  • Browser tabs open in omp's own headless WebKit engine instead of managed Chromium when the engine, ABKit, is installed (~/.o2/lib/abkit/ABHost, ABHost.exe on Windows, the location Tern uses too; or the browser.webkitPath setting / PI_BROWSER_WEBKIT_PATH): pages see a visible, focused window with no automation flag, and a default tab runs no omp script in the page (console, errors and the request log come from the engine; route, geolocation/locale/offline emulation, vitals and reactEnable add page code only when called; response bodies are unavailable there). Chromium still opens headed tabs where the engine ships no viewer and takes over, saying why, when the engine cannot start; app: "chromium" picks Chromium for one open and app: "webkit" requires WebKit (with headed: true its tab opens in a window), and the browser.webkit setting or PI_BROWSER_WEBKIT=0 turns it off. On macOS the engine has WebGL, WebGPU, silent video and audio playback, Web Audio, WebRTC, WebAuthn, gamepads and Web Share, and its TLS handshake, HTTP/2 settings and request headers are the ones Safari sends
  • omp downloads its WebKit engine, ABKit, from build.stencil.so into ~/.o2/lib/abkit (checked against the build's SHA-256) for app: "webkit" when it is missing, and before Chrome for Testing when an open finds no browser installed; a failed download leaves that open on Chromium and says why
  • The task tool description now lists only the delivery rules (results auto-deliver, wait, unverified completed); the read proc://, write proc://<id>/kill, job-expiry and write agent:// reference arrives with the session's first spawn result
  • The ask.timeout setting, README and RPC schema docs now describe the ask tool as an HTML form that submits its current values on timeout, not a question picker that auto-selects an option
  • The bash tool description lists the embedded shell's in-process builtins again, straight from the shell, so it follows every PI_DISABLE_* switch and the platform
