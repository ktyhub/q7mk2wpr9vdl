#オーマイパイv18.20.1

@oh-my-pi/pi-agent-core

修正済み

  • 推論履歴を省略するリクエストのコンテキスト コスト見積もりを修正したため、ツール呼び出しのために送信または再構築された場合にのみ、請求見積もりに思考テキストが含まれるようになりました。

@oh-my-pi/pi-ai

追加

  • setUnpausedProviders() を @oh-my-pi/pi-ai/oauth に追加し、アプリケーションが認証ルールによって一時停止されたプロバイダーを再度有効にできるようにします。ロードされた認証情報プールと拡張機能ログインは、次回の読み取り時に変更を認識します。

変更されました

  • v1beta1 API を使用するように Vertex AI Gemini リクエストを更新し、長い Gemini レスポンスのサポートを復元しました。
  • Google Antigravity クォータの回復が改善され、Gemini の共有容量が利用可能な場合にクォータまたはプランの変更後に Gemini 4 Argon アクセスを再開できるようになりました。
  • us-east-1 にフォールバックする前に、設定されたリージョン エンドポイントを尊重するように Amazon Bedrock リージョン選択が改善されました。

修正済み

  • Google、Vertex AI、Gemini CLI、Antigravity 全体で単一の出力セグメントを超える Gemini 4 応答を修正し、長い応答が生成され続け、1 つの完全な応答として配信されるようにしました。
  • カーソル会話を修正し、フックで追加されたプロンプト コンテンツが現在のユーザー メッセージに残り、会話のコンテキストがターンを超えて正しく保持されるようにしました。
  • Amazon Bedrock ストリーミングを修正し、不正な応答が即座に失敗し、中断された応答は完了したものとして扱われずに再試行されるようになりました。
  • 使用状況レポートに共有使用ウィンドウが 1 つしか含まれていない場合のクロード アカウントの回復を修正しました。
  • モデルを切り替えるときに推論コンテキストが保持されるように、OpenRouter と Kim および DeepSeek との会話を修正しました。
  • バンドルまたはキャッシュされた構成からロードされたモデルを含む、正しい地域エンドポイントを使用するように Xiaomi MiMo トークン プラン認証を修正しました。
  • ログイン フローおよびセットアップ ウィザードでの Perplexity サインイン (電子メール コードとブラウザベースの SSO 認証を含む) を修正しました。
  • ネイティブ ジャッジが、他の一時的な 502 エラーに対する再試行を保持しながら、上流の資格情報の枯渇によって引き起こされるゲートウェイ エラーを再試行することを停止しました。
  • サポートされているプロバイダーが停止シーケンスと頻度ペナルティ設定を受信できるように、単純な完了と認証されたゲートウェイ チャット ルートを修正しました。
  • 資格情報の変更、キーのローテーション、またはアイドル再開後の Muse セッションを修正し、後続のターンが通常どおり続行できるようにしました。

@oh-my-pi/pi-catalog

追加

  • Google Antigravity に Gemini 4 Hydrogen を、選択可能な低、中、高、xhigh の思考レベルを備えた単一モデルとして追加しました。価格は 100 万トークンあたり $1.50/$7.50 です。
  • ライブ モデル検出と CHUTES_API_KEY を使用した /login chutes 認証によるシュート プロバイダーのサポートを追加しました。

変更されました

  • Google Antigravity の一時停止: ログインは利用できなくなり、プロバイダーが再度有効になるまで、保存された認証情報は使用されません。代わりに、Google AI Studio または google-vertex プロバイダーで GEMINI_API_KEY を使用してください (#18341)。
  • Claude Haiku 5.5、GPT-6.1 Sol および Terra、Grok 4.7、および Claude Sonnet 5.5 のロングコンテキスト価格帯を含む、プロバイダーの現在の料金に一致するようにコマンド コード モデルの価格設定と使用状況レポートを更新しました。
  • Gemini API および Vertex AI の Gemini 4 アルゴン、カーボン、水素の最大出力が 262,144 トークンに増加し、大幅に長い応答が可能になりました。
  • OpenCode Go Claude Haiku 5.5 を更新し、明示的思考の障害を含む、低レベルから最大レベルまでの思考レベルをサポートしました。
  • 現在の安定バージョンである Devin CLI 3000.12.57 として識別するように Devin リクエストを更新しました。

修正済み

  • コマンド コードの Gemini 4 Argon を修正し、画像の添付ファイルが保存され、使用量が入力トークン 100 万あたり 2 ドル、出力トークン 100 万あたり 10 ドル、キャッシュ読み取りトークン 100 万あたり $0.10 で正しく請求されるようにしました (@wolfiesch による #19125)。
  • Bedrock または Snowflake セッション中に思考レベルを変更した後、次のターンで Factory Droid GPT-6 モデルが失敗する問題を修正しました (#19188 by @will-bogusz)。
  • ワークスペースに制限された API キーの OpenRouter モデル リストを修正し、各キーが正しい許可されたモデル一覧を表示し、独立したモデル キャッシュを維持できるようにしました (@YibaiMeng による #19013)。
  • OpenCode Go Muse Spark ツール呼び出しでステップ間の暗号化された推論が失われる問題を修正しました (@nico2525nn による #17748)。
  • Vertex AI Gemini 3 以降のモデルが思考シグネチャのないリプレイまたはクロスモデル ツール呼び出しを拒否する問題を修正しました (#17150 by @duck1eee)。
  • GLM 5.3 や Grok 4.7 (@joseotaviorf による #18248) など、プロバイダーが利用できるモデルを省略するカーソル モデルのリストを修正しました。

@oh-my-pi/pi-coding-agent

追加

  • 他のエージェントとユーザーの作業を保持しながら、エージェントまたは選択したサブエージェントによって行われた変更のみを含むコミットを作成するための /commit を追加しました。このワークフローは eval commit 名前空間を通じても利用でき、セッション ディレクトリの外部にあるリポジトリのターゲットをサポートし、バイナリ ファイルと非 UTF-8 ファイル、シンボリック リンク、ファイル モードの変更、初期コミットを処理し、オプションで no_verify によるコミット フックをスキップできます。無効にするには、commit.enabled を使用します。
  • auth.unpausedProviders (一時停止されていないプロバイダー 設定) を追加し、保存されているログイン状態を維持しながら、Google Antigravity などの一時停止されたプロバイダーを自己の責任で再度有効にします。
  • todo.midRunNudges を介して、設定可能なロングターン ToDo リマインダーを追加しました。これには、リマインダーを無効にする、リマインダーを 2 つに制限する、または間隔を増やして継続するオプションが含まれます。
  • スタイル付きコンテンツをコンポーザーに貼り付けると、マークダウン形式が保持され、埋め込まれた画像が元の位置に配置されますが、エディターからコピーされたコードはプレーン テキストのままです。
  • /clear がセッション ID を変更せずに現在のセッション コンテキストをリセットするときに発行される session_clear フックおよび拡張イベントを追加しました。
  • パス スコープの Bash 許可ルール、プロジェクトと構成のオーバーレイの優先順位、bash.allowedEnvVars およびルールごとの env 設定による環境変数制御を追加しました。
  • サブエージェントは、モデルを継承するときに @upstream プロバイダーの固定を保持するようになりました。
  • Ctrl+R 履歴から Delete キーを使用して個々のプロンプトを削除できるようになりました。
  • アクティブなモデルのプロバイダー外の補助サービスを制限または無効にするための --no-judge、--no-spotlight、および --offline オプションを追加しました。
  • リマインダーの繰り返しを制御するために、ルールごとの TTSR repeatMode 設定 (once、after-gap、または always) を追加しました。
  • Bash 承認プロンプトでは、複合コマンド セグメントが個別に表示され、どのセグメントが許可されているか、または承認が必要かを識別できるようになりました。
  • Todo done、drop、および rm オペレーションは、正確に一致するタスク名を分割することなく、改行、セミコロン、カンマ、またはスペースで区切られた入力を含む複数のタスクを 1 つのリクエストで受け入れるようになりました。
  • 複数のターゲットが関係している場合、Todo ステータス行にタスク数が表示されるようになりました。

変更されました

  • /fork および fork-from-transcript はアクティブな応答を中止し、すぐにフォークするようになりました。
  • 一致する行のみを表示し、ファイルごとの一致を制限することで、デフォルトの grep 出力を削減しました。周囲のコンテキストを含めるように grep.contextBefore および grep.contextAfter を構成します。
  • より深い結果分析とランク付けの向上のために、より高いリクエスト コストで、デフォルトの spotlight.thinking レベルを low から med に変更しました。
  • Spotlight が有効になっている場合、一般に、追加のソース ファイル タイプのサポートを含め、アウトラインの前にソースと発行またはプルリクエストのコンテンツがより完全に再読み込みされます。

修正済み

  • /loop は、レート制限などのプロバイダー エラーの後に、同じプロンプトを再送信して @file メンションを再度添付するのではなく、一時停止するようになりました (#19272)。
  • ディレクトリが削除されたセッションを再開すると、失敗するのではなく警告が表示され、現在のディレクトリで続行されるようになりました。
  • モデルのメンションと /switch の完了は、起動時にプロバイダーの検出が失敗した後、検出されたモデルを回復し、必要に応じて検出を再試行するようになりました。
  • ACP プロンプトの終了後に到着するバックグラウンド ジョブの結果は、目に見えないターンを開始するのではなく、次のプロンプトに引き継がれるようになりました。
  • OpenAI サーバーの圧縮が失敗した場合、別のモデルでサーバーの圧縮を再試行するのではなく、次に利用可能な圧縮方法に進むようになりました。
  • 言語サーバーは、macOS を含め、ファイルの作成直後に行われた編集を認識するようになりました。
  • 擬似シェル ビューに表示される Bash コマンドは、ヒアドキュメント、置換、ループ、継続、算術式、およびバックグラウンド実行を通じてストリーミングしている間も正確なままになりました。
  • セッションを再開するか、思考サフィックス (:xhigh など) を使用した再試行フォールバック後にサブエージェントを復活させると、フォールバックの思考レベルを保持するのではなく、プライマリ モデル自体の思考レベルが復元されるようになりました (#19273)。

@オーマイパイ/コラボウェブ

修正済み

  • 再参加に失敗した後、ゲストが古いエージェント、ツール カード、および動作状態を保持する問題を修正しました。ゲストは再接続時に現在のセッション状態を確実に復元できるようになりました。

@oh-my-pi/pi-natives

重大な変更

  • lsTree() を変更して、裸のパスの代わりに { path, mode } エントリを返すようにしました。 mode は git ls-tree の出力と一致します (たとえば、100755 または 120000)。

追加

  • commitCreate() オプションに noVerify を追加し、git commit --no-verify と一致するように、pre-commit フックと commit-msg フックをスキップします。
  • commitCreate() にオプティミスティック同時実行性と代替インデックスのサポートを追加しました。これにより、コミットで別のインデックスを使用し、HEAD が変更されたときに古いコミットを拒否できるようになります。
  • ネイティブのフォールバック動作と既存のストリーミング、フィルタリング、およびリンク追跡オプションを維持しながら、利用可能な場合はサービング デーモンを使用することにより、ovnfs チェックアウトの grep() および glob() のパフォーマンスが向上しました。

変更されました

  • ローカル ファイル システムとネットワーク ファイル システム全体にわたるシェル検索の改善: ローカル検索はネットワーク マウントを予期せず走査することを回避し、ネットワークを利用した検索はより多くのディレクトリ操作を同時に実行し、fd は無視、プルーニング、深さ、ワーカー、およびエラー報告オプションとともに並列走査をサポートします。

修正済み

  • Latin-1 などの非 UTF-8 テキストに対して diffText({ binary: true }) および diffNoIndex(…, true) によって生成されるバイナリ パッチを修正しました。これにより、パッチは元のバイトを保持し、正しく適用されます。
  • 一般的なフォント ファミリが使用できないフォントを参照する場合の SVG レンダリングを修正し、<text> 要素が消えるのを防ぎました。
  • 追跡されたディレクトリがシンボリックリンクに置き換えられる場合を含む、読み取り専用のファイルまたはディレクトリを含むソース チェックアウトに対するワークツリーの追加を修正しました。
  • キャンセルおよびタイムアウトした Shell.run 呼び出しを修正し、後の実行のためにシェル セッションを保持しながら、その呼び出しによって開始されたジョブのみを終了するようにしました。
  • 長い複数行のシェル コマンドを視覚化する際のメモリ使用量が削減されました。
  • シェルの cp ビルトインを修正し、再帰や属性の保存を無効にすることなく、シンボリックリンクをたどるオプションがアーカイブ モードやディレクトリ コピー モードで正しく動作するようにしました。
  • [ ] 内の非常に長い -a/-o チェーンでの組み込みシェルのクラッシュと、過度に深い式の明らかなエラーを伴うテスト式を置き換えました。

oh-my-pi v18.20.1

@oh-my-pi/pi-agent-core

Fixed

  • Corrected context cost estimates for requests that omit reasoning history, so billing estimates now include thinking text only when it is sent or reconstructed for a tool call.

@oh-my-pi/pi-ai

Added

  • Added setUnpausedProviders() to @oh-my-pi/pi-ai/oauth, allowing applications to re-enable providers paused by authentication rules; loaded credential pools and extension logins recognize the change on their next read.

Changed

  • Updated Vertex AI Gemini requests to use the v1beta1 API, restoring support for long Gemini responses.
  • Improved Google Antigravity quota recovery so Gemini 4 Argon access can resume after quota or plan changes when shared Gemini capacity is available.
  • Improved Amazon Bedrock region selection to honor a configured regional endpoint before falling back to us-east-1.

Fixed

  • Fixed Gemini 4 responses that exceed a single output segment across Google, Vertex AI, Gemini CLI, and Antigravity, ensuring long responses continue generating and are delivered as one complete reply.
  • Fixed Cursor conversations so hook-added prompt content remains in the current user message and conversation context is correctly preserved across turns.
  • Fixed Amazon Bedrock streaming so malformed responses fail promptly and interrupted responses are retried rather than treated as complete.
  • Fixed Claude account recovery when usage reports contain only one shared usage window.
  • Fixed OpenRouter conversations with Kimi and DeepSeek so reasoning context is preserved when switching models.
  • Fixed Xiaomi MiMo Token Plan authentication to use the correct regional endpoint, including for models loaded from bundled or cached configuration.
  • Fixed Perplexity sign-in in the login flow and setup wizard, including email-code and browser-based SSO authentication.
  • Stopped native judges from retrying gateway errors caused by exhausted upstream credentials while retaining retries for other transient 502 errors.
  • Fixed simple completion and authenticated gateway chat routes so supported providers receive stop-sequence and frequency-penalty settings.
  • Fixed Muse sessions after credential changes, key rotation, or idle resume so subsequent turns can continue normally.

@oh-my-pi/pi-catalog

Added

  • Added Gemini 4 Hydrogen on Google Antigravity as a single model with selectable low, medium, high, and xhigh thinking levels, priced at $1.50/$7.50 per million tokens.
  • Added Chutes provider support with live model discovery and /login chutes authentication using CHUTES_API_KEY.

Changed

  • Paused Google Antigravity: login is no longer available and stored credentials are not used until the provider is re-enabled. Use GEMINI_API_KEY with Google AI Studio or the google-vertex provider instead (#18341).

Added

  • Added /commit to create commits containing only changes made by the agent or a selected subagent, while preserving other agents’ and the user’s work. The workflow is also available through the eval commit namespace, supports targeting repositories outside the session directory, handles binary and non-UTF-8 files, symlinks, file mode changes, and initial commits, and can optionally skip commit hooks with no_verify; use commit.enabled to disable it.
  • Added auth.unpausedProviders (the Unpaused Providers setting) to re-enable paused providers such as Google Antigravity at your own risk while preserving their stored login state.
  • Added configurable long-turn todo reminders through todo.midRunNudges, including options to disable reminders, limit them to two, or continue with increasing intervals.

  • Added the session_clear hook and extension event, emitted when /clear resets the current session context without changing its session ID.

  • Subagents now preserve @upstream provider pinning when inheriting models.
