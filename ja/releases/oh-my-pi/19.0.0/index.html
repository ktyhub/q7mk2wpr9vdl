oh-my-pi v19.0.0

#オーマイパイv19.0.0

@oh-my-pi/pi-agent-core

追加

  • モデル コンテキストおよび圧縮またはブランチ サマリーからカスタム メッセージを除外するためのサポートが追加されました。同時に、キューに入れられたステアリング メッセージとフォローアップ メッセージが除外されたメッセージの後に正しく続行できるようになりました。

@oh-my-pi/pi-ai

追加

  • 課金対象の出力を生成せずにプロンプト キャッシュを更新するための、Anthropic Messages リクエストの prewarm ストリーム オプションを追加しました。予算の考え方、強制的なツールの選択、構造化された出力のために拒否されます。
  • クロード使用状況レポートには、metadata.subscriptionPlan のアカウント サブスクリプション プランが含まれるようになり、最大 5 倍、最大 20 倍、プロ、チーム、およびエンタープライズ プランをサポートします。
  • retryUnreachableBroker および onBrokerRetry オプションを discoverAuthStorage に追加しました。これにより、ホストは、一時的に利用できない認証ブローカーの起動再試行を制御し、再試行ステータスを表示できるようになります。

修正済み

  • 週ごとの共有使用制限が回復した後のクロード アカウントのフェイルオーバーを修正し、使用状況レポートにそのウィンドウが表示されなくなったときにアカウントが再び利用可能になるようにしました。
  • 認証ブローカーの起動では、最大 30 秒間の再試行によって一時的なブローカーの再起動と接続の中断が許容されるようになりましたが、拒否されたトークンや不正な形式のスナップショットに対してはすぐに失敗します。
  • 不明な認証情報、使用法、観察された使用法のフィールドと値を許容することにより、client とブローカーのバージョン間の認証ブローカーの互換性が向上しました。
  • Codex Spark 使用量メーターを修正し、metered_feature によってのみメーターを識別するレポートが Spark モデルに正しくスコープされたままになるようにしました。
  • gemini-4-hydrogen-high のみが提供されている場合に gemini-4-hydrogen を解決するなど、利用可能な ID にエフォート サフィックスが含まれるモデルに対する反重力 CLI リクエストを修正しました。

@oh-my-pi/pi-catalog

追加

  • isPromptCachePrewarmSupported 互換機能を介して、ファーストパーティの Anthropic エンドポイントでのプロンプト キャッシュの事前ウォーミングのサポートが追加されました。

修正済み

  • 32 を超える質問を評価する際の、TypeSafe、OpenRouter、コマンド コード、および OpenCode Zen のホストされた判定リクエストを修正しました。
  • プロバイダーの制限内でより多くの会話イメージをサポートするために Devin イメージの処理が改善され、請求されたトークンの使用量を反映するために Devin Gemini モデルのイメージ圧縮が更新されました。
  • プロモーション終了時にモデルがプロモーション価格からリスト価格に切り替わるように、Devin Gemini モデルの価格を修正しました。
  • Kiro API キー認証 (KIRO_API_KEY および ksk_…) を修正し、モデルのリスト、チャット、および /usage リクエストが正しく動作するようにしました。

@oh-my-pi/pi-coding-agent

重大な変更

  • SDK キャッシュ ウォーミング制御の変更: createAgentSession.cacheWarming はモード キャップ「オフ」、「ストリーミング」、または「アイドル」を受け入れるようになりました。この値と、providers.cacheWarming のうち低い方が適用されます。 false の代わりに「off」を使用してください。
  • アーティファクト://N リンクを、セッションの local:// ルートにある読み取り可能、一覧表示可能、および完全可能な local://N.log ファイルに置き換えました。既存のセッション内の artifact:// リンクは移行されません。
  • session.handoff(focus) を session.compact(focus, { mode: "handoff" }); に置き換えました。キャンセルするにはabortCompaction()を使用してください。
  • プロジェクト固有のブローカーではなく、ユーザーごとの 1 つのデーモンの下に共有バックグラウンド プロセスを統合しました。古いバージョンのデーモンとサービスは採用されません。 omp ps は、グローバル、プロジェクト、セッション単位をまとめてレポートし、--global を削除し、--json 出力を {daemon, reports} に変更し、dsm:// ハンドルに ?project= を追加しなくなりました。
  • SDK deferSkillDescriptionCompression の名前を deferHintCompression に変更し、startSkillDescriptionCompression() の名前を startHintCompression() に変更しました。これらの設定とメソッドは、MCP 名前空間のヒントもカバーするようになりました。

追加

  • Codex Desktop の node_repl の置き換えを含む、組み込みの MCP 変換を追加しました。組み込みは mcp.builtinTransforms で無効にできます。 /mcp list は置き換えられたサーバーを識別し、/mcp enable node_repl は明示的にサーバーに接続できます。
  • mcp.evalNamespaces を通じてオプションの MCP eval 名前空間を追加し、サーバーを JavaScript および Python 名前空間として公開し、ドキュメントは xd://eval/<server> にあります。結果はテキストと構造化データを保持し、バイナリ リソースは local:// ファイルとして保存されます。
  • /tan エージェントとそのトレイ カードにモデル生成の名前が追加され、名前付けが失敗またはタイムアウトした場合の読み取り可能なランダム フォールバックが追加されました。
  • 長いツール呼び出しキープアライブや有効期限前のプロンプト圧縮など、構成可能なキャッシュウォーミング戦略 (自動、キープアライブ、コンパクト) を追加しました。キャッシュウォーミングイベントは、選択されたメソッドとコストを報告するようになりました。
  • オプションのタスク間タスク検出と task.crossInstance によるメッセージングを追加し、agent://peers を通じて同じフォルダーのインスタンスを公開しました。
  • 追加モード: ? で始まるドラフト/btw の質問として送信すると、明確な UI 指示が表示されます。
  • サブエージェントとバックグラウンド ジョブを実行するための Tern ライブ カード (進行状況、ツール数、ステータス、コントロール、トランスクリプト、完了したエージェントへの復元されたアクセスなど) を追加しました。
  • デーモン更新の存続と、OMP_DAEMON_TCP を介したオプションの TCP ホスティングを追加し、デーモンのアップグレード全体で実行中のサービス、PTY、および言語サーバーを保持します。
  • Speech-to-Text および Text-to-Speech モデルをマシンごとに 1 回ロードし、15 分間非アクティブになった後にアンロードします。
  • ovnfs ワークツリーのサポートを /wt、プロジェクト再開ピッカー、および omp ワークツリー list/clear に追加しましたが、チェックアウト削除後にソース リポジトリからのセッション再開は保持されました。
  • omp 使用量と /usage 出力に Claude サブスクリプション プランを追加しました。
  • バックグラウンドスキル説明と MCP 名前空間ヒント生成の進行状況レポートを追加しました。
  • excludeFromContext を pi.sendMessage ペイロードに追加したため、拡張機能はモデルに送信せずにターンごとのメッセージを表示および保存できます。
  • 認証ブローカーが再起動するか、一時的に使用できない場合に、CLI および印刷モード コマンドに対する 30 秒の再試行ウィンドウを追加しました。
  • バックグラウンド コマンドおよび名前付きサービスからの一致する出力をレポートしたり、アイドル セッションを解除したり、ブロックされた待機を終了したりするための通知オプションを bash ツールに追加しました。

変更されました

  • Anthropic 互換プロバイダーのキャッシュ ウォーミングが改善され、サポートされている場合は出力なしの事前ウォーミングが行われ、実際の再生コストに基づいて課金されます。タスク サブエージェントは、ストリーミング ウォーミングが有効な場合、長いツール呼び出し中にプロンプ​​ト キャッシュをウォーム状態に保つようになりました。
  • スキルの説明と MCP 名前空間のヒントをマシンごとに 1 回生成し、omp ウィンドウ全体で結果と進行状況を共有します。
  • モデルを切り替えるときに思考レベルを保持し、選択したモデルが現在のレベルをサポートできない場合にのみ調整します。モデルのデフォルトは、レベルが設定されていない場合にのみ適用されます。
  • セッションのプロンプト キャッシュの有効期間を使用するために繰り返し応答とサブエージェントの待機を延長し、必要に応じて、サブエージェントの待機がライブ親の次のメッセージに続くようにしました。
  • 現在の応答と新しく到着するメッセージを保持しながら、/handoff をバックグラウンド圧縮として実行するようにしました。
  • 質問プロンプトをコンポーザーの上の単一のスクロール フォームとして再設計し、部分的な回答を保持し、ユーザーがメッセージを送信することで保留中の質問をスキップできるようにしました。
  • デフォルトで作曲家の予測を有効にし、ターンが完了した後にアクティブなモデルが提案する次のメッセージを表示します。 「設定」→「インタラクション」で無効にします。
  • 印刷、RPC、ACP、および SDK セッションでのツール呼び出しインテント トレースがデフォルトで無効になりました。 tools.intentTracing または PI_INTENT_TRACING で有効にします。
  • ovnfs チェックアウト ガイダンスと git Guard メッセージを更新し、変更を着陸、プル、または破棄する方法を説明しました。
  • サブエージェントの完了プローブとサイドリクエストが改善され、成果物に焦点を当て、単純な履歴として静止ストリーミング推論が含まれないようになりました。
  • 5 秒間の最初のアイドル待機とそれに続く 4 分間の連続待機に待機動作を標準化しました。
  • サブエージェントには常に共有 LSP ツールを提供します。 task.enableLsp は、LSP フォーマットと編集の診断のみを制御するようになりました。
  • セッション環境の継承、セッション ファイルの URL サポート、より明確な準備状況の検証、およびより透明性の高い最小化された出力により、bash サービス、PTY、および組み込みシェルが改善されました。
  • ウィンドウ内で実行するときのマネージド Chromium に明確な名前を付け、ブラウザ、スクリーンショット、アップロード、フレーム、セレクター、ネットワーク、およびタブとブラウザ バックエンドにわたる CDP の動作を改善しました。
  • 逐語的に置き換えられるボディ、より安全な範囲とパスの検証、より明確な解析と構文診断、より大きなファイルと SSH ファイルのサポート、およびより予測可能な RAW 読み取りと行セレクターによるハッシュライン編集の改善。
  • 10 分のツール呼び出し期限、進捗報告時の期限の延長、タイムアウトと接続エラーの明確化、HTTP セッションの期限切れ後の 1 回の再試行により、MCP の信頼性が向上しました。
  • ファイル検査、アーカイブ、プロセス制御、環境ロード、ファイル監視、ロック、音声認識、ファイルを開く、パッチ適用などの一般的なワークフローに対するポータブルな組み込みと内部 URL サポートを備えた組み込みシェルを拡張しました。
  • LSP とデバッグ診断、言語範囲、ワークスペース検出、参照、名前変更、コード アクション、およびサーバー ライフサイクル レポートが改善されました。

Fixed

  • Authentication broker startup now tolerates temporary broker restarts and connection interruptions by retrying for up to 30 seconds, while still failing immediately for rejected tokens or malformed snapshots.
  • Improved authentication broker compatibility across client and broker versions by tolerating unknown credential, usage, and observed-usage fields and values.
  • Fixed Codex Spark usage meters so reports that identify the meter only by metered_feature remain correctly scoped to the Spark model.

Daemons and services from older versions are not adopted; omp ps now reports global, project, and session units together, removes --global, changes --json output to {daemon, reports}, and no longer adds ?project= to dsm:// handles.

IP addresses, localhost, LAN short names, local network domains, and Tailscale names remain supported; configure reverse-proxy or other custom domains with OMP_STATS_ALLOWED_HOSTS, including wildcard subdomains such as *.example.com.

@oh-my-pi/pi-tui

Breaking Changes

  • Full-output references and the [raw output: …] footer now use local://N.log instead of artifact://N.

Added

  • Added the btw composer mode, including the btwMode theme color in all bundled themes.
  • Added feature-gated native docking for runtime children, allowing components to appear only on terminals that advertise the required capability.
  • Added options to preserve intraword underscores when stripping inline Markdown and to open JobsSheet on a selected job.
  • Custom message payloads can now be excluded from model context while remaining available in normalized and restored saved entries.
  • Added transcript blocks for output reported by running background jobs and services.

Changed

  • Reworked ask dialogs into a single stacked flow: the active question stays open while answered questions fold into compact summaries with their selected options visible. This applies across terminal and native interfaces and improves keyboard navigation, sizing, and host composer integration.
  • Improved composer behavior while an ask dialog is pending: the composer indicates that typing there will skip the question, folds to a compact state when appropriate, and offers an explicit Skip & send action for drafts that bypass the ask.
  • Added support for folded and faint composer states and clearer visual indication when the interface is awaiting an answer.
  • Model search now supports provider/model queries, prioritizing exact provider matches and searching that provider's model IDs first.

Fixed

  • Improved background-job notices in Tern by grouping all output under one header and showing the complete lines.
  • Fixed Tern composer handling of -> and => so typing them no longer unexpectedly inserts a line break.
  • Fixed web search results without a synthesized answer to show each source once with a concise cleaned excerpt.
  • Fixed long Tern tool-approval prompts so their details scroll within the available window and the choices and Approve/Deny controls remain visible.
  • Fixed table chart unit display and change-factor calculations for measurements with scaled units.
  • Fixed checkbox groups so pressing Enter with nothing selected first checks the focused box.
  • Ask forms now open each question with its preselected answer, allowing Enter to accept the recommendation without replacing it.

@oh-my-pi/pi-utils

Added

  • Added utilities for formatting and parsing session spill URLs using the local://N.log format.
  • Added postmortem.exitCleanlyOnStopSignals() so long-running services exit successfully after completing cleanup on SIGINT or SIGTERM.

Fixed

  • Fixed Windows shell discovery incorrectly selecting the WSL bash.exe launcher, which could cause services to run under WSL.
  • Fixed archive opening so the extraction-size limit is enforced when an oversized member is read rather than preventing access to the entire archive.
  • Fixed OMP_LOG_LEVEL so it also controls console output from services such as omp auth-broker serve, not just log-file output.
  • Fixed Markdown parsing so emphasis and link labels are not prematurely terminated by marker characters inside code spans, autolinks, inline HTML tags, or link destinations.

@oh-my-pi/pi-wire

Added

  • Added tray state and interaction properties, including focus, peek, quiet, main status, item references, card status and actions, and event state.
  • Added layout transition properties to nodes for coordinating layout animations.
  • Added support for folding a dock composer into its compact row.
