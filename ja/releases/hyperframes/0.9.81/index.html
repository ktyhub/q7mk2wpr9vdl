ハイパーフレーム v0.9.81

ハイパーフレーム v0.9.81

2026 年 11 月 22 日にリリースされました。 重いページがメモリ不足にならずにレンダリングされるようになりました。レンダリングは、適切な数のブラウザだけで開始されます。シールドされたプレビューでは、移動や切り抜きから元に戻すやホットキーに至るまで、さらに多くの編集を行うことができます。

修正

  • スタジオ: スタジオは、実際のプレスまたは click (3ac5265aac、#8503) の後にのみ、シールされたプレビューのキー レポートに基づいて動作します。
  • コア: 長さが設定されていない数百の clips のプレビューでは、それらすべてが読み込まれなくなりました (d4e8d6f983、#8303)。
  • スタジオ: カット全体をスクラブすると、黒ではなく最新のフレームが表示されます (0e6879b8ef、#8501)。
  • スタジオ: プロジェクトの構成 (45674e840f、#8490) の 1 つではないファイルのコピーと複製は拒否されます。
  • スタジオ: シールされたプレビューの clips は、GSAP 移行ラベル (97b90d8fa2、#8499) を保持します。
  • スタジオ: フレーム スワップを介して保持される封印されたプレスは、表示されているフレーム (a770f4b85d、#8492) で開始されます。
  • スタジオ: 同じファイル (0b73069201、#8483) からのものでない限り、貼り付けと複製の書き込みのみが許可されます。
  • スタジオ: シールドされたプレビューでレイヤーを回転すると、スタイルシートに示されている角度からレイヤーが回転します (039eca4f0f、#8469)。
  • スタジオ: 以下に適合しないメニューは上に開きます。開いたメニューの上に開くことはありません (679a5a7e0b、#8406)。
  • スタジオ サーバー: カットは、ファイル自体の ID (fccd00e719、#8481) から新しい半分に名前を付けます。
  • Ci: 結果がアップロードされなかったシャードは再実行され、編集精度の低下として読み取られることはありません (71588b0a73、#8477)。
  • スタジオ: 貼り付けられた要素は、スクリプト内ではなく、独自のオリジナルの後に配置されます (bfd6cb755f、#8489)。
  • コア: プレビュー シークは、グレーディングされた各ビデオが新しいフレームを描画するまで待機します (104eab37ad、#8488)。
  • コア: ランタイムが解放するはるか clip は、映画の長さの中でカウントされ続けます (5ae70826ed、#8480)。
  • プレイヤー: ランタイムの開始時に、シールされたフィルムの読み込みに失敗したことが表示されなくなりました (835e660e0e、#8472)。
  • スタジオ: 密閉されたプレビューには、Studio のデコーダー (61008a40dd、#8466) からの一時停止されたビデオ フレームが表示されます。
  • スタジオ: 拒否された編集の背後にあるドラッグは、clip (c99cbbe44d、#8456) に到達する場合にのみ拒否されます。
  • スタジオ: トリミングされたレイヤーのシールドされたレイヤー選択により、サイズ変更のコーナーがレイヤー全体に配置されます (f57552da49、#8468)。
  • Ci: キャプチャ チェックを再実行すると、PR の現在の本体 (8f7e59742f、#8479) が読み取られます。
  • スタジオ: シールされた移動またはサイズ変更は、保存自体のフレーム メッセージでドラフトを終了します (7e26a6d3c0、#8473)。
  • コア: パスに沿ってトゥイーンするページにのみモーション パス プラグインをロードします (4157992664、#8449)。
  • スタジオ: getter がスローする名前のスローされた値は、依然としてリロードにフォールバックします (f51e57b26e、#8474)。
  • エンジン: 重いページは、マシンのメモリが保持する数のキャプチャ ブラウザのみを起動します (969eeba6ee、#8452)。
  • スタジオ: プロジェクトの切り替え前にキューに入れられたタイムライン編集は、独自のプロジェクトに残ります (3e101f9654、#8458)。
  • スタジオ: シールされたクロップは、レイヤーのインセットを独自のスケールで描画し、シークに従います (05d1bc8b1c、#8451)。
  • スタジオ: スローするインプレース トゥイーン パッチには、リロードに戻った理由が記載されています (e98ca56c4a、#8454)。
  • スタジオ: シールされたサイズ変更では、自己中心化レイヤーがその場所に保持されます (926e1b5601、#8467)。
  • スタジオ: シールされたページの最初の編集を追加する元に戻すまたはやり直しは、所定の位置に残ります (2d72e523ff、#8462)。
  • スタジオ: 要素を非表示にすると、シールされているかどうかに関係なく、プレビューでその要素が非表示になります (d37563e35b、#8461)。
  • スタジオ: 拒否された編集の背後にキューに入れられたリップル シフトは、書き込み前に拒否されます (56e0d6fbd7、#8443)。
  • スタジオ: 再ロードされたプレビューには、元に戻したグレードではなく、保存されたグレードが表示されます (5e6068e94a、#8455)。
  • スタジオ: シールされたキャンバス ピックは、それが属するタイムライン clip (ff01d81be1、#8459) を選択します。
  • Studio: シールされたプレビューで押されたキーは、Studio のホットキー (34d5c4678d、#8444) に到達します。
  • CLI: クラッシュした、またはエンコーダが失敗したレンダリングは、デスクトップにそのコード (678fda62cd、#8434) を伝えます。
  • スタジオ: プレビュー clip のトラックは整数としてのみ取得されます (bf21bf9f78、#8447)。
  • スタジオ: プロパティ パネルで作成したカラー グレードはファイル (77f3b55fd3、#8450) に保存されます。
  • スタジオ: 要素の移動とナッジは、シールドされたプレビューで機能します (eea73b3107、#8263)。
  • 共有: 名前は端末にプレーン テキストとして出力され、保存された所有者のアドレスは実際のアドレス (d09a1809c1、#8341) である必要があります。
  • スタジオ: プレビューのタイムライン clips は数値フィールドを保持し、それらを数値としてドロップ書き込みします (59ea053f10、#8438)。
  • スタジオ: キャプション編集は、プロジェクトのファイル ライター (0774d96462、#8445) を通じて保存されます。
  • スタジオ: プレビュー clip のトラック、開始および長さは、数値 (e1845e5dec、#8446) としてのみタイムラインに入力されます。
  • スタジオ: トポロジ レンズは、密封されたプレビューに表示されます (79e43a33a8、#8420)。
  • メディアの使用: 共有または別のルートを指定するマニフェスト パスは、確認せずに拒否されます (2a24357338、#8437)。
  • スタジオ: 拒否された削除は、その背後にキューに入れられたリップル シフト (925cea1f1f、#8421) も拒否します。
  • スタジオ: 諦めたリロードでは、フレームが見つからないか、空白であるか、または読み取り不能であるかどうかが示されます (8ad7cbae24、#8419)。
  • スタジオ: タイムラインにシールされたコンポジションの clip を表示します (28502224a5、#8408)。
  • メディアの使用: 予約、書き込み、または録音する前に、.media の下のリンクを拒否します (0495a57f76、#8327)。

ドキュメントと例

  • README: HyperFrames が作成するものを主導し、すべての開発者セクション (84ff7d71c2、#8442) を保持します。

内部

  • CLI: 1 つのシェルで PowerShell ラウンドトリップ名を実行し、遅い Windows ランナーが間に合うようにします (680c9a5402、#8498)。
  • CLI: ドクター出力テストは、すべてのマシン チェックで実行されなくなりました (aa262c244d、#8497)。
  • スタジオ: プレビュー回帰は、封印されたプレビュー (3a68f7b3ca、#8470) に対して緑色で実行されます。
  • スタジオ: 編集精度ベンチは、封印された保存と取り消しの後にユーザーが何を終了したかを読み取ります (bc3d7b43e8、#8475)。
  • スタジオ: プレビュー回帰では、macOS ガンマ フィルター (154842851a、#8484) ではなく、デコードされたカバーがカウントされます。
  • Windows: ステップの期限内に収まるように、エンジンと CLI テストを 2 つではなく 3 つのシャードで実行します (a638c31aa1、#8476)。
  • スタジオ: プレビュー clip の番号とトラック ルールは 1 か所に存在します (deb478a3f6、#8471)。
  • スタジオ: Chrome 駆動テストは単体テストの後に単独で実行されます (c731046c77、#8440)。
  • 目に見える効果のないスタジオ変更は、どのサイズでもそう言えます (a0b76d20fb、#8439)。
  • CLI: スナップショット内の見逃した後期 SVG 画像には、どの待機が不足したかが示されています (826b4fcc69、#8435)。

hyperframes v0.9.81

HyperFrames v0.9.81

Released on 2026-11-22.

A heavy page now renders without running out of memory: a render starts only as many browsers as fit. Sealed previews take more edits in place, from moves and crops to undo and hotkeys.

Fixes

  • Studio: Studio acts on a sealed preview's key report only after a real press or click (3ac5265aac, #8503).
  • Core: A preview of hundreds of clips with no set length no longer loads them all (d4e8d6f983, #8303).
  • Studio: Scrubbing across a cut shows the newest frame, not black (0e6879b8ef, #8501).
  • Studio: Copy and duplicate refuse a file that is not one of the project's compositions (45674e840f, #8490).
  • Studio: A sealed preview's clips keep their GSAP transition label (97b90d8fa2, #8499).
  • Studio: A sealed press held across a frame swap starts on the frame shown (a770f4b85d, #8492).
  • Studio: Paste and duplicate write only allowed markup unless it comes from the same file (0b73069201, #8483).
  • Studio: Rotating a layer in a sealed preview turns it from the angle its stylesheet shows (039eca4f0f, #8469).
  • Studio: A menu that does not fit below opens above, never over what opened it (679a5a7e0b, #8406).
  • Studio Server: A cut names its new half from the file's own id (fccd00e719, #8481).
  • Ci: A shard whose results never uploaded is re-run, and never read as an edit accuracy drop (71588b0a73, #8477).
  • Studio: A pasted element lands after its own original, never inside a script (bfd6cb755f, #8489).
  • Core: A preview seek waits for each graded video to draw its new frame (104eab37ad, #8488).
  • Core: A far clip the runtime lets go of keeps counting in the film's length (5ae70826ed, #8480).
  • Player: A sealed film no longer shows failed to load while its runtime starts (835e660e0e, #8472).
  • Studio: A sealed preview shows paused video frames from Studio's decoder (61008a40dd, #8466).
  • Studio: A drag behind a refused edit is refused only when it would land on a clip (c99cbbe44d, #8456).
  • Studio: A sealed Layers pick of a cropped layer puts its resize corners on the whole layer (f57552da49, #8468).
  • Ci: A rerun of the captures check reads the PR's current body (8f7e59742f, #8479).
  • Studio: A sealed move or resize ends its draft in the save's own frame message (7e26a6d3c0, #8473).
  • Core: Load the motion path plugin only for a page that tweens along a path (4157992664, #8449).
  • Studio: A thrown value whose name getter throws still falls back to a reload (f51e57b26e, #8474).
  • Engine: A heavy page starts only as many capture browsers as the machine's memory holds (969eeba6ee, #8452).
  • Studio: A timeline edit queued before a project switch stays in its own project (3e101f9654, #8458).
  • Studio: A sealed crop draws a layer's insets at its own scale and follows a seek (05d1bc8b1c, #8451).
  • Studio: An in-place tween patch that throws says why it fell back to a reload (e98ca56c4a, #8454).
  • Studio: A sealed resize keeps a self-centring layer where it is (926e1b5601, #8467).
  • Studio: An undo or redo that adds a sealed page's first edit stays in place (2d72e523ff, #8462).
  • Studio: Hiding an element hides it in the preview, sealed or not (d37563e35b, #8461).
  • Studio: A ripple shift queued behind a refused edit is refused before it writes (56e0d6fbd7, #8443).
  • Studio: A reloaded preview shows the saved grade, not one an undo took back (5e6068e94a, #8455).
  • Studio: A sealed canvas pick selects the timeline clip it belongs to (ff01d81be1, #8459).
  • Studio: A key pressed in a sealed preview reaches Studio's hotkeys (34d5c4678d, #8444).
  • CLI: A crashed or encoder-failed render tells Desktop its code (678fda62cd, #8434).
  • Studio: A preview clip's track is taken only as a whole number (bf21bf9f78, #8447).
  • Studio: A colour grade made in the property panel saves to the file (77f3b55fd3, #8450).
  • Studio: Moving and nudging an element works in a sealed preview (eea73b3107, #8263).
  • Share: Names print as plain text in the terminal, and a saved owner address must be a real address (d09a1809c1, #8341).
  • Studio: Timeline clips from the preview keep numeric fields, and drops write them as numbers (59ea053f10, #8438).
  • Studio: Caption edits save through the project's file writer (0774d96462, #8445).
  • Studio: A preview clip's track, start and length enter the timeline only as numbers (e1845e5dec, #8446).
  • Studio: The topology lens shows in a sealed preview (79e43a33a8, #8420).
  • Media Use: A manifest path naming a share or another root is refused without looking at it (2a24357338, #8437).
  • Studio: A refused delete also refuses the ripple shifts queued behind it (925cea1f1f, #8421).
  • Studio: A reload that gives up says whether its frame was missing, blank or unreadable (8ad7cbae24, #8419).
  • Studio: Show a sealed composition's clip on the timeline (28502224a5, #8408).
  • Media Use: Refuse links under .media before reserving, writing or recording (0495a57f76, #8327).

Docs & Examples

  • README: Lead with what HyperFrames makes, keep every developer section (84ff7d71c2, #8442).

Internal

  • CLI: Run the PowerShell round-trip names in one shell so slow Windows runners stay in time (680c9a5402, #8498).
  • CLI: The doctor output test no longer runs every machine check (aa262c244d, #8497).
  • Studio: The preview regression runs green against a sealed preview (3a68f7b3ca, #8470).
  • Studio: The edit-accuracy bench reads what a person ends with after sealed saves and undos (bc3d7b43e8, #8475).
  • Studio: The preview regression counts decoded covers, not the macOS gamma filter (154842851a, #8484).
  • Windows: Run the engine and CLI tests in three shards, not two, to stay under the step deadline (a638c31aa1, #8476).
  • Studio: A preview clip's number and track rules live in one place (deb478a3f6, #8471).
  • Studio: Chrome-driven tests run alone after the unit tests (c731046c77, #8440).
  • A studio change with no visible effect can say so at any size (a0b76d20fb, #8439).
  • CLI: A missed late SVG image in snapshot says which wait came up short (826b4fcc69, #8435).
