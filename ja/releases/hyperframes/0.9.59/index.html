ハイパーフレーム v0.9.59

ハイパーフレーム v0.9.59

2026 年 11 月 16 日にリリースされました。

プレビュー プレーヤーには全画面ボタンが表示され、レンダリングに失敗するとその理由が表示されるようになりました。レンダリング、スタジオ、CLI は、プロジェクト独自のファイルとパブリック メディア ホストを維持します。

特徴

  • CLI: Diff --hide は、追加する内容によってプロジェクトのレイヤーをスコアリングします (e6d5c699b、#7972)。
  • プレーヤー: プレビュー プレーヤーに全画面ボタンを追加します (5be6c1580、#7726)。
  • コア: Describe 返信にはピッカーの要素ラベルが含まれ、Studio は StandInHandle (51ae92510、#7936) をエクスポートします。

修正

  • 隠しファイルと認証情報ファイルは Studio、履歴、lint から除外されます (c68c78445、#7979)。
  • コア: 別のサイト用にマークされたページは、そのサイトでのみ再生を提供します (c4d607c7f、#7980)。
  • スタジオ サーバー: 他のツールが実行するファイルまたは trust (2a28e4368、#7964) にアクセスする書き込みルートはありません。
  • CLI: スキル更新チェックでは、プロジェクトの git 構成 (e368db138、#7975) は決して読み取られません。
  • Lint: Studio を実行し、プロデューサーがホスト自身のスレッド (778a00564、#7974) からリントを取得します。
  • プロデューサー: サブ構成メディアのデフォルト (95e4e7f88、#7550) をプローブします。
  • CLI: 検証し、キーフレームでプロジェクト テキストを表示エスケープとして制御文字とともに印刷します (ce8d55d30、#7958)。
  • 確認: ロードに失敗したメディア ソースはタイムアウトとして報告されません (5e0c3db12、#7954)。
  • CLI: ヘルプには、各オプションのデフォルトが 1 回表示されます (d7f8d77fb、#7953)。
  • CLI: レンダリング --json は、欠落しているツール、保持されているスロット、および古いノードのそれぞれに独自のコード (47d007e5b、#7842) を与えます。
  • Sdk プレイグラウンド: Vite 構成は、22.18 (c7876f333、#7805) の前にノード 22 にロードされます。
  • チェック: コントラスト所見をその重症度でマークし、そのテキストを引用します (ec5a4e2a1、#7752)。
  • プレーヤー: 多くの clips が 1 つの長い録音を共有するときにプレビューがフリーズする問題の修正は、このリリースから取得されました。これは、プレビューを埋め込んでいるアプリが編集を表示するのを停止したためです (42508c1ef、#7795; 33e1a36a3 によって取り消されました、 #7978)。
  • スナップショットはプライベート ファイルをスキップし、テキスト アート デマルチプレクサーは使用せず、警告テキストをエスケープします (8959deb00、#7943)。
  • CLI: キャプチャは、バイパス エントリでローカル ページ サーバーのポートに名前を付けます (a9b0371c8、#7965)。
  • CLI: クラッシュまたはサイレント終了であっても、レンダリングが失敗すると、その理由がわかります (2623ded13、#7957)。
  • スタジオ: プロジェクト外部からの長いオーディオ ファイルは、その波形 (c77cd301c、#7961) としてデコードされることはありません。
  • 公開: npm がチェックしたものだけをアップロードします。タグはメイン、次、またはアルファコミット (5f4637977、#7959) のみをパブリッシュします。
  • エンジン: メディア URL の読み取りは、制限されたページ ネットワーク (994fbbde2、#7946) 下のパブリック ホストにのみ到達します。
  • Cli,engine: ページ サーバーの直接ホストを明示的なポートと Studio 独自のオリジン (dbc9c1826、#7945) に固定します。
  • プロデューサー: 長いオーディオ ミックスを待機しているレンダリングで、オーディオ (df698a029、#7952) を処理中であることが示されています。
  • コア: キャプチャ ページは、期限になった場合にのみ、長さが設定されていない clip をロードします (9e5048772、#7938)。
  • スタジオ: ビート分析では、曲よりも長い録音が選択されることはありません (87955b890、#7944)。
  • CLI: 独自のレンダリング スロット ロック ディレクトリ。他のアカウントが書き込むことができるキャッシュ ファイル (071a2da0b、#7951) を拒否します。
  • CLI: .hyperframes (061ff5bbb、#7950) の下のシンボリックリンクを通じてプロジェクト レコードを書き込まないでください。

ドキュメントと例

  • Changelog: 週間ダイジェスト 2026 年 11 月 9 日から 2026 年 11 月 16 日 (af873924d、#7969)。
  • 公開: 公開は承認なしで待機し、管理者のみがプレリリース タグ (a707e4737、#7960) をプッシュするとします。

カタログ

  • CLI: プロジェクト、ページ、レジストリ テキスト内のエスケープ制御文字 (6f88be394、#7913)。
  • Mcp: mcp-registry 環境 (45ff3526c、#7966) で MCP レジストリ パブリッシュを実行します。
  • Ci: メインが追い抜いたカタログ発行実行は、失敗せずに正常に終了しました (77e675574、#7816)。

hyperframes v0.9.59

HyperFrames v0.9.59

Released on 2026-11-16.

The preview player gets a fullscreen button, and a failed render now says why. Renders, Studio and the CLI keep to the project's own files and to public media hosts.

Features

  • CLI: Diff --hide scores a project's layer by what it adds (e6d5c699b, #7972).
  • Player: Add a fullscreen button to the preview player (5be6c1580, #7726).
  • Core: Describe replies carry the picker's element label, and studio exports standInHandle (51ae92510, #7936).

Fixes

  • Hidden and credential files stay out of Studio, history and lint (c68c78445, #7979).
  • Core: A page marked for another site gives that site only playback (c4d607c7f, #7980).
  • Studio Server: No write route touches files other tools run or trust (2a28e4368, #7964).
  • CLI: The skills update check never reads a project's git config (e368db138, #7975).
  • Lint: Run Studio and producer lint off the host's own thread (778a00564, #7974).
  • Producer: Probe sub-composition media defaults (95e4e7f88, #7550).
  • CLI: Validate and keyframes print project text with control characters as visible escapes (ce8d55d30, #7958).
  • Check: A media source that failed to load is not reported as a timeout (5e0c3db12, #7954).
  • CLI: Help shows each option's default once (d7f8d77fb, #7953).
  • CLI: Render --json gives each missing tool, a held slot and an old Node its own code (47d007e5b, #7842).
  • Sdk Playground: The Vite config loads on Node 22 before 22.18 (c7876f333, #7805).
  • Check: Mark a contrast finding by its severity and quote its text (ec5a4e2a1, #7752).
  • Player: The fix for the preview freezing when many clips share one long recording is pulled from this release, because it stopped an app embedding the preview from showing an edit (42508c1ef, #7795; reverted by 33e1a36a3, #7978).
  • Snapshot skips private files, no text-art demuxers, escaped warning text (8959deb00, #7943).
  • CLI: Capture names its local page server's port in the bypass entry (a9b0371c8, #7965).
  • CLI: A render that fails says why, even on a crash or a silent exit (2623ded13, #7957).
  • Studio: A long audio file from outside the project is never decoded for its waveform (c77cd301c, #7961).
  • Publish: Upload only what npm reads as checked; tags publish only main, next or alpha commits (5f4637977, #7959).
  • Engine: Media URL reads reach only public hosts under a restricted page network (994fbbde2, #7946).
  • Cli,engine: Pin the page server's direct host to an explicit port and the Studio's own origin (dbc9c1826, #7945).
  • Producer: A render waiting on a long audio mix says it is processing audio (df698a029, #7952).
  • Core: A capture page loads a clip with no set length only when it is due (9e5048772, #7938).
  • Studio: Beat analysis never picks a recording longer than a song (87955b890, #7944).
  • CLI: Own render-slot lock dir; refuse cache files other accounts can write (071a2da0b, #7951).
  • CLI: Never write project records through symlinks under .hyperframes (061ff5bbb, #7950).

Docs & Examples

  • Changelog: Weekly digest 2026-11-09-2026-11-16 (af873924d, #7969).
  • Publish: Say publishing waits for no approval and only admins push prerelease tags (a707e4737, #7960).

Catalog

  • CLI: Escape control characters in project, page and registry text (6f88be394, #7913).
  • Mcp: Run the MCP registry publish in the mcp-registry environment (45ff3526c, #7966).
  • Ci: A catalog publish run that main overtook ends clean instead of failing (77e675574, #7816).
