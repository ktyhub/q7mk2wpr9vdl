11/22
v0.9.83 パッチ MT

数千の clips またはスタイル ルールを含むページのコンパイルは高速に行われます。このメモには、v0.9.82 で出荷された修正プログラム (サンドボックス アプリがプロジェクト履歴を再度読み取る) もリストされています。

 11/22
v0.9.82 パッチ MT

プレビューは、ページ自体の GSAP フォルダーまたはホストのコピーから GSAP のモーション パス プラグインをロードするため、ネットワークがなくても動作します。 Sealed プレビューでは、サウンドやキーボードからネストされたコンポジション内の動きに至るまで、さらに多くの修正が加えられています。

 11/22
v0.9.81 パッチ MT

A heavy page now renders without running out of memory: a render starts only as many browsers as fit. Sealed previews take more edits in place, from moves and crops to undo and hotkeys.

 11/22
v0.9.80 パッチ MT

clip をメイントラック clips にドロップすると、そこに挿入できるようになりました。 Studio のプレビューはエクスポートとより厳密に一致し、ドライブが応答を停止してもプロジェクトが停止することはなくなりました。

 11/21
v0.9.79 パッチ MT

Trimming a main-track clip with Ripple on now closes the gap. Media files that sit outside a project are no longer reused, credited or written through a linked folder.

 11/21
v0.9.78 パッチ MT

エージェントのステップ後に元に戻すと、変更したファイルが戻されるようになりました。 Windows 上のカタログ ギャップ レポートでは、シェルが実行するようなクエリがコマンドに組み込まれることはなく、1 つのキャプチャ プロキシを共有することで接続が維持されます。

 11/21
v0.9.77 パッチ MT

CLI メッセージでは、制御文字がプレーン テキストとして表示されるようになりました。 Studio で元に戻す操作では、別のページがまだ使用しているファイルが削除されることはありません。また、ビッグ ルート プレビューが他のリクエストを保留することもなくなりました。

 11/21
v0.9.75 パッチ MT

多くのビデオを含む映画を検索しても Safari がハングしなくなりました。履歴を開いたり削除したりしても、遅いプロジェクト フォルダーで停止することはなくなり、CLI の書き込みでは、プロジェクト内の既存のリンクをたどることはありません。

 11/21
v0.9.74 パッチ MT

Films whose later scene sets an !important background on an id no longer render blank. Clips dropped on a sealed preview show on the timeline, and a package that fails to publish is tried again.

 11/20
v0.9.73 パッチ MT

長い clips のコピーをサウンド付きで再度プレビューすると、映像が黒く表示されなくなります。応答を停止したドライブに履歴を保存してもアプリがフリーズすることはなくなり、タイムラインが到着すると封印されたフィルムが表示されます…

 11/20
v0.9.72 パッチ MT

Renders limited by a CPU quota, such as a Kubernetes CPU limit, get their workers back, so long renders run at full speed again.

 11/19
v0.9.71 パッチ MT

レンダリングをキャンセルするとコンパイルが停止し、コンパイルでダウンロードされるファイルにはサイズの上限と 1 つの共有期限が設定されます。シークインデックスが最初のキーフレームを除外する MP4 からフレームを読み取り、SVG を多用したコンポジションをレンダリングします。

 11/19
v0.9.70 パッチ MT

多くの SVG 参照または大規模な変数セットを含むプロジェクトはコンパイルが速くなり、パスにタブが含まれるファイルは再度結合されます。ドキュメントに記載されているように、独自のプロジェクトの .env ファイル内のプロバイダー キーが再度使用されます。

 11/18
v0.9.69 パッチ MT

Image captioning in capture can now use a short-lived Vertex access token instead of a service-account key file. In Studio, a script edit in a sealed preview re-runs in place, without reloading the page.

 11/18
v0.9.68 パッチ MT

A render whose page Chrome closed while opening now reopens it, or says why it can't. Sealed previews keep an unsized video's own size and show animated values, and renders can send all their traffic through one…

 11/18
v0.9.67 パッチ MT

A failed render names the missing file again, looking only inside its own folders. Studio's sealed preview fills scenes and clips correctly and previews a 3D slider drag live.

 11/18
v0.9.66 パッチ MT

Studio のシールドされたプレビューでは、プロパティの編集、トリミング、サイズ変更が可能になり、スライドショー シーンが再生されます。 clip がダウンロードを停止すると、プレビューはバッファリングに残らなくなり、プレーヤーは独自のブランドを表示できるようになります。

 11/18
v0.9.65 パッチ MT

Studio's sealed preview now draws motion paths, reads keyframes and keeps a moved layer in place when you add a keyframe. Studio's error and analytics events no longer carry your error text, file paths or selectors.

 11/17
v0.9.64 パッチ MT

ホバーとサムネイルのキャプチャは、4K clip のプレビュー コピーを待たなくなりました。密閉されたプレビューでは、スクラブによって音楽トラックが再生され、タイムラインの行でその要素が認識されます。ハイパーフレーム チェックでは、顔の上にあるテキストが検出されます。

 11/17
v0.9.63 パッチ MT

Studio の密閉されたプレビューにはオーディオ メーターとオーディオ グループが表示され、レイヤーの並べ替えは 1 回元に戻すだけで済み、テキスト フィルムはより早く開始されます。 HyperFrames サーバーは、プロジェクト ファイルを Service Worker のスクリプトとして提供しません。

 11/17
v0.9.61 パッチ MT

受信したプロジェクトとそこに到達したファイルは、レンダリング、プレビュー、Studio 全体で独自のフォルダー内に留まり、封印されたプレビューが数分の 1 秒で所定の位置にリロードされます。

 11/17
v0.9.59 パッチ MT

プレビュー プレーヤーには全画面ボタンが表示され、レンダリングに失敗するとその理由が表示されるようになりました。レンダリング、スタジオ、および CLI は、プロジェクト独自のファイルとパブリック メディア ホストを保持します。

 11/16
v0.9.58 パッチ MT

Studio は、シールされたプレビューのチェックされた要素の読み取りと代役をエクスポートし、レンダリング、カービング、およびオーディオ エンジンをプロジェクト独自のファイルに保持します。

 11/15
