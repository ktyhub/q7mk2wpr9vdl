stable-diffusion-webui v1.3.0

マイナー 公開日2023年5月27日 出典AUTOMATIC1111/stable-diffusion-webui English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

安定拡散ウェブイ v1.3.0

特徴:

  • デフォルトを編集するための UI を追加
  • トークンのマージ (dbolya/tomesd 経由)
  • 設定タブを作り直しました: 多くの説明とリンクを追加しました
  • メインプログラムのロードと並行して拡張機能の Git メタデータをロードし、起動時の時間を大幅に節約します
  • 拡張機能テーブルの更新: ブランチを表示、別の列に日付を表示、可能な場合はタグからのバージョンを表示
  • TAESD - 安価なライブ プレビューのもう 1 つのオプション
  • サンプラーの選択を許可し、採用修正の 2 回目のパスを求めるプロンプトを表示 - デフォルトでは非表示、設定で有効
  • Lora のハッシュを計算します
  • lora ハッシュを情報テキストに追加します
  • 情報テキストを貼り付けるとき、情報テキストの lora ハッシュを使用して、ハッシュがユーザーの lora と一致する <lora:xxx:1> エントリのローカル lora を検索します。
  • UIからクロスアテンションの最適化を選択します

マイナー:

  • Gradio を 3.31.0 にバンプします
  • macOS および Linux AMD の場合、PyTorch を 2.0.1 にバンプします
  • 拡張機能のタブ内の要素のデフォルト設定を許可します
  • ライブ プレビューのファイル タイプを選択できるようにします
  • 初めて表示するときに追加のネットワークについては「読み込み中...」を表示します
  • ENSD 情報テキストを使用しないサンプラーの ENSD 情報テキストを抑制します
  • cliエントサイドの最適化
  • 追加ネットワーク内の隠しファイルとディレクトリを表示/非表示にし、隠しディレクトリ内のモデル/ファイルをリストしないオプションを追加します。 *styles.csv で空白を許可します
  • タブを並べ替えるオプションを追加
  • 一部の機能 (解像度を交換し、シードを -1 に設定) を client に移動
  • img2img のエディターの高さを指定するオプション
  • 画像解像度を img2img の幅/高さスライダーにコピーするボタン
  • pygrok から ngrok-py に切り替える
  • 追加のネットワーク UI での画像の遅延読み込み
  • リクエストに応じて、「ゲームパッドで画像ビューアをナビゲートする」オプションをデフォルトで false に設定します
  • デフォルトの models/<...> ではなく、ユーザー指定のディレクトリ (コマンドライン引数から) にモデルをダウンロードするようにアップスケーラーを変更します。
  • ui-config.json でボタンを非表示にすることを許可します

拡張機能:

  • /sdapi/v1/script-info api を追加
  • Ruff を使用して Python コードをリントします
  • ESlint を使用して Javascript コードをリントします
  • セルフアテンション ガイダンス拡張機能の CFG コールバックを追加/変更します
  • サーバーを正常に停止するためのコマンドとエンドポイントを追加します
  • 処理関数からいくつかのローカル (プロンプト/シード/など) をフィールドとして処理クラスに追加します
  • JSON を使用するために、コンマが含まれる情報テキスト項目の引用符を再加工します (以前に機能しなかった場合を除いて、下位互換性があるはずです)
  • /sdapi/v1/refresh-loras api チェックポイントポストリクエストを追加
  • テストのオーバーホール

バグ修正:

  • ユーザーが間違った Gradio テーマを指定した場合にプログラムが起動できない問題を修正
  • ファイルスクリプトからの壊れたプロンプトを修正
  • 追加ネットワークのシンボリックリンクスキャンを修正
  • webui-user.bat COMMANDLINE_ARGS 経由で起動するときに --data-dir が無視される問題を修正
  • Web UI を完全にオフラインで実行できるようにする
  • --freeze-settings で実行できない問題を修正
  • メタデータを追加せずにチェックポイントをマージできない問題を修正
  • 追加ネットワークの保存プレビュー画像が JPEG/WebM の情報テキストを追加しない問題を修正
  • ハイ修正およびスケール解像度プレビューのテキストから点滅効果を削除
  • http://<...>.git 拡張機能へのリンクを拡張機能タブで機能させる
  • git プロセスのハングにより起動時に webui がハングするバグを修正

stable-diffusion-webui v1.3.0

Features:

  • add UI to edit defaults
  • token merging (via dbolya/tomesd)
  • settings tab rework: add a lot of additional explanations and links
  • load extensions' Git metadata in parallel to loading the main program to save a ton of time during startup
  • update extensions table: show branch, show date in separate column, and show version from tags if available
  • TAESD - another option for cheap live previews
  • allow choosing sampler and prompts for second pass of hires fix - hidden by default, enabled in settings
  • calculate hashes for Lora
  • add lora hashes to infotext
  • when pasting infotext, use infotext's lora hashes to find local loras for <lora:xxx:1> entries whose hashes match loras the user has
  • select cross attention optimization from UI

Minor:

  • bump Gradio to 3.31.0
  • bump PyTorch to 2.0.1 for macOS and Linux AMD
  • allow setting defaults for elements in extensions' tabs
  • allow selecting file type for live previews
  • show "Loading..." for extra networks when displaying for the first time
  • suppress ENSD infotext for samplers that don't use it
  • clientside optimizations
  • add options to show/hide hidden files and dirs in extra networks, and to not list models/files in hidden directories
  • allow whitespace in styles.csv
  • add option to reorder tabs
  • move some functionality (swap resolution and set seed to -1) to client
  • option to specify editor height for img2img
  • button to copy image resolution into img2img width/height sliders
  • switch from pyngrok to ngrok-py
  • lazy-load images in extra networks UI
  • set "Navigate image viewer with gamepad" option to false by default, by request
  • change upscalers to download models into user-specified directory (from commandline args) rather than the default models/<...>
  • allow hiding buttons in ui-config.json

Extensions:

  • add /sdapi/v1/script-info api
  • use Ruff to lint Python code
  • use ESlint to lint Javascript code
  • add/modify CFG callbacks for Self-Attention Guidance extension
  • add command and endpoint for graceful server stopping
  • add some locals (prompts/seeds/etc) from processing function into the Processing class as fields
  • rework quoting for infotext items that have commas in them to use JSON (should be backwards compatible except for cases where it didn't work previously)
  • add /sdapi/v1/refresh-loras api checkpoint post request
  • tests overhaul

Bug Fixes:

  • fix an issue preventing the program from starting if the user specifies a bad Gradio theme
  • fix broken prompts from file script
  • fix symlink scanning for extra networks
  • fix --data-dir ignored when launching via webui-user.bat COMMANDLINE_ARGS
  • allow web UI to be ran fully offline
  • fix inability to run with --freeze-settings
  • fix inability to merge checkpoint without adding metadata
  • fix extra networks' save preview image not adding infotext for jpeg/webm
  • remove blinking effect from text in hires fix and scale resolution preview
  • make links to http://<...>.git extensions work in the extension tab
  • fix bug with webui hanging at startup due to hanging git process
