stable-diffusion-webui v1.1.0

マイナー 公開日2023年5月1日 出典AUTOMATIC1111/stable-diffusion-webui English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

安定拡散ウェブイ v1.1.0

特徴:

  • トーチ 2.0.0 に切り替えます (AMD GPU を除く)
  • カスタム コード スクリプトの視覚的な改善
  • ファイル名パターンを追加: [clip_skip]、[hasprompt<>]、[batch_number]、[世代番号]
  • 初期化イメージを img2img に保存するサポートを追加し、再現性のためにそのハッシュを情報テキストに記録します
  • Ctrl+上/下で重みを調整すると、現在の単語が自動的に選択されます
  • X/Y/Z プロットのドロップダウンを追加
  • 設定: 安定拡散/乱数ジェネレーター ソース: 特定の手動シードから生成された画像を、異なる GPU 間で一貫性のあるものにすることが可能になります。
  • GradioのテーマAPIをサポート
  • Linux ではデフォルトで TCMalloc を使用します。メモリリークを修正できる可能性がある
  • (最適化) 低いシグマ値でのネガティブな条件付けを削除するオプション #9177
  • モデルマージメタデータを .safetensors ファイルに埋め込みます
  • 拡張機能設定のバックアップ/復元機能 #9169
  • img2img に「サイズ変更」タブと「サイズ変更」タブを追加
  • テキスト反転画像の前処理に「元のサイズを維持」オプションを追加
  • アナログスティックを介してスクロールする画像ビューア
  • 失われたセッション/タブのリロードから進行状況を復元するボタン

マイナー:

  • グラデーションが 3.28.1 にバンプされました
  • エクストラタブで、エクストラの「スケール」をスライダーに変更します
  • ツールボタンにラベルを追加して非表示にできるようにします
  • ScuNET のタイル推論サポートを追加
  • 拡張機能のインストールのためのブランチ サポートを追加
  • Linux インストール スクリプトを /home/username ではなく現在のディレクトリにインストールするように変更します
  • テキスト反転埋め込みを名前で並べ替えます (大文字と小文字は区別されません) *styles.csv を docker にシンボリックリンクまたはマウントできるようにします
  • 「画像に透かしを追加しない」オプションを削除します
  • 選択したタブを UI 構成で構成可能にします
  • 追加のネットワーク UI は高さが固定され、スクロール可能になりました
  • 自己署名証明書で使用するための disable_tls_verify 引数を追加します

拡張機能:

  • リロードコールバックを追加
  • 処理用に is_hr_pass フィールドを追加

バグ修正:

  • 「エクストラ/バッチ処理」タブで壊れたバッチ画像処理を修正
  • 追加ネットワークのドロップダウンに「なし」オプションを追加します
  • CLIP インタロゲータの FileExistsError を修正
  • Linux で動作しない /sdapi/v1/txt2img エンドポイントを修正 #9319
  • 遅いタスク中に消えるライブ プレビューとプログレスバーを修正
  • 場合によっては全画面画像ビューが正しく動作しない問題を修正
  • alwayson_scripts args param が script_arg リストに挿入されるときにサイズ変更されないようにする
  • 二次サンプラーのプロンプトスケジュールを修正
  • 奇妙な解像度の画像マスク/合成を修正 #9628
  • AND を使用する場合は、プレビューに正しい画像を使用します (#9491 を参照)
  • img2img バッチ内の 1 つの破損した画像によってすべての処理が停止されるわけではありません
  • トレーニング/プリプロセスにおける画像の向きのバグを修正
  • リロードごとにトンネルを再作成する Ngrok を修正
  • --realesrgan-models-path と --ldsr-models-path が機能しない問題を修正
  • --skip-install が機能しない問題を修正
  • アウトペイント Mk2 & Poorman では、GRID ファイル形式ではなく、SAMPLE ファイル形式を使用して画像を保存する必要があります
  • 画像を作成するときに一部の Lora のロードに失敗した場合でも、すべての Lora が失敗することはありません

stable-diffusion-webui v1.1.0

Features:

  • switch to torch 2.0.0 (except for AMD GPUs)
  • visual improvements to custom code scripts
  • add filename patterns: [clip_skip], [hasprompt<>], [batch_number], [generation_number]
  • add support for saving init images in img2img, and record their hashes in infotext for reproducability
  • automatically select current word when adjusting weight with ctrl+up/down
  • add dropdowns for X/Y/Z plot
  • setting: Stable Diffusion/Random number generator source: makes it possible to make images generated from a given manual seed consistent across different GPUs
  • support Gradio's theme API
  • use TCMalloc on Linux by default; possible fix for memory leaks
  • (optimization) option to remove negative conditioning at low sigma values #9177
  • embed model merge metadata in .safetensors file
  • extension settings backup/restore feature #9169
  • add "resize by" and "resize to" tabs to img2img
  • add option "keep original size" to textual inversion images preprocess
  • image viewer scrolling via analog stick
  • button to restore the progress from session lost / tab reload

Minor:

  • gradio bumped to 3.28.1
  • in extra tab, change extras "scale to" to sliders
  • add labels to tool buttons to make it possible to hide them
  • add tiled inference support for ScuNET
  • add branch support for extension installation
  • change linux installation script to insall into current directory rather than /home/username
  • sort textual inversion embeddings by name (case insensitive)
  • allow styles.csv to be symlinked or mounted in docker
  • remove the "do not add watermark to images" option
  • make selected tab configurable with UI config
  • extra networks UI in now fixed height and scrollable
  • add disable_tls_verify arg for use with self-signed certs

Extensions:

  • Add reload callback
  • add is_hr_pass field for processing

Bug Fixes:

  • fix broken batch image processing on 'Extras/Batch Process' tab
  • add "None" option to extra networks dropdowns
  • fix FileExistsError for CLIP Interrogator
  • fix /sdapi/v1/txt2img endpoint not working on Linux #9319
  • fix disappearing live previews and progressbar during slow tasks
  • fix fullscreen image view not working properly in some cases
  • prevent alwayson_scripts args param resizing script_arg list when they are inserted in it
  • fix prompt schedule for second order samplers
  • fix image mask/composite for weird resolutions #9628
  • use correct images for previews when using AND (see #9491)
  • one broken image in img2img batch won't stop all processing
  • fix image orientation bug in train/preprocess
  • fix Ngrok recreating tunnels every reload
  • fix --realesrgan-models-path and --ldsr-models-path not working
  • fix --skip-install not working
  • outpainting Mk2 & Poorman should use the SAMPLE file format to save images, not GRID file format
  • do not fail all Loras if some have failed to load when making a picture
