stable-diffusion-webui v1.2.0

マイナー 公開日2023年5月13日 出典AUTOMATIC1111/stable-diffusion-webui English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

安定拡散ウェブイ v1.2.0

特徴:

  • 起動時に安定した拡散モデルが読み込まれるまで待機しません
  • ファイル名パターンを追加: [ノイズ除去]
  • 追加ネットワーク用のディレクトリ非表示: で始まるディレクトリ。特に検索されない限り、追加のネットワーク タブでカードを非表示にします
  • Lora: プロンプトの <...> テキストには、ファイル名の代わりに、ファイルのメタデータ内にある Lora の名前を使用します (存在する場合) (どちらも lora をアクティブ化するために使用できます)
  • Lora: kohya-ss の拡張パラメータが存在し、拡張機能がアクティブでない場合は、kohya-ss の拡張パラメータから infotext パラメータを読み取ります。
  • Lora: 一部の Lora が動作しない問題を修正 (3x3 畳み込み層を持つもの)
  • Lora: lora を適用する古い方法を使用するオプションを追加します (kohya-ss と同じ結果が得られます)
  • 開始時に情報テキスト、フッター、コンソール出力にバージョンを追加します
  • ファイル名パターン設定のための Wiki へのリンクを追加
  • クイック設定設定の拡張情報を追加し、テキスト フィールドの代わりに複数選択入力を使用します

マイナー:

  • グラデーションが 3.29.0 にバンプされました
  • トーチが 2.0.1 に衝突しました
  • リバース プロキシで使用する gradio の --subpath オプション
  • linux/OSX: すでにアクティブな場合は既存の virtualenv を使用します (VIRTUAL_ENV 環境変数)
  • フロントエンドの最適化の可能性: ローカリゼーションがない場合は適用しない
  • XYZ プロットの VAE に追加の None オプションを追加
  • img2img でのバッチ処理が失敗した場合にコンソールにエラーを出力します
  • 追加のネットワーク ページの HTML をオンデマンドでのみ作成します
  • で始まるディレクトリを許可します。 lora、チェックポイントなどのモデルを引き続きリストする
  • 情報テキストのオプションを設定タブの独自のカテゴリに追加します
  • ユーザーが設定で [すべてのページを表示] を選択した場合、ライセンス ページは表示されません

拡張機能:

  • ツールチップのローカリゼーションのサポート
  • プロンプト付きで LoRA モデルを取得するための api メソッドを追加

バグ修正:

  • /docs エンドポイントを再追加
  • ゲームパッドのナビゲーションを修正
  • ライトボックスの全画面画像が適切に機能するようにする
  • エクストラタブの潰れたサムネイルを修正
  • ユーザーがタブを更新するときに追加のネットワークの「検索」フィルターを保持します (以前は更新後にすべてが表示されていました)
  • 結果を常に同じファイルに保存するように生成を設定した場合に同じ画像が表示される WebUI を修正
  • アップスケーラーが正しく動作しないバグを修正
  • PyTorch 2.0.1、Intel Mac 上の MPS を修正
  • contextMenu.js のカスタム コンテキスト メニューがユーザーの click 後にのみ消え、ユーザー以外の click イベントを無視するようにします
  • まだ準備ができていないときに、UI の再読み込みボタン/リンクがページを再読み込みしないようにします
  • ドラッグ/ドロップファイルからコンテンツを読み取ることができないファイルスクリプトからのプロンプトを修正

stable-diffusion-webui v1.2.0

Features:

  • do not wait for stable diffusion model to load at startup
  • add filename patterns: [denoising]
  • directory hiding for extra networks: dirs starting with . will hide their cards on extra network tabs unless specifically searched for
  • Lora: for the <...> text in prompt, use name of Lora that is in the metdata of the file, if present, instead of filename (both can be used to activate lora)
  • Lora: read infotext params from kohya-ss's extension parameters if they are present and if his extension is not active
  • Lora: Fix some Loras not working (ones that have 3x3 convolution layer)
  • Lora: add an option to use old method of applying loras (producing same results as with kohya-ss)
  • add version to infotext, footer and console output when starting
  • add links to wiki for filename pattern settings
  • add extended info for quicksettings setting and use multiselect input instead of a text field

Minor:

  • gradio bumped to 3.29.0
  • torch bumped to 2.0.1
  • --subpath option for gradio for use with reverse proxy
  • linux/OSX: use existing virtualenv if already active (the VIRTUAL_ENV environment variable)
  • possible frontend optimization: do not apply localizations if there are none
  • Add extra None option for VAE in XYZ plot
  • print error to console when batch processing in img2img fails
  • create HTML for extra network pages only on demand
  • allow directories starting with . to still list their models for lora, checkpoints, etc
  • put infotext options into their own category in settings tab
  • do not show licenses page when user selects Show all pages in settings

Extensions:

  • Tooltip localization support
  • Add api method to get LoRA models with prompt

Bug Fixes:

  • re-add /docs endpoint
  • fix gamepad navigation
  • make the lightbox fullscreen image function properly
  • fix squished thumbnails in extras tab
  • keep "search" filter for extra networks when user refreshes the tab (previously it showed everthing after you refreshed)
  • fix webui showing the same image if you configure the generation to always save results into same file
  • fix bug with upscalers not working properly
  • Fix MPS on PyTorch 2.0.1, Intel Macs
  • make it so that custom context menu from contextMenu.js only disappears after user's click, ignoring non-user click events
  • prevent Reload UI button/link from reloading the page when it's not yet ready
  • fix prompts from file script failing to read contents from a drag/drop file
