stable-diffusion-webui v1.5.0

マイナー 公開日2023年7月25日 出典AUTOMATIC1111/stable-diffusion-webui English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

安定拡散ウェブイ v1.5.0

特徴:

  • SD XL サポート
    • --no-half-vae が必要です。詳細については、#11757 を参照してください。
  • カスタムネットワーク用のユーザーメタデータシステム
  • 拡張された Lora メタデータ エディター: アクティベーション テキスト、デフォルトの重み、表示タグ、トレーニング情報を設定します。
  • Lora 拡張機能を再加工して、他のタイプのネットワーク (以前は LyCORIS 拡張機能によって処理されていたものすべて) を含めるようにしました
  • 拡張機能には github の星を表示します
  • img2img バッチモードは png 情報から余分なものを読み取ることができます
  • img2img バッチはサブディレクトリで動作します
  • プロンプト要素を移動するホットキー: alt+左/右
  • リスタイル所要時間/VRAM表示
  • テキスト反転ハッシュを情報テキストに追加します
  • 最適化: git 拡張機能リポジトリ情報をキャッシュします
  • モバイル clients 用に生成された画像の横に生成ボタンを移動します
  • Lora 追加ネットワーク インターフェイスで互換性のない安定版拡散バージョンのネットワークのカードを非表示にする
  • すべてがすでにインストールされている場合は、pip を使用してパッケージのインストールをスキップします - 起動速度が約 2 秒向上します

マイナー:

  • [インストール済み] タブのすべての拡張機能をオン/オフにするチェックボックス
  • gradio ユーザーを情報テキストとファイル名パターンに追加します
  • 追加のネットワーク プレビュー用に gif を許可します
  • グリッドの色を変更するオプションを追加します
  • 追加ネットワーク内のアイテムには自然ソートを使用します
  • Mac: torch 2 の empty_cache() を使用して VRAM をクリアします
  • Navi3 (AMD) に適切なライブラリをインストールするための自動サポートを追加しました
  • SwinIR アップスケールを加速するオプション SWIN_torch_compile を追加
  • デフォルトでは、起動時の TI 埋め込み情報のコンソールへの出力を抑制します
  • 追加ネットワークのリストを高速化
  • [none] ファイル名トークンを追加しました。
  • 追加のネットワーク表示モードのサムを削除しました (サムを取得するには、設定タブを使用して幅/高さ/スケールを変更します)
  • always_discard_next_to_last_sigma オプションを XYZ プロットに追加します
  • 生成されたピクチャに NaN が含まれる場合、--no-half-vae コマンドライン フラグを必要とせずに、32 ビット浮動小数点 VAE に自動的に切り替えます。

拡張機能と API:

  • api エンドポイント: /sdapi/v1/server-kill、/sdapi/v1/server-restart、/sdapi/v1/server-stop
  • スクリプトにカスタム メタクラスを含めることを許可します
  • モデルの存在ステータスを確認/sdapi/v1/options を追加
  • --add-stop-route の名前を --api-server-stop に変更します
  • before_hr スクリプト コールバックを追加
  • コールバック after_extra_networks_activate を追加
  • デフォルトでは、API のコンソールでのリッチ例外出力を無効にします。有効にするには、WEBUI_RICH_EXCEPTIONS 環境変数を使用します。
  • サムファイルが見つからない場合は http 404 を返します
  • 拡張インデックスを環境変数に置き換えることを許可します

バグ修正:

  • 拡張インデックス #11290 を取得する際のキャッチエラーを修正
  • ネットワークドライブから読み取るときの .safetensors ファイルの読み込み速度が非常に遅い問題を修正
  • API キャッシュのクリーンアップ
  • ファイル CLIP インタロゲータ バッチ モードに書き込む際の UnicodeEncodeError を修正
  • PyTorch から非推奨となった「has_mps」の警告を修正
  • 世代情報が失われるプレビューとして画像を保存する追加のネットワークの問題を修正
  • I;16 モードで画像のサイズを変更しようとすると例外がスローされる問題を修正
  • #11534 の修正: キャンバスのズームとパンの拡張機能ハイジャックのショートカット キー
  • 起動スクリプトを任意のディレクトリから実行できるように修正
  • API 画像メタデータに「Seed Resize: -1x-1」を追加しないでください
  • Ctrl+上/下で終了括弧を正しく削除します
  • 新しい gradio バージョンで --subpath を修正
  • 修正: サイズ変更時に塗りつぶしサイズをゼロ以外でチェックする (修正 #11425)
  • クイック設定テキストボックスには送信とぼかしを使用します
  • image.save_image() で img2img バッチを保存
  • 無効な拡張機能に対して preload.py を実行しないようにします
  • 修正: 以前は、モデル名がディレクトリ名とともに infotext および [model_name] ファイル名パターンに追加されていました。ディレクトリ名は含まれなくなりました

stable-diffusion-webui v1.5.0

Features:

  • SD XL support
    • Requires --no-half-vae. See #11757 for more details.
  • user metadata system for custom networks
  • extended Lora metadata editor: set activation text, default weight, view tags, training info
  • Lora extension rework to include other types of networks (all that were previously handled by LyCORIS extension)
  • show github stars for extenstions
  • img2img batch mode can read extra stuff from png info
  • img2img batch works with subdirectories
  • hotkeys to move prompt elements: alt+left/right
  • restyle time taken/VRAM display
  • add textual inversion hashes to infotext
  • optimization: cache git extension repo information
  • move generate button next to the generated picture for mobile clients
  • hide cards for networks of incompatible Stable Diffusion version in Lora extra networks interface
  • skip installing packages with pip if they all are already installed - startup speedup of about 2 seconds

Minor:

  • checkbox to check/uncheck all extensions in the Installed tab
  • add gradio user to infotext and to filename patterns
  • allow gif for extra network previews
  • add options to change colors in grid
  • use natural sort for items in extra networks
  • Mac: use empty_cache() from torch 2 to clear VRAM
  • added automatic support for installing the right libraries for Navi3 (AMD)
  • add option SWIN_torch_compile to accelerate SwinIR upscale
  • suppress printing TI embedding info at start to console by default
  • speedup extra networks listing
  • added [none] filename token.
  • removed thumbs extra networks view mode (use settings tab to change width/height/scale to get thumbs)
  • add always_discard_next_to_last_sigma option to XYZ plot
  • automatically switch to 32-bit float VAE if the generated picture has NaNs without the need for --no-half-vae commandline flag.

Extensions and API:

  • api endpoints: /sdapi/v1/server-kill, /sdapi/v1/server-restart, /sdapi/v1/server-stop
  • allow Script to have custom metaclass
  • add model exists status check /sdapi/v1/options
  • rename --add-stop-route to --api-server-stop
  • add before_hr script callback
  • add callback after_extra_networks_activate
  • disable rich exception output in console for API by default, use WEBUI_RICH_EXCEPTIONS env var to enable
  • return http 404 when thumb file not found
  • allow replacing extensions index with environment variable

Bug Fixes:

  • fix for catch errors when retrieving extension index #11290
  • fix very slow loading speed of .safetensors files when reading from network drives
  • API cache cleanup
  • fix UnicodeEncodeError when writing to file CLIP Interrogator batch mode
  • fix warning of 'has_mps' deprecated from PyTorch
  • fix problem with extra network saving images as previews losing generation info
  • fix throwing exception when trying to resize image with I;16 mode
  • fix for #11534: canvas zoom and pan extension hijacking shortcut keys
  • fixed launch script to be runnable from any directory
  • don't add "Seed Resize: -1x-1" to API image metadata
  • correctly remove end parenthesis with ctrl+up/down
  • fixing --subpath on newer gradio version
  • fix: check fill size none zero when resize (fixes #11425)
  • use submit and blur for quick settings textbox
  • save img2img batch with images.save_image()
  • prevent running preload.py for disabled extensions
  • fix: previously, model name was added together with directory name to infotext and to [model_name] filename pattern; directory name is now not included
