gpt-研究者 v3.8.0

新しい UI と 4 分以内の詳細なレポート

<a href="https://github.com/user-attachments/assets/4d3f26cf-8ccc-413a-b17c-80aa9e1b52d1"> <img src="https://github.com/user-attachments/assets/3a56a008-fcbd-4373-9e40-8d6027120cfb" alt="質問を引用レポートに変える GPT 研究者" width="800"> </a>

Next.js アプリには、gptr.dev に一致する新しい紙のデザインが採用されています。設定は、リサーチ、MCP、ドキュメント、バックエンドのタブを備えた 1 つのモーダル内に存在します。実行すると平易な言語のフィードが表示され、書き込みが始まるとソースの余白がスライドして挿入されます。以前の UI は引き続き /classic で入手できます。

詳細レポートは、9:11** ではなく **3:27 で終了するようになりました。セクションは並行して調査され、デフォルトのライターは gpt-6-sol になり、最初にセクションごとに 1 分近くかかる推論ではなく、数秒以内に書き込みを開始します。測定値とモデルの比較は #2272 にあります。

⚠️ 注意事項の変更点

  • デフォルトのライター モデル: SMART_LLM は openai:gpt-6-sol になりました (以前は openai:gpt-5.4 でした)。以前のモデルを維持するには、SMART_LLM を設定します。
  • LLM アイドル タイムアウト: 300 秒間何も送信しない LLM 呼び出しは、実行をハングさせるのではなく、明らかなエラーで失敗するようになりました。 LLM_TIMEOUT で調整します (0 は無効にします)。 (#2220)
  • Docker: ルート .env はイメージにコピーされなくなりました。 docker compose は実行時にロードします (Compose 2.24+ が必要)。 docker run の場合は、--env-file .env を渡します。ローカルで構築したイメージをプッシュしたことがある場合は、.env にあったキーを回転させます。
  • LLM の試行がすべて失敗した場合に、空のレポートを返すのではなく、generate_report が発生するようになりました。 (#2219)

このリリースにも含まれています

  • GHCR 上の linux/amd64 および linux/arm64 用の構築済み Docker イメージ: バージョンと latest でタグ付けされた ghcr.io/assafelovic/gpt-researcher および ghcr.io/assafelovic/gpt-researcher-frontend-nextjs (#1517)
  • リサーチ オブザーバー: 構造化された進行状況イベントを必要とする統合用のオプションのライフサイクル オブザーバー (#2232)
  • MiniMax 地域プロバイダーと Flash デフォルト (#1924)、構成可能な TypeSafe ベース URL (#2243)、および render.yaml ブループリントを使用した Deploy on Render (#2184)
  • Web UI からのマルチエージェント プラン レビューのフィードバックが再び機能し、マルチエージェント ライターは SMART_TOKEN_LIMIT および REASONING_EFFORT を使用するようになりました (#2272)
  • 深い調査は推論の予算を尊重し、再試行とネストされた研究者をコストにカウントし、引用された学習を文字数制限内に保ちます (#2260、#2209、#2208)
  • MCP 検索はイベント ループをブロックしなくなり、max_tools の上限が適用されます (#2262、#2263)
  • 構成: JSON 構成ファイルの reasoning_effort、DOC_PATH / REPORT_SOURCE 環境オーバーライド、UTF-8 構成ファイル、およびイメージ生成設定がすべて再度適用されます (#2230、#2248、#2249、#2199、#2246)
  • Exa、Google、Bing、Bocha、PubMed Central、arXiv、オンライン ドキュメント、Windows テキスト ファイルにわたる Retriever、Scraper、ドキュメント ローダーの修正
  • Retriever プラグイン: Keenable および Sciverse のコミュニティ リスト (#2176、#2225)

このリリースには 53 件のコミュニティ プル リクエストが含まれています。ご協力いただいた皆様に感謝いたします。

gpt-researcher v3.8.0

A new UI, and detailed reports in under 4 minutes

<a href="https://github.com/user-attachments/assets/4d3f26cf-8ccc-413a-b17c-80aa9e1b52d1"> <img src="https://github.com/user-attachments/assets/3a56a008-fcbd-4373-9e40-8d6027120cfb" alt="GPT Researcher turning a question into a cited report" width="800"> </a>

The Next.js app has a new paper design that matches gptr.dev. Settings live in one modal with tabs for Research, MCP, Documents and Backend; a run shows a plain-language feed, and the sources margin slides in once writing starts. The previous UI is still available at /classic.

Detailed reports now finish in 3:27 instead of 9:11. Sections are researched in parallel, and the default writer is now gpt-6-sol, which starts writing within seconds instead of reasoning for close to a minute per section first. Measurements and the model comparison are in #2272.

⚠️ Changes to note

  • Default writer model: SMART_LLM is now openai:gpt-6-sol (was openai:gpt-5.4). Set SMART_LLM to keep the previous model.
  • LLM idle timeout: an LLM call that sends nothing for 300 seconds now fails with a clear error instead of hanging the run. Tune it with LLM_TIMEOUT (0 disables it). (#2220)
  • Docker: the root .env is no longer copied into images. docker compose loads it at runtime (needs Compose 2.24+); with docker run, pass --env-file .env. If you ever pushed an image you built locally, rotate the keys that were in your .env.
  • generate_report now raises when every LLM attempt fails, instead of returning an empty report. (#2219)

Also in this release

  • Prebuilt Docker images for linux/amd64 and linux/arm64 on GHCR: ghcr.io/assafelovic/gpt-researcher and ghcr.io/assafelovic/gpt-researcher-frontend-nextjs, tagged with the version and latest (#1517)
  • Research observer: an optional lifecycle observer for integrations that want structured progress events (#2232)
  • MiniMax regional providers and Flash defaults (#1924), a configurable TypeSafe base URL (#2243), and Deploy on Render with a render.yaml blueprint (#2184)
  • Multi-agent plan review feedback from the web UI works again, and the multi-agent writer uses SMART_TOKEN_LIMIT and REASONING_EFFORT (#2272)
  • Deep research honors reasoning budgets, counts retries and nested researchers in costs, and keeps cited learnings at the word limit (#2260, #2209, #2208)
  • MCP search no longer blocks the event loop, and the max_tools cap is enforced (#2262, #2263)
  • Configuration: reasoning_effort from JSON config files, DOC_PATH / REPORT_SOURCE env overrides, UTF-8 config files, and image generation settings are all honored again (#2230, #2248, #2249, #2199, #2246)
  • Retriever, scraper and document loader fixes across Exa, Google, Bing, Bocha, PubMed Central, arXiv, online documents and Windows text files
  • Retriever plugins: a community list with Keenable and Sciverse (#2176, #2225)

53 community pull requests went into this release. Thank you to everyone who contributed.

Install: pip install -U gpt-researcher (0.17.0)
