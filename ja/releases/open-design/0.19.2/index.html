open-design v0.19.2

オープンデザイン オープンデザイン-v0.19.2

🌟 コードネーム: コマンド 1 つでディープシーク ハーネス

🧰 PR 28 名 · 貢献者 9 名 · 2 日 — 0.19.2 はからのパスを短縮します DeepSeek Harness のインストールから作業の終了まで。 1 つのコマンドでセットアップできます。 互換性のある Harness ツールチェーンにより、スペースを含む Windows パスが分割されなくなりました。 Design 接続を開くと、長いストリームでも応答性が維持されます。このパッチにより追加されるのは、 オフラインでも安全な HTML エクスポートと構造化デザイン システム 3.0 ランタイム。

🔥 ハイライト

  • 🧰 1 つのコマンドで DeepSeek ハーネスをインストールします。 新しいブートストラップ スクリプト macOS、Linux、Windows PowerShell、および Windows CMD をカバーします。互換性のあるものを再利用します ローカル ツールを使用するか、分離されたユーザー スコープの Node.js 24 ツールチェーンをインストールします。 固定されたハーネスをリリースし、dsh web を開いて API キーをセットアップします。今すぐデザインを開く シェルセーフなプロファイル パスを介して接続コンポーネントをインストールします。 スペースを含む Windows アプリケーションおよび DSH_HOME パス。 (#6900、#6905)
  • 📦 移動後も機能し続ける HTML をエクスポートします。 HTML を今すぐダウンロードしました プロジェクトローカルのイメージ、スタイル、フォント、モジュール、ワーカー、およびネストされたものをバンドルします ドキュメントをオフラインでも安全な 1 つのファイルにまとめます。不足している依存関係またはサイズが大きすぎる依存関係が返される エクスポートが壊れているのではなく、明らかなエラーです。同じ出力は次の方法で利用できます。 od export --format html。 (#6855)
  • ⚡ 長時間のエージェント実行でも応答性が維持されます。 思考やテキストは引き続きストリーミングされます。 Open Design がバックグラウンドで永続化と React の更新をバッチ処理している間、チャットします。 ターミナル遷移は、最後にバッファされた出力をフラッシュします。 od exportも動作します プロジェクト ID のみを使用するため、エージェントはワークスペースやメンバーのフラグを必要としなくなりました。 すでにワークスペース バインディングが保存されているプロジェクトの場合。 (#6915)
  • 🎨 構造化設計システムにより、生成と検証が推進されるようになりました。 設計 システム 3.0 パッケージは、エージェントにインテント マップ、正確なコンポーネント実装、 トークンとルール。エージェントはコンポーネントを生成する前に解決できます。ロードのみ可能です。 宣言されたファイルを検証し、再利用、必要な状態、トークンの使用、および フォールバック動作。同じワークフローを次の方法で利用できます。 od tools design-systems。 (#6805)

✨ 追加しました

  • DeepSeek ハーネス設計ガイドには、検証済みの 13 のコンパニオン コレクションが追加されました。 ビジョン、生成 UI、ワークフロー、およびプレビューの使用ごとにグループ化されたデザイン プラグイン ローカライズされた詳細ページとソースベースのインストール コマンドを使用する場合。 (#6864、#6897)
  • パッケージ化されたアプリは、標準の nix-darwin、NixOS、システム、およびユーザー プロファイルを検索するようになりました ローカルにインストールされたエージェント CLI を検出するときのディレクトリ。 (#6885)

🔁 変更されました

  • ホーム作成行では、最も一般的なプロジェクト タイプが最初に配置され、 DeepSeek Pro と Flash のキャンペーン コピーは製品全体で統一されており、 ローカライズされたランディング ページは 8 月 27 日までです。(#6852、#6863、#6876、#6892)
  • ランディング ページの運用デプロイでは、公開後にアクティブなホストがパージされるようになりました。 HTML の短いエッジ TTL を維持し、訪問者が古いものに費やす時間を削減します リリース後のページ。 (#6552)

🐛 修正済み

🧠 DeepSeek ハーネスとエージェント

  • ハーネスの実行をキャンセルすると、キャンセルされたものとして確定し、プロファイルが終了するようになりました。 プロセスを実行し、プロバイダー エラーの詳細を保存し、正しいプロバイダーと 診断のモデル。キャンセルされたターンは、「作業中」、「完了」、「実行」として表示されなくなりました 失敗した。 (#6880)
  • DeepSeek 資格情報が欠落している場合、dsh web、設定→の手順が生成されるようになりました。 モデル、[object Object] ではなく DEEPSEEK_API_KEY。 (#6890)
  • 長く構造化されたイベント ストリームにより、有用な出力が終了した後にチャットがビジー状態になることがなくなりました。 が表示され、プロジェクトのエクスポートによりワークスペース コンテキストの繰り返しの失敗が回避されます。 (#6915)

🖼️ プレビューとワークスペース UI

  • Chromium が about:srcdoc を中止すると、生成されたプレゼンテーションが回復します ナビゲーション、リバース プロキシの背後で動作するパワード プレビュー、およびコメント ブリッジ レポートの準備が完了する前に、コミットされたプレビュー URL を待ちます。 (#5592、#6797、 #6882)
  • モバイルのコメント プレビューが閉じるときに点滅しなくなり、デッキのプレビューが表示されます。 レターボックスなしのビューアとチームへの移動ダイアログでコンポーザーがカバーされます その下にあります。 (#6785、#6829、#6854)
  • 展開されたメッセージ センターの行には、構成された HTTP(S) アクションが再度表示されます。 安全でないアクションの URL は非表示のままになります。 (#6894)

🖥️ デスクトップと配信

  • サイドカーは、設定された内部ホスト許可リストを受け入れ、パッケージ化されたままになります。 承認された内部ホストの背後で動作する展開。 (#6802)
  • チームの価格設定コピーが、ランディング ページ全体で 1 シートあたり 5 ドルのカタログと一致するようになりました。 表面。 (#6834)

🙏 0.19.2 を発送してくださった皆様、ありがとうございました

open-design open-design-v0.19.2

🌟 Codename: DeepSeek Harness, One Command Away

🧰 28 PRs · 9 contributors · 2 days — 0.19.2 shortens the path from installing DeepSeek Harness to finishing work with it. One command can set up a compatible Harness toolchain, Windows paths with spaces no longer break the Open Design connection, and long streams stay responsive. This patch also adds offline-safe HTML export and the structured Design System 3.0 runtime.

🔥 Highlights

  • 🧰 Install DeepSeek Harness with one command. The new bootstrap scripts cover macOS, Linux, Windows PowerShell, and Windows CMD. They reuse compatible local tools or install an isolated user-scoped Node.js 24 toolchain with the pinned Harness release, then open dsh web for API key setup. Open Design now installs its connection component through a shell-safe profile path, including Windows application and DSH_HOME paths that contain spaces. (#6900, #6905)

  • 📦 Export HTML that keeps working after you move it. Downloaded HTML now bundles project-local images, styles, fonts, modules, workers, and nested documents into one offline-safe file. Missing or oversized dependencies return a clear error instead of a broken export. The same output is available through od export --format html. (#6855)

  • ⚡ Long agent runs stay responsive. Thinking and text still stream into chat while Open Design batches persistence and React updates behind the scenes. Terminal transitions flush the last buffered output. od export also works with a project ID alone, so agents no longer need workspace or member flags for a project that already has a saved workspace binding. (#6915)

  • 🎨 Structured design systems now drive generation and validation. Design System 3.0 packages give agents an intent map, exact component implementations, tokens, and rules. Agents can resolve a component before generating, load only its declared files, then validate reuse, required states, token use, and fallback behavior. The same workflow is available through od tools design-systems. (#6805)

✨ Added

  • The DeepSeek Harness design guide now has a companion collection of 13 verified design plugins, grouped by vision, generative UI, workflow, and preview use cases, with localized detail pages and source-backed install commands. (#6864, #6897)
  • Packaged apps now search standard nix-darwin, NixOS, system, and user profile directories when discovering locally installed agent CLIs. (#6885)

🔁 Changed

  • The Home creation row puts the most common project types first, and the DeepSeek Pro and Flash campaign copy stays aligned across the product and localized landing pages through August 27. (#6852, #6863, #6876, #6892)
  • Landing-page production deploys now purge the active host after publishing and keep a short edge TTL for HTML, reducing the time visitors spend on stale pages after a release. (#6552)

🐛 Fixed

🧠 DeepSeek Harness and agents

  • Canceling a Harness run now settles once as canceled, terminates the profile process, preserves provider error details, and records the correct provider and model in diagnostics. Canceled turns no longer appear as Working, Done, or Run failed. (#6880)
  • Missing DeepSeek credentials now produce steps for dsh web, Settings → Models, and DEEPSEEK_API_KEY instead of [object Object]. (#6890)
  • Long structured event streams no longer leave chat busy after useful output has appeared, and project exports avoid repeated workspace-context failures. (#6915)

🖼️ Preview and workspace UI

  • Generated presentations recover when Chromium aborts an about:srcdoc navigation, powered previews work behind reverse proxies, and comment bridges wait for the committed preview URL before reporting ready. (#5592, #6797, #6882)
  • Mobile comment previews no longer flash during close, deck previews fill the viewer without letterboxing, and the move-to-team dialog covers the composer beneath it. (#6785, #6829, #6854)
  • Expanded Message Center rows show their configured HTTP(S) action again. Unsafe action URLs remain hidden. (#6894)

🖥️ Desktop and delivery

  • Sidecars accept the configured internal host allowlist, which keeps packaged deployments working behind approved internal hosts. (#6802)
  • Team pricing copy now matches the $5 per-seat catalog across landing-page surfaces. (#6834)

🙏 Thanks to everyone who shipped 0.19.2
