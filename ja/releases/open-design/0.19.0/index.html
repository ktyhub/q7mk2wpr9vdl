open-design v0.19.0

マイナー 公開日2026年8月11日 出典nexu-io/open-design English original

オープンデザイン オープンデザイン-v0.19.0

🌟 コード名: 画像生成、ロック解除

🖼️ Open Design サブスクリプションでアイデアを現実化 - 画像を生成 Seedream 5.0 Pro、GPT Image 2.0、および Nano Banana 2.0 を直接使用します。

🔥 ハイライト

  • 🎨 3 つの主力イメージ モデルがサブスクリプションに含まれています。 生成 Seedream 5.0 Pro、GPT Image 2.0、Nano を使用して画像を直接編集することもできます Open Design Cloud 経由の Banana 2.0。エージェントは複数の参照を渡すことができます 画像と明示的なアスペクト比、解像度、および品質設定 選択したモデルがそれらを公開します。リクエストは生成が開始される前にチェックされます。 進行状況は引き続き表示され、出力パスはデーモンから取得され、1 つの一時的なパスが表示されます。 ツール後の中断は、結果を落とすことなく回復できます。ビデオ この世代も、同じ Vela 統合を通じて実行されます。 (#6500)
  • 📤 エクスポート、共有、ハンドオフも直接アクションです。 アーティファクト ビューアは、これらのフローを 1 つのタブ付きポップオーバーの背後に隠すことがなくなりました。リードを次のようにエクスポート ファイル配信アクション。 Share はリンクと公開に重点を置いています。ハンドオフ 分割ボタンに戻ります。 HTML および React コンポーネント ビューアは同じものを使用します 構造が変更され、契約外の編集者の応答によってビューアがクラッシュすることはなくなりました。 (#6654)
  • 🤝 共有プロジェクトでは無駄な作業が減り、より効率的に回復できます。 チーム プロジェクト 同期により、生成されたツリーが一貫して除外され、背景のプルが制限されるようになりました。 マニフェストのサイズを変更し、失敗したパブリッシュを有限バックオフで再試行します。過渡現象 ワークスペースコンテキストの障害は、以前の状態を再利用せずに回復できます。 アカウント、会話フォークは正しい境界を保持し、MCP プロジェクト 操作はサインインしたワークスペースにアタッチされます。 (#6558、#6564、#6595、#6604、 #6605、#6673)

✨ 追加しました

  • MCP clients は、実行を開始するときにいくつかのスキルを提供できます。今のデーモン 選択したすべてのスキル ID を転送します。 (#6429)
  • Launch Week Vol.01 サイトでは、ローカライズされた毎日 5 つのドロップを公開しています キャンペーンページ。リクエスト時の公開コントロールにより、未開封のコンテンツがアクセスされないようにする ページのソース。 (#6647)
  • プレビュー iframe の失敗により、制限された診断イベントが生成され、サポートが提供されるようになりました。 アーティファクトがレンダリングできない場合の具体的なシグナル。 (#6671)

🔁 変更されました

  • Qwen コード モデルの選択は、ユーザー自身の Qwen 設定から行われるようになりました。 組み込みモデルはフォールバックとして保持されます。キーはそれらの設定の横に保存されます 読まれていない。 (#6546)
  • 長いスピーカー ノートは、cli で表示されるのではなく、プレゼンター ビュー内でスクロールします。 デッキのプレビューは、プロジェクトに戻るか、非表示のデッキにロードすると回復します。 ブラウザのタブ。 (#6271、#6519)
  • 「このターンのファイル」では、繰り返されたファイルをカウントするのではなく、一意のファイルをカウントします。 同じファイルへの書き込みと編集を行います。 (#6420)

🐛 修正済み

🧠 実行とプロジェクトの状態

  • 古い再試行世代は新しい世代を閉じることができなくなり、古くなります。 デザインの実行が成功すると、リロードのたびに再アタッチが停止します。 (#6578、#6600)
  • ワークスペース依存の書き込みは、制限付きで一時的な権限の失敗を再試行します。 バックオフが行われますが、アカウントを変更しても古いワークスペース コンテキストは引き続き無効になります。 ワークスペースのエラーには、より有用な診断コードも保持されます。 (#6604、#6666)
  • プロジェクトを削除すると、デザイン ブラウザの履歴とビューポート キャッシュがクリアされます。 新しいコメント ピンは廃止されたピン番号を再利用しなくなり、ダイアログを招待しなくなりました。 タイマーの期限切れから閉じる時間が長くなります。 (#6354、#6517、#6580)
  • ワークスペース外で作成したデザインシステムは再度削除できます。 (#6591)

🔌 エージェントと統合

  • Claude Enterprise 認証は実行時の検出中に認識されます。 (#6652)
  • MCP プロジェクト ツールは、空のワークスペースを返す代わりに、サインインしたワークスペースを使用します。 ワークスペースを対象としたアップグレード後のプロジェクト カタログ。 (#6595)
  • デーモンは、設定された静的ルートから Web アプリのフォールバックを提供するため、 アプリケーション ルートへの直接ナビゲーションは失敗しなくなりました。 (#6614)

🖥️ デスクトップとアップデート

  • パッケージ化された起動では、更新後に永続化されたランチャーのパスが更新されます。 MCP clients は古い実行可能ファイルを再起動してデスクトップの再起動をトリガーしなくなりました ループ。 (#6621)
  • ローカル od:// プロキシは、マシンがなくなるとすぐに再試行を停止します。 失敗したリクエストを増やす代わりに、ソケットまたはファイル記述子の数を増やします。 (#6530)
  • Windows のアンインストールでは、その Windows が所有するプロトコル登録のみが削除されます。 NSIS は、インストール全体にわたって引用符で囲まれたプロトコル コマンドを保持します。 そしてパスを更新します。 (#6694、#6699)
  • 診断エクスポートでは、以前のデーモン セッション ログが保持され、JSONL が保持されます。 イベントの末尾を完全なレコードに合わせて調整します。 (#6531)

🙏 0.19.0 を発送してくださった皆様、ありがとうございました

open-design open-design-v0.19.0

🌟 Codename: Image Generation, Unlocked

🖼️ Bring ideas to life with your Open Design subscription—generate images directly with Seedream 5.0 Pro, GPT Image 2.0, and Nano Banana 2.0.

🔥 Highlights

  • 🎨 Three flagship image models, included with your subscription. Generate and edit images directly with Seedream 5.0 Pro, GPT Image 2.0, and Nano Banana 2.0 through Open Design Cloud. The agent can pass multiple reference images and explicit aspect ratio, resolution, and quality settings when the selected model publishes them. Requests are checked before generation starts, progress remains visible, output paths come from the daemon, and one transient post-tool interruption can recover without dropping the result. Video generation also runs through the same Vela integration. (#6500)

  • 📤 Export, Share, and Handoff are direct actions again. The artifact viewer no longer hides these flows behind one tabbed popover. Export leads as the file-delivery action; Share focuses on links and publishing; Handoff returns to its split button. HTML and React component viewers use the same structure, and an off-contract editor response no longer crashes the viewer. (#6654)

  • 🤝 Shared projects do less wasteful work and recover better. Team project sync now excludes generated trees consistently, bounds background pulls by manifest size, and retries failed publishes on a finite backoff. Transient workspace-context failures can recover without reusing state from a previous account, conversation forks preserve the right boundary, and MCP project operations attach to the signed-in workspace. (#6558, #6564, #6595, #6604, #6605, #6673)

✨ Added

  • MCP clients can supply several skills when starting a run; the daemon now forwards every selected skill ID. (#6429)
  • The Launch Week Vol.01 site publishes five daily drops across localized campaign pages. Request-time reveal controls keep unopened content out of the page source. (#6647)
  • Preview iframe failures now produce bounded diagnostic events, giving support a concrete signal when an artifact cannot render. (#6671)

🔁 Changed

  • Qwen Code model choices now come from the user's own Qwen configuration, with the built-in models retained as fallbacks. Keys stored beside those settings are not read. (#6546)
  • Long speaker notes scroll inside Presenter View instead of being clipped, and deck previews recover after returning to a project or loading in a hidden browser tab. (#6271, #6519)
  • "Files from this turn" counts unique files rather than counting repeated writes and edits to the same file. (#6420)

🐛 Fixed

🧠 Runs and project state

  • An older retry generation can no longer close a newer generation, and stale successful Design runs stop reattaching on every reload. (#6578, #6600)
  • Workspace-dependent writes retry transient authority failures with bounded backoff, while account changes still invalidate old workspace context. Workspace errors also retain more useful diagnostic codes. (#6604, #6666)
  • Deleting a project clears its Design Browser history and viewport cache. New comment pins no longer reuse a retired pin number, and invite dialogs no longer close from an expired timer. (#6354, #6517, #6580)
  • Design systems created outside a workspace can be deleted again. (#6591)

🔌 Agents and integrations

  • Claude Enterprise authentication is recognized during runtime detection. (#6652)
  • MCP project tools use the signed-in workspace instead of returning an empty project catalog after a workspace-scoped upgrade. (#6595)
  • The daemon serves the web app fallback from the configured static root, so direct navigation to application routes no longer fails. (#6614)

🖥️ Desktop and updates

  • Packaged launches refresh the persisted launcher path after an update. MCP clients no longer relaunch an old executable and trigger a desktop restart loop. (#6621)
  • The local od:// proxy stops retrying immediately when the machine runs out of sockets or file descriptors, instead of multiplying the failed requests. (#6530)
  • Windows uninstall removes only the protocol registration owned by that installation, and NSIS preserves the quoted protocol command across install and update paths. (#6694, #6699)
  • Diagnostic exports retain the previous daemon session log and keep JSONL event tails aligned to complete records. (#6531)

🙏 Thanks to everyone who shipped 0.19.0
