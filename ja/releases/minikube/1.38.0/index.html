#ミニクベv1.38.0

📣😀 簡単な 5 つの質問からなるアンケート にご記入ください。これにより、minikube を使用する方法と理由、そしてどのような改善が必要かを知ることができます。ありがとう！ 💃🎉

Release Notes

バージョン 1.38.0 - 2026-01-28

ハイライト

  • macOS 26 以降では vfkit/krunkit に Sudo は必要ありません (最新の vmnet-helper が必要です)
  • [minikube を使用した Macos GPU での AI Playground] (https://minikube.sigs.k8s.io/docs/tutorials/ai-playground/) の実行に Sudo は必要ありません
  • vfkit: Apple シリコン上に amd64 イメージを展開するための Rosetta サポートを追加 (#22140)

特徴

  • Kubernetes v1.35.0 (#21650)(#22015)(#22119)(#22328) のサポートを追加
  • VM ドライバー: NVMe-oF/TCP ブロック デバイスのサポートを追加 (#22464)
  • VM ドライバー: ISO の eBPF ツールをサポートするために BTF デバッグ シンボルを有効にする (#21800)
  • --preload-source を通じて GCS ではなく github からプリロードをダウンロードするオプションを追加 (#22221)
  • Vfkit/Krunkit ドライバー: macOS 26 以降で非特権ユーザーとして vmnet-helper を実行する機能を追加 (#22501)
  • Helm ベースのアドオンを追加するオプションを追加 (#21847)
  • プリロード: gcs が利用できない場合に github からダウンロード (#21605)

警告と非推奨

  • UI: 次のバージョン (v1.39.0) でデフォルトのランタイムを「containerd」に変更する際の警告を追加します (#22508)
  • ハイパーキット: ドライバー ビルドを削除し、ユーザーに切り替えるよう警告 (#21946)
  • 32 ビット アーキテクチャの minikube サポートを削除 (#22401)

改善点

  • UI: ステータスに基づいてカラフル (プロファイルリスト、アドオンリスト) (#22418)
  • --no-kubernetes が設定されている場合、バイナリのキャッシュをスキップします (#21139)
  • 印刷される重複行が少なくなるように再試行ログを改善 (#22232)
  • 証明書ファイルをコピーする SSH ランナーを改善 (#21923)
  • vmnet: ダウンロード専用モードで検証をスキップ (#21635)
  • kubeconfig の Windows 証明書を改善: 生成された証明書パスをスラッシュに正規化 (#21845)
  • API サーバーステータスの cgroup v2 フリーザチェックを追加 (#22249)
  • cgroup v1 の場合、kubenetes 1.35+ の FailCgroupV1 kubelet オプションを設定します (#22319) *containerd: イメージロードの一時的な EOF エラーで再試行 (#22310)
  • cri: crictl コマンドのデフォルトの 2 秒タイムアウトを増加 (#22214)
  • crio: 「image rm」の後にイメージが削除されることを確認する (#22243)
  • docker ランタイム: ListImages 関数に CRI を使用する (#22263)
  • 画像保存: EOF の場合のローカル画像の再試行ロジックを追加 (#22072)
  • HA (マルチ コントロール プレーン): kube-vip を v1.0.0 から v1.0.3 に更新 (#21699)(#21960)(#22258)

ドライバー

  • ドライバー: WaitForSSHAccess を導入し、macos スモーク テストを修正 (#22179)
  • ハイパーキット ドライバー: ステータスのファイル記述子のリークを修正 (#22524)
  • kvm: SELinux を使用した Fedora/RHEL 上の minikube を修正 (#21550)
  • kvm: 外部ドライバーへの依存関係を削除 (#21625)
  • レガシーのParallelsドライバーを非推奨としてマーク (#22379)
  • ドライバーなし:containerd ランタイムの「stop」を修正 (#22275)
  • minikube マシンドライバーを更新 (#22369)
  • AUX ドライバーが正しくインストールされていることを確認し、インストールされていない場合は正常に終了します (#21576)
  • vfkit: Apple シリコン上に amd64 イメージを展開するための Rosetta サポートを追加 (#22140)
  • VM: Kubernetes の「systemd cgroup driver」を使用して cgroup v2 を有効にします… (#22320)

バグ修正

  • KIC ドライバー: crio ランタイムで docker ドライバーを修正: dbus をインストール (#21724)

  • アドオン レジストリ-creds: 設定ファイルなしでセグメンテーション違反を修正 (#21786)

UI

minikube v1.38.0

📣😀 Please fill out our fast 5-question survey so that we can learn how & why you use minikube, and what improvements we should make. Thank you! 💃🎉

Release Notes

Version 1.38.0 - 2026-01-28

Higlights

  • No Sudo required for vfkit/krunkit on macOS 26+ (requires latest vmnet-helper)
  • No Sudo required to run AI Playground on Macos GPUs using minikube
  • vfkit: Add Rosetta support for deploying amd64 images on Apple silicon (#22140)

Features

  • Add support for Kubernetes v1.35.0 (#21650)(#22015)(#22119)(#22328)
  • VM Drivers: add support for NVMe-oF/TCP block devices (#22464)
  • VM Drivers: Enable BTF debug symbols to support eBPF tooling in iso (#21800)
  • Add option to download preloads from github instead of GCS through --preload-source (#22221)
  • Vfkit/Krunkit drivers: add ability to Run vmnet-helper as unprivileged user on macOS 26+ (#22501)
  • add option to add helm-based addons (#21847)
  • preload: download from github when gcs not available (#21605)

Warnings & Deprecations

  • UI: Add a warning on changing default runtime to "containerd" in the next version (v1.39.0) (#22508)
  • hyperkit: remove driver builds & warn users to switch (#21946)
  • Remove minikube support for 32-bit architectures (#22401)

Improvements

  • UI: colorful based on status (profile list, addons list) (#22418)
  • Skip caching binaries when --no-kubernetes is set (#21139)
  • improve retry logs to print less duplicate lines (#22232)
  • improve ssh runner copying cert files (#21923)
  • vmnet: Skip validation in download-only mode (#21635)
  • Improve windows cert in kubeconfig: normalize generated cert paths to forward slashes (#21845)
  • Add cgroup v2 freezer check for API server status (#22249)
  • Set FailCgroupV1 kubelet option for kubenetes 1.35+ if cgroup v1 (#22319)
  • containerd: retry on transient EOF errors for image load (#22310)
  • cri: increase default 2s timeout for crictl commands (#22214)
  • crio: verify images are deleted after "image rm" (#22243)
  • docker runtime: Use CRI for ListImages function (#22263)
  • image save: Add retry logic for local image in case of EOF (#22072)
  • HA (multi-control plane): Update kube-vip from v1.0.0 to v1.0.3 (#21699)(#21960)(#22258)
