#JecgBoot v3.8.1

アップグレードログ

一連の新機能をリリースしました。 AI アプリケーション プラットフォームの機能は安定しています。 Electron デスクトップ アプリケーションをサポートします。 OpenAPI 機能は AK および SK 認証に基づいています。ユーザーインポートは、部門と役割のインポートをサポートします。コード生成は、関連するレコード コントロール、JS 拡張機能、カスタム ボタンなどをサポートします。

新機能
  • [メジャーアップグレード] AIアプリケーションモジュールの機能が安定し、オンライン標準に達しました。
  • [新機能] Electron デスクトップ アプリケーション パッケージングをサポートし、Vite+Vue3+Electron を使用してクライアント デスクトップ アプリケーションを構築します (Windows、Linux、macOS の 3 つの主要なプラットフォームをサポート)
  • [新機能] 外部APIのニーズを解決する「AKおよびSK認証と認証に基づくOpenAPI機能」
  • [新機能] ユーザーインポートで部門と役割のインポートをサポート
  • [新機能] 新しいバージョンの uniapp 用のコード ジェネレーター テンプレートを提供します
  • [新機能] コード生成は、関連するレコード コントロール、JS 拡張機能、およびカスタム ボタン生成の空のメソッドをサポートします。
  • [AI] AIダイアログボックスはモバイル端末をサポートします
  • [最適化] 新しいバージョンの DingTalk ログイン ロジックをサポート
  • [最適化] マルチテナント機能の利用簡素化
  • [新機能] AI OCR サンプルを提供します
  • 私の部門管理、サブ部門の追加と削除が可能
  • jsqlparse コードを削除し、minidao に移行します。アップグレードは jsqlparse の互換性の影響を受けなくなりました。
  • [AI] jdk21と互換性があるため、プログラムは起動できますが、AIプロセスオーケストレーションが使用できない旨のメッセージが表示されます。

  • [AI] プロセスがマルチテナントを有効にすると、インターフェイス呼び出しでプロセスが存在しないことを示すメッセージが表示されます。
  • [AI] プロセス呼び出しインターフェイスがログイン不要に変更されました。
  • JVxetable を新しいバージョン 4.13.31 にアップグレードします。
  • jsqlparser を 4.9 にアップグレードする
  • AIアプリケーション関連機能の権限アノテーションを追加

JeecgBoot v3.8.1

Highlights

  • Security and authorization — Fixes v3.8.0’s zip-bomb vulnerability (Issue #8199), SQL-blacklist bypass (Issue #8335), online-report permission gaps, and high-risk component vulnerabilities in JimuReport 1.9.4 on Spring Boot 3. These fixes matter most for internet-exposed deployments, file uploads, knowledge bases, and reporting.

  • AI platform hardened — AI applications are declared production-ready, with mobile chat, an OCR example, permission annotations, and fixes covering workflow scripts/classification/sub-flows, local DeepSeek and Ollama, stop handling, image parsing, and knowledge-base vectorization. Compatibility caveat: JDK 21 can start the application, but AI workflow orchestration remains unavailable there.

  • New integration and delivery options — Adds AK/SK-authenticated OpenAPI, Electron desktop packaging using Vite + Vue3 + Electron for Windows/Linux/macOS, and user imports that include departments and roles; DingTalk login and department synchronization are also improved. These primarily benefit teams exposing APIs, shipping desktop clients, or bulk-provisioning organizational data.

  • Low-code and dependency changes — Code generation adds related-record controls, JavaScript enhancements, custom-button empty methods, and a uniapp-vue3 template. JVxeTable moves to 4.13.31 and jsqlparser to 4.9, with SQL-parsing code consolidated into MiniDao, alongside numerous table, form, dictionary, and pagination fixes. Custom table extensions and SQL customizations should be regression-tested after these upgrades; no formal migration steps are documented.

  • Upgrade recommendation and API caveat — Strongly recommended for v3.8.0 users, particularly internet-exposed or AI-heavy deployments. Behavior change: the AI workflow-invocation interface now permits calls without login, so review gateway and network controls if those endpoints are reachable. Teams not using AI or desktop features can defer feature adoption if they are already protected from the listed vulnerabilities.
