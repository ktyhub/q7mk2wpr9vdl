#JecgBoot v3.9.0

アップグレードログ

このアップグレードでは、langchain4j が 1.3.0 にアップグレードされ、AI 機能が強化され、MCP とプラグインのサポートが追加され、チャット スタイルの業務運用 (「一文でユーザーを作成」など) が可能になり、AI チャットとプロセス オーケストレーション機能が拡張されます。人間 (クロード)、ネットワーク検索、および推論モデルを統合して、システムの深い思考能力を向上させます。 POIのバージョン5へのバージョンアップを完了し、ユーザー、部門、テナントなどのシステム管理機能を最適化しました。 v3.9.0+より、Spring Boot バージョン2への同時アップグレードを停止させていただきます。

AI機能強化
  • langchain4j をバージョン 1.3.0 にアップグレードします。
  • AI アプリケーションにより、MCP とプラグインのサポートが追加されます。
  • AIチャット機能はMCPおよびプラグイン拡張をサポートします。
  • AI プロセス オーケストレーションにより、MCP とプラグインのサポートが追加されます。
  • ビジネスを行うための AI チャットをサポート (例: 一文でユーザーを作成)
  • Anthropic (Claude) モデルのベンダー サポートを追加しました。
  • AI チャットは推論モデルをサポートし、深い思考能力を向上させます。
  • AIプロセスはエクスポートおよびインポート機能をサポートします
  • AI スクリプト ノードは Python 言語での記述をサポートします
  • AIチャットはQianwenモデルを統合し、オンライン検索機能をサポートします
  • 2000 以上の次元ベクトルをサポートします。pgvector のバージョンは 0.7 より大きい必要があります
機能アーキテクチャのアップグレード
  • v3.9.0+ バージョン以降、Spring Boot 2 バージョンは同時にアップグレードされなくなりました。
  • 変更ログを一括削除してコードの可読性を向上
  • POI がバージョン 5 にアップグレードされました。
  • package.json の依存パッケージのマイナー バージョン番号をアップグレードします。
  • ビルディング ブロック レポートが最新バージョン v2.2.0 にアップグレードされました。
  • Building Block BI は、新しいマルチ画面切り替え機能を備えた最新バージョン v2.2.0 にアップグレードされ、大画面デザインはエクスポートとインポートをサポートします。
  • vite-plugin-pwa を統合してプログレッシブ Web アプリケーション (PWA) を実装し、最初の画面の読み込み速度を大幅に向上させます。
  • システム リソースは非同期で読み込まれ、メニューの応答が速くなります。
  • ログインパスワードは、平文での送信を防止し、セキュリティを向上させるために、AES 暗号化を使用して送信されます。
  • APP と PC のログイン セッションの有効期間を個別に設定することをサポートします。
  • ログイン ルールの柔軟な構成をサポート: ・複数の場所からの同一アカウントへの同時ログインを許可するかどうか。
  • デフォルトのパスワードのログインリマインダーを有効にするかどうか。
  • ログイン認証コードの検証を有効にするかどうか。
  • ログイン ユーザーは、ログイン ルールの区別 (PC と APP の区別) をサポートし、端末デバイス情報を記録して、APP プッシュ機能の実装を容易にします。 ・部門管理に部門長を閲覧できる機能を追加しました。 ・部門管理では部門の上下関係をドラッグ＆ドロップで調整できるようになり、業務の利便性が向上します。
  • ユーザーの位置は、データ関連付け管理を最適化するためにリレーショナル テーブル構造に調整されます。
  • 全体的なユーザー エクスペリエンスを向上させるために、テナント インターフェイスが改訂されました。
  • デフォルトのパスワードルールを最適化してセキュリティを強化します。
  • プライバシーを保護するために、ユーザーの連絡先情報の非表示をサポートします。
  • リッチ テキスト エディターの最適化: ブログからコピーされた記事内の画像が自動的にダウンロードされ、クラウド ストレージにアップロードされます。
  • ログインページに部門選択機能を追加しました
  • BasicTable リスト ページは、Excel にエクスポートする際のエクスポート列の指定をサポートします。
  • uniappプッシュ機能はオンラインおよびオフラインメッセージをサポートします（システムアナウンスにすでに接続されています）
  • ログ出力量を削減するために、ログ レベルが情報からデバッグに調整されます。
  • ロードの遅延によって引き起こされるいくつかの機能障害を最適化し、トークン無視されたアノテーションの障害を修正しました。
  • 生成されたコードは均一に xlsx 形式にエクスポートされます
  • My Messages は既読メッセージの一括削除をサポートします
  • shardingsphere-jdbc を 5.5.0 にアップグレードして、ShardingSphere データ ソース構成を簡素化します
  • ユーザー管理は、組織構造ごとのユーザーのクエリをサポートします (複数選択をサポート) ・ユーザー管理に新たな振り分けフィールドが追加され、振り分けフィールドに応じて人物選択コンポーネントやアドレス帳などの機能が表示されます。

JeecgBoot v3.9.0

Highlights

  • AI model stack — langchain4j moves to 1.3.0, adding Anthropic/Claude support, Qwen web search, and reasoning-model chat. Revalidate provider credentials, model activation, and custom chains after upgrading; model activation and test-connection regressions are also addressed (#8955, #8972, #9071).
  • Tool-enabled AI workflows — MCP and plugins now extend AI apps, chat, and flow orchestration; flows support import/export, and script nodes support Python. Because chat can perform business writes such as creating users, enforce server-side authorization and auditing on tools rather than relying on prompts, and verify the Python execution environment before enabling untrusted workflows.
  • Runtime and dependency baseline — From v3.9.0+, Spring Boot 2 no longer receives synchronized releases, so Boot 2 deployments should plan migration to the Spring Boot 3 line. POI 5, ShardingSphere JDBC 5.5.0, and JimuReport/JimuBI 2.2.0 warrant regression testing of custom export templates, datasource configuration, and report imports.
  • Authentication behavior — Login passwords are AES-encrypted in transit, with separate PC/APP session lifetimes, configurable concurrent-login/captcha/default-password rules, and device tracking. Custom clients and gateways must accommodate the new password payload and session policies; review password-change brute-force protections following #8805.
  • Schema and vector prerequisites — User-position data adopts a relationship-table structure, so audit custom joins and data-migration scripts involving user/post assignments. Embeddings above 2,000 dimensions require pgvector newer than 0.7 (0.8+); plan dimension and index migrations before increasing embedding size.
  • Online low-code reliability — Fixes cover the systemic query-form failure (#8790), Java-enhancement regressions (#8859, #8951), MySQL bigint mapping (#8909), and SQL Server pagination requirements. Generated exports are now uniformly XLSX, and BasicTable supports column-selective export (#9052); update automation that assumes older formats or generated types.

升级日志

本次升级将 langchain4j 升级至 1.3.0，强化 AI 功能，新增 MCP 和插件支持，实现聊天式业务操作（如“一句话创建用户”），扩展 AI 聊天与流程编排能力。集成 Anthropic（Claude）、网络搜索及推理模型，提升系统深度思考能力。完成 POI 升级至 5 版本，优化用户、部门、租户等系统管理功能。 自 v3.9.0+ 起，停止同步升级 Spring Boot 2版。

AI功能增强
  • 升级 langchain4j 至 1.3.0 版本。
  • AI 应用新增对 MCP 和插件的支持。
  • AI 聊天功能支持 MCP 和插件扩展。
  • AI 流程编排新增 MCP 和插件支持。
  • 支持AI聊天做业务(例如：一句话创建用户)
  • 新增 Anthropic（Claude）模型厂商支持。
  • AI 聊天支持推理模型，提升深度思考能力。
  • AI流程支持导出与导入功能
  • AI脚本节点支持 Python 语言编写
  • AI聊天集成千问模型，支持联网搜索功能
  • 支持 2000+ 维度向量，pgvector 版本需大于 0.7
功能架构升级
  • 从 v3.9.0+ 版本起，不再同步升级 Spring Boot 2 版本。
  • 批量删除修改日志，提升代码可读性
  • POI 升级至 5 版本。
  • 升级 package.json 中依赖包的小版本号
  • 积木报表升级至最新版 v2.2.0。
  • 积木 BI 升级至最新版 v2.2.0，新增多屏切换功能，大屏设计支持导出和导入。
  • 集成 vite-plugin-pwa，实现渐进式 Web 应用（PWA），显著提升首屏加载速度。
  • 系统资源实现异步加载，菜单响应速度更快。
  • 登录密码采用 AES 加密传输，杜绝明文传输，提升安全性。
  • 支持单独设置 APP 和 PC 登录会话的有效期。
  • 支持登录规则灵活配置：
  • 是否允许同一账号多地同时登录。
  • 是否开启默认密码登录提醒。
