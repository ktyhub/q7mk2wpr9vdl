#インターンVL v1.2

日付: 2024/02/12<br> 開発者: Zhe Chen、Weiyun Wang、Wenhai Wang、Erfei Cui、Zhangwei Gao、Xizhou Zhu、Lewei Lu、Tong Lu、Yu Qiao、Jifeng Dai InternVL-Chat-V1.2 を導入できることを嬉しく思います。 LLaVA-NeXT-34B からインスピレーションを受け、Nous-Hermes-2-Yi-34B も言語モデルとして採用しました。以下がパイプラインです。

<img width="650" alt="image" src="https://github.com/czczup/InternVL-MoE/assets/23737120/9b68aa35-40fd-4e81-9595-d404cbbfc6bd">

実験結果から、より強力な言語モデル (34B) は、ビジョン基盤モデル (InternViT-6B) の強力な機能をより効果的に活用できることがわかりました。 トレーニングの再現性を高めるために、LLaVA-NeXT と同様の最小限の設計とデータ効率に従います。トレーニング コストを削減するために、事前トレーニング済みの MLP プロジェクターを提供し、SFT 用に約 100 万個の視覚的指示チューニング サンプルのみを使用します。私たちのモデルには合計 400 億のパラメーターがあり、32 個の A100 GPU を使用して 1.5 日以内にトレーニングできます。コード、データ、モデルは公開されます。

データの準備

LLaVA-NeXT からインスピレーションを受け、私たちはデータ効率の高い SFT 戦略を採用して、合計約 120 万のビジュアル命令チューニング サンプルを利用して InternVL-Chat-V1.2 をトレーニングしました。これらのサンプルはすべて完全にオープンソースです。マクロの意味では、ShareGPT-4V を基盤としており、さらに LLaVA-ZH、DVQA、ChartQA、AI2D、DocVQA、GeoQA+、およびSynthDoG-JP。データの大部分は LLaVA-NeXT と一致しています。 データ準備の詳細については、こちら をご覧ください。

InternVL v1.2

Highlights

  • New 40B model backbone — InternVL-Chat-V1.2 pairs InternViT-6B-448px-V1-2 with the 34B Nous-Hermes-2-Yi language model. Adopters should update model references and verify tokenizer, chat-template, and serving configurations for the new language backbone; the release does not document an in-place migration path.

  • Reproducible, lower-cost SFT — A pre-trained MLP projector and approximately 1.2M fully open-source visual instruction samples reduce training work and improve reproducibility. The data mix adds document, chart, diagram, geometry, and synthetic OCR coverage, making this release particularly relevant for document- and chart-heavy multimodal applications.

  • Broad benchmark gains, with important regressions — At 448×448 input resolution, V1.2 improves over LLaVA-NeXT-34B’s 672×672 setup on MMBench (82.2 vs. 79.3), MathVista (47.7 vs. 46.5), and MMMU test (46.2 vs. 44.7). It is not uniformly better: VizWiz drops from 63.8 to 60.0 and GQA from 67.1 to 64.0, so teams should benchmark their target tasks before switching.

  • Full-model training requires substantial resources — The included Slurm scripts support 32- or 64-GPU training, with 64 GPUs taking approximately 18 hours. The recipe fine-tunes all 40B parameters for one epoch using global batch size 512, learning rate 1e-5, maximum length 2048, and weight decay 0.05; this is full-model fine-tuning, not a parameter-efficient projector-only update.

  • Breaking changes — No breaking changes are announced in this release.

Date: 2024/02/12<br> Developed by: Zhe Chen, Weiyun Wang, Wenhai Wang, Erfei Cui, Zhangwei Gao, Xizhou Zhu, Lewei Lu, Tong Lu, Yu Qiao, Jifeng Dai

We are excited to introduce InternVL-Chat-V1.2. Inspired by LLaVA-NeXT-34B, we have also adopted Nous-Hermes-2-Yi-34B as the language model. Below is the pipeline.

<img width="650" alt="image" src="https://github.com/czczup/InternVL-MoE/assets/23737120/9b68aa35-40fd-4e81-9595-d404cbbfc6bd">

From the experimental results, we've observed that a stronger language model (34B) can better leverage the powerful capabilities of our vision foundation model (InternViT-6B).

For better training reproducibility, we follow the minimalist design and data efficiency similar to LLaVA-NeXT. To reduce training costs, we provide a pre-trained MLP projector and only employ around 1 million visual instruction tuning samples for SFT. Our model has a total of 40 billion parameters and can be trained within 1.5 days using 32 A100 GPUs. The code, data, and model will be made publicly available.

Data Preparation

Inspired by LLaVA-NeXT, we adopted a data-efficient SFT strategy to train InternVL-Chat-V1.2, utilizing approximately 1.2M of visual instruction tuning samples in total, all of which are fully open-source. In a macro sense, we build upon ShareGPT-4V and additionally integrate LLaVA-ZH, DVQA, ChartQA, AI2D, DocVQA, GeoQA+, and SynthDoG-EN. Most of the data remains consistent with LLaVA-NeXT.

For more details about data preparation, please see here.

Training (SFT)

We provide slurm scripts for multi-node multi-GPU training. You can use either 32 or 64 GPUs to train this model. If you use 64 GPUs, training will take approximately 18 hours.

For more details about training, please see here.
