#gスタックv1.99.1.0

gスタック v1.99.1.0

主に安全性に関する修正: gstack-uninstall は保存されていない作業を削除しなくなり、Brain Sync とプリプッシュ フックはより多くの隠された秘密を捕捉し、/review と /ship は非クロード ホストの Windows 上で再び起動します。

修正

  • /review と /ship は、Codex、Cursor、およびその他の非クロード ホストの下で Windows 上で再び開始されます。セットアップで必要なファイルが省略されており、/retro と /write-skill には同じギャップがありました (@SatriaSuriaAriffin に感謝) #4286。
  • gstack-uninstall は、別のチェックアウト内にネストされたワークツリー、ロックされたワークツリー、独自の git リポジトリである .gstack/ フォルダー、または続行を要求するときに編集したワークツリーを削除しなくなりました #4267。
  • gstack-uninstall は、実行元のリポジトリだけでなく、削除しようとしているすべてのフォルダーに、コミットされていない、またはプッシュされていない git 作業がないかどうかをチェックし、#4282 が見つかった場合はフォルダーの名前で停止します。
  • Brain Sync は、git がバイナリとして扱うファイルをスキャンし、既存のキーの下に追加された認証値をキャッチするようになりました。そのため、そのようなファイル内のキーはプッシュされなくなりました #4276。
  • Brain Sync は JSON エスケープの背後に隠された秘密を捕捉するようになり、~/.gstack のコミット前フックは同期が行うのと同じ種類の秘密をチェックします #4264。
  • シークレット チェックとプリプッシュ フックは、UTF-16 テキストの 2 行にまたがるシークレットの分割をキャッチするようになり、大きなバイナリ ファイルを削除してもプッシュがブロックされなくなりました #4261。
  • ベンチマークで作業が改善されずに問題が多すぎることが判明したため、gstack の QM エディションには gstack-review が含まれなくなりました。 gstack 自体の /review は変更されていません #4279。

メンテナ向けの変更点

  • /ship レビューの簿記: ドキュメントのみのコミット後に開始される付与されたフォローアップ レビューがカウントされるようになり、所有者の裁定により付与されたフォローアップ レビューで見つかった新しいブロッカーをクリアできるため、/ship はそれらをリストされた状態で終了できます #4278 #4260。
  • マージ前およびマージキューの修正: 部分的なマージ前チェック実行は完全なものとして渡されなくなり、キューは PR をチェックする前に最新のメインをフェッチし、準備完了ノートが GitHub に達しない場合は拒否し、ブランチのみの実行で赤のチェックが隠された場合に警告します #4258 #4256 #4254 #4270。
  • 実行内の無関係なジョブのみが再実行された場合に、再利用された CI 結果が受け入れられるようになりました #4274。
  • テストの修正: マージキュー テスト、新しいリリースごとに失敗するドクター ポリシー テスト、および正しい作業を誤って読み取ったり、独自のフィクスチャと競合した 6 つのテストおよび評価チェック #4271 #4293 #4284。 アップグレード: gstack-artifacts-init (または復元したマシンでは gstack-brain-restore) を再実行して、Brain-Sync のプリコミット フックを更新します。 QM エディションを実行する場合は、その sandbox/skills/gstack-review/ フォルダーを削除して、qm up を実行します。 v1.99.0.0...v1.99.1.0を比較 · フルchangelog

gstack v1.99.1.0

gstack v1.99.1.0

Mostly safety fixes: gstack-uninstall no longer deletes unsaved work, brain sync and the pre-push hook catch more hidden secrets, and /review and /ship start again on Windows under non-Claude hosts.

Fixes

  • /review and /ship start again on Windows under Codex, Cursor and the other non-Claude hosts, where setup had left out files they need, and /retro and /write-skill had the same gap (thanks @SatriaSuriaAriffin) #4286.
  • gstack-uninstall no longer deletes a worktree nested inside another checkout, a locked worktree, a .gstack/ folder that is its own git repo, or a worktree you edit while it asks to continue #4267.
  • gstack-uninstall now checks every folder it is about to delete for uncommitted or unpushed git work, not only the repo you run it from, and stops with the folder's name if it finds any #4282.
  • Brain sync now scans files git treats as binary and catches an auth value added under an existing key, so a key in such a file is no longer pushed #4276.
  • Brain sync now catches secrets hidden behind JSON escapes, and the pre-commit hook in ~/.gstack checks the same kinds of secrets the sync does #4264.
  • The secret check and pre-push hook now catch a secret split across two lines of UTF-16 text, and deleting a large binary file no longer blocks a push #4261.
  • The QM edition of gstack no longer includes gstack-review, after a benchmark found it flagged too many problems without improving the work; gstack's own /review is unchanged #4279.

Changes for maintainers

  • /ship review bookkeeping: a granted follow-up review that starts after a docs-only commit now counts, and an owner's ruling can clear new blockers a granted follow-up review found so /ship can finish with them listed #4278 #4260.
  • Pre-merge and merge-queue fixes: a partial pre-merge check run no longer passes as a full one, the queue fetches the latest main before it checks a PR, it refuses when its ready note never reached GitHub, and it warns when a branch-only run hid a red check #4258 #4256 #4254 #4270.
  • Reused CI results are now accepted when only an unrelated job in the run was rerun #4274.
  • Test fixes: the merge-queue tests, the doctor policy test that failed on every new release, and six test and eval checks that misread correct work or raced their own fixtures #4271 #4293 #4284.

Upgrade: rerun gstack-artifacts-init (or gstack-brain-restore on a machine you restored) to refresh the brain-sync pre-commit hook. If you run the QM edition, delete its sandbox/skills/gstack-review/ folder and run qm up.
