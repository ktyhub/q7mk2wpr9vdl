#gスタックv1.96.0.0

gスタック v1.96.0.0

バージョン 1.92.56.0 から 1.96.0.0 をカバーする大規模リリース: /ship now trust はテストを再実行する代わりにグリーン CI を実行し、危険なコードを詳細なレビューに送信します。ブラウザーにはタッチスクリーン テストとエージェントごとのタブが追加され、新しい /runaway-stopper スキルが追加され、いくつかのセキュリティ修正が行われます。

新機能

  • 新しいスキル: /runaway-stopper は、トークンを書き込んでいるエージェント スレッドとサブエージェントを見つけてクリーン ポイントで停止し、それらが戻らないようにデフォルトを設定します #3975。
  • /ship は、CI の実行がすでにまったく同じコードに渡されている場合に、テスト スイート全体を再実行しなくなりました。その結果を使用して早期にプッシュするため、そのチェックは CI #3901 の横で実行されます。
  • 各プッシュの前に、/ship は、タッチしたファイルに対してリポジトリの簡単なハウスキーピング チェック (生成されたファイル、サイズ ガードなど) を実行し、残ったマージ競合マーカー #3923、#3965 を拒否するようになりました。
  • /ship は、より危険なコードを完全なレビューに送信します。これには、支出および請求コード、評価スコアラー、アウトバウンド ネットワーク呼び出し、アーカイブ、プロセス生成、実行可能ファイル、データを封印したりレビューからファイルを隠すコード、および機密を印刷できるドキュメントが含まれます。リポジトリは、シップ ポリシー #3920、#3829、#3972、#3959、#3864、#3866 の新しい review キーを介して独自のリスク パスを追加できます。
  • /ship のレビュー担当者は独自に他のリポジトリのクローンを作成しなくなり、リポジトリは決して読み取ってはならないパスをリストできるようになりました #4007、#4011。
  • 新しい review_exclude_paths シップ ポリシー キーは、コードと資格情報 #3852 を読み取る行を保持しながら、データ、ログ、および領収書を /ship のレビューから除外します。
  • /review のチェックリストは、プル リクエストの種類 (ドキュメント、CI、スクリプト、またはアプリケーション コード) から始まり、新しいファイルがリポジトリ独自の言語、ツール、プラットフォームに従っているかどうかのチェックを追加します #3852。
  • /ship は、Greptile #3852 だけでなく、リストしたレビュー ボットからのコメントを優先順位付けできます。
  • Anthropic モデルでは、/ship の 2 番目のモデルのレビューはデフォルトで GPT-6.1 Sol (テストされた設定) になり、同じモデル ファミリー #3698 のレビュー担当者を拒否します。
  • Codex の 2 番目のモデルのレビューでは、使用したトークンの数が報告されるようになりました。@omicron-soft #3729 に感謝します。
  • 複数のエージェントが、互いのタブを引き継ぐことなく、同時に gstack のブラウザを操作できます。それぞれが独自のものを取得するか、--session #3858 でセッションに名前を付けることができます。
  • QA は、実際のタッチ入力を使用して電話ページをテストできます。$B device "iPhone 15" は電話をエミュレートし、$B tap、swipe、pinch、および touch はタッチ #3858 を送信します。
  • gstack-clean は、プロジェクトの .gstack/ フォルダー内の古いスクラッチ ファイルとサイズの大きい参照ログを再利用します。 --apply #3858 を渡すまでのみレポートします。
  • Capy の Claude Opus 5.5 セッションでは、コーチング テキストが減った軽量バージョンの gstack スキルが得られ、Claude Code ユーザーは ./setup --loadout lite #3858 でそれを選択できます。
  • /investigate は、モデルが固定の 5 段階の手順に従ってモデルを実行しなくなりました。評価では、この手順に従わなかったことが示されました #3858。
  • 2 つのオプトイン クロード コード フック: ./setup --skill-routing はプロンプトに適合する gstack スキルを提案し、./setup --skill-contracts は「完了手段」ステップが実行される前にスキルが終了するのを停止します #3912。
  • /investigate、/review、/qa、および /verify は、説明内でこれらを使用するタイミングを示し、ユーザーが実際に入力するフレーズのより多くに一致するようになりました #3909。
  • Claude Code と Cursor は、/land-and-deploy または /modernize を独自に開始しなくなりました。コマンドを入力して実行します #3808。
  • /autoplan は、バグ修正の計画レビューをスキップし、機能に対して 1 人の無駄のないレビュー担当者を使用します。また、親エージェントは、gstack-autoplan next --ceo-only #3897、#3767 による CEO レビューのみを実行できます。
  • /plan-tune は、質問が #3868 に関するスキル タグの場合、未登録の質問への回答から学習します。
  • 意図的に古い値を保持する必要があるテストでは、/ship のプリプッシュ リテラル チェックに失敗する代わりに、古い値とその理由を示す 1 行の放棄コメントを保持できるようになりました #3891。
  • Eval Planning は現在、Claude Haiku 5.5、GPT-6 Luna および Gemini 4 Argon の価格を設定しており、/codex は現在の GPT-6 層に名前を付けています。@exGeni と @DanCanadian #3732 に感謝します。
  • /ubicloud によって開始された Ubicloud 実行は、それを開始したマシンが停止した場合に、別のマシンから回復して破棄できます #3961。

修正

  • セキュリティ: gstack のブラウザは、macOS サンドボックス エスケープ (CVE-2026-106378) を修正する Chromium 156 を実行するようになり、browse handoff はブラウザ GSTACK_CHROMIUM_PATH 名 #3947 を使用します。

gstack v1.96.0.0

gstack v1.96.0.0

A large release covering versions 1.92.56.0 to 1.96.0.0: /ship now trusts a green CI run instead of rerunning your tests and sends risky code to deeper review, the browser gains touch-screen testing and per-agent tabs, a new /runaway-stopper skill arrives, and there are several security fixes.

What's new

  • New skill: /runaway-stopper finds agent threads and subagents that are burning tokens, stops them at a clean point, and sets defaults that keep them from coming back #3975.
  • /ship no longer reruns your whole test suite when a CI run already passed on the exact same code; it uses that result and pushes early so its checks run beside CI #3901.
  • Before every push, /ship now runs your repository's quick housekeeping checks (generated files, size guards and the like) for the files you touched, and refuses leftover merge conflict markers #3923, #3965.
  • /ship sends more risky code to its full review: spending and billing code, eval scorers, outbound network calls, archives, process spawning, executables, code that seals data or hides files from review, and docs that can print secrets. A repository can add its own risk paths through a new review key in its ship policy #3920, #3829, #3972, #3959, #3864, #3866.
  • /ship's reviewers no longer clone other repositories on their own, and a repository can list paths they must never read #4007, #4011.
  • A new review_exclude_paths ship-policy key leaves data, logs and receipts out of /ship's review while still keeping code and any line that reads a credential #3852.
  • /review's checklist now starts from the kind of pull request (docs, CI, scripts or application code) and adds a check that new files follow the repository's own languages, tools and platforms #3852.
  • /ship can triage comments from any review bot you list, not only Greptile #3852.
  • On an Anthropic model, /ship's second-model review now defaults to GPT-6.1 Sol, the setup it was tested with, and refuses a reviewer from the same model family #3698.
  • Codex second-model reviews now report how many tokens they used, thanks @omicron-soft #3729.
  • Several agents can drive gstack's browser at once without taking over each other's tab; each gets its own, or you can name a session with --session #3858.
  • QA can test phone pages with real touch input: $B device "iPhone 15" emulates the phone, and $B tap, swipe, pinch and touch send touches #3858.
  • gstack-clean reclaims old scratch files and oversized browse logs in a project's .gstack/ folder; it only reports until you pass --apply #3858.
  • Claude Opus 5.5 sessions on Capy get a lighter version of gstack's skills with less coaching text, and Claude Code users can pick it with ./setup --loadout lite #3858.
  • /investigate no longer walks the model through a fixed five-phase procedure, which an eval showed it never followed #3858.
  • Two opt-in Claude Code hooks: ./setup --skill-routing suggests the gstack skill that fits your prompt, and ./setup --skill-contracts stops a skill from ending before its "done means" steps ran #3912.
  • /investigate, /review, /qa and /verify now say when to use them in their descriptions and match more of the phrases people actually type #3909.
  • Claude Code and Cursor no longer start /land-and-deploy or /modernize on their own; type the command to run them #3808.
  • /autoplan skips plan review for bug fixes and uses one lean reviewer for features, and a parent agent can run only its CEO review with gstack-autoplan next --ceo-only #3897, #3767.
  • /plan-tune learns from answers to unregistered questions when the skill tags which preference the question is about #3868.
  • A test that must keep an old value on purpose can now hold a one-line waiver comment naming the old value and the reason, instead of failing /ship's pre-push literals check #3891.
  • Eval planning now prices Claude Haiku 5.5, GPT-6 Luna and Gemini 4 Argon, and /codex names the current GPT-6 tiers, thanks @exGeni and @DanCanadian #3732.
  • A Ubicloud run started by /ubicloud can be recovered and torn down from another machine if the machine that started it dies #3961.

Fixes

  • Security: gstack's browser now runs Chromium 156, which fixes a macOS sandbox escape (CVE-2026-106378), and browse handoff uses the browser GSTACK_CHROMIUM_PATH names #3947.
  • Security: /setup-browser-cookies now warns that the fallback browser still trusts the compromised eMudhra certificate authorities #3871.
  • Security: the qs and @hono/node-server dependencies are pinned past two medium-severity advisories #3870.
  • Security: the lean /autoplan reviewer no longer receives .envrc, .env-production, credential files or keys pasted into ordinary files #3921.
  • On public repositories, /ship no longer pastes the owner's approval words, run ids or plan hashes into the pull request description #3918.
  • gstack-autoplan export --public no longer includes the owner's own replies or quoted words #3967.
  • review_exclude_paths can no longer hide native binaries, code with a NUL byte, or a file marked binary that holds a credential line from review #3902.
  • /design-consultation and /design-review now use ease-out for exit animations instead of ease-in, thanks @nfitzsimmons #3963.
  • /retro keeps its history across git worktrees, so a run in a linked worktree compares against last week instead of starting over #3848.
  • A local main branch behind origin/main no longer changes what /ship and /review count as your change or how deeply they review it #3848, #3852, #3906.
  • /ship works on a checkout whose origin/HEAD points at the pull request branch itself, and stops instead of guessing when origin's default branch can't be read #3852, #3913.
  • Fewer false alarms in /ship's review planning: design-token files, file names that mention "cost", authorship files and chart SVGs no longer trigger extra reviewers, and one very long line can no longer stall planning #3999, #3942, #3906, #3848.
  • /ship no longer treats a reviewer's own "I found nothing CRITICAL." as a critical finding #3990.
  • /ship's second-model review: a "can't verify" reply is no longer read as a pass, numbered findings without a P0-P3 tag are kept, a ## Recommendation heading counts as finished (thanks @nfitzsimmons), and on Capy a hung review is stopped and recorded as missing #3946, #4000, #3895.
  • /ship asks for less re-review: base merges and docs commits keep review credit, a required edit or small change after review gets one scoped re-check instead of another full round, and lines brought in by a base merge don't count against the re-check #3970, #4020, #3926, #3955.
  • A stacked pull request keeps its /ship review after its parent squash-merges into main #3928, #3940.
  • Running /ship's full preflight again during an open /ship run no longer merges the base under its reviewers #3950.
  • /ship no longer crashes when every reviewer comes back clean, and two smaller /ship papercuts are fixed #3945.
  • /ship and /review no longer write exploratory QA reports into your project folder #3898.
  • A finished /ship no longer blocks gstack-upgrade for two hours #3932.
  • On a shared machine, an install for another workflow or reviewer no longer breaks /ship's or /autoplan's install check, and the lean /autoplan reviewer sees the committed draft on a pull request branch #3960, #3919, #3969.
  • gstack-ship-preflight --timeout now reaches the test step, so a test group longer than 10 minutes can finish #3927.
  • /ship's pre-push tests: a quiet but busy suite is no longer killed, a missing pytest is no longer blamed on your branch, Playwright specs and mixed-language tests get the right runner, and large diffs no longer crash the check (thanks @vilano93 and @nfitzsimmons) #3899, #3741, #3986, #3988.
  • /ship's pre-push checks no longer reject real files named like probe.py as scratch, or flag a newly added value as a changed one #3944.
  • Fewer secret-scan false positives: file names and keys passed to a lookup, Python and Dart string interpolation, short git shas, gstack version numbers and GitHub Actions run lists are no longer flagged #3893, #3782, #3998, #3941, #3949.
  • gstack-post pr-body keeps a pull request's opening paragraph and Capy badge #3949.
  • Renderers such as gstack-pr-shots install Chromium on first use instead of failing with an unclear error #3941.
  • browse starts again when proxy credentials come from BROWSE_PROXY_USER and BROWSE_PROXY_PASS #3739.
  • A tap right after $B goto now lands where you aimed #3956.
  • On Windows, native cookie import waits for Edge to actually exit before cleaning up #3805.
  • /pair-agent now says its instruction block includes the first and last ===== lines #3800.
  • A gbrain serve --http on this machine's loopback address counts as a local brain again, so transcripts are imported #3727.
  • /setup-gbrain no longer stops on a working brain because gbrain's checks failed on another agent's skills folder #3802.
  • /sync-gbrain's search guidance names the right source for past plans and retros. Reported by @extremenelson #3810.
  • Hermes can start gstack skills again, and the OpenClaw and Hermes start hook no longer breaks a harness that has no config yet #3825, #3794.
  • ./setup no longer starts several processes per skill just to read its name, which could hang Git Bash on Windows on ARM, thanks @habassa5 #3752.
  • On Windows, /ship records the session kind correctly, and the question-log hook no longer kills a slow first run #3823, #3948.
  • gstack-doctor finds its launch check again on macOS's built-in bash, thanks @bokeeeey #3753.
  • Overlapping background profile updates no longer drop /office-hours sessions, and /plan-tune no longer reports a preference mismatch with no answers behind it #3738, #3856.
  • On Capy, the installer picks the lighter skills from your model preference, and they keep your gbrain setup, disabled skills and the evidence rule #3872, #3874.
  • The skill-contract check runs through gstack's own install path and no longer counts an unrelated agent call as the required one #3957, #3964, #3933.
  • /runaway-stopper no longer reports a clean sweep when run from an automation thread outside the group it watches #3983.
  • gstack-ubi sync and pack work on a subdirectory of a git checkout #3839.

Changes for maintainers

  • gstack's merge and release tooling: pull requests merge directly at their own green head, versions are written at release, a paid release check can run on main every 8 hours and fails closed, and merge-step fixes cover stale bases, lost lock pushes, frozen queues and other projects' version strings, and the merge planner leaves out pull requests that conflict with main #3973, #3977, #3978, #3917, #3982, #3984, #3994, #4001, #3968, #3811.
  • CI reuse and test evidence: pull requests reuse a green CI run they can't control, more ways to map test runs to CI jobs, labels with spaces, sharded counts, skipped files, owner-granted flaky exceptions, and stricter run-URL checks #3929, #3930, #3934, #3935, #3985, #3883, #3865, #3841, #3832, #3911, #3952, #3801.
  • The pre-push remote test VM can be reattached after a restart instead of destroyed #3886.
  • /ship review records and receipts: blocker counts, the money and security re-read, fix-check rounds, owner edits after a fix-check, version changes after review, and the gstack version in the receipt are recorded accurately #3845, #3887, #3859, #3931, #3863, #3884, #3861, #3916, #3717, #3830, #3798, #4003, #3889, #3892, #3862, #3834, #3873, #3875, #4002, #4018, #3937.
  • /ship's finding collector reads severity from each finding's own fields #3867, #3869, #3894, #4017, #4019.
  • /ship's workflow text was made consistent with its tools #3996, #4004, #4006, #3881, #3981.
  • The AI scorers that graded skill prose or guessed agent behavior were removed, and the review-bot history check is now free #4009, #4014.
  • Trunk Dynamic CI watches pull request CI in learning mode only, Windows checks run by changed path, and CI uses larger runners with sub-shards and ffmpeg in the eval image #4012, #3904, #3846, #3730, #3962.
  • Eval docs and tooling: frontier models under test, flaky-test quarantine, Windows support tiers, priced paid trials, narrower paid screens, and red screens that name their failed rule cases #3847, #3888, #3882, #3958.
  • gstack adopts the "earn its place" principle: every part needs evidence that it helps, recorded in an evidence inventory #3837, #4005.
  • Agent and contributor docs: agents comment only under a bot identity and never on a maintainer's behalf, postmortems after reverts, routine stops recorded and skipped, plan-first rules, new-thread rules, and bin/dev-setup works in a fresh clone #4022, #4010, #3807, #3976, #3908, #3971, #3789.
  • The sealed-data guard skips commits the destination already holds and can refuse records that pair a label with an identifier #3689, #3747.
  • /health finds its tools with gstack's shared detector #3691.
  • /autoplan can record a hidden CEO-only prediction before each owner answer, for evaluation (off by default) #3858.
  • Test repairs and speedups: flaky-test passes, faster git fixtures, review pin files, and gstack's tests never touch a developer's real gbrain (thanks @AndreIntelas) #3804, #3878, #3953, #3954, #3896, #3716, #3761, #3936, #3974, #3877, #3582, #3586, #3822, #3860, #3997, #3816, #3903, #3876.
