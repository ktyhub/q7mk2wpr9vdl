PageIndex v0.3.0.dev3

Highlights

  • Multi-provider LLM support via LiteLLM — PR #168 replaces the OpenAI-only call path with LiteLLM, so model identifiers are no longer locked to OpenAI; PR #194 auto-prefixes retrieve_model values with litellm/ and disables agent tracing by default, and PR #342 pins litellm ≥1.84.0 to resolve a python-dotenv install conflict (after PR #214 bumped 1.82→1.83). Watch out: any custom retrieve_model overrides may need the prefix adjusted, and the tracing default change affects anyone who relied on agent traces.
  • Agent-based retrieval client — PR #125 introduces PageIndexClient on top of the OpenAI Agents SDK, giving adopters an agentic retrieval path over PageIndex's vectorless, tree-based index; PR #238 adds SDK compatibility, and PR #226 fixes cloud add_document to poll for status=="completed" rather than returning early — critical if your pipeline queries a document immediately after upload.
  • CLI entry point and repo layout reshuffle — PR #4 relocates the CLI entry point to run_pageindex.py, with PR #184 flattening the root directory and PR #189 restructuring examples/ and document storage (PR #191 simplifies the vectorless RAG demo to match). Scripts or imports bound to the old paths/entry point will need updating — this is the main migration friction in the release.
  • TOC/tree-building hardening — A cluster of fixes makes tree construction much more robust on messy documents: PR #21 handles TOC items exceeding document length, PR #65 eliminates an infinite loop in extract_toc_content, PR #188 prevents a KeyError crash and context exhaustion, PR #167 fixes list_index shadowing in fix_incorrect_toc, PR #331 uses .get() in get_leaf_nodes to avoid KeyError on leaf nodes, PR #281 restores a missing re import, and PR #109 corrects a tob→toc prompt-variable typo that could leave prompts with an undefined variable. Expect fewer hangs and crashes on irregular PDFs.
  • Markdown tree output — PR #32/#33 add a markdown-tree capability, letting the document hierarchy be emitted as markdown — useful for inspecting the generated structure or feeding it into downstream text-based tooling.
  • Packaging and CI maturity — PR #347 publishes to PyPI on version tags, making pip install a supported path; PR #241 adds Dependabot config, PR #248 adds security CI workflows, PR #338 bumps actions/checkout 4→7, and PR #63 makes ChatGPT_API_with_finish_reason return a consistent tuple (a subtle API-shape fix for callers unpacking its result).

No breaking changes were formally declared in this release.
