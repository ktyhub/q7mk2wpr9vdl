#オープンCLI v1.8.1

何が変わったのか

  • docs(readme): https://github.com/jackwener/OpenCLI/pull/1684 の @jackwener による開発者向けセクションを削除
  • ドキュメント (readme): CLI ハブ ブランド エイリアス + 終了コードが https://github.com/jackwener/OpenCLI/pull/1685 の @jackwener によってドキュメントに分割されました
  • 修正(bilibili): 字幕サポートbangumi/PGC bvid（番ストーリー/纪录片/电影/综艺） by @huanghe in https://github.com/jackwener/OpenCLI/pull/1669
  • 修正(xiaohongshu/download): INITIAL_STATE.imageList を介してカルーセルの順序を保存 (https://github.com/jackwener/OpenCLI/pull/1687 の @Benjamin-eecs による)
  • https://github.com/jackwener/OpenCLI/pull/1690 の @BruceLoveDecimal による jira confluence サポートを追加
  • feat(チェス): Chess.com アダプター (統計 / ゲーム / ゲーム / 分析) を追加 (https://github.com/jackwener/OpenCLI/pull/1659 の @Benjamin-eecs による)
  • 修正(拡張機能): https://github.com/jackwener/OpenCLI/pull/1693 の @kagura-agent による重複を防ぐためにタブ グループの作成をシリアル化します (修正 #1692)
  • feat(bilibili): https://github.com/jackwener/OpenCLI/pull/1588 の @asimovVong によるコメント コマンドと --parent 返信スレッドの読み取りを追加
  • ドキュメント (readme): 正しいノード フロア (>=20) + https://github.com/jackwener/OpenCLI/pull/1705 の @jackwener による冗長な前提条件セクションを削除
  • 修正: https://github.com/jackwener/OpenCLI/pull/1699 で @hiSandog によるバイト フォーマットを安定化
  • 修正 (twitter): https://github.com/jackwener/OpenCLI/pull/1702 の @Benjamin-eecs によるプライベートの「いいね！」/空のタイムライン形状のフォローを検出
  • fix(douyin/hashtag): https://github.com/jackwener/OpenCLI/pull/1697 の @Benjamin-eecs による API 呼び出しの前に、アクションごとに必要な引数を検証します
  • feat(notebooklm): https://github.com/jackwener/OpenCLI/pull/1691 の @Benjamin-eecs による create / add-source / write-note /generate-audio /generate-slides 書き込みコマンドを追加
  • feat(upwork): https://github.com/jackwener/OpenCLI/pull/1609 の @NSOiO による検索、フィード、詳細コマンドを追加
  • feat(geogebra): @gallexy-liu による GeoGebra ブラウザ アダプター スイートを https://github.com/jackwener/OpenCLI/pull/1591 に追加
  • 機能 (weread): https://github.com/jackwener/OpenCLI/pull/1577 の @galaxypluto による WeRead 本内を検索するための「weread book search」を追加
  • 修正（ドクター）: https://github.com/jackwener/OpenCLI/pull/1718 で @truffle-dev によって「接続されていません」と報告される前に、拡張機能の再接続を短時間ポーリングします。
  • 修正 (twitter): CDP 許可されていないエラーを処理し、ファイル プロパティの再定義を修正し、https://github.com/jackwener/OpenCLI/pull/1717 の @lvsao による返信ボタン待機を追加しました。
  • https://github.com/jackwener/OpenCLI/pull/1721 の @jackwener による「fix(doctor): 内線再接続のために短時間ポーリング」(#1718) を元に戻す
  • fix(suno): https://github.com/jackwener/OpenCLI/pull/1706 の @Benjamin-eecs による従来の data.plan ではなく subscription_type + plan[] から現在のプランを導出
  • feat(linkedin): https://github.com/jackwener/OpenCLI/pull/1731 の @jackwener によるプロフィール、求人、投稿、プロジェクトの読者を統合します。
  • テスト (ダウンロード): ランナーのコールド スタートの差異を吸収するためにメディア ダウンロード Windows テストを再試行 (https://github.com/jackwener/OpenCLI/pull/1708 の @Benjamin-eecs による)
  • 修正(xiaohongshu): ダッシュボードのフェッチをフックして、https://github.com/jackwener/OpenCLI/pull/1732 の @Benjamin-eecs による署名済みのデータセンター/メモ/* 応答をキャプチャします。
  • fix(zhihu): https://github.com/jackwener/OpenCLI/pull/1695 で @lenovobenben によって出力されたテキスト内の数値エンティティをデコードします
  • chore(ci): https://github.com/jackwener/OpenCLI/pull/1755 の @jackwener による dependabot の更新を無効にする
  • 修正 (ダウンロード): https://github.com/jackwener/OpenCLI/pull/1742 の @Benjamin-eecs による 0o600 の所有者のみのアクセス許可で yt-dlp Cookie ファイルを書き込む (修正 #1741)
  • feat(linkedin): https://github.com/jackwener/OpenCLI/pull/1738 の @gauravsaxena1997 によるプロフィール エクスペリエンスを読む
  • feat(xiaohongshu): https://github.com/jackwener/OpenCLI/pull/1736 の @Benjamin-eecs による、10 行 /analyze/list の上限を超えてクリエイター ノートをページ分割しました。
  • 修正: https://github.com/jackwener/OpenCLI/pull/1752 の @hiSandog による WeRead 検索 HTML エンティティのデコード
  • 修正 (twitter): https://github.com/jackwener/OpenCLI/pull/1746 の @Astro-Han による result.core からプロファイル名/created_at を読み取ります (修正 #1745)
  • ドキュメント (readme): https://github.com/jackwener/OpenCLI/pull/1773 の @jackwener によって、Trendshift トレンド リポジトリ バッジを README の先頭に追加します。
  • https://github.com/jackwener/OpenCLI/pull/1774 の @jackwener による「docs(readme): add Trendshift バッジ」(#1773) を元に戻します
  • 雑務(拡張子): https://github.com/jackwener/OpenCLI/pull/1792 の @jackwener による 1.0.16 へのバンプ
  • 修正 (twitter): https://github.com/jackwener/OpenCLI/pull/1776 の @Benjamin-eecs により、検索/通知/次の行フィールドに「不明」のサイレント センチネルをドロップ
  • 修正（pixiv）: https://github.com/jackwener/OpenCLI/pull/1768 の @Benjamin-eecs による入力エラーについて、ユーザー/詳細を pixivFetch ヘルパーに移行
  • 修正 (ブラウザ): https://github.com/jackwener/OpenCLI/pull/1766 の @Benjamin-eecs による 0o600 の所有者のみのアクセス許可でネットワーク キャッシュ ファイルを書き込む
  • 修正(拡張機能): https://github.com/jackwener/OpenCLI/pull/1794 で @jackwener が所有するタブ グループを統合
  • 雑用(リリース): 1.8.1 by @jackwener (https://github.com/jackwener/OpenCLI/pull/1795)

OpenCLI v1.8.1

Highlights

  • Broader CLI coverage — Jira/Confluence support (#1690), Upwork search/feed/detail commands (#1609), Chess.com stats/games/game/analyze (#1659), GeoGebra browser adapters (#1591), and WeRead in-book search (#1577) expand automation into team and research workflows. Bilibili also adds comment reads and --parent reply-thread access (#1588), enabling discussion-level collection beyond video metadata.
  • NotebookLM moves from retrieval to authoring — New create, add-source, write-note, generate-audio, and generate-slides commands (#1691) let scripts build notebooks and generate media. Treat these as side-effecting operations, not ordinary read commands.
  • LinkedIn and Xiaohongshu results are more complete — LinkedIn consolidates profile/jobs/posts/projects readers and adds profile experience (#1731, #1738), reducing output fragmentation. Xiaohongshu paginates creator notes beyond the 10-row /analyze/list cap (#1736), preserves carousel ordering (#1687), and captures signed note responses (#1732), reducing truncated or misordered downstream datasets.
  • Adapter data handling changes — X/Twitter no longer emits the literal "unknown" for unavailable search/notifications/following row fields (#1776), so parsers should handle missing values instead. Suno now derives plan information from subscription_type plus plans[] rather than legacy data.plan (#1706); integrations examining raw responses should follow the new shape.
  • Browser automation and local credentials are hardened — Serialized tab-group creation (#1693) and convergence of owned groups (#1794) reduce duplicate or stale groups, shipped with extension 1.0.16 (#1792). Separately, yt-dlp cookie files and browser network caches now use owner-only 0o600 permissions (#1742, #1766), protecting session data from other local users.
  • Breaking changes — None declared; Node.js >=20 remains required (#1705).
