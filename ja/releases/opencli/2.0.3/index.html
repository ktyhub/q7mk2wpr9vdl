OpenCLI v2.0.3

パッチ 公開日2026年11月7日 出典jackwener/OpenCLI English original

OpenCLI v2.0.3

Chrome 拡張機能 1.0.27 が含まれています。ループバック接続、ネイティブ キーボード入力、ブラウザ ウィンドウの回復修正のための拡張機能を更新します。

機能

  • Pinduoduo 検索と Twitter メンバーリストコマンドを追加します。
  • Twitter の検索結果に返信とリツイートを含め、認証失敗時にサイト ログイン コマンドを提案します。

修正

  • デーモン、CLI、および拡張機能全体で到達可能なループバック アドレスについて合意します。新しいデーモンを古い CLI に置き換えることは避けてください。
  • ブラウザー clicks を解決された要素に向け、兄弟オクルージョンを検出し、完全なネイティブ キーボード イベントを送信し、再起動後に所有されているアイドル状態のウィンドウを回復します。
  • ファイル選択が開かない場合は、DataTransfer アップロードに戻ります。 Windows 上の古いプラグイン ホスト ジャンクションを安全に置き換えます。
  • パイプライン内の JavaScript パイプと引用符で囲まれた式を保持し、URL フラグメントの前にクエリ パラメーターを追加し、CSV/Markdown ヘッダーをエスケープします。
  • 同時ダウンロードの一時ファイルを分離し、記事のコード ブロックを保存し、yt-dlp の失敗終了ステータスを尊重します。
  • LinkedIn のエクスペリエンス、アクティビティ、およびジョブの解析を改善します。 Weixin の検証と記事のレンダリングを待ちます。 Ctrip の列車ナビゲーションを修正しました。
  • Twitter ID、Facebook 検索、Reddit のブロックされたページの処理、JD ログイン検出、Gemini 会話抽出、Grok セッション/テキスト抽出、YouTube ログイン検出を改善します。
  • Xiaohonshu の検索と作成者ノートの抽出を更新し、アンロードされたインタラクションのカウントをゼロではなくエラーとして報告します。
  • 公開されたセキュリティ アドバイザリについては、undici を 7.30.1 に更新します。

OpenCLI v2.0.3

Highlights

  • Upgrade the extension alongside the CLI — Chrome extension 1.0.27 is required: daemon, CLI, and extension now agree on a single loopback address (#2782), and a CLI will only replace a daemon strictly older than itself (#2783). Mixed versions previously produced "daemon unreachable" connection failures, so treat the three components as one atomic upgrade rather than updating the CLI alone.
  • Browser interactions finally hit their targets — retargeted clicks now aim at the resolved element instead of an ancestor's centre, with sibling-occlusion detection (#2682); native key presses carry code, keyCode, and keypress text (#2756); owned idle windows are recovered after a restart (#2703); and uploads fall back to DataTransfer when the intercepted file chooser never opens (#2683). These fix the click-misses and form/upload flakiness that otherwise look like site breakage, especially on dynamic SPAs.
  • Security dependency refresh — undici is bumped to 7.30.1 to close three published advisories (#2709). Because undici backs the HTTP layer used across the site adapters, resolve this transitively in your lockfile even if you never import it directly.
  • Pipeline and output fidelity — pipes inside JavaScript expressions are preserved (#2742), quoted expressions now evaluate (#2696), query parameters are appended before URL fragments (#2738), and CSV/Markdown column headers are escaped (#2743). These were silent data-corruption bugs: downstream parsers previously received malformed URLs and broken tables, so re-validate any generated exports from earlier versions.
  • Download reliability — concurrent transfers now use isolated temporary files (#2741), article code blocks are preserved verbatim (#2745), and yt-dlp's failure exit status is honored (#2744). Parallel jobs no longer clobber each other, and failed downloads surface as errors instead of passing as apparent successes — worth checking if you branch on download exit codes.
  • New commands and stricter failure semantics — Pinduoduo search (#2752) and Twitter list-members (#2785) are added; Twitter search now includes replies and retweets (#2766), and not_logged_in rows suggest the relevant site-login command (#2775). In the same vein, more adapters now fail typed instead of returning misleading zeros or empty results: Xiaohongshu interaction counts that never load (#2708), JD search redirects to login (#2754), and Reddit's network-security block (#2784). Audit any automation that treats 0 or an empty result as valid data.

No breaking API changes in this release.

Includes Chrome extension 1.0.27. Update the extension for loopback connectivity, native keyboard input, and browser-window recovery fixes.

Features

  • Add Pinduoduo search and Twitter list-members commands.
  • Include replies and retweets in Twitter search results, and suggest site login commands on authentication failures.

Fixes

  • Agree on a reachable loopback address across the daemon, CLI, and extension; avoid replacing a newer daemon with an older CLI.
  • Aim browser clicks at the resolved element, detect sibling occlusion, send complete native keyboard events, and recover owned idle windows after restart.
  • Fall back to DataTransfer uploads when the file chooser does not open; safely replace stale plugin host junctions on Windows.
  • Preserve JavaScript pipes and quoted expressions in pipelines, append query parameters before URL fragments, and escape CSV/Markdown headers.
  • Isolate concurrent download temporary files, preserve article code blocks, and honor yt-dlp failure exit status.
  • Improve LinkedIn experience, activity, and job parsing; wait for Weixin verification and article rendering; fix Ctrip train navigation.
  • Improve Twitter identity, Facebook search, Reddit blocked-page handling, JD login detection, Gemini conversation extraction, Grok session/text extraction, and YouTube login detection.
  • Update Xiaohongshu search and creator-note extraction, and report unloaded interaction counts as errors rather than zero.
  • Update undici to 7.30.1 for published security advisories.
