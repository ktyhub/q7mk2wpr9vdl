スラング v0.5.12

ハイライト

  • DeepSeek V4 サポート: DeepSeek-V4 (#23882) の完全な推論パス。以下が含まれます。 0 日目の機能: #23882
    • 並列処理: テンソル並列処理/エキスパート並列処理/コンテキスト並列処理/データ並列処理
    • ハードウェア: Nvidia B300/B200/H200/H100/GB200/GB300、AMD MI35X
    • プリフィルとデコードの分解
    • 非アクティブな KV キャッシュを CPU メモリにオフロードするための HiSparse
    • Reasoning ParserとTool Call Parser
    • MegaMoE を含む DeepSeek V4 用の DeepGemm および FlashMLA カーネル Day-0 以降の追加:
    • 統合基数ツリー [UnifiedTree] の下の DeepSeek V4 用 HiCache: #24691
    • W4A4 MegaMoE カーネル — 精度の低下は無視できるものの、高速化: #25052
    • ホッパー上の Marlin/FlashInfer W4A8 MoE カーネル: #24816 #24986
    • 高速な V2 融合圧縮カーネル: #24890
    • H100/H20 での TP16 サポート: #24949
    • 融合 SiLU+クランプ+FP8 クォント カーネル: #24897
    • 最適化された MHC + DeepGemm パイプライン (融合ノルム、融合 hc_head): #24775
    • DSv4 の非標準チャット テンプレートのサポート: #23915
    • マルチデトークナイザーのサポート: #24944
    • DeepSeek-V4 のパイプライン並列処理 + PD サポート: #24700
    • すべての Nvidia GPU 用の統合 docker タグ lmsysorg/sglang:v0.5.12 詳細については、LMSYS ブログ および DeepSeek-V4 クックブック を参照してください。
  • TokenSpeed MLA アテンション バックエンド (Blackwell、FP8 KV キャッシュ): SM100 上のアテンション バックエンドとして統合された新しい MLA プリフィル/デコード カーネル。低遅延 MLA サービングのための FP8 KV キャッシュ サポートを備えています: #24925
  • DSv3.2 / GLM-5 FP4 低遅延パフォーマンス: DSv3.2 / GLM-5 カーネル全体で PDL が有効になり、DeepSeek V3.2 インデクサー GEMM 用の torch.mm、および Cute-DSL FP4 デンス GEMM の再ランド — FP4 パス上の低遅延オーバーヘッドを大幅にトリミング: #23965、#23856、 #23590、#25311
  • 新しいモデルのサポート: DeepSeek V4 #23882、Intern-S2-Preview #24875、MiniCPM-V 4.6 #24855、Laguna-XS.2 #24204、Ring-2.6-1T #25360、および Gemma 4 MTP #24436 — 調整された展開コマンドのクックブック レシピ付き。 docs.sglang.io/cookbook を参照してください。
  • HiCache + UnifiedRadixTree: UnifiedRadixTree (SWA を使用) の HiCache フレームワーク サポート、DeepSeek V4 の HiCache、Mooncake ストアを介した SSD オフロード、およびカスケード エビクション、トゥームストーン リプレイ、および部分一致パス全体の安定性修正: #23316、#23391、#24691、#24277、#24943、 #24972、#25068、#25277
  • 投機的デコーディング V2 の成熟度: アダプティブ スペック V2、EAGLE-3 SWA + 新しいドラフター、Kimi K2.5 EAGLE-3 MLA、Gemma 3/4 + EAGLE-3、およびドラフト拡張パスにわたる広範な名前付け/形状処理リファクタリング: #23336、#24663、#24664、#24826、 #23976、#24859
  • CUDA 13 DeepEP の移行: ゲートウェイ DeepEP ソースがコミュニティ フォークから deepseek-ai/DeepEP@hybrid-ep にスワップされたため、DeepEP は CUDA 13 デフォルトで正常にビルドおよび実行されます。 FlashInfer は gpt-oss triton-kernel 修正とともに 0.6.11.post1 に固定されました: #25113
