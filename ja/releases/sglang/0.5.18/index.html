MiniMax-M2.7、GLM-5.1、Kimi-K2.6、Qwen3.5-397B、DeepSeek-R1 (#29328) における 97.5-100.2% GSM8K リカバリと NVFP4 リファレンスの比較。 KIMI K3 は MI355X 向けに調整されています: グループ化されたヘッド MLA 検証カーネルは、共有レイテントをヘッドごとに 1 回再読み取りする MHA 形状の分割 KV パスを置き換え、同時実行数 2 ～ 32 で 1.37-1.77x スループットおよび 1.45-2.42x ITL を実現します。 AITER MLA プレフィル カーネルは、K3 の 12 ヘッド形状 (TTFT 最大 -14.9%) を受け入れるようになりました。 gfx950 で調整されたデコード ステージ 1 ジオメトリは、SGLANG_MLA_DECODE_TUNE=1 によるオプトインにより、68k 入力で 46 ～ 73% ITL を追加します。 GSM8K は 0.951-0.957 (#33981、#34261、#34837、#34580) で保持されます。 1 つのコンパイル済みカーネル キャッシュ ディレクトリ: Triton、FlashInfer、Inductor、DeepGEMM、および CUDA ドライバー キャッシュはすべて SGLANG_CACHE_DIR の下に移動します。アップグレード後の最初の起動では、再コンパイルが 1 回行われます。重大な変更 (#32434) を参照してください。 依存関係: トーチ 2.13.0 とトリトン 3.7.1 (#28836)、フラッシュインファー 0.6.17 (#33997)、CuTeDSL 4.6.2、Blackwell での FA4 起動回帰の修正 (#34372)、 重大な変更とアップグレードに関する注意事項

  • CUDA PyTorch スタックは、triton 3.7.1、torchvision 0.28.0、torchcodec 0.15.0 を備えた torch 2.13.0 に移動します (torchaudio は 2.11.0 のままです)。 AOT カーネルは、Torch 2.13 用に再構築され、XPU バックエンドは次のとおりです: #28836、#33841、#31751
  • すべてのコンパイル済みカーネル キャッシュは SGLANG_CACHE_DIR の下に移動するため、アップグレード後の最初の起動は 1 回再コンパイルされます。古いディレクトリを事前ウォーム マウントまたはボリューム マウントする場合は、古いディレクトリをコピーまたはシンボリックリンクします (deep_gemm と flashinfer は高価なディレクトリです): ~/.triton から {SGLANG_CACHE_DIR}/triton、~/.cache/flashinfer から {SGLANG_CACHE_DIR}/.cache/flashinfer、~/.cache/deep_gemm から {SGLANG_CACHE_DIR}/deep_gemm、/tmp/torchinductor_$USER から {SGLANG_CACHE_DIR}/inductor、~/.nv/ComputeCache から {SGLANG_CACHE_DIR}/nv。 TRITON_CACHE_DIR、FLASHINFER_WORKSPACE_BASE、SGLANG_DG_CACHE_DIR、TORCHINDUCTOR_CACHE_DIR、または CUDA_CACHE_PATH のいずれかを設定すると、その設定はそのまま維持されます: #32434
  • torchao の統合は削除されました (torchao ピンが 0.17.0 に移動して以来、--torchao-config は受け入れられた値ごとに ImportError を発生させていました): #34304

  • MoE 遅延ファイナライズは、融合されていない非 TP1 共有エキスパート (DeepSeek-V3 ファミリ) を使用する NVFP4 + flashinfer_trtllm パスでデフォルトでオンになっています。 SGLANG_ENABLE_MOE_DEFERRED_FINALIZE=False をフォールバックに設定: #33618
  • ユニファイド キャッシュのウィンドウ外 SWA スロットの解放は、ユニファイド基数キャッシュに対してデフォルトでオンになっています。 SGLANG_OPT_UNIFIED_CACHE_FREE_OUT_OF_WINDOW_SLOTS=False を設定して古い動作を復元します: #34653
  • リモート メディアのダウンロードはデフォルトで 64 MiB に制限されています。リダイレクト検証と、画像、ビデオ、音声 URL の正確なホスト名の許可リスト登録がオプトインされています: #34892

Plus cookbook recipes for the Qwen3.8 family, Ling-3.0, Nemotron 3.5 Lightning, Dots3-Note, and DeepSeek-V4-Pro-0813 (#34809).

Overlapped checkpoint staging at startup: Checkpoint pages now stage from storage while CUDA graphs capture. Qwen3-32B on H100 starts 8.6-11.7% faster than serial with prefetch, and 2.38x faster (35.6s vs 84.8s) than the plain default. Opt in with --startup-weight-load-mode overlap (#32017).

TP LMHead with All-to-All: The TP LMHead's allgather + scatter becomes a single all-to-all for pure-DP dp-attention. On DeepSeek-V4-Pro B200 decode, LMHead time drops 320us to 169us and TPOT improves 36.97ms to 35.67ms (#32313).

FlashInfer MNNVL for pure allreduce: Non-fused allreduce sites now reuse the FlashInfer MNNVL workspace instead of falling back to NCCL. DeepSeek-V4-Flash TP4 decode on Blackwell gains up to +6.9% at small batches. Auto-enabled for DeepSeek-V3/V3.2/V4; elsewhere --enable-flashinfer-pure-allreduce (#30700).

NVFP4 checkpoints run on AMD: --quantization quark_mxfp4 dequantizes ModelOpt and Quark NVFP4 weights and requantizes to MXFP4 at load, never holding a full-precision copy. 97.5-100.2% GSM8K recovery vs the NVFP4 reference across MiniMax-M2.7, GLM-5.1, Kimi-K2.6, Qwen3.5-397B, and DeepSeek-R1 (#29328).

Kimi K3 tuned for MI355X: a grouped-head MLA verify kernel replaces the MHA-shaped split-KV path that re-read the shared latent once per head, for 1.37-1.77x throughput and 1.45-2.42x ITL at concurrency 2-32; the AITER MLA prefill kernel now accepts K3's 12-head shape (TTFT up to -14.9%); a gfx950-tuned decode stage-1 geometry adds 46-73% ITL at 68k input, opt-in via SGLANG_MLA_DECODE_TUNE=1. GSM8K holds at 0.951-0.957 (#33981, #34261, #34837, #34580).

One compiled-kernel cache directory: Triton, FlashInfer, Inductor, DeepGEMM, and CUDA driver caches all move under SGLANG_CACHE_DIR. The first launch after upgrading recompiles once; see Breaking Changes (#32434).

Dependencies: torch 2.13.0 with triton 3.7.1 (#28836), flashinfer 0.6.17 (#33997), CuTeDSL 4.6.2, fixing an FA4 startup regression on Blackwell (#34372), DeepEP now installed from released sgl-deep-ep wheels (#33932), and sgl-kernel 0.4.6.post1 (#33842).

Breaking Changes & Upgrade Notes

  • The CUDA PyTorch stack moves to torch 2.13.0, with triton 3.7.1, torchvision 0.28.0, and torchcodec 0.15.0 (torchaudio stays at 2.11.0); AOT kernels are rebuilt for Torch 2.13 and the XPU backend follows: #28836, #33841, #31751
  • Every compiled-kernel cache moves under SGLANG_CACHE_DIR, so the first launch after upgrading recompiles once. Copy or symlink the old directories if you pre-warm or volume-mount them (deep_gemm and flashinfer are the expensive ones): ~/.triton to {SGLANG_CACHE_DIR}/triton, ~/.cache/flashinfer to {SGLANG_CACHE_DIR}/.cache/flashinfer, ~/.cache/deep_gemm to {SGLANG_CACHE_DIR}/deep_gemm, /tmp/torchinductor_$USER to {SGLANG_CACHE_DIR}/inductor, ~/.nv/ComputeCache to {SGLANG_CACHE_DIR}/nv. Setting any of TRITON_CACHE_DIR, FLASHINFER_WORKSPACE_BASE, SGLANG_DG_CACHE_DIR, TORCHINDUCTOR_CACHE_DIR, or CUDA_CACHE_PATH keeps that one where it is: #32434
  • The torchao integration is removed (--torchao-config had raised ImportError for every accepted value since the torchao pin moved to 0.17.0): #34304
  • DeepEP now installs from released sgl-deep-ep wheels instead of building from source: #33932
  • MoE deferred finalize is on by default on the NVFP4 + flashinfer_trtllm path with an unfused, non-TP1 shared expert (the DeepSeek-V3 family); set SGLANG_ENABLE_MOE_DEFERRED_FINALIZE=False to fall back: #33618
  • Unified-cache out-of-window SWA slot freeing is on by default for the unified radix cache; set SGLANG_OPT_UNIFIED_CACHE_FREE_OUT_OF_WINDOW_SLOTS=False to restore the old behavior: #34653
  • Remote media downloads are bounded to 64 MiB by default, with redirect validation and opt-in exact-hostname allowlisting for image, video, and audio URLs: #34892
  • The DSV4 fused MHC post+pre path is on by default, including on SM12x: #35214, #34019
  • torch.compile becomes opt-in for diffusion speed mode: #34173
  • 22 unmaintained benchmarks are removed: #34520
