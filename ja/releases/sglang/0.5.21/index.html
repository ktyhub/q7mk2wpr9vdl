主な機能

  • PD インスタンスは、再起動の必要がなく、プリフィルとデコードをオンザフライで切り替えることができます (#28403)。
  • プレフィックス キャッシュはデフォルトで Rust コアで実行されるようになりました (#39627)。
  • DeepSeek-V4.1 では、長いプロンプトでの最初のトークンの取得が 22% 高速化されました (#40352)。
  • Kim K3 は、PD サービングで 20.6% 高いプレフィル スループットを取得します (#40045)。
  • GLM-5.3-Flash は、FP8 / MXFP4 MoE および MTP 投機的デコード (#38546、#39341、#39778) を備えた AMD MI355X 上で動作するようになりました。
  • レイヤ通信が SGLang によって処理されるようになり、PP、DP アテンション、および CP の下でより正確な結果が得られます (ガイド、#41557)。
  • 新しい決定 API (/v1/decisions) は、LLM / VLM を低遅延の分類子およびスコアラーに変えます (docs、#41208)。
  • スコア API (/v1/score) は、1 つのリクエストですべての候補者をスコア付けします (#38965、#41188)。
  • ComfyUI 内で SGLang Diffusion を使用して MiniMax-H3 を実行します (#35990)。

重大な変更とアップグレードに関する注意事項

  • 統合基数ツリーはデフォルトで Rust コアを使用します。 Rust コアの構成は、Python への自動的なフォールバックをサポートしません。 SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python を設定して、あらゆる場所で Python コアを強制します: #39627
  • 数値精度を高めるため、FlashInfer MoE 融合ファイナライズはデフォルトでオフになっています。これにより、W4A4 MoE 遅延が多少発生します。 SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 を設定して、融合アトミックのファイナライズを復元します: #40105
  • PD デコードは、Mooncake および NIXL バックエンドでデフォルトで中止時の KV リリースを延期するようになりました。すべてのプレフィル ランクが確認応答するまでページを保持します (30 秒のタイムアウト、SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT)。即時リリースを復元するには、SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False を設定します: #41023
  • リクエストによって提供されたチャット テンプレートは拒否されます。 サーバーが --trust-request-chat-template で起動しない限り、/v1/chat/completions または /v1/tokenize の chat_template_kwargs 内の chat_template キーはエラーを返すようになりました。他の chat_template_kwargs は変更されていません: #28135
  • 非推奨のエンドポイント、環境変数、およびエイリアスは削除されます。 /get_weight_version および /weight_version の代わりに /model_info、/get_load の代わりに /v1/loads、/clear_hicache_storage_backend の代わりに POST /hicache/storage-backend/clear を使用します。 SGLANG_NSA_* エイリアスは SGLANG_DSA_* に置き換えられ、SGLANG_ENABLE_SPEC_V2 はなくなり、--elastic-ep-rejoin は --elastic-ep-join-mode recover になり、--kv-cache-dtype fp4_e2m1 は fp4_mx_block16 になり、python -m sglang.bench_offline_throughput / sglang.bench_one_batch は sglang.benchmark.offline_throughput / sglang.benchmark.one_batch に移動します: #40795
  • 従来の基数キャッシュ実装は削除されました。 実験的な C++ 基数ツリー (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) はなくなり (#40775)、SGLANG_ENABLE_UNIFIED_RADIX_TREE は何もしなくなりましたが、依然として非推奨の警告が出力されます (#40780)。 SWARadixCache、MambaRadixCache、または HiRadixCache をインポートするコードは UnifiedRadixCache に移動する必要があります: #40313、#40787
  • カスタム ロジット プロセッサは、完全な形状のロジットを返す必要があります。 (1, vocab) などの縮小された形状を返し、ブロードキャストに依存していた CustomLogitProcessor は、デコード時に発生するようになりました。内蔵プロセッサは影響を受けません: #39234
  • RL 重みの更新はセッション内で実行されます。 update_weights_from_tensor および update_weights_from_distributed は begin_weight_update() と end_weight_update() の間で呼び出す必要があります。 UpdateWeightsFromTensorReqInput.disable_draft_model は selector="target" に置き換えられ、ChecksumInfo.parallelism_info は役割ごとに 1 つのエントリを持つリストになりました: #40777
  • パラレルステート ゲッターは非推奨になりました。 これらは sglang.srt.distributed から再エクスポートされなくなりました。 get_parallel() (get_parallel().tp_group など) を通じてグループを読み取るか、parallel_state から直接インポートします: #40342、#40344、#40707
  • Ascend A2 (910b) イメージは公開されなくなりました。 リリースおよびナイトリー イメージは、A3 および 950 (A5) に対してのみ、Python 3.12 を備えた CANN 9.1.0 で出荷されます: #40524

Breaking Changes & Upgrade Notes

  • The unified radix tree uses the Rust core by default. Configurations the Rust core does not support fall back to Python automatically; set SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python to force the Python core everywhere: #39627
  • FlashInfer MoE fused finalize is off by default for numerical accuracy. This costs some W4A4 MoE latency; set SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 to restore the fused atomic finalize: #40105
  • PD decode now defers KV release on abort by default on the Mooncake and NIXL backends, holding pages until every prefill rank acks (30 s timeout, SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT). Set SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False to restore immediate release: #41023
  • Request-supplied chat templates are rejected. A chat_template key inside chat_template_kwargs on /v1/chat/completions or /v1/tokenize now returns an error unless the server starts with --trust-request-chat-template; other chat_template_kwargs are unchanged: #28135
  • Deprecated endpoints, env vars, and aliases are removed. Use /model_info instead of /get_weight_version and /weight_version, /v1/loads instead of /get_load, and POST /hicache/storage-backend/clear instead of /clear_hicache_storage_backend. SGLANG_NSA_* aliases give way to SGLANG_DSA_*, SGLANG_ENABLE_SPEC_V2 is gone, --elastic-ep-rejoin becomes --elastic-ep-join-mode recover, --kv-cache-dtype fp4_e2m1 becomes fp4_mx_block16, and python -m sglang.bench_offline_throughput / sglang.bench_one_batch move to sglang.benchmark.offline_throughput / sglang.benchmark.one_batch: #40795
  • Legacy radix cache implementations are removed. The experimental C++ radix tree (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) is gone (#40775), and SGLANG_ENABLE_UNIFIED_RADIX_TREE no longer does anything, though it still prints a deprecation warning (#40780). Code importing SWARadixCache, MambaRadixCache, or HiRadixCache must move to UnifiedRadixCache: #40313, #40787
  • Custom logit processors must return full-shape logits. A CustomLogitProcessor that returned a reduced shape such as (1, vocab) and relied on broadcasting now raises at decode time. The built-in processors are unaffected: #39234
  • RL weight updates run inside a session. update_weights_from_tensor and update_weights_from_distributed must be called between begin_weight_update() and end_weight_update(). UpdateWeightsFromTensorReqInput.disable_draft_model is replaced by selector="target", and ChecksumInfo.parallelism_info is now a list with one entry per role: #40777
  • Parallel-state getters are deprecated. They are no longer re-exported from sglang.srt.distributed; read groups through get_parallel() (for example get_parallel().tp_group) or import from parallel_state directly: #40342, #40344, #40707
  • Ascend A2 (910b) images are no longer published. Release and nightly images ship for A3 and 950 (A5) only, on CANN 9.1.0 with Python 3.12: #40524
