orca v1.4.271

パッチ 公開日2026年11月22日 出典stablyai/orca English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#シャチv1.4.271 1.4.269に続き、オルカの次回作です。ボットは Qwen コードに到達し、ペアリングされたコンピューターにまたがり、電話アプリはエージェントをエンドツーエンドで管理し、チャットはより軽量かつ高速になります。

コンピューター全体のボット、エージェントとよりきびきびとしたチャットを実行する電話 ✨

1 つのボット グループがペアリングされたコンピューターのボットを保持できるようになり、ボットは Qwen コードで実行でき、チャットは削除して使用制限後に独自に続行でき、電話アプリはデスクトップなしでエージェントを共有、インポート、接続できるようになりました。

  • 🤖 コンピューターとエージェント間のボット: 1 つのボット グループはペアリングされたコンピューターからのボットを保持でき、ボットは Qwen コードで実行でき、グループ ルームはエージェントが @メンションしたすべてのメンバーに手動でフォローアップを行います。
  • 📱 携帯電話からエージェントを実行: エージェントのオートメーションを編集し、Slack、Linear、GitHub、Google、Composio に接続し、リンクでエージェントを共有し、OpenClaw または Hermes からエージェントをインポートし、その魂を読み取り、そのメモリとスキルを管理し、別のエージェントに履歴セッションを渡します。これらには、一致するモバイル ビルドが必要です。
  • 💬 穏やかなチャット: チャットを削除し、デフォルトで使用制限が過ぎても続行し、@ メニューにフォルダーをリストし、静かな行とウェルカム テキストを明確に保つコンポーザーを表示します。
  • 🐧 安定した Windows と WSL: WSL ホストは、常時稼働するエージェントをカウントし、Codex アカウントと設定は WSL 上で動作し、WSL ホストへのフォルダーの移動は最初に尋ねられます。
  • ⚡ 全体的に軽量化: 端末のタイトルの変更、エージェントのステータスの更新、ボット リスト、電話の更新により、すべての再スキャンや再構築が停止され、非表示のアニメーションが一時停止します。
  • 🐙 複数の GitHub アカウント: より効率的なリンク プレビューとコメント投票を使用して、複数の GitHub アカウントをリンクします。

Orca ボット (ベータ版) について <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="36" height="36" valign="middle" />

Orca Bot は一流のチームメイトのように機能します。Orca Bot はコンピューター全体に広がり、完了した内容を記憶し、使用量の制限や再起動によって中断された箇所を認識します。

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> ボットの背後にある Qwen コード: Qwen コードは、ボットが実行できるエージェントに加わります。
  • 🖥️ 1 つのグループ、多数のコンピューター: ボット グループはペアリングされたコンピューターからのボットを保持でき、ピアの要求に対するエージェントの応答がルームに表示されます。
  • 📓 維持されるメモリ: ボットは、閉じられた各アイテムとその PR をジャーナルに記録し、作業状態がアイテムとジャーナルに存在することを認識し、パイロット Tidy-up はメモリ行を書き換えるのではなく移動してマージします。
  • 🔁 中断したところから再開: 再起動または使用制限による一時停止の後、ボットはオープン リクエストを保持し、一度続行します。
  • 💬 返信が簡単になりました: アイテムのコメント ボックスは作成者のメンションとスラッシュ ピッカーを取得し、「返信先」は回答する質問にジャンプします。

orca v1.4.271

Following 1.4.269, here is the next round of Orca. Bots reach Qwen Code and span your paired computers, the phone app manages agents end to end, and chats get lighter and quicker.

Bots across computers, a phone that runs your agents & snappier chats ✨

One bot group can now hold bots from your paired computers, bots can run on Qwen Code, chats can be deleted and continue on their own after a usage limit, and the phone app can share, import and connect agents without the desktop.

  • 🤖 Bots across computers and agents: One bot group can hold bots from paired computers, bots can run on Qwen Code, and group rooms hand follow-up turns to every member an agent @mentions.
  • 📱 Run agents from your phone: Edit an agent's automations, connect Slack, Linear, GitHub, Google and Composio, share an agent by link, import one from OpenClaw or Hermes, read its soul and manage its memory and skills, and hand a history session to another agent. These need the matching mobile build.
  • 💬 Calmer chats: Delete a chat, continue after a usage limit by default, list folders in the @ menu, and see quieter rows and a composer that keeps its welcome text clear.
  • 🐧 Steadier Windows and WSL: WSL hosts count working agents for keep-awake, Codex accounts and settings behave on WSL, and moving a folder to a WSL host asks first.
  • ⚡ Lighter all around: Terminal title changes, agent status updates, bot lists and phone refreshes stop rescanning or rebuilding everything, and hidden animations pause.
  • 🐙 More than one GitHub account: Link several GitHub accounts, with leaner link previews and comment polling.
