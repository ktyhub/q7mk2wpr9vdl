#シャチv1.4.261

以前のリリース: 1.4.259 — 大幅なパフォーマンスの向上、自動クリーンアップ、および集中的なサブエージェント ビュー。

パフォーマンスの大幅な改善、カーソルチャットとカスタマイズ可能な + メニュー ✨

Orca 1.4.261 は、忙しいチャット ワークフローの応答性を高め、何時間も使用しなかったブラウザ ページのメモリを解放します。カーソルはチャットに参加し、カスタマイズ可能な + メニューにより、好みの方法でタブを開くことができます。

  • ⚡ 待ち時間を少なくして忙しいチャット間を移動: 長い会話では履歴がページに読み込まれ、会話を切り替えるときにサイドバーや非表示チャットでのバックグラウンド返信の機能が軽減されます。
  • 🌐 すべてのページをロードしたままにせず、ブラウザのタブを維持します: メモリ セーバーは、デフォルトで 4 時間非表示になった後に対象のページを解放し、戻ったときにそれらのページをリロードします。セッション Cookie を使用するサイトでは、再起動後もサインインを維持することもできます。
  • 🤖 チャットでカーソルを使用する: コンピューターでカーソル サインインから開始し、モデル、作業量、および高速を選択し、コマンドを承認し、後で会話を再度開きます。
  • ➕ + メニューを自分のものにします: 新しいアイコン行の横にある歯車を使用して、アクションの順序を変更したり、未使用の選択肢を非表示にしたり、ショートカットを設定したりできます。非表示のアクションは、検索とそのショートカットを通じて引き続き利用できます。
  • ⌨️ ターミナルの作業を正確に進めます: コンテキストのコピー、フォーク、続行は、ターミナル プログラムによって描画されたスペースを保持します。 「編集」→「貼り付け」は、実際にフォーカスがある分割ペインをターゲットとします。

ハイライト

  • アクティブな作業のためのより多くのスペース: メモリ セーバーは、更新された orca serve ホスト上のブラウザ タブにも適用されます。デスクトップ タブには、タイトル、履歴、Cookie、保存されたサイト データが保持されます。 [設定] → [ブラウザ] を選択すると、アイドル間隔を変更したり、メモリ セーバーをオフにしたりできます。
  • より多くのエージェントの選択肢: Antigravity Chat は Windows 上で動作し、Pi Chat にはサブエージェントが表示されます。通常の Orca CLI コマンドは、サポートされている Mac での Electron の起動を回避します。 macOS 13.4 は既存のランチャーを保持します。
  • ワークスペースの概要: 実験用ワークスペース カードには、アクティビティ、未読の結果、障害、オフライン ホストが表示されます。 「ワークスペース」オプションから「クラシック」または「実験的」を選択します。ペインがスリープ状態のエージェントには、「完了」と表示され続けます。
  • 電話ナビゲーション: ペアリングされた電話インターフェイスには、デスクトップ プロジェクト グループと、チャットおよびターミナル リンク用の共有ブラウザ設定 (毎回確認を含む) が追加されます。デスクトップでは、電話主導のブラウザ タブの制御をすべて取り戻します。

互換性とアップグレードに関する注意事項

  • チャット履歴: 既存のチャットは、バックグラウンドで、または最初に開いたときに新しいストアに変換されます。元のチャット ファイルはこのリリースでもそのまま残ります。ダウングレードして再度アップグレードすると、古いバージョンで継続していたチャットが復元されます。以前に変換された会話は、新しいバージョンの横に 2 番目のチャットとして表示されます。
  • ブラウザのリロード: 解放されたページはその場でリロードされます。スクロール位置とページのみのメモリをリセットできます。デスクトップ メモリ セーバーは、保存されていない編集を検出した場合、または編集を安全に評価できない場合、ページをロードしたままにします。節約できる金額は、どのページが対象となるかによって異なります。
  • Android: 従来のアプリでは、新しい dev.orca.app を個別にインストールするようにユーザーに指示されます。新しいパッケージに更新することはできません。このデスクトップ リリースでは電話アプリはインストールされません。
  • 終了したエージェント: プロセスが終了するか、SSH ホストが切断されると、行はワークスペース カード、エージェント リスト、ダッシュボードから残ります。スリープ状態のペインは完了ステータスを保持します。

orca v1.4.261

Previous release: 1.4.259 — Major performance improvements, automatic cleanup and focused subagent views.

Major performance improvements, Cursor Chat & a customizable + menu ✨

Orca 1.4.261 makes busy Chat workflows more responsive and releases memory from browser pages you haven't used in hours. Cursor joins Chat, and a customizable + menu puts your preferred ways to open tabs within reach.

  • ⚡ Move between busy chats with less waiting: Long conversations load their history in pages, and background replies do less work in the sidebar and hidden chats when you switch conversations.
  • 🌐 Keep browser tabs without keeping every page loaded: Memory Saver frees eligible pages after four hours out of view by default, then reloads them when you return. Sites using session cookies can also keep you signed in across restarts.
  • 🤖 Use Cursor in Chat: Start with the Cursor sign-in on your computer, choose a model, effort and Fast, approve commands, and reopen the conversation later.
  • ➕ Make the + menu yours: Use the gear beside the new icon row to reorder actions, hide unused choices and set shortcuts. Hidden actions remain available through search and their shortcuts.
  • ⌨️ Carry terminal work forward accurately: Copy Context, Fork and Continue preserve spaces drawn by terminal programs. Edit → Paste targets the split pane that actually has focus.

Highlights

  • More room for active work: Memory Saver also applies to browser tabs on an updated orca serve host. Desktop tabs retain their title, history, cookies and saved site data. Settings → Browser lets you change the idle interval or turn Memory Saver off.
  • More agent choices: Antigravity Chat works on Windows, and Pi Chat shows subagents. Ordinary Orca CLI commands avoid Electron startup on supported Macs; macOS 13.4 retains the existing launcher.
  • Workspaces at a glance: Experimental workspace cards show activity, unread results, failures and offline hosts. Choose Classic or Experimental from Workspace options. Agents whose panes are asleep keep showing Done.
  • Phone navigation: The paired phone interface gains desktop project groups and a shared browser preference for chat and terminal links, including Ask each time. On desktop, Take back all returns control of phone-driven browser tabs.

Compatibility & upgrade notes

  • Chat history: Existing chats convert to the new store in the background or when first opened. Original chat files stay in place in this release. After downgrading and upgrading again, chats continued in the older version are recovered; a previously converted conversation can appear beside its newer version as a second chat.
  • Browser reloads: Freed pages reload in place; scroll position and page-only memory can reset. Desktop Memory Saver leaves pages loaded when it detects unsaved edits or cannot safely assess them. Savings depend on which pages qualify.
  • Android: The legacy app directs users to install the new dev.orca.app separately; it cannot update into the new package. This desktop release does not install a phone app.
  • Finished agents: Rows leave workspace cards, the Agents list and dashboard when the process exits or its SSH host disconnects. Sleeping panes retain their Done status.
