#シャチv1.4.268 本日、複数のリリースを出荷しました。 1.4.267と1.4.266もチェックしてください。

より多くのエージェント上のボット、よりリッチな Slack、より高速な Orca ✨

ボットは Cursor、GitHub Copilot、Hermes 上で実行できるようになり、Slack はスケジュール設定とキャンバスを取得し、Orca はバックグラウンドでの作業が減り、より速く感じられます。

  • 🤖 より多くのエージェントでボットを実行: ボットは Cursor、GitHub Copilot、Hermes で実行でき、OpenCode 2.x ボットは常駐の命令を取得します。新しいボットには ID カードが与えられ、Soul & Memory ではエディターが再設計されました。
  • 🖼️ 画像とファイルの送信: ボット チャット、グループ チャット、アイテム コメント (ペアリングされたコンピューター上のボットなど) に画像やファイルを添付します。 Slack リクエストの画像は画像としてエージェントに届きます。
  • 💬 Slack の詳細: orca slack post --at は後で投稿をスケジュールし、新しい pin、canvas、list、scheduled コマンドはピン、キャンバス、リストをカバーします。 Slack に接続すると、余分な click なしでコピーされたトークンが取得され、メンションは名前として読み取られます。
  • ⚡ 軽量でスムーズな Orca: アニメーションは 1 秒に 1 回ではなく再びスムーズに実行され、スピナーとパルスが描画するフレームが減り、資格情報の読み取りがメイン スレッドから移動し、自動ヒープ プロファイルがなくなりました。 Orca は、ディスクがほぼいっぱいになったときにワークスペースをクリーンアップすることも提案しています。
  • 🧭 信頼性の高いワーカーとチャット: クラッシュまたは再起動によって切断されたチャットは続行でき、ワーカーの最終レポートにより、それを開始したエージェントが起動され、チャット内のワーカー名によってワーカーが開きます。 Chat には、Antigravity、Claude、Codex、Droid の修正も含まれています。
  • 🌐 リモート ホスト上のページに注釈を付ける: ブラウザの注釈がリモート ホストでも機能するようになりました。

Orca ボット (ベータ版) について <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="36" height="36" valign="middle" />

Orca ボットは一流のチームメイトのように機能します。すべての管理対象エージェント セッションがそのツールと ID を取得し、ボットは所有者に代わって共有でき、Slack スレッドと Gmail トリガーをより確実に追跡し、それらの接続がより明確かつ安全になります。

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> すべてのボット セッションが独自のツールと ID を取得します: 管理対象エージェント セッションは、Claude と Codex に限定されなくなりました。それぞれが必要なツールとアイデンティティから始まります。
  • 🔗 ボットは所有者と同じように共有できます: エージェント CLI 発信者は、所有者と同じ方法で共有を使用できます。
  • 💬 Slack スレッドにはボットの動作が表示されます: スレッドはその順番で作業している内容を反映するようになり、長い回答は分割されずに丸ごと届きます。
  • 📬 Gmail トリガーは実際の送信者と一致します: トリガーは、異なる可能性がある表示名ではなく、送信者の実際のアドレスと一致します。
  • 🛡️ より明確なアクセス警告: アクセス確認ダイアログには、ボットに接続する前に許可している内容が詳しく表示されるようになりました。

orca v1.4.268

We shipped more than one release today. Check out 1.4.267 and 1.4.266 too.

Bots on more agents, richer Slack & a faster Orca ✨

Bots can now run on Cursor, GitHub Copilot and Hermes, Slack gets scheduling and canvases, and Orca does less work in the background so it feels quicker.

  • 🤖 Run bots on more agents: Bots can run on Cursor, GitHub Copilot and Hermes, and OpenCode 2.x bots get their standing instructions. New bots get an identity card, and Soul & Memory have redesigned editors.
  • 🖼️ Send images and files: Attach images and files in bot chats, group chats and item comments, including to a bot on a paired computer. Images on a Slack request reach the agent as images.
  • 💬 More from Slack: orca slack post --at schedules a post for later, and new pin, canvas, list and scheduled commands cover pins, canvases and lists. Connecting Slack takes the copied token without extra clicks, and mentions read as names.
  • ⚡ A lighter, smoother Orca: Animations run smoothly again instead of about once a second, spinners and pulses draw fewer frames, credential reads move off the main thread, and automatic heap profiles are gone. Orca also suggests cleaning up workspaces when the disk is almost full.
  • 🧭 More reliable workers and chats: Chats cut by a crash or restart can continue, a worker's final report wakes the agent that started it, and worker names in chat open the worker. Chat also gets Antigravity, Claude, Codex and Droid fixes.
  • 🌐 Annotate pages on remote hosts: Browser annotations now work on remote hosts too.

Orca Bots work like first-class teammates: every managed agent session gets its tools and identity, bots can share on the owner's behalf, they follow Slack threads and Gmail triggers more reliably, and connecting them is clearer and safer.
