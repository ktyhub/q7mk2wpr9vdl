orca v1.4.263

パッチ 公開日2026年11月18日 出典stablyai/orca English original

#シャチv1.4.263 以前のリリース: 1.4.262 — チャットの切り替えが高速になり、メモリ使用量が減り、Git BLAM が削減されます。

軽量化されたチャット スタートアップ、Hermes in Chat およびブラウザ拡張機能のサイド パネル ✨

メモリ使用量と起動作業を減らして、チャットでいっぱいのワークスペースを再度開きます。復元されたチャット インターフェイスは最初に表示されたときに読み込まれ、Orca は起動時に保存されたすべての会話を書き換えなくなります。開いているチャットは、戻ったときに下書きとスクロール位置を保持します。

  • 💬 チャットでエルメスの会話を続ける: 新しいタブ メニューからヘルメスを開始するか、セッション履歴エントリで 新しいチャットで再開 を選択して、元のワークスペースとプロファイルでターミナルの会話を続けます。
  • 🌐 拡張機能をページの横に置く: サイド パネルを使用する Chrome 拡張機能を、Orca ブラウザのサイズ変更可能なパネルで開くことができるようになりました。 Cli拡張機能のツールバー ボタンをクリックして、ブラウズ中にそのパネルを使用します。拡張機能のポップアップでは、貼り付け、コピー、すべて選択も可能です。
  • 🖥️ リモートワークにアクセス: 管理対象 SSH ポートに 進む ボタンが追加されました。 Windows では、マッピングされた WSL ドライブ文字を通じて開かれたプロジェクトは、ディストリビューションの WSL ホストに移動できます。
  • ⌨️ 再起動後もターミナル出力を表示したままにする: macOS および Linux では、シェルが停止したターミナルは、その下に新しいプロンプトを表示して保存された出力を復元できます。 Windows は既存の復元動作を維持します。

ハイライト

  • コマンド ラインから Linear に接続します: orca linear connect は、標準入力を介して API キーを受け入れ、ヘッドレス サーバーを含むターゲットのホストに接続します。各ホストは独自の接続を維持します。線形課題とプロジェクトのリストは、--limit を省略した場合にすべての結果を返すようになりました。
  • Windows でエージェントをセットアップする: クロード チャットと Codex チャットでは、エージェントが見つからない場合に インストール し、インストールを検出するために 再度確認 することができます。 orca agent installed には、スクリプトおよび起動セットアップ用に現在のホスト上で有効になっているエージェント CLI もリストされます。

互換性とアップグレードに関する注意事項

  • Hermes: チャットには、ワークスペースを実行しているマシンに Hermes 0.23.0 以降が必要です。非常に長いインポートでは最近のメッセージが表示されますが、Hermes では会話全体が保持されます。 SSH ワークスペースではチャットは利用できません。ペアリングされた Orca サーバーはそれをサポートします。 Hermes のゲートウェイが停止した後の最初のチャットは、開始までに 1 分かかる場合があります。
  • ブラウザ ID: ネイティブ がデフォルトになり、以前のデフォルトで見られた Cloudflare 検証ループに対処します。明示的な ID の選択は保持されます。 「設定」→「ブラウザ」→「ブラウザ ID」で変更してください。
  • 電話のアップデート: 以下にリストされている電話 UI の変更には、対応するモバイル ビルドが必要です。このデスクトップ更新では、Android または iOS アプリは更新されません。

既知の問題

  • 代わりにワークスペースをスリープします: そのワークスペースの別のタブがプロセスを実行している場合、このオプションは失敗する可能性があります。
  • orca agent installed --worktree: SSH およびペアサーバーワークスペースでのコマンドエラー。

orca v1.4.263

Previous release: 1.4.262 — Faster chat switching, lower memory use and git blame.

Lighter chat startup, Hermes in Chat & browser extension side panels ✨

Reopen workspaces full of chats with less memory use and less startup work. Restored chat interfaces load when first shown, and Orca no longer rewrites every saved conversation at launch. Opened chats keep their drafts and scroll position when you return.

  • 💬 Continue Hermes conversations in Chat: Start Hermes from the New Tab menu, or choose Resume in New Chat on a Session History entry to continue a terminal conversation in its original workspace and profile.
  • 🌐 Keep extensions beside your page: Chrome extensions that use side panels can now open in a resizable panel in Orca's browser. Click the extension's toolbar button to use its panel while browsing; extension popups also accept Paste, Copy and Select All.
  • 🖥️ Reach your remote work: Managed SSH ports now have a Forward button. On Windows, projects opened through a mapped WSL drive letter can move onto their distro's WSL host.
  • ⌨️ Keep terminal output in view after a restart: On macOS and Linux, a terminal whose shell stopped can restore its saved output with the new prompt below it. Windows keeps its existing restore behavior.

Highlights

  • Connect Linear from the command line: orca linear connect accepts an API key through stdin and connects the host you target, including a headless server. Each host keeps its own connection. Linear issue and project lists now return all results when you omit --limit.
  • Set up agents on Windows: Claude and Codex chats offer Install when the agent is missing, then Check again to detect the installation. orca agent installed also lists enabled agent CLIs on the current host for scripts and launch setup.

Compatibility & upgrade notes

  • Hermes: Chat requires Hermes 0.23.0 or later on the machine running the workspace. Very long imports show recent messages while Hermes retains the full conversation. Chat is unavailable for SSH workspaces; a paired Orca server supports it. The first chat after Hermes' gateway stops can take a minute to start.
  • Browser identity: Native is now the default, addressing the Cloudflare verification loop seen with the previous default. Explicit identity choices are preserved; change yours in Settings → Browser → Browser identity.
  • Phone updates: The phone UI changes listed below require a corresponding mobile build. This desktop update does not update Android or iOS apps.

Known issues

  • Sleep workspace instead: The option can fail when another tab in that workspace is running a process.
  • orca agent installed --worktree: The command errors on SSH and paired-server workspaces.
