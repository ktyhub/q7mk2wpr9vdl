WeKnora v0.3.5

Highlights

  • Breaking: MCP tool naming and Milvus metric type — MCP tools are now named by service name instead of UUID (PR #783, fixing #715), so any client or automation referencing UUID-based tool names must be updated. Separately, Milvus vector search switches from IP to COSINE (PR #802); because metric type is fixed at index creation, existing IP-based collections/indexes will likely need to be dropped and rebuilt for this to take effect. These are the two changes most likely to require migration work.

  • Security and data integrity hardening — SSRF protection in RemoteAPIChat is strengthened (PR #811), important for anyone exposing that endpoint. Tenant settings updates no longer risk losing api_key encryption (PR #800), and knowledge-base creation now respects the global default storage engine rather than overriding it (PR #784). If you manage tenants or expose remote chat, these fixes make upgrading strongly advisable.

  • New providers and IM channels — Adds OpenRouter as an embedding provider (PR #780), Novita AI as an LLM provider (PR #794), upgrades MiniMax models M2.1 → M2.7 (PR #812), and expands instant-messaging support with IM optimization, a new platform (PR #774, PR #796), and a Mattermost channel (PR #820). This is a meaningful expansion of backend and channel choices, though mostly additive rather than behavior-changing.

  • Agent capabilities — Introduces a GetSuggestedQuestions API for agent-specific question suggestions (PR #809), auto-describes MCP tool-result images via VLM (PR #808), improves context/intent classification in prompt templates (PR #814), and fixes empty responses when no Knowledge Base is configured (PR #819). Worth upgrading for teams building agents on top of WeKnora.

  • Chat/frontend correctness and dev experience — Preserves image markdown during sanitize (PR #789), supports native reasoning for vLLM by bypassing go-openai limitations (PR #791), fixes markdown code-block rendering (PR #797) and UTF-8 truncation in summary fallback (PR #813), resets the knowledge-file page counter (PR #790), filters empty passages to avoid Aliyun rerank errors (PR #806), plus first-run dev setup fixes (PR #779) and missing i18n keys (PR #804, PR #801). Net: recommended upgrade for most users; only pause if you depend on UUID MCP tool names or an IP-metric Milvus index and aren't ready to reindex.
