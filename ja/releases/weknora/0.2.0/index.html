#WeKnora v0.2.0

WeKnora v0.2.0 Release Notes

発売日: 2025-12-05 これは、ReACT Agent モード、モデル管理システム、FAQ ナレッジ ベースなどを導入する主要な機能アップデートです。

🚀 主な機能

ReACT エージェント モード

  • ナレッジベース検索用の組み込みツールを備えた新しい ReACT Agent モード
  • 外部サービスにアクセスするためのユーザー設定の MCP ツールと Web 検索ツールのサポート
  • 包括的な概要レポートを提供するための複数の反復と反映
  • 複数の知識ベースの選択を可能にする、知識ベース間の検索サポート

モデル管理システム

  • モデル構成の一元管理
  • ナレッジベース設定ページにモデル選択を追加しました
  • 複数のテナントにわたる組み込みのモデル共有機能
  • テナントは共有モデルを使用できますが、モデルの詳細の編集や表示は制限されています

複数タイプのナレッジベースのサポート

  • FAQ およびドキュメントナレッジベースタイプの作成のサポート
  • フォルダーインポート機能
  • URLインポート機能
  • タグ管理システム
  • オンラインでの知識入力機能

FAQ ナレッジベース

  • 新しい FAQ タイプのナレッジ ベース
  • 一括インポートおよび一括削除機能
  • オンライン FAQ エントリ
  • オンライン FAQ テスト機能

会話戦略の構成

  • エージェントモデルと通常モードモデルの設定のサポート
  • 構成可能な取得しきい値
  • オンラインプロンプト設定
  • マルチターンの会話動作と検索実行方法を正確に制御

Web 検索の統合

  • 拡張可能な Web 検索エンジンのサポート
  • 内蔵のDuckDuckGo検索エンジン

MCP ツールの統合

  • MCP を介したエージェント機能の拡張のサポート
  • 組み込みの uvx および npx MCP ランチャー ツール
  • 3 つのトランスポート メソッドのサポート: Stdio、HTTP Streamable、SSE

🎨 UI/UX の改善

  • 再設計: エージェント モード/通常モード切り替え付きの会話インターフェイス
  • 再設計: ログイン ページ UI
  • 強化: 時間順にグループ化されたセッション リスト
  • 新機能: 統一された UI 視覚効果を備えたクイック アクション エリア
  • 改善: 種類、ナレッジ数、ビルド ステータスを表示するナレッジ ベース リスト カード
  • 新規: FAQ およびドキュメント リスト ページのブレッドクラム ナビゲーション
  • 再設計: タイプ、モデル、チャンキング方法、詳細設定の個別の構成を備えたナレッジベース設定ページ
  • 新規: 権限を構成するためのグローバル設定ページ
  • 機能強化: ツール呼び出しの実行プロセス表示を備えた会話フロー ページ

⚡ インフラストラクチャのアップグレード

  • 新規: MQ ベースの非同期タスク管理により、サービスの再起動後のタスクの整合性が確保されます。
  • 新規: バージョンアップグレード時のスキーマとデータの移行をサポートする自動データベース移行
  • 新機能: 開発環境を迅速に起動するための docker-compose.dev.yml を使用した高速開発モード
  • 改善: ログ構造の最適化
  • 新規: イベントのサブスクリプションと公開メカニズム 完全な Changelog: CHANGELOG.md

WeKnora v0.2.0

Highlights

  • Agentic ReACT mode — v0.2.0 moves WeKnora from single-shot RAG to a reasoning-and-acting loop: the agent retrieves across multiple knowledge bases, invokes user-configured MCP and web-search tools, and iterates with reflection before producing a summary report. This is the headline capability — you can now build multi-step, tool-using workflows — but it also means more tokens, higher latency, and non-deterministic tool paths. Plan for observability; the conversation flow page now exposes tool-call execution to help debug runs.
  • MCP tool extensibility — Agents can be extended over three transports — Stdio, HTTP Streamable, and SSE — with built-in uvx and npx launchers. Transport choice is the real deployment decision here: Stdio runs tools locally alongside the service, while HTTP/SSE reach remote services, so pick according to your network and ops model rather than treating them as interchangeable.
  • Centralized model management & tenant sharing — Model configuration is consolidated, model selection now lives in each KB's settings, and models can be shared across tenants. Shared models are consumable but not editable or inspectable by tenant users — good for governance, but it means per-tenant customization of a shared model is no longer possible.
  • Typed knowledge bases (FAQ + document) — KBs now carry an explicit type, adding FAQ-specific operations (batch import/delete, online entry and testing) next to document KBs, plus folder/URL import and tag management. Treat this as a migration step: existing KBs will need a type assigned and a model selected in the redesigned settings page, so re-verify retrieval behavior after upgrading.
  • Async tasks & automatic DB migration — Work now runs through an MQ-backed queue that preserves task integrity across restarts, and upgrades get automatic schema/data migration. Operationally this is the most important upgrade note: take a backup, but expect the migration to be hands-off. A docker-compose.dev.yml fast dev mode and an event pub/sub mechanism round out the platform work.
  • Breaking changes — None explicitly called out in this release.

WeKnora v0.2.0 Release Notes

Release Date: 2025-12-05

This is a major feature update introducing ReACT Agent mode, Model Management System, FAQ Knowledge Base, and more.

🚀 Major Features

ReACT Agent Mode

  • New ReACT Agent mode with built-in tools for knowledge base retrieval
  • Support for user-configured MCP tools and web search tools to access external services
  • Multiple iterations and reflection to provide comprehensive summary reports
  • Cross-knowledge base retrieval support, allowing selection of multiple knowledge bases

Model Management System

  • Centralized model configuration management
  • Added model selection in knowledge base settings page
  • Built-in model sharing functionality across multiple tenants
  • Tenants can use shared models but are restricted from editing or viewing model details

Multi-Type Knowledge Base Support

  • Support for creating FAQ and document knowledge base types
  • Folder import functionality
  • URL import functionality
  • Tag management system
  • Online knowledge entry capability

FAQ Knowledge Base

  • New FAQ-type knowledge base
  • Batch import and batch delete functionality
  • Online FAQ entry
  • Online FAQ testing capability

Conversation Strategy Configuration

  • Support for configuring Agent models and normal mode models
  • Configurable retrieval thresholds
  • Online Prompt configuration
  • Precise control over multi-turn conversation behavior and retrieval execution methods

Web Search Integration

  • Support for extensible web search engines
  • Built-in DuckDuckGo search engine

MCP Tool Integration

  • Support for extending Agent capabilities through MCP
  • Built-in uvx and npx MCP launcher tools
  • Support for three transport methods: Stdio, HTTP Streamable, and SSE

🎨 UI/UX Improvements

  • REDESIGNED: Conversation interface with Agent mode/normal mode switching
  • REDESIGNED: Login page UI
  • ENHANCED: Session list with time-ordered grouping
  • NEW: Quick Actions area with unified UI visual effects
  • IMPROVED: Knowledge base list cards displaying type, knowledge count, and build status
  • NEW: Breadcrumb navigation in FAQ and document list pages
  • REDESIGNED: Knowledge base settings page with separate configuration for type, models, chunking methods, and advanced settings
  • NEW: Global settings page for permissions configuration
  • ENHANCED: Conversation flow page with tool call execution process display

⚡ Infrastructure Upgrades

  • NEW: MQ-based async task management ensuring task integrity after service restart
  • NEW: Automatic database migration supporting schema and data migration during version upgrades
  • NEW: Fast development mode with docker-compose.dev.yml for quick development environment startup
  • IMPROVED: Log structure optimization
  • NEW: Event subscription and publishing mechanism

Full Changelog: CHANGELOG.md
