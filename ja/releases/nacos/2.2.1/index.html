nacos 2.2.1

パッチ 公開日2023年3月17日 出典alibaba/nacos English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナコス2.2.1 このバージョンは主に 特別に、token.secret.key と server.identity のデフォルト値を削除します。 詳細については、発表 を参照してください。 そして、このバージョンでは、spring-boot、Grpc、jraft などの多くの依存関係がアップグレードされます。 さらに、このバージョンではベータ機能が追加され、grpc リクエストが TLS をサポートし、いくつかのバグが修正され、いくつかの使用上の問題が強化されています。 詳細は以下を参照してください。

機能

[#9276] コンテンツによる検索構成を追加しました。 [#9703] 無効になっているリストインスタンスをサポートするためにカタログv2 APIを追加しました。 [#9710] prometheus-sdベーシック認証をサポートしました。 [#9888] ベータ版では、Grpc TLS 機能がサポートされました。 [#10062] aliyun STS 認証のネーミングサポート。

強化とリファクタリング

[#9510] SQLログ出力機能を追加しました。 [#9646] 連結された文字列をプレースホルダーに置き換えます。 [#9708] HTTP client の期限切れおよび無効な接続をクリーンアップします。 [#9783] V2 http apiのパブリッシュおよびクエリ構成のデフォルトのnamespaceIdとしてパブリックnamespaceIdを処理します。 [#9837] クラスターがスナップショットのロードを迅速に開始したときの Grpc の接続時間を強化しました。 [#9859] デフォルトの認証プラグインをリファクタリングし、jjwt の代わりにカスタム JWT を使用します。 [#9860] SPIによるログバック1.4.5を適応させました。 [#9885] prometheus api 例外処理を追加しました。 [#9949] サーバー間のすべてのHTTPリクエストをGrpcを使用して置き換えます。 [#9951] メタデータプロセッサ用メッセージがnullかどうかを判定します。 [#10084] Cli非同期アペンダーを使用してログを出力します。 [#10108] ID のデフォルト値を削除しました。

バグ修正

[#9621] Config Client サーバーチェックが常に稼働している問題を修正しました。 [#9728] prometheus http sd のみがパブリック名前空間を返す問題を修正しました。 [#9732] ネームスペース v2 api 認証が機能しない問題を修正しました。 [#9734] デフォルトのポートの問題が発生しない http ログイン URL を修正しました。 [#9795] 認証を開いた後の非管理者ユーザーの設定エクスポート失敗の問題を修正しました。 [#9816] 同時実行でサービスを登録および登録解除するときに、REDO データがサーバーと異なる問題を修正しました。 [#9819] nginx使用後のパスワード更新失敗問題を修正しました。 [#9825] 設定履歴ページのページングの問題を修正しました。 [#9861] ディストリビューションフィルター前の認証チェックを修正しました。 [#9862] LDAPログインに失敗する問題を修正しました。 [#9943] derby データベースを使用している場合、Config cas の更新が機能しない問題を修正しました。 [#10014] 名前空間プロパティに関する混乱したロジックを明確にしました。 [#10038] フェイルオーバーファイルの読み込みエラーを修正しました。

依存関係

[#9504][#9767] スプリングブートのバージョンを 2.6.14 にアップグレードしました。 [#9789] jraft のバージョンを 1.3.12 にアップグレードします。 [#9772] Grpc バージョンを 1.50.2 にアップグレードします。 [#9985] flatten-maven-plugin を easyj-maven-plugin に置き換えます。 [#10091] SnakeYaml を 2.0 にアップグレードします。

nacos 2.2.1

This version is mainly Specially, Remove default value of token.secret.key and server.identity. Detail see: announcement.

And this version upgrade many dependencies such as spring-boot, Grpc, jraft and so on.

What's more, This version add a beta feature, make the grpc request support TLS, and fix some bugs and enhance some usage problems.

Detail see:

feature

[#9276] Add search config by content. [#9703] add catalog v2 API to support list instances which is un-enabled. [#9710] Support prometheus-sd basic auth. [#9888] Beta support Grpc TLS feature. [#10062] Naming support aliyun STS auth.

Enhancement&Refactor

[#9510] Add sql log print function. [#9646] Replace concatenated strings with placeholders. [#9708] Clean expired and invalid connections for HTTP client. [#9783] Handle public namespaceId as default namespaceId for publish and query config for V2 http api. [#9837] Enhance Grpc connected time when cluster started to load snapshot quickly. [#9859] Refactor default auth plugin, use custom JWT instead of jjwt. [#9860] Adapt logback 1.4.5 by SPI. [#9885] Add prometheus api exception handling. [#9949] Use Grpc replace all Http request between servers. [#9951] Judge the message whether null for metadata processor. [#10084] Client use Async appender to print log. [#10108] Remove identity default value.

BugFix

[#9621] Fix Config Client server check always up problem. [#9728] Fix prometheus http sd only return public namespace problem. [#9732] Fix namespace v2 api auth not work problem. [#9734] Fix http login url without default port problem. [#9795] Fix export config failure problem for non admin user after opening auth. [#9816] Fix redo data is different from server when register and unregister service with concurrency. [#9819] Fix update password failure problem after use nginx. [#9825] Fix config histroy page paged problem. [#9861] Fix auth check before distro filter. [#9862] Fix LDAP login failed. [#9943] Fix Config cas update can't work when using derby database. [#10014] Clear confused logic about namespace properties. [#10038] Fix load failover file failure.

Dependency

[#9504][#9767] Upgeade-spring-boot version to 2.6.14. [#9789] Upgrade jraft version to 1.3.12. [#9772] Upgrade Grpc version to 1.50.2. [#9985] Replace flatten-maven-plugin with easyj-maven-plugin. [#10091] Upgrade snakeYaml to 2.0.
