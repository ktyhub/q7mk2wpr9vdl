nacos 2.2.0

マイナー 公開日2022年12月14日 出典alibaba/nacos English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ナコス2.2.0 このバージョンはいくつかの大きな変更を含む重要なバージョンです。 最初の重要な変更は、1.x の命名に関する古い冗長コードを削除し、相対コードを二重に書き込むことです。変更後、2.2.0 バージョンは Nacos 1.X サーバーからアップグレードできなくなり、少なくともバージョン 2.0.0 からのみアップグレードできます。この変更は 1.X client リクエストの適応には影響しません。ユーザーは引き続き 2.2.0 バージョンの 1.X client を使用できます。 2 番目の重要な変更は、いくつかのプラグインを追加することです。

  • データソース プラグイン。他の DB をサポートするために Asoc 2022 プロジェクトによって追加されました。
  • データベースパスワードの復号化など、Nacos サーバーの構成を処理するためにコミュニティによって追加されたカスタム環境プラグイン。
  • 接続制限プラグイン。古い制限モジュールからリファクタリングされ、高圧下で Nacos サーバーを保護する機能を拡張します。 3 番目の重要な変更は、ベータ機能 Tracing plugin および batch register を強化し、より使いやすくすることです。 詳細は以下を参照してください。

機能

[#5863][#9331] バッチ登録およびバッチ登録解除サービスをサポートします。 [#8308] nacos 2.0用にv2 openAPIを追加しました。 [#8312] データソースプラグインをサポートします。 [#8481] トラックトレースプラグインをサポートしました。 [#8694] prometheus httpサービスディスカバリ(prometheus http sd)をサポートしました。 [#9318] LDAP 認証プラグインの caseSentive をサポートしました。 [#9366] Ldaps認証をサポートします。

強化とリファクタリング

[#7930] 1.x の命名に関する古い冗長コードを削除します。 [#9391] 最適化セレクター。 [#9393] 起動エラー時にサーバーが自動停止するようにしました。 [#9414] ファジークエリを最適化して SQL をより汎用的にします。 [#9415][#9449][#9466][#9497] 拡張データソースプラグイン。 [#9423] ExternalDataSourceProperties に isEmpty チェックを追加して、外部構成をサポートします。 [#9459] NacosApplicationListenerのメソッド修飾子をデフォルトに変更しました。 [#9471] リスト設定ページを返した後、コンソールのクエリ条件を設定に保持します。 [#9597] リストサービスページを返した後、ディスカバリーでコンソールのクエリ条件を保持します。 [#9615] client を強化してサーバーノードを選択し、サーバーをより分散してリクエストします。 [#9653] 接続制限モジュールをプラグインにリファクタリングしました。

バグ修正

[#9334] 多くのテーブルで異なる group_id データ長を修正しました。 [#9341] Bean ldapAuthenticationProvider を作成できない問題を修正しました。 [#9351] prometheusメトリクスのインスタンス数エラーを修正しました。 [#9367] 認証プラグインのプロパティ「token.secret.key」のbase64デコードエラーを修正しました。 [#9408][#9437] コンソール名前空間リストのデプロイの問題を修正しました。 [#9461] ClientWorker NullPointerの判定順序を修正しました。 [#9474] httpヘルスチェックへの変更後に一部のインスタンスが異常になる問題を修正しました。 [#9478] すべてのインスタンスの重みがゼロの場合のセレクターのバグを修正しました。 [#9584] コンソール設定のクエリボタンのオーバーフローが非表示になる問題を修正しました。 [#9586] サービスの有効期限が切れたメタデータの自動クリーンアップ後にインスタンスの登録解除が失敗する問題を修正しました。

依存関係

[#9652] ui の依存関係をアップグレードして、依存関係の脆弱性を修正します。

nacos 2.2.0

This version is an important version which include some large changes.

The first important change is remove the old redundant codes about 1.x naming and double write relative codes. After changed, The 2.2.0 version will can't upgraded from Nacos 1.X server, only can upgraded from at least version 2.0.0. The changes will not effect the adapt for 1.X client request, users can still use 1.X client with 2.2.0 version.

The second important change is adding several plugins:

  • datasource plugin, which added by Asoc 2022 project to support other DBs.
  • custom environment plugin, which added by community to handle configurations of Nacos server, such as decrypt database password.
  • connection limit plugin, which refactored from old limit module, to extend more abilities to protect Nacos server under high pressure.

The third important change is to enhance the beta feature Tracing plugin and batch register, which make them more easy to use.
