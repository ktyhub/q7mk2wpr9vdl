#ディープチューターv1.7.3

DeepTutor v1.7.3 Release Notes

発売日: 2026.11.16 v1.7.2 に基づいて構築された v1.7.3 は、読書と書籍の編集をより柔軟にし、検索とエージェントの接続を拡張し、学習記録、モデル ストリーム、デスクトップのアップグレードを改善します。

新機能

質問ヘルプを読んだり、ズームしたり、再アクセスしたりする

PDF リーダーには、連続ズーム、テキストフィット コントロール、および画像ビューアが追加されています。注釈の更新と複数マテリアルの選択の信頼性が向上しました。リーディングクイズでは、解答キーがサーバー上に保持され、質問にリンクされたヘルプが解答とは別に保存されます。権限を与えられた保護者は、読書の進捗状況、クイズの記録、アクティビティの支援を確認できます。

書籍の変更を適用する前に確認する

書籍全体を再構築せずに、生成された章やセクションを編集します。構造の変更とページチャットの提案では、適用前にレビュー可能な差分が表示され、変更されていない最新の編集は元に戻すことができます。開いたときに新しい空のセクションが生成されます。数学的なレンダリングとページチャットの継続も修正されます。

検索プロバイダーと接続エージェントの追加

検索には、DeepSeek、SpecStream、SearchApi (SearchApi Web、ニュース、および学者モードを含む) が追加されます。 Web Fetch には選択可能な DeepSeek バックエンドが追加され、Standard Compute がモデル設定に加わります。構成されたエージェント Client プロトコル (ACP) プロセスは、ローカル サブエージェントとして参照できます。 MCP OAuth の更新と再接続は、同意して再起動した後はより信頼性が高くなります。

会話と練習はコンテキストを保持します

会話ごとにサポートされる推論の労力を選択します。変更されていないチャット セッションは、準備ができているワークスペースのナレッジ ベースを継承し、保存されたサイドチャット タブは同じアカウントに対して再び開き、質問バンクのソースは検索とページネーションをサポートします。マスタリー修正により、失敗した試行全体で説明が保持され、インデックス再作成後も発行された質問が採点可能に保たれ、参照回答と狭い画面のナビゲーションが改善されます。

ドキュメント解析と言語サポートの向上

Docling は、構造化されたページ コンテンツを保持し、オプションの数式と画像のエンリッチメントを公開します。アップロードの検証は利用可能なパーサー形式に従い、GitHub ナレッジ ソースは MDX を受け入れ、取得では正確なソース パスが尊重されます。イタリア語とハンガリー語がインターフェイスと返信言語のオプションに加わり、ヒンディー語が返信言語になります。

より信頼性の高いモデル ストリームとデスクトップのアップグレード

プロバイダー呼び出しは、停止したストリーム、不完全な端末イベント、ツール識別子、および再生された推論をより慎重に処理します。明らかなミスで結露が止まった後も計画を上回る歴史。新しいデスクトップ アプリをインストールすると、バックアップとロールバックを備えた新しいバンドル コアが採用されます。 macOS Finder が起動すると、一般的なインストール場所にあるホスト CLI も検出されます。ランチャーとアップデーターの準備待機は、設定された制限に従って行われます。

アップグレードに関する注意事項

  • 完全なアプリ: DeepTutor を停止し、ランタイム ホームをバックアップしてから、python -m pip install --upgrade "deeptutor[full]==1.7.3" を実行します。同じ DEEPTUTOR_HOME を維持します。再起動する前に、python -m pip check および deeptutor module list で確認してください。追加の機能ホイールも 1.7.3 と一致する必要があります。
  • レガシー インストール: バージョン 1.6.15 以前では、モジュラー ファミリをインストールする前に古い deeptutor-cli パッケージをアンインストールする必要があります。 v1.7.0 の手動移行を使用します。古い更新ワーカーは、新しい移行ロジックを遡って取得することはできません。同じ環境で "deeptutor[full,parse]==1.7.3" を使用して、オプションの解析を行ってアプリ全体を復元します。
  • ソースと Docker: ソース ユーザーは、requirements/full.txt、次に python -m pip install -e . --no-deps をインストールし、Node.js 22 で web/ を npm ci --legacy-peer-deps で更新します。 Docker ユーザーは、ghcr.io/hkuds/deeptutor:1.7.3 または :latest をプルし、既存のデータ ボリュームでコンテナーを再作成します。
  • デスクトップ: 対応する Apple Silicon または Intel DMG、Windows インストーラー、またはポータブル ZIP を使用します。 Windows ビルドは未署名のままです。自動更新検出は接続されていません。アプリを置き換えると、バンドルされた新しいコアが試用され、ワー​​クスペースのバックアップが保存されます。
  • 埋め込み: インデックス付きの OpenAI 互換埋め込み応答が入力順序に復元されるようになりました。ゲートウェイが以前に並べ替えられたベクトルを返した場合は、影響を受けるインデックスを再構築して、テキストとベクトルの関連付けを修正します。既存のインデックス ファイルは保存されます。
  • ブック編集と ACP: 構造編集の前にブックの生成を一時停止します。 ACP には、設定されたエージェント コマンドと独自の認証が必要です。対話型の引き出しと許可の要求は、この初期の client ではサポートされていません。
  • プロバイダーの回復: デフォルトは store=false のままです。リクエストが既に store=true にオプトインされている場合、既知のレスポンスの回復は、公式の OpenAI Responses エンドポイントに限定されます。未解決の操作は、代替作業を自動的に送信する代わりに一時停止されます。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.7.2...v1.7.3

DeepTutor v1.7.3

Highlights

  • Reading and book editing — The PDF reader gains continuous zoom, text fitting, image viewing, and guardian-accessible reading/quiz activity. Generated chapters and sections can now be edited independently with reviewable diffs and undo, avoiding full-book rebuilds; pause book generation before applying structural changes.

  • Search, agents, and learning continuity — DeepSeek, SpecStream, and SearchApi expand search, while Web Fetch gains a DeepSeek backend and configured ACP processes can serve as local subagents. ACP requires its own command and authentication, with no interactive permission/elicitation support yet. Conversations retain workspace context, reasoning-effort choices, and side-chat tabs; mastery handling and question-bank navigation also improve.

  • Parsing and stream reliability — Docling preserves structured page content with optional formula/picture enrichment, upload validation follows parser capabilities, and GitHub sources accept MDX. Italian and Hungarian join the UI, Hindi becomes a reply language, and provider-stream fixes address stalls, incomplete terminal events, and replayed reasoning. These changes mainly benefit document-heavy and multilingual users.

  • Migration and data-integrity warning — OpenAI-compatible embedding responses are now restored to input order. If a gateway previously returned reordered vectors, rebuild affected indexes; existing index files are preserved, but their text/vector associations may be wrong. Full installs should stop the app, back up and retain the same DEEPTUTOR_HOME, install deeptutor[full]==1.7.3, then run python -m pip check and deeptutor module list; feature wheels must also match 1.7.3. Versions 1.6.15 and earlier must remove deeptutor-cli and follow the v1.7.0 manual migration because an old update worker cannot acquire the new logic.

  • Upgrade recommendation — This is a substantive feature and reliability release, worth upgrading for readers, book editors, search/ACP users, and anyone affected by embedding or streaming issues; users outside those areas can reasonably skip it. Desktop users should install the matching Apple Silicon/Intel DMG, Windows installer, or portable ZIP manually: Windows builds remain unsigned, automatic update discovery is not connected, and replacing the app trials its bundled core while preserving a workspace backup.

DeepTutor v1.7.3 Release Notes

Release Date: 2026.11.16

Building on v1.7.2, v1.7.3 makes reading and book editing more flexible, expands search and agent connections, and improves learning records, model streams, and desktop upgrades.

What's New

Read, zoom, and revisit question help

The PDF reader adds continuous zoom, text-fit controls, and an image viewer. Annotation updates and multi-material selection are more reliable. Reading quizzes keep answer keys on the server and preserve question-linked help separately from attempts; authorized guardians can review reading progress, quiz records, and help activity.

Review book changes before applying them

Edit generated chapters and sections without rebuilding the whole book. Structure changes and page-chat proposals show a reviewable diff before application, and the most recent unchanged edit can be undone. New empty sections generate when opened; math rendering and page-chat continuation also receive fixes.

More search providers and connected agents

Search adds DeepSeek, SpecStream, and SearchApi, including SearchApi web, news, and scholar modes. Web Fetch gains a selectable DeepSeek backend, and Standard Compute joins model setup. A configured Agent Client Protocol (ACP) process can be consulted as a local subagent. MCP OAuth refresh and reconnection are more reliable after consent and restarts.

Conversations and practice retain their context

Choose supported reasoning effort per conversation. Untouched chat sessions inherit ready workspace knowledge bases, saved side-chat tabs reopen for the same account, and question-bank sources support search and pagination. Mastery fixes preserve explanations across failed attempts, keep issued questions gradable after re-indexing, and improve reference answers and narrow-screen navigation.

Better document parsing and language support

Docling preserves structured page content and exposes optional formula and picture enrichments. Upload validation follows the available parser formats, GitHub knowledge sources accept MDX, and retrieval respects exact source paths. Italian and Hungarian join the interface and reply-language options, while Hindi becomes a reply language.

More reliable model streams and desktop upgrades

Provider calls handle stalled streams, incomplete terminal events, tool identifiers, and replayed reasoning more carefully. History that still exceeds its plan after condensation stops with a clear error. Installing a newer desktop app adopts its newer bundled core with backup and rollback; macOS Finder launches also discover host CLIs in common install locations. Launcher and updater readiness waits respect configured limits.

Upgrade Notes

  • Full app: stop DeepTutor and back up the runtime home, then run python -m pip install --upgrade "deeptutor[full]==1.7.3". Keep the same DEEPTUTOR_HOME; verify with python -m pip check and deeptutor module list before restarting. Additional feature wheels must also match 1.7.3.
  • Legacy installations: versions 1.6.15 and earlier require uninstalling the old deeptutor-cli package before installing the modular family. Use the manual migration in v1.7.0; an old update worker cannot acquire the new migration logic retroactively. Recover a full app with optional parsing using "deeptutor[full,parse]==1.7.3" in the same environment.
  • Source and Docker: source users install requirements/full.txt, then python -m pip install -e . --no-deps, and refresh web/ with npm ci --legacy-peer-deps on Node.js 22. Docker users pull ghcr.io/hkuds/deeptutor:1.7.3 or :latest and recreate the container with its existing data volume.
  • Desktop: use the matching Apple Silicon or Intel DMG, Windows installer, or portable ZIP. Windows builds remain unsigned. Automatic update discovery is not connected; replacing the app now trials a newer bundled core and preserves a workspace backup.
  • Embeddings: indexed OpenAI-compatible embedding responses are now restored to input order. If a gateway previously returned reordered vectors, rebuild affected indexes to correct their text/vector associations; existing index files are preserved.
  • Book editing and ACP: pause book generation before structural edits. ACP requires a configured agent command and its own authentication; interactive elicitation and permission requests are not supported by this initial client.
  • Provider recovery: the default remains store=false. Recovery of an already-known response is limited to the official OpenAI Responses endpoint when the request already opted into store=true; unresolved operations pause instead of automatically submitting replacement work.
