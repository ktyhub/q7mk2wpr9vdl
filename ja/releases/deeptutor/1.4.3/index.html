#ディープチューター v1.4.3

ディープチューター v1.4.3 Release Notes

発売日: 2026.06.12 v1.4.0以来最大のリリース。 TutorBot は次のように成長します。 パートナー、チャットは単一のエージェント ループに崩壊し、マルチユーザーが現実になる ユーザーごとの分離、視覚化、共同作成者、ファイル ビューア、ドキュメント 解析し、CLI がすべてレベルアップしました。のドキュメント deeptutor.info は並行して再構築されました — すべてのパートナー チャネルには、英語と中国語の独自のセットアップ ガイドが用意されています。

TutorBot からアップグレードしますか? 移行は自動で非破壊的です。 最初の起動時にボットがパートナーになります — チャネル構成 (シークレット) が含まれます）、モデルの選択、および魂のライブラリーは引き継がれ、それぞれ ボットのペルソナは SOUL.md になります。古い data/tutorbot/ ツリーは 何も変更されないため、ロールバックしても安全です。破壊的な変更の 1 つ: HTTP API が /api/v1/tutorbot/... から /api/v1/partners/... に移動 — それを呼び出すスクリプトを更新します。 [tutorbot] ピップは追加で維持されます [partners] のエイリアスとして活動しています。

新機能

TutorBot → パートナー

あなたのボットは パートナー になりました。同じ考えで、より強力な実行が行われます。

  • パートナーは、製品チャット (別個のチャット) と同じエージェント ループで実行されます。 nanobot エンジンは廃止されました)、チャットのあらゆる改善が IM ボットに反映されます 自動的に。
  • 運用グレードのメッセージ パイプライン: 送信の再試行、重複排除、結合、および チャネルごとの配信マトリックス。
  • Telegram、Discord、Feishu での ライブ ストリーミングの返信 — 回答 生成されたとおりにレンダリングします。
  • 新しい WeCom AI Bot チャンネル; Slack からの合計 15 チャネル コネクタ DiscordからDingTalk、QQ、WhatsAppまで。
  • Web チャットでは 添付ファイル を使用できるようになりました - 画像やファイルを直接ドロップします パートナーとの会話。
  • アプリ内エディターを備えた書き直された魂のテンプレート ライブラリ。

チャット用の 1 つのループ

2 フェーズのターゲティング/応答パイプラインは廃止されました。チャットは単一のチャットを実行するようになりました エンドツーエンドで呼び出しを行うネイティブ ツールを使用してエージェント ループを探索する - 移動が少なくなる 部品の使用、より賢い工具の使用、誤った方向の回転がなくなりました。新しいアクティビティ header はステータス行を上部に固定し、思考/ツールを折りたたむ 答えが見つかったら、それを追跡します。

実際のマルチユーザー分離

  • ユーザーごとの許可 v2: ツール、MCP サーバー、および実行アクセスが制御されます 管理 UI からユーザーごとに。
  • ワークスペースのレイアウトは data/users/<uid> + data/system に移動します。既存の デプロイメントは自動的に移行されます。
  • exec ランナーは、呼び出し側ユーザーのワークスペース サブツリーのみをマウントします (新しい Dockerfile.runner) なので、サンドボックス化されたコードは他のユーザーのファイルを参照することはありません。

視覚化、再構築

インラインでテーマを意識した SVG レンダリング。構造化されたプロンプト。そして地元の 古い完全な LLM レビューを置き換える検証 + 修復パス - より速く、 より安価で、壊れた図もはるかに少なくなります。全画面表示がすべてのデバイスで機能するようになりました。 ビジュアルタイプ。

よりシャープな日常ツール

  • 共同作成者 は、Mermaid を介してフローチャートとシーケンス図をレンダリングします。 選択範囲の質問はナレッジ ベースと Web から取得できます。
  • ファイル ビューア: ブラウザ内での真の docx/xlsx プレビュー、ドラッグしてサイズ変更、 アクティビティ パネルは、開いているファイルと一緒に表示されるようになりました。
  • ローカル バックエンドの代替としての MinerU クラウド解析 (/settings/mineru)、質問抽出で質問がキャプチャされるようになりました。 種類、難易度、答え。
  • Office スキルはすぐに使用できます — docx/pdf/pptx/xlsx 世代なし 長くするにはサンドボックス スイッチを切り替える必要があります。
  • CLI チャット、書き直されました: 新しいループ プロトコルに合わせた、対話型 端末の ask_user プロンプト、Ctrl-C キャンセル、および折りたたみ可能 思考のアウトプット。

重要な修正

Qwen モデルでは、JSON ラッパーが回答に漏れなくなり、Windows がインストールされます UTF-8 を正しく取得し、Zulip ボットがメンションを確実にキャッチし、 ファイル記述子の枯渇バグに加えて、誤検知のヘルスチェックもなくなりました。

ドキュメント、同期されました

deeptutor.info はこのリリースで再構築されました: すべてのパートナー チャネル用の専用セットアップ ガイド (英語 + 中文)、 全体のスクリーンショットを更新し、CLI とサーバー API を更新しました 参考文献。

アップグレードに関する注意事項

  • pip install -U deeptutor — 移行は最初に自動的に実行されます。 開始し、それらはすべて冪等です。
  • レガシー multi-user/ ツリーは所定の位置で data/users/ に移動します。家庭教師ボット ボットはパートナーになります (上部の注を参照)。
  • 実行ベースのスキルで、デフォルトでサブプロセスが許可されるようになりました。古いものを復元するには 動作を変更するには、システム設定で sandbox_allow_subprocess を false に設定します。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.4.2...v1.4.3

DeepTutor v1.4.3

Highlights

  • Partners replace TutorBot — On first start, bots convert automatically while preserving channel configs, secrets, model selection, and soul libraries; each persona becomes SOUL.md. The untouched data/tutorbot/ tree preserves rollback safety, and [tutorbot] remains an alias for [partners]. Partners gain Chat’s agent loop, streaming replies, web attachments, delivery retries/dedup/coalescing, and a new WeCom AI Bot connector.

  • Breaking API route change — Endpoints move from /api/v1/tutorbot/... to /api/v1/partners/.... Update scripts, automation, and external integrations before deploying; bot migration itself does not rewrite API callers.

  • Chat moves to a single agent loop — The two-phase targeting/respond pipeline and separate nanobot engine are removed in favor of native tool calling end to end, reducing mis-routed turns. The CLI follows the same protocol with terminal ask_user prompts, Ctrl-C cancellation, and collapsible thinking output.

  • Multi-user isolation is enforced — Per-user grants v2 now control tools, MCP servers, and exec access from the admin UI. Workspace migration moves legacy trees to data/users/<uid> and data/system; the new Dockerfile.runner mounts only the calling user’s subtree, preventing cross-user file access.

  • Visualize and everyday tools improve — Theme-aware inline SVGs plus a local validate-and-repair pass replace costly full-round LLM review, reducing broken diagrams and enabling fullscreen for every visual type. Co-writer adds Mermaid flowcharts/sequence diagrams, the viewer adds browser-native docx/xlsx previews, and MinerU offers cloud document parsing as an alternative to the local backend.

  • Sandbox subprocesses are now allowed by default — Office skills for docx/pdf/pptx/xlsx work without extra configuration, but this widens exec behavior. Set sandbox_allow_subprocess: false in system settings to preserve the previous policy.

DeepTutor v1.4.3 Release Notes

Release Date: 2026.06.12

The biggest release since v1.4.0. TutorBot grows up into Partners, Chat collapses into a single agent loop, multi-user gets real per-user isolation, and Visualize, Co-writer, the file viewer, document parsing, and the CLI all level up. The docs at deeptutor.info have been rebuilt alongside — every Partner channel now has its own setup guide, in English and Chinese.

Upgrading from TutorBot? Migration is automatic and non-destructive: on first start your bots become Partners — channel configs (secrets included), model selection, and the soul library carry over, and each bot's persona becomes its SOUL.md. The old data/tutorbot/ tree is left untouched, so rolling back stays safe. One breaking change: the HTTP API moved from /api/v1/tutorbot/... to /api/v1/partners/... — update any scripts that call it. The [tutorbot] pip extra keeps working as an alias for [partners].

What's New

TutorBot → Partners

Your bots are now Partners — same idea, much stronger execution:

  • Partners run on the same agent loop as product Chat (the separate nanobot engine is gone), so every Chat improvement reaches your IM bots automatically.
  • Production-grade message pipeline: send retries, dedup, coalescing, and a per-channel delivery matrix.
  • Live streaming replies on Telegram, Discord, and Feishu — answers render as they are generated.
  • New WeCom AI Bot channel; 15 channel connectors total, from Slack and Discord to DingTalk, QQ, and WhatsApp.
  • Web chat now takes attachments — drop images or files straight into a Partner conversation.
  • A rewritten soul template library with an in-app editor.

One Loop for Chat

The two-phase targeting/respond pipeline is gone. Chat now runs a single exploring agent loop with native tool calling end to end — fewer moving parts, smarter tool use, no more mis-routed turns. A new Activity header keeps the status line pinned on top and folds the thinking/tool trace away once the answer lands.

Real Multi-User Isolation

  • Per-user grants v2: tools, MCP servers, and exec access are controlled per user from the admin UI.
  • Workspace layout moves to data/users/<uid> + data/system; existing deployments migrate automatically.
  • The exec runner mounts only the calling user's workspace subtree (new Dockerfile.runner), so sandboxed code never sees another user's files.

Visualize, Rebuilt

Inline, theme-aware SVG rendering; structured prompts; and a local validate + repair pass replacing the old full-round LLM review — faster, cheaper, and far fewer broken diagrams. Fullscreen now works for every visual type.

Sharper Everyday Tools

  • Co-writer renders flowcharts and sequence diagrams via Mermaid, and selection-scoped questions can pull from your knowledge base and the web.
  • File viewer: true in-browser docx/xlsx previews, drag-to-resize, and the Activity panel now lives alongside your open files.
  • MinerU cloud parsing as an alternative to the local backend (/settings/mineru), and question extraction now captures question type, difficulty, and answers.
  • Office skills work out of the box — docx/pdf/pptx/xlsx generation no longer requires flipping a sandbox switch.
  • CLI chat, rewritten: aligned with the new loop protocol, interactive ask_user prompts in the terminal, Ctrl-C cancellation, and collapsible thinking output.

Fixes That Matter

Qwen models no longer leak JSON wrappers into answers, Windows installs get UTF-8 right, Zulip bots catch mentions reliably, and a file-descriptor exhaustion bug plus false-positive health checks are gone.

Docs, Synced

deeptutor.info was rebuilt with this release: a dedicated setup guide for every Partner channel (English + 中文), refreshed screenshots throughout, and updated CLI and server API references.

Upgrade Notes

  • pip install -U deeptutor — the migrations run automatically on first start, and all of them are idempotent.
  • Legacy multi-user/ trees move to data/users/ in place; TutorBot bots become Partners (see the note at the top).
  • Exec-based skills now allow subprocesses by default. To restore the old behavior, set sandbox_allow_subprocess to false in system settings.
