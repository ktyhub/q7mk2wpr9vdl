#ディープチューター v1.6.15

#ディープチューター v1.6.15 Release Notes

発売日: 2026.10.19

v1.6.14 に基づいて構築された v1.6.15 は、レビューされたアウトラインの変更、独立して採点された質問グループ、制限された個別指導の記憶により、ガイド付き学習を改善します。また、チャットの回復とドキュメントの解析も強化され、検索比較が追加され、Gemini のネイティブ音声が提供されます。

新機能

見直して実践できる学習パス

コミットする前にモジュールの並べ替えをプレビューし、調整された変更をモジュール間でまとめて適用します。講師は、グループとして 2 ～ 4 つの質問を提示し、部分的な提出物を保持し、各回答を個別に評価できます。ソースに基づいた意味論的評価は、不完全、不正確、不確実な回答を区別しながら、同等の説明を受け入れます。コンセプトカードとデザインカードは引き続き実践されます。習得するには依然として学習者自身の説明が必要です。

より長いセッションでの継続的な指導

Guided Learning では、指導の好み、未解決の誤解、関連するソースアンカーが境界付きメモリに保持され、必要に応じて元のやり取りにアクセスできます。ソースの準備は、現在の学習リクエストに従い、目に見える指導を保存し、セッション言語で進行状況を報告し、失敗を修復します。使用量の合計には、準備呼び出しとメモリ圧縮呼び出しが含まれるようになりました。圧縮には独自のコストがかかります。

より信頼性の高い会話と設定

ストリーミングされたコンテンツは回復のために定期的に保存され、完了したストリームはメモリ内イベントを解放し、再接続中の client は実際の端末イベントを待ちます。未送信のメッセージは、サーバーがメッセージの削除または置換を確認するまで、回復可能なコピーを保持します。設定では、カタログの書き込みが失敗した後も下書きが保持され、対処可能な権限または HTTP エラーが表示されます。学習ナビゲーションはアカウント許可を尊重し、名前付きタイムゾーンは Windows で機能します。

障害を切り分ける解析

MinerU CLI ワーカーは、明示的なプロセス所有権と一貫した期限を持ち、端末エラーの詳細を保持し、単にログが静かになったからといって停止されることはありません。読み取り不可能な PDF とネイティブ パーサーのエラーはインデックス作成中に分離されるため、他のドキュメントは続行できます。キャンセルは正しいインデックス作成の実行に関連付けられたままになり、回復メッセージによって再利用可能な解析と再起動が必要な埋め込み作業が区別されます。

検索実験とワークスペースの説明

オプションのクエリ リライト レイヤーは 1 つのスタンドアロン検索クエリを生成し、失敗すると元のクエリにフォールバックします。 deeptutor kb eval --rewrite off|standalone レコードは来歴を書き換えます。 deeptutor kb eval-diff baseline.json candidate.json は、保存されたメトリクスとケースを比較します。ワークスペースの指示は、サポートされる機能のその後のターンをガイドします。読み取りでは、ブラウザーで圧縮された .epub.zip フォルダーも受け入れられ、再生、引用、および注釈の回復が向上します。

プロバイダーとオプションのリクエストのスクリーニング

Gemini TTS は、Google 音声によるネイティブ generateContent 音声を使用し、onomeo が OpenAI 互換プロバイダー カタログに加わりました。オプションの guard エクストラにより、HTTP レート制限、アドレス ルール、およびリクエスト パターン スクリーニングが追加されます。デフォルトでは無効になっており、リクエスト本文や WebSocket トラフィックは検査されません。

英語と中国語のドキュメントは、リリースに合わせて deeptutor.info で更新されます。

アップグレードに関する注意事項

pip install -U deeptutor を実行します。 Docker ユーザーは ghcr.io/hkuds/deeptutor:latest をプルします。アップグレード後に実行中のサービスを再起動します。

  • Gemini 音声: Google 音声と WAV または PCM 出力を選択します。このアダプターは速度パラメーターを受け入れません。配信スタイルについては音声指示を使用します。
  • クエリ リライト: デフォルトでは無効になっています。文書化されたプロセスのオーバーライドを通じて、または評価のために明示的に data/user/settings/query_rewrite.json でこれを有効にします。書き換えると追加のモデル呼び出しが行われます。
  • ワークスペースの手順: [設定] → [ワークスペース] で設定します。変更は次のターンから適用されます。 Deep Research、Quiz、Manim では使用されません。
  • リクエスト スクリーニング: 必要な場合にのみ、deeptutor[guard] をインストールし、system.json で security_guard.enabled を有効にします。 ガード ガイド でプロキシとレート制限の設定を確認してください。カウンタは各サーバー プロセスに対してローカルです。
  • インデックス回復: 再試行では、互換性のある完了した解析と検証済みのクラウド スライスが再利用されます。作業の途中で中断されたローカル推論や埋め込みを再開することはありません。

DeepTutor v1.6.15

Highlights

  • Guided Learning gets editable paths and independent grading — Module reordering can now be previewed before it's committed and applied as coordinated multi-module changes, and tutors can batch 2–4 questions into a group that retains partial submissions and grades each answer independently. The source-grounded semantic grader accepts equivalent explanations while separating incomplete, incorrect, and uncertain answers — meaningful if you're building assessment flows, but note concept/design cards remain practice-only and mastery still requires a learner-authored explanation.

  • Bounded teaching memory — with a new cost axis — Guided Learning now persists teaching preferences, unresolved misunderstandings, and source anchors in bounded memory, with access to original exchanges when needed. Watch the metering change: usage totals now fold in source-preparation and memory-compression calls, and compression is billed separately, so per-session cost accounting will shift after upgrade (pip install -U deeptutor; restart running services).

  • Streaming and recovery hardening — Streamed content is checkpointed periodically, completed streams release their in-memory event buffers (a leak fix for long-lived servers), and reconnecting clients now wait for the actual terminal event instead of an early proxy. Unsent messages keep recoverable copies until the server acknowledges dismissal or replacement, settings preserve drafts after failed catalog writes with actionable permission/HTTP errors, and named timezones finally work on Windows.

  • Indexing isolates parse failures — MinerU CLI workers get explicit process ownership, consistent deadlines, and retained terminal error details, and they're no longer killed merely because logs go quiet. Unreadable PDFs and native parser failures are contained per document so the rest of an indexing run proceeds; cancellation is scoped to the correct run, and recovery messages distinguish reusable parses from embedding work that must restart. Operationally: retries reuse completed parses and validated cloud slices but do not resume interrupted local inference or embeddings mid-flight.

  • Retrieval eval tooling and workspace instructions — An optional query-rewrite layer emits one standalone query and falls back to the original on failure; it's off by default and adds an extra model call (enable via data/user/settings/query_rewrite.json, process overrides, or per-eval). The new deeptutor kb eval --rewrite off|standalone and deeptutor kb eval-diff baseline.json candidate.json let you A/B saved metrics and cases before flipping rewriting on globally. Workspace instructions steer subsequent turns but are deliberately ignored by Deep Research, Quiz, and Manim.

  • New providers and opt-in request screening — Gemini TTS moves to native generateContent speech with Google voices and WAV/PCM output (no speed parameter — use voice instructions for delivery style), and onomeo joins the OpenAI-compatible catalog. The optional deeptutor[guard] extra adds HTTP rate limits, address rules, and request-pattern screening; it's disabled by default, doesn't inspect bodies or WebSocket traffic, and its counters are local to each server process, so review proxy/rate-limit settings before enabling security_guard.enabled in system.json.

No breaking changes in this release.

DeepTutor v1.6.15 Release Notes

Release Date: 2026.10.19

Building on v1.6.14, v1.6.15 improves Guided Learning with reviewed outline changes, independently graded question groups, and bounded tutoring memory. It also strengthens chat recovery and document parsing, adds retrieval comparisons, and brings native Gemini speech.

What's New

Learning paths you can revise and practice

Preview module reordering before committing it, and apply coordinated changes across modules together. Tutors can present two to four questions as a group, retain partial submissions, and assess each answer independently. Source-grounded semantic assessment accepts equivalent explanations while distinguishing incomplete, incorrect, and uncertain answers. Concept and design cards remain practice; mastery still requires the learner's own explanation.

Teaching continuity in longer sessions

Guided Learning retains teaching preferences, unresolved misunderstandings, and relevant source anchors in bounded memory, with access to original exchanges when needed. Source preparation follows the current learning request, preserves visible teaching, and reports progress and repair failures in the session language. Usage totals now include preparation and memory-compression calls; compression has its own cost.

More reliable conversations and settings

Streamed content is saved periodically for recovery, completed streams release their in-memory events, and reconnecting clients wait for the actual terminal event. Unsent messages retain recoverable copies until the server acknowledges their dismissal or replacement. Settings keep drafts after failed catalog writes and show actionable permission or HTTP errors. Learning navigation respects account grants, and named timezones work on Windows.

Parsing that isolates failures

MinerU CLI workers have explicit process ownership and consistent deadlines, retain terminal error details, and are not stopped merely because their logs go quiet. Unreadable PDFs and native parser failures are isolated during indexing so other documents can continue. Cancellation stays attached to the correct indexing run, and recovery messages distinguish reusable parsing from embedding work that must restart.

Retrieval experiments and workspace instructions

An optional query-rewrite layer produces one standalone search query and falls back to the original on failure. deeptutor kb eval --rewrite off|standalone records rewrite provenance; deeptutor kb eval-diff baseline.json candidate.json compares saved metrics and cases. Workspace instructions guide subsequent turns in supported capabilities. Reading also accepts browser-zipped .epub.zip folders and improves playback, citations, and annotation recovery.

Providers and optional request screening

Gemini TTS uses native generateContent speech with Google voices, and onomeo joins the OpenAI-compatible provider catalog. An optional guard extra adds HTTP rate limits, address rules, and request-pattern screening; it is disabled by default and does not inspect request bodies or WebSocket traffic.

English and Chinese documentation is updated alongside the release at deeptutor.info.

Upgrade Notes

Run pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest. Restart running services after upgrading.

  • Gemini speech: select a Google voice and WAV or PCM output. This adapter does not accept a speed parameter; use voice instructions for delivery style.
  • Query rewrite: disabled by default. Enable it in data/user/settings/query_rewrite.json, through the documented process overrides, or explicitly for an evaluation. Rewriting makes an additional model call.
  • Workspace instructions: configure them in Settings → Workspace. Changes apply from the next turn; Deep Research, Quiz, and Manim do not use them.
  • Request screening: install deeptutor[guard] and enable security_guard.enabled in system.json only when wanted. Review proxy and rate-limit settings in the guard guide; counters are local to each server process.
  • Index recovery: retries reuse compatible completed parses and validated cloud slices. They do not resume interrupted local inference or embedding midway through its work.
