DeepTutor v1.5.15

パッチ 公開日2026年8月20日 出典HKUDS/DeepTutor English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューター v1.5.15 #ディープチューター v1.5.15 Release Notes 発売日: 2026.08.20 v1.5.14 文書を会話の隣に置きます。これは主にその背後にあるものに関するものです。Pag​​eIndex は自分でホストできるものになり、ドキュメント ツリーを推論して取得できます。質問バンクはファイルに登録できないリストではなくなり、サードパーティのパッケージは独自のツールと機能を登録できるようになります。そのほぼすべてがコミュニティのプル リクエストとして到着しました。ドロップイン — 移行や再インデックスの必要はありません。

新機能

PageIndex は自分でホストでき、その理由を取得する

PageIndex OSS は、独自のナレッジ ベース タイプとしてエンジン リストに参加します。ホストされたサービスと同じインターフェイスで、ベースのローカル ライブラリにバインドされ、PageIndex API キーの代わりに既に構成した LLM によって駆動されます。 両方のバリアントで取得が変更されました。 PageIndex ベースは、組み込みの MCP サーバーを通じて読み取られていました。そのパスはなくなり、ドキュメント ツリーをたどる小さな読み取りループに置き換えられました。最初に構造を作成し、次に必要なページだけを読み上げます。可動部分が減り、同じページレベルの引用が戻ってきます。

質問バンクは書き込み専用を停止します

addEntryToCategory は v1.3.6 で出荷され、フロントエンドから呼び出されることはありませんでした。そのため、11 回のリリースの間、学習者はカテゴリを作成しても、その中に何も入れることができませんでした。クイズ カードのカスタム ドロップダウンは、それを呼び出す共有カテゴリ メニューを使用するようになりました。 このページは、フラット リストでは実行できなかった 3 つの機能、つまり検索、一括選択、およびまだ誰も提出していない質問の受信箱を中心に再構築されています。段階別のマスタリー パスの質問には、説明と難易度が含まれています。 そしてついに家庭教師があなたのためにファイルを提出することができます。間違った答えをグループ化するように依頼すると、銀行には書き込み可能なハンドルがなかったため、write_note に到達し、あなたのリクエストは静かにノートブックの記録になりました。中国語の write_note ヒントには、追加する理由として「错题分析」さえ記載されていました。新しい question_bank ツールは名前でアドレス指定されます。organize はカテゴリ名を取得し、見つからない場合はそれを作成するため、ファイリングは 1 回のリストの後に 1 回の呼び出しで完了します。バンクにエントリがある場合にのみマウントされます。

サードパーティのツールと機能

2 つのエントリ ポイント グループにより、インストールされたパッケージはツリーに影響を与えることなく DeepTutor を拡張できます。 deeptutor.plugins は機能レジストリによってすでにインポートされており、/plugins/list は try/except の背後にありましたが、モジュールは存在しなかったため、プラグインの検出はデッド パスでした。それは今では現実です。 deeptutor.loop_capabilities は、名前の衝突に勝つ組み込み機能とともにチャット ループ機能を登録します。壊れたエントリ ポイントは致命的ではなくスキップされ、検出はプロセスごとにキャッシュされるため、プラグイン機能はシングルトンのままです。

Apache Tika の解析

7 番目のドキュメント解析エンジン。[設定] → [ナレッジベース] で選択できます。 Tika はリモート専用です。Python パッケージやモデルのダウンロードはありません。Apache Tika サーバー (TIKA_SERVER_URL) をポイントし、幅広い形式のセットを Markdown に変換します。

LightRAG のインデックス ノブ (UI 内)

max_concurrent_files、llm_model_max_async、および entity_extract_max_gleaning は、#877 のランタイム設定と API に到達しましたが、入力がなかったため、構成を手動で編集することによってのみ到達できました。これらは、独自の インデックス作成 ディバイダーの下に配置されるようになりました。これは、上記のクエリ ノブとは異なる軸であり、ベースの 構築方法 を形成するため、変更は次の質問ではなく次のビルドに適用されます。配線は、インストールされた RAG-Anything に何を受け入れるかを尋ね、残りを警告とともに削除します。そのため、古いインストールは、上げずにライブラリのデフォルトで実行し続けます。

ナレッジベース内のドキュメントツリーの再構築

3 つの修正が最終的に終了しました #866。リンクされたフォルダーのサブディレクトリが raw/ の最上位に折りたたまれなくなりました。異なるサブツリーにある同じ名前のドキュメントがお互いに通知なく削除されることはなくなりました (自由な兄弟名の下で異なるバイト ステージ間で衝突が発生し、同一のバイトは引き続き削除されます)。アップロードにはオプションの 宛先フォルダー が使用されるようになりました。 最後の 1 つが実際のブロッカーでした。ブラウザーのフォルダー選択では、選択したディレクトリを基準とした各ファイルのパスが報告されるため、应用开发/钉钉CLI/ を一度に 1 つずつサブツリーを追加すると、それがどこに属しているのかを知る方法がなく、钉钉CLI/... として到着します。すべてのバッチがルートに蓄積され、失われた祖先は最初からペイロードに含まれていませんでした。ファイルがステージングされると、ピッカーはベースの既存のフォルダーを提供するようになりました。

書籍: 学習を記録した受信箱

選択した読書セグメントは、明示的なステータスのライフサイクルとともに書籍ごとに保持されるため、キャプチャをどこにでも移動する前に確認できます。これとは別に、ドリフト警告が正確になりました。古いページの検出は実際に変更された KB ドキュメントに限定され、フラグが立てられたページが再コンパイルを待っている間は警告はクリアされません。

Whisper — コミュニティへの貢献

/whisper は、@alanguan73 が提供した 2 人掛けのカウンセリング練習室です。講師が訪問者を演じ、あなたは研修生の席に座り、スーパーバイザーがささやきながら研修生にだけ見えるコーチングを行い、セッション終了後の報告会が行われます。これは Learning Space → More Projects の下にあり、独自の機能パッケージをインストールする必要があります。水上艦やカウンセリング機能は DeepTutor の一部ではありません。 その作業の一般に有用な半分はランタイムにあります。機能は CAPABILITY_COMPLETE で本体と独自に宣言されたエクストラを公開できるようになりましたが、capability、session_id、および turn_id はなりすまし不可能のままです。明示的に宣言された sub-dict のみがイベント バス上に送られます。ターン メタデータは、ライブ呼び出し可能ファイルと ask_user 応答を保持するスクラッチパッドであり、決してワイヤー形式ではありませんでした。

各種詰め合わせ

  • モデルは今日が何日であるかを知っています。 実際の日付がなければ、Web 検索を作成するときにトレーニングのカットオフから「今日」を解決しました。挿入されたブロックは 1 日単位であるため、システム プロンプトは 1 日以内にバイト安定した状態を保ち、プロンプト キャッシュ ヒットを維持します。
  • ターンを削除してもセッションが空白にならなくなりました。 子孫が削除された行をポイントし、セッションはルートを失い、ページが空になりました (#912)。削除された行は親ポインター ツリーから切り離され、すでに破損したセッションは最も古い孤立したセッションから復元されます。
  • 古い CA バンドルによってすべての LLM 呼び出しが中断されることはなくなりました。 残りの SSL_CERT_FILE / SSL_CERT_DIR (ca-certificates なしで conda 環境をクローンした後によく見られます) により、構築中に httpx が発生しました。壊れたパスはドロップされるため、TLS はデフォルトのバンドルに戻ります。
  • 思考タグは非 SSE ローカル ストリームでもフィルタリングされます。 そのブランチは推論ブロックを直接渡しました。両方のブランチが 1 つのインクリメンタル パーサーを共有するようになりました。そのため、チャンクに分割されたタグや閉じられないままになったタグは、どちらの場合でも同じように動作します。
  • 未処理のサーバー エラーは、Starlette のプレーンテキスト 500 ではなく JSON を返し、ハンドラーはミドルウェア スタック内に留まるため、応答には引き続き CORS ヘッダーが含まれます。
  • Obsidian ボールトは現実世界のファイルでも存続します — デコード不可能なバイトと日付型のフロントマターは許容され、ボールトを開けなかった場合でも、不透明に失敗するのではなく、その理由が示されます。
  • スタックしたセッションのロードは回転せずに再試行可能な状態で終了し、ネイティブ アダプターによってプレーンな辞書として発行されたトークンの使用状況は失われるのではなく記録されます。
  • マスタリー読み取りはパスの発明を停止、ask_user 再開後に end_loop が尊重され、codebuddy の追加が再び解決されます。
  • フロントエンドは CI で lint されています。 ESLint はすべてのビルドで web/ で実行されるようになりました。 deeptutor.info のドキュメントは、このリリースとともに更新されました。

アップグレードに関する注意事項

pip install -U deeptutor; Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。スキーマの変更、インデックスの再作成、移行は必要ありません。

  • PageIndex OSS には、API キーまたはローカル LLM プロファイルが必要です。 OAuth 専用プロバイダー (OpenAI Codex、GitHub Copilot、CodeBuddy) はインデックス作成を駆動できないため、説明付きで拒否されます。 OSS ベースは PDF のみであり、リクエストごとに最大 1 つを選択できます。
  • PageIndex の組み込み MCP サーバーがなくなりました。 何も設定する必要はありません。ホストされたベースは新しい読み取りループを通じて動作し続けます。その MCP サーバーを自分でどこかに固定していた場合は、それを削除します。
  • Tika は何もインストールしません。 Apache Tika サーバーを実行し、そこに TIKA_SERVER_URL を指定します (デフォルトは http://localhost:9998)。 Python パッケージがないため、追加の parse-tika はありません。
  • LightRAG エクストラのフロアは、キーワード パススルーを含む最初のリリースである raganything>=1.2.5 に移動しました。古いインストールは壊れていません。サポートされていないノブは警告とともにドロップされます。しかし、3 つの新しいインストールを有効にするには、その下限が必要です。ノブは次の質問ではなく、次のビルドに適用されます。
  • 書籍ドリフト警告は一度ベースラインを再設定します。 フィンガープリントにはスキーム タグが含まれるようになり、式を変更すると、既存の書籍をすべて古いものとしてマークするのではなく、再ベースライン化されます。
  • Whisper は主要なナビゲーション エントリではありません。 これは 学習スペース → その他のプロジェクト の下にあり、ルームには独自の機能パッケージが必要です。ストック インストールにはページがありますが、その背後にカウンセリング機能はありません。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.5.14...v1.5.15

DeepTutor v1.5.15

Highlights

  • Self-hosted PageIndex and a reasoning retrieval loop — PageIndex OSS becomes a first-class KB type bound to the base's local library and driven by your configured LLM rather than a PageIndex API key; both hosted and OSS bases drop the old built-in MCP server for a small reading loop that walks the document tree structure-first and fetches only the pages it needs, preserving page-level citations. Breaking change: that MCP server is removed — remove it from anything you pinned. OSS bases are PDF-only, limited to one per request, and require an API-key or local-LLM profile (OAuth-only providers such as Codex, Copilot, and CodeBuddy are rejected). Otherwise drop-in: no re-index.

  • The question bank is finally writable — addEntryToCategory has existed since v1.3.6 but was never called from the frontend, so for eleven releases categories could be created but never filled; the quiz card now uses the shared category menu that does call it. The new question_bank tool is name-addressed — organize takes a category name and creates it if missing — and mounts only when the bank has entries, so tutor-initiated filing no longer silently degrades into a write_note notebook record (a misrouting the old Chinese hint even encouraged). The page gains search, batch selection, and an unfiled inbox; graded Mastery Path questions now carry their explanation and difficulty.

  • Third-party packages can register tools and capabilities — deeptutor.plugins was a dead path (imported under try/except but the module never existed); it's now real, joined by deeptutor.loop_capabilities for chat-loop capabilities. Broken entry points are skipped rather than fatal, built-ins win name collisions, and discovery is cached per process so plugin capabilities stay singletons. Why it matters: installed packages can extend DeepTutor without patching the tree — the runtime behind the community /whisper room also lets a capability publish its own declared extras on CAPABILITY_COMPLETE while capability, session_id, and turn_id remain unspoofable.

  • Apache Tika joins the parsers — a seventh engine selectable in Settings → Knowledge Base, remote-only: no Python package and no model download, just point TIKA_SERVER_URL (default http://localhost:9998) at a running Tika server. It converts a broad range of formats to Markdown, but it's an operational dependency — there's no parse-tika extra to install; you must run the server yourself.

  • LightRAG indexing knobs reach the UI (#877) — max_concurrent_files, llm_model_max_async, and entity_extract_max_gleaning move from hand-edited config into an Indexing divider, a distinct axis from the query knobs because they shape how a base is built: changes apply to the next build, not the next question. The UI introspects the installed RAG-Anything and drops unsupported knobs with a warning, so older installs keep running on library defaults — but the three new ones need raganything>=1.2.5, the first release carrying keyword passthrough.

  • Document-tree rebuild fixes (#866) — linked folders' subdirectories no longer collapse into raw/'s top level, same-named documents from different subtrees no longer silently drop one another (different bytes stage under a free sibling name; identical bytes still dedup), and uploads accept an optional destination folder. That last one was the real blocker: browser folder picks report paths relative to the chosen directory, so batches piled up at the root with the missing ancestor never in the payload; the picker now offers the base's existing folders once files are staged.

DeepTutor v1.5.15 Release Notes

Release Date: 2026.08.20

v1.5.14 put the document next to the conversation. This one is mostly about what sits behind it: PageIndex becomes something you can host yourself and retrieves by reasoning over a document tree, the question bank stops being a list you cannot file into, and third-party packages can now register their own tools and capabilities. Nearly all of it arrived as community pull requests. Drop-in — no migrations, nothing to re-index.

What's New

PageIndex you can host yourself, and retrieval that reasons

PageIndex OSS joins the engine list as its own knowledge-base type: the same interface as the hosted service, bound to the base's local library, driven by the LLM you already configured instead of a PageIndex API key.

Retrieval changed underneath both variants. A PageIndex base used to be read through a built-in MCP server; that path is gone, replaced by a small reading loop that walks the document tree — structure first, then only the pages it needs. Fewer moving parts, and the same page-level citations come back.

The question bank stops being write-only

addEntryToCategory shipped in v1.3.6 and was never called from the frontend, so for eleven releases a learner could create categories and never put anything in them. The quiz card's bespoke dropdown now uses the shared category menu that does call it.

The page is rebuilt around the three things a flat list could not do — search, batch selection, and an inbox for questions nobody has filed yet. Graded Mastery Path questions carry their explanation and difficulty in with them.

And the tutor can finally file for you. Asking it to group your wrong answers had no writable handle on the bank, so it reached for write_note and your request quietly became a notebook record — the Chinese write_note hint even listed 错题分析 as a reason to append. The new question_bank tool is name-addressed: organize takes a category name and creates it if missing, so filing is one call after one listing. It mounts only when the bank has entries.

Third-party tools and capabilities

Two entry-point groups let an installed package extend DeepTutor without touching the tree. deeptutor.plugins was already imported by the capability registry and /plugins/list behind a try/except — but the module never existed, so plugin discovery was a dead path; it is now real. deeptutor.loop_capabilities registers chat-loop capabilities alongside the built-ins, which win on name collisions. Broken entry points are skipped rather than fatal, and discovery is cached per process so plugin capabilities stay singletons.

Apache Tika parsing

A seventh document-parsing engine, selectable in Settings → Knowledge Base. Tika is remote-only: no Python package, no model download — it points at an Apache Tika server (TIKA_SERVER_URL) and converts a broad set of formats to Markdown.

LightRAG's indexing knobs, in the UI

max_concurrent_files, llm_model_max_async, and entity_extract_max_gleaning reached runtime settings and the API in #877 but had no inputs, so they were reachable only by hand-editing config. They now sit under their own Indexing divider — a different axis from the query knobs above, because they shape how a base is built, so a change applies to the next build rather than the next question. The wiring asks the installed RAG-Anything what it accepts and drops the rest with a warning, so an older install keeps running on library defaults instead of raising.

Rebuilding a document tree in a knowledge base

Three fixes finally close #866. A linked folder's subdirectories stopped collapsing into raw/'s top level; same-named documents from different subtrees stopped silently dropping one another (a clash between different bytes stages under a free sibling name, identical bytes still dedup); and uploads now take an optional destination folder.

That last one was the actual blocker. A browser folder pick reports each file's path relative to the directory you chose, so adding 应用开发/钉钉CLI/ one subtree at a time arrived as 钉钉CLI/... with no way to say where it belonged — every batch piled up at the root, and the missing ancestor was never in the payload to begin with. The picker now offers the base's existing folders once files are staged.

Book: a learning-capture inbox

Reading segments you select are kept per book with an explicit status lifecycle, so captures can be reviewed before they go anywhere. Separately, drift warnings got honest: stale-page detection is scoped to the KB documents that actually changed, and a warning will not clear while flagged pages are still awaiting recompilation.

Whisper — a community contribution

/whisper is a two-seat counselling-practice room contributed by @alanguan73: the tutor plays the visitor, you take the trainee seat, and a supervisor whispers coaching only the trainee sees, with an end-of-session debrief. It lives under Learning Space → More Projects and needs its own capability package installed — the surface ships, the counselling capability is not part of DeepTutor.

The generally useful half of that work is in the runtime: a capability can now publish a body and its own declared extras on CAPABILITY_COMPLETE, while capability, session_id, and turn_id stay unspoofable. Only the explicitly declared sub-dict goes on the event bus — turn metadata is a scratchpad holding live callables and your ask_user answers, and it was never a wire format.

Assorted

  • The model knows what day it is. Without the real date it resolved "today" from its training cutoff when composing web searches. The injected block is day-granular, so the system prompt stays byte-stable within a day and keeps prompt-cache hits.
  • Deleting a turn no longer blanks the session. Descendants pointed at deleted rows, the session lost its root, and the page rendered empty (#912). Deleted rows are spliced out of the parent-pointer tree, and already-corrupted sessions are recovered from their oldest orphan.
  • A stale CA bundle no longer breaks every LLM call. A leftover SSL_CERT_FILE / SSL_CERT_DIR — common after cloning a conda env without ca-certificates — made httpx raise mid-construction; broken paths are dropped so TLS falls back to the default bundle.
  • Thinking tags are filtered on non-SSE local streams too. That branch passed reasoning blocks straight through; both branches now share one incremental parser, so a tag split across chunks or left unclosed behaves the same either way.
  • Unhandled server errors return JSON instead of Starlette's plain-text 500, and the handler stays inside the middleware stack so the response still carries CORS headers.
  • Obsidian vaults survive real-world files — undecodable bytes and date-typed frontmatter are tolerated, and a vault that fails to open says why instead of failing opaquely.
  • A stuck session load ends in a retryable state rather than spinning, and token usage emitted as plain dicts by native adapters is recorded instead of lost.
  • Mastery reads stop inventing paths, end_loop is honored after an ask_user resume, and the codebuddy extra resolves again.
  • The frontend is linted in CI. ESLint now runs on web/ on every build.

The docs at deeptutor.info were refreshed alongside this release.

Upgrade Notes

pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest. No schema changes, no re-index, no migration.

  • PageIndex OSS needs an API-key or local LLM profile. An OAuth-only provider (OpenAI Codex, GitHub Copilot, CodeBuddy) cannot drive indexing and is rejected with an explanation. OSS bases are PDF-only, and at most one may be selected per request.
  • PageIndex's built-in MCP server is gone. Nothing to configure — hosted bases keep working through the new reading loop. If you had pinned that MCP server anywhere yourself, drop it.
  • Tika installs nothing. Run an Apache Tika server and point TIKA_SERVER_URL at it (default http://localhost:9998); there is no parse-tika extra because there is no Python package.
  • The LightRAG extra's floor moved to raganything>=1.2.5, the first release carrying the keyword passthrough. Older installs are not broken — unsupported knobs are dropped with a warning — but the three new ones need that floor to take effect. The knobs apply to the next build, not the next question.
  • Book drift warnings re-baseline once. Fingerprints now carry a scheme tag, so changing the formula re-baselines existing books instead of marking every one of them stale.
  • Whisper is not a primary nav entry. It sits under Learning Space → More Projects, and the room needs its own capability package — a stock install has the page but not the counselling capability behind it.
