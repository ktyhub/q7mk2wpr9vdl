DeepTutor v1.5.0

マイナー 公開日2026年7月4日 出典HKUDS/DeepTutor English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ディープチューターv1.5.0 #ディープチューター v1.5.0 Release Notes 発売日: 2026.07.04 v1.5.0 は v1.4 ライン全体を閉じて、次のラインを開きます。このノートでは、単一ポイントの差分ではなく、v1.4.0-beta から今日 (DeepTutor をエージェントネイティブでコミュニティ主導の個別指導プラットフォームに変えたリリース) までの全体を振り返ります。この数週間で、コミュニティは 36 件のマージされたプル リクエストを送信し、53 件の問題の解決に協力してくれました。ありがとう — このリリースは私たちのものであると同時に、あなたのものでもあります。

v1.4.0 以降のハイライト

  • Partners、TutorBot から生まれました。 TutorBot は Partners に成長しました。これは、15 以上のチャネル (Slack、Discord、Telegram、Feishu、WeCom、Zulip、Matrix (オプションの E2EE)) と、ライブ ストリーミング返信を備えたネイティブ Mattermost チャネルにわたる実稼働グレードの IM パイプラインです。 My Agents で自分のパートナー、またはローカル Claude Code / Codex に接続し、ライブチャット中に相談することができます。各パートナーは独自のプライベート メモリを持ち、会話を分岐、再開、再生できます。
  • 1 つのエージェント チャット エンジン。 チャットは、すべての OpenAI 互換クラウド プロバイダー (および SiliconFlow、MiniMax M3、Qwen、Gemini 2.5+) を呼び出すネイティブ ツール、スムーズなストリーミング、および正直なアクティビティ ヘッダーを使用して、単一のエージェント ループ上に再構築されました。
  • 本物のナレッジ センター。 複数の検索エンジン - LlamaIndex + FAISS ベクトル バックエンド、LightRAG (ローカルおよびスタンドアロン サーバー)、GraphRAG、PageIndex、およびリンクされた/Obsidian ナレッジ ベース - 1 つのコンソールの背後にある、プラグ可能なドキュメント解析レイヤー (テキストのみ、MinerU、Docling、 マークイットダウン、PyMuPDF4LLM)。大きな KB の取得が劇的に高速になりました。
  • ガイド付き学習とマスタリー パス。 タイプごとのマスタリー ゲート、/learning ダッシュボード、LaTeX でレンダリングされたクイズ、および質問バンクに入力される採点された質問を備えたチャット ループ上に再構築されています。
  • マルチユーザー、適切に実行されています。 実際のユーザーごとの分離、管理者権限、再設計された ユーザー管理 ページ、アバターを備えたセルフサービス プロフィール ページ、デフォルトで拒否される MCP ツール、およびユーザーごとのセッション分離。
  • 展開の強化。 Rootless-Podman / 読み取り専用 rootfs のサポート、単一ポートのリクエスト時プロキシ、環境設定可能なホスト バインディング、ポータブル スーパーバイザ設定。
  • セキュリティ ロックダウン。 Partner/TutorBot ツール サンドボックスがロックダウンされ、承認バイパス、パス トラバーサル、および RCE レポートのクラスターが修正されました (以下を参照)。
  • 3 層のメモリとより豊富なサーフェス。 パートナーの会話が組み込まれたトップレベルのメモリ ワークベンチ (L1/L2/L3) に加え、ディープ リサーチ、解決、視覚化 (アニメーターが統合)、および共同ライターの継続的な作業が行われます。 v1.5.0 では特に: デフォルトの LlamaIndex エンジンは、共有ドキュメント解析レイヤーを介して取り込みをルーティングするようになりました (そのため、選択した解析エンジンが尊重され、抽出された画像がマルチモーダル ノードとしてインデックス付けされます)。パートナー ID とソウル ID は ASCII/URL セーフであるため、非ラテン名にもアクセス可能で、オプションの graphrag / rag-lightrag エクストラは Python 3.14+ にクリーンにインストールされます (問題#606、および以下の修正)。

アップグレードに関する注意事項

v1.4.x: pip install -U deeptutor からのドロップイン。 Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。移行なし – 既存の知識ベース、パートナー、ソウル、マスタリー パスはそのまま機能し続けます。知っておくべき 2 つのこと:

  • LlamaIndex の再インデックス作成は、古いテキストのみのパスではなく、設定 → ドキュメント解析 で選択したエンジンを通じて抽出されるようになりました。既存のインデックスは変更されません。インデックスの再作成のみが新しいエンジンを選択します。ドキュメントが抽出されない場合は、アクティブなエンジンがその形式をサポートしていることを確認してください (以前の動作のためにテキストのみのままにしておきます)。
  • 非ラテン語のパートナー/ソウル ID は、新しく作成されたエンティティに対してのみ変更されます。ディスク上に既に存在するものは現在の ID を保持します。 ＃＃ ありがとう DeepTutor v1.5.0 は、成長を続けるコミュニティの作品です。問題をオープンしたり、レポートを提出したり、プル リクエストを送信したりしたすべての人に、特にこのサイクルのコントリビューターに感謝します: @wedone、@truffle-dev、@skinred78、@thelooter、@arlenwoox、@kagura-agent、@lezhimiffyliu、@washi4、@xiongjnu、@alvinets、@thakrarsagar、@octo-patch、@IliaAvdeev、 @enihcam、@emmett001、@Hinotoi-agent、@TyrionH-is-coding、@ZhouJ-sh、@VectorPeak、および @spring618。 deeptutor.info でドキュメントをお読みください。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.4.0-beta...v1.5.0

DeepTutor v1.5.0

Highlights

  • Partners become an integration platform — TutorBot evolves into a production IM pipeline spanning 15+ channels, including native Mattermost support (#590), with streaming replies, private per-Partner memory, and branching/resumable conversations. Developers can also connect local Claude Code/Codex agents and build multi-turn TutorBot integrations through the new HTTP API (#511).

  • Native tool calling reaches more providers — The unified chat engine supports reasoning models on OpenAI-compatible endpoints (#528), SiliconFlow (#584), and Qwen, while unblocking Gemini 2.5+ (#490) and defaulting MiniMax to M3 (#543). This reduces reliance on emulated tool calls; smoke-test tool execution when switching providers or models.

  • Knowledge ingestion becomes pluggable and multimodal — FAISS, LightRAG, GraphRAG, PageIndex, and linked/Obsidian knowledge bases share one console and parser layer, including MinerU, Docling, markitdown, and PyMuPDF4LLM. On re-indexing, LlamaIndex now honors Settings → Document Parsing and indexes extracted images; existing indexes remain untouched, so verify parser/format support or retain text-only for previous behavior. Chunking fixes also prevent Document nodes from bypassing the pipeline (#509) and preserve configured zero overlap (#602).

  • Multi-user security is substantially hardened — Fixes close cross-session regeneration and user-isolation bypasses (#515, #596), cross-bot file-management access (#516), path traversal and shell-tool RCE (#517, #518), and WebSocket command injection (#506, #507). Authentication now propagates user context asynchronously (#485), and MCP tools are deny-by-default (#579), so administrators must explicitly grant required tools after upgrading.

  • Deployment supports hardened containers — Rootless Podman with a read-only rootfs (#577), portable supervisord configuration (#593), and environment-configurable backend/frontend host binding (#586) simplify nonstandard and rootless deployments. The optional graphrag and rag-lightrag extras also install cleanly on Python 3.14+, including the uv installation fix (#605).

  • Breaking changes — None; v1.4.x upgrades in place without migrations.

DeepTutor v1.5.0 Release Notes

Release Date: 2026.07.04

v1.5.0 closes out the entire v1.4 line and opens the next. Rather than a single-point delta, this note looks back across the whole arc from v1.4.0-beta to today — the release that turned DeepTutor into an agent-native, community-driven tutoring platform. Over these weeks the community sent 36 merged pull requests and helped us resolve 53 issues. Thank you — this release is as much yours as ours.

Highlights since v1.4.0

  • Partners, born from TutorBot. TutorBot grew into Partners: a production-grade IM pipeline across 15+ channels — Slack, Discord, Telegram, Feishu, WeCom, Zulip, Matrix (with optional E2EE), and a native Mattermost channel — with live streaming replies. You can connect your own Partners, or your local Claude Code / Codex, under My Agents and consult them live mid-chat; each Partner carries its own private memory and its conversations can branch, resume, and replay.
  • One agentic chat engine. Chat was rebuilt on a single agent loop with native tool calling on every OpenAI-compatible cloud provider (and SiliconFlow, MiniMax M3, Qwen, Gemini 2.5+), smooth streaming, and an honest activity header.
  • A real Knowledge Center. Multiple retrieval engines — LlamaIndex + a FAISS vector backend, LightRAG (local and standalone-server), GraphRAG, PageIndex, and linked / Obsidian knowledge bases — behind one console, on a pluggable document-parse layer (text-only, MinerU, Docling, markitdown, PyMuPDF4LLM). Large-KB retrieval got dramatically faster.
  • Guided Learning & Mastery Path. Rebuilt on the chat loop with a per-type mastery gate, a /learning dashboard, LaTeX-rendered quizzes, and graded questions that flow into your Question Bank.
  • Multi-user, done properly. Real per-user isolation, admin grants, a redesigned User Management page, a self-service Profile page with avatars, deny-by-default MCP tools, and per-user session isolation.
  • Deployment hardening. Rootless-Podman / read-only-rootfs support, a single-port request-time proxy, env-configurable host binding, and a portable supervisord config.
  • Security lockdown. The Partner/TutorBot tool sandbox was locked down and a cluster of authorization-bypass, path-traversal, and RCE reports were fixed (see below).
  • Three-layer Memory & richer surfaces. A top-level Memory workbench (L1/L2/L3) with Partner conversations bridged in, plus continued work on Deep Research, Solve, Visualize (Animator merged in), and Co-Writer.

In v1.5.0 specifically: the default LlamaIndex engine now routes ingestion through the shared document-parse layer (so it honors your chosen parsing engine and indexes extracted images as multimodal nodes), Partner and Soul ids are ASCII/URL-safe so non-Latin names stay reachable, and the optional graphrag / rag-lightrag extras install cleanly on Python 3.14+ (issues #606, and the fixes below).

Upgrade Notes

Drop-in from any v1.4.x: pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest. No migrations — existing knowledge bases, partners, souls, and mastery paths keep working as-is. Two things to know:

  • LlamaIndex re-indexing now extracts through the engine you pick in Settings → Document Parsing, not the old text-only path. Existing indexes are untouched; only a re-index picks up the new engine. If a document doesn't extract, confirm the active engine supports that format (keep it on text-only for the previous behavior).
  • Non-Latin partner/soul ids only change for newly created entities — anything already on disk keeps its current id.
