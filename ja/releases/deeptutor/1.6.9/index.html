#ディープチューターv1.6.9

ディープチューター v1.6.9 Release Notes

発売日: 2026.09.21 v1.6.8 に基づいて構築された v1.6.9 は、フォルダーベースの学習ワークスペース、毎日の練習ループ、再設計された設定、およびよりクリアなストリーミング会話を提供します。ラーニング サーフェスは、古いリンクのリダイレクトを使用して /learning/ の下に移動します。会話の削除は永久的な削除を意味し、保持したい会話にはアーカイブが利用できるようになりました。

新機能

学習データ用のワークスペース

会話、書籍、マスタリー パス、読書、またはセッションの視聴を開始するときに、ワークスペースを選択します。カスタム ワークスペースは、学習データを .deeptutor/data/ に保持し、生成されたファイルを outputs/ に保持します。設定、認証情報、メモリはアカウント全体で共有されたままになります。 [設定] → [ワークスペース] で、ワークスペースとそのスキル、MCP サービス、ナレッジ ベースを管理します。パートナーはプライベート リソースを保持することも、ワークスペースへのリンクを維持することもできます。 ワークスペース を参照してください。

プレビューとリカバリを備えたデータ移行

[設定] → [データ移行] では、ワークスペース間でデータを移動する前に、関連するファイル、セッション、依存関係をプレビューします。転送では、ソースをクリアする前にコピーされたデータを検証し、競合する宛先データを拒否し、完了後にリカバリ スナップショットを保持します。中断された操作は、最近の操作から再開またはロールバックできます。

既存の問題バンクを練習する

パーソナライズされた学習→実践 では、/space/questions ですでに利用可能な質問に、毎日の復習、間違い追跡、および統計が追加されます。選択肢と正誤問題はサーバー側で採点されます。穴埋めと短答は自己評価を使用します。 .xlsx、.csv、.tsv、または .json ファイルをインポートします (インポートごとに最大 500 の質問)。マスターした質問はレビューのスケジュールを一時停止します。後で不正解になると再開されます。

専用ページでの設定

設定には、グループ化されたナビゲーションと、プロバイダー、言語モデル、タスク モデル、音声、マルチモーダル生成、使用状況、データ移行、およびアーカイブされたチャット用の個別のページが追加されました。再利用可能なプロバイダーの資格情報は、検出プローブと接続プローブとともにモデルの上に配置されます。モデルの編集は、適用されるまでステージングされたままになります。 OpenAI Codex のサインインは プロバイダー の下にあります。ランタイム診断は ランタイム ステータス の下にあります。

仕事の順序を示す会話

ストリーミング テキストは、導入されるツール呼び出しとともに残ります。答えが到着すると、ワークアウトは再実行可能なアクティビティ ヘッダーに折りたたまれます。質問カードは交換の一部として残り、スキップされた質問にはスキップされた状態が表示されます。コンポーザーは、前のターンのリソースを 1 click 再利用して、モード、エージェント、モデル、およびリソースを公開します。

マスタリーとレビューの改善

マスタリー評価では、クイズの正確さをコンセプトやデザインの評価ゲートから区別し、目標を達成することができないクイズの繰り返しを回避します。スタディ マップはターンが終了すると更新され、ドラフトは開始ターンの前にバインドされます。 Mastery、Book、Reading からのフォーカスチェックの試みは永続的なレビュー記録を共有します。再試行では、現在の試行の結果が使用されます。パートナーによって記録された不正解も質問バンクに届きます。

より信頼性の高い数学レンダリング

数学的正規化では、実際のコードと通常の通貨金額を維持しながら、コード スパンに埋め込まれた代替区切り文字と数式を処理します。あいまいなドル記号は、散文を飲み込むのではなく、表示されたままになります。

使用法、音声、モデルの選択

回答フッターには、ターンまたはセッション トークン、キャッシュの使用量および期間が表示されます。会話が削除された後も、プロンプト、応答、資格情報を保持することなく、耐久性のあるアカウントごとの使用状況台帳を利用できます。音声は、合成と転写のために Volcengine を介して Doubao Speech を追加します。ナレッジベースは独自の埋め込みモデルをバインドでき、接続されたエージェントはリモートの Herme ゲートウェイをサポートします。

信頼性に関する修正

読み取り拡張機能は独自のイベント ループを使用し、キャンセル可能なタイムアウト後の再試行をサポートします。空の LlamaIndex ナレッジ ベースは、最初のアップロードを受け入れます。テレグラム スレッド ルーティングは再起動後も存続し、埋め込みリクエストは日付形式の Retry-After ヘッダーを尊重し、ドキュメント クロールはロボット ルールとホストごとのペーシングを尊重します。チャットの継続時間は送信から完了までをカバーし、保存されたセッション モードはリロード後も存続します。初期の JavaScript は、重複排除された英語翻訳と遅延アニメーション機能によりサイズが小さくなりました。

アップグレードに関する注意事項

pip install -U deeptutor を実行します。 Docker ユーザーは ghcr.io/hkuds/deeptutor:latest を引きます。

  • 削除動作を確認してください。 削除では、会話、その講師スレッド、および関連する添付ファイルが完全に削除されます。アーカイブを使用すると、回復可能な状態を保ちながら会話を非表示にできます。従来のごみ箱会話は、セッション メタデータのアップグレード中にアーカイブされた会話に変換されます。 [設定] → [アーカイブされたチャット] から復元してください。
  • カスタム ワークスペースはオプトインです。 既存の学習データは、明示的に移動するまで、履歴の保存場所に保持されます。ワークスペースのメタデータとレガシーのアーカイブ状態レコードは自動的にアップグレードされます。設定、認証情報、メモリはアカウント レベルで共有されたままになります。
  • 学習 URL は移動されました。 /books/…、/mastery/…、/reading/…、/watching/… は同等の /learning/… にリダイレクトされます。 /settingsは引き続きご利用いただけます。
  • 移行スナップショットはディスク領域を使用します。 データを移動する前にプレビューを読み取り、コピーと回復スナップショット用の領域を確保し、影響を受けるディレクトリへの外部書き込みを一時停止します。既存のターゲット データまたは競合する ID により転送がブロックされます。
  • アーカイブされたワークスペースまたは使用できないワークスペースは、新しい書き込みを拒否します。 続行する前に、ワークスペースを復元または再接続してください。利用できないバインドされたワークスペースを持つパートナーは、他の場所にサイレントに切り替えるのではなく、エラーを報告します。 フル Changelog: https://github.com/HKUDS/DeepTutor/compare/v1.6.8...v1.6.9

DeepTutor v1.6.9

Highlights

  • Opt-in workspace isolation — Learning data and generated outputs can be scoped to custom workspaces, but Settings, credentials, and Memory remain account-wide. Existing data stays in its historical location until explicitly moved. Archived or unavailable workspaces reject new writes rather than silently falling back, so restore or reconnect them before resuming work.

  • Workspace migration is validated and recoverable — Settings → Data Migration previews affected files, sessions, and dependencies; refuses destination conflicts; and verifies copies before clearing the source. Interrupted transfers can be resumed or rolled back, while completed transfers retain recovery snapshots. Budget disk space for both copies and snapshots, and pause external writes during migration.

  • Breaking change: Delete is now permanent — Deleting a conversation removes its tutor threads and associated attachments, not merely the visible conversation. Use Archive for recoverable removal. Legacy recycle-bin conversations are converted to archives during the metadata upgrade and can be restored under Settings → Archived chats.

  • Learning routes moved under /learning/ — /books/…, /mastery/…, /reading/…, and /watching/… redirect to their new equivalents. Update bookmarks and integrations that depend on exact paths; /settings remains unchanged.

  • Daily practice adds mixed grading models — Existing /space/questions content gains review scheduling, mistake tracking, and statistics. Choice and true/false questions are graded server-side, while fill-in and short answers require self-assessment, so those results are not objectively scored. Imports accept .xlsx, .csv, .tsv, or .json with up to 500 questions; mastered questions pause until a later incorrect answer resumes review.

  • Streaming and configuration behavior changed — Tool calls remain beside the text they introduce, then collapse into a reopenable activity header after the answer arrives; UI tests and custom renderers should account for this. In Settings, provider credentials are reusable across models, but model edits remain staged until explicitly applied. OpenAI Codex sign-in moved under Providers, and diagnostics moved to Runtime status.

DeepTutor v1.6.9 Release Notes

Release Date: 2026.09.21

Building on v1.6.8, v1.6.9 brings folder-based learning workspaces, a daily practice loop, redesigned Settings, and clearer streaming conversations. Learning surfaces move under /learning/ with redirects for old links; conversation deletion now means permanent deletion, with archiving available for conversations you want to keep.

What's New

Workspaces for your learning data

Choose a workspace when starting a conversation, book, mastery path, reading or watching session. Custom workspaces keep learning data in .deeptutor/data/ and generated files in outputs/; settings, credentials and Memory remain shared across your account. Manage workspaces and their Skills, MCP services and knowledge bases in Settings → Workspaces. Partners can keep private resources or stay linked to a workspace. See workspaces.

Data migration with previews and recovery

Settings → Data Migration previews the files, sessions and dependencies involved before moving data between workspaces. Transfers verify copied data before clearing the source, refuse conflicting destination data, and retain recovery snapshots after completion. An interrupted operation can be resumed or rolled back from Recent operations.

Practice over your existing question bank

Personalized Learning → Practice adds daily review, mistake tracking and statistics to the questions already available at /space/questions. Choice and true/false questions are graded server-side; fill-in and short answers use self-assessment. Import .xlsx, .csv, .tsv or .json files, up to 500 questions per import. Mastered questions pause review scheduling; a later incorrect answer resumes it.

Settings with dedicated pages

Settings now has grouped navigation and separate pages for Providers, Language models, Task models, Voice, Multimodal generation, Usage, Data migration and Archived chats. Reusable provider credentials sit above their models, with discovery and connection probes. Model edits remain staged until applied. OpenAI Codex sign-in is under Providers; runtime diagnostics are under Runtime status.

Conversations that show the order of work

Streaming text stays alongside the tool calls it introduces. Once an answer arrives, the working-out folds into a reopenable activity header. Question cards remain part of the exchange, and skipped questions show their skipped state. The composer exposes mode, agent, model and resources, with one-click reuse of a previous turn's resources.

Mastery and review improvements

Mastery grading now distinguishes quiz accuracy from concept and design assessment gates, avoiding repeated quizzes that could never advance an objective. The study map refreshes when a turn ends, and drafts bind before their opening turn. Focus-Check attempts from Mastery, Book and Reading share persistent review records; retries use the current attempt's result. Incorrect answers recorded by Partners also reach the question bank.

More reliable maths rendering

Math normalization handles alternative delimiters and formulas embedded in code spans while preserving actual code and ordinary currency amounts. Ambiguous dollar signs stay visible instead of swallowing prose.

Usage, speech and model choices

Answer footers show turn or session tokens, cache usage and duration. A durable per-account usage ledger remains available after a conversation is deleted, without retaining prompts, responses or credentials. Voice adds Doubao Speech through Volcengine for synthesis and transcription. Knowledge bases can bind their own embedding model, and connected agents support a remote Hermes gateway.

Reliability fixes

Reading extensions use their own event loop and support retry after a cancellable timeout. Empty LlamaIndex knowledge bases accept their first upload. Telegram thread routing survives restarts, embedding requests honor date-form Retry-After headers, and documentation crawls respect robots rules and per-host pacing. Chat duration covers submission through completion, and stored session modes survive reloads. Initial JavaScript is smaller through deduplicated English translations and deferred animation features.

Upgrade Notes

Run pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest.

  • Review deletion behavior. Delete permanently removes a conversation, its tutor threads and associated attachments. Use Archive to hide a conversation while keeping it recoverable. Legacy recycle-bin conversations are converted to archived conversations during the session metadata upgrade; restore them through Settings → Archived chats.
  • Custom workspaces are opt-in. Existing learning data keeps its historical storage locations until you explicitly move it. Workspace metadata and legacy archived-state records are upgraded automatically. Settings, credentials and Memory remain shared at the account level.
  • Learning URLs moved. /books/…, /mastery/…, /reading/… and /watching/… redirect to their /learning/… equivalents. /settings remains available.
  • Migration snapshots use disk space. Read the preview before moving data, allow space for copies and recovery snapshots, and pause external writes to affected directories. Existing target data or conflicting IDs block a transfer.
  • Archived or unavailable workspaces refuse new writes. Restore or reconnect the workspace before continuing. A Partner with an unavailable bound workspace reports the error instead of silently switching elsewhere.
