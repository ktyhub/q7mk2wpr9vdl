  • プライベート チャット メッセージをバインドされた管理対象エージェント セッションにルーティングし、認証された WebSocket 経由で応答を返す実験的な WeCom 管理対象チャネル アダプターを追加します。 (#17441) by @wenshao
  • 呼び出し元が提供するスキルまたは明示的なピン リストなしでワークスペース セッションが作成される場合、オプションのカタログからデフォルトのワークスペース スキルをインストールしてピン留めします。 (#17703) by @doudouOUC
  • Web シェルのサイドバー セッション行にステータス色付きの目標マーカーを追加します。これにより、アクティブな目標を持つセッションが認識可能になり、マーカーからセッションを開くことができます。 (#17515) by @wenshao
  • 繁体字中国語の UI ロケールを Web シェルおよび VS Code コンパニオン Chrome に追加します。zh-TW、zh-HK、zh-MO、および zh-Hant は繁體中文 [zh-TW] に解決されます。 (#17421) by @callmeYe
  • WeCom、DingTalk、および GitHub 管理対象アダプターからの短縮された受信メッセージを文字数とバイトの制限内に保ちながら、切り捨て通知でマークします。 (#17726) by @wenshao
  • Hosted Harness は、アクティブな作業が終了した後、アイドル状態の管理対象エージェント セッションを一時停止し、次のリクエストでコールド オープンするようになりました。 (#17690) by @doudouOUC
  • 残りのターンで容量エラーによって消耗したモデルをスキップし、次のターンで再プローブするオプトイン設定を追加します。 (#17377) by @wenshao
  • DingTalk 永続台帳を登録 ID にバインドするため、同じロボット アプリの別の登録の下で保留中のメッセージが再生されなくなります。 (#17742) by @wenshao
  • 受信メッセージを実行中のターンに配信する注入チャネルのdispatchModeを追加し、エージェントが次のツールとバッチの境界でメッセージを読み取ることができるようにします。 (#15634) by @Eric-GoodBoy-Tech
  • セッション間でアーティファクトを参照、プレビュー、ダウンロードできるように、ワークスペース アーティファクト ライブラリを管理対象エージェント Web UI に追加します。 (#17728) by @wenshao
  • Ink はデフォルトのままで、キーボード ナビゲーション、安定した完了応答アナウンス、セマンティック履歴を備えた CLI のオプトイン ネイティブ スクリーン リーダー プレゼンテーションを追加します。 (#17500) by @chiga0
  • Artifacts (N) ヘッダー エントリを右側のパネルに移動し、cli をクリックすると、専用のセッション スコープの Artifacts リスト タブが切り替わります。 (#17689) by @wenshao
  • デーモン チャット インテント ライフサイクル コアを追加することで、送信、キャンセル、承認、および質問の状態がトランスポート応答のみではなく信頼できる証拠に基づいて解決されるようにします。 (#17709) by @wenshao
  • CI が失敗した場合、競合が発生した場合、またはヘッドが変更された場合に、パブリックに投稿せずに、監視されているプル リクエストにバインドされた管理セッションをプライベート プロンプトでウェイクアップします。 (#17665) by @wenshao
  • 一時停止後もアイドル状態の MCP 接続を維持し、再開されたセッションで再利用できるようにするためのオプトイン設定 qwen.managed-agent.runtime-broker.mcp-parking.enabled を追加します。 (#17749) by @doudouOUC
  • ワークフローで宣言されたメタフェーズを開始前に「未開始」レーンとして表示し、スクリプトがそのフェーズに到達したときに各レーンを置き換えます。 (#17782) by @qqqys
  • コントロール プレーン イベントを発行するための外部シェル ワーカーのマネージド エージェント サポートを追加します。 (#17478) by @yiliang114
  • エージェントがローカル ファイル、画像、ビデオ、音声メッセージを送信するためのツールを公開する、デフォルトではオフの QQ ボット オプションを追加します。 (#15450) by @Eric-GoodBoy-Tech
  • 個人チャット、グループメンション、スレッド分離、createTeamsIngress ホスト Webhook セットアップを備えた Microsoft Teams チャネル拡張機能を追加します。 (#15620) by @XIQIXIQIXIQI

  • DingTalk マネージド エージェントの返信は、プレーン テキスト メッセージではなく、より多くの返信セグメントが到着すると更新される単一の編集可能なネイティブ カードとしてレンダリングされるようになりました。 (#17748) by @wenshao
  • feat(core): 切り捨てが書き込みを拒否した場合の出力バジェットに名前を付けます (#16632) by @xxwtiancai
  • feat(web-shell): ホストがコンポーザー グローを無効にできるようにします (#17814) by @callmeYe

  • 偉業(cli): ヘッドレス モードでバックグラウンド ワークフローを実行 (#17809) by @qqqys
  • 履歴、コピー、検索、分岐の元のテキストを保持しながら、Mod で書き換えられたアシスタントの応答行を Web シェルに表示します。 (#17718) by @qqqys
  • --timeout オプションを /model --vision に追加して、visionBridgeTimeoutMs を設定し、秒またはミリ秒スタイルの値を受け入れてすぐに適用します。 (#17830) by @qqqys
  • デーモン チャット コントローラーを追加することで、受信デーモン イベントが安定する前に正しい試行にバインドされ、遅延イベントが終了したチャット試行に影響を与えるのを防ぎます。 (#17794) by @wenshao
  • 管理対象 GitHub アダプター台帳をその登録 ID にバインドし、保留中のコメントが別の登録で再生されないようにします。 (#17775) by @wenshao

  • すでに受け入れられている再送信された管理対象エージェントのターンを回復し、パークされた実行の準備ができたら、停止したままにするのではなく継続を駆動します。 (#17680) by @doudouOUC
  • マネージド Web シェルでは、リクエスト、セッション、および回復エラーが通常の会話メッセージとして表示されるようになり、メッセージ リンクまたは Ctrl+Y による再試行と、個別の回復パネルの数が減りました。 (#17557) by @yiliang114
  • 複数のチャンクで送信される管理対象 DingTalk 応答が切り捨てられないようにし、集計送信制限が適用されない理由を文書化します。 (#17529) by @wenshao
  • コールド ワークツリーの復元は、所有権の検証と作業ディレクトリの復元が完了するまで自動作業を遅らせ、復元のブロックを防ぎ、保留中の質問を保持します。 (#17654) by @doudouOUC
  • Web シェルは、/send レコードの下の余分なギャップを削除し、ターンが折りたたまれているときに各応答をクロスセッション メッセージ カードの横に表示したままにします。 (#17686) by @qqqys
  • /verify-pr --watch は準備前に監視ラウンドを登録するようになり、--start は --artifact-dir を必要としなくなり、既存の呼び出し元を中断することなくライブ性が向上します。 (#17550) by @wenshao
  • 長時間実行プロセスは、成功または失敗した書き込みが安定した後にアイドル状態の JSONL 追加ロックを解放するようになり、ロックの蓄積が減少します。 (#17577) by @Afloat16
  • Web シェル メモリ パネルには、パネルを閉じずにファイル リストを再ロードし、選択したファイルを再試行し、読み取りが成功したときに編集を復元する更新コントロールが追加されました。 (#17108) by @Afloat16
  • SDK ヘッダーのマージでは、HTTP ヘッダー名の大文字と小文字が区別されないように処理されるようになり、呼び出し元のヘッダーは重複した値を作成するのではなく、トランスポートのデフォルトをオーバーライドします。 (#17579) by @Afloat16
  • CLI 出口クリーンアップでは、ハンドラーの登録解除時に保留中のクリーンアップ作業が保存されるようになり、シャットダウン中にクリーンアップがスキップされたり繰り返されたりすることがなくなりました。 (#17572) by @Afloat16
  • ストリームがキャンセルされた後、バッファリングされた SSE イベントの配信を停止し、古いセッションの更新を防ぎます。 (#17569) by @Afloat16
  • ハートビート登録中に削除または置換されたセッションのハートビートをキャンセルし、タイマーの漏洩を防ぎます。 (#17117) by @Afloat16
  • カスタム コマンドは、プロンプト展開中に引数テキストをそのまま保持するようになりました。そのため、$$ と $& は再解釈されません。 (#17367) by @Afloat16
  • 1 つの待機中の制御呼び出しがキャンセルされたときに、Python SDK 初期化の実行を維持し、他の呼び出しとプロンプト入力を続行できるようにします。 (#17499) by @Afloat16
  • バックグラウンド作業が実行されている場合、Web シェルのサイドバー セッション行にオレンジ色のビジー マーカーが表示され、行のアクションがその状態に合わせられます。 (#17676) by @wenshao

  • ACP Java SDK は、パス区切り文字ではなく通常の改行で結合された選択されたファイル行を返すようになり、破損したファイル コンテンツがエージェントに表示されるのを防ぎます。 (#17688) by @Afloat16

  • SDK は、1 つのチャンクで完了した場合でも、ディスパッチ前に特大のピア フレームを拒否し、有効な個別のフレームを保持しながらバッチのオーバーフローを停止します。 (#17576) by @Afloat16

  • Composer イメージ バッチをキャンセルすると、開始されていないキューに入れられたイメージの読み取りが停止されるようになり、キャンセル後の不要な読み取りと Base64 割り当てが防止されます。 (#17705) by @cactuser-Lu
  • 実行時の動作を変更せずに、管理対象エージェントのクラスサイズとファサード人口のゲート チェックを復元し、メインに残された決定論的なゲートの障害を修正します。 (#17753) by @doudouOUC
  • SDK は、実際の子の終了を待機し、意図的なシャットダウンを分類し、障害を保存し、保留中のクエリおよび MCP リクエストを拒否する前にトランスポートを破棄するようになりました。 (#17580) by @Afloat16
  • QQ ボットのダイレクト チャットを修正し、qqbot.ugcimg.cn からの音声添付ファイルが空のターンではなくオーディオとしてダウンロードおよび配信されるようにしました。 (#15339) by @mvanhorn
  • ハーネスが入力添付ファイルをサポートしている場合、バインドされていないアクティブなセッションの管理対象コンポーザー添付ファイル エントリを表示します。 (#17722) by @wenshao
  • 幅のしきい値付近でコンポーザー ツールバーを安定させ、チャット幅の切り替えが表示されたときに承認ラベルとモデル ラベルが移動したり消えたりすることがなくなりました。 (#17729) by @callmeYe
