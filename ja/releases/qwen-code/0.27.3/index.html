qwen コード v0.27.3

ハイライト

以下の完全な変更リストを参照してください。

重大な変更

既知の重大な変更はありません。

完全な変更リスト

機能

  • 未完了のバックグラウンド ワークフロー、シェル、モニター、ローカル エージェント用のチップを Web シェル コンポーザーの上に追加し、ステータス バーのタスク ピルを置き換えました。 (#16813) by @qqqys
  • チャネル UI 言語が中国語で、他の言語は英語のままである場合に、PR バインド セッションでの GitHub チャネル イベント プロンプトの中国語ローカライズを追加しました。 (#16773) by @wenshao
  • マネージド MCP は、ライブ選択を最大 32 個までカウントし、削除されたエントリを回復用に保持し、16 個の有効な制限を維持し、保持されるスナップショットの上限を 96 個に制限するようになりました。 (#15161) by @yiliang114
  • 組み込みアプリケーションが外部ソースから正確なスキルまたは拡張機能のリビジョンをインポートし、コンパイルされたアーカイブをプライベート ストレージに保存できるようにするマネージド エージェント SPI を追加しました。 (#16882) by @doudouOUC
  • Mod が、保存されたメッセージ テキストと /copy 出力を保持しながら、OpenTUI ターミナルに表示される返信行を ui.render 経由で書き換えられるようにします。 (#16873) by @qqqys
  • スリム リストからプル リクエストの状態を記録し、そのキーをウォッチに渡すことで、閉じられたプル リクエストがビューのローテーションを正しく離れることができます。 (#16847) by @wenshao
  • 構成された DingTalk カスタム グループ ロボットに通知と成功したタスクの結果をマークダウンとして投稿する、送信専用の dingtalk-webhook チャネルを追加します。 (#16802) by @jkxiao
  • サイドバーのセッション リストは、click ごとに 10 セッションを展開し、すべてを一度に表示するのではなく、残りの数を示すラベルが付きます。 (#16830) by @wenshao
  • 管理セッションは、特大のリソースと圧縮された閉じられたジャーナルをオブジェクト ストレージに保存し、リカバリと通常の読み取りを維持するようになりました。 (#16868) by @doudouOUC
  • 現在の動作を変更せずに、統合エージェント ループの内部イベント バス プリミティブを追加します。 (#16935) by @wenshao
  • Web シェルに DingTalk Webhook 構成を追加し、スケジュールされたタスクが保存されたチャネルの宛先を選択できるようにします。 (#16804) by @jkxiao
  • ネイティブの検索、選択、キーボードの動作を維持しながら、埋め込みホストがヘッダーとモデルごとのコンテンツを Composer モデル ピッカーに追加できるようにします。 (#16933) by @callmeYe
  • 監視可能な動作を変更せずにイベント バス ハンドラーで共有エージェント ループを実行するためのオプトイン AgentLoopOptions.useEventBus を追加します。 (#16938) by @wenshao
  • サンドボックス化された /verify フローは、検証前に必要な PR とベース履歴を含めるためにチェックアウトを強化し、強制プッシュやコミットの欠落の処理を改善しました。 (#16781) by @wenshao
  • feat(cli): @wenshao による実験設定 (#16994) の背後でヘッドレスでイベント バス エージェント ループを有効にします
  • Experimental.unifiedAgentLoop が有効になっている場合、AgentCore モデルのラウンドは共有エージェント ループを通じて実行されるようになりました。 (#16880) by @qqqys
  • feat(ワークフロー): @qqqys による ACP セッションでのモデル要求のバックグラウンド実行を許可 (#16876)
  • feat(core): @qqqys による共有エージェント ループ (#17035) で AgentCore のツール バッチを実行します。
  • 偉業: 手動セッション PR バインディング (/pr コマンド + Web シェル ダイアログ) (#16877) by @wenshao
  • 管理対象エージェントのジャーナル リーダーは、ジャーナル パックから削除されたレコードを解決し、qwen.managed-agent.session-resources.deletion-enabled を有効にするようになりました。 (#17047) by @doudouOUC
  • 管理セッションは、セルフペースの /loop ウェイクアップをセッション ジャーナルに永続的に保存するようになり、再起動やテイクオーバーにも耐えられるようになりました。 (#16835) by @wenshao

バグ修正

  • 管理対象エージェント セッションを閉じると MCP 所有者が解放されるように修正され、閉じた後に MCP 設定が空になったり保持されたりすることがなくなりました。 (#16728) by @wenshao
  • ハーネス競合エラー コードの解析、ホスト コマンド出力の読み取り、および例外原因の報告時の管理対象エージェントの信頼性が向上しました。 (#16826) by @doudouOUC
  • Web シェル承認ピッカーがよりコンパクトになり、フル アクセス (yolo) が破壊的で高リスク モードとして視覚的にマークされます。 (#16874) by @callmeYe
  • CI 一時ランナーは、年齢のしきい値を超えても利用可能な状態を維持し、途中で破棄されるのではなく、遅く割り当てられたジョブを完了できるようになりました。 (#16871) by @yiliang114
  • Web シェル WeChat ログインの起動では、デーモンのより長い QR 作成タイムアウトが使用されるようになり、QR ミント作成に最大 30 秒かかる場合でもログインが中止されなくなります。 (#16838) by @wenshao
  • Docker または Podman サンドボックスでの CLI の起動は、サンドボックスのホーム ディレクトリを作成し、$HOME の欠落をクラッシュせずに許容するようになりました。 (#16878) by @yiliang114
  • Web シェルで管理されるモデルの変更は、読み取りの失敗後に正しく認識されるようになり、ピッカーがスタックしたままになることがなくなり、重複した再送信が回避されます。 (#16869) by @yiliang114
  • TUI エージェント ループ パリティの承認待機で承認されたファイルの効果を検証し、チェックスタイルのインポート順序を復元することで CI エラーを修正し、パイプラインの信頼性を向上しました。 (#16881) by @wenshao
  • DejaVu フォント パッケージをインストールすることでフォーク PR ランナーでの CI キャプチャ テストを修正し、太字とプレーンのターミナル レンダリングが正しく異なるようにしました。 (#16864) by @qwen-code-dev-bot
  • 一時ランナー マネージャーがシャットダウン前に実行中のジョブを排出できるようにし、再起動中に中断されたジョブや残りのコンテナを削減します。 (#16892) by @yiliang114
  • シェルコマンドの説明と思考翻訳のポップオーバーを修正して、狭いデフォルトに戻るのではなく、意図した 480 ピクセルの幅を維持します。 (#16916) by @callmeYe
  • より大きなサイズ制限を正しく設定して凍結されたコミット本体を読み取ることで、凍結後に停止したプライベート CSI リタイアメントを修正しました。 (#16923) by @doudouOUC
  • 自動メモリが無効になっている間は手動ワークスペース メモリの削除を許可し、外部ツール ガード プロバイダーが接続されている場合は Direct ACP がそれを拒否します。 (#16913) by @callmeYe
  • シェルコマンドの承認の説明と権限の選択肢を 1 つの応答性の高いフッターに配置して、広い画面でも狭い画面でも承認カードが一貫して見えるようにします。 (#16914) by @callmeYe
  • サイドバーのセッションの並べ替えを、セッション アクション行の複数選択の隣に移動し、並べ替えオプションと保存された設定を変更しないようにします。 (#16776) by @deggs7
  • コンパニオン リリース中の macOS のメモリ不足障害を防ぐために、Web シェルの実稼働ビルド ヒープ制限を 4096MB に引き上げます。 (#16902) by @yiliang114
  • GitHub チャネルは、開始時だけでなく、レート制限の拒否後の実行中に、保存された応答をバックグラウンドで再試行するようになりました。 (#16839) by @wenshao
  • CLI チャネル ステータスは、qwen サーブ ワーカーによって保持されるルートをカウントするようになり、デーモン管理のチャネル会話の過少報告が修正されました。 (#16929) by @wenshao
  • アクティベーションプルーフフィールドが誤ってクランプされるのではなく、宣言されたサイズ制限に従うように、base64 の処理を修正しました。 (#16934) by @doudouOUC
  • マネージド モデルの選択は DAC フローに従い、検証後すぐに適用され、確認をブロックすることなくバックグラウンドで更新されます。 (#16890) by @yiliang114
  • CI プール ジョブは、チェックアウト前に古いパッケージ マネージャー キャッシュとワークスペース git 状態をクリアするようになり、以前の実行による失敗を防ぎます。 (#16939) by @yiliang114
  • 自動編集モードでは、ツールが一致する権限を呼び出します。ask ルールは自動的に承認されるのではなく、確認が必要になりました。 (#16932) by @qqqys
  • Web シェルは、リポジトリ専用チャネルとして GitLab をサポートするようになり、ネストされたプロジェクト パスを受け入れ、ダイレクト メッセージ コントロールを非表示にします。 (#16845) by @wenshao
  • 修正(管理対象エージェント): @wenshao による再送信 ID の競合を 409 にマップし、投影ワイヤー形状 (#16846) を固定します。
  • CSI リタイア サイズ制限を一元化し、base64 検証を強化することで、管理対象エージェントのリタイア コミットが一貫した制限内に収まるようにします。 (#16956) by @doudouOUC
  • 承認された増加後に CI ワークフロー サイズのベースラインを更新し、夜間のリリース スクリプト テストが失敗しなくなるようにしました。 (#16978) by @qwen-code-dev-bot
  • パックを公開せずにウォーターマークを進める可能性があるジャーナル パックの同時公開競合を防ぐために、ビルダー リースを追加しました。 (#16983) by @doudouOUC
  • ライブセッションのタイムラインをチャットエリアで垂直方向の中央に配置し、リクエストの確認が表示されているときにターンナビゲーションを揃えます。 (#16912) by @callmeYe
  • チャネル エディターが閉じるかページがアンロードされるときに保留中の QQ ログイン セッションをキャンセルし、古いログイン セッションが長引くのを防ぎます。 (#16841) by @wenshao
  • バックアップをアトミックに書き込み、アクセス許可を保持し、失敗時に一時ファイルをクリーンアップすることにより、ファイル履歴バックアップ キャプチャをクラッシュ セーフにします。 (#16926) by @wenshao
  • CLI のデタッチを修正し、構成スコープのフック所有者が途中で解放されないようにし、回復されたターンが存続するはずの所有者を無効にするのを防ぎます。 (#16594) by @wenshao
  • 各リクエストのモデルを選択した後にシステム プロンプトが解決されるようになり、オーバーライド、フォールバック、および非ストリーミング リクエストの正確性が向上しました。 (#17023) by @callmeYe
  • ENOENT をリークする代わりに明確な再試行不可能なエラーを使用して、読み取り不可能なマシン ID を持つホストを拒否するように CLI SSH ストレージ プローブを修正しました。 (#17034) by @yiliang114
  • セッション フッターの設定、テーマ、ステータス、および展開コントロールを維持しながら、冗長なナビゲーションを非表示にするために、Web シェルのホームのみの埋め込みを修正しました。 (#17027) by @chiga0
  • Zod 4.6.6 をバンドルするために使用するブラウザーを更新し、アドバイザリーの影響を受ける依存関係を削除しました。ロケーターの検証は同じままですが、エラー コードとメッセージ テキストは変更される可能性があります。 (#17022) by @yiliang114
  • Web シェルのようこそ画面の設定を修正し、Set current が clicked になった後、選択したモデルがすぐに現在のモデルとして表示されるようにしました。 (#16819) by @deggs7
  • git commit --amend を含むコマンドが AUTO モードでハードブロックされるのではなく、人間の承認を必要とするように権限の処理が変更されました。 (#16075) by @yiliang114
  • ci: ディスクフロア拒否を分類し、アンケートのチェックアウトをオフにしておく /tmp (#17011) by @yiliang114
  • 修正(管理対象エージェント): 名前変更リカバリ テストを修復し、@doudouOUC による #17006 レビュー ラウンド (#17043) に対処します。
  • fix(permissions): @yiliang114 による >| clobber リダイレクトの書き込み (#17042) を参照してください。

パフォーマンス

  • 管理対象エージェントの調整は、不要な配信レコードの読み取りをスキップし、セグメント プランの書き込みと読み取りをバッチ処理して、スイープのオーバーヘッドを削減します。 (#16865) by @wenshao

ドキュメント

  • ドキュメント(プロバイダー): OpenAI 互換プロバイダー (#16850) による Wiro AI のドキュメント (@EminBudak 作成)
  • スキル エンドポイントがワークスペースのスキル設定を名前で更新するというドキュメントを明確にしました。 (#16833) by @521Peter
  • README にリンク付きの Qwen コード 1.0 プレビュー セクションが追加され、以下に示すインストール コマンドがメイン バージョン用であることが明確になりました。 (#16872) by @0xvincent
  • 文章やコードを変更せずに Lint および静的ワークフローの障害を修正するために、リポジトリの固定された Prettier バージョンを使用してフォーマットされた README。 (#16887) by @yiliang114
  • WeChat チャネルのドキュメントを更新して、ボットが読み取る会話に名前を付け、メッセージを通知せずにドロップできる許可手順を説明しました。 (#16888) by @wenshao
  • ターミナルドレイン動作と一致するように応答損失設計ノートを更新し、セッションが解放されストレージ所有者が保持されない状態で転送前リリースが終了することを明確にしました。 (#16898) by @yiliang114
  • 未承認の最初のメッセージはペアリング コードの応答を受け取り、承認後には再生されないことを WeChat ドキュメントで明確にしました。 (#16930) by @wenshao
  • ドキュメントには、現在削除が有効になっているリーダー移行の前提条件のみがリストされ、WorkspaceCsiCheckpointSnapshotStore が削除されたことが記載されています。 (#16984) by @doudouOUC
  • 管理対象エージェント ゲートのドキュメントには、ゲートがまだ必須のチェックではない理由と、その合格率がどのように測定されるかが説明されています。 (#16955) by @yiliang114
  • 設計ドキュメントでは、イベント バス エージェント ループと統合エージェント ループがクロスリンクされ、統合ループのステータスが更新されるようになりました。 (#17014) by @wenshao
  • 更新されたブラウザー 開発ドキュメントを使用して、npm install の代わりに corepack pnpm install を使用します。 (#17019) by @qqqys
  • CLAUDE.md は AGENTS.md をインポートするようになり、セッション開始時にリポジトリ規約が自動的にロードされます。 (#17017) by @qqqys
  • ブラウザの更新 ドキュメントを使用して、バンドル サイズの違いを esbuild パス コメントに正しく帰属させます。 (#17041) by @yiliang114
  • ドキュメント(コア): イベントバス設計の古い PR ステータスとプレビュー ファイル数を修正 (#16952) by @wenshao

内部変更

  • ホストされたツールの出力パブリケーションを常に非同期にし、HTTP 202 保留状態を返し、同期アップロード モードではなくバックグラウンド検証に依存するようにしました。 (#16840) by @doudouOUC
  • Experimental.unifiedAgentLoop が有効になっている場合の OpenTUI ステアリング入力と再試行動作を検証する CLI テストを追加しました。 (#16820) by @qqqys
  • 運用動作を変更することなく、管理対象エージェントのチャネル記録のテストの忠実度を向上させます。 (#16843) by @wenshao
  • ホスト型ハーネスのメッセージ停止テストに、停止したメッセージ ターンに対するより長い解決バジェットを与え、不安定な障害を軽減することにより、CI の信頼性が向上しました。 (#16855) by @qwen-code-dev-bot
  • [折りたたみ] ボタンのルックアップを正確にすることで Web シェル ブラウザ テストを修正し、[すべてのワークスペースを折りたたむ] と一致しなくなりました。 (#16905) by @yiliang114
  • ビルド ルートを現在の CentOS Stream 10 イメージ ダイジェストに再固定することにより、夜間デスクトップ チェック RHEL 10 rpm ビルドを復元しました。 (#16897) by @yiliang114
  • アクティブ化されたモデルがワークスペースのデフォルトとして保持されない現在の動作に一致するように、サブスクリプションのアクティブ化テストを更新します。 (#16904) by @yiliang114
  • Composer コンテキストのモバイル ホバー チェックをニュートラル フォーカス状態から開始することで、Web シェル テストの安定性が向上しました。 (#16907) by @yiliang114
  • リタイアの証拠を影響を受けるセッションに限定することで、管理対象エージェントの CSI リタイアの信頼性が向上します。 (#16910) by @doudouOUC
  • 生成された UI 請求書分割、チェックリスト、アクティビティ フォーム、および計画比較シナリオの受け入れテストを追加します。 (#16811) by @qqqys
  • 製品の動作を変更せずに E2E 層の障害に対処することで、夜間の Web シェル ブラウザー回帰テスト クラスターを修正しました。 (#16919) by @yiliang114
  • ユーザーが目に見える動作の変更を行わずに、管理対象エージェント ブローカーのファサード分解を完了します。 (#16922) by @doudouOUC
  • 呼び出されていない管理対象エージェントの CSI アドミッションとワークスペース カタログ コードを削除しますが、ユーザーに見える動作の変更はありません。 (#16928) by @doudouOUC
  • ユーザーに表示される動作を変更せずに、バインディングアドミッションとフェンスエンジンロジックを抽出することにより、マネージドエージェントの永続性をリファクタリングします。 (#16936) by @doudouOUC
  • ワークフローの動作を変更せずに、ドキュメントのみのプル リクエストの lint-lane ゲート条件と失敗ポリシーを固定する CI テストを追加します。 (#16950) by @yiliang114
  • 使い捨てランナー CI イメージにプリインストールされた Chromium、ffmpeg、およびライブラリと、ブラウザーのダウンロードを回避するためのキャップ付きタイプチェック ヒープ。 (#16951) by @yiliang114
  • TUI エージェント ループ パリティ テストで起動日を無視するようにしたため、深夜をまたぐ実行は失敗しなくなりました。 (#16961) by @qwen-code-dev-bot
  • 運用呼び出し元のない、未使用の CSI チェックポイント スナップショットとポッド ログ リーダー ツールを削除しました。 (#16957) by @doudouOUC
  • CSI バインドのクリーンアップが完了したため、管理対象エージェント履歴のデコードにより新しいサイズ制限が一貫して適用されます。 (#16981) by @doudouOUC
  • GitHub がホストするランナー上での特権公開および管理対象ホストのプッシュ実行を維持しながら、認証情報不要の Web シェル PR ジョブを一時ランナーにルーティングしました。 (#16917) by @yiliang114
  • 使用されていないメモリ内ランタイム ブローカー リポジトリを削除し、本番動作と一致するようにテストを JDBC ストレージに移行します。 (#16953) by @doudouOUC
  • Vitest がワーカー RPC タイムアウト エラーのみを報告する場合、失敗した単体テスト ワークスペースを 1 回再実行し、競合するホストでの誤った CI エラーを減らします。 (#16945) by @yiliang114
  • CI は、ユニット スイートの起動前にホストの CPU 負荷をチェックするようになり、ホストの競合が多すぎる場合は再実行プロンプトが表示されてすぐに失敗します。 (#16987) by @yiliang114
  • デフォルトのツール エグゼキュータがイベント バス パスを介してスケジューラ オプションとランタイム コンテンツ ジェネレータ ビューを正しく渡すことを確認するテストを追加しました。 (#17009) by @wenshao
  • セッション名の変更が同期的に完了するようになったため、確認されたセッション タイトルが即座に一貫して表示されます。 (#17006) by @doudouOUC
  • CI リント ゲートの鮮度チェックはリント スライスに絞り込まれ、関連するフォローアップ修正が含まれています。 (#16946) by @yiliang114
  • SSH ブートストラップ プロセス テストは、Linux ホスト マシン ID を固定して、それが不足しているランナーでの障害を回避するようになりました。 (#16976) by @qwen-code-dev-bot
  • lint 鮮度ゲートが強化されたため、古い lint 構成と無効なワークフロー定義により明確な CI エラーが発生します。 (#17028) by @yiliang114
  • テスト(チャネル): ピン バインド イベント ローカリゼーション コントラクト (#17026) by @wenshao
  • ci: スタンドアロン ランタイム アーカイブを一時イメージ (#17033) にベイクします (@yiliang114 による)
  • 雑用(管理対象エージェント): @doudouOUCによる検証メタラチェットのトリムとローカルゲートプロファイルの調整(#17044)
  • 内部テストでは、削除された [その他] メニューの代わりに、ホーム専用シェルのインライン フッター アクションから [設定] が開かれるようになりました。 (#17066) by @qwen-code-dev-bot
  • コンテナ境界プリフライト テストは、SANDBOX=docker を必要としながらも、環境から予想される分離マーカーを取得するようになりました。 (#17049) by @qwen-code-dev-bot
  • 管理対象エージェント サーバーの配布は、単一の実行可能 jar として出荷されるようになり、冗長なオペレーター ツール jar が削除されました。 (#17064) by @doudouOUC
  • マネージド エージェントの OSS 読み取りでは、冗長なバケット バージョン管理プローブが実行されなくなり、ツールの公開を有効にしなくてもオブジェクト ストレージを使用できるようになりました。 (#17058) by @doudouOUC

Features

  • Added chips above the Web Shell composer for unfinished background workflows, shells, monitors, and local agents, replacing the status-bar task pill. (#16813) by @qqqys
  • Added Chinese localization for GitHub channel event prompts in PR-bound sessions when the channel UI language is Chinese, while other languages remain English. (#16773) by @wenshao
  • Managed MCP now counts only up to 32 live selections, retains removed entries for recovery, keeps the 16-enabled limit, and caps retained snapshots at 96 entries. (#15161) by @yiliang114
  • Added managed-agent SPIs that let embedding applications import exact Skill or extension revisions from external sources and store compiled archives in private storage. (#16882) by @doudouOUC
  • Enables Mods to rewrite displayed reply rows in the OpenTUI terminal via ui.render while preserving stored message text and /copy output. (#16873) by @qqqys
  • Records pull request states from slim listings and passes their keys to the watch so closed pull requests can leave view rotation correctly. (#16847) by @wenshao
  • Adds a sending-only dingtalk-webhook channel that posts notifications and successful task results as Markdown to configured DingTalk custom group robots. (#16802) by @jkxiao
  • Sidebar session lists now expand ten sessions per click, with labels showing remaining count, instead of showing all at once. (#16830) by @wenshao
  • Managed Sessions now store oversized resources and compacted closed journals in object storage, preserving recovery and normal reads. (#16868) by @doudouOUC
  • Adds internal event-bus primitives for the unified agent loop without changing current behavior. (#16935) by @wenshao
  • Adds DingTalk webhook configuration in Web Shell and lets Scheduled Tasks pick saved Channel destinations. (#16804) by @jkxiao
  • Lets embedding hosts add header and per-model content to the composer model picker while preserving native search, selection, and keyboard behavior. (#16933) by @callmeYe
  • Adds opt-in AgentLoopOptions.useEventBus to run the shared agent loop on event-bus handlers without changing observable behavior. (#16938) by @wenshao
