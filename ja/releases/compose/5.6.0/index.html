compose v5.6.0

v5.6.0 を作成する

何が変わったのか

ℹ️ このリリースでは ジョブの部分的なサポート が追加されています。現時点では手動でトリガーされたジョブのみがサポートされており、スケジュールされたジョブはまだ利用できません。対応する Docker エンジン サポートが統合されると、完全なジョブ サポートが提供されます。

✨ 改善点

仕事

  • https://github.com/docker/compose/pull/14093 の @ndeloof による compose-go ジョブとコンテナー仕様の階層化を採用

プロバイダーサービス

  • 機能 (プロバイダー): https://github.com/docker/compose/pull/14175 の @ndeloof による get-service-config プロバイダー リクエスト
  • 機能 (プロバイダー): 発行エンドポイントは、https://github.com/docker/compose/pull/14193 の @ndeloof によってプロバイダー サービスのネットワーク リレーをデプロイします。
  • Get-relay-info は、https://github.com/docker/compose/pull/14258 の @ndeloof によってリレーのバインド先をプロバイダーに指示します。
  • 機能(構成): https://github.com/docker/compose/pull/14275 の @ndeloof によるプロバイダー リレー リンクの専用ネットワーク
  • プロバイダー サービスはイメージ フェーズに参加し、https://github.com/docker/compose/pull/14252 の @ndeloof によるオンデマンドでのイメージ配布を行います。

その他

  • Feat(compose): https://github.com/docker/compose/pull/14196 の @glours によってサポートされていない作成ファイル属性について警告します
  • PRIVATE_PORT は docker compose port のオプション (https://github.com/docker/compose/pull/13577 の @maxproske による)

🐛 修正

  • 修正 (ビルド): https://github.com/docker/compose/pull/14194 で @ndeloof によってベイクされる未解決の「自動」進行モードを手動で修正
  • 修正 (監視): https://github.com/docker/compose/pull/14202 の @glours によるファイル変更のバースト中にトリガーされる合体リビルド
  • 修正 (ポート): https://github.com/docker/compose/pull/14213 の @glours によるデュアル スタック ポート パブリッシャの同順位の保持
  • 修正(公開): https://github.com/docker/compose/pull/14146 の @htoyoda18 により、プッシュが OCI 1.1 から OCI 1.0 にフォールバックすると警告する
  • 修正: https://github.com/docker/compose/pull/13990 の @glours によるアップ モニターで外部から停止および削除されたコンテナーを検出する
  • 修正 (ドライラン): コミットによって実際のイメージが作成されなくなりました。インターセプト セットは、https://github.com/docker/compose/pull/14150 の @ndeloof によって宣言型になります。
  • 修正(アップ): 良性のコンテキストを削除。https://github.com/docker/compose/pull/14227 の @ndeloof による最終レポートからのノイズをキャンセル
  • 修正 (リレー): https://github.com/docker/compose/pull/14236 の @ndeloof によってルートが変更されない場合、新しいネットワークに再接続します
  • 修正 (プロバイダー): https://github.com/docker/compose/pull/14238 の @ndeloof により、古いリレーをクリーンアップし、それに対して開始/再起動をガードします。
  • 修正 (ハッシュ): https://github.com/docker/compose/pull/14215 の @ndeloof による compose-go struct リファクタリングから分離されたサービス config-hash バイト レイアウトを固定します。
  • 修正 (ハッシュ): #14093/#14215 が https://github.com/docker/compose/pull/14253 の @ndeloof によって逆順にマージされた後のメインを修復
  • 修正 (ログ): 再接続を再起動すると高速実行の出力が失われる — https://github.com/docker/compose/pull/14140 の @ndeloof による e2e のデフレークによって発見
  • 修正: プロバイダーの移行により、https://github.com/docker/compose/pull/14264 の @ndeloof によってサービスの古いレプリカが非難される
  • https://github.com/docker/compose/pull/14266 の @glours による rmi のぶら下がり画像を修正/削除
  • 修正/ドライラン サービスは正常に完了しました 14269 by @glours (https://github.com/docker/compose/pull/14270)
  • 修正: https://github.com/docker/compose/pull/14177 の @glours によるすべてのバルク エンジン コール ファンアウトにわたる Honor --Parallel
  • 修正: https://github.com/docker/compose/pull/14281 で @glours によってサイレントに x-initialSync を促進する compose-go v2.16.1 に適応する

compose v5.6.0

What's Changed

ℹ️ This release adds partial support for jobs: only manually-triggered jobs are supported for now, scheduled jobs are not yet available. Full job support will land once the corresponding Docker Engine support is merged.

✨ Improvements

Jobs

  • Adopt compose-go jobs and container-spec layering by @ndeloof in https://github.com/docker/compose/pull/14093

Provider services

  • Feat(provider): get-service-config provider request by @ndeloof in https://github.com/docker/compose/pull/14175
  • Feat(provider): publish-endpoint deploys a network relay for provider services by @ndeloof in https://github.com/docker/compose/pull/14193
  • Get-relay-info tells providers where to bind for the relay by @ndeloof in https://github.com/docker/compose/pull/14258
  • Feat(compose): dedicated network for the provider relay link by @ndeloof in https://github.com/docker/compose/pull/14275
  • Provider services take part in the image phase, with image distribution on demand by @ndeloof in https://github.com/docker/compose/pull/14252

Other

  • Feat(compose): warn on unsupported compose-file attributes by @glours in https://github.com/docker/compose/pull/14196
  • PRIVATE_PORT optional for docker compose port by @maxproske in https://github.com/docker/compose/pull/13577

🐛 Fixes
