#アリデザイン 6.6.4

  • 🗑 従来のアバター GroupProps、BackTop および FloatButton BackTopProps、Input GroupProps、Mentions OptionProps、および GetProps またはオプション派生型を優先して OptionProps 型を選択することを廃止します。 #58949 @li-jia-nan
  • 🐞 オートコンプリートでクリア ボタンの classNames.clear および styles.clear セマンティック カスタマイズが欠落していたのを修正しました。 #59245 @lazerg
  • テーブル
    • 🐞 応答性の高い列が非表示になっている場合に無視されるテーブル filteredValue を修正しました。 #59198 @QDyanbing
    • 🐞 pagination.classNames および pagination.styles セマンティック カスタマイズを無視するテーブルを修正しました。 #59267 @QDyanbing
    • 🐞 テーブルの仮想セルのコンテンツが垂直方向の中央に配置されない問題を修正しました。 #59260 @QDyanbing
  • モーダル
    • 🐞 偽の ReactNode 値に対して、モーダル okText および cancelText がデフォルトのテキストに戻る問題を修正しました。 #59254 @QDyanbing
    • 🐞 cancelButtonProps.onClick が指定されている場合にモーダルが onCancel をトリガーしない問題を修正しました。 #59255 @QDyanbing
  • カラーピッカー
    • 🐞 ColorPicker クリア コントロールがインタラクティブのままで、無効になっているときにホバー スタイルが表示される問題を修正しました。 #59164 @dogledogle
    • 🐞 ColorPicker が presets を変更し、プリセット項目がフリーズするとクラッシュする問題を修正しました。 #59272 @QDyanbing
  • 🐞 コンテナのサイズが変更されたときに、スプリッター パネルのサイズが min および max の制約を超える問題を修正しました。 #59084 @QDyanbing
  • 🐞 カスタム itemSelectedBg および itemSelectedColor トークンが使用されている場合、セグメント化された選択項目のテキストの色がサム アニメーションより遅れる問題を修正しました。 #59046 @EmilyyyLiu
  • 🐞 dataSource 項目 key タイプが変更された後に転送が古い選択を復元する問題を修正しました。 #59166 @QDyanbing
  • 🐞 trigger="hover" でポインタをトリガーからメニューに移動するときに FloatButton.Group メニューがちらつく問題を修正しました。 #59246 @QDyanbing
  • 🐞 水平レイアウト内で縮小するフォームの垂直 Form.Item コントロールを修正しました。 #59263 @QDyanbing
  • 🐞 styles.popup.root を無視するタブのドロップダウンを修正しました。 #59221 @giaBaoJS
  • 🐞 inherit が false の場合、ネストされたテーマで ConfigProvider が zeroRuntime を継承できない問題を修正しました。 #59250 @QDyanbing
  • 🗑 アバター GroupProps、BackTop および FloatButton BackTopProps、Input GroupProps、Mentions OptionProps および Select OptionProps 旧型、建案変更用 GetProps #58949 @li-jia-nan
  • 🐞 AutoComplete の欠落消去ボタン classNames.clear および styles.clear の対話構成の問題を修正します。#59245 @lazerg

  • カラーピッカー

ant-design 6.6.4

Highlights

  • Type API migration — Legacy GroupProps, BackTopProps, and select-like OptionProps exports are deprecated. Migrate type imports to GetProps or option-derived types before a future removal; this is a TypeScript API cleanup, not a runtime change. #58949

  • Table correctness across layouts — Responsive column hiding no longer causes filteredValue to be ignored, pagination semantic customizations now work, and virtualized cells align vertically. Existing data-grid styling and filtering configurations should behave consistently without workarounds. #59198 #59267 #59260

  • Modal behavior changes — Falsy ReactNode labels such as 0 or "" are no longer replaced by default text, and providing cancelButtonProps.onClick no longer suppresses onCancel. Review custom handlers that previously relied on that suppression. #59254 #59255

  • ColorPicker safety and disabled states — The clear control is now truly inert while disabled, and presets is no longer mutated. Frozen or shared preset arrays are safe to reuse without crashes. #59164 #59272

  • State, layout, and theming fixes — Splitter panels are re-clamped to min/max after container resizes, Transfer no longer restores stale selections when item key types change, and nested themes preserve zeroRuntime despite inherit={false}. AutoComplete clear-button and Tabs overflow-menu semantic styles now apply as configured. #59084 #59166 #59250 #59245 #59221

  • Compatibility — No breaking changes.

  • 🗑 Deprecate legacy Avatar GroupProps, BackTop and FloatButton BackTopProps, Input GroupProps, Mentions OptionProps, and Select OptionProps types in favor of GetProps or option-derived types. #58949 @li-jia-nan

  • 🐞 Fix AutoComplete missing classNames.clear and styles.clear semantic customizations for the clear button. #59245 @lazerg

  • Table

    • 🐞 Fix Table filteredValue being ignored when responsive columns are hidden. #59198 @QDyanbing
    • 🐞 Fix Table ignoring pagination.classNames and pagination.styles semantic customizations. #59267 @QDyanbing
    • 🐞 Fix Table virtual cell content not being vertically centered. #59260 @QDyanbing

  • Modal

    • 🐞 Fix Modal okText and cancelText falling back to default text for falsy ReactNode values. #59254 @QDyanbing
    • 🐞 Fix Modal not triggering onCancel when cancelButtonProps.onClick is provided. #59255 @QDyanbing

  • ColorPicker

    • 🐞 Fix ColorPicker clear control remaining interactive and showing hover styles when disabled. #59164 @dogledogle
    • 🐞 Fix ColorPicker modifying presets and crashing when preset items are frozen. #59272 @QDyanbing

  • 🐞 Fix Splitter panel sizes exceeding their min and max constraints when the container resizes. #59084 @QDyanbing

  • 🐞 Fix Segmented selected item text color lagging behind the thumb animation when custom itemSelectedBg and itemSelectedColor tokens are used. #59046 @EmilyyyLiu

  • 🐞 Fix Transfer restoring stale selections after dataSource item key types change. #59166 @QDyanbing

  • 🐞 Fix FloatButton.Group menu flickering when moving the pointer from the trigger to the menu with trigger="hover". #59246 @QDyanbing

  • 🐞 Fix Form vertical Form.Item controls shrinking inside horizontal layouts. #59263 @QDyanbing

  • 🐞 Fix Tabs more dropdown ignoring styles.popup.root. #59221 @giaBaoJS

  • 🐞 Fix ConfigProvider failing to inherit zeroRuntime in nested themes when inherit is false. #59250 @QDyanbing

  • 🗑 废弃 Avatar GroupProps、BackTop 和 FloatButton BackTopProps、Input GroupProps、Mentions OptionProps 与 Select OptionProps 旧类型，建议改用 GetProps 或从选项推导的类型。#58949 @li-jia-nan
  • 🐞 修复 AutoComplete 缺失清除按钮 classNames.clear 和 styles.clear 语义化配置的问题。#59245 @lazerg
  • Table
    • 🐞 修复 Table 响应式列隐藏后 filteredValue 失效的问题。#59198 @QDyanbing
    • 🐞 修复 Table 忽略 pagination.classNames 和 pagination.styles 语义化配置的问题。#59267 @QDyanbing
    • 🐞 修复 Table 虚拟滚动单元格内容未垂直居中的问题。#59260 @QDyanbing
  • Modal
    • 🐞 修复 Modal 的 okText 和 cancelText 为假值 ReactNode 时被默认文案覆盖的问题。#59254 @QDyanbing
    • 🐞 修复 Modal 配置 cancelButtonProps.onClick 时不触发 onCancel 的问题。#59255 @QDyanbing
  • ColorPicker
    • 🐞 修复 ColorPicker 禁用时清除控件仍可交互并显示悬浮样式的问题。#59164 @dogledogle
    • 🐞 修复 ColorPicker 修改 presets 并在预设项被冻结时崩溃的问题。#59272 @QDyanbing
  • 🐞 修复 Splitter 容器尺寸变化时面板尺寸超出 min 和 max 约束的问题。#59084 @QDyanbing
  • 🐞 修复 Segmented 使用自定义 itemSelectedBg 和 itemSelectedColor Token 时，选中项文字颜色滞后于滑块动画的问题。#59046 @EmilyyyLiu
  • 🐞 修复 Transfer 的 dataSource 项 key 类型变化后恢复旧选中状态的问题。#59166 @QDyanbing
  • 🐞 修复 FloatButton.Group 使用 trigger="hover" 时鼠标从触发按钮移向菜单出现闪烁的问题。#59246 @QDyanbing
  • 🐞 修复 Form 在水平布局中嵌套的垂直 Form.Item 控件高度被压缩的问题。#59263 @QDyanbing
