ant-design 6.6.1

Highlights

  • List → Listy migration path — List is now deprecated in favor of Listy, and this release ships official migration guidance covering item rendering, virtual scrolling, and common replacement patterns [#58985], plus a drag-sorting demo [#58962]. If you maintain a List-based feed, plan the port now: virtual-list behavior and item-render APIs differ enough that this is the one item here with real migration work attached.
  • Callback behavior that can change your app logic — Several fixes make events fire that previously didn't: Radio.Group with options now invokes an option's own onChange when selected [#59010], and Select clear buttons finally clear values when activated via Enter/Space [#58958]. Conversely, noisy duplicates are removed — Anchor no longer double-fires onChange with getCurrentAnchor [#58834], and Transfer no longer fires onSearch twice when clearing the input [#59016]. Audit any counters, debounces, or "fire once" workarounds built around the old behavior.
  • Controlled-state correctness — TreeSelect in controlled mode with SHOW_PARENT no longer drops already-selected disabled child nodes [#58935], and Upload no longer discards newly added files when an async onRemove resolves [#58814] — the latter is a genuine data-loss fix worth upgrading for alone if you remove files asynchronously.
  • Accessibility and i18n hardened considerably — Localized accessible names land for Upload actions, Modal/Notification close buttons, and Carousel arrows (newly configurable via ConfigProvider locale) [#58953, #58957, #59014]; RangePicker hides its decorative separator and Collapse hides redundant icon labels for screen readers [#58999, #59000]; Form complex controls allow explicit label-to-nested-control association [#59001]. On the locale side: Traditional Chinese terminology and Taiwan-preferred week wording in DatePicker [#58947, #58951], and corrected Icelandic/Mongolian min-value placeholders [#58965]. Expect visual DOM/aria snapshots to shift.
  • Layout and interaction stability — Form height no longer fluctuates during rapid validation changes and vertical labelCol.offset is respected [#59008, #58981]; Table row hover tracks rowSpan correctly with expanded rows and bordered tables without headers get proper corner radii [#58935, #57035]; inline Menu icon jitter and Tooltip flashing are fixed [#59018, #58865].
  • Documentation clarifications that may expose wrong assumptions — Form.Item required is documented as inferred from validation rules when unset [#58989], and Typography editable onChange fires only when editing completes, not on each keystroke [#59021].

No breaking changes in this release.
