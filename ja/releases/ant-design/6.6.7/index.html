ant-design 6.6.7

Highlights

  • Production import failures (top priority) — #59560 / react-component/util#810. If your production bundle crashed when importing antd because React's version export was unavailable (common with bundlers that alias or tree-shake react), this patch is the fix and effectively a must-upgrade — every other item here is cosmetic by comparison.

  • Post-unmount state updates, plus a Form shouldUpdate correctness fix — #59560 / rc-util#806 and #807. Button, Form, Slider, Typography and Upload now guard deferred state updates after unmount, clearing "update on unmounted component" noise. The same upstream change also restores missing re-renders for custom shouldUpdate comparisons when nested fields with preserve={false} unmount; watch for any logic that accidentally depended on that stale no-update behavior.

  • Select/TreeSelect/Cascader/Mentions popups stop inheriting Form validation state — #59463. popupRender dropdown content no longer picks up the parent Form.Item's validation status or feedback icons. This is one of the few genuinely visible behavior changes: if you styled dropdown content off the ancestor's error state, that coupling is gone.

  • Input.OTP becomes safe for real verification flows — #59580, #59439, #59518. With a filtering formatter, valid characters were silently dropped on paste — dangerous in OTP/login flows where losing a digit means a failed check. The root element now honors rootClassName, and a numeric 0 finally renders as separator instead of being treated as falsy.

  • Table selection semantics and fixed-header theming — #59570, #59554. Inverting selection now includes current-page tree descendants, and clearing selections no longer leaves disabled rows on other pages checked — important if you lock rows via getCheckboxProps. Separately, the sorted fixed-header hover background and fixedHeaderSortActiveBg token now actually take effect.

  • Smaller fixes worth knowing about — Theming/styling: Popover and Popconfirm preset color now paints the panel (#59549), Tooltip clamps left/right radius to 8px under large borderRadius tokens (#59568), Progress honors string widths like ['50%', 20] (#59597), ColorPicker no longer applies RTL styles under direction: ltr (#59441), and nested Descriptions stop inheriting outer borders/spacing (#59547). Behavior: Popconfirm's onPopupClick no longer fires twice per click (#59440) — drop any dedupe workaround. a11y: warning-only Form messages are now wired via aria-describedby (#59443) and Typography's default edit icon no longer exposes duplicate button semantics (#59112). Transfer's source list also renders faster (#59524). No breaking changes — this is a backward-compatible patch release with no migration steps required.
