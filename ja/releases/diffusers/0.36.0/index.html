ディフューザー v0.36.0

このリリースには、多数の新しい画像およびビデオ パイプライン、新しいキャッシュ方法、新しいトレーニング スクリプト、新しい kernels (強化されたアテンション バックエンド) などが含まれています。新しい内容がたくさん詰まっているので、必ず release note をよく読んでください 🚀

新しい画像パイプライン

  • Flux2: Flux2 は、Black Forest Labs の最新世代の画像生成および編集モデルです。複数の入力画像を参照として取得できるため、さまざまなユースケースに多用途に使用できます。
  • Z-Image: Z-Image は、6B param 体制における最高の画像生成モデルです。 https://github.com/huggingface/diffusers/pull/12703 の @JerryWu コードに感謝します。
  • QwenImage Edit Plus: QwenImage Edit のアップグレードであり、複数の入力画像を参照として取り込むことができます。生成モデルとしても編集モデルとしても機能します。 https://github.com/huggingface/diffusers/issues/12357. に貢献してくれた @naykun に感謝します
  • Bria FIBO: FIBO は、最大 1,000 語以上の構造化された JSON キャプションでトレーニングされており、照明、構成、色、カメラ設定などのさまざまな視覚パラメータを理解して制御するように設計されており、正確で再現可能な出力を可能にします。 https://github.com/huggingface/diffusers/pull/12545 でこれを投稿してくれた @galbria に感謝します。
  • Kandinsky Image Lite: Kandinsky 5.0 Image Lite は、軽量の画像生成モデル (6B パラメーター) です。 https://github.com/huggingface/diffusers/pull/12664 でこれを貢献してくれた @leffff に感謝します。
  • ChronoEdit: ChronoEdit は、画像編集をビデオ生成タスクとして再フレーム化し、入力画像と編集済み画像を開始/終了フレームとして使用して、時間的一貫性を持つ事前トレーニング済みのビデオ モデルを活用します。時間的推論ステージでは、物理的に妥当な編集を保証し、編集の軌跡を視覚化するための推論トークンが導入されます。 https://github.com/huggingface/diffusers/pull/12593. に貢献してくれた @zhangjiewu に感謝します

新しいビデオ パイプライン

  • Sana-Video: Sana-Video は高速かつ効率的なビデオ生成モデルであり、リニア アテンションが組み込まれているため、長いビデオ シーケンスを処理することができます。 https://github.com/huggingface/diffusers/pull/12634 でこれを貢献してくれた @lawrence-cj に感謝します。
  • Kandinsky 5: Kandinsky 5.0 T2V Lite は、このクラスのオープンソース モデルの中で #1 にランクされる軽量のビデオ生成モデル (2B パラメーター) です。これは、大規模なモデルよりも優れたパフォーマンスを発揮し、オープンソース エコシステムにおけるロシアの概念を最もよく理解できるようにします。 https://github.com/huggingface/diffusers/pull/12478 でこれを貢献してくれた @leffff に感謝します。
  • Hunyuan 1.5: HunyuanVideo-1.5 は軽量かつ強力なビデオ生成モデルで、わずか 8.3 億のパラメーターで最先端のビジュアル品質とモーションの一貫性を実現し、コンシューマーグレードの GPU での効率的な推論を可能にします。
  • Wan Animate: Wan-Animate は、Wan2.1 に基づいた最先端のキャラクター アニメーションおよび置換ビデオ モデルです。参照キャラクター画像と運転モーションビデオが与えられると、運転ビデオのモーションでキャラクターをアニメーション化するか、そのビデオ内の既存のキャラクターをそのキャラクターに置き換えることができます。

新しい kernels を利用したアテンション バックエンド

kernels ライブラリ は、さまざまな環境およびアクセラレータ用に事前構築されたカーネル インターフェイスを提供することで、時間を大幅に節約するのに役立ちます。このリリースには、kernels を利用した 3 つの新しいアテンション バックエンドが搭載されています。

  • フラッシュ アテンション 3 (+ その varlen バリアント)
  • フラッシュ アテンション 2 (+ その varlen バリアント)
  • セージ これは、上記のバックエンドのいずれかが開発環境でサポートされている場合、対応するカーネルを構築する手動プロセスをスキップして、次のものを使用できることを意味します。
# Make sure you have `kernels` installed: `pip install kernels`.
# You can choose `flash_hub` or `sage_hub`, too.
pipe.transformer.set_attention_backend("_flash_3_hub")

詳細については、ドキュメント を参照してください。

TaylorSeer キャッシュ

TaylorSeer はディフューザーでサポートされるようになり、品質の妥協をほとんどまたはまったくせずに最大 3 倍のスピードアップを実現します。 https://github.com/huggingface/diffusers/pull/12648 でこれを提供してくれた @toilaluan に感謝します。 ここ のドキュメントを確認してください。

新しいトレーニング スクリプト

Flux.2 統合には、ここ でチェックできる LoRA 微調整スクリプトが含まれています。コンシューマ GPU での実行を支援するために、いくつかの最適化が提供されています。

その他

  • AttentionMixin の再利用: AttentionMixin クラスから特定の互換モデルをサブクラスにすることで、2K LoC を取り除くことができました。今後、ユーザーは、ライブラリをよりスリムでシンプルにするのに役立つこのようなリファクタリングがさらに増えることを期待できます。詳細については、https://github.com/huggingface/diffusers/pull/12463 をご覧ください。
  • SGLang のディフューザー バックエンド: https://github.com/sgl-project/sglang/pull/14112.
  • 多方面にわたるライブラリの改善に協力してくれる才能あるコミュニティ メンバーと協力するために、ディフューザー MVP プログラム を開始しました。詳細については、リンクをご覧ください。

diffusers v0.36.0

The release features a number of new image and video pipelines, a new caching method, a new training script, new kernels - powered attention backends, and more. It is quite packed with a lot of new stuff, so make sure you read the release notes fully 🚀

New image pipelines

  • Flux2: Flux2 is the latest generation of image generation and editing model from Black Forest Labs. It’s capable of taking multiple input images as reference, making it versatile for different use cases.
  • Z-Image: Z-Image is a best-of-its-kind image generation model in the 6B param regime. Thanks to @JerryWu-code in https://github.com/huggingface/diffusers/pull/12703.
  • QwenImage Edit Plus: It’s an upgrade of QwenImage Edit and is capable of taking multiple input images as references. It can act as both a generation and an editing model. Thanks to @naykun for contributing in https://github.com/huggingface/diffusers/issues/12357.
  • Bria FIBO: FIBO is trained on structured JSON captions up to 1,000+ words and designed to understand and control different visual parameters such as lighting, composition, color, and camera settings, enabling precise and reproducible outputs. Thanks to @galbria for contributing this in https://github.com/huggingface/diffusers/pull/12545.
  • Kandinsky Image Lite: Kandinsky 5.0 Image Lite is a lightweight image generation model (6B parameters). Thanks to @leffff for contributing this in https://github.com/huggingface/diffusers/pull/12664.
  • ChronoEdit: ChronoEdit reframes image editing as a video generation task, using input and edited images as start/end frames to leverage pretrained video models with temporal consistency. A temporal reasoning stage introduces reasoning tokens to ensure physically plausible edits and visualize the editing trajectory. Thanks to @zhangjiewu for contributing this in https://github.com/huggingface/diffusers/pull/12593.

New video pipelines

  • Sana-Video: Sana-Video is a fast and efficient video generation model, equipped to handle long video sequences, thanks to its incorporation of linear attention. Thanks to @lawrence-cj for contributing this in https://github.com/huggingface/diffusers/pull/12634.
  • Kandinsky 5: Kandinsky 5.0 T2V Lite is a lightweight video generation model (2B parameters) that ranks #1 among open-source models in its class. It outperforms larger models and offers the best understanding of Russian concepts in the open-source ecosystem. Thanks to @leffff for contributing this in https://github.com/huggingface/diffusers/pull/12478.
  • Hunyuan 1.5: HunyuanVideo-1.5 is a lightweight yet powerful video generation model that achieves state-of-the-art visual quality and motion coherence with only 8.3 billion parameters, enabling efficient inference on consumer-grade GPUs.
  • Wan Animate: Wan-Animate is a state-of-the-art character animation and replacement video model based on Wan2.1. Given a reference character image and driving motion video, it can either animate the character with motion from the driving video, or replace the existing character in that video with that character.

New kernels-powered attention backends

The kernels library helps you save a lot of time by providing pre-built kernel interfaces for various environments and accelerators. This release features three new kernels-powered attention backends:

  • Flash Attention 3 (+ its varlen variant)
  • Flash Attention 2 (+ its varlen variant)
  • SAGE

This means if any of the above backend is supported by your development environment, you should be able to skip the manual process of building the corresponding kernels and just use:

# Make sure you have `kernels` installed: `pip install kernels`.
# You can choose `flash_hub` or `sage_hub`, too.
pipe.transformer.set_attention_backend("_flash_3_hub")

For more details, check out the documentation.

TaylorSeer cache

TaylorSeer is now supported in Diffusers, delivering upto 3x speedups with negligible-to-none quality compromise. Thanks to @toilaluan for contributing this in https://github.com/huggingface/diffusers/pull/12648. Check out the documentation here.

New training script

Our Flux.2 integration features a LoRA fine-tuning script that you can check out here. We provide a number of optimizations to help make it run on consumer GPUs.

Misc

  • Reusing AttentionMixin: Making certain compatible models subclass from the AttentionMixin class helped us get rid of 2K LoC. Going forward, users can expect more such refactorings that will help make the library leaner and simpler. Check out https://github.com/huggingface/diffusers/pull/12463 for more details.
  • Diffusers backend in SGLang: https://github.com/sgl-project/sglang/pull/14112.
  • We started the Diffusers MVP program to work with talented community members who will help us improve the library across multiple fronts. Check out the link for more information.
