ディフューザー v0.42.0

[!ヒント] このリリースでは、FLUX.3 Image Klein、Bria Fibo 2.0、Kandinsky 6、SANA-WM、および RFD4-Proteína がディフューザーに追加されるとともに、新しいアダプターのサポート、ハードウェア統合、モジュラー パイプラインが追加されます。 🚨 Python 3.11 以降が必要になりました。

FLUX.3 イメージ クライン

Black Forest Labs の FLUX.3 Image Klein は、テキストから画像への生成と、1 つ以上の参照画像を使用した編集をサポートしています。基本チェックポイントとステップ蒸留チェックポイントの両方が、短いリクエストを詳細なキャプションに変換し、境界ボックスを使用したレイアウト指示をサポートする統合プロンプト アップサンプラーを備えた ModularPipeline を通じて利用できます。この統合には、単一ファイルのトランスフォーマーのロード、BFL FP8r および NVFP4 チェックポイントも含まれています。

ModularPipeline.from_pretrained(...) でパイプラインをロードし、次に load_components(...) でその重みをロードします。プロンプトアップサンプリング、編集、メモリ使用の例とガイダンスについては、FLUX.3 ドキュメント を参照してください。

ブリア フィボ 2.0

Bria Fibo 2.0 は、構造化された JSON キャプションからの画像生成と、BriaFibo2Pipeline を介した最大 5 つの参照画像による編集をサポートします。この統合には、dev チェックポイントと edit-turbo チェックポイントが含まれており、分類子を使用しないガイダンスなしで 4 つのステップで実行されます。サポートされているプロンプト形式については、Fibo 2.0 ドキュメント を参照してください。

LoRA の読み込みと DreamBooth LoRA トレーニングのサンプルは、テキストから画像への変換と画像編集のために含まれています。モデルの統合 (#14991) については @muhamdali-afridi に感謝します。

カンディンスキー 6

Kandinsky 6 は、Kandinsky6TI2VAPipeline を介してテキストまたは参照画像から同期された音声を含むビデオを生成します。別の Kandinsky6SRPipeline はビデオの超解像度を提供します。この統合では、蒸留バリアントを含む Pro および Lite 生成チェックポイントがサポートされ、蒸留モデル用に PiflowScheduler が導入されます。チェックポイント固有の設定と超解像度の要件については、Kandinsky 6 ドキュメント を参照してください。モデルの統合 (#14949) については @lefff に感謝します。

サナ-WM

SANA-WM は、開始画像、テキスト プロンプト、カメラの軌跡からビデオを生成します。明示的なポーズまたは WASD/IJKL アクション文字列を使用してカメラを制御し、オプションで別の LTX-2 リファイナーを使用して出力を調整します。 2 段階のワークフローについては、SANA-WM ドキュメント を参照してください。

@lawrence-cj の統合 (#13881) に感謝します。

RFD4-プロテイナ

Baker Lab と NVIDIA の RFD4-Proteína は、ディフューザーに生体分子設計をもたらします。結合ターゲット、モチーフ、リガンドなどの分子コンテキストを条件付けしながら、タンパク質配列と全原子構造を共同生成します。統合には、パイプライン、トランスフォーマー、オートエンコーダー、スケジューラー、および LoRA ロードが含まれます。モデル入力の準備と CIF ファイルの作成には、別の rfd4-proteina-prep パッケージを使用します。 RFD4-Proteína ドキュメント を参照してください。

@kierandidi の統合 (#15088) に感謝します。

その他のハイライト

  • Qwen-Image 2.1: 新しいモジュラー パイプラインとテンソル並列処理のサポート。 (#14976、#14865)
  • さらなるハードウェア サポート: TorchTPU の統合により、即時実行、torch.compile、テンソル並列処理がカバーされます。 Tensor 並列処理も Intel XPU をサポートします。 (#14039、#15013)
  • LoKr アダプター: Z-Image および FLUX.2 (Klein を含む) 用の LyCORIS クロネッカー積アダプターをロードします。 (#14163)
  • LTX-2 モーション コントロール: motion_speed は、再生フレーム レートとは独立して位置タイム ベースを制御します。デフォルトとは異なる速度を実現するには、LTX-2.5 スローモーション コントロール LoRA などの互換性のあるアダプターを使用してください。 (#14967)
  • KVAE-Audio: AutoencoderKLKVAEAudio は、48 kHz オーディオのエンコードとデコードを追加します。 (#14384)
  • キャッシュ: MagCache が FLUX.2 をサポートするようになりました。 (#14756)
  • アダプターの修正: Z-Image は joint_attention_kwargs の LoRA スケールを尊重し、Qwen-Image は .alpha スケーリングを lora_A/lora_B チェックポイントに適用し、テキスト エンコーダーはアクティブなアダプターを正しく報告します。 (#15015、#15016、#14961)
  • パイプラインの修正: FlowMatchEulerDiscreteScheduler の明示的なタイムステップを保持し、Anima テキスト エンコーダーのエクスポートとスタンドアロン コアのノイズ除去を修正し、マスクが指定されていない場合の InpaintProcessor.preprocess からの 3 値の戻り値を保持します。 (#14956、#14943、#14481)

非推奨と互換性

  • Python 3.10 のサポートは終了しました。 このリリースをインストールする前に、Python 3.11 以降にアップグレードしてください。 (#15030)
  • モジュラー レイテント出力: FLUX、Krea 2、および LTX-Video は、コア デノイズ グループでレイテントをアンパックするようになりました。カスタム ワークフローは、アンパックされたレイテントをデコード ブロックに渡す必要があります。パックされた潜在のフォールバックは、0.47.0 で削除される予定です。 (#14737)
  • ハブの互換性: サポートされている huggingface_hub 範囲は >=1.32.0,<3.0 になりました。 (#14863)
  • TorchAO インポート: 0.15 より古い TorchAO バージョンがインストールされていても、モデルのインポートが中断されることはなくなりました。 TorchAO 量子化には、依然としてバージョン 0.15 以降が必要です。 (#15095)

このリリースに貢献してくれた皆さんに感謝します!

diffusers v0.42.0

[!TIP] This release brings FLUX.3 Image Klein, Bria Fibo 2.0, Kandinsky 6, SANA-WM, and RFD4-Proteína to Diffusers, alongside new adapter support, hardware integrations, and modular pipelines. 🚨 Python 3.11 or newer is now required.

FLUX.3 Image Klein

FLUX.3 Image Klein from Black Forest Labs supports text-to-image generation and editing with one or more reference images. Both the base and step-distilled checkpoints are available through ModularPipeline, with an integrated prompt upsampler that turns short requests into detailed captions and supports layout instructions with bounding boxes. The integration also includes single-file transformer loading and BFL FP8r and NVFP4 checkpoints.

Load the pipeline with ModularPipeline.from_pretrained(...), then load its weights with load_components(...). See the FLUX.3 documentation for examples and guidance on prompt upsampling, editing, and memory use.

Bria Fibo 2.0

Bria Fibo 2.0 supports image generation from structured JSON captions and editing with up to five reference images through BriaFibo2Pipeline. The integration includes the dev checkpoint and the edit-turbo checkpoint, which runs in four steps without classifier-free guidance. See the Fibo 2.0 documentation for the supported prompt formats.

LoRA loading and DreamBooth LoRA training examples are included for text-to-image and image editing. Thanks to @muhammadali-afridi for the model integration (#14991).

Kandinsky 6

Kandinsky 6 generates video with synchronized audio from text or a reference image through Kandinsky6TI2VAPipeline. A separate Kandinsky6SRPipeline provides video super-resolution. The integration supports Pro and Lite generation checkpoints, including distilled variants, and introduces PiflowScheduler for the distilled models. See the Kandinsky 6 documentation for checkpoint-specific settings and super-resolution requirements. Thanks to @lefff for the model integration (#14949).

SANA-WM

SANA-WM generates video from a starting image, a text prompt, and a camera trajectory. Control the camera with explicit poses or a WASD/IJKL action string, then optionally refine the output with the separate LTX-2 refiner. See the SANA-WM documentation for the two-stage workflow.

Thanks to @lawrence-cj for the integration (#13881).

RFD4-Proteína

RFD4-Proteína from the Baker Lab and NVIDIA brings biomolecular design to Diffusers. It jointly generates protein sequences and all-atom structures while conditioning on molecular context such as binding targets, motifs, or ligands. The integration includes the pipeline, transformer, autoencoder, schedulers, and LoRA loading. Preparing model inputs and writing CIF files uses the separate rfd4-proteina-prep package; see the RFD4-Proteína documentation.

Thanks to @kierandidi for the integration (#15088).

Other highlights

  • Qwen-Image 2.1: new modular pipelines and tensor parallelism support. (#14976, #14865)
  • More hardware support: TorchTPU integration covers eager execution, torch.compile, and tensor parallelism. Tensor parallelism also gains Intel XPU support. (#14039, #15013)
  • LoKr adapters: load LyCORIS Kronecker-product adapters for Z-Image and FLUX.2, including Klein. (#14163)
  • LTX-2 motion control: motion_speed controls the positional time base independently of playback frame rate. Use a compatible adapter for speeds far from the default, such as the LTX-2.5 slow-motion control LoRA. (#14967)
  • KVAE-Audio: AutoencoderKLKVAEAudio adds encoding and decoding for 48 kHz audio. (#14384)
  • Caching: MagCache now supports FLUX.2. (#14756)
  • Adapter fixes: Z-Image honors the LoRA scale in joint_attention_kwargs, Qwen-Image applies .alpha scaling to lora_A/lora_B checkpoints, and text encoders correctly report active adapters. (#15015, #15016, #14961)
  • Pipeline fixes: preserve explicit timesteps in FlowMatchEulerDiscreteScheduler, fix Anima text encoder exports and standalone core denoising, and preserve the three-value return from InpaintProcessor.preprocess when no mask is supplied. (#14956, #14943, #14481)

Deprecations and compatibility

  • Python 3.10 support is dropped. Upgrade to Python 3.11 or newer before installing this release. (#15030)
  • Modular latent outputs: FLUX, Krea 2, and LTX-Video now unpack latents in their core denoise groups. Custom workflows should pass unpacked latents to their decode blocks. The fallback for packed latents is deprecated for removal in 0.47.0. (#14737)
  • Hub compatibility: the supported huggingface_hub range is now >=1.32.0,<3.0. (#14863)
  • TorchAO imports: having a TorchAO version older than 0.15 installed no longer breaks model imports. TorchAO quantization still requires version 0.15 or newer. (#15095)

Thanks to everyone who contributed to this release!
