vllm v0.28.0

#v0.28.0

ハイライト

このリリースには、270 人の寄稿者 (76 人が新規) からの 584 件のコミットが含まれています。

  • Kimi-K3 パフォーマンスの向上: スタック全体にわたる Kimi-K3 の主要な最適化の取り組み — デコード コンテキスト パラレル (DCP) サポート (#50484)、融合された FlashKDA デコードおよびプリフィル カーネル (#50654、#51311、#52458)、MegaMoE の SiTU アクティベーション サポート (#50510)、シーケンス並列処理のための GEMM-RS (#52079)、オールギャザーと 1.5 の組み合わせによるカーネル レベルの 3 倍の高速化 (#51070)、DSpark TTFT の最大 60% 向上を実現する適応型投機トークン バジェット (#51725)、および GPU あたり最大 17 GiB のメモリを節約するオプションの共有エキスパート シャーディング (#50912)。 Kimi-K3 は、V2 モデル ランナー (#51653) を使用して ROCm 上でも実行できるようになりました。
  • DeepSeek V4: スパース MLA は、プレーン デコード、MTP、および DSpark 投機的デコード (#51538) に対してエンドツーエンドで動作するようになり、AMD Quark NVFP4 サポート (#47972)、推論エフォート プロンプトとマッピング (#50580)、スパース トップ K メタデータ カーネル最適化 (#52084、 #51967)、狭められた熱心な CUDA グラフ領域 (#51430、#52401)、gfx11 および gfx950 での ROCm の有効化 (#47017、#52212)。
  • 投機的デコードの進歩: ローカル畳み込みと候補セレクターを備えた DFlash2 (#52816)、DSpark の信頼性スケジュール検証 (#47808)、およびドラフト モデルに対して自動有効化された非同期スケジューリング (#48341)。
  • Model Runner V2 の成熟度: E/P/D 分解 (#38390)、重みオフロード (#51413)、マルチレイヤー MTP KV キャッシュ サポート (#50062)、エンコーダー CUDA グラフ (#49852)、デコーダー トークンごとのプーリング (#50931) と Transformers プーリング モデル (#52425)、アテンション フリー モデル(#52374)、および thinking_token_budget のサポート (#46727)。
  • 階層化された KV キャッシュ オフロード: ディスク オフロードのサポート (#49644)、module_path を介したツリー外のセカンダリ層マネージャー (#51007)、部分的なセカンダリ層のロード結果 (#50321)、階層化メトリクス (#48798)、および並列処理に依存しないオフロードのための正規の CPU レイアウト (#48414)。
  • Rust フロントエンドと gRPC: スタンドアロン レンダラー (#50289)、gRPC を介したマルチモーダル画像推論 (#50368)、明示的なデータ並列ランク ルーティング (#51178)、および RL ライフサイクル制御 (#51316)、および protobuf スキーマが Buf に公開されるようになりました (#51276)。
  • 新しいデフォルト: max_num_batched_tokens が 8192 から 16384 に引き上げられ (#51726)、Mamba モデルのプレフィックス キャッシュがデフォルトで有効になり (#50991)、Blackwell CUDA グラフ キャプチャのデフォルトが 1024 に引き上げられました (#49390)。
  • 重大な変更: bitsandbytes のサポートはツリー外のプラグインに移行されました (#43529)。変圧器は 5.15.0 (#51668) に衝突しました。非推奨の calculate_kv_scales ランタイム KV スケール計算が削除されました (#49389)。 override_attention_dtype は削除されました (#48684)。

  • Transformers モデリング バックエンド: MLA サポート (#48250)、ハードウェアに依存しないモデル定義 (#49458)、完全に汎用化された入力埋め込み処理 (#51247)、ロジット ソフトキャッピング (#52173)、および強化されたマルチモーダル パス (#51408、#51657)。

  • ビジョン エンコーダー: Kimi-K2.5 (#50929) および Ernie-4.5-VL (#45254、#51461) の ViT フル CUDA グラフ、Qwen3-VL エンコーダーの torch.compile (#40116)、および ViT で回避されたロングブロッキング H2D コピー (#51841)。
  • MoE: Mistral Large 3 および追加の MoE バックエンド (#48355) の拡張 EPLB サポート、CuTe DSL スキニー GEMM は GLM-5.2 (#49791) まで拡張されました。
  • 投機的デコードのカバレッジ: EAGLE3 サポートは KimLinear (#52171)、Qwen3.6 dSpark の受け入れカバレッジ (#51310) で宣言されています。
  • 正確性: MiniMax-M3 NVFP4 推論 (#48929) および圧縮テンソル FP8 MoE SwiGLU パラメータ (#46845)、Gemma3n/Gemma4 可変長オーディオ バッチ パディング (#50958)、Gemma 4 の次期 Transformers バージョンとの互換性 (#49797)、およびオーディオ トラックのないビデオでの Qwen3-Omni クラッシュ(#48420)。
  • マルチモーダル パフォーマンス: 融合されたオンデバイス マルチモーダル プリプロセス正規化 (#50411)、より高速なプレースホルダーおよびトークン マッチ スキャン (#50716)、および反復的なプロンプト更新スキャンの回避 (#51774)。

エンジンコア

  • 投機的デコード: DSpark の信頼性スケジュール検証 (#47808)、top-k DSpark マルコフ投影 (#49969)、ローカル畳み込みと候補セレクターを備えた DFlash2 (#52816)、ドラフト モデルに対して自動有効化された非同期スケジューリング (#48341)、local-argmax ドラフト トークンを使用した融合 MTP トレーリング all-reduce (#49793)、および投機的にスケジュールされた入力トークンの適応バジェット (#51725)。
  • KV キャッシュとスケジューリング: MLA チャンク コンテキストのリクエストごとのスケジューリング (#50613)、きめ細かいプレフィックス マッチングによる部分末尾プレフィックスの再利用 (#50507)、KV キャッシュ レイアウト リファクタリングでのバックエンド公開 KV パッキング (#51612、#51704)、プレフィックス キャッシュがオフの場合に復元された LIFO 空きブロックの再利用順序(#51482)、優先スケジューリングでのサイレントリクエストのスキップが修正されました (#49206)。
  • パフォーマンス: 実行パス上の GPU<->CPU 同期の継続的な排除 (#51458、#51738、#52369) は CI 同期チェックによって保護されています (#43107)、述語フィルタリングを備えた新しい JIT ウォームアップ インフラストラクチャ (#49315)、8 つのワープで起動された top-k/top-p Triton サンプラー (#51507)、オフラインビーム検索でのトークン化解除 (#50333)、マスクリプレイ (#49577)、最適化されたロングコンテキスト MLA キャッシュ収集 (#51739)、モデルロードごとに 1 回コミットハッシュに解決される HF リビジョン (#49990)。
  • ハイブリッド/Mamba: デフォルトでオンになるプレフィックス キャッシュ (#50991)、Mamba アテンション モジュール リファクタリングの最後の部分 (#44857)、状態コピー Triton カーネルの 3D グリッド タイリング (#49436)、およびエンコーダー キャップの前に適用される Mamba アライメント (#51603)。
  • RL ワークフロー: NCCL およびスパース NCCL を介したステートフル トレーナー送信 (#50902)、タグ選択型 GPU メモリ リリース用の CuMemAllocator.discard() (#52514)、LoRA 有効化によるレベル 2 のスリープ/ウェイク/リロードの修正 (#39935)、および標準化された例でウェイト転送ドキュメントを書き直しました (#51729)。
  • 起動の堅牢性: 単一ノード エグゼキューターの file:// ランデブーにより起動ポートの競合が排除され (#50999、#51652)、エンジン起動中にフロントエンド プロセスが監視され (#43417)、DP 予約ポートの get_open_port() ライブロックが修正され (#50965)、デバイス機能チェックのたびに NVML が再初期化されなくなりました。 (#50393)。

  • CPU: DeepSeek-V2/V3 を CPU (#49453) で実行できる MLA バックエンド、triton-cpu ホイール (#52092)、tcmalloc (#50841) とともに s390x で有効化された GPTQ および AWQ (#51148)、AMD の zentorch 経由でルーティングされた BF16 MoE (#44201)、 Power (VSX) 用の非量子化 MoE バックエンド (#51624)、モジュラー カーネル エキスパート構造に移行された非量子化 MoE (#50133)、および 4 命令ではなく 2 命令に折りたたまれた MXFP4 ブロック スケール (#51583)。

大規模なサービス提供

  • E/P/D の分離: Model Runner V2 E/P/D サポート (#38390)、GPU 側の前処理で重複した画像前処理を削除 (#50390)、KV コンシューマーはマルチモーダル エンベディングを省略できる (#52697)、画像がエンコードされるまでエンコーダー インスタンス リクエストは存続し続ける (#50275)、EC コネクタ スケジューラ/ワーカー メタデータ配管 (#49579、#49585)。
  • KV オフロード: SimpleCPUOffloadConnector のディスク オフロード (#49644)、module_path 経由のツリー外セカンダリ層マネージャー (#51007)、部分的なセカンダリ層ロード結果 (#50321)、階層化オフロード メトリクス (#48798)、オフロード バックエンドに公開されるデータ並列トポロジ (#51879)、標準 CPU レイアウト並列処理に依存しないオフロード (#48414)、および二次 ARC バッチエビクションが回避されました (#50992)。
  • Mooncake: ストア グループ セマンティクス (#44956)、テナント ID サポート (#48069)、および Docker イメージの公式ホイール (#51067)。
  • コネクタ: NIXL 互換性ハッシュに含まれる転送モード (プッシュ/プル) (#50620)、MoRIIO 層ごとの READ 完了バリア (#48534)、dp=ep=16 での mori-ep/mori-io による 2P2D Wide-EP (#45043)、およびプッシュ コネクタの古いリモート クリーンアップ (#50234)。
  • 並列性: EPLB バランス計算が修正およびテストされました (#51813)、高密度マルチノード DP 再スコープ (#49212)。

量子化

  • オンライン量子化: オンライン MXFP4 サポート (#49347)、TP 全体で共有されるオンライン体重計 (#49764)、オンライン NVFP4 エキスパート パッキングで保持される精度 (#50029)、およびリロード間で再利用されるオンライン NVFP4 MoE カーネル (#50074)。
  • NVFP4: CUTLASS (#40372)、KV 4-over-6 スケール検索 (#45187)、SwiGLU-OAI および ReLU2 アクティベーションを使用した CuTeDSL MoE (#47106)、およびモデル dtype に一致する out_dtype (#48861) によるバッチ不変 NVFP4 MoE。
  • 新しいカーネル: ブロック単位のscaled_mm (#49932)、エミュレーション カーネルを備えた DeepSeek-V4 AMD Quark NVFP4 (#47972)。
  • 修正: 動的 INT8 W8A8 MoE 構成は W8A16 としてビルドされなくなりました (#50833) および TritonExperts クラッシュ (#51411)、FlashInfer CUTLASS の MXFP4 変換 (#51038)、MXFP4 の fp32 ウェイト スケールとエキスパートごとのチェックポイント マッピング (#51419)、および融合ブロック スケールの方向(#50727)。

API とフロントエンド

  • 新機能: HTTP ヘッダーから解析されたリクエスト優先度 (#51089)、リクエストに組み込むセッション ID (#48048)、ストリーミング パーサー エンジンの count_reasoning_tokens (#45802)、/inference/v1/generate 上の content_parts (#51478)、すべての /derender リクエスト クラスでオプションの model (#51463)、出力トークン ID DEBUG レベルでログに記録され (#52098)、ネイティブ構成ベースの展開とベンチマークに接続された vLLM レシピ (#51308、#51878)。
  • Rust フロントエンド: スタンドアロン レンダラー (#50289)、gRPC マルチモーダル画像推論 (#50368)、明示的なデータ並列ランク ルーティング (#51178)、RL ライフサイクル制御 (#51316)、開発者メッセージからの動的ツール (#51144)、Buf に公開された protobuf スキーマ (#51276)、およびMiniJinja を 2.22 (#51235) にアップグレードしました。
  • 人為的な API: /v1/messages (#52246)、disable_parallel_tool_use の保存 (#52021)、および制限された停止シーケンス (#51997) での client が原因のエラーに対して 4xx が返されました。
  • Cohere: アップストリームのパーサー修正 (#51998)、正しく報告された停止シーケンス (#51556)、およびベクトル化されたバイナリ埋め込みビットパッキング (#52277)。
  • 構造化された出力: 文法が終了するまで xgrammar でマスクされたリクエスト ストップ トークン (#49227、#50595)、structured_outputs.regex で拒否された NUL バイト (#51796)、語彙外として拒否された負のトークン ID (#51795)、およびバリデーターから生成された VLLMValidationError (#52394)。
  • 堅牢性: uvicorn シグナル ハンドラーは競合するのではなく無効になり (#50916)、統合されたエントリポイント例外ハンドラー (#52261)、非オブジェクト JSON ボディでは 500 ではなく 400 (#51654、#52528)、高価な作業の前に境界が設定された生成入力 (#51447)、および cache_salt が必要になりました。空ではない(#50816)。

セキュリティ

  • オーディオ デコード期間ガードをバイパスするサンプルレート偽造による DoS を修正しました (#49948)。オーディオ デコード時間の制限は NanoNemotronVL でも適用されるようになりました (#50221)。
  • DeepStream は、ピクセル制限が適用された GPU バックエンドとして分類されました (#50755)。
  • _load_ov2_processor は resolve_trust_remote_code (#52952) でガードされます。
  • ドキュメントでは、--api-key がすべてのエンドポイントをゲートするわけではないことを警告するようになりました (#51999)。

Highlights

This release features 584 commits from 270 contributors (76 new)!

  • Kimi-K3 performance push: a major optimization effort for Kimi-K3 across the stack — Decode Context Parallel (DCP) support (#50484), fused FlashKDA decode and prefill kernels (#50654, #51311, #52458), SiTU activation support for MegaMoE (#50510), GEMM-RS for sequence parallelism (#52079), combined all-gathers with 1.5~3x kernel-level speedup (#51070), an adaptive speculative token budget delivering ~60% better DSpark TTFT (#51725), and optional shared-expert sharding saving ~17 GiB of memory per GPU (#50912). Kimi-K3 also now runs on ROCm with the V2 model runner (#51653).
  • DeepSeek V4: sparse MLA now works end-to-end for plain decode, MTP, and DSpark speculative decoding (#51538), joined by AMD Quark NVFP4 support (#47972), reasoning-effort prompts and mappings (#50580), sparse top-k metadata kernel optimizations (#52084, #51967), narrowed eager CUDA graph regions (#51430, #52401), and ROCm enablement on gfx11 and gfx950 (#47017, #52212).
  • Speculative decoding advances: DFlash2 with local convolution and a candidate selector (#52816), DSpark confidence-scheduled verification (#47808), and async scheduling auto-enabled for draft models (#48341).
  • Model Runner V2 maturation: E/P/D disaggregation (#38390), weight offloading (#51413), multi-layer MTP KV cache support (#50062), encoder CUDA graphs (#49852), decoder token-wise pooling (#50931) plus Transformers pooling models (#52425), attention-free models (#52374), and thinking_token_budget support (#46727).
  • Tiered KV cache offloading: disk offloading support (#49644), out-of-tree secondary tier managers via module_path (#51007), partial secondary-tier load results (#50321), tiering metrics (#48798), and a canonical CPU layout for parallelism-agnostic offload (#48414).
  • Rust frontend & gRPC: a standalone renderer (#50289), multimodal image inference over gRPC (#50368), explicit data-parallel rank routing (#51178), and RL lifecycle control (#51316), with protobuf schemas now published to Buf (#51276).
  • New defaults: max_num_batched_tokens raised from 8192 to 16384 (#51726), prefix caching enabled by default for Mamba models (#50991), and the Blackwell CUDA graph capture default raised to 1024 (#49390).
  • Breaking changes: bitsandbytes support migrated to an out-of-tree plugin (#43529); Transformers bumped to 5.15.0 (#51668); the deprecated calculate_kv_scales runtime KV scale calculation was removed (#49389); override_attention_dtype was removed (#48684).

  • Performance: continued elimination of GPU<->CPU syncs on the execution path (#51458, #51738, #52369) now guarded by a CI sync check (#43107), new JIT warmup infrastructure with predicate filtering (#49315), the top-k/top-p Triton sampler launched with 8 warps (#51507), detokenization skipped in offline beam search (#50333), Mask Replay (#49577), optimized long-context MLA cache gathers (#51739), and HF revisions resolved to a commit hash once per model load (#49990).

  • Fixes: dynamic INT8 W8A8 MoE config no longer built as W8A16 (#50833) and a TritonExperts crash (#51411), MXFP4 conversion for FlashInfer CUTLASS (#51038), fp32 weight scales and per-expert checkpoint mapping for MXFP4 (#51419), and fused block-scale orientation (#50727).

API & Frontend

  • New capabilities: request priority parsed from an HTTP header (#51089), session ID plumbing into requests (#48048), count_reasoning_tokens in the streaming parser engine (#45802), content_parts on /inference/v1/generate (#51478), model optional on all /derender request classes (#51463), output token IDs logged at DEBUG level (#52098), and vLLM Recipes connected to native config-based deployment and benchmarking (#51308, #51878).
  • Rust frontend: a standalone renderer (#50289), gRPC multimodal image inference (#50368), explicit data-parallel rank routing (#51178), RL lifecycle control (#51316), dynamic tools from developer messages (#51144), protobuf schemas published to Buf (#51276), and MiniJinja upgraded to 2.22 (#51235).
  • Anthropic API: 4xx returned for client-caused errors on /v1/messages (#52246), disable_parallel_tool_use preserved (#52021), and stop sequences bounded (#51997).
  • Cohere: upstreamed parser fixes (#51998), stop sequences reported correctly (#51556), and vectorized binary embedding bit-packing (#52277).
  • Structured output: request stop tokens masked in xgrammar until the grammar terminates (#49227, #50595), NUL bytes rejected in structured_outputs.regex (#51796), negative token IDs rejected as out-of-vocabulary (#51795), and VLLMValidationError raised from validators (#52394).
  • Robustness: uvicorn signal handlers disabled instead of racing them (#50916), a consolidated entrypoint exception handler (#52261), 400 instead of 500 on non-object JSON bodies (#51654, #52528), generation inputs bounded before expensive work (#51447), and cache_salt now required to be non-empty (#50816).

Security

  • Fixed a DoS via sample-rate forgery that bypassed the audio decode duration guard (#49948); the audio decode duration limit is now also enforced in NanoNemotronVL (#50221).
  • DeepStream classified as a GPU backend with pixel limits enforced (#50755).
  • _load_ov2_processor guarded with resolve_trust_remote_code (#52952).
  • Documentation now warns that --api-key does not gate all endpoints (#51999).

Dependencies

  • Transformers 5.15.0 (#51668), huggingface-hub 1.27.0 (#51422), fastsafetensors upgrade (#50827).
  • ROCm: torch 2.12, triton 3.7, torchaudio, torchvision (#50607).
  • Runtime image upgraded to Ubuntu 24.04, picking up rdma-core > 44 (#51058).
  • DeepGEMM pinned to the deepseek-ai nv_dev tip (#52035), DeepEP pinned by full commit hash (#52028), FlashAttention 3 built with the torch stable API (#49599).

Breaking Changes & Deprecations

  • bitsandbytes support is now an out-of-tree plugin (#43529).
  • The deprecated calculate_kv_scales runtime KV scale calculation was removed (#49389).
  • override_attention_dtype was removed (#48684).
  • reasoning_content output removal is documented as a breaking client change (#50624).
  • KV offload tiering metrics renamed from kv_offload_tiering_block_{queries,hits} to ..._chunk_... (#52812).
  • MoE legacy code removed (#51078).
