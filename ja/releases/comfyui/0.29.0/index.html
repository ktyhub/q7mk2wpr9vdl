ComfyUI v0.29.0

Highlights

  • Streaming video transcode — PR #14813 replaces frame-by-frame RAM buffering with a streamed transcode, so memory no longer scales with frame count; long or high-resolution jobs that previously OOM'd should now complete. Watch the downstream behavior: output is emitted incrementally rather than fully materialized, which can affect nodes that assumed a complete buffered result.
  • Native model support expands — First-class additions include JoyImageEdit (#14428), Gemma4 12B (#14304), MageFlow (#15026), Wan Uni3C ControlNet (#14946), anima lllite control models (#14954), and Krea 2 reference-image controls (#14843). Check #15081 (MageFlow fix on non-bf16 cards) and #15106 (float fps for LTXVEmptyLatentAudio) if you're on older GPUs or fractional-frame-rate video.
  • Comfy Kitchen kernel sweep — Many checkpoints were migrated to optimized RMS-Rope/int8 paths (#14980, #15018, #15036, #15055, #15056, #15080), meaning lower VRAM and better throughput on affected models. If you depend on bitwise-reproducible output, re-baseline: rope/precision changes can introduce small numeric drift.
  • Video becomes a first-class training input — PR #13588 adds video processing nodes, video support in image-processing nodes, and trainer video support. If you train on video, this changes your node graph; workflow templates were bumped repeatedly (v0.11.11 → v0.11.19) to keep pace.
  • Partner Nodes: API contract and model churn — Integration-facing changes matter here: ComfyUI Job Id is now sent in request headers (#14934), credits tracking uses X-Comfy-Credits-Used (#15091), Google Omni moved to the Interactions API (#14984), and the shared OpenAPI contract was re-synced (#14947). New models include GPT-5.6, Gemini 3.5 Flash, Claude Opus 5, HeyGen, Recraft V4.1 and ByteDance multilingual audio; Runway Gen3a is deprecated (#15050), so plan a migration off it.
  • AMD and memory-behavior fixes — gfx1035 is now treated as RDNA2 (#15009), portable ROCm was rolled back to an older build (#15127), and the default background-usage clamp was raised to 128GB (#15068). AMD users get corrected device handling, but portable-release users should note the ROCm version change.

No breaking changes in this release.
