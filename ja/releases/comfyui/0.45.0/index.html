ComfyUI v0.45.0

Highlights

  • Partner nodes expand — and auth flips on by default — Most of v0.45.0 is new partner-model coverage: Pika H3 Flex plus Soundtrack/SFX/Music (#17509, #17328), Tencent HY LLM (#17534), Kling 4.0 Flash with an original-audio option on Kling 4.0 (#17536), OpenAI GPT Image 2.6 (#17558) and GPT Image V3 plus GIF/SVG nodes (#17591), Gemini Omni Flash 1.2 (#17560), ByteDance Seedance 2.5 at 4k (#17579) and Seedream 5.5 (#17631), Breeze TTS 2 (#17611), and Grok price/tooltip updates for retired image models (#17532). The change with real operational impact is #17540: local_web_sso and partner_node_token are now enabled by default, so air-gapped or self-hosted installs will start attempting SSO/token-based partner auth — verify your deployment before rolling out.

  • BREAKING — Qwen Image nodes moved and portable scripts relocated — feat(Qwen): move Qwen Image nodes to Comfy Router (#17527) means saved Qwen Image workflows referencing the old nodes need their node wiring migrated. Separately, the portable launchers run_cpu (#17571) and the fast fp16 script (#17570) now live under ./advanced; custom launch scripts, shortcuts, and docs pointing at the old paths will break. If you rely on the old Qwen Image nodes or those script paths, treat this as a migration, not a drop-in upgrade.

  • Model support, speed, and memory work — Qwen 3.x gets continued perf work: combining parallel linear weights (#17361) and avoiding mixed prefetched/non-prefetched use of Combined Linear (#17625), plus video input support (#17582) and repetition/presence penalties applied in greedy decoding (#17635). SeedVR2 VAE slice length is now adaptive to free memory (#17508), reducing OOM risk. New coverage includes WeVisOne-VL (#17632), MiniMax-H3-image (#17655), RelayVSR (#17511), and texture rebaking with UltraTex support (#17636); a clearer error for a wrongly selected pixel_space VAE (#17518) helps diagnose bad VAE choices.

  • Crash and stability fixes worth having — A batch of real fixes landed: a generic potential crash (#17543), a potential database issue (#17602), a crash in UNetSelfAttentionMultiply (#17603), a qwen fp8 crash during text generation (#17620), Remesh Mesh on imported meshes (#17531), and Get Video Components now holding decoded frames once instead of twice (#17562) to cut memory use. Resolution-selector megapixel precision was also fixed (#17555). If you use qwen fp8, the mesh tools, or video components, these alone justify upgrading.

  • Supporting bumps / who can skip — Frontend bumped to comfyui-frontend-package 1.58.5 (#17442), workflow templates stepped v0.11.102 → 105 (#17541, #17563, #17658), comfy-kitchen 0.2.41 (#17542), comfy-agent is now unversioned in agent_requirements.txt (CORE-692, #17454), and the partner node team became code owners of comfy_api_nodes (#17575). Upgrade if you're on Qwen 3.x, video/3D workflows, new partner models, or want the crash fixes; skip if you're stable and air-gapped with no partner nodes and no dependency on the relocated scripts — accepting you stay on the old Qwen Image nodes and path layout.
