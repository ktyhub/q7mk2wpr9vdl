ComfyUI v0.40.0

Highlights

  • Assets are opt-in for most installs — Outside Windows standalone, start with --enable-assets; output-folder scanning is restored, while Windows standalone enables assets by default (#16884, #16926, #16928, #16929). Adoption unlocks a local export API (#16578), standardized 3D outputs (#16200), video metadata ingestion (#15180), and EXR previews (#16898). Budget for indexing I/O, or use --disable-assets to opt out.

  • Attention behavior is configurable per model and per LoRA — Broader comfy_attention support (#16806), Kitchen Sol configurations (#16831), and LoRA overrides of per-layer attention settings (#16880) enable finer-grained tuning without foranging model code. Validate existing LoRA workflows against optimized paths, particularly given the fused-path bypass fix (#16862).

  • Qwen 3.5 targets low-VRAM and image-conditioned workloads — Memory optimizations (#16820, #16870), the MTP embedding-offload fix (#16877), and MTP with image inputs (#16922) address unstable or memory-constrained deployments. Re-test existing workflows under your actual VRAM budget, especially image-input and long-generation runs.

  • Custom-node authors should review execution and governance changes — Dynamic input validation and lazy execution are preserved (#16377), while DynamicGroup remains internal during stabilization (#16811); avoid building extensions against its internals. Governance enforcement (#16167) makes extension compliance more significant, and the CSP now permits blob: and data: content (#15565), benefiting browser-based custom interfaces and previews.

  • Workflow and integration capabilities expand, with a Quiver migration — Camera nodes expose structured camera and shot data (#14964, #16251), while prompt metadata now reaches WebSocket messages and preview frames (#16763, #16809) for better external tracing. Quiver’s V2 SVG nodes add per-model inputs and deprecate the originals (#16775), so migrate affected workflows rather than cloning deprecated nodes.

  • Breaking changes — None explicitly declared.
