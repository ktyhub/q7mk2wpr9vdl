ストリームリット 1.56.0

何が変わったのか

新機能 🎉

  • [機能] https://github.com/streamlit/streamlit/pull/14051 の @lukasmauch による st.navigation の expanded を介して、表示されるアイテムの数を指定できるようにしました
  • [feat] on_click 再実行サポートを st.link_button に追加 (https://github.com/streamlit/streamlit/pull/14116 の @lukasma such によって)
  • [機能] st.file_uploader および st.chat_input のファイル タイプ ショートカットを @lukasma such によって https://github.com/streamlit/streamlit/pull/14140 に追加
  • https://github.com/streamlit/streamlit/pull/13594 の @lukasma such による st.dataframe の選択をプログラムで設定できるようにする
  • [feat] アラート本文から先頭アイコンを抽出 by @lukasmauch (https://github.com/streamlit/streamlit/pull/14173)
  • [機能] https://github.com/streamlit/streamlit/pull/14090 の @lukasma such によるネイティブ コンテンツ タイプで静的ファイルを提供する
  • 功績: ナビゲーション サイドバーの st.Page で外部 URL を許可 (https://github.com/streamlit/streamlit/pull/13691 の @t0k0shi により)
  • [feat] AudioColumn と VideoColumn を st.column_config に追加 (https://github.com/streamlit/streamlit/pull/14032 の @lukasma such によって)
  • [feat] @lukasmauch による st.menu_button ウィジェットを https://github.com/streamlit/streamlit/pull/13981 に追加
  • [機能] hide_index と hide_header を st.table に追加 by @lukasma such in https://github.com/streamlit/streamlit/pull/14113
  • [機能] https://github.com/streamlit/streamlit/pull/14165 の @lukasma such により、height パラメータを st.chat_input に追加
  • [機能] https://github.com/streamlit/streamlit/pull/14341 の @lukasmauch による AppTest に st.file_uploader サポートを追加
  • [機能] https://github.com/streamlit/streamlit/pull/14336 の @lukasma such によるデータフレーム列の可視性メニューを常に表示します
  • [機能] https://github.com/streamlit/streamlit/pull/14317 の @lukasma such によるメディア要素内の URL を提供する相対静的ファイルのサポートを追加
  • [機能] https://github.com/streamlit/streamlit/pull/14333 の @lukasma such により、alignment パラメーターを column_config 列に追加します
  • [feat] https://github.com/streamlit/streamlit/pull/13939 の @lukasmauch によるストリーミング中の完全な不完全なマークダウン構文
  • [機能] https://github.com/streamlit/streamlit/pull/14330 の @sfc-gh-lwilby によるパッシブ キー レイアウト コンテナー用の安定した Block.id
  • [機能] st.tabs 状態の永続化と CSS キー クラス (https://github.com/streamlit/streamlit/pull/14332 の @sfc-gh-lwilby による)
  • [機能] st.expander & st.popover 状態の永続化と CSS キー クラス (https://github.com/streamlit/streamlit/pull/14356 の @sfc-gh-lwilby による)
  • [機能] https://github.com/streamlit/streamlit/pull/14414 の @lukasma such により、st.pills と st.segmented_control に required パラメータを追加
  • https://github.com/streamlit/streamlit/pull/13812 の @lukasmauch によるパンダ 3.x のサポートを追加
  • [機能] st.dataframe に single-row-required 選択モードを追加 (@lukasma such による https://github.com/streamlit/streamlit/pull/14288)
  • [機能] https://github.com/streamlit/streamlit/pull/14502 の @lukasma such により、autoscroll パラメータを st.container に追加
  • [機能] https://github.com/streamlit/streamlit/pull/14537 で @lukasma such によるウィジェットを選択するフィルター モードを追加
  • [機能] https://github.com/streamlit/streamlit/pull/14433 に @lukasma such による st.iframe コマンドを追加

バグ修正 🐛

  • [修正] https://github.com/streamlit/streamlit/pull/14171 で @lukasma such による python 最適化を使用して streamlit を実行できるようにする
  • [修正] st.text_area height="content" が動作しない問題を修正 (@lukasma such による https://github.com/streamlit/streamlit/pull/14228 内)
  • https://github.com/streamlit/streamlit/pull/14251 で @lukasmauch によって一時ノードをクリアすると古いアンカーが保存される問題を修正
  • 修正（テスト）: https://github.com/streamlit/streamlit/pull/14301 の @tysoncung による AppTest モック ランタイムで BidiComponentManager を初期化
  • [修正] Python 3.14 https://github.com/streamlit/streamlit/pull/14327 の @lukasmauch による inspect.signature() 呼び出し間の PEP 649 アノテーションの互換性
  • [修正] https://github.com/streamlit/streamlit/pull/14353 の @lukasma such による st.multiselect 選択オプションのツールチップを復元する
  • [修正] https://github.com/streamlit/streamlit/pull/14391 の @lukasma such によるローカル開発サーバーのreactJsonViewCompat シムを復元します
  • [修正] https://github.com/streamlit/streamlit/pull/14374 の @mayagbarnes による MPA を使用して URL のバインドされたクエリ パラメータを復元する
  • [修正] https://github.com/streamlit/streamlit/pull/14417 の @sfc-gh-lwilby による狭い幅での st.Exception リンクのオーバーフロー
  • [修正] https://github.com/streamlit/streamlit/pull/14419 の @sfc-gh-lwilby により、適切な配置のために水平コンテナーの見出しパディングを削除
  • [修正] カラー ディレクティブを使用したストリーミング マークダウンで、https://github.com/streamlit/streamlit/pull/14468 の @lukasma such によるアーティファクトが表示される
  • [修正] https://github.com/streamlit/streamlit/pull/14174 の @lukasmauch による誤検知を減らすために Windows 安定性チェックをファイル ウォッチャーに追加しました
  • 修正 #11308: https://github.com/streamlit/streamlit/pull/14372 の @joanaarnauth によるポート 0 へのバインド後に server.port を更新
  • [修正] ダークモードでメインメニューに境界線を追加 by @lukasma such in https://github.com/streamlit/streamlit/pull/14529
  • [修正] https://github.com/streamlit/streamlit/pull/14476 の @mayagbarnes による session_duration メトリクスの OpenMetrics 準拠
  • https://github.com/streamlit/streamlit/pull/14455 で @lukasma such による AttributeDictionary を返すようにプログラムによるデータフレーム選択を修正しました

その他の変更点

  • [リファクタリング] https://github.com/streamlit/streamlit/pull/14141 の @lukasma such によるウィジェット状態の重複警告を UI ではなくコンソールにログ記録します
