🔥 新機能は何ですか?

重大な変更

  • #9620 - Supabase docker 構成コードをロック (@majdyz による) - PR

AutoGPT autogpt-platform-beta-v0.6.0

Highlights

  • Breaking — Supabase setup inlined, database volume moved — #9620 locks the Supabase docker-compose code into the repo, so you no longer need to load the Supabase repo as a git submodule. It also switches to a different DB volume location, which means existing database content starts fresh by default. To preserve your data, run cp -r supabase/docker/volumes/db/data db/docker/volumes/db/data from the autogpt_platform folder before starting. #9652 additionally fixes a db-config permission-denied error when running two different Supabase versions, which matters if you're mixing versions during this transition.

  • Agent portability improved — #9627 adds an "Export agent to file" action and #9640 makes export/import handle sub-agents correctly. If you share, back up, or migrate agents (especially ones composed of sub-agents), these are the headline functional gains.

  • Reliability fixes worth having — #9629 prevents an infinite-loop execution when an AddToListBlock self-loops, #9655 makes SendWebRequestBlock properly handle HTTP error responses, #9654 drastically increases batching time for agent runs, and #9630 fixes a failed RPC on the Notification Service. Anyone running complex or long-running agent graphs benefits; these address real hang/failure modes, not cosmetics.

  • UI polish and dependency bumps (low urgency) — UI/UX changes are incremental: reusable sidebar component used on the admin page (#9618), icons on primary run buttons (#9651), expandable agent input fields (#9650), improved agent I/O rendering (#9656), and title/description truncation on agent cards (#9658). Maintenance includes 13 production-dependency updates (#9611) and ruff 0.9.6→0.9.9 (#9559). Nice but not upgrade drivers on their own.

  • Upgrade recommendation — Upgrade if you rely on agent export/import with sub-agents, hit the AddToListBlock loop or web-request error issues, or want the new DB-permission fix — but plan for the database migration and backup your data first. You can safely skip if you're on a clean install with no DB state to preserve, don't use export/import, and aren't affected by those bugs; the remaining changes are largely UI polish and dependency updates.

🚀 Release autogpt-platform-beta-v0.6.0

Date: 19 March 2024

🔥 What's New?

Breaking Changes

  • #9620 - Lock Supabase docker-compose code (by @majdyz) - PR
    • We are locking the Supabase docker-compose setup to the repository, meaning you no longer need to load the Supabase repository as the git sub-module.
    • This release will use a different database volume location, causing your existing database content to start anew.
    • If you want to keep using your existing database, copy your data volume to the new location by executing the following command in the autogpt_platform folder: cp -r supabase/docker/volumes/db/data db/docker/volumes/db/data

New Features

  • #9627 - Add "Export agent to file" action (by @Pwuts) - PR
  • #9640 - Support sub-agent on export/import agent feature (by @majdyz) - PR

UI/UX Improvements

  • #9618 - Break out the sidebar into a reusable component + use it for admin page (by @ntindle) - PR
  • #9651 - Add icons to primary agent run action buttons (by @Pwuts) - PR
  • #9650 - Make agent input fields expandable (by @Pwuts) - PR
  • #9656 - Improve agent I/O rendering (by @Pwuts) - PR
  • #9658 - Truncate agent card title and description (by @Pwuts) - PR

Bug Fixes

  • #9616 - Fix backend admin page logic (by @ntindle) - PR
  • #9652 - Fix possible db-config permission denied when running two different Supabase versions (by @majdyz) - PR
  • #9629 - Avoid infinite loop execution on AddToListBlock self-loop (by @majdyz) - PR
  • #9654 - Drastically increase batching time for the agent run (by @ntindle) - PR
  • #9655 - SendWebRequestBlock to properly handle HTTP error responses (by @Torantulino) - PR
  • #9630 - Fix failed RPC on Notification Service (by @majdyz) - PR

Dependencies & Maintenance

  • #9611 - Bump the production-dependencies group across 1 directory with 13 updates (by @dependabot) - PR
  • #9559 - Bump ruff from 0.9.6 to 0.9.9 in /autogpt_platform/autogpt_libs (by @dependabot) - PR
  • #9620 - Lock Supabase docker-compose code (by @majdyz) - PR
