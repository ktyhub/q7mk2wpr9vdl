AutoGPT autogpt-platform-beta-v0.6.15

Highlights

  • Context-aware prompt compaction — #10252 makes LLM and SmartDecision blocks compact prompts based on the actual context window, so long-running graphs drop stale context instead of overflowing the model limit. Pair it with #10257, which makes CreateListBlock batch by token count rather than item count. Expect prompt composition to differ in graphs that previously depended on full-context behavior.
  • In-graph data primitives — #10294 adds KV data storage blocks and #10261 adds data manipulation blocks alongside a refactor of basic.py; #10304 adds plural outputs when blocks yield singular values inside loops. The net effect is you can hold and reshape state inside a graph instead of round-tripping to an external store. Watch the basic.py refactor if you've written custom blocks importing from it.
  • Credentials and auth boundary — #10215 scopes credentials to hosts for block HTTP requests, limiting secret exposure across endpoints, and #10283 adds aiohttp.BasicAuth support to make_request. Read the new OAuth security boundary docs (#10202) before wiring integrations: this release formalizes where credentials are allowed to travel.
  • Execution reliability — #10293 hardens stop-graph execution and #10260 stops swallowing exceptions on graph failure, so failed runs surface errors instead of silently hanging or reporting success. #10258 replaces pyclamd with aioclamd for concurrent antivirus scans, #10325 adds auto-type conversion for optional types, #10301 includes subgraphs in get_library_agent, and #10256 restores the GithubReadPullRequestBlock diff output.
  • New model and data-source blocks — #10326 brings Perplexity Sonar models, #9931 expands Revid.ai media generation, #10251 enriches SearchPeopleBlock emails and adds GetPersonDetailBlock, and #10287 improves Mem0 filtering with more GoogleSheets blocks. These are the quickest capability wins without custom code, but each is a new integration to validate.
  • Dashboard data-fetching restructure — #10265 changes the data fetching strategy and restructures the dashboard page, with the new pattern documented in #10268; #9912 adds Linux/Windows setup scripts to ease local onboarding. If you maintain dashboard-facing or custom fetch logic, re-check it against the new pattern.

No breaking changes are documented in this release.
