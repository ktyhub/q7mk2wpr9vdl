AutoGPT autogpt-プラットフォーム-ベータ-v0.12.0

⚠️重大な変更

フロントエンドは TRUST_X_FORWARDED_FOR を読み取らなくなりました (#16530、@Pwuts)。手動で設定したセルフホステッド フロントエンドは、TRUSTED_PROXIES がその前にプロキシをリストするまで、サインイン IP ログ、IP ブロック、および訪問者ごとのストア検索用に X-Forwarded-For から client IP を取得しません。単一コンテナー イメージと Vercel には何も必要ありません。 対処方法: フロントエンドで TRUST_X_FORWARDED_FOR が設定されている場合は、それを削除し、その前にあるプロキシのアドレスまたは CIDR 範囲のカンマ区切りリストを TRUSTED_PROXIES に設定します。そうするまで、フロントエンドは起動時に古い設定が無視されるという警告をログに記録します。同じ TRUSTED_PROXIES 設定により、バックエンドのプロキシと外部 API のアドレスごとの制限にも名前が付けられるようになり、動作し続けますが非推奨になった FORWARDED_ALLOW_IPS と TRUSTED_PROXY_COUNT が置き換えられます。独自のリバース プロキシの背後では、単一コンテナー イメージもそれを受け取ります。 Client IP アドレス を参照してください。

✨ ハイライト

  • AutoGPT をポケットに。 新しいネイティブ モバイル アプリを使用すると、チームが携帯電話に配置されます。サインインして、Otto や専門家とチャットし、マーケットプレイスから専門家を雇い、チャットから直接サービスに接続し、入力する代わりに生の音声ディクテーションで会話します。 (#16715、#16869、#16923、#17058)
  • より迅速に開始できます。 サインアップの手順が少なくなり (パスワードを 2 回入力する必要がなくなり)、サインアップ ページとログイン ページがすぐに表示され、セットアップが「セットアップを読み込んでいます…」でスタックすることがなくなりました。 Google にサインアップすると、同じ手順で Gmail、ドライブ、カレンダーに接続できます。 (#16829、#16831、#16968、#16845、#16877)
  • より安全なサインイン。 アカウント (Google、Microsoft、GitHub、または Discord) にサインインする新しい方法を追加すると、そのプロバイダーがメールボックス (Google 経由の Gmail、Microsoft 経由の Outlook.com) を実行している場合を除き、受信トレイから 6 桁のコードが取得されるようになりました。また、新しいサインイン方法が追加されるたびに電子メールが届きます。 (#16860)
  • メッセージを失うことはありません。 Otto がメッセージの到着を確認できない場合、送信時に 1 回の click を実行すると、ファイルも含めてメッセージが 2 回送信されることなく配信されます。そして、「考え中…」はオットーが答え始めるまで表示されるようになったので、それが機能していることが常にわかります。 (#17041、#16962、#17038)
  • 実行中の実際の位置を常に確認します。 接続が短時間切断されると、ライブラリ、実行履歴、アクティビティ、チャットが自動的に追いつくため、すでに終了した実行はまだ実行中であるようには見えなくなります。ライブ アップデートは、低速接続でも流れ続けます。 (#16898、#16915、#16932、#16903、#16865、#16960)
  • 信頼できるスケジュール 簡単なメンテナンス中、スケジュールは消えるのではなく一時的に利用不可として表示され、再起動中に予定されている実行は引き続き (正確に 1 回) 実行され、作成したばかりのスケジュールを再試行しても重複が作成されなくなります。 (#16937、#16866、#16919、#16904)
  • さらに多くのモデルから選択できます。 Gemini 4 Neon、GPT-6.2 Astra、GPT-6.2 Sol、および Qwen 4 Max がワークフローで利用できるようになり、Otto の高度な Codex 層が GPT-6.2 Astra で実行できるようになりました。 (#17023、#16870、#16899、#16836、#16852、#16902)
  • Otto 用の追加ツール。 Otto は AnySearch、Supabase、Klaviyo、AI/ML API、CompanyEnrich に接続できるようになり、Supabase からの読み取りに毎回承認が必要なくなり、Otto は接続したカスタム MCP サーバーを URL で検索できるようになりました。 (#16913、#16659、#16850、#15202、#16771、#16447、#15168)

AutoGPT autogpt-platform-beta-v0.12.0

Highlights

  • Proxy trust configuration is a breaking change — The frontend ignores TRUST_X_FORWARDED_FOR; remove it and set TRUSTED_PROXIES to comma-separated proxy addresses or CIDR ranges to preserve client IP handling for sign-in logs, IP blocks and per-visitor store searches. The setting now also covers backend and External API rate limits, deprecating FORWARDED_ALLOW_IPS and TRUSTED_PROXY_COUNT; single-container and Vercel deployments need no changes (#16530).

  • Live views recover automatically after interruptions — Library, run history, Activity and chats resynchronize after connection drops, preventing completed runs from appearing stuck. Slow connections retain live updates, reducing the need for manual refreshes (#16898, #16915, #16932).

  • Chat retries are safer and less confusing — “Send again” can recover an unconfirmed Otto delivery, including attachments, without creating a duplicate message. “Thinking…” remains visible until Otto actually starts responding, distinguishing active work from stalled or uncertain delivery (#17041, #16962, #17038).

  • Schedules survive restarts without duplicate execution — Maintenance windows show schedules as temporarily unavailable rather than removing them, due runs execute exactly once across restarts, and retrying a newly created schedule no longer creates a second one (#16937, #16866, #16919, #16904).

  • Model and tool coverage expands for agent workflows — Workflows gain Gemini 4 Neon, GPT-6.2 Astra, GPT-6.2 Sol and Qwen 4 Max, while Otto’s advanced Codex tier moves to GPT-6.2 Astra. Otto also gains AnySearch, Supabase, Klaviyo, AI/ML API and CompanyEnrich connections, repeatable Supabase reads and discovery of URL-connected MCP servers (#17023, #16870, #16899, #16836, #16852, #16902, #16913, #16771, #16447, #15168).

  • Account and organization security is tightened — Adding Google, Microsoft, GitHub or Discord sign-in requires inbox verification unless the provider hosts the mailbox, with email notifications for new methods (#16860). Session tools and several workflow/run routes are now organization-scoped (#16966, #16931), and credential masking prevents sensitive values from reaching validation logs and error reports (#16956, #16908); advisories for separately reported security fixes remain pending publication.

⚠️ Breaking change

The frontend no longer reads TRUST_X_FORWARDED_FOR (#16530, @Pwuts). A self-hosted frontend that set it by hand gets no client IP from X-Forwarded-For for the sign-in IP log, IP blocks and per-visitor store search until TRUSTED_PROXIES lists the proxy in front of it. The single-container image and Vercel need nothing.

What to do: if your frontend sets TRUST_X_FORWARDED_FOR, remove it and set TRUSTED_PROXIES to a comma-separated list of the addresses or CIDR ranges of the proxies in front of it. Until you do, the frontend logs a warning at start that the old setting is ignored. The same TRUSTED_PROXIES setting now also names the proxies for the backend and the External API's per-address limits, replacing FORWARDED_ALLOW_IPS and TRUSTED_PROXY_COUNT, which keep working but are deprecated; behind your own reverse proxy, the single-container image takes it too. See Client IP Addresses.

✨ Highlights

  • Get started faster. Signing up takes fewer steps (no more typing your password twice), the sign-up and login pages show up right away, and setup no longer gets stuck on "Loading your setup…". Sign up with Google and you can connect Gmail, Drive and Calendar in the same step. (#16829, #16831, #16968, #16845, #16877)
  • Safer sign-ins. Adding a new way to sign in to your account (Google, Microsoft, GitHub or Discord) now takes a six-digit code from your inbox, unless that provider runs your mailbox (Gmail through Google, Outlook.com through Microsoft). You also get an email whenever a new sign-in method is added. (#16860)
  • Never lose a message. If Otto can't confirm your message arrived, one click on Send again delivers it, files included, without sending it twice. And "Thinking…" now stays up until Otto starts answering, so you always know it's working. (#17041, #16962, #17038)
  • Always see where your runs really are. After a brief connection drop, your Library, run history, Activity and chats catch up on their own, so a run that already finished no longer looks like it's still going. Live updates also keep flowing on slow connections. (#16898, #16915, #16932, #16903, #16865, #16960)
  • Schedules you can count on. During brief maintenance your schedules show as temporarily unavailable instead of disappearing, a run that comes due during a restart still runs (exactly once), and retrying a schedule you just created no longer makes a duplicate. (#16937, #16866, #16919, #16904)
  • More models to choose from. Gemini 4 Neon, GPT-6.2 Astra, GPT-6.2 Sol and Qwen 4 Max are now available in your workflows, and Otto's advanced Codex tier now runs on GPT-6.2 Astra. (#17023, #16870, #16899, #16836, #16852, #16902)
  • More tools for Otto. Otto can now connect to AnySearch, Supabase, Klaviyo, AI/ML API and CompanyEnrich, reads from Supabase no longer need your approval each time, and Otto now finds the custom MCP servers you've connected by URL. (#16913, #16659, #16850, #15202, #16771, #16447, #15168)

Work in progress:

  • AutoGPT in your pocket. Our new native mobile app puts your team on your phone: sign in, chat with Otto and your experts, hire experts from the Marketplace, connect your services right from the chat, and talk instead of typing with live voice dictation. (#16715, #16869, #16923, #17058)
