⚠️重大な変更

  • #16459 - 支払い強制は、enable-platform-payment 機能フラグではなく、バックエンド設定 ENABLE_PLATFORM_PAYMENT (デフォルト オフ) になりました。有料のセルフホスト型インストールでは、これを設定する必要があります。 FORCE_FLAG_ENABLE_PLATFORM_PAYMENT と NEXT_PUBLIC_FORCE_FLAG_ENABLE_PLATFORM_PAYMENT は何もしなくなりました (@Pwuts より)
  • #16474 - プラットフォーム API は、アップロード ルートまたは Webhook Ingress ではないルート上の MAX_REQUEST_BODY_MB (デフォルトは 10 MiB) 上のリクエスト本文に対して 413 に応答します。より大きなファイルをインラインで渡す場合は、値を上げるか、メディア ストレージを構成します (@Pwuts による)
  • #16522 - X-Forwarded-For が複数のアドレスを持つプロキシ チェーンの背後で、新しい TRUSTED_PROXIES 設定 (IP アドレスまたは CIDR 範囲) にプロキシをリストします。設定しないままにすると、訪問者ごとの制限はヘッダーの左端のエントリの代わりに client IP を取得しません。 IP アドレスまたは CIDR 範囲ではないエントリにより、フロントエンドの起動が停止されます (@Pwuts による)
  • #15853 - LaunchDarkly のサポートが削除され、すべての機能フラグが PostHog から読み取られます。 LAUNCH_DARKLY_SDK_KEY、FEATURE_FLAG_BACKEND、NEXT_PUBLIC_LAUNCHDARKLY_ENABLED、NEXT_PUBLIC_LAUNCHDARKLY_CLIENT_ID、NEXT_PUBLIC_FEATURE_FLAG_BACKEND は無視されます。 PostHog がない場合、すべてのフラグがデフォルトになります (@kcze による)
  • #16026 - AutoPilot の会話は Langfuse まで追跡されなくなり、プロンプト管理のみに使用されるようになりました。 AutoPilot トレースは PostHog に送信されます (@kcze による)

Highlights

  • Breaking: self-hosting config moves — #16459 turns payment enforcement into the backend setting ENABLE_PLATFORM_PAYMENT (default off); the old FORCE_FLAG_ENABLE_PLATFORM_PAYMENT / NEXT_PUBLIC_FORCE_FLAG_ENABLE_PLATFORM_PAYMENT vars are now ignored, so any install that charges must set it explicitly. #16522 adds TRUSTED_PROXIES (IPs or CIDRs) for client-IP resolution: behind a multi-hop X-Forwarded-For chain, leaving it unset means per-visitor limits get no client IP at all, and a malformed entry blocks frontend startup. #16474 makes the platform API return 413 for bodies over MAX_REQUEST_BODY_MB (default 10 MiB) on every non-upload/non-webhook route — raise it or configure media storage if you send large inline payloads.
  • Observability consolidates on PostHog — #15853 removes LaunchDarkly outright: every flag now comes from PostHog, LAUNCH_DARKLY_SDK_KEY, FEATURE_FLAG_BACKEND and the NEXT_PUBLIC_LAUNCHDARKLY_* / NEXT_PUBLIC_FEATURE_FLAG_BACKEND vars are dead, and without PostHog all flags fall back to defaults. #16026 stops tracing AutoPilot conversations to Langfuse (now prompt-management only) and routes them to PostHog. Teams relying on either vendor must migrate flag configuration and trace dashboards or lose both signals.
  • Security and hardening sweep — #16419 bumps Better Auth to 1.7.12 ahead of its Nov 3 security release; #15326 makes OAuth code redemption single-use under races, #16444 adds attempt limits to login/reset-password, and #16311 returns a proper 401 (not 500) for tokens whose algorithm mismatches their key. A broad resource-bound wave (#16470, #16493, #16499, #16497, #16476, #16481) caps archive-unpack bytes, template/preview time and memory, graph inputs, preset counts and block work — expect firmer limits on untrusted content and the API surface.
  • v1 external API is now rate-limited — #14545 adds rate limiting to the v1 external API; clients that called it without constraint should add 429 handling and backoff before upgrading.
  • New agent capabilities — #16310 adds Parallel Decisions blocks (web-grounded yes/no, choice, score) for branching without sequential round-trips; #16268 collapses Microsoft mail, calendar, files, Teams, Copilot and Work IQ into a single connection, cutting OAuth wiring; #15087 adds Gemini 3.5 Flash, 3.5 Flash Lite and 3.1 Flash Lite to the catalog; #15733 lets Otto wake after opt-in background subtasks.
  • Frontend design-system migration lands — #16411 deletes the legacy layer and promotes design-system lint errors everywhere, with a CSS-first Tailwind 4 theme (#16429) and consolidated tokens/Text/Icon/Button variants (#16513, #16556, #16511). Forks carrying custom styles should expect lint and build failures until they migrate.

⚠️ Breaking Changes

  • #16459 - Payment enforcement is now the backend setting ENABLE_PLATFORM_PAYMENT (default off) instead of the enable-platform-payment feature flag. A self-hosted install that charges must set it; FORCE_FLAG_ENABLE_PLATFORM_PAYMENT and NEXT_PUBLIC_FORCE_FLAG_ENABLE_PLATFORM_PAYMENT no longer do anything (by @Pwuts)
  • #16474 - The platform API answers 413 to a request body over MAX_REQUEST_BODY_MB (default 10 MiB) on any route that is not an upload route or webhook ingress. Raise it, or configure media storage, if you pass larger files inline (by @Pwuts)
  • #16522 - Behind a proxy chain whose X-Forwarded-For carries more than one address, list your proxies in the new TRUSTED_PROXIES setting (IP addresses or CIDR ranges). Left unset, per-visitor limits get no client IP instead of the header's leftmost entry. An entry that is not an IP address or CIDR range stops the frontend from starting (by @Pwuts)
  • #15853 - LaunchDarkly support is removed and every feature flag is read from PostHog. LAUNCH_DARKLY_SDK_KEY, FEATURE_FLAG_BACKEND, NEXT_PUBLIC_LAUNCHDARKLY_ENABLED, NEXT_PUBLIC_LAUNCHDARKLY_CLIENT_ID and NEXT_PUBLIC_FEATURE_FLAG_BACKEND are ignored; without PostHog every flag is its default (by @kcze)
