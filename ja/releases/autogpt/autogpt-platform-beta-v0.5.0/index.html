AutoGPT autogpt-platform-beta-v0.5.0

Highlights

  • Onboarding flow lands end-to-end — Frontend UI (#9485) and backend (#9511) now funnel every new user through a guided intro. If you self-host or embed the platform, first-run state is now part of the backend contract, so validate your onboarding path rather than assuming users can jump straight into the builder.

  • Agent Library v2 changes the run lifecycle — A rebuilt library (#9407) adds cost indication for runs (#9527) backed by per-node and per-graph execution stats (#9520), which is the key primitive for anyone metering or billing agent usage. You also finally get agent deletion (#9546) and run Stop/Delete (#9547), plus Ideogram-generated thumbnails (#9568). Watch out for #9591: rendering now uses the correct graph version for I/O, so pinned older graphs should be re-checked after upgrade.

  • Smart Decision Maker becomes an agent loop — What started as a decision block (#9490, usage enabled in #9514) now supports full agent-loop capability and Anthropic models (#9585), conversation-history output (#9540), and tool-execution responses (#9552), with cost tracking in #9531. Two follow-ups changed output semantics you may depend on: #9550 removed an unused output pin and appends the prompt into conversation history, while #9551 switched to raw LLM content — rewire any consumers of that pin.

  • Pyro → HTTP RPC migration is partial, not swapped — Despite the "replace Pyro" theme, #9528 restored Pyro as the default transport; the FastAPI microservice migration (#9508) is in place but opt-in. What did land is better failure handling: exception responses and missing Running status fixes (#9529), error-argument propagation (#9533, #9535), and a raised log threshold to WARNING (#9576). Early adopters of HTTP RPC should explicitly configure it and test exception payloads before relying on it.

  • Execution and request behavior changes — Graphs with no starting node now fail loudly instead of silently doing nothing (#9566), which can surface latent broken graphs on upgrade. Blocks gain safe URL redirect handling for web requests (#9555, security-relevant), Postmark bounce handling (#9506), and unused Stripe code was removed from the frontend (#9536); websockets also jumps 13.1 → 14.2 (#9398), so verify client compatibility.

  • Critical fixes and developer tooling — #9578 unbreaks add_marketplace_agent_to_library (important if you pull agents from the marketplace), #9582 fixes pydantic serialization for GitHub checks/statuses, and #9503 fixes the Builder Run/Stop button after refresh. Also new: low-balance notifications (#9534), list/update comment blocks (#9583), Codecov flaky-test analytics (#9420), and initial Otto chat-bot code (#9266).

No breaking changes were announced in this release.
