AutoGPT autogpt-platform-beta-v0.6.25

Highlights

  • New blocks & integrations — Adds DataForSEO keyword research blocks (#10711), BaaS integration blocks (#10350), Stagehand (#10751), Ideogram V3 (#10752), and DiscordGetCurrentUserBlock for OAuth2 user details (#10723), plus a CI-aligned GitHub Copilot agent setup (#10708). If your workflows lean on SEO data, browser automation, image generation, or Discord identity, this meaningfully expands what you can build; otherwise these are opt-in additions with no impact on existing runs.
  • Admin/operator UX and notifications — The Agent Runs list gains infinite scroll (#10709) and new run modal components (#10729), the Blocks Menu backend was redesigned (#10128), and backend user timezone support (#10707) landed alongside low-balance/insufficient-funds alerts (#10656) and applicant email notifications on review response (#10718). Admins and anyone managing submissions or quotas get clearer workflows — but #10128 is a backend redesign, so check any custom code that touches the Blocks Menu.
  • Base image / runtime change — migration attention — #10654 switches the base image to debian:13-slim with Python 3.13, and ruff is bumped 0.12.3→0.12.4 (#10421). There is no explicit "breaking change" label, but the Python 3.13 + Debian 13 jump is the one item most likely to break self-hosters with custom blocks, pinned dependencies, or native packages that assumed the older runtime — validate those before upgrading.
  • Stability fixes worth having — Fixes malformed messages causing infinite requeueing (#10746), invalid MusicGen model responses (#10533), new runs not appearing in the list (#10750), scheduler cron validation (#10719), credential filtering to supported ones only (#10725), and agent name/description clearing on file removal (#10703), plus removal of the old experience alert (#10730). Collectively these address queue stalls, missing data, and bad credentials — a solid reason to upgrade if any of these bit you.
  • Upgrade verdict — This is a substantive beta covering the v0.6.23→v0.6.25 range (not a no-op or re-tag): upgrade if you want the new integrations, admin/notification improvements, or stability fixes, or if you're tracking the beta line from 0.6.23. You can reasonably skip if none of those touch your workflows or if a customized dependency stack could be disturbed by the Python 3.13 base image — either way, test custom blocks against the new base image first.
