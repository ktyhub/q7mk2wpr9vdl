AutoGPT autogpt-platform-beta-v0.4.10

Highlights

  • RabbitMQ enters the stack — #9437 and #9438 add RabbitMQ to docker-compose and wire it into the AppService. Self-hosters must pick up the new compose service on upgrade, and this is a directional signal that the platform is moving execution toward an async, queue-backed architecture — watch for new infrastructure requirements on future deploys.
  • Version-pinned scheduling and run deep-links — #9444 lets you schedule a specific agent version instead of whatever is currently published, and #9332 lets you open a graph by version and execution id. Together these are a real reproducibility/debugging win: pin scheduled jobs to known-good builds and jump straight to a failed execution rather than hunting through logs.
  • Richer extraction blocks — #9450 adds a dedicated XML Parser block, while #9470 gives ExtractTextInformationBlock batch matched results plus a match count. Text extraction now surfaces all matches rather than a single hit — check any downstream nodes that assumed one result, since the output contract has effectively expanded.
  • Python 3.10 support and friendlier local dev — #9468 adds official Python 3.10 compatibility, and #9441 stops the backend from throwing when the Stripe env var is absent. Contributors and self-hosters can now run a local, billing-free setup without crashes — a meaningful lowering of setup friction, not just a patch.
  • Google Cloud Storage major bump — #9399 moves google-cloud-storage from 2.19.0 to 3.0.0 in the backend. A major version can carry API/behavior changes, so regression-test any GCS-backed storage paths even though the changelog flags nothing as broken.
  • Builder and workflow polish — #9435 improves builder performance, #9439 fixes edge ("bead") rendering when a block output is an array, #9443 fixes pasting blocks, and #9428 renames the Credits page to Billing with a low-balance toast. Incremental but high-frequency quality-of-life fixes for anyone building graphs daily.
  • Breaking changes — None documented in this release.
