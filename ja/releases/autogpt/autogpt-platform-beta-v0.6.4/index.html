AutoGPT autogpt-platform-beta-v0.6.4

Highlights

  • RabbitMQ replaces the RPC-based execution queue — The execution queue and cancel mechanism were migrated to RabbitMQ (#9759) and the RPC service was removed from the Agent Executor (#9804). This is an infrastructure change, not UI polish: self-hosters must provision RabbitMQ and rework any custom integrations that depended on the old RPC service. Treat this as a breaking change if you run the platform yourself.

  • New observability and onboarding — Sentry environment tracking was added to the frontend and initialized in app services (#9773), and Onboarding Phase 2 shipped (#9736). These matter most to platform operators (error visibility) and to new users being guided through setup.

  • Database schema cleanup may require a migration — Library & Store DB schema was cleaned up (#9774), unchecked Prisma statements were fixed (#9805), and infrastructure pooling was improved (#9812). Check whether your deployment needs a Prisma migration before upgrading.

  • Skip if you're not self-hosting — The rest of the release is UI/UX fixes (store card styling, header/divider margins, marketplace newline rendering, miscellaneous UI bugs #9769/#9757/#9808/#9800). If you consume the hosted AutoGPT service rather than self-hosting the platform, there's little here that affects you.
