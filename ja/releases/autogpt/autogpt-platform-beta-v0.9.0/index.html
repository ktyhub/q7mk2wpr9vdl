  • Breaking: the classic layout is gone — #15106 deletes the classic layout and serves the sidebar layout to everyone, with no opt-back-in flag, so custom styling, screenshots, and user docs that assume the old chrome are stale. The accompanying mobile chat/sidebar polish (#15500, #15545, #15769) is now the only UI you ship, so budget a visual QA pass if you have heavy UI customization.

  • Breaking: plan gating gets stricter for free accounts — #15676 blocks accounts without an active plan from uploading, previewing, publishing, or connecting tools, while #15184 gives new free trials a single $20 CoPilot budget and #15208 resets usage on conversion to Pro/Max. If your workflow depends on free-tier file or tool access, validate this before upgrading; for paying teams it's mostly a billing-semantics change.

  • Auto's approval behavior changed, not just its UI — every block now declares its effect (#14981), letting Auto execute cheap outward actions itself and pause before costly ones; the chat approval gate also answers review pauses of workflows it started (#15564), and experts get a per-expert default approval mode for new web chats (#15115). Existing agent flows that relied on old auto-approve/always-ask behavior should be re-tested, since interruption patterns will differ.

  • A broad frontend performance pass is the main upgrade hook — transcript virtualization (#15740), memoized MessageRow rendering (#15715), lazy-loaded mermaid/shiki with 1-in-10-session profiling (#15712), and a long builder series (#15683, #15689, #15711, #15726) all attack render churn. Anyone using the web UI daily should upgrade for responsiveness; API-only or headless consumers can largely skip this release's headline value.

  • Self-hosting got easier but ops surface grew — the Docker Hub image and Windows installer (#14553) lower the self-host bar, yet browser (#15859) and Ollama (#15986) block traffic now routes through an egress proxy, internal service calls require a shared key (#15949), Claude Code CLI starts from an allow-listed environment (#15951), and IPv6 forms of blocked addresses are filtered (#15926). Self-hosters must configure these or expect broken blocks; the privacy fixes (#15705 stops sending emails/IPs to Sentry and masks replays, #15485 deletes onboarding voice recordings after transcription) are worthwhile but not a standalone reason to upgrade.
