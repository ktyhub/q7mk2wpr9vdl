AutoGPT autogpt-platform-beta-v0.6.34

Highlights

  • Shared caching — #11150 adds shared cache functionality to reduce duplicate work across execution paths. Review freshness and invalidation assumptions before caching mutable or user-specific data.
  • Safer JSON and template handling — SafeJson now prevents invalid \escape failures (#11187) and handles nested Pydantic models (#11188). TextFormatter reports Jinja errors as ValueError (#11236), so update exception handling if you previously caught Jinja-specific exceptions.
  • Credit correctness and migrations — Credit operations no longer depend on advisory locks (#11143), while #11192 fixes UserBalance migration and credit-spending bugs. Self-hosted deployments should back up balances and verify migrated records and concurrent debits before resuming traffic.
  • More resilient integrations — Linear OAuth now uses refresh tokens (#10998), reducing reauthentication interruptions; ensure credential storage supports refreshed tokens. LaunchDarkly initialization handles failures and runs only once (#11221, #11222), while its metrics integration is disabled (#11217), reducing retry risk but changing flag-service telemetry.
  • Tighter executor and API boundaries — The executor no longer runs direct queries (#11224), URL sanitization addresses substring-matching issues (#11232), and undefined query parameters are removed (#11238). Retest custom nodes and clients that relied on executor SQL, loose URL checks, or literal undefined parameters.
  • Breaking changes — None explicitly listed.
