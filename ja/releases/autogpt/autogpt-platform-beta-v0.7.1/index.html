AutoGPT autogpt-platform-beta-v0.7.1

Highlights

  • Single-container self-hosting — #13758 adds a single-container distribution, with image publishing and dispatch workflows in #13994/#13995. Combined with service-supervision hardening (#13755) and same-origin routing support (#13757), this offers a simpler deployment path; validate restarts and reverse-proxy routing before replacing a multi-container setup.

  • Expert scheduling is now end to end — #13772/#13787 connect triggers, thread posts, attribution, credit guardrails, and scheduling UI. #13798 stamps expert_id on schedules created from expert chat, so integrations should preserve that identifier and account for credit policy when designing unattended runs.

  • Expanded model and provider support — Tavily blocks (#13499) cover search, extract, crawl, and map; Claude Sonnet 5 receives tokenizer-aware support (#13629). ChatGPT/Codex subscription transport is preview-only (#13761), so validate authentication, tool behavior, and usage accounting before relying on it in production.

  • Tenant isolation and upgrade safety — #13745 assigns tenant ownership when executions, library items, and notifications are created instead of relying on a startup backfill, while #13591 excludes soft-deleted organizations from migration joins. Multi-tenant upgrades should still audit existing records and organization mappings rather than assume old data was retroactively repaired.

  • Onboarding persistence changes shape — #13119 replaces the Prisma OnboardingStep enum with String[]. Custom Prisma consumers, onboarding logic, and seed fixtures must handle arrays instead of scalar enum values. #13796 also recreates analytics views around onboarding retyping, so check downstream reporting dependencies after upgrading.

  • Runtime security fixes require rebuilt artifacts — #13782/#13781 patch or remove vulnerable runtime dependencies, #13783 addresses test tooling, and #13784 updates LangSmith. Rebuild and redeploy images rather than only updating source; the changelog does not enumerate advisories or severities. No breaking changes are explicitly declared.
