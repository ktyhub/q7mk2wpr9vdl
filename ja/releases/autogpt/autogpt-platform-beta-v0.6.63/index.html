AutoGPT autogpt-platform-beta-v0.6.63

Highlights

  • AutoPilot gets smarter and runs without an API key — Copilot now inserts a goal-decomposition step before agent building (#12731), gated by a library-similarity check (#13242), and can auto-discover MCP integrations when no native block exists (#13117). A local-LLM AutoPilot path (#12993) targets no-API-key installs, and "Copilot skills" is renamed to "AutoPilot skills" (#13270) — a label/UI change rather than an API break.

  • ExecutionContext plumbing and block execution — ExecutionContext is now carried at the direct-block-execute boundary (#13236) with user_timezone in run_block (#13247), and credential input masks are forwarded to tool-node execution (#13151), which matters if you depend on secrets being redacted during tool runs. Blocks also gain variable inputs for Execute Code (#13300), file inputs for the Replicate model block (#13272), and bounded CountdownTimerBlock inputs (#13237).

  • BREAKING / migration for self-hosted Postgres — the vector (pgvector) extension is moved to the extensions schema (#11902), so self-hosters must adjust search_path/migrations or unqualified vector references will break. The backend image now bundles libatomic1 so Prisma migrate boots (#13258), and webhook presets are auto-migrated to the new agent version (#12753). Review the DB migration before upgrading.

  • New search and artifact surfaces, one feature-flagged — a global search endpoint with a bucketed command-palette modal (#13217) gains navigate and action sections (#13283), plus optimized file preview with rich artifact cards (#13281) and an Artifacts page behind ARTIFACTS_PAGE (#13230); creator search (#13142) and mobile AutoPilot parity (#13232) also improve. Flag-gated, so low risk to adopt.

  • Billing enforcement and Discord bot hardening — upgrade verdict — bidirectional Stripe tier reconciliation with provenance and periodic sweep (#13284), NO_TIER in admin rate-limit display and one aggregated reconciliation Discord alert (#13291), DataFast attribution (#13288), and paywall enforcement on create-chat-session (#13320) make this worth upgrading for billing-affected deployments. The Discord bot also gains full thread history (#13323), workspace artifacts on replies (#13294), usage analytics (#13325, #13326), and thread hygiene (#13267, #13268, #13269, #13295). Upgrade if you use AutoPilot, the Discord bot, or Stripe billing; schedule the pgvector migration first if you self-host, and skip this beta if none of these paths apply to you.
