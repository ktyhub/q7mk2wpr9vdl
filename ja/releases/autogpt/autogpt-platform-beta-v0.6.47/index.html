AutoGPT autogpt-platform-beta-v0.6.47

Highlights

  • Expanded content-processing blocks — Text encoding (#11857) and video editing (#11796) add native workflow primitives, reducing the need for custom blocks in text and media pipelines.
  • Stronger Claude options — Claude Opus 4.6 support (#11983) and extended thinking for Claude models (#12052) give builders another model choice and deeper reasoning capability; thinking-enabled runs may consume more tokens and take longer.
  • Smoother agent creation and streaming — Custom AI SDK streaming with tailored response handling (#11901), StreamHeartbeat support (#11928), generation progress, and ready-to-test prompts (#11974, #11975) reduce ambiguous generation states and shorten the path to an agent’s first run. The edit_agent fix also prevents edits from creating duplicate agents (#11981).
  • File and credential security hardening — ClamAV scanning now covers local file paths and WorkspaceManager.write_file() (#11988, #11990), while run_agent filters host-scoped credentials (#11905). Self-hosted deployments should verify ClamAV availability and account for file writes passing through scanning.
  • Runtime behavior worth reviewing — ExecutionQueue now uses a thread-safe queue instead of multiprocessing (#11618), so custom execution integrations should recheck process-isolation and thread-safety assumptions. /api/graphs is cheaper and faster (#11986), stale RabbitMQ channels are handled (#11929), and YouTube block consumers should expect error-only output on failure (#11980). Custom ToolAccordion callers must also stop passing the removed defaultExpanded prop (#12054).
  • Breaking changes — None explicitly announced.
