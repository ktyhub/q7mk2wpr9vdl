何が変わったのか

🚀 機能

  • https://github.com/InternLM/lmdeploy/pull/4688 の @grimoire によるロングコンテキストおよび MTP プレフィックス キャッシュ ヒットをサポート
  • [機能] https://github.com/InternLM/lmdeploy/pull/4559 の @windreamer による投機的デコードのガイド付きデコード サポートを追加
  • feat(turbomind): https://github.com/InternLM/lmdeploy/pull/4717 の @lzhangzz によるメモリ アロケータ、オブジェクト キャッシュ、およびスケジューラの統合
  • 功績: @irexyc による AgRs all2all バックエンドの追加 (https://github.com/InternLM/lmdeploy/pull/4739)
  • https://github.com/InternLM/lmdeploy/pull/4554 の @grimoire による DeepSeek V4 サポート
  • https://github.com/InternLM/lmdeploy/pull/4767 で @lvhan028 による memdecode をサポート

💥改善点

  • https://github.com/InternLM/lmdeploy/pull/4705 の @jinminxi104 による上昇時の直線的注意のために blksize=128 を強制します
  • リファクタリング: https://github.com/InternLM/lmdeploy/pull/4644 の @CUHKSZzxy によるインターリーブ MRoPE ロータリー埋め込みを統合
  • https://github.com/InternLM/lmdeploy/pull/4711 の @jinminxi104 による ascend-A3 でのマルチノード サポートを改良
  • [改善]: https://github.com/InternLM/lmdeploy/pull/4682 の @RunningLeon によって lmdeploy から dlblas を削除
  • https://github.com/InternLM/lmdeploy/pull/4709 の @grimoire による h2d の同期を待機イベントに置き換えます
  • https://github.com/InternLM/lmdeploy/pull/4712 で @lvhan028 によってプロキシ URL が設定されている場合、DP モードで --server-port を尊重します。
  • https://github.com/InternLM/lmdeploy/pull/4716 の @lvhan028 により、テキストのみの VLM 推論用に -- language-model-only を追加し、 --disable-vision-encoder を削除しました
  • https://github.com/InternLM/lmdeploy/pull/4695 の @grimoire による TTFT の最適化
  • BaseResponseParser ストリーミングを最適化し、https://github.com/InternLM/lmdeploy/pull/4697 の @lvhan028 によるパーサー ベンチマークを追加
  • https://github.com/InternLM/lmdeploy/pull/4740 の @RunningLeon による qwen3.5 の場合のみ fp8 moe をサポート
  • https://github.com/InternLM/lmdeploy/pull/4729 の @grimoire によるスリープ中のランタイム状態のクリア
  • feat(serve): https://github.com/InternLM/lmdeploy/pull/4708 の @lvhan028 によるサーバー サンプリングのデフォルト用に --generation-config CLI を追加
  • 修正: https://github.com/InternLM/lmdeploy/pull/4747 の @CUHKSZzxy によってデフォルトで gzip トーチ プロファイラ トレースがトレースされる
  • https://github.com/InternLM/lmdeploy/pull/4751 の @grimoire により、エキスパートごとに小規模な平均ルーターの tp fp8 moe を最適化します。
  • リファクタリング(pytorch): https://github.com/InternLM/lmdeploy/pull/4727 の @grimoire によるスケジューラと入力メーカーの制御フローを明確にする
  • https://github.com/InternLM/lmdeploy/pull/4738 の @grimoire による保留中の作業の周りに DP ダミー入力をガードします
  • インタラクティブ チャットを削除し、推論をステートレスにします (https://github.com/InternLM/lmdeploy/pull/4730 の @lvhan028 による)
  • 偉業(turbomind): https://github.com/InternLM/lmdeploy/pull/4769 の @lzhangzz による、コンポーズ可能な TurboMind 並列構成の導出
  • https://github.com/InternLM/lmdeploy/pull/4757 の @lzhangzz による汎用テンソル コピーとアーキテクチャを意識したゲート デルタ ルールのサポートを追加
  • https://github.com/InternLM/lmdeploy/pull/4779 の @lzhangzz による GDR CP コントロールとレガシー カーネル オーバーライドを追加
  • fix(turbomind): https://github.com/InternLM/lmdeploy/pull/4790 の @lzhangzz による Qwen3.5 のゼロ中心 RMSNorm を修正
