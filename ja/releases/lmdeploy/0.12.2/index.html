何が変わったのか

🚀 機能

  • https://github.com/InternLM/lmdeploy/pull/4355 の @grimoire による glm5 をサポート
  • Qwen/Internlm/Llama Dense/Moe モデル fp8 quant オンライン by @43758726 (https://github.com/InternLM/lmdeploy/pull/4324)
  • Qwen3.5 by @grimoire (https://github.com/InternLM/lmdeploy/pull/4351)
  • GLM-4.7-Flash Turbomind のサポート (https://github.com/InternLM/lmdeploy/pull/4362 の @lapy による)
  • https://github.com/InternLM/lmdeploy/pull/4394 の @RunningLeon による qwen3.5 のルーター リプレイをサポートし、Quant Layer を無視する
  • [機能] https://github.com/InternLM/lmdeploy/pull/4389 の @lapy による Qwen3.5 モデル (dense + MoE) の TurboMind サポートを追加
  • https://github.com/InternLM/lmdeploy/pull/4288 の @grimoire による反復 ngram ロジッツ プロセッサをサポート

💥改善点

  • https://github.com/InternLM/lmdeploy/pull/4304 の @lvhan028 による TurboMind 側の変圧器 5.0 と互換性があります
  • https://github.com/InternLM/lmdeploy/pull/4160 の @RunningLeon による qwen および internlm モデルの fp32 ヘッドをサポート
  • https://github.com/InternLM/lmdeploy/pull/4373 の @lzhangzz によって MLA kv キャッシュ メモリを削減
  • https://github.com/InternLM/lmdeploy/pull/4376 の @grimoire により recurrent_gated_delta_rule カーネルを追加
  • [ascend] s1-pro dp*tp+ep に適応 (https://github.com/InternLM/lmdeploy/pull/4380 の @yao-fengchen による)
  • https://github.com/InternLM/lmdeploy/pull/4346 の @RunningLeon による mtp で glm4.7 をサポート
  • https://github.com/InternLM/lmdeploy/pull/4391 の @lzhangzz による高速 MLA カーネル
  • https://github.com/InternLM/lmdeploy/pull/4396 の @lzhangzz によるカーネルの自己登録と分離されたディスパッチングに注意してください

🐞 バグ修正

  • 修正: https://github.com/InternLM/lmdeploy/pull/4363 の @murray-macdonald による RepetitionPenaltyKernel のデバッグ ログを ERROR から DEBUG に変更
  • https://github.com/InternLM/lmdeploy/pull/4369 の @RunningLeon による internvl awq モデルの quant config 解析を修正
  • XGrammar ビットマスクの初期化を修正し、https://github.com/InternLM/lmdeploy/pull/4349 の @windreamer による生成メソッドで gen_config の null チェックを追加
  • https://github.com/InternLM/lmdeploy/pull/4370の@lvhan028によるセッション終了のロジックを修正
  • https://github.com/InternLM/lmdeploy/pull/4338 の @lvhan028 による承認を修正
  • いくつかの小さな問題を修正し、https://github.com/InternLM/lmdeploy/pull/4365 の @windreamer によるパイプラインのテストを提供
  • https://github.com/InternLM/lmdeploy/pull/4278 の @grimoire による set_step の dllm マスクを修正
  • https://github.com/InternLM/lmdeploy/pull/4381 の @grimoire によるトランスフォーマー >=5 のモデルを修正
  • https://github.com/InternLM/lmdeploy/pull/4403 で @lvhan028 によるリクエストを中止するときの例外を修正
  • https://github.com/InternLM/lmdeploy/pull/4420 の @lvhan028 による、qwen3.5-0.8b を使用する v100 で推論がクラッシュする問題を修正

🌐 その他

  • ci(lint): https://github.com/InternLM/lmdeploy/pull/4357 の @windreamer による python Wiki ページの不安定なデッドリンク テストをスキップします。
  • https://github.com/InternLM/lmdeploy/pull/4361 の @irexyc による fa3 インストールを修正
  • https://github.com/InternLM/lmdeploy/pull/4375 の @windreamer による lint を修正
  • https://github.com/InternLM/lmdeploy/pull/4379 の @grimoire によるトリトンとトーチのアップグレード
  • https://github.com/InternLM/lmdeploy/pull/4377 に @littlegy による投機的復号テストを追加
  • ci: https://github.com/InternLM/lmdeploy/pull/4390 の @windreamer により、clang 形式の lint をコミット前フックに統合
  • https://github.com/InternLM/lmdeploy/pull/4398 の @lvhan028 により、cu11 を削除し、cu12.4 を cu12.6 に変更して、dockerfile を更新します。
  • 開発イメージをバージョンごとに公開するのではなく、手動でビルドします (https://github.com/InternLM/lmdeploy/pull/4409 の @lvhan028 によって)
  • https://github.com/InternLM/lmdeploy/pull/4378 の @lvhan028 によりバージョンを v0.12.2 にバンプします

lmdeploy v0.12.2

<!-- Release notes generated using configuration in .github/release.yml at main -->

What's Changed

🚀 Features

  • support glm5 by @grimoire in https://github.com/InternLM/lmdeploy/pull/4355
  • Qwen/Internlm/Llama Dense/Moe model fp8 quant online by @43758726 in https://github.com/InternLM/lmdeploy/pull/4324
  • Qwen3.5 by @grimoire in https://github.com/InternLM/lmdeploy/pull/4351
  • GLM-4.7-Flash Turbomind support by @lapy in https://github.com/InternLM/lmdeploy/pull/4362
  • Support router replay and ignore quant layer for qwen3.5 by @RunningLeon in https://github.com/InternLM/lmdeploy/pull/4394
  • [Feature] Add TurboMind support for Qwen3.5 models (dense + MoE) by @lapy in https://github.com/InternLM/lmdeploy/pull/4389
  • support repetition ngram logits processor by @grimoire in https://github.com/InternLM/lmdeploy/pull/4288

💥 Improvements

  • Compatible with transformers 5.0 at TurboMind side by @lvhan028 in https://github.com/InternLM/lmdeploy/pull/4304
  • Support fp32 head for qwen and internlm models by @RunningLeon in https://github.com/InternLM/lmdeploy/pull/4160
  • Reduce MLA kv-cache memory by @lzhangzz in https://github.com/InternLM/lmdeploy/pull/4373
  • add recurrent_gated_delta_rule kernel by @grimoire in https://github.com/InternLM/lmdeploy/pull/4376
  • [ascend]adapt for s1-pro dp*tp+ep by @yao-fengchen in https://github.com/InternLM/lmdeploy/pull/4380
  • Support glm4.7 with mtp by @RunningLeon in https://github.com/InternLM/lmdeploy/pull/4346
  • Faster MLA kernels by @lzhangzz in https://github.com/InternLM/lmdeploy/pull/4391
  • Attention kernel self-registration and decoupled dispatching by @lzhangzz in https://github.com/InternLM/lmdeploy/pull/4396

🐞 Bug fixes

  • fix: change debug log from ERROR to DEBUG in RepetitionPenaltyKernel by @murray-macdonald in https://github.com/InternLM/lmdeploy/pull/4363
  • Fix quant config parsing for internvl awq model by @RunningLeon in https://github.com/InternLM/lmdeploy/pull/4369
  • Fix XGrammar bitmask initialization and add null check for gen_config in generate method by @windreamer in https://github.com/InternLM/lmdeploy/pull/4349
  • fix the logic of closing session by @lvhan028 in https://github.com/InternLM/lmdeploy/pull/4370
  • Fix authorization by @lvhan028 in https://github.com/InternLM/lmdeploy/pull/4338
  • Fix some minor issues and provide tests for Pipeline by @windreamer in https://github.com/InternLM/lmdeploy/pull/4365
  • fix dllm mask on set_step by @grimoire in https://github.com/InternLM/lmdeploy/pull/4278
  • fix models for transformers>=5 by @grimoire in https://github.com/InternLM/lmdeploy/pull/4381
  • fix exception when aborting a request by @lvhan028 in https://github.com/InternLM/lmdeploy/pull/4403
  • fix inference crashed on v100 with qwen3.5-0.8b by @lvhan028 in https://github.com/InternLM/lmdeploy/pull/4420

🌐 Other

  • ci(lint): skip flaky deadlink test for python wiki page by @windreamer in https://github.com/InternLM/lmdeploy/pull/4357
  • fix fa3 install by @irexyc in https://github.com/InternLM/lmdeploy/pull/4361
  • fix lint by @windreamer in https://github.com/InternLM/lmdeploy/pull/4375
  • upgrade triton and torch by @grimoire in https://github.com/InternLM/lmdeploy/pull/4379
  • Add speculative decoding test by @littlegy in https://github.com/InternLM/lmdeploy/pull/4377
