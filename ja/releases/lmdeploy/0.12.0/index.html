🚀 機能

  • https://github.com/InternLM/lmdeploy/pull/3362 の @irexyc によって Gloo 通信を Turbomind に追加

  • https://github.com/InternLM/lmdeploy/pull/4318 の @CUHKSZzxy による Intern-S1-Pro をサポート

💥改善点

  • https://github.com/InternLM/lmdeploy/pull/4227 の @lzhangzz による CUDA IPC コミュニケーターの最大 CTA と NVLS 使用量を構成可能
  • https://github.com/InternLM/lmdeploy/pull/4215 の @lvhan028 によるすべてのセッションの中止を改善

  • [AsyncEngine Refactor 1/N] https://github.com/InternLM/lmdeploy/pull/4250 の @lvhan028 によりマルチモーダル データ処理を処理する MultimodalProcessor を定義
  • [AsyncEngine Refactor 2/N] https://github.com/InternLM/lmdeploy/pull/4252 の @lvhan028 によりチャット テンプレートから非推奨を削除
  • https://github.com/InternLM/lmdeploy/pull/4255 の @CUHKSZzxy によって構成可能な uvicorn タイムアウト
  • https://github.com/InternLM/lmdeploy/pull/4242 の @JimyMa による dlsime v0.0.2 に適応します
  • [修正] https://github.com/InternLM/lmdeploy/pull/4256 の @43758726 によるクオント キャリブレーション データセットを修正
  • lmdeploy は、https://github.com/InternLM/lmdeploy/pull/4192 の @Tsundoku958 によるパラレル埋め込みをサポートします
  • https://github.com/InternLM/lmdeploy/pull/4223 の @lzhangzz による Turbomind エンジンのリファクタリング
  • リファクタリング エンジンと ModelAgent の対話 (https://github.com/InternLM/lmdeploy/pull/4265 の @grimoire による)
  • https://github.com/InternLM/lmdeploy/pull/4246 の @RunningLeon によるスリープのサポートと deepep バッファの破棄
  • https://github.com/InternLM/lmdeploy/pull/4301 に @grimoire による糸の切り捨てを追加
  • [AsyncEngine Refactor 3/N] @lvhan028 による Session と SessionManager を https://github.com/InternLM/lmdeploy/pull/4253 で紹介
  • https://github.com/InternLM/lmdeploy/pull/4313 の @lzhangzz による NCCL 2.27 メモリ リークに関する警告を追加
