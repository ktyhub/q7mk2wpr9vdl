svelte svelte@5.57.2

#スベルトスベルト@5.57.2

パッチの変更

  • 修正: 最上位の await を待機している間に破棄されたコンポーネントの非同期派生を作成しない (#18931)
  • 修正: 追跡されていない派生読み取りが切断された依存関係を保持しないようにします (#18829)
  • 修正: {:else} の後に別の {:else} または {:else if ...} が続く場合のエラー (#18900)
  • 修正: URL 更新中の SvelteURLSearchParams の追跡を回避します (#18791)
  • 修正: カスタム要素属性の更新スロー時にハイドレーション状態を復元する (#18467)
  • 修正: 本番環境でトップレベルの await の後に割り当てられるイベント ハンドラーをアタッチする (#18933)
  • 修正: flashSync コールバック関数を呼び出す前に保留中のものをすべてフラッシュする (#18878)
  • 修正: await ラッパーの位置情報を保持する (#18859)
  • 修正: migrate が宣言に変換できない場合、依存関係のないリアクティブな割り当てを維持します (#18817)
  • 修正: スクリプト タグと行を共有する宣言で migrate をハングしないようにしました (#18816)
  • 修正: 派生接続の再接続時にサブスクリプションが重複しないようにしました (#18899)
  • 修正: ハイドレーション中に予期しないノードがネストされた境界コメントを置き換えた場合に回復します (#18925)
  • 修正: 保留中の分岐のみを持つ {#await} ブロックを出力する (#18908)
  • 修正: href のない <area> 要素の冗長な link ロールについて警告しない (#18872)
  • 修正: bind:activeElement の使用中にフォーカスされた要素が削除された場合に state_unsafe_mutation をスローしないようにしました (#18921)
  • 修正: 不完全な数値入力を保持して、未変更のスプレッド value を上書きしないようにしました (#18864)
  • 修正: 各ブロックのコミットでバッチローカル配列を読み取る (#18879)
  • 修正: スニペット内の宣言がパラメータの 1 つを再宣言する場合のコンパイル時のエラー (#18842)
  • 修正: children スニペットを持つコンポーネントで let: ディレクティブを使用するとエラーが発生する (#18873)
  • 修正: 古い境界リセット コールバックを無視する (#18886)
  • 修正: 初期化前に中断された遅延トランジションのハンドル (#18776)
  • 修正: 水和不一致の回復がエラー境界によって中断されるのを防ぎます (#18841)
  • 修正: ハイドレーション中に動的要素の接続を保持する (#18855)

svelte svelte@5.57.2

Patch Changes

  • fix: don't create async deriveds for a component destroyed while waiting for its top-level await (#18931)

  • fix: prevent untracked derived reads from retaining disconnected dependencies (#18829)

  • fix: error if {:else} is followed by another {:else} or {:else if ...} (#18900)

  • fix: avoid tracking SvelteURLSearchParams during URL updates (#18791)

  • fix: restore hydration state when custom element attribute updates throw (#18467)

  • fix: attach event handlers that are assigned after a top-level await in production (#18933)

  • fix: flush anything pending before invoking flushSync callback function (#18878)

  • fix: preserve location information for await wrappers (#18859)

  • fix: keep a reactive assignment with no dependencies when migrate cannot turn it into a declaration (#18817)

  • fix: don't hang migrate on a declaration that shares a line with its script tag (#18816)

  • fix: prevent duplicate subscriptions when reconnecting deriveds (#18899)

  • fix: recover when an unexpected node replaces a nested boundary comment during hydration (#18925)

  • fix: print {#await} blocks that only have a pending branch (#18908)

  • fix: don't warn about a redundant link role on <area> elements without an href (#18872)

  • fix: don't throw state_unsafe_mutation when the focused element is removed while bind:activeElement is used (#18921)

  • fix: don't overwrite an unchanged spread value, preserving incomplete number input (#18864)

  • fix: read batch-local array on each-block commit (#18879)

  • fix: error at compile time when a declaration in a snippet redeclares one of its parameters (#18842)

  • fix: error when using let: directives on a component with a children snippet (#18873)

  • fix: ignore stale boundary reset callbacks (#18886)

  • fix: handle deferred transitions aborted before initialization (#18776)

  • fix: prevent hydration mismatch recovery from being intercepted by error boundaries (#18841)

  • fix: preserve dynamic element connections during hydration (#18855)
