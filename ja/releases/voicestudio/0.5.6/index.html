VoiceStudio v0.5.6

パッチ 公開日2026年9月23日 出典debpalash/VoiceStudio English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ボイススタジオv0.5.6

VoiceStudio は他のツールと通信できるようになりました。 保存された音声で Twilio の通話に応答し、Claude Code、Cursor、Codex CLI および OpenAI Agents SDK を、コピー可能な設定で VoiceStudio に接続します。これには、MCP が以前に HTTP 405 を返していた Docker も含まれます。統合カードには、どれが VoiceStudio で動作し、どれが外部リンクであるかが明確に表示されるようになりました。

このリリースでは、保存されたクローンのリファレンス サンプルを置き換えたり、OmniVoice で長いリファレンス clips をクローンしたり、8 GB GPU でオーディオブックの長いチャプタを終了したり、電源オフまたはデータ フォルダの移動を通じてレンダリングされたチャプタを保持したりすることもできます。

ダウンロード

|プラットフォーム |インストーラー | | --- | --- | | Windows x64 | インストーラー | | macOS Appleシリコン | DMG | | macOS インテル | DMG | | Linux x64 | AppImage · デブ |

アップグレード: 既存の Electron アプリを上書きインストールします。音声、プロジェクト、設定は保持されます。セットアップで尋ねられたら、[ローカル ランタイムのインストール] を選択して依存関係を更新します。 /mcp で構成された MCP client は動作し続けます。新しいエクスポートでは /mcp/ を使用します。 OpenAI 互換の /v1 clients では、HTTP 422 ではなく 400 で OpenAI 形式のエラーが発生し、response_format="mp3" は本物の MP3 を返します。

Tauri からの移行: Tauri を削除する前に、アプリを閉じ、データ ディレクトリをバックアップし、Electron をインストールし、音声とプロジェクトを確認します。 移行ガイドに従ってください。 Tauri v0.5.3 は、Tauri の最終リリースのままです。そのアップデーターは Electron をインストールできません。

インストーラー trust: Electron インストーラーは未署名またはアドホック署名されており、Apple によって公証されていません。 Windows/macOS では、trust 警告が表示される場合があります。 macOS の自動アップデートは未検証です。手動インストーラー更新を使用してください。 インストールガイドを参照してください。

ハイライト

  • 保存された音声の挨拶で Twilio 電話に応答します。デフォルトではオフ、ローカル電話品質テストあり (#2291)
  • クロード コード、カーソル、コーデックス CLI および OpenAI エージェント SDK が、動作するセットアップで VoiceStudio に接続します (#2289、#2290)
  • 保存されたクローンのリファレンス サンプルを置き換え、OmniVoice で 20 秒を超えるリファレンスからクローンを作成します (#2282、#2281) — @Cengokill に感謝します。
  • オーディオブックの長いチャプターは 8 GB GPU で終了し、電源オフやデータ フォルダーの移動後も存続します (#2287、#2279) — @Tran-Van-Hieu と @castlecreati に感謝します。
  • マラヤーラム語番号、章のキューシート、および音声マークアップタグのないキャプション (#2280、#2278、#2295) — @nikhilkilivayil、@shivsin25、@kevin9327 に感謝します。

変更されました

  • Voice Clone は、15 秒にトリミングするように要求する代わりに、アクティブなエンジンが使用する長い参照の量を表示します (#2281) — @Cengokill に感謝します!

追加

  • 保存した音声クローンのリファレンス サンプルを編集します。再生し、アップロードまたは録音して置き換え、同じ音声 (#2282) に戻して保存します。@Cengokill に感謝します。
  • 保存された音声で Twilio 電話に応答: デフォルトではオフ、署名付き Webhook と使い捨てストリーム トークン、ローカル電話品質テスト (#2291)
  • マラヤーラム語の吹き替えとオーディオブックでは、生の数字を読む代わりに、マラヤーラム語で数字、パーセンテージ、小数点を読み上げます (#2280) — @nikhilkilivayil に感謝します!
  • ストーリーまたはオーディオブックのレンダリング後にチャプター キュー シート (HH:MM:SS<TAB>Title) をダウンロードします。タイムスタンプは M4B の埋め込みチャプターと一致し、MP3 ポータブル チャプター (#2278) を与えます — @shivsin25 に感謝します!
  • OpenAI Agents 統合ページには、VoiceStudio で Agents SDK 音声パイプラインを実行するコピー可能なスニペットが含まれています (#2290)
  • OpenAI 互換の API に GET /v1/models と POST /v1/audio/translations が追加されました (多言語の Whisper モデル。ターボ モデルは拒否されます) (#2290)
  • 音声リクエストは、stream_format (audio または sse) および OpenAI の {"id": ...} 音声オブジェクト (#2290) を受け入れます。
  • 転写は、language、prompt、temperature を Whisper エンジンに渡し、words を timestamp_granularities[]=word (#2290) で返します。
  • 統合: Codex CLI (config.toml)、任意の MCP client (HTTP または stdio)、VoiceStudio API (curl および OpenAI SDK)、および Docker/GHCR (#2289) のコピー可能なセットアップ

修正済み

  • 貼り付けてインポートしたキャプションは、カラオケ タグ、<i>/<font> タグ、または {\an8} アライメント プレフィックスを読み上げなくなりましたが、2 < 3 などの SubRip ダイアログは保持されます。変更されていない WebVTT および SubRip エクスポートでは、元のキュー マークアップ (#2295) が維持されます — @kevin9327 に感謝します!
  • 音声を保存し、20 秒を超えるクローンを OmniVoice に再度アップロードします。最適なパッセージが自動的に選択されます (#2281) — @Cengokill に感謝します!
  • VoxCPM2 は、キャップ付き参照と clip 全体の転写物をペアにしなくなりました (#2281)
  • 話者のダイアライゼーションには Lightning 2.6.6 が使用され、細工されたチェックポイントからのコードの実行がブロックされます (#2296)
  • 8 GB GPU 上の長いオーディオブックのチャプターがレンダリング中にタイムアウトしなくなり、タイムアウトしたチャプターは現在のチャンク (#2287) の後で GPU の使用を停止します — @Tran-Van-Hieu に感謝します。
  • Windows では、1 つのリセット接続でバックエンドが実行中であるにもかかわらず到達不能のままになることはなくなりました (#2276) — @ialexbond に感謝します!
  • 公式 openai SDK および OpenAI エージェント SDK は変更なく動作します: gpt-4o-mini-tts および現在の OpenAI 音声名は「不明なモデル」で失敗しなくなりました (#2290)
  • OpenAI instructions は無視されるのではなく、音声エンジンに到達するようになりました。 OmniVoice では音声デザイン タグが使用されています (#2290)
  • OpenAI の仕様に従って、音声 pcm は 24 kHz です。 aac と opus は実際の AAC と Opus を返し、エンコーダーが見つからない場合はラベルが間違っている WAV ではなく明らかなエラーです (#2290)
  • 文字起こしでは、常に英語を言うのではなく、検出された言語が報告され、verbose_json セグメントは OpenAI のスキーマに従います (#2290)
  • OpenAI 互換ルートは OpenAI の形式でエラーを返し、無効なリクエストには 400 が返されます (#2290)
  • レンダリングされたオーディオブックのチャプターはデータ フォルダーの移動後も再利用可能であり、電源をオフにしても再開ポイントが空になったり、チャプターの音声が途切れたりすることはなくなりました (#2279) — @castlecreati に感謝します!
  • オーディオブックのチャプターキャッシュミスが、キャッシュされたレンダリング以降にどの入力が変更されたかを記録するようになりました (#2279)
  • /mcp を指す MCP clients は、HTTP 405 を取得する代わりに Docker で接続し、ソース ビルドを実行します (#2289)
  • MCP ツールと backend.speech_client は、ポート 3900 (#2289) を想定するのではなく、OMNIVOICE_PORT で移動されたバックエンドに従います。
  • 統合カードは実際の機能を示します: セットアップが存在する場合のみ「VoiceStudio で動作」、それ以外の場合は「外部リンク」 (#2289)

ドキュメント

  • エンジンガイドのエンジンごとのリファレンス clip 制限 (#2281)
  • プロンプトを使用してインストールが 2 行のプロンプトになりました。エージェントの完全な手順は docs/install/agent.md にあります (#2288)

貢献者

  • @nikhilkilivayil — マラヤーラム語の数字の言語化 (#2280)。
  • @shivsin25 および @Shivendra-Coherent — チャプターキューシートのエクスポート (#2278)。
  • @kevin9327 — 吹き替え用のキャプション マークアップの除去 (#2295)。
  • @debpalash — 統合 (Twilio、MCP、OpenAI SDK)、音声クローン、オーディオブックの信頼性、Windows バックエンド、セキュリティ アップデート、リリース検証。

VoiceStudio v0.5.6

Highlights

  • Integrations are the headline — v0.5.6 turns VoiceStudio into a hub: answer Twilio calls in a saved voice (off by default, signed webhooks, single-use stream tokens, #2291), and copyable setup now genuinely works for Claude Code, Cursor, Codex CLI and the OpenAI Agents SDK (#2289, #2290), including in Docker where MCP previously returned HTTP 405. If you've been trying to wire an agent or MCP client in, this is the release that makes it work instead of leaving you with a broken endpoint.

  • Migration from Tauri is the main operational cost — This is the first Electron line: Tauri v0.5.3 is the final Tauri release and its updater cannot install Electron. Tauri users must close the app, back up the data directory, install Electron, and verify voices/projects before removing Tauri. Existing Electron users install over the app and keep data; choose Install local runtime if prompted. Installers are unsigned/ad-hoc and not Apple-notarized, and macOS auto-updates are unverified — use manual installer updates. Don't do this casually on a locked-down Mac.

  • OpenAI-compatible API changed its contract — /v1 errors are now OpenAI-format with HTTP 400 instead of 422, response_format="mp3" returns real MP3, pcm is 24 kHz, and aac/opus return real codecs (missing encoder is a clear error, not mislabeled WAV). Added GET /v1/models, POST /v1/audio/translations (turbo models refused), stream_format (audio/sse), the {"id": ...} voice object, and transcription params (language, prompt, temperature, timestamp_granularities[]=word). Clients depending on 422 or the old WAV fallback need updating. Existing /mcp MCP clients keep working, new exports use /mcp/, and tools now follow a backend moved via OMNIVOICE_PORT instead of assuming port 3900.

  • Reliability and security improved materially — Long audiobook chapters finish on 8 GB GPUs without hanging and stop consuming GPU after a timed-out chunk (#2287), and rendered chapters survive power-offs and data-folder moves (#2279). Diarisation moves to Lightning 2.6.6, which blocks code execution from a crafted checkpoint (#2296) — a real security fix. Also fixes a Windows reset-connection dead backend (#2276) and captions speaking karaoke/<i>/{\an8} markup.

  • Verdict: upgrade for most, but mind the packaging — Worth it if you want MCP/agent integrations, Twilio, the OpenAI SDK, long-audiobook rendering on 8 GB GPUs, or the security fix; cloning also gains reference-sample replacement and >20 s OmniVoice references. You can reasonably skip if you're stable on Electron, don't need the new integrations, and want to avoid unsigned-installer trust friction — but Tauri users can't stay there forever, so plan the migration rather than treating this as optional.

VoiceStudio now talks to your other tools. Answer Twilio phone calls in a saved voice, and connect Claude Code, Cursor, Codex CLI and the OpenAI Agents SDK to VoiceStudio with copyable setup that works, including in Docker, where MCP previously returned HTTP 405. Integration cards now say plainly which ones work with VoiceStudio and which are external links.

This release also lets you replace a saved clone's reference sample, clones long reference clips on OmniVoice, finishes long audiobook chapters on 8 GB GPUs, and keeps rendered chapters through a power-off or data-folder move.

Highlights

  • Answer Twilio phone calls with a greeting in a saved voice; off by default, with a local phone-quality test (#2291)
  • Claude Code, Cursor, Codex CLI and the OpenAI Agents SDK connect to VoiceStudio with working setup (#2289, #2290)
  • Replace a saved clone's reference sample, and clone from references longer than 20 s on OmniVoice (#2282, #2281) — thanks @Cengokill!
  • Long audiobook chapters finish on 8 GB GPUs and survive a power-off or data-folder move (#2287, #2279) — thanks @Tran-Van-Hieu and @castlecreati!
  • Malayalam numbers, chapter cue sheets, and captions without spoken markup tags (#2280, #2278, #2295) — thanks @nikhilkilivayil, @shivsin25 and @kevin9327!

Changed

  • Voice Clone says how much of a long reference the active engine uses instead of asking you to trim to 15 s (#2281) — thanks @Cengokill!

Added

  • Edit a saved voice clone's reference sample: play it, replace it by upload or recording, and save back to the same voice (#2282) — thanks @Cengokill!
  • Answer Twilio phone calls in a saved voice: off by default, signed webhooks and single-use stream tokens, with a local phone-quality test (#2291)
  • Malayalam dubs and audiobooks speak numbers, percentages, and decimals in Malayalam instead of reading raw digits (#2280) — thanks @nikhilkilivayil!
  • Download a chapter cue sheet (HH:MM:SS<TAB>Title) after a Stories or Audiobook render; timestamps match the M4B's embedded chapters and give MP3 portable chapters (#2278) — thanks @shivsin25!
  • The OpenAI Agents integration page gives a copyable snippet that runs the Agents SDK voice pipeline on VoiceStudio (#2290)
  • The OpenAI-compatible API adds GET /v1/models and POST /v1/audio/translations (multilingual Whisper models; turbo models are refused) (#2290)
  • Speech requests accept stream_format (audio or sse) and OpenAI's {"id": ...} voice object (#2290)
  • Transcriptions pass language, prompt and temperature to Whisper engines and return words with timestamp_granularities[]=word (#2290)
  • Integrations: copyable setup for Codex CLI (config.toml), any MCP client (HTTP or stdio), the VoiceStudio API (curl and OpenAI SDK), and Docker/GHCR (#2289)

Fixed

  • Pasted and imported captions no longer speak karaoke tags, <i>/<font> tags or {\an8} alignment prefixes, while SubRip dialogue such as 2 < 3 is kept; unchanged WebVTT and SubRip exports keep the original cue markup (#2295) — thanks @kevin9327!
  • Saved voices and uploads longer than 20 s clone on OmniVoice again; the best passage is picked automatically (#2281) — thanks @Cengokill!
  • VoxCPM2 no longer pairs a capped reference with a transcript of the whole clip (#2281)
  • Speaker diarisation uses Lightning 2.6.6, which blocks code execution from a crafted checkpoint (#2296)
  • Long audiobook chapters on 8 GB GPUs no longer time out while still rendering, and a timed-out chapter stops using the GPU after its current chunk (#2287) — thanks @Tran-Van-Hieu!
  • On Windows, one reset connection no longer leaves the backend running but unreachable (#2276) — thanks @ialexbond!
  • The official openai SDK and OpenAI Agents SDK work unchanged: gpt-4o-mini-tts and current OpenAI voice names no longer fail with "Unknown model" (#2290)
  • OpenAI instructions now reaches the voice engine instead of being ignored; OmniVoice uses the voice-design tags in it (#2290)
  • Speech pcm is 24 kHz as OpenAI specifies; aac and opus return real AAC and Opus, and a missing encoder is a clear error instead of a mislabelled WAV (#2290)
  • Transcriptions report the detected language instead of always saying English, and verbose_json segments follow OpenAI's schema (#2290)
  • OpenAI-compatible routes return errors in OpenAI's format, with 400 for invalid requests (#2290)
  • Rendered audiobook chapters stay reusable after the data folder moves, and a power-off no longer empties the resume point or tears chapter audio (#2279) — thanks @castlecreati!
  • An audiobook chapter-cache miss now logs which input changed since the cached render (#2279)
  • MCP clients pointed at /mcp connect on Docker and source builds instead of getting HTTP 405 (#2289)
  • MCP tools and backend.speech_client follow a backend moved with OMNIVOICE_PORT instead of assuming port 3900 (#2289)
  • Integration cards show real capabilities: "Works with VoiceStudio" only where a setup exists, "External link" everywhere else (#2289)

Docs

  • Per-engine reference clip limits in the engine guide (#2281)
  • Install with prompt is now a two-line prompt; the full agent steps live in docs/install/agent.md (#2288)
