#ボイススタジオv0.5.0

ハイライト

  • アプリは VoiceStudio (以前は OmniVoice-Studio) になりました。これは、アプリ、ドキュメント、インストーラーにわたる 1 つの波形とスパークの ID です。データ フォルダー、設定、Docker イメージのパスはそのまま残ります。
  • モデル カタログ - 1 つのワークスペース内のエンジンとモデル: すべての TTS、トランスクリプション、LLM エンジンとそのデバイス ルーティングおよびインストール状態、そこで選択されたデフォルト。
  • ステータス バーまたは任意のワークスペースから TTS、ASR、および LLM エンジンを切り替えます。準備完了の選択肢、メモリ ステータス、環境ピン保護、Ctrl/Cmd+E。 (#1530)
  • 参加コードと QR スキャンを使用して別のマシンの GPU を貸与します。ステータス バーのコンピューティング コントロールによってジョブが実行される場所が選択され、取り消し可能な証明書で固定された接続を使用して 1 つの GPU ボックスを複数人で共有できます。 (#1516、#1496)
  • サーバー モードはロックダウンされています: 管理者のアクションには API キー (#1525) が必要で、リモート UI はブラウザ ストレージや WebSocket URL (#1528) に決して置かれない短期間のセッションとそれを交換します — ありがとう、bultodepapas!
  • プロダクション コマンド バーと言語ごとのカードを備えた、多言語プロダクション向けのより高速でクリーンなダブ ワークスペース。 (#1489)
  • アプリが常に宣伝していたデモのオーディオとビデオが、VoiceStudio 独自のエンジンによってレンダリングされて実際に出荷されるようになりました。 (#1517)
  • Wayland でディクテーションが機能するようになりました。ポータル ショートカットが実際に起動し (#1490、#1526)、録音機能がすべてのデスクトップに戻りました。
  • Launchpad は、プロジェクトの信号フィールド波形アートワークを、より静かでボーダーレスなレイアウト上に重ねて表示します。 (#1533)
  • カタログは破損ではなくヘッドルームとして読み取られます。利用可能なエンジンが最初に並べ替えられ、アンインストールされたエンジンは必要なものを示し (#1531)、LLM 行には実際に応答するプロバイダーの名前が付けられます (#1538)。
  • ギャラリーの音声はローカル プロファイルとして保存できます。オーディオは、検証済みのコンテンツ アドレス指定された参照とともにプロファイル ストアに保存されます。 (#1542)

変更されました

  • ギャラリー ペルソナは、ローカル バックエンドを通じてプレビューし、完全な音声デザイン レシピを保持し、音声、ストーリー、またはオーディオブックで直接開くことができるようになりました。 (#1542)
  • サポート額の選択では、すべてのテーマの共有カード、アクセント、フォーカス トークンが使用されるようになりました。 (#1530)
  • スポンサー、商用ライセンス、連絡先が 1 ページになりました。彼らは同じ質問に答え、それぞれが以前は別の場所に住んでいたため、1 つのスクロールに 3 つのセクションが表示されます。フッターの中心部、商用ライセンスのリンク、および連絡先はすべて、要求されたセクションに表示されます。 (#1522)
  • モデル カタログのペインは 2 状態切り替えではなくタブで切り替わり、エンジン互換性マトリックスの TTS / ASR / LLM スイッチャーもタブになり、矢印キーでナビゲート可能になり、各タブには使用するエンジンが表示されます。 (#1522)
  • 実際に使用できるエンジンは互換性マトリックスの先頭に並べられ、使用できないエンジンの名前は行全体が消える代わりに後退します。ステータス バッジと使用できない 理由 を示す GPU チップは判読可能なままです。 (#1522)
  • リモート ワーカーはデバイス リストとして読み取ります: ステータス ドット、アドレス、レイテンシ、ライブ タスク メーター、常駐モデル、マシンごとの最後に表示されたもの、ホバーと 3 段階の空の状態でハウスキーピング アクションが表示されます。 (#1516)
  • GPU ピッカーと新しいステータス バー コントロールは、固定パレット クラスではなくテーマ トークンからステータス ドットとメニュー サーフェスをペイントするため、Midnight と Catppuccin で Gruvbox カラーが表示されなくなります。 (#1516)
  • ディクテーションは、その薬を再び示します。キャプチャは、作業中の画面の下部近くに常に表示される小さなカプセルを置き、聞き取り、文字起こし、結果、およびエラーを行い、セッションが終了するとそれを取り除きます。フォーカスが取得されることはないため、テキストは入力していたアプリに表示されたままになります。 Wayland では、コンポジターが配置場所を決定します。それ以外の場所では下中央になります。
  • エンジンとモデルは設定から​​新しいモデル カタログ ワークスペースに移動され、アイコン レール (またはタイトル バー タブ) からアクセスできます。 「設定」→「エンジン」と「設定」→「モデル」がそこを指すようになり、「設定」はモデルのディレクトリとハグフェイスミラーを保持します。
  • 設定サイドバーはキーボードで操作できます。 ⌘K / Ctrl+K でフィルターにジャンプし、↑/↓ および Home/End でカテゴリー間を移動し、フィルターから Enter または ↓ でリストにドロップします。フィルタリングされたカテゴリ名内の一致するテキストが強調表示され、リストがスクロールしている間、グループ ヘッダーは固定されたままになります。
  • Launchpad は、より静かで広々とした外観です。ホバーまたはキーボード フォーカスで点灯する境界線のない機能タイル、単純な数字のカウント、ヘアライン セクション ルール、およびヒーロー、タイル、最近のファイル、およびプロジェクト リスト用の 1 つの共有ページ列があります。
  • Linux リリース スモークは、正常な AppImage を拒否するのではなく、linuxdeploy のラップされたカスタム ランチャーを検証するようになりました。 (#1506)
  • リモート GPU ワーカーはオーディオブックを章ごとにレンダリングし、章ごとの自動ローカル フォールバックと、ワーカーがドロップアウトした場合の 1 つの複合通知を行います。 (#1478)
  • リモート GPU ワーカーがジョブを最後まで実行できるようになりました。長いレンダリングが 2 分で終了することはなくなり、レンダリング中にドロップして再接続したワーカーは作業を維持し、タイムアウトしたジョブによってワーカーが永久にオフラインになることはなくなりました。ジョブを配置するには、依然として開発専用の POST /workers/tasks が必要です。次に、アプリ独自の合成ボタンを接続します。
  • 音声、ストーリー、オーディオブック、ギャラリー、設定、プロファイル、およびランチパッドは、アクセス可能なコントロールを備えたコンパクトで応答性の高いレイアウトを使用するようになりました。 (#1491)
  • ダビングの「ダビングの生成」、「ベリファイ」、および「エクスポート」アクションは、表示ラベル、応答性の高いリフロー、モーションセーフ フィードバックを備えたコンパクトな階層を使用するようになりました。 (#1493)
  • ダブ ワークスペースには、コンパクトなプロダクション コマンド バー、レスポンシブなフラグベースの言語カード、ダブ履歴のメディア プレビュー、および狭いプロジェクト レールが追加されました。 (#1489)
  • VoiceStudio は、タイトル バー、バージョン情報画面、README、ブラウザのファビコン、およびすべてのデスクトップ/プラットフォーム アイコンにわたって 1 つの波形とスパーク マークを使用するようになりました。 (#1487)
  • PocketTTS は、初めて使用する前にコード ライセンス、モデル ライセンス、ゲート アクセス条件を確認するよう求め、生のダウンロードの失敗を表示する代わりにモデルのロックを解除する方法を説明します — paoloantinori に感謝します。 (#1442)
  • リポジトリは github.com/debpalash/VoiceStudio に移動しました。アプリ、ドキュメント、スクリプト内のすべてのリンクがそこを指すようになりました。 GitHub は古い URL をリダイレクトし、Docker 画像パス、アプリ バンドル識別子、データ フォルダーはすべて意図的に変更されません。 (#1394)
  • アプリは VoiceStudio になりました (以前は OmniVoice-Studio)。表示される名前のみが変更されます。データ フォルダー、設定、Docker イメージのパスは変更されないため、アップグレードには何も必要ありません。 Linux では、.deb は voicestudio になりました。古い omnivoice-studio パッケージを一度削除します。
  • macOS フロアが 13.3 (Ventura) に引き上げられました — フロントエンドはしばらくの間 Safari 16.4 を必要としていたため、macOS 12 ではスタックが守れなかった約束でした (#1268)
  • 初回実行時のセットアップ画面が過剰に表示されることはなくなりました。それは無資格で「アカウントなし、クラウドなし、テレメトリなし」と主張しましたが、これは分析を選択する人にとっては真実ではありません。そして今度は、実際にはどちらの場合でも当てはまることを述べています。つまり、音声、録音、プロジェクトは決してマシンから出ず、処理はクラウドで行われないということです。
  • ディクテーションでフローティングピルが表示されなくなりました。ホットキーは、画面上に何も表示せずに記録、転写、貼り付けを行います。トレイ アイコンは引き続き録音をマークし、注意が必要なもの (アクセシビリティ、マイク、文字起こしの失敗など) がメイン ウィンドウに通知として表示されるようになりました。

追加

  • ギャラリー ペルソナは、ローカル バックエンドを通じてプレビューし、完全な音声デザイン レシピを保持し、音声、ストーリー、またはオーディオブックで直接開きます。また、検証された音声参照を含むローカル プロファイルとして保存できます。 (#1542)
  • アプリが常に宣伝してきたデモ オーディオが実際に出荷されるようになりました。7 つの音声デザイン プリセットすべてのプレビュー、3 つのディクテーション リプレイ clips、および吹き替えデモのソース ビデオと字幕付きの 4 つの吹き替え言語です。これらはすべて、以前はデッドリンクでした。それらをレンダリングするツールには macOS が必要だったので、Windows と Linux ではファイルがビルドされることはありませんでした。 (#1517)
  • デモ アセットは VoiceStudio 独自のエンジンによってレンダリングされるため、アプリが実行する場所であればどこでもツールが実行され、デモはデモするものによって作成されます。 (#1517)
  • マシンはアプリからコントロール プレーンに参加できるようになりました: [設定] → [システム] → [リモート ワーカー] → [このマシンの GPU を貸し出す]、参加コードを貼り付けて完了です。環境変数や再起動は必要ありません。アドレスはコードとともに送信されるため、マシンは後で自動的に再接続します。 (#1516)
  • 参加コードと接続文字列はテキストの横に QR コードとして表示され、ライブ有効期限カウントダウンが表示されます。40 文字を再入力する代わりに、他のマシンからスキャンしてください。 (#1516)
  • ステータス バーの コンピューティング コントロール: ローカルまたはリモート マシンを選択し、リモート ワーカーをオンまたはオフにし、設定を開かずに参加コードを作成します。これは、マシンをオプトインまたは登録した場合にのみ表示されます。 (#1516)
  • 承認待ちのワーカーは、その行から承認できます。委員会は以前にもその状態にラベルを付けましたが、そこから抜け出す方法は提供していませんでした。 (#1516)
  • モデル カタログ — エンジンとモデル用の独自のワークスペース: すべての TTS、トランスクリプション、LLM エンジンをそのデバイス ルーティングとインストール状態で参照し、それぞれのデフォルトを選択し、モデルの重みをインストールまたは削除します。これらすべてを、2 つの設定カテゴリではなく 1 つの画面から実行します。
  • リモート GPU マシンがダイヤルアウトの代わりに接続を受け入れることができるようになったため、複数の人が同時に同じボックスを使用できるようになりました。各ユーザーは、証明書で固定された TLS、接続者のライブ リスト、および切断ボタンを備えた独自の取り消し可能な接続文字列を取得します。 (#1496)
  • リモート GPU モデルのダウンロードでは、通常のモデルのインストール フローが使用され、ワーカーごとの進行状況が表示されるようになりました。 (#1478)
  • [設定] → [システム] → [リモート ワーカー] は、他のすべてがここに留まりながら、個々のジョブを他のマシン上の GPU に送信します。デフォルトではオフです。各マシンには使い捨てトークンが追加され、音声が到達する前に承認されます。 docs/remote-workers.md を参照してください。
  • 初回実行セットアップでは、セットアップ全体で使用できるコンパクトなコントロールを備えた、画面対応のインターフェイス スケールが推奨されるようになりました。 (#1502)
  • OrcaRouter は、OpenAI 互換の名前付き LLM プロバイダーとして利用できるようになりました — Marc-oss-hub に感謝します。 (#1499)
  • IndexTTS 2.5 は、5 か国語の吹き替え、表現力豊かなクローン作成、下位互換性のある IndexTTS-2 サポートを備えたピン留めされた 1-click サイドカーとして利用できます。 (#1482) — marwanlhabti5-coder に感謝します!
  • 音声録音では、すべてのデスクトップ プラットフォームでライブ入力レベル メーターを使用してマイクとチャンネルを選択できるようになりました。 (#1481)
  • [設定] → [外観] → [ナビゲーション スタイル] は、ウィンドウの端にあるアイコン レールとタイトル バーにあるブラウザ スタイルのタブの間でワークスペース スイッチャーを切り替えます。どちらも同じワークスペースを提供します。この選択は起動後も適用され、レールはデフォルトのままです。タイトル バーにスペースがなくなると、タブ ラベルはアイコンに折りたたまれます。現在いるワークスペースの名前は維持されます。 (#1412)
  • ポータブル モードでは、フォルダーを選択できます。最初の実行セットアップ画面で 変更… を押し、インストール全体を外部ドライブに置きます。また、デフォルトの Program Files のインストール後はグレー表示されなくなります。 (#766)
  • [設定] → [プライバシー] に 非表示の透かし の切り替えが追加されました。デフォルトでオンになっており、誰でも利用でき、変更後に生成されたオーディオにのみ影響します。 (#1308)
  • 新しいオプトインのクラッシュ分離 TTS エンジンにより、ネイティブ クラッシュによってバックエンド全体ではなくサイドカーがダウンします。paoloantinori に感謝します。 (#1292、#1298、#1304)
  • PocketTTS (Kyutai)、リファレンス clip からのゼロショット クローン作成により、6 つの言語 (en/fr/de/pt/it/es) で高速かつ低遅延のレンダリングを行うためのオプトイン CPU 専用エンジンです。 「設定」→「エンジン」で有効にしてください — paoloantinori に感謝します! (#1306、#1328)
  • 5 分間待機した後ではなく、低速生成の前に警告を発します。 (#1280)

修正済み

  • AMD/ROCm ホストは、「CUDA ドライバーのバージョンが不十分です」という理由で ASR をクラッシュしなくなりました。ROCm torch は自身を CUDA として報告しますが、whisperx/faster-whisper は NVIDIA 専用の CTranslate2 上で実行されます。それらはそこにある CPU パスを使用するようになり、自動検出は純粋に HIP GPU を使用する pytorch-whisper を優先します。 (#1529)
  • クラッシュ レポートには、クラッシュした実行独自の stderr が含まれるようになりました。共有エラー ログは、実行ごとのオフセットを持つ追加専用であるため、再起動によって、瀕死のプロセスの最終出力が代替の正常な起動で上書きされることはなくなりました。 (#1510)
  • Wayland: ポータル ID が古くなっても、セッション全体のディクテーション ショートカットが無効になることはなくなりました。アプリが GlobalShortcuts ポータル用に書き込むデスクトップ エントリは、その後移動されたバイナリ (cargo clean、再配置された AppImage) を指している可能性があります。その場合、GNOME は「アプリ情報が見つかりません」としてバインドを拒否し、ホットキーは静かに終了します。エントリは起動時に検証され、書き換えられるようになりました。 (#1526)
  • 劣化している ASR ローダー上で転写を続けるガードは、ルーターだけでなくバックエンド全体をスキャンするようになりました。リクエストに代わって転写するサービスは、ensure_loaded() を同様に徹底的にスキップしました。 (#1519) — ahov520 に感謝します!
  • Linux アプリのアイコンが空白ではなくなりました。 v0.4.2 以降のすべての AppImage は、それを構築したマシン (/home/runner/work/…) に絶対シンボリック リンクとして .DirIcon を同梱していたため、リンクはすべてのユーザーのコンピュータ上にぶら下がり、ファイル マネージャー、アプリ メニュー、およびデスクトップ統合はすべて何も描画されませんでした。リリース ビルドでは、公開前にアイコンがバンドル内で解決されることを確認するようになりました。 (#1518)

VoiceStudio v0.5.0

Highlights

  • Rebrand with a stable data layer — OmniVoice-Studio is now VoiceStudio and the repo moved to github.com/debpalash/VoiceStudio (#1394), but your data folder, settings, bundle ID and Docker image paths are deliberately unchanged, so no data migration is needed. Two things do change on upgrade: the Linux .deb is now voicestudio (remove the old omnivoice-studio package once), and the macOS floor rises to 13.3/Ventura since the frontend already required Safari 16.4 (#1268). Old GitHub URLs redirect, but update any bookmarks or scripts that pin the repo path.

  • Model Catalogue replaces Settings → Engines/Models — engines and model weights now live in a dedicated workspace where you route each TTS/ASR/LLM engine to a device, set defaults, and install or remove weights from one screen. Status-bar switching (Ctrl/Cmd+E) is ready-only — it won't install on demand — and respects environment pins, so CI or deployed setups can't be silently retargeted; the old Settings links redirect here, while the models directory and Hugging Face mirror stay in Settings.

  • Remote GPU sharing becomes a first-class control plane — a machine can enroll by pasting a join code (Settings → System → Remote workers → Lend this machine's GPU), with the address embedded in the code and QR codes plus expiry countdowns for pairing (#1516); workers can now accept connections so several people share one GPU box over revocable, certificate-pinned TLS strings (#1496). Long renders no longer die at the two-minute mark, survive worker reconnects, and fall back per chapter (#1478). Watch out: dispatching a job still needs the development-only POST /workers/tasks — wiring the app's own Synthesize button to it is future work.

  • Server mode tightens its admin surface — admin actions now require an API key (#1525), and the remote UI exchanges that key for short-lived sessions that are never stored in browser storage or embedded in WebSocket URLs (#1528). If you script admin endpoints, rework your auth flow; separately, a UI loaded from another machine's origin needs that origin in the backend's OMNIVOICE_ALLOWED_ORIGINS allow-list, which neither server mode nor trusted networks sets for you (#1348).

  • New opt-in engines, with guardrails — PocketTTS (Kyutai) adds CPU-only, low-latency rendering and zero-shot cloning in six languages (#1306, #1328) and now makes you acknowledge its code/model licenses and gated access before first use (#1442); IndexTTS 2.5 lands as a pinned one-click sidecar with five-language dubbing and backward-compatible IndexTTS-2 support (#1482), OrcaRouter as an OpenAI-compatible provider (#1499), and a crash-isolated TTS engine so a native crash kills the sidecar rather than the backend (#1292, #1298, #1304). All are opt-in so defaults stay put, but for unattended runs the crash isolation and the new pre-generation slow-render warning (#1280) are worth enabling.

  • Platform and diagnostics fixes worth upgrading for — Wayland dictation is repaired: a stale portal desktop entry no longer kills the global shortcut for the session (#1526) and the shortcut now fires reliably (#1490), with the recording pill restored on every desktop (compositor-positioned on Wayland). AMD/ROCm hosts no longer crash ASR with a bogus "CUDA driver version is insufficient" error — CTranslate2-based whisper engines take the CPU path while pytorch-whisper uses the HIP GPU (#1529) — and crash reports now carry the dying run's own stderr via per-run log offsets (#1510). Gallery voices can also be saved as local profiles with validated, content-addressed audio references (#1542).

  • Dubbing: the transcription overlay said "Transcribing with Whisper…" whatever ASR engine was actually running — it now names the stage, in all 21 languages — thanks paoloantinori! (#1352)
  • Error messages no longer arrive with terminal colour codes spliced into the sentence (download: ^[[0;31mERROR:^[[0m …) — every surfaced failure is cleaned now, whichever tool produced it. (#1344)
  • Linux AppImage: recording failed with "No microphone found" on hosts whose GStreamer is newer than the build runner's, even with a verified-healthy audio stack — your own GStreamer now takes precedence, and the plugin cache is app-private so it can neither be confused by nor corrupt the one other apps use — thanks Kakuzen93! (#1333)
  • Linux AppImage: that GStreamer preference actually takes effect — the check guarding it could never pass, so it had been silently doing nothing. (#1333)
  • A TTS job abandoned for exceeding its compute budget now records where it was actually stuck, so a hang stops being reported as a machine that is merely too slow. (#1338, #1329, #1348)
  • Translation through LM Studio works. The built-in model name was the placeholder local-model, which LM Studio rejects because it serves whatever you have loaded — VoiceStudio now asks it, and a 404 from a local server names the models that ARE loaded instead of telling you to check a URL that was fine — thanks biga73! (#1332)
  • Generation that silently dropped the end of the input now says so. When an engine returns no audio for part of the text the result sounds clean and is simply short, so the only way to notice was to read along; the backend log now names the sentences that produced nothing. (#1330)
  • Dubbing: a re-rendered line that quietly came back in a default voice instead of the cloned one now says why in the backend log — the clone clips are extracted per job and a saved dub outlives them, so regenerating after cleanup loses the reference with no error. (#1331)
  • RTX 40-series GPUs are used again instead of being sent to the CPU. (#1289)
  • Apple Silicon: transcription no longer needs a system ffmpeg, as the docs always said — thanks gambletan! (#1436)
  • A failed audiobook chapter says why, instead of turning red and saying nothing. (#1325)

CI

  • Windows CI falls back to a static ffmpeg build when the Chocolatey feed is down, instead of failing the run. (#1542)
  • The stdio wire protocol every engine sidecar speaks is now tested once across all nine of them, instead of against a single engine — a bug in any one sidecar's copy gets caught — thanks paoloantinori! (#1408)
  • Windows smoke tests stopped silently passing a broken ffmpeg install, and every smoke leg is now budgeted for a cold dependency install. (#1290)
  • Test suites no longer leak config paths or model-manager shutdown state into one another, which had been failing unrelated pull requests. (#1269)
  • The nightly preview build stopped refusing to publish its own healthy updater manifest when the macOS legs finished a few minutes ahead of the slowest one — Preview-channel users were silently left without new builds.
