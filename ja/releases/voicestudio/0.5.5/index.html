VoiceStudio v0.5.5

パッチ 公開日2026年9月22日 出典debpalash/VoiceStudio English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ボイススタジオv0.5.5

あなたの声を別の言語に。 クローン ワークスペースでは、音声サンプルを変更するときに選択した出力言語が保持されるようになりました。たとえば、英語のリファレンスは、多言語エンジンを使用してフランス語のスクリプトを読み取ることができます。クローンの自動は、参照プロファイルの言語を継承するのではなく、スクリプトに従います。

このリリースでは、Electron のインストールの回復も容易になり、スクリプト エディターと統合カタログの不具合が修正され、障害レポートがより便利になります。

アップグレード: 既存の Electron アプリを上書きインストールします。セットアップで尋ねられたら、[ローカル ランタイムのインストール] を選択して依存関係を更新します。 0.5.4 → 0.5.5 のアップグレードは、保存された音声と設定を使用してテストされました。

Tauri からの移行: Tauri を削除する前に、アプリを閉じ、データ ディレクトリをバックアップし、Electron をインストールし、音声とプロジェクトを確認します。 移行ガイドに従ってください。 Tauri v0.5.3 は、Tauri の最終リリースのままです。そのアップデーターは Electron をインストールできません。 Intel Mac は、リモート バックエンドで UI をサポートします。

インストーラー trust: Electron インストーラーは未署名またはアドホック署名されており、Apple によって公証されていません。 Windows/macOS では、trust 警告が表示される場合があります。 macOS の自動アップデートは未検証です。手動インストーラー更新を使用してください。 インストールガイドを参照してください。アーカイブされた Tauri アップデーターの署名は変更されません。

ハイライト

  • クローンは、参照音声を選択、アップロード、または保存するときにターゲット言語を保持します (#2272)
  • 1 つのコマンドで Electron リリースをインストールするか、メインをビルドします。データを失わずにアンインストールする (#2269)
  • 何か問題が発生したときに、より明確なクラッシュ レポートとローカル レンダー診断を取得します (#2267、#2266) — @shivsin25 に感謝します!
  • 式メニューを再度開かずにスクリプト カーソルを配置します (#2268) — @bipul0525 に感謝します!

追加

  • 診断バンドルには、スクリプト テキストやオーディオを記録せずに、ローカルのレンダリング ステージのタイミングと操作数が含まれます (#2266) — @shivsin25 に感謝します!

修正済み

  • Clone では、明示的な Auto がターゲット スクリプトに従います。リファレンスボイスを変更しても出力言語がリセットされなくなりました (#2272)
  • 新しいランタイム セットアップではマネージド Python を使用し、成功を報告する前に SentencePiece を検証します (#2270) — @mamislimen に感謝します!
  • 音声認識の起動エラーは実際の原因を保持し、無関係な再インストールのアドバイスを回避します (#2128) — @Sip19 に感謝します!
  • ベンダーが URL を共有する場合 (検索やフィルタリング後も含めて) 統合カードは区別されたままになります (#2273)
  • macOS シェルのインストールでアプリの登録が更新され、実行中の置き換えが防止され、削除されたアプリがゴミ箱に移動されます (#2269)
  • アップグレードでは、アーカイブされたセットアップによって記録されたカスタムおよびポータブル ストレージ パスが保持されます (#2269)
  • クラッシュ レポートは、ネイティブ フォールト、Python エラー、および終了信号を区別します (#2267) — @shivsin25 に感謝します!

VoiceStudio v0.5.5

Highlights

  • Language-preserving cloning — Changing, uploading, or saving a reference voice no longer resets the output language, and explicit Auto follows the target script instead of inheriting the reference profile’s language. This enables workflows such as an English reference reading a French script without manual language correction (#2272).
  • Recoverable Electron installs and runtimes — One-command install/build and data-preserving uninstall now include macOS app-registration fixes, protection against replacing a running app, and preservation of custom/portable storage paths (#2269). Fresh setups use managed Python and verify SentencePiece before reporting success (#2270); install over the existing app and choose Install local runtime if prompted.
  • Actionable diagnostics without content capture — Crash reports distinguish native faults, Python errors, and termination signals (#2267). Diagnostic bundles add local render-stage timings and operation counts without recording script text or audio (#2266), giving developers useful evidence for troubleshooting while limiting sensitive-data capture.
  • Fewer workflow interruptions — Script cursor placement no longer requires reopening the expression menu (#2268); integration cards remain distinct when vendors share a URL, including after search and filtering (#2273); speech-recognition startup errors retain their actual cause instead of suggesting unrelated reinstalls (#2128).
  • Migration and installer trust — Tauri v0.5.3 is the final Tauri release, and its updater cannot install Electron: close the app, back up its data directory, install Electron, and verify voices/projects before removing Tauri. Intel Macs support the UI with a remote backend. Electron installers are unsigned or ad-hoc signed and not Apple-notarized, so expect OS warnings and use manual macOS updates because automatic updates are unverified.
  • Breaking changes — None for existing Electron installs; Tauri users must follow the documented migration.

Your voice, another language. The Clone workspace now keeps your chosen output language when changing voice samples. For example, an English reference can read a French script with a multilingual engine; Auto in Clone follows the script instead of inheriting the reference profile's language.

This release also makes Electron installation easier to recover, fixes script-editor and integration-catalog glitches, and makes failure reports more useful.

Upgrading: Install over your existing Electron app. If setup asks, choose Install local runtime to refresh its dependencies. The 0.5.4 → 0.5.5 upgrade was tested with a saved voice and settings.

Moving from Tauri: Close the app, back up its data directory, install Electron, and verify your voices and projects before removing Tauri. Follow the migration guide. Tauri v0.5.3 remains the final Tauri release; its updater cannot install Electron. Intel Macs support the UI with a remote backend.

Installer trust: Electron installers are unsigned or ad-hoc signed and are not Apple-notarized. Windows/macOS may show trust warnings. macOS automatic updates are unverified; use manual installer updates. See the installation guide. Archived Tauri updater signatures are unchanged.
