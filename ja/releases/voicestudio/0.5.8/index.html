ハイライト

  • OmniVoice GGUF は、Windows および Linux 上の Vulkan を介して AMD、Intel、NVIDIA GPU を使用し、Intel Arc GPU が OmniVoice を実行します
  • PyTorch のダウンロードが失敗すると、セットアップはより小さい CPU ビルドにフォールバックし、GPU に障害が発生するとアプリは CPU にフォールバックします。
  • Windows は一度に 1 ファイルずつモデルをロードし、エンジンがクラッシュするとその原因を特定し、CPU での再起動を提案します。
  • dots.tts 音声クローン作成は、Python セットアップなしで、audio.cpp を通じて Windows 上で実行されます。
  • Convert では配信を維持し、ビデオを撮影できます。吹き替えでは最初に字幕をエクスポートし、スピーカー間で行を移動します

OmniVoice は AMD、Intel、または NVIDIA GPU を使用するようになり、VoiceStudio は壊れにくくなりました。 OmniVoice GGUF は Windows および Linux 上の Vulkan GPU で実行され、モデルのサイズをカードに合わせて設定し、リクエスト (オプトイン、設定 → パフォーマンス) 間でロードされたままにすることができ、Intel Arc GPU も OmniVoice を実行します。何か問題が発生した場合でも、アプリは動作し続けるようになりました。PyTorch のダウンロードが失敗し続ける場合、セットアップははるかに小さい CPU ビルドを提供し、停止したダウンロードを再試行し、GPU に障害が発生した場合は通知とともに VoiceStudio を CPU に移動します。 Windows では、初回起動時のクラッシュを避けるためにモデルは一度に 1 つのファイルをロードし、エンジンがクラッシュするとその背後にあるライブラリに名前を付け、CPU での再起動を提供します。

このリリースでは、Python セットアップ不要の Windows への dots.tts 音声クローン作成、配信を維持してビデオを撮影する Convert、最初に字幕をエクスポートしてスピーカー間の行を移動する吹き替え、voicestudio ターミナル コマンド、バックグラウンド更新、新しい macOS インストーラー ウィンドウ、および吹き替え、セットアップ、オーディオブック、電話アプリに対する数百の修正も提供されます。

新しい macOS インストーラー ウィンドウ (#4001)。

0.5.7 からのアップデート: 0.5.7 が提供するアプリ内アップデートを利用するか、既存のアプリに上書きインストールします。音声、プロジェクト、設定は保持されます。最初の起動時に、ローカル ランタイムは PyTorch 2.10 セキュリティ アップデート (#3884) を含むパッケージを所定の場所で更新します。

0.5.8 ベータ版からの更新: 何もする必要はありません。ベータ チャネルは自動的に 0.5.8 にロールフォワードされます。ベータ版の取得を停止するには、[設定] → [更新] → [更新チャネル] で [安定版] に切り替えます。

VoiceStudio v0.5.8

Highlights

  • OmniVoice GGUF goes cross-vendor on Vulkan — The GGUF path now runs on any Vulkan GPU on Windows and Linux, covering AMD, Intel and NVIDIA cards plus Intel Arc, with model sizing per card and an opt-in resident runtime (Settings → Performance) that skips the reload before every generation (#3965, #3654). Release installers now bundle omnivoice.cpp's tts-server so resident mode survives outside dev builds, falling back to per-request loading when unavailable (#4005), and a Self-test in Settings → Models names the Vulkan device it actually ran on — the quickest way to verify a driver setup before chasing generation bugs (#3993).
  • Failure paths became fallbacks — Setup offers a much smaller CPU build when the PyTorch download keeps failing (#3846) and retries stalled downloads; a startup GPU probe switches to CPU with a notice if the GPU fails (#3845). On Windows, models load one file at a time to avoid first-launch crashes, and engine crashes now name the offending library and offer Restart on CPU. Crash reports include what was running and free memory (#3844), turning anonymous OOMs into diagnosable ones.
  • Source builds drop Gradio and training from the default install — The migration item for anyone running from source: Gradio and WebDataset are no longer installed by default (~81 MB lighter), and the demo and training paths now require the ui and train extras (#4027). Add those explicitly if your workflow uses them. Expect a one-time in-place package update on first launch when coming from 0.5.7, including the PyTorch 2.10 security update (#3884).
  • dots.tts cloning reaches Windows without Python — Voice cloning runs through the audio.cpp runtime, so Windows users skip the Python setup that previously gated the feature. The runtime moves to v0.9.4, but installed Breeze-TTS-2, dots.tts and Sortformer models keep working without a re-download, and the previous runtime continues serving them until you install the update (#3129).
  • Convert and dubbing preserve more source material — Convert voice can keep the original delivery video, returning picture and background when they can be preserved and converted audio plus an explanation when they can't (#3750). Dubbing now exports subtitles first, moves lines between speakers, and can speak the original transcript in the source language to bypass translation entirely (#3747).
  • CLI and quieter updates — A new voicestudio terminal command exposes voices, speech, transcription, dubbing and models with tab completion, auto-starting the app in the background when needed (#3828). Updates download in the background and install on quit with a title-bar progress pill, Restart/Retry controls and a prompt when work is running (#3928), so long sessions aren't interrupted mid-task.

No breaking changes for existing installs.
