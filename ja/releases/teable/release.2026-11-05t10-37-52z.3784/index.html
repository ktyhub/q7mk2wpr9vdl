ティーブル release.2026-11-05T10-37-52Z.3784

機能の更新

  • フィールドの削除と変換のプレビューでは、影響を受けるアプリ、クエリ、フィールド、データ ソースが表示され、公開されたバージョンと最新に保存されたバージョンが区別されるようになりました。保存されたクエリは、より明確な説明とともに正常、ドリフト、または破損したステータスを報告します。プレビューは読み取り専用のままで、変更前に確認が必要で、影響を受けるアプリは自動的に変更されません。
  • 自己ホスト型管理者は、自動 HTTPS を使用してカスタム ドメインを公開アプリにマッピングできます。 [カスタム ドメイン] オプションによりセットアップ ガイドが開き、サインインすると標準アプリ リンクへのフォールバックを使用してマップされたドメインにユーザーが戻されるようになりました。
  • 管理者は、App Builder アプリのインスタンス全体の OIDC プロバイダーを構成できます。アプリは、既存のアクセス ルールとログイン方法を維持しながら、「SSO で続行」を提供できます。既存のアプリでは、所有者が SSO ボタンを追加して再公開する必要がある場合があります。
  • 個人アクセス トークンの設定には、4 つの権限プリセット、グループ化された読み取り/書き込みレベル、検索可能な個別の権限、および保存前の概要が含まれるようになりました。アクセスは、現在および将来のすべてのスペースとプロジェクト、または選択したスペースとプロジェクトをカバーできます。トークン リストにはプリセットが表示され、有効期限と最終使用の並べ替えがサポートされ、期限切れまたは期限切れ間近のトークンが強調表示されます。
  • ユーザーメニューにモバイルアプリのダウンロードオプションを追加しました。電話機では引き続きクラシック レイアウトが使用されます。

バグ修正と改善

  • 双方向リンク レコード フィールドを更新するクロスベース オートメーションが復元されました。既存のワークフローは、再公開したり、手動で無効にして再度有効にしたりせずに再開されます。
  • 名前付きクエリに関連するアプリ公開の失敗後、テンプレートのプレビューが「深く考えています...」でスタックする問題を修正しました。初期の失敗が再試行されるようになり、再試行が失敗した場合の最終エラーがより明確になります。
  • 既存の結果、権限、および元に戻す/やり直しの動作を維持しながら、特に少数のフィールドのみを変更する場合の広いテーブルでの大規模な一括レコード更新のパフォーマンスが向上し、メモリ使用量が削減されました。
  • フィールド変換が失敗した後のテーブル ページングの信頼性が向上しました。
  • App Builder セッションは、現在のアクセス設定を尊重しながら、埋め込みアプリを含め、ユーザーが少なくとも 1 時間後に再アクセスすると、さらに 7 日間更新されるようになりました。この動作を有効にするには、既存のアプリを再公開する必要があります。
  • より明確なサインイン エラーや再試行ガイダンスなど、接続された client の認証の信頼性が向上しました。一時的な障害によって資格情報が不必要に無効になることはなくなり、CLI は必要に応じてユーザーに再度サインインするよう明確に指示します。
  • 新しいチャット会話は最初のメッセージが送信された後にのみ作成されるため、空のチャットが蓄積されるのを防ぎます。未送信の下書きはページが更新されても保存されるようになりました。
  • チャットとテーブルの初期読み込みパフォーマンスが向上しました。
  • Admin AI 設定を、ステータス インジケーターとセットアップ ガイダンスを備えた番号付きのモデル、AI チャット、アプリ ビルダー セクションに再編成しました。チャット設定でのゲートウェイ モデルとカスタム プロバイダー モデルの両方のサポートを含む、モデル構成のレイアウト、概要、検索、および選択が改善されました。
  • サイドバーの自動折りたたみやレイアウト更新プロンプトの正しい位置など、小さなウィンドウでの新しいスペースのレイアウトが改善されました。
  • 完了時にグループ化フィールドのプロンプトが閉じるようにかんばん設定を修正しました。列内に作成されたレコードは、その列の単一選択値を継承するようになりました。
  • より明確なソース名とテキストの折り返しにより、プロジェクト インポート カードが改善されました。利用可能な場合、リソース タブにカスタム テーブル アイコンが表示されるようになりました。
  • 編集可能な共有ページのテーブル インポートの進行状況インジケーターが復元され、共有ページのセキュリティが向上しました。
  • ルーチンによって生成されたアーティファクトへのアクセスを修正しました。ルーチンを公開またはアクティブ化すると、そのユーザーに所有権が割り当てられ、所有権が変更されると通知が表示されます。対象となるタスク メンバーは実行チャットを表示できますが、チャットを続行または管理できるのは所有者だけです。
  • URL ベースのインポートのセキュリティとエラー処理が改善されました。
  • 大きなテキスト、生成されたクエリ、または GeoJSON ファイルを含むプロジェクトでのアプリ公開エラーを修正しました。
  • 検証結果が利用できない場合のカスタム ドメイン検証エラーを修正しました。
  • Android のタブとリソース リストから元の会話への左スワイプ ナビゲーションが復元されました。モバイル ギャラリーのタッチ処理が改善され、スクロール中の誤ったドラッグが減少しました。

teable release.2026-11-05T10-37-52Z.3784

Feature Updates

  • Field deletion and conversion previews now show affected apps, queries, fields, and data sources, distinguishing published and latest-saved versions. Saved queries report healthy, drifted, or broken status with clearer explanations. Previews remain read-only, require confirmation before changes, and do not automatically modify affected apps.
  • Self-hosted administrators can map custom domains to published apps with automatic HTTPS. The Custom domain option now opens the setup guide, and sign-ins return users to the mapped domain with a fallback to the standard app link.
  • Administrators can configure an instance-wide OIDC provider for App Builder apps. Apps can offer “Continue with SSO” while preserving existing access rules and login methods. Existing apps may require the owner to add the SSO button and republish.
  • Personal access token configuration now includes four permission presets, grouped read/write levels, searchable individual permissions, and a summary before saving. Access can cover all current and future spaces and projects or selected ones. The token list shows presets, supports expiration and last-use sorting, and highlights expired or soon-to-expire tokens.
  • Added a mobile app download option to the user menu. Phones continue to use the classic layout.

Bug Fixes & Improvements

  • Restored cross-base automations that update bidirectional linked-record fields. Existing workflows resume without republishing or manually disabling and re-enabling them.
  • Fixed template previews getting stuck on “Thinking deeply…” after app publishing failures involving named queries. Early failures are now retried, with clearer final errors when retries fail.
  • Improved performance and reduced memory use for large bulk record updates, especially on wide tables when changing only a few fields, while preserving existing results, permissions, and undo/redo behavior.
  • Improved table paging reliability after failed field conversions.
  • App Builder sessions now renew for another seven days when users revisit after at least one hour, including in embedded apps, while respecting current access settings. Existing apps must be republished for this behavior to take effect.
  • Improved authentication reliability for connected clients, including clearer sign-in errors and retry guidance. Temporary failures no longer unnecessarily invalidate credentials, and the CLI clearly directs users to sign in again when needed.
  • New chat conversations are created only after the first message is sent, preventing empty chats from accumulating. Unsent drafts now survive page refreshes.
  • Improved initial loading performance for chats and tables.
  • Reorganized Admin AI Settings into numbered Models, AI Chat, and App Builder sections with status indicators and setup guidance. Improved model configuration layouts, summaries, search, and selection, including support for both gateway and custom-provider models in chat settings.
  • Improved the new space layout in smaller windows, including automatic sidebar collapsing and correct positioning of the layout update prompt.
  • Fixed Kanban setup so the grouping-field prompt closes when complete. Records created within a column now inherit that column’s single-select value.
  • Improved project import cards with clearer source names and text wrapping. Resource tabs now display custom table icons when available.
  • Restored table import progress indicators on editable share pages and improved shared-page security.
  • Fixed access to artifacts generated by routines. Publishing or activating a routine now assigns ownership to that user, with notifications when ownership changes. Eligible task members can view run chats, while only the owner can continue or manage them.
  • Improved security and error handling for URL-based imports.
  • Fixed app publishing failures in projects containing large text, generated query, or GeoJSON files.
  • Fixed custom domain verification errors when verification results are unavailable.
  • Restored Android left-swipe navigation from tabs and resource lists to the originating conversation. Improved mobile gallery touch handling to reduce accidental dragging while scrolling.
