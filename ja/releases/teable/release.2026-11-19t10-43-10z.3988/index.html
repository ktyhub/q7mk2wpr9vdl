ティーブル release.2026-11-19T10-43-10Z.3988

機能の更新

  • アーティファクト パネルには、現在のスペースでアクセスできるすべてのアーティファクトが表示されます。作成者フィルターとプロジェクト フィルター、スクロールしても表示される検索バー、プロジェクト ラベル、サムネイル付きのコンパクトな行が表示されます。フィルターの選択は、同じブラウザー内のプロジェクト パネル全体で記憶されます。
  • 共有アーティファクトをブラウザ ビューアから直接ダウンロードするか、ティーブル アーティファクトの取得を使用してダウンロードします。受信者は現在共有されているバージョンのみをダウンロードでき、パスワードで保護された共有はブラウザで開く必要があります。

バグ修正と改善

  • コピー、インポート、またはテンプレートベースのワークフローでは、コネクタ トリガーでアカウントが必要な場合、ユーザーにアカウントの接続を求めるプロンプトが表示されるようになりました。
  • 日常的な複製と構成の公開の信頼性が向上しました。重複したルーチンは、セットアップが完了した後にのみ表示されます。
  • レコードの一括更新に対する権限の適用が改善されました。
  • リアルタイム コラボレーションの安定性が向上し、接続中断後の繰り返しの再接続が減少しました。
  • ブラウザストレージを使用するアーティファクトプレビューでの誤ったエラーバナーを修正しました。プレビューが開いている間、ストレージ データは引き続き使用できます。
  • CLI および App Builder のガイダンスを更新し、ブラウズにはティーテーブル レコードの取得、フィルターおよびグループ化されたサマリーにはティーテーブル クエリを推奨しました。このガイダンスでは、クエリ エラーの処理方法と、読み取り専用 SQL をいつ使用するかについて説明します。
  • アプリを削除すると、そのフォルダーを使用する場合も含めて、アクティブに生成中のアプリが一覧表示され、中断する前に確認が求められるようになりました。キャンセルすると作業は実行されたままになります。プロジェクト、スペース、またはアカウントを削除すると、関連する生成とキューに入れられた送信も停止します。
  • セッションの信頼性が向上し、アクティブ ユーザーがサインインを維持できるようになりました。
  • ワークフロー ボタンにはローカライズされたメッセージが表示され、レコードがトリガー フィルターを満たさない場合 (共有ビューを含む) にアクションがスキップされるようになりました。
  • 数値 SWITCH のケースを修正し、誤ってデフォルトの結果を返すのではなく、数式フィールドと構造化クエリの値で一致するようにしました。

teable release.2026-11-19T10-43-10Z.3988

Feature Updates

  • Artifact panels now show all artifacts you can access in the current space, with creator and project filters, a search bar that stays visible as you scroll, project labels, and compact rows with thumbnails. Filter selections are remembered across project panels in the same browser.
  • Download shared artifacts directly from the browser viewer or with teable artifact get. Recipients can download only the currently shared version, and password-protected shares must be opened in the browser.

Bug Fixes & Improvements

  • Copied, imported, or template-based workflows now prompt users to connect an account when a connector trigger requires one.
  • Routine duplication and configuration publishing are more reliable. Duplicated routines appear only after setup is complete.
  • Improved permission enforcement for bulk record updates.
  • Improved real-time collaboration stability and reduced repeated reconnects after connection interruptions.
  • Fixed false error banners in artifact previews that use browser storage. Storage data remains available while the preview is open.
  • Updated CLI and App Builder guidance to recommend teable record get for browsing and teable query for filtering and grouped summaries. The guidance explains how to handle query errors and when to use read-only SQL.
  • Deleting an app, including through its folder, now lists any apps that are actively generating and asks for confirmation before interrupting them. Canceling leaves the work running. Deleting a project, space, or account also stops related generation and queued sends.
  • Improved session reliability to help active users stay signed in.
  • Workflow buttons now show a localized message and skip the action when a record does not meet the trigger filter, including in shared views.
  • Fixed numeric SWITCH cases so they match by value in formula fields and structured queries instead of incorrectly returning the default result.
