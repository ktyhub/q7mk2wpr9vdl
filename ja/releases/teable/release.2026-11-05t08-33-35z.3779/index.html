ティーテーブル release.2026-11-05T08-33-35Z.3779

機能の更新

  • ユーザーメニューにモバイルアプリのダウンロードオプションを追加しました。
  • 自己ホスト型インスタンス上の公開アプリに対するカスタム ドメインのサポートを追加しました。
  • App Builder にインスタンス全体の OIDC 構成を追加し、アプリが既存のサインイン方法と並行して「Continue with SSO」を提供できるようにします。
  • 4 つの権限プリセット、グループ化された読み取り/書き込み権限、検索可能な個別の権限、およびより明確なアクセス範囲を備えたシンプルな個人アクセス トークン構成。トークン リストにはプリセットが表示され、有効期限と最終使用の並べ替えがサポートされ、期限切れまたは期限切れ間近のトークンが強調表示されるようになりました。

バグ修正と改善

  • 自動的にサイドバーが折りたたまれ、レイアウト更新プロンプトが正しく配置されるようになり、小さなウィンドウでのスペース レイアウトが改善されました。電話機では引き続きクラシック レイアウトが使用されます。
  • かんばん設定を修正し、設定後にグループ化フィールド プロンプトが閉じ、列に作成されたレコードがその単一選択値を継承するようにしました。
  • プロジェクト インポート カードが改善され、ソース名が明確になり、スタイルが一貫し、テキストの折り返しが改善されました。利用可能な場合、リソース タブにカスタム テーブル アイコンが表示されるようになりました。
  • 認証エラー処理が改善され、MCP clients は、一時的な障害時に有効な資格情報を破棄することなく、必要に応じてユーザーに再度サインインするよう求めることができます。レート制限されたトークン要求には再試行タイミングが含まれるようになり、CLI は明確なサインイン指示を提供します。
  • 新しいチャットは最初のメッセージが送信されたときにのみ作成されるようになり、チャット履歴に空の会話が残るのを防ぎます。新しい会話の未送信の下書きは、ページを更新しても残ります。
  • チャットとテーブルの初期読み込みパフォーマンスが向上しました。
  • 特に少数のフィールドのみを変更する場合の幅の広いテーブルの場合、大規模な一括更新のパフォーマンスが向上し、メモリ使用量が削減されました。
  • フィールド変換に失敗した後の回復が改善されました。
  • セルフホスト型カスタム ドメイン オプションでは、サポートされていないダイアログの代わりにセットアップ ガイドが開くようになりました。マップされたドメインへのサインインのリダイレクトとドメイン検証中のエラーを修正しました。
  • App Builder セッションは、現在のアクセス許可とログイン設定を尊重しながら、組み込みアプリを含む継続使用中に更新されるようになりました。
  • 管理 AI 設定をモデル、AI チャット、アプリ ビルダーのセクションに再編成し、ステータス インジケーター、セットアップ ガイダンス、より明確な構成概要、改善された狭い画面レイアウトを備えました。
  • チャット モデルの選択を修正し、ゲートウェイ モデルとカスタム プロバイダー モデルの両方をソースごとにグループ化して含めるようにしました。より明確な選択、スクロール、より関連性の高い検索結果を備えたモデル マッピングの改善。
  • 編集可能な共有ページのテーブル インポートの進行状況インジケーターが復元され、共有リンクのプライバシーとセキュリティが向上しました。
  • ルーチンによって生成されたアーティファクトへのアクセスを修正しました。ルーチンを公開またはアクティブ化すると、そのユーザーに所有権が割り当てられ、所有権が変更された場合にはハンドオーバー通知が送信されます。
  • 定期的な実行チャットは資格のあるタスク メンバーに表示されるようになりましたが、会話を継続または管理できるのは所有者だけです。
  • URL ベースのインポートのセキュリティと信頼性が向上しました。
  • 大きなテキスト、生成されたクエリ、または GeoJSON ファイルを含むプロジェクトのアプリ公開エラーを修正しました。
  • Android の左スワイプ ナビゲーションを元の会話に戻し、モバイル ギャラリーのスクロールを改善して誤ってセルをドラッグすることを減らしました。

teable release.2026-11-05T08-33-35Z.3779

Feature Updates

  • Added a mobile app download option to the user menu.
  • Added custom domain support for published apps on self-hosted instances.
  • Added instance-wide OIDC configuration for App Builder, enabling apps to offer “Continue with SSO” alongside existing sign-in methods.
  • Simplified personal access token configuration with four permission presets, grouped read/write permissions, searchable individual permissions, and clearer access coverage. Token lists now show presets, support expiration and last-use sorting, and highlight expired or soon-to-expire tokens.

Bug Fixes & Improvements

  • Improved the space layout on smaller windows with automatic sidebar collapsing and correctly positioned layout update prompts. Phones continue to use the classic layout.
  • Fixed Kanban setup so the grouping-field prompt closes after configuration and records created in a column inherit its single-select value.
  • Improved project import cards with clearer source names, consistent styling, and better text wrapping. Resource tabs now show custom table icons when available.
  • Improved authentication error handling so MCP clients can prompt users to sign in again when needed without discarding valid credentials during temporary failures. Rate-limited token requests now include retry timing, and the CLI provides a clear sign-in instruction.
  • New chats are now created only when the first message is sent, preventing empty conversations in chat history. Unsent drafts in new conversations survive page refreshes.
  • Improved initial loading performance for chats and tables.
  • Improved large bulk update performance and reduced memory use, especially for wide tables when changing only a few fields.
  • Improved recovery after failed field conversions.
  • The self-hosted Custom domain option now opens the setup guide instead of an unsupported dialog. Fixed sign-in redirects to mapped domains and errors during domain verification.
  • App Builder sessions now renew during continued use, including in embedded apps, while respecting current access permissions and login settings.
  • Reorganized Admin AI Settings into Models, AI Chat, and App Builder sections with status indicators, setup guidance, clearer configuration summaries, and improved narrow-screen layouts.
  • Fixed chat model selection to include both gateway and custom-provider models, grouped by source. Improved model mapping with clearer selections, scrolling, and more relevant search results.
  • Restored table import progress indicators on editable share pages and improved share-link privacy and security.
  • Fixed access to artifacts generated by Routines. Publishing or activating a Routine now assigns ownership to that user, with handover notifications when ownership changes.
  • Routine run chats are now visible to eligible task members, while only the owner can continue or manage the conversation.
  • Improved the security and reliability of URL-based imports.
  • Fixed app publishing failures for projects containing large text, generated query, or GeoJSON files.
  • Restored Android left-swipe navigation back to the originating conversation and improved mobile gallery scrolling to reduce accidental cell dragging.
