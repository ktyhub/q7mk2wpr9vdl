ティーテーブル release.2026-11-13T02-21-01Z.3890

機能の更新

  • レコード検索では、複数のフィールド、スペースで区切られたキーワード、語句、すべての用語、および完全一致モードがサポートされるようになりました。
  • アプリ ビルダーは、サインイン コードなしで、選択したユーザーとしてアプリを最大 1 時間プレビューできます。サインイン設定には、ドメイン ルールによってブロックされたユーザーを無効にし、ビルダーがプレビューを直接終了できるコンパクトなユーザー ピッカーが提供されるようになりました。
  • テンプレートは、セッション間で保存される進行状況、自動完了チェック、コンテキスト リンク、AI 支援、対象となる手動ステップを備えた対話型のスタート ガイドをサポートするようになりました。クリエイターは AI を使用してガイドの下書きを作成し、公開する前にコピーで試してみることができます。
  • 構造化クエリは、数式ベースのメトリクス、メトリクスごとのフィルタ、および集計レベルのフィルタリングをサポートするようになりました。クエリ式は数式フィールドと同じ数式構文を使用し、以前の v3 クエリのみの式構文を置き換えます。 v1 および v2 形式は変更されません。
  • 資格情報管理では、アプリまたはプロジェクトの名前または ID による大文字と小文字を区別しない検索がサポートされるようになり、一括操作は一致する結果に限定されます。
  • CLI コマンドは、AI フィールド操作をフィールドの下にグループ化し、インポートをインポートの下にグループ化するようになりました。新しいフィールド ai-status --poll コマンドは、1 つ以上のフィールドにわたる AI の入力が完了するまで待機します。従来のスタンドアロン コマンドはこのリリースでも互換性が残りますが、非推奨となり、1 つのリリース後に削除されます。
  • リソースペインのタブをドラッグして並べ替えられるようになりました。プロジェクト名を使用すると、アクションの作成、追加、名前変更、削除に簡単にアクセスできます。
  • 削除を開始する前に確認を行って、フォルダーをすべてのネストされたフォルダーおよびリソースとともにゴミ箱に移動できるようになりました。
  • スペースのみまたはパブリック リンク、オプションのパスワード、および有効期限を使用して、CLI および承認された API を通じてアーティファクト共有が利用できるようになりました。新しい CLI 共有には明示的なスコープが必要であり、共有を無効にするとリンクが無効になります。
  • Tea パッケージのインポートでは、プロジェクト名、コンテンツ数、および折りたたみ可能なフォルダー ツリーを含む確認プレビューが表示されるようになりました。
  • 自動化スクリプトは、bodyType を html に設定することで、生の HTML 電子メールを送信できます。マークダウンはデフォルトのままです。
  • シークレットの所有者は、公開キーが安全であることを確認した後、Web インターフェイスを通じて公開キーの公開警告を無視できます。
  • Cmd+K は、ワークスペース リソースとともにアクセス可能なチャット タイトルとメッセージ コンテンツを検索するようになりました。チャット結果には一致するスニペットが含まれており、チャットとリソースに対して個別のフィルターとページネーションを使用して、関連するメッセージが開きます。

バグ修正と改善

  • ビューを介した検索では、一貫してビュー フィルターが保持され、空の検索が拒否されるようになりました。全フィールド検索では、以前の 20 フィールド制限を超えて検索可能なフィールドがカバーされ、幅の広いテーブルでのパフォーマンスが向上します。
  • 集計クエリは、アクセス許可を尊重しながら、より一貫した合計、ページネーション、および null 処理を返すようになりました。一致するレコードがない場合、フィルターされたチェックボックスのパーセンテージ メトリックは null ではなく 0 を返します。
  • CLI レコード数とフィールド統計は、ネイティブ データ クエリが無効になっている場合に、アクセス許可と現在のビューを考慮するようになりました。
  • ユーザー ピッカーは、スクロール中にユーザーの追加にアクセスできるようにし、ユーザーが存在しない場合はユーザー追加フォームを自動的に開きます。テンプレート ガイドとアプリのプレビューには、より明確な検証、応答性の高いレイアウト、およびより信頼性の高いサインアウト動作も含まれています。
  • 無効または取り消されたアプリ セッションでは、サーバー エラーが表示されるのではなく、ユーザーがログイン ページに戻されるようになりました。生成されたアプリのプレビューが起動中に停止する可能性が低くなります。
  • アプリの保存、ロールバック、公開、複製、インポートと再試行の信頼性が向上しました。無効なクエリではアクション可能なフィールドと演算子の詳細が表示されるようになりましたが、出力のみのスキーマ変更では保存をブロックするのではなく警告が生成されます。
  • フィールド削除のプレビューで、影響を受けるアプリと名前付きクエリが特定されるようになりました。
  • リクエストが拒否された場合やプレビューが中断された場合でも、インライン アプリの編集と保存の再試行がより確実に回復されるようになりました。重複して保存すると、サーバー エラーではなく、再試行可能な競合が返されます。
  • 公開されたアプリは、暗号化キーのローテーション後の構成変更を誤って報告しなくなり、環境変数を再暗号化しても元の変更タイムスタンプが保持されます。
  • 自動認証情報のセキュリティと Webhook 認証の信頼性が向上しました。
  • スペースあたりのデフォルトの同時ルーチン実行制限は、10 ではなく 5 になりました。既存の管理者オーバーライドは変更されません。バッチが大きい場合は、完了までに時間がかかる場合があります。
  • テーブルの作成では、新しいフィールド設定を上書きしたり、重複したリンク フィールドを作成したりすることなく、一時的な競合からより確実に回復できるようになりました。
  • チャット スキルとメンション メニューは、フォーカスが他の場所に移動したときに正しく閉じられ、スキル マネージャーのスクロールバーがカードと重なりなくなりました。返信テーブルは水平スクロールでも読みやすい列幅を維持し、アクション メニューは長いラベルに適切に対応します。
  • レコード選択をクリアすると、明示的に選択されたレコードが正しく削除されるようになりました。
  • フォルダーの削除ダイアログは、完了するまで開いたままになります。ゴミ箱操作では、より明確な進行状況と部分復元のフィードバックが提供され、障害後の回復がより確実になり、モバイル レイアウトと長い名前の処理が改善されました。
  • ID によってレコードを貼り付けると、列の順序、値のマッピング、元に戻すとやり直し、権限、および部分完了の動作を維持しながら、必要な列がより確実に作成されます。
  • 無効または破損した Tea パッケージでは、より明確な検証エラーが表示されるようになり、一時的なプレビューの失敗によって有効なインポートが不必要にブロックされなくなりました。
  • Mobile App Builder の会話で正しいアプリ コンテキストが使用されるようになりました。最初の返信後に新しい会話がフリーズすることはなくなり、ステータス バーのタップ後にチャットの位置が保持され、通知により適切なアプリとページが開きます。
  • モバイルのコールド スタート時またはワークスペースの切り替え後、アプリは最後の会話を復元するのではなく、最初にアクセス可能なプロジェクトで新しい会話を開くようになりました。プロジェクトのないワークスペースでは、引き続きプロジェクトの作成が表示されます。
  • ビューを指定しないテーブル レベルのコピーでは、デフォルト ビューのフィルター、並べ替え、非表示フィールド、またはフィールド順序が継承されなくなりました。また、コピーするとカスタムの日付と時刻の書式設定が保持され、無効な負の行座標が拒否されます。
  • 設定ページでは、無駄なスペースが少なく、中央に配置された応答性の高いレイアウトが使用されるようになりました。検索は完全な結果を返せなかったため、アーカイブされたチャットから削除されました。
  • 評価フィルター値をエラーなしでクリアできるようになりました。カンバンのドラッグは横スクロール時の安定性が向上し、AI チャットは一時的なネットワーク障害からより確実に回復します。
  • 非表示フィールドを許可する共有フォームでは、表示されている必須フィールドが一貫して検証されるようになりました。これらのフィールドが不足している送信は拒否されますが、非表示の必須フィールドはオプションのままです。
  • リンク フィールドを削除しても、そのデータを共有している他のアクティブなフィールドがレコード ビュー、エクスポート、または公開アプリで失敗することがなくなりました。この修正では、以前に影響を受けたテーブルが自動的に修復されたり、欠落したデータが復元されたりすることはありません。
  • 設定、ナビゲーション、通知、電子メール テンプレート、数式、権限、AI 機能など、サポートされている言語全体で用語、翻訳、文法、ステータス メッセージが改善されました。
  • 削除されたテーブル リンクまたはアクセス不能なテーブル リンクを開くと、テーブルが利用できないことが 1 つ通知され、アクセス可能なプロジェクトの場所にリダイレクトされるようになりました。
  • ワークスペース リソースとチャットの検索結果は独立して読み込まれるため、一方が失敗した場合でも、一方が利用可能な状態を維持できます。フィルタリングとページネーションが改善され、古いチャットの一致とすべての有効なリソース タイプが検出可能になります。

teable release.2026-11-13T02-21-01Z.3890

Feature Updates

  • Record searches now support multiple fields, space-separated keywords, and phrase, all-terms, and exact matching modes.
  • App builders can preview apps as a selected user without a sign-in code for up to one hour. Sign-in settings now provide a compact user picker that disables users blocked by domain rules and lets builders end the preview directly.
  • Templates now support interactive Get Started guides with progress saved across sessions, automatic completion checks, contextual links, AI assistance, and eligible manual steps. Creators can draft guides with AI and try them in a copy before publishing.
  • Structured queries now support formula-based metrics, per-metric filters, and aggregate-level filtering. Query expressions use the same formula syntax as formula fields, replacing the previous v3 query-only expression syntax; v1 and v2 formats remain unchanged.
  • Credential management now supports case-insensitive search by app or project name or ID, with bulk actions limited to matching results.
  • CLI commands now group AI field operations under field and imports under import. The new field ai-status --poll command waits for AI fills across one or more fields to finish. Legacy standalone commands remain compatible for this release but are deprecated and will be removed after one release.
  • Resource pane tabs can now be reordered by dragging. Project names also provide quick access to create, more, rename, and delete actions.
  • Folders can now be moved to the trash together with all nested folders and resources, with confirmation before deletion begins.
  • Artifact sharing is now available through the CLI and authorized APIs, with space-only or public links, optional passwords, and expiration dates. New CLI shares require an explicit scope, and disabling sharing invalidates the link.
  • Tea package imports now show a confirmation preview with the project name, content counts, and a collapsible folder tree.
  • Automation scripts can send raw HTML email by setting bodyType to html. Markdown remains the default.
  • Secret owners can dismiss exposure warnings through the web interface for intentionally public keys after confirming that disclosure is safe.
  • Cmd+K now searches accessible chat titles and message content alongside workspace resources. Chat results include matching snippets and open at the relevant message, with separate filters and pagination for chats and resources.

Bug Fixes & Improvements

  • Searches through views now consistently preserve view filters and reject empty searches. All-field search covers searchable fields beyond the previous 20-field limit and improves performance on wide tables.
  • Aggregate queries now return more consistent totals, pagination, and null handling while respecting access permissions. Filtered checkbox percentage metrics return 0 instead of null when no records match.
  • CLI record counts and field statistics now respect permissions and the current view when native data queries are disabled.
  • The user picker keeps Add a user accessible while scrolling and opens the add-user form automatically when no users exist. Template guides and app previews also have clearer validation, responsive layouts, and more reliable sign-out behavior.
  • Invalid or revoked app sessions now return users to the login page instead of displaying a server error. Generated app previews are less likely to get stuck during startup.
  • Improved app save, rollback, publishing, duplication, and import-retry reliability. Invalid queries now show actionable field and operator details, while output-only schema changes produce a warning rather than blocking saves.
  • Field deletion previews now identify affected apps and named queries.
  • Inline app editing and save retries now recover more reliably after rejected requests or interrupted previews. Overlapping saves return a retryable conflict instead of a server error.
  • Published apps no longer incorrectly report configuration changes after encryption-key rotation, and re-encrypting environment variables preserves their original modification timestamps.
  • Improved automation credential security and webhook authentication reliability.
  • The default concurrent routine-run limit per space is now 5 instead of 10. Existing administrator overrides remain unchanged; large batches may take longer to complete.
  • Table creation now recovers more reliably from temporary conflicts without overwriting newer field settings or creating duplicate linked fields.
  • Chat skill and mention menus close correctly when focus moves elsewhere, and the Skills manager scrollbar no longer overlaps cards. Reply tables retain readable column widths with horizontal scrolling, and action menus better accommodate long labels.
  • Clearing a record selection now correctly removes explicitly selected records.
  • Folder deletion dialogs remain open until completion. Trash operations now provide clearer progress and partial-restore feedback, recover more reliably after failures, and offer improved mobile layouts and long-name handling.
  • Pasting records by ID more reliably creates required columns while preserving column order, value mapping, undo and redo, permissions, and partial-completion behavior.
  • Invalid or corrupted Tea packages now show clearer validation errors, while temporary preview failures do not unnecessarily block valid imports.
  • Mobile App Builder conversations now use the correct app context. New conversations no longer freeze after the first reply, chat position is preserved after status-bar taps, and notifications open the correct app and page.
  • On mobile cold starts or after switching workspaces, the app now opens a new conversation in the first accessible project instead of restoring the last conversation. Workspaces without projects continue to show project creation.
  • Table-level copying without a specified view no longer inherits default-view filters, sorting, hidden fields, or field order. Copying also preserves custom date and time formatting and rejects invalid negative row coordinates.
  • Settings pages now use a centered, responsive layout with less wasted space. Search has been removed from Archived Chats because it could not return complete results.
  • Rating filter values can now be cleared without errors. Kanban dragging is more stable during horizontal scrolling, and AI chat recovers more reliably from temporary network failures.
  • Shared forms that allow hidden fields now consistently validate visible required fields. Submissions missing those fields are rejected, while hidden required fields remain optional.
  • Deleting a link field no longer causes other active fields sharing its data to fail in record views, exports, or published apps. This fix does not automatically repair previously affected tables or restore missing data.
  • Improved terminology, translations, grammar, and status messages across supported languages, including settings, navigation, notifications, email templates, formulas, permissions, and AI features.
  • Opening a deleted or inaccessible table link now redirects to an accessible project location with a single notice that the table is unavailable.
  • Workspace resource and chat search results load independently, so one can remain available if the other fails. Improved filtering and pagination keep older chat matches and all enabled resource types discoverable.
