#カウエージェント2.2.1

🌐 英語 | 中文

📁 アーティファクト

新しい アーティファクト ページには、Web コンソールとデスクトップ client の両方で会話中に作成されたファイルがまとめられています。

  • 自動収集: エージェントが作成したドキュメント、Web ページ、画像、ビデオは、すべてのエージェントにわたって 1 つのタイムライン上に自動的にアーティファクトに表示されます。
  • プレビューとトレースバック: タイプまたはエージェントでフィルターし、検索し、その場でプレビューし、ファイルを生成した会話に戻ります (@rudycelekli #3732 に感謝)。
  • 固定と管理: アーティファクトを固定、名前変更、または削除します。会話内のファイル カードを使用すると、アーティファクト内のファイル カードに直接アクセスできます。 [アーティファクト] ページはデフォルトでは非表示になっていますが、メニュー エディタでオンにできます。

🧭 カスタムメニューとコンソールの改善

  • カスタム メニュー: 1 つの共有構成で、Web コンソールとデスクトップ client のメニュー エントリのグループ、順序、名前、アイコン、表示をカスタマイズします。アーティファクトと Web リンクをメニュー エントリとして追加できます。 カスタムメニューを参照してください。
  • トークンの使用量: 各応答には、キャッシュ ヒットを含む、そのターンで実際に使用されたトークンが表示されます。ありがとう @Harbor404 (#3440)
  • マーメイド ダイアグラム: マーメイド コード ブロックは、ズームおよび全画面表示のレンダリングされたダイアグラムに切り替えることができます。ありがとう@akushonkamen (#3620)
  • 長時間セッションの高速化: 多くのツール呼び出しを伴う長時間セッションがより速く開始されます。
  • 修正: 新しいセッション タイトルが失われることはなくなり、デフォルトのエージェントでのセッション アクションは失敗しなくなりました (@6vision #3625、#3617 に感謝)。一緒に保存された設定がすべて有効になり、ワークスペース ファイルが所属するエージェントの下に保存されるようになりました (@aniruddhaadak80 #3454、#3488 に感謝)。
  • 折りたたみ可能なサイドバー: Web コンソールのサイドバーはアイコン レールに折りたたむことができます。

🔌 エージェント チャット API を開く

エージェントは標準チャット API を通じて利用できるようになったので、サードパーティの client に接続したり、独自のシステムから直接エージェントに電話したりできます。

  • スイッチとキー: API をオンにし、Config ページの 1 つの click で API キーを生成します。 API の電源をオフにしてもキーは保持されます。構成ファイルまたは環境変数を通じて有効にすることもできます (@AaronZ345 #3068、@Bdysj #3342 に感謝します)。
  • エージェントとモデルの選択: agent_id のエージェントと model のモデルを選択します。モデルがない場合は、エージェントのデフォルト モデルが使用されます。
  • 複数ターンの会話: デフォルトでは、発信者は完全なメッセージ履歴を送信します。 conversation_id の場合、サーバーは履歴を保持するため、最新のメッセージのみを送信する必要があります。
  • 完全な出力: ストリーミング応答と非ストリーミング応答 (推論、トークン使用法、ツール呼び出しトレースを含む) (@AaronZ345 #3068、@c020627 #3545、#3588 に感謝)。

📐 プロンプトキャッシュとコンテキストコスト

  • クロード プロンプト キャッシュ: システム プロンプト、ツール定義、会話プレフィックスがキャッシュされるため、キャッシュ ヒット率が大幅に向上し、トークン コストと遅延が削減されます。キャッシュの有効期間は、claude_cache_ttl を介して構成できます。
  • トリミング後のヘッドルーム: コンテキストをトリミングするとヘッドルームが残るようになったため、プレフィックスは次の数ターンの間変更されず、長いセッションがキャッシュにヒットし続けます。
  • 予算の変更はすぐに適用されます: コンテキストの予算と最大ステップ数への変更は、セッションをクリアすることなく、実行中のエージェントにすぐに適用されます。
  • 工具レコードは圧縮で保持されます: 圧縮されたターンは工具呼び出しの概要を保持するため、モデルは結果を構成しません (@tsumon #3634 に感謝します)。
  • 修正: 圧縮中に到着したメッセージは失われなくなり、孤立したツールの結果がより正確にクリーンアップされます (@c020627 #3518、@rudycelekli #3652、#3653 に感謝します)。

🤖 モデルの機能

  • クロード拡張思考: 長い思考の間、接続は開いたままになり、出力が停止すると、リクエストはより低い思考労力で再試行されます。
  • カスタム ヘッダー: カスタム モデル プロバイダーは、OpenCode Go をサポートする headers をサポートします。
  • モデルの検出: モデル リストを編集するときに、利用可能なモデルをプロバイダーから自動的に取得できます。ありがとう @Harbor404 (#3441)
  • 推論コンテンツ: reasoning フィールドと thinking フィールドの両方がサポートされており、閉じられていない <think> タグによって応答が切断されることはなくなりました (@a1094174619 #3601、@fly0sheep-1734 #3538 に感謝します)。
  • フォールバック モデル: フォールバック モデルは、使用し続けるのではなく、各ターンの開始時にリセットされます。
  • OpenAI: 応答 API とストリーミング応答の処理を改善しました (@rudycelekli #3659、#3660、#3661、#3663、@aniruddhaadak80 #3486 に感謝します)。
  • モデル リスト: 相互に上書きする同時編集、有効にならないカスタム プライマリ モデル、および機能タグのマッチングを修正しました (@rudycelekli #3577、#3662、#3666、@aniruddhaadak80 #3501 に感謝)。
  • その他のプロバイダ: MiniMax、ModelScope、Baidu ERNIE、および Azure DALL·E との互換性の問題を修正しました (@aniruddhaadak80 #3464、#3476、#3479、#3507、#3512、@rudycelekli #3678 に感謝)。
  • エラー処理: 拒否されたリクエストは再送信されなくなり、エラーはより正確に認識され、コンテキストの使用状況により実際のトークン数が表示されます (@c020627 #3442、#3443、#3445、@aniruddhaadak80 #3505、@6vision #3624 に感謝します)。
  • 画像: 画像生成では元の形式とプロンプトが維持され、macOS での画像理解で画像がアップスケールされなくなりました (@aniruddhaadak80 #3503、#3504、@rudycelekli #3568 に感謝)。

🧠 記憶と知識ベース

  • ナレッジの編集とスキルのオーサリング: インデックスが自動的に更新される状態でコンソールでナレッジ ベース ページを直接編集し、スキルを最初から作成し、スキルのディレクトリ内のファイルを編集します。ありがとう@zkjqd (#3377)

CowAgent 2.2.1

Highlights

  • Open Agent Chat API — Integrate Agents through streaming or non-streaming chat requests. Select the Agent with agent_id and optionally override its model; callers can submit full history or use conversation_id for server-managed state. Responses include reasoning, token usage, and tool-call traces, and API keys persist across disable/re-enable cycles (#3068, #3342, #3545, #3588).
  • Prompt caching and live context tuning — Claude caching now covers system prompts, tool definitions, and conversation prefixes, with lifetime controlled by claude_cache_ttl. Context trimming preserves prefix reuse, while context-budget and maximum-step changes apply immediately to running Agents—useful for tuning, but potentially disruptive to in-flight behavior without a session restart.
  • Stricter security boundaries — Read-only mode now blocks previously missed Git writes and detects command substitution, argument-based writes, and root deletion. Outside full-access mode, MCP configuration and session permissions cannot be changed; path validation, credential blocking, download limits, and secret redaction are also tightened (#3352, #3357, #3579, #3602, #3446). Automation relying on permissive behavior may need permission or path adjustments.
  • Provider compatibility and error semantics — Custom provider headers, automatic model discovery, and both reasoning and thinking response fields broaden integration options, including OpenCode Go. Fallback models now reset at every turn rather than remaining sticky, rejected requests are no longer retried, and OpenAI Responses API/streaming handling is improved (#3441, #3601, #3659–#3663).
  • Artifacts as shared workspace state — Generated documents, pages, images, and videos are collected into a searchable, cross-Agent timeline with previews, management controls, and links back to their originating conversations (#3732). The page is opt-in through the menu editor, and its entries share the new Web/desktop custom-menu configuration.
  • Breaking changes — None announced.

📁 Artifacts

A new Artifacts page brings together the files created in your conversations, in both the Web console and the desktop client:

  • Automatic collection: documents, web pages, images, and videos your Agents create show up in Artifacts automatically, on one timeline across all Agents.
  • Preview and trace back: filter by type or Agent, search, preview in place, and jump back to the conversation that produced a file (Thanks @rudycelekli #3732).
  • Pin and manage: pin, rename, or remove artifacts; a file card in a conversation takes you straight to it in Artifacts. The Artifacts page is hidden by default and can be turned on in the menu editor.

🧭 Custom Menu & Console Improvements

  • Custom menu: customize the groups, order, names, icons, and visibility of menu entries in the Web console and desktop client, with one shared configuration; artifacts and web links can be added as menu entries. See Custom Menu.
  • Token usage: each reply shows the tokens actually used in that turn, including cache hits. Thanks @Harbor404 (#3440)
  • Mermaid diagrams: Mermaid code blocks can switch to a rendered diagram, with zoom and full screen. Thanks @akushonkamen (#3620)
  • Faster long sessions: long sessions with many tool calls open faster.
  • Fixes: new session titles are no longer lost, and session actions on the default Agent no longer fail (Thanks @6vision #3625, #3617); settings saved together now all take effect, and workspace files are saved under the Agent they belong to (Thanks @aniruddhaadak80 #3454, #3488).
  • Collapsible sidebar: the Web console sidebar can collapse into an icon rail.

🔌 Open Agent Chat API

Agents are now available through a standard chat API, so you can connect third-party clients or call an Agent directly from your own systems:

  • Switch and key: turn the API on and generate an API key in one click on the Config page; the key is kept when the API is turned off. It can also be enabled through the config file or environment variables (Thanks @AaronZ345 #3068, @Bdysj #3342).
  • Agent and model selection: choose the Agent with agent_id and the model with model; without a model, the Agent's default model is used.
  • Multi-turn conversations: by default the caller sends the full message history; with a conversation_id, the server keeps the history and only the latest message needs to be sent.
  • Complete output: streaming and non-streaming responses, including reasoning, token usage, and the tool call trace (Thanks @AaronZ345 #3068, @c020627 #3545, #3588).

Related docs: Chat API

📐 Prompt Caching & Context Cost

  • Claude prompt caching: the system prompt, tool definitions, and conversation prefix are cached, greatly improving cache hit rates and cutting token cost and latency. The cache lifetime is configurable via claude_cache_ttl.
  • Headroom after trimming: trimming the context now leaves headroom, so the prefix stays unchanged for the next several turns and long sessions keep hitting the cache.
  • Budget changes apply immediately: changes to the context budget and maximum steps apply to running Agents right away, without clearing the session.
  • Tool records kept in compaction: compacted turns keep a summary of their tool calls, so the model does not make up results (Thanks @tsumon #3634).
  • Fixes: messages arriving during compaction are no longer lost, and orphaned tool results are cleaned up more accurately (Thanks @c020627 #3518, @rudycelekli #3652, #3653).

🤖 Model Capabilities

  • Claude extended thinking: the connection stays open during long thinking, and when output stalls the request is retried at a lower thinking effort.
  • Custom headers: custom model providers support headers, with support for OpenCode Go.
  • Model discovery: when editing a model list, available models can be fetched from the provider automatically. Thanks @Harbor404 (#3441)
  • Reasoning content: both reasoning and thinking fields are supported, and an unclosed <think> tag no longer cuts off the reply (Thanks @a1094174619 #3601, @fly0sheep-1734 #3538).
  • Fallback models: the fallback model is reset at the start of each turn instead of staying in use.
  • OpenAI: improved handling of the Responses API and streaming responses (Thanks @rudycelekli #3659, #3660, #3661, #3663, @aniruddhaadak80 #3486).
  • Model list: fixed concurrent edits overwriting each other, custom primary models not taking effect, and capability tag matching (Thanks @rudycelekli #3577, #3662, #3666, @aniruddhaadak80 #3501).
  • Other providers: fixed compatibility issues with MiniMax, ModelScope, Baidu ERNIE, and Azure DALL·E (Thanks @aniruddhaadak80 #3464, #3476, #3479, #3507, #3512, @rudycelekli #3678).
  • Error handling: rejected requests are no longer resent, errors are recognized more accurately, and context usage shows real token counts (Thanks @c020627 #3442, #3443, #3445, @aniruddhaadak80 #3505, @6vision #3624).
  • Images: image generation keeps the original format and prompt, and image understanding on macOS no longer upscales images (Thanks @aniruddhaadak80 #3503, #3504, @rudycelekli #3568).
