#カウエージェント2.1.8

🌐 英語 | 中文

🤝 マルチエージェント チーム

CowAgent は マルチエージェント フレームワークになりました。それぞれに独自の役割を持つ複数のエージェントを作成してチームを形成し、単一セッション内で複雑なタスクに共同で取り組むことができます。 Web コンソール、デスクトップ client、およびチャネル統合でサポートされています。

  • チーム管理: エージェントを作成および維持し、名前、責任、デフォルトのモデル、スキル、および知識を構成し、既存のエージェントからセットアップをコピーします。
  • リソースの分離: 各エージェントには独自のワークスペース、メモリ、セッションがあります。知識ベースとスキルは共有することも、独立したままにすることもできます。

<フレーム> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/team-overview.png" alt="エージェント チーム" width="800" /> </フレーム>

  • グループ コラボレーション: 複数のエージェントを 1 つのセッションに追加し、@ を使用してメッセージを特定のメンバーに送ります。各エージェントは独自の構成モデルを使用します。
  • タスク委任: グループ チャットにはリード エージェントがあり、責任に基づいてそのタスクに最も適したメンバーにタスクを引き継ぐことができ、マルチレベルの委任と構成可能なスコープ、深さ、タイムアウトがサポートされています。

<フレーム> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/agent-group-chat-demo.png" alt="エージェント チーム グループ" width="800"/> </フレーム>

  • 複数のチャネル インスタンス: 同じタイプの IM チャネルで、それぞれが 1 つのエージェントまたはエージェント チームにバインドされた複数のインスタンスを実行できるようになりました。 WeChat、WeCom スマート ボット、Feishu、DingTalk、QQ、Telegram、Slack、Discord などでサポートされています。

<フレーム> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/channel-config.png" alt="エージェント チーム チャネル" width="800"/> </フレーム>

@AaronZ345 (#2975、#2973)、@zkjqd (#3096)、@cowagent (#3118) に感謝します。

ドキュメント: エージェント チーム

⏰ スケジュールされたタスクのアップグレード

チャネル受信者と実行レコードを追加して、スケジュールされたタスクをコンソールから作成および管理できるようになりました。

  • 手動タスク作成: タスク ページで直接タスクを作成、編集、実行し、チャネル インスタンスと受信者を選択します。
  • チャネル受信者管理: チャネル インスタンスごとに trusted 受信者を維持するため、タスクが作成されたチャネルのみではなく、指定された受信者にタスクを配信できます。ありがとう@dajiaohuang (#3043)
  • 実行記録: 新しい実行記録ページでは、履歴リストと各実行の詳細を確認できます。ありがとう @mengluo04 (#3107)
  • 同時更新の修正: 同時更新で失われるタスクを修正しました (@Whxuan0701 #3062 に感謝)。

<フレーム> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/scheduler-create.png" width="800"/> </フレーム>

📊 コンテキストの使用状況の視覚化

コンテキストの消費が可視化および制御可能になり、トークン コストの管理が容易になりました。

  • コンテキスト使用状況ビュー: リング ビューは以前のクリア コンテキスト ボタンを置き換え、コンテキストを構成するものの完全な内訳を表示します。
  • コンテキスト アクション: リング ビューの下で、スマート コンパクションをトリガーしたり、コンテキストをクリアしたり、最大コンテキスト サイズを設定したりできます。
  • コンテキスト計算: 使用量の内訳は、ユーザーが構成可能なコスト キャップとして agent_max_context_tokens を使用して、モデルの報告された使用量から自動的に導出されます。

@chimyves (#3087)、@sufan721 (#3079) に感謝します。

🤖 モデルの機能

  • 新しいモデル: deepseek-flash (DeepSeek V4.1 Flash)、gpt-6-astra、claude-fable-5-1、qwen3.8-flash、glm-5.3-flash、gemini-3.8-flash、およびビジョン モデル deepseek-v4-flash-vision-exp を追加しました (@a1094174619 #3094 に感謝)。
  • モデル フォールバック: [モデル構成] > [プライマリ モデル] でフォールバック モデルを構成します。これはプライマリ モデルに障害が発生したときに自動的に引き継ぎ、単一プロバイダーの停止による中断を防ぎます。ありがとう @alanyz106 (#3099)
  • 6 つの新しい検索プロバイダー:
    • AnySearch (匿名モードをサポート)。ありがとう@WangPan59 (#3083)
    • Serply (Google/Bing SERP API)。ありがとう@googio (#3071)
    • 並列検索。ありがとう@georgeatParallel (#3116)
    • Tavily (LLM 用に最適化された API を検索)。ありがとう @1printf (#3124)
    • SearXNG (自己ホスト型検索エンジン、インスタンス URL のみが必要です)。ありがとう @1printf (#3124)
    • Keenable (匿名モードをサポート、API キーは必要ありません)。ありがとう@ilya-bogin-keenable (#3122)

📝 ワークスペースファイルの編集

ワークスペース ファイル、長期記憶ドキュメント、スキル定義を Web コンソールとデスクトップ client で直接編集および保存できるようになりました。

  • インプレース編集: ワークスペース、メモリ、スキル モジュール内のテキスト ファイル (マークダウン、コード、CSV、HTML、プレーン テキストなど) は、Ctrl+S で保存、Esc で終了、Tab でインデントするキーボード ショートカットを使用して直接編集できます。
  • 安全な保存: 保存すると、ファイルを開いたときにファイルの変更時刻との競合がチェックされます。その間にエージェントがファイルを変更した場合は、ファイルを上書きするのではなく、最初に尋ねられます。パネルを閉じる、ファイルを切り替える、セッションを切り替える、またはワークスペースを切り替えると、保存されていない変更について確認を求めるプロンプトが表示されます。

ありがとう@zkjqd (#3076)

  • 構造化チャンク: マークダウン メモリとナレッジ ドキュメントは見出し構造によってチャンク化され、チャンクのバージョンが古い場合には再構築するよう求めるプロンプトが表示されます。ありがとう @alanyz106 (#3115)

CowAgent 2.1.8

Highlights

  • Multi-Agent teams become the core abstraction — This is the architectural centerpiece: CowAgent shifts from a single agent to a team framework where each agent carries its own role, model, skills, and isolated workspace/memory/sessions. What matters for adopters is @-mention routing in group chats and lead-agent delegation with configurable scope, depth, and timeout (#2975, #2973, #3096, #3118). Watch the channel config: the same IM type can now run multiple instances bound to different agents/teams, so existing single-instance bindings may need re-mapping; luckily backup/restore now includes all agent workspaces.

  • Scheduled tasks graduate to a first-class console object — Tasks can be created, edited, and run from the tasks page instead of only from chat, and trusted per-channel recipients decouple delivery from the channel that created the task — relevant if you want task output routed to a designated person rather than a noisy group (#3043, #3107). The concurrency fix (#3062) is the sneaky one: tasks were being lost under concurrent updates, so if you rely on scheduled jobs, this alone justifies the upgrade.

  • Context usage replaces the clear-context button — A behavioral/UI change: the old one-click clear button is gone, replaced by a ring view with a full breakdown; the clear/compaction actions now live below it (#3087, #3079). The meaningful addition for cost control is agent_max_context_tokens as a configurable cap, with the breakdown derived from the model's reported usage — useful for predictable spend, but expect to retrain users where the clear action moved.

  • Model fallback and new providers reduce single-vendor risk — A primary-model fallback under Model Config > Primary Model takes over automatically on provider failure (#3099), which matters more than the seven new models for production uptime. Six new search providers broaden data-source options, notably self-hosted SearXNG (just an instance URL) and the anonymous/keyless AnySearch and Keenable — relevant where privacy or data residency constrains provider choice (#3124, #3083, #3122, #3116, #3071, #3094).

  • In-place editing of workspace, memory, and skill files — You can now edit and save text files directly in the Web/desktop console with Ctrl+S/Esc/Tab (#3076). The important detail is mtime-based conflict detection: if the agent modified the file since you opened it, you're prompted rather than silently overwritten — a real safeguard now that agents and humans share the same files. Unsaved changes also trigger confirmation on panel/file/session/workspace switches.

  • Silent-failure fixes worth upgrading for — Several changes target failures that previously surfaced as opaque errors: streaming errors from seven model bots raised a NameError that masked the real upstream error (#3128); blank text chunks broke the entire memory index build and forced keyword-search fallback (#3121); and stop_reason is now passed through the agent loop so truncation by output limit is distinguishable from a natural stop (#3074). Combined with heading-based Markdown chunking that prompts a rebuild on version change (#3115) and MCP tool-name prefixes plus expired Streamable HTTP session recovery (#3116), these harden reliability without changing APIs.

No breaking changes.

🤝 Multi-Agent Teams

CowAgent is now a multi-Agent framework. You can create multiple Agents, each with its own role, to form a team and collaborate on complex tasks within a single session. Supported on the Web console, the desktop client, and channel integrations:

  • Team management: create and maintain Agents, configure name, responsibilities, default model, skills, and knowledge, and copy the setup from an existing Agent.
  • Resource isolation: each Agent has its own workspace, memory, and sessions; the knowledge base and skills can be shared or kept independent.
<Frame> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/team-overview.png" alt="Agent team" width="800" /> </Frame>
  • Group collaboration: add multiple Agents to one session and use @ to direct a message to a specific member, with each Agent using its own configured model.
  • Task delegation: a group chat has a lead Agent that can hand a task off to the member best suited for it based on their responsibilities, with support for multi-level delegation and configurable scope, depth, and timeout.
<Frame> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/agent-group-chat-demo.png" alt="Agent-team-group" width="800"/> </Frame>
  • Multiple channel instances: an IM channel of the same type can now run multiple instances, each bound to a single Agent or an Agent team. Supported on WeChat, WeCom smart bots, Feishu, DingTalk, QQ, Telegram, Slack, Discord, and more.
<Frame> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/channel-config.png" alt="Agent-team-channel" width="800"/> </Frame>

Thanks @AaronZ345 (#2975, #2973), @zkjqd (#3096), @cowagent (#3118)

Docs: Agent Teams

⏰ Scheduled Task Upgrades

Scheduled tasks can now be created and managed from the console, with channel recipients and execution records added:

  • Manual task creation: create, edit, and run tasks directly on the tasks page, and select the channel instance and recipient.
  • Channel recipient management: maintain trusted recipients per channel instance, so a task can be delivered to a designated recipient rather than only the channel where it was created. Thanks @dajiaohuang (#3043)
  • Execution records: a new execution-records page lets you review the history list and the details of each run. Thanks @mengluo04 (#3107)
  • Concurrent-update fix: fixed tasks being lost on concurrent updates (Thanks @Whxuan0701 #3062).
<Frame> <img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/scheduler-create.png" width="800"/> </Frame>

📊 Context-Usage Visualization

Context consumption is now visible and controllable, making token cost easier to manage:

  • Context-usage view: a ring view replaces the previous clear-context button and shows a full breakdown of what makes up the context.
  • Context actions: below the ring view you can trigger smart compaction, clear the context, or set the maximum context size.
  • Context calculation: the usage breakdown is derived automatically from the model's reported usage, with agent_max_context_tokens available as a user-configurable cost cap.

Thanks @chimyves (#3087), @sufan721 (#3079)

🤖 Model Capabilities

  • New models: added deepseek-flash (DeepSeek V4.1 Flash), gpt-6-astra, claude-fable-5-1, qwen3.8-flash, glm-5.3-flash, gemini-3.8-flash, and the vision model deepseek-v4-flash-vision-exp (Thanks @a1094174619 #3094).
  • Model fallback: configure a fallback model under Model Config > Primary Model, which takes over automatically when the primary model fails, preventing interruptions from a single provider outage. Thanks @alanyz106 (#3099)
  • Six new search providers:
    • AnySearch (supports anonymous mode). Thanks @WangPan59 (#3083)
    • Serply (Google/Bing SERP API). Thanks @googio (#3071)
    • Parallel Search. Thanks @georgeatparallel (#3116)
    • Tavily (search API optimized for LLMs). Thanks @1printf (#3124)
    • SearXNG (self-hosted search engine, only the instance URL is required). Thanks @1printf (#3124)
    • Keenable (supports anonymous mode, no API key required). Thanks @ilya-bogin-keenable (#3122)

📝 Workspace File Editing

Workspace files, long-term memory documents, and skill definitions can now be edited and saved directly in the Web console and the desktop client:

  • In-place editing: text files in the workspace, memory, and skill modules (Markdown, code, CSV, HTML, plain text, and more) can be edited directly, with keyboard shortcuts for Ctrl+S to save, Esc to exit, and Tab to indent.
  • Safe saving: saving checks for conflicts against the file's modification time when it was opened; if the Agent changed the file in the meantime, you are asked first instead of overwriting it. Closing the panel, switching files, switching sessions, or switching workspaces prompts for confirmation on unsaved changes.

Thanks @zkjqd (#3076)

  • Skill fixes:

  • Desktop client: check for updates and update with one click inside the client, or get the latest version from the download page.
