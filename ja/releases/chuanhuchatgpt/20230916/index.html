ChuanhuChatGPT 20230916

Highlights

  • Complete Gradio-based UI/UX rebuild — The interface was redesigned end to end: adaptive history panel + menu bar + chat area + toolbar, glassmorphism styling, a reworked input box, mobile-specific layouts with safe-area margins, and drawer-style toolbar/settings. This is a visual and interaction overhaul rather than a feature toggle, so custom CSS, themes, and UI-driven tests are likely to break; Gradio is pinned to 3.34.2 in this release.
  • Conversation history as a managed list — History is now shown as a list with rename and delete, auto-generated names derived from the first question and content summaries, name search including regex, and improved download/export plus upload of history. For users this turns chat logs into portable, searchable data; for integrators it means the history export/import paths changed and should be re-tested.
  • Installable PWA target — Chuanhu Chat can now be installed as a PWA: desktop browsers surface an install prompt, mobile browsers offer add-to-home-screen, and the icon was redesigned to work both cropped and standalone. Self-hosters gain an app-like web deployment, but need a valid manifest and service worker served over HTTPS for the install affordance to appear.
  • Model-layer expansion and context-preserving switching — Adds iFlytek Spark (讯飞星火) support and in-app finetuning of GPT-3.5, and lets you switch models inside the same conversation while retaining prior context. This is the most consequential change for anyone wiring up providers: adding a backend or letting users swap models no longer forces a context reset, which changes how multi-provider fallback can be designed.
  • Rich input area and actionable message bubbles — Web search, file-grounded Q&A, and single-turn mode are activated directly from the input area, and bubbles now expose delete, retry, and like on the latest message. Capabilities that previously lived in separate panels move into the composer, reducing UI surface area but changing the interaction paths that automation and tests must exercise.
  • Manual upgrade path and runtime changes — Users coming from the 20230911 beta may find the in-app update button unresponsive and must update manually, then run pip install -r requirements.txt to refresh dependencies. Also note the Gradio 3.34.2 bump, logging level set to info, locale aliases accepted in both en_US and en-US forms, read-only history now applying only when logged out with hide_history_when_not_logged_in set, plus fixes for Azure OpenAI, file-parse failure isolation, Windows paths, and bubble overflow.

No breaking changes in this release.
