アルゴ-cd v3.3.19

[!重要] サポート終了のお知らせ

これは、v3.3 リリース シリーズの最後のリリースです。 2026 年 11 月 3 日の時点で、このバージョンはサポート終了となり、バグ修正やセキュリティ アップデートは提供されなくなります。

必要なアクション: サポートされているバージョン (v3.4.13、v3.5.7、または v3.6.0) にアップグレードしてください。

クイックスタート

非HA:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.3.19/manifests/install.yaml

は:

kubectl create namespace argocd
kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.3.19/manifests/ha/install.yaml

リリースの署名と来歴

すべての Argo CD コンテナ イメージは連署によって署名されています。 SLSA レベル 3 仕様を満たすコンテナー イメージと CLI バイナリに対して来歴が生成されます。確認方法についてはドキュメントを参照してください。

Release Note のブログ投稿

このリリースの主な変更点と改善点の詳細については、公式ブログ投稿 をご覧ください。

argo-cd v3.3.19

Highlights

  • v3.3 is now end-of-life — This is the final v3.3 patch; after November 3, 2026, the series receives no bug fixes or security updates. Treat upgrading to v3.4.13, v3.5.7, or v3.6.0 as required, following the minor-version upgrade guide rather than treating this as a routine patch update.
  • ApplicationSet parameter and discovery fixes — Reserved cluster annotations are no longer exposed as generator parameters (#30480), narrowing what templates can consume; audit any ApplicationSets that referenced them. GitLab pull-request generators configured by project path now refresh correctly (#30622), addressing stale or missing PR-derived applications.
  • More accurate resource health — Crossplane Providers no longer fail solely because Installed or Healthy conditions are absent (#30626), inactive ManagedResourceDefinitions report Healthy (#30422), CNRM resources use status.healthy (#30656), and SealedSecret health waits for the current generation (#30356). Recheck monitoring and automation that compensated for previously false or stale health states.
  • Recoverable cancellations and cleaner timeouts — Operations blocked by sync windows can now be terminated (#30504); cancelled Git commands receive SIGTERM before SIGKILL (#30409), and exec timeouts no longer leak goroutines (#30434). Stuck syncs are therefore recoverable, with less resource leakage during cancellation.
  • Proxy, access, and stability edge cases — CLI gRPC-web connections now honor HTTP_PROXY, HTTPS_PROXY, and NO_PROXY (#30500); unauthenticated gRPC health checks are allowed (#30570); UserInfo cache limits are enforced when responses omit expires (#30619); and a / sourceNamespaces entry no longer causes a list-matching panic (#30612). Review probe exposure and proxy assumptions where applicable.
  • Repository and Ingress compatibility — OCI Helm repository URLs now accept IP-and-port forms (#30514), and TLS Ingresses without secretName generate HTTPS links (#30510). These remove connection and UI edge cases without requiring manifest changes.
  • Breaking changes — None are listed in this release.

[!IMPORTANT] END OF LIFE NOTICE

This is the final release of the v3.3 release series. As of November 3rd, 2026 this version has reached end of life and will no longer receive bug fixes or security updates.

Action Required: Please upgrade to a supported version (v3.4.13, v3.5.7, or v3.6.0).
