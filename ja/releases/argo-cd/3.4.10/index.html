セキュリティ修正

  • 重要: KusTOMize リモート参照はリポジトリ サーバーでコマンドを実行できる (GHSA-9v9p-x54c-58gc)
  • 重要: KusTOMize Helm 構成ホームはリポジトリ サーバーでコマンドを実行できます (GHSA-fw5c-w8rc-j7fx)
  • 重要: Jsonnet インポートはリポジトリ サーバーからファイルを読み取ることができます (GHSA-m3vr-7329-44ww)
  • クリティカル: PreDelete/PostDelete リソース フックによって AppProject の制限がバイパスされる (GHSA-fmxq-cgp8-87wp、CVE-2026-77459)
  • 高: ログイン失敗率制限は、同時リクエストによってバイパスできます (GHSA-4439-h7jw-5cjj、CVE-2025-61560)
  • 高: SSH Git リポジトリ上のリポジトリ プロキシ URL を介したコマンド インジェクション (GHSA-j6cw-g6p4-7hch、CVE-2026-55797)
  • 中程度: 任意の名前空間内のアプリケーションが有効な場合、拡張プロキシ RBAC はアプリケーションの名前空間を無視します (GHSA-g3ff-q88g-chrj)
  • 中度: 過大な OCI マニフェストにより、リポジトリ サーバーのメモリが使い果たされる可能性があります (GHSA-w996-f2wq-x9c6)

破壊的な可能性のある変更

  • Helm チャートをレンダリングする Customize ビルドでは、helmGlobals.configHome が考慮されなくなりました。通常の http、https、および oci チャート リポジトリは引き続き機能します。そのディレクトリから登録された Helm プラグインに依存するビルドは行われません (GHSA-fw5c-w8rc-j7fx)。
  • 4 MiB を超える OCI マニフェストは拒否されるようになりました (GHSA-w996-f2wq-x9c6)。

argo-cd v3.4.10

Highlights

  • Security-first patch, upgrade now — v3.4.10 is effectively an emergency security release: PR #30039 lands a coordinated set of fixes including four CRITICAL issues — Kustomize remote refs and Helm configHome enabling command execution in the repo-server, Jsonnet imports reading arbitrary repo-server files, and AppProject restrictions bypassable via PreDelete/PostDelete hooks (CVE-2026-77459). Also HIGH-severity login rate-limit bypass via concurrent requests (CVE-2025-61560) and SSH repo-proxy command injection (CVE-2026-55797). For anyone running multi-tenant Argo CD where users can submit repos or apps, this is a drop-everything upgrade; the写一篇 threat model here is untrusted manifests reaching the repo-server, not just the API surface.

  • Breaking: helmGlobals.configHome is ignored for Kustomize-rendered Helm charts — Kustomize builds that render Helm charts (GHSA-fw5c-w8rc-j7fx) no longer honor helmGlobals.configHome. Ordinary http, https, and oci chart repositories still work, but builds depending on a Helm plugin registered from that directory will break. Audit any kustomize + Helm setup that leans on custom config homes/plugins before rolling this out.

  • Breaking: 4 MiB OCI manifest ceiling — manifests larger than 4 MiB are now rejected outright (GHSA-w996-f2wq-x9c6) to close a repo-server memory-exhaustion vector. Teams publishing large OCI charts or image bundles should check manifest sizes and slim them down, since this is a hard functional cutoff rather than a warning.

  • Login attempts now record the username — the new server-side logging (#29860, cherry-pick of #29841) gives you an audit trail correlating failed/successful auth with specific accounts, which pairs directly with the concurrent-request rate-limit fix. Useful for spotting credential-stuffing that previously slipped under the rate limiter's radar.

  • Smaller fixes and dependency hardening — CMP .tgz stream temp directories are now cleaned up (#29148 / #29775) to avoid disk leaks in busy repo-servers, and the manifest viewer loses its jumpiness (#29691 / #29726). Dependency bumps include go-git/go-billy 5.9.0, golang.org/x/crypto 0.57.0, and js-yaml 4.3.2 — largely carrying forward upstream security patches rather than new features.

Changelog

Security fixes

  • CRITICAL: A Kustomize remote ref can run commands in the repo-server (GHSA-9v9p-x54c-58gc)
  • CRITICAL: A Kustomize Helm config home can run commands in the repo-server (GHSA-fw5c-w8rc-j7fx)
  • CRITICAL: A Jsonnet import can read files from the repo-server (GHSA-m3vr-7329-44ww)
  • CRITICAL: AppProject restrictions bypassed by PreDelete/PostDelete resource hooks (GHSA-fmxq-cgp8-87wp, CVE-2026-77459)
  • HIGH: Login failure rate limit can be bypassed via concurrent requests (GHSA-4439-h7jw-5cjj, CVE-2025-61560)
  • HIGH: Command injection via a repository proxy URL on SSH Git repositories (GHSA-j6cw-g6p4-7hch, CVE-2026-55797)
  • MODERATE: Extension proxy RBAC ignores application namespace when applications-in-any-namespace is enabled (GHSA-g3ff-q88g-chrj)
  • MODERATE: An oversized OCI manifest can exhaust repo-server memory (GHSA-w996-f2wq-x9c6)

Potentially-breaking changes

  • Kustomize builds that render Helm charts no longer honor helmGlobals.configHome. Ordinary http, https, and oci chart repositories still work. Builds that depended on a Helm plugin registered from that directory will not (GHSA-fw5c-w8rc-j7fx).
  • An OCI manifest larger than 4 MiB is now rejected (GHSA-w996-f2wq-x9c6).
