nocodb 2026.05.3

🐛 解決済みの問題

  • [終了] 🔦 機能: Community Edition 2026.05.2 #13928 で Web ページのファビコンと Web ページの静的タイトルを復元する
  • [クローズ] 🐛 バグ: 「スキーマ変更の許可」が無効になっているときに、V1 -> V2 リンクのアップグレードでスキーマが変更されました #13911
  • [終了] 🔦 機能: フォーム送信通知メールのカスタム件名 #13891
  • [クローズ] 🔦 機能: フォーム送信通知メールのプレーンテキスト オプション #13890
  • [クローズ] 🔦 機能: スイッチのオン/オフによるグループ化 #13851
  • [クローズ] 機能強化: すべてのテーブル タイプに CSV インポートによる一括レコード更新を追加 #13841
  • [閉鎖] Nocodb ドキュメントの公開共有? #13819
  • [クローズ] 🐛 バグ: リンクされたフィールドを更新しても GUI に変更が表示されない #13798
  • [クローズ] 🐛 バグ: V2 リンク — 多数の「+」ボタンからレコードを作成すると、親に自動リンクされません #13770
  • [クローズ] 🐛 バグ: UI で列を再配置した後、CSV エクスポートに列の順序が反映されない #13768
  • [クローズ] 🐛 バグ: テーブル A の同じ列を指す、テーブル B 内の複数の外部キー列の値が誤って表現されています #13759
  • [クローズ] 🐛 バグ: API キーは v2 API エンドポイントにアクセスできません - 403 "禁止 - 不正なアクセス" #13734
  • [クローズ] 🐛 バグ: 新しく作成されたアカウントがユーザー リストに「1 時間前」と表示される (タイムゾーン オフセットの問題) #13464
  • [クローズ] 0.265.1 から 0.301.5 へのアップグレード後のすべてのビューのデータ取得エラー (MySQL 9.0.1) #13404
  • [クローズ] 🐛 バグ: [外部 DB - PostgreSQL] 同じテーブル上の多対多のリレーションシップにより、不要なリンクが追加され、部分的に間違っている、またはリンクされていないレコードが生成されます。 #13349
  • [クローズ] 🐛 バグ: Webhook 設定のアクション入力/変更フィールドが壊れています。 ? #13110
  • [クローズ] 🐛 バグ: テーブル間のリンクが機能しない #13092

何が変わったのか

  • Nc 修正: https://github.com/nocodb/nocodb/pull/13923 の @rameshmane7218 によってソース スキーマが読み取り専用になっている場合、リンク v1→v2 アップグレードをブロックする
  • feat(group-by): https://github.com/nocodb/nocodb/pull/13921 の @rameshmane7218 によるグループごとの有効化/無効化の切り替え
  • Nc 修正 (nc-gui): https://github.com/nocodb/nocodb/pull/13927 の @rameshmane7218 によるレコード モーダルのリンク/リンク解除における矢印キー ナビゲーション
  • Nc の偉業: https://github.com/nocodb/nocodb/pull/13919 の @rameshmane7218 によるドキュメント改訂履歴
  • https://github.com/nocodb/nocodb/pull/13932 の @pranavxc による欠落している CE ビルド ファイルの修正/同期
  • 修正(nocodb): https://github.com/nocodb/nocodb/pull/13933 の @pranavxc によって提供された JWT が無効な場合、/auth/user/me を 401 で拒否する
  • https://github.com/nocodb/nocodb/pull/13934 の @pranavxc によりオートナンバー列を表示値として許可
  • https://github.com/nocodb/nocodb/pull/13884 の @DarkPhoenix2704 による Nc nocodb 同期
  • 修正: subGroup 列にリテラル '?' がある場合の groupby バインディングの不一致@fendy3002 による文字 (https://github.com/nocodb/nocodb/pull/13936)
  • https://github.com/nocodb/nocodb/pull/13935 の @dstala による Nc fix/cal サポートの問題
  • feat(nc-gui): https://github.com/nocodb/nocodb/pull/13924 の @dstala による選択フィールド オプションの永続的なアルファベット表示切り替え
  • Nc fix(nc-gui): https://github.com/nocodb/nocodb/pull/13937 の @rameshmane7218 により、ツールバーの幅が変更されたときにビュー検索ドロップダウンを再配置します。
  • ドキュメント: https://github.com/nocodb/nocodb/pull/13940 の @mertmit によるスタブ インテント コメント
  • https://github.com/nocodb/nocodb/pull/13946 の @pranavxc による Nc feat/org 管理者の役割の割り当て
  • https://github.com/nocodb/nocodb/pull/13944 の @pranavxc によるレコード グリッドの修正/重複
  • chore(deps): https://github.com/nocodb/nocodb/pull/13929 の @pranavxc による pnpm オーバーライドを介して残りの dependabot アドバイザリーにパッチを適用します
  • 修正: https://github.com/nocodb/nocodb/pull/13918 の @aakashgautam-git による CSV エクスポートで列の順序を保持する
  • Nc fix/delbypk 列名は https://github.com/nocodb/nocodb/pull/13941 の @pranavxc によって定義されていません
  • Nc 修正 (nocodb): https://github.com/nocodb/nocodb/pull/13956 の @rameshmane7218 によるフォーム/レコード電子メールでの正しいリンクとユーザー フィールドのレンダリング
  • Nc 修正 (nc-gui): V2 LTAR の「+」ボタンは、https://github.com/nocodb/nocodb/pull/13954 の @rameshmane7218 によって新しいレコードを親に自動リンクするようになりました。
  • Nc feat/v3 タイムライン ガント 9067 by @fendy3002 (https://github.com/nocodb/nocodb/pull/13960)
  • Nc feat/v3 api セパレータ列挙型 (@fendy3002 による https://github.com/nocodb/nocodb/pull/13959)
  • https://github.com/nocodb/nocodb/pull/13963 の @pranavxc によってオンプレミスで隠された Nc fix/sqlite データ ソース フル Changelog: https://github.com/nocodb/nocodb/compare/2026.05.2...2026.05.3
