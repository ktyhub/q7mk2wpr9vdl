nocodb 2026.09.1

<img width="1865" height="1147" alt="image" src="https://github.com/user-attachments/assets/c97fae32-5349-432f-beaf-1e8559e60a2f" /> ## 可用性 |特集 |コミュニティ版 |クラウド無料プラン |クラウド/オンプレミスの有料プラン | | --- | :---: | :---: | :---: | |アカウント全体の MCP 接続 | – | ✅ | ✅ | |テーブルツール | ✅ | ✅ | ✅ | |タイムラインビューで要約 | – | – | ✅ | |最終更新日の特定のフィールドを追跡 | ✅ | ✅ | ✅ | | YouTrack 同期 | – | – | ✅ | Timeline View には NocoDB Cloud の Business プラン以上が必要で、App Sync には Plus プラン以上が必要です。 ## アカウント全体の MCP 接続 1 つの MCP 接続は、あなたが許可したツールを使用して、あなたが選択したすべての拠点に到達しますが、あなた自身の役割以上のものは決してありません。サーバーには現在、メンバーとチームの管理、添付ファイルのアップロード、更新/挿入、監査ログ、ゴミ箱の復元、公開など、2026.09.0 より 50 多い 199 のツールがあります。 <img width="2264" height="1566" alt="image" src="https://github.com/user-attachments/assets/6cfb0af9-0919-4810-a616-9c5252761860" /> [MCPについて詳しくはこちら→](https://nocodb.com/docs/apis-and-mcp/mcp) ## テーブルツール ビュー ツールバーの 1 つの [ツール] ボタンにより、フィールド、リレーション、権限、Webhook、およびその他すべてのテーブル ツールが 1 つのパネルで開きます。 <img width="1922" height="500" alt="image" src="https://github.com/user-attachments/assets/570cdf6d-06d5-4ea0-8abc-b3350e2ae68b" /> --- <img width="2498" height="1564" alt="image" src="https://github.com/user-attachments/assets/c75842b4-dd8e-4ec2-970a-1b7e4ecff9bf" /> [テーブルツールについて詳しくはこちら→](https://nocodb.com/docs/product/tables/table-operations/table-details) ## タイムラインビューで要約する タイムラインの日、週、月ごとにカウント、合計、平均、またはその他の概要を表示します。 <img width="1924" height="1210" alt="image" src="https://github.com/user-attachments/assets/d94328a2-a098-43a6-8669-43b1172fdfa8" /> [Summarizeについて詳しくはこちら→](https://nocodb.com/docs/product/tables/views/view-types/timeline#summarize) ## 最終更新日の特定のフィールドを追跡する 最終更新時刻フィールドと最終更新者フィールドは、選択したフィールドのみを監視できます。 <img width="2290" height="1188" alt="image" src="https://github.com/user-attachments/assets/e8c45986-7db4-4d18-92f5-73a1f44dda71" /> [特定フィールドの追跡について詳しくはこちら→](https://nocodb.com/docs/product/tables/fields/field-types/date-time-based/last-modified-time#track-specific-fields) ## YouTrack 同期 [YouTrack](https://www.jetbrains.com/youtrack/) の問題、コメント、ユーザーを他のチケット発行ソースと合わせて NocoDB に同期します。 <img width="2554" height="1596" alt="image" src="https://github.com/user-attachments/assets/688a9a8f-3128-4123-b7e2-25088f5dbdf4" /> [YouTrack 同期について詳しくはこちら→](https://nocodb.com/docs/product/sync/app-sync/ticketing#youtrack) ## 改善点 - **リンクを招待** - 1 つのリンクを共有して、選択した役割のベースまたはワークスペースに人々を招待します。 [詳細](https://nocodb.com/docs/product/collaboration/invite-links) - **モーダルとしての基本設定** - 設定は現在のビュー上で検索を使用して開きます。 [詳細](https://nocodb.com/docs/product/bases/actions-on-base) - **統合ページ** - 最初に接続し、次にカテゴリ フィルターを備えた 1 つのカタログ グリッドを作成します。 [詳細](https://nocodb.com/docs/product/integrations) - **Webhook トリガー フィールド** - 後の手順で個々の本文、ヘッダー、クエリ値を選択します。 [詳細](https://nocodb.com/docs/workflows/nodes/trigger-nodes/webhook) - **電子メール リンクの変数** - [電子メールを送信] リンクでは、ワークフロー データをアドレスとして使用できます。 [詳細](https://nocodb.com/docs/workflows/nodes/action-nodes/send-email) - **フォームのインターフェイス** - フィールドを *必須* としてマークし、フォームから開いているレコードを更新し、ボタンのフォームを適切に管理します。 [詳細](https://nocodb.com/docs/interfaces/layouts/form) - **インターフェイス フィルター** - コンポーネント間でコピー アンド ペーストできる、より大きな *フィルター* エディター。 - **大きな数値の省略形** - 数値、10 進数、および通貨フィールドでは、1,234,567 を 1.2M として表示できます。 [詳細](https://nocodb.com/docs/product/tables/fields/field-types/numerical/number#large-number-abbreviation) - **Excel エクスポート** - 通貨と 10 進数を実数としてエクスポートします。 [詳細](https://nocodb.com/docs/product/tables/table-operations/download) - **高速メニュー** - ドロップダウンは即座に開きます。 - **リスト ビューのドラッグ アンド ドロップ** - ドロップはすぐに適用されます。 - **一括更新** - *選択したレコードを更新* パネルを再設計しました。 ## 修正された内容 - **グループ化されたグリッド** - リアルタイム更新後も、行は適切なグループに残ります。 - **オプションの選択** - 貼り付けまたは入力して新しいオプションを追加すると、既存のオプションが保持されます。 - **インポート、スナップショット、および複製** - 大きなテーブルと同期されたテーブルは完全にコピーされ、ユーザー値はワークスペース間で引き継がれます。 - **インターフェイス** - リンク値、表示ルール、リンク ピッカー、添付ファイルのダウンロード、および概要のカバー画像が期待どおりに機能します。フィールドが削除された後も公開されたページは機能し続け、貼り付けられたリンク値は新しい行に残ります。 - **一括更新** - すべてのレコードを更新すると、Webhook とワークフロー トリガーが起動されます。 - **カンバン** - スタック内のカードの並べ替えが保存されます。 - **ワークフロー** - 反復ループ内のステップは、テスト時に現在のレコードを取得し、複数の変数を組み合わせたフィールドは正しく解決されます。 - **ビュー** - 日付範囲のないカレンダー ビューとタイムライン ビューは正しく複製され、共有リスト ビューが開きます。 - **テーブルの名前が変更されました** - テーブルの名前を変更した後も、数式表示値は機能し続けます。 - **監査ログ** - *データ* イベントでフィルタリングすると、結果が返されます。 - **ドキュメント** - 空の表セルを含むマークダウンは正しく貼り付けられます。 - **API** - v3 リンク フィールドの `null` はリンクを変更しないままにし、複数の日付を含む v2 `in` フィルターはすべての一致を返し、ベース スコープのトークンはベースをリストできます。 - **MCP** - ベースから誰かを削除すると、そのベースの接続のみが取り消され、書き込みツールは読み取りツールが返すものを受け入れ、テンプレートから作成されたレコードはリンクを保持します。 - **招待** - セルフホストおよび Community Edition 展開での招待メールはユーザーを正しくサインアップし、Community Edition のワークスペース招待はメールを送信し、基本招待の再送信は機能します。 - **サインイン** - 簡単なネットワーク エラーではサインアウトされなくなり、セルフホスト SSO ボタンが再び表示されます。 - **SQL Server** - 単一引数 `CONCAT` は機能します。 - **Airtable インポート** - 1 つの失敗したアイテムによってインポートが停止されることはなくなり、一方向リンクとネストされたフィルターは正しくインポートされます。 ## セルフホスティングのメモ - **読み込みの高速化** - 静的ファイルはキャッシュされて圧縮されるため、最初の読み込みは約 3.6 分の 1 になります。 - **ライセンス サーバーの健全性** - ライセンス サーバーにアクセスできない場合、スーパー管理者には *今すぐ再試行* という警告が表示されます。 [詳細](https://nocodb.com/docs/self-hosting/license-activation) - **v3 API フィールドの変更** - 通貨オプションでは `currency_code` および `currency_locale` が使用され、フォーム バリデータ `minValue`、`maxValue`、および `custom` は拒否されます。 - **CSV 通貨エクスポート** - 通貨値に千単位の区切り文字が含まれなくなりました。 - **セキュリティの強化** - 監査ログへのアクセスが厳格になり、ファイル名がサニタイズされ、依存関係にパッチが適用されます。 --- 2026.09.0 に導入された機能の詳細については、[2026.09.0 changelog](https://nocodb.com/docs/changelog/2026.09.0) を参照してください。 ----------- - [**クローズ**] 🐛 バグ: Web ページの読み込みが信じられないほど遅い。 [#14623](https://github.com/nocodb/nocodb/issues/14623) - [**クローズ**] 🐛 バグ: CSV、JSON、XLSX のダウンロードは、docker 内に保存されていないローカル ディスクにダウンロードする必要があります [#14617](https://github.com/nocodb/nocodb/issues/14617) - [**クローズ**] i18n: 補間トークンがいくつかのロケール文字列 (fr/it/pt/es) で変換または削除されました [#14573](https://github.com/nocodb/nocodb/issues/14573) - [**クローズ**] 🐛 バグ: 通貨フィールドが U+202F の桁区切り記号を含むテキストとして Excel にエクスポートされる [#14563](https://github.com/nocodb/nocodb/issues/14563) - [**終了**] 🐛 バグ: [ドキュメント] プライベート ベースはビジネス プランまたはスケール プランで利用できますか? Timeline View requires the Business plan and above on NocoDB Cloud, and App Sync requires the Plus plan and above.

Account-Wide MCP Connections

One MCP connection now reaches every base you pick, with the tools you allow and never more than your own role. The server now has 199 tools, 50 more than 2026.09.0, including member and team management, attachment upload, upsert, audit logs, trash restore, and publishing.

Improvements

  • Invite links - Share one link to bring people into a base or workspace at the role you choose. Learn more
  • Base settings as a modal - Settings open over your current view, with search. Learn more
  • Integrations page - Your connections first, then one catalog grid with category filters. Learn more
  • Webhook trigger fields - Pick individual body, header, and query values in later steps. Learn more
  • Variables in email links - Send Email links can use workflow data as the address. Learn more
  • Interface forms - Mark fields Required, update the open record from a form, and manage a button's forms in place. Learn more
  • Interface filters - Larger Filter by editor, with copy and paste between components.
  • Large number abbreviation - Number, Decimal, and Currency fields can display 1,234,567 as 1.2M. Learn more
  • Excel exports - Currency and Decimal export as real numbers. Learn more
  • Faster menus - Dropdowns open instantly.
  • List View drag and drop - Drops apply immediately.
  • Bulk update - Redesigned Update selected records panel.

What's Fixed

  • Grouped grids - Rows stay in the right group after realtime updates.
  • Select options - Adding a new option by paste or typing keeps existing options.
  • Imports, snapshots, and duplication - Large tables and synced tables copy completely, and User values carry across workspaces.
  • Interfaces - Link values, visibility rules, link pickers, attachment downloads, and overview cover images work as expected. Published pages keep working after a field is deleted, and pasted link values stay on new rows.
  • Bulk Update - Updating all records fires webhooks and workflow triggers.
  • Kanban - Reordering cards within a stack is saved.
  • Workflows - Steps inside an Iterate loop get the current record when tested, and fields that combine several variables resolve correctly.
  • Views - Calendar and Timeline views without a date range duplicate correctly, and shared List views open.
  • Renamed tables - Formula display values keep working after a table rename.
  • Audit log - Filtering by Data events returns results.
  • Documents - Markdown with empty table cells pastes correctly.
  • API - null for a v3 link field leaves links unchanged, v2 in filters with several dates return every match, and base-scoped tokens can list their bases.
  • MCP - Removing someone from a base revokes only that base's connections, write tools accept what their read tools return, and records created from a template keep their links.
  • Invites - Invite emails on self-hosted and Community Edition deployments sign people up correctly, workspace invites in the Community Edition send an email, and resending a base invite works.
  • Sign-in - Brief network errors no longer sign you out, and self-hosted SSO buttons show again.
  • SQL Server - Single-argument CONCAT works.
  • Airtable import - One failing item no longer stops the import, and one-way links and nested filters import correctly.

Self-Hosting Notes

  • Faster loading - Static files are cached and compressed, so first loads are about 3.6 times smaller.
  • License server health - Super admins see a warning with Retry now when the license server is unreachable. Learn more
  • v3 API field changes - Currency options use currency_code and currency_locale, and form validators minValue, maxValue, and custom are rejected.
  • CSV currency exports - Currency values no longer include a thousands separator.
  • Security hardening - Stricter audit log access, sanitized filenames, and patched dependencies.

For more details on the features introduced in 2026.09.0, see the 2026.09.0 changelog.
