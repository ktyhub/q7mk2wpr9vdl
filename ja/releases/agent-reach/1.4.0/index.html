#エージェントリーチ v1.4.0

コアの変更: 6 つの主要なアップストリーム移行

このバージョンには、複数のチャネルからの上流ツールの大規模な移行が含まれており、非推奨のツール、不安定なソリューション、および高い導入しきい値の問題を解決します。

上流への移行

|チャンネル |古い計画 |新しいプラン |効果 | |------|--------|----------|------| | ツイッター/X |鳥 CLI (レポ 404) | twitter-cli (2,137 ⭐) |完全に使用できないチャンネルを修正する | | レディット | Exa クロール (頻繁にタイムアウト) | rdt-cli (304 ⭐) |検索 + 全文 + コメントへのフルアクセス、ログイン不要 | | 小紅書 | Docker MCP (導入しきい値が高い) | xhs-cli (1,477 ⭐) | pipx install は 1 行で実行でき、階層 2→1 | | WeChat パブリック アカウント | miku_ai (20ヶ月休止中) |エクサ検索＋閲覧 |ゼロ構成、階層 2→0 | | スノーボールクッキー | browser_cookie3 (15 か月間サービス停止中) |ルーキーピー (Rust カーネル) |より安定し、フォールバックを保持 | | ビリビリ |純粋な yt-dlp | yt-dlp + bili-cli (590 ⭐) |人気/ランキング/検索を追加 |

チャンネル調整

  • ➕ サイト B が bili-cli 拡張バックエンドを追加
  • ➖ Discord を削除します (メタデータのみ、実用的ではありません)
  • ➖ 見出しを削除します (HTML 解析は脆弱です)

コミュニティ PR マージ

  • #225 修正 (youtube): クロスプラットフォーム yt-dlp 構成パス (@biyusku)
  • #200 ドキュメント: 日本語 README (@eltociear)
  • #211 ドキュメント: Douyin/Xiaohongshu オプションの MCP ドキュメント (@JNHFlow21)

エンドツーエンドの検証

16 チャンネルすべてが実際のネットワークでテストされています。

  • ✅ Reddit: rdt search 実際の投稿とすべてのコメントに戻る
  • ✅ Twitter: twitter search は実際のツイート + インタラクション データを返します
  • ✅ ステーション B: bili hot が人気の動画と再生回数に戻ります
  • ✅ WeChat: Exa 検索で公式アカウントの記事と全文の読み取りが返されます
  • ✅ 小紅書: xhs CLI は正常にインストールされ、ログイン後に使用可能になります。
  • ✅ 77 のテストに合格

アップグレード方法

pip install --upgrade agent-reach
agent-reach doctor

注意: Twitter ユーザーはツールを再インストールする必要があります。

pipx install twitter-cli
# bird CLI 已弃用，可卸载：npm uninstall -g @steipete/bird

Agent-Reach v1.4.0

Highlights

  • Twitter/X channel restored — bird CLI’s 404 status is resolved by migrating to twitter-cli (2,137 ⭐), restoring a previously broken upstream with a maintained alternative. Developers no longer need to maintain a dead dependency or face surprise failures.
  • Reddit search+comments now login‑free — rdt-cli (304 ⭐) replaces timeout‑prone Exa crawling, delivering full posts and comment threads without requiring a Reddit account. Cuts integration friction for any reddit‑focused workflow.
  • 小红书 drops from tier 2 to 1 with pipx — xhs-cli (1,477 ⭐) replaces the Docker‑based MCP setup, installable in a single pipx install command. Lowers the deployment barrier significantly for China‑focused content pipelines.
  • 微信公众号 tier 2→0: zero‑config Exa replacement — The abandoned miku_ai (20‑month abandonment) is replaced by Exa search+read, enabling full‑article access with no custom scraper maintenance. A meaningful operational reduction for China‑content projects.
  • 雪球 Cookie stability upgrade: browser_cookie3 → rookiepy — Rust‑based rookiepy replaces the abandoned browser_cookie3 (15‑month abandonment), with a fallback path. Increases reliability of cookie‑dependent auth flows.
  • No breaking changes — The migration is purely additive, replacing deprecated tools with maintained alternatives without removing existing functionality or altering existing APIs.

核心变更：6 大上游迁移

本版本对多个渠道的上游工具进行了大规模迁移，解决了已弃用工具、不稳定方案和部署门槛高的问题。

上游迁移

| 渠道 | 旧方案 | 新方案 | 效果 | |------|--------|--------|------| | Twitter/X | bird CLI（repo 已 404） | twitter-cli (2,137 ⭐) | 修复完全不可用的渠道 | | Reddit | Exa crawling（经常超时） | rdt-cli (304 ⭐) | 搜索+全文+评论全通，无需登录 | | 小红书 | Docker MCP（部署门槛高） | xhs-cli (1,477 ⭐) | pipx install 一行搞定，tier 2→1 | | 微信公众号 | miku_ai（停更 20 个月） | Exa 搜索+阅读 | 零配置，tier 2→0 | | 雪球 Cookie | browser_cookie3（停更 15 月） | rookiepy (Rust 内核) | 更稳定，保留 fallback | | B站 | 纯 yt-dlp | yt-dlp + bili-cli (590 ⭐) | 增加热门/排行/搜索 |

渠道调整

  • ➕ B站增加 bili-cli 增强后端
  • ➖ 移除 Discord（仅元数据，不够实用）
  • ➖ 移除头条（HTML 解析脆弱）

社区 PR 合并

  • #225 fix(youtube): 跨平台 yt-dlp 配置路径 (@biyusku)
  • #200 docs: 日文 README (@eltociear)
  • #211 docs: 抖音/小红书可选 MCP 文档 (@JNHFlow21)

端到端验证

所有 16 个渠道经过真实网络测试：

  • ✅ Reddit: rdt search 返回真实帖子+全部评论
  • ✅ Twitter: twitter search 返回真实推文+互动数据
  • ✅ B站: bili hot 返回热门视频+播放量
  • ✅ 微信: Exa 搜索返回公众号文章+全文阅读
  • ✅ 小红书: xhs CLI 安装正常，登录后可用
  • ✅ 77 tests passing

pip install --upgrade agent-reach
agent-reach doctor

注意：Twitter 用户需要重新安装工具：

pipx install twitter-cli
