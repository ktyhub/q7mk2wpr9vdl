Agent-Reach v1.4.2

パッチ 公開日2026年6月10日 出典Panniantong/Agent-Reach English original

#エージェントリーチ v1.4.2

##チャンネル調整

**Douyin、Weibo、WeChat の 3 つのチャネルの公開アカウントを削除します。 ** 理由は簡単です - 彼らはもはや評判に応えていません:

  • Douyin: 上流の douyin-mcp-server はメンテナンス (アーカイブ) を停止しているため、ローカル サービスの 4 段階の手動構成が必要です。ほとんど誰もそれに対処できません。
  • Weibo: 長い間メンテナンスされておらず、実際には利用できなくなった個人のフォークに依存しています。
  • WeChat パブリック アカウント: 全文読み取りはクロール防止 (#339) によってますますブロックされていますが、依然として「ゼロ構成が利用可能」を推進しています。

破られた約束を誇示するのではなく、正直に破棄しましょう。信頼できる上流ソリューションがあれば、彼らは戻ってくるでしょう (v1.4.0 による Discord/Toutiao の削除の背後にあるのと同じロジック)。現在の口径: 13 プラットフォーム、6 つの真のゼロ構成。

新機能

  • agent-reach transcribe <链接或文件> — ささやき音声を CLI に直接転写します (Groq の無料キーで十分です。失敗すると OpenAI が自動的にダウングレードされます)。字幕のないビデオの隠蔽ソリューション (#277)
  • agent-reach doctor --json — 機械可読なヘルスチェック出力。 ✅/[!]/[X] の意味を理解しやすくするためにテキスト バージョンに凡例が追加されました (#348)
  • スキルの自動トリガーの最適化 — スキルの説明 (中国語と英語のプラットフォームのエイリアス + アクション トリガーの単語) を書き直しました。エージェントはエージェント リーチをより確実に自動的に使用できるようになりました (#324、ありがとう @alfred1994)

修正

  • Reddit インストール コマンドの修正 — 医師は以前、PyPI に存在しない rdt-cli 0.4.2 をインストールする方法を教えてくれました。これで、GitHub ソース (釘付けされた 0.4.2 コミット) からインストールされ、ドキュメントも同時に更新されます (#326、@Bortlesboat に感謝、#294 を閉じます)
  • リトル ユニバースの文字起こし品質 — ウィスパー プロンプトでは中国語の句読点の出力が必要です (bash に飲み込まれる引用符を修正)。プロンプトでも 429 再試行します。新しく追加されたオプションの --polish は、無料の Llama 3.3 70B を使用してセグメンテーションを磨きます (#291、ありがとう @hymansun)
  • Windows 中国語の文字化けコード — 子プロセスと MCP サーバーは、weibo 時代に導入された UTF-8 環境を強制し、mcporter クラス チャネルに共通です (#345、ありがとう @chidaobuchidao)
  • 誰も消費しない uv.lock をクリーンアップする

Agent-Reach v1.4.2

Highlights

  • Three channels removed (breaking) — Douyin, Weibo, and WeChat Official Account are gone, so any config or automation that names those channels will fail after upgrade. The reasons are operational, not cosmetic: Douyin's upstream douyin-mcp-server is archived and required a 4-step local-service setup almost nobody completed, Weibo rode an abandoned personal fork, and WeChat full-text reads are increasingly blocked by anti-scraping (#339) despite being marketed as "zero-config." The new claim is honest — 13 platforms, but only 6 genuinely zero-config — so audit your channel list before adopting. This is the same pruning that dropped Discord/Toutiao in v1.4.0.
  • Whisper transcription lands in the CLI — agent-reach transcribe <link-or-file> (#277) converts audio/video to text directly, using a free Groq key with automatic fallback to OpenAI. This closes a real capability gap: it's the intended safety net for videos with no subtitles, not just a polish pass.
  • Machine-readable diagnostics — agent-reach doctor --json (#348) makes health checks script-friendly, and the text output now ships a legend decoding ✅/[!]/[X]. If you've wired doctor into monitoring or CI, this is the integration hook that was missing; the legend also removes guesswork from manual triage.
  • Smarter skill auto-triggering — SKILL descriptions were rewritten with Chinese/English platform aliases and action trigger words (#324, @alfred1994), so agents invoke Agent Reach reliably without being told to. Expect fewer "agent ignored the tool" cases — but re-test your prompt flows, since trigger matching is precisely what changed.
  • Reddit install path corrected — doctor was telling users to install rdt-cli 0.4.2 from PyPI, a version that doesn't exist; it now installs from a pinned GitHub-source commit with docs synced (#326, @Bortlesboat, closes #294). Fresh Reddit setups finally work end-to-end — assume any older setup notes you have are wrong.
  • Transcription quality and Windows encoding — Xiaoyuzhou Whisper prompts now request Chinese punctuation (the old quotes were being eaten by bash), 429 retries carry the prompt, and an optional --polish step uses free Llama 3.3 70B to refine segmentation (#291, @hymansun). Separately, subprocesses and MCP servers force UTF-8 on Windows (#345, @chidaobuchidao), fixing mojibake for mcporter-style channels — a legacy of the Weibo integration that now benefits every channel of that type.

渠道调整

移除抖音、微博、微信公众号三个渠道。 原因很直接——它们已经名不副实：

  • 抖音：上游 douyin-mcp-server 已停止维护（archived），且需要手动起本地服务的 4 步配置，几乎没人能配通
  • 微博：依赖一个久未维护的个人 fork，实际已不可用
  • 微信公众号：全文阅读被反爬拦截越来越严重（#339），却还在宣传"零配置可用"

与其展示坏掉的承诺，不如诚实下架。等有可靠的上游方案时它们会回来（v1.4.0 移除 Discord/头条是同样的逻辑）。现在的口径：13 个平台，6 个真零配置。

新功能

  • agent-reach transcribe <链接或文件> — Whisper 音频转写直接进 CLI（Groq 免费 key 即可，失败自动降级 OpenAI），无字幕视频的兜底方案（#277）
  • agent-reach doctor --json — 机器可读的健康检查输出；文本版加了图例，看得懂 ✅/[!]/[X] 是什么意思了（#348）
  • Skill 自动触发优化 — 重写了 SKILL 描述（平台中英文别名 + 动作触发词），Agent 现在能更可靠地自动用上 Agent Reach（#324，感谢 @alfred1994）

修复

  • Reddit 安装命令修复 — doctor 之前教你装 PyPI 上不存在的 rdt-cli 0.4.2；现在从 GitHub 源安装（钉死 0.4.2 commit），文档同步更新（#326，感谢 @Bortlesboat，关闭 #294）
  • 小宇宙转写质量 — Whisper prompt 要求输出中文标点（修复了被 bash 吞掉的引号），429 重试也带 prompt；新增可选 --polish 用免费 Llama 3.3 70B 润色分段（#291，感谢 @hymansun）
  • Windows 中文乱码 — 子进程和 MCP server 强制 UTF-8 环境，weibo 时代引入、对 mcporter 类渠道通用（#345，感谢 @chidaobuchidao）
  • 清理无人消费的 uv.lock

升级方式

把这句话发给你的 Agent：

帮我更新 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md
