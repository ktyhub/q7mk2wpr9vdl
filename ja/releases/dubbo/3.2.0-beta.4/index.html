dubbo 3.2.0-beta.4

プレリリース 公開日2023年1月20日 出典apache/dubbo English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.2.0-beta.4

何が変わったのか

機能

  • https://github.com/apache/dubbo/pull/11117 に @icodening による bytebuddy サポートを追加
  • https://github.com/apache/dubbo/pull/11244 に @jojocodeX によるタイムアウト制限メトリクスを追加
  • Jvm メーターは、https://github.com/apache/dubbo/pull/11255 の @songxiaosheng によるアプリケーション名ラベルを追加します
  • https://github.com/apache/dubbo/pull/11295 の @fomeiherz により dubbo プロバイダー メトリクスに dubbo プレフィックス(dubbo.provider) を追加
  • https://github.com/apache/dubbo/pull/11315 の @jojocodeX による失敗したリクエストの合計のメトリクスを追加しました
  • https://github.com/apache/dubbo/pull/11309 に @MentosL による xdsroute 観察ロジックを追加
  • https://github.com/apache/dubbo/pull/11319 の @AlbumenJ によって xds ルーターが実行されるようにします ※https://github.com/apache/dubbo/pull/11327の@fomeiherzさんの命名規則に従って名前を変更します。

バグ修正

  • https://github.com/apache/dubbo/pull/11144 の @ShenFeng312 による REST プロトコルでトークンが機能しない問題を修正
  • https://github.com/apache/dubbo/pull/11239 の @AlbumenJ による nacos サービス ディスカバリの更新を強化
  • https://github.com/apache/dubbo/pull/11313 の @AlbumenJ によって更新されるように nacos をリファクタリング
  • https://github.com/apache/dubbo/pull/10885 の @aamingaa による xds サブスクライブの機能/変更
  • https://github.com/apache/dubbo/pull/11263 の @CrazyHZM による構成の反映に関するネイティブを修正
  • https://github.com/apache/dubbo/pull/11267 で @AlbumenJ によってシリアル化できない設定を修正
  • IPv6 アノテーションを更新し、https://github.com/apache/dubbo/pull/11266 の @HHoflittlefish777 によって無効な IPv6 をフィルタリングします
  • https://github.com/apache/dubbo/pull/11248 の @AlbumenJ によるルーター チェーンの切り替え時に呼び出し元が変更される問題を修正
  • https://github.com/apache/dubbo/pull/11300 の @aamingaa による lds 観察を修正
  • https://github.com/apache/dubbo/pull/11325 の @CrazyHZM によるネイティブ ケースでの fastjson2 のサポート
  • https://github.com/apache/dubbo/pull/11324 で @schneiderlin によって他の人がロックを保持している場合、ロックファイルを削除しないでください
  • https://github.com/apache/dubbo/pull/11349 の @jojocodeX によるメトリクス キーの重複を修正
  • https://github.com/apache/dubbo/pull/11351 の @aamingaa によるデプロイ リスナー例外を修正

パフォーマンスの最適化

  • ConcurrentHashMap#computeIfAbsent を最適化すると、jdk1.8 でパフォーマンスの問題が発生します (https://github.com/apache/dubbo/pull/11326 の @mxsm による)

コードの拡張

関連する PR: #11063、#10971、#11199、#11258、#11288、#11291、#11328、#11260

依存関係のアップグレード

  • protobuf-java を更新: 3.18.3 -> 3.19.6 #11282 #11283 #11284 #11281 #11356
  • cglib-nodep を更新: 2.2 -> 2.2.2 #11333
  • バイト仲間を更新: 1.12.19 -> 1.12.22 #11335
  • bouncycastle-bcprov_version を更新: 1.69 -> 1.70 #11336
  • javax.ws.rs-api を更新: 2.0 -> 2.1.1 #11337
  • curator_version を更新: 4.2.0 -> 4.3.0 #11345

  • slf4j-api を更新: 1.7.25 -> 1.7.36 #11348

  • maven-enforcer-plugin を更新: 3.0.0-M3 -> 3.1.0 #11343

What's Changed

Feature

  • Add bytebuddy support by @icodening in https://github.com/apache/dubbo/pull/11117
  • Add timeout limit metric by @jojocodeX in https://github.com/apache/dubbo/pull/11244
  • Jvm meter add application name label by @songxiaosheng in https://github.com/apache/dubbo/pull/11255
  • Add dubbo prefix(dubbo.provider) to dubbo provider metrics by @fomeiherz in https://github.com/apache/dubbo/pull/11295
  • Added metrics for failed request total by @jojocodeX in https://github.com/apache/dubbo/pull/11315
  • Add xdsroute observe logic by @MentosL in https://github.com/apache/dubbo/pull/11309
  • Make xds router run by @AlbumenJ in https://github.com/apache/dubbo/pull/11319
  • Change the name according to the naming convention by @fomeiherz in https://github.com/apache/dubbo/pull/11327

Bugfix

  • Fix token not work in rest protocol by @ShenFeng312 in https://github.com/apache/dubbo/pull/11144
  • Enhance nacos service discovery update by @AlbumenJ in https://github.com/apache/dubbo/pull/11239
  • Refactor nacos to update by @AlbumenJ in https://github.com/apache/dubbo/pull/11313
  • Feature/modify xds subscribe by @aamingaa in https://github.com/apache/dubbo/pull/10885
  • Fix native about reflect config by @CrazyHZM in https://github.com/apache/dubbo/pull/11263
  • Fix config unable to serialize by @AlbumenJ in https://github.com/apache/dubbo/pull/11267
  • Update IPv6 annotation and filter invalid IPv6 by @HHoflittlefish777 in https://github.com/apache/dubbo/pull/11266
  • Fix invokers has changed when router chain switch by @AlbumenJ in https://github.com/apache/dubbo/pull/11248
  • Fix lds observe by @aamingaa in https://github.com/apache/dubbo/pull/11300
  • Support fastjson2 in native case by @CrazyHZM in https://github.com/apache/dubbo/pull/11325
  • Don't delete lock file when lock is held by other by @schneiderlin in https://github.com/apache/dubbo/pull/11324
  • Fix metrics key duplication by @jojocodeX in https://github.com/apache/dubbo/pull/11349
  • Fix deploy listener exception by @aamingaa in https://github.com/apache/dubbo/pull/11351

Performance Optimization

  • Optimize ConcurrentHashMap#computeIfAbsent have performance problem in jdk1.8 by @mxsm in https://github.com/apache/dubbo/pull/11326

Code Enhancement

Releates PRs: #11063, #10971, #11199, #11258, #11288, #11291, #11328, #11260
