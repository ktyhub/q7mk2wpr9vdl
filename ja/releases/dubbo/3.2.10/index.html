dubbo 3.2.10

パッチ 公開日2023年12月15日 出典apache/dubbo English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.2.10

何が変わったのか

機能

  • Kubernetes および xDS 実装を apache/dubbo-spi-extensions リポジトリに移動 (https://github.com/apache/dubbo/pull/13469 の @AlbumenJ によって)

バグ修正

  • https://github.com/apache/dubbo/pull/13385 の @EarthChen によるトライ スタブ単項メソッドのオーバーロードを修正
  • https://github.com/apache/dubbo/pull/13408 の @owen200008 によるリスナー ハッシュ コード エラーを修正
  • https://github.com/apache/dubbo/pull/13439 の @namelesssssssssssss によって 1 つの nacos 名前空間 (3.2.x) にのみメタデータが登録される問題を修正
  • https://github.com/apache/dubbo/pull/13442 の @AlbumenJ によるトリプルのジェネリック呼び出しの失敗を修正
  • https://github.com/apache/dubbo/pull/13357 の @suncairong163 によるレスト プロキシの二重サービス メソッドを修正
  • https://github.com/apache/dubbo/pull/13449 の @songxiaosheng によるメトリクス サービス レベル設定のバグを修正
  • TriRpcStatus が https://github.com/apache/dubbo/pull/13453 の @AlbumenJ による Serializable を実装していない問題を修正
  • https://github.com/apache/dubbo/pull/13441 の @AlbumenJ による fastjson2 または hessian2 シリアル化依存関係の除外をサポート
  • https://github.com/apache/dubbo/pull/13446 の @kazetyan による streamobserver の実際のタイプを修正
  • https://github.com/apache/dubbo/pull/13468 の @manzhizhen による SslServerTlsHandler#decode 早期リターンを修正
  • https://github.com/apache/dubbo/pull/13505 の @AlbumenJ による Hessian2FactoryManager の潜在的な NPE を修正

コードの拡張

関連する PR: #13326、#13382、#13440、#13444、#13445、#13466

What's Changed

Feature

  • Move Kubernetes and xDS implementations to apache/dubbo-spi-extensions repo by @AlbumenJ in https://github.com/apache/dubbo/pull/13469

Bugfix

  • Fix tri stub unary method overload by @EarthChen in https://github.com/apache/dubbo/pull/13385
  • Fix listener hash code error by @owen200008 in https://github.com/apache/dubbo/pull/13408
  • Fix issue of metadata only registred to one nacos namespace (3.2.x) by @namelessssssssssss in https://github.com/apache/dubbo/pull/13439
  • Fix generic invoke failed for triple by @AlbumenJ in https://github.com/apache/dubbo/pull/13442
  • Fix rest proxy double service method by @suncairong163 in https://github.com/apache/dubbo/pull/13357
  • Fix metrics servce level config bug by @songxiaosheng in https://github.com/apache/dubbo/pull/13449
  • Fix TriRpcStatus not implements Serializable by @AlbumenJ in https://github.com/apache/dubbo/pull/13453
  • Support exclude fastjson2 or hessian2 serialization dependencies by @AlbumenJ in https://github.com/apache/dubbo/pull/13441
  • Fix streamobserver actual type by @kazetyan in https://github.com/apache/dubbo/pull/13446
  • Fix SslServerTlsHandler#decode early return by @manzhizhen in https://github.com/apache/dubbo/pull/13468
  • Fix potential NPE in Hessian2FactoryManager by @AlbumenJ in https://github.com/apache/dubbo/pull/13505
