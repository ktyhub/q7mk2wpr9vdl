dubbo 3.2.3

パッチ 公開日2023年6月13日 出典apache/dubbo English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.2.3

何が変わったのか

機能

  • https://github.com/apache/dubbo/pull/12386 の @AlbumenJ による設定クローズ タイムアウトをサポート
  • メトリクスは、https://github.com/apache/dubbo/pull/12364 の @jojocodeX によるスライディング タイム ウィンドウ統計を追加します
  • https://github.com/apache/dubbo/pull/12273 の @hujun-w-2 によって prometheus が存在しない場合のデフォルトのメトリクスをサポート
  • https://github.com/apache/dubbo/pull/12439 の @AlbumenJ による Spring プロキシの代わりに Dubbo プロキシを使用する
  • SIMPLE_TYPE としてデュレーションを追加し、https://github.com/apache/dubbo/pull/12469 の @conghuhu で変換します
  • https://github.com/apache/dubbo/pull/12389 で @finefuture によるスイッチを有効にするメトリクスを追加
  • https://github.com/apache/dubbo/pull/12477 の @AlbumenJ によるモジュール デプロイヤー状態イベントを公開
  • nacos と zookeeper 用の springboot-starter を @conghuhu により https://github.com/apache/dubbo/pull/12488 に追加
  • パスマッチャーと呼び出し元を https://github.com/apache/dubbo/pull/12482 の @suncairong163 によってユーザーにエクスポート
  • https://github.com/apache/dubbo/pull/12461 に @songxiaosheng による名前の処理メトリクス fun を追加

バグ修正

  • https://github.com/apache/dubbo/pull/12387 の @AlbumenJ による netty4 サーバー終了タイムアウトを修正
  • https://github.com/apache/dubbo/pull/12380 の @CrazyHZM による PojoUtils NPE 問題を修正
  • https://github.com/apache/dubbo/pull/12396 の @AlbumenJ による alibaba AbstractLoadBalance コンパクトを修正
  • https://github.com/apache/dubbo/pull/12404 の @AlbumenJ による PojoUtils で名前が一致しない場合の NPE を修正
  • https://github.com/apache/dubbo/pull/12416 に @AlbumenJ による alibaba RpcContext getInvocation コンパクトを追加
  • ブートスターターを追加し、https://github.com/apache/dubbo/pull/12408 の @songxiaosheng によるエンドポイントのバグを修正
  • https://github.com/apache/dubbo/pull/12425 の @wxbty によって invocation.getServiceKey が null になる可能性がある問題を修正
  • https://github.com/apache/dubbo/pull/12409 の @conghuhu による ConditionalOnDubboTracingEnable matchIfMissing の削除を修正
  • https://github.com/apache/dubbo/pull/12440 の @AlbumenJ による alibaba フィルター/結果コンパクトを修正
  • https://github.com/apache/dubbo/pull/12137 の @wxbty によるプロトコルとヒストグラムのデフォルトの有効化を追加
  • https://github.com/apache/dubbo/pull/12445 の @AlbumenJ による呼び出し元の回復を修正
  • https://github.com/apache/dubbo/pull/12427 の @icodening による Fox ビルド文字列エラー
  • シリアル化が失敗した場合、RpcException のコード値が https://github.com/apache/dubbo/pull/12357 の @wxbty によって誤って設定される問題を修正
  • https://github.com/apache/dubbo/pull/12449 の @AlbumenJ により、Apache URL を alibaba URL にプロキシする DelegateURL を導入
  • https://github.com/apache/dubbo/pull/12446 の @icodening によって実際の例外をキャッチできない問題を修正
  • https://github.com/apache/dubbo/pull/12451 の @icodening により、接続が閉じたときにすべてのアクティブなストリームをリセットします
  • https://github.com/apache/dubbo/pull/12450 の @AlbumenJ によって開始されたモジュールの後にサービスを登録します
  • https://github.com/apache/dubbo/pull/12472の@AlbumenJによる登録後の参照を確認してください
  • https://github.com/apache/dubbo/pull/12474 の @AlbumenJ による Spring Bean の競合を解決
  • https://github.com/apache/dubbo/pull/12479 の @AlbumenJ による injvm 呼び出し側チェックを修正
  • https://github.com/apache/dubbo/pull/12468 の @wegod による 2.6 ConsistentHashLoadBalance の hashCode の変更を修正
  • https://github.com/apache/dubbo/pull/12484 の @AlbumenJ による ThreadlessExecutor の長時間待機を修正
  • https://github.com/apache/dubbo/pull/12486 の @AlbumenJ による checkAndUpdateSubConfigs でレジストリをチェックします
  • https://github.com/apache/dubbo/pull/12494 に @AlbumenJ によるいくつかの nacos 接続ログを追加
  • https://github.com/apache/dubbo/pull/12504 の @AlbumenJ による client の正常なシャットダウンをサポート
  • リモート設定のログを追加します。 @chickenlj 著、https://github.com/apache/dubbo/pull/12294
  • https://github.com/apache/dubbo/pull/12361 の @wxbty によるプロトコル設定エラーの場合は高速です
  • https://github.com/apache/dubbo/pull/12491 の @chickenlj によるルーターの一致条件を修正
  • https://github.com/apache/dubbo/pull/12507 の @AlbumenJ による AbstractProxyProtocol の互換性を修正
  • https://github.com/apache/dubbo/pull/12511 の @AlbumenJ による ServiceConfig Ref が toString できない問題を修正
  • https://github.com/apache/dubbo/pull/12503 の @AlbumenJ によるチャネル終了イベントの原因でスレッドがハングする問題を修正

What's Changed

Feature

  • Support config close timeout by @AlbumenJ in https://github.com/apache/dubbo/pull/12386
  • Metrics add sliding time window statistics by @jojocodeX in https://github.com/apache/dubbo/pull/12364
  • Support metrics default if prometheus absent by @hujun-w-2 in https://github.com/apache/dubbo/pull/12273
  • Use Dubbo Proxy instead of Spring Proxy by @AlbumenJ in https://github.com/apache/dubbo/pull/12439
  • Add Duration as SIMPLE_TYPE and Convert by @conghuhu in https://github.com/apache/dubbo/pull/12469
  • Add metrics enable switch by @finefuture in https://github.com/apache/dubbo/pull/12389
  • Publish Module deployer state event by @AlbumenJ in https://github.com/apache/dubbo/pull/12477
  • Add springboot-starter for nacos and zookeeper by @conghuhu in https://github.com/apache/dubbo/pull/12488
  • Export path matcher&invoker to user by @suncairong163 in https://github.com/apache/dubbo/pull/12482
  • Add processing metric fun of name by @songxiaosheng in https://github.com/apache/dubbo/pull/12461

Bugfix

  • Fix netty4 server close timeout by @AlbumenJ in https://github.com/apache/dubbo/pull/12387
  • Fix PojoUtils NPE problem by @CrazyHZM in https://github.com/apache/dubbo/pull/12380
  • Fix alibaba AbstractLoadBalance compact by @AlbumenJ in https://github.com/apache/dubbo/pull/12396
  • Fix NPE if name not match in PojoUtils by @AlbumenJ in https://github.com/apache/dubbo/pull/12404
  • Add alibaba RpcContext getInvocation compact by @AlbumenJ in https://github.com/apache/dubbo/pull/12416
  • Add bootstarter and fix endpoints bug by @songxiaosheng in https://github.com/apache/dubbo/pull/12408
  • Fix invocation.getServiceKey maybe null by @wxbty in https://github.com/apache/dubbo/pull/12425

  • Add default enable for protocol and histogram by @wxbty in https://github.com/apache/dubbo/pull/12137
  • Fix invoker recovery by @AlbumenJ in https://github.com/apache/dubbo/pull/12445
  • Fox build string error by @icodening in https://github.com/apache/dubbo/pull/12427
  • Fix When serialization fails, the code value in RpcException is set incorrectly by @wxbty in https://github.com/apache/dubbo/pull/12357
  • Introduce DelegateURL to proxy apache URL to alibaba URL by @AlbumenJ in https://github.com/apache/dubbo/pull/12449

  • Resolve conflicts of spring bean by @AlbumenJ in https://github.com/apache/dubbo/pull/12474
  • Fix injvm invoker check by @AlbumenJ in https://github.com/apache/dubbo/pull/12479
  • Fix hashCode change in 2.6 ConsistentHashLoadBalance by @wegod in https://github.com/apache/dubbo/pull/12468
  • Fix long time await in ThreadlessExecutor by @AlbumenJ in https://github.com/apache/dubbo/pull/12484
  • Check registry in checkAndUpdateSubConfigs by @AlbumenJ in https://github.com/apache/dubbo/pull/12486
  • Add some nacos connection logs by @AlbumenJ in https://github.com/apache/dubbo/pull/12494

  • Fast fast when protocol configure error by @wxbty in https://github.com/apache/dubbo/pull/12361
  • Fix router match condition by @chickenlj in https://github.com/apache/dubbo/pull/12491
