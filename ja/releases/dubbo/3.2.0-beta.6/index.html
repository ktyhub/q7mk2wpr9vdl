dubbo 3.2.0-beta.6

#ダボダボ-3.2.0-beta.6

何が変わったのか

機能

  • feat: dubbo 提供: @aamingaa in https://github.com/apache/dubbo/pull/11390
  • 3.2 コンシューマー プロキシ呼び出しハンドラー (https://github.com/apache/dubbo/pull/11108 の @suncairong163 による)
  • https://github.com/apache/dubbo/pull/11574 の @mytang0 によるダボ バージョンの取得方法を強化
  • https://github.com/apache/dubbo/pull/11540 の @CrazyHZM によるネイティブの Dubbo Maven プラグイン
  • https://github.com/apache/dubbo/pull/11094 の @chickenlj によるオーバーライドおよびタグ ルールの「ラベル マッチ」サポートを追加
  • https://github.com/apache/dubbo/pull/11664 の @AlbumenJ による getConfig QoS コマンドを導入
  • https://github.com/apache/dubbo/pull/11517 の @mytang0 によるサービスレベル ペイロードの実装
  • https://github.com/apache/dubbo/pull/11578 の @AlbumenJ による動的証明書をサポートするのに正確
  • https://github.com/apache/dubbo/pull/11223 の @AlbumenJ によるサービス ディスカバリの更新間隔を強化

バグ修正

  • hasPreparedInternalModule が常に false になる問題を修正しました。 (#11535) by @KamToHung (https://github.com/apache/dubbo/pull/11536)
  • https://github.com/apache/dubbo/pull/11538 の @thisiswanghy による LFUCache#put() メソッドのバグを修正
  • 残りのバグ修正と最適化 (https://github.com/apache/dubbo/pull/11617 の @mytang0 による)
  • https://github.com/apache/dubbo/pull/11622 の @jojocodeX による dubbo-security Jackson エラー
  • https://github.com/apache/dubbo/pull/11506 の @AlbumenJ による qos コマンドのリモート チェックを修正
  • https://github.com/apache/dubbo/pull/11586 の @mytang0 によるタグ ルーターの問題修正
  • https://github.com/apache/dubbo/pull/11512 で @AlbumenJ によってシリアル化が変更された場合にハートビートが失敗する問題を修正
  • 修正: https://github.com/apache/dubbo/pull/11676 の @lan-dian による冗長例外を削除
  • https://github.com/apache/dubbo/pull/11699 の @liufeiyu1002 による参照 Bean 名の競合を修正
  • https://github.com/apache/dubbo/pull/11705 の @suncairong163 によってサンプルの依存関係の競合を解決

メトリクス

  • https://github.com/apache/dubbo/pull/11516 の @wxbty による t-digest ミスを修正
  • https://github.com/apache/dubbo/pull/11461 の @Webster-Yang によるスレッド プール メトリックを追加
  • https://github.com/apache/dubbo/pull/11529 の @jojocodeX によるメトリクス数の最適化
  • https://github.com/apache/dubbo/pull/11552の@jojocodeXによるobservationreceiverインスタンスエラー
  • メトリクス コードのオプション: 冗長、修飾子、マジック by @mytang0 (https://github.com/apache/dubbo/pull/11553)
  • https://github.com/apache/dubbo/pull/11522 の @wxbty によるメトリクス データの収集とエクスポートの公開部分を提供します
  • https://github.com/apache/dubbo/pull/11576 の @wxbty によるメトリック パッケージ構造の最適化
  • spring boot へのメーターの同期は https://github.com/apache/dubbo/pull/11630 の @songxiaosheng によって管理されます
  • 可観測性タスク: https://github.com/apache/dubbo/pull/11493 の @wxbty による登録センター
  • https://github.com/apache/dubbo/pull/11628 の @mytang0 によるメトリクス RT カウントの最適化
  • :recycle:refact メトリクス キーとメーター ユニット (https://github.com/apache/dubbo/pull/11661 の @songxiaosheng による)
  • https://github.com/apache/dubbo/pull/11596 の @jojocodeX によるエラー タイプのメトリクスを追加
  • 可観測性タスク: https://github.com/apache/dubbo/pull/11593 の @wxbty によるメタデータ センター
  • 可観測性タスク: https://github.com/apache/dubbo/pull/11692 の @mytang0 による GaugeMetricSample のリファクタリング
  • https://github.com/apache/dubbo/pull/11638 の @mytang0 によるメトリクス TimeWindow のリファクタリング
  • https://github.com/apache/dubbo/pull/11693 に @songxiaosheng によるコア スレッド プール メーターを追加
  • RT メトリクスのバグ修正 (https://github.com/apache/dubbo/pull/11694 の @mytang0 による)
  • https://github.com/apache/dubbo/pull/11659 の @wxbty によるメトリクス レジストリとメタデータのコードを最適化
  • 修正: https://github.com/apache/dubbo/pull/11724 の @conghuhu により可観測性にマイクロメーター bom を追加し、パッケージの構造を最適化しました。
  • :bug:Fix/コンシューマー プロバイダー メトリクス名のカバー (https://github.com/apache/dubbo/pull/11753 の @songxiaosheng による)
  • https://github.com/apache/dubbo/pull/11752 の @robin977 により、コア スレッド メトリクスが有効になっていた問題 (#11704) を修正しました
  • https://github.com/apache/dubbo/pull/11542 に @songxiaosheng による消費者指標を追加
  • https://github.com/apache/dubbo/pull/11579 の @ShenFeng312 による dubbo-spring-boot-observability-starter を追加
  • 修正: https://github.com/apache/dubbo/pull/11660 の @conghuhu による観測 spi 構成を修正
  • https://github.com/apache/dubbo/pull/11710 の @pmupkin による異常時間カウント
  • :bug: https://github.com/apache/dubbo/pull/11712 の @songxiaosheng によるプッシュ メタデータ コード メーター コレクターの場所を修正

パフォーマンスの最適化

  • https://github.com/apache/dubbo/pull/11698 の @icodening によって Http2StreamChannel 非同期を作成します
  • https://github.com/apache/dubbo/pull/11665 の @sourcelliu による NacosNamingServiceWrapper のパフォーマンスの向上

コードの拡張

関連する PR: #11503、#11523、#11532、#11582、#11544、#11527、#11530、#11533、#11621、#11641、#11629、#11642、#11668、#11671、#11674、 #11683、#11686、#11761
