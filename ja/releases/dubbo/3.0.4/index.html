dubbo 3.0.4

パッチ 公開日2021年10月19日 出典apache/dubbo English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.0.4

:star2:特徴

  • ロガー無効化オプションを追加（#8885）
  • バックグラウンドでのモジュール起動をサポート（#8869）
  • Service Discoveryのマルチサブスクライブをサポート（#8908）
  • dubbo 3.0.4（#8966）のネイティブをサポート
  • streamObserverキャンセルをサポート（#8946）
  • トリプル送信はメッセージ圧縮をサポート（#8817、#9018、#9021、#9032）
  • モデルフィールドのキャッシュプロパティをサポート（#9025）
  • Maven プラグインによるダボ ネイティブ プロジェクトの実行をサポート（#8970）
  • ExtensionLoader にのみ ExtensionClassLoaderPackages のサポートを追加（#9061）

🐞 バグ修正

  • appendAttributeキーを修正（#8847）
  • RpcContextの重複したオーバーライドを修正（#8842）
  • addParam()のStringIndexOutOfBoundsExceptionを修正（#8799）
  • デコード時に呼び出しnullチェックを追加(Channel,InputStream)（#8812）
  • IllegalStateException と doOverrideIfNecessary NPE の破棄を修正（#8768）
  • zookeeperノードデータ作成イベントチェックを追加（#8833）
  • 修正：複数のプロトコルを使用し、ポートを指定するとサービスが起動できない場合がありました。（#8769）
  • urlInvokerMapの同時アクセスの問題を修正（#8701）
  • 遅延注入された Bean の Deployer 状態を修正（#8867）
  • ZookeeperRegistry CountDownLatch を解放し、UT を追加する必要があります（#8870）
  • SerialVersionUID（#8852）を修正
  • Beanの同時作成エラーを修正（#8883）
  • サーブレットページ API（#8884）のリカバリ
  • CountDownLatchが解放されない問題を修正（#8878）
  • サブスクライブ時に設定チェックセクションが利用できない問題を修正（#8879）
  • ServiceDefinition公開時のClass.forNameを修正（#8894）
  • ローカルアドレスをフィルタリングするソックスプロキシ（#8876）
  • ServiceConfig で遅延エクスポートが機能しない問題を修正（#8912）
  • MergeableClusterInvoker NPE を修正（#8891）
  • Tomcatサーバーポートを閉じるためにdestroy()呼び出しを追加（#8920）
  • LazyConnectExchangeClientのクローズメソッドでclientをnullに設定する（#8881）
  • 修正: Telnet でのレジストリの AbstractRegistry へのキャスト エラー（#8619）
  • volatile修飾子を追加せずにAbstractServiceDiscovery#serviceInstance属性を修正（#8915）
  • アドレスが空の場合の状態ルータースロー例外を修正（#8951）
  • Injvm InvokeでServiceModelをリセット（#8952）
  • インスタンス モードのメッシュ ルートが URL パラメーターを取得できない問題を修正しました（#8947）
  • 例外情報を修正（#8974）
  • kryoシリアル化リカバリ用jdkかどうかの判定方法（#8968）
  • ApplicationConfig の重複エラー（#8989）を修正
  • testRecover()のremoveFailedRegisteredTaskとremoveFailedSubscribedTaskをオーバーライド（#8981）
  • ConfigManagerTest のスペルミスを修正（#8990）
  • SPI の Adaptive クラス作成時の並行問題を修正（#8998）
  • リスナーの初期初期化を修正（#9006）
  • クローズ操作時のClosedChannelExceptionをチェック（#9010）
  • NotifyServiceコールバックメソッドの引数の型を修正（#9008）
  • applicationDeployer checkStarted()でモジュール起動を設定（#9013）
  • マルチインスタンスの移行レポートを修正（#9020）
  • 取得設定の NPE を修正（#9024）
  • localMetadataService.blockUntilUpdated statをチェックするロジックを追加（#9002）
  • blockUntilUpdatedでapplicationModelの破棄状態を確認（#9001）
  • RegistryFactory 拡張ポイントのデフォルト実装を削除（#9027）
  • インスタンスの更新に失敗した問題を修正（#9040）
  • Tomcat ポートが既に使用されている場合にプロセスを停止できない問題を修正（#8552）

:rocket:最適化

  • Local InvokeにScopeModelを追加（#8849）
  • 最適化フィールドのスコープを修正（#8751）
  • dubboメタデータモジュールの一部コードを最適化（#8783）
  • 最初に警告を表示しない replaceWithLazyClient() （#8814）
  • 統一エラーメッセージ（#8794）

  • 単体テストの効率向上（#8877）

  • 複数のコードを最適化（#8900）

  • 呼び出し時のLinkedHashMapをHashMapに戻す（#8941）
  • エグゼキューターを破棄し、テストを改善する（#8928）
  • SimpleChannelInboundHandler（#8893）を削除
  • 新しいアルゴリズムで一貫したハッシュの負荷分散を改善（#8948）
  • 登録完了待ち追加ラッチ（#8962）
  • 未使用のclientハンドラーを削除（#8955）
  • Injvm 呼び出しコピーの Generic Invoke を無視する（#8986）
  • ScopeModelAwareによるTripleHttp2ProtocolへのapplicationModelの注入（#8984）
  • AbstractRegistry 用に最適化（#8971）
  • ローカル呼び出し元を Collections.singletonList から ArrayList に変更（#8997）
  • SerializingExecutor（#8999）を追加
  • 送信前にヘッダーサイズを見積もったり、ロジックを削除したりする必要はありません（#8802）
  • ヘルスサービスキャンセルハンドラを追加（#9004）
  • メソッドレベルの接続設定を削除（#9011）
  • 定数の抽出とタイプミスの修正（#9019）
  • ラッチの交換にはフューチャーを使用します（#9030）
  • デフォルトのサービスインスタンスのディープコピーをサポート（#9029）
  • 課題テンプレートの追加（#9036）
  • LazyConnectExchangeClient（#9041）用に InstanceAddressURL を ServiceConfigURL に再構築します
  • ListBoolMatch コードを埋め、DubboAttachmentMatch のコードを最適化（#8448）
  • フォーマットトリプル（#9058）
  • グローバル リソースとエグゼキューター サービスを管理し、zk client 接続を修正します（#9033）
  • 非推奨の説明を追加（#9065）

:rocket:安定性の向上
