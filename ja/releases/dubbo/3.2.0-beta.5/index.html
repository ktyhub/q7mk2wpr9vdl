dubbo 3.2.0-beta.5

プレリリース 公開日2023年2月9日 出典apache/dubbo English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.2.0-beta.5

何が変わったのか

機能

  • https://github.com/apache/dubbo/pull/11418 に @jojocodeX による Spring Security プラグインを追加
  • https://github.com/apache/dubbo/pull/11457 の @songxiaosheng によるダボ メーターのプル遅延の最適化とダボ バージョン メーターの追加
  • トリプルスタブは、https://github.com/apache/dubbo/pull/11464 の @icodening による非同期モードをサポートします
  • @KamToHung による JRE ユーティリティ (#11393) を https://github.com/apache/dubbo/pull/11396 に追加
  • https://github.com/apache/dubbo/pull/11021 の @marcingrzejszczak によるマイクロメーター観察 API のサポートを追加しました
  • https://github.com/apache/dubbo/pull/11359 の @AlbumenJ による ClusterFilter の呼び出し元を取得する Invocation#getInvokedInvokers を導入します

バグ修正

  • https://github.com/apache/dubbo/pull/11496 の @AlbumenJ によるアドレス無効チェックを削除
  • https://github.com/apache/dubbo/pull/11492 の @AlbumenJ による curator5 バージョンを修正
  • https://github.com/apache/dubbo/pull/11455 の @EarthChen によるトライ フューチャーを修正
  • https://github.com/apache/dubbo/pull/11443 の @AlbumenJ による ThreadLocal Remove を修正
  • https://github.com/apache/dubbo/pull/11392 の @songxiaosheng によるメトリクス フィルター パスを修正
  • https://github.com/apache/dubbo/pull/11360 の @KamToHung による、channelHandlers に null オブジェクト (#11357) がある問題を修正

パフォーマンスの最適化

  • https://github.com/apache/dubbo/pull/11440 の @icodening によるチャネル書き込み時の同期の最適化

コードの拡張

関連する PR: #11456、#11352、#11433、#11420、#11386、#11383

What's Changed

Feature

  • Add Spring Security Plugin by @jojocodeX in https://github.com/apache/dubbo/pull/11418
  • Optimization dubbo meter pull delay and add dubbo version meter by @songxiaosheng in https://github.com/apache/dubbo/pull/11457
  • Triple stub support async mode by @icodening in https://github.com/apache/dubbo/pull/11464
  • Add JRE utils (#11393) by @KamToHung in https://github.com/apache/dubbo/pull/11396
  • Added support for Micrometer Observation API by @marcingrzejszczak in https://github.com/apache/dubbo/pull/11021
  • Introduce Invocation#getInvokedInvokers to get invokers for ClusterFilter by @AlbumenJ in https://github.com/apache/dubbo/pull/11359

Bugfix

  • Remove address invalid check by @AlbumenJ in https://github.com/apache/dubbo/pull/11496
  • Fix curator5 version by @AlbumenJ in https://github.com/apache/dubbo/pull/11492
  • Fix tri future by @EarthChen in https://github.com/apache/dubbo/pull/11455
  • Fix ThreadLocal Remove by @AlbumenJ in https://github.com/apache/dubbo/pull/11443
  • Fix metrics filter path by @songxiaosheng in https://github.com/apache/dubbo/pull/11392
  • fix channelHandlers has null object (#11357) by @KamToHung in https://github.com/apache/dubbo/pull/11360

Performance Optimization

  • optimized sync on channel write by @icodening in https://github.com/apache/dubbo/pull/11440

Code Enhancement

Releates PRs: #11456, #11352, #11433, #11420, #11386, #11383
