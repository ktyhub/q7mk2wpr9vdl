dubbo 3.2.8

パッチ 公開日2023年11月1日 出典apache/dubbo English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ダボダボ-3.2.8

何が変わったのか

機能

  • https://github.com/apache/dubbo/pull/12955 の @icodening によるトリプル プロトコルのハートビートをサポート
  • https://github.com/apache/dubbo/pull/13201 の @suncairong163 による Jboss @Form サポート
  • 複数のレジストリのサポート サービス検出 (https://github.com/apache/dubbo/pull/13137 の @zhengkaifor による)

バグ修正

  • https://github.com/apache/dubbo/pull/13102 の @finefuture によるメモリ リークの防止に onData のハンドルが失敗した場合に ByteBuf を解放
  • https://github.com/apache/dubbo/pull/13178 の @finefuture によるトリプル client ストリーム エグゼキューターを修正
  • https://github.com/apache/dubbo/pull/12950 の @finefuture による RejectException を修正
  • https://github.com/apache/dubbo/pull/13199 の @sick-cat によって REST プロトコルでの受け入れのデフォルト値を設定
  • https://github.com/apache/dubbo/pull/13223 の @namelesssssssssssss による StubMethodDescriptor の間違った returnType を修正
  • https://github.com/apache/dubbo/pull/13228 で @AlbumenJ によるゴー アウェイ フレームを受信できない問題を修正
  • https://github.com/apache/dubbo/pull/13224 の @AlbumenJ によるトリプル メソッド オーバーライドを修正
  • https://github.com/apache/dubbo/pull/13220 の @AlbumenJ によるデッドロックを防ぐために遅延スプリング ターゲットの同期ロックを削除
  • https://github.com/apache/dubbo/pull/13237 で @AlbumenJ によってコンシューマのデフォルト値をロードすると MigrationRule が変更される問題を修正
  • https://github.com/apache/dubbo/pull/13247 の @sick-cat による残りのプロトコルの lowerCase ヘッダーを修正
  • https://github.com/apache/dubbo/pull/13249 の @sick-cat による未知のプロパティで失敗しないジャクソンの逆シリアル化を修正
  • https://github.com/apache/dubbo/pull/13272 で @AlbumenJ によってサービス インスタンス リスナーを削除するときのサービス キー パラメータを修正
  • https://github.com/apache/dubbo/pull/13277 の @AlbumenJ による ServiceDiscoveryRegistry の MappingListener オーバーライドを修正

コードの拡張

関連する PR: #13147、#13150、#13159、#13172、#13174、#13175、#13139、#13215、#13214、#13229、#13217、#13218、#13233、#13234、#13243、#13263

What's Changed

Feature

  • Support heartbeat for triple protocol by @icodening in https://github.com/apache/dubbo/pull/12955
  • Jboss @Form support by @suncairong163 in https://github.com/apache/dubbo/pull/13201
  • Multiple Registry support Service Discovery by @zhengkaifor in https://github.com/apache/dubbo/pull/13137

Bugfix

  • Release ByteBuf when handle onData failed to prevent memory leak by @finefuture in https://github.com/apache/dubbo/pull/13102
  • Fix triple client stream executor by @finefuture in https://github.com/apache/dubbo/pull/13178
  • Fix RejectException by @finefuture in https://github.com/apache/dubbo/pull/12950
  • Set default value for accept in rest protocol by @sick-cat in https://github.com/apache/dubbo/pull/13199
  • Fix wrong returnTypes for StubMethodDescriptor by @namelessssssssssss in https://github.com/apache/dubbo/pull/13223
  • Fix unable to receive go away frame by @AlbumenJ in https://github.com/apache/dubbo/pull/13228
  • Fix triple method override by @AlbumenJ in https://github.com/apache/dubbo/pull/13224
  • Remove sync lock for lazy spring target to prevent dead lock by @AlbumenJ in https://github.com/apache/dubbo/pull/13220
  • Fix MigrationRule changing when load consumer default value by @AlbumenJ in https://github.com/apache/dubbo/pull/13237
  • Fix lowerCase header in rest protocol by @sick-cat in https://github.com/apache/dubbo/pull/13247
  • Fix jackson deserialization, not fail on unknown properties by @sick-cat in https://github.com/apache/dubbo/pull/13249
  • Fix service key params when remove service instance listener by @AlbumenJ in https://github.com/apache/dubbo/pull/13272
  • Fix MappingListener override in ServiceDiscoveryRegistry by @AlbumenJ in https://github.com/apache/dubbo/pull/13277

Releates PRs: #13147, #13150, #13159, #13172, #13174, #13175, #13139, #13215, #13214, #13229, #13217, #13218, #13233, #13234, #13243, #13263
