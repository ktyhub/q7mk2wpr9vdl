#シェンユウv2.7.0

[v2.7.0]

✨ 新機能

  1. dockerfile Java ランタイム バージョン 8 から 17 にアップグレードします。
  2. SpringBoot を 3.x にアップグレードする
  3. ShenYu 管理クラスタのサポート
  4. checkstyle プラグインを 3.4.0 にアップグレードする
  5. データソースのサポート OceanBase
  6. セレクター/ルールステータスの一括変更をサポート
  7. PathAuthステータスの一括変更をサポート
  8. apache dubbo バージョンのアップグレード 9.Contribute with Gitpodをサポート
  9. 構成のエクスポートとインポートのサポート
  10. シェンユ cliENT ハートビートを追加
  11. 名前空間のサポート
  12. k8s の動的スケールのサポート
  13. Client ID 検証を実装して、新規ログイン時に以前のトークンを無効にする
  14. 分割プラグインでのグレーリリースのサポート
  15. Kubernetes レジストリをサポート
  16. shenyu-plugin-wasmを追加

⚡強化

  1. rocketmq ロギング e2e テストを追加
  2. メトリクスレートリミッター収集の強化
  3. Sentinel、Resilience4j、および Hystrix のメトリクス収集を強化する
  4. ソファ共通ツールの依存関係を整理する
  5. 期限切れのコメントを削除する
  6. 不足しているライセンスを追加する
  7. Kafka でメッセージ送信用のコールバックを設定する
  8. Dubbo のメタデータからロードバランス構成を使用する
  9. select から取得したアップストリームに非 null 検証を追加します。
  10. ルールハンドルからダボ RPC コンテキストまでのタイムアウトを設定します。
  11. セレクターとルールを有効にしたときにイベントを発行する
  12. 終了したセッションを NAMESPACE_SESSION_MAP から削除します
  13. ShenyuClientURIExecutorSubscriber のテスト ケースを追加
  14. ShenyuClientIllegalArgumentException のテスト ケースを追加
  15. ShenyuClientRegisterEventPublisher のテスト ケースを追加します。
  16. ShenyuClientMetadataExecutorSubscriber のテスト ケースを追加
  17. AbstractWasmPluginDataHandler のテスト ケースを追加
  18. ShenyuClientRegisterRepositoryFactoryTest のテスト ケースを追加します。
  19. AbstractWasmDiscoveryHandler のテスト ケースを追加
  20. ソファ RPC バージョンのサポートのアップグレード
  21. SignプラグインのヘッダーキーをCrossFilter設定に追加します
  22. パスワードを暗号化する
  23. AbstractShenyuWasmPluginTest を追加する
  24. RewritePlugin/ContextPathPlugin はアプリケーションとプラグイン全体をサポートします
  25. 重複パスチェックの削除
  26. Alibaba Dubbo サポートの削除
  27. docker env set http パスをサポート
  28. コードを追加してリファクタリングを改善する
  29. cookie\header\param からのトークンの取得をサポート
  30. ShenyuDubboService アノテーションのデフォルト値を DubboService アノテーションのデフォルト値と同じにする
  31. db スクリプトを管理パッケージに追加します
  32. デッドコードを削除し、いくつかの改善を追加する
  33. MotanServiceEventListenerTest ケースの最適化
  34. shenyu-registry-eureka.xml 内の重複した Maven を削除する
  35. Jwt 依存関係が更新されました
  36. 印刷プラグインの実行時間
  37. 管理者でのディスカバリ ローカル サポート アップストリーム ヘルス チェック
  38. ルールキャッシュを閉じる
  39. 同時実行性の低下
  40. 「orElse」の実行を回避するためにロジックを最適化する，VersionTwoExtractor.java を更新する

♻️リファクタリング

  1. spring-integration-jdbcによる管理分散ロック
  2. beanUtils をリファクタリングする
  3. macos ci を削除します
  4. ロギング プラグイン DataBuffer の非推奨メソッドを更新する
  5. e2e k8s を docker 構成に変更します
  6. Admin Swagger を springfox から springdoc に移行する
  7. springcloud プラグインのリファクタリング
  8. 一部のコードをリファクタリングする
  9. SO_SNDBUF と SO_RCVBUF を削除します
  10. shenyu-sync-data-http をリファクタリングします: ログ %s -> {} を置き換えます。
  11. ノードタイプリスナーの最適化
  12. プラグインのライフサイクルのリファクタリング
  13. コードの順序を調整し、無効な入力パラメータを削除します

🐛バグ修正

  1. リクエストプラグインの重複ヘッダーを修正
  2. 分割セレクターを削除しても proxy.selector と Discovery が削除されない問題を修正
  3. LoggingPlugin エラー ログ キャッチを修正
  4. ロギングプラグインサンプルのバグを修正 5.メモリオーバーフローを修正
  5. リライト統合テストを修正
  6. AbstractWasmPluginDataHandlerTest を修正
  7. sql-script/h2/schema.sql で欠落している PRIMARY KEY を修正する
  8. データ辞書ページのデータソート例外を修正 10.ドキュメントエラーを修正
  9. コンテキストパス更新後のダッシュボードのルーティングの不一致を解決する
  10. etcd同期設定の問題を修正
  11. 領事の同期問題を修正
  12. 登録しないとクエリができないバグを修正
  13. プラグイン ID クエリの修正とデータ型の更新により、プラグイン編集ページの問題を修正
  14. クラス AdminConstants に単語のスペルミスがある問題を修正
  15. shenyu-examples-springmvc の起動に失敗した問題を修正
  16. ダッシュボードメニューの子の並べ替えが機能しない問題を修正
  17. ShenyuApacheDubboXmlProviderApplication 構成を修正する
  18. プロキシ セレクターと検出のデータ同期 dataId が一意ではない問題を修正
  19. フィルタ無効辞書オプション
  20. SpringCloudParser MetaDataのnullデータを修正
  21. client レジスタの検証を修正
  22. ダボの設定serialize-check-status=DISABLE
  23. TestApacheDuboXmlApplication の起動に失敗する例を修正 26.nacos データ同期モデルに contextPath 設定が欠落しているのを修正
  24. マルチスレッドシナリオで SPI が非シングルトンオブジェクトを作成する問題を修正
  25. BadSqlGrammarException を修正する
  26. 単語のタイプミスを修正
  27. ListUtil->merge 例外を修正 31.メタデータの無効化がフィルタリングされない問題を修正
  28. 分割ロギングリクエストメソッドを修正
  29. e2e チャンクヘッダーエラーを修正
  30. Cookie エラーと SQL チェックを修正
  31. NPEの問題を修正
  32. 無効なパスエラーを修正
  33. ホットロードの問題を修正
  34. e2e テストケースが wget コマンドを実行できない問題を修正
  35. フォールバックの問題を修正する
  36. いくつかの CI のバグを修正 41.rule-sqlmap.xml の SQL エラーを解決する
  37. readYmlBuildRepository NPE を修正する
  38. nacos を Shenyu-examples-SpringCloud プロジェクトに登録できない問題を修正
  39. springCloudのルールデータパス設定が使用されなかったのを修正
  40. shenyu-plugin-logging-elasticsearch を修正: ElasticSearchLogConfig の setIndexName を変更
  41. サービスを停止するときにゲートウェイから最初にオフラインにならない問題を修正
  42. k8s liveness プローブが wget コマンドを実行できないエラーを修正
  43. 起動時の AbstractNodeDataSyncService ロード DiscoverUpstream を修正
