Stirling-PDF_0.33.1 Docker ハブを starlingtools v3.0.0 に移動

Stirling PDF V3.0 がリリースされました。 このアップデートでは、新しい自動化システム、すべての人に無料の OAuth SSO、新しいテキスト エディター、大量の新機能、バグ修正、セキュリティ修正など、多くのエキサイティングな新しい変更が導入されています。

「PDF エディター」と並んで「PDF プロセッサー」と呼ばれる新しいシステムがあります。 PDF プロセッサーは、Stirling PDF ですでに使用しているツールを利用し、さまざまなソース (フォルダー/FTP/S3 など) を含む多数のファイルに対してツールを実行できます。 アイデアは、10,000 個のファイルを OCR する必要がある場合、フォルダー全体を圧縮するか、ドキュメント ライブラリ全体を変換する必要がある場合、これを支援できるツールであり、今後のファイルが到着したときにリッスンして実行できるようにする必要があるということです。 これはプロセッサの最初のメジャー リリースであり、ユーザーの使用状況に基づいて迅速に改善する予定です。 例を含む完全なプロセッサ ガイド AI はプロセッサーのオプション部品としても利用できます。 AI を使用すると、ドキュメントを理解し、分類し、情報を抽出し、処理の自動化を支援できます。 AI は完全にオプションであり (デフォルトではオフ)、セットアップに応じてローカル/セルフホスト モデルを含むさまざまなモデルを使用できます。 自動化には、毎月 1,000 個の PDF が無料で含まれるようになりました。 この許容値は、プロセッサー、API、および AI 機能による自動処理に適用されます。 サーバーをスターリング.com にリンクすると、毎月 500 個の PDF が追加され、ホストされた AI (独自の AI をホストしたくない場合) にアクセスできるようになります。 通常の PDF エディターの使用は引き続き無料かつ無制限です。さらに、OAuth SSO をすべてのユーザーに無料で提供します。

V3.0 には、PDF エディター側の大幅な改善も含まれています。

  • すでに述べた無料の OAuth SSO
  • 新しいテキスト エディター。アルファ版は終了しました。UI、パフォーマンス、互換性が大幅に向上していることが期待できます。
  • フォームエディターとフォーム作成の改善
  • 自動フォーム検出
  • 新しいクイック アクセス バー
  • 自動回転
  • 大幅な編集の改善
  • PDF/UA 変換 (WIP)
  • PDF ポートフォリオのサポート
  • 専用リーダービュー
  • QRコードを使用して携帯電話から署名します
  • RFC3161 タイムスタンプ
  • すべての Stirling PDF を検索
  • モバイルUIの改善
  • デスクトップのファイル処理とファイル履歴が改善され、削除されたファイルはスターリング UI で削除されるようになりました
  • 新しいファイルライブラリ
  • 自動化を実行するためにディスクからスターリングにフォルダーをマウントするための新しいデスクトップフォルダー (将来の更新で拡張される予定)
  • 新しい設定ページ
  • 以前のツールの使用状況に基づいた、よりスマートなツールの提案
  • 一般的な UI の改善とバグ修正
  • いくつかのバグ修正とセキュリティの改善!

ぜひ V3.0 をお試しいただき、ご意見をお聞かせください。今後数週間にわたって修正、改善、新しいプロセッサーとエディターの機能を出荷し、リリースはほぼ毎週になる予定で、今後はコミュニティ PR に重点を置きます。

Stirling-PDF_0.33.1 Docker hub move to stirlingtools v3.0.0

Highlights

  • PDF Processor ships as a v1 automation engine — A second system alongside the Editor runs existing Stirling tools across thousands of files from folders, FTP, S3 and MCP sources (#6795), with watched folders that process files as they arrive — aimed squarely at bulk OCR/compress/convert jobs. It's explicitly billed as a first major release, and the fix list bears that out: circular dependencies in watched folders (#7308), locking files until processing completes (#8120), mounted-subfolder processing (#8141), and removal of the Automate operation timeout (#7082) all landed here, so treat it as fast-moving rather than stable. AI document classification and extraction are wired in but fully optional and off by default, with self-hosted model support.
  • Automation is now quota-metered — the key behavioral change — Processor/API/AI automation gets 1,000 PDFs/month free; linking your instance to stirling.com adds 500/month plus hosted AI, while normal Editor usage stays free and unlimited. Anyone running large batch or automated workflows must now budget allowance or link their server before relying on Processor in production — operationally the most significant change in the release despite being buried in the intro.
  • OAuth SSO is free for everyone — Previously gated behind paid tiers, SSO is now open to all users, removing a common adoption blocker and materially improving the self-hosted enterprise story.
  • Text Editor exits alpha; editor surface expands — The rebuilt text editor is out of alpha with major UI, performance and compatibility gains, joined by an improved form editor with auto-detection, quick access bar, redaction overhaul, PDF Portfolio support, RFC3161 timestamps, QR-code sign-from-phone and a dedicated reader view. PDF/UA conversion is still WIP — don't depend on it for accessibility compliance yet. Supporting fixes include signature placement (#7093), viewer search reporting "0 of 0" (#7228), and PDF preview/worker memory leaks (#7281).
  • Security and operational hardening worth upgrading for — Share-link route tokens are now constrained to UUID length (#7626), Telegram bot tokens are masked in settings output (#6822), the signup page is removed from self-hosted builds (#7406), SMTP timeouts are bounded so a wedged relay can't park a thread (#7879), and partial admin saves are merged instead of clobbered (#7545). Deployment note: the Docker Hub image has moved to the stirlingtools namespace — update your image references and pull policies.
  • Breaking changes — None explicitly documented; the Docker Hub namespace move above is the only deployment migration to plan for.

Stirling PDF V3.0 is live! With this update we are introducing a lot of exciting new changes, A brand new automation system, Free OAuth SSO for all, brand new text editor and a ton of new features, bug fixes and security fixes

We have a new system along side the "PDF Editor" called the "PDF Processor" The PDF Processor takes the tools you already use in Stirling PDF and lets you run them across a large numbers of files with a variety of sources (Folders/FTP/S3 etc) The idea is, If you need to OCR 10,000 files, Compress a whole folder or convert a whole document library this should be a tool which can help with that and allow it to listen and run for future files as they arrive This is the first major release of Processor and we will be improving it quickly based on how people use it. Full Processor guide with examples AI is also available as an optional part of Processor. You can use AI to understand documents, classify them, extract information, and help automate processing. AI is fully optional (and off by default) and can use various models including locally/self-hosted models depending on your setup. Automation now includes 1,000 PDFs per month free. This allowance applies to automated processing through Processor, API, and AI features. Linking your server to stirling.com gives you an additional 500 PDFs per month and access to our hosted AI (If you dont want to host your own). Normal PDF Editor usage remains free and unlimited. In addition, we are also making OAuth SSO free for all users.

V3.0 also includes major improvements to the PDF Editor side of things:

  • The already mentioned free OAuth SSO
  • Brand new Text Editor, now out of alpha you should expect drastic better UI, performance and compatibility
  • Improved Form Editor and form creation
  • Auto form detection
  • New Quick access bar
  • Auto rotate
  • Major redaction improvements
  • PDF/UA conversion (WIP)
  • PDF Portfolio support
  • Dedicated Reader view
  • Sign from your phone using a QR code
  • RFC3161 timestamps
  • Search across all Stirling PDF
  • Mobile UI improvements
  • File handling and file history improved for desktop so deleted files delete in stirling UI
  • Brand new Files Library
  • New desktop folders to mount folders from disk into stirling to run automation on (Will be expanded on in future updates)
  • Brand new Settings Page
  • Smarter tool suggestions based on previous tool usage
  • General UI improvements and bug fixes
  • Several bug fixes and security improvements!

Please try V3.0 and let us know what you think. We will be shipping fixes, improvements, and new Processor and editor capabilities over the next few weeks with releases expected to be near weekly, with a greater focus on community PRs going forward.
