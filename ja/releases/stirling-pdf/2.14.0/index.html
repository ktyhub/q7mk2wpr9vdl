Stirling-PDF v2.14.0

マイナー 公開日2026年6月30日 出典Stirling-Tools/Stirling-PDF English original

Stirling-PDF_0.33.1 Docker ハブを starlingtools v2.14.0 に移動

このリリースでは、デスクトップ ハードウェア トークンの署名やさまざまな UI 要素の変更など、いくつかの変更が追加されています。

特徴は次のとおりです。

  • デスクトップトークン署名！ USB/スマートカード PKCS#11 や OS 証明書ストアなど (現在デスクトップのみ)
  • トップバーに再導入される共有署名およびファイル共有 UI を修正
  • コメント/注釈および添付ファイルのサイド メニューが改善され、追加が簡単になり、新しいすべてクリア ボタンが追加されました。
  • 必要な企業向けのログイン免責事項機能
  • デスクトップのログイン問題を修正
  • インストーラーにロゴを追加し、インストーラーの内部名を Stirling-PDF から Stirling PDF (- なし) に変更します。

何が変わったのか

機能強化

  • https://github.com/Stirling-Tools/Stirling-PDF/pull/6766 に @Frooodle によるログイン同意書免責条項機能を追加
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/6792 の @MattSaito による一括コメントと注釈のクリアをエディターに追加
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/6786 の @jbrunton96 によるその他のデスクトップ CI 最適化
  • ローカル型チェックのために TS7 にアップグレード (https://github.com/Stirling-Tools/Stirling-PDF/pull/6815 の @jbrunton96 による)
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/6808 の @jbrunton96 によるフロントエンドでの any タイプのリンティングを拡張
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/6764 の @Frooodle により MSI インストーラーのブランドを設定し、表示名を Stirling PDF に変更
  • settings.yml のデフォルトを調整し、https://github.com/Stirling-Tools/Stirling-PDF/pull/6816 の @Frooodle によるデッド/ミスマップ設定を修正
  • https://github.com/Stirling-Tools/Stirling-PDF/pull/6552 の @Frooodle によるサイド メニューのブックマーク、コメント、添付ファイルの UX の改善
  • feat(policies): https://github.com/Stirling-Tools/Stirling-PDF/pull/6788 の @reecebrowne により、すべての PDF 出口パスに run-on-export ポリシーを適用します
  • 偉業(共有): @reecebrowne による @shared をブランド ロゴ アセットの単一ホームにする (https://github.com/Stirling-Tools/Stirling-PDF/pull/6714)

  • 署名 UI エッジケースのクリーンアップ (https://github.com/Stirling-Tools/Stirling-PDF/pull/6849 の @EthanHealy01 による)
  • build(deps): pypdf のバンプ テスト + https://github.com/Stirling-Tools/Stirling-PDF/pull/6831 の @dependabot[bot] による翻訳を追加

Stirling-PDF_0.33.1 Docker hub move to stirlingtools v2.14.0

Highlights

  • Desktop hardware-token signing (desktop only) — headline feature, biggest reason to upgrade — adds PKCS#11/USB smart-card and OS certificate-store signing, plus a fix for the missing refresh token on desktop (#6838) that resolves desktop login issues. If you sign on the desktop app, this release is worth installing; server/web-only users get little from this specific change.

  • Migration warning: settings.yml defaults and installer rename — #6816 "aligns settings.yml defaults and fix dead/mismapped settings," so deployments with a customized settings.yml should review it before upgrading: keys that were previously dead or mismapped may now take effect. Separately, #6764 brands the MSI installer and changes the internal/display name from Stirling-PDF to Stirling PDF (no hyphen), which can affect shortcuts, registry/uninstall entries, and scripts that match the old string.

  • Policy enforcement now covers every PDF exit path — #6788 makes run-on-export policies apply on all export paths, not just some. Organizations relying on policies should verify their flows, since previously unchecked export routes may now trigger restrictions; this is a real behavior change, not just a bug fix.

  • UI consolidation and a new business-facing login gate — the comments/annotations/attachments side menu is reworked with easier adding and new clear-all buttons (#6552, #6792 bulk comment/annotation clearing), shared signing and file sharing are folded back into the top workbench bar (#6715, #6849 signing edge-case cleanup), and businesses get an optional login agreement disclaimer (#6766).

  • Who can skip, and what can't be confirmed — most remaining changes are contributor/CI/internal only: TS7 local type-checking (#6815), expanded any linting (#6808), signed/unsigned desktop CI split (#6786, #6840, #6809), consolidating brand logos under @shared (#6714), and license/translation/test bumps (#6794, #6831). Web-only users with no custom settings and no reliance on export policies can defer. The release title mentions a "Docker hub move to stirlingtools," but the body contains no detail on any registry/namespace change, so no such change can be confirmed from this changelog.

This release adds several changes including desktop hardware token signing and changes to various UI elements

Features include:

  • Desktop token signing! Such as USB/smart-card PKCS#11 and OS certificate stores etc (Currently desktop only)
  • Fixes for shared signing and file sharing UIs to be reintroduced in top bar
  • Improved Side menu for comments/annotations and attachments with easier adding and new clear all buttons
  • Login disclaimer feature for businesses that want it
  • Fix desktop login issues
  • Adds logo to installer and renames installer internal name from Stirling-PDF to Stirling PDF (without the -)
