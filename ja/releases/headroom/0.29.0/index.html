#ヘッドルームv0.29.0

何が変わったのか

  • 修正（オープンコード）: ルート ネイティブ プロバイダー + トランスポート プラグインの読み込み、https://github.com/headroomlabs-ai/headroom/pull/1573 の @chopratejas による Serena コンテキストを修正
  • 修正(価格設定): https://github.com/headroomlabs-ai/headroom/pull/1186 の @shreyassks による MiniMax-M3 (プロバイダー プレフィックス + 事前登録) を解決します。
  • fix(learn): https://github.com/headroomlabs-ai/headroom/pull/1288 で @gglucass によって上書きされるのではなく、プロジェクト全体の冗長ベースラインを集約します。
  • 修正: https://github.com/headroomlabs-ai/headroom/pull/1427 で @aivinay による人為的パススルー ツールの順序を保持する
  • fix(mcp): https://github.com/headroomlabs-ai/headroom/pull/1428 の @rodboev による headroom_stats のライフタイム合計とラベル ローリング セッション スコープを表示します。
  • 修正 (opencode): https://github.com/headroomlabs-ai/headroom/pull/1596 の @rodboev によるカスタム OpenAI ゲートウェイ パスを保存
  • ドキュメント: ヘッドルーム CLI が pip のみであることを明確にします。 npm headroom-ai は、https://github.com/headroomlabs-ai/headroom/pull/1585 の @tenderdeve による TS SDK です。
  • 修正: AVX2 なしの x86 CPU で Magika バックエンドをスキップ (https://github.com/headroomlabs-ai/headroom/pull/1162 の @dwizzle204 による)
  • 修正(節約): https://github.com/headroomlabs-ai/headroom/pull/1429 の @gglucass による入力コスト見積もりでキャッシュ読み取りトークンをカウントする
  • 修正（プロキシ）: https://github.com/headroomlabs-ai/headroom/pull/1430 の @rodboev により、kompress の飽和によりプレアップストリーム バジェットが使い果たされる場合にフェール オープンが発生する
  • 修正 (コーデックス): https://github.com/headroomlabs-ai/headroom/pull/1431 で @rudironsoni によるヘッドルーム プロバイダー構成の重複を回避
  • 修正(プロキシ): https://github.com/headroomlabs-ai/headroom/pull/1451 で @aivinay によるストリーミング CCR 取得を処理する
  • 修正 (ラップ): Windows 上の共有プロキシを切り離し、https://github.com/headroomlabs-ai/headroom/pull/1464 の @quentinmaisonneuve の近くにある不正なエージェントが存続できるようにします。
  • fix(cortex-code): 現在の Cortex REST API エンドポイントに移行 + @sfc-gh-nashukla による e2e ベンチマークを https://github.com/headroomlabs-ai/headroom/pull/1474 に追加
  • 修正(ラップ): https://github.com/headroomlabs-ai/headroom/pull/1477 で @aivinay によるカスタム頂点ベース URL を保存
  • 修正(openclaw): https://github.com/headroomlabs-ai/headroom/pull/1459 の @Ru0k3 によって ~/.local/bin にある UV インストールされたヘッドルーム バイナリを検出
  • ci: https://github.com/headroomlabs-ai/headroom/pull/1505 の @wolph によるコミットされたマージ競合マーカーに対する保護
  • 修正 (ダッシュボード): https://github.com/headroomlabs-ai/headroom/pull/1511 の @rodboev によるライブ オリジンからプロジェクトごとのセットアップ URL を導出
  • fix(evals): CJK を意識した F1 トークン化 + https://github.com/headroomlabs-ai/headroom/pull/1527 の @lifeodyssey によるトークン推定
  • 修正(プロキシ): https://github.com/headroomlabs-ai/headroom/pull/1598 で @aivinay による応答パススルー バイトを保持
  • 修正(プロキシ): https://github.com/headroomlabs-ai/headroom/pull/1473 の @inix-x によってキャッシュ キーにシステム/ツール/サンプリングを含めます
  • 修正 (圧縮): https://github.com/headroomlabs-ai/headroom/pull/1479 の @rodboev によるユニット ルーター パスでの損失のあるマークのないツール出力を拒否
  • feat(proxy): --force-kompress-all を追加して、https://github.com/headroomlabs-ai/headroom/pull/1613 の @chopratejas によってすべてのコンテンツを kompress-v2-base 経由でルーティングします
  • 雑務: https://github.com/headroomlabs-ai/headroom/pull/1622 の @chopratejas によるメンテナのキャッチオールを使用して CODEOWNERS を追加
  • 修正(検出): https://github.com/headroomlabs-ai/headroom/pull/1548 の @tenderdeve による孤立した +++ ターゲット行に unidiff パニックが含まれています
  • 修正 (メモリ): ローカル エンベッダー CPU スレッドのオーバーサブスクリプションを制限 (#198) by @Krishnachaitanyakc (https://github.com/headroomlabs-ai/headroom/pull/1559)
  • 修正 (インストール): runtime_status (#1544) で Windows セーフ PID liveness プローブを使用 (https://github.com/headroomlabs-ai/headroom/pull/1560 の @Parideboy による)
  • chore(deps): https://github.com/headroomlabs-ai/headroom/pull/1662 の @dependabot[bot] により、uv グループ内の 5.0.0 から 5.3.0 へのトランスフォーマーを 1 つのディレクトリにバンプします。
  • fix(ccr): https://github.com/headroomlabs-ai/headroom/pull/1564 の @rodboev による SQLite ストアのワークスペース ディレクトリを優先します
  • 修正(変換): Windows ウォッチドッグによるバインドされたネイティブ コンテンツ検出 (#575) by @Parideboy (https://github.com/headroomlabs-ai/headroom/pull/1563)
  • 修正 (bedrock): https://github.com/headroomlabs-ai/headroom/pull/1553 の @tenderdeve によるセッション トークン認証に botocore がない場合に高速に失敗する
  • 修正: https://github.com/headroomlabs-ai/headroom/pull/1393 の @vladgrish による ANTHROPIC_VERTEX_BASE_URL によるクロード コードの Vertex AI サポート
  • 修正 (プロキシ): https://github.com/headroomlabs-ai/headroom/pull/1502 の @ShutovKS による専用 OpenAI ハンドラーの x-headroom-base-url を尊重します
  • 修正 (インストール): https://github.com/headroomlabs-ai/headroom/pull/1576 の @abhay-codes07 による start_detached_agent の親ログ fd を閉じる
  • 修正 (claude): https://github.com/headroomlabs-ai/headroom/pull/1610 の @rodboev による表面リモート コントロール プロキシの非互換性
  • 修正（プロキシ）：wire --compression-max-workers / HEADROOM_COMPRESSION_MAX_WORKERS by @gglucass in https://github.com/headroomlabs-ai/headroom/pull/1632
  • 修正(cli): https://github.com/headroomlabs-ai/headroom/pull/1634 の @gglucass によるバナー内の未接続の圧縮チューニング環境変数の広告を停止
  • 修正(学習): https://github.com/headroomlabs-ai/headroom/pull/1642 で @tenderdeve によってクロード ログとメモリを見つけるときに CLAUDE_CONFIG_DIR を尊重する
  • 修正(プロキシ): https://github.com/headroomlabs-ai/headroom/pull/1647 の @aivinay による永続的な節約メトリクスを公開
  • 修正 (ダッシュボード): https://github.com/headroomlabs-ai/headroom/pull/1653 の @chris-yyau によるトークン節約ヘッドラインの分母を揃える
  • 修正(プロキシ): https://github.com/headroomlabs-ai/headroom/pull/1663 の @gglucass によって HTTP /responses パス上の Codex lite ヘッダーを削除
  • docs(proxy): https://github.com/headroomlabs-ai/headroom/pull/1710 の @Parideboy によって --code-aware のデフォルトが無効になるように修正
  • feat(stats): https://github.com/headroomlabs-ai/headroom/pull/1680 の @gglucass による /stats 概要の Codex WS 圧縮カウンターを表面化
  • fix(proxy/auth): https://github.com/headroomlabs-ai/headroom/pull/1672 の @abhay-codes07 による実際の Anthropic OAuth トークン プレフィックス (sk-ant-oat) と一致します。
  • fix(transforms/content-router): https://github.com/headroomlabs-ai/headroom/pull/1717 の @chopratejas による内部ツール出力ペイロードの検出
  • 修正（メモリ）: https://github.com/headroomlabs-ai/headroom/pull/1691 の @tenderdeve によるコールドスタート レースを停止するための singleflight LocalBackend init
  • fix(transforms/content-router): https://github.com/headroomlabs-ai/headroom/pull/1719 の @chopratejas により、grep/ログ出力を HTML エクストラクターから遠ざけるようにルーティングしました。
  • feat(proxy): https://github.com/headroomlabs-ai/headroom/pull/1721 の @chopratejas によるフォーマットネイティブ圧縮による --lossless no-CCR モードを追加
  • fix(bedrock): converse、名前付き AWS プロファイル、au 経由で ARN をルーティングします。 re… by @mhaitana in https://github.com/headroomlabs-ai/headroom/pull/1456
  • perf(proxy): https://github.com/headroomlabs-ai/headroom/pull/1612 の @inix-x によるイベント ループからのオフロード画像圧縮
  • fix(wrap): https://github.com/headroomlabs-ai/headroom/pull/1604 の @abhay-codes07 による unwrap の Codex AGENTS.md から rtk 命令を削除
  • feat(transforms): 適応型大津 KEEP/DROP 閾値 (+ メインの土地関連性分割) by @chopratejas (https://github.com/headroomlabs-ai/headroom/pull/1726)
  • 雑務: https://github.com/headroomlabs-ai/headroom/pull/1574 の @github-actions[bot] によるメインのリリース
