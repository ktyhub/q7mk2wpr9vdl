  • プロキシ: --compressor + レジストリ インベントリを介して組み込みコンプレッサーを選択します (#2373) (56c7d4a)
  • rust: 構造化散文オフロード配管を追加 (#334) (#2378) (9e07785)
  • rust: CodeCompressor AST コンプレッサーを Rust (パリティのみ) (#1154) (e530de5) に移植します。
  • rust: Kompress ML 散文コンプレッサーを Rust (パリティのみ) (#1153) (83e27e5) に移植します。
  • テレメトリ: リクエストごとのレコード プロバイダー キャッシュの読み取り/書き込み/キャッシュされていないトークン (#2450) (bec4cce)
  • 変換: 圧縮信号を追加 + レジストリ経由で code_aware/html/diff をディスパッチ (#2400) (7ebda67)
  • 変換: プラグ可能なコンプレッサー レジストリ + headroom.compressor エントリ ポイントを追加 (#2370) (a02073e)
  • 変換: コンプレッサー レジストリ + 前方質問を介して kompress/text をディスパッチします (#2411) (446ec26)
  • 変換: コンプレッサー レジストリ経由で Smart_crusher をディスパッチします (kompress/テキスト ML 境界を延期) (#2404) (7c7bf43)
  • 変換: 組み込みコンプレッサーを実際のものにする Compressor 実装 (アダプター) (#2391) (981616c)
  • wrap: boost Serena — シンボルファースト ガイダンス、ラップ時間事前インデックス、リポ言語スコープ (#2425) (fd0e1a8)
  • wrap: デフォルトのコード メモリを、unified --code-memory の背後にある Serena (ダッシュボード ブラウザ オフ) に設定 (#2413) (6e4425a)
  • **wrap:**red-at-source — 起動されたエージェントの SAFE Quiet-CLI 環境デフォルト (#2548) (c990cfb)
