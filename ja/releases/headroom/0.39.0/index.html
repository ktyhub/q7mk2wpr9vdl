#ヘッドルームv0.39.0

0.39.0 (2026-09-25)

機能

  • 圧縮: CCR 圧縮がどの程度低下したかではなく、どの程度低下したかを説明します (#3635) (62d1cc0)
  • フック: メッセージごとの強力な圧縮拒否権であるprotect_messages を追加 (#3772) (d17ac6a)
  • opencode: トランスポート プラグイン ルーティングからホストを除外します (#3668) (0024b57)
  • プロキシ: /transformations/feed で番号のみのポーラーのメッセージ本文を省略させます (#3672) (46ac52d)
  • 節約: 履歴ロールアップに正確なキャッシュ読み取りコストが含まれます (#3734) (1cb779e)
  • 節約: ワイヤ全体の数値の横に新規入力の節約基準を表示します (#3485) (e92cccc)
  • 節約: 生涯の出力支出を追跡するため、料金負担率には分母が含まれます (#3520) (c766bdb)
  • sdk: compress() で呼び出しごとの構成オーバーライドをサポート (#3370) (c3e8a1e)
  • wrap: vscode クロードで 1m コンテキストをサポート (#3361) (fc5a09e)

バグ修正

  • バイナリ: ダウンロードに sha256 ピンが含まれていない場合にフェール クローズされる (#3724) (26a2c49)
  • キャッシュ/Google: タイムゾーンを認識したキャッシュの有効期限タイムスタンプを許容します (#3210) (7ce2580)
  • キャッシュ: デフォルトの CCR ペイロード プレビューはオフです。ログがオンのときにログを強化します (#3728) (5cb87bc)
  • キャッシュ: キャッシュ モードでは、すでに転送された小さな応答出力をバッチ圧縮しません (#3756) (ab62b9e)
  • キャッシュ: キャッシュ コントロール スキーマ プロパティを保持します (#3348) (b84c4c9)
  • キャッシュ: 転送された OpenAI チャット プレフィックスをターン間で保存します (#3757) (deca575)
  • cache: プレフィックス変換によるプロバイダー キャッシュの破壊を停止します (#3735) (a2bf5ed)
  • キャッシュ: 固定ツール配列でのツール圧縮のスキップを停止 (#3750) (a6a9cef)
  • cli: 非 ASCII 作業ディレクトリ名を init プロファイル スラッグから除外します (#3718) (f3d95ee)
  • cli: 匿名ビーコンのステータスをバナー、ログ、/stats で正確にレポートします (#3533) (fa9edb3)
  • content_detector: CMTrace (SCCM/Intune) ログを BUILD_OUTPUT (#3712) (6feb1fb) として検出します
  • ダッシュボード: 所有者ごとに個別のローリング キャッシュの経済性 (#3319) (a29162b)、クローズ #960
  • docker: ネイティブ ラッパーで OpenCode をサポート (#3547) (d90dadf)
  • 管理者以外の Windows タスク インストールのフォールバック (#3437) (b958509)
  • グラフ: Windows で zip codebase-memory-mcp アセットをフェッチして抽出します (#3730) (b776983)
  • grok: xAI モデル コンテキスト メタデータを保持します (#3312) (#3315) (c81378c)
  • init: コールド スタート レイテンシーを超えて確保フックのタイムアウトを上げます (#3438) (9a11109)
  • install: デプロイメントのインストール後に追加された管理対象環境変数を適用します (#3740) (a4cb2bc)

  • memory: インライン メモリ パーサー内の None メッセージ コンテンツを許容します (#3211) (5ccec67)

headroom v0.39.0

0.39.0 (2026-09-25)

Features

  • compression: describe what CCR compression dropped, not just how much (#3635) (62d1cc0)
  • hooks: add protect_messages, a hard per-message compression veto (#3772) (d17ac6a)
  • opencode: exclude hosts from transport plugin routing (#3668) (0024b57)
  • proxy: let /transformations/feed omit message bodies for number-only pollers (#3672) (46ac52d)
  • savings: carry exact cache-read cost in history rollups (#3734) (1cb779e)
  • savings: show the new-input savings basis beside the whole-wire figure (#3485) (e92cccc)
  • savings: track lifetime output spend so a bill-share rate has a denominator (#3520) (c766bdb)
  • sdk: support per-call config override in compress() (#3370) (c3e8a1e)
  • wrap: support 1m context in vscode claude (#3361) (fc5a09e)
