#ファイアクロールv1.9.0

Firecrawl v1.9.0 リリース

新機能:

セルフホストの改善

  • Supabase client の修正
  • LLM プロバイダーのサポートを修正
  • クロールがはるかに速くなりました
  • キャッシュ可能なルックアップ システムのグローバル採用
  • セットアップが簡単になりました

MCP の改善 (v1.11.0)

  • 多数の改善 (プロンプト、例、パラメータの適切な使用方法)

SDK および API の機能強化

  • SDK 2.0 に変更追跡を追加しました
  • クロールごとの同時実行制限によるクロール遅延のサポート
  • OpenRouter を介した新しい Qwen3 クローラーの例
  • バッチ スクレイピング エンドポイントをキャンセルします

パフォーマンスと制限

  • キャッシュ可能なルックアップ システムのグローバル採用
  • マップ エンドポイントの制限が 5,000 リンクから 30,000 リンクに増加
  • 検索スキーマの制限が 50 から 100 に増加しました

修正と安定性

  • SSL 障害に対するエラー処理の改善
  • オプションのチェーンバグ修正
  • firecrawl-py の WaitAction フィールドの検証
  • 優先順位ではなく時間によって優先順位を付けるように同時実行キューが作り直されました

ダッシュボード（クラウド版）

  • 新しいアクティビティログ

何が変わったのか

  • (sdk/py) https://github.com/mendableai/firecrawl/pull/1506 の @nickscamara によって 2.0 に追加された変更追跡
  • https://github.com/mendableai/firecrawl/pull/1507 の @rafaelsideguide による sdk/スキーマを修正
  • 修正: https://github.com/mendableai/firecrawl/pull/1508 の @devin-ai-integration によるアクション パラメーターの辞書インスタンスとモデル インスタンスの両方を処理する
  • [機能] コントローラー間で結果をスクレイピングするための GCS ストレージ オプションを実装し… by @rafaelsideguide in https://github.com/mendableai/firecrawl/pull/1500
  • (バッチ/スクレイピング) https://github.com/mendableai/firecrawl/pull/1509 の @nickscamara によるバッチ スクレイピング エンドポイントをキャンセルします
  • https://github.com/mendableai/firecrawl/pull/1510 の @devin-ai-integration による OpenRouter を使用した Qwen3 Web クローラーの例を追加
  • https://github.com/mendableai/firecrawl/pull/1413 の @devin-ai-integration によるクロールごとの同時実行制限 (FIR-249) によるクロール遅延機能を追加
  • https://github.com/mendableai/firecrawl/pull/1514 の @devin-ai-integration により、すべての SDK のクロール オプションに遅延パラメーターを追加

firecrawl v1.9.0

Firecrawl v1.9.0 Release

What's New:

Self-Host Improvements

  • Supabase client fixes
  • Fixed support for LLM Providers
  • Crawl is much faster now
  • Global adoption of cacheable lookup system
  • Easier setup

MCP Improvements (v1.11.0)

  • Tons of improvements to it (prompts, examples, and how to use params properly)

SDK & API Enhancements

  • Added change tracking to SDK 2.0
  • Crawl delay support with per-crawl concurrency limiting
  • New Qwen3 crawler example via OpenRouter
  • Cancel batch scrape endpoint

Performance & Limits

  • Global adoption of cacheable lookup system
  • Increased map endpoint limit from 5,000 to 30,000 links
  • Search schema limit increased from 50 to 100

Fixes & Stability

  • Better error handling for SSL failures
  • Optional chaining bug fixes
  • WaitAction field validation in firecrawl-py
  • Concurrency queue reworked to prioritize by time, not priority

Dashboard (Cloud version)

  • New activity logs
