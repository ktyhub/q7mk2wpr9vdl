aider v0.85.0

#エイダーv0.85.0

新しいモデル

  • 思考トークンのサポートを備えた gemini-2.5-pro、gemini-2.5-flash、gemini-2.5-pro-preview-06-05 などの新しい Gemini モデルのサポートを追加しました。
  • 更新されたモデル エイリアス: flash は gemini-2.5-flash を指し、gemini は gemini-2.5-pro を指すようになりました。
  • o1-pro、o3-pro などの応答 API モデルのサポート。
  • 複数のプロバイダーにわたる OpenAI o3-pro モデルのサポートを追加しました。
  • 強化された思考トークンのサポート: 0 に設定することで無効にできるようになり、例を含むヘルプ テキストが改善されました。
  • パフォーマンスを向上させるために、Deepseek モデルの最大トークンが 65536 に増加しました。
  • o3 の価格を更新しました。

新機能と機能強化

  • omarcinkonis により、.gitignore にリストされているファイルを Aider の編集スコープに追加できるようにする --add-gitignore-files フラグを追加しました。
  • 共同作成者属性がコミット メッセージに対してデフォルトで有効になるようになりました。
  • Luke Reeves により、システム プロンプト プレフィックスを使用するようにコミット メッセージ生成が強化されました。
  • 高山京介氏により、コミットメッセージの言語を指定するための --commit-language オプションを追加しました。
  • パフォーマンスを向上させるために --skip-sanity-check-repo が有効になっている場合、高価なファイル追跡操作をスキップします (Makar Ivashko 氏)。
  • jayeshthk によるチャット履歴要約パフォーマンスの最適化。
  • Vasil Markoukin による、--analytics-posthog-host および --analytics-posthog-project-api-key フラグを使用したカスタム PostHog 分析構成オプションを追加しました。

リポジトリ マップ

  • Matthew Tofano によるリポジトリ マップの MATLAB 言語サポートを追加しました。
  • Garrett Hopper によるリポジトリ マップに対する Clojure 言語サポートを追加しました。
  • コード分析を改善するために、リポジトリ マップでのケバブケース識別子の認識が改善されました。

修正と小さな改善

  • Vincent Taverna と Sebastian Estrella により、GitHub Copilot トークンの処理が改善され、検証とエラー メッセージが改善されました。
  • Vamsi Talupula により、リッチ マークダウン出力でのインライン コード レンダリングが改善されました。
  • Wietse Venema により、設定内の Vertex AI モデル名のプレフィックスを修正しました。
  • Matteo Landi により、リテラル パスを正しく解決するために /read-only コマンドが改良されました。
  • git diff 出力および LLM 履歴ログにおけるエンコードの問題を修正しました。
  • Mathis Beer により、HTML コンテンツを操作するときにオプションの終了タグを受け入れるように検索ブロック正規表現を修正しました。
  • 起動エラーを防ぐために、投稿者ごとにチャット履歴ファイルの親ディレクトリを自動作成します。
  • パッケージをインストールする前に pip が利用可能であることを確認してください。
  • Aider は、このリリースのコードの 21% を作成しました。

aider v0.85.0

Highlights

  • New models and changed aliases — Adds gemini-2.5-pro, gemini-2.5-flash, and gemini-2.5-pro-preview-06-05, plus Responses API support for o1-pro/o3-pro. Thinking tokens can now be disabled with 0, DeepSeek’s max-token setting rises to 65536, and o3 pricing is updated. Behavioral change / migration: flash now resolves to gemini-2.5-flash and gemini to gemini-2.5-pro; pin an exact model ID with --model if alias changes could alter your model choice or costs.
  • Editing scope and commit defaults — --add-gitignore-files lets Aider edit ignored files, which is useful for generated code but requires care to avoid exposing secrets. Commit messages now include Co-authored-by attribution by default, support --commit-language, and use system-prompt prefixes. Migration: review commit templates, hooks, and attribution requirements if generated trailers must match a specific format.
  • Performance and operational controls — Enabling --skip-sanity-check-repo now skips expensive file tracking, and chat-history summarization is faster. New --analytics-posthog-host and --analytics-posthog-project-api-key flags allow custom PostHog routing. The performance gain comes with reduced repository sanity checking, so enable it only when that tradeoff is acceptable.
  • Repository maps and reliability — Repository maps now support MATLAB and Clojure and recognize kebab-case identifiers better, improving context for those codebases. Fixes cover Copilot token validation, Vertex AI model prefixes, literal paths in /read-only, git-diff/history encoding, and chat-history directory creation—reducing provider, path, and startup failures.
  • Upgrade recommendation — Worth upgrading if you use the new Gemini/Responses API models, work in MATLAB or Clojure, hit Copilot/Vertex AI issues, or need commit-language control. Others can skip if their pinned models work reliably and they do not need the editing-scope, performance, or repository-map improvements—but review the alias and commit-attribution changes before upgrading.

New Models

  • Added support for new Gemini models including gemini-2.5-pro, gemini-2.5-flash, and gemini-2.5-pro-preview-06-05 with thinking tokens support.
  • Updated model aliases: flash now points to gemini-2.5-flash and gemini now points to gemini-2.5-pro.
  • Support for Responses API models like o1-pro, o3-pro.
  • Added support for OpenAI o3-pro model across multiple providers.
  • Enhanced thinking tokens support: can now be disabled by setting to 0, and improved help text with examples.
  • Increased max tokens for Deepseek models to 65536 for better performance.
  • Updated pricing for o3.

New Features & Enhancements

  • Added --add-gitignore-files flag to enable adding files listed in .gitignore to Aider's editing scope, by omarcinkonis.
  • Co-authored-by attribution is now enabled by default for commit messages.
  • Enhanced commit message generation to use system prompt prefixes, by Luke Reeves.
  • Added --commit-language option to specify the language for commit messages, by Kyosuke Takayama.
  • Skip expensive file tracking operations when --skip-sanity-check-repo is enabled for better performance, by Makar Ivashko.
  • Optimized chat history summarization performance, by jayeshthk.
  • Added custom PostHog analytics configuration options with --analytics-posthog-host and --analytics-posthog-project-api-key flags, by Vasil Markoukin.

Repository Map

  • Added MATLAB language support for repository maps, by Matthew Tofano.
  • Added Clojure language support for repository maps, by Garrett Hopper.
  • Improved kebab-case identifier recognition in repository maps for better code analysis.

Fixes & Small Improvements

  • Improved GitHub Copilot token handling with better validation and error messages, by Vincent Taverna and Sebastian Estrella.

  • Improved inline code rendering in Rich markdown output, by Vamsi Talupula.

  • Fixed Vertex AI model name prefixes in settings, by Wietse Venema.

  • Improved /read-only command to resolve literal paths correctly, by Matteo Landi.

  • Fixed encoding issues in git diff output and LLM history logging.

  • Fixed search block regex to accept optional closing tags when working with HTML content, by Mathis Beer.

  • Auto-create parent directories for chat history files to prevent startup errors, by contributor.

  • Ensure pip is available before package installation.

  • Aider wrote 21% of the code in this release.
