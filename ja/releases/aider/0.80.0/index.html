#補助者v0.80.0

  • OpenRouter OAuth 統合:
    • モデルとキーが提供されていない場合は、OpenRouter に対して OAuth をオファーします。
    • OPENROUTER_API_KEY が設定され、モデルが指定されていない場合は、無料/有料枠のステータスに基づいて OpenRouter のデフォルト モデルを選択します。 ・ 機種指定がない場合は、GEMINI_API_KEY が設定されている場合は gemini/gemini-2.5-pro-exp-03-25 が優先され、VERTEXAI_PROJECT が設定されている場合は vertex_ai/gemini-2.5-pro-exp-03-25 が優先されます。
  • 起動時にユーザーが構成した色設定を検証し、無効な色設定を警告/無効にします。
  • --stream と --cache-prompts を一緒に使用すると、コストの見積もりが不正確になる可能性があるため、起動時に警告します。
  • パス コンポーネントがチャットで言及された識別子と一致するファイルのリポマップ ランキングを高めます。
  • Web scraping タイムアウトをエラーから警告に変更し、scraping が不完全な可能性のあるコンテンツを続行できるようにします。
  • ターミナル出力のマークダウン見出しを左揃えにします (Peter Schilling 著)。
  • ユーザーが古いモデルのデフォルト形式を使用していた場合、/model でモデルを切り替えるときに、編集形式を新しいモデルのデフォルトに更新します。
  • openrouter/deepseek-chat-v3-0324:freeモデルを追加します。
  • Matteo Landi による、外部エディタで現在の入力バッファを編集するための Ctrl-X Ctrl-E キーバインドを追加しました。
  • Mir Adnan ALI による、シェルのメタキャラクターを含むファイルパスのリンティング エラーを修正しました。
  • Vasil Markoukin による Scala 言語の repomap サポートを追加しました。
  • 自動テストを妨げていた /run のバグを修正しました。
  • git ツリーのトラバーサル中に UnboundLocalError を妨げるバグを修正しました。
  • git がインストールされていない場合、または PATH にない場合に GitCommandNotFound エラーを処理します。
  • aider の実行中に現在の作業ディレクトリが削除された場合、FileNotFoundError を処理します。
  • Andrey Ivanov による完了メニューの現在の項目の色のスタイルを修正しました。
  • Aider はこのリリースのコードの 87% を書きました。 完全な変更ログ: https://aider.chat/HISTORY.html

aider v0.80.0

Highlights

  • OpenRouter onboarding — Aider now offers OAuth when no model or API keys are configured. With OPENROUTER_API_KEY set but no model selected, it chooses a default based on your free or paid tier, so implicit model selection can differ by account.

  • Gemini defaults — Without an explicit model, GEMINI_API_KEY prioritizes gemini/gemini-2.5-pro-exp-03-25, while VERTEXAI_PROJECT prioritizes vertex_ai/gemini-2.5-pro-exp-03-25. Pin --model when provider routing matters.

  • More relevant repository context — Repomap ranking now boosts files whose path components match identifiers mentioned in the chat, improving context selection for monorepos. Scala repositories also gain repomap support.

  • Model and prompt workflow improvements — /model switches to the new model’s default edit format only if you were using the previous default, preserving custom formats. Ctrl-X Ctrl-E opens the current input buffer in an external editor for complex prompts.

  • Clearer warnings and partial-output handling — Invalid terminal colors are disabled with a warning, and combining --stream with --cache-prompts triggers a cost-estimate warning. Web-scrape timeouts now warn and continue with potentially incomplete content, so review scraped results before relying on them.

  • Reliability fixes — /run auto-testing works again; filepath linting handles shell metacharacters; and aider now handles missing Git, deleted working directories, and a UnboundLocalError during Git tree traversal more gracefully.

  • Compatibility — No breaking changes in this release.

  • OpenRouter OAuth integration:

    • Offer to OAuth against OpenRouter if no model and keys are provided.
    • Select OpenRouter default model based on free/paid tier status if OPENROUTER_API_KEY is set and no model is specified.

  • Prioritize gemini/gemini-2.5-pro-exp-03-25 if GEMINI_API_KEY is set, and vertex_ai/gemini-2.5-pro-exp-03-25 if VERTEXAI_PROJECT is set, when no model is specified.

  • Validate user-configured color settings on startup and warn/disable invalid ones.

  • Warn at startup if --stream and --cache-prompts are used together, as cost estimates may be inaccurate.

  • Boost repomap ranking for files whose path components match identifiers mentioned in the chat.

  • Change web scraping timeout from an error to a warning, allowing scraping to continue with potentially incomplete content.

  • Left-align markdown headings in the terminal output, by Peter Schilling.

  • Update edit format to the new model's default when switching models with /model, if the user was using the old model's default format.

  • Add the openrouter/deepseek-chat-v3-0324:free model.

  • Add Ctrl-X Ctrl-E keybinding to edit the current input buffer in an external editor, by Matteo Landi.

  • Fix linting errors for filepaths containing shell metacharacters, by Mir Adnan ALI.

  • Add repomap support for the Scala language, by Vasil Markoukin.

  • Fixed bug in /run that was preventing auto-testing.

  • Fix bug preventing UnboundLocalError during git tree traversal.

  • Handle GitCommandNotFound error if git is not installed or not in PATH.

  • Handle FileNotFoundError if the current working directory is deleted while aider is running.

  • Fix completion menu current item color styling, by Andrey Ivanov.

  • Aider wrote 87% of the code in this release.

Full change log: https://aider.chat/HISTORY.html
