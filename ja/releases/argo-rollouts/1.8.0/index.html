argo-rollouts v1.8.0

Highlights

  • Analysis & metric providers — Adds Prometheus range-query support (PR #3704) and returns the resolved query as metadata in the New Relic provider (PR #3715), plus fixes to Datadog aggregator defaults (PR #3643, PR #3730) and RollbackWindow handling when reconciling AnalysisRuns (PR #3670); if your rollouts gate on analysis metrics, this is the main reason to upgrade.
  • Traffic management & routers — Corrects ALB weight verification at rollout end (PR #3627), scopes pingpong to ALB only when stable/canary services are defined (PR #3628), fixes a missing protocol in Ambassador canary mappings (PR #3603) and the Traefik resourceName (PR #3759), and lets nginx canary ingresses carry full annotations (PR #3671); upgrade if you rely on any of these traffic routers.
  • RBAC change for scaleDown (action required) — PR #3675 adds the update verb to ClusterRole permissions for the scaleDown feature (fixes #3672); if you installed with custom/Helm-managed RBAC you must reapply the updated ClusterRole or scaleDown will fail — this is the only item that needs an explicit migration step.
  • Platform, dashboard & build — The controller build now targets Go 1.22 (PR #3516), the dashboard moves to a newer react-scripts (PR #3584) with loader-utils pinned to 2.0.4 (PR #3601), and pod-status logic gains native-sidecar support (PR #3639, fixes #3366); relevant mainly if you build from source or run sidecar-injected pods.
