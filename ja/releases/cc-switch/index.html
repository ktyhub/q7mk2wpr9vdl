cc-switch

20 バージョンのインデックス付け · 2026年11月23日 上の最新の v4.0.40

farion1231/cc-switch ↗

202620

11/23
v4.0.40 パッチ MT

このバージョンでは、Grok Build の公式カードを認証センターの xAI アカウントにバインドでき、Claude や Codex 公式カードなどの複数の Grok アカウント間で切り替えることができます。プラグイン ページは Antigravity CLI をサポートしています。キャッシュ ヒット率は、使用統計のサプライヤーとモデルのリストに追加されます。 Xiaomi MiMo には残高とトークン プランのクォータ クエリが組み込まれています。認証センターのアカウント カードは、サイドバー アプリケーションの順序と非表示設定に従います。

 11/22
v4.0.39 パッチ MT

このバージョンは主に修理用です。 API キー入力ボックスにコピー ボタンが追加されます。バックアップには合計サイズ制限を設定でき、制限を超えると古いものから削除されます。 Claude Code が Codex OAuth 経由で GPT-6.2 Sol / Astra を使用すると、システムによって要求されるキャッシュ ヒット率が大幅に向上します。

 11/21
v4.0.38 パッチ MT

このバージョンは主に修理用です。ワンクリックのインポート リンクを WorkBuddy プロバイダーにインポートできるようになりました。 Antigravity アカウントは、Linux の認証センターでも切り替えることができます。 Antigravity のセッション リストには空のセッションや内部サブセッションが混在しなくなり、セッションのリーダーは思考、ツールの呼び出し、結果を確認できるようになりました。

 11/20
v4.0.37 パッチ MT

このバージョンは主に修理用です。読み取り不可能なベンダーおよび MCP エントリ (更新されたバージョンによって書き込まれ、WebDAV/S3 経由で同期されたエントリなど) は空の構成として扱われなくなり、次回保存するときにデフォルト値で上書きされます。代わりに、それらは個別にリストされ、削除できます。 Pi に Mistral AI プリセットが追加されました。韓国語インターフェースの翻訳が全体的に改善されました。

 11/19
v4.0.36 パッチ MT

このバージョンには新しいプラグイン ページがあります。 CC Switch では、Claude Code、Codex、Grok Build、M​​iniMax Code、OpenClaw、Pi のプラグインをインストール、有効化、更新、およびアンインストールしたり、Claude Code、Codex、および Grok Build のプラグイン マーケットを管理したりできます。スキル リポジトリは、アクセス トークンを使用してプライベート リポジトリを読み取ることができるようになりました。地元のサプライヤーは料金乗数を設定できます。および Claude Code デスクトップの章はセッション管理に表示されます。

 11/18
v4.0.35 パッチ MT

このバージョンでは、Claude Code / Claude Desktop で ChatGPT アカウントを使用する Codex カードが GPT-6.2 を使用できるようになります。 Codex /goal の完全な目標はセッション管理で確認でき、リクエスト詳細のリクエスト ID はワンクリックでコピーできます。

 11/17
v4.0.34 パッチ MT

このバージョンのスキル ウェアハウスは、GitLab、Gitea、Forgejo (自己構築インスタンスと Codeberg を含む) をサポートしており、GitHub にのみウェアハウスを追加することはできなくなりました。セッション管理で Antigravity CLI セッションを直接削除できるようになりました。自動ダウンロード更新をオンにすると、新しいバージョンのダウンロードがすぐに開始されます。さらに、WorkBuddy で手動で追加したモデルは思考の強度を設定でき、S3 同期により WebDAV などのローカルに保存された設定をクリアすることもできます。

 11/16
v4.0.33 パッチ MT

このバージョンでは、サードパーティのプロバイダーから Claude official に切り替えた後、すでに開いている Claude Code セッションが依然として前のプロバイダーにリクエストを送信し、回復するにはセッションを再起動する必要があるという問題が修正されています。 Ollama Cloud がパッケージ クォータ クエリに追加されました。認証センターでの Antigravity アカウントの切り替えは Windows もサポートするようになりました。

 11/14
v4.0.32 パッチ MT

このバージョンでは、バックグラウンドでのアップデートの自動ダウンロードが追加されています。「設定→バージョン情報」で「アップデートの自動ダウンロード」をオンにすると、新しいバージョンがバックグラウンドでダウンロードされ、検証されます。右下隅に、インストールするかどうかを尋ねるプロンプトが表示されます。確認しないと再起動されません。 「設定→ネットワーク」にIP検出が追加され、グローバルプロキシ、一時プロキシ、現在のネットワーク経由でCC Switchにアクセスした際の出口IPとリージョンを確認できるようになりました。

 11/12
v4.0.31 パッチ MT

このバージョンでは、新しいマネージド アプリケーション Tencent WorkBuddy が追加されています。カスタム モデルは WorkBuddy 独自のモデル構成に書き込まれ、WorkBuddy で直接選択できます。複数の WorkBuddy アカウントを切り替えることもでき、切り替える前に各アカウントのパッケージ、残りポイント、有効期限を確認できます。ドイツ語がインターフェイスに追加され、README は 8 つのインターフェイス言語すべてで利用できます。

 11/12
v4.0.30 パッチ MT

本版本新增隐私过滤器：在路由和聚合模式下，本地路由转发请求前可以把用户输入和系统提示里的个人信息和密钥替换成占位符，不让它们发到上游。默认关闭，开关在「设置 → 数据」。

 11/10
v4.0.29 パッチ MT

このバージョンでは、新しいマネージド アプリケーション GitHub Copilot CLI: 独自のキーを持つサプライヤーは、Copilot 独自のプロバイダー json に書き込まれます。コパイロットで /model を使用すると、CC スイッチを経由せずに公式モデルと一緒に選択できます。韓国語とロシア語がインターフェースに追加されました。 7か国語が同時に整備され、欠落箇所に英語が表示されなくなりました。

 11/08
v4.0.28 パッチ MT

このバージョンでは主に、11 月 8 日に行われた Codex の非互換アップデートに対応しています。

 11/07
v4.0.27 パッチ MT

このバージョンでは、セッション管理によるメッセージ本文の検索、インターフェイス密度とインターフェイス スケーリング設定の追加、モデル価格表の検索が可能になり、Grok Build で使用されているサプライヤーもターミナルを開くことができます。スキルのインストール済みページが再デザインされ、サプライヤーのアイコンがダークとライトのテーマに従います。また、設定ファイルが通常のファイルに置き換えられたり、ソフトリンクの場合に書き込みに失敗したりしました。リクエストをキャンセルした後、サプライヤーは再起動するまでサーキット ブレーカーの回復で停止しました。 Codex がカスタム権限を設定した後、プラン モードでエラーが報告されました。実行スキルがアップデートがあると誤って報告されました。スキルウェアハウスには 0 と表示されました...

 11/05
v4.0.26 パッチ MT

このバージョンでは、認証センターと公式サプライヤー カードに各アカウントのサブスクリプション プランを表示できるようになります。 GitHub Copilot アカウントには、上限のあるすべてのクォータがリストされます。ワンクリックのインポート リンクで、Claude Desktop、MiniMax Code、Kimi Code、DeepSeek Harness、Oh My Pi のサプライヤーもインポートできるようになりました。

 11/02
v4.0.25 パッチ MT

このバージョンでは、MCP ページに接続チェックが追加され、すべての有効な MCP サーバーが接続できるかどうかをワンクリックでチェックできます。 Codex がローカル ルーティングを通じて公式アカウントを使用する場合、クォータがほぼ使い果たされる前に公式リクエストは自動的に一時停止され、サードパーティ モデルは引き続き利用可能になります。さらに、使用状況ページの為替レートを自動的に取得でき、Codex サプライヤー フォームでサブエージェントの同時実行制限を設定できます。 Claude Code と Claude Desktop がルーティングまたは集約されると、モデル メニューには、各モデルがどのサプライヤーから提供されたものであるか、および実際にどのモデルであるかが示されます。 kimi Code セッションはセッション管理で削除することもできます。

 11/01
v4.0.24 パッチ EN

このバージョンでは、認証センターに「ログイン時にブラウザを自動的に開く」スイッチが追加されます。オフにした後は、ログイン リンクをコピーするだけでアカウントにログインでき、選択したブラウザで開くことができます。アカウントごとに独立したブラウザ環境を使用するユーザーに適しています。さらに、Claude Code および Claude Desktop 経由で GPT 6.1 Sol/Terra を使用する場合、最大思考レベルが xhigh に低下する問題、DeepSeek Harness により PDF 入力をサポートするモデルを選択した後にすべてのサードパーティ サプライヤーが表示されなくなる問題、起動後に WSL の CC スイッチが終了する問題、Codex... が修正されました。

 10/31
v4.0.23 パッチ MT

このバージョンでは、Kimi Code、MiniMax Code、および Oh My Pi のサプライヤー エディターで、構成ファイルの一部をアプリケーション独自の形式で表示できるようになります。 Claude Code と Claude Desktop がルーティング経由で OpenAI フォーマットと Gemini の上流に接続されている場合、クライアントが選択した思考装置をより多くのモデルに送信でき、カード上で送信する方法も選択できます。認証センターはワンクリックですべてのアカウントの割り当てを更新できます。 Antigravity、MiniMax コード 使用記録には、消費時間と最初の単語時間が含まれます。

 10/30
v4.0.22 パッチ MT

このバージョンでは、CC Switch によって管理される 14 番目のアプリケーションである DeepSeek Harness のサポートが追加されています。サプライヤーは Web とデスクトップの構成を一緒に記述し、MCP、スキル、およびプロンプト ワードがそれに同期され、セッションを参照でき、「アプリケーション」ページのインストール、アップグレード、およびアンインストールが可能です。認証センターで DeepSeek アカウントにログインし、残高や使用状況の統計を確認することもできます。 Oh My Pi の使用量もカウントされるようになりました。

 10/26
v4.0.21 パッチ MT

このバージョンでは、Claude Code の複数の公式サブスクリプション アカウント間の切り替えが追加されています。認証センターに複数の Claude アカウントを追加し、公式カードごとに 1 つを選択すると、どのカードに切り替えても、Claude Code はその番号を使用します。同時に複数の番号を使用したい場合は、カードから「端末を開く」と、その端末は常にカード上の番号を使用します。ログインして、公式のクロード コード プロセスに従ってください。トークンはローカル マシンのクロード コードにのみ残ります。 CC Switch はアップロード、更新、またはログアウトしません。アカウントと認証センターにバインドされたカードには、各アカウントのパッケージと残高が表示されます。
