feign 13.13

#13.13を装う

何が変わったのか

  • https://github.com/OpenFeign/feign/pull/3346 の @velo により、feign-validation モジュールと feign-http-cache モジュールを備えた MethodInterceptor 拡張ポイントを追加
  • https://github.com/OpenFeign/feign/pull/3172 で @loadkrnis によってロギングが無効になっている場合にバッファリングされていない応答を返す Slf4jLogger と JavaLogger を修正
  • カスタム タグのサポートを Metrics5Capability に追加 ユーザーが a… を渡すことができるようにします by @cexes in https://github.com/OpenFeign/feign/pull/3320
  • https://github.com/OpenFeign/feign/pull/3370 の @seonwooj0810 によってマイクロメーター モジュールによって公開されたドキュメント メトリクス
  • https://github.com/OpenFeign/feign/pull/3371 の @seonwooj0810 によって、CoroutineFeign ビルダーから AsyncFeign に dismiss404 を転送します
  • https://github.com/OpenFeign/feign/pull/3359 の @young0264 による UNWRAP で宣言されたチェックされた原因のみをアンラップします
  • feign-bom を実際のモジュールとして公開し、https://github.com/OpenFeign/feign/pull/3384 の @velo によって Central に自動デプロイされるようにする
  • https://github.com/OpenFeign/feign/pull/3385 の @velo による h2c 事前知識を使用して不安定な vertx http2NoConnectionLeak テストを修正
  • 修正: Content-Length の密輸、ログ形式文字列の挿入、https://github.com/OpenFeign/feign/pull/3395 の @velo による共通プールの枯渇を防止
  • [問題 #2998] https://github.com/OpenFeign/feign/pull/3393 の @Dainerx による RequestTemplate での uriTemplate の公開
  • https://github.com/OpenFeign/feign/pull/3407 の @seonwooj0810 による観測スコープを開き、FeignException 以外のエラーで停止する
  • https://github.com/OpenFeign/feign/pull/3394 の @seonwooj0810 による静的デフォルトの非同期エグゼキュータ (#3178) からの ClassLoader リークを回避
  • https://github.com/OpenFeign/feign/pull/3406 の @seonwooj0810 による削除された Request.create オーバーロードによって壊れていたフェインコア テストのコンパイルを修正
  • 元に戻す: Request.Body ストリーミングのマスターからの変更を破壊する移動。それらは https://github.com/OpenFeign/feign/pull/3409 の @velo による 14.x に属します。
  • https://github.com/OpenFeign/feign/pull/3405 の @alhudz による長いオーバーフローに対する数値再試行後のガード
  • [問題 1487] https://github.com/OpenFeign/feign/pull/3338 の @gitshabh による Apache HttpClient チェック例外に対して ErrorDecoder が呼び出されない問題を修正
