Roo-Code v3.36.3

Highlights

  • Reasoning and model coverage expand — Gemini gains minimal/medium effort, gpt-5.1-codex-max gains xhigh, and explicit supportsReasoningEffort lists are now honored (#9973, #9900, #9970). DeepSeek moves to V3.2 with updated pricing, Baseten adds V3-2 support, and Bedrock adds Kimi, MiniMax, and Qwen configurations (#9962, #9861, #9905), reducing manual setup and unsupported reasoning controls.
  • Roo provider settings are version-gated — Versioned settings now support minPluginVersion checks (#9934). When sharing or migrating settings, verify that installed plugins satisfy the required minimum versions.
  • OpenRouter now prefers native tools — Native tools become the default when supported (#9878), apply_diff is excluded when diffEnabled is false (#9920), and invalid tool_result IDs are repaired before requests (#9952). Custom provider integrations should retest tool discovery and call handling because supported models now follow a different execution path.
  • Token accounting uses less overhead — Separate count_tokens requests are discontinued (#9884), while tool statistics are streamed and token-usage updates throttled (#9926). Expect fewer API calls and steadier progress reporting, but update instrumentation that depended on explicit token-count requests.
  • Architect plans move to /plans — Plans are now saved in a gitignored /plans directory (#9944). Point automation at that location and add an explicit .gitignore exception if plans need to be committed.
  • Breaking changes — None are declared in this release.
