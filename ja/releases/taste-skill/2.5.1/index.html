taste-skill v2.5.1

パッチ 公開日2026年11月7日 出典Leonxlnx/taste-skill English original

#味覚スキルv2.5.1 2.5.0 の 44 サイトのテストで示された内容が修正されました。チェッカーがクリーンになるまでビルドが繰り返され、すべてのページが移動し、写真のない製品は写真に表示され、パレットは業界に適合し、コピーは独自の音声を取得し、電話機上の他のものには何も嘘をつきません。インストール名は変更されませんでした。

  • 終了ゲート: scripts/gate.mjs はチェッカー、レイアウト チェック、およびコピー lint を実行し、最後の行が GATE: PASS になるまでビルドは実行されません (3 ラウンド、最大 5 回の理由付き免除)。クロード コードでは、スキル自体からの Stop フックとして実行されます。エージェントを罠にはめることはありません。ユーザーへの質問にはコストはかかりません。gate.mjs --done はユーザーの言葉でビルドを終了します。
  • すべてのページにモーション: すべてのヒーローがロード時に 1 回表示され、すべてのページに 1 つまたは 2 つのスクロール モーメントが含まれます。カフェ、ショップ、サービスには、写真と入力によるもの (新しい photo-chapters、picture-develops の映画の外観) が導入されます。シェーダーエフェクトは技術ページに残ります。
  • レンダリングよりも写真: client の写真のない製品は、ライセンスを取得した代用写真に表示されます (photos.mjs search: Wikimedia Commons、CC0、CC BY、CC BY-SA およびパブリック ドメインのみ)。 3D レンダリングは、概要で要求された場合にのみ行われます。
  • 取引別のパレット: start.mjs deal --trade cafe はその取引用に作られたパレットを販売しているため、2 つのカフェが同じように始まることはなくなりました。 8 つの新しい配置パレット。
  • コピー レイヤー: ファクト シート、ボイス カード、1 つのレジスタとページの各部分の動き、およびモデルで書かれたコピーのテルをカウントする copy-lint.mjs。ゲートがそれを実行します。
  • アクセシビリティ、フォーム、およびメタデータ: アクセシブルな名前、ラベル、フォーカス リング、見出しの順序、共有タグ、および実際のフォーム送信がチェックされます。
  • 電話: セクションは、次のセクションに重なるのではなく、コンテンツとともに成長します。44 ピクセルのタップ ターゲット、ヒーローのボタンがスクロールして消えるまで待機する電話アクション バー、および新しい collide、tap-size、および 320px チェック。
  • 独自のチェックに合格するキット: 11 個のヒーロー レイアウトすべて、スターターおよび 2 つのページ内モーメント モデルが、1440 および 390 (tests/kit-clean.mjs) でチェッカーとレイアウト チェックに合格します。 インストールしたときと同じコマンドを使用して更新します。たとえば、次のようになります。
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

または、Claude Code プラグインとして、/plugin marketplace update taste-skill、次に /plugin install taste-skill@taste-skill。 完全なリストは CHANGELOG.md にあります。 2.5.x にプル リクエストを送信した、そこに名前が挙げられているコミュニティの貢献者に感謝します。

taste-skill v2.5.1

What a 44-site test of 2.5.0 showed, fixed: builds now iterate until the checker is clean, every page moves, products without photographs are shown in photographs, palettes fit the trade, the copy gets a voice of its own, and nothing lies on anything else on a phone. The install name did not change.

  • A finish gate: scripts/gate.mjs runs the checker, the layout check and a copy lint, and a build is not done until its last line reads GATE: PASS (three rounds, five waivers with reasons at most). In Claude Code it runs as a Stop hook from the skill itself. It never traps an agent: a question to the user costs no round, and gate.mjs --done ends a build at the user's word.
  • Motion on every page: every hero enters once on load, and every page carries one or two scroll moments. Cafes, shops and services get photo- and type-led ones (new photo-chapters, a film look for picture-develops); shader effects stay on tech pages.
  • Photographs over renders: a product without the client's pictures is shown in licensed stand-in photographs (photos.mjs search: Wikimedia Commons, CC0, CC BY, CC BY-SA and public domain only). A 3D render only when the brief asks for one.
  • Palettes by trade: start.mjs deal --trade cafe deals palettes made for that trade, so two cafes no longer start alike. Eight new place palettes.
  • A copy layer: a fact sheet, a voice card, one register and the moves for each part of the page, plus copy-lint.mjs, which counts the tells of model-written copy. The gate runs it.
  • Accessibility, forms and metadata: accessible names, labels, the focus ring, heading order, share tags and real form sends are checked.
  • Phones: sections grow with their content instead of lying over the next one, 44px tap targets, a phone action bar that waits until the hero's button has scrolled away, and new collide, tap-size and 320px checks.
  • A kit that passes its own checks: all 11 hero layouts, the starter and two in-page moment models pass the checker and the layout check at 1440 and 390 (tests/kit-clean.mjs).

Update with the same command you installed with, for example:

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

or, as a Claude Code plugin, /plugin marketplace update taste-skill and then /plugin install taste-skill@taste-skill.

Full list in CHANGELOG.md. Thanks to the community contributors named there, whose pull requests went into 2.5.x.
