pyvespa v0.63.0

マイナー 公開日2026年1月12日 出典vespa-engine/pyvespa English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ピベスパv0.63.0

何が変わったのか

  • https://github.com/vespa-engine/pyvespa/pull/1138 の @Copilot によるテスト メソッドからの戻り値に関する DeprecationWarning を排除するために TestQueryBuilderGrouping をリファクタリングします
  • https://github.com/vespa-engine/pyvespa/pull/1136 で @thomasht86 による接続を再利用しやすくします
  • https://github.com/vespa-engine/pyvespa/pull/1140 の @Copilot により、TestDeployPerf の max_wait パラメータを 600 秒から 1200 秒に増やします
  • https://github.com/vespa-engine/pyvespa/pull/1132 の @sebastiannberg による python 3.11 でノートブック テストを実行します。
  • (ドキュメント) https://github.com/vespa-engine/pyvespa/pull/1141 の @thomasht86 による出力から警告を削除
  • https://github.com/vespa-engine/pyvespa/pull/1142 の @Copilot による非推奨の httpx cert パラメータの使用法を修正
  • 依存関係の setuptools を v78 [SECURITY] に更新 (https://github.com/vespa-engine/pyvespa/pull/1124 の @renovate[bot] により)
  • 警告を削除 - deploy_to_prod by @thomasht86 in https://github.com/vespa-engine/pyvespa/pull/1143
  • https://github.com/vespa-engine/pyvespa/pull/1147 の @Copilot によるノートブックとドキュメントの依存関係の ipykernel==6.30.1 の固定
  • 1148 は、https://github.com/vespa-engine/pyvespa/pull/1149 の @thomasht86 により python 312 以降に開発依存関係をインストールできません
  • https://github.com/vespa-engine/pyvespa/pull/1154 の @PeriLara によって概要に追加された要素を選択します
  • https://github.com/vespa-engine/pyvespa/pull/1155 の @thomasht86 による統合テストでのデプロイのタイムアウトを増加
  • 最近隣最適化のためのクラスを追加 (https://github.com/vespa-engine/pyvespa/pull/1160 の @boeker による)
  • https://github.com/vespa-engine/pyvespa/pull/1162 の @thomasht86 によるドキュメント デプロイ用に 3.11 にピン留めします
  • https://github.com/vespa-engine/pyvespa/pull/1163 の @boeker により、ANN ツールの最大同時クエリ数を指定できるようになりました
  • https://github.com/vespa-engine/pyvespa/pull/1161 の @Copilot による数値を引用符で囲まないよう、rank_properties を修正しました。
  • https://github.com/vespa-engine/pyvespa/pull/1167 で @thomasht86 によるパーセンタイル計算を修正
  • https://github.com/vespa-engine/pyvespa/pull/1168 の @thomasht86 によって出力されたよりわかりやすい結果
  • https://github.com/vespa-engine/pyvespa/pull/1164 の @boeker による VespaAsync の証明書 CA ファイルを使用する
  • https://github.com/vespa-engine/pyvespa/pull/1169 の @boeker によるパラメーター オプティマイザーからのレポートにすべてのリコール測定値を含めます
  • https://github.com/vespa-engine/pyvespa/pull/1166 に @thomasht86 による ANN チューニング ノートブックを追加
  • ci: https://github.com/vespa-engine/pyvespa/pull/1165 の @esolitos による Mend スキャン GitHub ワークフローの簡素化と強化
  • https://github.com/vespa-engine/pyvespa/pull/1171 の @andreer によるデフォルトでの無制限のメモリ使用量
  • https://github.com/vespa-engine/pyvespa/pull/1172 内の @kkraune によるタイプミス
  • Thomasht86/https://github.com/vespa-engine/pyvespa/pull/1174 の @thomasht86 によるクエリへのプロファイル オプションの追加
  • パフォーマンス テスト、トークンと mlts のパフォーマンス (@sebastiannberg による https://github.com/vespa-engine/pyvespa/pull/1175)
  • https://github.com/vespa-engine/pyvespa/pull/1176 の @thomasht86 により httpx 読み取りタイムアウトを増加
  • https://github.com/vespa-engine/pyvespa/pull/1178 の @thomasht86 により非推奨の macos-13 を削除 *crossref を削除し、https://github.com/vespa-engine/pyvespa/pull/1179 の @thomasht86 に置き換えます
  • Thomasht86/https://github.com/vespa-engine/pyvespa/pull/1180 の @thomasht86 によるリンクを再度修正
  • https://github.com/vespa-engine/pyvespa/pull/1181 の @Shivamjohri247 による非同期リクエストの適応スロットリングを追加
  • SHADOW: PR #1181 のセキュリティ スキャン - https://github.com/vespa-engine/pyvespa/pull/1182 の @thomasht86 による非同期リクエストの適応スロットリングを追加
  • Thomasht86/https://github.com/vespa-engine/pyvespa/pull/1177 の @thomasht86 によるモデル構成の追加
  • 修正: https://github.com/vespa-engine/pyvespa/pull/1186 の @esolitos による修復ワークフローの条件の更新
  • https://github.com/vespa-engine/pyvespa/pull/1187 の @kkraune によりナビゲーションにアイテムが表示されるようにします
  • https://github.com/vespa-engine/pyvespa/pull/1188 の @kkraune によるログインを必要とするページを無視します
  • https://github.com/vespa-engine/pyvespa/pull/1189 の @kkraune によるリファレンス ナビゲーションを更新
  • https://github.com/vespa-engine/pyvespa/pull/1191 に @thomasht86 による CLAUDE.md を追加
  • https://github.com/vespa-engine/pyvespa/pull/1192 の @boeker により、ANN パラメータの最適化が高速化されました。
  • ANN パラメータ調整に関する情報を含む短いページを、https://github.com/vespa-engine/pyvespa/pull/1193 の @boeker によってフロント ページに追加

pyvespa v0.63.0

What's Changed

  • Refactor TestQueryBuilderGrouping to eliminate DeprecationWarning about returning values from test methods by @Copilot in https://github.com/vespa-engine/pyvespa/pull/1138
  • Make it easier to reuse connections by @thomasht86 in https://github.com/vespa-engine/pyvespa/pull/1136
  • Increase max_wait parameter from 600 to 1200 seconds in TestDeployPerf by @Copilot in https://github.com/vespa-engine/pyvespa/pull/1140
