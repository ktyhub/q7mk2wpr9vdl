#ナマケモノv0.1.908-beta

NVIDIA の新しい Nemotron 3.5 モデルと Meta の新しい Muse Spark Open を Unsloth でローカルに実行します。新機能: テキスト拡散 LLM、DeepSpeed トレーニング、コーディング エージェント向けのプロンプト キャッシュの改善。

ハイライト

  • NVIDIA Nemotron 3.5 Bolt: 24 GB のメモリで実行。 ガイド
  • NVIDIA Nemotron 3.5 Super VL: 120B (12B アクティブ) ガイド
  • Meta Muse Spark オープン: 816B (アクティブ 42.7B) - 256GB で実行 ガイド
  • コーディング エージェントのプロンプト キャッシュの改善: ローカル GGUF モデル上のクロード コード、コーデックスなどで再処理される各プロンプトの量ははるかに少なくなります。
  • ブラウザの使用: チャットごとに適切な動作、カーソル、および個別のタブを常に許可します。
  • 接続を介した画像: SD サーバー、Ollama、Lemonade、その他の画像サーバーを使用して生成します。
  • 拡散 LLM: ライブノイズ除去キャンバスを使用して、LLaDA、Dream、SDAR などをトレーニングし、チャットします。

ネモトロン 3.5

  • NVIDIA Nemotron 3.5 Super VL を実行します。これは、12B のアクティブ パラメーターと最大 1M のコンテキスト トークンを備えた 120B モデルで、文書の理解、コンピューターの使用、長時間実行されるエージェント向けに構築されています。 Super VL は、1 ビットで約 64 GB、4 ビットで 128 GB のメモリで実行されます。 【ガイド】(https://unsloth.ai/docs/models/nemotron-3.5-super-vl)・【GGUF】(https://huggingface.co/unsloth/NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-GGUF)
  • Super VL から圧縮された、9B アクティブ パラメーターと 128K コンテキストを備えた 74B モデルである NVIDIA Nemotron 3.5 Bolt を実行します。 Bolt は、1 ビットまたは 2 ビットで約 32 GB のメモリで実行されます。 【ガイド】(https://unsloth.ai/docs/models/nemotron-3.5-bolt)・【GGUF】(https://huggingface.co/unsloth/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-GGUF)
  • Nemotron 3.5 Super VL は、同様のインテリジェンスを備えた 100K 入力で Inkling Small よりも約 5 倍高速に生成します。
  • デフォルトでは、Unsloth は、DSpark ドラフター (約 1 ～ 2 GB の追加メモリ) を備えた Nemotron 3.5 Bolt と、出力を高速化するための内蔵 MTP を備えた Super VL を実行します。どちらも設定でオフにすることができます。 MTPガイド

ミューズスパークオープン

  • Meta の Muse Spark Open を実行します。これは、約 427 億のアクティブ パラメータと 100 万のコンテキスト トークンを備えた 816B MoE モデルで、マルチモーダル推論、コーディング、およびエージェント ワークフロー向けに構築されています。 Muse Spark Open は、2 ビットで約 256 GB のメモリで実行されます。 【ガイド】(https://unsloth.ai/docs/models/muse-spark-open)・【GGUF】(https://huggingface.co/unsloth/Muse-Spark-Open-816B-A42B-GGUF)
  • Muse Spark Open はテキスト、画像、ビデオ、オーディオを入力として受け取り、低から高まで推論を行います。
  • Muse Spark Open は、リポジトリ全体の生成、大規模なエンドツーエンド プロジェクト、自動リサーチなど、長期的なコーディング タスクについてトレーニングされました。

トレーニング

  • Unsloth アプリのテキスト拡散 LLM (LLaDA、Dream、SDAR、LLaDA2、Nemotron-Labs-Diffusion、DiffusionGemma など) をトレーニングしてチャットします。チャットの返信には、ノイズ除去されたライブ キャンバスが表示されます。
  • 4 ビット QLoRA、完全な微調整、DPO、CPU オフロードを含む DeepSpeed ZeRO-2 および ZeRO-3 を使用したトレーニング。 DDP および勾配チェックポイントを使用した LoRA トレーニングもクラッシュしなくなりました。
  • fast_inference を使用した GRPO は Nemotron 3 Nano およびブロック FP8 MoE モデルで実行され、vLLM と重みを共有します。
  • [トレーニング] ページで、評価損失の改善が止まったら早めに停止し、事前にトークン化されたデータセットでトレーニングします。 Random Seed は LoRA の開始ウェイトも設定するようになりました。

パフォーマンス

  • Claude Code、Codex、または OpenCode がローカルの GGUF モデルで実行される場合、フォローアップによる再処理が大幅に少なくなり、新しい Claude Code セッションの最初の応答が最大 4 倍早く開始されます。
  • Python では、シングル プロンプト model.generate は、Llama および Qwen3 モデルの 32K コンテキストで最大 2.7 倍高速です。
  • Python では、bitsandbytes 4 ビット モデルで 2 ～ 4 つのプロンプトを一度に生成すると、一部の NVIDIA GPU で最大 2.8 倍高速になります。
  • Nemotron 3 Nano での fast_inference を使用した GRPO ロールアウトは、デフォルトで最大 30% 高速になります。

ブラウザの使用

  • モデル cli が確認して入力するカーソルを表示するか、[設定] > [ブラウザ] > [ブラウザの使用] > [カーソルを表示] でカーソルをオフにします。
  • ブラウザーの使用プロンプトに [常に許可] が追加され、チャットの残りの部分でサイト上でその種のアクションが承認されます。スクリプトは今でも毎回尋ねます。
  • 各チャットは独自のブラウザ タブを保持し、デスクトップでは、画面上に表示されていないチャットでもブラウザの使用が機能し続けます。
  • Web UI では、ブラウザー ページはページ間のサイト設定を記憶し、独自のサイトからデータを読み込み、ビデオを全画面で再生します。

画像 + ビデオ

  • sd サーバー、Ollama、Lemonade、vLLM、llama.cpp またはカスタム OpenAI 互換 URL などの接続された画像サーバーを介して、[画像] ページで画像を生成します。
  • 画像およびビデオ モデルは、使用しないテキスト エンコーダ レイヤをスキップするようになり、ロードするたびにメモリを節約します。

チャット + デスクトップ

  • デスクトップの初回実行画面から、Windows 上で Unsloth をインストールする場所を選択します。
  • 埋め込みモデルを切り替えた後、ドキュメントを再度アップロードせずに再埋め込みます。
  • ファイルとのチャットは丸薬の列に折りたたまれ、その引用は引用ページで PDF を開き、新しく追加された Word および HTML ファイルはリスト番号を保持します。
  • チャット ヘッダー メニューから会話を圧縮し、ファイルが変更されていない場合でも巻き戻しで確認を求めなくなりました。

モデル + 設定

  • Claude Code、OpenCode、または Codex がクラウド モデルで実行される場合、--auto-route を unsloth start に追加して、ファイルの読み取り、コマンドの検索と実行などの日常的なコーディング作業をローカル モデルに送信します。
  • Codex はローカル モデルで MCP およびサブエージェント ツールを使用でき、Claude Code、Codex、および OpenCode は [設定] > [unsloth start --model との接続] からモデル上で実行できます。
  • [設定] > [API] > [モデル エイリアス] でモデルに一度名前を付けると、エイリアスの背後にあるモデルが変更されても、Unsloth API を使用するアプリは動作し続けます。
  • vLLM 接続と Unsloth 独自の vLLM エンジンは、思考努力レベルと思考の保持をサポートし、エンジンは長いチャットを自動圧縮するようになりました。 vLLM および SGLang ロードでは、FP8 KV キャッシュ、GPU メモリ制限、シードを設定することもできます。
  • GGUF クオンツを選択するのと同じ方法で、いくつかの精度を公開している MLX リポジトリから 2 ビット、4 ビット、6 ビット、または 8 ビットを選択します。 Xing4.0 と MiniCPM-V 4.7 は、MLX で実行およびトレーニングできるようになりました。

ハードウェアの互換性

  • CUDA 12 より古い NVIDIA ドライバーを搭載した Windows PC は、失敗する代わりに Vulkan または CPU llama.cpp ビルドをインストールします。
  • RDNA 1 や Polaris など、ROCm がサポートしていない AMD GPU は、ROCm がインストールされている場合や別の AMD GPU がサポートしている場合でも、Vulkan llama.cpp ビルドを取得するようになりました。
  • GGUF イメージの生成は、PyTorch が CPU のみの場合、AMD および Intel Arc GPU の Vulkan で実行されます。
  • PyTorch 2.10 および 2.11 に Windows をインストールすると、事前に構築された flash-attn、causal-conv1d、および mamba-ssm が取得されます。
  • GPU 世代が混在するマルチ GPU マシンが各 GPU のアテンション バックエンドを選択するようになり、conda-forge xformers を備えた Hopper GPU がクラッシュしなくなりました。

unsloth v0.1.908-beta

Run NVIDIA's new Nemotron 3.5 models and Meta's new Muse Spark Open locally in Unsloth. New: text-diffusion LLMs, DeepSpeed training and better prompt caching for coding agents.

Highlights

  • NVIDIA Nemotron 3.5 Bolt: Run on 24 GB of memory. Guide
  • NVIDIA Nemotron 3.5 Super VL: 120B (12B active) Guide
  • Meta Muse Spark Open: 816B (42.7B active) - runs on 256GB Guide
  • Better prompt caching for coding agents: Claude Code, Codex etc. on local GGUF models re-process far less of each prompt.
  • Browser use: Always allow properly works, cursor, and separate tabs for each chat.
  • Images through your connections: generate with sd-server, Ollama, Lemonade and other image servers.
  • Diffusion LLMs: train and chat with LLaDA, Dream, SDAR and more, with a live denoising canvas.

Nemotron 3.5

  • Run NVIDIA Nemotron 3.5 Super VL, a 120B model with 12B active parameters and up to 1M tokens of context, built for document understanding, computer use and long-running agents. Super VL runs in about 64 GB of memory at 1-bit, or 128 GB at 4-bit. Guide · GGUF
  • Run NVIDIA Nemotron 3.5 Bolt, a 74B model with 9B active parameters and 128K context, compressed from Super VL. Bolt runs in about 32 GB of memory at 1-bit or 2-bit. Guide · GGUF
  • Nemotron 3.5 Super VL generates about 5x faster than Inkling Small at 100K input with similar intelligence.
  • By default, Unsloth runs Nemotron 3.5 Bolt with a DSpark drafter (about 1 to 2 GB more memory) and Super VL with its built-in MTP for faster output. Both can be turned off in settings. MTP Guide

Muse Spark Open

  • Run Meta's Muse Spark Open, an 816B MoE model with about 42.7B active parameters and 1M tokens of context, built for multimodal reasoning, coding and agentic workflows. Muse Spark Open runs in about 256 GB of memory at 2-bit. Guide · GGUF
  • Muse Spark Open takes text, images, video and audio as input, with reasoning effort from low to xhigh.
  • Muse Spark Open was trained on long-horizon coding tasks, including whole-repository generation, large end-to-end projects and auto-research.

Training

  • Train and chat with text-diffusion LLMs in the Unsloth app, including LLaDA, Dream, SDAR, LLaDA2, Nemotron-Labs-Diffusion and DiffusionGemma. Chat replies show a live denoising canvas.
  • Train with DeepSpeed ZeRO-2 and ZeRO-3, including 4-bit QLoRA, full fine-tuning, DPO and CPU offload. LoRA training with DDP and gradient checkpointing also no longer crashes.
  • GRPO with fast_inference now runs on Nemotron 3 Nano and block-FP8 MoE models, sharing weights with vLLM.
  • On the Train page, stop early when eval loss stops improving and train on pre-tokenized datasets. Random Seed now also sets the LoRA starting weights.

Performance

  • When Claude Code, Codex or OpenCode runs on a local GGUF model, follow-up turns re-process much less of the conversation, and a new Claude Code session's first reply starts up to 4x sooner.
  • In Python, single-prompt model.generate is up to 2.7x faster at 32K context for Llama and Qwen3 models.
  • In Python, generating 2 to 4 prompts at once with a bitsandbytes 4-bit model is up to 2.8x faster on some NVIDIA GPUs.
  • GRPO rollouts with fast_inference on Nemotron 3 Nano are up to 30% faster by default.

Browser use

  • See a cursor where the model clicks and types, or turn it off in Settings > Browser > Browser use > Show cursor.
  • Browser use prompts now have Always allow, which approves that kind of action on a site for the rest of the chat. Scripts still ask every time.
  • Each chat keeps its own browser tabs, and in Desktop, browser use keeps working in chats that are not on screen.
  • In the web UI, browser pages remember site preferences between pages, load data from their own site, and play videos full screen.

Images + video

  • Generate images on the Images page through a connected image server, such as sd-server, Ollama, Lemonade, vLLM, llama.cpp or a custom OpenAI-compatible URL.
  • Image and video models now skip text-encoder layers they never use, saving memory on every load.

Chat + Desktop

  • Choose where Unsloth installs on Windows from Desktop's first-run screen.
  • Re-embed your documents after switching the embedding model, without uploading them again.
