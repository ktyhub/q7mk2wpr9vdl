openai-agents-python v0.24.0-alpha.7

openai-agents-python v0.24.0-alpha.7

エージェント SDK v0.24.0-alpha.7

ハイライト

  • ネイティブ実行と並行してクラシック ワークフローを使用します。 agents.classic を通じて、保持されている v0 ランタイムをインポートします。このアルファ版では、エグゼキュータの書き込みデフォルトも変更されます。既存の環境を開く前に、アップグレード アクションを確認してください。
  • 会話を自分のストレージに保存します。 CustomStorage を使用して耐久性のあるルート セッションを追加し、作業を再開する前に不確実なツールの影響を調整します。
  • 音声およびホストされたツールをネイティブ エージェントに追加します。 音声ワークフローをセッションに接続するか、互換性のある応答プロバイダーを通じて FileSearch、CodeInterpreter、および ImageGeneration を使用します。
  • コンテキスト、完了、および使用法を制御します。 モデル入力を変換し、圧縮中に選択したコンテキストを保持し、提案された回答を確認し、観察されたルートの使用を制限します。

0.24.0-alpha.6 からのアップグレード

  • 環境書き込みポリシーを確認してください。 新しい環境のデフォルトは write_policy="strict" であり、これには互換性のある Linux または macOS エグゼキューターが必要です。作業ディレクトリは書き込み可能なままです。追加のディレクトリには writable_roots を使用します。 Windows エグゼキューターなど、以前のリモート ポリシーを保持するには、write_policy="legacy" を設定し、writable_roots=None のままにします。ローカルでの実行には厳密モードが必要です。レガシー リモート チェックポイントまたはプロファイルを復元する場合は、明示的にレガシーを選択します。再開してもポリシーはアップグレードされません。 実行者のポリシーと復元ルール を参照してください。
  • 暗黙的推論設定を確認してください。 バンドルされたモデル カタログでは、gpt-6-astra、gpt-6.1-sol、および gpt-5.6-sol のデフォルトの推論努力が low から medium に変更されます。以前の作業が必要な場合は、model_settings={"reasoning_effort": "low"} を明示的に設定します。これはバンドルされたメタデータを記述します。明示的な設定またはプロバイダー モデルのメタデータでは、別の値を選択できます。 (#5517)
  • MCP 承認モードの名前を変更します。 approval_mode="auto" を "native" に、"approve" を "preapproved" に置き換えます。古い値は拒否されます。新しい名前では、それぞれの承認動作が維持されます。
  • 子ステップ コールバックを更新します。 NativeAgents.before_step は、個別の子引数とステップ インデックス引数の代わりに、context、child、および step_index を含む 1 つの ChildStepContext を受け取るようになりました。ルート before_step コールバックは既存の署名を保持します。
  • MCP フォームと URL を別々に処理します。 ElicitationRequest は現在、結合 FormRequest | UrlRequest です。フォームには FormRequest.reply() または respond() を使用します。 URL 同意には UrlRequest.reply_url_accept() または accept_url() を使用します。

追加されました

  • アプリケーション所有の会話ストレージ。 SessionStore、SQLiteSessionStore、および CustomStorage は、ルート履歴と自動 Python ツール結果を保持します。この初期プロファイルには、ネイティブ ツール、環境、子、計画ツール、生成されたコードの実行、手動ツール、およびポータブル チェックポイントは含まれません。 SQLiteSessionStore には、1 つのホストとローカル POSIX ファイルシステムが必要です。ローカル プロファイルとカスタム ストアは両方とも、明示的な調整を求める不確実なルート呼び出しを報告する可能性があります。どちらもそれらのエフェクトを自動的に再生しません。 (#5514、#5502)
  • プロバイダーがホストするツールとストレージ。 FileSearch、CodeInterpreter、ImageGeneration、コード インタープリターの呼び出し元ポリシー、プロバイダーが管理するストレージを追加します。ホストされたツールには、API キー プロバイダーと互換性のある標準応答モデルが必要です。 Responses Lite および Codex ログインは除外されます。ホスト型 Web 検索では、ドメインと場所の制御が追加され、引用が保持されます。 (#5576、ホストされたツール ガイド)
  • コンテキストおよび補完フック。 Agent.transform_context は、保存された履歴を変更せずに、サンプリングされた入力を変更します。 before_compact および選択された項目の保持制御の圧縮。 before_complete は、提案された回答を受け入れたり、ContinueTurn を返したり、停止したりできます。拒否されたテキストはすでにストリーミングされており、履歴に残っている可能性があります。高度な prepare_request 編集は、制限付き HTTP プロファイルをサポートします。 フックの契約と制限 を参照してください。
  • 観察された使用量バジェット。 RunBudget は、ルート リクエストの受付、報告されたトークン、または次のリクエストまでの推定コストを制限します。許可されたリクエストは制限を超える可能性があります。子供は除外されます。使用量が不足していると、デフォルトでそれ以上の許可が停止されます。アクティブな予算設定された操作では、ポータブル チェックポイントを使用できません。 (#5555)
  • MCP リソース、プロンプト、および再接続。 セッションがアイドル状態のときに、選択した HTTP サーバーまたは stdio サーバーで Session.list_mcp_resources()、list_mcp_resource_templates()、read_mcp_resource()、list_mcp_prompts()、および get_mcp_prompt() を使用します。取得されたデータは、モデル コンテキストに自動的には入りません。スコープ付きツールの選択と明示的な再接続により、不確実な呼び出しを再実行することなく、許可されたツールに対する制御が維持されます。 (#5597、#5604、#5556)
  • ローカル実行とプロジェクト検索 Environment.local() は、サポートされている実行ツールをローカルで実行します。 Linux では、LocalStorageMount(source=path) は既存の正規ディレクトリへの読み取り専用アクセスを許可します。送信元と宛先は一致する必要があります。 project_glob および project_grep は、コマンドの実行を許可せずに、環境の固定作業ディレクトリの下を検索します。 (#5501、#5575、#5574)
  • 統合と監視。 a2a エクストラ、明示的な TraceContext、ワークフロー トレース コントロール、API キー レート制限スナップショット、ターン レシート、正確なターン ステアリング、およびアテンション ウェイトを介して、ネイティブ A2A client とサーバー アダプターを追加します。クラシック統合では、classic および classic-* エクストラを使用します。クラシックおよびネイティブのオブジェクトとチェックポイントは分離されたままになります。
  • ネイティブの履歴とポリシーを使用した音声。 agents.voice.NativeSessionVoiceWorkflow は、音声パイプラインで呼び出し元所有のテキスト出力セッションを使用します。完成レビューと出力検証後に受け入れられた最終テキストを読み上げます。アプリケーションは対話とセッションの有効期間を処理します。 voice を追加で取り付けます。リアルタイム エージェントは agents.classic.realtime の下に残ります。 (#5596)

変更されました

  • 関数ツールのタイムアウト処理を選択します。 timeout_behavior="error_as_result" は、オプションの timeout_error_function フォーマットを使用して、モデルにタイムアウト エラーを返します。引き上げはデフォルトのままです。 (#5605)
  • オプションのバッファリングされた応答。 NativeProvider(response_mode="buffered") は、モデル出力を出力する前に、完全な HTTP JSON 応答をそれぞれ読み取ります。標準の応答モデルを明示的に選択します。デフォルトのモデルは Responses Lite を使用します。バッファモードでは API キー認証が必要で、WebSocket、ネイティブの子、Codex ログインは除外されます。ストリーミングはデフォルトのままです。 (#5589)
  • 実験的な保存されたログインの再利用。 NativeProvider(auth=CodexLogin()) は、HTTP 経由で保存された Codex ログインを使用できます。 api_key および base_url は省略します。この実験的な機能は変更または削除される可能性があります。 認証のガイダンスと制限 を参照してください。

修正済み

  • 作成および置換中、およびバインドされたクラシック サンドボックス アーカイブの抽出中、クラシック マウント認証情報ファイルを非公開に保ちます。
  • キャンセル後の延期作業と自動圧縮を停止します。クリーンアップ所有者を保持すると、呼び出し元は調整やツールの影響を繰り返すことなく、未完了のリソースの解放を再試行できます。
  • 端末プロバイダーの認証失敗後のサンプリングのリトライを停止します。入力された出力失敗の理由とキャプチャされたコンテキスト制限をレポートし、キャッシュ書き込みトークンの数を保存します。
  • プロバイダーの応答の観察と実行の詳細を、設定されたポリシーに基づいて保持します。ネイティブの起動とイベント読み取りのオーバーヘッドを削減します。

openai-agents-python v0.24.0-alpha.7

Agents SDK v0.24.0-alpha.7

Highlights

  • Use Classic workflows alongside native execution. Import the retained v0 runtime through agents.classic. This alpha also changes executor write defaults; review the upgrade actions before opening existing environments.
  • Keep conversations in your own storage. Add durable root Sessions with CustomStorage, and reconcile uncertain tool effects before resuming work.
  • Add voice and hosted tools to native agents. Connect speech workflows to a Session, or use FileSearch, CodeInterpreter, and ImageGeneration through compatible Responses providers.
  • Control context, completion, and usage. Transform model input, retain selected context during compaction, review proposed answers, and limit observed root usage.

Upgrading from 0.24.0-alpha.6

  • Review Environment write policies. New Environments default to write_policy="strict", which requires a compatible Linux or macOS executor. The working directory remains writable; use writable_roots for additional directories. To retain the previous remote policy, including on Windows executors, set write_policy="legacy" and leave writable_roots=None. Local execution requires strict mode. When restoring legacy remote checkpoints or profiles, select legacy explicitly; reopening does not upgrade their policy. See the executor policy and restore rules.
  • Check implicit reasoning settings. The bundled model catalog changes the default reasoning effort from low to medium for gpt-6-astra, gpt-6.1-sol, and gpt-5.6-sol. Set model_settings={"reasoning_effort": "low"} explicitly if you need the previous effort. This describes bundled metadata; an explicit setting or provider model metadata can select another value. (#5517)
  • Rename MCP approval modes. Replace approval_mode="auto" with "native", and "approve" with "preapproved". The old values are rejected; the new names preserve their respective approval behavior.
  • Update child step callbacks. NativeAgents.before_step now receives one ChildStepContext, with context, child, and step_index, instead of separate child and step-index arguments. Root before_step callbacks keep their existing signature.
  • Handle MCP forms and URLs separately. ElicitationRequest is now the union FormRequest | UrlRequest. Use FormRequest.reply() or respond() for forms; use UrlRequest.reply_url_accept() or accept_url() for URL consent.

Added

  • Application-owned conversation storage. SessionStore, SQLiteSessionStore, and CustomStorage persist root history and automatic Python tool results. This initial profile excludes native tools, Environments, children, planning tools, generated-code execution, manual tools, and portable checkpoints. SQLiteSessionStore requires one host and a local POSIX filesystem. Both local profiles and custom stores can report uncertain root calls for explicit reconciliation; neither automatically replays those effects. (#5514, #5502)
  • Provider-hosted tools and storage. Add FileSearch, CodeInterpreter, and ImageGeneration, Code Interpreter caller policies, and provider-managed storage. Hosted tools require an API-key provider and a compatible standard Responses model; they exclude Responses Lite and Codex login. Hosted web search adds domain and location controls and retains citations. (#5576, hosted-tool guide)
  • Context and completion hooks. Agent.transform_context changes sampled input without changing stored history. before_compact and selected-item retention control compaction. before_complete can accept, return ContinueTurn, or stop a proposed answer; rejected text may already have streamed and remains in history. Advanced prepare_request editing supports a restricted HTTP profile. See the hook contracts and limits.
  • Observed usage budgets. RunBudget limits root request admissions, reported tokens, or estimated cost before the next request. An admitted request can exceed a limit. Children are excluded; missing usage stops further admission by default. Active budgeted operations cannot use portable checkpoints. (#5555)
  • MCP resources, prompts, and reconnection. Use Session.list_mcp_resources(), list_mcp_resource_templates(), read_mcp_resource(), list_mcp_prompts(), and get_mcp_prompt() with a selected HTTP or stdio server while the Session is idle. Retrieved data does not enter model context automatically. Scoped tool selection and explicit reconnection preserve control over admitted tools without replaying uncertain calls. (#5597, #5604, #5556)
  • Local execution and project search. Environment.local() runs supported executor tools locally. On Linux, LocalStorageMount(source=path) grants read-only access to an existing canonical directory; source and destination must match. project_glob and project_grep search beneath the Environment's fixed working directory without granting command execution. (#5501, #5575, #5574)
  • Integration and supervision. Add native A2A client and server adapters through the a2a extra, explicit TraceContext, workflow tracing controls, API-key rate-limit snapshots, turn receipts, exact-turn steering, and attention waits. Classic integrations use the classic and classic-* extras; Classic and native objects and checkpoints remain separate.
  • Speech with native history and policies. agents.voice.NativeSessionVoiceWorkflow uses a caller-owned text-output Session with the speech pipeline. It speaks accepted final text after completion review and output validation. The application handles interactions and Session lifetime. Install the voice extra; Realtime agents remain under agents.classic.realtime. (#5596)

Changed

  • Choose function-tool timeout handling. timeout_behavior="error_as_result" returns a timeout error to the model, with optional timeout_error_function formatting. Raising remains the default. (#5605)
  • Optional buffered Responses. NativeProvider(response_mode="buffered") reads each complete HTTP JSON response before emitting model output. Select a standard Responses model explicitly; the default model uses Responses Lite. Buffered mode requires API-key authentication and excludes WebSockets, native children, and Codex login. Streaming remains the default. (#5589)
  • Experimental saved-login reuse. NativeProvider(auth=CodexLogin()) can use a saved Codex login over HTTP. Omit api_key and base_url. This experimental feature may change or be removed; see the authentication guidance and limits.

Fixed

  • Keep Classic mount credential files private during creation and replacement, and bound Classic sandbox archive extraction.
  • Stop deferred work and automatic compaction after cancellation. Retain cleanup owners so callers can retry unfinished release of resources without repeating reconciliation or tool effects.
  • Stop sampling retries after terminal provider authentication failures. Report typed output-failure reasons and captured context limits, and preserve cache-write token counts.
  • Retain provider response observations and execution details under their configured policies. Reduce native startup and event-reading overhead.
