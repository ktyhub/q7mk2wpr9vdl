#でのv2.9.2

2.9.2 / 2026.07.08

  • 特技(デスクトップ): React Router フレームワークの自動検出 (#35557)
  • 特技(デスクトップ): Vite および Nuxt で --hmr を有効にする (#35851)
  • 特技(デスクトップ): フレームワーク開発サーバーによる HMR の実行 (#35722)
  • 特技(デスクトップ): ウィンドウの不透明度と透明度 APIs (#35646)
  • feat(デスクトップ): --exclude-unused-npm を使用してコンパイルする (#35740)
  • feat(ext/node): v8.setHeapSnapshotNearHeapLimit を実装 (#35694)
  • 特技(内線/テレメトリ): OTEL_ATTRIBUTE_VALUE_LENGTH_LIMIT を尊重 (#35068)
  • feat(inspector): SIGUSR1 でインスペクターサーバーを起動 (#35738)
  • feat(node): node:test に getTestContext() を実装 (#35678)
  • 特技: minimumDependencyAge.exclude でワイルドカード パターンをサポート (#35746)
  • 修正(チェック): ワークスペース内でエラーを「チェック」行に挟まないようにしました (#35687)
  • 修正(コンパイル): flatpak での EU ストリップを存続させるために libsui を 0.16.1 にバンプする (#35699)
  • 修正（コンパイル）: gVisor/Cloud Run でのセグメンテーション違反を修正するために、libsui を 0.16.3 にバンプします。 (#35701)
  • 修正(コア): 評価途中の mod_evaluate_sync でマイクロタスクを排出しないようにしました (#35707)
  • fix(coverage): どちらかのアームが走行するときに分岐ジャンクションラインをカバーされたものとしてカウントします (#35858)
  • 修正(カバレッジ): V8 ブロック境界ギャップを分岐としてカウントしない (#35767)
  • 修正(カバレッジ): 末尾のコメントによって行のヒット数が変更されないようにしました (#35741)
  • 修正(デプロイ): 構成検出を無効にし、キャッシュされた CLI バージョンを更新します (#35754)
  • 修正(デスクトップ): 登録ウィンドウ ID への属性バインド呼び出し (#35654)
  • 修正(デスクトップ): deno.json のデスクトップ.バックエンドを尊重 (#35815)
  • 修正(デスクトップ): 生成された Vite SPA エントリポイントに @std/http を固定 + ハーメチックを追加 コンパイルテスト (#35676)
  • 修正(デスクトップ): ランチャーの名前を <app> に変更し、ランタイムを自己ロードするようにしました (#35709)
  • 修正(デスクトップ): 出力をバンドルする前にフレームワークのビルドステップを実行します (#35603)
  • 修正(デスクトップ): コンパイル済みアプリの起動エラーを、サイレントに終了するのではなく表示します。 (#35567)
  • 修正(dprint): tools/lzld サブモジュールを除外 (#35778)
  • 修正(ext): シリアル化できない値をポストするときに DataCloneError をスローする (#35604)
  • 修正(ext/cache): Cache.keys() を実装 (#35455)
  • 修正(ext/fetch): ノードの「フェッチ失敗」形状によるトランスポート失敗の拒否 (#35618)
  • 修正(ext/http): 非 Uint8Array 応答ストリームのエラー (#35783)
  • 修正(ext/http): HEAD 応答で明示的なコンテンツ長ヘッダーを尊重する (#35728)
  • 修正(ext/http): docs.deno.com/go リンクで従来の中止警告を指摘 (#35713)
  • 修正(ext/napi): ネイティブ アドオンに uv_cond_* ポリフィルを追加 (#35536)
  • 修正(ext/net): DNS 解決中に保留中の Deno.connect を中止する (#35729)
  • 修正(ext/node): 継承された追加の stdio TCP fds の採用を許可 (#35805)
  • 修正(ext/node): メインモジュールパスに無効なパーセントエンコーディングがある場合でもパニックに陥らないようにする (#35534)
  • fix(ext/node):inspector.waitForDebugger() で一時停止をスケジュールしないようにしました (#35796)
  • 修正(ext/node): ストリーム暗号の暗号final()でStringDecoderをフラッシュ (#35800)
  • 修正(ext/node): tls_conn チェック前のティアダウン時に TLSWrap をデッドとしてマークする (#35706)
  • fix(ext/node): process.getActiveResourcesInfo からすべてのアクティブなリソースをレポートします。 (#35532)
  • 修正(ext/node): ノード:net UNIX ソケットに --allow-net=unix が必要 (#35835)
  • 修正(ext/node): 生成された Deno の子で fd 3 パイプをサポート (#34133)
  • 修正(ext/signals): SignalStream がドロップされたときにハンドラーの登録を解除しました (#35832)
  • 修正(ext/web): 閉じるバイトストリームをティーイングする際の保留中のBYOB読み取りを解決します。 (#35828)
  • 修正(fmt): Astro インライン スクリプトを TypeScript としてフォーマットする (#35852)
  • fix(fs): FsStat で 1970 年より前の (負の) タイムスタンプをサポート (#35517)
  • 修正(インスペクター): ランタイムが破棄されたときにWebSocket接続を閉じる (#35791)
  • 修正(インストール): @latest のようなタグを持つ JSR 指定子でパニックにならないようにします (#35605)
  • 修正(インストール): パッケージ ファイルをコピーするときにハードリンクを介して書き込まないようにします。 (#35735)
  • 修正(インストール): セットアップ キャッシュ パッケージのハッシュを決定的にする (#35825)
  • fix(install): ホイストされたものに対してライフサイクル スクリプトの依存関係ビンを解決します。 レイアウト (#35762)
  • 修正(インストール): 複数のグローバル パッケージのアンインストールをサポート (#29352)
  • 修正(lint): CSS ファイルのような分析不可能なパッケージのエクスポートでエラーが発生しないようにしました。 (#35732)
  • 修正(lint): ワークスペースメンバーに設定ファイルを含める無効なバージョンエラー (#35759)
  • fix(lsp): TSCのJsRuntimeの前にtokio runtimeを作成することでCPUビジーループを修正 スレッド (#35595)
  • fix(node/fs): fs.glob() の followSymlinks オプションを実装 (#35524)
  • 修正(npm): レジストリに時間がない場合、実行のたびにパックを再フェッチしないようにしました。 データ (#35834)
  • fix(npm): 完全な npm exports 値を保持しない + --watch メモリ リークを修正 (#35677)
  • fix(npm): 誤ったプリエンプションを避けるために、node_modules ロックの古いマージンを広げます。 (#35806)
  • 修正(権限): --ignore-read でカンマ区切りのパスを分割 (#35661)
  • 修正(テスト): テスト ワーカーのシャットダウン時に Node-API ファイナライザーを実行する (#35695)
  • 修正(watch): fmt/lint/bench --watch でウォッチ パスを受け入れる (#35720)
  • 修正(watch): --watch の下でプリロード モジュールを実行 (#35792)
  • 修正(watch): 同期コードでブロックされているときに Ctrl+C で終了する (#35826)
  • 修正: ワークスペース deps で rusqlite の「fallible_uint」機能を有効にする (#35681)
  • perf(config): リテラルサフィックスを拒否し、ベースごとに無関係なグロブを削除します (#35688)
  • perf(core): 残りの遅延ソース登録を延期する (#35731)
  • perf(ext/fetch): wasm バイトを Rust からコンパイラーにストリーム (#35704)
  • perf(ext/node): TLSWrap データ パス上のチャンクごとのコピーを削除 (#35705)
  • perf(ext/node): stream_wrap パス上のゼロコピー非同期バッファ書き込み (#35780)
  • perf(ext/web): ID PipeThrough 書き込み可能バイパス (#35799)
  • perf(ext/web): 汎用 PipeTo ループの永続ポンプ (#35813)
  • perf(ext/web): 永続読み取りによる readableStreamCollectIntoUint8Array のポンプ リクエスト (#35790)
  • perf(ext/web): ストリーム読み取りおよび T パスでのチャンクごとの割り当てを削減します。 (#35786)
  • perf(ext/web): Web Streams のチャンクごとのオーバーヘッドを削減 (#35773)
  • perf(ext/web): マイクロタスクホップなしで同期プル完了を実行します。 (#35788)
  • perf(ext/web): 共有基盤ソース アルゴリズム、ホイスト リソース ブリッジ読み取り リクエスト (#35810)
  • perf(ext/web): ReadableStream 非同期イテレータ next() の同期高速パス (#35842)
  • perf(ext/web): TransformStream の同期変換高速パス (#35844)
  • perf(npm): SIMD JSON スキャナーを使用したインデックス パック (#35698)
  • perf(streams): op_pipe 経由で、リソースをサポートする PipeTo を Rust にオフロードします (#35689)
  • perf(workers): メッセージ受け渡しを最適化する (#35110)
  • perf(workers): 転送不可能なメッセージの受信操作から生のバッファを返します。 (#35756)
  • perf: op の代わりに V8 ネイティブ queueMicrotask を使用する (#35787)
