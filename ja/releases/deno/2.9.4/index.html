#でのv2.9.4

2.9.4 / 2026.07.23

  • 特技(デスクトップ): React Router の --hmr を有効にする (#35900)
  • feat(ext/node): byteLength/length パラメータを追加します。 Buffer.indexOf/lastIndexOf/includes (#35872)
  • feat(ext/node): crypto.createCipheriv で生の Chacha20 暗号をサポート (#36016)
  • 偉業: V8 を 150.2.0 にアップグレード (#36098)
  • 修正(追加): デノ追加/削除で --minimum-dependency-age フラグをサポート (#36099)
  • 修正(キャッシュ): Web キャッシュを元のデータの下に保存 (#36145)
  • 修正(キャンバス): ネイティブ ウィンドウ ハンドルに FFI 権限が必要 (#36080)
  • fix(clean): シンボリックリンクされたノードモジュールのクリーンアップルートを拒否する (#36190)
  • 修正(コンパイル): Windows リソース SizeOfImage を修正するために libsui を 0.16.4 にバンプします。 (#36242)
  • 修正(コア): キャッシュされたモジュールの評価中に動的インポートを許可 (#36258)
  • 修正(コア): バウンドエラーグラフ変換 (#36070)
  • 修正(コア): FsModuleLoader で JSON リクエストを強制する (#36137)
  • fix(core): 不正な形式のエラー コンストラクターを処理する (#36071)
  • 修正(コア): ロード前に拒否された動的インポートを停止する (#36136)
  • 修正(デスクトップ): BrowserWindow バインディングを入力可能にする (#35907)
  • 修正(デスクトップ): 遅延操作アップグレード後にバインディング ラッパーを保持する (#36065)
  • 修正(デスクトップ): アプリ名からランタイム拡張子を削除 (#36060)
  • 修正(ext/napi): 閉じた後に非同期送信をキャンセルする (#36077)
  • 修正(ext/napi): 呼び出しごとのスコープ コールバック情報 (#36076)
  • 修正(ext/node): http2 ストリーム書き込みにバックプレッシャーを適用する (#36044)
  • 修正(ext/node): ヒープ制限近くに0バイトの.heapsnapshotファイルを残さないようにします (#36113)
  • 修正(ext/node): Web ロック経由で worker_threads.locks を実装 (#35963)
  • fix(ext/node):node:sqlite Backup() および deserialize() 引数の検証 (#36127)
  • 修正(ext/node): 試行ごとのタイムアウトが発生した場合に DNS クエリを再試行します (#35955)
  • 修正(ext/node): ストリームクローズ時に http2 ファイルの読み取りを停止する (#36061)
  • 修正(ext/web): 失敗した Webtransport データグラム設定の処理 (#36067)
  • 修正(ext/webidl): ReadableStream.from の async_sequence を実装 (#35976)
  • 修正(フェッチ): バインドされたマルチパートパートヘッダー (#36096)
  • 修正(fmt): 埋め込み CSS カスタム プロパティのインデントを安定した状態に保つ (#35949)
  • 修正(fs): umask に sys 権限が必要 (#36222)
  • 修正(http): trust プロキシ環境設定を保持する (#36073)
  • fix(init): 一時的なノードモジュールの親を検証する (#36142)
  • 修正(jupyter): codemirror_mode を文字列としてレポートする (#36241)
  • 修正(ローダー): JSON インポートの非 JSON モジュールを拒否する (#36135)
  • 修正(napi): 外部文字列ファイナライザーを同期する (#36078)
  • 修正(ネット): 初期エラー時のキャンセルリソースをクリーンアップ (#36229)
  • fix(net): WebTransport ハンドシェイク フレーム バッファリングを制限する (#36068)
  • 修正(node_http2): 破壊されたセッションをクリーンアップ (#36043)
  • fix(node_resolver): CJS ファイルシステム パスのエッジ ケースを処理する (#36112)
  • fix(node_stream): Web Stream アダプターのエラーを処理 (#36193)
  • 修正(npm): ロックポーリングシンボリックリンクをたどらないようにします (#36192)
  • 修正(npm): 代わりに、設定されたレジストリから tarball をダウンロードします。 registry.npmjs.org (#36187)
  • 修正(npm): シンボリックリンクされたパッケージ実体化ディレクトリを拒否 (#36191)
  • 修正(古い): タイプのみの依存関係をロックファイルに保持する (#36140)
  • 修正(パック): tar 名フィールドより長いファイル パスをサポート (#36105)
  • 修正(権限): プロンプト内の Bidi コントロールをエスケープする (#36195)
  • 修正(プロセス): Windows stdio パイプ名の衝突を回避 (#36081)
  • 修正(パブリッシュ): 生成されたソースの書き換えを制限する (#36109)
  • 修正(リリース): バージョン順にversion.jsonに挿入 (#36097)
  • 修正(rt): 抽出されたネイティブ アドオンを分離する (#36144)
  • 修正(ランタイム): --inspect フラグに関係なく、コンソールをインスペクターにブリッジします。 (#35795)
  • 修正(ランタイム): 報告したスタック サイズをワーカー分離スレッドに与える (#36114)
  • 修正(テスト): テスト名のエスケープ制御文字 (#36196)
  • fix(tests): npm テスト レジストリが不正なアドバイザリ リクエスト本文を許容できるようにします。 (#36138)
  • fix(tls): sni リクエストを同時に解決 (#36062)
  • 修正(更新): npm キャッシュが古い場合にロックファイルをダウングレードしない (#35904)
  • 修正(webtransport): URL 解析パニックを回避 (#36066)
  • 修正(webtransport): 証明書の日付を検証する (#36069)
  • fix(x): --minimum-dependency-age と deno.json minimumDependencyAge を尊重します (#36025)
  • 修正: jsr: エントリーポイントの構成ファイルを検出 (#35838)
  • 修正: UTF-16 診断列の処理 (#36028)
  • perf(core): 遅延 ESM スナップショット ソースの重複を避ける (#36262)
  • perf(スナップショット): 内部ソース識別子をマングルする (#36263)
  • perf: バンドルされた AppImage ランタイムを圧縮 (#36261)
  • perf: ホット内部ハッシュ マップに FxHash を使用する (#36100)
