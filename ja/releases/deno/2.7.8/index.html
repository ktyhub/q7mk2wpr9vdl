#でのv2.7.8

2.7.8 / 2026.03.25

  • feat(core): NodeRuntime CDP ドメインを実装し、--inspect-brk ブロックを修正 (#32714)
  • feat(ext/crypto): P-521 署名、検証、ECDH 導出を実装 (#32602)
  • feat(ext/napi): node_api_create_object_with_named_properties を追加 (#32906)
  • feat(ext/telemetry): OpenTelemetry 用のコンソール エクスポーターを追加 (#32717)
  • feat(ext/telemetry): 関連するスパン属性を HTTP メトリクスにコピー (#32720)
  • 特技: グローバル インストールに jsr パッケージのロックファイルを使用する (#32490)
  • 修正(監査): 脆弱性チェックで package.json をオーバーライドする (#32878)
  • 修正(cli): Windows 上の対話型ピッカーの矢印キーを修正 (#32978)
  • 修正(cli): deno の更新と deno の期限切れに対する --frozen フラグの解析 (#32975)
  • 修正(コンパイル): スタンドアロンバイナリでのノードからデノへの引数変換をスキップ (#32980)
  • 修正(ext/console): Symbol.toStringTag getterのスローを適切に処理します。 (#32917)
  • 修正(ext/napi): 接戦後に有効な環境変数を tsfn call_js_cb に渡す (#32957)
  • 修正(ext/node): 読み取り権限が無視された許可されたディレクトリ全体でのfs.cp (#32927)
  • 修正(ext/node): child_processの改善(internalMessage、argv0、DEP0190) (#32885)
  • 修正(ext/node): 新しいスタイルのハンドルの HandleWrap.close() で libuv ハンドルを閉じる (#32958)
  • 修正(ext/node): 再入パニックを防ぐために uv_write コールバックを延期 (#32919)
  • 修正(ext/node): TTY の外で readline.createInterface のエラーをスローしないようにしました。 (#32874)
  • 修正(ext/node): h2c リクエストのアップグレード イベントを起動しない (#32866)
  • 修正(ext/node): 防止するために、poll_tcp_handle 内のすべての準備完了接続をドレインします。 飢餓を受け入れる (#32943)
  • fix(ext/node): キープアライブパス内のソケット「free」の前にリクエスト「close」を発行します。 (#32811)
  • 修正(ext/node): v8.getHeapStatistics のノード互換テストを有効にする (#32833)
  • 修正(ext/node): ノード:fs 互換テストを有効にする + lchmod 修正 (#32892)
  • fix(ext/node): 4GB を超えるバッファを切り捨てる Buffer.concat を修正 (#32913)
  • fix(ext/node): child_process での IPC stdio 処理を修正 (#32920)
  • fix(ext/node): 非同期境界を越えたノード:ドメインを修正 (#32897)
  • 修正(ext/node): Node.js と一致するように os.constants.signals をフリーズ (#32836)
  • 修正(ext/node): process.threadCpuUsage() を実装 (#32829)
  • 修正(ext/node): process.hrtime 引数の検証を改善しました (#32837)
  • 修正(ext/node): readline と EventEmitter の互換性を改善 (#32826)
  • fix(ext/node): uid/gid を渡して process.getgroups を生成および実装する (#32772)
  • 修正(ext/node): 再接続時に TLS アップグレード状態を保持する (#32838)
  • fix(ext/node): VM コンテキスト プロパティ列挙子からすべての独自のプロパティを返します。 (#32911)
  • 修正(ext/node): TTY ReadStream および WriteStream で fd プロパティを設定 (#32880)
  • fix(ext/node): sqlite prepare() オプション、防御的なデフォルト、イテレータ 無効化 (#32756)
  • 修正(ext/node): http2 createConnection ソケットをサポート (#32733)
  • 修正(ext/node): child_process stdio 配列で数値 FD をサポート (#32959)
  • 修正(ext/node): process.versions.napi を 9 に更新 (#32870)
  • 修正(ext/web): 有効期間の長いシグナルによる AbortSignal.any() メモリ リーク (#32916)
  • 修正(ext/web): RemoveEventListener での null オプションの処理 (#32605)
  • fix(fmt): コンポーネント式の書式設定を markup_fmt に委任する (#29763)
  • 修正(fmt): markup_fmt を 0.27.0 に、malva を 0.15.2 に更新 (#32949)
  • 修正(インスペクター): process.exit() で実行ContextDestroyedを送信 (#32934)
  • 修正(ロックファイル): 凍結されたロックファイルのエラー差分を 50 行に切り詰める (#32976)
  • 修正(napi): テスト カバレッジを追加し、escape_handle/throw バグを修正しました (#32960)
  • 修正(node/http): HTTPS アップグレード時の TCP ラッパーのリークを停止します。 createConnection TLSSocket (#32961)
  • 修正(npm): ロックファイルが無効な場合に approve-scripts がパッケージを検出する (#32842)
  • 修正(npm): グローバル npm インストール中にすべての bin エントリに対して shim を作成する (#32607)
  • 修正(npm): npm パッケージの file: および link: 依存関係をスキップ (#32876)
  • 修正(npm): 非推奨のパッケージ警告にボックス描画スタイルを使用する (#32979)
  • 修正(リゾルバー): BYONMのnode_modulesバージョンの場合、.deno/にフォールスルーします。 不一致 (#32981)
  • 修正(リゾルバー): BYONM npm解像度でバージョンが正確に一致することを優先 (#32977)
  • 修正: .env ファイル内の二重引用符で囲まれた環境値の内部引用符を処理する (#32930)
  • 修正: deno タイプの出力に Temporal タイプを含める (#32952)
  • 修正: フレームグラフ SVG がブラウザのビューポート全体に表示されるようにしました (#32727)
  • 修正:approve_scripts_no_lock を PTY テストとして書き換え、ロックファイル テストをスキップ ウィンドウズ (#32853)
  • 修正: Windows で不安定な test-process-threadCpuUsage-worker-threads をスキップする (#32886)
  • perf(ext/web): Base64 エンコード/デコードに simdutf を使用する (#32743)
  • パフォーマンス: jsonc-parser 0.32 (#32864) へのアップグレード

deno v2.7.8

2.7.8 / 2026.03.25

  • feat(core): implement NodeRuntime CDP domain and fix --inspect-brk blocking (#32714)
  • feat(ext/crypto): implement P-521 sign, verify, and ECDH derive (#32602)
  • feat(ext/napi): add node_api_create_object_with_named_properties (#32906)

  • feat: use lockfile from jsr package for global install (#32490)
  • fix(audit): respect package.json overrides in vulnerability checks (#32878)
  • fix(cli): fix arrow keys in interactive picker on Windows (#32978)

  • fix(compile): skip Node-to-Deno arg translation in standalone binaries (#32980)

  • fix(ext/node): don't fire upgrade event for h2c requests (#32866)

  • fix(ext/node): emit request "close" before socket "free" in keep-alive path (#32811)
  • fix(ext/node): enable node compat test for v8.getHeapStatistics (#32833)
  • fix(ext/node): enable node:fs compat tests + lchmod fix (#32892)
  • fix(ext/node): fix Buffer.concat truncating buffers larger than 4GB (#32913)
  • fix(ext/node): fix IPC stdio handling in child_process (#32920)

  • fix(ext/node): implement process.threadCpuUsage() (#32829)
  • fix(ext/node): improve process.hrtime argument validation (#32837)
  • fix(ext/node): improve readline and EventEmitter compat (#32826)
  • fix(ext/node): pass uid/gid to spawn and implement process.getgroups (#32772)
  • fix(ext/node): preserve TLS upgrade state on reconnect (#32838)
  • fix(ext/node): return all own properties from VM context property enumerator (#32911)
  • fix(ext/node): set fd property on TTY ReadStream and WriteStream (#32880)
  • fix(ext/node): sqlite prepare() options, defensive default, iterator invalidation (#32756)
  • fix(ext/node): support http2 createConnection sockets (#32733)
  • fix(ext/node): support numeric FDs in child_process stdio array (#32959)
  • fix(ext/node): update process.versions.napi to 9 (#32870)
  • fix(ext/web): AbortSignal.any() memory leak with long-lived signals (#32916)
  • fix(ext/web): handle null options in removeEventListener (#32605)
  • fix(fmt): delegate component expression formatting to markup_fmt (#29763)

  • fix(lockfile): truncate frozen lockfile error diff to 50 lines (#32976)
