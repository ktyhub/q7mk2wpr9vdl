#でのv2.9.5

2.9.5 / 2026.08.06

  • feat(add): スコープ外の名前でパッケージのエイリアスを設定する --unscoped フラグ (#36319)
  • feat(task): ワークスペースメンバーのみでタスクを実行するための --members フラグを追加 (#35748)
  • 特技: Blob/Body textStream() を追加 (#35616)
  • 特技: 実験的な QuickJS バックエンドを追加 (#36194)
  • 修正(バンドル): esbuild プロトコルのデッドロックを回避 (#36427)
  • 修正(バンドル): 実行時のファイル権限を尊重する (#36107)
  • 修正(cjs): 再帰分析にローダー ソースを使用する (#36111)
  • 修正(cli): 外部メタデータ内のエスケープ制御文字 (#36198)
  • fix(core): ユーザーのインポートマップを使用して内部モジュールのインポートを解決しない (#36303)
  • 修正(暗号化): "raw-secret" を KeyFormat タイプに追加 (#35708)
  • 修正(デスクトップ): 色付きの HMR URL とページの読み込みを処理する (#36316)
  • 修正(デスクトップ): 更新署名検証オプションを保持 (#36152)
  • 修正(ext/crypto): 長さ0のderiveBitsを許可 (#36283)
  • 修正(ext/napi): ポリフィル uv_handle_size および uv_strerror (#36308)
  • 修正(ext/net): 完了したQUICストリームリソースの解放 (#36247)
  • 修正(ext/net): ノード:dns.getServers() に --allow-sys が必要 (#35941)
  • fix(ext/node): Web ストリームのノード互換 (#36285)
  • 修正(ext/node): Readable.toWeb() でバックプレッシャーを適用する (#36321)
  • 修正(ext/node): 再入パニックを回避するために、TLS 書き込み完了コールバックを延期します。 (#35867)
  • 修正(ext/node): セッション破棄後に http2 設定コールバックを起動しないようにしました。 (#36230)
  • 修正(ext/node): ゲート制約付きメモリ cgroup 読み取り (#36218)
  • fix(ext/node): 事前に引用符で囲まれたシェル引数を処理する (#36371)
  • 修正(ext/node): ノード:テストタグを実装 (#36292)
  • 修正(ext/node): util.diff を実装 (#36289)
  • 修正(ext/node): v8.promiseHooks API を実装 (#36281)
  • fix(ext/node): Node.js と一致するように fs.readdir エントリをソート (#36341)
  • 修正(ext/node): ストリームのクローズ後に http2 ファイルの読み取りを停止します (#36300)
  • fix(ext/node): ブロックリスト範囲をコンパクトに保存 (#36212)
  • 修正(ext/node): 書き込み用の fs flush オプションをサポート (#36290)
  • 修正(ext/node): X509 ECDSA検証にsignatureAlgorithmダイジェストを使用 (#36326)
  • 修正(ext/node_crypto): 名前付きグループ指数サイズを使用 (#36347)
  • 修正(ext/web): WHATWG API 検証エラーにノード エラー コードを添付する (#36288)
  • 修正(ext/websocket): wss アップグレード パスでの HTTP/2 サーバー プッシュを無効にする (#36327)
  • 修正(fetch): リダイレクトに依存するヘッダーをオリジンごとにスコープする (#36361)
  • 修正(ffi): ノンブロッキング呼び出しでのサイズ変更可能なバッファーの拒否 (#36259)
  • 修正(fmt): 標準入力の xml および svg 拡張子を受け入れる (#36149)
  • 修正(fmt): lax-markup を 0.3.2 に、lax-css と lax-sql を 0.3.0 に更新しました (#36397)
  • 修正(http): リダイレクト間で削除されたヘッダーを保持する (#36360)
  • 修正(インスペクター): リクエストのホストヘッダーを検証する (#36348)
  • 修正(ネット): ストリームクローズ時に保留中の書き込みをキャンセル (#36369)
  • 修正(ネット): 同時にドロップされた負荷分散されたリスナーをクリーンアップ (#36246)
  • fix(net): 不正な形式の DNS レコード テキストを処理する (#36374)
  • 修正(ノード): Web ストリームの終了リスナーをクリーンアップ (#36227)
  • fix(node): 消費された HTTP ストリーム ラッパーを保持する (#36254)
  • 修正(npm): 無効なパッケージ bin ターゲットを無視する (#36354)
  • 修正(npm): パッケージ内の不正な形式の scripts フィールドを許容する (#36324)
  • 修正(npmrc): 認証設定を権限とパスで照合する (#36359)
  • 修正(古い): JSR プレリリース バージョンを最新として報告しない (#36325)
  • 修正(公開): レジストリが出所証明を拒否した場合にレポートする (#36404)
  • 修正(リゾルバー): deno eval モジュールを npm パッケージ ファイルとして扱わないようにしました (#36304)
  • 修正(ランタイム): 通知の Windows パス欠落エラーを NotFound にマップ (#35864)
  • fix(sync-types): too_many_arguments が許可する理由を追加します (lint)
  • 修正(テレメトリ): 再入可能な属性変換の処理 (#36256)
  • 修正(webgpu): 独自のマップされた範囲バッキング ストア (#36257)
  • 修正(webstorage): ストレージコンストラクター名を保持する (#35944)
  • 修正: ヘルプ テキストの capitalize IP (#36170)
  • 修正: deno_task_shell を 0.33.3 にアップグレード (#36406)
  • 修正: deno.json 設定から no-legacy-abort 不安定フラグをワイヤーリング (#36312)
  • perf(core): Rust で共通パス ティック ドレインを実行します (#36157)
  • perf(ext/node): udp 送信のリテラル IP での DNS ルックアップをバイパスします (#35909)
  • perf(ext/web): simdutf ops としてbase64url エンコード/デコードを実装 (#36398)
  • perf(fs): 非同期 readFile/writeFile でブロッキング プール上のファイルを開く (#36160)
  • perf: リリース ビルドでのスタートアップ関数の順序付け (#36219)
  • perf: 起動時の熱心なモジュール評価を削減 (#36331)
  • perf: リリース アーティファクトから Linux アンワインド テーブルを削除 (#36265)
