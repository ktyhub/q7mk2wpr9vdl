anything-llm v1.4.0

Highlights

  • Security fixes — This release fixes uploaded-file path traversal that could allow arbitrary file writes, unauthorized access to other users’ profile pictures, and improper audio-file/custom-model validation. Upgrade promptly if you expose uploads, profile images, or user-facing APIs.

  • Agent and reasoning-model UX — Improved agent-calling UI and model-agnostic display of <think> output make tool activity and reasoning responses clearer. LLM settings can now be edited from workspace settings, default agent skills can be disabled, and Ollama performance mode was updated. Worth upgrading for agent-heavy or reasoning-model workflows.

  • RAG and provider improvements — Adds a reranker option for RAG, a vector search API endpoint, NVIDIA NIM support, a Google Generative AI (Gemini) embedder, and voyage-3-large/voyage-code-3 embeddings. Embedding-history support and similarity-score fixes for Lance/Chroma may improve retrieval quality. Changing the vector database or embedder now purges cached documents and removes documents from all workspaces, so expect re-embedding/reindexing after such changes.

  • API and permission changes — Adds workspace user-management and thread-name APIs, exposes writable fields on the developer API’s new-workspace endpoint, supports Gemini authenticated-model discovery, and returns properly formatted OpenAI-compatible timestamps. default roles can use attachments but cannot upload documents; review role behavior if you relied on the previous defaults. API integrators should review these response and permission changes before upgrading.

  • Breaking removals — The fine-tuning flow (#2872) and native LLM option (#3024) were removed. Additionally, similarityResponse arguments changed from positional to object form (#2930). Migration required if you use removed features or call the affected API internally. Other users can skip unless the security, UX, provider, or RAG improvements are relevant to them.
