#何でも-llm v1.16.1

活動と思考回路の見直し

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/34e52190-51e3-40b5-baeb-d1936319cb4a" />

複数の思考とツールの呼び出しを表示する長期的なエージェント タスク向けに UI を全面的に見直し、単一のクリーンで折りたたみ可能な UI 要素にまとめられるようになりました。

これにより、モデルが生成する重要なコールスタックと思考を読みやすい形式で維持しながら、実際の応答のための画面領域がさらに広がります。

ナビゲーション警告

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/dfa98c30-4bde-4321-86cc-eb0bcd7b9873" />

最近、サポートされているすべての LLM に真の中止シグナルを追加しました。これにより、推論をキャンセルするかページを離れると、推論を停止してコンピューティング コストを節約できるようになります。

ただし、これには、チャットから離れるときに推論がキャンセルされ、バックグラウンドでの完了が妨げられるという意図しない副作用がありました。応答を中止する前に警告が表示されるようになりました。

ロードマップ項目: この動作をカスタマイズして、複数の並列推論セッションが可能な、より強力なセットアップや同時実行性の高いセットアップを使用しているユーザー向けにバックグラウンド推論を許可できるように、このユーザーを構成可能にする予定です。

Foundry ローカル組み込み (デスクトップのみ)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/d43ba423-83a8-4150-8b62-606ffb6c8882" />

FoundryLocal は、Microsoft によって構築された推論エンジンであり、Windows 11 (バージョン 24H2、ビルド 26100 以降) にプレインストールされて使用できます。

これは、WinML を使用して、あらゆる Windows ハードウェア構成にわたって CPU、GPU、または NPU のモデルを読み込みます。これは、明示的にサポートされていないハードウェア構成に最適なオプションです。 FoundryLocal はまだ展開中であるため、利用可能なモデルが制限される可能性があることに注意してください。ビジョン モデルは現在利用できません。

これに関しては Microsoft と提携しています。バグや問題がある場合は、FoundryLocal チームに転送することができます

GenieX for Snapdragon (デスクトップのみ)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/866a7cc2-e3e7-4189-af56-6a29c030aab5" />

[!NOTE] これは、以前の Snapdragon NPU エンジンを置き換えます。古いエンジンの以前のモデルは更新時に削除されるため、これらの最適化されたモデルを再ダウンロードする必要があります。 NPU モデルと通常の GGUF のパフォーマンスが大幅に向上していることがわかります。

このエンジンには GGUF モデルのみを使用することを強くお勧めします。 Qualcomm NPU のみのモデルには 4K コンテキスト ウィンドウがあり、エージェント エクスペリエンスが低下します。

GenieX は、Qualcomm (以前は NexaAI) によって構築されたオープンソース推論エンジンで、X および X2 Elite デバイスの NPU 上で GGUF および Qualcomm AI Hub モデルを効率的に実行します。

AnythingLLM は、ドロップダウンで「AnythingLLM GenieX」プロバイダーを選択することで、フルマネージドの組み込みサポートを提供します。 GGUF と NPU 専用モデルの両方で NPU を活用でき、両方の電力効率とインテリジェンスを実現します。

この点については Qualcomm と提携しています。バグや問題がある場合は、GenieX チームに転送するか、GitHub について問題を提起することができます。 @zhiyuan8、@alexchen4ai、@alanzhuly をよろしくお願いします

新機能

  • Windows (x64/ARM64) 上の [x] ネイティブ Foundry Local SDK - Foundry プロバイダーは完全に自己完結型になり、別個の Foundry Local インストールが不要になり、GPU/NPU に最適化されたモデル バリアントがカタログで公開されます。
  • [x] Windows ARM64 デバイスの GenieX ランタイム サポート
  • [x] AWS Bedrock クロスリージョン推論プロファイルのサポート - 地域プレフィックス付きのプロファイル ID (us.、eu.、global.) がモデルのドロップダウンに表示され、正しくルートされるようになりました。さらに、プリセット リスト外のリージョン (GovCloud、特殊なパーティション) の手動リージョン入力も可能になりました。
  • [x] LocalAI がイメージ生成プロバイダーとして追加され、サーバーからのイメージ対応モデルのみがリストされます。
  • [x] LocalAI コンテキスト ウィンドウの自動検出 - コンテキスト ウィンドウはサーバーの構成からモデルごとに読み取られ、手動設定はオプションでオーバーライドされるようになりました。
  • [x] Windows インストーラーのサイレント/ヘッドレス インストールおよびアンインストール フラグ - Windows インストール ドキュメント を参照してください。

  • [x] Foundry Local は、組み込みランタイムの使用時にセットアップを求めるプロンプトを表示しなくなり、機能検出によってモデルを自動ロードします。
  • [x] オンボーディング ライト モード スタイルと再設計された LLM 選択 UI
  • [x] Beacon は、折りたたみ可能な思考とモデル詳細テキストのオーバーフローの修正により、ストリーミング中に思考ブロックとマークダウン形式を正しくレンダリングするようになりました。
  • [x] Windows インストーラーにサイドバー パネルのイメージが含まれるようになりました
  • [x] プロンプト入力の下書きがナビゲーション間で保持されるようになりました。

anything-llm v1.16.1

Highlights

  • Chain-of-thought rollup — PR #6182 folds multi-step agent thinking and tool calls into a single collapsible rail: one line collapsed, one step per thought with a connected trace when expanded, and the live thought in the header while streaming. It's mirrored in the Assistant Panel, and Beacon now streams thinking blocks as collapsible markdown. For developers running long-horizon agents this reclaims screen real estate for the answer without losing the call stack; a related fix stops reasoning from hanging forever when a model never closes its think tag.
  • Navigation now warns before aborting inference — behavioral change worth knowing: earlier "true" abort signals silently killed generation the moment you left a chat to save compute. This release inserts a confirmation before the response is discarded, and #6190 blocks model unload while inference is active. Drafts also survive navigation (#6191). Watch for the new confirm dialog mid-stream; background completion is on the roadmap as a user-configurable option for high-concurrency setups.
  • Foundry Local embedded (desktop/Windows) — a native SDK makes the provider self-contained, so there's no separate Foundry Local install; works on x64 and ARM64, Windows 11 24H2 build 26100+. WinML targets CPU/GPU/NPU, the catalog exposes GPU/NPU-optimized variants, and models auto-load by capability detection. Practical caveats: model availability is still limited during Microsoft's rollout and vision models are unavailable — treat it as a fallback for hardware configurations AnythingLLM doesn't explicitly support.
  • GenieX replaces the Snapdragon NPU engine (breaking) — the managed "AnythingLLM GenieX" provider targets X/X2 Elite ARM64 devices, but models from the old engine are deleted on update and must be re-downloaded. Expect significant gains for NPU models and regular GGUFs; the team strongly recommends GGUFs only, because Qualcomm NPU-only models carry a 4K context window that degrades agent quality. Budget for the re-download and re-test your model choice on upgrade.
  • Bedrock and LocalAI provider expansion — AWS Bedrock cross-region inference profiles now route through bedrock-runtime (#6181): geo-prefixed IDs (us., eu., global.) appear in the dropdown and resolve correctly, with manual region entry for GovCloud and other partitions. LocalAI gains image generation (#6176) and per-model context-window auto-detection (#6177), demoting the manual context setting to an optional override — relevant if you previously hard-coded context lengths on a self-hosted server.
  • Cost tracking and stream-stability fixes — cost tracking lands in #6150, useful for metering agent spend. On the reliability side: a Gemini crash from a content-header length mismatch on unpinned undici (now compatible with v6 and v7), an Anthropic/Bedrock mid-stream abort crash in chat mode (#6186), and an abort-listener leak that could wipe the whole chat on pause are all fixed. Windows admins also get silent/headless install and uninstall flags for unattended deployments.

Activity and Chain of Thought Overhaul

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/34e52190-51e3-40b5-baeb-d1936319cb4a" />

We overhauled our UI for long-horizon agentic tasks that show multiple thinking and tool calls to now roll up into a single clean, collapsible UI element.

This gives you more screen real estate for the actual response while still keeping the important call stack and thoughts the model produces in an easy-to-read format.

Navigation Warning

<img width="3680" height="2212" alt="image" src="https://github.com/user-attachments/assets/dfa98c30-4bde-4321-86cc-eb0bcd7b9873" />

Recently, we added true abort signals across every supported LLM so that when you cancel inference or leave the page, we stop inference to save you on compute costs.

However, this had the unintended side effect of canceling inference when navigating away from a chat, preventing background completion. Now we warn you before aborting the response.

Roadmap item: We intend to make this user configurable so you can customize this behavior and allow background inference for those with more powerful or high-concurrency setups where multiple parallel inference sessions are feasible.

Foundry Local Embedded (Desktop Only)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/d43ba423-83a8-4150-8b62-606ffb6c8882" />

FoundryLocal is an inference engine built by Microsoft that is pre-installed and available on Windows 11 (version 24H2, build 26100 or later).

This uses WinML to load models for your CPU, GPU, or NPU across any Windows hardware configuration. It's a great option for hardware configurations we don't have explicit support for. Keep in mind that model availability may be limited as FoundryLocal is still rolling out. Vision models are not available currently.

We partner with Microsoft for this, if you have bugs or issues we can help forward them to the FoundryLocal team

GenieX for Snapdragon (Desktop Only)

<img width="1280" height="720" alt="image" src="https://github.com/user-attachments/assets/866a7cc2-e3e7-4189-af56-6a29c030aab5" />

[!NOTE] This replaces our previous Snapdragon NPU engine. Any previous models from the old engine are deleted on update, and you'll need to re-download these optimized models. You should see a significant performance increase for NPU models and regular GGUFs.

We highly recommend using only GGUF models for this engine. Qualcomm NPU-only models have 4K context windows and will result in a poor agent experience.

GenieX is an open-source inference engine built by Qualcomm (previously NexaAI) that efficiently runs GGUFs and Qualcomm AI Hub models on NPU for X and X2 Elite devices.

AnythingLLM offers fully managed and built-in support by selecting the "AnythingLLM GenieX" provider in the dropdown. Both GGUFs and NPU-only models can leverage the NPU, giving you the power efficiency and intelligence of both.

We partner with Qualcomm for this, if you have bugs or issues we can help forward them to the GenieX team or you can make an issue on their GitHub. s/o @zhiyuan8, @alexchen4ai & @alanzhuly

New Features

  • [x] Native Foundry Local SDK on Windows (x64/ARM64) - the Foundry provider is now fully self-contained and no longer requires a separate Foundry Local install, with GPU/NPU-optimized model variants exposed in the catalog
  • [x] GenieX runtime support for Windows ARM64 devices
  • [x] AWS Bedrock cross-region inference profile support - geo-prefixed profile IDs (us., eu., global.) now appear in the model dropdown and route correctly, plus manual region entry for regions outside the preset list (GovCloud, specialized partitions)
  • [x] LocalAI added as an image generation provider, listing only image-capable models from your server
  • [x] LocalAI context window auto-detection - context windows are read per-model from your server's config, with the manual setting now an optional override
  • [x] Silent/headless install and uninstall flags for the Windows installer - see the Windows installation docs

Improvements

  • [x] Chain of thought and agent activity are now a single collapsible component - one line when collapsed, one step per thought with a connected rail when expanded, and the live thought shown in the header while streaming
  • [x] The new chain of thought rollup is now mirrored in the Assistant Panel
  • [x] Leaving a thread or navigating away mid-inference now warns you before the response is lost, instead of silently killing the generation
  • [x] Foundry Local no longer prompts for setup when using the built-in runtime, and auto-loads models by capability detection
  • [x] Onboarding light mode styling and a redesigned LLM selection UI
  • [x] Beacon now renders thinking blocks and markdown formatting correctly while streaming, with collapsible thinking and a fix for model detail text overflow
  • [x] Windows installer now includes a sidebar panel image
  • [x] Prompt input drafts now persist between navigation

Bug Fixes

  • [x] Fixed a Gemini crash caused by a content-header length mismatch on unpinned undici versions - now compatible with both v6 and v7
  • [x] Fixed a crash when aborting an Anthropic (or Bedrock Anthropic) response mid-stream in chat mode and then sending a follow-up
  • [x] Fixed a memory leak from leaked abort-stream listeners, which also caused pausing a response to wipe the entire chat
  • [x] Fixed a crash when creating a new workspace
  • [x] Fixed missing setup CTAs on modals introduced by the new uniform modal component - Scheduled Job skill setup on both the category and tool views, Community Hub connection key, and the experimental features reject button
  • [x] Fixed the intermediate loader being too tall while waiting for an agent capability response
  • [x] Fixed the stray border around the delete button in Workspace Chats
