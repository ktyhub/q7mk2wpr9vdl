クロードコード v2.1.292

何が変わったのか

  • --marketplace <source> を claude plugin install に追加: 必要に応じて、claude plugin marketplace add と同じポリシー チェックの下でマーケットプレイスを追加し、そこからプラグインをインストールします。
  • エージェント ツールに effort パラメータを追加したため、クロードは要求された作業レベルでサブエージェントを実行します。
  • オーバーロードされた (529) リクエストを再試行するときにバックオフの基本遅延を長く設定するための CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS 環境変数を追加しました。
  • prompt.autocomplete を追加しました。MOD がプロンプト ボックスのオートコンプリート リストに独自の行を追加するためにフックするイベントです。
  • MOD の $.model.complete にプロンプト キャッシュを追加しました: prompt と system はテキストのブロックを受け取り、ブロック上の cache: true はそれまでのリクエストをキャッシュします。
  • ワークフロー エージェントを agent.spawn MOD フックに追加し、その実行とインデックスを追加したため、MOD がそれらを拒否できるようになりました。
  • 自動モードが利用できない（設定、サーキットブレーカー、または自動モードをサポートしていないモデルによって無効になっている）場合に、permissionMode: auto が自動モードに入るサブエージェント定義を修正しました。
  • サンドボックス コマンドが ~/.claude/seed-admin でアップロードされた /ultrareview のステージングされたファイル コピーを読み取ることができるように修正しました。
  • セッション中に表示または再ポイントされるマネージド サンドボックスの読み取り拒否パス (およびその横のユーザーのパス) が修正され、その中のプロジェクト許可が削除されたり、対象となるファイルからの認証情報の注入が終了したりしませんでした。
  • macOS および Windows で読み取られたノートブックまたは PDF が、読み取り中に交換されたリンクを通じて、承認された内容以外のファイルを返すことができる問題を修正しました。
  • 設定の取得が失敗したときに、サーバー管理設定のディスク上のキャッシュが改ざんされて、組み込みポリシー プラグインのスイッチをオフにしたり、設定を解除したりできる問題を修正しました。
  • 8.3 の短縮名、またはホーム フォルダーまたはドライブの別の代替 Windows スペルの rm -rf が削除として扱われない問題を修正しました。
  • セキュリティ: ネットワーク (UNC) パスからのファイル読み取りの許可プロンプトをバイパスする PreToolUse フックの承認と自動モードを修正しました。
  • ターンの途中でオートモードまたはプランモードを終了すると、後のターンでスキルまたはスラッシュコマンドのallowed-toolsルールが戻ってくる問題を修正しました
  • HTTPS_PROXY が設定されている場合、クロード コード自体の API リクエスト (サインイン、ポリシー、フィードバック、アーティファクト) に対して NO_PROXY が無視される問題を修正しました。
  • 128 文字を超える名前を持つ MCP ツールがすべてのリクエストを失敗させる問題を修正しました。このツールは現在削除されており、MCP エラーによってその名前が付けられています。
  • 最初の実行時に組織の管理設定が読み込まれる前に実行される marketplace add や install などの claude plugin コマンドを修正しました
  • ワンショット claude -p とエージェント SDK の実行が最終結果の 5 秒後にバックグラウンド コマンドを停止し、ワンショット claude -p の実行がスケジュールされたウェイクアップをドロップする問題を修正しました。どちらも現在待機中です
  • claude --resume セッション ピッカーまたは /resume でセッションを再開するときに、プラン モードが復元されない問題を修正しました。
  • /resume、/branch、または /clear の後に作成された保存済みスケジュール済みタスクが起動しない問題と、ミリ秒間隔でタスク ファイルに 2 回書き込みを行った後、保存済みタスクがその後の作成と削除を無視する問題を修正しました。
  • 保留中のウェイクアップが失われたため、セッションのプロセスが再起動されたとき（クラッシュ後など）、バックグラウンド セッションの /loop がサイレントに停止する問題を修正しました。
  • 指定されたファイルまたはフォルダーを読み取れなかった場合に一致しないと報告する Grep と Glob を修正しました。クロードは一度再試行するか、あなたに通知します
  • PDF の pages が「6,9,15」のようなリストである場合、読み取りツールがエラーなしで最初のエントリのみを返す問題を修正しました。各ページまたは範囲を個別に読み取るように指示するエラーが返されるようになりました。
  • @ で言及された 256KB を超えるテキスト ファイルがサイレントに除外される問題を修正しました。クロードはファイルのサイズを通知され、それを分割して読み取るようになりました。
  • エージェントがすでにメインの会話を停止している制限に失敗した場合に、バックグラウンド エージェントごとに 1 回繰り返される使用制限アラートを修正しました
  • デスクトップ アプリまたは IDE によってホストされるセッションで、リモート コントロール ビューアにバックグラウンド サブエージェントの空のサブエージェント ペインが表示される問題を修正しました。

claude-code v2.1.292

What's changed

  • Added --marketplace <source> to claude plugin install: adds the marketplace if needed, under the same policy checks as claude plugin marketplace add, then installs the plugin from it
  • Added an effort parameter to the Agent tool, so Claude runs a sub-agent at the effort level you ask for
  • Added CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS environment variable to set a longer base delay for the backoff when retrying an overloaded (529) request
  • Added prompt.autocomplete, an event a mod hooks to add its own rows to the prompt box's autocomplete list
  • Added prompt caching to $.model.complete for mods: prompt and system take blocks of text, and cache: true on a block caches the request up to it
  • Added workflow agents to the agent.spawn mod hook, with their run and index, so a mod can refuse them
  • Fixed subagent definitions with permissionMode: auto entering auto mode when auto mode is unavailable (disabled by settings, circuit breaker, or a model that doesn't support it)
  • Fixed sandboxed commands being able to read the staged file copies of /ultrareview uploads under ~/.claude/seed-admin
  • Fixed a managed sandbox read-deny path (and user ones beside it) that appears or re-points mid-session not dropping project grants inside it or ending credential injection from files it covers
  • Fixed a notebook or PDF read on macOS and Windows being able to return a file outside what was approved, through a link swapped in mid-read
  • Fixed a tampered on-disk cache of server-managed settings being able to switch off or unseat the built-in policy plugin while the settings fetch failed
