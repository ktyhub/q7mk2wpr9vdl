クロードコード v2.1.281

何が変わったのか

  • blockReadsOutsideWorkingDirectories および disableBypassPermissionsMode を含む、desktop ポリシー ブロックの新しいクロード デスクトップ キーに対するクロード アプリ ゲートウェイのサポートを追加しました。
  • クロード アプリ ゲートウェイの Bedrock アップストリームに assume_role を追加しました。ゲートウェイは、必要に応じて別の AWS アカウントで、STS を通じて引き受ける IAM ロールとして Bedrock を呼び出します。オプションで開発者ごとに 1 つのセッションを実行します。
  • クロード アプリ ゲートウェイの Bedrock アップストリームに guardrail: {id, version} を追加し、Amazon Bedrock ガードレールを経由して送信されるすべてのリクエストに適用します (すべての Bedrock アップストリームに設定するか、何も設定しません)
  • クロード デスクトップおよび /login セッションのテレメトリに固定ラベルを付けるために、telemetry.resource_attributes をクロード アプリ ゲートウェイ構成に追加しました
  • すべてのコミットと PR 属性を非表示にするために settings.json に "attribution": false を追加しました。古い CLI バージョンは、それを保持する設定ファイルをスキップするため、バージョン間で共有されるファイルにオブジェクト形式を保持します。
  • 2026 年 7 月 28 日のプロトコル接続に MCP URL モードの引き出しを追加したため、サーバーはクロード コードにブラウザベースのフローを開くように要求できます。サーバーが完了を確認する方法がない場合、待機中のダイアログは画面上に残されません。
  • MCP サーバー チェックを claude plugin validate に追加しました。ロード時にサイレントに削除される .mcp.json エントリ、宣言されていない ${user_config.*} 参照、および安全でない URL を報告します。
  • 最近のセッションで自動モードが処理できる許可プロンプトの数を推定する自動モードの推奨事項を /insights に追加しました
  • /skills、/mcp、/plugin のインストール済みリストに、/workflows のような全画面モードのスクロールバーを追加しました。スクロールバーは、マウスがリスト上にあるときに表示され、cli クリックまたはドラッグできます。
  • API リクエストの再試行中にセッションが終了する可能性があるクラッシュ (「回復不能なインターフェイス エラー」) を修正しました
  • モデルが解析不可能なツール呼び出しと出力制限の切り捨てを交互に実行したときに、--max-turns を無視して無限に再試行できる可能性があるターンを修正しました
  • 再開されたセッションが以前のターンを変更された形式 (並列ツール呼び出しターン、サーバーが再接続中の MCP ツール呼び出しの入力またはツール検索結果、または読み込みターンが中断されたツール検索結果) で再送信する問題を修正しました。これにより、API が会話の前の推論をドロップする可能性がありました。
  • 非常に大規模なセッションを再開すると、最後の数メッセージのみが復元される場合がある問題を修正しました
  • 保留中の許可プロンプト中に再起動後にセッションが再開され、以前とは異なる履歴が送信され、その時点からプロンプトのキャッシュが壊れる問題を修正しました。
  • ツール呼び出し中に終了したセッションの再開を修正しました。クロードは呼び出しを確認し、その結果は不明であると言われるようになり、手動で再開しても非表示の「続行」メッセージが追加されなくなりました。
  • 以前のアドバイザーとのセッションの結果、API が毎ターン失敗する 1 つのリクエストを読み取れなくなり、以前の推論が繰り返し失われる問題を修正しました。歴史は一度修復されました
  • ツール検索がオフになっている間 (たとえば、プロキシやゲートウェイの背後にある場合)、MCP サーバーが会話中に切断した場合、または再開後にまだ接続している場合にプロンプト キャッシュが失われる問題を修正しました。
  • 警告なしで完了としてストリームを正常に閉じるプロキシまたはゲートウェイによって応答が短縮され、重複したストリーム イベントでツール呼び出しが 2 回実行される問題を修正しました。
