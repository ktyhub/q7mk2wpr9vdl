クロードコード v2.1.282

何が変わったのか

  • 表とコード ブロックは全幅を維持しながら、ワイド端末でクロードの散文の幅を制限する maxProseWidth 設定を追加しました
  • 起動通知と、無視されたかテレメトリをオフにしたプロジェクトの設定ファイル内のテレメトリ変数をリストする /status および claude doctor エントリを追加しました。
  • claude --chrome を排他的な managed-mcp.json と並行して実行できるようにするための allowClaudeInChromeWithManagedMcp 管理設定を追加しました。 Chrome がブロックされたときに表示されるエラーに名前が付けられるようになりました
  • クロード アプリ ゲートウェイに store.readiness_grace_seconds を追加しました。これにより、データベース フェールオーバーなどの短期間の Postgres 停止中も /readyz が準備を整えられるようになります。
  • 全画面モードの /feedback ドラフト リストにスクロールバーを追加しました。マウスがリストの上にあるときに表示されます
  • API が復号化できない Web 検索結果を履歴に保持している会話 (サードパーティのゲートウェイ経由で応答したターンなど) ですべてのリクエストが 400 エラーで失敗する問題を修正しました。
  • 継続または再開されたセッション (--continue、--resume) が以前のメッセージを変更された形式で再送信するケースを修正しました。これにより、API がクロードの以前の推論を削除する可能性がありました。
  • クロードの作業中に/model、/rename、/artifacts、または別の即時スラッシュコマンドが使用されたときに以前の拡張思考がドロップされる問題を修正しました
  • 会話の前半で提供された組み込みツールを省略した --tools リストを使用して再起動すると、継続または再開された会話が以前の拡張思考を失う問題を修正しました
  • 「redacted_thinking ブロック内の data が無効です」API エラーによりセッションが毎ターン失敗する問題を修正。クロード コードは会話の思考ブロックを削除し、一度再試行するようになりました。
  • 要約リクエストが拒否された場合に圧縮が失敗する問題を修正しました。フォールバックモデルで再試行されるようになりました
  • 思考オフで努力値が高いセッションでの安全関連モデルの切り替え後の失敗したターン (「思考力がオフになっていると努力値 'xhigh' は使用できません」) を修正しました
  • Claude Desktop などの SDK がホストするセッションで、応答のない Fable の使用量クレジット プロンプトのモデル切り替えを修正しました。代わりにターンが終了し、リモコン cli にはモデル切り替えの通知が表示されます。
  • プランでまだ有効になっていない使用量クレジットが必要な場合に、使用量クレジット プロンプトが開かず、完全な Fable モデル ID の /model が API エラーで停止する問題を修正しました。
  • 他のプロセスが更新中に閉じられるか強制終了された後、「別のクロード コード プロセスが更新中です」というログイン エラーが発生し、リクエストが最大 1 分間失敗する問題を修正しました。
  • 別の Claude Code ウィンドウがサインインを更新している間に開始されたセッション (いくつかの VS Code ウィンドウに共通) が組織ポリシーの取得を再試行しない問題を修正しました。
  • 起動時に、.. または /.vol スタイルのカーネル パスを介して macOS の /Network に到達するリポジトリ シンボリック リンクを介して読み取られる CLAUDE.md とルール、またはリストされている macOS の /home へのルール リンクを修正しました。
  • --allowedTools は尊重するものの、設定ファイル内で中間パターン :* がスキップされる Bash 権限ルールを修正しました。それらはあらゆるソースから動作するようになり、それらがどのように一致するかについて起動時に警告が表示されます。
  • リモート セッションのワーカーが再起動されたときに、復元された権限プロンプトで承認されたコマンドが 2 回実行される問題を修正しました
  • disableClaudeAiConnectors や allowManagedPermissionRulesOnly などのブール型ロック キーのタイプミスした値を無視する管理設定を修正しました。ロックが適用され、起動時にキーに名前が付けられます
  • 1 つのネストされた値が無効な場合に、マネージド permissions、autoMode、worktree、および attribution 設定が完全​​に無視される問題を修正しました。ブロックの残りの部分は引き続き適用されます
  • マネージド allowManagedPermissionRulesOnly の下で allowed-tools 経由で独自のツールを事前承認するリポジトリ、ユーザー、--add-dir スキル、コマンド、およびスキル ディレクトリ プラグイン マニフェストを修正しました
  • Amazon Bedrock および Bedrock Mantle のセーフガード ブロック メッセージにリクエスト ID が表示されない問題を修正しました。ブロックメッセージにはメッセージIDも表示されるようになりました
  • Vertex AI: 新しくリリースされたモデルなど、Claude Code がまだ認識していないモデルに対して Web 検索が提供されない問題を修正しました。
  • Bash と PowerShell が「終了コード 1」の背後に完全なディスク クォータを隠し、大きな出力ファイルを一時ファイルに残す問題を修正しました。
  • 同じ呼び出し内の他のパラメータも無効な場合に、不明なパラメータ、欠落パラメータ、または入力ミスのパラメータのみを指定するツール入力検証エラーを修正しました。それらもリストに追加されました
  • 端末の括弧で囲まれた貼り付けモードがセッション中にリセットされた後、貼り付けられた複数行のテキストが行ごとに送信される問題を修正しました
  • SessionStart フックを使用したプロジェクトで、起動時にプロンプトのサンプル テキストが点滅したり消えたりする問題を修正しました。
  • 全画面モードで起動したときに最初のフレームの前に空白の画面が点滅する問題を修正しました
  • 端末よりも高いまま画面が短くなった後、非フルスクリーン レンダラーで文字化けし、間違って配置された行を修正しました。シェルコマンドが出力をストリーミングしている間にプロンプトラインを削除する
  • 再描画された行の CJK 文字または絵文字が次の行に折り返されたときに、差分の最後の列に古い文字が残る問題を修正しました
  • プロンプトにタブが含まれている場合、履歴から呼び出されたプロンプトの終了前にカーソルが着地する問題を修正しました。
  • 改行として送信する端末 (1.25 より前の Windows 端末) で Ctrl+Enter を表示する今すぐ送信のヒントを修正しました。そこに ctrl+x ctrl+s が表示されるようになりました
  • Remote Control 自体の適格性エラーでは --debug で実行するように指示されているにもかかわらず、「不明な引数: --debug」で失敗する claude remote-control --debug を修正しました。
  • /install-github-app が「キャンセルされました」と表示した後、ブランチをプッシュして API キー シークレットを保存する問題を修正しました。ここで終了すると、残りのステップが停止され、すでに行われた内容が報告されます。

  • プラグインのアンインストールで、削除後にインストールされているプラグインのリストを読み取れなかった場合に、プラグインの保存されたオプションとシークレットが削除される問題を修正しました。それらは現在保持されており、アンインストールではそのように表示されます

claude-code v2.1.282

What's changed

  • Added a maxProseWidth setting that caps the width of Claude's prose in wide terminals while tables and code blocks keep the full width
  • Added a startup notice, and /status and claude doctor entries, listing telemetry variables in a project's settings files that were ignored or that turned telemetry off
  • Added the allowClaudeInChromeWithManagedMcp managed setting to let claude --chrome run alongside an exclusive managed-mcp.json; the error shown when Chrome is blocked now names it
  • Added store.readiness_grace_seconds to the Claude apps gateway so /readyz can stay ready through a short Postgres outage such as a database failover
  • Added a scrollbar to the /feedback drafts list in fullscreen mode; it appears while the mouse is over the list
  • Fixed every request failing with a 400 error in conversations whose history holds web search results the API cannot decrypt (for example, from a turn answered through a third-party gateway)
  • Fixed more cases of continued or resumed sessions (--continue, --resume) re-sending earlier messages in a changed form, which could make the API drop Claude's earlier reasoning
  • Fixed earlier extended thinking being dropped when /model, /rename, /artifacts or another immediate slash command was used while Claude was working
  • Fixed continued or resumed conversations losing earlier extended thinking when relaunched with a --tools list that leaves out a built-in tool offered earlier in the conversation
  • Fixed sessions failing on every turn with an "Invalid data in redacted_thinking block" API error; Claude Code now drops the conversation's thinking blocks and retries once
  • Fixed compaction failing when the summarization request is refused; it now retries on a fallback model
  • Fixed a failed turn ("Effort 'xhigh' isn't available with thinking turned off") after a safety-related model switch in sessions with thinking off and effort above high
  • Fixed an unanswered Fable usage-credits prompt switching models in SDK-hosted sessions such as Claude Desktop; the turn now ends instead, and Remote Control clients now see the model-switch notice
  • Fixed /model with a full Fable model id stopping at an API error instead of opening the usage-credits prompt when the plan needs usage credits that aren't turned on yet
  • Fixed requests failing for up to a minute with an "another Claude Code process is refreshing it" login error after that other process was closed or killed mid-refresh
