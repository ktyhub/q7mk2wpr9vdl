claude-code v2.1.330

パッチ 公開日2026年11月20日 出典anthropics/claude-code English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

クロードコード v2.1.330

何が変わったのか

  • Anthropic の Enterprise Admin Console で管理されている組織へのサインインを追加しました。claude auth login の後、Claude Code は組織の設定を適用し、そのクラウド プロバイダーまたはゲートウェイを使用します。
  • macOS と Linux 上の Pro、Max、および利用可能な場合は Team と Enterprise で、質問されたときに MCP メトリクス結果の下にチャートを描画する組み込み MOD であるイーゼルを追加しました。 /config で自動チャートをオフにする
  • 短いサインイン リンクでエラーが表示される場合、またはスクリプトがサインイン リンクから値を読み取る場合に、完全なサインイン リンクを印刷するための CLAUDE_CODE_FULL_SIGN_IN_LINK=1 を追加しました。
  • 自己ホスト型ランナー: クロードがリポジトリのフォルダー内で作業を開始するように --start-dir / SELF_HOSTED_RUNNER_START_DIR を追加しましたが、設定とフックはそれなしの場合と同様に読み込まれます。
  • リポジトリがセッションの 1 つではないためにプラグイン マーケットプレイスを取得できない場合のクラウドおよびセルフホスト ランナー セッションに通知を追加しました。
  • 自己ホスト型ランナー: Anthropic 管理の git がプラグイン自身のリポジトリを拒否した場合の通知、プラグインの名前と対処方法を追加しました。
  • commandPrinted を claude plugin install --json の結果に追加しました。プラグインのインストール コマンドが stderr に書き込んだ場合は true、エラーで終了した場合、強制終了またはタイムアウトされた場合は commandFailed を追加しました。
  • 自己ホスト ランナーの /metrics に claude_code_self_hosted_runner_order_to_registered_seconds を追加しました: オーケストレーターが生成したランナー上で、作業指示書が発行されてから登録が受け入れられるまでの秒数
  • 自己ホスト ランナーの /metrics に claude_code_self_hosted_runner_order_to_first_session_seconds を追加しました: セッションを開始したランナーの作業指示から最初のセッションが引き渡されるまでの秒数
  • 非常に長い会話を圧縮した直後にクロードコードが最大数分間フリーズする問題を修正
  • WebFetch が一部のページでセッションを数分間フリーズし、他のページでは空の結果を返す問題を修正しました
  • ExitWorktree と、別の実行中のクロード コード セッションが作業していたワークツリーを削除するワークツリー終了ダイアログを修正しました。
  • 複数のクロード コード プロセスが同時にユーザー設定を保存すると、ユーザー設定への変更が失われる問題を修正
  • 最後に保存されたメッセージのタイムスタンプが欠落しているか無効な場合に、空のセッションを開いたり失敗したりする --continue および --resume を修正しました。
  • Linux および WSL で、切断された接続で 3 分間待機して 2 分以上スリープした後の最初のプロンプトを修正しました
  • 多くの MCP ツールに API が拒否する入力スキーマがある場合に、「JSON スキーマが無効です」というエラーでターンが失敗し、セッション ファイルがメガバイト単位で増加する問題を修正しました。
  • Linux: node_modules などの大きな無視されるフォルダーを含む低速リポジトリで、Bash コマンドが数秒待機し、残りのセッションでファイルの差分が表示されない問題を修正しました。
  • Windows: カスタム起動ファイルのないマシンで、Git Bash の起動に 10 ～ 60 秒かかった後、セッションの残りの部分で Bash コマンドの実行が遅くなる問題を修正しました。
  • 2 つのキューに入れられたプロンプトまたはスタックされたスキルが変更されたターンの直後に一緒に実行された場合、/rewind がファイルの古いバージョンを復元することがある問題を修正しました
  • 許可プロンプトを承認するときに追加されたテキストと画像が、承認されたコマンドまたはツールが失敗したときにドロップされる問題を修正しました
  • ターミナルのプロンプト ボックスで @ メンションされた場合に、claude.ai コネクタとプラグイン サーバーからの MCP リソースが接続されない問題を修正しました。
  • 他のサブエージェントまたはセッションがまだ使用している間に、サブエージェントの 1 つが終了したときにサブエージェントがシャットダウンを宣言する MCP サーバーを修正しました
  • Chrome を開いてサインインしていても、短い接続の問題の後、Chrome のクロードが「接続されていない」ままになる問題を修正
  • Amazon Bedrock (Mantle) のターミナル セッションが固定された Opus モデルを無視してモデルが選択されていない状態で開始され、フォールバックを発表した後も利用できないデフォルト モデルを呼び出し続ける問題を修正しました。
  • 計画が全画面モードで到着したときに、入力していた残りの部分が失われる問題を修正しました
  • サーバー URL を共有するときに異なる名前を持つ claude.ai コネクタがドロップされる問題を修正しました (anthropics/claude-code#101856)
  • 複数の claude plugin コマンドを同時に実行すると、インストール済みリストからプラグインが欠落する問題を修正しました
  • 複数のタスクの更新を同時に実行するとタスクの依存関係とメタデータが失われる問題を修正
  • ディスクがいっぱいの場合、~/.claude.json の不完全なバックアップが保持され、正常なバックアップが置き換えられる問題を修正
  • パススコープのルールまたは読み取り拒否ルールを使用してプロジェクト内の数百のファイルをコードで読み取った後のコードモードでの長い一時停止を修正しました
  • クロードがコードモードで呼び出したときに組み込みのチャートツールが失敗する問題を修正しました
  • 自動およびバイパス権限モードでスクリプトからターンを終了するという MCP ツールのリクエストを無視するコード モードを修正しました
  • 自動モードのコードモードを修正し、スクリプトがスキルをロードした後にMODがメモを追加したときに、以前の思考を削除してプロンプトキャッシュを書き換えました。
  • Esc と /compact の後にスクリプトが読み取ったファイルをコード モードが復元しない問題を修正
  • クロードの最初の返信の前にコードモードでシステムツールを過小カウントする/contextを修正しました
  • 停止したバックグラウンド サブエージェントが停止したままにならないことがある問題を修正しました
  • アプリまたは SDK によって実行されるセッションで、終了と同時に停止されたバックグラウンド エージェントをクロードがまだ待機している問題を修正
  • 計画を承認した後、バックグラウンドセッションが以前の許可モードで起動することがある問題を修正
  • リモート コントロール: 電話または Web からの停止によって終了するバックグラウンド エージェントに関するメモが、端末に入力したかのように表示される問題を修正しました。
  • リモート コントロール: 会話中にオンにした後、モバイル アプリで差分ボタンとプル リクエスト ボタンが非表示になったり、停止したセッションが動作中として表示されたりする問題を修正しました。
  • SessionStart フックによって書き込まれた環境変数が claude -p --continue で失われる問題を修正
  • 出力がフルディスク上のファイルに送信されたときに、メッセージなしで 0 で終了する claude -p を修正しました。完全な NFS エクスポートが認識されない可能性がありますが、エラーを出力して 1 で終了するようになりました。
  • /context の後、最初のメッセージが表示される前にモデルが変更された場合に、システム プロンプトが以前のモデルの指示を維持するように修正しました。
  • ターン途中でモデルが変更された後、クロードがコミット帰属リマインダーに返信し、早期にターンを終了することがある問題を修正。管理された設定で PR アトリビューションラインが設定されている場合でも発生する可能性があります
  • 遅い言語サーバーまたはスタックした言語サーバーを待機している LSP ツール呼び出しを Esc で終了できない問題を修正
  • 言語サーバーがまだ起動している間にいくつかの呼び出しまたは編集が到着すると、LSP ツールの呼び出しと診断が失敗する問題を修正しました
  • プラグイン サーバーをビルトインとしてリストする /mcp を修正しました。プラグイン サーバーは「プラグイン MCP」の下に表示され、--mcp-config とビルトイン サーバーは「その他の MCP」の下に表示されるようになり、サーバーのページでそのプラグインに名前が付けられます。
  • MCP の許可リストまたは拒否リストで組み込みのグラフ ツールが除外され、ブロックされたままになると、起動するたびに表示される「MCP サーバーがエンタープライズ ポリシーによってブロックされています: イーゼル」という警告が表示される問題を修正しました。
  • /stats がローカル タイム ゾーンではなく UTC 日で新しいアクティビティをカウントする問題を修正しました
  • シェルが別のリポジトリに移動した後、/ultrareview が失敗するか、間違ったコードをレビューする問題を修正しました。シェルが停止し、両方のフォルダに名前を付けるようになりました。
  • 複数行モードなしでパターンに改行が含まれている場合に Grep が一致を報告しない問題を修正しました。拒否されたパターンを報告するようになりました
  • バイト オーダー マークを使用して保存された Jupyter ノートブックが、Read および NotebookEdit ツールによって無効な JSON として報告される問題を修正しました。
  • CLAUDE.md および HTML コメントを含むメモリ ファイルから削除されるリンク参照定義を修正しました
  • 実行中のモニターが終了するまで以前の会話をメモリ内に保持する問題を修正しました
  • コンテキスト ウィンドウより大きい PDF が長い会話の後に続くと、スケジュールされたタスク以外のサードパーティ プロバイダー上の一部のクロード デスクトップ セッションが「プロンプトが長すぎます」でターンが終了する問題を修正しました。
  • ファイル検索でリストされた順序に応じて、同じ名前を宣言する 2 つのユーザー ファイルまたはプロジェクト エージェント ファイルの選択を修正しました。
  • ログ ファイルがない場合に git リポジトリ内で claude daemon logs が存在しない問題を修正しました
  • 段落の後半で絵文字の前にバックスラッシュがある場合に、太字または斜体のテキストの後に 1 文字または 2 文字が隠れるマークダウンを修正しました。
  • クロード設定ファイル内の一部の有効なフック コマンドを編集が拒否する問題を修正しました
  • スキャンされた 2 ページの見開きの両半分を各ページに表示するページ範囲を持つ Read を修正しました
  • HTML アーティファクトの人魚図に改行とクラス ステレオタイプが欠落している問題を修正
  • /config のプロジェクト指示ピッカーで、24 行の全画面ウィンドウに 4 つの選択肢のうち 1 つだけが表示される問題を修正しました。
  • opusplan または haiku でプラン モードのプラン モード モデル上で実行されるサブエージェント自身のサブエージェントとフォークを修正しました。
  • ゲートウェイが小型高速モデルを拒否した場合に /effort レベルを無視する WebFetch ページの概要を修正しました
  • モデルが ANTHROPIC_MODEL または設定ファイルからのものである場合、Google Cloud のエージェント プラットフォームで claude -p が --settings '{"fastMode":true}' を無視する問題を修正しました。このような実行では高速モード料金で請求されるようになりました
  • 一時的なサーバー エラーまたは接続の切断後に forceLoginOrgUUID での起動が拒否される問題を修正
  • claude.ai コネクタに進む道を与えない claude mcp remove を修正しました。/mcp でオフにするか、claude.ai で削除するように指示されるようになりました。
  • claude.ai がクエリなしでサーバーの URL にコネクタを持っている場合に、/mcp の「claude.ai に接続」チェックで「接続されていません」と表示される問題を修正しました。
  • 保留中の通知と申し立てリンクの代わりに保留中のアカウントの一般的なエラーが表示される /install-github-app および /design-login を修正しました
  • セッションをバックグラウンドに移動すると、実行中の MCP タスクが停止済みとして報告される問題を修正しました。バックグラウンド セッションはタスクをフォローできるようになりましたが、サーバーが stdio を使用しているかヘッダーを設定している場合はフォローできません。
  • 失敗レポートが失われた後、またはセッションが同じランナーに戻された後、自己ホストランナーが終了するまでセッションを無視する問題を修正しました。
  • セルフホストセッションでプロンプトキャッシュが失われ、再起動で準備できなかったリポジトリのリストが変更されたときの以前の考え方を修正しました
  • 自己ホスト型ランナー: テレメトリがオフのセッションで、新しいランナーがプロンプトを引き継いだときに、許可プロンプトの背後でツール呼び出しが結果なしで消える問題を修正しました。
  • --push-outcome-on-release が設定されている場合に、大規模なリポジトリでプッシュされた作業を行わずに開始される再開されたセルフホスト ランナー セッションを修正しました
  • クロード コードが開始するたびにハングし、--startup-timeout-min が 2 から約 6 の場合に、自己ホスト型ランナー セッションが機能しているように表示される問題を修正しました。
  • Linux 上のセルフホスト ランナー セッションで、独自のシェルが終了コード 144 で終了する、またはランナーが終了する pkill -f を修正しました (pkill と --ignore-ancestors が必要です)
  • テレメトリがオフになっている場合、またはサードパーティのプロバイダーが使用されている場合に、所有者に通知するツールがない自己ホスト型ランナーのスケジュールされたタスクを修正しました
  • 自己ホスト型ランナー: オーケストレーターが空きスロットのセッションを要求できないようにする 1 つの遅い spawn-runner フックを修正しました。スロットが空いている間は 4 ～ 6 秒ごとにポーリングするようになりました。
  • セルフホスト ランナー: 不正なシークレットまたはトークンとしてログに記録される、IP ホワイトリストなどの 403 を修正しました。そのような行のほとんどはサーバーの理由につながるため、古い単語と一致するログ アラートを更新します。
  • ほとんどの種類の最初の検出で停止するリポジトリ設定のセルフホスト ランナーの警告モードを修正しました。これは、セッションあたり最大 50 まで継続し、早期に停止したかどうかを通知するようになりました。
  • 自己ホスト型ランナー: ディスクがいっぱいになった状態で開始してセッションを取得し、失敗するランナーを修正しました。彼らは部屋を待ち、作業指示から開始されない限り、セッションなしで 1 分後に終了します。
  • 自己ホスト型ランナー: ランナーのマシンに git 資格情報がない場合に再試行を示唆する失敗した開始を修正しました。エラーには、リポジトリが間違っている場合に誰に尋ねるか、何をすべきかが表示されるようになりました。
  • ランナーが一度もポーリングに成功しなかったときに、セルフホスト ランナーの last_poll_age_seconds が 0 を読み取る問題を修正しました。
  • 組織名を指定しないスケジュールされたタスクのスキップに関する通知を修正しました。実行中のセッション内の /resume ではタスクが実行されないため、--resume でクロード コードを開始するように指示されるようになりました。
  • MOD の AbovePrompt または AbovePromptList フックが VS Code で実行されないという誤った警告を表示する claude plugin validate を修正しました
  • Claude Design がファイルを変更した名前で保存したときに、アップロードしたばかりのファイルを削除する /design-sync を修正しました
  • max_tokens がモデルまたはゲートウェイの制限を超えた場合の 2.1.329 の自動再試行の削除を元に戻しました。
  • /login、claude auth login、claude setup-token によって表示される claude.ai サインイン リンクを改善しました。大幅に短くなりました。
  • Windows: ローカル パス上の各組み込み ripgrep 検索に対してコンソール ホストを起動する必要がなくなり、Grep および Glob の速度が向上しました。
  • ファイルの差分の速度を改善しました
  • /config 検索の改善: 名前が入力した内容で始まるほとんどの設定が最初に表示され、「努力」でモデルが検索され、「ダーク」または「ライト」でテーマが検索されます。
  • /resume の改善: /model などの画面を開いただけで終了したセッションはリストされなくなりました。
  • /mcp および /plugin での再接続の改善: サーバーで障害が発生したり、サインインが必要な場合でも、サーバーのページは開いたままになり、原因が表示されるようになりました。
  • サンドボックス拒否リストが長すぎる場合の macOS のエラーを改善しました。長いリストに名前を付け、それらを短縮する方法が表示されるようになりました。
  • 全画面モードでの /plugin の改善: エラーのあるプラグインのページは、それらのエラーから始まるようになりました。
  • チーム プランおよびエンタープライズ プランにおける /ultrareview のコスト確認を改善しました。通常のレビュー費用を下回る場合に、毎月の支出制限がどのくらい残っているかが表示されるようになりました。
  • Amazon Bedrock または Google Cloud のエージェント プラットフォームでのセルフホスト ランナー セッションを改善し、アカウントが最初のモデルを拒否したために別のデフォルト モデルで開始するときにそのように通知するようにしました。
  • Windows: セッションのフォルダーがドライブ上にある場合のエラーを改善しました。クロード コードが検証できません。その理由と、再試行で解決できるかどうかが表示されます。
  • 改善されたコード モード: クロードは画像と PDF の見方を教えられるようになりました。
  • 改善されたコード モード: Esc の後、停止したコマンドの下に赤いエラーの代わりに「中断」が表示されるようになりました。
  • コード モードの改善: サブエージェントのスクリプトが何千回ものツール呼び出しを行った後、端末がフリーズする時間が大幅に短縮されました。
  • 定期的なスケジュールされたタスクと /loop を、セッションの実行中は 7 日間ではなく最大 30 日間実行し、いつ終了するかを通知するように変更しました。このリリースより前に作成されたタスクは依然として 7 日で終了します
  • 承認を求めるために、ルート、ホーム、最上位フォルダー、または作業フォルダーを対象とした rm コマンドをさらに変更しました。誰も答えられない場合は拒否されます
  • deniedMcpServers 名前エントリを変更して、指定された claude.ai コネクタのみを非表示にし、その URL の他のコネクタを非表示にしました。それらをすべてブロックするには、その正確な URL を拒否します
  • ブランチを切り替えるための git コマンドを実行する代わりに出力するように、一部のセットアップで claude --teleport を変更しました。 -p では、切り替えるまで 1 から終了します。

  • チェックアウト フックがステータス 108 で終了した場合に、他のランナーを試行せずにセッションの開始をすぐに停止するように自己ホスト ランナーを変更しました。

  • Added sign-in to organizations managed in Anthropic's Enterprise Admin Console: after claude auth login, Claude Code applies the organization's settings and uses its cloud provider or gateway

  • Added CLAUDE_CODE_FULL_SIGN_IN_LINK=1 to print the full sign-in link, if the short one shows an error or a script reads values from it
