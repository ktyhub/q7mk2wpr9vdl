クロードコード v2.1.323

何が変わったのか

  • クロードがツールを呼び出すために JavaScript を書き込む実験的なオプトインであるコード モードを追加しました。組織に対して有効にするか無効にする場合は、https://code.claude.com/docs/en/code-mode を参照してください。
  • engines["claude-code"] を plugin.json に追加: 指定されたクロード コードのバージョン範囲外のプラグインはインストール、更新、またはロードされず、インストールおよび更新では適合する最新バージョンを選択してください。
  • プラグインの TypeScript フック モジュールの型チェックを claude plugin validate に追加しました。それぞれの結果は警告であり、--strict は失敗します。
  • claude plugin validate に $ 名詞が追加され、MOD の engine.create フックが追加、保留、または置換します。
  • サードパーティプロバイダーの Claude Desktop セッションの管理設定で CLAUDE_CODE_AUTO_MODE_MODEL のサポートを追加しました (Claude Desktop にこのバージョンが含まれると有効になります)
  • モデルがオフになっている、または使い果たされている使用クレジットが必要な場合のオプション メニュー (停止、使用クレジットへの切り替え、アップグレード) を追加しました。
  • claude -p および SDK セッションでフックが長時間実行されている間、30 秒ごとに進行状況ハートビートを追加しました。そのため、Claude Desktop などのホストはハングとしてターンを終了しません (このバージョンが含まれると)。
  • Artifact ツール アセットのアップロードに .docx サポートを追加しました
  • 差分パネルに /diff to close ヒントを追加し、パネルをフォーカスして閉じるキーを ? ショートカット ガイドに追加しました。
  • 変数の値に * (Bash(PORT=* npm run dev) など) を含む Bash 許可ルールの起動警告を追加しました
  • プラグインの言語サーバーを起動できない場合の警告、サーバーの名前と確認内容を追加しました
  • Perforce 設定が見つかり、モードがオフの場合に、CLAUDE_CODE_PERFORCE_MODE という名前の 1 回限りの起動通知を追加しました
  • CLAUDE_CODE_DISABLE_AGENT_PROGRESS_SUMMARIES を追加 (2.1.318 以降利用可能): 1 に設定すると、サブエージェントの進捗状況の概要とそれを書き込むリクエストがオフになります (anthropics/claude-code#86879)
  • CLAUDE_CODE_RESUME_HINT_COMMAND を追加しました。クロード コードを開始するプログラムは、終了ヒント名に独自の再開コマンドを付けるように設定できます。
  • claude plugin install --json 結果に unsetOptionCount を追加: まだ設定されていない userConfig オプションの数
  • MOD のペインが描画される小道具に isPromptCovered を追加し、ダイアログまたはプロンプトの上のフィールドがプロンプトをカバーするときを通知します。
  • /compact を再度実行するか、/context などのコマンドを実行した後、クロードがまだ応答していないメッセージを要約する問題を修正しました。
  • 再開されたセッションが、再開されなかった古い中断されたメッセージに次のメッセージを結合する問題を修正しました
  • クロードが非常に大きなファイルを変更した後の次のプロンプトでのメモリのスパイクを修正しました
  • 実行中のセッションに保存された設定が、直前に settings.json に加えられた手動編集を元に戻す問題を修正しました。セッション中に削除した設定ファイルは削除されたままになります
  • トークンの更新中に終了すると、claude plugin コマンドと claude mcp list がコンソール プロファイルからサインアウトする問題を修正しました
  • 特定の /proc ファイルでの Edit と Bash のメモリ不足、およびデバイスと名前付きパイプでの Edit のハングまたはメモリ不足を修正しました
  • 構成ファイルの保存が「メモリ不足」で失敗した場合、クロード コードが起動できない、またはサインアウト時に保存されている資格情報がクリアされない問題を修正しました。
