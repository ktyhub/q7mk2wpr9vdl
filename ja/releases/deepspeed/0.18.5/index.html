DeepSpeed v0.18.5

Highlights

  • ZeRO-3 checkpointing & backward correctness — PR #7780 fixes gradient checkpointing when use_reentrant=True is paired with PyTorch-style backward and ZeRO-3, a combination that could silently yield wrong gradients; #7787 repairs backward for the pipeline engine, and #7789 skips empty parameters during gradient reduction. If you train on ZeRO-3 + checkpointing + pipeline parallelism, upgrade before trusting continued runs.
  • BF16 optimizer path changes — PRs #7788, #7790, and #7803 correct how DeepSpeed selects the BF16 optimizer: BF16_Optimizer is no longer applied when ZeRO is off, and is now chosen at the correct ZeRO stage. PR #7786 also fixes checkpoint save/load for ZeRO-0 + BF16. This alters which optimizer actually runs for BF16 configs, so sanity-check loss curves after upgrading.
  • ZeRO-3 communication optimizations — PR #7661 adds a sequential allgather optimization, #7805 fixes ping-pong buffer index resets and removes a redundant stream sync, and #7769 skips compressed allreduce on empty tensors. Net effect: less communication overhead and fewer syncs, most noticeably with compression enabled — a free throughput win with no config change.
  • Apple Silicon (MPS) support — PR #7767 lands a batch of MPS fixes, making this release substantially more usable on macOS/M-series GPUs. Worth retrying local DeepSpeed runs on Apple hardware if you were previously blocked.
  • Sequence parallelism & Evoformer — PR #7809 resolves a rank-index-out-of-range during backward when sp_size < world_size in Ulysses, #7784 fixes the Ulysses PEFT test, and #7760 fixes Evoformer compilation. Important for context-parallel / long-context and protein-folding workloads; the Ulysses bug specifically affects uneven sequence-parallel vs. world sizes.
  • Mutating gathered parameters now fails loudly — PR #7817 makes DeepSpeed raise a clear error on in-place edits to GatheredParameters without modifier_rank. Previously such edits could silently fail to propagate back to sharded params; migration is to pass modifier_rank (and use the context manager) when mutating gathered tensors. (Also note #7802 fixes the Muon optimizer's module path if you import it directly.)

No breaking changes.
