DeepSpeed v0.19.1

Highlights

  • Broader PyTorch compatibility — ZeRO-3 now handles modules with plain dict _parameters (#8009), supports torch.func through setup_context (#7916), and enables vmap for LinearFunctionForZeroStage3 (#8023). DeepCompile’s AOT keyword patching is also fixed for PyTorch ≥ 2.11 (#8024), reducing failures for custom layers and advanced transform/compile workflows.
  • BF16 optimizer states with CPU offload — Support added in #8010 reduces host memory required for offloaded optimizer state. When migrating existing FP32-state jobs, validate convergence rather than assuming numerically identical training.
  • Lower-overhead distributed communication — Singleton MoE collectives are optimized (#7997), and ZeRO-3 gains an SDMA all-gather path through Mori (#7999). The latter can improve gather performance where Mori/SDMA hardware and configuration are available.
  • More attention backend coverage — EvoFormerAttention now auto-detects CUTLASS (#8000), removing manual backend setup, while FPDT attention supports flash-attn 2.7.0 (#8022). Existing attention configurations should require no migration, but verify backend selection for your GPU stack.
  • Improved long-run resource safety — FastFileWriter._fini now closes its AIO file descriptor (#8005), preventing gradual descriptor exhaustion during extended checkpoint or data-writing workloads.
  • Breaking changes — None listed.
