DeepSpeed v0.19.0

Highlights

  • AutoSP goes multimodal, and SP flips to a deny-list default — Sequence parallelism now covers ViT+LLM stacks (#7984), and SP selection changes from an allow-list to a deny-list (#7887). This is the most consequential behavior change in the release: SP is applied far more broadly by default, so models that previously ran without it may suddenly shard activations. Audit your model against the deny list before upgrading if you relied on the old opt-in behavior.
  • New optimizer and memory levers — Muon gains Gram Newton-Schulz orthogonalization (#7953), ZeRO-3 gets a dedicated defragmentation utility (#7940), and dynamic offload now composes with static optimizer offload (#7979). These are net-new capabilities for memory-constrained training and optimizer quality; the offload change (#7979) is worth testing if you mix the two offload modes, since that combination previously wasn't supported.
  • Correctness fixes that can shift your metrics — The "major" top-k gating bug (#7986), a BF16_Optimizer last-microbatch gradient leak under ZeRO-1 (#7985), ZeRO-1/2 CPU-offloaded gradient norm (#7967) and gradient loss across multiple backward() calls per step (#7981), Adam subgroup inconsistency (#7982), and a flat-buffer detach to avoid in-place autograd errors with CP (#7948). If you train MoE models or CPU-offloaded ZeRO-1/2, re-baseline your runs — results may legitimately change.
  • DeepCompile on PyTorch 2.9/2.10 — Fixes DeepCompile+ZeRO-3 on PyTorch 2.9/2.10 (#7951) and spurious backward-graph recompilation caused by unbalanced forward/backward visits (#7980). Practical impact is fewer cache misses and more stable compile times; prioritize this upgrade if you're pinned to 2.9/2.10 with DeepCompile enabled.
  • Stability, builds, and observability — Process-group shutdown hang resolved (#7941) and overlap-communication buffer lifetimes corrected (#7965) for cleaner distributed teardown; FPQuantizer build and CUDA correctness repaired (UB/negative-shift warnings #7973, duplicate or wrong -gencode flags #7974, template-parameter cleanup #7976); WarmupCosineLR multi-group initialization fixed (#7969); and a new DeepSpeed NVTX domain (#7988) for more precise profiling.
  • Breaking changes — No explicit breaking API changes; review the SP allow→deny default (#7887) as the main behavioral shift.
