#v0.98.0をクラッシュする

Rex、OSC 7501、xAI/Grok OAuth など

おい！このリリースには、生活の質に優れたものがいくつか含まれています。見てみましょう！

レックスの時間です

Bubbletea のアップデートに続き、Crush は Program Status Protocol、別名 OSC 7501、Superlogical for Rex によって作成 をサポートするようになりました。おまけに、TUIOS もこのプロトコルをサポートしています。

x.AI OAuth

Crush は Grok OAuth ログインをサポートするようになりました。楽しむ！

<p><img width="550" src="https://github.com/user-attachments/assets/7663d52a-b5af-4969-972b-7db1189106b4" /></p>

さらに多くの修正

このバージョンでは多くの修正が導入されました。

  • @meowgorithm によるサーバー側の改善
  • 外部エディタが空のバッファを飲み込む
  • OAuth の背後にあるモデルは、Catwalk にない場合は使用できませんでした
  • MCP の切り替えの不正動作を修正

@tacturnaxolotl からはさらに多くの情報が寄せられました。以下をすべて読んでください！

幸運を祈ります。 チャーム XX 👋🏻

<summary>アーティファクトの確認</summary>

まず、checksums.txt ファイル と checksums.txt.sigstore.json ファイル ファイルを、たとえば wget でダウンロードします。

wget 'https://github.com/charmbracelet/crush/releases/download/v0.98.0/checksums.txt'
wget 'https://github.com/charmbracelet/crush/releases/download/v0.98.0/checksums.txt.sigstore.json'

次に、cosign を使用して検証します。

cosign verify-blob \
  --certificate-identity-regexp '^https://github.com/charmbracelet/crush/\.github/workflows/(release|nightly)\.yml@' \
  --certificate-oidc-issuer 'https://token.actions.githubusercontent.com' \
  --bundle 'checksums.txt.sigstore.json' \
  ./checksums.txt

出力が Verified OK の場合は、sha256sum を使用してリリースからダウンロードした他のアーティファクトのチェックサムを検証するために安全に使用できます。

sha256sum --ignore-missing -c checksums.txt

完了！これでアーティファクトが確認されました。

</詳細>

crush v0.98.0

Rex, OSC 7501, xAI/Grok OAuth and more

Hey! There’s some good quality of life stuff in this release. Let’s take a look!

It’s Rex Time

Following an update on Bubbletea Crush now supports the Program Status Protocol, aka OSC 7501, created by Superlogical for Rex! As a bonus, TUIOS also supports the protocol.

<p><img width="700" src="https://github.com/user-attachments/assets/85680681-9397-456b-8283-4eed19635681" /></p>

x.AI OAuth

Now Crush supports Grok OAuth login. Enjoy!

<p><img width="550" src="https://github.com/user-attachments/assets/7663d52a-b5af-4969-972b-7db1189106b4" /></p>

Many more fixes

A lot of fixes were introduced this version:

  • Server side improvements by @meowgorithm
  • External editor swallowing empty buffer
  • Models behind OAuth couldn't be used if they weren't in Catwalk
  • Fixed MCP toggled misbehavior

And a lot more from @taciturnaxolotl. Read all below!

Good luck, Charm XX 👋🏻
