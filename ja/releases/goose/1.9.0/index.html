goose v1.9.0

マイナー 公開日2025年9月24日 出典aaif-goose/goose English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#ガチョウv1.9.0

  • 雑用: openapi 仕様バージョンを更新する
  • 雑務(リリース): リリースバージョン 1.9.0
  • 修正: ビューはディレクトリを認識できます (#4701)
  • goosed スタンドアロンはプロバイダーと連携します (#4698)
  • コンテキスト長を超えた場合のストリーミング プロバイダーのセッションを自動的にコンパクト化 (#4565)
  • 開発者拡張機能がキャンセル メッセージを受け取った場合、それが所有する実行中のプロセスを強制終了する必要があります。 (#4604)
  • いくつかの未使用のものを削除する (#4388)
  • 易経 MCP を拡張カタログに追加 (#4525)
  • 会話が長くなりすぎた場合は、会話を要約または終了するよう申し出ます… (#4688)
  • リファクタリング(forge): 絶対パスをサポートするためにdesktopTemplateを採用する(#4084)
  • fix(nix): 既存のビルドプロセスに欠落しており、開発プロセスで役立つ nixpkg を追加 (#4490)
  • feat(acp): ツール名のより適切な書式設定を追加 (#4686)
  • 外部バックエンド使用時の gui client 初期化を修正 (#4669)
  • 偉業(acp): エージェント-client-プロトコルをアップグレードし、ツールのエクスペリエンスを向上させます (#4683)
  • サブレシピの使用に関するブログ投稿 (#4647)
  • 修正: コメントのコントラストと読みやすさのために oneDark テーマを改善 (#4655)
  • 修正: ディクテーションプロバイダーのドロップダウンが切れる (#4673)
  • 修正: 最初の /reply 呼び出しで ui から実行されるレシピのみをメトリクスする (#4679)
  • 修正: レシピの説明またはレンダリングをレシピの使用法としてカウントしない (#4678)
  • より堅牢なテストファインダーパッチ処理 (#4667)
  • 修正(圧縮): より多くのコンテキスト制限を超えたエラーを捕捉して圧縮しようとします (#4656)
  • chore(mcp): mcp に rust sdk を使用するようにメモリ mcp サーバーを変換します (#4668)
  • chore(mcp): mcp に rust sdk を使用するようにチュートリアル mcp サーバーを変換します (#4665)
  • テスト: RepetitionInspector::check_tool_call のテスト カバレッジを追加 (#4666)
  • chore(mcp): mcp に rust sdk を使用するように自動ビジュアライザーを変換します (#4664)
  • sh 構文を使用するように test-finder.yml を更新 (#4663)
  • セッションディレクトリ検証の問題を回避するために --path フラグを削除 (#4662)
  • テストファインダーワークフローを修正: 開発者拡張機能を有効にし、トークンメトリクスを追加 (#4661)
  • ドキュメント: レシピビデオカルーセル (#4660)
  • 修正: 最終的な構造化出力が欠落しているため、モデルにガイダンスを提供する必要があります (#4654)
  • 修正 #4550: xlsx ツールでの行/列の転置を修正 (#4622)
  • 修正: #4634 #4636 は常に絶対パスを推奨するとは限りません (#4641)
  • 修正(1718): Goose.app の起動時に --dir が機能するようにしました (#4642)
  • 弱い LLM の str_replace 命令をソフト化 (#4639)
  • ドキュメント: ロゴを変更しました (#4633)
  • 開発者拡張機能に analyze ツールを追加 (#4530)
  • インポートフォームにレシピタイトルを追加 (#4625)
  • デスクトップ json レシピのアップロード (#4629)
  • ノードメインでのエラーのキャッチ (#4627)
  • chore(deps-dev): /ui/desktop で vite を 7.1.3 から 7.1.5 にバンプします (#4583)
  • ドキュメント: Rube 拡張ドキュメントとサーバー構成を追加 (#4556)
  • レシピが受け入れられアクティブな場合、常にチャットの上部にレシピアクティビティを表示します (#4616)
  • UI のアクティビティにパラメータ置換を追加 (#4617)
  • UI レシピは無効、重複、未使用のパラメータをフィルタリングします (#4615)
  • gpt-5 入力コンテキスト制限を修正 (#4619)
  • [ドキュメント] MCP-UI ブログ投稿 (#4578)
  • リリース/1.8.0 (#4577)
  • 修正: docker ビルドには sha より前の有効な文字列が含まれていました (#4613)
  • レシピ作成のメッセージに対して会話フィクサーを実行する (#4605)
  • ドキュメント: github コパイロット構成の回避策 (#4607)
  • レシピスキーマ検証を UI に追加 (#4602)
  • ドキュメント: 組み込み拡張機能リストを更新し、リンクを修正 (#4601)
  • 可視性制御用のメッセージ メタデータを追加 (#4538)
  • 非推奨の Claude 3.5 モデルを削除 (#4590)
  • 未使用のloadRecipe関数を削除(#4599)
  • decodeRecipe でシークレットを送信 (#4597)
  • コンテンツをオーバーフローするマークダウン リンクを修正し、エージェント リンクのプレビューを非表示にする (#4585)
  • リファクタリング: 新しいレシピ依存関係アップデーターを追加 (#4596)
  • 雑用: 夜間のビルドを修正してタグを付ける (#4595)
  • 特技: レシピ「file」入力タイプパラメータからファイルコンテンツをインポート (#4558)
  • レシピ用に送信する api キーにもこの変更を追加 (#4587)
  • ローカル (作業ディレクトリ) のレシピ ストレージを修正 (#4588)
  • 修正: ツール呼び出しを編集しない (#4589)
  • 即時噴射検出 (簡略化 - パターンマッチングのみ) (#4237)
  • 特技: Tetrate Agent Router Service プロバイダーにストリーミング サポートを追加 (#4477)
  • ドキュメント: グースヒントの更新 (#4581)
  • Iand/レシピスキャナーのアップデート (#4584)
  • 権限変更のためのパッチ適用レシピスキャンワークフロー (#4579)
