goose v1.6.0

#ガチョウv1.6.0

  • 雑務: openapi 仕様バージョンのバンプ
  • 雑務(リリース): リリースバージョン 1.6.0
  • 修正: レシピパラメータが常に置き換えられない (#4207)
  • 雑用: ほとんど使用されていないセッション共有機能を削除する (#4249)
  • エージェントが応答すると自動スクロールを停止し、スクロール領域で一番下までスクロールできるようにします (#4257)
  • クリーンアップ中の誤った削除から cli プロジェクトを復元 (#4266)
  • 修正: ヘッダー構成のダイアログを表示するためのディープ リンク拡張機能のインストール (#4150)
  • 特技: 割り込み処理を備えたメッセージ キュー システムを追加 (#4179)
  • 拡張機能を同時に開始する (#4234)
  • 交換時に X-Title とリファラーヘッダーを Tetrate に追加 (#4250)
  • ドキュメント: [レシピの表示/編集] メニュー項目名を更新 (#4267)
  • 未使用のゲームを削除 (#4226)
  • 初期化後にアプリがホームにリダイレクトされるが、ユーザーがすでにチャットを開始している問題を修正 (#4260)
  • 機能: プロバイダーが要約用の高速モデルを構成できるようにする (#4228)
  • ドキュメント: ツール選択戦略の更新 (#4258)
  • 特技: @mcp-ui/client パッケージをアップグレードし、UI メッセージ処理を改善しました (#4164)
  • 作業ディレクトリを変更するときにチャットウィンドウを置き換えないようにしました (#4200)
  • ストリーミング中のリセットを避けるために、チャット状態がアイドルのときにのみセッション トークンをフェッチします (#4104)
  • e2e テストのタイムアウトをバンプする (#4251)
  • ドキュメント: カスタム コンテキスト ファイルの改善 (#4096)
  • 雑務: rmcp を 0.6.0 にアップグレードする (#4243)
  • ドキュメント: npx ではなく uvx (#4240)
  • Tetrate Agent Router Service の PKCE サポートを追加 (#4165)
  • デフォルトでAGENTS.mdを読み取る (#4232)
  • ドキュメント: プロバイダーとモデルを構成する (#4235)
  • ドキュメント: figma チュートリアルを追加 (#4231)
  • 再現可能なビルドのために Nix フレークを追加 (#4213)
  • 強化されたオンボーディング ページのビジュアル デザイン (#4156)
  • 特技: すべてのプロバイダーに mtls を追加 (#2794) (#2799)
  • 終了の確認ダイアログを表示しない (#4225)
  • 修正: CLI /mode ヘルプ テキストとエラー メッセージに Smart_approve がありません (#4132)
  • langfuse のドキュメントとスクリプトをクリーンアップ (#4220)
  • 特技: マークダウンで単一の改行を保持するリマークブレークプラグインを追加 (#4217)
  • feat(mcp/developer): insert_line 番号として -1 を受け入れます (#4112)
  • デッドコードと古い設定の移行を削除 (#4180)
  • lint ステージングからテストを削除 (#4203)
  • ドキュメント: openrouter と ollam の簡単なデスクトップ セットアップ (#4195)
  • カスタムプロバイダーの更新 (#4099)
  • ドキュメント: goose_terminal 環境変数 (#4205)
  • レシピ内で疑わしい Unicode 文字が見つかった場合のデスクトップ アラート (#4080)
  • 雑務: Google ドライブの組み込み拡張機能を削除する (#4187)
  • アプリの初期化を移動する (#4185)
  • 未使用の拡張機能を削除 (#4166)
  • 拡張機能のテストを追加しました (#3794)
  • 雑務(リリース): リリースバージョン 1.5.0 (#4169)
  • アップストリームの変更によるテストを修正し、lint ステージングおよび CI にテストを追加します (#4127)
  • figma チュートリアルのリストを解除 (#4186)
  • feat(ui): 再応答を伴うインプレースメッセージ編集の実装 (#3798)
  • 500 コードをすべて再試行 (#4160)
  • ブログ: Goose Mentor モードによる AI 支援の変革 (#4151)
  • すべての npm パッケージをアップグレードし、関連する問題を修正しました (#4072)
  • ドキュメント: グースヒントの @-メンション (#4171)
