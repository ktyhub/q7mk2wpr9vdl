#グースv1.22.0

グース v1.22.0 Release Notes

リリース日: 2026 年 1 月 29 日

✨ 新機能

  • セッション フォーク - 既存のセッションをフォークして、@wpfleger96 による新しい会話分岐 (#5882) を作成します
  • 折りたたみ可能なチャット ナビゲーション - チャット ナビゲーションは、@zanesq により、よりクリーンな UI のために折りたたみ可能になりました (#6649)

  • Codex サブスクリプションのサポート - @michaelneale による Codex サブスクリプション (#6600) のサポートを追加しました
  • 外部エディタのサポート - vim、helix などの外部エディタを使用します (#5823) by @peterwilli
  • 診断ビューアー - デバッグ用の新しい診断ビューアー (#6770) by @DOsinga
  • OVHcloud AI プロバイダー - @rbeuque74 により、OVHcloud AI を新しいプロバイダー オプションとして追加しました (#6527)
  • レシピの最大ターン数 - @jhult によるレシピとサブエージェント (#6687) に max_turns 設定を追加しました
  • コンテナ拡張機能 - コンテナ内で拡張機能を実行するオプション (#6590) by @jamadeo
  • カスタム プロバイダー認証フラグ - 認証なしのカスタム プロバイダーの requires_auth フラグ (#6705) by @rabi
  • Bedrock 用 AWS Bearer Token - @andreswebs による AWS_BEARER_TOKEN_BEDROCK 環境変数 (#6739) のサポート
  • Anthropic カスタム ヘッダー - @DOsinga による Anthropic プロバイダー (#6774) によるカスタム ヘッダーのサポート
  • コードモードのスキル - @michaelneale によるスキルがコードモードで利用可能になりました (#6763)
  • OSS スキル マーケットプレイス - 新しいオープンソース スキル マーケットプレイス (#6752) @EbonyLouis 作成
  • Vibe MCP アプリ - 新しい MCP アプリ機能 (#6569) by @DOsinga
  • PR コード レビュー - コード レビュー機能 (#6043) by @valeriikot

🐛 バグ修正

  • macOS キーチェーン ループ - @sheikhlimon による macOS キーチェーン (#6620) の無限プロンプト ループを修正しました

  • 空のメッセージ エラー - @Yorisoft による OpenAI 形式 (#6511) の空のメッセージでエラーを返す
  • スラッシュ/@ キーボード ナビゲーション - @zanesq によるポップオーバーの背景色 (#6550) を修正しました
  • 未保存の変更インジケーター - @zanesq による拡張機能 (#6743) に表示される誤った「未保存の変更」を修正しました
  • チャット入力幅 - @zanesq により、特定の幅でアクション ボタンの下に表示されるテキストを修正しました (#6751)
  • レシピ拡張機能の読み込み - デスクトップに読み込まれないレシピ拡張機能を修正しました (#6777) by @zanesq

  • OpenRouter カスタム モデル - @rabi による OpenRouter (#6761) のカスタム モデル エントリを有効にします
  • Gemini サブエージェント - @rabi による Gemini モデルのサブエージェント (#6513) が再度有効になりました
  • Google 思考署名 - @rabi によるストリーミング応答 (#6708) に思考署名を保存します。
  • read_resource_tool Deadlock - test_compaction のハングを引き起こすデッドロックを修正しました (#6737) by @lifeizhou-ap
  • Codex 推論の労力 - @fgsch による推論の労力の変換 (#6523) を修正しました
  • GCP Vertex AI グローバル エンドポイント - @clouatre による Gemini 3 モデル (#6187) のグローバル エンドポイント サポートを修正しました
  • ADD_ACTIVE_SESSION イベント - @jhult による「すべて表示」から移動する前にイベントをディスパッチします (#6679)
  • イレブンラボ API キー - @Abhijay007 による API キーが永続化されない問題を修正しました (#6557)
  • Flatpak リリース - @The-Best-Codes による flatpak ファイル (#6696) が見つからないリリース ワークフローを修正しました
  • MCP アプリの幅 - @Abhijay007 による MCP アプリのサイズ変更通知 (#6376) の幅パラメーターを尊重します
  • 拡張機能名の正規化 - @rabi による ExtensionManager (#6529) で拡張機能名を一貫して正規化します
  • シェル ストリーミング出力 - @rabi によるシェル ストリーミング出力 (#6558) の GOOSE_CLI_MIN_PRIORITY を尊重します。
  • Google JSON スキーマ - 完全な JSON スキーマ サポート (#6555) には、パラメータ JsonSchema を使用します (@rabi)
  • コンパイルの問題 - メイン (#6776) のコンパイルの問題に @alexhancock によって対処されます。
  • エラー メッセージの行番号 - @lifeizhou-ap によるエラー メッセージの行番号 (#6736) を削除しました
