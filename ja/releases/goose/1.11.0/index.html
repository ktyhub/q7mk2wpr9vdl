#ガチョウv1.11.0

  • 修正: openai ツールの正しいスキーマ (#5229)
  • 雑務: openapi バージョンのバンプ
  • 雑務(リリース): リリースバージョン 1.11.0
  • 圧縮を check_ および do_ 圧縮に戻す (#5212)
  • 修正: ビルドされたアプリ名を大文字の Goose に戻す (#5206)
  • 特技: コード ドキュメント ジェネレーター レシピを追加 (#5121) (#5125)
  • 「機能: 簡単に呼び出せるようにセッションを検索するためにグースを強化する (#5177)」 (#5209) を元に戻します
  • ブログ: goose を使用した迅速なエンジニアリングのベスト プラクティス (#5204)
  • セッション作成後に WAL 同期を強制する (#5202)
  • 機能: ガチョウ Apify MCP 統合ドキュメント (#5047)
  • 特技: グースを強化してセッションを検索し、簡単に思い出すことができます (#5177)
  • 隠しフォーマットと実フォーマットをスキップ (#5194)
  • ドキュメント: Hacktoberfest ブログ投稿 - エンタープライズ環境で Goose を使用するためのベスト プラクティス (Anudhyan Datta 著)。 (#5184)
  • ドキュメント: プロンプトインジェクション検出 (#5193)
  • mcp の大きな応答競合状態を修正 (#5065)
  • 圧縮オーバーホール (#5186)
  • 修正: #3960 動的タスクパラメータの入力スキーマへのより良いアプローチ (#5189)
  • レシピ ID またはディープリンクを使用してエージェントを起動しました (#5154)
  • [ドキュメント] ブログ投稿を追加:「LLM だけでなくユーザーのための AI の設計」(#5190)
  • ドキュメント: cognee、jetbrains、mbot 拡張設定の更新 (#5172)
  • 自律モデルではない場合、サブエージェントを最小限に無効にします (#5149)
  • プロバイダーのソートを修正 (#5188)
  • ブログ: Windows での Goose 入門 (#5156)
  • 特技: CI/CD パイプライン レシピを追加 (#5183)
  • 特技: Daily Standup Report Generator レシピを追加 (#5123) (#5131)
  • プロバイダーをアルファベット順またはランダムに並べ替えます (#5090)
  • 宣言型プロバイダー (#5084)
  • Firecrawl mcp チュートリアルに YouTube リンクを追加、東部時間 10 月 15 日午前 9 時以降にマージ (#5173)
  • Ollama 統合: 変更されたデフォルト モデル + 追加されたモデル (#5153)
  • ドキュメント内のコーデックス サブエージェント設定を修正 (#5180)
  • 修正: デスクトップ アプリの Apple Silicon ビルドをビルド アーティファクトに含める (#5174)
  • ビデオの埋め込みを修正 (#5171)
  • 雑務: 未使用のファイルをランダムにクリーンアップする (#5166)
  • 修正: OS 変数を許容しないように download_cli.sh を調整しました (#5169)
  • Firecrawl の mcp チュートリアル ページ (#5152)
  • 圧縮前に孤立したツール呼び出しを削除 (#5059)
  • 特技: マークダウンとしてコピー ボタンをドキュメント ページに追加 (#5158)
  • 雑用: ベンダー提供のノード実行可能ファイルを含める (#5160)
  • メッセージから余分な空白を削除 (#5159)
  • 使用後にディープリンクをクリアする (#5128)
  • 「gpt-5 入力コンテキスト制限を修正 (#4619)」を元に戻す (#5135)
  • 修正: Windows ビルドの cmake と protobuf が欠落しており、sh/pws の重複を排除します… (#5028)
  • 基盤ツールの入力スキーマを修正 (#5064)
  • グース検証用のセルフテスト レシピを追加 (#5111)
  • 修正: 推論モデルの openai リクエスト ロジックを変更 (#4221) (#4294)
  • set_param と set_secret の場合の競合状態の脅威を修正… (#5109)
  • チャットプロセスのクリーンルーム実装 (#5079)
  • バンプrmcp (#5096)
  • テスト用に環境変数にバージョンを設定します (#5100)
  • 修正: Goose デスクトップのファジー ファイル検索を強化 (#5071)
  • 非同期にする (#5126)
  • ドキュメント: アーカイブまたは移動されたサーバーを含む拡張機能のチュートリアルのリストを解除 (#5116)
  • API Documentation Generator プロンプトを追加 (#5001)
  • 11 ラボの音声ディクテーションを有効にするためのフラグを追加 (#5095)
  • 命令内のカスタムパラメータの使用を取得するためにフィールドを強制的に再レンダリングします (#5112)
  • isUserInputDisabled を削除 (#5115)
  • analyze ツールの Rust 解析出力を改善 (#5072)
  • 重複した prepare_reply_context 呼び出しを削除 (#5063)
  • 開発中の反応開発ツールをインストールする (#4979)
  • ドキュメント: PowerShell インストール リンクをガイドに追加しました (#5012)
