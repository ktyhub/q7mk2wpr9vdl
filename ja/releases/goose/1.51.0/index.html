#グースv1.51.0

✨ 特徴

  • ACP プロンプト メタ #11247 を介してデスクトップをステート マシン ループにルーティングします
  • 宣言型プロバイダーとしての EUrouter #11619
  • 外部バックエンド ACP ソケットをリダイレクト解決されたバックエンド URL に接続します #11829
  • GPT ライブ API のサポート #12011
  • ゲートウェイ ペアリングのオペレーター許可リスト #11979
  • ターン終了時または承認が必要な場合のオプトイン端末ベル #10182
  • 外部バックエンド接続障害の本当の原因を報告する #11828
  • Toolshim のスコープをカスタム プロバイダーに設定 #11414

🐛 バグ修正

  • 自動コンパクト 100% を無効として扱う #11932
  • スケジューラで一貫してレシピを検証 #11561
  • MCP の優先バージョンと HTTP 再試行 #12066
  • ドクター コマンドには開発者拡張機能が必要 #11437
  • テキストやツールの呼び出しに先立ってストリーミング思考を維持する #11837
  • Anthropic プロバイダー層の保存思考コンプライアンス #11836
  • コンテキスト管理の依存関係の解決 #11768
  • アストラ オフをreasoning.effort noneにマッピングするのを停止 #11976
  • ヘッドレス実行が中断された場合のリターン失敗 #11938
  • OpenCode Go のセッション ID ヘッダーを送信 #11944
  • Google functionResponse 名を先行リクエストとペアリングします #11888
  • 失敗したツール呼び出しの出力をデスクトップに表示 #11940
  • 見つからないロケールでのセッション アクション メニューの翻訳 #11894
  • ゴールを求めるすべてのツール呼び出しでの再ナッジを停止 #11697
  • 開発者拡張機能 #11411 でバインドされたイメージ応答ボディ
  • MCP アプリ ツールを拡張機能の所有者にバインド #11416
  • ゲートウェイペアリングコードを保護 #11427
  • ディクテーション用にバインドされたローカル オーディオ リサンプリング #11379
  • セッションストレージ権限を制限する #11613
  • 1 つの検証済みスナップショットからレシピを構築 #11612
  • スケジュールされたセッションのコンテンツをフィルター #11603
  • LiteLLM のデフォルトでチャット完了をストリーム配信 #11870

🔧 改善点

  • ACP でインライン化できないリソース リンクを保持する #11941
  • CLI #12061 から計画モードを削除
  • CLI #11942 のレシピ作成コマンドを削除
  • チャット コンテンツの RTL サポート #11851
  • 中国語ローカリゼーションのモデルトークンには词元/詞元を使用する #11945
  • スケジュールされた実行でレシピの推論前の順序付けをガードする #11502

📚 ドキュメント

  • Inkeep 検索統合を削除 #12085
  • 拡張ディレクトリ ポリシーを明確にする #11923
  • RISC-V ビルドのサポート #11933

goose v1.51.0

✨ Features

  • Route Desktop to state-machine loop via ACP prompt meta #11247
  • EUrouter as a declarative provider #11619
  • Connect external backend ACP socket to redirect-resolved backend URL #11829
  • GPT-live API support #12011
  • Operator allowlist for gateway pairing #11979
  • Opt-in terminal bell when a turn finishes or approval is needed #10182
  • Report real cause of external backend connection failures #11828
  • Scope Toolshim to custom providers #11414

🐛 Bug Fixes

  • Treat auto-compact 100% as disabled #11932
  • Validate recipes consistently in scheduler #11561
  • MCP preferred version and HTTP retries #12066
  • Require Developer extension for doctor command #11437
  • Keep streamed thinking ahead of text and tool calls #11837
  • Preserved-thinking compliance for Anthropic provider layer #11836
  • Context management dependency resolution #11768
  • Stop mapping Astra Off to reasoning.effort none #11976
  • Return failure for interrupted headless runs #11938
  • Send session ID header for OpenCode Go #11944
  • Pair Google functionResponse names with preceding request #11888
  • Show output for failed tool calls in desktop #11940
  • Translate session actions menu in missing locales #11894
  • Stop re-nudging on every tool call for goals #11697
  • Bound image response bodies in developer extension #11411
  • Bind MCP app tools to extension owners #11416
  • Protect gateway pairing codes #11427
  • Bound local audio resampling for dictation #11379
  • Restrict session storage permissions #11613
  • Build recipes from one validated snapshot #11612
  • Filter scheduled session content #11603
  • Stream chat completions by default for LiteLLM #11870

🔧 Improvements

  • Preserve resource links that cannot be inlined in ACP #11941
  • Remove planning mode from the CLI #12061
  • Remove create recipe command in CLI #11942
  • RTL support for chat content #11851
  • Use 词元/詞元 for model tokens in Chinese localization #11945
  • Guard recipe-before-inference ordering on scheduled runs #11502

📚 Documentation

  • Remove Inkeep search integration #12085
  • Clarify extension directory policy #11923
  • RISC-V build support #11933
