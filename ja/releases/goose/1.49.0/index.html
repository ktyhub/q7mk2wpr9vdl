#グースv1.49.0

✨ 特徴

  • デスクトップアプリケーション用自動アップデータ #10614
  • Linux ARM64 デスクトップ リリース パッケージ #11518
  • 拡張機能をバックグラウンドでロードして、CLI プロンプトをすぐに使用できるようにします #10403
  • ワークフローステップではなく、件名によってセッションにタイトルを付ける #11135
  • チャット下部バーの対話型 git ブランチ インジケーター #11290
  • PreToolUse フック用 on_failure ブロック #11449
  • Web 検索およびブラウザー使用の組み込みスキル #11233
  • モデルネイティブ音声転写プロバイダー #10589
  • --with-extension は拡張子 #11127 に名前を付けることができるようになりました
  • ユーザーが入力を開始するとチャット入力にオートフォーカス #11184
  • スケジュールされたジョブ セッションをチャット履歴のアコーディオンに折りたたむ #11265
  • スケジュール作成時に保存レシピを選択 #10892
  • チャット フッター モデル ピッカーで最近使用されたモデルを表示 #11097
  • PreToolUseResult イベントとツールのライフサイクル全体にわたる安定した tool_call_id #11120
  • 設定されたプロバイダーをプロバイダー リストの先頭に並べ替えます #11409
  • OpenRouter session_id 転送とアプリ カテゴリ ヘッダー #10868
  • ACP 思考努力の導出と転送 #10949
  • GPT-5.6 のコーデックスとレスポンスのフォローアップ サポート API #10460
  • streamable_http 拡張機能用の事前登録された OAuth clients #11182
  • OTEL リクエスト パラメータ、レスポンス メタデータ、ツール呼び出しパリティ、およびエージェント ID #11261

新しいプロバイダー

  • 宣言型 OpenAI 互換プロバイダーとしての Opper #11589
  • Databricks Unity カタログ モデル サービスの検出 #11575
  • TrustedRouter 宣言型プロバイダー #11422
  • 宣言型プロバイダーとしての OpenCode Zen ゲートウェイ #10939
  • 宣言型 OpenAI 互換プロバイダーとしてのゴンドラ #11421
  • 宣言型 OpenAI 互換プロバイダーとしての SayGM #11267
  • 宣言型 OpenAI 互換プロバイダーとしての Lynkr #11372
  • PleumRouter 宣言型プロバイダー #10479
  • Z.ai GLM-5.3 (GLM-5.2 代替品) #11226
  • OpenAI GPT-5.6 (ソル/テラ/ルナ) (Bedrock 経由) #10502
  • コスト追跡用のカスタムプロバイダーコストフィールド #11220

🐛 バグ修正

  • プロバイダー API #11213 の背後にあるコンテキスト制限解決を統合しました。
  • リフレッシュ トークンなしで有効な MCP アクセス トークンを使用し続ける #11324

  • 同時サブエージェント通知を分離 #10772

  • minijinja ビルトインを再度有効にして、文書化されたレシピ フィルターが機能するようにします #11310
