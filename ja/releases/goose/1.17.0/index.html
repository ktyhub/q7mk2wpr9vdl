#ガチョウv1.17.0 #グース v1.17.0 はこちら

✨ 特徴

  • コード モード MCP - 「コード モード」MCP ツール呼び出し用のプラットフォーム拡張機能。強化されたコード実行機能を有効にします [#6030](https://github.com/block/goose/pull/6030)
  • MCP 誘導サポート - MCP の誘導サポート。ツール実行中の対話型プロンプトが可能 [#5965](https://github.com/block/goose/pull/5965)
  • 外部 Goosed サーバー - 外部 Goosed サーバー バックエンドへの接続のサポート [#5978](https://github.com/block/goose/pull/5978)
  • インセプション プロバイダー - 新しいインセプション プロバイダー [#6029](https://github.com/block/goose/pull/6029) による Mercury モデルのサポート
  • OpenAI 応答ストリーミング - OpenAI 応答のストリーミング サポート API [#5837](https://github.com/block/goose/pull/5837)
  • プロバイダーの正規モデル - プロバイダー全体で標準化されたモデル定義 [#5694](https://github.com/block/goose/pull/5694)
  • レシピの検索とフィルタリング - レシピ ビューの検索バーとフィルタリング [#6019](https://github.com/block/goose/pull/6019)
  • オンボーディング プロバイダーの検出 - オンボーディング中の API キーからの自動プロバイダー検出 [#5955](https://github.com/block/goose/pull/5955)
  • DataHub レシピ - DataHub でデータを検索および理解するためのレシピ [#5859](https://github.com/block/goose/pull/5859)
  • Flutter PR コード レビュー レシピ - Flutter プル リクエスト コード レビューのレシピ [#6011](https://github.com/block/goose/pull/6011)

🐛 バグ修正

  • プラットフォーム拡張機能は default_enabled 値 [#6159](https://github.com/block/goose/pull/6159) を尊重するようになりました。
  • 新しいセッションでのトークン状態の読み込み [#6129](https://github.com/block/goose/pull/6129)
  • 現在の年に関する LLM の混乱を防ぐために、日時情報メッセージがより明確になりました [#6101](https://github.com/block/goose/pull/6101)
  • データベースで開発者ロールの代わりにシステム ロールが使用される [#6098](https://github.com/block/goose/pull/6098)
  • ツールの結果を含む古いセッションが正しく読み込まれるようになりました [#6094](https://github.com/block/goose/pull/6094)
  • キューに入れられたメッセージに添付ファイルが含まれるようになりました [#5961](https://github.com/block/goose/pull/5961)
  • 更新ダイアログのプロバイダータイプのサフィックスが正しくありません [#5909](https://github.com/block/goose/pull/5909)
  • Linux goosed が libssl エラーでクラッシュする [#6051](https://github.com/block/goose/pull/6051)
  • PostHog のメトリクス [#6024](https://github.com/block/goose/pull/6024)
  • 拡張機能 [#6000](https://github.com/block/goose/pull/6000) の Windows 上の PATH
  • アクティビティでパラメータが置換されない [#5992](https://github.com/block/goose/pull/5992)
  • プロンプト [#6007](https://github.com/block/goose/pull/6007) のタイプミス

🔧 改善点

  • サブエージェントとサブレシピのツールを 1 つのツールに統合 [#5893](https://github.com/block/goose/pull/5893)
  • 内線番号のないサブエージェントは許可されなくなりました [#5825](https://github.com/block/goose/pull/5825)
  • ツール応答メタデータのサポート [#6074](https://github.com/block/goose/pull/6074)

  • リリースワークフローでのレシピリファレンスの自動更新 [#5988](https://github.com/block/goose/pull/5988)
  • /goose 問題解決ツール GitHub ワークフロー [#6068](https://github.com/block/goose/pull/6068)

✨ Features

  • Code Mode MCP - Platform extension for "code mode" MCP tool calling, enabling enhanced code execution capabilities [#6030](https://github.com/block/goose/pull/6030)
  • MCP Elicitation Support - Elicitation support for MCP, allowing interactive prompts during tool execution [#5965](https://github.com/block/goose/pull/5965)
  • External Goosed Server - Support for connecting to an external goosed server backend [#5978](https://github.com/block/goose/pull/5978)
  • Inception Provider - Mercury models support via the new Inception provider [#6029](https://github.com/block/goose/pull/6029)
  • OpenAI Responses Streaming - Streaming support for OpenAI responses API [#5837](https://github.com/block/goose/pull/5837)
  • Canonical Models for Providers - Standardized model definitions across providers [#5694](https://github.com/block/goose/pull/5694)
  • Recipe Search & Filtering - Search bar and filtering for recipes view [#6019](https://github.com/block/goose/pull/6019)
  • Onboarding Provider Detection - Automatic provider detection from API key during onboarding [#5955](https://github.com/block/goose/pull/5955)
  • DataHub Recipe - Recipe for searching and understanding data in DataHub [#5859](https://github.com/block/goose/pull/5859)
  • Flutter PR Code Review Recipe - Recipe for Flutter pull request code reviews [#6011](https://github.com/block/goose/pull/6011)
