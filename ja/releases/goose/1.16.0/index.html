#グースv1.16.0

🚀 特徴

  • プロバイダーの構成後にモーダルセレクターを表示する (#6005)
  • api キーからのオンボーディング検出プロバイダー (#5955)
  • 複数のファイルポップアップ (#5905)
  • Firefox 用のサイドバーのコンテキスト情報を追加しました (#5433)
  • 事前設定のためのレシピディープリンクパラメータを有効にする (#5757)
  • アクションが必要 (#5897)
  • ACP でのセッションのロードをサポート (#5942)
  • カスタム ヘッダーとトグル キーリング CLI オプションを追加しました (#5017)
  • アップデートの自動インストール (#5345)
  • 端末内の @goose (ネイティブ端末サポート) (#5887)
  • ALPHA フラグの後ろの拡張子セレクター (#5892)
  • Goose リモート アクセス (#5251)
  • katex 経由で数学/科学記号のサポートを追加 (#5773)
  • トーストでエラー メッセージを表示する機能を追加 (#5851)
  • SKILLS.md の実装 - クロード互換性 (#5760)
  • 診断にスケジューラを追加 (#5849)
  • コルとトークン (#5850)
  • URL からのマークダウン エクスポート (#5830)
  • エラープロキシ経由でアウトオブコンテキスト圧縮テストを追加 (#5805)
  • /agent/stop エンドポイントを追加し、アクティブなエージェントの最大数を構成可能にします (#5826)
  • プロバイダー名とモデル構成をセッション内に保持します (#5419)
  • スラッシュコマンド (#5718)
  • MCP-UI プロキシとメッセージ処理の改善 (#5487)
  • コミットトランザクション管理を使用して WAL を再度有効にしました (#5793)
  • さまざまなタイプのエラーをシミュレートするためのプロバイダー エラー プロキシ (#5091)
  • posthog のメトリクス (#6024)

🐛 バグ修正

  • アクティビティでパラメータが置換されない (#5992)
  • Anthropic からの final assistant content cannot end with trailing whitespace エラー (#5967)
  • Groq 構成の修正 (#5833)
  • プロンプトの変更を削除し、構成からモデルを読み取ります (#5976)
  • ロックを使用して、複数の障害が発生した場合に備えてトンネルのみを実行する必要があることを確認します… (#5885)
  • MOIM インジェクションチェックの受け入れ可能な問題に「連続したアシスタントメッセージのマージ」を追加 (#5933)
  • Anthropic プロバイダー モデルの取得 (#5932)
  • MCP-UI は画像の CSP をプロキシ HTML に追加します (#5931)
  • ブログ投稿のタイプミスを修正 (AIMDOEL -> AIMODEL) (#5902)
  • Agent.rs の奇妙な間隔を調整 (#5877)
  • 「レシピに拡張機能がない場合、アクティブな拡張機能をロードしない」を元に戻す (#5871)
  • マルチツール呼び出しを修正 (#5855)
  • 複数のコンテンツチャンクと画像の処理を改善 (#5839)
  • GitHub が MacOS のランナーを破損しました (#5853)
  • gemini compat の汎用チェック (#5842)
  • セッションが空のメッセージで戻ってくる (#5841)
  • 会話圧縮メッセージ タイプの下位互換性を追加 (#5819)
  • ハンドル 404 (#5791)
  • Windows シェル PATH を永続的に編集しないように setx 呼び出しを削除 (#5821)
  • gcp 頂点プロバイダーの maas モデルを解析します (#5816)
  • Gemini 3 の思考署名をサポート (#5806)
  • cron エラーをキャッチ (#5707)
  • 対話型およびログインシェルからパスを読み取る (#5774)
  • コミュニティオールスタースクリプトのクイック修正 (#5798)

✨ 改善点

  • 空のチャットでレシピアイコンを非表示にする (#6022)
  • Anthropic モデルと Google Gemini モデルを最新の API バージョンに更新します (#5980)
  • Fedora ユーザー向けのクリーンアップ マーカー ロジックを更新 (#5868)
  • BedrockProvider での AWS 認証情報の読み込みと設定処理を改善 (#5699)
  • レシピアクションを下部のバーアイコンに移動し、設定へのグースヒントを編集します (#5864)
  • rmcp を 0.9.1 (#5860) にアップグレードします
  • コンテンツを取得するときにテキスト/マークダウンの使用を提案する (#5854)
  • いくつかの古いコードがぶら下がっており、cli の設定について言及しています (#5822)
  • 次のキャンプ リファクタリング ライブ (#5706)
  • 不安定な mcp 呼び出し元をコメントアウトします (#5827)
  • Adrian Cole をメンテナーに追加 (#5815)
  • 自動操縦実験機能を削除 (#5781)
  • メンテナープロフィールへのリンクを追加 (#5788)
  • LFフィードバックを組み込む(#5787)
  • npm パッケージのアップグレード (#5951)

📚 ドキュメント

  • チャットリコールチュートリアル (#5975)
  • 私の評議会 MCP (#5979)
  • ナノバナナエクステンション (#5977)
  • マルチモデルページにビデオを追加 (#5938)
  • プランニングガイドのプロモーション (#5934)
  • AI に適した機能の追加 (#5918) ・AIアナウンスの到来(#5917)
  • ブログのタイプミスを修正 (#5896)
  • ブログの画像 URL を修正 (#5895)
  • 開発者向け MCP (#5884)
  • 拡張マネージャー MCP (#5883)
  • 「ソーシャル メディア エージェントの構築」ブログ投稿を追加 (#5844)
  • DataHub MCP サーバー拡張機能のドキュメントを追加 (#5769)
  • 残りのトピックの小文字のガチョウ (#5861)
  • スタートガイドおよびガイドのトピックの小文字のガチョウ (#5857)
  • macOS ドックのドキュメント新規ウィンドウ メニュー (#5811)
  • ACP clients (#5800)
  • ドキュメント Mistral AI プロバイダー (#5799)
  • コミュニティ スターのレシピ スクリプトと txt ファイルを追加 (#5776)
  • クイックランチャー (#5779) 完全な Changelog: v1.15.0...v1.16.0

🚀 Features
