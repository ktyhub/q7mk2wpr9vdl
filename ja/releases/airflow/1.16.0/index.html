airflow 1.16.0

エアフローヘルムチャート/1.16.0

重大な変更

デフォルトの git-sync イメージが 4.3.0 に更新されました (#41411)

チャートで使用されるデフォルトの git-sync イメージは 4.3.0, previously it was 4.1.0 になりました。

デフォルトのエアフロー画像が 2.10.5 に更新されました (#46624)

チャートで使用されるデフォルトのエアフロー画像は 2.10.5, previously it was 2.9.3 になりました。

デフォルトの PgBouncer イメージが 1.23.1 に更新されました (#47416)

チャートで使用されるデフォルトの PgBouncer イメージは airflow-pgbouncer-2025.03.05-1.23.1, previously it was airflow-pgbouncer-2024.01.19-1.21.0 になりました。

デフォルトの PgBouncer Exporter イメージが v0.18.0 に更新されました (#47416)

チャートで使用されるデフォルトの PgBouncer Exporter イメージは airflow-pgbouncer-exporter-2025.03.05-0.18.0, previously it was airflow-pgbouncer-exporter-2024.06.18-0.17.0 になりました。

デフォルトの StatsD エクスポータ イメージが v0.28.0 に更新されました (#43393)

チャートで使用されるデフォルトの StatsD エクスポータ イメージは、v0.28.0, previously it was v0.26.1 になりました。

新機能

  • ログ グルーマー サイドカー コンテナーにカスタム環境を渡すことを許可 (#46003)
  • Redis StatefulSet での既存の永続性クレームの使用を許可 (#41619)
  • トリガーに hostAliases サポートを追加 (#41725)
  • Airflow WebサーバーのHPAを有効にする (#41955)
  • データベース移行ジョブの環境サポートを追加 (#42345)
  • Redis サービスで NodePort をサポート (#41811)
  • DAG プロセッサーのハートビート メトリックを追加 (#42398)
  • StatsD ホストの ipv6 ipaddress 解決サポートを有効にするオプション (#42625)
  • ワーカーで podManagementPolicy をカスタマイズできるようにしました (#42673)
  • チャート内で複数のエグゼキューターをサポート (#43606、#44424)
  • ヘルム チャートで内部 RPC サーバーを API サーバーと交換する (#44463)
  • OpenSearch リモート ロギング オプションを追加 (#45082)
  • 花展開にstartupProbeを追加(#45012)
  • PgBouncer と StatsD イングレスを追加 (#41759)
  • ログのグルーミング頻度を制御する環境変数を追加 (#46237)

改善点

  • メトリクス名を更新して、複数のエグゼキュータがメトリクスをレポートできるようにしました (#40778)
  • ClusterIP サービスに特定の内部 IP アドレスを追加します (#40912)
  • スケジューラ自動化 ServiceAccount トークンを削除 (#44173)
  • PgBouncer シークレット設定の制御を強化 (#45248)
  • ti.running メトリクスのエクスポートを追加 (#47773)
  • startupProbe initialDelaySeconds のオプション構成を追加 (#47094)
  • worker.extraPorts を導入して追加のポートをワーカー コンテナに公開します (#46679)

バグ修正

  • AIRFLOW__CELERY__BROKER_URL_CMD when passwordSecretName を有効にする (#40270)
  • 終了猶予期間の秒数を適切に実装する (#41374)
  • Kerberos 環境をベースコンテナ環境に追加し、webserver-config ボリュームを追加します (#41645)
  • volumeClaimTemplates missing apiVersion and kind (#41771) を修正
  • グローバル ボリュームとボリューム マウントをクリーンアップ ジョブにレンダリング (#40191) (#42268)
  • Flower Ingress サービス参照を修正 (#41179)
  • ローカルおよび永続モードのスケジューラの volumeClaimTemplate を修正 (#42946)
  • 複数の実行者の役割バインディングを修正 (#44424)
  • KEDA ScaledObject でコンテナ名を envSourceContainerName に設定 (#44963)
  • 複数のエグゼキューターに対応するためにスケジューラーのデプロイメントを更新 (#46039)
  • メタデータ ラベル内の禁止文字を置換する (#46811)
  • Airflow API サーバーにポッド ログの読み取り権限を付与 (#47212)
  • マルチエグゼキュータのスケジューラ ServiceAccount 自動マウントを修正 (#46486)

ドキュメントのみが変更されます

  • extraInitContainers がジョブでサポートされていることをドキュメントに反映 (#41674)
  • Kubernetes Secret を使用して PgBouncer を使用する方法のガイドを追加 (#42460)
  • 説明のプライベート レジストリ パラメータを更新 (#43721)
  • Kerberos reinitFrequency の説明を変更 (#45343)
  • workers.safeToEvict のデフォルト値を反映するように Helm eviction 構成ガイドを更新 (#44852)
  • storageClassName がテンプレート化できるという情報を追加 (#45176)
  • 実稼働ガイドのブローカー URL シークレット名を修正 (#45863)
  • ドキュメント内の DAG を DAG に置き換えます (#47959)
  • airflowLocalSettings 値の説明を強化 (#47855)
  • テンプレート化されたパラメータの表記に一貫性を持たせる (#46481)

その他

  • Notes でテンプレート化されたホスト名をサポート (#41423)
  • デフォルトのエアフロー バージョンは 2.10.5 (#46624)
  • トリガー設定オプション default_capacity to capacity を変更する (#48032)
  • AIP-84 パブリック api を /api/v2 の下に移動 (#47760)
  • デフォルトはチャート内の FabAuthManager (#47976)
  • PgBouncer を 1.23.1 and PgBouncer exporter to 0.18.0 に更新します (#47416)
  • api サーバーをポート 8080 に移動 (#47310)
  • Airflow 3 で api サーバーを起動し、Airflow 2 で Web サーバーを起動します (#47085)
  • 移動 fastapi-api command to api-server (#47076)
  • 実行_api_server_url 設定をコアセクションに移動 (#46969)
  • Airflow 3 にスタンドアロンの DAG プロセッサを使用する (#45659)
  • quay.io/prometheus/statsd-exporter from v0.26.1 to v0.28.0 を更新 (#43393)

airflow helm-chart/1.16.0

Highlights

  • Airflow 3 is now the default architecture — The chart defaults to Airflow 2.10.5 (up from 2.9.3) and FabAuthManager (#46624, #47976). Airflow 3 deployments run a standalone DAG processor and API server, while Airflow 2 keeps the webserver (#45659, #47085); validate your airflowVersion, auth manager, and component topology before upgrading.
  • The public API moves to /api/v2 and port 8080 — AIP-84 relocates the public API under /api/v2, and the API server moves to port 8080 (#47760, #47310). Update ingress rules, service probes, health checks, and clients; the CLI command also changes from fastapi-api to api-server (#47076).
  • Multi-executor support is operationalized — The chart supports multiple executors, with executor-specific scheduler and role-binding fixes (#43606, #44424, #46039, #46486). Executor metric names and role bindings have changed to avoid collisions (#40778), so review custom RBAC, scheduler configuration, and Prometheus queries.
  • Infrastructure defaults receive substantial version bumps — git-sync rises to 4.3.0, PgBouncer to 1.23.1, PgBouncer Exporter to 0.18.0, and StatsD Exporter to 0.28.0 (#41411, #47416, #43393). These defaults affect repository synchronization, connection pooling, and metrics behavior even if your Airflow image is pinned.
  • More deployment-level controls are available — New options cover webserver HPA (#41955), Redis NodePort (#41811), existing Redis PVCs (#41619), worker extraPorts and podManagementPolicy (#46679, #42673), migration-job environment variables (#42345), and log-groomer sidecars and frequency (#46003, #46237).
  • Configuration and observability fixes need explicit review — The triggerer option default_capacity is renamed to capacity (#48032), execution_api_server_url moves into the core section (#46969), and new ti.running and DAG-processor heartbeat metrics improve task visibility (#47773, #42398). Review values overrides and alerting dashboards for renamed or relocated settings.

No breaking changes are explicitly identified in the upstream changelog.

Significant Changes

Default git-sync image is updated to 4.3.0 (#41411)

The default git-sync image that is used with the Chart is now 4.3.0, previously it was 4.1.0.

Default Airflow image is updated to 2.10.5 (#46624)

The default Airflow image that is used with the Chart is now 2.10.5, previously it was 2.9.3.

Default PgBouncer image is updated to 1.23.1 (#47416)

The default PgBouncer image that is used with the chart is now airflow-pgbouncer-2025.03.05-1.23.1, previously it was airflow-pgbouncer-2024.01.19-1.21.0.

Default PgBouncer Exporter image is updated to v0.18.0 (#47416)

The default PgBouncer Exporter image that is used with the chart is now airflow-pgbouncer-exporter-2025.03.05-0.18.0, previously it was airflow-pgbouncer-exporter-2024.06.18-0.17.0.

Default StatsD exporter image is updated to v0.28.0 (#43393)

The default StatsD exporter image that is used with the chart is now v0.28.0, previously it was v0.26.1.

New Features

  • Allow passing custom env to log groomer sidecar containers (#46003)
  • Allow using existing persistence claim in Redis StatefulSet (#41619)
  • Add hostAliases support in Triggerer (#41725)
  • Enable HPA for Airflow Webserver (#41955)
  • Add env support for database migration job (#42345)
  • Support NodePort on Redis Service (#41811)
  • Add heartbeat metric for DAG processor (#42398)
  • Option to enable ipv6 ipaddress resolve support for StatsD host (#42625)
  • Allow customizing podManagementPolicy in worker (#42673)
  • Support multiple executors in chart (#43606, #44424)
  • Swap internal RPC server for API server in the helm chart (#44463)
  • Add OpenSearch remote logging options (#45082)
  • Add startupProbe to flower deployment (#45012)
  • Add PgBouncer and StatsD ingress (#41759)
  • Add environment variable controlling the log grooming frequency (#46237)

Improvements

  • Update metrics names to allow multiple executors to report metrics (#40778)
  • Add a specific internal IP address for the ClusterIP service (#40912)
  • Remove scheduler automate ServiceAccount token (#44173)
  • More controls for PgBouncer secrets configuration (#45248)
  • Add ti.running metric export (#47773)
  • Add optional configuration for startupProbe initialDelaySeconds (#47094)
  • Introduce worker.extraPorts to expose additional ports to worker container (#46679)

Bug Fixes

  • Enable AIRFLOW__CELERY__BROKER_URL_CMD when passwordSecretName is true (#40270)
  • Properly implement termination grace period seconds (#41374)
  • Add kerberos env to base container env, add webserver-config volume (#41645)
  • Fix volumeClaimTemplates missing apiVersion and kind (#41771)
  • Render global volumes and volume mounts into cleanup job (#40191) (#42268)
  • Fix flower ingress service reference (#41179)
  • Fix volumeClaimTemplate for scheduler in local and persistent mode (#42946)
  • Fix role binding for multiple executors (#44424)
  • Set container name to envSourceContainerName in KEDA ScaledObject (#44963)
  • Update scheduler-deployment to cope with multiple executors (#46039)
  • Replace disallowed characters in metadata label (#46811)
  • Grant Airflow API Server Permission to Read Pod Logs (#47212)
  • Fix scheduler ServiceAccount auto-mount for multi-executor (#46486)

Doc only changes

  • Reflect in docs that extraInitContainers is supported for jobs (#41674)
  • Add guide how to PgBouncer with Kubernetes Secret (#42460)
  • Update descriptions private registry params (#43721)
  • Change description for kerberos reinitFrequency (#45343)
  • Update Helm eviction configuration guide to reflect workers.safeToEvict default value (#44852)
  • Add info that storageClassName can be templated (#45176)
  • Fix broker-url secret name in production guide (#45863)
  • Replace DAGs with dags in docs (#47959)
  • Enhance airflowLocalSettings value description (#47855)
  • Be consistent with denoting templated params (#46481)

Misc

  • Support templated hostname in NOTES (#41423)
  • Default airflow version to 2.10.5 (#46624)
  • Changing triggerer config option default_capacity to capacity (#48032)
  • AIP-84 Move public api under /api/v2 (#47760)
  • Default to the FabAuthManager in the chart (#47976)
  • Update PgBouncer to 1.23.1 and PgBouncer exporter to 0.18.0 (#47416)
  • Move api-server to port 8080 (#47310)
  • Start the api-server in Airflow 3, webserver in Airflow 2 (#47085)
  • Move fastapi-api command to api-server (#47076)
  • Move execution_api_server_url config to the core section (#46969)
  • Use standalone dag processor for Airflow 3 (#45659)
  • Update quay.io/prometheus/statsd-exporter from v0.26.1 to v0.28.0 (#43393)
