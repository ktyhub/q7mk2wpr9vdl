airflow 1.12.0

マイナー 公開日2024年2月12日 出典apache/airflow English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

エアフローヘルムチャート/1.12.0

重大な変更

Helm チャートは新しいバージョンの bitnami/postgresql 依存関係を使用するようになりました (#34817)

bitnami/postgresql subchart upgraded from 12.10.0 to 13.2.24 のバージョン。 PostgreSQL binaries upgraded from 11 to 16.1.0 のバージョン。 この変更には既存の bitnami/postgresql subchart users to perform manual major version upgrade using pg_dumpall or pg_upgrade が必要です。 実稼働環境では set up an external database <https://airflow.apache.org/docs/helm-chart/stable/production-guide.html#database>_ を推奨します。

デフォルトのエアフロー画像が 2.8.1 に更新されました (#36907)

チャートで使用されるデフォルトのエアフロー画像は「2.8.1``, previously it was ``2.7.1」になりました。

デフォルトの PgBouncer および PgBouncer Exporter イメージが更新されました (#36898)

PgBouncer および PgBouncer Exporter イメージは、新しいソフトウェア/OS に基づいています。

  • pgbouncer: 1.21.0 based on alpine 3.14 (airflow-pgbouncer-2024.01.19-1.21.0)
  • pgbouncer-exporter: 0.16.0 based on alpine 3.19 (apache/airflow:airflow-pgbouncer-exporter-2024.01.19-0.16.0)

デフォルトの StatsD イメージが v0.26.0 に更新されました (#37187)

チャートで使用されるデフォルトの StatsD イメージは、v0.26.0, previously it was v0.22.8 になりました。

デフォルトの Redis イメージが 7-bookworm に更新されました (#37187)

チャートで使用されるデフォルトの Redis イメージは、7-bookworm, previously it was 7-bullseye になりました。

新機能

  • Airflow ワーカーのネイティブ HPA を有効にする (#36174)
  • Airflow Kerberos の初期コンテナ + サイドカー サポートを追加 (#35548)
  • MySQL バックエンドを KEDA トリガーとしてサポート (#36167)

改善点

  • デバッグ性を向上させるために PriorityClass を改善 (#36365)
  • DAG プロセッサのログ グルーマー サイドカーに securityContexts を追加 (#34499)
  • DAG プロセッサの移行待機コンテナに securityContexts のサポートを追加 (#35593)
  • PVC storageClassName のテンプレートを追加 (#35581)
  • ワーカーに volumeClaimTemplate を追加 (#34986)
  • Redis ポッドでの priorityClassName のサポートを追加 (#34879)
  • DAG ボリュームのマウント パスを構成可能 (#35083)
  • カスタム emptyDir 構成のサポートを追加 (#34837)
  • スケジューラーとウェブサーバーを有効/無効にする機能を追加 (#36991)

バグ修正

  • Airflow 設定の StatsD ホストを修正 (#35679)
  • AIRFLOW_HOME env var with airflowHome 値を設定します (#34839)
  • より安全なワーカー ポッドのアノテーション (#35309)
  • ワーカー safeToEvict を適切に設定する (#35130)
  • Redis ブローカー URL を useStandardNaming で修正 (#34825)
  • usePgbouncer が false の場合の KEDA 接続のメタデータ DB とポートを修正しました (#34741)
  • PgBouncer と useStandardNaming の接続を修正 (#34787)

ドキュメントのみが変更されます

  • Airflow Helm チャートの拡張に関するドキュメントを追加 (#36331)
  • Elasticsearch 接続スキームのコメントを追加 (#35588)
  • カスタム イメージの必要性を妨げる Virtualenvs に関するメモを追加 (#35306)

その他

  • デフォルトのエアフロー バージョンは 2.8.1 (#36907)
  • git-sync v4 をサポート (#34731)
  • bitnami/postgresql subchart to 13.2.24 をアップグレード (#36156)
  • git sync コンテナのインデントを 4 に変更 (#35824)
  • K8S 1.24 サポートを削除 (#35214)
  • pgbouncer and pgbouncer-exporter イメージを新しいバージョンで再構築します (#36898)
  • statsd and redis チャート画像を更新 (#37187)

airflow helm-chart/1.12.0

Highlights

  • Bundled PostgreSQL is a breaking major upgrade — The Bitnami subchart moves from 12.10.0 to 13.2.24, and PostgreSQL binaries jump from 11 to 16.1 (#34817, #36156). Existing bundled-database users must manually migrate with pg_dumpall or pg_upgrade; an in-place upgrade is not provided. Back up first, or move to an external production database.

  • Airflow 2.8.1 becomes the default runtime — Replacing 2.7.1 updates schedulers, workers, and other Airflow containers together (#36907). Validate custom providers, plugins, DAGs, and configuration against 2.8 before adopting the default; pin the image tag if you need a staged rollout.

  • Deployment topology and worker lifecycle are more configurable — Scheduler and webserver can now be disabled (#36991), workers support native Kubernetes HPA (#36174) and volumeClaimTemplate (#34986), and safeToEvict is set correctly (#35130). These changes enable task-only deployments and safer autoscaling/disruption, but HPA requires appropriate resource requests and metrics.

  • KEDA gains MySQL trigger support — MySQL-backed workloads can now use KEDA for scaling (#36167). The metadata database and port are also resolved correctly when PgBouncer is disabled (#34741), while standard-naming fixes address PgBouncer and Redis broker connections (#34787, #34825). Recheck connection settings if you bypass PgBouncer or customize release naming.

  • Kerberos and pod security are easier to integrate — Kerberos deployments can use an init container plus sidecar (#35548), and DAG-processor log-groomer and migration-wait containers now accept securityContexts (#34499, #35593). This reduces the need for custom image forks; verify permissions, credential mounts, and service-account access for the added containers.

  • Platform support and sidecar images move forward — Kubernetes 1.24 support is removed (#35214), so validate your cluster before upgrading. Defaults also shift to PgBouncer 1.21.0, exporter 0.16.0, StatsD v0.26.0, Redis 7-bookworm, and git-sync v4 (#34731, #36898, #37187); recheck custom scripts, probes, and sidecar assumptions against these images.

Significant Changes

The helm chart is now using a newer version of bitnami/postgresql dependency (#34817)

The version of bitnami/postgresql subchart upgraded from 12.10.0 to 13.2.24. The version of PostgreSQL binaries upgraded from 11 to 16.1.0.

The change requires existing bitnami/postgresql subchart users to perform manual major version upgrade using pg_dumpall or pg_upgrade.

As a reminder, it is recommended to set up an external database <https://airflow.apache.org/docs/helm-chart/stable/production-guide.html#database>_ in production.

Default Airflow image is updated to 2.8.1 (#36907)

The default Airflow image that is used with the Chart is now 2.8.1, previously it was 2.7.1.

Default PgBouncer and PgBouncer Exporter images have been updated (#36898)

The PgBouncer and PgBouncer Exporter images are based on newer software/os.

  • pgbouncer: 1.21.0 based on alpine 3.14 (airflow-pgbouncer-2024.01.19-1.21.0)
  • pgbouncer-exporter: 0.16.0 based on alpine 3.19 (apache/airflow:airflow-pgbouncer-exporter-2024.01.19-0.16.0)

Default StatsD image is updated to v0.26.0 (#37187)

The default StatsD image that is used with the Chart is now v0.26.0, previously it was v0.22.8.

Default Redis image is updated to 7-bookworm (#37187)

The default Redis image that is used with the Chart is now 7-bookworm, previously it was 7-bullseye.

New Features

  • Enable native HPA for Airflow Workers (#36174)
  • Add init container + sidecar support for Airflow Kerberos (#35548)
  • Support MySQL backend as KEDA trigger (#36167)

Improvements

  • Improve PriorityClass to improve debuggability (#36365)
  • Add securityContexts in dag processors log groomer sidecar (#34499)
  • Add support for securityContexts in dag processors wait-for-migrations container (#35593)
  • Add templating for PVC storageClassName (#35581)
  • Add volumeClaimTemplate for worker (#34986)
  • Add support for priorityClassName on Redis pods (#34879)
  • Configurable mount path for DAGs volume (#35083)
  • Add support for custom emptyDir config (#34837)
  • Added ability to enable/disable scheduler and webserver (#36991)

Bug Fixes

  • Fix StatsD host in Airflow config (#35679)
  • Set AIRFLOW_HOME env var with airflowHome value (#34839)
  • Safer worker pod annotations (#35309)
  • Set worker safeToEvict properly (#35130)
  • Fix Redis broker URL with useStandardNaming (#34825)
  • Fix metadata DB & port in KEDA connection when usePgbouncer is false (#34741)
  • Fix PgBouncer connection with useStandardNaming (#34787)

Doc only changes

  • Add docs about extending the Airflow Helm chart (#36331)
  • Add comment for Elasticsearch connection scheme (#35588)
  • Add notes about Virtualenvs preventing the need for custom images (#35306)

Misc

  • Default Airflow version to 2.8.1 (#36907)
  • Support git-sync v4 (#34731)
  • Upgrade bitnami/postgresql subchart to 13.2.24 (#36156)
  • Change git sync container indent to 4 (#35824)
  • Remove K8S 1.24 support (#35214)
  • Rebuild pgbouncer and pgbouncer-exporter images with newer versions (#36898)
  • Update statsd and redis chart images (#37187)
