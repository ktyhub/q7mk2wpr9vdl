#マネープリンターターボv1.3.5

英語 | 中文

<h2 id="en-v1.3.5">ハイライト</h2>
  • MiniMax および Fish Audio テキスト読み上げプロバイダーを追加し、MiniMax 地域エンドポイントと音声選択サポートを改善し、Gemini 音声を公式カタログと同期し、WebUI に自動音声プレビューを追加しました。
  • Anthropic Claude をネイティブ LLM プロバイダーとして追加しました。
  • Shengsuan AI および WaveSpeed のテキストからビデオへのマテリアル ソースを追加しました。
  • オプションの API キーのバックアップと復元を含む、再利用可能な WebUI 生成設定とプリセットのインポート/エクスポートを追加しました。
  • YouTube に限定するのではなく、サポートされているすべてのクロスポスト プラットフォームに LLM で生成されたソーシャル キャプションを追加しました。
  • イタリア語の WebUI 翻訳と日本語の README を追加しました。

セキュリティ

  • /api/v1 エンドポイントおよび生成されたタスク ファイル用のオプションの API キー認証を追加しました。 app.api_key が空である間、既存のインストールは下位互換性を維持します。
  • パスの通過を防ぐために、カスタム オーディオ入力を許可された場所に制限しました。
  • 生成されたタスク ファイルが escaping シンボリックリンク経由でアクセスできないようにしました。
  • より厳密なファイルとパスの検証による強化されたローカル マテリアルのアップロード。
  • client が提供するリクエスト ID をタスク処理で使用する前にサニタイズしました。

修正と改善

  • 複数行の字幕やディセンダーのないテキストなど、一部のテキストとフォントの組み合わせで最後の字幕行が clipped になる問題を修正しました。
  • FFmpeg が利用できない場合の対処可能な起動エラーを追加しました。
  • Docker 依存関係のインストールの再試行を修正し、永続的なパッケージの失敗により黙って無視されるのではなくビルドが停止されるようにしました。
  • バックグラウンドのスケジュールが失敗した場合にタスクの状態をロールバックし、タスクが誤った状態でスタックするのを防ぎます。
  • API 応答スキーマが改善され、モデル構成が Pydantic v2 ConfigDict に移行されました。 ・pingヘルスチェックルーターを登録しました。
  • 正規化された LLM 応答での段落境界の保持。
  • サポートされている Kim API プラットフォームを構成および WebUI で区別しました。
  • 繰り返しの UTF-8 BOM マーカーを含む設定ファイルを処理しました。
  • MiniMax 音声検出を改善し、既存の出力ファイルを置き換える前に生成されたオーディオを検証しました。

アップグレードに関する注意事項

  • デフォルトでは認証は必要ありません。 V1 API および生成されたタスク ファイルを保護するには、config.toml に app.api_key を設定し、x-api-key リクエスト ヘッダーで同じ値を送信します。
  • API キーのバックアップが有効になっている場合、設定プリセットのエクスポートにはプロバイダーの資格情報を含めることができます。エクスポートされたプリセット ファイルを安全に保存し、ソース管理にコミットしないでください。
  • Fish Audio、MiniMax、Anthropic Claude、WaveSpeed、および Shengsuan AI は、使用する前にそれぞれのプロバイダーの資格情報が必要です。

<h2 id="cn-v1.3.5">注目更新</h2>
  • 新しい MiniMax および Fish Audio の音声テキスト変換音声サービス、完善 MiniMax エリア エンドポイントと音色選択のサポート、Gemini 官方音色目録の同時追加、および WebUI での自動音声音声機能の追加。
  • 新しい Anthropic Claude 原生大言説モデル サービス商。
  • 新しい胜算云（Shengsuan AI）と WaveSpeed AI 文生ビデオ素材ソース。
  • WebUI は、汎用のビデオ生成設定と入力、出力機能を新たに追加し、選択キーと API キーをサポートします。
  • YouTube に限定されるものではなく、サポートされているすべてのプラットフォームで配信されており、大口語モデルを使用して社交メディア テンプレートを生成できます。
  • 新しい大利口語 WebUI 翻訳および日刊紙 README 文。

安全性

  • /api/v1 インターフェイスおよび生成されたタスク ファイルには、オプションの API キー キーが追加されます。app.api_key が空のままであれば、インストールされており、ゲストは変更する必要なく引き続き使用できます。
  • パスの通過を防止するため、許可されたコンテンツからのみ音声ファイルを取得できるように制限します。
  • シンボル チェーン経由でタスク アイテム以外のファイルが受信されるのを防ぎます。
  • ローカル素材上で転送されるファイルの種類、経路、およびファイル名チェックを追加します。
  • クライアントが送信したリクエスト ID は、ファイル パスや処理フローへの影響を回避するために、処理および調整処理が実行されます。

修正与変更

  • 修正部分の文字と文字が組み合わされた下の字幕の最後の一行が裁断された問題、複数の行の字幕、および下の拡張文字が含まれていないテキストを上書きします。
  • システムが FFmpeg を削除すると、直ちに起動が停止され、実行可能なクリーンなメッセージが表示されます。
  • 修正 Docker は取り付け再試行に依存しており、静的な簡単なテストではなく、ホイール パッケージが取り付けミスを超えて構築を継続することを保証します。
  • 後段のジョブ調整が失われると、自動的にジョブの状態に戻り、ジョブが障害状態に留まるのを回避します。
  • API 適用モデルを変更し、関連する Pydantic 構成を Pydantic v2 ConfigDict に移行します。
  • 正しく Ping 健康検査インターフェイスを確認します。
  • ダイアグラム モデルのセグメントと実行構造を保持します。
  • 構成および WebUI で、異なる Kimi API プラットフォームを明確に区別します。
  • 複数の UTF-8 BOM マークを含む構成ファイルの取得をサポートします。
  • MiniMax の音色の変更が選択され、既存の音声ファイルを置き換える前に、新しく生成された音声が有効かどうかがテストされます。

升级说明

  • V1 API と生成されたタスク ファイルを保護する必要がある場合は、API を使用せず、要求時に app.api_key を設定します。 x-api-key は同じ値を要求します。
  • API キーを押した後、公開された WebUI 設定にはサービス パッケージが含まれる可能性があります。公開コードに渡す必要のないファイルを保存します。
  • Fish Audio、MiniMax、Anthropic Claude、WaveSpeed、および計算云機能は、サービス プロバイダーの同期データを構成してから使用する必要があります。

MoneyPrinterTurbo v1.3.5

Highlights

  • Provider catalog expands across TTS, LLM, and video — MiniMax (#1175) and Fish Audio (#1228) join as text-to-speech backends, Anthropic Claude (#1223) becomes a native LLM provider, and WaveSpeed (#1201) plus Shengsuan AI add text-to-video material sources. All additive, so existing pipelines keep running untouched — but each provider is gated on its own credentials, so provision the relevant keys before enabling them in the WebUI.
  • Opt-in authentication for the V1 API and task files — You can now protect /api/v1 and generated artifacts by setting app.api_key in config.toml and passing the same value in the x-api-key header. Since the default is empty, upgrades are drop-in for current installs; enabling it is a deliberate hardening step for anything exposed beyond localhost, and you must update every client in lockstep or requests will start failing auth.
  • Reusable WebUI settings and credential-bearing presets — Generation settings now persist (#1191) and can be exported/imported as presets with optional API-key backup/restore (#1211), making it cheap to reproduce a config across machines. The catch: an exported preset can embed live provider credentials when backup is enabled, so handle those files securely and keep them out of source control.
  • API schema and security hardening — Response models were tightened and model config migrated to Pydantic v2 ConfigDict (#1217), so API consumers should re-verify deserialization against the updated schemas. Alongside this, four validation fixes (#1238–#1242) constrain custom audio to allowed directories, block symlink escapes from task files, harden local material uploads, and sanitize client-supplied request IDs — worth noting if you accept untrusted input.
  • Operational resilience and content fidelity — A missing FFmpeg now fails fast with an actionable error (#1222) instead of a cryptic crash, failed background scheduling rolls back task state rather than leaving jobs stuck (#1192), and the ping health-check router is finally registered (#1212), giving you a usable liveness probe. Subtitle rendering no longer clips the last line for certain font/text combinations, and LLM-generated captions now cover every cross-post platform (#1230), not just YouTube.
  • No breaking changes — all new behavior is opt-in or additive; existing installs and clients continue to work unchanged.

<h2 id="en-v1.3.5">Highlights</h2>
  • Added MiniMax and Fish Audio text-to-speech providers, improved MiniMax regional endpoint and voice selection support, synchronized Gemini voices with the official catalog, and added automatic voice previews in the WebUI.
  • Added Anthropic Claude as a native LLM provider.
  • Added Shengsuan AI and WaveSpeed text-to-video material sources.
  • Added reusable WebUI generation settings and preset import/export, including optional API key backup and restore.
  • Added LLM-generated social captions for every supported cross-post platform, instead of limiting them to YouTube.
  • Added an Italian WebUI translation and a Japanese README.

Security

  • Added optional API key authentication for /api/v1 endpoints and generated task files. Existing installations remain backward compatible while app.api_key is empty.
  • Restricted custom audio inputs to allowed locations to prevent path traversal.
  • Prevented generated task files from being accessed through escaping symlinks.
  • Hardened local material uploads with stricter file and path validation.
  • Sanitized client-supplied request IDs before using them in task processing.

Fixes and Improvements

  • Fixed the last subtitle line being clipped for some text and font combinations, including multiline subtitles and text without descenders.
  • Added an actionable startup error when FFmpeg is unavailable.
  • Fixed Docker dependency installation retries so persistent package failures stop the build instead of being silently ignored.
  • Rolled back task state when background scheduling fails, preventing tasks from remaining stuck in an incorrect state.
  • Improved API response schemas and migrated model configuration to Pydantic v2 ConfigDict.
  • Registered the ping health-check router.
  • Preserved paragraph boundaries in normalized LLM responses.
  • Distinguished the supported Kimi API platforms in configuration and the WebUI.
  • Handled configuration files containing repeated UTF-8 BOM markers.
  • Improved MiniMax voice discovery and validated generated audio before replacing an existing output file.

Upgrade Notes

  • No authentication is required by default. To protect the V1 API and generated task files, set app.api_key in config.toml and send the same value in the x-api-key request header.
  • Settings preset exports can contain provider credentials when API key backup is enabled. Store exported preset files securely and do not commit them to source control.
  • Fish Audio, MiniMax, Anthropic Claude, WaveSpeed, and Shengsuan AI require their respective provider credentials before they can be used.

<h2 id="cn-v1.3.5">重点更新</h2>
  • 新增 MiniMax 和 Fish Audio 文本转语音服务，完善 MiniMax 区域端点和音色选择支持，同步 Gemini 官方音色目录，并在 WebUI 中增加自动语音试听功能。
  • 新增 Anthropic Claude 原生大语言模型服务商。
  • 新增胜算云（Shengsuan AI）和 WaveSpeed AI 文生视频素材源。
  • WebUI 新增可复用的视频生成设置以及预设导入、导出功能，并支持选择性备份和恢复 API Key。
  • 所有受支持的跨平台发布渠道现在都可以使用大语言模型生成社交媒体文案，不再仅限于 YouTube。
  • 新增意大利语 WebUI 翻译和日语 README 文档。

安全性

  • 为 /api/v1 接口和生成的任务文件增加可选的 API Key 鉴权；当 app.api_key 保持为空时，现有安装和客户端仍可继续使用，无需修改。
  • 限制自定义音频文件只能从允许的目录读取，防止路径穿越。
  • 防止通过符号链接访问任务目录之外的文件。
  • 加强本地素材上传的文件类型、路径和文件名校验。
  • 对客户端传入的请求 ID 进行清理和规范化处理，避免其影响任务文件路径和处理流程。

修复与改进

  • 修复部分文字和字体组合下字幕最后一行被裁切的问题，覆盖多行字幕以及不包含下伸字符的文本。
  • 当系统缺少 FFmpeg 时立即停止启动，并提供清晰、可执行的错误提示。
  • 修复 Docker 依赖安装重试逻辑，确保软件包持续安装失败时终止构建，而不是静默忽略错误。
  • 后台任务调度失败时自动回滚任务状态，避免任务停留在错误状态。
  • 改进 API 响应模型，并将相关 Pydantic 配置迁移到 Pydantic v2 ConfigDict。
  • 正确注册 Ping 健康检查接口。
  • 保留大语言模型响应中的段落和换行结构。
  • 在配置和 WebUI 中明确区分不同的 Kimi API 平台。
  • 支持读取包含多个 UTF-8 BOM 标记的配置文件。
  • 改进 MiniMax 音色发现与选择，并在替换已有音频文件前验证新生成的音频是否有效。

升级说明

  • 默认情况下不会启用 API 鉴权，现有用户升级后不受影响。如需保护 V1 API 和生成的任务文件，请在 config.toml 中设置 app.api_key，并在请求中通过 x-api-key 请求头传递相同的值。
  • 开启 API Key 备份后，导出的 WebUI 设置预设可能包含服务商凭据。请妥善保存导出文件，不要将其提交到公开代码仓库。
  • Fish Audio、MiniMax、Anthropic Claude、WaveSpeed 和胜算云功能需要配置对应服务商的凭据后才能使用。
