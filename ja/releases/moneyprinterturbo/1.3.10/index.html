#マネープリンターターボ v1.3.10

英語 | 中文

<h2 id="en-v1.3.10">ハイライト</h2>
  • デバイス コード サインインと動的なモデル選択を備えた OpenAI Codex サブスクリプション アクセス、および別個の ChatGPT ネイティブ OAuth プロバイダーを追加しました。ネイティブ OAuth が利用できるかどうかは、アカウントの資格によって異なります。既存の Codex サインインは独立したままになります。
  • 素材ソースとして コーデックス画像生成 を追加しました。テキストと画像の生成では、アプリケーションの Codex ログインを共有でき、生成された画像は既存の静的および低速ズーム効果をサポートします。
  • Runcrate、CloudGPU、cheapaimodel LLM プロバイダーに加えて、LLM とビデオ生成用に Infistar と Jalapeno Cloud を追加しました。
  • 生成段階、経過時間、ポーリング ステータスに関する 長時間実行されるビデオ生成のフィードバックが改善されました。タスク追跡は、ページの更新や一時的なクエリの失敗の後も存続し、重複した送信から保護されます。
  • WebUI での プロバイダーの設定と選択 が簡素化され、構成されたサービスの検索と切り替えが容易になりました。
  • アラビア文字の字幕 shaping を追加しました。これには、接続された文字、右から左へのレイアウト、混合スクリプト フォントのフォールバック、グリフ対応のラッピングと背景が含まれます。
  • サブピクセル レンダリングにより 遅い画像ズームがよりスムーズになり、目に見える段差やぐらつきがなくなりました。
  • スクリプト言語の選択肢にインドネシア語を追加し、インドネシア語インターフェースの翻訳を改良しました。

修正と改善

  • ストリーミングされたチャンク間の不必要な遅延が原因で長い Edge TTS ナレーションがタイムアウトする問題を修正しました。スクリプトのサブタグを使用した Edge 音声のサポートと、より明確な Gemini の空のオーディオ診断が追加されました。
  • ナレーションと焼き付け字幕から絵文字を削除し、Gemini と MiMo TTS が音声速度設定を使用しないことを明確にしました。
  • 時刻、全角数字、日付、略語、名前、中国語と日本語の句読点を中心とした字幕の分割が改善されました。タイ語とラオス語の文字に文の分割を追加しました。
  • 字幕修正で完全なスクリプトを調整できない場合に、元の時間指定された文字起こしが保持されるようになりました。字幕類似性スコアリングにおける空の文字列と Unicode の長さ拡張のケースを修正しました。
  • 多言語ソーシャル ハッシュタグの結合マークを保持し、絵文字マークを除外し、中国語と日本語のハッシュタグ区切り文字を認識しました。
  • AI 生成が失敗したときに既存のスクリプトとキーワードを保持し、対処可能なエラーを表示し、スクリプト生成がすでに失敗した後はキーワードの要求を回避しました。
  • スクリプト オーダーのストック素材のマッチング中に繰り返されるトピックの位置を保持し、破損したビデオ キャッシュを修復し、より明確な Pexels と Coverr の検索失敗ログを追加しました。
  • コンソールのキーストロークによって FFmpeg clip 連結が途中で終了または停止することがなくなりました。 Windows でのレンダリング出力の同期とビッグエンディアンのグレースケール TIFF の明るさが修正されました。
  • 特殊文字を含むパス、他の作業ディレクトリから、LAN リスニングが有効な場合の Windows 起動が改善されました。リダイレクトされたコンソール ログと、設定を保存する際の Windows パスと非改行スペースの保存を修正しました。
  • アトミックなスロット予約、リース更新、およびキューに入れられたタスクの回復を備えた、ワーカー間での共有 Redis タスク同時実行制限。
  • 字幕フォントのエラー メッセージ、API 列挙型のデフォルト、ChatGPT/Codex サインイン診断が改善されました。 Docker 構成のセットアップと、誤ってマウントされた config.toml ディレクトリからのリカバリを明確にしました。
  • 修正可能なセキュリティの発見に対処するために CPU とコンテナの依存関係を更新し、コンテナの脆弱性スキャンを追加しました。リグレッションの対象範囲を拡大し、Windows 固有のパス アサーションを修正しました。

  • WebUI の ** サービスは、既に構成されているサービスの選択と切り替えを容易にするために、** を選択して設定されます。

修正与変更

  • エッジ TTS の修正により、ストリーム形式のデータ処理が遅延するため、長い文例のサウンドが発生する問題が発生します。バンド表示のエッジ トーンがサポートされ、Gemini がオーディオを返す際の原因の提案がサポートされます。
  • 配音と字幕から絵文字を削除すると、Gemini、MiMo TTS が配音の高速設定を使用していないことを明らかに示しています。
  • 時間、全角数字、日期、原稿、人名および中日文点附近の字幕断句；补充泰話、老句句句の間の空格拆分の処理を改善します。
  • 字幕補正無法、齐完全な文案に対する原文の書き込み時間の保持；修正類似度計算により空字列または特殊な Unicode 文字に遭遇した場合に除零、返還値の問題。
  • 複数の会話言社交信内の組み合わせ文字を保持し、絵文字を除外し、中国語、日文の区切り文字を認識します。
  • AI 文例または関連付けの作成が失敗した場合、既存のコンテンツを保持して、関連付けの要求を表示します。文例の作成が失敗した場合は、関連付けの要求を再度実行しません。
  • クリップの順序をメモリに合わせて修正すると、メインの失われる場所の問題が再発します。修正されたファイルのビデオ保存は、Pexels、カバーの失われの特定の原因を補います。
  • コンソール キーが途中で終了したり、FFmpeg フラグメントのスプライシングをブロックしたりしないようにします。 Windows レンダリング ファイルの同期と、ビッグ エンディアン グレースケール TIFF 画像の明るさの問題を修正しました。
  • Windows での特殊文字パス、他の作業ディレクトリ、LAN リスニング シナリオにおける起動互換性を向上させます。ログのリダイレクトを修正し、構成を保存するときに Windows パスと非改行スペースを保持します。
  • 複数のワーカー プロセスの Redis タスクの同時実行制限を統合し、実行クォータのアトミック占有、更新、およびキューに入れられたタスクの回復をサポートします。
  • 字幕フォントのエラー プロンプト、API 列挙のデフォルト値、ChatGPT/Codex ログイン診断を改善しました。 Docker の構成手順と、config.toml が誤ってディレクトリとしてマウントされた場合の回復プロンプトを追加しました。
  • CPU コンテナの依存関係を更新し、解決可能なセキュリティ スキャンの問題を修正し、コンテナの脆弱性スキャンを追加しました。回帰テストが改善され、Windows パス アサーションの誤検知が修正されました。

MoneyPrinterTurbo v1.3.10

Highlights

  • Provider expansion — Adds OpenAI Codex subscription access with device-code sign-in and dynamic model selection (#1715), a separate ChatGPT Native OAuth provider subject to account eligibility (#1716), and Codex image generation that reuses the application’s Codex login (#1719). Infistar and Jalapeno Cloud provide LLM and video generation; Runcrate, CloudGPU, and cheapaimodel add LLM options. Existing provider configurations remain usable without migration.

  • Generation reliability — Long-running video jobs now show generation stages, elapsed time, and polling status, survive page refreshes and temporary query failures, and reject duplicate submissions. Redis concurrency limits now apply across workers using atomic slot reservation, lease renewal, and queued-task recovery; multi-worker deployments should verify their limits if they previously assumed a per-worker cap. Provider settings and selection are also simpler.

  • Subtitle, narration, and internationalization — Arabic subtitles gain connected-letter shaping, right-to-left layout, mixed-script font fallback, and glyph-aware wrapping/backgrounds. Subtitle splitting and timing preservation improve for multilingual scripts, punctuation, dates, and abbreviations. Output behavior changed: emoji are removed from narration and burned-in subtitles, and Gemini/MiMo TTS continue to ignore voice-speed settings. Slow zoom is smoother, and Indonesian is now available for scripts with improved interface translations.

  • Platform and rendering fixes — Fixes include Edge TTS timeouts on long narration, Edge voices with script subtags, Windows startup from special-character paths or other working directories, LAN listening, render-output synchronization, FFmpeg concatenation interrupted by console input, corrupt video caches, and big-endian grayscale TIFF brightness. Failed AI generation now preserves existing scripts and keywords. These fixes particularly benefit Windows users and long or complex render workflows.

  • Upgrade recommendation — This is a substantive feature-and-fix release, not a re-tag or metadata-only update. Windows, Redis/multi-worker, Arabic-script, long-form TTS, and CPU-container users should upgrade; the latter also receive dependency security updates and vulnerability scanning. Users satisfied with their current providers and workflows can skip unless they need the new capabilities. No breaking changes or required migration steps are documented.

<h2 id="en-v1.3.10">Highlights</h2>
  • Added OpenAI Codex subscription access with device-code sign-in and dynamic model selection, plus a separate ChatGPT Native OAuth provider. Native OAuth availability depends on account eligibility; existing Codex sign-in remains independent.
  • Added Codex image generation as a material source. Text and image generation can share the application's Codex login, and generated images support the existing static and slow zoom effects.
  • Added Infistar and Jalapeno Cloud for LLM and video generation, alongside Runcrate, CloudGPU, and cheapaimodel LLM providers.
  • Improved long-running video generation feedback with generation stages, elapsed time, and polling status. Task tracking survives page refreshes and temporary query failures, with protection against duplicate submissions.
  • Simplified provider settings and selection in the WebUI, making configured services easier to find and switch between.
  • Added Arabic-script subtitle shaping, including connected letters, right-to-left layout, mixed-script font fallback, and glyph-aware wrapping and backgrounds.
  • Made slow image zoom smoother with sub-pixel rendering, eliminating visible stepping and wobble.
  • Added Indonesian to script-language choices and refined the Indonesian interface translations.

Fixes and Improvements

  • Fixed long Edge TTS narration timing out because of unnecessary delays between streamed chunks. Added support for Edge voices with script subtags and clearer Gemini empty-audio diagnostics.
  • Removed emoji from narration and burned-in subtitles, and clarified that Gemini and MiMo TTS do not use the voice-speed setting.
  • Improved subtitle splitting around clock times, full-width numbers, dates, abbreviations, names, and Chinese and Japanese punctuation. Added sentence splitting for Thai and Lao scripts.
  • Preserved the original timed transcription when subtitle correction cannot align the full script. Fixed empty-string and Unicode length-expansion cases in subtitle similarity scoring.
  • Preserved combining marks in multilingual social hashtags, excluded emoji marks, and recognized Chinese and Japanese hashtag separators.
  • Kept existing script and keywords when AI generation fails, displayed an actionable error, and avoided requesting keywords after script generation has already failed.
  • Preserved the position of repeated topics during script-order stock-material matching, repaired corrupt video caches, and added clearer Pexels and Coverr search-failure logs.
  • Stopped console keystrokes from prematurely ending or stalling FFmpeg clip concatenation. Fixed render-output synchronization on Windows and big-endian grayscale TIFF brightness.
  • Improved Windows startup from paths containing special characters, from other working directories, and with LAN listening enabled. Fixed redirected console logs and preserved Windows paths and non-breaking spaces when saving configuration.
  • Shared Redis task-concurrency limits across workers, with atomic slot reservation, lease renewal, and queued-task recovery.
  • Improved subtitle-font error messages, API enum defaults, and ChatGPT/Codex sign-in diagnostics. Clarified Docker configuration setup and recovery from an accidentally mounted config.toml directory.
  • Updated CPU-container dependencies to address fixable security findings and added container vulnerability scanning. Expanded regression coverage and corrected Windows-specific path assertions.

<h2 id="cn-v1.3.10">重点更新</h2>
  • 新增 OpenAI Codex 订阅接入，支持设备码登录和动态模型选择；另提供独立的 ChatGPT 原生 OAuth 接入。原生授权取决于账号资格，与已有 Codex 登录相互独立。
  • 新增 Codex 图片素材来源，文案与生图可复用本应用的 Codex 登录，生成的图片支持现有的静止和缓慢放大效果。
  • 新增 Infistar 和 Jalapeno Cloud 大模型及视频生成服务，以及 Runcrate、CloudGPU、cheapaimodel 大模型服务。
  • 完善长时间视频生成的进度反馈，显示生成阶段、已用时间和轮询状态；刷新页面或查询短暂失败后可继续跟踪任务，并增加重复提交保护。
  • 简化 WebUI 的服务商设置与选择，便于查找和切换已经配置的服务。
  • 新增阿拉伯语文字字幕整形，支持字母连写、从右到左排版、混合文字字体回退，以及按实际字形计算换行和背景。
  • 改善图片缓慢放大的流畅度，通过亚像素渲染消除明显的步进和抖动。
  • 新增印尼语脚本语言选项，并完善印尼语界面翻译。

修复与改进

  • 修复 Edge TTS 因流式数据处理延迟导致长文案配音超时的问题；支持带脚本子标签的 Edge 音色，并补充 Gemini 返回空音频时的原因提示。
  • 从配音和烧录字幕中清理 emoji，明确提示 Gemini、MiMo TTS 不使用配音语速设置。
  • 改善时间、全角数字、日期、缩写、人名及中日文标点附近的字幕断句；补充泰语、老挝语按句间空格拆分的处理。
  • 字幕校正无法对齐完整文案时保留原始转写时间轴；修复相似度计算遇到空字符串或特殊 Unicode 字符时除零、返回负值的问题。
  • 保留多语言社交标签中的组合字符，排除 emoji 标记，并识别中文、日文标签分隔符。
  • AI 文案或关键词生成失败时保留已有内容并显示错误；文案生成失败后不再继续请求关键词。
  • 修复按脚本顺序匹配库存素材时重复主题丢失位置的问题；修复损坏的视频缓存，并补充 Pexels、Coverr 搜索失败的具体原因。
  • 避免控制台按键提前结束或阻塞 FFmpeg 片段拼接；修复 Windows 渲染文件同步，以及大端灰度 TIFF 图片亮度问题。
  • 改善 Windows 下特殊字符路径、其他工作目录和局域网监听场景中的启动兼容性；修复日志重定向，并在保存配置时保留 Windows 路径和不换行空格。
  • 统一多个工作进程的 Redis 任务并发限制，支持原子占用执行名额、续期和排队任务恢复。
  • 改善字幕字体错误提示、API 枚举默认值和 ChatGPT/Codex 登录诊断；补充 Docker 配置说明，以及误将 config.toml 挂载为目录时的恢复提示。
  • 更新 CPU 容器依赖，修复可解决的安全扫描问题，并增加容器漏洞扫描；完善回归测试，修正 Windows 路径断言误报。
