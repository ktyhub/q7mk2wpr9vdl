#プランタムルv1.2026.8

何が変わったのか

  • ⬆️ https://github.com/plantuml/plantuml/pull/2833 の @dependabot[bot] によるアクション/setup-java を 5 から 6 にバンプします
  • 📝 ドキュメント: https://github.com/plantuml/plantuml/pull/2841 の @AzazelSensei による alphadoc #2420 を更新する方法を追加
  • ⚡️ https://github.com/plantuml/plantuml/pull/2838 の @lemonlion による SkinParam.getThickness のキャッシュ
  • ⚡️ TeaVM バックエンドでの SVG 番号と色の書式設定が高速化 (https://github.com/plantuml/plantuml/pull/2837 の @lemonlion による)
  • ⚡️ Teoz: https://github.com/plantuml/plantuml/pull/2839 の @lemonlion により NoteTile、CommunicationTileSelf、CommunicationExoTile のコンポーネントをキャッシュします
  • ⚡️ Teoz: https://github.com/plantuml/plantuml/pull/2836 の @lemonlion により CommunicationTile に ArrowComponent をキャッシュします
  • 👷 perf-bench を追加: https://github.com/plantuml/plantuml/pull/2840 の @lemonlion によるブラウザ エンジンのノンブロッキング レンダリング パフォーマンス トラッキング
  • ⚡️ Teoz: LiveBox での O(1) イベント ルックアップは NextEventADestroy と、https://github.com/plantuml/plantuml/pull/2835 の @lemonlion による getActivateColor
  • 🍵 https://github.com/plantuml/plantuml/pull/2848 の @lemonlion によるブラウザ (TeaVM) ビルドで !theme をサポート
  • 🍵 https://github.com/plantuml/plantuml/pull/2849 の @lemonlion によるブラウザー (TeaVM) ビルド (#2848 にスタック) でドキュメントの背景をペイントします。
  • 🐛 objectdiagram: https://github.com/plantuml/plantuml/pull/2843 の @onuracar-dev による関連付けリンクの方向を保持
  • ⬆️ https://github.com/plantuml/plantuml/pull/2855 の @dependabot[bot] により org.graalvm.buildtools.native を 1.1.10 から 1.1.11 にバンプします
  • ✨ TeaVM: https://github.com/plantuml/plantuml/pull/2851 の @lemonlion により viz-global.js が見つからない場合、未処理の例外ではなく読み取り可能なエラーが発生します
  • ⬆️ https://github.com/plantuml/plantuml/pull/2856 の @dependabot[bot] により org.eclipse.xtext:org.eclipse.xtext.xbase.lib を 2.36.0 から 2.44.0 にバンプします
  • ✨ TeaVM: https://github.com/plantuml/plantuml/pull/2852 の @lemonlion によるブラウザーのビルドで '!pragmalayout smetana' を尊重します
  • 👷 [GHA] アクション ジョブの名前を「テーマ」から「チェック」に変更し、https://github.com/plantuml/plantuml/pull/2863 の @The-Lum による Gradle タイトルを追加します
  • ⬆️ https://github.com/plantuml/plantuml/pull/2864 の @dependabot[bot] による /plantuml-mcp-js の 6.15.2 から 6.16.0 への QS のバンプ
  • ⬆️ https://github.com/plantuml/plantuml/pull/2865 の @dependabot[bot] により、/plantuml-mcp-js で fast-uri を 3.1.5 から 3.1.7 にバンプします
  • ⚡️ Smetana のパフォーマンス: https://github.com/plantuml/plantuml/pull/2858 の @lemonlion による辞書とデバッグ トレースのホット パスで例外が構築されなくなりました
  • ⚡️ クラス図: https://github.com/plantuml/plantuml/pull/2860 の @lemonlion によって isMethod の URL 正規表現を 1 回コンパイルします
  • ✨ TeaVM: https://github.com/plantuml/plantuml/pull/2861 の @lemonlion によって viz-global.js が読み込まれない場合は Smetana にフォールバックします
  • ♻️ README を site フォルダーに追加し、https://github.com/plantuml/plantuml/pull/2869 の @The-Lum によって JDepend ツールを再編成します
  • ♻️ perf-bench と browser-test を tools/ の下に移動 (https://github.com/plantuml/plantuml/pull/2868 の @lemonlion 作成)
  • 👷ソナーアクションとGPL_ONLY変数を更新します。 https://github.com/plantuml/plantuml/pull/2871 での @The-Lum による使用法
  • 👷 perf-bench: https://github.com/plantuml/plantuml/pull/2862 の @lemonlion による測定された比率に基づいて、予想される帯域を再センタリングします。
  • 📝 ドキュメントに Javadoc @param タグがありません #2629 by @AzazelSensei (https://github.com/plantuml/plantuml/pull/2850)
  • ⬆️ https://github.com/plantuml/plantuml/pull/2844 の @dependabot[bot] によるアクション/セットアップ ノードを 6 から 7 にバンプします
  • ✨ Stdlib には、ブラウザ エンジンのすべてのホスト用に次のものが含まれます: PLANTUML_STDLIB_BASE および PLANTUML_STDLIB_LOADER by @lemonlion (https://github.com/plantuml/plantuml/pull/2873)

新しい貢献者

  • @AzazelSensei が https://github.com/plantuml/plantuml/pull/2841 に初めて投稿しました
  • @onuracar-dev が https://github.com/plantuml/plantuml/pull/2843 で最初の貢献をしました

plantuml v1.2026.8

What's Changed

  • ⬆️ Bump actions/setup-java from 5 to 6 by @dependabot[bot] in https://github.com/plantuml/plantuml/pull/2833
  • 📝 docs: add how to update alphadoc #2420 by @AzazelSensei in https://github.com/plantuml/plantuml/pull/2841
  • ⚡️ Cache SkinParam.getThickness by @lemonlion in https://github.com/plantuml/plantuml/pull/2838
  • ⚡️ Faster SVG number and color formatting in the TeaVM backend by @lemonlion in https://github.com/plantuml/plantuml/pull/2837
  • ⚡️ Teoz: cache the component in NoteTile, CommunicationTileSelf and CommunicationExoTile by @lemonlion in https://github.com/plantuml/plantuml/pull/2839
  • ⚡️ Teoz: cache the ArrowComponent in CommunicationTile by @lemonlion in https://github.com/plantuml/plantuml/pull/2836
  • 👷 Add perf-bench: non-blocking render performance tracking for the browser engine by @lemonlion in https://github.com/plantuml/plantuml/pull/2840
  • ⚡️ Teoz: O(1) event lookup in LiveBoxes isNextEventADestroy and getActivateColor by @lemonlion in https://github.com/plantuml/plantuml/pull/2835
  • 🍵 Support !theme in the browser (TeaVM) build by @lemonlion in https://github.com/plantuml/plantuml/pull/2848
  • 🍵 Paint the document background in the browser (TeaVM) build (stacked on #2848) by @lemonlion in https://github.com/plantuml/plantuml/pull/2849
  • 🐛 objectdiagram: preserve association link direction by @onuracar-dev in https://github.com/plantuml/plantuml/pull/2843
  • ⬆️ Bump org.graalvm.buildtools.native from 1.1.10 to 1.1.11 by @dependabot[bot] in https://github.com/plantuml/plantuml/pull/2855
  • ✨ TeaVM: readable error instead of an unhandled exception when viz-global.js is missing by @lemonlion in https://github.com/plantuml/plantuml/pull/2851
  • ⬆️ Bump org.eclipse.xtext:org.eclipse.xtext.xbase.lib from 2.36.0 to 2.44.0 by @dependabot[bot] in https://github.com/plantuml/plantuml/pull/2856
  • ✨ TeaVM: honor '!pragma layout smetana' in the browser build by @lemonlion in https://github.com/plantuml/plantuml/pull/2852
  • 👷 [GHA] Rename action job from 'themes' to 'checks' and add Gradle title by @The-Lum in https://github.com/plantuml/plantuml/pull/2863
  • ⬆️ Bump qs from 6.15.2 to 6.16.0 in /plantuml-mcp-js by @dependabot[bot] in https://github.com/plantuml/plantuml/pull/2864
  • ⬆️ Bump fast-uri from 3.1.5 to 3.1.7 in /plantuml-mcp-js by @dependabot[bot] in https://github.com/plantuml/plantuml/pull/2865
  • ⚡️ Smetana performance: dictionary and debug trace hot paths no longer construct exceptions by @lemonlion in https://github.com/plantuml/plantuml/pull/2858
  • ⚡️ Class diagrams: compile the URL regexp in isMethod once by @lemonlion in https://github.com/plantuml/plantuml/pull/2860
  • ✨ TeaVM: fall back to Smetana when viz-global.js is not loaded by @lemonlion in https://github.com/plantuml/plantuml/pull/2861
  • ♻️ Add README to site folder and reorganize JDepend tools by @The-Lum in https://github.com/plantuml/plantuml/pull/2869
  • ♻️ Move perf-bench and browser-test under tools/ by @lemonlion in https://github.com/plantuml/plantuml/pull/2868
  • 👷 update sonar action and GPL_ONLY var. usage by @The-Lum in https://github.com/plantuml/plantuml/pull/2871
  • 👷 perf-bench: recenter expected bands on the measured ratios by @lemonlion in https://github.com/plantuml/plantuml/pull/2862
  • 📝 Document missing Javadoc @param tags #2629 by @AzazelSensei in https://github.com/plantuml/plantuml/pull/2850
  • ⬆️ Bump actions/setup-node from 6 to 7 by @dependabot[bot] in https://github.com/plantuml/plantuml/pull/2844
  • ✨ Stdlib includes for every host of the browser engine: PLANTUML_STDLIB_BASE and PLANTUML_STDLIB_LOADER by @lemonlion in https://github.com/plantuml/plantuml/pull/2873
