#エルメスエージェント v0.23.0

発売日: 2026 年 11 月 5 日 v0.22.0 以降: ~10,080 コミット · ~1,950 マージ PR · ~8,720 ファイル変更 · ~725,200 挿入 · ~201,400 削除 · ~850 件クローズ済み · 666 人の寄稿者

囲炉裏の解放 古い賛美歌では、ヘルメスが敷居を守り、ヘスティアが囲炉裏を守り、二人は並んで称賛されました。 v0.22.0 は新人を門から押し入れました。 v0.23.0 は周囲に集まった火を起こします。見出し: デスクトップ ワークスペース全体が、独自のゲートウェイによって提供されるブラウザー タブで開かれるようになりました。その下では、すべての会話が 1 か所に存在します。単一のゲートウェイが各セッションを所有し、CLI、TUI、デスクトップ、エディター、ボット、および cron は、それぞれが独自のエージェントを実行するのではなく、すべて同じテーブルに座ります。その 1 つの炉から、デスクトップは、Hermes を実行しているすべてのマシンを同時に接続し続け、グループ チャットは独自の会話をルーティングし、最終的にターミナルは画像をインラインで描画し、会話を巻き戻すことができます。その周りには、常に更新されるプラグイン、有料 MCP ツールの値札と支出制限、プラグイン可能な委任、約 600 エントリから 1,050 以上のエントリに増加したプラグイン カタログ、よりスリムな組み込みスキル セット、および長寿命のゲートウェイのための長時間のメモリとレイテンシの作業が含まれます。このリリースには、v0.22.1 ～ v0.22.7 パッチ リリースがまとめられ、完全に文書化されています。

✨ ハイライト

  • ブラウザー タブ内のデスクトップ ワークスペース - 新しい Web アプリは、ネットワーク上の任意のブラウザーまたはサインインを使用したパブリック URL の背後で、独自のゲートウェイから完全なデスクトップ ワークスペースを提供します。同じチャット、グループ チャット、プラグイン、設定が含まれます。 Docker 画像と Nix パッケージが出荷されます。デフォルトではオフになっています。 webapp.enabled または設定の Web アクセスでオンにします。 (#141864、#145598、#145536、#145072、#145153 — @jquesnelle、@BearHuddleston、@IAvecilla、 @アドラニウム)

  • 1 つのゲートウェイがすべての会話を所有 — 以前は、CLI、TUI、デスクトップ、エディター (ACP)、メッセージング ボット、および cron がそれぞれ同じチャットに対してエージェントの独自のコピーを実行できました。これにより、メッセージが 2 回書き込まれたり、サーフェス間で消失したりしていました。現在、各マシンはすべてのセッションを所有する 1 つのゲートウェイを実行し、すべてのサーフェスが client として接続されています。どこで開いてもチャットは同じチャットであ​​り、1 つのキューと 1 つの履歴があります。キューに入れられたプロンプトを 2 回実行しなくても、デスクトップから操作したり編集したりすることもできます。 (#106742、#140334 — @unsupportedpastels、@kshitijk4poor)

  • ターミナル内の画像 — 画像を貼り付けるか、ツールがスクリーンショットを撮ると、CLI と TUI は、ファイル パスを印刷する代わりにチャット内に画像を直接描画するようになりました。kitty と Ghostty (CLI と TUI) と iTerm2、WezTerm、Konsole (CLI) では実際のピクセルが表示され、その他の場所では色付きのブロックが表示され、画像サポートがオンになっている場合は VS Code のターミナルでフル解像度が表示されます。 (#147293、#148874 — @Adolanium)

  • 会話を巻き戻す — Esc を 2 回押すか、TUI または従来の CLI で /rewind と入力し、以前のメッセージを選択して編集して再送信するか、その時点から新しいセッションをフォークします。元のセッションはそのまま残ります。 TUI は、ターンの実行中に /new を開始することもできます。古いものはバックグラウンドで動作し続けます。 (#144937、#148880 — @SaguaroDev)

  • すべてのマシンを 1 つのデスクトップ ウィンドウに表示 — デスクトップではすべてのゲートウェイが同時に接続された状態になるため、このコンピュータと SSH またはリモート ゲートウェイ間の切り替えが瞬時に行えます。ターミナル タブは、タブが開かれたホスト上で実行され、グループ チャットでは異なるマシンのボットを混合できます。 (#147681、#147708、#148418 — @dskwe、@janviernine)

  • 自動的に実行されるグループ チャット — ボット モード ルームでは、リード ボットまたは自動ルーターが、誰も名前を出さないメッセージに応答する人を選択できます。スケジュールされたジョブをルームに投稿でき、ルームには目的と共有メモが保存され、ボットが無限ループで相互に ping を送信することはなくなりました。ルームも通常の Herme チャットのように見え、各ボットはライブで何をしているかを表示します (「スカウト・ターミナル・7s」)。 (#144833、#148417、#148888、#148903、#148422 — @KoNit-K)

  • 最新の状態に保つプラグイン - hermes plugins update はすべてを一度に更新し、オプトインの自動更新スイッチ (CLI、チャット、デスクトップ、ダッシュボード) によりカタログと git プラグインを最新の状態に保ちます。セットアップを破壊する可能性のある更新は、適用されずに保留されます。カタログ自体は約 600 エントリから 1,050 以上のエントリに増加し、ベンダー自身が構築したプラグインを新しい Verified レベルでマークします。 (#141513、#85794、#143468、#144257 — @charan-rathore、@YS-OH-CORE)

  • 有料ツールの値札と使用制限 - 3D やメディア生成などの有料 MCP ツールは、通話にかかる費用を宣言できます。承認プロンプトには各通話の料金とチャットの累計が表示され、YOLO モードであってもチャットが制限を超える前に Hermise が質問します。 (#142470、#143780、#143795、#143787 — @liuhao1024、@fangliquanflq)

  • 新しい公式プラグインと小型コア - Meshy (テキストと画像を 3D に変換)、イレブンラボの音楽とサウンドエフェクト、X Chat、REA (リバース エンジニアリング)、および Bubblewrap サンドボックスが 1 つのコマンドでインストールできるようになりました。 Camofox、mcp-serve、エージェント インポーター、および Singularity はコアからプラグインに移行し、使用する人全員に自動的にインストールされるようになりました。 (#142619、#146294、#139725、#143484、#139983)

  • サブエージェントの実行方法を選択 — 委任がプラグ可能になりました。デフォルトのままにするか、公式 advanced-delegation プラグインをインストールして、各サブエージェント タスクを名前付きモデルまたは別のプロファイルに送信します。 /delegationで切り替えます。 (#142563、#142564、#143423)

  • 軽量かつ高速、特に Hermes を一日中実行する場合 — 定期的な cron ジョブはプロンプト キャッシュを共有し、ワンショット実行では呼び出しごとに送信されるプロンプト トークンが約 1,570 少なくなり、LSP がオンの場合は patch/write_file がミリ秒で返されます。長く存続するゲートウェイは閉じられたセッションのメモリを解放し、セッションが蓄積してもデスクトップ サイドバーの速度が低下することはなくなりました (約 35,000 回の cron 実行を行った 1 つのストアでは、121 秒の更新から瞬時に更新されました)。 (#139876、#144177、#140387、#147863、#137087、#147819、 #144940 — @kshitijk4poor)

  • ロックできる無駄のないスキル セット — 組み込みスキルは 58 から 44 に増加し、Word、PowerPoint、Excel が 1 つの microsoft-office スキルに統合されました。 hermes curator lock は、YOLO モードであっても、エージェントが任意のツールを使用して手動でキュレートしたスキルを書き換えるのを防ぎます。 (#147557 — @davisford)

  • パスワード マネージャーとキーチェーン ボールト キー — 検証済みのパスワード マネージャー プラグインは、他のユーザーのログインを見ることなくブラウザーにログイン情報を渡すことができ、ブラウザー ボールトのキーは OS キーチェーン内に存在できるようになります。 (#143964、#144246 — @Jesssullivan)

  • 実行中の cron ジョブを停止する - CLI、デスクトップ、API、またはエージェント自体から実行中のジョブをキャンセルし、Hermes がオフのときに実行されなかった場合に何が起こるかをジョブごとに設定します。 (#144801 — @kokhlo、@fangliquanflq、@LeonSGP43)

⚠️ アップグレードに関する注意事項

  • 古い組み込みブラウザ ツールは廃止されました。 ブラウザ自動化は browser_exec でのみ実行されます。エージェント ブラウザーと 10 個の browser_* ツール (browser_navigate、browser_click など) が削除されました。 Camofox を使用していた家庭には、camofox プラグインが自動的にインストールされます。独自のプロンプト、スキル、またはツールセット リストで古いツールの名前が指定されている場合は、それらを browser_exec に切り替えます。 (#143146)
  • デスクトップには macOS 13 以降および 64 ビット Windows が必要です。 アプリは Electron 44 に移行され、macOS 11、macOS 12、または 32 ビット Windows では実行されなくなりました。 (#142727 — @OutThisLife、@Adihaliem)
  • hermes mcp serve は hermes mcp-serve になりました (プラグインに移動されました)。 MCP cliHermes をサーバーとして起動するエントでは、コマンドを更新する必要があります。それを書き換えるものは何もありません。
  • Word、PowerPoint、Excel のスキルは 1 つの microsoft-office スキルになりました。 古いコピーは、削除するまでディスク上に残ります。
  • Web アプリはデフォルトでオフになっています。 webapp.enabled または Web アクセスをオンにするまで、ブラウザには何も提供されません。

プロバイダーとモデル

  • GLM-5.3 は、選択しない場合のデフォルト モデルです — サイレント デフォルトは、ほぼ同じ価格で、Nous Portal と OpenRouter で同じ 1M コンテキスト ウィンドウを備えた GLM-5.2 から GLM-5.3 に移行します。 (#144810 — @calvinnwq)
  • 新モデル — GPT-6.1 Terra、DeepSeek V4.1 Flash 1017、および Solstice の Gemini 4 Argon。クロード・ミュトスは常に考えているものとして扱われるため、論理的なリクエストが最初の試行で失敗することはなくなります。 Nemotron 3.5 Super VL はデフォルトのパラメータを取得します。 (#145204、#140496、#139466、#148127、#138462 — @benbarclay、@unsupportedpastels、@rroverin)
  • 使用期間プラン — クレジットではなく許容量として使用量を追跡するサブスクリプションでは、/usage はリセット時間とともに許容量ごとに 1 つのバーを表示します。ピッカーはプランの推奨モデルを最初にリストし、それらに「Large」または「Free」のタグを付け、許容量がなくなったときに通知します。 (#142308、#145682 — @rob-maron)
  • 承認された ChatGPT サブスクリプションの夜明け — デフォルトでオフの agent.daybreak スイッチにより、OpenAI の Trusted Access for Cyber プログラムがオンになります。これは、アカウント独自の Codex カタログに承認済みとしてリストされているモデルにのみ表示され、リクエストごとに再度チェックされます。 (#148056 — @unsupportedpastels、@Froraut)
  • /model reset — CLI、TUI、デスクトップ、およびメッセージングで、会話を失うことなく、/model で固定されたセッションを設定されたデフォルトに戻します。 (#80448 — @shannonsands)
  • GitHub Copilot が labs プラグインに移動 — Copilot (copilot、copilot-acp) は github-copilot Hermes Labs プラグイン内に存在し、Copilot を使用するプロファイルは自動的にインストールされます。コアは、任意のプロバイダー プラグインが使用できる汎用プロバイダー フックを保持します。 (#144788)
  • カスタム エンドポイントは確実に解決 — 新しいプロファイルは、「不明なプロバイダー」で失敗するのではなく、custom:<name>、${VAR}、および従来のカスタム エンドポイントを継承します。再開されたチャットは、チャットを提供したエンドポイントに残り、組み込みプロバイダーのキーが同じ名前のカスタム エントリに漏洩することはなくなりました。 (#138513、#139947、#140335、#147761 — @jquesnelle、@unsupportedpastels)
  • プロバイダーの不具合の処理 — LM Studio、Kimi、MiniMax からのストリーミングされたツール呼び出しが分割された呼び出しに分割されなくなりました。 Gemini の安全ブロックはコンテンツ ポリシー エラーとして表示され、フォールバック モデルに移行します。画像を拒否するテキスト専用 vLLM サーバーが回復し、バイトキャップ 400 が圧縮をトリガーします。 Bedrock では、ハング コールは読み取りタイムアウトが 5 回ではなく 1 回後に失敗します。 (#140485、#85031、#85005、#85126、#146314 — @Chukwuebuka-2003)
  • llama.cpp b11671 のローカル ランタイム — 1 スロットの DFlash ドラフトとオプトイン Nemotron 3.5 ボルトを追加します。 (#139703 — @jquesnelle)

エージェント ループとセッション

  • プロンプト トークンとキャッシュのコストの削減 — 同じ cron ジョブのすべての起動で 1 つのプロンプト キャッシュ キーが共有されるようになりました。バックグラウンドでのワンショット呼び出し (要約、タイトル、/moa) では、キャッシュ書き込みに対する料金の支払いが停止されます。ワンショット実行では、呼び出しごとに送信されるプロンプト トークンが 1,570 少なくなり、4 つのツール スキーマは 319 トークン短くなります。ゲートウェイ ゴールとハートビート ターン、圧縮後のターン、およびターン間の MCP リフレッシュでは、キャッシュされたプレフィックスが書き換えられなくなりました。 (#139876、#140478、#144177、#144173、#139865、#139851 — @100yenadmin, @jonpol01、@chelsealong、@AdrianBinDC)
  • オプトインの準備済み圧縮 — compression.prepare_ahead: true では、セッションがトリガーに近づくと次の要約がバックグラウンドで書き込まれるため、要約の書き込み中に圧縮によってターンが一時停止されることがなくなりました。その間に到着したメッセージは、一言一句末尾に残ります。デフォルトではオフです。 (#144684、#144886 — @kshitijk4poor)
  • 圧縮はより正直で失速しにくい — 概要には UNVERIFIED: 行に関する不確実な主張がリストされているため、推測が事実として返されることはありません。メイン モデルのフォールバックはメイン ルートを使用し、/stop は要約ストリームを閉じ、キューに入れられたメッセージと /steer はコンテキスト枯渇リセット後も存続します。 (#86019、#139872、#144825、#139783、#139923 — @helix4u、@thehugegatsby)
  • hermes sessions refresh-prompts — 継続中のセッションでは、編集済みの SOUL.md、スキル、またはコンテキスト ファイルが次のターンで /new なしで取得されます。履歴は保持され、各セッションで 1 回のキャッシュ ミスが発生します。 (#143581 — @victor-kyriazakos)
  • オプトイン ストリームのライフタイム キャップ - agent.stream_max_lifetime (デフォルトではオフ) は、終了しないストリームを切断します。タイムアウト エラーには、失敗したフェーズと引き上げる設定が示されるようになりました。 (#80701、#80873 — @krzsda)
  • 写真に関するフォローアップの質問でも写真が表示されます — これは、--resume、API サーバー セッションの継続とゲートウェイの再起動後に適用されます。 (#139873 — @Alexbob0)
  • セッション ストレージ - 自動プルーンが再びオプトインされ、ディスクが少なくなったときに Hermes が 1 回尋ねます。 hermes sessions optimize-storage は進歩を示し、実店舗を約 18 倍の速さで完成させました。起動はスクラッチ プルーンを待機しなくなり、hermes sessions 障害は出口 1 で発生します。 (#139762、#144630、#144625、#144767)

メッセージング プラットフォーム (ゲートウェイ)

  • 1 つのゲートウェイがすべてのローカル セッションを所有するようになりました — v0.22.0 以降、従来の CLI、TUI、デスクトップ、API、ACP エディター、ボット、および cron はすべて 1 つのゲートウェイを介してセッションを実行します。このサイクルにより、問題が修正されました。スラッシュ コマンド、/retry、/refine、/review、明確化カード、推論表示、使用法と ACP セッションが再び機能し、設定の変更が再開されたセッションに反映されました。 (#139149、#139577、#139884、#140249、#140595、#141916、 #144005、#138719 — @unsupportedpastels、@yoniebans、@drzxk、@fangliquanflq)
  • ゲートウェイのメモリと応答性 — メモリ トリム中のおよそ 1 分に 1 回のフリーズはなくなり、閉じられたセッションはメモリから残り、glibc malloc アリーナの上限は 4 になり、測定されたイベント ループ ブロッカーはループから移動されました。 (#147840、#147831、#147810、#144911、#137156 — @koyichi、@ygd58、@zwmaupin, @kshitijk4poor)
  • より安全なゲートウェイ ライフサイクル — hermes gateway stop/restart はセッションがライブ中は拒否し、他のホームのサービスに影響を与えることはありません。エージェントの端末から起動されたゲートウェイは、自身を launchd サービスと誤認することがなくなり、起動時にすべてのプラットフォームに障害が発生しても、ゲートウェイは低下した状態で稼働したままになります。 (#142041、#145930、#144592、#140922 — @salch-cred)
  • ボット モード グループ チャット — Cron ジョブはルーム (deliver: room:<id>@<profile>) に投稿でき、@メンションしたボットのみを起動できます。ルームには目的と共有メモがあり、2 つのオプトイン モードにより、誰も名前を出さないメッセージ (リード ボットまたは auto ルーティング) に応答する人が選択されます。 message_agent は、応答するたびに質問者を 1 回目覚めさせます。 (#144833、#148417、#148888、#144789 — @rorsch、@OutThisLife)
  • ボット間のループの終了 — ボットは実行時通知を受信せず、人間による最後のメッセージ後の交換は max_hops (デフォルト 4) に制限されます。 hermes peer dm <peer>/hermes はピアのデフォルト ボットに到達します。 (#148903、#144900 — @KoNit-K)

  • ツールのコストとチャットあたりの支出制限 - MCP サーバーは、プラグイン パッケージまたは config.yaml から、各ツールのコストとチャットあたりの支出制限を宣言できます。承認プロンプトにはコストとチャットの累計が表示され、trusted サーバーまたは YOLO モードであっても、制限を超える可能性のある通話については最初に質問されます。 (#142470、#143787)

hermes-agent v0.23.0

Hermes Agent v0.23.0

Release Date: November 5, 2026 Since v0.22.0: ~10,080 commits · ~1,950 merged PRs · ~8,720 files changed · ~725,200 insertions · ~201,400 deletions · ~850 issues closed · 666 contributors

The Hearth Release. In the old hymns Hermes kept the threshold and Hestia kept the hearth, and the two were honored side by side. v0.22.0 got newcomers through the door; v0.23.0 builds the fire they gather around. The headline: your whole Desktop workspace now opens in a browser tab, served by your own gateway. Underneath it, every conversation lives in one place: a single gateway owns each session, and the CLI, TUI, Desktop, editors, bots and cron all sit down at the same table instead of each running its own agent. From that one hearth, Desktop keeps every machine you run Hermes on connected at once, Group Chats route their own conversations, and the terminal finally draws your images inline and lets you rewind a conversation. Around it: plugins that keep themselves updated, price tags and spend limits on paid MCP tools, pluggable delegation, a plugin catalog that grew from about 600 to over 1,050 entries, a leaner built-in skill set, and a long run of memory and latency work for long-lived gateways. This release rolls up and fully documents the v0.22.1–v0.22.7 patch releases.

✨ Highlights

  • Your Desktop workspace in a browser tab — The new Webapp serves the full Desktop workspace from your own gateway: the same chats, Group Chats, plugins and settings, in any browser on your network or behind a public URL with sign-in. The Docker image and Nix package ship it. It is off by default; turn it on with webapp.enabled or Web Access in Settings. (#141864, #145598, #145536, #145072, #145153 — @jquesnelle, @BearHuddleston, @IAvecilla, @Adolanium)

  • One gateway owns every conversation — Before, the CLI, TUI, Desktop, editors (ACP), messaging bots and cron could each run their own copy of the agent against the same chat, which is how messages got written twice or went missing between surfaces. Now each machine runs one gateway that owns every session, and every surface attaches to it as a client: a chat you open anywhere is the same chat, with one queue and one history. You can even steer or edit a queued prompt from Desktop without it running twice. (#106742, #140334 — @unsupportedpastels, @kshitijk4poor)

  • Pictures in the terminal — When you paste an image, or a tool takes a screenshot, the CLI and TUI now draw it right in the chat instead of printing a file path: real pixels in kitty and Ghostty (CLI and TUI) and in iTerm2, WezTerm and Konsole (CLI), coloured blocks everywhere else, and full resolution in VS Code's terminal when its image support is on. (#147293, #148874 — @Adolanium)

  • Rewind a conversation — Press Esc twice or type /rewind in the TUI or classic CLI, pick an earlier message, then edit and resend it or fork a new session from that point. The original session stays exactly as it was. The TUI can also start /new while a turn is still running; the old one keeps working in the background. (#144937, #148880 — @SaguaroDev)

  • Every machine in one Desktop window — Desktop now keeps all your gateways connected at once, so switching between this computer and an SSH or remote gateway is instant. Terminal tabs run on the host they were opened on, and a Group Chat can mix bots from different machines. (#147681, #147708, #148418 — @dskwe, @janviernine)

  • Group Chats that run themselves — Bot Mode rooms can let a lead bot, or an automatic router, pick who answers a message that names nobody. Scheduled jobs can post into a room, rooms keep a purpose and shared notes, and bots no longer ping each other in endless loops. Rooms also look like a normal Hermes chat now, and each bot shows what it is doing live ("scout · terminal · 7s"). (#144833, #148417, #148888, #148903, #148422 — @KoNit-K)

  • Plugins that keep themselves current — hermes plugins update updates everything at once, and an opt-in Auto-update switch (CLI, chat, Desktop and dashboard) keeps catalog and git plugins up to date. Updates that would break your setup are held back instead of applied. The catalog itself grew from about 600 to over 1,050 entries, and a new Verified tier marks plugins built by the vendor itself. (#141513, #85794, #143468, #144257 — @charan-rathore, @YS-OH-CORE)

  • Price tags and spend limits for paid tools — Paid MCP tools, such as 3D or media generation, can declare what a call costs. The approval prompt shows each call's price and the chat's running total, and Hermes asks before a chat goes over its limit, even in YOLO mode. (#142470, #143780, #143795, #143787 — @liuhao1024, @fangliquanflq)

  • New official plugins, and a smaller core — Meshy (text and image to 3D), ElevenLabs Music and Sound Effects, X Chat, REA (reverse engineering) and a bubblewrap sandbox are now one-command installs. Camofox, mcp-serve, the agent importers and Singularity moved out of core into plugins that install themselves for anyone who used them. (#142619, #146294, #139725, #143484, #139983)

  • Choose how subagents are run — Delegation is now pluggable: keep the default, or install the official advanced-delegation plugin to send each subagent task to a named model or into a separate profile. Switch with /delegation. (#142563, #142564, #143423)

  • Lighter and faster, especially when Hermes runs all day — Recurring cron jobs share a prompt cache, one-shot runs send about 1,570 fewer prompt tokens per call, and patch/write_file return in milliseconds with LSP on. Long-lived gateways now let go of closed sessions' memory, and the Desktop sidebar no longer slows down as sessions pile up (one store with ~35k cron runs went from a 121 s refresh to instant). (#139876, #144177, #140387, #147863, #137087, #147819, #144940 — @kshitijk4poor)

  • A leaner skill set you can lock — The built-in skills went from 58 to 44, with Word, PowerPoint and Excel merged into one microsoft-office skill. hermes curator lock stops the agent from rewriting a skill you curated by hand, through any tool, even in YOLO mode. (#147557 — @daviseford)

  • Password managers and a keychain vault key — Verified password-manager plugins can hand the browser your logins without seeing anyone else's, and the browser vault's key can now live in your OS keychain. (#143964, #144246 — @Jesssullivan)

  • Stop a running cron job — Cancel a running job from the CLI, Desktop, the API or the agent itself, and set per job what happens to runs missed while Hermes was off. (#144801 — @kokhlo, @fangliquanflq, @LeonSGP43)

⚠️ Upgrade notes

  • The old built-in browser tools are gone. Browser automation runs on browser_exec only; agent-browser and the ten browser_* tools (browser_navigate, browser_click, ...) were removed. Homes that used Camofox get the camofox plugin installed automatically. If your own prompts, skills or toolset lists name the old tools, switch them to browser_exec. (#143146)
  • Desktop needs macOS 13+ and 64-bit Windows. The app moved to Electron 44, which no longer runs on macOS 11, macOS 12 or 32-bit Windows. (#142727 — @OutThisLife, @Adihaliem)
  • hermes mcp serve is now hermes mcp-serve (it moved into a plugin). MCP clients that launch Hermes as a server need their command updated; nothing rewrites it for you.
  • Word, PowerPoint and Excel skills are now one microsoft-office skill. Old copies stay on disk until you remove them.
  • The Webapp is off by default. Nothing is served to a browser until you turn on webapp.enabled or Web Access.
