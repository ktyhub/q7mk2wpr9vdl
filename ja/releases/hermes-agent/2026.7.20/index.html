エルメスエージェント v2026.7.20

#エルメスエージェント v0.19.0(v2026.7.20) 発売日: 2026 年 7 月 20 日 v0.18.0 以降: ~2,245 コミット · ~1,065 マージ PR · ~2,465 ファイル変更 · ~300,000 挿入 · ~36,000 削除 · ~3,300 件がクローズ · 450 人以上のコミュニティ貢献者

クイックシルバー リリース。 エルメスはメッセンジャーの神であり、このウィンドウでは彼をそのように動かしました。最初のターンから最初のトークンまでの時間が ** すべてのプラットフォームで最大 80%** 低下し、ストリームがデフォルトでライブになるため、デスクトップ アプリは最大 20 PR 速度のオーバーホール (14 倍高速のストリーミング マークダウン、仮想化された差分、迅速なセッション切り替え) が行われ、TUI は段階的にマークダウンをレンダリングします。このスピードの背骨のあたりで、端末を離れることなく Nous サブスクリプションを管理できるようになり、Bitwarden と 1Password を Hermes に直接接続し、スマート承認 がフラグ付きコマンドをデフォルトで判断し、サブエージェントの動作をライブで監視し、耐久性のある配信台帳のおかげで完了した応答が ゲートウェイのクラッシュに耐えられることを確認できます。このリリースでは、v0.18.1 および v0.18.2 インフラストラクチャ パッチ タグのすべてもロールアップされます。これらのウィンドウについては、ここで完全に文書化されています。

✨ ハイライト

  • **Hermes が劇的に速くなりました - 最初のトークンがほんの少しの時間で ** - コールド スタートの「エージェントの初期化中...」は、最初のターンがモデルに到達する前に ~4.3 秒を消費していました。現在では最大 0.9 秒であり、CLI、ゲートウェイ、TUI、デスクトップ、および cron に同様に適用される最大 80% の短縮です。ラウンド 2 では、待機中に 見えるものを攻撃しました。推論モデルはデフォルトで思考をライブでストリーミングするようになり (スピナーを 30 秒間見つめることはなくなりました)、応答ボックスは行ごとではなくトークンごとに描画されます。エルメスが答える前に深呼吸をしたように感じたことがあったとしても、その呼吸は消えています。 (#59332、#59389 — @teknium1)
  • デスクトップ アプリのスピード ウェーブ - 20 を超えるターゲット パフォーマンス PR - 以前は、長い返信により、マークダウン スプリッターの CPU に現在の 14 倍のコストがかかりました。巨大な差分により、仮想化するまでレビュー ペインがフリーズしていました。セッションを切り替えてもレイアウトが乱れることがなくなりました。ストリーミングでは、トークンごとにサイドバーとすべてのツール行が再レンダリングされなくなり、ホバー インテントでプロファイル バックエンドが事前にウォーム化され、ブート非表示のペインがコールド スタート クリティカル パスではなくアイドル時にマウントされます。最終的な効果: デスクトップ アプリは、膨大なトランスクリプトや多忙なエージェントが存在する場合でも、負荷がかかっている状態ではネイティブ アプリのように感じられます。 (#67154、#67818、#65898、#66033、#66747、#67742 など — @OutThisLife)
  • ターミナルから Nous プランを管理します — /subscription および /topup — 以前は、サブスクリプションを変更するには、請求先 Web サイトにアクセスする必要がありました。 /subscription は、TUI または従来の CLI で直接完全なフローを開きます。プランと残りの許容量を確認し、アップグレードの費用を正確にプレビュー (「$46.30 を支払って今すぐアップグレード」)、またはダウングレードがいつ有効になるかをプレビューし、スケジュールされた変更バナーと元に戻す機能を使用して適用します。デスクトップ アプリには、対応する請求設定タブがありました。財布をキーボードから離れる必要はありません。 (#51639、#61054、#61067 — @alt-glitch)
  • スマート承認がデフォルトになりました —Hermes がフラグ付きコマンドを実行したい場合、LLM レビュー担当者がすべてのコマンドの承認を求めるのではなく、独立してそのコマンドを評価するようになりました。各判定はそのコマンドのみを対象とするため、同じパターンに一致する後のコマンドは独自のレビューを受けます。新しい ユーザー定義の拒否ルール (yolo モードでもコマンドをブロックします) と /deny <reason> (拒否した 理由 をエージェントに伝え、軌道修正します) と組み合わせることで、制御を放棄することなく、日々の承認疲労が急激に軽減されます。 (#62661、#59164、#54518 — @teknium1)
  • パスワード マネージャーを Hermes に接続します — Bitwarden と 1Password の秘密ソース — API キーはプレーンテキスト .env に存在する必要がなくなりました。新しいプラグイン可能な SecretSource インターフェイスにより、Hermes は読み込み時に Bitwarden と 1Password (op:// 参照) からシークレットを取得できます。複数のボールトが同時に有効になり、決定的な優先順位、競合警告、および変数ごとの来歴が表示されます。これにより、競合する 11 のコミュニティ PR が 1 つの統合されたインターフェイスに統合され、将来の Vault プロバイダーがプラグインとして追加されます。 (#59498 — @teknium1、@hwrdprkns から回収された 1Password プロバイダー)
  • サブエージェントの動作を監視します - ライブ トランスクリプト + 永続的なバックグラウンド委任 - delegate_task ディスパッチは、サブエージェントが起動した瞬間に tail -f できるライブ トランスクリプト ファイルを返すようになりました: すべてのツール呼び出し、結果、ストリーミング応答、子ごとに 1 つの人間が判読できるログ。また、バックグラウンド委任の完了は 耐久性 になりました。プロセスが実行中に再起動された場合、結果は消えるのではなく、所有権がチェックされた台帳を通じて復元され、配信されます。フリートを拡張し、ワーカーをライブで監視し、結果を失うことはありません。 (#67479、#63494 — @teknium1)
  • 完成した回答はもう失われることはありません — 配送義務台帳 — 回答を生成してからプラットフォームが実際に回答を配信したことを確認するまでの間にゲートウェイが停止した場合、以前はその回答は静かに消えていました (そしてあなたはそのターンの代金を支払ったことになります)。最終応答は、プラットフォーム送信時に state.db の耐久性のある台帳に記録され、次回起動時に再配信されます。これにより、Telegram、Discord、Slack、その他すべてのチャネルの P1 サイレント損失ウィンドウが閉じられます。 (#67181 — @teknium1)
  • 1 つのゲートウェイ、多数のプロファイル — プロファイルベースのメッセージ ルーティング — 1 つのボット トークンを共有する単一の多重ゲートウェイで、特定のギルド、チャネル、スレッドを異なるプロファイルにルーティングできるようになりました。それぞれのプロファイルは完全に分離された構成、スキル、メモリ、シークレットを持ちます。 1 つのボットから、職場の Discord サーバーを work プロファイルに、趣味のサーバーを personal に設定します。 2 回目の多重強化の波は、1 つの誤った構成のプロファイルによってゲートウェイ全体を停止できなくなることを意味します。 (#64835 @Burgunthy を回収中、#65700、#60589 — @teknium1、@benbarclay + 回収された 6 人の貢献者)
  • 新しいプロバイダーと最新のフロンティア モデル — Fireworks AI と DeepInfra がファーストクラスのプロバイダーとして登場 (コスト見積もりを備えた Fireworks とプロバイダー ピッカーの #2 スロット)、Upstage Solar がサルベージ経由で参加し、モデル カタログが取得されました GPT-5.6 (Sol/Terra/Luna + Pro バリアント、すべてのルートでエンドツーエンドで有線接続)、grok-4.5 (GA)、moonshotai/kimi-k3、claude-fable-5 / claude-sonnet-5、および GA tencent/hy3 — 加えて、ローカル セットアップ用の LM Studio JIT モデルのロード。 (#62593、#63969、#61616 — @kshitijk4poor @rob-maron の #61578、#60887、#65913 を完成させました、 #64541、#65472)
  • 思考を最大限に高める — 新しい推論労力層とモデルごとの制御 — 推論労力は max および ultra レベル (GPT-5.6 および Codex の最上位層) になり、CLI からデスクトップまでどこでも選択可能で、小規模なプロバイダーを適切に制限します。また、設定でモデルごとの推論エフォートのオーバーライドを固定したり、MoA プリセットでスロットごとのエフォートを設定したり（アドバイザーは熱心に考え、シンセサイザーは高速なままです）、補助モデルのタスクごとのエフォートを設定したりすることもできるようになりました。思考の深さはグローバル スイッチではなくダイヤルになりました。 (#62650、#64458、#64631、#64597 — @teknium1)
  • セッション、データ — すべてをエクスポート — hermes sessions export は、完全なフィルター サーフェス (年齢、ワークスペース、プラットフォーム)、オプトインの --redact シークレット スクラビング パス、および圧縮されたセッション リネージを 1 つの論理エクスポートにつなぎ合わせて、Markdown、Quarto、HTML、プロンプトのみ、さらには Hugging Face 対応のトレース形式を書き込むようになりました。新しいプルーン フィルターと一括アーカイブを組み合わせて、セッション ストアを整理整頓してください。会話履歴はブラック ボックスではなく、実際のデータセットになります。 (#60186 @web3blind をサルベージ中、#60492、#60507、#59327 — @teknium1)
  • セキュリティ強化ラウンド — このウィンドウは、資格情報表面のギャップの長いリストを閉じました。頂点資格情報はサブプロセス環境から離れてプロファイル シークレット スコープを介してスコープ設定され、メディア/ビジョン/イメージ生成ローカル ファイル読み取りは 1 つの共有資格情報読み取りガードを介してルーティングされ、すべての aiohttp サーバーにわたる Webhook のボディサイズキャップ スイープ、Telegram トランスポート エラーでのボット トークンの編集、Fireworks トークン プレフィックスの追加redactor、6 つの P1 ブラウザ/MEDIA/.env 強化 PR が 1 パスでサルベージされ、CI は untrusted-ref 補間に対して強化されました。 (#57660、#58709、#59215、#56582、#57842 — @teknium1、@srojk34、@kshitijk4poor、@jquesnelle)

推論とMOA

  • すべてのサーフェスとルートにわたる max + ultra の努力レベル (#62650 — @teknium1)

Hermes Agent v0.19.0 (v2026.7.20)

Release Date: July 20, 2026 Since v0.18.0: ~2,245 commits · ~1,065 merged PRs · ~2,465 files changed · ~300,000 insertions · ~36,000 deletions · ~3,300 issues closed · 450+ community contributors

The Quicksilver Release. Hermes is the messenger god, and this window we made him move like it. First-turn time-to-first-token dropped ~80% on every platform, reasoning streams live by default, the desktop app got a ~20-PR speed overhaul (14× faster streaming markdown, virtualized diffs, snappy session switching), and the TUI renders markdown incrementally. Around that speed spine: you can now manage your Nous subscription without leaving the terminal, plug Bitwarden and 1Password straight into Hermes, let smart approvals judge flagged commands for you by default, watch your subagents work live, and trust that a finished response survives a gateway crash thanks to a durable delivery ledger. This release also rolls up everything from the v0.18.1 and v0.18.2 infrastructure patch tags — those windows are fully documented here.

✨ Highlights

  • Hermes got dramatically faster — first token in a fraction of the time — Cold-start "Initializing agent..." used to eat ~4.3 seconds before your first turn even reached the model; it's now ~0.9s, an ~80% cut that applies to the CLI, gateway, TUI, desktop, and cron alike. Round 2 attacked what you see while waiting: reasoning models now stream their thinking live by default (no more staring at a spinner for 30 seconds), and the response box paints per token instead of per line. If Hermes ever felt like it took a deep breath before answering, that breath is gone. (#59332, #59389 — @teknium1)

  • The desktop app speed wave — 20+ targeted perf PRs — Long replies used to cost 14× more CPU in the markdown splitter than they do now; giant diffs froze the review pane until we virtualized it; switching sessions thrashes layout no more. Streaming no longer re-renders the sidebar and every tool row per token, profile backends pre-warm on hover intent, and boot-hidden panes mount at idle instead of on the cold-start critical path. The net effect: the desktop app feels like a native app under load, even with huge transcripts and busy agents. (#67154, #67818, #65898, #66033, #66747, #67742 and more — @OutThisLife)

  • Manage your Nous plan from the terminal — /subscription and /topup — Changing your subscription used to mean a trip to the billing website. Now /subscription opens a full flow right in the TUI or classic CLI: see your plan and remaining allowance, preview exactly what an upgrade costs ("Pay $46.30 & upgrade now") or when a downgrade takes effect, and apply it — with scheduled-change banners and undo. The desktop app got a matching billing settings tab. Your wallet never has to leave the keyboard. (#51639, #61054, #61067 — @alt-glitch)

  • Smart approvals are now the default — When Hermes wants to run a flagged command, an LLM reviewer now assesses it independently instead of asking you to approve every single one — and each verdict covers only that exact command, so a later command matching the same pattern gets its own review. Combined with the new user-defined deny rules (which block commands even under yolo mode) and /deny <reason> (which tells the agent why you refused so it course-corrects), day-to-day approval fatigue drops sharply without giving up control. (#62661, #59164, #54518 — @teknium1)

  • Plug your password manager into Hermes — Bitwarden & 1Password secret sources — API keys no longer have to live in a plaintext .env. A new pluggable SecretSource interface lets Hermes fetch secrets from Bitwarden and 1Password (op:// references) at load time, with multiple vaults enabled simultaneously, deterministic precedence, conflict warnings, and per-variable provenance. This consolidated eleven competing community PRs into one orchestrated interface — future vault providers drop in as plugins. (#59498 — @teknium1, 1Password provider salvaged from @hwrdprkns)

  • Watch your subagents work — live transcripts + durable background delegation — delegate_task dispatches now return live transcript files you can tail -f the moment the subagents launch: every tool call, result, and streamed reply, one human-readable log per child. And background delegation completions are now durable — if the process restarts mid-run, results are restored and delivered through an ownership-checked ledger instead of vanishing. Fan out a fleet, watch any worker live, and never lose the results. (#67479, #63494 — @teknium1)

  • A finished answer can no longer be lost — the delivery-obligation ledger — If the gateway died between generating your response and confirming the platform actually delivered it, that answer used to be silently gone (and you'd paid for the turn). Final responses are now recorded in a durable ledger in state.db around the platform send and redelivered on the next boot — closing a P1 silent-loss window for Telegram, Discord, Slack, and every other channel. (#67181 — @teknium1)

  • One gateway, many profiles — profile-based message routing — A single multiplexed gateway sharing one bot token can now route specific guilds, channels, or threads to different profiles — each with fully isolated config, skills, memory, and secrets. Point your work Discord server at the work profile and your hobby server at personal, from one bot. A second multiplex hardening wave means one misconfigured profile can no longer take down the whole gateway. (#64835 salvaging @Burgunthy, #65700, #60589 — @teknium1, @benbarclay + six salvaged contributors)

  • New providers and the newest frontier models — Fireworks AI and DeepInfra land as first-class providers (Fireworks with cost estimation and a #2 slot in the provider picker), Upstage Solar joins via salvage, and the model catalogs picked up GPT-5.6 (Sol/Terra/Luna + Pro variants, wired end-to-end across every route), grok-4.5 (GA), moonshotai/kimi-k3, claude-fable-5 / claude-sonnet-5, and GA tencent/hy3 — plus LM Studio JIT model loading for local setups. (#62593, #63969, #61616 — @kshitijk4poor completing @rob-maron's #61578, #60887, #65913, #64541, #65472)

  • Crank the thinking to max — new reasoning effort tiers and per-model control — Reasoning effort gained max and ultra levels (GPT-5.6 and Codex's top tiers), selectable everywhere from the CLI to the desktop, with sane clamping on providers with smaller scales. You can now also pin per-model reasoning-effort overrides in config, set per-slot effort in MoA presets (your advisors think hard, your synthesizer stays fast), and per-task effort for auxiliary models. Thinking depth is now a dial, not a global switch. (#62650, #64458, #64631, #64597 — @teknium1)

  • Your sessions, your data — export everything — hermes sessions export now writes Markdown, Quarto, HTML, prompt-only, and even Hugging Face-ready trace formats, with the full filter surface (age, workspace, platform), an opt-in --redact secret-scrubbing pass, and compacted-session lineage stitched into one logical export. Pair with the new prune filters and bulk archive to keep your session store tidy. Your conversation history is a real dataset now, not a black box. (#60186 salvaging @web3blind, #60492, #60507, #59327 — @teknium1)

  • Security hardening round — This window closed a long list of credential-surface gaps: Vertex credentials scoped away from subprocess env and through profile secret scopes, media/vision/image-gen local-file reads routed through one shared credential-read guard, a webhook body-size-cap sweep across every aiohttp server, bot-token redaction in Telegram transport errors, Fireworks token prefixes added to the redactor, six P1 browser/MEDIA/.env hardening PRs salvaged in one pass, and CI hardened against untrusted-ref interpolation.
