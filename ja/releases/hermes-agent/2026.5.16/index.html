エルメスエージェント v2026.5.16

#エルメスエージェント v0.14.0(v2026.5.16) 発売日: 2026 年 5 月 16 日 v0.13.0 以降: コミット数 808 · マージされた PR 633 · 変更されたファイル 1393 · 挿入 165,061 · クローズされた問題 545 件 (P0 12、P1 50) · コミュニティ貢献者 215 名 (共著者を含む)

Foundation リリース — Hermes はどこにでもインストールして実行でき、実際に使用したいものは同梱され、使用しないものの出荷は停止されます。 xAI Grok は、grok-4.3 が 1M コンテキスト ウィンドウに割り当てられた SuperGrok OAuth プロバイダーとして登場します。新しい OpenAI 互換ローカル プロキシは、OAuth 認証された Herme プロバイダー (Claude Pro、ChatGPT Pro、SuperGrok) を、Codex / Aider / Cline / Continue がヒットできるエンドポイントに変えます。 x_search は、OAuth または API キー認証を備えたファーストクラスの X (Twitter) 検索ツールとして登場しました。 Microsoft Teams スタックは、エンドツーエンド (グラフ認証 + Webhook リスナー + パイプライン ランタイム + アウトバウンド配信) で接続されています。膨張の波により、インストールが劇的に軽くなります。重いバックエンドは初回使用時に遅延インストールされるようになり、[all] エクストラは遅延配備でカバーされるすべてのものをドロップし、プラットフォーム上でホイールが拒否すると段階的インストールがフォールバックします。 pip install hermes-agent は PyPI から動作します。コールドスタートウェーブにより、hermes の起動時間が最大 19 秒短縮されます。ブラウザ CDP 呼び出しは 180 倍高速です。 2 つの新しいメッセージング プラットフォーム (LINE + SimpleX Chat) により、合計は 22 になります。セッション間の 1 時間のクロード プロンプト キャッシュ、実際にセッションをライブで転送する /handoff、Telegram と Discord の clarify のネイティブ ボタン UI、Discord チャネル履歴バックフィル、すべての書き込みの LSP セマンティック診断、統合されたプラグイン可能な video_generate、最終的に動作する computer_use cua ドライバー バックエンド非 Anthropic プロバイダー、あらゆる端末での clickable URL、uvx による Zed ACP レジストリの統合、ネイティブ Windows ベータ、9 つの新しいオプション スキル、OpenRouter パレート コード ルーター、trusted のデフォルト タップとしてのハグフェイス/スキル。 12 P0 + 50 P1 クロージャー。

✨ ハイライト

  • SuperGrok OAuth 経由の xAI Grok — そして grok-4.3 は 1M コンテキスト ウィンドウにジャンプします — SuperGrok を支払う場合、xAI アカウントでサインインすることで、Hermes 内で Grok を使用できるようになります — API キーや個別の請求はありません。また、ワイヤスルーにより grok-4.3 が 1M トークン コンテキスト ウィンドウに移動されるため、コードベース全体やリサーチ コーパスを 1 つのプロンプトにドロップできます。資格エラーの適切な処理と、リモート ボックスに SSH 接続して OAuth フローを完了する必要がある場合の SSH からトンネルへのドキュメント ページが含まれています。 (#26534、#26664、#26644、#26592)
  • OAuth プロバイダー用の OpenAI 互換ローカル プロキシ — hermes proxy を実行すると、OpenAI API を話す http://localhost:port エンドポイントが取得されますが、サインインしている OAuth プロバイダー (Claude Pro、ChatGPT Pro、SuperGrok) によってサポートされます。 OpenAI 互換エンドポイント (Codex CLI、Aider、Cline、Continue、カスタム スクリプト) を必要とするツールはすべて、既存のサブスクリプションで動作するため、API キーは必要ありません。 1 つのサブスクリプションですべてのツールを利用可能。 (#25969)
  • x_search — ファーストクラスの X (Twitter) 検索ツール — エージェントは、スキルをインストールしたりカスタム統合を接続したりせずに、X を直接検索できるようになりました。チャットから直接、タイムラインを検索し、スレッドを見つけ、特定の投稿を表示します。 X OAuth ログインまたは API キーのいずれかを使用して認証します。 (#26763)
  • Microsoft Teams — エンドツーエンド – Hermes は、Teams からのメッセージを読んでポストバックできるようになりました。完全な Microsoft Graph スタックが統合されています: auth + client 基盤、Teams イベントを受信する Webhook リスナー、パイプライン プラグイン ランタイム、アウトバウンド配信。ボットを一度接続してから、Teams チャネル、DM、またはグループからエージェントとチャットします。 (#21408 ～ #21411 のサルベージ) (#21922、#21969、#22007、#22024)
  • 衰退の波 — インストールが軽くなり、使用しないものが減ります — クリーンな pip install hermes-agent は、使用したかどうかに関係なく、すべてのメッセージング アダプター SDK、すべてのイメージ生成 SDK、すべての音声/TTS プロバイダーなど、すべてをプルダウンしていました。これらの重いバックエンド (Slack / Matrix / Feishu / DingTalk アダプター、後知恵 client、コーデックス アプリサーバー、Pixverse / Camofox / image-gen SDK、音声/TTS プロバイダー) は、実際に初めて使用するときに自動的にインストールされるようになりました。 [all] エクストラは、lazy-deps でカバーされているものをすべて削除し、ホイールがプラットフォームに適合しない場合、インストーラーは階層を通ってフォールバックし、サプライチェーン アドバイザリー チェッカーが安全でないバージョンがないかすべてのインストールをスキャンします。インストールの高速化、ディスク占有面積の縮小、推移的な脆弱性の減少。 (#24220、#24515、#25014、#25038、#25766、#21818)
  • pip install hermes-agent && hermes — Hermes Agent は実際の PyPI パッケージになりました。リポジトリのクローンを作成したり、シェル インストーラーを実行したりする必要はもうありません。pip コマンドを 1 つ実行するだけで実行できます。ホイールには Ink TUI バンドルとシェル ランチャーが同梱されているため、箱から出してすぐに完全なエクスペリエンスが得られます。 (#26350のサルベージ) (#26593、#26148)
  • セッション間 1 時間のクロード プロンプト キャッシュ — Anthropic、OpenRouter、または Nous Portal を通じてクロードを使用する場合、プロンプト プレフィックス (システム プロンプト、スキル、メモリ) がセッション間で 1 時間キャッシュされるようになりました。 /new セッションを開始すると、キャッシュが最後のセッションからまだ暖かいため、最初の応答がより速く、より安価に返されます。バックグラウンドメモリのレビューもキャッシュにヒットするため、毎ターン全額を支払うわけではありません。 (#23828、#25434、#24778)
  • 180 倍高速な browser_console 評価 — エージェントがブラウザ ツールを使用してページを検査したり、JavaScript を実行したりする場合、それらの呼び出しは、毎回新しい DevTools セッションを起動するのではなく、Chrome への 1 つの永続的な接続を共有するようになりました。違いは非常に大きく、これまでは呼び出しごとに数秒かかっていたものが数ミリ秒で返されます。現実世界のページのインタラクションは瞬時に感じられます。 (#23226)
  • コールド スタート パフォーマンス ウェーブ — hermes の起動から約 19 秒短縮 — hermes を実行すると、プロンプトが表示されるまでインポート オーバーヘッドとネットワーク呼び出しが大量に発生するまで待たなければなりませんでした。現在、起動パスはほとんど延期されています。重いアダプターは使用するときにのみロードされ、モデル カタログは最初にディスク キャッシュから取得され、ドクター チェックは並行して実行され、chat -q はウェルカム バナーを完全にスキップします。 hermes tools All-Platforms 画面だけでも、14 秒から 1.5 秒未満に短縮されました。 (#22138、#22120、#22681、#22790、#22808、#22831、 #22859、#22904、#22766、#25341)
  • 2 つの新しいメッセージング プラットフォーム — LINE + SimpleX Chat — LINE は日本、韓国、台湾で大きな成長を遂げており、Hermes は LINE メッセージング API でネイティブに動作します。 SimpleX Chat は、ユーザー ID を持たないプライバシー重視の分散型メッセンジャーであり、ファーストクラスのプラットフォームとしても機能します。これにより、Hermes には合計 22 のメッセージング プラットフォームが利用できるようになり、あなたとあなたのチームがどこでチャットしても、エージェントがそこにいることができます。 (#23197、#26232)
  • /handoff は実際にセッションをライブ転送します — 会話中にモデルやパーソナリティを切り替えることは、コンテキストを失ったり最初からやり直すことを意味していました。 /handoff は、アクティブなセッション (すべてのメッセージ、すべてのツール呼び出し、すべてのコンテキスト) を、何もドロップすることなく、ターゲットのモデル、ペルソナ、またはプロファイルにライブで移動します。デバッグの途中で、高速モデルから深い推論モデルにハンドオフするか、タスクのさまざまな部分のプロファイル間でセッションを渡します。 (#23395)
  • Telegram と Discord の clarify のネイティブ ボタン UI — エージェントが clarify ツールを使用して多肢選択の質問をする場合、オプション番号を入力し直すように求める代わりに、Telegram と Discord で実際のプラットフォーム ネイティブ ボタンが表示されるようになりました。ボタンをタップすると、エージェントが回答を受け取ります。特にモバイルでは便利です。 (#24199、#25485)
  • Discord チャンネル履歴バックフィル (デフォルト オン) — Hermes が Discord チャンネルまたはスレッドに初めて参加するとき、最近のメッセージ履歴を読み取るようになりました。これにより、応答する前に何が発言されたかを知ることができます。 「何について話しているの？」ということはもうありません。 — エージェントは、他の全員の画面上にすでに表示されているコンテキストを持っています。 (#25984)
  • vision_analyze は視覚対応モデルにピクセルを返します — エージェントに vision_analyze を使用して画像をポイントし、アクティブなモデル (GPT-5、Claude、Gemini、Grok-vision) が実際に見える場合、Hermes は生のピクセルを最初にテキスト記述に変換するのではなく、モデルに直接渡すようになりました。劣化したテキストと要約の往復ではなく、モデルの実際の視覚的な推論が得られます。 (#22955)
  • ターンごとのファイル変更検証フッター — ファイルの書き込みまたは編集を行うターンごとに、エージェントはディスク上の変更内容 (ファイル パス、行数、実際の差分) を正確に要約した短いフッターを取得するようになりました。つまり、ファイルが実際に保存されていないときに自信を持って「関数を追加しました」と伝えるのではなく、書き込みが失敗した場合やサイレントに上書きされた場合にエージェントが自らの間違いを発見することを意味します。 (#24498)
  • 書き込みごとに LSP セマンティック診断 — エージェントが write_file または patch を使用する場合、Hermes は編集されたファイルに対して実際の言語サーバーを実行し、次のターンの前に新しいエラーをエージェントに返します。型エラー、未定義のシンボル、インポートの欠落 - すぐに検出されます。実際のセマンティック分析であるため、v0.13.0 の基本的な Python/JSON/YAML/TOML リンティングをはるかに超えています。 (#24168、#25978)
  • プラグ可能なプロバイダー バックエンドを備えた統合 video_generate — 1 つのツールであらゆるビデオ モデルに対応。 Hermes には明らかなバックエンドがすでに付属していますが、コアには触れずに新しいビデオ プロバイダーをプラグインとして追加できます。したがって、来月新しいビデオ モデルが登場するとき、それはフォークではなく 1 つのファイルのプラグインになる可能性があります。 (#25126)
  • computer_use cua-driver バックエンド — Anthropic 以外のモデルでも動作するようになりました — コンピューター使用 (GUI アプリを駆動するためにマウスとキーボードを制御するエージェント) は、以前は Anthropic の SDK にロックされていました。新しい cua-driver バックエンドは、非 Anthropic プロバイダーでも動作し、適切なフォーカスセーフ操作を備え、hermes update で自身を更新します。ビジョン対応モデルならどれでもデスクトップを駆動できるようになりました。 (#16936の再サルベージ) (#21967、#24063)
  • あらゆる端末で Clickable URL — エージェント出力のリンクは、サポートされている端末でホバーハイライト付きの実際の OSC8 ハイパーリンクになりました。 Click をブラウザで開くと、トランスクリプトから長い URL をコピー＆ペーストしてトリミングする必要がなくなります。 iTerm2、Kitty、Ghostty、最新の Windows Terminal などで動作します (@OutThisLife) (#25071、#24013)
  • Zed ACP レジストリ — uvx を 1 つの click にインストール — Herme は Zed のエージェント Client プロトコル レジストリにリストされるようになったため、Zed ユーザーは 1 つの click でインストールできます。インストール パスは uvx を使用するため、npm への依存関係はありません。 hermes acp --setup-browser は、レジストリ主導のインストール用のブラウザ ツールをブートストラップします。 (#25908のサルベージ) (#26079、#26120、#26234)
  • OpenRouter パレート コード ルーター (min_coding_score ノブ付き) — OpenRouter の「パレート」ルーターは、最低品質基準を満たす最も安価なモデルを自動的に選択します。新しい min_coding_score 構成では、コーディング タスクに特化した基準を設定できます。Hermes は、少なくともその程度のコード能力を備えた最も手頃なモデルを選択します。中級モデルで済むのに、最上位モデルにお金を払うのはやめましょう。 (#22838)
  • 新しいモデル プロバイダーとしての NovitaAI — NovitaAI がプロバイダーのラインナップに加わり、価格設定とレート制限のあるオープンソース モデル ホスティング (Llama、Qwen、DeepSeek など) の別のオプションを提供します。 (サルベージ #7219) (@kshitijk4poor) (#25507)
  • OpenAI/Codex モデル用の Codex アプリサーバー ランタイム — OpenAI または Codex パスを使用している場合に、OpenAI の Codex CLI を内部で駆動するオプションのランタイム。セッションの再利用、ウェッジされたセッションの自動リタイア、および適切な OAuth 更新分類が得られます。これは、長時間にわたるエージェントの実行が失敗しないようにするための仕組みです。 (#24182、#25769)
  • huggingface/skills を trusted デフォルト タップとして使用 —huggingface.co/skills でホストされているコミュニティ スキル インデックスが、デフォルトでスキル ハブに接続されるようになりました。したがって、誰かがそこで便利なスキルを公開すると、追加の設定を行わずに自分の hermes skills ブラウザからそのスキルをインストールできます。 (#2549を閉じる) (#26219)
  • 9 つの新しいオプション スキル — Hyperliquid (SDK および REST API を介した Perp + スポット取引)、Yahoo Finance (ライブ マーケット データ、ファンダメンタルズ、ヒストリカル)、api テスト (REST + GraphQL デバッグ レシピ)、統合 EVM マルチチェーン (1 つのスキルで Ethereum + L2s + Base をカバー)、darwinian-evolver (進化的プロンプト/スキル チューニング)、 osint-investigation (人/ドメイン/組織の OSINT レシピ)、pingy-tunnel (ローカル サービスをパブリック インターネットに公開)、ウォッチャー (変更検出のため cron no_agent モード経由で RSS / HTTP JSON / GitHub をポーリング)、および 2026 年 5 月の開発者プラットフォーム向けの Notion の完全なオーバーホール。 (#23582、#23583、#23590、#25299、#26760、#26729、 #26765、#21881、#26612)

  • プラグインは、ctx.llm を介して任意の LLM 呼び出しを実行でき、tool_override を介して組み込みツールを置き換えることができます — Herme プラグインを作成している場合、アクティブなプロバイダーと資格情報を介して LLM 呼び出しを行うためのファーストクラスのアクセスが得られます。手動での client 配線は必要ありません。新しい tool_override フラグを使用すると、プラグインは組み込みツールを独自の実装ときれいに交換できます。プラグイン作成者は、コア エージェントが使用するのと同じモデル ルーティングと認証プラミングを取得します。 (#11049 を閉じます) (#23194、#26759)
  • Brave Search (無料枠) + Web 検索プロバイダーとしての DuckDuckGo (DDGS) — 2 つの新しい無料 Web 検索バックエンドが Tavily、SearXNG、Exa に加わりました。 Brave Search には寛大な無料枠があります。 DDGS はキーをまったく必要としない DuckDuckGo スクレーパーです。予算とレート制限のニーズに合ったものをお選びください。 (#21337)
  • Sudo ブルート フォース ブロック + 3 つの危険なコマンド バイパスのクローズ + ツール エラーのサニタイズ — 承認ゲートは sudo -S ブルート フォース試行をブロックし、stdin 供給または askpass 除去された sudo 呼び出しを危険として分類するようになりました。危険なコマンド検出の 3 つの既知のバイパスが閉鎖されました (Claude Code のコマンド検出作業からインスピレーションを得た)。また、ツールのエラー文字列はモデル コンテキストに再挿入される前にサニタイズされるため、悪意のあるファイルやリモート サービスがエラー出力を通じてエージェントに指示を渡すことができなくなります。 (#23736、#26829、#26823)
  • **/subgoal — アクティブな /goal に追加されるユーザー追加の基準 ** — /goal を実行している場合 (基準が満たされるまでエージェントが継続する永続的なラルフ ループ目標)、/subgoal <text> を使用して、実行中に追加の成功基準を重ね合わせることができるようになりました。裁判官は、ループを再開することなく、新しい基準を「完了」または「続行」の決定に組み入れます。 (#25449)

Includes proper handling for entitlement errors and an SSH-to-tunnel docs page for when you're SSH'd into a remote box and need to complete the OAuth flow. (#26534, #26664, #26644, #26592)

Now any tool that expects an OpenAI-compatible endpoint (Codex CLI, Aider, Cline, Continue, your custom scripts) just works with your existing subscription, no API key required. One subscription, every tool. (#25969)

  • x_search — first-class X (Twitter) search tool — The agent can now search X directly without installing a skill or wiring up a custom integration. Search the timeline, find threads, surface specific posts — straight from the chat. Auth with either your X OAuth login or an API key, whichever you have. (#26763)

The full Microsoft Graph stack lands together: auth + client foundation, a webhook listener that receives Teams events, a pipeline plugin runtime, and outbound delivery. Faster installs, smaller disk footprint, fewer transitive vulnerabilities. (#24220, #24515, #25014, #25038, #25766, #21818)

Start a /new session and the first response comes back faster and cheaper because the cache is still warm from your last session. Background memory review hits the cache too, so it's not paying full price every turn. (#23828, #25434, #24778)

Now the launch path is mostly deferred: heavy adapters only load when you use them, model catalogs come from disk cache first, doctor checks run in parallel, and chat -q skips the welcome banner entirely.
