hermes-agent v2026.4.30

#エルメスエージェント v0.12.0(v2026.4.30) 発売日: 2026 年 4 月 30 日 v0.11.0 以降: コミット数 1,096 · マージされた PR 550 · 変更されたファイル 1,270 · 挿入数 217,776 · コミュニティ貢献者 213 名 (共著者を含む)

Curator リリース — Hermes Agent が自身をメンテナンスするようになりました。自律的なバックグラウンド キュレーターが、独自のスケジュールでスキル ライブラリを評価、整理、統合します。何を節約するかを検討する自己改善ループが大幅にアップグレードされました。 4 つの新しい推論プロバイダー、18 番目のメッセージング プラットフォーム、19 番目の Teams プラグイン経由、ネイティブ Spotify と Google Meet の統合、ComfyUI と TouchDesigner-MCP がオプションからデフォルトでバンドルされ、表示される TUI コールド スタートが最大 57% 削減されました。

✨ ハイライト

  • 自律キュレーター - hermes curator は、ゲートウェイの cron ティッカーでバックグラウンド エージェントとして実行されます (デフォルトは 7 日サイクル)。スキル ライブラリを評価し、関連するスキルを統合し、無効になったスキルを削除し、実行ごとのレポートを logs/curator/run.json + REPORT.md に書き込みます。アーカイブされたスキルは、モデル + ヒューリスティックによって統合されたスキルとプルーニングされたスキルに分類されます。多層防御ゲートは、バンドル/ハブ スキルを突然変異から保護します。 auxiliary.curator に統合 — hermes model でキュレーターのモデルを選択し、ダッシュボードから管理します。 hermes curator status は、使用法 (最もよく使用される/最も使用されない) に基づいてスキルをランク付けします。 (#17277、#17307、#17941、#17868、#18033)
  • 自己改善ループ - 大幅にアップグレード - バックグラウンド レビュー フォーク (Hermes の自己改善の中核: 各ターン後に保存または更新するメモリ/スキルを決定する) はクラスファースト (自由形式ではなくルーブリックベース)、アクティブ更新バイアス (エージェントがロードしたばかりのスキルを優先) になり、references//templates/ サブファイルを処理し、親のライブ ランタイムを適切に継承します。 (プロバイダー、モデル、資格情報が実際に伝播されます)。メモリ + スキル ツールセットに制限されているため、拡散することはできません。メモリ プロバイダーが正常にシャットダウンされました。前のターンのツールメッセージが概要から除外されるため、フォークはクリーンなコンテキストを認識します。 (#16026、#17213、#16099、#16569、#16204、#15057)
  • スキルの統合 - 大幅な拡張 - 公式 CLI + REST + ハードウェア ゲート ローカル インストールを備えた ComfyUI v5 は、オプションから デフォルトで組み込み (#17610、#17631、#17734) に移行しました。 TouchDesigner-MCP はデフォルトでバンドルされており、GLSL、ポスト FX、オーディオ、ジオメトリ、および 9 つの新しいリファレンス ドキュメント (#16753、#16624、#16768 — @kshitijk4poor + @SHL0MS) で拡張されています。 Humanizer スキルは、AI 主義を取り除くテキスト クリーナーを移植します (#16787)。 claude-design HTML アーティファクト スキル + design-md (Google DESIGN.md 仕様) + airtable サルベージ + external_dirs での skill_manage 編集 + ダイレクト URL スキル インストール + /reload-skills スラッシュ コマンド。 (#16358、#14876、#16291、#17512、#16323、#17744)
  • LM Studio — ファーストクラスのプロバイダー — カスタム エンドポイント エイリアスから本格的なネイティブ プロバイダーにアップグレードされました: 専用認証、hermes doctor チェック、推論トランスポート、ライブ /models リスト。 (@kshitijk4poor の #17061 のサルベージ。) (#17102)
  • さらに 4 つの新しい推論プロバイダー — GMI Cloud (ファーストクラス、#11955 のサルベージ — @isaachuangGMICLOUD)、自動検出機能を備えた Azure AI Foundry、PKCE ブラウザー フローを備えた MiniMax OAuth (サルベージ #15203)、Tencent Tokenhub (#16860 のサルベージ)。 (#16663、#15845、#17524、#16960)
  • プラグイン可能なゲートウェイ プラットフォーム + Microsoft Teams — ゲートウェイはプラグイン ホストになりました。ドロップイン メッセージング アダプターはコアの外部に存在し、Microsoft Teams はプラグインが提供される最初のプラットフォームです。 (#17664 のサルベージ。) (#17751、#17828)
  • Tencent 元宝 (Yuanbao) – 18 番目のメッセージング プラットフォーム – テキスト + メディア配信を備えたネイティブ ゲートウェイ アダプター。 (#16298、#17424)
  • Spotify — ネイティブ ツール + バンドルされたスキル + ウィザード — PKCE OAuth の背後にある 7 つのツール (再生、検索、キュー、プレイリスト、デバイス)、インタラクティブなセットアップ ウィザード、バンドルされたスキル、hermes tools での表示、文書化された cron の使用法。 (#15121、#15130、#15154、#15180)
  • Google Meet プラグイン — 通話に参加し、文字に起こし、話し、フォローアップします。リアルタイム OpenAI トランスポート + ノード ボット サーバー、完全なパイプラインがプラグインとしてバンドルされています。 (#16364)
  • hermes -z ワンショット モード + hermes update --check — 非対話型 hermes -z <prompt> と --model/--provider/HERMES_INFERENCE_MODEL。 hermes update --checkのプリフライト。更新前の HERMES_HOME バックアップをオプトインします。 (#15702、#15704、#15841、#16539、#16566)
  • モデル ダッシュボード タブ + ブラウザ内モデル構成 — モデルごとの豊富な分析、ダッシュボードからメイン + 補助モデルを切り替えます。 (#17745、#17802)
  • リモート モデル カタログ マニフェスト — OpenRouter + Nous Portal モデル カタログはリモート マニフェストから取得されるようになったため、新しいモデルはリリースなしで表示されます。 (#16033)
  • ネイティブ マルチモーダル画像ルーティング — 画像は、プロバイダーのデフォルトではなく、モデルの実際の視覚能力に基づいてルーティングされるようになりました。 (#16506)
  • ゲートウェイ メディア パリティ — Telegram、Discord、Slack、Mattermost、Email、Signal にわたるネイティブ マルチイメージ送信。 FLAC サポート + Telegram ドキュメント フォールバックによる集中オーディオ ルーティング。 (#17909、#17833)
  • **TUI は古典的な CLI に追いつきます (そして過去を) ** — LaTeX レンダリング (@austinpickett)、/reload .env ホットリロード、プラグ可能なビジー インジケーター スタイル (@OutThisLife、#13610)、最後のセッションのオプトイン自動再開、拡張されたライト ターミナル自動検出、/resume ピッカーからのセッション削除d、修正されたマウス ホイール行スクロール、および ConPTY のファントム マウス インジェクション (@kevin-ho) を無効にする /mouse トグル。 (#17175、#17286、#17150、#17130、#17113、#17668、 #17669、#15488)
  • 可観測性 + 実績プラグイン — バンドルされた Langfuse 可観測性プラグイン (サルベージ #16845) + 完全なセッション履歴をスキャンするバンドルされた Hermes-Achievements プラグイン。 (#16917、#17754)
  • TTS プロバイダー レジストリ + Piper ローカル TTS — プラグ可能な tts.providers.<name> レジストリ。 Piper はネイティブのローカル TTS プロバイダーとして出荷されます。 (#8508 を閉じます。) (#17843、#17885)
  • Vercel サンドボックス バックエンド —execute_code/terminal バックエンドとしての Vercel サンドボックス (@kshitijk4poor)。 (#17445)
  • デフォルトで秘密の編集はオフ — デフォルトはオフに切り替わりました。偽のシークレット形状の部分文字列によってツールの出力が破壊される、長年にわたるパッチ破損インシデントを防止します。必要に応じて、redaction.enabled: true 経由でオプトインします。 (#16794)
  • コールド スタート パフォーマンス — 遅延エージェント初期化 (@OutThisLife)、OpenAI / Anthropic / Firecrawl / account_usage の遅延インポート、mtime キャッシュされた load_config()、TTL キャッシュされた check_fn 結果を含むメモ化された get_tool_definitions()、プリコンパイルされた危険なコマンド パターンによる目に見える TUI コールド スタートの削減 ~57%。 (#17190、#17046、#17041、#17098、#17206)

The Curator release — Hermes Agent now maintains itself. An autonomous background Curator grades, prunes, and consolidates your skill library on its own schedule. The self-improvement loop that reviews what to save got a substantial upgrade. Four new inference providers, a 18th messaging platform, a 19th via Teams plugin, native Spotify + Google Meet integrations, ComfyUI and TouchDesigner-MCP moved from optional to bundled-by-default, and a ~57% cut to visible TUI cold start.

Archived skills are classified consolidated-vs-pruned via model + heuristic. Defense-in-depth gates protect bundled/hub skills from mutation. Unified under auxiliary.curator — pick the curator's model in hermes model, manage it from the dashboard. hermes curator status ranks skills by usage (most-used / least-used).
