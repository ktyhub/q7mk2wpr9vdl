#xiaozhi-esp32 v2.2.2

何が変わったのか

  • 功績: @laride による ESP-SensairShuttle を https://github.com/78/xiaozhi-esp32/pull/1620 に追加
  • esp_audio_codec と esp_audio_Effects を使用して、https://github.com/78/xiaozhi-esp32/pull/1632 の @majingjing123 による 78opus を置き換えます
  • 功績: https://github.com/78/xiaozhi-esp32/pull/1629 の @espressif2022 によるエモート表示を更新
  • https://github.com/78/xiaozhi-esp32/pull/1637 の @espressif2022 による IDF v5.4 のビルド エラーを修正
  • https://github.com/78/xiaozhi-esp32/pull/1643 の @dunxuan による ESP-Hi エラーを修正
  • オーディオ サービスの強化: 入力リサンプラーとリセット ロジックのミューテックスを追加 … @78 (https://github.com/78/xiaozhi-esp32/pull/1653)
  • https://github.com/78/xiaozhi-esp32/pull/1648 の @tangjie133 により、Box 上で実行中の DF K10 の異常な画面とカメラの表示を修正
  • https://github.com/78/xiaozhi-esp32/pull/1654 の @YeezB による K10 コンパイル ドキュメント エラーを修正
  • 功績: サードパーティ製ボードの新しいサポート: waveshare ESP32-C6-Touch-AMOLED-1.8 by @Y1hsiaochunnn (https://github.com/78/xiaozhi-esp32/pull/1656)
  • https://github.com/78/xiaozhi-esp32/pull/1639 の @DrayxR3X による waveshare esp32-s3-rlcd-4.2 を追加
  • https://github.com/78/xiaozhi-esp32/pull/1663 の @78 により、bread-compact-nt26 ボードを追加
  • ESP32-S3 に esp32s3_camera を追加し、https://github.com/78/xiaozhi-esp32/pull/1670 の @Kevincoooool によってカメラ選択をリファクタリングします
  • https://github.com/78/xiaozhi-esp32/pull/1671 の @78 による Esp32 カメラ ※オートモード専用の処理を行い、オーディオドライバーのバッファが空になるのを待ってからリッスンモードに切り替えます。 @KingingWang 著、https://github.com/78/xiaozhi-esp32/pull/1675
  • https://github.com/78/xiaozhi-esp32/pull/1677 で @KingingWang によって blufi を有効にした後に発生したコンパイル エラーを修正しました
  • オープンソース サーバー関連のプロジェクトをドキュメントに追加します。 @KingingWang 著、https://github.com/78/xiaozhi-esp32/pull/1688
  • https://github.com/78/xiaozhi-esp32/pull/1694 の @KingingWang によってコードの形式を制御するためにclang-formatを追加しました
  • Zhengchen Technology AI カメラ Wi-Fi ボードと 4G ボードを追加 (26 再送信) by @Taikoto in https://github.com/78/xiaozhi-esp32/pull/1689
  • https://github.com/78/xiaozhi-esp32/pull/1695 の @HonestQiao による esp_video で ov2640 と ov3660 の両方をサポート
  • https://github.com/78/xiaozhi-esp32/pull/1655 の @ZhouKes により USB RNDIS ネットワーク カードのサポートを追加
  • https://github.com/78/xiaozhi-esp32/pull/1701 の @KingingWang で Bluetooth デバイス名を変更します
  • RNDIS ボードのサポートを追加し、https://github.com/78/xiaozhi-esp32/pull/1702 の @78 によるカメラの初期化を強化
  • https://github.com/78/xiaozhi-esp32/pull/1691 の @H-sw123 によって esp32-s3-touch-lcd-4.3c を追加
  • https://github.com/78/xiaozhi-esp32/pull/1708 の @Copilot による SetChatMessage での LVGL オブジェクト削除のクラッシュとスレッド セーフティの問題を修正
  • 修正: https://github.com/78/xiaozhi-esp32/pull/1715 の @78 により esp-box-3 の表示を lvgl にリセット
  • https://github.com/78/xiaozhi-esp32/pull/1704 の @txp666 による Assets システムを使用するために Electron および Otto ボードの絵文字初期化をリファクタリング
  • アセットのダウンロードと OTA プロセスのメモリ管理をリプリケーションによって強化します… by @78 (https://github.com/78/xiaozhi-esp32/pull/1716)
  • プロジェクト バージョンを 2.2.2 に更新し、チャット メッセージの処理を強化します。追加により… by @78 in https://github.com/78/xiaozhi-esp32/pull/1720
  • アプリケーションでのオーディオ チャネル処理とウェイク ワード検出をリファクタリングします… by @78 (https://github.com/78/xiaozhi-esp32/pull/1722)
  • AfeWakeWord を修正: AFE(FEED) のリングバッファが https://github.com/78/xiaozhi-esp32/pull/1723 の @78 までにいっぱいになる
  • https://github.com/78/xiaozhi-esp32/pull/1724 の @78 による ml307 コンポーネントのバージョンの更新
  • 功績: M5Stack Cardputer Adv ボードのサポートを追加 / M5Stack Cardputer Adv 開発ボードのサポートを追加 (https://github.com/78/xiaozhi-esp32/pull/1718 の @tkpdx01 により)
  • https://github.com/78/xiaozhi-esp32/pull/1726 の @txp666 による OV3660 の構成を追加して、Otto Robot カメラのサポートを強化します
  • 修正: https://github.com/78/xiaozhi-esp32/pull/1728 の @78 による uart-uhci コンパイル エラー
