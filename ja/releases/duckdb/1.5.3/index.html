duckdb v1.5.3

パッチ 公開日2026年5月20日 出典duckdb/duckdb English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アヒルデブv1.5.3 これは、v1.5.2 のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。 発表ブログ投稿: https://duckdb.org/2026/05/20/announcing-duckdb-153 も参照してください。

何が変わったのか

  • https://github.com/duckdb/duckdb/pull/22004 の @kryonix による json_serialize_sql の DB シリアル化互換性を使用
  • DuckLake バンプ by @pdet (https://github.com/duckdb/duckdb/pull/22014)
  • 修正: https://github.com/duckdb/duckdb/pull/22020 の @eitsupi による一時テーブルのシャドウイングを回避するために、ADBC インジェストで現在のカタログを解決します。
  • https://github.com/duckdb/duckdb/pull/21992 の @DinosL による json へのコピーの TIMESTAMPTZ 列で TIMESTAMPFORMAT が無視される問題を修正
  • https://github.com/duckdb/duckdb/pull/22029 の @ywelsch による結合フィルター プッシュダウンに対する BWC サポートを提供
  • https://github.com/duckdb/duckdb/pull/22037 に @NiclasHaderer による氷山コピー機能の自動ロードを追加
  • https://github.com/duckdb/duckdb/pull/22019 の @mlafeldt による DISABLE_EXTENSION_LOAD を修正
  • https://github.com/duckdb/duckdb/pull/22049 の @DinosL によって SET リストから競合する列を除外することで、INSERT OR REPLACE BY NAME 回帰を修正しました
  • https://github.com/duckdb/duckdb/pull/22056 の @mlafeldt によって生成された拡張ローダーを Git 無視する
  • https://github.com/duckdb/duckdb/pull/21827 の @AlfieJones によるラテラル テーブルの入出力関数の定数構造体引数を修正
  • シャットダウン中に Ctrl+C を処理しないようにします (状態がすでに終了している可能性があります) by @carlopi (https://github.com/duckdb/duckdb/pull/22059)
  • https://github.com/duckdb/duckdb/pull/22054 に @carlopi による DISABLE_BUILTIN_HTTPLIB オプションを追加
  • https://github.com/duckdb/duckdb/pull/22057 の @yan-alex による ALTER TABLE ... ADD COLUMN ... DEFAULT ... 回避策のステートメントに query フィールドを設定する
  • 共同タスクにより、TaskExecutor::WorkOnTasks でビジー回転が発生する可能性があります (https://github.com/duckdb/duckdb/pull/22092 の @NiclasHaderer による)
  • https://github.com/duckdb/duckdb/pull/22060 の @evertlammerts による行グループの追加
  • https://github.com/duckdb/duckdb/pull/22105 の @dentiny による空の寄木細工の子スキーマを修正

  • https://github.com/duckdb/duckdb/pull/22065 の @Dtenwolde により、C API を使用した VARIANT の読み取りのサポートを追加
  • https://github.com/duckdb/duckdb/pull/22121 の @taniabogatsch により Julia を v1.5.2 にバンプ
  • コミット反復オフセットのバグを修正 + https://github.com/duckdb/duckdb/pull/22094 の @artjomPlaunov による RemoveFromIndexes アサーションを緩和
  • 内部 #8812: https://github.com/duckdb/duckdb/pull/22000 の @hawkfish による TIMESTAMPTZ キャストより
  • https://github.com/duckdb/duckdb/pull/22100 の @rustyconover によってメイン DuckDB ライブラリをビルドするときのみ plan_serializer をビルドします

  • https://github.com/duckdb/duckdb/pull/22141 の @yan-alex による PIVOT MultiStatement の前処理を正しくスキップしました
  • fix(adbc): https://github.com/duckdb/duckdb/pull/22146 で @eitsupi によって追加するときにテーブルが存在しない場合にテーブル名を報告する

  • 修正: @alonfaraj による SQLAlchemy 2.0.45 リフレクションの pg_catalog.pg_collation 互換性ビューを https://github.com/duckdb/duckdb/pull/22160 に追加
  • https://github.com/duckdb/duckdb/pull/22176 の @dentiny による CSV エスケープを修正

duckdb v1.5.3

This is a bugfix release for various issues discovered after we released v1.5.2.

Please also refer to the announcement blog post: https://duckdb.org/2026/05/20/announcing-duckdb-153

What's Changed

  • Use DB serialization compatibility for json_serialize_sql by @kryonix in https://github.com/duckdb/duckdb/pull/22004
  • DuckLake Bump by @pdet in https://github.com/duckdb/duckdb/pull/22014
  • fix: resolve current catalog in ADBC Ingest to avoid temp table shadowing by @eitsupi in https://github.com/duckdb/duckdb/pull/22020
  • Fix TIMESTAMPFORMAT being ignored for TIMESTAMPTZ columns in copy to json by @DinosL in https://github.com/duckdb/duckdb/pull/21992
  • Provide BWC support for join filter pushdowns by @ywelsch in https://github.com/duckdb/duckdb/pull/22029
  • Add iceberg copy function autoload by @NiclasHaderer in https://github.com/duckdb/duckdb/pull/22037
  • Fix DISABLE_EXTENSION_LOAD by @mlafeldt in https://github.com/duckdb/duckdb/pull/22019
  • Fix INSERT OR REPLACE BY NAME regression by excluding conflict columns from SET list by @DinosL in https://github.com/duckdb/duckdb/pull/22049
  • Git-ignore generated extension loader by @mlafeldt in https://github.com/duckdb/duckdb/pull/22056
  • Fix constant struct args in lateral table in-out functions by @AlfieJones in https://github.com/duckdb/duckdb/pull/21827
  • Avoid handling Ctrl+C during shutdown (state might be already gone) by @carlopi in https://github.com/duckdb/duckdb/pull/22059
  • Add DISABLE_BUILTIN_HTTPLIB option by @carlopi in https://github.com/duckdb/duckdb/pull/22054
  • Set query field for statements in ALTER TABLE ... ADD COLUMN ... DEFAULT ... workaround by @yan-alex in https://github.com/duckdb/duckdb/pull/22057
  • Coorporative tasks might lead to busy spinning in TaskExecutor::WorkOnTasks by @NiclasHaderer in https://github.com/duckdb/duckdb/pull/22092
  • Row group append by @evertlammerts in https://github.com/duckdb/duckdb/pull/22060
  • Fix empty parquet child schema by @dentiny in https://github.com/duckdb/duckdb/pull/22105
