duckdb v1.2.1

パッチ 公開日2025年3月5日 出典duckdb/duckdb English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アヒルデブv1.2.1 これは、1.2.0 のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。新しい主要な機能はなく、バグ修正のみです。 v0.9.* までの DuckDB バージョンで作成されたデータベース ファイルは、このバージョンで読み取ることができます。

何が変わったのか

  • [開発] MultiFileReader は、https://github.com/duckdb/duckdb/pull/16114 の @Tishj による CreateFilterMap の InternalError を修正しました
  • [バグ修正] https://github.com/duckdb/duckdb/pull/15903 の @ Vegetable26 による失敗したコミットに対する catch ブロックのスローを回避する
  • 問題 #16098: https://github.com/duckdb/duckdb/pull/16140 の @hawkfish による ValidEnd 並列ベクトル化
  • 拡張オプションを追加しても、設定値が削除されたり、https://github.com/duckdb/duckdb/pull/15919 の @bleskes によって認識されないオプションが昇格されたりすることはありません
  • Parquet ライター: https://github.com/duckdb/duckdb/pull/16178 の @Mytherin による Strings の GetRowSize を再実装
  • 修正 #16157: https://github.com/duckdb/duckdb/pull/16180 の @Mytherin によって辞書ベクトルからハイブ パーティションを読み取るときに最初の行を正しく取得する
  • 修正 #16122: https://github.com/duckdb/duckdb/pull/16181 の @Mytherin による現在のバインダーのカタログ検索パスの変更を避けるために、サブバインダーにデフォルト値をバインドします。
  • 修正 #16134: カタログ/スキーマ/テーブルが同じ名前を持つ場合、https://github.com/duckdb/duckdb/pull/16189 で @Mytherin によってテーブル名を提案することを優先します。

duckdb v1.2.1

This is a bug fix release for various issues discovered after we released 1.2.0. There are no new major features, just bug fixes. Database files created by DuckDB versions all the way back to v0.9.* can be read by this version.

  • Fix #16134: when a catalog/schema/table has the same name, we prefer to suggest the table name by @Mytherin in https://github.com/duckdb/duckdb/pull/16189
