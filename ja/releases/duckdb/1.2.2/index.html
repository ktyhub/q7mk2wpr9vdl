duckdb v1.2.2

パッチ 公開日2025年4月8日 出典duckdb/duckdb English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アヒルデブv1.2.2 これは、1.2.1 のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。新しい主要な機能はなく、バグ修正のみです。 v0.9.* までの DuckDB バージョンで作成されたデータベース ファイルは、このバージョンで読み取ることができます。

何が変わったのか

  • [Python] https://github.com/duckdb/duckdb/pull/16522 で @Tishj が GIL を解放しないことが原因で発生する from_parquet と file_globs のデッドロックを修正
  • [Python] https://github.com/duckdb/duckdb/pull/16523 の @Tishj によるいくつかのスタブの問題を修正
  • [開発] https://github.com/duckdb/duckdb/pull/16533 の @Tishj によるシリアル化された storage_version に関連するベンチマーク ランナーの問題を修正
  • https://github.com/duckdb/duckdb/pull/16528 の @jeewonhh によって新しく作成された論理演算子に推定カーディナリティを設定します
  • https://github.com/duckdb/duckdb/pull/16459 の @carlopi により、custom_extension_repository がデフォルトの autoinstall_extension_repository にもなります
  • [Python 開発] https://github.com/duckdb/duckdb/pull/16433 で @Tishj による UDF を使用するときに DeprecationWarning がトリガーされなくなりました
  • https://github.com/duckdb/duckdb/pull/16578 の @carlopi による 1.2.1 への準備に関連する問題を修正
  • https://github.com/duckdb/duckdb/pull/16584 の @pdet で改善できない場合は、quote=escape を優先します。
  • ART キーの最大長 (https://github.com/duckdb/duckdb/pull/16588 の @taniabogatsch による)
  • 問題 #16617: https://github.com/duckdb/duckdb/pull/16628 の @hawkfish によるウィンドウ定数のファイナライズ
  • [修正] インデックス スキャン - https://github.com/duckdb/duckdb/pull/16650 の @taniabogatsch により、テーブル スキャン状態をローカル状態に移動します。
  • [修正] https://github.com/duckdb/duckdb/pull/16651 で @taniabogatsch による物理バッチ挿入中に積極的な制約チェックを実行する
  • [Python] 矢印スキャンのために OPTIONAL_FILTER を pyarrow に押し込まないでください。 @Tishj 著、https://github.com/duckdb/duckdb/pull/16657
  • https://github.com/duckdb/duckdb/pull/16656 の @jeewonhh により OrderPreservationRecursive を Physical_plan_generator.hpp に移動します
  • https://github.com/duckdb/duckdb/pull/16655 の @taniabogatsch によってバンドルされた静的ライブラリに libs フォルダーを追加
  • https://github.com/duckdb/duckdb/pull/16641 の @krlmlr による UMA の回避
  • https://github.com/duckdb/duckdb/pull/16643 の @krlmlr による UMA の回避
  • https://github.com/duckdb/duckdb/pull/16642 の @krlmlr による UMA の回避
  • https://github.com/duckdb/duckdb/pull/16636 の @pdet による CSV ファザー テストのいくつかの修正
  • FSST 修正: https://github.com/duckdb/duckdb/pull/16688 の @Mytherin によって残り 3 バイトがある状況を正しく検出します。
  • 修正 #16627: https://github.com/duckdb/duckdb/pull/16691 の @Mytherin によるゾーンマップ プッシュダウンで DISTINCT FROM および NOT DISTINCT FROM を処理する
  • 修正 #16554: https://github.com/duckdb/duckdb/pull/16693 の @Mytherin による .dump の一部として BLOB を出力する
  • https://github.com/duckdb/duckdb/pull/16708 に @samansmink による avro を追加
  • 問題 #16652: https://github.com/duckdb/duckdb/pull/16718 の @hawkfish による暗黙的な順序付けされた集計
  • 問題 #16649: @hawkfish による SelectNth 残り (https://github.com/duckdb/duckdb/pull/16705)
  • [開発] https://github.com/duckdb/duckdb/pull/16723 の @Tishj によって生成された schema.sql でセミコロンが欠落していた EXPORT DATABASE を修正
  • https://github.com/duckdb/duckdb/pull/16728 の @pdet により、CSV リーダーで最も早く発生したエラーを常にスローします
  • https://github.com/duckdb/duckdb/pull/16732 の @lnkuiper による #16662 を修正
  • [テスト] https://github.com/duckdb/duckdb/pull/16745 の @taniabogatsch による積極的制約チェック修正のための欠落していたテストを追加
  • クランプは、https://github.com/duckdb/duckdb/pull/16753 の @Mytherin によって、duckdb_memory 内のメモリを報告しました
  • CLI -help: https://github.com/duckdb/duckdb/pull/16755 の @carlopi による -nullvalue のデフォルト値を修正

  • [矢印] マップのキーのスキーマを null 以外に設定し、https://github.com/duckdb/duckdb/pull/16711 の @pdet によって矢印に Null 列を適切に書き込みます
  • https://github.com/duckdb/duckdb/pull/16777 の @abramk による数値キャスト例外メッセージの最小値/最大値を修正
  • [ADBC] 新しい接続にラッパーを追加し、接続の開始時にオプションを設定します (存在する場合)。 @pdet 著、https://github.com/duckdb/duckdb/pull/16748
  • https://github.com/duckdb/duckdb/pull/16794 の @carlopi によって夜間ベースで構築された拡張機能からデルタを削除 (1.2-histrionicus に対して)
  • PhysicalTopN: https://github.com/duckdb/duckdb/pull/16770 の @lnkuiper によってバッファーに割り当てられた StringHeap
  • [雑務] v1.2.2 をストレージ バージョンに追加し、https://github.com/duckdb/duckdb/pull/16799 の @carlopi による今後のパッチ リリースの準備
  • https://github.com/duckdb/duckdb/pull/16823 で @pdet によって行が空の場合の問題を修正

duckdb v1.2.2

This is a bug fix release for various issues discovered after we released 1.2.1. There are no new major features, just bug fixes. Database files created by DuckDB versions all the way back to v0.9.* can be read by this version.

What's Changed

  • [Python] Fix deadlock in from_parquet with file_globs caused by not releasing the GIL by @Tishj in https://github.com/duckdb/duckdb/pull/16522
  • [Python] Fix some stubs issues by @Tishj in https://github.com/duckdb/duckdb/pull/16523
  • [Dev] Fix issues in the benchmark runner related to the serialized storage_version by @Tishj in https://github.com/duckdb/duckdb/pull/16533
  • Set estimated cardinality to newly created logical operators by @jeewonhh in https://github.com/duckdb/duckdb/pull/16528
  • custom_extension_repository to also be the default autoinstall_extension_repository by @carlopi in https://github.com/duckdb/duckdb/pull/16459
  • [Python Dev] No longer trigger a DeprecationWarning when using a UDF by @Tishj in https://github.com/duckdb/duckdb/pull/16433
  • Fixup problems connected to prep to 1.2.1 by @carlopi in https://github.com/duckdb/duckdb/pull/16578
  • Give preference to quote=escape if we can't do better by @pdet in https://github.com/duckdb/duckdb/pull/16584
  • Max ART key length by @taniabogatsch in https://github.com/duckdb/duckdb/pull/16588
  • Issue #16617: Window Constant Finalize by @hawkfish in https://github.com/duckdb/duckdb/pull/16628
  • [Fix] Index scan - Move the table scan state into the local state by @taniabogatsch in https://github.com/duckdb/duckdb/pull/16650
  • [Fix] Perform eager constraint checking during physical batch insert by @taniabogatsch in https://github.com/duckdb/duckdb/pull/16651
  • [Python] Don't push down OPTIONAL_FILTER into pyarrow for the arrow scan. by @Tishj in https://github.com/duckdb/duckdb/pull/16657
