duckdb v1.5.6

#アヒルデブv1.5.6 これは、v1.5.5 のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。

何が変わったのか

  • https://github.com/duckdb/duckdb/pull/23972 の @NiclasHaderer によるキャッシュの再利用のために Unity ビルド ソースで相対インクルードを使用する
  • バンプボルテックス by @samansmink (https://github.com/duckdb/duckdb/pull/24089)
  • [variegata] https://github.com/duckdb/duckdb/pull/24127 の @evertlammerts による duckdb/DuckDB.jl を優先して Julia client を削除
  • [variegata] https://github.com/duckdb/duckdb/pull/24131 の @evertlammerts による C API の仕様とコード生成を置き換えます。
  • TopNWindowElimination 修正 (https://github.com/duckdb/duckdb/pull/24080 の @d-justen による)
  • https://github.com/duckdb/duckdb/pull/24123 で @NiclasHaderer によるアクティブなクエリ競合を修正
  • https://github.com/duckdb/duckdb/pull/24119 の @d-justen による UNNEST プッシュダウンを修正
  • [Parquet][Variant] https://github.com/duckdb/duckdb/pull/23591 で @Tishj によって設定された sorted_strings を使用して VARIANT メタデータを生成しないでください
  • https://github.com/duckdb/duckdb/pull/24240 の @DinosL による OFFSET を使用した揮発性プロジェクションによる LIMIT プッシュダウンを修正
  • https://github.com/duckdb/duckdb/pull/24239 の @DinosL による集計を介して揮発性グループにフィルターをプッシュしないでください
  • fix(adbc): https://github.com/duckdb/duckdb/pull/24196 の @eitsupi による ConnectionGetInfo から密結合を返します
  • バックポート 24038、@artjomPlaunov 著 (https://github.com/duckdb/duckdb/pull/24326)
  • clients/拡張機能の C-API シンボルのバージョン管理を統合し、https://github.com/duckdb/duckdb/pull/24362 の @Maxxen によってすべての v1 API を安定化
  • バックポート 24332 (https://github.com/duckdb/duckdb/pull/24427 の @DinosL による)
  • 修正 #24363: ORDER BY 式に https://github.com/duckdb/duckdb/pull/24399 の @sdk011 による列参照がない場合、トップ N ウィンドウの除外で NULL を保持する
  • バックポート 24260、@artjomPlaunov 著 (https://github.com/duckdb/duckdb/pull/24447)
  • https://github.com/duckdb/duckdb/pull/24438 の @NiclasHaderer による、行間のタイム ゾーン状態がリークする ICU strptime を修正
  • https://github.com/duckdb/duckdb/pull/24516 の @sebastiaan-dev により、スレッドローカル作業を PhysicalInsert::Combine のグローバル ロックの外に移動しました
  • https://github.com/duckdb/duckdb/pull/24580 の @mlafeldt による httpfs のバンプ
  • バンプボルテックス by @samansmink (https://github.com/duckdb/duckdb/pull/24650)
  • https://github.com/duckdb/duckdb/pull/24687 内の @smvv による 1.5 リリースを修正
  • ReplayRowGroupData のインデックスの重複を許可 (https://github.com/duckdb/duckdb/pull/24744 の @artjomPlaunov による)
  • https://github.com/duckdb/duckdb/pull/24720 の @mlafeldt による夜間ビルドのディスパッチ
  • https://github.com/duckdb/duckdb/pull/24592 の @d-justen による TopNWindowElimination の結合投影マップのバグを修正
  • https://github.com/duckdb/duckdb/pull/24802 の @mlafeldt による Go 夜間ワークフロー ディスパッチを修正
  • https://github.com/duckdb/duckdb/pull/24551 の @matthiasgoergens による null 許容順序付け式のトップ N ウィンドウの削除を修正
  • バックポート 23964 & 24336 by @DinosL (https://github.com/duckdb/duckdb/pull/24791)

  • https://github.com/duckdb/duckdb/pull/24586 の @d-justen による TopNWindowElimination の内部結合重複排除を修正
  • https://github.com/duckdb/duckdb/pull/24845 の @Maxxen による null/空 (v1.5 上) によるジオメトリ行グループのプルーニングを修正
  • https://github.com/duckdb/duckdb/pull/24852 の @JelteF により、DuckDB 2.0 API のスペルを 1.5 にバックポートします
  • https://github.com/duckdb/duckdb/pull/24888 の @jeewonhh による CollectionScanState::Initialize での column_ids.size() の予約
  • https://github.com/duckdb/duckdb/pull/24918 の @mdlavin によるオーバーフロー文字列の末尾にある NULL の病理学的スキャン メモリを修正 (#24897)
  • https://github.com/duckdb/duckdb/pull/24978 の @NiclasHaderer による MSVC MAX_PATH エラーを回避するには、Windows で絶対的な Unity ビルド インクルードを使用します。
  • https://github.com/duckdb/duckdb/pull/25026 の @mlafeldt による融合 (v1.5 バックポート) の拡張機能/ローダーの混合パス区切り文字を修正
  • バックポート #25101: LIMIT 0 によるトップ N でのクラッシュを修正 (#24794) (@RagamuffinCat による https://github.com/duckdb/duckdb/pull/25103)
  • Pipeline の MetaPipeline 内依存関係を追跡して公開 (https://github.com/duckdb/duckdb/pull/24494 の @jeewonhh による)

  • @carlopi による v1.5.6 ストレージを https://github.com/duckdb/duckdb/pull/25208 に追加
  • TryScanIndex は https://github.com/duckdb/duckdb/pull/25209 の @artjomPlaunov によって修正されました
  • バックポート #22678: https://github.com/duckdb/duckdb/pull/25139 の @peterboncz による比較で行ごとの DATE->TIMESTAMP キャストを回避する

  • https://github.com/duckdb/duckdb/pull/25331 の @carlopi による二重放出チャンクを避けるために TryFlushCachingOperators を修正
  • https://github.com/duckdb/duckdb/pull/25490 の @carlopi による WAL リカバリ中に名前を変更する前に、メイン WAL ハンドルを閉じてください。

  • https://github.com/duckdb/duckdb/pull/25668 の @bleskes による、コミットされた行グループのない行グループ コレクションのスキャンではアサートしないでください。

duckdb v1.5.6

This is a bug fix release for various issues discovered after we released v1.5.5

What's Changed

  • Use relative includes in unity build sources for cache reuse by @NiclasHaderer in https://github.com/duckdb/duckdb/pull/23972
