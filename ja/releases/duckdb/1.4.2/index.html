duckdb v1.4.2

パッチ 公開日2025年11月12日 出典duckdb/duckdb English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アヒルデブv1.4.2 これは、1.4.1 のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。 PR #19716 は、CVE-2025-64429 で提起された問題に対処しています。 DuckDB 暗号化機能のユーザーは更新することをお勧めします。

何が変わったのか

  • https://github.com/duckdb/duckdb/pull/19275 の @benfleis による 1.4.1 の dump duckdb-azure ref
  • https://github.com/duckdb/duckdb/pull/19290 の @mlafeldt によって contains に変換するときにフラグを削除するように正規表現の最適化を修正しました。
  • 功績: https://github.com/duckdb/duckdb/pull/19260 の @krlmlr によるソートキーの長さの修正
  • https://github.com/duckdb/duckdb/pull/19144 の @Dtenwolde によってラムダ バインディングを次のバインダーに渡します
  • https://github.com/duckdb/duckdb/pull/19306 の @c-herrewijn により Julia を v1.4.1 にバンプします
  • https://github.com/duckdb/duckdb/pull/19304 の @hannes による OSX 上の静的ライブラリのクロスコンパイルの使用
  • https://github.com/duckdb/duckdb/pull/19319 の @Mytherin により、データベース インスタンス間で同じデータベースへの複数の読み取り専用アタッチを許可します
  • https://github.com/duckdb/duckdb/pull/19318 の @carlopi による hugeint_t の修正

  • カルマン フィルターを修正: https://github.com/duckdb/duckdb/pull/19395 の @carlopi により、(0, 1) ではなく (0,scale_factor) に制限されました。

duckdb v1.4.2

This is a bug fix release for various issues discovered after we released 1.4.1. PR #19716 addresses the issues raised in CVE-2025-64429. Users of the DuckDB encryption feature are encouraged to update.

  • bump duckdb-azure ref for 1.4.1 by @benfleis in https://github.com/duckdb/duckdb/pull/19275
