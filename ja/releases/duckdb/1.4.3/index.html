duckdb v1.4.3

パッチ 公開日2025年12月9日 出典duckdb/duckdb English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アヒルデブv1.4.3 これは、1.4.2 のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。

何が変わったのか

  • https://github.com/duckdb/duckdb/pull/19722 の @Maxxen によるテーブル関数の適切な等価性を実装
  • https://github.com/duckdb/duckdb/pull/19739 の @Tishj による GROUP BY のない HAVING 句の動作を修正
  • httpfs パッチを削除し、https://github.com/duckdb/duckdb/pull/19763 で @carlopi によってバンプします
  • https://github.com/duckdb/duckdb/pull/19772 の @Mytherin によって EncryptionKeyManager にアクセスするときにロックを正しく使用する
  • https://github.com/duckdb/duckdb/pull/19764 の @carlopi による氷山をデフォルトの利用可能な拡張機能にバンプ
  • https://github.com/duckdb/duckdb/pull/19766の@Tmonsterでjsonの各関数のカラムバインディングを全て抽出
  • https://github.com/duckdb/duckdb/pull/19776 の @artjomPlaunov による制約違反のバグ修正
  • https://github.com/duckdb/duckdb/pull/19779 の @lnkuiper による型なしマクロのマクロ引数のバインドを回避する
  • https://github.com/duckdb/duckdb/pull/19694 の @hannes による EXTENSION_CONFIG_BUILD ではなく、おそらく ${EXTENSION_CONFIG_BUILD} であるはずです。
  • 修正 #19575: https://github.com/duckdb/duckdb/pull/19699 の @flashmouse による不正な utf8 文字を修正
  • 雑務: https://github.com/duckdb/duckdb/pull/19815 の @0ax1 によって 0.56.0 にボルテックスをバンプする
  • PositionalScan: https://github.com/duckdb/duckdb/pull/19824 の @carlopi による反復により HAVE_MORE_OUTPUT + 空のチャンクも処理します
  • AttachDatabase: 最初にファイルがリモートかどうかを設定し、その後、https://github.com/duckdb/duckdb/pull/19826 の @carlopi によって残りの処理を行います。
  • 正しいことを自動的に実行する CacheBehavior::AUTOMATIC を DBInstanceCache に追加 (https://github.com/duckdb/duckdb/pull/19841 の @Mytherin)
  • https://github.com/duckdb/duckdb/pull/19823 で @ywelsch による削除が存在する場合でもメタデータを再利用します
  • DuckIndexScanState::TableScanFunc、https://github.com/duckdb/duckdb/pull/19838 の @carlopi によって 2 つの明示的なフェーズに分割
  • httpfs と氷山を攻撃する (https://github.com/duckdb/duckdb/pull/19859 の @carlopi による)
  • https://github.com/duckdb/duckdb/pull/19863 の @Mytherin による MERGE INTO 子で実体化された CTE をバインドしている間、cte_root を存続させます。
  • CI クリーンアップ (#19840) by @yan-alex (https://github.com/duckdb/duckdb/pull/19857)
  • 修正 #19517: https://github.com/duckdb/duckdb/pull/19887 の @henry8128 によるテーブル修飾されたスター LIKE 式のリレーション名を保持
  • 単体テストの概要をレポートする際のアンダーフロー/「inf」ループを回避します (バックポート…by @benfleis in https://github.com/duckdb/duckdb/pull/19900)
  • https://github.com/duckdb/duckdb/pull/19891 での @Damon07 による APPROX_QUANTILE TIME の誤った処理を修正
  • https://github.com/duckdb/duckdb/pull/19907 の @maiadegraaf によりストレージ バージョンに v1.4.3 を追加
  • 拡張機能の構築中に tmp ファイルをクリーンアップ (https://github.com/duckdb/duckdb/pull/19908 の @c-herrewijn による)
  • バンプ: ダックレイク、mysql_scanner by @maiadegraaf (https://github.com/duckdb/duckdb/pull/19910)
  • https://github.com/duckdb/duckdb/pull/19911 に @guillesd によるフィルターがある場合は常に、大きな制限の最適化を削除します
  • https://github.com/duckdb/duckdb/pull/19912 の @c-herrewijn による拡張機能のアップロード ジョブの空きディスク容量
  • [圧縮] https://github.com/duckdb/duckdb/pull/19913 の @Tishj による COMPRESSION_EMPTY を COMPRESSION_CONSTANT でオーバーライドしないようにします
  • https://github.com/duckdb/duckdb/pull/19917 の @Mytherin によって常に origin/main と比較するのではなく、make tidy-check-diff をベース ブランチと比較するようにします
  • https://github.com/duckdb/duckdb/pull/19708 の @taniabogatsch によるアペンダーとアタッチ/デタッチのさらなるテスト
  • https://github.com/duckdb/duckdb/pull/19881 の @samansmink による拡張機能を手動でリリースするスクリプト
  • https://github.com/duckdb/duckdb/pull/19750 で @pdet によってデータをフェッチするときに、結果の型が列データのコレクションと一致することをアサートします。
  • https://github.com/duckdb/duckdb/pull/19931 の @maiadegraaf による DEBUG モードでのプロファイリングが自動有効にならなくなりました
  • オプティマイザが https://github.com/duckdb/duckdb/pull/19925 の @tianjq16 によって集計から ORDER BY 句を誤って削除する問題を修正
  • https://github.com/duckdb/duckdb/pull/19941 の @Mytherin によるバックポート復帰追加修正
  • バンプ: https://github.com/duckdb/duckdb/pull/19943 の @Maxxen による空間
  • 問題 #19916: WASM タイム ゾーン (@hawkfish 著、https://github.com/duckdb/duckdb/pull/19918)
  • https://github.com/duckdb/duckdb/pull/19945 の @d-justen による ConstantBinder の相関列バインディングを修正
  • [雑務] https://github.com/duckdb/duckdb/pull/19965 の @taniabogatsch による低速しきい値を増やす
  • [Parquet] https://github.com/duckdb/duckdb/pull/19966 で @Tishj によって準備されたコピー オプション パラメーターを修正
  • [TestConfig] verify_fetch_row 構成を修正し、https://github.com/duckdb/duckdb/pull/19967 の @Tishj による skip_tests の重複を削減
  • https://github.com/duckdb/duckdb/pull/19957 の @c-herrewijn によりアーティファクトから sha を削除
  • https://github.com/duckdb/duckdb/pull/19953 の @artjomPlaunov によるコンテキストを使用したアンバウンド インデックス バインディング
  • [修正] https://github.com/duckdb/duckdb/pull/19970 の @taniabogatsch による dict_fsst 圧縮によるインデックス付きテーブルの更新後の FetchRow のバグ
  • https://github.com/duckdb/duckdb/pull/19947 の @Dtenwolde による denormalized_table 引数に対する null アサーション
  • [Art][Wal]アンバウンド インデックス割り当て (@artjomPlaunov 著、https://github.com/duckdb/duckdb/pull/19901)
  • https://github.com/duckdb/duckdb/pull/19978 の @Tmonster による 281TB を超えるサンプリングはありません
  • https://github.com/duckdb/duckdb/pull/20005 で @pdet によって候補を選択する際にスニファーが非厳密性を使用したかどうかを考慮する
  • [CSV] https://github.com/duckdb/duckdb/pull/20007 の @pdet による厳密モードでの不要なエラーのスローを回避する
  • [圧縮] https://github.com/duckdb/duckdb/pull/20009 の @Tishj によって DICT_FSST で圧縮された列への NULL 更新の問題を修正
  • バンプ: デルタ、ダックレイク、氷山、@maiadegraaf 著 (https://github.com/duckdb/duckdb/pull/20012)
  • Unity_catalog を追加し、https://github.com/duckdb/duckdb/pull/20019 の @samansmink によるデルタを更新
  • https://github.com/duckdb/duckdb/pull/20020 の @staticlibs による空間バンプ
  • #19821 を v1.4 に再タグ付け - https://github.com/duckdb/duckdb/pull/20024 の @pdet による Parquet バージョン 1 に PLAIN_DICTIONARY を使用
  • https://github.com/duckdb/duckdb/pull/19989 の @henry8128 による部分的な列 (#19845) での INSERT OR REPLACE BY NAME を修正
  • https://github.com/duckdb/duckdb/pull/20025 の @staticlibs による MySQL スキャナーのバンプ
  • Windows は https://github.com/duckdb/duckdb/pull/20018 の @Tmonster によってサンプリングを少なくする必要があります
  • 問題 #20015: https://github.com/duckdb/duckdb/pull/20027 の @hawkfish によるストリーミング ウィンドウ シーケンス
  • 氷山を衝突させる by @Tmonster (https://github.com/duckdb/duckdb/pull/20032)
  • 修正 #20014: https://github.com/duckdb/duckdb/pull/20039 の @Mytherin によって統計が浮動小数点の -infinity に初期化されるように、NumericLimits::Min に numeric_limits<T>::min を正しく使用します。
  • https://github.com/duckdb/duckdb/pull/20004 の @staticlibs により、メイン拡張機能の windows_arm64 アーチを有効にします
  • https://github.com/duckdb/duckdb/pull/20033 の @kryonix によるマーク結合の非相関を修正
  • https://github.com/duckdb/duckdb/pull/20044 の @artjomPlaunov による Node4::DeleteChild のゲート ステータスの伝播
  • バンプ: httpfs by @samansmink (https://github.com/duckdb/duckdb/pull/20036)
  • https://github.com/duckdb/duckdb/pull/20054 の @pdet によるバンプダックレイク
  • https://github.com/duckdb/duckdb/pull/20057 の @benfleis により、Azure を v1.4.3 にバンプします
  • https://github.com/duckdb/duckdb/pull/20055 の @samansmink によるバンプ拡張機能

duckdb v1.4.3

This is a bug fix release for various issues discovered after we released 1.4.2.

What's Changed

  • implement proper equals for table functions by @Maxxen in https://github.com/duckdb/duckdb/pull/19722
  • Fix behavior for HAVING clause without a GROUP BY by @Tishj in https://github.com/duckdb/duckdb/pull/19739
  • Remove httpfs patches and bump by @carlopi in https://github.com/duckdb/duckdb/pull/19763
  • Correctly use a lock when accessing the EncryptionKeyManager by @Mytherin in https://github.com/duckdb/duckdb/pull/19772
  • Bump iceberg to now default available extension by @carlopi in https://github.com/duckdb/duckdb/pull/19764
  • Extract all column bindings of json each function by @Tmonster in https://github.com/duckdb/duckdb/pull/19766
  • constraint violation bug fix by @artjomPlaunov in https://github.com/duckdb/duckdb/pull/19776
  • Avoid binding macro arguments for untyped macros by @lnkuiper in https://github.com/duckdb/duckdb/pull/19779
  • It should probably be ${EXTENSION_CONFIG_BUILD} instead of EXTENSION_CONFIG_BUILD by @hannes in https://github.com/duckdb/duckdb/pull/19694
  • Fix #19575: Fix illegal utf8 character by @flashmouse in https://github.com/duckdb/duckdb/pull/19699
  • chore: bump vortex to 0.56.0 by @0ax1 in https://github.com/duckdb/duckdb/pull/19815
  • PositionalScan: handle also HAVE_MORE_OUTPUT + empty chunk via iteration by @carlopi in https://github.com/duckdb/duckdb/pull/19824
  • AttachDatabase: first set whether file is remote, then do the rest by @carlopi in https://github.com/duckdb/duckdb/pull/19826
  • Add CacheBehavior::AUTOMATIC to DBInstanceCache that automatically does the right thing™ by @Mytherin in https://github.com/duckdb/duckdb/pull/19841
  • Reuse metadata even in the presence of deletes by @ywelsch in https://github.com/duckdb/duckdb/pull/19823
  • DuckIndexScanState::TableScanFunc, split into 2 explicit phases by @carlopi in https://github.com/duckdb/duckdb/pull/19838
  • Bump httpfs and iceberg by @carlopi in https://github.com/duckdb/duckdb/pull/19859
  • Keep cte_root alive while binding materialized CTEs in MERGE INTO children by @Mytherin in https://github.com/duckdb/duckdb/pull/19863
  • CI Cleanup (#19840) by @yan-alex in https://github.com/duckdb/duckdb/pull/19857
  • Fix #19517: preserve relation name for table-qualified star LIKE expression by @henry8128 in https://github.com/duckdb/duckdb/pull/19887
  • avoid underflow/"inf" loop while reporting unittest summary (backport… by @benfleis in https://github.com/duckdb/duckdb/pull/19900
  • Fixes incorrect handing of APPROX_QUANTILE TIME by @Damon07 in https://github.com/duckdb/duckdb/pull/19891
  • Add v1.4.3 to Storage Version by @maiadegraaf in https://github.com/duckdb/duckdb/pull/19907
  • clean up tmp files while building extensions by @c-herrewijn in https://github.com/duckdb/duckdb/pull/19908
  • Bump: ducklake, mysql_scanner by @maiadegraaf in https://github.com/duckdb/duckdb/pull/19910
  • remove large limit optimization whenever there is a filter by @guillesd in https://github.com/duckdb/duckdb/pull/19911
  • free disk space in Upload Extensions job by @c-herrewijn in https://github.com/duckdb/duckdb/pull/19912
  • [Compression] Prevent overriding COMPRESSION_EMPTY with COMPRESSION_CONSTANT by @Tishj in https://github.com/duckdb/duckdb/pull/19913
  • Make make tidy-check-diff compare against base branch, instead of always comparing against origin/main by @Mytherin in https://github.com/duckdb/duckdb/pull/19917
  • More testing for appender and attach-detach by @taniabogatsch in https://github.com/duckdb/duckdb/pull/19708
  • Script to release a extension manually by @samansmink in https://github.com/duckdb/duckdb/pull/19881
  • Assert that result types match with column data collection when fetching data by @pdet in https://github.com/duckdb/duckdb/pull/19750
  • No longer auto-enable profiling on DEBUG mode by @maiadegraaf in https://github.com/duckdb/duckdb/pull/19931
  • Fix optimizer incorrectly remove ORDER BY clause from aggregates by @tianjq16 in https://github.com/duckdb/duckdb/pull/19925
  • Backport revert append fixes by @Mytherin in https://github.com/duckdb/duckdb/pull/19941
  • Bump: spatial by @Maxxen in https://github.com/duckdb/duckdb/pull/19943
  • Issue #19916: WASM Time Zones by @hawkfish in https://github.com/duckdb/duckdb/pull/19918
  • Fix correlated column binding in ConstantBinder by @d-justen in https://github.com/duckdb/duckdb/pull/19945
  • [chore] Increase slow threshold by @taniabogatsch in https://github.com/duckdb/duckdb/pull/19965
  • [Parquet] Fix prepared copy option parameter by @Tishj in https://github.com/duckdb/duckdb/pull/19966
  • [TestConfig] Fix verify_fetch_row config, reduce duplication in skip_tests by @Tishj in https://github.com/duckdb/duckdb/pull/19967
  • remove sha from artifacts by @c-herrewijn in https://github.com/duckdb/duckdb/pull/19957
  • Unbound index binding with context by @artjomPlaunov in https://github.com/duckdb/duckdb/pull/19953

  • No sampling over 281TB by @Tmonster in https://github.com/duckdb/duckdb/pull/19978
  • Take in consideration if the sniffer used unstrictness while selecting candidates by @pdet in https://github.com/duckdb/duckdb/pull/20005
  • [CSV] Avoid throwing unnecessary errors on strict mode by @pdet in https://github.com/duckdb/duckdb/pull/20007
  • [Compression] Fix an issue with NULL updates to a column compressed with DICT_FSST by @Tishj in https://github.com/duckdb/duckdb/pull/20009
