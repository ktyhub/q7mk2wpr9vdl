duckdb v2.0.1

パッチ 公開日2026年11月20日 出典duckdb/duckdb English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アヒルデブv2.0.1 これは、v2.0.0 のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。 発表ブログ投稿: https://duckdb.org/2026/11/20/announcing-duckdb-201.html も参照してください。

何が変わったのか

  • https://github.com/duckdb/duckdb/pull/27600 の @smvv によって Rust 拡張 CI グループをマージします
  • https://github.com/duckdb/duckdb/pull/27604 の @h4nsmuller によって、プロファイラーの末尾の空白行をレンダラーの印刷シンク経由で印刷します。
  • https://github.com/duckdb/duckdb/pull/27610 の @lnkuiper による StagedUpload.yml を修正
  • https://github.com/duckdb/duckdb/pull/27612 の @lnkuiper による StagedUpload.yml を修正
  • https://github.com/duckdb/duckdb/pull/27548 の @smvv によって非メイン ブランチでさらにリリース チェックを実行します
  • https://github.com/duckdb/duckdb/pull/27665 で @iremcaginyurtturk によるキャストが必要な、ベクター サイズより大きい追加チャンクを修正
  • https://github.com/duckdb/duckdb/pull/27684 の @smvv による v2.0-cyanoptera へのバックポート ラベル付き修正
  • ARRAY(SELECT ...) の ANY および ALL を、https://github.com/duckdb/duckdb/pull/27781 の @Robinho-MR によるリストの要素と比較します。
  • Parquet ライター: https://github.com/duckdb/duckdb/pull/27875 の @h4nsmuller によって行グループが NULL のみを保持する場合、列の最小/最大を RETURN_STATS に保持します。
  • https://github.com/duckdb/duckdb/pull/27928 の @kdmodii によって TIMESTAMPTZ_NS から TIMESTAMP へのキャストを追加
  • https://github.com/duckdb/duckdb/pull/27969 の @kdmodii により、can_have_nan オプションのデフォルトとして parquet_can_have_nan 設定を追加
  • [v2.0-cyanoptera] https://github.com/duckdb/duckdb/pull/27965 の @smvv による #27935 までのバックポート ラベル付き修正
  • [AUTOMATED_EDIT] https://github.com/duckdb/duckdb/pull/28020 の @maiadegraaf により、v2.0.1 を version_map.json に追加します
  • [v2.0-cyanoptera] https://github.com/duckdb/duckdb/pull/28072 の @Robinho-MR によるラベル付き修正をバックポートマージしました
  • https://github.com/duckdb/duckdb/pull/28125 の @EtgarDev による無相関化で重複排除を決定するときに error() を不揮発性として扱う
  • https://github.com/duckdb/duckdb/pull/28247 で @carlopi によってマージ解除された Cyanoptera の復帰
  • [v2.0-cyanoptera] バックポート #28129: https://github.com/duckdb/duckdb/pull/28139 の @ywelsch によってセグメントのデータが部分ブロックにコピーされたら、セグメントのバッファを解放します
  • [v2.0-cyanoptera] https://github.com/duckdb/duckdb/pull/28290 の @Robinho-MR によるバックポート マージされたラベル付き修正 (2)
  • https://github.com/duckdb/duckdb/pull/28362 の @DinosL による貪欲結合順序の候補として受信結合順序を保持します。
  • [v2.0-cyanoptera] https://github.com/duckdb/duckdb/pull/28396 の @Robinho-MR によるバックポート マージされたラベル付き修正 (3)
  • https://github.com/duckdb/duckdb/pull/28545 の @carlopi による、シアノプテラ上の vcpkg_installed/${VCPKG_TARGET_TRIPLET} に対する Wasm 拡張機能のリンク
  • aws を c2f2568 にバンプ (両方のリソース タイプの名前とコールバックを解決)、https://github.com/duckdb/duckdb/pull/28519 の @carlopi による cianoptera で
  • [テスト] https://github.com/duckdb/duckdb/pull/28577 の @Tishj による特定のエラー パスのエラー ログの問題を修正
  • [v2.0-cyanoptera] バックポート #27943: https://github.com/duckdb/duckdb/pull/28589 の @Robinho-MR によって書き込まれた列からのサイズ分割された COPY バッチ
  • https://github.com/duckdb/duckdb/pull/28638 の @h4nsmuller によって統計を読み取るときに、インデックスを介して複数ファイル スキャンの列を名前で検索します
  • https://github.com/duckdb/duckdb/pull/28575 の @staticlibs による Postgres、MySQL、SQLite (2.0.1) の更新

  • [v2.0-cyanoptera] https://github.com/duckdb/duckdb/pull/28710 の @Robinho-MR によるバックポート マージされたラベル付き修正 (5)

duckdb v2.0.1

This is a bug fix release for various issues discovered after we released v2.0.0.

Please also refer to the announcement blog post: https://duckdb.org/2026/11/20/announcing-duckdb-201.html

What's Changed

  • Merge Rust extension CI groups by @smvv in https://github.com/duckdb/duckdb/pull/27600
  • Print the profiler's trailing blank line through the renderer's print sink by @h4nsmuller in https://github.com/duckdb/duckdb/pull/27604
  • Fix StagedUpload.yml by @lnkuiper in https://github.com/duckdb/duckdb/pull/27610
  • Fix StagedUpload.yml by @lnkuiper in https://github.com/duckdb/duckdb/pull/27612
  • Run more release checks on non-main branch by @smvv in https://github.com/duckdb/duckdb/pull/27548
  • Fix appending chunks larger than the vector size that need a cast by @iremcaginyurtturk in https://github.com/duckdb/duckdb/pull/27665
  • Backport labeled fixes to v2.0-cyanoptera by @smvv in https://github.com/duckdb/duckdb/pull/27684
  • Compare ANY and ALL of ARRAY(SELECT ...) against the elements of the list by @Robinho-MR in https://github.com/duckdb/duckdb/pull/27781
  • Parquet writer: keep a column's min/max in RETURN_STATS when a row group holds only NULLs for it by @h4nsmuller in https://github.com/duckdb/duckdb/pull/27875
  • Add casts from TIMESTAMPTZ_NS to TIMESTAMP by @kdmodii in https://github.com/duckdb/duckdb/pull/27928
  • Add a parquet_can_have_nan setting as the default for the can_have_nan option by @kdmodii in https://github.com/duckdb/duckdb/pull/27969
  • [v2.0-cyanoptera] Backport labeled fixes through #27935 by @smvv in https://github.com/duckdb/duckdb/pull/27965
