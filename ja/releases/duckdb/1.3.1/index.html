duckdb v1.3.1

パッチ 公開日2025年6月16日 出典duckdb/duckdb English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アヒルデブv1.3.1 これは、1.3.0 "Ossivalis" のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。新しい主要な機能はなく、バグ修正のみです。 v0.9 までの DuckDB バージョンで作成されたデータベース ファイルは、このバージョンで読み取ることができます。

何が変わったのか

  • MultiFileReader: https://github.com/duckdb/duckdb/pull/17589 の @Mytherin によるネストされたリスト/マップのデフォルト値の処理を修正
  • 署名付きから署名なしへは、https://github.com/duckdb/duckdb/pull/17571 の @Tmonster によって元に戻すことはできません
  • [開発][CLI] https://github.com/duckdb/duckdb/pull/17598 の @Tishj による DUCKDB_LATEST_STORAGE_VERSION の未使用ビットを使用する
  • https://github.com/duckdb/duckdb/pull/17601 の @c-herrewijn による MAIN_BRANCH_VERSIONING のマイナーな再構築
  • https://github.com/duckdb/duckdb/pull/17602 で @c-herrewijn によってメイン ブランチのバージョン管理が false に設定されました
  • https://github.com/duckdb/duckdb/pull/17612 の @Mytherin によって正しい UUID v7 を生成
  • 問題 #17606: https://github.com/duckdb/duckdb/pull/17614 で @hawkfish による TIMESTAMPTZ キャストを無効にする
  • https://github.com/duckdb/duckdb/pull/17543 の @lnkuiper によるバグ修正
  • https://github.com/duckdb/duckdb/pull/17622 の @Mytherin による Windows ロック競合エラーを改善 ※実際の初期化はhttps://github.com/duckdb/duckdb/pull/17627の@Mytherinでファイルに一括コピー

duckdb v1.3.1

This is a bug fix release for various issues discovered after we released 1.3.0 "Ossivalis". There are no new major features, just bug fixes. Database files created by DuckDB versions all the way back to v0.9 can be read by this version.
