duckdb v1.4.4

パッチ 公開日2026年1月26日 出典duckdb/duckdb English original

このページは機械翻訳です。内容は必ず英文原文をご確認ください。

#アヒルデブv1.4.4 これは、1.4.3 のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。先ほどの誤ったリリースをお許しください。

何が変わったのか

  • キャスト修正: https://github.com/duckdb/duckdb/pull/20098 の @Mytherin によってキャストされた VARCHAR -> INTEGER の小数点を含む数値で負の指数を正しく処理します。
  • [ストレージ] https://github.com/duckdb/duckdb/pull/20103 の @Tishj による定数セグメントの NULL フィルター チェックを修正
  • install.duckdb.org の段階的アップロードを修正 - できれば https://github.com/duckdb/duckdb/pull/20104 の @hannes によるもの
  • https://github.com/duckdb/duckdb/pull/20105 の @artjomPlaunov による未定義ループを削除
  • [テスト] https://github.com/duckdb/duckdb/pull/20108 の @taniabogatsch による書き込み-書き込みの競合を予想するように同時アタッチ/デタッチ テストを調整します。
  • https://github.com/duckdb/duckdb/pull/20106 の @henry8128 による列エイリアス (#20008) を保持するようにフィルター プッシュダウンの ALIAS 関数を修正しました
  • https://github.com/duckdb/duckdb/pull/20030 の @samansmink による http ログからヘッダーが欠落しています
  • httpfs をバンピングして、@carlopi による https://github.com/duckdb/duckdb-httpfs/pull/174 を https://github.com/duckdb/duckdb/pull/20145 に含めます
  • 問題 #20136: https://github.com/duckdb/duckdb/pull/20153 の @hawkfish によるセカンダリ IGNORE NULLS
  • https://github.com/duckdb/duckdb/pull/20132 の @c-herrewijn による minio の夜間テストを修正
  • https://github.com/duckdb/duckdb/pull/20146 の @victor-ab によるモード集約結合関数の use-after-free を修正
  • https://github.com/duckdb/duckdb/pull/20165 の @evertlammerts による矢印タイプが文字列ビューではない場合のみプッシュダウン varchar
  • https://github.com/duckdb/duckdb/pull/20172 の @evertlammerts による adbc_get_objects の引用フィルター
  • 問題 #20156: ストリーミング ウィンドウ ユニオン (@hawkfish 著、https://github.com/duckdb/duckdb/pull/20191)
  • MergeInto: バッファーを正しくクリーンアップし、https://github.com/duckdb/duckdb/pull/20163 の @carlopi による重要な GetData を処理します。
  • https://github.com/duckdb/duckdb/pull/20227 の @carlopi による v1.4-andium ブランチの extension-ci-tools を最新リリース バージョンに修正
  • [雑用] タイムアウトを防ぐために CI の夜間実行をクリーンアップ by @taniabogatsch (https://github.com/duckdb/duckdb/pull/20150)
  • https://github.com/duckdb/duckdb/pull/20248 の @maiadegraaf により Julia を v1.4.3 にバンプ
  • 内部 #6881: https://github.com/duckdb/duckdb/pull/20258 の @hawkfish による 2025c タイム ゾーン
  • https://github.com/duckdb/duckdb/pull/20174 の @Dtenwolde によりステートメントをセミコロンで分割します
  • [雑務] https://github.com/duckdb/duckdb/pull/20278 の @taniabogatsch による numeric_cast.hpp インポートとその他の整ったものを削除
  • [雑務] https://github.com/duckdb/duckdb/pull/20277 の @taniabogatsch による VARCHAR インデックス作成テストのレイテンシを短縮する
  • https://github.com/duckdb/duckdb/pull/20267 の @ywelsch によるチェックポイント中に正しいテーブル レベルのメタデータを再利用する
  • https://github.com/duckdb/duckdb/pull/20260 の @Tishj により、参照されるテーブルが別のスキーマにある場合にビューの解像度が安定しない問題を修正
  • ConstantOrNullFunction 入力有効性マスクの上書きバグ修正 (https://github.com/duckdb/duckdb/pull/20283 の @artjomPlaunov による)
  • dbgen: https://github.com/duckdb/duckdb/pull/20284 の @Mytherin による TaskExecutor フレームワークを使用します
  • 修正(adbc): https://github.com/duckdb/duckdb/pull/20071 で @gishor によって空の SQL クエリを設定するとエラーが返される
  • 氷山を打ち破り、wasm プラットフォームを追加してください! @carlopi 著、https://github.com/duckdb/duckdb/pull/20205
  • _extension_distribution: https://github.com/duckdb/duckdb/pull/20294 の @carlopi による extension-ci-tools の v1.4-andium ブランチに固定します
  • https://github.com/duckdb/duckdb/pull/20252 の @EtgarDev による準備済みステートメントのパラメーター検索を最適化します。
  • https://github.com/duckdb/duckdb/pull/20343 の @lnquiper により ComputePartitionIndices の VectorType を更新
  • https://github.com/duckdb/duckdb/pull/20342 の @lnkuiper により、RadixPartitionedHashTable::Combine と RadixPartitionedHashTable::Finalize に防御的なプログラミングを追加
  • https://github.com/duckdb/duckdb/pull/20340 の @Flogex による SetPathsInternal のパスの予約サイズを増やす
  • Windows シェル (1.4) で UTF-16 コンソール出力を使用 (https://github.com/duckdb/duckdb/pull/20339 の @staticlibs による)
  • https://github.com/duckdb/duckdb/pull/20357 の @lnquiper による RadixPartitionedHashTable::Combine での強制再パーティション化
  • https://github.com/duckdb/duckdb/pull/20360 の @carlopi による、abdc のドライバーの間違った反復子との比較を修正
  • [雑務] https://github.com/duckdb/duckdb/pull/20279 の @taniabogatsch による dsdgen 生成の符号付き整数オーバーフローの修正
  • https://github.com/duckdb/duckdb/pull/20396 の @pdet によって設定で設定された変数を優先します
  • QueryContext を Write(void *buffer, idx_t nr_bytes) にも追加して、https://github.com/duckdb/duckdb/pull/20393 の @carlopi によって BytesWritten も更新されるようにします
  • 問題 #20233 を修正: https://github.com/duckdb/duckdb/pull/20302 の @ArNine による修飾の関数チェーンを修正
  • https://github.com/duckdb/duckdb/pull/20403 の @taniabogatsch によるバックポート client データ クリーンアップ
  • https://github.com/duckdb/duckdb/pull/20404 の @maiadegraaf によりストレージ バージョンに v1.4.4 を追加
  • Parquet Reader: https://github.com/duckdb/duckdb/pull/20405 で @Mytherin によってエラーをスローする代わりに、文字列統計の無効な UTF8 を無視します。
  • https://github.com/duckdb/duckdb/pull/20401 で @Dtenwolde によってステートメントを分割する場合は、最後のクエリにセミコロンを追加しないでください。
  • BRANCHES_TO_BE_CACHED を修正。変数は PR では利用できないため、環境は https://github.com/duckdb/duckdb/pull/20411 の @carlopi によるものです
  • [修正] C API での防御的な無限ループ ガードと UTF-8 チェック (https://github.com/duckdb/duckdb/pull/20348 の @taniabogatsch による)
  • https://github.com/duckdb/duckdb/pull/20319 の @carlopi によって CI で実行されるように、ducklake、httpfs、iceberg のテストを追加します。

duckdb v1.4.4

This is a bug fix release for various issues discovered after we released 1.4.3. Please excuse the erroneous release earlier.

What's Changed

  • Cast Fix: Correctly handle negative exponent with a number with a decimal in VARCHAR -> INTEGER cast by @Mytherin in https://github.com/duckdb/duckdb/pull/20098
