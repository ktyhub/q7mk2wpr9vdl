#アヒルデブv1.5.5 これは、v1.5.4 のリリース後に発見されたさまざまな問題に対するバグ修正リリースです。

何が変わったのか

  • https://github.com/duckdb/duckdb/pull/23197 の @Tishj によって #23100 で行われた範囲外のセキュリティ修正をバックポートします。
  • https://github.com/duckdb/duckdb/pull/23261 の @carlopi によって fmt dep (1.4) から Checked_array_iterator を削除
  • https://github.com/duckdb/duckdb/pull/23239 の @staticlibs により fmt dep (1.4) から Checked_array_iterator を削除

  • https://github.com/duckdb/duckdb/pull/23145 の @NiclasHaderer によるテスト構成拡張のサポートを追加
  • https://github.com/duckdb/duckdb/pull/23311 の @Tmonster により再び氷山にぶつかる
  • https://github.com/duckdb/duckdb/pull/23325 の @Mytherin により、完全に細断されたバリアントの型指定された値の統計を正しく取得します
  • https://github.com/duckdb/duckdb/pull/23326 で @benfleis によるバックフィル修正を含めるためのバンプ ユニティ

  • [開発] https://github.com/duckdb/duckdb/pull/23362 の @Tishj による scripts/lldb/pointer_print の再帰問題を修正
  • [MultiFileReader] https://github.com/duckdb/duckdb/pull/23354 の @Tishj による (おそらく欠落している) デフォルト値のため、NULL MAP キーを防止します
  • https://github.com/duckdb/duckdb/pull/23375 の @Mytherin によってラムダ バインディングを try 演算子に伝播します
  • https://github.com/duckdb/duckdb/pull/23398 の @carlopi により Julia を v1.5.4 にバンプ
  • https://github.com/duckdb/duckdb/pull/23341 の @sebastiaan-dev により、小さなブロック サイズでの圧縮中の例外を防ぐために DICT_FSST に追加のガードを追加
  • https://github.com/duckdb/duckdb/pull/23371 の @jmestwa-coder による json パス ReadKey 先読みの範囲外読み取りを修正
  • https://github.com/duckdb/duckdb/pull/23384 で @jmestwa-coder によってキャストされた構造体への文字列の範囲外の読み取りを修正
  • 問題 #23383: https://github.com/duckdb/duckdb/pull/23409 の @hawkfish による共通の集約 CTE
  • https://github.com/duckdb/duckdb/pull/23430 で @Mytherin による依存関係を検証するときに正しい開始時間を使用する
  • https://github.com/duckdb/duckdb/pull/23458 の @DinosL による誤った RLE 破損エラーを修正

  • https://github.com/duckdb/duckdb/pull/23480 の @DinosL による rle 破損エラー メッセージを改善

duckdb v1.5.5

This is a bug fix release for various issues discovered after we released v1.5.4.

What's Changed

  • backport the out-of-bounds security fixes made in #23100 by @Tishj in https://github.com/duckdb/duckdb/pull/23197
  • Remove checked_array_iterator from fmt dep (1.4) by @carlopi in https://github.com/duckdb/duckdb/pull/23261

  • Correctly get typed value stats for fully shredded variants by @Mytherin in https://github.com/duckdb/duckdb/pull/23325
  • bump unity to include backfill fix by @benfleis in https://github.com/duckdb/duckdb/pull/23326
