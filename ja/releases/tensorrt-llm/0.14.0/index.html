TensorRT-LLM v0.14.0

こんにちは。 TensorRT-LLM の 0.14.0 バージョンを発表できることを大変うれしく思います。このアップデートには以下が含まれます:

主な機能と拡張機能

  • LLM APIのLLMクラスを強化しました。
    • オフライン データセットを使用したキャリブレーションのサポートが追加されました。
    • Mamba2のサポートを追加しました。
    • finish_reason および stop_reason のサポートを追加しました。
  • CodeLlama の FP8 サポートを追加しました。
  • #2191 の @1ytic からの貢献のおかげで、クラス Module に __repr__ メソッドを追加しました。
  • 融合ゲート MLP の BFloat16 サポートを追加しました。
  • Apple ReDrafter v1.1 に一致するように ReDrafter ビーム検索ロジックを更新しました。
  • customAllReduce のパフォーマンスが向上しました。
  • ドラフト モデルは、orchestrator モードで MPI 経由でターゲット モデルのプロセスにロジットを直接コピーできるようになりました。この高速ロジット コピーにより、ドラフト トークンの生成とターゲット モデルの推論の開始の間の遅延が短縮されます。
  • NVIDIA Volta GPU サポートは非​​推奨となり、将来のリリースでは削除される予定です。

API の変更点

  • [重大な変更] trtllm-build コマンドのデフォルトの max_batch_size は 2048 に設定されます。
  • [重大な変更] BuildConfig クラスと trtllm-build コマンドから builder_opt を削除します。
  • Logits ポストプロセッサのサポートを ModelRunnerCpp クラスに追加します。
  • 現在のプロセスがエグゼキューター インスタンスの参加者であるかどうかを確認するための isParticipant メソッドを C++ Executor API に追加しました。

モデルの更新

  • NemotronNas のサポートを追加しました。examples/nemotron_nas/README.md を参照してください。
  • Deepseek-v1 のサポートを追加しました。examples/deepseek_v1/README.md を参照してください。
  • Phi-3.5 モデルのサポートを追加しました。examples/phi/README.md を参照してください。

修正された問題

  • #2152 の @wangkuiyi からの貢献のおかげで、tensorrt_llm/models/model_weights_loader.py のタイプミスを修正しました。
  • #2182 の @lkm2835 からの貢献のおかげで、tensorrt_llm/runtime/generation.py の重複したインポート モジュールを修正しました。
  • #2232 の @lkm2835 からの貢献のおかげで、レガシー チェックポイント変換パスに lm_head がないモデルに対して share_embedding を有効にしました。
  • #2219 の @qingquansong からの貢献のおかげで、Python ベンチマークの kv_cache_type の問題を修正しました。
  • カスタム データセットを使用した SmoothQuant キャリブレーションの問題を修正しました。 #2243 の @Bhuvanesh09 による貢献に感謝します。
  • 偽またはランダムな重みを伴う trtllm-build --fast-build に関する問題を修正しました。 #2135 にフラグを立ててくれた @ZJLi2013 に感謝します。
  • dict から BuildConfig を構築するときに欠落していた use_fused_mlp を修正しました。#2081 の @ethnzhng からの修正に感謝します。
  • numNewTokensCumSum の先読みバッチ レイアウトを修正しました。 (#2263)

インフラストラクチャの変更

  • 依存する ModelOpt バージョンが v0.17 に更新されました。

ドキュメント

  • @Sherlock113 が #2169 の最新ニュースに 技術ブログ を追加しました。貢献に感謝します。

既知の問題

  • リプリットコードはトランス 4.45+ ではサポートされていません。 新しい機能、バグ修正、パフォーマンスの最適化により、main ブランチを定期的に更新しています。 rel ブランチの更新頻度は低くなり、正確な頻度はフィードバックによって異なります。 ありがとう、 TensorRT-LLM エンジニアリング チーム

TensorRT-LLM v0.14.0

Highlights

  • LLM API expands calibration and model coverage — The Python LLM class now calibrates against an offline dataset, adds Mamba2 state-space models, and finally emits proper finish_reason/stop_reason. This lets you quantize without a live data path and lets serving layers branch on stop conditions instead of scraping tokens. The SmoothQuant-with-custom-datasets fix (#2243) makes that calibration path actually usable.
  • Two breaking build-config changes need migration — trtllm-build now defaults max_batch_size to 2048, and builder_opt is removed from both BuildConfig and the CLI. Audit scripts that relied on the old implicit batch default (memory footprint will jump sharply) and delete every builder_opt/--builder_opt reference or builds fail outright. This is the likeliest source of post-upgrade breakage.
  • Speculative decoding and low-precision get faster — ReDrafter beam search now matches Apple ReDrafter v1.1, customAllReduce is optimized, and in orchestrator mode the draft model copies logits directly over MPI into the target process, shrinking the draft-to-target gap. Together with BFloat16 fused gated MLP and FP8 for CodeLlama, these are real throughput/cost gains for speculative-decoding and quantized deployments — benchmark your own workloads rather than assuming parity.
  • Three new model families land — NemotronNas, DeepSeek-V1, and Phi-3.5 arrive with reference examples (examples/nemotron_nas, examples/deepseek_v1, examples/phi). If you were hand-rolling conversion for any of these, start from the shipped READMEs instead.
  • Finer-grained runtime control — ModelRunnerCpp accepts a logits post-processor, and the C++ Executor API adds isParticipant() to tell whether the current process belongs to an executor instance. Small additions, but key hooks for multi-process/distributed inference and custom sampling or guided-decoding pipelines.
  • Compatibility watch-outs before you upgrade — ModelOpt is bumped to v0.17 (align your quantization toolchain), Volta support is deprecated and slated for removal, and Replit Code is known-broken with transformers 4.45+. Also note fixes for --fast-build with fake/random weights (#2135), use_fused_mlp when building BuildConfig from a dict (#2081), and the lookahead numNewTokensCumSum batch layout (#2263).

Hi,

We are very pleased to announce the 0.14.0 version of TensorRT-LLM. This update includes:

Key Features and Enhancements

  • Enhanced the LLM class in the LLM API.
    • Added support for calibration with offline dataset.
    • Added support for Mamba2.
    • Added support for finish_reason and stop_reason.
  • Added FP8 support for CodeLlama.
  • Added __repr__ methods for class Module, thanks to the contribution from @1ytic in #2191.
  • Added BFloat16 support for fused gated MLP.
  • Updated ReDrafter beam search logic to match Apple ReDrafter v1.1.
  • Improved customAllReduce performance.
  • Draft model now can copy logits directly over MPI to the target model's process in orchestrator mode. This fast logits copy reduces the delay between draft token generation and the beginning of target model inference.
  • NVIDIA Volta GPU support is deprecated and will be removed in a future release.

API Changes

  • [BREAKING CHANGE] The default max_batch_size of the trtllm-build command is set to 2048.
  • [BREAKING CHANGE] Remove builder_opt from the BuildConfig class and the trtllm-build command.
  • Add logits post-processor support to the ModelRunnerCpp class.
  • Added isParticipant method to the C++ Executor API to check if the current process is a participant in the executor instance.

Model Updates

  • Added support for NemotronNas, see examples/nemotron_nas/README.md.
  • Added support for Deepseek-v1, see examples/deepseek_v1/README.md.
  • Added support for Phi-3.5 models, see examples/phi/README.md.

Fixed Issues

  • Fixed a typo in tensorrt_llm/models/model_weights_loader.py, thanks to the contribution from @wangkuiyi in #2152.
  • Fixed duplicated import module in tensorrt_llm/runtime/generation.py, thanks to the contribution from @lkm2835 in #2182.
  • Enabled share_embedding for the models that have no lm_head in legacy checkpoint conversion path, thanks to the contribution from @lkm2835 in #2232.
  • Fixed kv_cache_type issue in the Python benchmark, thanks to the contribution from @qingquansong in #2219.
  • Fixed an issue with SmoothQuant calibration with custom datasets. Thanks to the contribution by @Bhuvanesh09 in #2243.
  • Fixed an issue surrounding trtllm-build --fast-build with fake or random weights. Thanks to @ZJLi2013 for flagging it in #2135.
  • Fixed missing use_fused_mlp when constructing BuildConfig from dict, thanks for the fix from @ethnzhng in #2081.
  • Fixed lookahead batch layout for numNewTokensCumSum. (#2263)

Infrastructure Changes

  • The dependent ModelOpt version is updated to v0.17.

Documentation

  • @Sherlock113 added a tech blog to the latest news in #2169, thanks for the contribution.

Known Issues

  • Replit Code is not supported with the transformers 4.45+

We are updating the main branch regularly with new features, bug fixes and performance optimizations. The rel branch will be updated less frequently, and the exact frequencies depend on your feedback.

Thanks, The TensorRT-LLM Engineering Team
