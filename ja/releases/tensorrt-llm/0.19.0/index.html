TensorRT-LLM v0.19.0

TensorRT-LLM リリース 0.19.0

主な機能と拡張機能

  • C++ ランタイムはオープンソースになりました。
  • PyTorch ワークフロー
    • DeepSeek V3/R1 サポートを追加しました。 examples/deepseek_v3/README.md およびブログ docs/source/blogs/Best_perf_practice_on_DeepSeek-R1_in_TensorRT-LLM.md を参照してください。
    • Llava-Next のサポートを追加しました。
    • BERT サポートを追加しました。
    • C++ ベースのデコーダを追加しました。これにより、以下のサポートが追加されました。
      • TopK / TopP.
      • 悪い言葉。
      • 言葉を止めてください。
      • 埋め込みバイアス。
    • カスタム OP 互換のチューニング プロセス用に Autotuner を追加しました。
      • カーネル調整用に Python ベースの Autotuner コア フレームワークを追加しました。
      • コンセプトとパフォーマンスの評価のために、Autotuner を MoE と NVFP4 線形演算子の融合に適用しました。
    • ガイド付きデコードのサポート (XGrammar 統合) を追加しました。
    • PyExecutor のオーバーラップ スケジューラに対するパイプライン並列処理のサポートを追加しました。
    • Qwen2VL モデルのサポートを追加しました。
    • 混合精度量子化サポートを追加しました。
    • 注意 DP サポートによるパイプライン並列処理を追加しました。
    • キャッシュなしアテンションのサポートを追加しました。
    • PeftCacheManager のサポートを追加しました。
    • Qwen2.5‑VL サポートを追加し、Qwen2‑VL をリファクタリングしました。
    • trtllm‑gen FP4 GEMM サポートを追加しました。
    • Qwen2 MoE サポートを追加しました。
    • AutoTuner を Fused MoE と NVFP4 Linear オペレーターの両方に適用しました。
    • UserBuffers アロケータを導入しました。
    • Deepseek 熱心モードの AllReduce 融合サポートを追加しました。
    • マルチトークン予測 (MTP) サポートを追加しました。 examples/deepseek_v3/README.md の「マルチトークン予測 (MTP)」セクションを参照してください。
    • SM90 の FlashMLA サポートを追加しました。
    • CUDA グラフ パディングを使用して MTP を有効にするためのサポートが追加されました。
    • 初期の EAGLE-3 実装を追加しました。
    • NVIDIA Hopper および Blackwell GPU での FP8 MLA のサポートを追加しました。
  • PyTorch ワークフローの AutoDeploy。
    • AutoDeploy for PyTorch ワークフローは、tensorrt_llm._torch.auto_deploy の 実験的 機能です。
    • AutoDeploy は、既製のモデルから TensorRT-LLM ランタイムでの最適化されたデプロイメントへの自動パスを提供します。
    • 詳細については、examples/auto_deploy/README.md をご覧ください。
  • LLM API
    • [重大な変更] 動的ロジット プロセッサのサポートが追加され、非推奨の静的ロジット プロセッサが追加されました。
    • バッチ化されたロジットプロセッサのサポートを追加しました。
    • EAGLE サポートを追加しました。
    • 中止リクエストのサポートを追加しました。
    • get_stats のサポートを追加しました。

  • InternLM-XComposer2 のサポートを追加しました。 examples/multimodal/README.md の「InternLM-XComposer2」セクションを参照してください。
  • MoE モデルに INT4-AWQ サポートを追加しました。 examples/mixtral/README.md の「AWQ 量子化」セクションを参照してください。
  • Qwen2-Audio のサポートを追加しました。 examples/qwen2audio/README.mdを参照してください。
  • 言語アダプターのサポートを追加しました。 examples/language_adapter/README.mdを参照してください。
  • OpenSoRA text-to-video サポート用の STDiT を追加しました。 examples/stdit/README.mdを参照してください。
  • テンソル並列処理とコンテキスト並列処理をサポートするビジョン エンコーダを追加しました。 examples/vit/README.mdを参照してください。
  • EXAONE-Deep サポートを追加しました。 examples/exaone/README.mdを参照してください。
  • Phi-4-mini および Phi-4-MM のサポートを追加しました。
  • Gemma3 テキスト専用モデルのサポートを追加しました。 examples/gemma/README.md の「Gemma 3 の実行」セクションを参照してください。
  • Qwen2-VL に FP8 量子化サポートを追加しました。
  • LLM API MMLU サンプル examples/mmlu_llmapi.py のバッチ推論サポートを追加しました。
  • FP4 quantization-layernorm fusion プラグインのサポートを追加しました。 (ラマモデルのみ)
  • Mamba ハイブリッドのサポートを追加しました。
  • NVILA ビデオのサポートを追加しました。このサポートには、1 プロンプト - N メディアおよび N プロンプト - N メディアのバッチ モードが含まれます。
  • lm_head 量子化をサポートするために、--quantize_lm_head オプション examples/quantization/quantize.py を追加しました。
  • バッチ化されたテンソル FP4 量子化サポートを追加しました。
    • 反復統計をログに記録するために、trtllm-serve の /metrics エンドポイントを追加しました。
    • Phi-2 モデルに LoRA サポートを追加しました。
    • trtllm-serve に対するリターン コンテキスト ロジットのサポートを追加しました。
    • FP16/BF16 での UserBuffer AllReduce-Normalization のワンショット バージョンを追加しました。
    • disaggServerBenchmark のリクエスト BW メトリック測定を追加しました。
    • logits ビットマスク カーネルを v3 に更新しました。
    • アテンション DP が使用され、異なる GPU でのアクティブなリクエストが不均一だった場合に CUDA グラフを有効にしました。
    • trtllm-bench の反復ログのサポートを追加しました。
    • fp8_blockscale_gemm はオープンソースになりました。
    • ModelOpt チェックポイントの AWQ サポートを追加しました。
    • FP4 量子化でのリニア ブロック スケール レイアウトのサポートを追加しました。
    • Nemotron-mini-4b-instruct に事前量子化された FP8 チェックポイントのサポートを追加しました。
    • 可変ビーム幅検索 (VBWS) サポート (パート 2) を追加しました。
    • Gemma の LoRA サポートを追加しました。
    • 足場ワーカーをリファクタリングし、OpenAI API ワーカーのサポートを追加しました。
    • オプションで MoE 入力をチャンクに分割して、GPU メモリの使用量を削減します。
    • UCX IP インターフェイスのサポートを追加しました。
    • [重大な変更] 最初のトークンの出力を追加の生成出力に追加しました。
    • SM120 アーキテクチャに対する FP8 サポートを追加しました。
    • CMakeのオプションとしてENABLE_MULTI_DEVICEとENABLE_UCXを登録しました。
    • スキャフォールディング コントローラーをより汎用的にしました。
    • 重大な変更: 追加の出力ごとに個別の GatherContext サポートが追加されました。
    • kv_cache_manager の max_num_tokens を推定するための PyExecutor 推論フローを有効にしました。
    • デバッグ用に TLLM_OVERRIDE_LAYER_NUM および TLLM_TRACE_MODEL_FORWARD 環境変数を追加しました。
    • 切断されたリクエストの中止をサポートしました。
    • コンテキスト サーバーなしで分散サービスを実行するオプションを追加しました。
    • allreduce カーネルと Fusion カーネルを修正および改善しました。

API の変更点

  • kc_cache_retention_config を C++ executor API から LLM API に公開しました。
  • BuildConfig 引数を LlmArgs に移動しました。
  • ステートフル デコーダから投機的デコード パラメータを削除しました。
  • DecoderState をバインディング経由で公開し、デコーダーに統合しました。
  • LlmArgs を Pydantic でリファクタリングし、残りの pybinding 構成を Python に移行しました。
  • 細分化された配信スクリプトがリファクタリングされました。
  • numNodes を ParallelConfig に追加しました。
  • DeepSeek 用にマルチストリーム API を再設計しました。

修正された問題

  • PluginField の長さ引数の誤用を修正しました。これにより #2685 も修正されます。
  • Llama-3.2 SmoothQuant 変換チェックポイントの問題を修正しました。 (#2677)
  • LLM API 経由で LoRA を使用してエンジンをロードするときのバグを修正しました。 (#2782)
  • addCumLogProbs カーネルでのバッチ スロットの誤った使用法を修正しました。
  • Llama-3.2-11B-Vision-Instruct の誤った出力を修正しました。 (#2796)
  • pip install tensorrt-llm を実行する場合に必要な --extra-index-url https://pypi.nvidia.com を削除しました。

インフラストラクチャの変更

  • 依存する NVIDIA ModelOpt バージョンが 0.27 に更新されました。

既知の問題

  • SBSA の PyTorch ワークフローは、Ubuntu 24.04 などのベア メタル環境と互換性がありません。 SBSA プラットフォームでのサポートを最適化するには、PyTorch NGC Container を使用してください。

TensorRT-LLM v0.19.0

Highlights

  • Open runtime and automated deployment — The C++ runtime is open-sourced, and the Autotuner supports custom-operator tuning for fused MoE and NVFP4 linear kernels. Experimental tensorrt_llm._torch.auto_deploy adds an off-the-shelf-model-to-runtime path; evaluate it separately from production deployments until its APIs stabilize.
  • DeepSeek V3/R1 performance paths — MTP supports CUDA-graph padding, FlashMLA targets SM90, and FP8 MLA covers Hopper and Blackwell, providing hardware-specific latency options. EAGLE-3 is only an initial implementation, so validate speculative-decoding gains on your model and GPU before relying on them.
  • Scaling and multimodal coverage — PyExecutor adds overlap-scheduled pipeline parallelism and attention data parallelism, including CUDA graphs for uneven request loads across GPUs. Qwen2.5-VL and NVILA video batching broaden multimodal workloads, but skewed traffic should be benchmarked to confirm scheduler behavior.
  • LLM API contract changes require consumer updates — Additional generation outputs now include first-token data, and context gathering is handled individually per additional output; audit downstream parsers and gather logic. Migrate static logits processors to the new batched dynamic interface, as static processors are deprecated.
  • Configuration and decoder APIs move to Python — BuildConfig arguments move into Pydantic-based LlmArgs, remaining pybinding configurations migrate to Python, and speculative-decoding parameters are removed from stateful decoders. Update launchers accordingly; get_stats, abort handling, context logits, and /metrics add serving observability and cancellation controls.
  • Dependency and platform checks — ModelOpt is updated to 0.27, AWQ supports ModelOpt checkpoints, and installation no longer requires --extra-index-url https://pypi.nvidia.com. On SBSA, bare-metal Ubuntu 24.04 remains incompatible with the PyTorch workflow; use the PyTorch NGC container.

TensorRT-LLM Release 0.19.0

Key Features and Enhancements

  • The C++ runtime is now open sourced.
  • PyTorch workflow
    • Added DeepSeek V3/R1 support. Refer to examples/deepseek_v3/README.md, also to the blog docs/source/blogs/Best_perf_practice_on_DeepSeek-R1_in_TensorRT-LLM.md.
    • Added Llava-Next support.
    • Added BERT support.
    • Added a C++ based decoder, which added support for:
      • TopK / TopP.
      • Bad words.
      • Stop words.
      • Embedding bias.
    • Added Autotuner for custom-op-compatible tuning process.
      • Added a Python-based Autotuner core framework for kernel tuning.
      • Applied the Autotuner to fused MoE and NVFP4 linear operators for concept and performance evaluations.
    • Added guided decoding support (XGrammar integration).
    • Added pipeline parallelism support for the overlap scheduler in PyExecutor.
    • Added Qwen2VL model support.
    • Added mixed precision quantization support.
    • Added pipeline parallelism with attention DP support.
    • Added no-cache attention support.
    • Added PeftCacheManager support.
    • Added Qwen2.5‑VL support and refactored Qwen2‑VL.
    • Added trtllm‑gen FP4 GEMM support.
    • Added Qwen2 MoE support.
    • Applied AutoTuner to both Fused MoE and NVFP4 Linear operators.
    • Introduced a UserBuffers allocator.
    • Added Deepseek eager mode AllReduce fusion support.
    • Added Multi-Token Prediction (MTP) support. Refer to the “Multi-Token Prediction (MTP)” section of examples/deepseek_v3/README.md.
    • Added FlashMLA support for SM90.
    • Added support for enabling MTP with CUDA graph padding.
    • Added initial EAGLE-3 implementation.
    • Added support for FP8 MLA on NVIDIA Hopper and Blackwell GPUs.
  • AutoDeploy for PyTorch workflow.
    • The AutoDeploy for PyTorch workflow is an experimental feature in tensorrt_llm._torch.auto_deploy.
    • AutoDeploy provides an automated path from off-the-shelf models to optimized deployment in the TensorRT-LLM runtime.
    • Check out examples/auto_deploy/README.md for more details.
  • LLM API
    • [BREAKING CHANGE] Added dynamic logits processor support, and deprecated static logits processor.
    • Added batched logits processor support.
    • Added EAGLE support.
    • Added abort request support.
    • Added get_stats support.
    • Added multi-node support for Slurm-based clusters, refer to examples/llm-api/llm_mgmn_*.sh.
  • Added InternLM-XComposer2 support. Refer to “InternLM-XComposer2” section in examples/multimodal/README.md.
  • Added INT4-AWQ support for MoE models. Refer to the “AWQ Quantization” section in examples/mixtral/README.md.
  • Added Qwen2-Audio support. Refer to examples/qwen2audio/README.md.
  • Added Language-Adapter support. Refer to examples/language_adapter/README.md.
  • Added STDiT for OpenSoRA text-to-video support. Refer to examples/stdit/README.md.
  • Added vision encoders with tensor parallelism and context parallelism support. Refer to examples/vit/README.md.
  • Added EXAONE-Deep support. Refer to examples/exaone/README.md.
  • Added support for Phi-4-mini and Phi‑4‑MM.
  • Added Gemma3 text‑only model support. Refer to "Run Gemma 3" section at examples/gemma/README.md.
  • Added FP8 quantization support for Qwen2-VL.
  • Added batched inference support for the LLM API MMLU example examples/mmlu_llmapi.py.
  • Added FP4 quantization-layernorm fusion plugin support. (Llama models only)
  • Added Mamba-Hybrid support.
  • Added NVILA video support. The support includes 1 prompt - N media and N prompt - N media batching modes.
  • Added a --quantize_lm_head option examples/quantization/quantize.py to support lm_head quantization.
  • Added batched tensor FP4 quantization support.
  • Added a /metrics endpoint for trtllm-serve to log iteration statistics.
  • Added LoRA support for Phi-2 model.
  • Added returning context logits support for trtllm-serve.
  • Added one-shot version for UserBuffer AllReduce-Normalization on FP16/BF16.
  • Added request BW metric measurement for disaggServerBenchmark.
  • Updated logits bitmask kernel to v3.
  • Enabled CUDA graphs when attention DP was used and active requests on different GPUs were uneven.
  • Added iteration log support for trtllm-bench.
  • fp8_blockscale_gemm is now open-sourced.
  • Added AWQ support for ModelOpt checkpoints.
  • Added Linear block scale layout support in FP4 quantization.
  • Added pre-quantized FP8 checkpoint support for Nemotron-mini-4b-instruct.
  • Added Variable-Beam-Width-Search (VBWS) support (part2).
  • Added LoRA support for Gemma.
  • Refactored scaffolding worker, added OpenAI API worker support.
  • Optionally split MoE inputs into chunks to reduce GPU memory usage.
  • Added UCX IP interface support.
  • [BREAKING CHANGE] Added output of first token to additional generation outputs.
  • Added FP8 support for SM120 architecture.
  • Registered ENABLE_MULTI_DEVICE and ENABLE_UCX as CMake options.
  • Made the scaffolding Controller more generic.
  • Breaking change: Added individual gatherContext support for each additional output.
  • Enabled PyExecutor inference flow to estimate max_num_tokens for kv_cache_manager.
  • Added TLLM_OVERRIDE_LAYER_NUM and TLLM_TRACE_MODEL_FORWARD environment variables for debugging.
  • Supported aborting disconnected requests.
  • Added an option to run disaggregated serving without context servers.
  • Fixed and improved allreduce and fusion kernels.
  • Enhanced the integrated robustness of scaffolding via init.py.

API Changes

  • Exposed kc_cache_retention_config from C++ executor API to the LLM API.
  • Moved BuildConfig arguments to LlmArgs.
  • Removed speculative decoding parameters from stateful decoders.
  • Exposed DecoderState via bindings and integrated it in decoder.
  • Refactored the LlmArgs with Pydantic and migrated remaining pybinding configurations to Python.
  • Refactored disaggregated serving scripts.
  • Added numNodes to ParallelConfig.
  • Redesigned the multi‑stream API for DeepSeek.

Fixed Issues

  • Fixed misused length argument of PluginField. This also fixes #2685.
  • Fixed a Llama-3.2 SmoothQuant convert checkpoint issue. (#2677)
  • Fixed a bug when loading an engine using LoRA through the LLM API. (#2782)
  • Fixed incorrect batch slot usage in addCumLogProbs kernel.
  • Fixed incorrect output for Llama-3.2-11B-Vision-Instruct. (#2796)
  • Removed the necessary of --extra-index-url https://pypi.nvidia.com when running pip install tensorrt-llm.

Infrastructure Changes

  • The dependent NVIDIA ModelOpt version is updated to 0.27.

Known Issues

  • The PyTorch workflow on SBSA is incompatible with bare metal environments like Ubuntu 24.04. Please use the PyTorch NGC Container for optimal support on SBSA platforms.
