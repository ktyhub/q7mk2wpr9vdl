agentscope v2.0.9

エージェントスコープ v2.0.9

ハイライト

  • 標準操作手順 (実験的): タスクを順序付けられたマイルストーンに分割するための agentscope.sop モジュールを追加しました。各マイルストーンは次のマイルストーンの開始前に検証され、実行状態は保持および再開できます。また、エージェント サービスは、プロシージャを保存し、実行を開始し、手動でステップを確認できるように /sop エンドポイントを公開します。
  • チーム パイプライン: リーダー エージェントがメンバー エージェントにタスクを委任する TeamPipeline クラスを追加しました。メンバー エージェントは同時に実行され、結果を返します。
  • リアルタイム音声モデルの追加: OpenAI Realtime、Gemini Live、および xAI Grok Voice モデルがリアルタイム音声エージェントに追加されました。
  • ターミナル UI: agentscope.tui モジュールを導入しました。これは、エージェントとチャットし、launch_realtime_ui 経由でリアルタイム音声セッションを実行するための全画面ターミナル インターフェイスです。
  • AskUser ツール: エージェントがユーザーに複数選択の質問をできる外部ツールである AskUser を追加しました。
  • MiniMax モデルと Jev ベースのモデル ルーティング: MiniMax チャット モデル (デフォルトでは M3) と、各応答のチャット モデルを選択する新しい agentscope.classifier モジュール (Jev サポート付き) によってサポートされる ModelRouterMiddleware が追加されました。
  • DingTalk ナレッジ ベース ツール: DingTalk チャネルのエージェントは、DingTalk ナレッジ ベースを検索できるようになりました。
  • より安全なシェル権限チェック: 読み取り専用コマンドの検出が強化されたため、破壊的な git、sed、tee の使用によって権限の確認がスキップされなくなりました。

agentscope v2.0.9

Highlights

  • Standard Operating Procedures (experimental) — New agentscope.sop module (PR #2393) models a task as ordered milestones, each verified before the next starts, with run state that can be persisted and resumed, plus /sop service endpoints to store procedures, start runs, and manually review steps. This is the headline feature for anyone building durable, human-in-the-loop multi-step agents, but it is explicitly experimental (and already needed a follow-up so steps record what they actually kept, #2616) — treat the API as still settling.

  • New orchestration and model-routing primitives — TeamPipeline (PR #2764) adds leader-to-member delegation with members running concurrently and handing results back, while ModelRouterMiddleware backed by the new agentscope.classifier module with Jev support (#2758) picks the chat model for each reply; MiniMax chat support also lands with M3 as the default (#1764). Worth a look if you want structured delegation or per-reply model selection — note follow-up fixes stopped the router inheriting the previous reply's model (#2793) and a budget-middleware KeyError when ReplyEndEvent is swallowed (#2419).

  • Realtime voice broadens and gets hardened — Added OpenAI Realtime (#2552), Gemini Live (#2556), and xAI Grok Voice (#2553) backends, plus the agentscope.tui full-screen chat interface (#2507) and launch_realtime_ui for voice sessions (#2594). A dense cluster of realtime fixes — reconnect before sending text (#2591), dropping stale terminal events on reconnect (#2588), transport reset across restarts (#2740), reply IDs in interrupt events (#2692) — means voice was meaningfully stabilized, not just expanded. Upgrade if voice agents are in your stack; otherwise this module is largely irrelevant to you.

  • Interactive/channel tools and one behavioral change to watch — New AskUser external tool for multi-choice questions (#2573, with constraint validation #2586) and DingTalk knowledge-base search tools for DingTalk channels (#2464). Separately, read-only command detection was tightened so destructive git, sed, and tee usages no longer skip permission confirmation (#2629, #2747, #2795) — this is a behavioral change, not just a bug fix: automation that relied on those commands being auto-approved will now hit confirmation prompts, so audit shell-tool workflows before rolling out.

  • Upgrade guidance — This is a substantial feature-and-fix release, clearly not a no-op, re-tag, or metadata-only bump, and it documents no explicit breaking API changes or migration steps (a 2.0.x minor). Upgrade if you want SOP, TeamPipeline, Jev/model routing, MiniMax, realtime voice, or the broad correctness fixes across formatters, RAG parsers, storage locale handling, and cancellation propagation. Teams happy on a pinned 2.0.x with no use for these features — and with shell automation sensitive to the new permission behavior — can safely skip; for everyone else the volume of fixes makes this worth taking.

Highlight

  • Standard Operating Procedures (Experimental): Added the agentscope.sop module for splitting a task into ordered milestones, each verified before the next one starts, with run state that can be persisted and resumed. The agent service also exposes /sop endpoints to store procedures, start runs, and review steps by hand.
  • Team Pipeline: Added a TeamPipeline class where a leader agent delegates tasks to member agents, which run concurrently and hand their results back.
  • More Realtime Voice Models: Added OpenAI Realtime, Gemini Live, and xAI Grok Voice models to the realtime voice agent.
  • Terminal UI: Introduced the agentscope.tui module, a full-screen terminal interface for chatting with agents and running realtime voice sessions via launch_realtime_ui.
  • AskUser Tool: Added AskUser, an external tool that lets agents ask users multiple-choice questions.
  • MiniMax Model and Jev-based Model Routing: Added the MiniMax chat model (M3 by default), and a ModelRouterMiddleware backed by the new agentscope.classifier module (with Jev support) that picks the chat model for each reply.
  • DingTalk Knowledge Base Tools: Agents on DingTalk channels can now search DingTalk knowledge bases.
  • Safer Shell Permission Checks: Tightened read-only command detection so destructive git, sed, and tee usages no longer skip permission confirmation.
