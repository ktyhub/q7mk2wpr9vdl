agentscope v1.0.19

Highlights

  • Local multimedia inputs — Formatters now support local paths beginning with file:// (#1385), while Anthropic and DashScope convert local files to base64 for API requests (#1361, #1253). Developers can pass local media references without manually encoding them first.

  • Memory backend and concurrency improvements — TableStore is now available as a memory backend (#1308). AsyncSQLAlchemyMemory also serializes mutating operations and flushes sessions (#1390, #1396), fixing IntegrityError failures with ReActAgent(parallel_tool_calls=True); the tradeoff is that writes are queued rather than executed concurrently.

  • DeepResearch reliability and example migration — Response handling now locates text blocks instead of assuming the first block is text, preventing crashes with thinking models (#1492). A missing await on memory.add is also fixed so intermediate summaries are actually persisted (#1477). If you copied the example, rename ReflectFailure.decompose_subtask.rephrased_plan to failed_subtask (#1151).

  • Structured-output fallback — OpenAI chat models now fall back from response_format parsing to forced tool-call JSON when an endpoint does not support or rejects JSON-schema structured output (#1430). This improves compatibility with OpenAI-compatible providers; once triggered, the model instance continues using tool-call mode for subsequent structured requests.

  • Hook and token-accounting fixes — Subclasses overriding _reasoning or _acting no longer execute hooks twice (#1481). Anthropic input-token counting is refined (#1319), and OpenAITokenCounter tolerates tool properties missing type, avoiding KeyError failures with PlanNotebook schemas (#1403).

  • Breaking changes — None.
