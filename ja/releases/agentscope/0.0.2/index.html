エージェントスコープ v0.0.2

何が変わったのか

  • ReActAgent エージェントを追加
  • web_digestサービスを追加
  • 例をさらに追加します
    • メンションによる自律的な会話
    • 自己組織化された会話
    • LangChain ライブラリとの基本的な会話
    • ReAct Agentとの会話
    • RAG エージェントとの会話 *五目並べ
    • 分散討論
    • 分散並列検索
  • モデルラッパーをさらに追加します
    • DashScope: チャット、画像合成、テキスト埋め込み
    • 双子座: チャット、埋め込み
    • Ollama: チャット、埋め込み、生成
  • PromptEngine を置き換えるためにモデル ラッパー (チャットと生成) にフォーマット機能を追加
  • AgentScope Studio を追加
  • ドキュメントを適宜更新します

agentscope v0.0.2

Highlights

  • ReAct and RAG primitives — ReActAgent (#104) adds a reason–act loop for tool-using agents, while the packaged RAG module (#64) makes retrieval a reusable component. Developers can compose these patterns directly instead of building separate orchestration layers.
  • Broader model backend support — DashScope adds chat, image synthesis, and embeddings (#54); Gemini adds chat and embeddings (#59); Ollama adds chat, embeddings, and generation (#60). This enables hosted-to-local backend swaps, though message roles and prompt formatting should be regression-tested per provider, especially after the Qwen preprocessing changes (#73).
  • Prompt API migration — Chat and generation wrappers now expose format() to replace PromptEngine (#95; corrected in #105). Custom prompt-building code should move to the wrapper API and be checked for role ordering and provider-specific template behavior.
  • Web and visual development tooling — web_digest (#84) adds web-page digestion as a service for agent workflows, while AgentScope Studio gains ModelScope Gradio support (#44), usage guidance (#83), and reduced unnecessary logging (#96). This lowers the friction of supplying web content to agents and observing their behavior.
  • Multi-agent coordination patterns — Mention-aware group chat (#55), multi-user distributed debate (#68), pipeline participants (#107), and distributed parallel search (#121) expand beyond single-agent conversations. The examples provide reference architectures for routing turns and coordinating work across users and agents.
  • Compatibility — No other breaking changes are explicitly listed; the PromptEngine-to-format() migration is the main upgrade risk.
