エージェントスコープ v2.0.5

ハイライト

エージェント

  • 構造化出力のサポート (#2150)
  • 環境情報の挿入をサポート (#2134)

ワークスペース

  • OpenSandbox (#1953)、Daytona (#1943)、K8s (#1933)、Bubblewrap (#2051) をサポート

ツール

ラグ

モデル

agentscope v2.0.5

Highlights

  • Typed agent outputs and runtime awareness — Agent supports structured output and runtime state/environment injection (#2150, #2134), enabling schema-driven results and decisions based on current execution context rather than prompt-only extraction.
  • More portable workspaces and safer Windows tooling — OpenSandbox, Daytona, Kubernetes, and Bubblewrap broaden execution choices (#1953, #1943, #1933, #2051); K8s adds Pod/PVC lifecycle management, tar streaming, and an MCP gateway. Windows workspaces gain PowerShell (#2132), while read-only permissions now reject mutating find commands (#2004).
  • Expanded RAG backends and document coverage — MongoDB and Elasticsearch vector stores plus Excel/Word parsers support more existing data stacks (#2008, #2129, #2026, #2025). MilvusLite users should revalidate similarity thresholds after the milvus-lite 3.1.0 COSINE-distance adaptation (#2089), because ranking behavior may change.
  • Relational persistence and shared service resources — Agent as Service adds SQLAlchemy-based storage and group/org sharing of credentials, agents, and knowledge bases (#2029, #1998), enabling reusable multi-user deployments; review credential access boundaries before enabling sharing.
  • Provider expansion with compatibility checks — Dashscope, Kimi K3, and Gemini TTS broaden model and voice options (#2073, #2141, #1879), while nullable Gemini schemas and OpenAI/Anthropic reasoning replay are repaired (#2020, #2071, #2139). Check custom OpenAI wrappers for max_completion_tokens (#2065), MCP <2.0.0 (#2091), and reorganized optional dependency groups (#2157).
  • Breaking changes — None explicitly declared in this release.
