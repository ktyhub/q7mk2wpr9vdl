archify v3.1.0

Highlights

  • Ten types, five new — Archify jumps from five to ten diagram types, adding ERD, Class/interface, Tree, Timeline and Waterfall alongside Architecture, Workflow, Sequence, Dataflow and Lifecycle. Practically, schema/data-modeling and scheduling diagrams become first-class instead of approximations — but note the provenance rule: Timeline/Waterfall values only get a factual/measured label when backed by evidence, so illustrative examples stay explicitly marked. Treat generated numbers as examples until you supply sources.

  • Live motion is now the default — but it's presentation, not source — All ten types animate out of the box, a visible behavioral change for anyone with existing diagrams. The important design detail is that type-specific motion is stored separately from authored topology: switching to Still is a render toggle, not a source rewrite. That means one topology can feed both animated and deterministic/static output (docs, print, CI snapshots) without forking artifacts — the thing to watch is reproducibility if you expected frozen images.

  • A real authoring/validation pipeline, not a black box — Structured authoring diagnostics, bounded recovery, source verification, and distinct input / artifact / browser delivery gates. For automation this is the operational upgrade: failures are diagnosable, recovery is bounded (no runaway retry loops), and the three gates let you assert correctness at each stage — input sanity, generated artifact, and rendered browser output — instead of only eyeballing the final diagram. Worth wiring into CI if you generate diagrams at build time.

  • Portability and reader fixes — Export, clipboard and Windows path portability fixes, plus a localized optional repository link inside the reader-opened Guide. Mixed-OS teams benefit most: previously generated paths/links could break on Windows, so re-test any shared artifacts after upgrading. The localized Guide link is a small but real self-service win for non-English readers.

  • Manual perceptual review is still required — Automated validation does not replace it: expect initial-viewport control overlap in some long Sequence diagrams, shared visual corridors in some Dataflow diagrams, and awkward wrapping of long Class generic types. Budget a visual QA pass for these three cases before publishing; "validated" here means structurally sound, not visually clean.

  • Ecosystem lag and follow-ups — The independently published DSH plugin is still 1.0.0 / bundled Archify 3.0.1, with sync deferred to a separate follow-up, so the new types won't surface through that plugin yet. Public examples, README previews and website entry points are tracked in #916, #917 and #918. Upgrades are also owner-opt-in only — nothing force-updates existing installs.

No breaking changes.

Archify 3.1.0

https://github.com/user-attachments/assets/d6144aba-cb48-4692-a24d-b43bf7be62c2

30 seconds of Archify 3.1: five new diagram types, Live motion, light and dark.

Ten diagram types, with Live motion enabled by default: ERD, Class/interface, Tree, Timeline and Waterfall join Architecture, Workflow, Sequence, Dataflow and Lifecycle.

  • Type-specific motion stays separate from authored topology; switch to Still when needed.
  • Clearer cards, routing/label coordination, Sequence notes, Lifecycle layouts, and long-page reader navigation.
  • Structured authoring diagnostics, bounded recovery, source verification and distinct input/artifact/browser delivery gates.
  • Export, clipboard and Windows path portability fixes; a localized optional repository link inside the reader-opened Guide.

Full changelog · Release scope and trial-use evidence

Download archify.zip below, or use the canonical Skill source. Existing installations update only when their owner chooses to upgrade.

Known limitations include initial-viewport control overlap in some long Sequence diagrams, shared visual corridors in some Dataflow diagrams, and awkward wrapping of long Class generic types. Automated validation does not replace perceptual review. Timeline/Waterfall values require evidence to be described as factual/measured; illustrative examples remain labelled.

The independently published DSH plugin remains 1.0.0 / bundled Archify 3.0.1; its synchronization is a separate follow-up. Expanded public examples, README previews and website entry points are tracked in #916, #917 and #918.
